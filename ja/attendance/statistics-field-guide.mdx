## 1. 機能概要

企業のさまざまな勤怠統計シーンのニーズに応えるため、DingTalk はベーシックな勤怠統計フィールドを提供しており、日常の勤怠統計を効率化します。さらに、勤怠フィールドのカスタマイズ設定オプションも提供しており、企業がより柔軟に勤怠データを統計できるようサポートします。

## 2. 利用シーン

企業の勤怠統計レポートに個別のニーズがある場合に利用できます。

## 3. 操作手順

管理者は **PC 版 DingTalk > ワークベンチ > 勤怠打刻 > 勤怠統計 > レポート設定 > フィールド管理** を開き、対象フィールドの **編集** をクリックします。フィールドの編集方法には **オプションモード** と **エキスパートモード** の 2 種類があります。

<Note>
**操作上の注意事項：**

1. **オプションモード**：システム標準フィールドは、オプションモードでルールを編集できます。例：所定出勤日数、出勤日数、労働時間、出勤シフトなど。

2. **エキスパートモード**：企業はカスタム関数を利用して、個別・カスタマイズされた統計ルールを実現できます。システムが提供する演算子、フィールド、関数を用いて、企業に必要な計算ロジックとルールを記述できます。

3. **エキスパートモード** の利用には **DingTalk Pro** の開通が必要です。年間レポートの作成に対応し、複数月または年単位でのデータエクスポートが可能で、個別の勤怠ニーズに応えます。

4. 勤怠 **エキスパートモード** の紹介動画は、**こちら** をクリックしてご覧いただけます。
</Note>

## 4. フィールドの紹介

### 固定フィールド

*   **名前、勤怠グループ、部門、社員番号、職位** は固定フィールドであり、すべてのレポートに表示されます。レポート内での **削除** および **編集** は **できません**。

### ベーシックフィールド

| **ベーシックフィールド** | **説明** |
| --- | --- |
| 打刻時刻 | 社員が出退勤時に有効な打刻を行った時刻。以下のフィールドを含みます：出勤 1 打刻時刻、退勤 1 打刻時刻、出勤 2 打刻時刻、退勤 2 打刻時刻、出勤 3 打刻時刻、退勤 3 打刻時刻 |
| 打刻結果 | 社員の出退勤打刻と勤怠時間に基づいて生成される勤怠結果。以下のフィールドを含みます：出勤 1 打刻結果、退勤 1 打刻結果、出勤 2 打刻結果、退勤 2 打刻結果、出勤 3 打刻結果、退勤 3 打刻結果 |
| 関連する承認フォーム | 休暇申請、出張、打刻修正など勤怠に関連する承認フォーム |

### 出勤統計フィールド

| **出勤統計フィールド** | **説明** |
| --- | --- |
| 所定出勤日数 | 統計期間内でシフトが組まれている日数を集計します。ただし、統計期間内の法定休日、休息日、またはシフト未設定の日は、所定出勤日数として集計されません |
| 打刻修正回数 | 統計期間内に社員の打刻修正が承認された回数 |
| 出勤シフト | 社員が当日入るシフト |
| 出勤日数 | 統計期間内に社員が打刻した日数を表示。出勤日数ルールのカスタム設定に対応 |
| 休息日数 | 統計期間内に社員が打刻した日数を表示。出勤日数ルールのカスタム設定に対応 |
| 労働時間 | 社員の打刻の合計時間を表示。ルールのカスタム設定に対応 |
| 出張時間 | 統計期間内に社員が承認済みのすべての出張のうち、シフト時間帯内の出張合計時間（注：出張同行者のデータも自動的に同期されます） |
| 外出時間 | 統計期間内に社員が承認済みのすべての外出のうち、シフト時間帯内の外出合計時間 |
| 勤怠結果 | 社員の毎日の打刻結果 |
| シフト | 社員が当日のシフト設定で組まれたシフト |

### エラー統計フィールド

| **エラー統計フィールド** | **説明** |
| --- | --- |
| 遅刻回数 | 統計期間内に社員が出勤遅刻とカウントされた回数 |
| 遅刻時間 | 統計期間内に社員が出勤遅刻とカウントされた合計時間 |
| 重大遅刻回数 | 統計期間内に社員が重大遅刻とカウントされた回数 |
| 重大遅刻時間 | 統計期間内に社員が重大遅刻とカウントされた合計時間 |
| 欠勤遅刻回数 | 統計期間内に社員が欠勤遅刻とカウントされた回数 |
| 早退回数 | 統計期間内に社員が退勤早退した回数 |
| 早退時間 | 統計期間内に社員が退勤早退した合計時間 |
| 出勤打刻漏れ回数 | 統計期間内に社員が出勤打刻漏れとなった回数 |
| 退勤打刻漏れ回数 | 統計期間内に社員が退勤打刻漏れとなった回数 |
| 欠勤遅刻日数 | 統計期間内に社員が欠勤遅刻とカウントされた回数 |

### 休暇申請統計フィールド

| **休暇申請統計フィールド** | **説明** |
| --- | --- |
| 休暇申請 | 統計期間内に社員が承認済みの休暇申請承認フォームの合計時間 |

### 残業統計フィールド

| **残業統計フィールド** | **説明** |
| --- | --- |
| 残業承認フォーム統計 | 承認統計期間内に社員が平日、休息日、祝日に残業した合計時間 |
| 平日残業 | 統計期間内に社員が承認済みの平日残業時間の合計 |
| 休息日残業 | 統計期間内に社員が承認済みの休息日残業時間の合計 |
| 祝日残業 | 統計期間内に社員が承認済みの祝日残業時間の合計 |

## 5. よくある質問

<AccordionGroup>
  <Accordion title="出勤日数はどのように計算されますか？">

出勤日数の集計は、管理者が設定した出勤日数ルールに従って計算されます。未設定の場合は、システムのデフォルトルールに従って計算されます。すなわち、打刻ベースで計算され、休息日でもシフト設定日でも、打刻があれば出勤として集計されます。出勤日数ルールのカスタム設定に対応しています。管理者は **PC 版 DingTalk > ワークベンチ > 勤怠打刻 > 勤怠統計 > レポート設定 > フィールド管理** を開き、**出勤日数** フィールドの **編集** をクリックします。

  </Accordion>
  <Accordion title="所定出勤日数の計算が誤っている場合はどうすればよいですか？">

月次集計レポートに所定出勤日数のフィールドがない場合は、管理者がまずレポートに該当フィールドを追加する必要があります。管理者の操作パス：**PC 版 DingTalk > ワークベンチ > 勤怠打刻 > 勤怠統計 > レポート設定 > フィールド管理 > 所定出勤日数 > 編集** で保存すれば完了です。

<Note>
**操作上の注意事項：**

1. フレックスタイムは所定出勤日数として集計されません。

2. シフト未設定の場合は、所定出勤日数に計上されません。

3. 旧版の勤怠レポートは所定出勤日数の統計ルール設定に対応していないため、新版の勤怠レポート設定に切り替える必要があります。
</Note>

  </Accordion>
</AccordionGroup>
