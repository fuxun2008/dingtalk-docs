## 1. 機能概要

DingTalk勤怠打刻では、管理者がモバイル版でチームの勤怠データをかんたんに確認できます。

<Note>
**ご注意**：

1. 部門マネージャーは、自部門のデータを閲覧できます（部門マネージャーはDingTalk管理コンソールの組織構成と連動します）。

2. 勤怠管理者・勤怠グループ責任者・企業責任者は、勤怠グループのデータを閲覧できます。
</Note>

## 2. 適用シーン

スマートフォンで勤怠データを確認したい場面に適しています。

## 3. 操作説明

**モバイル版DingTalk > ワークベンチ > 勤怠打刻 > 統計** を開き、**チーム統計 / マイ統計** を切り替えて、**レポートのエクスポート** や **日次統計・週次統計・月次統計** を確認できます。

### レポートのエクスポート

**月次サマリー・日次統計・不正行為の疑いレコード・打刻レコード・原本レコード** の5種類のレポートタイプから選択でき、期間とメンバー範囲を指定できます。

<Note>
**レポートの説明：**

1. 月次サマリー：月単位の勤怠データのサマリーです。

2. 日次統計：日単位の勤怠データのサマリーです。

3. 不正行為の疑いレコード（ベーシックレポート）：社員の不正行為の疑いを記録し、照会・確認に活用できます。削除できません。

4. 打刻時間（ベーシックレポート）：社員の毎日の出退勤打刻時間を記録します。削除できません。

5. 原本レコード（ベーシックレポート）：社員一件ごとの打刻レコードを記録し、照会・確認に活用できます。削除できません。
</Note>

### 日次データ

勤怠権限を持つユーザーは、任意の日付を選択して、その日の出勤サマリーと出勤状況を確認できます。また、**打刻人数 / 出勤予定人数** をタップすると、打刻済みのメンバーおよび出勤予定で未打刻のメンバーのリストを確認でき、該当する社員に打刻の通知を送信できます。

### 週次統計 / 月次統計

任意の期間を選択すると、その期間の出勤サマリーを確認できます。

## 4. フィールド統計の説明

### 打刻人数

*   当日、実際に打刻を行ったメンバーの合計です。通常打刻・外勤打刻・遅刻打刻・早退打刻を含み、出張または外出状態で打刻を行ったメンバーや、シフトが設定されていなくても打刻を行ったメンバーも対象となります。当日の出勤が不要なメンバーが打刻した場合、打刻人数が出勤予定人数を上回ることがあります。なお、当日休暇申請を提出したメンバーは打刻人数から除外されます。

### 出勤予定人数

*   当日、出勤が必要なメンバーの合計です。管理者によって勤怠グループに追加され当日出勤が必要なメンバー、勤怠参加不要ユーザー / 勤怠グループ未参加 / シフト未設定 / 休みでも打刻を行ったメンバー、フレックスタイム（当日が勤務日）勤怠グループのメンバー、フレックスタイム（勤務日未設定）で手動で打刻したメンバーが含まれます。ただし、当日終日の休暇申請を提出したメンバー、休み、シフト未設定、終日外出 / 出張（外出 / 出張時に打刻不要と設定した場合に有効）のメンバーは除外されます。

### 出勤予定だが未打刻

*   当日、出勤が必要であるにもかかわらず打刻していないメンバーの合計です。シフト設定済みで未打刻のメンバー、フレックスタイム（当日が勤務日）勤怠グループで未打刻のメンバー、出張 / 外出時に未打刻のメンバー、フレックスタイム休暇申請中で未打刻のメンバーが含まれます。ただし、終日の休暇申請（フレックスタイム休暇申請は含まない）、終日の休み、シフト未設定のメンバー、終日外出 / 出張（外出 / 出張時に打刻不要と設定した場合に有効）は含まれません。
