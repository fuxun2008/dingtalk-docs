## 機能概要

管理者は **社員向けにメッセージ通知のデフォルトをオン / オフに設定** できます（打刻リマインダー、個人勤怠日報 / 月報 / 週報、打刻漏れリマインダーを含む）。関連設定を自ら変更したことがない社員のみに適用され、適用後も社員は打刻アプリ内で個別に設定を変更できます。

## 適用シーン

組織管理者が社員向けに打刻通知のメッセージ通知を設定するシーンに適しています。

## 操作手順

### 打刻リマインダー

#### 個人打刻リマインダー

**モバイル版 DingTalk ＞ ワークベンチ ＞ 勤怠打刻 ＞ 個人設定 ＞ 打刻リマインダー** を開き、**DING リマインダー / 業務通知 / システムアラームリマインダー** を設定できます。

<Note>
**操作にあたっての注意事項：**

1. DING リマインダー：定時に連続着信でメッセージ通知を送信します。

2. 業務通知：定時にアプリのメッセージ通知を送信します。

3. システムアラーム：スマートフォンのアラームによるリマインダーです。
</Note>

### 個人勤怠日報 / 月報 / 週報

権限を持つ管理者は、**モバイル版 DingTalk ＞ ワークベンチ ＞ 勤怠打刻 ＞ 設定 ＞ その他設定 ＞ 通知管理 ＞ 個人勤怠統計通知社員** を開き、個人勤怠日報 / 月報 / 週報の **オン / 閉じる** を切り替えられます。

<Note>
操作にあたっての注意事項：

1. 個人勤怠日報：毎日退勤後、統計を確認するよう社員へリマインドします。

2. 個人勤怠週報：毎週月曜日に統計を確認するよう社員へリマインドします。業務通知 / DingMail のいずれかの方法でプッシュできます。

3. 個人勤怠月報：毎月最初の営業日に統計を確認するよう社員へリマインドします。
</Note>

## デフォルト有効化時の動作説明

### 打刻リマインダー

管理者が社員向けに打刻リマインダーをオンにし、社員が設定を変更しない場合、リマインド時刻は始業 10 分前となります。

### 個人勤怠月報 / 週報

オンにした場合、社員は毎月最初の営業日に打刻月次統計メッセージを、毎週月曜日に打刻週次統計メッセージをデフォルトで受信します。

### 打刻漏れリマインダー

オンにした場合、毎日 10:00 以降に前日分の打刻漏れリマインダーが業務通知の形式でプッシュされます。
