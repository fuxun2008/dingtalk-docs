## 1. 機能概要

DingTalk は強力な勤怠・シフト管理機能を提供しており、企業の実情に合わせて各種シフトルールを柔軟に設定できます。シフトを適切に設定することで、より効率的な勤怠管理を実現できます。

## 2. 適用シーン

企業内で異なる勤怠対象者がそれぞれ異なるシフトで勤務するシーンに適しています。

## 2. 操作フロー

### モバイル版

権限を持つ管理者は、次のパスから操作できます：**モバイル版 DingTalk > ワークベンチ > 勤怠打刻 > 設定 > その他の設定 > シフト管理 > シフトの作成／変更／削除**

## 3. シフト設定項目の説明

| **フィールド名** | **説明** |
| --- | --- |
| シフト名 | 企業のニーズに応じてシフト名を設定します。 |
| シフト担当者 | 勤怠権限を持つ管理者のみをシフト担当者として選択できます。シフト担当者はシフトの変更・削除が可能です。 |
| 出退勤時間 | 企業の出退勤時間に基づいてユーザーの打刻時間を設定します。 |
| 打刻時間帯 | 企業ユーザーの勤怠打刻における最早・最遅の打刻時間を設定できます。 |
| 休憩時間 | 休憩時間をオンにして休憩時間帯を設定できます。複数の休憩時間の追加に対応しており、シフト内の休憩時間は労働時間に算入されません。 |
| フレックス打刻 | フレックス打刻には 3 つの方式があります：**遅出・遅退勤の許可、早出・早退勤の許可、数分の遅刻・早退をエラーとして扱わない、退勤が遅れた場合に翌日の遅出を許可**。詳細は **こちらをクリックしてご確認ください**。 |
| エラールール | 深刻な遅刻・欠勤とみなす遅刻分数を設定できます。 |

## 4. よくある質問

<AccordionGroup>
  <Accordion id="q1" title="シフト作成に上限はありますか？">

シフト作成の上限は 8000 件です。

  </Accordion>
  <Accordion id="q2" title="シフト名は重複できますか？">

シフト名は重複できません。

  </Accordion>
  <Accordion id="q3" title="シフトを一括で作成・削除できますか？">

シフトの一括作成・削除には対応していません。

  </Accordion>
  <Accordion id="q4" title="シフト管理内のシフトは並び替えに対応していますか？">

シフトは並び替えに対応していません。シフトの作成順序は、数値、アルファベット、漢字の順です。

  </Accordion>
  <Accordion id="q5" title="シフトを編集できないのはなぜですか？">

企業のスーパー管理者、または勤怠打刻権限を持つサブ管理者のみが編集できます。権限を持つ管理者に連絡し、[**管理コンソール**](https://oa.dingtalk.io) > **安全と権限 > 権限管理** から**スーパー管理者／サブ管理者**を設定してください。

  </Accordion>
</AccordionGroup>
