## 1. 機能概要

DingTalk勤怠打刻は、プロフェッショナルかつスマートな勤怠管理ツールです。勤怠・休暇・残業など全シーンをカバーする勤怠管理ソリューションを企業に提供し、勤怠管理の効率を大幅に向上させます。

DingTalk勤怠打刻では、管理者が管理コンソールで社員の勤怠・休暇・残業などのルールをカスタム設定できます。社員は企業が設定したルールに従って打刻や残業申請などの操作を行い、システムが社員の勤怠データを自動的に記録します。

## 2. 適用シーン

*   企業の日常勤怠管理：社員の出退勤時刻、遅刻・早退を記録します。

*   外出勤怠管理：固定場所以外での打刻シーンに対応し、チームの出勤状況を的確に把握できます。

*   チェーン業界の管理：複数拠点にまたがる店舗の勤怠データを一元管理します。

*   柔軟なシフト設定：プロジェクトチームやフリーランサーに適用します。

*   残業管理：残業時間を集計し、承認や代休の運用に活用できます。

*   その他、勤怠管理を必要とするあらゆるシーン。

## 4. 勤怠打刻を使いこなす

<Note>
勤怠打刻は主にシフト管理・勤怠グループ管理・勤怠ルール管理・休暇管理・データ管理の5つで構成されています。以下の5ステップに従って、勤怠管理を短時間で習得できます。
</Note>

### シフト管理

DingTalk勤怠打刻では、管理者がシフト（1日の出退勤時間と打刻ルール）を設定できます。設定完了後、シフトを勤怠グループに適用できます。

#### 操作パス

**PC版DingTalk > ワークベンチ > 勤怠打刻 > シフト管理** ページを開き、 **シフト追加** をクリックして新しいシフトの作成を開始します（既存のシフトがある場合は、**編集** をクリックして修正ページに入ることもできます）。

 **⚠️ 操作上の注意事項：**

シフト責任者は、自身が担当するシフトを削除・修正できます。デフォルトではシフトの作成者が責任者となり、他の管理者を追加して共同管理できます。

<Frame caption="シフト追加の操作手順の例">
![シフト追加の操作手順](https://img.alicdn.com/imgextra/i3/O1CN01GUjyK2zoejI2WiwC_!!6000000006639-2-tps-1245-667.png)
</Frame>

#### シフト追加の内容

 **⚠️ 操作上の注意事項：**

1. シフト責任者：シフト責任者は、自身が担当するシフトを削除・修正できます。デフォルトではシフトの作成者が責任者となり、他の管理者を追加して共同管理できます。

2. 打刻時間帯の設定：打刻時間帯外の打刻は勤怠に計上されません。

3. 退勤遅め、翌日出勤遅め可：前日の退勤が遅かった場合、翌日は遅めに出勤できます。固定シフト制の社内打刻のみ対応しています。

4. シフト労働時間：勤怠統計における労働時間、および休暇・出張・外出の集計は、この時間を基準とします。

1.  基本情報の設定：シフト名と責任者を設定します。

2.  シフトの勤怠時間の設定：複数回の出退勤、または1回の出退勤と打刻時間帯を設定できます。打刻時間帯を超えた打刻は勤怠に計上されません。

<Frame caption="シフトの勤怠時間設定ページの例">
![シフトの勤怠時間設定ページ](https://img.alicdn.com/imgextra/i2/O1CN01M6GUPaF2d9G2akgm_!!6000000004216-2-tps-1277-679.png)
</Frame>

3.  柔軟な打刻の設定。

| **柔軟なタイプ** | **説明** |
| --- | --- |
| **遅め出勤・遅め退勤、早め出勤・早め退勤を許可** | 出勤が遅ければ退勤も遅く、出勤が早ければ退勤も早くできます。1日4回打刻には現在対応していません |
| **遅め出勤・早め退勤の許容時間（エラーとしない）** | 出勤時の遅刻や退勤時の早退が何分以内であれば遅刻・早退としないかを設定できます |
| **退勤遅め、翌日出勤遅め可** | 前日の退勤が遅かった場合、翌日は遅めに出勤できます |

4.  何分以上の遅刻を重大な遅刻・欠勤扱いとするかを設定できます。

<Frame caption="遅刻扱いとする時間設定ページの例">
![遅刻扱いとする時間設定ページ](https://img.alicdn.com/imgextra/i3/O1CN01gSKtdqMaabE2clZA_!!6000000007966-2-tps-1293-691.png)

### 勤怠グループ管理

DingTalk勤怠打刻は「勤怠グループ」を単位として勤怠管理を行います。以下の手順に従って、勤怠ルールの編集を試してください。

#### 操作パス

**PC版DingTalk > ワークベンチ > 勤怠打刻 > 勤怠グループ管理** ページを開き、 **勤怠グループ追加** をクリックして新しい勤怠グループの作成を開始します（既存の勤怠グループがある場合は、**編集** をクリックして修正ページに入ることもできます）。

<Frame caption="勤怠グループの追加・修正の操作手順の例">
![勤怠グループの追加・修正の操作手順](https://img.alicdn.com/imgextra/i3/O1CN01SxOm3ar758K2WyXz_!!6000000004056-2-tps-1247-668.png)
</Frame>

#### 勤怠ルールの編集内容

1.  基本情報の設定：勤怠グループの名前、責任者、勤怠参加メンバーなどを設定します。

2.  勤怠タイプの設定：DingTalk勤怠打刻は4種類の勤怠タイプを提供しています。ニーズに応じて選択・設定し、出勤シフトを選択できます。

| **勤怠タイプ** | **説明** | **適用範囲** |
| --- | --- | --- |
| **固定シフト制** | 固定の出退勤時間を設定し、社員は固定時間に従って出退勤します | 事業単位、製造業、金融など出社型勤務 |
| **シフト制** | 社員ごとにシフトを設定し、社員は設定されたシフトに従って出退勤します | 工場、店舗などの交替勤務制 |
| **自由シフト制** | 固定の出退勤時間はなく、社員は時間範囲内で自由に打刻します | 臨時工、アルバイトなど柔軟な雇用形態 |

3.  打刻方法の設定：DingTalk勤怠打刻は4種類の勤怠方法を提供しています。ニーズに応じて選択・設定できます。

| **勤怠方法** | **説明** | **適用範囲** |
| --- | --- | --- |
| **位置情報打刻** | 位置情報の範囲を設定し、社員が指定位置に到着後に打刻します | 固定の勤務地がある場合 |
| **Wi-Fi打刻** | 指定のWi-Fiネットワークを設定し、社員が指定のWi-Fiに接続して打刻します | 固定のオフィスWi-Fiがある場合 |
| **打刻機打刻** | DingTalk打刻機を設定し、社員が打刻機を通じて打刻します | 固定の勤務地があり、打刻機を設置している場合 |
| **Zhidian.Bluetooth打刻** | 設定されたBluetooth指定範囲内で打刻機のBluetoothに接続して打刻します | 固定の勤務地があり、スマートBluetooth打刻機を設置している場合 |

    詳細は **4種類の勤怠方法の違い（位置情報、Wi-Fi、Zhidian.Bluetooth、打刻機）** をご参照ください。

4.  その他の勤怠設定：勤怠グループに対して、残業ルール、外勤打刻、休日打刻、打刻修正ルール、写真打刻、顔認証打刻など、さらに詳細な勤怠ルールを設定できます。

### 勤怠ルール管理

DingTalk勤怠打刻は残業、打刻修正、外出・出張、その他のルール管理機能を備えており、社内の各種ルールを一元的に管理できます。

**PC版DingTalk > ワークベンチ > 勤怠打刻 > 勤怠ルール管理** ページを開き、設定するルールをクリックします。

| **ルール名** | **説明** |
| --- | --- |
| 残業ルール | 残業ルール名、適用する勤怠グループの範囲、残業時間の計算方式などを設定できます |
| 外出、出張ルール | 外出・出張ルール名、適用範囲、打刻ルール、打刻時間範囲を設定できます |
| 打刻修正ルール | ルール名、適用範囲、打刻修正回数、打刻修正の期限、打刻修正のタイプを設定できます |
| その他のルール | 勤怠ホワイトリスト、休暇申請時の出社・退社時の打刻要否、半日の時間定義、勤怠グループ外での打刻ルール、写真承認打刻の可否を設定できます |

### 休暇管理

DingTalk勤怠打刻は休暇管理機能も備えており、社内の各種休暇を一元的に管理できます。

#### 操作パス

**PC版DingTalk > ワークベンチ > 勤怠打刻 > 休暇管理** ページを開きます。DingTalk勤怠打刻には、年次有給休暇、私用休暇、代休などのテンプレートがあらかじめ用意されています。**編集** をクリックして修正・利用したり、**休暇ルール追加** をクリックして新しい休暇タイプを作成したりできます。

<Frame caption="休暇ルール追加の操作手順の例">
![休暇ルール追加の操作手順](https://img.alicdn.com/imgextra/i2/O1CN01TaCkS1Au6sL2XbZI_!!6000000001831-2-tps-1252-660.png)
</Frame>

#### 休暇ルールの編集内容

1.  基本情報：休暇の名称、責任者、適用範囲などを設定します。

2.  付与ルールの編集：休暇が **上限あり** の場合は、付与サイクルや付与数量などの付与ルールを設定します（上限なしの休暇では、このステップは不要です）。

3.  休暇の利用期限の制限：休暇失効後の延長可否、失効後に保持可能な時間、休暇失効前のリマインドを設定できます。

 **⚠️ 操作上の注意事項：**

1. 有給かどうか：社員が有給休暇を取得した場合、勤怠統計では出勤として計算されます。

2. 最小休暇申請単位：時間単位で休暇申請を選択した場合、社員は1時間を最小単位として時間を選択でき、勤怠レポートも時間単位で集計されます。

![休暇ルール設定ページ](https://img.alicdn.com/imgextra/i3/O1CN01sLVrZg3OX0L2Z7EB_!!6000000005435-2-tps-1264-675.png)

### データ管理

DingTalk勤怠打刻は社員の勤怠データを自動的に記録し、勤怠打刻管理コンソールから手軽に確認・管理できます。

勤怠統計：**PC版DingTalk > ワークベンチ > 勤怠打刻 > 勤怠統計** ページを開くと、社員の勤怠データを閲覧・エクスポートできます。社員の打刻結果に誤りがある場合は、エラー結果を手動で修正できます。
