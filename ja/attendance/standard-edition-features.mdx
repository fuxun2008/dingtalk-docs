DingTalkインターナショナル版の勤怠は**スタンダード版**で、シンプルな出退勤シーンを対象とし、大多数の企業のシフト設定と労働時間計算を無料でサポートします。主な機能は以下のとおりです。

- 勤怠ルール設定
- 社員のシフト設定
- 社員のモバイル打刻、打刻機による打刻
- 休暇・勤怠承認
- 勤怠統計とレポート
- 勤怠確認

## スタンダード版機能一覧

以下の表は、スタンダード版で対応している機能の一覧です。一部の機能はスタンダード版で利用制限があります（「説明」欄に記載）。

| 機能モジュール | 機能 | 説明 |
| --- | --- | --- |
| ベーシック設定 | 稼働カレンダー | 元日・春節などの国民の祝日を自動同期（スタンダード版はカスタム祝日に非対応） |
| ベーシック設定 | 労働時間制度 | 標準労働時間制に対応（スタンダード版は変形労働時間制および裁量労働制に非対応） |
| ベーシック設定 | 休暇・勤怠承認 | 休暇申請、外出、出張、打刻修正などの承認により勤怠エラーを処理可能 |
| 勤怠グループ管理 | 勤怠対象メンバー | メンバーや部門単位で勤怠グループを素早く作成可能。新規社員が部門に加入すると自動で同期 |
| 勤怠グループ管理 | 勤怠時間 | 固定シフト制、シフト制に対応。フレックスタイム（労働時間を満たせばよい）にも対応 |
| 勤怠グループ管理 | 勤怠方式 | 位置情報打刻、Wi-Fi打刻、Bluetooth打刻、打刻機打刻など複数の方式に対応 |
| 勤怠グループ管理 | 関連ルール | 勤怠グループ単位で残業ルール、打刻修正ルール、外勤打刻、外出・出張ルールなどを設定可能 |
| シフト管理 | 固定シフト | 固定シフトに対応。1日1回または複数回の出退勤に対応 |
| シフト管理 | フレキシブルシフト | 早出早退、遅出遅退、遅くまで残業した翌日は遅出可などに対応 |
| シフト管理 | エラールール | シフト時刻に基づく遅刻・早退エラーの設定に対応 |
| シフト設定管理 | メンバー別シフト設定 | メンバー別のシフト設定に対応 |
| シフト設定管理 | サイクル別シフト設定 | 1つまたは複数のサイクルを設定して循環シフトを組むことが可能 |
| 社員打刻 | 打刻機による打刻 | DingTalk打刻機、入退室管理システムで指紋・顔認証打刻に対応 |
| 社員打刻 | モバイル打刻 | GPSによる高精度位置情報打刻、社内Wi-Fiおよび打刻機のBluetooth打刻に対応 |
| 打刻修正管理 | 打刻修正回数 | 月単位で打刻修正回数を設定可能 |
| 打刻修正管理 | 打刻修正タイプ | 遅刻／早退／打刻漏れなどのエラータイプごとに打刻修正の可否を設定可能 |
| 打刻修正管理 | 打刻修正期限 | 打刻修正申請の期限設定に対応 |
| 残業管理 | 残業タイプ | 平日／休日／祝日の残業ルールを個別に設定可能 |
| 残業管理 | 残業時間帯 | 始業前・終業後を残業として計算するかどうかを設定可能 |
| 残業管理 | 残業時間の計算方式 | 打刻時間／承認時間／承認時間帯内の打刻時間による計算に対応 |
| 残業管理 | 残業時間の端数処理 | スタンダード版は切り捨てのみ対応 |
| 残業管理 | 休憩時間の控除 | 時間帯別控除、残業時間別控除に対応 |
| 残業管理 | 残業補償 | 残業手当または代休への振替、あるいは社員自身による選択に対応 |
| 残業管理 | リスク警告 | 日／週／月単位で残業警告の上限を設定可能 |
| 休暇管理 | 手動付与 | 休暇残数の手動付与に対応 |
| 休暇管理 | 定期付与 | 毎年／毎月、ルールに基づき休暇残数を付与可能 |
| 休暇管理 | 残業の代休振替 | 残業時間に応じた代休への自動振替に対応 |
| 勤怠統計 | 日／週／月単位でのチーム統計の閲覧 | 社員の出勤レコードと結果をリアルタイムで確認可能 |
| 勤怠統計 | 日／週／月単位での社員統計の閲覧 | 社員が自身の勤怠レコードと結果をセルフサービスで確認可能 |
| 勤怠レポート | 打刻の元レコード | 打刻の元レコード、打刻時刻、および不正打刻の疑いのある行為の記録に対応 |
| 勤怠レポート | 集計統計レポート | 日別／月別の集計レポートのエクスポートに対応 |
| 勤怠レポート | 勤怠結果の修正 | 管理者による個別／一括の勤怠結果修正に対応 |
| 勤怠レポート | 勤怠確認 | 勤怠確認を送信し、社員が勤怠データをタイムリーに確認可能 |
