## 1. 機能概要

DingTalk の **勤怠申請** 入口は、社員が DingTalk プラットフォーム上で休暇申請・残業・打刻修正など各種の勤怠申請を発起できる機能モジュールです。複数タイプの勤怠申請フォームを統合し、カスタム設定にも対応しているため、企業ごとのニーズに柔軟に応えられます。社員は数ステップの操作で申請を完了でき、管理者も迅速にリクエストへレスポンスして処理できるため、効率的で透明性の高い勤怠管理フローを実現します。

## 2. 適用シーン

休暇申請・残業・打刻修正などの申請を素早く送信できます。

## 3. 操作フロー

**モバイル版 DingTalk ＞ ワークベンチ ＞ 勤怠打刻 ＞ 設定 ＞ その他の設定 ＞ 勤怠承認 ＞ クイック申請入口をオン** の順に開きます。

<Note>
オンにすると、社員の **勤怠打刻ホーム** に **申請** 入口が追加され、承認を手軽に発起できるようになります。表示範囲は承認管理画面の設定に準じます。
</Note>

<Note>
**1. オンの場合**：打刻アプリ内に **申請** 入口が **表示** され、社員は休暇申請・残業・出張などの申請を手軽に発起できます。

**2. 閉じるの場合**：打刻アプリ内の **申請** 入口は **非表示** となり、社員は打刻アプリから申請を発起できなくなります。
</Note>

## 4. よくある質問

<AccordionGroup>
  <Accordion id="q1" title="クイック申請入口を閉じると、社員に通知されますか？">

勤怠打刻画面のクイック **申請** 入口のオン／閉じるは、いずれも業務通知の形で社員へ通知されます。

  </Accordion>
  <Accordion id="q2" title="勤怠打刻のクイック申請入口に承認テンプレートが表示されないのはなぜですか？">

勤怠打刻ページの **申請** に表示される承認フォームテンプレートは、出勤スイートを利用している場合にのみ申請入口へ表示され、社員が承認フォームを送信できるようになります。

  </Accordion>
</AccordionGroup>
