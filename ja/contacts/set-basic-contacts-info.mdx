#### 1. 連絡先の組織構成を設定

連絡先の組織構成は、PC版の管理コンソール、モバイル版の企業管理ページ、または API から設定できます。

#### 2. 連絡先の社員属性フィールドを設定

設定できる項目は次のとおりです。

*   連絡先の表示スタイル
    
*   部門パスの表示スタイル
    

パス：[管理コンソール](https://oa.dingtalk.io) > **「連絡先」** > **「プロフィール管理」** に移動します。
