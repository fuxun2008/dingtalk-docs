まだPPTで報告や共有をしていませんか？

PPTを作るたびに、

揃え、配置、サイズ調整など、

一連の操作で目が疲れ果ててしまいます。

最も重要なのは、PPT作成に費やす時間の

半分は表現形式を考えることに使われ、

時にはコンテンツが不足し、形式で補うことすらあります。

本日、DingTalkドキュメントが簡単なテクニックをご紹介します。

ドキュメントを使えば、コンテンツの作成により集中できるだけでなく、

プレゼンテーションの際にもPPTのような効果を実現できます。

**使用する主要機能：DingTalkドキュメント-プレゼンテーション-プレゼンテーションページ編集**

**手取り足取りの操作手順は以下のとおりです：**

<Note>
1. DingTalkドキュメント内のコンテンツを準備した後、右上の「プレゼンテーション-プルダウン記号」をクリックし、「プレゼンテーションページ編集」を選択します。

2. プレゼンテーション時のロジックに基づき、分割と結合の複数回の操作を通じて、ドキュメント内のコンテンツを編集し、プレゼンテーション共有時の構成に調整できます。

動的効果は以下のとおりです：

3. 右上の「再生」をクリックすると、効果のプレビューができます。

4. プレゼンテーションでより聴衆の注目を集めるための、いくつかの小技をご紹介します：

報告時に正しい発表者が表示されない？プレゼンテーションモードで下部ツールバーの【プレゼンテーション設定】をクリックし、共有者名を変更できます。共有者を非表示にすることも可能です。

聴衆がコンテンツの要点を掴めないのが心配？プレゼンテーション中、下部ツールバーをクリックしてレーザーポインターのスタイルを切り替えることができ、重要なコンテンツを強調するのに役立ちます。

ドキュメントでプレゼンテーションモードをオンにすると、「ドキュメントのコメントを表示」でき、コメントを中心に深く議論・分析し、意見の相違を効率的に解消し、合意形成を図ることができます。

PPTにさよならして、ドキュメントだけで十分です。

マスターしましたか？さっそく使ってみましょう。
</Note>
