DingTalkスプレッドシートでは、他のプラットフォームを通じてお客様やほかの方に共有して閲覧してもらいたい場合、スプレッドシートの印刷およびエクスポート機能をご利用いただけます

## 操作手順

印刷：上部ナビゲーションバーの **メニュー → スプレッドシート → 印刷** をクリックすると印刷できます

エクスポート：上部ナビゲーションバーの **メニュー → スプレッドシート → ダウンロード形式** をクリックすると、すばやくローカルに保存できます。エクスポートパネルでは出力先スプレッドシートの見出しを再設定できますが、元のスプレッドシートには影響しません。（現在DingTalkスプレッドシートはXLSX、CSV、TSV、PDF形式でのローカルスプレッドシートへのエクスポートに対応しています）
