日常業務において、毎月の財務レポート、社員給与計算、社員出勤日数集計など、似たような種類のスプレッドシートを作成する必要が頻繁に発生します。DingTalk スプレッドシートでは、日常業務の効率向上と繰り返し作業の解消を目的として、**テンプレートとして保存**する機能をサポートしています。これにより、次回スプレッドシートを作成する際に「マイテンプレート」から直接選択して利用でき、業務をより効率化できます。

## 操作手順

## マイテンプレートとして保存する方法

1.  対象のスプレッドシートを作成し終えたら、上部ナビゲーションバーの **メニュー → スプレッドシート** をクリックし、プルダウンメニューから **テンプレートとして保存 → マイテンプレートとして保存** を選択します。

2.  ポップアップ画面でテンプレートの **見出し** をカスタマイズできます。後から素早く識別・選択できるようにし、テンプレートの判別性を高めます。

3.  ポップアップ画面の右下にある **作成** をクリックすると保存が完了します。

## 保存したテンプレートの確認場所

次回、保存したテンプレートを使用したい場合は、**左側のドキュメント → 右上のテンプレート → マイテンプレート → 右上のすべての種類をクリック → スプレッドシートで絞り込み** の順に進むことで、保存したテンプレートをすぐに見つけることができます。

## 保存したテンプレートの削除方法

まずマイテンプレートを開きます。**左側のドキュメント → 右上のテンプレート → マイテンプレート → 右上のすべての種類をクリック → スプレッドシートで絞り込み** の順に操作し、テンプレートの右上にある **削除ボタン** をクリックすると、すぐに削除できます。
