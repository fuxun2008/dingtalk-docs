DingTalkのスプレッドシートでは、「リンクを挿入」を使用して他のデータコンテンツをハイパーリンク形式で挿入し、コンテンツの検索に役立てることができます。現在、URLリンクアドレス、他のセル、他のワークシートの挿入をサポートしています。

## 操作手順

## リンクを挿入

### 通常のURLアドレス

1.  リンクを挿入したいセルを選択し、上部ナビゲーションバーの<strong>「挿入 - リンク」</strong>をクリックします。

2.  <strong>「見出し」</strong>に外部に表示する見出しテキストを入力します。

3.  <strong>「アドレス」</strong>にリンクアドレスを入力または貼り付けます。

4.  <strong>「確認」</strong>をクリックすればリンクの挿入が完了します。

### 同一スプレッドシート内の他のセルにリンク

1.  リンクを挿入したいセルを選択し、上部ナビゲーションバーの<strong>「挿入 - リンク」</strong>をクリックします。

2.  「アドレス」で「セルへのリンク」を選択します。

3.  「範囲セレクター」から手動入力またはセルを直接選択できます。

4.  「見出し」を変更後、「確認」をクリックすればリンクの挿入が完了します。

5.  リンクをクリックすると、対応するセルに直接リダイレクトされます。

### 他のワークシートへのリンク

1.  リンクを挿入したいセルを選択し、上部ナビゲーションバーの「挿入 - リンク」をクリックします。

2.  「アドレス」で「ワークシートへのリンク」を選択し、現在のスプレッドシート内の既存ワークシートを直接選択できます。

3.  「確認」をクリックすればリンクの挿入が完了します。

4.  リンクをクリックすると、対応するワークシートに直接リダイレクトされます。

### リンクの編集またはキャンセル

1.  セル内のリンクを選択し、「リンクパネル」を展開します。

2.  <strong>「リンクパネル」</strong>では以下の操作がサポートされています。

*   **編集**：クリックするとリンクを変更できます。

*   **コピー**：クリックするとリンクアドレスをワンクリックでコピーできます。

*   **キャンセル**：クリックすると現在のセルのリンク属性をキャンセルできます。セル内の入力内容は削除されません。
