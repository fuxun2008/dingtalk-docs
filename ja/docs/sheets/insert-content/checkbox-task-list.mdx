---
title: "チェックボックス：タスクリストの作成"
description: "セルにチェックボックスを挿入して、タスクの完了状況を管理できる機能です。"
---

**DingTalk スプレッドシート** では、 **「チェックボックスの挿入」** 機能でタスクリストを作成できます。

## 使い方

1.  タスク名と担当者を記載したタスクリストを設計し、タスクの完了状況を示す列を1列挿入します。

2.  空白のセルを選択し、ツールバーの **「チェックボックス」** をクリックすると、チェックボックスが挿入されます。

3.  **「チェックボックス」** をクリックするとチェックボックスを追加でき、完了状況に応じてチェックを入れられます。

チェックボックスを挿入したスプレッドシートをエクスポートすると、ローカルでは TRUE と FALSE で表示されます。
