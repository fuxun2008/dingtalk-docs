---

<AccordionGroup>
<Accordion title="DingTalk でスプレッドシートをオンライン編集できないのはなぜですか？">

  回答：暗号化された Excel ファイルはオンラインで編集できません。

</Accordion>
<Accordion title="絞り込みデータを自分だけに表示する設定方法は？">

  回答：ツールバーの絞り込みビュー機能を使用できます。具体的な手順は次のとおりです：ツールバーの「絞り込み」をクリック → 「絞り込みを作成」 → データを絞り込む際に、絞り込み結果を「自分のみ表示」に設定します。

</Accordion>
<Accordion title="スプレッドシートの全員閲覧可能の権限を変更するには？">

  回答：権限の適用範囲が「スプレッドシート全体」の場合、右上の「共有」からユーザーの権限を設定できます。

</Accordion>
<Accordion title="スプレッドシートで組織外のメンバーをメンションするには？">

  回答：現在、組織外の連絡先のメンションをサポートしています。セルに @ を入力すると、企業外のメンバーをすばやく選択できます。

</Accordion>
<Accordion title="スプレッドシートの履歴バージョンはどこで確認できますか？">

  回答：左上のナビゲーションバーで **メニュー → スプレッドシート →** **会議履歴** をクリックして確認します。

</Accordion>
<Accordion title="DingTalk のスプレッドシートをダウンロードするには？">

  回答：ファイルを開き、上部のナビゲーションバーから **メニュー → スプレッドシート → ダウンロード形式** の順にクリックすると、ローカルにすばやく保存できます。

</Accordion>
<Accordion title="オンラインスプレッドシート内でワークシートを作成できる上限はいくつですか？">

  回答：現在 1000 個のワークシートまでサポートしています。ただし、より快適にご利用いただくため、1 つのスプレッドシート内に過剰なワークシートを作成しないことをお勧めします。

</Accordion>
<Accordion title="スプレッドシートで個別のセルに注釈を追加するには？">

  回答：セルをクリックした後、マウスを右クリックしてコメントを追加できます。

</Accordion>
<Accordion title="スプレッドシートの検索機能で、すべてのブックのコンテンツを検索できますか？">

  回答：スプレッドシートの検索機能は、現在のワークシート内のコンテンツのみ検索可能です。

</Accordion>
<Accordion title="スプレッドシートを直接印刷できますか？">

  回答：可能です。上部のナビゲーションバーから **メニュー → スプレッドシート → 印刷** をクリックすると、すばやく印刷できます。
