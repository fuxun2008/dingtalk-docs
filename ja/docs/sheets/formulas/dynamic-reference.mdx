## INDIRECT 関数

INDIRECT 間接参照関数は、テキストを範囲参照として解析します。ほとんどの数式では、SUM(A1:A5) のように参照を直接記入します。この場合、「A1:A5」は引用符で囲まれておらず、参照範囲 A1:A5 を直接表します。

通常、INDIRECT 関数は連結記号「&」やテキスト関数と組み合わせて使用します。例えば、

図 1 「集計」シートの C1 セルにおける INDIRECT 引数を連結して得られるテキストは「リンゴ!B:B」であり、

INDIRECT 関数による解析を経て「リンゴ」シートの B 列データを参照し、SUM 関数で合計して「総売上高」を得ます。
