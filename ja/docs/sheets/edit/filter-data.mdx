DingTalkスプレッドシートでは、**「フィルター」**を使ってデータテーブルから条件に合致する一部のデータを抽出し、さらなる分析や処理に活用できます。一時的に不要なデータは非表示にできます。

## 操作手順

## ベーシック絞り込み：フィルターのオン／オフ

1.  絞り込みたいセル範囲を選択し、ツールバーの**「フィルター」**をクリックすると、フィルターがオンになります。

2.  この時、選択範囲の最初の行の各セル右上に**「フィルターボタン」**が表示されます。「フィルターボタン」をクリックすると絞り込み操作が行えます。前の手順で範囲を選択せずに直接「フィルター」をクリックした場合、ワークシート全体の絞り込みがデフォルトでオンになり、ワークシートの最初の行のすべてのセルに「フィルターボタン」が表示されます。

3.  ツールバーの「フィルター」を再度クリックすると、フィルターをオフにできます。

4.  1つのワークシート内では、1回につき1つのセル範囲のみフィルターをオンにできます。

## ベーシック絞り込み：フィルタータイプ

1.  **値で絞り込む**：特定のカテゴリーのデータを素早く絞り込みたい場合、検索ボックスにキーワードを入力すると、そのキーワードを含むすべての項目が絞り込み結果として表示されます。または、パネル内の繰り返さない項目にチェックを入れて絞り込むこともできます。

2.  **条件で絞り込む**：特定の条件のデータを絞り込みたい場合、対応するフィルターを設定します。

3.  **色で絞り込む**：特定の背景色やフォント色のセルを絞り込みたい場合、「色で絞り込む」を選択します。

4.  **自分のみに表示する絞り込み**：絞り込み結果を同期する／しないを設定したい場合、フィルターパネル内で「自分のみに表示する絞り込み」にチェックを入れます。

## 上級絞り込み：互いに影響しないフィルタービュー

独立して絞り込みを行いたい場合、他のユーザーのデータ閲覧に影響を与えたくない場合、またはスプレッドシートの権限が閲覧のみで、それでもデータを絞り込みたい場合は、「フィルタービュー」を使ってデータを絞り込んでください。

1.  絞り込みたいセル範囲を選択し、ツールバーの「**フィルター**のドロップダウン矢印->フィルタービューを作成」をクリックします。

    （MACの場合：「フィルター - その他」をクリックし、「フィルタービューを作成」をクリックすると、「フィルタービュー画面」に入ります）

2.  「フィルタービュー画面」での絞り込み結果は元のデータテーブルに同期されません。さらに以下の操作も実行できます：

    1.  フィルタービューの名前を変更し、区別しやすくする

    2.  絞り込み範囲を再選択して変更する

3.  フィルタービュー内の絞り込み機能は、ベーシック絞り込みと同じ操作ですが、現時点では「並び替え」には対応していません。
