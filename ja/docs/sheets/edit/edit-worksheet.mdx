DingTalk スプレッドシートでは、スプレッドシートファイル全体を<strong>「ブック」</strong>と呼び、各ブックには複数の<strong>「ワークシート」</strong>を含めることができます。「ワークシート」に対して追加・削除・変更などの編集操作を行うことができます。

## 操作方法

## 作成

下部バーの アイコンをクリックすると、新しいワークシートを作成できます。新規作成されたワークシートは、デフォルトで現在のワークシートの後ろに配置されます。

## ワークシートの編集

**名前を変更**：ワークシート名をダブルクリックするか、右クリックメニューで<strong>「名前を変更」</strong>をクリックすると、ワークシート名を変更できます。名前は既存の名前と重複することはできません。

**ワークシートのコピー**：コピーしたいワークシートを選択し、右クリックメニューで<strong>「コピー」</strong>をクリックします。

**ワークシートの移動**：移動したいワークシートを選択し、マウスでドラッグするか、右クリックメニューで<strong>「左へ移動 / 右へ移動」</strong>をクリックします。

図のとおり、右クリックメニューから編集機能を選択します。

## ワークシートの非表示

一時的に表示する必要のないワークシートを選択し、右クリックメニューで「非表示」をクリックします。再度表示したい場合は、左側のアイコンをクリックするとすべてのワークシートが展開されます。非表示になっているワークシートをクリックすると、非表示を解除できます。

## ワークシートの検索

ワークシートが10個を超えると、検索入口が表示され、キーワードでワークシートを検索できます。
