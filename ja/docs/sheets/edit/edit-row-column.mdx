スプレッドシートでは、行 / 列の挿入、削除、非表示、行の高さ / 列幅の設定が可能で、スプレッドシートのレイアウトをより適切に組み立てられます。

## 操作説明

## 行 / 列を挿入

1.  対象の行 / 列を選択します。

2.  右クリックメニューから「行 / 列を挿入」を見つけ、挿入したい方向と行数 / 列数を入力し、「挿入」をクリックします。

3.  最下部に行を挿入：現在のスプレッドシートの行数が不足している場合は、スプレッドシートの最下部までスクロールすると、行を一括で挿入できます。

## 行 / 列を削除

1.  対象の行 / 列を選択します。

2.  右クリックメニューから**「選択した行 / 列を削除」**を選択します。

## 行 / 列を非表示

一部のデータを一時的にスプレッドシートに表示したくないが、削除もしたくない場合は、「非表示」機能で行 / 列を一時的に非表示にできます。

1.  対象の行 / 列を選択し、**右クリックメニューから「行 / 列を非表示」を選択**します。

2.  非表示にした行 / 列の位置にはアイコンが表示され、再度クリックすると非表示を解除できます。

## 行の高さ・列幅を設定

1.  対象の行 / 列を選択します。

2.  右クリックメニューから「列幅 / 行の高さ」を見つけ、希望の数値を入力します。

## 行の高さ / 列幅を自動調整

選択したセル内にすでにデータの入力や画像の挿入がある場合、**「行の高さ / 列幅を自動調整」**を選択すると、入力内容の幅・高さに応じて行の高さ / 列幅が自動的に調整されます。
