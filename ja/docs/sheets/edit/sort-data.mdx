DingTalk スプレッドシートでは、「並び替え」を使用して、指定した順序でデータを再配置できます。これはデータ整理における重要な手段です。

## 操作手順

対象範囲を選択し、ツールバーの<strong>並び替え</strong>をクリックします。ドロップダウンメニューから並び替え方法を選択でき、「カスタム並び替え」にも対応しています。個人のニーズに応じて、スプレッドシートの並び替えを調整できます。

*   数値タイプのデータは、通常、数値全体の大きさに基づいて並び替えられます。

*   テキストタイプのデータは、通常、アルファベットや中国語ピンインの順序に基づいて並び替えられます。

*   お知らせ：正しい並び替え結果を得るために、並び替えの前に必ずデータ形式を統一してください。
