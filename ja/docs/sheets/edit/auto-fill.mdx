**DingTalk スプレッドシート** の「オートフィル」は、既存データの入力ルールに基づいて隣接するセルを素早くコピー・フィルできる機能です。セルデータの規則的な入力を完了させるのに便利で、コンテンツのコピーや連番などのデータ入力シーンに適しています。

## 使い方

1.  一部のデータが入力されているセル範囲を選択し、オートフィルの基準データとします。

2.  選択範囲の右下隅にあるセルの右下にマウスを合わせると、カーソルが<strong>「 + 」</strong>の形に変わります。これが<strong>フィルハンドル</strong>です。

3.  フィルハンドルを押したまま、垂直方向または水平方向にドラッグすると、対応する方向の空白セルにデータがフィルされます。

4.  フィルハンドルを離すと、フィル範囲の右下にフィルオプションが表示されます。クリックすると、<strong>セルのコピー、連続データ、書式のみコピー、書式なしコピー</strong>から選択できます。
