DingTalkのスプレッドシートでは、「検索と置換」機能を使ってデータをすばやく検索・置換できます。また、キーボード<strong>ショートカットキー Ctrl + F（Mac：Cmd + F）</strong> でデータを検索することも可能です。

## 使い方

1.  ツールバーの右端にある<strong>もっと->「検索と置換」</strong> をクリックしてパネルを展開し、**「検索」** 項目に検索したいデータを入力します。データ形式はテキスト、数値、記号に対応しています。

2.  検索データを含むセルがリアルタイムで抽出され、黄色のハイライトで表示されます。英語テキストの場合、大文字と小文字は区別されません。

3.  検索したデータを置換したい場合は、 **「置換後」** の入力欄に置換したいデータを入力し、 **「置換」** をクリックします。選択済みのセルデータの置換に対応しており、 **「すべて置換」** をクリックすると、検索されたすべてのデータを一括で置換できます。
