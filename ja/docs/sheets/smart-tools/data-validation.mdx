## 概要

データ検証機能は、あらかじめ入力ルールを設定して入力形式を統一し、入力ミスを防ぐ機能です。

## ユースケース

チームメンバーが共同でスプレッドシートのコンテンツを入力する際、全員が入力要件を十分に把握しているとは限らず、入力ミスが発生しがちで、手動チェックには時間と手間がかかります。「データ検証」機能を利用すれば、入力ルールを事前に設定して入力形式を統一し、入力ミスを防ぐことで、データ収集の正確性と効率を同時に向上させることができます。

## 使い方

入口：

1. 上部の **「メニュー」** > **「データ」** > **「データ検証」**

2. **「ツールバー」** > **「データ検証」**

3. **「右クリックメニュー」** > **「データ検証を設定」**

設定：

1. 入口をクリックし、 **「ルールを作成」**

2. ルール設定：必要なデータタイプと検証ルール（入力ヒントとエラー時のお知らせ）を設定できます。

（データ検証は互換性機能であり、ローカル操作ルールと一致していますが、一部の UI インタラクションが異なります）

3. **「完了」** をクリックして保存します。

検証：

1. 事前に設定したルールに従い、他のユーザーがセルをクリックすると入力ヒントが表示されます。

2. 設定したルールに合わないデータを入力すると、データが無効である旨のお知らせが表示されます。
