スプレッドシートの処理や装飾の過程で、テーブルの色、フォント、書式などを大量に変更する必要が生じることがよくあります。1つずつ変更するのは面倒で時間の浪費となりますが、書式のコピー機能を使えば、こうした操作を素早く簡単に完了できます。1つずつ処理する手間を省けます。

## 操作説明

## 書式のコピー

*   まず、書式をコピーしたい対象セルを選択します

*   次にツールバー左側の **書式のコピー** をクリックすると、対象セルの書式を素早くコピーできます。このとき、マウスカーソルがブラシ形状に変わり、書式のコピーが成功したことを示します

*   最後に書式を適用したいセルを選択してクリックすると、コピーした書式が適用され、対象セルと同じ書式に即座に変更されます。これで書式のコピーが正常に適用されたことになります

## 書式のクリア

*   まずクリアしたい対象セルを選択します

*   次にツールバー左側の **書式をクリア、またはショートカットキー Ctrl + / ( Mac：Cmd + / )** を使用することで、効率的に操作を完了できます。または、**右クリックメニュー → クリア → 書式をクリア** からも実行できます。
