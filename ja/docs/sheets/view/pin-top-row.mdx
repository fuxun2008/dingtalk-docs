DingTalkスプレッドシートのPC版では、スクロール中に指定した行を常にスプレッドシートの上部に固定でき、すべてのヘッダーを簡単にピン留めできます。

## 操作方法

*   行のピン留め：PC版で任意の行を選択 >> ツールバーをクリック >> 固定 >> 選択した行を上部に固定

*   行のピン留め解除：PC版でピン留め済みの行を選択 >> ツールバーをクリック >> 固定 >> 固定を解除
