---
title: "ページレイアウトの調整"
description: "DingTalk ドキュメントでページレイアウトを調整する方法を紹介します。"
---

**DingTalk ドキュメント** では、ドキュメントごとにページレイアウトの要件が異なります。ページレイアウトはドキュメント編集における重要なオプションの一つです。

## 余白の設定

トップナビゲーションバーをクリックし、 **「メニュー」** > **「レイアウト」** > **「余白」** を選択すると、ドキュメントの余白を設定できます。

## 用紙の向きの設定

トップナビゲーションバーをクリックし、 **「メニュー」** > **「レイアウト」** > **「用紙の向き」** を選択すると、ドキュメントを縦向きまたは横向きに設定できます。

## ページサイズの設定

トップナビゲーションバーをクリックし、 **「メニュー」** > **「レイアウト」** > **「ページ幅」** を選択すると、ドキュメントを 通常 / 超ワイド / 全幅 に設定できます。
