日常業務において、ドキュメントごとにページレイアウトの要件は異なります。ページレイアウトはドキュメント編集における重要なオプションの一つです。

## 操作手順

## 余白の設定

トップナビゲーションバーをクリックし、**メニュー - レイアウト - 余白** を選択すると、ドキュメントの余白を設定できます。

## 用紙の向きの設定

トップナビゲーションバーをクリックし、**メニュー - レイアウト - 用紙の向き** を選択すると、ドキュメントを縦向きまたは横向きに設定できます。

## ページサイズの設定

トップナビゲーションバーをクリックし、**メニュー - レイアウト - ページサイズ** を選択すると、ドキュメントを 通常 / 超ワイド / 全幅 に設定できます。
