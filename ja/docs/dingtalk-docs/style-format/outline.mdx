「ドキュメントアウトライン」機能を使用してドキュメントの構造を構築できます。DingTalkドキュメントは、ドキュメント内に設定された見出しを自動的に検出し、ドキュメント右側のアウトラインパネルに追加します。読み手はドキュメントのコンテンツ構造を素早く把握でき、編集者もドキュメントのコンテンツを調整する際に内容の漏れや重複がないかを素早く確認できます。

## 操作手順

## テキストアウトラインの追加

ドキュメントアウトラインにしたいテキストを選択し、上部ツールバーの見出しスタイルをクリックすると、システムが自動的に見出しをアウトラインに設定します。

## ドキュメントアウトラインの表示

### PC版

マウスをドキュメント右側のアウトラインのフローティングアイコンに合わせ、クリックするとアウトラインを固定できます。下図のとおりです。

### モバイル版

アウトラインの表示に対応しています。モバイル端末でDingTalkドキュメントを開き、右上の **··· - アウトライン** をクリックします。
