---
title: "リストの追加または編集"
description: "DingTalk ドキュメントでリストを追加・編集する方法を紹介します。"
---

**DingTalk ドキュメント** で、同一の件名に複数のコンテンツが対応する場合、これらのコンテンツに箇条書きや番号付きリストを追加することで、ドキュメントの内容が整然と並び、階層がより明確になります。

## リストの追加

ツールバーで対応するアイコンをクリックすると、箇条書き（順序なしリスト）、番号付きリスト（順序付きリスト）、タスクリストを順に追加できます。

## リストの編集

DingTalk ドキュメントでは、箇条書きの記号の種類や番号の種類の変更をサポートしています。ツールバーの対応する操作のプルダウンメニューの矢印、または対応する操作のアイコンをクリックして設定できます。
