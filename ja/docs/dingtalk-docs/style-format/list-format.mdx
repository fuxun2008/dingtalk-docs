日常的なドキュメント編集において、同一の件名に複数のコンテンツが対応する場合、これらのコンテンツに箇条書きや番号付きリストを追加することで、ドキュメントの内容が整然と並び、階層がより明確になります。

## 操作説明

## リストの追加

ツールバーで対応するアイコンをクリックすると、箇条書き（無秩序リスト）、番号付きリスト（順序付きリスト）、タスクリストを順に追加できます。

## リストの編集

DingTalkドキュメントでは、箇条書きのシンボル種類や番号種類の変更がサポートされています。ツールバーの対応する操作のプルダウンメニュー矢印、または対応する操作のアイコンをクリックして設定できます。
