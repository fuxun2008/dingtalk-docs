統一感のある、または規則性のある段落書式は、ドキュメントの整然さを引き立て、視覚的にも美しく見せます。

## 操作手順

## 段落の揃え方を変更する

変更したい段落を選択し、上部ツールバーで揃えオプションを選ぶか、上部ナビゲーションバーの **メニュー - 書式 - 水平揃え** をクリックし、希望の揃え方を選択します。

## 行間を変更する

変更したい行を選択し、ツールバーの **行の高さオプション** をクリックして行間の値を選択します。または、上部ナビゲーションバーの **メニュー - 書式 - 行間** をクリックし、希望の間隔値を選択します。

## テキストのインデントを調整する

インデントを設定したいテキスト行を選択し、カーソルをその行の任意の位置に置き、ツールバーの **インデントアイコン** をクリックすると、インデントを増減できます。ショートカットキー **Ctrl+【** または **Ctrl+】** を使用することもできます。また、上部ナビゲーションバーの **メニュー - 書式 - インデント** をクリックし、インデントの増減を選択することもできます。
