## 概要

**DingTalk ドキュメント** では、中国語と英語がスマートに識別され、間隔が自動的に調整されます。煩雑な手動操作が省かれ、ドキュメントコンテンツの編集がより規範的になります。

## ユースケース

DingSanduo氏は企画部のコンテンツ運営担当者で、日常的にDingTalk ドキュメントを使って企業の各種宣伝原稿、お知らせ通知、行政ドキュメントなどを編集しています。この機能を利用すると、原稿作成時に中国語の前後にある英語や数値に自動的にスペースが追加されるため、一つずつ書式を校正する必要がなくなり、文章の書式がより標準的になり、書式校正の作業負担を軽減できます。

## 使い方

トップナビゲーションバーをクリックし、右上の **...**\-**環境設定**\-**補助編集**\-**DingTalkドキュメント**\-<strong>中英文自動間隔</strong>をオンにします。オンにすると、編集時に中国語と英語、数値の間にスペースが自動的に追加されます。
