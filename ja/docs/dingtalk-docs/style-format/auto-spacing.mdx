## 機能の価値

中国語と英語をスマートに識別し、間隔を自動調整します。煩雑な手動操作を省き、ドキュメントコンテンツの編集をより規範的にします。

## 利用シーン

DingSanduoさんは企画部のコンテンツ運営担当者で、日常的にDingTalkドキュメントを使って企業の各種宣伝原稿、お知らせ通知、行政ドキュメントなどを編集しています。この機能を利用すると、原稿作成時に中国語の前後にある英語や数値に自動的にスペースが追加されるため、一つずつ書式を校正する必要がなくなり、文章の書式がより規範的かつ標準的になり、書式校正の作業負担を軽減できます。

## 操作方法

トップナビゲーションバーをクリックし、右上の **...**\-**環境設定**\-**補助編集**\-**DingTalkドキュメント**\-**中英文自動間隔**をオンにします。オンにすると、編集時に中国語と英語、数値の間にスペースが自動的に追加されます。
