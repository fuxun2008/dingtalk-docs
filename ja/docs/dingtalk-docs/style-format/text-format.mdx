テキスト書式を設定することで、ドキュメントの多様性を高められます。コンテンツに応じて異なるテキスト書式を設定することで、テキストの階層が明確になり、読者が要点を把握しやすくなり、コンテンツの理解を助けます。

## 操作説明

「DingTalkドキュメント」で設定可能なテキスト書式は以下のとおりです。

テキスト書式には、フォント、フォントサイズ、太字、斜体、下線、取り消し線、上付き文字、下付き文字、文字の色、テキストのハイライト色などがあります。

## フォントとフォントサイズの調整

*   対象のテキストを選択し、ツールバーの<strong>フォントボックス</strong>をクリックして、お好みのフォントを選択します。

*   対象のテキストを選択し、<strong>フォントサイズボックス</strong>をクリックして選択することでフォントサイズを調整できます。また、<strong>A</strong>^<strong>+</strong>^、<strong>A</strong>^<strong>-</strong>^を使用してすばやく調整することも可能で、この機能では通常一度のクリックでフォントサイズが2段階変更されます。

    ## テキストスタイルの調整

    フォントの太字、斜体、下線、取り消し線、上付き文字、下付き文字などは、メニューバーから選択するか、調整したいコンテンツを選択した後に直接設定できます。

    ## 文字の色の調整

*   <strong>文字の色</strong>をクリックし、ポップアップ表示されるカラーパネルからお好みの文字色を選択します。

*   <strong>テキストのハイライト色</strong>をクリックし、ポップアップ表示されるカラーパネルからお好みのハイライト色を選択します。
