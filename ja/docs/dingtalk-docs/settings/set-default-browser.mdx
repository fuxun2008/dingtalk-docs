**概要**

DingTalkドキュメントWeb版をより快適にご利用いただくため、システム上でDingTalkドキュメントが対応するブラウザをデフォルトブラウザに設定できます。以下に設定方法をご案内しますので、実際の操作ページを基準にご参照ください。

## 一、Windowsシステム

1.  「**スタート**」ボタンを選択し、「**設定**」をクリックします。

2.  「**アプリ**」を選択します。

3.  **アプリ** **\>** **既定のアプリ** **\>** **Webブラウザ**から、デフォルトに設定したいブラウザを選択し、「このプログラムを既定値に設定する」をクリックします。確認のお知らせが表示されたら「切り替える」を選択し、設定を完了します。

## 二、MacOSシステム

*   ステップ1：**システム設定**を開き、**デスクトップとDock**をクリックして開きます。

*   ステップ2：「デフォルトのWebブラウザ」を見つけ、デフォルトで使用したいブラウザを選択します。下図のとおりです：

## 三、デフォルトでブラウザを使用してDingTalkドキュメントを開く設定方法

DingTalkをご利用の際、個人の使用習慣に応じて、Webブラウザでドキュメントを開く・閲覧・編集するよう設定できます。

*   **Windowsシステム：DingTalk**を開き、**\>** 左上の**プロフィール写真 > 設定とプライバシー > 一般 > DingTalkドキュメント**から「常にブラウザでドキュメントを開く」をオンにすると、設定が完了します。

*   **Macシステム：DingTalk**を開き、**\>** 左上の**プロフィール写真 > 設定とプライバシー > 一般 > DingTalkドキュメント**から「常にブラウザでドキュメントを開く」にチェックを入れると、設定が完了します。
