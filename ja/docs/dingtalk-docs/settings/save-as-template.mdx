業務では、毎年または毎月の業務計画、業務報告、週次レポートなど、同じタイプのドキュメントを編集する場面によく遭遇します。このような場合、ご自身の作成習慣に合わせてドキュメントをテンプレートとして保存することで、繰り返しの編集の煩わしさを省き、業務効率を向上させることができます。さらに、DingTalkドキュメントでは、日常業務に便利な一般テンプレートも多数ご用意しています。

## 操作手順

ドキュメント右上のナビゲーションバーで ┇ <strong>\> テンプレートとして保存 > マイテンプレートに保存</strong> をクリックすると、対象のドキュメントをテンプレートとして保存できます。表示されるパネルでドキュメントの見出しを変更できますが、変更内容は元のドキュメントには反映されません。

作成したテンプレートは、新規作成時に **マイテンプレート** から選択して利用できます。
