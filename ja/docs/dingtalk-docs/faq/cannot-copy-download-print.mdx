## 問題の原因

デフォルトでは、「閲覧／ダウンロード可能」以上の権限を持つドキュメントの共同編集者は、ドキュメント本文のコンテンツのコピー、ドキュメントのダウンロード、ドキュメントの印刷、副本の作成が可能です。権限があるにもかかわらず、ドキュメントのコピー・ダウンロード・印刷ができない<strong>主な原因は次のとおりです：</strong>

ドキュメントまたはナレッジベースの管理者が「権限設定」機能において、<strong>「『管理可能』権限を持つユーザーのみダウンロード・副本作成・印刷が可能／全員ダウンロード・副本作成・印刷を禁止」</strong>を設定している場合、上記のルールは無効となります。

この場合、ユーザーがドキュメントの「閲覧／ダウンロード可能」権限を持っていても、ドキュメント本文のコンテンツのコピー、ドキュメントのダウンロード、ドキュメントの印刷、副本の作成などの操作はできません。このシナリオでは、関連する操作を行う際にお知らせが表示されます。

## 解決方法

ドキュメントまたはナレッジベースの管理者にご連絡いただき、ドキュメント／ナレッジベースの権限設定を変更してください。ドキュメント権限設定に関する詳細は、共有・コピー・ダウンロード・コメントなどの権限設定 をご参照ください。
