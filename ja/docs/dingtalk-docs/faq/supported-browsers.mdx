**DingTalk ドキュメント** の Web 版は、IEカーネルのブラウザには対応していません。DingTalk ドキュメントをより快適にご利用いただくため、対応ブラウザの中からお選びください。システムでDingTalk ドキュメント対応ブラウザをデフォルトブラウザに設定すると、スムーズで完全なDingTalk ドキュメント Web 版の体験が可能になります。

詳細はこちら：[システムのデフォルトブラウザを変更するには？](/ja/docs/dingtalk-docs/settings/set-default-browser)

## デフォルトブラウザの変更方法

### Windows システム

1. **「スタート」** ボタンを選択し、**「設定」** をクリックして、「既定のアプリ」と入力します。

2. 検索結果から **「既定のアプリ」** を選択します。

3. **「アプリ」** > **「既定のアプリ」** > **「Web ブラウザ」** を選び、デフォルトプログラムに設定したいブラウザを選択して、**「このプログラムを既定に設定する」** をクリックします。お知らせダイアログが表示された場合は **「強制的に変更」** を選択し、設定を完了します。
