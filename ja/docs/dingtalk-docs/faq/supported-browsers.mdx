DingTalkドキュメントのWeb版は、IEカーネルのブラウザには対応していません。DingTalkドキュメントをより快適にご利用いただくため、対応ブラウザの中からお選びください。システムでDingTalkドキュメント対応ブラウザをデフォルトブラウザに設定すると、スムーズで完全なDingTalkドキュメントWeb版の体験が可能になります。

詳細はこちら：[システムのデフォルトブラウザを変更するには？](/zh/docs/dingtalk-docs/settings/set-default-browser)

## 一、Windows システム

| **システムバージョン** | **対応ブラウザ** |
| --- | --- |
| **Windows 7、8、8.1、10** | *   [Chromeブラウザ](https://www.google.cn/chrome/)：63.0 以上のバージョン <br />    <br />*   [Microsoft Edge](https://www.microsoft.com/zh-cn/edge)（新バージョン） <br />    <br />*   [QQ ブラウザ](https://browser.qq.com/)（高速モード）：10.0 以上のバージョン <br />    <br />*   [360 高速ブラウザ](https://browser.360.cn/ee/)（高速モード） |
| **Windows XP** | *   [360 高速ブラウザ](https://browser.360.cn/ee/)（高速モード） |

## 四、デフォルトブラウザの変更方法

### Windows システム

1.  「スタート」ボタンを選択し、「設定」をクリックして、「既定のアプリ」と入力します。

2.  検索結果から「既定のアプリ」を選択します。

3.  アプリ \> 既定のアプリ \> Web ブラウザを選び、デフォルトプログラムに設定したいブラウザを選択して、「このプログラムを既定に設定する」をクリックします。お知らせダイアログが表示された場合は「強制的に変更」を選択し、設定を完了します。
