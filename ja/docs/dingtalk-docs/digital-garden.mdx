現在、企業の情報やナレッジは、グループチャット、個別チャット、会議、プロジェクトなどさまざまな形で業務シーンに分散して存在しています。便利な方法で「ワンストップ保存＋効率的な管理」を実現することは、企業が直面する大きな課題となっています。

2022年DingTalk 発表会において、DingTalk 副社長兼DingTalk コラボレーション製品責任者である傅徐軍氏が自身の回答を示しました。 **DingTalk ドキュメント** は情報の媒体を核とし、断片化された情報を構造化されたナレッジへと変換することで、ナレッジの創出と管理プラットフォームを構築し、企業のデジタルガーデンを築き上げます。

これに基づき、 **DingTalk ドキュメント** はナレッジの蓄積、整理、発見および接続といった一連の機能を提供し、企業のナレッジ管理を支援することで、企業ナレッジをより包括的に集約し、整然と整理し、便利に活用できるようにします。

1篇のドキュメントから始めて、企業のデジタルガーデンを築き上げ、ナレッジの魅力を花開かせましょう。1篇のドキュメントは多くの場合、多数の断片化された情報で構成されています。DingTalk ドキュメントのブロック化技術により、ブロック参照の同期機能を実現できます。一度の修正で複数のドキュメントを更新でき、参照されたすべてのナレッジ断片はその源泉を追跡することが可能となり、ナレッジの源のコンテキストを把握し、ナレッジの点・線・面の接続を形成できます。さらに、ドキュメントをリンク形式で別のドキュメントに挿入することで、2篇のドキュメント間に双方向関連の参照関係が構築されます。双方向リンクを通じて、自由かつトポロジー的なネットワーク状の接続方式でドキュメント間の関係が表示されます。さらにナレッジベースを通じて、フォルダー形式で分散したファイルが整然と組織化され、ナレッジの目次ツリーが形成されます。目次ツリーは無制限の階層のネストに対応し、複数人でのリアルタイム協働による組織化・管理が可能です。

今後、DingTalk ドキュメントはコンテンツコラボレーションの中国市場における展開と普及をさらに加速させ、すべての企業が自社専用のデジタルガーデンを構築できるようにしてまいります。
