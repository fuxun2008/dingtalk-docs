現在ドキュメントでサポートされているショートカットキーは以下の通りです。また、ドキュメント右下のキーボードアイコンをクリックすることで、一部のショートカットキーを表示できます。

| カテゴリ | 機能 | Mac | Windows |
| --- | --- | --- | --- |
| テキスト書式 | 太字 | ⌘ + B | Ctrl + B |
|  | 斜体 | ⌘ + I | Ctrl + I |
|  | 取り消し線 | ⌘ + Shift + X | Ctrl + Shift + X |
|  | 下線 | ⌘ + U | Ctrl + U |
|  | 上付き文字 | ⌘ + . | Ctrl + . |
|  | 下付き文字 | ⌘ + , | Ctrl + , |
|  | フォントサイズを大きく | `⌘ + Shift + >` | `Ctrl + Shift + >` |
|  | フォントサイズを小さく | `⌘ + Shift + <` | `Ctrl + Shift + <` |
|  | テキスト書式をコピー | ⌘ + Shift + C | Ctrl + Shift + C |
|  | テキスト書式を貼り付け | ⌘ + Shift + V | Ctrl + Shift + V |
|  | 書式をクリア | ⌘ + \ | Ctrl + \ |
| 挿入 | メンバーをメンション | @ | @ |
|  | ハイパーリンク | ⌘ + K | Ctrl + K |
| 段落書式 | 見出し | ⌘ + Option + \[1-4\] | Ctrl + Alt + \[1-4\] |
|  | 本文 | ⌘ + Option + 0 | Ctrl + Alt + 0 |
|  | 番号付きリスト | ⌘ + Shift + 7 | Ctrl + Shift + 7 |
|  | 箇条書き | ⌘ + Shift + 8 | Ctrl + Shift + 8 |
|  | タスクリスト | ⌘ + Shift + Y | Ctrl + Shift + Y |
|  | インデントを増やす | Tab | Tab |
|  | インデントを減らす | Shift+tab | Shift+tab |
|  | 左揃え | ⌘ + Shift + L | Ctrl + Shift + L |
|  | 中央揃え | ⌘ + Shift + E | Ctrl + Shift + E |
|  | 右揃え | ⌘ + Shift + R | Ctrl + Shift + R |
|  | 両端揃え | ⌘ + Shift + J | Ctrl + Shift + J |
| 編集 | 元に戻す | ⌘ + Z | Ctrl + Z |
|  | やり直し | ⌘ + Y | Ctrl + Y |
|  | 検索 | ⌘ + F | Ctrl + F |
|  | 検索と置換 | ⌘ + H | Ctrl + H |
| その他 | プレゼンテーションモード/全画面表示 | ⌘ + Shift + P | Ctrl + Shift + P |
|  | プレゼンテーションモードで拡大 | ⌘ + + | Ctrl + + |
|  | プレゼンテーションモードで縮小 | ⌘ + - | Ctrl + - |
|  | 印刷 | ⌘ + P | Ctrl + P |
