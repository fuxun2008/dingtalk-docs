---
title: "検索と置換"
description: "DingTalk ドキュメントで検索と置換機能を使用する方法を紹介します。"
---

**DingTalk ドキュメント** でドキュメントの編集や閲覧の際、検索と置換機能を使用することで、目的のコンテンツへ素早く移動できるだけでなく、ドキュメント内の該当コンテンツを一括で修正することも可能です。

## 使い方

ツールバー右側の **「検索と置換」** をクリックするか、ショートカットキー **Ctrl+F** （Mac： **Cmd+F** ）を使用すると、ドキュメント内で特定のフィールドを検索し、置換することができます。検索結果は黄色の背景色でハイライト表示されます。画面下部右下にある矢印で、検索したすべてのコンテンツを切り替えて確認できます。
