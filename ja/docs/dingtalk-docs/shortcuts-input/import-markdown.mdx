## 使い方

ドキュメントを作成する際、**「オンラインドキュメントとしてインポート」** を選択し、ローカルの.mdファイルを選択することで、 **DingTalk ドキュメント** にインポートできます。

## サポートされる形式

### ファイル形式

以下の3種類のファイルをサポートしています。

.markdown

.mark

.md

### エンコーディング

現在、utf-8文字セットでエンコードされたファイルのみサポートしています。
