## ご利用ガイド

ドキュメントを作成する際、「オンラインドキュメントとしてインポート」を選択し、ローカルの.mdファイルを選択することで、DingTalkドキュメントにインポートできます。

## サポートされる形式

### ファイル形式

以下の3種類のファイルをサポートしています。

.markdown

.mark

.md

### エンコーディング

現在、utf-8文字セットでエンコードされたファイルのみサポートしています。
