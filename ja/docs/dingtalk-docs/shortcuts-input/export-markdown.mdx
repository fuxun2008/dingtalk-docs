## 使い方

ドキュメントの編集が完了したら、mdファイルとしてダウンロードし、エクスポートできます。

DingTalkドキュメントは一般的なMarkdown構文に準拠しており、特定の書式をMarkdownテキストに変換します。また、DingTalkドキュメント独自の一部のテキスト要素についてはダウングレード処理を行います。具体的な変換結果は以下のとおりです。
