## 機能の価値

デュアルスクリーンモードでは、2つのドキュメントを同時に編集でき、ページを行き来する必要がなく、ドキュメントの編集や校正を効率的に行えます。

## 利用シーン

DingSanduoさんはニューメディア企業のコピーライターで、日常的にDingTalkドキュメントを使って各種コピー原稿の校正・審査や記事の執筆などを行っています。DingTalkドキュメントのデュアルスクリーンモードを使用すれば、コピー原稿の校正・審査時にドキュメントページを行き来する必要がありません。記事を執筆する際に資料を参照したい場合も、デュアルスクリーンモードで同時に進められるため、業務をより手軽かつ効率的に進められます。

## 利用方法

ドキュメントAを開き、ドキュメントA内に挿入されたドキュメントBをクリックすると、デュアルスクリーンモードに入ります（デュアルスクリーンモードでは2つのドキュメントを同時に編集できます）。
