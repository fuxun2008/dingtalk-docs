**DingTalk ドキュメント** はDingTalk と深く連携し、共同作業がより効率的になります。ドキュメント内で@を使って他のメンバーをメンションできます。本文またはコメントに直接 **「@＋ユーザー名」** を入力すると、相手にDingTalk チャット通知を送信し、ドキュメントやコメント内容への注目を促せます。受信者はチャット通知をクリックすることで、ドキュメントの該当箇所に直接ジャンプできます。以前は会議を開いて議論する必要があった企画書や重要ドキュメントも、DingTalk ドキュメントなら複数人がいつでもどこでも議論・修正でき、日常業務の効率が大幅に向上します。

## 使い方

1. 他のメンバーを@したいドキュメント内の位置を選択し、そこに直接 **「@」** を入力すると、連絡先パネルが自動的に表示されます。連絡先パネルから@したいユーザーを選択することで、通知する相手を指定できます。

2. ポップアップで **「送信」** を選択すると、DingTalk チャット通知で相手に閲覧やコメントを促すことができます。@された受信者はDingTalk チャット通知を直接クリックすることで、ドキュメントの指定位置にジャンプできます。
