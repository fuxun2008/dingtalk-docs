---

**DingTalk ドキュメント** にDingTalk プロジェクトを関連付けて、プロジェクトの振り返りやトラッキングが可能です。

## 使い方

ドキュメント内でプロジェクト看板を追加したい位置を選択し、上部ナビゲーションバーの<strong>挿入 → プロジェクト看板</strong>をクリックします。表示されるプロジェクト看板セレクタで挿入したいプロジェクトを選択すると、ドキュメント内で<strong>タスク、ステータス、担当者</strong>などのプロジェクト詳細を直接確認できます。さらに、プロジェクト看板上で並び替えや絞り込みの設定も可能です。
