DingTalkドキュメントにDingTalkプロジェクトを関連付けて、プロジェクトの振り返りとトラッキングを行います。

## 操作手順

ドキュメント内でプロジェクト看板を追加したい位置情報を選択し、上部ナビゲーションバーの**挿入 → プロジェクト看板**をクリックします。表示されるプロジェクト看板セレクタで挿入したいプロジェクトを選択すると、ドキュメント内で**タスク、ステータス、担当者**などのプロジェクト詳細を直接確認できます。さらに、プロジェクト看板上で並び替えや絞り込みの設定も可能です。
