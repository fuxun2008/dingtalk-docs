---
title: "タスクリストからタスクを生成"
description: "DingTalk ドキュメントのタスクリストをDingTalk タスクに変換する方法を紹介します。"
---

議事録やタスクリストの作成、またはチームの業務計画を立てる際には、フォローアップが必要なタスクが大量に発生することがよくあります。「すべてに応答し、すべてに結果を出す」にはどうすればよいでしょうか。 **DingTalk ドキュメント** では、タスクリストを直接DingTalk タスクとして生成し、担当者にメンションして確認を促すことができます。

## 操作説明

タスクリストを追加したいドキュメントの位置を選択し、ツールバーの<strong>タスクリスト</strong>をクリックするとタスクが生成されます。さらに、タスクリストの右端にあるアイコンをクリックして<strong>「DingTalk タスクに変換」</strong>を選択すると、タスクを生成できます。

## 補足説明

タスクには担当者をメンションしたり、期限を設定したり、DingTalk タスクに変換してリマインダーを生成したりできます。
