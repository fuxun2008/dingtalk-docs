議事録やToDoリストの作成、またはチームの業務計画を立てる際には、フォローアップが必要なタスクが大量に発生することがよくあります。「すべてに応答し、すべてに結果を出す」にはどうすればよいでしょうか。DingTalkドキュメントでは、タスクリストを直接DingTalkタスクとして生成し、担当者にメンションして確認を促すことができます。

## 操作説明

タスクリストを追加したいドキュメントの位置を選択し、ツールバーの**タスクリスト**をクリックするとタスクが生成されます。さらに、タスクリストの右端にあるアイコンをクリックすると、**「DingTalkタスクに変換」**でタスクを生成できます。

## 補足説明

タスクには担当者をメンションしたり、期限を設定したり、DingTalkタスクに変換してリマインダーを生成したりできます。
