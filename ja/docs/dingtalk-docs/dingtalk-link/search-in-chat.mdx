---
title: "グループ内チャット履歴からDingTalk ドキュメントを検索"
description: "DingTalk ドキュメントをグループ内のチャット履歴から検索する方法を紹介します。"
---

グループ内のチャット履歴検索で、 **「ファイル」** **「ドキュメント」** タブから直接 **DingTalk ドキュメント** を検索でき、より便利に検索できます。

## 使い方

PC版のグループチャットで、右上の<strong>「チャット履歴」</strong>をクリックし、対象ドキュメントのキーワードを検索すると、<strong>「ファイル」タブ</strong>から対象ドキュメントを直接検索できます。
