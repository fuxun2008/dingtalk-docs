グループ内のチャット履歴検索で、「ファイル」「ドキュメント」タブから直接DingTalkドキュメントを検索でき、より便利にお探しいただけます。

## 操作手順

PC版のチャットグループ内で、右上の<strong>「チャット履歴」</strong>をクリックし、対象ドキュメントのキーワードを検索すると、<strong>「ファイル」タブ</strong>から対象ドキュメントを直接検索できます。
