ドキュメントの編集において、リンクの挿入は頻繁に使用されます。読者が指定の位置に<strong>素早くリダイレクト</strong>できるため、閲覧時間の節約に役立ちます。また、リンクの挿入はドキュメントが扱う知識の範囲を拡張するのにも役立ち、一般的に著名人の紹介や専門用語の説明などに使用されます。

## 操作説明

## リンクを挿入

リンクを挿入したい位置または対象テキストを選択し、ドキュメントツールバー上部の<strong>リンク</strong>を選択します。リンク挿入位置または対象テキストのフォントカラーが青色で表示されれば、挿入成功です。

> Webリンクの追加は、左側の「Webリンクを追加」をクリックして、リンク挿入機能をお試しください。

## リンク関連設定

リンク挿入のポップアップ画面では、リンクの<strong>見出し</strong>コンテンツを設定でき、<strong>リンクスタイル</strong>として<strong>リンクまたはカード</strong>を選択できます。

## リンク挿入のキャンセル

挿入されたリンクの位置またはテキストをクリックし、上部の<strong>リンクをキャンセル</strong>をクリックします。
