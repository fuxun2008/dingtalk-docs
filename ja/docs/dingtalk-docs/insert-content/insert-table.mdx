業務において、データをより直感的に表示するために、ドキュメントにテーブルを挿入したい場合があります。

## 操作説明

## テーブルを追加

ツールバーの **挿入 —> テーブル** をクリック、またはツールバーの **テーブル挿入アイコン** を直接クリックし、挿入する行と列を選択すると、ドキュメントにテーブルが挿入されます。

## テーブルを削除

削除したいテーブルを選択し、テーブル左上のアイコンを左クリックして「削除」をクリックします。また、**右クリックメニュー** から **行・列を削除 - テーブルを削除** をクリックして操作することもできます。

## 行・列の追加／削除

### 行・列を追加

マウスをテーブルのヘッダー行・列の間にホバーすると、行・列を挿入するアイコンが表示されます。クリックすると行や列を素早く追加できます。また、**右クリックメニュー** から **上に行を挿入／下に行を挿入、左に列を挿入／右に列を挿入** を選択して操作することもできます。

### 行・列を削除

削除したい行または列を選択し、行／列の **ヘッダー網掛け部分** をクリックすると、行／列を削除するアイコンが表示されます。クリックすると素早く削除できます。また、削除したい行／列を選択した状態で、**右クリックメニュー —> 選択した行／列を削除** から操作することもできます。

## セルの結合・セル結合を解除

### セルの結合

結合したいセルを選択し、ツールバーの **セルの結合アイコン** をクリックすると、セルを結合できます。

### セル結合を解除

結合済みのセルを選択し、ツールバーの「セルの結合を解除」オプションをクリックすると、結合済みのセルを解除できます。

## テーブルの調整

### セルの背景色を塗りつぶす

セルまたは行・列全体を選択し、ツールバーの **セル背景色** をクリックすると、セルの色を変更できます。

### セルの罫線を設定

セルまたは行・列全体を選択し、ツールバーの **テーブル罫線** をクリックすると、セルの色や線種を設定できます。

### 行の高さ／列幅を調整

調整したい行／列の境界線を選択し、マウスでクリックして直接ドラッグすると調整できます。

### テーブルの揃え方を設定

*   **一括設定：** テーブル左上の **アイコン** をクリックしてテーブル全体を素早く選択し、ツールバーの **揃え方** をクリックすると、一括で設定できます。

*   **行／列ごとに個別設定：** 調整したい行／列／セルを選択し、ツールバーの **揃え方** をクリックします。

### テーブル内でコンテンツを改行

対象のセルを選択し、**Enterキー** を押すと素早く改行できます。
