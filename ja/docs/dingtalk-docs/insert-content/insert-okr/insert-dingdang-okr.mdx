## ご利用案内

DingTalkドキュメントには、サードパーティのOKRアプリを挿入し、チームや個人のOKRコンテンツを直接表示し、同期更新することができます。「叮当OKR」と「北极星OKR」のアプリを有効にした後、「/」と「+」を使って、対応するOKRアプリを簡単に選択して挿入できます。

## 二、DingTalkドキュメントへの挿入

### 方法一：リンクを直接貼り付け

ドキュメント内で Ctrl + v または右クリックでOKRのリンクを貼り付けると、自動的に認識され、テキストリンク、アイコン付きテキストリンク、サマリーカード、プレビューカードのいずれかを選択して表示できます。

### 方法二：挿入メニューから挿入

ドキュメント内の挿入メニューをクリックし、リストから「叮当OKR」を選択し、リンク入力欄にOKRリンクを入力して「完了」をクリックすると、OKRプレビューカードが生成されます。
