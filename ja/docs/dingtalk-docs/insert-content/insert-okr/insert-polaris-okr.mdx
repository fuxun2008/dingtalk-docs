## ご利用案内

DingTalkドキュメントには、サードパーティのOKRアプリを挿入し、チームや個人のOKRコンテンツを直接表示・同期更新できます。「叮当OKR」と「北極星OKR」アプリを有効化すると、「/」や「+」を使って対応するOKRアプリを簡単に選択・挿入できます。

## 🎯 北極星OKRの挿入方法

## 北極星OKRで目標リンクをコピー

1、共有したい目標にマウスを移動し、詳細をクリックします。

2、詳細ページで右上の**共有アイコン**をクリックし、**DingTalkドキュメントにコピー**を選択します。

**二、DingTalkドキュメントに目標を挿入**

方法1：ドキュメント内で Ctrl + V もしくは右クリックでOKRリンクを貼り付けると自動的に認識され、テキストリンク、アイコン付きテキストリンク、サマリーカード、プレビューカードのいずれかを選択して表示できます。

**方法2：** ドキュメント内の挿入メニューをクリックし、リストから「北極星OKR」を選択、リンク入力欄に目標リンクを入力して完了をクリックすると、目標プレビューカードが生成されます。

**三、目標カードの活用方法**

挿入したカードは多彩な表示機能を備えており、さまざまな業務シーンに対応できます。
