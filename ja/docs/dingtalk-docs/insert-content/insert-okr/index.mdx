## ご利用方法

DingTalkドキュメントには、サードパーティのOKRアプリを挿入し、チームや個人のOKRコンテンツを直接表示して同期更新することができます。「叮当OKR」と「北極星OKR」アプリを有効化すると、「/」や「+」を使って、対応するOKRアプリを簡単に選択して挿入できます。

## 二、DingTalkドキュメントへの挿入

### 方法1：リンクを直接貼り付ける

ドキュメント内で Ctrl + v または右クリックでOKRのリンクを貼り付けると、自動的に認識され、テキストリンク、アイコン付きテキストリンク、サマリーカード、プレビューカードのいずれかを選択して表示できます。

### 方法2：挿入メニューから挿入する

ドキュメント内の挿入メニューをクリックし、リストから「叮当OKR」を選択します。リンク入力欄にOKRリンクを入力し、完了をクリックするとOKRプレビューカードが生成されます。

## 🎯 北極星OKRの挿入方法

## 北極星OKRで目標リンクをコピー

1、共有したい目標にマウスを移動し、詳細をクリックします

2、詳細ページで右上の**共有アイコン**をクリックし、**DingTalkドキュメントにコピー**を選択します

**二、DingTalkドキュメントに目標を挿入**

方法1：ドキュメント内で Ctrl + v または右クリックでOKRのリンクを貼り付けると、自動的に認識され、テキストリンク、アイコン付きテキストリンク、サマリーカード、プレビューカードのいずれかを選択して表示できます。

**方法2：** ドキュメント内の挿入メニューをクリックし、リストから「北極星OKR」を選択します。リンク入力欄に目標リンクを入力し、完了をクリックすると目標プレビューカードが生成されます。

**三、目標カードの活用方法**

挿入されたカードは豊富な表示機能を備えており、さまざまなビジネスシーンに対応します。
