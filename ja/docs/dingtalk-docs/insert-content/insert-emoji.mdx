## 機能の価値

記事構造を明確化し、コンテンツの理解を助け、ドキュメントの組版に創造性と効率性を両立します。

## 利用シーン

従来のリスト記号——黒点に飽きていませんか？ご安心ください。DingTalkドキュメントのリストに絵文字シリーズが新登場。多彩な創造的選択肢を提供し、効率的なオフィスワークと美しさ・新鮮さを兼ね備えます。ドキュメントを開いてリストのスタイルを変え、楽しいオフィスワークを気軽に始めましょう。

## 利用方法

シンプルモード

1. 番号付き／箇条書きを入力

2. 番号をクリックしてスタイルを切り替え

3. 箇条書きスタイルの中から絵文字リストを見つけてクリックして切り替え

プロフェッショナルモード

1. ツールバー → 箇条書き → スタイル → 絵文字リストを選択

2. ツールバー → 番号付きリスト
