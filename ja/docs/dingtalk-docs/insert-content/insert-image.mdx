ドキュメントコンテンツのテーブルをより直感的にするために、画像を挿入する機能を利用することがあります。適切に画像を挿入することで、ドキュメントを見やすく整えられます。

## 操作説明

## 画像の追加

トップナビゲーションバーの **挿入 —> 画像** をクリックするか、ツールバーから直接<strong>画像</strong>をアップロードすることで、ローカルの画像をドキュメントにアップロードできます。

## 画像の編集

画像をクリックすると画像ツールバーが表示され、各種設定を行えます。現在サポートされている操作は以下のとおりです。

*   画像内の文字を抽出

*   画像をダウンロード

*   画像スタイルを設定

*   画像サイズを設定

*   画像をトリミング

*   画像の説明

*   リンクを追加

*   画像を回転

*   水平揃え

*   画像を置換
