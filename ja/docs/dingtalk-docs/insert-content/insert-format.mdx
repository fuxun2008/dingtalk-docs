**DingTalk ドキュメント** には多様な書式が含まれることが多く、書式を使い分けることでドキュメントの階層が明確になり、レイアウトも美しくなります。

## 操作手順

上部のナビゲーションバーで **挿入 > 参照** 、 **挿入 > 区切り線** をクリックすると、ドキュメントに対応する書式要素を追加できます。

* 区切り線の上部メニューバーで区切り線のスタイルを選択できます。下図のとおりです。
