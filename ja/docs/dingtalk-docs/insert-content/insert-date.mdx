「DingTalkドキュメント」では日付の挿入に対応しており、手動入力の手間を省き、日付の書式を統一できます。挿入する日付には具体的な時刻も含めることができます。

## 操作手順

日付を追加する位置情報を選択し、上部ナビゲーションバーの**挿入 → 日付**をクリックします。表示されるカレンダーから目的の日時を選択してください。追加された日付のフォントは**青色**で表示されます。修正が必要な場合は、当該日付を直接クリックして再選択できます。

## 補足説明

*   カレンダー上の**左右の矢印** `<` `>` をクリックすると月を切り替えられます。

*   カレンダー左上の年をクリックすると年を切り替えられます。

*   カレンダー下部の**時刻**オプションにチェックを入れると、具体的な時刻を日付の後ろに表示でき、時刻は任意に調整可能です。
