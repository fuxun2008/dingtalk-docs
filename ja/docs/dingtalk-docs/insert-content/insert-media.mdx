DingTalkドキュメントは、豊富なサードパーティのオンライン音声・動画埋め込み機能を提供しています。現在、**Youku**、**西瓜動画**、**Tencent Video**、**Sohu Video**、**bilibili**、**NetEase Cloud Music** などのプラットフォームに対応しています。本記事では、各プラットフォームから埋め込み可能なリンクを取得する方法を順に解説します。

> ご注意：埋め込みコンテンツはサードパーティによって提供されており、DingTalkドキュメントは長期的な利用可能性を保証できません。サードパーティの利用規約および現地の法令を遵守してください。

## Youku

再生ページで **共有** をクリックし、**ページアドレス** または **一般コード** をコピーします：

埋め込みリンクの形式は以下のとおりです：

```application/xml
https://v.youku.com/v_show/id_xxx==.html?xxx
または

```

## 西瓜動画

再生ページで **共有** をクリックし、**動画アドレス** をコピーします（ブラウザのアドレスバーのリンクを直接コピーすることも可能です）：

埋め込みリンクの形式は以下のとおりです：

```application/xml
https://www.ixigua.com/xxx
```

## Tencent Video

再生ページで **共有** をクリックし、**埋め込みコード**（推奨）または **リンク** をコピーします：

埋め込みリンクの形式は以下のとおりです：

```application/xml
https://v.qq.com/x/cover/xxx/xxx.html
または

```

## Sohu Video

再生ページで **共有** をクリックし、**一般コード** をコピーします（ページアドレスの解析には非対応）：

埋め込みリンクの形式は以下のとおりです：

```application/xml
https://v.qq.com/x/cover/xxx/xxx.html
または

```

## bilibili

再生ページで **共有** をクリックし、**動画アドレス** または **埋め込みコード** をコピーします（ブラウザのアドレスバーのリンクを直接コピーすることも可能です）：

埋め込みリンクの形式は以下のとおりです：

```application/xml
https://www.bilibili.com/video/xxx
または

```

## NetEase Cloud Music

**シングル曲ページのアドレス**（推奨）をコピーするか、**外部リンクプレイヤーを生成** をクリックして **コードをコピー** します：

埋め込みリンクの形式は以下のとおりです：

```application/xml
https://music.163.com/#/song?id=xxx
または

```

## よくある質問

1.  **短縮リンクには対応していますか？**

    DingTalkドキュメントはサードパーティプラットフォームの短縮リンクの解析には対応していません。上記の手順に従って埋め込みリンクを取得してください。

2.  **埋め込んだ動画が再生できないのはなぜですか？**

一部のプラットフォームでは埋め込みコンテンツに再生制限が設けられている場合があります。これはリソースのタイプに関連する場合（例：一部の映画動画は埋め込み側での再生が許可されていない）や、ご利用のアカウントに関連する場合（例：ログイン状態、会員資格など）があります。詳細は各プラットフォームのカスタマーサポートにお問い合わせください。なお、YouTube動画をご利用の際は、現在のネットワークから当該サイトに接続できることをご確認ください。
