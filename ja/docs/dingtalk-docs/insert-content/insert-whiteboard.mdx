---

複数人によるオンラインコラボレーションでアイデアを集約できる **DingTalk Whiteboard** が、 **DingTalk ドキュメント** に挿入できるようになりました。フローチャートやディスカッションボードの作成に対応し、ブレインストーミングや図形描画などのシーンでご利用いただけます。

## 操作手順

**DingTalk ドキュメント** にて、上部ツールバーの **「挿入」** をクリックするか、ドキュメント内で「/bb」と入力します。表示される挿入パネルから **「ホワイトボード」** を選択し、クリックして挿入してください。
