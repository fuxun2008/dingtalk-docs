複数人によるオンラインコラボレーションでアイデアを集約できるDingTalk Whiteboardが、DingTalkドキュメントに挿入できるようになりました。フローチャートやディスカッションボードの作成に対応し、ブレインストーミングや図形描画などのシーンでご利用いただけます。

## 操作手順

DingTalkドキュメントにて、上部ツールバーの「挿入」をクリックするか、ドキュメント内で「/bb」と入力します。表示される挿入パネルから<strong>【ホワイトボード】</strong>を選択し、クリックして挿入してください。
