業務時間の節約、同じ内容のドキュメントの重複編集の回避、読み手が特定の名詞やデータをより理解しやすくするために、ドキュメントへの添付の挿入は良い方法です。DingTalkドキュメントでは、さまざまなタイプのドキュメントを添付として挿入し、閲覧や編集を行うことができます。

## 操作説明

## ローカル／ドライブのファイルを挿入

上部ナビゲーションバーの **挿入 → ファイル** をクリックするか、ツールバーの **ファイルをアップロード** を直接クリックし、ドロップダウンメニューから **ローカルファイル／ドライブファイル** を選択すると、該当位置にある添付をドキュメントにアップロードできます。

## 添付のプレビュー

ドキュメントに挿入した音声／動画ファイル、Office ファイルは、ダウンロード不要でオンラインでそのままプレビューできます。

## 添付ビューの設定

ドキュメントに挿入した添付は、異なる表示スタイルを設定できます（現在は PC 版のみ対応）：

*   **アイコンとテキストリンク**

*   **要約カード**

*   **プレビューカード**

## 補足説明

現在、最大 251M までの添付のアップロードに対応しており、オンラインプレビューに対応するファイル形式は以下のとおりです：

| 画像形式 | jpg、jpeg、png、bmp、gif |
| --- | --- |
| ドキュメント形式 | doc、docx、xls、xlsx、ppt、pptx、pdf |
| 動画形式 | mp4、egg、webm、mov |
| 音声形式 | mp3 |
