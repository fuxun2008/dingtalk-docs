編集したドキュメントを他者に閲覧してもらうために印刷が必要な場面は多くあります。たとえば、提携プランやユーザー向け使い方ガイドなどです。

## 操作説明

## 印刷の入口

*   PC版では、ドキュメント右上のナビゲーションバーにある【┇】<strong>—> 印刷</strong>をクリックするか、**ショートカットキー Ctrl+P（MAC：Cmd + P）** を使用すると、印刷設定ページに入ることができます。

*   ドキュメントの透かしの有効化に対応しています（企業の管理画面で透かしをオンにする必要があります）。[**管理画面**](https://oa.dingtalk.io/)**＞ ドキュメントとストレージ管理 ＞ 権限と安全 ＞ 企業セキュリティ管理 ＞** 文書透かしの<strong>オン／オフ</strong>

*   モバイル版では、DingTalkドキュメントを開き、右上の<strong>「…」- 印刷</strong>をタップします。

## 印刷の権限

ドキュメントへのアクセス権限を持つ方であれば、どなたでもドキュメント内で印刷機能を利用できます。

## 補足説明

以下の要素は現時点で 1:1 の印刷に対応していません。

*   プロジェクト看板

*   オンライン音声／動画

*   数式
