日常業務において、個人のドキュメントを他者に送信して閲覧してもらう場面は避けられません。ドキュメントのコンテンツが勝手に改ざんされるのを防ぎ、情報の安全を守るため、ドキュメントをPDFとしてエクスポートすることで、こうしたビジネスシーンの困りごとを上手く解決できます。

## 操作方法

## PDFエクスポートの入口

ドキュメント右上のナビゲーションバーで ┇**＞ ローカルにダウンロード ＞** **PDF** をクリックすると、ドキュメントをローカルのPDFファイルとしてダウンロードできます。本文とコメントの同時エクスポートに対応しています。

## PDFエクスポートの権限

ドキュメントへのアクセス権限を持つユーザーであれば、誰でもドキュメントをPDFとしてエクスポートできます。

## 補足説明

以下の要素は現在1:1でのエクスポートに対応していません：

*   プロジェクト看板

*   オンライン音声／動画

*   数式
