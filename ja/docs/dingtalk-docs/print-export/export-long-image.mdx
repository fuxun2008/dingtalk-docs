ドキュメントを他のプラットフォーム経由でオンラインで送信したり、ドキュメントの内容を印刷して他の場所に掲示したりする際、画像としてエクスポートする方法はシンプルで便利です。

## 操作説明

## ロング画像エクスポートの入口

ドキュメント右上のナビゲーションバーの ┇ **＞ ローカルにダウンロード ＞ 高画質ロング画像** をクリックすると、ロング画像エクスポート画面に入ります。

ロング画像のエクスポートは **PC とスマートフォン** の2種類のプレビューモードに対応しており、必要に応じて **見出し、作成者、最終編集時刻、ドキュメント QRコード** の表示有無を選択できます。さらに、さまざまなスタイル設定も可能です。

## ロング画像エクスポートの権限

ドキュメントのアクセス権限を持つユーザーであれば、ドキュメント内でロング画像エクスポート機能を利用できます。

## 補足説明

以下の要素は現在 1:1 でのロング画像エクスポートに対応していません：

*   プロジェクト看板

*   オンライン音声 / 動画

*   数式
