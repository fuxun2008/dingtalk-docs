DingTalkドキュメントはWordへのエクスポートに対応しており、複数フォーマットでのプレビューと編集を実現し、他のユーザーの業務習慣にも適応します。

## 操作手順

## Wordエクスポートの入口

ドキュメント右上のナビゲーションバーの ┇**\> ローカルにダウンロード >** **Word**をクリックすると、ドキュメントをローカルのWordファイルとしてエクスポートできます。現在は**.docx**形式でのエクスポートのみ対応しています。

## Wordエクスポートの権限

ドキュメントへのアクセス権限を持つユーザーであれば、誰でもドキュメントをWordにエクスポートできます。

## 補足事項

以下の要素は現時点で1:1のエクスポートに対応していません。

*   プロジェクト看板

*   オンライン音声/動画

*   数式
