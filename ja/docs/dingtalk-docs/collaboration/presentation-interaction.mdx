ライブ配信や講演の際、視聴者と効果的にインタラクションするにはどうすればよいでしょうか。DingTalkドキュメントのプレゼンテーションモードでは、同一組織内のユーザーが**QRコードをスキャンしてライブで質問できます**。プレゼンテーションの最終ページでは寄せられた質問を確認でき、質問を見ながら本文も同時に閲覧できるため、視聴者の参加度を手軽に高められます。

## 操作手順

**方法1**：プレゼンテーションモードをオンにした後、下部ツールバーのプレゼンテーション設定で<strong>「ライブインタラクション」</strong>をクリックすると、QRコードが表示されます。スキャンするとインタラクションに参加できます。

**方法2**：DingTalkドキュメントの右上にあるプレゼンテーション横の矢印をクリックし、プレゼンテーションページの編集を選択して、上部の<strong>「プレゼンテーション設定」</strong>をクリックし、設定内で<strong>「ライブインタラクション」</strong>をオンにします。

QRコードによるインタラクションをオンにすると、視聴者はQRコードをスキャンするだけで質問やインタラクションができます。講演者は質問を見ながら本文も同時に閲覧できるため、視聴者の参加度を手軽に高められます。さらに、プレゼンテーションの最終ページでライブで寄せられた質問を確認できます。
