他のメンバーとドキュメントを共同編集する際、ドキュメントのコンテンツに対してコメントを付けたり、コメント内で関係者を @ することができます。コメント内容はチャット通知を通じてリアルタイムに相手へ届けられ、効率的かつタイムリーです。

## 操作説明

DingTalkドキュメントは全文コメントとインラインコメントに対応しており、ドキュメント全体にコメントすることも、ドキュメント内の特定のコンテンツに対してコメントすることもできます。

## コメントの追加

### インラインコメント

**PC版：** テキストコンテンツを選択し、右側の **コメントを追加** ボタンをクリックするか、ショートカットキー **Ctrl+Shift+M**（Mac：**Cmd+Shift+M**）を使用すると、該当コンテンツに対するコメントを投稿できます。コメント内容はドキュメント右側の余白エリアに表示されます。

**モバイル版：** ドキュメント内でテキストを長押しして選択するか、指で軽くスワイプして段落を選択し、下部のボタンをタップするとコメントできます。

### 全文コメント

ドキュメントを最下部までスクロールし、ページ最下部の入力欄から全文コメントを入力できます。

## コメントへの返信

コメントの後ろにある **返信** ボタンをクリックすると、そのコメント内容に対して返信できます。コメントの送信者にはDingTalkチャットで通知が届きます。

## コメントの削除

コメント投稿者は自分のコメントのみ削除でき、他人のコメントは削除できません。コメントの **右上の「┇」 → コメントを削除** をクリックすると、送信済みのコメント内容を削除できます。
