## 機能の価値

ドキュメント内のインラインコメントで画像のアップロードに対応。一枚の画像は千の言葉に勝り、明確な表現で効率的なコラボレーションを実現します。

## 利用シーン

DingSanduo氏はインターネット企業のプロダクト運営担当者で、日常業務でDingTalkドキュメントを使って同僚とインタラクションやコラボレーションを行っています。ドキュメントのインラインコメントで画像のアップロードがサポートされたことで、データ分析やプロジェクト進捗など、文字では表現しづらいコンテンツをコメントに直接画像として挿入でき、同僚間のコラボレーション効率が向上しました。

## 利用方法

コメント時に画像アイコンをクリックすると、画像をコメントに挿入できます。
