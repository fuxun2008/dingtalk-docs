## 概要

**DingTalk ドキュメント** のインラインコメントでは画像のアップロードに対応しています。画像を使えば、言葉では伝えきれない内容も明確に表現でき、効率的なコラボレーションが可能になります。

## ユースケース

DingSanduo氏はインターネット企業のプロダクト運営担当者で、日常業務でDingTalk ドキュメントを使って同僚とコミュニケーションやコラボレーションをしています。ドキュメントのインラインコメントで画像のアップロードがサポートされるようになり、データ分析やプロジェクト進捗など、文字では表現しづらいコンテンツをコメントに直接画像として挿入でき、同僚間のコラボレーション効率が向上しました。

## 使い方

コメント時に **「画像アイコン」** をクリックすると、画像をコメントに挿入できます。
