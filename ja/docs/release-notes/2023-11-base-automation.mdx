## 多次元テーブル

## 更新・通知・催促を手動で行うのは面倒？DingTalk 多次元テーブルにお任せして「自動」処理！

多次元テーブル「自動化」機能が登場しました！シンプルな設定だけで、繰り返し発生する煩雑なタスクを自動的にリマインドでき、人による催促なしでコラボレーション効率を簡単に向上させます。

[電球] 対応機能：Mac / Windows ユーザー向け（DingTalk プロフェッショナル版、専用版の特典）

[ノート] 使用方法：多次元テーブルページの右上にある「自動化」をクリックし、自動化フローを設定してください

## カレンダー

---
## 新たに「予定調整中」に対応、先に項目を記録してからスケジュール時間を設定、タスクを取りこぼさず柔軟に設定可能

DingTalk カレンダーでは、DingTalk 内のすべての未完了タスクを確認でき、完了予定時間を設定してカレンダービューに表示できます。重要な会議や予定の調整がより柔軟になり、タスクの取りこぼしを防ぎます。

[▶️ 動画で詳しく見る](https://cloud.video.taobao.com/play/u/null/p/1/e/6/t/1/438176348744.mp4)

[電球] 対応機能：Mac / Windows ユーザー向け

[ノート] 使用方法：

カレンダー右上の「予定調整中」から、期限が未設定のすべてのタスクを確認できます

「予定調整中」では、タスク関連情報の確認や、タスク詳細へのジャンプができます

さらにタスクの期限を設定することも可能で、設定後はカレンダービューに表示され、時間軸ですべての項目を確認しやすくなります
