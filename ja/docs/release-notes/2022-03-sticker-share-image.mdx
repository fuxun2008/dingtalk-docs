**更新バージョン：6.3.35**

**DingTalkドキュメント**

<Note>
## 1、テキスト：カバー画像の設定

機能価値：ドキュメントにシンプルなカバー画像を追加できます

主な操作：ドキュメントの見出しの上にある「カバーを追加」をクリックし、おすすめの背景画像を選択するか、画像をアップロードします

**2、テキスト：画像に 6 種類のスタイルをすばやく設定でき、幅と高さの細かい調整にも対応**

機能価値：画像ツールバーから画像スタイルをすばやく設定でき、画像設定パネルから幅と高さを正確に調整できます

主な操作：1. 画像をクリックすると、画像の上にツールバーが表示されます；2. スタイル設定をクリックすると、画像スタイルをすばやく調整できます；

3. プレミアム設定をクリックすると、画像の幅・高さ・スタイルなどを調整できます

**3、日報：日報テンプレートをグループに追加可能（PC 版）**

機能価値：グループ内でよく使う日報テンプレートにワンクリックでアクセス

主な操作：日報テンプレート管理

**4、日報：グループレポートをグループ日報にアップグレード**

機能価値：グループ日報の管理機能アップグレード - 複数のテンプレートの関連に対応；管理経路の最適化

主な操作：グループ日報プラグイン

**5、マインドマップ：アウトラインメニュー**

機能価値：アウトラインノートモードでも強調・太字・アイコンや画像の挿入などの操作が可能

主な操作：アウトラインモードに入り、「ノードの前の小さな丸印」をクリックすると、メニューが表示され対応する操作を実行できます

**6、マインドマップ：外枠**

機能価値：関連性のある複数のノードに外枠をまとめて追加し、注釈や説明を加えることができます

主な操作：複数のノードを選択した後、ツールバーの「外枠」ボタンをクリックすると、外枠を追加できます
</Note>

### メール

<Note>
## 1、デバイス管理（Alibaba メール Businessプラン - Web 版）

機能価値：1. ログインデバイスを追跡でき、より安全 2. 信頼済みデバイスを設定でき、ログイン認証不要でより便利

主な操作：1. デバイス管理画面でログインデバイスを確認できます 2. 信頼済みデバイスを設定できます

**2、アーカイブのアップグレード（Alibaba メール Businessプラン - Web 版）**

機能価値：5 年間のアーカイブサービス、独立した権限付与、より明確な検索により、企業のメールコンプライアンスや検索発見などの管理ニーズによりよく応えます

主な操作：1. オンボタンをクリックすると、5 年以内のメールが自動的にアーカイブされ、企業のコンプライアンスニーズによりよく応えます 2. スーパー管理者とアーカイブ管理者の権限を分離し、アーカイブ管理者を個別に設定する必要があり、データ安全保障がより厳格になります

**3、メール転送ルール（Alibaba メール Businessプラン - Web 版）**

機能価値：ルール定義機能をアップグレードし、「拒否して理由をフィードバック」などの新機能を追加しました。企業は実際のシーンに応じて、より柔軟にメール転送監視ルールを設定でき、情報安全を保障します

主な操作：1. メール監視転送ルールの設定 2. メール送信審査ルールの設定 3. メール受信フィルタールールの設定
</Note>

### カレンダー

<Note>
## カレンダーカードでの変更要素の表示（PC 版）

機能価値：参加者はカレンダーのリマインダーカード上で主催者が変更した情報を確認でき、情報取得が一目瞭然です

主な操作：主催者が予定の時間や場所などの情報を変更したとき、参加者は PC 版で通知を受け取り、タグで変更された要素がマークされ、参加者は変更要素を明確に把握できます
</Note>

### ドライブ

<Note>
## 共有リストに「自分への共有」と「自分が共有した」の具体的なファイルを並列表示

機能価値：共有リストに「自分への共有」と「自分が共有した」の具体的なファイルを並列表示し、ファイルの所属パスを隠すことで、コラボレーションがより効率的になり、情報がより安全になります

主な操作：ドライブ - 共有 - 自分への共有 / 自分が共有した：他のユーザーが自分に共有したファイル、または自分が共有した具体的なファイルを確認でき、同時にファイルの所属パスを把握する必要がありません（最適化前は最上位フォルダーから階層的に検索する必要がありました）
</Note>

### DingTalk プロジェクト

<Note>
## 1、「マイタスク」に「所属プロジェクト」の絞り込み機能を追加（DingTalk クライアント）

機能価値：タスクの絞り込み軸を充実させ、より効率的かつ正確に管理

主な操作：絞り込みコンポーネントを開き、「所属プロジェクト」をクリックして選択します

**2、タスクで DingTalkドキュメントフィールドと DingTalkドキュメントの関連をサポート（TB web / DingTalk クライアント / DingTalk モバイル版）**

機能価値：タスクに関連ドキュメントを関連付けし、タスク情報を充実させます

主な操作：1. タスクのタスクタイプを設定し、プレミアムフィールドの DingTalkドキュメントを追加し、タスク内に現在の企業の DingTalkドキュメントを入力します；2. タスクで「関連コンテンツ」-「リソースから追加」-「DingTalkドキュメント」を選択します

**3. グリッドビューでグループ分け表示をサポート（TB web / DingTalk クライアント）**

機能価値：さまざまな次元でタスクを分類し、絞り込みや並び替えと組み合わせてタスクをよりよく管理

主な操作：プロジェクト内のツールバーで「グループ分け」をクリックし、どのフィールドでグループ分けするかを選択します

**4、ツールバーのインタラクション最適化（TB web / DingTalk クライアント）**

機能価値：よく使う機能を外部に表示し、高頻度の操作を便利に

主な操作：1. 看板列 - タスクステータス別 のとき、作業フローを二次メニューからツールバーに昇格させ、ハイライト表示します 2. すべてのビューで、タスク階層メニューを「...」から取り出してツールバーに配置し、「サブタスクのみ」のときハイライト表示します；看板ビューでは、「カードフィールド」を「...」内に格納しました

**5、プロジェクト「グループチャット」設定のインタラクション最適化（DingTalk クライアント）**

機能価値：「グループチャット」設定の入口を外部に表示し、ユーザーが見つけられない事態を防ぎます

主な操作：プロジェクトチャットアプリを開きます

**6、「管理バックエンド」構造の最適化（TB web / DingTalk クライアント / DingTalk モバイル版）**

機能価値：情報構造がより明確になり、インタラクション体験がよりフレンドリーに

主な操作：「管理バックエンド」/「設定センター」を開きます
</Note>
