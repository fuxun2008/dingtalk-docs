## 安全管理権限のアップグレード、単一ドキュメントに「管理可能」権限の追加をサポート

単一ドキュメントごとに「管理可能」権限を個別に設定でき、ドキュメントコンテンツの管理者を追加することで、ドキュメントコンテンツの安全を確保します。

</Note>
[電球] 対応機能：Android/iOS/Mac/Windows/Web ユーザーが利用可能

[ノート] 使用方法：ドキュメント共有パネル > 権限管理
