マインドマップを作成する際、ショートカットキーを使用することでコンテンツをより効率的に入力でき、マウスとキーボードの切り替えを減らし、入力効率を向上させることができます。

## 使用方法

*   1 つまたは複数のノードを選択し、ショートカットキーを押します。ノードに関係のないショートカットキーは、コンテンツを選択しなくても使用できます。

## マインドマップビューモード

*   Mac OS の場合：

| ショートカットキー分類 | ショートカットキー機能 | ショートカットキー |
| --- | --- | --- |
| よく使う | 同じ階層のノードを挿入 | Enter |
|  | 子ノードを挿入 | Tab |
|  | 親ノードを挿入 | Shift + Tab |
|  | ノードを削除 | Delete、Backspace |
|  | ノードナビゲーション | ↑↓←→ |
|  | 元に戻す | ⌘ + Z |
|  | やり直す | ⌘ + Y |
| ノード操作 | ノードをコピー | ⌘ + C |
|  | ノードを切り取り | ⌘ + X |
|  | ノードを貼り付け | ⌘ + V |
|  | ノードの複製を作成 | ⌘ + D |
|  | 展開／折りたたみ | ⌘ + . |
| ナビゲーション | キャンバスを拡大 | ⌘ + + |
|  | キャンバスを縮小 | ⌘ + - |
|  | プレゼンテーションモードに入る | ⌘ + Shift + P |
|  | ショートカットキーアシスタント | Control + H |
