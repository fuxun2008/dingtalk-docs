ノードにアイコンを追加し、ノード全体を装飾できます（タグ、優先度、絵文字、タスクの設定など）。

## アイコンの追加

*   ノードのツールバーにある「マーク追加」ボタンをクリックすると、アイコンパネルが表示されます。該当するアイコンをクリックすると、そのアイコンがノードに挿入されます。

*   アイコンは現在、タグ、優先度、絵文字、タスクの4種類に分類されており、各タイプにつき最大1つのアイコンをノードに挿入できます。

*   現在のノードにすでに特定の種類のアイコンが挿入されている状態で、同じタイプの別のアイコンをクリックすると、現在のアイコンが「置換」されます。下図を例に挙げると、選択済みのノードには「タスク」タイプのアイコンが追加されており、この状態でパネル上の「タスク」の3つ目のアイコンをクリックすると、ノード上のアイコンが置換されます。

*   パネル上の「すべてのマークを削除」をクリックすると、ノード上のすべてのアイコンがクリアされます。

## ショートカットによるアイコンの置換 / 削除

*   ノードにアイコンを挿入した後、特定のアイコンをより素早く変更または削除したい場合は、アイコンを直接クリックし、表示されるパネルから置換 / 削除の操作を実行できます。

## モバイル端でのアイコン編集

*   「DingTalk Mind」モードでノードを選択し、ツールバーのボタンをクリックすると、アイコンパネルが表示され編集できます。挿入のルールは上記のPC版と同じです。

*   ノード上の特定のアイコンをクリックしても、同様にアイコンパネルを呼び出して編集できます。
