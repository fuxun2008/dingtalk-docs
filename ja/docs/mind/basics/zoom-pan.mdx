「マインドマップビュー」モードでは、キャンバス全体のズームやスクロールが可能で、詳細と全体像を簡単に切り替えられます。

## PC版でキャンバスをズーム

*   現在、以下の4つの方法に対応しています：

1.  Ctrl + マウスホイールで操作；

2.  タッチパッドの2本指で操作（現在 DingTalk Mac クライアントでは未対応。ブラウザで開くとより快適にご利用いただけます）；

3.  Ctrl + +/- で操作；

4.  右下のズームツールでキャンバスのズームを操作。

## PC版でキャンバスを移動

*   現在、以下の5つの方法に対応しています：

1.  マウスホイールでキャンバスを移動；

2.  タッチパッドの2本指で操作；

3.  マウス右ボタンを長押ししてキャンバスをドラッグ；

4.  左側の【手のひらアイコン】でキャンバスを移動；

5.  コンテンツが多い場合は、スクロールバーをドラッグしてキャンバスを移動することも可能。

## スマートフォン版でキャンバスをズーム

*   「マインドマップビュー」モードでは、キャンバスの空白エリアで2本指によるズーム操作が可能です。

*   2本指でのズームに成功すると、画面中央に現在のズーム倍率が表示されます。

## スマートフォン版でキャンバスを移動

*   「マインドマップビュー」モードでは、キャンバスの空白エリアを1本指でスワイプするとキャンバスを移動できます。
