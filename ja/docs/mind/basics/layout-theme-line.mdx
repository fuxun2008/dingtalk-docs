## レイアウト構造・件名・線種を切り替えるには？

*   PC版：「マインドマップビュー」モードで、画面左上のボタンをクリックするとパネルが表示され、お好みのレイアウト構造、線種、件名に切り替えできます。

*   スマートフォン版：「マインドマップビュー」モードで、画面右下のボタンをクリックするとパネルが表示され、お好みのレイアウトに切り替えできます。
