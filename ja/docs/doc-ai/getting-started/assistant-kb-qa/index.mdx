## 一、DingTalkドキュメント AI・ナレッジベース Q&A について

DingTalkドキュメントのナレッジベースは、大規模モデルの機能を統合することで、権限管理の範囲内で当該ナレッジベース専用のモデルを生成し、企業や組織が専属のスマートドキュメントアシスタントを保有できるようにします。社員一人ひとりがナレッジベースのコンテンツをより効率的に取得でき、知識の生産・消費効率を高め、学習型組織への成長を支援します。

## 二、主な機能

ナレッジベーススマートアシスタントを有効化すると、当該ナレッジベース内の **DingTalkドキュメント、PDF** ファイルの内容を自動学習でき、追加・削除・変更などの操作後も自動的に同期学習されます。DingTalk のチャット画面で直接 PDF ファイルを閲覧し、スマートアシスタントを開いて質問することができます。PDF から有効な情報を素早く抽出し、整理してわかりやすく回答してくれるので、論文・書籍・契約書を読むのがより楽になります。

*   **現在学習に対応しているドキュメント形式は以下の通りです：**

| ドキュメント形式 | 対応状況 | 表示名 |
| --- | --- | --- |
| DingTalkドキュメント | [進捗: 完了しました] 対応 | ドキュメント内の「テーブル」コンテンツの学習に対応 |
| スプレッドシート | 未対応 | |
| DingTalk Mind | 未対応 | |
| PDF | [進捗: 完了しました] 対応 |  |
| WORD | 未対応 | |
| EXCEL | 未対応 | |

\*2023年7月5日時点。「未対応」については、順次開発・提供予定です。

## 三、適用シーン

ナレッジベーススマートアシスタントを使えば、チームのナレッジを素早く取得できます。業務報告、ナレッジ Q&A、新人向けヘルプ、企業 Wiki、製品マニュアルなど、さまざまな業務シーンに適用可能です。チームのナレッジをスマートに読み取り、分析し、要約することで、企業ごとの専属ナレッジアシスタントとなります！

## 四、有効化と無効化の方法

*   <strong>初回有効化：</strong>管理権限のあるナレッジベースのホームに入り、右下の「AIアシスタント」を選択し、「今すぐオン」をクリックすることで有効化できます。

*   <strong>機械学習：</strong>初回有効化時、スマートアシスタントはナレッジベース内の権限のあるドキュメントコンテンツを自動学習します。しばらくお待ちください。学習完了後、スマートアシスタントに質問することができます。

## 五、よくある Q&A

## ナレッジベースのドキュメントには権限があるが、Q&A は権限を超えて回答しないか？

いいえ。質問者がドキュメントへの権限を持っている場合のみ、関連内容を回答します。

## 1つのナレッジベースの学習には平均どれくらい時間がかかるか？

通常 1〜5分以内に学習が完了します。最長でも 40分を超えることはありません。学習時間が長すぎる場合は、お手数ですがフィードバックをお願いいたします。

## 対応しているファイルタイプは？doc、xls はいつ対応するか？

現在は DingTalkドキュメントと PDF に対応しています。その他の形式についても、できるだけ早く対応する予定です。

## コンテキストベースの Q&A に対応しているか、いつ対応するか？

現在は未対応です。機能を計画中です。

## 5. ドキュメントスマートアシスタントには回数制限があるか？

現在、<strong>DingTalkドキュメントスマートアシスタントの指名招待にご参加いただいた</strong>お客様は、**招待期間中の利用時間に制限はありません。変更がある場合は、公式通知をご確認ください**。

## 6. ドキュメントスマートアシスタントのリリース時期と課金方法は？

DingTalkドキュメントスマートアシスタントは現在ベータテスト中で、一部の DingTalk プロフェッショナル版および専属版のお客様を対象に指名招待を行っています。具体的なリリース時期や課金方法については、引き続きご注目ください。
