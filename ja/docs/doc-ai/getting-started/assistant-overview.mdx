### **作成支援で、ドキュメント作成がこんなにシンプルに**

ドキュメント内で「作成支援」を使えば、AIがマーケティング企画、クリエイティブストーリー、プロモーション文案、まとめレポート、競合分析など、豊富なコンテンツを素早く生成し、業務効率を全面的に向上させます。

### **コンテンツのリライトで、表現をより豊かに**

トーンの表現が物足りない？AIにコンテンツをリライトしてもらいましょう。要約の生成、トーンの書き換え、文章の推敲など、さまざまな表現方法に手軽に変換できます。

### **画像生成で、多彩なスタイルの画像を手軽に作成**

創造力と想像力を発揮し、「画像生成」でAIにさまざまなスタイルで生き生きとした画像素材を生成してもらい、作成時間を短縮し、効率を向上させましょう。

### スプレッドシート生成で、ワンクリックで可視化テーブルを作成

ドキュメントの情報が煩雑？「スプレッドシート生成」を使えば、AIが構造化されたテーブルを素早く作成し、コンテンツ情報を明確に表示します。

### **ドキュメントからの文章生成で、業務ドキュメントを抽出・分析**

質問時に「ドキュメント追加」を使えば、AIが業務ドキュメントに基づき、分析、集計、抽出、コンテンツ作成を行います。根拠に基づいた、より正確なコンテンツをスマートに生成します。
