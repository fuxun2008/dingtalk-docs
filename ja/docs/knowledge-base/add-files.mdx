ナレッジベースでは、<strong>ローカルファイル、チャットファイル、クイック会議、日報</strong>を追加でき、さまざまなシーンで資料を整理・収納し、ナレッジの蓄積と管理をより便利にします。

## ローカルファイルをナレッジベースに追加するには？

ナレッジベースの<strong>ホームページ</strong>を開く >> 左側の目次バーの「」をクリック >> ローカルファイル／フォルダーを選択し、当該ナレッジベースにアップロードできます。

## チャットファイルをナレッジベースに追加するには？

**ローカルドキュメント**：ドキュメントカード右下の【追加先…】をクリックし、保存先のナレッジベースを選択します。

**オンラインドキュメント：** ドキュメントカード右下の【追加先…】をクリックし、保存先のナレッジベースを選択します。

## クイック会議をナレッジベースに追加するには？

クイック会議のドキュメントを開く >> 右上の【…】をクリック >> 【リンクを追加先】を選び、対応するナレッジベースおよびフォルダーを選択します。

## 日報をナレッジベースに追加するには？

ナレッジベースに追加したい日報を開く >> 【追加先】をクリック >> 対応するナレッジベースおよびフォルダーを選択します。

## グループファイルをまとめてナレッジベースに追加するには？

グループチャット画面で、上部の【**ズームアイコン**】をクリック >> 【**ファイル**】を選択 >> グループファイルのポップアップを開き、ナレッジベースに追加したい複数のファイルを選択 >> 【**追加先**】をクリック >> 対応するナレッジベースおよびフォルダーを選択します。ドキュメントやスプレッドシート、PDFだけでなく、フォルダーや音声ファイルなども選択できます。
