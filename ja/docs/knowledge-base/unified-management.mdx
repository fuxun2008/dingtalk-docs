## すべてのファイルを一か所に蓄積

### [優先度: 1] 一元的に蓄積

[進捗: 完了しました] DingTalkのチャット画面では、動画、画像、音声、オンラインドキュメント、ローカルファイルのいずれであっても、ファイルカードの**「追加先」**をクリックするだけでDingTalkドキュメントの統一保存パネルが起動し、**「マイドキュメント」「チームファイル」「ナレッジベース」**などお好きな場所にファイルを保存できます！

### [優先度: 2] ドライブの「チームファイル」を統合

[進捗: 完了しました] DingTalkドキュメントはドライブの「チームファイル」を統合し、共有ファイルへのアクセスと管理をワンストップで実現します。

[進捗: 完了しました] 大量・大容量で、かつチームで共有するローカルファイル（画像、動画など）は「チームファイル」への保存を推奨します。

### [優先度: 3] ドライブの「マイファイル」を統合

[進捗: 完了しました] 「マイドキュメント」はドライブの「マイファイル」を統合しており、個人の学習や業務に使用する資料はすべて**「マイドキュメント」**に蓄積し、個人の業務資料をワンストップで管理できます。

[進捗: 完了しました] 複数の並び替え方法やドラッグによる移動・整理に対応し、ドキュメントとドライブ両方の既存ユーザーの操作習慣に適合します。

### [優先度: 4] 「ナレッジベース」でチーム業務ドキュメントの管理・蓄積

[進捗: 完了しました] 「ナレッジベース」は、知識の蓄積、流通、コラボレーションを一体化した企業向けナレッジマネジメントプラットフォームです。

[進捗: 完了しました] オンラインドキュメントやローカルスプレッドシートなど、複数ユーザーでのコラボレーション編集や複数回の共有・流通が必要なドキュメントファイルは、**「ナレッジベース」**を選択して保存・管理できます！

## 二、目的のファイルを素早く検索

### [優先度: 1] 全体検索

[進捗: 完了しました] DingTalk左側のサイドバーから**「ドキュメント」**でホームに入り、上部の検索バーにキーワードを入力すると、DingTalkドキュメントまたはドライブのすべてのコンテンツを検索できます。

[進捗: 完了しました] さらに、所在位置情報、作成者、共有者などのフィールドでフィルターをかけて正確に検索し、目的のドキュメントを素早く特定できます。

### [優先度: 2] 共有

[進捗: 完了しました] 「共有」モジュールを新設し、権限追加やチャット共有などの方法で、自分と共有または自分が共有したコンテンツを効率的に検索できます。

### [優先度: 3] お気に入り検索

[進捗: 完了しました] DingTalkドキュメントまたはドライブのすべてのコンテンツをワンストップでお気に入り登録でき、多角的にお気に入りファイルを検索できます。

## 三、効率的な管理と安全な流通

### [優先度: 1] 一括操作

[進捗: 完了しました] 「ナレッジベース」の目次は、一括移動、コピー、削除の操作に対応しており、繰り返し操作の煩わしさを解消し、ファイル整理を素早く行うことで、ナレッジマネジメントをよりスピーディで効率的にします。

操作方法その1：ナレッジベースの左サイドバー目次ページで「一括操作」アイコンを選択し、一括操作したいコンテンツのチェックボックスを選択してから、コピー、移動、削除のアイコンを選択します。

操作方法その2：ナレッジベースのホーム目次ページで、一括操作したいファイルまたはフォルダーの前にマウスを置くとチェックボックスが表示されるので、一括操作したいファイルまたはフォルダーを選択します。

### [優先度: 2] 安全管理

[進捗: 完了しました] 安全権限の管理を全面的にアップグレードし、**「ウォーターマーク」「漏洩防止」**の管理設定を新設しました。ドキュメントデータの安全性を強化し、権限管理をより効率的に行えます。

| **安全レベル** | **操作手順** | **パス画像** |
| --- | --- | --- |
| 企業内すべてのドキュメントの安全設定 | 「PC版DingTalk」-「ドキュメント」-［下部のその他］-［企業設定］から管理画面に入り、コラボレーション系プロダクト設定の「権限と安全」で設定できます。<br />\*この設定権限は管理者のみに限定されます |  |
| ナレッジベース内すべてのドキュメントの安全設定 | ナレッジベース管理画面-「安全設定」で設定できます。<br />\*この設定権限はナレッジベース管理者のみに限定されます |  |
| 単一ドキュメントの安全設定 | 単一ドキュメントの「権限管理」で「権限設定」をクリックして設定できます。<br />\*この設定権限はドキュメント所有者および管理権限者のみに限定されます |  |
