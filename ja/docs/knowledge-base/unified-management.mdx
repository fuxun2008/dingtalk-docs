## すべてのファイルを一か所に蓄積

### 1. 一元的に蓄積

DingTalk のチャット画面では、動画、画像、音声、オンラインドキュメント、ローカルファイルのいずれでも、ファイルカードの **「追加先」** をクリックするだけで、DingTalk ドキュメントの統一保存パネルが起動します。**「マイドキュメント」**、**「チームファイル」**、**「ナレッジベース」** など、好きな場所にファイルを保存できます。

### 2. ドライブの「チームファイル」を統合

DingTalk ドキュメントはドライブの「チームファイル」を統合し、共有ファイルへのアクセスと管理をワンストップで実現します。

大量・大容量でチームで共有するローカルファイル（画像、動画など）は、「チームファイル」への保存を推奨します。

### 3. ドライブの「マイファイル」を統合

「マイドキュメント」はドライブの「マイファイル」を統合しており、個人の業務資料をワンストップで管理できます。

複数の並び替え方法やドラッグによる移動・整理に対応し、ドキュメントとドライブ両方の操作習慣に適合します。

### 4. 「ナレッジベース」でチーム業務ドキュメントの管理・蓄積

「ナレッジベース」は、知識の蓄積、流通、コラボレーションを一体化した企業向けナレッジマネジメントプラットフォームです。

複数ユーザーで共同編集や繰り返し共有が必要なドキュメントファイルは、**「ナレッジベース」** を選んで保存・管理できます。

## 目的のファイルを素早く検索

### 1. 全体検索

DingTalk 左側のサイドバーから **「ドキュメント」** でホームに入り、上部の検索バーにキーワードを入力すると、DingTalk ドキュメントまたはドライブのすべてのコンテンツを検索できます。

所在位置、作成者、共有者などでフィルターをかけて、目的のドキュメントを素早く絞り込めます。

### 2. 共有

「共有」モジュールでは、権限追加やチャット共有を経由して自分と共有された、または自分が共有したコンテンツを効率的に検索できます。

### 3. お気に入り検索

DingTalk ドキュメントまたはドライブのすべてのコンテンツをワンストップでお気に入り登録でき、お気に入りファイルを検索できます。

## 効率的な管理と安全な流通

### 1. 一括操作

「ナレッジベース」の目次は、一括移動、コピー、削除に対応しており、ファイル整理を素早く行えます。

操作方法その1：ナレッジベースの左サイドバー目次ページで「一括操作」アイコンを選択し、一括操作したいコンテンツのチェックボックスを選択してから、コピー、移動、削除のアイコンを選択します。

操作方法その2：ナレッジベースのホーム目次ページで、一括操作したいファイルまたはフォルダーの前にマウスを置くとチェックボックスが表示されるので、一括操作したいファイルまたはフォルダーを選択します。

### 2. 安全管理

安全権限の管理が強化され、**「ウォーターマーク」「漏洩防止」** の管理設定を利用できます。ドキュメントデータの安全性を高め、権限管理を効率化できます。

| **安全レベル** | **操作手順** | **パス画像** |
| --- | --- | --- |
| 企業内すべてのドキュメントの安全設定 | **「PC版DingTalk」** > **「ドキュメント」** > **「下部のその他」** > **「企業設定」** から管理画面に入り、コラボレーション系プロダクト設定の **「権限と安全」** で設定できます。<br />\*この設定権限は管理者のみに限定されます |  |
| ナレッジベース内すべてのドキュメントの安全設定 | ナレッジベース管理画面 > **「安全設定」** で設定できます。<br />\*この設定権限はナレッジベース管理者のみに限定されます |  |
| 単一ドキュメントの安全設定 | 単一ドキュメントの **「権限管理」** > **「権限設定」** をクリックして設定できます。<br />\*この設定権限はドキュメント所有者および管理権限者のみに限定されます |  |
