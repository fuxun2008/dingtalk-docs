## アップロードとインポートとは？

### アップロード：

すべての種類のローカルファイルをナレッジベースにアップロードでき、一部の形式はプレビューに対応しています。アップロード後はファイルリンクを取得して共有でき、**ファイル形式は変更されません**。

アップロード方法：**ナレッジベースのホームページ**\>>左側の目次バーの「」>>ローカルのファイル／フォルダーを当該ナレッジベースへアップロードを選択。

### インポート：

一部の種類のローカルファイルをナレッジベースにインポートでき、<strong>オンラインファイルへ変換</strong>されます。ドキュメントリンクを取得して共有でき、**DingTalkドキュメント形式に変換されます**。

インポート方法：**ナレッジベースのホームページ**\>>左側の目次バーの「」>>【オンラインドキュメントとしてインポート】を選択。

以下は、ファイルタイプごとのインポート後の変換形式の説明です：

| **ローカルファイルタイプ** | **オンラインファイルタイプ** |
| --- | --- |
| doc、docx、markdown、mark、md、txt | DingTalkドキュメント |
| xls、xlsx | スプレッドシート |
| xmind | DingTalk Mind |

## アップロードとインポートに対応するファイルタイプは？ファイルサイズに制限はありますか？

「アップロード」は<strong>多様なファイルタイプのプレビューに対応</strong>し、1ファイルあたり最大8Gまで対応します。「インポート」は<strong>ドキュメントタイプのみ対応</strong>し、1ファイルあたり最大20Mまでです。

具体的な違いは以下の通りです：

| **転送方法** | **ファイルタイプ** | **プレビュー対応形式** | **サイズ制限** |
| --- | --- | --- | --- |
| アップロード | ドキュメント | pdf, pptx, ppt, pot, potx, pps, ppsx, dps, dpt, pptm, potm, ppsm, xls, xlt, et, ett, xlsx, xltx, xlsb, xlsm, xltm, csv, doc, dot, wps, wpt, docx, dotx, docm, dotm, txt、xmind | 1ファイルあたり最大8G |
|  | 画像 | peg、bmp、png、jpg、ico、webp |
|  | 音声・動画 | 3GP、AVI、FLV、MP4、M3U8、MPG、ASF、WMV、MKV、MOV、TS、WebM、MXF、AAC、AC-3、ADPCM、AMR、DSD、MP1、MP2、MP3、PCM、RealAudio、Windows Media Audio |
|  | その他 | zip圧縮ファイル |
| インポート | ドキュメント | docx, xlsx, doc, xls、txt、xmind、markdown、mark、md | 1ファイルあたり最大20M |

## どのようなシーンでアップロードとインポートを使い分けるべきですか？

| **転送方法** | **適用シーン** |
| --- | --- |
| アップロード | *   既存のチームのPPTやドキュメント資料を、部門のナレッジベースにアップロードして一元管理したい<br />    <br />*   ローカルの画像や動画を、複数のチームで一緒に閲覧できるよう共有したい |
| インポート | *   ローカルファイルをオンラインファイルに変換 |

## アップロードとインポートは企業のストレージ容量を占有しますか？

「ファイルをアップロード」は<strong>企業のストレージ容量を占有します</strong>が、「オンラインドキュメントとしてインポート」は<strong>企業のストレージ容量を占有しません</strong>。具体的な説明は以下の通りです：

| **転送方法** | **課金対象** | **ストレージ容量に算入されるファイル** | **表示名** |
| --- | --- | --- | --- |
| **アップロード**<br />ローカルファイル（フォルダー）を「マイドキュメント」「ナレッジベース」へアップロード | アップロード先のスペース | アップロードされたすべてのファイル | *   フォルダーを直接アップロードした場合、フォルダー内のファイルのみがクラウドストレージ容量に算入され、フォルダー自体は算入されません。<br />    <br />*   他人が所有する画像、動画、ファイル等を閲覧する場合は、自身のスペースを占有しません。 |
| **インポート**<br />「マイドキュメント」「ナレッジベース」内で作成またはオンラインドキュメントとしてインポート | 【期間限定無料】現時点では算入されません | 【期間限定無料】現時点では算入されません | 【期間限定無料】現時点では算入されません |
