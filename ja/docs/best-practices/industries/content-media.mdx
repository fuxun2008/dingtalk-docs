Vivian さんは Ximalaya のイノベーションコンテンツ制作部門のプロデューサーで、主にサスペンス、映像作品コンテンツの特集を担当しており、毎年数十回の特集を企画しています。日常業務はコンテンツ企画、音声コンテンツの発注制作、品質管理、監修、イベントプロジェクト管理、まとめ報告に及び、いずれも多方面とのコミュニケーション・調整が必要です。Vivian さんは DingTalkドキュメントを活用することで、日常業務の効率と品質を確保しています。

## 一、コンテンツ特集を企画し、部門をまたぐ資料収集をシンプルかつ効率的に

音声コンテンツの制作は、Vivian さんの重要な業務の一つです。『覚醒年代』『トワイライト』などプラットフォームで人気のオーディオドラマ番組は、いずれも彼女の所属部門が主導して制作したものです。一つのコンテンツ特集の企画、制作からリリースまでには、部門をまたぐコラボレーションが必要となることが多くあります。IP の選定、件名コンテンツ、音声素材、作者情報、著作権情報、特集の文案などは、さまざまなチームに関わってきます。DingTalkドキュメントを活用することで、一つのドキュメント内に異なる部門から提供される情報を集約し、音声コンテンツの初期収集を効率的に完了できます。以前は、音声コンテンツ特集の制作からリリースまで通常 1 週間かかっていましたが、DingTalkドキュメントによるコラボレーションにより、現在は 2～3 日で完了できるようになりました。

DingTalkドキュメントで企画した特集『三生三世歩生蓮』がリリースされ、瞬く間にリスナーの人気ランキング上位に登場

## 二、リソース枠の申請を調整し、運営からのプロモーション要望を集約、コラボレーションとコミュニケーションの効率を向上

コンテンツ特集のリリースにはプロモーションが必要で、より多くのリスナーに特集を見てもらうため、社内でリソース枠を申請することになります。Ximalaya のアプリ内には、各種タイプのチャンネルページ、カルーセル画像、カードなどの運営枠があり、各チームが制作したコンテンツのプロモーションや露出に活用されています。運営担当者がリソース枠を申請する際には、申請部門、特集タイプ、リリース日、販売目標など複数の情報を集約する必要があり、リソース枠を管理する部門は DingTalkドキュメントを使って皆で共同作業を行います。情報収集後、コンテンツプロモーションのスケジュール調整だけでなく、運営担当者と具体的なリリース時間を同期し、リソース枠をオンにする必要があります。一つの DingTalkドキュメントで、部門をまたぐチーム間の高効率な双方向コラボレーションが実現できます。

1 枚のスプレッドシートで、運営リソース枠管理の双方向同期と効率的なコラボレーションを実現

## 三、人気 IP プロジェクトの管理、チームスペースでプロジェクトコンテンツを集約し、振り返りや閲覧を容易に

人気 IP シリーズの企画は、Ximalaya の重点コンテンツプロジェクトです。現在配信中の『高知能犯罪』『誰が犯人か』はいずれもチームが心を込めて制作した人気 IP コンテンツです。成功する IP プロジェクトをパッケージ化するには、版権、商務、マーケティング、運営、研究開発など、社内外の多方面とのコラボレーションが必要です。プロデューサー、すなわちプロジェクトの責任者として、Vivian さんは DingTalkドキュメントのチームスペースを活用し、異なる IP のナレッジベースを作成しました。チームスペース内では職能別にドキュメント素材、プロジェクト進捗、データレポートを集約し、プロジェクトメンバーがリアルタイムに閲覧、コラボレーション、共有できるようにしています。

複数の職能メンバーがコラボレーションし、リアルタイムでプロジェクトコンテンツを閲覧

## 四、週報のまとめを蓄積し、チームナレッジでメンバーの成長を促進

チームの週報、月報、年間まとめと計画について、Vivian さんは DingTalkドキュメントとチームスペースを活用して集約・蓄積しています。チームの各メンバーは上司の週報と月報を受け取ることもでき、上下間の情報統一を実現し、業務目標を明確化し、業務上で直面した問題と解決策を共有できます。新人メンバーは、チームメンバーがチームスペースに蓄積したまとめドキュメントを通じて、業務状況を素早く把握でき、業務への習熟難易度を下げ、チームへの溶け込みを加速できます。

業務まとめを蓄積し、チームナレッジでメンバーの成長をサポート

## 顧客紹介

画像出典：Ximalaya 公式サイト

Ximalaya はユーザーに愛されているオンライン音声共有プラットフォームであり、音声で人類の知恵を共有し、音声で豊かな生活をサポートし、家族みんなに一生の精神的糧を提供することに尽力しています。現在、Ximalaya は人気 IP からロングテールコンテンツまで全面的にカバーする健全でバランスの取れた活力あるエコシステムを構築し、オンライン音声サービスはユーザーの -1 歳から 100 歳まで、さまざまな年齢層に必要な豊富なコンテンツをカバーし、98 カテゴリーを含む 3.4 億本の音声コンテンツを蓄積しています。

Ximalaya は音声を特色とする「耳の経済」を推進し、2020 年にはアクティブなコンテンツクリエイターが 520 万人に達しました。「万物に音あり」の理念に基づき、Ximalaya は音声で数億のユーザーを接続・サポートし、国内初の全コンテンツインテリジェント AI スピーカー「小雅」などを発表し、音声による新たな伝播時代を切り開いています。同時に、Ximalaya はインテリジェントエコシステムの構築を強化し、自動車、スマートホーム、スマートスピーカー、ウェアラブルデバイスなどのハードウェア端末への展開を充実させ、音声と知識を水や電気のように遍在させ、いつでも利用できるようにしています。2021 年通年で、Ximalaya の全シーン平均月間アクティブユーザー数は 2.68 億人に達しました。

急速な事業成長により、Ximalaya はより多くの人材を引き続き採用しています。さらに巨大化する製品・研究開発業務ラインと拡大するチーム規模に対し、Ximalaya は DingTalkドキュメント を企業のコンテンツ作成プラットフォームとして選定し、プロダクト、研究開発、運営などの部門にもたらした新たな協働ワークスタイルにより、コンテンツ特集の制作の方向性を実効的に向上させました。
