**DingTalkプロジェクトマネージャーの智冀氏：** プロジェクトドキュメント管理の優れたツールをついに見つけました。情報がリアルタイムで同期され、フォーマットが統一されており、プロジェクト進行中にそのままプロジェクトドキュメントの蓄積が完了します。

## 背景

DingTalkのリリース・イテレーションは、毎回複数の業務ラインを横断するプロジェクトです。このプロセスにおいて、プロジェクトマネージャーは複数のチームのさまざまなロールとコミュニケーションを取り、最新の進捗を把握する必要があります。同時に、最新の進捗を全プロジェクトユーザーに即座に共有する必要もあります。プロジェクト完了後は、プロジェクト過程で発生したすべての関連プロセスドキュメントを統一的にアーカイブする必要があります。

## 課題

1.  各チームが多様なコンテンツを挿入するため、フォーマットや送信ツールが統一されず、情報の集約に時間と労力がかかります。

2.  さまざまなノートツールで分析・整理を試みましたが、PCとスマートフォンの両方に対応していないものや、複数人での共有権限設定に対応していないものがあります。

3.  プロジェクト完了後、ユーザーが送信したコンテンツとノート内のコンテンツを統一的にアーカイブ保存する必要があり、時間がかかる上に漏れが発生しやすいです。

## DingTalkナレッジベース導入後

*   プロジェクト開始時、プロジェクトマネージャーがテンプレートを使って事前にプロジェクトナレッジブックを作成し、ワンクリックでリンクをグループチャットに共有することで、迅速にコラボレーションを開始できます。

*   プロジェクト進行中、プロジェクトユーザーが権限に応じてそれぞれの役割を果たしながら同時に更新し、フォーマットが統一されているため、プロジェクトマネージャーが特別に整理・集約する必要がなく、タスクの進捗をリアルタイムでフィードバックできます。

*   プロジェクト完了後、ドキュメントは構造に沿って規範的にアーカイブされており、追加のアーカイブ整理は不要です。
