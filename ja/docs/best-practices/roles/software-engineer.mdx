**シニア開発者シンポン氏：** ナレッジベースは非常に俊敏なドキュメント管理ツールであり、開発・プロダクト間のコラボレーション効率を大幅に向上させ、開発中の知見をそのまま残すこともできます。

## 背景

開発プロセスにおいて、開発チームは毎日多くのタスクの進捗をフォローアップする必要があり、開発過程でプロダクトチームと継続的に擦り合わせる実行詳細もチームに公開する必要があります。典型的な技術課題を解決した際には、開発の知見を残し、他のチームメンバーに共有することも必要です。これらすべてには、多様なフォーマットに対応し、便利に使えるドキュメント管理ツールが欠かせません。

## 課題

1.  開発グループには毎日進捗を公開すべき多くのタスクがありますが、お知らせ機能ではスプレッドシートや動画などのコンテンツを挿入できず、使い勝手が良くありませんでした。

2.  開発過程でプロダクト設計と大量のコミュニケーションを行い、それらを実行可能なタスクに転換する必要がありますが、グループチャットのレコードはすぐに新しいチャット履歴に埋もれてしまい、検索が困難で、グループをまたいだ転送はさらに面倒です。

3.  開発過程での技術的な知見を蓄積する専用の場所が必要でしたが、保存場所が統一されておらず、新メンバーが加入するたびに各種権限を申請しなければならず非常に不便でした。また、チームメンバーの異動時にもアクセス権限の更新が遅れがちでした。

## DingTalkナレッジベース導入後

1.  ナレッジベースを使って毎日タスクリストを公開し、複数のフォーマットのコンテンツ挿入に対応、タスクの完了状況が一目瞭然です。

2.  詳細の擦り合わせ議論はナレッジベースに記録し、関連メンバーを@すると自動的に確認リマインドが送信されるため、チャット履歴を遡る必要がありません。

3.  開発の知見を一元的に記録し、日々蓄積することで、チームの知識の宝庫を構築。新メンバーがグループに参加すると自動で権限付与され、ワンステップで自己学習モードを開始できます。
