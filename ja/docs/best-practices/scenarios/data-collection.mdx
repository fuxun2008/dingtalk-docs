<Note>
日常業務では、多くのメンバーからデータを収集することがよくあり、最も一般的な方法はスプレッドシートを使うことです。データ収集を効率的に完了しつつ、データの安全性も確保するためには、次の2つの課題を考慮しなければなりません。

複数のメンバーから同時にデータを収集し、かつ完了状況をフォローするには、どうすればよいでしょうか。

データ収集時の不要なデータ漏洩を防ぐには、どうすればよいでしょうか。
</Note>

<Note>
**「スプレッドシート」を活用すれば、2つの強力な機能で「効率的なコラボレーション」と「データの安全性」を同時に実現でき、データ収集における効率と安全の課題を解決できます！**
</Note>

## — 01 複数ユーザーでのコラボレーションによるデータ送信 —

## 多彩なコンポーネントの挿入に対応し、さまざまなコラボレーションシーンのニーズに応えます

<Note>
        **私はプロダクト運営担当です**

       私たちは運営イベントを企画することが多く、イベントには多くの工程があり、さまざまな部門の同僚と連携して進める必要があります。スプレッドシートを使ってメンバーごとにタスクを割り振りますが、一人ひとりに送信して編集してもらうのは非常に手間がかかります。これが大きな悩みでした。どうすれば効率的にタスクを実行し、フィードバックを得られるでしょうか。
</Note>

以前は

現在は

<Note>
担当しているイベントプロジェクトでは、各部門の同僚が担当する業務を効率的に集約・共同編集・管理する必要があります。スプレッドシートを活用してプロジェクト管理プロセスを標準化し、業務が秩序立てて進み、期日通りに完了することを保証します。

⬇️ **おすすめ機能： @メンバー + チェックボックス + リンクを挿入 + 日付を挿入 + 条件付き書式のデータバー**

⬇️ **おすすめ機能：ドロップダウンリスト + 重複項目のハイライト**
</Note>

✅**タスクの割り当て、進捗の確認、スケジュール調整、ステータスの更新を、楽々フォロー**

✅**HRは「人材データベース」を構築でき、人材情報の重複登録を防ぎ、リアルタイムで担当者をアサインできます**

## — 02 データ収集の安全管理 —

## 重要なデータや機密データを簡単にロック

<Note>
**私は企業の経理担当です**

       私たちは毎月、企業の損益計算書やキャッシュフロー計算書などを含む財務報告書を作成する必要があり、いずれも重要なデータです。スプレッドシートを作成した後、データ漏洩を恐れて、他の人へ簡単に転送することができませんでした。しかし、その中には一部の社員に閲覧してもらう必要があるデータもあり、操作がとても煩雑で困っていました！
</Note>

以前は

現在は

<Note>
重要なデータの一部を限られた社員にだけ閲覧させたい場合は、**「ロック権限」** を活用して、ロールごとに異なる権限を設定できます。データを効率的に入力しつつ、データの安全性も確保できます！

⬇️ **編集権限のロック：重要なデータをロック設定し、指定したメンバーのみが編集可能**

⬇️ **閲覧権限のロック：機密データをロック設定し、その他のメンバーは閲覧不可**
</Note>

✅**フォーム編集者：社員ごとに異なるデータの閲覧権限を設定可能**

[添付ファイル《閲覧禁止.mp4》はDingTalkドキュメントでご確認ください。](https://docs.dingtalk.io/i/nodes/m0Xw6OYE4D7VLADMRKOlJRq13rbjgPM5?iframeQuery=anchorId%3DX02mfajzrd3599w3oqbhej)

✅**社員視点：一部のデータの閲覧・編集が可能**
