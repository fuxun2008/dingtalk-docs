ナレッジグループ作成後、グループユーザーの追加・削除や権限設定を行えます。ここでは空白グループを例に説明します。

## ユーザーの追加／削除方法

*   ユーザーの追加：グループユーザー管理リストで左上の「ユーザー追加」をクリックすると、<strong>連絡先、グループチャット、組織構造、一括インポート</strong>の 4 つの方法から選択して追加できます。現時点では組織内メンバーの追加のみに対応しており、組織外メンバーは追加できません。

*   **ユーザーの削除**：追加済みユーザーの操作列で **「削除」** をクリックすると、グループから削除できます。

## グループユーザーのロール権限について

グループユーザーのロールには、所有者、管理者、ユーザー、閲覧のみユーザー（ダウンロード可能）、閲覧のみユーザーがあり、それぞれの権限は以下のとおりです。

| ロールタイプ | グループ権限 |
| --- | --- |
| 所有者 | グループの引き継ぎ、管理、ホームページおよびナレッジベースの編集が可能 |
| 管理者 | 管理、ホームページおよびナレッジベースの編集が可能 |
| ユーザー | コンテンツの編集が可能 |
| 閲覧のみユーザー（ダウンロード可能） | コンテンツの閲覧／ダウンロードが可能 |
| 閲覧のみユーザー | 閲覧のみ可能、ダウンロード不可 |

## ナレッジベースの権限継承

グループ内のナレッジベースは、デフォルトでグループユーザーの権限を継承します。個別に権限を設定する場合は、ナレッジベースの **「ユーザーおよび権限」** で設定します。
