ナレッジグループを作成した後、グループユーザーを管理します。空のグループを例として、ユーザーの追加・削除が可能です。また、ユーザータイプの設定にも対応しており、各ユーザータイプには異なる権限が割り当てられます。

## ユーザーの追加／削除方法

*   ユーザーの追加：グループユーザー管理リストに入り、左上の「ユーザー追加」をクリックすると、**連絡先、グループチャット、組織構造、一括インポート**の4つの方法から選択して追加できます。ただし、現時点では組織内メンバーの追加のみに対応しており、組織外メンバーは追加できません。

*   ユーザーの削除：グループに追加済みのユーザーについて、操作の「削除」をクリックすることで、グループから削除できます。

## グループユーザーのロール権限について

グループユーザーのロールには、所有者、管理者、ユーザー、閲覧のみユーザー（ダウンロード可能）、閲覧のみユーザーがあり、それぞれの権限は以下のとおりです。

| ロールタイプ | グループ権限 |
| --- | --- |
| 所有者 | グループの引き継ぎ、管理、ホームページおよびナレッジベースの編集が可能 |
| 管理者 | 管理、ホームページおよびナレッジベースの編集が可能 |
| ユーザー | コンテンツの編集が可能 |
| 閲覧のみユーザー（ダウンロード可能） | コンテンツの閲覧／ダウンロードが可能 |
| 閲覧のみユーザー | 閲覧のみ可能、ダウンロード不可 |

## ナレッジベースはデフォルトでグループユーザーを継承

グループ内のナレッジベースは、デフォルトでグループユーザーの権限を継承します。グループ内のナレッジベースに個別に権限を設定する必要がある場合は、ナレッジベースの「ユーザーおよび権限」で設定する必要があります。
