---
title: "語雀ドキュメント各機能の復元効果について"
description: "語雀ドキュメントの各機能が DingTalk ナレッジグループでどう復元されるかの対応表。"
---

| 語雀ドキュメント機能 | 復元対応可否 | 表示名 |
| --- | --- | --- |
| **通常テキスト** | ✅ |  |
| **テキストスタイル** | ✅ |  |
| **テキスト書式** | ✅   太字 / 斜体 / 下線 / 取り消し線 / 上下付き文字 |  |
| **テキスト揃え** | ✅ |  |
| **文字の色** | ✅ |  |
| **箇条書き** | ✅ |  |
| **番号付きリスト** | ✅ |  |
| **タスクリスト** | ✅ |  |
| **タスク** | ✅ |  |
| **内部リンク** | ✅ |  |
| **外部リンク** | ✅ |  |
| **画像** | ✅ |  |
| **絵文字** | ✅ |  |
| **ドキュメント内スプレッドシート** | ✅ |  |
| **テーブル塗りつぶし色** | ✅ |  |
| **コードブロック** | ✅ |  |
| **コードスニペット** | ✅ |  |
| **レイアウト** | ✅ | 一部のレイアウトに変化が生じる場合があります |
| **参照** | ✅ |  |
| **区切り線** | ✅ |  |
| **ステータス** | ✅ 部分対応 | DingTalkドキュメントには該当機能がないため、コンテンツとスタイルはインポートできますが、語雀ドキュメントと同様の方法では変更できません。 |
| **折りたたみブロック** | ✅ 部分対応 | DingTalkドキュメントには該当機能がないため、非表示テキストは通常テキストに変換されます。 |
| **テキスト作図（plantUML、mermaid など）** | ✅ 部分対応 | DingTalkドキュメントは mermaid 作図のみに対応しているため、その他の作図（PlantUML など）をインポートするとエラーとなります。そのため、作図のソースコードと作図画像を別々にDingTalkドキュメントへインポートし、データの欠落を防いでいます。 |
| **DingTalk Mind** | ✅ 部分対応 | 画像に変換されます |
| **フローチャート** | ✅ 部分対応 | 画像に変換されます |
| **添付（リンクまたはカード）** | ✅ 部分対応 | リンクに変換されます |
| **数式** | ✅ 部分対応 | 画像に変換されます |
| **Youku / Bilibili などの埋め込み動画** | ✅ 部分対応 | リンクに変換されます |
| **@メンバー** | ✅ 部分対応 | テキストのみ表示され、ジャンプはできません |
| **データテーブル** | ❌ |  |
| **カレンダー** | ❌ |  |
| **暗号化テキストカード** | ❌ |  |
| **打刻** | ❌ |  |
| **投票** | ❌ |  |
