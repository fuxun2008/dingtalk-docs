<Note>
**DingTalkオンラインドキュメント内の添付ファイル（画像、動画、ファイルなど）は、2023年7月30日より正式に企業ストレージ容量として計算されます。容量の変動にご注意ください。**

容量の確認と容量拡張の購入手順については、以下の説明をご確認ください。
</Note>

## 一、DingTalkドキュメントの容量計算ルール

| ファイルタイプ | 利用行為 | 容量に計上するか |
| --- | --- | --- |
| ローカルファイル | DingTalkドキュメント内でファイルをアップロードします。ファイルタイプにはドキュメント、画像、音声・動画、圧縮ファイルなどが含まれます。 | 計上 |
| オンラインドキュメント | DingTalkドキュメント内でオンラインドキュメント（ドキュメント、スプレッドシート、マインドマップ、ホワイトボード）を作成またはインポートし、オンラインドキュメント内で編集する**挿入された添付ファイル（画像、音声・動画、圧縮ファイル、ローカルファイルを含む）**などのコンテンツ。 | **2023年7月30日**<br />**より正式に計上** |
| ショートカット | DingTalkドキュメント内でショートカットを追加します。 | 計上しない |

## 二、DingTalkドキュメントの容量計算範囲

**容量計算の対象には「マイドキュメント」と「ナレッジベース」が含まれます。**

*   <strong>マイドキュメント：</strong>企業から個人の知識管理のために割り当てられ、個人の業務知識の蓄積と管理に使用できます。

*   <strong>ナレッジベース：</strong>企業、部門、プロジェクトなどを主体として知識管理、共有、コラボレーションを行い、企業の知識の蓄積と管理に使用します。

## 三、ローカルファイルとオンラインドキュメントとは？

<strong>ローカルファイル：</strong>ローカルファイルをナレッジベースにアップロードしても、ファイル形式は変更されず、ファイルリンクを取得して共有できます。一部の形式はプレビューに対応しています。

<strong>オンラインドキュメント：</strong>オンラインドキュメントの作成とオンラインドキュメントのインポートの2種類があります。

*   オンラインドキュメントの作成：現在、DingTalkドキュメント、スプレッドシート、DingTalk Mindの3種類のドキュメントタイプの作成に対応しています。

*   オンラインドキュメントのインポート：一部のタイプのローカルファイルをナレッジベースにインポートすると、オンラインドキュメントに変換でき、ドキュメントリンクを取得して共有できます。また、DingTalkドキュメント形式に変換されます。インポート変換形式の説明：

| **ローカルファイルタイプ** | **オンラインファイルタイプ** |
| --- | --- |
| doc、docx、markdown、mark、md、txt | DingTalkドキュメント |
| xls、xlsx | スプレッドシート |
| xmind | DingTalk Mind |

## 四、現在アップロードおよびインポートに対応しているファイルタイプは何ですか？ファイルサイズに制限はありますか？

ファイルをアップロードする場合は複数のファイルタイプのプレビューに対応しており、1ファイルあたり最大8Gです。インポートはドキュメントタイプのみに対応しており、1ファイルあたり最大20Mです。具体的な違いは以下のとおりです：

| **転送方法** | **ファイルタイプ** | **プレビュー対応形式** | **サイズ制限** |
| --- | --- | --- | --- |
| アップロード | ドキュメント | pdf, pptx, ppt, pot, potx, pps, ppsx, dps, dpt, pptm, potm, ppsm, xls, xlt, et, ett, xlsx, xltx, xlsb, xlsm, xltm, csv, doc, dot, wps, wpt, docx, dotx, docm, dotm, txt、xmind | 1ファイルあたり最大8G |
|  | 画像 | peg、bmp、png、jpg、ico、webp |
|  | 音声・動画 | 3GP、AVI、FLV、MP4、M3U8、MPG、ASF、WMV、MKV、MOV、TS、WebM、MXF、AAC、AC-3、ADPCM、AMR、DSD、MP1、MP2、MP3、PCM、RealAudio、Windows Media Audio |
|  | その他 | zip圧縮ファイル |
| インポート | ドキュメント | docx, xlsx, doc, xls、txt、xmind、markdown、mark、md | 1ファイルあたり最大20M |

「アップロード」と「インポート」の詳細については、以下をご覧ください：

*   ナレッジベースはローカルファイルのアップロードに対応

*   DingTalkドキュメントナレッジベースの「アップロード」と「インポート」の違い

## 五、組織管理者はどこで容量使用明細を確認できますか？

OA管理画面 - ドキュメント・ストレージ管理 - ストレージスペースを開いてください（ログインアドレス：[https://oa.dingtalk.com/](https://oa.dingtalk.io/)）。

## 六、有料で容量を拡張するには？

DingTalkドキュメント（マイドキュメント、ナレッジベース）でローカルファイルをアップロードすると、企業ドライブの容量を消費します。オンラインドキュメント（ドキュメント、スプレッドシート、マインドマップ、ホワイトボード）で画像、音声・動画、圧縮ファイルを挿入すると、企業ドライブの容量を消費します。詳細は上記の第一点「DingTalkドキュメントの容量計算ルール」をご覧ください。

DingTalkは各組織にデフォルトで100GBの永久無料の企業ドライブ容量を提供しています。容量が不足した場合、組織は自身で購入できます。
