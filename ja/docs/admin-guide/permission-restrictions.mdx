## 一、なぜ権限の閲覧や共同編集者の追加ができないのですか？

*   ナレッジベース、フォルダー、単一ドキュメントファイルの管理者は、「誰が共同編集者を追加できるか」を設定できます（下図参照）。この設定の条件を満たさない場合、権限の閲覧や共同編集者の追加ができません。管理者にご連絡のうえ変更してください。

*   単一ドキュメント、ファイル、フォルダーの管理者は「権限管理 - 権限設定」で変更でき、ナレッジベースの管理者は「その他の設定 - 安全設定」で変更できます。詳しくは ドキュメント権限設定の説明 をご参照ください。

    # 二、なぜ外部ユーザーを追加できないのですか？

    外部ユーザーを追加できない場合、企業側での禁止、ナレッジベースでの禁止、フォルダーでの禁止、または単一ドキュメントファイルでの禁止が考えられます。具体的な原因については 誰がドキュメントを企業外に共有できるか をご参照ください。

    # 三、なぜコンテンツのコピー、副本の作成、印刷、ダウンロードなどができないのですか？

    #### 1）「権限設定」旧バージョン：

*   ナレッジベース、フォルダー、単一ドキュメントファイルの管理者は、「誰がコピー、ダウンロード、副本の作成、印刷を行えるか」を設定できます（下図参照）。この設定の条件を満たさない場合、コピー、副本の作成、副本の追加、印刷、ダウンロード、テンプレートとして保存など、コピー・ダウンロードに関連する操作ができません。管理者にご連絡のうえ変更してください。

*   単一ドキュメント、ファイル、フォルダーの管理者は「権限管理 - 権限設定」で変更でき、ナレッジベースの管理者は「その他の設定 - 安全設定」で変更できます。詳しくは ドキュメント権限設定の説明 をご参照ください。

    #### 2）「権限設定」新バージョン：

*   新バージョンでは、「誰がコピー、副本の作成、印刷を行えるか」の機能が「漏洩防止保護」へとアップグレードされます（下図参照）。ナレッジベース、フォルダー、単一ドキュメントで漏洩防止保護がオンになっている場合、具体的な漏洩防止保護の設定に基づき、一部のユーザーに対してコピー、副本の作成、副本の追加、印刷、ダウンロード、テンプレートとして保存など、コピー・ダウンロードに関連する操作が禁止されます。管理者にご連絡のうえ変更してください。

*   単一ドキュメント、ファイル、フォルダーの管理者は「権限管理 - 権限設定」で変更でき、ナレッジベースの管理者は「その他の設定 - 安全設定」で変更できます。詳しくは ドキュメントの「漏洩防止保護」とは？ をご参照ください。

    # 三、なぜドキュメントにコメントできないのですか？

*   ナレッジベース、フォルダー、単一ドキュメントファイルの管理者は、「誰がコメントできるか」を設定できます（下図参照）。この設定の条件を満たさない場合、ドキュメントにコメントできません。管理者にご連絡のうえ変更してください。

*   単一ドキュメント、ファイル、フォルダーの管理者は「権限管理 - 権限設定」で当該設定を変更でき、ナレッジベースの管理者は「その他の設定 - 安全設定」で当該設定を変更できます。詳しくは ドキュメント権限設定の説明 をご参照ください。
