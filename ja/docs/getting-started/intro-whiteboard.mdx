## 一、DingTalk Whiteboardクイックスタート

DingTalk Whiteboardは、リアルタイム編集に対応するオンラインコラボレーションホワイトボードです。無限に拡大縮小できるキャンバス上で、共同編集者全員が<strong>ペン、テキスト、図形、画像など</strong>多彩な要素を活用して共同制作できます。<strong>時間と空間の壁を打ち破り、アイデアを自由にぶつけ合いながら</strong>、思考からコンテンツ管理までのプロセスを簡単に完了でき、チームの<strong>「インスピレーション空間」</strong>を構築します。

### 豊富な要素で、無限の創造を

DingTalk Whiteboardに内蔵された「テンプレート」には豊富なテンプレートが用意されており、業界のベストプラクティスをワンクリックで再利用でき、チームの創造とコラボレーションの効率を高めます。また、ペン、テキスト、図形、画像、メモ、音声・動画などの豊富な要素により、あらゆるクリエイティブなアイデアをホワイトボード上に具体化できます。

### インスピレーションを刺激し、コラボレーションをボーダーレスに

DingTalk Whiteboardでは50名以上の同時オンラインコラボレーションに対応しています。共同編集者全員がここで思考し制作したり、コメントで提案したりでき、チームメンバーのコラボレーション効率と表現意欲を効果的に高めます。

### iPadに対応、ペーパーレスオフィスを実現

インスピレーションが湧いた瞬間、手元のiPadを取り出してスタイラスペンで記録すれば、図と文を組み合わせてアイデアを簡単に表現できます。マルチデバイスでデータが同期されるため、いつでもどこでもインスピレーションを記録でき、思いついたことを残せます。

### 「旧ホワイトボード」との違いは？

|  | **Before 旧ホワイトボード** | **After 新ホワイトボード** |
| --- | --- | --- |
| 1. **無限キャンバス** | キャンバスの背景が黒板に近く、ページ数は3ページまで。描画力や表現力に制限があります。 | 従来の「黒板」キャンバスを打ち破り、<strong>無限キャンバス</strong>で<strong>マルチ件名</strong>配色に対応。視覚効果がよりすっきりしています。 |
| 2. **柔軟な編集** | ペン、図形、テキストの3種類のベーシック編集機能のみで、創作能力が限定的です。 | 新ホワイトボードでは編集機能が拡充され、<strong>ペン、テキスト、図形、画像、メモ</strong>など多様なツールに対応。より柔軟に創作できます。 |
| 3. **豊富な要素** | 図形や線素材が限られ、色の選択肢も少なく、表現したい内容を生き生きと伝えられません。 | 線、図形、色の<strong>素材の種類がさらに豊富</strong>になり、<strong>洗練されたテンプレート</strong>もワンクリックで再利用可能。アイデアをより十分かつ生き生きと表現できます。 |
| 4. **複数ユーザーでのコラボレーション** | 同じキャンバス上で制作するだけで、インタラクションができません。 | 新ホワイトボードでは<strong>50名以上</strong>の同時オンラインコラボレーションに対応し、即座に<strong>コメントでのインタラクション</strong>が可能。意見交換がより便利になります。 |

### インスピレーション創作を始めるには？

**デスクトップ版の入口**：DingTalkを開き、左側のナビゲーションから「ドキュメント」に入り、「作成」をクリックして「ホワイトボード」を選択すれば作成完了です。

<strong>iPad版：</strong>DingTalkを開き<strong>、</strong>「その他」-「ドキュメント」をクリックし、下部の青い「+」から「ホワイトボード」を選択します。

## 二、DingTalk Whiteboardのベーシック操作

### 創作機能

要素を選択して編集：色、サイズ変更、移動、属性変更などが可能です。

キャンバスをドラッグして移動・拡大縮小できます。

ペンを挿入し、消しゴムと組み合わせれば、キャンバス上で自由に描画でき、線のサイズもドラッグで調整できます。

✅ メモや注釈の作成

✅ ディスカッション時の重要ポイントのマーク

✅ 楽しいコンテンツの描画

テキストボックスを挿入してテキストを入力でき、枠線、背景、フォントサイズ、色などを自由に設定できます。

豊富な図形を挿入できます。図形ライブラリにはベーシックな形状、数学記号、注釈、ボタンなど多彩なタイプが揃っており、フローチャート、業務アーキテクチャ図、マイルストーンなどのよく使うチャートを効率的に描画できます。

接続線を挿入してベーシックな図形間に関連を作成でき、異なる矢印スタイルに切り替え可能で、接続線のパスを精密に調整できます。

画像を挿入できます。画像サイズの柔軟な拡大縮小、塗りつぶし、枠線スタイルなどの操作に対応しています。

絵文字アイコンを挿入できます。重要な情報を強調するのに適しており、キャンバスのコンテンツをより生き生きと楽しいものにできます。

フレームを挿入できます。フレームは「ショット、画面」と理解できます。キャンバス要素を枠で囲んで「1フレーム」を形成し、プレゼンテーションモードでは各フレームがプレゼンテーションの1ページに対応します。

### コラボレーション機能

*   **リアルタイム共同編集**

50名以上の同時オンラインコラボレーションに対応しており、共同編集者全員がここで思考、創作、コメントでのインタラクションを行えます。ペン、テキスト、アイコンなどのツールでコンテンツをマークし、アイデアを表現できます。

*   **インタラクティブなコメント交流**

ビデオ会議でもオンラインディスカッションでも、1つのDingTalk Whiteboardを共有することで空間の制約を超え、会議室を追加のホワイトボードをオンラインに持ち込むことができます。メンバーは十分に交流でき、計画策定を迅速に進められ、コラボレーションをより効率的にします。

### 権限管理

他のタイプのDingTalkドキュメントと同様に、ホワイトボード右上の「…」-「権限管理」をクリックしてメンバー権限を設定できます。<strong>編集可、閲覧/ダウンロード可、閲覧のみ可、権限削除</strong>の4種類の権限タイプに対応しています。

### エクスポート・ダウンロード

ホワイトボード右上の「…」-「ローカルにダウンロード」をクリックすると、ホワイトボードのコンテンツを画像としてエクスポートできます。

### プレゼンテーション機能

*   右上の「プレゼンテーション」をクリックすると、キャンバス上のすべての「フレーム」が挿入順にプレゼンテーションされます。

*   順序を調整したい場合は、プレゼンテーションボタンの横にある矢印をクリックすると、プレゼンテーションのパスを確認でき、マウスのドラッグで変更できます。

## 三、利用シーン

### 1. 企業研修

DingTalk Whiteboardを使えば、いつでもどこでも企業研修やオンラインチームビルディングを始められます。境界がなくページ数に制限のないキャンバスに対応し、楽しいコンテンツ要素とインタラクション機能が内蔵されているため、パソコンの画面越しでもメンバーの参加意欲とアクティブ度を引き出せます。リアルタイムにコラボレーション・インタラクションでき、研修の楽しさを高めます。

### 2. ブレインストーミング

オンラインホワイトボードなら、生産性の高いブレインストーミングを簡単に開催でき、チームメンバーが発散的により多くのアイデアを生み出すことを促せます。複数ユーザーでのリアルタイムコラボレーションに対応し、インスピレーションをぶつけ合い、コメントでのインタラクションで即座に提案を発信でき、ブレストプロセスを整然と進められます。

3. **会議と計画ディスカッション**

新しいホワイトボードでオンライン会議が退屈ではなくなります。リアルタイムでコメントを投稿し計画の詳細について意見を発信でき、絵文字の追加にも対応しているため、ホワイトボードのコンテンツに姿勢と温度を持たせられます。計画を説明する際はワンクリックでプレゼンテーションでき、ホワイトボードが瞬時にPPTに変わります。ホワイトボードのコンテンツを生き生きと表示でき、参加者の注意を集中させ、計画の実現をより効率的に完了できます。

4. **社員引っ越し時の座席番号図**

会社の引っ越しで座席番号図が分からず自分の座席が見つからない、という時はどうしますか？DingTalk Whiteboardが簡単に解決します。DingTalk Whiteboardは複数ユーザーでのリアルタイムコラボレーション、多彩な線、背景色、メモなどの挿入に対応しているため、チームメンバーが一緒にオンラインでコラボレーションして座席レイアウト図を描けます。楽しく、そして生き生きと作成できます。

5. **タイムカプセル**

DingTalk Whiteboardは画像の挿入に対応しており、メンバーからのメッセージやチームの写真をホワイトボードに挿入して、忘れられない素晴らしい瞬間を記録できます。プレゼンテーションを開始すると、フレームごとにプレゼンテーションのパスとロジックをカスタムでき、静的なホワイトボードが瞬時に動的な動画に変わります。個人やチームのクリエイティブが動き出し、「紙上に躍動」します。
