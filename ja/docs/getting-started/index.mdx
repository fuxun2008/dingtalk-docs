*   プレゼンテーションモード、ドキュメントを瞬時にPPTに

*   オフィスアプリをワンクリックで接続

*   長い画像、動画をワンクリックで作成・共有

*   オープンリンクで、無限の表現を

*   セルコメントで、コミュニケーションをより集中的に

*   絞り込みビューで、互いに干渉せず作業可能
