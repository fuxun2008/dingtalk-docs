DingTalk ドキュメントスイートは 6 つのコラボレーションツールを備えています。用途に合ったものを選ぶか、すべて試してみましょう。

<CardGroup cols={2}>
  <Card title="DingTalk ドキュメント" icon="file-lines" href="/ja/docs/dingtalk-docs/insert-content/insert-whiteboard">
    スラッシュコマンド、AI による作成、プレゼンテーションモードで、コンテンツ協作をより効率的に。
  </Card>
  <Card title="スプレッドシート" icon="table-cells" href="/ja/docs/sheets/quickstart">
    安全で Excel 互換のオンラインスプレッドシート。400 以上の数式、ピボットテーブル、セル単位の権限。
  </Card>
  <Card title="AI テーブル" icon="table">
    スプレッドシート感覚で管理システムを構築——ガント・カレンダー・看板・アルバムをワンクリック生成。上部の **AI テーブル** タブから。
  </Card>
  <Card title="Mind" icon="diagram-project" href="/ja/docs/mind/quickstart">
    コラボレーション型のグラフィック思考——豊富な構造、ワンクリックアサイン、アウトライン⇄マインドマップ切替。
  </Card>
  <Card title="ナレッジベース" icon="book" href="/ja/docs/knowledge-base/about">
    ワンストップの企業ナレッジ管理。双方向参照、構造化された目次、充実した権限管理。
  </Card>
  <Card title="ホワイトボード" icon="chalkboard" href="/ja/docs/whiteboard/index">
    無限のキャンバスで複数人がリアルタイム協作。iPad 対応のペーパーレスオフィス。
  </Card>
