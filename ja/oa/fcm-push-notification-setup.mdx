---
title: "FCM プッシュ通知の設定ガイド"
description: "FCM を設定し、Firebase への登録と構成を通じて、海外の Android、iOS、Web デバイスで専用 DingTalk アプリのオフラインプッシュ通知を有効にします。"
---

FCM（Firebase Cloud Messaging）は、Android、iOS、Web プラットフォームに対応するクロスプラットフォームのメッセージングソリューションです。GCM（Google Cloud Messaging）の拡張版にあたります。

専用アプリで海外デバイスのオフラインプッシュ通知を受信したい場合は、FCM を申請し、必要な素材を提供してください。

---

## FCM を申請する

<Steps>
  <Step title="(1) Google Developer アカウントを申請する" />

  <Step title="(2) Firebase に登録する">
    Firebase でプロジェクトを作成し、アプリを登録します。登録 URL：[https://console.firebase.google.com/](https://console.firebase.google.com/)

    プロジェクトを作成した後、Android のアイコンを選択して Android アプリを設定します。

    <Frame>
      <img src="https://img.alicdn.com/imgextra/i2/O1CN01guJQUNGUwyJ4JFYZ_!!6000000004619-2-tps-2123-1256.png" alt="Firebase で Android アプリを設定する" />
    </Frame>

    <Note>
      ご注意ください：

      - **Android パッケージ名**：正しい専用 DingTalk のパッケージ名を入力します
      - **アプリのニックネーム（任意）**：専用 DingTalk のアプリ名を入力します
    </Note>

    <Frame>
      <img src="https://img.alicdn.com/imgextra/i4/O1CN014N2vWlWwdXL4TC7e_!!6000000005741-2-tps-2202-1256.png" alt="Android パッケージ名とアプリのニックネームを入力する" />
    </Frame>
  </Step>

  <Step title="(3) 設定ファイルをダウンロードし、DingTalk パッケージングプラットフォームにアップロードする">
    クリックして **google-services.json** をダウンロードします。ファイルを保存し、DingTalk テクニカルサポートに送信して設定してもらいます。

    <Frame>
      <img src="https://img.alicdn.com/imgextra/i4/O1CN01WTsNUs8mi5E4TC7e_!!6000000000771-2-tps-2202-1256.png" alt="google-services.json をダウンロードする" />
    </Frame>
  </Step>

  <Step title="(4) コンソールにアクセスして追加パラメーターを設定する">
    最後のステップに進み、コンソールに移動します。

    <Frame>
      <img src="https://img.alicdn.com/imgextra/i1/O1CN01eRtdR3nUVwD4TC7e_!!6000000003035-2-tps-2202-1256.png" alt="コンソールに移動する" />
    </Frame>
  </Step>

  <Step title="(5) サービスアカウントキーを作成する">
    **Project settings > Service accounts > Generate new private key** に移動します（下図参照）。

    <Frame>
      <img src="https://img.alicdn.com/imgextra/i2/O1CN01XyaTT4gI23E4JFYZ_!!6000000007143-2-tps-2123-1256.png" alt="Project settings、Service accounts、Generate new private key" />
    </Frame>

    <div style={{display: 'flex', gap: '12px', justifyContent: 'center', flexWrap: 'wrap', margin: '16px 0'}}>
      <img src="https://img.alicdn.com/imgextra/i3/O1CN01FvTOvlnxBfL4Cx4G_!!6000000003179-2-tps-2073-267.png" alt="秘密鍵の生成ダイアログ" style={{width: '48%', minWidth: '280px', borderRadius: '8px', boxShadow: '0 2px 12px rgba(0,0,0,0.08)', margin: 0}} />
      <img src="https://img.alicdn.com/imgextra/i1/O1CN01flqdzTN6gyB29JDC_!!6000000000826-2-tps-1059-419.png" alt="秘密鍵の生成を確認する" style={{width: '48%', minWidth: '280px', borderRadius: '8px', boxShadow: '0 2px 12px rgba(0,0,0,0.08)', margin: 0}} />
    </div>

    **Generate key** をクリックすると、JSON ファイルが自動的に生成されます。ファイルを保存し、DingTalk テクニカルサポートに送信します。

    <Frame>
      <img src="https://img.alicdn.com/imgextra/i3/O1CN017DaIO64VsrH3mOMe_!!6000000004888-2-tps-1862-550.png" alt="生成されたサービスアカウントキーの JSON ファイル" />
    </Frame>
  </Step>

  <Step title="(6) Realtime Database を作成する">
    **Create Database** をクリックします。

    <Frame>
      <img src="https://img.alicdn.com/imgextra/i1/O1CN01y5D2kVaat7H4IUjF_!!6000000003505-2-tps-2117-1256.png" alt="Create Database" />
    </Frame>

    <div style={{display: 'flex', gap: '12px', justifyContent: 'center', flexWrap: 'wrap', margin: '16px 0'}}>
      <img src="https://img.alicdn.com/imgextra/i4/O1CN01ZY57qv4yW1D29BSA_!!6000000003377-2-tps-1058-596.png" alt="Realtime Database のセットアップステップ" style={{width: '48%', minWidth: '280px', borderRadius: '8px', boxShadow: '0 2px 12px rgba(0,0,0,0.08)', margin: 0}} />
      <img src="https://img.alicdn.com/imgextra/i4/O1CN01LrHx3qI2SvJ2A49U_!!6000000003585-2-tps-1065-851.png" alt="Realtime Database のルール設定ステップ" style={{width: '48%', minWidth: '280px', borderRadius: '8px', boxShadow: '0 2px 12px rgba(0,0,0,0.08)', margin: 0}} />
    </div>

    **Enable** をクリックし、データベースの URL をコピーしてパッケージング素材とします。

    <Frame>
      <img src="https://img.alicdn.com/imgextra/i2/O1CN01kTvKb6jPuaB34xka_!!6000000005412-2-tps-1517-487.png" alt="データベースの URL をコピーする" />
    </Frame>
  </Step>

  <Step title="(7) 上記の素材を DingTalk に提供して設定してもらう">
    <Check>
      - google-services.json
      - サービスアカウントキーの JSON ファイル
      - Realtime Database の URL
    </Check>
  </Step>

  <Step title="(8) Firebase コンソールで FCM をテストする（任意）">
    <Note>
      **注意：このステップは任意です。**
    </Note>

    FCM を検証するには、Google プッシュサービスに対応したデバイス（Pixel デバイス推奨）を用意する必要があります。Firebase コンソールに移動し、**Messaging** を選択します。

    <Frame>
      <img src="https://img.alicdn.com/imgextra/i2/O1CN01ySABK2oxwGK1VHQE_!!6000000002684-2-tps-741-737.png" alt="Firebase コンソールで Messaging を選択する" />
    </Frame>

    画面の指示に従って順番にテスト通知を送信します。**重要：本番公開前にのみテストしてください。サービス障害を防ぐため、全ユーザーへの送信は避けてください。**

    <Frame>
      <img src="https://img.alicdn.com/imgextra/i2/O1CN01WiRJKFczodE4IcX8_!!6000000000978-2-tps-2118-1256.png" alt="テスト通知を送信する" />
    </Frame>

    送信後、デバイスがテスト通知を受信すれば、FCM の設定が成功したことを示します。

    <Frame>
      <img src="https://img.alicdn.com/imgextra/i4/O1CN01Wq3FA9W0RQC1Xfat_!!6000000004656-2-tps-760-291.png" alt="デバイスがテスト通知を受信する" />
    </Frame>
  </Step>
</Steps>
