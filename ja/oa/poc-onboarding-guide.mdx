本ガイドは、海外の新規顧客のプロジェクト責任者および組織管理者を対象に、公式サイトでのプラン選択、無料トライアルの申請、管理者登録、組織の作成から、管理コンソールへのログインと企業アカウントの一括インポートまでの一連のフローを説明します。

<Info>
  **対象読者**：DingTalk の企業 POC（概念実証）を推進するプロジェクト責任者、および最初の組織管理者。
</Info>

## フロー概要

<Steps>
  <Step title="公式サイトを開き、製品とプランを確認">DingTalk グローバル公式サイトを開き、Free / Basic / Standard / Premium の 4 つのプランを比較します。</Step>
  <Step title="無料トライアルを申請">適したプランを選び、30 日間の全機能無料トライアルを申請します。</Step>
  <Step title="最初の管理者を登録">新規登録し、本人確認を完了してパスワードを設定します。</Step>
  <Step title="企業組織を作成">組織情報を入力し、Org ID と Organization Code を記録します。</Step>
  <Step title="管理コンソールにログイン">管理コンソールに入り、組織の設定を行います。</Step>
  <Step title="部門構成を作成">テスト範囲に応じて部門を作成します。</Step>
  <Step title="企業アカウントを一括インポート">Excel テンプレートをダウンロードし、一括インポートして結果を抜き取り確認します。</Step>
</Steps>

---

## ステップ 1：公式サイトを開いてプランを選択

DingTalk グローバル公式サイトにアクセスします：[https://www.dingtalk.io/](https://www.dingtalk.io/)（日本語ページ：[https://www.dingtalk.io/](https://www.dingtalk.io/)）。

公式サイトでは 4 つのプランを提供しています。POC のユーザー数、業務シナリオ、セキュリティ要件、ストレージ需要、システム連携の範囲に応じて選択してください：

| プラン | 適したシーン |
|------|----------|
| **Free** | すぐに使える製品体験を提供 |
| **Basic** | スタートアップや小規模チーム向け。チャット、カレンダー、ドキュメントコラボレーションなどの基本機能を検証 |
| **Standard** | 成長企業向け。より強力なセキュリティポリシー、より大きなクラウドストレージ、サポートサービスを提供 |
| **Premium** | 中〜大規模組織向け。より高度な機能と大規模なチーム横断コラボレーションに対応 |

## ステップ 2：無料トライアルを申請

公式サイトで **無料トライアル（Start Free Trial）** をクリックします。すべてのプランで 30 日間の全機能無料トライアルを申請でき、クレジットカードは不要です。

<Tip>
  POC に Enterprise、データコンプライアンス、SSO、データリージョン、またはカスタム要件が含まれる場合は、**営業に問い合わせる（Contact Sales）** もクリックできます：[https://www.dingtalk.io/contact-sales/](https://www.dingtalk.io/zh/contact-sales/?from=%2F)
</Tip>

**申請前の準備：**

- 企業名と所在国・地域
- 予定される POC のユーザー数
- 予定開始時期とテスト期間
- 検証したい主な業務シナリオ
- スーパー管理者の氏名、メール、電話番号

<Note>
  **推奨する申請メモ**：DingTalk 企業 POC の申請、想定 XX 名、テスト期間 XX 日、組織管理・管理者ワークフロー・会議コラボレーション・従業員の一括開通を重点的に検証。
</Note>

## ステップ 3：管理者アカウントを登録

案内に従って、いずれかの方法で新規登録します：**有効なメール** / **Google アカウント** / **有効な電話番号と認証コード**。本人確認を完了し、パスワードを設定して、利用規約とプライバシーポリシーに同意します。

<Tip>
  企業 POC では、顧客の長期的に有効な業務用メールをスーパー管理者アカウントとして使用し、バックアップ管理者も設定することをおすすめします。
</Tip>

## ステップ 4：企業組織を作成

対象プランを選択し、案内に従って無料トライアルまたはサブスクリプションのフローを完了します。組織を作成する際は、以下の情報を準備してください：

| 項目 | 入力の目安 |
|------|----------|
| Organization Name | 企業の正式な英語名を使用し、個人名や一時的なプロジェクト名は避ける |
| Country / Region | 企業の主な運営地域または POC の所在地域を選択 |
| Industry / Organization Size | 実際の業種と想定従業員規模を入力 |
| Super Admin | 確認済みの管理者メールまたは電話番号を使用 |
| Org ID | 作成後にシステムが割り当てる組織固有の識別子を保存 |
| Organization Code | 企業アカウントでのログイン時に組織を特定するために使用。Org ID とは別に記録する |

<Warning>
  組織の作成後は、必ず **Org ID** を保存してください。企業アカウントでのログインに必要な **Organization Code** は、管理者が **Security and Permission → Organization code login** で確認できます。
</Warning>

会社チームを選択し、**Get Started** をクリックします：

## ステップ 5：管理コンソールにログイン

管理者は次の URL にアクセスします：[https://oa.dingtalk.io/](https://oa.dingtalk.io/)

案内に従って組織情報を入力し、ログイン方法を選択します：

- 登録済みメールまたは電話番号 + パスワード
- 電話番号 + 認証コード
- モバイル版 DingTalk で QR コードをスキャン
- 企業アカウント + Organization Code + パスワード
- 連携済みのサードパーティアカウント

DingTalk クライアントから入ることもできます：**プロフィール写真 → 管理コンソール**、または **連絡先 → 組織名 → 管理**。

<Note>
  アカウントが複数の組織に所属している場合は、今回の POC に対応する組織に入っていることを確認してください。
</Note>

## ステップ 6：部門構成を作成

管理コンソールで連絡先を開き、POC に必要な部門構成を作成します：

**管理コンソール → 連絡先（Contacts）→ 部門管理 → 部門を追加**

<Tip>
  まず第一階層の部門を作成し、次にテスト範囲に応じて必要な第二階層の部門を作成します。部門名は顧客の現在の組織構成と一致させてください。
</Tip>

## ステップ 7：Excel で企業アカウントを一括インポート

**操作パス**：管理コンソール（Admin Console）→ 連絡先（Contacts）→ メンバー（Members）→ 一括編集（Batch Edit）→ 一括インポート（Bulk Import）

<Steps>
  <Step title="テンプレートをダウンロード">**テンプレートをダウンロード（Download Template）** をクリックし、現在の組織からダウンロードした Excel 標準テンプレートを使用します。</Step>
  <Step title="従業員情報を入力">テンプレートの先頭行の例と入力説明を参考に、従業員情報を入力します。アップロード前に先頭行の例データを削除します。</Step>
  <Step title="テンプレート構造を維持">列名、列の順序、ワークシート構造、ファイルタイプを変更しないでください。</Step>
  <Step title="ファイルをアップロード">インポートページに戻り、**ファイルをアップロード（Upload File）** をクリックして、入力済みの Excel ファイルを選択し、**インポート（Import）** をクリックします。</Step>
  <Step title="結果を抜き取り確認">インポート完了後、メンバー一覧を部門・氏名・メール・電話番号で抜き取り確認します。</Step>
</Steps>

<Tip>
  まず 3〜5 名の管理者とテストユーザーをインポートすることをおすすめします。アカウント、部門への所属、ログインがすべて正常であることを確認してから、残りの POC ユーザーをインポートします。
</Tip>

## インポートの問題への対処

アップロードまたはインポートに失敗した場合：

<AccordionGroup>
  <Accordion title="従業員レコードを確認">画面のエラーメッセージに従って、該当する従業員レコードを確認します。</Accordion>
  <Accordion title="項目と形式を確認">必須項目と形式がテンプレートの説明に合っているか確認します。</Accordion>
  <Accordion title="テンプレート構造を確認">テンプレートの列名、列の順序、ワークシート構造を変更していないか確認します。</Accordion>
  <Accordion title="修正して再試行">誤ったレコードを修正して、もう一度アップロードします。</Accordion>
  <Accordion title="ページの異常に対処">ページの動作がおかしい場合は、ページを更新するか、再度ログインするか、最新版の Google Chrome で再試行します。</Accordion>
</AccordionGroup>

## POC 受け入れチェックリスト

<Check>以下のステップが完了したら、DingTalk 企業 POC の業務シナリオの設定とテストを開始できます。</Check>

- [ ] 対象プラン、地域、ユーザー数、トライアル期間が確認済み
- [ ] スーパー管理者が DingTalk クライアントと管理コンソールの両方にログインできる
- [ ] 企業名、地域、タイムゾーン、管理者情報が正確
- [ ] POC に必要な部門構成が作成済み
- [ ] テストアカウントが Excel で正常にインポートされ、正しい部門に割り当て済み
- [ ] 異なるロールのテストユーザーが 3 名以上、初回ログインを完了
- [ ] インポートエラーが修正またはクローズ済み
