# ファイル編集ロックとは？

*   ユーザーがDingTalkドライブのローカル同期フォルダー内でファイルの編集を開始すると、そのファイルはロックされます。
    
*   ロックされたファイルは、他のデバイス上の他のユーザーが編集できないため、バージョン競合を防ぎ、バージョン管理の手間を軽減します。
    
*   ユーザーがファイルを閉じると、ロックは自動的に解除され、他のユーザーがファイルを開いて編集できるようになります。
