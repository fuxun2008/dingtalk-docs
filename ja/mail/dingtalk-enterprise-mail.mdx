description: "DingTalk エンタープライズメールは、無制限ストレージ・大容量処理に対応したDingTalkネイティブのメールサービス。管理機能からユーザーのコラボレーション機能まで充実した機能を解説します。"
---

DingTalk エンタープライズメールは、DingTalk上に構築されたネイティブの法人向けメール製品です。コラボレーティブなオフィススイートの一部として多くのDingTalkアプリと連携し、ユーザーがより効率的に業務を進められるよう支援します。

DingTalk エンタープライズメールは、安全で高性能、かつ高い安定性を備えたメールインフラを提供します。大容量処理、負荷分散、動的なリソーススケジューリングとスケーリング、複数コピーによる冗長データストレージを念頭に設計されています。

| **ユーザー機能** |  |
| AIアシスタント | 招待制のみ |
| dingtalk.io メールボックスデータのワンクリック移行 | 個人のdingtalk.ioメールボックスから過去のメールをワンクリックで移行できます。今後受信するメールもDingTalk エンタープライズメールに同期できます。 |
| DingTalk メールアシスタント | DingTalk メールアシスタントを通じて、複数のメールボックスの新着メール通知をDingTalkのメッセージで受け取れるため、DingTalk上でメールを見逃しません。設定では、どのアカウントでメール通知を受け取るかをカスタマイズすることもできます。 |
| パスワード不要のメールボックスログイン | 管理者がアカウントを割り当てた後、従業員はDingTalkにサインインするだけでメールボックスを利用でき、より安全かつ便利にアクセスできます。 |
| メールとカレンダーの同期 | DingTalk カレンダーを通じて会議招待を送信でき、スケジュールと会議を一か所にまとめられます。 |
| DING で未読の受信者に通知 | 受信者がメールを既読にしたかどうかを確認し、未読の受信者にDINGリマインダーを送信できるため、重要な情報を見逃しません。 |
| DingTalkグループへのメール送信 | 組織内のグループにグルチャ・メーリングリストを作成し、ワンクリックでグループメールを送信できます。 |
| IMからのメール送信 | DingTalkのチャットウィンドウから連絡先に直接メールを作成できます。 |
| チャットへ転送 | メールをDingTalkのチャットに転送できます。 |
| DingTalk タスクとして設定 | メールをタスクとして設定し、重要な案件をリアルタイムでフォローアップできます。 |
| DingTalk 会議を開始 | メールからワンクリックで会議招待を開始できます。 |
| メール設定 | ログインログ、送信・受信・削除操作の検索、新着メール通知、署名、休暇中の自動返信、受信ルール、セルフサービス転送、ホワイトリスト／ブロックリスト、迷惑メール対策、メール閲覧などを含みます。 |
| 他のメールボックスからの送受信 | 他のメールアカウントを追加し、DingTalk エンタープライズメールから送受信を管理できます。 |
| 本文のショートカット機能 | DingTalk エンタープライズメールは、@、-p、-d などのよく使われるテキストショートカットに対応しています。メール本文では、@で誰かをメンションしたり、@と-pまたは-dを組み合わせて部門の同僚にすばやくメールを送れます。 |
| 機密モード | メールと添付ファイルを機密モードで送信し、機密情報を保護できます。メールの透かし、メールの有効期限、有効期限後のコンテンツ閲覧不可、転送・コピー・ダウンロードの制限などの機能を備えています。 |
| メール送信取消 | 誤って送信したメールを簡単に取り消せます。 |
| 個別表示での一斉送信 | 一斉メールを送信する際、各受信者には個別のメールが届くため、よりパーソナルな印象を与え、受信者のメールアドレスを保護できます。 |
| 会話モード | 件名ごとにメールをまとめ、関連するメールのやり取りを1つの会話として表示する閲覧モードです。 |
| 迷惑メールの疑いに関するリマインダー | システムは、傍受した迷惑メールについて毎日リマインダーを送信し、重要なメールの見逃しを防ぎます。ユーザーは必要に応じてこのリマインダーを有効または無効にできます。 |
| メールラベル | メールに複数のカテゴリラベルを追加し、個別に分類・管理できます。ユーザーはいつでも同じラベルが付いたすべてのメールを確認できます。 |
