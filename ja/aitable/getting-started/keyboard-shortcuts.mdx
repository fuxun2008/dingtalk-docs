AI テーブルでは、キーボードショートカットでさまざまな操作を素早く行えます。

| 操作            | Windows                            | Mac OS                          |
| ------------- | ---------------------------------- | ------------------------------- |
| **AI テーブルアシスタント** を開く      | `Ctrl` + `/`                   | `⌘` + `/`                   |
| 元に戻す            | `Ctrl` + `Z`                   | `⌘` + `Z`                   |
| やり直し            | `Ctrl` + `Shift` + `Z`       | `⌘` + `Shift` + `Z`       |
| 切り取り            | `Ctrl` + `X`                   | `⌘` + `X`                   |
| セル内容の削除       | `Del`                            | `Del`                         |
| 上下左右に複数セルを選択 | `Shift` + `↑/↓/←/→`            | `Shift` + `↑/↓/←/→`         |
| テーブルの端までスクロールしてセルを選択 | `Ctrl` + `Shift` + `↑/↓/←/→` | `⌘` + `Shift` + `↑/↓/←/→` |
| 下にレコードを追加        | `Shift` + `Enter`              | `Shift` + `Enter`           |
| すべて選択            | `Ctrl` + `A`                   | `⌘` + `A`                   |
| コメント            | `Ctrl` + `Shift` + `M`       | `⌘` + `Shift` + `M`       |
| ビュー設定を保存        | `Ctrl` + `S`                   | `⌘` + `S`                   |
| 検索            | `Ctrl` + `F`                   | `⌘` + `F`                   |
| テキストセルを展開       | `Shift` + `Space`              | `Shift` + `Space`           |
| サイドバーでレコード詳細を展開     | `Space`                          | `Space`                       |
| サイドバーのレコード詳細を閉じる     | `Esc`                            | `Esc`                         |
| ビューの最下部までスクロール       | `Ctrl` + `↓`                   | `⌘` + `↓`                   |
| ビューの最上部までスクロール       | `Ctrl` + `↑`                   | `⌘` + `↑`                   |
| レコード詳細で前のレコードへ切り替え   | `Ctrl` + `Shift` + `↑`       | `⌘` + `Shift` + `↑`       |
| レコード詳細で次のレコードに切り替え   | `Ctrl` + `Shift` + `↓`       | `⌘` + `Shift` + `↓`       |
| 左サイドバーの非表示／展開     | `Ctrl` + `\\`                  | `⌘` + `\\`                  |
| 縦スクロール          | `マウスホイール`                           | `マウスホイール`                        |
| 横スクロール          | `Shift` + `マウスホイール`               | `Shift` + `マウスホイール`            |
