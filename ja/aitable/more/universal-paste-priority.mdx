## Universal Paste とは

ひと言で言えば、クリップボードにあるものは何でも、AI Table に貼り付けてみてください。設定画面は不要です。空白のデータテーブルを作成して貼り付けるだけ。テーブルデータとして認識できるものは、そのまま取り込まれます。追加の操作は一切ありません。

> 注：Universal Paste はデスクトップ版限定です。

## 利用シーン

### AI Table に画像を貼り付ける

Excel のスクリーンショット、紙の帳票の写真、オンラインデータのスクリーンショット、BI レポート、ダッシュボードのキオスク表示、PDF、PPT スライドなどからデータを取り出し、チャートや分析のためにテーブルへ戻す作業はよくあるものです。

これまで：4×10 のテーブルのスクリーンショットには、10 分に加えて繰り返しの校正が必要でした。

これから：スクリーンショット → AI Table に `Ctrl` + `V` → 完了。

例：

テーブルのスクリーンショットをコピーします →

AI Table に貼り付ければ完了です。

### AI Table にテキストを貼り付ける

営業、人事、運用の担当者は、構造化されたテキスト（登録情報、顧客リスト、イベントのフィードバック、商品リストなど）を受け取り、分析のためにテーブルへ整える作業をよく行います。数百行ともなれば、この作業は手間がかかりミスも生じやすく、項目が漏れたり列がずれたりします。

これから：テキストを `Ctrl` + `C` → AI Table に `Ctrl` + `V` → 完了。

例：

テキストのまとまりを選択してコピーします。ここでは大学のリストです →

AI Table に貼り付ければ完了です。
