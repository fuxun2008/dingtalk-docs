## 機能概要

スクリプトプラグインは AI テーブルが提供するオープン機能の一つです。開発者は JS スクリプトを記述してカスタムスクリプトプラグインを構築し、テーブルのコラボレーターと共有して利用できます。
スクリプトプラグインはテーブルのデータと連携でき、複雑な業務ロジックを実現できます。AI テーブルのカスタムプラグインと比べ、スクリプト開発時はページ開発やデプロイが不要で、AI テーブルの右側サイドバーでスクリプトの編集・実行・公開ができます。組み込み API を使ってシンプルなプラグインのインタラクションパネルを構築できます。

## スクリプトプラグインを使う

DingTalk はよく使われるスクリプトプラグインをいくつか提供し、さまざまなシーンのニーズを満たすとともに、開発者の参考例として利用できます。

## 最後にプラグインの利用権限について

自分が開発したスクリプトプラグインを公開した後、現在の AI テーブルで以下の条件を満たすユーザーがスクリプトプラグインを閲覧・利用できます。

1. 高度な権限を有効にしていない場合、編集権限または管理権限を持つユーザーがプラグインを利用できます。
2. 高度な権限を有効にしている場合、データテーブルの管理権限を持つユーザーのみがプラグインを利用できます。

## FAQ

**Q：カスタムプラグインとの違いは何ですか？**

**A：** コピーは可能ですが、タイトル、テキスト、色のみがコピーされ、自動化設定はコピーされません。
