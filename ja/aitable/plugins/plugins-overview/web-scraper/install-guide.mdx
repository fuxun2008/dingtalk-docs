#### ステップ 2：ブラウザの拡張機能としてインストール

Chrome ブラウザにインストール：

| インストール手順                                                                                             | Chrome ブラウザ                                                              |
| ------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------- |
| 1. Chrome ブラウザを開き、`chrome://extensions/` をアドレスバーにコピーして Enter で拡張機能管理ページを開きます。**または**「拡張機能」ボタンをクリックして拡張機能管理ページを開きます。 | ![](/ja/aitable/plugins/plugins-overview/web-scraper/install-guide/images/image_D6wd-vw3G7.png)  ![](/ja/aitable/plugins/plugins-overview/web-scraper/install-guide/images/image_HM7QdxfzED.png) |
| 1. ページ右上の「デベロッパーモード」を有効にします。                                                                              | ![](/ja/aitable/plugins/plugins-overview/web-scraper/install-guide/images/image_PFBTQS5VuR.png)                                     |
| 1. **解凍済みの** Fusion フォルダを Chrome 拡張機能の画面にドラッグします。                                                         | ![](/ja/aitable/plugins/plugins-overview/web-scraper/install-guide/images/image_tImcl3ffLp.png)                                     |
| 1. 追加された Fusion プラグインを見つけ、**有効化を確認**します。                                                                  | ![](/ja/aitable/plugins/plugins-overview/web-scraper/install-guide/images/image_hYt8VkvZM1.png)                                     |
| 1. インストール成功後、AI テーブルを**更新**し、プラグインサイドバーを開いて、検索またはプラグインセンターから「Web ページ収集アシスタント」プラグインを開きます。初回の収集指示時に DingTalk アカウントでログインすると利用できます。              | ![](/ja/aitable/plugins/plugins-overview/web-scraper/install-guide/images/image_aFJgMIMhpo.png)  ![](/ja/aitable/plugins/plugins-overview/web-scraper/install-guide/images/image_z2vZ0D-f2f.png) |

Edge ブラウザにインストール：

| インストール手順                                        | Edge ブラウザ                                                                |
| ------------------------------------------- | ---------------------------------------------------------------------- |
| 1. Edge ブラウザを開き、右上のアイコンをクリックして「拡張機能」を選択します。               | ![](/ja/aitable/plugins/plugins-overview/web-scraper/install-guide/images/image_eyOw1ML8OX.png)                                     |
| 1. 「拡張機能の管理」をクリックします。                              | ![](/ja/aitable/plugins/plugins-overview/web-scraper/install-guide/images/image_9r-72RzILW.png)                                    |
| 1. 拡張機能管理ページに入り、「開発者モード」を有効化します。                     | ![](/ja/aitable/plugins/plugins-overview/web-scraper/install-guide/images/image_0mB0NeNL1q.png)                                     |
| 1. 解凍済みの Fusion **フォルダ**をブラウザウィンドウにドラッグします。           | ![](/ja/aitable/plugins/plugins-overview/web-scraper/install-guide/images/image_hfIflMZD-4.png)                                     |
| 1. ブラウザの拡張機能ボタンのポップアップで「Fusion」をクリックし、Fusion サイドバー画面を呼び出します。 | ![](/ja/aitable/plugins/plugins-overview/web-scraper/install-guide/images/image_C9ELxygGJA.png)                                     |
| 1. DingTalk でログインし、ログイン後 AI テーブルに戻って「Web ページ収集アシスタント」を有効化できます。         | ![](/ja/aitable/plugins/plugins-overview/web-scraper/install-guide/images/image_4EaoyzmAmD.png)  ![](/ja/aitable/plugins/plugins-overview/web-scraper/install-guide/images/image_z2vZ0D-f2f.png) |
