## 概要

組織管理者は、AI Table プラグインセンターの**サードパーティプラグイン権限**を設定できます。これをオンにすると、AI Table の管理者と編集者は、幅広い業務シナリオでプラグインセンターのサードパーティプラグインを利用できます。

## 権限をオンにする

管理コンソール（[https://oa.dingtalk.io/](https://oa.dingtalk.io/ "https://oa.dingtalk.io/")）にログインし、**ドキュメント・ストレージ管理 > 権限・安全 > 権限設定**に移動します。**編集**をクリックし、**AI Table プラグイン権限を有効化**にチェックを入れて保存します。

有効化すると、組織のメンバーは AI Table プラグインセンターでサードパーティプラグインを利用できます。サードパーティプラグインは、サーバーサイド API を通じて AI Table のデータを読み書きできます。
