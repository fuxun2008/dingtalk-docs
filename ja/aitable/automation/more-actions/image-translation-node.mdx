## 機能概要

商品画像をアップロードすると、自動化の画像翻訳ノードがレイアウトを維持したまま対象言語の画像を自動生成します。現在対応している言語は、簡体字中国語、繁体字中国語、英語、日本語、韓国語、マレー語、アラビア語です。

## このノードで作業フローを構築する

1. **自動化エディタを開く**

   トリガー：テーブルに画像が追加されたとき → 操作 **画像翻訳**（サードパーティの Aidge により提供 — 1000 回の無料トライアルが利用可能）→ レコードを元の行に更新します。

2. **画像翻訳ノードを追加した後、以下の手順で認証情報を取得します**
   - **Aidge ログインエントリ**
     - Web：[https://www.aidc-ai.com/](https://www.aidc-ai.com/ "https://www.aidc-ai.com/")
   - **Web のサインアップ／ログインの流れ：**
     - 上記の URL を開き、**Sign in** をクリックします。
   - **認証情報の取得と使用**
     - ログイン後、ホームページで **Try now** をクリックするか、右上のアバターをクリックしてコンソールを開きます。

     - 左側の **Assets** → **API Key** をクリックして、アカウント名とキーを取得します。API Key はこのアカウントの永続的な認証情報で、API を呼び出すために使用します。

- **自動化エディタに戻り、認証情報を入力して呼び出す商品を選択します**
  - 認証情報の名前：任意の名前
  - 名前：Aidge の API キー名
  - キー：Aidge の API キーシークレット

## 無料トライアルのクォータと使用状況

- すべてのユーザーは登録時に 1000 回の無料トライアル呼び出しを取得できます。コネクタを使用する際は、トライアルクォータと有料クォータのどちらを使用するかを選択します。クォータタイプは認証情報を入力する際に選択します。トライアル用と有料用にそれぞれ 1 つずつ認証情報を作成することをおすすめします。

- トライアルクォータと残高は Aidge コンソールで確認できます。左側のナビゲーションで **Usage** を開くと、無料 API の使用状況の詳細を確認できます。

- トライアルクォータを使い切った場合は、商品ごとに有料クォータを購入します。ホームページで **Pricing** をクリックすると、API ごとの価格を確認できます。

- 有料クォータと残高は同じ **Usage** ページで確認できます。
