## 利用効果

ユーザーが商品画像をアップロードすると、自動化ワークフロー内の画像翻訳ノードが自動的にトリガーされ、レイアウトが一致した目的言語の画像を生成できます。現在対応している言語：中国語、中国語（繁体字）、英語、日本語、韓国語、マレー語、アラビア語。

すぐに使えるテンプレート：[https://store.dingtalk.io/materials/1346](https://store.dingtalk.io/materials/1346 "https://store.dingtalk.io/materials/1346")

## このノードを使った自動化ワークフローの構築方法

1. **自動化ワークフロー構築フローに入る**

   テーブル内に画像が追加された際にすぐ実行する「画像翻訳」（サードパーティ Aidge 提供、現在 1000 回まで無料試用可能）アクションを選択し、最初のステップでトリガーされたフローにレコードを更新します。

   ![](/ja/aitable/automation/more-actions/image-translation-node/images/image_sHWgiwhzM-.png)
2. **画像翻訳ノードを追加後、以下の方法で認証情報を取得します**
   - **Aidge ログイン入口**
     - Web 版アドレス：[https://www.aidc-ai.com/](https://www.aidc-ai.com/ "https://www.aidc-ai.com/")
   - **Web 版の登録／ログインフロー：**
     - 上記 Web アドレスに進み、「ログイン」をクリックします。
       ![](/ja/aitable/automation/more-actions/image-translation-node/images/image_xP1YPVNE8h.png)
   - **認証情報の取得と利用**
     - Aidge プラットフォームのアカウントにログイン後、トップページの「すぐに試す」をクリックするか、右上のユーザーロゴをクリックしてコンソールに入ります。
       ![](/ja/aitable/automation/more-actions/image-translation-node/images/image%20(86)_cWnE5NfDxN.png)
     ![](/ja/aitable/automation/more-actions/image-translation-node/images/image%20(87)_G9AuI5diq-.png)
     - 左側の「資産」をクリックし、「API Key」をクリックすると、そのアカウントの名称と秘密鍵を取得できます。API Key はアカウントの永続的な認証情報で、API 呼び出しに使用できます。
       ![](/ja/aitable/automation/more-actions/image-translation-node/images/image%20(88)_Sqxxa2JuKI.png)

- **自動化フロー設定ページに戻り、認証情報を設定する際に呼び出し可能な製品を入力します**
  - 認証情報の名称：ユーザー任意
  - 名称：Aidge 公式サイトの API key 名称
  - 秘密鍵：Aidge 公式サイトの API key 秘密鍵
    ![](/ja/aitable/automation/more-actions/image-translation-node/images/image%20(89)_DNDaa-X_qL.png)

## 無料試用枠と利用量の確認

- すべてのユーザーは登録後、デフォルトで 1000 回の無料試用が付与されます。コネクタ使用時には、試用枠と正式枠のどちらを使用するかを選択できます。認証情報を登録する際に利用枠タイプ（試用／有料）を選び、無料用と有料用でそれぞれ認証情報を作成することをおすすめします。

  ![](/ja/aitable/automation/more-actions/image-translation-node/images/image%20(90)_73BoYOOn4k.png)
- 公式サイトで無料試用の利用量と残高を確認できます。コントロールセンターの左側「利用量」を開くと、すべての無料 API の利用状況を確認できます。

  ![](/ja/aitable/automation/more-actions/image-translation-node/images/image%20(91)_HuIkJ23n9k.png)
- 試用枠を使い切った場合、各製品の有料枠を購入できます。トップページの「製品料金」をクリックすると、各 API 製品の料金が確認できます。

  ![](/ja/aitable/automation/more-actions/image-translation-node/images/image%20(93)_NDSa-mF5UX.png)
- 公式サイトで有料利用量と残高を確認できます。コントロールセンターの左側「利用量」を開くと、すべての有料 API の利用状況を確認できます。
