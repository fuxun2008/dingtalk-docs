免責事項：本機能は以下のサードパーティ製ワークフローとの連携機能のみを提供します。DingTalk はそのサービスの安定性、データセキュリティおよび結果の正確性を保証しません。利用にともなうリスクと責任はユーザー自身が負うため、十分にご評価のうえご利用ください。

**本マニュアルはノーコードで、開発者でなくてもすぐに利用を開始できます：**

## 利用前の準備：**Feishu の App ID と App Secret を取得**

![](/ja/aitable/automation/more-actions/feishu-node/images/image_nY1PwQWXVm.png)

1. [**Feishu でカスタムアプリを作成**](https://open.feishu.cn/app "Feishu でカスタムアプリを作成")**し、App ID と App Secret を取得**します。

   ![](/ja/aitable/automation/more-actions/feishu-node/images/f25e9a4d-f7b3-4797-81e2-46a90b0da11f_yO9TQqAyxR.png)
2. **カスタムアプリに対応するフィールド権限が付与されていることを確認**します。

   たとえば [子部門リスト取得](https://open.feishu.cn/document/server-docs/contact-v3/department/children "子部門リスト取得") API を呼び出す場合、対応する連絡先関連 API の権限を有効化する必要があります。

   ![](/ja/aitable/automation/more-actions/feishu-node/images/a11a22fb-ceea-4f2b-9a13-d59bfce7c37b_lDtz7z3uRE.png)
3.  **カスタムアプリの API 権限を申請**（[**企業向けカスタムアプリの API 権限申請**](https://open.feishu.cn/document/server-docs/application-scope/introduction?lang=zh-CN "企業向けカスタムアプリの API 権限申請")）
   1. [開発者ポータル](https://open.feishu.cn/app "開発者ポータル")にログインし、対象のカスタムアプリに移動します。
   2. 左側ナビゲーションから 開発設定 > 権限管理 ページに進み、権限を有効化ボタンをクリックします。
   3. 表示されたページで必要な権限を選択し、権限有効化を確定をクリックすると、申請済み権限一覧ページに自動で遷移します。
      ![](/ja/aitable/automation/more-actions/feishu-node/images/75aef05e-aca4-4708-82ba-c115ef00a4a2_ZxKAxw9tgH.png)
