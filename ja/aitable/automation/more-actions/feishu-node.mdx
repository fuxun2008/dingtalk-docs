## はじめる前に：Feishuの**App IDとAppSecret**を取得する

1. **[Feishu Open Platformにアクセスしてカスタムアプリを作成し](https://open.feishu.cn/app "create a custom app on Feishu")**、**App IDとAppSecretを取得します**。

2. **カスタムアプリに関連するスコープが付与されていることを確認します**。

   例として、[List child departments](https://open.feishu.cn/document/server-docs/contact-v3/department/children "List child departments") APIには、対応する連絡先関連のスコープが必要です。

3. **カスタムアプリのAPIスコープを申請します**（[Apply for API scopes for an enterprise custom app](https://open.feishu.cn/document/server-docs/application-scope/introduction?lang=zh-CN "apply for API scopes")）。
   1. [開発者コンソール](https://open.feishu.cn/app "developer console")にログインし、カスタムアプリを開きます。
   2. 左側のナビゲーションで**Dev config > Permission management**に移動し、**Enable scopes**をクリックします。
   3. ダイアログで必要なスコープを選択し、**Confirm**をクリックすると、付与済みスコープのページに移動します。
