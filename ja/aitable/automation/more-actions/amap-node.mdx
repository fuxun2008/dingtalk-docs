# 天気照会

ユーザーが入力した **都市コード**（adcode）に基づき、対象エリアの現在／将来の天気を照会します。より高い精度や、冠水・積雪などの高度な天気機能が必要な場合は、[ワークオーダー](https://console.amap.com/dev/ticket/create/66 "ワークオーダー")から商談してください。

parameters は必須パラメータと任意パラメータを含みます。すべてのパラメータはアンパサンド（&）で区切ります。下記のリストで、これらのパラメータと利用ルールを示します。

1. **前提条件：都市コードを取得する必要があります**

   [都市コード表](https://lbs.amap.com/api/webservice/download " 都市コード表 ")へアクセスしてください。
2. **ワークフロー設定の説明**

   都市コードと気象タイプを入力します。

   ![](/ja/aitable/automation/more-actions/amap-node/images/image_ZdyYWDhPmU.png)

   パラメータ選択の説明はこちらを参照してください：

   [基礎 API ドキュメント - 開発ガイド - Web サービス API | 高徳地図 API  https://lbs.amap.com/api/webservice/guide/api/weatherinfo](https://lbs.amap.com/api/webservice/guide/api/weatherinfo "基礎 API ドキュメント - 開発ガイド - Web サービス API | 高徳地図 API  https://lbs.amap.com/api/webservice/guide/api/weatherinfo")
