# 天気照会

**adcode**を使って地域の**現在および将来の天気**を照会します。より高い精度や高度な指標（冠水、降雪）が必要な場合は、[チケットを送信](https://console.amap.com/dev/ticket/create/66 "submit a ticket")して商用プランについてお問い合わせください。

`parameters`フィールドには必須パラメータと任意パラメータの両方が含まれます。すべてのパラメータはアンパサンド（`&`）で区切ります。以下のリストにパラメータとその使い方を示します。

1. **前提条件：adcodeを取得する**

   [adcode一覧表](https://lbs.amap.com/api/webservice/download "adcode table")を参照してください。
2. **作業フローの設定**

   adcodeと天気タイプを入力します。

   パラメータリファレンス：

   [ベーシックAPIドキュメント — Web Service API | Amap https://lbs.amap.com/api/webservice/guide/api/weatherinfo](https://lbs.amap.com/api/webservice/guide/api/weatherinfo "Basic API docs — Web Service API | Amap https://lbs.amap.com/api/webservice/guide/api/weatherinfo")
