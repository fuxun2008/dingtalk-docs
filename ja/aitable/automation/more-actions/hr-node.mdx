## はじめに：認証情報を取得

**前提条件：**

- [DingTalk Open Platform へのアクセス権](https://open-dev.dingtalk.io/fe/app?hash=%23%2Fcorp%2Fapp#/corp/app "DingTalk Open Platform へのアクセス権")
- [DingTalk 管理者コンソールへのアクセス権](https://oa.dingtalk.io/index.htm#/welcome "DingTalk 管理者コンソールへのアクセス権")

両方を準備すると、認証情報（**Client ID と Client Secret**）を取得し、会議室リストを同期できます。

1. **AI Table のマイクロアプリを作成します。**

   DingTalk Open Platform を開き、左側のナビゲーションで **DingTalkアプリ** → **アプリを作成** を選択します。

   アプリコンソール：[https://open-dev.dingtalk.io/fe/app?hash=%23%2Fcorp%2Fapp#/corp/app](https://open-dev.dingtalk.io/fe/app?hash=#/corp/app#/corp/app "DingTalk Open Platform")

2. **作成後、「Credentials and basic info」タブを開き、Client ID と Client Secret をコピーします。**

3. **会議の認証情報スコープを申請します。**

   AI Table マイクロアプリの **開発設定** で **権限管理** を見つけ、次を入力します。
   > qyapi_get_department_member
   > 「apply」をクリックしてスコープアクセスを有効化します。

### ノードの設定 — 部門 ID（Dept_ID）を取得

部門詳細 API：[https://open.dingtalk.com/document/orgapp/query-department-details0-v2](https://open.dingtalk.com/document/orgapp/query-department-details0-v2 "部門詳細の取得 API")
