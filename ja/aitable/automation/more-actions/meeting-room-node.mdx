## はじめに：認証情報の取得

**前提条件：**

- [DingTalk Open Platform へのアクセス権](https://open-dev.dingtalk.io/fe/app?hash=#/corp/app#/corp/app "DingTalk Open Platform へのアクセス権")
- [DingTalk 管理コンソールへのアクセス権](https://oa.dingtalk.io/index.htm#/welcome "DingTalk 管理コンソールへのアクセス権")

この両方を用意すると、認証情報（**Client ID と Client Secret**）を取得し、会議室リストを同期できます。

1. **AI Table マイクロアプリを作成します。**

   DingTalk Open Platform を開き、左ナビゲーションの **DingTalkアプリ** → **アプリを作成** を選択します。

   アプリコンソール：[https://open-dev.dingtalk.io/fe/app?hash=%23%2Fcorp%2Fapp#/corp/app](https://open-dev.dingtalk.io/fe/app?hash=#/corp/app#/corp/app "DingTalk Open Platform")

2. **作成後、「Credentials and basic info」タブを開き、Client ID と Client Secret をコピーします。**

3. **会議認証情報のスコープを申請します。**

   AI Table マイクロアプリの **開発設定** で **権限管理** を見つけ、次を入力します。
   > ☘️VideoConference.Conference.Read
   > 「apply」をクリックしてスコープへのアクセスを有効化します。
