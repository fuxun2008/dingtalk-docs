# Coze ワークフローの呼び出し

主な利用シーン:

- **コンテンツ制作**:広告原稿の自動作成、感動系動画の生成など
- **データ取得**:Douyin の注文同期、競合動向の追跡、ホットニュースの収集
- **スマートカスタマーサポート**:スマートカスタマーサポート／販促 Bot、スマートチケットの構築
- **画像処理**:画像／動画認識、コンテンツ分析と比較

> ここでは次のワークフローを例に説明します:KOL の Douyin マイページリンクを追加した際に、Coze ワークフローでその KOL の動画リスト情報（動画リンク、動画ダウンロードリンク、動画カバー画像、音声リンク、いいね数、コメント数、シェア数、お気に入り数、ダウンロード数）などを取得し、AI テーブルに書き戻す。

### ステップ 1. [📎Coze スペース](https://www.coze.cn/space "📎Coze 空間") へ移動してワークフローを作成し、トークンと ID を取得

- まず Coze でアプリ／エージェントを作成する必要があります（[📎Coze ヘルプ](https://www.coze.cn/open/docs/guides/app_quickstart1 "📎Coze ヘルプ")）

  ![](/ja/aitable/automation/third-party-workflow/images/组%2024@1x_x6Xtad-3lm.png)

  例:開始 → Douyin ユーザー動画情報の取得（douyin_user_videos_pro）→ 終了 のフローを想定します
  - **ワークフロー ID の取得**:リンク内の /workflow/ の後ろの数字 2
    ![](/ja/aitable/automation/third-party-workflow/images/组%2025@1x_cItGezpc7G.png)
  - 公開 1 をクリックし、公開プラットフォームを API に選択して、API カード内の「**個人トークンを作成** 3」ボタンをクリックします
    ![](/ja/aitable/automation/third-party-workflow/images/组%2026@1x_D4F1x_54Od.png)
  - 遷移先で新しい個人トークンを追加し、確認をクリックします 4
    ![](/ja/aitable/automation/third-party-workflow/images/组%2027@1x_GvVa1GU1L4.png)
  - 確認後、ダイアログ内の **トークン** 5 をすぐにコピーして保存してください。注意:ダイアログを閉じるとトークンを再表示できません
    ![](/ja/aitable/automation/third-party-workflow/images/组%2028@1x_6zprTpqzTM.png)

### ステップ 3. 「Coze ワークフローを呼び出す」アクションノードを新規作成

- AI テーブル画面に切り替え、前ステップで取得した **トークン** 5 を入力します
- **ワークフロー ID を入力**:ワークフローリンク内の /workflow/ の後ろの数字 2

  ![](/ja/aitable/automation/third-party-workflow/images/组%2031@1x_Ecm5BRUpUO.png)
- ワークフローの入力パラメータ形式を入力します。**ワークフロー内の「開始」入力パラメータ形式と一致させてください**

  ![](/ja/aitable/automation/third-party-workflow/images/组%2033@1x_Tp3ZaCC1gF.png)

### ステップ 4. ワンクリックで出力パラメータ形式を取得

- ユーザーが「テスト実行」をクリックすると、システムは入力済みのパラメータで自動的にフローを実行します。「入力サンプルをワンクリックで反映 5」をクリックすると、JSON 形式が自動的に入力フォームに反映されます
- 変数を使用する場合、「テスト実行」では確定パラメータを手動入力する必要があります

  ![](/ja/aitable/automation/third-party-workflow/images/%E7%BB%84_RWyrTd32uz)

### ステップ 5. JSON 出力形式を自然言語に変換

- 「Coze ワークフロー」ノードの下に「AI に質問するノード」を追加すると、出力の JSON 配列を自然言語に変換して AI テーブルに書き戻せます

  ![](/ja/aitable/automation/third-party-workflow/images/image@1x-2_8gKwCA5emi.png)
- 一度テスト実行すれば、AI テーブルで KOL リンクのデータパフォーマンスを取得できます

  ![](/ja/aitable/automation/third-party-workflow/images/image@1x_P13rgzHbXy.png)

# Bailian アプリの呼び出し

主な利用シーン:

- **コンテンツ制作**:クリエイティブコピー、マーケティングコピー、脚本などの生成
- **データインサイト**:大量のコンテンツとホットイベントを分析し、ビジネス機会を洞察
- **スマートカスタマーサポート**:自動化された顧客相談・問題解決サービスの提供
- **文書レビュー**:文書の分類とレビュー（契約レビュー、法的分析など）
- **医療画像診断**:医療画像を分析し、疾病スクリーニング・診断を補助

> ここでは次のワークフローを例に説明します:毎日人気の Douyin 動画リンクを収集し、Bailian アプリ「Douyin コンテンツアシスタント」を通じて、Douyin リンクから透かしなしの動画と動画テキストを抽出し、スマートに加筆・リライトした結果を AI テーブルに書き戻す。

### ステップ 1. [📎](https://bailian.console.aliyun.com/ "📎")[Alibaba Cloud Bailian](https://bailian.console.aliyun.com/ "Alibaba Cloud Bailian") へ移動してアプリを作成し API キーを取得

- Alibaba Cloud Bailian プラットフォームに入り、アプリマーケットでアプリを 1 つ選択します（[📎Bailian ヘルプ](https://bailian.console.aliyun.com/?tab=doc#/doc/?type=app&url=https%3A%2F%2Fhelp.aliyun.com%2Fdocument_detail%2F2845095.html&renderType=iframe "📎Bailian ヘルプ")）

  例:Douyin リンク追加時 → リンクを「Douyin コンテンツアシスタント」に自動入力 → AI 回答結果を AI テーブルに書き戻すフロー

  ![](/ja/aitable/automation/third-party-workflow/images/组%2035@1x_YM5kewnIFj.png)
- アプリ詳細に入り、このアプリを複製 2 をクリックします

  ![](/ja/aitable/automation/third-party-workflow/images/组%2034@1x_NlS3F5iLnO.png)
- 複製の過程でモデルサービスの開通 3 が必要になる場合があります。開通の際には実名認証が必要です（Alibaba Cloud のホームに戻り、右上のアバターから認証してください）

  ![](/ja/aitable/automation/third-party-workflow/images/组%2036@1x_-fcKUKUpTm.png)
- アプリを複製・作成したら、**アプリ ID**（リンク末尾の数字列 6）を取得します

  ![](/ja/aitable/automation/third-party-workflow/images/组%2043@1x_3Sk5FjJ9kP.png)
- アプリを公開すると、**API Key** 5 を取得できます

  ![](/ja/aitable/automation/third-party-workflow/images/组%2041@1x_R7EsyAl0jQ.png)
- 左側ナビゲーション下部の **API-Key** からも取得できます 4

  ![](/ja/aitable/automation/third-party-workflow/images/组%2040@1x_h_J17kcysj.png)

### ステップ 3. Bailian アプリノードを呼び出し、入力パラメータ形式をワンクリック取得

- AI テーブル画面に切り替え、前ステップで取得した **API-Key** 4、5 を入力します
- **アプリ ID** を入力:アプリリンク末尾の数字列 6

  ![](/ja/aitable/automation/third-party-workflow/images/组%2042@1x_s6UIUkA0oy.png)

### ステップ 4. ワンクリックで出力パラメータ形式を取得

- 出力形式が JSON の場合は、「テスト実行」をクリックするとシステムが入力済みパラメータで自動的にフローを実行し、「入力サンプルをワンクリックで反映 5」をクリックすると JSON 形式が自動的に入力フォームに反映されます
- 出力形式が通常テキストの場合は、「テスト実行」は不要で、出力パラメータをテキストとして直接選択します

  ![](/ja/aitable/automation/third-party-workflow/images/%E7%BB%84_jRJ57KqrFs)

# Dify ワークフローの呼び出し（β 版）

Dify ワークフローを使って次のようなものを構築できます:

- **カスタマーサービス**:スマートカスタマーサポート／販促 Bot の構築
- **コンテンツ生成**:高品質なブログ記事、製品説明の生成
- **タスクの自動化**:タスク管理システムとの統合、プロジェクト管理の自動化
- **データ分析**:大規模なナレッジベースを分析し、レポートやサマリーを生成
- **メール処理**:メール、SNS 投稿などの草案作成

> ここでは次のワークフローを例に説明します:ボタンクリックで Dify の専門株式分析を使ってウォッチリスト銘柄を一括分析する。

### ステップ 1. [📎Dify ワークフロー画面](https://cloud.dify.ai/apps "📎Dify ワークフロー画面") へ移動して API キーを取得

- まず Dify でワークフローを作成する必要があります（[📎Dify ヘルプ](https://docs.dify.ai/zh-hans/guides/workflow/readme "📎Dify ヘルプ")）。Dify はネットワークアクセラレーションを有効にしないとアクセスできません

  例:開始 → 株式分析 → 終了 のフローを作成し、ワンクリック公開 1

  ![](/ja/aitable/automation/third-party-workflow/images/组%2020@1x_UMgoxVtejv.png)
- 必ずワークフローを公開 2 してから、Dify ワークフローの **API キー** 3 を取得してください

  ![](/ja/aitable/automation/third-party-workflow/images/组%2019@1x_uc7h3Wq85d.png)

  ![](/ja/aitable/automation/third-party-workflow/images/组%2021@1x_IXetuMUILC.png)

### ステップ 3. Dify ノードを呼び出し、入力パラメータ形式をワンクリック取得

- AI テーブル画面に切り替え、前ステップで取得した **API キー** 4 を入力します
- **カスタムユーザー識別子** を入力します（主にエンドユーザーの ID を定義し、検索や統計に役立ちます）
- 前ステップのノードキー設定が完了すれば「**パラメータをワンクリック同期** 5」が利用でき、クリックするとワークフローの入力パラメータが自動取得されます

  ![](/ja/aitable/automation/third-party-workflow/images/组%2022@1x_Xvc9wW8Pnq.png)

### ステップ 4. ワンクリックで出力パラメータ形式を取得

- ユーザーが「テスト実行」をクリックすると、システムは入力済みのパラメータで自動的にフローを実行します。「入力サンプルをワンクリックで反映 5」をクリックすると JSON 形式が自動的に入力フォームに反映されます
- 変数を使用する場合、「テスト実行」では確定パラメータを手動入力する必要があります

  ![](/ja/aitable/automation/third-party-workflow/images/%E7%BB%84_jRJ57KqrFs)

### ステップ 5. JSON 出力形式を自然言語に変換

- 「Dify ワークフロー」ノードの下に「AI に質問するノード」を追加すると、出力の JSON 配列を自然言語に変換して AI テーブルに書き戻せます

  ![](/ja/aitable/automation/third-party-workflow/images/组%2017@1x_V-tNZXQdkJ.png)
