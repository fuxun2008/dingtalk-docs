  推奨：まずデータ同期センターでコネクタの基本を確認してから進めてください。

## 事前準備

このコネクタを使用する前に、Lingxing ERPの管理画面でopen APIを有効化し、1セットの**App ID** + **App Secret**を取得して、AI TableにLingxingデータの読み取りを認可してください。

1. スーパー管理者としてLingxing ERPにログイン →**設定 → ビジネス設定 → 基本設定 → Open API**。

> 「Open API」エントリがビジネス設定の下に表示されない場合は、Lingxingのサポートに連絡して、アカウントのオープンプラットフォーム権限を有効化してください。

> 📌 open APIを初めて使用する場合：スーパー管理者として**Open API**にログインします。Lingxingからのopen APIリリースに関する通知を受信するため、バックアップ用のメールアドレスを提供する必要があります。

1. 組織のAppIDとAppSecretを確認します。**APIアカウント管理**の下でこれらを追加します。

> 📌 **注意**：このApp ID + App Secretは組織のすべてのデータにアクセスできます。慎重に取り扱い、漏洩させないでください。無効化するには、**リセット**をクリックして無効化し、新しい認可コードを生成するか、認可コードの有効期間を制限してください。

1. 認証情報の無効化／リセット。

既存のAppSecretを無効化するには（例：ユーザーが退職した場合）、スーパー管理者としてLingxing ERPにログイン →**設定 → ビジネス設定 → 基本設定 → Open API → APIアカウント管理** → AppSecretの**リセット**をクリックします。新しいAppSecretが生成されると、元のAppSecretは即座に無効化されます。または、Disableをクリックして、現在のApp ID + AppSecretによるデータアクセスをブロックします。リセット後は、新しいApp ID + AppSecretでAI Table内のアカウント情報も更新してください。

## データソースの選択

AI Table →**データ同期センター** →**Lingxing ERP**を検索 →**使用**をクリックしてコネクタ設定に入ります。

## データソース設定

1. **Lingxingアカウントをリンク**：初回使用時は**アカウントをリンク**をクリック → ダイアログにApp ID + App Secretを入力します。

入力後、**OK**をクリックします。アカウント情報は現在のデータソースに保存されます。後でデータソースページのアカウントカードから**アカウントの切り替え**または**アカウント情報の編集**を行えます。

1. **同期するデータテーブルを選択**：各データソース設定は1つのテーブルのみをサポートします。複数のテーブルを同期するには、データソースの作成を繰り返してください。現在サポートされているテーブル：

| データテーブル | 説明 | Lingxing ERPのソース |
| --- | --- | --- |
| マルチプラットフォーム売上統計 | 売上／注文数／収益を同期 — 毎日／毎週／毎月／毎年の集計 | 統計 → 売上分析 → 売上統計 |
| MSKUレベルの商品パフォーマンス | MSKUレベルの売上、収益、粗利益などを同期 | 統計 → 売上分析 → 商品パフォーマンス |
| ASINレベルの商品パフォーマンス | ASINレベルの売上、収益、粗利益などを同期 | 統計 → 売上分析 → 商品パフォーマンス |
| MSKUレベルの注文利益 | MSKUレベルの注文利益を同期（収益、粗利益、広告費を含む） | 統計 → 利益統計 → 注文利益 |
| 決済センター — 決済サマリー | Amazon決済センターのサマリーデータを同期 — 売上、返金、費用、振替 | 財務 → 財務決済 → 決済センター |
| 決済センター — 取引明細 | Amazon決済センターの取引明細を同期 — ソースでフィルタ可能 | 財務 → 財務決済 → 決済センター |
| MSKUレベルの利益レポート | MSKUレベルの利益レポートを同期 — 収益、広告費、保管料、粗利益 | 財務 → 財務レポート → 利益レポート |
| 倉庫在庫明細 | ローカル／海外倉庫の在庫を同期 — 数量、コスト、滞留日数 | 倉庫 → 在庫 → 在庫明細 |
| FBA在庫リスト | FBA在庫を同期 — 販売可能数、輸送中、滞留日数、コスト | 倉庫 → 在庫 → FBA在庫明細 |
| FBA出荷リスト | FBA出荷を同期 — ステータス、商品明細、住所 | FBA → 出荷 → FBA出荷 |
| 発注リスト | 発注を同期 — 商品、サプライヤー、金額、ステータス | 仕入 → 仕入書類 → 発注 |
| Amazonショップリスト | 認可済みのすべてのAmazon SCショップを同期 — サイト、ステータス、広告認可 | 設定 → プラットフォーム認可 → ショップ認可 |
| Amazonコンセプトショップリスト | Amazonコンセプトショップを同期 — サイト、ステータス | 設定 → プラットフォーム認可 → ショップ認可 |
| 倉庫リスト | 倉庫を同期 — 倉庫タイプ、海外タイプ、削除ステータスでフィルタ可能 | 設定 → 倉庫設定 |
| ローカル商品リスト | ローカル商品を同期 — SKU、名前、仕入情報、ステータス、タグ | 商品 → 商品管理 |
| Amazon注文リスト | Amazon注文を同期 — ショップ、日付、ステータス、フルフィルメントでフィルタ可能 | 販売 → プラットフォーム注文 → 注文リスト |
| Amazonマルチチャンネル注文リスト | Amazon MCF注文を同期 — 注文ステータス、商品情報、配送情報 | 販売 → プラットフォーム注文 → 注文リスト |

テーブルを選択すると、コネクタがその設定を自動的に読み込みます。取得したいデータスコープを選択してください。

1. **ビジネスパラメータ設定**：必須パラメータはテーブルごとに異なります。一般的なもの：
   - **統計の日付範囲**：時間軸を持つテーブル（売上、利益、注文）向け。2つのモードがあります — 「自然日範囲」と「直近N日間のローリング範囲」（後者は同期のたびに範囲を当日まで自動的にシフトします）。
   - **ショップフィルタ**：認可済みのLingxingショップを1つ以上選択して、そのデータのみを同期します。空のままにすると、このアカウントで認可済みのすべてのショップを同期します。
2. **フィールド**：**次へ**をクリックすると、選択したテーブルのフィールドリストが読み込まれます。同期するフィールドを選択します。主キーはデフォルトでチェックされており、チェックを外せません。

## 作成をクリックして同期を開始

上記の操作の後、**保存して同期**をクリックすると、コネクタが同期を開始します。

## 完了 — データの確認

同期が完了すると、新しいテーブルがAI Tableの左サイドバーに表示されます。これは「同期テーブル」として存在し、以下の後続操作をサポートします：

- **同期設定の編集**

  データテーブルの右側のその他メニューで**データ同期設定**を選択し、フィールドの選択と同期パラメータを調整します。
- **手動更新**

  データテーブルの右側のその他メニューで**データを更新**をクリックすると、コネクタが即座にLingxing APIを再度呼び出し、現在のテーブルを更新します。
- **同期関係の切り離し**

  データテーブルの右側のその他メニューで**同期を切り離す**をクリックすると、同期テーブルは通常の編集可能なテーブルになり、Lingxingソースに追従しなくなります。
- **カスタムフィールドの追加**

  同期されたフィールドに影響を与えずに、AI Tableでカスタムフィールド（メモ、タグ、AIフィールドなど）を追加できます。カスタムフィールドは同期によって上書きされません。

## FAQ

### Q1. Lingxing ERPの管理画面で「Open API」エントリが見つかりません。

「Open API」はLingxingのオープンプラットフォーム機能の一部です。**スーパー管理者アカウント**でログインし、**設定 → ビジネス設定 → 基本設定**の下を確認してください。それでも表示されない場合は、Lingxingに連絡して、組織のオープンプラットフォーム権限が有効になっているかを確認してください。

### Q2. 「AppIDまたはAppSecretが無効」というエラーが表示されます。

次の順序で確認してください：

1. AppIDとAppSecretが**同じ組織の**open API管理画面 →**API情報**から取得したものであり、リセットされていないことを確認します。
2. 認証情報を貼り付ける際に、余分なスペース、改行、その他の不可視文字が混入していないことを確認します。
3. コネクタサービスの**送信元IP**がLingxingのIPホワイトリストに追加されていることを確認します（AI Tableの公式サポートに連絡して解決してください）。
