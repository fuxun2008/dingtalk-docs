  まずデータコネクタの基本機能を理解するため、データコネクタセンターをご確認のうえ、以下の操作を行うことを推奨します。

## 利用前の準備

本コネクタを利用する前に、LingXing ERP の管理画面でオープン API を有効化し、**App ID** と **App Secret** を取得する必要があります。これらは AI テーブルが LingXing データを読み取るための認可情報です。

1. スーパー管理者アカウントで LingXing ERP にログインし、**【設定】 → 【業務設定】 → 【基本】 → 【オープン API】** へ順に進みます。

> 【業務設定】に「オープン API」の入口が表示されない場合、LingXing カスタマーサービスにアカウントのオープンプラットフォーム権限の有効化を依頼してください。

> 📌 オープン API を初めて利用する際は、スーパー管理者アカウントで LingXing ERP にログインして【**オープン API】**に入る必要があります。LingXing から発信されるオープン API 関連通知の受信用メールアドレスをあらかじめ登録してください。

![](/ja/aitable/data-connectors/data-connectors-overview/lingxing-erp/images/截屏2026-05-09%2010.24.58_qUHpeXwdI6.png)

1. 企業の AppID と AppSecret を確認します。**【API アカウント管理】** で企業の AppID と AppSecret を追加できます。

![](/ja/aitable/data-connectors/data-connectors-overview/lingxing-erp/images/image_P-8sZG62sm.png)

> 📌 **ご注意**:この App ID と AppSecret を取得すると企業の全データへアクセスできるようになるため、漏洩しないよう適切に管理してください。失効させたい場合は **【リセット】** ボタンをクリックして無効化し、新しい認可コードを生成するか、認可コードの有効期限を制限できます。

1. 認証情報の失効とリセット

担当者の退職など何らかの理由で既存の AppSecret を失効させる必要がある場合、スーパー管理者アカウントで LingXing ERP にログインし、**【設定】 → 【業務設定】 → 【基本】 → 【オープン API】** **→** 【**API アカウント管理**】 で AppSecret を **【リセット】** することで、新しい AppSecret を生成し、元の AppSecret は即時失効します。あるいは無効化をクリックして、現在の App ID と AppSecret によるデータアクセスを禁止することもできます。リセット後は、AI テーブル側でもアカウント情報を編集して新しい App ID と AppSecret を入力してください。

![](/ja/aitable/data-connectors/data-connectors-overview/lingxing-erp/images/截屏2026-05-08%2020.16.56_KozpZ8nB57__c4qotx82C.png)

## データソースの選択

AI テーブルの **データコネクタセンター** に入り、**LingXing ERP** コネクタを検索して **【利用】** ボタンをクリックすると、コネクタ設定画面に入ります。

![](/ja/aitable/data-connectors/data-connectors-overview/lingxing-erp/images/截屏2026-05-09%2010.29.28_fK10y52oae.png)

## データソース設定

1. **LingXing アカウントの紐付け**:初回利用時には **【アカウントを紐付け】** ボタンをクリックし、ダイアログで App ID と App Secret を入力します。

![](/ja/aitable/data-connectors/data-connectors-overview/lingxing-erp/images/截屏2026-05-08%2020.35.14_J3pDA2bj5D.png)

入力後 **【確定】** をクリックすると、アカウント情報が現在のデータソースに保存され、以後はデータソースページのアカウントカードから **アカウント切り替え** や **アカウント情報の編集** が可能です。

1. **同期するデータテーブルを選択**:データソース設定 1 件につき選択できるデータテーブルは 1 つです。複数のデータテーブルを同期するには、データソースを繰り返し作成してください。本コネクタは現在、以下のデータテーブルの同期に対応しています。

| データテーブル          | 説明                               | LingXing ERP データソース            |
| ------------- | -------------------------------- | ----------------------- |
| マルチプラットフォーム販売数量統計       | 販売数量／注文数量／売上を同期し、日次・週次・月次・年次の集計に対応      | 【統計】→ 【販売分析】 → 【販売数量統計】   |
| MSKU 単位の製品パフォーマンス統計 | MSKU 単位の販売数量、売上、粗利益などのパフォーマンスデータを同期       | 【統計】→ 【販売分析】 → 【製品パフォーマンス】   |
| ASIN 単位の製品パフォーマンス統計 | ASIN 単位の販売数量、売上、粗利益などのパフォーマンスデータを同期       | 【統計】→ 【販売分析】 → 【製品パフォーマンス】   |
| MSKU 単位の注文利益   | MSKU 単位の注文利益を同期(売上、粗利益、広告費などを含む)   | 【統計】→ 【利益統計】 → 【注文利益】   |
| 決済センター - 決済サマリー     | Amazon 決済センターの決済サマリー(販売、返金、支出、振替などを含む)を同期   | 【財務】 → 【財務決済】 → 【決済センター】  |
| 決済センター - 取引明細     | Amazon 決済センターの取引明細を同期、ソース別フィルタに対応         | 【財務】 → 【財務決済】 → 【決済センター】  |
| MSKU 単位の利益レポート    | MSKU 単位の利益レポートを同期(売上、広告費、保管費、粗利益などを含む)   | 【財務】 → 【財務レポート】 → 【利益レポート】  |
| 倉庫在庫明細        | ローカル倉庫／海外倉庫の在庫明細を同期(在庫数、コスト、滞留日数などを含む)        | 【倉庫】 → 【在庫】 → 【在庫明細】    |
| FBA 在庫リスト       | FBA 在庫データを同期(販売可能数、輸送中、滞留日数、コストなどを含む)        | 【倉庫】 → 【在庫】 → 【FBA 在庫明細】 |
| FBA 出荷リスト       | FBA 出荷データを同期(出荷ステータス、子項目明細、住所情報などを含む)     | 【FBA】 → 【出荷】 → 【FBA 出荷】  |
| 発注書リスト         | 発注書データを同期(子項目明細、サプライヤー、金額、ステータスなどを含む)         | 【調達】 → 【調達伝票】 → 【発注書】   |
| Amazon ストアリスト       | 企業が認可した全 Amazon SC ストア情報を同期(サイト、ステータス、広告認可などを含む) | 【設定】 → 【プラットフォーム認可】 → 【ストア認可】  |
| Amazon コンセプトストアリスト     | Amazon コンセプトストア情報(サイト、ステータスなど)を同期              | 【設定】 → 【プラットフォーム認可】 → 【ストア認可】  |
| 倉庫リスト          | 倉庫データを同期、倉庫タイプ、海外倉庫タイプ、削除ステータスでフィルタ可能      | 【設定】 → 【倉庫設定】           |
| ローカル製品リスト        | ローカル製品データを同期(SKU、品名、調達情報、ステータス、タグなどを含む)     | 【製品】 → 【製品管理】           |
| Amazon 注文リスト       | Amazon 注文データを同期、ストア・日付・ステータス・配送方法でフィルタ可能     | 【販売】 → 【プラットフォーム注文】 → 【注文リスト】  |
| Amazon マルチチャネル注文リスト    | Amazon マルチチャネル注文データを同期(注文ステータス、商品情報、配送情報などを含む)    | 【販売】 → 【プラットフォーム注文】 → 【注文リスト】  |

データテーブルを選択すると、コネクタは対応するデータテーブル設定を自動で読み込みます。必要に応じてデータソースから取得するデータ内容を選択してください。

1. **業務パラメータ設定**:データテーブルによって必要な業務パラメータは異なります。一般的なパラメータは以下のとおりです。
   - **集計日付範囲**:販売数量、利益、注文など時間軸を持つデータテーブルで使用します。「カレンダー日付範囲」と「直近 N 日のダイナミック範囲」の 2 つのモードに対応し、後者は同期のたびに当日を基準に時間範囲を自動で切り出します。
   - **ストアフィルター**:LingXing で認可済みのストアを 1 つまたは複数選択し、指定ストアのデータのみ同期できます。チェックを入れない場合は、当該アカウントで認可されている全ストアのデータが同期されます。
2. **フィールド設定**:【次へ】をクリックすると、当該データテーブルのフィールドリストが自動で読み込まれます。同期したいフィールドを必要に応じて選択でき、主キーフィールドはデフォルトでチェックされ解除できません。

![](/ja/aitable/data-connectors/data-connectors-overview/lingxing-erp/images/截屏2026-05-08%2021.00.22_6nIgYgUgIf.png)

## 作成をクリックしてデータ同期を開始

上記設定が完了したら、**【保存して同期】** ボタンをクリックすると、コネクタがデータ同期を行います。

![](/ja/aitable/data-connectors/data-connectors-overview/lingxing-erp/images/截屏2026-05-08%2021.05.18_zTsJl9ROYX.png)

## 作成完了とデータ確認

同期完了後、AI テーブル左側のデータテーブルリストに新規作成されたデータテーブルが表示されます。このテーブルは「同期テーブル」として存在し、以後は次の操作が可能です。

- **データ同期設定の変更**

  データテーブル右側の その他の操作 メニューで【データ同期設定】を選択すると、選択したフィールドや同期パラメータを調整できます。
- **手動で同期更新**

  データテーブル右側の その他の操作 メニューで【データを更新】をクリックすると、コネクタが直ちに LingXing API を再呼び出しして、現在のテーブルデータを更新します。
- **同期関係の解除**

  データテーブル右側の その他の操作 メニューで【同期関係を解除】をクリックすると、同期テーブルは通常の編集可能なテーブルに変換され、LingXing データソースとの同期は維持されなくなります。
- **カスタムフィールドの追加**

  同期フィールドに影響を与えない範囲で、AI テーブル内にカスタムフィールド(備考、タグ、AI フィールドなど)を追加できます。カスタムフィールドは同期操作で上書きされません。

## よくある質問

### Q1. LingXing ERP の管理画面で「オープン API」の入口が見つからない

「オープン API」は LingXing オープンプラットフォームの機能で、**スーパー管理者アカウント** でログインしたうえで **【設定】 → 【業務設定】 → 【基本】** から確認できます。それでも表示されない場合は、LingXing 側に企業がオープンプラットフォーム権限を有効化済みかご確認ください。

### Q2. 「AppID または AppSecret が無効です」と表示される

以下の順に確認してください。

1. AppID と AppSecret が**同一企業**のオープン API 管理画面【API 情報】から取得されており、リセットされていないこと。
2. コピー時に空白や改行などの不可視文字が混入していないこと。
3. コネクタサービスの**送信元 IP** が LingXing 側の IP ホワイトリストに登録されていること(AI テーブル運営にお問い合わせください)。
