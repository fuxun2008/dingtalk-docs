  先に[データコネクタ](/ja/aitable/data-connectors/data-connectors-overview)を確認し、データソース同期の基本機能を把握してから以下の操作を進めることを推奨します。

⚠️ パブリッククラウドにデプロイされた Teambition ユーザーのみ対応しています。プライベートデプロイ版は同期非対応です。

⚠️ AI テーブルの所属組織とプロジェクトの所属組織が同一である必要があります。一致して初めて、Teambition で利用するアカウントでログインし、設定したプロジェクトにアクセスできます。一致しない場合、アカウント無効・認証失敗と表示されます。

## 利用前の準備：プロジェクト ID

1. PC 版 DingTalk のサイドバー下部で **その他** を見つけ、クリック後 **アプリを追加** を選択

   ![](/ja/aitable/data-connectors/data-connectors-overview/teambition/images/image_g7cNuvH6hg.png)
2. ビジネスデジタル化エリアで「プロジェクト」を見つけ、クリックすると Teambition が DingTalk サイドバーに追加されます

   ![](/ja/aitable/data-connectors/data-connectors-overview/teambition/images/image_quUvRO88me.png)
3. Teambition に進入し、新規プロジェクトを作成、該当プロジェクトビューに進入。ページ右上の **メニュー** ボタンをクリックし、**リンクをコピー** を選択

   ![](/ja/aitable/data-connectors/data-connectors-overview/teambition/images/image_ZWmb5ZOm-D.png)
4. リンクをコピーし、`project/` の後に続くプロジェクト ID を抽出

   ![](/ja/aitable/data-connectors/data-connectors-overview/teambition/images/image_Uy4_8FeRah.png)

## データコネクタへの進入

AI テーブル左下の **追加／インポート** ボタンをクリックし、**データコネクタ** を選択します。

![](/ja/aitable/data-connectors/data-connectors-overview/teambition/images/image_hm_BtRGD9P.png)

## データソースの選択

**Teambition** コネクタを選択または検索し、**使用** ボタンをクリックしてデータソース設定画面に進みます。

![](/ja/aitable/data-connectors/data-connectors-overview/teambition/images/image_C0VpBIrIWX.png)

## データソース設定

![](/ja/aitable/data-connectors/data-connectors-overview/teambition/images/image_QD_2KAtzwD.png)

1. **データソース選択**：データソースをチェック。現在 1 つのデータソースのみで、デフォルトでチェック済み
2. **アカウント設定**：アカウント名はカスタムで、ステップ 1 で準備したデータ同期対象のプロジェクト ID を入力
3. **フィールド設定**：全選択／一部選択でテーブルのフィールド範囲を柔軟に設定可能。主キーはチェック解除不可
4. **同期設定**：データテーブル同期設定をオン／オフ可能。オン時、毎時同期モードまたは定時同期モードを選択可能

   ![](/ja/aitable/data-connectors/data-connectors-overview/teambition/images/image_OlVSVUfnuE.png)
   - 毎時同期：1 時間／12 時間／24 時間ごとの同期から選択可能
   - 定時同期：毎日／毎週／毎月の固定時刻を選択可能、祝日のスキップも設定可能

     ヒント：コネクタ設定中に問題が発生した場合、**データソース設定ページ - フィードバック送信** からフィードバックできます

## 作成をクリックしてデータ同期を開始

コネクタ設定完了後、**作成** をクリックしてデータ同期を行います。作成成功後、データ同期テーブルが自動で追加されます。

![](/ja/aitable/data-connectors/data-connectors-overview/teambition/images/image_Utf0z6n8QL.png)

## 同期後の関連操作

- **データ同期設定の変更**

  同期設定済みのデータテーブルで設定を変更したい場合、データ同期テーブル右側のアイコンをクリックし、**データ同期設定** を選択。同期フィールドや同期メカニズムの変更、自動同期のオン／オフに対応しています
- **手動同期更新**

  同期されたデータテーブルをクリックし、テーブル名右側の ⋮ その他の操作 アイコンをクリック。**データ更新** をクリックすると手動同期が起動し、データソースから再取得して当該テーブルを更新します
- **同期関係の解除**

  **同期関係を解除** をクリックすると、同期テーブルが編集可能なテーブルになり、元データソースとの同期関係はなくなります

![](/ja/aitable/data-connectors/data-connectors-overview/teambition/images/image_nVA8EP4pyG.png)
