## 接続したいデータソースを探す

1. AI テーブル左下の **+ 追加 / インポート**ボタンをクリック
2. **データコネクタセンター**を選択し、コネクタセンターに入る
3. 利用したいデータソースを選択する

![](https://img.alicdn.com/imgextra/i2/O1CN01G9p9sv1qlXlOM9UcG_!!6000000005536-1-tps-2770-1556.gif)

## データソースの設定

1. データソースの選択：必要なデータソースにチェックを入れます。現状はデータソースが 1 つのみで、デフォルトで選択されています
2. アカウント設定：アカウント名をカスタムし、用意した Alibaba Cloud アカウントの App Code を追加します
3. パラメータ設定：一部のコネクタでは設定が必要です。例えば**天気予報**の取得時には、省 / 自治区 / 直轄市と都市の指定が必要です
4. フィールド設定：全選択 / 一部選択で、テーブルのフィールド範囲を柔軟に設定できます。プライマリフィールド[^注釈1]は選択を解除できません
5. 同期設定：データテーブルの同期設定をオン / オフできます。オンの場合、時間単位での同期と定刻同期のいずれかを選択できます：
   - 時間単位での同期：1 時間、12 時間、24 時間ごとの同期から選択可能
   - 定刻同期：毎日、毎週、毎月の特定の時刻での同期に対応。祝日をスキップするかどうかも設定できます
6. **作成**をクリックすると、データソースの設定が完了し、新しいデータ同期テーブルが即座に追加されます。

## 同期後の関連操作

- **データ同期設定の変更**

  同期設定済みのデータテーブルで設定を変更したい場合、データ同期テーブル右側のアイコンをクリックし、**データ同期設定**を選びます。同期するフィールドや同期メカニズムの変更、自動同期のオン / オフが可能です。
- **手動での同期更新**

  同期されたデータテーブルをクリックし、データテーブル名右側の ⋮ その他の操作アイコンをクリックします。**データ更新**をクリックすると手動同期が実行され、データソースから最新データを再取得して現在のテーブルを更新します。
- **同期関係の解除**

  **同期関係を解除**をクリックすると、同期テーブルが編集可能なテーブルに変換され、元のデータソースとは同期されなくなります。

![](/ja/aitable/data-connectors/data-connectors-overview/account-settings/images/image_92wVrrUvFp.png)

[^注釈1]: AI テーブルの先頭列はプライマリフィールドと呼ばれ、削除や非表示はできません
