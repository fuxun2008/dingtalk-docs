## 接続するデータソースを検索

1. AI Table の左下で、**+ 追加 / インポート** をクリックします。
2. **データ同期センター** を選択して入ります。
3. 利用したいデータソースを選択します。

## データソースを設定

1. **データソースの選択**：利用可能なソースは 1 つのみで、デフォルトで選択されています。
2. **アカウント設定**：名前は任意です。準備した Aliyun App Code を追加します。
3. **パラメータ**：一部のコネクタにはパラメータが必要です。たとえば **天気予報** では、省 / 直轄市と都市を指定します。
4. **フィールド**：すべて選択するか一部のフィールドを選択します。プライマリフィールド[^note1] のチェックは外せません。
5. **同期設定**：同期のオン / オフを切り替えます。オンの場合は **時間単位** または **スケジュール** を選択します。
   - **時間単位**：1 / 12 / 24 時間ごと。
   - **スケジュール**：毎日 / 毎週 / 毎月の固定時刻。休日をスキップするよう設定できます。
6. **作成** をクリックしてデータソースの設定を完了します。新しい同期テーブルが直ちに自動追加されます。

## 同期後の操作

- **同期設定の編集**

  既存の同期テーブルでは、右側のアイコンをクリック →**データ同期設定** で、同期するフィールド・同期方式の変更や自動同期の切り替えができます。
- **手動更新**

  同期テーブルを開き、テーブル名の横にある ⋮ その他アイコンをクリック →**データの更新** で、ソースから手動で再取得して更新します。
- **同期関係の解除**

  **同期を解除** をクリックすると、同期テーブルが編集可能になり、ソースに追従しなくなります。

[^note1]: AI Table の最初の列は **プライマリフィールド** と呼ばれ、削除や非表示にはできません。
