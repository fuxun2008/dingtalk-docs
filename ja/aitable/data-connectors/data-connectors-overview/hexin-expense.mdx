  まずデータ同期センターを確認し、コネクタの基本を理解してから進めることをおすすめします。

## 事前準備

このコネクタを使用する前に、合思経費精算のバックエンドでオープンAPIを有効化し、**AppKey** + **App Security** の組を1セット取得して、AI Tableが合思経費精算のデータを読み取る権限を付与してください。

1. 合思経費精算（旧：易快報）のバックエンドにログイン →**アプリセンター → アプリストア → 「オープンAPI（新）」を検索** → 該当する項目を選択します。

1. オープンAPI（新）の詳細ページを開く →**項目設定** をクリックして、組織の **AppKey**（アクセスアカウント）と **App Security**（アクセスパスワード）を取得します。

> 📌 **注意**：AppKeyとApp Securityは組織のすべてのデータにアクセスできます。安全に管理し、漏洩させないでください。取り消す場合は、**オープンAPI（新）** で **無効** にします。既存のAppKeyとApp Securityは無効化と同時に即時反映されます。

1. 認証情報の取り消し / リセット

   既存のAppKey + App Securityを取り消す場合（例：ユーザーの退職時）、管理者は **アプリセンター → アプリストア → オープンAPI（新） → 項目設定** に移動し、**無効** をクリックします。既存のAppKeyとApp Securityは無効化と同時に即時反映されます。無効化後は新しいキーを作成できます。新しいAppKey + App SecurityでAI Tableのアカウント情報も更新してください。

> 📌 オープンAPIの詳細については、[合思オープンプラットフォーム公式ドキュメント](https://docs.ekuaibao.com/docs/open-api/getting-started/question-answer "合思オープンプラットフォーム公式ドキュメント")をご覧ください。

## データソースを選択

AI Table →**データ同期センター** → **合思経費精算** を検索 → **使用** をクリックしてコネクタ設定に入ります。

## データソース設定

1. **合思経費精算アカウントの連携**：初回利用時は **アカウント連携** をクリック → ダイアログでAppKey + App Securityを入力します。

入力後、**OK** をクリックすると、アカウント情報が現在のデータソースに保存されます。後でデータソースページのアカウントカードから **アカウントの切り替え** や **アカウント情報の編集** ができます。

1. **同期するデータテーブルの選択**：各データソース設定は1つのテーブルのみをサポートします。複数のテーブルを同期するには、データソースの作成を繰り返してください。現在サポートしているテーブル：

| データテーブル | 説明 |
| --- | --- |
| 合思経費精算 — 予算バッグ一覧 | 予算バッグ情報を同期 |
| 合思経費精算 — 経費精算記録 | 経費精算記録と金額を同期 |
| 合思経費精算 — 貸付記録一覧 | 貸付記録情報を同期 |
| 合思経費精算 — 申請一覧 | 申請記録情報を同期 |

テーブルを選択すると、コネクタがその設定を自動で読み込みます。取得したいデータのスコープを選択してください。

1. **フィールド**：テーブルを選択すると、コネクタがそのフィールド一覧を読み込みます。同期したいフィールドを選択してください。主キーはデフォルトでチェックされており、チェックを外せません。

## 作成をクリックして同期を開始

上記の手順を終えたら、**保存して同期** をクリックすると、コネクタが同期を開始します。

## 完了 — データを確認

同期が完了すると、新しいテーブルがAI Tableの左サイドバーに表示されます。これは「同期テーブル」として存在し、次の操作がサポートされます。

- **同期設定の編集**

  データテーブル右側のその他メニューで **データ同期設定** を選択し、フィールドの選択や同期パラメータを調整します。
- **手動更新**

  データテーブル右側のその他メニューで **データ更新** をクリックすると、コネクタが即座に合思経費精算APIを再呼び出しし、現在のテーブルを更新します。
- **同期関係の解除**

  データテーブル右側のその他メニューで **同期解除** をクリックすると、同期テーブルは編集可能な通常のテーブルになり、合思経費精算のソースに追従しなくなります。
- **カスタムフィールドの追加**

  同期されたフィールドに影響を与えることなく、AI Tableでカスタムフィールド（メモ、タグ、AIフィールドなど）を追加できます。カスタムフィールドは同期によって上書きされません。
