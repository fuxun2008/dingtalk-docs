  データコネクタの基本機能については、まずデータコネクタセンターをご確認のうえ、以下の操作にお進みください。

## 利用前の準備

本コネクタを利用するには、合思費用管理の管理画面で開放インターフェイスを有効化し、AI テーブルが合思費用管理のデータを読み取れるよう、**App Key** と **App Security** のセットを取得する必要があります。

1. 合思費用管理（旧：易快报）の管理画面にログインし、**【アプリセンター】 → 【アプリストア】 → 「开放接口(新)」を検索** → 該当商品を選択

![](/ja/aitable/data-connectors/data-connectors-overview/hexin-expense/images/截屏2026-05-09%2009.47.28_WJrUCVCNmo.png)

1. 開放インターフェイス（新）の詳細画面で**【商品配置】**をクリックすると、企業の **App Key**（接続アカウント）と **App Security**（接続パスワード）を取得できます。

![](/ja/aitable/data-connectors/data-connectors-overview/hexin-expense/images/截屏2026-05-09%2009.52.49_fIGLX2MRPL.png)

![](/ja/aitable/data-connectors/data-connectors-overview/hexin-expense/images/截屏2026-05-09%2009.54.30_ReaEKgU9a8.png)

> 📌 **ご注意**：App Key と App Security には、対応する企業の全データにアクセスできる権限があります。漏洩しないよう厳重に管理してください。無効化する場合は【开放接口（新）】で**停止**操作を行ってください。停止後は元の App Key と App Security が即時に無効化されます。

1. 認証情報の無効化と再設定

   退職などの理由で既存の App Key と App Security を無効化する必要がある場合、管理者は **【アプリセンター】 → 【アプリストア】 → 【开放接口（新）】 → 【商品配置】** で**【停止】**をクリックすると、即座に無効化されます。停止後は新しいキーを作成できます。AI テーブル側でもアカウント情報を編集し、新しい App Key と App Security を入力してください。

> 📌 開放インターフェイスの詳細は、[合思開放プラットフォーム公式ドキュメント](https://docs.ekuaibao.com/docs/open-api/getting-started/question-answer "合思開放プラットフォーム公式ドキュメント")を参照してください。

## データソースの選択

AI テーブルの**データコネクタセンター**で、**合思費用管理**コネクタを検索し、**【使用】**ボタンをクリックして設定画面に入ります。

![](/ja/aitable/data-connectors/data-connectors-overview/hexin-expense/images/截屏2026-05-09%2009.18.02_UGnqzrhyHA.png)

## データソースの設定

1. **合思費用管理アカウントを連携**：初回利用時は**【アカウントを連携】**ボタンをクリックし、ポップアップに App Key と App Security を入力します：

![](/ja/aitable/data-connectors/data-connectors-overview/hexin-expense/images/截屏2026-05-09%2009.19.45_JR7q1X34uO.png)

入力後**【確定】**をクリックすると、アカウント情報が現在のデータソースに保存されます。以降はデータソース画面のアカウントカードから**アカウントの切り替え**や**アカウント情報の編集**が可能です。

1. **同期するデータテーブルを選択**：データソース 1 件につき、データテーブル 1 つのみ選択できます。複数のデータテーブルを同期したい場合は、データソースを繰り返し作成してください。本コネクタは現在、以下のデータテーブルの同期に対応しています：

| データテーブル | 説明 |
| ----------- | ----------- |
| 合思費用管理 予算パッケージ一覧 | 予算パッケージ情報を同期 |
| 合思費用管理 経費精算書類一覧 | 経費精算書類と金額情報を同期 |
| 合思費用管理 借入申請書類一覧 | 借入申請書類情報を同期 |
| 合思費用管理 申請書類一覧 | 申請書類情報を同期 |

データテーブルを選択すると、コネクタが対応するデータテーブル設定を自動で読み込みます。必要に応じて、データソースから取得する内容を選んでください。

1. **フィールド設定**：データテーブルを選択すると、フィールド一覧が自動で読み込まれます。同期したいフィールドを必要に応じて選択してください。プライマリキーフィールドはデフォルトで選択されており、解除はできません。

## クリックで作成し、データの同期を開始

上記の設定が完了したら、**【保存して同期】**ボタンをクリックすると、コネクタがデータの同期を開始します。

![](/ja/aitable/data-connectors/data-connectors-overview/hexin-expense/images/截屏2026-05-09%2010.06.36_DAdtQBBnGX.png)

## 作成完了とデータの確認

同期完了後、AI テーブル左側のデータテーブル一覧に新しく作成されたデータテーブルが表示されます。このテーブルは「同期テーブル」として存在し、以下の操作が可能です。

- **データ同期設定の変更**

  データテーブル右側の「その他の操作」メニューから【データ同期設定】を選ぶと、選択したフィールドや同期パラメータを調整できます。
- **手動での同期更新**

  データテーブル右側の「その他の操作」メニューから【データ更新】をクリックすると、コネクタが合思費用管理のインターフェイスを再度呼び出し、現在のテーブルデータを更新します。
- **同期関係の解除**

  データテーブル右側の「その他の操作」メニューから【同期関係を解除】をクリックすると、同期テーブルが通常の編集可能なテーブルに変換され、合思費用管理のデータソースとは同期されなくなります。
- **カスタムフィールドの追加**

  同期フィールドに影響を与えずに、AI テーブル内でカスタムフィールド（メモ、タグ、AI フィールドなど）を追加できます。カスタムフィールドは同期操作によって上書きされません。
