## 利用前の準備：Alibaba Cloud アカウントへの登録とログイン

開始前に、Alibaba Cloud アカウントの登録と有効化が完了していることを確認してください。

1. Alibaba Cloud 公式サイトを開き、[https://www.aliyun.com](https://www.aliyun.com "https://www.aliyun.com") の右上のログインをクリックします

   ![](/ja/aitable/data-connectors/data-connectors-overview/alibaba-cloud/images/image_vBlrWgQiwO.png)
2. 携帯電話番号、または Alibaba Cloud / Alipay / DingTalk アカウントでログインします。

   ![](/ja/aitable/data-connectors/data-connectors-overview/alibaba-cloud/images/image_BZ1dz8Vs7v.png)

## Alibaba Cloud AccessKey の取得

### AccessKey とは

アクセスキー AccessKey（略称：AK）は、Alibaba Cloud がユーザーに提供する長期アクセス資格情報で、AccessKey ID と AccessKey Secret から成る一組のキーペアです。

1. 右上のアバターをクリックし、「権限とセキュリティ」の下にある AccessKey を選択

   ![](/ja/aitable/data-connectors/data-connectors-overview/alibaba-cloud/images/image_8PFtnVxQxr.png)
2. データ接続には**RAM アカウント** + AccessKey の組み合わせを推奨します。クラウドアカウントのキーは使用しないでください。
   > メインアカウントの権限は強力すぎるため、本番環境ではメインアカウントによる AccessKey 作成をできるだけ避け、適切な権限を付与した RAM ユーザーで AccessKey を作成・管理してください。
   > ![](/ja/aitable/data-connectors/data-connectors-overview/alibaba-cloud/images/image_Plq55VzGmC.png)
3. 左側ナビゲーションで**アイデンティティ管理** > **ユーザー**を選択。ユーザーが存在しない場合は、まずユーザーを作成してください。

   ![](/ja/aitable/data-connectors/data-connectors-overview/alibaba-cloud/images/image_VkTfb8jVKg.png)
4. 「権限の追加」をクリックして、当該ユーザーに `AliyunRAMFullAccess`（RAM 管理者）システムポリシーを付与すると、RAM ユーザーの AccessKey 作成・管理が可能になります。少なくとも OSS の読み取り専用権限 `AliyunOSSReadOnlyAccess` を付与してください。

   ![](/ja/aitable/data-connectors/data-connectors-overview/alibaba-cloud/images/image_IkOV9DT3Gf.png)

   ![](/ja/aitable/data-connectors/data-connectors-overview/alibaba-cloud/images/image_Keb4jiBJEX.png)
5. 権限を付与したら、ユーザー一覧で対象の **RAM ユーザー**を見つけ、その名前をクリックします。

   ![](/ja/aitable/data-connectors/data-connectors-overview/alibaba-cloud/images/image_khrGer3Huo.png)
6. **認証管理**タブの **AccessKey** エリアで、**AccessKey の作成**をクリックします。

   ![](/ja/aitable/data-connectors/data-connectors-overview/alibaba-cloud/images/image_yWTMrOY6tt.png)

> 各 RAM ユーザーは最大 2 つの **AccessKey** を作成できます。1 つは通常使用、もう 1 つは古い AccessKey を交換するためのローテーション用として作成します。

1. ポップアップに表示される AccessKey の利用シーンと推奨事項を確認し、最適な認証方式を選択してください。**「AccessKey の作成が必要であることを確認しました」**にチェックを入れ、**作成を続行**をクリックします。

   ![](/ja/aitable/data-connectors/data-connectors-overview/alibaba-cloud/images/image_LxGBJrWkrR.png)
2. AccessKey 作成のダイアログで、AccessKey ID と AccessKey Secret を保存し、確定をクリックします。AccessKey Secret は作成時のみ表示されるため、大切に保管してください。

   ![](/ja/aitable/data-connectors/data-connectors-overview/alibaba-cloud/images/image_URcHRmjYpB.png)

> AccessKey の作成手順詳細：[https://help.aliyun.com/zh/ram/user-guide/create-an-accesskey-pair?spm=5176.2020520153.console-base_help.dexternal.2a9a336aqdUEYd#task-2245479](https://help.aliyun.com/zh/ram/user-guide/create-an-accesskey-pair?spm=5176.2020520153.console-base_help.dexternal.2a9a336aqdUEYd#task-2245479 "https://help.aliyun.com/zh/ram/user-guide/create-an-accesskey-pair?spm=5176.2020520153.console-base_help.dexternal.2a9a336aqdUEYd#task-2245479")
