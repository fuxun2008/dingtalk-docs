## 事前準備：Aliyun の登録とログイン

開始する前に、Aliyun アカウントを用意してください。

1. Aliyun を開きます：[https://www.aliyun.com](https://www.aliyun.com "https://www.aliyun.com") — 右上の **ログイン** をクリックします。

2. 電話番号、Aliyun、Alipay、または DingTalk アカウントでログインします。

## Aliyun AccessKey の取得

### AccessKey とは

アクセスキー（略称 AK）は Aliyun が提供する長期有効のアクセス認証情報で、AccessKey ID と AccessKey Secret のキーペアです。

1. 右上のアバターをクリックし、**権限とセキュリティ** で **AccessKey** を選択します。

2. 推奨：接続には **RAMユーザー + AccessKey** を使用し、クラウドアカウントのキーは使用しないでください。
   > メインアカウントは権限が広範すぎるため、本番環境ではメインアカウントで AccessKey を作成せず、適切な権限を付与した RAM ユーザーを使用してください。
3. 左側のナビゲーションで **ID管理** → **ユーザー** を選択します。ユーザーがまだない場合は **ユーザーを作成** をクリックします。

4. **権限を追加** をクリックし、`AliyunRAMFullAccess`（RAM 管理者）のシステムポリシーを付与すると、そのユーザーが RAM ユーザーの AccessKey を作成・管理できます。または少なくとも OSS の閲覧のみ権限 `AliyunOSSReadOnlyAccess` を付与します。

5. 付与後、ユーザー一覧で対象の **RAMユーザー** を見つけ、その名前をクリックします。

6. **認証管理** → **AccessKey** で **AccessKeyを作成** をクリックします。

> 各 RAM ユーザーは最大 2 つの **AccessKey** を保持できます。1 つは通常のアクセスに使用し、ローテーション時に古いものを置換するために 2 つ目を作成します。

1. ダイアログで AccessKey の利用シーンと推奨事項を確認し、より適した認証情報プランを選択します。**AccessKeyの作成が必要であることを確認します** にチェックを入れ、**続く** をクリックします。

2. Create AccessKey ダイアログで AccessKey ID と AccessKey Secret を保存し、**OK** をクリックします。AccessKey Secret は作成時にのみ表示されるため、安全に保管してください。

> AccessKey の詳細な作成ガイド：[https://help.aliyun.com/en/ram/user-guide/create-an-accesskey-pair?spm=5176.2020520153.console-base_help.dexternal.2a9a336aqdUEYd#task-2245479](https://help.aliyun.com/en/ram/user-guide/create-an-accesskey-pair?spm=5176.2020520153.console-base_help.dexternal.2a9a336aqdUEYd#task-2245479 "https://help.aliyun.com/en/ram/user-guide/create-an-accesskey-pair?spm=5176.2020520153.console-base_help.dexternal.2a9a336aqdUEYd#task-2245479")
