  ご利用の前に、まず[データコネクタ](/ja/aitable/data-connectors/data-connectors-overview)の基本機能を確認したうえで以下の操作を行うことをおすすめします。

## 利用前の準備:金数据アカウントの紐付け

1. 以下のリンクを開き、ご自身のアカウント情報を取得します:[https://open.jinshuju.net/#/api_v1/authentication](https://open.jinshuju.net/#/api_v1/authentication "https://open.jinshuju.net/#/api_v1/authentication")

   ![](/ja/aitable/data-connectors/data-connectors-overview/jinshuju/images/image_ibAkD8OfrP.png)
2. API アクセスを有効化します。

   ![](/ja/aitable/data-connectors/data-connectors-overview/jinshuju/images/image_5Tcy9aOAEK.png)
3. **App Key** と **App Secret** をコピーします。API アクセスの有効化には、有料アップグレードまたは高度版のお試しが必要です。

   ![](/ja/aitable/data-connectors/data-connectors-overview/jinshuju/images/image_6ECAcEu_Of.png)

   ![](/ja/aitable/data-connectors/data-connectors-overview/jinshuju/images/image_FmvvmJbXDj.png)

## データコネクタを開く

AI テーブル左下の **追加/インポート** ボタンをクリックし、**データコネクタ** を選択します。

![](/ja/aitable/data-connectors/data-connectors-overview/jinshuju/images/image_zgdbYem7mf.png)

データコネクタを開きます。

![](/ja/aitable/data-connectors/data-connectors-overview/jinshuju/images/image_cLLAQXPOA8.png)

## データソースの選択

**金数据** コネクタを選択するか直接検索し、**使用** ボタンをクリックして設定画面に入ります。

![](/ja/aitable/data-connectors/data-connectors-overview/jinshuju/images/image_ERV5GptV--.png)

## データソースの設定

1. **データソースの選択**:必要なデータソースをチェックします。現在は 1 つのみで、デフォルトでチェック済みです。
2. **アカウント設定**:アカウント名を任意で設定し、ステップ 1 で用意した API Key と API Secret を入力します。

   ![](/ja/aitable/data-connectors/data-connectors-overview/jinshuju/images/image_DQ_c7nABii.png)
3. **フィールド設定**:全選択または一部選択で、テーブルのフィールド範囲を柔軟に設定できます。プライマリキーはチェックを外せません。
4. **同期設定**:データテーブルの同期設定をオン/オフできます。オンにすると、時間単位同期モードまたは定時同期モードを選択できます。
   - 時間単位同期:1 時間・12 時間・24 時間ごとの同期から選択できます。
   - 定時同期:毎日・毎週・毎月の特定時刻に同期するよう設定でき、祝日をスキップするかどうかも構成可能です。

     ヒント:コネクタの設定中に問題が発生した場合は、**データソース設定画面 - フィードバック送信** からご連絡ください。

     ![](/ja/aitable/data-connectors/data-connectors-overview/jinshuju/images/image_ENU-oTAk8h.png)

## 「作成」をクリックしてデータ同期を開始

コネクタの設定が完了したら、**作成** をクリックしてデータ同期を行います。作成に成功すると、データ同期テーブルが自動的に追加されます。

![](/ja/aitable/data-connectors/data-connectors-overview/jinshuju/images/image__N4P7-gmh9.png)

## 同期後の操作

- **データ同期設定の変更**

  すでに同期設定済みのデータテーブルで設定を変更するには、データ同期テーブル右側のアイコンをクリックし、**データ同期設定** を選択します。同期するフィールドや同期方式の変更、自動同期のオン/オフ切り替えに対応しています。
- **手動同期**

  同期されたデータテーブルを開き、テーブル名右側の ⋮ アイコン(その他の操作)から **データ更新** をクリックすると、手動同期がトリガーされ、データソースから再取得して現在のテーブルが更新されます。
- **同期関係の解除**

  **同期関係の解除** をクリックすると、同期テーブルが編集可能なテーブルに変わり、元のデータソースとの同期関係が解消されます。

![](/ja/aitable/data-connectors/data-connectors-overview/jinshuju/images/image_-pn5P7SOjg.png)
