  おすすめ：まず[データ同期センター](/aitable/data-connectors/data-connectors-overview)を確認してコネクタの基本を理解してから進めてください。

## 準備：Jinshujuアカウントを連携する

1. リンクを開き、クリックしてアカウント情報を取得します：[https://open.jinshuju.net/#/api_v1/authentication](https://open.jinshuju.net/#/api_v1/authentication "https://open.jinshuju.net/#/api_v1/authentication")

2. APIアクセスを有効化します。

3. **App Key** と **App Secret** をコピーします。APIアクセスを有効化するには、有料アップグレードまたはProトライアルが必要です。

## データ同期センターを開く

AI Tableの左下で **追加 / インポート** → **データ同期センター** をクリックします。

データ同期センターを開きます。

## データソースを選択する

**Jinshuju** コネクタを選択または検索し、**使用** をクリックしてコネクタ設定に進みます。

## データソース設定

1. **データソースの選択**：利用可能なソースは1つのみで、デフォルトで選択されています。
2. **アカウント設定**：名前は任意です。フローノード1で準備したAPI KeyとAPI Secretを貼り付けます。

3. **フィールド**：すべてのフィールドまたは一部のフィールドを選択します。主キーは選択を解除できません。
4. **同期設定**：同期のオン / オフを切り替えます。オンの場合は **1時間ごと** または **スケジュール** を選択します：
   - **1時間ごと**：1 / 12 / 24時間ごと。
   - **スケジュール**：毎日 / 毎週 / 毎月の固定時刻。祝日をスキップするように設定できます。

     ヒント：コネクタ設定中に問題が発生した場合は、**データソースページ → フィードバックを送信** から通報してください。

## 作成をクリックして同期を開始する

コネクタの設定が完了したら、**作成** をクリックして同期を開始します。成功すると、新しい同期テーブルが自動的に追加されます。

## 同期後の操作

- **同期設定を編集する**

  既存の同期テーブルで、右側のアイコンをクリックし、**データ同期設定** を選択すると、同期するフィールド、同期メカニズムの変更、または自動同期のオン / オフ切り替えができます。
- **手動更新**

  同期テーブルを開き、テーブル名の横にある ⋮ その他アイコンをクリックして **データを更新** を選択すると、ソースから手動で再取得して更新します。
- **同期関係を解除する**

  **同期を解除** をクリックすると、同期テーブルが編集可能になり、ソースに追従しなくなります。
