  推奨：まず[データ同期センター](/aitable/data-connectors/data-connectors-overview)を確認してコネクタの基本を理解してから進めてください。

## 準備：Jiandaoyunアカウントを連携する

アカウント申請ガイド：[https://hc.jiandaoyun.com/open/10992](https://hc.jiandaoyun.com/open/10992 "https://hc.jiandaoyun.com/open/10992")

まずJiandaoyunに**ログイン**してください。新規ユーザーは管理者バックエンドでTrialを取得できます。

API Keyを取得します。[https://www.jiandaoyun.com/open#/key/api_key](https://www.jiandaoyun.com/open#/key/api_key "https://www.jiandaoyun.com/open#/key/api_key")を開き、API Keyを作成してコピーします。

## データ同期センターを開く

AI Tableの左下で、**追加 / インポート** → **データ同期センター**をクリックします。

データ同期センターを開きます。

## データソースを選択する

**Jiandaoyun**コネクタを選択または検索し、**使用**をクリックしてデータソース設定に進みます。

## データソース設定

### **データソースを選択**

利用できるソースは1つのみで、デフォルトで選択されています。

### **アカウント設定**

名前は任意です。準備しておいたAPI Keyを追加します（上記の「準備」を参照）。

### **フィールド**

すべて選択または一部選択により、テーブルの列を柔軟にスコープ設定できます。主キーは選択を解除できません。

### **同期設定**

同期のオン / オフを切り替えます。オンの場合、**時間単位**または**定期**を選択します：

- **時間単位**：1 / 12 / 24時間ごと。
- **定期**：毎日 / 毎週 / 毎月の固定時刻。祝日をスキップするように設定することも可能です。

  ヒント：コネクタの設定中に問題が発生した場合は、**コネクタページ → フィードバックを送信**から通報してください。

## 「作成」をクリックして同期を開始する

コネクタの設定が完了したら、**作成**をクリックして同期を開始します。成功すると、新しい同期テーブルが自動的に追加されます。

## 同期後の操作

- **同期設定を編集する**

  既存の同期テーブルで、右側のアイコンをクリックし、**データ同期設定**を選択すると、同期するフィールド、同期メカニズムの変更や、自動同期の切り替えができます。
- **手動で更新する**

  同期テーブルを開き、テーブル名の横にある⋮その他アイコンをクリックし、**データを更新**を選択すると、ソースから手動で再取得して更新できます。
- **同期関係を解除する**

  **同期を解除**をクリックすると、同期テーブルが編集可能になり、ソースに追従しなくなります。
