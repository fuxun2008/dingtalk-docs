  まずデータコネクタの基本機能を理解するため、[データコネクタセンター](/ja/aitable/data-connectors/data-connectors-overview)をご確認のうえ、以下の操作を行うことを推奨します。

## 利用前の準備:JianDaoYun アカウントの紐付け

アカウント申請ガイド:[https://hc.jiandaoyun.com/open/10992](https://hc.jiandaoyun.com/open/10992 "https://hc.jiandaoyun.com/open/10992")

まず JianDaoYun に**ログイン** してください。新規ユーザーは管理画面に入ると、トライアル版を取得できます。

![](/ja/aitable/data-connectors/data-connectors-overview/jiandaoyun/images/image_98uLlc9NeR.png)

API Key を取得するには、[https://www.jiandaoyun.com/open#/key/api_key](https://www.jiandaoyun.com/open#/key/api_key "https://www.jiandaoyun.com/open#/key/api_key") をクリックして API Key を作成し、コピーするだけです。

![](/ja/aitable/data-connectors/data-connectors-overview/jiandaoyun/images/image_UiVgSMrb5Z.png)

## データコネクタセンターに入る

AI テーブル左下の **追加／インポート** ボタンをクリックし、**データコネクタセンター** を選択します。

![](/ja/aitable/data-connectors/data-connectors-overview/jiandaoyun/images/image_gJNkUq9c5u.png)

データコネクタセンターに入ります。

![](/ja/aitable/data-connectors/data-connectors-overview/jiandaoyun/images/image_Dw_LPLZj2q.png)

## データソースの選択

**JianDaoYun** コネクタを選択するか直接検索し、**利用** ボタンをクリックすると、データソース設定画面に入ります。

![](/ja/aitable/data-connectors/data-connectors-overview/jiandaoyun/images/image_Qpw4GAqpY5.png)

## データソース設定

### **データソースの選択**

データソースを選択します。現時点では 1 つのデータソースのみで、デフォルトで選択されています。

![](/ja/aitable/data-connectors/data-connectors-overview/jiandaoyun/images/image_zXFYt_m1N-.png)

### **アカウント設定**

アカウント名をカスタマイズし、準備済みの API Key を追加します。詳細は上記の利用前の準備をご覧ください。

![](/ja/aitable/data-connectors/data-connectors-overview/jiandaoyun/images/image_haP2o_nmHp.png)

### **フィールド設定**

全選択またはフィールドの一部を選択して、テーブルのフィールド範囲を柔軟に設定できます。主キーは選択解除できません。

### **同期設定**

![  ](/ja/aitable/data-connectors/data-connectors-overview/jiandaoyun/images/20250823142129_ZKB82IJEn5.jpg)

データテーブル同期設定の有効化と無効化が可能です。有効にすると、時間単位の同期モードと定時同期モードを選択できます。

- 時間単位の同期:1 時間、12 時間、24 時間ごとの同期から選択可能。
- 定時同期:毎日、毎週、毎月の決まった時間で同期するよう設定可能で、休日をスキップするかも設定できます。

  ヒント:コネクタ設定中に問題が発生した場合は、**コネクタ設定ページ - フィードバック送信** からフィードバックいただけます。

## 作成をクリックしてデータ同期を開始

コネクタ設定が完了したら、**作成** をクリックしてデータ同期を行います。作成成功後、データ同期テーブルが自動的に追加されます。

![](/ja/aitable/data-connectors/data-connectors-overview/jiandaoyun/images/image_XDybbmjY5R.png)

## 同期後の関連操作

- **データ同期設定の変更**

  同期設定済みのデータテーブルで同期設定を変更したい場合は、データ同期テーブル右側の  アイコンをクリックして **データ同期設定** を選択します。同期するフィールドや同期メカニズムの変更、自動同期の有効化／無効化に対応します。
- **手動で同期更新**

  同期されたデータテーブルをクリックし、データテーブル名右側の ⋮ その他の操作 アイコンをクリックします。**データを更新** をクリックすると手動同期が開始され、データソースのデータを再取得して現在のテーブルを更新します。
- **同期関係の解除**

  **同期関係を解除** をクリックすると、同期テーブルが編集可能なテーブルになり、元のデータソースとの同期関係はなくなります。

![](/ja/aitable/data-connectors/data-connectors-overview/jiandaoyun/images/image_NRnOfkXqMV.png)
