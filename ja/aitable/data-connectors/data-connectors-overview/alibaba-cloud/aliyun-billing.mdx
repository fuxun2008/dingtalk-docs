title: "Aliyun Billingデータの同期"
description: "Aliyun Billingの請求データと注文データを、データ同期センター経由でAI Tableに同期。RAMサブアカウントのAccessKeyを使い、クラウドコスト分析・費用照合・財務管理を実現します。"
---

AI Tableは**Aliyun Billingコネクタ**に対応し、Aliyunアカウント配下の**請求データ**と**注文データ**を同期できます。コスト分析、費用照合、財務管理にご利用ください。

このガイドでは、次の手順を説明します。

- Aliyunコンソールへのログイン。
- AccessKey IDとAccessKey Secretの取得。
- AI TableでのAliyun Billingデータソースの作成。
- パラメータとフィールドの設定、同期の完了。

---
## 事前準備

開始前に、次の点を確認してください。

- ログイン可能な登録済みのAliyunアカウント。
- アカウントでBilling／Billサービスが有効になっていること。
- アカウントに少なくとも閲覧のみのBilling権限があること。
- AI Tableへのアクセス権があること。

> ⚠️ プライマリアカウントのキーではなく、**RAMサブアカウント＋AccessKey**の利用を推奨します。

---
## Aliyun AccessKeyの取得

AI TableはAccessKeyを介してAliyun Billing APIを呼び出します。まずAliyunコンソールで作成してください。

詳細は**Aliyun公式サービス**をご覧ください。

### 1. Aliyunコンソールへのログイン

1. Aliyunを開きます：[https://www.aliyun.com](https://www.aliyun.com "https://www.aliyun.com")。
2. 右上の**ログイン**をクリックします。
3. Aliyunアカウントでログインします。

---
### 2. AccessKeyの作成または取得（RAMユーザー推奨）

1. ログイン後、**RAM（アクセス制御）**を開きます。
2. 左メニューで**ユーザー**を選択します。
3. RAMユーザーを作成するか、既存のものを選択します。
4. Billing権限を付与します（閲覧のみで十分です）。
   - 例：`AliyunBSSOpenApiReadOnlyAccess`。
5. **認証管理**を開きます。
6. AccessKeyを作成します。
7. 次の項目をコピーして保存します。
   - **AccessKey ID**
   - **AccessKey Secret**

> ⚠️ AccessKey Secretは作成時に一度しか表示されません。必ず保存してください。

---
## AI TableでのAliyun Billingデータソースの作成

### 1. データ同期センターを開く

1. AI Tableを開きます。
2. 左下の**データ同期センター**をクリックします。
3. **Aliyun**を検索します。
4. **Aliyun請求**を選択します。

---
## データソース設定

**データソース**で、同期するデータ型を選択します。

### 対応するデータソースタイプ

- **Aliyun Billing・請求一覧**

  アカウントレベルの請求明細データを同期します。
- **Aliyun Billing・注文一覧**

  アカウント配下の注文情報（新規購入、更新、アップグレードなど）を同期します。

各データソースは個別に作成する必要があります。

---
## アカウント設定

Aliyunアカウントを連携します。

### フィールド参照

| フィールド | 説明 |
| --- | --- |
| アカウント名 | 複数のAliyunアカウントを区別するためのカスタムラベル |
| AccessKey ID | Aliyunコンソールから取得 |
| AccessKey Secret | Aliyunコンソールから取得 |

完了したら**確認**をクリックします。

> 🔒 AI TableはAccessKey情報を保存時に暗号化します。このデータソースのみで使用されます。

---
## パラメータ

### 1. エンドポイント／地域（必須）

請求データのサイトを指定します。

- 例：`China`。
- 地域が異なると、請求データと注文データも異なります。

---
### 2. 請求期間／会議時間範囲（必須）

請求データの同期期間を指定します。

#### 請求一覧の共通設定

- 期間の形式：`YYYY-MM`。

  例：`2025-12`。
- 単一の請求月を選択します。

#### 注文一覧の共通設定

- 時間範囲タイプ：最近／指定。
- 例：直近7日間、直近30日間。

---
### 3. 請求／注文タイプ（任意）

データ型でフィルタリングします。

#### 一般的な注文タイプ

- 新規購入（New）。
- 更新（Renew）。
- アップグレード（Upgrade）。
- ダウングレード（Downgrade）。
- 返金（Refund）。
- 変換（Convert）。
- OS変更（ChangeOperatingSystem）。

---
### 4. 支払いステータス（任意）

注文または請求を支払いステータスでフィルタリングします。

---
## フィールド

AI Tableに同期するフィールドを選択します。

---
### 一般的な請求フィールド

| フィールド | 説明 |
| --- | --- |
| 請求／注文ID | 請求または注文の固定値の識別子 |
| 請求タイプ | 請求のタイプ |
| 製品コード | クラウド製品コード |
| 製品名 | クラウド製品名 |
| 製品タイプ | クラウド製品カテゴリ |
| 注文タイプ | 新規購入／更新／アップグレードなど |
| 支払いステータス | 現在の支払いステータス |
| 通貨 | 決済通貨 |
| 元の金額 | 元の請求金額 |
| 支払い金額 | 実際の支払い予定額 |
| 割引金額 | 割引／免除金額 |
| 税額 | 税額 |
| 税込金額 | 税込みの合計額 |

---
### 割引・相殺フィールド

| フィールド | 説明 |
| --- | --- |
| 割引 | 割引免除金額 |
| クーポン相殺 | クーポン相殺金額 |
| バウチャー相殺 | バウチャー相殺金額 |
| プリペイドカード相殺 | プリペイドカード相殺金額 |
| クレジット返金相殺 | クレジット関連の相殺 |
| 現金支払い（クレジット含む） | 実際に支払った現金 |
| 現金支払い（クレジット除く） | 支払った現金部分 |
| 未払い金額 | 未決済のまま残っている金額 |

---
### 時間・リソースフィールド

| フィールド | 説明 |
| --- | --- |
| 作成日時 | 注文の作成日時 |
| 支払い日時 | 実際の支払い日時 |
| 請求開始時刻 | 請求サイクルの開始 |
| 請求終了時刻 | 請求サイクルの終了 |
| リソース所有者アカウントID | リソースを所有するアカウント |

---
次のことができます。

- **すべて選択**にチェックを入れて、すべてのフィールドを同期します。
- または、財務関連のフィールドのみを選択します。

---
## 同期設定

### モード

- **オフ（デフォルト）**

  データは作成時または手動更新時のみ更新されます。
- **オン**

  システムが設定した周期で最新の請求データを自動同期します。

> 月次照合やコスト監視に推奨します。

---
## 完了——データの表示

1. 右下の**作成**をクリックします。
2. AI TableがAliyun Billingデータの取得を開始します。
3. 完了後、AI Tableで請求一覧または注文一覧を表示します。
4. データは次の用途に活用できます。
   - コスト分析。
   - 財務照合。
   - クラウドリソースのコスト内訳と統計。

---
## FAQ

#### Q1：権限が拒否される、または同期に失敗する場合は？

- RAMユーザーにBilling権限があるか確認してください。
- AccessKeyが正しく入力されているか確認してください。

#### Q2：請求金額がコンソールと異なる場合は？

- 請求期間の設定を確認してください。
- APIによって、明細請求または集計請求のいずれかが返されます。

#### Q3：AccessKeyは安全ですか？

- AI TableはAccessKey情報を保存時に暗号化します。
- このデータソースのみで使用され、外部に公開されることはありません。
