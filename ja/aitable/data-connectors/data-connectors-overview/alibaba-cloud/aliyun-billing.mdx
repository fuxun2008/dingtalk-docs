AI テーブルでは「Alibaba Cloud 費用管理」データコネクタを通じて、Alibaba Cloud アカウント配下の **請求データ** と **注文データ** を同期し、テーブル上でコスト分析・費用精算・財務管理を行えます。

本記事では、以下の手順を案内します。

- Alibaba Cloud コンソールへのログイン
- AccessKey ID と AccessKey Secret の取得
- AI テーブルでの Alibaba Cloud 費用管理データソース作成
- パラメータとフィールドの設定によるデータ同期完了

---
## 利用前の準備

開始前に、以下の条件を満たしているか確認してください。

- Alibaba Cloud アカウントを登録・ログイン済み
- アカウントで費用管理／請求サービスを有効化済み
- アカウントが費用管理に関する読み取り以上の権限を保有
- AI テーブルの利用権限を保有

> ⚠️ **RAM サブアカウント + AccessKey** によるデータ接続を推奨します。マスターアカウントの鍵は使用しないでください。

---
## Alibaba Cloud AccessKey の取得

AI テーブルは AccessKey を介して Alibaba Cloud 費用管理 API を呼び出すため、事前に Alibaba Cloud コンソールで鍵を作成する必要があります。

詳細手順は **Alibaba Cloud 公式サービス** を参照してください。

### 1. Alibaba Cloud コンソールへのログイン

1. Alibaba Cloud 公式サイトを開きます：[https://www.aliyun.com](https://www.aliyun.com "https://www.aliyun.com")
2. 右上の【ログイン】をクリック
3. Alibaba Cloud アカウントでログインを完了

---
### 2. AccessKey の作成または取得（RAM ユーザー推奨）

1. ログイン後、【アクセス制御 RAM】に進みます
2. 左側メニューの【ユーザー】をクリック
3. RAM ユーザーを新規作成または既存ユーザーを選択
4. 該当ユーザーに費用管理関連の権限（読み取り専用で可）を付与
   - 例：`AliyunBSSOpenApiReadOnlyAccess`
5. 【認証管理】に進みます
6. AccessKey を作成
7. 以下の情報をコピーして保管：
   - **AccessKey ID**
   - **AccessKey Secret**

> ⚠️ AccessKey Secret は作成時にのみ表示されます。大切に保管してください。

---
## AI テーブルで Alibaba Cloud 費用管理データソースを作成

### 1. データコネクタに進入

1. AI テーブルを開きます
2. 左下の【データコネクタ】をクリック
3. 「Alibaba Cloud」で検索
4. 【Alibaba Cloud 費用管理】を選択

---
## データソース設定

「データソース選択」で、同期するデータタイプを選べます。

### 対応データソースタイプ

- **Alibaba Cloud 費用管理 · 請求一覧**  

  アカウント単位の請求明細データを同期
- **Alibaba Cloud 費用管理 · 注文一覧**  

  アカウント配下の注文情報（新規購入・更新・アップグレード等）を同期

異なるデータソースは個別に作成する必要があります。

---
## アカウント設定

「アカウント設定」で Alibaba Cloud アカウントを紐付けます。

### 入力項目

| フィールド            | 説明                          |
| ---------------- | --------------------------- |
| アカウント名           | カスタム名称、複数の Alibaba Cloud アカウントを区別するため |
| AccessKey ID     | Alibaba Cloud コンソールで取得した AccessKey ID     |
| AccessKey Secret | Alibaba Cloud コンソールで取得した AccessKey Secret |

入力完了後、【確定】をクリックします。

> 🔒 AI テーブルは鍵を暗号化して保存し、当該データソースの呼び出しのみに使用します。

---
## パラメータ設定説明

### 1. アクセスドメイン／リージョン（必須）

費用データが属するサイトを指定します。

- 例：`中国`
- リージョンごとに請求と注文のデータが異なります

---
### 2. 課金期間／時間範囲（必須）

同期する費用データの時間範囲を指定します。

#### 請求一覧の一般的な設定

- 課金期間フォーマット：`YYYY-MM`  

  例：`2025-12`
- 単月の課金期間を指定可能

#### 注文一覧の一般的な設定

- 時間範囲タイプ：直近時間／指定時間
- 例：直近 7 日、直近 30 日

---
### 3. 請求／注文タイプ（任意）

特定タイプのデータをフィルターするのに使用します。

#### 一般的な注文タイプ

- 新規購入（New）
- 更新（Renew）
- アップグレード（Upgrade）
- ダウングレード（Downgrade）
- 返金（Refund）
- 変換（Convert）
- OS 変更（ChangeOperatingSystem）

---
### 4. 支払いステータス（任意）

支払いステータス別に注文または請求をフィルターします。

---
## フィールド設定説明

業務ニーズに応じて、AI テーブルに同期するフィールドを選択できます。

---
### 一般的な請求フィールド

| フィールド名     | 説明            |
| --------- | ------------- |
| 請求番号／注文番号 | 請求または注文の一意識別子 |
| 請求タイプ     | 請求の所属タイプ      |
| プロダクトコード  | クラウドプロダクトのコード |
| プロダクト名    | クラウドプロダクトの名称  |
| プロダクトタイプ  | クラウドプロダクトの分類  |
| 注文タイプ     | 新規購入／更新／アップグレード等 |
| 支払いステータス  | 現在の支払いステータス   |
| 通貨        | 決済通貨          |
| 元金額       | 元の請求金額        |
| 請求金額      | 実際の請求金額       |
| 割引金額      | 割引減額金額        |
| 税額        | 税額            |
| 税込金額      | 税込み金額         |

---
### 割引・控除関連フィールド

| フィールド名         | 説明       |
| ------------ | -------- |
| 割引特典         | 割引による減額金額   |
| クーポン控除       | クーポンによる控除金額 |
| 引換券控除        | 引換券による控除金額 |
| プリペイドカード控除   | プリペイドカードによる控除金額 |
| 与信枠返金控除      | 与信枠関連の控除 |
| 現金支払い（与信枠含む） | 実際の現金支払金額 |
| 現金支払い（与信枠除く） | 現金部分の支払金額 |
| 未精算金額        | 未精算の金額   |

---
### 時間とリソース関連フィールド

| フィールド名      | 説明       |
| --------- | -------- |
| 作成時刻      | 注文作成時刻   |
| 支払時刻      | 実際の支払時刻  |
| 請求開始時刻    | 請求期間の開始時刻 |
| 請求終了時刻    | 請求期間の終了時刻 |
| リソース所属アカウント ID | リソースが属するアカウント識別子 |

---
以下を選択できます。

- 【全選択】で全フィールドを同期
- または財務分析・コスト精算に必要な主要フィールドのみを選択

---
## 同期設定

### 同期方法の説明

- **同期オフ（デフォルト）**  

  作成時または手動更新時のみデータを更新
- **同期オン**  

  設定した頻度で最新の費用データを自動同期

> 月次精算やコスト監視のシーンでは自動同期の有効化を推奨します。

---
## 作成完了とデータ確認

1. 右下の【作成】をクリック
2. AI テーブルが Alibaba Cloud 費用管理データの取得を開始
3. 同期完了後、テーブルで請求または注文一覧を確認可能
4. データの活用シーン：
   - コスト分析
   - 財務精算
   - クラウドリソース費用の按分・統計

---
## よくある質問

### Q1：権限なしの表示や同期失敗が発生します

- RAM ユーザーに費用管理関連の権限が付与されているか確認してください
- AccessKey の入力が正しいか確認してください

### Q2：請求金額がコンソールと一致しません

- 課金期間の設定が正しいか確認してください
- API ごとに返却されるデータが明細請求か集計請求か異なります

### Q3：AccessKey は安全ですか？

- AI テーブルは AccessKey 情報を暗号化して保存します
- 当該データソースの呼び出しのみに使用し、外部に公開されません
