AI テーブルは「Alibaba Cloud Security Center」データコネクタを通じて、Alibaba Cloud アカウントの **セキュリティアラートデータ** を同期できます。クラウド上のセキュリティリスク、アラートイベント、対処状況をテーブルで一元管理するのに役立ちます。

本記事では、以下の操作手順を説明します。

- Alibaba Cloud コンソールにログインする
- AccessKey ID と AccessKey Secret を取得する
- AI テーブルで Alibaba Cloud Security Center データソースを作成する
- パラメータとフィールドを設定し、データ同期を完了する

## 一、ご利用前の準備

開始前に、以下の条件を満たしているか確認してください。

- Alibaba Cloud アカウントが登録済みでログインできる
- アカウントで **Alibaba Cloud Security Center** が有効化されている
- アカウントに Security Center の読み取り専用以上の権限がある
- AI テーブルの利用権限がある

> ⚠️ **RAM サブアカウント + AccessKey** の方式でデータ接続を行うことを推奨します。マスターアカウントの鍵は使用しないでください。

## 二、Alibaba Cloud AccessKey の取得

AI テーブルは AccessKey を使って Alibaba Cloud Security Center API を呼び出します。事前に Alibaba Cloud コンソールで鍵を作成する必要があります。

### 1. Alibaba Cloud コンソールにログインする

1. Alibaba Cloud 公式サイトを開きます。[https://www.aliyun.com](https://www.aliyun.com "https://www.aliyun.com")
2. 右上の【ログイン】をクリックします。
3. Alibaba Cloud アカウントでログインします。

### 2. AccessKey の作成または取得（RAM ユーザー推奨）

1. ログイン後、【アクセス制御 RAM】に進みます。
2. 左側メニューの【ユーザー】をクリックします。
3. 新規作成、または既存の RAM ユーザーを選択します。
4. そのユーザーに Security Center 関連の権限（最低でも読み取り専用）を付与します。
   - 例：Security Center 読み取り専用権限
5. 【認証管理】に進みます。
6. AccessKey を作成します。
7. 以下の情報をコピーして保存します。
   - **AccessKey ID**
   - **AccessKey Secret**

> ⚠️ AccessKey Secret は作成時にしか表示されません。大切に保管してください。

## 三、AI テーブルで Alibaba Cloud Security Center データソースを作成

### 1. データコネクタに進む

1. AI テーブルを開きます。
2. 上部の【データコネクタ】をクリックします。
3. 検索ボックスに「Alibaba Cloud」と入力します。
4. 【Alibaba Cloud Security Center】を選択します。

## 四、データソース設定

「データソース選択」では、現在対応しているデータソースタイプは以下のとおりです。

- **アラート一覧**

  現在の Alibaba Cloud アカウントの Security Center アラート記録を同期します。

選択後、次のステップに進みます。

## 五、アカウント設定

「アカウント設定」で Alibaba Cloud アカウントを関連付けます。

### 入力項目の説明

| フィールド          | 説明                                  |
| ---------------- | ----------------------------------- |
| アカウント名         | カスタム名称。AI テーブル内で異なる Alibaba Cloud アカウントを区別するために使用します。 |
| AccessKey ID     | Alibaba Cloud コンソールで取得した AccessKey ID     |
| AccessKey Secret | Alibaba Cloud コンソールで取得した AccessKey Secret |

入力完了後、【確定】をクリックします。

> 🔒 AI テーブルは鍵を暗号化して保存し、当該データソースの呼び出しのみに使用します。

## 六、パラメータ設定の説明

### 1. リージョン（必須）

Security Center データのリージョン範囲を指定します。

- 例：`国内リージョン`
- リージョンによって対応する Security Center データ範囲が異なります。

### 2. 開始時間（必須）

同期するアラートデータの時間範囲の起点を指定します。

選択方式：

- 直近の時間
- 指定した時点

### 3. 時間範囲（必須）

同期するアラートの時間幅を指定します。

- 例：直近 7 日間 / 直近 30 日間
- 時間範囲が広いほど、同期データ量が増えます。

## 七、フィールド設定の説明

業務ニーズに応じて、AI テーブルに同期するアラートフィールドを選択できます。

### よく使うアラート基本フィールド

| フィールド名   | 説明              |
| -------- | --------------- |
| アラート ID  | セキュリティアラートの一意な識別子 |
| マスターアカウント ID | Alibaba Cloud マスターアカウント ID |
| イベント UUID | アラートイベントの一意な識別子 |
| アラート記録時間  | アラートが発生した時間   |
| アラート発生元プロダクト | アラートを発生させたクラウドプロダクト |
| アラートタイトル | アラートのタイトル      |
| アラートタイプ  | アラートのタイプ       |
| アラート名    | アラートルール名       |
| 脅威レベル    | アラートのリスクレベル    |
| アラート状態   | 現在のアラート処理状態    |

### アラート時間関連フィールド

| フィールド名     | 説明              |
| ---------- | --------------- |
| アラート発生時間   | アラートが最初に発生した時間  |
| アラート初回発生時間 | 初回トリガーされた時間     |
| アラート終了時間   | アラート終了時間        |
| アラート最終更新時間 | 直近の更新時間         |

### アラート詳細・拡張フィールド

| フィールド名         | 説明                |
| -------------- | ----------------- |
| アラート説明         | アラートの詳細説明         |
| アラート英語説明       | 英語の説明             |
| アラート説明コード      | 説明に対応するコード        |
| アラート詳細         | 詳細なイベント情報         |
| アラートログ UUID    | アラートログの識別子        |
| エンティティ詳細       | アラート関連資産情報        |
| ATT\\&CK 攻撃技法タグ | MITRE ATT\\&CK タグ |
| 防御済みかどうか       | 防御措置を取ったかどうか      |

### アカウント・資産関連フィールド

| フィールド名   | 説明             |
| -------- | -------------- |
| サブユーザー ID | RAM サブアカウント ID |
| サブユーザー名  | RAM サブアカウント名   |
| クラウドベンダーコード | クラウドサービス事業者の識別子 |
| プロダクト ID | 関連するクラウドプロダクト ID |
| クラウドコード  | クラウドリソースコード    |
| 検知ルール ID | アラート検知ルールの識別子  |
|          |                |

可能な操作：

- 【すべて選択】にチェックを入れて全フィールドを同期する
- または関心のあるフィールドのみを選択し、セキュリティ分析や統計に使用する

## 八、同期設定

### 同期方法の説明

- **同期オフ（デフォルト）**

  作成時または手動で同期をトリガーした際にのみデータを更新します。
- **同期オン**

  設定された頻度に従い、最新のアラートデータを自動同期します。

> セキュリティ監視や運用当番などのシーンでは自動同期の有効化を推奨します。

## 九、作成完了とデータ確認

1. 右下の【作成】をクリックします。
2. AI テーブルが Alibaba Cloud Security Center のアラートデータの取り込みを開始します。
3. 同期完了後、テーブルでアラート一覧を確認できます。
4. データの活用例：
   - セキュリティリスク統計
   - アラートの追跡と対処
   - 複数アカウントのセキュリティ分析

## 十、よくある質問

### Q1：権限がない、または同期に失敗するという表示が出ます

- RAM ユーザーに Security Center 関連の権限が付与されているか確認してください。
- AccessKey が正しく入力されているか確認してください。

### Q2：アラート数がコンソールと一致しないのはなぜですか

- 時間範囲の設定を確認してください。
- リージョンによってアラートデータが異なる場合があります。

### Q3：AccessKey は安全ですか

- AI テーブルは AccessKey 情報を暗号化して保存します。
- 現在のデータソース呼び出しのみに使用され、外部に公開されることはありません。
