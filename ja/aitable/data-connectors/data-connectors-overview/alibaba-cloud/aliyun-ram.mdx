AI テーブルでは「Alibaba Cloud Resource Access Management（RAM）」データソースコネクタを利用して、Alibaba Cloud アカウント配下の **RAM ロール情報** および **RAM ユーザー情報** を同期できます。クラウドアカウントの権限、メンバー、ロール設定をテーブル上で一元管理しましょう。

本ドキュメントでは以下の手順を案内します。

- Alibaba Cloud コンソールへのログイン
- AccessKey ID と AccessKey Secret の取得
- AI テーブルで Alibaba Cloud RAM データソースを作成
- パラメータとフィールドを設定し、データ同期を完了

## 一、利用前の準備

開始前に、以下の条件を満たしていることをご確認ください。

- Alibaba Cloud アカウントを登録済み、ログイン済みであること
- アカウントで「Resource Access Management（RAM）」サービスを有効化済みであること
- RAM 関連の読み取り専用以上の権限を保有していること
- AI テーブルの利用権限を保有していること

> ⚠️ メインアカウントのキーを直接使用することは避け、**RAM サブアカウント + AccessKey** によるデータ接続を推奨します。

## 二、Alibaba Cloud AccessKey の取得

AI テーブルは AccessKey を介して Alibaba Cloud RAM API を呼び出すため、事前に Alibaba Cloud コンソールでキーを作成する必要があります。

### 1. Alibaba Cloud コンソールへログイン

1. Alibaba Cloud 公式サイトを開く：[https://www.aliyun.com](https://www.aliyun.com "https://www.aliyun.com")
2. 右上の【ログイン】をクリック
3. Alibaba Cloud アカウントでログインを完了

### 2. AccessKey の作成または取得（RAM ユーザー利用を推奨）

1. ログイン後【Resource Access Management（RAM）】に入る
2. 左メニューの【ユーザー】をクリック
3. 新規作成または既存の RAM ユーザーを選択
4. 当該ユーザーへ権限を付与（最低でも RAM 読み取り権限を含める）
   - 権限例：`AliyunRAMReadOnlyAccess`
5. 【認証管理】に入る
6. AccessKey を作成
7. 以下の情報をコピーして保存
   - **AccessKey ID**
   - **AccessKey Secret**

> ⚠️ AccessKey Secret は作成時のみ表示されます。必ず適切に保管してください。

## 三、AI テーブルで Alibaba Cloud RAM データソースを作成

### 1. データコネクタへ移動

1. AI テーブルを開く
2. 上部の【データコネクタ】をクリック
3. 「Alibaba Cloud」を検索
4. 【Alibaba Cloud RAM】を選択

![](/ja/aitable/data-connectors/data-connectors-overview/alibaba-cloud/aliyun-ram/images/image_gLmi2rWeG2.png)

## 四、データソース設定

「データソース選択」のステップで、同期するデータタイプを選択できます。

### サポートされるデータソースタイプ

- **Alibaba Cloud RAM ロールリスト**

  現在のアカウント配下のすべての RAM ロールを同期
- **Alibaba Cloud RAM ユーザーリスト**

  現在のアカウント配下のすべての RAM ユーザーを同期

いずれかを選択してください（または個別に複数のデータソースを作成）。

## 五、アカウント設定

「アカウント設定」で Alibaba Cloud アカウントを関連付けます。

### 入力項目の説明

| フィールド            | 説明                                 |
| ---------------- | ---------------------------------- |
| アカウント名           | カスタム名称。AI テーブルで複数の Alibaba Cloud アカウントを区別するために使用 |
| AccessKey ID     | Alibaba Cloud コンソールで取得した AccessKey ID     |
| AccessKey Secret | Alibaba Cloud コンソールで取得した AccessKey Secret |

入力完了後、【確認】をクリックします。

> 🔒 AI テーブルは AccessKey 情報を暗号化して保存し、データ同期呼び出しのみに使用します。

## 六、パラメータ設定の説明

### アクセスドメイン（必須）

Alibaba Cloud RAM サービスの API アクセスアドレスを指定します。

- デフォルト値：`ram.aliyuncs.com`
- 通常は変更不要

## 七、フィールド設定の説明

必要に応じて AI テーブルへ同期するフィールドを選択できます。

### 1. RAM ロールフィールドの説明

| フィールド名   | 説明                |
| -------- | ----------------- |
| ロール ID   | RAM ロールの一意な識別子    |
| ロール名     | RAM ロール名          |
| ロール説明    | ロールの説明情報          |
| 作成日時     | ロール作成日時           |
| 更新日時     | ロールの最終更新日時        |
| 最大セッション時間 | ロールの最大セッション時間   |
| リソース記述子  | ロールのリソース識別情報      |
| タグ       | ロールに紐付けられたタグ      |

### 2. RAM ユーザーフィールドの説明

| フィールド名      | 説明           |
| ----------- | ------------ |
| RAM ユーザー ID | ユーザーの一意な識別子  |
| RAM ユーザー名   | ユーザー名        |
| ログイン名       | ユーザーログイン名    |
| ユーザーメール     | 紐付けられたメールアドレス |
| 携帯電話番号      | 紐付けられた携帯電話番号 |
| 作成日時        | ユーザー作成日時     |
| ユーザー更新日時    | 最終更新日時       |
| 備考          | ユーザー備考情報     |

以下の操作が可能です。

- 【全選択】にチェックを入れすべてのフィールドを同期
- または業務上必要なフィールドのみを選択

## 八、同期設定

### 同期方式の説明

- **同期オフ（デフォルト）**

  データは作成時または手動トリガー時のみ更新
- **同期オン**

  設定した頻度に従って RAM データを自動同期

> 権限が頻繁に変更されるシナリオでは、自動同期を有効化することを推奨します。

## 九、作成完了とデータの確認

1. 右下の【作成】をクリック
2. AI テーブルが Alibaba Cloud RAM データを取得開始
3. 同期完了後、テーブル上でロールまたはユーザーリストを確認可能
4. データはフィルタリング、権限棚卸し、メンバー管理、監査分析などに利用可能

## 十、よくある質問

#### Q1：権限なしまたは取得失敗と表示される場合

- RAM ユーザーに RAM 関連権限が付与されているか確認してください
- AccessKey が正しく入力されているか確認してください

#### Q2：一部のユーザーまたはロールが同期されないのはなぜですか

-
- アカウント配下に該当リソースが存在するか確認してください
- 正しい AccessKey を使用しているか確認してください

#### Q3：AccessKey は安全ですか

- AI テーブルはキーを暗号化して保存します
- キーは現在のデータソース呼び出しのみに使用され、外部に公開されません
