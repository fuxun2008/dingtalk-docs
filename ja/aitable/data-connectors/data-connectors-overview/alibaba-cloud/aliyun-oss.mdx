AI Table は **Aliyun Object Storage Service (OSS) コネクタ**に対応しており、アカウントの OSS バケット情報を AI Table に同期して、一元的に管理・分析できます。

本ガイドでは、次の手順を説明します。

- Aliyun コンソールへのログイン
- AccessKey ID と AccessKey Secret の取得
- AI Table での Aliyun OSS データソースの作成
- パラメータとフィールドの設定、同期の完了

## 1. 事前準備

開始する前に、次の点を確認してください。

- **Aliyun アカウント**を保有していること
- そのアカウントで **OSS サービス**が有効になっていること
- 現在のアカウントが OSS リソースに対して**閲覧以上**の権限を持っていること
- AI Table へのアクセス権があること

> ⚠️ プライマリアカウントのキーではなく、**RAM サブアカウント + AccessKey** の利用を推奨します。

## 2. Aliyun AccessKey の取得

AI Table は AccessKey を介して Aliyun OSS API を呼び出します。まず Aliyun コンソールで AccessKey を作成してください。

### 1. Aliyun コンソールへのログイン

1. Aliyun を開きます：[https://www.aliyun.com](https://www.aliyun.com "https://www.aliyun.com")。
2. 右上の **サインイン** をクリックします。
3. Aliyun アカウントでログインします。

### 2. AccessKey の作成・取得

#### 方法 1：RAM ユーザー（推奨）

1. ログイン後、<strong>RAM（アクセス制御）</strong>を開きます。
2. 左メニューで **ユーザー** を選択します。
3. RAM ユーザーを新規作成するか、既存のユーザーを選択します。
4. ユーザーに権限を付与します（最低でも OSS の閲覧のみ権限、例：`AliyunOSSReadOnlyAccess`）。
5. **認証管理** を開きます。
6. AccessKey を作成します。
7. 以下をコピーして保存します。
   - **AccessKey ID**
   - **AccessKey Secret**

> ⚠️ AccessKey Secret は作成時に一度だけ表示されます。必ず保存してください。

#### 方法 2：既存の AccessKey

すでに AccessKey をお持ちの場合は、**RAM → ユーザー → AccessKey管理** で AccessKey ID を確認できます。必要に応じて Secret を再作成してください。

## 3. AI Table での Aliyun OSS データソースの作成

### 1. Data sync center を開く

1. AI Table を開きます。
2. 左下の **データ同期センター** をクリックします。
3. **Aliyun** を検索します。
4. **Aliyun OSS** を選択します。

### 2. データソースの選択

現在サポートしているデータソースのタイプは次のとおりです。

- **Aliyun OSS バケットリスト**

  現在のアカウント配下にあるすべての OSS バケットの基本情報を同期します。

確認して続行します。

## 4. アカウント設定

Aliyun アカウント情報を連携します。

### フィールド参照

| フィールド | 説明 |
| --- | --- |
| アカウント名 | AI Table 内で複数の Aliyun アカウントを区別するためのカスタムラベル |
| AccessKey ID | Aliyun コンソールから取得 |
| AccessKey Secret | Aliyun コンソールから取得 |

完了したら **確認** をクリックします。

🔒 AI Table はキーを保存時に暗号化し、データ同期にのみ使用します。

## 5. パラメータ

### 1. 地域（必須）

OSS サービスの地域を指定します。

- 例：`cn-hangzhou`、`cn-shanghai`
- OSS API のエンドポイントを決定します。

> バケットが複数の地域にまたがる場合は、地域ごとに 1 つのデータソースを作成してください。

### 2. プレフィックス（任意）

名前のパターンでバケットをフィルタリングします。

- 空欄：アカウント配下のすべてのバケットを同期します。
- プレフィックス指定：名前がプレフィックスで始まるバケットのみを同期します。

例：

- `prod-`：`prod-xxx` バケットのみ同期します。
- `test/`：そのパス配下のリソースを同期します（対応している場合）。

## 6. フィールド

AI Table に同期するフィールドを選択します。

| フィールド | 説明 |
| --- | --- |
| 名前 | OSS バケット名 |
| OSS 固有の Region ID | バケットの実際の地域 |
| Aliyun 共通の Region ID | Aliyun 統一の地域識別子 |
| パブリックアクセスエンドポイント | バケットのパブリックアクセス URL |
| 内部アクセスエンドポイント | バケットの内部アクセス URL |
| バケットのストレージクラス | Standard / Infrequent Access など |
| バケットの作成日時 | バケットが作成された日時 |
| 備考 | 拡張用に予約 |

次のことができます。

- **すべて選択**にチェックを入れて、すべてのフィールドを同期する。
- または業務に関連するフィールドのみを選択する。

## 7. 同期設定

### モード

- **オフ（デフォルト）**：

  作成時または手動更新時にのみデータが更新されます。
- **オン**：

  設定したスケジュールでシステムが OSS データを自動同期します。

> データの更新頻度とユースケースに応じて選択してください。

## 8. 完了 — データの表示

1. 右下の **作成** をクリックします。
2. システムが OSS データを取得します。
3. 完了すると、AI Table で OSS バケットリストを表示できます。
4. このデータをフィルタリング、分析、他のテーブルとの連携に活用できます。

## 9. よくある質問

#### Q1：AccessKey で「権限がありません」と表示されます。原因は何ですか？

- RAM ユーザーが OSS の権限を持っているか確認してください。
- 最低でも OSS の閲覧権限が必要です。

#### Q2：一部のバケットが表示されないのはなぜですか？

- **地域**が一致しているか確認してください。
- プレフィックスフィルタが設定されていないか確認してください。

#### Q3：AccessKey が漏洩することはありませんか？

- AI Table はキーを保存時に暗号化します。
- このデータソースでのみ使用され、外部に公開されることはありません。
