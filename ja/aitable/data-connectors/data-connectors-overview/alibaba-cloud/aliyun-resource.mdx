AI テーブルは「Alibaba Cloud リソース管理」データソースコネクタを通じて、Alibaba Cloud アカウント配下の **リソースタグデータ** を同期できます。AI テーブル上でクラウドリソース、タグ体系、リソース帰属情報を一元管理できます。

本記事では、Alibaba Cloud から AI テーブルへの完全なデータ同期の流れ（アカウントの準備、AccessKey の取得、パラメータ設定、フィールド説明）を解説します。

---
## 一、利用前の準備

開始前に、以下の条件を満たしているかご確認ください。

- Alibaba Cloud アカウントを登録し、正常にログインできること
- アカウントで **リソース管理（Resource Management）** サービスを有効化していること
- 現在のアカウントまたは RAM サブアカウントに、リソース管理関連の読み取り専用権限があること
- AI テーブルの利用権限を保有していること

アカウントの安全のため、**RAM サブアカウント + AccessKey でのデータ接続** を推奨します。マスターアカウントの鍵を直接利用するのは避けてください。

---
## 二、AccessKey ID と AccessKey Secret の取得

AI テーブルは AccessKey を使って Alibaba Cloud のリソース管理 API を呼び出してデータを取得します。事前に Alibaba Cloud コンソールで鍵を作成する必要があります。

### 操作手順

1. Alibaba Cloud 公式サイト（[https://www.aliyun.com](https://www.aliyun.com "https://www.aliyun.com")）を開き、Alibaba Cloud アカウントでログインします。
2. 「アクセスコントロール（RAM）」コンソールに入ります。
3. 左側メニューの「ユーザー」をクリックし、新規 RAM ユーザーを作成するか、既存のユーザーを選択します。
4. そのユーザーに、リソース管理関連の権限（読み取り専用で十分）を付与します。
5. 当該 RAM ユーザーの「認証管理」ページに入り、AccessKey を作成します。
6. 以下の情報をコピーし、適切に保管します。
   - **AccessKey ID**
   - **AccessKey Secret**

> 注：AccessKey Secret は作成時に一度だけ表示されます。すぐに保存してください。

---
## 三、AI テーブルで Alibaba Cloud リソース管理データソースを作成

1. AI テーブルを開きます。
2. 上部の「データコネクタ」をクリックします。
3. 検索ボックスに「Alibaba Cloud」と入力します。
4. 「Alibaba Cloud リソース管理」データソースを選びます。

---
## 四、データソースの設定

「データソース選択」のステップで、現在対応しているデータソースタイプは以下のとおりです。

- **リソースタグ一覧**

  現在のアカウント配下のすべてのクラウドリソースとそのタグ情報を同期します。

選択を確認したら、次のステップへ進みます。

---
## 五、アカウント設定

アカウント設定のステップでは、Alibaba Cloud アカウントの認証情報を入力します。

- **アカウント名**：AI テーブル上で複数の Alibaba Cloud アカウントを区別するための任意の名前
- **AccessKey ID**：Alibaba Cloud コンソールで取得した AccessKey ID
- **AccessKey Secret**：Alibaba Cloud コンソールで取得した AccessKey Secret

入力後、「確認」をクリックします。

> AI テーブルは AccessKey 情報を暗号化して保存し、当該データソースの同期にのみ利用します。

---
## 六、パラメータ設定の説明

### アクセスドメイン / リージョン

リソースデータを同期するリージョン範囲を指定します。

- 例：華北 1（青島）
- リージョンが異なるリソースは個別に同期する必要があります。
- アカウント配下のリソースが複数のリージョンに分散している場合、リージョンごとにデータソースを作成してください。

---
## 七、フィールド設定の説明

業務ニーズに応じて、AI テーブルに同期するフィールドを選択できます。

### 現在対応しているフィールド

| フィールド名   | 説明                    |
| ------ | --------------------- |
| リソース ARN | クラウドリソースのグローバル一意識別子 |
| タグキー    | リソースタグの Key             |
| タグ値    | リソースタグの Value           |
| タグタイプ   | タグのソースタイプ（システムタグ / カスタムタグなど） |

選択方法：

- 「全選択」にチェックを入れて全フィールドを同期する
- 業務に必要なフィールドだけを選び、リソース分類、帰属、コスト分析に利用する

---
## 八、同期設定

- **同期オフ（既定）**

  作成時または手動同期実行時のみ、データが更新されます。
- **同期オン**

  設定した頻度に従って、最新のリソースタグデータが自動同期されます。

リソースの変更が頻繁な場合や、タグ統制のシーンでは、自動同期の有効化を推奨します。

---
## 九、作成完了とデータの確認

1. 右下の「作成」をクリックします。
2. AI テーブルが Alibaba Cloud リソース管理のデータ取得を開始します。
3. 同期完了後、AI テーブルでリソースタグ一覧を確認できます。
4. 次のシーンで活用できます。
   - クラウドリソースの棚卸し
   - タグ規範の統制
   - リソース帰属とコスト分析

---
## 十、よくある質問

### 同期に失敗、または「権限なし」と表示される場合は？

RAM ユーザーにリソース管理関連の権限が付与されているか、AccessKey の入力が正しいかをご確認ください。

### 一部のリソースが同期されないのはなぜですか？

選択したリージョンが正しいかをご確認ください。リージョンが異なるリソースは個別に同期する必要があります。

### AccessKey は安全ですか？

AI テーブルは AccessKey 情報を暗号化して保存し、当該データソースの呼び出しにのみ利用するため、外部に公開されることはありません。
