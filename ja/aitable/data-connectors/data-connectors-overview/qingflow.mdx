## 事前準備：Access Token の取得とアカウント設定

Access Token の取得手順例：

1. Qingflow のショップ - 拡張プラグインにアクセスします：[https://qingflow.com/center/plugin#3](https://qingflow.com/center/plugin#3 "https://qingflow.com/center/plugin#3")。「サードパーティ連携」をクリックし、OPEN API を選んで設定をクリックします。

   ![](/ja/aitable/data-connectors/data-connectors-overview/qingflow/images/image_RIrpz5o4cS.png)

   ![](/ja/aitable/data-connectors/data-connectors-overview/qingflow/images/image_zNtONDjpm9.png)
2. Access Token の取得：スーパー管理者の Access Token はワークスペース作成者の権限を持ち、「コードログ・コメント」以外のすべての openAPI を呼び出せます。サブ管理者権限での取得手順については、「詳細を見る」をクリックして Qingflow の設定ガイドをご覧ください：[https://exiao.yuque.com/ixwxsb/bgzs0e/onnrnp9i7nihz5l8](https://exiao.yuque.com/ixwxsb/bgzs0e/onnrnp9i7nihz5l8 "https://exiao.yuque.com/ixwxsb/bgzs0e/onnrnp9i7nihz5l8")

   ![](/ja/aitable/data-connectors/data-connectors-overview/qingflow/images/image_AQ8Ly769Z7.png)

## データコネクタを開く

AI テーブル左下の「追加 / インポート」ボタンをクリックし、「データコネクタ」を選びます。

![](/ja/aitable/data-connectors/data-connectors-overview/qingflow/images/image_7GDJX22gfM.png)

データコネクタに入ります。

![](/ja/aitable/data-connectors/data-connectors-overview/qingflow/images/image_nC7xX4HUsy.png)

## データソースの選択

**Qingflow** コネクターを選択するか直接検索し、「使用」ボタンをクリックして設定画面を開きます。

![](/ja/aitable/data-connectors/data-connectors-overview/qingflow/images/image_0G--q2S3EO.png)

## データソースの設定

1. **データソースの選択**：データソースにチェックを入れます。現在はデータソースが 1 つのみで、初期状態でチェックされています。
2. **アカウント設定**：アカウント名は任意に設定でき、最初のステップで取得した Access Token を入力します。

   ![](/ja/aitable/data-connectors/data-connectors-overview/qingflow/images/image_1NxLUIlKTr.png)
3. **フィールド設定**：フィールドを全選択するか必要なものにチェックを入れ、テーブルのフィールド範囲を柔軟に設定できます。主キーはチェックを外せません。
4. **同期設定**：データテーブルの同期設定を有効化または無効化できます。有効化すると、毎時同期モードまたは定時同期モードを選択できます。
   - 毎時同期：1 時間ごと、12 時間ごと、24 時間ごとから選べます。
   - 定時同期：毎日、毎週、毎月の決まった時刻を指定して同期できます。祝日をスキップするかも設定可能です。

     ヒント：コネクタの設定中に問題が発生した場合は、**データソース設定ページ - フィードバックを送信**からご報告ください。

![](/ja/aitable/data-connectors/data-connectors-overview/qingflow/images/image_3ITBBayEJu.png)

## 「作成」をクリックしてデータの同期を開始

コネクタの設定が完了したら、「作成」をクリックしてデータ同期を開始します。作成に成功すると、データ同期テーブルが自動で 1 つ追加されます。

## 同期後の操作

1. **データ同期設定の変更**

   同期設定済みのデータテーブルで設定を変更したい場合は、データ同期テーブル右側のアイコンをクリックし、「データ同期設定」を選びます。同期するフィールド項目や同期方法の変更、自動同期の有効化・無効化が行えます。
2. **手動での同期更新**

   同期されたデータテーブルをクリックし、テーブル名右側の「⋮ その他の操作」アイコンをクリックします。「データを更新」をクリックすると手動同期が始まり、データソースのデータを再取得してテーブルを更新します。
3. **同期関係の解除**

   「同期関係を解除」をクリックすると、同期テーブルが編集可能なテーブルに変わり、元のデータソースとの同期関係はなくなります。
