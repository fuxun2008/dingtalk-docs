  推奨：まず[Data sync center](/aitable/data-connectors/data-connectors-overview)を確認して基本を理解してから進めてください。

## 準備：アカウント設定用のアクセストークンを取得する

アクセストークンの取得手順：

1. Qingflowを開く → プラグインセンター：[https://qingflow.com/center/plugin#3](https://qingflow.com/center/plugin#3 "https://qingflow.com/center/plugin#3")。**サードパーティコネクタ** → **OPEN API** → **設定** の順にクリックします。

2. アクセストークンを取得：スーパー管理者のアクセストークンはワークスペース作成者権限を持ち、`code登评论`（コメント登録）を除くすべてのopenAPIエンドポイントを呼び出せます。サブ管理者の権限スコープについては、**詳細を見る** をクリックし、Qingflowの完全な設定をご確認ください：[https://exiao.yuque.com/ixwxsb/bgzs0e/onnrnp9i7nihz5l8](https://exiao.yuque.com/ixwxsb/bgzs0e/onnrnp9i7nihz5l8 "https://exiao.yuque.com/ixwxsb/bgzs0e/onnrnp9i7nihz5l8")。

## Data sync centerを開く

AI Tableの左下で、**追加 / インポート** → **Data sync center** の順にクリックします。

Data sync centerを開きます。

## データソースを選択する

**Qingflow** コネクタを選択または検索し、**使用** をクリックしてコネクタ設定に入ります。

## データソース設定

1. **データソースの選択**：利用できるソースは1つのみで、デフォルトで選択されています。
2. **アカウント設定**：名前は任意です。手順1で取得したアクセストークンを貼り付けます。

3. **フィールド**：すべて／一部のフィールドを選択します。主キーは選択を外せません。
4. **同期設定**：同期のオン／オフを切り替えます。オンの場合は **毎時** または **定時** を選択します：
   - **毎時**：1／12／24時間ごと。
   - **定時**：毎日／毎週／毎月の固定時刻。祝日をスキップするよう設定できます。

     ヒント：コネクタ設定中に問題が発生した場合は、**データソースページ → フィードバックを送信** から通報してください。

## 作成をクリックして同期を開始する

コネクタの設定が完了したら、**作成** をクリックして同期を開始します。成功すると、新しい同期テーブルが自動的に追加されます。

## 同期後の操作

1. **同期設定の編集**

   既存の同期テーブルで、右側のアイコンをクリック → **データ同期設定** で、同期フィールド、同期方式の変更、または自動同期のオン／オフの切り替えができます。
2. **手動更新**

   同期テーブルを開き、テーブル名の横にある ⋮ その他アイコンをクリック → **データを更新** で、ソースから手動で再取得して更新します。
3. **同期関係の解除**

   **同期を解除** をクリックすると、同期テーブルが編集可能になり、ソースに追従しなくなります。
