  まず データコネクタ を確認し、データコネクタの基本機能を理解したうえで以下の操作を行うことをおすすめします。

## 利用前の準備

本コネクタを利用する前に、Tapd の【会社管理】ポータルで API アカウントを開通し、**API アカウント**と **API シークレット**、および同期したいデータの **プロジェクト ID** を取得する必要があります。これらは AI テーブルが Tapd データを読み取る権限を付与するために使用します。

> Tapd API は Tapd の有償モジュールで、**Tapd 企業版**のみが対応しています。**会社管理者**は【**会社管理**】 → 【**オープン連携**】 → 【**API アカウント管理**】から 90 日間の試用を申請できます。

1. API アカウントと API シークレットを申請して確認します。会社管理者アカウントで Tapd にログインし、【**会社管理**】 → 【**オープン連携**】 → 【**API アカウント管理**】の順に進み、API アカウントの申請と開通を行います。開通が完了すると、企業の **API アカウント**と **API シークレット**を確認できます。

![](/ja/aitable/data-connectors/data-connectors-overview/tapd/images/截屏2026-05-08%2021.20.51_hop2TiZm8h.png)

![](/ja/aitable/data-connectors/data-connectors-overview/tapd/images/截屏2026-05-08%2021.24.10_kI1xgTe6g2.png)

> **ご注意**：API アカウントと API シークレットは対応する企業プロジェクトデータへのアクセス権限を持つため、外部に漏れないよう適切に保管してください。無効化が必要な場合は【API アカウント管理】から該当の API シークレットをリセットでき、リセット後は元のシークレットがただちに失効します。

1. プロジェクト ID を取得します。各データソース同期タスクには **プロジェクト ID** の指定が必要で、コネクタにどのプロジェクト空間のデータを同期するかを伝えます。Tapd にログイン後、対応するプロジェクト空間に入り、ページ右上の【**設定**】 → 【**基本情報**】 → 【**プロジェクト情報**】の順にクリックすると、プロジェクト ID を確認できます。

![](/ja/aitable/data-connectors/data-connectors-overview/tapd/images/截屏2026-05-09%2010.34.43_-F17ANiUNK.png)

![](/ja/aitable/data-connectors/data-connectors-overview/tapd/images/截屏2026-05-09%2010.36.43_rM7_MkSHF_.png)

![](/ja/aitable/data-connectors/data-connectors-overview/tapd/images/截屏2026-05-09%2010.38.17_s9SWkaMP_n.png)

> 1 つのデータソースで設定できるプロジェクト ID は 1 つのみです。複数プロジェクトのデータを同期する場合は、データソースを繰り返し作成してください。

## データソースを選択する

AI テーブルの **データコネクタ** に移動し、**Tapd** コネクタを検索して【**使用**】ボタンをクリックすると、コネクタ設定画面に進みます。

![](/ja/aitable/data-connectors/data-connectors-overview/tapd/images/截屏2026-05-09%2010.42.01_JBHpZsE2mr.png)

## データソースを設定する

1. **Tapd アカウントを連携**します。初回利用時は【**アカウントを連携**】ボタンをクリックし、表示されるダイアログで API アカウントと API シークレットを入力します。

![](/ja/aitable/data-connectors/data-connectors-overview/tapd/images/截屏2026-05-08%2021.45.47_qRTdh2bslW.png)

入力後【**確定**】をクリックすると、アカウント情報が現在のデータソースに保存されます。以降はデータソースページのアカウントカードから **アカウント切り替え** や **アカウント情報の編集** が可能です。

1. **同期するデータテーブルを選択**します。1 回のデータソース設定で選択できるデータテーブルは 1 つのみです。複数のデータテーブルを同期する場合は、データソースを繰り返し作成してください。本コネクタが現在対応しているデータテーブルは以下のとおりです：

| データテーブル | 説明 |
| --------- | ------------------ |
| Tapd イテレーション一覧 | 指定プロジェクト内で検索条件に合致するすべてのイテレーションを同期 |
| Tapd バグ一覧 | 指定プロジェクト内で検索条件に合致するすべてのバグを同期 |
| Tapd 要件一覧 | 指定プロジェクト内で検索条件に合致するすべての要件を同期 |
| Tapd タスク一覧 | 指定プロジェクト内で検索条件に合致するすべてのタスクを同期 |

データテーブルを選択すると、コネクタは対応するデータテーブル設定を自動でロードします。必要に応じてデータソースから取得する内容を選択してください。

1. **フィールド設定**。同期したいフィールドを必要に応じてチェックします。主キーフィールドはデフォルトでチェック済みで、解除はできません。

## 作成をクリックしてデータ同期を開始する

上記の設定が完了したら【**保存して同期**】ボタンをクリックします。コネクタがデータ同期を実行します。

![](/ja/aitable/data-connectors/data-connectors-overview/tapd/images/截屏2026-05-08%2021.50.22_3N1KyHauux.png)

## 作成完了後にデータを確認する

同期完了後、AI テーブル左側のデータテーブル一覧に新しく作成されたデータテーブルが表示されます。このテーブルは「同期テーブル」として存在し、以降は次の操作が可能です：

- **データ同期設定の変更**

  データテーブル右側の その他の操作 メニューから【データ同期設定】を選ぶと、チェックしたフィールドや同期パラメータを調整できます。
- **手動で同期を更新**

  データテーブル右側の その他の操作 メニューから【データを更新】をクリックすると、コネクタがただちに Tapd の API を再呼び出しして現在のテーブルデータを更新します。
- **同期関係を解除**

  データテーブル右側の その他の操作 メニューから【同期関係を解除】をクリックすると、同期テーブルは通常の編集可能テーブルに変換され、Tapd データソースとの同期は停止します。
- **カスタムフィールドを追加**

  同期フィールドに影響を与えない範囲で、AI テーブルにカスタムフィールド（メモ、タグ、AI フィールドなど）を追加できます。カスタムフィールドが同期操作で上書きされることはありません。
