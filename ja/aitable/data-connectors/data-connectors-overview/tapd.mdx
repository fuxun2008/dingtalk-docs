  まずはデータ同期センターを確認してコネクタの基礎を理解してから、操作を進めることをおすすめします。

## 事前準備

このコネクタを使用する前に、TAPDの**企業管理**バックエンドで API アカウントを有効化し、**API アカウント**と**API シークレット**を1組取得してください。さらに、同期したいプロジェクトの**プロジェクトID**も取得します。これにより、AI Table が TAPD のデータを読み取る権限が付与されます。

> 📌 TAPD API は TAPD の商用モジュールであり、**TAPD Enterprise** でのみ利用できます。**企業管理者**は、**企業管理 → オープン連携 → API アカウント管理**から90日間の Trial を申請できます。

1. API アカウント／API シークレットの申請と確認。企業管理者として TAPD にログインし、**企業管理 → オープン連携 → API アカウント管理**で申請して有効化します。有効化すると、組織の **API アカウント**と **API シークレット**を確認できます。

> 📌 **注意**：API アカウントと API シークレットは組織のすべてのプロジェクトデータにアクセスできます。安全に管理し、漏洩させないでください。無効化するには、**API アカウント管理**で API シークレットをリセットします。リセットすると、元のシークレットは即座に有効になります。

1. プロジェクトIDの取得。各データソースの同期タスクには、コネクタにどのプロジェクトスペースから同期するかを指定するための**プロジェクトID**が必要です。TAPD にログインし、対象のプロジェクトスペースを開いて、右上の**設定 → 基本情報 → プロジェクト情報**でプロジェクトIDを確認します。

> 📌 1つのデータソースで対応できるプロジェクトIDは1つのみです。複数のプロジェクトのデータを同期するには、データソースの作成を繰り返してください。

## データソースの選択

AI Table → **データ同期センター**で **TAPD** を検索し、**使用**をクリックしてコネクタの設定画面に入ります。

## データソース設定

1. **TAPD アカウントの連携**：初回利用時は、**アカウントを連携**をクリックし、ダイアログで API アカウントと API シークレットを入力します。

入力後、**OK** をクリックすると、アカウント情報が現在のデータソースに保存されます。その後は、データソースページのアカウントカードから**アカウントの切り替え**や**アカウント情報の編集**を行えます。

1. **同期するデータテーブルの選択**：各データソース設定で対応できるテーブルは1つのみです。複数のテーブルを同期するには、データソースの作成を繰り返してください。現在対応しているテーブルは次のとおりです。

| データテーブル | 説明 |
| --- | --- |
| TAPD イテレーションリスト | 指定したプロジェクト内で、クエリ条件に一致するすべてのイテレーションを同期します |
| TAPD バグリスト | 指定したプロジェクト内で、クエリ条件に一致するすべてのバグを同期します |
| TAPD ストーリーリスト | 指定したプロジェクト内で、クエリ条件に一致するすべてのストーリーを同期します |
| TAPD タスクリスト | 指定したプロジェクト内で、クエリ条件に一致するすべてのタスクを同期します |

テーブルを選択すると、コネクタがその設定を自動的に読み込みます。取得したいデータのスコープを選択してください。

1. **フィールド**：同期したいフィールドを選択します。プライマリキーはデフォルトで選択されており、選択を解除できません。

## 作成をクリックして同期を開始

上記の設定が完了したら、**保存して同期**をクリックすると、コネクタが同期を開始します。

## 完了 — データの確認

同期が完了すると、新しいテーブルが AI Table の左サイドバーに表示されます。このテーブルは「同期テーブル」として存在し、次の操作に対応しています。

- **同期設定の編集**

  データテーブル右側のその他メニューで**データ同期設定**を選択すると、フィールドの選択や同期パラメータを調整できます。
- **手動更新**

  データテーブル右側のその他メニューで**データを更新**をクリックすると、コネクタが即座に TAPD API を再呼び出しし、現在のテーブルを更新します。
- **同期関係の解除**

  データテーブル右側のその他メニューで**同期を解除**をクリックすると、同期テーブルが通常の編集可能なテーブルになり、TAPD ソースに追従しなくなります。
- **カスタムフィールドの追加**

  同期されたフィールドに影響を与えることなく、AI Table でカスタムフィールド（メモ、タグ、AI フィールドなど）を追加できます。カスタムフィールドは同期によって上書きされません。
