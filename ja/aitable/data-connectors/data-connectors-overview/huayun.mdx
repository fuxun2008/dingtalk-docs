## 利用前の準備

始める前に、以下の条件を満たしていることをご確認ください。

| \# | 条件 | 説明 |
| --- | --- | --- |
| 1 | 氚雲**プロフェッショナル版**以上 | **カスタム API** 機能が有効化されていること（基本版はバックエンドコードに非対応） |
| 2 | 氚雲**システム管理者**アカウント | **システム管理 → システム連携** から認証情報を取得する必要があります |
| 3 | AI テーブルへのアクセス権限 | AI テーブルでデータソースを作成します |

> 注意：最初の 4 ステップ（利用前の準備〜バックエンドコードのデプロイ）は **氚雲の管理画面** で行います。最後の 1 ステップ（AI テーブル側でデータソースを設定）は **AI テーブル** での操作です。ブラウザのウィンドウを 2 つ開いておくと便利です。

---
## 氚雲の EngineCode と Secret を取得する

EngineCode と Secret は、氚雲があなたに発行する **アクセストークン** に相当します。AI テーブルはこの情報を使って氚雲のデータ API を呼び出します。

### システム管理に入る

氚雲の管理画面にログイン後、以下の手順で進めます。

1. 右上の**アバター**をクリックします。
2. ドロップダウンメニューから **システム管理** を選択します。

![システム管理の入口](/ja/aitable/data-connectors/data-connectors-overview/huayun/images/S1-系统管理入口_YxRdWe9_pL.png)

### EngineCode と Secret を確認する

システム管理の左側メニューで **システム連携** をクリックすると、右側の **企業情報** カードに **EngineCode** と **Secret** が表示されます。

![システム連携 - EngineCode](/ja/aitable/data-connectors/data-connectors-overview/huayun/images/S2-系统集成-EngineCode_aDym7gE7gm.png)

> コピーのコツ：EngineCode と Secret のフィールドにマウスをかざすとコピーボタンが表示されます。それぞれコピーして安全な場所に保管してください。**関係のない第三者に絶対に共有しないでください**。

> セキュリティに関する注意：Secret は機密性の高い認証情報です。**リセット** ボタンをクリックすると、旧 Secret は即座に無効化され、設定済みの AI テーブルデータソースも再設定が必要になります。

## アプリケーションコード（AppCode）を取得する

AppCode は、AI テーブルに対して **氚雲のどのアプリと同期するか** を指示するために使用します。

### 対象アプリに入る

氚雲管理画面のホームで、同期したい**対象アプリ**をクリックして、アプリのトップページに移動します。

### アプリ設定を開く

アプリのトップページに入ったら、左側メニュー**最下部**の **アプリ設定** をクリックします。

![アプリトップページ - アプリ設定への入口](/ja/aitable/data-connectors/data-connectors-overview/huayun/images/获取AppCode1_MxAND39mlU.png)

> 別の方法：ブラウザのアドレスバーが見やすい方には、**アプリトップページ URL の `/application/` 以降の文字列がそのまま AppCode** です（上図の赤枠を参照）。直接コピーしてご利用いただけます。

### アプリケーションコードをコピーする

アプリ設定ページの **基本情報** タブに **アプリケーションコード** フィールドが表示されますので、コピーして保存してください。

![アプリ設定 - アプリケーションコード](/ja/aitable/data-connectors/data-connectors-overview/huayun/images/S4-应用配置-应用编码_AolgC-YSym.png)

> 混同にご注意：**アプリ名称** は人間が読むための日本語名で、**アプリケーションコード** こそが AI テーブルで必要となる文字列です。

## バックエンドコードのデプロイ（重要ステップ）

> このステップは、AI テーブルが氚雲フォームのフィールドメタデータを読み取れるようにするために必要です。氚雲の標準 API には **フィールド定義** を返すエンドポイントがないため、氚雲管理画面に **カスタムインターフェース** のコードを手動でデプロイしていただきます（**コードはご用意済みなので、コピー＆ペーストするだけです**）。

### フォームデザインに入る

対象アプリ内で、**任意のフォームを 1 つ選択**します（シンプルで頻繁に変更されないフォームを **コードの設置先フォーム** として選ぶことをお勧めします）。フォームページ右上の **フォームをデザイン** ボタンをクリックします。

![フォームデザインの入口](/ja/aitable/data-connectors/data-connectors-overview/huayun/images/S5-设计表单按钮_Hpa3yT70Bx.png)

> どのフォームでも問題ありません：バックエンドコードはそのフォーム自体の業務機能には影響しません。あくまでフォームの入口を **借りて** コードをデプロイするだけです。

### **バックエンドコード** タブに切り替える

フォームデザインに入ると、左上はデフォルトで **グラフィックデザイン** タブになっています。**バックエンドコード** タブに切り替えてください。

![バックエンドコード タブ](/ja/aitable/data-connectors/data-connectors-overview/huayun/images/S6-后端代码Tab_vSDKaeKQ3o.png)

### コード全文を貼り付ける

エディタ内の**デフォルトのクラスコードはそのまま残し**、**デフォルトコードの下に**、以下のコードを丸ごと貼り付けてください。

> 注意：氚雲のバックエンドコードは `using` / `import` 文に対応していません。すべてのシステム型はフルパス指定が必要です。下記のコードはこの仕様に対応済みのため、**using 文の追加・削除はしないでください**。

```c# 
// ========================================
// AI表格数据源连接器 - 自定义接口
// 支持的 ActionName：
//   1. GetAppList    - 获取所有应用列表（NodeType=190）
//   2. GetFormList   - 获取指定应用下的表单列表（NodeType IN 200,210）
//   3. GetFieldMeta  - 获取表单字段元数据（编码→名称→类型，含关联表单信息）
//   4. GetUserInfo        - 批量查询用户详细信息（Name/Mobile/Position/Email 等）
//   5. GetBizObjectNames  - 批量根据 ObjectId 查询业务表的 Name 字段（用于关联字段反查可读名称）
// 
// 使用方法：将此代码粘贴到任意表单的「后端代码」中，放在默认类代码下方，保存即可。
// ========================================

public class FieldMetaController: H3.SmartForm.RestApiController
{
    public FieldMetaController(H3.SmartForm.RestApiRequest request): base(request) { }

    protected override void OnInvoke(string actionName, H3.SmartForm.RestApiResponse response)
    {
        try
        {
            if(actionName == "GetAppList")
            {
                HandleGetAppList(response);
            }
            else if(actionName == "GetFormList")
            {
                HandleGetFormList(response);
            }
            else if(actionName == "GetFieldMeta")
            {
                HandleGetFieldMeta(response);
            }
            else if(actionName == "GetUserInfo")
            {
                HandleGetUserInfo(response);
            }
            else if(actionName == "GetBizObjectNames")
            {
                HandleGetBizObjectNames(response);
            }
            else
            {
                response.ReturnData.Add("result", "error");
                response.ReturnData.Add("message", "未知的 actionName: " + actionName + "。支持: GetAppList, GetFormList, GetFieldMeta, GetUserInfo");
            }
        }
        catch(System.Exception ex)
        {
            response.ReturnData.Add("result", "error");
            response.ReturnData.Add("message", "接口异常: " + ex.Message);
        }
    }

    // -------------------------------------------------------------------------
    // GetAppList - 获取所有应用列表（NodeType=190）
    // -------------------------------------------------------------------------
    private void HandleGetAppList(H3.SmartForm.RestApiResponse response)
    {
        string sql = "SELECT ObjectId, DisplayName, Code FROM H_FunctionNode WHERE NodeType = 190 ORDER BY DisplayName";
        System.Data.DataTable dt = this.Request.Engine.Query.QueryTable(sql, null);

        System.Collections.Generic.List < System.Collections.Generic.Dictionary < string, string >> appList
        = new System.Collections.Generic.List<System.Collections.Generic.Dictionary<string, string>>();

        if(dt != null && dt.Rows.Count > 0)
        {
            foreach(System.Data.DataRow row in dt.Rows)
            {
                System.Collections.Generic.Dictionary < string, string > appInfo
                = new System.Collections.Generic.Dictionary<string, string>();
                appInfo.Add("objectId", row["ObjectId"] + "");
                appInfo.Add("displayName", row["DisplayName"] + "");
                appInfo.Add("appCode", row["Code"] + "");
                appList.Add(appInfo);
            }
        }

        response.ReturnData.Add("result", "success");
        response.ReturnData.Add("totalCount", appList.Count);
        response.ReturnData.Add("apps", appList);
    }

    // -------------------------------------------------------------------------
    // GetFormList - 获取指定应用下的表单列表（NodeType IN 200,210）
    // 支持 TargetAppCode 参数：Invoke 路由用 AppCode，业务查询用 TargetAppCode
    // 兼容旧调用：如果没有 TargetAppCode，回退到 AppCode
    // -------------------------------------------------------------------------
    private void HandleGetFormList(H3.SmartForm.RestApiResponse response)
    {
        // 优先从 TargetAppCode 取业务查询的目标应用编码
        string appCode = this.Request.GetValue<string>("TargetAppCode", "");
        if(string.IsNullOrEmpty(appCode))
        {
            appCode = this.Request.GetValue<string>("AppCode", "");
        }
        if(string.IsNullOrEmpty(appCode))
        {
            response.ReturnData.Add("result", "error");
            response.ReturnData.Add("message", "TargetAppCode 或 AppCode 不能为空");
            return;
        }

        // NodeType=200 普通表单, NodeType=210 流程表单
        string sql = "SELECT ObjectId, DisplayName, Code, AppCode FROM H_FunctionNode WHERE AppCode = '" + appCode + "' AND NodeType IN (200, 210) ORDER BY NodeType, DisplayName";
        System.Data.DataTable dt = this.Request.Engine.Query.QueryTable(sql, null);

        System.Collections.Generic.List < System.Collections.Generic.Dictionary < string, string >> formList
        = new System.Collections.Generic.List<System.Collections.Generic.Dictionary<string, string>>();

        if(dt != null && dt.Rows.Count > 0)
        {
            foreach(System.Data.DataRow row in dt.Rows)
            {
                System.Collections.Generic.Dictionary < string, string > formInfo
                = new System.Collections.Generic.Dictionary<string, string>();
                formInfo.Add("objectId", row["ObjectId"] + "");
                formInfo.Add("displayName", row["DisplayName"] + "");
                formInfo.Add("code", row["Code"] + "");
                formInfo.Add("appCode", row["AppCode"] + "");
                formList.Add(formInfo);
            }
        }

        response.ReturnData.Add("result", "success");
        response.ReturnData.Add("totalCount", formList.Count);
        response.ReturnData.Add("forms", formList);
    }

    // -------------------------------------------------------------------------
    // GetFieldMeta - 获取表单字段元数据
    // 增强：当字段类型为 Association/AssociationArray 时，额外返回关联表单编码
    // -------------------------------------------------------------------------
    private void HandleGetFieldMeta(H3.SmartForm.RestApiResponse response)
    {
        string schemaCode = this.Request.GetValue<string>("SchemaCode", "");
        if(string.IsNullOrEmpty(schemaCode))
        {
            response.ReturnData.Add("result", "error");
            response.ReturnData.Add("message", "SchemaCode 不能为空");
            return;
        }

        // 获取表单的 Schema 定义
        H3.DataModel.BizObjectSchema schema =
            this.Request.Engine.BizObjectManager.GetPublishedSchema(schemaCode);

        if(schema == null)
        {
            response.ReturnData.Add("result", "error");
            response.ReturnData.Add("message", "未找到表单: " + schemaCode);
            return;
        }

        // 遍历所有字段属性
        H3.DataModel.PropertySchema[] properties = schema.Properties;
        System.Collections.Generic.List < System.Collections.Generic.Dictionary < string, string >> fieldList
        = new System.Collections.Generic.List<System.Collections.Generic.Dictionary<string, string>>();

        foreach(H3.DataModel.PropertySchema prop in properties)
        {
            System.Collections.Generic.Dictionary < string, string > fieldInfo
            = new System.Collections.Generic.Dictionary<string, string>();
            fieldInfo.Add("code", prop.Name);                        // 控件编码，如 F0000001
            fieldInfo.Add("displayName", prop.DisplayName);          // 控件名称，如 订单编号
            fieldInfo.Add("dataType", prop.DataType + "");              // 数据类型，如 ShortString, DateTime
            // 在遍历 properties 构建 fieldInfo 时，额外检查关联表单
            string dt = prop.DataType + "";
            if(dt == "Association" || dt == "AssociationArray")
            {
                string assocCode = "";
                try
                {
                    assocCode = prop.AssociationSchemaCode;
                }
                catch(System.Exception) { }
                if(assocCode == null) { assocCode = ""; }
                fieldInfo.Add("associationSchemaCode", assocCode);

                string childCode = "";
                try
                {
                    if(prop.ChildSchema != null)
                    {
                        childCode = prop.ChildSchema.SchemaCode;
                    }
                }
                catch(System.Exception) { }
                if(childCode == null) { childCode = ""; }
                fieldInfo.Add("childSchemaCode", childCode);
            }
            fieldList.Add(fieldInfo);
        }

        response.ReturnData.Add("result", "success");
        response.ReturnData.Add("schemaCode", schemaCode);
        response.ReturnData.Add("totalCount", fieldList.Count);
        response.ReturnData.Add("fields", fieldList);
    }

    // -------------------------------------------------------------------------
    // GetUserInfo - 批量查询用户详细信息
    // 入参: UserIds (逗号分隔的 ObjectId 列表)
    // 返回: 用户列表，包含 Name, Mobile, Position, Email, EmployeeNumber, DingId, State
    // -------------------------------------------------------------------------
    private void HandleGetUserInfo(H3.SmartForm.RestApiResponse response)
    {
        string userIds = this.Request.GetValue<string>("UserIds", "");
        if(string.IsNullOrEmpty(userIds))
        {
            response.ReturnData.Add("result", "error");
            response.ReturnData.Add("message", "UserIds 不能为空");
            return;
        }

        // 拆分并构建 IN 子句
        // 防注入措施：移除单引号 + 限制长度（UUID 标准长度 36 字符）
        // 注：氚云 QueryTable 不支持参数化查询，只能用字符串拼接
        string[] idArray = userIds.Split(',');
        System.Collections.Generic.List < string > safeIds = new System.Collections.Generic.List<string>();
        foreach(string rawId in idArray)
        {
            string trimmedId = rawId.Trim();
            if(!string.IsNullOrEmpty(trimmedId) && trimmedId.Length <= 40)
            {
                safeIds.Add("'" + trimmedId.Replace("'", "") + "'");
            }
        }

        if(safeIds.Count == 0)
        {
            response.ReturnData.Add("result", "success");
            response.ReturnData.Add("totalCount", 0);
            response.ReturnData.Add("users", new System.Collections.Generic.List<object>());
            return;
        }

        string inClause = string.Join(",", safeIds.ToArray());
        string sql = "SELECT ObjectId, Name, Mobile, Position, Email, EmployeeNumber, DingId, State, ParentId FROM H_User WHERE ObjectId IN (" + inClause + ")";
        System.Data.DataTable dt = this.Request.Engine.Query.QueryTable(sql, null);

        System.Collections.Generic.List < System.Collections.Generic.Dictionary < string, string >> userList
        = new System.Collections.Generic.List<System.Collections.Generic.Dictionary<string, string>>();

        if(dt != null && dt.Rows.Count > 0)
        {
            foreach(System.Data.DataRow row in dt.Rows)
            {
                System.Collections.Generic.Dictionary < string, string > userInfo
                = new System.Collections.Generic.Dictionary<string, string>();
                userInfo.Add("objectId", row["ObjectId"] + "");
                userInfo.Add("name", row["Name"] + "");
                userInfo.Add("mobile", row["Mobile"] + "");
                userInfo.Add("position", row["Position"] + "");
                userInfo.Add("email", row["Email"] + "");
                userInfo.Add("employeeNumber", row["EmployeeNumber"] + "");
                userInfo.Add("dingId", row["DingId"] + "");
                userInfo.Add("state", row["State"] + "");
                userInfo.Add("parentId", row["ParentId"] + "");
                userList.Add(userInfo);
            }
        }

        response.ReturnData.Add("result", "success");
        response.ReturnData.Add("totalCount", userList.Count);
        response.ReturnData.Add("users", userList);
    }
    // -------------------------------------------------------------------------
    // GetBizObjectNames - 批量根据 ObjectId 查询业务表的 Name 字段
    // 入参:
    //   - SchemaCode (必填): 业务表单编码（如 D146656stuu9sfosulmfmahjf）
    //   - ObjectIds  (必填): 逗号分隔的 ObjectId 列表，单次最多 200 个
    // 返回: { result, schemaCode, totalCount, names: [{objectId, name}, ...] }
    //
    // 使用场景: 当 AI 表格连接器同步主表数据，发现关联字段值是 ObjectId 时，
    //           调用此接口批量反查关联表的 Name 字段，用于在 AI 表格中展示可读的关联名称。
    //
    // 实现说明:
    //   - 业务表的物理表名规则为 i_<SchemaCode>（来源：氚云官方 SQL 接口文档）
    //   - 防注入: ObjectId 长度受限 ≤ 40 字符 + 移除单引号；SchemaCode 限制为字母数字
    //   - 与 GetUserInfo 同样使用 QueryTable，氚云不支持参数化查询，只能字符串拼接
    // -------------------------------------------------------------------------
    private void HandleGetBizObjectNames(H3.SmartForm.RestApiResponse response)
    {
        string schemaCode = this.Request.GetValue<string>("SchemaCode", "");
        string objectIds = this.Request.GetValue<string>("ObjectIds", "");

        if(string.IsNullOrEmpty(schemaCode))
        {
            response.ReturnData.Add("result", "error");
            response.ReturnData.Add("message", "SchemaCode 不能为空");
            return;
        }
        if(string.IsNullOrEmpty(objectIds))
        {
            response.ReturnData.Add("result", "error");
            response.ReturnData.Add("message", "ObjectIds 不能为空");
            return;
        }

        // SchemaCode 防注入：仅允许字母、数字（业务表 schemaCode 形如 D146656xxx，全部字母数字）
        bool schemaCodeValid = true;
        foreach(char c in schemaCode)
        {
            if(!char.IsLetterOrDigit(c)) { schemaCodeValid = false; break; }
        }
        if(!schemaCodeValid || schemaCode.Length > 64)
        {
            response.ReturnData.Add("result", "error");
            response.ReturnData.Add("message", "SchemaCode 格式非法，仅允许字母数字");
            return;
        }

        // 拆分并构建 IN 子句（与 GetUserInfo 同模式：长度 ≤ 40 + 移除单引号）
        string[] idArray = objectIds.Split(',');
        System.Collections.Generic.List < string > safeIds = new System.Collections.Generic.List<string>();
        foreach(string rawId in idArray)
        {
            string trimmedId = rawId.Trim();
            if(!string.IsNullOrEmpty(trimmedId) && trimmedId.Length <= 40)
            {
                safeIds.Add("'" + trimmedId.Replace("'", "") + "'");
            }
            // 单次上限 200 个，避免 SQL IN 子句过长
            if(safeIds.Count >= 200) { break; }
        }

        if(safeIds.Count == 0)
        {
            response.ReturnData.Add("result", "success");
            response.ReturnData.Add("schemaCode", schemaCode);
            response.ReturnData.Add("totalCount", 0);
            response.ReturnData.Add("names", new System.Collections.Generic.List<object>());
            return;
        }

        string inClause = string.Join(",", safeIds.ToArray());
        string tableName = "i_" + schemaCode;
        string sql = "SELECT ObjectId, Name FROM " + tableName + " WHERE ObjectId IN (" + inClause + ")";

        System.Data.DataTable dt = null;
        try
        {
            dt = this.Request.Engine.Query.QueryTable(sql, null);
        }
        catch(System.Exception ex)
        {
            // 表名不存在或 SQL 异常：返回明确错误码，调用方据此降级到串行单条查询
            response.ReturnData.Add("result", "error");
            response.ReturnData.Add("errorCode", "SQL_FAILED");
            response.ReturnData.Add("message", "查询失败（表名规则可能不匹配）: " + ex.Message);
            return;
        }

        System.Collections.Generic.List < System.Collections.Generic.Dictionary < string, string >> nameList
        = new System.Collections.Generic.List<System.Collections.Generic.Dictionary<string, string>>();

        if(dt != null && dt.Rows.Count > 0)
        {
            foreach(System.Data.DataRow row in dt.Rows)
            {
                System.Collections.Generic.Dictionary < string, string > item
                = new System.Collections.Generic.Dictionary<string, string>();
                item.Add("objectId", row["ObjectId"] + "");
                item.Add("name", row["Name"] + "");
                nameList.Add(item);
            }
        }

        response.ReturnData.Add("result", "success");
        response.ReturnData.Add("schemaCode", schemaCode);
        response.ReturnData.Add("totalCount", nameList.Count);
        response.ReturnData.Add("names", nameList);
    }
}

```

## AI テーブル側でデータソースを設定する

以上の 4 ステップで、氚雲管理画面側の **認証情報・AppCode・バックエンドインターフェース** がすべて揃いました。続いて AI テーブル側に戻り、データソースを接続します。

### 氚雲データソースを新規作成する

AI テーブルで **+ 新規データソース → 氚雲を選択または検索** をクリックすると、氚雲データソースの設定ダイアログが表示されます。

> ヘッダーの案内：ダイアログ上部の **完全ガイドを表示** リンクは本ドキュメントへの導線です。あとからいつでも参照できます。

### 氚雲アカウントを連携する

初回利用時は、**連携アカウント** のドロップダウンから **新規アカウント** をクリックすると、**アカウント編集** ダイアログが表示されます。

1. **アカウント名**：識別しやすい名前を自由に設定します（例：**氚雲 - 本番環境**）。
2. **EngineCode**：[前のステップで取得した EngineCode](#vg9CseQ4UQE3E7J53FMJZ8 "前のステップで取得した EngineCode") を貼り付けます。
3. **EngineSecret**：[前のステップで取得した Secret](#vg9CseQ4UQE3E7J53FMJZ8 "前のステップで取得した Secret") を貼り付けます。
4. **接続テスト** をクリックし、**接続に成功しました** と表示されたら保存します。

![アカウント連携](/ja/aitable/data-connectors/data-connectors-overview/huayun/images/image_9rL53dVrtX.png)

> 同一アカウントは複数のデータソースで使い回せます。データソースごとに新規作成する必要はありません。

### アプリとフォームを選択する

アカウント連携後、メインダイアログに戻ります。

1. **アプリケーションコード AppCode**：[前のステップでバックエンドコードをデプロイしたアプリの AppCode](#jdQAZkzc6zpNowqvJYjnAm "前のステップでバックエンドコードをデプロイしたアプリの AppCode") を貼り付けます。
2. **アプリを読み込む** をクリックします。

![](/ja/aitable/data-connectors/data-connectors-overview/huayun/images/image_IruprpriFt.png)

1. **アプリ一覧**：当該アカウントがアクセス権を持つすべてのアプリが自動的に読み込まれます。
2. **フォーム**：同期したい対象フォームを選択します（**バックエンドコードの設置先** ではなく、実際にデータを取得したいフォームです）。
3. 同期オプションを設定し、**確定** をクリックします。

成功すると、AI テーブルが自動的に初回同期を開始します。以降は設定した頻度で自動的に増分同期が行われます。

## よくある質問（FAQ）

#### Q：**接続テストに失敗した場合は？**

A：

- EngineCode と Secret が完全にコピーされているかご確認ください（前後に空白が入っていないか注意）。
- 氚雲アカウントが無効化されていないか、**カスタム API** 権限が引き続き付与されているかをご確認ください。
- 直近で **Secret のリセット** を行った場合は、[EngineCode と Secret を確認する](#vg9CseQ4UQE3E7J53FMJZ8 "EngineCode と Secret を確認する") から最新の Secret を再取得してください。

#### Q：**AppCode を入力してもフォームのドロップダウンが空になる場合は？**

A：

- AppCode のコピーが正しいかご確認ください（アプリ名称ではなくアプリケーションコード）。
- [バックエンドコードのデプロイ](#3EV2jtg6Hyrfz4sB6d4Kmj "バックエンドコードのデプロイ") のコードが**保存に成功している**かご確認ください（上部のトースト通知）。
- バックエンドコードが**デフォルトクラスコードの下**に貼り付けられているかご確認ください（デフォルトコードを置き換えないこと）。

#### Q：**複数の AI テーブルデータソースで、同じバックエンドコードを共用できますか？**

A：可能です。バックエンドコードは、どのアプリ・どのフォームの下にデプロイしても有効になります（氚雲のバックエンドコードは企業全体で共有される仕組みです）。**任意のアプリ・任意のフォームに 1 度デプロイするだけで**、その他のデータソースは EngineCode と異なる AppCode を設定するだけで動作します。

#### Q：**氚雲のバックエンドコードは、氚雲側のアプリリリースで上書きされたり消えたりしますか？**

A：消えません。バックエンドコードはフォームと一緒に氚雲側で永続化されます。当該フォームを明示的に削除・初期化しない限り、コードは継続して有効です。

#### Q：**同期の頻度と増分ロジックはどうなっていますか？**

A：

- 既定では AI テーブルプラットフォームの統一スケジュール戦略に従って実行されます（詳細は AI テーブルのデータソース管理ページをご確認ください）。
- 増分同期は氚雲レコードの `ModifiedTime` フィールドに基づき、前回同期以降に変更されたレコードのみを取得します。
