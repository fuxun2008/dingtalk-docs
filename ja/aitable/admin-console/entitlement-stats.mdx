**権益データ**ページでは、企業管理者が組織で利用している **AI テーブル**のバージョン権益と利用状況を一元的に確認・管理できます。容量の上限、機能の有効化状態、リアルタイムの利用進捗などを把握できます。

このページから、管理者は次の情報を一目で確認できます。

- 現在利用中の AI テーブルバージョンと有効期間。
- 各種コア権益の利用上限と使用済み件数。
- 拡張やアップグレードが必要な権益項目。

これらの情報をもとに、企業の**容量計画、権限設計、バージョンアップ判断**を行えます。

![](/ja/aitable/admin-console/entitlement-stats/images/image_4zIMUodv2N.png)

## アクセス方法

DingTalk クライアント＞その他＞管理画面、または [https://oa.dingtalk.io/#/welcome](https://oa.dingtalk.io/#/welcome "https://oa.dingtalk.io/#/welcome") に直接アクセスして DingTalk 管理画面を開きます。左側メニューで「AI テーブル」＞「権益データ」を選び、権益データページを開きます。

![](/ja/aitable/admin-console/entitlement-stats/images/image_KCZ2NJLjuh.png)

## 情報の説明

### 現在のバージョンと有効期間

ページ上部には、組織で利用中の AI テーブルバージョン（企業版／旗艦版）と、利用日数および有効期限が表示されます。管理者は契約状況を素早く確認でき、有効期限が近づいた場合は「相談予約」または「アップグレード」を選択できます。

### 権益アラート

行数や役割数などの主要な権益が上限に近づいたり到達したりすると、システムが通知します。管理者は「相談予約」をクリックして対応を進められます。

![](/ja/aitable/admin-console/entitlement-stats/images/image_0ymaP1WbWj.png)

## 権益データモジュールの説明

| **権益タイプ**  | **権益名**      | **詳細説明**                                                       |
| ---------- | -------------- | --------------------------------------------------------------- |
| **使用量型権益** | 自動化フローの実行回数      | 月ごとに自動化ワークフローのノードが実行できる最大上限です。翌月 1 日にリセットされます。                             |
|            | 1 テーブルあたりの最大行数         | 1 つのデータテーブルに格納できるレコード数で、最大 1,000 万行まで拡張できます。                            |
|            | 高度な権限のカスタムロール数    | 1 つの AI テーブルに設定できる、高度な権限のカスタムロールの数です。                                       |
| **機能型権益** | ユーザー権限に応じたダッシュボード集計   | ダッシュボードのチャート表示を、閲覧者ごとのデータ権限に応じた集計結果にできます。1 つのダッシュボードで複数ユーザーに異なるデータを表示できます。                   |
|            | 自動化ループノードの最大実行回数 | AI テーブルの自動化ワークフローはノードのループ実行に対応しています。設定したルールに従って同じ操作を繰り返し、タスクが完了するまで実行します。1 つのループノードで実行できる最大回数を表します。 |
|            | ダッシュボードのテーブル横断分析        | 1 つの AI テーブル内で、異なるデータテーブルのデータを 1 枚のグラフにまとめて表示でき、より総合的で深いデータ分析を実現できます。               |
|            | AI フィールドの高速モード       | AI フィールドの生成を高速化し、待ち時間を短縮することで、業務をより効率的に進められます。                                       |
|            | AI フィールドの定期更新       | 一部の高度な AI フィールドが 24 時間ごとに自動更新されます（配送状況の照会、行内容のサマリーなどに対応）。                           |

### 権益の拡張

#### **1 テーブルあたりの最大行数の拡張**

1. 「1 テーブルあたりの最大行数」カードの「拡張する」をクリックします。

   ![](/ja/aitable/admin-console/entitlement-stats/images/image_rLGU1dqw7d.png)
2. 拡張申請フォームに移動し、申請内容を送信します。

   ![](/ja/aitable/admin-console/entitlement-stats/images/image_-kbL5qqMif.png)

#### **高度な権限のカスタムロール数の拡張**

1. 「高度な権限のカスタムロール数」カードの「拡張する」をクリックします。

   ![](/ja/aitable/admin-console/entitlement-stats/images/image_GBK3XK7LbQ.png)
2. 注文ページに移動し、アップグレード注文の送信や相談予約が行えます。

   ![](/ja/aitable/admin-console/entitlement-stats/images/image_EA0WAn6Iqz.png)

### 利用明細

#### **1 テーブルあたりの最大行数の利用明細**

1. 「1 テーブルあたりの最大行数」カードの「利用明細」をクリックします。

   ![](/ja/aitable/admin-console/entitlement-stats/images/image_TsTduB0C3P.png)
2. データテーブル行数の利用画面に移動し、企業内のデータテーブルの行数利用状況を確認できます。

   ![](/ja/aitable/admin-console/entitlement-stats/images/image_XJ97g0KWRv.png)

#### **カスタムロールの利用明細**

1. 「高度な権限のカスタムロール数」カードの「利用明細」をクリックします。

   ![](/ja/aitable/admin-console/entitlement-stats/images/image_IfV40nihny.png)
2. 高度な権限のカスタムロール利用画面に移動し、企業内のデータテーブルでのカスタムロール利用状況を確認できます。

   ![](/ja/aitable/admin-console/entitlement-stats/images/image_nw-n1fIFOH.png)

## 利用に関するおすすめ

1. 管理者は権益データページを定期的に確認し、コア容量の利用傾向を把握することをおすすめします。
2. 赤い進捗バーや権益アラートが表示されたら、速やかにリソースを調整してください。
3. 企業の規模や業務の複雑さを踏まえ、AI テーブルのバージョン選択やアップグレードを検討してください。
