**権限統計**ページでは、組織管理者が**AI Table**における社内のプラン権限を一元的に確認できます。容量上限、機能の有効化状況、リアルタイムの利用状況を一覧できます。

このページから、管理者は以下を明確に把握できます。

- 現在のAI Tableプランと有効期限。
- 各コア権限の上限と現在の利用状況。
- 拡張またはアップグレードが必要な権限。

これにより、**容量計画、権限設定、アップグレードの判断**を支援します。

## アクセス方法

DingTalkクライアントを開き、**その他** > **管理コンソール**を選択するか、[https://oa.dingtalk.io/#/welcome](https://oa.dingtalk.io/#/welcome "https://oa.dingtalk.io/#/welcome") に直接アクセスします。左側のメニューで**AI Table** > **権限統計**を開きます。

## ページの内容

### 現在のプランと有効期限

ページ上部には、現在のAI Tableプラン（Business / Enterprise）に加えて、使用日数と有効期限が表示されます。管理者はサブスクリプションの状態をすぐに確認し、有効期限の前に**相談を予約**または**今すぐアップグレード**を選択できます。

### 権限アラート

主要な権限（行数、ロール数など）が上限に近づいた、または上限に達した場合、システムが通知を表示します。管理者は**相談を予約**をクリックできます。

## 権限モジュール

| **タイプ** | **権限** | **説明** |
| ---------- | -------------- | --------------------------------------------------------------- |
| **使用量ベース** | 自動化実行 | 月あたりの自動化ワークフローノード実行の最大回数。翌月1日にリセットされます。 |
|  | テーブルあたりの最大行数 | 1つのテーブルが保持できるレコード数。テーブルあたり最大1,000万行まで拡張可能です。 |
|  | 高度な権限のカスタムロール | AI Tableごとに設定できるカスタムロール数。 |
| **機能ベース** | ダッシュボード統計が閲覧者の権限に従う | ダッシュボードのチャートを閲覧者のデータ権限に従うように設定できます。1つのダッシュボードで、閲覧者ごとに異なるビューを表示します。 |
|  | ループノードあたりの最大反復回数 | 自動化内の1つのループノードが反復できる最大回数。ループノードはタスクが完了するまで同じ操作を繰り返します。 |
|  | テーブル横断のダッシュボード分析 | 同じAI Tableの異なるテーブルのデータを1つのチャートにまとめ、より深いエンドツーエンドの分析を行います。 |
|  | AIフィールドのファストレーン | AIフィールドの結果がより速く表示され、待ち時間が減少して作業がスムーズに進みます。 |
|  | AIフィールドの定期更新 | 一部の高度なAIフィールドは24時間ごとのスケジュールで更新されます（例：荷物追跡の照会、行全体の要約）。 |

### 権限の拡張

#### **テーブルあたりの最大行数を拡張する**

1. **テーブルあたりの最大行数**カードで**拡張**をクリックします。

2. 拡張フォームが表示されるので、そこからリクエストを送信します。

#### **高度な権限のカスタムロール数を拡張する**

1. **高度な権限のカスタムロール**カードで**拡張**をクリックします。

2. 注文ページが表示されるので、アップグレード注文を送信するか、相談を予約します。

### 利用状況の内訳

#### **テーブルあたりの最大行数 — 利用状況の内訳**

1. **テーブルあたりの最大行数**カードで**利用状況の内訳**をクリックします。

2. テーブル単位の行利用状況ページが開き、社内の各テーブルにわたる行の利用状況を照会できます。

#### **カスタムロール — 利用状況の内訳**

1. **カスタムロール**カードで**利用状況の内訳**をクリックします。

2. 高度な権限のカスタムロール利用状況ページが開き、社内の各テーブルにわたるカスタムロールの利用状況を照会できます。

## 推奨事項

1. 権限統計ページを定期的に確認し、コア容量の傾向を注視します。
2. プログレスバーが赤くなったり権限アラートが表示されたりした場合は、速やかにリソースを調整します。
3. 社内の実際の規模と業務の複雑さに基づいて、AI Tableプランを選択（またはアップグレード）します。
