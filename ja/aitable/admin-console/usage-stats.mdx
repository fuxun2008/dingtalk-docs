**AI Table 利用統計**ページでは、組織管理者が**AI Table の活用状況とアクティビティのトレンド**を、組織全体・メンバーのエンゲージメント・個々のテーブル利用ランキングという観点から総合的に把握できます。

このページでは、管理者は次のことができます。

- 組織内における AI Table の浸透度とアクティビティを素早く評価する。
- 中核となる部門と最も重要なテーブルを特定する。
- 展開・権限設定・商用に関する意思決定をデータに基づいて行う。

## アクセス方法

DingTalk クライアントを開き、**その他** > **管理コンソール**を選択するか、[https://oa.dingtalk.io/#/welcome](https://oa.dingtalk.io/#/welcome "https://oa.dingtalk.io/#/welcome") に直接アクセスします。左側のメニューで **AI Table** > **利用統計**を開きます。

## 主要指標

ページ上部のカードには、組織の主要な利用指標が表示されます。

### アクティブ部門（過去7日間）

> 組織内の**部門のリーチ**を測定します。

定義：過去7日間に、少なくとも1人のメンバーが AI Table でアクティブだった（作成・編集・閲覧・共有など）部門の数。

### アクティブユーザー（過去7日間）

> 組織内の**実際の利用規模**を反映します。

定義：過去7日間に AI Table でアクティブだった（作成・編集・閲覧・共有など）組織内のユーザーの総数。

### AI Table 総数

> 組織が AI Table で構築した**資産の規模**を反映します。

定義：組織内で正常に作成され、完全に削除されていない AI Table の総数。

## 利用トレンド

### 利用トレンドチャート

選択した期間（7/30/90日間）における3つの中核ユーザー指標を示す折れ線チャートです。

1. **アクティブユーザー** — 期間内に AI Table を作成・編集・閲覧・コメント・共有したユーザーの総数。
2. **編集者** — 期間内に AI Table を編集したユーザーの総数。
3. **閲覧者** — 期間内に AI Table を閲覧したユーザーの総数。

時間範囲を切り替えて、短期と中期のトレンドを比較できます。

## AI Table ランキング

### 表示内容

選択した期間内で最も活発な AI Table を表示します（7/30/90日間で切り替え可能）。

### **活用メリット**

1. 組織内の中核となる業務テーブルを素早く特定する。
2. コラボレーションや再利用が活発な AI Table の活用シーンを把握する。
3. 権限ガバナンス・テンプレートの整備・展開戦略に役立てる。
