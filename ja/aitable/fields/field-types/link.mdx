# 1 機能概要

「リンク」フィールドを使用すると、リンクと表示テキストを素早く入力でき、クリックで対応する Web ページへジャンプできます。

# 2 基本操作

## 2.1 リンクフィールドの新規作成

1. タイトル右側の + をクリック
2. 「フィールドタイプ」をクリックして選択
3. フィールドタイプとして「リンク」を選択

## 2.2 リンクの編集

1. セルをダブルクリック
2. 上部のテキストボックスに表示する **テキスト** を入力
3. 下部のリンクボックスにジャンプ先の Web ページ **リンク** を入力
4. 入力完了後、保存をクリック

# 3 よくある質問

- **Q：1 つのセル内に複数のリンクを追加できますか？**

  A：できません。各セル内には 1 つのリンクのみ追加可能です。
