# 機能概要

AI テーブルのメールフィールドは、フォーマット検証を通じて入力されたメールアドレスが規定どおり有効であることを保証します。

# 基本操作

新規フィールド作成：AI テーブルのタイトル列右側の + をクリックし、フィールドタイプでメールを選択します。

メールアドレスを入力すると、自動的に検証されます。

# よくある質問

- **問：同じセルに複数のメールアドレスを入力できますか**

  答：できません。新しいメールアドレスを入力すると、以前のメールアドレスが上書きされます。
