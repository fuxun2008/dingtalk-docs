## 概要

**同期機能**：[片方向関連](/ja/aitable/fields/field-types/one-way-link)または[双方向関連](/ja/aitable/fields/field-types/two-way-link)を利用して A 表と B 表を連動させると、片方向（双方向）関連フィールドはプライマリフィールドとして表示されます。A 表の **「その他フィールド」** を B 表に表示したい場合、**「関連引用」** フィールドを利用できます。

**集計機能**：A 表のその他フィールドを B 表に表示すると同時に、そのフィールドに対して元の値、重複排除、合計などの簡単な集計処理を実施できます。

## 基本操作

### フィールドの作成

AI テーブルのタイトルバー右側の + をクリックして新規フィールドを作成し、フィールドタイプから **「関連引用」** を選択します。

### 関連引用の設定

**「参照したいデータの選択」**：属するデータテーブル内の **「片方向 / 双方向関連フィールド」** のみ選択可能です。つまり、関連引用を使う前提として片方向 / 双方向関連フィールドが存在する必要があります。

**「参照したいフィールドの選択」**：片方向 / 双方向参照の **「データソーステーブル」** 内のみ選択可能です。例：参照したいデータで a フィールドを選択し、a フィールドが A 表への参照である場合、参照したいフィールドは A 表内のみ選択可能です。

**「計算方式」** には以下の種類があります：元の値、重複排除、合計、平均値、最大値、最小値、非空の数値カウント、非空値カウント、重複排除カウント、行数、テキスト連結。具体的な説明は以下のとおりです。

| 計算方式名称 | 説明                     |
| ------ | ---------------------- |
| 元の値     | データテーブルから列データを直接参照     |
| 重複排除   | 元の値データの重複を排除            |
| 合計     | 元の値データを合算              |
| 平均値    | 元の値データの平均を計算            |
| 最大値    | 元の値データの最大値を返す            |
| 最小値    | 元の値データの最小値を返す            |
| 非空の数値カウント | 元の値データ内で空でない【数値】型データの件数を計算    |
| 非空値カウント  | 元の値データ内で空でないデータの件数を計算（数値とテキスト値を含む） |
| 重複排除カウント   | 元の値データから重複を除いた件数を計算           |
| 行数     | 元の値のレコード件数を計算              |
| テキスト連結  | 表示値を1つのテキストに連結。区切り文字はカンマ    |

### フィールドの管理と編集

タイトルバーをダブルクリックするか、タイトルバー右側のドロップダウンボタンをクリックすると、そのフィールドのコピー、貼り付け、固定を選択できます。
