# 1 機能概要

**情報収集**で身分証番号を集約する際に使用するフィールドです。番号の妥当性を**検証**し、形式が正しくない場合はエラーが表示され、保存ができません。

# 2 基本操作

## 2.1 グリッドビューでフィールドを新規作成する

AI テーブル上部のヘッダー右端の ➕ をクリックし、フィールドタイプから**身分証**を選択します。

## 2.2 フォームビューでフィールドを新規作成する

フォーム左側の質問項目から「身分証」を選択すれば、フォームの設問として情報を収集できます。

## 2.3 フィールドを管理・編集する

フィールド名をダブルクリック、またはドロップダウンボタンをクリックすると、ダイアログから複製・削除・固定などの操作を選択できます。

# 3 利用シーンの実践

身分証フィールドは情報収集のシーンで主に活用します。回答者のプライバシー保護のため、フォームビューで収集することをお勧めします。グリッドビューで収集したい場合は、**高度な権限** を有効にし、ロールの **編集可能権限** を「メンバー自身に関連するレコード」に設定したうえで、その他のレコード権限を **閲覧不可** に設定してください。
