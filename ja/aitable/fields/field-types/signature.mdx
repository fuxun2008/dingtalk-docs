# 1 機能概要

署名はユーザーが署名画像を作成するための補助機能であり、『中華人民共和国電子署名法』に定められた電子署名または電子署名行為には該当しません。**法的効力を有さず**、ユーザーの記録用途のみにご利用ください。

# 2 基本操作

上部タイトルバー右側の ➕ 新規フィールドをクリックし、フィールドタイプから**手書き署名**を選択します。

![](/ja/aitable/fields/field-types/signature/images/全屏截图@1x-8_M0w8LOuqre.png)

**セルをダブルクリック**するとホワイトボードがポップアップし、署名できます。署名が気に入らない場合は右上の**クリア**をクリックし、満足できたら右下の**確定**をクリックします。

![](/ja/aitable/fields/field-types/signature/images/DingTalk录屏_2025-03-21%20150120_IBMVj5dId8.gif)
