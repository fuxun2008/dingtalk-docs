# 1 機能概要

AI テーブルの「**位置情報**」を使うと、**省・市・区（–町）** の形式で位置情報を手動で選択できます。

# 2 基本操作

**テーブルビュー — 住所の追加**

1. タイトル列の右端の + をクリックします。
2. 「フィールドタイプ」をクリックして選択します。
3. フィールドタイプを「**住所**」に設定します。

**住所形式の設定**

形式のドロップダウンから「**省・市・区**」または「**省・市・区–町**」を選びます。

「**省・市・区**」を選んだ場合は、組み込みの省・市・区からのみ選択できます。

「**省・市・区–町**」を選んだ場合は、選択後に詳細住所も入力する必要があります。

**フォームビュー — 住所の追加**

1. 左側の「設問を追加」から「**住所**」を選びます。
2. 設問の下のドロップダウンから「形式」を選びます。

「**省・市・区**」を選ぶと、フォーム入力時の表示は次のようになります。

「**省・市・区–町**」を選ぶと、フォーム入力時の表示は次のようになります。

# 3 よくある質問

- **問：同じセルに複数の位置情報を入力できますか？**

  答：できません。
- **問：位置情報の入力方式を切り替えると、入力済みの情報に影響しますか？**

  答：影響しません。
