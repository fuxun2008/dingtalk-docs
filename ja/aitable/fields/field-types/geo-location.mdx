# 1 機能概要

AI テーブルの**位置情報**フィールドを使えば、位置情報を素早く記録できます。手入力、任意の地点の検索、モバイル端末からのリアルタイム取得に対応しています。

**よくあるシーン：** モバイル端末で実位置を取得し、巡回点検や勤怠打刻などの位置情報の真実性を担保します。

# 2 基本操作

表ビュー上部の機能バー右側にある ➕ **新規フィールド** をクリックし、フィールドタイプで**位置情報**を選択します。入力方式は**任意の位置情報を入力可能**と**モバイル端末でのリアルタイム測位のみ許可**から選べます。

![](/ja/aitable/fields/field-types/geo-location/images/全屏截图@1x_-B4UZfRePJ.png)

**フォームビュー**では、左側の項目で**位置情報**を選択して追加し、**モバイル端末でのリアルタイム測位のみ許可**を有効化／無効化することで、フォームでの位置情報収集を実現できます。

![](/ja/aitable/fields/field-types/geo-location/images/全屏截图@1x-2_-pIAJKiIMf.png)

入力方式で**任意の位置情報を入力可能**を選択した場合、セルをダブルクリックして検索バーに住所を入力し、検索結果から住所を選び、右下の確認をクリックして保存します。

![](/ja/aitable/fields/field-types/geo-location/images/DingTalk录屏_2025-03-21%20153104_fspfI2RQ_1.gif)

入力方式で**モバイル端末でのリアルタイム測位のみ許可**を選択した場合、モバイル端末でレコード詳細に入る、またはフォームリンクをクリックし、**測位をクリック**します。

![](/ja/aitable/fields/field-types/geo-location/images/image_3DburAzLdb.png)

![](/ja/aitable/fields/field-types/geo-location/images/image_Ipnyjx0yoN.png)

# 3 よくある質問

- **問：1 つのセルに複数の位置情報をインポートできますか？**

  答：できません。
- **問：位置情報の入力方式を切り替えると、入力済みの情報に影響しますか？**

  答：影響しません。
