フォームに **初期値をプリフィル** することで、以下のような運用が可能になります。

**初期値のプリフィル** ：店舗がフォームタスクを送信する際に、店舗情報を自動入力して入力ミスを防ぎます。

**送信元チャネルの取得** ：ユーザーが申し込みを送信した際に、 **送信元チャネル** を自動的に列に記録します。

> 📌 リンク生成ツールを使えば、プリフィルリンクをワンクリックで一括生成できます：[https://store.dingtalk.io/materials/659](https://store.dingtalk.io/materials/659 "https://store.dingtalk.io/materials/659")

## 基本操作

書式：
**1問のみ設定** ：フォーム共有リンク`?prefill_項目名=初期値`**複数問の設定** ：フォーム共有リンク`?prefill_項目名=初期値&prefill_項目名=初期値`

例：
[https://docs.dingtalk.io/notable/share/form/v011GXn4BrXGJobODQ4_hERWDMS_7LisUkm?prefill_标题=预设标题&prefill_单选=选项二](https://docs.dingtalk.io/notable/share/form/v011GXn4BrXGJobODQ4_hERWDMS_7LisUkm?prefill_标题=预设标题&prefill_单选=选项二 "https://docs.dingtalk.io/notable/share/form/v011GXn4BrXGJobODQ4_hERWDMS_7LisUkm?prefill_标题=预设标题&prefill_单选=选项二")

現在、初期値の設定に対応している項目タイプは、テキスト、数値、単一選択、複数選択です。

| 項目タイプ | 設定ルール |
| --- | --- |
| テキスト | フォームリンク`?prefill_チャネル=WeChat` |
| 数値 | フォームリンク`?prefill_スコア=1` |
| 単一選択／複数選択 | フォームリンク`?prefill_単一選択=スニーカー` |

初期値に特殊記号を含める場合は、下表に従ってエンコード変換が必要です。

| 特殊記号 | リンクに追加する変換後の文字列 |
| --- | --- |
| 半角スペース | %20 または + |
| ; | %3B |
| : | %3A |
| \\[ | %5B |
| ( | %28 |
| ) | %29 |
| & | %26 |
| \\\$ | %24 |
| , | %2C |
| ！ | %21 |
| @ | %40 |
| ] | %5D |
| \{ | %7B |
| \} | %7D |
| \# | %23 |

初期値を設定した項目自体をフォーム上に表示したくない場合は、フォームリンクの末尾に `&hide_項目名=1` を追加することで非表示にできます。例えば、コンテンツ送信フォームの「レビュー担当者」情報を非表示にする場合は、次のようにフォームリンクを設定します。

[フォームリンク?prefill_レビュー担当者=Kato](https://docs.dingtalk.io/notable/share/form/v011GXn4BrXGJobODQ4_hERWDMS_7LisUkm?prefill_标题=预设标题&prefill_单选=选项二 "フォームリンク?prefill_レビュー担当者=Kato")[&hide_プロジェクト責任者=1](https://docs.dingtalk.io/notable/share/form/v011GXn4BrXGJobODQ4_hERWDMS_7LisUkm?prefill_标题=预设标题&prefill_单选=选项二 "&hide_プロジェクト責任者=1")

この方法を使えば、フォームの送信チャネルを追跡することも可能です。例えば、ユーザーからのイベントへのフィードバックを収集する際に、どのチャネルからの送信が最も多いかを分析したい場合は、次のように操作します。

1. フォームに「送信プラットフォーム」という項目を新規追加します。
2. フォームの共有機能を開き、回答可能範囲を設定したうえで、共有リンクをコピーします。
3. フォームリンクに送信元パラメータを追加します。例えば、送信元がDingTalkの場合のリンクは次のようになります。

   フォームリンク`?prefill_送信プラットフォーム=DingTalk&hide_送信プラットフォーム=1`
4. 異なるリンクをそれぞれのプラットフォームで共有します。

設定が完了すると、初期値からフォーム送信元の具体的なチャネルを追跡できるようになります。

## よくある質問

#### **Q: フォームの項目名を変更すると、プリフィルした初期値は無効になりますか？**

A: はい、初期値が無効になります。新しい項目名に合わせて再設定してください。

#### **Q: AI テーブルのフォームでプリフィルした人物名が反映されないのはなぜですか？**

A: 以下のような原因が考えられます。

- 同じ氏名が組織内に複数存在している。
- 該当人物が組織外メンバーで、かつご自身のDingTalk連絡先に登録されていない。
- 氏名の入力に誤りがある。内容をご確認のうえ修正してください。

#### **Q: AI テーブルのフォームで初期値を設定した場合、すべての回答者に初期値が見えてしまいますか？**

A: はい、見えます。回答者に表示したくない場合は、`&hide_項目名=1` パラメータを追加して該当項目を非表示にできます。詳細は前述のとおりです。

#### **Q: リンクで非表示パラメータを設定したのに、フォーム上で項目が表示され続けるのはなぜですか？**

A: フィールドが必須項目で、かつ初期値が無効になっている可能性があります。初期値が無効なため必須項目が空となり、非表示にできない状態です。初期値を設定し直すことで解消できます。
