数式が誤っているか、現在の行に基づいて結果を計算できない場合、セルにエラーコードが表示されます。

AI テーブルでよく見られるエラーコードは次のとおりです。

| エラーコード                 | 意味                                                             | 例                          |
| -------------------- | -------------------------------------------------------------- | --------------------------- |
| \#NULL!             | **NULL エラー**  数式に誤った範囲演算子が含まれているか、交差しない 2 つの範囲が指定されています。                    |                             |
| \#DIV/0!            | **0 除算エラー**  除算で除数が 0 または空白セルを参照している場合に発生します。                     | `2/0`                     |
| \#REF!              | **無効な参照エラー**  参照が無効、または数式が参照していた列が削除されています。参照中の列が変更・削除された場合に発生します。       |                             |
| \#N/A               | **値が利用不可エラー**  関数や数式に対してある値が利用できず、参照値が見つからない場合に発生します。                         | `REGEXEXTRACT("def","a")` |
| \#VALUE!            | **値エラー**  数式や関数で使用している引数やオペランドの型が誤っています（例：テキストを数値演算に使用）。                   | `SQRT("test")`            |
| \#ERROR!            | **数式解析エラー**  数式に誤りがある場合にこのコードが表示されます。                                   | `test formula`            |
| \#NUM!              | **数値エラー**  数値や関数に無効な値が使用されているか、生成された数値が大きすぎる／小さすぎて表示できない場合に発生します（例：負数の平方根）。      | `SQRT(-1)`                |
| \#NAME?             | **無効な名前エラー**  数式中のテキストを認識できません。関数名や名前のスペル誤りなどが原因です。                        | `SUMMM()`                 |
| \#TOO\\_LARGE!     | **計算結果が大きすぎるエラー**  結果が 200 件を超えると発生します。例：参照を検索で元の値を返す設定にした際、結果が 200 件を超える場合など。 |                             |
| \#MISMATCH\\_TYPE! | **型の不一致エラー**  現在の実際の結果が、現在の列の結果型と一致していません。元の値が変更された後に発生しやすい現象です。                |                             |
| \#CIRCULAR!         | **循環参照エラー**  数式が直接または間接的に、自身が存在するセルを参照して循環を形成しています。                    |                             |
| \#UNSUPPORT!        | **未対応機能エラー**  数式で使用している関数や機能が、将来サポート予定（現在は未対応）です。例：テーブル間の機能を利用した場合など。      | \-                         |
