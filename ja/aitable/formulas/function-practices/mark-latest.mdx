#### 1 機能

テーブル内で各メンバーの最新の日報レコードをマークします。

![](/ja/aitable/formulas/function-practices/mark-latest/images/image_Qd_UUFWcC-.png)

#### 2 設定方法

「最終更新時間フィールド」を新規作成すると、システムが各レコードの最終更新時間を自動でマークします。

![](/ja/aitable/formulas/function-practices/mark-latest/images/image_jxOIlXyjXX.png)

ルックアップ参照フィールドを新規作成し、人員情報をもとに最新レコードの入力時間を見つけ出します。

![](/ja/aitable/formulas/function-practices/mark-latest/images/image_OzoUwKTnRe.png)

数式関数を新規作成し、どれが最新のレコードかを視覚的にマークします。

```javascript 
IF([最終更新時間]=[最後に入力した時間],"✅最新の入力結果です","")
```
