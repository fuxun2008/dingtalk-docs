数式フィールドは AI テーブルのフィールドタイプの 1 つで、豊富な関数式を使ってデータの柔軟な計算を実現できます。

## 数式フィールドを新規作成する

AI テーブルのフィールドタイトルバー右側の + アイコンをクリックし、フィールドタイプから**数式**を選択します。

![](https://img.alicdn.com/imgextra/i1/O1CN01Qkznx71eXYH9gb8Uf_!!6000000003881-2-tps-1032-474.png)

## 数式を編集する

**数式編集**をクリックすると、数式編集ウィンドウが表示されます。

![](https://img.alicdn.com/imgextra/i4/O1CN01GpkxPA1Dy7cv6C9jX_!!6000000000284-2-tps-628-433.png)

上部の編集ボックスで直接**数式編集**が行えます。

**数式編集**タブをクリックすると、フィールドの参照や各タイプの関数メソッドを選択できます。

**AI 数式生成**タブをクリックすると、自然言語による説明で数式を生成できます。詳細は[AI による数式生成の利用](/ja/aitable/formulas/ai-generate-formula)をご参照ください。

![](https://img.alicdn.com/imgextra/i2/O1CN01Rgi2P71ulK2HVJLKi_!!6000000006077-2-tps-1080-936.png)

## 数式の概念

| **用語**​ | **説明**​                    |
| ------- | -------------------------- |
| フィールド      | データテーブル内、対象列に対応する各行の値で、数式計算に参加します |
| 列全体フィールド    | データテーブル内、対象列の各行の値の集合で、数式計算に参加します  |
| 角括弧     | 数式中で AI テーブルのデータテーブルやフィールドを参照するために使用します        |
| 演算子     | 数式中で使用するロジックや演算記号             |
| 関数      | 特定の演算ルールにより期待する出力値を得ます          |
| 引数      | 数式中で計算に参加する数値またはテキスト             |
| 文字列     | 数式計算に参加する一連のテキスト               |
| 配列      | 数値の集合                      |

## よく使う演算記号

| **記号タイプ**​ | **演算子**​ | **説明**​                       |
| --------- | -------- | ----------------------------- |
| 数値演算子     | `+`    | 2 つの数値を加算                        |
|           | `-`    | 2 つの数値を減算                        |
|           | ` *`     | 2 つの数値を乗算                        |
|           | `/`    | 2 つの数値を除算                        |
| テキスト連結子     | `&`    | 2 つのテキストを連結。数値とテキスト間で使用すると、数値とテキストを連結 |
| 論理演算子     | `>`    | より大きい                            |
|           | `>=`   | 以上                          |
|           | `<`    | より小さい                            |
|           | `<=`   | 以下                          |
|           | `=`    | 等しい                            |
|           | `!=`   | 等しくない                           |
|           | `&&`   | 論理積（AND）                      |
|           | `|`   | 論理和（OR）                       |
