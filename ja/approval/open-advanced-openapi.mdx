## 1. 機能概要

多くの開発者様のパーソナライズドアプリ開発ニーズにお応えするため、DingTalk OA 承認では 2024 年 9 月 1 日より、スマート OA のお客様向けに専用 OpenAPI を順次リリースしています。これらの専用 OpenAPI はより充実した機能を備え、パーソナライズドなビジネスニーズに応えるとともに、さまざまなシーンでの社内アプリ開発をサポートします。開発者様には OpenAPI を合理的かつ効果的にご活用いただき、より健全な DingTalk オープンエコシステムを構築されることをお勧めします。

## 2. 適用シーン

<Note>
DingTalk は、法令や規制の変更、監督当局の指示への対応、または DingTalk サービスの安全性維持などの理由により、以下の API の範囲や具体的な機能を追加、変更または削除する場合があります。お客様に実際に公開される API は、DingTalk オープンプラットフォームで随時公示される内容が正式なものとなります。
</Note>

| OpenAPI 名 | OpenAPI 詳細 | 適用シーン |
| --- | --- | --- |
| 承認センターのユーザー未処理タスクリストを照会 | 本 API を呼び出すと、社内の指定ユーザーの未処理承認タスクリスト（公式 OA 承認タスク、およびサードパーティ業務システムから DingTalk に同期された承認タスクを含む）を照会でき、企業の社内承認センター構築を支援します。 | 社内承認センター構築 |
| 承認センターのユーザー処理済みタスクリストを照会 | 本 API を呼び出すと、社内の指定ユーザーが処理済みの承認タスクリスト（公式 OA 承認タスク、およびサードパーティ業務システムから DingTalk に同期された承認タスクを含む）を照会でき、企業の社内承認センター構築を支援します。 | 社内承認センター構築 |
| 承認センターのユーザー起票済みインスタンスリストを照会 | 本 API を呼び出すと、社内の指定ユーザーが起票済みの承認インスタンスリスト（公式 OA 承認インスタンス、およびサードパーティ業務システムから DingTalk に同期された承認インスタンスを含む）を照会でき、企業の社内承認センター構築を支援します。 | 社内承認センター構築 |
| 承認センターのユーザー受信済みインスタンスリストを照会 | 本 API を呼び出すと、社内の指定ユーザーが受信済みの承認インスタンスリスト（公式 OA 承認インスタンス、およびサードパーティ業務システムから DingTalk に同期された承認インスタンスを含む）を照会でき、企業の社内承認センター構築を支援します。 | 社内承認センター構築 |
| 承認タスクを一括で承認または拒否 | 本 API を呼び出し、指定した userId、タスク結果 (result)、コメント (remark) を用いて、異なる承認インスタンス ID・タスクノード ID を持つ一連の承認タスクを一括処理します。 | 社内承認センター構築 |
| 管理者が指定社員の未処理タスクリストを照会 | 本 API は組織管理者向けに未処理タスク照会サービスを提供します。管理者 (managerUserId) が現在の承認者 UserId のすべての未処理 OA 承認タスク情報を照会でき、在職社員と離職社員の未処理タスク照会に対応します。 | フロー引継ぎソリューション |
| 管理者が指定社員の未処理タスクを一括転送 | 未転送承認タスク照会 API を通じて、管理者が組織内の他の在職メンバーへタスクを一括転送できます。転送元は在職メンバーと離職メンバーの双方に対応しますが、転送先は組織内の在職メンバーである必要があります。 | フロー引継ぎソリューション |
| 業務グループの作成または更新 | 本 API を呼び出すと、サードパーティシステム内の業務グループ情報を DingTalk OA 承認に同期し、対応する DingTalk タスクの OA 承認カテゴリ配下の 2 階層目「業務追加元グループ」を生成できます。以後、未処理タスクを DingTalk に同期する際、タスクが属する業務グループ情報を指定できます。 | フローセンター連携（カスタム業務グループ分け） |
| 業務グループの削除 | 本 API を呼び出すと、サードパーティシステムから DingTalk OA 承認に同期されたグループ情報を削除でき、同時に DingTalk タスクの OA 承認カテゴリ配下の 2 階層目分類も削除されます。対応する分類配下の DingTalk タスクデータは、OA 承認カテゴリ配下の「その他」グループへ移動されます。 | フローセンター連携（カスタム業務グループ分け） |
| フローセンター外部連携承認テンプレートを保存（承認ホスティング、カスタム業務グループ分けなどの featureConfig をサポート） | 本 API を呼び出すと、サードパーティ業務システム内の独自承認テンプレートデータを DingTalk OA 承認に同期でき、同時にテンプレート単位で承認ホスティング、カスタム業務グループ分け、カスタムクイック承認など複数のプレミアム機能モジュールのカスタム連携設定に対応します。 | フローセンター連携（承認ページホスティングモード） |
| フローセンター外部連携承認インスタンスを保存（承認ホスティング、カスタム業務グループ分けなどの featureConfig をサポート） | 本 API を呼び出すと、サードパーティ業務システム内の独自承認インスタンスデータを DingTalk OA 承認に同期でき、同時にインスタンス単位で承認ホスティング、カスタム業務グループ分け、カスタムクイック承認など複数のプレミアム機能モジュールのカスタム連携設定に対応します。 | フローセンター連携（承認ページホスティングモード） |
| フローセンター外部連携承認タスクを保存（カスタムクイック承認などの featureConfig をサポート） | 本 API を呼び出すことで、サードパーティシステムは承認タスクのコールバック API を設定できます。これにより承認者は DingTalk の承認タスクセンターで直接承認操作を行うことができ、承認タスクセンターがサードパーティシステムにコールバックし、サードパーティシステムはコールバックを受信するとタスク情報を更新し、新しいタスク情報を承認センターへ同期して返すことで、クローズドループを形成します。 | フローセンター連携（カスタム業務グループ分け） |

### 2.1 社内承認センターの構築

複数の業務システム（企業の自社開発システム、または購入したサードパーティシステム）の承認タスクを DingTalk 承認センターに接続し、DingTalk OA 承認のオープン機能を活用して社内承認センターを構築し、追加元別の絞り込みや一括承認などの機能を実現したい場合に適しています。

## 3. 操作手順

上記の専用 OpenAPI について、標準版のお客様は **スマート OA へのアップグレード** 後に申請してご利用いただけます。一部のお客様は 2024 年 9 月 1 日のリリース前にパブリックベータへ参加され、これらの OpenAPI の呼び出し権限を取得されています。以下のルールに従ってご利用ください。

| 顧客タイプ | パブリックベータ参加有無 | 影響有無 |
| --- | --- | --- |
| スマート OA のお客様 | 参加済み | 影響なし。引き続き通常どおり呼び出し可能 |
| スマート OA のお客様 | 未参加 | API 利用権限を申請後、呼び出し可能 |
| 標準版のお客様 | 参加済み | 呼び出し不可。スマート OA へのアップグレード後、API 呼び出し権限を申請することで再度呼び出し可能。権限申請手順は下記説明をご参照ください |
| 標準版のお客様 | 未参加 | 呼び出し不可。スマート OA へのアップグレード後、API 呼び出し権限を申請することで呼び出し可能。権限申請手順は下記説明をご参照ください |

権限申請パス：**開発者管理コンソール** > アプリ開発 > DingTalk アプリ > 新規アプリまたは既存アプリ > アプリをクリック >【権限管理】>【OA 承認】から、必要な権限を選択して申請します。

<Frame>

![開発者管理コンソールのアプリ権限管理ページ。OA 承認カテゴリ配下で必要な API 権限を選択して申請](https://img.alicdn.com/imgextra/i3/O1CN01oYmIaSY0ZpJ4QvZw_!!6000000007579-2-tps-2184-1024.png)

## 4. よくあるご質問

<AccordionGroup>
  <Accordion id="q1" title="専用 OpenAPI の課金ルールは？">

標準版の DingTalk のお客様はスマート OA の専用 OpenAPI をご利用いただけません。これらの API を呼び出すには、まず **スマート OA へのアップグレード** が必要です。専用 OpenAPI 利用時はスマート OA の OpenAPI 利用枠を消費します。

  </Accordion>
