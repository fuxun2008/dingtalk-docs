## 一、操作説明

<Note>
プレミアム設定は管理者のみ操作可能です。

プレミアム設定は現在の **単一フォーム** に対してのみ有効です。

設定内容：申請者設定、承認者設定、データ見出し／サマリー設定、権限設定、記入リマインダーなど。
</Note>

## 二、操作前提

*   プロセス設計は承認管理者のみ実施できるため、まず承認管理者になる必要があります。

承認管理者でない場合は、DingTalk OA承認を開き、【設定】→【承認フォームを作成】→【管理者権限を申請】の順にクリックし、「送信」をクリックします。

## 三、操作手順

### 1、プレミアム設定を開く

「**承認管理コンソール**」→「**フォーム管理**」ページで、対象フォームの操作欄にある【**編集**】をクリックします。

<Frame>

![フォーム管理から編集を開く](https://img.alicdn.com/imgextra/i1/O1CN01XbUIqd5PJ7H5bBcU_!!6000000005183-2-tps-2758-1728.png)
</Frame>

【**プレミアム設定**】をクリックしてメイン画面に入ります。

<Frame>

![プレミアム設定のメイン画面](https://img.alicdn.com/imgextra/i3/O1CN01bxi9ToYtTjG5aw0g_!!6000000004249-2-tps-2756-1726.png)
</Frame>

### 2、申請者設定

<Note>
このセクションの設定項目はすべて、**当該フォーム** の **申請者およびコメント者** にのみ有効です。
</Note>

<Frame>

![申請者設定画面](https://img.alicdn.com/imgextra/i1/O1CN01LROkJusEQXL3GQ5K_!!6000000005136-2-tps-1608-922.png)
</Frame>

<AccordionGroup>
<Accordion id="q1" title="元に戻す設定">

申請者による承認済みフォームの取り消しを許可。

デフォルト：取り消しを許可しない。

範囲：承認完了時から1〜180日。

申請者による承認中フォームの取り消しを許可。

デフォルト：取り消しを許可。

範囲：設定不可、最長180日。

コメント者によるフォーム上のコメントの取り消しを許可。

デフォルト：取り消しを許可（変更不可）。

範囲：コメント後1〜30分以内。

</Accordion>
<Accordion id="q2" title="修正設定">

申請者による承認済みフォームの修正を許可。

デフォルト：修正を許可しない。

範囲：承認完了時から1〜180日、修正回数1〜3回。

オン後：申請者が承認フォームを修正可能。

</Accordion>
<Accordion id="q3" title="送信後に承認者を選択">

申請者がフォームを先に送信し、後から承認者を選択することを許可。

デフォルト：許可。

</Accordion>
<Accordion id="q4" title="チャットに送信">

申請者による承認フォームのグループチャット／個別チャットへの送信を許可。

デフォルト：許可。

</Accordion>
<Accordion id="q5" title="複数部門オプション">

申請者が複数部門に所属している場合の所属部門のデフォルト値。

デフォルト：申請時に手動で選択。

【スマート人事】アプリの主部門に従って設定することも可能。

</Accordion>
<Accordion id="q6" title="代理送信">

現在のフローで他ユーザーによる代理申請を許可。

デフォルト：許可しない。

オン後：他ユーザーによる代理送信が可能。

</Accordion>
</AccordionGroup>

### 3、承認者設定

<Note>
このセクションの設定項目はすべて、承認者に対して有効です。
</Note>

<Frame>

![承認者設定画面](https://img.alicdn.com/imgextra/i2/O1CN01j1wJS2mxB6J2z349_!!6000000002090-2-tps-1470-999.png)
</Frame>

<AccordionGroup>
<Accordion id="q7" title="承認者の重複排除">

同一の承認者が複数回登場する場合の重複排除。

デフォルト：重複排除しない。

設定オプション：

*   フロー中に複数回登場した場合、最初の1つのみ保持

*   連続して登場した場合のみ自動で重複排除

承認者と申請者が同一人物の場合、自動承認。

デフォルト：オフ。

</Accordion>
<Accordion id="q8" title="承認コメント">

承認者に承認コメントの入力を必須とする。

デフォルト：オフ。

範囲：承認コメントの入力お知らせを設定可能。

承認者のコメントを管理者と承認者のみに公開。

デフォルト：オフ。

オン後：承認コメントは申請者には非表示。

</Accordion>
<Accordion id="q9" title="リクエスト署名を許可">

承認者が承認プロセス中に承認者を追加できるかどうか。

デフォルト：許可。

申請者のリクエスト署名を許可。

デフォルト：許可しない。

</Accordion>
<Accordion id="q10" title="手書き署名">

承認者に手書き署名の入力を必須とするかどうか。

デフォルト：オフ。

設定オプション：

*   前回の署名を使用：初回の署名以降、後続の承認で繰り返し使用可能

*   毎回再署名：承認のたびに手書き署名をやり直す

</Accordion>
<Accordion id="q11" title="承認関連メッセージ通知">

承認拒否時、それまでに承認したユーザーに通知。

デフォルト：オン。

承認拒否時、同一ノードの他の或署名承認者に通知。

デフォルト：オン。

承認拒否時、同一ノードの他の会署名承認者に通知。

デフォルト：オン。

承認同意時、同一ノードの他の或署名承認者に通知。

デフォルト：オン。

</Accordion>
<Accordion id="q12" title="承認差し戻し">

差し戻し後の再送信時に、再度承認が必要かどうか。

デフォルト：承認を最初からやり直す。

有料機能：承認済みノードをスキップし、差し戻したノードに戻す設定。

</Accordion>
<Accordion id="q13" title="時間制限承認">

有料機能。

デフォルト：オフ。

</Accordion>
<Accordion id="q14" title="ユーザー連絡先の職位情報を表示">

有料機能でオン化。

</Accordion>
</AccordionGroup>

### 5、権限管理

<Note>
権限設定はアプリ内のデータ閲覧のみに有効で、管理コンソールには適用されません。

注意：ここで管理者のデータ閲覧・操作権限を削除しても、ベーシック設定の **【フォーム管理者】** で管理不可に設定した場合、管理者はアプリ内でデータ操作ができないだけで、**管理コンソールでは引き続きデータを閲覧・削除できます**。
</Note>

**操作入口**

OA承認アプリ内→【データ管理】

<Frame>

![データ管理の入口](https://img.alicdn.com/imgextra/i1/O1CN01huShjKlKEYK5bBcW_!!6000000004494-2-tps-2758-1730.png)
</Frame>

フォーム→【会議履歴】

<Frame>

![フォームの会議履歴](https://img.alicdn.com/imgextra/i3/O1CN01L7gjek0sDFB5bREW_!!6000000001454-2-tps-2760-1744.png)
</Frame>

**デフォルト権限グループ：すべての【OA承認】管理者**

企業全体の承認データを閲覧、エクスポート、削除できます。

<Frame>

![デフォルト権限グループの設定](https://img.alicdn.com/imgextra/i3/O1CN01YhCgMqug3ZF5bBcc_!!6000000003845-2-tps-2758-1736.png)
</Frame>

**管理範囲の説明**

| 管理範囲 | 説明 |
| --- | --- |
| 自分が担当するもの | 権限グループのユーザー本人が送信したフォーム |
| 企業全体 | 企業の全メンバーが送信したフォーム |
| 同階層 | 権限グループのユーザーと同じ上長配下の全メンバーが送信したフォーム |
| 部下のもの | 権限グループのユーザー本人とその部下が送信したフォーム |
| カスタム | 権限グループのユーザー本人と、指定した部門またはメンバーが送信したフォーム |

**操作権限の説明**

| 操作権限 | 説明 |
| --- | --- |
| 閲覧 | この権限を持つ組織のユーザーは、OA承認アプリ内→【データ管理】およびフォーム→【会議履歴】で、管理範囲内の承認フォームリストと詳細を閲覧できます |
| エクスポート | この権限を持つ組織のユーザーは、OA承認アプリ内→【データ管理】およびフォーム→【会議履歴】で、管理範囲内の承認フォーム明細リストをエクスポートできます |
| 削除 | この権限を持つ組織のユーザーは、OA承認アプリ内→【データ管理】、フォーム→【会議履歴】、およびフォーム上で、管理範囲内の承認データを削除できます |
