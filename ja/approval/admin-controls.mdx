## 1. フォームコントロール詳細

承認フォームは各種コントロールで構成され、コントロールは以下の3種類に分類されます。

| コントロール分類 | 含まれるコントロール |
| --- | --- |
| レイアウトコントロール | 分割 |
| ベーシックコントロール | 単一行入力欄、複数行入力欄、数値入力欄、単一選択、複数選択、日付、日付範囲、説明文、身分証、電話番号 |
| 拡張コントロール | カスケード／分類、画像、明細／テーブル、金額、添付、手書き署名、連絡先、部門、現在地、数式、関連承認フォーム、都道府県／市区町村、評価点 |

### 1.1 レイアウトコントロール

分割は、デスクトップ版での情報表示効率を最適化するために使用され、フォームフィールドを複数列に並べて表示できます。

<Note>
分割効果は**デスクトップ版**のみで有効です。スマートフォン版では引き続き1列で表示されます。本コントロールは属性設定、データ制約、検索の対象外です。
</Note>

### 1.2 ベーシックコントロール

ベーシックコントロールは、以下の共通設定項目を共有します。

| 共通設定項目 | 詳細説明 |
| --- | --- |
| 見出し | フォームに表示される見出し。最大50文字まで対応 |
| プレースホルダー | 未入力時にフォーム入力欄に表示されるグレーのプレースホルダー。最大50文字まで対応 |
| デフォルト | 未入力時にフォーム入力欄に表示されるデフォルト内容。ノード権限が「編集可能」の場合、当該コントロールに対応するフィールド内容を変更可能 |
| 必須設定 | デフォルトはオフ。有効にすると、フォーム申請時に当該コントロールに対応するフィールドの入力チェックを行い、未入力の場合は申請できません |
| 印刷設定 | デフォルトはオン。オフにすると、当該コントロールに対応するフィールドはダウンロードおよび印刷されたフォーム詳細PDFに表示されません |

| 検索範囲 | 承認フォームの見出しによるあいまい検索に対応 |
