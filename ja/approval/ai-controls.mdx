## 一、機能概要

<Note>
一言価値：承認者がフォームの重要情報を素早く把握し、判断効率を高めます。

適用ロール：承認者

対応フィールド：テキスト、数値、画像などほとんどの承認フォームコントロール。添付、ビジネスコントロールグループには未対応です。

コア機能：管理者がコントロールスキルを選択 → 承認者がフォームを開いた際に自動呼び出し
</Note>

| 使用前 | 使用後 |
| --- | --- |
| フォームのコンテンツが多く、要点が見つからない | テキスト要約：秘書のように、申請の核心内容を一言で要約します |
| 日付、金額、数量などの重要情報が分散し、見落としやすい | 情報抽出：秘書のように、重点情報を抽出して構造化表示します |
| 多国間承認で、承認フォームの内容が理解できない | テキスト翻訳：随行翻訳者のように、承認処理が必要な場面で翻訳をサポートします |
| 画像情報を一枚ずつ確認する必要があり、効率が低い | 画像解読：熟練者のように画像を解読し、専門的な判断を提示します |

## 二、適用シーン

<Note>
入力：フォーム内のコントロール（カスタム選択、最大10個まで対応）

判断根拠：デフォルトの4つのスキル + カスタムprompt

出力：承認者に向けて結論を出力
</Note>

## 三、操作手順

<Steps>

<Step title="【AIコントロール】をフォームに追加">

右上の【承認フォーム管理】をクリックして管理コンソールに入り、【AIコントロール】を追加したいフォームを検索します。【編集】をクリックしてフォーム設計ツールに入り、【フォーム設計】をクリックして【AIコントロール】をフォームに追加します。

<Frame>

![フォーム設計ツール画面。左側のコントロールリストからAIコントロールをフォームにドラッグ](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/yBRq1ZPyX12BWOdv/img/72c1a4d1-487a-45c8-94cf-d6dcf9b07964.png)
</Frame>

</Step>

<Step title="【AIコントロール】を設定">

【AIコントロール】の見出しと【使用シーン】を選択するとモデルが自動でマッチングされます。対応が必要なフィールドを選択し、AIお知らせボックスに要件を入力します。

<Frame>

![AIコントロール設定パネル。見出し、使用シーン、対応フィールド、AI結果の要件を設定可能](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/yBRq1ZPyX12BWOdv/img/e15531de-5904-4b5b-ae54-1d1ed2212abb.png)

### 4、画像解読

prompt例：

```text
この店舗の山積み陳列が整然としているか、ショーウィンドウの陳列が美しいか、広告表示が正常に貼り出されているかを分析してください。
画像に基づいてこの店舗を採点し、減点理由を重点的に説明してください。
山積み陳列は満点40点、最大40点まで減点可能です。最低4枚の画像が必要で、各画像の最高得点は10点、内容が関連しない画像は得点しません。画像に異常がある場合は異常の程度に応じて減点し、最低0点、4枚を超える場合は得点が最も高い4枚の画像を採用します。
ショーウィンドウは満点30点、最低3枚の画像が必要で、その他のルールは同上です。
広告表示は満点30点、最低3枚の画像が必要で、その他のルールは同上です。
```

## 五、よくある質問

<AccordionGroup>

<Accordion title="AIコントロールは誰が閲覧できますか？">

AIコントロールは他のコントロールと同様に、ノードごとに表示範囲を設定できます。

<Frame>

![フローノードのフィールド権限設定画面。AIコントロールはノードごとに表示範囲を設定可能](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/yBRq1ZPyX12BWOdv/img/16d3ffdb-98d8-4162-8f56-78e4ccfc3ddd.png)
</Frame>

</Accordion>

<Accordion title="どのコントロールに対応していますか？">

テキスト要約、情報抽出、テキスト翻訳：説明テキスト、画像、明細／スプレッドシート、添付、手書き署名、業界連絡先部門、関連承認フォーム、エンジニアリングプロジェクト、すべてのビジネスコントロール、身分証識別、すべてのビジネスコントロールグループには未対応です。

画像解読：画像コントロールのみ対応。

</Accordion>

<Accordion title="モバイル版でも使えますか？">

現在、設定状態はPC版とWeb版のみに対応し、使用状態はモバイル版とPC版の両方に対応しています。

</Accordion>

<Accordion title="AIは私の承認コンテンツを読み取りますか？">

AI機能を使用する際にのみ、現在のコンテンツを一時的に送信して生成に使用し、その後は保存も記録も行いません。企業データの安全要件に準拠しています。

</Accordion>

</AccordionGroup>
