## 1. 役割の説明

<Note>
DingTalk OA承認において、管理者ではないもののデータを管理できる主管や担当者などの操作者を「データ管理者」と呼びます。

データ管理者の操作権限：権限スコープ内のデータの閲覧、エクスポート、削除。

データ管理者は【OA承認】-【データセンター】、【OA承認】-フォーム-【会議履歴】でデータ管理操作を実行できます。

**注**：データ管理者の管理範囲や操作権限は、承認管理者がフォーム内で設定します。
</Note>

## 2. 操作の前提

承認アプリ内のデータ権限は、デフォルトでは「**本人が申請または参加**」した承認フォームのみ「**閲覧**」できます。より広いデータ範囲とより多くの操作権限を取得したい場合は、管理者がフォーム内で【**権限グループの作成**】を行う必要があります。

フォーム-【編集】-【プレミアム設定】-【権限管理】から【権限グループの追加】を行い、【管理範囲】と【操作権限】を設定します。

<Frame>

![権限グループ設定画面のスクリーンショット](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/2M9qP5jJXRgRYO01/img/274762ad-1afd-4563-9989-edb1308313a7.png)
</Frame>

**管理範囲の説明**

| 管理範囲 | 説明 |
| --- | --- |
| 自分が担当 | 権限グループのメンバー自身が提出したフォーム |
| 全社 | 企業内のすべてのユーザーが提出したフォーム |
| 同一階層 | 権限グループのメンバーと同じ主管に属するすべてのユーザーが提出したフォーム |
| 部下 | 権限グループのメンバー自身とその部下が提出したフォーム |
| カスタム | 権限グループのメンバー自身、および指定された部門またはメンバーが提出したフォーム |

**操作権限の説明**

| 操作権限 | 説明 |
| --- | --- |
| 閲覧 | この権限を持つ組織メンバーは、OA承認アプリ内の【データ管理】およびフォーム-【会議履歴】で、管理範囲内の承認フォームのリストと詳細を閲覧できます。 |
| エクスポート | この権限を持つ組織メンバーは、OA承認アプリ内の【データ管理】およびフォーム-【会議履歴】で、管理範囲内の承認フォームの明細リストをエクスポートできます。 |
| 削除 | この権限を持つ組織メンバーは、OA承認アプリ内の【データ管理】、フォーム-【会議履歴】、およびフォーム上で、管理範囲内の承認データを削除できます。 |

## 3. データ管理者の主要操作

### 1. データの閲覧

すべてのフォームデータを閲覧するには、【OA承認】-【データ管理】に移動します。

<Frame>

![データ管理画面のスクリーンショット](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/pLdn55XrMNw57no8/img/978dde68-fa3f-454c-b691-98e880aa8f41.png)
</Frame>

特定のフォームデータを閲覧するには、【OA承認】-フォーム-【履歴データ】に移動します。

<Frame>

![履歴データ画面のスクリーンショット](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/pLdn55XrMNw57no8/img/deda141b-b44b-44c6-b5a5-9820b9426c60.png)
</Frame>

### 2. データの検索・エクスポート

フォーム名、承認ステータス、申請者、承認番号、申請日時、完了日時でデータを検索できます。期間は最大で半年間まで選択可能です。

<Frame>

![検索条件画面のスクリーンショット](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/pLdn55XrMNw57no8/img/6972e028-e77b-433e-8bc7-7f96df2cbec2.png)
</Frame>

エクスポート先は、スプレッドシートまたはローカルへのダウンロードから選択できます。

<Frame>

![エクスポート方式選択画面のスクリーンショット](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/pLdn55XrMNw57no8/img/7d41886e-bb56-4b25-8af7-e8243257a07c.png)
</Frame>

ローカルへのダウンロードを選択すると、業務通知でローカルスプレッドシートが送信されます。

<Frame>

![業務通知でのスプレッドシート受信画面のスクリーンショット](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/pLdn55XrMNw57no8/img/58851a44-339b-4941-99c7-d81c311f0b96.png)
</Frame>

### 3. データの削除

絞り込み・検索後、すべて選択して削除することも、一部のデータのみを選択して「選択項目を削除」を実行することもできます。

<Frame>

![データ削除画面のスクリーンショット](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/pLdn55XrMNw57no8/img/e2a2eff8-c36a-4c87-95de-98ca0fc64dcb.png)
</Frame>

削除は影響が大きい操作のため、本人の署名による確認が必要です。

<Frame>

![署名確認画面のスクリーンショット](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/pLdn55XrMNw57no8/img/861f0997-3bca-48ad-86ba-5d1f67d0f924.png)
</Frame>

### 5. ダウンロード

「閲覧」をクリックしてフォーム詳細を開いた後、右上の「ダウンロード」をクリックすると、現在のフォームのPDFをローカルに保存できます。また、そのままクラウド印刷も可能です。

<Frame>

![フォームPDFダウンロード画面のスクリーンショット](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/pLdn55XrMNw57no8/img/a7834610-2c68-4723-9b6f-7653a5c29e61.png)
</Frame>

### 6. 操作ログの確認

操作ログでは、**操作者本人**によるエクスポート、印刷、削除の記録を確認できます。

<Frame>

![操作ログ画面のスクリーンショット](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/pLdn55XrMNw57no8/img/6b9e0f44-0aa2-4d10-9d8d-dfd00a53c027.png)
</Frame>
