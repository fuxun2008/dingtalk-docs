## 1. 操作説明

<Note>
管理者は管理コンソールで代理設定を操作できます。

設定項目：被代理人、代理人、代理期間。
</Note>

## 2. 操作の前提条件

*   プロセス設計を実施できるのは承認管理者のみのため、まず承認管理者になる必要があります。

承認管理者でない場合は、DingTalk OA承認を開き、「設定」→「承認フォームの作成」→「管理者権限の申請」の順にクリックし、「送信」をクリックします。

## 3. 操作手順

### 3.1 代理設定画面を開く

「**承認管理コンソール**」→「**システム管理**」→「**代理設定**」の順に進みます。

<Frame>

![代理設定画面](https://img.alicdn.com/imgextra/i1/O1CN01XzJSKu9nVvC4gn7Y_!!6000000002762-2-tps-2310-1634.png)
</Frame>

### 3.2 代理人を設定する

「**被代理人**」と「**代理人**」を選択し、「**代理期間**」を指定します。

<Frame>

![代理人設定画面](https://img.alicdn.com/imgextra/i2/O1CN01IHcerq6KcQL4gn7U_!!6000000000321-2-tps-2310-1630.png)
</Frame>

### 3.3 代理レコードを確認する

「**代理レコード**」をクリックすると、「**被代理人**」または「**代理人**」で代理レコードを検索できます。また、有効中の代理レコードを取り下げることも可能です。

<Frame>

![代理レコード画面](https://img.alicdn.com/imgextra/i2/O1CN013qPjMQP5ZiD2LWMh_!!6000000000019-2-tps-1156-819.png)
</Frame>
