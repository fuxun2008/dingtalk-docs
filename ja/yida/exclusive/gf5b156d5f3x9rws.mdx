専用クラスター環境のアプリデータはプライベート環境に保存されており、パブリックネットワークからアクセスできません。そのため、DingTalk Open Platform 上の Yida OpenAPI ではこれらのデータを取得できません。クラスター環境内で OpenAPI を呼び出す必要があります。クラスター環境の OpenAPI は基本的に DingTalk Open Platform と同じで、ホストと必要な AK/SK のみが異なります。

本記事では、Yida専用版クラスター環境で Yida OpenAPI を呼び出す方法について説明します。

<Note>
注意:

Yida専用版は現在、高頻度で利用されるデータサービス API を公開しています。2023年12月31日時点で DingTalk Open Platform 上で利用可能な Yida API 機能に基づき、合計 52 個の OpenAPI が利用可能です。
</Note>

## 呼び出しフロー

クラスター環境における Yida API の呼び出しは、DingTalk Open Platform と類似しています。DingTalk Open Platform 上のすべての関連 OpenAPI は api.dingtalk.com 経由で呼び出されます。クラスター版 OpenAPI の場合は、api.dingtalk.com を組織のクラスター版 Yida ドメインに置き換えるだけです。

1. 社内の Yida専用版クラスターのドメイン（例: ddyd.corp.com）を取得します。
2. 社内のクラスター版の AK と SK を取得します。

<Note>
社内の DingTalk 管理者にお問い合わせください。[DingTalk Open Platform](https://open-dev.dingtalk.com/) にログインし、社内アプリの中から「Yida Dedicated Cluster」を検索し、**Yida Dedicated Cluster Authentication App** という名前のアプリから関連情報を取得します。
</Note>

<Steps>
  <Step title="ステップ 1">
    前の手順で取得した AK/SK を使用して /v1.0/oauth2/accessToken エンドポイントを呼び出し、アプリの access_token を取得します。リクエストパラメータについては、社内アプリの access_token を取得する方法を参照してください。

    <Warning>
    Open Platform では、呼び出しは https://api.dingtalk.com/v1.0/oauth2/accessToken となります。

    社内の Yida ドメインが https://your-org-private-yida-domain.com であると仮定すると、クラスター版の呼び出しは次のようになります:

    https://your-org-private-yida-domain.com/v1.0/oauth2/accessToken

    access_token はデフォルトで 2 時間有効です。
    </Warning>
  </Step>
  <Step title="access_token を使用して Yida API を呼び出す">
  </Step>
</Steps>

DingTalk Open Platform は、開発者向けに Java、PHP、Python、.NET の SDK を提供しています。クラスター版 OpenAPI も同様の呼び出しをサポートしています。

<Note>
社内アプリとサードパーティ社内アプリは同じサーバーサイド SDK を共有しています。以下のいずれかのリンクをクリックしてダウンロードしてください。

- 社内アプリ: サーバーサイド SDK をダウンロードします。
- サードパーティ社内アプリ: サーバーサイド SDK をダウンロードします。
</Note>

5. DingTalk Open Platform SDK を使用している場合は、次の変更を適用します。

変更 1: ドメインが http を使用する場合、config.protocol = "http" を設定します。

変更 2: client._endpoint に社内の実際の Yida ドメインを明示的に設定します。

```java
private static com.aliyun.dingtalkyida_2_0.Client createOpenApiClient() {
        Config config = new Config();
        config.regionId = "central";
        config.protocol = "http";
        config.connectTimeout = 60 * 1000;
        config.readTimeout = 60 * 1000;
        try {
            com.aliyun.dingtalkyida_2_0.Client client = new com.aliyun.dingtalkyida_2_0.Client(config);
          client._endpoint =  "your-org-private-yida-domain.com";
            return client;
        } catch (Exception e) {
            throw new RuntimeException(e);
        }
    }
```
