専用版限定

Yida専用版では、組織のパフォーマンスデータ詳細を確認できます。本記事では、Yida専用版のパフォーマンスデータ詳細について説明します。

データ詳細の指標は以下のとおりです。

## 今週の1日平均訪問数

| **指標** | **説明** |
|---|---|
| 今週の1日平均訪問数UV | 今週における、社内全ユーザーによるYidaへの平均訪問数です。 |
| 業界参考値 | 組織が属する業界の1日平均訪問数です。 |
| 直近7日間の訪問数上位10ユーザー | 直近7日間で最も訪問数が多かった上位10ユーザーの訪問数です。 |
| 直近7日間の訪問数PV折れ線チャート | 直近7日間のPV合計を示す折れ線チャートで、訪問トレンドを確認できます。 |
| 直近30日間のアプリ訪問数 | 直近30日間における社内従業員のYidaアプリ訪問の詳細です。 |

## 権限付与利用状況データ

| **指標** | **説明** |
|---|---|
| 権限付与ユーザー数 | Yidaを利用可能な社内ユーザーの合計数です。 |
| 業界参考値 | 組織が属する業界において、Yidaを利用可能な平均人数です。 |
| 部門別利用状況 | 社内の各部門におけるYida利用者の割合です。 |
| アクティブ利用部門 | 社内の各部門におけるYida利用者の合計人数です。 |
| （権限付与ユーザーの）最近の利用記録 | 直近30日間における社内従業員のYida訪問の詳細です。<br />**注意**：権限付与ユーザーの最近の利用記録は、データ更新ルールが `T + 1` です。権限付与後に該当ユーザーの訪問記録がない場合、権限付与時刻が最終訪問時刻として扱われます。権限付与後に訪問記録がある場合は、実際の最終訪問時刻が採用されます。権限付与ユーザーの最終訪問時刻が権限付与時刻より前の場合は、以前に権限付与された後、権限が取り消された可能性を示しています。 |

| 先週の累計新規インスタンス数 | 組織で先週作成された新規アプリ数です。 |

| 先週送信されたインスタンス表 | 先週社内で送信されたインスタンスの詳細です。 |

## 権限付与済みアクセスデータ

- 大企業では、プラットフォームライセンスの権限付与アカウントを大量に購入するケースが多くあります。権限付与された従業員が実際に活用しているかどうかは、組織のデジタル化コストとビジネス価値を測る重要な参考指標となります。
- 組織内のすべての権限付与ユーザーの最終訪問時刻記録の詳細を確認でき、詳細情報はExcel形式でエクスポート可能です（ユーザーの権限付与日がデフォルトの初回タイムスタンプとして使用されます）。
- 組織のプラットフォーム管理管理者は、アクティブ状態（最終訪問時刻）に基づいて組織独自のアカウント管理戦略を策定でき、権限付与管理画面から非アクティブなアカウントを一時的に凍結できます。
