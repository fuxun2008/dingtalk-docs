YiDAのブロードキャスト可能なポータルでは、現在8種類のコンポーネントを提供しています。コンポーネントごとに機能が異なるため、ポータルデザイナーで用途に応じたコンポーネントを選択してください。

## コンポーネント一覧

> データ読み込みとパフォーマンスを最適化するため、1つのポータルに配置するコンポーネントは合計20個以内、指標は5個以内を推奨します。

| **コンポーネント名** | **ユースケース** |
|---|---|
| [**指標**](/ja/yida/portal/tax9ktxaqxxbkcft) | レポートの指標コンテンツを素早く参照して、データ表示・分析に活用でき、必要に応じて**データブロードキャストを有効**にできます。**1つのポータルページにつき最大5個の指標を設定できます。** |
| [**クイックエントリ**](/ja/yida/portal/kb5a0gh7oq93ffgl) | アプリ内ページをリンクしたり外部リンクを参照したりして、さまざまなシーンのページに素早くアクセスできます。 |
| [**タスク指標**](/ja/yida/portal/cnl6wehhgf0iiz4e) | 異なる作業フローステータスのタスク指標を素早く確認できます。**データはデフォルトでYiDAのタスクセンターから読み取ります。1ページにつき本コンポーネントは1個のみ設定できます。** |
| [**タスクリスト**](/ja/yida/portal/vntvxl7vsxwfgt09) | 異なる作業フローステータスのタスクリストを素早く確認できます。**データはデフォルトでYiDAのタスクセンターから読み取ります。1ページにつき本コンポーネントは1個のみ設定できます。** |
| [**お知らせボード**](/ja/yida/portal/ik3610wn0kc5twhv) | 画像付きテキストの概要を素早くアップロードし、お知らせとして表示できます。 |
| [**ニュースリスト**](/ja/yida/portal/bd77lg07oxxuuhcg) | 画像付きテキスト素材をアップロードし、ニュースリストとして表示できます。 |
| [**カルーセル**](/ja/yida/portal/xbn4iv7pclumwhep) | リンクを埋め込んだ複数の画像をアップロードし、ループ再生のカルーセル形式で表示できます。 |
| [**DingTalk予定**](/ja/yida/portal/wohqsumlwfir3d4u) | 公式のDingTalkカレンダーを直接参照して、会議予定を素早く確認できます。**データはデフォルトでDingTalkカレンダーから読み取ります。1ページにつき本コンポーネントは1個のみ設定できます。** |

## 特記事項

ポータルコンポーネントライブラリでは、現在すぐに使える利用頻度の高い標準コンポーネントを提供しています。今後、ポータルコンポーネントはカスタマイズに対応し、シナリオの拡張と機能強化を実現していく予定です。ポータルコンポーネントに関するご提案やご要望がございましたら、個別リクエストフォームから送信してください。
