基本情報管理ページでは、組織構成内でのYida利用状況に関するデータを確認できます。組織の基本情報やリソース消費状況など、重要な情報を一覧で閲覧できます。

## 組織の基本情報

このページでは、以下の情報を確認できます。

- エディション情報：Yidaでは現在、Freeプラン、ベーシック版、プロフェッショナル版、専用版の4つのエディションを提供しています。社内で現在利用中のYidaエディションがここに表示されます。
- 組織名：現在ログイン中の組織の名称です。
- Corp ID：DingTalkが登録済みの各組織に割り当てる固有識別子です。企業アカウントの識別・区別、およびデータの分離と安全性の確保に使用します。
- Corp トークン：組織の認証情報とも呼ばれ、組織リソースおよびサービスへのアクセスを認証・認可するためのセキュリティトークンです。
- ドメイン：Yidaで組織が使用するドメインです。Yidaの有料エディションでは、セカンドレベルドメインを最大3回まで変更できます。YidaのFreeプランは、現時点でセカンドレベルドメインの変更に対応していません。

<Note>
変更できるのはセカンドレベルドメインのみです。例えば、`***.aliwork.com`というドメインの`***`部分をカスタマイズできます。
</Note>

## リソース容量

リソース容量セクションでは、組織が現在使用しているリソース量と、契約エディションの上限値を分かりやすく確認できます。

| **リソース** | **説明** |
|---|---|
| **認証ユーザー** | 社内でYidaを利用できるユーザーの総数です。ユーザー数を増やすには、下部の**追加購入**ボタンをクリックしてください。 |
| **組織データ容量** | 社内のすべてのアプリで利用可能なフォームデータの合計容量です。合計容量を増やすには、下部の**追加購入**ボタンをクリックしてください。 |
| **単一フォームデータ上限** | 単一フォームで扱えるデータ容量の上限値です。上限を引き上げるには、下部の**追加購入**ボタンをクリックしてください。 |
| **組織の添付容量** | 現在の組織がYidaプラットフォーム全体でアップロードした添付ファイルの累計容量です。フォームの添付、アプリアイコン、マルチメディア添付（カスタムページ）、フォームでアップロード済みだが未送信の添付などを含みます（これらに限りません）。<br />**注意**：一部のエディションでは、DingTalk企業ストレージとの連携による容量共有に対応しています。詳細は[YidaとDingTalk企業ストレージの連携](https://docs.aliwork.com/docs/yida_updates/yvhg4bx5wkiugnsv#zufFX)をご覧ください。 |

## プレミアム機能

| **リソース** | **説明** |
|---|---|
| **Yidaデータダッシュボード** | DataVダッシュボードの使用状況と利用可能な総クォータを表示します。詳細 |
| **印刷** | DingTalk印刷の利用可能数と総利用状況を表示します。 |
| **データソース** | 利用可能なファイルおよびデータベースの数と合計数を表示します。 |
| **電子署名** | 残りの署名回数を表示します。<br />電子署名を利用するには、事前にサービスを有効化し、電子署名アカウントを新規登録する必要があります。 |
| **データ準備** | データ準備および自動実行の使用回数と合計回数を表示します。 |
| **OCR認識（AIコンポーネント）** | OCR認識の使用回数と合計回数を表示します。 |
