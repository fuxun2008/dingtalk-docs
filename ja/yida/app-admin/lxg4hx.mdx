Yidaプラットフォームでは、アプリのアクセス URL をカスタマイズできるため、アプリの宣伝や共有がより簡単に行えます。設定はアプリ設定ページで行います。本記事では、アプリのカスタムアクセス URL を設定する方法について説明します。

## 手順

1. Yidaワークベンチにログインし、**マイアプリ**をクリックします。
2. 対象のアプリを見つけ、アプリの右下にある **···** > **アプリ設定**をクリックしてアプリ設定ページを開きます。

<Steps>
  <Step title="ベーシック設定ページでアクセス URL セクションに移動し、カスタムアプリアクセス URL フィールドにカスタムアクセス URL を入力します。">
    <Note>
    カスタム URL には、英大文字・小文字、数字、アンダースコア（_）、ハイフン（-）、スラッシュ（/）のみ使用できます。使用したい URL がすでに使われている場合は、固定値にするために接尾辞を追加してください。例：`your_personal-address/enjoy/01`。
    </Note>
  </Step>
  <Step title="設定が完了したら、ページ下部の保存をクリックします。">
  </Step>
</Steps>
