現在のアプリのすべてのフォームデータソースを一元管理します。詳細は下表をご参照ください。

| **名前** | **用途** |
|---|---|
| [**データセット**](/ja/yida/app-admin/roe3o1) | 現在のアプリ内のすべての単一テーブルデータソース、ビューテーブル（複数テーブル関連付け）、データ準備（ビッグデータオフラインソリューション）、およびクロスアプリ（フォーム）データソースを一元管理します。データセットは、データ相互接続シナリオにおけるYiDAの標準データ制御単位として機能します。 |
| [**ビューテーブル**](/ja/yida/app-admin/oim554) | ビューテーブルは、単一テーブルまたは複数テーブルの関連付けを通じて既存のフォームデータを前処理し、さらに中間テーブルモードにも対応してデータ処理能力を強化します。現在、レポートデータの可視化やフォーム連動などのシナリオでは、ビューテーブルからデータを直接呼び出すことができます。 |
| [**クロスアプリ**](/ja/yida/app-admin/btrtnt) | クロスアプリデータ取得とも呼ばれます。現在のアプリ内で他のYiDAアプリのフォームデータを呼び出し、YiDAアプリ間のデータ相互接続を実現します。 |
| [**データソース**](/ja/yida/app-admin/duy0wi) | データソースは、データの出所に関する情報を示します。YiDAは、ファイルやデータベースなどのデータソースの管理と保守に対応しています。 |
| [**データカード**](/ja/yida/app-admin/cpkmxvpgchx339qq) | 新しいデータ可視化のキャリアです。完全な分析パイプラインを持つレポートとは異なり、データカードは断片的でシナリオベースのチャートを迅速に組み合わせて、YiDAポータルで使用できます。また、カードにはブロードキャスト機能が組み込まれており、データをスナップショットとしてグループに同期します。 |
| [**データサービス**](/ja/yida/app-admin/fw9qtv) | データサービスは、特定のフィールドを選択してデータセットを処理し、APIサービスに変換します。現在は、統合と自動化 / 作業フローデザイナーのカードノード内でのみ利用可能です。 |
| [**データ準備**](/ja/yida/app-admin/ykemo6) | データ分析および利用の前に、生データをクレンジング、マージ、変換して、分散したデータを標準化されたデータセットに集約し、可視化分析やデータドリブンな意思決定をサポートします。 |
