本ページでは、YiDAで利用可能なユーザー関連の全関数を紹介します。

## 関数一覧

| **関数名** | **説明** |
|---|---|
| [USER](/ja/yida/form/vwncwe) | 引数なしモード：User()は現在ログイン中のユーザーを返します。引数ありモード：User(level)は現在ログイン中のユーザーの上長を返します。levelで取得する上長の階層を指定します。 |
| [USERFIELD](/ja/yida/form/oyuexdmpaxiys2tm) | ユーザー検索ボックスに関連付けられた基本情報を自動的に取り込みます。 |
| [DIRECTOR](/ja/yida/form/pvw37ge84kxg9x28) | 現在ログイン中のユーザーの上長の名前を取得します。 |
| [EMPLOYEE](/ja/yida/form/sxc8gv9dkhmt8zro) | 対応するユーザー情報オブジェクトの配列（ユーザーコンポーネントの内部値）を返します。 |
| [GETUSERNAME](/ja/yida/form/zl5s2mdi2ue214n4) | 現在ログイン中のユーザーの名前を取得します。 |
| [LOGINUSER](/ja/yida/form/iak2o5xcbksb13wz) | ログイン中のユーザー。 |
| [LOGINUSERWORKNO](/ja/yida/form/sprth45e4nh19yhw) | 現在ログイン中のユーザーの固定値の社員番号（社員UserID）を取得します。 |
| [DEPTNAME](/ja/yida/form/igrvxuztr0syw9sn) | 指定したuserIdに基づき、ユーザーの部門情報を取得します。 |
