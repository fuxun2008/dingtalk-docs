一行テキストコンポーネントは、身分証番号、電話番号、学籍番号、社員番号、銀行カード番号、会員番号などの数値入力に対応します。プレーンテキストの入力にも利用できます。

## 基本機能

QRコードスキャン、文字数カウンター、ワンクリッククリア、および高度なページリダイレクトに対応しています。

### QRコードスキャン

#### スキャンモード

> DingTalkのスキャン機能を呼び出し、QRコードやバーコードのデータを一行テキストコンポーネントに素早く取り込みます。
> 
> 機器点検や資産棚卸しなど、スキャンによる入力が必要なシーンでよく利用されます。

#### スキャンタイプ

**対応するスキャンタイプ：** `すべて`、`QRコードのみ`、`バーコードのみ`。

**すべて：** 1つのコントロールで`QRコード`と`バーコード`の両方を認識できます。

アルバムから画像を選択して認識することもできます。

## 高度な使い方

QRコードやバーコードのスキャンで取得した情報をリンクに組み込み、ページのリダイレクトをトリガーできます。

たとえば、スキャンして商品詳細を表示する、スキャンして飲食を注文するといったシーンで活用できます。

結果：

**パス：** 一行テキスト >> プレミアム >> アクションを作成し、固定のURLを設定します。

**例：** 新規アクション用のJSを記述する際に、固定のURLを設定します。スキャンが成功すると、取得した情報がURLパラメータとして渡され、あらかじめ設定した固定URLへリダイレクトして詳細を表示します。これにより、スキャン成功後の自動ページリダイレクトが実現します。

参考設定：

**注意：** コード内のハイライト部分を、右側に表示される固定値の識別子に合わせて更新してください。

**固定値の識別子：** 各コントロールのID証のようなものです。コントロールごとに異なる固定値の識別子を持ちます。

**貼り付けてそのまま使える参考JSコード：**

```javascript
export function onScanCodeSuccess(text) {
  const fieldId = 'editorField_klbopk6r';
  // text が http または https で始まらない場合、以下のテキストは表示しません。
  if (!/^http(s)/.test(text)) {
    this.$(fieldId).setValue(null);
    return text;
  }
  const html = `<div><span style="color: #0089ff;"><a style="color: #0089ff;" href="${text}" target="_blank">クリックしてトレーサビリティ記録を表示</a></span></div>`;
  // 値を代入します
  this.$(fieldId).setValue(html);
  // 注意：onScanCodeSuccess イベントは必ず text を return する必要があります。そうしないと値が正しく設定されません。
  return text;
}
```
