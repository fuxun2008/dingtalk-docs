## 1. 概要

フィールドを選択してフィルターを設定し、データを表示します。

**注意：フィルターパネルが前回開かれていたか閉じていたかを、システムが記憶します。**

**パス**：フォーム >> データ管理 >> フィルター >> フィルターの設定。以下の例をご覧ください。

- 演算子は現在、Is empty / Is not empty には対応していません。

### 1.3 トークン検索

アップグレード前は、1文字のあいまい検索や完全一致検索に対応していませんでしたが、この点が改善されました。例：

「萄」を検索した場合：

- 葡萄
- 葡萄树
- 葡萄气泡水
- 吃葡萄要吐葡萄皮
- 吃不到葡萄说葡萄酸

結果は**新しい順に表示されます**。

## 2. 操作手順

手順：対象のフォームに移動 >> データ管理 >> フィルター >> フィルターを追加 >> フィルタリングするフィールドを選択。

現在対応している機能：

- 複数のフィルター条件を AND / OR ロジックで組み合わせ可能。
- 新しい検索ストレージでは、検索対象となるフィールドの制限が撤廃されました。デフォルトで、追加したすべてのフィルターフィールドが検索対象になります。
- 以前のフィルターは、再利用しやすいように保持されます。
- ワンクリックですべてのフィルターをクリア可能。
