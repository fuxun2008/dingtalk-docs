本記事では、YiDAで利用可能なすべてのテキスト関数を紹介します。

## 関数一覧

| **関数名** | **説明** |
|---|---|
| [ARRAYGET](/ja/yida/form/mggsmf) | データセット内の指定位置の値を返します。 |
| [CONCATENATE](/ja/yida/form/mbe6045dlu6ebg33) | 複数のテキスト文字列を1つの文字列に結合します。 |
| [LEFT](/ja/yida/form/xylna43s4gpoyz9k) | テキスト文字列の先頭から、指定した文字数分の文字を返します。テキストの長さが指定した文字数より短い場合は、元のテキストをそのまま返します。 |
| [RIGHT](/ja/yida/form/ch2gvwhzh2bn9u82) | テキスト文字列の末尾から、指定した文字数分の文字を返します。 |
| [LEN](https://docs.aliwork.com/ytnegt00zgbwos60) | テキスト文字列の文字数を返します。 |
| [LOWER](/ja/yida/form/aire3ioygvfi7vul) | テキスト文字列内のすべての大文字を小文字に変換します。 |
| [UPPER](/ja/yida/form/fm0og6ccdh0n0q2k) | テキスト文字列内のすべての小文字を大文字に変換します。 |
| [MID](/ja/yida/form/pghawu8hdwng91in) | テキスト文字列の指定位置から、指定した文字数分の文字を返します。 |
| [PINYINHEADCHAR](/ja/yida/form/dvfmdhg8i3ohg0c4) | 文字列内の各漢字のピンイン頭文字を大文字で返します。 |
| [REPLACE](/ja/yida/form/gtz0638tp96gbnhf) | 指定した文字数に基づき、テキスト文字列の一部を別のテキスト文字列に置換します。 |
| [REPT](/ja/yida/form/scd5m0bi74omfpyg) | テキストを指定した回数分繰り返します。 |
| [RMBFORMAT](/ja/yida/form/ff4mghegi9kbsc7m) | 数値を人民元（RMB）形式にフォーマットします。 |
| [SEARCH](/ja/yida/form/mhwnrwy04c03o2z4) | テキスト2内におけるテキスト1の開始位置を返します。 |
| [SPLIT](/ja/yida/form/yf6hkwf5lzcyin93) | 指定した区切り文字でテキストを配列に分割します。ARRAYGETと組み合わせることで、指定位置の文字を取得できます。 |
| [TEXT](/ja/yida/form/bt0wov266h45hpi4) | 数値をテキスト形式に変換します。 |
| [TRIM](/ja/yida/form/tzmpoqk3e4szn7ar) | 文字列の先頭と末尾のスペースを削除します。ただし、単語間の1つのスペースは保持します。 |
| [UUID](/ja/yida/form/xb7gg8vrhik5yg5s) | 一意の文字列を生成し、一行テキストフィールドに割り当てます。 |
| [VALUE](/ja/yida/form/awk6sfyg9vcqe1g1) | テキストを数値に変換します。通常、既にデータが入力されており、再計算が必要な場合に使用します。 |
