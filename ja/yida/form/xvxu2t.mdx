## 1. 予定変更の履歴の概要

インポート、エクスポート、変更、ファイルのダウンロード、印刷の各操作記録を照会できます。

<Frame>
  ![](https://gw.alicdn.com/imgextra/i4/O1CN01kT5LdzbkdaG5oH9e_!!6000000000734-2-tps-2862-1164.png)
</Frame>

**ご注意**：繰り返しダウンロードの有効期限は7日間です。この期限は、インポート記録、エクスポート記録、変更記録、ファイルダウンロード記録、印刷記録のすべてに適用されます。

<Frame>
  ![](https://gw.alicdn.com/imgextra/i4/O1CN01uz04GTu7T7B5qHxQ_!!6000000000694-2-tps-2878-890.png)
</Frame>

### 1.1 エクスポート記録の照会

**パス**：フォーム／ワークフローフォーム >> データ管理 >> エクスポート記録 の順にクリックします。

添付名称、ステータス、操作者、更新日時で絞り込むと、エクスポート記録を素早く見つけられます。次の図を参照してください。

<Frame>
  ![](https://gw.alicdn.com/imgextra/i2/O1CN0152GzobOKZFG5q2PW_!!6000000004538-2-tps-2876-1130.png)
</Frame>

エクスポート記録

### 1.2 インポート記録の照会

**パス**：フォーム／ワークフローフォーム >> データ管理 >> インポート記録 の順にクリックします。

同様に、添付名称、ステータス、操作者、更新日時で絞り込むと、インポート記録を素早く見つけられます。次の図を参照してください。

<Frame>
  ![](https://gw.alicdn.com/imgextra/i4/O1CN01T13jyPan9kI5qI1w_!!6000000004410-2-tps-2878-1170.png)
</Frame>

インポート記録

### 1.3 印刷記録の照会

**パス**：フォーム／ワークフローフォーム >> データ管理 >> 印刷記録 の順にクリックします。

**ご注意**：印刷記録は絞り込みできません。

<Frame>
  ![](https://gw.alicdn.com/imgextra/i3/O1CN01qhIedUMSvHH5qHxg_!!6000000008039-2-tps-2878-906.png)
</Frame>

印刷記録

### 1.4 変更記録の照会

**パス**：フォーム／ワークフローフォーム >> データ管理 >> 変更記録 の順にクリックします。

変更記録は、添付名称、ステータス、操作者、更新日時で素早く絞り込めます。次の図を参照してください。

<Frame>
  ![](https://gw.alicdn.com/imgextra/i2/O1CN01VDd9MTeMuUG5q2OW_!!6000000007512-2-tps-2876-1068.png)
</Frame>

変更記録

### 1.5 ファイルダウンロード記録の照会

**パス**：フォーム／ワークフローフォーム >> データ管理 >> ファイルダウンロード記録 の順にクリックします。

このページには、**添付**および**画像**の一括ダウンロード記録が表示されます。添付名称、ステータス、操作者、更新日時で絞り込めます。次の図を参照してください。

<Frame>
  ![](https://gw.alicdn.com/imgextra/i4/O1CN01yBcewuLufWD5qI10_!!6000000000816-2-tps-2878-1112.png)
</Frame>

ファイルダウンロード記録
