## 1. 一括印刷

### 1.1 印刷テンプレート

印刷設定は現在、ベーシック版とプロフェッショナル版でのみ対応しています。Freeプランでは印刷テンプレートの設定に対応していません。

印刷設定

### 1.2 一括印刷

選択したデータについて印刷テンプレートに基づき印刷ファイルを生成し、一括でダウンロードします。

<Frame>
  ![](https://gw.alicdn.com/imgextra/i4/O1CN018Iodz9zmgHC5qI1i_!!6000000005013-2-tps-2878-1156.png)
</Frame>

**パス1**：データ管理 >> 印刷するレコードを選択 >> その他の操作 >> 選択項目を印刷 >> テンプレートを選択 >> 確認。

テンプレートの選択

## 2. 一括印刷ファイルのダウンロード方法（2種類）

### 2.1 業務通知

**パス**：業務通知 >> 詳細を見るをクリック >> ローカルダウンロードページへリダイレクト >> ファイルを印刷。

<Frame>
  ![](https://gw.alicdn.com/imgextra/i3/O1CN014XX3rejeulI37EMJ_!!6000000005749-2-tps-1535-968.png)
</Frame>

業務通知

### 2.2 印刷履歴

**パス**：フォーム >> データ管理 >> 印刷履歴 >> ダウンロード（ローカルデバイスに直接ダウンロードされます）。
