## 1. ユースケース

クラスピッカーコンポーネントは、クラス徳育評価など、クラス選択が必要な K-12 スクールのシーンに適しています。

## 2. 基本機能

### 2.1 複数選択モード

複数のクラスを選択できます。単一クラスのみ選択可能にする場合は、このボタンをオフにしてください。

| **フォームデザインビュー** | **フォームランタイムビュー** |
|---|---|
|  |  |

### 2.2 データ入力

データ入力機能により、クラスの基本属性を Yida アプリのコンポーネントに反映し、フォームデータを自動生成します。クラス属性には以下が含まれます。

- キャンパス
- 学齢段階

- 学年
- 担任教師

- クラスの生徒数
- 入学年度

| **フォームデザインビュー** | **フォームランタイムビュー** |
|---|---|
|  |  |

## 3. データソース

スクール連絡先のクラスマスターデータを使用します。
