<Warning>
有料版のデータ管理ページでは、30,000件のレコード検索に対応しています **（Freeプランでは5,000件までの検索のみサポートされます。詳細は** [**アップグレードの前提条件**](https://docs.aliwork.com/docs/yida_support/yida_updates/mw0bmqngpgz6sxba/bxefi9)**をご参照ください）**。この上限を超えた場合はエラーが表示されます。フィルターコンポーネントを使用して検索範囲を絞り込んでください。
</Warning>

## 1. データ管理ページの概要

データ管理ページには、送信済みのすべてのフォームレコードが表示され、インポート/インポート履歴、エクスポート/エクスポート履歴、編集履歴、ファイルダウンロード/ダウンロード履歴、印刷/印刷履歴、追加、その他の操作（データの編集、削除）、検索、フィルター、表示列の設定、並び替え、更新、フルスクリーンなどの機能を提供します。

## 2. 機能概要

**パス**：マイアプリ >> アプリをクリック >> フォーム/ワークフローフォーム >> データ管理

| **機能** | **説明** |
|---|---|
| [**エクスポート/エクスポート履歴**](/ja/yida/form/vz0ebe) | 検索条件に一致するレコードをExcelファイルにエクスポートします。エクスポート履歴で以前にエクスポートしたレコードを確認できます。 |
| [**インポート/インポート履歴**](/ja/yida/form/andrke) | フォームレコードを一括で送信し、送信者が複数のフォームレコードを迅速に送信できるようにします。インポートしたレコードはインポート履歴で確認できます。 |
| **ファイルダウンロード/ダウンロード履歴** | 複数のレコードを選択してファイルをダウンロードし、以前にダウンロードしたファイルレコードをダウンロード履歴で確認できます。<br />**注意**：添付ファイルが大きすぎる場合、一括ダウンロードは200 MBごとのパッケージに分割されます。 |
| [**データ編集/編集履歴**](/ja/yida/form/ne8htk) | フォームのデータ管理ページでレコードを一括編集します。この機能は管理者のみが使用できます。編集履歴で編集前後のデータを確認できます。 |
| [**削除**](/ja/yida/form/fxxris) | フォームのデータ管理ページでレコードを一括削除します。この機能は管理者のみが使用できます。 |
| [**印刷/印刷履歴**](/ja/yida/form/nmrhfo) | 印刷テンプレートに基づいて選択したレコードの印刷ファイルを生成し、パッケージとしてダウンロードします。印刷履歴の確認も可能です。 |
| [**並び替え**](https://docs.aliwork.com/docs/yida_support/yida_updates/_3/iglusc) | レコードが多い場合、特定のフィールドで昇順または降順に並び替えできます。対応コンポーネント：一行テキスト、複数行テキスト、数値、選択、評価点、日付。 |
| [**フィルター**](/ja/yida/form/if3mza) | 異なるフィールドにフィルター条件を設定して、レコードを絞り込んで表示します。 |
| [**表示列**](/ja/yida/form/lzqqf6) | フィールドを選択してレコードに表示するコンテンツを設定します。 |
| **更新** | データのインポート後にビューを迅速に更新します。 |

### 2.1 データ詳細情報

#### 2.1.1 コピー

通常のフォームでは、追加設定なしでレコード詳細のクイックコピー機能が提供されます。レコード詳細ページを開くだけで使用できます。ワークフローフォームの場合は、基本設定で [**ワークフローのコピー**](https://docs.aliwork.com/docs/yida_support/yida_qalist/uop0b0ndpgc0gevb/ovg9ul) ボタンを有効化する必要があります。

**注意事項：**

- この機能は1.0または2.0アプリでは対応していません。
- YiDAのすべてのエディションで利用可能です。
- 非表示、無効、閲覧のみに設定されたフィールドはコピーされません。

#### 2.1.2 新しいページで開く

データ管理ページでレコードをクリックすると、小さなウィンドウで開きます。レコード詳細をフルページモードで表示するには、以下のように「新しいページで開く」をクリックします。

## 3. FAQ

<AccordionGroup>
<Accordion title="3.1 コピーボタンをクリックすると「このページにアクセスする権限がありません」と表示されるのはなぜですか？">
  フォーム送信ステータスの権限グループが、お使いのアカウントによるレコード送信を許可する設定になっているかご確認ください。
</Accordion>
<Accordion title="3.2 一部のフォームデータ管理ページでサブフォームを展開できるのはなぜですか？">
  新しいストレージではサブフォームコンポーネントがデフォルトで展開されますが、古いストレージではデフォルトで読み込まれません。そのため、古いストレージには「サブフォームを展開」ボタンが残されています。
</Accordion>
<Accordion title="3.3 グローバル検索の結果が正確でないのはなぜですか？">
  現在のアプリが古いストレージを使用している場合、グローバル検索結果が正確でない可能性があります。検索機能のアップグレードの詳細については、[**こちらをクリック**](https://docs.aliwork.com/docs/yida_support/yida_updates/mw0bmqngpgz6sxba/bxefi9)してください。

  **注意：フォームのデータ管理ページに「サブフォームを展開」ボタンがある場合、そのアプリは古いストレージを使用しています。**
</Accordion>
<Accordion title="3.4 一部のアプリフォームでデフォルトのフィルターフィールドと並び替えの管理者設定がないのはなぜですか？">
  新しいストレージのアプリでは、検索できるフィールドの制限がなくなりました。デフォルトで、追加したすべてのフィルターフィールドが検索可能です。そのため、このボタンがまだ残っているフォームのアプリは古いストレージを使用しています。
</Accordion>
</AccordionGroup>
