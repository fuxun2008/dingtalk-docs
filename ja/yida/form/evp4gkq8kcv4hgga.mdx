**XOR** 関数は、排他的論理和を表します。

XOR は論理式の比較に使用します。この関数は、以下の場合にのみ true を返します。

- 論理式のうち 1 つだけが true で、その他すべてが false の場合、XOR 関数は true を返します。

## 対応する製品シナリオ

XOR 関数は、以下の Yida シナリオで利用できます。

- フォーム（メインテーブルフィールド）
- フォーム（業務関連ルール）
- フォーム（バリデーション）
- ワークフロー設計（バリデーションルール）
- 統合と自動化
- 作業フローノード
- コネクタ

## 書式

```text
XOR(condition1,condition2....condition.N)
```
