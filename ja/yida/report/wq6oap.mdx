レポートには多様なチャートスタイルが用意されています。明細表とピボットテーブルを利用すれば、フォームやワークフローフォームのデータの詳細および集計を確認できます。Column や折れ線チャートなどを使ってデータを加工し、傾向やカテゴリ間の比較を可視化することも可能です。円チャートを使えば、データに占める各要素の割合を表示できます。

| **コンポーネント名** | **用途** |
|---|---|
| [**Column**](/ja/yida/report/xybfun) | 縦棒または横棒を用いて、**カテゴリ間の数値比較**を表示します。 |
| [**円チャート**](/ja/yida/report/hb73mq) | 各部門のデータ割合を確認する際に使用します。 |
| [**折れ線チャート**](/ja/yida/report/pnsoga) | データが**連続した時間間隔または時間範囲でどのように変化するか**を表示します。時間の経過や順序付けられたカテゴリを通じて、事象の変化傾向を反映します。 |
| [**Column-折れ線チャート複合チャート**](/ja/yida/report/wfno1e) | Column はデータグループ間の差異を可視化し、個々の比較を強調します。<br />折れ線チャートは製品の売上が時間の経過とともにどのように変化するかを分析し、将来の売上予測に役立ちます。<br />Column-折れ線チャート複合チャートは、Column と折れ線チャートを同時に表示します。 |
| [**ダッシュボード**](/ja/yida/report/xgetgl) | コンポーネントのサイズを制御し、位置を自由に移動（左揃え、中央揃え、右揃え）できます。 |
| [**ファネルチャート**](/ja/yida/report/hd3q1n) | 各業務段階のコンバージョン状況を直感的に確認できます。ある意味で、ファネルチャートは経路分析の応用であり、主にクリティカルパスのコンバージョン分析に焦点を当てています。 |
| [**ワードクラウド**](/ja/yida/report/gtyrhp) | フォームデータからワードクラウドチャートを生成します。 |
| [**レーダーチャート**](/ja/yida/report/grr9lt) | 多変量データを二次元チャートの形で表現する手法で、同じ点から始まる軸上に3つ以上の量的変数を表示します。 |
| [**カレンダーヒートマップ**](/ja/yida/report/lyedo6) | カレンダー上で異なる時間帯にわたる進捗を表示し、値に応じて色を調整します。**一定期間のコード量や作業活動などのシナリオの振り返りに適しています。** |
| [**中国地図**](/ja/yida/report/plcwtt) | 省・市・県レベルの中国地図に対応し、これらの階層間のドリルダウンおよびロールアップが可能な行政区画地図コンポーネントです。 |
| [**ベーシック表**](/ja/yida/report/stqur9) | 送信されたフォームデータを Excel 形式のスプレッドシートで表示します。 |
| [**クロスピボットテーブル**](/ja/yida/report/osbbht) | 日常的な分析で最も頻繁に使用される可視化のひとつで、Excel に類似しています。YiDA は多階層のピボット、指標計算、合計と小計、クイックフィルターなどの機能を提供します。指標をクリックして詳細データを表示するなど、便利な操作も利用できます。 |
| [**ベーシック指標カード**](/ja/yida/report/vn761o) | 指標とアイコンを設定して主要な指標値とアイコンを表示し、アイコンクリックによるドリルダウンにも対応します。 |
| [**テキスト**](/ja/yida/report/hu9aqr) | 基本的なテキスト情報を表示する際に使用します。 |
| [**画像**](/ja/yida/report/pyrhm5) | 画像情報を表示する際に使用します。 |
| [**リンク**](/ja/yida/report/tst3xa) | URL へのリダイレクト先を指定し、パラメーターを自由に組み合わせる際に使用します。 |
| [**コンテナ**](/ja/yida/report/qhbihp) | 主にレイアウト用途で使用し、他のコンポーネントと組み合わせられます。 |
| [**列分割**](/ja/yida/report/xvx3lt) | 主にレイアウト用途で使用し、他のコンポーネントと組み合わせられます。 |
| [**タブ**](/ja/yida/report/pux8db) | 標準とカプセルの2つの一般的なスタイルがあります。主にレイアウト用途で使用し、他のコンポーネントと組み合わせられます。 |
| [**時間フィルター**](/ja/yida/report/hbqowi) | フィルタリング用に、**単一値**および**範囲**の両方の設定に対応します。 |
| [**ドロップダウンフィルター**](/ja/yida/report/is9r5k) | **選択**および**複数選択**の設定に対応し、入力ボックスでのあいまい検索が可能です。フィールドを表示を設定することで、ユーザーに表示するフィールドと実際にクエリするフィールドを区別できます（例：部門名を表示しつつ、部門コードでクエリする）。<br />タグベースのフィルタリング用の**タグ**モードにも対応しています。 |
| [**iFrame**](/ja/yida/report/cs2lgv) | 他の Web ページのコンテンツを現在のデザイナーページに埋め込みます。 |
