<Warning>
以下の機能設定にはコーディングスキルが必要です。コーディングに不慣れな場合は、ノーコードソリューションをご利用ください。
</Warning>

## ユースケース

- データを定期的に自社システムへ取得し、後続処理やアーカイブを行う。
- フォーム送信と作業フロー起票のエントリを既存プラットフォームに統合する。
- YiDA のアクションパネルで JavaScript コードを記述し、カスタムビジネスロジックや条件チェックを実装する。

**推奨：**[**開発者センター**](/ja/open/yida/guide/about)
