polished: true

1. ページのレンダリングが完了すると、以下の関数が直ちに呼び出されます。この関数は、現在のページの「設定 - ライフサイクル - Page loaded」イベントにバインドされます。

**注意：カスタムページでは、必ず手動で一度バインドしてください。バインドしない場合、イベントはトリガーされません。**

<Frame>
  ![](https://gw.alicdn.com/imgextra/i2/O1CN01jwJhh3D1uoK3vD1o_!!6000000003908-2-tps-1932-1856.png)
</Frame>

2. didMount 内のコードは、フォーム送信ページと詳細ページの両方で実行されます。特定のシナリオでは、以下のように両者を区別する必要があります。

```jsx
this.utils.isSubmissionPage() // フォームが送信ページかどうかを確認
this.utils.isViewPage() // フォームが詳細ページかどうかを確認
```
