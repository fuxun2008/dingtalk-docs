title: "繰り返しの予定を設定する"
description: "DingTalkカレンダーで複数週にわたる繰り返しの予定を作成する方法を解説。予定作成画面で「繰り返さない」を選び、毎日・毎週・毎月・カスタムから周期を選択して、今後のスケジュールを自動入力できます。"

カレンダーでは、今後の複数週分の繰り返しの予定を一度に設定でき、手動での繰り返し設定の手間を省けます。

### 設定方法

**DingTalkカレンダー**を開き、**+**をクリックして予定を作成します。

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/4maOgXbR2br1vlWN/img/1dff1165-9037-4952-bf33-211e4209a492.png)

予定の作成画面で、**繰り返さない**をクリックします。繰り返しの周期は、毎日・毎週・毎月などに設定できます。カスタムの繰り返し周期もサポートしています。
