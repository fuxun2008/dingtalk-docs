カレンダーでは、今後の複数週分の繰り返しの予定を一度に設定でき、手動での繰り返し設定の手間を省けます。

### 設定方法

DingTalk **「カレンダー」** を開き、**「 + 」** をクリックして予定を作成できます。

![](https://img.alicdn.com/imgextra/i2/O1CN011qgfhimIwkJ5VtjE_!!6000000001117-2-tps-2716-1356.png)

予定の作成画面で、**「繰り返さない」** をクリックすると、繰り返しの周期を毎日・毎週・毎月などに設定できます。カスタムの繰り返し周期にも対応しています。

![](https://img.alicdn.com/imgextra/i3/O1CN01U1EowjwnI5E5VtjE_!!6000000005653-2-tps-2716-1356.png)
