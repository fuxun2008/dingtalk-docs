開発を始める前に、組織管理者が開発者に開発権限を付与する必要があります。異なる識別情報を持つ開発者は、それぞれ異なるタイプのアプリを開発できます。

|  |  |  |
| --- | --- | --- |
| **開発者** | **開発するアプリタイプ** | **関連組織** |
| 内部開発者 | 組織が構築する社内アプリ | 社内の社員として、組織が構築する社内アプリを開発します。 |
| ソリューションプロバイダーの開発者 | サードパーティ社内アプリ  委託による社内アプリの開発 | ソリューションプロバイダーの開発者として、組織向けにサードパーティ社内アプリやカスタムアプリを開発するには、社内でソリューションプロバイダー認証を完了する必要があります。詳細は[全体連携プロセスガイド](/zh/open/development/isv-cooperation-guide)を参照してください。 |

## 手順

組織管理者は、次の手順で開発者に開発権限を付与します。

**注意**

開発権限を申請した後、開発者はログインしてアプリの開発、アップロード、公開を行えます。

1. 組織管理者が [OA 管理コンソール](https://oa.dingtalk.com/index.htm#/safety/subAccount)にログインします。

2. 管理コンソールで、**安全と権限** > **権限管理**を選択し、**管理グループ**をクリックして**管理グループ**ページを開きます。

3. **管理グループを追加**をクリックします。

4. **管理グループの編集**ページで次の項目を入力し、**保存**をクリックします。

- **管理グループ名:** 管理グループの名前を入力します。
- **ユーザー:** 管理グループにユーザーを割り当てます。
- **管理スコープ:** 管理スコープを選択します。
- **権限の割り当て:** 対応する権限を選択します。

5. 開発者が [開発者コンソール](https://open-dev.dingtalk.com/#/index)にログインしてアプリを開発します。
