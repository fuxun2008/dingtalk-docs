---
title: "ボットでメッセージを受信する"
---

ボットでメッセージを受信する機能を開発する場合、本ドキュメントの手順に沿ってサーバーサイドの開発を行うことができます。

## 背景情報

ボットでメッセージを受信するモードは、Stream モードと HTTP モードの 2 種類に分かれます。以下では、それぞれのモードでボットがメッセージを受信する方法を紹介します。

## 前提条件

1. [アプリの作成](/zh/open/dingstart/create-and-configure-an-application) を完了している必要があります。
2. アプリ機能の追加フローを完了している必要があります。

## 操作手順

### Stream モード（推奨）

> その他の言語については、サーバーサイドの Stream モードを参照してください。

1. Java 開発環境の準備：

- 実行環境：JDK 1.8 以上
- Java SDK のインストール：

  プロジェクトの `pom.xml` ファイルに依存関係を追加するか、対応する jar パッケージをダウンロードしてください。最新の SDK バージョンは [こちら](https://s01.oss.sonatype.org/?spm=openapi-amp.sdkpublish.0.0.78cefAyIfAyImO#nexus-search;quick~app-stream-client) で確認・ダウンロードできます。

  ```xml lines
  <dependency>
    <groupId>com.dingtalk.open</groupId>
    <artifactId>app-stream-client</artifactId>
    <version>{sdk-version}</version>
  </dependency>
  ```

2. サーバーサイドの接続例：

   ```java lines
   public class BotExample {

     public static void main(String[] args) {
       OpenDingTalkClient client = OpenDingTalkStreamClientBuilder
                   .custom()
                   .credential(new AuthClientCredential("${ClientId}", "${ClientSecret}"))
                   .registerCallbackListener("${topic}", new RobotMsgCallbackConsumer())
                   .build();
        client.start();
     }

     public static class RobotMsgCallbackConsumer implements OpenDingTalkCallbackListener<JSONObject, JSONObject> {

       /*
        * @param request
        * @return
        */
       @Override
       public JSONObject execute(JSONObject request) {
           System.out.println(JSON.toJSONString(request));
           try {
               JSONObject text = request.getJSONObject("text");
               if (text != null) {
                   // ボットが受信したメッセージのコンテンツ
                   String msg = text.getString("content").trim();
                   String openConversationId = request.getString("conversationId");
               }
           } catch (Exception e) {
               log.error("receive group message by robot error:" +e.getMessage(), e);
           }
           return new JSONObject();
       }
     } 
   }
   ```

   | **パラメータ名** | **説明** |
   | --- | --- |
   | ClientId | 社内アプリのアプリ認証情報 ClientId。 |
   | ClientSecret | 社内アプリのアプリ認証情報 ClientSecret。 |
   | topic | ボットのコールバック名。固定値：`/v1.0/im/bot/messages/get`。 |
3. 開発完了後、[ボットをグループに追加](/zh/open/dingstart/add-robot-to-group) する必要があります。ボットを @メンバーして「こんにちは」を送信すると、サーバーサイドが受信するメッセージのフォーマットは以下のとおりです：

   | text | テキストメッセージ：  - content：テキストコンテンツ |

   | msgtype | チャットタイプ。 |

### HTTP モード

1. Java 開発環境の準備：

   - 実行環境：JDK 1.7 以上
2. サーバーサイドの接続例：

   ```java lines
   @RestController
   public class RobotsController {
     	// 下記の value = "/robots" は、設定するボットメッセージ受信アドレスを決定します。例：https://example.com/robots
       @RequestMapping(value = "/robots", method = RequestMethod.POST)
       public String helloRobots(@RequestBody(required = false) JSONObject json) {
           System.out.println(json);
         	// ボットが受信したメッセージのコンテンツ
           String content = json.getJSONObject("text").get("content").toString().replaceAll(" ", "");

           return null;
       }
   }
   ```
