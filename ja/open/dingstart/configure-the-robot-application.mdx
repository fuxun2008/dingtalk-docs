---
title: "社内ボットの設定"
---

社内ボットアプリを設定する必要がある場合は、本ドキュメントの操作手順を参照してください。

## 前提条件

1. [アプリの作成](/ja/open/dingstart/create-application)フローを完了する必要があります。
2. アプリ機能の追加フローを完了する必要があります。

## 操作手順

1. [開発者管理画面](https://open-dev.dingtalk.io/#/)にログインし、対象のアプリをクリックしてアプリ詳細ページに移動します。
2. **アプリ機能** > **ボット** をクリックし、ボット設定をオンにします。
3. **ボット情報の設定**：

   | **設定項目** | **必須** | **説明** |
   | --- | --- | --- |
   | ボット名 | はい | 意図が正しく、文明的な語彙を使用し、曖昧な表現、誤字、不適切な語彙を避けてください。 |
   | ボットアイコン | はい | サイズは 240 ピクセル \* 240 ピクセルを推奨します。鮮明な画像を使用し、画像の主要コンテンツは中央揃えにしてください。サイズが小さすぎる、大きすぎる、または不適切なコンテンツの画像は避けてください。 |
   | ボット紹介 | はい | ボット情報を簡潔に記述してください。最大 10 文字までで、この説明はグループ内でボットを追加する際にユーザーに表示されます。 |
   | ボットの説明 | はい | ボットの機能を記述してください。最大 200 文字までで、この説明はボットの名刺情報およびグループ内でボットを追加する際にユーザーに表示されます。 |
   | ボットメッセージプレビュー画像 | はい | 画像形式は png、jpeg、jpg のいずれかで、2M を超えない必要があります。変更可能です。 |
   | メッセージ受信モード | いいえ | DingTalk からプッシュされる POST メッセージを受信するために使用します： - HTTP モード - Stream モード 詳細は[ボットのメッセージ受信](/ja/open/dingstart/robot-receive-message)を参照してください。 |
   | メッセージ受信アドレス  **説明**  **HTTP モード** の場合のみ入力が必要です | いいえ | インターネットからアクセス可能な自社の HTTPS サービスアドレスを入力します。DingTalk からプッシュされる POST メッセージを受信するために使用します。 |
4. ボットを公開（保存）するためにクリックします。
5. （オプション）公開後、**デバッグ開始** ボタンをクリックすると、テストグループが生成されます。グループ内でボットへの @ 機能をテストできます。

## 後続のステップ

ボットを公開した後、必ずアプリを公開する必要があります。詳細はアプリの公開を参照してください。
