## ページ概要

**コンポーネント管理** ページは、カスタムコンポーネントの閲覧とインストールを行うページです。**マイコンポーネント**、**組織コンポーネント**、**コンポーネントマーケット**（近日公開予定、ご期待ください）の3つのモジュールで構成されています。各モジュールはそれぞれ異なる観点からコンポーネントを表示し、コンポーネント管理を効率化します。

### ページエントリ

**パス**：アプリバックエンド >> アプリ設定 >> コンポーネント管理（下図参照）

### ページ機能

**コンポーネント管理テーブル**
ページは **マイコンポーネント**、**組織コンポーネント**、**コンポーネントマーケット**（近日公開予定、ご期待ください）の3つのモジュールに分かれており、これら3つの観点から情報をテーブル形式で表示します。（下図参照）

各観点で表示される内容は以下のとおりです。

- **マイコンポーネント**：**現在ログイン中のユーザー** が作成したコンポーネント情報を表示します。
- **組織コンポーネント**：**現在の組織内のすべてのユーザー** が作成したコンポーネント情報を表示します。
- **コンポーネントマーケット**：近日公開予定、ご期待ください。

#### コンポーネント情報テーブルのフィールド
| **フィールド** | **説明** |  
| --- | --- | 
| コンポーネント名 | 作成時に入力したコンポーネント名です。作成後は変更できません。 |  
| コンポーネントの説明 | コンポーネント作成時に入力した概要情報です。[後から変更できます](/ja/open/yida/guide/customComponent/start#ステップ-5コンポーネント情報の表示または変更)。 |  
| 最新バージョン | 現在のコンポーネントの開発イテレーションにおける最新バージョンです。 | 
| インストール済みバージョン | 現在フォームデザイナーで使用可能なバージョンです。 |  
| タイプ | 現在のコンポーネントのタイプです。コンポーネントタイプの[詳細を見る](/ja/open/yida/guide/concept/customComponent#コンポーネントのタイプ)。 |  
| インストールスコープ | 現在のコンポーネントのインストールスコープで、コンポーネントを使用可能な範囲を決定します。インストールスコープの[詳細を見る](/ja/open/yida/guide/concept/customComponent#コンポーネントのインストールタイプ)。 |  
| 更新時間 | 現在のコンポーネントバージョンの最終リリース時刻です。 |  
| 管理者 | 現在のコンポーネントを開発・デバッグする権限を持ちます。デフォルトはコンポーネントの作成者です。[管理者の追加・削除が可能です](/ja/open/yida/guide/customComponent/start#ステップ-5コンポーネント情報の表示または変更)。 |  
| 操作 - インストール | 現在のコンポーネントをインストールします。[コンポーネントバージョン](/ja/open/yida/guide/concept/customComponent#コンポーネントバージョンについて) と [インストールスコープ](/ja/open/yida/guide/concept/customComponent#コンポーネントのインストールタイプ) の選択にご注意ください。 |  
| 操作 - ドキュメントを見る | クリックすると、現在のコンポーネントのドキュメントを表示します。ドキュメントリンクは、コンポーネント作成時または基本コンポーネント情報で入力され、ユーザーがコンポーネントを理解するのに役立ちます。 |  

**コンポーネントセンター**
ページ右上の **コンポーネントセンター** ボタンをクリックすると、コンポーネントセンターに移動します。（下図参照）

各項目の説明は以下のとおりです。

- **コンポーネントを追加** ボタン：[カスタムコンポーネントを作成](/ja/open/yida/guide/customComponent/start#ステップ-1カスタムコンポーネントの作成)できます。
- **マイコンポーネント**：[コンポーネント管理テーブル](/ja/open/yida/guide/customComponent/manage#コンポーネント情報テーブルのフィールド) とは異なり、マイコンポーネントページのテーブルには、現在ログイン中のユーザーが作成し、リリースおよびインストール済みのコンポーネント情報のみが表示されます。「開発」ボタンをクリックすると [コンポーネントを開発・デバッグ](/ja/open/yida/guide/customComponent/debug) でき、「詳細」をクリックすると [コンポーネント情報を表示または変更](/ja/open/yida/guide/customComponent/start#ステップ-5コンポーネント情報の表示または変更) できます。

<Note>
**注意**：マイコンポーネントテーブルに表示されるフィールドの意味は、[上記のテーブル](/ja/open/yida/guide/customComponent/manage#コンポーネント情報テーブルのフィールド) と同じです。
</Note>
