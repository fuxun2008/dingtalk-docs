画像リソースの表示に使用します。

## 利用シーン

- ページに単一の画像を表示します。

## コンポーネント例

## コンポーネントプロパティ

| 属性 | 説明 | タイプ | デフォルト |
|---|---|---|---|
| `alt` | 画像の読み込みに失敗した際に表示されるプレースホルダーテキスト。 | `string` | `'Image 404'` |
| `autuHeight` | 高さの自動調整。 | `boolean` | `false` |
| `autuWidth` | 幅の自動調整。 | `boolean` | `false` |
| `fit` | 画像の表示モード。`cover`: コンテナに合わせてトリミング。`contain`: アスペクト比を維持し余白を付与。`fill`: コンテナに合わせて引き伸ばし。 | `'cover' \| 'contain' \| 'fill'` | `'cover'` |
| `height` | 画像の高さ。 | `number` | `200` |
| `preview` | 画像のプレビューを有効にするかどうか。 | `boolean` | `false` |
| `round` | 画像の角丸半径（px 単位）。 | `'16' \| '8' \| '4' \| '0' \| 'Custom'` | `'0'` |
| `roundRadius` | カスタムの角丸半径。**round** 属性が `'Custom'` に設定されている場合のみ有効です。 | `number` | `0` |
| `src` | 画像 URL。 | `string` | - |
| `title` | 画像のタイトル。ネイティブ HTML の `title` 属性として設定され、マウスホバー時に表示されます。 | `string` | - |
| `width` | 画像の幅。 | `number` | `350` |
