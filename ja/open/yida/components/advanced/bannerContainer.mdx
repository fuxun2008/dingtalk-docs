ボトムバナーコンポーネントを使用すると、ページ下部にコンテンツを追加できます。コンテンツはページ下部に固定表示され、全幅でレンダリングされます。

## 使用シーン

- 著作権情報など、ページ下部にコンテンツを配置する必要がある場合。

## コンポーネント例

## コンポーネントプロパティ

| プロパティ | 説明 | タイプ | デフォルト |
|---|---|---|---|
| `autoWidth` | 幅を自動調整するかどうか | `boolean` | `false` |
| `containerWidth` | コンテナ幅を px または % で指定します。例：100px、50% | `string` | - |
| `contentWidth` | コンテンツ幅を px または % で指定します。例：100px、50% | `string` | - |
| `extra` | カスタムコンテンツ | `ReactNode` | - |
| `getRefContainer` | カスタムのマウント先コンテナを設定します | `() => React.HTMLElement` | - |
| `layout` | レイアウトモードを設定します。h は横並び、v は縦並び | `'h' \| 'v'` | `'h'` |
