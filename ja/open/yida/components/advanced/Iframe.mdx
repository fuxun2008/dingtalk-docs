Iframe コンポーネントを使用すると、他の Web ページのコンテンツを現在のデザイナーページに埋め込めます。

## 使用シーン

- 現在のページ内に外部ページのコンテンツを埋め込んで表示する場合に使用します。

## コンポーネント例

## コンポーネントの属性

| 属性 | 説明 | タイプ | デフォルト |
|---|---|---|---|
| `autoFit` | 高さを自動調整します。高さの値 = ウィンドウの高さ － 上部オフセットの高さ － 追加コンテンツ領域の高さ | 真偽値 | `false` |
| `extraHeight` | 追加コンテンツ領域の高さ | `number` | `0` |
| `offsetTop` | 上部余白の高さ。自動高さ調整が有効な場合のみ機能し、上部に確保する余白領域の高さを指定します | `number` | `0` |
| `src` | Iframe コンポーネントに表示する Web ページの URL | 文字列 | `'https://www.yidaapps.com/'` |
| `title` | Iframe コンポーネントのタイトル | 文字列 | `'iFrame コンポーネント'` |
