## 利用シーン

- ネイティブの select 要素の代替として、事前定義されたオプション群から選択する場合に使用します。中核となる機能は「選択」です。

## コンポーネント例

## コンポーネント属性

| 属性 | 説明 | タイプ | デフォルト |
|---|---|---|---|
| `autoWidth` | ドロップダウンメニューの幅をセレクターに揃えるかどうか | `boolean` | `true` |
| `behavior` | フォームコンポーネントの表示状態 | [Behavior](/ja/open/yida/components/interface#behavior) | `'NORMAL'` |
| `dataSource` | オプションを設定します | [DataSource[]](/ja/open/yida/components/interface#datasource) | `[ { "text": "選択肢 1", "value": "1" }, { "text": "選択肢 2", "value": "2" }, { "text": "選択肢 3", "value": "3" } ]` |
| `filter` | ローカルフィルターメソッド。ローカルフィルタリングが有効な場合のみ利用可能 | `(value: string[], data: DataSource) => boolean` | - |
| `filterLocal` | データソースがリモートの場合は無効化します。オプションを保持するかどうかを判定する真偽値を返します | `boolean` | `true` |
| `hasArrow` | ドロップダウン矢印を表示するかどうか | `boolean` | `true` |
| `hasBorder` | 枠線を表示するかどうか | `boolean` | `true` |
| `hasSelectAll` | すべて選択機能を有効化するかどうか | `boolean` | `false` |
| `label` | フォームコンポーネントのタイトル | `string` | - |
| `labelAlign` | フォームコンポーネントタイトルの位置 | `'left' \| 'top'` | `'top'` |
| `labelColOffset` | タイトルのオフセット位置を設定します。グリッドシステムに基づき、1 は 1/24 を表します | `number` | `0` |
| `labelColSpan` | タイトルの幅を設定します。グリッドシステムに基づき、1 は 1/24 を表します | `number` | `4` |
| `labelTextAlign` | フォームコンポーネントタイトルの揃え | `'left' \| 'right'` | `'right'` |
| `labelTipsIcon` | フォームコンポーネントタイトルのお知らせエントリのアイコン。`labelTipsTypes` が **text** または **render** の場合に有効 | `string` | - |
| `labelTipsRender` | フォームコンポーネントタイトルのお知らせに対するカスタムレンダーメソッド。`labelTipsTypes` が **render** の場合に有効 | `(props: IComponentProps) => ReactNode` | - |
| `labelTipsText` | フォームコンポーネントタイトルのお知らせテキスト。`labelTipsTypes` が **text** の場合に有効 | `string` | - |
| `labelTipsTypes` | フォームコンポーネントタイトルに表示されるお知らせのタイプ | [LabelTipsTypes](/ja/open/yida/components/interface#labeltipstypes) | `'none'` |
| `notFoundContent` | 検索結果が見つからない場合に表示するテキスト | `string` | - |
| `onChange` | コンポーネントの値が変更されたときに発火します。`actionType` はトリガー種類を示します。指定可能な値：`'itemClick'`、`'enter'`、`'change'` | `({value: string, actionType:string, item:Data}) => void` | - |
| `onRemove` | 値が削除されたときに発火します | `(item: DataSource) => void` | - |
| `onSearch` | 検索ボックスの値が変更されたときに発火します | `(keyword: string) => void` | - |
| `onVisibleChange` | ポップアップレイヤーの表示・非表示時に発火します | `(visible: boolean) => void` | - |
| `onVisibleChange` | ポップアップレイヤーの表示・非表示時に発火します | `(visible: boolean) => void` | - |
| `placeholder` | フォームコンポーネントのプレースホルダーテキスト | `string` | `'選択してください'` |
| `searchDelay` | 検索遅延（ミリ秒単位） | `number` | `300` |
| `showSearch` | 展開後に検索を有効にするかどうか。タグモードでは `true` に固定されます | `boolean` | `true` |
| `showSearch` | 展開後に検索を有効にするかどうか。タグモードでは `true` に固定されます | `boolean` | `true` |
| `size` | フォームコンポーネントのサイズ | [Size](/ja/open/yida/components/interface#size) | `'medium'` |
| `tips` | フォームコンポーネントの説明。コントロールの下に表示されます | `string` | - |
| `useDetailValue` | 値にオブジェクト形式 \{label, value} を使用します | `boolean` | `false` |
| `validation` | フォームコンポーネントのバリデーション設定。詳細は [フォームバリデーションのドキュメント](/ja/open/yida/guide/concept/validation) を参照してください | [Validation[]](/ja/open/yida/components/interface#validation) | `[]` |
| `value` | 現在のコンポーネントのデフォルト値 | `string[]` | - |
| `wrapperColOffset` | フォームコンポーネントのオフセット位置を設定します。グリッドシステムに基づき、1 は 1/24 を表します | `number` | `0` |
| `wrapperColSpan` | フォームコンポーネントの幅を設定します。グリッドシステムに基づき、1 は 1/24 を表します | `number` | `0` |
