## 使用シーン
- ページ上で担当者を指定する場合
- ユーザーがプロフィール情報を登録する場合

## コンポーネント例

## コンポーネント属性

| 属性 | 説明 | タイプ | デフォルト |
|---|---|---|---|
| `beforeSearch` | ユーザー検索リクエストを送信する前に、この関数でパラメータを加工できます。**dataType** 属性が url の場合に有効です | `(params: Record<string, string>) => Record<string, string>` | - |
| `beforeSearchTeam` | 組織検索リクエストを送信する前に、この関数でパラメータを加工できます。**dataType** 属性が url の場合に有効です | `(params: Record<string, string>) => Record<string, string>` | - |
| `behavior` | フォームコンポーネントの表示状態 | [Behavior](/ja/open/yida/components/interface#behavior) | `'NORMAL'` |
| `closeOnSelect` | 選択後に閉じるかどうか | `boolean` | `false` |
| `dataSource` | ユーザーデータ。**dataType** が dataSource の場合に有効です | `any[]` | - |
| `dataType` | データ型。url: HTTP URL リクエスト、DataSource: データソース | `'url' \| 'dataSource'` | `'url'` |
| `emplIdInLabel` | 選択済みの結果に社員番号を表示するかどうか | `boolean` | `true` |
| `fetchDataOnMount` | ページ読み込み後に自動で HTTP URL をリクエストするかどうか | `boolean` | `true` |
| `fit` | 非同期データの結果加工。**dataType** 属性が url の場合に有効です | `(response: any) => any` | - |
| `hasClear` | クリアボタンを表示 | `boolean` | `true` |
| `hasOrderNum` | 主務および兼務の職位を表示 | `boolean` | - |
| `hiddenSelected` | - | `boolean` | - |
| `label` | フォームコンポーネントのタイトル | `string` | - |
| `labelAlign` | フォームコンポーネントのタイトルの位置 | `'left' \| 'top'` | `'top'` |
| `labelColOffset` | タイトルのオフセット位置を設定します。設定値はグリッド値で、1 は 1/24 を表します | `number` | `0` |
| `labelColSpan` | タイトルの占有幅を設定します。設定値はグリッド値で、1 は 1/24 を表します | `number` | `4` |
| `labelTextAlign` | フォームコンポーネントのタイトルの揃え方法 | `'left' \| 'right'` | `'right'` |
| `labelTipsIcon` | フォームコンポーネントのタイトルのお知らせ情報エントリアイコン。labelTipsTypes が **text** または **render** の場合に有効です | `string` | - |
| `labelTipsRender` | フォームコンポーネントのタイトルのお知らせ情報のカスタムレンダリングメソッド。labelTipsTypes が **render** の場合に有効です | `(props: IComponentProps) => ReactNode` | - |
| `labelTipsText` | フォームコンポーネントのタイトルのお知らせテキスト情報。labelTipsTypes が **text** の場合に有効です | `string` | - |
| `labelTipsTypes` | フォームコンポーネントのタイトルのお知らせ情報のタイプ設定 | [LabelTipsTypes](/ja/open/yida/components/interface#labeltipstypes) | `'none'` |
| `multiple` | 複数選択モードをオン | `boolean` | `false` |
| `orderNum` | 0 の場合はユーザー選択モード（主務の職位情報のみ表示）、0 以外の場合は職位選択モード（複数の兼務職位情報を表示）となります | `string` | - |
| `placeholder` | ユーザー検索ボックスのプレースホルダーお知らせ | `string` | `'選択してください'` |
| `renderOption` | 選択肢のカスタムレンダリングフィールド | `(option: any) => string` | - |
| `renderSelection` | 選択後のカスタムレンダリングフィールド | `(option: any) => string` | - |
| `searchDelay` | 検索の遅延時間（単位: ms） | `number` | `100` |
| `showAllSub` | すべてのメンバーを表示 | `boolean` | - |
| `showAvater` | 選択ポップアップにプロフィール写真を表示するかどうか | `boolean` | `true` |
| `showDeptDesc` | 部門の説明を表示するかどうか | `boolean` | `true` |
| `showEmplId` | ユーザー検索ボックスに社員番号を表示 | `boolean` | `false` |
| `showJobDesc` | 職位の説明を表示するかどうか | `boolean` | `true` |
| `showSub` | 部下を表示 | `boolean` | `false` |
| `size` | フォームコンポーネントのサイズ | [Size](/ja/open/yida/components/interface#size) | `'medium'` |
| `subUrl` | 部下の非同期 HTTP URL。すべてのメンバーおよび部下を検索する際のカスタムサービス URL。デフォルトでは HTTP URL が使用されます | `string` | - |
| `tips` | フォームコンポーネントの説明情報。コントロールの下に表示されます | `string` | - |
| `url` | ユーザー情報の非同期 HTTP URL。**dataType** 属性が url の場合に有効です | `string` | - |
| `validation` | フォームコンポーネントのバリデーション設定。詳しい使い方は [フォームバリデーションドキュメント](/ja/open/yida/guide/concept/validation) を参照してください | [Validation[]](/ja/open/yida/components/interface#validation) | `[]` |
| `value` | 現在のコンポーネントのデフォルト値 | `any[]` | - |
| `wrapperColOffset` | フォームコンポーネントのオフセット位置を設定します。設定値はグリッド値で、1 は 1/24 を表します | `number` | `0` |
| `wrapperColSpan` | フォームコンポーネントの占有幅を設定します。設定値はグリッド値で、1 は 1/24 を表します | `number` | `0` |
