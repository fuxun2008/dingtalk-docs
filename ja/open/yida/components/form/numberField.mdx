## 使用シーン

- 入力データをバリデーションし、自動的に補正する数値セレクター。

## コンポーネント例

## コンポーネントプロパティ

| 属性 | 説明 | タイプ | デフォルト |
|---|---|---|---|
| `behavior` | フォームコンポーネントの表示状態 | [Behavior](/ja/open/yida/components/interface#behavior) | `'NORMAL'` |
| `innerAfter` | 数値入力フィールドの単位テキスト | `string` | - |
| `innerBefore` | フォームコンポーネントのプレフィックステキスト | `string` | - |
| `label` | フォームコンポーネントのタイトル | `string` | - |
| `labelAlign` | フォームコンポーネントのタイトルの位置 | `'left' \| 'top'` | `'top'` |
| `labelColOffset` | タイトルのオフセット位置を設定します。設定値はグリッド値で、1 は 1/24 を表します | `number` | `0` |
| `labelColSpan` | タイトルの幅を設定します。設定値はグリッド値で、1 は 1/24 を表します | `number` | `4` |
| `labelTextAlign` | フォームコンポーネントのタイトルの揃え方法 | `'left' \| 'right'` | `'right'` |
| `labelTipsIcon` | フォームコンポーネントのタイトルお知らせエントリのアイコン。labelTipsTypes が **text** または **render** に設定されている場合に有効 | `string` | - |
| `labelTipsRender` | フォームコンポーネントのタイトルお知らせのカスタムレンダリングメソッド。labelTipsTypes が **render** に設定されている場合に有効 | `(props: IComponentProps) => ReactNode` | - |
| `labelTipsText` | フォームコンポーネントのタイトルお知らせのテキスト。labelTipsTypes が **text** に設定されている場合に有効 | `string` | - |
| `labelTipsTypes` | フォームコンポーネントのタイトルお知らせタイプの設定 | [LabelTipsTypes](/ja/open/yida/components/interface#labeltipstypes) | `'none'` |
| `onChange` | フォームコンポーネントの値変更イベント | `({value: number}) => void` | - |
| `placeholder` | フォームコンポーネントのプレースホルダーお知らせ | `string` | `'数値を入力してください'` |
| `precision` | 小数点以下の桁数。許容値：0 〜 20 | `number` | `0` |
| `size` | フォームコンポーネントのサイズ | [Size](/ja/open/yida/components/interface#size) | `'medium'` |
| `thousandsSeparators` | 桁区切り記号を使用するかどうか | `boolean` | `false` |
| `tips` | フォームコンポーネントの説明。コントロールの下に表示されます | `string` | - |
| `validation` | フォームコンポーネントのバリデーション設定。詳細は [フォームバリデーションドキュメント](/ja/open/yida/guide/concept/validation) を参照してください | [Validation[]](/ja/open/yida/components/interface#validation) | `[]` |
| `value` | フォームコンポーネントのデフォルト値 | `number` | - |
| `wrapperColOffset` | フォームコンポーネントのオフセット位置を設定します。設定値はグリッド値で、1 は 1/24 を表します | `number` | `0` |
| `wrapperColSpan` | フォームコンポーネントの幅を設定します。設定値はグリッド値で、1 は 1/24 を表します | `number` | `0` |
