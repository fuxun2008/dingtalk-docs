## 使用シーン

- 主にユーザーフィードバックのシーンで使用します。

## コンポーネント例

## コンポーネントプロパティ

| 属性 | 説明 | タイプ | デフォルト |
|---|---|---|---|
| `allowHalf` | 半分のスター評価に対応するかどうか | `boolean` | `false` |
| `behavior` | フォームコンポーネントの表示状態 | [Behavior](/ja/open/yida/components/interface#behavior) | `'NORMAL'` |
| `count` | 評価スターの総数 | `number` | `5` |
| `label` | フォームコンポーネントのタイトル | `string` | - |
| `labelAlign` | フォームコンポーネントタイトルの配置位置 | `'left' \| 'top'` | `'top'` |
| `labelColOffset` | タイトルのオフセット位置。値はグリッドビューの値で、1 は 1/24 を表します | `number` | `0` |
| `labelColSpan` | タイトルの幅。値はグリッドビューの値で、1 は 1/24 を表します | `number` | `4` |
| `labelTextAlign` | フォームコンポーネントのタイトル揃え | `'left' \| 'right'` | `'right'` |
| `labelTipsIcon` | フォームコンポーネントのタイトルお知らせのエントリアイコン。labelTipsTypes を **text** または **render** に設定した場合に有効 | `string` | - |
| `labelTipsRender` | フォームコンポーネントのタイトルお知らせのカスタムレンダリングメソッド。labelTipsTypes を **render** に設定した場合に有効 | `(props: IComponentProps) => ReactNode` | - |
| `labelTipsText` | フォームコンポーネントのタイトルお知らせテキスト。labelTipsTypes を **text** に設定した場合に有効 | `string` | - |
| `labelTipsTypes` | フォームコンポーネントのタイトルお知らせのタイプ設定 | [LabelTipsTypes](/ja/open/yida/components/interface#labeltipstypes) | `'none'` |
| `onChange` | ユーザーが評価点をクリックしたときにトリガー | `({ value: number }) => void` | - |
| `onHoverChange` | ユーザーが評価点にホバーしたときにトリガー | `(value: number) => void` | - |
| `showGrade` | スコアを表示するかどうか | `boolean` | `false` |
| `size` | フォームコンポーネントのサイズ | [Size](/ja/open/yida/components/interface#size) | `'medium'` |
| `tips` | フォームコンポーネントの説明。コントロールの下に表示されます | `string` | - |
| `validation` | フォームコンポーネントのバリデーション設定。詳細は [フォームバリデーションドキュメント](/ja/open/yida/guide/concept/validation) を参照してください | [Validation[]](/ja/open/yida/components/interface#validation) | `[]` |
| `value` | フォームコンポーネントのデフォルト値 | `number` | `2.5` |
| `wrapperColOffset` | フォームコンポーネントのオフセット位置。値はグリッドビューの値で、1 は 1/24 を表します | `number` | `0` |
| `wrapperColSpan` | フォームコンポーネントの幅。値はグリッドビューの値で、1 は 1/24 を表します | `number` | `0` |
