---
title: "予定を削除"
---

本 API を呼び出して、指定した予定を削除します。

## API 呼び出し説明

- 主催者が予定を削除する場合（URL に主催者の unionId を使用）、すべての参加者に予定キャンセル通知が送信され、予定はすべての参加者のカレンダーから削除されます。
- 参加者が予定を削除する場合（URL に参加者の unionId を使用）、その予定は自分のカレンダーからのみ削除され、他の予定参加者には影響しません。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | `https://api.dingtalk.io/v1.0/calendar/users/{userId}/calendars/{calendarId}/events/{eventId}` |
| HTTP Method | DELETE |
| 対応アプリタイプ | appType-社内アプリ　appType-サードパーティ社内アプリ　appType-サードパーティ個人アプリ |
| 必要な権限 | permission-Calendar.Event.Write-カレンダーアプリにおける予定の書き込み権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-client-token | String | 任意 | 冪等性チェック。     - 同じ `x-client-token` は同一リクエストを示します。 - 有効期限は 1 日です。 |
| x-acs-dingtalk-access-token | String | 必須 | 本 API を呼び出すためのアクセス認証情報。以下の方法で取得します。   - 社内アプリの場合は [社内アプリの accessToken を取得](https://open.dingtalk.io/document/development/obtain-the-access-token-of-an-internal-app#) API を呼び出して取得します。 - サードパーティ社内アプリの場合は [サードパーティアプリに認可された企業の accessToken を取得](https://open.dingtalk.io/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#) API を呼び出して取得します。 - サードパーティ個人アプリの場合は [ユーザートークンを取得](https://open.dingtalk.io/document/development/obtain-user-token#) API を呼び出して取得します。 |

### パスパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| userId | String | 必須 | 削除対象の予定が属するユーザーの unionId。   - 社内アプリおよびサードパーティ社内アプリの場合は [ユーザー詳細を照会](https://open.dingtalk.io/document/development/query-user-details#) API を呼び出して unionid パラメータの値を取得します。 - サードパーティ個人アプリの場合は [ユーザーの連絡先プロフィールを取得](https://open.dingtalk.io/document/development/dingtalk-retrieve-user-information#) API を呼び出して unionId パラメータの値を取得します。 |
| calendarId | String | 必須 | 予定が属するカレンダー ID。primary 固定で、ユーザーのメインカレンダーを示します。 |
| eventId | String | 必須 | 予定 ID。[予定を作成](https://open.dingtalk.io/document/development/create-event#) API または [予定リストを照会](https://open.dingtalk.io/document/development/query-an-event-list#) API を呼び出して id パラメータの値を取得できます。 |

### クエリパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| pushNotification | Boolean | 任意 | ポップアップ通知を行うかどうか:   - true: 行う - false: 行わない |
