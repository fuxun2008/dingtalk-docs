本インターフェースを呼び出し、テンプレート ID に基づいてカスタム画面テンプレートを削除します。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/v1.0/rooms/devices/screens/templates/remove |
| HTTP Method | POST |
| サポートされるアプリタイプ | appType-社内アプリ　appType-サードパーティ社内アプリ |
| 必要な権限 | permission-Rooms.DeviceTemplate.Write-DingTalk 会議 Rooms システムのカスタム画面書き込み権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | はい | API 認証情報。[ユーザートークンの取得](/ja/open/development/obtain-user-token#) インターフェースを呼び出して取得します。  ユーザートークンを取得するリクエストでは、入力パラメータ `code` を使用しますが、リンクを構築して取得するプロセスにおいて、scope の範囲は必ずユーザー ID と組織 ID（つまり `scope=openid corpid`）である必要があります。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| templateId | Long | はい | テンプレート ID。[カスタム画面テンプレートリストの照会](https://open.dingtalk.com/document/development/api-querydevicecustomtemplatelist#) インターフェースを呼び出して取得できます。 |

### リクエスト例

POST /v1.0/rooms/devices/screens/templates/remove HTTP/1.1
Host:api.dingtalk.io
x-acs-dingtalk-access-token:xxxxxxxx
Content-Type:application/json

{
  "templateId" : 89
}
