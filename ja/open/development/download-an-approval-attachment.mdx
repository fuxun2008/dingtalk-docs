この API を呼び出して、承認ファイルのダウンロード権限を取得し、ダウンロードリンクを生成します。

## API 呼び出し説明

- DingTalk クライアントから承認フォームを手動で送信し、ローカルファイルを添付した場合、この API が返す添付ファイルのダウンロードアドレスは #zifgs49xxxxx.file 形式になります。この場合は、[単一の承認インスタンスの詳細を取得](/ja/open/development/obtains-the-details-of-a-single-approval-instance-pop) API と組み合わせて使用してください。インスタンス詳細 API から添付ファイルの fileName と fileType を取得し、この API が返す #zifgs49xxxxx.file のファイル名と拡張子を置換します。これで添付ファイルを正しく開けます。
- 添付ファイルのサイズは 0 より大きい必要があります。空のファイルにはダウンロードリンクを生成できません。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/v1.0/workflow/processInstances/spaces/files/urls/download |
| HTTP メソッド | POST |
| 対応するアプリタイプ | appType-社内アプリ　appType-サードパーティ社内アプリ |
| 権限 | permission-Workflow.Instance.Write-ワークフローインスタンスの書き込み権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | はい | この API を呼び出すためのアクセス認証情報です。取得方法は次のとおりです。   - 社内アプリ：[社内アプリのアクセストークンを取得](/ja/open/development/obtain-the-access-token-of-an-internal-app) API を呼び出します。 - サードパーティ社内アプリ：サードパーティアプリが権限付与された組織のアクセストークンを取得する API を呼び出します。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| processInstanceId | String | はい | 承認インスタンス ID です。   - [承認インスタンスを作成](/ja/open/development/create-an-approval-instance) API を呼び出して、`InstanceId` パラメータの値を取得します。 - [承認インスタンス ID のリストを取得](/ja/open/development/obtain-an-approval-list-of-instance-ids) API を呼び出して、`list` パラメータの値を取得します。 |
| fileId | String | はい | ファイルの fileId です。[単一の承認インスタンスの詳細を取得](/ja/open/development/obtains-the-details-of-a-single-approval-instance-pop) API を呼び出して、`fileId` パラメータの値を取得します。      このファイル ID は、承認コンポーネントでアップロードされたファイルの fileId です。コメントでアップロードされた添付ファイルのダウンロードリンクには、現在対応していません。 |
| withCommentAttatchment | Boolean | いいえ | コメント内の添付ファイルを含めるかどうかを指定します。デフォルトでは、コメント内の添付ファイルは無視されます。 |
