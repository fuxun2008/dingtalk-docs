---

この API を呼び出して、勤怠の打刻修正リクエストが承認されたことを通知します。

## リクエスト

| **基本情報** | |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/topapi/attendance/approve/check |
| HTTP メソッド | POST |
| サポートされるアプリタイプ | appType-社内アプリ　appType-サードパーティ社内アプリ |
| 権限 | permission-qyapi_attendance_group_manage-勤怠グループ管理権限 |

### クエリパラメータ

| 名前 | タイプ | 必須 | 例 | 説明 |
| --- | --- | --- | --- | --- |
| access_token | String | はい | bE74xxxx | この API の呼び出しに使用するアプリ認証情報です。   - 社内アプリの場合は、[社内アプリの access_token を取得](/ja/open/development/obtain-orgapp-token) API を呼び出して取得します。 - サードパーティ社内アプリの場合は、「サードパーティ組織の access_token を取得」API を呼び出して取得します。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 例 | 説明 |
| --- | --- | --- | --- | --- |
| userid | String | はい | manager4220 | 社員のユーザー ID です。 |
| work_date | String | はい | 2019-08-15 | 打刻修正の日付です。[ユーザーのシフト設定情報を一括照会](/ja/open/development/query-batch-scheduling-information) API から返される work_date の値を使用します。 |
| punch_id | Number | はい | 176877195378 | 打刻修正の対象となるシフトの ID です。[ユーザーのシフト設定情報を一括照会](/ja/open/development/query-batch-scheduling-information) API から返される shift_id の値を使用します。 |
| punch_check_time | String | はい | 2019-08-15 08:00 | シフトの予定打刻時刻です。[ユーザーのシフト設定情報を一括照会](/ja/open/development/query-batch-scheduling-information) API から返される plan_check_time の値を使用します。 |
| user_check_time | String | はい | 2019-08-15 07:59 | ユーザーが打刻した時刻です。 |
| approve_id | String | はい | aasdv13124 | 承認フォームの ID です。任意の値を指定できます。 |
| jump_url | String | はい | https://open.dingtalk.io/ | 承認フォームのリダイレクト先 URL です。 |
| tag_name | String | はい | 打刻修正 | 承認フォームの名前です。 |

Java

```java

```

Python

```python
import dingtalk.api

req=dingtalk.api.OapiAttendanceApproveCheckRequest("https://api.dingtalk.io/topapi/attendance/approve/check")

req.userid="dd_dd"
req.work_date="2019-08-15"
req.punch_id=12345
req.punch_check_time="2019-08-15 08:00"
req.user_check_time="2019-08-15 07:59"
req.approve_id="aasdv13124"
req.jump_url="https://xxx.xxx"
req.tag_name="打刻修正"
try:
  resp= req.getResponse(access_token)
  print(resp)
except Exception,e:
  print(e)
```

## レスポンス

### レスポンスボディ

| 名前 | タイプ | 例 | 説明 |
| --- | --- | --- | --- |
| errcode | Number | 0 | 戻りコードです。 |
| errmsg | String | ok | 戻りコードの説明です。 |

### レスポンスボディの例

```json
{
  "errcode":0,
  "errmsg":"ok"
}
```

### エラーコード

呼び出しでエラーが返された場合は、エラーメッセージをもとに[グローバルエラーコード](/ja/open/development/server-api-error-codes-1)ドキュメントで解決方法を検索してください。
