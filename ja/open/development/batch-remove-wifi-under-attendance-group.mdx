---
title: "Wi-Fi 情報の一括削除"
description: "勤怠グループ ID と Wi-Fi キーを指定し、勤怠グループの Wi-Fi 情報を一括削除する API です。1 回で最大 100 件まで削除できます。"
---

この API を呼び出して、指定した勤怠グループから Wi-Fi 情報を一括削除します。

## リクエスト

| **基本情報** | |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/topapi/attendance/group/wifis/remove |
| HTTP メソッド | POST |
| 対応アプリタイプ | appType-社内アプリ |
| 必須権限 | permission-qyapi_attendance_group_manage-勤怠グループ管理権限 |

### クエリパラメータ

| 名前 | タイプ | 必須 | 例 | 説明 |
| --- | --- | --- | --- | --- |
| access_token | String | はい | 6d1bxxxx | この API の呼び出しに使用するアプリ認証情報です。[社内アプリの access_token を取得](/ja/open/development/obtain-orgapp-token) API を呼び出して取得します。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 例 | 説明 |
| --- | --- | --- | --- | --- |
| op_userid | String | いいえ | user01 | 操作者の userId です。 |
| group_key | String | はい | CEDDFxxxx | 勤怠グループ ID です。  **注意**  group_id で勤怠グループを識別している場合は、[groupId を groupKey に変換](/ja/open/development/groupid-to-groupkey) API を呼び出して、group_id を group_key に変換してください。 |
| wifi_key_list | String | はい | 0151Exxxx | Wi-Fi キーです。[Wi-Fi 情報の一括照会](/ja/open/development/batch-query-wifi-under-attendance-group) API を呼び出して取得します。1 回の呼び出しで削除できる Wi-Fi 情報は最大 100 件です。 |

### リクエスト例

```curl
curl -X POST "https://api.dingtalk.io/topapi/attendance/group/wifis/remove" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=deb9baxxxx32b89' \
-d 'group_key=0151E022xxxx917E876' \
-d 'op_userid=123456' \
-d 'wifi_key_list=0151E02xxxx917E876'
```

Java

```java

```

## レスポンス

### レスポンスボディ

| 名前 | タイプ | 例 | 説明 |
| --- | --- | --- | --- |
| result | Result |  | 削除に成功した wifiId のリストです。 |
| error_info_list | ErrorInfo[] |  | 失敗のリストです。 |
| failure_list | String[] | 0151EEDDDF0xxxx | エラーのリストです。 |
| msg | String | 業務エラー | エラーの説明です。 |
| code | String | 1000 | エラーコードです。 |
| success_list | String[] | 0151EEDDDF0xxxx | 成功のリストです。 |
| errcode | Number | 0 | 戻りコードです。 |
| errmsg | String | ok | 戻りコードの説明です。 |
| success | Boolean | true | 呼び出しに成功したかどうかを示します。   - **true**：成功 - **false**：失敗 |
| request_id | String | 7o76z7s5cett | リクエスト ID です。 |

### レスポンスボディの例

```json
{
  "errcode": 0,
  "errmsg":"ok",
  "result": {
    "success_list": [
      "0151Exxxx",
    ]
  },
  "success": true,
  "request_id": "7o76z7s5cett"
}
```

### エラーコード

呼び出しでエラーが返された場合は、エラーメッセージをもとに [グローバルエラーコード](/ja/open/development/server-api-error-codes-1) ドキュメントで解決方法を確認してください。
