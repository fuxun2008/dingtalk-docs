本 API を呼び出して、ユーザー属性の表示設定を取得します。

## API 呼び出し説明

ユーザー属性の表示設定 API を呼び出した後、本 API を呼び出すことで、企業の社員属性フィールドの非表示設定情報を取得できます。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/v1.0/contact/staffAttributes/visibilitySettings |
| HTTP Method | GET |
| サポートされるアプリタイプ | appType-社内アプリ　appType-サードパーティ社内アプリ |
| 必要な権限 | permission-Contact.ReachableRule.ReadWrite-連絡先データの表示管理権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | はい | 本 API を呼び出すためのアクセス認証情報。以下の方法で取得します:   - 社内アプリの場合、[社内アプリの accessToken を取得](/ja/open/development/obtain-the-access-token-of-an-internal-app#) API を呼び出して取得します。 - サードパーティ社内アプリの場合、[サードパーティアプリが権限付与された企業の accessToken を取得](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#) API を呼び出して取得します。 |

### クエリパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| nextToken | Long | いいえ | ページングカーソル。   - 初回呼び出し時は -1 を指定します。 - 2 回目以降の呼び出し時は、前回の呼び出しで返された nextToken を指定します。 |
| maxResults | Integer | いいえ | ページサイズ。最大 100 までサポートします。 |

### リクエスト例

HTTP

```http
GET /v1.0/contact/staffAttributes/visibilitySettings?nextToken=-1&maxResults=10 HTTP/1.1
Host:api.dingtalk.io
x-acs-dingtalk-access-token:aec2bd0xxx
Content-Type:application/json
```
