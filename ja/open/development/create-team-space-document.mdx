---
title: "ナレッジベースドキュメントの作成"
---

本インターフェースを呼び出して、ナレッジベース内にドキュメントまたはフォルダーを作成します。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | `https://api.dingtalk.io/v1.0/doc/workspaces/{workspaceId}/docs` |
| HTTP Method | POST |
| 対応アプリタイプ | appType-社内アプリ　appType-サードパーティ社内アプリ |
| 権限要件 | permission-Document.WorkspaceDocument.Write-ナレッジベースドキュメント書き込み権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | はい | 本インターフェースを呼び出す際のアクセス認証情報。以下の方法で取得します。   - 社内アプリの場合は、[社内アプリの access_token を取得](/ja/open/development/obtain-the-access-token-of-an-internal-app#)インターフェースを呼び出して取得します。 - サードパーティ社内アプリの場合は、[サードパーティアプリが認可された企業の access_token を取得](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#)インターフェースを呼び出して取得します。 |

### パスパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| workspaceId | String | はい | ナレッジベース ID。[ナレッジベースの作成](/ja/open/development/new-knowledge-base#)インターフェースまたは[ナレッジベースリストの取得](/ja/open/development/get-knowledge-base-list#)インターフェースで取得した workspaceId フィールドの値です。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| name | String | はい | ドキュメント名。 |
| docType | String | はい | ドキュメントタイプ。以下の値を取ります。   - **DOC**：文字ドキュメント - **WORKBOOK**：スプレッドシート - **MIND**：マインドマップ - **FOLDER**：フォルダー |
| operatorId | String | はい | ユーザーの unionId。[ユーザー詳細の照会](/ja/open/development/query-user-details#)インターフェースを呼び出して取得できます。 |
| parentNodeId | String | いいえ | 親ノード ID。[ノードリストの取得](/ja/open/development/get-node-list#)インターフェースを呼び出して DentryModel パラメータの値を取得します。指定しない場合、デフォルトでルートディレクトリに作成されます。      親ノードはフォルダーでも通常のドキュメントでも構いません。 |
| templateId | String | いいえ | ドキュメントテンプレート ID。 |
| templateType | String | いいえ | ドキュメントテンプレートのタイプ。以下の値をサポートします。   - **public_template**：おすすめのテンプレート - **team_template**：チームテンプレート - **user_template**：個人テンプレート |
