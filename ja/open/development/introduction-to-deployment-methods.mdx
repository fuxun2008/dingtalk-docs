## **Compute Nest とは**

Compute Nest は、サービスプロバイダー（企業向けアプリサービスプロバイダー、IT インテグレーションサービスプロバイダー、デリバリーサービスプロバイダー、マネージドサービスプロバイダーを含む）とユーザーに公開されたサービス管理 PaaS プラットフォームです。Compute Nest は、効率的で便利かつ安全なサービス体験を提供します。サービスプロバイダーは Alibaba Cloud 上でサービスをより効果的にデプロイ、デリバリー、管理でき、ユーザーは異なるサービスプロバイダーから Alibaba Cloud 上でサブスクリプションしたさまざまなサービスを一元管理できます。

## デプロイ方法

組織の連絡先（ユーザー名、ユーザーの役職名、部門名）は、重要かつ機密性の高い組織データです。サービスプロバイダーは連絡先データの安全を確保する必要があります。確保できない場合、App Marketplace にアプリを掲載できません。

| **ソリューション概要** | **デプロイ方法** | **リソース要件** | **メリットとデメリット** | **有効化方法** |
| --- | --- | --- | --- | --- |
| DingTalk Security Rendering Component を自身で統合し、連絡先を暗号化 | Compute Nest + DingTalk Security Rendering Component | - ECS - SLB（現在は CLB のみ対応） - RDS - EIP | - メリット：Data Security Center を購入する必要がありません。 - デメリット：統合および改修のコストが発生します。 | - 方法 1：管理者が App Marketplace で有効化 - 方法 2：製品 QRコードによるオフライン有効化 |
| Data Security Center を有効化し、連絡先データを含むすべてのデータを包括的に保護 | Compute Nest + [Data Security Center](https://help.aliyun.com/product/88674.html?spm=ding_open_doc.document.0.0.7ea04a97BcYnJr) | - ECS - SLB（現在は CLB のみ対応） - RDS - EIP - DSC | メリット：統合や改修が不要です。 |
| App Marketplace に掲載しない（非推奨） | Compute Nest | - ECS - SLB（現在は CLB のみ対応） - RDS - EIP | デメリット：自社チャネルを通じてのみプロモーションできます。 | 製品 QRコードによるオフライン有効化 |
