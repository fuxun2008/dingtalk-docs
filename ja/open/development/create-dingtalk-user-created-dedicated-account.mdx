---
title: "DingTalk セルフビルド企業アカウントを作成する"
---

この API を呼び出して、DingTalk セルフビルド企業アカウントユーザーを作成します。本 API は購入・開通した組織のみ利用可能です。

## リクエスト

| **ベーシック情報** | |
| --- | --- |
| HTTP URL | https://oapi.dingtalk.io/topapi/v2/user/create |
| HTTP Method | POST |
| 対応アプリタイプ | appType-社内アプリ |
| 必要な権限 | permission-qyapi_manage_addresslist-連絡先データ管理権限 |

### クエリパラメータ

| 名前 | タイプ | 必須 | 例 | 説明 |
| --- | --- | --- | --- | --- |
| access_token | String | はい | BE3xxxx | この API を呼び出すためのアプリ認証情報。社内アプリの access_token を取得する API から取得します。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 例 | 説明 |
| --- | --- | --- | --- | --- |
| userid | String | いいえ | zhangsan | 社員の一意な識別 ID（変更不可）、長さは 1～64 文字。  **説明**   - 社内で一意である必要があります。 - 指定しない場合、userId が自動生成されます。 |
| exclusive_account | Boolean | はい | true | 必ず true を指定してください。企業アカウントを作成することを意味します。  **説明**  企業アカウントのみに適用されます。 |
| exclusive_account_type | String | はい | dingtalk | 必ず dingtalk を指定してください。DingTalk セルフビルド企業アカウントを意味します。  **説明**  DingTalk セルフビルド企業アカウントのみに適用されます。 |
| login_id | String | はい | login_id3 | DingTalk セルフビルド企業アカウントのログイン名。  **説明**  携帯電話番号やメールリンクなどの情報を含めないことを推奨します。通信事業者の規制により新規登録 SMS がブロックされる場合があります。 |
| init_password | String | はい | init_password220 | DingTalk セルフビルド企業アカウントの初期パスワード。初期パスワードは少なくとも 8 文字必要です。  **説明**   - 全て英字または数値のみは不可です。 - 携帯電話番号、メール、リンクなどの情報を含めないことを推奨します。通信事業者の規制により新規登録 SMS がブロックされる場合があります。 |
| send_password_to_user | Boolean | いいえ | false | アカウントとパスワードを送信するかどうか。デフォルトは false：   - **false**：送信しない - **true**：送信する   **説明**   - 送信時、社員の携帯電話番号宛に SMS、または個人メール宛にメールが送信されます。 - このパラメータが **true** の場合、`init_password` パラメータは必須です。指定しない場合は送信されません。 |
| name | String | はい | 山田太郎 | 社員名。最大 80 文字。 |
| dept_id_list | String | はい | "2,3,4" | 所属部門 ID のリスト。複数の部門 ID は `半角カンマ` で区切ります。1 回の呼び出しで最大 100 個の部門 ID を指定できます。 |
| telephone | String | いいえ | 010-86123456-2345 | 内線番号。最大 50 文字。  **説明**  内線番号は一意であり、社内で重複できません。 |
| job_number | String | いいえ | 4 | 社員番号。最大 50 文字。 |
| title | String | いいえ | 技術ディレクター | 職位。最大 200 文字。 |
| email | String | いいえ | test@xxx.com | 社員の個人メール。最大 50 文字。  **説明**  社員のメールは一意であり、社内で重複できません。 |
| org_email | String | いいえ | test@xxx.com | 社員のエンタープライズメール。最大 100 文字。  **説明**  以下の条件を満たす場合にのみこのフィールドが有効になります：社員がエンタープライズメールを開通済みであること。 |
| org_email_type | String | いいえ | profession | 社員のエンタープライズメールタイプ：   - **profession：** 標準版。 - **base：** ベーシック版。 |
| work_place | String | いいえ | 未来パーク | 勤務地。最大 100 文字。 |
| remark | String | いいえ | 表示名情報 | 表示名。最大 2000 文字。 |
| dept_order_list | Object[] | いいえ |  | 対応する部門内における社員の並び替え順。 |
| dept_id | Number | いいえ | 2 | 部門 ID。 |
| order | Number | いいえ | 1 | 部門内における社員の並び替え順。数値が大きいほど上位に表示されます。 |
| dept_title_list | Object[] | いいえ |  | 対応する部門内における社員の職位。 |
| dept_id | Number | いいえ | 2 | 部門 ID。 |
| title | String | いいえ | シニアプロダクトマネージャー | 部門内における社員の職位。 |
| extension | String | いいえ | `{"趣味":"旅行","年齢":"24"}` | 拡張属性。複数の属性を設定可能。最大長は 2000 文字。**説明**   - 携帯電話には最大 10 個の拡張属性しか表示できません。 - このパラメータを使用する前に、[DingTalk 管理コンソール](https://oa.dingtalk.io/index_new.htm#/setting/contactInfo) で該当属性を追加してから、API を呼び出して値を設定してください。 - このフィールドの値はリンクタイプの入力に対応し、リンクは変数ワイルドカードによる自動置換にも対応しています。現在対応しているワイルドカードは userid、corpid です。例：`{"趣味":"[趣味](http://www.dingtalk.io?userid=#userid#&corpid=#corpid#)"}`。 |
| senior_mode | Boolean | いいえ | false | 役員モードをオンにするかどうか。デフォルトは false。   - **true**：オンにする。  **説明**    - オンにすると、携帯電話番号が全社員に対して非表示になります。   - 一般社員はその社員に対して DING の送信や DingTalk ビジネスコールの発信ができなくなります。   - 役員同士では DING の送信や DingTalk ビジネスコールの発信が可能です。 - **false**：オンにしない。 |
| hired_date | Number | いいえ | 1597573616828 | 入社日。Unix タイムスタンプ、単位はミリ秒。 |
| manager_userid | String | いいえ | 001 | 直属上司の userId。 |
| exclusive_mobile | String | いいえ | +86-13412341234 | 企業アカウントの携帯電話番号。  **説明**  企業アカウントのみに適用されます。 |
| avatarMediaId | String | いいえ | @lALPDfmVUw19YdrNA-jNA-g | 本組織の企業アカウントを作成する際に指定可能なプロフィール写真の MediaId。jpg/png のみ対応。  [メディアファイルをアップロードする](/ja/open/development/upload-media-files) API を呼び出して取得できます。  **説明**  企業アカウントのみに適用されます。 |
| nickname | String | いいえ | 名前 | 本組織の企業アカウントを作成する際に指定可能な名前。  **説明**  企業アカウントのみに適用されます。 |

## レスポンス

### レスポンスボディ

| 名前 | タイプ | 例 | 説明 |
| --- | --- | --- | --- |
| errcode | Number | 0 | エラーコード。0 は成功を表します。 |
| errmsg | String | ok | エラーメッセージ。 |
| result | Object |  | 戻り結果。 |
| userid | String | zhangsan | 社員 ID。 |
| unionId | String | xxxx | 社員の一意な ID。 |

### レスポンスボディ例

```json
{
  "errcode":"0",
  "result":{
    "unionId":"xxxx",
    "userid":"zhangsan"
  },
  "errmsg":"ok"
}
```

### エラーコード

この API の呼び出しでエラーが発生した場合は、エラーメッセージを基に [グローバルエラーコード](/ja/open/development/server-api-error-codes-1) ドキュメントから解決策を確認してください。
