---
title: "企業アカウントのスーパー管理者（作成者）を移管する"
---

本 API を呼び出すことで、当組織内のある企業アカウントが所有権を持つ組織を、別の企業アカウントに移管できます。受け取る側のアカウントが該当組織に所属していない場合は、自動的に参加します。

## API 呼び出し説明

例えば、DingTalk 組織 A に企業アカウント A1 と企業アカウント A2 という 2 つの企業アカウントがあり、企業アカウント A1 が別の企業名「DingTalk 組織 B」の作成者であるとします（現在のテスト企業の OA 管理画面 - 安全と権限 - スーパー管理者リストで確認できます）。本 API を呼び出すことで、DingTalk 組織 B の作成者を企業アカウント A2 に変更できます。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/v1.0/contact/orgAccounts/mainAdministrators/change |
| HTTP Method | POST |
| サポートするアプリタイプ | appType-社内アプリ |
| 必要な権限 | permission-Contact.OrgAccountSecurity.ReadWrite-連絡先企業アカウント安全データの読み書き権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | はい | 本 API を呼び出すためのアクセス認証情報です。[社内アプリのアクセストークンを取得する](https://open.dingtalk.io/document/development/obtain-the-access-token-of-an-internal-app#) API を呼び出して取得します。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| sourceUserId | String | はい | 元の企業アカウントの userid。以下 4 つの方法で取得できます：   - [携帯電話番号から企業アカウントユーザーを検索する](https://open.dingtalk.io/document/development/obtain-the-userid-of-your-mobile-phone-number#) - [SSO 企業アカウントを作成する](https://open.dingtalk.io/document/development/create-an-sso-account#) - [DingTalk 自社作成の企業アカウントを作成する](https://open.dingtalk.io/document/development/create-dingtalk-user-created-dedicated-account#) - [他組織の企業アカウントを招待する](https://open.dingtalk.io/document/development/invite-other-organization-specific-accounts-to-join#) |
| targetUserId | String | はい | 受け取り側の専属アカウントの userid。以下 4 つの方法で取得できます：   - [携帯電話番号から企業アカウントユーザーを検索する](https://open.dingtalk.io/document/development/obtain-the-userid-of-your-mobile-phone-number#) - [SSO 企業アカウントを作成する](https://open.dingtalk.io/document/development/create-an-sso-account#) - [DingTalk 自社作成の企業アカウントを作成する](https://open.dingtalk.io/document/development/create-dingtalk-user-created-dedicated-account#) - [他組織の企業アカウントを招待する](https://open.dingtalk.io/document/development/invite-other-organization-specific-accounts-to-join#) |
| effectCorpId | String | はい | 移管される組織の corpId。詳細はベーシック概念の [CorpId](https://open.dingtalk.io/document/development/basic-concepts-beta#section-bbk-mv0-oxd) を参照してください。 |
