---
title: "権限リストの取得"
---

本インターフェースを呼び出し、指定した ID（ファイル uuid、ナレッジベース rootNodeId、ナレッジベースノード nodeId）と操作者 ID に基づいて、ユーザーのファイル権限リストを取得します。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | `https://api.dingtalk.io/v2.0/storage/spaces/dentries/{dentryUuid}/permissions/query` |
| HTTP Method | POST |
| サポートされるアプリタイプ | appType-社内アプリ |
| 必要な権限 | permission-Storage.Permission.Read-企業ストレージ権限付与情報の読み取り権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | はい | 本インターフェースを呼び出す際のアクセス認証情報。[社内アプリの access_token を取得する](/ja/open/development/obtain-the-access-token-of-an-internal-app)インターフェースを呼び出して取得できます。 |

### パスパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| dentryUuid | String | はい | ファイル uuid。[ファイル検索](/ja/open/development/search-for-files)インターフェース、または [dentryUuid 情報の取得](/ja/open/development/api-getuuidbydentryid)インターフェースを呼び出し、戻りパラメータの dentryUuid フィールドを取得します。 |

### クエリパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| unionId | String | はい | ユーザーの unionId。[ユーザー詳細の取得](/ja/open/development/query-user-details)インターフェースを呼び出して取得します。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| option | Object | いいえ | オプションパラメータ。 |
| nextToken | String | いいえ | ページングカーソル。 |
| maxResults | Integer | いいえ | ページサイズ。デフォルトは 30。 |
| filterRoleIds | Array of String | いいえ | フィルタリング対象のロール。 |

### レスポンスボディ

| 名前 | タイプ | 説明 |
| --- | --- | --- |
| permissions | Array | 権限リストのページングデータ。最大 30 件まで表示されます。 |
| dentryUuid | String | ファイル uuid。 |
| member | Object | 権限ユーザー。 |
| type | String | 権限ユーザーのタイプ。列挙値：   - **ORG**：企業 - **DEPT**：部門 - **TAG**：カスタムタグ - **CONVERSATION**：チャット - **USER**：ユーザー |
| id | String | 権限ユーザーの id：   - `type=ORG` の場合、id は企業 id - `type=DEPT` の場合、id は部門 id - `type=TAG` の場合、id はタグ id - `type=CONVERSATION` の場合、id はチャット id - `type=USER` の場合、id は社員 userId |
| corpId | String | 権限の帰属先企業。       - 企業 id が存在する場合、対応する member が退職した際に権限が自動的にクリーンアップされます。 - memberType が dept タイプの場合、必ず企業 id が必要です。 |
| name | String | ユーザー名。 |
| role | Object | 権限ロール。 |
| id | String | ロール id。列挙値：   - **OWNER**：所有者。以下の権限スコープを持ちます：    - PermissionPrivilegeEnum.INFO   - PermissionPrivilegeEnum.LIST   - PermissionPrivilegeEnum.PREVIEW   - PermissionPrivilegeEnum.READ   - PermissionPrivilegeEnum.WRITE   - PermissionPrivilegeEnum.DOWNLOAD   - PermissionPrivilegeEnum.ADD   - PermissionPrivilegeEnum.DELETE   - PermissionPrivilegeEnum.MODIFY   - PermissionPrivilegeEnum.COPY   - PermissionPrivilegeEnum.RENAME   - PermissionPrivilegeEnum.READ_PERMISSION   - PermissionPrivilegeEnum.WRITE_PERMISSION   - PermissionPrivilegeEnum.ASSIGN - **MANAGER**：管理者。以下の権限スコープを持ちます：    - PermissionPrivilegeEnum.INFO   - PermissionPrivilegeEnum.LIST   - PermissionPrivilegeEnum.PREVIEW   - PermissionPrivilegeEnum.READ   - PermissionPrivilegeEnum.WRITE   - PermissionPrivilegeEnum.DOWNLOAD   - PermissionPrivilegeEnum.ADD   - PermissionPrivilegeEnum.DELETE   - PermissionPrivilegeEnum.MODIFY   - PermissionPrivilegeEnum.COPY   - PermissionPrivilegeEnum.RENAME   - PermissionPrivilegeEnum.READ_PERMISSION   - PermissionPrivilegeEnum.WRITE_PERMISSION - **EDITOR**：編集者。以下の権限スコープを持ちます：    - PermissionPrivilegeEnum.INFO   - PermissionPrivilegeEnum.LIST   - PermissionPrivilegeEnum.PREVIEW   - PermissionPrivilegeEnum.READ   - PermissionPrivilegeEnum.WRITE   - PermissionPrivilegeEnum.DOWNLOAD   - PermissionPrivilegeEnum.ADD - **DOWNLOADER**：閲覧・ダウンロード者。以下の権限スコープを持ちます：    - PermissionPrivilegeEnum.INFO   - PermissionPrivilegeEnum.LIST   - PermissionPrivilegeEnum.PREVIEW   - PermissionPrivilegeEnum.READ   - PermissionPrivilegeEnum.DOWNLOAD - **READER**：閲覧のみ可能な閲覧者。以下の権限スコープを持ちます：    - PermissionPrivilegeEnum.INFO   - PermissionPrivilegeEnum.LIST   - PermissionPrivilegeEnum.PREVIEW |
| name | String | ロール名。 |
| duration | Long | 有効期間。      `duration` が空の場合、権限付与に有効期限の制限がないことを示します。 |
