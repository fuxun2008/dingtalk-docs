---
title: "ドロップダウンリストの削除"
---

本インターフェースを呼び出すことで、スプレッドシート内の指定したセル範囲に設定済みのドロップダウンリスト設定を削除できます。データ入力制約を解除し、セルを自由入力状態に戻すシナリオで使用します。削除操作はドロップダウンオプションの定義のみを削除し、セルに入力済みの値には影響しません。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | `https://api.dingtalk.io/v1.0/doc/workbooks/{workbookId}/sheets/{sheetId}/ranges/{rangeAddress}/deleteDropdownLists` |
| HTTP Method | POST |
| 対応アプリタイプ | appType-社内アプリ |
| 必要な権限 | permission-Document.Workbook.Write-スプレッドシート書き込み権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | はい | 本インターフェース呼び出し時のアクセス認証情報です。[社内アプリの access_token を取得](/ja/open/development/obtain-the-access-token-of-an-internal-app)インターフェースを呼び出して取得できます。 |

### パスパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| workbookId | String | はい | スプレッドシートファイル ID。[ナレッジベース API](/ja/open/development/knowledge-base-overview) が返す `nodeId(dentryUuid)` がスプレッドシートの `workbookId` に相当します。[ノードを取得](https://open.dingtalk.com/document/development/get-node)および[ナレッジベースドキュメントの作成](/ja/open/development/create-team-space-document)インターフェースを呼び出して取得できます。 |
| sheetId | String | はい | ワークシート ID または見出し。[すべてのワークシートを取得](/ja/open/development/obtain-all-worksheets)インターフェースを呼び出して、id とワークシートの見出しを取得できます。 |
| rangeAddress | String | はい | Range アドレス。 |

### クエリパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| operatorId | String | はい | 操作者の unionId。[ユーザー詳細を照会](/ja/open/development/query-user-details)インターフェースを呼び出して取得できます。操作者に権限がない場合、インターフェースは `The operator has no permission` エラーを返します。 |
