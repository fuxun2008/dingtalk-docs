## グループアプリの公開プロセス

## 利用プロセス

開始する前に、[DingTalk 開発者になる](https://open.dingtalk.com/document/isvapp/become-a-dingtalk-developer#)ための準備が完了していることを確認してください。グループアプリの開発プロセスは以下のとおりです。

1. [サードパーティ社内アプリを公開する](https://open.dingtalk.com/document/isvapp/become-an-application-service-provider#)。公開したサードパーティ社内アプリをもとに、グループアプリを開発します。
2. [グループアプリの基本情報を設定する](https://open.dingtalk.com/document/isvapp/configure-the-basic-information-of-the-group-application#)。サードパーティ社内アプリの**クールアプリ拡張**で、グループアプリを作成し、基本情報を設定します。グループアプリの作成が成功すると、グループアプリコードを取得できます。
3. [メッセージプッシュを設定する](https://open.dingtalk.com/document/isvapp/group-application-development-and-access#)。**メッセージプッシュ**で、ボットを開発しバインドします。
4. [インタラクティブカードを開発する](https://open.dingtalk.com/document/isvapp/interactive-card-development-and-access#)。ボットをバインドすることで、インタラクティブカードなどを送信できます。
5. [審査に提出しグループアプリを公開する](https://open.dingtalk.com/document/isvapp/group-application-operations#)。グループアプリの開発が完了したら、審査に提出し、運用チームに連絡して公開します。
6. [グループアプリを有効化して利用する](https://open.dingtalk.com/document/isvapp/enable-and-use-a-group-application-cool#)。グループアプリがクールアプリセンターに公開されたら、有効化します。

## グループアプリの一般的な API

グループアプリのクライアントサイド API については、[クールアプリをインストールしてグループに追加する](https://open.dingtalk.com/document/isvapp/install-cool-applications-and-add-them-to-the-group#)を参照してください。
