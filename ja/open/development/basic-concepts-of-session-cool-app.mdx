## グループアプリの公開プロセス

## 利用プロセス

開始する前に、[DingTalk 開発者になる](/ja/open/dingstart/become-a-dingtalk-developer)ための準備が完了していることを確認してください。グループアプリの開発プロセスは以下のとおりです。

1. サードパーティ社内アプリを公開する。公開したサードパーティ社内アプリをもとに、グループアプリを開発します。
2. グループアプリの基本情報を設定する。サードパーティ社内アプリの**クールアプリ拡張**で、グループアプリを作成し、基本情報を設定します。グループアプリの作成が成功すると、グループアプリコードを取得できます。
3. メッセージプッシュを設定する。**メッセージプッシュ**で、ボットを開発しバインドします。
4. インタラクティブカードを開発する。ボットをバインドすることで、インタラクティブカードなどを送信できます。
5. 審査に提出しグループアプリを公開する。グループアプリの開発が完了したら、審査に提出し、運用チームに連絡して公開します。
6. グループアプリを有効化して利用する。グループアプリがクールアプリセンターに公開されたら、有効化します。

## グループアプリの一般的な API

グループアプリのクライアントサイド API については、クールアプリをインストールしてグループに追加するを参照してください。
