---
title: "部門の企業アカウントユーザー詳細を取得"
description: "企業アカウント環境で指定部門の社員詳細情報を複数ページ対応で一覧取得できます"
---

本インターフェースを呼び出すと、指定した部門配下の社員の詳細情報を取得できます。子部門の社員情報は取得できません。本インターフェースは、企業アカウントを購入・開通している組織でのみ利用可能です。

## リクエスト

| **基本情報** | |
| --- | --- |
| HTTP URL | https://oapi.dingtalk.io/topapi/v2/user/list |
| HTTP Method | POST |
| 対応アプリタイプ | appType-社内アプリ appType-サードパーティ社内アプリ |
| 必要な権限 | permission-qyapi_get_department_member-連絡先の部門メンバー読み取り権限 |

### クエリパラメータ

| 名前 | タイプ | 必須 | 例 | 説明 |
| --- | --- | --- | --- | --- |
| access_token | String | 必須 | be3Fxxxx | この API を呼び出すためのアプリ認証情報。   - 社内アプリの場合、[社内アプリの access_token を取得する](/ja/open/development/obtain-orgapp-token)インターフェースから取得します。 - サードパーティ社内アプリの場合、サードパーティ企業の access_token を取得するインターフェースから取得します。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 例 | 説明 |
| --- | --- | --- | --- | --- |
| dept_id | Number | 必須 | 10 | 部門 ID。[部門リストを取得](/ja/open/development/user-management-acquires-the-list-departments)インターフェースを呼び出して dept_id の値を取得できます。  **説明**   - 現在の部門配下の社員情報のみ取得し、子部門内の社員は含みません。 - ルート部門の場合、このパラメータには 1 を指定します。 |
| cursor | Number | 必須 | 0 | ページング検索のカーソル。最初は 0 を指定し、以降はレスポンスパラメータの next_cursor 値を指定します。 |
| size | Number | 必須 | 10 | ページサイズ。 |
| order_field | String | 任意 | modify_desc | 部門メンバーの並べ替えルール。デフォルト（未指定の場合）はカスタム並び替え（custom）です：   - **entry_asc**：部門への参加時間の昇順 - **entry_desc**：部門への参加時間の降順 - **modify_asc**：部門情報の編集時間の昇順 - **modify_desc**：部門情報の編集時間の降順 - **custom**：ユーザー定義順（未定義の場合はピンイン順） |
| contain_access_limit | Boolean | 任意 | false | アクセス制限のある社員を返すかどうか：   - true：返す - false：返さない |
| language | String | 任意 | zh_CN | 連絡先の言語。指定可能な値：   - **zh_CN**：中国語（デフォルト） - **en_US**：英語 |

### リクエスト例

```curl
curl -X POST "https://oapi.dingtalk.io/topapi/v2/user/list" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=8d4de2xxxx49c' \
-d 'contain_access_limit=false' \
-d 'cursor=0' \
-d 'dept_id=10' \
-d 'language=zh_CN' \
-d 'order_field=modify_desc' \
-d 'size=10'
```

Java

```text
DingTalkClient client = new DefaultDingTalkClient("https://oapi.dingtalk.io/topapi/v2/user/list");
OapiV2UserListRequest req = new OapiV2UserListRequest();
req.setDeptId(10L);
req.setCursor(0L);
req.setSize(10L);
req.setOrderField("modify_desc");
req.setContainAccessLimit(false);
req.setLanguage("zh_CN");
OapiV2UserListResponse rsp = client.execute(req, access_token);
System.out.println(rsp.getBody());
```

### エラーコード

このインターフェースの呼び出しでエラーが発生した場合、エラーメッセージをもとに [グローバルエラーコード](/ja/open/development/server-api-error-codes-1) ドキュメントで解決方法を検索してください。

| エラーコード（errcode） | エラーコードの説明（errmsg） | 解決方法 |
| --- | --- | --- |
| 400002 | 無効なパラメータ | パラメータが要件通りに入力されているかご確認ください |
| 50004 | 部門が権限スコープ外です | access_token に操作権限があるかご確認ください |
| 40035 | パラメータが不正です | dept_id、cursor、size、または order_field の入力が規範に沿っていません |
| 60019 | 部門からユーザーを取得できません | 関連パラメータが正しく入力されているかご確認ください |
| -1 | システムビジー | 後で再試行してください |
