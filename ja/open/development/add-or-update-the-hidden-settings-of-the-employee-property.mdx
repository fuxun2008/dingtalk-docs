title: "ユーザー属性の表示権限を設定する"
---

本インターフェースを呼び出して、ユーザー属性の表示権限を設定します。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/v1.0/contact/staffAttributes/visibilitySettings |
| HTTP Method | POST |
| サポートされるアプリタイプ | appType-社内アプリ　appType-サードパーティ社内アプリ |
| 必要な権限 | permission-Contact.ReachableRule.ReadWrite-連絡先データ表示権限の管理権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | はい | 当該インターフェース呼び出しのアクセス認証情報。以下の方法で取得します：   - 社内アプリの場合、[社内アプリの accessToken を取得する](https://open.dingtalk.io/document/development/obtain-the-access-token-of-an-internal-app#)インターフェースを呼び出して取得します。 - サードパーティ社内アプリの場合、[サードパーティアプリの認可企業の accessToken を取得する](https://open.dingtalk.io/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#)インターフェースを呼び出して取得します。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| id | Long | いいえ | 設定 ID。       - 新規追加時は設定 ID を空にします。 - 変更時は変更対象の ID を指定します。 |
| name | String | いいえ | 設定の名前。 |
| description | String | いいえ | 設定の説明情報。 |
| objectStaffIds | Array of String | いいえ | フィールドを非表示にする対象社員の userId。[サイレントログインコードでユーザー情報を取得する](/zh/open/development/obtain-the-userid-of-a-user-by-using-the-log-free) により userid パラメータ値を取得できます。 |
| objectDeptIds | Array of Long | いいえ | フィールドを非表示にする対象部門の deptId。[部門リストを取得する](/zh/open/development/user-management-acquires-the-list-departments) により dept_id パラメータ値を取得できます。 |
| objectTagIds | Array of Long | いいえ | フィールドを非表示にする対象ロールの roleId。[企業ロールリストを取得する](/zh/open/development/obtains-a-list-of-enterprise-roles) により id パラメータ値を取得できます。 |
| hideFields | Array of String | いいえ | 非表示にするユーザー属性 ID のリスト。   - 非表示にするユーザー属性が企業カスタム属性の場合、その属性の属性 ID を渡します。 - 非表示にするユーザー属性がシステムデフォルト属性の場合、システムデフォルト属性リストの値を渡します。       システムデフォルト属性リストは以下のとおりです：   - **name**： 名前 - **department**： 部門 - **email**： メール - **manager**： 直属の上司 - **title**： 職位 - **mobile**： 携帯電話番号 - **ext_number**： 内線番号 - **work_station**： 勤務地 - **remark**： 表示名 - **hire_date**： 入社日 - **job_number**： 社員番号 |
| excludeStaffIds | Array of String | いいえ | 非表示フィールドを表示可能とする社員の userId。 |
| excludeDeptIds | Array of Long | いいえ | 非表示フィールドを表示可能とする部門の deptId。 |
| excludeTagIds | Array of Long | いいえ | 非表示フィールドを表示可能とするロールの roleId。 |
| active | Boolean | いいえ | 有効にするかどうか。   - **true**：有効 - **false**：無効 |
