本インターフェースを呼び出して、サブスクライブカレンダーを作成します。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | `https://api.dingtalk.io/v1.0/calendar/users/{userId}/subscribedCalendars` |
| HTTP Method | POST |
| 対応アプリタイプ | appType-社内アプリ　appType-サードパーティ社内アプリ　appType-サードパーティ個人アプリ |
| 必要な権限 | permission-Calendar.Calendar.Write-カレンダーアプリにおけるカレンダー書き込み権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | はい | 本インターフェースを呼び出すためのアクセス認証情報。以下の方法で取得します:   - 社内アプリの場合、[社内アプリの accessToken を取得](/ja/open/development/obtain-the-access-token-of-an-internal-app#)インターフェースを呼び出して取得します。 - サードパーティ社内アプリの場合、[サードパーティアプリ認可企業の accessToken を取得](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#)インターフェースを呼び出して取得します。 - サードパーティ個人アプリの場合、[ユーザートークンを取得](/ja/open/development/obtain-user-token#)インターフェースを呼び出して取得します。 |

### パスパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| userId | String | はい | カレンダー作成者の unionId。   - 社内アプリおよびサードパーティ社内アプリの場合、[ユーザー詳細の照会](/ja/open/development/query-user-details#)インターフェースを呼び出して unionid パラメータ値を取得します。 - サードパーティ個人アプリの場合、[ユーザー連絡先のプロフィールを取得](/ja/open/development/dingtalk-retrieve-user-information#)インターフェースを呼び出して unionId パラメータ値を取得します。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| name | String | はい | サブスクライブカレンダーの名前。 |
| description | String | いいえ | サブスクライブカレンダーの説明。最大長は 1024 文字です。 |
| managers | Array of String | いいえ | サブスクライブカレンダーの共同編集者の unionId。   - 社内アプリおよびサードパーティ社内アプリの場合、[ユーザー詳細の照会](/ja/open/development/query-user-details#)インターフェースを呼び出して unionid パラメータ値を取得します。 - サードパーティ個人アプリの場合、[ユーザー連絡先のプロフィールを取得](/ja/open/development/dingtalk-retrieve-user-information#)インターフェースを呼び出して unionId パラメータ値を取得します。 |
| subscribeScope | Object | はい | 当該カレンダーをサブスクライブ可能な対象。 |
| unionIds | Array of String | いいえ | 当該カレンダーをサブスクライブ可能なメンバーの unionId。   - 社内アプリおよびサードパーティ社内アプリの場合、[ユーザー詳細の照会](/ja/open/development/query-user-details#)インターフェースを呼び出して unionid パラメータ値を取得します。 - サードパーティ個人アプリの場合、[ユーザー連絡先のプロフィールを取得](/ja/open/development/dingtalk-retrieve-user-information#)インターフェースを呼び出して unionId パラメータ値を取得します。 |
| openConversationIds | Array of String | いいえ | 当該カレンダーをサブスクライブ可能なグループの OpenConversationId リスト。   - 社内アプリの場合、[グループチャットの OpenConversationId を取得](/ja/open/development/obtain-group-openconversationid#)インターフェースを呼び出して openConversationId パラメータ値を取得します。 - サードパーティ社内アプリの場合、[グループを作成](https://open.dingtalk.com/document/development/create-a-scene-group-v2#)インターフェースを呼び出して open_conversation_id パラメータ値を取得します。   - 予定作成者の unionId は、当該 openConversationIds パラメータのグループ内、または corpId パラメータの組織配下である必要があります。 - サードパーティ個人アプリでは本パラメータの指定は不要です。 |
| corpIds | Array of String | いいえ | 当該カレンダーをサブスクライブ可能な組織の corpId リスト。[DingTalk 開発者バックエンド](https://open-dev.dingtalk.io/#/)にログインし、ホームページで企業の corpId を確認できます。  予定作成者の unionId は、当該 corpId 組織配下、または openConversationIds パラメータのグループ内である必要があります。 |

| 400 | invalidParameter | calendar name length must less than 128 | カレンダー名は 128 文字を超えてはいけません |
