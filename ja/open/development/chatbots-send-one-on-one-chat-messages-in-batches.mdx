---
title: "ユーザーとボットのチャットへボットメッセージを一括送信"
---

本 API を呼び出すことで、ユーザーとボットのチャット（ユーザーとボットの個別チャット）へボットメッセージを一括送信します。複数のユーザー（最大 20 名）にボットメッセージを一括送信する必要があるシナリオ、たとえば企業通知やシステムアラート通知などに適しています。

## API 呼び出し説明

本 API は社内アプリのボットに対応しています。詳細は [社内ボットの設定](/ja/open/dingstart/configure-the-robot-application) を参照してください。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/v1.0/robot/oToMessages/batchSend |
| HTTP Method | POST |
| 対応アプリタイプ | appType-社内アプリ　appType-サードパーティ社内アプリ |
| 権限要件 | permission-qyapi_robot_sendmsg-社内ボットによるメッセージ送信権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | はい | 本 API を呼び出す際のアクセス認証情報。以下の方法で取得します。   - 社内アプリの場合、[社内アプリのアクセストークンを取得](https://open.dingtalk.io/document/development/obtain-the-access-token-of-an-internal-app#) API を呼び出して取得します。 - サードパーティアプリの場合、[サードパーティアプリが権限付与された企業のアクセストークンを取得](https://open.dingtalk.io/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#) API を呼び出して取得します。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| robotCode | String | はい | ボットのコード。本パラメーターには必ず社内アプリのボットの robotCode を使用してください。詳細は [ボット ID](https://open.dingtalk.io/document/development/development-robot-overview#447ec33014hrl) を参照してください。 |
| userIds | Array of String | はい | メッセージを受信するユーザーの userId リスト。一度に最大 20 件まで指定できます。[ユーザー詳細を照会](https://open.dingtalk.io/document/development/query-user-details#) または [部門ユーザーの userid リストを取得](https://open.dingtalk.io/document/development/query-the-list-of-department-userids#) API で取得できます。 |
| msgKey | String | はい | メッセージテンプレート key。詳細は [社内ボットが送信するメッセージのタイプ](https://open.dingtalk.io/document/dingstart/types-of-messages-sent-by-robots#) を参照してください。 |
| msgParam | String | はい | メッセージテンプレートのパラメーター。詳細は [社内ボットが送信するメッセージのタイプ](https://open.dingtalk.io/document/dingstart/types-of-messages-sent-by-robots#) を参照してください。 |
