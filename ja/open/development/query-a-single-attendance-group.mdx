---
title: "勤怠グループ詳細の取得"
description: "DingTalkの勤怠グループ ID を指定して、単一の勤怠グループの詳細を取得する API です。グループ名、主管理者、勤怠タイプなどの情報を取得し、勤怠管理システムとの連携に活用できます。"
---

勤怠グループ ID を指定してこの API を呼び出し、勤怠グループの詳細を取得します。取得できる情報には、勤怠グループ名、勤怠グループの主管理者、勤怠タイプなどがあります。

## リクエスト

| **基本情報** | |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/topapi/attendance/group/query |
| HTTP メソッド | POST |
| 対応するアプリタイプ | appType-社内アプリ appType-サードパーティ社内アプリ |
| 必要な権限 | permission-qyapi_attendance_group_read-勤怠グループの照会権限 |

### クエリパラメータ

| 名前 | タイプ | 必須 | 例 | 説明 |
| --- | --- | --- | --- | --- |
| access_token | String | はい | bE74xxxx | この API の呼び出しに使用するアプリ認証情報です。   - 社内アプリの場合は、[社内アプリの access_token を取得](/ja/open/development/obtain-orgapp-token) API を呼び出して取得します。 - サードパーティ社内アプリの場合は、サードパーティ社内アプリの access_token を取得 API を呼び出して取得します。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 例 | 説明 |
| --- | --- | --- | --- | --- |
| op_user_id | String | はい | user123 | 操作者の userId です。 |
| group_id | Number | はい | 685935028 | 勤怠グループ ID です。[勤怠グループの詳細を一括取得](/ja/open/development/batch-obtain-attendance-group-details) API を呼び出して group_id の値を取得します。  **注意**  旧形式の勤怠グループ識別子（group_key）を使用している場合は、[groupKey から groupId への変換](/ja/open/development/convert-groupkey-to-groupid) API を呼び出して、group_key を group_id に変換してください。 |

### リクエスト例

```curl
curl -X POST "https://api.dingtalk.io/topapi/attendance/group/query" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=65671xxxx92ddf0' \
-d 'group_id=23456' \
-d 'op_user_id=dd_dd'
```

Java

```text
DingTalkClient client = new DefaultDingTalkClient("https://api.dingtalk.io/topapi/attendance/group/query");
OapiAttendanceGroupQueryRequest req = new OapiAttendanceGroupQueryRequest();
req.setOpUserId("dd_dd");
req.setGroupId(23456L);
OapiAttendanceGroupQueryResponse rsp = client.execute(req, access_token);
System.out.println(rsp.getBody());
```

Python

```python
import dingtalk.api

req=dingtalk.api.OapiAttendanceGroupQueryRequest("https://api.dingtalk.io/topapi/attendance/group/query")

req.op_user_id="dd_dd"
req.group_id=23456
try:
  resp= req.getResponse(access_token)
  print(resp)
except Exception,e:
  print(e)
```

C#

```text

```

## レスポンス

### レスポンスボディ

| 名前 | タイプ | 例 | 説明 |
| --- | --- | --- | --- |
| result | TopSimpleGroupVO |  | 返却結果です。 |
| name | String | 勤怠 | 勤怠グループ名です。 |
| shift_ids | Number[] | [677995086] | シフト ID です。 |
| id | Number | 685935028 | 勤怠グループ ID です。 |
| wifis | String[] | ["test-inc"] | Wi-Fi 名です。 |
| address_list | String[] | ["西渓湿地"] | 勤怠打刻場所の住所です。 |
| work_day_list | Number[] | [0,1,2,3] | 勤務日です。 |
| member_count | Number | 39 | ユーザー数です。 |
| type | String | TURN | 勤怠グループのタイプです。   - **FIXED：** 固定シフト制の勤怠グループ - **TURN：** シフト制の勤怠グループ - **NONE：** フレックスタイムの勤怠グループ |
| url | String | https://attend.dingtalk.io/xxxx | リダイレクト先のリンクです。 |
| manager_list | String | user456 | 勤怠グループの管理者です。 |
| owner_user_id | String | user01 | 勤怠グループの主管理者の userId です。 |
| success | Boolean | true | リクエストが成功したかどうかを示します。   - **true**：成功 - **false**：失敗 |
| errcode | Number | 0 | リターンコードです。 |
| request_id | String | 72hycvnsyykp | リクエスト ID です。 |
