---
title: "ファイルバージョンリストの取得"
---

本 API を呼び出して、ファイルのバージョンリストを取得します。

## API 呼び出し説明

ストレージスペースで [ファイル送信](https://open.dingtalk.io/document/development/submittal-file) API を呼び出す際、ファイル名ポリシーに `OVERWRITE` を使用している場合、同名のファイルがアップロードされると、そのファイルの履歴バージョンが生成されます。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | `https://api.dingtalk.io/v1.0/storage/spaces/{spaceId}/dentries/{dentryId}/versions` |
| HTTP Method | GET |
| 対応アプリタイプ | appType-社内アプリ　appType-サードパーティ社内アプリ |
| 必要な権限 | permission-Storage.File.Read-企業ストレージファイル読み取り権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | 必須 | 本 API を呼び出すためのアクセス認証情報。以下の方法で取得します：   - 社内アプリの場合は、[社内アプリの accessToken を取得する](https://open.dingtalk.io/document/development/obtain-the-access-token-of-an-internal-app) API を呼び出して取得します。 - サードパーティ社内アプリの場合は、[サードパーティアプリで権限付与された企業の accessToken を取得する](https://open.dingtalk.io/document/development/obtain-the-access-token-of-the-authorized-enterprise-1) API を呼び出して取得します。 |

### パスパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| spaceId | String | 必須 | スペース ID。[スペースの追加](https://open.dingtalk.io/document/development/add-space) API を呼び出して、id パラメータの値を取得できます。 |
| dentryId | String | 必須 | ファイル ID。[ファイルまたはフォルダーのリストを取得](https://open.dingtalk.io/document/development/get-a-list-of-files-or-folders) API、または [dentryUuid から spaceId と dentryId を取得](https://open.dingtalk.io/document/development/api-getdentryidbyuuid) API を呼び出して、id パラメータの値を取得できます。 |

### クエリパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| nextToken | String | 任意 | ページングカーソル。   - 初回クエリの場合、本パラメータは指定しません。 - 2 回目以降のクエリの場合、本パラメータに前回呼び出し時に返された nextToken を指定します。 |
| maxResults | Integer | 任意 | 1 ページあたりのエントリ数。デフォルトは 100、最大値は 100 です。 |
| unionId | String | 必須 | 操作者の unionId。[ユーザー詳細クエリ](https://open.dingtalk.io/document/development/query-user-details) API を呼び出して、unionid パラメータの値を取得できます。 |
