---
title: "勤怠書き込み権限の照会"
description: "DingTalk勤怠 API で、社員の userId、リソースタイプ、権限スコープを指定し、勤怠グループに対する書き込み権限を照会する方法を解説します。シフト設定や打刻方法の変更などの操作可否を確認できます。"
---

この API を呼び出して、勤怠グループに対する社員の操作権限を照会します。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/v1.0/attendance/writePermissions/query |
| HTTP メソッド | POST |
| 対応アプリタイプ | appType-社内アプリ　appType-サードパーティ社内アプリ |
| 必要な権限 | permission-Attendance.Permission.Read-勤怠の権限付与情報に対する読み取り権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | はい | この API を呼び出すためのアクセス認証情報です。   - 社内アプリの場合は、[社内アプリのアクセストークンを取得](/ja/open/development/obtain-the-access-token-of-an-internal-app)を呼び出して取得します。 - サードパーティ社内アプリの場合は、サードパーティアプリに権限付与した組織のアクセストークンを取得する API を呼び出して取得します。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| opUserId | String | はい | 社員の userId です。 |
| category | String | はい | リソースタイプです。   - **GROUP**：勤怠グループ。現在はこの値のみサポートされています。 |
| resourceKey | String | はい | 権限スコープです。   - **GROUP_MEMBER**：勤怠対象者の設定 - **GROUP_NAME**：勤怠グループ名の変更 - **GROUP_TYPE**：勤怠グループタイプの設定 - **CHECK_TIME**：勤怠時間の設定 - **SCHEDULE**：社員のシフト設定 - **CHECK_POSITION_TYPE**：打刻方法の設定 - **OVER_TIME_RULE**：残業ルールの設定 - **CAMERA_CHECK**：写真認証ルール - **OUT_SIDE_CHECK**：外勤打刻の設定 - **MANAGE**：勤怠グループのサブ管理者 - **OWNER**：勤怠グループのメイン管理者 - **DELETE_GROUP**：勤怠グループの削除 |
| entityIds | Array of Long | はい | リソース ID です。category が GROUP の場合は、勤怠グループ ID を指定します。[ユーザーの勤怠グループを取得](/ja/open/development/queries-a-user-attendance-group)を呼び出して group_id の値を取得してください。 |
