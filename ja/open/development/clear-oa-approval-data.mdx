この API を呼び出して、承認関連のデータをクリーンアップします。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/v1.0/workflow/processes/clean |
| HTTP メソッド | POST |
| 対応アプリタイプ | appType-サードパーティ社内アプリ |
| 権限 | permission-Workflow.Data.Clean-作業フローデータクリーンアップ専用権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | はい | この API を呼び出すためのアクセス認証情報です。サードパーティ社内アプリの suiteAccessToken を取得する API を呼び出して取得してください。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| processCode | String | はい | テンプレートの一意のコードです。承認テンプレートを作成または更新する API を呼び出して取得してください。 |
| corpId | String | はい | 権限付与を行った組織の組織 ID です。 |

### リクエスト例

HTTP

```http
POST /v1.0/workflow/processes/clean HTTP/1.1
Host:api.dingtalk.io
x-acs-dingtalk-access-token:6d1bxxxx
Content-Type:application/json

{
  "processCode" : "PROC-EF6Yxxxxx",
  "corpId" : "ding1234"
}
```
