---
title: "行の高さを一括設定"
---

本インターフェースを呼び出すと、DingTalk スプレッドシート内の指定行から連続する複数行の高さ（単位：ピクセル）を一度に設定できます。行の高さを一括で調整し、行間隔を統一したり、複数行テキストの表示に合わせたりする場面に適しています。高さの値は自動的に正の整数に丸められ、インターフェースは操作後のワークシート情報を返します。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | `https://api.dingtalk.io/v1.0/doc/workbooks/{workbookId}/sheets/{sheetId}/setRowsHeight` |
| HTTP Method | POST |
| サポートするアプリタイプ | appType-社内アプリ |
| 権限要件 | permission-Document.Workbook.Write-DingTalk スプレッドシート書き込み権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | はい | 本インターフェースを呼び出すためのアクセス認証情報です。[社内アプリの access_token を取得](https://open.dingtalk.io/document/development/obtain-the-access-token-of-an-internal-app)インターフェースを呼び出して取得できます。 |

### パスパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| workbookId | String | はい | スプレッドシートファイルの ID です。[ナレッジベース API](https://open.dingtalk.io/document/development/knowledge-base-overview) が返す `nodeId(dentryUuid)` がスプレッドシートの `workbookId` に該当します。[ノードの取得](https://open.dingtalk.io/document/development/get-node)および[ナレッジベースドキュメントの作成](https://open.dingtalk.io/document/development/create-team-space-document)インターフェースを呼び出して取得できます。 |
| sheetId | String | はい | ワークシートの ID または見出しです。[すべてのワークシートを取得](https://open.dingtalk.io/document/development/obtain-all-worksheets)インターフェースを呼び出して、id とワークシートの見出しを取得できます。 |

### クエリパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| operatorId | String | はい | 操作者の unionId です。[ユーザー詳細の照会](https://open.dingtalk.io/document/development/query-user-details)インターフェースを呼び出して取得できます。操作者に権限がない場合、インターフェースは `The operator has no permission` エラーを返します。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| row | Long | はい | 行の高さを変更する最初の行のカーソル。0 から始まります。 |
| rowCount | Long | はい | 行の高さを変更する連続行数。 |
| height | Long | はい | 高さ。単位：ピクセル。 |

### リクエスト例

HTTP

```http
POST /v1.0/doc/workbooks/xxx/sheets/Sheet1/setRowsHeight?operatorId=xxx HTTP/1.1
Host:api.dingtalk.io
x-acs-dingtalk-access-token:f86e0bxxx
Content-Type:application/json

{
  "row" : 0,
  "rowCount" : 10,
  "height" : 50
}
```
