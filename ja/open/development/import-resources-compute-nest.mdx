社内連絡先データを安全に確保した後、Compute Nest へリソースをインポートします。

## **手順**

1. [開発者コンソール](https://open-dev.dingtalk.com/) にログインし、**アプリ開発** > **サードパーティ社内アプリ** > **社内アプリ** をクリックして、対象のアプリを選択しアプリ詳細ページを開きます。
2. **アプリリリース** > **アプリデプロイ** をクリックし、適切なデプロイ方法を選択します。
3. **アカウントを選択** をクリックして Alibaba Cloud アカウントを関連付けます。

   - すでに Alibaba Cloud アカウントが関連付けられている場合は、検出された Alibaba Cloud アカウントをそのまま選択し、**確認** をクリックします。
   - Alibaba Cloud アカウントが関連付けられていない場合は、新しいページが開きます。**Alibaba Cloud アカウントを関連付ける** > **確認** をクリックします。その後、アプリデプロイページで、検出された Alibaba Cloud アカウントを再度選択し、**確認** をクリックします。詳細は、[DingTalk アカウントを Alibaba Cloud アカウントにバインドする](https://open.dingtalk.com/document/isvapp/bind-a-dingtalk-account-to-an-alibaba-cloud-account#) を参照してください。
4. アカウントを選択した後、**Compute Nest サービスセキュリティ検出権限付与契約に同意します** を選択し、**Compute Nest に権限付与** をクリックします。
5. **アセット管理** をクリックして、関連付けられた Compute Nest の **アプリ管理** に移動します。
6. Compute Nest の **アプリ管理** を開きます。

   アプリ管理を開いた後、クラウドリソースの所在地に応じて、対応する地域の **アプリグループ** を作成します。複数の地域のアプリグループをそれぞれ作成できます。

   例えば、クラウドリソースが杭州にある場合は、**アプリグループを作成** をクリックし、グループ名をカスタマイズして、地域として **華東1（杭州）** を選択します。作成時に、インポートするクラウドリソースを選択できます。デフォルトでは、SLB、ECS、RDS、EIP などのクラウドリソースインスタンスをインポートします。

7. アプリグループの作成後、**リソース管理** の **リソースをインポート** を使用して、インポートするクラウドリソースおよびインスタンスを選択することもできます。

   **重要**
   1. RDS プッシュを使用するには、**華東1** または **華北3** 地域から RDS インスタンスを Compute Nest アプリにインポートし、アプリデプロイの RDS ページでプッシュデータソースを設定します。
   2. プライベート SLB がサポートする地域とゾーンは次のとおりです。

      |  |  |
      | --- | --- |
      | 地域 | ゾーン |
      | 華東1（杭州） | ゾーン B、ゾーン E、ゾーン F、ゾーン G、ゾーン H、ゾーン I、ゾーン J、ゾーン K |
      | 華東2（上海） | ゾーン B、ゾーン E、ゾーン F、ゾーン G、ゾーン L、ゾーン M、ゾーン N、ゾーン I、ゾーン H |
      | 華北2（北京） | ゾーン B、ゾーン C、ゾーン D、ゾーン E、ゾーン F、ゾーン G、ゾーン H、ゾーン I、ゾーン K、ゾーン L |
      | 華北3（張家口） | ゾーン A、ゾーン B、ゾーン C |
      | 華南1（深圳） | ゾーン D、ゾーン E、ゾーン F |

## **次のステップ**

リソースのインポート後、[安全なドメイン名の設定と更新](https://open.dingtalk.com/document/isvapp/configure-update-secure-domain-name) を行う必要があります。
