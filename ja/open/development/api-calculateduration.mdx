この API を呼び出すと、勤怠システムのシフト設定に基づいて、社員の残業時間、出張時間、休暇時間を事前に計算します。

## API 呼び出し説明

たとえば、ある社員が11月2日は出勤（始業 09:00、終業 18:00）、11月3日は休日にシフト設定されているとします。

この社員が11月2日 09:00:00 から11月3日 18:00:00 まで休暇を取得する予定の場合、この API を呼び出すと、この期間の休暇時間の見込みを取得できます。結果は1日のみとなります。

- 社員が勤怠グループに所属していない場合、または休暇日にシフトが設定されていない場合、休暇時間はデフォルトの勤怠時間に基づいて計算されます。
- デフォルトの勤怠時間は、**DingTalk モバイル版 > ワークベンチ > 勤怠 > 設定 > その他の設定 > 休暇・勤怠承認 > デフォルト勤怠時間** で設定します。例：

  ある社員が11月2日は出勤（始業 09:00、終業 18:00）にシフト設定され、11月3日はシフトが設定されていないとします。デフォルトのシフトは 08:30〜17:30 です。この社員が11月2日 09:00:00 から11月3日 18:00:00 まで休暇を取得する予定の場合、この API を呼び出すと、この期間の休暇時間の見込みを取得できます。結果は2日となります。

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| userId | String | いいえ | ユーザーの userId です。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| bizType | Long | いいえ | 承認フォームのタイプ：   - 1：残業 - 2：出張 - 3：休暇 |
| fromTime | String | いいえ | 開始時刻。開始時刻には、現在時刻から31日より前の時刻は指定できません。対応フォーマット：   - 2019-08-15 - 2019-08-15 AM - 2019-08-15 12:43 |
| toTime | String | いいえ | 終了時刻。   - biz_type が 1 の場合、終了時刻と開始時刻の差は1日以内である必要があります。 - biz_type が 2 または 3 の場合、開始時刻から終了時刻までの日数は31日以内である必要があります。   対応フォーマット：   - 2019-08-15 - 2019-08-15 AM - 2019-08-15 12:43 |
| durationUnit | String | いいえ | 時間の単位。指定できる値：   - day - halfDay - hour：biz_type が 1 の場合は hour のみ指定できます。   時刻のフォーマットは時間の単位と一致させる必要があります。   - 2019-08-15 は day に対応 - 2019-08-15 AM は halfDay に対応 - 2019-08-15 12:43 は hour に対応 |
| calculateModel | Long | いいえ | 計算方法：   - 0：暦日単位 - 1：勤務日単位 |
| leaveCode | String | いいえ | 休暇ルールの一意の識別子です。任意。bizType=3（休暇）の場合にのみ適用されます。指定すると、休暇タイプに設定された端数処理ルールに従って時間が丸められます。 |
