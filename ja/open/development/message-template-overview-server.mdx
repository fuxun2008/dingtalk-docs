サードパーティの企業アプリは、メッセージテンプレートを使ってメッセージ通知を送信できます。

メッセージテンプレートは、業務通知によるメッセージプッシュをアップグレードしたものです。より簡潔で標準化された開発・設定体験を提供するとともに、より安全で管理・制御しやすいメッセージ通知機能をお客様に提供します。

**注意**

メッセージテンプレートを使用する際は、以下の点にご留意ください。

- **サードパーティ企業アプリ**のみがサポートされます。
- 承認されたメッセージテンプレートのみが、業務通知メッセージのプッシュに使用できます。

## テンプレートタイプ

現在、以下の 3 種類のメッセージテンプレートタイプがサポートされています。

- Markdown テンプレート

  Markdown テンプレートは、Markdown 構文を使ってメッセージを設定・送信します。操作を必要としない純粋な通知メッセージに適しています。Markdown テンプレートを使えば、テキスト、画像、リンクなどの表示形式を簡単にサポートできます。
- ActionCard テンプレート

  ActionCard テンプレートは、ActionCard メッセージタイプを使ってメッセージを送信します。コンテンツとアクションポイントを組み合わせたメッセージをサポートし、メッセージ内で 1 つまたは複数のアクションポイントを使ってタスクを素早く処理する必要があるシナリオに適しています。

  ActionCard テンプレートは Markdown テンプレートをベースに構築されており、全体ジャンプと個別ジャンプの両方のスタイルをサポートします。
- Form テンプレート

  Form テンプレートは、OA メッセージタイプに基づいてメッセージを送信します。注文などのメッセージの表示に適しており、メッセージの詳細を表示するためのジャンプをサポートします。

## 作業フロー

下図のように、メッセージテンプレートを使って業務通知を送信するには、以下の手順が必要です。

1. メッセージテンプレートを作成・設定します。詳細については、[メッセージテンプレートの管理](/zh/open/development/manage-message-templates)を参照してください。
2. テンプレートの承認を取得します。
3. テンプレートを使った業務通知送信用の API を呼び出します。詳細については、[テンプレートを使った業務通知メッセージの送信](/zh/open/development/work-notification-templating-send-notification-interface)を参照してください。
