この API を呼び出して、休暇ルールを作成します。

## API 呼び出し説明

この API では、次の 2 種類の休暇ルールを作成できます。

- 私用休暇や結婚休暇などの一般休暇ルール。これらのルールの残数は変更できます。この API で一般休暇ルールを作成すると、残数はデフォルトで 0 になります。[休暇残数の初期化](/ja/open/development/initialize-holiday-balance) API を呼び出して、休暇残数を初期化してください。
- 代休ルール。この API で追加した代休のデフォルトの残数ルールは **残業時間を自動的に代休残数に加算** です。残数初期化 API を呼び出す必要はありません。

DingTalk 管理コンソールでの同等の設定は、**休暇管理** > **休暇ルール** にあります。**休暇を追加** をクリックすると **新規休暇** ダイアログが開きます。このダイアログには次のフィールドがあります。

| フィールド | 説明 / オプション |
|---|---|
| **休暇名** | 休暇名を入力します |
| **新入社員の休暇** | 例：**入社時から休暇取得可能** |
| **適用範囲** | 例：**企業全体**（編集可能） |
| **有給** | **有給** または **無給**。有給休暇は統計上出勤として扱われます |
| **最小休暇単位** | 例：**日単位** |
| **休暇時間の計算方法** | 例：**勤務日設定に基づいて計算**（シフト設定のない週末や法定休日など、社員の休日を除外します） |

**休暇時間の計算ルール** セクションには、**最小休暇単位** と **休暇時間の計算方法** の設定がまとめられています。**保存** をクリックすると、ルールが作成されます。
