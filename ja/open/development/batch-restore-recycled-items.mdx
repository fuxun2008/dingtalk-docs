本インターフェースを呼び出して、ゴミ箱項目を一括復元します。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | `https://api.dingtalk.io/v1.0/storage/recycleBins/{recycleBinId}/recycleItems/batchRestore` |
| HTTP Method | POST |
| サポートするアプリタイプ | appType-社内アプリ　appType-サードパーティ社内アプリ |
| 権限要件 | permission-Storage.RecycleBin.Write-ドライブアプリゴミ箱ファイル書き込み権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | 必須 | 本インターフェースを呼び出すためのアクセス認証情報。以下の方法で取得します。   - 社内アプリは、[社内アプリの access_token を取得](https://open.dingtalk.io/document/development/obtain-the-access-token-of-an-internal-app#)インターフェースを呼び出して取得します。 - サードパーティ社内アプリは、[サードパーティアプリで権限付与された企業の access_token を取得](https://open.dingtalk.io/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#)インターフェースを呼び出して取得します。 |

### パスパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| recycleBinId | String | 必須 | ゴミ箱 ID。[ゴミ箱情報を取得](https://open.dingtalk.io/document/development/obtain-information-about-the-recycle-bin#)インターフェースを呼び出して取得できます。 |

### クエリパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| unionId | String | 必須 | 操作者の unionId。[ユーザー詳細を照会](https://open.dingtalk.io/document/development/query-user-details#)インターフェースを呼び出して取得できます。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| recycleItemIds | Array of String | 必須 | ゴミ箱項目 ID リスト。[ゴミ箱項目リストを取得](https://open.dingtalk.io/document/development/gets-the-list-of-recycle-items#)インターフェースを呼び出して取得します。最大値は 30 です。 |
| option | Object | 任意 | オプションパラメータ。 |
| conflictStrategy | String | 任意 | ファイル名の競合戦略。復元時に元のパスに同名のファイルが既に存在する可能性があります。   - **AUTO_RENAME**：自動的に名前を変更（デフォルト） - **OVERWRITE**：上書き - **RETURN_DENTRY_IF_EXISTS**：既存ファイルを返す - **RETURN_ERROR_IF_EXISTS**：ファイルが既に存在する場合はエラーを返す |
