---
title: "承認用ドライブファイルのダウンロード権限を付与する"
description: "DingTalk 承認の承認用ドライブスペースにあるファイルについて、spaceId と fileId を指定し、特定ユーザーにダウンロード権限を付与するサーバー API です。最大10件まで一括で権限付与できます。"
---

承認用ドライブスペースの spaceId とファイルの fileId を指定し、承認用ドライブスペース内のファイルにダウンロード権限を付与するには、この API を呼び出します。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/v1.0/workflow/processInstances/spaces/files/authDownload |
| HTTP メソッド | POST |
| サポートされるアプリタイプ | appType-社内アプリ　appType-サードパーティ社内アプリ |
| 必要な権限 | permission-Workflow.Instance.Write-ワークフローインスタンスの書き込み権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | 文字列 | はい | この API を呼び出すためのアクセス認証情報です。次の方法で取得します。   - 社内アプリ：[社内アプリのアクセストークンを取得する](/ja/open/development/obtain-the-access-token-of-an-internal-app) API を呼び出します。 - サードパーティ社内アプリ：サードパーティアプリを承認した組織のアクセストークンを取得する API を呼び出します。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| userId | 文字列 | はい | 権限を付与するユーザーの userId です。 |
| fileInfos | 配列 | はい | 権限を付与するドライブファイルのリストです。一括での権限付与に対応しています。リストには最大10件まで含められます。 |
| fileId | 文字列 | はい | ファイルの fileId です。[単一の承認インスタンスの詳細を取得する](/ja/open/development/obtains-the-details-of-a-single-approval-instance-pop) API を呼び出して `fileId` の値を取得します。      ファイル ID は、承認コンポーネントでアップロードされたファイルの fileId です。 |
| spaceId | Long | はい | 承認用ドライブスペースの spaceId です。[承認用ドライブスペースの情報を取得する](/ja/open/development/obtains-the-information-about-approval-nail-disk) API を呼び出して `spaceId` の値を取得します。 |
