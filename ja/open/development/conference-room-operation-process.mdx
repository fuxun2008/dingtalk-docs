本ドキュメントでは、社内アプリを作成し、スマート会議室が提供する API を使用して会議室の作成、更新、照会、削除を行う一連のフローを紹介します。

## 想定される効果

会議室の表示効果は以下のとおりです。

## フロー概要

前提条件：[アプリの作成と設定](/ja/open/dingstart/create-application)のフローを完了していること。

ステップ 1：アプリ認証情報を取得し、クライアント ID と Client Secret を取得します。

ステップ 2：API 権限をリクエストし、スマート会議室関連の API 権限を申請します。

ステップ 3：アプリのアクセス認証情報を取得します。[社内アプリのアクセストークン取得](/ja/open/development/obtain-the-access-token-of-an-internal-app)を参照してください。API を呼び出す際は、アクセストークンによって呼び出し元の身元を認証します。

ステップ 4：会議室関連の API を呼び出します。

1. サーバー API の [会議室の作成](/ja/open/development/create-a-meeting-room) インターフェースを呼び出し、会議室の戻り値 `result` フィールド、すなわち会議室 ID を取得します。
2. 会議室 ID に基づき、サーバー API の [会議室情報の更新](/ja/open/development/update-meeting-room-information) インターフェースを呼び出し、会議室情報の更新操作を実行します。
3. サーバー API の [会議室リストの照会](/ja/open/development/check-the-meeting-room-list) インターフェースを呼び出し、会議室リストのコンテンツを取得します。
4. 会議室 ID に基づき、サーバー API の [会議室詳細の照会](/ja/open/development/check-meeting-room-details) インターフェースを呼び出し、特定の会議室の詳細情報を取得します。
5. 会議室 ID に基づき、サーバー API の [会議室の削除](/ja/open/development/delete-a-meeting-room) インターフェースを呼び出し、会議室の削除操作を実行します。

## 前提条件

[アプリの作成と設定](/ja/open/dingstart/create-application)のフローを完了していること。

## ステップ 1：アプリ認証情報の取得

1. 対象アプリを選択してアプリ詳細ページに入り、**ベーシック情報** > **認証情報とベーシック情報** をクリックします。
2. クライアント ID と Client Secret を取得します。

## ステップ 2：API 権限の追加

**開発設定** > **権限管理** をクリックし、権限検索ボックスに `VideoConference.Conference.Write` と `VideoConference.Conference.Read` をそれぞれ入力し、権限をリクエストします。

## ステップ 3：アプリのアクセス認証情報（アクセストークン）の取得

<Warning>
サーバー API の差異の詳細は、旧版 API VS 新版 API を参照してください。以下の API はすべてサーバー API を使用しています。SDK のダウンロード詳細はサーバーサイド SDK ダウンロードを参照してください。
</Warning>

ステップ 1 で取得したクライアント ID と Client Secret を使用し、アプリのアクセス認証情報を取得します。[社内アプリのアクセストークン取得](/ja/open/development/obtain-the-access-token-of-an-internal-app)を参照してください。

```java
 public void getAccessToken() throws Exception {

        config.protocol = "https";

                .setAppKey("din*********hgn")
                .setAppSecret("9G_O************mBkhgGIO");
        GetAccessTokenResponse accessToken = client.getAccessToken(accessTokenRequest);
        System.out.println(JSON.toJSONString(accessToken.getBody()));
    }
```
