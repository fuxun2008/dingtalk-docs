---
title: "コンテンツを挿入する"
description: "ドキュメント内の指定位置に Markdown 形式のコンテンツを段落単位で挿入します"
---

このインターフェースを呼び出すことで、ドキュメントの指定位置に一段落のコンテンツを挿入します。コンテンツタイプは Markdown をサポートします。

## API 呼び出し説明

挿入位置は、ドキュメントのルートノードの `children`、またはブロック要素の挿入をサポートする `BlockElement`（ハイライトブロックや Table など）の children を指定できます。`path` パラメータと `index` パラメータを組み合わせて挿入位置を決定します。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | `https://api.dingtalk.io/v1.0/doc/suites/documents/{documentId}/content` |
| HTTP Method | POST |
| サポートするアプリタイプ | appType-社内アプリ |
| 権限要件 | permission-Storage.File.Write-企業ストレージファイル書き込み権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | はい | このインターフェース呼び出しのアクセス認証情報。[社内アプリのアクセストークンを取得する](/ja/open/development/obtain-the-access-token-of-an-internal-app) インターフェースを呼び出して取得します。 |

### パスパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| documentId | String | はい | ドキュメント ID（ドキュメントの docKey または dentryUuid）。[ナレッジベースドキュメントを作成する](/ja/open/development/create-team-space-document) インターフェースでドキュメントを作成し、戻り値から `docKey` パラメータを取得します。      ドキュメント URL から `dentryUuid` を取得します。例えば https://docs.dingtalk.io/i/nodes/Zxxxxa-id の場合、dentryUuid は Zxxxxa-id です。 |

### クエリパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| operatorId | String | はい | ユーザーの unionId。[ユーザー詳細を照会する](/ja/open/development/query-user-details) インターフェースから unionid パラメータの値を取得できます。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| path | Array of Integer | いいえ | 挿入位置。 |
| index | Integer | いいえ | 挿入位置。 |
| content | Object | はい | 挿入するコンテンツ。 |
| type | String | はい | 挿入するコンテンツの具体的なタイプ。現在は `markdown` のみサポートしています。 |
| content | String | はい | 挿入するコンテンツのテキスト。 |

### リクエスト例

HTTP

```http
POST /v1.0/doc/suites/documents/doc_id/content?operatorId=union_id HTTP/1.1
Host:api.dingtalk.io
x-acs-dingtalk-access-token:access_token
Content-Type:application/json

{
  "content" : {
    "content" : "## Heading",
    "type" : "markdown"
  }
}
```
