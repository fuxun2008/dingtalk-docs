この API を呼び出すと、部門または社員が勤怠グループに所属しているかを確認できます。

## API 呼び出し説明

- 社員リストを確認する場合、この API は勤怠グループに所属する社員の userId を返します。
- 部門リストを確認する場合、この API は勤怠グループに所属する部門の ID を返します。部門内の社員の userId リストは返しません。

たとえば、ある勤怠グループの勤怠対象者に **テスト部門** と社員の **山田太郎** が含まれているとします。テスト部門には社員の佐藤次郎が所属しています。この場合、部門またはユーザーごとに API は次の結果を返します。

- 佐藤次郎の userId を確認した場合、佐藤次郎の userId は返されません。
- 山田太郎の userId を確認した場合、山田太郎の userId が返されます。
- テスト部門の ID を確認した場合、テスト部門の ID が返されます。
- 山田太郎と佐藤次郎が勤怠グループに所属しているかを確認した場合、山田太郎の userId が返されます。

## リクエスト

| **基本情報** | |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/topapi/attendance/group/member/listbyids |
| HTTP メソッド | POST |
| 対応アプリタイプ | appType-社内アプリ appType-サードパーティ社内アプリ |
| 権限 | permission-qyapi_attendance_group_read-勤怠グループ照会権限 |

### クエリパラメータ

| 名前 | タイプ | 必須 | 例 | 説明 |
| --- | --- | --- | --- | --- |
| access_token | String | はい | 6d1bxxxx | - 社内アプリの場合は、[社内アプリの access_token の取得](/ja/open/development/obtain-orgapp-token) API を呼び出して取得します。 - サードパーティ社内アプリの場合は、サードパーティ社内アプリの access_token の取得 API を呼び出して取得します。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 例 | 説明 |
| --- | --- | --- | --- | --- |
| op_user_id | String | はい | dd_dd | 操作者の userId です。 |
| group_id | Number | はい | 98562 | 勤怠グループ ID です。 **注意** 旧来の勤怠グループ識別子 group_key を使用している場合は、[groupKey から groupId への変換](/ja/open/development/convert-groupkey-to-groupid) API を呼び出して group_key を group_id に変換してください。 |
| member_ids | String | はい | user123,user456 | メンバー ID です。各 ID には userId または deptId を指定できます。複数の ID はカンマ（,）で区切ります。1 回の呼び出しで最大 20 件まで指定できます。 |
| member_type | Number | はい | 0 | メンバータイプです。 - **0**：社員 - **1**：部門 |

### リクエスト例

```curl
curl -X POST "https://api.dingtalk.io/topapi/attendance/group/member/listbyids" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=9bacfaxxxx71260' \
-d 'group_id=1234' \
-d 'member_ids=dd_dd' \
-d 'member_type=0' \
-d 'op_user_id=dd_dd'
```

Java

```text
DingTalkClient client = new DefaultDingTalkClient("https://api.dingtalk.io/topapi/attendance/group/member/listbyids");
OapiAttendanceGroupMemberListbyidsRequest req = new OapiAttendanceGroupMemberListbyidsRequest();
req.setOpUserId("user123");
req.setMemberIds("user123,user456");
req.setMemberType(0L);
req.setGroupId(68593L);
OapiAttendanceGroupMemberListbyidsResponse rsp = client.execute(req, access_token);
System.out.println(rsp.getBody());
```

## レスポンス

### レスポンスボディ

| 名前 | タイプ | 例 | 説明 |
| --- | --- | --- | --- |
| request_id | String | z81tif88lkot | リクエスト ID です。 |
| errmsg | String | ok | 戻りコードの説明です。 |
| errcode | Number | 0 | 戻りコードです。 |
| success | Boolean | true | 呼び出しに成功したかどうかを示します。 - **true**：成功 - **false**：失敗 |
| result | String[] | ["user123","user456"] | 勤怠グループに所属するメンバーの ID です。各 ID は userId または deptId です。 |

### レスポンスボディの例

```json
{
  "errcode": 0,
  "errmsg":"ok",
  "result": [
    "user123",
    "user456"
  ],
  "success": true,
  "request_id": "4nvsqf4ij2xq"
}
```

### エラーコード

API 呼び出しでエラーが返された場合は、エラーメッセージをもとに [グローバルエラーコード](/ja/open/development/server-api-error-codes-1) ドキュメントで解決方法を確認してください。
