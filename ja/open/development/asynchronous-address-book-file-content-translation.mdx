# 連絡先 ID の非同期変換

## API 呼び出し説明

1. 変換が必要なドキュメントを作成します。例は下図のとおりです。

### 説明

   xlsx、xls、csv、txt 形式のファイルのみサポートします。

2. [単一ステップファイルアップロード](https://open.dingtalk.com/document/isvapp/single-step-file-upload) API を呼び出して、media_id を取得します。
3. 本 API を呼び出して、変換タスク ID を取得します。

### 説明

   本 API を呼び出した後、ファイル変換が成功すると、非同期タスクのコールバック通知がトリガーされます。
4. [非同期変換タスクの結果取得](/ja/open/development/obtains-the-results-of-an-asynchronous-translation-task) API を呼び出して、変換後のファイルダウンロードリンクを取得します。

### 説明

   返されたファイルダウンロードリンクは `<a> タグ` で参照することを推奨します。`download` 属性は指定できません（ブラウザの互換性問題のため）。
5. ユーザーがダウンロードしたファイルの内容は下図のとおりです。

本 API を呼び出す過程で、以下の問題に遭遇する可能性があります。

- **問題**：`NodeJs` のサードパーティライブラリ `exceljs` で生成した `excel` ファイルは、内容は正常に見えますが、変換が成功しません。
- **問題の原因**：`exceljs` は `sharedString` をオンにしていない場合、デフォルトで `formula string` を使用してファイル内容を書き込みます。この動作は規約に準拠しておらず、変換が失敗する原因となります。
- **解決方法**：`exceljs` のドキュメントを参照し、`useSharedStrings` オプションを強制的にオンにしてください。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/v1.0/contact/files/translate |
| HTTP Method | POST |
| サポートされるアプリタイプ | appType-サードパーティ社内アプリ |
| 権限要件 | permission-qyapi_get_member-ユーザー情報読み取り権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | はい | 本 API を呼び出す際のアクセス認証情報。[サードパーティアプリで認可された企業の access_token を取得](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#) API を呼び出して取得します。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| medias | `Map<String, String>` | はい | 変換が必要なファイル情報。   - Map タイプ。key はドライブのファイル media_id で、[ファイルアップロード情報の取得](/ja/open/development/obtain-file-upload-informations#) API を呼び出して取得します。 - value はファイル名で、拡張子を含む必要があります。[ファイルアップロード情報の取得](/ja/open/development/obtain-file-upload-informations#) API を呼び出す際に渡したファイル名と一致させてください。        - xlsx、xls、csv、txt タイプのファイルのみサポートします。 - 最大 20 ファイルまで。 |
| outputFileName | String | いいえ | 変換後にパッケージングするファイル名。拡張子は不要です。      medias 内のファイル数が 1 を超える場合、このパラメータは必須です。 |
| unionId | String | はい | 現在ドキュメントをエクスポートする操作を行うユーザーの unionId。[サイレントログインコードによるユーザー情報の取得](/ja/open/development/obtain-the-userid-of-a-user-by-using-the-log-free#) API を呼び出して取得できます。 |
