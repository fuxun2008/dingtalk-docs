---
title: "ブロック要素の更新"
description: "ドキュメント内の段落ブロック要素のコンテンツと属性を部分的に更新し、柔軟に編集できます"
---

本 API を呼び出すことで、ドキュメント内の任意の 1 つのブロック要素のコンテンツまたは属性を更新できます。

## API 呼び出し説明

- 本質的には PATCH 操作（非冪等）であり、渡されたフィールドのみが更新され、渡されないフィールドはそのまま維持されます。
- 現時点では、段落タイプのブロック要素の更新のみサポートしています。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | `https://api.dingtalk.io/v1.0/doc/suites/documents/{documentId}/blocks/{blockId}` |
| HTTP Method | PUT |
| サポートするアプリタイプ | appType-社内アプリ |
| 必要な権限 | permission-Storage.File.Write-企業ストレージファイル書き込み権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | はい | 本 API を呼び出すためのアクセス認証情報です。[社内アプリのアクセストークン取得](/ja/open/development/obtain-the-access-token-of-an-internal-app) API を呼び出して取得します。 |

### パスパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| documentId | String | はい | ドキュメント ID（ドキュメントの docKey または dentryUuid）。[ナレッジベースドキュメントの作成](/ja/open/development/create-team-space-document) API を呼び出してドキュメントを作成した後、戻り値から `docKey` パラメータを取得します。      ドキュメント URL から `dentryUuid` を取得します。例えば https://alidocs.dingtalk.io/i/nodes/Zxxxxa-id の場合、dentryUuid は Zxxxxa-id となります。 |
| blockId | String | はい | 対象段落の一意な識別子です。[ブロック要素の検索](/ja/open/development/api-docblocksquery) API を呼び出すことで、該当段落の `blockId` パラメータを取得できます。 |

### クエリパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| operatorId | String | はい | ユーザーの unionId です。[ユーザー詳細の検索](/ja/open/development/query-user-details) API を呼び出して unionid パラメータの値を取得できます。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| element | `Map<String, Any>` | はい | 更新対象のブロック要素 BlockElement タイプおよび対応するタイプに必要な属性です（詳細は[ブロック要素データ構造](/ja/open/development/block-data-structure)を参照）。構造は以下の通りです。   ``` {   "blockType": enum(BlockType),   [blockType]: Object(ElementProperties), } ``` |
|  | Any | いいえ | 更新対象のブロック要素属性。 |

### リクエスト例

HTTP

```http
PUT /v1.0/doc/suites/documents/doc_id/blocks/block_id?operatorId=union_id HTTP/1.1
Host:api.dingtalk.io
x-acs-dingtalk-access-token:access_token
Content-Type:application/json

{
  "element" : {
    "blockType" : "paragraph",
    "paragraph" : {
      "folded": true
    }
  }
}
```
