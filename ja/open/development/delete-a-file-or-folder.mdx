---
title: "ファイルまたはフォルダーの削除"
---

本インターフェースを呼び出すことで、ファイルまたはフォルダーを削除できます。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | `https://api.dingtalk.io/v1.0/storage/spaces/{spaceId}/dentries/{dentryId}` |
| HTTP Method | DELETE |
| 対応アプリタイプ | appType-社内アプリ　appType-サードパーティ社内アプリ |
| 権限要件 | permission-Storage.File.Write-企業ストレージファイル書き込み権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | はい | 本インターフェース呼び出し時のアクセス認証情報。以下の方法で取得します:   - 社内アプリの場合、[社内アプリのaccessToken取得](/ja/open/development/obtain-the-access-token-of-an-internal-app)インターフェースを呼び出して取得します。 - サードパーティ社内アプリの場合、[サードパーティアプリにより権限付与された企業のaccessToken取得](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1)インターフェースを呼び出して取得します。 |

### パスパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| spaceId | String | はい | スペースID。[スペース作成](/ja/open/development/add-space)インターフェースを呼び出してidパラメータの値を取得できます。 |
| dentryId | String | はい | 削除対象のファイルまたはフォルダーのID。[ファイルまたはフォルダーリストの取得](/ja/open/development/get-a-list-of-files-or-folders)または[dentryUuidを使ったspaceIdとdentryIdの取得](/ja/open/development/api-getdentryidbyuuid)インターフェースを呼び出してidパラメータの値を取得できます。 |

### クエリパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| toRecycleBin | Boolean | いいえ | 削除後、ゴミ箱にバックアップするかどうか:   - **true**: はい - **false**: いいえ（デフォルト）   現時点では、[スペース作成](/ja/open/development/new-space)インターフェースで作成したクラウドドライブスペース内のファイルおよびフォルダーのみゴミ箱へのバックアップに対応しています。 |
| unionId | String | はい | 操作者のunionId。[ユーザー詳細の照会](/ja/open/development/query-user-details)インターフェースを呼び出してunionidパラメータの値を取得できます。 |

### リクエスト例

```http
DELETE /v1.0/storage/spaces/85xxxxx/dentries/456xxxxx?toRecycleBin=true&unionId=chyxxxxx HTTP/1.1
Host:api.dingtalk.io
x-acs-dingtalk-access-token:xxxxx
Content-Type:application/json
```
