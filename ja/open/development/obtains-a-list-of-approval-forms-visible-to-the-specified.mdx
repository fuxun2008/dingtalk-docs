この API を呼び出すと、社員の userId をもとに、その社員が閲覧できる承認フォームの一覧をページ単位で取得します。1 回の呼び出しで返されるフォームは最大 100 件です。

## リクエスト

### ベーシック情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/v1.0/workflow/processes/userVisibilities/templates |
| HTTP メソッド | GET |
| 対応アプリタイプ | appType-社内アプリ |
| 必要な権限 | permission-Workflow.Form.Read-作業フローテンプレートの読み取り権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | はい | この API を呼び出すためのアクセス認証情報です。[社内アプリのアクセストークンを取得](/ja/open/development/obtain-the-access-token-of-an-internal-app) API を呼び出して取得してください。 |

### クエリパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| userId | String | いいえ | 照会する社員の userId です。指定しない場合は、組織内のすべての承認フォームを返します。 |
| maxResults | Long | はい | 1 ページあたりの件数です。最大値は 100 です。 |
| nextToken | Long | はい | ページネーションカーソルです。- 初回の呼び出しでは 0 を指定します。- 2 回目以降の呼び出しでは、前回の呼び出しで返された nextToken を指定します。 |

### リクエスト例

HTTP

```http
GET /v1.0/workflow/processes/userVisibilities/templates?userId=manager7078&maxResults=10&nextToken=0 HTTP/1.1
Host:api.dingtalk.io
x-acs-dingtalk-access-token:6d1bxxxx
Content-Type:application/json
```
