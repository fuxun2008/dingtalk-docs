本インターフェースを呼び出すことで、DingTalk スプレッドシート内の既存のフローティング画像の属性（画像アドレス、アンカー位置、サイズオフセット量を含む）を更新できます。部分更新に対応しており、渡されなかったフィールドは元の値を保持します。たとえば `anchor` のみを渡すことで、他の属性に影響を与えずに画像位置のみを調整できます。画像位置の調整、画像ソースの差し替え、表示サイズの変更などのシーンに適しています。成功時には、更新後の画像の完全な属性を返します。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | `https://api.dingtalk.io/v1.0/doc/workbooks/{workbookId}/sheets/{sheetId}/floatImages/{id}` |
| HTTP Method | PUT |
| 対応アプリタイプ | appType-社内アプリ |
| 権限要件 | permission-Document.Workbook.Write-DingTalk スプレッドシート書き込み権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | はい | 本インターフェースを呼び出すためのアクセス認証情報です。[社内アプリの accessToken を取得](https://open.dingtalk.io/document/development/obtain-the-access-token-of-an-internal-app)インターフェースを呼び出して取得できます。 |

### パスパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| workbookId | String | はい | スプレッドシートファイル ID。[ナレッジベース API](https://open.dingtalk.io/document/development/knowledge-base-overview) が返す `nodeId(dentryUuid)` がスプレッドシートの `workbookId` に該当します。[ノードの取得](https://open.dingtalk.io/document/development/get-node)および[ナレッジベースドキュメントの作成](https://open.dingtalk.io/document/development/create-team-space-document)インターフェースを呼び出して取得できます。 |
| sheetId | String | はい | ワークシート ID または見出し。[すべてのワークシートを取得](https://open.dingtalk.io/document/development/obtain-all-worksheets)インターフェースを呼び出して、id とワークシートの見出しを取得できます。 |
| id | String | はい | 指定するフローティング画像 id。「フローティング画像の検索」インターフェースから取得できます。 |

### クエリパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| operatorId | String | はい | 操作者の unionId。[ユーザー詳細の検索](https://open.dingtalk.io/document/development/query-user-details)インターフェースを呼び出して取得できます。操作者に権限がない場合、インターフェースは `The operator has no permission` というエラーを返します。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| src | String | いいえ | フローティング画像のリソースアドレス。[リソースアップロード情報の取得](https://open.dingtalk.io/document/development/api-getresourceuploadinfo)インターフェースを呼び出して `resourceUrl` を取得する必要があります。 |
| anchor | Object | いいえ | アンカー位置。画像をどのセルに固定するかを指定します。 |
| row | Integer | いいえ | アンカーが存在する行番号（0 から開始）。 |
| col | Integer | いいえ | アンカーが存在する列番号（0 から開始）。 |
| coordinate | Object | いいえ | 画像サイズおよびアンカーセルからの相対オフセット量。 |
| width | double | いいえ | 画像の幅。単位：ピクセル。 |
| height | double | いいえ | 画像の高さ。単位：ピクセル。 |
| offsetX | double | いいえ | アンカーセル左上隅からの水平オフセット量。単位：ピクセル。 |
| offsetY | double | いいえ | アンカーセル左上隅からの垂直オフセット量。単位：ピクセル。 |
