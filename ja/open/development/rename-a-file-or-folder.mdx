---
title: "ファイルまたはフォルダーの名前を変更"
---

本インターフェースを呼び出すことで、ファイルまたはフォルダーの名前を変更できます。ただし、ストレージスペース内のルートディレクトリは名前変更に対応していません。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | `https://api.dingtalk.io/v1.0/storage/spaces/{spaceId}/dentries/{dentryId}/rename` |
| HTTP Method | POST |
| 対応アプリタイプ | appType-社内アプリ　appType-サードパーティ社内アプリ |
| 権限要件 | permission-Storage.File.Write-企業ストレージファイル書き込み権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | はい | 本インターフェースを呼び出すためのアクセス認証情報。以下の方法で取得します：   - 社内アプリの場合、[社内アプリのaccess_tokenを取得](https://open.dingtalk.io/document/development/obtain-the-access-token-of-an-internal-app)インターフェースを呼び出して取得します。 - サードパーティ社内アプリの場合、[サードパーティアプリが権限付与された企業のaccess_tokenを取得](https://open.dingtalk.io/document/development/obtain-the-access-token-of-the-authorized-enterprise-1)インターフェースを呼び出して取得します。 |

### パスパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| spaceId | String | はい | スペースID。[スペースの追加](https://open.dingtalk.io/document/development/add-space)インターフェースを呼び出してidパラメータの値を取得できます。 |
| dentryId | String | はい | ファイルまたはフォルダーのID。[ファイルまたはフォルダーリストの取得](https://open.dingtalk.io/document/development/get-a-list-of-files-or-folders)または[dentryUuidに基づいてspaceIdとdentryIdを取得](https://open.dingtalk.io/document/development/api-getdentryidbyuuid)インターフェースを呼び出してidパラメータの値を取得できます。  ストレージスペースのルートディレクトリは名前変更に対応していないため、本パラメータに0を渡すことはできません。 |

### クエリパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| unionId | String | はい | 操作者のunionId。[ユーザー詳細の照会](https://open.dingtalk.io/document/development/query-user-details)インターフェースを呼び出してunionidパラメータの値を取得できます。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| newName | String | はい | ファイルまたはフォルダーの新しい名称。命名規則は以下のとおりです：- 先頭と末尾にスペースを含めることはできません。含まれる場合は自動的に削除されます - 特殊文字（タブ、`*`、`"`、`<`、`>`、`|`）を含めることはできません - `.` で終わることはできません |

### リクエスト例

HTTP

```http
POST /v1.0/storage/spaces/854xxxxx/dentries/645xxxxx/rename?unionId=cHtUYxxxxx HTTP/1.1
Host:api.dingtalk.io
x-acs-dingtalk-access-token:xxxxx
Content-Type:application/json

{
  "newName" : "测试"
}
```
