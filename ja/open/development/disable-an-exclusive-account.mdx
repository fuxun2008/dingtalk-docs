---
title: "企業アカウントの無効化"
---

本 API を呼び出して、指定した企業アカウントを無効化します。

## API 呼び出し説明

シングルサインオンタイプの企業アカウントは、現在 API 経由でのみ管理可能です。自社作成の企業アカウントの場合、企業管理バックエンドからも管理できます。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/v1.0/contact/orgAccounts/disable |
| HTTP Method | POST |
| サポートするアプリタイプ | appType-社内アプリ　appType-サードパーティ社内アプリ |
| 必要な権限 | permission-Contact.OrgAccountSecurity.ReadWrite-連絡先企業アカウント安全データの読み書き権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | はい | 本 API を呼び出すためのアクセス認証情報です。[社内アプリの アクセストークン を取得する](/ja/open/development/obtain-the-access-token-of-an-internal-app#) API を呼び出して取得します。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| userId | String | はい | 企業アカウントの userid です。次の 4 つの方法で取得できます：   - [携帯電話番号から企業アカウントユーザーを照会する](/ja/open/development/obtain-the-userid-of-your-mobile-phone-number#) - [SSO 企業アカウントを作成する](/ja/open/development/create-an-sso-account#) - [DingTalk 自社作成企業アカウントを作成する](/ja/open/development/create-dingtalk-user-created-dedicated-account#) - [他の組織の企業アカウントを招待して参加させる](/ja/open/development/invite-other-organization-specific-accounts-to-join#) |
| reason | String | いいえ | 企業アカウントの無効化理由です。 |

### リクエスト例

HTTP

```http
POST /v1.0/contact/orgAccounts/disable HTTP/1.1
Host:api.dingtalk.io
x-acs-dingtalk-access-token:BExxx
Content-Type:application/json

{
  "userId" : "user123",
  "reason" : "アカウント有効期限切れ。"
}
```
