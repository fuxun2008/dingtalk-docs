description: "DingTalk サーバー API で、プロセスセンター経由で連携したOA承認タスクを照会する方法を解説します。userId を指定して、過去1年以内の実行中のタスクをページ分割で取得できます。"

この API を呼び出して、ユーザーの実行中の承認タスクを照会します。

## API 呼び出し説明

- この API で照会できるのは、過去1年以内のタスクデータのみです。
- この API は、「プロセスセンター未処理タスクの作成」API でユーザー向けに作成された未処理タスクを照会します。これらのタスクは DingTalk のタスクに同期され、**DingTalk クライアント > タスク > OA承認** で確認できます。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/v1.0/workflow/processCentres/todoTasks |
| HTTP メソッド | GET |
| 対応アプリタイプ | appType-社内アプリ　appType-サードパーティ社内アプリ |
| 必要な権限 | permission-qyapi_aflow-承認作業フローデータ管理権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | はい | この API を呼び出すためのアクセス認証情報です。以下の方法で取得します。   - 社内アプリ：[社内アプリのアクセストークンの取得](/ja/open/development/obtain-the-access-token-of-an-internal-app) API を呼び出します。 - サードパーティ社内アプリ：「サードパーティアプリが承認された組織のアクセストークンの取得」API を呼び出します。 |

### クエリパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| userId | String | はい | タスク実行者の userId です。[部門内のユーザー ID リストの照会](/ja/open/development/query-the-list-of-department-userids) API を呼び出して取得します。 |
| pageSize | Integer | はい | 1ページあたりの件数です。1 から始まります。最大値：40。 |
| pageNumber | Integer | はい | ページ番号です。1 から始まります。 |
| createBefore | Long | いいえ | 照会の開始時刻です。    現在時刻から1年以上前の時刻は指定できません。 |

### リクエスト例

HTTP

```http
GET /v1.0/workflow/processCentres/todoTasks?userId=manager001&pageSize=1&pageNumber=1&createBefore=1660036833411 HTTP/1.1
Host:api.dingtalk.io
x-acs-dingtalk-access-token:xxxx
Content-Type:application/json
```
