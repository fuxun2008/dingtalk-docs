## グループ拡張の開発プロセスについて

作業を開始する前に、[DingTalk 開発者になる](https://open.dingtalk.com/document/app/become-a-dingtalk-developer#topic-2024337)ための準備が完了していることを確認してください。グループアプリの開発プロセスは以下のとおりです。

1. [社内アプリを開発する](https://open.dingtalk.com/document/org/create-orgapp#topic-2024342)。グループ拡張の開発は、社内アプリをベースに行う必要があります。社内アプリがない場合は、[アプリを作成](https://open.dingtalk.com/document/org/create-orgapp#topic-2024342)してください。既にお持ちの場合は、そのまま利用できます。
2. [メッセージプッシュを設定する](https://open.dingtalk.com/document/org/configure-push-settings#topic-2199272)。**メッセージプッシュ**で、ボットをバインドして開発します。
3. [グループ拡張のベーシック情報を設定する](https://open.dingtalk.com/document/org/configure-the-basic-information-of-the-group-application#topic-2199273)。社内アプリの**クールアプリ拡張**で、グループ拡張を有効化し、ベーシック情報を設定します。作成が成功すると、グループ拡張のアプリコードを取得できます。
4. [インタラクティブカードを開発する](https://open.dingtalk.com/document/org/interactive-card#topic-2199274)（任意）。ボットをバインドすることで、インタラクティブカードなどを送信できます。
5. [グループ拡張アプリを有効化する](https://open.dingtalk.com/document/org/install-group-applications#topic-2199277)。グループアプリの開発が完了したら、**グループに追加**し、クールアプリセンターで有効化する必要があります。
6. [グループ拡張アプリを利用する](https://open.dingtalk.com/document/org/install-group-applications#topic-2199277)。内部グループのグループアプリバーで、クールアプリを表示して利用します。

## グループ拡張の共通 API

グループ拡張の共通 API については、[グループ拡張の共通 API](https://open.dingtalk.com/document/orgapp-server/api-operations-for-group-applications#topic-2198333)をご覧ください。

グループ拡張のクライアントサイド API については、[クールアプリをインストールしてグループに追加する](https://open.dingtalk.com/document/orgapp-client/install-cool-applications-and-add-them-to-the-group#topic-2209393)をご覧ください。
