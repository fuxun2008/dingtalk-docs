このドキュメントは、DingTalk 連絡先を全体的に理解いただくことを目的としています。本ドキュメントを通じて、企業管理者、IT 担当者、開発者は連絡先の機能範囲を迅速に把握し、今後のシステム統合やビジネス革新の基礎を築くことができます。

## DingTalk 連絡先とは

DingTalk 連絡先は、社内情報を一元管理するためのコアインフラです。企業の組織構成とメンバー情報をデジタル化して表現し、企業メンバーが素早く人を探し、効率的にコラボレーションするための基盤機能を提供します。

機能の詳細については、[DingTalk 使い方ガイド - 企業連絡先](https://docs.dingtalk.io/i/p/Y7kmbokZp3pgGLq2/docs/Y7kmbpxy30LLzLq2?dontjump=true#)をご参照ください。

| **観点** | **説明** |
| --- | --- |
| 本質 | 企業の組織構成をデジタル化して表現するキャリア |
| 形態 | ツリー型部門構造 + メンバー情報データベース |
| 役割 | 企業の人・物・事をつなぐハブであり、承認フロー、メッセージルーティング、権限制御などのシーンを支える |

## 連絡先の確認方法

### 組織管理者の視点

組織管理者は、以下の方法で連絡先を管理・閲覧できます。

- DingTalk 管理コンソール：[DingTalk 管理コンソール](https://oa.dingtalk.io/)にログインし、**社内連絡先**モジュールに入ると、連絡先の完全な管理と設定を行えます。
- 連絡先設定：連絡先の可視性ルール、カスタムフィールド、役員モードなどのプレミアム機能を設定できます。

### 一般メンバー

一般組織メンバーは、以下のクライアントから連絡先を閲覧できます。

- **DingTalk PC 版**：DingTalk PC クライアントで「連絡先」タブをクリックすると、企業の組織構成と連絡先詳細を閲覧できます。
- **DingTalk モバイル版**：DingTalk モバイル App で「連絡先」ページに入り、部門別の閲覧やキーワード検索が可能です。
- **DingTalk Web 版**：DingTalk ウェブ版を通じて連絡先機能にアクセスできます。

## 用語解説

### 社員番号

社員番号に対応するフィールドコードは job_number です。社内社員の社員番号は一意である必要はないため、社員の社内での一意の識別子としては使用できません。

組織管理者が[DingTalk 管理コンソール](https://oa.dingtalk.io/)にログインし、連絡先ページで**社員名**をクリックすると、社員の社員番号を確認できます。社員番号フィールドは任意フィールドです。

### unionId

現在の DingTalk オープンプラットフォームアカウント範囲内におけるユーザーの一意の識別子です。同一の DingTalk オープンプラットフォームアカウントには複数のオープンアプリを含めることができ、ISV のスイートアプリや企業アプリも含まれます。

unionId は[ユーザー詳細の取得](/ja/open/development/query-user-details) API を呼び出して取得できます。

### ロールグループとロール

社内で定義されたロールグループとロールであり、社員の身分情報を管理しやすくします。社員は同時に複数のロール身分を持つことができます。

組織管理者が[DingTalk 管理コンソール](https://oa.dingtalk.io/)にログインし、**連絡先 > 社内連絡先管理**ページで**ロール**をクリックすると、ロールグループとロールを確認できます。

### 連絡先拡張フィールド

連絡先には拡張フィールドを追加できます。

組織管理者が[DingTalk 管理コンソール](https://oa.dingtalk.io/)にログインし、**社内連絡先設定 > 連絡先情報** > **カスタムフィールド追加**ページで、カスタムフィールドを新規追加します。
