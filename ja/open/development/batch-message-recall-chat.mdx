---
title: "人とボットのチャットにおけるボットメッセージの一括取り消し"
description: "ボットメッセージを24時間以内に一括で取り消し、企業の誤送信対応を効率化します"
---

人とボットのチャットにおけるボットメッセージを一括で取り消すために使用します。呼び出し時には、POST リクエストで robotCode、processQueryKeys などのビジネスフィールドを送信します。本インターフェースは、企業が 24 時間以内に誤送信した通知メッセージを取り消すなどのシナリオに適用されます。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/v1.0/robot/otoMessages/batchRecall |
| HTTP Method | POST |
| サポートされるアプリタイプ | appType-社内アプリ　appType-サードパーティ社内アプリ |
| 権限要件 | permission-qyapi_robot_sendmsg-社内ボットメッセージ送信権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | はい | 本インターフェースを呼び出すためのアクセス認証情報。以下の方法で取得します：   - 社内アプリの場合は、[社内アプリの access_token を取得する](/ja/open/development/obtain-the-access-token-of-an-internal-app#)インターフェースを呼び出して取得します。 - サードパーティ社内アプリの場合は、[サードパーティアプリが認可された企業の access_token を取得する](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#)インターフェースを呼び出して取得します。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| robotCode | String | はい | ボットのコード。詳細は[ボット ID](/ja/open/development/development-robot-overview#447ec33014hrl)を参照してください。  [ボットによるグループチャットメッセージの送信](/ja/open/development/the-robot-sends-a-group-message#)インターフェースを使用する際の robotCode と一致させる必要があります。 |
| processQueryKeys | Array of String | はい | メッセージの一意識別子のリスト。[人とボットのチャットにおけるボットメッセージの一括送信](/ja/open/development/chatbots-send-one-on-one-chat-messages-in-batches#)インターフェースを通じて取得できます。    - 1 回あたり最大 20 件まで指定可能です。 - メッセージ送信後 24 時間以内であれば processQueryKey を使用してメッセージを取り消せますが、24 時間を超えるとメッセージは取り消せません。 |
