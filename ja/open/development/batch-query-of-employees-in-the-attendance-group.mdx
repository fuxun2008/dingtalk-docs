この API を呼び出すと、勤怠グループの groupKey に基づき、指定した勤怠グループの勤怠対象者である社員を照会します。部門を勤怠対象者として設定している場合、この API は部門 ID を返しません。

## リクエスト

| **基本情報** | |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/topapi/attendance/group/users/query |
| HTTP メソッド | POST |
| 対応アプリタイプ | appType-社内アプリ |
| 必要な権限 | permission-qyapi_attendance_group_read-勤怠グループの照会権限 |

### クエリパラメータ

| 名前 | タイプ | 必須 | 例 | 説明 |
| --- | --- | --- | --- | --- |
| access_token | String | はい | 4c9ebd2b1534xxxx | この API の呼び出しに使用するアプリ認証情報です。[社内アプリの access_token の取得](/ja/open/development/obtain-orgapp-token) API を呼び出して取得してください。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 例 | 説明 |
| --- | --- | --- | --- | --- |
| size | Number | いいえ | 50 | 1 ページあたりの件数です。 |
| cursor | String | はい | 10 | 前回取得したバッチの最後のユーザー ID です。最初から照会する場合は、null または空の値を渡してください。 |
| op_userid | String | いいえ | user01 | 操作者のユーザー ID です。 |
| group_key | String | はい | CEDDFFxxxx | 勤怠グループ ID です。 **注意**  勤怠グループの識別子が group_id の場合は、[groupId から groupKey への変換](/ja/open/development/groupid-to-groupkey) API を呼び出して、group_id を group_key に変換してください。 |

### リクエスト例

```curl
curl -X POST "https://api.dingtalk.io/topapi/attendance/group/users/query" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=d2ee6exxxx9266c' \
-d 'cursor=%5C%22%5C%22' \
-d 'group_key=0151Exxxx17E876' \
-d 'op_userid=123456' \
-d 'size=50'
```

Java

```text
DingTalkClient client = new DefaultDingTalkClient("https://api.dingtalk.io/topapi/attendance/group/users/query");
OapiAttendanceGroupUsersQueryRequest req = new OapiAttendanceGroupUsersQueryRequest();
req.setSize(50L);
req.setCursor("10");
req.setOpUserid("user01");
req.setGroupKey("CEDDFFxxxx");
OapiAttendanceGroupUsersQueryResponse rsp = client.execute(req, access_token);
System.out.println(rsp.getBody());
```

## レスポンス

### レスポンスボディ

| 名前 | タイプ | 例 | 説明 |
| --- | --- | --- | --- |
| request_id | String | ntxswpdprw5d | リクエスト ID です。 |
| result | DingOpenResult |  | 返却結果です。 |
| result | Result |  | 照会結果です。 |
| user_list | String[] | user01 | ユーザーのリストです。 |
| has_more | String | false | さらにデータがあるかどうかを示します。   - **true**：あり - **false**：なし |
| errcode | Number | 0 | リターンコードです。 |
| errmsg | String | ok | リターンコードの説明です。 |
| success | Boolean | true | 呼び出しに成功したかどうかを示します。   - **true**：成功 - **false**：失敗 |

### レスポンスボディの例

```json
{
  "result": {
    "errcode": 0,
    "errmsg":"ok",
    "result": {
      "has_more": "false",
      "user_list": [
        "user01"
      ]
    },
    "success": true
  },
  "request_id": "ntxswpdprw5d"
}
```

### エラーコード

この API の呼び出しでエラーが返された場合は、エラーメッセージをもとに[グローバルエラーコード](/ja/open/development/server-api-error-codes-1)ドキュメントで解決方法を確認してください。
