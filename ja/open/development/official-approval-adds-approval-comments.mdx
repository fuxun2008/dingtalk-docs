この API を呼び出して、承認インスタンスにコメントを追加します。

## API 呼び出し説明

承認コメントに添付を追加するには、ファイルを承認用ドライブスペースにアップロードします。これにより、API パラメータの spaceId、fileType、fileName、fileId、fileSize を取得します。取得手順は次のとおりです。

1. [承認用ドライブスペース情報の取得](/ja/open/development/obtains-the-information-about-approval-nail-disk) API を呼び出し、ドライブスペースへのアップロード権限と、承認用ドライブスペースの spaceId を取得します。
2. 承認用ドライブスペースの spaceId を使用し、Web アプリ（H5 マイクロアプリ）で、ドライブへ添付をアップロードするか、ドライブからファイルを選択します。これにより、ドライブの添付ファイル情報を取得します。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/v1.0/workflow/processInstances/comments |
| HTTP メソッド | POST |
| 対応するアプリタイプ | appType-社内アプリ |
| 必要な権限 | permission-Workflow.Instance.Write-ワークフローインスタンスの書き込み権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | はい | この API を呼び出すためのアクセス認証情報です。[社内アプリのアクセストークンの取得](/ja/open/development/obtain-the-access-token-of-an-internal-app) API を呼び出して取得します。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| processInstanceId | String | はい | 承認インスタンス ID です。   - [承認インスタンスの作成](/ja/open/development/create-an-approval-instance) API を呼び出し、`InstanceId` パラメータの値を取得します。 - [承認インスタンス詳細の取得](/ja/open/development/obtain-an-approval-list-of-instance-ids) API を呼び出し、`list` パラメータの値を取得します。 |
| text | String | はい | コメント内容です。最大長は 1,024 文字です。 |
| commentUserId | String | はい | コメント者の userId です。 |
| file | Object | いいえ | ファイルです。 |
| photos | Array of String | いいえ | 画像の URL です。 |
| attachments | Array | いいえ | 添付のリストです。リスト要素の最大数は 20 です。 |
| spaceId | String | いいえ | ドライブスペース ID です。      本トピックの「API 呼び出し説明」を参照してください。 |
| fileSize | String | いいえ | ファイルサイズです。      本トピックの「API 呼び出し説明」を参照してください。 |
| fileId | String | いいえ | ファイル ID です。最大長は 256 文字です。      本トピックの「API 呼び出し説明」を参照してください。 |
| fileName | String | いいえ | ファイル名です。最大長は 256 文字です。      本トピックの「API 呼び出し説明」を参照してください。 |
| fileType | String | いいえ | ファイルタイプです。      本トピックの「API 呼び出し説明」を参照してください。 |
