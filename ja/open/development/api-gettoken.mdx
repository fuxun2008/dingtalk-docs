## API 呼び出し説明

これまで以下の API を使用していた場合：

- 社内アプリ：[社内アプリの accessToken を取得する](https://open.dingtalk.io/document/development/obtain-the-access-token-of-an-internal-app#) API を呼び出して、企業が API を呼び出すための認証情報を取得していました。
- サードパーティ社内アプリ：[サードパーティアプリで権限付与された企業の accessToken を取得する](https://open.dingtalk.io/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#) API を呼び出して、サードパーティアプリで権限付与された企業が API を呼び出すための認証情報を取得していました。

現在、これら 2 つのシナリオは 1 つの API に統一されています。アプリタイプを区別する必要はなく、本 API を直接呼び出すことで、アクセストークンを取得し、アプリ権限の API を呼び出すことができます。

## リクエスト

| **基本情報** | |
| --- | --- |
| HTTP URL | `https://api.dingtalk.io/v1.0/oauth2/{corpId}/token` |
| HTTP Method | POST |
| サポートするアプリタイプ | appType-社内アプリ appType-サードパーティ社内アプリ |
| 権限要件 | permission-qyapi_base-企業 API を呼び出す際に必要な基本権限 |

### パスパラメータ

| 名前 | タイプ | 必須 | 例 | 説明 |
| --- | --- | --- | --- | --- |
| corpId | String | はい | ding9f\*\*\*\*41 | 組織 ID。アプリが動作する組織の corpId を指定します：   - 社内アプリ：自社の corpId を指定します。 - サードパーティ社内アプリ：アプリを利用開始した、権限付与済み企業の corpId を指定します。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 例 | 説明 |
| --- | --- | --- | --- | --- |
| client_id | String | はい | suite123 | アプリの ClientID。 |
| client_secret | String | はい | \*\*\*\*\*\*\*\* | アプリの ClientSecret。 |
| grant_type | String | はい | client_credentials | 認可タイプ：client_credentials |

### リクエスト例

HTTP

```http
POST /v1.0/oauth2/ding9f****41/token HTTP/1.1
Host:api.dingtalk.io
Content-Type:application/json

{
  "client_id" : "suite123",
  "client_secret" : "********",
  "grant_type" : "client_credentials"
}
```

### レスポンスボディ

| 名前 | タイプ | 例 | 説明 |
| --- | --- | --- | --- |
| access_token | String | 2bf\*\*\*\*\*\*9be361a5084f1e2b8 | アクセス認証情報。 |
| expires_in | Integer | 7200 | アクセス認証情報の有効期間（単位：秒）。 |


### エラーコード

API 呼び出し時にエラーが発生した場合は、エラーメッセージをもとに [グローバルエラーコード](https://open.dingtalk.io/document/development/server-api-error-codes-1#) ドキュメントで解決方法を検索してください。

| HttpCode | エラーコード | エラーメッセージ | 説明 |
| --- | --- | --- | --- |
| 400 | invalid.client | invalid.client | 無効な ClientID または ClientSecret です |
| 400 | unsupported.grant.type | unsupported.grant.type | この認可タイプはサポートされていません。認可タイプパラメータを確認してください |
| 401 | unauthorized.client | unauthorized.client | アプリに権限が付与されていません |
| 500 | server.error | server.error | サーバーの予期せぬエラー |
