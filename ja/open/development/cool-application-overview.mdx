本記事では、クールアプリの開発者ガイドで扱う機能を紹介します。

## **クールアプリとは**

アプリをあらゆる場所で見つけやすく、利用しやすくします。

クールアプリは、まったく新しいシナリオベースのアプリです。アプリの機能を DingTalk 内の複数の製品シナリオに統合し、没入型の体験を提供するとともに、新しいインタラクション手法を切り拓き、データ活用能力を強化します。ユーザーがアプリを探すモデルから、アプリがユーザーに届くモデルへと転換し、新しいシナリオベースのコラボレーション体験を生み出します。

詳細については、クールアプリを参照してください。

## **クールアプリの開発方法**

### **グループチャットクールアプリの開発**

- **没入型体験：** 現在の作業を中断することなく、チャットのコンテキスト内にとどまります。
- **シナリオベースのコラボレーション：** 特定のシナリオやタスクを中心に、情報をリアルタイムかつ効率的にコラボレーションします。
- **即時データ分析：** 効率的なコラボレーションによって生成された構造化データを、即時分析と実行可能なインサイトに活用します。

### **プロセス概要**

開始する前に、前提条件である[DingTalk 開発者になる](/ja/open/dingstart/become-a-dingtalk-developer)を完了していることを確認してください。統合フローは以下のとおりです。詳細については、[グループチャットクールアプリ開発者ガイド](/zh/open/development/group-chat-cool-app-overview)を参照してください。

1. クールアプリの作成により、グループチャットクールアプリの作成を完了します。
2. クイック設定エントリのコンテンツを設定し、チャットのクイックアクセスバーに表示します。
3. グループチャットクールアプリの開発が完了したら、クールアプリの公開と利用を行い、アプリのリリースと利用を完了します。

上記の手順を完了すると、シンプルなグループチャットクールアプリの開発と公開が完了します。これで、グループチャット内にクールアプリをインストールし、クイックアクセスエントリからそのページにアクセスできるようになります。さらに、以下の追加機能を利用して、より優れた体験を備えたクールアプリを構築することもできます。

**注意**

クールアプリの高度な開発（任意）

- グループチャットクールアプリが送信するメッセージコンテンツを設定します。

  - プレーンメッセージを開発します。グループチャットクールアプリボットからプレーンメッセージを送信し、基本的なメッセージの送信と管理を実装します。
  - インタラクティブカードを開発し、インタラクティブなカードメッセージの送信と管理を行い、ユーザーのインタラクションを可能にします。
  - トップバナーカードを開発し、トップバナーカード情報の送信と管理を行い、ユーザーのインタラクションを可能にします。
- グループチャットボットの高度なインタラクションを実装します。詳細については、ボットの会話を有効化するを参照してください。
- グループ管理 API を使用して、アプリの既存機能をグループ管理に統合します。詳細については、グループ管理を参照してください。
- グループチャットクールアプリのコールバックイベントを使用して、クールアプリがグループ内にインストールまたはアンインストールされたタイミングを検知します。これにより、オンボーディングガイダンスやデータ権限の回収など、初期化や終了の処理を実行できます。詳細については、グループの変更を検知する（イベントサブスクリプション）を参照してください。

### **メッセージメニュークールアプリの開発**

DingTalk では、メッセージを長押しするとメニューが表示され、メニューオプションを使ってメッセージに対する操作（転送、予定への変換、タスクへの変換など）を実行できます。メッセージメニューの新しいクイックアクションでは、開発者が独自の機能を統合し、業務シナリオに合わせてカスタマイズすることもできます。

- **メッセージ単一選択ビュー**
- **メッセージ複数選択ビュー**

### **プロセス概要**

開始する前に、前提条件である[DingTalk 開発者になる](/ja/open/dingstart/become-a-dingtalk-developer)を完了していることを確認してください。統合フローは以下のとおりです。詳細については、メッセージメニュー統合ガイドを参照してください。

1. リンク強化の開発は、社内アプリをベースに行う必要があります。社内アプリがない場合は、アプリの作成が必要です。すでにお持ちの場合は、そのまま利用します。
2. メッセージメニューの拡張情報を設定します。クールアプリの拡張機能で、メッセージメニューへの拡張を有効にし、基本情報を設定します。
3. JSAPI 認証を実行します。詳細については、H5 マイクロアプリ JSAPI 認証を参照してください。
4. メッセージコンテンツを取得します。H5 JSAPI - メッセージコンテンツの取得 API を呼び出してメッセージコンテンツを取得し、実際の業務ニーズに基づいてアプリを開発します。

### **リンク強化クールアプリの開発**

対象のリンクを開くには、通常リンクをクリックして対象ページに遷移します。リンク強化機能は、DingTalk チャット内のリンクを変換します。統合すると、リンクは自動的に認識され、カードに変換されます。ユーザーはカードのコンテンツを直接確認でき、カードのインタラクティブ機能を使ってカード上で直接業務操作を実行できます。

- **プレーンリンク**
- **強化リンク**

  - **画像テキストリンクをカードに変換し、Web ページの情報を表示**

  - **承認リンクをカードに変換し、直接インタラクション**

### **プロセス概要**

開始する前に、前提条件である[DingTalk 開発者になる](/ja/open/dingstart/become-a-dingtalk-developer)を完了していることを確認してください。統合フローは以下のとおりです。詳細については、リンク強化統合ガイドを参照してください。

ステップ 1：リンク強化の開発は、社内アプリをベースに行う必要があります。社内アプリがない場合は、アプリの作成が必要です。すでにお持ちの場合は、そのまま利用します。

ステップ 2：リンク強化ルールを設定します。クールアプリの拡張機能で、リンク強化ルールの基本情報を登録・設定します。

ステップ 3：テストユーザーを追加し、リンク強化機能の後続のデバッグを可能にします。

ステップ 4：業務コールバック API を実装し、リンク強化のコールバック変換を有効にします。

ステップ 5：リリースを送信し、社内でリンク強化を有効化します。

## **ベストプラクティス**

- DingTalk クールアプリは OKR グループアプリのシナリオを連携し、軽量で便利な体験を提供することで、OKR の運用とコラボレーションをより効率的にします。詳細については、クールアプリがオンライン OKR 管理の新しいモデルを実現を参照してください。
- DingTalk クールアプリは、タスクカード、プロジェクトトップバナー、プロジェクト日報、マイタスクなどの機能を活用して、軽量なプロジェクト管理クールアプリを構築します。詳細については、プロジェクト管理クールアプリの設計方法を参照してください。
- DingTalk クールアプリは、オムニチャネルでの顧客接点、顧客ライフサイクル全体の管理、精緻な営業プロセス管理を実現します。詳細については、XiaoBangBang クールアプリが営業チームの精緻な管理を実現を参照してください。
