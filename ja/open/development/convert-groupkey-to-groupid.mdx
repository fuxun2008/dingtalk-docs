---
title: "groupKey から groupId への変換"
description: "操作者の userId と勤怠グループの groupKey を指定し、旧形式の識別子を新しい groupId に変換する API です。"
---

この API を呼び出して、勤怠グループの groupKey を groupId に変換します。

## リクエスト

| **ベーシック情報** | |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/topapi/attendance/groups/keytoid |
| HTTP メソッド | POST |
| サポートされるアプリタイプ | appType-社内アプリ　appType-サードパーティ社内アプリ |
| 必須権限 | qyapi_attendance_group_read（勤怠グループの読み取り権限） |

### クエリパラメータ

| 名前 | タイプ | 必須 | 例 | 説明 |
| --- | --- | --- | --- | --- |
| access_token | String | はい | bE74xxxx | この API の呼び出しに使用するアプリ認証情報です。   - 社内アプリ：[社内アプリの access_token を取得](/ja/open/development/obtain-orgapp-token) API を呼び出して取得します。 - サードパーティ社内アプリ：サードパーティ社内アプリの access_token を取得 API を呼び出して取得します。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 例 | 説明 |
| --- | --- | --- | --- | --- |
| op_user_id | String | はい | user01 | 操作者の userId です。 |
| group_key | String | はい | 02B1Exxxx | 勤怠グループ ID（旧形式の勤怠グループ識別子）です。[勤怠グループ詳細の一括取得](/ja/open/development/batch-obtain-attendance-group-details) API を呼び出して、group_id パラメータの値を取得してください。 |

### リクエスト例

```curl
curl -X POST "https://api.dingtalk.io/topapi/attendance/groups/keytoid" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=40bafxxxx9d3b06' \
-d 'group_key=0151E0xxxxA917E876' \
-d 'op_user_id=123'
```

Java

```java

req.setGroupKey("02B1Exxxx");

System.out.println(rsp.getBody());
```

## レスポンス

### レスポンスボディ

| 名前 | タイプ | 例 | 説明 |
| --- | --- | --- | --- |
| result | Number | 685935028 | 勤怠グループ ID です。 |
| success | Boolean | true | リクエストが成功したかどうかを示します。   - **true**：成功 - **false**：失敗 |
| errcode | Number | 0 | リターンコードです。 |
| errmsg | String | ok | リターンコードの説明です。 |
| request_id | String | 3yt2gu3zz0qi | リクエスト ID です。 |

### レスポンスボディの例

```json
{
  "errcode":0,
  "result":685935028,
  "errmsg":"ok",
  "success":true,
  "request_id":"3yt2gu3zz0qi"
}
```

### エラーコード

API がエラーを返した場合は、エラーメッセージをもとに[グローバルエラーコード](/ja/open/development/server-api-error-codes-1)ドキュメントで解決方法を確認してください。
