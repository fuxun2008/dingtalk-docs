本記事では、メッセージテンプレートの作成、削除、有効化、無効化、複製、テスト、設定の方法について説明します。

## メッセージテンプレートの作成と設定

1. [Developer Console](https://open-dev.dingtalk.com/?version=5.86.5#/appMgr/provider/eapp/57406/2) にログインします。
2. **App 開発**をクリックし、**サードパーティ社内アプリ**を選択して、ミニプログラムまたは H5 マイクロアプリを作成します。
3. アプリ詳細ページで**メッセージプッシュ**をクリックします。メッセージテンプレート管理エリアで**追加**をクリックします。

4. テンプレートタイプを選択し、**作成**をクリックします。

5. メッセージテンプレートを設定し、**保存**をクリックします。

   **注記**

   テンプレートにテンプレートパラメータが設定されている場合、テンプレートパラメータが下部に自動的に読み込まれ、動的パラメータの説明を設定できます。

   メッセージコンテンツ内の一部の値は、注文番号、携帯電話番号、商品名など、動的に変化します。これらの値はテンプレート設定時には確定できないため、テンプレートパラメータを使用して置換できます。
6. **テスト**をクリックし、**テストメッセージを送信**をクリックして、メッセージテンプレートが正しく設定されているかを確認します。

## Markdown テンプレートの設定

Markdown テンプレートは、Markdown 構文を使用してメッセージを設定・送信します。操作を必要としない純粋な通知メッセージに適しています。

Markdown テンプレートを使用すると、テキスト、画像、リンクなどの表示形式を簡単にサポートできます。

**Markdown メッセージテンプレート設定の説明**

| 設定項目 | テンプレートパラメータ対応 | 説明 |
| --- | --- | --- |
| **テンプレート名** | 非対応 | テンプレート名を指定します。テンプレートのユースケースやタイプに基づいて命名できます。例：新規チケット通知テンプレート。 |
| **ユースケース** | 非対応 | テンプレートのユースケースを説明します。 |
| **画像** | 非対応 | メッセージ内の画像。画像リンクまたは media_id の形式です。この設定項目で個別に設定し、1 通のメッセージには 1 枚の画像のみを対応します。画像は上部に固定されます。 |
| **メッセージタイトル** | 非対応 | メッセージのタイトルであり、チャットの最初の画面に表示されるコンテンツです。 |
| **メッセージコンテンツ** | 対応 | Markdown 形式のメッセージコンテンツです。1,000 文字以内に収めることをお勧めします。サポートされる Markdown 構文については、以下の表を参照してください。**注記** - メッセージテンプレートの Markdown 構文はタイトルをサポートしません。つまり、「# + タイトルテキスト」のタイトル形式はサポートされません。メッセージタイトルはタイトル入力ボックスに個別に入力してください。第 1 レベルのタイトルのみサポートされます。- メッセージテンプレートの Markdown 構文は画像をサポートしません。つまり、「」形式はサポートされません。メッセージ画像は画像入力ボックスに個別に入力してください。1 通のメッセージには 1 枚の画像のみを対応します。 |

**Markdown 構文**：

```
参照
> 信念を持たない者は、何にでも惑わされる。
 
太字と斜体
**bold**
*italic*
 
リンク
[this is a link](http://name.com)
 
箇条書き
- item1
- item2
 
番号付きリスト
1. item1
2. item2

改行
 入力ボックスで改行を入力するだけで表示されます。\n はサポートされません。
```

## ActionCard テンプレート

ActionCard テンプレートは、ActionCard メッセージタイプを使用してメッセージを送信します。コンテンツとアクションポイントを組み合わせたメッセージをサポートし、1 つまたは複数のアクションポイントを通じてメッセージを素早く処理する必要があるシナリオに適しています。

ActionCard テンプレートは Markdown テンプレートをベースとしており、全体リダイレクトと独立リダイレクトの両方のスタイルをサポートします。

**ActionCard テンプレート設定の説明**

| 設定項目 | テンプレートパラメータ対応 | 説明 |
| --- | --- | --- |
| **テンプレート名** | 非対応 | テンプレート名を指定します。テンプレートのユースケースやタイプに基づいて命名できます。例：新規チケット通知テンプレート。 |
| **ユースケース** | 非対応 | テンプレートのユースケースを説明します。 |
| **画像** | 非対応 | メッセージ内の画像。画像リンクまたは media_id の形式です。この設定項目で個別に設定し、1 通のメッセージには 1 枚の画像のみを対応します。 |
| **メッセージタイトル** | 非対応 | メッセージのタイトルであり、チャットリストや通知に表示されるテキストです。最大 64 文字です。 |
| **メッセージコンテンツ** | 対応 | Markdown 形式のメッセージコンテンツです。1,000 文字以内に収めることをお勧めします。サポートされる Markdown 構文については、以下の表を参照してください。**注記** - メッセージテンプレートの Markdown 構文はタイトルをサポートしません。つまり、「# + タイトルテキスト」のタイトル形式はサポートされません。メッセージタイトルは**タイトル**入力ボックスに個別に入力してください。第 1 レベルのタイトルのみサポートされます。- メッセージテンプレートの Markdown 構文は画像をサポートしません。つまり、「」形式はサポートされません。メッセージ画像は**画像**入力ボックスに個別に入力してください。1 通のメッセージには 1 枚の画像のみを対応します。 |
| **アクションポイント** | 対応 | カードメッセージは、全体リダイレクト ActionCard スタイルと独立リダイレクト ActionCard スタイルをサポートします：- 全体リダイレクト ActionCard スタイルは、1 つのクリック可能なアクションをサポートします。1 つの設定を渡すと全体リダイレクトスタイルになります。- 独立リダイレクト ActionCard スタイルは、複数のクリック可能なアクションをサポートします。複数の設定を渡すと独立リダイレクトスタイルになります。 |
| **アクションポイントリンク** | 対応 | メッセージをクリックしたときにリダイレクトするリンクアドレスです。メッセージがミニプログラムとして送信される場合、ミニプログラムのリダイレクトリンクをサポートします。最大 500 文字です。 |
| **アクションポイントタイトル** | 対応 | リダイレクトボタンのタイトルです。最大 20 文字です。 |

## フォームテンプレート

フォームテンプレートは、OA メッセージタイプに基づいてメッセージを送信します。注文などのメッセージ表示に適しており、メッセージ詳細を表示するためのリダイレクトをサポートします。

**フォームメッセージテンプレート設定の説明**

| 設定項目 | テンプレートパラメータ対応 | 説明 |
| --- | --- | --- |
| **テンプレート名** | 非対応 | テンプレート名を指定します。テンプレートのユースケースやタイプに基づいて命名できます。例：新規チケット通知テンプレート。 |
| **ユースケース** | 非対応 | テンプレートのユースケースを説明します。 |
| **メッセージボックスヘッダーコンテンツ** | 対応 | メッセージのヘッダータイトルです。最大 10 文字に制限されます。これは通常のチャットに送信する際に有効になります。組織チャットに送信する際は、マイクロアプリの名前に置き換えられます。 |
| **メッセージボックスヘッダー背景色** | 対応 | メッセージヘッダーの背景色です。長さは半角 8 文字に制限され、最初の 2 文字が透明度、後の 6 文字が色の値を表します。0x は付けないでください。例：FFBBBBBB |
| **メッセージタイトル** | 非対応 | メッセージ本文のタイトルです。50 文字以内に収めることをお勧めします。 |
| **メッセージコンテンツ** | 対応 | メッセージ本文のコンテンツです。最大 3 行まで表示されます。 |
| **メッセージ本文内の画像** | 非対応 | メッセージ内の画像。画像リンクまたは media_id の形式です。この設定項目で個別に設定し、1 通のメッセージには 1 枚の画像のみを対応します。 |
| **フォームコンテンツ** | 対応（タイトルと変数値） | メッセージ本文のフォームです。最大 6 項目まで表示されます。左右の入力ボックスは、それぞれメッセージ本文の key と、その key に対応する value を表します。 |
| **モバイルリンク** | 対応 | メッセージをクリックしたときにリダイレクトするリンクアドレスです。メッセージがミニプログラムとして送信される場合、ミニプログラムのリダイレクトリンクをサポートします。 |
| **PC リンク** | 対応 | PC 上でメッセージをクリックしたときにリダイレクトするアドレスです。 |

## テンプレートパラメータの設定

メッセージコンテンツ内の一部の値は、注文番号、携帯電話番号、商品名など、動的に変化します。これらの値はテンプレート設定時には確定できないため、テンプレートパラメータを使用して置換できます。

業務通知を送信する際は、実際の値を渡してテンプレートパラメータを置換します。テンプレートパラメータは必須ではなく、実際のニーズに応じて設定できます。

**テンプレートパラメータの形式**

テンプレートパラメータは `${parameter name}` の形式を使用します。パラメータは以下のルールに従う必要があります。

- 文字またはアンダースコアで始まる必要があります。
- 先頭以降の部分は、文字、アンダースコア、数字で構成できます。
- 1 通のメッセージに動的パラメータを設定しすぎないことをお勧めします。5 個以内を推奨します。

例えば、メッセージコンテンツが次の場合：

```
The product ${product} you follow is now in stock. Hurry up and grab it!
```

ここで、`${product}` はテンプレートパラメータであり、パラメータ名は `product` です。メッセージ送信時にこのパラメータの値を渡します。例えば、メッセージ送信時に `product` に「使い捨てマスク」を渡します。すると「使い捨てマスク」が $&#123;product&#125; テンプレートパラメータを置換し、エンドユーザーが受信するメッセージコンテンツは次のようになります：

```
The product Disposable Mask you follow is now in stock. Hurry up and grab it!
```

メッセージテンプレートには、複数のテンプレートパラメータを設定することも、まったく設定しないこともできます。実際のニーズに応じて設定してください。

**ID 変換**

動的パラメータを渡す際、ID 変換がサポートされます。現在、部門 ID を部門名に、userId をユーザー名に変換することがサポートされています。

ID 変換の構文は次のとおりです：

```
$departmentName=DEPARTMENT_ID$
$userName=USERID$
```

各項目の意味：

- DEPARTMENT_ID は数値の部門 ID です。
- USERID はユーザーの user ID です。

例：

- $departmentName=100$ を、部門 ID「100」に対応する部門名（例：「DingTalk Open Platform」）に置換します。
- $userName=zhangsan01$ を、ユーザー ID「zhangsan01」に対応するユーザー名（例：「John」）に置換します。

## 審査の申請

メッセージテンプレートを作成した後、**送信**をクリックしてテンプレートを審査に提出します。

## テンプレートの有効化

テンプレートが審査に合格すると、自動的に有効になります。メッセージテンプレートが有効になると、API を呼び出してテンプレートメッセージを送信できます。詳細については、[テンプレートを使用して業務通知を送信する](/zh/open/development/work-notification-templating-send-notification-interface)を参照してください。

## テンプレートの無効化

テンプレートが不要になった場合は、有効化ボタンをオフにして使用を停止します。

## テンプレートの削除

**削除**をクリックしてテンプレートを削除します。

## テンプレートの複製

**複製**をクリックすると、同じ設定のテンプレートをコピーします。

## テンプレートのテスト

**編集**をクリックしてテンプレート編集画面に入り、テンプレート編集ページで**テスト**ボタンをクリックしてテストを実行します。テストでは、自分自身に業務通知を送信します。
