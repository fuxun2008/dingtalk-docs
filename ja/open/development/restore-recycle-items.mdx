---
title: "ゴミ箱項目を復元"
---

本インターフェースを呼び出して、ゴミ箱項目を元の位置に復元します。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | `https://api.dingtalk.io/v1.0/storage/recycleBins/{recycleBinId}/recycleItems/{recycleItemId}/restore` |
| HTTP Method | POST |
| サポートするアプリタイプ | appType-社内アプリ　appType-サードパーティ社内アプリ |
| 必要な権限 | permission-Storage.RecycleBin.Write-企業ストレージゴミ箱書き込み権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | はい | 本インターフェースを呼び出すためのアクセス認証情報です。以下の方法で取得します：   - 社内アプリの場合は、[社内アプリの access_token を取得](/ja/open/development/obtain-the-access-token-of-an-internal-app#)インターフェースを呼び出して取得します。 - サードパーティ社内アプリの場合は、[サードパーティアプリで権限付与された企業の access_token を取得](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#)インターフェースを呼び出して取得します。 |

### パスパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| recycleBinId | String | はい | ゴミ箱 ID。[ゴミ箱情報を取得](/ja/open/development/obtain-information-about-the-recycle-bin#)インターフェースを呼び出して取得できます。 |
| recycleItemId | String | はい | ゴミ箱項目 ID。[ゴミ箱項目リストを取得](/ja/open/development/gets-the-list-of-recycle-items#)インターフェースを呼び出して id パラメータ値を取得できます。 |

### クエリパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| unionId | String | はい | 操作者の unionId。[ユーザー詳細を照会](/ja/open/development/query-user-details#)インターフェースを呼び出して取得できます。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| option | Object | いいえ | オプションパラメータ。 |
| conflictStrategy | String | いいえ | ファイル名の競合戦略。復元時に元のパスに同名のファイルが既に存在する可能性があります。   - **AUTO_RENAME**：自動的に名前を変更（デフォルト） - **OVERWRITE**：上書き - **RETURN_DENTRY_IF_EXISTS**：既存ファイルを返す - **RETURN_ERROR_IF_EXISTS**：ファイルが既に存在する場合はエラーを返す |
