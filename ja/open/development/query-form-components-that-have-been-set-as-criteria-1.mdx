条件に設定されたフォームコンポーネントを照会します。

## API 呼び出し説明

ソリューションプロバイダーが承認テンプレート作成 API で組織向けの承認テンプレートを作成すると、組織は承認の管理コンソールで承認フローを設定できるようになります。この設定の際、フォームコンポーネントをフローの条件として設定できます。ISV は、フローの条件に設定されたフォームコンポーネントを更新できません。この API を呼び出して、フローの条件に設定されているフォームコンポーネントを照会してください。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/v1.0/workflow/processes/conditions/components |
| HTTP メソッド | GET |
| サポートされるアプリタイプ | appType-サードパーティ社内アプリ |
| 必須の権限 | permission-Workflow.Form.Read-作業フローテンプレートの読み取り権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | はい | この API を呼び出すためのアクセス認証情報です。サードパーティアプリに権限付与した組織のアクセストークンを取得する API を呼び出して取得します。 |

### クエリパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| processCode | String | はい | 承認フローの固有コードです。[承認フォームテンプレートの作成または更新](/ja/open/development/create-an-approval-form-template) API を呼び出すか、[OA承認の概要 - 用語集](/ja/open/development/workflow-overview)から取得します。 |
| agentId | Long | いいえ | アプリの agentId です。   - 内部アプリの場合は、[開発者コンソール](https://open-dev.dingtalk.io/#/)のアプリ詳細ページで取得します。 - サードパーティ社内アプリの場合は、組織の権限付与情報を取得する API を呼び出して取得します。 |

### リクエスト例

HTTP

```http
GET /v1.0/workflow/processes/conditions/components?processCode=PROC-xxx&agentId=10 HTTP/1.1
Host:api.dingtalk.io
x-acs-dingtalk-access-token:6d1bxxxx
Content-Type:application/json
```
