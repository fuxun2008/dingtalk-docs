---

この API を呼び出して、勤怠シフトの打刻時間帯の設定を更新します。現在、この API で指定できるのは、打刻ポイントで打刻が必要かどうかのみです。

## リクエスト

| **基本情報** | |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/topapi/attendance/shift/updatepunches |
| HTTP メソッド | POST |
| 対応するアプリタイプ | appType-社内アプリ |
| 必要な権限 | permission-qyapi_attendance_group_manage-勤怠グループ管理権限 |

### クエリパラメータ

| 名前 | タイプ | 必須 | 例 | 説明 |
| --- | --- | --- | --- | --- |
| access_token | 文字列 | はい | af21axxx | この API を呼び出すためのアプリ認証情報です。[社内アプリの access_token を取得](/ja/open/development/obtain-orgapp-token) API を呼び出して取得してください。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 例 | 説明 |
| --- | --- | --- | --- | --- |
| op_user_id | 文字列 | はい | user456 | 操作者の userId です。 |
| punches | TopPunchVO[] | いいえ |  | 打刻ポイントの情報です。 |
| id | 数値 | はい | 123 | 打刻ポイントの ID です。[シフト詳細の取得](/ja/open/development/shift-query) API を呼び出して id の値を取得してください。 |
| free_check | 真偽値 | はい | true | 打刻を不要にするかどうかを指定します。   - **true**：打刻免除をオンにします。 - **false**：打刻免除をオフにします。 |
| shift_id | 数値 | はい | 456 | シフト ID です。[シフト概要の取得](/ja/open/development/enterprise-shift-query-in-batches) API を呼び出して id の値を取得してください。 |

### リクエスト例

```curl
curl -X POST "https://api.dingtalk.io/topapi/attendance/shift/updatepunches" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=16869xxx0e890' \
-d 'op_user_id=dd' \
-d 'punches=null' \
-d 'shift_id=456'
```

Java

```java
DingTalkClient client = new DefaultDingTalkClient("https://api.dingtalk.io/topapi/attendance/shift/updatepunches");
OapiAttendanceShiftUpdatepunchesRequest req = new OapiAttendanceShiftUpdatepunchesRequest();
List<TopPunchVO> punchVOS = new ArrayList<>();
TopPunchVO punchVO = new TopPunchVO();
punchVO.setFreeCheck(true);
punchVO.setId(373271823L);
req.setPunches(punchVOS);
req.setOpUserId("user456");
req.setShiftId(712550377L);
OapiAttendanceShiftUpdatepunchesResponse rsp = client.execute(req, access_token);
System.out.println(rsp.getBody());
```

## レスポンス

### レスポンスボディ

| 名前 | タイプ | 例 | 説明 |
| --- | --- | --- | --- |
| success | 真偽値 | true | 呼び出しに成功したかどうかを示します。   - **true**：成功 - **false**：失敗 |
| errcode | 数値 | 0 | リターンコードです。 |
| errmsg | 文字列 | システムエラー | 呼び出しに失敗した場合に返されるエラーメッセージです。 |
| request_id | 文字列 | 5moh5icna65x | リクエスト ID です。 |

### レスポンスボディの例

```json
{
  "errcode": 0,
  "success": true,
  "request_id": "ed67bcymo0bw"
}
```

### エラーコード

この API の呼び出し時にエラーが発生した場合は、エラーメッセージをもとに[グローバルエラーコード](/ja/open/development/server-api-error-codes-1)ドキュメントで解決方法を確認してください。
