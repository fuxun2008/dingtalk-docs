---
title: "アクセス制御リストの取得"
---

本インターフェースを呼び出して、カレンダーのアクセス制御リスト（ユーザー ID、権限情報など）を取得します。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | `https://api.dingtalk.io/v1.0/calendar/users/{userId}/calendars/{calendarId}/acls` |
| HTTP Method | GET |
| サポートされるアプリタイプ | appType-社内アプリ　appType-サードパーティ個人アプリ |
| 権限要件 | permission-Calendar.Acl.Read-カレンダーアプリのアクセス制御読み取り権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | はい | 本インターフェースを呼び出すためのアクセス認証情報。以下の方法で取得します：   - 社内アプリの場合、[社内アプリの access_token を取得する](https://open.dingtalk.io/document/development/obtain-the-access-token-of-an-internal-app#)インターフェースを呼び出して取得します。 - サードパーティ個人アプリの場合、[ユーザートークンを取得する](https://open.dingtalk.io/document/development/obtain-user-token#)インターフェースを呼び出して取得します。 |

### パスパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| userId | String | はい | 予定主催者の unionId。   - 社内アプリの場合、[ユーザー詳細の照会](https://open.dingtalk.io/document/development/query-user-details#)インターフェースを呼び出して unionid パラメータ値を取得します。 - サードパーティ個人アプリの場合、[ユーザーの連絡先プロフィールを取得する](https://open.dingtalk.io/document/development/dingtalk-retrieve-user-information#)インターフェースを通じて unionId パラメータ値を取得します。 |
| calendarId | String | はい | 予定が属するカレンダー ID。一律 primary で、ユーザーのメインカレンダーを表します。 |

## レスポンス

### レスポンスボディ

| 名前 | タイプ | 説明 |
| --- | --- | --- |
| acls | Array | アクセス制御リスト。 |
| privilege | String | 権限情報。取り得る値：   - **free_busy_reader**：空き状況を確認 - **title_reader**：見出しを確認 - **reader**：詳細を見る - **writer**：作成および編集 |
| aclId | String | 権限リソース ID。 |
| scope | Object | 権限スコープ。 |
| userId | String | ユーザー ID。      **scopeType** の値が **user** の場合、ユーザーの **unionId** の値となります。 |
| scopeType | String | 権限タイプ。現在は **user**（ユーザーを表す）のみサポートします。 |
