---
title: "ファイルまたはフォルダー情報の取得"
---

このAPIを呼び出して、ストレージスペース内にフォルダーまたはファイルを追加した際の関連情報を取得します。

## API 呼び出し説明

ファイルおよびフォルダー情報を取得する際、フォルダータイプの場合はファイルサイズおよびファイル拡張子は取得されません。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | `https://api.dingtalk.io/v1.0/storage/spaces/{spaceId}/dentries/{dentryId}/query` |
| HTTP Method | POST |
| サポートされるアプリタイプ | appType-社内アプリ　appType-サードパーティ社内アプリ |
| 必要な権限 | permission-Storage.File.Read-企業ストレージファイル読み取り権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | 必須 | 当該APIを呼び出すためのアクセス認証情報です。以下の方法で取得します。   - 社内アプリの場合、[社内アプリのaccessTokenを取得](https://open.dingtalk.io/document/development/obtain-the-access-token-of-an-internal-app)APIを呼び出して取得します。 - サードパーティ社内アプリの場合、[サードパーティアプリが認可された企業のaccessTokenを取得](https://open.dingtalk.io/document/development/obtain-the-access-token-of-the-authorized-enterprise-1)APIを呼び出して取得します。 |

### パスパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| spaceId | String | 必須 | スペースIDです。[スペースの追加](https://open.dingtalk.io/document/development/add-space)APIを呼び出してidパラメータ値を取得できます。 |
| dentryId | String | 必須 | ファイルまたはフォルダーIDです。[ファイルまたはフォルダーリストの取得](https://open.dingtalk.io/document/development/get-a-list-of-files-or-folders)または[dentryUuidに基づいてspaceIdとdentryIdを取得](https://open.dingtalk.io/document/development/api-getdentryidbyuuid)APIを呼び出してidパラメータ値を取得できます。 |

### クエリパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| unionId | String | 必須 | 操作者のunionIdです。[ユーザー詳細の照会](https://open.dingtalk.io/document/development/query-user-details)APIを呼び出してunionidパラメータ値を取得できます。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| option | Object | 任意 | オプションパラメータです。 |
| appIdsForAppProperties | Array of String | 任意 | 指定したスペースownerIdリストに基づき、対応する可視属性を返します。最大20個まで。   - ownerTypeがAPPの場合、ownerIdはアプリ識別子です。 - ownerTypeがUSERの場合、ownerIdは作成者のunionIdです。 |
| withThumbnail | Boolean | 任意 | ファイルサムネイルの一時リンクを取得するかどうか。必要に応じて取得してください。API呼び出しの所要時間に影響します。   - **true**：取得する - **false**（デフォルト）：取得しない |
