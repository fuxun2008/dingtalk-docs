デバイスの属性を照会します。

## API 呼び出し説明

本 API を呼び出す前に、[イベントサブスクリプション](https://open.dingtalk.io/document/development/event-subscription-overview#)を導入し、[デバイスと会議室バインディングの変更](https://open.dingtalk.io/document/development/org-event-overview#)イベントを購読する必要があります。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/v1.0/rooms/devices/properties/query |
| HTTP Method | POST |
| 対応アプリタイプ | appType-社内アプリ |
| 必要な権限 | permission-VideoConference.Conference.Read-ビデオ会議情報の読み取り権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | 必須 | この API を呼び出すためのアクセス認証情報です。[社内アプリのアクセストークンを取得](https://open.dingtalk.io/document/development/obtain-the-access-token-of-an-internal-app#) API を呼び出して取得します。 |

### クエリパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| operatorUnionId | String | 必須 | 照会操作を行うメンバーの unionId です。[ユーザー詳細を照会](https://open.dingtalk.io/document/development/query-user-details#) API を呼び出して取得します。 |
| deviceId | String | 任意 | 照会対象のデバイス ID です。[デバイスと会議室バインディングの変更](https://open.dingtalk.io/document/development/org-event-overview#)イベントの購読により取得します。 |
| deviceUnionId | String | 任意 | 照会対象のデバイス unionId です。[デバイスと会議室バインディングの変更](https://open.dingtalk.io/document/development/org-event-overview#)イベントの購読により取得します。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| propertyNames | Array of String | 任意 | デバイス属性名のリスト。最大 10 件。   - dev_code：画面ミラーリングコード - dev_model：デバイス機種 - dev_app_status：デバイスステータス - dev_net_ip：デバイス IP - dev_net_type：デバイスネットワークタイプ - dev_wifi_mac：デバイスの無線 MAC アドレス - dev_wire_mac：デバイスの有線 MAC アドレス - dev_firmware_v：デバイスファームウェアバージョン - dev_software_v：デバイスソフトウェアバージョン - dev_hdmi：デバイス外付けディスプレイ |
