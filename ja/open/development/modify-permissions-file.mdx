title: "権限の変更"
---

本インターフェースを呼び出し、指定された id（ファイル uuid、ナレッジベース rootNodeId、ナレッジベースノード nodeId）、操作者 unionId および権限ロール id などの情報に基づいて、権限ユーザーのファイル権限を更新します。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | `https://api.dingtalk.io/v2.0/storage/spaces/dentries/{dentryUuid}/permissions` |
| HTTP Method | PUT |
| 対応アプリタイプ | appType-社内アプリ |
| 必要な権限 | permission-Storage.Permission.Write-企業ストレージ権限付与情報の書き込み権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | はい | 本インターフェースを呼び出すためのアクセス認証情報です。[社内アプリの access_token を取得](/ja/open/development/obtain-the-access-token-of-an-internal-app)インターフェースを呼び出して取得できます。 |

### パスパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| dentryUuid | String | はい | ファイル uuid。[ファイル検索](/ja/open/development/search-for-files)インターフェースまたは [dentryUuid 情報の取得](/ja/open/development/api-getuuidbydentryid)インターフェースを呼び出して、レスポンスパラメータの dentryUuid フィールドを取得できます。 |

### クエリパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| unionId | String | はい | ユーザー unionId。[ユーザー詳細の照会](/ja/open/development/query-user-details)インターフェースを呼び出して取得できます。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| roleId | String | はい | ロール id。列挙値：   - **OWNER**：所有者。以下の権限スコープを保持します。    - PermissionPrivilegeEnum.INFO   - PermissionPrivilegeEnum.LIST   - PermissionPrivilegeEnum.PREVIEW   - PermissionPrivilegeEnum.READ   - PermissionPrivilegeEnum.WRITE   - PermissionPrivilegeEnum.DOWNLOAD   - PermissionPrivilegeEnum.ADD   - PermissionPrivilegeEnum.DELETE   - PermissionPrivilegeEnum.MODIFY   - PermissionPrivilegeEnum.COPY   - PermissionPrivilegeEnum.RENAME   - PermissionPrivilegeEnum.READ_PERMISSION   - PermissionPrivilegeEnum.WRITE_PERMISSION   - PermissionPrivilegeEnum.ASSIGN - **MANAGER**：管理者。以下の権限スコープを保持します。    - PermissionPrivilegeEnum.INFO   - PermissionPrivilegeEnum.LIST   - PermissionPrivilegeEnum.PREVIEW   - PermissionPrivilegeEnum.READ   - PermissionPrivilegeEnum.WRITE   - PermissionPrivilegeEnum.DOWNLOAD   - PermissionPrivilegeEnum.ADD   - PermissionPrivilegeEnum.DELETE   - PermissionPrivilegeEnum.MODIFY   - PermissionPrivilegeEnum.COPY   - PermissionPrivilegeEnum.RENAME   - PermissionPrivilegeEnum.READ_PERMISSION   - PermissionPrivilegeEnum.WRITE_PERMISSION - **EDITOR**：編集者。以下の権限スコープを保持します。    - PermissionPrivilegeEnum.INFO   - PermissionPrivilegeEnum.LIST   - PermissionPrivilegeEnum.PREVIEW   - PermissionPrivilegeEnum.READ   - PermissionPrivilegeEnum.WRITE   - PermissionPrivilegeEnum.DOWNLOAD   - PermissionPrivilegeEnum.ADD - **DOWNLOADER**：閲覧・ダウンロード可能ユーザー。以下の権限スコープを保持します。    - PermissionPrivilegeEnum.INFO   - PermissionPrivilegeEnum.LIST   - PermissionPrivilegeEnum.PREVIEW   - PermissionPrivilegeEnum.READ   - PermissionPrivilegeEnum.DOWNLOAD - **READER**：閲覧のみ可能ユーザー。以下の権限スコープを保持します。    - PermissionPrivilegeEnum.INFO   - PermissionPrivilegeEnum.LIST   - PermissionPrivilegeEnum.PREVIEW |
| members | Array | はい | 権限ユーザーリスト。最大サイズは 30 です。 |
| type | String | はい | 権限ユーザータイプ。列挙値：   - **ORG**：企業 - **DEPT**：部門 - **TAG**：カスタム tag - **CONVERSATION**：チャット - **USER**：ユーザー |
| id | String | はい | 権限ユーザー id：   - `type=ORG` の場合、id は企業 id - `type=DEPT` の場合、id は部門 id - `type=TAG` の場合、id はタグ id - `type=CONVERSATION` の場合、id はチャット id - `type=USER` の場合、id は社員 id |
| corpId | String | いいえ | 権限が帰属する企業：       - 企業 id が存在する場合、対応する member が退職した際に権限が自動的にクリアされます。 - memberType が dept タイプの場合、企業 id が必須です。 |
| option | Object | いいえ | オプションパラメータ。 |
| duration | Long | いいえ | 有効時間（秒）。       - 現在、OwnerType が APP の Space のみ一時権限をサポートしています。 - 最大値は 3600 です。 |
