---
title: "ブロック要素を挿入する"
---

このAPIを呼び出すと、指定した位置にブロック要素を1つ挿入できます。

## API 呼び出し説明

ドキュメントのコンテンツに関するデータ構造の詳細については、[ドキュメントデータ構造](/ja/open/development/document-data-structure)をご参照ください。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | `https://api.dingtalk.io/v1.0/doc/suites/documents/{docKey}/blocks` |
| HTTP Method | POST |
| サポートするアプリタイプ | appType-社内アプリ |
| 必要な権限 | permission-Storage.File.Write-企業ストレージファイル書き込み権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | はい | このAPIを呼び出すためのアクセス認証情報です。[社内アプリのアクセストークンを取得する](/ja/open/development/obtain-the-access-token-of-an-internal-app)APIを呼び出して取得します。 |

### パスパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| docKey | String | はい | ドキュメントID（ドキュメントの docKey または dentryUuid）です。[ナレッジベースドキュメントを作成する](/ja/open/development/create-team-space-document)APIでドキュメントを作成した後、レスポンスから `docKey` パラメータを取得します。      `dentryUuid` はドキュメントURLから取得します。例えば https://alidocs.dingtalk.io/i/nodes/Zxxxxa-id の場合、dentryUuid は Zxxxxa-id です。 |

### クエリパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| operatorId | String | はい | ユーザーのunionIdです。[ユーザー詳細を照会する](/ja/open/development/query-user-details)APIを呼び出して unionid パラメータの値を取得できます。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| blockId | String | いいえ | 対象 Block の一意な識別子です。[ブロック要素を照会する](/ja/open/development/api-docblocksquery)APIを呼び出して `blockId` パラメータを取得できます。未入力の場合は index が使用されます。 |
| index | Integer | いいえ | `blockId` が存在しない場合、`index` を使用してドキュメントの `index` 番目のトップレベルブロック要素を対象位置として検索します。`index` は 0 から始まります。      未入力の場合、デフォルトでドキュメントの末尾になります。 |
| where | String | いいえ | 対象位置の前後どちらに挿入するかを指定します。値:   - **after**: 対象位置の後ろに挿入します（デフォルト値）。 - **before**: 対象位置の前に挿入します。 |
| element | `Map<String, Any>` | はい | 挿入する BlockElement のタイプと、対応するタイプを作成するために必要な属性です（詳細は[ブロック要素データ構造](/ja/open/development/block-data-structure)をご参照ください）。構造は次のとおりです:   ``` {   "blockType": enum(BlockType),   [blockType]: Object(CreateElementProperties), } ``` |
|  | Any | いいえ | 要素タイプおよびその要素を作成するために必要な情報を含みます。 |

### リクエスト例

HTTP

```http
POST /v1.0/doc/suites/documents/doc_id/blocks?operatorId=union_id HTTP/1.1
Host:api.dingtalk.io
x-acs-dingtalk-access-token:7dc9ec4xxx
Content-Type:application/json

{
  "blockId" : "block_id",
  "index" : 1,
  "where" : "after",
  "element" : {
    "blockType" : "paragraph",
    "paragraph" : {
      "text" : "foo"
    }
  }
}
```
