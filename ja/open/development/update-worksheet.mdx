---
title: "ワークシートを更新する"
---

このインターフェースを呼び出すことで、DingTalk スプレッドシート内の指定されたワークシートのメタ属性（ワークシート名、表示・非表示状態、固定行列数など）を変更できます。プログラムからワークシート設定を管理するシナリオに適しており、1 回のリクエストで複数の属性を同時に更新できます。更新後、ワークシートの id を返します。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | `https://api.dingtalk.io/v1.0/doc/workbooks/{workbookId}/sheets/{sheetId}` |
| HTTP Method | PUT |
| 対応アプリタイプ | appType-社内アプリ |
| 必要な権限 | permission-Document.Workbook.Write-DingTalk スプレッドシートの書き込み権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | 必須 | このインターフェースを呼び出すためのアクセス認証情報です。[社内アプリの access_token を取得する](/ja/open/development/obtain-the-access-token-of-an-internal-app)インターフェースを呼び出して取得できます。 |

### パスパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| workbookId | String | 必須 | スプレッドシートファイルの ID です。[ナレッジベース API](/ja/open/development/knowledge-base-overview) で返される `nodeId(dentryUuid)` がスプレッドシートの `workbookId` です。[ノードを取得する](https://open.dingtalk.com/document/development/get-node)および[ナレッジベースドキュメントを作成する](/ja/open/development/create-team-space-document)インターフェースを呼び出して取得できます。 |
| sheetId | String | 必須 | ワークシートの ID または見出しです。[すべてのワークシートを取得する](/ja/open/development/obtain-all-worksheets)インターフェースを呼び出して、id とワークシートの見出しを取得できます。 |

### クエリパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| operatorId | String | 必須 | 操作者の unionId です。[ユーザー詳細を取得する](/ja/open/development/query-user-details)インターフェースを呼び出して取得できます。操作者に権限がない場合、インターフェースは `The operator has no permission` エラーを返します。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| frozenRowCount | Long | 任意 | 固定する行のインデックスです。1 から始まり、0 は固定しないことを表します。3 を指定した場合、1 行目から 3 行目までを固定します。 |
| frozenColumnCount | Long | 任意 | 固定する列のインデックスです。1 から始まり、0 は固定しないことを表します。3 を指定した場合、1 列目から 3 列目までを固定します。 |
| visibility | String | 任意 | ワークシートを非表示にするかどうかを指定します。指定可能な値：   - **visible**：表示 - **hidden**：非表示 |
| name | String | 任意 | 新しいワークシート名です。 |

### リクエスト例

HTTP

```http
PUT /v1.0/doc/workbooks/e54Lq3xxx/sheets/Sheet1?operatorId=ppgAxxx HTTP/1.1
Host:api.dingtalk.io
x-acs-dingtalk-access-token:f86e0bxxx
Content-Type:application/json

{
  "frozenRowCount" : 1,
  "frozenColumnCount" : 1,
  "visibility" : "hidden",
  "name" : "Sheet2"
}
```
