---
title: "ファイルまたはフォルダーをコピー"
---

このAPIを呼び出すと、ファイルまたはフォルダーを他のスペースまたはディレクトリにコピーできます。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | `https://api.dingtalk.io/v1.0/storage/spaces/{spaceId}/dentries/{dentryId}/copy` |
| HTTP Method | POST |
| サポートされるアプリタイプ | appType-社内アプリ　appType-サードパーティ社内アプリ |
| 権限要件 | permission-Storage.File.Write-企業ストレージファイル書き込み権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | はい | このAPIを呼び出すためのアクセス認証情報。以下の方法で取得します：   - 社内アプリの場合は、[社内アプリのaccessTokenを取得](/ja/open/development/obtain-the-access-token-of-an-internal-app)APIを呼び出して取得します。 - サードパーティ社内アプリの場合は、[サードパーティアプリが権限付与された企業のaccessTokenを取得](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1)APIを呼び出して取得します。 |

### パスパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| spaceId | String | はい | ファイルまたはフォルダーが存在するソーススペースID。[スペースを追加](/ja/open/development/add-space)APIを呼び出してidパラメータの値を取得できます。 |
| dentryId | String | はい | コピー対象のファイルまたはフォルダーのID。[ファイルまたはフォルダーのリストを取得](/ja/open/development/get-a-list-of-files-or-folders)または[dentryUuidからspaceIdとdentryIdを取得](/ja/open/development/api-getdentryidbyuuid)APIを呼び出してidパラメータの値を取得できます。 |

### クエリパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| unionId | String | はい | 操作者のunionId。[ユーザー詳細を取得](/ja/open/development/query-user-details)APIを呼び出してunionidパラメータの値を取得できます。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| targetSpaceId | String | はい | 保存先のターゲットスペースID。[スペースを追加](/ja/open/development/add-space)APIを呼び出してidパラメータの値を取得できます。 |
| targetFolderId | String | はい | 保存先の親ディレクトリID。[ファイルまたはフォルダーのリストを取得](/ja/open/development/get-a-list-of-files-or-folders)APIを呼び出してidパラメータの値を取得できます。 |
| option | Object | いいえ | オプションパラメータ。 |
| conflictStrategy | String | いいえ | ファイルおよびフォルダーの名前競合戦略：   - **AUTO_RENAME**（デフォルト）：自動で名前を変更 - **OVERWRITE**：上書き - **RETURN_DENTRY_IF_EXISTS**：既存ファイルを返す - **RETURN_ERROR_IF_EXISTS**：ファイルが既に存在する場合はエラーを返す |
