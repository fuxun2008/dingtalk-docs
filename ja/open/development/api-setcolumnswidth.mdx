---
title: "列幅の一括設定"
description: "複数列の幅をピクセル単位で一括設定し、表示や印刷レイアウトを最適化します"
---

本インターフェースを呼び出すことで、スプレッドシート内の指定した列から連続する複数列の幅（単位：ピクセル）を一度に設定できます。コンテンツ表示や印刷レイアウトに合わせて列幅を一括調整するシーンに適しており、幅の値は自動的に正の整数に丸められます。インターフェースは操作後のワークシート情報を返します。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | `https://api.dingtalk.io/v1.0/doc/workbooks/{workbookId}/sheets/{sheetId}/setColumnsWidth` |
| HTTP Method | POST |
| サポートするアプリタイプ | appType-社内アプリ |
| 権限要件 | permission-Document.Workbook.Write-スプレッドシート書き込み権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | はい | 本インターフェースを呼び出すためのアクセス認証情報です。[社内アプリのaccessTokenを取得](/ja/open/development/obtain-the-access-token-of-an-internal-app)インターフェースを呼び出して取得できます。 |

### パスパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| workbookId | String | はい | スプレッドシートファイル ID 。[ナレッジベース API](/ja/open/development/knowledge-base-overview) が返す `nodeId(dentryUuid)` がスプレッドシートの `workbookId` に該当します。[ノードを取得](https://open.dingtalk.com/document/development/get-node)および[ナレッジベースドキュメントの作成](/ja/open/development/create-team-space-document)インターフェースを呼び出して取得できます。 |
| sheetId | String | はい | ワークシートIDまたは見出し。[全ワークシートの取得](/ja/open/development/obtain-all-worksheets)インターフェースを呼び出して、idとワークシートの見出しを取得できます。 |

### クエリパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| operatorId | String | はい | 操作者のunionIdです。[ユーザー詳細の照会](/ja/open/development/query-user-details)インターフェースを呼び出して取得できます。操作者に権限がない場合、インターフェースは `The operator has no permission` というエラーを返します。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| column | Integer | はい | 列幅を変更する最初の列のカーソル。0から始まります。 |
| width | Integer | はい | 幅。単位：ピクセル。 |
| columnCount | Integer | はい | 列幅を変更する連続列数。 |

### リクエスト例
