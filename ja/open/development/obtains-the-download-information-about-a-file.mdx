本 API を呼び出して、ストレージスペース内ファイルのダウンロード情報を取得します。

## API 呼び出し説明

ステップ 1：本 API を呼び出し、ファイルダウンロードの情報を取得して、ダウンロード URL と headers を取得します。

ステップ 2：ダウンロードを実行します。サンプルは以下を参照してください：

```java
public static void main(String[] args) {
        String url = ""; // ダウンロード情報取得APIから取得したinternalResourceUrls。
        String path = "/Users/xxxxx/Downloads/test.txt"; // ファイルをダウンロードする対象パス。
        // ダウンロード情報取得APIから取得したheaders情報。
        Map<String, String> headers = "" //ダウンロード情報取得APIから取得したheaders。
        OkHttpClient client = new OkHttpClient();
        Request request = new Request.Builder()
                .url(url)
                .headers(Headers.of(headers))
                .build();
        client.newCall(request).enqueue(new Callback() {
            @Override
            public void onFailure(Call call, IOException e) {
            }

            @Override
            public void onResponse(Call call, Response response) throws IOException {
                Sink sink = null;
                BufferedSink bufferedSink = null;
                try {
                    File dest = new File(path);
                    sink = Okio.sink(dest);
                    bufferedSink = Okio.buffer(sink);
                    bufferedSink.writeAll(response.body().source());
                } catch (Exception e) {
                    e.printStackTrace();
                } finally {
                    if (bufferedSink != null) {
                        bufferedSink.close();
                    }
                    if (sink != null) {
                        sink.close();
                    }
                }
            }
        });
    }
```

<Note>
ファイルサイズが大きい場合、リソースを分割して取得する必要があります。上記サンプルに headers フィールドを追加できます：`headers.put("Range","bytes=0-499");`。詳細は [Range を指定して部分コンテンツをダウンロード](/ja/open/development/use-range-download-a-part-of-content) を参照してください。
</Note>

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | `https://api.dingtalk.io/v1.0/storage/spaces/{spaceId}/dentries/{dentryId}/downloadInfos/query` |
| HTTP Method | POST |
| サポートするアプリタイプ | appType-社内アプリ |
| 権限要件 | permission-Storage.DownloadInfo.Read-企業ストレージファイルダウンロード情報の読み取り権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | はい | 本 API を呼び出すためのアクセス認証情報。[社内アプリのアクセストークンを取得](/ja/open/development/obtain-the-access-token-of-an-internal-app#) API を呼び出して取得します。 |

### パスパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| spaceId | String | はい | スペース ID。[スペースを追加](/ja/open/development/add-space#) API を呼び出して id パラメータ値を取得します。 |
| dentryId | String | はい | ファイル ID。[ファイルまたはフォルダーリストを取得](/ja/open/development/get-a-list-of-files-or-folders#) または [dentryUuid に基づいて spaceId を取得](/ja/open/development/api-getdentryidbyuuid#) API を呼び出して id パラメータ値を取得します。 |

### クエリパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| unionId | String | はい | 操作者の unionId。[ユーザー詳細を照会](/ja/open/development/query-user-details#) API を呼び出して取得します。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| option | Object | いいえ | オプションパラメータ。 |
| version | Long | いいえ | ファイルのバージョン番号。[ファイルバージョンリストを取得](/ja/open/development/obtains-a-list-of-file-versions#) API を呼び出して version を取得します。 |
| preferIntranet | Boolean | いいえ | 内部ネットワーク転送を優先的に使用するかどうか。本パラメータを使用する前提として、専用ストレージ内部ネットワーク転送が設定されている必要があります。   - true：はい、デフォルト - false：いいえ |
