この API を呼び出して、権限スコープ内の関連部門の承認インスタンス ID リストを取得します。

## API 呼び出し説明

### 重要な注意事項

[OA プレミアム](dingtalk://dingtalkclient/page/link?url=https%3A%2F%2Fpage.dingtalk.io%2Fwow%2Fdingtalk%2Fdefault%2Fdingtalk%2FlnfR8GaRSWqNncZHSvLLx%3Fdd_mini_app_id%3D5000000004997171&web_wnd=general&width=480&height=800)をご利用のお客様は、この API で最大過去 5 年分のインスタンスデータを照会できます（startTime には現在時刻から 5 年以内の値を指定してください）。OA プレミアムにアップグレードすると、この機能が利用可能になります。より高度な開発ニーズへの対応、カスタム業務シナリオのサポート、すべての専用 OpenAPI へのアクセスも可能です。

### API 呼び出しフロー

1. この API を呼び出して、承認作業フローの承認インスタンス ID を取得します。
2. [単一の承認インスタンスの詳細を取得](/ja/open/development/obtains-the-details-of-a-single-approval-instance-pop) API を呼び出して、各承認インスタンスの詳細を取得します。

### 使用上の注意

- **startTime** のみを指定する場合、現在時刻から 120 日以内の値を指定してください。**endTime** を省略した場合、デフォルトで現在時刻が使用されます。
- **startTime** と **endTime** の両方を指定する場合、期間は 120 日以内とし、**startTime** には現在時刻から 365 日以内の値を指定してください。
- 繰り返し呼び出しによって分割取得するインスタンス ID の合計数は、10,000 件以内に制限されます。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/v1.0/workflow/processes/instanceIds/query |
| HTTP メソッド | POST |
| 対応するアプリタイプ | appType-社内アプリ |
| 必要な権限 | permission-Workflow.Instance.Read-ワークフローインスタンスの読み取り権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | はい | この API を呼び出すためのアクセス認証情報です。[社内アプリのアクセストークンを取得](/ja/open/development/obtain-the-access-token-of-an-internal-app) API を呼び出して取得します。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| processCode | String | はい | 承認作業フローの固有コードです。   - [承認フォームテンプレートの作成または更新](/ja/open/development/create-an-approval-form-template) API を呼び出して `processCode` の値を取得します。 - [用語集 - processCode](/ja/open/development/workflow-overview) を参照してください。 |
| startTime | Long | はい | 承認インスタンスの開始時刻です。ミリ秒単位の Unix タイムスタンプで指定します。    例：2020年4月10日から2020年4月14日までに提出された承認フォームを取得する場合は、2020年4月10日 00:00:00 のタイムスタンプである 1586448000000 を指定します。 |
| endTime | Long | いいえ | 承認インスタンスの終了時刻です。ミリ秒単位の Unix タイムスタンプで指定します。    例：2020年4月10日から2020年4月14日までに提出された承認フォームを取得する場合は、2020年4月14日 23:59:59 のタイムスタンプである 1586879999000 を指定します。 |
| nextToken | Long | はい | ページングカーソルです。   - 初回の呼び出しでは 0 を指定します。 - 2 回目以降の呼び出しでは、前回の呼び出しで返された nextToken を指定します。 |
| maxResults | Long | はい | 1 ページあたりの件数を指定するページングパラメータです。最大値：20。 |
| userIds | Array of String | いいえ | 申請者のユーザー ID リストです。リストの最大長：10。[部門のユーザー ID リストを取得](/ja/open/development/query-the-list-of-department-userids) API を呼び出して取得します。 |
| statuses | Array of String | いいえ | ワークフローインスタンスのステータスです。   - **RUNNING**：承認中 - **TERMINATED**：取り消し済み - **COMPLETED**：承認完了     省略した場合、すべてのステータスのインスタンス ID が返されます。 |
