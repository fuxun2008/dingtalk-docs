---
title: "会議室グループの作成"
---

本インターフェースを呼び出して、会議室グループを作成します。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/v1.0/rooms/groups |
| HTTP Method | POST |
| 対応アプリタイプ | appType-社内アプリ　appType-サードパーティ社内アプリ |
| 必要な権限 | permission-VideoConference.Conference.Write-ビデオ会議情報管理権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | はい | 本インターフェースを呼び出すためのアクセス認証情報。以下の方法で取得します：   - 社内アプリの場合は、[社内アプリの access_token を取得する](https://open.dingtalk.io/document/development/obtain-the-access-token-of-an-internal-app#)インターフェースを呼び出して取得します。 - サードパーティ社内アプリの場合は、[サードパーティアプリ権限付与企業の access_token を取得する](https://open.dingtalk.io/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#)インターフェースを呼び出して取得します。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| unionId | String | はい | 操作者の unionId。[ユーザー詳細の照会](https://open.dingtalk.io/document/development/query-user-details#)インターフェースを呼び出して取得できます。 |
| groupName | String | いいえ | グループ名。 |
| parentGroupId | Long | はい | 親グループ ID。0 を指定するとルートグループを表します。[会議室グループ分けリストの照会](https://open.dingtalk.io/document/development/query-meeting-rooms-groups#)インターフェースを呼び出して取得できます。 |
