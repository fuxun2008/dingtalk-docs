---
title: "ワークシートを取得"
description: "ワークシートの ID、名前、行数、列数などの属性情報を取得し、スプレッドシート構成を確認します"
---

本インターフェースを呼び出して、特定のワークシートの属性（ワークシート ID、ワークシート名、ワークシートの行数、ワークシートの列数など）を取得します。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | `https://api.dingtalk.io/v1.0/doc/workbooks/{workbookId}/sheets/{sheetId}` |
| HTTP Method | GET |
| サポートされるアプリタイプ | appType-社内アプリ |
| 権限要件 | permission-Document.Workbook.Read-スプレッドシート読み取り権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | はい | 本インターフェースを呼び出す際のアクセス認証情報。[社内アプリのアクセストークンを取得](/ja/open/development/obtain-the-access-token-of-an-internal-app#)インターフェースを呼び出して取得します。 |

### パスパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| workbookId | String | はい | スプレッドシートファイル ID。[ナレッジベース API](/ja/open/development/knowledge-base-overview#)が返す `nodeId(dentryUuid)` がスプレッドシートの `workbookId` です。[ノードを取得](https://open.dingtalk.com/document/development/get-node#)および[ナレッジベースドキュメントを作成](/ja/open/development/create-team-space-document#)インターフェースを呼び出して取得できます。 |
| sheetId | String | はい | ワークシート ID または名称。[すべてのワークシートを取得](/ja/open/development/obtain-all-worksheets#)インターフェースを呼び出して id または name パラメータ値を取得できます。 |

### クエリパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| operatorId | String | はい | 操作者の unionId。   - [サイレントログインコードでユーザー情報を取得](/ja/open/development/obtain-the-userid-of-a-user-by-using-the-log-free#)インターフェースで unionid パラメータ値を取得できます。 - [ユーザー詳細を照会](/ja/open/development/query-user-details#)インターフェースを呼び出して unionid パラメータ値を取得できます。     操作者に権限がない場合、インターフェースは `The operator has no permission` というエラーを返します。 |

```http
GET /v1.0/doc/workbooks/e54Lq3xxx/sheets/Sheet1?operatorId=ppgAxxx HTTP/1.1
Host:api.dingtalk.io
x-acs-dingtalk-access-token:xxxxx
Content-Type:application/json
```
