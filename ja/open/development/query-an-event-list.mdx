---
title: "予定リストの照会"
---

本 API を呼び出して、特定ユーザーの特定期間における予定リストを照会し、予定の見出し、開始日、開始時間、終了日、終了時間などの情報を取得します。

## API 呼び出し説明

- 繰り返し予定の場合、過去のすべての繰り返し予定インスタンスを返しますが、未来のものは返しません。例えば、1月1日から始まる毎日繰り返しの予定があり、照会時点が1月4日の場合、1月1日～1月4日の繰り返し予定インスタンスを返しますが、1月4日以降は返しません。
- 返された予定オブジェクトの recurrenceId が空かどうかによって、その予定が繰り返し予定のインスタンスであるかを判断できます。
- デフォルトでは削除済みの予定は返されません。返却が必要な場合は `showDeleted=true` を設定してください。返された予定が削除済みの場合、[単一予定の詳細を照会](/ja/open/development/query-details-about-an-event#) API を呼び出すと **instanceNotExist** エラーが返されます。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | `https://api.dingtalk.io/v1.0/calendar/users/{userId}/calendars/{calendarId}/events` |
| HTTP Method | GET |
| サポートされるアプリタイプ | appType-社内アプリ　appType-サードパーティ社内アプリ　appType-サードパーティ個人アプリ |
| 必要な権限 | permission-Calendar.Event.Read-カレンダーアプリにおける予定の読み取り権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | 必須 | 本 API を呼び出すためのアクセス認証情報。以下の方法で取得します：   - 社内アプリの場合、[社内アプリのアクセストークンを取得](/ja/open/development/obtain-the-access-token-of-an-internal-app#) API を呼び出して取得します。 - サードパーティ社内アプリの場合、[サードパーティアプリが認可された企業のアクセストークンを取得](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#) API を呼び出して取得します。 - サードパーティ個人アプリの場合、[ユーザートークンを取得](/ja/open/development/obtain-user-token#) API を呼び出して取得します。 |

### パスパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| userId | String | 必須 | 照会対象ユーザーの unionId。   - 社内アプリおよびサードパーティ社内アプリの場合、[ユーザー詳細の照会](/ja/open/development/query-user-details#) API を呼び出して unionid パラメータ値を取得します。 - サードパーティ個人アプリの場合、[ユーザー連絡先のプロフィールを取得](/ja/open/development/dingtalk-retrieve-user-information#) API を呼び出して unionId パラメータ値を取得します。 |
| calendarId | String | 必須 | 予定が所属するカレンダー ID。一律 primary を指定し、ユーザーのメインカレンダーを表します。 |

### クエリパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| timeMin | String | 任意 | 予定開始時間の最小値。ISO-8601 の date-time 形式。省略可能。      `timeMin` と `timeMax` の最大差は 1 年です。 |
| timeMax | String | 任意 | 予定開始時間の最大値。ISO-8601 の date-time 形式。省略可能。      `timeMin` と `timeMax` の最大差は 1 年です。 |
| showDeleted | Boolean | 任意 | 削除済みの予定を返すかどうか：   - **true**：返す - **false**（デフォルト）：返さない |
| maxResults | Integer | 任意 | 最大返却レコード数。最大値は 100、デフォルトは 100 です。 |
| maxAttendees | Integer | 任意 | 各予定の参加者照会件数。デフォルトは 100、最大は 100。 参加者が 100 人を超え、全参加者を取得する必要がある場合は、[予定参加者を取得](/ja/open/development/get-the-participants-of-a-schedule#) API を使用して取得してください。 |
| nextToken | String | 任意 | ページングカーソル。      1 回のリクエストですべての結果を返せない場合、ページング token が返されます。次回の照会時に当該 token を付与すると後続のデータが返され、ページング token が null になるまで継続することで全データを照会できます。 |
| syncToken | String | 任意 | 同期 token。増分データ同期のシナリオで使用します。1 つの照会条件で全データが返された後（データ量が多い場合はページングで返されるため、呼び出し側は nextToken を使用して連続的に照会し、すべてのページを照会して nextToken が null を返すまで続ける必要があります）、syncToken が返されます。次回この token を付与して照会すると、2 回の照会の間に発生した変更の増分データが返されます。      timeMax を指定した場合、syncToken は返されません。 |
| seriesMasterId | String | 任意 | 繰り返し予定のメイン予定 ID。非繰り返し予定の場合は空。 |

| interval | Integer | 繰り返し間隔。type により単位が異なります。例えば `type=daily` の場合は N 日間隔、`type=absoluteYearly` の場合は N 年間隔を表します。 |
