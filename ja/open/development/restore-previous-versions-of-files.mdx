---
title: "ファイル履歴バージョンの復元"
description: "ファイルを指定したバージョンに復元し、ファイル内容をそのバージョンと同一にします"
---

本 API を呼び出して、ファイルの履歴バージョンを復元します。

## API 呼び出し説明

例えば、**テストファイル.txt** というファイルがあり、現在の最新バージョンが 5 だとします。本 API を呼び出すことで、このファイルをバージョン 3 に復元できます。API 呼び出しに成功すると、テストファイル.txt の最新バージョンは 6 となり、ファイルのコンテンツはバージョン 3 と同一になります。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | `https://api.dingtalk.io/v1.0/storage/spaces/{spaceId}/dentries/{dentryId}/versions/{version}/revert` |
| HTTP Method | POST |
| サポートするアプリタイプ | appType-社内アプリ　appType-サードパーティ社内アプリ |
| 必要な権限 | permission-Storage.File.Write-企業ストレージファイル書き込み権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | 必須 | 本 API を呼び出す際のアクセス認証情報。以下の方法で取得します:   - 社内アプリの場合、[社内アプリの accessToken を取得](/ja/open/development/obtain-the-access-token-of-an-internal-app) API を呼び出して取得します。 - サードパーティ社内アプリの場合、[サードパーティアプリに権限付与した企業の accessToken を取得](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1) API を呼び出して取得します。 |

### パスパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| spaceId | String | 必須 | スペース ID。[スペースの追加](/ja/open/development/add-space) API を呼び出して id パラメータの値を取得できます。 |
| dentryId | String | 必須 | ファイル ID。[ファイルまたはフォルダーのリストを取得](/ja/open/development/get-a-list-of-files-or-folders) または [dentryUuid に基づき spaceId と dentryId を取得](/ja/open/development/api-getdentryidbyuuid) API を呼び出して id パラメータの値を取得できます。 |
| version | Long | 必須 | 復元するファイルのバージョン番号。最小値は 0 です。 |

### クエリパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| unionId | String | 必須 | 操作者の unionId。[ユーザー詳細の照会](/ja/open/development/query-user-details) API を呼び出して unionid パラメータの値を取得できます。 |
