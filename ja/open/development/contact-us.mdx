**より迅速かつ正確にご質問へお答えするため、チケット作成時には送信ガイドラインに従って追加情報をご提供いただくことをおすすめします。フィードバックにご協力いただき誠にありがとうございます。**

## セルフサービスツール

開発中に問題が発生した場合は、まず関連ドキュメントをお読みいただくか、セルフサービスツールを使用して、検証が必要な API のデバッグと特定を行うことをおすすめします。

- Server API デバッグツール
- ミニプログラム開発デバッグツール
- マイクロアプリ フロントエンドデバッグツール

## テクニカルサポート

**より高い品質のサービスをご提供し、待ち時間を短縮するため、まずはセルフサービスツールでの問題解決をお試しいただくことをおすすめします。問題が解決しない場合は、以下のチャネルからサポートをご利用いただけます。**

1. [Developer Console](https://open-dev.dingtalk.com) にログインします。
2. 右下隅の **Tabler** をクリックします。

3. Tabler をクリックした後、入力ボックスにご質問を入力してヘルプを受けられます。Tabler の回答で問題が解決しない場合は、下部の Ticket Center をクリックしてチケットを送信してください。

4. チケットを送信します。

   **注意**
   1. チケットを送信する際、API 呼び出しの問題が発生した場合は、組織の CorpID、API ドキュメント、requestID、その他のエラー詳細をご提供ください。
   2. チケットを送信すると、システムが自動的にグループチャットを作成し、テクニカルサポートを割り当てます（営業時間内）。チケット一覧で「グループに参加」をクリックすると、グループチャットに参加してコミュニケーションできます。
   3. グループチャットに他のユーザーを追加する場合は、ご自身で行ってください。パス：チケットチャットのよく使う機能 > チケット詳細 > メンバー追加ボタン（同一組織内のユーザーのみ対応）。

   ページに入った後、送信済みのイシューを確認・管理できます。

## **チケットシステムの概要**

チケットシステムは、イシューの記録とフォローアップをより簡単にするためにサポートサービスコンポーネントをアップグレードし、開発者により良いサービス体験をお届けできるよう努めています。

- **Ticket Center：現在の組織内のすべてのチケットを集約し、対応の進捗状況が一目で把握できます。**

- **チケットチャット：営業時間内（営業日の 09:00〜18:00）に、送信された各イシューに対して 1 時間以内に専用の DingTalk チケットチャットが作成されます。チケット一覧の「グループに参加」ボタンをクリックすると、グループチャットを通じてサービス担当者とシームレスにコミュニケーションできます。これによりコミュニケーションの手間が減り、イシュー対応がより効率的になります。**

- **サービスタイムライン：すべてのイシュー対応プロセスがタイムラインに記録され、プロセス中のすべてのチャット履歴が保存されるため、イシュー対応のライフサイクル全体を可視化し、透明性を確保できます。**

- **確認と評価：サービス担当者が解決策を提供すると、チケット完了カードがグループチャットに送信されます。解決策が有効であることを確認した場合は**Resolved**をクリックします。現時点で解決策を受け入れない場合は**Unresolved**をクリックすると、イシューが解決するまでサービス担当者が引き続きフォローアップします。**

- **イシューが解決した後、サービス担当者が提供したサービスを評価できます。**

## 注意事項

**問題を迅速に特定・調査できるよう、フィードバックを送信する際には以下の開発情報をご提供いただくことをおすすめします（これらに限定されません）。**

- 開発しているアプリタイプまたはシナリオ

  - 社内アプリ
  - サードパーティ社内アプリ
  - サードパーティ個人アプリ
  - ワークベンチ開発
  - チャットオープン機能 など
- 問題の詳細な説明と関連するスクリーンショット
- 企業名と CorpId
- Server API 呼び出しの問題の場合は、以下をご提供ください。

  - リクエストした API URL
  - パラメータの詳細
  - 実際に返された結果
  - 期待される返却結果
- フロントエンド API 呼び出しの問題の場合は、以下をご提供ください。

  - 電話番号のモデル
  - 電話番号のオペレーティングシステム
  - 使用中の DingTalk バージョン
  - API 呼び出しパラメータ
  - 実際に返された結果
  - 期待される返却結果
