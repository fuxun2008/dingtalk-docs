---
title: "メッセージリンクの説明"
---

本記事では、メッセージリンクの開き方について説明します。

## PC のサイドバーまたは外部ブラウザでメッセージリンクを開く

PC クライアントでチャット内の URL リンクをクリックする際に、リンクの開き方を制御したい場合は、以下の方法を使用します。

```text
dingtalk://dingtalkclient/page/link?url=http%3A%2F%2Fwww.dingtalk.io&pc_slide=true
```

### パラメータ説明

| **パラメータ** | 説明 |
| --- | --- |
| url | 開きたいリンク。urlEncode が必須です。 |
| pc_slide | - true：PC クライアントのサイドバーで開く - false：ブラウザで開く |

## ミニプログラムリンク

ミニプログラムからチャットを送信し、メッセージリンクをクリックしてミニプログラムにリダイレクトする機能で、対応するシナリオは以下のとおりです。

| アプリタイプ | 業務通知チャット | 社内グループチャット | 通常メッセージ |
| --- | --- | --- | --- |
| 社内アプリ | 対応 | 非対応 | 非対応 |
| サードパーティ社内アプリ | 対応 | 非対応 | 非対応 |
| サードパーティ個人アプリ | — | — | 対応 |

ミニプログラムへのリダイレクト用メッセージリンクの形式は以下のとおりです。

```text
 eapp://page?query
```

例：eapp://pages/index/index?param1=aa&param2=bb

### パラメータ説明

- 当該リンクはミニプログラムからチャットを送信する場合のみ対応しており、マイクロアプリからチャットを送信する場合は非対応です。
- リダイレクト先のミニプログラムは、本番バージョンを公開している必要があります。これにより正常なリダイレクトが保証されます。
- page はミニプログラムのページアドレスを表します。例：pages/index/index。この page は app.json 設定の pages 配下に定義されたパスである必要があります。

### 説明

  リダイレクト先のミニプログラムは、本番バージョンを公開している必要があります。これにより正常なリダイレクトが保証されます。

- query は page ページの onLoad の query パラメータを表します。例：param1=aa&param2=bb。パラメータ値に特殊文字が含まれる場合は、urlEncode でエンコード処理を行う必要があります。
