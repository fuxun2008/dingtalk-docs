---
title: "ファイルまたはフォルダーの一括削除"
---

本インターフェースを呼び出して、ファイルまたはフォルダーを一括削除できます。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | `https://api.dingtalk.io/v1.0/storage/spaces/{spaceId}/dentries/batchRemove` |
| HTTP Method | POST |
| 対応アプリタイプ | appType-社内アプリ　appType-サードパーティ社内アプリ |
| 権限要件 | permission-Storage.File.Write-企業ストレージファイル書き込み権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | はい | 本インターフェース呼び出し時のアクセス認証情報。以下の方法で取得します。   - 社内アプリの場合、[社内アプリの access_token を取得する](https://open.dingtalk.io/document/development/obtain-the-access-token-of-an-internal-app)インターフェースを呼び出して取得します。 - サードパーティ社内アプリの場合、[サードパーティアプリが権限付与された企業の access_token を取得する](https://open.dingtalk.io/document/development/obtain-the-access-token-of-the-authorized-enterprise-1)インターフェースを呼び出して取得します。 |

### パスパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| spaceId | String | はい | スペース ID。[スペース追加](https://open.dingtalk.io/document/development/add-space)インターフェースを呼び出して id パラメータ値を取得できます。 |

### クエリパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| unionId | String | はい | 操作者の unionId。[ユーザー詳細の照会](https://open.dingtalk.io/document/development/query-user-details)インターフェースを呼び出して unionid パラメータ値を取得できます。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| dentryIds | Array of String | はい | ファイルまたはフォルダー ID のリスト。最大 50 件。[ファイルまたはフォルダーリストの取得](https://open.dingtalk.io/document/development/get-a-list-of-files-or-folders)または [dentryUuid を使用して spaceId と dentryId を取得](https://open.dingtalk.io/document/development/api-getdentryidbyuuid)インターフェースを呼び出して id パラメータ値を取得できます。 |
| option | Object | いいえ | 任意パラメータ。 |
| toRecycleBin | Boolean | いいえ | ゴミ箱に削除するかどうか。   - **true**：ゴミ箱に移動 - **false**（デフォルト）：ゴミ箱に移動せず、直接削除 |

### リクエスト例

    "toRecycleBin" : true
  }
