---
title: "ファイルまたはフォルダー情報の一括取得"
---

ストレージスペース内に追加されたフォルダーやアップロードされたファイルについて、本 API を呼び出すことで関連情報を一括取得できます。

## API 呼び出し説明

ファイルおよびフォルダー情報を取得する際、フォルダーの場合はファイルサイズおよびファイル拡張子フィールドを取得できません。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | `https://api.dingtalk.io/v1.0/storage/spaces/{spaceId}/dentries/query` |
| HTTP Method | POST |
| サポートされるアプリタイプ | appType-社内アプリ　appType-サードパーティ社内アプリ |
| 必要な権限 | permission-Storage.File.Read-企業ストレージファイル読み取り権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | はい | この API を呼び出すためのアクセス認証情報。以下の方法で取得します：   - 社内アプリの場合、[社内アプリのaccessTokenを取得](/ja/open/development/obtain-the-access-token-of-an-internal-app) APIを呼び出して取得します。 - サードパーティ社内アプリの場合、[サードパーティアプリが権限付与された企業のaccessTokenを取得](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1) APIを呼び出して取得します。 |

### パスパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| spaceId | String | はい | スペース ID。[スペースを追加](/ja/open/development/add-space) API を呼び出して id パラメータ値を取得できます。 |

### クエリパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| unionId | String | はい | 操作者の unionId。[ユーザー詳細の照会](/ja/open/development/query-user-details) API を呼び出して unionid パラメータ値を取得できます。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| dentryIds | Array of String | はい | ファイルまたはフォルダーの ID リスト。最大 30 個。[ファイルまたはフォルダーのリストを取得](/ja/open/development/get-a-list-of-files-or-folders) または [dentryUuid から spaceId と dentryId を取得](/ja/open/development/api-getdentryidbyuuid) API を呼び出して id パラメータ値を取得できます。 |
| option | Object | いいえ | オプションパラメータ。 |
| appIdsForAppProperties | Array of String | いいえ | 指定するアプリ ID リスト。最大 20 個。[スペース情報の取得](/ja/open/development/get-space-information) API を介して ownerId パラメータ値を取得できます。       - このパラメータを渡すと、当該ファイルまたはフォルダーに対応するアプリの属性が返されます。 - このパラメータを渡さない場合、当該ファイルまたはフォルダーのすべてのアプリの属性が返されます。 |
| withThumbnail | Boolean | いいえ | ファイルのサムネイル情報を取得するかどうか。   - **true**：はい - **false**：いいえ       必要に応じて取得してください。取得時には API の処理時間が増加します。 |
