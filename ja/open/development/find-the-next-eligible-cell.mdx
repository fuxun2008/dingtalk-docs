---
title: "ワークシート内のセルを検索"
description: "findOptions.scope パラメータを指定した場合、検索範囲はさらにその範囲と積集合を取ります。"
---

指定された条件に基づき、与えられた文字列に一致する次のセルを検索します。検索範囲は、指定領域（rangeAddress）の左上セル以降のワークシート全体です。findOptions.scope パラメータを指定した場合、検索範囲はさらにその範囲と積集合を取ります。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | `https://api.dingtalk.io/v1.0/doc/workbooks/{workbookId}/sheets/{sheetId}/ranges/{rangeAddress}/findNext` |
| HTTP Method | POST |
| サポートされるアプリタイプ | appType-社内アプリ |
| 必要な権限 | permission-Document.Workbook.Read-スプレッドシート読み取り権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | はい | この API を呼び出すためのアクセス認証情報です。[社内アプリの access_token を取得](https://open.dingtalk.io/document/development/obtain-the-access-token-of-an-internal-app) を呼び出して取得できます。 |

### パスパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| workbookId | String | はい | スプレッドシートファイルの ID です。`nodeId`（dentryUuid）がスプレッドシートの `workbookId` に相当します。[ノードを取得](https://open.dingtalk.io/document/development/get-knowledge-base-acquisition-node) および [ナレッジベースドキュメントを作成](https://open.dingtalk.io/document/development/create-team-space-document) を呼び出して取得できます。 |
| sheetId | String | はい | ワークシートの ID またはタイトルです。[すべてのワークシートを取得](https://open.dingtalk.io/document/development/obtain-all-worksheets) を呼び出して id を取得するか、ワークシートのタイトルを渡してください。 |
| rangeAddress | String | はい | 検索を開始する起点位置です。この領域の左上のセルから開始します（ただし当該セル自体は含まれません）。 |

### クエリパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| operatorId | String | はい | 操作者の unionId です。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| text | String | はい | 検索するテキストです。 |
| findOptions | Object | いいえ | 検索オプションです。 |
| matchEntireCell | Boolean | いいえ | セル全体に一致させるかどうか：   - **true**：はい - **false**：いいえ |
| matchCase | Boolean | いいえ | 大文字小文字を区別するかどうか：   - **true**：はい - **false**：いいえ |
| useRegExp | Boolean | いいえ | text パラメータを正規表現として扱うかどうか：   - **true**：はい - **false**：いいえ |
| matchFormulaText | Boolean | いいえ | 数式内を検索するかどうか：   - **true**：はい - **false**：いいえ |
| scope | String | いいえ | 検索範囲です。A1 表記で指定する Range アドレス形式です。 |
| includeHidden | Boolean | いいえ | 非表示のセルを含めるかどうか。すなわち、行・列の非表示、絞り込み、グループ分けなどの機能により不可視となったセルを指します。ただし、閲覧権限のないセルは含まれません。   - **true**：はい - **false**：いいえ |
