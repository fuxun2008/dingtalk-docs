この API を呼び出して、進行中の承認インスタンスを取り消します。

## API 呼び出し説明

- 承認フローは、開始後 15 秒以内には取り消せません。
- isSystem パラメータを false（指定した操作者による終了）に設定する場合は、申請者を指定して承認インスタンスを取り消してください。
- この API で取り消せるのは進行中の承認インスタンスのみです。承認が完了した承認インスタンスは取り消せません。
- この API を呼び出す前に、[DingTalk 管理コンソール](https://oa.dingtalk.io/) > **ワークベンチ > アプリ管理 > OA承認アプリ** に移動し、**OA承認管理コンソール** を開きます。**テンプレート > プレミアム設定 > 承認フォームを元に戻す/変更** で、**提出者による進行中の承認フォームの取り消しを許可** を選択してください。この設定を行わない場合、タスクを処理する権限がないため、呼び出しは `errcode:820008, success:false, errmsg:Approval system error` で失敗します。

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/v1.0/workflow/processInstances/terminate |
| HTTP メソッド | POST |
| 対応アプリタイプ | appType-社内アプリ |
| 必要な権限 | permission-Workflow.Instance.Write-ワークフローインスタンスの書き込み権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | はい | この API を呼び出すためのアクセス認証情報です。[社内アプリのアクセストークンを取得](/ja/open/development/obtain-the-access-token-of-an-internal-app) API を呼び出して取得します。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| processInstanceId | String | はい | 承認インスタンス ID です。   - [承認インスタンスを作成](/ja/open/development/create-an-approval-instance) API を呼び出して、`InstanceId` パラメータの値を取得します。 - [承認インスタンス ID のリストを取得](/ja/open/development/obtain-an-approval-list-of-instance-ids) API を呼び出して、`list` パラメータの値を取得します。 |
| isSystem | Boolean | いいえ | システムによる操作かどうかを指定します。   - **true**：システムがインスタンスを直接終了します。 - **false**：指定した操作者がインスタンスを終了します（申請者を指定して取り消します）。 |
| remark | String | いいえ | 終了時の備考です。最大長：1,024 文字。 |
| operatingUserId | String | いいえ | 操作者の userId です。      isSystem が false の場合は必須です（申請者を指定して取り消します）。 |
