title: "企業の招待情報を取得"

本インターフェースを呼び出して、企業の招待情報を取得します。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/v1.0/contact/invites/infos |
| HTTP Method | GET |
| 対応アプリタイプ | appType-社内アプリ　appType-サードパーティ社内アプリ |
| 権限要件 | permission-Contact.Common.Read-連絡先ベーシックデータ読み取り権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | はい | 本インターフェースを呼び出すためのアクセス認証情報。以下の方法で取得します：   - 社内アプリの場合、[社内アプリのアクセストークンを取得](/ja/open/development/obtain-the-access-token-of-an-internal-app#)インターフェースを呼び出して取得します。 - サードパーティ社内アプリの場合、[サードパーティアプリが権限付与された企業のアクセストークンを取得](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#)インターフェースを呼び出して取得します。 |

### クエリパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| inviterUserId | String | いいえ | 招待者の userId。詳細は [ベーシック概念-UserId](/ja/open/dingstart/basic-concepts-beta#section-aa9-zk1-os6) を参照してください。  本パラメータを指定しない場合、デフォルトの招待者は現在の企業作成者の userId となります。 |
| deptId | Long | いいえ | 部門招待リンクを取得する部門 ID。 |

### リクエスト例

```http
GET /v1.0/contact/invites/infos?inviterUserId=user123&deptId=6612366 HTTP/1.1

x-acs-dingtalk-access-token:acc2343exxxx
Content-Type:application/json
```

| 名前 | タイプ | 説明 |

| inviteSwitch | Boolean | 招待をオンにするかどうか。   - **true**：オン - **false**：オフ |
| searchNameInvite | Boolean | 企業名検索による申請をオンにするかどうか。   - **true**：オン - **false**：オフ |
| orgApplyCodeInvite | Boolean | チーム番号による参加申請をオンにするかどうか。   - **true**：オン - **false**：オフ |

| inviteUrl | String | 招待リンク。 |
| auditType | Long | 審査タイプ。   - **0**：審査不要 - **1**：権限を持つサブ管理者   部門招待のみ有効です。 |
| empApplyJoinDept | Boolean | 社員が QR コードをスキャンして部門に参加することを許可するかどうか。   - **true**：許可 - **false**：不許可   審査不要の場合のみ有効で、既に組織内にいるユーザーが部門 QR コードをスキャンして特定の部門に参加できます。 |
