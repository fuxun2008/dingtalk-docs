本インターフェースを呼び出して、スペース内のファイルまたはフォルダー一覧を取得します。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | `https://api.dingtalk.io/v1.0/storage/spaces/{spaceId}/dentries` |
| HTTP Method | GET |
| サポートするアプリタイプ | appType-社内アプリ　appType-サードパーティ社内アプリ |
| 権限要件 | permission-Storage.File.Read-企業ストレージファイル読み取り権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | はい | 本インターフェースを呼び出すためのアクセス認証情報。以下の方法で取得します。   - 社内アプリの場合、[社内アプリの access_token を取得する](/ja/open/development/obtain-the-access-token-of-an-internal-app#)インターフェースを呼び出して取得します。 - サードパーティ社内アプリの場合、[サードパーティアプリで権限付与された企業の access_token を取得する](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#)インターフェースを呼び出して取得します。 |

### パスパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| spaceId | String | はい | スペースID。[スペースを追加する](/ja/open/development/add-space#)インターフェースを呼び出して id パラメータ値を取得します。 |

### クエリパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| parentId | String | はい | 親ディレクトリID。ルートディレクトリの場合は 0 です。[ファイルまたはフォルダー一覧を取得する](#)インターフェースを呼び出して parentId パラメータ値を取得します。 |
| nextToken | String | いいえ | ページネーションカーソル。   - 初回呼び出しの場合は、このパラメータ値を渡しません。 - 2 回目以降の呼び出しの場合は、前回の呼び出しで返された nextToken を渡します。 |
| maxResults | Integer | いいえ | 1 ページあたりのエントリ数。最大値は 50 です。 |
| orderBy | String | いいえ | 並び替えフィールド。   - **MODIFIED_TIME**：最終編集時間、デフォルト - **CREATE_TIME**：作成時間 - **NAME**：名前 - **SIZE**：サイズ |
| order | String | いいえ | 並べ替えルール。   - **ASC**：昇順 - **DESC**：降順、デフォルト |
| withThumbnail | Boolean | いいえ | ファイルのサムネイル一時リンクを取得するかどうか。必要に応じて取得してください。インターフェースの所要時間に影響します。   - true：取得する - false：取得しない、デフォルト |
| unionId | String | はい | 操作者の unionId。[ユーザー詳細を照会する](/ja/open/development/query-user-details#)インターフェースを呼び出して取得できます。 |
