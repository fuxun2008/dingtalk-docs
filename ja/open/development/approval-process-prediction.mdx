この API を呼び出して、承認フォームのフローにおけるノード情報を取得します。

## API 呼び出し説明

### 使用上の注意

この API を呼び出すと、次のノード情報を取得できます。

- 自選ノードの場合：ノード名、承認タイプ、承認者の設定、選択スコープ、複数承認者の承認方法、ノードのアクティブ化タイプなど。
- 自選ノード以外の場合：ノード名、承認タイプ、承認者の設定、複数承認者の承認方法、ノードのアクティブ化タイプなど。

承認ノードには次の設定項目があります。

**タイプ**：**手動承認**、**自動承認**、または **自動却下**。

**承認者** の **設定**：**指定メンバー**、**申請者が自分で選択**、**連続する複数階層の上司**、**部門マネージャー**、**直属の上司**、**ロール**、または **申請者本人**。申請者が選択する場合は、選択可能な **スコープ**（例：**指定メンバー**）と、1 人選択または複数人選択のモードを設定します。

**複数承認者の承認方法**：

| 方法 | 動作 |
| --- | --- |
| 順次承認 | 承認者が順番に処理します |
| 全員承認 | すべての承認者による承認が必要です |
| いずれか承認 | 1 人の承認者の承認または却下で結果が確定します |

### ユースケース

1. 自選ノードの有無を判断します。この API は、[承認インスタンスの作成](/ja/open/development/create-an-approval-instance) API と組み合わせて使用します。

   **注意**：この API は、**承認インスタンスの作成** API の呼び出し時に承認フローを指定せず、承認の管理コンソールで設定済みの承認フローを再利用する場合にのみ適用されます。

   承認テンプレートの編集画面では、設定が **基本設定**、**フォーム設計**、**フロー設計**、**高度な設定** の 4 つのステップに分かれています。**フロー設計** のキャンバスでは、承認フローが上から下へ順にノードとして配置されます。

   1. **申請者** ノード：承認インスタンスを開始する人です。
   2. **自選ノード**（申請者が処理担当者を選択するノード）：**申請者が自分で選択** として表示されます。
   3. **承認者** ノード：指定された承認者です。

   自選ノードでは、申請者がリクエストの送信時にそのステップの処理担当者を選択できます。
2. ノードタイプやノード名など、承認テンプレートに設定されたノード情報を取得します。

### 自選ノードの有無の判断

#### 自選ノードがある場合

この API を呼び出します。返される情報に、`activityType` フィールドの値が `target_select` であるノードが含まれます。

この API を **承認インスタンスの作成** API と組み合わせて使用する場合は、次の点に注意してください。

- 該当ノードの `actorKey` フィールドの値を、承認インスタンスの作成 API の actionerKey パラメータとして使用します。
- `actorSelectionRange` 内の `workNo` フィールドの値を、承認インスタンスの作成 API の `actionerUserIds` パラメータとして使用します。

  承認フローのデザイナーでは、**フロー設計** ステップ（**基本設定** > **フォーム設計** > **フロー設計** > **高度な設定**）で自選ノードを設定します。例のフローは **申請者** > **自選ノード**（タイプ：**申請者が選択**）> **承認者** の順に構成されています。

#### 自選ノードがない場合

この API を呼び出します。返される情報に、`activityType` フィールドの値が `target_approval` であるノードは含まれません。
