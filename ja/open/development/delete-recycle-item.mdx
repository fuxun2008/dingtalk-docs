---
title: "ゴミ箱項目の削除"
---

本 API を呼び出して、ゴミ箱内の特定の項目を削除します。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | `https://api.dingtalk.io/v1.0/storage/recycleBins/{recycleBinId}/recycleItems/{recycleItemId}` |
| HTTP Method | DELETE |
| サポートされるアプリタイプ | appType-社内アプリ　appType-サードパーティ社内アプリ |
| 必要な権限 | permission-Storage.RecycleBin.Write-企業ストレージゴミ箱の書き込み権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | はい | この API を呼び出すためのアクセス認証情報。以下の方法で取得します：   - 社内アプリの場合、[社内アプリの access_token を取得](https://open.dingtalk.io/document/development/obtain-the-access-token-of-an-internal-app#) を呼び出して取得します。 - サードパーティ社内アプリの場合、[サードパーティアプリで権限付与された企業の access_token を取得](https://open.dingtalk.io/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#) を呼び出して取得します。 |

### パスパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| recycleBinId | String | はい | ゴミ箱 Id。[ゴミ箱情報を取得](https://open.dingtalk.io/document/development/obtain-information-about-the-recycle-bin#) を呼び出して取得できます。 |
| recycleItemId | String | はい | ゴミ箱項目 Id。[ゴミ箱項目リストを取得](https://open.dingtalk.io/document/development/gets-the-list-of-recycle-items#) を呼び出して id パラメータの値を取得できます。 |

### クエリパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| unionId | String | はい | 操作者の unionId。[ユーザー詳細を取得](https://open.dingtalk.io/document/development/query-user-details#) を呼び出して取得できます。 |
