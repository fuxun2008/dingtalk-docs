この API を呼び出して、シフト制の勤怠グループのメンバーのシフトを設定します。勤怠グループのタイプが**シフト制**であることを確認してください。

## リクエスト

| **基本情報** | |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/topapi/attendance/group/schedule/async |
| HTTP メソッド | POST |
| 対応アプリタイプ | appType-社内アプリ　appType-サードパーティ社内アプリ |
| 必要な権限 | permission-qyapi_attendance_group_manage-勤怠グループ管理権限 |

### クエリパラメータ

| 名前 | タイプ | 必須 | 例 | 説明 |
| --- | --- | --- | --- | --- |
| access_token | String | はい | bE74xxxx | この API の呼び出しに使用するアプリ認証情報です。   - 社内アプリの場合は、[社内アプリの access_token を取得](/ja/open/development/obtain-orgapp-token) API を呼び出して取得します。 - サードパーティ社内アプリの場合は、サードパーティ組織の access_token を取得する API を呼び出して取得します。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 例 | 説明 |
| --- | --- | --- | --- | --- |
| op_user_id | String | はい | user456 | 操作者のユーザー ID です。 |
| group_id | Number | はい | 2987 | 勤怠グループ ID です。  **注意**  旧形式の勤怠グループ識別子 group_key を使用している場合は、[groupKey から groupId への変換](/ja/open/development/convert-groupkey-to-groupid) API を呼び出して group_key を group_id に変換してください。 |
| schedules | TopScheduleParam[] | はい |  | シフト設定の詳細です。例：   ``` &#123;   "is_rest": false,   "work_date": 1605150671000,   "shift_id": 1,   "userid": "user123" &#125; ```   **注意**  リストの最大長は 200 です。 |
| shift_id | Number | はい | 1 | シフト ID です。休息シフトの場合は 1 を指定します。id の値は、[シフト概要を取得](/ja/open/development/enterprise-shift-query-in-batches) API を呼び出して取得します。  **注意**   - is_rest が true の場合は、shift_id に 1 を指定してください。 - シフトをクリアする場合は、shift_id に -2 を指定してください。 |
| work_date | Number | はい | 1564985177000 | シフト設定の日付です。  **注意**  日付は、180 日前から 180 日後までの範囲で指定してください。 |
| is_rest | Boolean | いいえ | false | 休日かどうかを指定します。   - **true**：休日  **注意**  このパラメータが true の場合は、shift_id に 1 を指定してください。 - **false**：休日ではない |
| userid | String | はい | user123 | 対象ユーザーのユーザー ID です。 |

### リクエスト例

```curl
curl -X POST "https://api.dingtalk.io/topapi/attendance/group/schedule/async" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=d64b3xxxx57b23' \
-d 'group_id=2987' \
-d 'op_user_id=dd_test' \
-d 'schedules=null'
```

Java

```java
DingTalkClient client = new DefaultDingTalkClient("https://api.dingtalk.io/topapi/attendance/group/schedule/async");
OapiAttendanceGroupScheduleAsyncRequest req = new OapiAttendanceGroupScheduleAsyncRequest();
req.setOpUserId("user456");
req.setGroupId(2987L);
List<TopScheduleParam> list2 = new ArrayList<TopScheduleParam>();
TopScheduleParam obj3 = new TopScheduleParam();
obj3.setShiftId(1L);
obj3.setWorkDate(1564985177000L);
obj3.setIsRest(false);
obj3.setUserid("user123");
list2.add(obj3);
req.setSchedules(list2);
OapiAttendanceGroupScheduleAsyncResponse rsp = client.execute(req, access_token);
System.out.println(rsp.getBody());
```

PHP

```php

```

## レスポンス

### レスポンスボディ

| 名前 | タイプ | 例 | 説明 |
| --- | --- | --- | --- |
| success | Boolean | true | リクエストが成功したかどうかを示します。   - **true**：成功 - **false**：失敗 |
| errcode | Number | 0 | 戻りコードです。 |
| errmsg | String | ok | 戻りコードの説明です。 |
| request_id | String | zpd0i7dlr7bi | リクエスト ID です。 |

### レスポンスボディの例

```json
{
  "errcode":0,
  "errmsg":"ok",
  "success":true,
  "request_id":"zpd0i7dlr7bi"
}
```

### エラーコード

API の呼び出しでエラーが返された場合は、エラーメッセージをもとに[グローバルエラーコード](/ja/open/development/server-api-error-codes-1)ドキュメントで解決方法を確認してください。
