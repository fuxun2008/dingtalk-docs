title: "予定参加者の取得"

本インターフェースを呼び出して、予定参加者のリストを取得します。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | `https://api.dingtalk.io/v1.0/calendar/users/{userId}/calendars/{calendarId}/events/{eventId}/attendees` |
| HTTP Method | GET |
| サポートするアプリタイプ | appType-社内アプリ　appType-サードパーティ社内アプリ　appType-サードパーティ個人アプリ |
| 必要な権限 | permission-Calendar.Event.Read-カレンダーアプリにおける予定の読み取り権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | 必須 | 当該インターフェースを呼び出すためのアクセス認証情報。以下の方法で取得します。   - 社内アプリの場合は、[社内アプリの access_token を取得](/ja/open/development/obtain-the-access-token-of-an-internal-app#) インターフェースを呼び出して取得します。 - サードパーティ社内アプリの場合は、[サードパーティアプリで権限付与された企業の access_token を取得](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#) インターフェースを呼び出して取得します。 - サードパーティ個人アプリの場合は、[ユーザートークンを取得](/ja/open/development/obtain-user-token#) インターフェースを呼び出して取得します。 |

### パスパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| userId | String | 必須 | 本リクエストのリソースが所属するユーザーの unionId。   - 社内アプリおよびサードパーティ社内アプリの場合は、[ユーザー詳細の照会](/ja/open/development/query-user-details#) インターフェースを呼び出して unionid パラメータの値を取得します。 - サードパーティ個人アプリの場合は、[ユーザーの連絡先プロフィールを取得](/ja/open/development/dingtalk-retrieve-user-information#) インターフェースを呼び出して unionId パラメータの値を取得します。 |
| calendarId | String | 必須 | 予定が所属するカレンダー ID。 **primary** で統一されており、ユーザーのメインカレンダーを表します。 |
| eventId | String | 必須 | 予定 ID。[予定リストの照会](/ja/open/development/query-an-event-list#) インターフェースを呼び出して id パラメータの値を取得できます。 |

### クエリパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| maxResults | Integer | 任意 | 最大返却レコード数。デフォルトは 100、最大値は 500 です。 |
| nextToken | String | 任意 | ページングカーソル。      1 つのクエリ条件で一度にすべての結果を返せない場合、ページングトークンが返されます。次回のクエリでこのトークンを付与すると後続のデータが返却され、ページングトークンが null になるとすべてのデータの照会が完了したことを示します。 |
