title: "ユーザーを削除する"
description: "ユーザーを削除し、勤怠グループとスマート人事の名簿から同期的に削除します"
---

本 API を呼び出し、ユーザー ID に基づいて指定されたユーザーを削除します。

## API 呼び出し説明

本 API を呼び出して連絡先の社員の削除に成功すると、同時に以下のコンテンツも削除されます。

- 該当社員が所属する勤怠グループから、当該社員が同期的に削除されます。
- スマート人事の名簿から当該社員が同期的に削除されます。社員情報はスマート人事の退職済みメンバーで確認できます。

## リクエスト

| **基本情報** | |
| --- | --- |
| HTTP URL | https://oapi.dingtalk.io/topapi/v2/user/delete |
| HTTP Method | POST |
| サポートするアプリタイプ | appType-社内アプリ |
| 権限要件 | permission-qyapi_manage_addresslist-連絡先データ管理権限 |

### クエリパラメータ

| 名前 | タイプ | 必須 | 例 | 説明 |
| --- | --- | --- | --- | --- |
| access_token | String | はい | Be3xxxx | 本 API を呼び出すためのアプリ認証情報。社内アプリの access_token 取得 API から取得します。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 例 | 説明 |
| --- | --- | --- | --- | --- |
| userid | String | はい | uxxxx3 | 社員のユーザー ID。 |

### リクエスト例

```bash
curl -X POST "https://oapi.dingtalk.io/topapi/v2/user/delete" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=0b8a6220-ef56-4427-83d5-5690431776e5' \
-d 'userid=zhangsan'
```

Java

```java
DingTalkClient client = new DefaultDingTalkClient("https://oapi.dingtalk.io/topapi/v2/user/delete");
OapiV2UserDeleteRequest req = new OapiV2UserDeleteRequest();

OapiV2UserDeleteResponse rsp = client.execute(req, access_token);
System.out.println(rsp.getBody());
```

## レスポンス

### レスポンスボディ

| 名前 | タイプ | 例 | 説明 |
| --- | --- | --- | --- |
| request_id | String | 4f9md9obopn2 | リクエスト ID。 |
| errcode | Number | 0 | リターンコード。 |
| errmsg | String | 不正な userid | 呼び出しに失敗した際に返されるエラーメッセージ。 |

### レスポンスボディ例

```json
{
  "errcode": 0,
  "errmsg": "ok",
  "request_id": "4f9md9obopn2"
}
```

### エラーコード

本 API の呼び出し時にエラーが発生した場合は、エラーメッセージをもとに [グローバルエラーコード](/ja/open/development/server-api-error-codes-1) ドキュメントで解決策を検索してください。

| エラーコード（errcode） | エラーコードの説明（errmsg） | 解決策 |
| --- | --- | --- |
| 33012 | 無効な userId | userId が正しいか確認してください |
| 400002 | 無効なパラメータ | パラメータが要件通りに入力されているか確認してください |
| -1 | システムビジー | 後でもう一度お試しください |
