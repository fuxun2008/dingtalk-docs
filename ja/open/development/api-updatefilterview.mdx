---
title: "フィルタービューの更新"
description: "新規データ列をカバーしたり、特定の列のフィルタールールを変更して最新のビジネスニーズを反映したりします。"
---

本インターフェースを呼び出して、指定したフィルタービューの名前、範囲、またはフィルターを更新します。各フィールドはいずれもオプションであり、指定されたフィールドのみが更新されます。既存のフィルタービューを調整するシーンに適しており、例えばビューの名前を変更して識別しやすくしたり、フィルター範囲を拡大して新規データ列をカバーしたり、特定の列のフィルタールールを変更して最新のビジネスニーズを反映したりする場合に利用できます。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | `https://api.dingtalk.io/v1.0/doc/workbooks/{workbookId}/sheets/{sheetId}/filterViews/{filterViewId}` |
| HTTP Method | PATCH |
| サポートされるアプリタイプ | appType-社内アプリ |
| 権限要件 | permission-Document.Workbook.Write-スプレッドシート書き込み権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | はい | 当該インターフェースを呼び出すためのアクセス認証情報。[社内アプリの access_token を取得する](/ja/open/development/obtain-the-access-token-of-an-internal-app) インターフェースを呼び出して取得できます。 |

### パスパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| workbookId | String | はい | スプレッドシートファイル ID。[ナレッジベース API](https://open.dingtalk.io/document/orgapp/knowledge-base-overview) が返す `nodeId(dentryUuid)` がスプレッドシートの `workbookId` です。[ノードの取得](https://open.dingtalk.io/document/orgapp/get-node) および [ナレッジベースドキュメントの作成](https://open.dingtalk.io/document/orgapp/create-team-space-document) インターフェースを呼び出して取得できます。 |
| sheetId | String | はい | ワークシート ID または名前。[すべてのワークシートを取得する](https://open.dingtalk.io/document/orgapp/obtain-all-worksheets) インターフェースを呼び出して id または name パラメータ値を取得できます。 |
| filterViewId | String | はい | フィルタービューの ID。 |

### クエリパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| operatorId | String | はい | 操作者の unionId。   - [サイレントログインコードによるユーザー情報取得](https://open.dingtalk.io/document/orgapp/obtain-the-userid-of-a-user-by-using-the-log-free) インターフェースで unionid パラメータ値を取得できます。 - [ユーザー詳細の照会](https://open.dingtalk.io/document/orgapp/query-user-details) インターフェースを呼び出して unionid パラメータ値を取得できます。       操作者に権限がない場合、インターフェースは `The operator has no permission` というエラーを返します。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| name | String | いいえ | フィルタービューの新しい名前。指定しない場合は名前を更新しません。 |
| range | String | いいえ | フィルタービューの新しい範囲。A1 表記を使用します。指定しない場合は範囲を更新しません。 |
| criteria | `Map<String, Object>` | いいえ | 更新が必要な列のフィルター。key は列のオフセット（range の先頭列を基準とし、0 から始まる）、value はフィルターオブジェクトです。指定された列のみが更新され、他の列の既存のフィルターには影響しません。指定しない場合はフィルターを更新しません。 |
|  | Object | いいえ | 当該列のフィルターオブジェクト |
| filterType | String | いいえ | フィルタータイプ。指定可能な値：   - **values**：値で絞り込み - **color**：色で絞り込み - **condition**：条件で絞り込み |
| visibleValues | Array of String | いいえ | 表示する値 |
| conditions | Array | いいえ | 条件で絞り込む場合、指定するフィルター条件のリスト。`filterType` が `condition` の場合のみ有効です。各条件オブジェクトには `operator`（演算子）と `value`（条件値）フィールドが含まれます。 |
| operator | String | いいえ | 条件演算子。指定可能な値：   - **equal**：等しい - **not-equal**：等しくない - **contains**：含む - **not-contains**：含まない - **starts-with**：で始まる - **not-starts-with**：で始まらない - **ends-with**：で終わる - **not-ends-with**：で終わらない - **greater**：より大きい - **greater-equal**：以上 - **less**：より小さい - **less-equal**：以下 |
| value | String | いいえ | 条件値 |
| conditionOperator | String | いいえ | 複数条件間の論理関係。指定可能な値：`and`（かつ）、`or`（または）。デフォルトは `and` です。`filterType` が `condition` で、かつ複数条件がある場合のみ有効です。 |
| backgroundColor | String | いいえ | 背景色で絞り込む場合に指定する色値（16 進数、例：`#FF0000`）。`filterType` が `color` の場合のみ有効で、`fontColor` と択一です。 |
| fontColor | String | いいえ | フォント色で絞り込む場合に指定する色値（16 進数、例：`#FF0000`）。`filterType` が `color` の場合のみ有効で、`backgroundColor` と択一です。 |
