---
title: "ファイルまたはフォルダーの一括移動"
---

本インターフェイスを呼び出すと、ファイルまたはフォルダーを任意の場所へ一括で移動できます。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | `https://api.dingtalk.io/v1.0/storage/spaces/{spaceId}/dentries/batchMove` |
| HTTP Method | POST |
| サポートされるアプリタイプ | appType-社内アプリ　appType-サードパーティ社内アプリ |
| 権限要件 | permission-Storage.File.Write-企業ストレージファイル書き込み権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | はい | 本インターフェイスを呼び出すためのアクセス認証情報。以下の方法で取得します：   - 社内アプリの場合、[社内アプリの access_token を取得](https://open.dingtalk.io/document/development/obtain-the-access-token-of-an-internal-app)インターフェイスを呼び出して取得します。 - サードパーティ社内アプリの場合、[サードパーティアプリに権限付与された企業の access_token を取得](https://open.dingtalk.io/document/development/obtain-the-access-token-of-the-authorized-enterprise-1)インターフェイスを呼び出して取得します。 |

### パスパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| spaceId | String | はい | 移動元ファイルまたはフォルダーのスペース ID。[スペースの追加](https://open.dingtalk.io/document/development/add-space)インターフェイスを呼び出して id パラメータの値を取得できます。 |

### クエリパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| unionId | String | はい | 操作者の unionId。[ユーザー詳細の照会](https://open.dingtalk.io/document/development/query-user-details)インターフェイスを呼び出して unionid パラメータの値を取得できます。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| targetSpaceId | String | はい | 移動先スペース ID。[スペースの追加](https://open.dingtalk.io/document/development/add-space)インターフェイスを呼び出して id パラメータの値を取得できます。 |
| targetFolderId | String | はい | 移動先フォルダーの id。ルートディレクトリの id は 0 です。[ファイルまたはフォルダーリストの取得](https://open.dingtalk.io/document/development/get-a-list-of-files-or-folders)インターフェイスでパラメータ値を取得できます。 |
| dentryIds | Array of String | はい | 移動元ファイルまたはフォルダーの ID リスト。最大 30 件まで指定可能。[ファイルまたはフォルダーリストの取得](https://open.dingtalk.io/document/development/get-a-list-of-files-or-folders)または [dentryUuid から spaceId と dentryId を取得](https://open.dingtalk.io/document/development/api-getdentryidbyuuid)インターフェイスを呼び出して id パラメータの値を取得できます。 |
| option | Object | いいえ | オプションパラメータ。 |
| conflictStrategy | String | いいえ | ファイルまたはフォルダー名の衝突時の処理方針。   - **AUTO_RENAME**：自動で名前を変更（デフォルト） - **OVERWRITE**：上書き - **RETURN_DENTRY_IF_EXISTS**：既存ファイルを返す - **RETURN_ERROR_IF_EXISTS**：既に存在する場合はエラーを返す |
| preservePermissions | Boolean | いいえ | 移動後に権限を保持するかどうか。   - **true**：保持する - **false**（デフォルト）：保持しない |
