---
title: "行の表示／非表示を設定"
---

本インターフェースを呼び出して、行の表示状態を設定します。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | `https://api.dingtalk.io/v1.0/doc/workbooks/{workbookId}/sheets/{sheetId}/setRowsVisibility` |
| HTTP Method | POST |
| サポートするアプリタイプ | appType-社内アプリ　appType-サードパーティ社内アプリ |
| 権限要件 | permission-Document.Workbook.Write-スプレッドシート書き込み権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | はい | 本インターフェース呼び出し時のアクセス認証情報です。以下の方法で取得します：   - 社内アプリの場合、[社内アプリのaccessToken取得](/ja/open/development/obtain-the-access-token-of-an-internal-app#)インターフェースを呼び出して取得します。 - サードパーティ社内アプリの場合、[サードパーティアプリの認可企業のaccessToken取得](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#)インターフェースを呼び出して取得します。 |

### パスパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| workbookId | String | はい | スプレッドシートファイルID。[ナレッジベース API](/ja/open/development/knowledge-base-overview#) が返す `nodeId(dentryUuid)` がスプレッドシートの `workbookId` です。[ノードの取得](https://open.dingtalk.com/document/development/get-node#)および[ナレッジベースドキュメントの作成](/ja/open/development/create-team-space-document#)インターフェースを呼び出して取得できます。 |
| sheetId | String | はい | ワークシートのIDまたは見出し。   - 社内アプリの場合、[すべてのワークシート取得](/ja/open/development/obtain-all-worksheets#)インターフェースを呼び出してidを取得するか、ワークシートの見出しを渡します。 - サードパーティ社内アプリの場合、ワークシートの見出しを渡すことを推奨します。   ワークシート見出しの確認手順は下図を参照してください。 |

### クエリパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| operatorId | String | はい | 操作者のunionId。[ユーザー詳細クエリ](/ja/open/development/query-user-details#)インターフェースを呼び出して取得できます。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| visibility | String | はい | 表示状態。   - **visible**：表示 - **hidden**：非表示 |
| row | Long | はい | 表示または非表示にする最初の行のカーソル。0から始まります。 |
| rowCount | Long | はい | 表示または非表示にする行数。 |

### リクエスト例

HTTP

```http
POST /v1.0/doc/workbooks/e54Lq3xxx/sheets/Sheet1/setRowsVisibility?operatorId=ppgAxxx HTTP/1.1
Host:api.dingtalk.io
x-acs-dingtalk-access-token:xxxxx
Content-Type:application/json

{
  "visibility" : "hidden",
  "row" : 0,
  "rowCount" : 1
}
```
