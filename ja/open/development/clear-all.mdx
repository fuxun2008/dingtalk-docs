---
title: "セル範囲内のすべてのコンテンツをクリアする"
---

セルのコンテンツとスタイルを含むすべてのコンテンツをクリアします。

## API 呼び出し説明

本 API を呼び出して、指定範囲内のすべてのコンテンツ（書式およびデータを含む）をクリアします。実現される効果は下図の操作と同じです。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | `https://api.dingtalk.io/v1.0/doc/workbooks/{workbookId}/sheets/{sheetId}/ranges/{rangeAddress}/clear` |
| HTTP Method | POST |
| サポートされるアプリタイプ | appType-社内アプリ　appType-サードパーティ社内アプリ |
| 必要な権限 | permission-Document.Workbook.Write-スプレッドシート書き込み権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | はい | この API を呼び出すためのアクセス認証情報。以下の方法で取得します。   - 社内アプリの場合、[社内アプリのアクセストークンを取得](/ja/open/development/obtain-the-access-token-of-an-internal-app#) API を呼び出して取得します。 - サードパーティ社内アプリの場合、[サードパーティアプリが権限付与された企業のアクセストークンを取得](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#) API を呼び出して取得します。 |

### パスパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| workbookId | String | はい | スプレッドシートファイルの ID。[ナレッジベース API](/ja/open/development/knowledge-base-overview#) が返す `nodeId(dentryUuid)` がスプレッドシートの `workbookId` となります。[ノードを取得](https://open.dingtalk.com/document/development/get-node#) および [ナレッジベースドキュメントを作成](/ja/open/development/create-team-space-document#) API を呼び出して取得できます。 |
| sheetId | String | はい | ワークシートの ID または見出し。   - 社内アプリの場合、[すべてのワークシートを取得](/ja/open/development/obtain-all-worksheets#) API を呼び出して id を取得するか、ワークシートの見出しを渡します。 - サードパーティ社内アプリの場合、ワークシートの見出しを渡すことを推奨します。   ワークシートの見出しの確認手順は下図のとおりです。 |
| rangeAddress | String | はい | クリアするセル範囲。形式は `範囲内左上のセル:範囲内右下のセル` です。  例：B2:C3 の場合、表す範囲は下図のとおりです。 |

### クエリパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| operatorId | String | はい | 操作者の unionId。[ユーザー詳細を照会](/ja/open/development/query-user-details#) API を呼び出して取得できます。 |

Content-Type:application/json
