description: "DingTalkのAPIを呼び出し、社内のすべての勤怠グループの概要を一括取得する方法を解説します。ページングCursorを使って勤怠グループ名と勤怠グループIDを効率的に取得できます。"
---

この API を呼び出して、社内のすべての勤怠グループの概要をページ単位で取得します。各勤怠グループの名前と、対応する勤怠グループ ID が含まれます。

## リクエスト

| **ベーシック情報** | |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/topapi/attendance/group/minimalism/list |
| HTTP メソッド | POST |
| 対応アプリタイプ | appType-社内アプリ appType-サードパーティ社内アプリ |
| 権限 | permission-qyapi_attendance_group_read-勤怠グループの読み取り権限 |

### クエリパラメータ

| 名前 | タイプ | 必須 | 例 | 説明 |
| --- | --- | --- | --- | --- |
| access_token | String | はい | bE74xxxx | この API を呼び出すためのアプリ認証情報です。   - 社内アプリの場合は、[社内アプリの access_token を取得](/ja/open/development/obtain-orgapp-token)を呼び出して取得します。 - サードパーティ社内アプリの場合は、サードパーティ組織の access_token を取得する API を呼び出して取得します。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 例 | 説明 |
| --- | --- | --- | --- | --- |
| op_user_id | String | はい | user123 | 操作者の userId です。 |
| cursor | Number | いいえ | 222 | ページングカーソルです。前回のリクエスト結果から取得します。省略した場合は、最初の項目からクエリを開始します。 |

### リクエスト例

```curl
curl -X POST "https://api.dingtalk.io/topapi/attendance/group/minimalism/list" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=6dd4xxxx94138' \
-d 'cursor=222' \
-d 'op_user_id=dd_dd'
```

Java

```text
DingTalkClient client = new DefaultDingTalkClient("https://api.dingtalk.io/topapi/attendance/group/minimalism/list");
OapiAttendanceGroupMinimalismListRequest req = new OapiAttendanceGroupMinimalismListRequest();
req.setOpUserId("manager4220");
req.setCursor(0L);
OapiAttendanceGroupMinimalismListResponse rsp = client.execute(req, access_token);
System.out.println(rsp.getBody());
```

Python

```python
import dingtalk.api

req=dingtalk.api.OapiAttendanceGroupMinimalismListRequest("https://api.dingtalk.io/topapi/attendance/group/minimalism/list")

req.op_user_id="dd_dd"
req.cursor=222
try:
  resp= req.getResponse(access_token)
  print(resp)
except Exception,e:
  print(e)
```

PHP

```php

date_default_timezone_set('Asia/Shanghai');

$c = new DingTalkClient(DingTalkConstant::$CALL_TYPE_OAPI, DingTalkConstant::$METHOD_POST , DingTalkConstant::$FORMAT_JSON);

$req->setCursor("222");
$resp = $c->execute($req, $access_token, "https://api.dingtalk.io/topapi/attendance/group/minimalism/list");
```

C#

```text
IDingTalkClient client = new DefaultDingTalkClient("https://api.dingtalk.io/topapi/attendance/group/minimalism/list");
OapiAttendanceGroupMinimalismListRequest req = new OapiAttendanceGroupMinimalismListRequest();
req.OpUserId = "dd_dd";
req.Cursor = 222L;
OapiAttendanceGroupMinimalismListResponse rsp = client.Execute(req, access_token);
Console.WriteLine(rsp.Body);
```

## レスポンス

### レスポンスボディ

| 名前 | タイプ | 例 | 説明 |
| --- | --- | --- | --- |
| result | PageResult | demo | 返される結果です。 |
| has_more | Boolean | false | さらにデータがあるかどうかを示します。   - **true**：はい - **false**：いいえ |
| cursor | Number | 685935028 | カーソルの位置です。 |
| result | TopMinimalismGroupVo[] |  | 勤怠情報です。 |
| name | String | 通常勤務 | 勤怠グループの名前です。 |
| id | Number | 677765054 | 勤怠グループ ID です。 |
| success | Boolean | true | リクエストが成功したかどうかを示します。   - **true**：成功 - **false**：失敗 |
| errcode | Number | 0 | 戻りコードです。 |
| errmsg | String | ok | エラーメッセージの説明です。 |
| request_id | String | wv9973jntam | リクエスト ID です。 |
