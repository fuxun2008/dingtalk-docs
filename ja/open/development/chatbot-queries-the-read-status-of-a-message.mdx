---
title: "社内ボットのグループチャットメッセージ既読状態を照会"
---

本 API を呼び出すことで、ボットメッセージの送信状態や既読ユーザーの userId などの情報を取得できます。たとえば、社内ボットが内部グループチャットでグループチャットメッセージを送信した後、本 API を利用することで、既読ユーザーの userId を照会できます。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/v1.0/robot/groupMessages/query |
| HTTP Method | POST |
| サポートされるアプリタイプ | appType-社内アプリ　appType-サードパーティ社内アプリ |
| 必要な権限 | permission-qyapi_robot_sendmsg-社内ボットのメッセージ送信権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | はい | 本 API を呼び出すためのアクセス認証情報。以下の方法で取得します:   - 社内アプリの場合、[社内アプリのアクセストークンを取得](/ja/open/development/obtain-the-access-token-of-an-internal-app#) API を呼び出して取得します。 - サードパーティ社内アプリの場合、[サードパーティアプリで認可された企業のアクセストークンを取得](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#) API を呼び出して取得します。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| openConversationId | String | いいえ | グループ ID。クライアントサイドの [chooseChat](https://open.dingtalk.com/document/development/jsapi-choose-chat#) でグループチャットの openConversationId を取得できます。  [ボットによるグループチャットメッセージの送信](/ja/open/development/the-robot-sends-a-group-message#) API 呼び出し時に使用した openConversationId と一致させる必要があります。 |
| robotCode | String | いいえ | ボットのコード。詳細は [ボット ID](https://open.dingtalk.com/document/development/robot-overview#) を参照してください。  [ボットによるグループチャットメッセージの送信](/ja/open/development/the-robot-sends-a-group-message#) API 呼び出し時に使用した robotCode と一致させる必要があります。 |
| processQueryKey | String | はい | メッセージの一意識別子。[ボットによるグループチャットメッセージの送信](/ja/open/development/the-robot-sends-a-group-message#) API のレスポンスパラメーター processQueryKey フィールドから取得します。 |
| maxResults | Long | いいえ | ページネーション取得の 1 ページあたりの件数。最大値は 200 です。 |
| nextToken | String | いいえ | ページネーションカーソル。空にするとホームから取得を開始します。 |
