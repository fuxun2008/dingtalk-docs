---
title: "個人間チャットでボットから通常メッセージを送信する"
---

本 API を呼び出して、個人間チャットでボットから通常メッセージを送信します。

## API 呼び出し説明

個別チャット型クールアプリのシナリオでのみ使用できます。詳細は [個別チャット型クールアプリ](https://open.dingtalk.com/document/dingstart/private-chat-coolapp-overview#) を参照してください。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/v1.0/robot/privateChatMessages/send |
| HTTP Method | POST |
| 対応アプリタイプ | appType-社内アプリ　appType-サードパーティ社内アプリ |
| 必要な権限 | permission-qyapi_robot_sendmsg-社内ボットメッセージ送信権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | 必須 | 本 API を呼び出すためのアクセス認証情報。以下の方法で取得します。   - 社内アプリの場合は、[社内アプリのアクセストークンを取得する](/ja/open/development/obtain-the-access-token-of-an-internal-app#) API を呼び出して取得します。 - サードパーティ社内アプリの場合は、[サードパーティアプリで権限付与された企業のアクセストークンを取得する](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#) API を呼び出して取得します。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| msgParam | String | 必須 | メッセージテンプレートのパラメーター。詳細は [社内ボットが送信するメッセージのタイプ](https://open.dingtalk.com/document/dingstart/types-of-messages-sent-by-robots#) を参照してください。 |
| msgKey | String | 必須 | メッセージテンプレートの key。詳細は [社内ボットが送信するメッセージのタイプ](https://open.dingtalk.com/document/dingstart/types-of-messages-sent-by-robots#) を参照してください。 |
| openConversationId | String | 必須 | チャット ID。[クールアプリを個別チャットへ一括インストール](https://open.dingtalk.com/document/development/batch-chat-session#) または [個別チャット型クールアプリイベント](https://open.dingtalk.com/document/development/org-event-overview#260a4e7084gs2) のリスニングを通じて OpenConversationId の値を取得できます。 |
| robotCode | String | 必須 | ボットコード。本パラメーターには社内ボットの robotCode を使用します。詳細は [ボット ID](https://open.dingtalk.com/document/development/robot-overview#) を参照してください。 |
| coolAppCode | String | 必須 | クールアプリのコード。 |
