---
title: "ビデオ会議情報の照会"
---

本インターフェースを呼び出すと、会議名、会議時間、会議開始時間、会議終了時間、累計参加人数などの会議の基本情報を取得できます。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | `https://api.dingtalk.io/v1.0/conference/videoConferences/{conferenceId}` |
| HTTP Method | GET |
| サポートされるアプリタイプ | appType-社内アプリ　appType-サードパーティ社内アプリ |
| 権限要件 | permission-VideoConference.Conference.Read-ビデオ会議情報の読み取り権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | はい | 当該インターフェース呼び出し用のアクセス認証情報。以下の方法で取得します。   - 社内アプリの場合は、[社内アプリの access_token を取得](https://open.dingtalk.io/document/development/obtain-the-access-token-of-an-internal-app#)インターフェースを呼び出して取得します。 - サードパーティ社内アプリの場合は、[サードパーティアプリで権限付与された企業の access_token を取得](https://open.dingtalk.io/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#)インターフェースを呼び出して取得します。 |

### パスパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| conferenceId | String | はい | 会議の conferenceId。[ビデオ会議を作成](https://open.dingtalk.io/document/development/create-a-video-conference#)インターフェースを呼び出して conferenceId を取得できます。 |

## レスポンス

### レスポンスボディ

| 名前 | タイプ | 説明 |
| --- | --- | --- |
| confInfo | Object | 会議情報。 |
| activeNum | Integer | 現在の参加人数。 |
| attendNum | Integer | 累計参加人数。 |
| confDuration | Long | 会議時間（単位：ミリ秒）。      会議終了後に当該フィールドが返されます。 |
| conferenceId | String | 会議 ID。 |
| creatorId | String | 会議作成者の unionId。 |
| creatorNick | String | 会議作成者の名前。 |
| externalLinkUrl | String | 会議への参加リンク。 |
| invitedNum | Integer | 招待人数。 |
| startTime | Long | 会議開始タイムスタンプ（単位：ミリ秒）。 |
| status | Integer | 会議ステータス。   - 0：初期化 - 1：会議終了 - 2：会議開始 |
| title | String | タイトル。 |
| roomCode | String | 会議コード。 |
| endTime | Long | 会議終了タイムスタンプ（単位：ミリ秒）。      会議終了後に当該フィールドが返されます。 |
| scheduleConferenceId | String | 予約会議 ID。 |
| bizType | String | 会議業務タイプ：   - **0**：即時ビデオ会議 - **3**：予約会議 - **audio_conf**：ビデオ会議 |
| cloudRecordStatus | Integer | 会議クラウド録画ステータス：   - **0**：未録画 - **1**：録画中 - **2**：録画一時停止 - **3**：録画終了 |
| cloudRecordOwnerUnionId | String | クラウド録画所有者の unionId。 |
| minutesStatus | Integer | 会議閃記ステータス：   - **0**：未オン - **1**：録画中 - **2**：一時停止 - **3**：終了       会議中の閃記機能は移行されたため、当該フィールドは返されなくなります。 |
| minutesOwnerUnionId | String | 閃記所有者の unionId。      会議中の閃記機能は移行されたため、当該フィールドは返されなくなります。 |
| extensionAppSettings | Array | 会議単位の拡張アプリカスタム情報リスト。 |
| appId | String | 会議クールアプリが所属するマイクロアプリの AgentId。 |
| appCode | String | クールアプリの appCode。 |
| autoOpenMode | Integer | 自動オープンモード：   - **0**：自動オープンしない - **1**：主催者／共同主催者のみ自動オープン - **2**：全員自動オープン |
| extensionAppBizData | String | 会議単位の拡張アプリカスタム情報。 |
