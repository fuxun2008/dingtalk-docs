---
title: "OA承認タスクの転送"
description: "指定した OA承認タスクを別のユーザーに転送する API です。転送備考や操作ノード名、添付ファイルを指定できます。"
---

この API を呼び出して、OA承認タスクを転送します。

## API 呼び出し説明

<Note>
この API は、公式承認またはネイティブ承認フローで開始された承認のタスクのみに対応しています。カスタム承認で作成されたインスタンスのタスクには対応していません。
</Note>

承認添付ファイルを追加するには、ファイルを承認用ドライブスペースにアップロードします。これにより、spaceId、fileType、fileName、fileId、fileSize の各パラメーターを取得できます。手順は次のとおりです。

1. [承認用ドライブスペース情報の取得](/ja/open/development/obtains-the-information-about-approval-nail-disk) API を呼び出し、ドライブスペースへのアップロード権限と、承認用ドライブスペースの spaceId を取得します。
2. 承認用ドライブスペースの spaceId を使用して、Web アプリ（H5 マイクロアプリ）で添付ファイルをドライブにアップロードするか、ドライブからファイルを選択し、ドライブ添付ファイルの情報を取得します。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/v1.0/workflow/tasks/redirect |
| HTTP メソッド | POST |
| 対応アプリタイプ | appType-社内アプリ　appType-サードパーティ社内アプリ |
| 権限 | permission-Workflow.Instance.Write-ワークフローインスタンスの書き込み権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | はい | この API を呼び出すためのアクセス認証情報です。次の方法で取得します。   - 社内アプリ：[社内アプリのアクセストークンの取得](/ja/open/development/obtain-the-access-token-of-an-internal-app) API を呼び出します。 - サードパーティ社内アプリ：サードパーティアプリを承認済みの組織のアクセストークンを取得する API を呼び出します。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| taskId | Long | はい | OA承認タスクの ID です。[単一承認インスタンスの詳細の取得](/ja/open/development/obtains-the-details-of-a-single-approval-instance-pop) API が返す taskId の値を使用します。 |
| toUserId | String | はい | OA承認タスクの転送先ユーザーの userId です。 |
| remark | String | いいえ | 転送の備考です。最大長：256 文字。 |
| operateUserId | String | はい | 操作者の userId です。タスクの現在の担当者と一致している必要があります。一致しない場合、検証に失敗します。 |
| actionName | String | いいえ | 操作ノード名です。最大長：128 文字。 |
| file | Object | いいえ | ファイルです。 |
| photos | Array of String | いいえ | 画像の URL です。最大長：1,024 文字。 |
| attachments | Array | いいえ | 添付ファイルのリストです。最大要素数：20。 |
| spaceId | String | いいえ | ドライブスペースの ID です。      本ドキュメントの「API 呼び出し説明」セクションを参照してください。 |
| fileSize | String | いいえ | ファイルサイズです。      本ドキュメントの「API 呼び出し説明」セクションを参照してください。 |
| fileId | String | いいえ | ファイルの ID です。最大長：256 文字。      本ドキュメントの「API 呼び出し説明」セクションを参照してください。 |
| fileName | String | いいえ | 添付名称です。最大長：256 文字。      本ドキュメントの「API 呼び出し説明」セクションを参照してください。 |
| fileType | String | いいえ | 添付種類です。      本ドキュメントの「API 呼び出し説明」セクションを参照してください。 |

```java
                    // err には code 属性と message 属性が含まれており、問題の特定に役立ちます
                }
            }
        }

    }
}
```
