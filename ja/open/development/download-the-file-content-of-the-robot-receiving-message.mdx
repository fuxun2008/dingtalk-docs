title: "ボットが受信したチャットのファイルコンテンツをダウンロード"
---

ボットメッセージ内のファイルダウンロードリンクを取得します。

## API 呼び出し説明

1. ユーザーがボットに画像メッセージ、音声メッセージ、動画メッセージ、ファイルメッセージ、リッチテキストメッセージを送信すると、ボットからデベロッパーへのコールバック情報の中に一時ダウンロードコード `downloadCode` が含まれます。
2. 一時ダウンロードコード `downloadCode` を使って本 API を呼び出し、チャット内の画像、音声、ファイル、動画などのファイルの一時ダウンロードリンクを取得します。
3. 一時ダウンロードリンクにアクセスして、ファイルコンテンツを取得します。

### 説明

- グループチャットの場合：グループメンバーがボットを @ メンションした際、ボットは音声、ファイル、動画タイプの受信をサポートしていません。
- 個人間チャットの場合：ボットは音声、ファイル、動画タイプの受信をサポートしていません。
- 個人とボット間のチャットの場合：ボットは音声、ファイル、動画タイプの受信をサポートしています。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/v1.0/robot/messageFiles/download |
| HTTP Method | POST |
| サポートされるアプリタイプ | appType-社内アプリ　appType-サードパーティ社内アプリ |
| 必要な権限 | permission-qyapi_robot_sendmsg-社内ボットによるチャット送信権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | はい | この API を呼び出すためのアクセス認証情報。以下の方法で取得します：   - 社内アプリの場合、[社内アプリの accessToken を取得](https://open.dingtalk.io/document/development/obtain-the-access-token-of-an-internal-app#) API を呼び出して取得します。 - サードパーティ社内アプリの場合、[サードパーティアプリ認可企業の accessToken を取得](https://open.dingtalk.io/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#) API を呼び出して取得します。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| downloadCode | String | はい | ユーザーがボットにファイルメッセージを送信した後、ボットからデベロッパーへのコールバックメッセージ内のダウンロードコード。詳細は [ボットによるチャット受信](https://open.dingtalk.io/document/dingstart/receive-message#) を参照してください。 |
| robotCode | String | はい | ボットのコード。詳細は [ボット ID](https://open.dingtalk.io/document/development/robot-overview#) を参照してください。 |
