---
title: "権限の削除"
---

本インターフェースを呼び出して、ファイル UUID、操作者の unionId、権限 ID などの情報に基づき、ナレッジベース、ナレッジベースノード、およびドライブファイルのメンバー権限を削除します。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | `https://api.dingtalk.io/v2.0/storage/spaces/dentries/{dentryUuid}/permissions/remove` |
| HTTP Method | POST |
| サポートされるアプリタイプ | appType-社内アプリ |
| 必要な権限 | permission-Storage.Permission.Write-企業ストレージ権限付与情報の書き込み権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | はい | 本インターフェース呼び出しのアクセス認証情報です。[社内アプリの access_token を取得](https://open.dingtalk.io/document/development/obtain-the-access-token-of-an-internal-app)インターフェースを呼び出して取得できます。 |

### パスパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| dentryUuid | String | はい | ファイル UUID。[ファイル検索](https://open.dingtalk.io/document/development/search-for-files)インターフェースまたは [dentryUuid 情報の取得](https://open.dingtalk.io/document/development/api-getuuidbydentryid)インターフェースを呼び出し、レスポンスパラメータの dentryUuid フィールドを取得できます。 |

### クエリパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| unionId | String | はい | ユーザーの unionId。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| roleId | String | はい | ロール ID。列挙値：   - **OWNER**：オーナー。以下の権限スコープを持ちます：    - PermissionPrivilegeEnum.INFO   - PermissionPrivilegeEnum.LIST   - PermissionPrivilegeEnum.PREVIEW   - PermissionPrivilegeEnum.READ   - PermissionPrivilegeEnum.WRITE   - PermissionPrivilegeEnum.DOWNLOAD   - PermissionPrivilegeEnum.ADD   - PermissionPrivilegeEnum.DELETE   - PermissionPrivilegeEnum.MODIFY   - PermissionPrivilegeEnum.COPY   - PermissionPrivilegeEnum.RENAME   - PermissionPrivilegeEnum.READ_PERMISSION   - PermissionPrivilegeEnum.WRITE_PERMISSION   - PermissionPrivilegeEnum.ASSIGN - **MANAGER**：管理者。以下の権限スコープを持ちます：    - PermissionPrivilegeEnum.INFO   - PermissionPrivilegeEnum.LIST   - PermissionPrivilegeEnum.PREVIEW   - PermissionPrivilegeEnum.READ   - PermissionPrivilegeEnum.WRITE   - PermissionPrivilegeEnum.DOWNLOAD   - PermissionPrivilegeEnum.ADD   - PermissionPrivilegeEnum.DELETE   - PermissionPrivilegeEnum.MODIFY   - PermissionPrivilegeEnum.COPY   - PermissionPrivilegeEnum.RENAME   - PermissionPrivilegeEnum.READ_PERMISSION   - PermissionPrivilegeEnum.WRITE_PERMISSION - **EDITOR**：編集者。以下の権限スコープを持ちます：    - PermissionPrivilegeEnum.INFO   - PermissionPrivilegeEnum.LIST   - PermissionPrivilegeEnum.PREVIEW   - PermissionPrivilegeEnum.READ   - PermissionPrivilegeEnum.WRITE   - PermissionPrivilegeEnum.DOWNLOAD   - PermissionPrivilegeEnum.ADD - **DOWNLOADER**：閲覧・ダウンロード者。以下の権限スコープを持ちます：    - PermissionPrivilegeEnum.INFO   - PermissionPrivilegeEnum.LIST   - PermissionPrivilegeEnum.PREVIEW   - PermissionPrivilegeEnum.READ   - PermissionPrivilegeEnum.DOWNLOAD - **READER**：閲覧のみ。以下の権限スコープを持ちます：    - PermissionPrivilegeEnum.INFO   - PermissionPrivilegeEnum.LIST   - PermissionPrivilegeEnum.PREVIEW |
| members | Array | はい | 権限メンバーリスト。最大 30 件。 |
| type | String | はい | 権限メンバータイプ。列挙値：   - **ORG**：企業 - **DEPT**：部門 - **TAG**：カスタム tag - **CONVERSATION**：チャット - **USER**：ユーザー |
| id | String | はい | 権限メンバー ID：   - `type=ORG` の場合、id は企業 ID - `type=DEPT` の場合、id は部門 ID - `type=TAG` の場合、id はタグ ID - `type=CONVERSATION` の場合、id はチャット ID - `type=USER` の場合、id は社員の userId |
| corpId | String | いいえ | 権限が帰属する企業。       - 企業 ID が存在する場合、対応するメンバーが退職した際に権限が自動的に削除されます。 - memberType が dept タイプの場合、企業 ID が必須となります。 |
