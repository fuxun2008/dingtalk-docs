---
title: "社内ボットによる内部グループメッセージの送信取消"
---

本インターフェースを呼び出すことで、社内ボットによる内部グループメッセージの送信取消を実現できます。グループチャットボットの誤送信メッセージを一括で送信取消するシナリオに適しています。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/v1.0/robot/groupMessages/recall |
| HTTP Method | POST |
| サポートするアプリタイプ | appType-社内アプリ　appType-サードパーティ社内アプリ |
| 必要な権限 | permission-qyapi_robot_sendmsg-社内ボットによるメッセージ送信権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | はい | 本インターフェース呼び出し時のアクセス認証情報。以下の方法で取得します：   - 社内アプリの場合、[社内アプリの access_token を取得](https://open.dingtalk.io/document/development/obtain-the-access-token-of-an-internal-app#)インターフェースを呼び出して取得します。 - サードパーティ社内アプリの場合、[サードパーティアプリが権限付与された企業の access_token を取得](https://open.dingtalk.io/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#)インターフェースを呼び出して取得します。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| openConversationId | String | はい | グループ ID。クライアントサイドの [chooseChat](https://open.dingtalk.io/document/development/jsapi-choose-chat#) によりグループチャットの openConversationId を取得できます。  [ボットがグループチャットメッセージを送信](https://open.dingtalk.io/document/development/the-robot-sends-a-group-message#)インターフェースで使用した openConversationId と一致させる必要があります。 |
| robotCode | String | はい | ボットのコード。[ボット ID](https://open.dingtalk.io/document/development/robot-overview#) を参照してください。  [ボットがグループチャットメッセージを送信](https://open.dingtalk.io/document/development/the-robot-sends-a-group-message#)インターフェースで使用した robotCode と一致させる必要があります。 |
| processQueryKeys | Array of String | はい | メッセージ ID リスト。[ボットがグループチャットメッセージを送信](https://open.dingtalk.io/document/development/the-robot-sends-a-group-message#)インターフェースの戻りパラメータ processQueryKey フィールドから取得できます。 |
