---
title: "ファイルプレビューまたは編集情報の取得"
---

本インターフェースを呼び出すことで、ストレージスペース内のファイルのプレビューまたは編集リンクを取得できます。権限を持つユーザーはリンクを通じてファイルのプレビューまたは編集操作を行えます。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | `https://api.dingtalk.io/v1.0/storage/spaces/{spaceId}/dentries/{dentryId}/openInfos/query` |
| HTTP Method | POST |
| サポートされるアプリタイプ | appType-社内アプリ　appType-サードパーティ社内アプリ |
| 権限要件 | permission-Storage.File.Read-企業ストレージファイル読み取り権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | はい | 本インターフェース呼び出しのアクセス認証情報。以下の方法で取得します：   - 社内アプリの場合、[社内アプリの access_token を取得](https://open.dingtalk.io/document/development/obtain-the-access-token-of-an-internal-app)インターフェースを呼び出して取得します。 - サードパーティ社内アプリの場合、[サードパーティアプリで権限付与された企業の access_token を取得](https://open.dingtalk.io/document/development/obtain-the-access-token-of-the-authorized-enterprise-1)インターフェースを呼び出して取得します。 |

### パスパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| spaceId | String | はい | スペース ID。[スペース追加](https://open.dingtalk.io/document/development/add-space)インターフェースを呼び出して id パラメータの値を取得できます。 |
| dentryId | String | はい | ファイル ID。[ファイルまたはフォルダーのリストを取得](https://open.dingtalk.io/document/development/get-a-list-of-files-or-folders)または [dentryUuid から spaceId と dentryId を取得](https://open.dingtalk.io/document/development/api-getdentryidbyuuid)インターフェースを呼び出して id パラメータの値を取得できます。 |

### クエリパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| unionId | String | はい | 操作者の unionId。[ユーザー詳細の照会](https://open.dingtalk.io/document/development/query-user-details)インターフェースを呼び出して unionid パラメータの値を取得できます。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| option | Object | いいえ | オプションパラメータ。 |
| version | Long | いいえ | 指定するファイルのバージョン番号。[ファイルまたはフォルダーのリストを取得](https://open.dingtalk.io/document/development/get-a-list-of-files-or-folders)インターフェースを呼び出して id パラメータの値を取得できます。 |
| type | String | いいえ | ファイルの開き方：   - **PREVIEW**：プレビュー、デフォルト - **EDIT**：編集 |
| waterMark | Boolean | いいえ | 透かしの要否：   - **true**：必要 - **false**：不要、デフォルト   現在、透かしに対応しているのは WPS 形式ファイル（Word、Excel、PPT、Pdf）のみです。 |
| checkLogin | Boolean | いいえ | DingTalk のログイン状態をチェックするかどうか。現在、type パラメータの値が PREVIEW の場合のみ有効です。   - **true**：チェックします。ページに入る際に DingTalk のログイン状態を検証します。ログイン状態がない場合はログインページにリダイレクトされ、ログイン成功後に現在のページへ続けてリダイレクトされます。 - **false**（デフォルト）：チェックしません。ページに入る際に DingTalk のログイン状態を検証しませんが、以下の制限があります：    - ベーシックなドキュメント形式ファイル（Word、Excel、PPT、Pdf）、一部の画像形式（jpg、jpeg、jpe、png、gif、bmp、pcx、jiff、tiff、tif、ico、fax、wbmp、webp）およびすべての種類の音声・動画ファイルに対応します。プレビューウィンドウ右上の副本転送、オンライン編集、ダウンロードなどの機能操作はサポートされません。   - リンク取得後、1 回のみアクセス可能です（ブラウザ session 単位）。   - リンク取得後、5 分間使用しないと自動的に失効します。 |
