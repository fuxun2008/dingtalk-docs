---
title: "アプリ情報の取得"
description: "アプリのストレージスペース情報を取得して組織 ID や容量などを確認します"
---

本インターフェースを呼び出すことで、現在のアプリに対応するストレージスペース情報を取得できます。例えば、アプリ所属企業の組織 ID、アプリ識別子、容量情報などです。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/v1.0/storage/currentApps/query |
| HTTP Method | POST |
| サポートされるアプリタイプ | appType-社内アプリ　appType-サードパーティ社内アプリ |
| 権限要件 | permission-Storage.App.Read-企業ストレージアプリの読み取り権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | はい | 本インターフェース呼び出し時のアクセス認証情報。以下の方法で取得します。   - 社内アプリの場合は、[社内アプリの access_token を取得](/ja/open/development/obtain-the-access-token-of-an-internal-app#)インターフェースを呼び出して取得します。 - サードパーティ社内アプリの場合は、[サードパーティアプリで権限付与済み企業の access_token を取得](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#)インターフェースを呼び出して取得します。 |

### クエリパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| unionId | String | はい | 操作者の unionId。[ユーザー詳細の照会](/ja/open/development/query-user-details#)インターフェースを呼び出して取得できます。 |

## レスポンス

### レスポンスボディ

| 名前 | タイプ | 説明 |
| --- | --- | --- |
| app | Object | 企業ストレージアプリの情報。 |
| corpId | String | アプリ所属企業の組織 ID。 |
| appId | String | アプリ識別子。 |
| name | String | アプリ名。 |
| createTime | String | アプリスペースの作成時間。iso8601 形式。例：2022-07-29T14:55Z。 |
| modifiedTime | String | アプリスペースの編集時間。iso8601 形式。例：2022-07-29T14:55Z。 |
| partitions | Array | パーティション情報のリスト。 |
| partitionType | String | パーティションタイプ。   - **PUBLIC_OSS_PARTITION**：パブリッククラウド OSS ストレージパーティション - **MINI_OSS_PARTITION**：専用 MiniOSS ストレージパーティション |
| quota | Object | 容量情報。 |
| used | Long | 使用済み容量。単位は Byte。 |
| max | Long | 最大容量。単位は Byte。      現在のアプリに quota 容量が設定されていない場合は、このフィールドは返されません。 |
| reserved | Long | 事前割り当ての残り容量。単位は Byte。      管理画面ではアプリまたはスペースに容量を事前割り当てできます。このフィールドは事前割り当てされた残り容量、つまり事前割り当て容量のうち未使用部分を表します。事前割り当て容量が設定されていない場合、このフィールドは空となります。 |
| type | String | 容量タイプ。   - **SHARE**：企業共有容量 - **PRIVATE**：専有容量 |
