---
title: "スペースを追加"
---

本 API を呼び出して、企業クラウドドライブに新しいスペースを作成します。作成したスペース内では、フォルダーの作成やファイルのアップロードなどの操作が可能です。

## API 呼び出し説明

### ストレージスペースの紹介

- ストレージスペースは企業クラウドドライブの一部ですが、本 API で追加したスペースはクライアントサイドのクラウドドライブからは表示されません。
- ストレージスペースは企業クラウドドライブの容量を消費します。

### ストレージスペースの分類

- ユーザースペース、つまり USER スペース。このスペース内のファイルには永続的な権限のみ付与でき、権限付与者が管理権限を持っている必要があります。
- アプリスペース、つまり APP スペース。このスペース内のファイルには一時的な権限のみ付与でき、権限付与者に管理権限は不要です。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/v1.0/storage/spaces |
| HTTP Method | POST |
| サポートされるアプリタイプ | appType-社内アプリ　appType-サードパーティ社内アプリ |
| 必要な権限 | permission-Storage.Space.Write-企業ストレージスペース書き込み権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | はい | 本 API を呼び出すためのアクセス認証情報。以下の方法で取得します。   - 社内アプリの場合、[社内アプリの accessToken を取得](https://open.dingtalk.io/document/development/obtain-the-access-token-of-an-internal-app#) API を呼び出して取得します。 - サードパーティ社内アプリの場合、[サードパーティアプリで権限付与された企業の accessToken を取得](https://open.dingtalk.io/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#) API を呼び出して取得します。 |

### クエリパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| unionId | String | はい | 操作者の unionId。[ユーザー詳細の照会](https://open.dingtalk.io/document/development/query-user-details#) API を呼び出して取得します。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| option | Object | いいえ | オプションパラメータ。 |
| name | String | いいえ | スペース名。デフォルトではスペース名なし。 |
| quota | Long | いいえ | スペースが使用できる最大容量。単位は Byte。      このパラメータを指定しない場合、スペース容量に具体的な制限はありませんが、企業クラウドドライブの総容量を超えることはできません。 |
| capabilities | Object | いいえ | スペースの機能項目。デフォルトでは拡張機能項目を設定しません。 |
| canSearch | Boolean | いいえ | 検索をサポートするかどうか。   - **true**：サポートする - **false**：サポートしない、デフォルト値。 |
| canRename | Boolean | いいえ | スペース名の名前を変更をサポートするかどうか。   - **true**：サポートする - **false**：サポートしない、デフォルト値。 |
| canRecordRecentFile | Boolean | いいえ | 最近使用したものリストへの登録をサポートするかどうか。   - **true**：サポートする - **false**：サポートしない、デフォルト値。 |
| scene | String | いいえ | スペースシーン。このパラメータは開発者がカスタムで指定します。       - このパラメータを指定しない場合、デフォルト値は default です。 - このパラメータ値 + sceneId が既に存在する場合、本 API は作成済みのスペースを返し、新しいスペースは作成しません。 |
| sceneId | String | いいえ | スペースシーン ID。このパラメータ値は開発者がカスタムで指定します。       - このパラメータを指定しない場合、デフォルト値は 0 です。 - パラメータ sceneId + このパラメータ値が既に存在する場合、本 API は作成済みのスペースを返し、新しいスペースは作成しません。 |
| ownerType | String | いいえ | owner タイプ。   - **USER**：ユーザータイプ、デフォルト値 - **APP**：App タイプ |

| max | Long | 最大容量。単位は Byte。       - 現在のアプリ容量が max に設定されている場合、現在のアプリ容量に上限が設定されていることを表し、used パラメータ値は max パラメータ値を超えることができません。 - 現在のアプリ容量が max に設定されていない場合は空を返します。この場合、アプリは該当企業の残り使用可能容量を共有します。 |
| reserved | Long | 事前割り当ての残り容量。単位は Byte。      管理バックエンドではアプリまたはスペースに容量を事前に割り当てることができます。このフィールドは事前割り当ての残り容量、つまり事前割り当て容量のうち未使用部分を表します。事前割り当て容量が設定されていない場合、このフィールドは空です。 |
| type | String | 容量タイプ。   - **SHARE**: 共有容量。このモードでは Quota.max が空となり、企業容量を共有することを表します。 - **PRIVATE**: 事前割り当て容量（専用容量）。このモードでは Quota.max に値を設定すると、容量を独占することを表します。       単一のアプリの使用可能容量が他のアプリの影響を受けないようにする必要がある場合、事前割り当て容量（専用容量）を使用できます。 |
