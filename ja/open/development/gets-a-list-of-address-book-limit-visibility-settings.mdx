---
title: "限定公開連絡先設定リストの取得"
---

本 API を呼び出すことで、連絡先の表示制限設定情報のリストを取得します。

## API 呼び出し説明

企業が [限定公開連絡先設定の新規追加または変更](/ja/open/development/add-or-modify-visibility-settings-for-address-book-restrictions#) API を呼び出した後、本 API を呼び出して企業配下の限定公開連絡先設定情報をページング検索できます。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/v1.0/contact/restrictions/settings |
| HTTP Method | GET |
| 対応アプリタイプ | appType-社内アプリ |
| 権限要件 | permission-Contact.Visibility.ReadWrite-連絡先データ表示範囲管理権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | はい | 本 API を呼び出すためのアクセス認証情報。[社内アプリのアクセストークンを取得](/ja/open/development/obtain-the-access-token-of-an-internal-app#) API を呼び出して取得します。 |

### クエリパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| nextToken | Long | いいえ | ページングカーソル。   - 初回呼び出し時は、このパラメータを指定しません。 - 2 回目以降の呼び出し時は、前回の呼び出しで返された nextToken を指定します。 |
| maxResults | Integer | いいえ | 最大返却結果数。最大値は 100 です。 |

### リクエスト例

HTTP

```http
GET /v1.0/contact/restrictions/settings?nextToken=1&maxResults=100 HTTP/1.1
Host:api.dingtalk.io
x-acs-dingtalk-access-token:xxxxx
Content-Type:application/json
```

## レスポンス

### レスポンスボディ

| 名前 | タイプ | 説明 |
| --- | --- | --- |
| hasMore | Boolean | さらにデータがあるかどうか。   - true：あり - false：なし |
| nextToken | Long | ページングカーソル。 |
| list | Array | 限定公開連絡先設定リスト。 |
| id | Long | 設定 ID。 |
| name | String | 限定公開連絡先設定の名称。 |
| description | String | 限定公開連絡先の説明。 |
| subjectUserIds | Array of String | 連絡先の表示を制限する対象ユーザーの userId リスト。 |
| subjectDeptIds | Array of Long | 連絡先の表示を制限する対象部門の deptId リスト。 |
| subjectTagIds | Array of Long | 連絡先の表示を制限する対象ロールの roleId。 |
| type | String | 制限タイプ。   - excludeNode：ホワイトリスト内のユーザーと部門のみ表示可能。 - onlySelf：本人のみ表示可能。 - onlySelfDeptAndChild：自身が所属する部門および子部門のみ表示可能。 |
| excludeUserIds | Array of String | ホワイトリスト内のユーザー userId リスト。 |
| excludeDeptIds | Array of Long | ホワイトリスト内の部門 deptId リスト。 |
| excludeTagIds | Array of Long | ホワイトリスト内のロール roleId リスト。 |
| active | Boolean | 有効かどうか。   - true：有効 - false：無効 |
| restrictInUserProfile | Boolean | プロフィールページの閲覧も同時に制限するかどうか。   - true：はい - false：いいえ |
| restrictInSearch | Boolean | 検索も同時に制限するかどうか。   - true：はい - false：いいえ |
