title: "予約済み会議室のキャンセル"

本インターフェースを呼び出して、予定で予約済みの会議室をキャンセルします。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | `https://api.dingtalk.io/v1.0/calendar/users/{userId}/calendars/{calendarId}/events/{eventId}/meetingRooms/batchRemove` |
| HTTP Method | POST |
| サポートするアプリタイプ | appType-社内アプリ　appType-サードパーティ社内アプリ |
| 権限要件 | permission-Calendar.Event.Write-カレンダーアプリの予定書き込み権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | はい | 本インターフェースを呼び出すためのアクセス認証情報。以下の方法で取得します:   - 社内アプリの場合、[社内アプリの access_token を取得](https://open.dingtalk.io/document/development/obtain-the-access-token-of-an-internal-app#)インターフェースを呼び出して取得します。 - サードパーティ社内アプリの場合、[サードパーティアプリが認可された企業の access_token を取得](https://open.dingtalk.io/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#)インターフェースを呼び出して取得します。 |

### パスパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| userId | String | はい | 予定の主催者の unionId。[ユーザー詳細の照会](https://open.dingtalk.io/document/development/query-user-details#)インターフェースを呼び出して取得できます。 |
| calendarId | String | はい | 予定が属するカレンダー ID。**primary** で統一されており、ユーザーのメインカレンダーを示します。 |
| eventId | String | はい | 予定 ID。[予定リストの照会](https://open.dingtalk.io/document/development/query-an-event-list#)インターフェースを呼び出して id パラメータの値を取得できます。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| meetingRoomsToRemove | Array | いいえ | 予約をキャンセルする会議室情報のリスト。 |
| roomId | String | いいえ | 予約をキャンセルする会議室の roomId。[単一の予定詳細の照会](https://open.dingtalk.io/document/development/query-details-about-an-event#)インターフェースを呼び出して取得した roomId パラメータの値を使用します。 |
