この API を呼び出して、作業フローを使用しない承認インスタンスを作成します。返された承認インスタンス ID は、以降の API 呼び出しで使用するため保存してください。

## API 呼び出し説明

オープン API に無効なデータが渡されるのを防ぐため、この API では受信データに対してより厳格な検証を行います。

- 単一選択コントロールと複数選択コントロールでは、渡すオプション値をすべてオプションリストに設定しておく必要があります。
- 社内連絡先コントロールでは、渡す userID が現在の組織の在籍メンバーのものである必要があります。
- 部門コントロールでは、部門 ID が現在の組織内の有効な部門 ID である必要があります。
- 関連承認フォームコントロールでは、渡すインスタンス ID が現在の組織内に存在する承認インスタンス ID である必要があります。

フォームのデータ検証の強化が適用されると、これらのルールに違反して申請された承認フォームは作成に失敗する場合があります。
