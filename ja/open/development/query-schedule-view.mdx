---
title: "予定ビューの照会"
description: "特定ユーザーの一定期間内の予定を照会し、繰り返し予定を展開して取得します"
---

本 API を呼び出すことで、特定ユーザーの一定期間内の予定リストを照会し、予定の見出し、開始日、開始時刻、終了日、終了時刻などの情報を取得できます。

## API 呼び出し説明

- 本 API と**予定リストの照会** API との違いは、繰り返し予定の取り扱いにあります。本 API は繰り返しルールに基づき、照会期間内のすべての繰り返し予定を展開しますが、データベース内に実際のインスタンスを生成することはありません。例えば、1月1日から開始される毎日繰り返しの予定がある場合、照会時点が1月4日で、照会期間が1月1日から1月10日であるとき、本 API は1月1日から1月10日までのすべての繰り返し予定を返しますが、[予定リストの照会](/ja/open/development/query-an-event-list#) API では1月4日以降の予定は返されません。
- 返された予定オブジェクトの seriesMasterId が空かどうかにより、その予定が繰り返し予定のインスタンスであるかを判断できます。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | `https://api.dingtalk.io/v1.0/calendar/users/{userId}/calendars/{calendarId}/eventsview` |
| HTTP Method | GET |
| 対応アプリタイプ | appType-社内アプリ　appType-サードパーティ社内アプリ　appType-サードパーティ個人アプリ |
| 必要な権限 | permission-Calendar.Event.Read-カレンダーアプリにおける予定の読み取り権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | はい | 本 API を呼び出すためのアクセス認証情報。以下の方法で取得します。   - 社内アプリの場合、[社内アプリの accessToken を取得](/ja/open/development/obtain-the-access-token-of-an-internal-app#) API を呼び出して取得します。 - サードパーティ社内アプリの場合、[サードパーティアプリ認可企業の accessToken を取得](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#) API を呼び出して取得します。 - サードパーティ個人アプリの場合、[ユーザートークンを取得](/ja/open/development/obtain-user-token#) API を呼び出して取得します。 |

### パスパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| userId | String | はい | 照会対象ユーザーの unionId。   - 社内アプリおよびサードパーティ社内アプリの場合、[ユーザー詳細の照会](/ja/open/development/query-user-details#) API を呼び出して unionid パラメータ値を取得します。 - サードパーティ個人アプリの場合、[ユーザーの連絡先プロフィールを取得](/ja/open/development/dingtalk-retrieve-user-information#) API を呼び出して unionId パラメータ値を取得します。 |
| calendarId | String | はい | 予定が属するカレンダー ID。[カレンダーの照会](/ja/open/development/query-a-calendar#) API を呼び出して現在のユーザーの予定を照会します。**primary** キーワードを使用すると、現在のユーザーのプライマリカレンダーを表します。 |

### クエリパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| timeMin | String | いいえ | 予定終了時刻 >= TimeMin を照会します。ISO-8601 の date-time 形式です。 |
| timeMax | String | いいえ | 予定開始時刻 `< timeMax` を照会します。ISO-8601 の date-time 形式です。 |
| maxResults | Integer | いいえ | 最大返却レコード数。最大値 100、デフォルト 100。 |
| maxAttendees | Integer | いいえ | 各予定の参加者照会件数。デフォルト 100、最大 100。参加人数が 100 人を超え、すべての参加者を取得する必要がある場合は、[予定参加者の取得](/ja/open/development/get-the-participants-of-a-schedule#) API を使用して取得してください。 |
| nextToken | String | いいえ | ページングカーソル。1 回の照会条件ですべての結果を返せない場合、ページングトークンが返されます。次回の照会時にそのトークンを付与すると、後続のデータが返されます。ページングトークンが null になるまで、すべてのデータが照会完了したことを意味します。 |
