---
title: "フィルターの削除"
---

本 API を呼び出すと、指定したワークシート上のグローバルフィルターを削除し、フィルター条件によって非表示にされていたすべての行を再表示できます。現在のフィルター状態をクリアして完全なデータビューに戻したい場合、たとえばデータエクスポート前にフィルターを削除して全量データのエクスポートを保証するシーンに適しています。

## API 呼び出し説明

API 呼び出しに成功すると、すべての列のフィルター条件と並び替え状態も同時にクリアされます。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | `https://api.dingtalk.io/v1.0/doc/workbooks/{workbookId}/sheets/{sheetId}/deleteFilter` |
| HTTP Method | POST |
| サポートされるアプリタイプ | appType-社内アプリ |
| 権限要件 | permission-Document.Workbook.Write-スプレッドシート書き込み権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | はい | この API を呼び出すためのアクセス認証情報です。[社内アプリの accessToken を取得](/ja/open/development/obtain-the-access-token-of-an-internal-app) API を呼び出して取得できます。 |

### パスパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| workbookId | String | はい | スプレッドシートファイル ID です。[ナレッジベース API](/ja/open/development/knowledge-base-overview) が返す `nodeId(dentryUuid)` がスプレッドシートの `workbookId` です。[ノードの取得](https://open.dingtalk.com/document/orgapp/get-node) および [ナレッジベースドキュメントの作成](/ja/open/development/create-team-space-document) API を呼び出して取得できます。 |
| sheetId | String | はい | ワークシートの ID または名前です。[すべてのワークシートを取得](/ja/open/development/obtain-all-worksheets) API を呼び出して id または name パラメータ値を取得できます。 |

### クエリパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| operatorId | String | はい | 操作者の unionId。   - [サイレントログインコードによるユーザー情報の取得](/ja/open/development/obtain-the-userid-of-a-user-by-using-the-log-free) API で unionid パラメータ値を取得できます。 - [ユーザー詳細のクエリ](/ja/open/development/query-user-details) API を呼び出して unionid パラメータ値を取得できます。       操作者に権限がない場合、API はエラー `The operator has no permission` を返します。 |
