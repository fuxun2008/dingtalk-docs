---
title: "行の高さを自動調整"
---

本 API を呼び出すと、指定したフォントサイズに合わせて DingTalk スプレッドシート内の指定行の行の高さを自動調整し、コンテンツを完全に表示できます。

## API 呼び出し説明

- 指定した `fontWidth`（フォントサイズ）に基づき、指定範囲内の各行の高さを自動調整し、コンテンツを完全に表示します。
- `row`（開始行カーソル）と `rowCount`（行数）で自動調整の対象範囲を指定します。
- 行カーソルは 0 から始まります。つまり 1 行目のカーソルは 0 です。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | `https://api.dingtalk.io/v1.0/doc/workbooks/{workbookId}/sheets/{sheetId}/autofitRows` |
| HTTP Method | POST |
| サポートするアプリタイプ | appType-社内アプリ |
| 必要な権限 | permission-Document.Workbook.Write-DingTalk スプレッドシート書き込み権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | はい | 本 API を呼び出すためのアクセス認証情報です。[社内アプリのアクセストークンを取得](https://open.dingtalk.io/document/development/obtain-the-access-token-of-an-internal-app) API を呼び出して取得できます。 |

### パスパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| workbookId | String | はい | スプレッドシートファイル ID です。`nodeId`（dentryUuid）を渡せばスプレッドシートの `workbookId` となります。[ノードを取得](https://open.dingtalk.io/document/development/get-knowledge-base-acquisition-node) および [ナレッジベースドキュメントを作成](https://open.dingtalk.io/document/development/create-team-space-document) API を呼び出して取得できます。 |
| sheetId | String | はい | ワークシートの ID またはタイトルです。[すべてのワークシートを取得](https://open.dingtalk.io/document/development/obtain-all-worksheets.md) API を呼び出して取得するか、ワークシートのタイトルを入力します。 |

### クエリパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| operatorId | String | はい | 操作者の unionId です。[ユーザー詳細を照会](https://open.dingtalk.io/document/development/query-user-details) API を呼び出して取得できます。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| row | Long | はい | 行番号。0 から始まります。 |
| rowCount | Long | はい | 行数。 |
| fontWidth | Long | はい | フォントサイズ。 |

### リクエスト例
