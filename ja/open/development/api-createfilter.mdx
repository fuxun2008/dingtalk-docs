---
title: "フィルターを作成する"
---

本 API を呼び出すと、スプレッドシートの指定したワークシート上にグローバルフィルターを作成し、フィルター範囲を指定できます。テーブルデータに対して行レベルの絞り込み表示が必要なシーン、例えば営業レポートで特定エリアやステータスのデータのみを表示する場合などに適しています。

## API 呼び出し説明

- API 呼び出しに成功した後、フィルター条件を設定する API を使用して各列のフィルタールールを設定できます。条件を満たさない行は自動的に非表示になります。
- 各ワークシートで作成できるグローバルフィルターは 1 つのみです。すでにフィルターが存在する場合はエラーが返ります。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | `https://api.dingtalk.io/v1.0/doc/workbooks/{workbookId}/sheets/{sheetId}/createFilter` |
| HTTP Method | POST |
| サポートするアプリタイプ | appType-社内アプリ |
| 必要な権限 | permission-Document.Workbook.Write-スプレッドシート書き込み権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | はい | この API を呼び出すためのアクセス認証情報。[社内アプリの accessToken を取得](/ja/open/development/obtain-the-access-token-of-an-internal-app) API を呼び出して取得します。 |

### パスパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| workbookId | String | はい | スプレッドシートファイルの ID。[ナレッジベース API](https://open.dingtalk.io/document/orgapp/knowledge-base-overview) が返す `nodeId(dentryUuid)` がスプレッドシートの `workbookId` に相当し、[ノードを取得](https://open.dingtalk.io/document/orgapp/get-node) および [ナレッジベースドキュメントを作成](https://open.dingtalk.io/document/orgapp/create-team-space-document) API を呼び出して取得できます。 |
| sheetId | String | はい | ワークシートの ID または名前。[すべてのワークシートを取得](https://open.dingtalk.io/document/orgapp/obtain-all-worksheets) API を呼び出して id または name パラメータの値を取得します。 |

### クエリパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| operatorId | String | はい | 操作者の unionId。   - [サイレントログインコードでユーザー情報を取得](https://open.dingtalk.io/document/orgapp/obtain-the-userid-of-a-user-by-using-the-log-free) API を呼び出して unionid パラメータの値を取得できます。 - [ユーザー詳細を取得](https://open.dingtalk.io/document/orgapp/query-user-details) API を呼び出して unionid パラメータの値を取得できます。       操作者に権限がない場合、API は `The operator has no permission` というエラーを返します。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| range | String | はい | フィルター範囲。A1 表記を使用します。例えば `A1:D10` は A1 から D10 までの範囲を表します。フィルター範囲の最初の行は見出し行として扱われ、フィルター計算には含まれません。 |
| criteria | `Map<String, Object>` | いいえ | 任意。フィルターの作成時に各列のフィルター条件を同時に設定します。key は列のオフセット（フィルター範囲の先頭列からの相対値、0 から始まる文字列）、value はその列のフィルター条件オブジェクト（FilterCriteria）です。指定しない場合は空のフィルターが作成されます。 |
|  | Object | いいえ | 現在の列のフィルター条件 |
| filterType | String | いいえ | フィルタータイプ。指定可能な値:   - **values**: 値で絞り込み - **color**: 色で絞り込み - **condition**: 条件で絞り込み |
| visibleValues | Array of String | いいえ | 表示する値 |
| conditions | Array | いいえ | フィルター条件の配列。最大 2 個。`filterType` が `condition` の場合のみ指定が必要です。 |
| operator | String | いいえ | 条件演算子。指定可能な値:   - **equal**: 等しい - **not-equal**: 等しくない - **contains**: 含む - **not-contains**: 含まない - **starts-with**: 〜で始まる - **not-starts-with**: 〜で始まらない - **ends-with**: 〜で終わる - **not-ends-with**: 〜で終わらない - **greater**: より大きい - **greater-equal**: 以上 - **less**: より小さい - **less-equal**: 以下 |
| value | String | いいえ | 条件値 |
| conditionOperator | String | いいえ | 複数の条件間の関係。`"and"`（デフォルト）または `"or"`。`filterType` が `condition` の場合のみ指定が必要です。 |
| backgroundColor | String | いいえ | 背景色で絞り込み。16 進数のカラー値（例: `"#FF0000"`）。`filterType` が `color` の場合のみ指定します。 |
| fontColor | String | いいえ | フォント色で絞り込み。16 進数のカラー値（例: `"#0000FF"`）。`filterType` が `color` の場合のみ指定します。 |
