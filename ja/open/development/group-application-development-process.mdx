## グループ拡張機能の開発プロセスの概要

作業を開始する前に、[DingTalk開発者になる](https://open.dingtalk.com/document/app/become-a-dingtalk-developer#topic-2024337)の事前準備を完了していることを確認してください。グループアプリの開発プロセスは以下のとおりです。

1. [社内アプリを開発する](https://open.dingtalk.com/document/org/create-orgapp#topic-2024342)。グループ拡張機能の開発は社内アプリをベースにする必要があります。社内アプリがない場合は、[アプリを作成](https://open.dingtalk.com/document/org/create-orgapp#topic-2024342)してください。すでにお持ちの場合は、既存のアプリをそのままご利用ください。
2. [メッセージプッシュを設定する](https://open.dingtalk.com/document/org/configure-push-settings#topic-2199272)。**メッセージプッシュ**で、ボットのバインドを設定・開発します。
3. [グループ拡張機能のベーシック情報を設定する](https://open.dingtalk.com/document/org/configure-the-basic-information-of-the-group-application#topic-2199273)。社内アプリの**クールアプリ拡張**セクションで、グループ拡張機能を有効化し、ベーシック情報を設定します。作成が成功すると、グループ拡張機能アプリのコードを取得できます。
4. [インタラクティブカードを開発する](https://open.dingtalk.com/document/org/interactive-card#topic-2199274)（任意）。ボットをバインドして、インタラクティブカードなどを送信します。
5. [グループ拡張機能アプリを有効化する](https://open.dingtalk.com/document/org/install-group-applications#topic-2199277)。グループアプリの開発が完了したら、**グループに追加**し、クールアプリセンターで有効化します。
6. [グループ拡張機能アプリを使用する](https://open.dingtalk.com/document/org/install-group-applications#topic-2199277)。社内のグループアプリバーで、クールアプリを表示して使用します。

## グループ拡張機能の共通 API

グループ拡張機能の共通 API については、[グループ拡張機能の共通 API](https://open.dingtalk.com/document/orgapp-server/api-operations-for-group-applications#topic-2198333)を参照してください。

グループ拡張機能のクライアントサイド API については、[クールアプリをインストールしてグループに追加する](https://open.dingtalk.com/document/orgapp-client/install-cool-applications-and-add-them-to-the-group#topic-2209393)を参照してください。
