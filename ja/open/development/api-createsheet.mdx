本インターフェースを呼び出して、AIテーブル内に新しいデータテーブルを作成します。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | `https://api.dingtalk.io/v1.0/notable/bases/{baseId}/sheets` |
| HTTP Method | POST |
| サポートされるアプリタイプ | appType-社内アプリ |
| 権限要件 | permission-Notable.Base.Write.All-AIテーブルアプリ書き込み権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | はい | 本インターフェースを呼び出すためのアクセス認証情報。[社内アプリの access_token を取得](/ja/open/development/obtain-the-access-token-of-an-internal-app#) インターフェースを呼び出して取得します。 |

### パスパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| baseId | String | はい | AIテーブル ID。取得方法は [データ構造](/ja/open/development/data-structure#) を参照してください。 |

### クエリパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| operatorId | String | はい | 操作者の unionId。以下の 2 つの方法で取得できます。   - [ユーザー詳細の照会](/ja/open/development/query-user-details#) インターフェースを呼び出して取得します。 - [サイレントログインコードによるユーザー情報の取得](/ja/open/development/obtain-the-userid-of-a-user-by-using-the-log-free#) インターフェースを呼び出して取得します。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| name | String | いいえ | データテーブル名。 |
| fields | Array | いいえ | データテーブルフィールドに関連する設定。 |
| name | String | はい | フィールド名。 |
| type | String | はい | フォールド種類。サポートされるタイプは [フィールド属性](https://open.dingtalk.com/document/development/field-properties#) を参照してください。 |
| property | `Map<String, Any>` | いいえ | フィールド属性。具体的なフォーマットは [フィールド属性](https://open.dingtalk.com/document/development/field-properties#) を参照してください。 |
|  | Any | いいえ | フィールド属性。タイプの異なるフィールドには異なる属性設定があります。 |
