---
title: "フィルターの更新"
---

本インターフェースを呼び出すことで、グローバルフィルターにおける複数列のフィルターを一括で更新できます。複数列に対してフィルタールールの設定、変更、またはクリアを同時に行う必要があるシーンに適しています。たとえば、データ分析レポートで、メンバー、金額範囲、マークカラーといった複数の観点で同時に絞り込みを行う場合などです。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | `https://api.dingtalk.io/v1.0/doc/workbooks/{workbookId}/sheets/{sheetId}/filter/updateFilter` |
| HTTP Method | POST |
| サポートされるアプリタイプ | appType-社内アプリ |
| 必要な権限 | permission-Document.Workbook.Write-スプレッドシート書き込み権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | はい | 本インターフェースを呼び出すためのアクセス認証情報です。[社内アプリのアクセストークンを取得する](/zh/open/development/obtain-the-access-token-of-an-internal-app)インターフェースを呼び出して取得できます。 |

### パスパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| workbookId | String | はい | スプレッドシートファイル ID。[ナレッジベース API](https://open.dingtalk.io/document/orgapp/knowledge-base-overview) が返す `nodeId(dentryUuid)` がスプレッドシートの `workbookId` です。[ノードの取得](https://open.dingtalk.io/document/orgapp/get-node)および[ナレッジベースドキュメントの作成](https://open.dingtalk.io/document/orgapp/create-team-space-document)インターフェースを呼び出して取得できます。 |
| sheetId | String | はい | ワークシート ID または名前。[すべてのワークシートを取得](https://open.dingtalk.io/document/orgapp/obtain-all-worksheets)インターフェースを呼び出して、id または name パラメータの値を取得できます。 |

### クエリパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| operatorId | String | はい | 操作者の unionId。   - [サイレントログインコードでユーザー情報を取得](https://open.dingtalk.io/document/orgapp/obtain-the-userid-of-a-user-by-using-the-log-free)インターフェースから unionid パラメータの値を取得できます。 - [ユーザー詳細の照会](https://open.dingtalk.io/document/orgapp/query-user-details)インターフェースを呼び出して unionid パラメータの値を取得できます。       操作者に権限がない場合、インターフェースは `The operator has no permission` というエラーを返します。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| criteria | `Map<String, Object>` | はい | 列オフセットからフィルターへのマッピング。Key は列オフセット（フィルター範囲の先頭列を基準とした、0 から始まる文字列）、Value はその列のフィルターオブジェクトまたは `null`（その列のフィルターをクリアすることを意味します）です。 |
|  | Object | いいえ | 該当列に対応するフィルター |
| filterType | String | いいえ | フィルタータイプ。指定可能な値：   - **values**：値で絞り込み - **color**：色で絞り込み - **condition**：条件で絞り込み |
| visibleValues | Array of String | いいえ | 表示する値 |
| conditions | Array | いいえ | フィルター条件の配列。最大 2 個。`filterType` が `condition` の場合のみ指定します。 |
| operator | String | いいえ | 条件の演算子。指定可能な値：   - **equal**：等しい - **not-equal**：等しくない - **contains**：含む - **not-contains**：含まない - **starts-with**：で始まる - **not-starts-with**：で始まらない - **ends-with**：で終わる - **not-ends-with**：で終わらない - **greater**：より大きい - **greater-equal**：以上 - **less**：より小さい - **less-equal**：以下 |
| value | String | いいえ | 条件値 |
| conditionOperator | String | いいえ | 複数条件間の関係。`"and"`（デフォルト）または `"or"`。`filterType` が `condition` の場合のみ指定します。 |
| backgroundColor | String | いいえ | 背景色で絞り込み。16 進カラー値（例：`"#FF0000"`）。`filterType` が `color` の場合のみ指定します。 |
| fontColor | String | いいえ | フォント色で絞り込み。16 進カラー値（例：`"#0000FF"`）。`filterType` が `color` の場合のみ指定します。 |
