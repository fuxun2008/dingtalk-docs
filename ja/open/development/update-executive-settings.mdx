---
title: "高管モードの設定"
description: "社員の高管モードを有効にし、ビデオ通話など複数シナリオで通信相手を制限します"
---

本 API を呼び出して、社員の高管モードを設定します。

## API 呼び出し説明

社員を高管に設定すると、設定された遮断シナリオにおいて、同一企業内では他の高管、高管ホワイトリスト内のユーザー、および高管の連絡先のみが連絡可能となります。それ以外のユーザーは連絡できません。例：userA を高管に設定し、遮断シナリオを VIDEO_CALL、ホワイトリストユーザーに userB を設定します。userB と userC は同一企業の一般社員で、userA と連絡先関係がない場合、userB は userA に対してビデオ通話を発信できますが、userC は userA に対してビデオ通話を発信できません。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/v1.0/contact/seniorSettings |
| HTTP Method | POST |
| サポートされるアプリタイプ | appType-社内アプリ |
| 権限要件 | permission-qyapi_manage_addresslist-連絡先メンテナンスの API アクセス権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | はい | この API を呼び出すためのアクセス認証情報。[社内アプリの accessToken を取得](/ja/open/development/obtain-the-access-token-of-an-internal-app#) を呼び出して取得します。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| seniorStaffId | String | はい | 設定する社員の userid。 |
| open | Boolean | はい | 高管モードをオンにするかどうか。値：   - **true**：高管モードをオン - **false**：高管モードを閉じる |
| permitStaffIds | Array of String | いいえ | 高管ホワイトリスト社員の userid リスト。      パラメータ **permitStaffIds**、**permitDeptIds**、**permitTagIds** のリスト内要素の合計は最大 200 件です。 |
| permitDeptIds | Array of Long | いいえ | 高管ホワイトリスト部門リスト。      パラメータ **permitStaffIds**、**permitDeptIds**、**permitTagIds** のリスト内要素の合計は最大 200 件です。 |
| permitTagIds | Array of Long | いいえ | 高管ホワイトリストロールリスト。      パラメータ **permitStaffIds**、**permitDeptIds**、**permitTagIds** のリスト内要素の合計は最大 200 件です。 |
| protectScenes | Array of String | いいえ | 高管遮断シナリオ。値：   - **DING_SMS**：SMS Ding メッセージ - **DING_MSG**：アプリ内 Ding メッセージ - **CHAT**：IM チャット（個別チャット、グループチャット） - **CONFERENCE_VIDEO**：ビデオ会議 - **CONFERENCE**：ビデオ会議 - **VIDEO_CALL**：ビデオ通話 - **CONFERENCE_VOIP**：音声通話 - **CALL**：電話会議、オフィス電話 - **SEARCH**：電話会議内の検索機能 - **CALL_CENTER**：コールセンター |
