title: "会議室情報の更新"

本 API を呼び出して、会議室情報を更新します。

## API 呼び出し説明

会議室情報を更新できるのは、スマート会議室アプリの管理権限を持つ管理者のみです。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/v1.0/rooms/meetingRooms |
| HTTP Method | PUT |
| サポートするアプリタイプ | appType-社内アプリ　appType-サードパーティ社内アプリ |
| 必要な権限 | permission-VideoConference.Conference.Write-ビデオ会議情報の管理権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | はい | この API を呼び出す際のアクセス認証情報。以下の方法で取得します。   - 社内アプリの場合は、[社内アプリの accessToken を取得](https://open.dingtalk.io/document/development/obtain-the-access-token-of-an-internal-app) を呼び出して取得します。 - サードパーティ社内アプリの場合は、[サードパーティアプリの認可企業の accessToken を取得](https://open.dingtalk.io/document/development/obtain-the-access-token-of-the-authorized-enterprise-1) を呼び出して取得します。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| unionId | String | はい | 操作者の unionId。[ユーザー詳細の照会](https://open.dingtalk.io/document/development/query-user-details) を呼び出して取得します。 |
| roomId | String | はい | 会議室 ID。[会議室リストの照会](https://open.dingtalk.io/document/development/check-the-meeting-room-list) を呼び出して取得します。 |
| roomName | String | いいえ | 会議室名。 |
| roomCapacity | Integer | いいえ | 会議室の収容人数。 |
| roomPicture | String | いいえ | 会議室の画像。 |
| roomStatus | Integer | いいえ | 会議室の状態。   - **0**：全員が利用可能 - **1**：管理者のみ利用可能 - **2**：一部のメンバーに権限あり |
| roomLocation | Object | いいえ | 会議室の位置情報。 |
| title | String | いいえ | 会議室の位置の見出し。 |
| desc | String | いいえ | 会議室の位置の詳細情報。 |
| roomLabelIds | Array of Long | いいえ | タグ ID。   - **1**：テレビ - **2**：電話番号 - **3**：プロジェクター - **4**：ホワイトボード - **5**：ビデオ会議 |
| isvRoomId | String | いいえ | 呼び出し側の外部会議室 ID。呼び出し側は自社システム内の会議室 ID を渡せます。      外部会議室と関連付けない場合は、自社のエンティティ会議室番号を渡せます。 |
| groupId | Long | いいえ | 会議室が属するグループ ID。[会議室グループリストの照会](https://open.dingtalk.io/document/development/query-meeting-rooms-groups) を呼び出して取得します。 |
| reservationAuthority | Object | いいえ | roomStatus が「一部権限」の場合に設定する、会議室の予約権限。 |
| authorizedMembers | Array | いいえ | 権限を持つユーザーリスト。 |
| memberId | String | いいえ | ユーザーの ID。memberType の設定により異なります。   - **メンバー**：ユーザーの unionId。[ユーザー詳細の照会](https://open.dingtalk.io/document/development/query-user-details) を呼び出して取得します。 - **部門**：部門 ID、dept_id。[部門リストの取得](https://open.dingtalk.io/document/development/obtain-the-department-list-v2) を呼び出して dept_id のパラメータ値を取得します。 |
| memberType | String | いいえ | ユーザーのタイプ。   - **メンバー**：user - **部門**：dept |
| memberName | String | いいえ | ユーザーの名前：   - **メンバー**：ユーザー名 - **部門**：部門名 |
| enableCycleReservation | Boolean | いいえ | 会議室が定期予約をサポートするかどうか。   - **true**：はい - **false**：いいえ |
| openReservation | Boolean | いいえ | 会議室を予約可能として開放するかどうか。   - **true**：はい - **false**：いいえ |
| roomDescription | String | いいえ | 会議室の説明情報。 |
