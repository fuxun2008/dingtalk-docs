この API を呼び出すと、シフト設定のルールに基づいて自動計算された各社員の休暇時間を取得できます。

## リクエスト

| **基本情報** | |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/topapi/attendance/getleaveapproveduration |
| HTTP メソッド | POST |
| 対応アプリタイプ | appType-社内アプリ appType-サードパーティ社内アプリ |
| 必要な権限 | permission-qyapi_base-組織の API を呼び出すために必要なベーシック権限 |

### クエリパラメータ

| 名前 | タイプ | 必須 | 例 | 説明 |
| --- | --- | --- | --- | --- |
| access_token | String | はい | bE74xxxx | この API を呼び出すためのアプリ認証情報です。   - 社内アプリ：[社内アプリの access_token を取得](/ja/open/development/obtain-orgapp-token)を呼び出して取得します。 - サードパーティ社内アプリ：サードパーティ企業の access_token を取得する API を呼び出して取得します。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 例 | 説明 |
| --- | --- | --- | --- | --- |
| userid | String | はい | user123 | 社内における社員のユーザー ID です。組織はこのフィールドでユーザーを一意に識別します。 |
| from_date | Date | はい | 2016-03-09 11:11:11 | 休暇の開始日時です。 |
| to_date | Date | はい | 2016-03-10 11:11:11 | 休暇の終了日時です。 |

### リクエスト例

```curl
curl -X POST "https://api.dingtalk.io/topapi/attendance/getleaveapproveduration" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=6777xxxx6f4eff' \
-d 'from_date=2016-03-09+11%3A11%3A11' \
-d 'to_date=2016-03-10+11%3A11%3A11' \
-d 'userid=zhangsan'
```

Java

```text
DingTalkClient client = new DefaultDingTalkClient("https://api.dingtalk.io/topapi/attendance/getleaveapproveduration");
OapiAttendanceGetleaveapprovedurationRequest req = new OapiAttendanceGetleaveapprovedurationRequest();
req.setUserid("user123");
req.setFromDate(StringUtils.parseDateTime("2016-03-09 11:11:11"));
req.setToDate(StringUtils.parseDateTime("2016-03-10 11:11:11"));

```

C#

```text
IDingTalkClient client = new DefaultDingTalkClient("https://api.dingtalk.io/topapi/attendance/getleaveapproveduration");
OapiAttendanceGetleaveapprovedurationRequest req = new OapiAttendanceGetleaveapprovedurationRequest();
req.Userid = "zhangsan";
req.FromDate = DateTime.Parse("2016-03-09 11:11:11");

```

## レスポンス

### レスポンスボディ

| 名前 | タイプ | 例 | 説明 |
| --- | --- | --- | --- |
| result | ApproveDurationForTopVo |  | 返却結果です。 |
| duration_in_minutes | Number | 0 | 休暇時間（分単位）です。 |
| errcode | Number | 0 | 戻りコードです。 |
| errmsg | String | ok | 戻りコードの説明です。 |
| request_id | String | 3ynh2gp5ndke | リクエスト ID です。 |

### レスポンスボディの例

```json
{
  "errcode": 0,
  "errmsg":"ok",
  "result": {
    "duration_in_minutes": 480
  },
  "request_id": "6porp1hqkb9k"
}
```

### エラーコード

この API の呼び出しでエラーが返された場合は、エラーメッセージをもとに[グローバルエラーコード](/ja/open/development/server-api-error-codes-1)ドキュメントで解決方法を検索してください。
