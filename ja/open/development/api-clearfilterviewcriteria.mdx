---
title: "フィルタービュー条件の削除"
---

本 API を呼び出すと、指定したフィルタービューにおける特定の列のフィルター条件を解除し、その列をフィルター計算の対象から除外できます。個人フィルタービューにおいて、他の列の絞り込み状態は維持したまま特定列のフィルタールールのみを取り消したい場合に利用します。

## API 呼び出し説明

クリア操作は現在のフィルタービューにのみ影響し、グローバルフィルターや他のフィルタービューには影響しません。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | `https://api.dingtalk.io/v1.0/doc/workbooks/{workbookId}/sheets/{sheetId}/filterViews/{filterViewId}/clearColumnFilterCriteria` |
| HTTP Method | POST |
| サポートするアプリタイプ | appType-社内アプリ |
| 必要な権限 | permission-Document.Workbook.Write-スプレッドシート書き込み権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | 必須 | この API を呼び出すためのアクセス認証情報です。[社内アプリの access_token を取得する](/ja/open/development/obtain-the-access-token-of-an-internal-app) API を呼び出して取得できます。 |

### パスパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| workbookId | String | 必須 | スプレッドシートファイルの ID です。[ナレッジベース API](https://open.dingtalk.io/document/orgapp/knowledge-base-overview) から返される `nodeId(dentryUuid)` がスプレッドシートの `workbookId` に該当します。[ノードの取得](https://open.dingtalk.io/document/orgapp/get-node) および [ナレッジベースドキュメントの作成](https://open.dingtalk.io/document/orgapp/create-team-space-document) API を呼び出して取得できます。 |
| sheetId | String | 必須 | ワークシートの ID または名称です。[全ワークシートの取得](https://open.dingtalk.io/document/orgapp/obtain-all-worksheets) API を呼び出して、id または name パラメータの値を取得できます。 |
| filterViewId | String | 必須 | フィルタービューの ID です。 |

### クエリパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| operatorId | String | 必須 | 操作者の unionId です。   - [サイレントログインコードによるユーザー情報の取得](https://open.dingtalk.io/document/orgapp/obtain-the-userid-of-a-user-by-using-the-log-free) API を呼び出して unionid パラメータの値を取得できます。 - [ユーザー詳細の照会](https://open.dingtalk.io/document/orgapp/query-user-details) API を呼び出して unionid パラメータの値を取得できます。       操作者に権限がない場合、API は `The operator has no permission` というエラーを返します。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| column | Long | 必須 | 列オフセットです。フィルタービュー範囲の先頭列を基準とし、0 から始まります。例えばフィルタービュー範囲が `B1:E10` の場合、`column=0` は B 列、`column=1` は C 列を表します。 |

### リクエスト例

```http
POST /v1.0/doc/workbooks/e54Lq3xxx/sheets/Sheet1/filterViews/fv-xxxxx/clearColumnFilterCriteria?operatorId=ppgAxxx HTTP/1.1
Host:api.dingtalk.io
x-acs-dingtalk-access-token:f86e0bxxx
Content-Type:application/json

{
  "column" : 0
}
```
