---
title: "フローティング画像の作成"
---

本インターフェースを呼び出すことで、DingTalk スプレッドシートの指定されたワークシート内のすべてのフローティング画像のリスト情報を取得できます。エクスポート、同期、監査など、ワークシート内のフローティング画像を一括で読み取る必要があるシーンに適用できます。戻り値には、各画像の一意の識別子、画像アドレス、アンカー位置、サイズオフセット情報が含まれます。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | `https://api.dingtalk.io/v1.0/doc/workbooks/{workbookId}/sheets/{sheetId}/floatImages` |
| HTTP Method | POST |
| サポートされるアプリタイプ | appType-社内アプリ |
| 権限要件 | permission-Document.Workbook.Write-DingTalk スプレッドシート書き込み権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | はい | 本インターフェースを呼び出すためのアクセス認証情報です。[社内アプリの accessToken を取得する](/ja/open/development/obtain-the-access-token-of-an-internal-app)インターフェースを呼び出して取得できます。 |

### パスパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| workbookId | String | はい | スプレッドシートのファイル ID。[ナレッジベース API](/ja/open/development/knowledge-base-overview) から返される `nodeId(dentryUuid)` がスプレッドシートの `workbookId` です。[ノードを取得する](https://open.dingtalk.com/document/development/get-node)および[ナレッジベースドキュメントを作成する](/ja/open/development/create-team-space-document)インターフェースを呼び出して取得できます。 |
| sheetId | String | はい | ワークシート ID または見出し。[すべてのワークシートを取得する](/ja/open/development/obtain-all-worksheets)インターフェースを呼び出して、id およびワークシートの見出しを取得できます。 |

### クエリパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| operatorId | String | はい | 操作者の unionId。[ユーザー詳細を照会する](/ja/open/development/query-user-details)インターフェースを呼び出して取得できます。操作者に権限がない場合、インターフェースは `The operator has no permission` というエラーを返します。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| src | String | はい | フローティング画像のリソースアドレス。[リソースアップロード情報を取得する](/ja/open/development/api-getresourceuploadinfo)インターフェースを呼び出して `resourceUrl` を取得する必要があります。 |
| anchor | Object | はい | フローティング画像の位置情報。 |
| row | Integer | はい | 何行目を基準に位置を指定するか。カーソルは 0 から始まります。 |
| col | Integer | はい | 何列目を基準に位置を指定するか。カーソルは 0 から始まります。 |
| coordinate | Object | はい | 幾何情報の設定。 |
| width | double | はい | 画像の幅を指定します。単位：ピクセル。 |
| height | double | はい | 画像の高さを指定します。単位：ピクセル。 |
| offsetX | double | はい | 位置指定座標に対する水平方向のオフセット量。単位：ピクセル。 |
| offsetY | double | はい | 位置指定座標に対する垂直方向のオフセット量。単位：ピクセル。 |
