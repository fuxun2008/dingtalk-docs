title: "ユーザーのフリー/ビジー情報を取得する"

本インターフェースを呼び出して、指定したユーザーリストの指定期間内のフリー/ビジー情報を照会します。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | `https://api.dingtalk.io/v1.0/calendar/users/{userId}/querySchedule` |
| HTTP Method | POST |
| サポートされるアプリタイプ | appType-社内アプリ　appType-サードパーティ社内アプリ　appType-サードパーティ個人アプリ |
| 必要な権限 | permission-Calendar.EventSchedule.Read-カレンダーアプリにおける予定のフリー/ビジー状態の読み取り権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | 必須 | 本インターフェースを呼び出すためのアクセス認証情報。以下の方法で取得します。   - 社内アプリの場合は、[社内アプリの access_token を取得する](/ja/open/development/obtain-the-access-token-of-an-internal-app#)インターフェースを呼び出して取得します。 - サードパーティ社内アプリの場合は、[サードパーティアプリの認可企業の access_token を取得する](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#)インターフェースを呼び出して取得します。 - サードパーティ個人アプリの場合は、[ユーザートークンを取得する](/ja/open/development/obtain-user-token#)インターフェースを呼び出して取得します。 |

### パスパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| userId | String | 必須 | 本リクエストのリソースが帰属するユーザーの unionId。   - 社内アプリおよびサードパーティ社内アプリの場合は、[ユーザー詳細を照会する](/ja/open/development/query-user-details#)インターフェースを呼び出して unionid パラメータの値を取得します。 - サードパーティ個人アプリの場合は、[ユーザーの連絡先プロフィールを取得する](/ja/open/development/dingtalk-retrieve-user-information#)インターフェースを呼び出して unionId パラメータの値を取得します。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| userIds | Array of String | 必須 | 照会対象ユーザーの unionId。   - 社内アプリおよびサードパーティ社内アプリの場合は、[ユーザー詳細を照会する](/ja/open/development/query-user-details#)インターフェースを呼び出して unionid パラメータの値を取得します。 - サードパーティ個人アプリの場合は、[ユーザーの連絡先プロフィールを取得する](/ja/open/development/dingtalk-retrieve-user-information#)インターフェースを呼び出して unionId パラメータの値を取得します。       ユーザーリストの最大長は 20 です。 |
| startTime | String | 必須 | 照会の開始時刻。 |
| endTime | String | 必須 | 照会の終了時刻。 |
