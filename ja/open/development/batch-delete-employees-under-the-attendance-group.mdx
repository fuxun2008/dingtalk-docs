この API を呼び出して、指定した勤怠グループからメンバーを一括削除します。

## API 呼び出し説明

この API は勤怠グループ内の勤怠対象者のみを削除します。勤怠に参加している部門は削除されません。

## リクエスト

| **基本情報** | |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/topapi/attendance/group/users/remove |
| HTTP メソッド | POST |
| 対応アプリタイプ | appType-社内アプリ |
| 権限 | permission-qyapi_attendance_group_manage-勤怠グループ管理権限 |

### クエリパラメータ

| 名前 | タイプ | 必須 | 例 | 説明 |
| --- | --- | --- | --- | --- |
| access_token | String | はい | 4c9ebd2b153xxxx | この API を呼び出すためのアプリ認証情報です。[社内アプリの access_token を取得する](/ja/open/development/obtain-orgapp-token) API を呼び出して取得してください。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 例 | 説明 |
| --- | --- | --- | --- | --- |
| op_userid | String | いいえ | user01 | 操作者の userId です。 |
| group_key | String | はい | 0151E0223B1xxxx | 勤怠グループ ID です。 **注意** 勤怠グループの識別子が group_id の場合は、[groupId から groupKey への変換](/ja/open/development/groupid-to-groupkey) API を呼び出して、group_id を group_key に変換してください。 |
| user_id_list | String[] | はい | user01,user02 | ユーザーリストです。1 回の呼び出しで最大 100 件の userId を指定できます。 |

### リクエスト例

```curl
curl -X POST "https://api.dingtalk.io/topapi/attendance/group/users/remove" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=49ceexxxx4c192' \
-d 'group_key=0151E022xxxx917E876' \
-d 'op_userid=123456' \
-d 'user_id_list=123456%2C123457'
```

Java

```text

```
