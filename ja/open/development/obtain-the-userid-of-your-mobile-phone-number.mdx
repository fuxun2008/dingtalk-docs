---
title: "携帯電話番号で企業アカウントユーザーを検索"
description: "携帯電話番号から企業アカウント内のユーザーのユーザー ID を取得し、社員情報の確認や管理を効率化します"
---

本インターフェースを呼び出すことで、携帯電話番号から企業アカウントユーザーの userId を取得できます。社員が退職している場合は、携帯電話番号からユーザーの userId を取得できません。

## リクエスト

| **基本情報** | |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/topapi/v2/user/getbymobile |
| HTTP Method | POST |
| サポートされるアプリタイプ | appType-社内アプリ |
| 権限要件 | permission-qyapi_get_member_by_mobile-携帯電話番号でユーザーの基本情報を取得する権限 |

### クエリパラメータ

| 名前 | タイプ | 必須 | 例 | 説明 |
| --- | --- | --- | --- | --- |
| access_token | String | はい | be3Fxxxx | 当該インターフェースを呼び出すためのアプリ認証情報。[社内アプリの access_token を取得する](/ja/open/development/obtain-orgapp-token)インターフェースから取得します。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 例 | 説明 |
| --- | --- | --- | --- | --- |
| mobile | String | はい | 185xxxxx676 | ユーザーの携帯電話番号。 |
| support_exclusive_account_search | Boolean | はい | true | 携帯電話番号による企業アカウント検索をサポートするかどうか。   - **true**：サポートします。 - **fasle**：サポートしません。   **説明**     - 企業アカウントのみ適用されます。 - 現在の企業で作成された企業アカウントのみ検索可能です。 |

### リクエスト例

```curl
curl -X POST "https://api.dingtalk.io/topapi/v2/user/getbymobile" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=a16xxxxa2efbee' \
-d 'mobile=1851xxxx676' \
-d 'support_exclusive_account_search=true'
```

## レスポンス

### レスポンスボディ

| 名前 | タイプ | 例 | 説明 |
| --- | --- | --- | --- |
| request_id | String | 5w82ciuur781 | リクエスト ID。 |
| errcode | Number | 0 | リターンコード。 |
| errmsg | String | ok | リターンコードの説明。 |
| result | Object |  | 戻り結果。 |
| userid | String | zhangsan | 社員の userId。 |
| exclusive_account_userid_list | String[] | ["zxxxx","lixxxi"] | 企業アカウント社員の userId リスト。  **説明**  現在の組織で作成された企業アカウントのみ返されます。 |

### レスポンスボディ例

```json
{
  "errcode":"0",
  "result":{
    "exclusive_account_userid_list":"[\"zxxxx\",\"lixxxi\"]",
    "userid":"zhangsan"
  },
  "errmsg":"ok"
}
```

### エラーコード

当該インターフェースの呼び出しでエラーが発生した場合は、エラーメッセージをもとに[グローバルエラーコード](/ja/open/development/server-api-error-codes-1)ドキュメントから解決策を検索してください。

| エラーコード（errcode） | エラーコードの説明（errmsg） | 解決策 |
| --- | --- | --- |
| 400002 | 無効なパラメータ | 上記ドキュメントの要件に従ってパラメータが入力されているかご確認ください |
| 40104 | 企業内で無効な携帯電話番号 | 携帯電話番号が正しいかご確認ください |
| 60121 | 該当ユーザーが見つかりません | 入力情報が正しいかご確認ください |
| -1 | システムが混雑しています | 後で再度お試しください |
