---
title: "ドキュメント全体を上書きする（アプリ認可）"
---

この API を呼び出すと、Markdown 形式でドキュメント全体のコンテンツを上書きできます。

## 権限

この API を呼び出すには、以下のいずれかの権限が必要です。

| アプリタイプ | サポート可否 | 権限 | API Explorer デバッグ |
| --- | --- | --- | --- |
| 社内アプリ | サポート | 企業ストレージファイル書き込み権限 | [API Explorer](https://open-dev.dingtalk.io/apiExplorer#/?devType=org&api=doc_1.0%23DocUpdateContent) |
| サードパーティ社内アプリ | 未サポート | 未サポート | 未サポート |
| サードパーティ個人アプリ | 未サポート | 未サポート | 未サポート |

## HTTP メソッド

```http
POST /v1.0/doc/suites/documents/{docKey}/overwriteContent?operatorId=String HTTP/1.1
Host:api.dingtalk.io
x-acs-dingtalk-access-token:String
Content-Type:application/json

{
  "dataType" : "String",
  "content" : "String"
}
```

## Header パラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | 必須 | この API を呼び出すためのアクセス認証情報。[社内アプリのアクセストークンを取得](/ja/open/development/obtain-the-access-token-of-an-internal-app) API を呼び出して取得します。 |

## Path パラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| docKey | String | 必須 | ドキュメント ID（ドキュメントの docKey または dentryUuid）。[ナレッジベースドキュメントの作成](/ja/open/development/create-team-space-document) API を呼び出してドキュメントを作成した後、レスポンスから `docKey` パラメータを取得します。  **説明**  ドキュメント URL から `dentryUuid` を取得する場合、https://alidocs.dingtalk.io/i/nodes/Z9xxxxa-id を例にすると、dentryUuid は Z9xxxxa-id です。 |

## Query パラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| operatorId | String | 必須 | ユーザーの unionId。[ユーザー詳細の取得](/ja/open/development/query-user-details) API を呼び出して unionid パラメータの値を取得できます。 |

## Body パラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| dataType | String | 任意 | 上書きするコンテンツのデータ形式。値：   - **markdown**：上書き対象のコンテンツが markdown 形式です（デフォルト）。 |
| content | String | 必須 | 書き込むコンテンツの文字列。注意事項：   - dataType が **markdown** の場合、ここには markdown 形式の文字列を指定します。 - 最大長は 50000 文字です。 |

## レスポンスパラメータ

| 名前 | タイプ | 説明 |
| --- | --- | --- |
| success | Boolean | リクエストが成功したかどうか。 |
| result | Object | リクエスト結果。 |
| data | `Map<String, Any>` | リクエスト結果。 |
|  | Any | リクエスト結果。 |
