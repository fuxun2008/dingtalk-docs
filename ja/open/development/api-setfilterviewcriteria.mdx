---
title: "フィルタービュー条件の設定"
description: "フィルタービューで列単位にフィルター条件を設定して担当プロジェクトやタスクを絞り込みます"
---

本 API を呼び出すことで、指定したフィルタービュー内の特定の列にフィルター条件を設定または更新できます。個人のフィルタービューで単一列のデータ表示範囲を細かく制御するシナリオに適しています。たとえば、個人の業務ビューで自分が担当するプロジェクトのみを表示したり、特定の色マーキングで優先度の高いタスクを絞り込んだりする場合に利用できます。

## API 呼び出し説明

フィルタービューの条件は現在のビューにのみ影響し、他のユーザーが見るデータは変更されません。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | `https://api.dingtalk.io/v1.0/doc/workbooks/{workbookId}/sheets/{sheetId}/filterViews/{filterViewId}/setColumnFilterCriteria` |
| HTTP Method | POST |
| サポートするアプリタイプ | appType-社内アプリ |
| 必要な権限 | permission-Document.Workbook.Write-スプレッドシート書き込み権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | はい | 本 API を呼び出すためのアクセス認証情報です。[社内アプリの accessToken を取得](/ja/open/development/obtain-the-access-token-of-an-internal-app) API を呼び出して取得できます。 |

### パスパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| workbookId | String | はい | スプレッドシートファイルの ID です。[ナレッジベース API](/ja/open/development/knowledge-base-overview) が返す `nodeId(dentryUuid)` がスプレッドシートの `workbookId` に該当します。[ノードの取得](https://open.dingtalk.com/document/orgapp/get-node) および [ナレッジベースドキュメントの作成](/ja/open/development/create-team-space-document) API を呼び出して取得できます。 |
| sheetId | String | はい | ワークシートの ID または名前です。[すべてのワークシートを取得](/ja/open/development/obtain-all-worksheets) API を呼び出して id または name パラメータの値を取得できます。 |
| filterViewId | String | はい | フィルタービューの ID |

### クエリパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| operatorId | String | はい | 操作者の unionId。   - [サイレントログインコードでユーザー情報を取得](/ja/open/development/obtain-the-userid-of-a-user-by-using-the-log-free) API で unionid パラメータの値を取得できます。 - [ユーザー詳細の照会](/ja/open/development/query-user-details) API を呼び出して unionid パラメータの値を取得できます。       操作者に権限がない場合、API は `The operator has no permission` エラーを返します。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| column | Long | はい | 列オフセット。フィルタービュー範囲の先頭列を基準に 0 から始まります。たとえばフィルタービュー範囲が `B1:E10` の場合、`column=0` は B 列、`column=1` は C 列を表します。 |
| filterCriteria | Object | はい | フィルター条件オブジェクト。 |
| filterType | String | はい | フィルタータイプ。指定可能な値：   - **values**：値で絞り込み - **color**：色で絞り込み - **condition**：条件で絞り込み |
| visibleValues | Array of String | いいえ | 表示する値 |
| backgroundColor | String | いいえ | 背景色で絞り込む際の表示色。16 進数形式（例：`#FF0000`）。`filterType` が `color` の場合、`backgroundColor` と `fontColor` のいずれかが必須です。 |
| fontColor | String | いいえ | フォント色で絞り込む際の表示色。16 進数形式（例：`#00FF00`）。`filterType` が `color` の場合、`backgroundColor` と `fontColor` のいずれかが必須です。 |
| conditions | Array | いいえ | 条件で絞り込む際の条件リスト。最大 2 件まで設定可能です。`filterType` が `condition` の場合は必須です。 |
| operator | String | いいえ | 条件演算子。指定可能な値：   - **equal**：等しい - **not-equal**：等しくない - **contains**：含む - **not-contains**：含まない - **starts-with**：で始まる - **not-starts-with**：で始まらない - **ends-with**：で終わる - **not-ends-with**：で終わらない - **greater**：より大きい - **greater-equal**：以上 - **less**：より小さい - **less-equal**：以下 |
| value | String | いいえ | 条件値 |
| conditionOperator | String | いいえ | 複数条件間の論理関係。指定可能な値： \* **and**：かつ（デフォルト） \* **or**：または。 `conditions` に 2 件の条件が含まれる場合に有効です。 |

### エラーコード

本 API の呼び出しでエラーが発生した場合は、エラーメッセージをもとに [グローバルエラーコード](/ja/open/development/server-api-error-codes-1) のドキュメントで解決方法をご確認ください。

| HttpCode | エラーコード | エラーメッセージ | 説明 |
| --- | --- | --- | --- |
| 400 | invalidRequest.inputArgs.invalid | %s | リクエストパラメータが不正です。エラーメッセージをご確認ください。 |
| 400 | invalidRequest.inputArgs.workbookIdIllegal | The workbookId is illegal. | workbookId が不正です。 |
| 400 | invalidRequest.resource.notWorkbook | %s | サポートされていないドキュメントタイプです。workbookId をご確認ください。 |
| 400 | invalidRequest.document.stillInitializing | The document is still initializing. Please try again later. | ドキュメントを初期化中です。後で再試行してください。 |
| 403 | forbidden.accessDenied | The operator has no permission. | 現在のユーザーには本操作の権限がありません。 |
| 403 | forbidden.acrossOrg | %s | リクエストが不正です。アクセス対象のドキュメントが accessToken で指定された組織に所属しているかご確認ください。 |
| 403 | forbidden.operationIllegal | %s | リクエスト操作が不正です。エラーメッセージをご確認ください。 |
| 403 | forbidden.document.sizeOverLimit | The document size is over limit and the server is unable to complete your request. Retry is unlikely to work unless the document size is decreased. | スプレッドシートのコンテンツが大きすぎます。コンテンツを削減してください。 |
| 404 | invalidRequest.resource.notFound | %s | リクエストが失敗しました。アクセス対象のリソースが見つかりません。 |
| 500 | serviceBusy | The server is busy and unable to complete your request. Please try again later. | サービスが混雑しています。後で再試行してください。 |
| 500 | internalError | The server encountered an internal error and was unable to complete your request. Please try again later. | サービス内部エラーが発生しました。後で再試行してください。 |
