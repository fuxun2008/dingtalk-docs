サードパーティ企業アプリは、メッセージテンプレートを通じてメッセージ通知を送信できます。

メッセージテンプレートは、業務通知によるメッセージのプッシュをアップグレードしたものです。メッセージテンプレートに対して、よりシンプルで標準化された開発・設定の体験を提供するとともに、顧客側でより安全で管理・制御しやすいメッセージ通知機能を実現します。

**重要**

メッセージテンプレートを使用する際は、次の点にご注意ください。

- **サードパーティ企業アプリ**のみサポートされます。
- 承認済みのメッセージテンプレートのみ、業務通知メッセージのプッシュに使用できます。

## テンプレートのタイプ

現在、以下の3種類のメッセージテンプレートのタイプがサポートされています。

- Markdown テンプレート

  Markdown テンプレートは、Markdown 構文を使用してメッセージを設定・送信します。操作を必要としない純粋な通知メッセージのタイプに適しています。Markdown テンプレートを使うと、テキスト、画像、リンクなどの表示形式を簡単にサポートできます。
- ActionCard テンプレート

  ActionCard テンプレートは、ActionCard メッセージタイプを使用してメッセージを送信します。コンテンツと操作ポイントを組み合わせたメッセージをサポートし、メッセージ内で1つ以上の操作ポイントを使ってタスクを迅速に処理する必要があるシナリオに適しています。

  ActionCard テンプレートは、Markdown テンプレートを基盤とし、全体ジャンプと個別ジャンプの両方のスタイルをサポートします。
- フォームテンプレート

  フォームテンプレートは、OA メッセージタイプに基づいてメッセージを送信します。注文などのメッセージの表示に適しており、メッセージの詳細を表示するためのジャンプをサポートします。

## 利用手順

以下の図に示すように、メッセージテンプレートを使用して業務通知を送信するには、次の操作が必要です。

1. メッセージテンプレートを作成して設定します。詳しくは、[メッセージテンプレートの管理](/zh/open/development/manage-message-templates)を参照してください。
2. テンプレートを審査に通します。
3. API を呼び出し、テンプレートを使用して業務通知を送信します。詳しくは、[テンプレートを使用した業務通知メッセージの送信](/zh/open/development/work-notification-templating-send-notification-interface)を参照してください。
