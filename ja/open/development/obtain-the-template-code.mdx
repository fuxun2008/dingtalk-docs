---
title: "テンプレートコードの取得"
description: "承認テンプレート名から processCode（テンプレートコード）を取得する作業フロー API です。"
---

この API を呼び出すと、承認テンプレートの名前を指定して、その processCode を取得できます。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/v1.0/workflow/processCentres/schemaNames/processCodes |
| HTTP メソッド | GET |
| 対応アプリタイプ | appType-社内アプリ　appType-サードパーティ社内アプリ |
| 必要な権限 | permission-Workflow.Form.Read-作業フローテンプレートの読み取り権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | はい | この API を呼び出すためのアクセス認証情報です。取得方法は次のとおりです。   - 社内アプリ：[社内アプリのアクセストークンの取得](/ja/open/development/obtain-the-access-token-of-an-internal-app) API を呼び出します。 - サードパーティ社内アプリ：サードパーティアプリを承認した組織のアクセストークンを取得する API を呼び出します。 |

### クエリパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| name | String | はい | テンプレート名です。最大 64 文字です。承認テンプレートの作成または更新を行う API のリクエストパラメータで、フォームテンプレート名フィールド `name` から取得します。 |

### リクエスト例

HTTP

```http
GET /v1.0/workflow/processCentres/schemaNames/processCodes?name=名前 HTTP/1.1
Host:api.dingtalk.io
x-acs-dingtalk-access-token:6d1bxxxx
Content-Type:application/json
```
