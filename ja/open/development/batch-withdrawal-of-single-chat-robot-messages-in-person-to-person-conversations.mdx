---
title: "個人間チャットにおけるボットメッセージの一括送信取消"
---

本 API を呼び出して、チャット ID、ボットコード、メッセージ ID リストに基づき、個人間チャットにおけるボットメッセージを一括で送信取消します。企業のメッセージ送信ミスを取り消すシーンに適しています。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/v1.0/robot/privateChatMessages/batchRecall |
| HTTP Method | POST |
| 対応アプリタイプ | appType-社内アプリ　appType-サードパーティ社内アプリ |
| 必要な権限 | permission-qyapi_robot_sendmsg-社内ボットのメッセージ送信権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | はい | 本 API を呼び出すためのアクセス認証情報です。以下の方法で取得します。   - 社内アプリの場合は、[社内アプリの access_token を取得する](/ja/open/development/obtain-the-access-token-of-an-internal-app#) API を呼び出して取得します。 - サードパーティ社内アプリの場合は、[サードパーティアプリで権限付与された企業の access_token を取得する](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#) API を呼び出して取得します。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| openConversationId | String | はい | チャット ID。[個人間チャットでボットが通常メッセージを送信する](/ja/open/development/the-robot-sends-ordinary-messages-in-a-person-to-person-conversation#) API または [カードを作成して配信する](https://open.dingtalk.com/document/development/create-and-deliver-cards#) API で使用した openConversationId と一致させる必要があります。 |
| robotCode | String | はい | ボットのコード。[ボット ID](https://open.dingtalk.com/document/development/robot-overview#) を参照してください。  [個人間チャットでボットが通常メッセージを送信する](/ja/open/development/the-robot-sends-ordinary-messages-in-a-person-to-person-conversation#) API で使用した robotCode と一致させる必要があります。 |
| processQueryKeys | Array of String | はい | メッセージ ID。   - 社内アプリの場合は、[カードを作成して配信する](https://open.dingtalk.com/document/development/create-and-deliver-cards#) API または [個人間チャットでボットが通常メッセージを送信する](/ja/open/development/the-robot-sends-ordinary-messages-in-a-person-to-person-conversation#) API を呼び出して、`processQueryKey` パラメータの値を取得できます。 |
