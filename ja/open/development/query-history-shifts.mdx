---
title: "過去のシフトの照会"
description: "シフト ID とバージョンを指定し、過去のシフトをを照会する API です。シフト名、シフト設定、打刻時間、休憩時間を取得できます。"
---

この API を呼び出すと、シフト ID とバージョンを指定して過去のシフトを照会できます。レスポンスには、シフト名、シフト設定、打刻時間、休憩時間が含まれます。

## リクエスト

| **基本情報** | |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/topapi/attendance/shift/history/query |
| HTTP メソッド | POST |
| サポートされるアプリタイプ | appType-社内アプリ |
| 権限 | permission-qyapi_attendance_group_read-勤怠グループの照会権限 |

### クエリパラメータ

| 名前 | タイプ | 必須 | 例 | 説明 |
| --- | --- | --- | --- | --- |
| access_token | String | はい | 73e9xxx | この API の呼び出しに使用するアプリ認証情報です。[社内アプリの access_token の取得](/ja/open/development/obtain-orgapp-token) API を呼び出して取得します。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 例 | 説明 |
| --- | --- | --- | --- | --- |
| op_user_id | String | はい | user123 | 操作者の userId です。 |
| shift_id | Number | はい | 628380875 | シフト ID です。[シフト概要の取得](/ja/open/development/enterprise-shift-query-in-batches) API を呼び出し、id の値を取得します。 |
| version | Number | はい | 624190327 | シフトのバージョンです。[ユーザーのシフト設定情報の一括照会](/ja/open/development/query-batch-scheduling-information) API を呼び出し、shift_version の値を取得します。 |

### リクエスト例

```curl
curl -X POST "https://api.dingtalk.io/topapi/attendance/shift/history/query" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=e56f7xxxxeb7ef1' \
-d 'op_user_id=dd_dd' \
-d 'shift_id=2445' \
-d 'version=222'
```

Java

```java
DingTalkClient client = new DefaultDingTalkClient("https://api.dingtalk.io/topapi/attendance/shift/history/query");
OapiAttendanceShiftHistoryQueryRequest req = new OapiAttendanceShiftHistoryQueryRequest();
req.setOpUserId("user456");
req.setShiftId(715390132L);
req.setVersion(624190327L);
OapiAttendanceShiftHistoryQueryResponse rsp = client.execute(req, access_token);
System.out.println(rsp.getBody());
```

Python

```python
import dingtalk.api

req=dingtalk.api.OapiAttendanceShiftHistoryQueryRequest("https://api.dingtalk.io/topapi/attendance/shift/history/query")

req.op_user_id="dd_dd"
req.shift_id=2445
req.version=222
try:
  resp= req.getResponse(access_token)
  print(resp)
except Exception,e:
  print(e)
```

PHP

```php
include "TopSdk.php";
date_default_timezone_set('Asia/Shanghai');

$c = new DingTalkClient(DingTalkConstant::$CALL_TYPE_OAPI, DingTalkConstant::$METHOD_POST , DingTalkConstant::$FORMAT_JSON);
$req = new OapiAttendanceShiftHistoryQueryRequest;
$req->setOpUserId("dd_dd");
$req->setShiftId("2445");
$req->setVersion("222");
$resp = $c->execute($req, $access_token, "https://api.dingtalk.io/topapi/attendance/shift/history/query");
```

C#

```csharp
IDingTalkClient client = new DefaultDingTalkClient("https://api.dingtalk.io/topapi/attendance/shift/history/query");
OapiAttendanceShiftHistoryQueryRequest req = new OapiAttendanceShiftHistoryQueryRequest();
req.OpUserId = "dd_dd";
req.ShiftId = 2445L;
req.Version = 222L;
OapiAttendanceShiftHistoryQueryResponse rsp = client.Execute(req, access_token);
Console.WriteLine(rsp.Body);
```

## レスポンス

### レスポンスボディ

| 名前 | タイプ | 例 | 説明 |
| --- | --- | --- | --- |
| result | TopShiftVo |  | 照会結果です。 |
| shift_group_name | String | 通常日勤 | シフトグループ名です。 |
| corp_id | String | dinge87fxxx | 組織 ID（corpId）です。 |
| shift_setting | TopShiftSettingVo |  | シフト設定です。 |
| shift_id | Number | 628380875 | シフト ID です。 |
| gmt_modified | Date | 2021-01-14 14:21:03 | シフトの最終更新日時です。 |
| corp_id | String | dinge87fxxx | 組織 ID（corpId）です。 |
| is_deleted | String | N | 削除フラグです。 |
| work_time_minutes | Number | 480 | 勤務時間（分）です。-1 の場合、この機能は無効です。 |
| id | Number | 350530359 | シフト設定 ID です。現在は使用されていません。 |
| attend_days | String | 21 | このシフトの出勤日数です。 |
| gmt_create | Date | 2021-01-14 14:18:08 | 作成時間です。 |
| name | String | 通常日勤 | シフト名です。 |
| id | Number | 241120079 | シフト ID です。 |
| sections | TopSectionVo[] |  | 打刻セクションです。 |
| punches | TopPunchVo[] |  | 打刻ポイントです。 |
| check_type | String | OnDuty | 打刻タイプ：  - **OnDuty**：出勤打刻 - **OffDuty**：退勤打刻 |
| end_min | Number | 1 | 打刻を許可する最大の遅延時間（分）です。 |
| across | Number | 0 | シフトが翌日にまたがるかどうか：  - **0**：翌日にまたがらない - **1**：翌日にまたがる |
| check_time | Date | 1970-01-01 09:00:00 | 打刻時間です。 |
| permit_minutes | Number | 60 | 遅刻または早退の許容時間です。 |
| free_check | Boolean | false | 打刻が免除されるかどうか：  - **true**：打刻不要 - **false**：打刻必須 |
| id | Number | 376955859 | 打刻ポイント ID です。現在は使用されていません。 |
| begin_min | Number | demo | 打刻を許可する最大の前倒し時間（分）です。 |
| work_time_minutes | Number | 480 | 勤務時間（分）です。 |
| rests | TopRestVo[] |  | 休憩セクションです。 |
| check_type | String | OnDuty | 休憩タイプ：  - **OnDuty**：休憩開始 - **OffDuty**：休憩終了 |
| across | Number | 0 | 休憩が翌日にまたがるかどうか（休憩時間が翌日にあたるかどうか）：  - **0**：翌日にまたがらない - **1**：翌日にまたがる |
| check_time | Date | 1970-01-01 12:00:00 | 休憩時間です。 |
| id | Number | 376955861 | 休憩ポイント ID です。 |
| id | Number | 22979360 | 打刻セクション ID です。出勤打刻と退勤打刻の 1 組で 1 セクションとなります。1 つのシフトに複数のセクションを設定できます。 |
| shift_group_id | Number | 22979 | シフトグループ ID です。 |
| success | Boolean | true | 呼び出しに成功したかどうか：  - **true**：成功 - **false**：失敗 |
| errcode | Number | 0 | リターンコードです。 |
| errmsg | String | ok | リターンコードの説明です。 |
| request_id | String | q3ef3y3sogkd | リクエスト ID です。 |
