---
title: "予約会議を作成"
---

作成者、予約会議のタイトル、開始・終了時刻などの情報をもとに予約会議を作成します。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/v1.0/conference/scheduleConferences |
| HTTP Method | POST |
| 対応アプリタイプ | appType-社内アプリ　appType-サードパーティ社内アプリ |
| 必要な権限 | permission-VideoConference.Conference.Write-ビデオ会議情報管理権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | はい | この API を呼び出すためのアクセス認証情報：   - 社内アプリの場合、[社内アプリの accessToken を取得](/ja/open/development/obtain-the-access-token-of-an-internal-app) API を呼び出して取得します。 - サードパーティ社内アプリの場合、[サードパーティアプリ認可企業の accessToken を取得](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1) API を呼び出して取得します。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| creatorUnionId | String | はい | 作成者の unionId。 |
| title | String | はい | 予約会議のタイトル。最大長は 50 文字で、超えた場合は切り捨てられます。256 文字を超えた場合、API 呼び出しは失敗します。 |
| startTime | Long | はい | 予約会議の開始時刻。ミリ秒単位の UTC タイムスタンプ。 |
| endTime | Long | はい | 予約会議の終了時刻。ミリ秒単位の UTC タイムスタンプ。 |
| scheduleConfSettingModel | Object | いいえ | 予約会議の設定。 |
| hostUnionId | String | いいえ | 主催者の unionId。 |
| confAllowedCorpId | String | いいえ | 組織内会議の組織 ID。 |
| lockRoom | Integer | いいえ | 会議をロック：   - **0**：ロック解除 - **1**：ロック |
| screenShareForbidden | Integer | いいえ | 共有の開始：   - **0**：共有を許可 - **1**：共有を禁止 |
| muteOnJoin | Integer | いいえ | ユーザーが会議に参加する際のミュート：   - **-1**：オン - **0**：オフ - **6**：6 人を超える場合に自動的にミュートをオン |
| moziConfVirtualExtraSetting | Object | いいえ | 予約会議の設定。 |
| waitingRoom | Integer | いいえ | 待機室：   - **1**：オン - **2**：オフ |
| joinBeforeHost | Integer | いいえ | 主催者が参加する前に会議に参加：   - **0**：オフ - **1**：オン |
| enableChat | Integer | いいえ | チャットとインタラクション：   - **0**：オフ - **1**：オン |
| lockNick | Integer | いいえ | 自分の名前を変更：   - **0**：自分の名前変更を許可 - **1**：自分の名前変更を禁止 |
| lockMediaStatusMicMute | Integer | いいえ | 自分でミュートを解除：   - **0**：自分でミュート解除を許可 - **1**：自分でミュート解除を禁止 |
| moziConfExtensionAppSettings | Array | いいえ | 会議拡張アプリ設定リスト。 |
| coolAppCode | String | いいえ | クールアプリの appCode。 |
| autoOpenMode | Integer | いいえ | 自動的に開くかどうか：   - **0**：自動的に開かない - **1**：主催者/共同主催者のみ自動的に開く - **2**：全員自動的に開く |
| extensionAppBizData | String | いいえ | 会議ディメンションの拡張アプリのカスタム情報。 |
| enableWebAnonymousJoin | Boolean | いいえ | Web 端からのサイレントログイン参加に対応するかどうか：   - **true**：対応 - **false**：非対応 |
| pushAllMeetingRecords | Boolean | いいえ | すべての議事録をプッシュするかどうか：   - **true**：すべてのレコードをプッシュ - **false**：実際の開催時刻が予約会議の予定時間内に収まっている議事録のみをプッシュ。   予約会議の予定時間外の定義：会議開始時刻 > 予約会議の予定終了時刻、または会議終了時刻 > 予約会議の予定開始時刻。 |
| pushMinutesCard | Boolean | いいえ | 議事録カードをプッシュするかどうか：   - **true**：プッシュ - **false**：プッシュしない   デフォルトはプッシュ。 |
| pushCloudRecordCard | Boolean | いいえ | クラウド録画の議事録カードをプッシュするかどうか：   - **true**：プッシュ - **false**：プッシュしない   デフォルトはプッシュ。 |
| minutesOwnerUnionId | String | いいえ | 議事録の所有者。デフォルトは予約会議の主催者に帰属します。 |
| cloudRecordOwnerUnionId | String | いいえ | クラウド録画の所有者。デフォルトは予約会議の主催者に帰属します。 |
| minutesSummaryTemplateType | String | いいえ | クラウド録画サマリーの指定テンプレート：   - **0**：公式提供のテンプレート。 - **1**：カスタムテンプレート。 |
| minutesSummaryTemplateId | String | いいえ | - `minutesSummaryTemplateType= 0` の場合、公式テンプレートに対応する Id を渡します。 - `minutesSummaryTemplateType = 1` の場合、カスタムテンプレートに対応する id を渡します。 |
| minutesSummaryDiyTemplateVersion | String | いいえ | - `minutesSummaryTemplateType = 0` の場合、渡す必要はありません。 - `minutesSummaryTemplateType = 1` の場合、カスタムテンプレートに対応するバージョン番号を渡す必要があります。 |
| hiddenOwnerNick | Boolean | いいえ | クラウド録画の発起者名を非表示にするかどうか：   - **true**：発起者名を非表示 - **false**（デフォルト）：非表示にしない |
| cohostUnionIds | Array of String | いいえ | 共同主催者の unionId。 |
| moziConfOpenRecordSetting | Object | いいえ | 自動録画設定。 |
| recordAutoStart | Integer | いいえ | クラウド録画を自動的に開始するかどうか：   - **0**：自動的に開始しない - **1**：自動的に開始 |
| recordAutoStartType | Integer | いいえ | クラウド録画の自動開始タイプ：   - **0**：自分が主催者として会議に参加した後に自動開始 - **1**：他の人が共同主催者として会議に参加した後に開始 - **2**：任意の人が任意の身分で会議に参加した後に開始 |
| mode | String | いいえ | 会議録画レイアウト：   - **grid**：グリッドモード（デフォルト 9 グリッド 3x3） - **speech**：発言者モード - **full_screen**：フルスクリーンモード - **auto_grid**：自動グリッドモード（デフォルト最大 4x4 グリッド） - **screen_cast**：画面共有モード（画面共有ストリームのみ配置） - **p2p**：2 人通話モード - **full_screen_and_speaker**：共有コンテンツ + 発言者モード |
| isFollowHost | Boolean | いいえ | 主催者に追従するかどうか：   - **true**：追従する - **false**：追従しない |
| restrictShareMinutesSummaryOnly | Integer | いいえ | 議事録の共有をサマリーのみに制限するかどうか：   - **0**：制限しない - **1**：制限する |
| aiAgentSummarySetting | Object | いいえ | 会議の AI 議事録設定。 |
| value | String | いいえ | AI アシスタント要約をオンにするかどうか：   - **disable**：オフ - **enable**：オン |
| receiverType | Integer | いいえ | 会議後の議事録プッシュ受信範囲：   - **0**：すべてのメンバー - **1**：作成者のみ |
| allowAllParticipantsStart | Integer | いいえ | すべてのメンバーに議事録の開始を許可するかどうか：   - **0**：許可しない - **1**：許可する |
| restrictShareMinutesSummaryOnly | Integer | いいえ | 議事録の共有をサマリーのみに制限するかどうか：   - **0**：制限しない - **1**：制限する |
| enableAiAgentStatus | Boolean | いいえ | AI 議事録機能を表示するかどうか：   - **true**：表示 - **false**：非表示（Android DingTalk バージョン 8.3.20 以上で有効。iOS、PC など他の端末は全て有効） |
