この API を呼び出して、OA承認のタスクを作成します。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/v1.0/workflow/processCentres/tasks |
| HTTP メソッド | POST |
| サポートされるアプリタイプ | appType-社内アプリ　appType-サードパーティ社内アプリ |
| 必要な権限 | permission-qyapi_aflow-承認フローデータ管理権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | はい | この API を呼び出すためのアクセス認証情報です。次の方法で取得します。   - 社内アプリ：[社内アプリのアクセストークンを取得する](/ja/open/development/obtain-the-access-token-of-an-internal-app) API を呼び出します。 - サードパーティ社内アプリ：サードパーティアプリを承認した組織のアクセストークンを取得する API を呼び出します。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| processInstanceId | String | はい | OA承認のワークフローインスタンス ID です。[インスタンスを作成する](/ja/open/development/create-a-ticket-approval-instance) API を呼び出して `processInstanceId` の値を取得します。 |
| activityId | String | いいえ | カスタム承認ノードの ID です。カスタムパラメータで、最大長は 256 文字です。 |
| tasks | Array | はい | タスクリストです。最大 20 要素まで指定できます。 |
| userId | String | いいえ | ユーザー ID です。[部門内のユーザー ID リストを取得する](/ja/open/development/query-the-list-of-department-userids) API を呼び出して取得します。 |
| url | String | いいえ | タスクのリダイレクト URL です。最大長は 1,024 文字です。  - 承認インスタンス作成 API の url は、DingTalk 承認アプリ内の承認フォームにリダイレクトします。 - この API の url は、DingTalk タスクページ上の対応するタスクカードからリダイレクトします。 - DingTalk タスクページはモバイルと PC の両方のクライアントに対応しています。この API に渡す url のページが、モバイルと PC の両方に対応していることを確認してください。 |
| customData | String | いいえ | ユーザーのカスタムデータです。ページのリダイレクト時に URL パラメータとして返されます。最大長は 500 文字です。 |
| dueTimestamp | Long | いいえ | タスクの期限です。ミリ秒単位の Unix タイムスタンプで指定します。設定すると、DingTalk タスクセンターに承認タスクの期限が表示され、期限による並べ替えや、「本日期限」「期限切れ」などのタグによる絞り込みが可能になります。 |
| featureConfig | Object | いいえ | プロセスセンターの連携設定です。タスクおよびカード通知におけるショートカット操作ボタンのエントリをタスクごとに設定します。 |
| features | Array | いいえ | 設定リストです。 |
| name | String | いいえ | サードパーティがカスタマイズできる機能モジュールの名前です。現在サポートされている値は次のとおりです。   - **CUSTOM_SHORTCUT**：タスクおよびカード通知のショートカット操作ボタン |
| pcUrl | String | いいえ | PC 向けのサードパーティカスタムリダイレクトリンクです。最大長は 1,024 文字です。 |
| mobileUrl | String | いいえ | モバイル向けのサードパーティカスタムリダイレクトリンクです。最大長は 1,024 文字です。 |
| runType | String | いいえ | 実行モードです。  features.name が `CUSTOM_SHORTCUT` の場合、次の値をサポートします。   - **ORIGIN**：ネイティブモード。タスクの詳細ページを開くと、公式の承認詳細ページにリダイレクトします。 - **REDIRECT**：外部リダイレクトモード。タスクの詳細ページを開くと、pcUrl または mobileUrl に設定したアドレスにリダイレクトします。 |
| callback | Object | いいえ | ゲートウェイのコールバック設定です。ショートカット操作ボタンが必要な場合は必須です。ゲートウェイ経由でコールバックされる外部データ API は、「データソース管理」でゲートウェイとして登録する必要があります。詳細は「データソースを作成する」を参照してください。 |
| appUuid | String | いいえ | ゲートウェイの appUuid です。ショートカット操作ボタンが必要な場合は必須です。  データソースを所有する組織の組織 ID を渡します。 |
| apiKey | String | いいえ | ゲートウェイの apiKey です。ショートカット操作ボタンのエントリが必要な場合は必須です。作成したデータソースから `apiKey` を取得します。  - ゲートウェイが外部 API をコールバックする際、DingTalk はビジネスシナリオに応じて、業務処理に必要なパラメータを ISV に返します。コールバックリクエストの受信後にこれらのパラメータを解析するには、ISV がデータソースの作成時に対応するパラメータキーを設定する必要があります。   たとえば、TASK_EXECUTE タスク実行モジュール（詳細ページの「承認」ボタンと「却下」ボタン）にコールバックを設定した場合、DingTalk は次の固定パラメータを返します：`&#123;"outResult":"agree","processInstanceId":"xxx","activityId":"xxx","corpId":"dingxxx","data":[],"remark":"承認","title":"xxx が提出した備品申請","taskId":111,"operator":"manager0001"&#125;`。 - ISV はデータソースの作成時に、業務要件に応じて解析するキーを設定する必要があります：outResult,processInstanceId,activityId,corpId,remark,title,taskId,operator |
| version | String | いいえ | ゲートウェイ API のバージョンです。  - ショートカット操作ボタンのエントリが必要な場合は必須です。 - デフォルト：1。 |
| config | String | いいえ | サードパーティがカスタマイズした機能モジュールの設定です。最大長は 1,024 文字です。 |
