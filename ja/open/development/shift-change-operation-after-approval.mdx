シフト交換の承認後に本 API を呼び出し、勤怠システムにシフト交換のアクションを実行するよう通知します。ユーザーは自分自身または他のユーザーとシフトを交換できます。

## API 呼び出し説明

シフト交換には以下の制約があります。

- 双方がシフト制の勤怠グループに所属している必要があります。
- 双方とも、交換日と返却日の両方にシフトまたは休日が設定されている必要があります。
- 交換後の打刻時間が重複してはいけません。たとえば、1日のシフトが 08:00-22:00、2日のシフトが 10:00-09:00（翌日）だとします。1日と2日のシフトを交換すると、1日のシフトは 10:00-09:00（翌日）、2日のシフトは 08:00-22:00 になります。この場合、1日の打刻時間帯が2日の労働時間と重複します。これを打刻時間の重複と呼びます。
- シフト交換は取り消せません。

## リクエスト

| **基本情報** | |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/topapi/attendance/approve/schedule/switch |
| HTTP メソッド | POST |
| 対応アプリタイプ | appType-社内アプリ appType-サードパーティ社内アプリ |
| 必要な権限 | permission-qyapi_attendance_group_manage-勤怠グループ管理権限 |

### クエリパラメータ

| 名前 | タイプ | 必須 | 例 | 説明 |
| --- | --- | --- | --- | --- |
| access_token | String | はい | bE74xxxx | 本 API を呼び出すためのアプリ認証情報です。   - 社内アプリの場合は、[社内アプリの access_token の取得](/ja/open/development/obtain-orgapp-token) API を呼び出して取得します。 - サードパーティ社内アプリの場合は、サードパーティ組織の access_token の取得 API を呼び出して取得します。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 例 | 説明 |
| --- | --- | --- | --- | --- |
| userid | String | はい | manager123 | 申請者のユーザー ID です。 |
| switch_date | String | はい | 2019-09-08 | シフト交換を申請する日付です。この日付にシフトまたは休日が設定されている必要があります。 |
| reback_date | String | はい | 2019-09-09 | 返却日です。この日付にシフトまたは休日が設定されている必要があります。  **注意**  申請者と交換相手が同一人物の場合、返却日は必須です。 |
| apply_userid | String | はい | manager123 | シフト交換申請者のユーザー ID です。シフト制の勤怠グループのユーザーのみ対応しています。 |
| target_userid | String | はい | user123 | 交換相手のユーザー ID です。シフト制の勤怠グループのユーザーのみ対応しています。 |
| approve_id | String | はい | 2376620852 | 承認フォームの ID です。カスタムのパラメータ値です。 |
| apply_shift_id | Number | はい | 1234566 | 交換日における申請者のシフト ID です。[ユーザーのシフト設定情報の一括取得](/ja/open/development/query-batch-scheduling-information) API を呼び出して shift_id の値を取得します。 |
| target_shift_id | Number | はい | 1234566 | 交換日における交換相手のシフト ID です。[ユーザーのシフト設定情報の一括取得](/ja/open/development/query-batch-scheduling-information) API を呼び出して shift_id の値を取得します。 |
| reback_apply_shift_id | Number | はい | 1234566 | 返却日における申請者のシフト ID です。[ユーザーのシフト設定情報の一括取得](/ja/open/development/query-batch-scheduling-information) API を呼び出して shift_id の値を取得します。 |
| reback_target_shift_id | Number | はい | 1234566 | 返却日における交換相手のシフト ID です。[ユーザーのシフト設定情報の一括取得](/ja/open/development/query-batch-scheduling-information) API を呼び出して shift_id の値を取得します。 |

### リクエスト例

```curl
curl -X POST "https://api.dingtalk.io/topapi/attendance/approve/schedule/switch" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=82683xxxxc28be8' \
-d 'apply_shift_id=123' \
-d 'apply_userid=dd_dd' \
-d 'approve_id=asdasdjashd' \
-d 'reback_apply_shift_id=789' \
-d 'reback_date=2019-09-09' \
-d 'reback_target_shift_id=897' \
-d 'switch_date=2019-09-08' \
-d 'target_shift_id=456' \
-d 'target_userid=aa_aa' \
-d 'userid=dd_dd'
```

## レスポンス

### レスポンスボディ

| 名前 | タイプ | 例 | 説明 |
| --- | --- | --- | --- |
| errcode | Number | 0 | 戻りコードです。 |
| errmsg | String | ok | 戻りコードの説明です。 |


本 API の呼び出し時にエラーが発生した場合は、エラーメッセージをもとに[グローバルエラーコード](/ja/open/development/server-api-error-codes-1)ドキュメントで解決方法を確認してください。
