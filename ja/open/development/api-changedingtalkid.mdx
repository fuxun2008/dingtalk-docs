---
title: "企業アカウントの DingTalk ID を変更"
description: "API で企業アカウントの DingTalk ID を変更し、変更後 1 年間は再度変更できません"
---

本 API を呼び出して、企業アカウントの DingTalk ID を変更します。

## API 呼び出し説明

各アカウントは DingTalk ID を変更した後、1 年以内は再度変更できません。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/v1.0/contact/orgAccounts/dingTalkIds/change |
| HTTP Method | POST |
| サポートするアプリタイプ | appType-社内アプリ |
| 権限要件 | permission-qyapi_manage_addresslist-連絡先メンテナンスの API アクセス権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | はい | 本 API を呼び出すためのアクセス認証情報。[社内アプリの accessToken を取得](/ja/open/development/obtain-the-access-token-of-an-internal-app#) API を呼び出して取得します。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| userId | String | はい | 社員の userId。本企業に所属する企業アカウントの userId のみサポートします。 |
| dingTalkId | String | はい | 新しい DingTalk ID。グローバルに一意であり、組織内のみで一意というわけではないため、既存のものと重複できません。重複が発生した場合は別の候補値に変更してください。フォーマット要件：`6 <= 長さ <= 20`、英字で始まり、英字と数値のみ使用可。禁止コンテンツを含めることはできません。 |

### リクエスト例

HTTP

```http
POST /v1.0/contact/orgAccounts/dingTalkIds/change HTTP/1.1
Host:api.dingtalk.io
x-acs-dingtalk-access-token:f788baa23xxxx
Content-Type:application/json

{
  "userId" : "userIdBB",
  "dingTalkId" : "abc123"
}
```
