---
title: "フィルターの取得"
---

本インターフェースを呼び出すと、指定したワークシート上で現在有効なグローバルフィルター情報を取得できます。レスポンスにはフィルター ID、フィルター範囲、各列に設定されたフィルター条件が含まれます。フィルター条件を変更する前に現在の状態を確認したい場合や、プログラムでフィルター設定を読み取り後続処理を行う場合に適しています。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | `https://api.dingtalk.io/v1.0/doc/workbooks/{workbookId}/sheets/{sheetId}/filter/getFilter` |
| HTTP Method | GET |
| サポートするアプリタイプ | appType-社内アプリ |
| 権限要件 | permission-Document.Workbook.Read-スプレッドシート読み取り権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | はい | 本インターフェースを呼び出すためのアクセス認証情報です。[社内アプリの access_token を取得する](/ja/open/development/obtain-the-access-token-of-an-internal-app)インターフェースを呼び出して取得できます。 |

### パスパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| workbookId | String | はい | スプレッドシートファイル ID 。[ナレッジベース API](/ja/open/development/knowledge-base-overview) が返す `nodeId(dentryUuid)` がスプレッドシートの `workbookId` です。[ノードの取得](/ja/open/development/get-knowledge-base-acquisition-node)および[ナレッジベースドキュメントの作成](/ja/open/development/create-team-space-document)インターフェースを呼び出して取得できます。 |
| sheetId | String | はい | ワークシート ID または名前です。[すべてのワークシートを取得する](/ja/open/development/obtain-all-worksheets)インターフェースを呼び出して id または name パラメータ値を取得できます。  **説明**  ワークシート上にフィルターが存在しない場合、インターフェースは 404 エラーを返します。 |

### クエリパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| operatorId | String | はい | 操作者の unionId です。   - [サイレントログインコードでユーザー情報を取得する](/ja/open/development/obtain-the-userid-of-a-user-by-using-the-log-free)インターフェースを呼び出して unionid パラメータ値を取得できます。 - [ユーザー詳細の照会](/ja/open/development/query-user-details)インターフェースを呼び出して unionid パラメータ値を取得することもできます。       操作者に権限がない場合、インターフェースは `The operator has no permission` エラーを返します。 |

## レスポンス

### レスポンスボディ

| 名前 | タイプ | 説明 |
| --- | --- | --- |
| id | String | フィルターの一意識別 ID |
| range | String | フィルター範囲。A1 表記。 |
| criteria | `Map<String, Object>` | すべての列のフィルター条件マッピング。key はフィルター範囲の先頭列を基準とした列オフセット（0 から開始）、value は該当列のフィルター条件オブジェクトです。フィルター条件が未設定の場合は空オブジェクト `{}` を返します。 |
|  | Object | 現在の列のフィルター条件 |
| filterType | String | フィルタータイプ。指定可能な値：   - **values**：値による絞り込み - **color**：色による絞り込み - **condition**：条件による絞り込み |
| visibleValues | Array of String | 表示する値 |
| conditions | Array | 条件による絞り込み時の条件リスト。`filterType` が `condition` の場合のみ返します。 |
| operator | String | 条件演算子。指定可能な値：   - **equal**：等しい - **not-equal**：等しくない - **contains**：含む - **not-contains**：含まない - **starts-with**：で始まる - **not-starts-with**：で始まらない - **ends-with**：で終わる - **not-ends-with**：で終わらない - **greater**：より大きい - **greater-equal**：以上 - **less**：より小さい - **less-equal**：以下 |
| value | String | 条件値 |
| conditionOperator | String | 複数条件間の論理関係（`and` または `or`）。`filterType` が `condition` の場合のみ返します。 |
| backgroundColor | String | 背景色による絞り込み時の表示色。16 進数形式。`filterType` が `color` かつ背景色による絞り込みの場合のみ返します。 |
| fontColor | String | フォント色による絞り込み時の表示色。16 進数形式。`filterType` が `color` かつフォント色による絞り込みの場合のみ返します。 |
