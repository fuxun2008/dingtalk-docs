本ドキュメントでは、アプリのボットを利用してグループチャットへメッセージを送信する方法について説明します。

## API 呼び出し説明

本 API は社内アプリのボットに対応しています。詳細は [社内アプリのボットを作成する](/ja/open/dingstart/configure-the-robot-application#) を参照してください。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/v1.0/robot/groupMessages/send |
| HTTP Method | POST |
| 対応するアプリタイプ | appType-社内アプリ　appType-サードパーティ社内アプリ |
| 権限要件 | permission-qyapi_robot_sendmsg-社内ボットによるメッセージ送信権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | はい | この API を呼び出すためのアクセス認証情報。以下の方法で取得します：   - 社内アプリの場合は、[社内アプリの access_token を取得する](/ja/open/development/obtain-the-access-token-of-an-internal-app#) API を呼び出して取得します。 - サードパーティ社内アプリの場合は、[サードパーティアプリにより認可された企業の access_token を取得する](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#) API を呼び出して取得します。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| msgParam | String | はい | メッセージテンプレートのパラメータ。詳細は [社内ボットが送信するメッセージのタイプ](https://open.dingtalk.com/document/orgapp/types-of-messages-sent-by-robots#) を参照してください。長さは 15000 バイト以内です。 |
| msgKey | String | はい | メッセージテンプレートの key。詳細は [社内ボットが送信するメッセージのタイプ](https://open.dingtalk.com/document/dingstart/types-of-messages-sent-by-robots#) を参照してください。 |
| openConversationId | String | はい | チャット ID：   - 内部グループの場合    - 新規作成した内部グループの場合、社内アプリでは [内部グループを作成する](https://open.dingtalk.com/document/development/create-group-session#) API を呼び出して取得できます。既存の内部グループの場合は、[chooseChat](https://open.dingtalk.com/document/development/jsapi-choose-chat#) を呼び出して取得します。 - シーングループの場合    - 社内アプリでは [シーングループを作成する](https://open.dingtalk.com/document/development/create-a-scene-group-v2#) API を呼び出して取得できます。既存のシーングループの場合は、[chooseChat](https://open.dingtalk.com/document/orgapp/jsapi-choose-chat#) のチャット選択 JSAPI を呼び出して取得します。 |
| robotCode | String | はい | ボットのコード。詳細は [ボット ID](/ja/open/development/development-robot-overview#) を参照してください。 |
| coolAppCode | String | いいえ | グループチャットクールアプリのコード。詳細は [グループチャットクールアプリ](https://open.dingtalk.com/document/dingstart/configuration-group-chat-quick-entry#) を参照してください。    グループチャットクールアプリ方式でボットをインストールしている場合は、このパラメータを **必ず** 渡してください。 |
