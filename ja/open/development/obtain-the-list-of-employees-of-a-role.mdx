title: "指定したロールの社員リストを取得"

---

本 API を呼び出して、指定したロールの社員リストを取得します。

## リクエスト

| **基本情報** | |
| --- | --- |
| HTTP URL | https://oapi.dingtalk.io/topapi/role/simplelist |
| HTTP Method | POST |
| 対応アプリタイプ | appType-社内アプリappType-サードパーティ社内アプリ |
| 必要な権限 | permission-qyapi_get_department_member-連絡先の部門ユーザー読み取り権限 |

### クエリパラメータ

| 名前 | タイプ | 必須 | 例 | 説明 |
| --- | --- | --- | --- | --- |
| access_token | String | 必須 | bE74xxxx | この API を呼び出すためのアプリ認証情報。   - 社内アプリの場合、[社内アプリの access_token 取得](/ja/open/development/obtain-orgapp-token) API から取得します。 - サードパーティ社内アプリの場合、サードパーティ企業の access_token 取得 API から取得します。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 例 | 説明 |
| --- | --- | --- | --- | --- |
| role_id | Number | 必須 | 1203141 | ロールの roleId。[ロールリストの取得](/ja/open/development/obtains-a-list-of-enterprise-roles) API を呼び出して id パラメータの値を取得できます。 |
| size | Number | 任意 | 20 | ページサイズ。  **説明**  offset パラメータと同時に設定した場合にのみ有効です。このパラメータはページサイズを表します。デフォルトは 20、最大 100。 |
| offset | Number | 任意 | 0 | ページオフセット。  **説明**  size パラメータと同時に設定した場合にのみ有効です。このパラメータはオフセットを表し、オフセットは 0 から始まります。 |

### リクエスト例

```curl
curl -X POST "https://oapi.dingtalk.io/topapi/role/simplelist" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=d1812xxxxc53245' \
-d 'offset=0' \
-d 'role_id=1203141' \
-d 'size=20'
```

```text

```

## レスポンス

### レスポンスボディ

| 名前 | タイプ | 例 | 説明 |
| --- | --- | --- | --- |
| request_id | String | f6249uw1kuus | リクエスト ID。 |
| errcode | Number | 0 | レスポンスコード。 |
| errmsg | String | ok | レスポンスコードの説明。 |
| result | PageVo |  | クエリ結果。 |
| hasMore | Boolean | true | さらにデータがあるかどうか。 |
| list | OpenEmpSimple[] |  | ロールに属する社員リスト。 |
| userid | String | manager4220 | 社員の userid。 |
| name | String | 山田太郎 | 社員の名前。 |
| manageScopes | OrgDeptVo[] |  | 管理範囲。 |
| dept_id | Number | 11 | 部門 ID。 |
| name | String | 監査部 | 部門名。 |

### エラーコード

この API の呼び出しでエラーが発生した場合は、エラーメッセージをもとに[グローバルエラーコード](/ja/open/development/server-api-error-codes-1)ドキュメントで解決策を検索してください。

| エラーコード（errorcode） | エラーコードの説明（errmsg） | 解決策 |
| --- | --- | --- |
| 33011 | 無効な roleId | roleId が正しいか確認してください |
| 40069 | 無効な size | ページサイズを調整してください |
| 40068 | 無効なオフセット | オフセットを調整してください |
| 400001 | システムエラー | 後で再試行してください |
