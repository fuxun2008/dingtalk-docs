---
title: "シフトの作成"
description: "勤怠シフトを作成する API です。シフト名、出勤・退勤の打刻時刻、打刻セクション、休憩時間を設定し、作成したシフト ID を返します。"
---

この API を呼び出して、DingTalk の勤怠シフトを作成します。

## リクエスト

| **基本情報** | |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/topapi/attendance/shift/add |
| HTTP メソッド | POST |
| 対応アプリタイプ | appType-社内アプリ |
| 必要な権限 | permission-qyapi_attendance_group_manage-勤怠グループ管理権限 |

### クエリパラメータ

| 名前 | タイプ | 必須 | 例 | 説明 |
| --- | --- | --- | --- | --- |
| access_token | String | はい | 6d1bxxxx | この API の呼び出しに使用するアプリ認証情報です。[社内アプリの access_token を取得](/ja/open/development/obtain-orgapp-token) API を呼び出して取得します。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 例 | 説明 |
| --- | --- | --- | --- | --- |
| op_user_id | String | はい | user01 | 操作者の userId です。 |
| shift | TopAtClassVo | はい |  | シフトです。 |
| owner | String | いいえ | user01 | シフトの所有者です。 |
| class_group_name | String | いいえ | def | シフトグループ名です。 |
| corp_id | String | いいえ | ding23 | 組織 ID（corpId）です。[開発者コンソール](https://open-dev.dingtalk.io/)で確認できます。CorpId |
| name | String | はい | 日勤 | シフト名です。 |
| id | Number | いいえ | 124 | シフト ID です。[シフト概要の取得](/ja/open/development/enterprise-shift-query-in-batches) API を呼び出して取得します。  **注意**  シフトを新規作成する場合は id を空にします。既存のシフトを変更する場合は id を指定します。 |
| sections | TopAtSectionVo[] | はい |  | 打刻セクションです。 |
| times | TopAtTimeVo[] | はい |  | 打刻情報です。 |
| check_type | String | はい | OnDuty | 打刻タイプです。   - **OnDuty**：出勤打刻 - **OffDuty**：退勤打刻 |
| across | Number | はい | 0 | 翌日にまたがるかどうかです。   - **0**：当日 - **1**：翌日 |
| end_min | Number | いいえ | -1 | 打刻可能な最も遅い時刻（分単位）です。-1 は制限なしを表します。 |
| check_time | Date | はい | 2020-12-02 09:00:00 | 打刻時刻です。 |
| free_check | Boolean | いいえ | false | 打刻を免除するかどうかです。   - **false**：打刻が必要 - **true**：打刻を免除 |
| begin_min | Number | いいえ | 30 | 打刻可能な最も早い事前打刻時間（分単位）です。 |
| setting | TopAtClassSettingVo | いいえ |  | 設定です。 |
| rest_begin_time | TopAtTimeVo | いいえ |  | 休憩開始です。 |
| check_type | String | いいえ | OnDuty | 休憩タイプです。   - **OnDuty**：休憩開始 - **OffDuty**：休憩終了 |
| check_time | Date | いいえ | 2020-12-02 09:00:00 | 休憩の打刻時刻です。 |
| free_check | Boolean | いいえ | false | 打刻を免除するかどうかです。   - **true**：打刻を免除 - **false**：打刻が必要 |
| across | Number | いいえ | 0 | 翌日にまたがるかどうかです。翌日にまたがる場合、休憩は翌日になります。   - **0**：当日 - **1**：翌日 |
| class_id | Number | いいえ | 221 | シフト ID です。[シフト概要の取得](/ja/open/development/enterprise-shift-query-in-batches) API を呼び出して取得します。 |
| is_flexible | Boolean | いいえ | false | フレックスシフトかどうかです。   - **true**：フレックス - **false**：フレックスではない |
| corp_id | String | いいえ | ding121 | 組織 ID（corpId）です。[開発者コンソール](https://open-dev.dingtalk.io/)で確認できます。CorpId |
| is_deleted | String | いいえ | N | シフトが削除済みかどうかです。   - **N**：はい - **Y**：いいえ |
| rest_end_time | TopAtTimeVo | いいえ |  | 休憩終了です。 |
| check_type | String | いいえ | OffDuty | 休憩タイプです。   - **OnDuty**：休憩開始 - **OffDuty**：休憩終了 |
| check_time | Date | いいえ | 2020-12-02 09:00:00 | 休憩時刻です。 |
| free_check | Boolean | いいえ | false | 打刻を免除するかどうかです。   - **false**：打刻が必要 - **true**：打刻を免除 |
| across | Number | いいえ | 1 | 翌日にまたがるかどうかです。翌日にまたがる場合、休憩は翌日になります。   - **0**：当日 - **1**：翌日 |
| serious_late_minutes | Number | いいえ | 31 | 重度の遅刻・早退とみなす時間（分単位）です。 |
| absenteeism_late_minutes | Number | いいえ | 60 | 欠勤とみなす遅刻・早退の時間（分単位）です。  **注意**  この値は重度の遅刻とみなす時間より大きくする必要があります。 |
| extras | Json | いいえ | `{"cause":"{\"type\":\"approve\",\"relatedId\":\"43494469-21a6-4111-953b-7810a709f27f\"}"}` | シフト設定の拡張フィールドです。臨時シフト以外では指定不要です。 |
| tags | String | いいえ | temp:schedule:isv | シフトのタグです。臨時シフト以外では指定不要です。 |

### リクエスト例

```curl
curl -X POST "https://api.dingtalk.io/topapi/attendance/shift/add" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=39cbcxxxx9058' \
-d 'op_user_id=abc' \
-d 'shift=null'
```

## レスポンス

### レスポンスボディ

| 名前 | タイプ | 例 | 説明 |
| --- | --- | --- | --- |
| result | TopAtClassVo |  | シフト情報です。 |
| id | Number | 706715401 | シフト ID です。 |
| name | String | A1 | シフト名です。 |
| errmsg | String | ok | リターンコードの説明です。 |
| errcode | Number | 0 | リターンコードです。 |
| success | Boolean | true | 呼び出しに成功したかどうかです。   - **true**：成功 - **false**：失敗 |
| request_id | String | wp2oh4e4vlbu | リクエスト ID です。 |
