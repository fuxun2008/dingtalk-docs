title: "ノードの取得"

本インターフェースを呼び出し、操作者の unionId とノード ID に基づいて、単一ノードの情報を取得します。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | `https://api.dingtalk.io/v2.0/wiki/nodes/{nodeId}` |
| HTTP Method | GET |
| サポートされるアプリタイプ | appType-社内アプリ　appType-サードパーティ社内アプリ |
| 必要な権限 | permission-Wiki.Node.Read-ナレッジベースノード読み取り権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | はい | 当該インターフェースを呼び出すアクセス認証情報。以下の方法で取得します：   - 社内アプリの場合、[社内アプリのアクセストークン取得](/ja/open/development/obtain-the-access-token-of-an-internal-app#)インターフェースを呼び出して取得します。 - サードパーティ社内アプリの場合、[サードパーティアプリ認可企業のアクセストークン取得](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#)インターフェースを呼び出して取得します。 |

### パスパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| nodeId | String | はい | ノード ID（ノード dentryUuid）。[ノードリストの取得](/ja/open/development/get-node-list#)インターフェースを呼び出し、戻りパラメータの `nodeId` フィールドから取得できます。 |

### クエリパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| withStatisticalInfo | Boolean | いいえ | 統計情報を取得するかどうか：   - true：取得する - false：取得しない       デフォルトは false。 |
| withPermissionRole | Boolean | いいえ | 権限情報を取得するかどうか：   - true：取得する - false：取得しない       デフォルトは false。 |
| operatorId | String | はい | 操作者の unionId。 |
