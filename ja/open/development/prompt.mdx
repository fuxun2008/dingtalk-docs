## プロンプトとは

プロンプトとは、大規模言語モデル（LLM）に与える入力テキストであり、対応する出力を生成するようモデルを導くものです。プロンプトは通常、ハードコードされた単なる文字列ではなく、テンプレート・いくつかの例・ユーザー入力を組み合わせたものです。プロンプトを管理・利用しやすくするために、通常はプロンプトテンプレート（PromptTemplate）を使って作成・保守します。

## PromptTemplateとは

プロンプトテンプレートとは、エンドユーザーから一連のパラメータを受け取ってプロンプトを生成する、再利用可能なテキスト文字列です。テンプレート内のパラメータ値を置き換えることで、DingTalkドキュメントでドキュメントテンプレートからドキュメントを作成するのと同じように、プロンプトを簡単に構築・利用できます。

開発者がプロンプトテンプレートの作成やデバッグを行いやすいように、DingTalk AI アプリはプロンプトビルダーを提供しています。プロンプトビルダーを使うと、開発者はプロンプトをエンティティとして扱い、永続的な管理・ユニットチューニング・バージョン反復を行えるほか、独自の PromptTemplate コンポーネントを構築して、さまざまなアプリやスキル間で再利用できます。今後、プロンプトビルダーはデータ評価・自動最適化・使用量見積もりなどの機能もサポートする予定です。詳しくは、[プロンプトビルダーの使い方](https://open.dingtalk.com/document/ai-dev/how-to-use-the-prompt-word-builder#)を参照してください。

## **プロンプトテンプレートでの変数の使い方**

AI 機能が実行されると、大量のデータが生成されます。例えば、Tabler が動作しているグループチャットの openConversationId、ユーザーが所属する組織の corpId、ユーザーの名前や userId などです。開発者がこれらの値にアクセスしやすいように、AI アプリ開発プラットフォームは便利な取得方法を提供しています。

#### **例**

- ユーザー入力を取得するには、プロンプトテンプレートに変数 `@{input}` を入力します。
- ユーザーの名前を取得するには、プロンプトテンプレートに変数 `@{user.name}` を入力します。
- 現在の時刻を取得するには、プロンプトテンプレートに変数 `@{time}` を入力します。

#### **使い方**

- 値の式

  ```
  @{user.name}
  ```
- 反復の式

  ```
  @foreach{message : aiMessages} 
    @{message.sender.nick}: @{message.summary}
  @end{}
  ```
- 条件式

  ```
  @if{groupConversation != null}
    Group Chat title: @{groupConversation.title}
  @else{singleConversation != null}
    Direct Message target: @{singleConversation.targetUser.name}
  @else{}
    Not currently in an IM conversation
  @end{}
  ```

#### **システム変数**

```
<!-- ユーザー入力 -->
@{input} 

<!-- 現在の時刻 -->
@{time} 

<!-- 現在のユーザー情報（ユーザーの組織名、組織の corpId、ユーザーの名前、ユーザーの userId を含む） -->
@{user} 

<!-- 組織内でのユーザーの名前 -->
@{user.name}

<!-- 組織内でのユーザーの userId -->
@{user.staffId}

<!-- 現在のグループチャットの openConversationId。IM シナリオでグループチャットの場合のみ利用可能 -->
@{groupConversation.openConversationId} 

<!-- 現在の個別チャットの openConversationId。IM シナリオで個別チャットの場合のみ利用可能 -->
@{singleConversation.openConversationId}
```
