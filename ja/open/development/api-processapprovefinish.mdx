description: "DingTalk勤怠に承認完了を通知するサーバー API の仕様を解説します。残業・休暇・外出・出張の承認結果を連携し、社員の勤怠ステータスを自動で更新するためのパラメータとコード例を紹介します。"

この API を呼び出して、承認が完了したことを DingTalk に通知します。対象となるタイプは残業、休暇、外出、出張です。

## API 呼び出し説明

たとえば、ある社員の本日の勤務予定が 8:00〜18:00 で、組織独自の承認システムで休暇申請を提出したとします。申請が承認された後にこの API を呼び出して DingTalk 勤怠に通知すると、その社員は本日打刻する必要がなく、欠勤としても記録されません。社員のステータスは休暇と表示されます。別の例として、社員の Xiaoding が 11月15日に打刻しておらず、勤怠統計にこの打刻漏れが記録されているとします。

この API を呼び出して承認完了を DingTalk に通知すると、Xiaoding の 11月15日の勤怠が休暇、出張、または残業に変更されます。

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | はい | この API を呼び出すためのアクセス認証情報です。次の方法で取得します。   - 社内アプリ：[社内アプリのアクセストークンを取得](/ja/open/development/obtain-the-access-token-of-an-internal-app) API を呼び出します。 - サードパーティ社内アプリ：サードパーティアプリに権限を付与した組織のアクセストークンを取得する API を呼び出します。 |

### クエリパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| userId | String | いいえ | 社員の userId です。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| topCalculateApproveDurationParam | Object | いいえ | 時間の計算に関する入力パラメータです。 |
| bizType | Long | いいえ | 承認フォームのタイプです。有効な値：   - **1**：残業 - **2**：出張または外出 - **3**：休暇 |
| fromTime | String | いいえ | 開始時刻です。現在時刻から 31 日より前の時刻は指定できません。  対応する形式：   - 2019-08-15 - 2019-08-15 AM - 2019-08-15 12:43 |
| toTime | String | いいえ | 終了時刻です。  対応する形式：   - 2019-08-15 - 2019-08-15 AM - 2019-08-15 12:43   **注意**  - 終了時刻を開始時刻より前に設定することはできません。 - 期間は 360 日を超えることはできません。 - 開始時刻から終了時刻までの日数は 31 日を超えることはできません。 - `biz_type` が 1 の場合、開始時刻から終了時刻までの日数は 1 日を超えることはできません。 |
| durationUnit | String | いいえ | 時間の単位です。対応する値：   - **day** - **halfDay** - **hour**：`biz_type` が 1 の場合は hour のみ対応しています。   時刻の形式は時間の単位と一致させる必要があります。   - 2019-08-15 は day に対応 - 2019-08-15 AM は halfDay に対応 - 2019-08-15 12:43 は hour に対応 |
| calculateModel | Long | いいえ | 計算方法：   - **0**：暦日で計算 - **1**：勤務日で計算 |
| leaveCode | String | いいえ | 休暇ルールの一意の識別子です。任意です。  **注意**  `bizType=3`（休暇）の場合のみ、空でない値を渡してください。その場合、休暇タイプに設定された端数処理ルールに従って時間が丸められます。 |
| timeZoneId | String | いいえ | タイムゾーン ID です。形式は `Asia/Shanghai` です。 |
| tagName | String | いいえ | 承認フォームのタイプ名です（最大 20 文字）。対応する値：请假（休暇）、出差（出張）、外出（外出）、加班（残業）。 |
| subType | String | いいえ | サブタイプ名です（最大 64 文字）。  **注意**  承認フォームのタイプ biz_type が 3 の場合、このパラメータは必須です。 |
| approveId | String | いいえ | 承認フォーム ID です（最大 100 文字）。任意の値を指定できます。  **注意**  サードパーティ社内アプリはこの値を保存する必要があります。承認の取り消しを通知する際に必要となります。同じ approveId でこの API を再度呼び出すと、更新として処理されます。 |
| jumpUrl | String | いいえ | 承認フォームのリダイレクト先 URL です（最大 200 文字）。  **注意**  勤怠統計ページでユーザーがサードパーティ社内アプリのエントリをクリックすると、DingTalk はこの URL にリダイレクトします。承認フォームの詳細ページの URL を指定してください。 |
| overtimeDuration | String | いいえ | biz_type が 1 の場合は必須です。残業時間です（単位：時間）。 |
| overTimeToMore | Long | いいえ | biz_type が 1 の場合は必須です。   - **1**：残業を代休に振り替え - **2**：残業を残業代に振り替え |
