この API を呼び出して、指定した休暇ルールを削除します。

## リクエスト

| **基本情報** | |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/topapi/attendance/vacation/type/delete |
| HTTP メソッド | POST |
| 対応アプリタイプ | 社内アプリ、サードパーティ社内アプリ |
| 必要な権限 | qyapi_holiday_manage：DingTalk 休暇管理権限 |

### クエリパラメータ

| 名前 | タイプ | 必須 | 例 | 説明 |
| --- | --- | --- | --- | --- |
| access_token | String | はい | bE74xxxx | この API の呼び出しに使用するアプリ認証情報です。   - 社内アプリの場合は、[社内アプリの access_token を取得](/ja/open/development/obtain-orgapp-token)を呼び出して取得します。 - サードパーティ社内アプリの場合は、サードパーティ組織の access_token を取得する API を呼び出して取得します。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 例 | 説明 |
| --- | --- | --- | --- | --- |
| leave_code | String | はい | 03747xxxx | 休暇ルールの一意の識別子です。[休暇ルール一覧の照会](/ja/open/development/holiday-type-query)を呼び出して leave_code の値を取得します。 |
| op_userid | String | はい | user01 | **OA承認**のアプリ権限を持つ、社内の管理者のユーザー ID です。 |

### リクエスト例

```curl
curl -X POST "https://api.dingtalk.io/topapi/attendance/vacation/type/delete" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=3acaxxxxa30a2' \
-d 'leave_code=037477axxxxae5e7973' \
-d 'op_userid=03085665764167'
```

## レスポンス

### レスポンスボディ

| 名前 | タイプ | 例 | 説明 |
| --- | --- | --- | --- |
| result | LeaveTypeVo |  | 返却結果です。 |
| leave_code | String | 03747xxxx | 休暇ルールの一意の識別子です。 |
| leave_name | String | 年次有給休暇 | 休暇の名前です。 |
| leave_view_unit | String | day | 休暇申請の単位です。   - **day**：日 - **halfDay**：半日 - **hour**：時間 |
| biz_type | String | general_leave | 休暇タイプです。   - **general_leave**：通常の休暇 - **lieu_leave**：残業を代休に振り替えた休暇 |
| natural_day_leave | Boolean | true | 暦日で休暇時間を計算するかどうかを示します。   - **true**：暦日で休暇時間を計算します。 - **false**：暦日で休暇時間を計算しません。  **注意**  値が **false** の場合、ユーザーが休暇申請を提出する際に、休暇期間中のユーザーのシフト設定に基づいて休暇時間を計算します。 |
| hours_in_per_day | Number | 1000 | 1日あたりの労働時間です（単位：1/100 時間）。  例：1日 = 10時間 = 1000。 |
| errcode | Number | 0 | 戻りコードです。 |
| errmsg | String | ok | 戻りコードの説明です。 |
| success | Boolean | true | 呼び出しに成功したかどうかを示します。   - **true**：はい - **false**：いいえ |
| request_id | String | xss3trk3zypq | リクエスト ID です。 |

### レスポンスボディの例

```json
{
  "errcode": 0,
  "errmsg":"ok",
  "result": {
    "biz_type": "general_leave",
    "hours_in_per_day": 1000,
    "leave_code": "03747xxxx",
    "leave_name": "年次有給休暇",
    "leave_view_unit": "day",
    "natural_day_leave": true
  },
  "success": true,
  "request_id": "xss3trk3zypq"
}
```

### エラーコード

呼び出しでエラーが返された場合は、エラーメッセージをもとに[グローバルエラーコード](/ja/open/development/server-api-error-codes-1)ドキュメントで解決方法を確認してください。
