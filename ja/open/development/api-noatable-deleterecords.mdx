---
title: "複数行レコードの削除"
---

本インターフェースを呼び出して、データテーブル内の複数行のレコードを削除します。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | `https://api.dingtalk.io/v1.0/notable/bases/{baseId}/sheets/{sheetIdOrName}/records/delete` |
| HTTP Method | POST |
| 対応アプリタイプ | appType-社内アプリ |
| 必要な権限 | permission-Notable.Base.Write.All-AIテーブルアプリ書き込み権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | はい | 本インターフェースを呼び出す際のアクセス認証情報です。[社内アプリのアクセストークン取得](https://open.dingtalk.io/document/development/obtain-the-access-token-of-an-internal-app#)インターフェースを呼び出して取得します。 |

### パスパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| baseId | String | はい | AIテーブル ID。取得方法は[データ構造](https://open.dingtalk.io/document/development/data-structure#)を参照してください。 |
| sheetIdOrName | String | はい | データテーブル ID またはデータテーブル名。データテーブル ID は以下の 2 つの方法で取得できます。   - [全データテーブルの取得](https://open.dingtalk.io/document/development/api-notable-getallsheets#)インターフェースを呼び出して取得します。 - [データテーブルの取得](https://open.dingtalk.io/document/development/api-notable-getsheet#)インターフェースを呼び出して取得します。 |

### クエリパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| operatorId | String | はい | 操作者の unionId。以下の 2 つの方法で取得できます。   - [ユーザー詳細の照会](https://open.dingtalk.io/document/development/query-user-details#)インターフェースを呼び出して取得します。 - [サイレントログインコードによるユーザー情報取得](https://open.dingtalk.io/document/development/obtain-the-userid-of-a-user-by-using-the-log-free#)インターフェースを呼び出して取得します。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| recordIds | Array of String | はい | レコード ID。以下の 2 つの方法で取得できます。   - [レコード追加](https://open.dingtalk.io/document/development/api-notable-insertrecords#)インターフェースを呼び出して取得します。 - [複数行レコードの一覧](https://open.dingtalk.io/document/development/api-notable-listrecords#)インターフェースを呼び出して取得します。 |

{
