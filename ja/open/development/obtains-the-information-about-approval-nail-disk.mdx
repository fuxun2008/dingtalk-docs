---
title: "承認用ドライブスペース情報の取得"
description: "ユーザーの userId から承認用ドライブスペースの ID を取得し、添付ファイルのアップロード権限を付与する API です。"
---

この API を呼び出すと、承認用ドライブスペースの ID を取得し、現在のユーザーに添付ファイルのアップロード権限を付与します。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/v1.0/workflow/processInstances/spaces/infos/query |
| HTTP メソッド | POST |
| 対応アプリタイプ | appType-社内アプリ |
| 必要な権限 | permission-Workflow.Instance.Write-ワークフローインスタンスの書き込み権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | はい | この API を呼び出すためのアクセス認証情報です。[社内アプリのアクセストークンを取得](/ja/open/development/obtain-the-access-token-of-an-internal-app) API を呼び出して取得してください。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| userId | String | はい | ユーザーの userId です。 |
| agentId | Long | いいえ | アプリの agentId です。詳細は AgentId の説明を参照してください。 |

### リクエスト例

HTTP

```http
POST /v1.0/workflow/processInstances/spaces/infos/query HTTP/1.1
Host:api.dingtalk.io
x-acs-dingtalk-access-token:6d1bxxxx
Content-Type:application/json

{
  "userId" : "user123",
  "agentId" : 8345000
}
```
