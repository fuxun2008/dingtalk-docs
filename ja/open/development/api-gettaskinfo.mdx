---
title: "タスクステータスの取得"
description: "非同期で実行するドキュメント複製タスクの進捗状況をリアルタイムで照会します"
---

Task を使用してタスクのステータスを照会します。ドキュメントのコピー機能と組み合わせて使用できます。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | `https://api.dingtalk.io/v2.0/doc/task/info/{taskId}` |
| HTTP Method | GET |
| サポートされるアプリタイプ | appType-社内アプリ |
| 必要な権限 | permission-SNS.Document.WorkspaceDocument.Read-SNS ナレッジベースドキュメント読み取り権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | はい | このインターフェースを呼び出すためのアクセス認証情報。[社内アプリの access_token を取得する](/ja/open/development/obtain-the-access-token-of-an-internal-app#) インターフェースを呼び出して取得します。 |

### パスパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| taskId | String | はい | タスク ID。[ドキュメントのコピー](/ja/open/development/api-copydoc#) インターフェースを通じて取得できます。 |

### リクエスト例

HTTP

```http
GET /v2.0/doc/task/info/12345678 HTTP/1.1
Host:api.dingtalk.io
x-acs-dingtalk-access-token:example-token
Content-Type:application/json
```

## レスポンス

### レスポンスボディ

| 名前 | タイプ | 説明 |
| --- | --- | --- |
| taskId | String | タスク ID。 |
| status | Integer | タスクステータス：   - **-1**：待機中 - **0**：実行中 - **1**：成功 - **2**：一部失敗 - **3**：すべて失敗 - **4**：失敗 |
| totalCount | Integer | タスクの総数。 |
| succCount | Integer | 成功した数。 |
| failCount | Integer | 失敗した数。 |

### レスポンスボディの例

```text
HTTP/1.1 200 OK
Content-Type:application/json

{
  "taskId" : "abcd",
  "status" : 2,
  "totalCount" : 1,
  "succCount" : 1,
  "failCount" : 0
}
```
