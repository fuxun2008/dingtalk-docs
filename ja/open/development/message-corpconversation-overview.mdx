メッセージ通知のさまざまなタイプ、使用シーン、メッセージ通知 API の機能、およびメッセージ通知 API 機能の統合方法について説明します。

## メッセージ通知のタイプ

### 業務通知メッセージ

企業の業務通知チャットにて、特定のマイクロアプリの名義で社員にプッシュされる通知メッセージです。例えば、誕生日のお祝いや入社リマインダーなどがあります。

### テンプレートを使用した業務通知の送信

### 説明

- チャットテンプレートはサードパーティ社内アプリのみ対応し、社内アプリには対応していません。
- 審査を通過したチャットテンプレートのみ、業務通知メッセージのプッシュに使用できます。

- **Markdown** テンプレート

  Markdown テンプレートは Markdown 構文を使用してチャットを設定・送信します。操作を伴わない純粋な通知メッセージタイプに適しています。Markdown テンプレートを使用することで、テキスト、画像、リンクなどの表現方法を簡単にサポートできます。
- **ActionCard** テンプレート

  ActionCard テンプレートは ActionCard チャットタイプでチャットを送信します。チャットコンテンツとアクションポイント操作を組み合わせたチャットをサポートし、チャット内で単一または複数のアクションポイントを使用して迅速に処理する必要があるシーンに適しています。

  ActionCard テンプレートは Markdown テンプレートをベースに、全体リダイレクトと個別リダイレクトのスタイルをサポートします。
- **Form** テンプレート

  Form テンプレートは OA チャットタイプをベースにチャットを送信します。注文などのチャット表示に適しており、リダイレクトしてチャット詳細を確認することができます。

### 使用フロー

下図のとおり、チャットテンプレートを使用して業務通知を送信するには、以下の操作を完了する必要があります。

1. チャットテンプレートを作成・設定します。詳細は「チャットテンプレートの管理」を参照してください。
2. テンプレート審査。
3. テンプレートを使用した業務通知送信 API を呼び出します。詳細は[テンプレートを使用した業務通知チャットの送信](/zh/open/development/work-notification-templating-send-notification-interface)を参照してください。

## オープン概要

メッセージ通知は豊富な API オープン機能を提供しています。開発者は API を通じて、メッセージ通知と企業の業務システムを連携できます。

| **API** | **API 説明** | **API バージョン** |
| --- | --- | --- |
| [業務通知の送信](/zh/open/development/asynchronous-sending-of-enterprise-session-messages) | 業務通知チャットを送信します。 | 旧バージョン |
| [業務通知ステータスバーの更新](/zh/open/development/update-work-notification-status-bar) | OA 業務通知チャットのステータスを更新します。 | 旧バージョン |
| [業務通知チャットの送信進捗の取得](/zh/open/development/obtain-the-sending-progress-of-asynchronous-sending-of-enterprise-session) | 業務通知チャットの送信進捗を取得します。 | 旧バージョン |
| [業務通知チャットの送信結果の取得](/zh/open/development/gets-the-result-of-sending-messages-asynchronously-to-the-enterprise) | 業務通知チャットの送信結果を照会します。 | 旧バージョン |
| 業務通知チャットの送信取消 | 業務チャット通知を送信取消します。 | 旧バージョン |
| [テンプレートを使用した業務通知チャットの送信](/zh/open/development/work-notification-templating-send-notification-interface) | チャットテンプレートを使用して業務通知を送信します。 | 旧バージョン |

## メッセージ通知 API 機能の統合方法

DingTalk はメッセージ通知 API の統合フローのサンプルを提供しています。

- 業務通知をクリックして DingTalk ミニプログラムへリダイレクト
- [業務通知をクリックして Web アプリへリダイレクト](/zh/open/development/redirect-micro-applications-to-work-messages)
- [業務通知の送信、照会、送信取消](/zh/open/development/work-notice-option)

## 用語解説

### task_id

task_id は業務通知チャットの一意の識別フィールドであり、[業務通知の送信](/zh/open/development/asynchronous-sending-of-enterprise-session-messages) API を呼び出すと返されます。

task_id を使用して[業務通知チャットの送信進捗の取得](/zh/open/development/obtain-the-sending-progress-of-asynchronous-sending-of-enterprise-session) API および[業務通知チャットの送信結果の取得](/zh/open/development/gets-the-result-of-sending-messages-asynchronously-to-the-enterprise) API を呼び出し、業務通知チャットの送信進捗と送信結果を照会できます。
