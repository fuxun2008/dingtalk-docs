このAPIを呼び出して、社内で勤怠のスマートレポートが有効になっているかを確認します。スマートレポートが無効の場合、ほかの統計レポートAPIは呼び出せません。

## リクエスト

| **ベーシック情報** | |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/topapi/attendance/isopensmartreport |
| HTTP メソッド | POST |
| 対応アプリタイプ | appType-社内アプリ　appType-サードパーティ社内アプリ |
| 権限 | permission-qyapi_base-組織 API の呼び出しに必要なベーシック権限 |

### クエリパラメータ

| 名前 | タイプ | 必須 | 例 | 説明 |
| --- | --- | --- | --- | --- |
| access_token | 文字列 | はい | 6d1bxxxx | このAPIの呼び出しに使用するアプリ認証情報です。   - 社内アプリ：[社内アプリの access_token を取得](/ja/open/development/obtain-orgapp-token) APIを呼び出して取得します。 - サードパーティ社内アプリ：サードパーティ社内アプリの access_token を取得するAPIを呼び出して取得します。 |

### リクエスト例

```curl
curl -X POST "https://api.dingtalk.io/topapi/attendance/isopensmartreport" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=b74b3xxxx0bb7c'
```

Java

```java
DingTalkClient client = new DefaultDingTalkClient("https://api.dingtalk.io/topapi/attendance/isopensmartreport");
OapiAttendanceIsopensmartreportRequest req = new OapiAttendanceIsopensmartreportRequest();
OapiAttendanceIsopensmartreportResponse rsp = client.execute(req, access_token);
System.out.println(rsp.getBody());
```

Python

```python
import dingtalk.api

req=dingtalk.api.OapiAttendanceIsopensmartreportRequest("https://api.dingtalk.io/topapi/attendance/isopensmartreport")

try:
  resp= req.getResponse(access_token)
  print(resp)
except Exception,e:
  print(e)
```

PHP

```php

date_default_timezone_set('Asia/Shanghai');

```

C#

```csharp

```

## レスポンス

### レスポンスボディ

| 名前 | タイプ | 例 | 説明 |
| --- | --- | --- | --- |
| result | IsOpenSmartReportForTopVo |  | 返却結果です。 |
| smart_report | 真偽値 | true | スマート統計レポートが有効かどうかを示します。   - **true**：有効 - **false**：無効 |
| request_id | 文字列 | 6f9h5mh9a94i | リクエスト ID です。 |
| errcode | 数値 | 0 | 戻りコードです。 |

### レスポンスボディの例

```json
{
  "errcode": 0,
  "result": {
    "smart_report": true
  },
  "request_id": "6f9h5mh9a94i"
}
```

### エラーコード

API の呼び出しでエラーが返された場合は、エラーメッセージをもとに[グローバルエラーコード](/ja/open/development/server-api-error-codes-1)ドキュメントで解決方法を検索してください。
