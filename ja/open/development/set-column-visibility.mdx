---
title: "列の表示・非表示を設定"

---

本インターフェースを呼び出して、列の表示・非表示を設定します。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | `https://api.dingtalk.io/v1.0/doc/workbooks/{workbookId}/sheets/{sheetId}/setColumnsVisibility` |
| HTTP Method | POST |
| サポートするアプリタイプ | appType-社内アプリ　appType-サードパーティ社内アプリ |
| 権限要件 | permission-Document.Workbook.Write-スプレッドシート書き込み権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | はい | 当該インターフェースを呼び出すためのアクセス認証情報。以下の方法で取得します。   - 社内アプリの場合、[社内アプリのaccess_tokenを取得](/ja/open/development/obtain-the-access-token-of-an-internal-app#)インターフェースを呼び出して取得します。 - サードパーティ社内アプリの場合、[サードパーティアプリが権限付与された企業のaccess_tokenを取得](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#)インターフェースを呼び出して取得します。 |

### パスパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| workbookId | String | はい | スプレッドシートファイル ID。[ナレッジベース API](/ja/open/development/knowledge-base-overview#) が返す `nodeId(dentryUuid)` がスプレッドシートの `workbookId` です。[ノード取得](https://open.dingtalk.com/document/development/get-node#)および[ナレッジベースドキュメント作成](/ja/open/development/create-team-space-document#)インターフェースを呼び出して取得できます。 |
| sheetId | String | はい | ワークシートの ID または見出し。   - 社内アプリの場合、[すべてのワークシートを取得](/ja/open/development/obtain-all-worksheets#)インターフェースを呼び出して id を取得するか、ワークシートの見出しを渡します。 - サードパーティ社内アプリの場合、ワークシートの見出しを渡すことを推奨します。   ワークシートの見出しの確認手順は下図のとおりです。 |

### クエリパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| operatorId | String | はい | 操作者の unionId。[ユーザー詳細を照会](/ja/open/development/query-user-details#)インターフェースを呼び出して取得できます。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| column | Long | はい | 表示または非表示にする最初の列のカーソル。0 から始まります。 |
| columnCount | Long | はい | 表示または非表示にする列の数。 |
| visibility | String | はい | 表示・非表示。   - **visible**：表示 - **hidden**：非表示 |

### リクエスト例

HTTP

```http
POST /v1.0/doc/workbooks/e54Lq3xxx/sheets/Sheet1/setColumnsVisibility?operatorId=ppgAxxx HTTP/1.1
Host:api.dingtalk.io
x-acs-dingtalk-access-token:xxxxx
Content-Type:application/json

{
  "column" : 0,
  "columnCount" : 1,
  "visibility" : "hidden"
}
```
