---
title: "groupId から groupKey への変換"
description: "勤怠グループの groupId を新バージョンの識別子 groupKey に変換する API です。"
---

この API を呼び出して、勤怠グループの groupId を groupKey に変換します。groupKey は、新バージョンの勤怠グループで使用される識別子フィールドです。一部の勤怠グループでは、パラメータとして groupKey が必要です。勤怠グループの groupId フィールドしかない場合は、この API を呼び出して groupKey を取得してください。

## リクエスト

| **基本情報** | |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/topapi/attendance/groups/idtokey |
| HTTP メソッド | POST |
| 対応アプリタイプ | appType-社内アプリ　appType-サードパーティ社内アプリ |
| 必要な権限 | permission-qyapi_attendance_group_read-勤怠グループ照会権限 |

### クエリパラメータ

| 名前 | タイプ | 必須 | 例 | 説明 |
| --- | --- | --- | --- | --- |
| access_token | String | はい | 6d1bxxxx | この API を呼び出すためのアプリ認証情報です。   - 社内アプリの場合は、[社内アプリの access_token を取得する](/ja/open/development/obtain-orgapp-token) API を呼び出して取得します。 - サードパーティ社内アプリの場合は、サードパーティ社内アプリの access_token を取得する API を呼び出して取得します。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 例 | 説明 |
| --- | --- | --- | --- | --- |
| op_user_id | String | いいえ | user01 | 操作者の userId です。 |
| group_id | Number | はい | 1586536 | 勤怠グループ ID です。[勤怠グループ詳細の一括取得](/ja/open/development/batch-obtain-attendance-group-details) API を呼び出して group_id の値を取得してください。 |

### リクエスト例

```curl
curl -X POST "https://api.dingtalk.io/topapi/attendance/groups/idtokey" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=ea55fdxxxx64242a' \
-d 'group_id=12' \
-d 'op_user_id=123'
```

Java

```java
DingTalkClient client = new DefaultDingTalkClient("https://api.dingtalk.io/topapi/attendance/groups/idtokey");
OapiAttendanceGroupsIdtokeyRequest req = new OapiAttendanceGroupsIdtokeyRequest();
req.setOpUserId("user01");
req.setGroupId(1586536L);
OapiAttendanceGroupsIdtokeyResponse rsp = client.execute(req, access_token);
System.out.println(rsp.getBody());
```

Python

```python

try:
  resp= req.getResponse(access_token)
  print(resp)

  print(e)
```

## レスポンス

### レスポンスボディ

| 名前 | タイプ | 例 | 説明 |
| --- | --- | --- | --- |
| result | String | 0151E0223B1xxxx | 勤怠グループ ID です。 |
| errcode | Number | 0 | 戻りコードです。 |
| errmsg | String | ok | 戻りコードの説明です。 |
| request_id | String | 3yt2gu3zz0qi | リクエスト ID です。 |

### レスポンスボディの例

```json
{
  "errcode":0,
  "result":0151E0223B1xxxx,

```

### エラーコード

この API の呼び出しでエラーが返された場合は、エラーメッセージをもとに[グローバルエラーコード](/ja/open/development/server-api-error-codes-1)ドキュメントで解決方法を検索してください。
