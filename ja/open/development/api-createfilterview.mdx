---
title: "フィルタービューの作成"
---

本 API を呼び出すことで、DingTalk スプレッドシートの指定したワークシート上にフィルタービューを作成し、ビュー名と絞り込み範囲を指定できます。作成に成功した後、各列にフィルターを設定できます。

## API 呼び出し説明

- フィルタービューは、グローバルなフィルターとは独立した個人向けのデータフィルタリング方式であり、複数ユーザーでのコラボレーションの場面で、異なるユーザーがそれぞれ異なるデータのサブセットを表示する必要がある場合に適しています。
- 各ワークシートには最大 20 個のフィルタービューを作成できます。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | `https://api.dingtalk.io/v1.0/doc/workbooks/{workbookId}/sheets/{sheetId}/filterViews` |
| HTTP Method | POST |
| サポートするアプリタイプ | appType-社内アプリ |
| 必要な権限 | permission-Document.Workbook.Write-スプレッドシート書き込み権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | はい | 本 API を呼び出すためのアクセス認証情報です。[社内アプリのアクセストークンを取得する](/ja/open/development/obtain-the-access-token-of-an-internal-app) API を呼び出して取得できます。 |

### パスパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| workbookId | String | はい | スプレッドシートファイル ID。[ナレッジベース API](/ja/open/development/knowledge-base-overview) が返す `nodeId(dentryUuid)` がスプレッドシートの `workbookId` に該当します。[ノードを取得する](https://open.dingtalk.com/document/orgapp/get-node) および [ナレッジベースドキュメントを作成する](/ja/open/development/create-team-space-document) API を呼び出して取得できます。 |
| sheetId | String | はい | ワークシートの ID または名前。[すべてのワークシートを取得する](/ja/open/development/obtain-all-worksheets) API を呼び出して id または name の値を取得できます。 |

### クエリパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| operatorId | String | はい | 操作者の unionId。   - [サイレントログインコードによりユーザー情報を取得する](/ja/open/development/obtain-the-userid-of-a-user-by-using-the-log-free) API で unionid の値を取得できます。 - [ユーザー詳細を照会する](/ja/open/development/query-user-details) API を呼び出して unionid の値を取得できます。       操作者に権限がない場合、API は `The operator has no permission` というエラーを返します。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| name | String | はい | フィルタービューの名前。 |
| range | String | はい | フィルタービューの範囲。A1 表記を使用します。例えば `A1:D10` は A1 から D10 までの領域を表します。絞り込み範囲の 1 行目は見出し行として扱われ、絞り込み計算には含まれません。 |
| criteria | `Map<String, Object>` | いいえ | 作成時に各列のフィルターを同時に設定します。key は列のオフセット（range の先頭列に対する相対値、0 から始まる）、value はフィルターオブジェクトです。指定しない場合は、空のフィルタービューが作成されます。 |
|  | Object | いいえ | 現在の列のフィルター |
| filterType | String | いいえ | 絞り込みタイプ。指定可能な値：   - **values**：値で絞り込み - **color**：色で絞り込み - **condition**：条件で絞り込み |
| visibleValues | Array of String | いいえ | 表示する値 |
| conditions | Array | いいえ | 条件で絞り込む際に、フィルターのリストを指定します。`filterType` が `condition` の場合に有効です。各条件オブジェクトには `operator`（演算子）および `value`（条件値）フィールドが含まれます。 |
| operator | String | いいえ | 条件演算子。指定可能な値：   - **equal**：等しい - **not-equal**：等しくない - **contains**：含む - **not-contains**：含まない - **starts-with**：で始まる - **not-starts-with**：で始まらない - **ends-with**：で終わる - **not-ends-with**：で終わらない - **greater**：より大きい - **greater-equal**：以上 - **less**：より小さい - **less-equal**：以下 |
| value | String | いいえ | 条件値 |
| conditionOperator | String | いいえ | 複数条件間の論理関係。指定可能な値：`and`（かつ）、`or`（または）。デフォルトは `and` です。`filterType` が `condition` で、かつ複数の条件がある場合に有効です。 |
| backgroundColor | String | いいえ | 背景色で絞り込む際に、色の値（16 進数、例：`#FF0000`）を指定します。`filterType` が `color` の場合に有効で、`fontColor` とは二者択一です。 |
| fontColor | String | いいえ | フォント色で絞り込む際に、色の値（16 進数、例：`#FF0000`）を指定します。`filterType` が `color` の場合に有効で、`backgroundColor` とは二者択一です。 |

```java
                }
            }
        }

    }
}
```

## レスポンス

### レスポンスボディ

| 名前 | タイプ | 説明 |
| --- | --- | --- |
| id | String | フィルタービューの一意な ID。 |
