---
title: "指定列の左側に複数列を挿入"
---

このAPIを呼び出すことで、指定した列の左側に複数の列を挿入します。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | `https://api.dingtalk.io/v1.0/doc/workbooks/{workbookId}/sheets/{sheetId}/insertColumnsBefore` |
| HTTP Method | POST |
| サポートするアプリタイプ | appType-社内アプリ　appType-サードパーティ社内アプリ |
| 権限要件 | permission-Document.Workbook.Write-スプレッドシート書き込み権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | はい | このAPIを呼び出すためのアクセス認証情報。以下の方法で取得します：   - 社内アプリの場合は、[社内アプリのaccess_tokenを取得](https://open.dingtalk.io/document/development/obtain-the-access-token-of-an-internal-app#)APIを呼び出して取得します。 - サードパーティ社内アプリの場合は、[サードパーティアプリが権限付与された企業のaccess_tokenを取得](https://open.dingtalk.io/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#)APIを呼び出して取得します。 |

### パスパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| workbookId | String | はい | スプレッドシートファイルのID。[ナレッジベース API](https://open.dingtalk.io/document/development/knowledge-base-overview#)が返す`nodeId(dentryUuid)`がスプレッドシートの`workbookId`に該当し、[ノードを取得](https://open.dingtalk.io/document/development/get-node#)および[ナレッジベースドキュメントを作成](https://open.dingtalk.io/document/development/create-team-space-document#)APIを呼び出して取得できます。 |
| sheetId | String | はい | ワークシートのIDまたは見出し。   - 社内アプリの場合は、[すべてのワークシートを取得](https://open.dingtalk.io/document/development/obtain-all-worksheets#)APIを呼び出してidを取得するか、ワークシートの見出しを渡すことができます。 - サードパーティ社内アプリの場合は、ワークシートの見出しを渡すことを推奨します。   ワークシートの見出しの確認手順は下図のとおりです。 |

### クエリパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| operatorId | String | はい | 操作者のunionId。[ユーザー詳細を照会](https://open.dingtalk.io/document/development/query-user-details#)APIを呼び出して取得できます。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| column | Long | はい | 指定する列のカーソル位置。0から始まります。 |
| columnCount | Long | はい | 挿入する列の数。 |

### リクエスト例

HTTP

```http
POST /v1.0/doc/workbooks/e54Lq3xxx/sheets/Sheet1/insertColumnsBefore?operatorId=ppgAxxx HTTP/1.1
Host:api.dingtalk.io
x-acs-dingtalk-access-token:xxxxx
Content-Type:application/json

{
  "column" : 0,
  "columnCount" : 1
}
```
