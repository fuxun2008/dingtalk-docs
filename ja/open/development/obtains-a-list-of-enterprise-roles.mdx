---
title: "ロールリストの取得"
---

本インターフェースを呼び出して、ロールリストを取得します。

## リクエスト

| **基本情報** | |
| --- | --- |
| HTTP URL | https://oapi.dingtalk.io/topapi/role/list |
| HTTP Method | POST |
| 対応アプリタイプ | appType-社内アプリappType-サードパーティ社内アプリ |
| 権限要件 | permission-qyapi_get_department_list-連絡先部門情報の読み取り権限 |

### クエリパラメータ

| 名前 | タイプ | 必須 | 例 | 説明 |
| --- | --- | --- | --- | --- |
| access_token | String | はい | 6ed1bxxx | この API を呼び出すためのアプリ認証情報。   - 社内アプリの場合、社内アプリの access_token 取得インターフェースから取得します。 - サードパーティ社内アプリの場合、サードパーティ企業の access_token 取得インターフェースから取得します。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 例 | 説明 |
| --- | --- | --- | --- | --- |
| size | Number | いいえ | 20 | ページング検索をサポートします。offset パラメータと同時に設定した場合のみ有効になります。本パラメータはページサイズを表します**。**デフォルトは 20**、**最大値は 200 です。 |
| offset | Number | いいえ | 0 | ページング検索をサポートします。size パラメータと同時に設定した場合のみ有効になります。本パラメータはオフセットを表し、オフセットは 0 から始まります。 |

### リクエスト例

```curl
curl -X POST "https://oapi.dingtalk.io/topapi/role/list" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=a0a639xxxx2998' \
-d 'offset=0' \
-d 'size=20'
```

Java

```text
DingTalkClient client = new DefaultDingTalkClient("https://oapi.dingtalk.io/topapi/role/list");
OapiRoleListRequest req = new OapiRoleListRequest();
req.setSize(20L);
req.setOffset(0L);
OapiRoleListResponse rsp = client.execute(req, access_token);
System.out.println(rsp.getBody());
```

Python

```python
import dingtalk.api

req=dingtalk.api.OapiRoleListRequest("https://oapi.dingtalk.io/topapi/role/list")

req.size=20
req.offset=0
try:
  resp= req.getResponse(access_token)
  print(resp)
except Exception,e:
  print(e)
```

### エラーコード

本インターフェースの呼び出しでエラーが発生した場合、エラーメッセージに基づき [グローバルエラーコード](/ja/open/development/server-api-error-codes-1) ドキュメントから解決方法を検索できます。

| エラーコード（errcode） | エラーコードの説明（errmsg） | 解決方法 |
| --- | --- | --- |
| 400043 | 不正な orgId | access_token が正しいかどうかを確認してください |
| 40069 | 不正な size | ページサイズを調整してください |
| 40068 | 無効なオフセット | オフセットの値を調整してください |
| 400001 | システムエラー | 後でもう一度お試しください |
