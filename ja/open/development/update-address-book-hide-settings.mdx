連絡先の非表示設定を追加または更新するために使用します。呼び出し時に PUT リクエストで name、description、objectStaffIds、objectDeptIds、objectTagIds、excludeStaffIds などのビジネスフィールドを送信します。

## API 呼び出し説明

DingTalk OA 管理バックエンドでは、部門に対して非表示設定を行うことができます。本 API の機能は部門の非表示設定の拡張であり、部門の非表示だけでなく、**社員およびロールの非表示も実現できます**。

<Note>
本 API の非表示設定と OA バックエンドの非表示設定は独立して保存されており、最終的に有効となる結果は両者の設定の OR 関係となります。例えば、同一部門に対して本 API または OA バックエンドのいずれかで非表示に設定されていれば、最終的にその部門は非表示となります。
</Note>

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/v1.0/contact/contactHideSettings |
| HTTP Method | PUT |
| サポートするアプリタイプ | appType-社内アプリ |
| 権限要件 | permission-Contact.Visibility.ReadWrite-連絡先データの可視範囲管理権限 |

| 名前 | タイプ | 必須 | 説明 |
