title: "ファイル分割アップロード情報の取得"
---

本 API を呼び出して、分割後の各ファイルのアップロード情報を取得します。

## API 呼び出し説明

API 呼び出し手順は以下のとおりです。

ステップ 1：[ファイル分割アップロードの初期化](/ja/open/development/initialize-a-multipart-upload-object) API を呼び出し、アップロード識別子 uploadKey を取得します。

ステップ 2：本 API を呼び出して、各ファイルのアップロード情報を取得します。

ステップ 3：各ファイルに対してアップロードを繰り返し実行します。

ステップ 4：ステップ 1 で取得したアップロード識別子 uploadKey を使用し、[ファイルの送信](/ja/open/development/submittal-file) API を呼び出してアップロードを完了します。

完全なサンプルは以下を参照してください。

    File file = new File(filePath);
    long fileLength = file.length();
    int partCount = (int) (fileLength / partSize) + ((fileLength % partSize != 0) ? 1 : 0);

    for (int i = 0; i < partCount; i++) {
      long startPos = i * partSize;
      long curPartSize = (i + 1 == partCount) ? (fileLength - startPos) : partSize;

            uploadPartFile(startPos, curPartSize, headerSignatureInfo, file);
        }
            // ファイルを送信し、アップロードを完了
            CommitFileHeaders commitFileHeaders = new CommitFileHeaders();
            commitFileHeaders.xAcsDingtalkAccessToken = "accessToken";
            CommitFileRequest.CommitFileRequestOption commitFileRequestOption
                = new CommitFileRequest.CommitFileRequestOption()
                .setSize(1024L)
                .setConflictStrategy("OVERWRITE");
            CommitFileRequest commitFileRequest = new CommitFileRequest()
                .setUnionId(unionId)

            CommitFileResponseBody.CommitFileResponseBodyDentry dentry = client.commitFileWithOptions("ストレージスペースID", commitFileRequest, commitFileHeaders, new RuntimeOptions()).body.dentry;
            System.out.println(dentry);

    private void uploadPartFile(long start, long size, GetMultipartFileUploadInfosResponseBody.GetMultipartFileUploadInfosResponseBodyMultipartHeaderSignatureInfosHeaderSignatureInfo headerSignatureInfo, File file) throws Exception {
        InputStream inputStream = new FileInputStream(file);
        if (start > 0) {
            inputStream.skip(start);
        }

        URL url = new URL(headerSignatureInfo.getResourceUrls().get(0));
        HttpURLConnection connection = (HttpURLConnection)url.openConnection();
        connection.setDoOutput(true);
        connection.setRequestMethod("PUT");
        connection.setUseCaches(false);
        if (headerSignatureInfo.getHeaders() != null) {
            for (Map.Entry<String, String> entry : headerSignatureInfo.getHeaders().entrySet()) {
                connection.setRequestProperty(entry.getKey(), entry.getValue());
            }
        }
        connection.setReadTimeout(10000);
        connection.setConnectTimeout(10000);
        connection.connect();
        OutputStream out = connection.getOutputStream();
        byte[] buffer = new byte[1024];
        long remain = size;
        for (;remain > 0;) {
            int sizeToRead = remain < buffer.length ? (int)remain : buffer.length;
            int rsz = inputStream.read(buffer, 0, sizeToRead);
            if (rsz < 0) {
                break;
            }
            out.write(buffer, 0, rsz);
            remain -= rsz;
        }
        out.flush();
        out.close();
        int responseCode = connection.getResponseCode();
        if (responseCode == 200) {
            System.out.println("アップロード成功");
        } else {
            System.out.println("アップロード失敗");
        }
        connection.disconnect();
    }

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/v1.0/storage/spaces/files/multiPartUploadInfos/query |
| HTTP Method | POST |
| サポートされるアプリタイプ | appType-社内アプリ　appType-サードパーティ社内アプリ |
| 必要な権限 | permission-Storage.UploadInfo.Read-企業ストレージファイルアップロード情報の読み取り権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | はい | 本 API を呼び出すためのアクセス認証情報。以下の方法で取得します。   - 社内アプリの場合、[社内アプリの accessToken を取得する](https://open.dingtalk.io/document/development/obtain-the-access-token-of-an-internal-app#) API を呼び出して取得します。 - サードパーティ社内アプリの場合、[サードパーティアプリで権限付与された企業の accessToken を取得する](https://open.dingtalk.io/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#) API を呼び出して取得します。 |

### クエリパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| unionId | String | はい | 操作者の unionId。[ユーザー詳細の照会](https://open.dingtalk.io/document/development/query-user-details#) API を呼び出して取得します。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| uploadKey | String | はい | アップロード一意識別子。[ファイル分割アップロードの初期化](https://open.dingtalk.io/document/development/initialize-a-multipart-upload-object#) API を呼び出して、アップロード識別子 uploadKey を取得します。 |
| partNumbers | Array of Integer | はい | 各分割ファイルの Id。ファイルの分割数は最大 10000、各分割ファイルサイズは 100KB～5GB の範囲で、最大 30 個まで指定できます。    各分割ファイルの Id は開発者が指定し、本 API は各分割ファイルのアップロード URL や headers などの情報を返します。  例：[1,2,3,4,5] |
| option | Object | いいえ | オプションパラメータ。 |
| preferIntranet | Boolean | いいえ | 内部ネットワーク転送を優先的に使用するかどうか。本パラメータを使用する前提として、専用ストレージ内部ネットワーク転送が設定されている必要があります。   - true：はい（デフォルト） - false：いいえ |

            catch (Exception _err)

                TeaException err = new TeaException(new Dictionary<string, object>
                {
                    { "message", _err.Message }
                });
                if (!AlibabaCloud.TeaUtil.Common.Empty(err.Code) && !AlibabaCloud.TeaUtil.Common.Empty(err.Message))
                {

                }

    }

## レスポンス

### レスポンスボディ

| 名前 | タイプ | 説明 |
| --- | --- | --- |
| multipartHeaderSignatureInfos | Array | 分割 Header 署名アップロード情報リスト。 |
| partNumber | Integer | 分割 Id。 |
| headerSignatureInfo | Object | header 情報。 |
| resourceUrls | Array of String | 複数のアップロード URL、最大 10 個、前の URL が優先されます。 |
| headers | `Map<String, String>` | リクエストヘッダー。 |
| expirationSeconds | Integer | 有効期限（秒単位）。 |
| region | String | リージョン。   - **ZHANGJIAKOU**：張家口 - **SHENZHEN**：深圳 - **SHANGHAI**：上海 - **SINGAPORE**：シンガポール - **UNKNOWN**：不明 |
| internalResourceUrls | Array of String | 内部ネットワーク URL リスト。    本フィールドは現在使用シーンがないため、無視してください。 |
