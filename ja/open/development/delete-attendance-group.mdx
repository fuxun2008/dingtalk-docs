## リクエスト

| **基本情報** | |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/topapi/attendance/group/delete |
| HTTP メソッド | POST |
| サポートされるアプリタイプ | appType-社内アプリ |
| 必要な権限 | permission-qyapi_attendance_group_manage-勤怠グループ管理権限 |

### クエリパラメータ

| 名前 | タイプ | 必須 | 例 | 説明 |
| --- | --- | --- | --- | --- |
| access_token | String | はい | 4c9ebd2xxxx | この API を呼び出すためのアプリ認証情報です。[社内アプリの access_token を取得](/ja/open/development/obtain-orgapp-token) API を呼び出して取得してください。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 例 | 説明 |
| --- | --- | --- | --- | --- |
| op_userid | String | いいえ | user01 | 操作者のユーザー ID です。 |
| group_key | String | はい | 0151E02xxxx | 勤怠グループの ID です。 **注記** group_id で勤怠グループを識別している場合は、[groupId を groupKey に変換](/ja/open/development/groupid-to-groupkey) API を呼び出して、group_id を group_key に変換してください。 |

### リクエスト例

```curl
curl -X POST "https://api.dingtalk.io/topapi/attendance/group/delete" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=0d5exxxxf31e2da' \
-d 'group_key=0151E02xxxx1A917E876' \
-d 'op_userid=123456'
```

Java

```text
DingTalkClient client = new DefaultDingTalkClient("https://api.dingtalk.io/topapi/attendance/group/delete");
OapiAttendanceGroupDeleteRequest req = new OapiAttendanceGroupDeleteRequest();
req.setOpUserid("user01");
req.setGroupKey("0151E02xxxx");
OapiAttendanceGroupDeleteResponse rsp = client.execute(req, access_token);
System.out.println(rsp.getBody());
```

## レスポンス

### レスポンスボディ

| 名前 | タイプ | 例 | 説明 |
| --- | --- | --- | --- |
| result | String | BE8C35586xxxx | 勤怠グループの ID です。 |
| success | Boolean | true | 呼び出しに成功したかどうかを示します。   - **true**：成功 - **false**：失敗 |
| errmsg | String | ok | 戻りコードの説明です。 |
| errcode | Number | 0 | 戻りコードです。 |
| request_id | String | 3x1mikbgn3ca | リクエスト ID です。 |

### レスポンスボディの例

```json
{
    "errcode": 0,
    "errmsg":"ok",
    "result": "BE8C35586xxxx",
    "success": true,
    "request_id": "3x1mikbgn3ca"
}
```

### エラーコード

この API の呼び出しでエラーが返された場合は、エラーメッセージをもとに[グローバルエラーコード](/ja/open/development/server-api-error-codes-1)ドキュメントで解決方法を確認してください。
