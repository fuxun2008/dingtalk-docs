---
title: "社員ロールの一括追加"
description: "複数の社員に対してロールを一括で割り当てることで、組織の権限管理を効率化します"
---

本インターフェイスを呼び出して、社員のロールを一括で追加します。「デフォルト」グループ分け内のロール（責任者、主管、スーパー管理者、サブ管理者を含む）の追加は許可されていません。

## リクエスト

| **基本情報** | |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/topapi/role/addrolesforemps |
| HTTP Method | POST |
| サポートされるアプリタイプ | appType-社内アプリ |
| 権限要件 | permission-qyapi_manage_addresslist-連絡先データ管理権限 |

### クエリパラメータ

| 名前 | タイプ | 必須 | 例 | 説明 |
| --- | --- | --- | --- | --- |
| access_token | String | はい | 6d1bxxxx | 当該インターフェイスを呼び出すためのアプリ認証情報。[社内アプリの access_token を取得する](/ja/open/development/obtain-orgapp-token)インターフェイスから取得します。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 例 | 説明 |
| --- | --- | --- | --- | --- |
| roleIds | String | はい | 1507113584 | ロールの roleId リスト。[ロールリストの取得](/ja/open/development/obtains-a-list-of-enterprise-roles)インターフェイスを呼び出して取得できます。  複数の roleId は半角カンマ（,）で区切り、最大 20 個まで指定できます。 |
| userIds | String | はい | user1 | 社員の userId。[電話番号によるユーザー検索](/ja/open/development/query-users-by-phone-number)を呼び出して取得できます。  複数の userId は半角カンマ（,）で区切り、最大 20 個まで指定できます。 |

### リクエスト例

```curl
curl -X POST "https://api.dingtalk.io/topapi/role/addrolesforemps" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=8f577dxxxx76f2a3a2' \
-d 'roleIds=1507113584' \
-d 'userIds=user1'
```


## レスポンス

### レスポンスボディ

| 名前 | タイプ | 例 | 説明 |
| --- | --- | --- | --- |
| errcode | Number | 0 | リターンコード。 |
| errmsg | String | ok | リターンコードの説明。 |
| request_id | String | emhw6ma4xmeg | リクエスト ID。 |

### レスポンスボディ例

```json
{
  "errcode": 0,
  "request_id": "emhw6ma4xmeg"
}
```

### エラーコード

当該インターフェイスの呼び出しでエラーが発生した場合は、エラーメッセージをもとに[グローバルエラーコード](/ja/open/development/server-api-error-codes-1)ドキュメントで解決策を検索してください。

| エラーコード（errcode） | エラーコードの説明（errmsg） | 解決策 |
| --- | --- | --- |
| 33011 | 無効な roleIds | roleIds が正しいか確認してください |
| 33012 | 無効な userIds | userId が正しいか確認してください |
| 12012 | 当該企業が存在しません | access_token が正しいか確認してください |
| 1002 | システムビジー | 後で再試行してください |
