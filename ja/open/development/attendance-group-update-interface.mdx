勤怠グループ ID を指定してこの API を呼び出し、勤怠グループの情報を更新します。

## リクエスト

| **基本情報** | |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/topapi/attendance/group/modify |
| HTTP メソッド | POST |
| 対応アプリタイプ | appType-社内アプリ |
| 必要な権限 | permission-qyapi_attendance_group_manage-勤怠グループ管理権限 |

### クエリパラメータ

| 名前 | タイプ | 必須 | 例 | 説明 |
| --- | --- | --- | --- | --- |
| access_token | String | はい | b5e95d101165xxxx | この API を呼び出すためのアプリ認証情報です。[社内アプリの access_token を取得](/ja/open/development/obtain-orgapp-token) API を呼び出して取得してください。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 例 | 説明 |
| --- | --- | --- | --- | --- |
| op_user_id | String | はい | 123dfd | 操作者のユーザー ID です。 |
| top_group | Object | はい |  | 勤怠グループの情報です。 |
| shift_vo_list | Object[] | いいえ |  | シフトの情報です。 |
| id | Number | いいえ | 123 | シフト ID です。[シフト概要の取得](/ja/open/development/enterprise-shift-query-in-batches) API を呼び出して id の値を取得してください。 |
| id | Number | はい | 123 | 勤怠グループ ID です。 **注意**  旧来の勤怠グループ識別子 group_key を使用している場合は、[groupKey から groupId への変換](/ja/open/development/convert-groupkey-to-groupid) API を呼び出して、group_key を group_id に変換してください。 |
| name | String | いいえ | 日勤勤怠 | 勤怠グループ名です。 |
| positions | Object[] | いいえ |  | 勤怠場所の設定です。 |
| address | String | いいえ | バイオテクノロジー産業パーク 経二路21号 | 住所です。 |
| corp_id | String | いいえ | 123dfd | 組織の CorpId です。[開発者コンソール](https://open-dev.dingtalk.io/#/index)のホームページで確認できます。 |
| latitude | String | いいえ | 36.687495 | 緯度です（小数点以下 6 桁まで）。 |
| longitude | String | いいえ | 101.750329 | 経度です（小数点以下 6 桁まで）。 |
| title | String | いいえ | 青海チベット高原自然史博物館 | 勤怠場所のタイトルです。 |
| accuracy | String | いいえ | 0 | 精度です。 **注意**  このフィールドは実際には機能せず、精度に影響しません。2022年3月7日に廃止されました。 |
| offset | Number | いいえ | 300 | 勤怠の有効範囲です。 |
| manager_list | String[] | いいえ | ["userId1","userId2"] | 勤怠グループのサブ管理者のユーザー ID リストです。 |
| enable_camera_check | Boolean | いいえ | true | 写真打刻を有効にするかどうかを指定します。   - **true**：オン - **false**（デフォルト）：オフ   **注意**  このパラメータは廃止されました。代わりに open_camera_check パラメータを使用してください。 |
| owner | String | いいえ | 123dfdf | 勤怠担当者のユーザー ID です。 |
| disable_check_when_rest | Boolean | いいえ | false | 休日の打刻に承認が必要かどうかを指定します。   - **true**：必要 - **false**：不要 |
| skip_holidays | Boolean | いいえ | true | 祝日をスキップするかどうかを指定します。   - **true**（デフォルト）：スキップする - **false**：スキップしない |
| enable_outside_check | Boolean | いいえ | true | 外勤打刻を許可するかどうかを指定します。   - **true**（デフォルト）：許可 - **false**：許可しない |
| disable_check_without_schedule | Boolean | いいえ | false | シフトが割り当てられていない場合に、社員の打刻を禁止するかどうかを指定します。   - **true**：禁止 - **false**：禁止しない |
| enable_emp_select_class | Boolean | いいえ | true | シフトが割り当てられていない場合に、社員がシフトを選択して打刻できるかどうかを指定します。   - **true**：許可 - **false**：許可しない |
| resource_permission_map | Object | いいえ |  | サブ管理者の権限スコープです。   - **w**：管理可能 - **r**：閲覧のみ |
| camera_check | String | いいえ | w | 写真打刻ルールの設定です。 |
| over_time_rule | String | いいえ | r | 残業ルールの設定です。 |
| check_position_type | String | いいえ | w | 打刻方法の設定です。 |
| check_time | String | いいえ | r | 勤怠時間の設定です。 |
| group_type | String | いいえ | w | 勤怠タイプの設定です。 |
| group_member | String | いいえ | r | 勤怠対象者の設定です。 |
| schedule | String | いいえ | w | 社員のシフト設定です。 |
| out_side_check | String | いいえ | r | 外勤打刻の設定です。 |
| workday_class_list | Number[] | いいえ | [12,12,12,12,0,0] | 1 週間のシフトリストです。 **注意**   - 固定シフト制の場合は必須です。0 は休日を表します。 - 配列内の値は、左から順に日曜日から土曜日までの毎日のシフト設定を表します。 |
| open_camera_check | Boolean | いいえ | true | 写真打刻を有効にするかどうかを指定します。   - **true**：オン - **false**（デフォルト）：オフ |

### リクエスト例

```curl
curl -X POST "https://api.dingtalk.io/topapi/attendance/group/modify" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=ca21b524-0a09-4909-b6e9-af087e28a86b' \
-d 'op_user_id=123dfd' \
-d 'top_group=null'
```

## レスポンス

### レスポンスボディ

| 名前 | タイプ | 例 | 説明 |
| --- | --- | --- | --- |
| result | Object |  | 勤怠グループの結果です。 |
| name | String | 日勤勤怠 | 勤怠グループ名です。 |
| id | Number | 123 | 勤怠グループ ID です。 |
| errmsg | String | 0 | エラーメッセージです。 |
| errcode | Number | ok | エラーコードです。 |
| success | Boolean | true | 呼び出しに成功したかどうかを示します。   - **true**：成功 - **false**：失敗 |

### レスポンスボディの例

```json
{
  "result":{
    "name":"日勤勤怠",
    "id":"123"
  },
  "errcode":0,
  "success":true,
  "errmsg":"ok"
}
```

### エラーコード

呼び出しでエラーが返された場合は、エラーメッセージをもとに[グローバルエラーコード](/ja/open/development/server-api-error-codes-1)ドキュメントで解決方法を確認してください。
