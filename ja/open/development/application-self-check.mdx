製品品質を確保するため、アプリをマーケットプレイスに公開または外部でプロモーションする前に、自己点検プロセスを完了してください。

## アプリ自己点検の概要

サードパーティ社内アプリの開発が完了したら、アプリの自己点検を実施します。

- 機能の自己点検。アプリサーバーのアウトバウンド IP やプッシュ設定などの基本設定を確認するために使用します。
- 安全審査。安全に関する項目を確認するために使用します。
- 安定性モニタリング。アプリのブランクスクリーン率や平均 API 遅延など、アプリの安定性を確認するために使用します。

## 手順

1. [Developer Console](https://open-dev.dingtalk.com/) にログインします。
2. 作成したサードパーティ社内アプリを選択します。
3. 対象のアプリをクリックして詳細ページを開き、**App Self-Inspection** を選択して、**Start Check** をクリックします。

   - **Function Self-Inspection（機能の自己点検）**

     アプリサーバーのアウトバウンド IP、プッシュ設定、API 連携など、アプリの基本設定を確認するために使用します。点検の詳細は以下のとおりです。

     |  |  |  |
     | --- | --- | --- |
     | 点検項目 | 説明 | 参照先 |
     | サーバーのアウトバウンド IP が設定されているか | アプリの開発情報でサーバーのアウトバウンド IP を設定します。 | [Development Overview](https://open.dingtalk.com/document/isvapp/isvapp-development-overview#) |
     | 有効なプッシュタイプが設定されているか | アプリの開発情報でプッシュ設定を完了します。 | [Overview](https://open.dingtalk.com/document/isvapp/callback-events-overview#) |
     | 公式受け入れ組織が現在のアプリを正常にインストールできているか | 後続の製品受け入れのため、DingTalk 公式受け入れ組織に現在のアプリをインストールします。アプリの自己点検ページで Start Check ボタンをクリックすると、公式受け入れ組織（CorpId: ding0ed2f6a472ab48fef5bf40eda33b7ba0、Open Platform App Review Group）が自動的にアプリをインストールします。 **注意** Start Check ボタンをクリックする際は、アプリのプッシュサービスが正常に動作していることを確認してください。 | — |
     | Monitoring Center の連携が完了しているか | Monitoring Center で連携を完了し、モニタリングデータを生成します。 | [Monitoring Center](https://open.dingtalk.com/document/isvapp/monitoring-center#) |
     | サーバーが Alibaba Cloud または Jushita にデプロイされているか | アプリのクラウドデプロイ方式として Alibaba Cloud または Jushita を選択します。詳しくは、アプリデプロイのドキュメントを参照してください。 | [Deployment Overview](https://open.dingtalk.com/document/isvapp/deployment-overview#) |
     | ミニプログラムバージョンが公開されているか | アプリのバージョン管理でミニプログラムバージョンを公開します。 | [Version Management and Publishing](https://open.dingtalk.com/document/isvapp/publish-and-install-isvapp#) |
     | 安全ゲートウェイドメインが申請され、アプリで使用されているか | マーケットプレイスに公開されるアプリ、すなわち Jushita にデプロイされるアプリは、安全ドメインを使用する必要があります。 | [DingTalk Security Domain](/zh/open/development/config-domain-name) |
4. **Next** をクリックして **Security Review** ページを開きます。
5. [Security Access Evaluation Guide](https://open.dingtalk.com/document/isvapp/security-access-evaluation-guide#) を参照し、アプリ公開の安全審査評価項目の資料を完成させて送信します。
6. 送信後、**Stability Monitoring** ページが開きます。

   **注意**

   DingTalk マーケットプレイスにアプリを公開する前に、安定性審査を完了してください。安定性モニタリングシステムと連携すると、DingTalk は以下のアプリデータを収集して表示し、データが基準を下回った場合に通知します。詳しくは、[Stability Certification Standards](https://open.dingtalk.com/document/isvapp/stabilistandards#) を参照してください。
7. **Integrate the Stability Monitoring System** を選択します。

   |  |  |  |
   | --- | --- | --- |
   | データ指標 | 説明 | 指標要件 |
   | Monitoring Center の API 成功率 | Monitoring Center の **Monitoring Metrics** -> **API Requests** -> **Success Rate** で確認します。 | ≥98.99% |
   | Monitoring Center の平均 API 遅延 | Monitoring Center の **Monitoring Metrics** -> **API Requests** -> **Request Latency** で確認します。 | &lt;300 |
   | Monitoring Center の JS エラー率 | Monitoring Center の **Monitoring Metrics** -> **JS Errors** -> **Error Count to PV Ratio** で確認します。 | &lt;1.99% |
   | Monitoring Center のブランクスクリーン率 | Monitoring Center の **Monitoring Metrics** -> **Blank Screen Errors** -> **Blank Screen Rate** で確認します。 | &lt;1.99% |
   | dd.config 成功率 | **dd.config** JSAPI 呼び出しの1日平均成功率です。 | ≥98.99% |
   | HTTP プッシュ成功率 | プッシュタイプが HTTP または SyncHttp の場合、成功率は統計期間中に DingTalk がコールバック URL へプッシュした成功率です（**1,500 ms を超えるプッシュはタイムアウト失敗としてカウントされます**）。 | ≥98.99% |
8. **Self-Inspection Complete** をクリックして自己点検を完了します。アプリの自己点検プロセスを完了すると、結果は以下のようになります。

   アプリの自己点検が完了すると、DingTalk マーケットプレイスへの公開やオフラインプロモーション活動の実施が可能になります。
