---

description: "DingTalk の API で、指定した社員の休暇タイプごとの休暇残数変更記録を一括取得する方法を解説します。残数の初期化、クォータ消費、残数更新の履歴をページングで取得できます。"
---

この API を呼び出して、社員の休暇残数変更記録をすべて取得します。記録には、休暇残数の初期化、社員が消費したクォータ、休暇残数の更新が含まれます。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/v1.0/attendance/vacations/records/query |
| HTTP メソッド | POST |
| 対応アプリタイプ | appType-社内アプリ　appType-サードパーティ社内アプリ |
| 権限 | permission-qyapi_holiday_readonly-DingTalk 休暇照会権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | 文字列 | はい | この API を呼び出すためのアクセス認証情報です。次の方法で取得します。   - 社内アプリ：[社内アプリのアクセストークンを取得](/ja/open/development/obtain-the-access-token-of-an-internal-app) API を呼び出します。 - サードパーティ社内アプリ：サードパーティアプリを承認した組織のアクセストークンを取得する API を呼び出します。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| opUserId | 文字列 | はい | OA承認のアプリ権限を持つ社内の管理者の userId です。スーパー管理者の userId を指定してください。[管理者リストを取得](/ja/open/development/query-the-administrator-list) API を呼び出し、レスポンス内のスーパー管理者の `userId` フィールドを使用します。 |
| leaveCode | 文字列 | はい | 休暇タイプの一意の識別子です。[休暇ルールリストを照会](/ja/open/development/holiday-type-query) API を呼び出して `leave_code` の値を取得します。 |
| userIds | 文字列の配列 | はい | 照会対象の社員の userId リストです。1 回の呼び出しで最大 50 件の userId を指定できます。 |
| pageNumber | long | はい | ページングカーソルです。   - 初回の照会時は 0 を指定します。 - 2 回目以降は、前回の照会までの累積オフセットを指定します。 |
| pageSize | 整数 | はい | ページングのオフセットです。最大値：200。 |
