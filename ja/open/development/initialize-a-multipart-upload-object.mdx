本 API を呼び出して、ファイル分割アップロードを初期化します。

## API 呼び出し説明

API 呼び出しのフローは、以下のステップを参考にしてください。

ステップ 1：本 API を呼び出して、ファイル分割アップロードを初期化し、アップロード識別子 uploadKey を取得します。

ステップ 2：[ファイル分割アップロード情報の取得](/ja/open/development/obtains-the-information-about-multipart-uploads-of-an-object) API を呼び出して、各分割ファイルのアップロード情報を取得します。

ステップ 3：各分割ファイルに対してアップロード操作を繰り返し実行します。

ステップ 4：ステップ 1 の API で取得したアップロード識別子 uploadKey を使用して、[ファイル送信](/ja/open/development/submittal-file) API を呼び出し、アップロードを完了します。

完全なサンプルは以下を参考にしてください。

            long curPartSize = (i + 1 == partCount) ? (fileLength - startPos) : partSize;

            CommitFileHeaders commitFileHeaders = new CommitFileHeaders();
            commitFileHeaders.xAcsDingtalkAccessToken = "accessToken";
            CommitFileRequest.CommitFileRequestOption commitFileRequestOption

    private void uploadPartFile(long start, long size, GetMultipartFileUploadInfosResponseBody.GetMultipartFileUploadInfosResponseBodyMultipartHeaderSignatureInfosHeaderSignatureInfo headerSignatureInfo, File file) throws Exception {
        InputStream inputStream = new FileInputStream(file);
        if (start > 0) {
            inputStream.skip(start);
        }

        URL url = new URL(headerSignatureInfo.getResourceUrls().get(0));
        HttpURLConnection connection = (HttpURLConnection)url.openConnection();
        connection.setDoOutput(true);
        connection.setRequestMethod("PUT");
        connection.setUseCaches(false);
        if (headerSignatureInfo.getHeaders() != null) {
            for (Map.Entry<String, String> entry : headerSignatureInfo.getHeaders().entrySet()) {
                connection.setRequestProperty(entry.getKey(), entry.getValue());
            }
        }
        connection.setReadTimeout(10000);
        connection.setConnectTimeout(10000);
        connection.connect();
        OutputStream out = connection.getOutputStream();
        byte[] buffer = new byte[1024];
        long remain = size;
        for (;remain > 0;) {
            int sizeToRead = remain < buffer.length ? (int)remain : buffer.length;
            int rsz = inputStream.read(buffer, 0, sizeToRead);
            if (rsz < 0) {
                break;
            }
            out.write(buffer, 0, rsz);
            remain -= rsz;
        }
        out.flush();
        out.close();
        int responseCode = connection.getResponseCode();
        if (responseCode == 200) {
            System.out.println("アップロード成功");
        } else {
            System.out.println("アップロード失敗");
        }
        connection.disconnect();
    }
}

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | `https://api.dingtalk.io/v1.0/storage/spaces/{spaceId}/files/multiPartUploadInfos/init` |
| HTTP Method | POST |
| 対応アプリタイプ | appType-社内アプリ　appType-サードパーティ社内アプリ |
| 権限要件 | permission-Storage.UploadInfo.Read-企業ストレージファイルアップロード情報の読み取り権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | 必須 | 本 API を呼び出すためのアクセス認証情報。以下の方法で取得します：   - 社内アプリの場合、[社内アプリの accessToken 取得](/ja/open/development/obtain-the-access-token-of-an-internal-app#) API を呼び出して取得します。 - サードパーティ社内アプリの場合、[サードパーティアプリの権限付与企業の accessToken 取得](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#) API を呼び出して取得します。 |

### パスパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| spaceId | String | 必須 | スペース Id。[スペースの追加](/ja/open/development/add-space#) API を呼び出して id パラメータ値を取得できます。 |

### クエリパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| unionId | String | 必須 | 操作者の unionId。[ユーザー詳細の照会](/ja/open/development/query-user-details#) API を呼び出して取得できます。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| option | Object | 任意 | オプションパラメータ。 |
| storageDriver | String | 任意 | ファイルストレージドライバタイプ。現在は DINGTALK のみサポート。 |
| preCheckParam | Object | 任意 | 事前チェックフィールド。    ファイル名、ファイル完全性、容量のチェックを実現できます。 |
| md5 | String | 任意 | ファイル md5 値、`DigestUtils.md5Hex()`。    ファイル完全性チェック。指定しない場合はチェックを行いません。 |
| size | Long | 任意 | ファイルサイズ、単位 Byte。    容量関連のチェック。指定しない場合はチェックを行いません。 |
| parentId | String | 任意 | 親ディレクトリ Id。ルートディレクトリの場合、本パラメータは 0 です。[ファイルまたはフォルダーリストの取得](https://open.dingtalk.com/document/development/obtain-the-file-list-storage#) API を呼び出して parentId パラメータ値を取得します。    同一ディレクトリ内のファイル名の重複チェックに使用します。 |
| name | String | 任意 | ファイル名。命名には以下の要件があります：- 先頭と末尾に空白を含めることはできません。含まれている場合は自動的に除去されます - 特殊文字（タブ、`*`、`"`、`<`、`>`、`|`）を含めることはできません - `.` で終わることはできません - ファイル名の妥当性とファイル名の重複チェック。 |
| preferRegion | String | 任意 | 優先地域。   - **ZHANGJIAKOU**：張家口 - **SHENZHEN**：深セン - **SHANGHAI**：上海 - **SINGAPORE**：シンガポール - **UNKNOWN**：不明     リソースをどの地域に保存することを優先するか。近距離アップロードなどの機能を実現できます。 |
