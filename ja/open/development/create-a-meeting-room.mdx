本インターフェースを呼び出して、会議室を作成します。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/v1.0/rooms/meetingrooms |
| HTTP Method | POST |
| サポートするアプリタイプ | appType-社内アプリ　appType-サードパーティ社内アプリ |
| 必要な権限 | permission-VideoConference.Conference.Write-ビデオ会議情報管理権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | はい | 本インターフェースを呼び出すためのアクセス認証情報。以下の方法で取得します：   - 社内アプリの場合、[社内アプリのアクセストークンを取得](https://open.dingtalk.io/document/development/obtain-the-access-token-of-an-internal-app)インターフェースを呼び出して取得します。 - サードパーティ社内アプリの場合、[サードパーティアプリ権限付与企業のアクセストークンを取得](https://open.dingtalk.io/document/development/obtain-the-access-token-of-the-authorized-enterprise-1)インターフェースを呼び出して取得します。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| unionId | String | はい | 操作者のunionId。[ユーザー詳細を取得](https://open.dingtalk.io/document/development/query-user-details)インターフェースを呼び出して取得します。 |
| roomName | String | はい | 会議室名。 |
| roomCapacity | Integer | いいえ | 会議室の収容人数。現時点で上限はありません。 |
| roomPicture | String | いいえ | 会議室の画像。 |
| roomStatus | Integer | はい | 会議室のステータス。   - **0**：全員が使用可能 - **1**：管理者のみ使用可能 - **2**：一部のメンバーに権限あり |
| roomLocation | Object | いいえ | 会議室の位置情報。 |
| title | String | いいえ | 会議室位置の見出し。 |
| desc | String | いいえ | 会議室位置の詳細情報。 |
| roomLabelIds | Array of Long | いいえ | タグID。   - **1**：テレビ - **2**：電話番号 - **3**：プロジェクター - **4**：ホワイトボード - **5**：ビデオ会議 |
| isvRoomId | String | はい | 呼び出し側の外部会議室ID。呼び出し側は自社システム内の会議室IDを渡すことができます。      呼び出し側が外部会議室と関連しない場合、自社のエンティティ会議室番号を渡すことができます。 |
| groupId | Long | いいえ | グループ分けID。[会議室グループ分けリストを取得](https://open.dingtalk.io/document/development/query-meeting-rooms-groups)インターフェースを呼び出して取得します。 |
| reservationAuthority | Object | いいえ | roomStatusが一部権限の場合に、設定する会議室予約権限。 |
| authorizedMembers | Array | いいえ | 権限を持つユーザーリスト。 |
| memberId | String | いいえ | ユーザーのID。memberTypeの設定に応じて指定します。   - **メンバー**：ユーザーのunionId。[ユーザー詳細を取得](https://open.dingtalk.io/document/development/query-user-details)インターフェースを呼び出して取得します。 - **部門**：部門ID（dept_id）。[部門リストを取得](https://open.dingtalk.io/document/development/obtain-the-department-list-v2)インターフェースを呼び出して取得します。 |
| memberType | String | いいえ | ユーザーのタイプ：   - **メンバー**：user - **部門**：dept |
| memberName | String | いいえ | ユーザーの名前：   - **メンバー**：ユーザー名 - **部門**：部門名 |
| enableCycleReservation | Boolean | いいえ | 会議室が定期予約をサポートするかどうか：   - **true**：はい - **false**：いいえ |
| openReservation | Boolean | いいえ | 会議室の予約を開放するかどうか：   - **true**：はい - **false**：いいえ |
| roomDescription | String | いいえ | 会議室の説明情報。 |
