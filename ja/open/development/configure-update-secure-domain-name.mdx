リソースのインポート後に、DingTalk の安全ドメインを設定します。本ドキュメントの手順に沿ってセットアップを完了してください。

## 前提条件

作業を開始する前に、Developer Console に関連付けられた Alibaba Cloud アカウント（Compute Nest デプロイ）で SLB が購入済みであること、および該当の SLB に [HTTP プロトコルのリスニングポート](https://help.aliyun.com/document_detail/85949.html?spm=a2c4g.86438.0.0.19195491uwAdyO)が設定されていることを確認してください。現在は CLB のみサポートしています。

**お知らせ**

443 や 8443 などの一般的な HTTPS ポートを使用して、HTTP から HTTPS へのリダイレクトを行わないでください。

## **手順**

1. Developer Console にログインし、アプリの詳細ページに移動して、**アプリ公開 > アプリセルフチェック**をクリックします。
2. 関連付けるプライベートネットワーク SLB を選択し、権限付与の同意事項を選択したうえで、**関連**をクリックします。
3. 関連付けの完了後、ドメインの審査とドメイン設定の初期化を待ちます。

   **Note**

   安全ドメインのバインドリクエストを送信した後、DingTalk の安全審査をお待ちください。通常は 1〜2 営業日かかります。承認されると、プライベートネットワーク SLB が安全ドメインに自動的にバインドされ、有効になるまで 1〜2 営業日かかります。ステータスの更新をご確認ください。リクエストが辞退された場合は、内容を修正して申請を再送信してください。
4. アプリで安全ドメインを更新します。

   - プッシュタイプが SyncHTTP の場合は、コールバック URL のプッシュアドレスで DingTalk の安全ドメインを使用します。
   - 開発者のサーバー API ドメインには DingTalk の安全ドメインを使用します。
   - アプリがフロントエンドとバックエンドを分離したアーキテクチャで構築されていない場合は、アプリのホームページ URL に DingTalk の安全ドメインを使用します。
