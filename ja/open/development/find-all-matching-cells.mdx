本インターフェースを呼び出すと、DingTalk スプレッドシートの指定ワークシート内で、対象テキストを含むすべてのセルを検索し、一致したセルの位置情報リストを返します。大量データから特定コンテンツを一括で特定するシーンに適しており、完全一致、大文字小文字の区別、正規表現、数式内検索など、複数の検索モードに対応します。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | `https://api.dingtalk.io/v1.0/doc/workbooks/{workbookId}/sheets/{sheetId}/findAll` |
| HTTP Method | POST |
| 対応アプリタイプ | appType-社内アプリ |
| 権限要件 | permission-Document.Workbook.Read-DingTalk スプレッドシート読み取り権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | 必須 | 本インターフェースを呼び出すためのアクセス認証情報です。[社内アプリの accessToken を取得](https://open.dingtalk.io/document/development/obtain-the-access-token-of-an-internal-app) インターフェースを呼び出して取得します。 |

### パスパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| workbookId | String | 必須 | スプレッドシートファイル ID。[ナレッジベース API](https://open.dingtalk.io/document/development/knowledge-base-overview) が返す `nodeId(dentryUuid)` がスプレッドシートの `workbookId` です。[ノードを取得](https://open.dingtalk.io/document/development/get-node) および [ナレッジベースドキュメントを作成](https://open.dingtalk.io/document/development/create-team-space-document) インターフェースを呼び出して取得できます。 |
| sheetId | String | 必須 | ワークシート ID またはタイトル。[すべてのワークシートを取得](https://open.dingtalk.io/document/development/obtain-all-worksheets) インターフェースを呼び出して、id とワークシートのタイトルを取得できます。 |

### クエリパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| operatorId | String | 必須 | 操作者の unionId。[ユーザー詳細を照会](https://open.dingtalk.io/document/development/query-user-details) インターフェースを呼び出して取得します。操作者に権限がない場合、インターフェースは `The operator has no permission` エラーを返します。 |
| select | String | 任意 | 戻り値のフィールドを絞り込みます。本パラメータを指定しない場合、すべてのフィールドが返されます。   - select=a1Notation の場合、本インターフェースは a1Notation フィールドのみを返します。 - 複数のフィールドを返す場合は、カンマで区切ります。例：select=a1Notation,values の場合、本インターフェースは a1Notation と values フィールドのみを返します。       パフォーマンスを向上させ、今後戻り値が追加された際の API タイムアウトを防ぐため、本パラメータの指定を推奨します。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| text | String | 必須 | 検索するテキスト。**useRegExp** がオンの場合は正規表現パターンとなります。例：「\\d+」 |
| findOptions | Object | 必須 | 検索オプション。 |
| matchEntireCell | Boolean | 任意 | セル全体に一致させるかどうか。指定可能な値：   - **true**：はい - **false**：いいえ（デフォルト） |
| matchCase | Boolean | 任意 | 大文字小文字を区別するかどうか。指定可能な値：   - **true**：はい - **false**：いいえ（デフォルト） |
| useRegExp | Boolean | 任意 | text を正規表現として扱うかどうか。指定可能な値：   - **true**：はい - **false**：いいえ（デフォルト） |
| matchFormulaText | Boolean | 任意 | 数式の元テキストで検索するかどうか。指定可能な値：   - **true**：はい - **false**：いいえ（デフォルト）   例えば、あるセルに数式「=A1+B1」が入力されており、表示値が 4 の場合   - 検索テキストが「4」で matchFormulaText が true のとき、結果に含まれません。 - 検索テキストが「=A1」で matchFormulaText が true のとき、結果に含まれます。 |
| scope | String | 任意 | 検索範囲。A1 表記で指定する Range アドレス形式です。 |
| includeHidden | Boolean | 任意 | 非表示のセル（行列の非表示、絞り込み、グループ分けなどの機能によって不可視となったセル）を含めるかどうか。閲覧権限のないセルは含まれません。指定可能な値：   - **true**：はい - **false**：いいえ（デフォルト） |
| unionCells | Boolean | 必須 | 検出されたセルのアドレスを集約するかどうか。集約することを推奨します。集約しない場合、大量のアドレスが返される可能性があります。指定可能な値：   - **true**：はい - **false**：いいえ（デフォルト） |
