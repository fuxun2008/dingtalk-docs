title: "スペース配下のすべてのファイルまたはフォルダー一覧を取得"

本インターフェースを呼び出して、スペース配下のすべてのファイルまたはフォルダー一覧をフラットに取得します。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | `https://api.dingtalk.io/v1.0/storage/spaces/{spaceId}/dentries/listAll` |
| HTTP Method | POST |
| 対応アプリタイプ | appType-社内アプリ　appType-サードパーティ社内アプリ |
| 必要な権限 | permission-Storage.File.Read-企業ストレージファイル読み取り権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | はい | 本インターフェースを呼び出すためのアクセス認証情報。以下の方法で取得します：   - 社内アプリの場合は、[社内アプリのaccessTokenを取得](https://open.dingtalk.io/document/development/obtain-the-access-token-of-an-internal-app#)インターフェースを呼び出して取得します。 - サードパーティ社内アプリの場合は、[サードパーティアプリ認可企業のaccessTokenを取得](https://open.dingtalk.io/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#)インターフェースを呼び出して取得します。 |

### パスパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| spaceId | String | はい | スペースID。[スペース追加](https://open.dingtalk.io/document/development/add-space#)インターフェースを呼び出してidパラメータの値を取得します。 |

### クエリパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| unionId | String | はい | 操作ユーザーのunionId。[ユーザー詳細照会](https://open.dingtalk.io/document/development/query-user-details#)インターフェースを呼び出して取得できます。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| option | Object | いいえ | オプションパラメータ。 |
| nextToken | String | いいえ | ページングカーソル。   - 初回呼び出しの場合は、このパラメータを渡しません。 - 2回目以降の呼び出しの場合は、前回の呼び出しで返されたnextTokenを渡します。 |
| maxResults | Integer | いいえ | 1ページあたりのエントリ数。デフォルトは50、最大は50です。 |
| order | String | いいえ | 並べ替えルール。現時点では編集時間による並び替えのみサポートします。   - **ASC**（デフォルト）：昇順 - **DESC**：降順   - 昇順の場合、ページング取得中にファイルが変更されると、データが重複して取得される可能性があります。 - 降順の場合、ページング取得中にファイルが変更されると、データが欠落する可能性があります。 |
| withThumbnail | Boolean | いいえ | ファイルサムネイルのリンクを取得するかどうか。   - **true**：はい - **false**（デフォルト）：いいえ   必要に応じて取得してください。取得するとインターフェースの処理時間が増加します。 |
