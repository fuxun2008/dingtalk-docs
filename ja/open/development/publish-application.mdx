このドキュメントでは、DingTalk の内部アプリを公開する方法を説明します。このドキュメントの手順に従って、内部アプリの公開を完了してください。

## **前提条件**

[アプリの作成](/ja/open/dingstart/create-application)のプロセスを完了しておきます。

## **手順**

1. [開発者コンソール](https://open-dev.dingtalk.com/#/)にログインし、対象のアプリをクリックして詳細ページを開きます。
2. **App Release** > **Version Management and Release** > **Create a Version** をクリックします。
3. バージョンの詳細を設定します。

   1. アプリのバージョン番号：1.0.0 の形式でバージョン番号を入力します。最小値は 1.0.0 で、各セグメントの最大値は 99（1.99.0）です。1.100.0 の形式はサポートされていません。
   2. バージョンの説明：このバージョンの変更点を簡単に記述します。
   3. 公開するコンテンツ：公開したいコンテンツを選択します。

      **重要**

      ワークベンチ以外のアプリ（ミニプログラムアプリまたは Web アプリ）を公開する場合は、ワークベンチアプリも合わせて選択して公開する必要があります。ワークベンチアプリを選択しない場合、デフォルトでオフラインになり、稼働中のアプリが正常に動作しなくなります。したがって、アプリのバージョンを公開する際は慎重に行い、正常な稼働を維持するために、ワークベンチアプリも同時に選択して公開してください。

      - ワークベンチアプリ：ワークベンチアプリでは、ミニプログラムまたは Web アプリのいずれかを選択でき、ミニプログラムはバージョンごとに選択できます。

        **注意**

        ミニプログラムと Web アプリのいずれか一方のみを選択できます。
      - ボット：**App Capabilities** > **Bots** の下に保存されたボットアプリを公開します。
      - クールアプリ：**App Capabilities** > **Cool App** の下で作成・リリースされたすべてのクールアプリを一括で公開します。
      - Magic Wand アプリ：**App Capabilities** > **AI App** > **Magic Wand App** の下に保存された Magic Wand アプリを公開します。
      - デジタル社員：**App Capabilities** > **AI App** > **Tabler** の下に保存された Tabler を公開します。
   4. アプリの可視範囲：特定のユーザーまたは部門のみがアプリを利用できるように、適切な可視範囲を選択します。
4. 設定が完了したら、**Save** > **Publish Directly** をクリックしてアプリの公開を完了します。

公開が完了すると、Version Management and Release の一覧で公開済みのアプリを確認できます。

## **その他の情報**

アプリの公開後、次の方法で追加して利用できます。

### **ミニプログラムアプリ / Web アプリ**

ミニプログラムアプリまたは Web アプリを公開すると、クライアントサイドのワークベンチで該当するアプリを検索して利用できます。

### **ボット**

1. **DingTalk クライアントサイド** > 指定のグループチャットを開きます。
2. **グループ設定**をクリックしてグループ設定ページを開きます。
3. **グループ管理** > **ボット**をクリックしてボット管理ページを開きます。
4. ボットの追加をクリックし、該当するボットを選択して追加を完了します。

### **Magic Wand アプリ**

- **Magic Wand アプリ**：Magic Wand アプリを公開すると、DingTalk クライアントサイドで Magic Wand を利用できます。

  1. DingTalk ホームページを開き、右上の「**/**」をクリックして DingTalk Tabler ページを開きます。

     **注意**

     この Magic Wand アプリのスキルを利用する前に、DingTalk クライアントサイドの現在の組織が、アプリを公開した組織に切り替わっていることを確認してください。
  2. Tabler ページで、左上の「**Tabler ⇋**」をクリックし、Tabler の一覧から今公開した Magic Wand アプリを選択します。
  3. 入力ボックスにリクエストを入力し、送信アイコンをクリックします。Magic Wand は会話形式で出力を返します。

### **Tabler**

- **Tabler**：公開された Tabler は、該当する組織の組織構成に自動的に追加されます。Tabler を利用するには、次を参照してください。

  メイン検索ボックスで Tabler 名を検索して利用します。
