---
title: "予定参加者を削除"
---

本 API を呼び出して、予定参加者から指定したユーザーを削除します。

## API 呼び出し説明

予定参加者の操作は 1 回あたり最大 500 名まで対応し、最大 5000 名の予定まで操作可能です。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | `https://api.dingtalk.io/v1.0/calendar/users/{userId}/calendars/{calendarId}/events/{eventId}/attendees/batchRemove` |
| HTTP Method | POST |
| 対応アプリタイプ | appType-社内アプリ　appType-サードパーティ社内アプリ　appType-サードパーティ個人アプリ |
| 権限要件 | permission-Calendar.Event.Write-カレンダーアプリにおける予定の書き込み権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-client-token | String | いいえ | 冪等性チェック。       - 同一の `x-client-token` は同一リクエストを示します。 - 有効期限は 1 日です。 |
| x-acs-dingtalk-access-token | String | はい | 本 API を呼び出すためのアクセス認証情報。以下の方法で取得します：   - 社内アプリの場合は、[社内アプリの accessToken を取得](https://open.dingtalk.io/document/development/obtain-the-access-token-of-an-internal-app#) API を呼び出して取得します。 - サードパーティ社内アプリの場合は、[サードパーティアプリで認可された企業の accessToken を取得](https://open.dingtalk.io/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#) API を呼び出して取得します。 - サードパーティ個人アプリの場合は、[ユーザートークンを取得](https://open.dingtalk.io/document/development/obtain-user-token#) API を呼び出して取得します。 |

### パスパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| userId | String | はい | 予定作成者の unionId。   - 社内アプリおよびサードパーティ社内アプリの場合は、[ユーザー詳細を照会](https://open.dingtalk.io/document/development/query-user-details#) API を呼び出して unionid パラメータ値を取得します。 - サードパーティ個人アプリの場合は、[ユーザー連絡先のプロフィールを取得](https://open.dingtalk.io/document/development/dingtalk-retrieve-user-information#) API を呼び出して unionId パラメータ値を取得します。 |
| calendarId | String | はい | 予定が属するカレンダー ID。一律 primary で、ユーザーのメインカレンダーを示します。 |
| eventId | String | はい | 予定 ID。[予定リストを照会](https://open.dingtalk.io/document/development/query-an-event-list#) API を呼び出して id パラメータ値を取得できます。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| attendeesToRemove | Array | いいえ | 削除対象の予定参加者リスト。 |
| id | String | いいえ | ユーザーの unionId。   - 社内アプリおよびサードパーティ社内アプリの場合は、[ユーザー詳細を照会](https://open.dingtalk.io/document/development/query-user-details#) API を呼び出して unionid パラメータ値を取得します。 - サードパーティ個人アプリの場合は、[ユーザー連絡先のプロフィールを取得](https://open.dingtalk.io/document/development/dingtalk-retrieve-user-information#) API を呼び出して unionId パラメータ値を取得します。 |
