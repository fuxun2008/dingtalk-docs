---

本インターフェースを呼び出して、企業の外部連絡先リストを取得します。

## リクエスト

| **基本情報** | |
| --- | --- |
| HTTP URL | https://oapi.dingtalk.io/topapi/extcontact/list |
| HTTP Method | POST |
| サポートするアプリタイプ | appType-社内アプリappType-サードパーティ社内アプリ |
| 権限要件 | permission-qyapi_ext_read-企業の外部連絡先の読み取り権限 |

### クエリパラメータ

| 名前 | タイプ | 必須 | 例 | 説明 |
| --- | --- | --- | --- | --- |
| access_token | String | はい | 6d1bxxxx | 当該 API を呼び出すためのアプリ認証情報。   - 社内アプリの場合、[社内アプリの access_token を取得する](/ja/open/development/obtain-orgapp-token)インターフェースで取得します。 - サードパーティ社内アプリの場合、サードパーティ企業の access_token を取得するインターフェースで取得します。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 例 | 説明 |
| --- | --- | --- | --- | --- |
| size | Number | いいえ | 20 | ページング検索をサポートし、offset パラメータと同時に設定した場合のみ有効になります。本パラメータはページサイズを表し、最大 100 です。 |
| offset | Number | いいえ | 0 | ページング検索をサポートし、size パラメータと同時に設定した場合のみ有効になります。本パラメータはオフセット量を表し、0 から開始します。 |

### リクエスト例

```curl
curl -X POST "https://oapi.dingtalk.io/topapi/extcontact/list" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=b5039xxxx8bcc' \
-d 'offset=0' \
-d 'size=20'
```

Java

```text
DingTalkClient client = new DefaultDingTalkClient("https://oapi.dingtalk.io/topapi/extcontact/list");
OapiExtcontactListRequest req = new OapiExtcontactListRequest();
req.setSize(20L);
req.setOffset(0L);
OapiExtcontactListResponse rsp = client.execute(req, access_token);
System.out.println(rsp.getBody());
```

Python

```python
import dingtalk.api

req=dingtalk.api.OapiExtcontactListRequest("https://oapi.dingtalk.io/topapi/extcontact/list")

req.offset=0
req.size=20
try:
  resp= req.getResponse(access_token)
  print(resp)
except Exception,e:
  print(e)
```

PHP

```php
include "TopSdk.php";
date_default_timezone_set('Asia/Shanghai');

$c = new DingTalkClient(DingTalkConstant::$CALL_TYPE_OAPI, DingTalkConstant::$METHOD_POST , DingTalkConstant::$FORMAT_JSON);
$req = new OapiExtcontactListRequest;
$req->setOffset("0");
$req->setSize("20");
$resp = $c->execute($req, $access_token, "https://oapi.dingtalk.io/topapi/extcontact/list");
```

C#

```text
IDingTalkClient client = new DefaultDingTalkClient("https://oapi.dingtalk.io/topapi/extcontact/list");
OapiExtcontactListRequest req = new OapiExtcontactListRequest();
req.Offset = 0L;
req.Size = 20L;
OapiExtcontactListResponse rsp = client.Execute(req, access_token);
Console.WriteLine(rsp.Body);
```

### エラーコード

当該インターフェースの呼び出し時にエラーが発生した場合、エラーメッセージをもとに[グローバルエラーコード](/ja/open/development/server-api-error-codes-1)ドキュメントで解決方法を検索してください。

| エラーコード（errcode） | エラーコードの説明（errmsg） | 解決方法 |
| --- | --- | --- |
| 33009 | 無効な tokenGrantType | access_token が正しいかご確認ください |
| 40069 | 無効な size | ページサイズを調整してください |
| 40068 | 無効なオフセット量 | オフセット量を調整してください |
| 400001 | システムエラー | 後でもう一度お試しください |
