この API を呼び出して、組織向けに作成した承認テンプレートを削除します。テンプレート配下で作成されたインスタンスとタスクもあわせて削除できます。

## API 呼び出し説明

- 社内アプリの場合、削除されるのはテンプレートのみです。テンプレートから作成されたインスタンスとタスクは削除されません。
- サードパーティ社内アプリの場合、テンプレートに加えて、テンプレートから作成されたインスタンスとタスクも削除されます。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/v1.0/workflow/processCentres/schemas |
| HTTP メソッド | DELETE |
| 対応アプリタイプ | appType-社内アプリ　appType-サードパーティ社内アプリ |
| 必要な権限 | permission-Workflow.Form.Write-作業フローテンプレートの書き込み権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | はい | この API を呼び出すためのアクセス認証情報です。次の方法で取得します。   - 社内アプリの場合は、[社内アプリのアクセストークンの取得](/ja/open/development/obtain-the-access-token-of-an-internal-app) API を呼び出します。 - サードパーティ社内アプリの場合は、サードパーティアプリを承認した組織のアクセストークンを取得する API を呼び出します。 |

### クエリパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| processCode | String | はい | テンプレートコードです。   - 社内アプリの場合は、[テンプレートコードの取得](/ja/open/development/obtain-the-template-code) API を呼び出して取得します。 |
| cleanRunningTask | Boolean | いいえ | 実行中のタスクをクリーンアップするかどうかを指定します。   - **true**：はい - **false**：いいえ |

### リクエスト例

HTTP

```http
DELETE /v1.0/workflow/processCentres/schemas?processCode=proc-abc&cleanRunningTask=false HTTP/1.1
Host:api.dingtalk.io
x-acs-dingtalk-access-token:6d1bxxxx
Content-Type:application/json
```
