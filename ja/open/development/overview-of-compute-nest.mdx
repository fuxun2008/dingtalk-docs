## Compute Nest とは

Compute Nest は、Alibaba Cloud がエンタープライズ向けアプリケーションサービスプロバイダーに提供するサービス管理プラットフォームです。Compute Nest では、サービスプロバイダーは統一された環境内でアプリを管理し、クラウドリソースとアプリケーションの診断をワンクリックで実行し、統合された監視・イベント収集・アラートシステムを利用してアプリケーションを安定稼働させることができます。

## オプション 1：Alibaba Cloud + Compute Nest + 連絡先の暗号化

### コアプロセス

### プロセス概要

1. プロダクトソリューションプロバイダーとしてオンボーディングする際、組織はすでにパートナープラットフォーム上で[安全責任共有および安全誓約](https://partner.dingtalk.com/indexReource#/isv_service/contract_manage)に署名済みです。
2. [DingTalk 開発者コンソール](https://open-dev.dingtalk.com/?spm=dd_developers.header.unLogin.openDevBtn#/)にログインして Alibaba Cloud アカウントを関連付け、DingTalk がセキュリティリスクチェックと脆弱性スキャンを実行できるよう権限付与します。詳細はアプリのデプロイを参照してください。
3. 関連付けた Alibaba Cloud アカウント内で、ネットワーク分離のために専用の VPC を作成して DingTalk アプリをデプロイし、アプリリソースを Compute Nest に登録します。
4. 開発して公開したアプリに連絡先の暗号化を統合済みです。
5. 開発して公開したアプリで、[DingTalk 安全ドメイン](/zh/open/development/config-domain-name)へのアクセスを申請・設定済みです。
6. 開発して公開したアプリが[アプリケーションセルフチェック](/zh/open/development/application-self-check)プロセスを通過し、セキュリティ受入審査資料を提出して審査に合格済みです。

### その他のデプロイ時セキュリティ要件

1. データベースには、外部システムに直接接続したりデータを外部へエクスポートしたりするためのパブリックネットワークアドレスを設定してはなりません。
2. 個人の機微情報（電話番号、身分証番号、銀行口座番号、パスワードなど）は、個人情報保護法の要件に従って分類、暗号化、非識別化（マスキングなど）する必要があります。
3. DingTalk と合意したセキュリティ要件に従い、DingTalk が実施するセキュリティチェックに協力する責任を負います。

## 参考：個人の機微情報の判定

-- 出典：GB/T 35273—2020「情報安全技術 個人情報安全規範」

個人の機微情報とは、いったん漏えい、違法提供、または不正使用された場合に、個人の身体・財産の安全を脅かし、個人の名誉、心身の健康を害し、または差別的取り扱いを招くおそれのある個人情報を指します。一般に、14 歳以下の児童の個人情報および自然人のプライバシーに関わる情報は、個人の機微情報に該当します。ある情報が個人の機微情報に該当するかどうかは、以下の観点から判断できます。

漏えい：個人情報がいったん漏えいすると、個人情報の主体および当該個人情報を収集・利用する組織や機関はその管理を失い、拡散範囲や利用目的を制御できなくなります。一部の個人情報は漏えい後、個人情報主体の意思に反して直接利用されたり、他の情報との関連分析に付されたりして、個人情報主体の権利利益に重大なリスクをもたらす可能性があるため、個人の機微情報と判定すべきです。例えば、個人情報主体の身分証のコピーが、他人によって電話 SIM カードの実名登録や銀行口座・カードの開設に利用される場合などです。

違法提供：一部の個人情報は、主体が権限付与し同意した範囲を超えて拡散されるだけで、個人情報主体の権利利益に重大なリスクをもたらすため、個人の機微情報と判定すべきです。性的指向、預金情報、感染症の既往歴などが例に挙げられます。

不正使用：一部の個人情報は、権限付与された合理的な範囲を超えて利用された場合（処理目的の変更や処理範囲の拡大など）、個人情報主体の権利利益に重大なリスクをもたらす可能性があるため、個人の機微情報と判定すべきです。例えば、個人情報主体の権限付与を得ずに、健康情報を保険会社のマーケティングや個人の保険料水準の決定に利用する場合などです。

個人の機微情報の例：

|  |  |
| --- | --- |
| 個人の財産情報 | 銀行口座、認証情報（パスワード）、預金情報（資金額、入出金記録など含む）、不動産情報、信用記録、信用照会情報、取引・消費記録、取引フロー記録など、および仮想通貨、仮想取引、ゲーム引換コードなどの仮想財産情報 |
| 個人の健康・生理情報 | 個人が疾病の治療を受けた際に生成される記録（症状、入院記録、医師の指示、検査報告、手術・麻酔記録、看護記録、投薬記録、薬物・食物アレルギー情報、生殖情報、既往歴、診断・治療、家族の病歴、現病歴、感染症の既往歴など） |
| 個人の生体認証情報 | 個人の遺伝子、指紋、声紋、掌紋、耳介、虹彩、顔認証特徴など |
| 個人の身元情報 | 身分証、軍人証、パスポート、運転免許証、就労許可証、社会保障カード、居住許可証など |
| その他の情報 | 性的指向、婚姻歴、宗教的信条、未公開の犯罪歴、通信記録および内容、連絡先、連絡先リスト、グループリスト、移動軌跡、Web 閲覧履歴、宿泊情報、正確な位置情報など |
