---
title: "部門リストの取得"
description: "特定部門の直下にある子部門リストを取得して企業の組織階層を把握します"
---

本インターフェースを呼び出して、下位階層の部門のベーシック情報を取得します。本インターフェースは現在の部門の下位階層部門のベーシック情報のみ取得可能で、現在の部門配下のすべての階層の子部門の取得には対応していません。

## リクエスト

| **基本情報** | |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/topapi/v2/department/listsub |
| HTTP Method | POST |
| 対応アプリタイプ | appType-社内アプリ appType-サードパーティ社内アプリ |
| 必要な権限 | permission-qyapi_get_department_list-連絡先部門情報の読み取り権限 |

### クエリパラメータ

| 名前 | タイプ | 必須 | 例 | 説明 |
| --- | --- | --- | --- | --- |
| access_token | String | はい | bE74xxxx | 当該 API を呼び出すためのアプリ認証情報。   - 社内アプリの場合、[社内アプリの access_token を取得する](/ja/open/development/obtain-orgapp-token)インターフェースから取得します。 - サードパーティ社内アプリの場合、サードパーティ企業の access_token を取得するインターフェースから取得します。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 例 | 説明 |
| --- | --- | --- | --- | --- |
| dept_id | Number | いいえ | 1 | 親部門 ID。[部門リストの取得](#) インターフェースを呼び出して dept_id パラメータの値を取得できます。 |
| language | String | いいえ | zh_CN | 連絡先の言語：   - **zh_CN**（デフォルト）：中国語 - **en_US**：英語 |

### リクエスト例

```curl
curl -X POST "https://api.dingtalk.io/topapi/v2/department/listsub" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=6846xxxx0cc781' \
-d 'dept_id=100' \
-d 'language=zh_CN'
```

## レスポンス

### レスポンスボディ

| 名前 | タイプ | 例 | 説明 |
| --- | --- | --- | --- |
| request_id | String | 5um7ykyaalsj | リクエスト ID。 |
| errcode | Number | 0 | リターンコード。 |
| errmsg | String | 不正な access_token | 呼び出しに失敗した際に返されるエラーメッセージ。 |
| result | DeptBaseResponse[] |  | 部門リスト。 |
| dept_id | Number | 100 | 部門 ID。 |
| name | String | HR | 部門名。 |
| parent_id | Number | 50 | 親部門 ID。 |
| create_dept_group | Boolean | true | 当該部門に関連する企業グループを同時に作成するかどうか：   - **true**：作成する - **false**：作成しない |
| auto_add_user | Boolean | false | 部門グループが既に作成された後、新しいメンバーが部門に加入した際に自動的に当該グループに加入するかどうか：   - **true**：自動的にグループに加入する - **false**：加入しない |

### エラーコード

当該インターフェースの呼び出し時にエラーが発生した場合は、エラーメッセージを基に [グローバルエラーコード](/ja/open/development/server-api-error-codes-1) ドキュメントから解決方法を検索してください。

| エラーコード（errcode） | エラーコード説明（errmsg） | 解決方法 |
| --- | --- | --- |
| 60003 | 該当する部門が見つかりません | dept_id が正しいかご確認ください |
| 400002 | 無効なパラメータ | パラメータが要件通りに入力されているかご確認ください |
| -1 | システムビジー | 後で再度お試しください |
