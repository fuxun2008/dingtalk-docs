---
title: "セル領域の更新"
---

本インターフェースを呼び出すと、セルの値、背景色、ハイパーリンク、フォントサイズ、水平揃え、垂直揃えなど、セルの情報を更新できます。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | `https://api.dingtalk.io/v1.0/doc/workbooks/{workbookId}/sheets/{sheetId}/ranges/{rangeAddress}` |
| HTTP Method | PUT |
| 対応アプリタイプ | appType-社内アプリ　appType-サードパーティ社内アプリ |
| 必要な権限 | permission-Document.Workbook.Write-スプレッドシート書き込み権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | はい | 本インターフェースを呼び出すためのアクセス認証情報です。以下の方法で取得できます：   - 社内アプリの場合は、[社内アプリの access token を取得](https://open.dingtalk.io/document/development/obtain-the-access-token-of-an-internal-app)インターフェースを呼び出して取得します。 - サードパーティ社内アプリの場合は、[サードパーティアプリの認可企業の access token を取得](https://open.dingtalk.io/document/development/obtain-the-access-token-of-the-authorized-enterprise-1)インターフェースを呼び出して取得します。 |

### パスパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| workbookId | String | はい | スプレッドシートファイル ID です。[ナレッジベース API](https://open.dingtalk.io/document/development/knowledge-base-overview) が返す `nodeId(dentryUuid)` がスプレッドシートの `workbookId` です。[ノードの取得](https://open.dingtalk.io/document/development/get-node) および [ナレッジベースドキュメントの作成](https://open.dingtalk.io/document/development/create-team-space-document) インターフェースを呼び出して取得できます。 |
| sheetId | String | はい | ワークシート ID または名前です。   - 社内アプリの場合は、[すべてのワークシートを取得](https://open.dingtalk.io/document/development/obtain-all-worksheets)インターフェースを呼び出して id または name パラメータ値を取得できます。 - サードパーティ社内アプリの場合は、[ワークシートの作成](https://open.dingtalk.io/document/development/create-a-worksheet)インターフェースを呼び出して id および name を取得できます。 |
| rangeAddress | String | はい | Range アドレスです。 |

### クエリパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| operatorId | String | はい | 操作者の unionId です。[ユーザー詳細の照会](https://open.dingtalk.io/document/development/query-user-details)インターフェースを呼び出して取得できます。      操作者に権限がない場合、インターフェースは `The operator has no permission` というエラーを返します。 |

### リクエスト例

HTTP

```http
PUT /v1.0/doc/workbooks/e54Lqxxxxx/sheets/Sheet1/ranges/A1:B1?operatorId=ppgAQuxxxxx HTTP/1.1
Host:api.dingtalk.io
x-acs-dingtalk-access-token:f86e0bxxx
Content-Type:application/json

{
  "horizontalAlignments" : [ [ "general" ] ],
  "numberFormat" : "@",
  "wordWrap" : "autoWrap",
  "values" : [ [ "text" ] ],
  "complexValues" : [ [ "text" ] ],
  "backgroundColors" : [ [ "#ff0000" ] ],
  "fontColors" : [ [ "#000000" ] ],
  "fontSizes" : [ [ 14 ] ],
  "fontWeights" : [ [ "bold" ] ],
  "hyperlinks" : [ [ {
    "type" : "path",
    "link" : "https://www.dingtalk.io",
    "text" : "DingTalk"
  } ] ],
  "verticalAlignments" : [ [ "middle" ] ]
}
```
