title: "人とボットのチャットにおけるボットメッセージの既読状態を一括照会"
description: "ボットメッセージの既読状況を24時間以内に確認し、社内コミュニケーションの配信実績を把握できます"
---

本 API を呼び出すことで、人とボットのチャットにおけるボットメッセージの既読状態を一括照会できます。社内コミュニケーションにおいて、24 時間以内にメッセージが既読かどうかを確認する必要があるシーンに適しています。

## API 呼び出し説明

- 1 回のリクエストで、1 件の個別チャットメッセージにつき最大 20 名の受信者の既読データを照会できます。
- 直接 HTTP リクエストを発行する場合、まず processQueryKey パラメータを URLEncoding でエスケープし、エスケープ後の processQueryKey を URL に組み込んでください。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/v1.0/robot/oToMessages/readStatus |
| HTTP Method | GET |
| 対応アプリタイプ | appType-社内アプリ　appType-サードパーティ社内アプリ |
| 必要な権限 | permission-qyapi_robot_sendmsg-社内ボットメッセージ送信権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | 必須 | 本 API を呼び出すためのアクセス認証情報です。以下の方法で取得します。   - 社内アプリの場合は、[社内アプリのアクセストークン取得](/ja/open/development/obtain-the-access-token-of-an-internal-app#) API を呼び出して取得します。 - サードパーティアプリの場合は、[サードパーティアプリが権限付与された企業のアクセストークン取得](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#) API を呼び出して取得します。 |

### クエリパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| robotCode | String | 必須 | ボットのコードです。詳細は [ボット ID](/ja/open/development/development-robot-overview#447ec33014hrl) を参照してください。 |
| processQueryKey | String | 必須 | メッセージの一意の識別子です。[人とボットのチャットでボットメッセージを一括送信](/ja/open/development/chatbots-send-one-on-one-chat-messages-in-batches#) API のレスポンスパラメータ `processQueryKey` フィールドから取得できます。    メッセージ送信から 24 時間以内であれば processQueryKey を使って既読状態を照会できます。24 時間を超えると照会できません。 |

### リクエスト例

Host:api.dingtalk.io

Content-Type:application/json
