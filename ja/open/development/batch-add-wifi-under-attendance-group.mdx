この API を呼び出して、指定した勤怠グループに Wi-Fi 情報を一括追加します。

## リクエスト

| **基本情報** | |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/topapi/attendance/group/wifis/add |
| HTTP メソッド | POST |
| 対応アプリタイプ | appType-社内アプリ |
| 権限 | permission-qyapi_attendance_group_manage-勤怠グループ管理権限 |

### クエリパラメータ

| 名前 | タイプ | 必須 | 例 | 説明 |
| --- | --- | --- | --- | --- |
| access_token | String | はい | 1eb68xxx | この API を呼び出すためのアプリ認証情報です。[社内アプリの access_token を取得](/ja/open/development/obtain-orgapp-token)を呼び出して取得します。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 例 | 説明 |
| --- | --- | --- | --- | --- |
| op_userid | String | いいえ | user01 | 操作者のユーザー ID です。 |
| group_key | String | はい | 0151E0xxx | 勤怠グループ ID です。 **注意** 勤怠グループの識別子が group_id の場合は、[groupId を groupKey に変換](/ja/open/development/groupid-to-groupkey)を呼び出して group_id を group_key に変換してください。 |
| wifi_list | Wifi[] | はい |  | Wi-Fi のリストです。1回の呼び出しで最大100件の Wi-Fi を追加できます。 |
| foreign_id | String | はい | office-wifi | 業務側の Wi-Fi ID です。 |
| mac_addr | String | はい | 11:11:11:11:11:11 | MAC アドレスです。 |
| ssid | String | はい | office-wifi-1 | 名前です。 |

### リクエスト例

```curl
curl -X POST "https://api.dingtalk.io/topapi/attendance/group/wifis/add" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=b040xxxx34a60' \
-d 'group_key=0151E02xxxx17E876' \
-d 'op_userid=123456' \
-d 'wifi_list=null'
```

Java

```java

OapiAttendanceGroupWifisAddRequest req = new OapiAttendanceGroupWifisAddRequest();
req.setOpUserid("123456");
req.setGroupKey("0151Exxxx17E876");

Wifi obj3 = new Wifi();
list2.add(obj3);
obj3.setForeignId("123456");
obj3.setMacAddr("11:11:11:11:11:11");
obj3.setSsid("alibaba-guest");
req.setWifiList(list2);
OapiAttendanceGroupWifisAddResponse rsp = client.execute(req, access_token);
System.out.println(rsp.getBody());
```

## レスポンス

### レスポンスボディ

| 名前 | タイプ | 例 | 説明 |
| --- | --- | --- | --- |
| result | DingOpenResult |  | 返却情報です。 |
| result | Result |  | Wi-Fi の追加結果です。 |
| error_info_list | ErrorInfo[] |  | 追加に失敗した Wi-Fi のリストです。 |
| failure_list | Wifi[] |  | 失敗リストです。 |
| foreign_id | String | alibaba-guest | 業務側の Wi-Fi ID です。 |
| mac_addr | String | 02:10:18:11:11:11 | MAC アドレスです。 |
| ssid | String | alibaba-guest1 | MAC 名です。 |
| wifi_key | String | 01xxxxE876 | 追加に失敗した Wi-Fi のキーです。 |
| msg | String | 業務エラー | エラーの説明です。 |
| code | String | 1000 | エラーコードです。 |
| success_list | Wifi[] |  | 追加に成功した Wi-Fi のリストです。 |
| foreign_id | String | office-wifi | 業務側の Wi-Fi ID です。 |
| mac_addr | String | 11:11:11:11:11:11 | MAC アドレスです。 |
| ssid | String | office-wifi-1 | MAC 名です。 |
| wifi_key | String | 01xxxxE876 | 追加に成功した Wi-Fi のキーです。 |
| errcode | Number | 0 | 戻りコードです。 |
| errmsg | String | ok | 戻りコードの説明です。 |
| success | Boolean | true | 呼び出しに成功したかどうかを示します。   - **true**：成功 - **false**：失敗 |
| request_id | String | wicoxqraqt0g | リクエスト ID です。 |
