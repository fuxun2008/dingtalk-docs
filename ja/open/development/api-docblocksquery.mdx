---
title: "ブロック要素のクエリ"
---

このインターフェースを呼び出して、ドキュメント配下の第1階層のブロック要素（ルートノード直下の第1階層のブロック要素）をクエリします。開始・終了位置およびブロックタイプによるフィルタリングをサポートします。

## API 呼び出し説明

ドキュメントコンテンツに関するデータ構造の詳細は、[ドキュメントデータ構造](/ja/open/development/document-data-structure) を参照してください。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | `https://api.dingtalk.io/v1.0/doc/suites/documents/{docKey}/blocks` |
| HTTP Method | GET |
| サポートされるアプリタイプ | appType-社内アプリ |
| 必要な権限 | permission-Storage.File.Read-企業ストレージファイル読み取り権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | はい | この API を呼び出すためのアクセス認証情報。[社内アプリの access_token を取得](/ja/open/development/obtain-the-access-token-of-an-internal-app) API を呼び出して取得します。 |

### パスパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| docKey | String | はい | ドキュメント ID（ドキュメントの docKey または dentryUuid）。[ナレッジベースドキュメントの作成](/ja/open/development/create-team-space-document) API を呼び出してドキュメントを作成した後、戻り値から `docKey` パラメータを取得します。      `dentryUuid` はドキュメント URL から取得します。例えば https://alidocs.dingtalk.io/i/nodes/Zxxxxa-id の場合、dentryUuid は Zxxxxa-id です。 |

### クエリパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| startIndex | Integer | いいえ | 開始位置。0 以上の整数で、ドキュメント配下の第 `startIndex` 番目のブロック要素から開始することを示します。 |
| endIndex | Integer | いいえ | 終了位置。0 以上の整数で、第 `endIndex` 番目のブロック要素までクエリすることを示します。 |
| blockType | String | いいえ | 指定するブロック要素タイプ。詳細は [ブロック要素データ構造](/ja/open/development/block-data-structure) を参照してください。 |
| operatorId | String | はい | ユーザーの unionId。[ユーザー詳細のクエリ](/ja/open/development/query-user-details) API を呼び出して unionid パラメータの値を取得できます。 |

### リクエスト例

```http
GET /v1.0/doc/suites/documents/doc_id/blocks?startIndex=0&endIndex=1&blockType=paragraph&operatorId=union_id HTTP/1.1
Host:api.dingtalk.io
x-acs-dingtalk-access-token:7dc9ec4xxx
Content-Type:application/json
```
