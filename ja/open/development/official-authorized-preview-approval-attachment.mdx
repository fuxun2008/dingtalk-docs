本 API を呼び出して、承認添付ファイルのプレビュー権限を付与します。

## API 呼び出し説明

<Note>
本 API は、ドライブの JSAPI と組み合わせて使用してください。
</Note>

1. 承認用ドライブスペースの spaceId を取得します。[承認用ドライブスペース情報の取得](/ja/open/development/obtains-the-information-about-approval-nail-disk) API を呼び出して、承認用ドライブスペースの spaceId を取得します。
2. 承認用ドライブスペースの spaceId を使って、Web アプリ（H5 マイクロアプリ）またはミニプログラムでドライブ添付ファイルの情報を取得します。取得するには、ドライブに添付ファイルをアップロードするか、ドライブからファイルを選択します。
3. 承認インスタンスの processInstanceId を取得します。[承認インスタンスの作成](/ja/open/development/create-an-approval-instance) API を呼び出して、InstanceId パラメータの値を取得します。
4. 上記の情報を使用して本 API を呼び出し、ユーザーに承認添付ファイルのプレビュー権限を付与します。承認添付ファイルをプレビューする前に、毎回本 API を呼び出して権限を付与してください。
5. **ドライブファイルのプレビュー** API を呼び出して、ファイルをプレビューします。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/v1.0/workflow/processInstances/spaces/authPreview |
| HTTP メソッド | POST |
| 対応アプリタイプ | appType-社内アプリ　appType-サードパーティ社内アプリ |
| 必要な権限 | permission-Workflow.Instance.Write-ワークフローインスタンスの書き込み権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | はい | 本 API を呼び出すためのアクセス認証情報です。取得方法は以下のとおりです。   - 社内アプリ：[社内アプリのアクセストークンの取得](/ja/open/development/obtain-the-access-token-of-an-internal-app) API を呼び出します。 - サードパーティ社内アプリ：サードパーティアプリに権限付与した組織のアクセストークンを取得する API を呼び出します。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| userId | String | はい | 添付ファイルのプレビュー権限を付与するユーザーの userId です。 |
| agentId | Long | いいえ | アプリの agentId です。   - 社内アプリ：AgentId 情報を確認します。 - サードパーティ社内アプリ：組織の権限付与情報を取得する API を呼び出して、`agentid` パラメータの値を取得します。 |
| processInstanceId | String | はい | 承認インスタンス ID です。   - [承認インスタンスの作成](/ja/open/development/create-an-approval-instance) API を呼び出して、`InstanceId` パラメータの値を取得します。 - [承認インスタンス ID リストの取得](/ja/open/development/obtain-an-approval-list-of-instance-ids) API を呼び出して、`list` パラメータの値を取得します。 |
| fileId | String | はい | 承認添付ファイルの ID です。      fileId は、作成済みの承認インスタンスの添付ファイルコンポーネント内にあるファイルの fileId と一致している必要があります。一致しない場合は、権限がない旨のエラーメッセージが返されます。 |
| fileIdList | Array of String | いいえ | 添付ファイル ID のリストです。一括での権限付与に対応しています。リストの最大長は 20 です。 |
| withCommentAttatchment | Boolean | いいえ | コメント内の添付ファイルを含めるかどうかを指定します。デフォルトでは、コメント内の添付ファイルは無視されます。 |
