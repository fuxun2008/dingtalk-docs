本インターフェースを呼び出して、アプリ ID で指定ユーザーにファイルを送信します。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/v1.0/convFile/apps/conversations/files/send |
| HTTP Method | POST |
| サポートされるアプリタイプ | appType-社内アプリ　appType-サードパーティ社内アプリ |
| 必要な権限 | permission-ConvFile.File.Send-グループファイル送信権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | はい | 本インターフェース呼び出しのためのアクセス認証情報。以下の方法で取得します：   - 社内アプリの場合は、[社内アプリの accessToken を取得](/ja/open/development/obtain-the-access-token-of-an-internal-app#) インターフェースを呼び出して取得します。 - サードパーティ社内アプリの場合は、[サードパーティアプリで権限付与された企業の accessToken を取得](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#) インターフェースを呼び出して取得します。 |

### クエリパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| unionId | String | はい | ファイルを受信するユーザーの unionId。[ユーザー詳細を照会](/ja/open/development/query-user-details#) インターフェースを呼び出して取得できます。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| spaceId | String | はい | ファイルが存在するスペース ID。[スペースを追加](/ja/open/development/add-space#) インターフェースを呼び出して、id パラメータの値を取得します。 |
| dentryId | String | はい | ファイル ID。[ファイルまたはフォルダーリストを取得](https://open.dingtalk.com/document/development/obtain-the-file-list-storage#) インターフェースを呼び出して、id パラメータの値を取得できます。 |
