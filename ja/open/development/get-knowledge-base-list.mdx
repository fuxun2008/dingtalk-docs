title: "ナレッジベース一覧の取得"

本インターフェースを呼び出し、操作者の unionId に基づきナレッジベース一覧情報を取得します。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/v2.0/wiki/workspaces |
| HTTP Method | GET |
| サポートされるアプリタイプ | appType-社内アプリ　appType-サードパーティ社内アプリ |
| 権限要件 | permission-Wiki.Workspace.Read-ナレッジベース読み取り権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | はい | 本インターフェースを呼び出すためのアクセス認証情報です。以下の方法で取得します:   - 社内アプリの場合は、[社内アプリのアクセストークンを取得](/ja/open/development/obtain-the-access-token-of-an-internal-app#)インターフェースを呼び出して取得します。 - サードパーティ社内アプリの場合は、[サードパーティアプリの認可企業のアクセストークンを取得](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#)インターフェースを呼び出して取得します。 |

### クエリパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| nextToken | String | いいえ | ページネーションカーソル。初回取得時には不要です。 |
| maxResults | Integer | いいえ | ページサイズ。デフォルトは 30 です。  最大値は 30 です。 |
| orderBy | String | いいえ | 並び替え方式。列挙値:   - **VIEW_TIME_DESC**: 閲覧時間の降順 - **CREATE_TIME_DESC**: 作成時間の降順 - **MODIFIED_TIME_DESC**: 編集時間の降順 |
| withPermissionRole | Boolean | いいえ | 権限を同時にクエリするかどうか:   - true: クエリする - false: クエリしない   デフォルトは false です。 |
| operatorId | String | はい | 操作者の unionId です。 |
