# spaceId を指定してスペース情報を取得する

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/v1.0/drive/managements/spaces/query |
| HTTP Method | POST |
| 対応アプリタイプ | appType-社内アプリ　appType-サードパーティ社内アプリ |
| 必要な権限 | permission-Drive.SpaceManage.Read-ドライブアプリスペース管理情報の読み取り権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | はい | 本インターフェース呼び出しのアクセス認証情報です。以下の方法で取得します。   - 社内アプリの場合は、[社内アプリの accessToken を取得する](https://open.dingtalk.io/document/development/obtain-the-access-token-of-an-internal-app) インターフェースを呼び出して取得します。 - サードパーティ社内アプリの場合は、[サードパーティアプリで権限付与された企業の accessToken を取得する](https://open.dingtalk.io/document/development/obtain-the-access-token-of-the-authorized-enterprise-1) インターフェースを呼び出して取得します。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| spaceIds | Array of String | はい | スペース ID のリスト。最大 30 件まで指定可能です。[スペースリストを取得する](https://open.dingtalk.io/document/development/queries-a-space-list) インターフェースを呼び出して取得できます。 |
| unionId | String | はい | ユーザーの unionId。[ユーザー詳細を照会する](https://open.dingtalk.io/document/development/query-user-details) インターフェースを呼び出して取得できます。 |

## レスポンス

### レスポンスボディ

| 名前 | タイプ | 説明 |
| --- | --- | --- |
| spaces | Array | スペースのリスト。 |
| spaceId | String | スペース ID。 |
| spaceName | String | スペース名。 |
| spaceType | String | スペースのタイプ。   - **personal**：個人スペース - **org**：企業スペース |
| quota | Long | スペースの総容量。   - **-1**：スペースの容量が無制限であることを示します。企業属性がある場合、企業スペースの容量を超えることはできません。 |
| usedQuota | Long | スペースの使用済み容量。 |
| permissionMode | String | 権限レベル。値は以下のとおりです。   - **acl**：acl 権限付与 - **custom**：カスタム権限付与 |
| createTime | String | 作成時間。ISO8601 形式（例：2022-07-29T14:55Z）。 |
| modifyTime | String | 編集時間。ISO8601 形式（例：2022-07-29T14:55Z）。 |
