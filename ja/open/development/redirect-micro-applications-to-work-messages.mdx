title: "業務通知をクリックして Web アプリへリダイレクト"

---

本ドキュメントでは、送信した業務通知メッセージをクリックして DingTalk マイクロアプリへリダイレクトする方法について説明します。

## 前提条件

[アプリの作成](/ja/open/dingstart/create-application) の手順を完了していること。

## 操作手順

1. 対象アプリを選択し、アプリ詳細ページに入って、**ベーシック情報** > **認証情報とベーシック情報** をクリックします。
2. クライアント ID と Client Secret を取得します。
3. 社内アプリでは業務通知の API 権限がデフォルトで開通されているため、手動で申請を送信する必要はありません。
4. アプリのアクセス認証情報を取得し、社内アプリの access_token を取得します。API を呼び出す際は、アクセストークンを利用して呼び出し元の身元を認証します。
5. [業務通知の送信](/ja/open/development/asynchronous-sending-of-enterprise-session-messages) API を呼び出して、対象ユーザーに業務メッセージ通知を送信します。ユーザーがメッセージをクリックしてリダイレクトする必要があるため、適したメッセージタイプは link メッセージ、OA メッセージ、カードメッセージとなります。詳細は [メッセージ通知のタイプ](/ja/open/development/message-types-and-data-format) を参照してください。

## 業務通知をクリックして Web アプリ（H5 マイクロアプリ）へリダイレクト

1. [業務通知の送信](/ja/open/development/asynchronous-sending-of-enterprise-session-messages) API を呼び出します。業務メッセージのフォーマットには link メッセージ、OA メッセージ、またはカードメッセージを選択します。これら 3 種類のメッセージはリダイレクト可能です。
2. リダイレクトリンクの構築方法は [メッセージリンクの説明](/ja/open/development/message-link-description) を参照してください。以下に上記 3 種類のメッセージにおけるリンクの構築例を示します。完全なメッセージ送信フォーマットは [メッセージ通知のタイプ](/ja/open/development/message-types-and-data-format) を参照してください。

   | **パラメータ** | 説明 |
   | --- | --- |
   | corpid | - 社内アプリ - Web アプリ（H5 マイクロアプリ）の場合、このパラメータは現在のマイクロアプリが所属する企業の corpid 値です。- サードパーティ社内アプリ - Web アプリ（H5 マイクロアプリ）の場合、このパラメータは現在のアプリの利用を許可した認可企業の corpid 値です。 |
   | container_type | リンクを開く方式（固定値）： - **work_platform**：ワークベンチで開くことを示します。 |
   | app_id | - 社内アプリ - H5 マイクロアプリの場合、このパラメータには 0_agentId を入力します。数値の 0、下線、AgentId を連結したものです。AgentId の確認方法は AgentId を参照してください。- サードパーティ社内アプリ - H5 マイクロアプリの場合、このパラメータには現在のサードパーティマイクロアプリの appId 値を入力します。appId の確認方法は App ID を参照してください。 |
   | redirect_type | このシナリオでは **jump** を入力します（固定値）。 |
   | redirect_url | リダイレクト先のアドレス。**必ず urlEncode する必要があります**。 |

### 例

```text
dingtalk://dingtalkclient/action/openapp?corpid=企業のcorpid&container_type=work_platform&app_id=appId&redirect_type=jump&redirect_url=リダイレクトurl
```

### Link メッセージのリダイレクトリンク構築例

```text
"messageUrl": "dingtalk://dingtalkclient/action/openapp?corpid=企業のcorpid&container_type=work_platform&app_id=appId&redirect_type=jump&redirect_url=リダイレクトurl"
```

### OA メッセージのリダイレクトリンク構築例

```text
"message_url": "dingtalk://dingtalkclient/action/openapp?corpid=企業のcorpid&container_type=work_platform&app_id=appId&redirect_type=jump&redirect_url=リダイレクトurl"
```

### カードメッセージのリダイレクトリンク構築例

カードメッセージは、全体リダイレクト ActionCard スタイルと独立リダイレクト ActionCard スタイルをサポートします：

- 全体リダイレクト ActionCard スタイル

  ```text
  "single_url": "dingtalk://dingtalkclient/action/openapp?corpid=企業のcorpid&container_type=work_platform&app_id=appId&redirect_type=jump&redirect_url=リダイレクトurl"
  ```
- 独立リダイレクト ActionCard スタイル

  ```text
  "action_url": "dingtalk://dingtalkclient/action/openapp?corpid=企業のcorpid&container_type=work_platform&app_id=appId&redirect_type=jump&redirect_url=リダイレクトurl"
  ```
