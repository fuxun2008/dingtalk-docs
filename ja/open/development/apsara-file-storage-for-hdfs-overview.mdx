## メディアファイルとは

### メディアファイルの保存場所について

本機能のメディアファイルが使用するスペースは、DingTalk が組織に提供する専用のストレージスペースであり、組織のドライブスペースには属しません。本機能の API を呼び出してファイルをアップロードしても、DingTalk 組織のドライブスペースを消費しません。

### 保存有効期間について

本機能のファイルの保存有効期間に制限はありません。通常、DingTalk 組織が解散されない限り、ファイルアップロード時に返される media_id は継続して使用できます。

## オープン概要

メディアファイルは豊富な API 機能を提供しており、開発者は API を通じてメディアファイルと企業の業務システムを連携できます。

| API | 説明 | API バージョン |
| --- | --- | --- |
| [メディアファイルのアップロード](/ja/open/development/upload-media-files) | 画像、音声などのメディアリソースファイルおよび通常のファイルをアップロードします。 | 旧バージョン |
