---
title: "ファイルまたはフォルダーのアプリ属性を更新する"
---

本 API を呼び出して、ファイルまたはフォルダーのアプリ属性を更新します。

## API 呼び出し説明

API に渡されるアプリ属性情報は、属性名に基づいて検証されます。

- ファイルまたはフォルダーの既存属性名と API パラメータで渡された属性名が同一の場合、API は属性の更新を実行します。
- ファイルまたはフォルダーの既存属性名と API パラメータで渡された属性名が異なる場合、API は属性の追加を実行します。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | `https://api.dingtalk.io/v1.0/storage/spaces/{spaceId}/dentries/{dentryId}/appProperties` |
| HTTP Method | PUT |
| サポートするアプリタイプ | appType-社内アプリ　appType-サードパーティ社内アプリ |
| 権限要件 | permission-Storage.File.Write-企業ストレージファイル書き込み権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | 必須 | 本 API を呼び出すためのアクセス認証情報。以下の方法で取得します。   - 社内アプリの場合、[社内アプリの accessToken を取得する](/ja/open/development/obtain-the-access-token-of-an-internal-app) API を呼び出して取得します。 - サードパーティ社内アプリの場合、[サードパーティアプリが権限付与された企業の accessToken を取得する](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1) API を呼び出して取得します。 |

### パスパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| spaceId | Long | 必須 | スペース ID。[スペースを追加する](/ja/open/development/add-space) API を呼び出して id パラメータの値を取得できます。 |
| dentryId | Long | 必須 | ファイルまたはフォルダーの id。[ファイルまたはフォルダーのリストを取得する](/ja/open/development/get-a-list-of-files-or-folders) または [dentryUuid に基づいて spaceId と dentryId を取得する](/ja/open/development/api-getdentryidbyuuid) API を呼び出して id パラメータの値を取得できます。 |

### クエリパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| unionId | String | 必須 | 操作者の unionId。[ユーザー詳細を照会する](/ja/open/development/query-user-details) API を呼び出して unionid パラメータの値を取得できます。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| appProperties | Array | 必須 | アプリ属性リスト。最大値は 3 です。 |
| name | String | 必須 | 属性名。       - 属性名が既に存在する場合、既存の属性情報を更新します。 - 属性名が存在しない場合、当該属性情報を追加します。 |
| value | String | 必須 | 属性値。 |
| visibility | String | 必須 | 属性の可視範囲。   - **PUBLIC**：当該属性はすべての App から参照可能 - **PRIVATE**：当該属性は所属する App のみ参照可能。デフォルト |
