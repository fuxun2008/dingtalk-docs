---
title: "ショートカットの作成"
---

本インターフェースを呼び出して、指定した位置にナレッジベースまたはファイルのショートカットを作成します。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/v2.0/doc/resource/shortcut/create |
| HTTP Method | POST |
| サポートされるアプリタイプ | appType-社内アプリ |
| 権限要件 | permission-snsapi_base-SNS API 呼び出し時に必要な基本権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | はい | 本インターフェース呼び出し時のアクセス認証情報。[ユーザートークンの取得](https://open.dingtalk.io/document/development/obtain-user-token) インターフェースを呼び出して取得します。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| param | Object | はい | 必須パラメータ。 |
| sourceResourceId | String | はい | ソースリソースの位置情報の id。dentryUUid または rootNodeUUid を指定できます。[ファイル検索](https://open.dingtalk.io/document/development/search-for-files) インターフェースを呼び出して取得した dentryUUid フィールドの値です。 |
| sourceResourceType | String | はい | ソースリソースのタイプ：   - **DENTRY**：ファイル - **WORKSPACE**：ナレッジベース |
| targetResourceId | String | はい | ターゲット位置の id。dentryUUid または rootNodeUUid を指定できます。[ファイル検索](https://open.dingtalk.io/document/development/search-for-files) インターフェースを呼び出して取得した dentryUUid フィールドの値です。 |
| targetResourceType | String | はい | ターゲットリソースのタイプ：   - **DENTRY**：ファイル - **WORKSPACE**：ナレッジベース |
| targetResourceName | String | いいえ | ショートカット名。指定しない場合はソースリソース名がデフォルトで使用されます。 |
