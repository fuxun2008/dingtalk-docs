title: "ビデオ会議デバイス情報の照会"

本 API を呼び出して、ビデオ会議デバイス情報を照会します。

## API 呼び出し説明

本 API を呼び出す前に、[イベントサブスクリプション](https://open.dingtalk.io/document/development/event-subscription-overview#)を導入し、[デバイスと会議室のバインド変更](https://open.dingtalk.io/document/development/org-event-overview#)イベントをサブスクライブする必要があります。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/v1.0/rooms/devices |
| HTTP Method | GET |
| 対応アプリタイプ | appType-社内アプリ |
| 必要な権限 | permission-VideoConference.Conference.Read-ビデオ会議情報の読み取り権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | 必須 | 本 API を呼び出すためのアクセス認証情報。[社内アプリの access_token を取得する](https://open.dingtalk.io/document/development/obtain-the-access-token-of-an-internal-app#) API を呼び出して取得します。 |

### クエリパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| operatorUnionId | String | 必須 | 操作を行うメンバーの unionId。[ユーザー詳細の照会](https://open.dingtalk.io/document/development/query-user-details#) API を呼び出して取得します。 |
| deviceId | String | 任意 | 照会対象のデバイス ID。本パラメータは[デバイスと会議室のバインド変更](https://open.dingtalk.io/document/development/org-event-overview#)イベントのサブスクリプションから取得します。 `deviceId` フィールドと `deviceUnionId` フィールドは、いずれか一方を必ず指定してください。 |
| deviceUnionId | String | 任意 | 照会対象のデバイス unionId。本パラメータは[デバイスと会議室のバインド変更](https://open.dingtalk.io/document/development/org-event-overview#)イベントのサブスクリプションから取得します。 `deviceId` フィールドと `deviceUnionId` フィールドは、いずれか一方を必ず指定してください。 |

### リクエスト例

```http
GET /v1.0/rooms/devices?operatorUnionId=lmvxxxxx&deviceId=1234&deviceUnionId=lmvUxxxxx HTTP/1.1
Host:api.dingtalk.io
x-acs-dingtalk-access-token:xxxxx
Content-Type:application/json
```
