---
title: "休暇状況の照会"
description: "ユーザー ID リストと期間を指定して、日ごとの休暇状況や休暇時間を照会する API です。最大 180 日間の範囲指定とページング取得に対応しています。"
---

この API を呼び出すと、指定した組織のユーザーについて、指定期間内の日ごとの休暇状況と休暇時間を照会できます。

## リクエスト

| **基本情報** | |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/topapi/attendance/getleavestatus |
| HTTP メソッド | POST |
| 対応アプリタイプ | appType-社内アプリ　appType-サードパーティ社内アプリ |
| 必須権限 | permission-qyapi_get_attendance_data-勤怠データの読み取り権限 |

### クエリパラメータ

| 名前 | タイプ | 必須 | 例 | 説明 |
| --- | --- | --- | --- | --- |
| access_token | String | はい | 6d1bxxxx | この API の呼び出しに使用するアプリ認証情報です。[社内アプリの access_token を取得する](/ja/open/development/obtain-orgapp-token) を呼び出して取得してください。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 例 | 説明 |
| --- | --- | --- | --- | --- |
| userid_list | String | はい | user456,user123 | 照会するユーザー ID のリストです。1 回のリクエストにつき最大 100 件まで指定できます。 |
| start_time | Number | はい | 1538323200000 | 開始時刻（Unix タイムスタンプ）です。照会期間は最大 180 日間です。 |
| end_time | Number | はい | 1546358399000 | 終了時刻（Unix タイムスタンプ）です。照会期間は最大 180 日間です。 |
| offset | Number | はい | 0 | ページングのオフセットです。0 から始まります。size パラメータと併せて設定した場合にのみ有効です。 |
| size | Number | はい | 10 | ページサイズです。最大値は 20 です。offset パラメータと併せて設定した場合にのみ有効です。 |

### リクエスト例

```curl
curl -X POST "https://api.dingtalk.io/topapi/attendance/getleavestatus" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=11b9xxxxc35a' \
-d 'end_time=1546358399000' \
-d 'offset=0' \
-d 'size=10' \
-d 'start_time=1538323200000' \
-d 'userid_list=123%2C121'
```

Java


## レスポンス

### レスポンスボディ

| 名前 | タイプ | 例 | 説明 |
| --- | --- | --- | --- |
| errcode | Number | 0 | リターンコードです。 |
| result | LeaveStatusListVO |  | 照会結果です。 |
| has_more | Boolean | true | さらにデータがあるかどうかを示します。   - **true**：あり - **false**：なし |
| leave_status | LeaveStatusVO[] |  | 休暇状況のリストです。 |
| duration_unit | String | percent_day | 休暇の単位です。   - **percent_day**：日 - **percent_hour**：時間 |
| duration_percent | Number | 100 | 休暇時間に 100 を掛けた値です。たとえば、ユーザーの休暇時間が 1 日の場合、この値は 100 になります。 |
| end_time | Number | 1599465600000 | 休暇の終了時刻（Unix タイムスタンプ）です。 |
| start_time | Number | 1599372000000 | 休暇の開始時刻（Unix タイムスタンプ）です。 |
| userid | String | user456 | ユーザー ID です。 |
| success | Boolean | true | リクエストが成功したかどうかを示します。   - **true**：成功 - **false**：失敗 |
| request_id | String | 5lbpbi9p1awk | リクエスト ID です。 |
