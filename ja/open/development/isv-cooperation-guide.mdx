本記事では、プロダクトソリューションプロバイダーが DingTalk 上で企業ユーザーに標準 SaaS アプリサービスおよびカスタマイズサービスを提供できる、2 つのパートナーシップモデルについて解説します。

## パートナーシップモデル

### モデル 1: 標準 SaaS アプリサービス

標準 SaaS アプリサービス製品を DingTalk 上で公開した後、以下の 2 つの方法でプロモーションできます。

- **アプリマーケットでのプロモーション**: 既にアプリ製品をお持ちか、開発を計画しており、DingTalk アプリマーケットの公開基準を満たす明確なビジネスモデルがある場合、審査に合格すればアプリマーケットに公開してプロモーションできます。アプリが公開されると、顧客は DingTalk アプリマーケットでアプリを検索、閲覧、インストール、購入できます。
- **自社チャンネルでのプロモーション**: 既にアプリ製品をお持ちか、開発を計画している場合、DingTalk が提供する API を使用してオフラインプロモーション用の QRコードを生成し、サービスプロバイダー自身のチャンネルまたは DingTalk 外のチャンネル（外部広告やサードパーティの公式サイトなど）を通じてアプリをプロモーションできます。顧客は QRコードをスキャンするか、リンクをクリックしてアプリをインストールできます。

**重要**

自社チャンネルでのプロモーションは厳格な審査の対象となります。オンボーディング前に、以下のサービスグループに参加して詳細を相談・確認したうえでオンボーディングおよび開発のリクエストを提出してください。開発完了後の審査不合格を避けるためです。

### モデル 2: カスタマイズサービス

DingTalk のプロダクトソリューションプロバイダーになった後は、DingTalk オープンプラットフォームのデータ API とリソースを使用して、DingTalk ユーザー向けにパーソナライズされたプロジェクトベースの開発や連携を提供できます。例: カスタマイズされたワークベンチ、カスタマイズされたシステム連携、その他の技術開発サービスなど。

- サービスプロバイダーに社内アプリの開発を権限付与する
- サービスプロバイダーにワークベンチの開発を権限付与する

## サービスプロバイダーとしてオンボーディングする際の共通資料

### DingTalk 組織プレミアム認証

- 組織の営業許可証
- 法定代表者およびその ID 番号
- 認証権限付与レター（[DingTalk OA 管理コンソール](https://oa.dingtalk.com/index.htm#/chooseAuthType) > **組織プレミアム認証**ページでダウンロードします）
- 注: 一部の DingTalk 組織のプレミアム認証は、年次審査認証（有料）にアップグレードされています。認証ページの案内に従って年次審査認証を完了してください。

### オンボーディング申請

- 組織の営業許可証（原本または公印付きの写し）
- ビジネスオーナーの連絡先情報とメールアドレス（法定代表者である必要はなく、DingTalk のビジネスオーナーで十分です）
- 権限付与レター（組織の公印が押印されている必要があります。[こちら](https://files.alicdn.com/tpsservice/e2593e64e0597c07aff8f01be87af293.doc)からテンプレートをダウンロードしてください）
- アプリ製品紹介の提案書（PDF ドキュメントを推奨）
- 契約署名者の ID カードの表裏の写真
- 企業の Alipay アカウント

### アプリ公開の入会審査基準

- アプリ製品のポジショニングに関する明確な紹介
- 明確で十分に定義された取引モデルと価格設定の仕様
- アプリの取引が DingTalk と連携していること

  **注**

  取引の支払いは、オンボーディング時にサービスプロバイダーが開設した Alipay エスクローアカウントに入金されます。
- オンラインサービスを処理する担当者
- 全国規模でビジネスにサービスを提供できる能力
- すべてのアプリ体験審査項目が基準を満たしていること
- ISV の DingTalk 組織の DingTalk インデックススコアが 1,000 以上であること
- 少なくとも 3 社の顧客との深い共創を完了し、3 社の顧客について深い共創レポートを提供したこと
- アプリをアプリマーケットに公開する場合は、次の条件も満たす必要があります: 過去 6 か月間の DingTalk 有料顧客数が 10 以上かつ GMV が 100,000 以上、または有料顧客数が 3 以上かつ GMV が 500,000 以上であること。（出張カテゴリ: 過去 6 か月間に DingTalk で発生した GMV が 2,000 万以上）

注: 入会審査基準は更新され、2025年4月に発効しました。

**重要**

自社チャンネルでのプロモーションは厳格な審査の対象となります。オンボーディング前に、以下のサービスグループに参加して詳細を相談・確認したうえでオンボーディングおよび開発のリクエストを提出してください。開発完了後の審査不合格を避けるためです。
