この API を呼び出して、インスタンス ID で承認インスタンスの詳細を取得します。詳細には、承認インスタンスのタイトル、申請者の userId、承認者の userId、操作ログが含まれます。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/v1.0/workflow/processInstances |
| HTTP メソッド | GET |
| サポートされる App の種類 | appType-社内アプリ　appType-サードパーティ社内アプリ |
| 必要な権限 | permission-Workflow.Instance.Read-ワークフローインスタンスの読み取り権限 |

### リクエストヘッダー

| 名前 | 型 | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | はい | この API を呼び出すためのアクセス認証情報です。次の方法で取得します。   - 社内アプリ：[社内アプリのアクセストークンを取得する](/ja/open/development/obtain-the-access-token-of-an-internal-app) API を呼び出します。 - サードパーティ社内アプリ：サードパーティアプリを承認した組織のアクセストークンを取得する API を呼び出します。 |

### クエリパラメータ

| 名前 | 型 | 必須 | 説明 |
| --- | --- | --- | --- |
| processInstanceId | String | はい | 承認インスタンス ID です。   - [承認インスタンスを作成する](/ja/open/development/create-an-approval-instance) API を呼び出して、`InstanceId` パラメータの値を取得します。 - [承認インスタンス ID のリストを取得する](/ja/open/development/obtain-an-approval-list-of-instance-ids) API を呼び出して、`list` パラメータの値を取得します。 |
