---
title: "会議をロックする"
---

本 API を呼び出して、会議をロックします。

## API 呼び出し説明

会議をロックすると、当該会議に参加できなくなります。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | `https://api.dingtalk.io/v1.0/conference/videoConferences/{conferenceId}/lock` |
| HTTP Method | POST |
| 対応アプリタイプ | appType-社内アプリ　appType-サードパーティ社内アプリ |
| 権限要件 | permission-VideoConference.Conference.Write-ビデオ会議情報管理権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | はい | 本 API を呼び出すためのアクセス認証情報。以下の方法で取得します：   - 社内アプリの場合、[社内アプリの accessToken を取得](/ja/open/development/obtain-the-access-token-of-an-internal-app#) API を呼び出して取得します。 - サードパーティ社内アプリの場合、[サードパーティアプリにより権限付与された企業の accessToken を取得](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#) API を呼び出して取得します。 |

### パスパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| conferenceId | String | はい | 会議 ID。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| action | String | はい | 操作タイプ：   - **lock**：会議をロック - **unlock**：会議のロックを解除 |

### リクエスト例

HTTP

```http
POST /v1.0/conference/videoConferences/644272f14ba3310xxxxxxxxx/lock HTTP/1.1
Host:api.dingtalk.io
x-acs-dingtalk-access-token:08e68b256cc73400a8f4256c17c3ff9a
Content-Type:application/json

{
  "action" : "lock"
}
```
