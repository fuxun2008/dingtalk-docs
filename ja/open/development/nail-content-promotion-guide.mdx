## 1. DingTalk統合レベルの定義

DingTalk統合レベルは、アプリがDingTalkとどれだけ深く統合されているかを測る指標です。DingTalk API、コネクタ、クールアプリなどと接続することで、アプリはDingTalkとの深い統合を実現します。

- **API**

  DingTalk Open Platform は、OA承認、メッセージ通知、勤怠、New Education、Exclusive DingTalk、顧客管理など、さまざまな標準や開発シナリオに対応した API を提供します。開発者ガイド、開発サンプル、ツールリソースも用意されており、アプリを DingTalk と迅速に統合できます。詳しくは API 概要 をご覧ください。
- **コネクタ**

  ビジュアルなドラッグ＆ドロップ設定やワンクリック購読などのゼロコード手法を使えば、DingTalk、社内システム、著名ベンダーのシステム、DingTalk サードパーティアプリの間でのデータ相互接続と統合を、シンプルかつ効率的に実現できます。詳しくは [コネクタのウェブサイト](/ja/open/yida/guide/concept/connector) をご覧ください。
- **クールアプリ**

  クールアプリは、アプリ機能と DingTalk 内の複数の製品シナリオを融合させた、新しいタイプのシナリオベースのアプリです。没入型の体験を提供し、新しいインタラクション手法を生み出し、データの活用を強化します。ユーザーがアプリを探すのではなく、アプリがユーザーを見つける形へと転換し、新しいシナリオベースのコラボレーション体験を構築します。詳しくは クールアプリのウェブサイト をご覧ください。
