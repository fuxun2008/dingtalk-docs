---
title: "グループチャットの作成"
---

本 API を呼び出して、内部グループおよび一般グループのチャットを作成します。企業がグループチャットを迅速に作成する必要があるシーンに適しています。

## API 呼び出し説明

本 API はデフォルトで内部グループの作成のみをサポートします。一般グループを作成する必要がある場合は、テクニカルサポートにホワイトリスト登録を依頼してください。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/v1.0/im/group/create |
| HTTP Method | POST |
| サポートされるアプリタイプ | appType-社内アプリ |
| 必要な権限 | permission-qyapi_chat_manage-DingTalk グループのベーシック情報管理権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | はい | 本 API を呼び出す際のアクセス認証情報です。[社内アプリのアクセストークンの取得](/ja/open/development/obtain-the-access-token-of-an-internal-app) API から取得できます。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| name | String | はい | グループ名。文字数制限は 1〜20 文字です。 |
| owner | String | はい | グループ作成者の userId。電話番号によるユーザー検索 API から userId を取得できます。 |
| ownerType | String | いいえ | グループ作成者のタイプ。   - **emp**：企業の社員 - **ext**：外部連絡先 |
| useridlist | Array of String | はい | ユーザーの StaffId。 |
| conversationTag | Long | いいえ | 会話タイプのマーク。デフォルトは内部グループです。一般グループの作成にはテクニカルサポートにホワイトリスト登録を依頼してください。   - **0**：一般グループ - **2**：内部グループ |
| extidlist | Array of String | いいえ | 外部連絡先 |
| icon | String | いいえ | グループのプロフィール写真。mediaId を渡す必要があり、[メディアファイルのアップロード](/ja/open/development/upload-media-files) API から取得できます。 |
| managementOptions | Object | いいえ | グループ作成のその他の属性 |
| mentionAllAuthority | Integer | いいえ | @all の使用範囲。   - **0**（デフォルト）：全員が使用可能 - **1**：グループ作成者のみ @all 可能 |
| showHistoryType | Integer | いいえ | 新規ユーザーが過去 100 件のチャット履歴を閲覧できるかどうか。値を渡さない場合は閲覧不可を意味します。   - **1**：閲覧可能 - **0**：閲覧不可 |
| validationType | Integer | いいえ | グループ参加時に検証が必要かどうか。 -\*\* 0\*\*（デフォルト）：検証なし   - **1**：参加検証あり |
| searchable | Integer | いいえ | グループが検索可能かどうか。 -\*\* 0\*\*（デフォルト）：検索不可   - **1**：検索可能 |
| chatBannedType | Integer | いいえ | グループの発言禁止をオンにするかどうか。   - **0**（デフォルト）：発言禁止なし - **1**：全員ミュート |
| managementType | Integer | いいえ | グループ管理タイプ。   - **0**（デフォルト）：全員が管理可能 - **1**：グループ作成者のみ管理可能 |
