---
title: "ユーザー専用ショートリンクの作成"
description: "ユーザー専用ショートリンクを作成し、会議参加時に拡張アプリのカスタム情報を取得します"
---

ユーザー情報に基づいて、ユーザー専用ショートリンクを作成します。ユーザーが専用ショートリンクから会議に参加すると、クライアントサイドの JSAPI を通じて、そのユーザーの拡張アプリのビジネスカスタム情報を取得できます。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/v1.0/conference/customShortLinks |
| HTTP Method | POST |
| サポートされているアプリタイプ | appType-社内アプリ appType-サードパーティ社内アプリ |
| 必要な権限 | permission-VideoConference.Conference.Write-ビデオ会議情報管理権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | はい | この API を呼び出す際のアクセス認証情報。以下の方法で取得します。   - 社内アプリの場合は、[社内アプリの accessToken を取得](/ja/open/development/obtain-the-access-token-of-an-internal-app#) API を呼び出して取得します。 - サードパーティ社内アプリの場合は、[サードパーティアプリで権限付与された企業の accessToken を取得](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#) API を呼び出して取得します。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| creatorUnionId | String | はい | 予約会議の作成者の unionId。 |
| scheduleConferenceId | String | はい | 予約会議 ID。[予約会議の作成](/ja/open/development/create-appointment-meeting#) API を呼び出し、戻りパラメータ `scheduleConferenceId` フィールドから取得できます。 |
| coolAppCode | String | はい | クールアプリのコード。開発者バックエンドのマイクロアプリでクールアプリコードを確認できます。 |
| extensionAppBizData | String | いいえ | ユーザー単位の拡張アプリのカスタム情報。 |
| useExtensionApp | Boolean | いいえ | 拡張アプリを使用するかどうか。   - true: 使用する - false: 使用しない |
