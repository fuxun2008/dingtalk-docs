本インターフェースを呼び出して、ファイルのサムネイル情報を一括取得します。

### インターフェース機能の紹介

ストレージスペースにアップロードされた画像、WPS 形式のドキュメント（Word、Excel、PowerPoint）、PDF 形式ファイルおよび txt 形式ファイルは、非同期で自動的にサムネイルが生成されます。

本インターフェースを呼び出すことで、ストレージファイルのサムネイル情報を一括取得できます。

## 権限

この API を呼び出すには、以下のいずれかの権限が必要です。

| アプリタイプ | 対応可否 | 権限 | API Explorer デバッグ |
| --- | --- | --- | --- |
| 社内アプリ | 対応 | 企業ストレージファイル読み取り権限 | [API Explorer](https://open-dev.dingtalk.io/apiExplorer#/?devType=org&api=storage_1.0%23GetDentryThumbnails) |
| サードパーティ社内アプリ | 対応 | 企業ストレージファイル読み取り権限 | [API Explorer](https://open-dev.dingtalk.io/apiExplorer#/?devType=isv&api=storage_1.0%23GetDentryThumbnails) |
| サードパーティ個人アプリ | 未対応 | 企業ストレージファイル読み取り権限 | 未対応 |

## HTTP メソッド

```http
POST /v1.0/storage/spaces/{spaceId}/thumbnails/query?unionId=String HTTP/1.1
Host:api.dingtalk.io
x-acs-dingtalk-access-token:String
Content-Type:application/json

{
  "dentryIds" : [ "String" ]
}
```

## Header パラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | はい | 本インターフェースを呼び出すためのアクセス認証情報。以下の方法で取得します：   - 社内アプリの場合、[社内アプリの accessToken を取得](/ja/open/development/obtain-the-access-token-of-an-internal-app)インターフェースを呼び出して取得します。 - サードパーティ社内アプリの場合、サードパーティアプリ認可企業の accessToken を取得するインターフェースを呼び出して取得します。 |

## Path パラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| spaceId | String | はい | スペース ID。[スペース追加](/ja/open/development/add-space)インターフェースを呼び出して id パラメータの値を取得します。 |

## Query パラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| unionId | String | はい | 操作者の unionId。[ユーザー詳細照会](/ja/open/development/query-user-details)インターフェースを呼び出して取得できます。 |

## Body パラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| dentryIds | Array of String | はい | ファイル ID。最大値は 30。ファイルまたはフォルダーリスト取得インターフェースを呼び出して id パラメータの値を取得します。 |

## レスポンスパラメータ

| 名前 | タイプ | 説明 |
| --- | --- | --- |
| resultItems | Array | サムネイル取得結果リスト。 |
| spaceId | String | ファイルが所在するスペース ID。 |
| dentryId | String | ファイル ID。 |
| success | Boolean | サムネイル情報の取得に成功したかどうか。true は成功を示します。 |
| errorCode | String | エラー原因。 |
| thumbnail | Object | サムネイル情報。 |
| width | Integer | サムネイルの幅、単位は px。 |
| height | Integer | サムネイルの高さ、単位は px。 |
| url | String | サムネイルの URL。 |
