---
title: "段落末尾にテキストを追加"
description: "企業ストレージのドキュメント段落の末尾にテキストを追加します"
---

本 API を呼び出すことで、段落の末尾にテキストを追加できます。

## API 呼び出し説明

ドキュメントコンテンツに関連するデータ構造については、[ドキュメントデータ構造](/ja/open/development/document-data-structure)をご参照ください。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | `https://api.dingtalk.io/v1.0/doc/suites/documents/{docKey}/blocks/{blockId}/paragraph/appendText` |
| HTTP Method | POST |
| 対応アプリタイプ | appType-社内アプリ |
| 権限要件 | permission-Storage.File.Write-企業ストレージファイル書き込み権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | はい | 本 API を呼び出すためのアクセス認証情報。[社内アプリのアクセストークンを取得](/ja/open/development/obtain-the-access-token-of-an-internal-app) API を呼び出して取得します。 |

### パスパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| docKey | String | はい | ドキュメント ID（ドキュメントの docKey または dentryUuid）。[ナレッジベースドキュメントを作成](/ja/open/development/create-team-space-document) API を呼び出してドキュメントを作成後、レスポンスから `docKey` パラメータを取得します。      ドキュメント URL から `dentryUuid` を取得します。例：https://docs.dingtalk.io/i/nodes/Zxxxxa-id の場合、dentryUuid は Zxxxxa-id となります。 |
| blockId | String | はい | 対象段落の一意の識別子。[ブロック要素を取得](/ja/open/development/api-docblocksquery) API を呼び出して該当段落の `blockId` パラメータを取得できます。 |

### クエリパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| operatorId | String | はい | ユーザーの unionId。[ユーザー詳細を取得](/ja/open/development/query-user-details) API を呼び出して unionid パラメータの値を取得できます。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| text | String | はい | 挿入するテキスト。 |

### リクエスト例

HTTP

```http
POST /v1.0/doc/suites/documents/doc_id/blocks/block_id/paragraph/appendText?operatorId=union_id HTTP/1.1
Host:api.dingtalk.io
x-acs-dingtalk-access-token:7dc9ec4xxx
Content-Type:application/json

{
  "text" : "text"
}
```
