---
title: "会議録画のテキスト情報を取得"
---

本 API を呼び出して、ビデオ会議録画の音声から変換されたテキスト情報（テキストコンテンツ、テキストレコードの開始時刻、テキストレコードの終了時刻など）を取得します。

## API 呼び出し説明

DingTalk ビデオ会議でクラウド録画（閃記）をオンにすると、クラウド録画期間中にメンバーが発言した内容が自動的にテキストへ変換されレコードが生成されます。

例えば、会議の主催者が **会議録画-クラウド録画** 機能をオンにすると、会議終了後に主催者へ会議録画のプッシュチャットが届きます。記録された音声からテキストへの変換コンテンツは下図のとおりです。

本 API を呼び出すことで、クラウド録画中に記録されたテキスト情報（テキストコンテンツ、テキストレコードの開始時刻、テキストレコードの終了時刻など）を取得できます。

主催者が会議録画をオンにする際は、まず **クラウド録画（閃記）** を選択する必要があります。さらに録画期間中にメンバーが発言している場合に限り、本 API を呼び出して会議録画のテキスト情報を取得できます。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | `https://api.dingtalk.io/v1.0/conference/videoConferences/{conferenceId}/cloudRecords/getTexts` |
| HTTP Method | GET |
| 対応アプリタイプ | appType-社内アプリ　appType-サードパーティ社内アプリ |
| 必要権限 | permission-VideoConference.Conference.Read-ビデオ会議情報の読み取り権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | はい | 本 API を呼び出すためのアクセス認証情報。以下の方法で取得します:   - 社内アプリの場合、[社内アプリの accessToken を取得](https://open.dingtalk.io/document/development/obtain-the-access-token-of-an-internal-app#) API を呼び出して取得します。 - サードパーティ社内アプリの場合、[サードパーティアプリで権限付与された企業の accessToken を取得](https://open.dingtalk.io/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#) API を呼び出して取得します。 |

### パスパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| conferenceId | String | いいえ | 会議 ID。[ビデオ会議を作成](https://open.dingtalk.io/document/development/create-a-video-conference#) API を呼び出して conferenceId パラメータの値を取得できます。 |

### クエリパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| unionId | String | いいえ | ユーザーの unionId。[ユーザー詳細を取得](https://open.dingtalk.io/document/development/query-user-details#) API を呼び出して unionid パラメータの値を取得できます。 |
| startTime | Long | いいえ | 開始時刻のミリ秒（1/1000 秒）、単位はミリ秒。  例えば、本パラメータの値を 2000 にすると、録画開始から 2 秒目以降を取得対象とします。 |
| direction | String | いいえ | 取得方法:   - **0**: 時刻昇順で取得します（デフォルト）。 - **1**: 時刻降順で取得します。 |
| maxResults | Long | いいえ | 一度に取得する件数。最大 2000 件。 |
| nextToken | Long | いいえ | ページネーションカーソル。   - 初回取得時は本パラメータを指定しなくて構いません。 - 初回以外の場合は、前回本 API 呼び出し時にレスポンスで返された nextToken を指定します。 |

### エラーコード

本 API の呼び出しでエラーが発生した場合、エラーメッセージをもとに [グローバルエラーコード](https://open.dingtalk.io/document/development/server-api-error-codes-1) ドキュメントから解決策を検索できます。

| HttpCode | エラーコード | エラーメッセージ | 説明 |
| --- | --- | --- | --- |
| 400 | orgAccessForbidden | orgAccessForbidden | 組織へのアクセスが制限されています |
| 400 | unknownUserError | unknownUserError | ユーザーを識別できません |
| 400 | paramsError | error:%s | パラメータエラー |
| 400 | resourceClose | The meeting has ended | 当該会議は終了しています |
| 400 | cloudRecordNotFound | cloudRecordNotFound | クラウド録画レコードが見つからない/クラウド録画がオンになっていません |
| 404 | permissionError | permissionError:%s | グループ権限の制限 |
| 500 | systemError | systemError:%s | システムエラー |
