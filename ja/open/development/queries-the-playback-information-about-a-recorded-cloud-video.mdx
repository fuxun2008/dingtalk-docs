本インターフェースを呼び出して、会議録画の動画情報（動画のダウンロードURL、動画ファイルサイズ、動画の長さなど）を取得します。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | `https://api.dingtalk.io/v1.0/conference/videoConferences/{conferenceId}/cloudRecords/videos/getPlayInfos` |
| HTTP Method | GET |
| サポートされるアプリタイプ | appType-社内アプリ　appType-サードパーティ社内アプリ |
| 必要な権限 | permission-VideoConference.Conference.Read-ビデオ会議情報の読み取り権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | はい | 本インターフェース呼び出し用のアクセス認証情報。以下の方法で取得します：   - 社内アプリの場合は、[社内アプリのaccessTokenを取得](/ja/open/development/obtain-the-access-token-of-an-internal-app#)インターフェースを呼び出して取得します。 - サードパーティ社内アプリの場合は、[サードパーティアプリ認可企業のaccessTokenを取得](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#)インターフェースを呼び出して取得します。 |

### パスパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| conferenceId | String | はい | 会議ID。[ビデオ会議を作成](/ja/open/development/create-a-video-conference#)インターフェースを呼び出して conferenceId パラメータの値を取得できます。 |

### クエリパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| unionId | String | はい | ユーザーの unionId。[ユーザー詳細を取得](/ja/open/development/query-user-details#)インターフェースを呼び出して unionid パラメータの値を取得できます。 |
| mediaId | String | はい | メディアファイルID。[会議録画の詳細情報を取得](/ja/open/development/query-recording-information#)インターフェースを呼び出して mediaId パラメータの値を取得できます。 |
| regionId | String | はい | リージョンID。[会議録画の詳細情報を取得](/ja/open/development/query-recording-information#)インターフェースを呼び出して regionId パラメータの値を取得できます。 |
