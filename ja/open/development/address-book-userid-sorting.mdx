# 連絡先ユーザー ID の並び替え

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/contact/users/sort |
| HTTP Method | POST |
| 対応アプリタイプ | appType-サードパーティ社内アプリ |
| 必要な権限 | permission-qyapi_get_member-ユーザー情報の読み取り権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | はい | 本 API を呼び出すためのアクセス認証情報です。[サードパーティアプリ認可企業の access_token を取得](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#) を呼び出して取得します。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| userIdList | Array of String | はい | ユーザーの userId です。[サイレントログインコードによるユーザー情報の取得](/ja/open/development/obtain-the-userid-of-a-user-by-using-the-log-free#) を通じて userid の値を取得できます。 |
| sortType | Integer | いいえ | 並び替え方法です。取りうる値：   - **0**：名前のピンイン昇順 - **1**：名前のピンイン降順 |

### リクエストボディ例

```http
POST /v1.0/contact/users/sort HTTP/1.1
Host:api.dingtalk.io
x-acs-dingtalk-access-token:BE1xxxx
Content-Type:application/json

{
  "userIdList" : [ "45252328xxx" ],
  "sortType" : 0
}
```
