この API を呼び出すと、複数の残業ルール ID を指定して、残業ルール設定の詳細を一括で照会できます。

## API 呼び出し説明

たとえば、社内の勤怠グループで、残業ルールが **承認時間に基づいて残業を計算** に設定されているとします。

DingTalk の管理コンソールで、**勤怠グループ管理** > **勤怠グループを変更** > **残業ルール** > **設定** の順に移動します。一般の残業ルールは **承認時間に基づいて残業を計算** に設定されています。この設定は勤務日・休日・祝日のすべてに適用されます。残業には承認が必要で、残業時間は承認フォームに基づいて計算されます。

この API を呼び出すと、**承認時間に基づいて残業を計算** という残業ルールの設定詳細を取得できます。取得できる情報には、ルール名や残業時間の計算方法が含まれます。

管理コンソールで **勤怠ルール管理** > **残業ルール** を開き、残業ルールを編集します。**残業ルールを編集** パネルには、次の設定項目があります。

| フィールド | 選択肢 / 備考 |
| --- | --- |
| **ルール名** | 最大 30 文字 |
| **適用範囲** | 例：社内全体（他の残業ルールが適用されているメンバーを除く） |
| **所有者** | 任意 |
| 日の種類タブ | **勤務日**、**休日**、**祝日** |
| **残業を許可** | オン / オフの切り替え |
| **残業可能な時間帯** | **始業前**、**終業後** |
| **計算方法** | **承認時間に基づいて計算**、または **承認期間内の打刻時間に基づいて計算** |

この例のルールでは、**承認時間に基づいて計算** の方法を使用しています。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/v1.0/attendance/overtimeSettings/query |
| HTTP メソッド | POST |
| 対応するアプリの種類 | appType-社内アプリ　appType-サードパーティ社内アプリ |
| 権限 | permission-qyapi_attendance_group_read-勤怠グループの照会権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | 文字列 | はい | この API を呼び出すためのアクセス認証情報です。次の方法で取得します。   - 社内アプリ：[社内アプリのアクセストークンを取得](/ja/open/development/obtain-the-access-token-of-an-internal-app) API を呼び出します。 - サードパーティ社内アプリ：サードパーティアプリに権限を付与した組織のアクセストークンを取得する API を呼び出します。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| overtimeSettingIds | long の配列 | いいえ | 残業ルール設定の ID です。[ユーザーのシフト設定情報を照会](/ja/open/development/query-scheduling-for-a-day) API を呼び出し、features 内の overtimeSettingId フィールドから取得します。 |

| workMinutesPerDay | 整数 | 1 日に相当する時間です。単位は分です。 |
| overtimeDivisions | 配列 | 時間の分割ルールです。 |
| previousDayType | 文字列 | 前日の種類です。 |
| nextDayType | 文字列 | 翌日の種類です。 |
| timeSplitPoint | 文字列 | 時間の分割点です。 |
| id | long | 過去の残業ルール設定の ID です。 |

| HttpCode | エラーコード | エラーメッセージ | 説明 |
| --- | --- | --- | --- |
| 400 | invalidSize | サイズが無効です | overtimeSettingIds のサイズが無効です |
| 400 | invalidParameter | パラメータエラー | overtimeSettingIds パラメータが無効です |
| 500 | systemError | システムエラー | システムエラー |
