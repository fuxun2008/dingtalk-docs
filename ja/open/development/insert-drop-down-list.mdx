---
title: "ドロップダウンリストの挿入"
---

本インターフェースを呼び出すと、スプレッドシート内の指定したセル範囲にドロップダウンリストの選択肢を設定できます。各選択肢のテキスト値とタグの色をカスタマイズ可能です。データ入力の標準化や、ステータス・分類などのプリセット選択肢を提供するシーンに適しており、設定後はユーザーが事前定義された選択肢からのみ値を選択できるようになります。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | `https://api.dingtalk.io/v1.0/doc/workbooks/{workbookId}/sheets/{sheetId}/ranges/{rangeAddress}/insertDropdownLists` |
| HTTP Method | POST |
| サポートするアプリタイプ | appType-社内アプリ |
| 必要な権限 | permission-Document.Workbook.Write-スプレッドシート書き込み権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | 必須 | 本インターフェース呼び出しのアクセス認証情報です。[社内アプリの access_token を取得](https://open.dingtalk.io/document/development/obtain-the-access-token-of-an-internal-app)インターフェースを呼び出して取得できます。 |

### パスパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| workbookId | String | 必須 | スプレッドシートファイル ID。[ナレッジベース API](https://open.dingtalk.io/document/development/knowledge-base-overview) が返す `nodeId(dentryUuid)` がスプレッドシートの `workbookId` に相当します。[ノード取得](https://open.dingtalk.io/document/development/get-node)および[ナレッジベースドキュメント作成](https://open.dingtalk.io/document/development/create-team-space-document)インターフェースを呼び出して取得できます。 |
| sheetId | String | 必須 | ワークシート ID または見出しです。[全ワークシート取得](https://open.dingtalk.io/document/development/obtain-all-worksheets)インターフェースを呼び出して、id およびワークシートの見出しを取得できます。 |
| rangeAddress | String | 必須 | Range アドレスです。 |

### クエリパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| operatorId | String | 必須 | 操作者の unionId です。[ユーザー詳細クエリ](https://open.dingtalk.io/document/development/query-user-details)インターフェースを呼び出して取得できます。操作者に権限がない場合、インターフェースは `The operator has no permission` というエラーを返します。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| options | Array | 必須 | ドロップダウンリスト選択肢の配列です。 |
| value | String | 必須 | ドロップダウンリストの値です。 |
| color | String | 任意 | ドロップダウンリストの色です。16 進数表記を使用します（例：#ff0000）。 |
