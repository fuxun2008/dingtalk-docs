カスタムスクリーンテンプレート ID に基づいて、カスタムスクリーンテンプレートの情報内容を更新します。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/v1.0/rooms/devices/screens/templates |
| HTTP Method | PUT |
| サポートされるアプリタイプ | appType-社内アプリ　appType-サードパーティ社内アプリ |
| 必要な権限 | permission-Rooms.DeviceTemplate.Write-DingTalk 会議 Rooms システムのカスタムスクリーン書き込み権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | はい | API 認証情報。[ユーザートークンを取得する](/ja/open/development/obtain-user-token#) API を呼び出して取得します。  ユーザートークンを取得するリクエストで使用する入力パラメータ `code` を取得する際、リンク構築の過程で scope の範囲は必ずユーザー ID と組織 ID にする必要があります。すなわち `scope=openid corpid` です。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| templateName | String | はい | テンプレート名。 |
| logo | String | いいえ | テンプレートのロゴ。[メディアファイルをアップロードする](/ja/open/development/upload-media-files#) API を呼び出して mediaId を取得できます。画像サイズ: 240\*240、画像 1 枚あたりのサイズは 1M 以下。 |
| orgName | String | いいえ | テンプレートの企業名。 |
| customDoc | String | いいえ | テンプレートのカスタムテキストコンテンツ。 |
| bgUrl | String | いいえ | テンプレートのカスタム背景 URL。 |
| bgImgList | Array of String | いいえ | 画像の mediaId。[メディアファイルをアップロードする](/ja/open/development/upload-media-files#) API を呼び出して出力パラメータ `media_id` を取得できます。最大 9 枚の画像をアップロードでき、画像 1 枚あたりのサイズは 5M 以下です。 |
| instruction | Boolean | いいえ | 使用説明の表示。デフォルトは false。値:   - true: 表示する - false: 表示しない |
| bgType | Integer | いいえ | テンプレートのカスタム背景タイプ。デフォルトは 1。値:   - 1: 画像 - 2: URL |
| isPicTop | Integer | いいえ | ホーム情報バーの表示。デフォルトは 1。値:   - 0: 表示する - 1: 表示しない |
| hideServerCodeWhenProjecting | Boolean | いいえ | 画面ミラーリング中に画面ミラーリングコードを非表示にする。デフォルトは false。値:   - true: 非表示にする - false: 非表示にしない |
| showCalendarTitle | Boolean | いいえ | 予定カードに予定の見出しを表示する。デフォルトは false。値:   - true: 表示する - false: 表示しない |
| desensitizeUserName | Boolean | いいえ | 予定カードで予約者の名前をマスキングする。デフォルトは false。値:   - true: マスキングする - false: マスキングしない |
| picturePlayInterval | Integer | いいえ | カスタム背景画像の切り替え間隔（秒）。 |
| showCalendarCard | Boolean | いいえ | 予定カードを表示する。デフォルトは false。値:   - true: 表示する - false: 表示しない |
| showFunctionCard | Boolean | いいえ | 機能カードを表示する。デフォルトは false。値:   - true: 表示する - false: 表示しない |
| deviceUnionIds | Array of String | いいえ | デバイスの unionId。このパラメータは [デバイスと会議室の紐付け変更](https://open.dingtalk.com/document/development/org-event-overview#) イベントを購読することで取得します。 |
| groupIds | Array of Long | いいえ | グループ ID。[会議室グループリストを照会する](/ja/open/development/query-meeting-rooms-groups#) API を呼び出して取得できます。 |
| roomIds | Array of String | いいえ | 会議室 ID。[会議室リストを照会する](/ja/open/development/check-the-meeting-room-list#) API を呼び出して取得できます。 |
| templateId | Long | はい | テンプレート ID。[カスタムスクリーンテンプレートリストを照会する](https://open.dingtalk.com/document/development/api-querydevicecustomtemplatelist#) API を呼び出して取得できます。 |
