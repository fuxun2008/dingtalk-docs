この API を呼び出して、勤怠グループを作成します。

## リクエスト

| **基本情報** | |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/topapi/attendance/group/add |
| HTTP メソッド | POST |
| 対応アプリタイプ | appType-社内アプリ |
| 必要な権限 | permission-qyapi_attendance_group_manage-勤怠グループ管理権限 |

### クエリパラメータ

| 名前 | タイプ | 必須 | 例 | 説明 |
| --- | --- | --- | --- | --- |
| access_token | String | はい | 4c9d5xxxx | この API の呼び出しに使用するアプリ認証情報です。[社内アプリの access_token を取得](/ja/open/development/obtain-orgapp-token) API を呼び出して取得します。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 例 | 説明 |

| corp_id | String | いいえ | dingdfe | 組織の CorpId です。[開発者コンソール](https://open-dev.dingtalk.io/#/index)のホームページで取得します。 |

| special_days | String | いいえ | `{"onDuty":{1400000:123,1400001:123},"offDuty":[1400000,1400001]}` | 特別日の設定です。 |
| enable_outside_camera_check | Boolean | いいえ | true | 外勤打刻時に写真の撮影を必須にするかどうかを指定します。   - **true**：オン - **false**（デフォルト）：オフ |

| title | String | いいえ | 青蔵高原自然博物館 | 勤怠場所のタイトルです。 |

| enable_camera_check | Boolean | いいえ | true | 写真打刻を有効にするかどうかを指定します。   - **true**：オン - **false**（デフォルト）：オフ |
| shift_vo_list | `List<TopShiftVo>` | いいえ |  | シフトの設定です。 |
| id | Number | いいえ | 123 | シフト ID です。[シフト概要の取得](/ja/open/development/enterprise-shift-query-in-batches) API を呼び出して id の値を取得します。 |
| enable_outside_check | Boolean | いいえ | true | 外勤打刻を許可するかどうかを指定します。   - **true**（デフォルト）：許可 - **false**：許可しない |

| role | String | はい | Attendance | ロールです。固定値：Attendance。 |
| corp_id | String | いいえ | 123dfd | 組織の CorpId です。[開発者コンソール](https://open-dev.dingtalk.io/#/index)のホームページで取得します。 |
| type | String | はい | StaffMember | タイプです。   - StaffMember：ユーザータイプ - DeptMember：部門タイプ |
| user_id | String | はい | 1212jfkd | ID です。   - ユーザー：userId - 部門：deptId |
| name | String | はい | 日勤勤怠 | 勤怠グループの名前です。 |
| id | Number | いいえ | 123 | 勤怠グループ ID です。 |
| enable_next_day | Boolean | いいえ | false | 設定を翌日から有効にするかどうかを指定します。   - **true**：はい - **false**：いいえ |

| default_class_id | Number | いいえ | 1234 | デフォルトのシフト ID です。  **注意**  固定シフト制の場合は必須です。[シフト概要の取得](/ja/open/development/enterprise-shift-query-in-batches) API を呼び出して id の値を取得します。 |
| offset | Number | いいえ | 500 | 勤怠範囲です。 |

| schedule | String | いいえ | w | 社員のシフト設定です。 |

| check_time | String | いいえ | w | 勤怠時間を設定します。 |
| check_position_type | String | いいえ | r | 打刻方法を設定します。 |
| over_time_rule | String | いいえ | r | 残業ルールを設定します。 |
| camera_check | String | いいえ | w | 写真打刻のルールを設定します。 |
| out_side_check | String | いいえ | w | 外勤打刻を設定します。 |
| wifis | `List<TopWifiVo>` | いいえ |  | Wi-Fi 打刻の設定です。 |
| mac_addr | String | いいえ | C0:E0:D0:E0:C0:0F | MAC アドレスです。 |
| ssid | String | いいえ | OFFICE-WiFi | Wi-Fi ネットワークの SSID です。 |
| corp_id | String | いいえ | 123dfd | 組織の CorpId です。[開発者コンソール](https://open-dev.dingtalk.io/#/index)のホームページで取得します。 |
| disable_check_without_schedule | Boolean | いいえ | false | シフト未設定時に、社員の打刻を禁止するかどうかを指定します。   - **true**：禁止 - **false**：禁止しない |
| freecheck_work_days | Number[] | いいえ | [1,2,3,4,5,6,0] | フレックスタイムの勤怠グループの勤務日です。  **注意**     - 0 は休日を表します。 - 配列の値は、左から順に日曜日から土曜日までの各曜日のシフト設定を表します。 |
| freecheck_day_start_min_offset | Number | いいえ | 240 | フレックスタイムの勤怠グループにおける勤怠開始時刻と、当日 00:00 との差（分）です。  例えば、540 は 9:00 を表します。 |
| disable_check_when_rest | Boolean | いいえ | false | 休日の打刻に承認を必要とするかどうかを指定します。   - **true**：必要 - **false**：不要 |
