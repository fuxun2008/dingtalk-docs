---
title: "条件付き書式ルールの作成"
description: "重複入力されたデータをハイライト表示して確認しやすくしたり、特定の範囲内の数値を特定の背景色で区別したりできます。ルール作成後、条件を満たすセルには指定したフォントカラーまたは背景色が自動的に適用され、手動で個別に設定する必要がありません。"
---

本インターフェースを呼び出すことで、DingTalk スプレッドシートの指定したワークシートに条件付き書式ルールを作成し、セルの値や重複状況に基づいて自動的にハイライトスタイルを適用できます。データを視覚的にマークする必要があるシーンに適しており、たとえば目標値を下回るセルを赤くマークしたり、重複入力されたデータをハイライト表示して確認しやすくしたり、特定の範囲内の数値を特定の背景色で区別したりする用途があります。ルール作成後、条件を満たすセルには指定したフォントカラーまたは背景色が自動的に適用され、手動で個別に設定する必要がありません。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | `https://api.dingtalk.io/v1.0/doc/workbooks/{workbookId}/sheets/{sheetId}/conditionalFormattingRules` |
| HTTP Method | POST |
| サポートするアプリタイプ | appType-社内アプリ |
| 権限要件 | permission-Document.Workbook.Write-DingTalk スプレッドシート書き込み権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | はい | このインターフェースを呼び出すためのアクセス認証情報です。[社内アプリの access_token を取得する](/ja/open/development/obtain-the-access-token-of-an-internal-app)インターフェースを呼び出して取得できます。 |

### パスパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| workbookId | String | はい | スプレッドシートファイル ID です。[ナレッジベース API](/ja/open/development/knowledge-base-overview) が返す `nodeId(dentryUuid)` がスプレッドシートの `workbookId` に該当します。[ノードを取得する](https://open.dingtalk.com/document/development/get-node) および [ナレッジベースドキュメントを作成する](/ja/open/development/create-team-space-document) インターフェースを呼び出して取得できます。 |
| sheetId | String | はい | ワークシート ID またはタイトルです。[全ワークシートを取得する](/ja/open/development/obtain-all-worksheets)インターフェースを呼び出して、ID とワークシートのタイトルを取得できます。 |

### クエリパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| operatorId | String | はい | 操作者の unionId です。[ユーザー詳細を取得する](/ja/open/development/query-user-details)インターフェースを呼び出して取得できます。操作者に権限がない場合、インターフェースは `The operator has no permission` というエラーを返します。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| ranges | Array of String | はい | セルアドレス。A1 表記を使用します。 |
| duplicateCondition | Object | いいえ | 重複値ルール。 |
| operator | String | いいえ | 演算子。現在は duplicate のみサポートし、重複項目を意味します。 |
| numberCondition | Object | いいえ | 数値ルール。 |
| operator | String | いいえ | 比較演算子。指定可能な値:   - **equal**：等しい - **not-equal**：等しくない - **greater**：より大きい - **greater-equal**：以上 - **less**：より小さい - **less-equal**：以下 - **between**：両者の間（境界を含む） - **not-between**：両者の間ではない |
| value1 | Any | いいえ | value1 — 1 つ目の比較値（必須）。 |
| value2 | Any | いいえ | value2 — 2 つ目の比較値（任意、operator が between または not-between の場合のみ指定が必要で、範囲の上限として使用します）。 |
| cellStyle | Object | いいえ | 現在設定するルールのセルスタイルを指定します。 |
| backgroundColor | String | いいえ | 背景色。16 進数のカラー表記を使用します（例: #ff0000）。 |
| fontColor | String | いいえ | フォントカラー。 |
