---
title: "退職レコードリストの照会"
---

本 API を呼び出すことで、企業の退職レコードリストを照会できます。退職社員の退職日付、電話番号、企業から脱退する方法などの情報が含まれます。

## API 呼び出し説明

例えば、企業向けスマート人事アプリにおいて、2022年6月1日から2022年6月7日までの退職レコードは下図のとおりで、社員「小钉2」の退職日付は2022年6月7日、「钉钉测试」の退職日付は2022年6月7日です。

本 API を呼び出して 2022年6月1日から2022年6月7日までの退職レコードを照会すると、社員「小钉2」と「钉钉测试」の組織を離れた時刻、電話番号、企業から脱退する方法などの情報を取得できます。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/v1.0/contact/empLeaveRecords |
| HTTP Method | GET |
| サポートするアプリタイプ | appType-社内アプリ |
| 必要な権限 | permission-Contact.Common.Read-連絡先基本データ読み取り権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | はい | 本 API を呼び出すためのアクセス認証情報です。[社内アプリのアクセストークン取得](https://open.dingtalk.io/document/development/obtain-the-access-token-of-an-internal-app#) API を呼び出して取得します。 |

### クエリパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| startTime | String | はい | 開始時刻。  フォーマット：`YYYY-MM-DDTHH:mm:ssZ`（ISO 8601/RFC 3339）。 |
| endTime | String | いいえ | 終了時刻。  フォーマット：`YYYY-MM-DDTHH:mm:ssZ`（ISO 8601/RFC 3339）。  - 本パラメータを指定しない場合、開始時刻は現在時刻から 365 日を超えてはなりません。 - 本パラメータを指定する場合、開始時刻と終了時刻の期間は 365 日を超えてはなりません。 |
| nextToken | String | いいえ | ページネーションカーソル。   - 初回照会時は、本パラメータに 0 を指定します。 - 2 回目以降の照会時は、前回呼び出し時に返された nextToken を本パラメータに指定します。 |
| maxResults | Integer | はい | 1 ページあたりの最大エントリ数。最大値は 50 です。 |
