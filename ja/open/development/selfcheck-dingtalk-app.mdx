title: "アプリのセルフチェック"
description: "アプリのリリース後、公開前に必要なセルフチェックを実施しましょう。DingTalkのサーバー設定やHTTPS、プッシュ設定、安定性監視の各項目を確認する手順を解説します。"
---

アプリのリリース後、公開前にセルフチェックを実施してください。本ドキュメントの手順に従って、アプリのセルフチェックを行います。

## **手順**

1. [Developer Console](https://open-dev.dingtalk.com/) にログインし、対象のアプリをクリックして詳細ページを開きます。
2. アプリの詳細ページで、**アプリ公開 > アプリセルフチェック**をクリックします。
3. チェック開始をクリックし、機能のセルフチェックを完了します。

   | チェック項目 | 説明 |
   | --- | --- |
   | サーバーの送信元 IP が設定されているか | アプリの**開発設定 > セキュリティセンター**でサーバーの送信元 IP を設定します。 |
   | アプリのホームページまたは管理コンソール URL が HTTPS を使用しているか | アプリのホームページまたは管理コンソール URL は HTTPS プロトコルを使用する必要があります。 |
   | 有効なプッシュタイプが設定されているか | アプリの開発情報でプッシュ設定を完了します。SyncHTTP プッシュを使用する場合、コールバック URL は [DingTalk セキュアドメイン](/ja/open/development/configure-update-secure-domain-name)を使用する必要があります。 |
   | 監視センターが接続されているか | 監視センターに接続し、監視データを生成します。 |
   | サーバーが Alibaba Cloud にデプロイされているか | 正しいデプロイ方式を選択します。 |
4. 機能のセルフチェックが完了したら、**次へ**をクリックして安全審査に進みます。Security Access Evaluation を参照し、アプリの公開に必要な安全審査評価項目の資料を入力して送信します。
5. 送信後、安定性監視ページに移動します。詳細な要件については、Stability Certification Standards を参照してください。

   | **データ指標** | **説明** | **指標要件** |
   | --- | --- | --- |
   | 監視センターの API 成功率 | 監視センターの**監視指標** > **API リクエスト** > **成功率**で確認します。 | ≥98.99% |
   | 監視センターの API 平均遅延 | 監視センターの**監視指標** > **API リクエスト** > **リクエスト遅延**で確認します。 | &lt;300 |
   | 監視センターの JS エラー率 | 監視センターの**監視指標** > **JS エラー** > **エラー数の PV 比率**で確認します。 | &lt;1.99% |
   | 監視センターのホワイトスクリーン率 | 監視センターの**監視指標** > **ホワイトスクリーンエラー** > **ホワイトスクリーン率**で確認します。 | &lt;1.99% |
   | dd.config 成功率 | **dd.config** SAPI の呼び出しの毎日平均成功率です。 | ≥98.99% |
   | HTTP プッシュ成功率 | プッシュタイプが Stream または SyncHttp の場合、統計期間中に DingTalk がコールバック URL へプッシュした成功率です（**1,500 ms を超えるプッシュはタイムアウト失敗としてカウントされます**）。 | ≥98.99% |
6. 安定性監視が完了したら、**セルフチェック完了**をクリックし、続いて**公開申請**をクリックします。

## **次のステップ**

アプリの公開申請後、アプリの公開情報を入力します。List Your Product を参照してください。
