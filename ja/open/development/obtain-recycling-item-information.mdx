---
title: "ゴミ箱項目情報の取得"
---

本インターフェースを呼び出すと、ゴミ箱内の特定の項目に関する詳細情報（元のスペース ID、元のパス、サイズ、名前など）を取得できます。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | `https://api.dingtalk.io/v1.0/storage/recycleBins/{recycleBinId}/recycleItems/{recycleItemId}` |
| HTTP Method | GET |
| サポートされるアプリタイプ | appType-社内アプリ　appType-サードパーティ社内アプリ |
| 必要な権限 | permission-Storage.RecycleBin.Read-企業ストレージのゴミ箱読み取り権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | はい | 本インターフェースを呼び出すためのアクセス認証情報。以下の方法で取得します。   - 社内アプリの場合、[社内アプリの access_token を取得する](https://open.dingtalk.io/document/development/obtain-the-access-token-of-an-internal-app#)インターフェースを呼び出して取得します。 - サードパーティ社内アプリの場合、[サードパーティアプリが権限付与された企業の access_token を取得する](https://open.dingtalk.io/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#)インターフェースを呼び出して取得します。 |

### パスパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| recycleBinId | String | はい | ゴミ箱 ID。[ゴミ箱情報の取得](https://open.dingtalk.io/document/development/obtain-information-about-the-recycle-bin#)インターフェースを呼び出して取得できます。 |
| recycleItemId | String | はい | ゴミ箱項目 ID。[ゴミ箱項目リストの取得](https://open.dingtalk.io/document/development/gets-the-list-of-recycle-items#)インターフェースを呼び出して id パラメータの値を取得できます。 |

### クエリパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| unionId | String | はい | 操作者の unionId。[ユーザー詳細の照会](https://open.dingtalk.io/document/development/query-user-details#)インターフェースを呼び出して取得できます。 |
