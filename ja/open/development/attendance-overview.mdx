このトピックでは、勤怠オープン API の機能と連携方法を説明します。

## 勤怠とは

勤怠は、組織向けに社員の勤怠管理ソリューションを提供する DingTalk の公式アプリです。チームの状況をいつでもどこでも確認できます。**誰が出勤しているかがひと目でわかり**、手作業で確認しなくても**勤怠データを自動で集計します**。詳しくは、[勤怠管理者向けクイックスタート](/ja/attendance/admin-quick-start)を参照してください。

主な機能：

- **多様な勤怠シーンに対応する複数の打刻方法**：GPS 位置情報や Wi-Fi などで打刻できます。
- **社内勤務と外勤を一元管理し、集計を効率化**：外勤打刻により、一時的に外出している社員や出張中の社員の勤怠を記録できます。
- **休暇・勤怠承認と連携し、勤怠統計を 1 つの表に集約**：休暇、残業、外出、出張の承認が自動で集計・計算されるため、複数のレポートを照合する必要がありません。

## 勤怠を有効にする方法

勤怠は、DingTalk にデフォルトでインストールされている公式アプリです。社員は DingTalk のワークベンチから開いて利用します。

- モバイル：DingTalk モバイルクライアント > ワークベンチ

  DingTalk モバイルクライアントで、次の操作を行います。
  1. 下部のナビゲーションバーで **ワークベンチ** をタップします。
  2. **勤怠** アプリを開きます。
- デスクトップ：DingTalk デスクトップクライアント > ワークベンチ

  DingTalk クライアントで **ワークベンチ** を開きます。**全社員** セクションで **勤怠** アプリを選択し、設定を開始します。

### 勤怠グループ

勤怠グループとは、組織管理者が社員向けに設定する勤怠ルールのまとまりです。社内の職種に応じて、異なるタイプの勤怠グループを作成できます。

<Note>
旧バージョンと新バージョンの API 仕様の違いにより、勤怠グループは group_id または groupKey のいずれかで一意に識別されます。groupKey の値を対応する group_id に変換するには、[groupKey から groupId への変換](/ja/open/development/convert-groupkey-to-groupid) API を呼び出してください。
</Note>

勤怠グループには次の 3 種類があります。

- **固定シフト制勤怠グループ**：毎日 9:00〜18:00 勤務で週末が固定休みなど、勤務時間と休日が固定されている社員向けです。
- **シフト制勤怠グループ**：早番・遅番がある社員、日ごとにシフトが異なる社員、休日をシフトで設定する必要がある社員向けです。
- **フレックスタイム勤怠グループ**：勤務時間が柔軟な社員向けです。

[DingTalk 管理コンソール](https://oa.dingtalk.io/?lang=ja_JP)にログインし、**ワークベンチ > アプリ管理 > 勤怠 > 勤怠グループ管理** に移動して勤怠グループを追加します。

### 休暇ルール（leave_code）

休暇ルールは leave_code で一意に識別されます。

DingTalk 管理コンソールで **休暇管理** > **休暇ルール** に移動すると、休暇ルールを表示・設定できます。**休暇を追加** をクリックして休暇ルールを作成します。各休暇ルールには次の属性があります。

| フィールド | 説明 |
| --- | --- |
| 休暇名 | 休暇タイプの名前（例：私用休暇、代休、病気休暇、年次有給休暇、産前産後休暇、配偶者出産休暇、結婚休暇） |
| 休暇単位 | 申請の最小単位：時間単位、半日単位、または日単位 |
| 時間の計算方法 | 休暇時間のカウント方法（例：勤務日ベース） |
| 有給 | 有給休暇か無給休暇か |
| 残数ルール | 残数の上限（例：残数無制限） |
| スコープ | ルールの適用対象（例：組織全体） |
| 操作 | ルールの編集または削除 |

### シフト

勤怠グループを作成する際にシフトを紐付けます。シフトでは、勤怠グループ内の社員の打刻時刻と労働時間を定義します。柔軟な打刻、遅く出勤した場合の遅い退勤、早く出勤した場合の早い退勤、遅刻、欠勤の設定など、社内のニーズに合わせて勤怠シフトをカスタマイズできます。

[DingTalk 管理コンソール](https://oa.dingtalk.io/?lang=ja_JP)にログインし、**アプリ管理 > 勤怠 > シフト管理** に移動してシフトを追加します。

**シフト管理** ページで **シフトを追加** をクリックすると、新しいシフトを作成できます。既存のシフトは次の列で一覧表示されます。

| 列 | 説明 |
| --- | --- |
| **シフト名** | シフトの名前（例：デフォルトシフト） |
| **勤務時間** | 勤務時間帯（例：09:00〜18:00） |
| **操作** | シフトの **編集** または **削除** |
