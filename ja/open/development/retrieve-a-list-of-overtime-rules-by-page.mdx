この API を呼び出すと、勤怠の打刻設定に登録された残業ルールの一覧をページ単位で取得できます。各ルールの名前と ID が含まれます。

## API 呼び出し説明

たとえば、社内の勤怠ルール管理に **承認後に打刻時間で残業を計算**、**承認時間で残業を計算**、**打刻時間で残業を計算** の 3 つの残業ルールがあるとします。

この API を呼び出すと、3 つの残業ルールすべてのルール名とルール ID を取得できます。

残業ルールは **勤怠ルール管理** > **残業ルール** で管理します。**残業ルールを追加** からルールを追加でき、既存のルールは **編集** または **削除** できます。例に挙げた 3 つのルールの動作は次のとおりです。

| ルール名 | コンテンツ（勤務日 / 休息日 / 祝日） | 適用範囲 |
| --- | --- | --- |
| 承認時間で残業を計算 | 残業には承認が必要です。残業時間は承認フォームに基づきます | 企業全体（他の残業ルールが適用されているメンバーを除く） |
| 承認後に打刻時間で残業を計算 | 残業には承認が必要です。打刻に基づきますが、承認フォームの時間を超えることはできません | 未使用 |
| 打刻時間で残業を計算 | 残業に承認は不要です。残業時間は打刻時間から計算されます | 未使用 |

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/v1.0/attendance/overtimeSettings |
| HTTP メソッド | GET |
| 対応するアプリタイプ | appType-社内アプリ　appType-サードパーティ社内アプリ |
| 必要な権限 | permission-qyapi_attendance_group_read-勤怠グループの読み取り権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | はい | この API を呼び出すためのアクセス認証情報です。以下の方法で取得します。   - 社内アプリ：[社内アプリのアクセストークンを取得](/ja/open/development/obtain-the-access-token-of-an-internal-app) API を呼び出します。 - サードパーティ社内アプリ：サードパーティアプリを承認した組織のアクセストークンを取得する API を呼び出します。 |

### クエリパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| pageNumber | Long | はい | 開始ページ番号です。  値は 1 から始まります。 |
| pageSize | Long | はい | 1 ページあたりの件数です。  最大値は 50 です。 |

### リクエスト例

HTTP

```http
GET /v1.0/attendance/overtimeSettings?pageNumber=1&pageSize=10 HTTP/1.1
Host:api.dingtalk.io
x-acs-dingtalk-access-token:xxxxx
Content-Type:application/json
```
