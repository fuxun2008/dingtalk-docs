## **DingTalk 開発者の皆様へ**

より安定的で公平、かつ持続可能なオープンプラットフォームのエコシステムを構築し、すべての開発者がプラットフォームリソースを効率的かつ責任を持って利用いただけるよう、DingTalk Open Platform の API 呼び出しクォータポリシーを変更する予定です。既存の「無制限」ポリシー（通称「PaaS ホワイトリスト」）を見直し、影響を受けるすべての組織には、新ルールに適応するための十分な移行期間を設けます。

### **PaaS ホワイトリストポリシー変更に関するお知らせ**

- **2025年9月1日より**、一部の業界の組織が開発した社内アプリおよび個別に保護されている組織を対象とした、従来の PaaS 無制限「ホワイトリスト」ポリシーを終了します。（無制限クォータには、API 呼び出し無制限、Webhook および Stream 呼び出し無制限、コネクタフローの実行ノードの実行回数無制限が含まれます。）

### **3か月間の最適化移行期間**

- **2025年9月1日から11月30日まで**、使用量がクォータを超過してもサービスは中断されず、引き続きご利用いただけます。
- DingTalk Open Platform は、組織管理者に超過に関するお知らせを送信します。
- この期間中に、組織においてコードを最適化するか、追加の利用パッケージの購入をご準備いただくことをお勧めします。

### **新ポリシーの適用開始日**

- **2025年12月1日より**、スケールアップが間に合わないことによる業務の中断を防ぐため、毎月のクォータを使い切ると、システムが自動的に**最大5日間のバッファ保護期間**を提供します。この期間中も、アプリは通常どおり API を呼び出すことができます。さらに、**社内アプリ開発アドオンパッケージ1つの15日間の無料 Trial** の権利を提供します。デベロッパーコンソールでご自身で申請いただくか、担当のアカウントマネージャーとの QRコードのスキャンによりご利用いただけます。

ポリシー変更後も業務を円滑に運用いただくため、事前の評価と計画を強くお勧めします。DingTalk デベロッパーコンソールにログインし、最近の期間におけるアプリの API 呼び出し状況を確認し、今後の使用量を見積もってください。

今回の変更により、対応にお時間を要する可能性があることを理解しており、最大3か月間の最適化バッファ期間に加え、この期間中はサービスの中断なしでのご利用とお知らせによるサポートを提供します。見積もった使用量がフリークォータを超過する場合は、以下のオプションでより多くのクォータを取得できます。

- **オプション1**：より多くの呼び出し回数が必要な場合は、[社内アプリ開発アドオンパッケージ](https://open.dingtalk.com/document/orgapp/dingtalk-application-development-platform-billing-model)を個別に購入してください。

- **オプション2**：DingTalk Pro または専用版にアップグレードすると、プラン内でより多くのフリー呼び出しクォータや付加価値特典を受けられます。

私たちの目標は、皆様とともに成長し、より健全で効率的な開発環境を構築することです。ご不明な点がございましたら、デベロッパーコンソールを通じてお問い合わせいただくか、担当のアカウントマネージャーにご連絡ください。

本お知らせは2025年7月17日に発効します。ご支援とご理解を賜り、誠にありがとうございます。

## **FAQ**

**Q1：私は DingTalk の開発者です。「ホワイトリスト」が廃止されると聞きましたが、具体的にはいつですか？**

A：はい。プラットフォームサービスの公平性と安定性を確保するため、既存の「無制限」ポリシー（通称「PaaS ホワイトリスト」）を統一された**標準クォータポリシー**にアップグレードします。この変更は2025年9月1日に正式に適用され、皆様のために十分な移行プランをご用意しています。

**Q2：2025年9月1日に私のサービスはすぐに停止されますか？**

決してそのようなことはありません。2025年9月1日から11月30日までの3か月間を「移行・最適化期間」として設定しています。この期間中は、使用量が新しい標準クォータを超過しても、サービスは**中断されることなく通常どおり稼働し続けます**。使用状況を把握いただけるよう、お知らせを送信します。

**Q3：移行期間中に何をする必要がありますか？**

A：この期間は、新ポリシーに向けて準備を進める絶好の機会です。以下をお勧めします。

- **使用状況の確認：** デベロッパーコンソールにログインし、現在の API 使用状況を確認します。
- **コードの最適化：** アプリを見直し、使用量を削減できる API 呼び出しロジックの最適化がないか確認します。
- **事前の計画：** 業務上、より多くのクォータが本当に必要な場合は、利用アドオンパッケージのオプションを事前にご確認ください。

**Q4：新ポリシーはいつ正式に適用されますか？クォータを超過した場合はどうなりますか？**

A：新ポリシーは2025年12月1日に正式に適用されます。万が一クォータを超過しても、ご安心ください。**5日間の使用保護期間**を提供します。この保護期間中は、サービスは通常どおり稼働し続けます。**この5日以内に**使用量の問題を解決する必要があります。5日を過ぎても問題が解決されない場合、クォータを超過した呼び出しリクエストには相応の制限が適用されます。
