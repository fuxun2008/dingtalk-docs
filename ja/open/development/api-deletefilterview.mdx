---
title: "フィルタービューの削除"
description: "フィルタービューが上限の 20 個に達した際に、古いビューを削除して空きを確保します。"
---

本 API を呼び出すと、指定したワークシート上の特定のフィルタービューと、そのすべてのフィルター条件を削除できます。不要になったフィルタービューを整理するシーン、例えばプロジェクト終了後に一時的に作成したデータ絞り込み用ビューを削除する場合や、ワークシートごとの上限である 20 個に達した際に古いビューを削除して空きを確保する場合に適しています。

## API 呼び出し説明

削除操作は、グローバルフィルターおよび他のフィルタービューには影響しません。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | `https://api.dingtalk.io/v1.0/doc/workbooks/{workbookId}/sheets/{sheetId}/filterViews/{filterViewId}` |
| HTTP Method | DELETE |
| サポートされるアプリタイプ | appType-社内アプリ |
| 必要な権限 | permission-Document.Workbook.Write-スプレッドシート書き込み権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | はい | 本 API を呼び出すためのアクセス認証情報です。[社内アプリの accessToken を取得する](/ja/open/development/obtain-the-access-token-of-an-internal-app) API を呼び出して取得します。 |

### パスパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| workbookId | String | はい | スプレッドシートファイル ID。[ナレッジベース API](https://open.dingtalk.io/document/orgapp/knowledge-base-overview) が返す `nodeId(dentryUuid)` がスプレッドシートの `workbookId` に相当します。[ノードの取得](https://open.dingtalk.io/document/orgapp/get-node) および [ナレッジベースドキュメントの作成](https://open.dingtalk.io/document/orgapp/create-team-space-document) API を呼び出して取得できます。 |
| sheetId | String | はい | ワークシート ID または名前。[全ワークシートの取得](https://open.dingtalk.io/document/orgapp/obtain-all-worksheets) API を呼び出して、id または name のパラメータ値を取得できます。 |
| filterViewId | String | はい | フィルタービューの ID |

### クエリパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| operatorId | String | はい | 操作者の unionId。   - [サイレントログインコードによるユーザー情報の取得](https://open.dingtalk.io/document/orgapp/obtain-the-userid-of-a-user-by-using-the-log-free) API で unionid パラメータ値を取得できます。 - [ユーザー詳細の照会](https://open.dingtalk.io/document/orgapp/query-user-details) API を呼び出して unionid パラメータ値を取得できます。       操作者に権限がない場合、API は `The operator has no permission` というエラーを返します。 |
