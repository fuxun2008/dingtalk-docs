---
title: "カスタム画面テンプレート一覧の取得"
---

本 API を呼び出して、カスタム画面テンプレート一覧の情報を直接取得します。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/v1.0/rooms/devices/screens/templateLists |
| HTTP Method | GET |
| サポートするアプリタイプ | appType-社内アプリ　appType-サードパーティ社内アプリ |
| 必要な権限 | permission-Rooms.DeviceTemplate.Read-DingTalk 会議 Rooms システムのカスタム画面の読み取り権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | はい | API 認証情報。[ユーザートークンを取得する](/ja/open/development/obtain-user-token#) を呼び出して取得します。ユーザートークンを取得するリクエストで使用するパラメータ `code` を構築するリンクの取得過程で、scope の範囲はユーザー ID と組織 ID、つまり `scope=openid corpid` である必要があります。 |

### リクエスト例

```http
GET /v1.0/rooms/devices/screens/templateLists HTTP/1.1
Host:api.dingtalk.io
x-acs-dingtalk-access-token:xxxxxxxxx
```
