---
title: "承認フォームテンプレートの作成または更新"
description: "承認フォームテンプレートを作成・更新する API です。フォームコントロールを指定してデフォルトの承認フローを自動生成できます。"
---

この API を呼び出して、OA承認のワークフローフォームテンプレートを作成または更新します。フォームコントロールのリストを指定すると、デフォルトの承認フローが生成されます。

## API 呼び出し説明

- 各組織で作成できる公式承認テンプレートは最大 200 個です。上限に達すると、この API を呼び出してもエラーが返されます。
- 公式 OA 承認テンプレートでサポートされるのは、このドキュメントに記載された承認コンポーネントのみです。その他のコンポーネントはサポートされていません。
- 公式 OA 承認テンプレートでサポートされるのは、このドキュメントに記載された承認コンポーネントのみです。その他のコンポーネントはサポートされていません。
- 承認テンプレートを更新する際、更新対象のコンポーネントがワークフロー設計で分岐条件として使用されている場合は、テンプレートのフォームを変更できません。

## リクエスト

### ベーシック情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/v1.0/workflow/forms |
| HTTP メソッド | POST |
| サポートされるアプリの種類 | appType-社内アプリ　appType-サードパーティ社内アプリ |
| 権限 | permission-Workflow.Form.Write-作業フローテンプレートの書き込み権限 |

### リクエストヘッダー

| 名前 | 型 | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | 文字列 | はい | この API を呼び出すためのアクセス認証情報です。以下の方法で取得します。   - 社内アプリ：[社内アプリのアクセストークンを取得](/ja/open/development/obtain-the-access-token-of-an-internal-app) API を呼び出します。 - サードパーティ社内アプリ：サードパーティアプリを承認した組織のアクセストークンを取得する API を呼び出します。 |

### リクエストボディ

| 名前 | 型 | 必須 | 説明 |
| --- | --- | --- | --- |
| processCode | 文字列 | いいえ | フォームの ProcessCode です。フォームテンプレートを更新する場合に指定します。    **ProcessCode** を渡してフォームコンポーネントを変更・更新する場合、ワークフロー設計で条件分岐として使用されているコントロールは削除・変更できません。たとえば、元のフォームに分岐条件として使用されている**単一選択コントロール**「社員タイプ」がある場合、フォームの更新時に「社員タイプ」フィールドのコントロールタイプを変更したり、フィールドを削除したりすることはできません。   - このパラメーターを空にした場合は、新しいテンプレートが作成されます。 - このパラメーターを指定した場合は、値に一致する承認テンプレートが更新されます。   **process_code の取得方法**：DingTalk 管理コンソールの承認テンプレートで確認します。    確認方法は新旧の DingTalk 管理コンソールで異なります。詳細は [OA承認の概要 - 用語集 - processCode](/ja/open/development/workflow-overview) を参照してください。  **新しい DingTalk 管理コンソール**：承認テンプレートの編集ページを開き、ベーシック設定に移動して、ページ下部で確認します。**旧 DingTalk 管理コンソール**：承認テンプレートの編集ページの URL で確認します。 |
| name | 文字列 | はい | フォームテンプレートの名前です。最大 200 文字です。 |
| description | 文字列 | いいえ | フォームテンプレートの説明です。最大 300 文字です。 |
| formComponents | 配列 | はい | フォームコントロールのリストです。1 つのフォームに含められるコンポーネントは最大 200 個です。 |
| FormComponent | FormComponent | はい | フォームコントロールのリストです。詳細は [FormComponent パラメーター](/ja/open/development/oa-formcomponent-message) を参照してください。 |
| templateConfig | オブジェクト | いいえ | フォームのグローバル属性の設定です。 |
| disableStopProcessButton | 真偽値 | いいえ | 管理リストページの**無効化**ボタンを無効にするかどうかを指定します。   - **true**：はい - **false**：いいえ |
| hidden | 真偽値 | いいえ | 作業フローテンプレートのエントリをグローバルに非表示にするかどうかを指定します。   - **true**：はい - **false**：いいえ |
| disableDeleteProcess | 真偽値 | いいえ | テンプレートの**削除**ボタンを無効にするかどうかを指定します。   - **true**：はい - **false**：いいえ |
| disableFormEdit | 真偽値 | いいえ | フォームの**編集**機能を無効にするかどうかを指定します。   - **true**：はい - **false**：いいえ |
| disableResubmit | 真偽値 | いいえ | 詳細ページの**再提出**ボタンを無効にするかどうかを指定します。   - **true**：はい - **false**：いいえ |
| disableHomepage | 真偽値 | いいえ | ホームページでテンプレートを非表示にするかどうかを指定します。   - **true**：はい - **false**：いいえ |
| dirId | 文字列 | いいえ | テンプレートのディレクトリ ID です。テンプレートディレクトリを作成する場合に指定します。 |
| originDirId | 文字列 | いいえ | 元のディレクトリ ID です。テンプレートディレクトリを更新する場合に、移動元のディレクトリ ID を指定します。 |
