本記事では、メッセージテンプレートの作成、削除、有効化、無効化、複製、テスト、および設定の方法について説明します。

## メッセージテンプレートの作成と設定

1. [開発者コンソール](https://open-dev.dingtalk.com/?version=5.86.5#/appMgr/provider/eapp/57406/2)にログインします。
2. **アプリ開発**をクリックし、**サードパーティ社内アプリ**を選択して、ミニプログラムまたは H5 マイクロアプリを作成します。
3. アプリ詳細ページで**メッセージプッシュ**をクリックします。メッセージテンプレート管理エリアで、**追加**をクリックします。
4. テンプレートタイプを選択し、**作成**をクリックします。
5. メッセージテンプレートを設定し、**保存**をクリックします。

   **重要**

   テンプレートにテンプレートパラメータが設定されている場合、それらは自動的に下部に読み込まれ、各動的パラメータの説明を設定できます。

   メッセージコンテンツ内の一部の値は、注文番号、電話番号、商品名など、動的に変化します。これらの値はテンプレート設定時には確定できないため、テンプレートパラメータを使用して置換できます。
6. **テスト**をクリックし、次に**テストメッセージを送信**をクリックして、メッセージテンプレートが正しく設定されていることを確認します。

## Markdown テンプレートの設定

Markdown テンプレートは、Markdown 構文を使用してメッセージを設定・送信します。操作を必要としない純粋な通知メッセージに適しています。

Markdown テンプレートを使用すると、テキスト、画像、リンクなどの表示形式を簡単にサポートできます。

**Markdown メッセージテンプレートの設定**

| 設定項目 | テンプレートパラメータ対応 | 説明 |
| --- | --- | --- |
| **テンプレート名** | 非対応 | テンプレート名を指定します。テンプレートのユースケースとタイプに基づいて命名します。例：新規チケット通知テンプレート。 |
| **ユースケース** | 非対応 | テンプレートのユースケースを説明します。 |
| **画像** | 非対応 | メッセージ内の画像です。画像リンクまたは media_id 形式をサポートします。この設定項目は個別に設定され、各メッセージは 1 枚の画像のみサポートします。画像は最上部に固定されます。 |
| **メッセージタイトル** | 非対応 | メッセージのタイトルおよびチャットの最初の画面に表示されるコンテンツです。 |
| **メッセージコンテンツ** | 対応 | Markdown 形式のメッセージコンテンツです。最大 1,000 文字を推奨します。サポートされる Markdown 構文については、以下の表を参照してください。**重要**     - メッセージテンプレートの Markdown 構文は見出しをサポートしません。つまり、「# +見出しテキスト」の見出し形式はサポートされません。メッセージタイトルはタイトル入力ボックスで個別に入力してください。第 1 レベルのタイトルのみサポートされます。 - メッセージテンプレートの Markdown 構文は画像をサポートしません。つまり、「」形式はサポートされません。メッセージ画像は画像入力ボックスで個別に入力してください。各メッセージは 1 枚の画像のみサポートします。 |

**Markdown 構文**：

```text
参照
> 信念を持たない者は、何にでも惑わされる。
 
太字と斜体
**太字**
*斜体*
 
リンク
[これはリンクです](http://name.com)
 
箇条書き
- item1
- item2
 
番号付きリスト
1. item1
2. item2

改行
 入力ボックス内で改行を表示するだけで十分です。\n はサポートされません。
```

## ActionCard テンプレート

ActionCard テンプレートは、ActionCard メッセージタイプのメッセージを送信します。メッセージコンテンツとアクションポイントを組み合わせたメッセージをサポートし、メッセージ内の 1 つまたは複数のアクションポイントを使用して迅速に処理する必要があるシナリオに適しています。

Markdown テンプレートをベースに、ActionCard テンプレートは全体リダイレクトと個別リダイレクトの両方のスタイルをサポートします。

**ActionCard テンプレートの設定**

| 設定項目 | テンプレートパラメータ対応 | 説明 |
| --- | --- | --- |
| **テンプレート名** | 非対応 | テンプレート名を指定します。テンプレートのユースケースとタイプに基づいて命名します。例：新規チケット通知テンプレート。 |
| **ユースケース** | 非対応 | テンプレートのユースケースを説明します。 |
| **画像** | 非対応 | メッセージ内の画像です。画像リンクまたは media_id 形式をサポートします。この設定項目は個別に設定され、各メッセージは 1 枚の画像のみサポートします。 |
| **メッセージタイトル** | 非対応 | メッセージのタイトルおよびチャットリストと通知に表示されるテキストです。最大 64 文字。 |
| **メッセージコンテンツ** | 対応 | Markdown 形式のメッセージコンテンツです。最大 1,000 文字を推奨します。サポートされる Markdown 構文については、以下の表を参照してください。**重要**     - メッセージテンプレートの Markdown 構文は見出しをサポートしません。つまり、「# +見出しテキスト」の見出し形式はサポートされません。メッセージタイトルは**タイトル**入力ボックスで個別に入力してください。第 1 レベルのタイトルのみサポートされます。 - メッセージテンプレートの Markdown 構文は画像をサポートしません。つまり、「」形式はサポートされません。メッセージ画像は**画像**入力ボックスで個別に入力してください。各メッセージは 1 枚の画像のみサポートします。 |
| **アクションポイント** | 対応 | カードメッセージは、全体リダイレクト ActionCard スタイルと個別リダイレクト ActionCard スタイルの両方をサポートします：   - 全体リダイレクト ActionCard スタイルは、単一のクリックアクションをサポートします。1 つの設定を渡すと全体リダイレクトスタイルになります。 - 個別リダイレクト ActionCard スタイルは、複数のクリックアクションをサポートします。複数の設定を渡すと個別リダイレクトスタイルになります。 |
| **アクションポイントリンク** | 対応 | メッセージをクリックしたときにリダイレクトされるリンクアドレスです。メッセージがミニプログラムとして送信される場合、ミニプログラムのリダイレクトリンクをサポートします。最大 500 文字。 |
| **アクションポイントタイトル** | 対応 | リダイレクトボタンのタイトルです。最大 20 文字。 |

## フォームテンプレート

フォームテンプレートは、OA メッセージタイプに基づいてメッセージを送信します。注文などのメッセージ表示に適しており、メッセージ詳細を表示するためのリダイレクトをサポートします。

**フォームメッセージテンプレートの設定**

| 設定項目 | テンプレートパラメータ対応 | 説明 |
| --- | --- | --- |
| **テンプレート名** | 非対応 | テンプレート名を指定します。テンプレートのユースケースとタイプに基づいて命名します。例：新規チケット通知テンプレート。 |
| **ユースケース** | 非対応 | テンプレートのユースケースを説明します。 |
| **メッセージボックスヘッダーコンテンツ** | 対応 | メッセージのヘッダータイトルです。最大 10 文字。通常のチャットに送信された場合に有効です。組織チャットに送信された場合は、マイクロアプリの名前に置き換えられます。 |
| **メッセージボックスヘッダー背景色** | 対応 | メッセージヘッダーの背景色です。最大 8 文字の英字で、最初の 2 文字は透明度、最後の 6 文字は色の値を示します。0x は追加しないでください。例：FFBBBBBB |
| **メッセージタイトル** | 非対応 | 本文のタイトルです。最大 50 文字を推奨します。 |
| **メッセージコンテンツ** | 対応 | 本文のコンテンツです。最大 3 行まで表示されます。 |
| **本文内の画像** | 非対応 | メッセージ内の画像です。画像リンクまたは media_id 形式をサポートします。この設定項目は個別に設定され、各メッセージは 1 枚の画像のみサポートします。 |
| **フォームコンテンツ** | 対応（タイトルと変数値） | 本文のフォームです。最大 6 項目まで表示されます。左右の入力ボックスは、それぞれ本文のキーワードとそれに対応する値を表します。 |
| **モバイルリンク** | 対応 | メッセージをクリックしたときにリダイレクトされるリンクアドレスです。メッセージがミニプログラムとして送信される場合、ミニプログラムのリダイレクトリンクをサポートします。 |
| **PC リンク** | 対応 | PC でクリックしたときにリダイレクトされるアドレスです。 |

## テンプレートパラメータの設定

メッセージコンテンツ内の一部の値は、注文番号、電話番号、商品名など、動的に変化します。これらの値はテンプレート設定時には確定できないため、テンプレートパラメータを使用して置換できます。

業務通知を送信するときに、実際の値を渡してテンプレートパラメータを置換します。テンプレートパラメータは任意で、必要に応じて設定できます。

**テンプレートパラメータの形式**

テンプレートパラメータは `${parameter name}` の形式を使用します。パラメータは以下の仕様に準拠する必要があります。

- 文字またはアンダースコアで始まる必要があります。
- 残りの部分は、文字、アンダースコア、数字で構成できます。
- 1 つのメッセージに動的パラメータを設定しすぎないでください。5 つ以内を推奨します。

例えば、メッセージコンテンツが以下のとおりだとします：

```text
フォロー中の商品「${product}」が入荷しました。お早めにお買い求めください！
```

ここで、`${product}` はパラメータ名が `product` のテンプレートパラメータです。メッセージ送信時に、このパラメータの値を渡すだけです。例えば、メッセージ送信時に `product` の値として「使い捨てマスク」を渡します。すると「使い捨てマスク」が $&#123;product&#125; テンプレートパラメータを置き換え、ユーザーが最終的に受け取るメッセージコンテンツは以下のようになります：

```text
フォロー中の商品「使い捨てマスク」が入荷しました。お早めにお買い求めください！
```

メッセージテンプレートには、複数のテンプレートパラメータを設定することも、まったく設定しないこともできます。実際のニーズに基づいて設定してください。

**ID 変換**

動的パラメータを渡すときに、ID 変換がサポートされます。現在、部門 ID を部門名に変換すること、および userId をユーザー名に変換することをサポートしています。

ID 変換の構文は以下のとおりです：

```text
$departmentName=DEPARTMENT_ID$
$userName=USERID$
```

ここで：

- DEPARTMENT_ID は数値の部門 ID です。
- USERID はユーザーのユーザー ID です。

例：

- $departmentName=100$ を、部門 ID「100」に対応する部門名（例：「DingTalk Open Platform」）に置き換えます。
- $userName=zhangsan01$ を、ユーザー ID「zhangsan01」に対応するユーザー名（例：「山田太郎」）に置き換えます。

## 審査に提出

メッセージテンプレートを作成した後、**送信**をクリックしてテンプレートを審査に提出します。

## テンプレートの有効化

テンプレートが審査に通過すると、自動的に有効化されます。メッセージテンプレートが有効化されると、API を呼び出してテンプレートメッセージを送信できます。詳細については、[テンプレートを使用した業務通知メッセージの送信](/zh/open/development/work-notification-templating-send-notification-interface)を参照してください。

## テンプレートの無効化

テンプレートが不要になった場合は、有効化トグルをオフにしてテンプレートの使用を停止します。

## テンプレートの削除

**削除**をクリックしてテンプレートを削除します。

## テンプレートの複製

**複製**をクリックすると、同じ設定のテンプレートをコピーできます。

## テンプレートのテスト

**編集**をクリックすると、テンプレート編集画面に入ります。テンプレート編集ページの**テスト**ボタンをクリックすると、テストを実行できます。テストでは、業務通知を自分自身に送信します。
