## はじめに

[クラウド開発プラットフォーム](https://workbench.aliyun.com/page/quickstart)は、Alibaba Cloudが開発者向けに提供するクラウドベースの研究開発ワークスペースです。クラウド開発プラットフォームを使えば、DingTalkミニプログラムやH5マイクロアプリをオンラインで素早く開発・デプロイできます。ブラウザベースの **CloudIDE** には、Node.js、Java、PHP、Pythonといった一般的な言語の実行環境が標準搭載されており、複雑な設定作業が不要です。ビジネスロジックの開発だけに集中でき、ブラウザを開くだけで **ゼロコスト** で開発を始められます。さらに、従来型サーバーの購入やデプロイも必要ありません。Alibaba CloudのServerless製品ラインが提供するサービスにより、真にメンテナンス不要な運用とコール数課金を実現し、デプロイおよび運用コストを大幅に削減します。

クラウド開発プラットフォームは、2つのDingTalkアプリテンプレートを提供しています。これら2つのアプリテンプレートを使えば、DingTalkアプリを素早く作成し、試すことができます。

- [DingTalk会議室予約](https://developers.dingtalk.com/document/tutorial/quickly-build-h5-microapplications-meeting-room-reservation)
- [DingTalk抽選ミニプログラム](https://developers.dingtalk.com/document/tutorial/dingtalk-lottery-applet)

### 前提条件

アプリテンプレートを使ってDingTalkアプリを開発する前に、以下の前提条件を満たしてください。

- DingTalk開発者アカウントを登録・有効化し、サブ管理者および開発者の権限を保有していること。まだの場合は、[DingTalk開発者になる](https://developers.dingtalk.com/document/app/become-a-dingtalk-developer#topic-2024337)を参照してください。
- Alibaba Cloudアカウントを保有し、実名認証を完了していること。まだの場合は、[Alibaba Cloudアカウントの新規登録](https://account.aliyun.com/register/register.htm)を参照してください。

## DingTalkアプリの作成

このセクションでは、Developer ConsoleでH5マイクロアプリを作成します。

1. [DingTalk Developer Console](https://open-dev.dingtalk.com/)にログインします。

   **注意**

   Developer Consoleにログインできるのは、管理者とサブ管理者のみです。
2. **Developer Console** ページで **内部アプリ開発** を選択し、**アプリを作成** をクリックします。
3. 表示される「アプリを作成」ページで、作成したいアプリのタイプを選択し、基本情報を入力し、開発方法として「組織による自己開発」を選択します。次に「確認」をクリックしてアプリを作成します。
4. アプリの作成後、**基本情報** ページで、アプリの **AgentId**、**AppKey**、**AppSecret** をコピーして後で使用できるようにします。

## クラウドアプリの作成

このセクションでは、クラウド開発プラットフォームを使ってバックエンドのクラウドアプリを作成します。

1. Alibaba Cloudアカウントで[クラウド開発プラットフォーム](https://workbench.aliyun.com/page/quickstart)にログインします。
2. 以下の情報に基づいてチームを作成します。

   組織名またはチーム名を入力し、**作成を完了** をクリックします。
3. **アプリ管理** ページで、右上の **アプリを作成** をクリックします。
4. 以下の手順でアプリの作成を完了します。

   1. 「アプリを作成」ページで、**権限付与を承認** をクリックしてクラウドリソースへのアクセス権限付与を完了し、**次へ** をクリックします。
   2. 以下の情報に基づいてアプリの作成方法を設定し、**次へ** をクリックします。

      - 開発言語：開発言語を選択して、まったく新しいアプリを作成できます。現在、Java、NodeJS、Python、PHPがサポートされています。
      - 作成方法：クラウド開発プラットフォームでは、現在2つの作成方法を提供しています。

        - 直接作成
        - テンプレートから作成
      - テンプレートソース：クラウド開発プラットフォームは、多数のアプリテンプレートを提供しています。アプリテンプレートを選択すれば、テンプレートコードをすでに含んだアプリを作成できます。その中でも「**DingTalk会議室予約**」と「**DingTalk抽選ミニプログラム**」は、DingTalkアプリ専用に設計された2つのテンプレートです。テンプレートからアプリを作成すると、開発作業量を大幅に削減できます。
   3. アプリの基本情報を入力し、**次へ** をクリックします。

      クラウド開発プラットフォームは、3つのコンピュートサービスを提供しています。

      - **Function Compute (FC)**：関数ベースのServerlessで、コール数課金に対応し、ゼロコストでプロジェクトを開始できます。エラスティックインスタンスには一定の無料クォータが提供されます。
      - **SAEコンピュートサービス**：アプリケーション指向のServerlessコンピュートサービスで、アプリケーション層で完全なPaaSエコシステム機能を提供します。従量課金と低コストなマイクロサービスのクラウド移行により、Serverlessアーキテクチャとマイクロサービスアーキテクチャを完璧に組み合わせます。
      - **ASKコンピュートサービス**：コンテナ指向のServerlessコンピュートサービスで、クラスタノードのメンテナンスやキャパシティプランニングが不要で、設定済みのコンテナ仕様に基づいてオンデマンドで課金されます。ASKクラスタは包括的なKubernetes互換性を提供しつつ、Kubernetesの利用ハードルを下げるため、基盤インフラの管理ではなくアプリケーションに集中できます。
   4. **完了** をクリックしてアプリの作成を終了します。

      **注意**

      依存するクラウドサービスがまだ有効化されていない場合は、それぞれの **今すぐ有効化** をクリックして、これらのクラウドサービスを有効化してください。

## クラウドアプリの開発

アプリの作成後、開発を開始できます。

1. 右上の **オンライン開発とデプロイ** をクリックして、CloudIDEを開きます。

   **注意**

   CloudIDEが開くまで約3分かかります。しばらくお待ちください。
2. CloudIDEが起動すると、アプリのコードが自動的にロードされます。初期状態では、ロードされるコードは、アプリ作成時に選択したアプリテンプレートが提供するデフォルトのコードファイルです。これでアプリの開発作業を開始できます。

## クラウドアプリの設定

クラウド開発プラットフォームは、**テスト環境（TEST）**、**ステージング環境（PRE）**、**本番環境（RELEASE）** という一貫した3つのServerless環境を提供し、各環境をそれぞれ設定できます。「**アプリ管理**」→「**アプリ詳細**」→「**開発とデプロイ**」タブで、対応する環境を選択して **アプリ設定** を行えます。

1. **開発とデプロイ** ページで **環境** を選択し、操作列の **デプロイ設定** をクリックして、現在のアプリのデプロイ設定を確認します。

   クラウド開発プラットフォームが提供するデフォルト設定を使用することも、開発ニーズに応じてカスタムのデプロイ環境設定を選択することもできます。
2. **開発とデプロイ** ページで **環境** を選択し、操作列の **アプリ設定** をクリックします。

   **編集** をクリックすると、複数の `KEY=VALUE` ペアを一度に貼り付けまたは入力できます。一般的なアプリ設定の取得方法については、[クラウド開発ドキュメント](https://help.aliyun.com/document_detail/177083.html?#h1-u5E38u89C1u7684u5E94u7528u914Du7F6Eu83B7u53D6u529Eu6CD53)を参照してください。

   一般的なDingTalkアプリのパラメータの取得方法については、[DingTalkオープンプラットフォームの基本概念](https://developers.dingtalk.com/document/app/basic-concepts/title-wxx-amg-62k#title-wxx-amg-62k)を参照してください。

   **注意**

   データベース、ファイルストレージ、汎用ミドルウェアサービスは、アプリの必要に応じて有効化・設定し、ビジネスコードにアクセスサービスを提供するためにプロジェクトに組み込む必要があります。クラウド開発プラットフォームはこれらのサービス設定を利用しません。

## クラウドアプリのデプロイ

1. アプリ設定が完了したら、**オンライン開発とデプロイ** をクリックして **CloudIDE** を開きます。
2. **デプロイ** をクリックし、デプロイする環境を選択して、**デプロイ** をクリックします。

   **注意**

   デプロイプロセス全体は約5分かかります。しばらくお待ちください。

   テスト環境とステージング環境のデプロイが完了すると、クラウド開発プラットフォームはテスト用の無料一時ドメインを割り当てます。
3. カスタムドメインをバインドします。

   独自のドメインをバインドする必要がある場合は、以下の手順を参照してください。

   1. デプロイが成功したら、**アプリ詳細** ページ ＞ **開発とデプロイ** に戻り、対応する環境の後ろにある **ドメイン設定** をクリックします。アプリにバインドされているドメインを確認できます。**API Gatewayドメイン**、つまり **CNAMEアドレス** をコピーします。
   2. [Alibaba Cloud DNSコンソール](https://dns.console.aliyun.com/?spm=a2c4g.11186623.2.12.3b9859cbIuhfCy#/dns/domainList)にログインします。**ドメイン解決** ページで、**ドメイン** をクリックして **解決設定** ページに入ります。
   3. 「レコードを追加」をクリックし、以下の情報に基づいてレコードを追加します。

      - **レコードタイプ**：CNAMEを選択します。
      - **ホストレコード**：作成したいドメインを入力します。
      - **解決ライン**：解決ラインを選択します。
      - **レコード値**：先ほどコピーした **API Gatewayドメインアドレス** を貼り付けます。
      - **TTL**：デフォルト値のままにするか、適切と思われる値を設定します。
   4. ドメインの設定後、**クラウド開発プラットフォーム** に戻ります。**アプリ詳細** ページ ＞ **開発とデプロイ** で、対応する環境を選択し、**ドメイン設定** をクリックして、作成したドメインを設定します。
   5. CloudIDEに入り、**WB** とラベル付けされたデプロイテストプラグインを開き、対応する環境を選択して **デプロイ** をクリックします。

      デプロイが成功すると、右側の **出力** パネルにデプロイ成功メッセージが表示されます。ハイライトされた領域で、先ほどバインドしたドメインが正常にバインドされたものの、CNAMEがまだ有効になっていないことを確認できます。

      お使いのコンピュータでターミナルを開き、先ほどバインドしたドメインを入力します。以下のようなメッセージが表示されれば、CNAMEが有効になっています。

      **注意**

      有効になるまでの時間は、先ほどドメイン解決を作成したときに設定したTTL値によって異なります。しばらくお待ちください。

## DingTalkアプリの設定とリリース

1. ミニプログラムの設定。

   1. ミニプログラムIDEツールを開き、appconfig.jsファイルを開いて、アプリのドメインを、アプリのデプロイ時にクラウド開発プラットフォームが提供した一時ドメイン、またはバインドしたカスタムドメインに変更します。
   2. [Developer Console](https://open-dev.dingtalk.com/#/index)にログインし、**アプリ詳細** ページで **セキュリティセンター** をクリックして、**HTTPセキュリティドメインを追加** します。HTTPセキュリティドメインを、アプリのデプロイ時にクラウド開発プラットフォームが提供した **一時ドメイン**、またはバインドした **カスタムドメイン** に設定します。
2. H5マイクロアプリの設定。

   1. [DingTalk Developer Console](https://open-dev.dingtalk.com/#/corph5)にログインし、作成したH5マイクロアプリをクリックします。アプリ詳細ページで **開発管理** をクリックし、以下の情報を設定します。

      - サーバー送信元IP：255.255.255.255を入力します。
      - アプリホームページURL：アプリのデプロイ後に生成された一時ドメインアドレス、またはバインドしたカスタムドメインアドレスを入力します。
3. アプリをリリースするには、[バージョン管理とリリース](https://developers.dingtalk.com/document/app/publish-orgapp)を参照してください。
