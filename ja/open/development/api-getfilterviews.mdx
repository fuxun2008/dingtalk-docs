---
title: "絞り込みビューの一覧取得"
---

本 API を呼び出すことで、指定したワークシート上のすべての絞り込みビューの一覧を取得できます。各絞り込みビューの ID、名前、範囲、フィルター条件が返されます。絞り込みビューを管理または切り替える前に既存のビューを列挙する場合や、プログラム内で絞り込みビュー設定を一括して読み取り後続処理を行う場合に適しています。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | `https://api.dingtalk.io/v1.0/doc/workbooks/{workbookId}/sheets/{sheetId}/filterViews` |
| HTTP Method | GET |
| サポートされるアプリタイプ | appType-社内アプリ |
| 必要な権限 | permission-Document.Workbook.Read-スプレッドシート読み取り権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | はい | この API を呼び出す際のアクセス認証情報です。[社内アプリのアクセストークン取得](/ja/open/development/obtain-the-access-token-of-an-internal-app) API を呼び出して取得できます。 |

### パスパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| workbookId | String | はい | スプレッドシートファイル ID です。[ナレッジベース API](https://open.dingtalk.io/document/orgapp/knowledge-base-overview) が返す `nodeId(dentryUuid)` がスプレッドシートの `workbookId` です。[ノード取得](https://open.dingtalk.io/document/orgapp/get-node) および [ナレッジベースドキュメント作成](https://open.dingtalk.io/document/orgapp/create-team-space-document) API を呼び出して取得できます。 |
| sheetId | String | はい | ワークシート ID または名前です。[全ワークシート取得](https://open.dingtalk.io/document/orgapp/obtain-all-worksheets) API を呼び出して id または name パラメータの値を取得できます。  **説明**  ワークシート上に絞り込みビューが存在しない場合、API は空の配列を返します。 |

### クエリパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| operatorId | String | はい | 操作者の unionId です。   - [サイレントログインコードによるユーザー情報取得](https://open.dingtalk.io/document/orgapp/obtain-the-userid-of-a-user-by-using-the-log-free) API を呼び出して unionid パラメータの値を取得できます。 - [ユーザー詳細クエリ](https://open.dingtalk.io/document/orgapp/query-user-details) API を呼び出して unionid パラメータの値を取得できます。       操作者に権限がない場合、API は `The operator has no permission` というエラーを返します。 |

## レスポンス

### レスポンスボディ

| 名前 | タイプ | 説明 |
| --- | --- | --- |
| filterViews | Array | 絞り込みビューのリスト。絞り込みビューが存在しない場合は空の配列となります。 |
| id | String | 絞り込みビューの一意識別 ID。 |
| name | String | 絞り込みビューの名前。 |
| range | String | 絞り込みビューの範囲（A1 表記）。 |
| criteria | `Map<String, Object>` | 各列のフィルターです。key は列のオフセット（range の先頭列を基準とし、0 から開始）、value はフィルター条件オブジェクトです。フィルター条件がない場合は空オブジェクト `{}` となります。 |
|  | Object | フィルター条件 |
| filterType | String | 絞り込みタイプ。設定可能な値：`values`（値で絞り込み）、`condition`（条件で絞り込み）、`color`（色で絞り込み）。 |
| visibleValues | Array of String | 表示する値 |
| conditions | Array | 条件で絞り込む場合の、絞り込み条件のリスト。`filterType` が `condition` の場合に有効です。各条件オブジェクトには `operator`（演算子）と `value`（条件値）フィールドが含まれます。 |
| operator | String | 条件演算子。設定値：   - **equal**：等しい - **not-equal**：等しくない - **contains**：含む - **not-contains**：含まない - **starts-with**：で始まる - **not-starts-with**：で始まらない - **ends-with**：で終わる - **not-ends-with**：で終わらない - **greater**：より大きい - **greater-equal**：以上 - **less**：より小さい - **less-equal**：以下 |
| value | String | 条件値 |
| conditionOperator | String | 複数条件間の論理関係。設定可能な値：`and`（かつ）、`or`（または）。デフォルトは `and`。`filterType` が `condition` で複数条件がある場合に有効です。 |
| backgroundColor | String | 背景色で絞り込む場合、色値（16 進数、例：`#FF0000`）を指定します。`filterType` が `color` の場合に有効で、`fontColor` といずれかを選択します。 |
| fontColor | String | フォント色で絞り込む場合、色値（16 進数、例：`#FF0000`）を指定します。`filterType` が `color` の場合に有効で、`backgroundColor` といずれかを選択します。 |
