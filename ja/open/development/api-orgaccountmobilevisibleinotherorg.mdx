---
title: "他組織への自組織の企業アカウント情報の閲覧権限付与"
---

自組織の企業アカウントが他組織に参加した後、他組織で当該企業アカウント情報の特定フィールドを閲覧できるよう権限を付与します。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/v1.0/contact/orgAccounts/mobiles/visibleInOtherOrg |
| HTTP Method | PUT |
| サポートされるアプリタイプ | appType-社内アプリ |
| 必要な権限 | permission-Contact.OrgAccount.VisiblityInOtherOrg-企業アカウントが他組織に参加後のデータ可視性権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | はい | 当該 API を呼び出すためのアクセス認証情報。[社内アプリの accessToken を取得](/ja/open/development/obtain-the-access-token-of-an-internal-app#) API を呼び出して取得します。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| toCorpIds | Array of String | はい | 権限付与対象組織の corpId リスト。権限付与対象組織の corpId リスト、および API 呼び出し者に対応する userId は、いずれも空にできません。パラメータエラーの場合は呼び出しエラーとなります。 |
| optUserId | String | はい | 現在 API を呼び出している呼び出し者に対応する userId。データ監査用のため、現在の組織内に実在する社員の userId を指定する必要があります。指定しない場合、API 呼び出しは失敗します。 |
| fields | Array of String | いいえ | 権限付与フィールド：fields が空または空集合の場合、mobile のみに権限付与されます（旧バージョン互換）。  - **mobile**：企業アカウントの携帯電話番号。 - **status**：企業アカウントの停止ステータス。 |
