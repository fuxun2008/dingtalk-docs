本インターフェースを呼び出して、AIテーブル内の 1 行のレコードを取得します。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | `https://api.dingtalk.io/v1.0/notable/bases/{baseId}/sheets/{sheetIdOrName}/records/{recordId}` |
| HTTP Method | GET |
| 対応アプリタイプ | appType-社内アプリ |
| 権限要件 | permission-Notable.Base.Read.All-AIテーブルアプリ読み取り権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | はい | 本インターフェース呼び出し時のアクセス認証情報。[社内アプリの access_token を取得する](/ja/open/development/obtain-the-access-token-of-an-internal-app#)インターフェースを呼び出して取得します。 |

### パスパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| baseId | String | はい | AIテーブルの ID。取得方法は [データ構造](/ja/open/development/data-structure#) をご参照ください。 |
| sheetIdOrName | String | はい | データテーブルの ID またはデータテーブル名。データテーブルの ID は次の 2 つの方法で取得できます。   - [すべてのデータテーブルを取得](/ja/open/development/api-notable-getallsheets#)インターフェースを呼び出して取得します。 - [データテーブルを取得](/ja/open/development/api-notable-getsheet#)インターフェースを呼び出して取得します。 |
| recordId | String | はい | レコード ID。次の 2 つの方法で取得できます。   - [レコードの新規追加](/ja/open/development/api-notable-insertrecords#)インターフェースを呼び出して取得します。 - [複数行レコードの一覧取得](/ja/open/development/api-notable-listrecords#)インターフェースを呼び出して取得します。 |

### クエリパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| operatorId | String | はい | 操作者の unionId。次の 2 つの方法で取得できます。   - [ユーザー詳細を照会](/ja/open/development/query-user-details#)インターフェースを呼び出して取得します。 - [サイレントログインコードでユーザー情報を取得](/ja/open/development/obtain-the-userid-of-a-user-by-using-the-log-free#)インターフェースを呼び出して取得します。 |
