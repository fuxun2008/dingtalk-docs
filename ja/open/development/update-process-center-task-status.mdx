この API を呼び出して、プロセスセンター内の指定したタスクのステータスを更新します。

## リクエスト

### ベーシック情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/v1.0/workflow/processCentres/tasks |
| HTTP メソッド | PUT |
| 対応アプリタイプ | appType-社内アプリ　appType-サードパーティ社内アプリ |
| 権限 | permission-qyapi_aflow-承認作業フローデータ管理権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | はい | この API を呼び出すためのアクセス認証情報です。次の方法で取得します。   - 社内アプリ：[社内アプリのアクセストークンを取得](/ja/open/development/obtain-the-access-token-of-an-internal-app) API を呼び出します。 - サードパーティ社内アプリ：サードパーティアプリを認可した組織のアクセストークンを取得する API を呼び出します。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| processInstanceId | String | いいえ | OA承認のワークフローインスタンス ID です。[インスタンスを作成](/ja/open/development/create-a-ticket-approval-instance) API を呼び出して `processInstanceId` の値を取得します。 |
| tasks | Array | はい | OA承認タスクのリストです。最大 20 件まで指定できます。 |
| taskId | Long | はい | OA承認タスクの ID です。[プロセスセンター経由で連携したOA承認タスクを照会](/ja/open/development/query-oa-approval-tasks-integrated-through-process-center) API を呼び出して taskId の値を取得します。 |
| status | String | はい | 変更後のタスクステータスです。   - **CANCELED**：元に戻す - **COMPLETED**：完了 |
| result | String | いいえ | タスクの結果です。   - status が **COMPLETED** の場合は、タスクの結果を指定します。    - **AGREE**：承認   - **REFUSE**：却下 - status が **CANCELED** の場合は、result を渡さないでください。 |

    "result" : "AGREE"
  } ]
}
