---
title: "管理者のアプリ管理権限を取得"
---

本 API を呼び出して、管理者のアプリ管理権限を取得します。

## API 呼び出し説明

本 API を呼び出す前に、以下を確認してください。

- アプリはプロダクトソリューションプロバイダーによって開発されたものである必要があります。[**DingTalk 開発者管理画面**](https://open-dev.dingtalk.io/#/appMgr/provider/eapp/53642/1) **> サードパーティ社内アプリ**のアプリ詳細ページで AppId を取得できます。
- 本 API を呼び出す前に、[管理者リストを取得](/zh/open/development/query-the-administrator-list) API を呼び出して、現在の企業の管理者 ID を取得できます。

## リクエスト

| **基本情報** | |
| --- | --- |
| HTTP URL | https://oapi.dingtalk.io/user/can_access_microapp |
| HTTP Method | GET |
| サポートされるアプリタイプ | appType-サードパーティ社内アプリ |
| 権限要件 | permission-qyapi_get_member-ユーザー情報読み取り権限 |

### クエリパラメータ

| 名前 | タイプ | 必須 | 例 | 説明 |
| --- | --- | --- | --- | --- |
| access_token | String | はい | 6d1bxxxx | 本 API を呼び出すためのアプリ認証情報。サードパーティ企業の access_token を取得する API から取得します。 |
| appId | Number | はい | 2000121xxxx | アプリ ID。[**DingTalk 開発者管理画面**](https://open-dev.dingtalk.io/#/appMgr/provider/eapp/53642/1) **> サードパーティ社内アプリ**のアプリ詳細ページで AppID を取得できます。 |
| userId | String | はい | 2000121xxxx | 検索対象の管理者社員 ID。[管理者リストを取得](/zh/open/development/query-the-administrator-list) API を呼び出して userid パラメータ値を取得できます。 |

### リクエスト例

```curl
curl -X GET "https://oapi.dingtalk.io/user/can_access_microapp" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=c54ee841-199a-459e-8146-3d08c1830a10' \
-d 'appId=1' \
-d 'userId=1'
```

Java

```text
DingTalkClient client = new DefaultDingTalkClient("https://oapi.dingtalk.io/user/can_access_microapp");
OapiUserCanAccessMicroappRequest req = new OapiUserCanAccessMicroappRequest();
req.setAppId(1L);
req.setUserId("1");
req.setHttpMethod("GET");
OapiUserCanAccessMicroappResponse rsp = client.execute(req, access_token);
System.out.println(rsp.getBody());
```

## レスポンス

### レスポンスボディ

| 名前 | タイプ | 例 | 説明 |
| --- | --- | --- | --- |
| request_id | String | 4f9md9obopn2 | リクエスト ID。 |
| errcode | Number | 0 | 戻りコード。 |
| errmsg | String | システムエラー | 戻りコードの説明。 |
| canAccess | Boolean | true | 管理権限の有無：   - **true**：管理権限あり - **false**：管理権限なし |

### レスポンスボディ例

```json
{
  "errcode":0,
  "canAccess":"true",
  "request_id":"4f9md9obopn2"
}
```

### エラーコード

本 API の呼び出しでエラーが発生した場合は、エラーメッセージをもとに[グローバルエラーコード](/zh/open/development/server-api-error-codes-1)ドキュメントで解決方法を検索してください。
