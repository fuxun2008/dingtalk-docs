この API を呼び出して、現在の組織内でユーザーが管理できるすべての承認フォームを取得します。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/v1.0/workflow/processes/managements/templates |
| HTTP メソッド | GET |
| 対応アプリタイプ | appType-社内アプリ |
| 権限 | permission-Workflow.Form.Read-作業フローテンプレートの読み取り権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | はい | この API を呼び出すためのアクセス認証情報です。[社内アプリのアクセストークンを取得](/ja/open/development/obtain-the-access-token-of-an-internal-app) API を呼び出して取得してください。 |

### クエリパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| userId | String | はい | ユーザーの userId です。 **注意** userId に対応するユーザーは、組織内でOA承認の権限を持っている必要があります。 |

### リクエスト例

HTTP

```http
GET /v1.0/workflow/processes/managements/templates?userId=manager7078 HTTP/1.1
Host:api.dingtalk.io
x-acs-dingtalk-access-token:6d1bxxxx
Content-Type:application/json
```

## レスポンス

### レスポンスボディ

| 名前 | タイプ | 説明 |
| --- | --- | --- |
| result | Array | テンプレートの一覧です。 |
| iconName | String | テンプレートのアイコン名です。 |
| flowTitle | String | テンプレートの名前です。 |
| processCode | String | テンプレートのコードです。 |
| newProcess | Boolean | 新しいテンプレートかどうかを示します。   - **true**：はい - **false**：いいえ |
| gmtModified | String | 編集時間です。 |
| attendanceType | Integer | 関連付けられた勤怠タイプです。有効な値：   - **0**：なし - **1**：打刻修正申請 - **2**：休暇申請 |
| iconUrl | String | アイコンの URL です。 |
| success | Boolean | API の呼び出しが成功したかどうかを示します。   - **true**：成功 - **false**：失敗 |
