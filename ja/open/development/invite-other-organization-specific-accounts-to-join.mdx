---
title: "他組織の企業アカウントを招待して参加させる"
description: "他組織の企業アカウントを自組織に参加させ、複数組織での連携協業を実現します"
---

本 API を呼び出して、他組織の企業アカウントを自組織に参加させます。

## API 呼び出し説明

他組織の企業アカウントを自組織に参加させる機能は、購入して有効化した組織のみ利用可能です。

本 API を呼び出して他組織の企業アカウントを自組織に参加させる際は、以下の点にご注意ください。

1. 本 API は、他企業の非企業アカウントの参加には対応していません。
2. 他企業側で API【[企業アカウントの複数組織参加を許可する](/ja/open/development/authorize-a-dedicated-account-to-join-multiple-organizations)】を呼び出し、他企業の企業アカウントが自組織に参加することを許可する必要があります。権限付与が完了すると、他企業が自企業に対し、他企業の企業アカウントを自企業へ参加させることを許可したことを意味します。
3. 本 API の呼び出しに成功すると、他企業の企業アカウントは直接自組織に参加します。他企業の企業アカウント側での承認は不要です（上記 2 の権限付与が完了した時点で、他企業が承認済みとみなされ、アカウント単位での再度の承認は不要です）。

## リクエスト

| **基本情報** | |
| --- | --- |
| HTTP URL | https://oapi.dingtalk.io/topapi/v2/user/create |
| HTTP Method | POST |
| 対応するアプリタイプ | appType-社内アプリ |
| 権限要件 | permission-qyapi_manage_addresslist-連絡先データ管理権限 |

### クエリパラメータ

| 名前 | タイプ | 必須 | 例 | 説明 |
| --- | --- | --- | --- | --- |
| access_token | String | 必須 | BE3xxxx | 本 API を呼び出すアプリ認証情報。[社内アプリの access_token 取得](/ja/open/development/obtain-orgapp-token) API から取得します。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 例 | 説明 |
| --- | --- | --- | --- | --- |
| userid | String | 任意 | zhangsan | 社員の一意の識別 ID（変更不可）。長さは 1〜64 文字。  **説明**   - 社内で一意である必要があります。 - 指定しない場合は、userid が自動生成されます。 |
| outer_exclusive_corpid | String | 必須 | ding12345 | 追加する企業アカウントが所属する corpId。 |
| outer_exclusive_userid | String | 必須 | user01 | 追加する企業アカウントが所属する userId。 |
| name | String | 必須 | 山田太郎 | 社員名。最大 80 文字。 |
| dept_id_list | String | 必須 | "2,3,4" | 所属部門 ID リスト。複数の部門 ID は `半角カンマ ,` で区切ります。1 回の呼び出しで最大 100 個の部門 ID を指定できます。 |
| telephone | String | 任意 | 010-86123456-2345 | 内線番号。最大 50 文字。  **説明**  内線番号は一意であり、社内で重複できません。 |
| job_number | String | 任意 | 4 | 社員番号。最大 50 文字。 |
| title | String | 任意 | 技術ディレクター | 職位。最大 200 文字。 |
| email | String | 任意 | test@xxx.com | 社員の個人メール。最大 50 文字。  **説明**  社員のメールは一意であり、社内で重複できません。 |
| org_email | String | 任意 | test@xxx.com | 社員のエンタープライズメール。最大 100 文字。  **説明**  本フィールドが有効になるのは、社員がエンタープライズメールを有効化している場合のみです。 |
| org_email_type | String | 任意 | profession | 社員のエンタープライズメールタイプ。   - **profession:** 標準版。 - **base：** ベーシック版。 |
| work_place | String | 任意 | みらいパーク | 勤務地。最大 100 文字。 |
| remark | String | 任意 | 備考情報 | 表示名。最大 2000 文字。 |
| dept_order_list | Object[] | 任意 |  | 対応する部門における社員の並び替え。 |
| dept_id | Number | 任意 | 2 | 部門 ID。 |
| order | Number | 任意 | 1 | 部門内での社員の並び替え。数値が大きいほど上位に表示されます。 |
| dept_title_list | Object[] | 任意 |  | 対応する部門における社員の職位。 |
| dept_id | Number | 任意 | 2 | 部門 ID。 |
| title | String | 任意 | シニアプロダクトマネージャー | 部門内での社員の職位。 |
| extension | String | 任意 | `{"趣味":"旅行","年齢":"24"}` | 拡張属性。複数の属性を設定可能で、最大 2000 文字。**説明**   - モバイル上では最大 10 個の拡張属性まで表示できます。 - 本パラメータを使用する前に、[DingTalk 管理者画面](https://oa.dingtalk.io/index_new.htm#/setting/contactInfo) で当該属性を追加してから API を呼び出して値を設定してください。 - 本フィールドの値にはリンクタイプの指定が可能で、リンク内では変数ワイルドカードによる自動置換に対応しています。現在対応しているワイルドカードは userid、corpid です。例：`{"趣味":"[趣味](http://www.dingtalk.io?userid=#userid#&corpid=#corpid#)"}`。 |
| senior_mode | Boolean | 任意 | false | 役員モードを有効にするかどうか。デフォルトは false。   - **true**：オン。  **説明**    - 有効にすると、携帯電話番号がすべての社員に対して非表示になります。   - 一般社員から DING の送信や DingTalk ビジネス通話の発信ができなくなります。   - 役員同士では DING の送信や DingTalk ビジネス通話の発信が可能です。 - **false**：オフ。 |
| hired_date | Number | 任意 | 1597573616828 | 入社日時。Unix タイムスタンプ、単位はミリ秒。 |
| manager_userid | String | 任意 | 001 | 直属上司の userId。 |

### リクエスト例

```curl
curl -X POST "https://oapi.dingtalk.io/topapi/v2/user/create" \
  -H 'Content-Type: application/x-www-form-urlencoded;charset=utf-8' \
  -d 'access_token=YOUR_ACCESS_TOKEN' \
  -d 'outer_exclusive_corpid=ding12345' \
  -d 'outer_exclusive_userid=user01' \
  -d 'name=山田太郎' \
  -d 'dept_id_list=2,3,4' \
  -d 'userid=zhangsan' \
  -d 'telephone=010-86123456-2345' \
  -d 'job_number=4' \
  -d 'title=技術ディレクター' \
  -d 'email=test@xxx.com' \
  -d 'work_place=みらいパーク' \
  -d 'remark=備考情報'
```

## レスポンス

### レスポンスボディ

| 名前 | タイプ | 例 | 説明 |
| --- | --- | --- | --- |
| errcode | Number | 0 | エラーコード。0 は成功を表します。 |
| errmsg | String | ok | エラーメッセージ。 |
| result | Object |  | 戻り結果。 |
| userid | String | zhangsan | 社員の userId。 |
| unionId | String | xxxx | 社員の unionId。 |

### レスポンスボディの例

```json
{
  "errcode":"0",
  "result":{
    "unionId":"xxxx",
    "userid":"zhangsan"
  },
  "errmsg":"ok"
}
```

### エラーコード

本 API の呼び出し時にエラーが発生した場合は、エラーメッセージをもとに [グローバルエラーコード](/ja/open/development/server-api-error-codes-1) ドキュメントから解決策をご確認ください。
