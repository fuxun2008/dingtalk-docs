本記事では、ストレージとは何か、ストレージ API の機能、およびリソースなどについて説明します。

## ストレージとは

ストレージ API はスマートかつ安全な企業データ管理ソリューションを提供し、ファイルストレージを中心とするオフィスシーンでのコラボレーションニーズに対応します。主な機能には、ファイルのアップロード・ダウンロード・管理・流通、主要なファイルのオンラインプレビューと編集機能、権限管理などが含まれますが、これらに限定されません。ストレージ API を利用することで、シンプルなアプリの添付ファイル機能から複雑なクラウドドライブ製品まで、幅広い機能を実現できます。

ストレージ API をアプリに組み込むことで、次のようなことが実現できます。

- DingTalk のほかのアプリにあるファイルと効率的に連携できます。
- 組織管理者によるファイル管理のニーズに対応できます。詳しくは [DingTalk 管理者バックエンド](https://oa.dingtalk.io/dingtalk-enterprise-storage.htm#/) をご参照ください。

## リソース説明

- **スペース**リソースには主に次の属性が含まれます。

  | 属性 | タイプ | 説明 |
  | --- | --- | --- |
  | spaceId | string | スペース Id。 |
  | spaceName | string | スペース名。 |
  | spaceType | string | スペースタイプ。  - **USER**：ユーザースペース - **APP**：アプリスペース |
  | quota | int64 | スペース総容量。  **説明**  -1 は容量無制限を表します。企業属性がある場合、企業のスペース容量を超えることはできません。 |
  | usedQuota | int64 | 使用済み容量。 |
  | createTime | string (iso8601) | 作成時間。 |
  | modifyTime | string (iso8601) | 編集時間。 |
- **ファイルとフォルダー**リソースには主に次の属性が含まれます。

  | 属性 | タイプ | タイプ |
  | --- | --- | --- |
  | id | string | ファイルまたはフォルダーの id。 |
  | spaceId | string | スペース Id。 |
  | path | string | ファイルまたはフォルダーのスペース内のパス。 |
  | status | string | ステータス。  - **NORMAL**：正常 - **DELETED**：ゴミ箱 - **EXPIRED**：期限切れ |
  | partitionType | string | ストレージパーティション。  - **PUBLIC_OSS_PARTITION**：パブリッククラウド OSS ストレージパーティション - **MINI_OSS_PARTITION**：専用 MiniOSS ストレージパーティション |
  | parentId | string | ファイル目次 Id。 |
  | fileType | string | ファイルタイプ。  - **FILE**：ファイル - **FOLDER**：フォルダー |
  | extension | string | ファイル拡張子。 |
- **権限**には主に次の属性が含まれます。

  | 属性 | タイプ | 説明 |
  | --- | --- | --- |
  | id | string | 権限ユーザー id。  - type パラメータの値が **ORG** の場合、このパラメータには企業の **corpId** を指定します。 - type パラメータの値が **DEPT** の場合、このパラメータには部門の **deptId** を指定します。[部門リストを取得する](/ja/open/development/user-management-acquires-the-list-departments) インターフェースを呼び出して dept_id パラメータの値を取得します。 - type パラメータの値が **TAG** の場合、このパラメータには **tag 名** を指定します。 - type パラメータの値が **CONVERSATION** の場合、このパラメータにはチャットの **openConversationId** を指定します。グループチャット作成インターフェースまたはシーングループ作成インターフェースから取得します。 - type パラメータの値が **USER** の場合、このパラメータにはユーザーの **unionId** を指定します。[ユーザー詳細を照会する](/ja/open/development/query-user-details) インターフェースを呼び出して unionid パラメータの値を取得できます。 |
  | roleId | string | 権限ロール Id。  - **OWNER**：所有者 - **MANAGER**：管理者 - **EDITOR**：編集者 - **DOWNLOADER**：ダウンロード者 - **READER**：閲覧者 |
  | type | string | 権限ユーザータイプ：  - **ORG**：企業 - **DEPT**：部門 - **TAG**：カスタム tag - **CONVERSATION**：チャット - **USER**：ユーザー |
  | duration | string | 権限付与の有効期間。単位は秒で、デフォルトは -1（永久有効）です。  - 権限を付与するスペースタイプが APP の場合、有効期間は有効になります。 - 権限を付与するスペースタイプが USER の場合、有効期間は無効で、デフォルトで永久有効となります。 |
