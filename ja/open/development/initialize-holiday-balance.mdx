この API を呼び出して、社員の複数の通常休暇の休暇残数を初期化します。

## API 呼び出し説明

代休の休暇タイプは、この API で初期化する必要はありません。残業時間は自動的に代休の休暇時間に換算されます。休暇ルールは、API の呼び出しまたは DingTalk 公式の勤怠アプリのいずれかの方法で作成します。

| 休暇ルールの作成方法 | 本 API による休暇タイプの更新可否 |
| --- | --- |
| [休暇ルールの追加](/ja/open/development/add-holiday-rules) API を呼び出して作成した休暇タイプ。 | 対応 |
| 管理コンソールの勤怠アプリで作成した休暇タイプ。   - 勤怠アプリのシステムによりデフォルトで作成されたもの。 - 勤怠アプリの管理画面から作成したもの。 | 非対応 |

## リクエスト

| **基本情報** | |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/topapi/attendance/vacation/quota/init |
| HTTP メソッド | POST |
| 対応アプリタイプ | appType-社内アプリ appType-サードパーティ社内アプリ |
| 必要な権限 | permission-qyapi_holiday_manage-DingTalk 休暇管理権限 |

### クエリパラメータ

| 名前 | タイプ | 必須 | 例 | 説明 |
| --- | --- | --- | --- | --- |
| access_token | String | はい | bE74xxxx | この API を呼び出すためのアプリ認証情報です。   - 社内アプリの場合は、[社内アプリの access_token の取得](/ja/open/development/obtain-orgapp-token) API を呼び出して取得します。 - サードパーティ社内アプリの場合は、サードパーティ組織の access_token を取得する API を呼び出して取得します。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 例 | 説明 |
| --- | --- | --- | --- | --- |
| op_userid | String | はい | manager1 | **OA承認** のアプリ権限を持つ社内の管理者のユーザー ID です。 |
| leave_quotas | LeaveQuotas | はい |  | 初期化する休暇残数のレコードです。 |
| userid | String | はい | zhangsan | 社員のユーザー ID です。 |
| end_time | Number | はい | 1653851001000 | クォータの有効期間の終了時刻です（ミリ秒単位のタイムスタンプ）。 |
| start_time | Number | はい | 1553851001000 | クォータの有効期間の開始時刻です（ミリ秒単位のタイムスタンプ）。 |
| leave_code | String | はい | f84a282xxxx | 休暇タイプの一意の識別子です。  **注意**   - [休暇ルールの追加](/ja/open/development/add-holiday-rules) API を呼び出して追加した休暇タイプは初期化できます。 - 組織に組み込まれている休暇タイプは初期化できません。 |
| reason | String | いいえ | 管理者によるインポート | 操作の理由です。 |
| quota_num_per_day | Number | いいえ | 100 | 日単位で計算したクォータの合計です。  **注意**  休暇タイプが日単位で計算される場合、この値は空にできません。単位は 1/100 日です。  例：1000 = 10 日。 |
| quota_num_per_hour | Number | いいえ | 100 | 時間単位で計算したクォータの合計です。  **注意**  休暇タイプが時間単位で計算される場合、この値は空にできません。単位は 1/100 時間です。  例：1000 = 10 時間。 |
| quota_cycle | String | いいえ | 2019 | クォータが適用される期間です。  **注意**  形式は「yyyy」である必要があります。 |

### リクエスト例

```curl
curl -X POST "https://api.dingtalk.io/topapi/attendance/vacation/quota/init" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=d82be2bxxxx023' \
-d 'leave_quotas=null' \
-d 'op_userid=zhangsan'
```

```text
leaveQuotas.setQuotaNumPerDay(100L);
```


## レスポンス

### レスポンスボディ

| 名前 | タイプ | 例 | 説明 |
| --- | --- | --- | --- |
| result | Result[] |  | 返却される結果です。 |
| reason | String | 日単位のクォータは空にできません | 失敗の理由です。 |
| quota | Quota |  | 失敗したレコードです。 |
| leave_code | String | f84a2829-xxxx0653 | 休暇タイプの一意の識別子です。 |

| quota_cycle | String | 2019 | クォータが適用される期間です。 |
| errcode | Number | 0 | リターンコードです。 |
| errmsg | String | ok | 呼び出しに失敗した場合に返されるエラーメッセージです。 |
| success | Boolean | true | リクエストが成功したかどうかを示します。   - **true**：成功 - **false**：失敗 |
| request_id | String | zq4aec1jton8 | リクエスト ID です。 |
