---
title: "外部連絡先タグリストの取得"
description: "企業の外部連絡先に付与されたタグを取得して連絡先の属性別分類管理ができます"
---

本インターフェースを呼び出して、企業の外部連絡先のタグを取得します。企業はこのインターフェースを使用して、企業の外部連絡先タグリストを取得できます。例えば、この外部連絡先が企業のお客様である場合、タグは「お客様」となる可能性があります。

## リクエスト

| **基本情報** | |
| --- | --- |
| HTTP URL | https://oapi.dingtalk.io/topapi/extcontact/listlabelgroups |
| HTTP Method | POST |
| サポートされるアプリタイプ | appType-社内アプリappType-サードパーティ社内アプリ |
| 必要な権限 | permission-qyapi_ext_read-企業外部連絡先の読み取り権限 |

### クエリパラメータ

| 名前 | タイプ | 必須 | 例 | 説明 |
| --- | --- | --- | --- | --- |
| access_token | String | はい | bE74xxxx | このAPIを呼び出すアプリ認証情報。   - 社内アプリの場合、社内アプリのaccess_token取得インターフェースから取得します。 - サードパーティ社内アプリの場合、サードパーティ企業のaccess_token取得インターフェースから取得します。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 例 | 説明 |
| --- | --- | --- | --- | --- |
| size | Number | いいえ | 20 | ページング検索をサポートし、offsetパラメータと同時に設定された場合のみ有効になります。このパラメータはページサイズを表し、最大100です。 |
| offset | Number | いいえ | 0 | ページング検索をサポートし、sizeパラメータと同時に設定された場合のみ有効になります。このパラメータはオフセット量を表し、オフセット量は0から始まります。 |

### リクエスト例

```curl
curl -X POST "https://oapi.dingtalk.io/topapi/extcontact/listlabelgroups" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=e6eaxxxxa401' \
-d 'offset=0' \
-d 'size=20'
```

### エラーコード

このインターフェースの呼び出し時にエラーが発生した場合は、エラーメッセージに基づいて[グローバルエラーコード](/ja/open/development/server-api-error-codes-1)ドキュメントで解決策を検索してください。

| エラーコード（errcode） | エラーコードの説明（errmsg） | 解決策 |
| --- | --- | --- |
| 33009 | 無効なtokenGrantType | access_tokenが正しいかご確認ください |
| 400043 | 無効なorgId | access_tokenが正しいかご確認ください |
| 41101 | 無効なsize | ページサイズが正しいかご確認ください |
| 40068 | 無効なオフセット量 | オフセット量を調整してください |
| -1 | システムビジー | 後で再試行してください |
