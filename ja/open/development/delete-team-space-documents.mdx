---
title: "ナレッジベースドキュメントの削除"
---

本インターフェースを呼び出すことで、チームスペースのドキュメントまたはフォルダーを削除できます。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | `https://api.dingtalk.io/v1.0/doc/workspaces/{workspaceId}/docs/{nodeId}` |
| HTTP Method | DELETE |
| 対応アプリタイプ | appType-社内アプリ |
| 必要な権限 | permission-Document.WorkspaceDocument.Write-ナレッジベースドキュメント書き込み権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | はい | 本インターフェースの呼び出しに使用するアクセス認証情報です。[社内アプリの access_token を取得](/ja/open/development/obtain-the-access-token-of-an-internal-app) インターフェースを呼び出して取得できます。 |

### パスパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| workspaceId | String | はい | チームスペースの ID です。[ナレッジベースの作成](/ja/open/development/new-knowledge-base) インターフェースまたは [ナレッジベースリストの取得](/ja/open/development/get-knowledge-base-list) インターフェースから取得した workspaceId フィールドの値です。 |
| nodeId | String | はい | チームスペースノードの ID です。ドキュメント ID またはフォルダー ID を指定できます。[ナレッジベースドキュメントの作成](/ja/open/development/create-team-space-document) インターフェースから nodeId パラメータの値を取得できます。 |

### クエリパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| operatorId | String | はい | 削除リクエストを実行するユーザーの unionId です。[ユーザー詳細の照会](/ja/open/development/query-user-details) インターフェースから unionid パラメータの値を取得できます。 |
