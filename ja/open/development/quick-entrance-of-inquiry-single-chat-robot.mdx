---
title: "シングルチャットボットのショートカットを照会"
---

本インターフェースを呼び出して、シングルチャットボットのショートカット（ショートカット名、ショートカットアイコン、PC 版ショートカット遷移リンク、モバイル版ショートカットリンクを含む）を照会します。組織管理者がボット機能を設定する際に、ショートカット設定情報を素早く取得する用途に適しています。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/v1.0/robot/plugins/query |
| HTTP Method | POST |
| サポートするアプリタイプ | appType-社内アプリ |
| 必要な権限 | permission-Robot.SingleChat.ReadWrite-シングルチャットボット利用管理権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | はい | 本インターフェース呼び出し時のアクセス認証情報。[社内アプリのアクセストークンを取得](https://open.dingtalk.io/document/development/obtain-the-access-token-of-an-internal-app#)インターフェースを呼び出して取得します。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| robotCode | String | はい | ボットのコード。[ボット用語集 - robotCode](https://open.dingtalk.io/document/development/robot-overview#)の内容を参照して `robotCode` を取得してください。 |

### リクエスト例

```http
POST /v1.0/robot/plugins/query HTTP/1.1
Host:api.dingtalk.io
x-acs-dingtalk-access-token:asxsbjekdndkajXXXXX
Content-Type:application/json

{
  "robotCode" : "dingykcdkXXXXXX"
}
```

## レスポンス

### レスポンスボディ

| 名前 | タイプ | 説明 |
| --- | --- | --- |
| pluginInfoList | Array | ショートカットリスト。 |
| name | String | ショートカット名。国際化設定に対応しています（例：`{"en_US":"test123","ja_JP":"テスト123"}`）。 |
| icon | String | ショートカットアイコンの ID。 |
| pcUrl | String | PC 版チャットのショートカット遷移リンク。 |
| mobileUrl | String | モバイル版ショートカット遷移リンク。 |

```text
}
```
