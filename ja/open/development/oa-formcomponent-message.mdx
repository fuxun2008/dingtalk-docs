## FormComponent パラメーター

**formComponents** はフォームコンポーネントのリストです。すべてのコンポーネントが Props のすべての属性をサポートしているわけではありません。各コントロールがサポートする属性は、以下のリクエスト例を参照してください。承認スイートや明細コントロールなど一部のコンテナコントロールは、子コントロールをサポートします。各子コントロールのタイプと属性は children で定義します。子コントロールの属性定義は、他のコントロールと同じです。コントロールのモデルは次のとおりです。

<Warning>
フォームコントロールの共通制限：
</Warning>

- componentId：コントロール ID。最大 64 文字です。
- bizAlias：コントロールの業務表示名。フォーム内で一意である必要があります。bizAlias と componentId のいずれかを指定してください。最大 64 文字です。
- label：コントロールのタイトル。最大 20 文字です。
- placeholder：入力ヒント。最大 128 文字です。
- content：TextNote コントロールのコンテンツ。最大 500 文字です。
- テーブル形式の明細コントロールの合計長は 65,535 文字以内です。各明細コントロールのレコード数は 100 件以内にしてください。

#### 共通コントロール属性

```json
{
  "componentId": "TextField-12345677",   // コントロール ID。フォーム内で一意。bizAlias といずれかを指定
  "required":true,  // 必須かどうか
  "label": "一行テキスト",   // コントロールのタイトル
  "placeholder": "値を入力してください",    // 入力ヒント
  "bizAlias": "staffId", // コントロールの業務表示名。フォーム内で一意。componentId といずれかを指定
  "print": "0", // 印刷に含めるかどうか（0：印刷しない、1：印刷可能）。デフォルト：印刷可能
  "disabled": false, // コントロールを編集可能にするかどうか
}
```

#### 位置情報コントロール

```json
{
   "componentType": "TimeAndLocationField",
   "props": {
       "label": "[\"現在時刻\",\"現在地\"]",
       "componentId": "TimeAndLocationField_1CVHM5TIIWR9C",
       "required": false,
       "mask": true
    }
}
```

#### 一行入力コントロール

```json
{
    "componentType": "TextField",
    "props": {
       "label": "一行入力", // コントロールのタイトル
       "placeholder": "値を入力してください", // 入力ヒント
       "componentId": "TextField_17EZKEGSOCTC0", // コントロール ID。フォーム内で一意。業務上の意味は持たない
       "required": false, // 必須かどうか。デフォルト：任意
       "bizAlias": "staffId" // コントロールの業務表示名。フォーム内で一意。componentId といずれかを指定
    }
}
```

#### 選択コントロール

```json

    "props": {

            "value": "選択肢2",

        },
        {
            "value": "選択肢3",

```

## FormComponentValues パラメーター

値は、テンプレート作成時に使用したコンポーネントに厳密に従って定義してください。フォームコンポーネントへの値の割り当てについては、[FormComponent パラメーター](#900adc505f44g)を参照してください。

### 位置情報コントロール

```json
{
    "name": "[\"現在時刻\",\"現在地\"]", // コントロールのラベル
    "value": "[\"2025-05-27 14:27:20\",120.021195,30.281506,\"浙江省杭州市余杭区文一西路960-1 Alibaba Group 西渓園区C区\",100]"
}
```
