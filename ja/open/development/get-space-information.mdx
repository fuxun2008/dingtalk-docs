本 API を呼び出して、ストレージスペースの情報を取得します。

## API 呼び出し説明

本 API を呼び出すことで、スペース名、使用済み容量、owner タイプなど、スペースの詳細情報を取得します。

- ストレージスペースタイプが USER の場合、スペースの権限を持つユーザーはすべて操作可能です。それ以外の社員が操作するには、[権限の追加](/ja/open/development/add-permissions-file) API を呼び出して権限を付与する必要があります。
- ストレージスペースタイプが APP の場合、誰が操作する場合でも、[権限の追加](/ja/open/development/add-permissions-file) API を呼び出して権限を付与する必要があります。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | `https://api.dingtalk.io/v1.0/storage/spaces/{spaceId}` |
| HTTP Method | GET |
| サポートされるアプリタイプ | appType-社内アプリ　appType-サードパーティ社内アプリ |
| 権限要件 | permission-Storage.Space.Read-企業ストレージスペース読み取り権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | はい | 本 API を呼び出す際のアクセス認証情報。以下の方法で取得します。   - 社内アプリの場合は、[社内アプリの accessToken を取得する](/ja/open/development/obtain-the-access-token-of-an-internal-app#) API を呼び出して取得します。 - サードパーティ社内アプリの場合は、[サードパーティアプリ認可企業の accessToken を取得する](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#) API を呼び出して取得します。 |

### パスパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| spaceId | String | はい | スペース ID。[スペースの追加](/ja/open/development/add-space#) API を呼び出して id パラメータの値を取得できます。 |

### クエリパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| unionId | String | はい | 操作者の unionId。[ユーザー詳細の照会](/ja/open/development/query-user-details#) API で取得します。 |
