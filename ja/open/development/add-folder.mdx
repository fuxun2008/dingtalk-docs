---
title: "フォルダーの追加"
---

本 API を呼び出して、ストレージスペース内にフォルダーを追加します。

## API 呼び出し説明

ストレージスペースを追加した後、本 API を呼び出してスペース内にフォルダーを追加できます。

- ストレージスペースタイプが USER の場合、スペースの権限を持つユーザーは操作権限を持ちます。その他の社員が操作するには、[権限の追加](/zh/open/development/add-permissions-file) API を呼び出して権限付与を行ってください。
- ストレージスペースタイプが APP の場合、誰が操作する場合でも [権限の追加](/zh/open/development/add-permissions-file) API を呼び出して権限付与を行う必要があります。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | `https://api.dingtalk.io/v1.0/storage/spaces/{spaceId}/dentries/{parentId}/folders` |
| HTTP Method | POST |
| サポートするアプリタイプ | appType-社内アプリ　appType-サードパーティ社内アプリ |
| 必要な権限 | permission-Storage.File.Write-企業ストレージファイル書き込み権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | はい | 本 API を呼び出すためのアクセス認証情報。以下の方法で取得します。   - 社内アプリの場合、[社内アプリの accessToken を取得](https://open.dingtalk.io/document/development/obtain-the-access-token-of-an-internal-app#) API を呼び出して取得します。 - サードパーティ社内アプリの場合、[サードパーティアプリの認可企業の accessToken を取得](https://open.dingtalk.io/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#) API を呼び出して取得します。 |

### パスパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| spaceId | String | はい | スペース ID。[スペースの追加](https://open.dingtalk.io/document/development/add-space#) API を呼び出して id パラメータの値を取得できます。 |
| parentId | String | はい | 親ディレクトリ ID。[ファイルまたはフォルダーリストの取得](https://open.dingtalk.io/document/development/obtain-the-file-list-storage#) API を呼び出して取得します。ルートディレクトリの場合は 0 を指定します。 |

### クエリパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| unionId | String | はい | 操作者の unionId。[ユーザー詳細の照会](https://open.dingtalk.io/document/development/query-user-details#) API を呼び出して取得できます。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| name | String | はい | フォルダーの名前。命名には以下の要件があります。- 先頭と末尾に空白を含めることはできません（含めた場合は自動的に削除されます）。 - 特殊文字（タブ、`*`、`"`、`<`、`>`、`|`）を含めることはできません。 - `.` で終わることはできません。 |
| option | Object | いいえ | オプションパラメータ。 |
| conflictStrategy | String | いいえ | フォルダー名が重複した場合の処理戦略。   - **AUTO_RENAME**：自動的に名前を変更（デフォルト） - **OVERWRITE**：上書き - **RETURN_DENTRY_IF_EXISTS**：既存のフォルダーを返す - **RETURN_ERROR_IF_EXISTS**：フォルダーが既に存在する場合はエラーを返す |
| appProperties | Array | いいえ | 現在のフォルダーのアプリ属性リスト。最大 3 件。 |
| name | String | はい | 属性名。 |
| value | String | はい | 属性値。 |
| visibility | String | はい | 属性の可視性。   - **PUBLIC**：すべてのアプリから可視 - **PRIVATE**：現在のアプリのみ可視 |
