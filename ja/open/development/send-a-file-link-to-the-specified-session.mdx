本インターフェースを呼び出し、ファイルリンクを指定したチャットに送信します。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/v1.0/convFile/conversations/files/links/send |
| HTTP Method | POST |
| 対応アプリタイプ | appType-社内アプリ |
| 権限要件 | permission-ConvFile.File.Send-グループファイル送信権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | はい | 本インターフェースを呼び出すためのアクセス認証情報です。[社内アプリの access_token を取得する](/ja/open/development/obtain-the-access-token-of-an-internal-app#)インターフェースを呼び出して取得します。 |

### クエリパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| unionId | String | はい | 操作者の unionId です。[ユーザー詳細を照会する](/ja/open/development/query-user-details#)インターフェースを呼び出して取得できます。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| spaceId | String | はい | ファイルが存在するスペース ID です。[スペースを追加する](/ja/open/development/add-space#)インターフェースを呼び出して取得します。 |
| dentryId | String | はい | ファイル ID です。[ファイルまたはフォルダーのリストを取得する](https://open.dingtalk.com/document/development/obtain-the-file-list-storage#)インターフェースを呼び出し、id パラメータの値を取得します。 |
| openConversationId | String | はい | 送信先チャットの openConversationId です。[グループを作成する](https://open.dingtalk.com/document/development/create-group-session#)インターフェースを呼び出し、openConversationId パラメータの値を取得します。 |

## レスポンス

### レスポンスボディ

| 名前 | タイプ | 説明 |
| --- | --- | --- |
| file | Object | 送信先チャットに送信されたファイルリンクの情報です。 |
| id | String | ファイル ID。 |
| conversationId | String | ファイルが存在するチャットの openConversationId。 |
| spaceId | String | ファイルが存在するスペース ID。 |
| parentId | String | ファイルの親ディレクトリ ID。ルートディレクトリの ID 値は 0 です。 |
| type | String | ファイルタイプ。   - **FILE**：ファイル - **FOLDER**：フォルダー |
| name | String | ファイル名。 |
| size | Long | ファイルサイズ。単位は Byte。 |
| path | String | ファイルパス。 |
| version | Long | ファイルバージョン番号。 |
| status | String | ファイルステータス。   - **NORMAL**：正常 - **DELETED**：ゴミ箱 - **EXPIRED**：期限切れ |
| extension | String | ファイル拡張子。 |
| creatorId | String | ファイルの作成者の unionId。 |
| modifierId | String | ファイルの編集者の unionId。 |
| createTime | String | ファイルの作成時間。iso8601 形式（例：2022-07-29T14:55Z）。 |
| modifiedTime | String | ファイルの編集時間。iso8601 形式（例：2022-07-29T14:55Z）。 |
| uuid | String | 識別フィールド。 |
