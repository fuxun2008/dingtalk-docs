多くの組織には、休暇付与に関する独自のルールがあります。たとえば、社員の職位に応じて異なる休暇残数を付与する場合があります。現在、DingTalkの休暇ルールはこのようなカスタムロジックに対応していません。そこでDingTalkでは、こうした独自の運用に対応できるよう、休暇関連の Open API を提供しています。

<Warning>
休暇 API を呼び出す前に、開発者コンソールで必要な API 権限をリクエストしてください。
</Warning>

## 権限をリクエストする

休暇管理 API を呼び出す前に、API 権限をリクエストします。

1. [開発者コンソール](https://open-dev.dingtalk.io/#/appMgr/provider/eapp/53642/1)にログインし、対象のアプリをクリックします。
2. **権限管理**をクリックし、**勤怠**をクリックします。
3. 休暇管理の API 権限を追加し、**権限をリクエスト**または**一括リクエスト**をクリックします。

### 注意事項

   権限のリクエストが辞退された場合は、**リクエスト**列で**休暇管理**の API 権限を確認してください。**辞退**にカーソルを合わせると、理由が表示されます。

   アプリのコンソールで**基本情報** > **権限管理**に移動し、一覧から休暇管理の権限を探します。

| 権限 | コード | 含まれる API |
| --- | --- | --- |
| DingTalk休暇管理 | `qyapi_holiday_manage` | 休暇ルールの追加、休暇ルールの更新、休暇ルールの削除 |
| DingTalk休暇照会 | `qyapi_holiday_readonly` | 休暇ルール一覧の照会、休暇残数の照会、社員の休暇残数変更履歴の一括照会 |

各権限の横にある**権限をリクエスト**をクリックします。

## シナリオ 1：休暇ルールを同期する

休暇 API を使用して、社内の既存の休暇ルールをDingTalkの休暇管理システム（[DingTalk管理コンソール](https://oa.dingtalk.io) **> ワークベンチ > アプリ管理 > OA承認**）に同期します。

**OA承認**の管理コンソールで**休暇管理** > **休暇ルール**に移動し、**休暇を追加**をクリックして休暇ルールを定義します。各ルールでは、次の項目を設定します。

| 項目 | 説明 |
|---|---|
| **休暇名** | 例：私用休暇、代休、病気休暇、年次有給休暇、産前産後休暇、育児休暇（男性）、結婚休暇 |
| **休暇単位** | 時間単位、半日単位、または日単位 |
| **日数の計算方法** | 例：勤務日ベース |
| **有給** | 有給休暇かどうか |
| **残数ルール** | 例：残数無制限 |
| **スコープ** | 例：全社 |
| **操作** | 編集または削除 |

次に、休暇申請フォームのフォーム設計で、DingTalkが提供する承認用の勤怠キットを追加します。このキットは休暇残数を自動で計算し、DingTalkの勤怠アプリに同期します。

OA承認のフォームエディターでは、**基本設定** > **フォーム設計** > **プロセス設計** > **詳細設定**の順に設定を行います。**フォーム設計**画面で**キット**タブを開き、**勤怠キット**から**休暇キット**をフォームに追加します。

## シナリオ 2：社内の休暇残数をDingTalk承認に同期する

社内独自の休暇ルールがあり、社内の休暇残数をDingTalk承認に同期する必要がある場合は、次の API を使用します（ここでは社内アプリを例に説明します）。

1. [休暇残数の初期化](/ja/open/development/initialize-holiday-balance) API を呼び出します。
2. 管理者として[DingTalk管理コンソール](https://oa.dingtalk.io) **> ワークベンチ > アプリ管理 > OA承認 > 休暇管理 > 社員の休暇残数**に移動し、更新された社員の休暇残数を確認します。

**社員の休暇残数**ページで、**社員の休暇ルールを設定**または**Excel で残数を一括編集**をクリックします。組織の範囲で絞り込み、必要に応じて**90日以内に退職した社員を含める**を選択します。各レコードには社員 1 名分の情報が表示され、**名前**、**部門**、**入社日**、**初出勤日**、**私用休暇（時間）**、**代休（時間）**、**病気休暇（時間）**、**年次有給休暇（日）**、**産前産後休暇（日）**の各列が含まれます。
