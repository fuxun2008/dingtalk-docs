この API を呼び出すと、勤怠設定に登録された打刻修正ルールの一覧をページ単位で取得できます。取得できる情報には、ルール名とルール ID が含まれます。

## API 呼び出し説明

たとえば、ある組織の勤怠ルール管理に、**テスト用打刻修正ルール**と**デフォルト打刻修正ルール**の 2 つの打刻修正ルールがあるとします。

この API を呼び出すと、2 つの打刻修正ルールのルール名とルール ID を取得できます。

勤怠の管理コンソールで **勤怠ルール** > **打刻修正ルール** を開くと、設定済みの打刻修正ルールを確認できます。各ルールには **ルール名**、**ルールの詳細**（月あたりの申請可能回数、打刻修正を申請できる過去の期間、打刻漏れ・遅刻・早退などの対象タイプ）、**スコープ** が表示され、**編集** と **削除** の操作を実行できます。新しいルールを作成するには、**打刻修正ルールを追加** を使用します。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/v1.0/attendance/adjustments |
| HTTP メソッド | GET |
| 対応するアプリタイプ | appType-社内アプリ　appType-サードパーティ社内アプリ |
| 必要な権限 | permission-qyapi_attendance_group_read-勤怠グループの読み取り権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | はい | この API を呼び出すためのアクセス認証情報です。次の方法で取得してください。   - 社内アプリの場合は、[社内アプリのアクセストークンを取得](/ja/open/development/obtain-the-access-token-of-an-internal-app) API を呼び出します。 - サードパーティ社内アプリの場合は、サードパーティアプリを承認した組織のアクセストークンを取得する API を呼び出します。 |

### クエリパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| pageNumber | Long | はい | 開始ページ番号です。  値は 1 から始まります。 |
| pageSize | Long | はい | ページサイズです。  最大値は 50 です。 |

### リクエスト例

HTTP

```http
GET /v1.0/attendance/adjustments?pageNumber=1&pageSize=10 HTTP/1.1
Host:api.dingtalk.io
x-acs-dingtalk-access-token:xxxxx
Content-Type:application/json
```
