---
title: "全員ミュートまたは全員ミュート解除"
---

会議中、本インターフェースを使用して全員をミュートまたは全員のミュートを解除できます。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | `https://api.dingtalk.io/v1.0/conference/videoConferences/{conferenceId}/allMembers/mute` |
| HTTP Method | POST |
| サポートするアプリタイプ | appType-社内アプリ　appType-サードパーティ社内アプリ |
| 必要な権限 | permission-VideoConference.Conference.Write-ビデオ会議情報管理権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | はい | 本インターフェースを呼び出すためのアクセス認証情報。以下の方法で取得します：   - 社内アプリの場合、[社内アプリのアクセストークンを取得](/ja/open/development/obtain-the-access-token-of-an-internal-app#) インターフェースを呼び出して取得します。 - サードパーティ社内アプリの場合、[サードパーティアプリ認可企業のアクセストークンを取得](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#) インターフェースを呼び出して取得します。 |

### パスパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| conferenceId | String | はい | 会議ID。[ビデオ会議を作成](/ja/open/development/create-a-video-conference#) インターフェースを呼び出し、戻り値の `conferenceId` フィールドから取得できます。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| action | String | はい | 操作タイプ：   - **mute**：ミュート - **un_mute**：ミュート解除 |
| forceMute | Boolean | いいえ | 強制ミュートするかどうか：   - **true**：強制ミュート。参加者によるオンを許可しません - **false**：非強制ミュート。参加者は再度オンにできます |

### リクエスト例

HTTP

```http
POST /v1.0/conference/videoConferences/644272f14ba331014745cxxx-xxxx/allMembers/mute HTTP/1.1
Host:api.dingtalk.io
x-acs-dingtalk-access-token:d8be6dc28b123e7682312ac55xxxx
Content-Type:application/json

{
  "action" : "mute",
  "forceMute" : true
}
```
