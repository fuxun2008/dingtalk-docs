本記事では、H5マイクロアプリデバッグツールとその使い方について説明します。

## はじめに

H5マイクロアプリデバッグツールは、DingTalk Open Platform がリリースした新しいH5マイクロアプリ用のデバッグツールです。デバッグページでは、実行中のアプリの **Elements**、**Console**、**Network**、**AppLog** を確認できます。機能は Chrome DevTools に類似しています。

### H5マイクロアプリデバッグツールが現在サポートする機能

- タグとスタイルのデバッグ
- デバッグ文の出力とコマンドの実行
- ネットワークリクエストの確認
- JSAPI 呼び出しの確認

## 作業フロー

以下の手順に従って、H5マイクロアプリデバッグツールでデバッグします。

1. [開発者バックエンド](https://open-dev.dingtalk.com/)にログインし、対象の **App Details** ページに移動します。
2. **App Details** ページで **Development Management** をクリックし、**Development Tools** を選択して **Generate Dedicated Debugging Tool** をクリックします。

3. 画面の指示に従って、デバッグツールのページを開きます。

4. このアプリ専用のデバッグコードをコピーし、マイクロアプリの `<header></header>` タグにコードを追加します。

5. デバッグを開始します。

## FAQ

### Q：DevTools デバッグツールが未接続、または切断されました。DevTools デバッグツールを更新してから、現在のページを更新してください。

A：必ず先に DevTools デバッグツールのページを開き、その後にマイクロアプリのページを開いてください。

### Q：別のクライアントがすでに同じ DevTools リンクでデバッグしています。新しい DevTools デバッグリンクを生成してください。

A：同一の DevTools デバッグツールリンクでは、一度に1つのページのみがデバッグできます。**Generate Debugging Tool** ボタンを再度クリックして、新しい DevTools デバッグツールリンクを生成してください。

### Q：JSAPI のデバッグ時にエラーが発生します：[No permission info for action: xxx]。

A：&lt;https://www.npmjs.com/package/dingtalk-jsapi> を参照し、JSAPI を呼び出す前に初期化してください。

### Q：JSAPI のデバッグ時にエラーが発生します：[The current micro app is not in your organization]。

A：デバッグ用に新しいH5マイクロアプリを作成し、新規作成したアプリのホームページ URL に現在のマイクロアプリの ip:port を入力してください。

### Q：ネットワークリクエスト時にリクエストヘッダーとレスポンスヘッダーが表示されません。

A：リクエストヘッダーが表示されないのは、ブラウザのセキュリティポリシーに関連しています。レスポンスヘッダーが表示されない場合は、API のレスポンスヘッダーに Access-Control-Expose-Headers フィールドが設定されているかを確認してください。
