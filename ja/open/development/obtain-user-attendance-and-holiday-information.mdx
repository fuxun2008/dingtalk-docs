description: "社員リストと開始日・終了日を指定し、期間内の休日情報を一括取得する API です。法定休日・代休日・振替出勤日の判別に利用できます。"
---

この API を呼び出すと、指定した期間内の社員の休日情報を照会できます。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/v1.0/attendance/holidays |
| HTTP メソッド | POST |
| 対応するアプリタイプ | appType-社内アプリ　appType-サードパーティ社内アプリ |
| 必須の権限 | permission-qyapi_attendance_group_read-勤怠グループの照会権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | はい | この API を呼び出すためのアクセス認証情報です。取得方法は次のとおりです。   - 社内アプリ：[社内アプリのアクセストークンを取得](/ja/open/development/obtain-the-access-token-of-an-internal-app) API を呼び出します。 - サードパーティ社内アプリ：サードパーティアプリを承認した組織のアクセストークンを取得する API を呼び出します。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| userIds | Array of String | はい | 社員のリストです。 |
| workDateFrom | Long | はい | 開始日です。 |
| workDateTo | Long | はい | 終了日です。 |

### リクエスト例

## レスポンス

### レスポンスボディ

| 名前 | タイプ | 説明 |
| --- | --- | --- |
| result | Array | 社員の休日リストです。 |
| userId | String | 社員のユーザー ID です。 |
| holidays | Array | 休日のリストです。 |
| workDate | Long | 日付です。 |
| holidayName | String | 休日の名前です。 |
| holidayType | String | 休日のタイプです。   - festival：法定休日 - rest：代休日 - overtime：振替出勤日 |
| realWorkDate | Long | 振替休日です。休日のタイプが振替出勤日の場合のみ値が設定されます。 |
