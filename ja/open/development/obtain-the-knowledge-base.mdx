ナレッジベースを取得します。GET リクエストで呼び出します。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | `https://api.dingtalk.io/v2.0/wiki/workspaces/{workspaceId}` |
| HTTP Method | GET |
| サポートするアプリタイプ | appType-社内アプリ　appType-サードパーティ社内アプリ |
| 権限要件 | permission-Wiki.Workspace.Read-ナレッジベース読み取り権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | はい | この API を呼び出すためのアクセス認証情報。   - 社内アプリの場合は [社内アプリのアクセストークン取得](https://open.dingtalk.com/document/orgapp/obtain-the-access_token-of-an-internal-app) API を呼び出して取得します。 - サードパーティ社内アプリの場合は [サードパーティアプリが認可された企業のアクセストークン取得](https://open.dingtalk.com/document/isvapp/obtain-the-access_token-of-the-authorized-enterprise) API を呼び出して取得します。 |

### パスパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| workspaceId | String | はい | ナレッジベース ID：   - 社内アプリの場合は [ナレッジベース一覧取得](/ja/open/development/get-knowledge-base-list) API を呼び出し、レスポンスパラメータ `workspaceId` フィールドから取得します。 - サードパーティ社内アプリの場合は [ナレッジベース一覧取得](/ja/open/development/get-knowledge-base-list) API を呼び出し、レスポンスパラメータ `workspaceId` フィールドから取得します。 |

### クエリパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| withPermissionRole | Boolean | いいえ | 権限情報を取得するかどうか：   - true：取得する - false：取得しない   デフォルトは false です。 |
| operatorId | String | はい | 操作者の unionId。 |

### リクエスト例

Host:api.dingtalk.io
x-acs-dingtalk-access-token:access_token
Content-Type:application/json

| icon | Object | ナレッジベースのアイコン。 |
