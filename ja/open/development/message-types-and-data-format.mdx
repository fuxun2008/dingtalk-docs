本記事では、DingTalk のメッセージ通知タイプとデータ形式について説明します。

## DingTalk メッセージ通知タイプ

**業務通知メッセージ**：企業の業務通知チャット内で特定のマイクロアプリの名義で社員にプッシュされる通知メッセージです。例：誕生日のお祝い、入社リマインドなど。

## テキストメッセージ（text）

```json
{
    "msgtype": "text",
    "text": {
        "content": "月会通知"
    }
}
```

### パラメータ説明：

| 名前 | タイプ | 必須 | 例 | 説明 |
| --- | --- | --- | --- | --- |
| msgtype | String | はい | text | メッセージタイプ。テキストメッセージのタイプは text です。 |
| content | String | はい | 月会通知 | メッセージ内容。500 文字以内を推奨します。 |

| link.messageUrl | String | はい | http://dingtalk.io | メッセージクリック時のリンクアドレス。送信メッセージがミニプログラムの場合はミニプログラムへのリダイレクトリンクをサポートします。[メッセージリンク説明](/zh/open/development/message-link-description) を参照してください。 |

## Markdown メッセージ

```json
{
    "msgtype": "markdown",
    "markdown": {
        "title": "首屏会话透出的展示内容",
        "text": "# 这是支持markdown的文本   \n   ## 标题2    \n   * 列表1   \n  "
    }
}
```

### Markdown 構文の説明は以下のとおりです：

```text
标题
# 一级标题
## 二级标题
### 三级标题
#### 四级标题
##### 五级标题
###### 六级标题
 
引用
> A man who stands for nothing will fall for anything.
 
文字加粗、斜体
**bold**
*italic*
 
链接
[this is a link](http://name.com)
 
图片

 
无序列表
- item1
- item2
 
有序列表
1. item1
2. item2

换行
  \n  (建议\n前后分别加2个空格)
```

### パラメータ説明：

| 名前 | タイプ | 必須 | 例 | 説明 |
| --- | --- | --- | --- | --- |
| msgtype | String | はい | markdown | メッセージタイプ。[メディアファイルのアップロード](/zh/open/development/upload-media-files) インターフェースを呼び出して取得します。Markdown タイプは markdown です。 |
| title | String | はい | 测试标题 | ファーストスクリーンのチャットで表示されるコンテンツ。iShot2022-07-14_09 |
| text | String | はい | 测试内容 | Markdown 形式のメッセージ。最大 5000 文字までです。 |

### メッセージサンプル：

## カードメッセージ

カードメッセージは、全体リダイレクト ActionCard スタイルと独立リダイレクト ActionCard スタイルをサポートします。

- 全体リダイレクト ActionCard スタイルは、1 つのクリック Action をサポートし、パラメータ single_title と single_url の指定が必須です。

  ```json lines
  {
      "msgtype": "action_card",
      "action_card": {
          "title": "是透出到会话列表和通知的文案",
          "markdown": "支持markdown格式的正文内容",
          "single_title": "查看详情",
          "single_url": "https://open.dingtalk.io"
      }
  }
  ```
- 独立リダイレクト ActionCard スタイルは、複数のクリック Action をサポートし、パラメータ btn_orientation と btn_json_list の指定が必須です。

  ```json lines
  {
      "msgtype": "action_card",
      "action_card": {
          "title": "是透出到会话列表和通知的文案",
          "markdown": "支持markdown格式的正文内容",
          "btn_orientation": "1",
          "btn_json_list": [
              {
                  "title": "一个按钮",
                  "action_url": "https://www.taobao.com"
              },
              {
                  "title": "两个按钮",
                  "action_url": "https://www.tmall.com"
              }
          ]
      }
  }
  ```

### パラメータ説明：

| 名前 | タイプ | 必須 | 例 | 説明 |
| --- | --- | --- | --- | --- |
| msgtype | String | はい | action_card | メッセージタイプ。カードメッセージのタイプは action_card です。 |
| action_card.markdown | String | はい | 支持markdown格式的正文内容 | メッセージ内容。Markdown をサポートし、構文は標準 Markdown 構文を参照してください。1000 文字以内を推奨します。 |
| action_card.title | String | いいえ | 测试标题 | チャットリストと通知に表示されるテキスト。222 |
| action_card.single_title | String | いいえ | 查看详情 | 全体リダイレクト ActionCard スタイルを使用する際のタイトル。single_url と同時に設定する必要があり、最長 20 文字です。  **説明**  全体リダイレクトの ActionCard スタイルの場合、**single_title** と **single_url** は必ず設定してください。 |
| action_card.single_url | String | いいえ | https://open.dingtalk.io | メッセージクリック時のリンクアドレス。[メディアファイルのアップロード](/zh/open/development/upload-media-files) インターフェースを呼び出して取得します。送信メッセージがミニプログラムの場合はミニプログラムへのリダイレクトリンクをサポートし、最長 500 文字です。 |
| action_card.btn_orientation | String | いいえ | 0 | 独立リダイレクト ActionCard スタイルを使用する際のボタン配置方式：   - **0**：縦並び - **1**：横並び  btn_json_list と同時に設定する必要があります。 |
| action_card.btn_json_list | JSONArray | いいえ |  | 独立リダイレクト ActionCard スタイルを使用する際のボタンリスト。btn_orientation と同時に設定する必要があり、長さは 1000 文字以内です。  **説明**  独立リダイレクトの ActionCard スタイルの場合、btn_json_list と btn_orientation は必ず設定してください。 |
| action_card.btn_json_list.title | String | いいえ | 两个按钮 | 独立リダイレクト ActionCard スタイルを使用する際のボタンのタイトル。最長 20 文字です。 |
| action_card.btn_json_list.action_url | String | いいえ | https://www.tmall.com | 独立リダイレクト ActionCard スタイルを使用する際のリダイレクトリンク。最長 700 文字です。 |
