本記事では、DingTalk のメッセージ通知タイプとデータ形式について説明します。

## DingTalk メッセージ通知タイプ

**業務通知メッセージ**：企業の業務通知チャット内で特定のマイクロアプリの名義で社員にプッシュされる通知メッセージです。例：誕生日のお祝い、入社リマインドなど。

## テキストメッセージ（text）

```json
{
    "msgtype": "text",
    "text": {
        "content": "月例ミーティング通知"
    }
}
```

### パラメータ説明：

| 名前 | タイプ | 必須 | 例 | 説明 |
| --- | --- | --- | --- | --- |
| msgtype | String | はい | text | メッセージタイプ。テキストメッセージのタイプは text です。 |
| content | String | はい | 月例ミーティング通知 | メッセージ内容。500 文字以内を推奨します。 |

## 画像メッセージ

```json

    "msgtype": "image",
    "image": {
        "media_id": "@lADOADmaWMzazQKA"
    }

```

### パラメータ説明：

| 名前 | タイプ | 必須 | 例 | 説明 |
| --- | --- | --- | --- | --- |
| msgtype | String | はい | image | メッセージタイプ。画像メッセージのタイプは image です。 |
| media_id | String | はい | @lADOADmaWMzazQKA | メディアファイル mediaId。[メディアファイルのアップロード](/ja/open/development/upload-media-files) インターフェースを呼び出して mediaId パラメータ値を取得します。幅 600 ピクセル × 高さ 400 ピクセル、縦横比 3:2 を推奨します。 |

## リンクメッセージ

```json
{
    "msgtype": "link",
    "link": {
        "messageUrl": "http://s.dingtalk.io/market/dingtalk/error_code.php",
        "picUrl":"@lALOACZwe2Rk",
        "title": "テスト",
        "text": "テスト"
    }
}
```

### パラメータ説明：

| 名前 | タイプ | 必須 | 例 | 説明 |
| --- | --- | --- | --- | --- |
| msgtype | String | はい | link | メッセージタイプ。リンクメッセージのタイプは link です。 |
| link.messageUrl | String | はい | http://dingtalk.io | メッセージクリック時のリンクアドレス。送信メッセージがミニプログラムの場合はミニプログラムへのリダイレクトリンクをサポートします。[メッセージリンク説明](/ja/open/development/message-link-description) を参照してください。 |
| link.picUrl | String | はい | @lADOADmaWMzazQKA | [メディアファイルのアップロード](/ja/open/development/upload-media-files) インターフェースを呼び出して取得します。 |
| link.title | String | はい | linkメッセージテスト | メッセージタイトル。100 文字以内を推奨します。 |
| link.text | String | はい | メッセージ内容テスト | メッセージの説明。500 文字以内を推奨します。 |

## Markdown メッセージ

```json
{
    "msgtype": "markdown",
    "markdown": {
        "title": "ファーストスクリーンのチャットで表示されるコンテンツ",
        "text": "# これは markdown をサポートするテキストです   \n   ## 見出し2    \n   * リスト1   \n  "
    }
}
```

### Markdown 構文の説明は以下のとおりです：

```text
見出し
# 一級見出し
## 二級見出し
### 三級見出し
#### 四級見出し
##### 五級見出し
###### 六級見出し
 
参照
> A man who stands for nothing will fall for anything.
 
文字の太字、斜体
**bold**
*italic*
 
リンク
[this is a link](http://name.com)
 
画像

 
箇条書き
- item1
- item2
 
番号付きリスト
1. item1
2. item2

改行
  \n  （\n の前後にそれぞれ半角スペース2個を入れることを推奨）
```

### パラメータ説明：

| 名前 | タイプ | 必須 | 例 | 説明 |
| --- | --- | --- | --- | --- |
| msgtype | String | はい | markdown | メッセージタイプ。[メディアファイルのアップロード](/ja/open/development/upload-media-files) インターフェースを呼び出して取得します。Markdown タイプは markdown です。 |
| title | String | はい | テストタイトル | ファーストスクリーンのチャットで表示されるコンテンツ。iShot2022-07-14_09 |
| text | String | はい | テスト内容 | Markdown 形式のメッセージ。最大 5000 文字までです。 |

### メッセージサンプル：

## カードメッセージ

カードメッセージは、全体リダイレクト ActionCard スタイルと独立リダイレクト ActionCard スタイルをサポートします。

- 全体リダイレクト ActionCard スタイルは、1 つのクリック Action をサポートし、パラメータ single_title と single_url の指定が必須です。

  ```json lines
  {
      "msgtype": "action_card",
      "action_card": {
          "title": "チャットリストと通知に表示されるテキスト",
          "markdown": "markdown形式に対応した本文内容",
          "single_title": "詳細を見る",
          "single_url": "https://open.dingtalk.com"
      }
  }
  ```
- 独立リダイレクト ActionCard スタイルは、複数のクリック Action をサポートし、パラメータ btn_orientation と btn_json_list の指定が必須です。

  ```json lines
  {
      "msgtype": "action_card",
      "action_card": {
          "title": "チャットリストと通知に表示されるテキスト",
          "markdown": "markdown形式に対応した本文内容",
          "btn_orientation": "1",
          "btn_json_list": [
              {
                  "title": "ボタン1",
                  "action_url": "https://www.taobao.com"
              },
              {
                  "title": "ボタン2",
                  "action_url": "https://www.tmall.com"
              }
          ]
      }
  }
  ```

### パラメータ説明：

| 名前 | タイプ | 必須 | 例 | 説明 |
| --- | --- | --- | --- | --- |
| msgtype | String | はい | action_card | メッセージタイプ。カードメッセージのタイプは action_card です。 |
| action_card.markdown | String | はい | markdown形式に対応した本文内容 | メッセージ内容。Markdown をサポートし、構文は標準 Markdown 構文を参照してください。1000 文字以内を推奨します。 |
| action_card.title | String | いいえ | テストタイトル | チャットリストと通知に表示されるテキスト。222 |
| action_card.single_title | String | いいえ | 詳細を見る | 全体リダイレクト ActionCard スタイルを使用する際のタイトル。single_url と同時に設定する必要があり、最長 20 文字です。  **説明**  全体リダイレクトの ActionCard スタイルの場合、**single_title** と **single_url** は必ず設定してください。 |
| action_card.single_url | String | いいえ | https://open.dingtalk.com | メッセージクリック時のリンクアドレス。[メディアファイルのアップロード](/ja/open/development/upload-media-files) インターフェースを呼び出して取得します。送信メッセージがミニプログラムの場合はミニプログラムへのリダイレクトリンクをサポートし、最長 500 文字です。 |
| action_card.btn_orientation | String | いいえ | 0 | 独立リダイレクト ActionCard スタイルを使用する際のボタン配置方式：   - **0**：縦並び - **1**：横並び  btn_json_list と同時に設定する必要があります。 |
| action_card.btn_json_list | JSONArray | いいえ |  | 独立リダイレクト ActionCard スタイルを使用する際のボタンリスト。btn_orientation と同時に設定する必要があり、長さは 1000 文字以内です。  **説明**  独立リダイレクトの ActionCard スタイルの場合、btn_json_list と btn_orientation は必ず設定してください。 |
| action_card.btn_json_list.title | String | いいえ | ボタン2 | 独立リダイレクト ActionCard スタイルを使用する際のボタンのタイトル。最長 20 文字です。 |
| action_card.btn_json_list.action_url | String | いいえ | https://www.tmall.com | 独立リダイレクト ActionCard スタイルを使用する際のリダイレクトリンク。最長 700 文字です。 |
