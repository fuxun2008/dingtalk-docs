---
title: "フィルター条件の設定"
description: "指定列にフィルター条件を設定し、データ表示範囲を厳密に制御します"
---

本 API を呼び出すと、グローバルフィルター内の指定列にフィルター条件を設定または更新できます。単一列のデータ表示範囲を厳密に制御したい場合に適しています。

## API 呼び出し説明

新しく設定した条件は、その列の既存のフィルター条件を上書きします。条件を満たさない行は自動的に非表示になります。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | `https://api.dingtalk.io/v1.0/doc/workbooks/{workbookId}/sheets/{sheetId}/filter/setColumnFilterCriteria` |
| HTTP Method | POST |
| サポートするアプリタイプ | appType-社内アプリ |
| 権限要件 | permission-Document.Workbook.Write-スプレッドシート書き込み権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | はい | 本 API を呼び出すためのアクセス認証情報です。[社内アプリの accessToken を取得](/ja/open/development/obtain-the-access-token-of-an-internal-app) API を呼び出して取得できます。 |

### パスパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| workbookId | String | はい | スプレッドシートファイルの ID です。[ナレッジベース API](/ja/open/development/knowledge-base-overview) が返す `nodeId(dentryUuid)` がスプレッドシートの `workbookId` に該当します。[ノードを取得](https://open.dingtalk.com/document/orgapp/get-node) および [ナレッジベースドキュメントを作成](/ja/open/development/create-team-space-document) API を呼び出して取得できます。 |
| sheetId | String | はい | ワークシートの ID または名前です。[全ワークシートを取得](/ja/open/development/obtain-all-worksheets) API を呼び出して id または name パラメータの値を取得できます。 |

### クエリパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| operatorId | String | はい | 操作者の unionId です。   - [サイレントログインコードでユーザー情報を取得](/ja/open/development/obtain-the-userid-of-a-user-by-using-the-log-free) API で unionid パラメータの値を取得できます。 - [ユーザー詳細を照会](/ja/open/development/query-user-details) API を呼び出して unionid パラメータの値を取得できます。       操作者に権限がない場合、API は `The operator has no permission` というエラーを返します。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| column | Long | はい | 列オフセット。フィルター範囲の先頭列を基準とし、0 から始まります。例えばフィルター範囲が `B1:E10` の場合、`column=0` は B 列、`column=1` は C 列を表します。 |
| filterCriteria | Object | はい | フィルター条件オブジェクト。 |
| filterType | String | はい | フィルタータイプ。指定可能な値:   - **values**: 値で絞り込み - **color**: 色で絞り込み - **condition**: 条件で絞り込み |
| visibleValues | Array of String | いいえ | 表示する値 |
| backgroundColor | String | いいえ | 背景色で絞り込む際の表示色。16 進数形式（例: `#FF0000`）。`filterType` が `color` の場合、`backgroundColor` と `fontColor` のいずれかを必須で指定します。 |
| fontColor | String | いいえ | フォント色で絞り込む際の表示色。16 進数形式（例: `#00FF00`）。`filterType` が `color` の場合、`backgroundColor` と `fontColor` のいずれかを必須で指定します。 |
| conditions | Array | いいえ | 条件で絞り込む際の条件リスト。最大 2 件まで指定できます。`filterType` が `condition` の場合は必須です。 |
| operator | String | いいえ | 条件演算子。指定可能な値:   - **equal**: 等しい - **not-equal**: 等しくない - **contains**: 含む - **not-contains**: 含まない - **starts-with**: ～で始まる - **not-starts-with**: ～で始まらない - **ends-with**: ～で終わる - **not-ends-with**: ～で終わらない - **greater**: より大きい - **greater-equal**: 以上 - **less**: より小さい - **less-equal**: 以下 |
| value | String | いいえ | 比較値 |
| conditionOperator | String | いいえ | 複数条件間の論理関係。指定可能な値: **and**: かつ（デフォルト） **or**: または。 `conditions` に 2 件の条件が含まれる場合に有効です。 |
