本インターフェースを呼び出して、データテーブルにフィールドを作成します。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | `https://api.dingtalk.io/v1.0/notable/bases/{baseId}/sheets/{sheetIdOrName}/fields` |
| HTTP Method | POST |
| サポートされるアプリタイプ | appType-社内アプリ |
| 必要な権限 | permission-Notable.Base.Write.All-AIテーブルアプリ書き込み権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | はい | 本インターフェースを呼び出すためのアクセス認証情報です。[社内アプリのアクセストークンの取得](/ja/open/development/obtain-the-access-token-of-an-internal-app#)インターフェースを呼び出して取得します。 |

### パスパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| baseId | String | はい | AIテーブル ID。取得方法は[データ構造](/ja/open/development/data-structure#)を参照してください。 |
| sheetIdOrName | String | はい | データテーブル ID またはデータテーブル名。データテーブル ID は以下の 2 つの方法で取得できます。   - [すべてのデータテーブルの取得](/ja/open/development/api-notable-getallsheets#)インターフェースを呼び出して取得します。 - [データテーブルの取得](/ja/open/development/api-notable-getsheet#)インターフェースを呼び出して取得します。 |

### クエリパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| operatorId | String | はい | 操作者の unionId。以下の 2 つの方法で取得できます。   - [ユーザー詳細のクエリ](/ja/open/development/query-user-details#)インターフェースを呼び出して取得します。 - [サイレントログインコードによるユーザー情報の取得](/ja/open/development/obtain-the-userid-of-a-user-by-using-the-log-free#)インターフェースを呼び出して取得します。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| name | String | はい | フィールド名。 |
| property | `Map<String, Any>` | いいえ | フィールド属性。具体的なフォーマットは[フィールド属性](https://open.dingtalk.com/document/development/field-properties#)を参照してください。 |
|  | Any | いいえ | フィールド属性。 |
| type | String | はい | フォールド種類。 |
