---
title: "絞り込み結果の並び替え"
---

本 API を呼び出すと、グローバル絞り込み範囲内のデータを指定列で昇順または降順に並び替えできます。絞り込み後のデータを順序付きで表示する必要があるシーン、例えば売上データを金額の高い順に並べたり、タスクリストを締切日の昇順に並べたりする用途に適しています。

## API 呼び出し説明

並び替え操作は、ワークシート内のデータ行の実際の格納順序を永続的に変更するものであり、単に表示順序を変えるだけではありません。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | `https://api.dingtalk.io/v1.0/doc/workbooks/{workbookId}/sheets/{sheetId}/filter/sort` |
| HTTP Method | POST |
| サポートするアプリタイプ | appType-社内アプリ |
| 必要な権限 | permission-Document.Workbook.Write-DingTalk スプレッドシート書き込み権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | 必須 | 本 API を呼び出すためのアクセス認証情報。[社内アプリの accessToken を取得](/ja/open/development/obtain-the-access-token-of-an-internal-app) API を呼び出して取得します。 |

### パスパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| workbookId | String | 必須 | スプレッドシートファイル ID。[ナレッジベース API](https://open.dingtalk.io/document/orgapp/knowledge-base-overview) が返す `nodeId(dentryUuid)` がスプレッドシートの `workbookId` です。[ノード取得](https://open.dingtalk.io/document/orgapp/get-node) および [ナレッジベースドキュメント作成](https://open.dingtalk.io/document/orgapp/create-team-space-document) API を呼び出して取得できます。 |
| sheetId | String | 必須 | ワークシートの ID または名前。[全ワークシート取得](https://open.dingtalk.io/document/orgapp/obtain-all-worksheets) API を呼び出して id または name パラメータの値を取得できます。 |

### クエリパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| operatorId | String | 必須 | 操作者の unionId。   - [サイレントログインコードによるユーザー情報取得](https://open.dingtalk.io/document/orgapp/obtain-the-userid-of-a-user-by-using-the-log-free) API で unionid パラメータの値を取得できます。 - [ユーザー詳細取得](https://open.dingtalk.io/document/orgapp/query-user-details) API を呼び出して unionid パラメータの値を取得できます。       操作者に権限がない場合、API は `The operator has no permission` エラーを返します。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| field | Object | 必須 | 並べ替えルールオブジェクト。 |
| column | Long | 必須 | 列オフセット。絞り込み範囲の先頭列を基準とし、0 から始まります。 |
| ascending | Boolean | 任意 | 昇順で並び替えるかどうか。デフォルトは `true`（昇順）。`false` に設定すると降順になります。 |

### リクエスト例
