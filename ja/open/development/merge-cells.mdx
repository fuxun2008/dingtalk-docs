本 API を呼び出すことで、DingTalk スプレッドシート内の指定範囲にある複数のセルを 1 つに結合できます。表のヘッダーで列をまたぐ見出しを作成したり、同じ分類の行を結合したりするなど、セルレイアウトを調整するシーンに適しています。すべて結合・行単位で結合・列単位で結合の 3 種類のモードに対応しており、結合後は左上のセルのデータのみが保持され、その他のセルの内容はクリアされます。レスポンスでは実際に操作されたセルのアドレスが返されます。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | `https://api.dingtalk.io/v1.0/doc/workbooks/{workbookId}/sheets/{sheetId}/ranges/{rangeAddress}/merge` |
| HTTP Method | POST |
| 対応するアプリタイプ | appType-社内アプリ |
| 必要な権限 | permission-Document.Workbook.Write-DingTalk スプレッドシートの書き込み権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | はい | 本 API を呼び出すためのアクセス認証情報。[社内アプリの access_token を取得する](https://open.dingtalk.io/document/development/obtain-the-access-token-of-an-internal-app) API を呼び出して取得できます。 |

### パスパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| workbookId | String | はい | スプレッドシートファイルの ID。[ナレッジベース API](https://open.dingtalk.io/document/development/knowledge-base-overview) から返される nodeId（dentryUuid）がスプレッドシートの workbookId です。[ノードを取得する](https://open.dingtalk.io/document/development/get-knowledge-base-acquisition-node) および [ナレッジベースドキュメントを作成する](https://open.dingtalk.io/document/development/create-team-space-document) API を呼び出して取得できます。 |
| sheetId | String | はい | ワークシートの ID またはタイトル。[すべてのワークシートを取得する](https://open.dingtalk.io/document/development/obtain-all-worksheets) API を呼び出して id およびワークシートのタイトルを取得できます。 |
| rangeAddress | String | はい | 結合対象のセル範囲。フォーマットは `範囲内の左上のセル:範囲内の右下のセル` です。例：B2:C3 |

### クエリパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| operatorId | String | はい | 操作者の unionId。[ユーザー詳細を照会する](https://open.dingtalk.io/document/development/query-user-details) API を呼び出して取得できます。操作者に権限がない場合、API は `The operator has no permission` というエラーを返します。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| mergeType | String | いいえ | セルの結合方法を指定します。指定可能な値：   - **mergeAll**：すべてのセルを結合します（デフォルト） - **mergeRows**：行単位で結合します。選択範囲内で同じ行の隣接するセルを 1 つのセルに結合します - **mergeColumns**：列単位で結合します。選択範囲内で同じ列の隣接するセルを 1 つのセルに結合します |

### リクエスト例

HTTP

```http
POST /v1.0/doc/workbooks/e54Lq3xxx/sheets/Sheet1/ranges/A1:B1/merge?operatorId=ppgAQuxxx HTTP/1.1
Host:api.dingtalk.io
x-acs-dingtalk-access-token:token:f86e0bxxx
Content-Type:application/json

{
  "mergeType" : "mergeRows"
}
```
