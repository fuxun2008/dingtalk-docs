---
title: "ファイルまたはフォルダーの移動"
---

本インターフェースを呼び出すことで、ファイルまたはフォルダーを任意の場所に移動できます。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | `https://api.dingtalk.io/v1.0/storage/spaces/{spaceId}/dentries/{dentryId}/move` |
| HTTP Method | POST |
| サポートするアプリタイプ | appType-社内アプリ　appType-サードパーティ社内アプリ |
| 必要な権限 | permission-Storage.File.Write-企業ストレージファイル書き込み権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | はい | 本インターフェースを呼び出すためのアクセス認証情報。以下の方法で取得します：   - 社内アプリの場合、[社内アプリのaccessTokenを取得](https://open.dingtalk.io/document/development/obtain-the-access-token-of-an-internal-app)インターフェースを呼び出して取得します。 - サードパーティ社内アプリの場合、[サードパーティアプリで権限付与された企業のaccessTokenを取得](https://open.dingtalk.io/document/development/obtain-the-access-token-of-the-authorized-enterprise-1)インターフェースを呼び出して取得します。 |

### パスパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| spaceId | String | はい | ファイルまたはフォルダーが存在する元スペースのId。[スペースの追加](https://open.dingtalk.io/document/development/add-space)インターフェースを呼び出してidパラメータ値を取得できます。 |
| dentryId | String | はい | 移動対象のファイルまたはフォルダーId。[ファイルまたはフォルダーリストの取得](https://open.dingtalk.io/document/development/get-a-list-of-files-or-folders)または[dentryUuidからspaceIdとdentryIdを取得](https://open.dingtalk.io/document/development/api-getdentryidbyuuid)インターフェースを呼び出してidパラメータ値を取得できます。 |

### クエリパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| unionId | String | はい | 操作者のunionId。[ユーザー詳細の照会](https://open.dingtalk.io/document/development/query-user-details)インターフェースを呼び出してunionidパラメータ値を取得できます。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| targetSpaceId | String | はい | 格納先となる対象スペースのId。[スペースの追加](https://open.dingtalk.io/document/development/add-space)インターフェースを呼び出してidパラメータ値を取得できます。 |
| targetFolderId | String | はい | 格納先となる親ディレクトリのId。[ファイルまたはフォルダーリストの取得](https://open.dingtalk.io/document/development/get-a-list-of-files-or-folders)インターフェースを呼び出してidパラメータ値を取得できます。  ルートディレクトリの場合、このパラメータは0です。 |
| option | Object | いいえ | オプションパラメータ。 |
| conflictStrategy | String | いいえ | ファイルおよびフォルダー名の競合戦略。   - **AUTO_RENAME**（デフォルト）：自動的に名前を変更 - **OVERWRITE**：上書き - **RETURN_DENTRY_IF_EXISTS**：既存のファイルを返却 - **RETURN_ERROR_IF_EXISTS**：ファイルが既に存在する場合エラーを返す |
| presevePermissions | Boolean | いいえ | 移動後に権限を保持するかどうか：   - **true**：はい - **false**：いいえ（デフォルト） |
