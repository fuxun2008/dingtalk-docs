この記事では、社内アプリ、開発プロセス、権限に関するよくある質問を解説します。

## **組織認証アプリとは**

組織認証アプリとは、組織レベルのアプリです。DingTalk の初期バージョンから提供されているアプリ形式です。このタイプのアプリを使用するには、組織の固有識別子（Organization ID、つまり CorpId）とセキュリティキー（Organization Secret、つまり CorpSecret）に基づいて、専用の API 認証情報を生成する必要があります。生成した API 認証情報を使用すると、OpenAPI、Webhook、Stream などの開発機能にアクセスして利用できます。

**注意**

組織認証コールを表示・管理できるのは組織の管理者のみです。その他のメンバーはこれらの操作を行えません。

## **組織認証コールとは**

[DingTalk 開発者コンソール](https://open-dev.dingtalk.com/) にログインし、**その他** > **基本情報** > [開発情報（レガシー）](https://open-dev.dingtalk.com/fe/old#/corpAuthInfo) をクリックします。ここで、Organization ID（CorpId）と Organization Secret（CorpSecret）を確認して記録できます。この 2 つの値を使用して、OpenAPI にアクセスするための専用の API 認証情報を生成できます。このプロセスを組織認証コールと呼びます。

> これは初期の Open Platform のレガシー製品です。必要な場合は、社内アプリを通じて OpenAPI を呼び出すことをおすすめします。詳しくは、[社内アプリの access_token を取得する](/ja/open/development/obtain-the-access-token-of-an-internal-app) をご覧ください。

## **組織認証コールを停止する方法**

組織認証コール機能を無効にする必要がある場合、Organization Secret（CorpSecret）を直接削除することはできません。認証コールの使用を停止したい場合は、開発権限を持つスーパー管理者が行えます。具体的には、バインドされている IP アドレスを無効なアドレスに変更することで、組織認証コールを無効化します。

## ワークベンチで社内アプリが見つからない

回答：ワークベンチで該当するアプリが見つからない場合は、次の手順に従って問題をトラブルシューティングしてください。

1. 現在のワークベンチの組織が、アプリの所属する組織と一致していることを確認します。
2. アプリが公開されていることを確認します。管理者に依頼して、[開発者コンソール](https://open-dev.dingtalk.com/#/) **> 対象アプリ > バージョン管理とリリース** にアクセスし、アプリが公開状態になっているかどうかを確認してください。
3. アプリの利用可能範囲を確認します。管理者に依頼して、[開発者コンソール](https://open-dev.dingtalk.com/#/) **> 対象アプリ > バージョン管理とリリース** にアクセスし、アプリを見つけられないユーザーが利用可能範囲に含まれているかどうかを確認してください。

## ミニプログラム IDE で社内アプリをデバッグすると「申し訳ありませんが、このアプリの利用可能範囲に含まれていません。設定を変更するには管理者に連絡してください」と表示される

回答：社内アプリのデバッグ時にこのメッセージが表示される考えられる原因には、以下が含まれますが、これらに限定されません。

1. 社内アプリをデバッグしている人が開発者リストに含まれていない。[開発者コンソール](https://open-dev.dingtalk.com/#/) **> 対象アプリ > ユーザー管理** で開発者を設定してください。
2. 社内アプリのバージョンがアップロードされていない。ミニプログラム IDE でアプリのバージョンをアップロードし、その後 [開発者コンソール](https://open-dev.dingtalk.com/#/) **> 対象アプリ > バージョン管理とリリース** でバージョンをリリースしてください。
3. [開発者コンソール](https://open-dev.dingtalk.com/#/) **> 対象アプリ > バージョン管理とリリース > 利用可能範囲** でユーザーが設定されていない。

   **注意**

   社内アプリのミニプログラムでは、ミニプログラム IDE でバージョンをアップロードし、バージョン管理とリリースでバージョンをリリースした後にのみ、利用可能範囲が表示されます。

## 社内マイクロアプリまたはミニプログラムに AppKey または AppSecret がない

回答：作成したアプリに AppKey と AppSecret が表示されない理由は、以下のとおりです。

- 開発者コンソールで社内アプリを作成する際に、下図のように開発方法として **委託サービスプロバイダーによる開発** を選択した場合、これらの値がアプリ管理に表示されません。

  **注意**

  委託開発が実際には必要ない場合は、**自社開発** を選択してください。

- あなたがアプリの作成者ではなく、AppKey と AppSecret を表示するための該当する権限を持っていない。[DingTalk 管理コンソール](https://oa.dingtalk.com/#/welcome) **> 安全と権限 > 権限管理** ページで、対応するアプリ管理権限を追加するようスーパー管理者に連絡してください。
