---
title: "段落の末尾にインライン要素を追加"
---

本 API を呼び出すことで、指定した段落の末尾にインライン要素を 1 つ追加します。ステッカー（Sticker）、画像（Image）、リンク（Link）などのタイプのインライン要素の追加に対応しています。

## API 呼び出し説明

ドキュメントコンテンツに関連するデータ構造については、[ドキュメントデータ構造](https://open.dingtalk.io/document/development/document-data-structure) を参照してください。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | `https://api.dingtalk.io/v1.0/doc/suites/documents/{docKey}/blocks/{blockId}/paragraph/appendElement` |
| HTTP Method | POST |
| 対応アプリタイプ | appType-社内アプリ |
| 必要権限 | permission-Storage.File.Write-企業ストレージファイル書き込み権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | 必須 | 本 API を呼び出すためのアクセス認証情報。[社内アプリの access_token を取得](https://open.dingtalk.io/document/development/obtain-the-access-token-of-an-internal-app) API を呼び出して取得します。 |

### パスパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| docKey | String | 必須 | ドキュメント ID（ドキュメントの docKey または dentryUuid）。[ナレッジベースドキュメントを作成](https://open.dingtalk.io/document/development/create-team-space-document) API でドキュメントを作成した後、戻り値から `docKey` パラメータを取得します。      ドキュメント URL から `dentryUuid` を取得することも可能です。例えば https://alidocs.dingtalk.io/i/nodes/Zxxxxa-id の場合、dentryUuid は Zxxxxa-id です。 |
| blockId | String | 必須 | 対象段落の一意な識別子。[ブロック要素をクエリ](https://open.dingtalk.io/document/development/api-docblocksquery) API を呼び出して `blockId` パラメータを取得します。 |

### クエリパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| operatorId | String | 必須 | ユーザーの unionId。[ユーザー詳細をクエリ](https://open.dingtalk.io/document/development/query-user-details) API を呼び出して unionid パラメータ値を取得します。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| elementType | String | 必須 | インライン要素のタイプ。詳細は [ブロック要素データ構造](https://open.dingtalk.io/document/development/block-data-structure) のインライン要素タイプを参照してください。 |
| properties | `Map<String, Any>` | 必須 | 対応する `elementType` タイプのインライン要素を作成するために必要な属性。 |
|  | Any | 任意 | 属性値。 |
