---
title: "リソースアップロード情報の取得"
---

この API を呼び出して、ドキュメント内の指定リソースのアップロードアドレスを照会します。

## API 呼び出し説明

リソースとは、ドキュメント内の画像やファイルなどの添付を指します。本 API は通常、他プロダクトの添付アップロード API と組み合わせて使用します。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | `https://api.dingtalk.io/v1.0/doc/docs/resources/{docId}/uploadInfos/query` |
| HTTP Method | POST |
| 対応アプリタイプ | appType-社内アプリ |
| 必要な権限 | permission-Storage.File.Read-企業ストレージファイル読み取り権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | はい | この API を呼び出すためのアクセス認証情報。[社内アプリの accessToken を取得](https://open.dingtalk.io/document/development/obtain-the-access-token-of-an-internal-app#) API を呼び出して取得します。 |

### パスパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| docId | String | はい | ドキュメント ID (dentryUuid/documentId/workbookId/baseId)。以下の 2 つの方法で取得できます：   - [ナレッジベースドキュメントの作成](https://open.dingtalk.io/document/development/create-team-space-document#) API を呼び出して取得します。 - [ノードリストの取得](https://open.dingtalk.io/document/development/get-node-list#) API を呼び出して取得します。 |

### クエリパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| operatorId | String | はい | 操作者の unionId。[ユーザー詳細の照会](https://open.dingtalk.io/document/development/query-user-details#) API または [サイレントログインコードでユーザー情報を取得](https://open.dingtalk.io/document/development/obtain-the-userid-of-a-user-by-using-the-log-free#) API を呼び出して取得します。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| size | Long | はい | リソースのサイズ。単位：バイト。 |
| mediaType | String | はい | リソースのタイプ。具体的な値は [MIME Types](https://developer.mozilla.org/zh-CN/docs/Web/HTTP/Guides/MIME_types/Common_types) を参照してください。 |
| resourceName | String | はい | リソース名。 |

### リクエスト例

HTTP

```http
POST /v1.0/doc/docs/resources/xxxxx/uploadInfos/query?operatorId=xxxxx HTTP/1.1
Host:api.dingtalk.io
x-acs-dingtalk-access-token:xxxxx
Content-Type:application/json

{
  "size" : 200,
  "mediaType" : "image/jpeg",
  "resourceName" : "logo.jpg"
}
```
