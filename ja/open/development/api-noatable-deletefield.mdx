本インターフェースを呼び出して、AIテーブル内のフィールドを 1 件削除します。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | `https://api.dingtalk.io/v1.0/notable/bases/{baseId}/sheets/{sheetIdOrName}/fields/{fieldIdOrName}` |
| HTTP Method | DELETE |
| 対応アプリタイプ | appType-社内アプリ |
| 必要な権限 | permission-Notable.Base.Write.All-AIテーブルアプリ書き込み権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | はい | 本インターフェースを呼び出すためのアクセス認証情報です。[社内アプリの access_token を取得](https://open.dingtalk.io/document/development/obtain-the-access-token-of-an-internal-app#)インターフェースを呼び出して取得します。 |

### パスパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| baseId | String | はい | AIテーブル ID です。取得方法については[データ構造](https://open.dingtalk.io/document/development/data-structure#)をご参照ください。 |
| sheetIdOrName | String | はい | データテーブル ID またはデータテーブル名です。データテーブル ID は以下の 2 つの方法で取得できます。   - [すべてのデータテーブルを取得](https://open.dingtalk.io/document/development/api-notable-getallsheets#)インターフェースを呼び出して取得します。 - [データテーブルを取得](https://open.dingtalk.io/document/development/api-notable-getsheet#)インターフェースを呼び出して取得します。 |
| fieldIdOrName | String | はい | フィールド ID またはフィールド名です。フィールド ID は[すべてのフィールドを取得](https://open.dingtalk.io/document/development/api-noatable-getallfields#)インターフェースを呼び出して取得できます。 |

### クエリパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| operatorId | String | はい | 操作者の unionId です。以下の 2 つの方法で取得できます。   - [ユーザー詳細の照会](https://open.dingtalk.io/document/development/query-user-details#)インターフェースを呼び出して取得します。 - [サイレントログインコードによるユーザー情報の取得](https://open.dingtalk.io/document/development/obtain-the-userid-of-a-user-by-using-the-log-free#)インターフェースを呼び出して取得します。 |
