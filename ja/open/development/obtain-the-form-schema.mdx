---
title: "フォームスキーマの取得"
description: "processCode を指定して OA 承認フォームのフォームスキーマを取得する API です。"
---

この API を呼び出し、processCode を指定してフォームのスキーマを取得します。

## リクエスト

### ベーシック情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/v1.0/workflow/forms/schemas/processCodes |
| HTTP メソッド | GET |
| 対応するアプリの種類 | appType-社内アプリ　appType-サードパーティ社内アプリ |
| 権限 | permission-Workflow.Form.Read-作業フローテンプレートの読み取り権限 |

### リクエストヘッダー

| 名前 | 型 | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | はい | この API を呼び出すためのアクセス認証情報です。次の方法で取得します。   - 社内アプリ：[社内アプリのアクセストークンを取得](/ja/open/development/obtain-the-access-token-of-an-internal-app) API を呼び出します。 - サードパーティ社内アプリ：サードパーティアプリに権限を付与した組織のアクセストークンを取得する API を呼び出します。 |

### クエリパラメータ

| 名前 | 型 | 必須 | 説明 |
| --- | --- | --- | --- |
| processCode | String | はい | フォーム固有のコードです。[承認フォームテンプレートの作成または更新](/ja/open/development/create-an-approval-form-template) API を呼び出して取得するか、[OA承認の概要 - 用語集](/ja/open/development/workflow-overview)を参照してください。 |
| appUuid | String | いいえ | アプリ構築用の分離情報です。 |

| props | Object | 子コントロールの属性です。 |
| id | String | コントロール ID です。 |
| label | String | コントロール名です。 |
| bizAlias | String | コントロールの業務エイリアスです。 |

| icon | String | アイコンです。 |

| bizType | String | フォームの業務上の意味を表す種類です。 |
| engineType | Integer | エンジンの種類です。有効な値：   - 1：ページ - 0：フォーム |

| listOrder | Integer | 並べ替え ID です。 |
| customSetting | String | カスタム業務設定のデータです。 |
| procType | String | 対象の種類です。有効な値：   - inner：社内 - outer：社外 - customer：カスタム |
| visibleRange | String | 公開スコープの種類です。 |
| gmtCreate | String | 作成時間のタイムスタンプです。 |
