本ドキュメントでは、ミニプログラム、Web アプリ、クールアプリ、ボットを含む DingTalk アプリの多彩な機能について理解を深めます。

## **ミニプログラム**

ミニプログラムは、DingTalk 内で利用する軽量なアプリです。共同オフィスワーク、人事管理、企業サービス、業務プロセスなど、幅広いシーンに対応します。

Web アプリと比較して、DingTalk のミニプログラム開発モデルは React Native や Weex に類似した開発フレームワークを採用しています。これにより、簡潔なフロントエンド構文で Native レベルのパフォーマンス体験を記述でき、iOS や Android など複数のプラットフォームへのデプロイに対応します。

## **Web アプリ**

Web アプリは、Web 技術で開発された軽量なアプリです。豊富なネイティブコントロール機能を呼び出すことができ、デバイスの基本情報や位置情報などのスマートフォンシステム機能へ効率的にアクセスできます。また、Scan、Share、Drive などの DingTalk 独自機能を直接利用でき、マイクロアプリにネイティブコードに近い体験をもたらします。

## **クールアプリ**

クールアプリは、グループ、ドキュメント、音声／動画などのシーンにおいて、複雑なアプリロジックをカード形式のインタラクションでユーザーに提示し、すばやいアクセスを可能にします。

## **ボット**

ボットは独立したアプリ機能です。すぐに利用できるうえ、二次開発にも対応します。グループなどの他のアプリやシーンと密接に結び付ける必要はありません。簡単な設定だけで、ボットを使って業務情報やタスクを配信し、DingTalk のチャットシーンで俊敏なコラボレーションを実現できます。

## **ミニプログラムと Web アプリの違い**

ミニプログラムと Web アプリの違いは次のとおりです。

| **比較項目** | **ミニプログラム** | **H5 マイクロアプリ** |
| --- | --- | --- |
| **対応プラットフォーム** | モバイルと PC に対応   - Android - iOS - Windows - Mac | モバイルと PC に対応   - Android - iOS - Windows - Mac |
| **読み込みパフォーマンス** | 初回利用時はやや遅いが、以降の読み込みは高速 | 多くの要因に左右され、最適化が難しく、遅くなりやすい |
| **実行時パフォーマンス** | スムーズで Native に近い | 動作が重くなりやすい |
| **ページ遷移／切り替え** | Native と同等の効果 | Native と同等の効果は実現できない |
| **開発環境の構築** | DingTalk 開発者ツールを提供し、プロジェクトを素早く作成可能 | DingTalk 開発者ツールを提供し、プロジェクトを素早く作成可能 |
| **デバッグ** | DingTalk 開発者ツールを提供し、ほとんどの機能をコンピューター上でデバッグ可能 | コンピューター上では UI のみデバッグ可能。DingTalk JSAPI が関わる部分は実機でデバッグする必要がある |
| **オープンソース UI コンポーネントの利用** | 現在は未対応 | 対応 |
| **NPM パッケージの利用** | 対応 | 対応 |
| **モジュール化されたコード構成** | ミニプログラム専用のモジュール化に対応 | Vue や React などのフレームワークがモジュール化をサポート |
| **グレーリリース** | DingTalk が提供 | 開発者が実装する必要がある |
| **CDN** | ミニプログラムのパッケージはデフォルトで CDN 上に配置 | 開発者が関連サービスを自身で購入する必要がある |
| **個人アプリの開発** | 対応 | 未対応 |
| **オフラインアプリのサポート** | 対応 | 対応 |
