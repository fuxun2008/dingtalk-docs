本インターフェースを呼び出して、ノードリストを取得します。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/v2.0/wiki/nodes |
| HTTP Method | GET |
| サポートされるアプリタイプ | appType-社内アプリ　appType-サードパーティ社内アプリ |
| 権限要件 | permission-Wiki.Node.Read-ナレッジベースノード読み取り権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | はい | 本インターフェースを呼び出すためのアクセス認証情報。以下の方法で取得します：   - 社内アプリの場合は、[社内アプリのアクセストークン取得](/ja/open/development/obtain-the-access-token-of-an-internal-app#)インターフェースを呼び出して取得します。 - サードパーティ社内アプリの場合は、[サードパーティアプリが認可された企業のアクセストークン取得](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#)インターフェースを呼び出して取得します。 |

### クエリパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| parentNodeId | String | はい | 親ノード ID（親ノード dentryUuid）。[ナレッジベースリスト取得](/ja/open/development/get-knowledge-base-list#)インターフェースを呼び出し、レスポンスパラメータの`rootNodeId`フィールドから取得できます。 |
| nextToken | String | いいえ | ページネーションカーソル。初回取得時は指定不要です。 |
| maxResults | Integer | いいえ | ページサイズ。デフォルトは 50。    最大値は 50。 |
| withPermissionRole | Boolean | いいえ | 権限情報を取得するかどうか：   - true：取得する - false：取得しない     デフォルトは false。 |
| operatorId | String | はい | 操作者の unionId。 |
