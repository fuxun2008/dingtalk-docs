この API を呼び出すと、ユーザーの userId に基づいて、そのユーザーの承認待ち件数を取得できます。

## API 呼び出し説明

以下のリンクから対象ページを開くと、DingTalk 承認の **自分の承認待ち** ページにリダイレクトされます。URL の組み立て例は次のとおりです：https://aflow.dingtalk.io/dingtalk/mobile/homepage.htm?showmenu=false&dd_share=false&corpid=ding1\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*288#/upcoming?swfrom=work_homepage

## リクエスト

### ベーシック情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/v1.0/workflow/processes/todoTasks/numbers |
| HTTP メソッド | GET |
| 対応アプリタイプ | appType-社内アプリ |
| 権限 | permission-Workflow.Instance.Read-作業フローインスタンスの読み取り権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | はい | この API を呼び出すためのアクセス認証情報です。[社内アプリのアクセストークンを取得](/ja/open/development/obtain-the-access-token-of-an-internal-app) API を呼び出して取得してください。 |

### クエリパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| userId | String | はい | 照会対象ユーザーの userId です。 |

### リクエスト例

HTTP

```http
GET /v1.0/workflow/processes/todoTasks/numbers?userId=manager123 HTTP/1.1
Host:api.dingtalk.io
x-acs-dingtalk-access-token:6d1bxxxx
Content-Type:application/json
```
