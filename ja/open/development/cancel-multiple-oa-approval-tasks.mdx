description: "ワークフローインスタンス ID とタスクグループ ID を指定して、プロセスセンターの未処理タスクを一括キャンセルする API です。"
---

プロセスセンターの未処理タスクを一括でキャンセルします。processInstanceId、activityId、activityIds などの業務フィールドを指定して POST リクエストを送信してください。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/v1.0/workflow/processCentres/tasks/cancel |
| HTTP メソッド | POST |
| 対応アプリタイプ | appType-社内アプリ　appType-サードパーティ社内アプリ |
| 権限 | permission-Workflow.Instance.Write-ワークフローインスタンスの書き込み権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | はい | この API を呼び出すためのアクセス認証情報です。取得方法は次のとおりです。   - 社内アプリの場合は、[社内アプリのアクセストークンを取得](/ja/open/development/obtain-the-access-token-of-an-internal-app) API を呼び出します。 - サードパーティ社内アプリの場合は、サードパーティアプリを承認した組織のアクセストークンを取得する API を呼び出します。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| processInstanceId | String | はい | OA承認のワークフローインスタンス ID です。[インスタンスを作成](/ja/open/development/create-a-ticket-approval-instance) API を呼び出して processInstanceId の値を取得します。 |
| activityId | String | はい | タスクグループ ID です。[プロセスセンターの未処理タスクを作成](/ja/open/development/create-pending-tasks-in-process-center) API を呼び出して取得します。最大長は 512 文字です。  プロセスセンターの未処理タスクを作成する API を呼び出す際に、この値を明示的に設定してください。 |
| activityIds | Array of String | いいえ | タスクグループ ID のリストです。[プロセスセンターの未処理タスクを作成](/ja/open/development/create-pending-tasks-in-process-center) API を呼び出して取得します。 |
