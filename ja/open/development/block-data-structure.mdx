オンラインドキュメントは複数のブロック要素から成るツリー構造です。BlockElement のタイプによって内部に入れ子にできる要素タイプが異なります。例えば、ハイライトブロックには任意の `BlockElement` を入れ子にできますが、段落ブロックには InlineElement のみを入れ子にできます。

1 つのブロック要素のデータ構造は以下のとおりです。

```json
{
  "blockType": enum(BlockType),             // ブロック要素のタイプ。詳細はドキュメント末尾の `BlockType` 列挙型を参照してください
  /**
   * 以下はサポートされているすべての Block タイプです（Heading、Paragraph など）。
   * タイプの異なる Block はそれぞれ独自の property を持ちます。
  */
  "blockquote": Object(Callout),
  "callout": Object(Callout),
  "columns": Object(Columns),
  "heading": Object(Heading),
  "paragraph": Object(Paragraph),
  "orderedList": Object(OrderedList)
  "unorderedList": Object(UnorderedList),
  "table": Object(Table),
  // 各 Block にはそれぞれサポートする BlockChildren があります。詳細は各 Block タイプ内の `children` の説明を参照してください

  "children": BlockChildren[ ],

}
```

## ブロック要素データ構造の説明

オンラインドキュメントは、複数の **ブロック要素** から成るツリー構造で構成されます。ブロック要素のタイプによって、入れ子にできる子要素のタイプが異なります。

- `callout`、`columns` の `children` は **BlockElement 配列** のみ指定できます。
- `paragraph`、`heading`、`orderedList`、`unorderedList`、`blockquote` の `children` は **InlineElement 配列** のみ指定できます。
- `table` は現時点で `children` の指定をサポートしていません。

### BlockType 列挙

| 列挙値 | 説明 |
| --- | --- |
| paragraph | 段落ブロック。 |
| heading | 見出しブロック。 |
| blockquote | 引用ブロック。 |
| callout | ハイライトブロック。 |
| columns | カラム分割ブロック。 |
| orderedList | 番号付きリストブロック。 |
| unorderedList | 箇条書きブロック。 |
| table | スプレッドシートブロック。 |
| tableRow | テーブル行ブロック（スプレッドシートブロックの子ブロック）。 |
| tableCell | テーブルセルブロック（スプレッドシートブロックの子ブロック）。 |

> 未サポートの要素タイプは一律 `Undefined` を返します。

### 段落

```json
{
  "blockType": "paragraph",
  "paragraph": {
    "text": "段落テキストの内容",
    "indent": { "left": 32 },
    "folded": false
  },
  "children": [InlineElement]
}
```

| フィールド名 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| text | string | 否 | 段落のテキストコンテンツ。 |
| indent | object(Indent) | 否 | インデント値。`left` は 0 より大きい整数である必要があります。 |
| folded | boolean | 否 | 段落を折りたたむかどうか（現在の段落より indent 値が大きいブロック要素を折りたたむ）。 |

- `children`：**InlineElement 配列**。
- `paragraph` オブジェクトは **省略不可** です。コンテンツが空の場合は `{}` を渡してください。

### 見出し

```json
{
  "blockType": "heading",
  "heading": {
    "level": 1,
    "text": "見出し 1"
  },
  "children": [InlineElement]
}
```

| フィールド名 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| text | string | 否 | 見出しのテキストコンテンツ。 |
| level | integer(enum) | 否 | 見出しレベル。値は `1` ～ `6`。1 は H1 を表します。 |

- `children`：**InlineElement 配列**。

### 引用

```json
{
  "blockType": "blockquote",
  "blockquote": {
    "text": "引用の内容",
    "indent": { "left": 32 }
  },
  "children": [InlineElement]
}
```

| フィールド名 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| text | string | 否 | 引用内のテキスト。 |
| indent | object(Indent) | 否 | 具体的なインデント値。 |

- `children`：**InlineElement 配列**。

### ハイライトブロック

```json
{
  "blockType": "callout",
  "callout": {
    "sticker": "灯泡",
    "showstk": true,
    "color": "#333333",
    "border": "#FFD700",
    "bgcolor": "#FFF9C4"
  },
  "children": [BlockElement]
}
```

| フィールド名 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| sticker | string(enum Emoji) | 否 | 絵文字コード。詳細は [絵文字（Emoji）の列挙値](/ja/open/development/enumeration-values-of-emojis) を参照してください。 |
| showstk | boolean | 否 | 絵文字を表示するかどうか。 |
| color | string | 否 | 文字色。 |
| border | string | 否 | 枠線の色。 |
| bgcolor | string | 否 | 背景色。 |

- `children`：**BlockElement 配列**（InlineElement は不可）。

### カラム分割

```json
{
  "blockType": "columns",
  "columns": {
    "size": 2,
    "noFill": false
  },
  "children": [BlockElement]
}
```

| フィールド名 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| size | number | 否 | カラムの数。 |
| noFill | boolean | 否 | 背景色を自動で塗りつぶすかどうか。 |

- `children`：**BlockElement 配列**（InlineElement は不可）。

### 番号付きリスト

```json
{
  "blockType": "orderedList",
  "orderedList": {
    "list": {
      "listId": "list-001",
      "level": 0,
      "listStyleType": "decimal",
      "listStyle": {
        "format": "decimal",
        "text": "%1.",
        "align": "left"
      },
      "symbolStyle": {
        "bold": false
      }
    },
    "indent": { "left": 32 }
  },
  "children": [InlineElement]
}
```

| フィールド名 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| list | object(ListObject) | 是 | 番号付きリストの具体的な属性。詳細は [ListObject（リストオブジェクト）](#e6621bc176irg) を参照してください。 |
| indent | object(Indent) | 否 | インデント値。`left` は 0 より大きい整数である必要があります。 |

- `children`：**InlineElement 配列**。

### 箇条書き

```json
{
  "blockType": "unorderedList",
  "unorderedList": {
    "list": {
      "listId": "list-002",
      "level": 0,
      "listStyleType": "disc",
      "listStyle": {
        "format": "disc",
        "text": "%1",
        "align": "left"
      },
      "symbolStyle": {
        "bold": false
      }
    },
    "indent": { "left": 32 }
  },
  "children": [InlineElement]
}
```

| フィールド名 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| list | object(ListObject) | 是 | 箇条書きの具体的な属性。詳細は [ListObject（リストオブジェクト）](#e6621bc176irg) を参照してください。 |
| indent | object(Indent) | 否 | インデント値。`left` は 0 より大きい整数である必要があります。 |

- `children`：**InlineElement 配列**

### スプレッドシート

```json
{
  "blockType": "table",
  "table": {
    "rolSize": 3,
    "colSize": 4,
    "cells": [
      ["Row1-Col1", "Row1-Col2", "Row1-Col3", "Row1-Col4"],
      ["Row2-Col1", "Row2-Col2", "Row2-Col3", "Row2-Col4"],
      ["Row3-Col1", "Row3-Col2", "Row3-Col3", "Row3-Col4"]
    ]
  }
}
```

| フィールド名 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| rolSize | number | 是 | 行数。 |
| colSize | number | 是 | 列数。 |
| cells | String[][] | 否 | セルのテキストコンテンツ。二次元 String 配列。 |

- `children`：children の指定は **現時点でサポートされていません**。

## InlineElement のデータ構造説明

インライン要素は、テキスト系ブロック要素（段落、見出し、リストなど）の `children` で使用します。

### InlineType 列挙

| 列挙値 | 説明 |
| --- | --- |
| text | テキスト。 |
| sticker | 絵文字。 |
| image | 画像。 |
| link | リンク。 |

### テキスト

```json
{
  "text": "太字の赤色テキスト",
  "sz": 16,
  "color": "red",
  "highlight": "yellow",
  "bold": true,
  "italic": false,
  "stike": false,
  "underline": false,
  "fonts": "monospace"
}
```

| フィールド名 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| text | string | 是 | テキストコンテンツ。 |
| sz | number | 否 | フォントサイズ（デフォルト単位は px）。 |
| color | string | 否 | 文字色。 |
| highlight | string | 否 | ハイライト背景色。 |
| bold | boolean | 否 | 太字にするかどうか。 |
| italic | boolean | 否 | 斜体にするかどうか。 |
| stike | boolean | 否 | 取り消し線を引くかどうか。 |
| underline | boolean | 否 | 下線を引くかどうか。 |
| fonts | string(enum Fonts) | 否 | フォント。列挙値は以下のとおり：   - **monospace**：等幅フォント - **STSong**：華文宋体 - **Microsoft YaHei**：微軟雅黒 - **FangSong_GB2312**：仿宋 GB2312 - **Helvetica**：Helvetica フォント - **Helvetica Neue**：Neue Helvetica フォント - **Consolas**：Consolas フォント - **宋体**：宋体 - **Impact**：Impact フォント - **sanrif**：sanrif フォント - **Calibri**：Calibri フォント |

### 絵文字

```json
{
  "elementType": "sticker",
  "properties": {
    "code": "大笑"
  }
}
```

| フィールド名 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| code | string(enum Emoji) | 是 | 絵文字コード。詳細は [絵文字（Emoji）の列挙値](/ja/open/development/enumeration-values-of-emojis) を参照してください。 |

### 画像

```json
{
  "elementType": "image",
  "properties": {
    "src": "https://example.com/image.jpg"
  }
}
```

| フィールド名 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| src | string | 否 | 画像リソースの URL。 |

### リンク

```json
{
  "elementType": "link",
  "properties": {
    "href": "https://example.com"
  },
  "children": [
    { "text": "リンクをクリックして遷移" }
  ]
}
```

| フィールド名 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| href | string | 否 | リンク URL。 |

- `children`：**Text 配列**。リンクを挿入する際は必ず `children` を指定する必要があり、`text` が空でないテキストノードを少なくとも 1 つ含めてください。

## 共通データ構造

### Indent（インデント）

| フィールド名 | タイプ | 必須 | 説明 | 例 |
| --- | --- | --- | --- | --- |
| left | number | 否 | 具体的なインデント値。0 より大きい整数である必要があります。それ以外の場合はエラーになります。 | `32` |

---

### ListObject（リストオブジェクト）

| フィールド名 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| listId | string | 否 | 現在のリストの ID。複数階層の番号付きリストを挿入する場合、同一グループ内の複数階層リストで `listId` を一致させる必要があります。一致しない場合は表示エラーになります。 |
| level | number | 是 | リストの階層（0 から始まる）。 |
| listStyleType | string | 是 | リストスタイルのタイプ。 |
| listStyle | object(ListStyle) | 是 | リストの具体的なスタイル。詳細は [ListStyle（リストスタイル）](#bad921c2ebc3h) を参照してください。 |
| symbolStyle | object(SymbolStyle) | 否 | リスト記号のスタイル。詳細は [SymbolStyle（リスト記号スタイル）](#b16d5427cbutg) を参照してください。 |

---

### ListStyle（リストスタイル）

| フィールド名 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| format | string | 是 | 箇条書きのフォーマット。 |
| text | string | 是 | テキスト。 |
| align | string | 是 | 揃え方。例：`left`、`center`、`right`。 |

---

### SymbolStyle（リスト記号スタイル）

| フィールド名 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| sz | number | 否 | 箇条書きのフォントサイズ。 |
| shd | string | 否 | 箇条書きの背景色。 |
| fonts | string | 否 | 箇条書きのフォント形式。 |
| color | string | 否 | 箇条書きのフォント色。 |
| bold | boolean | 否 | 太字にするかどうか。 |
| strike | boolean | 否 | 取り消し線を表示するかどうか。 |
| italic | boolean | 否 | 斜体で表示するかどうか。 |
