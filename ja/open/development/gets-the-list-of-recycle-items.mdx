---
title: "ゴミ箱項目リストの取得"
---

本インターフェイスを呼び出すと、ゴミ箱内のすべての回収項目の詳細情報（元の所属スペース ID、元のパス、サイズ、名前など）をページネーション形式で取得できます。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | `https://api.dingtalk.io/v1.0/storage/recycleBins/{recycleBinId}/recycleItems` |
| HTTP Method | GET |
| サポートするアプリタイプ | appType-社内アプリ　appType-サードパーティ社内アプリ |
| 権限要件 | permission-Storage.RecycleBin.Read-企業ストレージゴミ箱読み取り権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | はい | 本インターフェイスを呼び出すためのアクセス認証情報。以下の方法で取得します：   - 社内アプリの場合、[社内アプリの accessToken を取得](https://open.dingtalk.io/document/development/obtain-the-access-token-of-an-internal-app#)インターフェイスを呼び出して取得します。 - サードパーティ社内アプリの場合、[サードパーティアプリの権限付与企業の accessToken を取得](https://open.dingtalk.io/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#)インターフェイスを呼び出して取得します。 |

### パスパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| recycleBinId | String | はい | ゴミ箱 ID。[ゴミ箱情報の取得](https://open.dingtalk.io/document/development/obtain-information-about-the-recycle-bin#)インターフェイスを呼び出して id パラメータの値を取得できます。 |

### クエリパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| nextToken | String | いいえ | ページネーションカーソル。   - 初回呼び出しの場合、本パラメータは渡しません。 - 初回以外の呼び出しの場合、前回呼び出し時に返された nextToken を渡します。 |
| maxResults | Integer | いいえ | 1 ページあたりの最大エントリ数。デフォルトは 50、最大値は 50 です。 |
| unionId | String | はい | 操作者の unionId。[ユーザー詳細の照会](https://open.dingtalk.io/document/development/query-user-details#)インターフェイスを呼び出して取得できます。 |

GET /v1.0/storage/recycleBins/recyclebin_id/recycleItems?nextToken=next_token&maxResults=30&unionId=chyxxxxx HTTP/1.1
Host:api.dingtalk.io
x-acs-dingtalk-access-token:access_token
Content-Type:application/json
