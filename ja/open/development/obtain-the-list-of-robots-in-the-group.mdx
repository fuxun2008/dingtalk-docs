本インターフェースを呼び出して、グループ内のボットリストを取得します。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/v1.0/robot/groups/robots/query |
| HTTP Method | POST |
| サポートするアプリタイプ | appType-社内アプリ |
| 必要な権限 | permission-qyapi_chat_manage-DingTalk グループベーシック情報管理権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | 必須 | 本インターフェースを呼び出すためのアクセス認証情報です。[社内アプリの access_token を取得](/ja/open/development/obtain-the-access-token-of-an-internal-app#)インターフェースを呼び出して取得します。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| openConversationId | String | 必須 | グループ ID：グループテンプレートに基づいて作成されたグループの場合、[グループの作成](https://open.dingtalk.com/document/development/create-a-scene-group-v2#)インターフェースを呼び出して `open_conversation_id` パラメーターの値を取得します。 |

## レスポンス

### レスポンスボディ

| 名前 | タイプ | 説明 |
| --- | --- | --- |
| chatbotInstanceVOList | Array | 戻されるボットリストです。 |
| robotCode | String | ボットのコードです。[ボット用語集 - robotCode](https://open.dingtalk.com/document/development/robot-overview#) を参照して `robotCode` を取得します。 |
| name | String | ボットの名前です。 |
| downloadIconURL | String | ボットのプロフィール写真のダウンロードリンクです。 |
| openRobotType | Integer | ボットのタイプ：   - **1**：パブリックテンプレートボット（カスタムボット、心知天気など）。 - **2**：社内アプリのボット。 - **3**：サードパーティ社内アプリのボット。 - **4**：シーングループボット。 |

### レスポンスボディ例

    "openRobotType" : 1
  } ]
}
