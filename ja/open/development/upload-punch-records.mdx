description: "DingTalk の打刻記録アップロード API の使い方を解説します。サードパーティの勤怠システムで取得したカード打刻や顔認証の記録を、社員と打刻時刻ごとに DingTalk 勤怠へ連携できます。"
---

この API を呼び出すと、サードパーティの勤怠システムで取得したカード打刻記録や顔認証記録を DingTalk 勤怠にアップロードし、DingTalk の打刻記録として登録します。

## リクエスト

| **ベーシック情報** | |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/topapi/attendance/record/upload |
| HTTP メソッド | POST |
| 対応アプリタイプ | appType-社内アプリ |
| 必要な権限 | permission-Pro.AttendanceRecord.Write-勤怠打刻記録の書き込み権限 |

### クエリパラメータ

| 名前 | タイプ | 必須 | 例 | 説明 |
| --- | --- | --- | --- | --- |
| access_token | 文字列 | はい | af21axxx | この API の呼び出しに使用するアプリ認証情報です。[社内アプリの access_token を取得する](/ja/open/development/obtain-orgapp-token)を呼び出して取得してください。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 例 | 説明 |
| --- | --- | --- | --- | --- |
| userid | 文字列 | はい | user123 | 打刻記録をアップロードする社員のユーザー ID です。 |
| device_name | 文字列 | はい | 東門打刻機 | 打刻機の名前です。123456 などのカスタム値を指定します。 |
| device_id | 文字列 | はい | abc123456 | 打刻機の ID です。abcde などのカスタム値を指定します。 |
| photo_url | 文字列 | いいえ | https://xxx.com/xxx.png | 打刻時の表示名画像の URL です。公開アクセス可能な URL を指定してください。 |
| user_check_time | 数値 | はい | 1587020403000 | 社員の打刻時刻（ミリ秒）です。  **注意**   - ミリ秒単位で指定してください。 - 直近 180 日以内の日付を指定してください。 |

### リクエスト例

```curl
curl -X POST "https://api.dingtalk.io/topapi/attendance/record/upload" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=0927xxxx3e28ea' \
-d 'device_id=abc123456' \
-d 'device_name=%E6%9D%B1%E9%96%80%E6%89%93%E5%88%BB%E6%A9%9F' \
-d 'photo_url=https%3A%2F%2Fxxx.com%2Fxxx.png' \
-d 'user_check_time=1587020403000' \
-d 'userid=dd_dd'
```

Java

```text
DingTalkClient client = new DefaultDingTalkClient("https://api.dingtalk.io/topapi/attendance/record/upload");
OapiAttendanceRecordUploadRequest req = new OapiAttendanceRecordUploadRequest();
req.setUserid("dd_dd");
req.setDeviceName("東門打刻機");
req.setDeviceId("abc123456");
req.setPhotoUrl("https://xxx.com/xxx.png");
req.setUserCheckTime(1587020403000L);
OapiAttendanceRecordUploadResponse rsp = client.execute(req, access_token);
System.out.println(rsp.getBody());
```

## レスポンス

### レスポンスボディ

| 名前 | タイプ | 例 | 説明 |
| --- | --- | --- | --- |
| success | 真偽値 | true | 呼び出しに成功したかどうかを示します。 |
| errcode | 数値 | 0 | リターンコードです。 |
| errmsg | 文字列 | ok | リターンコードの説明です。 |
| request_id | 文字列 | ktoftehkz2bt | リクエスト ID です。 |

### レスポンスボディの例

```json
{
  "errcode":0,
  "success":true,
  "request_id" : "3ynh2gp5ndke"
}
```

### エラーコード

この API の呼び出しに失敗した場合は、エラーメッセージをもとに [グローバルエラーコード](/ja/open/development/server-api-error-codes-1) ドキュメントで解決方法を検索してください。
