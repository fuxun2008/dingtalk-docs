本インターフェースを呼び出して、指定した会議室のフリー / ビジー情報を取得します。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | `https://api.dingtalk.io/v1.0/calendar/users/{userId}/meetingRooms/schedules/query` |
| HTTP Method | POST |
| サポートされるアプリタイプ | appType-社内アプリ　appType-サードパーティ社内アプリ |
| 必要な権限 | permission-Calendar.Event.Read-カレンダーアプリにおける予定の読み取り権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | はい | 本インターフェース呼び出し時のアクセス認証情報。以下の方法で取得します。   - 社内アプリの場合は、[社内アプリの access_token を取得](/ja/open/development/obtain-the-access-token-of-an-internal-app#)インターフェースを呼び出して取得します。 - サードパーティ社内アプリの場合は、[サードパーティアプリで権限付与された企業の access_token を取得](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#)インターフェースを呼び出して取得します。 |

### パスパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| userId | String | はい | 本リクエストのリソースが属するユーザーの unionId。[ユーザー詳細を照会](/ja/open/development/query-user-details#)インターフェースを呼び出して取得できます。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| roomIds | Array of String | はい | 照会対象の会議室 roomId リスト。[会議室リストを照会](/ja/open/development/check-the-meeting-room-list#)インターフェースを呼び出して取得できます。5 件以内を推奨します。 |
| startTime | String | はい | 照会開始時刻（iso8601 形式）。例：2022-07-29T14:55Z。 |
| endTime | String | はい | 照会終了時刻（iso8601 形式）。例：2022-07-29T14:55Z。 |
