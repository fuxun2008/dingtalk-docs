---
title: "ブロック要素の削除"
---

本インターフェースを呼び出すことで、ドキュメント内の特定のブロック要素を 1 つ削除できます。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | `https://api.dingtalk.io/v1.0/doc/suites/documents/{docKey}/blocks/{blockId}` |
| HTTP Method | DELETE |
| サポートされるアプリタイプ | appType-社内アプリ |
| 権限要件 | permission-Storage.File.Write-企業ストレージファイル書き込み権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | はい | 本インターフェースを呼び出すためのアクセス認証情報。[社内アプリのアクセストークン取得](https://open.dingtalk.io/document/development/obtain-the-access-token-of-an-internal-app)インターフェースを呼び出して取得します。 |

### パスパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| docKey | String | はい | ドキュメント ID（ドキュメントの docKey または dentryUuid）。[ナレッジベースドキュメント作成](https://open.dingtalk.io/document/development/create-team-space-document)インターフェースでドキュメントを作成後、戻り値から `docKey` パラメータを取得します。  ドキュメント URL から `dentryUuid` を取得する場合、https://alidocs.dingtalk.io/i/nodes/Zxxxxa-id を例にとると、dentryUuid は Zxxxxa-id となります。 |
| blockId | String | はい | 削除対象ブロックの `blockId`。[ブロック要素のクエリ](https://open.dingtalk.io/document/development/api-docblocksquery)インターフェースから `blockId` パラメータを取得できます。 |

### クエリパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| operatorId | String | はい | ユーザーの unionId。[ユーザー詳細クエリ](https://open.dingtalk.io/document/development/query-user-details)インターフェースから unionid パラメータ値を取得できます。 |

### リクエスト例

HTTP

```http
DELETE /v1.0/doc/suites/documents/doc_key/blocks/block_id?operatorId=union_id HTTP/1.1
Host:api.dingtalk.io
x-acs-dingtalk-access-token:7dc9ec4xxx
Content-Type:application/json
```
