---
title: "部門の可視性優先度を設定"
---

本 API を呼び出して、連絡先部門の可視性優先度を設定します。

## API 呼び出し説明

デフォルトでは、子部門（経営層）の **部門メンバーの連絡先閲覧範囲** が親部門と異なっていても、親部門の設定が引き継がれます。

子部門（経営層）で個別に設定した **部門メンバーの連絡先閲覧範囲** を有効にするには、本 API を呼び出して子部門の優先度を引き上げてください。

部門設定の優先度はデフォルトで **親部門の設定が子部門より優先** されます。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/v1.0/contact/depts/settings/priorities |
| HTTP Method | POST |
| 対応アプリタイプ | appType-社内アプリ |
| 権限要件 | permission-Contact.Visibility.ReadWrite-連絡先データ可視範囲管理権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | はい | 本 API を呼び出すためのアクセス認証情報。[社内アプリのアクセストークンを取得](https://open.dingtalk.io/document/development/obtain-the-access-token-of-an-internal-app#) を呼び出して取得します。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| enable | Boolean | はい | 子部門設定の優先をオンにするかどうか。取り得る値:   - **true**: 子部門の設定が親部門より優先 - **false（デフォルト）**: 親部門の設定が子部門より優先 |

### リクエスト例

HTTP

```http
POST /v1.0/contact/depts/settings/priorities HTTP/1.1
Host:api.dingtalk.io
x-acs-dingtalk-access-token:ebf12xxx
Content-Type:application/json

{
  "enable" : true
}
```
