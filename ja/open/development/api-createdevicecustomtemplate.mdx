---
title: "カスタム画面テンプレートを作成する"
description: "テンプレート名やロゴ背景などを設定してカスタム画面テンプレートを作成します"

本インターフェースを呼び出して、テンプレート名に基づきカスタム画面テンプレートを作成します。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/v1.0/rooms/devices/screens/templates |
| HTTP Method | POST |
| 対応アプリタイプ | appType-社内アプリ　appType-サードパーティ社内アプリ |
| 必要な権限 | permission-Rooms.DeviceTemplate.Write-DingTalk 会議 Rooms システムのカスタム画面書き込み権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | はい | API 認証情報。[ユーザートークン取得](/ja/open/development/obtain-user-token#)インターフェースを呼び出して取得します。  ユーザートークン取得のリクエストで使用する入力パラメータ `code` は、リンク構築の過程で scope の範囲を必ずユーザー ID と組織 ID とする必要があります。すなわち `scope=openid corpid` です。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| templateName | String | はい | テンプレート名。 |
| logo | String | いいえ | テンプレートロゴ。[メディアファイルアップロード](/ja/open/development/upload-media-files#)インターフェースを呼び出して取得できます。画像アップロード後の mediaId。画像サイズ：240\*240、1 枚あたり 1 MB 以内。 |
| orgName | String | いいえ | テンプレートの企業名。 |
| customDoc | String | いいえ | テンプレートのカスタムテキストコンテンツ。 |
| bgUrl | String | いいえ | テンプレートのカスタム背景 URL。 |
| bgImgList | Array of String | いいえ | 画像 mediaId。[メディアファイルアップロード](/ja/open/development/upload-media-files#)インターフェースを呼び出して取得できます。最大 9 枚までアップロード可能で、1 枚あたり 5 MB 以内。 |
| instruction | Boolean | いいえ | 使用説明の表示：   - **true**：表示する - **false**：表示しない |
| bgType | Integer | いいえ | テンプレートのカスタム背景タイプ：   - **1**：画像 - **2**：URL |
| isPicTop | Integer | いいえ | ホーム情報バーの表示：   - **0**：表示する - **1**：表示しない |
| hideServerCodeWhenProjecting | Boolean | いいえ | 画面ミラーリング中に画面ミラーリングコードを非表示にする：   - **true**：非表示 - **false**：非表示にしない |
| showCalendarTitle | Boolean | いいえ | 予定カードに予定の見出しを表示する：   - **true**：表示する - **false**：表示しない |
| desensitizeUserName | Boolean | いいえ | 予定カードで予約者の名前をマスキングする：   - **true**：マスキングする - **false**：マスキングしない |
| picturePlayInterval | Integer | いいえ | カスタム背景画像のスライドショー間隔（秒）。 |
| showCalendarCard | Boolean | いいえ | 予定カードを表示する：   - **true**：表示する - **false**：表示しない |
| showFunctionCard | Boolean | いいえ | 機能カードを表示する：   - **true**：表示する - **false**：表示しない |
| deviceUnionIds | Array of String | いいえ | デバイスの unionId。本パラメータは、[デバイスと会議室の紐付け変更](https://open.dingtalk.com/document/development/org-event-overview#)イベントの購読から取得します。 |
| groupIds | Array of Long | いいえ | グループ分け ID。[会議室グループ分けリスト取得](/ja/open/development/query-meeting-rooms-groups#)インターフェースを呼び出して取得できます。 |
| roomIds | Array of String | いいえ | 会議室 ID。[会議室リスト取得](/ja/open/development/check-the-meeting-room-list#)インターフェースを呼び出して取得できます。 |
