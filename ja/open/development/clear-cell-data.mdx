---
title: "セル範囲内のデータをクリア"
description: "スプレッドシートで指定した範囲のセル内のデータをクリアし、書式を保持します"
---

本 API を呼び出して、セル内のデータをクリアします（書式は含まれません）。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | `https://api.dingtalk.io/v1.0/doc/workbooks/{workbookId}/sheets/{sheetId}/ranges/{rangeAddress}/clearData` |
| HTTP Method | POST |
| 対応アプリタイプ | appType-社内アプリ　appType-サードパーティ社内アプリ |
| 権限要件 | permission-Document.Workbook.Write-スプレッドシート書き込み権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | はい | 本 API を呼び出すためのアクセス認証情報。以下の方法で取得します。   - 社内アプリの場合、[社内アプリの access_token を取得](/ja/open/development/obtain-the-access-token-of-an-internal-app#) API を呼び出して取得します。 - サードパーティ社内アプリの場合、[サードパーティアプリの認可企業の access_token を取得](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#) API を呼び出して取得します。 |

### パスパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| workbookId | String | はい | スプレッドシートファイルの ID。[ナレッジベース API](/ja/open/development/knowledge-base-overview#) が返す `nodeId(dentryUuid)` がスプレッドシートの `workbookId` に該当します。[ノードを取得](https://open.dingtalk.com/document/development/get-node#) および [ナレッジベースドキュメントを作成](/ja/open/development/create-team-space-document#) API を呼び出して取得できます。 |
| sheetId | String | はい | ワークシートの ID または見出し。   - 社内アプリの場合、[全ワークシートを取得](/ja/open/development/obtain-all-worksheets#) API を呼び出して id を取得するか、ワークシートの見出しを渡します。 - サードパーティ社内アプリの場合、ワークシートの見出しを渡すことを推奨します。   ワークシートの見出しの確認手順は下図のとおりです。 |
| rangeAddress | String | はい | クリア対象のセル範囲。形式は `領域内の左上セル:領域内の右下セル` です。  例：B2:C3 は下図に示す領域を表します。 |

### クエリパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| operatorId | String | はい | 操作者の unionId。[ユーザー詳細を照会](/ja/open/development/query-user-details#) API を呼び出して取得できます。 |

### リクエスト例

```http
POST /v1.0/doc/workbooks/e54Lq3xxx/sheets/Sheet1/ranges/A1:B1/clearData?operatorId=ppgAxxx HTTP/1.1
Host:api.dingtalk.io
x-acs-dingtalk-access-token:xxxxx
Content-Type:application/json
```
