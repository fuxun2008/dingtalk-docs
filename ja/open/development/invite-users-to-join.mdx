---
title: "ユーザーを会議に招待"
description: "進行中のビデオ会議にユーザーを招待し、参加通知を自動送信します"
---

会議中に新しいユーザーを会議に招待します。本インターフェースを呼び出すと、招待されたユーザーは会議に参加する通知を受け取ります。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | `https://api.dingtalk.io/v1.0/conference/videoConferences/{conferenceId}/users/invite` |
| HTTP Method | POST |
| サポートされるアプリタイプ | appType-社内アプリ　appType-サードパーティ社内アプリ |
| 必要な権限 | permission-VideoConference.Conference.Write-ビデオ会議情報管理権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | はい | 本インターフェースを呼び出すためのアクセス認証情報。以下の方法で取得します：   - 社内アプリの場合は、[社内アプリのaccessTokenを取得](/ja/open/development/obtain-the-access-token-of-an-internal-app#)インターフェースを呼び出して取得します。 - サードパーティ社内アプリの場合は、[サードパーティアプリに認可された企業のaccessTokenを取得](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#)インターフェースを呼び出して取得します。 |

### パスパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| conferenceId | String | いいえ | 会議ID。[ビデオ会議を作成](/ja/open/development/create-a-video-conference#)インターフェースを呼び出し、戻り値の`conferenceId`フィールドから取得できます。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| unionId | String | いいえ | 操作ユーザーのunionId。  指定しない場合、呼び出しバーに招待者の名前が表示されません。 |
| inviteeList | Array | いいえ | 招待されるユーザーのリスト。 |
| unionId | String | いいえ | 招待されるユーザーのunionId。 |
| nick | String | はい | 招待されるユーザーの名前。 |
| phoneInviteeList | Array | いいえ | 招待される電話番号のリスト。 |
| phoneNumber | String | いいえ | 招待されるユーザーの電話番号。 |
| nick | String | いいえ | 招待されるユーザーの名前。 |
