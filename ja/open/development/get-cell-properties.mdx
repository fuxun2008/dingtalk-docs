---
title: "セル範囲の取得"
---

本インターフェースを呼び出すと、セルの属性を取得できます。現在、セル内の値、数式、表示値、背景色、フォントサイズ、水平揃え、垂直揃えを取得できます。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | `https://api.dingtalk.io/v1.0/doc/workbooks/{workbookId}/sheets/{sheetId}/ranges/{rangeAddress}` |
| HTTP Method | GET |
| 対応アプリタイプ | appType-社内アプリ |
| 必要な権限 | permission-Document.Workbook.Read-スプレッドシート読み取り権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | はい | 本インターフェース呼び出し時のアクセス認証情報。[社内アプリのアクセストークンを取得](/ja/open/development/obtain-the-access-token-of-an-internal-app#)インターフェースを呼び出して取得します。 |

### パスパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| workbookId | String | はい | スプレッドシートファイル ID。[ナレッジベース API](/ja/open/development/knowledge-base-overview#) が返す `nodeId(dentryUuid)` がスプレッドシートの `workbookId` となります。[ノードの取得](https://open.dingtalk.com/document/development/get-node#)および[ナレッジベースドキュメントの作成](/ja/open/development/create-team-space-document#)インターフェースを呼び出して取得できます。 |
| sheetId | String | はい | ワークシート ID または名前。[すべてのワークシートの取得](/ja/open/development/obtain-all-worksheets#)インターフェースを呼び出して id または name パラメータの値を取得できます。 |
| rangeAddress | String | はい | Range アドレス。 |

### クエリパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| select | String | いいえ | 返却するフィールドを絞り込みます。本パラメータを指定しない場合、すべてのフィールドが返されます。   - 例：`select=values` を指定すると、本インターフェースは values フィールドのみ返します。 - 複数のフィールドを返す場合はカンマで区切ります。例：`select=values,formulas` を指定すると、本インターフェースは values と formulas フィールドのみ返します。     パフォーマンス向上のため、また将来的に返却値が追加された際の API タイムアウトを避けるため、本パラメータの指定を推奨します。 |
| operatorId | String | はい | 操作者の unionId。   - [サイレントログインコードによるユーザー情報の取得](/ja/open/development/obtain-the-userid-of-a-user-by-using-the-log-free#)インターフェースを呼び出して unionid パラメータの値を取得できます。 - [ユーザー詳細の照会](/ja/open/development/query-user-details#)インターフェースを呼び出して unionid パラメータの値を取得できます。     操作者に権限がない場合、インターフェースは `The operator has no permission` のエラーを返します。 |
