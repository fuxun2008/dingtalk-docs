---
title: "ビデオ会議の作成、検索、終了"
---

本ドキュメントでは、会議 API を呼び出してビデオ会議を作成する流れを説明します。まず社内アプリを作成し、次に会議が提供する API を使用して、ビデオ会議の作成、ビデオ会議の終了、ビデオ会議情報の一括検索を実現します。

## フロー概要

前提条件：[アプリの作成と設定](/ja/open/dingstart/create-and-configure-an-application)のフローを完了します。

ステップ 1：アプリ認証情報を取得し、クライアント ID と Client Secret を取得します。

ステップ 2：API 権限をリクエストし、会議関連 API の権限をリクエストします。

ステップ 3：アプリのアクセス認証情報を取得します。[社内アプリのアクセストークンを取得する](/ja/open/development/obtain-the-access-token-of-an-internal-app)を参照し、API を呼び出す際は、アクセストークンによって呼び出し元の身元を認証します。

ステップ 4：サーバーサイドの会議関連 API を呼び出します。

1. サーバー API [ビデオ会議の作成](/ja/open/development/create-a-video-conference) を呼び出してビデオ会議を作成し、ビデオ会議の conferenceId を取得します。
2. ビデオ会議の conferenceId に基づき、サーバー API [ビデオ会議情報の一括検索](/ja/open/development/batch-query-of-video-conference-information) を呼び出して、ビデオ会議情報とメンバーリストを取得します。
3. ビデオ会議の conferenceId に基づき、サーバー API [ビデオ会議のクラウド録画を開始](/ja/open/development/video-conference-open-cloud-recording) を呼び出して、ビデオ会議のクラウド録画を開始します。
4. ビデオ会議の conferenceId に基づき、サーバー API [ビデオ会議のクラウド録画を開始](/ja/open/development/video-conference-open-cloud-recording) を呼び出して、ビデオ会議のクラウド録画を停止します。
5. ビデオ会議の conferenceId に基づき、サーバー API [ビデオ会議の終了](/ja/open/development/close-audio-video-conference) を呼び出して、ビデオ会議を終了します。
6. 会議録画情報を検索します。

   1. ビデオ会議の conferenceId に基づき、サーバー API [会議録画の詳細情報を検索](/ja/open/development/query-recording-information) を呼び出して、会議録画の録画者、録画開始時刻、録画継続時間などの情報を検索します。
   2. ビデオ会議の conferenceId に基づき、サーバー API [会議録画の動画情報を検索](/ja/open/development/queries-the-playback-information-about-a-recorded-cloud-video) を呼び出して、動画のダウンロード URL、動画ファイルサイズ、動画の長さなどの情報を検索します。
   3. ビデオ会議の conferenceId に基づき、サーバー API [会議録画のテキスト情報を検索](/ja/open/development/queries-the-text-information-about-cloud-recording) を呼び出して、会議録画のテキストコンテンツ、テキスト記録開始時刻、テキスト記録終了時刻などの情報を検索します。

## 前提条件

[アプリの作成と設定](/ja/open/dingstart/create-and-configure-an-application)のフローを完了します。

## ステップ 1：アプリ認証情報の取得

1. 対象のアプリを選択して詳細ページに移動し、**ベーシック情報** > **認証情報とベーシック情報** をクリックします。
2. クライアント ID と Client Secret を取得します。

## ステップ 2：API 権限の追加

**開発設定** > **権限管理** をクリックし、権限検索ボックスに `VideoConference.Conference.Write` と `VideoConference.Conference.Read` をそれぞれ入力して、権限をリクエストします。

## ステップ 3：アプリのアクセストークン取得

<Warning>
サーバー API の差異の詳細は、旧版 API VS 新版 API を参照してください。以下の API はすべてサーバー API を使用しており、SDK のダウンロード詳細はサーバーサイド SDK ダウンロードを参照してください。
</Warning>

ステップ 1 で取得したクライアント ID と Client Secret に基づき、アプリのアクセス認証情報を取得します。詳細は [社内アプリのアクセストークンを取得する](/ja/open/development/obtain-the-access-token-of-an-internal-app) を参照してください。
