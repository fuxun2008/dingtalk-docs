この API を呼び出して、指定した休暇タイプのルールを更新します。

## API 呼び出し説明

休暇ルールの作成方法は 2 つあります。API を呼び出して作成する方法と、DingTalk 公式の勤怠アプリで作成する方法です。

| 休暇ルールの作成方法 | この API による休暇タイプの更新可否 |
| --- | --- |
| [休暇ルールの追加](/ja/open/development/add-holiday-rules) API を呼び出して作成した休暇タイプ | 可 |
| 管理コンソールの勤怠アプリで作成した休暇タイプ   - 勤怠アプリのシステムによりデフォルトで作成されたもの - 勤怠アプリの管理画面で作成したもの | 不可 |

**勤怠** > **休暇管理** > **休暇ルール** ページで、既存の 4 つの休暇ルールを確認します。

- 「API で作成した休暇タイプ1」と「API で作成した休暇タイプ2」は API で作成されたものです。この API を呼び出して、休暇名、休暇申請の単位、休暇時間の計算方法、残高の適用範囲などの情報を更新できます。
- 「私用休暇」と「代休」は、勤怠アプリのシステムによりデフォルトで作成された休暇タイプです。この API ではこれらの休暇タイプを更新できず、次のエラーメッセージが返されます：errcode:880015,errmsg:指定された leaveCode または userId が存在しません。

<Note>
API で作成された休暇ルールを確認するには、[休暇ルール一覧の取得](/ja/open/development/holiday-type-query) API を呼び出してください。
</Note>

DingTalk の管理コンソールで **休暇管理** > **休暇ルール** に移動すると、休暇ルールの一覧を確認できます。新しいルールを作成するには **+ 休暇を追加** をクリックします。各ルールには次の列が表示されます。

| 列 | 説明 |
| --- | --- |
| 休暇名 | 例：私用休暇、代休、API で作成した休暇タイプ1/2 |
| 休暇申請の単位 | 時間単位 または 日単位 |
| 休暇時間の計算方法 | 例：勤務日で計算 |
| 残高ルール | 例：残高制限なし |
| 適用範囲 | 例：全社 |
| 操作 | 編集、削除 |

私用休暇や代休などのデフォルトの休暇タイプは申請単位に「時間単位」を使用し、API で作成した休暇タイプは「日単位」を使用しています。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/v1.0/attendance/leaves/types |
| HTTP メソッド | PUT |
| 対応するアプリタイプ | appType-社内アプリ　appType-サードパーティ社内アプリ |
| 必要な権限 | permission-qyapi_holiday_manage-DingTalk 休暇管理権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |

### クエリパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| opUserId | String | はい | 操作者の userId です。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| leaveName | String | いいえ | 休暇名です。 |
| leaveViewUnit | String | はい | 休暇申請の単位です。   - **day**：日 - **halfDay**：半日 - **hour**：時間 |
| bizType | String | はい | 休暇タイプです。   - **general_leave**：通常の休暇 - **lieu_leave**：残業を代休に振り替える休暇 |
| naturalDayLeave | Boolean | いいえ | 休暇時間を暦日で計算するかどうかを指定します。   - **true**：はい - **false**：いいえ     例えば、社員の山田さんが、2022年4月11日 9:30 から 2022年4月18日 18:30 までの休暇申請の承認フォームを提出したとします。4月16日と4月17日は土曜日・日曜日の休日です。   - このパラメータが true の場合、承認フォームの休暇日数は、勤務予定のない休日と祝日を含めて 8 日として計算されます。 - このパラメータが false の場合、承認フォームの休暇日数は、勤務予定のない休日と祝日を除いて 6 日として計算されます。 |
| hoursInPerDay | Long | いいえ | 換算に使用する 1 日あたりの労働時間です。パラメータ値を 100 で割った値になります。    例えば、社員のシフトの労働時間が 8 時間の場合、このパラメータには 8\*100=800 を設定します。 |
| leaveCode | String | はい | API で追加した休暇ルールの識別子です。leave_code は、API で追加した休暇タイプに属するものである必要があります。   - 社内アプリ：休暇ルールの追加 API が返す leave_code の値を使用します。 - サードパーティ社内アプリ：休暇ルールの追加 API が返す leave_code の値を使用します。 |
| extras | String | いいえ | 代休の有効期限ルールです。   - **validity_type**：有効期限のタイプ    - **absolute_time**：絶対日時   - **relative_time**：相対日時 - **validity_value**：延長日    - validity_type が **absolute_time** の場合、この値は必須で、「yy-mm」形式で指定する必要があります。   - validity_type が **relative_time** の場合、この値は 1 より大きい整数である必要があります。 |
| visibilityRules | Array | いいえ | 適用範囲ルールのリストです。指定しない場合、ルールは全社に適用されます。 |
| visible | Array of String | いいえ | 適用範囲に含まれるデータのリストです。   - type=staff の場合、社員の userId のリストを渡します。 - type=dept の場合、部門 ID のリストを渡します。 - type=label の場合、ロール ID のリストを渡します。 |
| type | String | いいえ | 適用範囲ルールのタイプです。   - **dept**：部門 - **staff**：社員 - **label**：ロール |
| submitTimeRule | Object | いいえ | 提出期限ルールです。 |
| timeValue | Long | いいえ | 制限値です。   - timeUnit が **day** の場合、有効範囲は 0〜30 日です。 - timeUnit が **hour** の場合、有効範囲は 0〜24 時間です。 |
| timeUnit | String | いいえ | 時間の単位です。   - **day**：日 - **hour**：時間 |
| timeType | String | いいえ | 制限のタイプです。   - **before**：事前提出 - **after**：事後提出 |
| enableTimeLimit | Boolean | いいえ | 提出期限を有効にするかどうかを指定します。   - **true**：オン - **false**：オフ |
| leaveCertificate | Object | いいえ | 休暇証明です。 |
| unit | String | いいえ | 休暇証明の単位です。   - **hour**：時間 - **day**：日 |
| duration | double | いいえ | 休暇証明が必要となる休暇時間のしきい値です。 |
| enable | Boolean | いいえ | 休暇証明を必須にするかどうかを指定します。   - **true**：オン - **false**：オフ |
