この API を呼び出すと、休暇名とユーザー ID を指定して、DingTalk のスマート勤怠レポートから休暇データを取得します。返されるデータには、指定期間内のレポートの休暇列に含まれるすべての値が含まれます。休暇列は動的に生成されるため、データを取得する際は休暇名を必ず指定してください。

## API 呼び出し説明

その他のデータアクセス・活用機能を利用する場合は、データアセットプラットフォームをご利用ください。データアセットプラットフォーム（dPaaS）は、組織向けの統合データ管理プラットフォームです。DingTalk を基盤として、安全性・拡張性・保守性に優れたデータサービスを提供し、ビジネス上の意思決定を支援します。

## リクエスト

| **基本情報** | |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/topapi/attendance/getleavetimebynames |
| HTTP メソッド | POST |
| 対応するアプリタイプ | 社内アプリ、サードパーティ社内アプリ |
| 必要な権限 | permission-qyapi_base-組織 API の呼び出しに必要なベーシック権限 |

### クエリパラメータ

| 名前 | タイプ | 必須 | 例 | 説明 |
| --- | --- | --- | --- | --- |
| access_token | String | はい | 6d1bxxxx | この API の呼び出しに使用するアプリ認証情報です。   - 社内アプリの場合は、[社内アプリの access_token を取得する](/ja/open/development/obtain-orgapp-token) API を呼び出して取得します。 - サードパーティ社内アプリの場合は、サードパーティ組織の access_token を取得する API を呼び出して取得します。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 例 | 説明 |
| --- | --- | --- | --- | --- |
| userid | String | はい | manager123 | ユーザーのユーザー ID です。 |
| leave_names | String | はい | 年次有給休暇 | 休暇名です。複数指定する場合はカンマで区切ります。最大長：20。 |
| from_date | Date | はい | 2020-09-09 12:12:12 | 開始日時です。225 日より前のデータには対応していません。 |
| to_date | Date | はい | 2020-09-11 12:12:12 | 終了日時です。開始日時と終了日時の間隔は 31 日以内にする必要があります。 |

### リクエスト例

```curl
curl -X POST "https://api.dingtalk.io/topapi/attendance/getleavetimebynames" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=1b8b85xxxxx3ccfdd' \
-d 'from_date=2018-07-11+12%3A12%3A12' \
-d 'leave_names=年次有給休暇' \
-d 'to_date=2018-07-11+12%3A12%3A12' \
-d 'userid=zhangsan'
```

Java

```text
DingTalkClient client = new DefaultDingTalkClient("https://api.dingtalk.io/topapi/attendance/getleavetimebynames");
OapiAttendanceGetleavetimebynamesRequest req = new OapiAttendanceGetleavetimebynamesRequest();
req.setUserid("zhangsan");
req.setLeaveNames("年次有給休暇");
req.setFromDate(StringUtils.parseDateTime("2020-09-01 00:00:00"));
req.setToDate(StringUtils.parseDateTime("2020-09-30 00:00:00"));
OapiAttendanceGetleavetimebynamesResponse rsp = client.execute(req, access_token);
System.out.println(rsp.getBody());
```

## レスポンス

### レスポンスボディ

| 名前 | タイプ | 例 | 説明 |
| --- | --- | --- | --- |
| result | ColumnValListForTopVo |  | 返却結果です。 |
| columns | ColumnValForTopVo[] |  | 列情報と列値データです。 |
| columnvo | ColumnForTopVo |  | 列情報です。 |
| name | String | 私用休暇 | 休暇名です。 |
| sub_type | Number | 0 | サブタイプです。 |
| status | Number | 0 | 列のステータスです。 |
| alias | String | leave_ | 表示名です。 |
| type | Number | 0 | 列のタイプです。 |
| columnvals | ColumnDayAndVal[] |  | 列値データです。 |
| value | String | 1.0 | 日ごとの値です。 |
| date | Date | 2020-09-09 12:12:12 | 開始日時です。 |
| errcode | Number | 0 | リターンコードです。 |
| request_id | String | whv0fhtk8cnc | リクエスト ID です。 |
