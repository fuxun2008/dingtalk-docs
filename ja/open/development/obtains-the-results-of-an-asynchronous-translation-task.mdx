title: "非同期翻訳タスク結果の取得"

本 API を呼び出して、既に送信済みの翻訳タスクの結果を取得します。

## API 呼び出し説明

### API 機能紹介

1. 翻訳対象のドキュメントを構成します。例は下図のとおりです。

### 説明

   xlsx、xls、csv、txt 形式のファイルのみサポートします。

2. [シングルステップファイルアップロード](https://open.dingtalk.io/document/isvapp/single-step-file-upload) API を呼び出して、media_id を取得します。
3. [連絡先 ID の非同期翻訳](https://open.dingtalk.io/document/isvapp/asynchronous-address-book-file-content-translation) API を呼び出して、翻訳タスク ID を取得します。

### 説明

   連絡先 ID の非同期翻訳 API を呼び出した後、ファイルの翻訳が成功すると、非同期タスクのコールバック通知がトリガーされます。
4. 本 API を呼び出して、翻訳後のファイルのダウンロードリンクを取得します。

### 説明

   返されたファイルのダウンロードリンクは `<a> タグ` で参照することを推奨します。`download` 属性は指定できません（ブラウザの互換性問題）。
5. ユーザーがダウンロードしたファイルの内容は下図のとおりです。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/v1.0/contact/files/translateResults |
| HTTP Method | GET |
| サポートされるアプリタイプ | appType-サードパーティ社内アプリ |
| 必要な権限 | permission-qyapi_get_member-ユーザー情報の読み取り権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | はい | 本 API を呼び出すためのアクセス認証情報。[サードパーティアプリに権限付与した企業の access_token を取得する](https://open.dingtalk.io/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#) API を呼び出して取得します。 |

### クエリパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| jobId | String | はい | 非同期翻訳タスク ID。[連絡先 ID の非同期翻訳](https://open.dingtalk.io/document/development/asynchronous-address-book-file-content-translation#) API を呼び出して jobId パラメータ値を取得します。 |
