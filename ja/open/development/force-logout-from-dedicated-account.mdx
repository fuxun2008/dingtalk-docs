---
title: "企業アカウントの強制ログアウト"
---

本 API を呼び出して、指定した企業アカウントを強制的にログアウトさせます。

## API 呼び出し説明

特定のシーンにおいて、企業アカウントを緊急に強制ログアウトさせる必要がある場合、本 API を呼び出して強制ログアウトを実行できます。

ログアウト後、ユーザー側の DingTalk には以下のように表示されます。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/v1.0/contact/orgAccounts/signOut |
| HTTP Method | POST |
| サポートするアプリタイプ | appType-社内アプリ |
| 必要な権限 | permission-Contact.OrgAccountSecurity.ReadWrite-連絡先企業アカウント安全データ読み書き権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | 必須 | 本 API を呼び出すためのアクセス認証情報。[社内アプリの access_token を取得する](/ja/open/development/obtain-the-access-token-of-an-internal-app) API を呼び出して取得します。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| userId | String | 必須 | 企業アカウントの userid。以下 4 つの方法で取得できます。   - [携帯電話番号から企業アカウントユーザーを取得する](/ja/open/development/obtain-the-userid-of-your-mobile-phone-number) - [シングルサインオン企業アカウントを作成する](/ja/open/development/create-an-sso-account) - [DingTalk 自社作成企業アカウントを作成する](/ja/open/development/create-dingtalk-user-created-dedicated-account) - [他組織の企業アカウントを招待して参加させる](/ja/open/development/invite-other-organization-specific-accounts-to-join) |
| reason | String | 任意 | 企業アカウント強制ログアウトの理由（DingTalk 管理画面の監査ログに表示）。 |
| reasonI18nForEmployee | `Map<String, String>` | 任意 | - 企業アカウント強制ログアウトの理由（社員に表示）。 - 例：`{"zh_CN":"ログアウトの理由","en_US":"Reason for logging out"}` - 対応言語は DingTalk クライアントサイドの現行言語を参照してください。例：`zh_CN`、`zh_HK`、`zh_TW`、`en_US`、`ja_JP`、`vi_VN`、`fr_FR`、`ru_RU`、`ko_KR`、`es_LA`、`tr_TR`、`pt_BR`、`ms_MY`、`id_ID`、`th_TH` |

  }
