---
title: "企業アカウントのユーザー情報を更新"
---

本インターフェースを呼び出して、指定した企業アカウントのユーザー情報を更新します。企業アカウントを購入・開通した組織のみ利用可能です。

## リクエスト

| **ベーシック情報** | |
| --- | --- |
| HTTP URL | https://oapi.dingtalk.io/topapi/v2/user/update |
| HTTP Method | POST |
| サポートされるアプリタイプ | appType-社内アプリ |
| 必要な権限 | permission-qyapi_manage_addresslist-連絡先データ管理権限 |

### クエリパラメータ

| 名前 | タイプ | 必須 | 例 | 説明 |
| --- | --- | --- | --- | --- |
| access_token | String | 必須 | be3Fxxxx | このインターフェースを呼び出すためのアプリ認証情報。社内アプリの access_token を取得するインターフェースで取得します。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 例 | 説明 |
| --- | --- | --- | --- | --- |
| userid | String | 必須 | user123 | 社員の userId。 |
| name | String | 任意 | 山田太郎 | 社員名。最大 80 文字。 |
| hide_mobile | Boolean | 任意 | false | 電話番号を非表示にするかどうか：   - **true**：非表示  電話番号を非表示にすると、プロフィールページでは番号が非表示となりますが、DING の送信や DingTalk ビジネス電話の発信は引き続き可能です。 - **false**：非表示にしない |
| telephone | String | 任意 | 010-86123456-2345 | 内線番号。最大 50 文字。  **説明**  内線番号は一意であり、社内で重複できません。 |
| job_number | String | 任意 | 4 | 社員番号。最大 50 文字。 |
| manager_userid | String | 任意 | 0001 | 直属の上司の userId。 |
| title | String | 任意 | 技術ディレクター | 職位。最大 200 文字。 |
| email | String | 任意 | test@xxx.com | 社員のメール。最大 50 文字。  **説明**  社員のメールは一意であり、社内で重複できません。 |
| org_email | String | 任意 | test@xxx.com | 社員のエンタープライズメール。  **説明**  以下の条件を満たす場合のみこのフィールドが有効になります：社員のエンタープライズメールが開通済みであること。 |
| work_place | String | 任意 | 未来パーク | 勤務地。最大 100 文字。 |
| remark | String | 任意 | 表示名情報 | 表示名。最大 2000 文字。 |
| dept_id_list | String | 必須 | "2,3,4" | 所属部門 ID リスト。 |
| dept_order_list | DeptOrder[] | 任意 |  | 対応する部門内での社員の並び替え。 |
| dept_id | Number | 任意 | 2 | 部門 ID。 |
| order | Number | 任意 | 1 | 部門内での社員の並び替え。 |
| dept_title_list | DeptTitle[] | 任意 |  | 対応する部門内での社員の職位。 |
| dept_id | Number | 任意 | 2 | 部門 ID。 |
| title | String | 任意 | シニアプロダクトマネージャー | 部門内での社員の職位。 |
| extension | String | 任意 | `{"趣味":"旅行","年齢":"24"}` | 拡張属性。最大 2000 文字。**説明**   - モバイル端末では最大 10 個の拡張属性のみ表示できます。 - 社員に 10 個の拡張属性フィールドが設定されている場合、更新時には拡張属性フィールドの値が変更されていなくても、10 個すべての拡張属性フィールドを渡す必要があります。1 個のみを渡すと、残りの 9 個のフィールドはすべて消去されます。 - このパラメータを使用する前に、まず [**DingTalk 管理バックエンド**](https://oa.dingtalk.io/index.htm#/setting#setOrgInfo) > **設定** > **連絡先情報** で該当属性を追加する必要があります。 - このフィールドの値はリンクタイプの入力をサポートし、リンクは変数ワイルドカードによる自動置換をサポートします。現在サポートされているワイルドカードは userid、corpid です。例：`[座席住所](http://www.dingtalk.io?userid=#userid#&corpid=#corpid#)`。 |
| ext_attrs_update_mode | Number | 任意 | 1 | 拡張属性カスタムフィールドの更新モード：   - 0：上書き方式 - 1：追加方式   デフォルトは上書きです。 |
| senior_mode | Boolean | 任意 | false | 役員モードをオンにするかどうか。デフォルト値は false。   - **true**：オン。  **説明**      - オンにすると、電話番号がすべての社員に対して非表示になります。   - 一般社員は DING の送信や DingTalk ビジネス電話の発信ができません。   - 役員同士は DING の送信や DingTalk ビジネス電話の発信が可能です。 - **false**：オフ。 |
| hired_date | Number | 任意 | 1597573616828 | 入社日。UNIX タイムスタンプ、単位はミリ秒。 |
| language | String | 任意 | zh_CN | 連絡先の言語。設定値：   - **zh_CN**：中国語（デフォルト）。 - **en_US**：英語。 |
| force_update_fields | String | 任意 | manager_userid | 強制更新フィールド。指定したフィールドのクリアをサポートし、複数フィールドはカンマで区切ります。現在サポートされているフィールド：`manager_userid`、`org_email`。  **説明**   - 強制更新フィールドに org_email が含まれており、リクエスト内の org_email フィールドが空の場合、社員とエンタープライズメールの紐付けが解除され、エンタープライズメールアカウントが凍結または削除されます。 - 強制更新フィールドに org_email が含まれており、社員が既に他のエンタープライズメールに紐付けられている場合、社員と元のエンタープライズメールの紐付けが解除され、元のエンタープライズメールアカウントが凍結または削除され、社員と新しいエンタープライズメールの紐付けが確立されます。 - 強制更新フィールドに org_email が含まれており、対応するメールアカウントが公共メールまたはサービスメールの場合、メールタイプが通常のメールに変換され、社員とエンタープライズメールの紐付けが確立されます。 |
| org_email_type | String | 任意 | profession | 企業アカウント社員のエンタープライズメールタイプ。   - profession: 標準版 - base: ベーシック版 |
| loginId | String | 任意 | loginId123 | DingTalk 企業アカウントのログイン名。DingTalk 企業アカウントのみこのフィールドの更新をサポートし、シングルサインオン企業アカウントは現在サポートされていません。  **説明**  キャリアによる SMS フィルタリングを避けるため、電話番号、メール、リンクなどの連絡先情報を含めないことを推奨します。 |
| init_password | String | 任意 | init_password220 | DingTalk 企業アカウントの初期パスワード。初期パスワードは最低 8 文字です。  **説明**   - 全文字をアルファベットまたは数値にすることはできません。 - DingTalk 企業アカウントのみこのフィールドの更新をサポートし、シングルサインオン企業アカウントは現在サポートされていません。 - キャリアによる SMS フィルタリングを避けるため、電話番号、メール、リンクなどの連絡先情報を含めないことを推奨します.|
| send_password_to_user | Boolean | 任意 | false | アカウントとパスワードを送信するか。デフォルト値は false：   - **false**：送信しない - **true**：送信する   **説明**   - このパラメータが **true** の場合、`init_password` パラメータは必須です。そうでない場合は送信されません。 - 送信時は、社員の電話番号で SMS を送信するか、個人メールで電子メールを送信します。 - DingTalk 企業アカウントのみこのフィールドの設定をサポートし、シングルサインオン企業アカウントは現在サポートされていません。 |
| exclusive_mobile | String | 任意 | 150xxxxxxx | 企業アカウントの電話番号。 |
| avatarMediaId | String | 任意 | @lALPDfmVUw19YdrNA-jNA-g | 当組織の企業アカウントを更新する際にプロフィール写真の MediaId を指定可能。jpg/png 形式のみサポート。メディアファイルアップロードインターフェースを呼び出して取得できます。  **説明**  自社構築企業アカウントとシングルサインオン企業アカウントをサポート |
| nickname | String | 任意 | 名前 | 企業アカウントの名前。  **説明**  自社構築企業アカウントとシングルサインオン企業アカウントをサポート |
| dept_position_list | DeptPosition[] | 任意 |  | 部門内の在職情報。 |
| extension_i18n | Json | 任意 | `{"趣味":{"zh_CN":"旅游","en_US":"travel","aJP":"旅行"}}` | 拡張属性の国際化値。 |

## レスポンス

### レスポンスボディ

| 名前 | タイプ | 例 | 説明 |
| --- | --- | --- | --- |
| errcode | Number | 0 | 戻りコード。0 は成功を表します。 |
| errmsg | String | 該当ユーザーが見つかりません | 呼び出しに失敗した場合に返されるエラーメッセージ。 |

### レスポンスボディ例

```json
{
  "errcode":0,
  "errmsg":"ok",
  "request_id":"55o5i31j4cg8"
}
```

### エラーコード

このインターフェースの呼び出し時にエラーが発生した場合、エラーメッセージをもとに [グローバルエラーコード](/ja/open/development/server-api-error-codes-1) ドキュメントで解決策を検索してください。
