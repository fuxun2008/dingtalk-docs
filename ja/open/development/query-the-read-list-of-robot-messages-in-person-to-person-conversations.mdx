---
title: "個別チャットにおけるボットメッセージの既読リストを取得"
---

本インターフェースを呼び出すと、グループ ID、ボットコード、メッセージ ID をもとに、個別チャットにおけるボットメッセージの既読リスト情報を取得できます。企業メンバー間の個別チャットで、ボットメッセージが既読かどうかを確認する必要があるシーンに適しています。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/v1.0/robot/privateChatMessages/query |
| HTTP Method | POST |
| サポートするアプリタイプ | appType-社内アプリ　appType-サードパーティ社内アプリ |
| 必要な権限 | permission-qyapi_robot_sendmsg-社内ボットによるメッセージ送信権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | はい | 本インターフェース呼び出し用のアクセス認証情報。以下の方法で取得します。   - 社内アプリの場合、[社内アプリの accessToken を取得](/ja/open/development/obtain-the-access-token-of-an-internal-app#)インターフェースを呼び出して取得します。 - サードパーティ社内アプリの場合、[サードパーティアプリが認可された企業の accessToken を取得](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#)インターフェースを呼び出して取得します。 |

### リクエストボディ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| openConversationId | String | いいえ | 個別チャットのオープン会話 ID。[酷アプリを個別チャットへ一括インストール](https://open.dingtalk.com/document/development/batch-chat-session#)を利用し、[会話管理](https://open.dingtalk.com/document/development/org-event-overview#260a4e7084gs2)イベントを購読することで OpenConversationId パラメータの値を取得できます。 |
| robotCode | String | いいえ | ボットのコード。詳細は [ボット ID](https://open.dingtalk.com/document/development/robot-overview#) を参照してください。 |
| processQueryKey | String | はい | メッセージ ID。[カードの作成と配信](https://open.dingtalk.com/document/development/create-and-deliver-cards#)インターフェース、または [個別チャットでボットが通常メッセージを送信](/ja/open/development/the-robot-sends-ordinary-messages-in-a-person-to-person-conversation#)インターフェースを呼び出すことで、`processQueryKey` パラメータの値を取得できます。 |
| maxResults | Long | いいえ | ページング検索における 1 ページあたりの件数。 |
| nextToken | String | いいえ | 前回のクエリ後に返される、暗号化されたページング認証情報。初回クエリでは指定不要です。 |
