本ドキュメントでは、メッセージ通知の種類と利用シーン、メッセージ通知 API の機能、およびその連携方法について説明します。

## メッセージ通知の種類

DingTalk では以下の種類のメッセージ通知を提供しています。

- **テンプレートを使用した業務通知の送信：**

  メッセージテンプレートは、サードパーティ企業アプリが業務通知を通じてメッセージをプッシュする方式をアップグレードしたものです。メッセージテンプレートに対して、よりシンプルかつ標準化された開発・設定機能を提供するとともに、顧客側でより安全で管理・制御しやすいメッセージ通知機能を提供します。詳細については、[メッセージテンプレート概要](/zh/open/development/message-template-overview)を参照してください。

  **注意**

  メッセージテンプレートはサードパーティ企業アプリのみ対応しており、内部アプリでは利用できません。

- **業務通知メッセージ**：

  社内の業務通知チャット内で、マイクロアプリの名義で従業員にプッシュされる通知メッセージです。誕生日のお祝いメッセージや入社リマインダーなどが該当します。

## メッセージ通知 API の機能

### 公開されているメッセージ通知 API の一覧

メッセージ通知は豊富な API 機能を提供しています。API を通じて、開発者はメッセージ通知を組織の業務システムと連携できます。

**業務通知**

|  |  |  |  |
| --- | --- | --- | --- |
| API | 説明 | 新仕様（新しいサーバー API） | 旧仕様（サーバー API） |
| 業務通知の送信 | 業務通知メッセージを送信します。 | - | [業務通知の送信](/zh/open/development/asynchronous-sending-of-enterprise-session-messages) |
| 業務通知ステータスバーの更新 | OA 業務通知メッセージのステータスを更新します。 | - | [業務通知ステータスバーの更新](/zh/open/development/update-work-notification-status-bar) |
| 業務通知メッセージの送信進捗の取得 | 業務通知メッセージの送信進捗を取得します。 | - | [業務通知メッセージの送信進捗の取得](/zh/open/development/obtain-the-sending-progress-of-asynchronous-sending-of-enterprise-session) |
| 業務通知メッセージの送信結果の取得 | 業務通知メッセージの送信結果を照会します。 | - | [業務通知メッセージの送信結果の取得](/zh/open/development/gets-the-result-of-sending-messages-asynchronously-to-the-enterprise) |
| 業務通知メッセージの送信取消 | 業務通知メッセージを送信取消します。 | - | [業務通知メッセージの送信取消](/zh/open/development/notification-of-work-withdrawal) |

## メッセージ通知 API 機能の連携方法

DingTalk では、メッセージ通知 API のサンプル連携フローを提供しています。

- [業務通知から DingTalk ミニプログラムへのリダイレクト](https://open.dingtalk.com/document/orgapp/send-personal-work-notifications#)
- [業務通知から DingTalk マイクロアプリへのリダイレクト](/zh/open/development/redirect-micro-applications-to-work-messages)

## 用語集

### task\_id

`task_id` は業務通知メッセージの固定値の識別子フィールドです。[業務通知の送信](/zh/open/development/asynchronous-sending-of-enterprise-session-messages) API を呼び出した際に返されます。

`task_id` を使用して、[業務通知メッセージの送信進捗の取得](/zh/open/development/obtain-the-sending-progress-of-asynchronous-sending-of-enterprise-session) API および[業務通知メッセージの送信結果の取得](/zh/open/development/gets-the-result-of-sending-messages-asynchronously-to-the-enterprise) API を呼び出すことで、業務通知メッセージの送信進捗と送信結果を照会できます。
