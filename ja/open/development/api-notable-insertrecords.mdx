本インターフェースを呼び出して、AIテーブル内の指定したデータテーブルに行レコードを新規追加します。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | `https://api.dingtalk.io/v1.0/notable/bases/{baseId}/sheets/{sheetIdOrName}/records` |
| HTTP Method | POST |
| サポートされるアプリタイプ | appType-社内アプリ |
| 権限要件 | permission-Notable.Base.Write.All-AIテーブルアプリ書き込み権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | はい | 本インターフェースを呼び出す際のアクセス認証情報です。[社内アプリの access_token を取得](/ja/open/development/obtain-the-access-token-of-an-internal-app)インターフェースを呼び出して取得できます。 |

### パスパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| baseId | String | はい | AIテーブル ID。取得方法は[データ構造](/ja/open/development/data-structure)をご参照ください。 |
| sheetIdOrName | String | はい | データテーブル ID またはデータテーブル名。データテーブル ID は以下の 2 つの方法で取得できます：   - [すべてのデータテーブルを取得](/ja/open/development/api-notable-getallsheets)インターフェースを呼び出して取得します。 - [データテーブルを取得](/ja/open/development/api-notable-getsheet)インターフェースを呼び出して取得します。 |

### クエリパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| operatorId | String | はい | 操作者の unionId。以下の 2 つの方法で取得できます：   - [ユーザー詳細の照会](/ja/open/development/query-user-details)インターフェースを呼び出して取得します。 - [サイレントログインコードでユーザー情報を取得](/ja/open/development/obtain-the-userid-of-a-user-by-using-the-log-free)インターフェースを呼び出して取得します。 |
| clientToken | String | いいえ | 標準の UUID v4 形式で、操作の冪等性制御に使用されます。   - 値が空：新しいリクエストを発行します - 値が空でない：冪等更新となり、同じ値の繰り返しリクエストは重複実行されません |

### リクエストボディ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| records | Array | はい | 書き込む行レコードのデータ。 |
| fields | `Map<String, Any>` | はい | 該当行レコードの各フィールド値。`Map<String, Any>` 形式で指定します：   - key：フィールド名（String タイプ）、データテーブル内のフィールド名に対応します - value：フィールド値（Any タイプ）、フォールド種類に応じた形式の値を渡します。具体的なフィールド値の形式は、レコード値形式のドキュメントをご参照ください。[レコード値形式](https://open.dingtalk.com/document/development/record-value-format)。 |
|  | Any | いいえ | フィールド値。フォールド種類によって値の形式が異なります。詳細はレコード値形式をご参照ください。 |
