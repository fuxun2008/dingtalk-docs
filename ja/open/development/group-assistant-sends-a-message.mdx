---
title: "グループアシスタントでチャットを送信"
---

本サンプルでは、グループアシスタントでチャットを送信する方法を紹介します。

1. 対象アプリを選択し、アプリ詳細ページに入り、ベーシック情報 > 認証情報とベーシック情報をクリックします。
2. アプリのクライアント ID と Client Secret を取得します。
3. グループアシスタントチャット送信 API の権限をリクエストします。
4. アプリのアクセス認証情報を取得します。[社内アプリのアクセストークンを取得する](/ja/open/development/obtain-the-access-token-of-an-internal-app)を参照してください。
5. 開発者バックエンド - シーングループページで、[ボット](https://open-dev.dingtalk.io/fe/im#/robot/list)をリクエストし、審査通過後にボット ID パラメータ **robotCode** を取得します。
6. 開発者バックエンド - シーングループページで、[グループテンプレート](https://open-dev.dingtalk.io/fe/im#/group/list)を作成し、グループテンプレート ID パラメータ **template_id** を取得します。
7. [シーングループ - ボット](https://open-dev.dingtalk.io/fe/im#/robot/list)を[シーングループ - グループテンプレート](https://open-dev.dingtalk.io/fe/im#/group/list)に紐付け、編集内容を保存し、グループシーンリストに戻ります。
8. 対応するグループテンプレートに入り、審査を送信し、公開をクリックします。
9. **template_id** に基づきグループ作成 API を呼び出し、**openConversationId** を取得します。
10. グループアシスタントチャット送信 API を呼び出し、ボットによるグループチャットの送信を実現します。

## 前提条件

[アプリの作成](/ja/open/dingstart/create-application)のフローを完了していること。

## 操作手順

1. 対象アプリを選択し、アプリ詳細ページに入り、**ベーシック情報** > **認証情報とベーシック情報**をクリックします。
2. アプリのクライアント ID と Client Secret を取得します。
3. **開発設定** > **権限管理**をクリックし、権限検索ボックスに `qyapi_chat_manage` を入力して権限をリクエストします。
4. アプリのアクセス認証情報を取得します。[社内アプリのアクセストークンを取得する](/ja/open/development/obtain-the-access-token-of-an-internal-app)を参照してください。API を呼び出す際は、アクセストークンによって呼び出し元の身元を認証します。
5. 開発者バックエンド - シーングループページで、[ボット](https://open-dev.dingtalk.io/fe/im#/robot/list)をリクエストし、ボット ID パラメータ、すなわち **robotCode** を取得します。

### 説明

   ボットのリクエストには審査が必要です。承認後に ID を確認できます。

6. 開発者バックエンド - シーングループページで、[グループテンプレート](https://open-dev.dingtalk.io/fe/im#/group/list)を作成し、グループテンプレート ID パラメータ **template_id** を取得します。

7. [シーングループ - ボット](https://open-dev.dingtalk.io/fe/im#/robot/list)を[シーングループ - グループテンプレート](https://open-dev.dingtalk.io/fe/im#/group/list)に紐付け、編集内容を保存し、グループシーンリストに戻ります。

8. 対応するグループテンプレートに入り、審査を送信し、公開をクリックします。

### 説明

   審査は自動的に通過するため、承認は不要です。

9. **template_id** を介してグループ作成 API を呼び出し、**openConversationId** を取得します。
10. グループアシスタントチャット送信 API を呼び出し、ボットによるグループチャットの送信を実現します。
