---
title: "ストレージ内の非同期タスク情報を取得"
description: "ファイル・フォルダーの一括操作の非同期タスク完了状況と成功結果を取得します"
---

本インターフェイスを呼び出して、ストレージ内の非同期タスク情報（非同期タスクが完了したかどうか、成功したかどうかなど）を取得します。例えば、ファイルやフォルダーの一括移動、一括コピー、一括削除などの操作において、操作対象に子ノードが存在する場合、対応する操作は非同期操作となります。

## リクエスト

### 基本情報

| フィールド | 値 |
| --- | --- |
| HTTP URL | `https://api.dingtalk.io/v1.0/storage/tasks/{taskId}` |
| HTTP Method | GET |
| サポートされるアプリタイプ | appType-社内アプリ　appType-サードパーティ社内アプリ |
| 権限要件 | permission-Storage.Task.Read-企業ストレージタスク読み取り権限 |

### リクエストヘッダー

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | はい | 本インターフェイスを呼び出すためのアクセス認証情報。以下の方法で取得します：   - 社内アプリの場合は、[社内アプリのアクセストークンを取得](/ja/open/development/obtain-the-access-token-of-an-internal-app#) インターフェイスを呼び出して取得します。 - サードパーティ社内アプリの場合は、[サードパーティアプリ認可企業のアクセストークンを取得](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#) インターフェイスを呼び出して取得します。 |

### パスパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| taskId | String | はい | ストレージ内の非同期タスク ID。[ファイルやフォルダーの一括移動](/ja/open/development/bulk-move-files-or-folders#) インターフェイスを呼び出して taskId パラメータ値を取得できます。  例えば、ファイルやフォルダーの一括移動の非同期タスク ID です。 |

### クエリパラメータ

| 名前 | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| unionId | String | はい | 操作者の unionId。[ユーザー詳細を照会](/ja/open/development/query-user-details#) インターフェイスを呼び出して取得できます。 |

## レスポンス

### レスポンスボディ

| 名前 | タイプ | 説明 |
| --- | --- | --- |
| task | Object | タスク情報。 |
| id | String | タスク ID。 |
| status | String | タスクステータス。   - **INIT**：初期化 - **IN_PROGRESS**：進行中 - **SUCCESS**：成功 - **FAIL**：失敗 |
| totalCount | Long | サブタスクの総数。 |
| successCount | Long | サブタスクの成功総数。 |
| failCount | Long | サブタスクの失敗総数。 |
| failMessage | String | タスク失敗の原因。 |
| beginTime | String | タスク開始時刻。iso8601 形式。例：2022-07-29T14:55Z。 |
| endTime | String | タスク終了時刻。iso8601 形式。例：2022-07-29T14:55Z。 |
