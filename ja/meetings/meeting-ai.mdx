ビデオ会議AIは次の機能をサポートします。

*   会議中、ビデオ会議AIは会議のコンテンツをリアルタイムで確認できます。参加者ができることとして、文字起こしされた字幕の閲覧、要約の生成、会議内容に関する質問などがあり、重要な発言を聞き逃しません。
    
*  会議が終了すると、DingTalkは議事録とToDoを自動作成し、チームを記録業務から解放します。
    

---

## 概要

### リアルタイム文字起こし

ビデオ会議AIは会議のコンテンツをリアルタイムで文字起こしするため、参加者は議論された内容を素早く確認・分析できます。

### 会議後の議事録

会議終了後、DingTalkは会議の音声と文字起こしを保存し、それらをAI議事録として会議の開始者に送信します。AI議事録では、議事録と推奨されるToDoを確認できます。参加者は、会議終了ページや会議一覧などのエントリから、主催者にAI議事録へのアクセスをリクエストすることもできます。

## 使い方

### AI議事録を手動でオンまたはオフにする

AI議事録をオンにすると、会議のコンテンツがリアルタイムで文字起こしされます。すべての参加者に、画面上部に **「AI議事録の作成中」** という明確な通知が表示されます。

1.  会議中、参加者は文字起こしに基づいて自由な質問ができます。
    
2.  会議終了後、文字起こしと音声が保存され、スマート議事録が生成されてAI議事録として**会議の開始者**に送信されます。
    

**PC版：** 会議中 >> 下部の **「会議AI」** をクリック >> **「AI議事録」** をオンまたはオフにします。

![](https://img.alicdn.com/imgextra/i3/O1CN01TvyqXFSSxlEBKvlk_!!6000000006807-2-tps-5584-2740.png)

**モバイル版：** 会議中 >> 下部の **「その他」** をタップ >> **「会議AI」** をタップ >> **「AI議事録」** をオンまたはオフにします。

![](https://img.alicdn.com/imgextra/i2/O1CN01Avwf1VqXKBIAhfKP_!!6000000005250-2-tps-5272-5061.png)

### AI議事録を自動的にオンにする

**PC版：** 会議中 >> 下部のメニューバーで **「もっと」** をクリック >> **「設定」** をクリック >> **「会議AI」** をクリック >> **「AI議事録を自動的にオンにする」** を選択または解除します。

![](https://img.alicdn.com/imgextra/i2/O1CN01i4Dswy4qp3I2lCbo_!!6000000001695-2-tps-1360-1200.png)

**モバイル版：** 会議中 >> 右下の **「その他」** をタップ >> **「設定」** >> **「AI議事録を自動的にオンにする」**。

![](https://img.alicdn.com/imgextra/i4/O1CN01dpVezyebjlEAFihZ_!!6000000007530-2-tps-5050-5067.png)

## FAQ

**Q：会議後に生成されたAI議事録は誰が閲覧できますか？**

A：システムからAI議事録を自動的に受け取るのは会議の開始者のみです。すべての参加者に自動的には共有されません。主催者は、会議終了ページや会議詳細ページなどのエントリから、すばやく共有できます。

**Q：AI議事録とクラウド録画の違いは何ですか？**

|  | **AI議事録** | **クラウド録画** |
| --- | --- | --- |
| **オンにする方法** | **会議AI** >> **AI議事録**をクリック | **録画** >> **クラウド録画**をクリック |
| **会議中** | いつでも以前の議論を確認し、自由に質問できます | サポートされていません |
| **保存されるコンテンツ** | 音声＋文字起こし＋要約 | 動画＋音声＋文字起こし＋要約 |
| **配信** | デフォルトでは会議の開始者のみに送信されます | デフォルトでは会議の開始者のみに送信されます |
