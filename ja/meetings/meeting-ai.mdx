会議AIは次の機能をサポートします。

*   会議中、会議AIは会議のコンテンツをリアルタイムで確認できます。参加者ができることとして、文字起こしされた字幕の閲覧、要約の生成、会議内容に関する質問などがあり、重要な発言を聞き逃しません。
    
*   各会議の終了後、DingTalkは議事録とToDoを自動生成し、チームの手作業によるメモ取りを不要にします。
    

---

## 機能概要

### 会議中のリアルタイム文字起こしとQ&A

会議AIは会議のコンテンツをリアルタイムで文字起こしするため、参加者は議論された内容を素早く確認・分析できます。

### 会議後のスマート議事録

会議終了後、DingTalkは会議の音声と文字起こしを保存し、それらをAI議事録として会議の開始者に送信します。AI議事録では、議事録と推奨されるToDoを確認できます。参加者は、会議終了ページや会議一覧などのエントリから、主催者にAI議事録へのアクセスをリクエストすることもできます。

## 使い方

### AI議事録を手動でオンまたはオフにする

AI議事録をオンにすると、会議のコンテンツがリアルタイムで文字起こしされます。すべての参加者に、画面上部に**AI議事録の作成中**という明確な通知が表示されます。

1.  会議中、参加者はTranscriptに基づいて自由な質問ができます。
    
2.  会議終了後、Transcriptと音声が保存され、スマート議事録が生成されてAI議事録として**会議の開始者**に送信されます。
    

**デスクトップ：** 会議中 >> 下部の**会議AI**をクリック >> **AI議事録**をオンまたはオフにします。

**モバイル：** 会議中 >> 下部の**その他**をタップ >> **会議AI**をタップ >> **AI議事録**をオンまたはオフにします。

![](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/ybEnB5jDdaAd3lP1/img/0ebbd63f-0283-41cb-b7c0-89a74c86f87a.png?x-oss-process=image/crop,x_0,y_219,w_5272,h_5061/ignore-error,1)

### AI議事録を自動的にオンにする

**デスクトップ：** 会議中 >> 下部のメニューバーで**その他**をクリック >> **設定**をクリック >> **会議AI**をクリック >> **AI議事録を自動的にオンにする**を選択または解除します。

![](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/ybEnB5jDdaAd3lP1/img/75eabdb0-e766-42b0-9086-78dcf403b41e.png)

**モバイル：** 会議中 >> 右下の**その他**をタップ >> **設定** >> **AI議事録を自動的にオンにする**。

## FAQ

**Q：会議後に生成されたAI議事録は誰が閲覧できますか？**

A：システムからAI議事録を自動的に受け取るのは会議の開始者のみです。すべての参加者に自動的には共有されません。主催者は、会議終了ページや会議詳細ページなどのエントリから、すばやく共有できます。

**Q：AI議事録とクラウド録画の違いは何ですか？**

|  | **AI議事録** | **クラウド録画** |
| --- | --- | --- |
| **オンにする方法** | **会議AI** >> **AI議事録**をクリック | **録画** >> **クラウド録画**をクリック |
| **会議中** | いつでも以前の議論を確認し、自由に質問できます | サポートされていません |
| **保存されるコンテンツ** | 音声＋文字起こし＋要約 | 動画＋音声＋文字起こし＋要約 |
| **配信** | デフォルトでは会議の開始者のみに送信されます | デフォルトでは会議の開始者のみに送信されます |
