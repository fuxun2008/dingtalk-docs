DingTalk会議には、会議を始める方法が2つあります。**会議を開始**と**会議を予約**です。会議の開始はすぐに始める臨時の会議に適しています。会議の予約では、あらかじめ時間を確保し、予定の時刻に会議を始めることができます。

---

## 会議を開始するガイド

## デスクトップで会議を開始する

### 会議ページから開始する

DingTalkデスクトップクライアントを開いてログイン >> クライアント左側の**会議**をクリック >> 会議ページを表示 >> **会議を開始**をクリックします。

![](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/jP2lRYjN60prAO8g/img/c8b81956-e1eb-4b19-ae76-23104146dc86.png?x-oss-process=image/crop,x_94,y_0,w_5290,h_3400/ignore-error,1)

### チャットウィンドウから開始する

DingTalkデスクトップクライアントを開いてログイン >> チャット入力欄の下にある<strong>+</strong>アイコンをクリック >> **ビデオ・通話**を選択します。

![](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/jP2lRYjN60prAO8g/img/eda96b51-0eec-497b-85af-4c84b54e36b7.png?x-oss-process=image/crop,x_2196,y_0,w_3068,h_3572/ignore-error,1)

## モバイルで会議を開始する

### 会議ページから開始する

DingTalkモバイルアプリを開いてログイン >> 右上の**通話**アイコンをタップ >> **会議を開始**をタップします。

## 会議を予約するガイド

## デスクトップで会議を予約する

### 会議ページから予約する

**方法1：** DingTalkデスクトップクライアントを開く >> 左側の**会議**をクリック >> **会議を予約**をクリック >> 会議時間と参加者を設定 >> **完了**をクリックします。

![](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/jP2lRYjN60prAO8g/img/eaaaa2ba-4649-42af-b5a2-fcec04b02cb7.png?x-oss-process=image/crop,x_94,y_0,w_2451,h_3436/ignore-error,1)

![](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/jP2lRYjN60prAO8g/img/240d1788-483b-4ced-893c-8baf3fe5d587.png)

### カレンダーページから予約する

DingTalkデスクトップクライアントを開く >> 左側の**カレンダー**をクリック >> 左上の<strong>+</strong>ボタンをクリック >> 会議時間と参加者を選択 >> **ビデオ会議を追加可能**をクリック >> **DingTalkビデオ会議**を選択 >> **完了**をクリックします。

![](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/jP2lRYjN60prAO8g/img/d3fc1f78-559c-48cc-9dad-8de3382e5f68.png)

### チャットウィンドウから予約する

チャット入力欄の下にある<strong>+</strong>アイコンをクリック >> **予定**をクリック >> 会議時間と参加者を選択 >> **ビデオ会議を追加可能**をクリック >> **DingTalkビデオ会議**を選択 >> **完了**をクリックします。

![](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/jP2lRYjN60prAO8g/img/02bb335c-4cb5-44b1-8dd3-228040d8491e.png?x-oss-process=image/crop,x_2175,y_0,w_3073,h_3466/ignore-error,1)

## モバイルで会議を予約する

### 会議ページから予約する

DingTalkモバイルアプリを開く >> 右上の**通話**アイコンをタップ >> **会議を予約**を選択します。

### カレンダーページから予約する

DingTalkモバイルアプリを開く >> 左上の**カレンダー**をタップ >> 右下のアイコンをタップして予定を作成 >> 下にスクロールして**ビデオ会議を追加可能**をタップ >> **DingTalkビデオ会議**を選択します。

![](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/jP2lRYjN60prAO8g/img/f3dd882b-640f-4c42-8832-850845eeea5a.png?x-oss-process=image/crop,x_0,y_38,w_1598,h_1060/ignore-error,1)

### チャットウィンドウから予約する

DingTalkモバイルアプリでチャットウィンドウを開く >> 右下の<strong>+</strong>アイコンをタップ >> **予定**をタップして予定を作成 >> 下にスクロールして**ビデオ会議を追加可能**をタップ >> **DingTalkビデオ会議**を選択します。

![](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/jP2lRYjN60prAO8g/img/04ee0600-0404-4459-8075-4f53458c5706.png)

## 予約した会議の設定可能なオプション

*   会議の**タイトル**、**時間**、**参加者**を設定します。予約が完了すると、会議は**カレンダー**で確認できます。
    
*   **繰り返し会議**を設定するには、**繰り返さない**をクリック >> 繰り返しのルールを選択 >> 設定をカスタマイズします。
    
*   **会議室**を追加します。この機能は繰り返し会議には対応していません。社内でDingTalkスマート会議室にオフライン会議室を登録している場合は、ここでオフライン会議室を選択または予約できます。
    
*   **ビデオ会議**を追加します。DingTalkビデオ会議またはDingTalkライブ配信を追加できます。
    
*   **会議リマインダー**を設定するか、リマインダーなしを選択します。
    
*   会議の作成後、**会議IDと参加情報**を取得できます。
