DingTalk会議には、会議を始める方法が2つあります。**「会議を開始」** と **「会議を予約」** です。**会議の開始** はすぐに始める臨時の会議に適しています。**会議の予約** では、あらかじめ時間を予約し、予定の時刻に会議を始めることができます。

---

## 会議を開始するガイド

## PC版

### 会議ページから開始する

DingTalk PC版アプリを開いてログイン>>左側のナビゲーションバーの **「会議」** をクリック >> 会議ページを表示 >> **「会議を開始」** をクリックします。

![](https://img.alicdn.com/imgextra/i4/O1CN01nSMfiCCwCtBAjvNa_!!6000000007716-2-tps-5290-3400.png)

### チャットウィンドウから開始する

DingTalk PC版アプリを開いてログイン >> チャット入力欄の下にある **「 + 」** アイコンをクリック >> **「ビデオと通話」** を選択します。

![](https://img.alicdn.com/imgextra/i4/O1CN01fh1LsMNflfH6EDXE_!!6000000003963-2-tps-3068-3572.png)

## モバイル版

### 会議ページから開始する

DingTalkモバイルアプリを開いてログイン >> 右上の **「通話」** アイコンをタップ >> **「会議を開始」** をタップします。

## 会議を予約するガイド

## PC版で

### 会議ページから予約する

**方法一：** DingTalk PC版アプリを開いてログイン >> 左側ナビゲーションバーの **「会議」** をクリック >> **「会議を予約」** をクリック >> 会議時間と参加者を設定 >> **「完了」** をクリックします。

![](https://img.alicdn.com/imgextra/i1/O1CN01Xy5q824mN2H4yY2h_!!6000000005731-2-tps-2451-3436.png)

![](https://img.alicdn.com/imgextra/i3/O1CN012HK9WrFhRrL3eagK_!!6000000004994-2-tps-1800-1336.png)

### カレンダーページから予約する

DingTalk PC版アプリを開いてログイン >> 左側の **「カレンダー」** をクリック >> 左上の **「 + 」** ボタンをクリック >> 会議時間と参加者を選択 >> **「ビデオ会議を追加可能」** をクリック >> **「DingTalkビデオ会議」** を選択 >> **「完了」** をクリックします。

![](https://img.alicdn.com/imgextra/i3/O1CN01nzB5d69cyFDAxGfw_!!6000000001810-2-tps-5396-3420.png)

### チャットウィンドウから予約する

チャット入力欄の下にある **「 + 」** アイコンをクリック >> **「予定」** をクリック >> 会議時間と参加者を選択 >> **「ビデオ会議を追加」** をクリック >> **「DingTalkビデオ会議」** を選択 >> **「完了」** をクリックします。

![](https://img.alicdn.com/imgextra/i4/O1CN01sIuDMXp8alE6EqWx_!!6000000001398-2-tps-3073-3466.png)

![](https://img.alicdn.com/imgextra/i2/O1CN01eifczTiasEF7JgaG_!!6000000004503-2-tps-3604-2676.png)

## モバイル版で

### 会議ページから予約する

DingTalkモバイルアプリを開く >> 右上の **「通話」** アイコンをタップ >> **「会議を予約」** を選択します。

### カレンダーページから予約する

DingTalkモバイルアプリを開く >> 画面下部の **「カレンダー」** をタップ >> 右下の **「 + 」** アイコンをタップして予定を作成 >> 下にスクロールして **「ビデオ会議を追加可能」** をタップ >> **「DingTalkビデオ会議」** を選択します。

![](https://img.alicdn.com/imgextra/i1/O1CN01758V01HpY4E3FA4g_!!6000000006726-2-tps-1598-1060.png)

### チャットウィンドウから予約する

DingTalkモバイルアプリでチャットを開く >> 右下の **「 + 」** アイコンをタップ >> **「予定」** をタップして予定を作成 >> 下にスクロールして **「ビデオ会議を追加」** をタップ >> **「DingTalkビデオ会議」** を選択します。

![](https://img.alicdn.com/imgextra/i2/O1CN01MLvu4qM5WUG3XXVU_!!6000000000614-2-tps-1744-892.png)

## 予約した会議の設定可能なオプション

*   会議の **「タイトル」**、**「時間」**、**「参加者」** を設定します。予約が完了すると、会議は **「カレンダー」** で確認できます。
    
*   **「繰り返し会議」** を設定するには、**「繰返さない」** をクリック >> 繰り返しのルールを選択 >> 設定をカスタマイズします。
    
*   **「会議室」** を追加します。この機能は繰り返し会議には対応していません。社内でDingTalkスマート会議室システムにオフライン会議室を登録している場合は、ここでオフライン会議室を選択または予約できます。
    
*   **「ビデオ会議」** を追加します。DingTalkビデオ会議を追加できます。
    
*   **「会議リマインダー」** を設定するか、リマインダーなしを選択します。
    
*   会議の作成後、**「会議IDと参加情報」** を取得できます。
