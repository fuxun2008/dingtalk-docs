DingTalkのビデオ会議には複数の参加方法があります。**会議カード**、**会議ID**、**参加リンク**、**会議リスト**、**カレンダー**、または**クイックエントリバー**から参加できます。

---

## デスクトップで会議に参加する

### 会議IDで参加する

DingTalkデスクトップクライアントを開いてログイン >> 左側の**会議**をクリック >> **会議に参加**をクリック >> **会議ID**を入力 >> **会議に入る**をクリックします。

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/1GXn45KojmV4KqDQ/img/dea22bcf-5fce-4c94-b744-4241aedc29d7.png)

### 参加リンクで参加する

> ブラウザから参加する場合は、コンピューターでカメラとマイクの権限を許可してください。

**参加リンク**を開く >> **名前**を入力 >> **会議に参加**をクリックします。DingTalkクライアントを開いて参加する場合は、ページ下部の**DingTalkを開く**をクリックします。

### 会議カードで参加する

チャットウィンドウで相手から送信された**会議カード**をクリック >> 下部の**会議に参加**をクリックします。

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/Lk3lbmb2jg26jOm9/img/5821b838-58ca-428d-82cc-0782732b7bbb.png)

### 会議リストから参加する

DingTalkデスクトップクライアントを開いてログイン >> 左側の**会議**をクリック >> 右側の会議リストから参加したい会議を検索 >> **会議に参加**をクリックします。

> 予約された会議、進行中の会議、参加後に退出した会議は、すべて会議リストに表示されます。

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/1GXn45KojmV4KqDQ/img/0e9b92ca-57e5-44fd-a1c5-d67f7a35e314.png)

### カレンダーから参加する

DingTalkデスクトップクライアントを開いてログイン >> 左側の**カレンダー**をクリック >> 参加したい会議を選択 >> **会議に参加**をクリックします。

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/1GXn45KojmV4KqDQ/img/463f5dea-af26-4e06-b58a-07efbb2cef6f.png)

### 右上のプラスパネルから参加する

DingTalkデスクトップクライアントを開いてログイン >> 右上の<strong>+</strong>アイコンをクリック >> **会議に参加**をクリックします。

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/1GXn45KojmV4KqDQ/img/eb8142c6-efba-4c53-829e-11a46f1b03de.png?x-oss-process=image/crop,x_0,y_0,w_5481,h_3436/ignore-error,1)

## モバイルで会議に参加する

### 会議IDで参加する

DingTalkモバイルアプリを開く >> 右上の**通話**アイコンをタップ >> **会議に参加**をタップ >> **会議ID**を入力して参加します。

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/1GXn45KojmV4KqDQ/img/1d6a7690-47c0-4d21-986f-f18a18a02725.png?x-oss-process=image/crop,x_0,y_227,w_2432,h_5053/ignore-error,1)

### 参加リンクで参加する

> ブラウザから参加する場合は、カメラとマイクの権限を許可してください。

モバイルのチャットで相手から送信された**参加リンク**をタップ >> **会議に入る**をタップ >> **名前**を入力 >> **会議に入る**をタップします。DingTalkクライアントを開いて参加する場合は、ページ下部の**DingTalkを開く**をタップします。

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/1GXn45KojmV4KqDQ/img/e3d45963-5c40-4f1a-92e4-554e4aa65040.png?x-oss-process=image/crop,x_0,y_527,w_2432,h_4753/ignore-error,1)

### 会議カードで参加する

モバイルアプリを開く >> チャットで相手から送信された**会議カード**をタップ >> **会議に参加**をタップします。

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/1GXn45KojmV4KqDQ/img/0daf4295-4b48-4453-bcc4-5f812b9d36d9.png?x-oss-process=image/crop,x_0,y_809,w_1660,h_1400/ignore-error,1)

### 会議リストから参加する

DingTalkモバイルアプリを開く >> 右上の**通話**アイコンをタップ >> 会議リストから参加したい会議を検索 >> **会議に参加**をタップします。

> 予約された会議、進行中の会議、参加後に退出した会議は、すべて会議リストに表示されます。

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/1GXn45KojmV4KqDQ/img/5bbdb510-b2b3-46a7-bf42-9134de9d917b.png?x-oss-process=image/crop,x_0,y_230,w_2586,h_5050/ignore-error,1)

### カレンダーから参加する

DingTalkモバイルアプリを開く >> 下部の**カレンダー**をタップ >> カレンダーで参加したい会議をタップ >> **会議に参加**を選択します。

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/1GXn45KojmV4KqDQ/img/5ed3f1eb-4171-4cc7-8704-9c3b7c01bfa0.png?x-oss-process=image/crop,x_0,y_113,w_1216,h_2527/ignore-error,1)

### リマインダーバーから参加する

すでに開始している会議は、**モバイルのチャットリスト上部にあるリマインダーバー**から素早く参加できます。

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/1GXn45KojmV4KqDQ/img/8d4e5a0a-a00f-40ff-9b9f-e37c07e29b0c.png?x-oss-process=image/crop,x_0,y_206,w_2520,h_2413/ignore-error,1)
