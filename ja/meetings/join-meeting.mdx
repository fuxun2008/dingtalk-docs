DingTalkのビデオ会議には複数の参加方法があります。**会議カード**、**会議ID**、**参加リンク**、**会議リスト**、**カレンダー**、または **クイックアクセス** から参加できます。

---

## PC版

### 会議IDで参加する

DingTalk PC版アプリを開いてログイン >> 左側の **「会議」** をクリック >> **「会議に参加」** をクリック >> **「会議ID」** を入力 >> **「会議に入る」** をクリックします。

![](https://img.alicdn.com/imgextra/i2/O1CN010gskr84YHYIAfe20_!!6000000002096-2-tps-5256-3436.png)

### 参加リンクで参加する

> ブラウザから参加する場合は、コンピューターでカメラとマイクの権限を許可してください。

**「参加リンク」** を開く >> **「名前」** を入力 >> **「会議に参加」** をクリックします。DingTalkアプリを開いて参加する場合は、ページ下部の **「DingTalkを開く」** をクリックします。

### 会議カードで参加する

チャットウィンドウで相手から送信された **「会議カード」** をクリック >> 下部の **「会議に参加」** をクリックします。

![](https://img.alicdn.com/imgextra/i4/O1CN01RTzy4uypSlH1UOii_!!6000000001347-2-tps-734-470.png)

### 会議リストから参加する

DingTalk PC版アプリを開いてログイン >> 左側の **「会議」** をクリック >> 右側の会議リストから参加したい会議を検索 >> **「参加」** をクリックします。

> 予約された会議、進行中の会議、参加後に退出した会議は、すべて会議リストに表示されます。

![](https://img.alicdn.com/imgextra/i2/O1CN010zaq0eJuuTFAy1VS_!!6000000000548-2-tps-5402-3432.png)

### カレンダーから参加する

DingTalk PC版アプリを開いてログイン >> 左側の **「カレンダー」** をクリック >> 参加したい会議を選択 >> **「会議に参加」** をクリックします。

![](https://img.alicdn.com/imgextra/i4/O1CN01G09Re3zlRLGAedau_!!6000000003552-2-tps-5248-3436.png)

### 右上の **「 + 」** アイコンから参加する

DingTalk PC版アプリを開いてログイン >> 右上の **「 + 」** アイコンをクリック >> **「会議に参加」** をクリックします。

![](https://img.alicdn.com/imgextra/i2/O1CN01uU2mY5wBoFJB7y4b_!!6000000000603-2-tps-5481-3436.png)

## モバイル版

### 会議IDで参加する

DingTalkモバイルアプリを開く >> 右上の **「通話」** アイコンをタップ >> **「会議に参加」** をタップ >>  **「会議ID」** を入力して参加します。

### 参加リンクで参加する

> ブラウザから参加する場合は、カメラとマイクの権限を許可してください。

モバイルのチャットで相手から送信された **「参加リンク」** をタップ >> **「会議に入る」** をタップ >> **「名前」** を入力 >> **「会議に入る」** をタップします。DingTalkアプリを開いて参加する場合は、ページ下部の **「DingTalkを開く」** をタップします。

</div>

### 会議カードで参加する

モバイルアプリを開く >> チャットで相手から送信された **「会議カード」** をタップ >> **「会議に参加」** をタップします。

![](https://img.alicdn.com/imgextra/i3/O1CN01hBcWrgcXgaF3My3A_!!6000000003040-2-tps-1660-1400.png)

### 会議リストから参加する

DingTalkモバイルアプリを開く >> 右上の **「通話」** アイコンをタップ >> 会議リストから参加したい会議を検索 >> **「会議に参加」** をタップします。

> 予約された会議、進行中の会議、参加後に退出した会議は、すべて会議リストに表示されます。

### カレンダーから参加する

DingTalkモバイルアプリを開く >> 下部の **「カレンダー」** をタップ >> カレンダーで参加したい会議をタップ >> **「会議に参加」** を選択します。

### リマインダーバーから参加する

すでに開始している会議は、**モバイルのチャットリスト上部にあるリマインダーバー**から素早く参加できます。
