同じ話題やプロジェクト、チームの業務について複数人で話し合いたいときは、グループチャットを作成できます。

## グループチャットの作成

1.  DingTalk PC版アプリの右上にある **「 + 」** をクリックします。
    
2.  **「グループを作成」** を選択します。
    
3.  **「連絡先を選択」** の画面で、連絡先を検索するか、**友だち**、**組織構造**、**グループ**、**一括登録**から選択します。
    
4.  追加したい連絡先を選択します。
    
5.  **「完了」** をクリックします。
    

グループの作成後、チャットリストに表示されます。

![](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/r4mlQ5bJkLb4klxo/img/2f19aac5-3fa2-42ba-8df0-656ef7761fd7.png)

## グループメンバーの追加

1.  グループチャットを開きます。
    
2.  右上の歯車アイコンをクリックします。
    
3.  メンバー一覧の横にある **「 + 」** をクリックします。
    
4.  追加したい連絡先を検索するか、**一括登録**、**組織構造** から選択します。
    
5.  **「完了」** をクリックします。
    

![](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/8K4nyeZJgvppjnLb/img/e0c9407f-94c6-4082-a15a-3aaa90c8825c.png)

## グループ設定からの招待

グループチャットを開き、歯車アイコンをクリックして、**「グループQRコード」** を選択します。

このページで**グループQRコード**、**グループリンク**、**グループ番号** から連絡先を招待できます。

## グループ設定

グループチャットを開き、右上隅の歯車アイコンをクリックします。

グループ設定では、**メンバー**、**グループチャット情報**、**招待**、**パーソナライズ設定**、**グループ管理**、**ボット** などがあります。

| 面積チャート | 管理できる内容 |
| --- | --- |
| メンバー | メンバーを表示するか、グループに人を追加します。 |
| グループチャット情報 | **名前**の更新、**お知らせ**の表示、または**グループ招待**を使用します。 |
| 個人設定 | **グループ内での自分のニックネーム**、**グループ表示名**、**最上部に固定**、または**通知をミュート**を設定します。 |
| グループ管理 | 管理者、権限、クイックバー設定、参加権限、メッセージ、グループ退出を管理します。 |

## チャット履歴の削除

グループチャットを開く ＞ 歯車アイコン ＞ 下にスクロール ＞ **チャット履歴を削除** の順に選択します。

これにより、グループチャットからローカルのチャット履歴がすべて消去されます。

![](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/8K4nyeZJgvppjnLb/img/35e4e22f-7678-41d9-8410-d6fa4ed980e8.png)


## グループからの退出

グループチャットを開く ＞ 歯車アイコン ＞ 下にスクロール ＞ **グループから退会** の順に操作します。

退出すると、グループはチャットリストから削除されます。
