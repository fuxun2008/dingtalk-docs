同じトピック、プロジェクト、チームの最新情報について複数人で話し合う必要があるときは、グループチャットを作成します。

## グループチャットの作成

1.  DingTalkデスクトップアプリの右上隅にある<strong>+</strong>をクリックします。
    
2.  **グルチャ作成**を選択します。
    
3.  **連絡先を選択**で、人を検索するか、**友達**、**組織**、**グループ分け**、または**インポート**から選びます。
    
4.  追加したい人を選択します。
    
5.  **確認**をクリックします。
    

グループの作成後、メッセージ一覧に表示されます。

## グループへのメンバーの追加

1.  グループチャットを開きます。
    
2.  右上隅の歯車アイコンをクリックします。
    
3.  メンバー一覧の横にある<strong>+</strong>をクリックします。
    
4.  追加したい人を選択します。
    
5.  **確認**をクリックします。
    

![](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/8K4nyeZJgvppjnLb/img/e0c9407f-94c6-4082-a15a-3aaa90c8825c.png)

## グループ設定からの招待

グループチャットを開き、歯車アイコンをクリックして、**グループ招待**を選択します。

グループ設定ページからさらに人を招待したいときは、このエントリを使用します。

## グループ設定を開く

グループチャットを開き、右上隅の歯車アイコンをクリックします。

グループ設定では、グループ情報、メンバー、招待、通知環境設定、グループレベルの制御を管理できます。

| 面積チャート | 管理できる内容 |
| --- | --- |
| メンバー | メンバーを表示するか、グループに人を追加します。 |
| グループチャット情報 | **名前**の更新、**お知らせ**の表示、または**グループ招待**を使用します。 |
| 個人設定 | **グループ内での自分のニックネーム**、**グループ表示名**、**最上部に固定**、または**通知をミュート**を設定します。 |
| グループ管理 | 管理者、権限、クイックバー設定、参加権限、メッセージ、グループ退出を管理します。 |

## グループ権限の管理

グループチャットを開く＞歯車アイコン＞**グループ管理**＞**グループ権限設定**の順に選択します。

このページでは、@全員の使用、グループ内でのDINGの送信、グループメッセージの最上部への固定、グループニュースのピン留め、ファイルのアップロード、会議の開始など、権限を制御できます。

## グループからの退出

グループチャットを開く＞歯車アイコン＞下にスクロール＞**退出**の順に操作します。

退出すると、グループはアクティブな会話から削除されます。
