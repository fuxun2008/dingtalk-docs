グループ作成者と管理者は、**グループ管理**を開いて高度なグループ制御を管理できます。

## グループ管理を開く

1.  グループチャットを開きます。
    
2.  右上隅の歯車アイコンをクリックします。
    
3.  **グループ管理**を選択します。

## 利用できる高度な設定

グループ管理には、管理者、ミュート制御、メンバー権限、参加権限、グループツール、グループ関連機能の設定が含まれます。

| 設定 | 用途 |
| --- | --- |
| **管理者** / **追加** | グループ管理者を追加します。 |
| **ミュート設定** | ミュート関連の制御を開きます。 |
| **グループ権限設定** | 選択したグループ機能を使用できるユーザーを制御します。 |
| **グループクイックバー** | グループクイックバーを管理します。 |
| **グループ参加権限** | 新しいメンバーの参加方法を管理します。 |
| **新しいメンバーがチャット履歴を閲覧できる期間** | 新しいメンバーが閲覧できる過去の履歴の範囲を管理します。 |
| **グループカレンダー** | グループカレンダーの設定を開きます。 |
| **グループがメールを受信できる** | グループがメールを受信できるかどうかを管理します。 |
| **Ding Driveへの自動同期を有効化** | Ding Driveへの自動同期を管理します。 |
| **メンバー間の個別チャットを禁止** | グループからの個別チャットのアクセスを管理します。 |
| **グループ作成者を譲渡** | 所有権を別のメンバーに譲渡します。 |

## グループ権限設定

特定のグループ機能を使用できるユーザーを制御する必要がある場合は、**グループ権限設定**を開きます。

利用できる権限項目は次のとおりです。

*   **@全員を実行できるユーザー**
    
*   **グループでDINGを送信できるユーザー**
    
*   **グループメッセージを上部に固定できるユーザー**
    
*   **グループニュースをピン留めできるユーザー**
    
*   **ファイル、フォルダ、Ding Driveファイルをアップロードできるユーザー**
    
*   **グループでビデオ会議や音声会議を開始できるユーザー**
