**グループ設定**を使用して、グループ情報、個人の環境設定、グループ全体の管理を行います。

グループ設定を開くには、グループチャットを開き、右上の歯車アイコンをクリックします。

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/yBRq1ZPmNPRo5Odv/img/56b03218-9e3f-47fe-9159-1f338eec511e.png)

## グループ情報

グループ情報セクションでは、グループの基本的な詳細を管理します。

| 設定 | 機能 |
| --- | --- |
| **名前** | グループ名を確認または編集します。 |
| **お知らせ** | グループのお知らせを開きます。 |
| **グループ招待** | グループ招待のオプションを開きます。 |

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/yBRq1ZPmNPRo5Odv/img/73c8690b-7121-419f-9603-2c4ffa674e9a.png)

## 個人のグループ設定

これらの設定は、グループ内での自分自身の表示にのみ影響します。

| 設定 | 機能 |
| --- | --- |
| **グループ内での自分のニックネーム** | このグループでの表示名を設定します。 |
| **グループ表示名** | グループのローカル表示名を設定します。 |
| **トップに固定** | グループを会話リストの上部付近に固定します。 |
| **通知をミュート** | このグループの通知をミュートします。 |

## グループ管理

管理者、権限、参加ルール、グループ機能を管理する必要がある場合は、**グループ管理**を開きます。

| 設定 | 機能 |
| --- | --- |
| **管理者** / **追加** | グループ管理者を追加します。 |
| **ミュート設定** | グループのミュート設定を開きます。 |
| **グループ権限設定** | グループ機能に対するメンバーの権限を制御します。 |
| **グループクイックバー** | グループクイックバーを設定します。 |
| **グループ参加権限** | 新しいメンバーの参加方法を設定します。 |
| **新しいメンバーがチャット履歴を閲覧できる期間** | 新しいメンバーが閲覧できる過去の履歴の範囲を設定します。 |
| **グループカレンダー** | グループカレンダーの設定を開きます。 |
| **グループがメールを受信できる** | グループがメールを受信できるかどうかを設定します。 |
| **Ding Driveへの自動同期を有効にする** | グループファイルをDing Driveに同期します。 |
| **メンバー間の個別チャットを禁止** | グループからの個別チャットへの入口を無効にします。 |
| **グループ作成者を譲渡** | 別のメンバーにグループ作成者を譲渡します。 |

## メッセージの削除またはグループの退出

*   ローカルのメッセージを削除するには、グループ設定 > **メッセージを削除**を開きます。
    
*   グループを退出するには、グループ設定 > **退出**を開きます。
