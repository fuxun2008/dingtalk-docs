**グループ設定** では、グループチャット情報、パーソナライズ設定、グループ管理などがあります。

グループ設定を開くには、グループチャットを開き、右上の歯車アイコンをクリックします。

![](https://img.alicdn.com/imgextra/i4/O1CN01kma392VuadL4N9W8_!!6000000001089-2-tps-2154-1322.png)

## グループチャット情報

グループチャット情報では、グループの基本的な情報やグループへの招待を設定できます。

| 設定 | 機能 |
| --- | --- |
| **名前** | グループ名を確認または編集します。 |
| **お知らせ** | グループのお知らせを開きます。 |
| **グループ招待** | グループ招待のオプションを開きます。 |

![](https://img.alicdn.com/imgextra/i4/O1CN01J8XsR3h8ZaF4N9W8_!!6000000000760-2-tps-2154-1322.png)

## パーソナライズ設定

以下の設定は、グループ内での自分の表示にのみ適用されます。

| 設定 | 機能 |
| --- | --- |
| **グループ内での自分のニックネーム** | このグループでの表示名を設定します。 |
| **グループ表示名** | グループのローカル表示名を設定します。 |
| **トップに固定** | グループを会話リストの上部付近に固定します。 |
| **通知をミュート** | このグループの通知をミュートします。 |

## グループ管理

グループ管理には、管理者の追加と削減、グループ権限、グループ関連機能の設定が含まれます。

| 設定 | 機能 |
| --- | --- |
| **管理者** / **追加** | グループ管理者を追加します。 |
| **ミュート設定** | グループのミュート設定を開きます。 |
| **グループ権限設定** | グループ機能に対するメンバーの権限を制御します。 |
| **グループクイックバー** | グループクイックバーを設定します。 |
| **グループ参加権限** | 新しいメンバーの参加方法を設定します。 |
| **新しいメンバーがチャット履歴を閲覧できる期間** | 新しいメンバーが閲覧できる過去の履歴の範囲を設定します。 |
| **グループカレンダー** | グループカレンダーの設定を開きます。 |
| **グループがメールを受信できる** | グループがメールを受信できるかどうかを設定します。 |
| **Ding Driveへの自動同期を有効にする** | グループファイルをDing Driveに同期します。 |
| **メンバー間の個別チャットを禁止** | グループからの個別チャットへの入口を無効にします。 |
| **グループ作成者を譲渡** | 別のメンバーにグループ作成者を譲渡します。 |

## チャット履歴の削除またはグループからの退出

*   ローカルのメッセージを削除するには、グループ設定 > **「チャット履歴を削除」** を選択します。
    
*   グループを退出するには、グループ設定 > **「グループから退出」** を選択します。
