テキストの書式設定は、長めのメッセージを読みやすくします。最新情報を共有したり、作業をまとめたり、次のステップのリストを送信したりする際に役立ちます。

書式設定されたメッセージは、メンバーが情報をすばやく把握する必要があるグループチャットで特に役立ちます。

## 書式設定ツールバーを開く

1.  チャットを開きます。
    
2.  メッセージ入力欄で **「Aa」** をクリックします。
    

![](https://img.alicdn.com/imgextra/i2/O1CN01jdOg1HvUt9D4N9W8_!!6000000002847-2-tps-2154-1322.png)

入力欄の上に書式設定ツールバーが表示されます。

## 書式設定のオプション

| オプション | 用途 |
| --- | --- |
| **本文** | テキストスタイルを選択します。 |
| **太字** | 重要な語句を強調します。 |
| **テキストの色** | 選択したテキストをハイライトします。 |
| **斜体** | 軽い強調を加えます。 |
| **取り消し線** | 無効になったテキストとしてマークします。 |
| **箇条書き** | 順序なしリストを作成します。 |
| **番号付きリスト** | 順序付きリストを作成します。 |
| **リンク** | ハイパーリンクを追加します。 |
| **書式をクリア** | 選択したテキストから書式を削除します。 |

![](https://img.alicdn.com/imgextra/i2/O1CN012CRvMBLyC4K4N9W8_!!6000000004925-2-tps-2154-1322.png)

## 書式を設定されたメッセージの送信

1.  **「Aa」** をクリックします。
    
2.  メッセージを入力します。
    
3.  書式を設定したいテキストを選択します。
    
4.  ツールバーから書式設定オプションを選択します。
    
5.  **「送信」** をクリックします。
    

## 書式設定のヒント

*   重要なポイントや締め切りは、 **太字** にします。
    
*   アクションアイテムやステータスの更新は、**番号付きリスト** にします。
    
*   長い URL を共有したい場合は、 **リンク** を選択します。
    
*   コピーしたテキストに不要なスタイルを削除するには、 **書式をクリア** を選択します。
