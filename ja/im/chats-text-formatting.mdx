リッチテキストの書式設定は、長めのメッセージを読みやすくするのに役立ちます。最新情報を共有したり、業務をまとめたり、次のステップのリストを送信したりする際に使用してください。

書式設定されたメッセージは、読者が情報をすばやく把握する必要があるグループチャットで特に役立ちます。

## 書式設定ツールバーを開く

1.  会話を開きます。
    
2.  メッセージ入力欄で **Aa** をクリックします。
    

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/4EZlweZLRE8ZBqxA/img/1c13b842-d559-4598-9055-16eaf098c9ed.png?x-oss-process=image/crop,x_0,y_65,w_2024,h_1401/ignore-error,1)

入力ボックスの上にリッチテキストツールバーが表示されます。

## 書式設定オプション

| オプション | 用途 |
| --- | --- |
| **本文** | テキストスタイルを選択します。 |
| **太字** | 重要な語句を強調します。 |
| **テキストの色** | 選択したテキストをハイライトします。 |
| **斜体** | 軽い強調を加えます。 |
| **取り消し線** | 無効になったテキストとしてマークします。 |
| **箇条書き** | 順序なしリストを作成します。 |
| **番号付きリスト** | 順序付きリストを作成します。 |
| **リンク** | ハイパーリンクを追加します。 |
| **書式をクリア** | 選択したテキストから書式を削除します。 |

## 書式設定されたメッセージを送信する

1.  **Aa** をクリックします。
    
2.  メッセージを入力します。
    
3.  書式設定したいテキストを選択します。
    
4.  ツールバーから書式設定オプションを選択します。
    
5.  **送信** をクリックします。
    

## 書式設定のヒント

*   重要なポイントや締め切りには **太字** を使用します。
    
*   アクションアイテムやステータスの更新にはリストを使用します。
    
*   長い URL をメッセージに貼り付けずに参照を含めたい場合は **リンク** を使用します。
    
*   コピーしたテキストに不要なスタイルが含まれている場合は **書式をクリア** を使用します。
