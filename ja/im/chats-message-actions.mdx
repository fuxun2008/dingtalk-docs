メッセージと会話のアクションを使って、メッセージの詳細を確認したり、**メッセージ**で会話の表示方法を管理したりできます。

利用できるアクションは、メニューを開く場所によって異なります。メッセージアクションは、開いている会話内の特定のメッセージに適用されます。会話アクションは、会話リストに適用されます。

## メッセージアクションを開く

1.  **メッセージ**を開きます。
    
2.  会話を開きます。
    
3.  管理したいメッセージを右クリックします。
    
4.  メニューからアクションを選択します。
    

## メッセージアクション

| アクション | 機能 |
| --- | --- |
| **コピー** | メッセージのコンテンツをコピーします。 |
| **転送** | メッセージの転送フローを開きます。 |
| **返信** | メッセージへの返信を開始します。 |
| **送信取消** | 送信したメッセージを、送信取消が可能な間に取り消します。 |
| **再編集** | メッセージのコンテンツを入力欄に戻し、編集して再送信できるようにします。 |
| **複数選択** | バッチ操作のために複数のメッセージを選択できます。 |
| **その他** | 利用可能な場合、追加のメッセージアクションを開きます。 |

利用できるアクションは、メッセージのタイプ、差出人、会話タイプ、メッセージが送信されてからの経過時間によって異なる場合があります。

## メッセージの編集履歴を表示する

一部のメッセージには、編集履歴を確認するためのメッセージ横アクションボタンも表示されます。

1.  **メッセージ**を開きます。
    
2.  会話を開きます。
    
3.  確認したいメッセージに移動します。
    
4.  メッセージの横にあるメッセージアクションボタンをクリックします。
    
5.  **メッセージ編集履歴**を選択します。
    

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/3M0OzeZNkZ1LZqze/img/75ded193-c328-4e17-a002-614f9b224203.png)

**メッセージ編集履歴**パネルが会話の右側に表示されます。

メッセージが編集されたかどうかを確認したいときに使用します。

## 会話リストから会話を管理する

1.  **メッセージ**を開きます。
    
2.  管理したい会話を検索します。
    
3.  会話を右クリックします。
    
4.  メニューからアクションを選択します。
    

## 会話リストのアクション

| アクション | 機能 |
| --- | --- |
| **会話を上部に固定** | 会話をリストの上部付近に保持します。 |
| **未読にする** | 会話を未読としてマークします。 |
| **メッセージのサイレント（通知オフ）** | 会話の通知をミュートします。 |
| **この会話を表示しない** | 会話をリストから非表示にします。 |
| **個人情報** | プロフィールまたは会話の情報を開きます。 |
| **チャット履歴を空にする** | 会話のローカルチャット履歴を消去します。 |

これらのアクションは、DingTalkデスクトップアプリでの会話の表示方法に影響します。

## 会話アクションのよくある使い方

*   頻繁に確認する会話には**会話を上部に固定**を使用します。
    
*   後で会話に戻る必要があるときは**未読にする**を使用します。
    
*   アクセスできる状態は保ちつつ、通知で中断されたくない会話には<strong>メッセージのサイレント（通知オフ）</strong>を使用します。
    
*   ローカル履歴を消去せずに会話をリストから削除するには**この会話を表示しない**を使用します。
