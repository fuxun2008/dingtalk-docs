メッセージとチャットリストの操作メニューを使用すると、メッセージの返信、編集などを操作したり、チャットリストでチャットの表示方法を管理したりできます。利用できる操作は、メニューを開く場所によって異なります。

*   メッセージの操作メニュー：開いているチャット内の特定のメッセージに適用されます。
*   チャットの操作メニュー：チャットリスト内のチャットに適用されます。

## メッセージの操作メニュー

1.  **メッセージ** を開きます。
    
2.  チャットを開きます。
    
3.  操作したいメッセージを右クリックします。
    
4.  操作メニューからアクションを選択します。
    

## メッセージの操作メニューの機能

| アクション | 機能 |
| --- | --- |
| **コピー** | メッセージのコンテンツをコピーします。 |
| **転送** | メッセージの転送フローを開きます。 |
| **返信** | メッセージへの返信を開始します。 |
| **送信取消** | 送信したメッセージを、送信取消が可能な間に取り消します。 |
| **再編集** | メッセージのコンテンツを入力欄に戻し、編集して再送信できるようにします。 |
| **複数選択** | バッチ操作のために複数のメッセージを選択できます。 |
| **その他** | 利用可能な場合、追加のメッセージアクションを開きます。 |

![](https://img.alicdn.com/imgextra/i3/O1CN01W0kPbZSFCAL4N9W8_!!6000000003419-2-tps-2154-1322.png)

利用できるアクションは、メッセージのタイプ、差出人、チャットタイプ、メッセージが送信されてからの経過時間によって異なる場合があります。

## メッセージの編集履歴

再編集したメッセージには、編集履歴を確認するための **編集済み** の表示があります。

1.  **メッセージ** を開きます。
    
2.  チャットを開きます。
    
3.  確認したいメッセージに移動します。
    
4.  メッセージの下にある **「編集済み」** をクリックします。
    
5.  **編集履歴** パネルがチャットの右側に表示されます。
    

![](https://img.alicdn.com/imgextra/i4/O1CN01nrKkFTMe4uD4N9W8_!!6000000007502-2-tps-2154-1322.png)

メッセージが編集されたかどうかを確認したいときに使用します。

## チャットの操作メニュー

1.  **メッセージ** を開きます。
    
2.  管理したいチャットを検索します。
    
3.  チャットリストで会話を右クリックします。
    
4.  操作メニューからアクションを選択します。
    

## チャットの操作メニューの機能

| アクション | 機能 |
| --- | --- |
| **会話を上部に固定** | 会話をリストの上部付近に保持します。 |
| **未読にする** | 会話を未読としてマークします。 |
| **メッセージのサイレント（通知オフ）** | 会話の通知をミュートします。 |
| **この会話を表示しない** | 会話をリストから非表示にします。 |
| **個人情報** | プロフィールまたは会話の情報を開きます。 |
| **チャット履歴を空にする** | 会話のローカルチャット履歴を消去します。 |

以上のアクションは、チャットの表示方法に影響します。

## よく使うチャットの操作

*   頻繁に確認するチャットは **ピン留め** で上部に固定できます。
    
*   後でチャットに戻りたい時は **未読としてマーク** を付けます。
    
*   アクセスを保ちつつ、通知により中断されたくないチャットは **通知をオフ** にします。
    
*   ローカル履歴を消さずにチャットをリストから外したい時は **この会話を表示しない** を選択します。
