1対1のプライベートな会話には個別チャットを使用します。個別チャットは、ちょっとした質問、集中したフォローアップ、グループチャットを必要としない業務トピックに便利です。

## 個別チャットの開始

1.  DingTalkデスクトップ版アプリ上部の検索バーをクリックします。
    
2.  相手の名前を入力します。
    
3.  検索結果から相手を選択します。
    
4.  入力ボックスにメッセージを入力します。
    
5.  **Enter** を押すか、**送信** をクリックします。
    

会話を開くと、メッセージ一覧に表示されるため、後で再び開くことができます。

## 個別チャット内の検索

その相手と以前にやり取りした内容を見つけたいときは、チャット内検索を使用します。

1.  個別チャットを開きます。
    
2.  右上隅の検索アイコンをクリックします。
    
3.  **チャット履歴** を選択したままにします。
    
4.  キーワードを入力します。
    
5.  必要に応じて **フィルター** を使用して結果を絞り込みます。
    

検索結果はコンテキスト付きで開くため、会話の該当部分に戻ることができます。

## 個別チャットの管理

個別チャットは、会話の設定または会話一覧から管理できます。

| タスク | 操作手順 |
| --- | --- |
| 通知をミュートする | 会話を開く > 歯車アイコン > **通知をミュート** |
| 会話を上部に固定する | 会話を開く > 歯車アイコン > **トップに固定** |
| 会話一覧からミュートする | 会話を右クリック > **メッセージのサイレント（通知オフ）** |
| 会話一覧から上部に固定する | 会話を右クリック > **セッションをトップに固定** |
| 未読にする | 会話を右クリック > **未読にする** |
| 一覧から非表示にする | 会話を右クリック > **このセッションを表示しない** |
| ローカル履歴を消去する | 会話を右クリック > **チャット履歴を消去** |

## 個別チャットから会議を開始する

個別チャットを開き、右上隅のビデオ会議アイコンをクリックします。

会議は現在の会話から開始されるため、コンテキストを切り替えることなくチャットからライブのディスカッションに移行できます。
