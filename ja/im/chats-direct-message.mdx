個人チャットは、簡単な質問やフォローアップなどグループチャットを必要としないトピックに便利です。

## 個人チャットの作成

1.  DingTalk PC版アプリ上部の検索ボックスをクリックします。
    
2.  連絡先の名前を入力します。
    
3.  検索結果から連絡先を選択します。
    
4.  入力ボックスにメッセージを入力します。
    
5.  **Enter** を押すか、**「送信」** をクリックします。
    

チャットを開くと、チャットリストに表示されるため、後で再び開くことができます。

## 個人チャットの履歴検索

その連絡先との以前のやり取りを見つけたい際には、チャット内で検索できます。

1.  個人チャットを開きます。
    
2.  右上隅の検索アイコンをクリックします。
    
3.  **チャット記録** を選択したままにします。
    
4.  キーワードを入力します。
    
5.  必要に応じて **絞り込み** を使用して結果を絞り込みます。
    

検索結果を選択すると、チャットの該当部分に移動できます。

## 個人チャットの管理

個人チャットは、チャット設定またはチャットリストから管理できます。

| タスク | 操作手順 |
| --- | --- |
| 通知をミュートする | 会話を開く > 歯車アイコン > **通知をミュート** |
| 会話を上部に固定する | 会話を開く > 歯車アイコン > **トップに固定** |
| 会話一覧からミュートする | 会話を右クリック > **メッセージのサイレント（通知オフ）** |
| 会話一覧から上部に固定する | 会話を右クリック > **セッションをトップに固定** |
| 未読にする | 会話を右クリック > **未読にする** |
| 一覧から非表示にする | 会話を右クリック > **このセッションを表示しない** |
| ローカル履歴を消去する | 会話を右クリック > **チャット履歴を消去** |

## 個人チャットからビデオ会議を使用する

 個人チャットを開き、右上のビデオ会議アイコンをクリックします。

チャットからビデオ会議を直接開始できるため、会話の流れを中断せずにライブのディスカッションに切り替えることができます。
