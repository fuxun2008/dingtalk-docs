チャットの操作メニューを使用すると、チャットの表示方法を自由に管理できます。重要なチャットをリスト上部に固定したり、未対応のメッセージの通知を保持したり、不要なメッセージの通知を減らしたりできます。

## ピン留め

チャットを右クリックし、**「ピン留め」** を選択します。

その会話がチャットリストの上部に固定され、進行中のチャットにすぐ戻れます。

## 未読としてマーク

チャットを右クリックし、**「未読としてマーク」** を選択します。

チャットを開いたものの、後でもう一度確認したい場合に使います。

## 通知をオフ

チャットを右クリックし、**「通知をオフ」** を選択します。

通知をオフにしたチャットはリストに残りますが、新着メッセージがあっても通知は届きません。

## この会話を表示しない

チャットを右クリックし、**「この会話を表示しない」** を選択します。

履歴を削除せずに、会話をリストから取り除きたい場合に使います。

## ローカルのチャット履歴をクリアする

会話を右クリックし、**「チャット履歴をクリア」** を選択します。

その会話のローカルのチャット履歴が消去されます。

## 目的に合った操作を選ぶ

| 目的 | 使用する操作 |
| --- | --- |
| 優先度の高い会話を常に表示する | **上部に固定** |
| 後で会話に戻る | **未読にする** |
| 通知による中断を止める | **メッセージのサイレント（通知オフ）** |
| 会話をリストから取り除く | **この会話を表示しない** |
| ローカルのメッセージ履歴を消去する | **チャット履歴を消去** |
