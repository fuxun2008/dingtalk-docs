メッセージは、DingTalkで仕事上のやり取りを管理する場所です。PC版アプリでは、個人チャットやグループチャットの開始、チャット履歴の検索、チャットの表示設定、通知の管理などに対応します。

## メッセージ機能について

DingTalk PC版アプリで、左側のナビゲーションバーにある **「メッセージ」** をクリックします。

チャットリストには、最近の個人チャットとグループチャットが表示され、未読マークや新着メッセージの通知も確認できます。連絡先、グループ、チャット履歴、ファイルを検索したい場合は、DingTalk上部にある検索ボックスが使用できます。

## 個人チャットの作成

個人チャットを使用すると、他のユーザーと個別会話を行うことができます。

1.  DingTalk PC版アプリ上部の検索ボックスをクリックします。
    
![](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/mxPOG5zJab01knKa/img/778cff6b-8578-49c9-a6ff-897076a7b859.png)
    
2.  連絡先の名前を入力します。
    
3.  検索結果から連絡先を選択します。
    
4.  入力ボックスにメッセージを入力します。
    
5.  **Enter**キーを押すか、 **「送信」** をクリックします。
    

チャットを開始すると、チャットリストに表示されます。後で再びこのチャットに戻ることができます。

## グループチャットの作成

複数のユーザーが同じトピックやプロジェクトについて話し合う際には、グループチャットが役立ちます。

1.  DingTalk PC版アプリの右上にある **「 + 」** をクリックします。
    
![](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/mxPOG5zJab01knKa/img/11a04c4a-b5ff-43f4-a42f-a4c71316db2b.png)
    
2.  **「グルーブを作成」** を選択します。
    
![](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/mxPOG5zJab01knKa/img/47a19797-43ce-4378-84ae-9d1f949bcfb8.png)
    
3.  **「連絡先を選択」** の画面で、連絡先を検索するか、**友だち**、**組織構造**、**グループ**、**一括登録**から選択します。
    
4.  追加したい連絡先を選択します。
    
5.  **「完了」** をクリックします。
    

グループを作成すると、チャットリストに表示されます。

## メッセージの送信

チャット下部にある入力ボックスから、メッセージの入力と送信ができます。

| タスク | 操作方法 |
| --- | --- |
| テキストメッセージを送信する | メッセージを入力し、**Enter**キーを押すか、**送信**をクリックします。 |
| 改行を入れる | **Shift + Enter**キーを押します。 |
| テキストを書式設定する | **Aa**をクリックして、リッチテキストのツールバーを開きます。 |
| サイレント送信または送信ロックを行う | **送信**の横にあるドロップダウン矢印をクリックし、**サイレント設定**または**送信ロック**を選択します。 |
| 作成欄のショートカットを開く | <strong>+</strong>をクリックして、**連絡先**、**コードスニペット**、**DingTalkドキュメント**、**予定を作成**、**ビデオ会議**、**メール**を使用します。 |

## ビデオ会議の使用

チャットでリアルタイムの会話が必要な場合は、入力ボックスの **「 + 」** をクリックして、 **「ビデオ会議と通話」** を選択します。

チャット右上にあるビデオ会議アイコンを使用することもできます。

![](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/mxPOG5zJab01knKa/img/5d0a4a3b-b840-4097-9a30-e8b92a75b19c.png)

## チャット履歴の検索

チャット履歴を検索するには、右上の検索アイコンをクリックします。デフォルトで **チャット記録** が表示されます。キーワードを入力し、必要に応じて **「絞り込み」** を使用してさらに詳しく検索できます。

共有されたファイルを閲覧するには、右上のファイル/フォルダーアイコンをクリックします。

## チャットの管理

チャットリストで会話を右クリックすると、チャットの表示方法と通知などを設定できます。

| 操作 | 機能 |
| --- | --- |
| **セッションを上部に固定** | チャットを一覧の上部付近に固定します。 |
| **未読にする** | チャットを未読としてマークし、後で再び開けるようにします。 |
| **メッセージをサイレント（通知オフ）** | チャットの通知をミュートします。 |
| **このセッションを表示しない** | チャットを一覧から非表示にします。 |
| **チャット履歴を消去** | チャットのローカルのチャット履歴を消去します。 |

![](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/mxPOG5zJab01knKa/img/1bf6fa20-eafc-4173-9add-2ed937674e24.png)

## グループチャットの設定

グループチャットを開き、右上の歯車アイコンをクリックします。グループ設定では、メンバーの確認、**お知らせ**の作成、**グループチャットでの表示名**の変更、**ピン留め**、**通知をオフ**、**グループ管理**、**チャット履歴の削除**、**グループから退会**ができます。

![](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/mxPOG5zJab01knKa/img/5e64b833-5c4f-4d03-90ee-170bf81b7bbc.png)

## サービスチャットの管理

一部のチャットは、DingTalkのサービスや製品機能によって作成されます。サービスチャットでは、右上の歯車アイコンをクリックすると、**ピン留め**や**通知をオフ**を設定できます。
