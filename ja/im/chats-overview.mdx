メッセージは、DingTalkで業務上のチャットを管理する場所です。デスクトップアプリから、個別チャットの開始、グループチャットの作成、過去のチャットの検索、一覧でのチャットの表示方法の調整ができます。

## メッセージを開く

DingTalkデスクトップアプリで、左側のサイドバーにある**メッセージ**をクリックします。

チャット一覧には、最近の個別チャットとグループチャットが表示され、未読インジケーターや最新メッセージのプレビューも確認できます。人物、グループ、チャット記録、ドキュメント、レポート、タグ、機能、部門を探したいときは、ウィンドウ上部の検索バーを使用します。

## 個別チャットを開始する

1対1のプライベートな会話には、個別チャットを使用します。

1.  DingTalkデスクトップアプリ上部の検索バーをクリックします。
    
    ![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/mxPOG5zJab01knKa/img/fc650f95-eaff-4d2c-b09f-613d5739b8b1.png)
    
2.  相手の名前を入力します。
    
3.  検索結果から相手を選択します。
    
4.  入力ボックスにメッセージを入力します。
    
5.  **Enter**キーを押すか、**送信**をクリックします。
    

チャットを開くと、そのチャットがメッセージ一覧に表示され、後で再び開けるようになります。

## グループチャットを作成する

複数の人が同じトピックやプロジェクトについて話し合う必要があるときは、グループチャットを使用します。

1.  DingTalkデスクトップアプリの右上にある**+**をクリックします。
    
    ![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/mxPOG5zJab01knKa/img/aa6a7133-9479-4b66-a5f9-efbca0010831.png)
    
2.  **グルチャ作成**を選択します。
    
    ![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/mxPOG5zJab01knKa/img/ff7944e6-e5a9-43d3-8d84-d96f96c2627e.png)
    
3.  **連絡先を選択**で、人物を検索するか、**友だち**、**組織**、**グループ分け**、**インポート**から選択します。
    
4.  追加したい人を選択します。
    
5.  **確認**をクリックします。
    

グループを作成すると、メッセージ一覧に表示されます。

## メッセージを送信・書式設定する

チャット下部のメッセージ作成欄を使って、メッセージの作成と送信を行います。

| タスク | 操作方法 |
| --- | --- |
| テキストメッセージを送信する | メッセージを入力し、**Enter**キーを押すか、**送信**をクリックします。 |
| 改行を入れる | **Shift + Enter**キーを押します。 |
| テキストを書式設定する | **Aa**をクリックして、リッチテキストのツールバーを開きます。 |
| サイレント送信または送信ロックを行う | **送信**の横にあるドロップダウン矢印をクリックし、**サイレント設定**または**送信ロック**を選択します。 |
| 作成欄のショートカットを開く | **+**をクリックして、**連絡先**、**コードスニペット**、**DingTalkドキュメント**、**予定を作成**、**ビデオ会議**、**メール**を使用します。 |

## ビデオ会議を開始する

チャットでの議論にリアルタイムの会話が必要なときは、チャットを開き、メッセージ作成欄の**+**をクリックして、**ビデオ会議**を選択します。

グループチャットでは、チャット右上にあるビデオ会議アイコンを使用することもできます。

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/mxPOG5zJab01knKa/img/0db8747d-16ef-410e-85e0-c3e5d4a9b36a.png)

## メッセージとファイルを検索する

チャット内を検索するには、チャットを開き、右上の検索アイコンをクリックします。デフォルトで**チャット記録**が開きます。キーワードを入力し、必要に応じて**フィルター**を使って結果を絞り込みます。

共有されたファイルを閲覧するには、チャットを開き、右上のファイル/フォルダーアイコンをクリックします。

## チャットを管理する

チャット一覧でチャットを右クリックすると、表示方法や通知方法を管理できます。

| 操作 | 機能 |
| --- | --- |
| **セッションを上部に固定** | チャットを一覧の上部付近に固定します。 |
| **未読にする** | チャットを未読としてマークし、後で再び開けるようにします。 |
| **メッセージをサイレント（通知オフ）** | チャットの通知をミュートします。 |
| **このセッションを表示しない** | チャットを一覧から非表示にします。 |
| **チャット履歴を消去** | チャットのローカルのチャット履歴を消去します。 |

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/mxPOG5zJab01knKa/img/c2d9bf75-fbba-487a-be40-77962f56681a.png)

## グループ設定を開く

グループチャットを開き、右上の歯車アイコンをクリックします。グループ設定から、メンバーの確認、**お知らせ**を開く、**グループ招待**の使用、**グループ内の自分のニックネーム**の更新、**通知をミュート**のオン、**グループ管理**を開く、メッセージの消去、グループの**退出**ができます。

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/mxPOG5zJab01knKa/img/ab813e0a-7a04-4f8a-b009-2e15c3c19402.png)

## サービスチャットを管理する

一部のチャットは、DingTalkのサービスや製品機能によって作成されます。サービスチャットを開いて歯車アイコンをクリックすると、**通知をミュート**や**上部に固定**を管理できます。
