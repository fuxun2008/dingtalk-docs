メッセージ入力欄には、ファイルの送信や関連作業を素早く開始できるショートカットが用意されています。チャットで直接資料を共有したり、予定を作成したり、他のツールを開いたりすることができます。

メッセージ入力欄のショートカットを使えば、別の画面に切り替えることなく、**メッセージ** からそのまま操作を実行できます。

## チャットからファイルを送信する

1.  チャットを開きます。
    
2.  メッセージ入力欄のアップロードアイコンをクリックします。
    
![](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/1wvqrebRvbV2vnak/img/fee3274d-e5b5-4885-818e-21105d5524ec.png)
    
3.  次のいずれかのオプションを選択します。
    
    *   **ファイルをアップロード**
        
    *   **フォルダーをアップロード**
        
    *   **ドライブのファイルを送信**
        
    *   **DingTalkドキュメントを送信**
        
    
![](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/NpQlK5jwr84wLqDv/img/59c794bc-1196-4da9-bdf1-8edc4e188d79.png)
    
4.  ファイルまたはドキュメントの選択を **「完了」** します。
    

**ファイルをアップロード** で、コンピューター上のローカルファイルを送信します。**フォルダをアップロード** で、フォルダ全体を送信します。**ドライブのファイルを送信** または **DingTalkドキュメントを送信** で、DingTalkに保存済みのコンテンツを送信します。



コンピューター上の画像や動画は、**ファイルをアップロード** からローカルファイルとして送信できます。

## 入力欄のショートカット

1.  チャットを開きます。
    
2.  メッセージ入力欄の **「 + 」** をクリックします。
    
3.  使用したいショートカットを選択します。
    

メニューには、**連絡先**、**コードスニペット**、**DingTalkドキュメント**、**予定**、**ビデオ会議と通話**、**メール**が含まれます。

## ショートカットの利用

| ショートカット | 利用する場面 |
| --- | --- |
| **連絡先** | 会話から連絡先を共有または選択したいとき。 |
| **コードスニペット** | コードを構造化された形式で送信したいとき。 |
| **DingTalkドキュメント** | チャットからDingTalkドキュメントを操作したいとき。 |
| **予定を作成** | 議論に関連する予定を作成したいとき。 |
| **ビデオ会議** | 会話をライブ会議に移行したいとき。 |
| **メール** | 会話からメール関連のフローを開始したいとき。 |

## 共有ファイルをまとめて閲覧する

チャットを開き、右上のファイル/フォルダーアイコンをクリックします。

これによりチャットで共有されたファイルが表示されます。チャット履歴を遡らずに資料をすぐに確認できます。

チャット履歴を検索せずに共有ファイルを確認したい場合は、ファイルビューが便利です。。
