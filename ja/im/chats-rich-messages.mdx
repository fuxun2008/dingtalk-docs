メッセージ入力欄には、ファイルの送信や会話からの関連作業の開始に使えるショートカットが用意されています。資料を共有したり、予定を作成したり、コードスニペットを追加したり、その他のツールを開いたりする際に、チャットを離れることなくこれらのショートカットを利用できます。

入力欄のショートカットを使えば、別のモジュールに切り替えることなく、会話をそのままアクションにつなげられます。

## 会話からファイルを送信する

1.  会話を開きます。
    
2.  メッセージ入力欄のアップロードアイコンをクリックします。
    
![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/1wvqrebRvbV2vnak/img/fee3274d-e5b5-4885-818e-21105d5524ec.png)
    
3.  次のいずれかのオプションを選択します。
    
    *   **ファイルをアップロード**
        
    *   **フォルダーをアップロード**
        
    *   **ドライブのファイルを送信**
        
    *   **DingTalkドキュメントを送信**
        
    
![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/NpQlK5jwr84wLqDv/img/59c794bc-1196-4da9-bdf1-8edc4e188d79.png)
    
4.  ファイルまたはドキュメントの選択を完了します。
    

コンピューター上のローカルファイルには**ファイルをアップロード**を使用します。フォルダー全体を送信する場合は**フォルダーをアップロード**を使用します。資料がすでにDingTalkに保存されている場合は、**ドライブのファイルを送信**または**DingTalkドキュメントを送信**を使用します。

コンピューター上の画像や動画は、**ファイルをアップロード**からローカルファイルとして送信できます。

## 入力欄ショートカットを開く

1.  会話を開きます。
    
2.  メッセージ入力欄の<strong>+</strong>をクリックします。
    
3.  使用したいショートカットを選択します。
    

メニューには、**連絡先**、**コードスニペット**、**DingTalkドキュメント**、**予定を作成**、**ビデオ会議**、**メール**が含まれます。

## ショートカットの例

| ショートカット | 利用する場面 |
| --- | --- |
| **連絡先** | 会話から連絡先を共有または選択したいとき。 |
| **コードスニペット** | コードを構造化された形式で送信したいとき。 |
| **DingTalkドキュメント** | チャットからDingTalkドキュメントを操作したいとき。 |
| **予定を作成** | 議論に関連する予定を作成したいとき。 |
| **ビデオ会議** | 会話をライブ会議に移行したいとき。 |
| **メール** | 会話からメール関連のフローを開始したいとき。 |

## 会話内のファイルを閲覧する

会話を開き、右上のファイル/フォルダーアイコンをクリックします。

これにより会話で共有されたファイルが開き、メッセージ履歴をスクロールすることなく共有された資料を見つけられます。

チャットメッセージを検索せずに共有された資料を見つけたいときは、ファイルビューを利用してください。
