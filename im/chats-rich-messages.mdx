The message composer includes shortcuts for sending files and starting related work from a conversation. Use these shortcuts when you want to share materials, create an event, add a code snippet, or open other tools without leaving the chat.

Composer shortcuts help you turn a conversation into an action without switching to another module first.

## Send files from a conversation

1.  Open a conversation.
    
2.  Click the upload icon in the message composer.
    
![](https://img.alicdn.com/imgextra/i3/O1CN013z51ZjohDwC4N9W8_!!6000000006086-2-tps-2154-1322.png)
    
3.  Select one of the following options:
    
    *   **Upload File**
        
    *   **Upload Folder**
        
    *   **Send Files in DingTalk Drive**
        
    *   **Send DingTalk Docs**
        
    
![](https://img.alicdn.com/imgextra/i4/O1CN01TuVrf8c5nNC4N9W8_!!6000000003339-2-tps-2154-1322.png)
    
4.  Complete the file or document selection.
    

Use **Upload File** for a local file on your computer. Use **Upload Folder** when you need to send an entire folder. Use **Send Files in DingTalk Drive** or **Send DingTalk Docs** when the material is already stored in DingTalk.

Images and videos on your computer can be sent as local files through **Upload File**.

## Open composer shortcuts

1.  Open a conversation.
    
2.  Click **+** in the message composer.
    
3.  Select the shortcut you want to use.
    

The menu includes **Contacts**, **Code snippet**, **DingTalk documentation**, **New Event**, **Video Conference**, and **Mail**.

## Shortcut examples

| Shortcut | Use it when |
| --- | --- |
| **Contacts** | You need to share or select a contact from the conversation. |
| **Code snippet** | You want to send code in a structured format. |
| **DingTalk documentation** | You want to work with DingTalk documentation from the chat. |
| **New Event** | You want to create an event related to the discussion. |
| **Video Conference** | You want to move the conversation into a live meeting. |
| **Mail** | You want to start a mail-related flow from the conversation. |

![](https://img.alicdn.com/imgextra/i2/O1CN01aaFt37SCzVE4N9W8_!!6000000000936-2-tps-2154-1322.png)

## Browse files in a conversation

Open a conversation and click the file/folder icon in the upper-right corner.

This opens the files shared in the conversation, so you can find shared materials without scrolling through the message history.

Use the file view when you need to find shared materials without searching through chat messages.
