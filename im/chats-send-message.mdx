description: "Send text messages with formatting, attach files or documents, send silently to avoid notifications, lock the message composer to prevent accidental sending, and use composer shortcuts."
---

Use the message composer to write, format, and send messages in direct messages or group chats.

## Send a text message

1.  Open a conversation.
    
2.  Type your message in the input box.
    
3.  Press **Enter** or click **Send**.
    

To add a line break without sending the message, press **Shift + Enter**.

## Format a message

Click **Aa** in the message composer to open the rich text toolbar.

You can use formatting options such as **Body**, **Bold**, **Text Color**, **Italic**, **Strikethrough**, **Bulleted List**, **Numbered List**, **Link**, and **Clear Formatting**.

Use rich text when you want to send a structured update, a list of action items, or a message that needs emphasis.

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/NpQlK5jwr84wLqDv/img/f4d2a5c8-3551-41e6-8d60-1e6707ce0cc6.png)

## Send files or documents

1.  Open a conversation.
    
2.  Click the upload icon in the message composer.
    
3.  Select **Upload File**, **Upload Folder**, **Send Files in DingTalk Drive**, or **Send DingTalk Docs**.
    
4.  Complete the selection.
    

Use this menu when you need to send a local file, a folder, a file from DingTalk Drive, or a DingTalk Doc.

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/NpQlK5jwr84wLqDv/img/01d63297-cd60-46e5-8ba3-bc89bf0db647.png)

## Send silently or lock sending

1.  Type your message.
    
2.  Click the dropdown arrow next to **Send**.
    
3.  Select **Set silent** or **Lock Send**.
    

Use **Set silent** when the message should be delivered without interrupting others. Use **Lock Send** when you need to send with additional protection.

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/NpQlK5jwr84wLqDv/img/6f035cc5-5dac-48d8-9e1e-1ed505e2f16f.png)

## Use composer shortcuts

Click **+** in the message composer to open shortcuts.

The menu includes:

*   **Contacts**
    
*   **Code snippet**
    
*   **DingTalk documentation**
    
*   **New Event**
    
*   **Video Conference**
    
*   **Mail**
    

Use these shortcuts when you want to create related work directly from the conversation.
