Rich text formatting helps make longer messages easier to read. Use it when you need to share updates, summarize work, or send a list of next steps.

Formatted messages are especially helpful in group chats where readers need to scan information quickly.

## Open the formatting toolbar

1.  Open a conversation.
    
2.  Click **Aa** in the message composer.
    

![](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/4EZlweZLRE8ZBqxA/img/2b840945-1002-45b3-a147-e5caa2988988.png)

The rich text toolbar appears above the input box.

## Formatting options

| Option | Use it to |
| --- | --- |
| **Body** | Choose the text style. |
| **Bold** | Emphasize important words. |
| **Text Color** | Highlight selected text. |
| **Italic** | Add light emphasis. |
| **Strikethrough** | Mark text as no longer valid. |
| **Bulleted List** | Create an unordered list. |
| **Numbered List** | Create an ordered list. |
| **Link** | Add a hyperlink. |
| **Clear Formatting** | Remove formatting from selected text. |

![](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/4EZlweZLRE8ZBqxA/img/59c00527-28a6-476a-93da-32d0d1fa8a56.png)

## Send a formatted message

1.  Click **Aa**.
    
2.  Type your message.
    
3.  Select the text you want to format.
    
4.  Choose a formatting option from the toolbar.
    
5.  Click **Send**.
    

## Formatting tips

*   Use **Bold** for key points or deadlines.
    
*   Use lists for action items or status updates.
    
*   Use **Link** when you want to include a reference without pasting a long URL into the message.
    
*   Use **Clear Formatting** if copied text brings in unwanted styles.
