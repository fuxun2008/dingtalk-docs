Use search when you need to find a person, group, previous message, document, or shared file in DingTalk.

You can search from the main DingTalk window or from inside a specific conversation.

## Search across DingTalk

1.  Click the search bar at the top of the DingTalk window.
    
2.  Enter a keyword.
    
3.  Review results by category.
    
4.  Select a result to open it.
    

Search results can include **All**, **Contacts**, **Groups**, **Chat Records**, **Document**, **Report**, **Tags**, **Functions**, and **Departments**.

Use global search when you are not sure where the item is located.![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/r4mlQ5bJkLBpXlxo/img/94205c70-41dd-438d-b9d6-f6148aac1ff1.png)

## Search within a conversation

Use in-chat search when you already know which conversation contains the message.

1.  Open the conversation.
    
2.  Click the search icon in the upper-right corner.
    
![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/r4mlQ5bJkLBpXlxo/img/3b7fe2e3-7100-4a25-ba2e-4c6586bdc34f.png)
    
3.  Keep **Chat Records** selected.
    
4.  Enter a keyword.
    
5.  Use **Filter** to narrow the results. Use **Reset** to clear filters.
    

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/r4mlQ5bJkLBpXlxo/img/eaf99f2d-f652-41dc-8984-09bd0a24dfbc.png)

## Browse files in a conversation

Open a conversation and click the file/folder icon in the upper-right corner.

Use this view when you want to find files shared in the conversation rather than searching message text.

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/r4mlQ5bJkLBpXlxo/img/0b24f217-1f67-4873-b5af-c0cea9b88354.png)

## Tips for better search results

*   Use specific keywords, such as a person's name, project name, or document title.
    
*   Use in-chat search when you know which conversation contains the message.
    
*   Use the file/folder icon when you are looking for shared files rather than text messages.
