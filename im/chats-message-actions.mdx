Use message and conversation actions to review message details or manage how a conversation appears in **Messages**.

The actions available depend on where you open the menu. Message actions apply to a specific message in an open conversation. Conversation actions apply to the conversation list.

## Open message actions

1.  Open **Messages**.
    
2.  Open a conversation.
    
3.  Right-click the message you want to manage.
    
4.  Select an action from the menu.
    

## Message actions

| Action | What it does |
| --- | --- |
| **Copy** | Copies the message content. |
| **Forward** | Opens the forwarding flow for the message. |
| **Reply** | Starts a reply to the message. |
| **Recall** | Recalls a message you sent, when recall is still available. |
| **Re-edit** | Puts the message content back in the composer so you can edit and send it again. |
| **Multi-Choose** | Lets you select multiple messages for a batch action. |
| **More** | Opens additional message actions when available. |

The available actions may vary by message type, sender, conversation type, and how long ago the message was sent.

## View message edit history

Some messages also include a message-side action button for edit history.

1.  Open **Messages**.
    
2.  Open a conversation.
    
3.  Move to the message you want to check.
    
4.  Click the message action button next to the message.
    
5.  Select **Message Edit History**.
    

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/3M0OzeZNkZ1LZqze/img/75ded193-c328-4e17-a002-614f9b224203.png)

The **Message Edit History** panel opens on the right side of the conversation.

Use this when you need to check whether a message has been edited.

## Manage a conversation from the conversation list

1.  Open **Messages**.
    
2.  Find the conversation you want to manage.
    
3.  Right-click the conversation.
    
4.  Select an action from the menu.
    

## Conversation list actions

| Action | What it does |
| --- | --- |
| **Set-top session** | Keeps the conversation near the top of the list. |
| **Mark as unread** | Marks the conversation as unread. |
| **Message Do Not Disturb** | Mutes notifications for the conversation. |
| **Do not display this session** | Hides the conversation from the list. |
| **Personal Information** | Opens profile or conversation information. |
| **Empty chat history** | Clears local chat history for the conversation. |

These actions affect how the conversation appears for you in DingTalk desktop app.

## Common ways to use conversation actions

*   Use **Set-top session** for conversations you check frequently.
    
*   Use **Mark as unread** when you need to come back to a conversation later.
    
*   Use **Message Do Not Disturb** for conversations that should stay accessible but should not interrupt you.
    
*   Use **Do not display this session** to remove a conversation from your list without clearing its local history.
