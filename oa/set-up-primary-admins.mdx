# I. Feature Overview

**Primary Admin:** Has full administrative permissions across the organization. Can sign in to the Admin Console and manage the organization's Contacts, Attendance, Approval, Reports, Announcements, and other applications. Can also delegate administrative permissions to others.

# II. Operation Flow

**Path 1:** **Home > Assign Admins > Add primary admins**

**Path 2:** **Security & permission > Permission > Add primary admins**

**⚠️ Important Notes:**

The account that originally created the organization structure is designated as the **Creator** primary admin. This account cannot be added or deleted — it can only be transferred.

Primary admins without the **Creator** tag are regular primary admins. They can be added or deleted, and changes take effect immediately.

Only one primary admin with the Creator tag can be set. The maximum number of regular primary admins is 999.
:::
