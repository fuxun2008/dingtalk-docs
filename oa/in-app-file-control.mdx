---
title: "In-App File Control"
description: "Restrict forwarding downloading and copy-paste of in-app files and scope the policy to specific employees departments or roles from the admin console."
---

Organizations can manage operations related to in-app files, including controlling actions such as forwarding, downloading, and copy-paste.

---

## II. User Guide

### 1. Admin Console Navigation

In the left navigation pane, go to **Security & permission > Security > Data Protection > In-App File Control**

### 2. Administrator — No Rules Configured

In-App File Control includes multiple capabilities, covering both mobile and desktop clients and involving various file operations.

Taking "Download files to the mobile terminal" as an example:

When not configured, the feature is disabled.

When disabled, the behavior is consistent with the default DingTalk experience.

### 3. Administrator — Configuration Example

<Steps>
  <Step title="Preview the card configuration">
    Click the info icon to preview the effect of the card configuration.

    <Frame>
      <img src="https://img.alicdn.com/imgextra/i3/O1CN01Yqm2U59fBPE1D1eJ_!!6000000004915-2-tps-596-347.png" alt="Preview the card configuration" />
    </Frame>
  </Step>
  <Step title="Enable the feature">
    Toggle the switch and click **Confirm** in the dialog to enable the feature.

    <Frame>
      <img src="https://img.alicdn.com/imgextra/i2/O1CN01swUjbxK1rlH1cSHz_!!6000000005868-2-tps-798-749.png" alt="Enable the feature" />
    </Frame>
  </Step>
  <Step title="Configure the applicable scope">
    The feature applies to all employees by default.

    Click **Edit** to configure the applicable scope — specify which employees the policy applies to or excludes.

    For example, to apply the policy only to the Engineering Department, select **Specific Employees**, then use the contact picker to select the department.

    The contact picker also supports selection by role, giving administrators flexibility to configure as needed.
