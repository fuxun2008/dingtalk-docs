This guide is for project leads and organization admins of new customers. It covers the complete flow — from choosing a plan on the website, starting a free trial, registering the admin, and creating an organization, to signing in to the Admin Console and bulk-importing enterprise accounts.

<Info>
  **Who this is for**: Project leads and the first organization admin responsible for driving a DingTalk enterprise POC (Proof of Concept).
</Info>

## Overview

<Steps>
  <Step title="Open the website and explore plans">Open the DingTalk global website and compare the Free / Basic / Standard / Premium plans.</Step>
  <Step title="Start a free trial">Choose a plan that fits and apply for a 30-day full-featured free trial.</Step>
  <Step title="Register the first admin">Sign up, complete identity verification, and set a password.</Step>
  <Step title="Create an organization">Fill in the organization details and record the Org ID and Organization Code.</Step>
  <Step title="Sign in to the Admin Console">Enter the Admin Console to configure your organization.</Step>
  <Step title="Build the department structure">Create departments based on your test scope.</Step>
  <Step title="Bulk-import enterprise accounts">Download the Excel template, bulk-import, and spot-check the results.</Step>
</Steps>

## Step 1: Open the website and choose a plan

Visit the DingTalk global website: [https://www.dingtalk.io/](https://www.dingtalk.io/) (Chinese page: [https://www.dingtalk.io/zh/](https://www.dingtalk.io/zh/)).

The website offers four plans. Choose one based on your POC user count, business scenarios, security requirements, storage needs, and system integration scope:

| Plan | Best for |
|------|----------|
| **Free** | An out-of-the-box product experience |
| **Basic** | Startups and small teams — validate core capabilities such as messaging, calendar, and document collaboration |
| **Standard** | Growing organizations — stronger security policies, more cloud storage, and support services |
| **Premium** | Mid-to-large organizations — more advanced capabilities and large-scale cross-team collaboration |

## Step 2: Start a free trial

On the website, click **Start Free Trial**. Every plan is eligible for a 30-day full-featured free trial — no credit card required.

<Tip>
  If your POC involves Enterprise, data compliance, SSO, data region, or custom requirements, you can also click **Contact Sales**: [https://www.dingtalk.io/contact-sales/](https://www.dingtalk.io/zh/contact-sales/?from=%2F)
</Tip>

**Prepare before applying:**

- Organization name and country/region
- Estimated number of POC users
- Planned start time and test period
- Key business scenarios to validate
- Super Admin's name, email, and phone number

<Note>
  **Suggested application note**: Applying for a DingTalk enterprise POC, ~XX users, XX-day test period, focused on validating organization management, admin workflows, meeting collaboration, and bulk employee onboarding.
</Note>

## Step 3: Register the admin account

Choose one of the following methods to sign up as prompted: **a valid email** / **a Google account** / **a valid phone number with verification code**. Complete identity verification, set a password, and accept the Terms of Service and Privacy Policy.

<Tip>
  For an enterprise POC, use the customer's long-term work email as the Super Admin account, and configure a backup admin.
</Tip>

## Step 4: Create the organization

Select your target plan and complete the free trial or subscription flow as prompted. When creating the organization, prepare the following:

| Field | Recommendation |
|------|----------|
| Organization Name | Use the company's official English name; avoid personal or temporary project names |
| Country / Region | Select the organization's primary operating or POC region |
| Industry / Organization Size | Fill in the actual industry and expected headcount |
| Super Admin | Use a verified admin email or phone number |
| Org ID | Save the unique organization identifier assigned after creation |
| Organization Code | Used to locate the organization when signing in with an enterprise account; record it separately from the Org ID |

<Warning>
  After the organization is created, be sure to save the **Org ID**. The **Organization Code** required for enterprise-account sign-in can be viewed by the admin under **Security and Permission → Organization code login**.
</Warning>

## Step 5: Sign in to the Admin Console

The admin visits: [https://oa.dingtalk.io/](https://oa.dingtalk.io/)

Enter your organization details as prompted and choose a sign-in method:

- Registered email or phone number + password
- Phone number + verification code
- Scan the QR code with mobile DingTalk
- Enterprise account + Organization Code + password
- A linked third-party account

You can also enter from the DingTalk client: **Profile Photo → Admin Console**, or **Contacts → organization name → Manage**.

<Note>
  If your account belongs to multiple organizations, make sure you enter the one for this POC.
</Note>

## Step 6: Build the department structure

In the Admin Console, open Contacts and create the department structure your POC needs:

**Admin Console → Contacts → Department Management → Add Department**

<Tip>
  Create top-level departments first, then add the second-level departments needed for your test scope. Department names should match the customer's current organization structure.
</Tip>

## Step 7: Bulk-import enterprise accounts via Excel

**Path**: Admin Console → Contacts → Members → Batch Edit → Bulk Import

<Steps>
  <Step title="Download the template">Click **Download Template** and use the standard Excel template downloaded from your current organization.</Step>
  <Step title="Fill in employee details">Follow the example row and instructions in the template to enter employee details. Delete the example row before uploading.</Step>
  <Step title="Keep the template structure">Do not change the column names, column order, worksheet structure, or file type.</Step>
  <Step title="Upload the file">Return to the import page, click **Upload File**, select your completed Excel file, then click **Import**.</Step>
  <Step title="Spot-check the results">After the import completes, spot-check the member list by department, name, email, or phone number.</Step>
</Steps>

<Tip>
  Import 3–5 admins and test users first. Once accounts, department assignments, and sign-in all work correctly, import the remaining POC users.
</Tip>

## Troubleshooting imports

If the upload or import fails:

<AccordionGroup>
  <Accordion title="Check the employee record">Review the relevant employee record based on the on-screen error message.</Accordion>
  <Accordion title="Verify fields and format">Confirm that required fields and formats match the template instructions.</Accordion>
  <Accordion title="Verify the template structure">Confirm you have not changed the template's column names, column order, or worksheet structure.</Accordion>
  <Accordion title="Fix and retry">Fix the incorrect records and upload again.</Accordion>
  <Accordion title="Handle page issues">If the page behaves unexpectedly, refresh it, sign in again, or retry with the latest version of Google Chrome.</Accordion>
</AccordionGroup>

## POC acceptance checklist

<Check>Once the steps below are complete, you can start configuring and testing business scenarios for the DingTalk enterprise POC.</Check>

- [ ] Target plan, region, user count, and trial period are confirmed
- [ ] The Super Admin can sign in to both the DingTalk client and the Admin Console
- [ ] Organization name, region, time zone, and admin details are accurate
- [ ] The department structure required for the POC is built
- [ ] Test accounts are successfully imported via Excel and assigned to the correct departments
- [ ] At least 3 test users with different roles have completed their first sign-in
- [ ] Import errors have been fixed or closed out
