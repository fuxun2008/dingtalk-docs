---
title: "Organization Code Login"
description: "Administrators locate and share the organization code in the Admin Console so members can sign in to enterprise accounts with their login name and password."
---

Administrators can view and copy the current organization code in the Admin Console. Members can sign in to their enterprise accounts using the organization code, login name, and password.

---

## II. Operation Flow

<Steps>
  <Step title="View the current organization code">
    **View the current organization code:** Organization settings > Organization code

    <Frame>
      <img src="https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/ybEnB5jovard3lP1/img/0c8a07fa-d49b-4118-89b3-b460b0c89ba3.png" alt="View the current organization code" />
    </Frame>
  </Step>
  <Step title="Add member accounts">
    **Add member accounts**

    **Path 1:** Home > Add Members > Add Members

    **Path 2:** Contacts > Members > Add Members

  </Step>

After configuring the member's information, the administrator can copy the details and share them with the member.

Members can then sign in to the enterprise account using the **organization code**, **username**, and **password**.
