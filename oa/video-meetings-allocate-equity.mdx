# Prerequisites

Administrators must sign in to the [Admin Console](https://oa.dingtalk.io/).

# Equity Allocation

In the left navigation pane of the Admin Console, click **Video Meetings > Conference Equity Allocation** to allocate equity to specific users.

:::
Cloud Meeting Room is shared with all employees by default, but can be allocated to specific members.

Meeting concurrency is shared with all employees by default. Once switched to authorized members only, only authorized members can use the equity.

Meeting duration is shared with all employees by default. Once switched to authorized members only, only authorized members can use the equity.
:::

Taking **Cloud Meeting Room** as an example:

1.  Switch to the **Cloud Meeting Room** tab. You can choose between Entitlement View or User View to examine the allocation from different perspectives.
    
    ![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/4EZlweZd1ojaQqxA/img/30440797-f24f-41f0-9cd3-4cf6a469dade.png)
    
    ![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/4EZlweZd1ojaQqxA/img/294c1e39-1a84-47a0-a3dc-214665a284f8.png)
    
2.  To allocate a meeting room equity to a specific user, expand the corresponding meeting room equity, click **Modify**, then select the user to allocate it to.
    

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/4EZlweZd1ojaQqxA/img/3e826896-2491-449d-8348-faba741e8c5a.png)

Usage rules for different allocation scenarios and equity types:

:::
Users will first consume any equity allocated to them by the administrator. When the allocated equity resources are insufficient, they will automatically fall back to the shared equity pool.

If a user has access to multiple equity types, the system will prioritize them based on availability in the following order: Cloud Meeting Room first, then Meeting Concurrency, and finally Meeting Duration.
:::

# Resource Usage

In the left navigation pane of the Admin Console, click **Video Meetings > Amount of equity** to view the resource usage of different equity types and monitor real-time resource consumption.
