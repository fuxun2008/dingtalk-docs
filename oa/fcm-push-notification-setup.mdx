# What is FCM?

FCM (Firebase Cloud Messaging) is a cross-platform messaging solution that supports Android, iOS, and Web platforms. It is an enhanced version of GCM (Google Cloud Messaging).

If you want your exclusive App to receive offline push notifications on overseas devices, please apply for FCM and provide the required materials.

# Apply for FCM

## (1) Apply for a Google Developer Account

## (2) Register on Firebase

Create a project and register an app on Firebase. Registration URL: [https://console.firebase.google.com/](https://console.firebase.google.com/)

After creating the project, select the Android icon to configure the Android app:

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/oJGq750ZzNR62lAK/img/c4aad5dd-2700-4c73-8ca9-12d7982b655e.png?x-oss-process=image/crop,x_0,y_0,w_2123,h_1256/ignore-error,1)

Please note:

*   **Android package name**: Enter the correct exclusive DingTalk package name
    
*   **App nickname (optional)**: Enter the exclusive DingTalk app name
    

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/oJGq750ZzNR62lAK/img/101a77fa-1f28-41e1-a02d-54c25993bd9e.png)

## (3) Download the Configuration File and Upload to the DingTalk Packaging Platform

Click to download **google-services.json**. Save the file and send it to DingTalk technical support for configuration.

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/oJGq750ZzNR62lAK/img/5e35c707-9ce5-476f-ab49-5edf39df96ee.png)

## (4) Access the Console to Configure Additional Parameters

Proceed to the final step and go to the console.

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/oJGq750ZzNR62lAK/img/76639f3f-62a5-493a-8138-42f1fe8027d9.png)

## (5) Create a Service Account Key

Navigate to **Project settings > Service accounts > Generate new private key**, as shown below:

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/oJGq750ZzNR62lAK/img/df3d85fa-c5a6-49ba-bbe3-55eb86b80f42.png?x-oss-process=image/crop,x_0,y_0,w_2123,h_1256/ignore-error,1)

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/oJGq750ZzNR62lAK/img/03d425ad-ee49-44ef-a16e-a37cbd4ea8f3.png)

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/oJGq750ZzNR62lAK/img/2479da7f-c331-4f51-826e-243b7c261aa2.png)

After clicking **Generate key**, a JSON file will be automatically generated. Save the file and send it to DingTalk technical support:

![image](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/LAJdl6zMMMDQlke1/img/adb6ae9a-4fa7-4764-87af-5dd4afd82d38.png)

## (6) Create a Realtime Database

Click **Create Database**:

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/oJGq750ZzNR62lAK/img/ab8c9db6-2bad-4c34-9358-a9b65051a3d1.png)

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/oJGq750ZzNR62lAK/img/a5fa837c-2683-4850-aa0a-0ad7625cac12.png)

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/oJGq750ZzNR62lAK/img/003a8cd3-04c4-4ab8-b7a0-6290a50a54e0.png)

Click **Enable**, then copy the database URL as a packaging material.

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/oJGq750ZzNR62lAK/img/f417ba2c-bb63-47a4-a099-f78d598bf473.png)

## (7) Provide the Above Materials to DingTalk for Configuration

*   google-services.json
    
*   Service account key JSON file
    
*   Realtime Database URL
    

## (8) Test FCM via the Firebase Console (Optional)

**Note: This step is optional.**

To verify FCM, you need to prepare a device with Google push services (an Pixel device is recommended). Go to the Firebase console and select **Messaging**.

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/oJGq750ZzNR62lAK/img/3ab137e0-1067-4a11-a519-c10fc121a042.png)

Follow the prompts step by step to send a test notification. **Important: Only test before going live — avoid sending messages to all users to prevent service disruptions.**

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/oJGq750ZzNR62lAK/img/9327cdf4-d064-4acb-a47d-f42cf13af335.png)

After sending, the device will receive the test notification, indicating that the FCM setup was successful:

![image](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/LAJdl6zMMMDQlke1/img/fb12f2da-5680-4df3-a285-e394f73f979a.png?x-oss-process=image/crop,x_0,y_305,w_760,h_291/ignore-error,1)
