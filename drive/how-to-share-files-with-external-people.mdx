At work, you may often need to share files with external people. Sending files securely is important. This guide provides the recommended steps.

## Method 1: Configure Permissions

### Desktop

Open the DingTalk Drive home page, **Team Files** on the Docs home page, or **My Files (from DingTalk Drive)** under My Docs. Find the target file or folder, click **...** for more options, and select **Permission Management**.

![截屏2026-06-11 16.44.34.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/5VLqXLb2k0NEVqX1/img/98eb54a0-c519-49a7-bab9-14d50ec9c4f3.png?x-oss-process=image/crop,x_0,y_69,w_3456,h_2165/ignore-error,1)

Click **Add Collaborator**, select the member you want to add, choose the corresponding permission level, and click **OK**. The permission notification can be sent through one-on-one chat.

Permission levels include **Can manage**, **Can edit**, **Can view/download**, and **View only**.

To better protect information security, if the external person does not need to edit the file, set the permission to **View only**. If they need to download the file, set the permission to **Can view/download**.

## Method 2: Send a Link

Open the DingTalk Drive home page, **Team Files** on the Docs home page, or **My Files (from DingTalk Drive)** under My Docs. Find the target file or folder and click **...** for more options.

![截屏2026-06-11 17.05.52.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/5VLqXLb2k0NEVqX1/img/47100563-2543-4e45-9b38-b88197cf04ba.png?x-oss-process=image/crop,x_0,y_69,w_3456,h_2165/ignore-error,1)

For online documents such as documents, sheets, and mind maps, click **...**, then click **Share**. The file share will be sent to the other party as a DingTalk chat message, and permissions can be adjusted in the chat interface.

For folders, local files, videos, images, and similar items, click **...** and then click **Send Link** to share.

### Mobile

For online documents such as documents, sheets, and mind maps, tap **...** for more options and then tap **Send to Chat**.
