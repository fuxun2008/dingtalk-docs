DingTalk Drive provides each user with 2 GB of private storage space in **Private Drive**. Files are synchronized in real time across desktop and mobile, and data is protected with encryption for safer use.

Because DingTalk Drive is deeply integrated with DingTalk, you can save files to DingTalk Drive in one click.

## Desktop

Click **Add to** in the lower-right corner of the target file, choose the save directory, and then select the corresponding folder.
