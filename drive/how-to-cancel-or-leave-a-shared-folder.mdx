---
title: "How to Cancel or Leave a Shared Folder"
description: "As a folder creator, cancel sharing on desktop or mobile so the folder becomes private again; as a member, leave a shared folder you no longer need so it stops appearing in your DingTalk Drive."
---

If you are the creator of a folder, you can cancel sharing for that folder. After sharing is canceled, the folder becomes private again, and others can no longer view or edit it.

If you are a recipient of a shared folder, you can only leave the share. You cannot cancel sharing for everyone. After you leave the share, the folder is removed from your full file list.

## Desktop

Open the DingTalk Drive home page, **Team Files** on the Docs home page, or **My Files (from DingTalk Drive)** under My Docs. Find the target folder, click **...**, select **Permission Management**, and remove members who currently have access.
