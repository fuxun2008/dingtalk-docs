title: "How to Set or Change Member Permissions"
description: "Assign or change DingTalk Drive permissions precisely by file and by person on desktop or mobile, with notes on edge cases — protecting data assets while keeping the right people in collaboration."
---

DingTalk Drive supports precise permission assignment by file and by person, helping protect data assets.

## Desktop

Open the DingTalk Drive home page, **Team Files** on the Docs home page, or **My Files (from DingTalk Drive)** under My Docs. Find the target file or folder, click **...** for more options, and select **Permission Management**.

![截屏2026-06-11 15.34.53.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/8oLl952DemZ1glap/img/8167195e-c2e7-435a-b44d-32fdf51cb039.png?x-oss-process=image/crop,x_0,y_69,w_3456,h_2165/ignore-error,1)

Click **Add Collaborator**, then select the specified group, person, or department to grant access.

![截屏2026-06-11 15.41.57.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/8oLl952DemZ1glap/img/d1ce55d3-2a0e-4ef2-987b-e158aed0d693.png)

After collaborators are added, you can modify permissions for people, groups, or departments that already have access.

![截屏2026-06-11 15.39.55.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/8oLl952DemZ1glap/img/fa62770c-44a3-4f4f-a137-6437a51f4718.png?x-oss-process=image/crop,x_0,y_69,w_3456,h_2165/ignore-error,1)

## Mobile

Open the DingTalk Drive home page, **Team Files** on the Docs home page, or **My Files (from DingTalk Drive)** under My Docs. Find the target file or folder, tap **...** for more options, select **Permission Management**, and then tap **Add Collaborator**.

![IMG_5030.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/8oLl952DemZ1glap/img/4be08b25-7875-4056-9ee3-1d0a9b059cc7.png)

![IMG_5029.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/8oLl952DemZ1glap/img/06727e3e-b108-44bb-bdbf-c890730547d4.png)

![IMG_5031.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/8oLl952DemZ1glap/img/4a92626f-5eb9-413b-9b23-8778c4fcc7f3.png)

Select the specified group, person, or department to grant access, then choose the corresponding permission level: **Can manage**, **Can edit**, **Can view/download**, or **View only**.

## Notes

*   Authorization information can be sent to the other party through DingTalk chat. The recipient can receive the authorization message immediately and can change permissions directly in the chat box.
    
*   If the specified target is a group or department, the system automatically syncs membership changes for that group or department.
