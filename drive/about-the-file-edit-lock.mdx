# What Is the File Edit Lock?

*   When a user starts editing a file in a DingTalk Drive local sync folder, the file becomes locked.
    
*   Locked files cannot be edited by others on other devices, which prevents version conflicts and reduces version management overhead.
    
*   When the user closes the file, the lock is automatically released, and others can open and edit it.
