---
title: "How to Use the DingTalk Drive File Picker to Send Files Efficiently"
description: "Use the DingTalk Drive File Picker inside chat — click the send-file icon below the input box, choose Send DingTalk Drive File, and pick existing files from your Drive to send efficiently."
---

In a chat message window, click the **send file** icon below the input box, then select **Send DingTalk Drive File** to choose and send files from DingTalk Drive.
