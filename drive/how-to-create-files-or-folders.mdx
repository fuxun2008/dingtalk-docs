The DingTalk Drive home page supports creating and uploading files or folders, making it easier for enterprises and users to manage files independently.

## Desktop

1.  Open **DingTalk Drive**. In **Recents**, click **New** in the upper-right corner, then select the file type or folder you want to create.
    
    ![截屏2026-06-11 14.02.50.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/5VLqXLb2k0xBwqX1/img/7cac3504-df35-4686-b235-2dd83761ade0.png?x-oss-process=image/crop,x_0,y_69,w_3456,h_2165/ignore-error,1)
    
2.  On the DingTalk Drive home page, open **My Files**. You can also open **My Docs** on the Docs home page and go to **My Files (from DingTalk Drive)**. Click **New** in the upper-right corner to create a file type, upload files, or upload folders.
    
    ![截屏2026-06-11 13.41.39.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/5VLqXLb2k0xBwqX1/img/e036bc31-9a18-4572-98f4-cdd66e83ba7f.png?x-oss-process=image/crop,x_0,y_69,w_3456,h_2165/ignore-error,1)
    
    ![截屏2026-06-11 14.07.04.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/5VLqXLb2k0xBwqX1/img/23951d22-9176-4f71-9d84-b21663edc440.png?x-oss-process=image/crop,x_0,y_69,w_3456,h_2165/ignore-error,1)
    
3.  On the DingTalk Drive home page, open **Team Files**. Create a folder first, then enter the folder to create file types, upload files, or upload folders.

When creating a folder in **Team Files**, configure the corresponding permissions:

*   **Add specified people:** Add members in the organization who can access the folder.
    
*   **Security configuration:** Use file preview watermarks, anti-leakage protection, and flexible permission settings to reduce the risk of sensitive team information leakage and protect data security.

## Mobile

### Method 1

Open DingTalk, go to **Workbench**, and select **DingTalk Drive**. You can also search for the **DingTalk Drive** app in the DingTalk search box.

As on desktop, you can open **Recent** or **My Files** and tap the **+** button in the lower-right corner to create folders, documents, sheets, collection forms, mind maps, whiteboards, and more.

![IMG_5015.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/5VLqXLb2k0xBwqX1/img/3d4e543e-69f1-4d17-a9d9-046145ff9691.png)

![IMG_5016.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/5VLqXLb2k0xBwqX1/img/0878ae34-429c-4dfc-b6b3-af775d574ae2.png)

As on desktop, in **Team Files**, you must first create a folder and configure permissions. Then tap the **+** button in the lower-right corner to create folders, documents, sheets, collection forms, mind maps, whiteboards, and more.

### Method 2

In DingTalk, go to **More** and select **Docs**. Under **My Files (from DingTalk Drive)**, tap the **+** button in the lower-right corner to create folders, documents, sheets, collection forms, mind maps, whiteboards, and more.
