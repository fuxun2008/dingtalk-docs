title: "What Is DingTalk Drive?"
description: "An Alibaba Cloud-based enterprise drive uniting file storage, management, and collaboration — save files in one click, set granular permissions, edit online anywhere, and collaborate effortlessly."
---

DingTalk Drive is an enterprise drive based on Alibaba Cloud. It provides an intelligent and secure enterprise data management solution. DingTalk Drive combines **file storage, file management, and multi-person collaboration** in one file management platform.

You can **store, edit, and share** work and study materials from any device, anytime and anywhere, making document collaboration more efficient.

The initial capacity of Enterprise Drive is 100 GB.

DingTalk Drive mainly consists of **Enterprise Drive**, which includes three folders:

1.  My Files
    
2.  Team Files
    
3.  Chat Files, including My Chat Files and Internal Group Files

## Save to DingTalk Drive in One Click and Access Files Anytime

Files can be saved to DingTalk Drive in one click, so enterprise work assets can be managed in one place. The process is simple, and files can be viewed, edited, and organized at any time.

## More Granular Permission Management

Fine-grained file permissions let you grant access precisely by file and by person, helping protect enterprise data assets.

## Edit Online Anytime, Anywhere

Open documents directly from DingTalk Drive on any device. Edits are saved automatically in real time, so you can create freely wherever you are.
