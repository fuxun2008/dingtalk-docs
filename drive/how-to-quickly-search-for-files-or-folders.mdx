title: "How to Quickly Search for Files or Folders"
description: "Use DingTalk Drive's fast search on desktop and mobile to quickly locate files or folders in a large drive — improving work efficiency by skipping manual browsing through deep folder trees."
---

To improve work efficiency and quickly find target files in a large file drive, DingTalk Drive supports fast search.

## Desktop

On the DingTalk Drive home page, enter a title or content keyword in the search box. Select the file type and filter scope to quickly find the target file.

## Mobile

On the DingTalk Drive home page, enter a title or content keyword in the search box, tap **Filter**, and select the file type to quickly find the target file.
