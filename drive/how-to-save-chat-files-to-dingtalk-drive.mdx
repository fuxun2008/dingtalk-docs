---
title: "How to Save Chat Files to DingTalk Drive"
description: "Save chat files to DingTalk Drive on desktop or mobile — Enterprise Drive starts with 100 GB across My Files, Team Files, and Chat Files, so personal and team work files stay organized in one place."
---

DingTalk Drive supports storing personal and team work files. Under each enterprise organization, Enterprise Drive initially provides three storage folders: **My Files**, **Team Files**, and **Chat Files**. The initial capacity is 100 GB.

After an employee leaves the organization, they can no longer access these files, which helps protect information security.

## Desktop

To save enterprise files from a DingTalk chat window, such as local files, online documents, videos, or images, select **Add to** on the message card and save the file to **Team Files** under **DingTalk Drive**.

To save personal files from a DingTalk chat window, such as local files, online documents, videos, or images, select **Add to** on the message card and choose **My Files** under **DingTalk Drive**.

![](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/oJGq75kdAmvVPlAK/img/3a609ea7-9f43-4b9e-a503-896938aa2cf3.png?x-oss-process=image/crop,x_0,y_69,w_3456,h_2165/ignore-error,1)

## Mobile

Tap **Add to** on the file message card, then choose to save the file to **Team Files** or **My Docs**.
