title: "How to Edit Files in DingTalk Drive"
description: "Open the DingTalk Drive file list on desktop or mobile, click the online editing icon next to a file, or open the file directly to start collaborative editing without downloading or extra tools."
---

## Desktop

Open the DingTalk Drive home page, select the target file, and click the online editing icon next to the file name. You can also click the file directly to start editing it online.

![](https://img.alicdn.com/imgextra/i3/O1CN01vkWFXkFU5nH713Mn_!!6000000006308-2-tps-3456-2169.png)

## Mobile

Open **DingTalk Drive** and tap the target file to start editing it online.
