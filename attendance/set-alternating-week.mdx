## 1. Overview

If your organization follows an alternating single/double day off (alternating week schedule) attendance pattern—working six days one week and five days the next in a rotating cycle—configure it as described below to manage attendance flexibly.

## 2. Use cases

*   Organizations that follow an alternating single/double day off (alternating week schedule) attendance pattern.

*   Other attendance scenarios that follow a regular date pattern.

## 3. Steps

### Fixed shift attendance

#### Method 1: Set special dates

*   **Mobile:** Open **Mobile DingTalk > Workbench > Attendance > Settings >** enter the **Fixed shift attendance** attendance group **> Attendance hours > Special dates >** add **Mandatory clock-in dates / No clock-in dates required**.

*   **Desktop:** Open **Desktop DingTalk > Workbench > Attendance > Attendance group management >** select the target **attendance group > Edit > Attendance hours settings > Special dates >** add **Mandatory clock-in dates / No clock-in dates required**.

### 2. Shift-based attendance

#### Method 1: Set a scheduling cycle

<Note>
**Notes:**

Add a new scheduling cycle, set **Days per cycle** to 14, and configure the shifts for the two weeks as needed (for example, work on days 1–5, rest on days 6 and 7, work on days 8–13, and rest on day 14). After clicking Confirm, open the scheduling table, click the scheduling start date of the target employee, select **Schedule by cycle**, and choose the cycle. This applies the alternating single/double day off (alternating week schedule) schedule from that date through the last day of the current month.
</Note>

*   **Mobile:** Open **Mobile DingTalk > Workbench > Attendance > Settings >** enter the shift-based attendance group **> Scheduling > Scheduling settings > Scheduling cycle**.

<Frame caption="Setting a scheduling cycle on mobile">
![Scheduling cycle settings on mobile](https://img.alicdn.com/imgextra/i4/O1CN016CscIqA2wZI3YnZB_!!6000000000590-2-tps-1754-943.png)
</Frame>

*   **Desktop:** Open **Desktop DingTalk > Workbench > Attendance > Attendance group management >** select the **Shift-based attendance** group **> Edit > Attendance hours settings > Add scheduling cycle**.

<Frame caption="Setting a scheduling cycle on desktop">
![Scheduling cycle settings on desktop](https://img.alicdn.com/imgextra/i4/O1CN01OcZWZdLy8iD2XyzE_!!6000000006170-2-tps-1255-677.png)

#### Method 2: Import a scheduling table

<Note>
**Notes:**

1. You can schedule employees manually in batches. For details on configuring a shift-based attendance group, refer to **Admin sets up a shift-based attendance group**.

2. Add attendance shifts first, so the downloaded Excel file includes the corresponding shift options.
</Note>

*   **Desktop:** Open **Desktop DingTalk > Workbench > Attendance > Scheduling management >** click the target attendance group **Edit scheduling > Batch schedule via Excel > Download scheduling table > Edit the downloaded scheduling table** to schedule employees **> Import scheduling table**, and save.

## 4. FAQ

<AccordionGroup>
  <Accordion id="q1" title="Can special dates be set in batches?">

Mandatory clock-in dates cannot be set in batches and must be added one day at a time. No clock-in dates required can be set in batches only on desktop, where you can add them by selecting a date range.

  </Accordion>
  <Accordion id="q2" title="Can special dates be set retroactively?">

Yes. Special dates can be set retroactively.

  </Accordion>
  <Accordion id="q3" title="Does deleting special dates have any impact?">

Deleting special dates within 180 days after they are set will affect attendance data. Deleting them after 180 days will not affect attendance data.

  </Accordion>
</AccordionGroup>
