<AccordionGroup>
  <Accordion title="How do I add a shift?">

If an attendance group has multiple shifts configured, you can choose from them during scheduling.

  </Accordion>
</AccordionGroup>
## Mobile

<Steps>
  <Step>

Open DingTalk on mobile > **Workbench** > **Attendance** > **Settings** > **Shift Management** > **Add Shift**.

 **⚠️ Notes:**

Total working hours: Close/\*hours are counted as one day of attendance (the number of days is editable).

<Frame caption="Adding a shift on mobile">
![Add shift screen on mobile DingTalk](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/MAeqxebJ4e9RdO8j/img/3129cc0c-f558-4b85-866d-58956fc7979c.png)
</Frame>

  </Step>
  <Step>

Tap an existing shift and edit it.

 **⚠️ Notes:**

If this shift is currently in use by an attendance group, any changes will affect that attendance group.

<Frame caption="Editing an existing shift on mobile">
![Edit shift screen on mobile DingTalk](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/MAeqxebJ4e9RdO8j/img/db46789e-b05a-40e1-8e2e-22db82147546.png)
</Frame>

  </Step>
  <Step>

If an attendance group already exists, open DingTalk on mobile > **Workbench** > **Attendance** > **Settings** > select the target attendance group > **Edit Attendance Group** > **Scheduling Settings** > **Attendance Shifts**, then tap the target shift to edit it.

 **⚠️ Notes:**

If this shift is currently in use by an attendance group, any changes will affect that attendance group.

  </Step>
</Steps>
## Desktop

<Steps>
  <Step>

Go to [**Admin Console**](https://oa.dingtalk.io) > **Workbench** > **App Center** > **Attendance** > **Shift Management** > **Add Shift**.

 **⚠️ Notes:**

1. Shift owner: The shift owner can delete or modify their own shift. The shift creator is the default owner, and other admins can be added for collaborative management.

2. Clock-in time range: Clock-ins made outside the configured time range do not count toward attendance.

3. Late off, late in the next day: If an employee works late on the first day, they may arrive later the next day. This option is supported only for on-site clock-ins under fixed shift attendance.

4. Shift working hours: This value serves as the basis for working-hours attendance statistics, as well as statistics for leave requests, business trips, and outings.
