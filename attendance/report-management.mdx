## 1. Overview

Report management is a tool for collecting, processing, analyzing, and displaying data. It helps organizations understand their operations and make informed decisions.

## 2. Use cases

*   Employee attendance statistics

*   Leave usage tracking

## 3. How to use

### View reports

<Steps>
  <Step>

Admins with the required permissions can open DingTalk desktop > Workbench > Attendance.

<Frame caption="View report page example">
![View report entry on the DingTalk Workbench](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/QvjnA3jbvDKDROXo/img/507f07ea-db66-48f7-bfbb-8a791e9e79f2.png)
</Frame>

  </Step>
  <Step>

Go to Attendance statistics > Report management > Select the target report > Click View to see the statistical details.

<Frame caption="View report page example">
![Statistical details of an attendance report](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/QvjnA3jbvDKDROXo/img/93a9dd1f-a3a6-4124-9d92-008fb88cac90.png)
</Frame>

<Note>
**Report descriptions:**

1. Monthly summary: aggregated monthly attendance data.

2. Daily statistics: aggregated daily attendance data.

3. Suspected cheating records (basic report): records employees' suspected cheating behavior for review. Cannot be deleted.

4. Clock-in time (basic report): records employees' daily clock-in and clock-out times. Cannot be deleted.

5. Original records (basic report): records every clock-in entry from employees for review. Cannot be deleted.
</Note>

  </Step>
</Steps>

### Create a report

<Steps>
  <Step>

Go to Attendance statistics > Report management > Click Add report > Select the report type.

<Frame caption="Create report page example">
![Selecting a report type when creating a new report](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/QvjnA3jbvDKDROXo/img/3a927b19-93f2-41c8-b38b-e3b961378b6f.png)

  </Step>

Click Settings > Configure the report name, owner, view permission, and description > Save.

</Frame>

  </Step>
  <Step>

Select Add column > Select the fields to associate > Save.

<Frame caption="Create report page example">
![Adding a column to a report](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/QvjnA3jbvDKDROXo/img/2634d5b9-0dd9-4c6f-bb82-ffc6794e87b5.png)
</Frame>

<Frame caption="Create report page example">
![Selecting fields to associate with the new column](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/QvjnA3jbvDKDROXo/img/174c45b4-fdd4-43e4-9839-24a8f012e004.png)
</Frame>

  </Step>
  <Step>

Click the column name to edit or delete it.

<Note>
**General rules (whether a leave type is paid can be set in the leave rules. Path:** Admins with the required permissions can open **DingTalk desktop > Workbench > Attendance > Leave management > Leave rules > Edit an existing leave type or Create a leave rule):**

1. When an employee has a missed clock-in: do not deduct attendance.

2. Paid leave: annual leave, compensatory leave, marriage leave.

3. Unpaid leave: personal leave.

4. Whether to deduct attendance when an employee takes unpaid leave: do not deduct attendance.

5. When an employee is on a business trip: attendance is calculated based on clock-in results.

6. When an employee is out on business: attendance is calculated based on clock-in results.
</Note>

### Basic reports

The system provides preset reports—**Suspected cheating records, Clock-in time, and Original records**—that cannot be edited or deleted. You can export these reports and view their export records.

<Note>
**Report descriptions:**

1. Suspected cheating records (basic report): records employees' suspected cheating behavior for review. Cannot be deleted.

2. Clock-in time (basic report): records employees' daily clock-in and clock-out times. Cannot be deleted.

3. Original records (basic report): records every clock-in entry from employees for review. Cannot be deleted.
</Note>
