## 1. Overview

Fixed shift attendance groups are designed for office-based employees with fixed working hours, such as 9-to-5. If your organization uses **fixed shift** attendance, follow the steps below to set it up.

## 2. Use cases

*   Centralized office work, such as employees in the administration, finance, and human resources departments.

*   Other scenarios that follow standard working hours.

## 3. Procedure

### On mobile

<Steps>
  <Step>

An admin with the required permissions can go to DingTalk Mobile > Workbench > Attendance > Settings > Global settings > Add attendance group > Attendance type, and select Fixed working hours.

<Frame caption="Page example">
![Attendance type selection on mobile](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/YdgOk27mJKrR6q4B/img/fc495f7a-95da-4b18-b521-682c85a6896e.png)
</Frame>

  </Step>
  <Step>

Under Attendance time, select the working days and set the start and end times for those days. You can also tap Add rule to configure multiple attendance time rules.

  </Step>
  <Step>

Tap Working hours to select another shift or add a new one. For details about shifts, see **Admin shift settings**.

</Frame>

  </Step>
</Steps>
### On desktop

<Steps>
  <Step>

An admin with the required permissions can go to DingTalk Desktop > Workbench > Attendance > Attendance group management > Add attendance group.

<Frame caption="Add attendance group page example">
![Add attendance group page](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/YdgOk27mJKrR6q4B/img/126be24a-f839-467a-81f5-8140e7503d8b.png)
</Frame>

  </Step>
  <Step>

Click Attendance time > Settings > Attendance type, select Fixed shift, and configure the remaining fields as needed.

<Note>
**About fixed shift (fixed working hours):**

All members of the attendance group clock in at the same times. This mode suits office-based work, such as 9-to-5.
</Note>

## 4. FAQ

<AccordionGroup>
  <Accordion id="q1" title="Can I change the attendance group type after setup?">

Yes. Go to **DingTalk Mobile > Workbench > Attendance > Settings > Global settings > Edit the target attendance group > Change the attendance type**.

  </Accordion>
  <Accordion id="q2" title="Why can't I set up fixed shift attendance?">

To set up fixed shift attendance, you must be the **Super Admin of the organization or a Sub Admin with Attendance permissions**. Contact an admin with the required permissions to go to **Admin Console > Security and permissions > Manage permissions**, and assign a Super Admin or Sub Admin.

  </Accordion>
  <Accordion id="q3" title="What if there are other working hours?">

If there are other working hours, an **admin with the required permissions** can click **Change shift** to update that day's shift. This helps with schedules such as a 5.5-day or 4.5-day workweek. For example, if a half day of leave is needed on a specific date, set that day to a half-day shift.

*   Permission path: Go to **Admin Console > Security and permissions > Manage permissions**, and assign a Super Admin or Sub Admin.

*   Change shift path: Go to **DingTalk Mobile > Workbench > Attendance > Settings > More settings > Shift management**, and click **Add shift** to create a new shift, **or** click **【＞】** next to a shift to delete or edit it.

  </Accordion>
  <Accordion id="q4" title="Will absenteeism be recorded if I don't clock in on a holiday?">

If your company's holiday schedule matches statutory public holidays, turn on **Auto rest on statutory holidays** in the attendance group. Once enabled, the attendance group automatically marks the day as a rest day, and no absenteeism is recorded when you don't clock in.

  </Accordion>
  <Accordion id="q5" title="How many days of scheduling can I view in a fixed shift attendance group?">

Fixed shift attendance groups support viewing scheduling for the next **15 days** only.

  </Accordion>
</AccordionGroup>
