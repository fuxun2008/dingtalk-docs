"Real-time alerts for employee check-in cheating" is a capability of the enhanced attendance security version. After you purchase the enhanced version and enable this feature, the admin receives a real-time message notification on DingTalk whenever an employee cheats on check-in, **up to three times per day**. View the full cheating records under "Attendance → Statistics → Anti-cheating → Violation check-in list."

## Enable settings

<Info>
Path to enable: **Attendance → Statistics → Anti-cheating → Real-time alerts for employee check-in cheating**
</Info>
