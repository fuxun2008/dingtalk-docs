"Real-time alerts for employee clock-in cheating" is a capability of the Attendance Security Enhanced version. After you purchase the enhanced version and enable this feature, the admin receives a real-time message notification on DingTalk whenever an employee cheats during clock-in, **up to three times per day**. View the full cheating records under **Attendance → Statistics → Anti-cheating → Violation clock-in list**.

## Enable settings

<Info>
Path to enable: **Attendance → Statistics → Anti-cheating → Real-time alerts for employee clock-in cheating**
</Info>
