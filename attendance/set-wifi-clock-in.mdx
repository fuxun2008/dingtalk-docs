## 1. Overview

Wi-Fi clock-in matches the MAC address of the Wi-Fi router with the MAC address of the network the employee connects to. Enter the **complete MAC address**. For the pros and cons of each clock-in method, see [**Differences between clock-in methods**](/attendance/clock-in-methods-comparison).

## 2. Use cases

This method suits organizations with fixed workplaces that record attendance by connecting to a designated company Wi-Fi network. No extra equipment is required.

## 3. Procedure

### Mobile

An Admin with the required Permissions can go to **DingTalk mobile app > Workbench > Attendance > Settings > Global Settings > Add attendance group or Edit an existing attendance group > Clock-in method**.

## 4. FAQ

<AccordionGroup>
  <Accordion id="q1" title="Why can't iOS devices use Wi-Fi clock-in?">

A single Wi-Fi network may have multiple MAC addresses. iOS devices identify the network by the **Wi-Fi** MAC address. We recommend that the Admin use an Android phone to add the MAC address of each Wi-Fi network.

  </Accordion>
  <Accordion id="q2" title="How do I clock in across multiple Wi-Fi networks?">

Set multiple clock-in Locations and multiple clock-in Wi-Fi networks. Employees can tap to clock in as soon as they reach any of the Locations or connect to any of the Wi-Fi networks.

  </Accordion>
  <Accordion id="q3" title="How many Wi-Fi networks can be added to an attendance group?">

You can add up to **1,000** Wi-Fi networks to a single attendance group.

  </Accordion>
</AccordionGroup>
