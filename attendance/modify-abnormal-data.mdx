## 1. Feature overview

The clock-in App automatically records attendance errors such as missed clock-ins and late arrivals, and allows Admins to modify them. If an employee forgets to clock in or clocks in late, the Admin can update the record based on the actual situation.

## 2. Use cases

*   The employee has an attendance error but does not need to submit an Approval form to fix it.

*   Special circumstances prevented the employee from clocking in.

*   The employee has used up the monthly makeup clock-in quota, but a missed clock-in or similar error still needs to be corrected.

## 3. Procedure

Attendance errors can be modified in two ways: the Admin **updates the record directly in the Admin Console**, or **the employee submits a makeup clock-in request** for the Admin to approve.

### Admin modifies directly

#### Mobile

Go to **DingTalk Mobile > Workbench > Attendance > Statistics > Team statistics > Daily statistics > Missed clock-in / Late arrival / Number of clock-ins / Expected attendance > Corresponding User > Corresponding date > Modification result**, locate the attendance error, and tap **Modify**. After the change, the attendance report shows the Admin who made the modification.

#### Desktop

Go to **DingTalk Desktop > Workbench > Attendance > Attendance statistics > Error handling > Select the corresponding date / range / error status / handling result > Click the corresponding User >** and handle attendance error records such as **missed clock-in / late arrival / external work**.

<Note>
**Notes:**

To **modify attendance errors for multiple employees at once**, the Admin can go to **DingTalk Desktop > Workbench > Attendance > Attendance statistics > Error handling >** select multiple Users on this Page, and click **Batch process**.
</Note>

### Employee submits a makeup clock-in request

<Steps>
  <Step>

The employee submits a makeup clock-in request. Open DingTalk Mobile > Workbench > Attendance > tap Apply in the upper right of the clock-in Page > Select the required Approval form Type (for example, makeup clock-in, and fill in the makeup clock-in time as needed) > Submit the Approval form. Once the request is submitted, the system automatically pushes a message to the approver.

<Frame caption="Example: Employee submitting a makeup clock-in request on mobile">
![Employee submitting a makeup clock-in request on mobile](https://img.alicdn.com/imgextra/i4/O1CN01EeTc5QQiX2K1W9zv_!!6000000003295-2-tps-748-519.png)
</Frame>

  </Step>
  <Step>

The Admin accepts the employee's makeup clock-in request. Open DingTalk Mobile > Workbench > Open Work Notifications > Find the corresponding Approval form > Tap Accept to complete the makeup clock-in Approval. The attendance data will then automatically update the error record.

<Frame caption="Example: Admin receiving a makeup clock-in request">
![Admin receiving a makeup clock-in request](https://img.alicdn.com/imgextra/i2/O1CN01CnoOc0R7jfE0Ys24_!!6000000004643-2-tps-277-579.png)
</Frame>

<Note>
**Notes:**

Alternatively, the Admin can open **DingTalk Mobile > Workbench > OA Approval > Pending >** find the **makeup clock-in request** submitted by the employee **> Accept** the Approval to complete the makeup clock-in.
</Note>

  </Step>
</Steps>
## 4. FAQ

<AccordionGroup>
  <Accordion id="q1" title="Can a normal clock-in record be changed to an error?">

No. Changing a normal clock-in record to an error is not supported.

  </Accordion>
  <Accordion id="q2" title="How far back can attendance errors be modified?">

Admins can currently modify attendance errors from the past six months.

  </Accordion>
  <Accordion id="q3" title="Can attendance errors be modified in batches on mobile?">

No. Batch modification of attendance errors is not supported on mobile. Admins with the required Permissions should open **DingTalk Desktop > Workbench > Attendance > Attendance statistics > Error handling >** select multiple Users on this Page, and click **Batch process**.

  </Accordion>
  <Accordion id="q4" title="After an attendance error is changed to a normal record, can it be changed back to an error?">

A missed clock-in can be changed to normal, late arrival, or early leave. However, once changed to normal, it cannot be reverted to missed clock-in, late arrival, or early leave.

  </Accordion>
  <Accordion id="q5" title="Who is notified when an attendance error is modified?">

When an attendance record is modified, only the affected employee is notified. Managers, Sub Admins, Super Admins, and others are not notified.

  </Accordion>
  <Accordion id="q6" title="Can the record of an attendance error modification be deleted or withdrawn?">

Records of Admin modifications to employee attendance results cannot be deleted or withdrawn.

  </Accordion>
</AccordionGroup>
