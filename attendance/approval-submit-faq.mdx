<AccordionGroup>
  <Accordion id="q1" title="Can I modify or withdraw an approved makeup clock-in request?">

Yes. Approved makeup clock-in requests can be modified or withdrawn, but any modification or withdrawal must go through the approval process again.

  <Accordion id="q2" title="Can outing requests be submitted more than once?">

**You cannot submit duplicate outing requests for the same time period.** If you try to submit again, the page prompts that a duplicate record already exists.

 **⚠️ Note:**

For example, if you have already submitted an outing request for June 26, 15:00–18:00, submitting another outing request for 16:00–18:00 will show that the selected time period already has a duplicate record.
