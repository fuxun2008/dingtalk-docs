## 1. Overview

If your organization uses flexible shift attendance—meaning no fixed shifts are configured and employees can clock in or out at any time within the specified period—follow the steps below to set it up.

## 2. Use cases

*   Attendance times are not fixed. Employees can clock in at any time, and attendance is tracked by recording working hours.

*   Start and end times are not fixed, and employees can clock in at any time. This suits scenarios such as sales, decoration, housekeeping, and other hourly work.

## 3. Procedure

### Mobile

An Admin with the required permissions can open **DingTalk on mobile > Workbench >** select **Attendance > Settings > Global settings > Add attendance group > Attendance type >** select **Flexible working hours**, complete the settings as prompted, and tap Save.

<Note>
**Flexible working hours:**

Start and end times are not fixed, and employees can clock in at any time. This applies to sales, hourly workers, and similar roles.
</Note>

## 4. FAQs

<AccordionGroup>
  <Accordion id="q1" title="Why can't I set up flexible attendance?">

Setting up flexible attendance requires the **Super Admin or a Sub Admin with attendance permissions**. Contact an Admin with the required permissions to go to **Admin Console > Security and Permissions > Manage permissions >** and assign a Super Admin or Sub Admin.

  </Accordion>
  <Accordion id="q2" title="Can employees clock in at any time under flexible working hours?">

If an attendance start time is set, employees can clock out within 24 hours from the specified time. If no start time is set, employees can clock out by 7:00 AM the next day, provided their working hours do not exceed 16 hours.

  </Accordion>
  <Accordion id="q3" title="Can I set clock-in duration or deduct lunch break time under flexible working hours?">

Flexible working hours do not support setting clock-in duration or deducting lunch break time.

  </Accordion>
  <Accordion id="q4" title="Do flexible working hours support overtime?">

Yes. You can configure overtime rules based on your needs, including converting overtime to compensatory leave or overtime pay. To configure, open **DingTalk on desktop > Workbench > Attendance > Attendance rules management > overtime rules**.

  </Accordion>
</AccordionGroup>
