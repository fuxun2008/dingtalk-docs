In real-world organization attendance management, some users do not need to check in but remain in the attendance group. As a result, they receive daily check-in reminders, missed check-in reminders, and message notifications such as weekly and monthly reports. To avoid disruption, the system sets these users as **silent users**.

## Why is a user set as a silent user?

After the system sets a user who **has not checked in for a long time** as a silent user:

- The silent user is no longer scheduled.
- The silent user no longer receives notifications such as check-in reminders, missed check-in reminders, weekly reports, and monthly reports.

## How does a silent user get reactivated?

<Tip>
A silent user can be reactivated by any method, such as **checking in via a Time Clock** or **checking in via a phone**. Once reactivated, the system automatically schedules the user for today and future dates.
</Tip>
