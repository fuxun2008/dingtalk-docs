In day-to-day attendance management, some users do not need to clock in but remain in the attendance group. As a result, they still receive daily clock-in reminders, missed clock-in reminders, and message notifications such as weekly and monthly reports. To prevent this disruption, the system marks these users as **silent users**.

## Why is a user set as a silent user?

Once the system sets a user who **has not clocked in for a long time** as a silent user:

- The silent user is no longer scheduled.
- The silent user no longer receives notifications such as clock-in reminders, missed clock-in reminders, weekly reports, or monthly reports.

## How does a silent user get reactivated?

<Tip>
A silent user can be reactivated by any clock-in action, such as **clocking in via a Time Clock** or **clocking in via a phone**. Once reactivated, the system automatically schedules the user for today and future dates.
</Tip>
