## 1. Feature overview

When employees need to clock in while working off-site, on business trips, or from home, you can enable the **Field clock-in** feature to record the clock-in time and location. Field records are counted in employees' working hours. Once field clock-in is enabled, all employees in the attendance group can perform field clock-in. To restrict who can use field clock-in, also enable "Field clock-in requires approval" so that only approved users can clock in from the field.

## 2. Applicable scenarios

Scenarios where employees work outside company premises and their data needs to be recorded for statistical purposes.

## 3. Procedure

### 1. Enable field clock-in

<Tabs>
  <Tab title="Mobile">
    An Admin with permission can open **DingTalk on mobile → Workbench → Attendance → Settings → Add attendance group / Edit existing attendance group → More settings → Field rules → Turn "Allow field clock-in" on or off**.

### 3. How employees clock in

When an employee is **outside the clock-in location range** or **not connected to the designated network**, they can tap the "Field clock-in" button and fill in the required information as set by the Admin to complete the field clock-in.

## 4. FAQ

<AccordionGroup>
  <Accordion title="Can field clock-ins be summarized?">
    Currently, the attendance report cannot directly count the number of field clock-ins or summarize them automatically. We recommend viewing the report online or exporting it, then filtering field clock-ins in the spreadsheet and summarizing them manually.
  </Accordion>
  <Accordion title="Why does clock-in show that field clock-in is closed?">
    When the Admin does not allow field clock-in, the button appears gray when you clock in outside the attendance range, and the clock-in shows: Field clock-in is closed.
  </Accordion>
  <Accordion title="Can I only enable field clock-in for a single attendance group?">
    Allowing field clock-in is currently supported only at the attendance group level. If you want to set it by department, we recommend creating a different attendance group for each department.
  </Accordion>
  <Accordion title="Are there area restrictions for field clock-in?">
    Clocking in outside the attendance range counts as a field clock-in. Currently, field clock-in has no area restrictions, and you cannot set a field clock-in range. Employees can perform a field clock-in at any address that Amap can locate.
  </Accordion>
  <Accordion title="Why is the detailed address not shown?">
    When an employee enables Hide detailed address, the field clock-in location shows only the province - city - district - county information. The Admin also sees only the province - city - district - county information in the attendance management console.
  </Accordion>
  <Accordion title="Can the Admin see the updated field clock-in photo?">
    If an employee updates a field clock-in, the Admin can see the photos before and after the update in the attendance management console.
  </Accordion>
  <Accordion title="Can the Admin see the field clock-in alias?">
    If an employee updates a field clock-in, the Admin can see the aliases entered before and after the update in the attendance management console.
  </Accordion>
  <Accordion title="After field clock-in requires approval is enabled, how is it displayed on the employee side?">
    After field clock-in requires approval is enabled, when an employee taps "Submit approval", they go directly to the available application form page.
  </Accordion>
</AccordionGroup>
