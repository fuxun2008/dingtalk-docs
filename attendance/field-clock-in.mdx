## 1. Feature overview

When employees need to clock in while working off-site, on business trips, or from home, enable the **Field clock-in** feature to record their clock-in time and location. Field records count toward employees' working hours. Once field clock-in is enabled, all members of the attendance group can use it. To restrict access, also enable **Field clock-in requires approval** so that only approved users can clock in from the field.

## 2. Applicable scenarios

Scenarios where employees work outside company premises and their attendance data needs to be recorded for reporting.

## 3. Procedure

### 1. Enable field clock-in

<Tabs>
  <Tab title="Mobile">
    An authorized Admin can go to **DingTalk mobile → Workbench → Attendance → Settings → Add attendance group / Edit existing attendance group → More settings → Field rules → toggle "Allow field clock-in" on or off**.

### 3. How employees clock in

When employees are **outside the clock-in location range** or **not connected to the designated network**, they can tap **Field clock-in** and fill in the information required by the Admin to complete the field clock-in.

## 4. FAQ

<AccordionGroup>
  <Accordion title="Can field clock-ins be summarized?">
    Currently, the attendance report cannot directly count or automatically summarize field clock-ins. We recommend viewing the report online or exporting it, then filtering field clock-ins in the spreadsheet and summarizing them manually.
  </Accordion>
  <Accordion title="Why does clock-in show that field clock-in is closed?">
    When the Admin has not enabled field clock-in, the button appears gray when you try to clock in outside the attendance range, and the message shows: Field clock-in is closed.
  </Accordion>
  <Accordion title="Can I enable field clock-in for a single attendance group only?">
    Field clock-in can currently be enabled only at the attendance group level. To set it by department, create a separate attendance group for each department.
  </Accordion>
  <Accordion title="Are there area restrictions for field clock-in?">
    Clocking in outside the attendance range counts as a field clock-in. Field clock-in currently has no area restrictions, and you cannot set a field clock-in range. Employees can perform a field clock-in at any address that Amap can locate.
  </Accordion>
  <Accordion title="Why is the detailed address not shown?">
    When employees enable **Hide detailed address**, the field clock-in location shows only province, city, district, and county. The Admin also sees only this information in the attendance management console.
  </Accordion>
  <Accordion title="Can the Admin see the updated field clock-in photo?">
    If an employee updates a field clock-in, the Admin can see the photos before and after the update in the attendance management console.
  </Accordion>
  <Accordion title="Can the Admin see the field clock-in alias?">
    If an employee updates a field clock-in, the Admin can see the aliases entered before and after the update in the attendance management console.
  </Accordion>
  <Accordion title="How does it appear on the employee side after field clock-in requires approval is enabled?">
    After **Field clock-in requires approval** is enabled, tapping **Submit approval** takes employees directly to the available application form page.
  </Accordion>
</AccordionGroup>
