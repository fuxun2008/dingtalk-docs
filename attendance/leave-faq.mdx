  <Accordion id="q1" title="How can Admins view Employee leave balances?">

To view an Employee's leave balance, open **DingTalk desktop > Workbench > Attendance > Leave Management > Employee Leave Balance** to see the remaining leave for each Employee. To download the balances, click **Export** in the upper-left corner of the Employee Leave Balance page.

  <Accordion id="q2" title="Why are fewer leave types available when submitting a leave request?">

If Users notice that leave types have decreased, or that some Users cannot see certain leave types when submitting a leave request, check the following:

*   The Approval Admin has deleted certain leave types, so fewer options appear when submitting a leave request.

*   The Approval Admin has set an applicable scope for certain leave types. Employees outside that scope will not see those leave types when submitting a leave request.
