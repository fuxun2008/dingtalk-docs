## 1. Feature overview

Users in your organization can clock in from their mobile device at fixed locations or over a fixed Wi-Fi connection. When configuring location-based clock-in or Wi-Fi clock-in, Admins can use **Bulk Import/Export Clock-in Methods** to **add attendance locations and attendance Wi-Fi networks** in bulk.

## 2. Use cases

*   Employees clock in from mobile devices.

*   Employees clock in at fixed locations.

## 3. Workflow

### Bulk import attendance locations and Wi-Fi networks

<Steps>
  <Step>

Download the spreadsheet template. On DingTalk desktop, go to **Workbench > Attendance > Attendance Group Management > Edit attendance group > Clock-in Method settings > Export Clock-in Methods** to obtain the template along with any existing location or Wi-Fi information.

<Frame caption="Example: path to export clock-in methods">
![Export clock-in methods entry point on DingTalk desktop](https://img.alicdn.com/imgextra/i3/O1CN01cD2fyrRJLnL27XzV_!!6000000003898-2-tps-1045-588.png)
</Frame>

<Note>
**Notes:**

For both location-based clock-in and Wi-Fi clock-in, attendance group members can complete their clock-in as long as one method is satisfied. Multiple clock-in methods can coexist, depending on which methods the Organization Admin selects.
</Note>

  </Step>
  <Step>

Fill in the spreadsheet. Enter or edit the information in the Excel spreadsheet as required, then Save the file once the information is correct.

<Frame caption="Example: local spreadsheet entry page">
![Excel spreadsheet showing attendance location and Wi-Fi fields](https://img.alicdn.com/imgextra/i1/O1CN01zGLTiiJFYpK1yU2a_!!6000000003228-2-tps-973-523.png)
</Frame>

  </Step>
  <Step>

Import clock-in methods. On DingTalk desktop, go to **Workbench > Attendance > Attendance Group Management > Edit attendance group > Clock-in Method settings > Import Clock-in Methods** to import the attendance location or Wi-Fi information. Only the Excel format is currently supported.

<Frame caption="Example: path to import clock-in methods">
![Import clock-in methods entry point on DingTalk desktop](https://img.alicdn.com/imgextra/i3/O1CN01cD2fyrRJLnL27XzV_!!6000000003898-2-tps-1045-588.png)
</Frame>

  </Step>
</Steps>
## 4. FAQ

<AccordionGroup>
  <Accordion id="q1" title="When bulk importing attendance locations, the message 'A cell in the Office Address worksheet cannot be empty and must be a number' appears. How can I fix it?">

This happens because every required field in the import spreadsheet must be filled in. Complete the spreadsheet before importing.

  </Accordion>
  <Accordion id="q2" title="How do I obtain latitude and longitude?">

On **DingTalk desktop**, go to **Workbench > Attendance > Attendance Group Management > Edit attendance group > Clock-in Method settings > Add Location** to view the latitude and longitude.

  </Accordion>
  <Accordion id="q3" title="Why are the previously configured attendance locations gone after importing?">

Importing attendance locations overwrites existing data. To keep existing addresses, do not delete them in Excel after exporting. Add new entries on top of the existing data before importing.

  </Accordion>
  <Accordion id="q4" title="How many attendance groups can an organization add? How many Wi-Fi networks and addresses can be set?">

An organization can add up to **10,000 attendance groups**, with **up to 5,000 users** per attendance group. Each attendance group can have up to **1,000 Wi-Fi networks and addresses**.

  </Accordion>
</AccordionGroup>
