## 1. Overview

When employees need to clock in while working outside, on a business trip, or from home, enable the **Field clock-in** feature. The system records both the clock-in time and location, and field clock-in entries count toward working hours. Once **Field clock-in** is enabled, every member of the attendance group can use it. To restrict access, enable the approval requirement so that only employees with an approved request can clock in.

## 2. Use cases

Field clock-in applies when employees work outside the company premises and their attendance data still needs to be recorded for reporting.

## 3. Procedure

### Enable field clock-in

#### Mobile

Admins with the required permissions can go to **Mobile DingTalk > Workbench > Attendance > Settings > Add attendance group / Edit existing attendance group > More settings > Field rules >** and toggle **Allow field clock-in** on or off.

#### Allow employees to hide detailed address

Once enabled, a **Hide detailed address** option appears on the clock-in page when employees perform a field clock-in.

#### Allow office and field clock-in entries to overwrite each other

**Allow office clock-in to overwrite field clock-in for check-in**: Once enabled, if both an office clock-in and a field clock-in fall within the check-in time window, the earlier office clock-in is used as the check-in record. This suits organizations or teams that require employees to check in at the office. If employees may leave to work outside at the start of the day and then return to the office, keep this option off.

**Allow field clock-in to overwrite office clock-in for check-out**: Once enabled, if both an office clock-in and a field clock-in fall within the check-out time window, the later field clock-in is used as the check-out record. This suits organizations or teams whose employees work overtime outside the office and need to update their check-out time.

## 4. FAQ

<AccordionGroup>
  <Accordion id="q1" title="Can field clock-in entries be summarized?">

The attendance report does not currently support counting or automatically summarizing field clock-in entries. As a workaround, view the attendance report online or export it, and then filter by field clock-in in the spreadsheet to summarize the entries manually.

  </Accordion>
  <Accordion id="q2" title="Why does the system show that field clock-in is disabled?">

When the Admin has disabled field clock-in, the button appears gray if you try to clock in outside the attendance area, and the system displays the message: Field clock-in is disabled.

  </Accordion>
  <Accordion id="q3" title="Can Allow field clock-in be enabled only for a single attendance group?">

The Allow field clock-in setting is currently only available at the attendance group level. To apply it by department, create a separate attendance group for each department.

  </Accordion>
  <Accordion id="q4" title="Are there any area restrictions for field clock-in?">

Any clock-in performed outside the attendance area is considered a field clock-in. Field clock-in currently has no area restrictions, and setting a field clock-in area is not supported. Any location that Amap can locate is eligible for field clock-in.

  </Accordion>
  <Accordion id="q5" title="Why is the detailed address not shown?">

When an employee enables Hide detailed address, the field clock-in address shows only the province, city, and district. The Admin also sees only the province, city, and district in the Attendance Admin Console.

  </Accordion>
  <Accordion id="q6" title="Can Admins see updated field clock-in photos?">

If an employee updates a field clock-in, Admins can see both the original and updated photos in the Attendance Admin Console.

  </Accordion>
  <Accordion id="q7" title="Can Admins see the alias entered for a field clock-in?">

If an employee updates a field clock-in, Admins can see both the original and updated aliases in the Attendance Admin Console.

  </Accordion>
  <Accordion id="q8" title="How is the approval requirement displayed on the employee side after it is enabled?">

Once field clock-in requires approval is enabled, employees are taken directly to the available request form page after tapping **Submit for approval**.

  </Accordion>
</AccordionGroup>
