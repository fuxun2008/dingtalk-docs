<Note>
After you complete a check-in, do not worry if the "Check-in recorded, calculating result" screen appears. Your check-in record has already been uploaded to the Attendance server and the result is being calculated. Brief latency is normal, so **there is no need to check in again**.
</Note>

Once the result is calculated, the home page and personal statistics page update automatically. Please check back shortly.
