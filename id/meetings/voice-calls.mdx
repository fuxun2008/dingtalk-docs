Di DingTalk, Anda dapat melakukan Panggilan Suara gratis dengan Kontak. Panggilan Suara memiliki manfaat berikut:

*   **Perlindungan terhadap penyadapan**: Data panggilan dilindungi demi Keamanan.
    
*   **Tanpa biaya panggilan**: Gunakan fitur ini tanpa membayar biaya telepon.
    
*   **Kualitas audio HD**: Kualitas audio melampaui panggilan telepon tradisional berkat peredam bising, peredam gema, dan algoritma audio lainnya.
    
*   **Kartu Nama penelepon**: Menampilkan Kartu penelepon untuk rekan kerja dan Mitra Bisnis.
    

## Cara menggunakan Panggilan Suara

### Melakukan atau mengakhiri Panggilan Suara di ponsel

**Melakukan panggilan:**

Buka Obrolan satu lawan satu di ponsel >> ketuk tombol **+** di sisi kanan kotak input >> pilih **Panggilan Suara** >> ketuk **Panggilan Suara** untuk menelepon.

Anda juga dapat membuka Obrolan satu lawan satu di ponsel >> ketuk ikon di sudut kanan atas >> pilih **Panggilan Suara** >> ketuk **Panggilan Suara** untuk menelepon.

![](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/AJdl65AXv2da7Oke/img/e797538c-1c15-4a5a-8aee-4c0fce657ebc.png)

**Mengakhiri panggilan:** Saat panggilan belum dijawab atau setelah Panggilan Suara tersambung, ketuk **Batal** atau **Tutup** di bagian bawah untuk membatalkan atau mengakhiri panggilan.

> Saat Anda menerima Panggilan Suara DingTalk, aplikasi ponsel menampilkan pop-up panggilan masuk meskipun Anda sedang tidak berada di layar DingTalk, sehingga Anda tidak akan melewatkan panggilan penting.

![](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/AJdl65AXv2da7Oke/img/a4cd237d-52b3-4459-ab98-e9bc689f25a4.png)

### Melakukan atau mengakhiri Panggilan Suara di desktop

**Melakukan panggilan:** Buka Obrolan satu lawan satu di DingTalk desktop >> klik ikon di sudut kanan atas >> klik **Panggilan Suara** untuk menelepon.

![](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/QvjnA3jZEoMrbOXo/img/358ff348-48a2-4ca9-bb9f-b324773e9a42.png?x-oss-process=image/crop,x_1233,y_0,w_1869,h_2466/ignore-error,1)

**Mengakhiri panggilan:** Saat panggilan belum dijawab atau setelah Panggilan Suara tersambung, klik ikon tutup telepon di layar panggilan untuk mengakhiri panggilan.
