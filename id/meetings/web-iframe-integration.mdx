## Panduan integrasi iframe Web DingTalk Meetings

DingTalk Meetings Web dapat disematkan ke situs web bisnis Anda menggunakan **iframe** untuk mendukung skenario layanan kustom seperti wawancara, rekrutmen, dan pelatihan perusahaan.

## Ketersediaan

1.  DingTalk Meetings Web diperlukan.
    
2.  Diperlukan versi berbayar, seperti Meeting Membership, Cloud Meeting Room, edisi Professional, atau Dedicated.
    

Paket berbayar DingTalk Meetings menyediakan rapat tanpa batas waktu dan lebih dari 10 manfaat. Pengguna dapat membeli atau meminta konsultasi melalui halaman pembelian DingTalk Meetings yang relevan.

## Kasus penggunaan: wawancara dan rekrutmen

Dengan integrasi iframe DingTalk Meetings, Anda dapat menyematkan antarmuka rapat di mana pun dalam situs web wawancara dan beralih tampilan kapan saja. Anda juga dapat menyembunyikan tombol atau fitur yang tidak diperlukan sesuai kasus penggunaan sehingga kontrol izin menjadi lebih mudah.

## Cara mengintegrasikannya ke situs web

Menyematkan melalui iframe sangat sederhana. Sisipkan tag iframe DingTalk Meetings ke dalam halaman HTML.

Contoh dasar:

```html
<iframe 
  src="https://meeting.dingtalk.io/app/room?linkId={:linkId}" 
  allow="camera; microphone; display-capture">
</iframe>
```

Setelah mengintegrasikan DingTalk Meetings Web melalui iframe, Anda dapat menggunakan parameter URL dan penyampaian pesan untuk menyesuaikan UI serta memperoleh informasi di dalam rapat. Untuk mempelajari API tertentu, mintalah dokumentasi developer lengkap melalui saluran konsultasi DingTalk.

## UI kustom

Fitur ini mendukung konfigurasi kustom untuk menampilkan atau menyembunyikan komponen UI pada halaman rapat, seperti tombol Bagikan atau tombol Undang.

Contoh:

```html
<iframe 
  src="https://meeting.dingtalk.io/app/room?linkId={:linkId}&invite=0&screen_share=0" 
  allow="camera; microphone; display-capture">
</iframe>

<!-- Tombol bagikan dan undang disembunyikan melalui parameter URL. -->
```
