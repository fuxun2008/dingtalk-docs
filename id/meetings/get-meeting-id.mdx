**ID Rapat** membantu Anda bergabung dengan cepat ke Rapat Video tertentu dan berkomunikasi secara efisien antar-organisasi.

---

## Mendapatkan ID Rapat di desktop

### Mendapatkan ID Rapat untuk rapat terjadwal

Setelah menjadwalkan rapat, atau setelah mengklik rapat terjadwal dari Kalender atau halaman Rapat, buka pop-up detail rapat >> klik ikon **Salin** di samping ID Rapat yang dihasilkan otomatis di sudut kanan atas.

![](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/Yvenve56z2BE1loy/img/d0ef6cf0-5868-4991-935b-ebaae9cf958b.png)

### Mendapatkan ID Rapat selama rapat berlangsung

Selama rapat berlangsung, arahkan kursor ke **Informasi Rapat** di sudut kiri atas >> klik tombol **Salin** di samping ID Rapat, atau klik **Salin Informasi Gabung**.

![](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/Yvenve56z2BE1loy/img/eaa219f7-6d84-4a4f-a8fe-6a003f6a4852.png?x-oss-process=image/crop,x_91,y_162,w_3921,h_2726/ignore-error,1)

## Mendapatkan ID Rapat di ponsel

### Mendapatkan ID Rapat untuk rapat terjadwal

Setelah menjadwalkan rapat, atau setelah menekan rapat terjadwal dari Kalender atau halaman Rapat, buka halaman detail rapat >> tekan tombol **Salin** di samping ID Rapat.

![](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/Yvenve56z2BE1loy/img/447ac704-4b32-45af-82a1-3cb8e04b7f5d.png?x-oss-process=image/crop,x_0,y_14,w_982,h_1004/ignore-error,1)

### Mendapatkan ID Rapat selama rapat berlangsung

Mulai atau gabung ke rapat >> pada layar rapat, tekan **Informasi Rapat** di bagian atas >> tekan tombol **Salin** di samping ID Rapat.

![](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/Yvenve56z2BE1loy/img/b68f919a-453b-4d8e-b5af-a3ecc38c0af2.png)
