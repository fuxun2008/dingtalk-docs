Untuk merekam dan mengarsipkan konten rapat secara efektif, Rapat Video DingTalk menyediakan **perekaman rapat** bagi tuan rumah, sehingga konten mudah ditangkap dan ditinjau di kemudian hari.

---

## Merekam rapat di desktop

**Mulai merekam:** Selama rapat, klik **Rekam** di bilah alat bawah >> pilih **Perekaman Cloud** atau **Perekaman Lokal**.

![](https://img.alicdn.com/imgextra/i2/O1CN01Cac3lwH8UYK3zMSB_!!6000000008156-2-tps-1965-1366.png)

**Hentikan perekaman:** Selama rapat, klik **Hentikan Rekaman** di bilah alat bawah.

![](https://img.alicdn.com/imgextra/i4/O1CN01hPQzxTyb3AG3yEDA_!!6000000001414-2-tps-1956-1364.png)

#### Menampilkan atau mengubah jalur penyimpanan perekaman lokal

**Metode 1:** Untuk perekaman lokal, setelah Anda mengklik **Hentikan Rekaman**, sistem otomatis menampilkan notifikasi bahwa perekaman telah selesai. Klik **Buka Folder** untuk menampilkannya.

![](https://img.alicdn.com/imgextra/i3/O1CN01PU80cW46lDJ3z6qN_!!6000000006650-2-tps-1963-1364.png)

**Metode 2:** Selama rapat, klik **Lainnya** di bagian bawah >> **Pengaturan** >> **Perekaman** >> tampilkan **Jalur file perekaman** >> klik **Buka** di sebelah kanan untuk mengubah jalur penyimpanan.

![](https://img.alicdn.com/imgextra/i3/O1CN01UD1vVimJd1J60cLy_!!6000000006527-2-tps-2960-2490.png)

## Merekam rapat di perangkat seluler

**Mulai merekam:** Selama rapat, ketuk **Lainnya** >> ketuk **Perekaman Cloud**.

![](https://img.alicdn.com/imgextra/i3/O1CN011CfU0ZETw8JAU4SP_!!6000000001415-2-tps-5164-5173.png)

**Hentikan perekaman:** Selama rapat, ketuk **Lainnya** >> ketuk **Hentikan Rekaman**.

![](https://img.alicdn.com/imgextra/i1/O1CN01uvbrVKth1wJA4dtI_!!6000000007277-2-tps-4962-5054.png)
