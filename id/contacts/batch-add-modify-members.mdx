## 1. Ikhtisar fitur

Untuk meningkatkan efisiensi pengelolaan HR, DingTalk menyediakan fitur Menambah Anggota Secara Massal dan Mengubah Informasi Anggota Secara Massal bagi admin perusahaan. Dengan mengimpor file Excel, Anda dapat menambah atau memperbarui informasi karyawan dalam jumlah besar secara cepat dan menghindari pekerjaan manual yang berulang.

## 2. Kasus penggunaan

Gunakan fitur ini ketika:

*   Perusahaan membuat organisasi DingTalk baru atau membentuk departemen baru.
    
*   Perusahaan menjalankan rekrutmen kampus atau proses rekrutmen berskala besar lainnya.
    
*   Perusahaan mengerjakan proyek dengan mitra eksternal, seperti pemasok atau pelanggan.
    
*   Anda perlu menambah anggota atau mengubah informasi anggota secara massal.
    

## 3. Prosedur

Admin yang memiliki izin dapat membuka [Admin Console](https://oa.dingtalk.io) > Kontak > Anggota > Edit Massal > Impor Massal / Ekspor Massal.

![](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/AJdl65AEw3LXBOke/img/3d3b0f2f-715b-43d7-b26a-2dc52975ce12.png)

Untuk menambah anggota secara massal, unduh templat standar di halaman Impor Anggota Secara Massal, isi informasi anggota, lalu unggah kembali ke DingTalk untuk menambahkan anggota baru ke Kontak Perusahaan dengan cepat.

Untuk ekspor atau modifikasi massal, ekspor templat standar dari halaman Ekspor/Ubah Anggota, ubah informasi anggota dalam file tersebut, lalu unggah kembali ke DingTalk untuk mengubah beberapa anggota sekaligus dengan cepat.

### Menambah anggota secara massal

#### Buka impor massal

Buka [Admin Console](https://oa.dingtalk.io) > Kontak > Anggota > Edit Massal > Impor Massal > Unduh Templat.

![](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/AJdl65AEw3LXBOke/img/07b41e67-e78f-4c86-9761-d54ee7e79919.png)

#### Isi informasi karyawan

Setelah mengunduh templat, lihat teks contoh pada baris pertama dan petunjuk pengisian, lalu masukkan informasi karyawan baru.

![](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/AJdl65AEw3LXBOke/img/8a4c4096-90e8-49f4-bb0f-f9802c0f401f.png)

#### Hapus baris contoh

Setelah mengisi file, hapus baris pertama yang berisi teks contoh, lalu simpan file.

#### Unggah file

Pada halaman Impor Anggota Secara Massal, klik Unggah File, pilih file informasi karyawan, lalu klik Impor. Anggota baru akan ditambahkan ke Kontak Perusahaan.

![](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/AJdl65AEw3LXBOke/img/4411e388-0c3d-4c69-95c6-4fa2b44ced25.png)

### Mengubah informasi anggota secara massal

#### Ekspor informasi anggota

Buka [Admin Console](https://oa.dingtalk.io) > Kontak > Anggota > Edit Massal > Ekspor Massal, lalu klik Ekspor/Ubah Anggota > Ekspor.

![](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/AJdl65AEw3LXBOke/img/361b044e-a8a0-40f2-a7f0-b176c81b17ec.png)

#### Pilih departemen

Pilih departemen yang informasinya perlu diubah, lalu klik Konfirmasi.

![](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/AJdl65AEw3LXBOke/img/a7604022-5ed4-4830-b47c-e7179bd6c3ed.png)

#### Unduh file yang diekspor

Ketika halaman menampilkan bahwa ekspor Kontak berhasil, klik Unduh.

![](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/AJdl65AEw3LXBOke/img/18bfd1ef-29dd-40af-8482-11098564faa4.png)

#### Ubah file

Buka file yang telah diunduh, lalu ubah informasi yang ada sesuai petunjuk pengisian.

![](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/AJdl65AEw3LXBOke/img/608caa11-0216-4fb8-a39b-f813c4ab8517.png)

#### Unggah file yang telah diubah

Unggah dan impor file yang telah disimpan.

![](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/AJdl65AEw3LXBOke/img/9b26a753-6a65-4b06-850e-0899432eae84.png)

## 4. Pertanyaan yang sering diajukan

### T: Mengapa unggah atau ekspor gagal?

J: Muat ulang halaman, atau masuk kembali ke Admin Console menggunakan browser lain. Google Chrome direkomendasikan untuk kompatibilitas yang lebih baik.
