#### 1. Konfigurasikan Struktur Organisasi Kontak

Konfigurasikan Struktur Organisasi Kontak melalui Admin Console desktop, halaman manajemen organisasi versi seluler, atau API.

#### 2. Konfigurasikan atribut karyawan di Kontak

Anda dapat mengonfigurasi:

*   Gaya tampilan Kontak
    
*   Gaya tampilan jalur departemen
    

Jalur: Buka [Admin Console](https://oa.dingtalk.io) > Kontak > Manajemen Profil.
