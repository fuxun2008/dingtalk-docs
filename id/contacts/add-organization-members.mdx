## 1. Ikhtisar fitur

Admin dapat mengundang karyawan untuk bergabung ke sebuah tim dengan menambahkannya secara manual, sekaligus menetapkan karyawan ke departemen tertentu.

## 2. Prosedur

### Menambahkan karyawan sebagai admin organisasi di desktop

Buka [Admin Console](https://oa.dingtalk.io) > Kontak > Pengelolaan Anggota > pilih departemen tempat anggota akan ditambahkan > Tambah Anggota / Undang Anggota / Pengelolaan Massal untuk mengundang anggota bergabung ke organisasi.
