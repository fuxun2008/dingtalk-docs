Untuk meningkatkan efisiensi kerja dan menemukan file target dengan cepat di drive yang berisi banyak file, DingTalk Drive mendukung pencarian cepat.

## Desktop

Di halaman beranda DingTalk Drive, masukkan kata kunci judul atau konten pada kotak pencarian. Pilih tipe file dan cakupan filter untuk menemukan file target dengan cepat.

![](https://img.alicdn.com/imgextra/i1/O1CN01x4DftPhtKpL713Mj_!!6000000006761-2-tps-3456-2165.png)

## Seluler

Di halaman beranda DingTalk Drive, masukkan kata kunci judul atau konten pada kotak pencarian, ketuk **Filter**, lalu pilih tipe file untuk menemukan file target dengan cepat.
