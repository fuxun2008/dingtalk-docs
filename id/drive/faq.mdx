  <Accordion title="Kapan File Obrolan satu lawan satu kedaluwarsa?">
    *   Untuk DingTalk Exclusive Edition, jika **Penyimpanan File Khusus** diaktifkan, File Obrolan satu lawan satu yang dikirim karyawan disimpan di penyimpanan khusus dan tidak akan dibersihkan.
    *   DingTalk Professional Edition hanya mendukung tampilan riwayat obrolan untuk obrolan satu lawan satu internal dan grup internal. Masa penyimpanan maksimum adalah 10 tahun. Pada tanggal aktivasi, riwayat obrolan 2 tahun terakhir dapat dicari, dan riwayat disimpan untuk 8 tahun ke depan. Pada tahun berikutnya, informasi teks 3 tahun terakhir dapat dicari, dan seterusnya. Jika Professional Edition kedaluwarsa dan tidak diperpanjang, file yang berusia lebih dari 90 hari akan dipindahkan ke tempat sampah.
    *   Jika kedua peserta dalam obrolan satu lawan satu berasal dari perusahaan yang sama dan perusahaan tersebut menggunakan Professional Edition, obrolan dilindungi oleh aturan Professional Edition yang menyimpan File Obrolan selama 180 hari.
    *   Jika salah satu peserta dalam obrolan satu lawan satu menggunakan DingTalk Standard Edition, obrolan hanya disimpan selama 90 hari.
    *   Jika kedua peserta dalam obrolan satu lawan satu tidak berasal dari perusahaan yang sama, meskipun keduanya telah mengaktifkan Professional Edition, obrolan tetap dihitung menurut aturan Standard Edition dan hanya disimpan selama 90 hari.
  </Accordion>
  <Accordion title="Bagaimana cara mengetahui apakah File Obrolan satu lawan satu saya akan segera dibersihkan? Bagaimana cara mencadangkannya?">
    *   Jika obrolan satu lawan satu Anda memuat file yang akan kedaluwarsa dalam 30 hari dan belum dicadangkan, DingTalk akan mengingatkan Anda melalui cara berikut.
    *   Dalam obrolan satu lawan satu, klik **ikon pencarian** di pojok kanan atas, lalu buka **File** untuk melihat daftar riwayat file pada obrolan saat ini. Jika ada file yang akan kedaluwarsa dalam 30 hari, entri **File yang akan kedaluwarsa** akan muncul dan menampilkan semua file yang akan kedaluwarsa serta dihapus dalam 30 hari.
    *   File Obrolan yang diunggah dapat disimpan ke penyimpanan perusahaan. Pada DingTalk desktop, buka **DingTalk Drive > Lainnya > Manajemen Unggah File Obrolan**, pilih organisasi yang sesuai, lalu aktifkan opsi tersebut. File yang baru diunggah dalam obrolan satu lawan satu, termasuk obrolan dengan diri sendiri, kemudian akan disimpan ke penyimpanan perusahaan dari organisasi yang ditampilkan di pojok kiri atas, sehingga membantu menjaga keamanan file perusahaan.
    *   Pengingat kedaluwarsa untuk File Obrolan satu lawan satu saat ini tidak dapat dimatikan, tetapi pengingat akan berhenti setelah beberapa waktu.
  </Accordion>
  <Accordion title="Apakah file dapat dipulihkan setelah kedaluwarsa?">
    Setelah kedaluwarsa, file otomatis masuk ke tempat sampah file untuk obrolan tersebut. File tetap berada di tempat sampah selama 30 hari. Setelah 30 hari, file dihapus secara permanen dan tidak dapat dipulihkan.
  </Accordion>
