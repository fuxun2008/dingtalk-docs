polished: true

DingTalk Drive mendukung penyimpanan file kerja pribadi dan tim. Di setiap organisasi perusahaan, Enterprise Drive menyediakan tiga folder penyimpanan: **File Saya**, **File Tim**, dan **File Obrolan**. Kapasitas awalnya 100 GB.

Setelah karyawan keluar dari organisasi, mereka tidak dapat lagi mengakses file-file ini sehingga keamanan informasi tetap terlindungi.

## Desktop

Untuk menyimpan file perusahaan dari jendela obrolan DingTalk, seperti file lokal, dokumen online, video, atau gambar, pilih **Tambah ke** pada kartu pesan, lalu simpan file ke **File Tim** di **DingTalk Drive**.

Untuk menyimpan file pribadi dari jendela obrolan DingTalk, seperti file lokal, dokumen online, video, atau gambar, pilih **Tambah ke** pada kartu pesan, lalu pilih **File Saya** di **DingTalk Drive**.

![](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/oJGq75kdAmvVPlAK/img/3a609ea7-9f43-4b9e-a503-896938aa2cf3.png?x-oss-process=image/crop,x_0,y_69,w_3456,h_2165/ignore-error,1)

## Ponsel

Ketuk **Tambah ke** pada kartu pesan file, lalu pilih untuk menyimpan file ke **File Tim** atau **Dokumen Saya**.
