Dalam pekerjaan, Anda sering perlu membagikan file dengan pihak eksternal. Mengirim file secara aman sangatlah penting. Panduan ini menyediakan langkah-langkah yang direkomendasikan.

## Metode 1: Konfigurasikan izin

### Desktop

Buka halaman beranda DingTalk Drive, **File Tim** di halaman beranda Docs, atau **File Saya (dari DingTalk Drive)** di bawah Dokumen Saya. Cari file atau folder yang dituju, klik **...** untuk opsi lainnya, lalu pilih **Manajemen Izin**.

![](https://img.alicdn.com/imgextra/i1/O1CN01h8FevQyl1IF713Mj_!!6000000008037-2-tps-3456-2165.png)

Klik **Tambah Kolaborator**, pilih anggota yang ingin ditambahkan, tentukan tingkat izin yang sesuai, lalu klik **OK**. Notifikasi izin dapat dikirim melalui obrolan satu lawan satu.

Tingkat izin meliputi **Dapat mengelola**, **Dapat mengedit**, **Dapat melihat/mengunduh**, dan **Hanya lihat**.

![](https://img.alicdn.com/imgextra/i4/O1CN01WsPeDmzectB713Mj_!!6000000001348-2-tps-3456-2165.png)

![](https://img.alicdn.com/imgextra/i3/O1CN01TIt97u5NvEJ713Mj_!!6000000000137-2-tps-3456-2165.png)

![](https://img.alicdn.com/imgextra/i2/O1CN01yQBoK9tCBrJ713Mj_!!6000000000070-2-tps-3456-2165.png)

![](https://img.alicdn.com/imgextra/i1/O1CN01hWRuqMyhWcD713Mj_!!6000000002584-2-tps-3456-2165.png)

![](https://img.alicdn.com/imgextra/i4/O1CN01lE7Fkn7lbGK713Mj_!!6000000002646-2-tps-3456-2165.png)

Untuk melindungi keamanan informasi, jika pihak eksternal tidak perlu mengedit file, atur izin ke **Hanya lihat**. Jika mereka perlu mengunduh file, atur izin ke **Dapat melihat/mengunduh**.

## Metode 2: Kirim tautan

Buka halaman beranda DingTalk Drive, **File Tim** di halaman beranda Docs, atau **File Saya (dari DingTalk Drive)** di bawah Dokumen Saya. Cari file atau folder yang dituju, lalu klik **...** untuk opsi lainnya.

![](https://img.alicdn.com/imgextra/i1/O1CN01nu1iULkL88B713Mj_!!6000000007147-2-tps-3456-2165.png)

Untuk dokumen online seperti dokumen, spreadsheet, dan mind map, klik **...**, lalu klik **Bagikan**. File yang dibagikan akan dikirim ke pihak lain sebagai pesan obrolan DingTalk, dan izin dapat disesuaikan di antarmuka obrolan.

![](https://img.alicdn.com/imgextra/i2/O1CN01WWJuNSPBjsH713Mj_!!6000000001396-2-tps-3456-2165.png)

![](https://img.alicdn.com/imgextra/i2/O1CN015zvcjLeEY6F713Mj_!!6000000006796-2-tps-3456-2165.png)

![](https://img.alicdn.com/imgextra/i1/O1CN01r559r87qCfI713Mj_!!6000000007896-2-tps-3456-2165.png)

Untuk folder, file lokal, video, gambar, dan item sejenis, klik **...** lalu klik **Kirim Tautan** untuk membagikannya.

![](https://img.alicdn.com/imgextra/i4/O1CN012pD9GsLOc9K713Mj_!!6000000003055-2-tps-3456-2165.png)

![](https://img.alicdn.com/imgextra/i3/O1CN01vsik6rWXr2H713Mj_!!6000000005292-2-tps-3456-2165.png)

### Ponsel

Untuk dokumen online seperti dokumen, spreadsheet, dan mind map, ketuk **...** untuk opsi lainnya lalu ketuk **Kirim ke Obrolan**.
