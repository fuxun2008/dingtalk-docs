---
title: "Cara cepat menemukan folder tujuan"
description: "Unduh beberapa file sekaligus dari DingTalk Drive atau daftar file grup. Folder lokal dibuat otomatis dengan nama berdasarkan tanggal unduhan dan nama file pertama, sehingga folder tujuan mudah ditemukan."
polished: true
---

Di daftar file DingTalk Drive atau daftar file grup, pilih beberapa file lalu klik **Unduh**. Sebuah folder lokal akan dibuat secara otomatis dengan nama berdasarkan tanggal unduhan dan nama file pertama.
