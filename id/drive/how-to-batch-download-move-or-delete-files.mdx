File dan folder DingTalk Drive mendukung operasi massal seperti memindahkan, menyalin, dan menghapus. Cara ini mengurangi pekerjaan berulang serta membuat pengelolaan file dan pengetahuan menjadi lebih cepat dan efisien.

## Desktop

Buka halaman beranda DingTalk Drive, **File Tim** di halaman beranda Docs, atau **File Saya (dari DingTalk Drive)** di bawah Dokumen Saya. Pilih beberapa file atau folder, lalu gunakan toolbar untuk mengunduh, memindahkan, menghapus, dan lainnya secara massal.

![](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/4j6OJ5jRzbk3Kq3p/img/d131d74b-cee1-4a04-850b-6ee66e3cca17.png?x-oss-process=image/crop,x_0,y_69,w_3456,h_2165/ignore-error,1)

Untuk mengunduh file dari DingTalk Drive, klik **Unduh** di toolbar, lalu pilih lokasi penyimpanan lokal.

![](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/4j6OJ5jRzbk3Kq3p/img/9e746b8f-ac98-4ac4-bffb-6111288bc0ad.png?x-oss-process=image/crop,x_0,y_69,w_3456,h_2165/ignore-error,1)

Untuk memindahkan file di DingTalk Drive, klik **Pindahkan** di toolbar. File dapat dipindahkan ke lokasi lain seperti Knowledge Base, Grup Pengetahuan, File Saya, atau File Tim. Setelah dipindahkan, file tidak akan lagi muncul di lokasi asalnya.

Jika Anda ingin menyimpan file di lokasi asalnya, pilih **Tambah ke** di toolbar untuk membuat salinan, lalu simpan ke Knowledge Base, Grup Pengetahuan, File Saya, File Tim, atau lokasi lain.

Pilih **Hapus** untuk memindahkan file ke Tempat Sampah. Dari Tempat Sampah, Anda dapat memulihkan file atau menghapusnya secara permanen.
