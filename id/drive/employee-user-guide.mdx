DingTalk Drive menyediakan ruang penyimpanan pribadi 2 GB untuk setiap pengguna di **Private Drive**. File disinkronkan secara real-time di desktop dan seluler, serta datanya dilindungi dengan enkripsi agar lebih aman digunakan.

Karena DingTalk Drive terintegrasi secara mendalam dengan DingTalk, Anda dapat menyimpan file ke DingTalk Drive hanya dengan satu klik.

## Desktop

Klik **Tambah Kepada** di sudut kanan bawah file yang dituju, pilih direktori penyimpanan, lalu pilih folder yang sesuai.

## Seluler

Ketuk file yang dituju, pilih **Tambah Kepada**, pilih folder yang sesuai, lalu ketuk **Konfirmasi**.
