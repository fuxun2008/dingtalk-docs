## 1. Buka halaman Kapasitas Penyimpanan Perusahaan

Buka DingTalk Drive, klik **Lainnya** di sudut kiri bawah, lalu klik **Kapasitas penyimpanan perusahaan** untuk masuk ke halaman kapasitas penyimpanan perusahaan. Klik **Lihat Detail**, lalu klik **Kelola** untuk membuka halaman pengelolaan kapasitas DingTalk Drive.

## 2. Konfigurasikan detail di halaman pengelolaan

Di halaman pengelolaan, Anda dapat menetapkan batas kapasitas dan melihat penggunaan untuk area DingTalk Drive seperti **File Saya**, **File Tim**, **File grup**, mini app, dan berbagi eksternal.

![](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/4j6OJ5jaGEr2Rq3p/img/6b26f308-301c-4ef9-b190-633887db97b2.png?x-oss-process=image/crop,x_0,y_69,w_3456,h_2165/ignore-error,1)

Di halaman **File Saya**, atur apakah peran seperti administrator perusahaan, administrator DingTalk Drive, orang tertentu, dan lainnya diizinkan untuk menggunakan **File Saya**.

![](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/4j6OJ5jaGEr2Rq3p/img/f08b3f46-7049-41b6-a812-206963083107.png?x-oss-process=image/crop,x_0,y_69,w_3456,h_2165/ignore-error,1)

Anda juga dapat melihat penggunaan penyimpanan anggota, menetapkan batas kapasitas anggota, dan memberi tahu anggota dengan satu klik untuk membersihkan file yang tidak diperlukan di **Dokumen Saya** pribadi mereka.

![](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/4j6OJ5jaGEr2Rq3p/img/02720e8d-573b-4ce5-986e-1390163ed605.png?x-oss-process=image/crop,x_0,y_69,w_3456,h_2165/ignore-error,1)

## 3. Hapus file yang tidak diperlukan

**Desktop:** Buka **DingTalk Drive**, pilih file yang dituju, klik **...** di samping file tersebut, lalu klik **Hapus**.

**Seluler:** Ikuti langkah yang sama seperti di desktop.

![](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/4j6OJ5jaGEr2Rq3p/img/4af326ad-83e8-4a1d-b5ad-c5a7a315e6eb.png?x-oss-process=image/crop,x_0,y_69,w_3456,h_2165/ignore-error,1)

## Tips

*   File Ruang tim dapat dihapus oleh **administrator utama** atau oleh **pengelola folder yang telah ditambahkan di pengaturan**.
    
*   File bersama atau folder bersama dapat dihapus oleh **pembuat folder** dan oleh orang yang telah diberi izin **pengelola**.
    
*   Jika file obrolan grup menggunakan banyak ruang, hubungi pemilik grup untuk menghapusnya dari file grup. File yang dihapus disimpan di Tempat Sampah selama 30 hari, kemudian dibersihkan secara otomatis oleh sistem.
