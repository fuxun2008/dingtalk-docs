Folder dan file dapat dihapus di DingTalk Drive. Setelah dihapus, item akan dipindahkan ke Tempat Sampah dan masih dapat dipulihkan. Dengan begitu, pengelolaan file menjadi lebih praktis dan aman.

## Desktop

Buka halaman beranda DingTalk Drive, **File Tim** di halaman beranda Docs, atau **File Saya (dari DingTalk Drive)** di bawah Dokumen Saya. Pilih file yang ingin dihapus, lalu klik **Hapus**. File akan dipindahkan ke Tempat Sampah. Item di Tempat Sampah tidak menggunakan kapasitas penyimpanan.

![](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/YdgOk2b6JABpLq4B/img/80c83cd0-c823-4a1f-a219-09c82810fa7c.png?x-oss-process=image/crop,x_0,y_69,w_3456,h_2165/ignore-error,1)

Untuk memulihkan dokumen yang telah dihapus, klik **Lainnya** di sudut kiri bawah DingTalk Drive, lalu klik **Tempat Sampah**. Klik **...** di samping file yang dituju, lalu pilih **Pulihkan** untuk mengembalikannya ke lokasi semula. Jika Anda mengklik **Hapus Permanen**, file tidak dapat dipulihkan lagi.

## Ponsel

Buka halaman beranda DingTalk Drive, **File Tim** di halaman beranda Docs, atau **File Saya (dari DingTalk Drive)** di bawah Dokumen Saya. Ketuk **...** di sebelah kanan file yang ingin dihapus, lalu ketuk **Hapus**. File akan dipindahkan ke Tempat Sampah. Item di Tempat Sampah tidak menggunakan kapasitas penyimpanan.

Untuk memulihkan dokumen yang telah dihapus, ketuk **...** di sudut kanan atas DingTalk Drive, lalu ketuk **Tempat Sampah**. Ketuk **...** di samping file yang dituju, lalu pilih **Pulihkan** untuk mengembalikannya ke lokasi semula. Jika Anda mengetuk **Hapus Permanen**, file tidak dapat dipulihkan lagi.
