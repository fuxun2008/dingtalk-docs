Anda mungkin menerima banyak file setiap hari saat bekerja. Daripada menggulir Riwayat Obrolan setiap kali, gunakan metode berikut untuk menemukan file lama di obrolan dengan cepat.

## Desktop

### Metode 1

Di sudut kanan atas obrolan grup, klik **ikon pencarian** lalu pilih **File**. Gunakan kondisi pencarian atau filter, dan prioritaskan hasil bertipe folder untuk menemukan file atau folder lama dari obrolan dengan cepat.

### Metode 2

Di halaman beranda DingTalk Drive, klik **File Obrolan** untuk melihat **File Obrolan Saya** dan **File Grup Internal** yang telah disinkronkan ke DingTalk Drive.
