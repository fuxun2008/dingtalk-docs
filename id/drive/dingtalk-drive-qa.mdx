## Produk

<AccordionGroup>
  <Accordion id="q1" title="Berapa banyak penyimpanan gratis yang disediakan DingTalk Drive?">
    Enterprise Drive menyediakan 100 GB. Personal Drive menyediakan 2 GB.
  </Accordion>
  <Accordion id="q2" title="Di mana Enterprise Drive berada?">
    Buka DingTalk Drive. Sistem menampilkan Enterprise Drive secara default.

    **Desktop:** Buka DingTalk desktop, lalu klik ikon **DingTalk Drive** di menu sebelah kiri.

    **Seluler:** Buka DingTalk seluler, ketuk **Jelajahi** di sudut kanan bawah, lalu ketuk **DingTalk Drive**.
  </Accordion>
</AccordionGroup>

## Penyimpanan

<AccordionGroup>
  <Accordion id="q3" title="Bagaimana cara menyimpan file obrolan ke DingTalk Drive?">
    **Metode 1:** Untuk grup internal, admin grup dapat langsung mengaktifkan sinkronisasi file grup.

    **Metode 2:** Pilih **Tambahkan ke** pada kartu pesan, atau klik kanan lalu pilih **Tambahkan ke**. Pada panel penyimpanan, pilih **File Tim** atau **Dokumen Saya > File Saya (dari DingTalk Drive)**.

    **Metode 3:** Dalam obrolan grup internal, buka daftar file grup, pilih file yang ingin disimpan, klik **Tambahkan ke**, lalu pilih **File Tim** atau **Dokumen Saya > File Saya (dari DingTalk Drive)** pada panel penyimpanan.
  </Accordion>
  <Accordion id="q4" title="Mengapa Enterprise Drive 100 GB penuh padahal hanya sedikit file yang disimpan?">
    Untuk grup internal, nonaktifkan sinkronisasi file grup ke DingTalk Drive agar banyak file kecil yang tidak penting tidak tersimpan otomatis dan menghabiskan penyimpanan. Untuk mengelola kapasitas DingTalk Drive secara efektif, alokasikan juga kapasitas yang tersedia kepada karyawan dan mini app tertentu.

    Jalur: Admin membuka **Enterprise Admin Console**, klik **Storage Space** di bawah **Docs and Storage Management**, klik **Manage** setelah DingTalk Drive pada storage management, lalu buka halaman manajemen kapasitas DingTalk Drive.
  </Accordion>
</AccordionGroup>

## Manajemen File dan Kapasitas

<AccordionGroup>
  <Accordion id="q5" title="Bagaimana cara melihat penggunaan kapasitas DingTalk Drive?">
    Klik **Lainnya (...)** di menu DingTalk sebelah kiri. Admin membuka **Enterprise Admin Console**, buka **Storage Space** di bawah **Docs and Storage Management**, lalu klik **Manage** setelah DingTalk Drive pada storage management untuk melihat penggunaan kapasitas.

    Tips: Langkah ini lebih mudah dilakukan di desktop. Hanya admin yang dapat melihat informasi ini.
  </Accordion>
  <Accordion id="q6" title="Bagaimana cara mencegah file grup tersinkronisasi ke DingTalk Drive?">
    **Metode 1:** Buka Enterprise Admin Console, buka **Storage Space** di bawah **Docs and Storage Management**, klik **Manage** setelah DingTalk Drive pada storage management, buka halaman **Group Files**, lalu nonaktifkan **Allow internal groups to enable DingTalk Drive sync**.

    Tips: Hanya admin yang dapat mengonfigurasi pengaturan ini.

    **Metode 2:** Dalam obrolan grup internal, buka pengaturan di sudut kanan atas, klik **Kelola Grup**, lalu nonaktifkan **Auto-sync to DingTalk Drive**.

    Tips: Pengaturan ini hanya dapat dikonfigurasi untuk grup internal.
  </Accordion>
  <Accordion id="q7" title="Bagaimana cara mengalokasikan kapasitas penyimpanan pribadi kepada karyawan?">
    Buka **Enterprise Admin Console**, klik **Storage Space** di bawah **Docs and Storage Management**, klik **Manage** setelah DingTalk Drive pada storage management, lalu buka halaman manajemen kapasitas DingTalk Drive. Pada halaman **My Files**, klik ikon edit setelah **Employee personal file storage**, lakukan perubahan, lalu konfirmasi.
  </Accordion>
  <Accordion id="q8" title="Bagaimana cara mengalokasikan kapasitas khusus untuk sebuah aplikasi?">
    Di **Enterprise Admin Console**, klik **Storage Space** di bawah **Docs and Storage Management**. Pada storage management, klik **Allocate** setelah aplikasi yang membutuhkan kapasitas, lalu pilih kapasitas yang akan dialokasikan dan selesaikan pengaturannya.
  </Accordion>
  <Accordion id="q9" title="Apa yang harus saya lakukan jika file terhapus secara tidak sengaja?">
    File yang dihapus otomatis dipindahkan ke tempat sampah dan dihapus secara permanen setelah 30 hari.

    Entri tempat sampah: Di desktop, klik **Tempat Sampah**, klik **...** setelah file yang dituju, lalu pilih **Restore** untuk mengembalikannya ke lokasi asli. Jika Anda klik **Permanently Delete**, file tidak dapat dipulihkan. Di seluler, ketuk **...** di sudut kanan atas DingTalk Drive, ketuk **Tempat Sampah**, ketuk **...** setelah file yang dituju, lalu pilih **Restore** untuk mengembalikannya ke lokasi asli. Jika Anda ketuk **Permanently Delete**, file tidak dapat dipulihkan.
  </Accordion>
  <Accordion id="q10" title="Bagaimana cara membersihkan kapasitas DingTalk Drive?">
    Admin organisasi perusahaan dapat membersihkan kapasitas DingTalk Drive di admin console.

    Jalur pembersihan: Pada DingTalk desktop, klik **Lainnya (...)** di bilah alat sebelah kiri, buka **Admin Console**, klik **Storage Space** di bawah **Docs and Storage Management**, lalu klik **Manage** setelah DingTalk Drive pada storage management. Setelah itu, kelola file yang disimpan di berbagai lokasi atau minta anggota perusahaan untuk membersihkan file.
  </Accordion>
  <Accordion id="q11" title="Bagaimana cara menambah kapasitas Enterprise Drive?">
    Enterprise Drive memiliki kapasitas awal 100 GB. Setelah kapasitas awal habis, perusahaan harus membayar untuk menambah kapasitas.

    Harga penambahan kapasitas: Lihat gambar.

    ![](https://img.alicdn.com/imgextra/i2/O1CN01q3X0EOE7q0F55Sua_!!6000000002278-2-tps-2506-1954.png)

    Jalur penambahan kapasitas: Pada DingTalk desktop, buka admin console, buka **Fees**, pilih **Purchase or Upgrade**, klik **Buy Now**, lalu ikuti petunjuknya.

    Tips: Saat ini penambahan kapasitas hanya tersedia untuk DingTalk Drive perusahaan, bukan untuk ruang pribadi. Setelah pembayaran, kapasitas gratis 100 GB awal tetap dapat digunakan.
  </Accordion>
  <Accordion id="q12" title="Setelah sebuah grup dihapus atau dibubarkan, di mana saya dapat menemukan file dari grup tersebut?">
    Jika file obrolan grup tidak tersinkronisasi ke DingTalk Drive, file akan terhapus bersama grup setelah grup dihapus atau dibubarkan.

    Jika file obrolan grup tersinkronisasi ke DingTalk Drive, yang hanya tersedia untuk grup internal perusahaan, pemilik grup tetap dapat menemukan file grup terkait di bawah **File grup** pada Enterprise Drive setelah grup dihapus atau dibubarkan.
  </Accordion>
  <Accordion id="q13" title="Ke mana perginya dokumen yang disimpan seorang karyawan setelah karyawan tersebut keluar?">
    File yang disimpan ke Enterprise Drive menjadi milik perusahaan. Setelah keluar, karyawan tidak dapat lagi mengaksesnya. File hanya dapat diakses oleh anggota internal perusahaan.
  </Accordion>
</AccordionGroup>

## Kolaborasi

<AccordionGroup>
  <Accordion id="q14" title="Bagaimana cara berkolaborasi dengan orang lain pada file yang sama?">
    Jika Anda pembuat file, tambahkan izin edit untuk kolaborator. Buka DingTalk Drive, klik **...** setelah file, buka **Permission Settings**, tambahkan orang yang ditentukan, lalu pilih **Can edit**.

    Jika Anda penerima file yang dibagikan, minta izin edit dari pembuat file tersebut.
  </Accordion>
  <Accordion id="q15" title="Apa yang harus saya lakukan jika konten terhapus secara tidak sengaja saat berkolaborasi?">
    Pulihkan versi file sebelumnya melalui riwayat versi.

    **Desktop:** Buka DingTalk Drive, klik file, klik waktu penyimpanan untuk melihat riwayat pengeditan file, lalu klik **Restore** untuk memulihkan konten yang terhapus secara tidak sengaja dengan cepat.

    **Seluler:** Buka DingTalk Collaboration, buka DingTalk Drive, ketuk **...** setelah file terkait, lalu buka **History Versions**.

    Sistem otomatis mengurutkan versi berdasarkan urutan pengeditan dan menampilkan editor serta waktu pengeditan sehingga Anda dapat menemukan versi yang benar dengan cepat.
  </Accordion>
  <Accordion id="q16" title="Bagaimana cara mengatur folder sebagai folder bersama untuk pengeditan kolaboratif banyak orang?">
    Saat membuat folder, atur ke **Share with others** dan undang orang lain untuk berkolaborasi. Folder akan ditandai dengan indikator berbagi. Setelah dibuat, folder otomatis muncul di DingTalk Drive pihak lain.
  </Accordion>
</AccordionGroup>

## Perlindungan Keamanan Informasi

**Metode 1: Konfigurasikan izin.** Kami menyarankan untuk mengatur izin pihak lain ke **View only**.

Buka halaman beranda DingTalk Drive, **File Tim** pada beranda Docs, atau **File Saya (dari DingTalk Drive)** di bawah Dokumen Saya. Cari file atau folder yang dituju, klik **...** untuk opsi lainnya, lalu pilih **Permission Management**.

Klik **Add Collaborator**, pilih anggota yang ingin ditambahkan, pilih tingkat izin yang sesuai, lalu klik **OK**. Tingkat izin meliputi **Can manage**, **Can edit**, **Can view/download**, dan **View only**. Notifikasi izin dapat dikirim melalui obrolan satu lawan satu.

**Metode 2: Kirim tautan.**

Buka halaman beranda DingTalk Drive, **File Tim** pada beranda Docs, atau **File Saya (dari DingTalk Drive)** di bawah Dokumen Saya. Cari file atau folder yang dituju, klik **...** untuk opsi lainnya, lalu klik **Bagikan** atau **Send Link**.

**Metode 3: Teruskan salinan.**

Untuk folder, file lokal, video, gambar, PDF, dan dokumen non-online lainnya, klik **...** untuk opsi lainnya, lalu pilih **Forward copy** untuk mengirim salinan ke pihak lain.

**Metode 4: Dapatkan tautan berbagi.**

Buka DingTalk Drive, klik **...** setelah dokumen terkait, yang berlaku untuk dokumen unggahan biasa, dapatkan tautan berbagi, atur masa berlaku file, lalu kirim tautan eksternal ke pihak lain.
