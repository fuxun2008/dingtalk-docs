---
title: "Tidak Bisa Membuka File Secara Lokal?"
description: "Tanpa izin unduh, file tidak dapat disinkronkan ke folder lokal atau dibuka secara lokal. Penyebab umum: Anda tidak punya izin lihat/unduh, file memiliki proteksi kebocoran, atau admin membatasi unduhan lokal untuk file tertentu."
---

Jika Anda tidak memiliki izin untuk mengunduh sebuah file, file tersebut tidak dapat disinkronkan ke folder lokal Anda atau dibuka secara lokal. Nama file tetap terlihat di folder lokal, tetapi mengklik nama file akan meminta Anda untuk membukanya di DingTalk.

Alasan umum Anda mungkin tidak memiliki izin unduh:

1. Anda tidak memiliki izin **Dapat melihat/mengunduh** atau yang lebih tinggi.

2. File atau folder induknya memiliki proteksi kebocoran yang diaktifkan. Untuk memeriksanya, buka **Lainnya** pada file > **Manajemen Izin** > **Pengaturan Keamanan** > **Proteksi Kebocoran**.

3. Admin perusahaan Anda telah mengaktifkan proteksi keamanan file yang mencegah file tertentu diunduh secara lokal. (Hubungi admin Anda untuk detailnya.)
