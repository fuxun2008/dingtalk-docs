Halaman beranda DingTalk Drive mendukung pembuatan dan pengunggahan file atau folder, sehingga memudahkan perusahaan dan pengguna mengelola file secara mandiri.

## Desktop

1.  Buka **DingTalk Drive**. Di **Terbaru**, klik **Baru** di sudut kanan atas, lalu pilih tipe file atau folder yang ingin Anda buat.
    
![](https://img.alicdn.com/imgextra/i3/O1CN01oVosCOrGPHB713Mj_!!6000000003527-2-tps-3456-2165.png)
    
2.  Di halaman beranda DingTalk Drive, buka **File Saya**. Anda juga dapat membuka **Dokumen Saya** di halaman beranda Docs, lalu masuk ke **File Saya (dari DingTalk Drive)**. Klik **Baru** di sudut kanan atas untuk membuat tipe file, mengunggah file, atau mengunggah folder.
    
![](https://img.alicdn.com/imgextra/i2/O1CN01ikSCvEfOWbI713Mj_!!6000000001844-2-tps-3456-2165.png)
    
![](https://img.alicdn.com/imgextra/i1/O1CN01TFWoOB1M6oD713Mj_!!6000000005997-2-tps-3456-2165.png)
    
3.  Di halaman beranda DingTalk Drive, buka **File Tim**. Buat folder terlebih dahulu, lalu masuk ke folder tersebut untuk membuat tipe file, mengunggah file, atau mengunggah folder.
    

![](https://img.alicdn.com/imgextra/i4/O1CN01qw7aZsMQNtC713Mj_!!6000000003812-2-tps-3456-2165.png)

![](https://img.alicdn.com/imgextra/i4/O1CN01CJ8wm8Jl4wE713Mj_!!6000000000872-2-tps-3456-2165.png)

![](https://img.alicdn.com/imgextra/i3/O1CN01oDdSVAFCexH713Mj_!!6000000005918-2-tps-3456-2165.png)

Saat membuat folder di **File Tim**, konfigurasikan izin yang sesuai:

*   **Tambah orang tertentu:** Tambahkan anggota di dalam organisasi yang dapat mengakses folder tersebut.
    
*   **Konfigurasi keamanan:** Gunakan watermark pratinjau file, perlindungan anti-kebocoran, dan pengaturan izin yang fleksibel untuk mengurangi risiko kebocoran informasi sensitif tim serta menjaga keamanan data.
    

![](https://img.alicdn.com/imgextra/i2/O1CN01HpcbaeA9pdF713Mj_!!6000000007300-2-tps-3456-2165.png)

## Ponsel

### Metode 1

Buka DingTalk, masuk ke **Workbench**, lalu pilih **DingTalk Drive**. Anda juga dapat mencari aplikasi **DingTalk Drive** di kotak pencarian DingTalk.

Sama seperti di desktop, buka **Terbaru** atau **File Saya**, lalu ketuk tombol **+** di sudut kanan bawah untuk membuat folder, dokumen, spreadsheet, formulir pengumpulan, mind map, whiteboard, dan lainnya.

### Metode 2

Di DingTalk, masuk ke **Lainnya**, lalu pilih **Docs**. Di bawah **File Saya (dari DingTalk Drive)**, ketuk tombol **+** di sudut kanan bawah untuk membuat folder, dokumen, spreadsheet, formulir pengumpulan, mind map, whiteboard, dan lainnya.
