Halaman beranda DingTalk Drive memungkinkan Anda mencari file dengan cepat, membuat atau mengunggah file dan folder, meninjau semua file yang dilihat atau diedit di DingTalk selama sebulan terakhir, serta melihat semua file yang tersimpan di Enterprise Drive, termasuk Dokumen Saya, File Tim, File Obrolan, dan file yang dibagikan. Bagian di bawah ini menjelaskan setiap area.

## Cari file

Di dalam organisasi perusahaan, gunakan bidang **Cari File** untuk memasukkan nama file atau folder yang ingin Anda temukan.

![](https://img.alicdn.com/imgextra/i3/O1CN01yaaLaOnIpgI713Mj_!!6000000005026-2-tps-3456-2165.png)

## Buat atau unggah

Halaman beranda DingTalk Drive mendukung pembuatan atau pengunggahan file dan folder, sehingga memudahkan perusahaan dan pengguna mengelola file secara mandiri.

![](https://img.alicdn.com/imgextra/i2/O1CN01dsyNcTXF6FL713Mj_!!6000000002849-2-tps-3456-2165.png)

## Terbaru

**Terbaru** di DingTalk Drive membantu Anda menemukan file dengan cepat. Bagian ini menampilkan semua file yang dilihat atau diedit di DingTalk selama sebulan terakhir. File historis dikelompokkan ke dalam tiga kategori: **Baru saja dilihat**, **Baru saja diedit**, dan **Baru saja diunduh**, sehingga meningkatkan efisiensi dalam melacak dan mengakses file yang dituju.

![](https://img.alicdn.com/imgextra/i1/O1CN01xzVy3CSzMqG3ANU8_!!6000000001825-2-tps-1560-1008.png)

## File: File Saya dan File Tim

**File** adalah tempat penyimpanan file kerja di Enterprise Drive. Bagian ini dapat menampilkan file kerja yang disimpan di folder yang berbeda. File yang telah Anda edit atau lihat di DingTalk Docs juga tersimpan di **File** secara default.

DingTalk Drive menyediakan dua folder awal: **File Saya** dan **File Tim**. Kapasitas awalnya adalah 100 GB.

![](https://img.alicdn.com/imgextra/i3/O1CN01Hc4XsXDCicG713Mj_!!6000000001002-2-tps-3456-2165.png)

**Urutkan file:** Urutkan file berdasarkan nama, waktu pembaruan, waktu pembuatan, atau ukuran file.

![](https://img.alicdn.com/imgextra/i1/O1CN01oxXjcy3j11H713Mj_!!6000000000786-2-tps-3456-2165.png)

**Ganti gaya tampilan:** Beralih antara **tampilan thumbnail** dan **tampilan daftar**.

![](https://img.alicdn.com/imgextra/i4/O1CN01JrFDp2EDeBJ713Mj_!!6000000002257-2-tps-3456-2165.png)

![](https://img.alicdn.com/imgextra/i4/O1CN01Qpp1oLquVGB713Mj_!!6000000003321-2-tps-3456-2165.png)

## File Tim

File yang diedit, dilihat, atau diunggah oleh perusahaan atau organisasi dalam pekerjaan sehari-hari disimpan di **File Tim**.

![](https://img.alicdn.com/imgextra/i1/O1CN01keEgRbfQRaE713Mj_!!6000000003087-2-tps-3456-2165.png)

## File Obrolan

File dari File Obrolan Saya, grup biasa, dan grup perusahaan dapat disimpan di **File Obrolan**.

![](https://img.alicdn.com/imgextra/i2/O1CN01PPNVdi2b1dC713Mj_!!6000000004183-2-tps-3456-2165.png)

## Dibagikan

Di **Dibagikan**, Anda dapat melihat catatan file yang **dibagikan kepada saya** dan file yang **dibagikan oleh saya**.

![](https://img.alicdn.com/imgextra/i2/O1CN01rEewFUTlcaL713Mj_!!6000000004989-2-tps-3456-2165.png)
