DingTalk Drive adalah drive perusahaan berbasis Alibaba Cloud yang menyediakan solusi pengelolaan data perusahaan yang cerdas dan aman. DingTalk Drive menyatukan **penyimpanan file, pengelolaan file, dan kolaborasi banyak orang** dalam satu platform pengelolaan file.

Simpan, edit, dan bagikan materi kerja dan belajar dari perangkat mana pun, kapan pun dan di mana pun, sehingga kolaborasi dokumen menjadi lebih efisien.

Kapasitas awal Enterprise Drive adalah 100 GB.

DingTalk Drive terutama terdiri atas **Enterprise Drive**, yang mencakup tiga folder:

1.  File Saya
    
2.  File Tim
    
3.  File Obrolan, yang mencakup File Obrolan Saya dan File Grup Internal

## Simpan ke DingTalk Drive dalam satu klik dan akses file kapan saja

Simpan file ke DingTalk Drive hanya dengan satu klik, sehingga aset kerja perusahaan terkelola di satu tempat. Prosesnya sederhana, dan file dapat dilihat, diedit, serta diatur kapan saja.

![](https://img.alicdn.com/imgextra/i2/O1CN01qaXpk7g0eGF713Mj_!!6000000001664-2-tps-3456-2165.png)

![](https://img.alicdn.com/imgextra/i4/O1CN01DcuCk62h5FL713Mj_!!6000000005955-2-tps-3456-2165.png)

## Pengelolaan izin yang lebih terperinci

Izin file yang terperinci memungkinkan Anda memberikan akses secara tepat berdasarkan file dan orang, sehingga membantu melindungi aset data perusahaan.

![](https://img.alicdn.com/imgextra/i2/O1CN01Ss39QE2j8zC713Mj_!!6000000001303-2-tps-3456-2165.png)

## Edit online kapan saja, di mana saja

Buka dokumen langsung dari DingTalk Drive di perangkat mana pun. Hasil edit tersimpan secara otomatis dan real-time, sehingga Anda dapat berkarya dengan bebas di mana pun berada.

![](https://img.alicdn.com/imgextra/i2/O1CN01l1v2vSLxLGD713Mj_!!6000000004434-2-tps-3456-2165.png)

## Kolaborasi file tanpa hambatan

Tidak perlu lagi mengirim file bolak-balik. Beberapa orang dapat berkolaborasi secara online, konten tersinkron secara real-time, dan semua orang melihat versi terbaru.

![](https://img.alicdn.com/imgextra/i2/O1CN01oNvcgYSN4HH713Mj_!!6000000003258-2-tps-3456-2165.png)
