---
title: "Cara Menggunakan File Picker DingTalk Drive untuk Mengirim File Secara Efisien"
description: "Gunakan File Picker DingTalk Drive di dalam obrolan: klik ikon kirim file di bawah kotak input, pilih Send DingTalk Drive File, lalu pilih file dari Drive Anda untuk dikirim secara efisien."
polished: true
---

Di jendela pesan obrolan, klik ikon **kirim file** di bawah kotak input, lalu pilih **Send DingTalk Drive File** untuk memilih dan mengirim file dari DingTalk Drive.
