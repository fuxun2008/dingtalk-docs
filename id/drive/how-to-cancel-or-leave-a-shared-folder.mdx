polished: true

Jika Anda pembuat sebuah folder, Anda dapat membatalkan berbagi untuk folder tersebut. Setelah berbagi dibatalkan, folder kembali menjadi privat, dan orang lain tidak lagi dapat melihat atau mengeditnya.

Jika Anda penerima folder bersama, Anda hanya dapat meninggalkan folder tersebut. Anda tidak dapat membatalkan berbagi untuk semua orang. Setelah Anda meninggalkan folder, folder akan dihapus dari daftar file lengkap Anda.

## Desktop

Buka halaman beranda DingTalk Drive, **File Tim** pada halaman beranda Docs, atau **File Saya (dari DingTalk Drive)** di bawah Dokumen Saya. Cari folder yang dituju, klik **...**, pilih **Manajemen Izin**, lalu hapus anggota yang saat ini memiliki akses.
