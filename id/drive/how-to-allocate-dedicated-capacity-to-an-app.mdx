---
title: "Cara Mengalokasikan Kapasitas Khusus ke Aplikasi"
description: "Panduan admin — buka Admin Console, masuk ke Storage Management, klik Allocate di samping aplikasi target, dan alokasikan kapasitas DingTalk Drive khusus agar data aplikasi tersebut tetap terpisah."
polished: true
---

Buka Admin Console. Di **Storage Management**, klik **Allocate** di samping aplikasi yang membutuhkan kapasitas, lalu pilih kapasitas yang akan dialokasikan dan selesaikan pengaturannya.
