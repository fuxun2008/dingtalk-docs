# Apa itu kunci edit file?

*   Saat pengguna mulai mengedit file di folder sinkronisasi lokal DingTalk Drive, file tersebut akan dikunci.
    
*   File yang terkunci tidak dapat diedit oleh pengguna lain di perangkat lain sehingga mencegah konflik versi dan mengurangi beban pengelolaan versi.
    
*   Saat pengguna menutup file, kunci akan otomatis dilepas dan pengguna lain dapat membuka serta mengeditnya.
