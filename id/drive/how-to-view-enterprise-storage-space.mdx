description: "Cek penggunaan 100 GB penyimpanan Drive perusahaan gratis di DingTalk Drive. Saat penyimpanan penuh, perluas kapasitas atau bersihkan file lama secara berkala untuk mengatasi masalah kapasitas tanpa biaya tambahan."
polished: true
---

Setiap perusahaan memperoleh 100 GB penyimpanan DingTalk Drive secara gratis. Jika ruang tersebut penuh, perusahaan dapat memperluas kapasitas. Jika tidak ingin membayar kapasitas tambahan, perusahaan juga dapat membersihkan penyimpanan secara berkala untuk mengatasi masalah kapasitas DingTalk Drive.

Buka DingTalk Drive, klik **Lainnya** di pojok kiri bawah, lalu klik **Kapasitas penyimpanan perusahaan** untuk melihat kapasitas yang sedang digunakan perusahaan.

![](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/NpQlK5jBd0130qDv/img/5d9d53d6-4dc2-4c2e-89e3-46dc2ffedba2.png?x-oss-process=image/crop,x_0,y_69,w_3456,h_2165/ignore-error,1)

Klik **Lihat Detail** untuk melihat penggunaan terperinci per aplikasi.

![](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/NpQlK5jBd0130qDv/img/a2966856-70d2-46f9-adec-8e1e41b07ccc.png?x-oss-process=image/crop,x_0,y_69,w_3456,h_2165/ignore-error,1)

Klik **Kelola** untuk membuka konsol admin perusahaan dan melihat informasi kapasitas penyimpanan secara terperinci.

![](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/NpQlK5jBd0130qDv/img/e1eb3475-e381-42d5-96b3-4a6ee9260762.png?x-oss-process=image/crop,x_0,y_74,w_3456,h_2160/ignore-error,1)
