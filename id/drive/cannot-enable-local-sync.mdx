<Tip>
  Local Sync sedang dirilis secara bertahap. Nantikan pembaruannya.
</Tip>

# 1. Aktifkan local sync dari desktop DingTalk.

*   Local sync mendukung sinkronisasi data dua arah antara folder di komputer Anda dan folder di DingTalk Drive.
    

*   Di perangkat seluler, buka DingTalk Drive untuk melihat versi terbaru file Anda kapan saja.
    

# 2. Pastikan sistem operasi dan desktop DingTalk Anda diperbarui ke versi terbaru.

*   **Desktop DingTalk**: Versi 8.2.0 atau lebih baru (unduh dari [**dingtalk.io**](https://www.dingtalk.io/download/))
    
*   **Windows**: Windows 10 (64-bit), versi 1709 atau lebih baru
    
*   **Mac**: Belum tersedia. Nantikan pembaruannya.
    

# 3. Pastikan admin perusahaan Anda mengizinkan penggunaan local sync.

*   Admin perusahaan dapat membatasi anggota mana yang boleh menggunakan local sync.
    
*   Di Admin Console perusahaan, buka **Docs and Storage Management** > **Permissions and Security** > **Permission Settings** untuk mengonfigurasi siapa yang boleh menggunakan local sync.
    
*   Anggota yang dibatasi tidak akan melihat opsi **Enable Local Sync** di DingTalk Drive.
