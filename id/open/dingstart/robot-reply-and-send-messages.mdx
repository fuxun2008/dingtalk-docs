Jika Anda perlu menerapkan balasan Bot atau pengiriman pesan Bot, ikuti langkah-langkah dalam dokumen ini untuk mengembangkan balasan Bot atau pengiriman pesan Bot.

## Latar belakang

Membalas pesan dengan Bot pada dasarnya sama dengan proses mengirim pesan dengan Bot. Oleh karena itu, dalam dokumen ini, membalas dan mengirim memiliki makna yang sama.

Pesan dapat dikirim melalui Server API atau Webhook. Bagian berikut memperkenalkan kedua metode tersebut.

## Prasyarat

1. Selesaikan proses [Buat aplikasi](/id/open/dingstart/create-application).
2. Selesaikan proses penambahan kapabilitas aplikasi.

## Kirim pesan melalui Webhook

### Kirim pesan melalui Webhook

<Note>
Pengiriman pesan melalui Webhook mendukung fitur @. Lihat contoh integrasi di bawah untuk detailnya.
</Note>

1. Kirim pesan melalui URL Webhook Bot aplikasi:

   1. Di [Bot menerima pesan](/id/open/dingstart/robot-receive-message), dapatkan URL Webhook Bot aplikasi dalam grup. Untuk detailnya, lihat [Dapatkan Webhook Bot aplikasi](/id/open/development/faq-robot).
   2. Penyiapan lingkungan pengembangan Java:

      - Impor Java SDK. Untuk SDK dalam bahasa lain, lihat unduhan SDK sisi server versi lama.

        ```xml lines
        <dependency>
            <groupId>com.aliyun</groupId>
            <artifactId>alibaba-dingtalk-service-sdk</artifactId>
            <version>2.0.0</version>
        </dependency>
        ```
   3. Contoh kode integrasi:

      ```java lines
      public void sendMessageWebhook() throws ApiException {
              DingTalkClient client = new DefaultDingTalkClient("{ Webhook url }");
              OapiRobotSendRequest request = new OapiRobotSendRequest();
              request.setMsgtype("text");
              OapiRobotSendRequest.Text text = new OapiRobotSendRequest.Text();
              text.setContent("Pesan teks uji coba");
              request.setText(text);
              OapiRobotSendRequest.At at = new OapiRobotSendRequest.At();
              at.setAtUserIds(Arrays.asList("4525xxxxxxxxx7041"));
              at.setIsAtAll(false);
              request.setAt(at);
              OapiRobotSendResponse response = client.execute(request);
              System.out.println(response.getBody());
      }
      ```

      Untuk lebih banyak jenis pesan, lihat jenis pesan yang didukung oleh pengiriman pesan Bot kustom.
2. Kirim pesan melalui bidang sessionWebhook yang dikembalikan saat Bot menerima pesan.

   1. Dapatkan URL sessionWebhook dari data JSON yang dikembalikan di [Bot menerima pesan](/id/open/dingstart/robot-receive-message).
   2. Penyiapan lingkungan pengembangan Java:

      - Impor Java SDK. Untuk SDK dalam bahasa lain, lihat unduhan SDK sisi server versi lama.

        ```xml lines
        <dependency>
            <groupId>com.aliyun</groupId>
            <artifactId>alibaba-dingtalk-service-sdk</artifactId>
            <version>2.0.0</version>
        </dependency>
        ```
   3. Contoh kode integrasi:

      ```java lines
      public void sendMessageWebhook() throws ApiException {
              DingTalkClient client = new DefaultDingTalkClient("{ SessionWebhook url }");
              OapiRobotSendRequest request = new OapiRobotSendRequest();
              request.setMsgtype("text");
              OapiRobotSendRequest.Text text = new OapiRobotSendRequest.Text();
              text.setContent("Pesan teks uji coba");
              request.setText(text);
              OapiRobotSendRequest.At at = new OapiRobotSendRequest.At();
              at.setAtUserIds(Arrays.asList("4525xxxxxxxxx7041"));
              at.setIsAtAll(false);
              request.setAt(at);
              OapiRobotSendResponse response = client.execute(request);
              System.out.println(response.getBody());
      }
      ```

      Untuk lebih banyak jenis pesan, lihat jenis pesan yang didukung oleh pengiriman pesan Bot kustom.
