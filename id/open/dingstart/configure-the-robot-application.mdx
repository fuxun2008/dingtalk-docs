Untuk mengonfigurasi aplikasi bot perusahaan, ikuti langkah-langkah dalam dokumen ini.

## Prasyarat

1. Selesaikan proses [Buat aplikasi](/id/open/dingstart/create-application).
2. Selesaikan proses penambahan kemampuan aplikasi.

## Prosedur

1. Masuk ke [Developer Backend](https://open-dev.dingtalk.io/#/) dan klik aplikasi target untuk membuka halaman detail aplikasi.
2. Klik **App Capabilities** > **Bots** lalu aktifkan konfigurasi bot.
3. **Konfigurasikan informasi bot**:

   | **Item** | **Wajib** | **Deskripsi** |
   | --- | --- | --- |
   | Nama bot | Ya | Gunakan kata-kata yang jelas dan sesuai. Hindari ambiguitas, salah ketik, dan istilah yang tidak sesuai ketentuan. |
   | Ikon bot | Ya | Ukuran yang disarankan: 240 x 240 piksel. Gunakan gambar yang jelas dengan konten utama berada di tengah. Hindari gambar yang terlalu kecil, terlalu besar, atau memuat konten yang tidak sesuai ketentuan. |
   | Ringkasan bot | Ya | Berikan deskripsi singkat tentang bot, maksimal 10 karakter. Deskripsi ini ditampilkan kepada pengguna saat bot ditambahkan ke sebuah grup. |
   | Deskripsi bot | Ya | Jelaskan fitur bot, maksimal 200 karakter. Deskripsi ini ditampilkan pada Kartu Nama bot dan saat bot ditambahkan ke sebuah grup. |
   | Gambar pratinjau pesan bot | Ya | Gambar harus dalam format PNG, JPEG, atau JPG dan tidak lebih besar dari 2 MB. Gambar dapat diubah. |
   | Mode penerimaan pesan | Tidak | Digunakan untuk menerima pesan POST yang dikirim oleh DingTalk: - Mode HTTP - Mode Stream. Untuk detailnya, lihat [Penerimaan pesan bot](/id/open/dingstart/robot-receive-message). |
   | URL penerimaan pesan  **Catatan**  Hanya wajib dalam **mode HTTP** | Tidak | Masukkan endpoint HTTPS milik organisasi Anda yang dapat diakses publik untuk menerima pesan POST yang dikirim oleh DingTalk. |
4. Klik Publish (Simpan) untuk memublikasikan bot.
5. (Opsional) Setelah memublikasikan, klik tombol **Debug**. Sebuah grup uji dibuat secara otomatis. Anda dapat menguji fitur @bot di dalam grup tersebut.

## Langkah selanjutnya

Setelah memublikasikan bot, Anda juga harus memublikasikan aplikasi. Untuk detailnya, lihat Publikasikan aplikasi.
