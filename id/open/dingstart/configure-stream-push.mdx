---
title: "Mengonfigurasi Push Stream (Direkomendasikan)"
description: "Konfigurasikan push peristiwa mode Stream untuk aplikasi internal di Konsol Pengembang DingTalk untuk menerima pesan langganan peristiwa melalui koneksi persisten, tanpa perlu URL callback publik."
---

Jika Anda perlu mengonfigurasi push peristiwa mode Stream, ikuti langkah-langkah dalam dokumen ini untuk menyelesaikan integrasi.

## Prasyarat

- Anda memiliki <a href="https://open.dingtalk.com/document/orgapp/obtain-developer-permissions" target="_blank">izin pengembang</a> di Konsol Pengembang DingTalk organisasi Anda.
- Anda memiliki <a href="https://open.dingtalk.com/document/orgapp/create-an-application" target="_blank">aplikasi internal</a> di organisasi DingTalk Anda.
- Anda telah menyelesaikan proses <a href="https://open.dingtalk.com/document/orgapp/develop-stream-mode-push-server" target="_blank">Mengembangkan server push mode Stream (Direkomendasikan)</a>.

## Prosedur

<Steps>
<Step title="Buka halaman detail aplikasi">
Masuk ke <a href="https://open-dev.dingtalk.com/" target="_blank">Konsol Pengembang</a>, klik aplikasi target, lalu buka halaman detail aplikasi.
</Step>
<Step title="Pilih push mode Stream">
Klik **Konfigurasi Pengembangan > Langganan Peristiwa**, lalu pilih **Push mode Stream**.
</Step>
<Step title="Verifikasi saluran koneksi">
Setelah pengembangan sisi server selesai, klik **Integrasi selesai, verifikasi saluran koneksi**.
</Step>
<Step title="Simpan">
Klik **Simpan**. Daftar langganan peristiwa hanya muncul setelah Anda menyimpan.
