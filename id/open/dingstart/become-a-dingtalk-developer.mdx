Sebelum memulai pengembangan, admin organisasi harus memberikan izin developer kepada developer. Developer dengan identitas berbeda dapat mengembangkan jenis aplikasi yang berbeda.

|  |  |  |
| --- | --- | --- |
| **Developer** | **Jenis aplikasi yang dikembangkan** | **Organisasi terkait** |
| Developer internal | Aplikasi internal yang dibuat oleh organisasi | Mengembangkan aplikasi internal yang dibuat oleh organisasi sebagai karyawan internal. |
| Developer dari penyedia solusi | Aplikasi perusahaan pihak ketiga  Mengembangkan aplikasi internal atas delegasi | Untuk mengembangkan aplikasi perusahaan pihak ketiga atau aplikasi kustom bagi organisasi sebagai developer dari penyedia solusi, Organisasi Anda harus menyelesaikan autentikasi penyedia solusi. Untuk detailnya, lihat [Panduan Proses Kerja Sama Penuh](/zh/open/development/isv-cooperation-guide). |

## Prosedur

Admin organisasi memberikan izin developer kepada developer dengan mengikuti langkah-langkah berikut:

**Catatan**

Setelah mengajukan izin developer, developer dapat masuk untuk mengembangkan, mengunggah, dan menerbitkan aplikasi.

1. Admin organisasi masuk ke [OA Admin Console](https://oa.dingtalk.com/index.htm#/safety/subAccount).

2. Di Admin Console, pilih **Security & Permissions** > **Manage Permissions**, lalu klik **Management Groups** untuk membuka halaman **Management Groups**.

3. Klik **Add Management Group**.

4. Di halaman **Edit Management Group**, isi kolom-kolom berikut, lalu klik **Save**.

- **Management group name:** Masukkan nama grup manajemen.
- **Users:** Tetapkan pengguna ke grup manajemen.
- **Management scope:** Pilih cakupan manajemen.
- **Assign permissions:** Pilih izin yang sesuai.

5. Developer masuk ke [Developer Console](https://open-dev.dingtalk.com/#/index) untuk mengembangkan aplikasi.
