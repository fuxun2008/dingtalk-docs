Untuk mengirim pesan di Grup Standar atau Obrolan Eksternal, ikuti langkah-langkah dalam dokumen ini untuk membuat Bot kustom.

<Warning>
Bot kustom hanya mendukung pengiriman pesan di dalam grup. Pesan Langsung tidak didukung.
</Warning>

## Prosedur

1. Masuk ke Sisi klien DingTalk dan pilih Obrolan Grup tempat Anda ingin menambahkan bot.
2. Buka Obrolan Grup dan klik ikon **Pengaturan grup** di sudut kanan atas.

3. Di bagian Kelola Grup, klik **Bot** > **Tambah Bot**, lalu pilih Bot kustom.

4. Klik **Tambah** dan konfigurasikan informasi bot:

   | **Item** | **Deskripsi** |
   | --- | --- |
   | Foto Profil Bot | Klik ikon edit untuk mengunggah Foto Profil bot. |
   | Nama Bot | Masukkan nama untuk bot. |
   | Pengaturan Keamanan | Jenis Pengaturan Keamanan: - Kata kunci kustom - Tanda tangani permintaan - Alamat IP (rentang) Untuk detail tentang Pengaturan Keamanan, lihat [Pengaturan keamanan Bot kustom](/id/open/dingstart/customize-robot-security-settings). |
   | (Opsional) Aktifkan mekanisme Outgoing | Saat Bot grup disebut dengan @, pesan dikirim ke layanan eksternal tertentu, dan respons dari layanan eksternal dapat dikembalikan ke Obrolan Grup. Untuk jenis pesan dan format Data yang diterima oleh bot, lihat Penerimaan pesan bot. |

   Setelah konfigurasi, pilih **Custom Bot Service and Disclaimer** lalu klik **Selesai**.

## Langkah berikutnya

Untuk mengirim pesan menggunakan Bot kustom, lihat Dokumen berikut:

- Kirim pesan Obrolan Grup dengan Bot kustom
