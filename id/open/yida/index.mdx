DingTalk YiDA adalah platform pengembangan low-code dari Cloud DingTalk. Selain kemampuan dasar seperti formulir, alur kerja, dan laporan, YiDA juga menghadirkan pengalaman pengembangan **halaman kustom** yang jauh lebih fleksibel: pengembangan drag-and-drop WYSIWYG, kumpulan API frontend yang lengkap untuk seluruh siklus hidup aplikasi, akses langsung ke DingTalk JS-API, serta kustomisasi backend melalui konektor.

<Note>
Jika Anda belum familier dengan kode dan ingin membangun halaman formulir, alur kerja, atau laporan dengan cepat, mulailah dari [Panduan Pengguna YiDA](/id/yida/intro/sbg6g2nsoxacis5y) untuk mempelajari kemampuan inti produk.
</Note>
