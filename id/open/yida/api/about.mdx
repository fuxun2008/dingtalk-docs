Platform YiDA menyediakan beragam solusi Open API bagi developer. Untuk skenario yang berbeda, developer dapat memilih solusi Open API yang sesuai guna memenuhi kebutuhan bisnisnya. Perbedaan dan skenario penggunaan setiap Open API adalah sebagai berikut:

- **YiDA JS-API** — Digunakan untuk memanggil API fungsional sisi klien pada skenario panel aksi atau pengikatan variabel di dalam desainer YiDA, seperti pemformatan string dan pengambilan nilai komponen formulir. Untuk detail penggunaan, lihat [Dokumentasi YiDA JS-API](/id/open/yida/api/yidaAPI).
- **Cross-app Data Source API** — Digunakan pada konfigurasi remote API di dalam desainer YiDA untuk melakukan operasi CRUD pada data aplikasi YiDA, seperti kueri data formulir dan inisiasi proses. Untuk detail penggunaan, lihat [Dokumentasi Cross-app Data Source API](/id/open/yida/api/openAPI).
- **DingTalk JS-API** — Digunakan oleh produk yang telah dibangun untuk memanggil JSAPI yang disediakan oleh klien DingTalk di dalam DingTalk, seperti dialog native dan pengambilan informasi perangkat. Untuk detail penggunaan, lihat [Dokumentasi DingTalk JS-API](/id/open/yida/api/dingAPI).
- **Server-side Open API** — Digunakan untuk memanggil Open API YiDA dari sisi server. Fungsinya pada dasarnya sama dengan Cross-app Data Source API, tetapi ditujukan untuk pemanggilan sisi server sehingga menyertakan langkah autentikasi. Untuk detail penggunaan, lihat [Dokumentasi Server-side Open API](/id/open/yida/api/serverAPI).
