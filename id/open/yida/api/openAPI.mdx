YiDA menyediakan kemampuan remote API yang memungkinkan Anda memanggil antarmuka asinkron berbasis HTTP (lihat [dokumentasi remote API](/id/open/yida/guide/concept/datasource) untuk detailnya). Selain itu, platform YiDA menyediakan sejumlah remote API bawaan untuk mengoperasikan data YiDA.

<Warning>
YiDA Open API memerlukan autentikasi, sehingga tidak dapat dipanggil langsung dari halaman silent-login. Rutekan panggilan tersebut melalui fungsi FaaS atau layanan backend mandiri.
</Warning>

## Catatan penggunaan API

### Jalur permintaan

YiDA menyediakan API pada tingkat aplikasi. Di dalam sebuah aplikasi, panggil remote API (panggilan lintas aplikasi didukung) menggunakan format URL berikut:

```bash
# Anda dapat menemukan kode aplikasi di halaman Deployment & Operations pada App Settings.
# Untuk jalur antarmuka, lihat dokumentasi di bawah. API yang berbeda menggunakan jalur antarmuka yang berbeda.
"/dingtalk/web/${appCode}/${interfacePath}"
```

<Tip>
Saat menulis kode permintaan API di platform YiDA, gunakan jalur relatif seperti contoh berikut agar Anda tidak perlu memperbarui kode ketika subdomain organisasi berubah.

```bash
/dingtalk/web/APP_X1X2X3X4/v1/form/searchFormDatas.json
```

</Tip>

### Struktur respons

Struktur respons yang dikembalikan oleh remote API YiDA adalah sebagai berikut:

```typescript
interface IResponse {
  success: boolean; // Apakah permintaan berhasil
  result?: object | array | string; // Konten respons saat permintaan berhasil
  errorMsg?: string; // Pesan error
  errorCode?: string; // Kode error
  errorLevel?: number; // Tingkat error
}
```

## API Formulir

Platform YiDA menyediakan halaman bertipe formulir untuk mengumpulkan data formulir. API Formulir memungkinkan Anda membuat, membaca, memperbarui, dan menghapus data formulir. "Instans formulir" di sini mengacu pada satu rekaman dalam kumpulan data formulir.

### Buat instans formulir

- Jalur antarmuka: `/v1/form/saveFormData.json`
- Metode permintaan: `POST`
- Parameter: (`formDataJson` harus diserialisasi dengan `JSON.stringify()`.)

| Parameter    | Deskripsi        | Wajib | Contoh                                                                 | Catatan                                                                                     |
| :----------- | :--------------- | :---- | :--------------------------------------------------------------------- | :------------------------------------------------------------------------------------------ |
| formUuid     | ID Formulir      | Ya    | FORM-NJYJZELV8YZRDEI2N5IQ7L6VEDMR1VE9GMPCJB                            |                                                                                             |
| appType      | ID Aplikasi      | Ya    | APP_DR4OK27ZKL5N22B907E8                                               |                                                                                             |
| formDataJson | Data formulir    | Ya    | `{"textField_jcpm6agt": "Baris tunggal", "employeeField_jcos0sar": ["workno"]}` | Lihat [Lampiran 1: Format Data Formulir untuk Simpan/Perbarui](#format-data-formulir-untuk-simpanperbarui). |

- Contoh respons:

```json
{
  "result": "FINST-EF6Y93URN2UZ1SBPLIP9NAV6HR2GEO1Z4ZCHSCJ0",
  "success": true
}
```

- Antarmuka: `/v1/form/updateFormData.json`

- Parameter:

| updateFormDataJson | Nilai komponen formulir yang akan diperbarui  | Ya    | `{"employeeField_jcpm5gy2": ["xxxxx", "yyyyy"]}` | Lihat [Lampiran 1: Format Data Formulir untuk Simpan/Perbarui](#format-data-formulir-untuk-simpanperbarui). ## API Alur Kerja

Formulir alur kerja adalah salah satu kemampuan inti platform YiDA. API Alur Kerja memungkinkan Anda mengoperasikan instans alur kerja.

- Metode permintaan: `POST`
- Parameter:

| Parameter    | Deskripsi                                       | Wajib | Contoh                                                                                     | Catatan                                                                          |
| :----------- | :---------------------------------------------- | :---- | :----------------------------------------------------------------------------------------- | :------------------------------------------------------------------------------- |
| processCode  | Kode alur kerja                                 | Ya    | TPROC--EF6Y4G8WO2FN0SUB43TDQ3CGC3FMFQ1G9400RCJ4 (tersedia pada URL halaman mulai mandiri)  |                                                                                  |
| formUuid     | ID Formulir                                     | Ya    | FORM-EF6Y4G8WO2FN0SUB43TDQ3CGC3FMFQ1G9400RCJ3 (tersedia pada URL halaman mulai mandiri)    |                                                                                  |
| formDataJson | Data formulir                                   | Ya    |                                                                                            | Lihat [Lampiran 1: Format Data Formulir untuk Simpan/Perbarui](#format-data-formulir-untuk-simpanperbarui). |

- Setiap komponen dalam formulir memiliki ID unik (terlihat di panel "Advanced" di sebelah kanan komponen dalam desainer halaman), dan setiap komponen menggunakan format data tetap. Komponen formulir berikut didukung: input satu baris, input multi-baris, angka, radio, pilih dropdown, pilih banyak, pilih banyak dropdown, tanggal, rentang tanggal, pemilih pengguna, pemilih wilayah, pemilih departemen, pilih bertingkat, dan subformulir.
- Saat menyimpan atau memperbarui data formulir, teruskan nilai formulir sebagai string JSON dalam format `Map<String, Object>`. Key-nya adalah ID komponen, dan value-nya adalah nilai komponen. Format nilai untuk setiap komponen adalah sebagai berikut:

### Format Nilai Komponen untuk Pencarian Kondisional

- Setiap komponen dalam formulir memiliki ID unik (terlihat di panel "Advanced" di sebelah kanan komponen dalam desainer halaman), dan setiap komponen memiliki format pencariannya sendiri. Komponen formulir berikut mendukung pencarian: input satu baris, input multi-baris, angka, radio, pilih dropdown, pilih banyak, pilih banyak dropdown, tanggal, rentang tanggal, pemilih pengguna, pemilih wilayah, pemilih departemen, pilih bertingkat, dan subformulir.
- Saat mencari, gunakan format `Map<String, Object>` untuk mengekspresikan kondisi pencarian pada setiap komponen. Key-nya adalah ID komponen, dan value-nya adalah nilai pencarian untuk komponen tersebut. Tipe pencarian dan format nilai untuk setiap komponen adalah sebagai berikut:

| Tipe komponen              | Tipe data     | Format data                                                                 | Catatan                                                                                                                                    |
| :------------------------- | :------------ | :-------------------------------------------------------------------------- | :----------------------------------------------------------------------------------------------------------------------------------------- |
| Input satu baris           | String        | "danhang"                                                                   | Pencarian fuzzy.                                                                                                                           |
| Input multi-baris          | String        | "duohang"                                                                   | Pencarian fuzzy.                                                                                                                           |
| Input angka                | Array string  | ["1", "10"]                                                                 | Pencarian rentang. Nilai pertama adalah minimum; kedua adalah maksimum.                                                                    |
| Radio                      | String        | "Opsi 1"                                                                    | Kecocokan tepat.                                                                                                                           |
| Pilih dropdown             | String        | "Opsi 1"                                                                    |                                                                                                                                            |
| Pilih Banyak               | Array string  | ["Opsi 2"]                                                                  | Pencarian array. Nilai pencarian harus merupakan subset dari nilai pilih banyak.                                                           |
| Pilih banyak dropdown      | Array string  | ["Opsi 2"]                                                                  | Pencarian array. Nilai pencarian harus merupakan subset dari nilai pilih banyak.                                                           |
| Komponen tanggal           | Array string  | ["1514736000000", "1517414399000"]                                          | Pencarian rentang. Nilai pertama adalah stempel waktu tanggal mulai; kedua adalah stempel waktu tanggal akhir.                             |
| Rentang tanggal            | Array         | [["1514736000000", "1517414399000"], ["1514736000000", "1517414399000"]]    | Pencarian rentang. Array pertama adalah rentang pencarian untuk awal rentang tanggal; kedua adalah rentang pencarian untuk akhir.          |
| Pemilih pengguna           | Array string  | ["xxxxx", "yyyyy"]                                                          | ["xxxxx", "yyyyyy"] — kecocokan tepat. Nilai harus persis sama, dan urutan ID karyawan harus sama.                                         |
| Pemilih kota               | Array string  | ["110000", "110100", "110101"]                                              | ["110000", "110100", "110101"] — pencarian array. Nilai pencarian harus merupakan subset dari nilai kota. Untuk menyertakan ID kota, Anda harus menyertakan ID provinsi. Untuk menyertakan ID distrik, Anda harus menyertakan ID provinsi dan kota. |
| Pemilih departemen         | Angka         | 1123456                                                                     | Kecocokan tepat.                                                                                                                           |
| Pilih bertingkat           | Array string  | ["part", "part_b"]                                                          | Pencarian array. Batasan sama dengan pemilih kota.                                                                                         |
| Komponen subformulir       | String        | "danhang"                                                                   | Pencarian fuzzy. Nilai subformulir diperlakukan sebagai bidang teks besar, sehingga pencarian fuzzy digunakan.                             |

### Format Objek Detail Instans Alur Kerja

- Setiap komponen dalam formulir memiliki ID unik (terlihat di panel "Advanced" di sebelah kanan komponen dalam desainer halaman), dan setiap komponen memiliki format pencariannya sendiri. Komponen formulir berikut mendukung pencarian: input satu baris, input multi-baris, angka, radio, pilih dropdown, pilih banyak, pilih banyak dropdown, tanggal, rentang tanggal, pemilih pengguna, pemilih wilayah, pemilih departemen, pilih bertingkat, dan subformulir.
- Saat mencari, gunakan format `Map<String, Object>` untuk mengekspresikan kondisi pencarian pada setiap komponen. Key-nya adalah ID komponen, dan value-nya adalah nilai pencarian untuk komponen tersebut. Tipe pencarian dan format nilai untuk setiap komponen adalah sebagai berikut:

| Bidang            | Deskripsi                                                        | Contoh                                                                        | Catatan                                                                          |
| :---------------- | :--------------------------------------------------------------- | :---------------------------------------------------------------------------- | :------------------------------------------------------------------------------- |
| actioners         | Penerima tugas saat ini dari instans alur kerja                  | `[{"userId": "workno", "name":{"zh_CN": "user_zh_name", "type": "i18n"}}]`    | Jika alur kerja selesai dan tidak memiliki penerima tugas, bidang ini kosong.    |
| processInstanceId | ID instans                                                       | "f30233fb-72e1-4af4-8cb8-c7e0ea9ee530"                                        | Unik.                                                                            |
| formUuid          | ID formulir alur kerja                                           | FORM-EF6Y4G8WO2FN0SUB43TDQ3CGC3FMFQ1G9400RCJ3                                 |                                                                                  |
| processCode       | Kode alur kerja                                                  | TPROC--EF6Y4G8WO2FN0SUB43TDQ3CGC3FMFQ1G9400RCJ4                               |                                                                                  |
| title             | Judul instans                                                    | Alur kerja yang dimulai oleh xxxx                                             | Judul dikembalikan dalam bahasa lokal Anda.                                      |
| instanceStatus    | Status instans                                                   | RUNNING                                                                       |                                                                                  |
| approvedResult    | Hasil persetujuan saat alur kerja berakhir                        | agree                                                                         | agree → disetujui; disagree → ditolak.                                           |
| originator        | Array string                                                     | `[{"name":{"zh_CN": "user_zh_name", "type": "i18n"}, "userId": "workno"}]`    |                                                                                  |
| data              | Data formulir                                                    |                                                                               | Lihat [Lampiran 4: Format Data Formulir sebagai Nilai Respons](#format-data-formulir-sebagai-nilai-respons). |

### Format Data Formulir sebagai Nilai Respons

Format data formulir untuk nilai respons pada dasarnya sama dengan [Lampiran 1: Format Data Formulir untuk Simpan/Perbarui](#format-data-formulir-untuk-simpanperbarui), dengan perbedaan berikut:

- Pada input, nilai komponen wilayah adalah ["ID Provinsi", "ID Kota", "ID Distrik"]. Dalam respons, nilainya adalah ["Nama Provinsi", "Nama Kota", "Nama Distrik"].
- Komponen radio, pilih dropdown, pilih banyak, dan pilih banyak dropdown mendukung internasionalisasi. Respons mengembalikan nilai data yang sesuai dengan parameter bahasa yang Anda teruskan.
