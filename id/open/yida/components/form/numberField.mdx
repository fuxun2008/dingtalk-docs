## Kapan digunakan

- Pemilih numerik yang memvalidasi dan mengoreksi data input secara otomatis.

## Contoh komponen

## Properti komponen

| Atribut | Deskripsi | Tipe | Default |
|---|---|---|---|
| `behavior` | Status tampilan komponen formulir | [Behavior](/id/open/yida/components/interface#behavior) | `'NORMAL'` |
| `innerAfter` | Teks satuan pada bidang input angka | `string` | - |
| `innerBefore` | Teks awalan komponen formulir | `string` | - |
| `label` | Judul komponen formulir | `string` | - |
| `labelAlign` | Lokasi judul komponen formulir | `'left' \| 'top'` | `'top'` |
| `labelColOffset` | Atur posisi offset judul. Nilai yang dikonfigurasi adalah nilai kisi, di mana 1 mewakili 1/24 | `number` | `0` |
| `labelColSpan` | Atur lebar judul. Nilai yang dikonfigurasi adalah nilai kisi, di mana 1 mewakili 1/24 | `number` | `4` |
| `labelTextAlign` | Metode perataan judul komponen formulir | `'left' \| 'right'` | `'right'` |
| `labelTipsIcon` | Ikon entri Tips judul komponen formulir. Berlaku ketika labelTipsTypes disetel ke **text** atau **render** | `string` | - |
| `labelTipsRender` | Metode rendering kustom untuk Tips judul komponen formulir. Berlaku ketika labelTipsTypes disetel ke **render** | `(props: IComponentProps) => ReactNode` | - |
| `labelTipsText` | Informasi teks Tips judul komponen formulir. Berlaku ketika labelTipsTypes disetel ke **text** | `string` | - |
| `labelTipsTypes` | Pengaturan tipe Tips judul komponen formulir | [LabelTipsTypes](/id/open/yida/components/interface#labeltipstypes) | `'none'` |
| `onChange` | Acara perubahan nilai komponen formulir | `({value: number}) => void` | - |
| `placeholder` | Tips placeholder komponen formulir | `string` | `'Masukkan angka'` |
| `precision` | Jumlah tempat desimal. Nilai yang diizinkan: 0 - 20 | `number` | `0` |
| `size` | Ukuran komponen formulir | [Size](/id/open/yida/components/interface#size) | `'medium'` |
| `thousandsSeparators` | Apakah menggunakan pemisah ribuan | `boolean` | `false` |
| `tips` | Informasi deskripsi komponen formulir, ditampilkan di bawah kontrol | `string` | - |
| `validation` | Pengaturan validasi komponen formulir. Untuk detailnya, lihat [dokumentasi validasi formulir](/id/open/yida/guide/concept/validation) | [Validation[]](/id/open/yida/components/interface#validation) | `[]` |
| `value` | Nilai default komponen formulir | `number` | - |
| `wrapperColOffset` | Atur posisi offset komponen formulir. Nilai yang dikonfigurasi adalah nilai kisi, di mana 1 mewakili 1/24 | `number` | `0` |
| `wrapperColSpan` | Atur lebar komponen formulir. Nilai yang dikonfigurasi adalah nilai kisi, di mana 1 mewakili 1/24 | `number` | `0` |
