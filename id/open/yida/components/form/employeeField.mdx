## Properti Komponen

| Atribut | Deskripsi | Tipe | Default |
|---|---|---|---|
| `beforeSearch` | Sebelum mengirim permintaan pencarian pengguna, proses parameter melalui fungsi ini. Berlaku ketika atribut **dataType** bernilai url | `(params: Record<string, string>) => Record<string, string>` | - |
| `beforeSearchTeam` | Sebelum mengirim permintaan pencarian organisasi, proses parameter melalui fungsi ini. Berlaku ketika atribut **dataType** bernilai url | `(params: Record<string, string>) => Record<string, string>` | - |
| `behavior` | Status tampilan Komponen formulir | [Behavior](/id/open/yida/components/interface#behavior) | `'NORMAL'` |
| `closeOnSelect` | Apakah Tutup setelah pemilihan | `boolean` | `false` |
| `dataSource` | Data Pengguna. Berlaku ketika **dataType** bernilai dataSource | `any[]` | - |
| `dataType` | Tipe data. url: permintaan URL HTTP; dataSource: Sumber Data | `'url' \| 'dataSource'` | `'url'` |
| `emplIdInLabel` | Apakah menampilkan ID Karyawan pada hasil Dipilih | `boolean` | `true` |
| `fetchDataOnMount` | Apakah otomatis meminta URL HTTP setelah halaman dimuat | `boolean` | `true` |
| `fit` | Pemrosesan hasil data async. Berlaku ketika atribut **dataType** bernilai url | `(response: any) => any` | - |
| `hasClear` | Menampilkan tombol hapus | `boolean` | `true` |
| `hasOrderNum` | Menampilkan Jabatan utama dan Jabatan rangkap | `boolean` | - |
| `hiddenSelected` | - | `boolean` | - |
| `label` | Judul Komponen formulir | `string` | - |
| `labelAlign` | Posisi Judul Komponen formulir | `'left' \| 'top'` | `'top'` |
| `labelColOffset` | Mengatur posisi offset Judul. Nilai konfigurasi berupa kisi, 1 mewakili 1/24 | `number` | `0` |
| `labelColSpan` | Mengatur lebar placeholder Judul. Nilai konfigurasi berupa kisi, 1 mewakili 1/24 | `number` | `4` |
| `labelTextAlign` | Metode Ratakan untuk Judul Komponen formulir | `'left' \| 'right'` | `'right'` |
| `labelTipsIcon` | Ikon Entri informasi Tips pada Judul Komponen formulir. Berlaku ketika labelTipsTypes bernilai **text** atau **render** | `string` | - |
| `labelTipsRender` | Metode render Kustom untuk informasi Tips pada Judul Komponen formulir. Berlaku ketika labelTipsTypes bernilai **render** | `(props: IComponentProps) => ReactNode` | - |
| `labelTipsText` | Informasi Teks Tips pada Judul Komponen formulir. Berlaku ketika labelTipsTypes bernilai **text** | `string` | - |
| `labelTipsTypes` | Pengaturan Tipe informasi Tips pada Judul Komponen formulir | [LabelTipsTypes](/id/open/yida/components/interface#labeltipstypes) | `'none'` |
| `multiple` | Aktifkan mode Pilih Banyak | `boolean` | `false` |
| `orderNum` | Bernilai 0 berarti mode pemilihan Pengguna (hanya menampilkan informasi jabatan utama). Bernilai bukan 0 berarti mode pemilihan jabatan (menampilkan beberapa informasi jabatan rangkap) | `string` | - |
| `placeholder` | Tips placeholder kotak pencarian Pengguna | `string` | `'Please Select'` |
| `renderOption` | Bidang render opsi Kustom | `(option: any) => string` | - |
| `renderSelection` | Bidang render Kustom setelah pemilihan | `(option: any) => string` | - |
| `searchDelay` | Penundaan pencarian, dalam satuan ms | `number` | `100` |
| `showAllSub` | Menampilkan semua anggota | `boolean` | - |
| `showAvater` | Apakah menampilkan Foto Profil di popup pemilihan | `boolean` | `true` |
| `showDeptDesc` | Apakah menampilkan deskripsi Departemen | `boolean` | `true` |
| `showEmplId` | Kotak pencarian Pengguna menampilkan ID Karyawan | `boolean` | `false` |
| `showJobDesc` | Apakah menampilkan deskripsi Jabatan | `boolean` | `true` |
| `showSub` | Menampilkan bawahan | `boolean` | `false` |
| `size` | Ukuran Komponen formulir | [Size](/id/open/yida/components/interface#size) | `'medium'` |
| `subUrl` | URL HTTP async bawahan. URL layanan Kustom saat mencari semua anggota dan bawahan. Default menggunakan URL HTTP | `string` | - |
| `tips` | Informasi deskripsi Komponen formulir, ditampilkan di bawah kontrol | `string` | - |
| `url` | URL HTTP async informasi pengguna. Berlaku ketika atribut **dataType** bernilai url | `string` | - |
| `validation` | Pengaturan validasi formulir. Untuk penggunaan spesifik, lihat [Dokumentasi validasi formulir](/id/open/yida/guide/concept/validation) | [Validation[]](/id/open/yida/components/interface#validation) | `[]` |
| `value` | Nilai Default komponen saat ini | `any[]` | - |
| `wrapperColOffset` | Mengatur posisi offset Komponen formulir. Nilai pengaturan berupa kisi, 1 mewakili 1/24 | `number` | `0` |
| `wrapperColSpan` | Mengatur lebar placeholder Komponen formulir. Nilai pengaturan berupa kisi, 1 mewakili 1/24 | `number` | `0` |
