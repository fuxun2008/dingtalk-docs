## Kapan digunakan

- Gunakan untuk skenario yang memerlukan input teks dalam jumlah besar, dengan area input lebih luas dibandingkan input teks standar.

## Contoh komponen

## Properti komponen

| Atribut | Deskripsi | Tipe | Default |
|---|---|---|---|
| `addonAfter` | Konten yang ditambahkan setelah input. | `string` | - |
| `addonBefore` | Konten yang ditambahkan sebelum input multi-baris. | `string` | - |
| `autoFocus` | Apakah mengaktifkan fokus otomatis. | `boolean` | `false` |
| `autoHeight` | Apakah mengaktifkan tinggi otomatis untuk input multi-baris. | `boolean` | `false` |
| `behavior` | Status tampilan komponen formulir. | [Behavior](/id/open/yida/components/interface#behavior) | `'NORMAL'` |
| `cutString` | Apakah memotong string saat melebihi maxLength. | `boolean` | `false` |
| `hasClear` | Apakah menampilkan tombol hapus pada teks multi-baris. | `boolean` | `true` |
| `hasLimitHint` | Apakah menampilkan penghitung karakter untuk teks multi-baris. | `boolean` | `false` |
| `label` | Judul komponen formulir. | `string` | - |
| `labelAlign` | Posisi judul komponen formulir. | `'left' \| 'top'` | `'top'` |
| `labelColOffset` | Posisi offset judul. Nilai berupa nilai kisi, dengan 1 mewakili 1/24. | `number` | `0` |
| `labelColSpan` | Lebar judul. Nilai berupa nilai kisi, dengan 1 mewakili 1/24. | `number` | `4` |
| `labelTextAlign` | Perataan judul komponen formulir. | `'left' \| 'right'` | `'right'` |
| `labelTipsIcon` | Ikon entri untuk tips judul komponen formulir. Berlaku saat labelTipsTypes diatur ke **text** atau **render**. | `string` | - |
| `labelTipsRender` | Metode render kustom untuk tips judul komponen formulir. Berlaku saat labelTipsTypes diatur ke **render**. | `(props: IComponentProps) => ReactNode` | - |
| `labelTipsText` | Teks tips untuk judul komponen formulir. Berlaku saat labelTipsTypes diatur ke **text**. | `string` | - |
| `labelTipsTypes` | Pengaturan tipe tips untuk judul komponen formulir. | [LabelTipsTypes](/id/open/yida/components/interface#labeltipstypes) | `'none'` |
| `maxLength` | Batas jumlah karakter untuk teks multi-baris. | `number` | - |
| `onChange` | Peristiwa yang dipicu saat nilai komponen berubah. | `({ value: string }) => void` | - |
| `placeholder` | Teks placeholder untuk komponen formulir. | `string` | `Silakan masukkan` |
| `rows` | Tinggi teks multi-baris. Hanya berlaku di PC. | `number` | `4` |
| `size` | Ukuran komponen formulir. | [Size](/id/open/yida/components/interface#size) | `'medium'` |
| `state` | Status input. | `'error' \| 'loading' \| 'success' \| ''` | `''` |
| `tips` | Deskripsi komponen formulir, ditampilkan di bawah kontrol. | `string` | - |
| `trim` | Apakah memangkas spasi di awal dan akhir secara otomatis. | `boolean` | `false` |
| `validation` | Pengaturan validasi untuk komponen formulir. Untuk detailnya, lihat [dokumentasi validasi formulir](/id/open/yida/guide/concept/validation). | [Validation[]](/id/open/yida/components/interface#validation) | `[]` |
| `value` | Nilai default komponen saat ini. | `string` | - |
| `wrapperColOffset` | Posisi offset komponen formulir. Nilai berupa nilai kisi, dengan 1 mewakili 1/24. | `number` | `0` |
| `wrapperColSpan` | Lebar komponen formulir. Nilai berupa nilai kisi, dengan 1 mewakili 1/24. | `number` | `0` |
