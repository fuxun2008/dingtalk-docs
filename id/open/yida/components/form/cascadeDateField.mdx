## Kapan digunakan

- Masukkan atau pilih rentang tanggal. Ketika pengguna perlu memasukkan rentang tanggal, klik kotak input standar untuk membuka panel tanggal dan melakukan pemilihan.

## Contoh komponen

## Properti komponen

| Atribut | Deskripsi | Tipe | Default |
|---|---|---|---|
| `behavior` | Status tampilan komponen formulir | [Behavior](/id/open/yida/components/interface#behavior) | `'NORMAL'` |
| `disabledDate` | Pembatasan kustom. Berlaku ketika properti **type** bernilai kustom | `(current: number)=> boolean` | - |
| `format` | Format tampilan komponen rentang tanggal | `'YYYY' \| 'YYYY-MM' \| 'YYYY-MM-DD' \| 'YYYY-MM-DD HH:mm' \| 'YYYY-MM-DD HH:mm'YYY-MM-DD HH:mm:ss` | `'YYY-MM-DD'` |
| `hasClear` | Menampilkan tombol hapus | `boolean` | `true` |
| `label` | Judul komponen formulir | `string` | - |
| `labelAlign` | Lokasi judul komponen formulir | `'left' \| 'top'` | `'top'` |
| `labelColOffset` | Mengatur lokasi offset judul. Nilainya berupa nilai kisi, di mana 1 mewakili 1/24 | `number` | `0` |
| `labelColSpan` | Mengatur lebar yang ditempati oleh judul. Nilainya berupa nilai kisi, di mana 1 mewakili 1/24 | `number` | `4` |
| `labelTextAlign` | Perataan judul komponen formulir | `'left' \| 'right'` | `'right'` |
| `labelTipsIcon` | Ikon entri untuk tips judul komponen formulir. Berlaku ketika labelTipsTypes diatur ke **text** atau **render** | `string` | - |
| `labelTipsRender` | Metode render kustom untuk tips judul komponen formulir. Berlaku ketika labelTipsTypes diatur ke **render** | `(props: IComponentProps) => ReactNode` | - |
| `labelTipsText` | Teks tips untuk judul komponen formulir. Berlaku ketika labelTipsTypes diatur ke **text** | `string` | - |
| `labelTipsTypes` | Pengaturan tipe untuk tips judul komponen formulir | [LabelTipsTypes](/id/open/yida/components/interface#labeltipstypes) | `'none'` |
| `onChange` | Peristiwa yang dipicu ketika nilai komponen berubah | `({value：object}) => void` | - |
| `onOk` | Peristiwa yang dipicu ketika Konfirmasi diklik | `(value: object) => void` | - |
| `onVisibleChange` | Peristiwa yang dipicu ketika panel pop-up ditampilkan atau disembunyikan | `(visible：boolean) => void` | - |
| `placeholder` | Teks placeholder komponen formulir | `string` | `'Please select'` |
| `ranges` | Pemilihan rentang cepat | `()=> number[]` | - |
| `resetTime` | Apakah waktu diatur ulang setiap kali tanggal dipilih | `boolean` | `false` |
| `returnType` | Tipe kembalian rentang tanggal | `'timestamp' \| 'string' \| 'moment'` | `'timestamp'` |
| `size` | Ukuran komponen formulir | [Size](/id/open/yida/components/interface#size) | `'medium'` |
| `tips` | Deskripsi komponen formulir, ditampilkan di bawah kontrol | `string` | - |
| `validation` | Pengaturan validasi formulir. Untuk detail, lihat [dokumentasi validasi formulir](/id/open/yida/guide/concept/validation) | [Validation[]](/id/open/yida/components/interface#validation) | `[]` |
| `value` | Nilai default komponen formulir | `number[]` | - |
| `wrapperColOffset` | Mengatur lokasi offset komponen formulir. Nilainya berupa nilai kisi, di mana 1 mewakili 1/24 | `number` | `0` |
| `wrapperColSpan` | Mengatur lebar yang ditempati oleh komponen formulir. Nilainya berupa nilai kisi, di mana 1 mewakili 1/24 | `number` | `0` |
