## Kapan digunakan

- Untuk memasukkan atau memilih waktu tertentu. Ketika pengguna perlu memasukkan tanggal, klik kotak input standar untuk membuka panel tanggal, lalu lakukan pemilihan.

## Contoh komponen

## Properti komponen

| Atribut | Deskripsi | Tipe | Default |
|---|---|---|---|
| `behavior` | Status tampilan komponen formulir | [Behavior](/id/open/yida/components/interface#behavior) | `'NORMAL'` |
| `disabledDate` | Pembatasan kustom, berlaku ketika properti **type** bernilai `custom` | `(current: number)=> boolean` | - |
| `end` | Waktu akhir tanggal, berlaku ketika properti **type** bernilai `duration` | `number` | - |
| `format` | Format tanggal | `'YYYY' \| 'YYYY-MM' \| 'YYYY-MM-DD'\| 'YYYY-MM-DD HH:mm'\| 'YYYY-MM-DD HH:mm:ss'` | `'YYYY-MM-DD'` |
| `hasClear` | Apakah menampilkan tombol bersihkan | `boolean` | `true` |
| `label` | Judul komponen formulir | `string` | - |
| `labelAlign` | Lokasi judul komponen formulir | `'left' \| 'top'` | `'top'` |
| `labelColOffset` | Mengatur posisi offset judul. Nilainya berupa nilai kisi, dengan 1 mewakili 1/24. | `number` | `0` |
| `labelColSpan` | Mengatur lebar judul. Nilainya berupa nilai kisi, dengan 1 mewakili 1/24. | `number` | `4` |
| `labelTextAlign` | Perataan judul komponen formulir | `'left' \| 'right'` | `'right'` |
| `labelTipsIcon` | Ikon entri untuk tips judul komponen formulir. Berlaku ketika `labelTipsTypes` diatur ke **text** atau **render**. | `string` | - |
| `labelTipsRender` | Metode render kustom untuk tips judul komponen formulir. Berlaku ketika `labelTipsTypes` diatur ke **render**. | `(props: IComponentProps) => ReactNode` | - |
| `labelTipsText` | Teks tips untuk judul komponen formulir. Berlaku ketika `labelTipsTypes` diatur ke **text**. | `string` | - |
| `labelTipsTypes` | Pengaturan tipe untuk tips judul komponen formulir | [LabelTipsTypes](/id/open/yida/components/interface#labeltipstypes) | `'none'` |
| `onChange` | Peristiwa yang dipicu ketika nilai komponen berubah | `({value: number})=> void` | - |
| `onOk` | Peristiwa yang dipicu ketika Konfirmasi diklik | `({value: number})=> void` | - |
| `onVisibleChange` | Peristiwa yang dipicu ketika lapisan pop-up ditampilkan atau disembunyikan | `(visible: boolean) => void` | - |
| `placeholder` | Tips placeholder | `string` | `'Silakan pilih'` |
| `resetTime` | Apakah mengatur ulang waktu setiap kali tanggal dipilih | `boolean` | `false` |
| `returnType` | Tipe pengembalian tanggal | `'timestamp' \| 'string' \| 'moment'` | `'timestamp'` |
| `size` | Ukuran komponen formulir | [Size](/id/open/yida/components/interface#size) | `'medium'` |
| `start` | Waktu mulai tanggal. Berlaku ketika properti **type** bernilai `duration`. | `number` | - |
| `tips` | Deskripsi komponen formulir, ditampilkan di bawah kontrol | `string` | - |
| `type` | Rentang pembatasan waktu | `'none' \| 'beforeToday' \| 'afterToday'\| 'duration'\| 'custom'` | `'none'` |
| `validation` | Pengaturan validasi untuk komponen formulir. Untuk detailnya, lihat [dokumentasi validasi formulir](/id/open/yida/guide/concept/validation). | [Validation[]](/id/open/yida/components/interface#validation) | `[]` |
| `value` | Nilai default pemilih tanggal | `number` | - |
| `wrapperColOffset` | Mengatur posisi offset komponen formulir. Nilainya berupa nilai kisi, dengan 1 mewakili 1/24. | `number` | `0` |
| `wrapperColSpan` | Mengatur lebar komponen formulir. Nilainya berupa nilai kisi, dengan 1 mewakili 1/24. | `number` | `0` |
