## Kapan digunakan

- Gunakan sebagai pengganti select native untuk memilih satu opsi dari kumpulan terbatas. Kemampuan intinya adalah pemilihan.

## Contoh komponen

## Atribut komponen

| Atribut | Deskripsi | Tipe | Default |
|---|---|---|---|
| `autoWidth` | Apakah menu dropdown menyelaraskan lebar dengan selector. | `boolean` | `true` |
| `behavior` | Status tampilan komponen formulir. | [Behavior](/id/open/yida/components/interface#behavior) | `'NORMAL'` |
| `dataSource` | Konfigurasikan opsi. | [DataSource[]](/id/open/yida/components/interface#datasource) | `[ { "text": "Opsi 1", "value": "1" }, { "text": "Opsi 2", "value": "2" }, { "text": "Opsi 3", "value": "3" } ]` |
| `filter` | Metode filter lokal. Hanya berlaku jika filter lokal diaktifkan. | `(value: string, data: DataSource) => boolean` | - |
| `filterLocal` | Apakah filter lokal didukung. Nonaktifkan jika sumber data berasal dari remote. | `boolean` | - |
| `hasArrow` | Apakah menampilkan panah dropdown. | `boolean` | `true` |
| `hasBorder` | Apakah menampilkan border. | `boolean` | `true` |
| `hasClear` | Apakah menampilkan tombol bersihkan. | `boolean` | `true` |
| `label` | Judul komponen formulir. | `string` | - |
| `labelAlign` | Posisi judul komponen formulir. | `'left' \| 'top'` | `'top'` |
| `labelColOffset` | Posisi offset judul. Nilai menggunakan satuan kisi, dengan 1 mewakili 1/24. | `number` | `0` |
| `labelColSpan` | Lebar area judul. Nilai menggunakan satuan kisi, dengan 1 mewakili 1/24. | `number` | `4` |
| `labelTextAlign` | Perataan teks judul komponen formulir. | `'left' \| 'right'` | `'right'` |
| `labelTipsIcon` | Ikon entri Tips judul. Berlaku jika labelTipsTypes diatur ke **text** atau **render**. | `string` | - |
| `labelTipsRender` | Metode render kustom untuk Tips judul. Berlaku jika labelTipsTypes diatur ke **render**. | `(props: IComponentProps) => ReactNode` | - |
| `labelTipsText` | Konten teks Tips judul. Berlaku jika labelTipsTypes diatur ke **text**. | `string` | - |
| `labelTipsTypes` | Tipe Tips judul. | [LabelTipsTypes](/id/open/yida/components/interface#labeltipstypes) | `'none'` |
| `notFoundContent` | Teks yang ditampilkan saat tidak ada opsi yang cocok. | `string` | `'Silakan masukkan'` |
| `onChange` | Peristiwa yang dipicu saat nilai komponen berubah. | `(value: string) => void` | - |
| `onRemove` | Peristiwa yang dipicu saat sebuah nilai dihapus. | `(item: object) => void` | - |
| `onSearch` | Peristiwa yang dipicu saat nilai kotak pencarian berubah. | `(keyword: string) => void` | - |
| `onVisibleChange` | Peristiwa yang dipicu saat dropdown ditampilkan atau disembunyikan. | `(visible: boolean) => void` | - |
| `placeholder` | Teks placeholder komponen formulir. | `string` | `'Silakan pilih'` |
| `searchDelay` | Jeda pencarian dalam milidetik. | `number` | `300` |
| `showSearch` | Apakah pencarian diaktifkan setelah dropdown dibuka. Selalu true dalam mode tag. | `boolean` | `true` |
| `size` | Ukuran komponen formulir. | [Size](/id/open/yida/components/interface#size) | `'medium'` |
| `tips` | Teks deskripsi komponen formulir, ditampilkan di bawah kontrol. | `string` | - |
| `useDetailValue` | Apakah menggunakan tipe object \{label, value} sebagai nilai. | `boolean` | `false` |
| `validation` | Pengaturan validasi formulir. Untuk detail, lihat [dokumentasi validasi formulir](/id/open/yida/guide/concept/validation). | [Validation[]](/id/open/yida/components/interface#validation) | `[]` |
| `value` | Nilai default komponen saat ini. | `string` | - |
| `wrapperColOffset` | Posisi offset komponen formulir. Nilai menggunakan satuan kisi, dengan 1 mewakili 1/24. | `number` | `0` |
| `wrapperColSpan` | Lebar area komponen formulir. Nilai menggunakan satuan kisi, dengan 1 mewakili 1/24. | `number` | `0` |
