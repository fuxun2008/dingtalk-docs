## Kapan digunakan

- Gunakan komponen ini untuk menggantikan elemen select bawaan saat memilih dari sekumpulan opsi yang telah ditentukan. Kemampuan intinya adalah pemilihan.

## Contoh komponen

## Properti komponen

| Atribut | Deskripsi | Tipe | Default |
|---|---|---|---|
| `autoWidth` | Apakah menu dropdown menyesuaikan lebar selektor | `boolean` | `true` |
| `behavior` | Status tampilan komponen formulir | [Behavior](/id/open/yida/components/interface#behavior) | `'NORMAL'` |
| `dataSource` | Konfigurasikan opsi | [DataSource[]](/id/open/yida/components/interface#datasource) | `[ { "text": "Opsi 1", "value": "1" }, { "text": "Opsi 2", "value": "2" }, { "text": "Opsi 3", "value": "3" } ]` |
| `filter` | Metode filter lokal; hanya tersedia bila pemfilteran lokal diaktifkan | `(value: string[], data: DataSource) => boolean` | - |
| `filterLocal` | Nonaktifkan opsi ini bila sumber data bersifat remote. Mengembalikan nilai Boolean yang menentukan apakah opsi dipertahankan | `boolean` | `true` |
| `hasArrow` | Apakah menampilkan tanda panah dropdown | `boolean` | `true` |
| `hasBorder` | Apakah menampilkan border | `boolean` | `true` |
| `hasSelectAll` | Apakah mengaktifkan fitur Pilih semua | `boolean` | `false` |
| `label` | Judul komponen formulir | `string` | - |
| `labelAlign` | Posisi judul komponen formulir | `'left' \| 'top'` | `'top'` |
| `labelColOffset` | Atur posisi offset judul. Nilainya menggunakan sistem kisi, dengan 1 mewakili 1/24 | `number` | `0` |
| `labelColSpan` | Atur lebar judul. Nilainya menggunakan sistem kisi, dengan 1 mewakili 1/24 | `number` | `4` |
| `labelTextAlign` | Perataan judul komponen formulir | `'left' \| 'right'` | `'right'` |
| `labelTipsIcon` | Ikon untuk entri tips pada judul komponen formulir. Berlaku bila `labelTipsTypes` disetel ke **text** atau **render** | `string` | - |
| `labelTipsRender` | Metode render kustom untuk tips pada judul komponen formulir. Berlaku bila `labelTipsTypes` disetel ke **render** | `(props: IComponentProps) => ReactNode` | - |
| `labelTipsText` | Teks tips untuk judul komponen formulir. Berlaku bila `labelTipsTypes` disetel ke **text** | `string` | - |
| `labelTipsTypes` | Tipe tips yang ditampilkan untuk judul komponen formulir | [LabelTipsTypes](/id/open/yida/components/interface#labeltipstypes) | `'none'` |
| `notFoundContent` | Teks yang ditampilkan bila tidak ada hasil yang ditemukan | `string` | - |
| `onChange` | Peristiwa yang dipicu ketika nilai komponen berubah. `actionType` menunjukkan jenis pemicu. Nilai yang tersedia: `'itemClick'`, `'enter'`, `'change'` | `({value: string, actionType:string, item:Data}) => void` | - |
| `onRemove` | Peristiwa yang dipicu ketika sebuah nilai dihapus | `(item: DataSource) => void` | - |
| `onSearch` | Peristiwa yang dipicu ketika nilai pada kotak pencarian berubah | `(keyword: string) => void` | - |
| `onVisibleChange` | Peristiwa yang dipicu ketika lapisan pop-up ditampilkan atau disembunyikan | `(visible: boolean) => void` | - |
| `onVisibleChange` | Peristiwa yang dipicu ketika lapisan pop-up ditampilkan atau disembunyikan | `(visible: boolean) => void` | - |
| `placeholder` | Teks placeholder komponen formulir | `string` | `'Silakan pilih'` |
| `searchDelay` | Jeda pencarian, dalam milidetik | `number` | `300` |
| `showSearch` | Apakah pencarian diaktifkan setelah diperluas. Ditetapkan `true` pada mode tag | `boolean` | `true` |
| `showSearch` | Apakah pencarian diaktifkan setelah diperluas. Ditetapkan `true` pada mode tag | `boolean` | `true` |
| `size` | Ukuran komponen formulir | [Size](/id/open/yida/components/interface#size) | `'medium'` |
| `tips` | Deskripsi komponen formulir, ditampilkan di bawah kontrol | `string` | - |
| `useDetailValue` | Atur nilai untuk menggunakan tipe object \{label, value} | `boolean` | `false` |
| `validation` | Pengaturan validasi komponen formulir. Untuk detailnya, lihat [dokumentasi Validasi Formulir](/id/open/yida/guide/concept/validation) | [Validation[]](/id/open/yida/components/interface#validation) | `[]` |
| `value` | Nilai default komponen saat ini | `string[]` | - |
| `wrapperColOffset` | Atur posisi offset komponen formulir. Nilainya menggunakan sistem kisi, dengan 1 mewakili 1/24 | `number` | `0` |
| `wrapperColSpan` | Atur lebar komponen formulir. Nilainya menggunakan sistem kisi, dengan 1 mewakili 1/24 | `number` | `0` |
