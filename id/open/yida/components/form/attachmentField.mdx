## Kapan digunakan

- Gunakan komponen ini untuk skenario unggah dan pengiriman File.

## Contoh komponen

## Properti komponen

| Atribut | Deskripsi | Tipe | Default |
|---|---|---|---|
| `accept` | Menetapkan tipe File yang diizinkan untuk diunggah (pisahkan beberapa nilai dengan koma), misalnya .doc, .docx, .pdf. | `string` | - |
| `autoUpload` | Apakah File diunggah secara otomatis. Jika dinonaktifkan, panggil this.$('fieldId').startUpload() secara manual untuk memulai unggahan. | `boolean` | `true` |
| `beforeUpload` | Peristiwa pemrosesan sebelum Unggah. | `(file: object, options: object) => void` | - |
| `behavior` | Status tampilan komponen formulir. | [Behavior](/id/open/yida/components/interface#behavior) | `'NORMAL'` |
| `buttonSize` | Menetapkan ukuran tombol. | `'small' \| 'medium' \| 'large'` | `'medium'` |
| `buttonText` | Menetapkan Konten tombol. | `string` | `'Unggah File'` |
| `buttonType` | Menetapkan Tipe tombol. | `'primary' \| 'secondary' \| 'normal'` | `'primary'` |
| `customUploadPane` | Panel kustom. | `() => ReactNode` | - |
| `data` | Menetapkan parameter tambahan yang disertakan pada unggahan. | `Record<string, string>` | `{}` |
| `formatter` | Peristiwa pemrosesan data. | `(response: any) => any` | - |
| `headers` | Menetapkan header permintaan untuk unggahan. | `Record<string, string>` | `{}` |
| `label` | Judul komponen formulir. | `string` | - |
| `labelAlign` | Posisi Judul komponen formulir. | `'left' \| 'top'` | `'top'` |
| `labelColOffset` | Menetapkan posisi offset Judul. Nilai dalam satuan grid, dengan 1 mewakili 1/24. | `number` | `0` |
| `labelColSpan` | Menetapkan lebar placeholder Judul. Nilai dalam satuan grid, dengan 1 mewakili 1/24. | `number` | `4` |
| `labelTextAlign` | Perataan Judul komponen formulir. | `'left' \| 'right'` | `'right'` |
| `labelTipsIcon` | Ikon untuk entri Tips Judul komponen formulir. Berlaku ketika labelTipsTypes disetel ke **text** atau **render**. | `string` | - |
| `labelTipsRender` | Metode render kustom untuk Tips Judul komponen formulir. Berlaku ketika labelTipsTypes disetel ke **render**. | `(props: IComponentProps) => ReactNode` | - |
| `labelTipsText` | Konten teks Tips Judul komponen formulir. Berlaku ketika labelTipsTypes disetel ke **text**. | `string` | - |
| `labelTipsTypes` | Pengaturan Tipe untuk Tips Judul komponen formulir. | [LabelTipsTypes](/id/open/yida/components/interface#labeltipstypes) | `'none'` |
| `limit` | Menetapkan jumlah maksimum File yang dapat diunggah. | `number` | `9` |
| `maxFileSize` | Menetapkan ukuran maksimum per File (dalam MB). | `number` | `50` |
| `multiple` | Apakah unggah banyak File didukung. | `boolean` | `true` |
| `name` | Nama yang dikirim ke Sisi server saat Unggah. | `string` | - |
| `onCancel` | Peristiwa yang dipicu saat pengguna membatalkan unggahan. | `() => void` | - |
| `onChange` | Peristiwa yang dipicu saat nilai komponen berubah. | `({ value: object }) => void` | - |
| `onDragLeave` | Peristiwa yang dipicu saat tindakan drag meninggalkan komponen. | `() => void` | - |
| `onDragOver` | Peristiwa yang dipicu saat tindakan drag melewati komponen. | `() => void` | - |
| `onDrop` | Peristiwa yang dipicu saat tindakan drag diselesaikan pada komponen. | `() => void` | - |
| `onError` | Peristiwa yang dipicu saat unggah komponen gagal. | `(file: object, value: array) => void` | - |
| `onProgress` | Peristiwa yang dipicu selama komponen mengunggah. | `() => void` | - |
| `onRemove` | Peristiwa yang dipicu saat pengguna menghapus File yang telah diunggah. | `(file: object) => void` | - |
| `onSelect` | Peristiwa yang dipicu saat sebuah File dipilih. | `(file: object) => void` | - |
| `onSuccess` | Peristiwa yang dipicu saat unggah komponen berhasil. | `(file: object, value: array) => void` | - |
| `size` | Ukuran komponen formulir. | [Size](/id/open/yida/components/interface#size) | `'medium'` |
| `timeout` | Menetapkan batas waktu Unggah dalam milidetik. | `number` | `0` |
| `tips` | Deskripsi komponen formulir. Ditampilkan di bawah kontrol. | `string` | - |
| `type` | Menetapkan Tipe Unggah. Hanya berlaku di PC. | `'normal' \| 'drag'` | `'normal'` |
| `validation` | Pengaturan validasi komponen formulir. Untuk detail, lihat [dokumentasi validasi formulir](/id/open/yida/guide/concept/validation). | [Validation[]](/id/open/yida/components/interface#validation) | `[]` |
| `value` | Nilai Default. | `array` | - |
| `withCredentials` | Apakah permintaan diizinkan membawa cookie. | `boolean` | `false` |
| `wrapperColOffset` | Menetapkan posisi offset komponen formulir. Nilai dalam satuan grid, dengan 1 mewakili 1/24. | `number` | `0` |
| `wrapperColSpan` | Menetapkan lebar placeholder komponen formulir. Nilai dalam satuan grid, dengan 1 mewakili 1/24. | `number` | `0` |
