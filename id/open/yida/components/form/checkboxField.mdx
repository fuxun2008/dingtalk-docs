## Kapan menggunakan

- Ketika Anda perlu memilih banyak item dari sekelompok opsi.
- Ketika digunakan sendiri, komponen ini dapat mewakili toggle antara dua status, mirip switch. Perbedaannya, toggle switch memicu perubahan status secara langsung, sedangkan kotak centang umumnya digunakan untuk menandai status dan bekerja bersama tindakan kirim.

## Properti komponen

| Atribut | Deskripsi | Tipe | Default |
|---|---|---|---|
| `behavior` | Status tampilan komponen formulir | [Behavior](/id/open/yida/components/interface#behavior) | `'NORMAL'` |
| `dataSource` | Konfigurasikan opsi | [DataSource[]](/id/open/yida/components/interface#datasource) | `[ { "text": "Option 1", "value": "1" }, { "text": "Option 2", "value": "2" }, { "text": "Option 3", "value": "3" } ]` |
| `iconPosition` | Posisi ikon pada perangkat mobile | `'left' \| 'right'` | `'left'` |
| `itemDirection` | Arah tata letak opsi pada PC | `'hoz' \| 'ver'` | `'hoz'` |
| `label` | Judul komponen formulir | `string` | - |
| `labelAlign` | Posisi Judul komponen formulir | `'left' \| 'top'` | `'top'` |
| `labelColOffset` | Atur posisi offset Judul. Nilai mengikuti sistem kisi, dengan 1 mewakili 1/24. | `number` | `0` |
| `labelColSpan` | Atur lebar Judul. Nilai mengikuti sistem kisi, dengan 1 mewakili 1/24. | `number` | `4` |
| `labelTextAlign` | Perataan Teks Judul komponen formulir | `'left' \| 'right'` | `'right'` |
| `labelTipsIcon` | Ikon untuk entri tooltip Judul komponen formulir. Berlaku ketika labelTipsTypes bernilai **text** atau **render**. | `string` | - |
| `labelTipsRender` | Metode render kustom untuk tooltip Judul komponen formulir. Berlaku ketika labelTipsTypes bernilai **render**. | `(props: IComponentProps) => ReactNode` | - |
| `labelTipsText` | Teks tooltip untuk Judul komponen formulir. Berlaku ketika labelTipsTypes bernilai **text**. | `string` | - |
| `labelTipsTypes` | Tipe tooltip untuk Judul komponen formulir | [LabelTipsTypes](/id/open/yida/components/interface#labeltipstypes) | `'none'` |
| `onChange` | Acara yang dipicu ketika nilai komponen berubah | `(value: string[]) => void` | - |
| `size` | Ukuran komponen formulir | [Size](/id/open/yida/components/interface#size) | `'medium'` |
| `tips` | Deskripsi komponen formulir, ditampilkan di bawah kontrol | `string` | - |
| `useDrawerInMobile` | Gaya tata letak pada perangkat mobile. Jika true, opsi ditampilkan inline; jika false, menggunakan drawer bawah. | `boolean` | `false` |
| `validation` | Pengaturan validasi formulir untuk komponen. Untuk detail, lihat [dokumentasi validasi formulir](/id/open/yida/guide/concept/validation). | [Validation[]](/id/open/yida/components/interface#validation) | `[]` |
| `value` | Nilai Default komponen saat ini | `string[]` | - |
| `wrapperColOffset` | Atur posisi offset komponen formulir. Nilai mengikuti sistem kisi, dengan 1 mewakili 1/24. | `number` | `0` |
| `wrapperColSpan` | Atur lebar komponen formulir. Nilai mengikuti sistem kisi, dengan 1 mewakili 1/24. | `number` | `0` |
