Hyperlink yang digunakan untuk berpindah ke halaman baru.

## Kapan digunakan

- Berpindah ke halaman lain dalam aplikasi saat ini.
- Berpindah ke halaman eksternal.

## Contoh komponen

## Properti komponen

| Atribut | Deskripsi | Tipe | Default |
|---|---|---|---|
| `content` | Menetapkan konten teks tautan. | `string` | `'Ini adalah tautan'` |
| `isBlank` | Apakah tautan dibuka di halaman baru. | `boolean` | `false` |
| `page` | UUID halaman internal. Berlaku saat atribut **type** diatur ke `page`. | `string` | - |
| `params` | Parameter kueri URL, biasanya digunakan untuk meneruskan parameter saat berpindah halaman. | `Record<string, string>` | - |
| `textOverflow` | Memotong teks menjadi satu baris. Saat diaktifkan, teks yang melebihi satu baris ditampilkan dengan elipsis, dan atribut `title` pada tag HTML ditetapkan sesuai. | `boolean` | `false` |
| `type` | Tipe tautan. `page`: halaman internal; `url`: tautan eksternal. | `'page' \| 'url'` | `'page'` |
| `url` | Alamat tautan. Klik tautan untuk berpindah ke halaman yang sesuai. Berlaku saat atribut **type** diatur ke `url`. | `string` | - |
