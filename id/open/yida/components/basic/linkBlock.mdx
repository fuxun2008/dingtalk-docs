Kontainer tautan level blok yang berfungsi sama seperti komponen Link, tetapi dapat menyematkan konten lain seperti gambar.

## Kapan digunakan

- Navigasi ke halaman lain di dalam aplikasi saat ini.
- Alihkan ke halaman eksternal.

## Contoh komponen

## Properti komponen

| Atribut | Deskripsi | Tipe | Default |
|---|---|---|---|
| `disabled` | Menentukan apakah blok tautan dinonaktifkan. Saat dinonaktifkan, mengeklik blok tidak akan memicu navigasi. | `boolean` | `false` |
| `isBlank` | Menentukan apakah target dibuka di halaman baru. | `boolean` | `false` |
| `page` | UUID halaman internal. Berlaku ketika atribut **type** diatur ke `page`. | `string` | - |
| `params` | Parameter query URL, umumnya digunakan untuk meneruskan parameter saat navigasi halaman. | `Record<string, string>` | - |
| `type` | Tipe tautan. `page`: halaman internal; `url`: tautan eksternal. | `'page' \| 'url'` | `'page'` |
| `url` | Alamat tautan. Mengeklik tautan akan mengalihkan ke halaman yang sesuai. Berlaku ketika atribut **type** diatur ke `url`. | `string` | - |
