Menampilkan teks.

## Kapan digunakan

- Menampilkan informasi deskriptif melalui teks.

## Contoh komponen

## Properti komponen

| Atribut | Deskripsi | Tipe | Default |
|---|---|---|---|
| `behavior` | Status default | `'NORMAL' \| 'HIDDEN'` | `'NORMAL'` |
| `content` | Konten teks | `string` | `'Teks'` |
| `contentPaddingMobile` | Padding kiri dan kanan pada perangkat mobile, dalam px | `'0 \| 16'` | `'0'` |
| `maxLine` | Jumlah baris maksimum; otomatis dipotong dengan elipsis jika melebihi batas | `number` | `0` |
| `showTitle` | Menampilkan Konten sebagai atribut title dari tag HTML atau tidak | `boolean` | `false` |
