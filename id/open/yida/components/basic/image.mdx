Digunakan untuk menampilkan sumber daya gambar.

## Kapan digunakan

- Menampilkan satu gambar pada halaman.

## Contoh komponen

## Properti komponen

| Atribut | Deskripsi | Tipe | Default |
|---|---|---|---|
| `alt` | Teks placeholder yang ditampilkan saat gambar gagal dimuat. | `string` | `'Image 404'` |
| `autuHeight` | Tinggi adaptif. | `boolean` | `false` |
| `autuWidth` | Lebar adaptif. | `boolean` | `false` |
| `fit` | Mode tampilan gambar. `cover`: memotong agar pas dengan kontainer; `contain`: mempertahankan rasio aspek dengan padding; `fill`: meregangkan agar pas dengan kontainer. | `'cover' \| 'contain' \| 'fill'` | `'cover'` |
| `height` | Tinggi gambar. | `number` | `200` |
| `preview` | Mengaktifkan atau menonaktifkan pratinjau gambar. | `boolean` | `false` |
| `round` | Radius sudut gambar, dalam px. | `'16' \| '8' \| '4' \| '0' \| 'Custom'` | `'0'` |
| `roundRadius` | Radius sudut kustom. Hanya berlaku saat atribut **round** disetel ke `'Custom'`. | `number` | `0` |
| `src` | URL gambar. | `string` | - |
| `title` | Judul gambar. Menyetel atribut `title` HTML native, yang muncul saat kursor mouse diarahkan ke gambar. | `string` | - |
| `width` | Lebar gambar. | `number` | `350` |
