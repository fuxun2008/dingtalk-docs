## Kapan digunakan

- Kontrol video untuk memutar sumber video HTML-native seperti mp4 dan mov.

## Contoh komponen

## Properti komponen

| Atribut | Deskripsi | Tipe | Default |
|---|---|---|---|
| `autoplay` | Putar otomatis. Mungkin tidak berfungsi pada skenario tertentu. | `boolean` | `false` |
| `canPlayThrough` | Terpicu saat video selesai dimuat dan siap diputar. | `(ctx: object) => void` | - |
| `controls` | Batang kontrol. | `boolean` | `true` |
| `controlsList` | Menyesuaikan batang kontrol native. | `'nodownload' \| 'nofullscreen' \| 'noremoteplayback' \| 'disablePictureInPicture'` | - |
| `loop` | Pemutaran berulang. Menentukan apakah video otomatis diulang setelah selesai. | `boolean` | `false` |
| `muted` | Menentukan apakah video dibisukan. | `boolean` | `false` |
| `onEnded` | Terpicu saat video berakhir. | `(ctx: object) => void` | - |
| `onEnterFullscreen` | Terpicu saat masuk ke mode layar penuh. | `(ctx: object) => void` | - |
| `onError` | Terpicu saat terjadi kesalahan pemutaran. | `(ctx: object) => void` | - |
| `onExitFullscreen` | Terpicu saat keluar dari mode layar penuh. | `(ctx: object) => void` | - |
| `onPause` | Terpicu saat video dijeda. | `(ctx: object) => void` | - |
| `onPlay` | Terpicu saat pemutaran dimulai. | `(ctx: object) => void` | - |
| `pipControls` | Picture-in-picture. Hanya berfungsi di Chrome dan Safari; tidak didukung di Firefox maupun perangkat seluler. | `boolean` | `false` |
| `playbackRate` | Daftar kecepatan pemutaran. | `array` | `[ 0.8, 1, 1.5, 2 ]` |
| `playbackRateControls` | Menentukan apakah kontrol kecepatan pemutaran ditampilkan. | `boolean` | `false` |
| `poster` | URL gambar poster. | `string` | - |
| `sizeFit` | Mode paskan tampilan. | `'contain' \| 'fill' \| 'cover' \| 'scale-dowm' \| 'none'` | `'contain'` |
| `timeUpdate` | Terpicu saat waktu pemutaran diperbarui. | `(ctx: object) => void` | - |
| `title` | Judul native. Menetapkan atribut title native HTML yang ditampilkan saat kursor diarahkan ke video. | `string` | - |
| `url` | URL video. | `string` | `'https://cloud.video.taobao.com/play/u/1804320196/p/1/e/6/t/1/287344840104.mp4'` |
| `volume` | Tingkat volume. Minimum 0, maksimum 1. | `number` | `1` |
| `volumeControls` | Menentukan apakah kontrol volume ditampilkan. | `boolean` | `true` |
