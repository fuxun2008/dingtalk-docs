## Properti komponen

| Atribut | Deskripsi | Tipe | Default |
|---|---|---|---|
| `config` | Konfigurasi item filter | [FilterConfig[]](/id/open/yida/components/interface#filterconfig) | `[]` |
| `createForm` | Node Buat | `boolean` | `true` |
| `labelAlign` | Lokasi Judul | `'left' \| 'top'` | `'top'` |
| `labelColSpan` | Lebar judul, dengan 1 mewakili 1/24 | `number` | `4` |
| `rowColumn` | Kolom per Rekam | `number` | `3` |
| `showTag` | Mode isolasi Tag. Komponen yang dapat dipilih otomatis ditampilkan di area terpisah | `boolean` | `true` |
| `size` | Ukuran komponen formulir | [Size](/id/open/yida/components/interface#size) | `'medium'` |
