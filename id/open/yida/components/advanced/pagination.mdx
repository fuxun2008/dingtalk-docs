## Kapan digunakan

- Gunakan saat konten dalam jumlah besar perlu dimuat per halaman.

## Contoh komponen

## Properti komponen

| Atribut | Deskripsi | Tipe | Default |
|---|---|---|---|
| `current` | Nomor halaman saat ini | `number` | `1` |
| `hideOnlyOnePage` | Menyembunyikan paginator saat hanya ada satu halaman | `boolean` | `false` |
| `onChange` | Terpicu saat nomor halaman berubah | `(currentPagination: number) => void` | - |
| `onPageSizeChange` | Terpicu saat ukuran halaman berubah | `(pageSize: number) => void` | - |
| `pageSize` | Jumlah item yang ditampilkan per halaman | `number` | `10` |
| `pageSizeList` | Nilai yang tersedia pada selektor ukuran halaman | `string` | `'5,10,20'` |
| `pageSizePosition` | Posisi selektor ukuran halaman di dalam komponen | `'start' \| 'end'` | `'end'` |
| `pageSizeSelector` | Tipe selektor ukuran halaman | `false \| 'filter' \| 'dropdown'` | `false` |
| `shape` | Gaya tombol sebelumnya/berikutnya | `'normal' \| 'arrow-only' \| 'arrow-prev-only' \| 'no-border'` | `'normal'` |
| `showJump` | Menampilkan input lompat halaman dan Button. Hanya berlaku saat **type** bernilai normal dan jumlah halaman lebih dari 5. | `boolean` | `true` |
| `size` | Ukuran paginasi | `'small' \| 'medium' \| 'large'` | `'medium'` |
| `total` | Jumlah total data | `number` | - |
| `type` | Tipe paginasi | `'normal' \| 'simple' \| 'mini'` | `'normal'` |
