Menampilkan data baris dan kolom.

## Kapan digunakan

- Tabel merender data dalam bentuk tabel HTML yang sangat fleksibel untuk dikustomisasi dan mudah diakses. Fungsi intinya adalah menyajikan data terstruktur dalam format tabel.
- Manfaatkan berbagai parameter untuk menambahkan fitur seperti pengurutan, penyaringan, pengguliran, dan penguncian Kolom.
