Komponen bottom banner memungkinkan Anda menambahkan konten di bagian bawah halaman. Konten tetap berada di bagian bawah dan melebar penuh.

## Kapan digunakan

- Ketika Anda perlu menambahkan konten di bagian bawah halaman, misalnya informasi hak cipta.

## Contoh komponen

## Properti komponen

| Properti | Deskripsi | Tipe | Default |
|---|---|---|---|
| `autoWidth` | Mengaktifkan lebar adaptif atau tidak | `boolean` | `false` |
| `containerWidth` | Atur lebar container dalam px atau %, misalnya 100px, 50% | `string` | - |
| `contentWidth` | Atur lebar konten dalam px atau %, misalnya 100px, 50% | `string` | - |
| `extra` | Konten kustom | `ReactNode` | - |
| `getRefContainer` | Atur container mount kustom | `() => React.HTMLElement` | - |
| `layout` | Atur mode tata letak: h untuk horizontal, v untuk vertikal | `'h' \| 'v'` | `'h'` |
