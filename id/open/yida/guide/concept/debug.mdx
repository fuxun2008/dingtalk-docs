Debug sangat penting selama pengembangan halaman kustom. Platform YiDA menyediakan beberapa metode debug berikut untuk pengembangan halaman kustom:

## Buka panel debug swalayan
Developer dapat menambahkan parameter `__showDevtools` pada URL halaman untuk mengaktifkan panel debug ([perakitan tautan swalayan](https://demo.aliwork.com/o/debug_by_self?__showDevtools=true)), contoh: [https://www.aliwork.com/bench/feedback?__showDevtools](https://www.aliwork.com/bench/feedback?__showDevtools).

Melalui panel debug, developer dapat melakukan tindakan berikut:
* Melihat variabel Sumber Data
* Melihat data formulir
* Melihat permintaan yang Gagal
* Melaporkan log Error

Yang terpenting, panel debug membuat proses debug pada perangkat mobile menjadi jauh lebih praktis.

## Aktifkan Schema workbench (Impor/Ekspor skema)
Di pojok kiri bawah desainer formulir YiDA, terdapat tombol tersembunyi untuk mengaktifkan Schema workbench. Halaman dapat dihasilkan dengan cepat melalui impor skema di Schema workbench. Fitur ini juga mendukung penyuntingan skema di dalam workbench, sehingga formulir dapat didefinisikan dengan cepat melalui perubahan skema. Pengguna dapat menambahkan parameter `__debug` langsung pada URL tautan desain untuk mengaktifkannya ([perakitan tautan swalayan](https://demo.aliwork.com/o/debug_by_self?__showDevtools=true)), seperti ditunjukkan di bawah:

## Debug mobile/in-App menggunakan vConsole
Buka panel aksi halaman yang perlu di-debug, lalu masukkan kode berikut di bagian atas. Akses halaman untuk memulai debug.
Catatan: Hapus kode ini setelah debug selesai.
```javascript
  const vConsole = 'https://g.alicdn.com/code/lib/vConsole/3.11.2/vconsole.min.js';
  const js = document.createElement('script');
  js.src = vConsole;
  document.body.append(js);
  js.onload = function() {
    window.vConsole = new window.VConsole();
  };
```
