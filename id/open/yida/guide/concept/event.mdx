Penanganan event adalah salah satu logika yang paling umum dalam pengembangan sistem. YiDA menyediakan kemampuan pengikatan tindakan Pengguna secara Umum, beserta panel aksi untuk menulis logika penanganan JS. Implementasi penanganan event umumnya mencakup dua langkah berikut:
* Tambah konfigurasi pengikatan tindakan ke Komponen (hampir setiap Komponen menyediakan opsi pengikatan tindakan yang sesuai).
* Terapkan logika penanganan tindakan di panel aksi.

<Tip>
Saat mengikat suatu tindakan, Pengguna dapat mengonfigurasi parameter untuk tindakan tersebut, seperti ditunjukkan di bawah ini. Parameter yang Terkonfigurasi dapat dibaca di dalam Fungsi handler melalui `this.params.xxx`, dengan `xxx` sebagai nama parameter yang ditetapkan oleh Pengguna.

Cara membaca parameter:
```js
export function onClick(){
  const { name, age } = this.params
  console.log(name, age);
}
```
</Tip>

## Kasus penggunaan
Berikut adalah contoh sederhana penggunaan penanganan event:
Dengarkan event klik pada sebuah Button dan tampilkan dialog untuk menampilkan informasi terkait. Untuk mengimplementasikan fitur penanganan event, Pengguna perlu melakukan dua langkah:
* Ikat event Tindakan Pengguna ke Komponen. Seperti ditunjukkan di bawah ini, kita mengikat event `onClick` ke Komponen Button.
* Terapkan logika penanganan event yang sesuai di panel aksi. Saat Pengguna mengklik Button, kita menampilkan dialog untuk menampilkan salam (`state.name` adalah variabel global yang kita tetapkan, dengan nilai awal "Xiaoming").

Saat Pengguna mengklik tombol Pratinjau di pojok kanan atas, mereka akan melihat efek Pratinjau berikut. Ketika Pengguna mengklik Button Hello, program akan menampilkan dialog yang menunjukkan "Hello Xiaoming".
