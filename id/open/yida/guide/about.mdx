DingTalk YiDA adalah platform pengembangan low-code yang dibangun di atas Cloud DingTalk stack. Platform ini menyediakan kemampuan inti untuk membangun Formulir, alur kerja, dan laporan sesuai kebutuhan bisnis, serta kemampuan halaman kustom yang lebih fleksibel untuk memenuhi kebutuhan bisnis yang kompleks.

Pusat Pengembang ditujukan bagi Pengguna yang memiliki pengalaman pengembangan, membantu mereka membuka keterampilan YiDA tingkat lanjut untuk membangun sistem bisnis yang lebih canggih.

Sebagian konten dalam dokumentasi ini juga berlaku untuk desainer formulir.

Halaman kustom DingTalk YiDA menyediakan lingkungan pengembangan frontend lintas platform yang terbuka. Serupa dengan pengembangan Mini program, YiDA menyediakan sekumpulan API frontend yang kaya, mencakup siklus hidup Aplikasi, dan juga memungkinkan Anda memanggil DingTalk JS API secara langsung. Aplikasi yang dihasilkan dapat dipublikasikan sebagai URL yang dapat diakses oleh Pengguna, baik di dalam maupun di luar Organisasi. Pengembangan DingTalk Mini program secara mandiri belum mendukung mobile dan PC sekaligus, sehingga dalam skenario manajemen perusahaan halaman HTML5 lebih cocok untuk membangun pengalaman lintas platform dengan biaya rendah. Di sisi backend, YiDA membuka kustomisasi melalui node Groovy dan FaaS pada Connectors.

Halaman kustom DingTalk YiDA juga dapat memanfaatkan Formulir Aplikasi YiDA sebagai penyimpanan data, melakukan operasi CRUD pada Formulir melalui YiDA Open API, serta menggunakan YiDA sebagai basis data sekaligus layanan hosting gambar. Dengan demikian, Anda dapat membangun produk tampilan depan sendiri, seperti halaman [Kasus Industri YiDA](https://www.aliwork.com/o/customer_cases). Efisiensi dan stabilitas engine ini telah terbukti pada sebagian besar bisnis Alibaba Group — sistem inti HR, keuangan, hukum, alur kerja, aset, dan situs grup semuanya dibangun di atasnya.

## Target audiens
* Jika Anda memiliki pengalaman pemrograman dan familier dengan React atau Vue, Pusat Pengembang YiDA adalah sumber terbaik untuk meningkatkan keterampilan pengembangan low-code Anda.
* Jika Anda memiliki pengalaman pemrograman tetapi baru di bidang pengembangan frontend, Pusat Pengembang YiDA membantu Anda cepat memulai pada skenario low-code umum.
* Jika Anda tidak memiliki pengalaman coding dan ingin cepat membangun Formulir, alur kerja, atau halaman laporan sederhana dengan YiDA, kami menyarankan Anda mengunjungi [Panduan Pengguna Produk YiDA](/id/yida/intro/sbg6g2nsoxacis5y) terlebih dahulu untuk memahami kemampuan dasar YiDA. Setelah itu, ikuti contoh-contoh di Pusat Pengembang untuk secara bertahap memenuhi kebutuhan yang lebih spesifik dan meningkatkan keterampilan Anda.

## Kasus penggunaan
Pusat Pengembang YiDA terutama melayani kasus penggunaan berikut:
* Ketika Anda ingin naik level dari Pengguna YiDA biasa menjadi power user, Pusat Pengembang menawarkan pengenalan konsep yang komprehensif, tutorial contoh, dan tombol how-to untuk membantu Anda cepat membuka keterampilan YiDA tingkat lanjut.
* Saat mengembangkan fitur baru, Pusat Pengembang membantu Anda cepat menemukan cara menggunakan fitur tertentu atau menemukan contoh demo.
* Saat menghadapi masalah selama pengembangan, Pusat Pengembang membantu Anda cepat menemukan FAQ serupa atau saluran untuk mengajukan pertanyaan lebih lanjut.

## Fitur 🎉
Halaman kustom YiDA menawarkan fitur utama berikut:
* 🦧 Mode pengembangan drag-and-drop WYSIWYG, dilengkapi berbagai Komponen umum dan API sistem yang disediakan secara resmi, sehingga pengembangan low-code mudah dikuasai.
* 🦊 Solusi full-stack yang mengintegrasikan model data backend dan penyimpanan sekaligus mengabstraksi detail engineering frontend, sehingga Anda dapat cepat membangun halaman yang menarik.
* 🐯 Mode pengembangan low-code yang fleksibel: bangun UI secara visual dan terapkan logika bisnis dengan mudah menggunakan kode JS.

### Apa perbedaan antara halaman kustom dan halaman Formulir?

Dari sisi implementasi, DingTalk YiDA pada dasarnya dibangun di atas [Low-Code Engine yang dikembangkan sendiri oleh YiDA](https://github.com/alibaba/lowcode-engine). Kedua jenis halaman berbagi Standar dasar yang sama, tetapi menggunakan paket material yang berbeda.

Halaman kustom berbeda dari halaman formulir biasa dalam hal pustaka material dan kasus penggunaannya. Halaman formulir biasa terutama digunakan untuk mengumpulkan data atau memublikasikan alur kerja, sehingga Komponen yang tersedia sebagian besar berjenis input. YiDA juga mengenkapsulasi logika terkait Formulir seperti pengiriman dan Pratinjau, sehingga hambatan untuk memulai tetap rendah. Halaman kustom mendukung jenis Komponen yang jauh lebih beragam dan memerlukan kode JS untuk mengimplementasikan logika bisnis. Kurva pembelajarannya sedikit lebih tinggi, tetapi dapat diterapkan pada skenario yang lebih luas.

### Dapatkah halaman kustom terintegrasi dengan layanan pihak ketiga?
Ya. Halaman kustom menyediakan kemampuan konfigurasi remote API. Anda dapat menggunakan remote API resmi yang ditawarkan YiDA maupun layanan remote pihak ketiga, dengan catatan layanan pihak ketiga harus memenuhi persyaratan API tertentu.

### Dapatkah halaman kustom mendukung Login senyap?
Ya. Baik halaman kustom maupun halaman formulir biasa merupakan tipe halaman, sehingga Anda dapat mengaktifkan Login senyap di Pengaturan Halaman YiDA.
