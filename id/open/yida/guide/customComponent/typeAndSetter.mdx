description: "Referensi lengkap tipe properti dan setter komponen kustom di YiDA — pelajari setiap setter beserta deskripsi dan ilustrasinya untuk merancang panel konfigurasi komponen secara efisien."
polished: true
---

Tipe properti komponen dan setter menyediakan berbagai opsi konfigurasi bagi pengguna untuk memenuhi beragam kebutuhan penggunaan. Tipe properti dan setter saling berkaitan, sebagaimana dijelaskan pada tabel berikut.

| **Tipe properti** | **Nama setter** | **Deskripsi** | **Ilustrasi** |
| --- | --- | --- | --- |
| **Teks** | TextSetter | Setter teks: gaya umum untuk komponen bertipe teks, memungkinkan input teks biasa. | |
|  | I18nSetter | Secara default, komponen yang baru di-drag tidak mengaktifkan internasionalisasi. Untuk mengaktifkannya, klik tombol internasionalisasi di bagian atas panel pengaturan properti. Setelah tombol diklik, editor akan terbuka sehingga Anda dapat membuat entri internasionalisasi baru atau mencari entri yang sudah ada untuk diikat. Untuk entri internasionalisasi yang sudah terikat, klik tombol internasionalisasi untuk langsung mengedit teks internasionalisasi pada bahasa yang bersangkutan. | |
|  | DateSetter | Menyediakan kotak pemilih tanggal dan menampilkan waktu yang dipilih sebagai Stempel waktu pada halaman. | |
|  | ChoiceSetter | Properti komponen kustom ditampilkan sebagai opsi di panel properti. Ketika opsi yang berbeda dipilih, konten komponen pada halaman berubah menjadi nilai opsi yang telah ditentukan. | |
|  | ImageSetter |  | |
| **boolean** | BoolSetter | Properti komponen kustom ditampilkan sebagai sakelar pada panel properti di halaman desain formulir. Saat aktif, konten komponen menampilkan `true`; saat nonaktif, menampilkan `false`. | |
| **Angka** | NumberSetter | Formulir kustom menjadi mirip dengan format komponen Numerik YiDA, sehingga input data dalam format selain angka tidak diizinkan. Nilai numerik yang dimasukkan di panel properti akan ditampilkan pada konten komponen. | |
| **object** | JsonSetter | Memungkinkan nilai properti komponen dimasukkan sebagai kode berformat object, dan ditampilkan pada konten komponen sebagai `[object Object]`. | |
| **array** | OptionsSetter | Digunakan untuk menghasilkan object array sederhana, umumnya untuk konfigurasi opsi pada pilihan dropdown. | |
|  | ListSetter | Digunakan untuk menghasilkan komponen object kompleks dengan konfigurasi yang relatif rumit. | |
|  | JsonSetter | Sama seperti setter object JsonSetter | Efek yang sama dengan setter object JsonSetter |
| **Fungsi** | ActionSetter | Digunakan untuk mengonfigurasi fungsi Callback. Ketika ActionSetter dipilih, dalam mode penggunaan properti tersebut menjadi pengaturan tindakan di bawah "Premium". | |
|  | CodeSetter | Digunakan untuk mengonfigurasi fungsi Callback. Perbedaannya dengan ActionSetter adalah dalam mode penggunaan, setter ini langsung menghasilkan kotak kode. | |
| **Element** | SlotSetter | Digunakan untuk membuat komponen bertipe kontainer yang dapat menampung komponen lain yang di-drag ke dalamnya. Untuk menggunakannya, deklarasikan terlebih dahulu sebuah properti dan Pilih SlotSetter, lalu drag komponen "Slot Placeholder" dan ikat ke properti yang telah dideklarasikan. | |
