## Gambaran umum

Debugging di aplikasi YiDA berarti **memecahkan dan menyelesaikan masalah pada komponen kustom agar fiturnya lebih sesuai dengan kebutuhan bisnis Anda**. Debugging komponen kustom tersedia dalam dua mode: **debugging sederhana** dan **debugging integrasi aplikasi**.

## Debugging sederhana

Di desainer komponen low-code, klik Pratinjau untuk menguji konfigurasi atribut dasar seperti teks, boolean, dan angka. Ubah nilai suatu atribut untuk mengamati efeknya.

<Warning>
**Catatan**: Gunakan mode [debugging integrasi aplikasi](#debugging-integrasi-aplikasi) untuk skenario berikut:

1. Atribut atau konfigurasi apa pun yang terkait dengan fungsi tidak dapat diuji dalam mode debugging sederhana.
2. Komponen yang terikat pada organisasi atau aplikasi — seperti unggah gambar atau pemilih orang — tidak dapat diuji dalam mode debugging sederhana.
</Warning>

## Debugging integrasi aplikasi

Selama pengembangan komponen kustom, setiap efek konfigurasi yang terkait dengan `function` harus di-debug melalui **debugging integrasi aplikasi**. Cakupannya meliputi pemeriksaan nilai kembalian serta menampilkan output pemanggilan `console.log()` di dalam fungsi.

**Langkah-langkah:**

1. Buat **aplikasi uji.**
2. Buka Pengaturan Aplikasi >> Manajemen Komponen >> temukan komponen yang telah Anda kembangkan >> klik Instal >> pilih "0.1.0 (Versi pengembangan, perubahan komponen tersinkronisasi secara real time)" >> klik Instal. (Lihat gambar di bawah.)

3. Setelah instalasi, buka desainer halaman, klik panel komponen, klik Komponen Kustom, lalu seret komponen yang baru diinstal ke dalam desainer halaman. Setiap perubahan di desainer komponen akan tercermin di desainer halaman secara real time. (Lihat gambar di bawah.)

<Warning>

1. Jangan debug komponen di aplikasi produksi yang sedang berjalan agar tidak berdampak pada aplikasi tersebut.
2. Jika komponen Anda tidak muncul di panel komponen kustom, periksa apakah cakupan instalasinya sudah benar.
</Warning>
