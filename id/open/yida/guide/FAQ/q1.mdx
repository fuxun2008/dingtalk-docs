## Kasus penggunaan

Untuk mengambil dan menampilkan data dari halaman formulir atau proses di dalam halaman kustom, ikuti konfigurasi pada dokumen ini guna menampilkan informasi produk pada halaman kustom.

## Tutorial video

## Langkah-langkah

### Langkah 1: Ambil data formulir yang telah dikirim

Kunjungi [YiDA Server OpenAPI](/id/open/yida/api/openAPI) untuk melihat seluruh remote OpenAPI yang disediakan YiDA, lalu temukan API kueri Data Formulir.

### Langkah 2: Konfigurasikan Sumber Data

- Tambah Sumber Data — Susun endpoint API sesuai dokumentasi OpenAPI, lalu konfigurasikan URL Permintaan, misalnya: `/dingtalk/web/APP_M14MKG7F402M1Q7H2MGO/v1/form/searchFormDatas.json`.

- Konfigurasikan parameter — Tambahkan formUuid dari Formulir target ke parameter Permintaan.

- Ambil formUuid — Lihat formUuid setiap formulir pada Aplikasi saat ini di halaman berikut.

- Simpan Sumber Data, lalu pratinjau hasilnya.
