Sistem mid-office dan back-office umumnya menerapkan kontrol izin yang ketat, sehingga pemecahan masalah pada lingkungan produksi menjadi sulit. Pada sebagian besar kasus, kami memulai dengan menyelidiki masalah terkait resource.

## Contoh kasus

Seorang pengguna melaporkan: "Saya memiliki sistem eksternal yang berjalan normal di jaringan internal, tetapi muncul masalah ketika saya memutuskan koneksi dari VPN." Lihat tangkapan layar berikut:

Bagaimana cara menyelidiki masalah ini?

## Pendekatan umum

Anda perlu memperoleh tautan, meminta izin, dan mengumpulkan berbagai prasyarat sebelum mulai melakukan debugging. Setelah semua langkah ini selesai, cukup banyak waktu telah terbuang.

## Cara menyelesaikannya menggunakan file HAR

### Langkah 1: Minta pengguna mengunduh file HAR. Bagaimana cara mengunduhnya?

1. Pada halaman yang bermasalah, ikuti langkah-langkah yang ditunjukkan pada GIF di bawah ini.

2. File `***.har` yang telah diunduh adalah yang Anda butuhkan. Kirim file ini ke developer untuk dianalisis. (Jangan gunakan metode ini pada halaman yang berisi informasi sensitif, karena berisiko menyebabkan kebocoran data.)

### Langkah 2: Bagaimana cara developer memeriksa permintaan jaringan melalui file HAR?

Buka `about:blank`, lalu unggah file tersebut di area yang sama seperti ditunjukkan pada tangkapan layar unduh di atas.

## Apa penyebab utamanya pada contoh ini?

Berdasarkan informasi dalam file HAR, terlihat bahwa permintaan dikirim ke domain internal `go.alibaba-inc.com`, dan versi yang digunakan adalah `0.4.0` (build harian). Beralih ke versi produksi akan menyelesaikan masalah ini.
