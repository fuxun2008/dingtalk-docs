Panggil API ini untuk mengueri daftar Izin File pengguna berdasarkan ID yang ditentukan (uuid file, rootNodeId Knowledge Base, atau nodeId node Knowledge Base) dan ID operator.

## Permintaan

### Informasi dasar

| Bidang | Nilai |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v2.0/storage/spaces/dentries/{dentryUuid}/permissions/query` |
| Metode HTTP | POST |
| Tipe aplikasi yang didukung | appType-Aplikasi internal |
| Izin yang diperlukan | permission-Storage.Permission.Read-Izin baca untuk informasi otorisasi penyimpanan organisasi |

### Header permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Panggil API [Mendapatkan access token aplikasi internal](/id/open/development/obtain-the-access-token-of-an-internal-app) untuk memperolehnya. |

### Parameter path

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| dentryUuid | String | Ya | uuid file. Panggil API [Pencarian File](/id/open/development/search-for-files) atau API [Mendapatkan informasi dentryUuid](/id/open/development/api-getuuidbydentryid) untuk memperoleh bidang dentryUuid dari respons. |

### Parameter query

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| unionId | String | Ya | unionId pengguna. Panggil API [Mengueri detail pengguna](/id/open/development/query-user-details) untuk memperolehnya. |

### Isi permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| option | Object | Tidak | Parameter opsional. |
| nextToken | String | Tidak | Cursor paginasi. |
| maxResults | Integer | Tidak | Ukuran halaman. Nilai default: 30. |
| filterRoleIds | Array of String | Tidak | Peran yang akan difilter. |

## Respons

### Isi respons

| Nama | Tipe | Deskripsi |
| --- | --- | --- |
| permissions | Array | Daftar izin dengan paginasi. Maksimal 30 item dikembalikan. |
| dentryUuid | String | uuid file. |
| member | Object | Anggota izin. |
| type | String | Tipe anggota izin. Nilai enum:   - **ORG**: Organisasi - **DEPT**: Departemen - **TAG**: Tag kustom - **CONVERSATION**: Obrolan - **USER**: Pengguna |
| id | String | ID anggota izin:   - Ketika `type=ORG`, id adalah ID organisasi. - Ketika `type=DEPT`, id adalah ID departemen. - Ketika `type=TAG`, id adalah ID tag. - Ketika `type=CONVERSATION`, id adalah ID obrolan. - Ketika `type=USER`, id adalah userId karyawan. |
| corpId | String | Organisasi tempat izin tersebut berada.       - Jika ID organisasi ada, izin akan otomatis dibersihkan ketika anggota terkait keluar. - Jika memberType adalah dept, ID organisasi wajib diisi. |
| name | String | Nama anggota. |
| role | Object | Peran izin. |
| id | String | ID peran. Nilai enum:   - **OWNER**: Pemilik, dengan cakupan izin berikut:    - PermissionPrivilegeEnum.INFO   - PermissionPrivilegeEnum.LIST   - PermissionPrivilegeEnum.PREVIEW   - PermissionPrivilegeEnum.READ   - PermissionPrivilegeEnum.WRITE   - PermissionPrivilegeEnum.DOWNLOAD   - PermissionPrivilegeEnum.ADD   - PermissionPrivilegeEnum.DELETE   - PermissionPrivilegeEnum.MODIFY   - PermissionPrivilegeEnum.COPY   - PermissionPrivilegeEnum.RENAME   - PermissionPrivilegeEnum.READ_PERMISSION   - PermissionPrivilegeEnum.WRITE_PERMISSION   - PermissionPrivilegeEnum.ASSIGN - **MANAGER**: Manajer, dengan cakupan izin berikut:    - PermissionPrivilegeEnum.INFO   - PermissionPrivilegeEnum.LIST   - PermissionPrivilegeEnum.PREVIEW   - PermissionPrivilegeEnum.READ   - PermissionPrivilegeEnum.WRITE   - PermissionPrivilegeEnum.DOWNLOAD   - PermissionPrivilegeEnum.ADD   - PermissionPrivilegeEnum.DELETE   - PermissionPrivilegeEnum.MODIFY   - PermissionPrivilegeEnum.COPY   - PermissionPrivilegeEnum.RENAME   - PermissionPrivilegeEnum.READ_PERMISSION   - PermissionPrivilegeEnum.WRITE_PERMISSION - **EDITOR**: Editor, dengan cakupan izin berikut:    - PermissionPrivilegeEnum.INFO   - PermissionPrivilegeEnum.LIST   - PermissionPrivilegeEnum.PREVIEW   - PermissionPrivilegeEnum.READ   - PermissionPrivilegeEnum.WRITE   - PermissionPrivilegeEnum.DOWNLOAD   - PermissionPrivilegeEnum.ADD - **DOWNLOADER**: Tampilkan dan unduh, dengan cakupan izin berikut:    - PermissionPrivilegeEnum.INFO   - PermissionPrivilegeEnum.LIST   - PermissionPrivilegeEnum.PREVIEW   - PermissionPrivilegeEnum.READ   - PermissionPrivilegeEnum.DOWNLOAD - **READER**: Hanya tampilkan, dengan cakupan izin berikut:    - PermissionPrivilegeEnum.INFO   - PermissionPrivilegeEnum.LIST   - PermissionPrivilegeEnum.PREVIEW |
| name | String | Nama peran. |
| duration | Long | Masa berlaku.      `duration` yang kosong menunjukkan bahwa otorisasi tidak memiliki batas waktu. |
| nextToken | String | Cursor paginasi.      `nextToken` yang tidak kosong menunjukkan bahwa masih ada data lainnya. |
