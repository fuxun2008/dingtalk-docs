Panggil API ini untuk mendapatkan detail pengguna dalam departemen tertentu.

## Deskripsi panggilan API

- API ini hanya mengembalikan detail pengguna dalam departemen yang ditentukan. Pengguna dalam sub-departemen tidak dikembalikan.
- API ini dapat mengembalikan detail pengguna akun reguler maupun pengguna Akun Perusahaan dalam sebuah departemen. Karena penggunaan parameter sangat berbeda antara kedua skenario tersebut, dokumentasi dipisah berdasarkan tipe akun agar lebih jelas:

  - Untuk mendapatkan detail pengguna akun reguler dalam sebuah departemen, lihat dokumen ini.
  - Untuk mendapatkan detail pengguna Akun Perusahaan dalam sebuah departemen (biasanya pengguna Enterprise DingTalk), lihat [Mendapatkan detail pengguna Akun Perusahaan dalam sebuah departemen](/id/open/development/queries-account-details).

## Permintaan

| **Informasi dasar** | |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/topapi/v2/user/list |
| Metode HTTP | POST |
| Tipe aplikasi yang didukung | appType-Aplikasi internal, appType-Aplikasi perusahaan pihak ketiga |
| Izin yang diperlukan | permission-qyapi_get_department_member-Izin baca untuk anggota departemen di Kontak |

### Parameter kueri

| Nama | Tipe | Wajib | Contoh | Deskripsi |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | bE74xxxx | Kredensial aplikasi yang digunakan untuk memanggil API ini.   - Untuk aplikasi internal, dapatkan melalui API untuk mendapatkan [access_token aplikasi internal](/id/open/development/obtain-orgapp-token). - Untuk aplikasi perusahaan pihak ketiga, dapatkan melalui API untuk mendapatkan access_token perusahaan pihak ketiga. |

### Isi permintaan

| Nama | Tipe | Wajib | Contoh | Deskripsi |
| --- | --- | --- | --- | --- |
| dept_id | Number | Ya | 10 | ID departemen. Panggil [Mendapatkan daftar departemen](/id/open/development/user-management-acquires-the-list-departments) untuk mendapatkannya. Untuk departemen root, setel parameter ini ke 1.  **Catatan**  Hanya pengguna dalam departemen saat ini yang dikembalikan. Pengguna dalam sub-departemen tidak disertakan. |
| cursor | Number | Ya | 0 | Cursor untuk kueri berhalaman. Setel ke 0 untuk panggilan pertama, lalu gunakan nilai `next_cursor` yang dikembalikan oleh panggilan sebelumnya. |
| size | Number | Ya | 10 | Ukuran halaman. |
| order_field | String | Tidak | modify_desc | Aturan pengurutan untuk anggota departemen. Jika tidak ditentukan, defaultnya adalah pengurutan kustom (`custom`):   - **entry_asc**: urutkan berdasarkan waktu bergabung ke departemen secara menaik. - **entry_desc**: urutkan berdasarkan waktu bergabung ke departemen secara menurun. - **modify_asc**: urutkan berdasarkan waktu modifikasi informasi departemen secara menaik. - **modify_desc**: urutkan berdasarkan waktu modifikasi informasi departemen secara menurun. - **custom**: urutkan berdasarkan urutan yang ditentukan pengguna (atau berdasarkan pinyin jika tidak ditentukan). |
| contain_access_limit | Boolean | Tidak | false | Apakah mengembalikan pengguna dengan akses terbatas:   - true: kembalikan. - false: jangan kembalikan. |
| language | String | Tidak | zh_CN | Bahasa untuk Kontak:   - **zh_CN**: Bahasa Tionghoa (default). - **en_US**: Bahasa Inggris. |

### Contoh permintaan

```curl
curl -X POST "https://api.dingtalk.io/topapi/v2/user/list" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=834f6b00-25b8-4484-a89d-595d1f7fa0a7' \
-d 'contain_access_limit=false' \
-d 'cursor=0' \
-d 'dept_id=10' \
-d 'language=zh_CN' \
-d 'order_field=modify_desc' \
-d 'size=10'
```

Java

```text
DingTalkClient client = new DefaultDingTalkClient("https://api.dingtalk.io/topapi/v2/user/list");
OapiV2UserListRequest req = new OapiV2UserListRequest();
req.setDeptId(1L);
req.setCursor(0L);
req.setSize(10L);
req.setOrderField("modify_desc");
req.setContainAccessLimit(false);
req.setLanguage("zh_CN");
OapiV2UserListResponse rsp = client.execute(req, "");
System.out.println(rsp.getBody());
```


### Kode error

Jika error dikembalikan saat Anda memanggil API ini, temukan solusinya di [Kode error global](/id/open/development/server-api-error-codes-1) berdasarkan pesan error.

| Kode error (errcode) | Pesan error (errmsg) | Solusi |
| --- | --- | --- |
| 400002 | Invalid parameter | Periksa apakah parameter telah diisi sesuai ketentuan. |
| 50004 | The department is out of the permission scope | Periksa apakah access_token memiliki izin operasi. |
| 40035 | Invalid parameter | Nilai dept_id, cursor, size, atau order_field tidak memenuhi persyaratan. |
| 60019 | Failed to get users from the department | Periksa apakah parameter terkait telah diisi dengan benar. |
| -1 | System busy | Coba lagi nanti. |
