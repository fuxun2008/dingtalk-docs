Panggil API ini untuk memperbarui informasi ruang.

## Deskripsi panggilan API

Perbarui informasi ruang. Hanya Admin dengan izin Kelola Aplikasi pada Ruang rapat pintar yang diizinkan melakukan tindakan ini.

## Permintaan

### Informasi dasar

| Bidang | Nilai |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/v1.0/rooms/meetingRooms |
| Metode HTTP | PUT |
| Tipe aplikasi yang didukung | appType-Aplikasi internal　appType-Aplikasi perusahaan pihak ketiga |
| Izin yang diperlukan | permission-VideoConference.Conference.Write-Izin pengelolaan informasi Rapat Video |

### Header permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Dapatkan dengan cara berikut:   - Untuk Aplikasi internal, panggil API [Memperoleh access token aplikasi internal](/id/open/development/obtain-the-access-token-of-an-internal-app). - Untuk Aplikasi perusahaan pihak ketiga, panggil API [Memperoleh access token perusahaan yang diberi otorisasi](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1). |

### Isi permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| unionId | String | Ya | unionId operator. Panggil API [Kueri detail pengguna](/id/open/development/query-user-details) untuk memperolehnya. |
| roomId | String | Ya | ID Ruang. Panggil API [Kueri daftar ruang rapat](/id/open/development/check-the-meeting-room-list) untuk memperolehnya. |
| roomName | String | Tidak | Nama Ruang. |
| roomCapacity | Integer | Tidak | Kapasitas Ruang. |
| roomPicture | String | Tidak | Gambar Ruang. |
| roomStatus | Integer | Tidak | Status Ruang.   - **0**: Tersedia untuk semua pengguna - **1**: Tersedia hanya untuk Admin - **2**: Tersedia untuk pengguna tertentu yang diberi otorisasi |
| roomLocation | Object | Tidak | Informasi Lokasi Ruang. |
| title | String | Tidak | Judul Lokasi Ruang. |
| desc | String | Tidak | Informasi Lokasi Ruang yang detail. |
| roomLabelIds | Array of Long | Tidak | ID Tag.   - **1**: TV - **2**: Telepon - **3**: Proyektor - **4**: Whiteboard - **5**: Rapat Video |
| isvRoomId | String | Tidak | ID Ruang eksternal dari pemanggil. Pemanggil dapat memasukkan ID Ruang dari sistemnya sendiri.      Jika pemanggil tidak perlu mengaitkan dengan Ruang eksternal, Nomor Ruang fisik Organisasi dapat dimasukkan. |
| groupId | Long | Tidak | ID Grup tempat Ruang berada. Panggil API [Kueri daftar Grup ruang rapat](/id/open/development/query-meeting-rooms-groups) untuk memperolehnya. |
| reservationAuthority | Object | Tidak | Izin reservasi yang dikonfigurasi untuk Ruang ketika roomStatus disetel ke otorisasi parsial. |
| authorizedMembers | Array | Tidak | Daftar Pengguna yang diberi otorisasi. |
| memberId | String | Tidak | ID Pengguna, dikonfigurasi berdasarkan memberType:   - **User**: unionId Pengguna. Panggil API [Kueri detail pengguna](/id/open/development/query-user-details) untuk memperolehnya. - **Department**: ID Departemen (dept_id). Panggil API [Memperoleh daftar departemen](https://open.dingtalk.com/document/development/obtain-the-department-list-v2) untuk memperoleh nilai parameter dept_id. |
| memberType | String | Tidak | Tipe Pengguna:   - **User**: user - **Department**: dept |
| memberName | String | Tidak | Nama Pengguna:   - **User**: Nama Pengguna - **Department**: Nama departemen |
| enableCycleReservation | Boolean | Tidak | Apakah Ruang mendukung reservasi berulang:   - **true**: Ya - **false**: Tidak |
| openReservation | Boolean | Tidak | Apakah Ruang terbuka untuk reservasi:   - **true**: Ya - **false**: Tidak |
| roomDescription | String | Tidak | Deskripsi Ruang. |
