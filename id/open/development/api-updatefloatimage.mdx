title: "Memperbarui gambar mengambang"
description: "Panggil API ini untuk memperbarui atribut gambar mengambang di DingTalk Spreadsheet, termasuk sumber gambar, posisi anchor, dan offset ukuran. Mendukung pembaruan sebagian, bidang yang tidak diatur mempertahankan nilai aslinya."
---

Panggil API ini untuk memperbarui atribut gambar mengambang yang sudah ada di DingTalk Spreadsheet, termasuk sumber gambar, posisi anchor, dan offset ukuran. Pembaruan sebagian didukung—bidang yang tidak disediakan akan mempertahankan nilai aslinya. Misalnya, kirim hanya `anchor` untuk menyesuaikan posisi gambar tanpa memengaruhi atribut lain. API ini cocok untuk menyesuaikan posisi gambar, mengganti sumber gambar, atau memodifikasi ukuran tampilan. Setelah panggilan berhasil, atribut lengkap dari gambar yang diperbarui akan dikembalikan.

## Permintaan

### Informasi dasar

| Bidang | Nilai |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/doc/workbooks/{workbookId}/sheets/{sheetId}/floatImages/{id}` |
| Metode HTTP | PUT |
| Jenis aplikasi yang didukung | appType-Internal app |
| Izin yang diperlukan | permission-Document.Workbook.Write-DingTalk Spreadsheet write permission |

### Header permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Panggil API [Mendapatkan access token dari aplikasi internal](/id/open/development/obtain-the-access-token-of-an-internal-app) untuk memperolehnya. |

### Parameter path

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| workbookId | String | Ya | ID file Spreadsheet. `nodeId(dentryUuid)` yang dikembalikan oleh [Knowledge Base API](/id/open/development/knowledge-base-overview) adalah `workbookId` Spreadsheet. Peroleh dengan memanggil API [Mendapatkan node](https://open.dingtalk.com/document/development/get-node) atau [Membuat dokumen Knowledge Base](/id/open/development/create-team-space-document). |
| sheetId | String | Ya | ID atau judul Lembar Kerja. Panggil API [Mendapatkan semua lembar kerja](/id/open/development/obtain-all-worksheets) untuk memperoleh ID dan judul Lembar Kerja. |
| id | String | Ya | ID gambar mengambang yang ditentukan. Peroleh melalui API "Query floating images". |

### Parameter query

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| operatorId | String | Ya | unionId dari operator. Panggil API [Menanyakan detail pengguna](/id/open/development/query-user-details) untuk memperolehnya. Jika operator tidak memiliki izin, API mengembalikan error `The operator has no permission`. |

### Isi permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| src | String | Tidak | Alamat sumber daya dari gambar mengambang. Panggil API [Mendapatkan informasi unggah sumber daya](/id/open/development/api-getresourceuploadinfo) untuk memperoleh `resourceUrl`. |
| anchor | Object | Tidak | Posisi anchor yang menentukan Sel tempat gambar diberi anchor. |
| row | Integer | Tidak | Nomor baris dari anchor (dimulai dari 0). |
| col | Integer | Tidak | Nomor kolom dari anchor (dimulai dari 0). |
| coordinate | Object | Tidak | Ukuran gambar dan offset relatif terhadap Sel anchor. |
| width | double | Tidak | Lebar gambar, dalam piksel. |
| height | double | Tidak | Tinggi gambar, dalam piksel. |
| offsetX | double | Tidak | Offset horizontal relatif terhadap sudut kiri atas Sel anchor, dalam piksel. |
| offsetY | double | Tidak | Offset vertikal relatif terhadap sudut kiri atas Sel anchor, dalam piksel. |
