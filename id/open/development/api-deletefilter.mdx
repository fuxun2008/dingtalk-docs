---
title: "Menghapus filter"
description: "Panggil API ini untuk menghapus filter global pada worksheet tertentu di DingTalk Spreadsheet dan memunculkan kembali baris yang disembunyikan filter — cocok untuk mengosongkan filter sebelum ekspor data."
---

Panggil API ini untuk menghapus filter global pada worksheet tertentu sehingga semua record yang disembunyikan oleh kondisi filter kembali terlihat. Ini berlaku untuk skenario ketika Anda perlu mengosongkan status filter saat ini dan memulihkan tampilan data penuh—misalnya, menghapus filter sebelum mengekspor data untuk memastikan seluruh dataset terekspor.

## Deskripsi panggilan API

Setelah panggilan berhasil, kondisi filter dan status pengurutan pada semua kolom juga dikosongkan.

## Permintaan

### Informasi dasar

| Bidang | Value |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/doc/workbooks/{workbookId}/sheets/{sheetId}/deleteFilter` |
| Metode HTTP | POST |
| Jenis aplikasi yang didukung | appType-Aplikasi internal |
| Izin yang diperlukan | permission-Document.Workbook.Write-Izin tulis DingTalk Spreadsheet |

### Header permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Panggil API [Memperoleh access token aplikasi internal](/id/open/development/obtain-the-access-token-of-an-internal-app) untuk mendapatkannya. |

### Parameter jalur

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| workbookId | String | Ya | ID file spreadsheet. `nodeId(dentryUuid)` yang dikembalikan oleh [Knowledge Base API](/id/open/development/knowledge-base-overview) adalah `workbookId` spreadsheet. Anda dapat memperolehnya dengan memanggil API [Memperoleh node](https://open.dingtalk.com/document/orgapp/get-node) dan [Membuat dokumen Knowledge Base](/id/open/development/create-team-space-document). |
| sheetId | String | Ya | ID atau nama worksheet. Panggil API [Memperoleh semua worksheet](/id/open/development/obtain-all-worksheets) untuk mendapatkan value parameter id atau name. |

### Parameter kueri

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| operatorId | String | Ya | unionId dari operator.   - Panggil API [Memperoleh informasi pengguna dengan kode login senyap](/id/open/development/obtain-the-userid-of-a-user-by-using-the-log-free) untuk mendapatkan value parameter unionid. - Panggil API [Mengkueri detail pengguna](/id/open/development/query-user-details) untuk mendapatkan value parameter unionid.       Jika operator tidak memiliki izin, API mengembalikan error `The operator has no permission`. |
