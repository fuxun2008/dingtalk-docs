title: "Mendapatkan rentang sel"

---

Panggil API ini untuk mengambil atribut sel. Saat ini, Anda dapat mengambil nilai, formula, nilai tampilan, warna latar, ukuran font, perataan horizontal, dan perataan vertikal dari sel.

## Permintaan

### Informasi dasar

| Bidang | Nilai |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/doc/workbooks/{workbookId}/sheets/{sheetId}/ranges/{rangeAddress}` |
| Metode HTTP | GET |
| Jenis aplikasi yang didukung | appType-Aplikasi internal |
| Izin yang diperlukan | permission-Document.Workbook.Read-Izin baca Spreadsheet |

### Header permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Dapatkan dengan memanggil API [Mendapatkan access token aplikasi internal](/id/open/development/obtain-the-access-token-of-an-internal-app#). |

### Parameter path

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| workbookId | String | Ya | ID file spreadsheet. Nilai `nodeId(dentryUuid)` yang dikembalikan oleh [Knowledge Base API](/id/open/development/knowledge-base-overview#) adalah `workbookId` dari spreadsheet. Dapatkan dengan memanggil API [Mendapatkan sebuah node](https://open.dingtalk.com/document/development/get-node#) atau [Membuat dokumen Knowledge Base](/id/open/development/create-team-space-document#). |
| sheetId | String | Ya | ID atau nama lembar kerja. Dapatkan nilai parameter id atau name dengan memanggil API [Mendapatkan semua lembar kerja](/id/open/development/obtain-all-worksheets#). |
| rangeAddress | String | Ya | Alamat rentang. |

### Parameter query

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| select | String | Tidak | Memfilter bidang yang akan dikembalikan. Jika parameter ini tidak ditentukan, semua bidang akan dikembalikan.   - Contohnya, `select=values` hanya mengembalikan bidang values. - Untuk mengembalikan beberapa bidang, pisahkan dengan koma. Contohnya, `select=values,formulas` hanya mengembalikan bidang values dan formulas.     Kami menyarankan Anda menentukan parameter ini untuk meningkatkan performa dan menghindari timeout API akibat penambahan nilai kembalian di kemudian hari. |
| operatorId | String | Ya | unionId dari operator.   - Dapatkan nilai parameter unionid dengan memanggil API [Mendapatkan informasi pengguna melalui kode login senyap](/id/open/development/obtain-the-userid-of-a-user-by-using-the-log-free#). - Dapatkan nilai parameter unionid dengan memanggil API [Kueri detail pengguna](/id/open/development/query-user-details#).     Jika operator tidak memiliki izin, API akan mengembalikan error `The operator has no permission`. |
