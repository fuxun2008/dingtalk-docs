# Menerjemahkan ID Kontak secara asinkron

## Deskripsi panggilan API

1. Susun dokumen yang akan diterjemahkan, seperti ditunjukkan pada gambar berikut.

### Catatan

   Hanya file dengan format xlsx, xls, csv, dan txt yang didukung.

2. Panggil API [Unggah file satu langkah](https://open.dingtalk.com/document/isvapp/single-step-file-upload) untuk memperoleh media_id.
3. Panggil API ini untuk memperoleh ID job terjemahan.

### Catatan

   Setelah API ini dipanggil, jika file berhasil diterjemahkan, notifikasi callback job asinkron akan terpicu.
4. Panggil API [Memperoleh hasil tugas terjemahan asinkron](/id/open/development/obtains-the-results-of-an-asynchronous-translation-task) untuk memperoleh tautan unduh file yang telah diterjemahkan.

### Catatan

   Disarankan untuk mereferensikan tautan unduh file yang dikembalikan dengan `<a> tag`. Jangan tentukan atribut `download` (karena masalah kompatibilitas browser).
5. Konten file yang diunduh oleh pengguna ditunjukkan pada gambar berikut.

Saat memanggil API ini, Anda mungkin menemui masalah berikut:

- **Issue**: File `excel` yang dihasilkan dengan pustaka pihak ketiga `NodeJs` yaitu `exceljs` terlihat baik-baik saja dari sisi konten, tetapi terjemahannya gagal.
- **Penyebab**: Ketika `sharedString` tidak diaktifkan, `exceljs` secara default menulis konten file menggunakan `formula string`. Perilaku ini tidak standar dan menyebabkan terjemahan gagal.
- **Solusi**: Rujuk dokumentasi `exceljs` dan paksa-aktifkan opsi `useSharedStrings`.

## Permintaan

### Informasi dasar

| Bidang | Value |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/v1.0/contact/files/translate |
| Metode HTTP | POST |
| Tipe aplikasi yang didukung | appType-Aplikasi perusahaan pihak ketiga |
| Persyaratan izin | permission-qyapi_get_member-Izin baca informasi pengguna |

### Header permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Peroleh dengan memanggil API [Memperoleh access token perusahaan yang diberikan otorisasi ke aplikasi pihak ketiga](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#). |

### Isi permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| medias | `Map<String, String>` | Ya | Informasi tentang file yang akan diterjemahkan.   - Tipe Map. Key adalah media_id file Drive, yang diperoleh dengan memanggil API [Memperoleh informasi unggah file](/id/open/development/obtain-file-upload-informations#). - Value adalah nama file, yang harus menyertakan ekstensi file dan konsisten dengan nama file yang dikirim saat memanggil API [Memperoleh informasi unggah file](/id/open/development/obtain-file-upload-informations#).        - Hanya file dengan format xlsx, xls, csv, dan txt yang didukung. - Maksimal 20 file. |
| outputFileName | String | Tidak | Nama file terpaket setelah terjemahan. Jangan sertakan ekstensi file.      Parameter ini wajib jika lebih dari satu file ditentukan dalam medias. |
| unionId | String | Ya | unionId pengguna yang saat ini mengekspor dokumen. Peroleh dengan memanggil API [Memperoleh informasi pengguna dengan kode login senyap](/id/open/development/obtain-the-userid-of-a-user-by-using-the-log-free#). |
