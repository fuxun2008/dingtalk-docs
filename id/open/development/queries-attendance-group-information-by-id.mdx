---
title: "Kueri informasi grup absensi berdasarkan groupKey"
description: "Panggil API DingTalk ini dengan groupKey untuk mengambil informasi grup absensi: jangkauan absen, izin absensi lapangan, dan kebutuhan persetujuan."
---

API ini mengueri informasi grup absensi berdasarkan groupKey grup absensi, termasuk jangkauan absen, apakah absensi lapangan diizinkan, dan apakah absensi lapangan memerlukan persetujuan.

## Permintaan

| **Informasi dasar** | |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/topapi/attendance/group/get |
| Metode HTTP | POST |
| Jenis aplikasi yang didukung | appType-Aplikasi internal |
| Izin yang diperlukan | permission-qyapi_attendance_group_read-Izin baca grup absensi |

### Parameter kueri

| Nama | Tipe | Wajib | Contoh | Deskripsi |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | 4c9ebd2b1534xxxx | Kredensial aplikasi yang digunakan untuk memanggil API ini. Dapatkan dengan memanggil [Mendapatkan access_token Aplikasi internal](/id/open/development/obtain-orgapp-token). |

### Isi permintaan

| Nama | Tipe | Wajib | Contoh | Deskripsi |
| --- | --- | --- | --- | --- |
| op_userid | String | Tidak | user123 | ID pengguna operator. |
| group_key | String | Ya | 02B1Exxxx | groupKey grup absensi.  **Catatan**  Jika pengidentifikasi grup absensi Anda adalah group_id, panggil [Konversi groupId ke groupKey](/id/open/development/groupid-to-groupkey) untuk mengonversi group_id menjadi group_key. |

### Contoh permintaan

```curl
curl -X POST "https://api.dingtalk.io/topapi/attendance/group/get" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=9d319xxxx6e5f0' \
-d 'group_key=0151E0xxxx2A1A917' \
-d 'op_userid=123456'
```

Java

```java
DingTalkClient client = new DefaultDingTalkClient("https://api.dingtalk.io/topapi/attendance/group/get");
OapiAttendanceGroupGetRequest req = new OapiAttendanceGroupGetRequest();
req.setOpUserid("123456");
req.setGroupKey("0151E022xxxxx1A917");
OapiAttendanceGroupGetResponse rsp = client.execute(req, access_token);
System.out.println(rsp.getBody());
```

## Respons

### Isi respons

| Nama | Tipe | Contoh | Deskripsi |
| --- | --- | --- | --- |
| result | Object |  | Hasil informasi grup absensi. |
| name | String | Grup absensi uji 1 | Nama grup absensi. |
| ext | String |  | Bidang ekstensi dalam format JSON. |
| location_offset | Number | 100 | Jangkauan absen, dalam meter.  **Catatan**  Bidang ini tidak digunakan lagi. Gunakan offset yang dikembalikan oleh [Kueri lokasi secara massal](/id/open/development/batch-query-position-under-attendance-group) sebagai gantinya. |
| group_key | String | 0151E0223B1EDDDF00DD6B7F72A1A917 | groupKey grup absensi. |
| enable_face_check | Boolean | false | Apakah absen dengan senyum diaktifkan.   - **true**: Aktif - **false** (default): Nonaktif |
| enable_face_beauty | Boolean | false | Apakah filter kecantikan diaktifkan.   - **true**: Aktif - **false** (default): Nonaktif |
| enable_camera_check | Boolean | false | Apakah absen dengan foto diaktifkan.   - **true**: Aktif - **false** (default): Nonaktif |
| enable_outside_check | Boolean | false | Apakah absensi lapangan diizinkan.   - **true**: Diizinkan - **false** (default): Tidak diizinkan |
| enable_outside_apply | Boolean | false | Apakah absensi lapangan memerlukan persetujuan.   - **true**: Wajib - **false** (default): Tidak wajib |
| outside_check_approve_mode | Number | 0 | Mode persetujuan untuk absensi lapangan.   - **-1** (default): Nonaktif - **0**: Setujui terlebih dahulu, lalu absen - **1**: Absen terlebih dahulu, lalu setujui |
| enable_outside_remark | Boolean | false | Apakah absensi lapangan memerlukan keterangan.   - **true**: Wajib - **false** (default): Tidak wajib |
| enable_outside_camera_check | Boolean | false | Apakah absensi lapangan memerlukan keterangan foto.   - **true**: Wajib - **false** (default): Tidak wajib |
| forbid_hide_outside_address | Boolean | true | Apakah karyawan dilarang menyembunyikan alamat detail.   - **true** (default): Dilarang - **false**: Tidak dilarang |
| enable_outside_update_normal_check | Boolean | false | Apakah catatan absensi lapangan dapat memperbarui catatan absen reguler.   - **true**: Diizinkan - **false** (default): Tidak diizinkan |
| enable_trim_distance | Boolean | false | Apakah penyesuaian halus jarak lokasi diizinkan.   - **true**: Diizinkan - **false** (default): Tidak diizinkan |
| trim_distance | Number | 50 | Jangkauan penyesuaian halus lokasi, dalam meter. |
| errmsg | String | ok | Pesan error yang dikembalikan. |
| success | Boolean | true | Apakah permintaan berhasil.   - **true**: Berhasil - **false**: Gagal |
| errcode | Number | 0 | Kode error. |
