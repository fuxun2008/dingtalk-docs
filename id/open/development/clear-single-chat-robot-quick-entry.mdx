Panggil API ini untuk menghapus entri cepat Bot obrolan tunggal.

## Permintaan

### Informasi dasar

| Bidang | Nilai |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/v1.0/robot/plugins/clear |
| Metode HTTP | POST |
| Jenis aplikasi yang didukung | appType-Aplikasi internal |
| Izin yang diperlukan | permission-Robot.SingleChat.ReadWrite-Izin pengelolaan Bot obrolan tunggal |

### Header permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Peroleh dengan memanggil API [Mendapatkan access token Aplikasi internal](/id/open/development/obtain-the-access-token-of-an-internal-app#). |

### Isi permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| robotCode | String | Ya | Kode bot. Untuk memperoleh `robotCode`, lihat topik [Glosarium Bot - robotCode](https://open.dingtalk.com/document/development/robot-overview#). |

### Contoh permintaan
