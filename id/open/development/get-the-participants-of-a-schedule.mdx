Panggil API ini untuk mengambil daftar peserta acara.

## Permintaan

### Informasi dasar

| Bidang | Nilai |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/calendar/users/{userId}/calendars/{calendarId}/events/{eventId}/attendees` |
| Metode HTTP | GET |
| Tipe aplikasi yang didukung | appType-Aplikasi internal　appType-Aplikasi perusahaan pihak ketiga　appType-Aplikasi personal pihak ketiga |
| Izin yang diperlukan | permission-Calendar.Event.Read-Izin baca untuk acara di aplikasi Calendar |

### Header permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses yang digunakan untuk memanggil API ini. Dapatkan seperti berikut:   - Untuk aplikasi internal, panggil [Mendapatkan access token aplikasi internal](/id/open/development/obtain-the-access-token-of-an-internal-app#). - Untuk aplikasi perusahaan pihak ketiga, panggil [Mendapatkan access token organisasi yang memberi otorisasi ke aplikasi pihak ketiga](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#). - Untuk aplikasi personal pihak ketiga, panggil [Mendapatkan user token](/id/open/development/obtain-user-token#). |

### Parameter path

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| userId | String | Ya | unionId dari pengguna yang memiliki resource yang diminta.   - Untuk aplikasi internal atau aplikasi perusahaan pihak ketiga, panggil [Kueri detail pengguna](/id/open/development/query-user-details#) untuk mendapatkan nilai parameter unionid. - Untuk aplikasi personal pihak ketiga, panggil [Mendapatkan profil pengguna dari Kontak](/id/open/development/dingtalk-retrieve-user-information#) untuk mendapatkan nilai parameter unionId. |
| calendarId | String | Ya | ID kalender tempat acara berada. Setel ke **primary**, yang mewakili kalender utama pengguna. |
| eventId | String | Ya | ID acara. Panggil [Kueri daftar acara](/id/open/development/query-an-event-list#) untuk mendapatkan nilai parameter id. |

### Parameter kueri

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| maxResults | Integer | Tidak | Jumlah maksimum record yang dikembalikan. Default: 100. Maksimum: 500. |
| nextToken | String | Tidak | Cursor paginasi.      Jika kueri tidak dapat mengembalikan semua hasil sekaligus, token paginasi akan dikembalikan. Kirim token ini pada permintaan berikutnya untuk mengambil data selanjutnya, hingga token paginasi bernilai null, yang menandakan bahwa semua data telah dikembalikan. |
