description: "Panggil API DingTalk ini untuk memberikan izin unduh file Drive persetujuan kepada pengguna tertentu berdasarkan spaceId dan fileId, dengan dukungan otorisasi massal."
---

Panggil API ini untuk memberikan izin unduh file di ruang Drive persetujuan berdasarkan spaceId ruang Drive dan fileId file.

## Permintaan

### Informasi dasar

| Bidang | Nilai |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/v1.0/workflow/processInstances/spaces/files/authDownload |
| Metode HTTP | POST |
| Tipe aplikasi yang didukung | appType-Aplikasi internal　appType-Aplikasi perusahaan pihak ketiga |
| Izin yang diperlukan | permission-Workflow.Instance.Write-Izin tulis instans alur kerja |

### Header permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Cara mendapatkannya:   - Aplikasi internal: Panggil API [Mendapatkan access token aplikasi internal](/id/open/development/obtain-the-access-token-of-an-internal-app). - Aplikasi perusahaan pihak ketiga: Panggil API untuk mendapatkan access token organisasi yang telah mengotorisasi aplikasi pihak ketiga. |

### Isi permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| userId | String | Ya | userId pengguna yang akan diotorisasi. |
| fileInfos | Array | Ya | Daftar file Drive yang akan diotorisasi. Mendukung otorisasi massal. Daftar dapat berisi maksimal 10 item. |
| fileId | String | Ya | fileId file. Panggil API [Mendapatkan detail satu instans persetujuan](/id/open/development/obtains-the-details-of-a-single-approval-instance-pop) untuk mendapatkan nilai `fileId`.      ID file adalah fileId dari file yang diunggah di komponen persetujuan. |
| spaceId | Long | Ya | spaceId ruang Drive persetujuan. Panggil API [Mendapatkan informasi ruang Drive persetujuan](/id/open/development/obtains-the-information-about-approval-nail-disk) untuk mendapatkan nilai `spaceId`. |
