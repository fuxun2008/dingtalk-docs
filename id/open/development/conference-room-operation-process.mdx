Dokumen ini menunjukkan cara membuat aplikasi internal dan menggunakan API yang disediakan oleh Ruang rapat pintar untuk membuat, memperbarui, mencari, dan menghapus ruang rapat.

## Hasil yang diharapkan

Ruang rapat ditampilkan sebagai berikut:

## Gambaran umum proses

Prasyarat: Selesaikan proses [Pembuatan dan konfigurasi aplikasi](/id/open/dingstart/create-application).

Langkah 1: Dapatkan informasi kredensial aplikasi, termasuk client ID dan Client Secret.

Langkah 2: Ajukan izin API untuk Ruang rapat pintar.

Langkah 3: Dapatkan kredensial akses aplikasi dengan mengikuti [Mendapatkan access token aplikasi internal](/id/open/development/obtain-the-access-token-of-an-internal-app). Access token digunakan untuk mengautentikasi pemanggil saat memanggil API.

Langkah 4: Panggil API ruang rapat:

1. Panggil Server API [Membuat ruang rapat](/id/open/development/create-a-meeting-room). Bidang `result` yang dikembalikan oleh API adalah ID ruang rapat.
2. Dengan ID ruang rapat, panggil Server API [Memperbarui informasi ruang rapat](/id/open/development/update-meeting-room-information) untuk memperbarui informasi ruang rapat.
3. Panggil Server API [Mencari daftar ruang rapat](/id/open/development/check-the-meeting-room-list) untuk mengambil daftar ruang rapat.
4. Dengan ID ruang rapat, panggil Server API [Mencari detail ruang rapat](/id/open/development/check-meeting-room-details) untuk mengambil detail ruang rapat tertentu.
5. Dengan ID ruang rapat, panggil Server API [Menghapus ruang rapat](/id/open/development/delete-a-meeting-room) untuk menghapus ruang rapat.

## Prasyarat

Selesaikan proses [Pembuatan dan konfigurasi aplikasi](/id/open/dingstart/create-application).

## Langkah 1: Dapatkan kredensial aplikasi

1. Pilih aplikasi yang dituju dan buka halaman detail aplikasi. Klik **Informasi dasar** > **Kredensial dan informasi dasar**.
2. Dapatkan client ID dan Client Secret.

## Langkah 2: Tambahkan izin API

Klik **Konfigurasi pengembangan** > **Kelola izin**. Pada kotak pencarian izin, masukkan `VideoConference.Conference.Write` dan `VideoConference.Conference.Read` secara terpisah, lalu ajukan izinnya.

## Langkah 3: Dapatkan access token

<Warning>
Untuk detail tentang perbedaan antarversi Server API, lihat perbandingan antara API lama dan API baru. Semua endpoint berikut menggunakan Server API. Untuk detail tentang unduhan SDK, lihat unduhan SDK sisi server.
</Warning>

Dengan menggunakan client ID dan Client Secret dari Langkah 1, dapatkan kredensial akses aplikasi dengan mengikuti [Mendapatkan access token aplikasi internal](/id/open/development/obtain-the-access-token-of-an-internal-app).

```java
 public void getAccessToken() throws Exception {
        Config config = new Config();
        config.protocol = "https";
        config.regionId = "central";
        com.aliyun.dingtalkoauth2_1_0.Client client = new com.aliyun.dingtalkoauth2_1_0.Client(config);
        GetAccessTokenRequest accessTokenRequest = new GetAccessTokenRequest()
                .setAppKey("din*********hgn")
                .setAppSecret("9G_O************mBkhgGIO");
        GetAccessTokenResponse accessToken = client.getAccessToken(accessTokenRequest);
        System.out.println(JSON.toJSONString(accessToken.getBody()));
    }
```
