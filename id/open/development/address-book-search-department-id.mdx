# Mencari ID departemen

## Permintaan

### Informasi dasar

| Bidang | Value |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/v1.0/contact/departments/search |
| Metode HTTP | POST |
| Tipe aplikasi yang didukung | appType-Aplikasi internal　appType-Aplikasi perusahaan pihak ketiga |
| Izin yang diperlukan | permission-qyapi_addresslist_search-Izin untuk mencari Kontak organisasi |

### Header permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses yang digunakan untuk memanggil API ini. Dapatkan dengan cara berikut:   - Untuk aplikasi internal, panggil API [Memperoleh access token aplikasi internal](/id/open/development/obtain-the-access-token-of-an-internal-app#). - Untuk aplikasi perusahaan pihak ketiga, panggil API [Memperoleh access token organisasi yang diberi otorisasi ke aplikasi pihak ketiga](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#). |

### Isi permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| queryWord | String | Ya | Nama departemen atau pinyin dari nama departemen. |
| offset | Integer | Ya | Nomor halaman. |
| size | Integer | Ya | Ukuran halaman. |

### Contoh permintaan

## Respons

### Isi respons

| Nama | Tipe | Deskripsi |
| --- | --- | --- |
| hasMore | Boolean | Menunjukkan apakah masih tersedia data lainnya. |
| totalCount | Long | Jumlah total record. |
| list | Array of Long | Daftar ID departemen. |

### Contoh isi respons

```text
HTTP/1.1 200 OK
Content-Type:application/json

{
  "hasMore" : false,
  "totalCount" : 2,
  "list" : [ 220141953, 220207936 ]
}
```
