Panggil API ini untuk mengkueri daftar lokasi grup absensi tertentu secara batch.

## Permintaan

| **Informasi dasar** | |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/topapi/attendance/group/positions/query |
| Metode HTTP | POST |
| Tipe aplikasi yang didukung | appType-Aplikasi internal |
| Izin | permission-qyapi_attendance_group_read-Izin kueri grup absensi |

### Parameter kueri

| Nama | Tipe | Wajib | Contoh | Deskripsi |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | 4c9ebd2b15xxxx | Kredensial aplikasi yang digunakan untuk memanggil API ini. Dapatkan dengan memanggil API [Mendapatkan access_token Aplikasi internal](/id/open/development/obtain-orgapp-token). |

### Isi permintaan

| Nama | Tipe | Wajib | Contoh | Deskripsi |
| --- | --- | --- | --- | --- |
| cursor | String | Tidak | 0151Exxxx | Biarkan kosong pada permintaan pertama. Untuk permintaan berikutnya saat has_more bernilai true, isi cursor dengan nilai position_key terakhir dari hasil permintaan sebelumnya. |
| size | Number | Ya | 50 | Ukuran halaman. |
| op_userid | String | Tidak | user01 | ID pengguna operator. |
| group_key | String | Ya | CEDDFxxxx | ID grup absensi.  **Catatan**  Jika pengidentifikasi grup absensi Anda berupa group_id, panggil API [Konversi groupId ke groupKey](/id/open/development/groupid-to-groupkey) untuk mengonversi group_id menjadi group_key. |

### Contoh permintaan

```curl
curl -X POST "https://api.dingtalk.io/topapi/attendance/group/positions/query" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=80645xxxx3164b3' \
-d 'cursor=0151E02xxxx7E876' \
-d 'group_key=0151ExxxxA1A917E876' \
-d 'op_userid=123456' \
-d 'size=50'
```

Java

```java
DingTalkClient client = new DefaultDingTalkClient("https://api.dingtalk.io/topapi/attendance/group/positions/query");
OapiAttendanceGroupPositionsQueryRequest req = new OapiAttendanceGroupPositionsQueryRequest();
req.setCursor("0151Exxxx");
req.setSize(50L);

req.setGroupKey("CEDDFxxxx");
OapiAttendanceGroupPositionsQueryResponse rsp = client.execute(req, access_token);
System.out.println(rsp.getBody());
```

## Respons

### Isi respons

| Nama | Tipe | Contoh | Deskripsi |
| --- | --- | --- | --- |
| result | DingOpenResult |  | Hasil yang dikembalikan. |
| result | Result |  | Hasil kueri. |
| position_list | Position[] |  | Daftar lokasi. |
| offset | Number | 100 | Toleransi jarak yang diizinkan untuk lokasi absen. |
| address | String | Kampus Xixi Alibaba Group | Deskripsi alamat. |
| latitude | String | 30,123 | Garis lintang (maksimal 6 angka desimal). |
| longitude | String | 120,123 | Garis bujur (maksimal 6 angka desimal). |
| position_key | String | 9E459Fxxxx | Pengidentifikasi unik lokasi. |
| has_more | Boolean | false | Menunjukkan apakah masih ada data lainnya.   - **true**: Ya - **false**: Tidak |
| errcode | Number | 0 | Kode pengembalian. |
| errmsg | String | ok | Deskripsi kode pengembalian. |
| success | Boolean | true | Menunjukkan apakah permintaan berhasil.   - **true**: Berhasil - **false**: Gagal |
| request_id | String | rss38gia1egs | ID permintaan. |

### Contoh isi respons

```json
{
  "result": {
```

### Kode error

Jika panggilan API ini mengembalikan error, cari solusinya di dokumen [Kode error global](/id/open/development/server-api-error-codes-1) berdasarkan pesan error yang diterima.
