---
title: "Mendapatkan nilai kolom laporan absensi"
description: "Panggil API DingTalk Smart Attendance untuk mengambil nilai dan informasi kolom laporan absensi berdasarkan ID pengguna, ID kolom laporan, dan rentang waktu."
---

Panggil API ini untuk mendapatkan data nilai kolom dari laporan DingTalk Smart Attendance. Data mencakup semua nilai kolom laporan dalam rentang waktu tertentu beserta informasi kolom terkait, untuk digunakan oleh ISV yang ditunjuk.

## Deskripsi panggilan API

- Informasi absensi pengguna yang sudah keluar dari organisasi tidak tersedia melalui API ini. Cari data absensi pengguna yang sudah keluar di [OA Admin Console](https://attend.dingtalk.io/portal/index.html).
- Saat mengambil nilai bidang "Hari absensi wajib", API ini hanya mengembalikan nilai dalam 15 hari terakhir. Untuk tanggal lebih dari 15 hari yang lalu, nilai hari absensi wajib adalah 0.

## Permintaan

| **Informasi dasar** | |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/topapi/attendance/getcolumnval |
| Metode HTTP | POST |
| Tipe aplikasi yang didukung | appType-Aplikasi internal appType-Aplikasi perusahaan pihak ketiga |
| Izin | permission-qyapi_base-Izin dasar yang diperlukan untuk memanggil API organisasi |

### Parameter query

| Nama | Tipe | Wajib | Contoh | Deskripsi |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | 6d1bxxxx | Kredensial aplikasi yang digunakan untuk memanggil API ini.   - Untuk Aplikasi internal, panggil API [Mendapatkan access_token Aplikasi internal](/id/open/development/obtain-orgapp-token) untuk memperolehnya. - Untuk Aplikasi perusahaan pihak ketiga, panggil API untuk mendapatkan access_token organisasi pihak ketiga untuk memperolehnya. |

### Isi permintaan

| Nama | Tipe | Wajib | Contoh | Deskripsi |
| --- | --- | --- | --- | --- |
| userid | String | Ya | manager4220 | ID pengguna dari pengguna terkait. |
| column_id_list | String | Ya | 129339038 | ID kolom laporan. Panggil API [Mendapatkan definisi kolom laporan absensi](/id/open/development/queries-the-enterprise-attendance-report-column) untuk memperoleh nilai parameter id. Pisahkan beberapa nilai dengan koma. Panjang maksimum: 20. |
| from_date | Date | Ya | 2018-07-11 12:12:12 | Waktu mulai. |
| to_date | Date | Ya | 2018-07-11 12:12:12 | Waktu selesai. Selisih antara waktu mulai dan waktu selesai tidak boleh lebih dari 31 hari. |

### Contoh permintaan

```curl
curl -X POST "https://api.dingtalk.io/topapi/attendance/getcolumnval" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=4bfc0fxxxx3916c7' \
-d 'column_id_list=1%2C2%2C3' \
-d 'from_date=2018-07-11+12%3A12%3A12' \
-d 'to_date=2018-07-11+12%3A12%3A12' \
-d 'userid=zhangsan'
```

## Respons

### Isi respons

| Nama | Tipe | Contoh | Deskripsi |
| --- | --- | --- | --- |
| request_id | String | 45n2azecqj21 | ID permintaan. |
| errcode | Number | 0 | Kode pengembalian. |
| result | ColumnValListForTopVo |  | Hasil yang dikembalikan. |
| column_vals | ColumnValForTopVo[] |  | Informasi kolom dan data nilai kolom. |
| column_vals | ColumnDayAndVal[] |  | Data nilai kolom. |
| date | Date | 2020-09-09 00:00:00 | Tanggal. |
| value | String | 1.0 | Nilai kolom. |
| column_vo | ColumnForTopVo |  | Informasi kolom. |
| id | Number | 129339038 | ID kolom laporan. |
| fixed_value | String | 0 | Nilai tetap.  **Catatan**  Beberapa kolom laporan memiliki nilai tetap. Nilainya hanya dikembalikan di bidang ini, tidak di column_vals. |
