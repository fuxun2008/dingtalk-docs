# Mendapatkan daftar ID subdepartemen

## Deskripsi panggilan API

- API ini tidak dibatasi oleh cakupan otorisasi.
- API ini hanya mendukung pengambilan daftar ID departemen satu tingkat di bawahnya.

Misalnya, jika Anda memanggil API ini untuk mendapatkan daftar ID subdepartemen dari Departemen root, hasilnya adalah [123,666]. Subdepartemen di bawah Departemen 1 dan Departemen 2 tidak dapat diambil.

## Permintaan

| **Informasi dasar** | |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/topapi/v2/department/listsubid |
| Metode HTTP | POST |
| Tipe aplikasi yang didukung | appType-Aplikasi internal, appType-Aplikasi perusahaan pihak ketiga |
| Izin | permission-qyapi_get_department_list-Izin baca untuk informasi departemen Kontak |

### Parameter kueri

| Nama | Tipe | Wajib | Contoh | Deskripsi |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | bE74xxxx | Kredensial aplikasi yang digunakan untuk memanggil API ini.   - Untuk aplikasi internal, dapatkan melalui API untuk mendapatkan [access_token aplikasi internal](/id/open/development/obtain-orgapp-token). - Untuk aplikasi perusahaan pihak ketiga, dapatkan melalui API untuk mendapatkan access_token perusahaan pihak ketiga. |

### Isi permintaan

| Nama | Tipe | Wajib | Contoh | Deskripsi |
| --- | --- | --- | --- | --- |
| dept_id | Number | Ya | 1 | ID departemen induk. Masukkan 1 untuk Departemen root. Untuk mendapatkan nilai dept_id, panggil API [Mendapatkan daftar departemen](/id/open/development/user-management-acquires-the-list-departments). |

### Contoh permintaan

```curl
curl -X POST "https://api.dingtalk.io/topapi/v2/department/listsubid" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=0dcxxxx108dcd028' \
-d 'dept_id=100'
```

Java

```text
DingTalkClient client = new DefaultDingTalkClient("https://api.dingtalk.io/topapi/v2/department/listsubid");
OapiV2DepartmentListsubidRequest req = new OapiV2DepartmentListsubidRequest();
req.setDeptId(100L);
OapiV2DepartmentListsubidResponse rsp = client.execute(req, access_token);
System.out.println(rsp.getBody());
```

Python

```python
import dingtalk.api

req=dingtalk.api.OapiV2DepartmentListsubidRequest("https://api.dingtalk.io/topapi/v2/department/listsubid")

req.dept_id=100
try:
  resp= req.getResponse(access_token)
  print(resp)
except Exception,e:
  print(e)
```

PHP


C#

```text

```

## Respons

### Isi respons

| Nama | Tipe | Contoh | Deskripsi |
| --- | --- | --- | --- |
| request_id | String | 48vhxdnwhve6 | ID permintaan. |
| errcode | Number | 0 | Kode pengembalian. |
| errmsg | String | Invalid department ID | Pesan error yang dikembalikan saat panggilan gagal. |
| result | DeptListSubIdResponse |  | Hasil yang dikembalikan. |
| dept_id_list | Number[] | [2,3,4,5] | Daftar subdepartemen. |

### Kode error

Jika terjadi error saat memanggil API ini, lihat dokumen [Kode error global](/id/open/development/server-api-error-codes-1) untuk menemukan solusi berdasarkan pesan error.

| Kode error (errcode) | Pesan error (errmsg) | Solusi |
| --- | --- | --- |
| 60003 | The corresponding department is not found | Pastikan dept_id sudah benar. |
| 400002 | Invalid parameter | Pastikan parameter dimasukkan sesuai ketentuan. |
| -1 | System busy | Coba lagi nanti. |
