description: "Panggil API ini untuk mendapatkan informasi pengguna melalui kode Login senyap di DingTalk — cara mengidentifikasi pengguna aktif dalam skenario login senyap pada aplikasi klien DingTalk."
---

## Permintaan

| **Informasi dasar** | |
| --- | --- |
| URL HTTP | https://oapi.dingtalk.io/topapi/v2/user/getuserinfo |
| Metode HTTP | POST |
| Tipe aplikasi yang didukung | appType-Aplikasi internalappType-Aplikasi perusahaan pihak ketiga |
| Izin yang diwajibkan | permission-qyapi_base-Izin dasar yang diperlukan untuk memanggil API perusahaan |

### Parameter query

| Nama | Tipe | Wajib | Contoh | Deskripsi |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | 6ed1bxxx | Kredensial aplikasi yang digunakan untuk memanggil API ini.   - Untuk aplikasi internal, dapatkan melalui API untuk mendapatkan [access_token aplikasi internal](/id/open/development/obtain-orgapp-token). - Untuk aplikasi perusahaan pihak ketiga, dapatkan melalui API untuk mendapatkan access_token perusahaan pihak ketiga. |

### Isi permintaan

| Nama | Tipe | Wajib | Contoh | Deskripsi |
| --- | --- | --- | --- | --- |
| code | String | Ya | bab02f63c1e030fbbxxxx | Kode otorisasi Login senyap. Untuk cara mendapatkannya, lihat:   - Kode otorisasi Login senyap untuk mini program - Kode otorisasi Login senyap untuk aplikasi mikro   **Catatan**  Kode otorisasi ini berlaku selama 5 menit dan hanya dapat digunakan satu kali. |

### Contoh permintaan

```curl
curl -X POST "https://oapi.dingtalk.io/topapi/v2/user/getuserinfo" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=417124xxxx2a3c270d5' \
-d 'code=123456'
```


## Respons

### Isi respons

| Nama | Tipe | Contoh | Deskripsi |
| --- | --- | --- | --- |
| request_id | String | e8krly4vyiln | ID permintaan. |
| errcode | Number | 0 | Kode pengembalian**.** |
| errmsg | String | ok | Deskripsi teks dari kode pengembalian. |
| result | UserGetByCodeResponse |  | Hasil yang dikembalikan. |
| userid | String | user456 | ID pengguna dari pengguna. |
| device_id | String | 12drtfxxxxx | ID perangkat. |
| sys | Boolean | true | Menunjukkan apakah pengguna adalah admin.   - **true**: Ya - **false**: Tidak |
| sys_level | Number | 1 | Level admin.   - **1**: Super Admin - **2**: Sub Admin - **100**: Boss - **0**: Lainnya (seperti karyawan biasa) |
| associated_unionid | String | N2o5U3axxxx | unionId yang terkait dengan pengguna. |
| unionid | String | gliiW002zUxxxx | unionId dari pengguna. |
| name | String | Zhang xx | Nama pengguna. |
