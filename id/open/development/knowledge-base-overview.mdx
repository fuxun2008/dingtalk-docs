Dokumen ini memperkenalkan produk Knowledge Base, apa itu Knowledge Base, dan kemampuan API apa saja yang tersedia.

## Apa itu Knowledge Base

Knowledge Base adalah platform manajemen pengetahuan perusahaan yang profesional dan efisien di dalam DingTalk. Platform ini dapat digunakan untuk membangun pustaka manajemen pengetahuan perusahaan dan memungkinkan kolaborasi dokumen internal. Pengoperasiannya sederhana dan praktis. Setelah admin menambahkan pengguna, beberapa orang dapat berbagi konten secara real time. Pengguna Knowledge Base dapat merekam semua konten yang dihasilkan melalui kolaborasi internal.

## Fitur

### Manajemen dokumen

Di dalam Knowledge Base, Anda dapat menggunakan folder untuk mengategorikan dokumen. Setiap Knowledge Base menampilkan seluruh dokumennya dalam satu pohon daftar isi. Anda juga dapat membuat dokumen atau folder langsung pada pohon tersebut.

Anda juga dapat menampilkan seluruh dokumen dalam Knowledge Base secara terstruktur melalui tampilan Peta Pikiran. Pada halaman beranda Knowledge Base, seret dan lepas langsung pada Peta Pikiran untuk menyesuaikan struktur dokumen dengan cepat.

### Kelola izin

Knowledge Base mendukung pengaturan izin berjenjang, termasuk tingkat Knowledge Base, tingkat folder, dan tingkat dokumen individual.

Jenis izinnya adalah: Dapat mengelola, Dapat mengedit, Dapat melihat/mengunduh, dan Hanya melihat.

Anda dapat menambah, mengubah, atau menghapus izin untuk mengontrol akses bagi pengguna, departemen, grup, dan organisasi.

## Glosarium

### Daftar isi

Merujuk pada pohon yang terbentuk dari struktur direktori Knowledge Base.

### Node

Merujuk pada sebuah node pada Daftar isi Knowledge Base. Ada dua jenis: folder dan file.

### Izin

- Gunakan izin untuk mengelola dokumen secara aman dalam sebuah tim atau organisasi.
- Izin secara default diwarisi dari dokumen atau folder induk, sehingga meningkatkan efisiensi pemberian izin.
- Izin dapat ditambah atau dihapus untuk memperkuat manajemen keamanan informasi tim.
