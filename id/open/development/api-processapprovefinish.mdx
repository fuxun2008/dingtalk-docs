description: "Beri tahu DingTalk Attendance saat persetujuan lembur, cuti, keluar kantor, atau perjalanan dinas disetujui agar status kehadiran karyawan diperbarui otomatis."
---

Panggil API ini untuk memberi tahu DingTalk bahwa persetujuan telah disetujui. Tipe yang didukung: lembur, cuti, keluar kantor, dan perjalanan dinas.

## Deskripsi panggilan API

Misalnya, seorang karyawan dijadwalkan bekerja hari ini pukul 08.00–18.00. Ia mengirim pengajuan cuti melalui sistem persetujuan milik organisasi sendiri. Setelah pengajuan disetujui, panggil API ini untuk memberi tahu DingTalk Attendance. Karyawan tersebut tidak perlu absen hari ini dan tidak ditandai sebagai tidak hadir. Statusnya ditampilkan sebagai cuti. Contoh lain: karyawan Xiaoding tidak absen pada 15 November, dan statistik kehadiran mencatat absen terlewat ini.

Panggil API ini untuk memberi tahu DingTalk bahwa persetujuan telah disetujui. Kehadiran Xiaoding pada 15 November akan berubah menjadi cuti, perjalanan dinas, atau lembur.

### Isi permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| topCalculateApproveDurationParam | Object | Tidak | Parameter input terkait durasi. |
| bizType | Long | Tidak | Tipe formulir persetujuan. Nilai yang valid:   - **1**: Lembur - **2**: Perjalanan dinas atau keluar kantor - **3**: Cuti |
| fromTime | String | Tidak | Waktu mulai. Waktu mulai tidak boleh lebih dari 31 hari sebelum waktu saat ini.  Format yang didukung:   - 2019-08-15 - 2019-08-15 AM - 2019-08-15 12:43 |
| toTime | String | Tidak | Waktu selesai.  Format yang didukung:   - 2019-08-15 - 2019-08-15 AM - 2019-08-15 12:43   **Catatan**  - Waktu selesai tidak boleh lebih awal dari waktu mulai. - Rentang waktu tidak boleh melebihi 360 hari. - Jumlah hari antara waktu mulai dan waktu selesai tidak boleh melebihi 31. - Jika `biz_type` bernilai 1, jumlah hari antara waktu mulai dan waktu selesai tidak boleh melebihi 1. |
| durationUnit | String | Tidak | Satuan durasi. Nilai yang didukung:   - **day** - **halfDay** - **hour**: Jika `biz_type` bernilai 1, hanya hour yang didukung.   Format waktu harus sesuai dengan satuan durasi:   - 2019-08-15 untuk day - 2019-08-15 AM untuk halfDay - 2019-08-15 12:43 untuk hour |
| calculateModel | Long | Tidak | Metode perhitungan:   - **0**: Hitung berdasarkan hari kalender - **1**: Hitung berdasarkan hari kerja |
| leaveCode | String | Tidak | Pengenal unik aturan cuti. Opsional.  **Catatan**  Isi dengan nilai yang tidak kosong hanya jika `bizType=3` (cuti). Durasi kemudian dibulatkan sesuai aturan pembulatan yang ditetapkan untuk jenis cuti tersebut. |
| timeZoneId | String | Tidak | ID zona waktu, dengan format `Asia/Shanghai`. |
| tagName | String | Tidak | Nama tipe formulir persetujuan, maksimal 20 karakter. Nilai yang didukung: 请假 (cuti), 出差 (perjalanan dinas), 外出 (keluar kantor), 加班 (lembur). |
| subType | String | Tidak | Nama subtipe, maksimal 64 karakter.  **Catatan**  Parameter ini wajib jika tipe formulir persetujuan biz_type bernilai 3. |
| approveId | String | Tidak | ID formulir persetujuan, maksimal 100 karakter. Nilai kustom.  **Catatan**  Aplikasi perusahaan pihak ketiga harus menyimpan nilai ini. Nilai ini wajib saat memberi tahu pembatalan persetujuan. Memanggil API ini lagi dengan approveId yang sama akan menjalankan pembaruan. |
| jumpUrl | String | Tidak | URL pengalihan formulir persetujuan, maksimal 200 karakter.  **Catatan**  Saat pengguna mengklik entri Aplikasi perusahaan pihak ketiga di halaman statistik kehadiran, DingTalk mengalihkan mereka ke URL ini. Isi dengan URL halaman detail formulir persetujuan. |
| overtimeDuration | String | Tidak | Wajib jika biz_type bernilai 1. Durasi lembur, dalam jam. |
| overTimeToMore | Long | Tidak | Wajib jika biz_type bernilai 1:   - **1**: Konversi lembur menjadi cuti pengganti - **2**: Konversi lembur menjadi upah |

### Isi respons

| Nama | Tipe | Deskripsi |
| --- | --- | --- |
| result | Object | Hasil yang dikembalikan. |
| duration | double | Total durasi. Satuan bidang ini sama dengan satuan yang ditetapkan untuk formulir persetujuan terkait di organisasi Anda. |
| durationDetail | Array | Detail. |
| date | String | Tanggal persetujuan disetujui. |
| duration | double | Durasi harian. |
| success | Boolean | Menunjukkan apakah panggilan API berhasil. |

### Contoh isi respons

```text
HTTP/1.1 200 OK
Content-Type:application/json

{
  "result" : {
    "duration" : 2,
    "durationDetail" : [ {
      "date" : "2019-08-15",
      "duration" : 1
    } ]
  },
  "success" : true
}
```

### Kode error

Jika panggilan API mengembalikan error, cari solusinya berdasarkan pesan error di dokumen [Kode error global](/id/open/development/server-api-error-codes-1).
