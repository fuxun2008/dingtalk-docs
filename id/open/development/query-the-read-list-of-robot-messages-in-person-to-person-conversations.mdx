Panggil API ini untuk mengueri daftar pembaca pesan Bot dalam obrolan satu lawan satu berdasarkan ID grup, kode Bot, dan ID pesan. API ini berlaku untuk skenario ketika Anda perlu memastikan apakah sebuah pesan Bot sudah dibaca selama komunikasi pesan langsung antaranggota di dalam organisasi Anda.

## Permintaan

### Informasi dasar

| Bidang | Nilai |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/v1.0/robot/privateChatMessages/query |
| Metode HTTP | POST |
| Tipe aplikasi yang didukung | appType-Aplikasi internal　appType-Aplikasi perusahaan pihak ketiga |
| Izin yang diperlukan | permission-qyapi_robot_sendmsg-Izin bagi Bot dalam organisasi Anda untuk mengirim pesan |

### Header permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Dapatkan dengan cara berikut:   - Untuk aplikasi internal, panggil API [Mendapatkan access token aplikasi internal](/id/open/development/obtain-the-access-token-of-an-internal-app#). - Untuk aplikasi perusahaan pihak ketiga, panggil API [Mendapatkan access token organisasi resmi untuk aplikasi pihak ketiga](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#). |

### Isi permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| openConversationId | String | Tidak | ID percakapan terbuka untuk obrolan satu lawan satu. Dapatkan nilainya dengan memanggil [Menginstal Mini App secara massal ke obrolan pesan langsung](https://open.dingtalk.com/document/development/batch-chat-session#) dan berlangganan [Peristiwa manajemen obrolan](https://open.dingtalk.com/document/development/org-event-overview#260a4e7084gs2) untuk memperoleh OpenConversationId. |
| robotCode | String | Tidak | Kode Bot. Untuk detailnya, lihat [ID Bot](https://open.dingtalk.com/document/development/robot-overview#). |
| processQueryKey | String | Ya | ID pesan. Dapatkan nilai `processQueryKey` dengan memanggil API [Membuat dan mengirim kartu](https://open.dingtalk.com/document/development/create-and-deliver-cards#) atau API [Mengirim pesan teks biasa melalui Bot dalam obrolan satu lawan satu](/id/open/development/the-robot-sends-ordinary-messages-in-a-person-to-person-conversation#). |
| maxResults | Long | Tidak | Jumlah item per halaman dalam kueri berpaginasi. |
| nextToken | String | Tidak | Kredensial paginasi terenkripsi yang dikembalikan dari kueri sebelumnya. Kosongkan bidang ini untuk kueri pertama. |
