---
title: "Kueri massal riwayat perubahan saldo cuti karyawan"
description: "Panggil API DingTalk untuk mengambil riwayat perubahan saldo cuti karyawan secara massal, mencakup inisialisasi, pemakaian kuota, dan pembaruan saldo dengan paginasi."
---

Panggil API ini untuk mengambil semua riwayat perubahan saldo cuti seorang karyawan. Riwayat mencakup inisialisasi saldo cuti, kuota yang telah dipakai karyawan, dan pembaruan saldo cuti.

## Permintaan

### Informasi dasar

| Bidang | Nilai |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/v1.0/attendance/vacations/records/query |
| Metode HTTP | POST |
| Tipe aplikasi yang didukung | appType-Aplikasi internal　appType-Aplikasi perusahaan pihak ketiga |
| Izin | permission-qyapi_holiday_readonly-Izin kueri cuti DingTalk |

### Header permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Cara mendapatkannya:   - Aplikasi internal: Panggil API [Mendapatkan access token aplikasi internal](/id/open/development/obtain-the-access-token-of-an-internal-app). - Aplikasi perusahaan pihak ketiga: Panggil API untuk mendapatkan access token organisasi yang telah memberikan otorisasi kepada aplikasi pihak ketiga. |

### Isi permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| opUserId | String | Ya | userId admin di organisasi Anda yang memiliki izin aplikasi Persetujuan OA. Isi dengan userId Super Admin. Panggil API [Mendapatkan daftar admin](/id/open/development/query-the-administrator-list) dan gunakan bidang `userId` milik Super Admin dari respons. |
| leaveCode | String | Ya | Pengidentifikasi unik jenis cuti. Panggil API [Kueri daftar aturan cuti](/id/open/development/holiday-type-query) untuk mendapatkan nilai `leave_code`. |
| userIds | Array of String | Ya | Daftar userId karyawan yang akan dikueri. Kirim maksimal 50 userId per panggilan. |
| pageNumber | Long | Ya | Cursor paginasi:   - Untuk kueri pertama, isi dengan 0. - Untuk kueri berikutnya, isi dengan offset kumulatif dari kueri sebelumnya. |
| pageSize | Integer | Ya | Offset paginasi. Maksimum: 200. |

## Respons

### Isi respons

| Nama | Tipe | Deskripsi |
| --- | --- | --- |
| result | Object | Hasil yang dikembalikan. |
| hasMore | Boolean | Menunjukkan apakah masih ada hasil lainnya.   - **true**: Masih ada hasil lainnya. - **false**: Tidak ada hasil lainnya. |
| leaveRecords | Array | Daftar riwayat pemakaian cuti. |
| userId | String | userId karyawan. |
| leaveCode | String | Pengidentifikasi unik jenis cuti. |
| recordId | String | Pengidentifikasi unik riwayat pemakaian cuti. |
| quotaId | String | Pengidentifikasi unik kuota cuti. |
| calType | String | Tipe perhitungan.   - **insert**: Rekaman baru - **add**: Ditambahkan - **delete**: Dihapus - **update**: Diperbarui - **null** (atau bidang tidak dikembalikan): Dipakai oleh pengajuan cuti |
| startTime | Long | Waktu mulai masa berlaku kuota atau pengajuan cuti, dalam format stempel waktu milidetik. |
| endTime | Long | Waktu berakhir masa berlaku kuota atau pengajuan cuti, dalam format stempel waktu milidetik. |
| leaveViewUnit | String | Satuan tampilan.   - **day**: Hari - **hour**: Jam |
| leaveReason | String | Alasan. |
| leaveRecordType | String | Tipe riwayat cuti.   - **leave**: Pengajuan cuti - **update**: Pembaruan kuota - **modify_quota**: Inisialisasi saldo atau pembaruan saldo |
| leaveStatus | String | Status pengajuan cuti.   - **init**: Pengajuan cuti sedang menunggu persetujuan. - **success**: Pengajuan cuti disetujui. - **refuse**: Pengajuan cuti ditolak. - **abort**: Pengajuan cuti ditarik kembali. - **revoke**: Pengajuan cuti telah disetujui, lalu permintaan pembatalannya diterima. |
| recordNumPerDay | Long | Kuota yang dipakai, dihitung dalam hari.   - **Catatan**  Jika jenis cuti dihitung per hari, nilai ini tidak kosong dan diukur dalam perseratus hari. Contoh: 1.000 = 10 hari. |
| recordNumPerHour | Long | Kuota yang dipakai, dihitung dalam jam.   - **Catatan**  Jika jenis cuti dihitung per jam, nilai ini tidak kosong dan diukur dalam perseratus jam. Contoh: 1.000 = 10 jam. |
| gmtCreate | Long | Waktu pembuatan rekaman, dalam format stempel waktu milidetik. |
| gmtModified | Long | Waktu modifikasi rekaman, dalam format stempel waktu milidetik. |
| opUserId | String | ID operator rekaman. |
| success | Boolean | Menunjukkan apakah permintaan berhasil.   - **true**: Ya - **false**: Tidak |
