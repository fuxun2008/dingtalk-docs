---
title: "Melakukan pemeriksaan mandiri aplikasi Anda"
description: "Pelajari cara melakukan pemeriksaan mandiri aplikasi di DingTalk sebelum listing — dari pengaturan keamanan hingga sertifikasi stabilitas, panduan untuk developer menyiapkan aplikasi agar lolos peninjauan."
---

Setelah merilis aplikasi Anda, selesaikan pemeriksaan mandiri sebelum melakukan listing. Ikuti langkah-langkah dalam dokumen ini untuk memeriksa aplikasi Anda secara mandiri.

## **Prosedur**

1. Masuk ke [Developer Console](https://open-dev.dingtalk.com/), lalu klik aplikasi yang dituju untuk membuka halaman detailnya.
2. Pada halaman detail aplikasi, klik **App Release > App Self-Check**.
3. Klik Start Check untuk menyelesaikan pemeriksaan mandiri fitur.

   | Item Pemeriksaan | Deskripsi |
   | --- | --- |
   | Apakah IP egress server telah disetel | Setel IP egress server di **Development Configuration > Security Center** pada aplikasi. |
   | Apakah URL beranda aplikasi atau Admin Console menggunakan HTTPS | URL beranda aplikasi atau Admin Console harus menggunakan protokol HTTPS. |
   | Apakah tipe push yang valid telah disetel | Selesaikan pengaturan push pada informasi pengembangan aplikasi. Jika Anda menggunakan push SyncHTTP, URL callback harus menggunakan [domain aman DingTalk](/id/open/development/configure-update-secure-domain-name). |
   | Apakah Monitoring Center telah terhubung | Hubungkan ke Monitoring Center dan hasilkan data pemantauan. |
   | Apakah server di-deploy di Alibaba Cloud | Pilih metode deployment yang benar. |
4. Setelah pemeriksaan mandiri fitur selesai, klik **Next** untuk melanjutkan ke peninjauan keamanan. Merujuk ke Security Access Evaluation, lalu isi dan kirim materi untuk item evaluasi peninjauan keamanan yang diperlukan untuk listing aplikasi.
5. Setelah pengiriman, buka halaman pemantauan stabilitas. Untuk persyaratan rinci, merujuk ke Stability Certification Standards.

   | **Metrik Data** | **Deskripsi** | **Persyaratan Metrik** |
   | --- | --- | --- |
   | Tingkat keberhasilan API di Monitoring Center | Lihat di Monitoring Center pada **Monitoring Metrics** > **API Requests** > **Success Rate**. | ≥98,99% |
   | Latensi API rata-rata di Monitoring Center | Lihat di Monitoring Center pada **Monitoring Metrics** > **API Requests** > **Request Latency**. | &lt;300 |
   | Tingkat error JS di Monitoring Center | Lihat di Monitoring Center pada **Monitoring Metrics** > **JS Errors** > **Error Count to PV Ratio**. | &lt;1,99% |
   | Tingkat layar kosong di Monitoring Center | Lihat di Monitoring Center pada **Monitoring Metrics** > **Blank Screen Errors** > **Blank Screen Rate**. | &lt;1,99% |
   | Tingkat keberhasilan dd.config | Tingkat keberhasilan rata-rata harian panggilan ke SAPI **dd.config**. | ≥98,99% |
   | Tingkat keberhasilan push HTTP | Ketika tipe push adalah Stream atau SyncHttp, ini adalah tingkat keberhasilan push DingTalk ke URL callback selama periode statistik (**push yang memakan waktu lebih dari 1.500 ms dihitung sebagai kegagalan timeout**). | ≥98,99% |
6. Setelah pemantauan stabilitas selesai, klik **Self-Check Complete**, lalu **Submit for Listing**.

## **Langkah selanjutnya**

Setelah mengirim aplikasi Anda untuk listing, isi informasi listing aplikasi. Merujuk ke List Your Product.
