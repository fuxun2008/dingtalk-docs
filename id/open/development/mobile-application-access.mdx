---

DingTalk Sign-in untuk aplikasi seluler adalah sistem masuk Otorisasi OAuth 2.0 DingTalk yang dibangun di atas [standar protokol OAuth 2.0](https://oauth.net/2/).

**Catatan**

- Saat ini, DingTalk Sign-in pada aplikasi seluler hanya mendukung metode masuk native, yang mengharuskan pengguna menginstal DingTalk Sisi klien.
- Untuk aplikasi Android, tampilkan tombol DingTalk Sign-in setiap saat. Ketika ponsel pengguna belum menginstal DingTalk Sisi klien, arahkan pengguna untuk mengunduh dan menginstalnya.

## Kasus penggunaan

Ketika seorang karyawan menggunakan Aplikasi yang dikembangkan secara internal oleh organisasinya, mereka perlu masuk dengan akun dan kata sandi. Untuk menyederhanakan proses masuk, tambahkan tombol DingTalk langsung pada halaman masuk sehingga karyawan dapat masuk ke Aplikasi menggunakan akun DingTalk mereka.

Gambar di bawah ini menunjukkan halaman masuk klien BOC International. Pengguna yang memiliki akun DingTalk dan telah menginstal DingTalk Sisi klien dapat masuk langsung dengan Otorisasi DingTalk, tanpa memasukkan akun dan kata sandi.

## Petunjuk

Ketika Aplikasi Anda perlu menggunakan DingTalk Sign-in, pertama-tama tambahkan Aplikasi DingTalk di **DingTalk Open Platform**, lalu integrasikan permintaan masuk otorisasi menggunakan SDK yang disediakan oleh DingTalk Open Platform. Setelah Anda mengintegrasikan SDK dengan benar dan memperoleh cakupan otorisasi yang relevan (cakupan otorisasi; saat ini, DingTalk hanya mendukung masuk otorisasi dan pengambilan informasi dasar pengguna), Aplikasi seluler developer akan meluncurkan Aplikasi DingTalk secara lokal di perangkat untuk masuk otorisasi. Setelah pengguna DingTalk mengonfirmasi, DingTalk akan meluncurkan Aplikasi seluler developer dan meneruskan parameter tiket otorisasi sementara `code`. Selanjutnya, panggil API informasi pengguna pribadi DingTalk untuk mengambil informasi dasar pengguna yang masuk, termasuk nomor telepon, DingTalk Name, URL DingTalk Profile Photo, dan lainnya.
