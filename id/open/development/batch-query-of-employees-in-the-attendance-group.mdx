---
title: "Mengkueri daftar anggota absensi"
description: "Gunakan API DingTalk ini untuk mengkueri daftar anggota absensi per halaman berdasarkan group_key grup absensi, lengkap dengan parameter, contoh kode, dan respons."
---

Panggil API ini untuk mengkueri karyawan yang menjadi anggota absensi dari grup absensi tertentu berdasarkan groupKey grup absensi tersebut. Jika departemen dikonfigurasi sebagai anggota absensi, API ini tidak dapat mengembalikan ID departemen.

## Permintaan

| **Informasi dasar** | |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/topapi/attendance/group/users/query |
| Metode HTTP | POST |
| Tipe aplikasi yang didukung | appType-Aplikasi internal |
| Izin yang diperlukan | permission-qyapi_attendance_group_read-Izin kueri grup absensi |

### Parameter kueri

| Nama | Tipe | Wajib | Contoh | Deskripsi |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | 4c9ebd2b1534xxxx | Kredensial aplikasi untuk memanggil API ini. Dapatkan dengan memanggil API [Mendapatkan access_token aplikasi internal](/id/open/development/obtain-orgapp-token). |

### Isi permintaan

| Nama | Tipe | Wajib | Contoh | Deskripsi |
| --- | --- | --- | --- | --- |
| size | Number | Tidak | 50 | Ukuran halaman. |
| cursor | String | Ya | 10 | ID pengguna terakhir dari batch sebelumnya. Kirim null atau nilai kosong untuk memulai kueri dari awal. |
| op_userid | String | Tidak | user01 | ID pengguna operator. |
| group_key | String | Ya | CEDDFFxxxx | ID grup absensi.  **Catatan**  Jika pengenal grup absensi Anda berupa group_id, panggil API [Mengonversi groupId menjadi groupKey](/id/open/development/groupid-to-groupkey) untuk mengonversi group_id menjadi group_key. |

### Contoh permintaan

```curl
curl -X POST "https://api.dingtalk.io/topapi/attendance/group/users/query" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=d2ee6exxxx9266c' \
-d 'cursor=%5C%22%5C%22' \
-d 'group_key=0151Exxxx17E876' \
-d 'op_userid=123456' \
-d 'size=50'
```

Java

```java
DingTalkClient client = new DefaultDingTalkClient("https://api.dingtalk.io/topapi/attendance/group/users/query");
OapiAttendanceGroupUsersQueryRequest req = new OapiAttendanceGroupUsersQueryRequest();
req.setSize(50L);
req.setCursor("10");
req.setOpUserid("user01");
req.setGroupKey("CEDDFFxxxx");
OapiAttendanceGroupUsersQueryResponse rsp = client.execute(req, access_token);
System.out.println(rsp.getBody());
```

## Respons

### Isi respons

| Nama | Tipe | Contoh | Deskripsi |
| --- | --- | --- | --- |
| request_id | String | ntxswpdprw5d | ID permintaan. |
| result | DingOpenResult |  | Hasil yang dikembalikan. |
| result | Result |  | Hasil kueri. |
| user_list | String[] | user01 | Daftar pengguna. |
| has_more | String | false | Menunjukkan apakah masih ada data lainnya.   - **true**: Ya - **false**: Tidak |
| errcode | Number | 0 | Kode pengembalian. |
| errmsg | String | ok | Deskripsi kode pengembalian. |
| success | Boolean | true | Menunjukkan apakah panggilan berhasil.   - **true**: Berhasil - **false**: Gagal |

### Contoh isi respons

```json
{
  "result": {
    "errcode": 0,
    "errmsg":"ok",
    "result": {
      "has_more": "false",
      "user_list": [
        "user01"
      ]
    },
    "success": true
  },
  "request_id": "ntxswpdprw5d"
}
```

### Kode kesalahan

Jika panggilan API ini mengembalikan error, gunakan pesan error untuk mencari solusi di dokumen [Kode error global](/id/open/development/server-api-error-codes-1).
