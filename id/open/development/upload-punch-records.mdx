---

Panggil API ini untuk mengunggah rekaman kartu atau pengenalan wajah dari sistem kehadiran pihak ketiga ke DingTalk Attendance sebagai rekaman absen DingTalk.

## Permintaan

| **Informasi dasar** | |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/topapi/attendance/record/upload |
| Metode HTTP | POST |
| Tipe aplikasi yang didukung | appType-Aplikasi internal |
| Izin yang diperlukan | permission-Pro.AttendanceRecord.Write-Izin tulis untuk rekaman absen kehadiran |

### Parameter query

| Nama | Tipe | Wajib | Contoh | Deskripsi |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | af21axxx | Kredensial aplikasi yang digunakan untuk memanggil API ini. Dapatkan dengan memanggil [Mendapatkan access_token Aplikasi internal](/id/open/development/obtain-orgapp-token). |

### Isi permintaan

| Nama | Tipe | Wajib | Contoh | Deskripsi |
| --- | --- | --- | --- | --- |
| userid | String | Ya | user123 | ID pengguna karyawan yang rekaman absennya ingin Anda unggah. |
| device_name | String | Ya | Mesin Absensi Gerbang Timur | Nama mesin Absensi. Nilai ini bersifat kustom, misalnya 123456. |
| device_id | String | Ya | abc123456 | ID mesin Absensi. Nilai ini bersifat kustom, misalnya abcde. |
| photo_url | String | Tidak | https://xxx.com/xxx.png | URL gambar alias absen. URL harus dapat diakses secara publik. |
| user_check_time | Number | Ya | 1587020403000 | Waktu karyawan melakukan absen, dalam milidetik.  **Catatan**   - Parameter ini harus dalam milidetik. - Masukkan tanggal dalam 180 hari terakhir. |

### Contoh permintaan

```curl
curl -X POST "https://api.dingtalk.io/topapi/attendance/record/upload" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=0927xxxx3e28ea' \
-d 'device_id=abc123456' \
-d 'device_name=Mesin%20Absensi%20Gerbang%20Timur' \
-d 'photo_url=https%3A%2F%2Fxxx.com%2Fxxx.png' \
-d 'user_check_time=1587020403000' \
-d 'userid=dd_dd'
```

Java

```text
DingTalkClient client = new DefaultDingTalkClient("https://api.dingtalk.io/topapi/attendance/record/upload");
OapiAttendanceRecordUploadRequest req = new OapiAttendanceRecordUploadRequest();
req.setUserid("dd_dd");
req.setDeviceName("Mesin Absensi Gerbang Timur");
req.setDeviceId("abc123456");
req.setPhotoUrl("https://xxx.com/xxx.png");
req.setUserCheckTime(1587020403000L);
OapiAttendanceRecordUploadResponse rsp = client.execute(req, access_token);
System.out.println(rsp.getBody());
```

## Respons

### Isi respons

| Nama | Tipe | Contoh | Deskripsi |
| --- | --- | --- | --- |
| success | Boolean | true | Menunjukkan apakah panggilan berhasil. |
| errcode | Number | 0 | Kode pengembalian. |
| errmsg | String | ok | Deskripsi kode pengembalian. |
| request_id | String | ktoftehkz2bt | ID permintaan. |

### Contoh isi respons

```json
{
  "errcode":0,
  "success":true,
  "request_id" : "3ynh2gp5ndke"
}
```

### Kode kesalahan

Jika panggilan API ini gagal, cari solusi berdasarkan pesan error di dokumen [Kode kesalahan global](/id/open/development/server-api-error-codes-1).
