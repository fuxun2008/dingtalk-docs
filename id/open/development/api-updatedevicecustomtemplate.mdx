Perbarui konten templat layar kustom berdasarkan ID templatnya.

## Permintaan

### Informasi dasar

| Bidang | Nilai |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/v1.0/rooms/devices/screens/templates |
| Metode HTTP | PUT |
| Tipe aplikasi yang didukung | appType-Aplikasi internal　appType-Aplikasi perusahaan pihak ketiga |
| Izin yang diperlukan | permission-Rooms.DeviceTemplate.Write-Izin tulis untuk layar kustom Ruang Rapat DingTalk |

### Header permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial API. Peroleh dengan memanggil API [Dapatkan token pengguna](/id/open/development/obtain-user-token#). Saat membangun tautan untuk memperoleh token pengguna, parameter `code` harus diperoleh dengan cakupan yang disetel ke ID pengguna dan ID organisasi, yaitu `scope=openid corpid`. |

### Isi permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| templateName | String | Ya | Nama templat. |
| logo | String | Tidak | Logo templat. Panggil API [Unggah file media](/id/open/development/upload-media-files#) untuk memperoleh mediaId. Dimensi gambar: 240\*240. Satu gambar tidak boleh melebihi 1 MB. |
| orgName | String | Tidak | Nama organisasi yang ditampilkan di templat. |
| customDoc | String | Tidak | Konten teks kustom templat. |
| bgUrl | String | Tidak | URL latar belakang kustom templat. |
| bgImgList | Array of String | Tidak | mediaId gambar. Panggil API [Unggah file media](/id/open/development/upload-media-files#) untuk memperoleh parameter respons `media_id`. Maksimal 9 gambar dapat diunggah. Satu gambar tidak boleh melebihi 5 MB. |
| instruction | Boolean | Tidak | Apakah petunjuk penggunaan ditampilkan. Default: false. Nilai:   - true: tampilkan - false: jangan tampilkan |
| bgType | Integer | Tidak | Tipe latar belakang kustom templat. Default: 1. Nilai:   - 1: gambar - 2: URL |
| isPicTop | Integer | Tidak | Apakah bilah informasi beranda ditampilkan. Default: 1. Nilai:   - 0: tampilkan - 1: jangan tampilkan |
| hideServerCodeWhenProjecting | Boolean | Tidak | Apakah kode transmisi disembunyikan saat transmisi. Default: false. Nilai:   - true: sembunyikan - false: jangan sembunyikan |
| showCalendarTitle | Boolean | Tidak | Apakah judul acara ditampilkan pada kartu acara. Default: false. Nilai:   - true: tampilkan - false: jangan tampilkan |
| desensitizeUserName | Boolean | Tidak | Apakah nama pemesan disamarkan pada kartu acara. Default: false. Nilai:   - true: samarkan - false: jangan samarkan |
| picturePlayInterval | Integer | Tidak | Interval carousel, dalam detik, untuk gambar latar belakang kustom. |
| showCalendarCard | Boolean | Tidak | Apakah kartu acara ditampilkan. Default: false. Nilai:   - true: tampilkan - false: jangan tampilkan |
| showFunctionCard | Boolean | Tidak | Apakah kartu fungsi ditampilkan. Default: false. Nilai:   - true: tampilkan - false: jangan tampilkan |
| deviceUnionIds | Array of String | Tidak | unionId perangkat. Peroleh parameter ini dari langganan peristiwa [Perubahan pengikatan Perangkat-ke-Ruang](https://open.dingtalk.com/document/development/org-event-overview#). |
| groupIds | Array of Long | Tidak | ID grup. Panggil API [Kueri daftar grup Ruang](/id/open/development/query-meeting-rooms-groups#) untuk memperolehnya. |
| roomIds | Array of String | Tidak | ID Ruang. Panggil API [Kueri daftar Ruang](/id/open/development/check-the-meeting-room-list#) untuk memperolehnya. |
| templateId | Long | Ya | ID templat. Panggil API [Kueri daftar templat layar kustom](https://open.dingtalk.com/document/development/api-querydevicecustomtemplatelist#) untuk memperolehnya. |
