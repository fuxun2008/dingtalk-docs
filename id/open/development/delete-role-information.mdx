Panggil API ini untuk menghapus peran tertentu berdasarkan role ID.

## Deskripsi panggilan API

- Sebelum memanggil API ini, pastikan semua karyawan yang terkait dengan peran tersebut sudah dilepaskan dari peran itu.
- Peran di bawah grup peran default tidak dapat dihapus.

## Permintaan

| **Informasi dasar** | |
| --- | --- |
| URL HTTP | https://oapi.dingtalk.io/topapi/role/deleterole |
| Metode HTTP | POST |
| Jenis aplikasi yang didukung | appType-Aplikasi internal |
| Izin yang diperlukan | permission-qyapi_manage_addresslist-Izin pengelolaan data Kontak |

### Parameter query

| Nama | Tipe | Wajib | Contoh | Deskripsi |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | 6ed1xxxx | Kredensial aplikasi untuk memanggil API ini. Dapatkan melalui API untuk memperoleh access_token dari aplikasi internal. |

### Isi permintaan

| Nama | Tipe | Wajib | Contoh | Deskripsi |
| --- | --- | --- | --- | --- |
| role_id | Number | Ya | 1581321999 | ID peran yang akan dihapus. Panggil API [Ambil daftar peran](/id/open/development/obtains-a-list-of-enterprise-roles) untuk memperolehnya.  Peran di grup "Default" tidak dapat diubah, termasuk: Owner, Manager, Super Admin, dan Sub Admin. |

### Contoh permintaan

```curl
curl -X POST "https://oapi.dingtalk.io/topapi/role/deleterole" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=f5326exxxxbe8d071' \
-d 'role_id=11'
```

Java

```text
DingTalkClient client = new DefaultDingTalkClient("https://oapi.dingtalk.io/topapi/role/deleterole");
OapiRoleDeleteroleRequest req = new OapiRoleDeleteroleRequest();
req.setRoleId(1581321999L);
OapiRoleDeleteroleResponse rsp = client.execute(req, access_token);
System.out.println(rsp.getBody());
```

Python

```python
import dingtalk.api

req=dingtalk.api.OapiRoleDeleteroleRequest("https://oapi.dingtalk.io/topapi/role/deleterole")

req.role_id=11
try:
  resp= req.getResponse(access_token)
  print(resp)
except Exception,e:
  print(e)
```

PHP

```php

date_default_timezone_set('Asia/Shanghai');
```

```text

```

## Respons

### Isi respons

| Nama | Tipe | Contoh | Deskripsi |
| --- | --- | --- | --- |
| errcode | Number | 0 | Kode pengembalian. |
| errmsg | String | ok | Deskripsi kode pengembalian. |
| request_id | String | zw9fhpj3m32u | ID permintaan. |

### Contoh isi respons

```json
{
  "errcode":"0",
  "request_id":"zw9fhpj3m32u"
}
```

### Kode error

Jika terjadi error saat memanggil API ini, lihat dokumen [Kode error global](/id/open/development/server-api-error-codes-1) untuk menemukan solusi berdasarkan pesan error.

| Kode error (errcode) | Pesan error (errmsg) | Solusi |
| --- | --- | --- |
| 33011 | Invalid role_id | Pastikan role_id sudah benar. |
| 23004 | Editing system tags is not allowed | Pastikan role_id valid. |
| 1002 | System busy | Coba lagi nanti. |
