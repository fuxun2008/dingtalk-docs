description: "Panggil API DingTalk untuk menghapus templat persetujuan berdasarkan kode templat, sekaligus membersihkan instans dan tugas terkait secara opsional."
---

Panggil API ini untuk menghapus templat persetujuan yang dibuat untuk organisasi, beserta instans dan tugas yang dibuat dari templat tersebut.

## Deskripsi panggilan API

- Untuk Aplikasi internal, hanya templat yang dihapus. Instans dan tugas yang dibuat dari templat tersebut tidak ikut dihapus.
- Untuk Aplikasi perusahaan pihak ketiga, templat dihapus beserta instans dan tugas yang dibuat dari templat tersebut.

## Permintaan

### Informasi dasar

| Bidang | Nilai |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/v1.0/workflow/processCentres/schemas |
| Metode HTTP | DELETE |
| Tipe aplikasi yang didukung | appType-Aplikasi internal　appType-Aplikasi perusahaan pihak ketiga |
| Izin yang diperlukan | permission-Workflow.Form.Write-Izin tulis untuk templat alur kerja |

### Header permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Cara memperolehnya:   - Untuk Aplikasi internal, panggil API [Dapatkan access token Aplikasi internal](/id/open/development/obtain-the-access-token-of-an-internal-app). - Untuk Aplikasi perusahaan pihak ketiga, panggil API untuk mendapatkan access token organisasi yang telah memberikan otorisasi kepada Aplikasi pihak ketiga. |

### Parameter kueri

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| processCode | String | Ya | Kode templat.   - Untuk Aplikasi internal, panggil API [Dapatkan kode templat](/id/open/development/obtain-the-template-code) untuk memperolehnya. |
| cleanRunningTask | Boolean | Tidak | Menentukan apakah tugas yang sedang berjalan akan dibersihkan.   - **true**: Ya - **false**: Tidak |

### Contoh permintaan

HTTP

```http
DELETE /v1.0/workflow/processCentres/schemas?processCode=proc-abc&cleanRunningTask=false HTTP/1.1
Host:api.dingtalk.io
x-acs-dingtalk-access-token:6d1bxxxx
Content-Type:application/json
```

## Respons

### Isi respons

| Nama | Tipe | Deskripsi |
| --- | --- | --- |
| result | Object | Hasil. |
| processCode | String | Kode templat. |

### Contoh isi respons

```text
HTTP/1.1 200 OK
Content-Type:application/json

{
  "result" : {
    "processCode" : "proc-1234"
  }
}
```
