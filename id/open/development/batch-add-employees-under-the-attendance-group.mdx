Panggil API ini untuk menambahkan anggota absensi secara massal ke grup absensi tertentu berdasarkan groupKey. API ini hanya mendukung penambahan karyawan. Penambahan departemen tidak didukung.

## Permintaan

| **Informasi dasar** | |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/topapi/attendance/group/users/add |
| Metode HTTP | POST |
| Jenis aplikasi yang didukung | appType-Aplikasi internal |
| Izin | permission-qyapi_attendance_group_manage-Izin pengelolaan grup absensi |

### Parameter query

| Nama | Tipe | Wajib | Contoh | Deskripsi |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | 4c9ebd2b1534xxxx | Kredensial aplikasi yang digunakan untuk memanggil API ini. Dapatkan dengan memanggil API [Mendapatkan access_token Aplikasi internal](/id/open/development/obtain-orgapp-token). |

### Isi permintaan

| Nama | Tipe | Wajib | Contoh | Deskripsi |
| --- | --- | --- | --- | --- |
| op_userid | String | Tidak | user01 | ID pengguna operator. |
| group_key | String | Ya | CEDDxxxx | ID grup absensi.  **Catatan**  Jika pengidentifikasi grup absensi Anda adalah group_id, panggil API [Mengonversi groupId menjadi groupKey](/id/open/development/groupid-to-groupkey) untuk mengonversi group_id menjadi group_key. |
| user_id_list | String[] | Ya | user02,user03 | Daftar ID pengguna. Maksimum: 100. |

### Contoh permintaan

```curl
curl -X POST "https://api.dingtalk.io/topapi/attendance/group/users/add" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=e0f3d9xxxxa9b71' \
-d 'group_key=0151E0xxxx917E876' \
-d 'op_userid=123456' \
-d 'user_id_list=123456%2C123457'
```

Java

```java
DingTalkClient client = new DefaultDingTalkClient("https://api.dingtalk.io/topapi/attendance/group/users/add");
OapiAttendanceGroupUsersAddRequest req = new OapiAttendanceGroupUsersAddRequest();
req.setOpUserid("user01");
req.setGroupKey("CEDDxxxx");
req.setUserIdList("user02,user03");
OapiAttendanceGroupUsersAddResponse rsp = client.execute(req, access_token);
System.out.println(rsp.getBody());
```

## Respons

### Isi respons

| Nama | Tipe | Contoh | Deskripsi |
| --- | --- | --- | --- |
| result | Result |  | Hasil yang dikembalikan. |
| error_info_list | ErrorInfo[] |  | Daftar error. |
| failure_list | String[] |  | Daftar entri yang gagal. |
| msg | String | business fault | Pesan error. |
| code | String | 1000 | Kode error. |
| success_list | String[] |  | Daftar entri yang berhasil. |
| errcode | Number | 0 | Kode pengembalian. |
| errmsg | String | ok | Deskripsi kode pengembalian. |
| success | Boolean | true | Menunjukkan apakah permintaan berhasil.   - **true**: Berhasil - **false**: Gagal |
| request_id | String | w8iju9gfb236 | ID permintaan. |

### Contoh isi respons

```json
{
  "errcode": 0,
  "result": {
    "success_list": [
      "user456",
      "manager4220"
    ]
  },
  "success": true,
  "request_id": "w8iju9gfb236"
}
```

### Kode error

Jika panggilan API ini mengembalikan error, cari solusinya di dokumen [Kode error global](/id/open/development/server-api-error-codes-1) berdasarkan pesan error yang muncul.
