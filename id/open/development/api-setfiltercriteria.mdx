title: "Menetapkan kriteria filter"
description: "Panggil API ini untuk menetapkan atau memperbarui kriteria filter pada kolom tertentu di filter global — solusi tepat untuk mengontrol rentang visibilitas satu kolom secara presisi di DingTalk Spreadsheet."
---

Panggil API ini untuk menetapkan atau memperbarui kriteria filter pada kolom tertentu di filter global. API ini cocok untuk skenario yang memerlukan kontrol presisi atas rentang data yang terlihat pada satu kolom.

## Deskripsi panggilan API

Kriteria yang baru dikonfigurasi akan menimpa kriteria filter yang sudah ada pada kolom tersebut, dan record yang tidak memenuhi kriteria akan otomatis disembunyikan.

## Permintaan

### Informasi dasar

| Bidang | Nilai |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/doc/workbooks/{workbookId}/sheets/{sheetId}/filter/setColumnFilterCriteria` |
| Metode HTTP | POST |
| Jenis aplikasi yang didukung | appType-Aplikasi internal |
| Izin | permission-Document.Workbook.Write-Izin tulis DingTalk Spreadsheet |

### Header permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Untuk memperolehnya, panggil API [Memperoleh access token aplikasi internal](/id/open/development/obtain-the-access-token-of-an-internal-app). |

### Parameter path

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |

Untuk memperolehnya, panggil API [Memperoleh node](https://open.dingtalk.com/document/orgapp/get-node) atau [Membuat dokumen Knowledge Base](/id/open/development/create-team-space-document). |
| sheetId | String | Ya | ID atau nama lembar kerja. Untuk memperoleh nilai parameter id atau name, panggil API [Memperoleh semua lembar kerja](/id/open/development/obtain-all-worksheets). |

### Parameter query

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| operatorId | String | Ya | unionId operator.   - Untuk memperoleh nilai parameter unionid, panggil API [Memperoleh informasi pengguna dengan kode login senyap](/id/open/development/obtain-the-userid-of-a-user-by-using-the-log-free). - Untuk memperoleh nilai parameter unionid, panggil API [Melihat detail pengguna](/id/open/development/query-user-details).       Jika operator tidak memiliki izin, API akan mengembalikan error `The operator has no permission`. |

### Isi permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| column | Long | Ya | Offset kolom relatif terhadap kolom pertama dari rentang filter, dimulai dari 0. Misalnya, jika rentang filter adalah `B1:E10`, `column=0` mewakili kolom B, dan `column=1` mewakili kolom C. |
| filterCriteria | Object | Ya | Object kriteria filter. |
| filterType | String | Ya | Tipe filter. Nilai yang valid:   - **values**: filter berdasarkan nilai - **color**: filter berdasarkan warna - **condition**: filter berdasarkan kondisi |
| visibleValues | Array of String | Tidak | Nilai yang terlihat. |
| backgroundColor | String | Tidak | Warna yang terlihat saat memfilter berdasarkan warna latar belakang, dalam format heksadesimal (seperti `#FF0000`). Ketika `filterType` adalah `color`, salah satu dari `backgroundColor` atau `fontColor` wajib diisi. |
| fontColor | String | Tidak | Warna yang terlihat saat memfilter berdasarkan warna font, dalam format heksadesimal (seperti `#00FF00`). Ketika `filterType` adalah `color`, salah satu dari `backgroundColor` atau `fontColor` wajib diisi. |
| conditions | Array | Tidak | Daftar kondisi saat memfilter berdasarkan kondisi. Maksimal 2 kondisi yang didukung. Parameter ini wajib diisi ketika `filterType` adalah `condition`. |
| operator | String | Tidak | Operator kondisi. Nilai yang valid:   - **equal**: sama dengan - **not-equal**: tidak sama dengan - **contains**: mengandung - **not-contains**: tidak mengandung - **starts-with**: diawali dengan - **not-starts-with**: tidak diawali dengan - **ends-with**: diakhiri dengan - **not-ends-with**: tidak diakhiri dengan - **greater**: lebih besar dari - **greater-equal**: lebih besar dari atau sama dengan - **less**: lebih kecil dari - **less-equal**: lebih kecil dari atau sama dengan |
| value | String | Tidak | Nilai pembanding. |
| conditionOperator | String | Tidak | Hubungan logis antara beberapa kondisi. Nilai yang valid: **and**: DAN (default) **or**: ATAU. Parameter ini berlaku ketika `conditions` berisi 2 kondisi. |
