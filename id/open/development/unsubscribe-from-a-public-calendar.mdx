Panggil API ini untuk berhenti berlangganan kalender publik.

## Permintaan

### Informasi dasar

| Bidang | Nilai |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/calendar/users/{userId}/calendars/{calendarId}/unsubscribe` |
| Metode HTTP | POST |
| Tipe aplikasi yang didukung | appType-Aplikasi internal　appType-Aplikasi perusahaan pihak ketiga　appType-Aplikasi personal pihak ketiga |
| Izin yang diperlukan | permission-Calendar.Calendar.Write-Izin tulis untuk kalender di aplikasi Kalender |

### Header permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses yang digunakan untuk memanggil API ini. Peroleh sebagai berikut:   - Untuk aplikasi internal, panggil API [Memperoleh access token aplikasi internal](/id/open/development/obtain-the-access-token-of-an-internal-app#). - Untuk aplikasi perusahaan pihak ketiga, panggil API [Memperoleh access token organisasi terotorisasi untuk aplikasi pihak ketiga](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#). - Untuk aplikasi personal pihak ketiga, panggil API [Memperoleh user token](/id/open/development/obtain-user-token#). |

### Parameter path

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| userId | String | Ya | unionId dari pihak yang berhenti berlangganan.   - Untuk aplikasi internal dan aplikasi perusahaan pihak ketiga, panggil API [Query detail pengguna](/id/open/development/query-user-details#) untuk memperoleh nilai parameter unionid. - Untuk aplikasi personal pihak ketiga, panggil API [Memperoleh profil pengguna dari Kontak](/id/open/development/dingtalk-retrieve-user-information#) untuk memperoleh nilai parameter unionId. |
| calendarId | String | Ya | ID kalender yang dilanggan. Pembuat kalender yang dilanggan atau pengguna yang telah berlangganan dapat memanggil API [Query kalender](/id/open/development/query-a-calendar#) untuk memperoleh nilai parameter event ID saat type adalah subscribed. |
