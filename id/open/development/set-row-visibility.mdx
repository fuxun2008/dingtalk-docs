Panggil API ini untuk mengatur visibilitas baris.

## Permintaan

### Informasi dasar

| Bidang | Nilai |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/doc/workbooks/{workbookId}/sheets/{sheetId}/setRowsVisibility` |
| Metode HTTP | POST |
| Tipe aplikasi yang didukung | appType-Aplikasi internal　appType-Aplikasi perusahaan pihak ketiga |
| Izin yang diperlukan | permission-Document.Workbook.Write-Izin tulis DingTalk Spreadsheet |

### Header permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Peroleh dengan cara berikut:   - Untuk aplikasi internal, panggil API [Memperoleh access token aplikasi internal](/id/open/development/obtain-the-access-token-of-an-internal-app#). - Untuk aplikasi perusahaan pihak ketiga, panggil API [Memperoleh access token organisasi yang memberikan otorisasi kepada aplikasi pihak ketiga](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#). |

### Parameter path

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| workbookId | String | Ya | ID file spreadsheet. `nodeId(dentryUuid)` yang dikembalikan oleh [API Knowledge Base](/id/open/development/knowledge-base-overview#) adalah `workbookId` spreadsheet. Peroleh dengan memanggil API [Memperoleh node](https://open.dingtalk.com/document/development/get-node#) dan [Membuat dokumen Knowledge Base](/id/open/development/create-team-space-document#). |
| sheetId | String | Ya | ID atau judul lembar kerja.   - Untuk aplikasi internal, panggil API [Memperoleh semua lembar kerja](/id/open/development/obtain-all-worksheets#) untuk mendapatkan ID, atau berikan judul lembar kerja. - Untuk aplikasi perusahaan pihak ketiga, kami sarankan untuk memberikan judul lembar kerja.   Langkah untuk melihat judul lembar kerja ditunjukkan pada gambar berikut. |

### Parameter query

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| operatorId | String | Ya | unionId operator. Panggil API [Kueri detail pengguna](/id/open/development/query-user-details#) untuk memperolehnya. |

### Isi permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| visibility | String | Ya | Visibilitas.   - **visible**: tampil. - **hidden**: tersembunyi. |
| row | Long | Ya | Cursor baris pertama yang akan ditampilkan atau disembunyikan, dimulai dari 0. |
| rowCount | Long | Ya | Jumlah baris yang akan ditampilkan atau disembunyikan. |
