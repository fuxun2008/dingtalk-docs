---
title: "Membuat filter"
description: "Panggil API ini untuk membuat filter global dengan rentang tertentu pada Lembar Kerja target di DingTalk Spreadsheet, cocok untuk skenario pemfilteran tingkat baris seperti menampilkan data berdasarkan wilayah atau status."
---

Panggil API ini untuk membuat filter global pada Lembar Kerja tertentu dari sebuah DingTalk Spreadsheet dan menentukan rentang filter. API ini cocok untuk skenario yang memerlukan pemfilteran data spreadsheet pada tingkat rekam, seperti hanya menampilkan data untuk wilayah atau status tertentu dalam laporan penjualan.

## Deskripsi panggilan API

- Setelah panggilan berhasil, Anda dapat memanggil API untuk mengatur kriteria filter guna mengonfigurasi aturan filter pada setiap kolom. Rekam yang tidak memenuhi kriteria akan otomatis disembunyikan.
- Setiap Lembar Kerja hanya dapat memiliki satu filter global. Jika filter sudah ada, akan dikembalikan sebuah error.

## Permintaan

### Informasi dasar

| Bidang | Nilai |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/doc/workbooks/{workbookId}/sheets/{sheetId}/createFilter` |

| Jenis aplikasi yang didukung | appType-Internal app |
| Izin | permission-Document.Workbook.Write-DingTalk Spreadsheet write permission |

### Header permintaan

### Parameter jalur

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| workbookId | String | Ya | ID file spreadsheet. `nodeId(dentryUuid)` yang dikembalikan oleh [API Knowledge Base](/id/open/development/knowledge-base-overview) adalah `workbookId` dari spreadsheet tersebut. Anda dapat memanggil API [Mendapatkan node](https://open.dingtalk.com/document/orgapp/get-node) dan [Membuat dokumen Knowledge Base](/id/open/development/create-team-space-document) untuk memperolehnya. |
| sheetId | String | Ya | ID atau nama Lembar Kerja. Panggil API [Mendapatkan semua Lembar Kerja](/id/open/development/obtain-all-worksheets) untuk memperoleh nilai parameter id atau name. |

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| operatorId | String | Ya | unionId dari operator.   - Panggil API [Mendapatkan informasi pengguna melalui kode login senyap](/id/open/development/obtain-the-userid-of-a-user-by-using-the-log-free) untuk memperoleh nilai parameter unionid. - Panggil API [Mengkueri detail pengguna](/id/open/development/query-user-details) untuk memperoleh nilai parameter unionid. ### Isi permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| range | String | Ya | Rentang filter, dalam notasi A1. Misalnya, `A1:D10` menunjukkan area dari A1 hingga D10. Rekam pertama dari rentang filter diperlakukan sebagai rekam judul dan tidak disertakan dalam perhitungan filter. |
| criteria | `Map<String, Object>` | Tidak | Opsional. Mengatur kriteria filter untuk setiap kolom saat membuat filter. Key adalah offset kolom (string yang dimulai dari 0, relatif terhadap bidang utama dari rentang filter), dan value adalah object kriteria filter (FilterCriteria) untuk kolom tersebut. Jika tidak diberikan, akan dibuat filter kosong. |
|  | Object | Tidak | Kriteria filter untuk kolom saat ini. |
| filterType | String | Tidak | Tipe filter. Nilai yang valid:   - **values**: Filter berdasarkan nilai. - **color**: Filter berdasarkan warna. - **condition**: Filter berdasarkan kondisi. |
| visibleValues | Array of String | Tidak | Nilai yang terlihat. |
| conditions | Array | Tidak | Array kondisi filter. Maksimal 2 kondisi diperbolehkan. Wajib hanya jika `filterType` adalah `condition`. |
| operator | String | Tidak | Operator kondisi. Nilai yang valid:   - **equal**: Sama dengan. - **not-equal**: Tidak sama dengan. - **contains**: Mengandung. - **not-contains**: Tidak mengandung. - **starts-with**: Diawali dengan. - **not-starts-with**: Tidak diawali dengan. - **ends-with**: Diakhiri dengan. - **not-ends-with**: Tidak diakhiri dengan. - **greater**: Lebih besar dari. - **greater-equal**: Lebih besar dari atau sama dengan. - **less**: Lebih kecil dari. - **less-equal**: Lebih kecil dari atau sama dengan. |
| value | String | Tidak | Nilai kondisi. |
| conditionOperator | String | Tidak | Hubungan antara beberapa kondisi: `"and"` (default) atau `"or"`. Wajib hanya jika `filterType` adalah `condition`. |
| backgroundColor | String | Tidak | Filter berdasarkan warna latar belakang. Nilai warna heksadesimal, seperti `"#FF0000"`. Wajib hanya jika `filterType` adalah `color`. |
| fontColor | String | Tidak | Filter berdasarkan warna font. Nilai warna heksadesimal, seperti `"#0000FF"`. Wajib hanya jika `filterType` adalah `color`. |
