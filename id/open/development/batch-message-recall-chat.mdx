title: "Tarik pesan Bot secara massal di obrolan satu lawan satu"
description: "Panggil API ini untuk menarik pesan Bot secara massal di obrolan satu lawan satu melalui robotCode dan processQueryKeys, cocok untuk menarik notifikasi yang salah kirim dalam 24 jam."
---

Gunakan API ini untuk menarik pesan Bot secara massal di obrolan satu lawan satu antara pengguna dan Bot. Kirimkan bidang bisnis seperti `robotCode` dan `processQueryKeys` melalui permintaan POST. API ini berlaku untuk skenario ketika organisasi perlu menarik pesan notifikasi yang salah dikirim dalam 24 jam.

## Permintaan

### Informasi dasar

| Bidang | Value |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/v1.0/robot/otoMessages/batchRecall |
| Metode HTTP | POST |
| Tipe aplikasi yang didukung | appType-Aplikasi internal　appType-Aplikasi perusahaan pihak ketiga |
| Izin yang diwajibkan | permission-qyapi_robot_sendmsg-Izin bagi Bot di organisasi Anda untuk mengirim pesan |

### Header permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Perolehlah sebagai berikut:   - Untuk aplikasi internal, panggil API [Memperoleh access token aplikasi internal](/id/open/development/obtain-the-access-token-of-an-internal-app#). - Untuk aplikasi perusahaan pihak ketiga, panggil API [Memperoleh access token organisasi yang diotorisasi ke aplikasi pihak ketiga](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#). |

### Isi permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| robotCode | String | Ya | Kode Bot. Untuk detailnya, lihat [ID Bot](/id/open/development/development-robot-overview#447ec33014hrl).  Nilai ini harus cocok dengan `robotCode` yang digunakan saat memanggil API [Bot mengirim pesan obrolan grup](/id/open/development/the-robot-sends-a-group-message#). |
| processQueryKeys | Array of String | Ya | Daftar pengenal pesan yang unik. Perolehlah melalui API [Kirim pesan Bot secara massal di obrolan satu lawan satu](/id/open/development/chatbots-send-one-on-one-chat-messages-in-batches#).    - Maksimal 20 entri per panggilan. - Anda dapat menarik pesan melalui `processQueryKey`-nya dalam 24 jam setelah dikirim. Pesan tidak dapat ditarik setelah 24 jam. |

## Respons

### Isi respons

| Nama | Tipe | Deskripsi |
| --- | --- | --- |
| successResult | Array of String | Daftar ID tugas pengiriman pesan yang berhasil ditarik.  **Catatan**  Ketika pesan yang dikirim oleh Bot ditarik, tidak ada pemberitahuan yang muncul di obrolan. |
| failedResult | `Map<String, String>` | Daftar ID tugas pengiriman pesan yang gagal ditarik, beserta alasan kegagalan yang bersangkutan. |

### Contoh isi respons

```text
HTTP/1.1 200 OK
Content-Type:application/json

{
  "successResult" : [ "b5fe1xxx" ],
  "failedResult" : { }
}
```

### Kode error

Jika pemanggilan API ini mengembalikan error, temukan solusinya di dokumen [Kode error global](/id/open/development/server-api-error-codes-1) berdasarkan pesan error.

| HttpCode | Kode error | Pesan error | Deskripsi |
| --- | --- | --- | --- |
| 400 | invalidParameter.robotCode | %s | Bot tidak ada. Periksa apakah Bot yang sesuai dengan `robotCode` telah dipasang di organisasi Anda. |
| 400 | invalidParameter.processQueryKeys.overMax | %s | Jumlah `processQueryKeys` melebihi batas maksimal 20. Pisahkan `processQueryKeys` menjadi beberapa array yang masing-masing tidak lebih dari 20 entri dan panggil API ini secara bertahap. |
| 400 | not.allowed.robotCode | %s | Pesan yang akan ditarik tidak dikirim oleh Bot yang sesuai dengan `robotCode`. Anda tidak memiliki izin untuk menarik pesan tersebut. Masukkan `robotCode` yang benar. |
| 400 | invalidParameter.param.invalid | %s | Parameter tidak valid. Periksa apakah parameter kosong. |
| 400 | invalidParameter.processQueryKey.missing | %s | `processQueryKey` tidak ada. |
| 400 | invalid.processQueryKey | %s | `processQueryKey` tidak valid. Periksa apakah `processQueryKey` sudah benar. |
| 400 | robot.processQueryKey.expired | %s | `processQueryKey` telah kedaluwarsa. Pesan tidak dapat ditarik. |
| 400 | notRevoke.all.messages | %s | Tidak semua pesan berhasil ditarik. |
| 500 | system.error | %s | Error sistem yang tidak diketahui. |
