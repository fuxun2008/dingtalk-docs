title: "Kueri saldo cuti"
description: "Gunakan API DingTalk untuk mengkueri saldo kuota cuti karyawan berdasarkan jenis cuti dan ID Karyawan dengan paginasi, hingga 50 data per panggilan."
---

Panggil API ini untuk mengkueri saldo cuti berdasarkan organisasi atau karyawan dengan paginasi. Setiap panggilan mengembalikan maksimal 50 data.

## Permintaan

| **Informasi dasar** | |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/topapi/attendance/vacation/quota/list |
| Metode HTTP | POST |
| Tipe aplikasi yang didukung | appType-Aplikasi internal appType-Aplikasi perusahaan pihak ketiga |
| Izin yang diperlukan | permission-qyapi_holiday_readonly-Izin baca cuti DingTalk |

### Parameter kueri

| Nama | Tipe | Wajib | Contoh | Deskripsi |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | bE74xxxx | Kredensial aplikasi yang digunakan untuk memanggil API ini.   - Aplikasi internal: Dapatkan dengan memanggil API [Mendapatkan access_token Aplikasi internal](/id/open/development/obtain-orgapp-token). - Aplikasi perusahaan pihak ketiga: Dapatkan dengan memanggil API Mendapatkan access_token Perusahaan Pihak Ketiga. |

### Isi permintaan

| Nama | Tipe | Wajib | Contoh | Deskripsi |
| --- | --- | --- | --- | --- |
| leave_code | String | Ya | f84a2xxxx | Pengidentifikasi unik jenis cuti. Panggil API [Kueri daftar aturan cuti](/id/open/development/holiday-type-query) untuk mendapatkan nilai leave_code. |
| op_userid | String | Ya | user01 | ID pengguna admin di organisasi Anda yang memiliki izin aplikasi untuk **Persetujuan OA**. |
| userids | String | Ya | user02,user03 | Daftar ID Karyawan yang akan dikueri. |
| offset | Number | Ya | 0 | Offset paginasi. Harus berupa integer non-negatif yang dimulai dari 0. |
| size | Number | Ya | 10 | Ukuran halaman. Nilai maksimum: 50. |

### Contoh permintaan

```curl
curl -X POST "https://api.dingtalk.io/topapi/attendance/vacation/quota/list" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=48acxxxx0dbdbee' \
-d 'leave_code=f84a2829-d245-4312-9ff2-0653e5b3abb2' \
-d 'offset=0' \
-d 'op_userid=zhangsan' \
-d 'size=10' \
-d 'userids=zhangsan%2Clisi'
```

Java

```text
DingTalkClient client = new DefaultDingTalkClient("https://api.dingtalk.io/topapi/attendance/vacation/quota/list");
OapiAttendanceVacationQuotaListRequest req = new OapiAttendanceVacationQuotaListRequest();
req.setLeaveCode("f84a2xxxx");
req.setOpUserid("user01");
req.setUserids("user02,user03");
req.setOffset(0L);
req.setSize(10L);
OapiAttendanceVacationQuotaListResponse rsp = client.execute(req, access_token);
System.out.println(rsp.getBody());
```

## Respons

### Isi respons

| Nama | Tipe | Contoh | Deskripsi |
| --- | --- | --- | --- |
| result | OapiLeaveQuotaUserListVo |  | Hasil yang dikembalikan. |
| has_more | Boolean | false | Menunjukkan apakah masih ada data lainnya.   - **true**: Masih ada data lainnya. - **false**: Tidak ada data lainnya. |
| leave_quotas | Leavequotas[] |  | Daftar saldo cuti. |
| userid | String | user01 | ID pengguna karyawan. |
| leave_code | String | f84a2xxxx | Pengidentifikasi unik jenis cuti. |
| quota_cycle | String | 2019 | Siklus yang berlaku untuk kuota. |
| quota_id | String | f8abb2xxxx | Pengidentifikasi unik kuota. |
| start_time | Number | 1653851001000 | Waktu mulai masa berlaku cuti, berupa stempel waktu dalam milidetik. |
| end_time | Number | 1753851001000 | Waktu berakhir masa berlaku kuota, berupa stempel waktu dalam milidetik. |
| quota_num_per_hour | Number | 1000 | Total kuota, dihitung dalam jam.  **Catatan**  Jika jenis cuti dihitung dalam jam, nilai ini tidak kosong dan dinyatakan dalam perseratus jam.  Contoh: 1000 = 10 jam. |
| quota_num_per_day | Number | 1000 | Total kuota, dihitung dalam hari.  **Catatan**  Jika jenis cuti dihitung dalam hari, nilai ini tidak kosong dan dinyatakan dalam perseratus hari.  Contoh: 1000 = 10 hari. |
| used_num_per_day | Number | 100 | Kuota yang telah digunakan, dihitung dalam hari.  **Catatan**  Jika jenis cuti dihitung dalam hari, nilai ini tidak kosong dan dinyatakan dalam perseratus hari.  Contoh: 100 = 1 hari. |
| used_num_per_hour | Number | 1000 | Kuota yang telah digunakan, dihitung dalam jam.  **Catatan**  Jika jenis cuti dihitung dalam jam, nilai ini tidak kosong dan dinyatakan dalam perseratus jam.  Contoh: 1000 = 10 jam. |
| errcode | Number | 0 | Kode pengembalian. |
| errmsg | String | ok | Deskripsi kode pengembalian. |
| success | Boolean | true | Menunjukkan apakah panggilan berhasil.   - **true**: Ya - **false**: Tidak |
