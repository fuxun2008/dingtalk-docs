Panggil API ini untuk memperbarui pengaturan waktu absen pada shift absensi. Saat ini, API ini hanya mendukung pengaturan apakah absen wajib dilakukan di suatu titik absen.

## Permintaan

| **Informasi dasar** | |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/topapi/attendance/shift/updatepunches |
| Metode HTTP | POST |
| Jenis aplikasi yang didukung | appType-Aplikasi internal |
| Izin yang diperlukan | permission-qyapi_attendance_group_manage-Izin kelola grup absensi |

### Parameter query

| Nama | Tipe | Wajib | Contoh | Deskripsi |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | af21axxx | Kredensial aplikasi yang digunakan untuk memanggil API ini. Dapatkan dengan memanggil API [Mendapatkan access_token aplikasi internal](/id/open/development/obtain-orgapp-token). |

### Isi permintaan

| Nama | Tipe | Wajib | Contoh | Deskripsi |
| --- | --- | --- | --- | --- |
| op_user_id | String | Ya | user456 | userId operator. |
| punches | TopPunchVO[] | Tidak |  | Informasi titik absen. |
| id | Number | Ya | 123 | ID titik absen. Dapatkan nilai id dengan memanggil API [Mendapatkan detail shift](/id/open/development/shift-query). |
| free_check | Boolean | Ya | true | Menentukan apakah absen tidak diwajibkan.   - **true**: Pembebasan absen aktif. - **false**: Pembebasan absen nonaktif. |
| shift_id | Number | Ya | 456 | ID shift. Dapatkan nilai id dengan memanggil API [Mendapatkan ringkasan shift](/id/open/development/enterprise-shift-query-in-batches). |

### Contoh permintaan

```curl
curl -X POST "https://api.dingtalk.io/topapi/attendance/shift/updatepunches" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=16869xxx0e890' \
-d 'op_user_id=dd' \
-d 'punches=null' \
-d 'shift_id=456'
```

Java

```text
DingTalkClient client = new DefaultDingTalkClient("https://api.dingtalk.io/topapi/attendance/shift/updatepunches");
OapiAttendanceShiftUpdatepunchesRequest req = new OapiAttendanceShiftUpdatepunchesRequest();
List<TopPunchVO> punchVOS = new ArrayList<>();
TopPunchVO punchVO = new TopPunchVO();
punchVO.setFreeCheck(true);
punchVO.setId(373271823L);
req.setPunches(punchVOS);
req.setOpUserId("user456");
req.setShiftId(712550377L);
OapiAttendanceShiftUpdatepunchesResponse rsp = client.execute(req, access_token);
System.out.println(rsp.getBody());
```

## Respons

### Isi respons

| Nama | Tipe | Contoh | Deskripsi |
| --- | --- | --- | --- |
| success | Boolean | true | Menunjukkan apakah panggilan berhasil.   - **true**: Berhasil - **false**: Gagal |
| errcode | Number | 0 | Kode respons. |
| errmsg | String | Error sistem | Pesan error yang dikembalikan saat panggilan gagal. |
| request_id | String | 5moh5icna65x | ID permintaan. |

### Contoh isi respons

```json
{
  "errcode": 0,
  "success": true,
  "request_id": "ed67bcymo0bw"
}
```

### Kode error

Jika terjadi error saat memanggil API ini, cari solusinya di dokumen [Kode error global](/id/open/development/server-api-error-codes-1) berdasarkan pesan error yang diterima.
