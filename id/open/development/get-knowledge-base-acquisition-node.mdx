Panggil API ini untuk mendapatkan informasi tentang sebuah node tunggal berdasarkan unionId operator dan ID node.

## Permintaan

### Informasi dasar

| Bidang | Nilai |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v2.0/wiki/nodes/{nodeId}` |
| Metode HTTP | GET |
| Tipe aplikasi yang didukung | appType-Aplikasi internal　appType-Aplikasi perusahaan pihak ketiga |
| Izin yang diperlukan | permission-Wiki.Node.Read-Izin baca node Knowledge Base |

### Header permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Dapatkan dengan cara berikut:   - Untuk aplikasi internal, panggil API [Mendapatkan access token aplikasi internal](/id/open/development/obtain-the-access-token-of-an-internal-app#). - Untuk aplikasi perusahaan pihak ketiga, panggil API [Mendapatkan access token perusahaan terotorisasi dari aplikasi pihak ketiga](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#). |

### Parameter path

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| nodeId | String | Ya | ID node (dentryUuid node). Untuk mendapatkannya, panggil API [Mendapatkan daftar node](/id/open/development/get-node-list#) dan gunakan nilai dari bidang `nodeId` pada respons. |

### Parameter query

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| withStatisticalInfo | Boolean | Tidak | Apakah akan mendapatkan informasi statistik:   - true: Mendapatkan. - false: Tidak mendapatkan.       Default: false. |
| withPermissionRole | Boolean | Tidak | Apakah akan mendapatkan informasi izin:   - true: Mendapatkan. - false: Tidak mendapatkan.       Default: false. |
| operatorId | String | Ya | unionId operator. |

## Respons

### Isi respons

| Nama | Tipe | Deskripsi |
| --- | --- | --- |
| node | Object | Node. |
| nodeId | String | ID node (dentryUuid). |
| workspaceId | String | ID Knowledge Base (spaceUuid). |
| name | String | Nama. |
| size | Long | Ukuran. |
| type | String | Tipe. Nilai enum:   - **FILE**: File. - **FOLDER**: Folder. |
| category | String | Kategori. Nilai enum:   - **ALIDOC**: DingTalk Docs. - **DOCUMENT**: Dokumen lokal. - **IMAGE**: Gambar. - **VIDEO**: Video. - **AUDIO**: Audio. - **ARCHIVE**: File arsip. - **OTHER**: Tipe lain. |
| extension | String | Ekstensi file. |
| url | String | URL akses. |
| creatorId | String | userId pembuat. |
| modifierId | String | userId pengubah terakhir. |
| createTime | String | Waktu pembuatan. |
| modifiedTime | String | Waktu modifikasi. |
| hasChildren | Boolean | Apakah node memiliki node anak. |
| statisticalInfo | Object | Informasi statistik. |
| wordCount | Long | Jumlah kata. |
| permissionRole | String | Peran izin pengguna saat ini pada node Knowledge Base. Nilai enum:   - **OWNER**: Pemilik. - **MANAGER**: Pengelola. - **EDITOR**: Editor. - **DOWNLOADER**: Penampil dengan izin unduh. - **READER**: Penampil (hanya lihat). - **NONE**: Tanpa izin. |
