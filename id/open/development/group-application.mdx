**Peringatan**

Untuk meningkatkan pengalaman pengguna, produk Cool App telah ditingkatkan, dan dokumen ini dimigrasikan pada 2 November 2022. Dokumen ini tidak lagi dikelola. Lihat Proses pengembangan Cool App Obrolan Grup.

## Proses pengembangan ekstensi grup

## Pengantar proses pengembangan ekstensi grup

Sebelum memulai, pastikan Anda telah menyelesaikan persiapan untuk [Menjadi Developer DingTalk](/id/open/dingstart/become-a-dingtalk-developer). Proses untuk mengembangkan aplikasi grup adalah sebagai berikut:

1. Mengembangkan Aplikasi internal. Pengembangan ekstensi grup harus didasarkan pada aplikasi internal. Jika Anda tidak memiliki aplikasi internal, buat aplikasi. Jika sudah memilikinya, Anda dapat langsung menggunakannya.
2. Mengonfigurasi Push pesan. Di **Push pesan**, ikat dan kembangkan Bot.
3. Mengonfigurasi Informasi dasar ekstensi grup. Di **Ekstensi Cool App** pada aplikasi internal, aktifkan ekstensi grup dan konfigurasikan informasi dasar. Setelah berhasil dibuat, Anda dapat memperoleh kode aplikasi ekstensi grup.
4. Mengembangkan Kartu interaktif (opsional). Dengan mengikat Bot, Anda dapat mengirim Kartu interaktif dan lainnya.
5. Mengaktifkan Aplikasi ekstensi grup. Setelah pengembangan aplikasi grup selesai, Anda perlu **menambahkannya ke grup** dan mengaktifkannya di Cool App Center.
6. Menggunakan Aplikasi ekstensi grup. Di batang aplikasi grup pada Grup Internal, tampilkan dan gunakan Cool App.
