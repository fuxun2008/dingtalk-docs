**Peringatan**

Untuk meningkatkan pengalaman pengguna, produk Cool App telah ditingkatkan, dan dokumen ini dimigrasikan pada 2 November 2022. Dokumen ini tidak lagi dikelola. Lihat [Proses pengembangan Cool App Obrolan Grup](https://open.dingtalk.com/document/org/create-a-process#).

## Proses pengembangan ekstensi grup

## Pengantar proses pengembangan ekstensi grup

Sebelum memulai, pastikan Anda telah menyelesaikan persiapan untuk [Menjadi Developer DingTalk](https://open.dingtalk.com/document/app/become-a-dingtalk-developer#topic-2024337). Proses untuk mengembangkan aplikasi grup adalah sebagai berikut:

1. [Mengembangkan Aplikasi internal](https://open.dingtalk.com/document/org/create-orgapp#topic-2024342). Pengembangan ekstensi grup harus didasarkan pada aplikasi internal. Jika Anda tidak memiliki aplikasi internal, [buat aplikasi](https://open.dingtalk.com/document/org/create-orgapp#topic-2024342). Jika sudah memilikinya, Anda dapat langsung menggunakannya.
2. [Mengonfigurasi Push pesan](https://open.dingtalk.com/document/org/configure-push-settings#topic-2199272). Di **Push pesan**, ikat dan kembangkan Bot.
3. [Mengonfigurasi Informasi dasar ekstensi grup](https://open.dingtalk.com/document/org/configure-the-basic-information-of-the-group-application#topic-2199273). Di **Ekstensi Cool App** pada aplikasi internal, aktifkan ekstensi grup dan konfigurasikan informasi dasar. Setelah berhasil dibuat, Anda dapat memperoleh kode aplikasi ekstensi grup.
4. [Mengembangkan Kartu interaktif](https://open.dingtalk.com/document/org/interactive-card#topic-2199274) (opsional). Dengan mengikat Bot, Anda dapat mengirim Kartu interaktif dan lainnya.
5. [Mengaktifkan Aplikasi ekstensi grup](https://open.dingtalk.com/document/org/install-group-applications#topic-2199277). Setelah pengembangan aplikasi grup selesai, Anda perlu **menambahkannya ke grup** dan mengaktifkannya di Cool App Center.
6. [Menggunakan Aplikasi ekstensi grup](https://open.dingtalk.com/document/org/install-group-applications#topic-2199277). Di batang aplikasi grup pada Grup Internal, tampilkan dan gunakan Cool App.
