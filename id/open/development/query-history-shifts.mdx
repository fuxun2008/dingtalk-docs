title: "Kueri riwayat shift"

---

Panggil API ini untuk mengkueri riwayat shift berdasarkan ID shift dan versinya. Respons mencakup nama shift, pengaturan shift, waktu absen, dan waktu istirahat.

## Permintaan

| **Informasi dasar** | |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/topapi/attendance/shift/history/query |
| Metode HTTP | POST |
| Tipe aplikasi yang didukung | appType-Aplikasi internal |
| Izin | permission-qyapi_attendance_group_read-Izin kueri grup absensi |

### Parameter kueri

| Nama | Tipe | Wajib | Contoh | Deskripsi |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | 73e9xxx | Kredensial aplikasi yang digunakan untuk memanggil API ini. Dapatkan dengan memanggil API [Mendapatkan access_token Aplikasi internal](/id/open/development/obtain-orgapp-token). |

### Isi permintaan

| Nama | Tipe | Wajib | Contoh | Deskripsi |
| --- | --- | --- | --- | --- |
| op_user_id | String | Ya | user123 | userId operator. |
| shift_id | Number | Ya | 628380875 | ID shift. Dapatkan nilai id dengan memanggil API [Mendapatkan ringkasan shift](/id/open/development/enterprise-shift-query-in-batches). |
| version | Number | Ya | 624190327 | Versi shift. Dapatkan nilai shift_version dengan memanggil API [Kueri massal informasi penjadwalan shift pengguna](/id/open/development/query-batch-scheduling-information). |

### Contoh permintaan

```curl
curl -X POST "https://api.dingtalk.io/topapi/attendance/shift/history/query" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=e56f7xxxxeb7ef1' \
-d 'op_user_id=dd_dd' \
-d 'shift_id=2445' \
-d 'version=222'
```

Java

```java
DingTalkClient client = new DefaultDingTalkClient("https://api.dingtalk.io/topapi/attendance/shift/history/query");
OapiAttendanceShiftHistoryQueryRequest req = new OapiAttendanceShiftHistoryQueryRequest();
req.setOpUserId("user456");
req.setShiftId(715390132L);
req.setVersion(624190327L);
OapiAttendanceShiftHistoryQueryResponse rsp = client.execute(req, access_token);
System.out.println(rsp.getBody());
```

Python

```python
import dingtalk.api

req=dingtalk.api.OapiAttendanceShiftHistoryQueryRequest("https://api.dingtalk.io/topapi/attendance/shift/history/query")

req.op_user_id="dd_dd"
req.shift_id=2445
req.version=222
try:
  resp= req.getResponse(access_token)
  print(resp)
except Exception,e:
  print(e)
```

PHP

```php
include "TopSdk.php";
date_default_timezone_set('Asia/Shanghai');

$c = new DingTalkClient(DingTalkConstant::$CALL_TYPE_OAPI, DingTalkConstant::$METHOD_POST , DingTalkConstant::$FORMAT_JSON);

$req->setOpUserId("dd_dd");
$req->setShiftId("2445");
$req->setVersion("222");
$resp = $c->execute($req, $access_token, "https://api.dingtalk.io/topapi/attendance/shift/history/query");
```

C#

```csharp
IDingTalkClient client = new DefaultDingTalkClient("https://api.dingtalk.io/topapi/attendance/shift/history/query");
OapiAttendanceShiftHistoryQueryRequest req = new OapiAttendanceShiftHistoryQueryRequest();
req.OpUserId = "dd_dd";
req.ShiftId = 2445L;
req.Version = 222L;
OapiAttendanceShiftHistoryQueryResponse rsp = client.Execute(req, access_token);
Console.WriteLine(rsp.Body);
```

## Respons

### Isi respons

| Nama | Tipe | Contoh | Deskripsi |
| --- | --- | --- | --- |
| result | TopShiftVo |  | Hasil kueri. |
| shift_group_name | String | Shift siang reguler | Nama grup shift. |
| corp_id | String | dinge87fxxx | ID organisasi (corpId). |
| shift_setting | TopShiftSettingVo |  | Pengaturan shift. |
| shift_id | Number | 628380875 | ID shift. |
| gmt_modified | Date | 2021-01-14 14:21:03 | Waktu terakhir shift diubah. |
| corp_id | String | dinge87fxxx | ID organisasi (corpId). |
| is_deleted | String | N | Penanda penghapusan. |
| work_time_minutes | Number | 480 | Durasi kerja, dalam menit. Nilai -1 menunjukkan fitur ini dinonaktifkan. |
| id | Number | 350530359 | ID pengaturan shift. Saat ini tidak digunakan. |
| attend_days | String | 21 | Jumlah hari kehadiran untuk shift ini. |
| gmt_create | Date | 2021-01-14 14:18:08 | Waktu pembuatan. |
| name | String | Shift siang reguler | Nama shift. |
| id | Number | 241120079 | ID shift. |
| sections | TopSectionVo[] |  | Sesi absen. |
| punches | TopPunchVo[] |  | Titik absen. |
| check_type | String | OnDuty | Tipe absen:   - **OnDuty**: Absen masuk - **OffDuty**: Absen pulang |
| end_min | Number | 1 | Batas keterlambatan maksimum yang diizinkan untuk absen, dalam menit. |
| across | Number | 0 | Apakah shift berlanjut ke hari berikutnya:   - **0**: Tidak berlanjut ke hari berikutnya - **1**: Berlanjut ke hari berikutnya |
| check_time | Date | 1970-01-01 09:00:00 | Waktu absen. |
| permit_minutes | Number | 60 | Durasi yang diizinkan untuk keterlambatan atau pulang lebih awal. |
| free_check | Boolean | false | Apakah dibebaskan dari absen:   - **true**: Tidak wajib absen - **false**: Wajib absen |
| id | Number | 376955859 | ID titik absen. Saat ini tidak digunakan. |
| begin_min | Number | demo | Batas paling awal yang diizinkan untuk absen lebih dulu, dalam menit. |
| work_time_minutes | Number | 480 | Durasi kerja, dalam menit. |
| rests | TopRestVo[] |  | Sesi istirahat. |
| check_type | String | OnDuty | Tipe istirahat:   - **OnDuty**: Mulai istirahat - **OffDuty**: Selesai istirahat |
| across | Number | 0 | Apakah istirahat berlanjut ke hari berikutnya, yaitu waktu istirahat jatuh pada hari berikutnya:   - **0**: Tidak berlanjut ke hari berikutnya - **1**: Berlanjut ke hari berikutnya |
| check_time | Date | 1970-01-01 12:00:00 | Waktu istirahat. |
| id | Number | 376955861 | ID titik istirahat. |
| id | Number | 22979360 | ID sesi absen. Setiap pasangan absen masuk dan absen pulang membentuk satu sesi. Satu shift dapat memiliki beberapa sesi. |
| shift_group_id | Number | 22979 | ID grup shift. |
| success | Boolean | true | Apakah panggilan berhasil.   - **true**: Berhasil - **false**: Gagal |
| errcode | Number | 0 | Kode respons. |
| errmsg | String | ok | Deskripsi kode respons. |
| request_id | String | q3ef3y3sogkd | ID permintaan. |
