Panggil API ini untuk membuat sebuah acara.

## Deskripsi panggilan API

- Setiap operasi peserta acara mendukung hingga 500 pengguna, dan satu acara mendukung total hingga 5.000 peserta.
- Untuk menambahkan atau menghapus peserta acara, kami menyarankan menggunakan API [Tambahkan peserta acara](/id/open/development/add-schedule-participant#) dan [Hapus peserta acara](/id/open/development/delete-schedule-participant#).

## Permintaan

### Informasi dasar

| Bidang | Nilai |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/calendar/users/{userId}/calendars/{calendarId}/events` |
| Metode HTTP | POST |
| Jenis aplikasi yang didukung | appType-Aplikasi internal　appType-Aplikasi perusahaan pihak ketiga　appType-Aplikasi personal pihak ketiga |
| Izin yang diperlukan | permission-Calendar.Event.Write-Izin tulis untuk acara di aplikasi Calendar |

### Header permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| x-client-token | String | Tidak | Pemeriksaan idempotensi.    - `x-client-token` yang sama mewakili permintaan yang sama. - Kedaluwarsa setelah 1 hari. |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Peroleh dengan cara berikut:   - Untuk aplikasi internal, panggil API [Peroleh access token aplikasi internal](/id/open/development/obtain-the-access-token-of-an-internal-app#). - Untuk aplikasi perusahaan pihak ketiga, panggil API [Peroleh access token perusahaan resmi (aplikasi Marketplace)](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#). - Untuk aplikasi personal pihak ketiga, panggil API [Peroleh user token](/id/open/development/obtain-user-token#). |

### Parameter jalur

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| userId | String | Ya | unionId dari penyelenggara acara.   - Untuk aplikasi internal dan aplikasi perusahaan pihak ketiga, panggil API [Kueri detail pengguna](/id/open/development/query-user-details#) untuk memperoleh nilai unionid. - Untuk aplikasi personal pihak ketiga, panggil API [Peroleh profil pengguna di Kontak](/id/open/development/dingtalk-retrieve-user-information#) untuk memperoleh nilai unionId. |
| calendarId | String | Ya | ID kalender tempat acara berada. Selalu diatur ke **primary**, yang mewakili kalender utama pengguna. |

### Isi permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| summary | String | Ya | Judul acara. Maksimal 2.048 karakter. |

| start | Object | Ya | Waktu mulai acara. |

| dateTime | String | Tidak | Waktu mulai acara dalam format tanggal-waktu ISO-8601.    - Harus dikosongkan untuk acara sepanjang hari. - Wajib untuk acara yang bukan sepanjang hari. |

| uiStatus | String | Tidak | Status komponen. Nilai yang valid:   - **hide**: Disembunyikan. - **disable**: Dinonaktifkan (didukung pada halaman detail baru; tidak didukung pada versi lama, di mana komponen akan disembunyikan).    Komponen tombol: tidak dapat diklik.   Komponen bagian: tidak dapat berinteraksi.
