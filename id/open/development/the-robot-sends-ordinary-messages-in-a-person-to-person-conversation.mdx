Panggil API ini untuk mengirim pesan teks biasa dari Bot dalam obrolan satu lawan satu.

## Deskripsi panggilan API

API ini hanya dapat digunakan dalam skenario coolapp pesan langsung. Untuk detailnya, lihat [Coolapp pesan langsung](https://open.dingtalk.com/document/dingstart/private-chat-coolapp-overview#).

## Permintaan

### Informasi dasar

| Bidang | Nilai |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/v1.0/robot/privateChatMessages/send |
| Metode HTTP | POST |
| Tipe aplikasi yang didukung | appType-Aplikasi internal　appType-Aplikasi perusahaan pihak ketiga |
| Persyaratan izin | permission-qyapi_robot_sendmsg-Izin untuk Bot di organisasi Anda mengirim pesan |

### Header permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses yang digunakan untuk memanggil API ini. Dapatkan sebagai berikut:   - Untuk aplikasi internal, panggil API [Dapatkan access token aplikasi internal](/id/open/development/obtain-the-access-token-of-an-internal-app#). - Untuk aplikasi perusahaan pihak ketiga, panggil API [Dapatkan access token organisasi yang telah memberi otorisasi ke aplikasi pihak ketiga](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#). |

### Isi permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| msgParam | String | Ya | Parameter templat pesan. Untuk detailnya, lihat [Tipe pesan yang dikirim oleh Bot perusahaan](https://open.dingtalk.com/document/dingstart/types-of-messages-sent-by-robots#). |
| msgKey | String | Ya | Kunci templat pesan. Untuk detailnya, lihat [Tipe pesan yang dikirim oleh Bot perusahaan](https://open.dingtalk.com/document/dingstart/types-of-messages-sent-by-robots#). |
| openConversationId | String | Ya | ID obrolan. Dapatkan nilai OpenConversationId dengan memanggil [Instal coolapp ke obrolan pesan langsung secara massal](https://open.dingtalk.com/document/development/batch-chat-session#) atau dengan mendengarkan [Peristiwa coolapp pesan langsung](https://open.dingtalk.com/document/development/org-event-overview#260a4e7084gs2). |
| robotCode | String | Ya | Kode Bot. Gunakan robotCode dari Bot perusahaan untuk parameter ini. Untuk detailnya, lihat [ID Bot](https://open.dingtalk.com/document/development/robot-overview#). |
| coolAppCode | String | Ya | Kode coolapp. |
