Panggil API ini untuk mengatur mode pewarisan izin berdasarkan UUID file, unionId operator, dan mode pewarisan.

## Permintaan

### Informasi dasar

| Bidang | Nilai |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v2.0/storage/spaces/dentries/{dentryUuid}/permissions/inheritances` |
| Metode HTTP | PUT |
| Tipe aplikasi yang didukung | appType-Aplikasi internal |
| Izin yang diperlukan | permission-Storage.Permission.Write-Izin tulis untuk informasi otorisasi penyimpanan organisasi |

### Header permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Dapatkan dengan memanggil API [Mendapatkan access token aplikasi internal](/id/open/development/obtain-the-access-token-of-an-internal-app). |

### Parameter jalur

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| dentryUuid | String | Ya | UUID file. Dapatkan nilai parameter respons `dentryUuid` dengan memanggil API [Pencarian File](/id/open/development/search-for-files) atau [Mendapatkan informasi dentryUuid](/id/open/development/api-getuuidbydentryid). |

### Parameter kueri

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| unionId | String | Ya | unionId pengguna. Dapatkan nilai parameter unionid dengan memanggil API [Mengueri detail pengguna](/id/open/development/query-user-details). |

### Isi permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| inheritance | String | Ya | Mode pewarisan izin. Nilai enum:   - **PASS_ON**: Diteruskan. File atau folder saat ini mewarisi izin dari semua node induk, yang kemudian digabungkan dengan izin pada file atau folder saat ini. Untuk pengguna yang sama, izin tertinggi yang diterapkan. - **BREAK**: Diputus. Pewarisan izin dihentikan pada node saat ini.        - Break tidak didukung untuk OWNER dan MANAGER. - Ini adalah mode pewarisan izin default. |
