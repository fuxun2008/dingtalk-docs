Panggil API ini untuk memperbarui informasi satu kalender langganan.

## Permintaan

### Informasi dasar

| Bidang | Value |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/calendar/users/{userId}/subscribedCalendars/{calendarId}` |
| Metode HTTP | PUT |
| Tipe aplikasi yang didukung | appType-Aplikasi internal　appType-Aplikasi perusahaan pihak ketiga　appType-Aplikasi personal pihak ketiga |
| Izin yang diperlukan | permission-Calendar.Calendar.Write-Izin tulis untuk aplikasi Kalender |

### Header permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Dapatkan sebagai berikut:   - Untuk aplikasi internal, panggil [Memperoleh access token aplikasi internal](/id/open/development/obtain-the-access-token-of-an-internal-app#). - Untuk aplikasi perusahaan pihak ketiga, panggil [Memperoleh access token perusahaan yang diberi otorisasi untuk aplikasi pihak ketiga](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#). - Untuk aplikasi personal pihak ketiga, panggil [Memperoleh user token](/id/open/development/obtain-user-token#). |

### Parameter path

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| calendarId | String | Ya | ID kalender langganan. Panggil [Membuat kalender langganan](/id/open/development/create-subscription-calendar#) untuk memperoleh value parameter calendarId. |
| userId | String | Ya | unionId pembuat kalender atau co-editor.   - Untuk aplikasi internal dan aplikasi perusahaan pihak ketiga, panggil [Mengkueri detail pengguna](/id/open/development/query-user-details#) untuk memperoleh value parameter unionid. - Untuk aplikasi personal pihak ketiga, panggil [Memperoleh profil pengguna Kontak](/id/open/development/dingtalk-retrieve-user-information#) untuk memperoleh value parameter unionId. |

### Isi permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| name | String | Tidak | Judul kalender langganan. |
| description | String | Tidak | Deskripsi kalender langganan. |
| managers | Array of String | Tidak | Daftar unionId co-editor kalender.   - Untuk aplikasi internal dan aplikasi perusahaan pihak ketiga, panggil [Mengkueri detail pengguna](/id/open/development/query-user-details#) untuk memperoleh value parameter unionid. - Untuk aplikasi personal pihak ketiga, panggil [Memperoleh profil pengguna Kontak](/id/open/development/dingtalk-retrieve-user-information#) untuk memperoleh value parameter unionId. |
| subscribeScope | Object | Tidak | Cakupan langganan kalender. |
| unionIds | Array of String | Tidak | unionId pengguna yang dapat berlangganan kalender.   - Untuk aplikasi internal dan aplikasi perusahaan pihak ketiga, panggil [Mengkueri detail pengguna](/id/open/development/query-user-details#) untuk memperoleh value parameter unionid. - Untuk aplikasi personal pihak ketiga, panggil [Memperoleh profil pengguna Kontak](/id/open/development/dingtalk-retrieve-user-information#) untuk memperoleh value parameter unionId. |
| openConversationIds | Array of String | Tidak | Daftar OpenConversationId grup yang dapat berlangganan kalender ini.   - Untuk aplikasi internal, panggil [Memperoleh OpenConversationId obrolan grup](/id/open/development/obtain-group-openconversationid#) untuk memperoleh value parameter openConversationId. - Untuk aplikasi perusahaan pihak ketiga, panggil [Membuat grup](https://open.dingtalk.com/document/development/create-a-scene-group-v2#) untuk memperoleh value parameter open_conversation_id.        - Anda harus meneruskan OpenConversationId grup tempat pembuat acara langganan berada. - Untuk aplikasi personal pihak ketiga, parameter ini tidak diperlukan. |
| corpIds | Array of String | Tidak | Daftar corpId organisasi yang dapat berlangganan kalender ini. Masuk ke [DingTalk Developer Console](https://open-dev.dingtalk.io/#/) dan lihat ID organisasi Anda di halaman Beranda.      Anda harus meneruskan corpId organisasi tempat pembuat acara langganan berada. |
