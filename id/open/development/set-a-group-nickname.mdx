title: "Memperbarui nama panggilan anggota grup"
description: "Panggil API ini untuk memperbarui nama panggilan anggota di dalam grup DingTalk, berguna saat admin menyeragamkan nama panggilan atau anggota mengubah nama panggilannya sendiri."
---

Panggil API ini untuk memperbarui nama panggilan anggota grup di dalam sebuah obrolan. Ini berlaku untuk skenario ketika admin grup menyeragamkan nama panggilan anggota atau ketika anggota mengubah nama panggilannya sendiri.

## Permintaan

| **Informasi dasar** | |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/topapi/chat/updategroupnick |
| Metode HTTP | POST |
| Tipe aplikasi yang didukung | appType-Internal app |
| Izin yang diperlukan | permission-qyapi_chat_manage-DingTalk group basic information management permission |

### Parameter kueri

| Nama | Tipe | Wajib | Contoh | Deskripsi |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | beE3xxxx | Kredensial aplikasi yang digunakan untuk memanggil API ini. Dapatkan melalui API untuk memperoleh [access_token dari aplikasi internal](/id/open/development/obtain-orgapp-token). |

### Isi permintaan

| Nama | Tipe | Wajib | Contoh | Deskripsi |
| --- | --- | --- | --- | --- |
| userid | String | Ya | user123 | userId dari anggota grup yang nama panggilannya akan diperbarui. Anda dapat memperoleh userId anggota melalui API [Memperoleh informasi obrolan grup](/id/open/development/obtain-a-group-session). |
| chatid | String | Ya | chate3929fxxxx | ID obrolan grup. Anda dapat memperoleh nilai chatid melalui API untuk membuat grup. |
| group_nick | String | Ya | DingTalk Assistant | Nama panggilan anggota di dalam grup. |

### Contoh permintaan

```curl
curl -X POST "https://api.dingtalk.io/topapi/chat/updategroupnick" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=61a72xxxx8d62' \
-d 'chatid=0' \
-d 'group_nick=nick' \
-d 'userid=0'
```

Java

```text
DingTalkClient client = new DefaultDingTalkClient("https://api.dingtalk.io/topapi/chat/updategroupnick");
OapiChatUpdategroupnickRequest req = new OapiChatUpdategroupnickRequest();
req.setUserid("user123");
req.setChatid("chate39f540d572b71cf97a556d95929fxxxx");
req.setGroupNick("DingTalk Assistant");
OapiChatUpdategroupnickResponse rsp = client.execute(req, access_token);
System.out.println(rsp.getBody());
```

## Respons

### Isi respons

| Nama | Tipe | Contoh | Deskripsi |
| --- | --- | --- | --- |
| errcode | Number | 0 | Kode pengembalian. |
| errmsg | String | ok | Deskripsi kode pengembalian. |
| success | Boolean | true | Menunjukkan apakah tindakan berhasil.   - **true**: Berhasil - **false**: Gagal |
| request_id | String | id1aatxt9mco | ID permintaan. |

### Contoh respons

```json
{
  "errcode": 0,
  "errmsg": "ok",
  "success": true,
  "request_id": "id1aatxt9mco"
}
```

### Kode error

Jika terjadi error saat Anda memanggil API ini, lihat dokumen [Kode error global](/id/open/development/server-api-error-codes-1) untuk menemukan solusi berdasarkan pesan error.

| Kode error (errorcode) | Pesan error (errmsg) | Solusi |
| --- | --- | --- |
| 40003 | Invalid userid | Pastikan userid dimasukkan dengan benar. |
| 34001 | Invalid chatid | Pastikan chatid sudah benar. |
| 41049 | Contains prohibited content | Ubah nama panggilan yang Anda masukkan. |
| 60124 | The user is not in the corresponding group | Perbarui pengguna di dalam grup. |
| 400002 | Parameter error | Periksa bahwa parameter dimasukkan sesuai dengan persyaratan di atas. |
| 400001 | System error | Coba lagi nanti. |
