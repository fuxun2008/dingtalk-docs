Topik ini menjelaskan apa itu penyimpanan, kemampuan Storage API, dan sumber daya terkait.

## Apa itu penyimpanan

Storage API menyediakan solusi manajemen data yang cerdas dan aman untuk organisasi serta memenuhi kebutuhan skenario kolaborasi kantor yang berpusat pada penyimpanan file. Kemampuan intinya mencakup, tetapi tidak terbatas pada, unggah, unduh, kelola, dan transfer file, pratinjau serta pengeditan online untuk format file utama, dan manajemen izin. Anda dapat menggunakan Storage API untuk membangun apa saja, dari lampiran aplikasi sederhana hingga produk cloud drive berfitur lengkap.

Setelah aplikasi Anda mengintegrasikan Storage API, Anda dapat:

- Mentransfer file secara efisien antara aplikasi Anda dan aplikasi DingTalk lainnya.
- Memenuhi kebutuhan tata kelola file para Admin Organisasi. Untuk informasi selengkapnya, lihat [Konsol admin DingTalk](https://oa.dingtalk.io/dingtalk-enterprise-storage.htm#/).

## Referensi sumber daya

- Sumber daya **Space** mencakup atribut berikut:

  | Atribut | Tipe | Deskripsi |
  | --- | --- | --- |
  | spaceId | string | ID ruang. |
  | spaceName | string | Nama ruang. |
  | spaceType | string | Tipe ruang.  - **USER**: ruang pengguna - **APP**: ruang aplikasi |
  | quota | int64 | Total kapasitas ruang.  **Catatan**  Nilai -1 menunjukkan bahwa ruang tidak memiliki batasan kuota. Jika ruang memiliki atribut organisasi, kuota tidak boleh melebihi kuota ruang organisasi. |
  | usedQuota | int64 | Kapasitas ruang yang telah digunakan. |
  | createTime | string (iso8601) | Waktu pembuatan. |
  | modifyTime | string (iso8601) | Waktu modifikasi. |
- Sumber daya **File dan folder** mencakup atribut berikut:

  | Atribut | Tipe | Deskripsi |
  | --- | --- | --- |
  | id | string | ID file atau folder. |
  | spaceId | string | ID ruang. |
  | path | string | Jalur file atau folder di dalam ruang. |
  | status | string | Status.  - **NORMAL**: normal - **DELETED**: dihapus - **EXPIRED**: kedaluwarsa |
  | partitionType | string | Partisi penyimpanan.  - **PUBLIC_OSS_PARTITION**: partisi penyimpanan OSS cloud publik - **MINI_OSS_PARTITION**: partisi penyimpanan MiniOSS khusus |
  | parentId | string | ID folder induk. |
  | fileType | string | Tipe file.  - **FILE**: file - **FOLDER**: folder |
  | extension | string | Ekstensi nama file. |
- Sumber daya **Permission** mencakup atribut berikut:

  | Atribut | Tipe | Deskripsi |
  | --- | --- | --- |
  | id | string | ID pengguna izin.  - Jika parameter type adalah **ORG**, atur parameter ini ke **corpId** organisasi. - Jika parameter type adalah **DEPT**, atur parameter ini ke **deptId** departemen. Panggil API [Memperoleh daftar departemen](/id/open/development/user-management-acquires-the-list-departments) untuk memperoleh nilai dept_id. - Jika parameter type adalah **TAG**, atur parameter ini ke **nama tag**. - Jika parameter type adalah **CONVERSATION**, atur parameter ini ke **openConversationId** obrolan, yang diperoleh melalui API buat obrolan grup atau API buat grup skenario. - Jika parameter type adalah **USER**, atur parameter ini ke **unionId** pengguna. Panggil API [Kueri detail pengguna](/id/open/development/query-user-details) untuk memperoleh nilai unionid. |
  | roleId | string | ID peran izin.  - **OWNER**: pemilik - **MANAGER**: pengelola - **EDITOR**: editor - **DOWNLOADER**: pengunduh - **READER**: penampil |
  | type | string | Tipe pengguna izin:  - **ORG**: organisasi - **DEPT**: departemen - **TAG**: tag kustom - **CONVERSATION**: obrolan - **USER**: pengguna |
  | duration | string | Periode validitas otorisasi, dalam detik. Nilai default-nya adalah -1, yang menunjukkan validitas permanen.  - Periode validitas otorisasi berlaku ketika tipe ruang izin yang diberikan adalah APP. - Periode validitas otorisasi tidak berlaku ketika tipe ruang izin yang diberikan adalah USER, dan secara default bersifat validitas permanen. |
