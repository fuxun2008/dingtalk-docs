Panggil API ini untuk mendapatkan properti lembar kerja, termasuk ID lembar kerja, nama lembar kerja, jumlah baris, dan jumlah kolom.

## Permintaan

### Informasi dasar

| Bidang | Nilai |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/doc/workbooks/{workbookId}/sheets/{sheetId}` |
| Metode HTTP | GET |
| Jenis aplikasi yang didukung | appType-Aplikasi internal |
| Izin yang diperlukan | permission-Document.Workbook.Read-Izin baca untuk DingTalk Spreadsheet |

### Header permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses yang digunakan untuk memanggil API ini. Untuk mendapatkannya, panggil API [Mendapatkan access token aplikasi internal](/id/open/development/obtain-the-access-token-of-an-internal-app#). |

### Parameter path

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| workbookId | String | Ya | ID file spreadsheet. `nodeId(dentryUuid)` yang dikembalikan oleh [Knowledge Base API](/id/open/development/knowledge-base-overview#) adalah `workbookId` dari spreadsheet. Anda dapat memperolehnya dengan memanggil API [Mendapatkan node](https://open.dingtalk.com/document/development/get-node#) dan [Membuat dokumen Knowledge Base](/id/open/development/create-team-space-document#). |
| sheetId | String | Ya | ID atau nama lembar kerja. Panggil API [Mendapatkan semua lembar kerja](/id/open/development/obtain-all-worksheets#) untuk mendapatkan nilai parameter id atau name. |

### Parameter query

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| operatorId | String | Ya | unionId operator.   - Panggil API [Mendapatkan userid pengguna menggunakan kode login senyap](/id/open/development/obtain-the-userid-of-a-user-by-using-the-log-free#) untuk mendapatkan nilai parameter unionid. - Panggil API [Kueri detail pengguna](/id/open/development/query-user-details#) untuk mendapatkan nilai parameter unionid.     Jika operator tidak memiliki izin, API mengembalikan error `The operator has no permission`. |

## Respons

### Isi respons

| Nama | Tipe | Deskripsi |
| --- | --- | --- |
| id | String | ID lembar kerja. |
| name | String | Nama lembar kerja. |
| visibility | String | Visibilitas lembar kerja. |
| lastNonEmptyRow | Long | Posisi baris tidak kosong terakhir, dimulai dari 0. Mengembalikan -1 ketika lembar kerja kosong. |
| lastNonEmptyColumn | Long | Posisi kolom tidak kosong terakhir, dimulai dari 0. Mengembalikan -1 ketika lembar kerja kosong. |
| rowCount | Long | Jumlah baris dalam lembar kerja. |
| columnCount | Long | Jumlah kolom dalam lembar kerja. |

  "columnCount" : 40
}
