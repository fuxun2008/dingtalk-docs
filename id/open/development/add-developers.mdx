title: "(Opsional) Menambahkan pengembang"
description: "Pelajari cara menambahkan pengembang di DingTalk Developer Console agar dapat mengembangkan aplikasi secara kolaboratif dengan pengguna di organisasi Anda."
---

Untuk mengembangkan aplikasi secara kolaboratif dengan pengguna di organisasi Anda, ikuti langkah-langkah dalam dokumen ini untuk menambahkan pengguna.

**Penting**

Jika Anda tidak menambahkan pengguna pengembangan kolaboratif, pengguna tersebut tidak dapat melihat aplikasi.

## **Prasyarat**

Selesaikan proses [Buat Aplikasi](https://open.dingtalk.com/document/orgapp/create-an-application).

## **Prosedur**

1. Masuk ke [Developer Console](https://open-dev.dingtalk.com/#/), lalu klik aplikasi target untuk membuka halaman detailnya.
2. Klik **Basic Information** > **User Management** > **Add User** untuk menambahkan pengguna pengembangan kolaboratif.
