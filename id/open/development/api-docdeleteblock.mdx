Panggil API ini untuk menghapus elemen block tertentu di dalam dokumen.

## Permintaan

### Informasi dasar

| Bidang | Nilai |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/doc/suites/documents/{docKey}/blocks/{blockId}` |
| Metode HTTP | DELETE |
| Jenis aplikasi yang didukung | appType-Aplikasi internal |
| Izin yang diwajibkan | permission-Storage.File.Write-Izin tulis file penyimpanan Organisasi |

### Header permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses yang digunakan untuk memanggil API ini. Perolehlah dengan memanggil API [Mendapatkan access token aplikasi internal](/id/open/development/obtain-the-access-token-of-an-internal-app). |

### Parameter path

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| docKey | String | Ya | ID Dokumen (nilai `docKey` atau `dentryUuid` dari dokumen). Setelah membuat dokumen dengan memanggil API [Membuat dokumen Knowledge Base](/id/open/development/create-team-space-document), perolehlah `docKey` dari respons. Perolehlah `dentryUuid` dari URL dokumen. Sebagai contoh, untuk `https://docs.dingtalk.io/i/nodes/Zxxxxa-id`, maka `dentryUuid`-nya adalah `Zxxxxa-id`. |
| blockId | String | Ya | Nilai `blockId` dari block yang akan dihapus. Perolehlah `blockId` dengan memanggil API [Mengkueri elemen block](/id/open/development/api-docblocksquery). |

### Parameter kueri

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| operatorId | String | Ya | unionId dari pengguna. Perolehlah unionid dengan memanggil API [Mengkueri detail pengguna](/id/open/development/query-user-details). |

### Contoh permintaan

HTTP

```http
DELETE /v1.0/doc/suites/documents/doc_key/blocks/block_id?operatorId=union_id HTTP/1.1
Host:api.dingtalk.io
x-acs-dingtalk-access-token:7dc9ec4xxx
Content-Type:application/json
```
