Panggil API ini untuk menghapus kalender berlangganan.

## Deskripsi panggilan API

- Hanya pembuat kalender yang dapat menghapus kalender. Oleh karena itu, bidang userId dalam parameter jalur harus berupa unionId dari pembuat kalender.
- Setelah kalender berlangganan dihapus, pengguna yang telah berlangganan kalender tersebut secara otomatis berhenti berlangganan.

## Permintaan

### Informasi dasar

| Bidang | Value |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/calendar/users/{userId}/subscribedCalendars/{calendarId}` |
| Metode HTTP | DELETE |
| Tipe aplikasi yang didukung | appType-Aplikasi internal　appType-Aplikasi perusahaan pihak ketiga　appType-Aplikasi personal pihak ketiga |
| Izin yang diperlukan | permission-Calendar.Calendar.Write-Izin tulis untuk aplikasi Kalender |

### Header permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Dapatkan dengan cara berikut:   - Untuk aplikasi internal, panggil API [Mendapatkan access token aplikasi internal](/id/open/development/obtain-the-access-token-of-an-internal-app#). - Untuk aplikasi perusahaan pihak ketiga, panggil API [Mendapatkan access token perusahaan yang diberi otorisasi untuk aplikasi pihak ketiga](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#). - Untuk aplikasi personal pihak ketiga, panggil API [Mendapatkan user token](/id/open/development/obtain-user-token#). |

### Parameter jalur

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| userId | String | Ya | unionId dari pembuat kalender.   - Untuk aplikasi internal dan aplikasi perusahaan pihak ketiga, panggil API [Kueri detail pengguna](/id/open/development/query-user-details#) untuk mendapatkan nilai unionid. - Untuk aplikasi personal pihak ketiga, panggil API [Mendapatkan profil pengguna dari Kontak](/id/open/development/dingtalk-retrieve-user-information#) untuk mendapatkan nilai unionId. |
| calendarId | String | Ya | ID kalender berlangganan. Panggil API [Membuat kalender berlangganan](/id/open/development/create-subscription-calendar#) untuk mendapatkan nilai calendarId. |
