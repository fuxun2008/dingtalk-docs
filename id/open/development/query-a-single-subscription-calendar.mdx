Panggil API ini untuk query detail kalender langganan.

## Permintaan

### Informasi dasar

| Bidang | Nilai |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/calendar/users/{userId}/subscribedCalendars/{calendarId}` |
| Metode HTTP | GET |
| Tipe aplikasi yang didukung | appType-Aplikasi internal　appType-Aplikasi perusahaan pihak ketiga　appType-Aplikasi personal pihak ketiga |
| Izin yang diperlukan | permission-Calendar.Calendar.Read-Izin baca untuk aplikasi Kalender |

### Header permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Dapatkan sebagai berikut:   - Untuk Aplikasi internal, panggil API [Mendapatkan access token Aplikasi internal](/id/open/development/obtain-the-access-token-of-an-internal-app#). - Untuk Aplikasi perusahaan pihak ketiga, panggil API [Mendapatkan access token organisasi yang telah mengizinkan Aplikasi pihak ketiga](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#). - Untuk Aplikasi personal pihak ketiga, panggil API [Mendapatkan user token](/id/open/development/obtain-user-token#). |

### Parameter path

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| userId | String | Ya | unionId pembuat kalender atau salah satu co-editor.   - Untuk Aplikasi internal atau Aplikasi perusahaan pihak ketiga, panggil API [Query detail pengguna](/id/open/development/query-user-details#) untuk mendapatkan nilai parameter unionid. - Untuk Aplikasi personal pihak ketiga, panggil API [Mendapatkan profil pengguna dari Kontak](/id/open/development/dingtalk-retrieve-user-information#) untuk mendapatkan nilai parameter unionId. |
| calendarId | String | Ya | ID kalender langganan. Panggil API [Membuat kalender langganan](/id/open/development/create-subscription-calendar#) untuk mendapatkan nilai parameter calendarId. |
