title: "Kueri hasil absen penjadwalan shift"
description: "Gunakan API DingTalk ini untuk mengkueri hasil absen penjadwalan shift secara massal berdasarkan ID jadwal, lengkap dengan tipe absensi dan waktu absen terencana."
---

Panggil API ini untuk mengkueri hasil absen penjadwalan shift berdasarkan ID jadwal serta mendapatkan tipe absensi, waktu absen terencana, waktu modifikasi terakhir, dan informasi lainnya.

## Permintaan

| **Informasi Dasar** | |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/topapi/attendance/schedule/result/listbyids |
| Metode HTTP | POST |
| Tipe aplikasi yang didukung | appType-Aplikasi internal appType-Aplikasi perusahaan pihak ketiga |
| Izin yang diperlukan | permission-qyapi_attendance_group_read-Izin kueri grup absensi |

### Parameter kueri

| Nama | Tipe | Wajib | Contoh | Deskripsi |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | bE74xxxx | Kredensial aplikasi yang digunakan untuk memanggil API ini.   - Untuk Aplikasi internal, dapatkan dengan memanggil API [Mendapatkan access_token Aplikasi internal](/id/open/development/obtain-orgapp-token). - Untuk Aplikasi perusahaan pihak ketiga, dapatkan dengan memanggil API Mendapatkan access_token Aplikasi perusahaan pihak ketiga. |

### Isi permintaan

| Nama | Tipe | Wajib | Contoh | Deskripsi |
| --- | --- | --- | --- | --- |
| op_user_id | String | Ya | manager123 | userId operator. |
| schedule_ids | String | Ya | 144872188723,144872188722 | ID jadwal. Panggil API [Kueri detail penjadwalan shift absensi organisasi](/id/open/development/interface-for-daily-full-query-of-attendance-scheduling-information) untuk mendapatkan nilai parameter plan_id. Pisahkan beberapa ID jadwal dengan koma. Setiap panggilan mendukung hingga 100 ID jadwal. |

### Contoh permintaan

```curl
curl -X POST "https://api.dingtalk.io/topapi/attendance/schedule/result/listbyids" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=711cexxxx8ce772' \
-d 'op_user_id=dd_dd' \
-d 'schedule_ids=1234%2C3214'
```

## Respons

### Isi respons

| Nama | Tipe | Contoh | Deskripsi |
| --- | --- | --- | --- |
| result | TopScheduleResultVo[] | demo | Hasil kueri. |
| check_type | String | OnDuty | Tipe absensi:   - **Onduty**: Absen masuk - **OffDuty**: Absen pulang |
| gmt_modified | Date | 2020-11-11 19:03:21 | Waktu modifikasi terakhir. |
| plan_check_time | Date | 2020-11-11 19:03:20 | Waktu absen terencana. |
| corp_id | String | dingxxxxx1c1 | ID organisasi. |
| base_check_time | Date | 2020-11-11 19:03:00 | Waktu absen terencana setelah disesuaikan dengan aturan seperti toleransi keterlambatan dan pulang lebih awal. |
| group_id | Number | 67xxxx4 | ID grup absensi. |
| gmt_create | Date | 2020-11-11 19:03:21 | Waktu pembuatan. |
| user_id | String | user123 | userId pengguna. |
| work_date | Date | 2020-11-11 00:00:00 | Hari kerja, yaitu tanggal spesifik jadwal tersebut. |
| id | Number | 11xxxx19 | ID hasil absen. |
| location_result | String | Normal | Hasil lokasi absen:   - **Normal**: Absen normal - **NotSigned**: Belum absen - **Outside**: Kerja lapangan |
| is_legal | String | Y | Menunjukkan apakah absen mengalami error:   - **N**: Tidak - **Y**: Ya |
| time_result | String | Normal | Hasil waktu absen:   - **Normal**: Absen normal - **NotSigned**: Belum absen - **Late**: Keterlambatan - **SeriousLate**: Keterlambatan serius - **Absenteeism**: Mangkir karena keterlambatan - **Early**: Pulang lebih awal |
| record_id | Number | 48xxxx644 | Catatan absen. |
| user_check_time | Date | 2020-11-11 19:03:20 | Waktu absen. |
| schedule_id | Number | 5672xxxx63 | ID jadwal. |
| success | Boolean | true | Menunjukkan apakah permintaan berhasil.   - **true**: Berhasil - **false**: Gagal |
| errcode | Number | 0 | Kode pengembalian. |
| errmsg | String | ok | Deskripsi kode pengembalian. |
| request_id | String | 6k9c3cvix353 | ID permintaan. |
