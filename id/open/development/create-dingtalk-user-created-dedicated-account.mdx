Panggil API ini untuk membuat pengguna Akun Perusahaan bawaan DingTalk. API ini hanya tersedia untuk organisasi yang telah membeli dan mengaktifkan fitur ini.

## Permintaan

| **Informasi dasar** | |
| --- | --- |
| URL HTTP | https://oapi.dingtalk.io/topapi/v2/user/create |
| Metode HTTP | POST |
| Jenis aplikasi yang didukung | appType-Aplikasi internal |
| Izin yang diperlukan | permission-qyapi_manage_addresslist-Izin pengelolaan data Kontak |

### Parameter kueri

| Nama | Tipe | Wajib | Contoh | Deskripsi |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | BE3xxxx | Kredensial aplikasi yang digunakan untuk memanggil API ini. Dapatkan melalui API untuk memperoleh [access_token dari aplikasi internal](/id/open/development/obtain-orgapp-token). |

### Isi permintaan

| Nama | Tipe | Wajib | Contoh | Deskripsi |
| --- | --- | --- | --- | --- |
| userid | String | Tidak | zhangsan | Identifier unik karyawan (tidak dapat diubah), dengan panjang 1 hingga 64 karakter.  **Catatan**   - Harus unik dalam Organisasi Anda. - Jika tidak ditentukan, userId akan dibuat secara otomatis. |
| exclusive_account | Boolean | Ya | true | Harus diatur ke true, yang menandakan bahwa Akun Perusahaan akan dibuat.  **Catatan**  Hanya berlaku untuk Akun Perusahaan. |
| exclusive_account_type | String | Ya | dingtalk | Harus diatur ke dingtalk, yang menandakan Akun Perusahaan bawaan DingTalk.  **Catatan**  Hanya berlaku untuk Akun Perusahaan bawaan DingTalk. |
| login_id | String | Ya | login_id3 | Nama login Akun Perusahaan bawaan DingTalk.  **Catatan**  Jangan sertakan informasi seperti nomor telepon atau tautan email agar pesan SMS pendaftaran tidak diblokir oleh operator. |
| init_password | String | Ya | init_password220 | Kata sandi awal Akun Perusahaan bawaan DingTalk. Kata sandi awal harus terdiri dari minimal 8 karakter.  **Catatan**   - Kata sandi tidak boleh seluruhnya berupa huruf atau angka. - Jangan sertakan informasi seperti nomor telepon, email, atau tautan agar pesan SMS pendaftaran tidak diblokir oleh operator. |
| send_password_to_user | Boolean | Tidak | false | Apakah akan mengirim kredensial akun. Nilai default: false.   - **false**: Tidak dikirim. - **true**: Dikirim.   **Catatan**   - Saat dikirim, pesan SMS dikirim ke nomor telepon karyawan atau email dikirim ke alamat email pribadi. - Ketika parameter ini diatur ke **true**, parameter `init_password` wajib diisi; jika tidak, tidak ada pesan yang dikirim. |
| name | String | Ya | Zhang San | Nama karyawan, dengan panjang maksimal 80 karakter. |
| dept_id_list | String | Ya | "2,3,4" | Daftar ID departemen tempat karyawan bernaung. Pisahkan beberapa ID departemen dengan koma (`,`). Maksimal 100 ID departemen dapat diteruskan per panggilan. |
| telephone | String | Tidak | 010-86123456-2345 | Nomor ekstensi, dengan panjang maksimal 50 karakter.  **Catatan**  Nomor ekstensi harus unik dalam Organisasi Anda. |
| job_number | String | Tidak | 4 | ID Karyawan, dengan panjang maksimal 50 karakter. |
| title | String | Tidak | Technical Director | Jabatan, dengan panjang maksimal 200 karakter. |
| email | String | Tidak | test@xxx.com | Email pribadi karyawan, dengan panjang maksimal 50 karakter.  **Catatan**  Email karyawan harus unik dalam Organisasi Anda. |
| org_email | String | Tidak | test@xxx.com | Email Perusahaan karyawan, dengan panjang maksimal 100 karakter.  **Catatan**  Bidang ini hanya berfungsi ketika karyawan telah mengaktifkan Email Perusahaan. |
| org_email_type | String | Tidak | profession | Tipe Email Perusahaan karyawan:   - **profession:** Edisi Standar. - **base:** Edisi Dasar. |
| work_place | String | Tidak | Future Park | Lokasi Kerja, dengan panjang maksimal 100 karakter. |
| remark | String | Tidak | Alias information | Alias, dengan panjang maksimal 2.000 karakter. |
| dept_order_list | Object[] | Tidak |  | Urutan sortir karyawan dalam setiap departemen. |
| dept_id | Number | Tidak | 2 | ID departemen. |
| order | Number | Tidak | 1 | Urutan sortir karyawan dalam departemen. Nilai yang lebih besar menandakan posisi yang lebih tinggi. |
| dept_title_list | Object[] | Tidak |  | Jabatan karyawan dalam setiap departemen. |
| dept_id | Number | Tidak | 2 | ID departemen. |
| title | String | Tidak | Senior Product Manager | Jabatan karyawan dalam departemen. |
| extension | String | Tidak | `{"Hobby":"Travel","Age":"24"}` | Atribut tambahan. Beberapa atribut dapat diatur, dengan panjang maksimal 2.000 karakter. **Catatan**   - Maksimal 10 atribut tambahan dapat ditampilkan di perangkat seluler. - Sebelum menggunakan parameter ini, tambahkan atribut terlebih dahulu di [konsol admin DingTalk](https://oa.dingtalk.io/index_new.htm#/setting/contactInfo), lalu panggil API untuk menetapkan nilai. - Nilai bidang ini mendukung tipe tautan. Tautan mendukung wildcard variabel yang diganti secara otomatis. Wildcard yang saat ini didukung adalah userid dan corpid. Contoh: `{"Hobby":"[Hobby](http://www.dingtalk.io?userid=#userid#&corpid=#corpid#)"}`. |
| senior_mode | Boolean | Tidak | false | Apakah akan mengaktifkan mode eksekutif. Nilai default: false.   - **true**: Aktifkan.  **Catatan**    - Ketika diaktifkan, nomor telepon disembunyikan dari semua karyawan.   - Karyawan biasa tidak dapat mengirim DING atau memulai panggilan bisnis DingTalk kepada eksekutif.   - Sesama eksekutif dapat saling mengirim DING dan memulai panggilan bisnis DingTalk. - **false**: Jangan aktifkan. |
| hired_date | Number | Tidak | 1597573616828 | Tanggal perekrutan, dalam format Unix timestamp (dalam milidetik). |
| manager_userid | String | Tidak | 001 | userId atasan langsung. |
| exclusive_mobile | String | Tidak | +86-13412341234 | Nomor telepon Akun Perusahaan.  **Catatan**  Hanya berlaku untuk Akun Perusahaan. |
| avatarMediaId | String | Tidak | @lALPDfmVUw19YdrNA-jNA-g | Saat membuat Akun Perusahaan untuk Organisasi Anda, Anda dapat menentukan MediaId Foto Profil. Hanya format jpg dan png yang didukung.  Dapatkan dengan memanggil API [Unggah file media](/id/open/development/upload-media-files).  **Catatan**  Hanya berlaku untuk Akun Perusahaan. |
| nickname | String | Tidak | Name | Saat membuat Akun Perusahaan untuk Organisasi Anda, Anda dapat menentukan Nama.  **Catatan**  Hanya berlaku untuk Akun Perusahaan. |

## Respons

### Isi respons

| Nama | Tipe | Contoh | Deskripsi |
| --- | --- | --- | --- |
| errcode | Number | 0 | Kode error. 0 menandakan berhasil. |
| errmsg | String | ok | Pesan error. |
| result | Object |  | Hasil yang dikembalikan. |
| userid | String | zhangsan | ID karyawan. |
| unionId | String | xxxx | ID unik karyawan. |

### Contoh isi respons

```json
{
  "errcode":"0",
  "result":{
    "unionId":"xxxx",
    "userid":"zhangsan"
  },
  "errmsg":"ok"
}
```

### Kode error

Jika error dikembalikan saat memanggil API ini, lihat dokumen [Kode error global](/id/open/development/server-api-error-codes-1) untuk menemukan solusi berdasarkan pesan error.
