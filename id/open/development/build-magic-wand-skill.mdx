Kemampuan AI adalah fungsi atau layanan spesifik yang menyelesaikan sebuah tugas secara menyeluruh dengan menggunakan serangkaian teknologi AI dan rekayasa. Sebuah aplikasi Magic Wand yang lengkap biasanya terdiri dari satu atau beberapa keterampilan yang bekerja sama untuk menghadirkan fungsi dan tugas AI yang kompleks dan beragam.

Sebuah kemampuan AI biasanya terdiri dari komponen seperti execution chain, model, prompt engineering, plugin, dan kartu AI. Untuk penjelasan detail tentang komponen kemampuan AI, lihat Pengenalan Komponen.

## **Prasyarat**

1. Selesaikan proses [Membuat Aplikasi](/id/open/dingstart/create-application).
2. Tambahkan kemampuan aplikasi Magic Wand. Untuk detailnya, lihat Menambahkan Kemampuan Aplikasi AI.

## **Prosedur**

1. Cari **AI App** di bilah navigasi kiri, lalu klik AI Capabilities untuk membuka halaman AI Capabilities.
2. Buat sebuah kemampuan AI.

   - Opsi 1: Buat dari templat. Platform menyediakan berbagai templat kemampuan AI yang mencakup beragam skenario seperti rekrutmen, konsultasi administrasi, penerjemahan bahasa, dan tanya jawab cerdas, membantu Anda memulai pengembangan aplikasi AI dengan cepat.
   - Opsi 2: Buat secara langsung. Jika templat tidak memenuhi kebutuhan bisnis Anda, buat kemampuan AI kosong secara langsung dan bangun dari awal.

   Setelah keterampilan dibuat, sistem akan otomatis membuka halaman pembuatan keterampilan.

3. Bangun kemampuan AI.

   1. Pilih execution chain yang sesuai dengan skenario bisnis Anda. Untuk pengenalan tentang execution chain umum dan skenario bisnis tipikal.
   2. Berdasarkan execution chain yang dipilih, pilih komponen keterampilan lain yang Anda perlukan. Misalnya, large model execution chain memerlukan komponen model umum dan templat prompt. Oleh karena itu, pilih sebuah model dan sebuah templat prompt di panel komponen pada sisi kiri halaman pembuatan keterampilan.
   3. Masukkan nilai parameter untuk komponen. Jika sebuah atribut dalam sebuah komponen ditandai dengan "**\***", maka parameter tersebut wajib; jika tidak, maka parameter tersebut opsional. Untuk penjelasan detail tentang setiap komponen dan parameternya, lihat Pengenalan Komponen.
   4. Berdasarkan dependensi antar komponen, hubungkan semua komponen dengan menyeretnya untuk menggabungkannya menjadi execution chain yang lengkap, lalu klik **Save**.
4. Konfigurasikan metode pemicu.

   |  |  |  |
   | --- | --- | --- |
   | **Item Konfigurasi** | | **Deskripsi** |
   | Informasi Dasar | Nama Kemampuan AI | Nama keterampilan, dengan panjang maksimum 6 karakter. |
   | Deskripsi Kemampuan AI | Deskripsi lebih lanjut tentang keterampilan, ditampilkan kepada pengguna, dengan panjang maksimum 15 karakter. |
   | Prompt Umum | Judul Prompt | Contoh judul pertanyaan umum dari pengguna, digunakan untuk memandu pengguna memicu keterampilan. |
   | Deskripsi Prompt | Contoh deskripsi pertanyaan umum dari pengguna, digunakan untuk memandu pengguna memicu keterampilan. |
   | Prompt Terkait, Contoh Lainnya | | Masukkan lebih banyak variasi frasa yang mirip dengan prompt umum.  Catatan: Prompt tidak ditampilkan kepada pengguna dan hanya diberikan kepada model untuk meningkatkan pengenalan keterampilan. |
5. Setelah konfigurasi selesai, klik **Save**.

## **Langkah Berikutnya**

Setelah membangun kemampuan AI, Anda perlu Mengonfigurasi Aplikasi Magic Wand.
