---
title: "Memperbarui lembar kerja"
description: "Panggil API ini untuk memperbarui atribut meta lembar kerja tertentu di DingTalk Spreadsheet, termasuk nama, visibilitas, serta baris atau kolom yang dibekukan, dengan beberapa atribut dapat diperbarui dalam satu permintaan."
---

Panggil API ini untuk mengubah metadata lembar kerja tertentu dalam DingTalk Spreadsheet, termasuk nama lembar kerja, visibilitas, serta jumlah baris dan kolom yang dibekukan. API ini cocok untuk mengelola konfigurasi lembar kerja secara terprogram dan mendukung pembaruan beberapa atribut dalam satu permintaan. id lembar kerja dikembalikan setelah pembaruan.

## Permintaan

### Informasi dasar

| Bidang | Nilai |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/doc/workbooks/{workbookId}/sheets/{sheetId}` |
| Metode HTTP | PUT |
| Jenis aplikasi yang didukung | appType-Internal app |
| Izin | permission-Document.Workbook.Write-DingTalk Spreadsheet write permission |

### Header permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Untuk memperoleh kredensial, panggil API [Mendapatkan access token dari aplikasi internal](/id/open/development/obtain-the-access-token-of-an-internal-app). |

### Parameter path

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| workbookId | String | Ya | ID file spreadsheet. `nodeId(dentryUuid)` yang dikembalikan oleh [Knowledge Base API](/id/open/development/knowledge-base-overview) adalah `workbookId` dari spreadsheet. Untuk memperolehnya, panggil API [Get node](https://open.dingtalk.com/document/development/get-node) atau [Membuat dokumen Knowledge Base](/id/open/development/create-team-space-document). |
| sheetId | String | Ya | ID atau judul lembar kerja. Untuk memperoleh id dan judul lembar kerja, panggil API [Mendapatkan semua lembar kerja](/id/open/development/obtain-all-worksheets). |

### Parameter query

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| operatorId | String | Ya | unionId dari operator. Untuk memperolehnya, panggil API [Menanyakan detail pengguna](/id/open/development/query-user-details). Jika operator tidak memiliki izin yang diperlukan, API akan mengembalikan error `The operator has no permission`. |

### Isi permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| frozenRowCount | Long | Tidak | Indeks baris tempat baris dibekukan. Dimulai dari 1. Nilai 0 berarti tidak ada baris yang dibekukan. Misalnya, atur nilai ini ke 3 untuk membekukan baris 1 hingga 3. |
| frozenColumnCount | Long | Tidak | Indeks kolom tempat kolom dibekukan. Dimulai dari 1. Nilai 0 berarti tidak ada kolom yang dibekukan. Misalnya, atur nilai ini ke 3 untuk membekukan kolom 1 hingga 3. |
| visibility | String | Tidak | Apakah lembar kerja disembunyikan. Nilai yang valid:   - **visible**: Tampilkan. - **hidden**: Sembunyikan. |
| name | String | Tidak | Nama lembar kerja baru. |

### Contoh permintaan

```http
PUT /v1.0/doc/workbooks/e54Lq3xxx/sheets/Sheet1?operatorId=ppgAxxx HTTP/1.1

  "frozenRowCount" : 1,
  "frozenColumnCount" : 1,

  "name" : "Sheet2"
```

### Isi respons

| Nama | Tipe | Deskripsi |
| --- | --- | --- |
| id | String | id lembar kerja. |

### Contoh isi respons

```text
HTTP/1.1 200 OK
Content-Type:application/json

{
  "id" : "sheet_id"
}
```
