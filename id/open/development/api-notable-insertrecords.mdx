Panggil API ini untuk menyisipkan rekaman ke tabel tertentu dalam AI Table.

## Permintaan

### Informasi dasar

| Bidang | Nilai |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/notable/bases/{baseId}/sheets/{sheetIdOrName}/records` |
| Metode HTTP | POST |
| Jenis aplikasi yang didukung | appType-Aplikasi internal |
| Izin | permission-Notable.Base.Write.All-Izin tulis untuk aplikasi AI Table |

### Header permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Panggil API [Memperoleh access token aplikasi internal](/id/open/development/obtain-the-access-token-of-an-internal-app) untuk mendapatkannya. |

### Parameter path

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| baseId | String | Ya | ID dari AI Table. Untuk cara memperolehnya, lihat [Struktur data](/id/open/development/data-structure). |
| sheetIdOrName | String | Ya | ID tabel atau nama tabel. Anda dapat memperoleh ID tabel dengan salah satu cara berikut:   - Panggil API [Memperoleh semua tabel](/id/open/development/api-notable-getallsheets). - Panggil API [Memperoleh sebuah tabel](/id/open/development/api-notable-getsheet). |

### Parameter query

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| operatorId | String | Ya | unionId dari operator. Peroleh dengan salah satu cara berikut:   - Panggil API [Mengambil detail pengguna](/id/open/development/query-user-details). - Panggil API [Memperoleh userid pengguna melalui kode login senyap](/id/open/development/obtain-the-userid-of-a-user-by-using-the-log-free). |
| clientToken | String | Tidak | String UUID v4 standar yang digunakan untuk kontrol idempotensi.   - Kosong: Memulai permintaan baru. - Tidak kosong: Melakukan pembaruan idempoten. Permintaan berulang dengan nilai yang sama tidak akan dieksekusi lebih dari satu kali. |

### Isi permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| records | Array | Ya | Data rekaman yang akan disisipkan. |
| fields | `Map<String, Any>` | Ya | Nilai bidang dari rekaman, dalam format `Map<String, Any>`:   - key: Nama field (tipe String), sesuai dengan nama field di tabel. - value: Nilai bidang (tipe Any). Berikan nilai dalam format yang sesuai berdasarkan tipe bidang. Untuk detail tentang format nilai bidang, lihat [Format nilai rekaman](https://open.dingtalk.com/document/development/record-value-format). |
|  | Any | Tidak | Nilai bidang. Formatnya bervariasi tergantung pada tipe bidang. Untuk detailnya, lihat Format nilai rekaman. |
