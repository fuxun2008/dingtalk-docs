Menghapus nilai properti aplikasi pada suatu file.

## Deskripsi panggilan API

- Ketika tipe ruang penyimpanan adalah USER, semua pengguna yang memiliki izin pada ruang tersebut memiliki izin operasi. Karyawan lain harus memanggil API [Tambah izin](/id/open/development/add-permissions-file) untuk memperoleh otorisasi.
- Ketika tipe ruang penyimpanan adalah APP, siapa pun yang melakukan operasi harus memanggil API [Tambah izin](/id/open/development/add-permissions-file) untuk memperoleh otorisasi.

## Permintaan

### Informasi dasar

| Bidang | Nilai |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/storage/spaces/{spaceId}/dentries/{dentryId}/appProperties/remove` |
| Metode HTTP | POST |
| Tipe aplikasi yang didukung | appType-Aplikasi internal　appType-Aplikasi perusahaan pihak ketiga |
| Persyaratan izin | permission-Storage.File.Write-Izin tulis file penyimpanan organisasi |

### Header permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Perolehlah sebagai berikut:   - Untuk aplikasi internal, panggil API [Dapatkan access token aplikasi internal](/id/open/development/obtain-the-access-token-of-an-internal-app). - Untuk aplikasi perusahaan pihak ketiga, panggil API [Dapatkan access token organisasi yang diberi otorisasi kepada aplikasi pihak ketiga](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1). |

### Parameter path

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| spaceId | Long | Ya | ID ruang. Panggil API [Tambah ruang](/id/open/development/add-space) untuk memperoleh nilai parameter id. |
| dentryId | Long | Ya | ID file atau folder. Panggil API [Dapatkan daftar file atau folder](/id/open/development/get-a-list-of-files-or-folders) atau [Dapatkan spaceId dan dentryId berdasarkan dentryUuid](/id/open/development/api-getdentryidbyuuid) untuk memperoleh nilai parameter id. |

### Parameter query

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| unionId | String | Ya | unionId operator. Panggil API [Kueri detail pengguna](/id/open/development/query-user-details) untuk memperoleh nilai parameter unionid. |

### Isi permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| propertyNames | Array of String | Ya | Daftar nama properti aplikasi dari file atau folder. Jumlah maksimum adalah 3. |

### Isi respons

| Nama | Tipe | Deskripsi |
| --- | --- | --- |
| success | Boolean | Apakah penghapusan berhasil.   - **true**: Berhasil - **false**: Gagal |

### Contoh isi respons

```text
HTTP/1.1 200 OK
Content-Type:application/json

{
  "success" : true
}
```
