---
title: "Menghapus kriteria tampilan filter"
description: "Panggil API ini untuk menghapus kriteria filter kolom tertentu dalam tampilan filter di DingTalk Spreadsheet, cocok saat status filter kolom lain harus dipertahankan dalam filter pribadi."
---

Panggil API ini untuk menghapus kriteria filter kolom tertentu dalam tampilan filter, sehingga kolom tersebut tidak lagi ikut dalam perhitungan filter. Ini berlaku saat Anda ingin menghapus aturan filter satu kolom dalam tampilan filter pribadi sambil mempertahankan status filter kolom lainnya.

## Deskripsi panggilan API

Operasi penghapusan hanya memengaruhi tampilan filter saat ini dan tidak memengaruhi filter global maupun tampilan filter lainnya.

## Permintaan

### Informasi dasar

| Bidang | Value |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/doc/workbooks/{workbookId}/sheets/{sheetId}/filterViews/{filterViewId}/clearColumnFilterCriteria` |
| Metode HTTP | POST |
| Jenis aplikasi yang didukung | appType-Aplikasi internal |
| Izin yang diperlukan | permission-Document.Workbook.Write-Izin tulis DingTalk Spreadsheet |

### Header permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Dapatkan dengan memanggil API [Memperoleh access token aplikasi internal](/id/open/development/obtain-the-access-token-of-an-internal-app). |

### Parameter path

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| workbookId | String | Ya | ID file spreadsheet. `nodeId(dentryUuid)` yang dikembalikan oleh [Knowledge Base API](/id/open/development/knowledge-base-overview) adalah `workbookId` spreadsheet. Dapatkan dengan memanggil API [Memperoleh node](https://open.dingtalk.com/document/orgapp/get-node) dan [Membuat dokumen Knowledge Base](/id/open/development/create-team-space-document). |
| sheetId | String | Ya | ID atau nama lembar kerja. Dapatkan nilai parameter id atau name dengan memanggil API [Memperoleh semua lembar kerja](/id/open/development/obtain-all-worksheets). |
| filterViewId | String | Ya | ID tampilan filter. |

### Parameter query

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| operatorId | String | Ya | unionId operator.   - Dapatkan nilai parameter unionid dengan memanggil API [Memperoleh userid pengguna melalui kode login senyap](/id/open/development/obtain-the-userid-of-a-user-by-using-the-log-free). - Dapatkan nilai parameter unionid dengan memanggil API [Mengkueri detail pengguna](/id/open/development/query-user-details).       Jika operator tidak memiliki izin, API mengembalikan error `The operator has no permission`. |

### Isi permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| column | Long | Ya | Offset kolom relatif terhadap kolom pertama dari rentang tampilan filter, dimulai dari 0. Misalnya, jika rentang tampilan filter adalah `B1:E10`, maka `column=0` mewakili kolom B, dan `column=1` mewakili kolom C. |
