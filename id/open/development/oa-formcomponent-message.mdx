## Parameter FormComponent

**formComponents** adalah daftar komponen formulir. Tidak semua komponen mendukung setiap atribut dalam Props. Lihat contoh permintaan di bawah untuk mengetahui atribut yang didukung setiap kontrol. Beberapa kontrol kontainer, seperti paket persetujuan dan kontrol rincian, mendukung kontrol turunan. Gunakan children untuk menentukan tipe dan atribut setiap kontrol turunan. Kontrol turunan menggunakan definisi atribut yang sama dengan kontrol lainnya. Model kontrolnya adalah sebagai berikut:

<Warning>
Batasan umum untuk kontrol formulir:
</Warning>

- componentId: ID kontrol. Panjang maksimum: 64 karakter.
- bizAlias: Alias bisnis kontrol. Nilainya harus unik dalam formulir. Tentukan bizAlias atau componentId. Panjang maksimum: 64 karakter.
- label: Judul kontrol. Panjang maksimum: 20 karakter.
- placeholder: Petunjuk input. Panjang maksimum: 128 karakter.
- content: Konten kontrol TextNote. Panjang maksimum: 500 karakter.
- Total panjang kontrol rincian tabel tidak boleh melebihi 65.535 karakter. Batasi setiap kontrol rincian maksimal 100 entri.

#### Atribut umum kontrol

```json
{
  "componentId": "TextField-12345677",   // ID kontrol. Unik dalam formulir. Tentukan ini atau bizAlias
  "required":true,  // Apakah kontrol wajib diisi
  "label": "Teks satu baris",   // Judul kontrol
  "placeholder": "Masukkan nilai",    // Petunjuk input
  "bizAlias": "staffId", // Alias bisnis kontrol. Unik dalam formulir. Tentukan ini atau componentId
  "print": "0", // Apakah bidang disertakan saat dicetak (0: tidak dicetak; 1: dapat dicetak). Default: dapat dicetak
  "disabled": false, // Apakah kontrol dapat diedit
}
```

## Parameter FormComponentValues

Tentukan nilai secara ketat sesuai komponen yang digunakan saat membuat templat. Lihat [Parameter FormComponent](#900adc505f44g) untuk mengisi nilai komponen formulir:

### Kontrol lokasi

```json
{
    "name": "[\"Waktu Saat Ini\",\"Lokasi Saat Ini\"]", // Label kontrol
    "value": "[\"2025-05-27 14:27:20\",120.021195,30.281506,\"Alibaba Group Xixi Campus Zona C, 960-1 Wenyi West Road, Distrik Yuhang, Hangzhou, Zhejiang\",100]"
}
```

### Kontrol input satu baris

```json
{
    "name": "Judul (Input satu baris)", // Label kontrol
    "value": "Judul uji (Input satu baris)"
}
```

### Kontrol input multi-baris

```json
{
    "name": "Deskripsi (Input multi-baris)", // Label kontrol
    "value": "Deskripsi uji (Input multi-baris)"
```
