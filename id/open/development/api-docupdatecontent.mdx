Panggil API ini untuk menimpa dokumen menggunakan Markdown.

## Permintaan

| **Informasi dasar** | |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v2.0/doc/me/suites/documents/{docKey}/overwriteContent` |
| Metode HTTP | POST |
| Tipe aplikasi yang didukung | appType-Aplikasi internal, appType-Aplikasi perusahaan pihak ketiga |
| Izin yang diperlukan | permission-qyapi_report_manage-Izin pengelolaan data log karyawan |

### Parameter query

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses yang digunakan untuk memanggil API ini. Dapatkan melalui API [Mendapatkan token pengguna](/id/open/development/obtain-user-token). |

### Parameter path

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| docKey | String | Ya | ID Dokumen (doc_key atau dentryUuid). |

### Isi permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| dataType | String | Tidak | Tipe data dari konten yang ditimpa. |
| content | String | Ya | Isi konten. |

### Contoh permintaan

```http
POST /v2.0/doc/me/suites/documents/Z90D4da/overwriteContent HTTP/1.1
Host:api.dingtalk.io
x-acs-dingtalk-access-token:access_token
Content-Type:application/json

{
  "dataType" : "markdown",
  "content" : "# Judul"
}
```
