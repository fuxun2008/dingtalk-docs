Panggil API ini untuk mengonfigurasi visibilitas atribut pengguna.

## Permintaan

### Informasi dasar

| Bidang | Nilai |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/v1.0/contact/staffAttributes/visibilitySettings |
| Metode HTTP | POST |
| Tipe aplikasi yang didukung | appType-Aplikasi internal　appType-Aplikasi perusahaan pihak ketiga |
| Izin yang diperlukan | permission-Contact.ReachableRule.ReadWrite-Izin pengelolaan visibilitas data Kontak |

### Header permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses yang digunakan untuk memanggil API ini. Dapatkan sebagai berikut:   - Untuk aplikasi internal, panggil API [Dapatkan access token dari aplikasi internal](/id/open/development/obtain-the-access-token-of-an-internal-app#). - Untuk aplikasi perusahaan pihak ketiga, panggil API [Dapatkan access token dari perusahaan yang diotorisasi ke aplikasi pihak ketiga](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#). |

### Isi permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| id | Long | Tidak | ID pengaturan.       - Kosongkan saat menambahkan pengaturan baru. - Berikan ID pengaturan yang akan diubah saat memperbarui. |
| name | String | Tidak | Nama pengaturan. |
| description | String | Tidak | Deskripsi pengaturan. |
| objectStaffIds | Array of String | Tidak | userId karyawan yang bidangnya disembunyikan. Dapatkan nilai parameter userid dengan memanggil [Dapatkan ID pengguna menggunakan kode login senyap](/id/open/development/obtain-the-userid-of-a-user-by-using-the-log-free). |
| objectDeptIds | Array of Long | Tidak | deptId departemen yang bidangnya disembunyikan. Dapatkan nilai parameter dept_id dengan memanggil [Dapatkan daftar departemen](/id/open/development/user-management-acquires-the-list-departments). |
| objectTagIds | Array of Long | Tidak | roleId peran yang bidangnya disembunyikan. Dapatkan nilai parameter id dengan memanggil [Dapatkan daftar peran organisasi](/id/open/development/obtains-a-list-of-enterprise-roles). |
| hideFields | Array of String | Tidak | Daftar ID atribut pengguna yang akan disembunyikan.   - Jika atribut pengguna yang akan disembunyikan adalah atribut organisasi kustom, berikan ID atribut. - Jika atribut pengguna yang akan disembunyikan adalah atribut default sistem, berikan daftar atribut default sistem.       Daftar atribut default sistem adalah sebagai berikut:   - **name**: Nama - **department**: Departemen - **email**: Email - **manager**: Manajer langsung - **title**: Jabatan - **mobile**: Nomor ponsel - **ext_number**: Nomor ekstensi - **work_station**: Lokasi Kerja - **remark**: Alias - **hire_date**: Tanggal masuk - **job_number**: ID Karyawan |
| excludeStaffIds | Array of String | Tidak | userId karyawan yang dapat melihat bidang yang disembunyikan. |
| excludeDeptIds | Array of Long | Tidak | deptId departemen yang dapat melihat bidang yang disembunyikan. |
| excludeTagIds | Array of Long | Tidak | roleId peran yang dapat melihat bidang yang disembunyikan. |
| active | Boolean | Tidak | Apakah pengaturan berlaku.   - **true**: Berlaku. - **false**: Tidak berlaku. |

### Kode error

Jika error dikembalikan saat Anda memanggil API ini, temukan solusinya di dokumen [Kode error global](/id/open/development/server-api-error-codes-1) berdasarkan pesan error.

| HttpCode | Kode error | Pesan error | Deskripsi |
| --- | --- | --- | --- |
| 400 | parameter.error | Parameter error | Error parameter |
| 400 | ruleNum.exceed.limit | The number of visibility rules of this type has reached the upper limit | Jumlah aturan telah mencapai batas maksimum |
| 400 | forbid.add.rule | The number of visibility rules for the current organization has exceeded the limit. Adding new rules is not allowed | Penambahan aturan baru tidak diizinkan |
| 400 | directory.invalid | The rule directory is unavailable | Direktori aturan tidak tersedia |
| 500 | system.error | Update error | Error pembaruan |
