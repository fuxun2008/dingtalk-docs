## Apa itu DingTalk Drive

DingTalk Drive adalah drive perusahaan yang dibangun di atas Alibaba Cloud dan menghadirkan pengelolaan data yang cerdas serta aman bagi organisasi. Ini adalah platform pengelolaan file terpadu yang menggabungkan penyimpanan file, pengelolaan, dan kolaborasi multi-pengguna. Dengan DingTalk Drive, Anda dapat menyimpan, mengedit, dan membagikan materi kerja serta belajar di perangkat apa pun, kapan saja dan di mana saja, sehingga kolaborasi dokumen menjadi lebih efisien.

DingTalk Drive terdiri dari drive pribadi dan drive perusahaan. Drive perusahaan berisi tiga folder:

1. File Saya dan File Tim.
2. File grup.
3. Penyimpanan untuk aplikasi mikro lainnya, yang dapat Anda lihat di **DingTalk Drive > Manajemen Kapasitas > Aplikasi Mikro** pada konsol OA.

Drive pribadi menyediakan kapasitas awal 2 GB, dan drive perusahaan menyediakan kapasitas awal 100 GB. Untuk fitur selengkapnya, lihat [Panduan Pengguna DingTalk - DingTalk Drive](https://docs.dingtalk.io/i/p/Y7kmbokZp3pgGLq2/docs/6wPdlBDrQk4JYrl0vX2Y8XKx72oEGeL5).

## Glosarium

### spaceId

DingTalk Drive menggunakan ruang sebagai wadah untuk penyimpanan file, mirip dengan drive seperti C: atau E: pada komputer. Misalnya, di DingTalk, setiap kumpulan file grup berkaitan dengan sebuah ruang, dan area publik, folder berbagi, serta File Saya pada drive perusahaan masing-masing berkaitan dengan ruang yang terpisah.

### fileId

Pengidentifikasi unik dari sebuah file di DingTalk Drive.

### Ruang kustom

Untuk memenuhi kebutuhan yang dipersonalisasi dari organisasi atau ISV, DingTalk Drive menyediakan ruang kustom di dalam setiap organisasi. Sebuah organisasi dapat membuat beberapa ruang penyimpanan kustom, dan setiap aplikasi mikro dapat menggunakan satu ruang penyimpanan kustom. Ruang kustom tidak terlihat di Sisi klien DingTalk, tetapi Anda dapat melihat penyimpanan organisasi yang digunakannya di konsol admin.

### Izin DingTalk Drive

Berbeda dengan penyimpanan file standar, DingTalk Drive menyediakan pengelolaan izin yang menyeluruh. Tindakan seperti mengunggah, mengunduh, dan melihat file hanya dapat dilakukan jika izin mengizinkannya.

### Server penyimpanan dan server DingTalk Drive

Server penyimpanan menyediakan penyimpanan file, di mana setiap file diidentifikasi secara unik oleh `mediaId`. Server DingTalk Drive mengelola hierarki folder, izin, dan layanan lainnya, serta mengidentifikasi setiap file secara unik melalui `fileId`. File pada server penyimpanan dapat ditambahkan ke sistem file DingTalk Drive.

### Kapasitas ruang perusahaan

Kapasitas penyimpanan di DingTalk Drive adalah sumber daya yang terbatas. Kapasitas tambahan di luar kuota yang disertakan memerlukan pembelian berbayar. DingTalk Drive menyediakan penyimpanan gratis sebesar 100 GB untuk setiap organisasi, dan setiap ruang kustom yang digunakan oleh aplikasi mikro akan diperhitungkan terhadap kuota perusahaan ini.
