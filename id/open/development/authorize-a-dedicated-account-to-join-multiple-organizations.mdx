description: "Panggil API ini untuk mengotorisasi Akun Perusahaan agar dapat bergabung ke beberapa organisasi di DingTalk; hanya akun yang telah diotorisasi yang dapat bergabung ke organisasi eksternal."
---

Panggil API ini untuk mengotorisasi Akun Perusahaan agar dapat bergabung ke beberapa organisasi. Akun Perusahaan hanya dapat bergabung ke organisasi eksternal setelah diotorisasi.

## Deskripsi panggilan API

Setelah otorisasi berhasil, Akun Perusahaan hanya dapat ditambahkan ke organisasi melalui panggilan API.

## Permintaan

### Informasi dasar

| Bidang | Nilai |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/v1.0/contact/orgAccounts/multiOrgPermissions/auth |
| Metode HTTP | POST |
| Jenis aplikasi yang didukung | appType-Aplikasi internal |
| Izin yang diperlukan | permission-Contact.OrgAccountSecurity.ReadWrite-Izin baca dan tulis untuk data keamanan Akun Perusahaan Kontak |

### Header permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Dapatkan dengan memanggil API [Memperoleh access token aplikasi internal](/id/open/development/obtain-the-access-token-of-an-internal-app#). |

### Isi permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| joinCorpId | String | Ya | CorpId dari organisasi yang akan diotorisasi. |
| grantDeptIdList | Array of Long | Tidak | Daftar departemen yang diotorisasi.   - Jika parameter ini tidak ditentukan, seluruh organisasi diotorisasi. - Jika parameter ini ditentukan, departemen yang sesuai dengan nilai parameter akan diotorisasi. |
