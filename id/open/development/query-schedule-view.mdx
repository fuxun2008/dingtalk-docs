Panggil API ini untuk mengueri daftar acara pengguna dalam rentang waktu tertentu. Anda dapat memperoleh informasi seperti judul acara, tanggal mulai, waktu mulai, tanggal berakhir, dan waktu berakhir.

## Deskripsi panggilan API

- Perbedaan antara API ini dan API **Kueri daftar acara** terletak pada cara acara berulang ditangani. API ini memperluas semua acara berulang dalam rentang kueri berdasarkan aturan pengulangan, tetapi tidak benar-benar menghasilkan instance terkait di database. Misalnya, jika ada acara berulang harian yang dimulai pada 1 Januari, tanggal saat ini adalah 4 Januari, dan rentang kueri adalah 1 Januari hingga 10 Januari, API ini mengembalikan semua acara berulang dari 1 Januari hingga 10 Januari, sedangkan API [Kueri daftar acara](/id/open/development/query-an-event-list#) tidak mengembalikan acara setelah 4 Januari.
- Anda dapat menentukan apakah suatu acara merupakan instance dari acara berulang dengan memeriksa apakah `seriesMasterId` dari objek acara yang dikembalikan bernilai kosong.

| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. ### Parameter path

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| userId | String | Ya | unionId dari pengguna yang akan dikueri.   - Untuk aplikasi internal dan aplikasi perusahaan pihak ketiga, panggil API [Kueri detail pengguna](/id/open/development/query-user-details#) untuk memperoleh nilai parameter `unionid`. - Untuk aplikasi personal pihak ketiga, panggil API [Memperoleh profil pengguna dari Kontak](/id/open/development/dingtalk-retrieve-user-information#) untuk memperoleh nilai parameter `unionId`. |
| calendarId | String | Ya | ID kalender tempat acara berada. Panggil API [Kueri kalender](/id/open/development/query-a-calendar#) untuk mengueri acara pengguna saat ini. Gunakan kata kunci **primary** untuk merujuk ke kalender utama pengguna saat ini. |

### Parameter kueri

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| timeMin | String | Tidak | Mengueri acara yang waktu berakhirnya >= TimeMin. Formatnya adalah format tanggal-waktu ISO-8601. |
| timeMax | String | Tidak | Mengueri acara yang waktu mulainya `< timeMax`. Formatnya adalah format tanggal-waktu ISO-8601. |
| maxResults | Integer | Tidak | Jumlah maksimum record yang dikembalikan. Nilai maksimum adalah 100, dan nilai default adalah 100. |
| maxAttendees | Integer | Tidak | Jumlah peserta yang dikembalikan untuk setiap acara. Nilai default adalah 100, dan nilai maksimum adalah 100. Jika jumlah peserta melebihi 100 dan Anda perlu memperoleh semua peserta, gunakan API [Memperoleh peserta acara](/id/open/development/get-the-participants-of-a-schedule#). |
| nextToken | String | Tidak | Cursor paginasi.      Jika satu kueri tidak dapat mengembalikan semua hasil, token paginasi akan dikembalikan. Kirim token ini pada kueri berikutnya untuk mengambil data selanjutnya, hingga token paginasi bernilai null, yang menandakan bahwa semua data telah dikueri. |

| responseStatus | String | Status respons ruang rapat.   - **accepted**: Diterima - **tentative**: Menunggu persetujuan - **declined**: Persetujuan ditolak |
| displayName | String | Nama ruang rapat. |
