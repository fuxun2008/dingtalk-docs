title: "Dapatkan detail absen"
description: "Gunakan API DingTalk untuk mengambil detail absen karyawan, termasuk waktu, lokasi, dan validitas, berdasarkan daftar userId dan rentang hari kerja hingga 7 hari."
---

Panggil API ini untuk mendapatkan detail absen aktual karyawan di organisasi Anda.

## Deskripsi panggilan API

- API ini tidak mendukung kueri data yang lebih lama dari 180 hari.
- Jika Anda hanya memerlukan hasil absen tanpa data detail, panggil API [Dapatkan hasil absen](/id/open/development/open-attendance-clock-in-data).
- Sinkronisasi data absensi dapat mengalami keterlambatan. Jika data belum lengkap, coba lagi nanti.
- **Jika pengguna memiliki jadwal shift pada hari tertentu tetapi tidak melakukan absen, API ini mengembalikan data kosong**.
- API ini mengembalikan semua detail absen, termasuk data absen untuk skenario yang memerlukan konfirmasi sekunder, seperti keterlambatan. Catatan tersebut merupakan absen yang tidak valid. Filter catatan tersebut sesuai skenario bisnis Anda setelah data diambil. Perhatikan parameter output `invalidRecordType`, `isLegal`, dan `invalidRecordMsg`.

Sebagai contoh, sebuah organisasi menjadwalkan karyawan untuk absen pada pukul 09.00 dan 18.00. Jika karyawan melakukan absen beberapa kali dalam periode tersebut, API ini mengembalikan semua catatan absen.

Untuk melihat data absen mentah yang sama di konsol Absensi, buka **Statistik kehadiran** > **Manajemen laporan** > **Catatan mentah**. Setiap catatan memuat kolom berikut: **Nama**, **Grup absensi**, **Departemen**, **Nomor karyawan**, **Jabatan**, **Tanggal absensi**, **Waktu absensi** (waktu shift terjadwal), **Waktu absen**, dan **Hasil absen**. Hasil seperti *absen susulan disetujui* menunjukkan bahwa catatan berasal dari koreksi yang telah disetujui, bukan dari absen langsung.

## Permintaan

| **Informasi dasar** | |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/attendance/listRecord |
| Metode HTTP | POST |
| Tipe aplikasi yang didukung | appType-Aplikasi internal　appType-Aplikasi perusahaan pihak ketiga |
| Izin yang diperlukan | permission-qyapi_get_attendance_data-Izin baca data absensi |

### Parameter query

| Nama | Tipe | Wajib | Contoh | Deskripsi |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | bE74xxxx | Kredensial aplikasi yang digunakan untuk memanggil API ini.   - Untuk Aplikasi internal, panggil API [Dapatkan access_token Aplikasi internal](/id/open/development/obtain-orgapp-token) untuk memperolehnya. - Untuk Aplikasi perusahaan pihak ketiga, panggil API Dapatkan access_token Aplikasi perusahaan pihak ketiga untuk memperolehnya. |

### Isi permintaan

| Nama | Tipe | Wajib | Contoh | Deskripsi |
| --- | --- | --- | --- | --- |
| userIds | List | Ya | ["user456","user123"] | Daftar ID karyawan di organisasi Anda. Maksimum: 50.  **Penting**  Pastikan nilai userId sudah benar. Jika tidak, API ini mengembalikan data kosong. |
| checkDateFrom | String | Ya | 2020-09-07 00:00:00 | Hari kerja awal untuk kueri catatan absen. Format: yyyy-MM-dd hh:mm:ss.  Contohnya, jika Anda meneruskan "2021-12-01 10:00:00", absen karyawan pada pukul 09.00 tidak dikembalikan.  **Penting**  Selisih parameter workDateFrom dan workDateTo  maksimal 7 hari (inklusif). |
| checkDateTo | String | Ya | 2020-09-08 00:00:00 | Hari kerja akhir untuk kueri catatan absen. Format: yyyy-MM-dd hh:mm:ss.  Contohnya, jika Anda meneruskan "2021-12-01 18:00:00", absen karyawan pada pukul 19.00 tidak dikembalikan.  **Penting**  Selisih parameter workDateFrom dan workDateTo  maksimal 7 hari (inklusif). |
| isI18n | Boolean | Tidak | true | Menentukan apakah organisasi merupakan organisasi luar negeri:   - **true**: Digunakan di platform luar negeri - **false** (default): Digunakan di platform Tiongkok |

### Contoh permintaan

```curl
curl -X POST "https://api.dingtalk.io/attendance/listRecord" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=7258e1c9-af43-411c-b3f4-bcb069bfbb93' \
-d 'checkDateFrom=2018-01-01' \
-d 'checkDateTo=2018-01-01' \
-d 'isI18n=true' \
-d 'userIds=%221%22%2C%222%22'
```

Java

```java
DingTalkClient client = new DefaultDingTalkClient("https://api.dingtalk.io/attendance/listRecord");
OapiAttendanceListRecordRequest req = new OapiAttendanceListRecordRequest();
req.setUserIds(Arrays.asList("user123","user456"));
req.setCheckDateFrom("2020-11-07 08:00:00");
req.setCheckDateTo("2020-11-12 08:00:00");
req.setIsI18n(false);
OapiAttendanceListRecordResponse rsp = client.execute(req, access_token);
System.out.println(rsp.getBody());
```

Python

```python
import dingtalk.api

req=dingtalk.api.OapiAttendanceListRecordRequest("https://api.dingtalk.io/attendance/listRecord")

req.userIds="[\"1\",\"2\"]"
req.checkDateFrom="2018-01-01"
req.checkDateTo="2018-01-01"
req.isI18n=true
try:
	resp= req.getResponse(access_token)
	print(resp)
except Exception,e:
	print(e)
```

PHP

```php
include "TopSdk.php";
date_default_timezone_set('Asia/Shanghai');

$c = new DingTalkClient(DingTalkConstant::$CALL_TYPE_OAPI, DingTalkConstant::$METHOD_POST , DingTalkConstant::$FORMAT_JSON);
$req = new OapiAttendanceListRecordRequest;
$req->setUserIds("[\"1\",\"2\"]");
$req->setCheckDateFrom("2018-01-01");
$req->setCheckDateTo("2018-01-01");
$req->setIsI18n("true");
$resp = $c->execute($req, $access_token, "https://api.dingtalk.io/attendance/listRecord");
```

C#

```csharp

OapiAttendanceListRecordRequest req = new OapiAttendanceListRecordRequest();
```
