Panggil API ini untuk membuat lembar kerja baru di dokumen spreadsheet.

## Permintaan

### Informasi dasar

| Bidang | Nilai |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/doc/workbooks/{workbookId}/sheets` |
| Metode HTTP | POST |
| Tipe aplikasi yang didukung | appType-Internal app　appType-Third-party enterprise app |
| Izin yang diperlukan | permission-Document.Workbook.Write-DingTalk Spreadsheet write permission |

### Header permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Dapatkan dengan cara berikut:   - Untuk aplikasi internal, panggil API [Dapatkan access token aplikasi internal](/id/open/development/obtain-the-access-token-of-an-internal-app#). - Untuk aplikasi perusahaan pihak ketiga, panggil API [Dapatkan access token organisasi yang diberi otorisasi untuk aplikasi pihak ketiga](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#). |

### Parameter path

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| workbookId | String | Ya | ID file spreadsheet. `nodeId(dentryUuid)` yang dikembalikan oleh [Knowledge Base API](/id/open/development/knowledge-base-overview#) adalah `workbookId` dari spreadsheet. Dapatkan dengan memanggil API [Dapatkan node](https://open.dingtalk.com/document/development/get-node#) atau [Buat dokumen Knowledge Base](/id/open/development/create-team-space-document#). |

### Parameter query

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| operatorId | String | Ya | unionId dari operator. Dapatkan dengan memanggil API [Kueri detail pengguna](/id/open/development/query-user-details#).    Jika operator tidak memiliki izin yang diperlukan, API mengembalikan error `The operator has no permission`. |

### Isi permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| name | String | Ya | Nama lembar kerja.    Jika nama lembar kerja yang ditentukan berbenturan dengan yang sudah ada, nama akan diganti secara otomatis menjadi nilai yang valid. |

### Contoh permintaan

HTTP

```http
POST /v1.0/doc/workbooks/e54Lqxxx/sheets?operatorId=ppgAQuHfOoNVpJiStDwWCEgiEiE HTTP/1.1
Host:api.dingtalk.io
x-acs-dingtalk-access-token:xxxxx
Content-Type:application/json

{
  "name" : "Sheet1"
}
```

## Respons

### Isi respons

| Nama | Tipe | Deskripsi |
| --- | --- | --- |
| visibility | String | Visibilitas lembar kerja. Nilai tetapnya adalah visible. |
| name | String | Nama lembar kerja. |
| id | String | ID lembar kerja. |

### Contoh isi respons

```text
HTTP/1.1 200 OK
Content-Type:application/json

{
  "visibility" : "visible",
  "name" : "Sheet1",
  "id" : "st-xxxxx"
}
```
