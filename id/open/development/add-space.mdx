title: "Menambahkan ruang"
description: "Panggil API ini untuk membuat ruang penyimpanan baru pada DingTalk Drive perusahaan, lalu buat folder dan unggah file di dalamnya untuk mengelola penyimpanan cloud organisasi."
---

Panggil API ini untuk membuat ruang baru di cloud drive organisasi Anda. Di dalam ruang tersebut, Anda dapat membuat folder, mengunggah file, dan melakukan tindakan lainnya.

## Deskripsi panggilan API

### Tentang ruang penyimpanan

- Ruang penyimpanan adalah bagian dari cloud drive organisasi Anda, tetapi ruang yang dibuat melalui API ini tidak terlihat di cloud drive sisi klien.
- Ruang penyimpanan mengonsumsi kapasitas cloud drive organisasi Anda.

### Tipe ruang penyimpanan

- Ruang pengguna (USER): File di ruang ini hanya dapat diberikan izin permanen, dan pemberi izin harus memiliki izin pengelolaan untuk memberikan akses.
- Ruang aplikasi (APP): File di ruang ini hanya dapat diberikan izin sementara, dan pemberi izin tidak diwajibkan memiliki izin pengelolaan.
