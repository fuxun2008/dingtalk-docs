Artikel ini memperkenalkan alat debug aplikasi mikro H5 dan cara menggunakannya.

## Pengenalan

Alat debug aplikasi mikro H5 adalah alat debug aplikasi mikro H5 baru yang dirilis oleh DingTalk Open Platform. Pada halaman debug, Anda dapat melihat **Elements**, **Console**, **Network**, dan **AppLog** dari aplikasi yang sedang berjalan. Fungsinya mirip dengan Chrome DevTools.

### Alat Debug Aplikasi Mikro H5 saat ini mendukung fitur berikut

- Debug tag dan gaya
- Mencetak pernyataan debug dan menjalankan perintah
- Melihat permintaan jaringan
- Melihat panggilan JSAPI

## Alur kerja

Ikuti langkah-langkah berikut untuk melakukan debug dengan alat debug aplikasi mikro H5.

1. Masuk ke [Developer Backend](https://open-dev.dingtalk.com/), lalu buka halaman **App Details** yang dituju.
2. Pada halaman **App Details**, klik **Development Management**, lalu pilih **Development Tools**, dan klik **Generate Dedicated Debugging Tool**.

3. Ikuti petunjuk di layar untuk membuka halaman alat debug.

4. Salin kode debug khusus untuk aplikasi ini, lalu tambahkan kode tersebut ke tag `<header></header>` pada aplikasi mikro.

5. Mulai debug.

## FAQ

### T: Alat debug DevTools tidak terhubung atau telah terputus. Muat ulang alat debug DevTools, lalu muat ulang halaman saat ini.

J: Pastikan untuk membuka halaman alat debug DevTools terlebih dahulu, lalu buka halaman aplikasi mikro.

### T: Klien lain sudah melakukan debug melalui tautan DevTools yang sama. Buat tautan debug DevTools baru.

J: Untuk tautan alat debug DevTools yang sama, hanya satu halaman yang dapat melakukan debug dengannya pada satu waktu. Klik tombol **Generate Debugging Tool** lagi untuk membuat tautan alat debug DevTools yang baru.

### T: Terjadi kesalahan saat melakukan debug JSAPI: [No permission info for action: xxx].

J: Lihat &lt;https://www.npmjs.com/package/dingtalk-jsapi> untuk melakukan inisialisasi sebelum memanggil JSAPI.

### T: Terjadi kesalahan saat melakukan debug JSAPI: [The current micro app is not in your organization].

J: Buat aplikasi mikro H5 baru untuk debug, lalu masukkan ip:port dari aplikasi mikro saat ini pada URL halaman Beranda aplikasi yang baru dibuat.

### T: Header permintaan dan Header respons tidak ada selama permintaan jaringan.

J: Header permintaan yang hilang terkait dengan Kebijakan Keamanan peramban. Untuk Header respons yang hilang, periksa apakah Header respons API telah dikonfigurasi dengan bidang Access-Control-Expose-Headers.
