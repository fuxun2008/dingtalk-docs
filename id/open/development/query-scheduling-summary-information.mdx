description: "Panggil API DingTalk ini untuk mengambil ringkasan penjadwalan shift beberapa pengguna sekaligus: nama shift, ID versi shift, dan ID grup absensi dalam rentang maksimal 7 hari."
---

Panggil API ini untuk mengkueri ringkasan penjadwalan shift pengguna dalam rentang waktu tertentu. Ringkasan mencakup nama shift, ID versi shift, dan ID grup absensi.

## Permintaan

| **Informasi dasar** | |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/topapi/attendance/schedule/shift/listbydays |
| Metode HTTP | POST |
| Tipe aplikasi yang didukung | appType-Aplikasi internal |
| Izin yang diperlukan | permission-qyapi_attendance_group_manage-Izin kelola grup absensi |

### Parameter kueri

| Nama | Tipe | Wajib | Contoh | Deskripsi |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | 57cf92xxx | Kredensial aplikasi untuk memanggil API ini. Dapatkan kredensial dengan memanggil API [Mendapatkan access_token Aplikasi internal](/id/open/development/obtain-orgapp-token). |

### Isi permintaan

| Nama | Tipe | Wajib | Contoh | Deskripsi |
| --- | --- | --- | --- | --- |
| op_user_id | String | Ya | manager123 | ID pengguna operator. |
| userids | String | Ya | user123,user456 | Daftar ID pengguna yang akan dikueri. Pisahkan beberapa ID pengguna dengan koma. Setiap kueri mendukung maksimal 20 ID pengguna. |
| from_date_time | Number | Ya | 1564985177000 | Unix timestamp tanggal mulai, dalam milidetik.  **Catatan**  Rentang waktu tidak boleh melebihi 7 hari. |
| to_date_time | Number | Ya | 1564985177000 | Unix timestamp tanggal akhir, dalam milidetik.  **Catatan**  Rentang waktu tidak boleh melebihi 7 hari. |

### Contoh permintaan

```curl
curl -X POST "https://api.dingtalk.io/topapi/attendance/schedule/shift/listbydays" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=ecff22xxxx1f8d5d' \
-d 'from_date_time=1564985177000' \
-d 'op_user_id=dd_dd' \
-d 'to_date_time=1564985177000' \
-d 'userids=dd_test%2Ctl2342'
```

## Respons

### Isi respons

| Nama | Tipe | Contoh | Deskripsi |
| --- | --- | --- | --- |
| result | TopDayScheduleShiftVo[] |  | Daftar hasil yang dikembalikan. |
| work_date | Date | 2020-12-14 00:00:00 | Hari kerja. |
| shift_names | String[] | ["A"] | Nama shift. |
| userid | String | user123 | ID pengguna. |
| shift_versions | Number[] | [9527] | ID versi shift. |
| shift_ids | Number[] | [9087] | ID shift. |
| group_id | Number | 7786 | ID grup absensi. |
| corp_id | String | dinge8xxx | ID organisasi. |
| success | Boolean | true | Menunjukkan apakah panggilan berhasil.   - **true**: Berhasil - **false**: Gagal |
| errcode | Number | 0 | Kode pengembalian. |
| errmsg | String | ok | Deskripsi kode pengembalian. |
| request_id | String | 5fyefrdh2mf4 | ID permintaan. |
