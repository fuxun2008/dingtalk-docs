Aplikasi perusahaan pihak ketiga dapat mengirim notifikasi pesan melalui templat pesan.

Templat pesan merupakan peningkatan dari pengiriman pesan melalui Notifikasi Kerja. Templat ini memberikan pengalaman pengembangan dan konfigurasi templat pesan yang lebih ringkas dan terstandardisasi, sekaligus menghadirkan kemampuan notifikasi pesan yang lebih aman, terkelola, dan terkendali bagi pelanggan.

**Catatan**

Perhatikan hal berikut saat menggunakan templat pesan:

- Hanya **aplikasi perusahaan pihak ketiga** yang didukung.
- Hanya templat pesan yang telah disetujui yang dapat digunakan untuk mengirim pesan Notifikasi Kerja.

## Tipe templat

Saat ini tersedia tiga tipe templat pesan berikut.

- Templat Markdown

  Templat Markdown menggunakan sintaks Markdown untuk mengonfigurasi dan mengirim pesan. Templat ini cocok untuk pesan notifikasi murni yang tidak memerlukan tindakan. Dengan templat Markdown, Anda dapat dengan mudah mendukung teks, gambar, tautan, dan format tampilan lainnya.
- Templat ActionCard

  Templat ActionCard mengirim pesan menggunakan tipe pesan ActionCard. Templat ini mendukung pesan yang menggabungkan konten dengan titik tindakan, dan cocok untuk skenario yang memerlukan satu atau beberapa titik tindakan guna menangani tugas dengan cepat di dalam sebuah pesan.

  Dibangun di atas templat Markdown, templat ActionCard mendukung gaya lompatan keseluruhan maupun lompatan mandiri.
- Templat Formulir

  Templat Formulir mengirim pesan berdasarkan tipe pesan OA. Templat ini cocok untuk menampilkan pesan seperti pesanan dan mendukung lompatan untuk melihat detail pesan.

## Alur kerja

Seperti ditunjukkan pada gambar di bawah, mengirim Notifikasi Kerja menggunakan templat pesan memerlukan langkah-langkah berikut:

1. Buat dan konfigurasikan templat pesan. Untuk detailnya, lihat [Kelola Templat Pesan](/zh/open/development/manage-message-templates).
2. Dapatkan persetujuan atas templat.
3. Panggil API untuk mengirim Notifikasi Kerja dengan templat. Untuk detailnya, lihat [Kirim Pesan Notifikasi Kerja Menggunakan Templat](/zh/open/development/work-notification-templating-send-notification-interface).
