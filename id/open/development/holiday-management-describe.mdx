Sebagian besar organisasi memiliki aturan sendiri dalam pemberian cuti. Misalnya, organisasi dapat memberikan saldo cuti yang berbeda berdasarkan jabatan karyawan. Saat ini, aturan cuti DingTalk belum mendukung logika kustom semacam ini. Untuk itu, DingTalk menyediakan Open API cuti agar organisasi dapat mendukung skenario kustom tersebut.

<Warning>
Sebelum memanggil API cuti, minta Izin API yang diperlukan di Developer Console.
</Warning>

## Minta izin

Minta Izin API sebelum memanggil API manajemen cuti:

1. Masuk ke [Developer Console](https://open-dev.dingtalk.io/#/appMgr/provider/eapp/53642/1), lalu klik Aplikasi yang dituju.
2. Klik **Kelola izin**, lalu klik **Absensi**.
3. Tambahkan Izin API manajemen cuti, lalu klik **Minta izin** atau **Minta secara massal**.

### Catatan

   Jika permintaan izin ditolak, cari Izin API **manajemen cuti** di kolom **Permintaan**. Arahkan kursor ke **Ditolak** untuk melihat alasannya.

   Di konsol Aplikasi, buka **Informasi Dasar** > **Kelola izin**, lalu cari izin manajemen cuti dalam daftar:

| Izin | Kode | API yang tercakup |
| --- | --- | --- |
| Manajemen cuti DingTalk | `qyapi_holiday_manage` | Tambah aturan cuti, Perbarui aturan cuti, Hapus aturan cuti |
| Kueri cuti DingTalk | `qyapi_holiday_readonly` | Kueri daftar aturan cuti, Kueri saldo cuti, Kueri massal catatan perubahan saldo cuti karyawan |

Klik **Minta izin** di samping setiap izin.

## Skenario 1: Sinkronkan aturan cuti

Gunakan API cuti untuk menyinkronkan aturan cuti yang sudah ada di organisasi Anda ke sistem manajemen cuti DingTalk ([Admin Console DingTalk](https://oa.dingtalk.io/?lang=id_ID) **> Workbench > Kelola Aplikasi > Persetujuan OA**).

Di Admin Console **Persetujuan OA**, buka **Manajemen Cuti** > **Aturan Cuti**, lalu klik **Tambah cuti** untuk menentukan aturan cuti. Konfigurasikan setiap aturan dengan kolom berikut:

| Kolom | Deskripsi |
|---|---|
| **Nama cuti** | Contoh: Cuti Pribadi, Cuti Pengganti, Cuti Sakit, Cuti Tahunan, Cuti Melahirkan, Cuti Ayah, atau Cuti Menikah |
| **Satuan cuti** | Per jam, per setengah hari, atau per hari |
| **Perhitungan durasi** | Contoh: berdasarkan hari kerja |
| **Berbayar** | Menentukan apakah cuti tersebut berbayar |
| **Aturan saldo** | Contoh: saldo tidak terbatas |
| **Cakupan** | Contoh: seluruh perusahaan |
| **Tindakan** | Edit atau Hapus |

Selanjutnya, pada desain formulir untuk Formulir pengajuan cuti, tambahkan kit absensi Persetujuan yang disediakan oleh DingTalk. Kit ini secara otomatis menghitung saldo cuti dan menyinkronkannya ke Aplikasi Absensi DingTalk.

Editor Formulir Persetujuan OA terdiri atas empat langkah: **Pengaturan Dasar** > **Desain Formulir** > **Desain Proses** > **Pengaturan Lanjutan**. Pada langkah **Desain Formulir**, buka tab **Kit**. Di bagian **Kit absensi**, tambahkan **Kit Cuti/Izin Tidak Masuk** ke Formulir.

## Skenario 2: Sinkronkan saldo cuti internal ke Persetujuan DingTalk

Jika organisasi Anda memiliki aturan cuti sendiri dan perlu menyinkronkan saldo cuti internal ke Persetujuan DingTalk, gunakan API berikut (Aplikasi internal digunakan sebagai contoh):

1. Panggil API [Inisialisasi saldo cuti](/id/open/development/initialize-holiday-balance).
2. Sebagai Admin, buka [Admin Console DingTalk](https://oa.dingtalk.io/?lang=id_ID) **> Workbench > Kelola Aplikasi > Persetujuan OA > Manajemen Cuti > Saldo Cuti Karyawan** untuk melihat saldo Karyawan yang telah diperbarui.

Di halaman **Saldo Cuti Karyawan**, klik **Atur Aturan Cuti Karyawan** atau **Edit Saldo Massal via Excel**. Filter berdasarkan cakupan organisasi, dan jika perlu, pilih **Sertakan karyawan yang keluar dalam 90 hari terakhir**. Setiap catatan menampilkan satu Karyawan dengan kolom berikut: **Nama**, **Departemen**, **Tanggal Bergabung**, **Tanggal Mulai Bekerja Pertama**, **Cuti Pribadi (jam)**, **Cuti Pengganti (jam)**, **Cuti Sakit (jam)**, **Cuti Tahunan (hari)**, dan **Cuti Melahirkan (hari)**.
