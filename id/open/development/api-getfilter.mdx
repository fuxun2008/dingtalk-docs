---
title: "Mendapatkan filter"
description: "Panggil API ini untuk mengambil filter global yang sedang aktif pada Lembar Kerja tertentu di DingTalk Spreadsheet — menampilkan ID filter, rentang, dan kondisi per kolom untuk memverifikasi status atau membaca konfigurasi filter."
---

Panggil API ini untuk membaca filter global yang sedang berlaku pada Lembar Kerja tertentu. Respons mengembalikan ID filter, rentang filter, dan kondisi filter yang diatur untuk setiap kolom. Ini berguna untuk memverifikasi status filter saat ini sebelum mengubah kondisi filter, atau untuk membaca konfigurasi filter secara programatik guna pemrosesan lebih lanjut.

## Permintaan

### Informasi dasar

| Bidang | Nilai |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/doc/workbooks/{workbookId}/sheets/{sheetId}/filter/getFilter` |
| Metode HTTP | GET |
| Tipe aplikasi yang didukung | appType-企业内部应用 |
| Izin yang diwajibkan | permission-Document.Workbook.Read-钉钉表格读权限 |

### Header permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Panggil API [Mendapatkan access token dari aplikasi internal](/id/open/development/obtain-the-access-token-of-an-internal-app) untuk memperolehnya. |

### Parameter path

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| workbookId | String | Ya | ID dari file Spreadsheet. `nodeId(dentryUuid)` yang dikembalikan oleh [Knowledge Base API](/id/open/development/knowledge-base-overview) adalah `workbookId` dari Spreadsheet tersebut. Panggil API [Mendapatkan node](/id/open/development/get-knowledge-base-acquisition-node) atau [Membuat dokumen Knowledge Base](/id/open/development/create-team-space-document) untuk memperolehnya. |
| sheetId | String | Ya | ID atau nama Lembar Kerja. Panggil API [Mendapatkan semua Lembar Kerja](/id/open/development/obtain-all-worksheets) untuk memperoleh nilai parameter `id` atau `name`.  **Catatan**  Jika tidak ada filter pada Lembar Kerja, API mengembalikan error 404. |

### Parameter query

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| operatorId | String | Ya | unionId dari operator.   - Panggil API [Mendapatkan informasi pengguna melalui kode Login senyap](/id/open/development/obtain-the-userid-of-a-user-by-using-the-log-free) untuk memperoleh nilai parameter `unionid`. - Panggil API [Kueri detail pengguna](/id/open/development/query-user-details) untuk memperoleh nilai parameter `unionid`.       Jika operator tidak memiliki izin, API mengembalikan error `The operator has no permission`. |

## Respons

### Isi respons

| Nama | Tipe | Deskripsi |
| --- | --- | --- |
| id | String | Pengidentifikasi unik dari filter. |
| range | String | Rentang filter dalam notasi A1. |
| criteria | `Map<String, Object>` | Pemetaan kondisi filter untuk semua kolom. Key adalah offset kolom (relatif terhadap kolom pertama dari rentang filter, dimulai dari 0), dan value adalah object kondisi filter untuk kolom tersebut. Jika tidak ada kondisi filter yang diatur, sebuah object kosong `{}` akan dikembalikan. |
|  | Object | Kondisi filter dari kolom saat ini. |
| filterType | String | Tipe filter. Nilai yang valid:   - **values**: filter berdasarkan nilai. - **color**: filter berdasarkan warna. - **condition**: filter berdasarkan kondisi. |
| visibleValues | Array of String | Nilai yang terlihat. |
| conditions | Array | Daftar kondisi saat memfilter berdasarkan kondisi. Dikembalikan hanya ketika `filterType` bernilai `condition`. |
| operator | String | Operator kondisi. Nilai yang valid:   - **equal**: sama dengan. - **not-equal**: tidak sama dengan. - **contains**: mengandung. - **not-contains**: tidak mengandung. - **starts-with**: diawali dengan. - **not-starts-with**: tidak diawali dengan. - **ends-with**: diakhiri dengan. - **not-ends-with**: tidak diakhiri dengan. - **greater**: lebih besar dari. - **greater-equal**: lebih besar dari atau sama dengan. - **less**: lebih kecil dari. - **less-equal**: lebih kecil dari atau sama dengan. |
| value | String | Nilai kondisi. |
| conditionOperator | String | Hubungan logis antara beberapa kondisi (`and` atau `or`). Dikembalikan hanya ketika `filterType` bernilai `condition`. |
| backgroundColor | String | Warna yang terlihat saat memfilter berdasarkan warna latar belakang, dalam format heksadesimal. Dikembalikan hanya ketika `filterType` bernilai `color` dan memfilter berdasarkan warna latar belakang. |
| fontColor | String | Warna yang terlihat saat memfilter berdasarkan warna font, dalam format heksadesimal. Dikembalikan hanya ketika `filterType` bernilai `color` dan memfilter berdasarkan warna font. |
