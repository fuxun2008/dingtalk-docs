Artikel ini memperkenalkan model penagihan App Development Platform.

App Development Platform menyediakan berbagai jenis aplikasi dan kemampuan aplikasi yang kaya bagi developer perusahaan untuk mendukung transformasi digital perusahaan. Penggunaan Open API yang dikonsumsi oleh pengembangan aplikasi internal diukur, dan penggunaan pesan Webhook serta Stream oleh Langganan peristiwa dan Bot Kustom dikenakan biaya.

## **Aturan penghitungan**

- Panggilan gagal yang disebabkan oleh batas laju QPS satu aplikasi, batas laju QPS API global, jaringan tidak terjangkau, dan alasan serupa tidak dihitung dalam Jumlah panggilan.
- Open API dasar tidak dikenakan biaya. Untuk detailnya, lihat Appendix A: List of APIs Not Included in the Monthly Call Count Limit.
- Langganan peristiwa dasar tidak dikenakan biaya. Untuk detailnya, lihat Appendix B: List of Events Not Included in the Webhook and Stream Usage Limit.

## **Rekomendasi penggunaan**

Untuk memanggil endpoint API DingTalk secara lebih efisien dan wajar, perhatikan poin-poin berikut:

1. **Optimalkan logika panggilan API**: Misalnya, jika sebuah API membaca data DingTalk, hindari memanggilnya dengan pengatur waktu berulang (polling). Jika diperlukan, integrasikan notifikasi callback DingTalk untuk secara efektif mengurangi Jumlah panggilan dan lebih menjamin ketepatan waktu data.
2. **Periksa Kode error API**: Misalnya, ketika panggilan API mengembalikan error, tentukan penyebabnya berdasarkan Kode error. Jangan mencoba ulang tanpa batas, dan kendalikan jumlah percobaan ulang.
3. Untuk batas laju QPS tingkat aplikasi pada API, lihat Appendix C: How to Handle Rate Limiting on the DingTalk Server API.

Untuk menggunakan saluran pesan Webhook dan Stream DingTalk secara lebih efisien dan wajar, perhatikan hal berikut:

1. **Optimalkan solusi Langganan peristiwa Anda dengan mengikuti prinsip-prinsip ini**: Berlangganan hanya untuk peristiwa yang diperlukan, lakukan deduplikasi penanganan event, serta respons dan kembalikan dengan cepat. Untuk detailnya, lihat Appendix D: Recommendations for Rational Use of Resources.
