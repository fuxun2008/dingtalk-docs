title: "Terima atau tolak tugas persetujuan"
description: "Panggil API DingTalk ini untuk menerima atau menolak tugas persetujuan berdasarkan ID instans dan ID tugas, lengkap dengan komentar persetujuan dan lampiran."
---

Panggil API ini untuk memproses satu tugas persetujuan berdasarkan ID templat, ID instans persetujuan, ID node tugas, dan userId operator yang ditentukan.

## Deskripsi panggilan API

1. Satu proses persetujuan dapat berisi beberapa node persetujuan, dan satu node persetujuan dapat berisi satu atau beberapa tugas persetujuan. Memproses satu tugas persetujuan belum tentu mengakhiri proses persetujuan.

   - Jika proses persetujuan hanya memiliki satu penyetuju, menerima atau menolak tugas persetujuan tersebut akan mengakhiri proses persetujuan.

     **Proses persetujuan** yang umum berjalan secara berurutan: **Kirim permintaan** (oleh pengaju) > **penyetuju** > **penerima CC**.
   - Jika proses persetujuan memiliki beberapa penyetuju, keseluruhan proses persetujuan bergantung pada beberapa tugas.

     - Menolak satu tugas persetujuan akan mengakhiri proses persetujuan.
     - Menerima satu tugas persetujuan akan meneruskan proses persetujuan ke penyetuju berikutnya.

       Satu node persetujuan dapat mewajibkan beberapa penyetuju dengan salah satu dari dua mode berikut: **Countersign**: semua anggota yang tercantum harus memilih **Terima** agar node lolos. **Or-sign**: persetujuan dari salah satu anggota yang tercantum sudah cukup agar node lolos.
2. Untuk menambahkan lampiran pada komentar persetujuan, unggah file ke ruang Drive persetujuan. Langkah ini menghasilkan parameter API spaceId, fileType, fileName, fileId, dan fileSize. Dapatkan parameter tersebut sebagai berikut:

   1. Panggil API [Dapatkan informasi ruang Drive persetujuan](/id/open/development/obtains-the-information-about-approval-nail-disk) untuk memperoleh izin Unggah ke ruang Drive dan mendapatkan spaceId ruang Drive persetujuan.
   2. Gunakan spaceId ruang Drive persetujuan untuk mengunggah lampiran ke Drive atau memilih file dari Drive di aplikasi web (Aplikasi mikro H5) guna memperoleh informasi file lampiran Drive.

## Permintaan

### Informasi dasar

| Bidang | Nilai |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/v1.0/workflow/processInstances/execute |
| Metode HTTP | POST |
| Tipe aplikasi yang didukung | appType-Aplikasi internal |
| Izin yang diperlukan | permission-Workflow.Instance.Write-Izin tulis instans alur kerja |

### Header permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Panggil API [Dapatkan access token Aplikasi internal](/id/open/development/obtain-the-access-token-of-an-internal-app) untuk memperolehnya. |

### Isi permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| processInstanceId | String | Ya | ID instans persetujuan:   - Panggil API [Buat instans persetujuan](/id/open/development/create-an-approval-instance) untuk memperoleh nilai parameter `InstanceId`. - Panggil API [Dapatkan daftar ID instans persetujuan](/id/open/development/obtain-an-approval-list-of-instance-ids) untuk memperoleh nilai parameter `list`. |
| remark | String | Tidak | Komentar persetujuan. Panjang maksimum: 1.024 karakter. Boleh kosong. |
| result | String | Ya | Tindakan persetujuan. Nilai yang valid:   - **agree**: Terima - **refuse**: Tolak |
| actionerUserId | String | Ya | userId operator. Panggil API [Dapatkan detail satu instans persetujuan](/id/open/development/obtains-the-details-of-a-single-approval-instance-pop) untuk memperoleh nilai parameter `userId`. |
| taskId | Long | Ya | ID tugas. Panggil API [Dapatkan detail satu instans persetujuan](/id/open/development/obtains-the-details-of-a-single-approval-instance-pop) untuk memperoleh nilai parameter `taskId`. |
| file | Object | Tidak | File. |
| photos | Array of String | Tidak | URL gambar. Panjang maksimum: 1.024 karakter. |
| attachments | Array | Tidak | Daftar lampiran. Jumlah elemen maksimum: 20. |
| spaceId | String | Tidak | ID ruang Drive.      Lihat deskripsi panggilan API dalam topik ini. |
| fileSize | String | Tidak | Ukuran file.      Lihat deskripsi panggilan API dalam topik ini. |
| fileId | String | Tidak | ID file. Panjang maksimum: 256 karakter.      Lihat deskripsi panggilan API dalam topik ini. |
| fileName | String | Tidak | Nama file. Panjang maksimum: 256 karakter.      Lihat deskripsi panggilan API dalam topik ini. |
| fileType | String | Tidak | Tipe file.      Lihat deskripsi panggilan API dalam topik ini. |
