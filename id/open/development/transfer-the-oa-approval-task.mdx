title: "Alihkan tugas Persetujuan OA"
description: "Gunakan API DingTalk untuk mengalihkan tugas Persetujuan OA ke pengguna lain, lengkap dengan catatan pengalihan, node tindakan, dan lampiran persetujuan."
---

Panggil API ini untuk mengalihkan tugas Persetujuan OA.

## Deskripsi panggilan API

<Note>
API ini hanya mendukung tugas dari persetujuan yang diajukan melalui proses persetujuan resmi atau persetujuan bawaan. API ini tidak mendukung tugas instans yang dibuat oleh persetujuan kustom.
</Note>

Untuk menambahkan lampiran persetujuan, unggah file ke ruang Drive persetujuan. Langkah ini menghasilkan parameter spaceId, fileType, fileName, fileId, dan fileSize. Ikuti langkah berikut:

1. Panggil API [Dapatkan informasi ruang Drive persetujuan](/id/open/development/obtains-the-information-about-approval-nail-disk) untuk mendapatkan izin unggah ke ruang Drive dan spaceId ruang Drive persetujuan.
2. Gunakan spaceId ruang Drive persetujuan untuk mengunggah lampiran ke Drive atau memilih file dari Drive di aplikasi web (Aplikasi mikro H5) Anda guna mendapatkan informasi file lampiran Drive.

## Permintaan

### Informasi dasar

| Bidang | Nilai |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/v1.0/workflow/tasks/redirect |
| Metode HTTP | POST |
| Tipe aplikasi yang didukung | appType-Aplikasi internal　appType-Aplikasi perusahaan pihak ketiga |
| Izin | permission-Workflow.Instance.Write-Izin tulis instans alur kerja |

### Header permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Cara mendapatkannya:   - Aplikasi internal: Panggil API [Dapatkan access token Aplikasi internal](/id/open/development/obtain-the-access-token-of-an-internal-app). - Aplikasi perusahaan pihak ketiga: Panggil API untuk mendapatkan access token Organisasi yang telah memberikan otorisasi kepada Aplikasi pihak ketiga. |

### Isi permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| taskId | Long | Ya | ID tugas Persetujuan OA. Gunakan nilai taskId yang dikembalikan oleh API [Dapatkan detail satu instans persetujuan](/id/open/development/obtains-the-details-of-a-single-approval-instance-pop). |
| toUserId | String | Ya | userId pengguna yang menjadi tujuan pengalihan tugas Persetujuan OA. |
| remark | String | Tidak | Catatan pengalihan. Panjang maksimum: 256 karakter. |
| operateUserId | String | Ya | userId operator. Nilai ini harus sama dengan penerima tugas saat ini. Jika tidak, verifikasi akan gagal. |
| actionName | String | Tidak | Nama node tindakan. Panjang maksimum: 128 karakter. |
| file | Object | Tidak | File. |
| photos | Array of String | Tidak | URL gambar. Panjang maksimum: 1.024 karakter. |
| attachments | Array | Tidak | Daftar lampiran. Jumlah elemen maksimum: 20. |
| spaceId | String | Tidak | ID ruang Drive.      Lihat bagian Deskripsi panggilan API pada dokumen ini. |
| fileSize | String | Tidak | Ukuran file.      Lihat bagian Deskripsi panggilan API pada dokumen ini. |
| fileId | String | Tidak | ID file. Panjang maksimum: 256 karakter.      Lihat bagian Deskripsi panggilan API pada dokumen ini. |
| fileName | String | Tidak | Nama file. Panjang maksimum: 256 karakter.      Lihat bagian Deskripsi panggilan API pada dokumen ini. |
| fileType | String | Tidak | Tipe file.      Lihat bagian Deskripsi panggilan API pada dokumen ini. |
