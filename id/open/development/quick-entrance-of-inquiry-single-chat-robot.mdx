Panggil API ini untuk mengueri entri cepat dari Bot obrolan tunggal, termasuk nama entri, ikon entri, tautan pengalihan PC, dan tautan pengalihan seluler. API ini cocok untuk Admin Organisasi yang perlu mengambil informasi konfigurasi entri cepat dengan cepat saat mengonfigurasi fitur Bot.

## Permintaan

### Informasi dasar

| Bidang | Nilai |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/v1.0/robot/plugins/query |
| Metode HTTP | POST |
| Jenis aplikasi yang didukung | appType-Aplikasi internal |
| Izin yang wajib | permission-Robot.SingleChat.ReadWrite-Izin manajemen Bot obrolan tunggal |

### Header permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses yang digunakan untuk memanggil API ini. Dapatkan dengan memanggil [Dapatkan access token dari aplikasi internal](/id/open/development/obtain-the-access-token-of-an-internal-app#). |

### Isi permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| robotCode | String | Ya | Kode Bot. Lihat [Glosarium Bot - robotCode](https://open.dingtalk.com/document/development/robot-overview#) untuk detail cara memperoleh `robotCode`. |

### Contoh permintaan

## Respons

### Isi respons

| Nama | Tipe | Deskripsi |
| --- | --- | --- |
| pluginInfoList | Array | Daftar entri cepat. |
| name | String | Nama entri cepat. Mendukung internasionalisasi, misalnya: `{"en_US":"test123","zh_CN":"Test123"}`. |
| icon | String | ID ikon entri cepat. |
| pcUrl | String | Tautan pengalihan untuk entri cepat di obrolan PC. |
| mobileUrl | String | Tautan pengalihan untuk entri cepat di seluler. |

### Contoh isi respons

```text

Content-Type:application/json

  "pluginInfoList" : [ {
    "name" : "{\"zh_CN\":\"Test123\"}",

    "pcUrl" : "https://www.dingtalk.io",
    "mobileUrl" : "https://www.dingtalk.io"
  } ]
}
```
