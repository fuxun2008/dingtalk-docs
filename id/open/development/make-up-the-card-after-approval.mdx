Panggil API ini untuk memberi tahu bahwa permintaan absen susulan telah disetujui.

## Permintaan

| **Informasi dasar** | |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/topapi/attendance/approve/check |
| Metode HTTP | POST |
| Tipe aplikasi yang didukung | appType-Aplikasi internal appType-Aplikasi perusahaan pihak ketiga |
| Izin | permission-qyapi_attendance_group_manage-Izin pengelolaan grup absensi |

### Parameter kueri

| Nama | Tipe | Wajib | Contoh | Deskripsi |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | bE74xxxx | Kredensial aplikasi yang digunakan untuk memanggil API ini.   - Untuk Aplikasi internal, panggil API [Mendapatkan access_token aplikasi internal](/id/open/development/obtain-orgapp-token) untuk memperolehnya. - Untuk Aplikasi perusahaan pihak ketiga, panggil API Mendapatkan access_token organisasi pihak ketiga untuk memperolehnya. |

### Isi permintaan

| Nama | Tipe | Wajib | Contoh | Deskripsi |
| --- | --- | --- | --- | --- |
| userid | String | Ya | manager4220 | ID pengguna karyawan. |
| work_date | String | Ya | 2019-08-15 | Tanggal absen susulan. Gunakan nilai work_date yang dikembalikan oleh API [Kueri informasi penjadwalan shift pengguna secara massal](/id/open/development/query-batch-scheduling-information). |
| punch_id | Number | Ya | 176877195378 | ID shift yang akan disusulkan. Gunakan nilai shift_id yang dikembalikan oleh API [Kueri informasi penjadwalan shift pengguna secara massal](/id/open/development/query-batch-scheduling-information). |
| punch_check_time | String | Ya | 2019-08-15 08:00 | Waktu absen terjadwal untuk shift tersebut. Gunakan nilai plan_check_time yang dikembalikan oleh API [Kueri informasi penjadwalan shift pengguna secara massal](/id/open/development/query-batch-scheduling-information). |
| user_check_time | String | Ya | 2019-08-15 07:59 | Waktu pengguna melakukan absen. |
| approve_id | String | Ya | aasdv13124 | ID formulir persetujuan. Nilai ini bersifat kustom. |
| jump_url | String | Ya | https://open.dingtalk.io/ | URL pengalihan formulir persetujuan. |
| tag_name | String | Ya | Absen susulan | Nama formulir persetujuan. |

Java

```bash
curl -X POST "https://api.dingtalk.io/topapi/attendance/approve/check" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=1eddxxxxca1a1' \
-d 'approve_id=aasdv13124' \
-d 'jump_url=https%3A%2F%2Fxxx.xxx' \
-d 'punch_check_time=2019-08-15+08%3A00' \
-d 'punch_id=12345' \
-d 'tag_name=Absen+susulan' \
-d 'user_check_time=2019-08-15+07%3A59' \
-d 'userid=dd_dd' \
-d 'work_date=2019-08-15'
```

Python

```python
import dingtalk.api

req=dingtalk.api.OapiAttendanceApproveCheckRequest("https://api.dingtalk.io/topapi/attendance/approve/check")

req.userid="dd_dd"
req.work_date="2019-08-15"
req.punch_id=12345
req.punch_check_time="2019-08-15 08:00"
req.user_check_time="2019-08-15 07:59"
req.approve_id="aasdv13124"
req.jump_url="https://xxx.xxx"
req.tag_name="Absen susulan"
try:
  resp= req.getResponse(access_token)
  print(resp)
except Exception,e:
  print(e)
```

PHP


## Respons

### Isi respons

| Nama | Tipe | Contoh | Deskripsi |
| --- | --- | --- | --- |
| errcode | Number | 0 | Kode pengembalian. |
| errmsg | String | ok | Deskripsi kode pengembalian. |

### Contoh isi respons

```json
{
  "errcode":0,
  "errmsg":"ok"
}
```

### Kode error

Jika panggilan mengembalikan error, cari solusinya di dokumen [Kode error global](/id/open/development/server-api-error-codes-1) berdasarkan pesan error yang diterima.
