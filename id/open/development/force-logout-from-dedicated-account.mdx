Panggil API ini untuk memaksa keluar dari Akun Perusahaan tertentu.

## Deskripsi panggilan API

Pada skenario tertentu ketika Anda perlu segera memaksa keluar sebuah Akun Perusahaan, panggil API ini untuk melakukan pengeluaran paksa.

Setelah keluar, DingTalk di sisi pengguna ditampilkan seperti di bawah ini:

## Permintaan

### Informasi dasar

| Bidang | Nilai |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/v1.0/contact/orgAccounts/signOut |
| Metode HTTP | POST |
| Jenis aplikasi yang didukung | appType-Aplikasi internal |
| Izin yang diperlukan | permission-Contact.OrgAccountSecurity.ReadWrite-Izin baca dan tulis untuk data keamanan Akun Perusahaan Kontak |

### Header permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Peroleh dengan memanggil [Dapatkan access token dari aplikasi internal](/id/open/development/obtain-the-access-token-of-an-internal-app). |

### Isi permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| userId | String | Ya | ID pengguna dari Akun Perusahaan. Peroleh melalui salah satu dari empat metode berikut:   - [Dapatkan ID pengguna berdasarkan nomor telepon](/id/open/development/obtain-the-userid-of-your-mobile-phone-number) - [Buat Akun Perusahaan SSO](/id/open/development/create-an-sso-account) - [Buat Akun Perusahaan yang dibuat oleh DingTalk](/id/open/development/create-dingtalk-user-created-dedicated-account) - [Undang Akun Perusahaan dari organisasi lain untuk bergabung](/id/open/development/invite-other-organization-specific-accounts-to-join) |
| reason | String | Tidak | Alasan pengeluaran paksa Akun Perusahaan (ditampilkan di log audit konsol admin DingTalk). |
| reasonI18nForEmployee | `Map<String, String>` | Tidak | - Alasan pengeluaran paksa Akun Perusahaan (ditampilkan kepada karyawan). - Contoh: `{"zh_CN":"Alasan keluar","en_US":"Alasan keluar"}` - Bahasa yang didukung mengacu pada bahasa saat ini dari klien DingTalk. Misalnya: `zh_CN`, `zh_HK`, `zh_TW`, `en_US`, `ja_JP`, `vi_VN`, `fr_FR`, `ru_RU`, `ko_KR`, `es_LA`, `tr_TR`, `pt_BR`, `ms_MY`, `id_ID`, `th_TH`. |

### Contoh permintaan

POST /v1.0/contact/orgAccounts/signOut HTTP/1.1
Host:api.dingtalk.io

  "reasonI18nForEmployee" : {

  }
}
