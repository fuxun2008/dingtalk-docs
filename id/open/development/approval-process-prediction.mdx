Panggil API ini untuk mendapatkan informasi node dalam proses formulir persetujuan.

## Deskripsi panggilan API

### Catatan penggunaan

Panggil API ini untuk mendapatkan informasi node berikut:

- Untuk node pilihan sendiri: nama node, jenis persetujuan, pengaturan penyetuju, cakupan pilihan, metode persetujuan untuk beberapa penyetuju, jenis aktivasi node, dan lainnya.
- Untuk node selain node pilihan sendiri: nama node, jenis persetujuan, pengaturan penyetuju, metode persetujuan untuk beberapa penyetuju, jenis aktivasi node, dan lainnya.

Node persetujuan memiliki opsi konfigurasi berikut:

**Jenis**: **Persetujuan Manual**, **Setujui Otomatis**, atau **Tolak Otomatis**.

**Pengaturan** untuk **penyetuju**: **Anggota Tertentu**, **Dipilih Sendiri oleh Pengaju**, **Manajer Multi-Tingkat Berturut-turut**, **Manajer Departemen**, **Atasan Langsung**, **Peran**, atau **Pengaju Sendiri**. Untuk opsi pilih sendiri, tetapkan **Cakupan** yang dapat dipilih (misalnya, **Anggota Tertentu**) serta mode satu orang atau banyak orang.

**Metode persetujuan untuk beberapa penyetuju**:

| Metode | Perilaku |
| --- | --- |
| Berurutan | Penyetuju bertindak satu per satu secara bergiliran |
| Tanda tangan bersama | Semua penyetuju harus menyetujui |
| Tanda tangan salah satu | Persetujuan atau penolakan dari satu penyetuju menentukan hasil |

### Kasus penggunaan

1. Tentukan apakah terdapat node pilihan sendiri. Gunakan API ini bersama API [Buat instans persetujuan](/id/open/development/create-an-approval-instance).

   **Catatan**: API ini hanya berlaku jika Anda memanggil API **Buat instans persetujuan** tanpa menentukan proses persetujuan, dan menggunakan kembali proses persetujuan yang dikonfigurasi di konsol admin persetujuan.

   Editor templat persetujuan membagi konfigurasi ke dalam empat langkah: **Pengaturan Dasar**, **Desain Formulir**, **Desain Proses**, dan **Pengaturan Lanjutan**. Kanvas Desain Proses menyusun Proses persetujuan sebagai urutan node dari atas ke bawah:

   1. Node **Pengaju**: orang yang memulai instans persetujuan.
   2. **Node pilihan sendiri** (node tempat pengaju memilih pelaksana): ditampilkan sebagai **Dipilih sendiri oleh pengaju**.
   3. Node **Penyetuju**: penyetuju yang ditetapkan.

   Node pilihan sendiri memungkinkan pengaju memilih siapa yang menangani langkah tersebut saat mengirimkan permintaan.
2. Dapatkan informasi node yang dikonfigurasi dalam templat persetujuan, seperti jenis node dan nama node.

### Periksa node pilihan sendiri

#### Dengan node pilihan sendiri

Panggil API ini. Informasi yang dikembalikan berisi node dengan nilai field `activityType` berupa `target_select`.

Saat menggunakan API ini bersama API **Buat instans persetujuan**, perhatikan hal berikut:

- Gunakan nilai field `actorKey` dari node saat ini sebagai parameter actionerKey pada API Buat instans persetujuan.
- Gunakan nilai field `workNo` dalam `actorSelectionRange` sebagai parameter `actionerUserIds` pada API Buat instans persetujuan.

  Di desainer Proses persetujuan, konfigurasikan node pilihan sendiri pada langkah **Desain Proses** (**Pengaturan Dasar** > **Desain Formulir** > **Desain Proses** > **Pengaturan Lanjutan**). Contoh alur diurutkan sebagai berikut: **Pengaju** > **Node pilihan sendiri** (jenis **Dipilih oleh pengaju**) > **Penyetuju**.

#### Tanpa node pilihan sendiri

Panggil API ini. Informasi yang dikembalikan tidak berisi node dengan nilai field `activityType` berupa `target_approval`.
