---
title: "Mengonversi groupId menjadi groupKey"
description: "Gunakan API absensi DingTalk ini untuk mengonversi groupId grup absensi menjadi groupKey, pengenal yang diperlukan oleh grup absensi versi baru."
---

Panggil API ini untuk mengonversi groupId grup absensi menjadi groupKey. groupKey adalah bidang pengenal yang digunakan pada grup absensi versi baru. Beberapa grup absensi memerlukan groupKey sebagai parameter. Jika Anda hanya memiliki bidang groupId dari grup absensi, panggil API ini untuk memperoleh groupKey.

## Permintaan

| **Informasi dasar** | |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/topapi/attendance/groups/idtokey |
| Metode HTTP | POST |
| Tipe aplikasi yang didukung | appType-Aplikasi internal　appType-Aplikasi perusahaan pihak ketiga |
| Izin yang diperlukan | permission-qyapi_attendance_group_read-Izin kueri grup absensi |

### Parameter kueri

| Nama | Tipe | Wajib | Contoh | Deskripsi |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | 6d1bxxxx | Kredensial aplikasi yang digunakan untuk memanggil API ini.   - Untuk Aplikasi internal, peroleh dengan memanggil API [Memperoleh access_token Aplikasi internal](/id/open/development/obtain-orgapp-token). - Untuk Aplikasi perusahaan pihak ketiga, peroleh dengan memanggil API Memperoleh access_token Aplikasi perusahaan pihak ketiga. |

### Isi permintaan

| Nama | Tipe | Wajib | Contoh | Deskripsi |
| --- | --- | --- | --- | --- |
| op_user_id | String | Tidak | user01 | userId operator. |
| group_id | Number | Ya | 1586536 | ID grup absensi. Panggil API [Memperoleh detail grup absensi secara massal](/id/open/development/batch-obtain-attendance-group-details) untuk memperoleh nilai group_id. |

### Contoh permintaan

```curl
curl -X POST "https://api.dingtalk.io/topapi/attendance/groups/idtokey" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=ea55fdxxxx64242a' \
-d 'group_id=12' \
-d 'op_user_id=123'
```

Java

```java
DingTalkClient client = new DefaultDingTalkClient("https://api.dingtalk.io/topapi/attendance/groups/idtokey");
OapiAttendanceGroupsIdtokeyRequest req = new OapiAttendanceGroupsIdtokeyRequest();
req.setOpUserId("user01");
req.setGroupId(1586536L);
OapiAttendanceGroupsIdtokeyResponse rsp = client.execute(req, access_token);
System.out.println(rsp.getBody());
```

## Respons

### Isi respons

| Nama | Tipe | Contoh | Deskripsi |
| --- | --- | --- | --- |
| result | String | 0151E0223B1xxxx | ID grup absensi. |
| errcode | Number | 0 | Kode pengembalian. |
| errmsg | String | ok | Deskripsi kode pengembalian. |
| request_id | String | 3yt2gu3zz0qi | ID permintaan. |

### Contoh isi respons

```json
{
  "errcode":0,
  "result":0151E0223B1xxxx,
  "errmsg":"ok",
  "request_id":"3yt2gu3zz0qi"
}
```

### Kode kesalahan

Jika panggilan API ini mengembalikan Error, cari solusinya di dokumen [Kode kesalahan global](/id/open/development/server-api-error-codes-1) berdasarkan Pesan error.
