## Alat Layanan Mandiri

Jika Anda mengalami masalah selama pengembangan, kami menyarankan Anda untuk terlebih dahulu membaca dokumentasi terkait atau menggunakan alat layanan mandiri untuk melakukan debug dan menemukan API yang perlu Anda verifikasi.

- Alat Debug Server API
- Alat Debug Pengembangan Mini Program
- Alat Debug Frontend Aplikasi Mikro

## Dukungan Teknis

**Untuk memberikan kualitas layanan yang lebih baik dan mengurangi waktu tunggu Anda, kami menyarankan Anda untuk terlebih dahulu mencoba menyelesaikan masalah dengan alat layanan mandiri. Jika masalah masih berlanjut, Anda dapat meminta bantuan melalui saluran berikut.**

1. Masuk ke [Developer Console](https://open-dev.dingtalk.com).
2. Klik **Tabler** di sudut kanan bawah.

3. Setelah mengklik Tabler, Anda dapat memasukkan pertanyaan Anda di kotak input untuk mendapatkan bantuan. Jika jawaban Tabler tidak menyelesaikan masalah Anda, klik Ticket Center di bawah untuk mengajukan tiket.

4. Ajukan tiket.

   **Catatan**
   1. Saat mengajukan tiket layanan, jika Anda mengalami masalah pemanggilan API, berikan CorpID organisasi, dokumentasi API, requestID, dan detail error lainnya.
   2. Setelah Anda mengajukan tiket layanan, sistem akan otomatis membuat obrolan grup dan menugaskan dukungan teknis (selama jam kerja). Klik Gabung obrolan di daftar tiket untuk bergabung ke obrolan grup dan berkomunikasi.
   3. Untuk menambahkan pengguna lain ke obrolan grup, lakukan sendiri. Jalur: Tindakan Cepat Obrolan Tiket > Detail Tiket > tombol Tambah Orang (hanya mendukung pengguna dalam organisasi yang sama).

   Setelah masuk ke halaman, Anda dapat melihat dan mengelola issue yang telah Anda ajukan.

## **Ikhtisar Sistem Tiket**

Sistem tiket telah meningkatkan komponen layanan pendukungnya untuk memudahkan pencatatan dan tindak lanjut issue, berupaya memberikan pengalaman layanan yang lebih baik bagi para pengembang.

- **Ticket Center: Mengumpulkan semua tiket di bawah organisasi saat ini, sehingga progres penanganan terlihat jelas sekilas.**

- **Ticket Chat: Selama jam kerja (09.00 hingga 18.00 pada hari kerja), obrolan tiket DingTalk khusus dibuat dalam waktu satu jam untuk setiap issue yang diajukan. Klik tombol "Gabung obrolan" di daftar tiket untuk berkomunikasi tanpa hambatan dengan staf layanan melalui obrolan grup. Ini mengurangi langkah komunikasi dan membuat penanganan issue lebih efisien.**

- **Service Timeline: Setiap proses penanganan issue dicatat pada lini masa, dan semua riwayat obrolan selama proses tersebut disimpan, sehingga seluruh siklus penanganan issue menjadi terlihat dan transparan.**

- **Konfirmasi dan Evaluasi: Setelah staf layanan memberikan solusi, kartu penyelesaian tiket akan dikirim ke obrolan grup. Jika Anda mengonfirmasi bahwa solusi tersebut efektif, klik **Resolved**; jika Anda belum menerima solusi tersebut untuk saat ini, klik **Unresolved**, dan staf layanan akan terus menindaklanjuti hingga issue terselesaikan.**

- **Setelah issue terselesaikan, Anda dapat memberikan penilaian terhadap layanan yang diberikan oleh staf layanan.**

## Catatan

**Agar kami dapat dengan cepat menemukan dan mengatasi masalah, kami menyarankan Anda untuk memberikan informasi pengembangan berikut saat mengirimkan masukan, termasuk namun tidak terbatas pada:**

- Jenis aplikasi atau skenario yang Anda kembangkan

  - Aplikasi internal
  - Aplikasi perusahaan pihak ketiga
  - Aplikasi personal pihak ketiga
  - Pengembangan Workbench
  - Kemampuan terbuka obrolan, dan sebagainya
- Deskripsi terperinci tentang issue dan tangkapan layar terkait
- Nama perusahaan dan CorpId
- Untuk masalah pemanggilan Server API, berikan hal berikut:

  - URL API yang diminta
  - Detail parameter
  - Hasil yang sebenarnya dikembalikan
  - Hasil yang diharapkan dikembalikan
- Untuk masalah pemanggilan API frontend, berikan hal berikut:

  - Model ponsel
  - Sistem operasi ponsel
  - Versi DingTalk yang digunakan
  - Parameter pemanggilan API
  - Hasil yang sebenarnya dikembalikan
  - Hasil yang diharapkan dikembalikan
