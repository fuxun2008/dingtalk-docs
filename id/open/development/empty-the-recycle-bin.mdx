Panggil API ini untuk mengosongkan file di Tempat Sampah berdasarkan ID Tempat Sampah. File yang telah dihapus tidak dapat dipulihkan.

## Permintaan

### Informasi dasar

| Bidang | Nilai |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/storage/recycleBins/{recycleBinId}/clear` |
| Metode HTTP | POST |
| Tipe aplikasi yang didukung | appType-Aplikasi internal　appType-Aplikasi perusahaan pihak ketiga |
| Izin yang diwajibkan | permission-Storage.RecycleBin.Write-Izin tulis untuk Tempat Sampah penyimpanan organisasi |

### Header permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Dapatkan dengan cara berikut:   - Untuk aplikasi internal, panggil API [Mendapatkan access token aplikasi internal](/id/open/development/obtain-the-access-token-of-an-internal-app#). - Untuk aplikasi perusahaan pihak ketiga, panggil API [Mendapatkan access token organisasi yang memberi otorisasi ke aplikasi pihak ketiga](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#). |

### Parameter path

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| recycleBinId | String | Ya | ID Tempat Sampah. Untuk mendapatkannya, panggil API [Mendapatkan informasi Tempat Sampah](/id/open/development/obtain-information-about-the-recycle-bin#). |

### Parameter query

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| unionId | String | Ya | unionId dari operator. Untuk mendapatkannya, panggil API [Kueri detail pengguna](/id/open/development/query-user-details#). |

### Contoh permintaan

HTTP

```http
POST /v1.0/storage/recycleBins/pQy3R7xxxxx/clear?unionId=chyxxxxx HTTP/1.1
Host:api.dingtalk.io
x-acs-dingtalk-access-token:xxxxx
Content-Type:application/json
```
