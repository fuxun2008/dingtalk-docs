Panggil API ini untuk mengkueri detail pengaturan aturan lembur secara massal berdasarkan beberapa ID aturan lembur.

## Deskripsi panggilan API

Sebagai contoh, misalkan aturan lembur di grup absensi Organisasi Anda diatur ke **Hitung lembur berdasarkan waktu persetujuan**.

Di Admin Console DingTalk, buka **Kelola grup absensi** > **Ubah grup absensi** > **Aturan lembur** > **Pengaturan**. Aturan lembur umum diatur ke **Hitung lembur berdasarkan waktu persetujuan**. Pengaturan ini berlaku untuk hari kerja, hari istirahat, dan hari libur: lembur wajib disetujui, dan durasi lembur didasarkan pada formulir persetujuan.

Panggil API ini untuk mendapatkan detail pengaturan aturan lembur **Hitung lembur berdasarkan waktu persetujuan**, termasuk nama aturan dan metode perhitungan lembur.

Di Admin Console, buka **Kelola aturan absensi** > **Aturan lembur**, lalu edit aturan lembur. Panel **Edit aturan lembur** berisi pengaturan berikut:

| Bidang | Opsi / catatan |
| --- | --- |
| **Nama aturan** | Maksimal 30 karakter |
| **Cakupan penerapan** | Misalnya, seluruh Organisasi (kecuali yang memiliki aturan lembur lain) |
| **Pemilik** | Opsional |
| Tab jenis hari | **Hari kerja**, **Hari istirahat**, **Hari libur** |
| **Izinkan lembur** | Tombol aktif/nonaktif |
| **Periode lembur yang diizinkan** | **Sebelum kerja**, **Setelah kerja** |
| **Metode perhitungan** | **Hitung berdasarkan durasi persetujuan**, atau **Hitung berdasarkan durasi absen dalam periode yang disetujui** |

Aturan dalam contoh ini menggunakan metode **Hitung berdasarkan durasi persetujuan**.

## Permintaan

### Informasi dasar

| Bidang | Nilai |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/v1.0/attendance/overtimeSettings/query |
| Metode HTTP | POST |
| Jenis aplikasi yang didukung | appType-Aplikasi internal　appType-Aplikasi perusahaan pihak ketiga |
| Izin | permission-qyapi_attendance_group_read-Izin kueri grup absensi |

### Header permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Dapatkan dengan cara berikut:   - Aplikasi internal: Panggil API [Mendapatkan access token aplikasi internal](/id/open/development/obtain-the-access-token-of-an-internal-app). - Aplikasi perusahaan pihak ketiga: Panggil API untuk mendapatkan access token Organisasi yang diotorisasi ke Aplikasi pihak ketiga. |

### Isi permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| overtimeSettingIds | Array of Long | Tidak | ID pengaturan aturan lembur. Panggil API [Kueri informasi penjadwalan shift pengguna](/id/open/development/query-scheduling-for-a-day) untuk mendapatkannya dari bidang overtimeSettingId di features. |

| settingId | Long | ID pengaturan. |
| name | String | Nama aturan. |
| default | Boolean | Apakah aturan ini merupakan aturan default.   - **true**: Ya - **false**: Tidak |

|  | Object | Detail jenis aturan lembur. |
| calcType | Integer | Apakah formulir persetujuan diperlukan untuk lembur. Nilai yang valid:   - **1**: Formulir persetujuan wajib diajukan - **2**: Formulir persetujuan tidak diperlukan - **3**: Lembur tidak diizinkan |

| settings | Map | Nilainya adalah **Waktu mulai lembur** atau **Durasi lembur minimum**. |
| overtimeRedressBy | String | Cara durasi lembur dihitung. Nilai yang valid:   - **vacation**: Dihitung sebagai cuti pengganti - **charge**: Dihitung sebagai upah lembur - **manual**: Dipilih oleh Karyawan |
| vacationRate | Float | Rasio perhitungan durasi cuti pengganti. |
| skipTime | String | Cara waktu istirahat dipotong. Nilai yang valid:   - **frame**: Potong berdasarkan periode istirahat - **duration**: Potong berdasarkan durasi lembur |

| endTime | String | Waktu selesai, dalam format `HH:mm`. |
