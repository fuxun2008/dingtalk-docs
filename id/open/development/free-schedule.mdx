Panggil API ini untuk mengkueri informasi luang/sibuk daftar pengguna tertentu dalam rentang waktu tertentu.

## Permintaan

### Informasi dasar

| Bidang | Nilai |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/calendar/users/{userId}/querySchedule` |
| Metode HTTP | POST |
| Tipe aplikasi yang didukung | appType-Aplikasi internal　appType-Aplikasi perusahaan pihak ketiga　appType-Aplikasi personal pihak ketiga |
| Persyaratan izin | permission-Calendar.EventSchedule.Read-Izin baca untuk status luang/sibuk acara di aplikasi Kalender |

### Header permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Dapatkan sebagai berikut:   - Untuk aplikasi internal, panggil API [Mendapatkan access token aplikasi internal](/id/open/development/obtain-the-access-token-of-an-internal-app#). - Untuk aplikasi perusahaan pihak ketiga, panggil API [Mendapatkan access token perusahaan yang mengotorisasi aplikasi pihak ketiga](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#). - Untuk aplikasi personal pihak ketiga, panggil API [Mendapatkan token pengguna](/id/open/development/obtain-user-token#). |

### Parameter path

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| userId | String | Ya | unionId pengguna pemilik resource permintaan ini.   - Untuk aplikasi internal dan aplikasi perusahaan pihak ketiga, panggil API [Mengkueri detail pengguna](/id/open/development/query-user-details#) untuk mendapatkan nilai parameter unionid. - Untuk aplikasi personal pihak ketiga, panggil API [Mendapatkan profil kontak pengguna](/id/open/development/dingtalk-retrieve-user-information#) untuk mendapatkan nilai parameter unionId. |

### Isi permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| userIds | Array of String | Ya | unionId pengguna target yang akan dikueri.   - Untuk aplikasi internal dan aplikasi perusahaan pihak ketiga, panggil API [Mengkueri detail pengguna](/id/open/development/query-user-details#) untuk mendapatkan nilai parameter unionid. - Untuk aplikasi personal pihak ketiga, panggil API [Mendapatkan profil kontak pengguna](/id/open/development/dingtalk-retrieve-user-information#) untuk mendapatkan nilai parameter unionId.       Panjang maksimum daftar pengguna adalah 20. |
| startTime | String | Ya | Waktu mulai kueri. |
| endTime | String | Ya | Waktu akhir kueri. |
