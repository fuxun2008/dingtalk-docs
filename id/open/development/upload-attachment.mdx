Dokumen ini menjelaskan cara mengunggah lampiran di AI Table.

Mengunggah lampiran di AI Table bekerja mirip dengan tindakan yang ditunjukkan di bawah ini.

Mengunggah lampiran melibatkan tiga langkah:

1. Dapatkan informasi unggahan. Untuk detailnya, lihat API [Dapatkan informasi unggahan sumber daya](/id/open/development/api-getresourceuploadinfo).
2. Unggah file lokal ke `uploadUrl` yang dikembalikan pada langkah 1. Gunakan permintaan `PUT` untuk mengunggah file lokal.

   Berikut adalah contoh menggunakan perintah `cURL` (simbol @ dalam contoh wajib ada).

   ```bash
   curl -X PUT -H "Content-Type: image/jpeg" --data-binary @/path/to/your/image.jpg {uploadUrl returned in step 1}
   ```
3. Panggil API [Sisipkan rekam](/id/open/development/api-notable-insertrecords) dan [Perbarui beberapa rekam](/id/open/development/api-noatable-updaterecords) untuk menulis lampiran ke dalam AI Table.

   Format nilai rekam adalah sebagai berikut.

   ```json lines
   [
     {
         "filename": "pikaqiu.jpg", // resourceName yang diteruskan pada langkah 1
         "size": 200, // size yang diteruskan pada langkah 1
         "type": "image/jpeg", // mediaType yang diteruskan pada langkah 1
         "url": "xxx"，// resourceUrl yang dikembalikan pada langkah 1. Catatan: ini bukan uploadUrl. Contohnya, /core/api/resources/img/xxx
         "resourceId": "xxx" // resourceId yang dikembalikan pada langkah 1. Contohnya, 9ee6c515-4ebd-47a0-b8c3-5383c4241d84
     }
   ]
   ```
