Panggil API ini untuk mendapatkan informasi tentang file atau folder saat menambahkannya ke ruang penyimpanan.

## Deskripsi panggilan API

Saat mendapatkan informasi file atau folder, ukuran file dan ekstensi file tidak dikembalikan untuk entri bertipe folder.

## Permintaan

### Informasi dasar

| Bidang | Nilai |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/storage/spaces/{spaceId}/dentries/{dentryId}/query` |
| Metode HTTP | POST |
| Tipe aplikasi yang didukung | appType-Aplikasi internal　appType-Aplikasi perusahaan pihak ketiga |
| Izin yang diperlukan | permission-Storage.File.Read-Izin baca pada file penyimpanan organisasi |

### Header permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Dapatkan sebagai berikut:   - Untuk aplikasi internal, panggil API [Mendapatkan access token aplikasi internal](/id/open/development/obtain-the-access-token-of-an-internal-app). - Untuk aplikasi perusahaan pihak ketiga, panggil API [Mendapatkan access token perusahaan yang diberi otorisasi ke aplikasi pihak ketiga](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1). |

### Parameter path

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| spaceId | String | Ya | ID ruang. Panggil API [Menambahkan ruang](/id/open/development/add-space) untuk mendapatkan nilai parameter `id`. |
| dentryId | String | Ya | ID file atau folder. Panggil API [Mendapatkan daftar file atau folder](/id/open/development/get-a-list-of-files-or-folders) atau API [Mendapatkan spaceId dan dentryId dari dentryUuid](/id/open/development/api-getdentryidbyuuid) untuk mendapatkan nilai parameter `id`. |

### Parameter query

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| unionId | String | Ya | unionId operator. Panggil API [Mengkueri detail pengguna](/id/open/development/query-user-details) untuk mendapatkan nilai parameter `unionid`. |

### Isi permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| option | Object | Tidak | Parameter opsional. |
| appIdsForAppProperties | Array of String | Tidak | Mengembalikan properti terlihat yang sesuai dengan menentukan daftar `ownerId` ruang. Maksimum: 20.   - Ketika `ownerType` adalah `APP`, `ownerId` adalah identifier aplikasi. - Ketika `ownerType` adalah `USER`, `ownerId` adalah unionId pembuat. |
| withThumbnail | Boolean | Tidak | Apakah akan mendapatkan tautan sementara ke thumbnail file. Dapatkan sesuai kebutuhan karena memengaruhi latensi API.   - **true**: Dapatkan. - **false** (default): Jangan dapatkan. |
