Topik ini menjelaskan tipe notifikasi pesan dan format data di DingTalk.

## Tipe notifikasi pesan DingTalk

**Pesan Notifikasi Kerja**: Pesan notifikasi yang dikirim kepada karyawan atas nama sebuah aplikasi mikro di obrolan Notifikasi Kerja suatu organisasi. Contohnya termasuk ucapan ulang tahun dan pengingat orientasi karyawan baru.

## Pesan teks (text)

```json
{
    "msgtype": "text",
    "text": {
        "content": "Notifikasi rapat bulanan"
    }
}
```

### Parameter

| Nama | Tipe | Wajib | Contoh | Deskripsi |
| --- | --- | --- | --- | --- |
| msgtype | String | Ya | text | Tipe pesan. Setel ke `text` untuk pesan teks. |
| content | String | Ya | Notifikasi rapat bulanan | Konten pesan. Disarankan maksimal 500 karakter. |

## Pesan gambar

```json
{
    "msgtype": "image",
    "image": {
        "media_id": "@lADOADmaWMzazQKA"
    }
}
```

### Parameter

| Nama | Tipe | Wajib | Contoh | Deskripsi |
| --- | --- | --- | --- | --- |
| msgtype | String | Ya | image | Tipe pesan. Setel ke `image` untuk pesan gambar. |
| media_id | String | Ya | @lADOADmaWMzazQKA | ID media. Panggil API [Unggah file media](/id/open/development/upload-media-files) untuk memperoleh nilai parameter `mediaId`. Disarankan ukuran 600 x 400 piksel dengan rasio aspek 3:2. |

## Pesan tautan

```json

    "msgtype": "link",
    "link": {
        "messageUrl": "http://s.dingtalk.io/market/dingtalk/error_code.php",
        "picUrl":"@lALOACZwe2Rk",
        "title": "Test",
        "text": "Test"
    }
}
```

### Parameter

| Nama | Tipe | Wajib | Contoh | Deskripsi |
| --- | --- | --- | --- | --- |
| msgtype | String | Ya | link | Tipe pesan. Setel ke `link` untuk pesan tautan. |
| link.messageUrl | String | Ya | http://dingtalk.io | URL yang dibuka saat pesan diklik. Saat pesan dikirim ke mini program, URL pengalihan mini program didukung. Lihat [Deskripsi tautan pesan](/id/open/development/message-link-description). |
| link.picUrl | String | Ya | @lADOADmaWMzazQKA | Panggil API [Unggah file media](/id/open/development/upload-media-files) untuk memperoleh nilai ini. |

| link.text | String | Ya | Uji konten pesan | Deskripsi pesan. Disarankan maksimal 500 karakter. |

## Pesan Markdown

```json
{
    "msgtype": "markdown",
    "markdown": {
        "title": "Konten yang ditampilkan pada layar pertama obrolan",
        "text": "# Ini adalah teks yang mendukung markdown   \n   ## Heading 2    \n   * Item daftar 1   \n  "
    }
}
```

### Sintaks Markdown

```text
Judul
# Heading 1
## Heading 2
### Heading 3
#### Heading 4
##### Heading 5
###### Heading 6
 
Kutip
> A man who stands for nothing will fall for anything.
 
Tebal, Miring
**bold**
*italic*
 
Tautan
[ini adalah tautan](http://name.com)
 
Gambar

 
Daftar Berpoin
- item1
- item2
 
Daftar Bernomor
1. item1
2. item2

Ganti baris
  \n  (Disarankan menambahkan 2 spasi sebelum dan sesudah \n)
```

### Parameter

| Nama | Tipe | Wajib | Contoh | Deskripsi |
| --- | --- | --- | --- | --- |
| msgtype | String | Ya | markdown | Tipe pesan. Panggil API [Unggah file media](/id/open/development/upload-media-files) untuk memperoleh nilai ini. Setel ke `markdown` untuk pesan Markdown. |
| title | String | Ya | Uji judul | Konten yang ditampilkan pada layar pertama obrolan. |
| text | String | Ya | Uji konten | Pesan berformat Markdown. Panjang maksimal 5.000 karakter. |

## Pesan kartu

Pesan kartu mendukung gaya ActionCard pengalihan menyeluruh dan gaya ActionCard pengalihan mandiri:

- Gaya ActionCard pengalihan menyeluruh mendukung satu tindakan klik. Parameter `single_title` dan `single_url` bersifat wajib.

  ```json lines
  {
      "msgtype": "action_card",
      "action_card": {
          "title": "Teks yang ditampilkan di daftar obrolan dan notifikasi",
          "markdown": "Konten isi dalam format Markdown",
          "single_title": "Lihat Detail",
          "single_url": "https://open.dingtalk.com"
      }
  }
  ```
- Gaya ActionCard pengalihan mandiri mendukung beberapa tindakan klik. Parameter `btn_orientation` dan `btn_json_list` bersifat wajib.

  ```json lines
  {
      "msgtype": "action_card",
      "action_card": {
          "title": "Teks yang ditampilkan di daftar obrolan dan notifikasi",
          "markdown": "Konten isi dalam format Markdown",
          "btn_orientation": "1",
          "btn_json_list": [
              {
                  "title": "Tombol satu",
                  "action_url": "https://www.taobao.com"
              },
              {
                  "title": "Tombol dua",
                  "action_url": "https://www.tmall.com"
              }
          ]
      }
  }
  ```

### Parameter

| Nama | Tipe | Wajib | Contoh | Deskripsi |
| --- | --- | --- | --- | --- |
| msgtype | String | Ya | action_card | Tipe pesan. Setel ke `action_card` untuk pesan kartu. |
| action_card.markdown | String | Ya | Konten isi dalam format Markdown | Konten pesan. Markdown didukung. Ikuti sintaks Markdown standar. Disarankan maksimal 1.000 karakter. |
| action_card.title | String | Tidak | Uji judul | Teks yang ditampilkan di daftar obrolan dan notifikasi. |
| action_card.single_title | String | Tidak | Lihat Detail | Judul yang digunakan dengan gaya ActionCard pengalihan menyeluruh. Harus disetel bersama `single_url`. Panjang maksimal 20 karakter.  **Catatan**  Untuk gaya ActionCard pengalihan menyeluruh, **single_title** dan **single_url** bersifat wajib. |
| action_card.single_url | String | Tidak | https://open.dingtalk.com | URL yang dibuka saat pesan diklik. Panggil API [Unggah file media](/id/open/development/upload-media-files) untuk memperoleh nilai ini. Saat pesan dikirim ke mini program, URL pengalihan mini program didukung. Panjang maksimal 500 karakter. |
| action_card.btn_orientation | String | Tidak | 0 | Tata letak tombol yang digunakan dengan gaya ActionCard pengalihan mandiri:   - **0**: vertikal - **1**: horizontal  Harus disetel bersama `btn_json_list`. |
| action_card.btn_json_list | JSONArray | Tidak |  | Daftar tombol yang digunakan dengan gaya ActionCard pengalihan mandiri. Harus disetel bersama `btn_orientation`. Panjang total tidak boleh melebihi 1.000 karakter.  **Catatan**  Untuk gaya ActionCard pengalihan mandiri, `btn_json_list` dan `btn_orientation` bersifat wajib. |
| action_card.btn_json_list.title | String | Tidak | Dua tombol | Judul tombol yang digunakan dengan gaya ActionCard pengalihan mandiri. Panjang maksimal 20 karakter. |
| action_card.btn_json_list.action_url | String | Tidak | https://www.tmall.com | URL pengalihan yang digunakan dengan gaya ActionCard pengalihan mandiri. Panjang maksimal 700 karakter. |
