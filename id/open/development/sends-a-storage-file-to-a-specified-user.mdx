Panggil API ini untuk mengirim file ke pengguna tertentu sebagai aplikasi.

## Permintaan

### Informasi dasar

| Bidang | Nilai |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/v1.0/convFile/apps/conversations/files/send |
| Metode HTTP | POST |
| Tipe aplikasi yang didukung | appType-Aplikasi internal　appType-Aplikasi perusahaan pihak ketiga |
| Izin yang diperlukan | permission-ConvFile.File.Send-Izin pengiriman file grup |

### Header permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Dapatkan melalui salah satu metode berikut:   - Untuk aplikasi internal, panggil API [Mendapatkan access token aplikasi internal](/id/open/development/obtain-the-access-token-of-an-internal-app#). - Untuk aplikasi perusahaan pihak ketiga, panggil API [Mendapatkan access token organisasi yang diberi otorisasi ke aplikasi pihak ketiga](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#). |

### Parameter query

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| unionId | String | Ya | unionId dari pengguna yang menerima file. Untuk mendapatkan nilai ini, panggil API [Kueri detail pengguna](/id/open/development/query-user-details#). |

### Isi permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| spaceId | String | Ya | ID ruang tempat file berada. Panggil API [Menambahkan ruang](/id/open/development/add-space#) untuk mendapatkan nilai parameter id. |
| dentryId | String | Ya | ID file. Panggil API [Mendapatkan daftar file atau folder](https://open.dingtalk.com/document/development/obtain-the-file-list-storage#) untuk mendapatkan nilai parameter id. |

## Respons

### Isi respons

| Nama | Tipe | Deskripsi |
| --- | --- | --- |
| file | Object | Informasi tentang file yang dikirim ke obrolan target. |
| id | String | ID file. |
| conversationId | String | ID obrolan tempat file berada. |
| spaceId | String | ID ruang tempat file berada. |
| parentId | String | ID folder induk tempat file berada. Untuk folder root, parameter ini bernilai 0. |
| type | String | Tipe file.   - **FILE**: File - **FOLDER**: Folder       API ini hanya dapat mengirim file. |
| name | String | Nama file. |
| size | Long | Ukuran file, dalam byte. |
| path | String | Jalur file. |
| version | Long | Versi file. |
| status | String | Status file.   - **NORMAL**: Normal - **DELETED**: Dihapus - **EXPIRED**: Kedaluwarsa |
| extension | String | Ekstensi file. |
| creatorId | String | unionId dari pembuat. |
| modifierId | String | unionId dari pengubah. |
| createTime | String | Waktu pembuatan dalam format ISO 8601. Contoh, 2022-07-29T14:55Z. |
| modifiedTime | String | Waktu modifikasi dalam format ISO 8601. Contoh, 2022-07-29T14:55Z. |
| uuid | String | uuid bisnis.      API ini tidak mengembalikan bidang ini. |
