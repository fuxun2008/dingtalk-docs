Panggil API ini untuk menambahkan Akun Perusahaan dari organisasi lain ke dalam organisasi Anda.

## Deskripsi panggilan API

Menambahkan Akun Perusahaan dari organisasi lain ke dalam organisasi Anda hanya tersedia bagi organisasi yang telah membeli dan mengaktifkan fitur ini.

Perhatikan hal berikut saat memanggil API ini untuk menambahkan Akun Perusahaan dari organisasi lain ke dalam organisasi Anda:

1. API ini tidak mendukung penambahan akun non-Akun Perusahaan dari organisasi lain.
2. Organisasi lain harus memanggil API [Otorisasi Akun Perusahaan untuk bergabung ke beberapa organisasi](/id/open/development/authorize-a-dedicated-account-to-join-multiple-organizations) untuk mengotorisasi Akun Perusahaan mereka bergabung ke organisasi Anda. Setelah otorisasi selesai, organisasi lain telah mengizinkan organisasi Anda untuk menambahkan Akun Perusahaan mereka ke dalam organisasi Anda.
3. Setelah panggilan API ini berhasil, Akun Perusahaan dari organisasi lain langsung ditambahkan ke dalam organisasi Anda. Tidak diperlukan konfirmasi tambahan dari Akun Perusahaan. (Setelah otorisasi pada langkah 2 selesai, organisasi lain dianggap telah menerima, dan tidak diperlukan penerimaan tambahan di tingkat akun.)

## Permintaan

| **Informasi dasar** | |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/topapi/v2/user/create |
| Metode HTTP | POST |
| Tipe aplikasi yang didukung | appType-Aplikasi internal |
| Izin yang wajib | permission-qyapi_manage_addresslist-Izin pengelolaan data Kontak |

### Parameter query

| Nama | Tipe | Wajib | Contoh | Deskripsi |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | BE3xxxx | Kredensial aplikasi yang digunakan untuk memanggil API ini. Peroleh melalui API untuk mendapatkan [access_token dari Aplikasi internal](/id/open/development/obtain-orgapp-token). |

### Isi permintaan

| Nama | Tipe | Wajib | Contoh | Deskripsi |
| --- | --- | --- | --- | --- |
| userid | String | Tidak | zhangsan | Pengidentifikasi unik Karyawan (tidak dapat diubah). Panjang: 1–64 karakter.  **Catatan**   - Harus unik di dalam Organisasi Anda. - Jika tidak diisi, ID pengguna akan dibuat secara otomatis. |
| outer_exclusive_corpid | String | Ya | ding12345 | ID organisasi tempat Akun Perusahaan yang akan ditambahkan berada. |
| outer_exclusive_userid | String | Ya | user01 | ID pengguna tempat Akun Perusahaan yang akan ditambahkan berada. |
| name | String | Ya | Budi Santoso | Nama Karyawan. Panjang maksimum: 80 karakter. |
| dept_id_list | String | Ya | "2,3,4" | Daftar ID Departemen tempat Karyawan berada. Pisahkan beberapa ID Departemen dengan tanda koma bahasa Inggris `,`. Maksimal 100 ID Departemen dapat dikirim per panggilan. |
| telephone | String | Tidak | 010-86123456-2345 | Nomor ekstensi. Panjang maksimum: 50 karakter.  **Catatan**  Nomor ekstensi bersifat unik dan tidak boleh berulang di dalam Organisasi Anda. |
| job_number | String | Tidak | 4 | ID Karyawan. Panjang maksimum: 50 karakter. |
| title | String | Tidak | Direktur Teknis | Jabatan. Panjang maksimum: 200 karakter. |
| email | String | Tidak | test@xxx.com | Email pribadi Karyawan. Panjang maksimum: 50 karakter.  **Catatan**  Email Karyawan bersifat unik dan tidak boleh berulang di dalam Organisasi Anda. |
| org_email | String | Tidak | test@xxx.com | Email Perusahaan Karyawan. Panjang maksimum: 100 karakter.  **Catatan**  Bidang ini hanya berlaku ketika Karyawan telah mengaktifkan Email Perusahaan. |
| org_email_type | String | Tidak | profession | Tipe Email Perusahaan Karyawan:   - **profession:** Edisi Standar. - **base:** Edisi Dasar. |
| work_place | String | Tidak | Future Park | Lokasi Kerja. Panjang maksimum: 100 karakter. |
| remark | String | Tidak | Informasi alias | Alias. Panjang maksimum: 2000 karakter. |
| dept_order_list | Object[] | Tidak |  | Urutan Karyawan di dalam setiap Departemen. |
| dept_id | Number | Tidak | 2 | ID Departemen. |
| order | Number | Tidak | 1 | Urutan Karyawan di dalam Departemen. Nilai yang lebih besar berarti posisi yang lebih tinggi dalam urutan. |
| dept_title_list | Object[] | Tidak |  | Jabatan Karyawan di dalam setiap Departemen. |
| dept_id | Number | Tidak | 2 | ID Departemen. |
| title | String | Tidak | Manajer Produk Senior | Jabatan Karyawan di dalam Departemen. |
| extension | String | Tidak | `{"hobby":"travel","age":"24"}` | Atribut ekstensi. Beberapa atribut dapat diatur. Panjang maksimum: 2000 karakter. **Catatan**   - Maksimal 10 atribut ekstensi dapat ditampilkan di perangkat seluler. - Sebelum menggunakan parameter ini, tambahkan atribut di [DingTalk Admin Console](https://oa.dingtalk.io/index_new.htm#/setting/contactInfo), lalu panggil API untuk menetapkan nilai. - Bidang ini mendukung nilai tipe Tautan. Tautan juga mendukung wildcard variabel untuk penggantian otomatis. Wildcard yang saat ini didukung adalah userid dan corpid. Sebagai contoh: `{"hobby":"[hobby](http://www.dingtalk.io?userid=#userid#&corpid=#corpid#)"}`. |
| senior_mode | Boolean | Tidak | false | Apakah mengaktifkan mode eksekutif. Default: false.   - **true**: Aktifkan.  **Catatan**    - Setelah diaktifkan, nomor telepon disembunyikan dari semua Karyawan.   - Karyawan biasa tidak dapat mengirim DING atau memulai panggilan bisnis DingTalk dengan pengguna ini.   - Para eksekutif dapat saling mengirim DING dan memulai panggilan bisnis DingTalk satu sama lain. - **false**: Nonaktifkan. |
| hired_date | Number | Tidak | 1597573616828 | Tanggal masuk kerja. Unix timestamp, dalam milidetik. |
| manager_userid | String | Tidak | 001 | ID pengguna dari atasan langsung. |

### Contoh permintaan

```curl
curl -X POST "https://api.dingtalk.io/topapi/v2/user/create" \
  -H 'Content-Type: application/x-www-form-urlencoded;charset=utf-8' \
  -d 'access_token=YOUR_ACCESS_TOKEN' \
  -d 'outer_exclusive_corpid=ding12345' \
  -d 'outer_exclusive_userid=user01' \
  -d 'name=Budi Santoso' \
  -d 'dept_id_list=2,3,4' \
  -d 'userid=zhangsan' \
  -d 'telephone=010-86123456-2345' \
  -d 'job_number=4' \
  -d 'title=Direktur Teknis' \
  -d 'email=test@xxx.com' \
  -d 'work_place=Future Park' \
  -d 'remark=Informasi alias'
```

## Respons

### Isi respons

| Nama | Tipe | Contoh | Deskripsi |
| --- | --- | --- | --- |
| errcode | Number | 0 | Kode error. 0 menandakan Berhasil. |
| errmsg | String | ok | Pesan error. |
| result | Object |  | Hasil yang dikembalikan. |
| userid | String | zhangsan | ID pengguna Karyawan. |
| unionId | String | xxxx | unionId Karyawan. |

### Contoh isi respons

```json
{
  "errcode":"0",
  "result":{
    "unionId":"xxxx",
    "userid":"zhangsan"
  },
  "errmsg":"ok"
}
```

### Kode error

Jika terjadi error saat memanggil API ini, lihat dokumen [Kode error global](/id/open/development/server-api-error-codes-1) untuk menemukan solusi berdasarkan pesan error.
