Panggil API ini untuk mencari grup absensi berdasarkan nama secara fuzzy dan mendapatkan ringkasan grup absensi, termasuk nama dan ID grup absensi.

## Permintaan

| **Informasi dasar** | |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/topapi/attendance/group/search |
| Metode HTTP | POST |
| Tipe aplikasi yang didukung | appType-Aplikasi internal　appType-Aplikasi perusahaan pihak ketiga |
| Izin yang diperlukan | permission-qyapi_attendance_group_read-Izin baca grup absensi |

### Parameter query

| Nama | Tipe | Wajib | Contoh | Deskripsi |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | bE74xxxx | Kredensial aplikasi yang digunakan untuk memanggil API ini.   - Aplikasi internal: Panggil API [Mendapatkan access_token aplikasi internal](/id/open/development/obtain-orgapp-token) untuk memperolehnya. - Aplikasi perusahaan pihak ketiga: Panggil API Mendapatkan access_token organisasi pihak ketiga untuk memperolehnya. |

### Isi permintaan

| Nama | Tipe | Wajib | Contoh | Deskripsi |
| --- | --- | --- | --- | --- |
| op_user_id | String | Ya | manager123 | userId operator. |
| group_name | String | Ya | Absensi | Nama grup absensi. |

### Contoh permintaan

```curl
curl -X POST "https://api.dingtalk.io/topapi/attendance/group/search" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=d7689axxxx70e7a' \
-d 'group_name=%Exxxx%BA%97' \
-d 'op_user_id=dd_dd'
```

Java

```java
DingTalkClient client = new DefaultDingTalkClient("https://api.dingtalk.io/topapi/attendance/group/search");
OapiAttendanceGroupSearchRequest req = new OapiAttendanceGroupSearchRequest();
req.setOpUserId("manager123");
req.setGroupName("Absensi");
OapiAttendanceGroupSearchResponse rsp = client.execute(req, access_token);
System.out.println(rsp.getBody());
```


## Respons

### Isi respons

| Nama | Tipe | Contoh | Deskripsi |
| --- | --- | --- | --- |
| result | TopMinimalismGroupVO[] |  | Hasil query. |
| name | String | Absensi | Nama grup absensi. |
| id | Number | 685935028 | ID grup absensi. |
| success | Boolean | true | Menunjukkan apakah query berhasil.   - **true**: Berhasil - **false**: Gagal |
| errcode | Number | 0 | Kode hasil. |
| request_id | String | 750mu3wy9fu | ID permintaan. |

### Contoh isi respons

```json
{
  "errcode": 0,
  "result": [
    {
      "id": 685935028,
      "name": "Absensi"
    }
  ],
  "success": true,
  "request_id": "750muu3wy9fu"
}
```

### Kode kesalahan

Jika pemanggilan API ini mengembalikan error, cari solusinya berdasarkan pesan error di dokumen [Kode kesalahan global](/id/open/development/server-api-error-codes-1).
