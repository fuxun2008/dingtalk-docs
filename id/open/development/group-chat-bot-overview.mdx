Topik ini menjelaskan apa itu Bot obrolan grup.

## Cara mengintegrasikan Bot obrolan grup

Jenis Bot berikut dapat digunakan dalam skenario obrolan grup:

- [Bot aplikasi internal](/id/open/dingstart/configure-the-robot-application)
- Bot aplikasi pihak ketiga
- Integrasi Bot templat grup
- [Integrasi Bot kustom](/id/open/dingstart/custom-bot-creation-and-installation)

Pemilik grup dan admin grup dapat mengaktifkan Bot webhook serta Bot internal dari halaman Pengaturan asisten grup, atau mengaktifkan Bot grup melalui templat grup pada halaman Plugin Lainnya.

<Note>
Beberapa Bot dapat diaktifkan secara manual dalam satu grup. Bot-bot tersebut beroperasi secara independen dan dapat berdampingan.
</Note>

Bot grup berlaku untuk skenario berikut:

- [Kolaborasi proyek](/id/open/development/project-collaboration-1)
- [Pesan grup interaktif](/id/open/development/interactive-group-message-1)
