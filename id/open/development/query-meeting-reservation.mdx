Menanyakan judul dan informasi lainnya dari rapat yang telah dipesan berdasarkan ID-nya.

## Permintaan

### Informasi dasar

| Bidang | Nilai |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/conference/scheduleConferences/{scheduleConferenceId}/infos` |
| Metode HTTP | GET |
| Tipe aplikasi yang didukung | appType-Internal app　appType-Third-party enterprise app |
| Izin yang diperlukan | permission-VideoConference.Conference.Read-Video Meeting information read permission |

### Header permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Dapatkan dengan cara berikut:   - Untuk aplikasi internal, panggil API [Mendapatkan access token aplikasi internal](/id/open/development/obtain-the-access-token-of-an-internal-app#). - Untuk aplikasi perusahaan pihak ketiga, panggil API [Mendapatkan access token organisasi yang memberi otorisasi kepada aplikasi pihak ketiga](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#). |

### Parameter path

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| scheduleConferenceId | String | Ya | ID rapat yang telah dipesan. Dapatkan dari bidang `scheduleConferenceId` yang dikembalikan oleh API [Membuat rapat terjadwal](/id/open/development/create-appointment-meeting#). |

### Parameter query

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| requestUnionId | String | Ya | unionId dari pemohon. |

| scheduleConferenceId | String | ID rapat yang telah dipesan. |
| title | String | Judul rapat yang telah dipesan. |
| startTime | Long | Waktu mulai rapat yang telah dipesan, sebagai stempel waktu UTC dalam milidetik. |
| endTime | Long | Waktu berakhir rapat yang telah dipesan, sebagai stempel waktu UTC dalam milidetik. |
| roomCode | String | Nomor rapat. |
