Panggil API ini untuk membuat atau memperbarui templat persetujuan.

## Deskripsi panggilan API

- Setiap organisasi dapat membuat hingga 200 templat di Pusat Proses. Setelah batas ini tercapai, panggilan ke API ini akan mengembalikan error.
- Klien DingTalk hanya menampilkan tiga field pertama dari formulir templat di daftar persetujuan.
- Simpan nama templat dan processCode yang dikembalikan API ini untuk setiap templat alur kerja persetujuan mandiri yang Anda buat. API lain memerlukan nilai-nilai ini.
- Templat Persetujuan OA mandiri hanya mendukung komponen persetujuan yang tercantum dalam dokumen ini. Komponen lain tidak didukung.

## Permintaan

### Informasi dasar

| Field | Nilai |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/v1.0/workflow/processCentres/schemas |
| Metode HTTP | POST |
| Jenis aplikasi yang didukung | appType-Aplikasi internal　appType-Aplikasi perusahaan pihak ketiga |
| Izin yang diperlukan | permission-Workflow.Form.Write-Izin tulis templat alur kerja |

### Header permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Cara mendapatkannya:   - Aplikasi internal: Panggil API untuk mendapatkan access token aplikasi internal. - Aplikasi perusahaan pihak ketiga: Panggil API untuk mendapatkan access token organisasi yang telah memberikan otorisasi kepada aplikasi pihak ketiga. |

### Isi permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| processCode | String | Tidak | ProcessCode formulir. Tentukan parameter ini saat memperbarui templat formulir. Untuk mendapatkan nilai processCode, panggil API [Mendapatkan kode templat](/id/open/development/obtain-the-template-code).      Jika Anda meneruskan ProcessCode untuk mengubah dan memperbarui komponen formulir, Anda tidak dapat menghapus atau mengubah kontrol yang sudah digunakan sebagai cabang kondisional dalam desain alur kerja. Misalnya, jika formulir asli menggunakan kontrol pilihan tunggal [Jenis karyawan] sebagai kondisi cabang, Anda tidak dapat mengubah tipe kontrol field [Jenis karyawan] atau menghapusnya saat memperbarui formulir ini.     - Kosongkan parameter ini untuk membuat templat baru. - Tentukan parameter ini untuk memperbarui templat persetujuan yang sesuai dengan nilai yang diteruskan. |
| name | String | Ya | Nama templat formulir. Panjang maksimum: 200 karakter. |
| description | String | Tidak | Deskripsi templat formulir. Panjang maksimum: 300 karakter. |
| formComponents | Array | Ya | Daftar kontrol formulir. Kontrol yang didukung tercantum di bawah ini. Satu formulir dapat berisi hingga 200 komponen.  Untuk detail tentang jenis kontrol yang didukung, lihat **Catatan tambahan tentang parameter FormComponent** dalam dokumen ini.   - **TextField**: Input satu baris - **TextareaField**: Input multibaris - **NumberField**: Input angka - **DDSelectField**: Pilihan tunggal - **DDMultiSelectField**: Pilih Banyak - **DDDateField**: Kontrol tanggal - **DDDateRangeField**: Kontrol rentang waktu - **TextNote**: Kontrol catatan teks - **DDPhotoField**: Kontrol gambar - **MoneyField**: Kontrol nominal - **TableField**: Kontrol rincian (kontrol tabel) - **DDAttachment**: Lampiran - **InnerContactField**: Kontrol kontak - **RelateField**: Formulir persetujuan terkait - **AddressField**: Kontrol provinsi/kota/distrik - **StarRatingField**: Kontrol penilaian - **DepartmentField**: Kontrol departemen |
| FormComponent | FormComponent | Ya | Kontrol formulir. Untuk kontrol yang didukung, lihat [Deskripsi parameter FormComponent](/id/open/development/oa-formcomponent-message). Satu formulir dapat berisi hingga 200 komponen. |
| processFeatureConfig | Object | Tidak | Konfigurasi integrasi Pusat Proses. |
| features | Array | Tidak | Daftar konfigurasi. |
| name | String | Tidak | Nama modul fitur yang dapat dikustomisasi oleh pihak ketiga. Nilai yang didukung:   - **TASK_EXECUTE**: Modul eksekusi tugas, yaitu tombol Terima dan Tolak di halaman detail - **SYNC_BOXSTER**: Cara tugas disinkronkan ke To-Do - **CUSTOM_SHORTCUT**: Tombol tindakan pintasan di item To-Do dan notifikasi kartu - **AFFILIATION_DIR**: Menentukan grup bisnis To-Do |
| pcUrl | String | Tidak | Tautan pengalihan kustom pihak ketiga untuk PC. Panjang maksimum: 1.024 karakter. |
| mobileUrl | String | Tidak | Tautan pengalihan kustom pihak ketiga untuk perangkat seluler. Panjang maksimum: 1.024 karakter. |
| runType | String | Tidak | Mode eksekusi. Jika features.name bernilai `TASK_EXECUTE`, nilai yang didukung:   - **ORIGIN**: Eksekusi native. Fitur berjalan di dalam aplikasi Persetujuan resmi dan memicu API Callback yang dikonfigurasi di callback. - **REDIRECT**: Eksekusi dengan pengalihan eksternal. Fitur berjalan di alamat pihak ketiga, dan pengguna dialihkan ke alamat yang dikonfigurasi di pcUrl atau mobileUrl.   Jika features.name bernilai `SYNC_BOXSTER`, nilai yang didukung:   - **DEFAULT**: Menyinkronkan tugas persetujuan ke To-Do secara default. - **OUTBIZ_CUSTOM**: Tidak menyinkronkan ke To-Do. Pihak bisnis menerapkan penanganan kustom.   Jika features.name bernilai `CUSTOM_SHORTCUT`, nilai yang didukung:   - **ORIGIN**: Eksekusi native. Membuka halaman detail To-Do akan mengalihkan pengguna ke halaman detail aplikasi Persetujuan resmi. - **REDIRECT**: Eksekusi dengan pengalihan eksternal. Membuka halaman detail To-Do akan mengalihkan pengguna ke alamat yang dikonfigurasi di pcUrl atau mobileUrl.   Jika features.name bernilai `AFFILIATION_DIR`, nilai yang didukung:   - **OUTBIZ_CUSTOM**: Menentukan grup To-Do. Pihak bisnis menentukan kategori item To-Do. |
| callback | Object | Tidak | Konfigurasi Callback gateway. Wajib jika runType bernilai ORIGIN.  Daftarkan semua API data eksternal yang dipanggil balik oleh gateway sebagai gateway di "Manajemen Sumber Data". Untuk detail, lihat Membuat sumber data. |
| appUuid | String | Tidak | appUuid gateway. Wajib jika runType bernilai ORIGIN.  Teruskan ID organisasi (corpId) dari organisasi yang membuat sumber data. |
| apiKey | String | Tidak | apiKey gateway. Wajib jika runType bernilai ORIGIN. Dapatkan `apiKey` dari sumber data yang telah dibuat.       - Saat gateway memanggil API eksternal, DingTalk mengembalikan parameter yang diperlukan untuk pemrosesan bisnis, tergantung skenario bisnisnya. Untuk mengurai parameter ini setelah menerima permintaan Callback, ISV harus mengonfigurasi key parameter yang sesuai saat membuat sumber data.   Misalnya, saat Callback dikonfigurasi untuk modul TASK_EXECUTE (tombol Terima dan Tolak di halaman detail), DingTalk mengembalikan parameter tetap berikut: `&#123;"outResult":"agree","processInstanceId":"xxx","activityId":"xxx","corpId":"dingxxx","data":[],"remark":"Setuju","title":"Permintaan pengambilan aset yang diajukan oleh xxx","taskId":111,"operator":"manager0001"&#125;`. - Saat membuat sumber data, ISV harus mengonfigurasi key yang diperlukan untuk penguraian sesuai kebutuhan bisnis: outResult,processInstanceId,activityId,corpId,remark,title,taskId,operator |
| version | String | Tidak | Versi API gateway.       - Wajib jika runType bernilai ORIGIN. - Default: 1. |
| config | String | Tidak | Konfigurasi modul fitur yang dikustomisasi oleh pihak ketiga. |
| templateConfig | Object | Tidak | Konfigurasi templat Pusat Proses. |
| hidden | Boolean | Tidak | Apakah templat disembunyikan:   - **true**: Templat tersembunyi - **false**: Bukan templat tersembunyi |
| createInstanceMobileUrl | String | Tidak | URL seluler untuk membuat formulir. Panjang maksimum: 1.024 karakter. |
| createInstancePcUrl | String | Tidak | URL PC untuk membuat formulir. Panjang maksimum: 1.024 karakter. |
| templateEditUrl | String | Tidak | URL pengeditan templat. Panjang maksimum: 1.024 karakter. |
| disableSendCard | Boolean | Tidak | Apakah notifikasi kartu pesan dinonaktifkan saat membuat tugas tertunda di Pusat Proses:   - **true**: Dinonaktifkan. Notifikasi kartu pesan tidak dikirim. - **false**: Default. Tidak dinonaktifkan. Notifikasi kartu pesan dikirim. |
