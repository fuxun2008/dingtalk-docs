Panggil API ini untuk menarik kembali pesan bot dalam obrolan satu lawan satu secara massal berdasarkan ID obrolan, kode bot, dan daftar ID pesan. API ini cocok untuk skenario ketika pesan yang dikirim ke organisasi Anda perlu ditarik kembali karena kesalahan.

## Permintaan

### Informasi dasar

| Bidang | Value |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/v1.0/robot/privateChatMessages/batchRecall |
| Metode HTTP | POST |
| Tipe aplikasi yang didukung | appType-Aplikasi internal　appType-Aplikasi perusahaan pihak ketiga |
| Izin yang diperlukan | permission-qyapi_robot_sendmsg-Izin bagi bot untuk mengirim pesan dalam organisasi Anda |

### Header permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Dapatkan dengan cara berikut:   - Untuk aplikasi internal, panggil API [Dapatkan access token aplikasi internal](/id/open/development/obtain-the-access-token-of-an-internal-app#). - Untuk aplikasi perusahaan pihak ketiga, panggil API [Dapatkan access token perusahaan yang telah memberikan otorisasi ke aplikasi pihak ketiga](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#). |

### Isi permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| openConversationId | String | Ya | ID obrolan. Nilainya harus sama dengan openConversationId yang digunakan pada API [Kirim pesan teks biasa dalam obrolan satu lawan satu melalui bot](/id/open/development/the-robot-sends-ordinary-messages-in-a-person-to-person-conversation#) atau API [Buat dan kirim kartu](https://open.dingtalk.com/document/development/create-and-deliver-cards#). |
| robotCode | String | Ya | Kode bot. Untuk informasi lebih lanjut, lihat [ID Bot](https://open.dingtalk.com/document/development/robot-overview#).  Nilainya harus sama dengan robotCode yang digunakan pada API [Kirim pesan teks biasa dalam obrolan satu lawan satu melalui bot](/id/open/development/the-robot-sends-ordinary-messages-in-a-person-to-person-conversation#). |
| processQueryKeys | Array of String | Ya | ID pesan.   - Untuk aplikasi internal, dapatkan nilai parameter `processQueryKey` dengan memanggil API [Buat dan kirim kartu](https://open.dingtalk.com/document/development/create-and-deliver-cards#) atau API [Kirim pesan teks biasa dalam obrolan satu lawan satu melalui bot](/id/open/development/the-robot-sends-ordinary-messages-in-a-person-to-person-conversation#). |
