title: "Membuat atau memperbarui pengaturan penyembunyian kontak"
description: "Panggil API ini untuk membuat atau memperbarui pengaturan penyembunyian kontak di DingTalk melalui permintaan PUT, dengan mengirim bidang name, description, objectStaffIds, objectDeptIds, objectTagIds, dan excludeStaffIds."
---

Gunakan API ini untuk membuat atau memperbarui pengaturan penyembunyian kontak. Kirim bidang bisnis `name`, `description`, `objectStaffIds`, `objectDeptIds`, `objectTagIds`, dan `excludeStaffIds` melalui permintaan PUT.

## Deskripsi panggilan API

Di konsol admin OA DingTalk, Anda dapat menyembunyikan departemen. API ini memperluas kemampuan penyembunyian di luar departemen — **Anda juga dapat menyembunyikan karyawan dan peran**.

<Note>
Pengaturan penyembunyian yang dikonfigurasi melalui API ini disimpan secara independen dari yang dikonfigurasi di konsol admin OA. Efek akhirnya adalah gabungan (OR) dari keduanya. Misalnya, jika departemen yang sama disembunyikan baik melalui API ini maupun melalui konsol admin OA, departemen tersebut akan disembunyikan.
</Note>
