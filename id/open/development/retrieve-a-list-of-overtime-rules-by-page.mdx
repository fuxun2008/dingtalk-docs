Panggil API ini untuk mendapatkan daftar aturan lembur yang dikonfigurasi di pengaturan absen secara berhalaman, termasuk nama dan ID setiap aturan.

## Deskripsi panggilan API

Sebagai contoh, misalkan pengelolaan aturan absensi di Organisasi Anda memiliki tiga aturan lembur: **Hitung lembur berdasarkan waktu absen setelah persetujuan**, **Hitung lembur berdasarkan waktu persetujuan**, dan **Hitung lembur berdasarkan waktu absen**.

Panggil API ini untuk mendapatkan nama aturan dan ID aturan dari ketiga aturan lembur tersebut.

Aturan lembur dikelola di **Pengelolaan Aturan Absensi** > **Aturan Lembur**. Di sana, Anda dapat menambahkan aturan melalui **Tambah Aturan Lembur**, serta melakukan **Edit** atau **Hapus** pada aturan yang sudah ada. Berikut perilaku ketiga contoh aturan tersebut:

| Nama aturan | Konten (hari kerja / hari istirahat / hari libur) | Cakupan penerapan |
| --- | --- | --- |
| Hitung lembur berdasarkan waktu persetujuan | Lembur harus disetujui; durasi lembur mengacu pada formulir persetujuan | Seluruh perusahaan (kecuali yang memiliki aturan lembur lain) |
| Hitung lembur berdasarkan waktu absen setelah persetujuan | Lembur harus disetujui; mengacu pada absen, tetapi tidak boleh melebihi durasi pada formulir persetujuan | Tidak digunakan |
| Hitung lembur berdasarkan waktu absen | Lembur tidak memerlukan persetujuan; durasi lembur dihitung dari waktu absen | Tidak digunakan |

## Permintaan

### Informasi dasar

| Bidang | Nilai |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/v1.0/attendance/overtimeSettings |
| Metode HTTP | GET |
| Tipe Aplikasi yang didukung | appType-Aplikasi internal　appType-Aplikasi perusahaan pihak ketiga |
| Izin yang diperlukan | permission-qyapi_attendance_group_read-Izin baca grup absensi |

### Header permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Cara mendapatkannya:   - Aplikasi internal: Panggil API [Mendapatkan access token Aplikasi internal](/id/open/development/obtain-the-access-token-of-an-internal-app). - Aplikasi perusahaan pihak ketiga: Panggil API untuk mendapatkan access token organisasi yang telah memberikan otorisasi kepada Aplikasi pihak ketiga. |

### Parameter kueri

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| pageNumber | Long | Ya | Nomor halaman awal.  Nilai dimulai dari 1. |
| pageSize | Long | Ya | Ukuran halaman.  Nilai maksimum adalah 50. |

## Respons

### Isi respons

| Nama | Tipe | Deskripsi |
| --- | --- | --- |
| result | Object | Hasil yang dikembalikan. |
| pageNumber | Long | Nomor halaman saat ini. |
| totalPage | Long | Jumlah total halaman. |
| items | Array | Daftar aturan lembur. |
| id | Long | ID aturan lembur. |
| name | String | Nama aturan lembur. |
| settingId | Long | settingId aturan lembur. |

### Contoh isi respons

```text
HTTP/1.1 200 OK
Content-Type:application/json

{
  "result" : {
    "pageNumber" : 1,
    "totalPage" : 10,
    "items" : [ {
      "id" : 221375127,
      "name" : "Hitung lembur berdasarkan waktu persetujuan",
      "settingId" : 221375127
    } ]
  }
}
```
