Panggil API ini untuk memperbarui beberapa rekaman dalam tabel.

## Permintaan

### Informasi dasar

| Bidang | Nilai |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/notable/bases/{baseId}/sheets/{sheetIdOrName}/records` |
| Metode HTTP | PUT |
| Jenis aplikasi yang didukung | appType-Aplikasi internal |
| Izin | permission-Notable.Base.Write.All-Izin tulis aplikasi AI Table |

### Header permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Dapatkan dengan memanggil API [Memperoleh access token aplikasi internal](/id/open/development/obtain-the-access-token-of-an-internal-app#). |

### Parameter path

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| baseId | String | Ya | ID AI Table. Untuk detail cara memperolehnya, lihat [Struktur data](/id/open/development/data-structure#). |
| sheetIdOrName | String | Ya | ID tabel atau nama tabel. Anda dapat memperoleh ID tabel dengan salah satu cara berikut:   - Panggil API [Memperoleh semua tabel](/id/open/development/api-notable-getallsheets#). - Panggil API [Memperoleh sebuah tabel](/id/open/development/api-notable-getsheet#). |

### Parameter query

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| operatorId | String | Ya | unionId operator. Anda dapat memperolehnya dengan salah satu cara berikut:   - Panggil API [Mengambil detail pengguna](/id/open/development/query-user-details#). - Panggil API [Memperoleh ID pengguna dengan kode login senyap](/id/open/development/obtain-the-userid-of-a-user-by-using-the-log-free#). |

### Isi permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| records | Array | Ya | Rekaman yang akan diperbarui. |
| id | String | Ya | ID rekaman. |
| fields | `Map<String, Any>` | Ya | Nilai-nilai bidang dalam rekaman, dalam format `Map<String, Any>`:   - key: nama field (String), sesuai dengan nama field dalam tabel. - value: nilai bidang (Any), diteruskan dalam format yang sesuai dengan tipe bidang. Untuk detail, lihat [Format nilai rekaman](https://open.dingtalk.com/document/development/record-value-format#). |
|  | Any | Tidak | Nilai bidang (Any), diteruskan dalam format yang sesuai dengan tipe bidang. Untuk detail, lihat [Format nilai rekaman](https://open.dingtalk.com/document/development/record-value-format#). |
