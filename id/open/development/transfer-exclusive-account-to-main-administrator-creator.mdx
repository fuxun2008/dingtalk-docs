Panggil API ini untuk mentransfer organisasi milik Akun Perusahaan di organisasi Anda ke Akun Perusahaan lain. Jika akun penerima tidak termasuk dalam organisasi tersebut, akun tersebut akan ditambahkan secara otomatis.

## Deskripsi panggilan API

Sebagai contoh, DingTalk Organisasi A memiliki dua Akun Perusahaan, yaitu Akun Perusahaan A1 dan Akun Perusahaan A2. Akun Perusahaan A1 adalah pembuat dari organisasi lain bernama DingTalk Organisasi B (yang dapat dilihat di konsol admin OA organisasi pengujian saat ini pada bagian Keamanan dan Izin > Daftar Super Admin). Panggil API ini untuk mengubah pembuat DingTalk Organisasi B dari Akun Perusahaan A1 menjadi Akun Perusahaan A2.

## Permintaan

### Informasi dasar

| Bidang | Nilai |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/v1.0/contact/orgAccounts/mainAdministrators/change |
| Metode HTTP | POST |
| Jenis aplikasi yang didukung | appType-Aplikasi internal |
| Izin yang diwajibkan | permission-Contact.OrgAccountSecurity.ReadWrite-Izin baca dan tulis untuk data keamanan Akun Perusahaan Kontak |

### Header permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Dapatkan dengan memanggil API [Mendapatkan access token aplikasi internal](/id/open/development/obtain-the-access-token-of-an-internal-app#). |

### Isi permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| sourceUserId | String | Ya | ID pengguna Akun Perusahaan sumber. Dapatkan dengan salah satu dari empat cara berikut:   - [Mendapatkan ID pengguna berdasarkan nomor telepon](/id/open/development/obtain-the-userid-of-your-mobile-phone-number#) - [Membuat Akun Perusahaan SSO](/id/open/development/create-an-sso-account#) - [Membuat Akun Perusahaan buatan sendiri DingTalk](/id/open/development/create-dingtalk-user-created-dedicated-account#) - [Mengundang Akun Perusahaan dari organisasi lain untuk bergabung](/id/open/development/invite-other-organization-specific-accounts-to-join#) |
| targetUserId | String | Ya | ID pengguna akun khusus tujuan. Dapatkan dengan salah satu dari empat cara berikut:   - [Mendapatkan ID pengguna berdasarkan nomor telepon](/id/open/development/obtain-the-userid-of-your-mobile-phone-number#) - [Membuat Akun Perusahaan SSO](/id/open/development/create-an-sso-account#) - [Membuat Akun Perusahaan buatan sendiri DingTalk](/id/open/development/create-dingtalk-user-created-dedicated-account#) - [Mengundang Akun Perusahaan dari organisasi lain untuk bergabung](/id/open/development/invite-other-organization-specific-accounts-to-join#) |
| effectCorpId | String | Ya | ID organisasi dari organisasi yang akan ditransfer. Untuk detailnya, lihat Konsep dasar - [CorpId](/id/open/dingstart/basic-concepts-beta#section-bbk-mv0-oxd). |
