---
title: "Menyetel kondisi tampilan filter"
description: "Panggil API ini untuk menyetel atau memperbarui kriteria filter suatu kolom dalam tampilan filter DingTalk Spreadsheet, cocok untuk mengontrol secara presisi rentang tampilan kolom pada tampilan filter pribadi."
---

Panggil API ini untuk menyetel atau memperbarui kriteria filter suatu kolom dalam tampilan filter tertentu. Ini berguna ketika Anda perlu mengontrol secara presisi rentang data yang terlihat dari satu kolom dalam tampilan filter pribadi, misalnya hanya menampilkan proyek yang Anda miliki dalam tampilan kerja pribadi, atau memfilter tugas berprioritas tinggi berdasarkan label warna tertentu.

## Deskripsi panggilan API

Kondisi tampilan filter hanya memengaruhi tampilan saat ini dan tidak mengubah data yang dilihat oleh pengguna lain.

## Permintaan

### Informasi dasar

| Bidang | Nilai |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/doc/workbooks/{workbookId}/sheets/{sheetId}/filterViews/{filterViewId}/setColumnFilterCriteria` |
| Metode HTTP | POST |
| Tipe aplikasi yang didukung | appType-Internal app |
| Izin yang diperlukan | permission-Document.Workbook.Write-DingTalk Spreadsheet write permission |

### Header permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Panggil API [Mendapatkan access token dari aplikasi internal](/id/open/development/obtain-the-access-token-of-an-internal-app) untuk memperolehnya. |

### Parameter path

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| workbookId | String | Ya | ID file spreadsheet. `nodeId(dentryUuid)` yang dikembalikan oleh [Knowledge Base API](/id/open/development/knowledge-base-overview) adalah `workbookId` dari spreadsheet. Peroleh dengan memanggil API [Get node](https://open.dingtalk.com/document/orgapp/get-node) dan [Buat dokumen Knowledge Base](/id/open/development/create-team-space-document). |
| sheetId | String | Ya | ID atau nama lembar kerja. Panggil API [Mendapatkan semua lembar kerja](/id/open/development/obtain-all-worksheets) untuk memperoleh nilai parameter id atau name. |
| filterViewId | String | Ya | ID tampilan filter. |

### Parameter query

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| operatorId | String | Ya | unionId dari operator.   - Panggil API [Mendapatkan informasi pengguna menggunakan kode login senyap](/id/open/development/obtain-the-userid-of-a-user-by-using-the-log-free) untuk memperoleh nilai parameter unionid. - Panggil API [Kueri detail pengguna](/id/open/development/query-user-details) untuk memperoleh nilai parameter unionid.       Jika operator tidak memiliki izin, API mengembalikan `The operator has no permission`. |

### Isi permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| column | Long | Ya | Offset kolom relatif terhadap kolom pertama dari rentang tampilan filter, dimulai dari 0. Misalnya, jika rentang tampilan filter adalah `B1:E10`, `column=0` merepresentasikan kolom B dan `column=1` merepresentasikan kolom C. |
| filterCriteria | Object | Ya | Objek kriteria filter. |
| filterType | String | Ya | Tipe filter. Nilai yang valid:   - **values**: filter berdasarkan nilai - **color**: filter berdasarkan warna - **condition**: filter berdasarkan kondisi |
| visibleValues | Array of String | Tidak | Nilai yang terlihat. |
| backgroundColor | String | Tidak | Warna latar belakang yang terlihat saat memfilter berdasarkan warna latar belakang, dalam format heksadesimal (seperti `#FF0000`). Ketika `filterType` bernilai `color`, salah satu dari `backgroundColor` atau `fontColor` wajib diisi. |
| fontColor | String | Tidak | Warna font yang terlihat saat memfilter berdasarkan warna font, dalam format heksadesimal (seperti `#00FF00`). Ketika `filterType` bernilai `color`, salah satu dari `backgroundColor` atau `fontColor` wajib diisi. |
| conditions | Array | Tidak | Daftar kondisi saat memfilter berdasarkan kondisi. Maksimal 2 kondisi diperbolehkan. Wajib diisi ketika `filterType` bernilai `condition`. |
| operator | String | Tidak | Operator kondisi. Nilai yang valid:   - **equal**: sama dengan - **not-equal**: tidak sama dengan - **contains**: mengandung - **not-contains**: tidak mengandung - **starts-with**: dimulai dengan - **not-starts-with**: tidak dimulai dengan - **ends-with**: diakhiri dengan - **not-ends-with**: tidak diakhiri dengan - **greater**: lebih besar dari - **greater-equal**: lebih besar dari atau sama dengan - **less**: lebih kecil dari - **less-equal**: lebih kecil dari atau sama dengan |
| value | String | Tidak | Nilai kondisi. |
| conditionOperator | String | Tidak | Hubungan logis antara beberapa kondisi. Nilai yang valid: \* **and**: DAN (default) \* **or**: ATAU. Berlaku ketika `conditions` berisi 2 kondisi. |
