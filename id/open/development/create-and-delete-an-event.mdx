## Ringkasan alur integrasi

Dokumen ini mendemonstrasikan cara membuat aplikasi internal, lalu menggunakan API yang disediakan oleh Calendar untuk membuat, mengubah, mengkueri detail satu acara, dan menghapus acara.

Prasyarat: Selesaikan alur [Membuat dan mengonfigurasi aplikasi](/id/open/dingstart/create-application).

Langkah 1: Dapatkan informasi kredensial aplikasi, termasuk client ID dan Client Secret.

Langkah 2: Ajukan izin API untuk API terkait Calendar.

Langkah 3: Dapatkan kredensial akses aplikasi [Mendapatkan access token dari aplikasi internal](/id/open/development/obtain-the-access-token-of-an-internal-app). Saat memanggil API, gunakan access token untuk mengautentikasi pemanggil.

Langkah 4: Panggil Server API untuk Calendar:

1. Panggil Server API [Acara Baru](/id/open/development/create-schedule) untuk membuat acara. Dapatkan `id` acara.
2. Berdasarkan `id` acara, panggil Server API [Mengubah acara](/id/open/development/modify-event) untuk mengubah informasi acara.
3. Berdasarkan `id` acara, panggil Server API [Mengkueri detail sebuah acara](/id/open/development/query-details-about-an-event) untuk mendapatkan detail acara.
4. Berdasarkan `id` acara, panggil Server API [Hapus Acara](/id/open/development/delete-event) untuk menghapus acara yang telah dibuat.

## Prasyarat

Selesaikan alur [Membuat dan mengonfigurasi aplikasi](/id/open/dingstart/create-application).

## Langkah 1: Dapatkan kredensial aplikasi

1. Pilih aplikasi target untuk masuk ke halaman detail aplikasi, lalu klik **Basic information** > **Credentials and basic information**.
2. Dapatkan client ID dan Client Secret.

## Langkah 2: Tambahkan izin API

Klik **Development configuration** > **Manage permissions**. Pada kotak pencarian izin, masukkan `Calendar.Event.Write` dan `Calendar.Event.Read` secara berurutan, lalu ajukan izinnya.

## Langkah 3: Dapatkan access token aplikasi

<Warning>
Untuk detail tentang perbedaan antar Server API, lihat Legacy API vs. New API. API berikut semuanya menggunakan Server API. Untuk detail unduhan SDK, lihat Server-side SDK download.
</Warning>

Gunakan client ID dan Client Secret dari Langkah 1 untuk mendapatkan access_token dari aplikasi internal.

```java
 public void getAccessToken() throws Exception {
        Config config = new Config();
        config.protocol = "https";
        config.regionId = "central";

        GetAccessTokenRequest accessTokenRequest = new GetAccessTokenRequest()
                .setAppKey("ding*********hgn")
                .setAppSecret("9G_O**********xamBkhgGIO");
        GetAccessTokenResponse accessToken = client.getAccessToken(accessTokenRequest);
        System.out.println(JSON.toJSONString(accessToken.getBody()));
    }
```

<Note>
Dua skenario penghapusan berikut didukung:
</Note>

- Ketika penyelenggara menghapus acara (parameter userId di path menggunakan unionId penyelenggara), semua peserta menerima notifikasi pembatalan acara, dan acara dihapus dari kalender semua peserta.
- Ketika seorang peserta menghapus acara (parameter userId di path menggunakan unionId peserta), acara hanya dihapus dari kalender peserta itu sendiri, dan peserta acara lainnya tidak terpengaruh.
