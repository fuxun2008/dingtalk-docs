Panggil API ini untuk memperbarui status pesan notifikasi kerja OA.

## Deskripsi panggilan API

- API ini dirancang untuk notifikasi kerja OA dan memperbarui status persetujuan secara real-time.
- API ini hanya dapat memperbarui status bar notifikasi kerja yang dikirim dalam 7 hari terakhir.

## Permintaan

| **Informasi dasar** | |
| --- | --- |
| URL HTTP | https://oapi.dingtalk.io/topapi/message/corpconversation/status_bar/update |
| Metode HTTP | POST |
| Tipe aplikasi yang didukung | appType-Aplikasi internalappType-Aplikasi perusahaan pihak ketiga |
| Izin yang diperlukan | permission-qyapi_base-Izin dasar yang diperlukan untuk memanggil API perusahaan |

### Parameter kueri

| Nama | Tipe | Wajib | Contoh | Deskripsi |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | bE74xxxx | Kredensial aplikasi yang digunakan untuk memanggil API ini.   - Untuk aplikasi internal, dapatkan dengan memanggil API untuk mendapatkan [access_token aplikasi internal](/id/open/development/obtain-orgapp-token). - Untuk aplikasi perusahaan pihak ketiga, dapatkan dengan memanggil API untuk mendapatkan access_token perusahaan pihak ketiga. |

### Isi permintaan

| Nama | Tipe | Wajib | Contoh | Deskripsi |
| --- | --- | --- | --- | --- |
| agent_id | Number | Ya | 123 | AgentId dari aplikasi mikro yang digunakan untuk mengirim pesan.   - Untuk aplikasi internal, lihat pada halaman detail aplikasi di [Developer Backend](https://open-dev.dingtalk.io/#/appMgr/inner/h5/836390886/1). - Untuk aplikasi perusahaan pihak ketiga, dapatkan dengan memanggil API untuk mendapatkan informasi otorisasi perusahaan. |
| task_id | Number | Ya | 11 | ID tugas notifikasi kerja. Dapatkan nilai task_id dengan memanggil API [Kirim notifikasi kerja](/id/open/development/asynchronous-sending-of-enterprise-session-messages). |
| status_value | String | Ya | Accepted | Nilai status bar. |
| status_bg | String | Tidak | 0xFF78C06E | Warna latar belakang status bar. Kami menyarankan format 0xFF diikuti dengan nilai warna enam digit. |

### Contoh permintaan

```curl
curl -X POST "https://oapi.dingtalk.io/topapi/message/corpconversation/status_bar/update" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=e4bbxxxxe7683' \
-d 'agent_id=123' \
-d 'status_bg=0xFFF65E5E' \
-d 'status_value=Completed' \
-d 'task_id=1111'
```

Java

```text
DingTalkClient client = new DefaultDingTalkClient("https://oapi.dingtalk.io/topapi/message/corpconversation/status_bar/update");
OapiMessageCorpconversationStatusBarUpdateRequest req = new OapiMessageCorpconversationStatusBarUpdateRequest();
req.setAgentId(123L);
req.setTaskId(1111L);
req.setStatusValue("Completed");
req.setStatusBg("0xFFF65E5E");
OapiMessageCorpconversationStatusBarUpdateResponse rsp = client.execute(req, access_token);
System.out.println(rsp.getBody());
```

| errcode | Number | 0 | Kode pengembalian. |

### Kode error

Jika terjadi error saat Anda memanggil API ini, cari pesan error pada dokumen [Kode error global](/id/open/development/server-api-error-codes-1) untuk menemukan solusinya.

| Kode error (errorcode) | Pesan error (errmsg) | Solusi |
| --- | --- | --- |
| 40056 | Invalid agentid | Pastikan agentId sudah benar. |
| 40035 | Invalid parameter | Pastikan taskId sudah benar. |
| 41052 | Too many recipients in this delivery; sending results will no longer be returned. | - Kurangi jumlah penerima notifikasi kerja. - Periksa apakah notifikasi kerja telah selesai dikirim. Error ini terjadi jika pengiriman masih berlangsung. |
| 500 | System error | Terjadi error sistem yang tidak diketahui. |
