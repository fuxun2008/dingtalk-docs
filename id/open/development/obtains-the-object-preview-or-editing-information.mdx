---
title: "Mendapatkan informasi pratinjau atau edit file"
description: "Panggil API ini untuk mendapatkan tautan pratinjau atau edit file di ruang penyimpanan DingTalk, sehingga pengguna yang berwenang dapat melihat atau mengedit file melalui tautan tersebut."
---

Panggil API ini untuk mendapatkan tautan pratinjau atau edit file di suatu ruang penyimpanan. Pengguna dengan izin yang diperlukan dapat melihat atau mengedit file melalui tautan tersebut.

## Permintaan

### Informasi dasar

| Bidang | Nilai |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/storage/spaces/{spaceId}/dentries/{dentryId}/openInfos/query` |
| Metode HTTP | POST |
| Tipe aplikasi yang didukung | appType-Internal app　appType-Third-party enterprise app |
| Izin yang diperlukan | permission-Storage.File.Read-Organization storage file read permission |

### Header permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Dapatkan dengan cara berikut:   - Untuk aplikasi internal, panggil API [Mendapatkan access token aplikasi internal](/id/open/development/obtain-the-access-token-of-an-internal-app). - Untuk aplikasi perusahaan pihak ketiga, panggil API [Mendapatkan access token organisasi yang diberi otorisasi ke aplikasi pihak ketiga](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1). |

### Parameter path

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| spaceId | String | Ya | ID ruang. Panggil API [Menambahkan ruang](/id/open/development/add-space) untuk mendapatkan nilai parameter id. |
| dentryId | String | Ya | ID file. Panggil API [Mendapatkan daftar file atau folder](/id/open/development/get-a-list-of-files-or-folders) atau [Mendapatkan spaceId dan dentryId berdasarkan dentryUuid](/id/open/development/api-getdentryidbyuuid) untuk mendapatkan nilai parameter id. |

### Parameter query

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| unionId | String | Ya | unionId dari operator. Panggil API [Mengkueri detail pengguna](/id/open/development/query-user-details) untuk mendapatkan nilai parameter unionid. |

### Isi permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| option | Object | Tidak | Parameter opsional. |
| version | Long | Tidak | Nomor versi dari file yang ditentukan. Panggil API [Mendapatkan daftar file atau folder](/id/open/development/get-a-list-of-files-or-folders) untuk mendapatkan nilai parameter id. |
| type | String | Tidak | Mode buka file:   - **PREVIEW**: Pratinjau. Nilai default. - **EDIT**: Edit. |
| waterMark | Boolean | Tidak | Apakah tanda air diperlukan:   - **true**: Diperlukan. - **false**: Tidak diperlukan. Nilai default.   Saat ini, hanya file berformat WPS (Word, Excel, PPT, PDF) yang mendukung tanda air. |
| checkLogin | Boolean | Tidak | Apakah akan memeriksa status masuk DingTalk. Parameter ini hanya berlaku ketika nilai type adalah PREVIEW.   - **true**: Periksa. Status masuk DingTalk diverifikasi saat memasuki halaman. Jika pengguna belum masuk, halaman akan mengalihkan ke halaman masuk, lalu melanjutkan ke halaman saat ini setelah berhasil masuk. - **false** (default): Jangan periksa. Status masuk DingTalk tidak diverifikasi saat memasuki halaman, tetapi batasan berikut berlaku:    - Mendukung format dokumen dasar (Word, Excel, PPT, PDF), beberapa format gambar (jpg, jpeg, jpe, png, gif, bmp, pcx, jiff, tiff, tif, ico, fax, wbmp, webp), dan semua jenis file audio serta video. Aksi Teruskan, Edit online, Unduh, dan aksi lainnya di sudut kanan atas jendela pratinjau tidak didukung.   - Setelah didapatkan, tautan hanya dapat diakses satu kali (per sesi browser).   - Setelah didapatkan, tautan otomatis kedaluwarsa setelah 5 menit tidak aktif. |
