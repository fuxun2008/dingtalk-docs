---

Panggil API ini untuk memperbarui informasi pengguna internal dari Akun Perusahaan tertentu. Hanya tersedia untuk organisasi yang telah membeli dan mengaktifkan Akun Perusahaan.

## Permintaan

| **Informasi dasar** | |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/topapi/v2/user/update |
| Metode HTTP | POST |
| Tipe aplikasi yang didukung | appType-Aplikasi internal |
| Izin yang diperlukan | permission-qyapi_manage_addresslist-Izin pengelolaan data Kontak |

### Parameter query

| Nama | Tipe | Wajib | Contoh | Deskripsi |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | be3Fxxxx | Kredensial aplikasi yang digunakan untuk memanggil API ini. Dapatkan melalui API untuk memperoleh [access_token dari Aplikasi internal](/id/open/development/obtain-orgapp-token). |

### Isi permintaan

| Nama | Tipe | Wajib | Contoh | Deskripsi |
| --- | --- | --- | --- | --- |
| userid | String | Ya | user123 | ID pengguna dari karyawan. |
| name | String | Tidak | Zhang San | Nama karyawan. Maksimal 80 karakter. |
| hide_mobile | Boolean | Tidak | false | Apakah menyembunyikan nomor telepon:   - **true**: Sembunyikan. Setelah nomor telepon disembunyikan, nomor tersebut tidak ditampilkan di halaman Profil, tetapi Anda tetap dapat mengirim DING dan memulai panggilan bisnis DingTalk kepada karyawan ini. - **false**: Jangan sembunyikan. |
| telephone | String | Tidak | 010-86123456-2345 | Nomor ekstensi. Maksimal 50 karakter.  **Catatan**  Nomor ekstensi bersifat unik dan tidak boleh sama dalam Organisasi Anda. |
| job_number | String | Tidak | 4 | ID Karyawan. Maksimal 50 karakter. |
| manager_userid | String | Tidak | 0001 | ID pengguna dari atasan langsung. |
| title | String | Tidak | Technical Director | Jabatan. Maksimal 200 karakter. |
| email | String | Tidak | test@xxx.com | Email karyawan. Maksimal 50 karakter.  **Catatan**  Email karyawan bersifat unik dan tidak boleh sama dalam Organisasi Anda. |
| org_email | String | Tidak | test@xxx.com | Email Perusahaan dari karyawan.  **Catatan**  Bidang ini hanya berlaku jika kondisi berikut terpenuhi: Email Perusahaan karyawan telah diaktifkan. |
| work_place | String | Tidak | Future Park | Lokasi Kerja. Maksimal 100 karakter. |
| remark | String | Tidak | Alias information | Alias. Maksimal 2000 karakter. |
| dept_id_list | String | Ya | "2,3,4" | Daftar ID departemen tempat karyawan bernaung. |
| dept_order_list | DeptOrder[] | Tidak |  | Urutan sortir karyawan dalam departemen terkait. |
| dept_id | Number | Tidak | 2 | ID departemen. |
| order | Number | Tidak | 1 | Urutan sortir karyawan dalam departemen. |
| dept_title_list | DeptTitle[] | Tidak |  | Jabatan karyawan dalam departemen terkait. |
| dept_id | Number | Tidak | 2 | ID departemen. |
| title | String | Tidak | Senior Product Manager | Jabatan karyawan dalam departemen. |
| extension | String | Tidak | `{"hobby":"travel","age":"24"}` | Atribut lanjutan. Maksimal 2000 karakter. **Catatan**   - Maksimal 10 atribut lanjutan dapat ditampilkan di perangkat seluler. - Jika 10 bidang atribut lanjutan disetel untuk seorang karyawan, semua 10 bidang harus dikirim saat pembaruan, meskipun nilainya tidak berubah. Jika hanya 1 yang dikirim, 9 lainnya akan dikosongkan. - Sebelum menggunakan parameter ini, tambahkan atribut di [**DingTalk Admin Console**](https://oa.dingtalk.io/index.htm#/setting#setOrgInfo) > **Pengaturan** > **Informasi Kontak**. - Nilai bidang ini mendukung input tipe tautan, dan tautan mendukung penggantian otomatis wildcard variabel. Wildcard yang saat ini didukung adalah userid dan corpid. Contoh: `[Alamat nomor meja](http://www.dingtalk.io?userid=#userid#&corpid=#corpid#)`. |
| ext_attrs_update_mode | Number | Tidak | 1 | Mode pembaruan untuk bidang Kustom dari atribut lanjutan:   - 0: Mode timpa - 1: Mode tambah   Default adalah Timpa. |
| senior_mode | Boolean | Tidak | false | Apakah mengaktifkan Mode Eksekutif. Default adalah false.   - **true**: Aktifkan.  **Catatan**      - Saat diaktifkan, nomor telepon disembunyikan dari semua karyawan.   - Karyawan biasa tidak dapat mengirim DING atau memulai panggilan bisnis DingTalk kepada pengguna ini.   - Para eksekutif dapat saling mengirim DING dan memulai panggilan bisnis DingTalk. - **false**: Jangan aktifkan. |
| hired_date | Number | Tidak | 1597573616828 | Tanggal perekrutan, dalam bentuk UNIX timestamp dalam milidetik. |
| language | String | Tidak | zh_CN | Bahasa Kontak. Nilai:   - **zh_CN**: Bahasa Mandarin (Default). - **en_US**: Bahasa Inggris. |
| force_update_fields | String | Tidak | manager_userid | Bidang yang dipaksa untuk diperbarui. Mendukung pengosongan bidang tertentu. Pisahkan beberapa bidang dengan koma. Bidang yang saat ini didukung: `manager_userid`, `org_email`.  **Catatan**   - Jika org_email disertakan dalam bidang yang dipaksa diperbarui dan parameter org_email kosong, ikatan antara karyawan dan Email Perusahaan akan dihapus, dan akun Email Perusahaan akan dibekukan atau dihapus. - Jika org_email disertakan dalam bidang yang dipaksa diperbarui dan karyawan sudah terikat dengan Email Perusahaan lain, ikatan dengan Email Perusahaan asli akan dihapus, akun Email Perusahaan asli akan dibekukan atau dihapus, dan karyawan akan diikat ke Email Perusahaan yang baru. - Jika org_email disertakan dalam bidang yang dipaksa diperbarui dan akun mailbox terkait adalah mailbox publik atau layanan, tipe mailbox akan dikonversi menjadi mailbox biasa, dan karyawan akan diikat ke Email Perusahaan. |
| org_email_type | String | Tidak | profession | Tipe Email Perusahaan untuk karyawan Akun Perusahaan.   - profession: Edisi Standar - base: Edisi Dasar |
| loginId | String | Tidak | loginId123 | Nama masuk untuk Akun Perusahaan DingTalk. Hanya Akun Perusahaan DingTalk yang dapat memperbarui bidang ini. Akun Perusahaan Single Sign-On tidak didukung.  **Catatan**  Jangan sertakan informasi kontak seperti nomor telepon, alamat email, atau tautan agar pesan SMS tidak diblokir oleh operator. |
| init_password | String | Tidak | init_password220 | Kata sandi awal untuk Akun Perusahaan DingTalk. Minimal 8 karakter.  **Catatan**   - Tidak boleh terdiri seluruhnya dari huruf atau angka. - Hanya Akun Perusahaan DingTalk yang dapat memperbarui bidang ini. Akun Perusahaan Single Sign-On tidak didukung. - Jangan sertakan informasi kontak seperti nomor telepon, alamat email, atau tautan agar pesan SMS tidak diblokir oleh operator. |
| send_password_to_user | Boolean | Tidak | false | Apakah mengirim kredensial akun. Default adalah false.   - **false**: Jangan kirim - **true**: Kirim   **Catatan**   - Ketika parameter ini bernilai **true**, parameter `init_password` bersifat Wajib; jika tidak, kredensial tidak akan dikirim. - Saat pengiriman, pesan SMS akan dikirim ke nomor telepon karyawan atau email akan dikirim ke mailbox pribadi karyawan. - Hanya Akun Perusahaan DingTalk yang mendukung pengaturan bidang ini. Akun Perusahaan Single Sign-On tidak didukung. |
| exclusive_mobile | String | Tidak | 150xxxxxxx | Nomor telepon dari Akun Perusahaan. |
| avatarMediaId | String | Tidak | @lALPDfmVUw19YdrNA-jNA-g | Saat memperbarui Akun Perusahaan untuk organisasi saat ini, Anda dapat menentukan MediaId Foto Profil. Hanya format jpg dan png yang didukung. Dapatkan melalui API Unggah media File.  **Catatan**  Mendukung Akun Perusahaan Kustom dan Akun Perusahaan Single Sign-On. |
| nickname | String | Tidak | Name | Nama dari Akun Perusahaan.  **Catatan**  Mendukung Akun Perusahaan Kustom dan Akun Perusahaan Single Sign-On. |
| dept_position_list | DeptPosition[] | Tidak |  | Informasi posisi dalam departemen. |
| extension_i18n | Json | Tidak | `{"hobby":{"zh_CN":"travel","en_US":"travel","aJP":"travel"}}` | Nilai terinternasionalisasi dari atribut lanjutan. |

```curl
-d 'access_token=9321cd22-5087-4456-969a-190ad398e925' \
-d 'userid=zhangsan' \
```


## Respons

### Isi respons

| Nama | Tipe | Contoh | Deskripsi |
| --- | --- | --- | --- |
| errcode | Number | 0 | Kode pengembalian. 0 menunjukkan Berhasil. |
| errmsg | String | User not found | Pesan error yang dikembalikan saat panggilan gagal. |

### Contoh isi respons

```json
{
  "errcode":0,
  "errmsg":"ok",
  "request_id":"55o5i31j4cg8"
}
```

### Kode error

Jika terjadi error saat memanggil API ini, lihat dokumen [Kode error global](/id/open/development/server-api-error-codes-1) untuk solusinya.
