# Mengirim sinyal API kontrol pusat Rooms

## Permintaan

### Informasi dasar

| Bidang | Nilai |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/v1.0/rooms/central/control |
| Metode HTTP | POST |
| Tipe aplikasi yang didukung | appType-Aplikasi internal |
| Izin yang diperlukan | permission-VideoConference.Conference.Write-Izin pengelolaan informasi Rapat Video |

### Header permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Untuk memperolehnya, panggil API [Mendapatkan access token aplikasi internal](/id/open/development/obtain-the-access-token-of-an-internal-app). |

### Isi permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| unionId | String | Tidak | unionId operator. Untuk memperolehnya, panggil API [Kueri detail pengguna](/id/open/development/query-user-details). |
| roomId | String | Tidak | ID ruang rapat. Untuk memperolehnya, panggil API [Kueri daftar ruang rapat](/id/open/development/check-the-meeting-room-list). |
| controlBody | String | Tidak | Sinyal kontrol pusat. Hubungi account manager Anda untuk memperoleh parameter ini. |
