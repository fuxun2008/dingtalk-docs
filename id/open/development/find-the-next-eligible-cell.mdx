---
title: "Menemukan sel di lembar kerja"
description: "Panggil API ini untuk menemukan sel berikutnya di lembar kerja DingTalk Spreadsheet yang cocok dengan string dan kondisi tertentu, mulai setelah sel kiri atas rangeAddress serta opsional beririsan dengan findOptions.scope."
---

Temukan sel berikutnya yang cocok dengan string tertentu berdasarkan kondisi yang ditentukan. Cakupan pencarian mencakup seluruh lembar kerja mulai setelah sel kiri atas dari rentang yang ditentukan (yaitu, rangeAddress). Jika parameter `findOptions.scope` ditentukan, cakupan pencarian selanjutnya diirisikan dengan parameter tersebut.

## Permintaan

### Informasi dasar

| Bidang | Nilai |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/doc/workbooks/{workbookId}/sheets/{sheetId}/ranges/{rangeAddress}/findNext` |
| Metode HTTP | POST |
| Tipe aplikasi yang didukung | appType-Internal app |
| Izin yang diperlukan | permission-Document.Workbook.Read-DingTalk Spreadsheet read permission |

### Header permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses yang digunakan untuk memanggil API ini. Panggil API [Mendapatkan access token aplikasi internal](/id/open/development/obtain-the-access-token-of-an-internal-app) untuk memperolehnya. |

### Parameter path

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| workbookId | String | Ya | ID file spreadsheet. Teruskan `nodeId` (dentryUuid) sebagai `workbookId` spreadsheet. Panggil API [Mendapatkan node](/id/open/development/get-knowledge-base-acquisition-node) atau [Membuat dokumen Knowledge Base](/id/open/development/create-team-space-document) untuk memperolehnya. |
| sheetId | String | Ya | ID atau judul lembar kerja. Panggil API [Mendapatkan semua lembar kerja](/id/open/development/obtain-all-worksheets) untuk memperoleh ID, atau teruskan judul lembar kerja. |
| rangeAddress | String | Ya | Posisi awal pencarian. Pencarian dimulai setelah sel kiri atas dari rentang ini (sel kiri atas itu sendiri tidak termasuk). |

### Parameter query

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| operatorId | String | Ya | unionId operator. |

### Isi permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| text | String | Ya | Teks yang akan dicari. |
| findOptions | Object | Tidak | Opsi pencarian. |
| matchEntireCell | Boolean | Tidak | Apakah mencocokkan seluruh sel:   - **true**: Ya - **false**: Tidak |
| matchCase | Boolean | Tidak | Apakah mencocokkan huruf besar/kecil:   - **true**: Ya - **false**: Tidak |
| useRegExp | Boolean | Tidak | Apakah parameter text merupakan ekspresi reguler:   - **true**: Ya - **false**: Tidak |
| matchFormulaText | Boolean | Tidak | Apakah mencari di dalam formula:   - **true**: Ya - **false**: Tidak |
| scope | String | Tidak | Cakupan pencarian. Tentukan alamat Range dalam notasi A1. |
| includeHidden | Boolean | Tidak | Apakah menyertakan sel tersembunyi, yaitu sel yang tidak terlihat karena baris atau kolom tersembunyi, filter, grup, dan fitur serupa. Sel yang tidak memiliki izin untuk dilihat pengguna tidak disertakan.   - **true**: Ya - **false**: Tidak |
