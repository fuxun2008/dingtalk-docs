## Deskripsi panggilan API

Langkah-langkah panggilan API adalah sebagai berikut:

Langkah 1: Panggil API [Memperoleh informasi unggahan file](/id/open/development/obtain-file-upload-informations) untuk memperoleh informasi yang diperlukan untuk mengunggah file.

Langkah 2: Unggah file menggunakan metode OSS header sign request. Lihat contoh berikut:

public static string HttpRequest(string url, string filePath, Dictionary<string, string> headers) {

    FileStream fileStream = new FileStream(filePath, FileMode.Open, FileAccess.Read, FileShare.Read);
    BinaryReader reader = new BinaryReader(fileStream);
    reader.BaseStream.Seek(0, SeekOrigin.Begin);
    byte[] datas = reader.ReadBytes((int)reader.BaseStream.Length);
    HttpWebRequest request = (HttpWebRequest)WebRequest.Create(url);
    request.Method = "PUT";
    request.Timeout = 150000;
    foreach (var header in headers) {
        request.Headers.Add($"{header.Key}", $"{header.Value}");
    }
    Stream requestStream = null;
    string responseStr = null;
    try {
        if (datas != null) {
            request.ContentLength = datas.Length;
            requestStream = request.GetRequestStream();
            requestStream.Write(datas, 0, datas.Length);
            requestStream.Close();
        } else {
            request.ContentLength = 0;
        }
        HttpWebResponse response = request.GetResponse() as HttpWebResponse;
        responseStr = response.Headers.GetValues("x-oss-request-id")[0];
    } catch (Exception ex) {
        Console.WriteLine("error");
    } finally {
        request = null;
        requestStream = null;
    }
    return responseStr;
}

Langkah 3: Panggil API ini untuk menerapkan (commit) file dan menyelesaikan unggahan.

### Catatan

- Ketika tipe ruang penyimpanan adalah USER, semua pengguna dengan izin pada ruang tersebut memiliki hak operasi. Karyawan lain harus memanggil API [Menambahkan izin](/id/open/development/add-permissions-file) untuk memberikan otorisasi.
- Ketika tipe ruang penyimpanan adalah APP, setiap operator harus memanggil API [Menambahkan izin](/id/open/development/add-permissions-file) untuk memberikan otorisasi.

## Permintaan

### Informasi dasar

| Bidang | Nilai |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v2.0/storage/spaces/files/{parentDentryUuid}/commit` |
| Metode HTTP | POST |
| Tipe aplikasi yang didukung | appType-Aplikasi internal　appType-Aplikasi perusahaan pihak ketiga |
| Persyaratan izin | permission-Storage.File.Write-Izin tulis file penyimpanan organisasi |

### Header permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Peroleh sebagai berikut:   - Untuk aplikasi internal, panggil API [Memperoleh access token aplikasi internal](/id/open/development/obtain-the-access-token-of-an-internal-app#). - Untuk aplikasi perusahaan pihak ketiga, panggil API [Memperoleh access token perusahaan yang diotorisasi dari aplikasi pihak ketiga](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#). |

### Parameter jalur

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| parentDentryUuid | String | Ya | dentryUuid dari node induk. Panggil API [Pencarian File](/id/open/development/search-for-files#) atau [Memperoleh informasi dentryUuid](/id/open/development/api-getuuidbydentryid#) untuk memperoleh bidang `dentryUuid` dari respons.    Untuk direktori root ruang, teruskan dentryUuid dari direktori root ruang. |

### Parameter kueri

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| unionId | String | Ya | unionId pengguna. Panggil API [Mengkueri detail pengguna](/id/open/development/query-user-details#) untuk memperolehnya. |

### Isi permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| uploadKey | String | Ya | Pengenal unik dari file yang akan ditambahkan. Panggil API [Memperoleh informasi unggahan file](/id/open/development/obtain-file-upload-informations#) untuk memperoleh nilai parameter uploadKey. |
| name | String | Ya | Nama file, termasuk ekstensinya. Aturan penamaan:- Tidak boleh ada spasi di awal atau akhir; jika tidak, akan dipangkas secara otomatis. - Tidak boleh ada karakter khusus, termasuk tab, `*`, `"`, `<`, `>`, `|`. - Tidak boleh diakhiri dengan `.`. |
| option | Object | Tidak | Parameter opsional. |
| size | Long | Tidak | Ukuran file default, dalam byte.    Jika bidang ini tidak kosong, sistem penyimpanan organisasi memverifikasi apakah ukuran file sebenarnya sesuai dengan nilai ini. Ketidaksesuaian menyebabkan error. |
| conflictStrategy | String | Tidak | Strategi konflik nama file.   - **AUTO_RENAME**: Ganti nama secara otomatis. Default. - **OVERWRITE**: Timpa. - **RETURN_DENTRY_IF_EXISTS**: Kembalikan file yang ada. - **RETURN_ERROR_IF_EXISTS**: Kembalikan error jika file sudah ada. |
| appProperties | Array | Tidak | Daftar properti aplikasi dari file saat ini. Maksimum: 3. |
| name | String | Ya | Nama properti.    Nama properti harus unik dalam aplikasi saat ini. Properti dengan nama yang sama pada aplikasi berbeda tidak saling memengaruhi. |
| value | String | Ya | Nilai properti. |
| visibility | String | Ya | Visibilitas properti.   - **PUBLIC**: Terlihat oleh semua aplikasi. - **PRIVATE**: Hanya terlihat oleh aplikasi saat ini. |
| convertToOnlineDoc | Boolean | Tidak | Apakah akan mengonversi menjadi dokumen online.   - **false** (default): Tidak. - **true**: Ya. |
