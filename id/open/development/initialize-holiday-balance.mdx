Panggil API ini untuk menginisialisasi beberapa saldo cuti reguler bagi seorang karyawan.

## Deskripsi panggilan API

Jenis cuti pengganti tidak perlu diinisialisasi melalui API ini. Durasi lembur otomatis dikonversi menjadi durasi cuti pengganti. Aturan cuti dapat dibuat dengan 2 cara, yaitu dengan memanggil API atau melalui aplikasi resmi DingTalk Attendance:

| Metode pembuatan aturan cuti | Dukungan pembaruan jenis cuti oleh API ini |
| --- | --- |
| Jenis cuti yang dibuat dengan memanggil API [Menambahkan aturan cuti](/id/open/development/add-holiday-rules). | Didukung |
| Jenis cuti yang dibuat di aplikasi Attendance pada Admin Console.   - Dibuat secara default oleh sistem aplikasi Attendance. - Dibuat melalui backend aplikasi Attendance. | Tidak didukung |

## Permintaan

| **Informasi dasar** | |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/topapi/attendance/vacation/quota/init |
| Metode HTTP | POST |
| Tipe aplikasi yang didukung | appType-Aplikasi internal appType-Aplikasi perusahaan pihak ketiga |
| Persyaratan izin | permission-qyapi_holiday_manage-Izin manajemen cuti DingTalk |

### Parameter query

| Nama | Tipe | Wajib | Contoh | Deskripsi |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | bE74xxxx | Kredensial aplikasi yang digunakan untuk memanggil API ini.   - Untuk Aplikasi internal, dapatkan dengan memanggil API [Mendapatkan access_token Aplikasi internal](/id/open/development/obtain-orgapp-token). - Untuk Aplikasi perusahaan pihak ketiga, dapatkan dengan memanggil API untuk mendapatkan access_token organisasi pihak ketiga. |

### Isi permintaan

| Nama | Tipe | Wajib | Contoh | Deskripsi |
| --- | --- | --- | --- | --- |
| op_userid | String | Ya | manager1 | ID pengguna admin di Organisasi Anda yang memiliki izin aplikasi untuk **Persetujuan OA**. |
| leave_quotas | LeaveQuotas | Ya |  | Catatan saldo cuti yang akan diinisialisasi. |
| userid | String | Ya | zhangsan | ID pengguna karyawan. |
| end_time | Number | Ya | 1653851001000 | Waktu berakhirnya masa berlaku kuota, dalam bentuk stempel waktu milidetik. |
| start_time | Number | Ya | 1553851001000 | Waktu dimulainya masa berlaku kuota, dalam bentuk stempel waktu milidetik. |
| leave_code | String | Ya | f84a282xxxx | Pengidentifikasi unik jenis cuti.  **Catatan**   - Inisialisasi didukung untuk jenis cuti yang ditambahkan dengan memanggil API [Menambahkan aturan cuti](/id/open/development/add-holiday-rules). - Inisialisasi tidak didukung untuk jenis cuti bawaan organisasi. |
| reason | String | Tidak | Diimpor oleh admin | Alasan tindakan. |
| quota_num_per_day | Number | Tidak | 100 | Total kuota, dihitung dalam hari.  **Catatan**  Jika jenis cuti dihitung dalam hari, nilai ini tidak boleh kosong dan diukur dalam perseratus hari.  Contoh: 1000 = 10 hari. |
| quota_num_per_hour | Number | Tidak | 100 | Total kuota, dihitung dalam jam.  **Catatan**  Jika jenis cuti dihitung dalam jam, nilai ini tidak boleh kosong dan diukur dalam perseratus jam.  Contoh: 1000 = 10 jam. |
| quota_cycle | String | Tidak | 2019 | Siklus yang berlaku untuk kuota.  **Catatan**  Formatnya harus "yyyy". |

### Contoh permintaan

```curl
curl -X POST "https://api.dingtalk.io/topapi/attendance/vacation/quota/init" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=d82be2bxxxx023' \
-d 'leave_quotas=null' \
-d 'op_userid=zhangsan'
```

Java

```text
DingTalkClient client = new DefaultDingTalkClient("https://api.dingtalk.io/topapi/attendance/vacation/quota/init");
OapiAttendanceVacationQuotaInitRequest req = new OapiAttendanceVacationQuotaInitRequest();
req.setOpUserid("zhangsan");
List<LeaveQuotas> list = new ArrayList<LeaveQuotas>();
LeaveQuotas leaveQuotas = new LeaveQuotas();
list.add(leaveQuotas);
leaveQuotas.setUserid("user1");
leaveQuotas.setEndTime(1653851001000L);
leaveQuotas.setStartTime(1553851001000L);
leaveQuotas.setLeaveCode("f84a2829-xxxx0653");
leaveQuotas.setReason("Diimpor oleh admin");
leaveQuotas.setQuotaNumPerDay(100L);
leaveQuotas.setQuotaNumPerHour(100L);
leaveQuotas.setQuotaCycle("2019");
req.setLeaveQuotas(list);
OapiAttendanceVacationQuotaInitResponse rsp = client.execute(req, access_token);
System.out.println(rsp.getBody());
```

## Respons

### Isi respons

| Nama | Tipe | Contoh | Deskripsi |
| --- | --- | --- | --- |
| result | Result[] |  | Hasil yang dikembalikan. |
| reason | String | Kuota yang dihitung dalam hari tidak boleh kosong | Alasan kegagalan. |
| quota | Quota |  | Catatan yang gagal. |
| leave_code | String | f84a2829-xxxx0653 | Pengidentifikasi unik jenis cuti. |
| userid | String | user1 | ID pengguna karyawan. |
| quota_cycle | String | 2019 | Siklus yang berlaku untuk kuota. |
| errcode | Number | 0 | Kode pengembalian. |
| errmsg | String | ok | Pesan error yang dikembalikan jika panggilan gagal. |
| success | Boolean | true | Menunjukkan apakah permintaan berhasil.   - **true**: Ya - **false**: Tidak |
| request_id | String | zq4aec1jton8 | ID permintaan. |

### Contoh isi respons
