Panggil API ini untuk menghapus lembar kerja dari spreadsheet.

## Permintaan

### Informasi dasar

| Bidang | Nilai |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/doc/workbooks/{workbookId}/sheets/{sheetId}` |
| Metode HTTP | DELETE |
| Tipe aplikasi yang didukung | appType-Internal app　appType-Third-party enterprise app |
| Izin yang diperlukan | permission-Document.Workbook.Write-Spreadsheet write permission |

### Header permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Dapatkan dengan cara berikut:   - Untuk aplikasi internal, panggil API [Dapatkan access token aplikasi internal](/id/open/development/obtain-the-access-token-of-an-internal-app#). - Untuk aplikasi perusahaan pihak ketiga, panggil API [Dapatkan access token organisasi yang diberi otorisasi ke aplikasi pihak ketiga](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#). |

### Parameter path

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| workbookId | String | Ya | ID file spreadsheet. Nilai `nodeId(dentryUuid)` yang dikembalikan oleh [API Knowledge Base](/id/open/development/knowledge-base-overview#) merupakan `workbookId` dari spreadsheet. Dapatkan dengan memanggil API [Dapatkan node](https://open.dingtalk.com/document/development/get-node#) dan [Buat dokumen Knowledge Base](/id/open/development/create-team-space-document#). |
| sheetId | String | Ya | ID atau nama lembar kerja.   - Untuk aplikasi internal, panggil API [Dapatkan semua lembar kerja](/id/open/development/obtain-all-worksheets#) untuk memperoleh nilai parameter `id` atau `name`. - Untuk aplikasi perusahaan pihak ketiga, panggil API [Buat lembar kerja](/id/open/development/create-a-worksheet#) untuk memperoleh `id` dan `name`. |

### Parameter kueri

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| operatorId | String | Ya | unionId operator. Panggil API [Kueri detail pengguna](/id/open/development/query-user-details#) untuk memperolehnya.    Jika operator tidak memiliki izin, API mengembalikan error `The operator has no permission`. |

```http
DELETE /v1.0/doc/workbooks/e54Lq3rgxxx/sheets/Sheet1?operatorId=ppgAQuxxx HTTP/1.1
Host:api.dingtalk.io

Content-Type:application/json
```

```java
}
```
