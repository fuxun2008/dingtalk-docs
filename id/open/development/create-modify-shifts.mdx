---

Panggil API ini untuk membuat shift absensi DingTalk.

## Permintaan

| **Informasi dasar** | |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/topapi/attendance/shift/add |
| Metode HTTP | POST |
| Tipe aplikasi yang didukung | appType-Aplikasi internal |
| Izin yang diperlukan | permission-qyapi_attendance_group_manage-Izin pengelolaan grup absensi |

### Parameter kueri

| Nama | Tipe | Wajib | Contoh | Deskripsi |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | 6d1bxxxx | Kredensial aplikasi yang digunakan untuk memanggil API ini. Dapatkan dengan memanggil API [Mendapatkan access_token aplikasi internal](/id/open/development/obtain-orgapp-token). |

### Isi permintaan

| Nama | Tipe | Wajib | Contoh | Deskripsi |
| --- | --- | --- | --- | --- |
| op_user_id | String | Ya | user01 | userId operator. |
| shift | TopAtClassVo | Ya |  | Shift. |
| owner | String | Tidak | user01 | Pemilik shift. |
| class_group_name | String | Tidak | def | Nama grup shift. |
| corp_id | String | Tidak | ding23 | ID organisasi (corpId). Temukan di [Developer Console](https://open-dev.dingtalk.io/). CorpId |
| name | String | Ya | Shift siang | Nama shift. |
| id | Number | Tidak | 124 | ID shift. Dapatkan dengan memanggil API [Mendapatkan ringkasan shift](/id/open/development/enterprise-shift-query-in-batches).  **Catatan**  Kosongkan id untuk membuat shift. Isi id untuk mengubah shift yang sudah ada. |
| sections | TopAtSectionVo[] | Ya |  | Sesi absen. |
| times | TopAtTimeVo[] | Ya |  | Informasi absen. |
| check_type | String | Ya | OnDuty | Tipe absen:   - **OnDuty**: Absen masuk - **OffDuty**: Absen pulang |
| across | Number | Ya | 0 | Apakah waktu melewati hari berikutnya:   - **0**: Hari yang sama - **1**: Hari berikutnya |
| end_min | Number | Tidak | -1 | Batas waktu absen paling lambat, dalam menit. -1 berarti tanpa batas. |
| check_time | Date | Ya | 2020-12-02 09:00:00 | Waktu absen. |
| free_check | Boolean | Tidak | false | Apakah dibebaskan dari absen:   - **false**: Wajib absen - **true**: Bebas absen |
| begin_min | Number | Tidak | 30 | Batas waktu absen paling awal sebelum jadwal, dalam menit. |
| setting | TopAtClassSettingVo | Tidak |  | Pengaturan. |
| rest_begin_time | TopAtTimeVo | Tidak |  | Awal istirahat. |
| check_type | String | Tidak | OnDuty | Tipe istirahat:   - **OnDuty**: Mulai istirahat - **OffDuty**: Selesai istirahat |
| check_time | Date | Tidak | 2020-12-02 09:00:00 | Waktu absen istirahat. |
| free_check | Boolean | Tidak | false | Apakah dibebaskan dari absen:   - **true**: Bebas absen - **false**: Wajib absen |
| across | Number | Tidak | 0 | Apakah waktu melewati hari berikutnya. Melewati berarti waktu istirahat jatuh pada hari berikutnya:   - **0**: Hari yang sama - **1**: Hari berikutnya |
| class_id | Number | Tidak | 221 | ID shift. Dapatkan dengan memanggil API [Mendapatkan ringkasan shift](/id/open/development/enterprise-shift-query-in-batches). |
| is_flexible | Boolean | Tidak | false | Apakah shift bersifat fleksibel:   - **true**: Fleksibel - **false**: Tidak fleksibel |
| corp_id | String | Tidak | ding121 | ID organisasi (corpId). Temukan di [Developer Console](https://open-dev.dingtalk.io/). CorpId |
| is_deleted | String | Tidak | N | Apakah shift telah dihapus:   - **N**: Ya - **Y**: Tidak |
| rest_end_time | TopAtTimeVo | Tidak |  | Akhir istirahat. |
| check_type | String | Tidak | OffDuty | Tipe istirahat:   - **OnDuty**: Mulai istirahat - **OffDuty**: Selesai istirahat |
| check_time | Date | Tidak | 2020-12-02 09:00:00 | Waktu istirahat. |
| free_check | Boolean | Tidak | false | Apakah dibebaskan dari absen:   - **false**: Wajib absen - **true**: Bebas absen |
| across | Number | Tidak | 1 | Apakah waktu melewati hari berikutnya. Melewati berarti waktu istirahat jatuh pada hari berikutnya:   - **0**: Hari yang sama - **1**: Hari berikutnya |
| serious_late_minutes | Number | Tidak | 31 | Durasi yang dihitung sebagai keterlambatan atau pulang lebih awal berat, dalam menit. |
| absenteeism_late_minutes | Number | Tidak | 60 | Durasi keterlambatan atau pulang lebih awal yang dihitung sebagai mangkir, dalam menit.  **Catatan**  Nilai ini harus lebih besar daripada durasi keterlambatan berat. |
| extras | Json | Tidak | `{"cause":"{\"type\":\"approve\",\"relatedId\":\"43494469-21a6-4111-953b-7810a709f27f\"}"}` | Bidang ekstensi untuk pengaturan shift. Tidak diperlukan untuk shift non-sementara. |
| tags | String | Tidak | temp:schedule:isv | Tag shift. Tidak diperlukan untuk shift non-sementara. |
| service_id | Number | Tidak | 123 | ID layanan yang terikat dengan penjadwalan shift Premium. Tidak diperlukan untuk shift non-sementara. |

### Contoh permintaan

```curl
curl -X POST "https://api.dingtalk.io/topapi/attendance/shift/add" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=39cbcxxxx9058' \
-d 'op_user_id=abc' \
-d 'shift=null'
```

## Respons

### Isi respons

| Nama | Tipe | Contoh | Deskripsi |
| --- | --- | --- | --- |
| result | TopAtClassVo |  | Informasi shift. |
| id | Number | 706715401 | ID shift. |
| name | String | A1 | Nama shift. |
| errmsg | String | ok | Deskripsi kode respons. |
| errcode | Number | 0 | Kode respons. |
| success | Boolean | true | Apakah panggilan berhasil:   - **true**: Berhasil - **false**: Gagal |
| request_id | String | wp2oh4e4vlbu | ID permintaan. |

### Contoh isi respons

```json
{
  "errcode": 0,
  "errmsg":"ok",
  "result": {
    "id": 706715401,
    "name": "A1"
  },
  "success": true,
  "request_id": "wp2oh4e4vlbu"
}
```

### Kode error

Jika panggilan API mengembalikan error, cari solusinya di dokumen [Kode error global](/id/open/development/server-api-error-codes-1) berdasarkan pesan error yang diterima.
