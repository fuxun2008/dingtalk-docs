# Mendapatkan informasi ruang tertentu berdasarkan spaceId

## Permintaan

### Informasi dasar

| Bidang | Nilai |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/v1.0/drive/managements/spaces/query |
| Metode HTTP | POST |
| Tipe aplikasi yang didukung | appType-Aplikasi internal　appType-Aplikasi perusahaan pihak ketiga |
| Persyaratan izin | permission-Drive.SpaceManage.Read-Izin baca untuk informasi pengelolaan ruang aplikasi Drive |

### Header permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Dapatkan dengan salah satu cara berikut:   - Untuk aplikasi internal, panggil API [Mendapatkan access token aplikasi internal](/id/open/development/obtain-the-access-token-of-an-internal-app). - Untuk aplikasi perusahaan pihak ketiga, panggil API [Mendapatkan access token organisasi yang diotorisasi ke aplikasi pihak ketiga](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1). |

### Isi permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| spaceIds | Array of String | Ya | Daftar ID ruang. Anda dapat memasukkan hingga 30 ID. Panggil API [Mendapatkan daftar ruang](/id/open/development/queries-a-space-list) untuk mendapatkannya. |
| unionId | String | Ya | unionId pengguna. Panggil API [Kueri detail pengguna](/id/open/development/query-user-details) untuk mendapatkannya. |

### Contoh permintaan

## Respons

### Isi respons

| Nama | Tipe | Deskripsi |
| --- | --- | --- |
| spaces | Array | Daftar ruang. |
| spaceId | String | ID ruang. |
| spaceName | String | Nama ruang. |
| spaceType | String | Tipe ruang.   - **personal**: Ruang pribadi - **org**: Ruang organisasi |
| quota | Long | Total kuota ruang.   - **-1**: Kuota ruang tidak terbatas. Jika ruang memiliki atribut organisasi, tidak boleh melebihi kuota ruang organisasi. |
| usedQuota | Long | Kuota ruang yang telah digunakan. |
| permissionMode | String | Mode otorisasi. Nilai yang valid:   - **acl**: Otorisasi ACL - **custom**: Otorisasi kustom |
| createTime | String | Waktu pembuatan, dalam format ISO 8601, misalnya 2022-07-29T14:55Z. |
| modifyTime | String | Waktu modifikasi, dalam format ISO 8601, misalnya 2022-07-29T14:55Z. |

### Contoh isi respons

