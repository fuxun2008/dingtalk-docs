Panggil API ini untuk menghapus aturan cuti tertentu.

## Permintaan

| **Informasi dasar** | |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/topapi/attendance/vacation/type/delete |
| Metode HTTP | POST |
| Tipe aplikasi yang didukung | appType-Aplikasi internal　appType-Aplikasi perusahaan pihak ketiga |
| Izin yang diperlukan | qyapi_holiday_manage: Izin manajemen cuti DingTalk |

### Parameter query

| Nama | Tipe | Wajib | Contoh | Deskripsi |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | bE74xxxx | Kredensial aplikasi yang digunakan untuk memanggil API ini.   - Untuk Aplikasi internal, panggil [Mendapatkan access_token Aplikasi internal](/id/open/development/obtain-orgapp-token) untuk memperolehnya. - Untuk Aplikasi perusahaan pihak ketiga, panggil API untuk mendapatkan access_token organisasi pihak ketiga untuk memperolehnya. |

### Isi permintaan

| Nama | Tipe | Wajib | Contoh | Deskripsi |
| --- | --- | --- | --- | --- |
| leave_code | String | Ya | 03747xxxx | Pengidentifikasi unik aturan cuti. Panggil [Mengkueri daftar aturan cuti](/id/open/development/holiday-type-query) untuk memperoleh nilai leave_code. |
| op_userid | String | Ya | user01 | ID pengguna admin di Organisasi Anda yang memiliki izin aplikasi **Persetujuan OA**. |

### Contoh permintaan

```curl
curl -X POST "https://api.dingtalk.io/topapi/attendance/vacation/type/delete" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=3acaxxxxa30a2' \
-d 'leave_code=037477axxxxae5e7973' \
-d 'op_userid=03085665764167'
```

## Respons

### Isi respons

| Nama | Tipe | Contoh | Deskripsi |
| --- | --- | --- | --- |
| result | LeaveTypeVo |  | Hasil yang dikembalikan. |
| leave_code | String | 03747xxxx | Pengidentifikasi unik aturan cuti. |
| leave_name | String | Cuti tahunan | Nama cuti. |
| leave_view_unit | String | day | Satuan pengajuan cuti.   - **day**: Hari - **halfDay**: Setengah hari - **hour**: Jam |
| biz_type | String | general_leave | Jenis cuti.   - **general_leave**: Cuti reguler - **lieu_leave**: Lembur yang dikonversi menjadi cuti pengganti |
| natural_day_leave | Boolean | true | Apakah durasi cuti dihitung berdasarkan hari kalender.   - **true**: Durasi cuti dihitung berdasarkan hari kalender. - **false**: Durasi cuti tidak dihitung berdasarkan hari kalender.  **Catatan**  Jika nilainya **false**, durasi cuti dihitung berdasarkan penjadwalan shift pengguna selama periode cuti saat pengguna mengirimkan pengajuan cuti. |
| hours_in_per_day | Number | 1000 | Jam kerja per hari, dalam satuan 1/100 jam.  Contoh: 1 hari = 10 jam = 1000. |
| errcode | Number | 0 | Kode pengembalian. |
| errmsg | String | ok | Deskripsi kode pengembalian. |
| success | Boolean | true | Apakah panggilan berhasil.   - **true**: Ya - **false**: Tidak |
| request_id | String | xss3trk3zypq | ID permintaan. |

### Contoh isi respons

```json
{
  "errcode": 0,
  "errmsg":"ok",
  "result": {
    "biz_type": "general_leave",
    "hours_in_per_day": 1000,
    "leave_code": "03747xxxx",
    "leave_name": "Cuti tahunan",
    "leave_view_unit": "day",
    "natural_day_leave": true
  },
  "success": true,
  "request_id": "xss3trk3zypq"
}
```

### Kode error

Jika panggilan mengembalikan error, cari solusinya di dokumen [Kode error global](/id/open/development/server-api-error-codes-1) berdasarkan pesan error.
