## Langkah 1: Buat aplikasi DingTalk

1. Masuk ke [DingTalk Developer Console](https://open-dev.dingtalk.io/#/corpeapp).
2. Klik App Development lalu buat aplikasi internal atau aplikasi perusahaan pihak ketiga.
3. Pada halaman detail aplikasi, dapatkan Client ID (sebelumnya App Key/SuiteKey) dan Client Secret (sebelumnya App Secret/SuiteSecret) dari aplikasi tersebut.

## Langkah 2: Dapatkan kredensial akses aplikasi

Panggil API [Mendapatkan access token aplikasi internal](/id/open/development/obtain-the-access-token-of-an-internal-app) atau API Mendapatkan access token organisasi terotorisasi aplikasi pihak ketiga untuk menghasilkan access token.
