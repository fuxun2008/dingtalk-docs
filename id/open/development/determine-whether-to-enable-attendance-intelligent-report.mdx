---
title: "Periksa apakah laporan statistik cerdas diaktifkan"
description: "Panggil API DingTalk ini untuk memeriksa status laporan statistik cerdas absensi organisasi Anda dan pastikan API laporan statistik lainnya dapat dipanggil."
---

Panggil API ini untuk memeriksa apakah organisasi Anda telah mengaktifkan laporan cerdas absensi. Jika laporan cerdas dinonaktifkan, API laporan statistik lainnya tidak dapat dipanggil.

## Permintaan

| **Informasi dasar** | |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/topapi/attendance/isopensmartreport |
| Metode HTTP | POST |
| Tipe aplikasi yang didukung | appType-Aplikasi internal　appType-Aplikasi perusahaan pihak ketiga |
| Izin | permission-qyapi_base-Izin dasar yang diperlukan untuk memanggil API organisasi |

### Parameter query

| Nama | Tipe | Wajib | Contoh | Deskripsi |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | 6d1bxxxx | Kredensial aplikasi yang digunakan untuk memanggil API ini.   - Aplikasi internal: Dapatkan dengan memanggil API [Mendapatkan access_token Aplikasi internal](/id/open/development/obtain-orgapp-token). - Aplikasi perusahaan pihak ketiga: Dapatkan dengan memanggil API Mendapatkan access_token Aplikasi perusahaan pihak ketiga. |

### Contoh permintaan

```curl
curl -X POST "https://api.dingtalk.io/topapi/attendance/isopensmartreport" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=b74b3xxxx0bb7c'
```

Java

```java

```

## Respons

### Isi respons

| Nama | Tipe | Contoh | Deskripsi |
| --- | --- | --- | --- |
| result | IsOpenSmartReportForTopVo |  | Hasil yang dikembalikan. |
| smart_report | Boolean | true | Status laporan statistik cerdas:   - **true**: Diaktifkan - **false**: Dinonaktifkan |
| request_id | String | 6f9h5mh9a94i | ID permintaan. |
| errcode | Number | 0 | Kode respons. |

### Contoh isi respons

```json
{
  "errcode": 0,
  "result": {
    "smart_report": true
  },
  "request_id": "6f9h5mh9a94i"
}
```

### Kode error

Jika panggilan API mengembalikan error, cari solusinya di dokumen [Kode Error Global](/id/open/development/server-api-error-codes-1) berdasarkan pesan error.
