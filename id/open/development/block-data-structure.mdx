Dokumen online adalah sebuah pohon yang tersusun dari beberapa elemen block. Tipe BlockElement yang berbeda dapat menyusun tipe elemen yang berbeda di dalamnya. Misalnya, block Callout dapat menyusun `BlockElement` apa pun, tetapi block Paragraph hanya dapat menyusun InlineElement.

Struktur data dari sebuah elemen block adalah sebagai berikut:

```json
{
  "blockType": enum(BlockType),             // Tipe elemen block. Lihat enum `BlockType` di bagian bawah dokumen ini.
  /**
   * Berikut ini adalah semua tipe Block yang didukung, seperti Heading dan Paragraph.
   * Setiap tipe Block memiliki property-nya sendiri.
  */
  "blockquote": Object(Callout),
  "callout": Object(Callout),
  "columns": Object(Columns),
  "heading": Object(Heading),
  "paragraph": Object(Paragraph),
  "orderedList": Object(OrderedList)
  "unorderedList": Object(UnorderedList),
  "table": Object(Table),
  // Setiap tipe Block memiliki BlockChildren yang didukungnya sendiri. Lihat deskripsi `children` pada setiap tipe Block.

  "children": BlockChildren[ ],

}
```

## Struktur data elemen block

Dokumen online adalah struktur pohon yang tersusun dari beberapa **elemen block**. Tipe elemen block yang berbeda mendukung tipe elemen anak bertingkat yang berbeda:

- `children` dari `callout` dan `columns` harus berupa **array BlockElement**.
- `children` dari `paragraph`, `heading`, `orderedList`, `unorderedList`, dan `blockquote` harus berupa **array InlineElement**.
- `table` saat ini tidak mendukung penentuan `children`.

### Enum BlockType

| Nilai enum | Deskripsi |
| --- | --- |
| paragraph | Block paragraf. |
| heading | Block heading. |
| blockquote | Block kutipan. |
| callout | Block callout. |
| columns | Block kolom. |
| orderedList | Block Daftar Bernomor. |
| unorderedList | Block Daftar Berpoin. |
| table | Block Spreadsheet. |
| tableRow | Block baris tabel (anak dari block tabel). |
| tableCell | Block sel tabel (anak dari block tabel). |

> Tipe elemen yang tidak didukung secara seragam mengembalikan `Undefined`.

### Paragraph

```json
{
  "blockType": "paragraph",
  "paragraph": {
    "text": "Konten teks paragraf",
    "indent": { "left": 32 },
    "folded": false
  },
  "children": [InlineElement]
}
```

| Nama field | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| text | string | Tidak | Konten teks paragraf. |
| indent | object(Indent) | Tidak | Nilai indentasi. `left` harus berupa integer lebih besar dari 0. |
| folded | boolean | Tidak | Apakah paragraf dilipat (melipat elemen block dengan nilai indentasi lebih besar dari paragraf saat ini). |

- `children`: **array InlineElement**.
- Object `paragraph` **tidak boleh dihilangkan**. Ketika konten kosong, kirim `{}`.

### Heading

```json
{
  "blockType": "heading",
  "heading": {
    "level": 1,
    "text": "Heading level 1"
  },
  "children": [InlineElement]
}
```

| Nama field | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| text | string | Tidak | Konten teks heading. |
| level | integer(enum) | Tidak | Level heading. Rentang nilai: `1` hingga `6`. 1 menunjukkan heading level 1. |

- `children`: **array InlineElement**.

### Quote

```json
{
  "blockType": "blockquote",
  "blockquote": {
    "text": "Konten yang dikutip",
    "indent": { "left": 32 }
  },
  "children": [InlineElement]
}
```

| Nama field | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| text | string | Tidak | Teks di dalam kutipan. |
| indent | object(Indent) | Tidak | Nilai indentasi tertentu. |

- `children`: **array InlineElement**.

### Block callout

```json
{
  "blockType": "callout",
  "callout": {
    "sticker": "灯泡",
    "showstk": true,
    "color": "#333333",
    "border": "#FFD700",
    "bgcolor": "#FFF9C4"
  },
  "children": [BlockElement]
}
```

| Nama field | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| sticker | string(enum Emoji) | Tidak | Kode emoji. Lihat [Nilai enum Emoji](/id/open/development/enumeration-values-of-emojis). |
| showstk | boolean | Tidak | Apakah emoji ditampilkan. |
| color | string | Tidak | Warna teks. |
| border | string | Tidak | Warna border. |
| bgcolor | string | Tidak | Warna latar belakang. |

- `children`: **array BlockElement** (InlineElement tidak diizinkan).

### Columns

```json
{
  "blockType": "columns",
  "columns": {
    "size": 2,
    "noFill": false
  },
  "children": [BlockElement]
}
```

| Nama field | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| size | number | Tidak | Jumlah kolom. |
| noFill | boolean | Tidak | Apakah warna latar belakang diisi secara otomatis. |

- `children`: **array BlockElement** (InlineElement tidak diizinkan).

### Daftar Bernomor

```json
{
  "blockType": "orderedList",
  "orderedList": {
    "list": {
      "listId": "list-001",
      "level": 0,
      "listStyleType": "decimal",
      "listStyle": {
        "format": "decimal",
        "text": "%1.",
        "align": "left"
      },
      "symbolStyle": {
        "bold": false
      }
    },
    "indent": { "left": 32 }
  },
  "children": [InlineElement]
}
```

| Nama field | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| list | object(ListObject) | Ya | Atribut spesifik Daftar Bernomor. Lihat [ListObject](#e6621bc176irg). |
| indent | object(Indent) | Tidak | Nilai indentasi. `left` harus berupa integer lebih besar dari 0. |

- `children`: **array InlineElement**.

### Daftar Berpoin

```json
{
  "blockType": "unorderedList",
  "unorderedList": {
    "list": {
      "listId": "list-002",
      "level": 0,
      "listStyleType": "disc",
      "listStyle": {
        "format": "disc",
        "text": "%1",
        "align": "left"
      },
      "symbolStyle": {
        "bold": false
      }
    },
    "indent": { "left": 32 }
  },
  "children": [InlineElement]
}
```

| Nama field | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| list | object(ListObject) | Ya | Atribut spesifik Daftar Berpoin. Lihat [ListObject](#e6621bc176irg). |
| indent | object(Indent) | Tidak | Nilai indentasi. `left` harus berupa integer lebih besar dari 0. |

- `children`: **array InlineElement**.

### Spreadsheet

```json
{
  "blockType": "table",
  "table": {
    "rolSize": 3,
    "colSize": 4,
    "cells": [
      ["Baris1-Kol1", "Baris1-Kol2", "Baris1-Kol3", "Baris1-Kol4"],
      ["Baris2-Kol1", "Baris2-Kol2", "Baris2-Kol3", "Baris2-Kol4"],
      ["Baris3-Kol1", "Baris3-Kol2", "Baris3-Kol3", "Baris3-Kol4"]
    ]
  }
}
```

| Nama field | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| rolSize | number | Ya | Jumlah baris. |
| colSize | number | Ya | Jumlah kolom. |
| cells | String[][] | Tidak | Konten teks sel. Sebuah array String dua dimensi. |

- `children`: **Tidak didukung**. Penentuan children saat ini tidak diizinkan.

## Struktur data InlineElement

Elemen inline digunakan dalam `children` dari elemen block berbasis teks (paragraf, heading, daftar, dan sebagainya).

### Enum InlineType

| Nilai enum | Deskripsi |
| --- | --- |
| text | Teks. |
| sticker | Emoji. |
| image | Gambar. |
| link | Tautan. |

### Text

```json
{
  "text": "Teks merah tebal",
  "sz": 16,
  "color": "red",
  "highlight": "yellow",
  "bold": true,
  "italic": false,
  "stike": false,
  "underline": false,
  "fonts": "monospace"
}
```

| Nama field | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| text | string | Ya | Konten teks. |
| sz | number | Tidak | Ukuran font (satuan default: px). |
| color | string | Tidak | Warna teks. |
| highlight | string | Tidak | Warna latar belakang sorotan. |
| bold | boolean | Tidak | Apakah menerapkan tebal. |
| italic | boolean | Tidak | Apakah menerapkan miring. |
| stike | boolean | Tidak | Apakah menerapkan coret. |
| underline | boolean | Tidak | Apakah menerapkan garis bawah. |
| fonts | string(enum Fonts) | Tidak | Font. Nilai enum:   - **monospace**: monospace font - **STSong**: STSong - **Microsoft YaHei**: Microsoft YaHei - **FangSong_GB2312**: FangSong GB2312 - **Helvetica**: Helvetica - **Helvetica Neue**: Helvetica Neue - **Consolas**: Consolas - **宋体**: SimSun - **Impact**: Impact - **sanrif**: sanrif - **Calibri**: Calibri |

### Emoji

```json
{
  "elementType": "sticker",
  "properties": {
    "code": "大笑"
  }
}
```

| Nama field | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| code | string(enum Emoji) | Ya | Kode emoji. Lihat [Nilai enum Emoji](/id/open/development/enumeration-values-of-emojis). |

### Image

```json
{
  "elementType": "image",
  "properties": {
    "src": "https://example.com/image.jpg"
  }
}
```

| Nama field | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| src | string | Tidak | URL sumber daya gambar. |

### Link

```json
{
  "elementType": "link",
  "properties": {
    "href": "https://example.com"
  },
  "children": [
    { "text": "Klik untuk membuka tautan" }
  ]
}
```

| Nama field | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| href | string | Tidak | URL tautan. |

- `children`: **array Text**. Saat menyisipkan tautan, `children` harus ditentukan dan berisi setidaknya satu node teks yang `text`-nya tidak kosong.

## Struktur data umum

### Indent

| Nama field | Tipe | Wajib | Deskripsi | Contoh |
| --- | --- | --- | --- | --- |
| left | number | Tidak | Nilai indentasi tertentu. Harus berupa integer lebih besar dari 0, jika tidak akan mengembalikan error. | `32` |

---

### ListObject

| Nama field | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| listId | string | Tidak | ID dari daftar saat ini. Saat menyisipkan Daftar Bernomor bertingkat, pastikan `listId` konsisten di seluruh grup daftar bertingkat yang sama, jika tidak tampilannya akan salah. |
| level | number | Ya | Tingkat daftar (dimulai dari 0). |
| listStyleType | string | Ya | Tipe gaya daftar. |
| listStyle | object(ListStyle) | Ya | Gaya daftar tertentu. Lihat [ListStyle](#bad921c2ebc3h). |
| symbolStyle | object(SymbolStyle) | Tidak | Gaya simbol daftar. Lihat [SymbolStyle](#b16d5427cbutg). |

---

### ListStyle

| Nama field | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| format | string | Ya | Format Daftar Berpoin. |
| text | string | Ya | Teks. |
| align | string | Ya | Perataan, seperti `left`, `center`, atau `right`. |

---

### SymbolStyle

| Nama field | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| sz | number | Tidak | Ukuran font simbol Daftar Berpoin. |
| shd | string | Tidak | Warna latar belakang simbol Daftar Berpoin. |
| fonts | string | Tidak | Format font simbol Daftar Berpoin. |
| color | string | Tidak | Warna font simbol Daftar Berpoin. |
| bold | boolean | Tidak | Apakah menerapkan tebal. |
| strike | boolean | Tidak | Apakah menampilkan coret. |
| italic | boolean | Tidak | Apakah menampilkan miring. |
