Dokumen ini menjelaskan apa itu manajemen paket offline dan bagaimana cara menggunakan paket offline.

## Apa itu paket offline

Paket offline menggabungkan sumber daya statis dalam halaman, termasuk HTML, JavaScript, dan CSS, ke dalam satu arsip terkompresi. Ketika pengguna membuka aplikasi, Sisi klien mengunduh paket offline secara lokal, lalu memuatnya langsung dari penyimpanan lokal melalui Sisi klien DingTalk. Hal ini meminimalkan dampak lingkungan jaringan terhadap Aplikasi mikro H5 DingTalk.

## Batasan integrasi

- Hanya tersedia di perangkat seluler, dan Versi Sisi klien harus 6.5.20 atau yang lebih baru.
- Ukuran total sumber daya offline yang diunggah tidak boleh melebihi 10 MB.

## Langkah integrasi

### Langkah 1: Aktifkan fitur paket offline Aplikasi mikro

1. Masuk ke [DingTalk Developer Console](https://open-dev.dingtalk.com/).
2. Pilih aplikasi yang ingin Anda aktifkan paket offline-nya.
3. Pada batang navigasi, klik **Version Management and Release**. Pada halaman **Version Management and Release**, klik tombol **Offline Package Management**, lalu klik **Confirm**.

### Langkah 2: Kemas paket offline

1. Pada proyek Anda, instal [dingtalk-h5package-opensdk](https://www.npmjs.com/package/dingtalk-h5package-opensdk) melalui npm.

   ```
   npm install dingtalk-h5package-opensdk --save-dev
   ```
2. Pada proyek Anda, buat file konfigurasi paket offline `localresource.json`. Berikut adalah contohnya:

   ```
   {
     "miniAppId": "ID paket offline yang akan dikemas",
     // Pemetaan antara URL sumber daya online dan file atau direktori lokal. Key adalah jalur URL sumber daya online yang sesuai dengan sumber daya lokal, dan value adalah direktori sumber daya lokal.
     "assets": {
       // Value adalah sebuah direktori. Konfigurasi ini menambahkan sumber daya di bawah direktori ./dist ke jalur https://www.example.com/myapp.
       "https://www.example.com/myapp": "./dist"
     },
     // Daftar URL eksternal yang menjadi dependensi.
     "externalAssets": [
       "https://unpkg.com/react@16.7.0/umd/react.production.min.js",
       "https://unpkg.com/vue@3.2.45/dist/vue.global.js",
       "https://unpkg.com/jquery@3.6.1/dist/jquery.js"
     ]
   }
   ```
3. Jalankan perintah pengemasan pada proyek Anda untuk menghasilkan file sumber daya bernama `${offlinePackageId}.zip` secara lokal.

   ```
   npx h5package pack
   ```

### Langkah 3: Unggah paket offline

Pada halaman **Version Management and Release**, klik **Please upload the H5 resource package (.zip, .tar, .tar.gz)**, pilih sumber daya arsip dari Langkah 2, lalu tunggu hingga paket offline selesai diurai.

### Langkah 4: Rilis paket offline

Pilih versi target dari paket offline, klik tombol **Release**, lalu klik **Confirm Release**.

## Cara menggunakan

Pada parameter kueri URL bisnis, tambahkan bidang `dd_mini_app_id`. Dapatkan nilainya dari **Offline Package ID** pada halaman **Offline Package Management**.

Contoh:

URL normal: https://www.example.com/myapp/index.html

URL paket offline: https://www.example.com/myapp/index.html?dd_mini_app_id=500000000xxxxx

## Alat debugging

DingTalk menyediakan alat debugging untuk paket offline. Fitur utamanya adalah **memeriksa informasi paket offline lokal di ponsel** dan **DevTools untuk halaman paket offline H5**.

Persyaratan Versi Sisi klien untuk menggunakan alat debugging: Android 6.5.35 atau yang lebih baru; iOS 6.5.35 atau yang lebih baru.

Cara menggunakan alat: Pindai Kode QR berikut dengan Sisi klien DingTalk.

Setelah memindai Kode QR, Anda masuk ke halaman beranda alat debugging.

### Diagnosis halaman H5

Cara kerja diagnosis halaman: Ketika halaman paket offline H5 dibuka, kontainer menyuntikkan DevTools ke dalam halaman untuk memantau cara halaman berjalan.

Langkah:

1. Klik **H5 Page Diagnosis**.
2. Masukkan URL paket offline H5 yang akan diaktifkan.
3. Klik **Start Diagnosis** untuk masuk ke halaman diagnosis.

### Pemeriksaan paket offline lokal

Langkah:

1. Klik **Local Offline Package Query**.
2. Masukkan `miniAppId`, yaitu ID paket offline.
3. Klik **View Offline Package Information**.
