Panggil API ini untuk mengkueri detail semua grup absensi.

## Deskripsi panggilan API

Di aplikasi Absensi DingTalk, grup absensi adalah sekumpulan pengguna atau departemen yang memiliki aturan absensi yang sama, seperti shift dan lokasi absensi. Organisasi dapat membuat beberapa grup absensi sesuai kebutuhan bisnis.

<Note>
Berbeda dengan API [Mendapatkan detail grup absensi](/id/open/development/query-a-single-attendance-group), API ini mengembalikan informasi grup absensi yang mencakup pengaturan shift.
</Note>

Untuk melihat grup absensi, buka **Kelola Grup Absensi** di admin console **Absensi** DingTalk. Misalnya, grup yang dibuat melalui API dapat berupa grup absensi shift tetap dengan shift siang pukul 09.00–18.00 dari Senin hingga Jumat serta hari libur pada Sabtu dan Minggu.

## Permintaan

| **Informasi dasar** | |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/topapi/attendance/getsimplegroups |
| Metode HTTP | POST |
| Tipe aplikasi yang didukung | appType-Aplikasi internal appType-Aplikasi perusahaan pihak ketiga |
| Izin | permission-qyapi_base-Izin dasar yang diperlukan untuk memanggil API organisasi |

### Parameter kueri

| Nama | Tipe | Wajib | Contoh | Deskripsi |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | bE74xxxx | Kredensial aplikasi yang digunakan untuk memanggil API ini.   - Untuk Aplikasi internal, panggil API [Mendapatkan access_token Aplikasi internal](/id/open/development/obtain-orgapp-token). - Untuk Aplikasi perusahaan pihak ketiga, panggil API untuk mendapatkan access_token organisasi pihak ketiga. |

### Isi permintaan

| Nama | Tipe | Wajib | Contoh | Deskripsi |
| --- | --- | --- | --- | --- |
| offset | Number | Tidak | 0 | Offset paginasi. Hanya berlaku jika diatur bersama parameter size. Offset dimulai dari 0. Pada panggilan berikutnya, kirim jumlah size dan offset dari panggilan sebelumnya. |
| size | Number | Tidak | 10 | Ukuran halaman. Nilai maksimum: 10. |

### Contoh permintaan

```curl
curl -X POST "https://api.dingtalk.io/topapi/attendance/getsimplegroups" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=c4a715xxxx0a0da2' \
-d 'offset=0' \
-d 'size=10'
```

Java

```text
DingTalkClient client = new DefaultDingTalkClient("https://api.dingtalk.io/topapi/attendance/getsimplegroups");
OapiAttendanceGetsimplegroupsRequest req = new OapiAttendanceGetsimplegroupsRequest();
req.setOffset(0L);
req.setSize(10L);
OapiAttendanceGetsimplegroupsResponse rsp = client.execute(req, access_token);
System.out.println(rsp.getBody());
```

Python

```python
import dingtalk.api

req=dingtalk.api.OapiAttendanceGetsimplegroupsRequest("https://api.dingtalk.io/topapi/attendance/getsimplegroups")

req.offset=0
req.size=10
try:
  resp= req.getResponse(access_token)
  print(resp)
except Exception,e:
  print(e)
```

```php

$req = new OapiAttendanceGetsimplegroupsRequest;
$req->setOffset("0");
$req->setSize("10");
$resp = $c->execute($req, $access_token, "https://api.dingtalk.io/topapi/attendance/getsimplegroups");
```

C#

```text

```
