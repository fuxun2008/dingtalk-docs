---
title: "Perbarui filter"
description: "Panggil API ini untuk memperbarui kriteria filter beberapa kolom sekaligus dalam filter global di DingTalk Spreadsheet — cocok untuk mengatur, mengubah, atau menghapus Aturan Filter di banyak kolom secara bersamaan."
---

Panggil API ini untuk memperbarui kondisi filter beberapa kolom sekaligus dalam filter global. API ini cocok untuk skenario ketika Anda perlu mengatur, mengubah, atau menghapus Aturan Filter untuk beberapa kolom secara bersamaan. Misalnya, dalam laporan analisis data, Anda dapat memfilter berdasarkan pengguna, rentang jumlah, dan warna label di beberapa dimensi sekaligus.

## Permintaan

### Informasi dasar

| Bidang | Value |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/doc/workbooks/{workbookId}/sheets/{sheetId}/filter/updateFilter` |
| Metode HTTP | POST |
| Jenis aplikasi yang didukung | appType-Internal app |
| Izin yang diperlukan | permission-Document.Workbook.Write-DingTalk Spreadsheet write permission |

### Header permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Panggil API [Mendapatkan access token aplikasi internal](/id/open/development/obtain-the-access-token-of-an-internal-app) untuk memperolehnya. |

### Parameter path

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| workbookId | String | Ya | ID file Spreadsheet. `nodeId(dentryUuid)` yang dikembalikan oleh [API Knowledge Base](/id/open/development/knowledge-base-overview) adalah `workbookId` Spreadsheet. Anda dapat memperolehnya dengan memanggil API [Mendapatkan node](https://open.dingtalk.com/document/orgapp/get-node) dan [Membuat dokumen Knowledge Base](/id/open/development/create-team-space-document). |
| sheetId | String | Ya | ID atau nama Lembar Kerja. Panggil API [Mendapatkan semua lembar kerja](/id/open/development/obtain-all-worksheets) untuk memperoleh nilai parameter id atau name. |

### Parameter query

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| operatorId | String | Ya | unionId operator.   - Panggil API [Mendapatkan informasi pengguna menggunakan kode login senyap](/id/open/development/obtain-the-userid-of-a-user-by-using-the-log-free) untuk memperoleh nilai parameter unionid. - Panggil API [Mengkueri detail pengguna](/id/open/development/query-user-details) untuk memperoleh nilai parameter unionid.       Jika operator tidak memiliki izin, API mengembalikan error `The operator has no permission`. |

### Isi permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| criteria | `Map<String, Object>` | Ya | Peta dari offset kolom ke kondisi filter. Key adalah offset kolom (string yang dimulai dari 0, relatif terhadap kolom pertama dari rentang filter). Value adalah object kondisi filter untuk kolom tersebut, atau `null` (yang menghapus kondisi untuk kolom tersebut). |
|  | Object | Tidak | Kondisi filter untuk kolom saat ini. |
| filterType | String | Tidak | Tipe filter. Nilai yang valid:   - **values**: Filter berdasarkan nilai. - **color**: Filter berdasarkan warna. - **condition**: Filter berdasarkan kondisi. |
| visibleValues | Array of String | Tidak | Nilai yang terlihat. |
| conditions | Array | Tidak | Array kondisi filter. Maksimal 2 diperbolehkan. Wajib hanya ketika `filterType` adalah `condition`. |
| operator | String | Tidak | Operator kondisi. Nilai yang valid:   - **equal**: Sama dengan. - **not-equal**: Tidak sama dengan. - **contains**: Berisi. - **not-contains**: Tidak berisi. - **starts-with**: Diawali dengan. - **not-starts-with**: Tidak diawali dengan. - **ends-with**: Diakhiri dengan. - **not-ends-with**: Tidak diakhiri dengan. - **greater**: Lebih besar dari. - **greater-equal**: Lebih besar dari atau sama dengan. - **less**: Lebih kecil dari. - **less-equal**: Lebih kecil dari atau sama dengan. |
| value | String | Tidak | Nilai kondisi. |
| conditionOperator | String | Tidak | Hubungan antara beberapa kondisi. Atur ke `"and"` (default) atau `"or"`. Wajib hanya ketika `filterType` adalah `condition`. |
| backgroundColor | String | Tidak | Filter berdasarkan warna latar belakang. Nilai warna heksadesimal, seperti `"#FF0000"`. Berikan hanya ketika `filterType` adalah `color`. |
| fontColor | String | Tidak | Filter berdasarkan warna font. Nilai warna heksadesimal, seperti `"#0000FF"`. Berikan hanya ketika `filterType` adalah `color`. |
