Topik ini menjelaskan tipe pesan dan format data yang dapat dikirim oleh Bot, serta format data untuk pesan yang diterima oleh Bot.

## Mengirim pesan dengan Bot

### Tipe pesan

Anda dapat mengirim pesan Bot dengan dua cara: **memanggil API** atau menggunakan **Webhook**. Tipe pesan dan format data yang didukung berbeda tergantung metode yang digunakan.

<Note>
Kami menyarankan Anda mengirim pesan dengan memanggil API.
</Note>

| Tipe pesan | Kirim via API | Kirim via Webhook |
| --- | --- | --- |
| Text | ✅ | ✅ |
| Markdown | ✅ | ✅ |
| Image | ✅ | ❌ |
| ActionCard | ✅ | ✅ |
| FeedCard | ❌ | ✅ |
| Link | ✅ | ✅ |
| Audio | ✅ | ❌ |
| File | ✅ | ❌ |
| Video | ✅ | ❌ |

### Metode 1: Panggil sebuah API

### Penting

- Pesan Bot dalam obrolan satu lawan satu antara pengguna dan Bot: mendukung **pengiriman dan penerimaan** gambar, pesan suara, dan file.
- Pesan Bot dalam obrolan grup: Bot dapat **mengirim** gambar, pesan suara, video, dan file. **Namun, pengguna tidak dapat @ Bot untuk mengirim pesan suara, video, atau file ke Bot di dalam obrolan grup.**

#### API yang tersedia

- [Mengirim pesan Bot satu lawan satu secara massal](/id/open/development/chatbots-send-one-on-one-chat-messages-in-batches)
- [Mengirim pesan obrolan grup dengan Bot](/id/open/development/the-robot-sends-a-group-message)

#### Format data

- **Message template key**: pengidentifikasi unik yang digunakan saat developer mengirim pesan. Ini memungkinkan kode untuk dengan cepat mereferensikan templat pesan yang telah ditentukan sebelumnya.
- **Message template parameters**: data aktual yang digunakan untuk menggantikan placeholder yang telah ditentukan sebelumnya dalam templat pesan. Misalnya, ketika message template key adalah `sampleText`, Anda perlu mengatur nilai bidang `content`.
- **Contoh**: contoh HTTP berikut menunjukkan bagaimana Bot aplikasi internal mengirim pesan **text** ke sebuah **grup**:

  - Message template key: `"msgKey" : "sampleText"`
  - Message template parameters: `"msgParam" : "{\"content\":\"DingTalk, tempat kemajuan terjadi\"}"`

Untuk informasi selengkapnya, lihat [Mengirim pesan obrolan grup dengan Bot](/id/open/development/the-robot-sends-a-group-message).

```http
POST /v1.0/robot/groupMessages/send HTTP/1.1
Host:api.dingtalk.io
x-acs-dingtalk-access-token:<your access token>
Content-Type:application/json

{
  "msgParam" : "{\"content\":\"DingTalk, tempat kemajuan terjadi\"}",
  "msgKey" : "sampleText",
  "openConversationId" : "cid6KeBBLov********",
  "robotCode" : "dingue4kfzdxbyn*******"
}
```

### Metode 2: Gunakan Webhook

<Note>
Webhook hanya didukung dalam obrolan grup.
</Note>

Untuk informasi tentang mengirim pesan via Webhook, lihat [Bot membalas dan mengirim pesan](/id/open/dingstart/robot-reply-and-send-messages) dan [Membuat Bot kustom](/id/open/dingstart/custom-bot-creation-and-installation).

#### Pesan text

```json
{
    "at": {
        "atMobiles": [
            "180xxxxxx"
        ],
        "atUserIds": [
            "user123"
        ],
        "isAtAll": false
    },
    "text": {
        "content": "Saya adalah diri saya sendiri, @180xxxxxx adalah percikan yang berbeda"
    },
    "msgtype": "text"
}
```

| **Parameter** | **Wajib** | **Tipe** | **Deskripsi** |
| --- | --- | --- | --- |
| msgtype | Ya | String | text. |
| content | Ya | String | Teks pesan. |
| atMobiles | Tidak | Array | Nomor telepon pengguna yang di-@.  **Catatan**  Tambahkan nomor telepon pengguna yang di-@ dalam `content`. Hanya anggota grup yang dapat di-@. Nomor telepon non-anggota disamarkan. |
| atUserIds | Tidak | Array | ID pengguna dari pengguna yang di-@.  **Catatan**  Tambahkan ID pengguna dari pengguna yang di-@ dalam `content`. |
| isAtAll | Tidak | Boolean | Setel ke true untuk @ semua orang; jika tidak, setel ke false. |

## Menerima pesan dengan Bot

Ketika pengguna @ Bot grup atau mengirim pesan langsung ke Bot, DingTalk meneruskan pesan yang diterima ke layanan callback Bot yang telah dikonfigurasi oleh developer.

Contoh berikut menggunakan tipe pesan text. Jika Anda menggunakan callback HTTP, DingTalk mengirimkan pesan dengan permintaan POST.

  "atUsers": [
    {
      "dingtalkId": "xxx",
      "staffId":"xxx",
      "unionId":"edxxx34"
    }
  ],
  "chatbotCorpId": "ding9733d095*******6cb783455b",
  "chatbotUserId": "$:LWCP_xxxxr5",
  "msgId": "msgrK2xxxxU+riw==",
  "senderNick": "Xiao Ding",
  "isAdmin": true,
  "senderStaffId": "0147xxxx8602",
  "sessionWebhookExpiredTime": 1708332604316,
  "createAt": 1708327204136,
  "senderCorpId": "ding9733d095*******6cb783455b",
  "conversationType": "2",
  "senderId": "$:LWCP_v1xxxxBv1MhAv9",
  "conversationTitle": "Grup uji",

| chatbotUserId | String | ID Bot terenkripsi. |
| msgId | String | ID pesan terenkripsi. |
| senderNick | String | Nama pengirim. |

### Tipe pesan

Bot saat ini dapat menerima pesan dengan tipe berikut: text, suara, gambar, file, video, dan Teks Kaya. Bidang untuk setiap tipe pesan dijelaskan di bawah. Selain bidang tipe pesan dan isi pesan, parameter lainnya sama seperti pada tabel di atas.

#### Pesan text

```json
{
  "msgtype": "text",
  "text": {
    "content": "Hello"
  }
}
```

| **Parameter** | **Tipe** | **Deskripsi** |
| --- | --- | --- |
| msgtype | String | Tipe pesan:   - **text**: pesan text |
| text | Object | Teks pesan:   - **content**: konten pesan yang diterima oleh Bot. |

#### Pesan Teks Kaya

```json
{
  "msgtype": "richText",
  "content": {
    "richText": [
      {
        "text": "Hello"
      },
      {
        "downloadCode": "mIofN681YE3f*************JkVBG2vhj4Q9、d2tn/t6XxjaB6UxxxxOVnYYbn1aMT/n3JFgb4i64X3TFxxxxGWxJPR/egKS8syvGzxxxxOO/FYLor2Q==",
        "type": "picture"
      }
    ]
  }
}
```

| Nama | Tipe | Deskripsi |
| --- | --- | --- |
| msgtype | String | Tipe pesan:   - **richText**: Teks Kaya |
| content | Object | Konten pesan. |
| richText | Array of Object | Daftar Teks Kaya.  **Catatan**  Daftar pesan dapat berisi:   - **text**: pesan text - **picture**: pesan gambar  Gunakan downloadCode gambar untuk memperoleh URL unduhan sementara dengan memanggil Server API [Mengunduh konten file dari pesan yang diterima Bot](/id/open/development/download-the-file-content-of-the-robot-receiving-message). |

| **Parameter** | **Tipe** | **Deskripsi** |

### Konten terkait

Jika Anda memilih mode HTTP sebagai mode penerimaan pesan saat [membuat Bot aplikasi internal](/id/open/dingstart/configure-the-robot-application), parameter header HTTP yang ditunjukkan di bawah disertakan bersama isi pesan saat Bot menerima pesan:

```json
{
  "Content-Type": "application/json; charset=utf-8",
  "timestamp": "1577262236757",
  "sign":"xxxxxxxxxx"
}
```

| **Parameter** | **Deskripsi** |
| --- | --- |
| timestamp | Stempel waktu saat pesan dikirim, dalam milidetik. |
| sign | Nilai tanda tangan. |

Anda harus memverifikasi timestamp dan sign di header untuk memastikan bahwa permintaan adalah permintaan sah dari DingTalk dan untuk mencegah pihak ketiga menyamar sebagai DingTalk dalam memanggil layanan HTTPS Anda. Aturan verifikasinya adalah sebagai berikut:

- Jika selisih antara timestamp dan stempel waktu sistem saat ini lebih besar dari 1 jam, permintaan dianggap tidak sah.
- Jika sign tidak cocok dengan nilai tanda tangan yang Anda hitung, permintaan dianggap tidak sah.

Sebuah permintaan dianggap sah hanya ketika timestamp dan sign berhasil melewati verifikasi.

Gunakan algoritma HmacSHA256 untuk menghitung tanda tangan, lalu enkode dengan Base64 untuk mendapatkan nilai tanda tangan akhir. Contoh:

```java
import javax.crypto.Mac;
import javax.crypto.spec.SecretKeySpec;
import org.apache.commons.codec.binary.Base64;

public class Test {
    public static void main(String[] args) throws Exception {
        Long timestamp = 1577262236757L;
        String appSecret = "this is a secret";
        String stringToSign = timestamp + "\n" + appSecret;
        Mac mac = Mac.getInstance("HmacSHA256");
        mac.init(new SecretKeySpec(appSecret.getBytes("UTF-8"), "HmacSHA256"));
        byte[] signData = mac.doFinal(stringToSign.getBytes("UTF-8"));
        String sign = new String(Base64.encodeBase64(signData));
        System.out.println(sign);
    }
}
```

| **Item konfigurasi** | **Deskripsi** |
| --- | --- |
| timestamp | Stempel waktu saat ini, dalam milidetik. |
| appSecret | Client Secret aplikasi. Untuk informasi selengkapnya, lihat [Client Secret](/id/open/dingstart/basic-concepts-beta). |
