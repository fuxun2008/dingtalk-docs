Panggil API ini untuk mengambil hasil pekerjaan terjemahan yang telah dikirim.

## Deskripsi panggilan API

### Ikhtisar API

1. Susun dokumen yang akan diterjemahkan, seperti pada contoh berikut.

### Catatan

   Hanya file .xlsx, .xls, .csv, dan .txt yang didukung.

2. Panggil API [Unggah file dalam satu langkah](https://open.dingtalk.com/document/isvapp/single-step-file-upload) untuk memperoleh `media_id`.
3. Panggil API [Terjemahkan ID Kontak secara asinkron](/id/open/development/asynchronous-address-book-file-content-translation) untuk memperoleh ID pekerjaan terjemahan.

### Catatan

   Setelah Anda memanggil API Terjemahkan ID Kontak secara asinkron, jika file berhasil diterjemahkan, notifikasi callback pekerjaan asinkron akan terpicu.
4. Panggil API ini untuk memperoleh tautan unduh file yang telah diterjemahkan.

### Catatan

   Disarankan agar tautan unduh file yang dikembalikan direferensikan menggunakan `tag <a>`. Atribut `download` tidak boleh ditentukan (karena masalah kompatibilitas browser).
5. Pengguna mengunduh file, yang isinya ditunjukkan pada contoh berikut.

| Izin | permission-qyapi_get_member-Izin baca informasi pengguna |

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| jobId | String | Ya | ID pekerjaan terjemahan asinkron. Peroleh nilai parameter `jobId` dengan memanggil API [Terjemahkan ID Kontak secara asinkron](/id/open/development/asynchronous-address-book-file-content-translation#). |
