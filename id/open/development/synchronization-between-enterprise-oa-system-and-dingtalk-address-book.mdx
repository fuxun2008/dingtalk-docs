# Sinkronkan sistem OA Anda dengan Kontak DingTalk

## Prasyarat

Selesaikan proses [Buat aplikasi](/id/open/dingstart/create-application).

## Langkah 1: Dapatkan kredensial aplikasi

1. Pilih aplikasi target dan buka halaman detail aplikasi. Klik **Basic Information** > **Credentials and Basic Information**.
2. Dapatkan Client ID dan Client Secret.

## Langkah 2: Tambahkan izin API

Klik **Development Configuration** > **Manage permissions**. Masukkan `qyapi_manage_addresslist` di kotak pencarian izin lalu ajukan permintaan izin.

## Langkah 3: Dapatkan access token aplikasi

### Penting

- Untuk perbedaan antara Server API, lihat perbandingan antara Server API lama dan Server API baru.
- Untuk mengunduh SDK Server API, lihat unduhan Server SDK.

Gunakan Client ID dan Client Secret yang diperoleh pada Langkah 1 untuk mendapatkan [access_token dari aplikasi internal](/id/open/development/obtain-orgapp-token).

```java
public void getAccessToken() throws ApiException {
        DingTalkClient client = new DefaultDingTalkClient("https://oapi.dingtalk.io/gettoken");
        OapiGettokenRequest req = new OapiGettokenRequest();
        req.setAppkey("dingxxxxxxxxxhgn");
        req.setAppsecret("9G_xxxxxxxxxxxxxxx1JDf0Qq3nexxxxxxxxGIO");
        req.setHttpMethod("GET");
        OapiGettokenResponse rsp = client.execute(req);
        System.out.println(rsp.getBody());
    }
```

## Langkah 4: Alur kerja sinkronisasi Kontak

1. Sinkronkan Kontak DingTalk ke kontak sistem OA:

   Kunci sinkronisasi ini adalah setiap perubahan pada Kontak DingTalk harus memicu tindakan terkait pada kontak sistem OA.

   1. Pertama, lihat dokumen Dapatkan semua karyawan dalam organisasi untuk mengimpor Struktur Organisasi DingTalk saat ini ke kontak sistem OA.
   2. Gunakan fitur Langganan peristiwa yang disediakan oleh DingTalk dan berlangganan peristiwa kontak. Perubahan pada Kontak DingTalk akan memicu peristiwa Callback terkait. Untuk format pesan Push peristiwa kontak, lihat Kontak.
   3. Sistem OA menerima dan memproses peristiwa kontak yang di-Push oleh DingTalk, lalu memperbarui kontak sistem OA sesuai perubahan tersebut.
2. Sinkronkan pembaruan kontak sistem OA ke Kontak DingTalk:

   Ketika informasi pada kontak sistem OA berubah, sinkronkan pembaruan tersebut ke Kontak DingTalk agar tetap konsisten.

   1. Ketika sebuah departemen dibuat pada kontak sistem OA, panggil API Buat departemen untuk membuat tingkat departemen dan nama departemen yang sama pada Sisi klien DingTalk berdasarkan tingkat dan nama departemen di sistem OA.

      ```java lines
       public void deptCreate() throws ApiException {
              DingTalkClient client = new DefaultDingTalkClient("https://api.dingtalk.io/topapi/v2/department/create");
              OapiV2DepartmentCreateRequest req = new OapiV2DepartmentCreateRequest();
              req.setParentId(1L);
              req.setOuterDept(true);
              req.setHideDept(false);
              req.setCreateDeptGroup(true);
              req.setOrder(1L);
              req.setName("Tes Departemen 1019");
              req.setSourceIdentifier("Tes Departemen 1019");
              req.setOuterPermitUsers("manager7675,01472825524039877041");
              req.setOuterDeptOnlySelf(true);
              OapiV2DepartmentCreateResponse rsp = client.execute(req, getAccessToken());
              System.out.println(rsp.getBody());
          }
      ```

### Catatan

      ID departemen di Kontak DingTalk dibuat secara otomatis dan tidak dapat diatur secara manual. Saat menyinkronkan pembaruan kontak, gunakan nama departemen sebagai identifier ketika menyinkronkan ke DingTalk, dan simpan ID departemen Kontak DingTalk terkait untuk digunakan nanti.
   2. Tambahkan peran ke kontak sistem OA berdasarkan informasi peran di sistem OA.

      1. Panggil Server API [Tambahkan grup peran](/id/open/development/add-a-role-group) untuk membuat informasi Grup peran.

         ```java lines
         public void addRoleGroup() throws ApiException {
                 DingTalkClient client = new DefaultDingTalkClient("https://oapi.dingtalk.io/role/add_role_group");
                 OapiRoleAddrolegroupRequest req = new OapiRoleAddrolegroupRequest();
                 req.setName("Tes Grup Peran 1019");
                 OapiRoleAddrolegroupResponse rsp = client.execute(req, getAccessToken());
                 System.out.println(rsp.getBody());
             }
         ```
      2. Panggil Server API Buat peran untuk membuat informasi peran bagi organisasi.

         ```java lines
           public void addRole() throws ApiException {
                 DingTalkClient client = new DefaultDingTalkClient("https://oapi.dingtalk.io/role/add_role");
                 OapiRoleAddRoleRequest req = new OapiRoleAddRoleRequest();

         ```
