Panggil API ini untuk mengkueri informasi rapat berdasarkan roomCode rapat dan parameter paginasi.

## Permintaan

### Informasi dasar

| Bidang | Nilai |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/conference/roomCodes/{roomCode}/infos` |
| Metode HTTP | GET |
| Tipe aplikasi yang didukung | appType-Aplikasi internal　appType-Aplikasi perusahaan pihak ketiga |
| Izin yang diperlukan | permission-VideoConference.Conference.Read-Izin baca untuk informasi Rapat Video |

### Header permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses yang digunakan untuk memanggil API ini. Peroleh dengan cara berikut:   - Untuk Aplikasi internal, panggil API [Memperoleh access token aplikasi internal](/id/open/development/obtain-the-access-token-of-an-internal-app#). - Untuk Aplikasi perusahaan pihak ketiga, panggil API [Memperoleh access token organisasi yang diberi otorisasi untuk aplikasi pihak ketiga](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#). |

### Parameter path

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| roomCode | String | Ya | Kode rapat. |

### Parameter kueri

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| nextToken | String | Tidak | Cursor paginasi. |
| maxResults | Integer | Tidak | Ukuran halaman. |

## Respons

### Isi respons

| Nama | Tipe | Deskripsi |
| --- | --- | --- |
| nextToken | String | Cursor paginasi. |
| hasMore | Boolean | Apakah tersedia lebih banyak hasil. |
| totalCount | Integer | Jumlah total hasil. |
| conferenceList | Array | Daftar informasi rapat. Jika kode rapat berkaitan dengan Pesan Rapat atau rapat berulang, kode rapat tersebut dapat berkaitan dengan beberapa instance rapat. |
| conferenceId | String | ID rapat. |
| title | String | Judul rapat. |
| roomCode | String | Kode rapat. |
| externalLinkUrl | String | Tautan untuk Gabung ke konferensi. |
| status | Integer | Status rapat:   - 0: Diinisialisasi - 1: Rapat berakhir - 2: Rapat dimulai |
| startTime | Long | Stempel waktu mulai rapat, dalam milidetik. |
| endTime | Long | Stempel waktu akhir rapat, dalam milidetik. Dikembalikan setelah rapat berakhir. |
| confDuration | Long | Durasi rapat, dalam milidetik. Dikembalikan setelah rapat berakhir. |
| creatorId | String | unionId pembuat rapat. |
| creatorNick | String | Nama pembuat rapat. |
| scheduleConferenceId | String | ID Pesan Rapat. |
| bizType | String | Tipe bisnis rapat:   - 0: Rapat Video instan - 3: Pesan Rapat - audio_conf: Rapat Audio |
