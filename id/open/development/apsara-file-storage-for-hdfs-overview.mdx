Topik ini menjelaskan file media, kemampuan API yang tersedia untuk file media, dan cara mengintegrasikan API file media.

## Apa itu file media

### Lokasi penyimpanan file media

Ruang penyimpanan yang digunakan fitur ini adalah area penyimpanan khusus yang disediakan DingTalk untuk organisasi. Ruang ini tidak termasuk ruang Drive organisasi. File yang diunggah melalui API fitur ini tidak mengonsumsi ruang Drive organisasi.

### Masa berlaku penyimpanan

Tidak ada batas waktu berapa lama file disimpan oleh fitur ini. Selama organisasi DingTalk tidak dibubarkan, `media_id` yang dikembalikan saat mengunggah file tetap berlaku untuk terus digunakan.

## Ikhtisar kemampuan terbuka

File media menyediakan serangkaian kemampuan API terbuka yang lengkap. Developer dapat menggunakan API ini untuk mengintegrasikan file media dengan sistem bisnis organisasi mereka.

| API | Deskripsi | Versi API |
| --- | --- | --- |
| [Mengunggah file media](/id/open/development/upload-media-files) | Unggah gambar, sumber daya media suara, dan file umum. | Legacy |
