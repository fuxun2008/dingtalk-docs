## Deskripsi panggilan API

Jika sebelumnya Anda menggunakan:

- Aplikasi internal: Memanggil API [Mendapatkan access token aplikasi internal](/id/open/development/obtain-the-access-token-of-an-internal-app#) untuk mendapatkan kredensial guna memanggil API organisasi Anda.
- Aplikasi perusahaan pihak ketiga: Memanggil API [Mendapatkan access token perusahaan yang diberi otorisasi](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#) untuk mendapatkan kredensial guna memanggil API atas nama perusahaan yang memberikan otorisasi pada aplikasi pihak ketiga.

Kedua skenario ini kini disatukan menjadi satu API. Anda tidak perlu lagi membedakan tipe aplikasi. Panggil API ini langsung untuk mendapatkan Access Token guna memanggil API yang memerlukan izin aplikasi.

## Permintaan

| **Informasi dasar** | |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/oauth2/{corpId}/token` |
| Metode HTTP | POST |
| Tipe aplikasi yang didukung | appType-Aplikasi internal, appType-Aplikasi perusahaan pihak ketiga |
| Persyaratan izin | permission-qyapi_base-Izin dasar yang diperlukan untuk memanggil API perusahaan |

### Parameter jalur

| Nama | Tipe | Wajib | Contoh | Deskripsi |
| --- | --- | --- | --- | --- |
| corpId | String | Ya | ding9f\*\*\*\*41 | ID Organisasi. Masukkan corpId organisasi tempat aplikasi berjalan:   - Aplikasi internal: Masukkan corpId organisasi Anda. - Aplikasi perusahaan pihak ketiga: Masukkan corpId perusahaan yang diberi otorisasi dan telah mengaktifkan aplikasi. |

### Isi permintaan

| Nama | Tipe | Wajib | Contoh | Deskripsi |
| --- | --- | --- | --- | --- |
| client_id | String | Ya | suite123 | ClientID aplikasi. |
| client_secret | String | Ya | \*\*\*\*\*\*\*\* | ClientSecret aplikasi. |
| grant_type | String | Ya | client_credentials | grant_type: client_credentials |

### Contoh permintaan

HTTP

```http
POST /v1.0/oauth2/ding9f****41/token HTTP/1.1
Host:api.dingtalk.io
Content-Type:application/json

{
  "client_id" : "suite123",
  "client_secret" : "********",
```

| 401 | unauthorized.client | unauthorized.client | Aplikasi tidak diberi otorisasi. |
