Panggil API ini untuk menghapus kriteria filter pada kolom tertentu di filter global, sehingga kolom tersebut tidak lagi ikut dalam perhitungan filter. API ini berlaku untuk skenario ketika Anda perlu membatalkan aturan filter satu kolom sambil mempertahankan status filter kolom lainnya. Misalnya, dalam filter multi-kolom, Anda dapat menghapus sementara batasan filter pada satu kolom untuk melihat lebih banyak data.

## Deskripsi panggilan API

Setelah panggilan API berhasil, baris yang sebelumnya disembunyikan oleh kriteria filter kolom tersebut akan ditampilkan kembali, selama baris tersebut tidak disembunyikan oleh kriteria filter kolom lain.

## Permintaan

### Informasi dasar

| Bidang | Nilai |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/doc/workbooks/{workbookId}/sheets/{sheetId}/filter/clearColumnFilterCriteria` |
| Metode HTTP | POST |
| Jenis aplikasi yang didukung | appType-Internal app |
| Izin yang diperlukan | permission-Document.Workbook.Write-DingTalk Spreadsheet write permission |

### Header permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Panggil API [Mendapatkan access token aplikasi internal](/id/open/development/obtain-the-access-token-of-an-internal-app) untuk memperolehnya. |

### Parameter path

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| workbookId | String | Ya | ID file Spreadsheet. `nodeId(dentryUuid)` yang dikembalikan oleh [API Knowledge Base](/id/open/development/knowledge-base-overview) adalah `workbookId` dari Spreadsheet. Anda dapat memperolehnya dengan memanggil API [Get node](https://open.dingtalk.com/document/orgapp/get-node) dan [Membuat dokumen Knowledge Base](/id/open/development/create-team-space-document). |
| sheetId | String | Ya | ID atau nama Lembar Kerja. Panggil API [Mendapatkan semua Lembar Kerja](/id/open/development/obtain-all-worksheets) untuk memperoleh nilai parameter id atau name. |

### Parameter query

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| operatorId | String | Ya | unionId dari operator.   - Anda dapat memanggil API [Mendapatkan informasi pengguna melalui kode login senyap](/id/open/development/obtain-the-userid-of-a-user-by-using-the-log-free) untuk memperoleh nilai parameter unionid. - Anda dapat memanggil API [Kueri detail pengguna](/id/open/development/query-user-details) untuk memperoleh nilai parameter unionid.       Jika operator tidak memiliki izin, API mengembalikan error `The operator has no permission`. |

### Isi permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| column | Long | Ya | Offset kolom relatif terhadap kolom pertama dari rentang filter, dimulai dari 0. Misalnya, jika rentang filter adalah `B1:E10`, `column=0` mewakili kolom B, dan `column=1` mewakili kolom C. |
