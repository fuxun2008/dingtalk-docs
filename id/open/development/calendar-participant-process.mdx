Dokumen ini menjelaskan cara memanggil API terkait acara untuk mengelola peserta acara. Pertama, buat aplikasi internal. Kemudian, gunakan API yang disediakan untuk acara guna membuat acara, menambah peserta acara, mengambil peserta acara, menetapkan status respons undangan, dan menghapus peserta acara.

## Hasil yang diharapkan

- Setelah acara berhasil dibuat, hasilnya tampil seperti berikut.

- Antarmuka untuk menambah peserta acara tampil seperti berikut.

- Status respons acara tampil seperti berikut.

## Ikhtisar alur integrasi

Dokumen ini menunjukkan cara membuat aplikasi internal lalu menggunakan API yang disediakan untuk acara guna mengelola peserta acara.

Prasyarat: Selesaikan alur [Pembuatan dan konfigurasi aplikasi](/id/open/dingstart/create-application).

Langkah 1: Ambil kredensial aplikasi, termasuk client ID dan Client Secret.

Langkah 2: Ajukan izin API untuk API terkait acara.

Langkah 3: Dapatkan Kredensial akses aplikasi dengan mengikuti [Mendapatkan access token aplikasi internal](/id/open/development/obtain-the-access-token-of-an-internal-app). Access token digunakan untuk mengautentikasi identitas pemanggil saat memanggil API.

Langkah 4: Panggil Server API terkait acara di sisi server.

1. Panggil Server API [Acara Baru](/id/open/development/create-schedule) untuk membuat acara dan mengambil `id` acara.
2. Berdasarkan `id` acara, panggil Server API [Tambah peserta acara](/id/open/development/add-schedule-participant) untuk menambah peserta acara.
3. Berdasarkan `id` acara, panggil Server API [Dapatkan peserta acara](/id/open/development/get-the-participants-of-a-schedule) untuk mengambil informasi peserta.
4. Berdasarkan `id` acara, panggil Server API [Tetapkan status respons undangan acara](/id/open/development/configure-response-status) untuk menetapkan status respons undangan peserta.
5. Berdasarkan `id` acara, panggil Server API [Hapus peserta acara](/id/open/development/delete-schedule-participant) untuk menghapus peserta acara.

## Prasyarat

Selesaikan alur [Pembuatan dan konfigurasi aplikasi](/id/open/dingstart/create-application).

## Langkah 1: Ambil kredensial aplikasi

1. Pilih aplikasi target untuk membuka halaman detailnya, lalu klik **Informasi dasar** > **Kredensial dan informasi dasar**.
2. Ambil client ID dan Client Secret.

## Langkah 2: Tambah izin API

Klik **Konfigurasi pengembangan** > **Kelola izin**. Pada kotak pencarian izin, masukkan `Calendar.Event.Write` dan `Calendar.Event.Read` masing-masing, lalu ajukan setiap izin.

## Langkah 3: Dapatkan access token

<Warning>
Untuk perbedaan antar-Server API, lihat API lama vs. API baru. API berikut semuanya menggunakan Server API. Untuk unduhan SDK, lihat unduhan SDK sisi server.
</Warning>

Gunakan client ID dan Client Secret dari Langkah 1 untuk mendapatkan access_token aplikasi internal.

```java
 public void getAccessToken() throws Exception {
        Config config = new Config();
        config.protocol = "https";
        config.regionId = "central";
        com.aliyun.dingtalkoauth2_1_0.Client client = new com.aliyun.dingtalkoauth2_1_0.Client(config);
        GetAccessTokenRequest accessTokenRequest = new GetAccessTokenRequest()
                .setAppKey("ding*********hgn")
                .setAppSecret("9G_O**********xamBkhgGIO");
        GetAccessTokenResponse accessToken = client.getAccessToken(accessTokenRequest);
        System.out.println(JSON.toJSONString(accessToken.getBody()));
    }
```
