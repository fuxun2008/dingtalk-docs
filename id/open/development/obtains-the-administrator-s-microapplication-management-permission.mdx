Panggil API ini untuk mendapatkan izin pengelolaan aplikasi seorang admin.

## Deskripsi panggilan API

Sebelum memanggil API ini, pastikan bahwa:

- Aplikasi dikembangkan oleh penyedia solusi produk. Dapatkan AppId di halaman detail aplikasi pada [**DingTalk Developer Backend**](https://open-dev.dingtalk.io/#/appMgr/provider/eapp/53642/1) **> Aplikasi perusahaan pihak ketiga**.
- Sebelum memanggil API ini, Anda dapat memanggil API [Kueri daftar admin](/id/open/development/query-the-administrator-list) untuk mendapatkan ID admin dari organisasi saat ini.

## Permintaan

| **Informasi dasar** | |
| --- | --- |
| URL HTTP | https://oapi.dingtalk.io/user/can_access_microapp |
| Metode HTTP | GET |
| Jenis aplikasi yang didukung | appType-Aplikasi perusahaan pihak ketiga |
| Persyaratan izin | permission-qyapi_get_member-Izin baca untuk informasi pengguna |

### Parameter kueri

| Nama | Tipe | Wajib | Contoh | Deskripsi |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | 6d1bxxxx | Kredensial aplikasi untuk memanggil API ini. Diperoleh melalui API untuk mendapatkan access_token dari perusahaan pihak ketiga. |
| appId | Number | Ya | 2000121xxxx | ID aplikasi. Dapatkan AppID di halaman detail aplikasi pada [**DingTalk Developer Backend**](https://open-dev.dingtalk.io/#/appMgr/provider/eapp/53642/1) **> Aplikasi perusahaan pihak ketiga**. |
| userId | String | Ya | 2000121xxxx | ID pengguna dari admin yang akan dikueri. Panggil API [Kueri daftar admin](/id/open/development/query-the-administrator-list) untuk mendapatkan nilai parameter userid. |

### Contoh permintaan

```curl
curl -X GET "https://oapi.dingtalk.io/user/can_access_microapp" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=c54ee841-199a-459e-8146-3d08c1830a10' \
-d 'appId=1' \
-d 'userId=1'
```

Java

```text
DingTalkClient client = new DefaultDingTalkClient("https://oapi.dingtalk.io/user/can_access_microapp");
OapiUserCanAccessMicroappRequest req = new OapiUserCanAccessMicroappRequest();
req.setAppId(1L);
req.setUserId("1");
req.setHttpMethod("GET");
OapiUserCanAccessMicroappResponse rsp = client.execute(req, access_token);
System.out.println(rsp.getBody());
```

## Respons

### Isi respons

| Nama | Tipe | Contoh | Deskripsi |
| --- | --- | --- | --- |
| request_id | String | 4f9md9obopn2 | ID permintaan. |
| errcode | Number | 0 | Kode pengembalian. |
| errmsg | String | system error | Deskripsi kode pengembalian. |
| canAccess | Boolean | true | Apakah pengguna memiliki izin pengelolaan:   - **true**: memiliki izin pengelolaan. - **false**: tidak memiliki izin pengelolaan. |

### Contoh isi respons

```json
{
  "errcode":0,
  "canAccess":"true",
  "request_id":"4f9md9obopn2"
}
```

### Kode error

Jika error dikembalikan saat memanggil API ini, temukan solusinya di dokumen [Kode error global](/id/open/development/server-api-error-codes-1) berdasarkan pesan error.
