Panggil API ini untuk mengkueri informasi penjadwalan shift pengguna pada hari tertentu.

## Permintaan

| **Informasi dasar** | |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/topapi/attendance/schedule/listbyday |
| Metode HTTP | POST |
| Tipe aplikasi yang didukung | appType-Aplikasi internal　appType-Aplikasi perusahaan pihak ketiga |
| Izin | qyapi_attendance_group_read (izin baca grup absensi) |

### Parameter kueri

| Nama | Tipe | Wajib | Contoh | Deskripsi |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | bE74xxxx | Kredensial aplikasi yang digunakan untuk memanggil API ini.   - Aplikasi internal: Dapatkan dengan memanggil [Mendapatkan access_token Aplikasi internal](/id/open/development/obtain-orgapp-token). - Aplikasi perusahaan pihak ketiga: Dapatkan dengan memanggil Mendapatkan access_token Aplikasi perusahaan pihak ketiga. |

### Isi permintaan

| Nama | Tipe | Wajib | Contoh | Deskripsi |
| --- | --- | --- | --- | --- |
| op_user_id | String | Ya | manager123 | userId operator. |
| user_id | String | Ya | dd_dd | userId pengguna yang akan dikueri. |
| date_time | Number | Ya | 1564145519000 | Tanggal yang akan dikueri, dalam format Unix timestamp milidetik. |

### Contoh permintaan

```curl
curl -X POST "https://api.dingtalk.io/topapi/attendance/schedule/listbyday" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=5d7f91f3-e22c-41ca-aee3-aa008603e00b' \
-d 'date_time=1564145519000' \
-d 'op_user_id=dd_dd' \
-d 'user_id=dd_dd'
```

Java

```java

```

## Respons

### Isi respons

| Nama | Tipe | Contoh | Deskripsi |
| --- | --- | --- | --- |
| result | TopScheduleVo[] |  | Hasil kueri. |
| check_type | String | OnDuty | Tipe absensi:   - **Onduty**: Absen masuk kerja - **OffDuty**: Absen pulang kerja |
| approve_type | String | demo | Tipe persetujuan.  **Catatan**  Bidang ini tidak dikembalikan jika tidak ada formulir persetujuan pada hari tersebut. |
| gmt_modified | Date | 2020-11-10 14:33:13 | Waktu modifikasi terakhir. |
| gmt_create | Date | 2020-10-26 03:26:59 | Waktu pembuatan. |
| corp_id | String | dinge8xxxx | ID organisasi (corpId). Lihat di halaman Beranda [Developer Console](https://open-dev.dingtalk.io/). |
| check_date_time | Date | 2020-11-10 14:33:13 | Waktu absen karyawan. |
| group_id | Number | 394775001 | ID grup absensi. |
| class_name | String | dsdsd | Nama shift. |
| user_id | String | dd_test | userId pengguna. |
| approve_biz_type | Number | demo | Tipe persetujuan cuti dan absensi yang terikat pada penjadwalan shift:   - **1**: Lembur - **2**: Perjalanan dinas - **3**: Cuti   **Catatan**  Bidang ini tidak dikembalikan jika tidak ada formulir persetujuan pada hari tersebut. |
| approve_id | Number | 123 | ID formulir persetujuan yang terikat pada penjadwalan shift.  **Catatan**  Bidang ini tidak dikembalikan jika tidak ada formulir persetujuan pada hari tersebut. |
| class_setting_id | Number | 297490031 | ID pengaturan shift yang terkait dengan penjadwalan shift.  **Catatan**  Bidang ini tidak dikembalikan jika menggunakan pengaturan global. |
| approve_tag_name | String | Cuti | Nama formulir persetujuan cuti dan absensi yang terikat pada penjadwalan shift.  **Catatan**  Bidang ini tidak dikembalikan jika tidak ada formulir persetujuan pada hari tersebut. |
| features | String | `{\"dataSource\":\"adminSetting\",\"flexMinutes\":[60,60],\"overtimeSettingId\":221375127,\"punchId\":524588947}` | Bidang tambahan.   - **dataSource**: Bidang ini saat ini tidak memiliki makna praktis. - **flexMinutes**: Waktu fleksibel yang diizinkan oleh pengaturan shift untuk datang terlambat dan pulang terlambat, atau datang lebih awal dan pulang lebih awal, dalam satuan menit. - **punchId**: ID titik absen yang terkait. - **overtimeSettingId**: ID aturan lembur. |
| class_id | Number | 370370019 | ID shift. |
| check_status | String | Timeout | Status absen:   - **Init**: Belum absen - **Checked**: Sudah absen - **Timeout**: Absen terlewat |
| work_date | Date | 2020-11-10 00:00:00 | Hari kerja, menunjukkan hari spesifik penjadwalan shift. |
| check_end_time | Date | 2020-09-08 09:30:00 | Waktu berakhir rentang absen. |
| is_rest | String | N | Apakah hari tersebut merupakan hari libur:   - **Y**: Dijadwalkan sebagai hari libur - **N**: Bukan hari libur |
| check_begin_time | Date | 2020-09-08 09:00:00 | Waktu mulai rentang absen. |
| real_plan_time | Date | 2020-09-08 10:00:00 | Waktu pengguna seharusnya absen setelah penyesuaian jam kerja fleksibel diaktifkan untuk titik absen. |
| id | Number | 56676915454 | ID penjadwalan shift. |
| success | Boolean | true | Menunjukkan apakah permintaan berhasil.   - **true**: Berhasil - **false**: Gagal |
| errcode | Number | 0 | Kode pengembalian. |
| errmsg | String | demo | Deskripsi kode pengembalian. |
| request_id | String | 6bzhf2vn89pv | ID permintaan. |
