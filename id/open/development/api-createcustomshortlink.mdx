title: "Membuat tautan pendek khusus pengguna"
description: "Panggil API ini untuk membuat tautan pendek khusus pengguna dari informasi pengguna di DingTalk; setelah pengguna bergabung ke rapat melalui tautan tersebut, jsapi sisi klien dapat mengambil informasi kustom aplikasi ekstensi pengguna."
---

Buat tautan pendek khusus pengguna berdasarkan informasi pengguna. Setelah seorang pengguna bergabung ke konferensi melalui tautan pendek khusus pengguna, pengguna dapat mengueri informasi bisnis kustom dari aplikasi ekstensi melalui JSAPI sisi klien.

## Permintaan

### Informasi dasar

| Bidang | Nilai |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/v1.0/conference/customShortLinks |
| Metode HTTP | POST |
| Tipe aplikasi yang didukung | appType-Aplikasi internalappType-Aplikasi perusahaan pihak ketiga |
| Izin yang diperlukan | permission-VideoConference.Conference.Write-Izin pengelolaan informasi Rapat Video |

### Header permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses yang digunakan untuk memanggil API ini. Dapatkan dengan cara berikut:   - Untuk aplikasi internal, panggil API [Mendapatkan access token aplikasi internal](/id/open/development/obtain-the-access-token-of-an-internal-app#). - Untuk aplikasi perusahaan pihak ketiga, panggil API [Mendapatkan access token organisasi yang diberi otorisasi ke aplikasi pihak ketiga](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#). |

### Isi permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| creatorUnionId | String | Ya | unionId dari pengguna yang membuat rapat terjadwal. |
| scheduleConferenceId | String | Ya | ID rapat terjadwal. Dapatkan parameter keluaran `scheduleConferenceId` dengan memanggil API [Membuat rapat terjadwal](/id/open/development/create-appointment-meeting#). |
| coolAppCode | String | Ya | Kode CoolApp. Lihat kode CoolApp di bagian Aplikasi mikro pada konsol developer. |
| extensionAppBizData | String | Tidak | Informasi kustom tingkat pengguna dari aplikasi ekstensi. |
| useExtensionApp | Boolean | Tidak | Menentukan apakah akan menggunakan aplikasi ekstensi:   - true: Ya - false: Tidak |
