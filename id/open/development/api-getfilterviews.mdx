---
title: "Mendapatkan daftar tampilan filter"
description: "Panggil API ini untuk mengambil semua tampilan filter pada Lembar Kerja tertentu, mengembalikan ID, nama, rentang, dan kondisi filter setiap tampilan — cocok untuk enumerasi atau pembacaan massal konfigurasi tampilan."
---

Panggil API ini untuk mengambil daftar semua tampilan filter pada Lembar Kerja tertentu. Respons mengembalikan ID, nama, rentang, dan kondisi filter dari setiap tampilan filter. Gunakan API ini untuk melakukan enumerasi tampilan yang ada sebelum mengelola atau mengganti tampilan filter, atau untuk membaca konfigurasi tampilan filter secara massal guna diproses lebih lanjut dalam program Anda.

## Permintaan

### Informasi dasar

| Bidang | Nilai |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/doc/workbooks/{workbookId}/sheets/{sheetId}/filterViews` |
| Metode HTTP | GET |
| Jenis aplikasi yang didukung | appType-Aplikasi internal |
| Izin yang diperlukan | permission-Document.Workbook.Read-Izin baca Spreadsheet |

### Header permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses yang digunakan untuk memanggil API ini. Panggil API [Mendapatkan access token aplikasi internal](/id/open/development/obtain-the-access-token-of-an-internal-app) untuk memperolehnya. |

### Parameter path

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| workbookId | String | Ya | ID file Spreadsheet. `nodeId(dentryUuid)` yang dikembalikan oleh [Knowledge Base API](/id/open/development/knowledge-base-overview) adalah `workbookId` dari Spreadsheet. Perolehlah dengan memanggil API [Mendapatkan node](https://open.dingtalk.com/document/orgapp/get-node) atau [Membuat dokumen Knowledge Base](/id/open/development/create-team-space-document). |
| sheetId | String | Ya | ID atau nama Lembar Kerja. Panggil API [Mendapatkan semua lembar kerja](/id/open/development/obtain-all-worksheets) untuk memperoleh nilai parameter id atau name.  **Catatan**  Jika Lembar Kerja tidak memiliki tampilan filter, API mengembalikan array kosong. |

### Parameter query

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| operatorId | String | Ya | unionId dari operator.   - Panggil API [Mendapatkan informasi pengguna melalui kode login senyap](/id/open/development/obtain-the-userid-of-a-user-by-using-the-log-free) untuk memperoleh unionId. - Panggil API [Kueri detail pengguna](/id/open/development/query-user-details) untuk memperoleh unionId.       Jika operator tidak memiliki izin, API mengembalikan error `The operator has no permission`. |

## Respons

### Isi respons

| Nama | Tipe | Deskripsi |
| --- | --- | --- |
| filterViews | Array | Daftar tampilan filter. Mengembalikan array kosong jika tidak ada tampilan filter. |
| id | String | Identifier unik dari tampilan filter. |
| name | String | Nama tampilan filter. |
| range | String | Rentang tampilan filter dalam notasi A1. |
| criteria | `Map<String, Object>` | Kondisi filter untuk setiap kolom. Key adalah offset kolom (relatif terhadap bidang utama rentang, dimulai dari 0), dan value adalah object kondisi filter. Mengembalikan object kosong `{}` jika tidak ada kondisi filter. |
|  | Object | Kondisi filter. |
| filterType | String | Tipe filter. Nilai yang valid: `values` (filter berdasarkan nilai), `condition` (filter berdasarkan kondisi), `color` (filter berdasarkan warna). |
| visibleValues | Array of String | Nilai yang terlihat. |
| conditions | Array | Daftar kondisi filter ketika memfilter berdasarkan kondisi. Berlaku ketika `filterType` bernilai `condition`. Setiap object kondisi berisi bidang `operator` dan `value`. |
| operator | String | Operator kondisi. Nilai yang valid:   - **equal** - **not-equal** - **contains** - **not-contains** - **starts-with** - **not-starts-with** - **ends-with** - **not-ends-with** - **greater** - **greater-equal** - **less** - **less-equal** |
| value | String | Nilai kondisi. |
| conditionOperator | String | Hubungan logis antara beberapa kondisi. Nilai yang valid: `and`, `or`. Nilai default: `and`. Berlaku ketika `filterType` bernilai `condition` dan beberapa kondisi ditetapkan. |
| backgroundColor | String | Nilai warna (heksadesimal, seperti `#FF0000`) ketika memfilter berdasarkan warna latar belakang. Berlaku ketika `filterType` bernilai `color`. Saling eksklusif dengan `fontColor`. |
| fontColor | String | Nilai warna (heksadesimal, seperti `#FF0000`) ketika memfilter berdasarkan warna font. Berlaku ketika `filterType` bernilai `color`. Saling eksklusif dengan `backgroundColor`. |
