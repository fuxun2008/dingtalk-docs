Panggil API ini untuk membuat aturan cuti.

## Deskripsi panggilan API

API ini dapat membuat dua jenis aturan cuti:

- Aturan cuti umum, misalnya cuti pribadi dan cuti menikah. Saldo aturan ini dapat diubah. Setelah Anda membuat aturan cuti umum dengan API ini, saldonya default bernilai 0. Panggil API [Inisialisasi saldo cuti](/id/open/development/initialize-holiday-balance) untuk menginisialisasi saldo cuti.
- Aturan cuti pengganti. Untuk cuti pengganti yang ditambahkan melalui API ini, aturan saldo default-nya adalah **Durasi lembur otomatis dihitung ke saldo cuti pengganti**. Anda tidak perlu memanggil API inisialisasi saldo.

Pengaturan yang setara di DingTalk Admin Console terdapat di **Manajemen Cuti** > **Aturan Cuti**. Klik **Tambah Cuti** untuk membuka dialog **Cuti Baru** yang berisi bidang berikut:

| Bidang | Deskripsi / Opsi |
|---|---|
| **Nama Cuti** | Masukkan nama cuti |
| **Cuti Karyawan Baru** | Misalnya **Dapat mengambil cuti sejak mulai bekerja** |
| **Cakupan Penerapan** | Misalnya **Seluruh Perusahaan** (dapat diedit) |
| **Berbayar** | **Berbayar** atau **Tidak Berbayar**; cuti berbayar dihitung sebagai kehadiran dalam statistik |
| **Unit Cuti Minimum** | Misalnya **Per Hari** |
| **Perhitungan Durasi Cuti** | Misalnya **Hitung berdasarkan Hari Kerja** (tidak termasuk hari libur karyawan, seperti akhir pekan yang tidak dijadwalkan dan hari libur nasional) |

Bagian **Aturan Perhitungan Durasi Cuti** mengelompokkan pengaturan **Unit Cuti Minimum** dan **Perhitungan Durasi Cuti**. Klik **Simpan** untuk membuat aturan.

## Permintaan

### Informasi dasar

| Bidang | Nilai |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/v1.0/attendance/leaves/types |
| Metode HTTP | POST |
| Jenis aplikasi yang didukung | appType-Aplikasi internal　appType-Aplikasi perusahaan pihak ketiga |
| Izin yang diperlukan | permission-qyapi_holiday_manage-Izin manajemen cuti DingTalk |

### Header permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Cara memperolehnya:   - Aplikasi internal: panggil API [Mendapatkan access token Aplikasi internal](/id/open/development/obtain-the-access-token-of-an-internal-app). - Aplikasi perusahaan pihak ketiga: panggil API untuk mendapatkan access token organisasi yang telah memberikan otorisasi kepada Aplikasi pihak ketiga. |

### Parameter query

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| opUserId | String | Ya | userId admin. Admin ini juga harus memiliki izin pengelolaan untuk aplikasi Persetujuan OA.  Jika kondisi ini tidak terpenuhi, API akan mengembalikan error yang menyatakan bahwa admin departemen tidak ada. |

### Isi permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| leaveName | String | Ya | Nama aturan cuti. |
| leaveViewUnit | String | Ya | Unit durasi cuti.   - **day**: Hari - **halfDay**: Setengah hari - **hour**: Jam |
| bizType | String | Ya | Jenis cuti.   - **general_leave**: Cuti umum - **lieu_leave**: Cuti pengganti lembur   Satu organisasi hanya dapat memiliki satu aturan cuti pengganti lembur. |
| naturalDayLeave | Boolean | Ya | Menentukan apakah durasi cuti dihitung berdasarkan hari kalender.   - **true**: Ya - **false**: Tidak   Contoh: karyawan Budi mengirimkan formulir persetujuan pengajuan cuti dengan waktu mulai 11 April 2022 pukul 09.30 dan waktu selesai 18 April 2022 pukul 18.30. Tanggal 16 dan 17 April adalah akhir pekan (hari libur).   - Jika parameter ini bernilai true, pengajuan cuti dihitung 8 hari. Perhitungan ini mencakup hari libur karyawan yang tidak dijadwalkan dan hari libur nasional. - Jika parameter ini bernilai false, pengajuan cuti dihitung 6 hari. Perhitungan ini tidak mencakup hari libur karyawan yang tidak dijadwalkan dan hari libur nasional. |
| hoursInPerDay | Long | Ya | Jumlah jam kerja per hari yang digunakan untuk konversi. Nilai sebenarnya adalah nilai parameter dibagi 100.  Contoh: jika shift karyawan memiliki 8 jam kerja, atur parameter ini ke 8\*100=800. |
| extras | String | Tidak | Aturan masa berlaku cuti pengganti.   - **validity_type**: Jenis masa berlaku    - **absolute_time**: Waktu absolut   - **relative_time**: Waktu relatif - **validity_value**: Tanggal perpanjangan    - Jika validity_type adalah **absolute_time**, nilai ini tidak boleh kosong dan harus menggunakan format "yy-mm".   - Jika validity_type adalah **relative_time**, nilai ini harus berupa bilangan bulat yang lebih besar dari 1.   Parameter ini wajib diisi jika jenis cuti biz_type adalah **lieu_leave**. |
| paidLeave | Boolean | Tidak | Menentukan apakah cuti ini berbayar. |

| visibilityRules | Array | Tidak | Daftar aturan cakupan penerapan. Jika tidak ditentukan, aturan berlaku untuk seluruh perusahaan. |
| visible | Array of String | Tidak | Daftar data dalam cakupan penerapan.   - Jika type=staff, kirimkan daftar userId karyawan. - Jika type=dept, kirimkan daftar ID departemen. - Jika type=label, kirimkan daftar ID peran. |
| type | String | Tidak | Jenis aturan cakupan penerapan.   - **dept**: Departemen - **staff**: Karyawan - **label**: Peran |
| whenCanLeave | String | Tidak | Waktu cuti dapat diambil.  Bidang ini khusus untuk Aplikasi perusahaan pihak ketiga.   - **entry**: Dapat diambil sejak mulai bekerja. - **formal**: Dapat diambil setelah masa percobaan berakhir. |
| leaveTimeCeilMinUnit | String | Tidak | Unit minimum yang digunakan saat membulatkan durasi cuti ke atas.  Bidang ini khusus untuk Aplikasi perusahaan pihak ketiga.   - **hour**: Jam. Durasi kurang dari 1 jam dihitung sebagai 1 jam. - **halfHour**: Setengah jam. Durasi kurang dari setengah jam dihitung sebagai setengah jam. |
| leaveTimeCeil | Boolean | Tidak | Menentukan apakah durasi cuti dibulatkan ke atas.  Bidang ini khusus untuk Aplikasi perusahaan pihak ketiga. |
| minLeaveHour | double | Tidak | Durasi cuti minimum (berlaku jika unit cuti adalah jam). Jika durasi cuti kurang dari nilai ini, nilai ini yang digunakan.  Bidang ini khusus untuk Aplikasi perusahaan pihak ketiga. |
| submitTimeRule | Object | Tidak | Aturan batas waktu pengiriman. |
| timeValue | Long | Tidak | Nilai batas.   - Jika timeUnit adalah day, rentang yang valid adalah 0 hingga 30 hari. - Jika timeUnit adalah hour, rentang yang valid adalah 0 hingga 24 jam. |
| timeUnit | String | Tidak | Unit waktu.   - **day**: Hari - **hour**: Jam |
| timeType | String | Tidak | Jenis batas.   - **before**: Kirim lebih awal - **after**: Kirim susulan |
| enableTimeLimit | Boolean | Tidak | Menentukan apakah batas waktu pengiriman diaktifkan.   - **true**: Aktif - **false**: Nonaktif |
| leaveCertificate | Object | Tidak | Surat keterangan cuti. |
| unit | String | Tidak | Unit durasi untuk mewajibkan surat keterangan cuti.   - **hour**: Jam - **day**: Hari |
| duration | double | Tidak | Durasi cuti yang, jika dilampaui, mewajibkan surat keterangan cuti.   - Jika unit adalah day, surat keterangan cuti diwajibkan untuk cuti lebih dari satu hari. - Jika unit adalah hour, surat keterangan cuti diwajibkan untuk cuti lebih dari satu jam. | maxLeaveTime | Long | Tidak | Durasi cuti maksimum (berlaku jika unit cuti adalah jam atau hari).  Bidang ini khusus untuk Aplikasi perusahaan pihak ketiga. |
| leaveHourCeil | String | Tidak | Cara pembulatan durasi cuti:  Bidang ini khusus untuk Aplikasi perusahaan pihak ketiga.   - **up**: Bulatkan ke atas - **down**: Bulatkan ke bawah - **none**: Tanpa pembulatan |
| freedomLeave | Boolean | Tidak | Jenis cuti yang tidak memerlukan kontrol saldo (misalnya cuti pribadi).  Bidang ini khusus untuk Aplikasi perusahaan pihak ketiga. |
