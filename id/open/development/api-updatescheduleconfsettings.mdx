Panggil API ini untuk memperbarui pengaturan rapat terjadwal.

## Permintaan

### Informasi dasar

| Bidang | Nilai |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/v1.0/conference/scheduleConferences/settings |
| Metode HTTP | PUT |
| Jenis aplikasi yang didukung | appType-Internal app　appType-Third-party enterprise app |
| Izin yang diperlukan | permission-VideoConference.Conference.Write-Video Meeting information management permission |

### Header permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini:   - Untuk aplikasi internal, panggil API [Dapatkan access token aplikasi internal](/id/open/development/obtain-the-access-token-of-an-internal-app) untuk memperolehnya. - Untuk aplikasi perusahaan pihak ketiga, panggil API [Dapatkan access token organisasi terotorisasi untuk aplikasi pihak ketiga](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1) untuk memperolehnya. |

### Isi permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| creatorUnionId | String | Ya | unionId pembuat rapat terjadwal. |
| scheduleConferenceId | String | Ya | ID rapat terjadwal. |
| scheduleConfSettingModel | Object | Tidak | Pengaturan rapat terjadwal. |
| hostUnionId | String | Tidak | unionId tuan rumah. |
| confAllowedCorpId | String | Tidak | ID organisasi untuk rapat internal. |
| lockRoom | Integer | Tidak | Kunci rapat:   - **0**: Buka kunci - **1**: Kunci |
| screenShareForbidden | Integer | Tidak | Berbagi layar:   - **0**: Izinkan berbagi - **1**: Larang berbagi |
| muteOnJoin | Integer | Tidak | Bisukan pengguna saat bergabung:   - **-1**: Aktif - **0**: Nonaktif - **6**: Bisukan otomatis saat lebih dari 6 pengguna bergabung |
| moziConfVirtualExtraSetting | Object | Tidak | Pengaturan rapat terjadwal. |
| waitingRoom | Integer | Tidak | Ruang tunggu:   - **0**: Nonaktif - **1**: Aktif |
| joinBeforeHost | Integer | Tidak | Gabung rapat sebelum tuan rumah:   - **0**: Nonaktif - **1**: Aktif |
| enableChat | Integer | Tidak | Obrolan dan interaksi:   - **0**: Nonaktif - **1**: Aktif |
| lockNick | Integer | Tidak | Izinkan pengguna mengganti nama sendiri:   - **0**: Izinkan ganti nama sendiri - **1**: Larang ganti nama sendiri |
| lockMediaStatusMicMute | Integer | Tidak | Izinkan pengguna membunyikan suara sendiri:   - **0**: Izinkan bunyikan suara sendiri - **1**: Larang bunyikan suara sendiri |
| moziConfExtensionAppSettings | Array | Tidak | Daftar pengaturan aplikasi ekstensi rapat. |
| coolAppCode | String | Tidak | appCode cool app. |
| autoOpenMode | Integer | Tidak | Mode buka otomatis:   - **0**: Jangan buka otomatis - **1**: Buka otomatis hanya untuk tuan rumah dan wakil tuan rumah - **2**: Buka otomatis untuk semua pengguna |
| extensionAppBizData | String | Tidak | Informasi kustom aplikasi ekstensi cakupan rapat. |
| enableWebAnonymousJoin | Boolean | Tidak | Apakah mengizinkan login senyap dari klien web untuk bergabung ke rapat:   - **true**: Izinkan - **false**: Larang |
| pushAllMeetingRecords | Boolean | Tidak | Apakah mem-push semua rekaman rapat:   - **true**: Push semua rekaman - **false**: Push hanya rekaman yang waktu rapat sebenarnya berada dalam rentang waktu terencana rapat terjadwal.   Di luar rentang waktu terencana rapat terjadwal didefinisikan sebagai: waktu mulai rapat > waktu berakhir terencana rapat terjadwal, atau waktu berakhir rapat > waktu mulai terencana rapat terjadwal. |
| pushMinutesCard | Boolean | Tidak | Apakah mem-push kartu Notulen:   - **true**: Push - **false**: Jangan push. Di-push secara default. |
| pushCloudRecordCard | Boolean | Tidak | Apakah mem-push kartu Notulen rekaman cloud:   - **true**: Push - **false**: Jangan push. Di-push secara default. |
| minutesOwnerUnionId | String | Tidak | Pemilik Notulen. Secara default, pemiliknya adalah penyelenggara rapat terjadwal. |
| cloudRecordOwnerUnionId | String | Tidak | Pemilik rekaman cloud. Secara default, pemiliknya adalah penyelenggara rapat terjadwal. |
| minutesSummaryTemplateType | String | Tidak | Templat yang ditentukan untuk ringkasan rekaman cloud:   - **0**: Templat resmi - **1**: Templat kustom |
| minutesSummaryTemplateId | String | Tidak | - Jika `minutesSummaryTemplateType = 0`, masukkan ID templat resmi yang sesuai. - Jika `minutesSummaryTemplateType = 1`, masukkan ID templat kustom yang sesuai. |
| minutesSummaryDiyTemplateVersion | String | Tidak | - Jika `minutesSummaryTemplateType = 0`, tidak diperlukan nilai. - Jika `minutesSummaryTemplateType = 1`, masukkan nomor versi templat kustom yang sesuai. |
| hiddenOwnerNick | Boolean | Tidak | Apakah menyembunyikan nama pemrakarsa rekaman cloud. |
| cohostUnionIds | Array of String | Tidak | unionId para wakil tuan rumah. |
| moziConfOpenRecordSetting | Object | Tidak | Pengaturan perekaman otomatis. |
| recordAutoStart | Integer | Tidak | Apakah memulai rekaman cloud secara otomatis:   - **0**: Jangan mulai otomatis - **1**: Mulai otomatis |
| recordAutoStartType | Integer | Tidak | Tipe mulai otomatis untuk rekaman cloud:   - **0**: Mulai otomatis saat saya bergabung sebagai tuan rumah - **1**: Mulai otomatis saat orang lain bergabung sebagai wakil tuan rumah - **2**: Mulai otomatis saat siapa pun bergabung dalam peran apa pun |
| mode | String | Tidak | Tata letak perekaman rapat:   - **grid**: Mode kisi, 9-kisi (3x3) secara default - **speech**: Mode pembicara - **full_screen**: Mode layar penuh - **auto_grid**: Mode kisi otomatis, hingga 4x4 kisi secara default - **screen_cast**: Mode berbagi layar, hanya menampilkan aliran berbagi layar - **p2p**: Mode panggilan dua orang - **full_screen_and_speaker**: Konten bersama + mode pembicara |
| isFollowHost | Boolean | Tidak | Apakah mengikuti tuan rumah:   - **true**: Ikuti - **false**: Jangan ikuti |
| restrictShareMinutesSummaryOnly | Integer | Tidak | Apakah membatasi berbagi Notulen hanya pada ringkasan:   - **0**: Tanpa batasan - **1**: Dibatasi |
| aiAgentSummarySetting | Object | Tidak | Pengaturan AI Minutes rapat. |
| value | String | Tidak | Apakah mengaktifkan ringkasan Asisten AI:   - **disable**: Nonaktif - **enable**: Aktif |
| receiverType | Integer | Tidak | Cakupan penerima untuk push Notulen setelah rapat:   - **0**: Semua anggota rapat - **1**: Hanya pembuat |
| allowAllParticipantsStart | Integer | Tidak | Apakah mengizinkan semua anggota rapat untuk memulai:   - **0**: Larang - **1**: Izinkan |
| restrictShareMinutesSummaryOnly | Integer | Tidak | Apakah membatasi berbagi Notulen hanya pada ringkasan:   - **0**: Tanpa batasan - **1**: Dibatasi |
| enableAiAgentStatus | Boolean | Tidak | Apakah menampilkan fitur AI Minutes:   - **true**: Tampilkan - **false**: Sembunyikan (berlaku pada DingTalk Android versi 8.3.20 atau lebih baru; berlaku pada iOS, PC, dan klien lainnya) |
