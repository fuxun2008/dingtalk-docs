Panggil API ini untuk mendapatkan detail item tertentu di Tempat Sampah, termasuk ID Ruang tempat item tersebut awalnya berada, path aslinya, ukuran, nama, dan informasi lainnya.

## Permintaan

### Informasi dasar

| Bidang | Nilai |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/storage/recycleBins/{recycleBinId}/recycleItems/{recycleItemId}` |
| Metode HTTP | GET |
| Tipe aplikasi yang didukung | appType-Internal app　appType-Third-party enterprise app |
| Persyaratan izin | permission-Storage.RecycleBin.Read-Izin baca untuk Tempat Sampah penyimpanan Organisasi |

### Header permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Dapatkan sebagai berikut:   - Untuk Aplikasi internal, panggil API [Mendapatkan access token aplikasi internal](/id/open/development/obtain-the-access-token-of-an-internal-app#). - Untuk Aplikasi perusahaan pihak ketiga, panggil API [Mendapatkan access token organisasi yang mengotorisasi aplikasi pihak ketiga](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#). |

### Parameter path

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| recycleBinId | String | Ya | ID Tempat Sampah. Panggil API [Mendapatkan informasi tentang Tempat Sampah](/id/open/development/obtain-information-about-the-recycle-bin#) untuk mendapatkannya. |
| recycleItemId | String | Ya | ID item sampah. Panggil API [Mendapatkan daftar item sampah](/id/open/development/gets-the-list-of-recycle-items#) untuk mendapatkan nilai parameter `id`. |

### Parameter query

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| unionId | String | Ya | unionId operator. Panggil API [Kueri detail pengguna](/id/open/development/query-user-details#) untuk mendapatkannya. |

### Contoh permintaan

Host:api.dingtalk.io

## Respons

### Isi respons

| Nama | Tipe | Deskripsi |
| --- | --- | --- |
| item | Object | Informasi item sampah. |
| id | String | ID item sampah. |
| spaceId | String | ID Ruang tempat File atau Folder asli berada. |
| dentryId | String | ID File atau Folder asli. |
| size | Long | Ukuran File atau Folder asli, dalam byte. |
| type | String | Tipenya.   - **FILE**: File - **FOLDER**: Folder |
| originalName | String | Nama File atau Folder asli. |
| originalPath | String | Path File atau Folder asli. |
| operatorId | String | unionId pengguna yang melakukan tindakan hapus. |
| operatorTime | String | Waktu penghapusan, dalam format ISO 8601. Contoh: 2022-07-29T14:55Z. |
