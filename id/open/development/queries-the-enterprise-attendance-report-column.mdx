title: "Mendapatkan definisi kolom laporan absensi"
description: "Panggil API DingTalk ini untuk mendapatkan definisi kolom laporan absensi cerdas, termasuk ID, tipe, dan nama kolom, guna memilih kolom untuk perhitungan penggajian."
---

Panggil API ini untuk mengkueri statistik kolom dalam laporan absensi cerdas berdasarkan ID kolom. Organisasi dapat memilih nilai kolom yang digunakan dalam perhitungan penggajian.

## Deskripsi panggilan API

- API ini tidak mengembalikan ID untuk bidang terkait cuti. Untuk mendapatkan data terkait cuti, panggil API [Mendapatkan data cuti laporan](/id/open/development/obtains-the-holiday-data-from-the-smart-attendance-report).
- Pastikan fitur statistik cerdas sudah diaktifkan.

## Permintaan

| **Informasi dasar** | |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/topapi/attendance/getattcolumns |
| Metode HTTP | POST |
| Tipe aplikasi yang didukung | appType-Aplikasi internal appType-Aplikasi perusahaan pihak ketiga |
| Izin yang diperlukan | permission-qyapi_base-Izin dasar yang diperlukan untuk memanggil API organisasi |

### Parameter kueri

| Nama | Tipe | Wajib | Contoh | Deskripsi |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | bE74xxxx | Kredensial aplikasi yang digunakan untuk memanggil API ini.   - Untuk Aplikasi internal, dapatkan melalui API [Mendapatkan access_token Aplikasi internal](/id/open/development/obtain-orgapp-token). - Untuk Aplikasi perusahaan pihak ketiga, dapatkan melalui API Mendapatkan access_token organisasi pihak ketiga. |

### Contoh permintaan

```curl
curl -X POST "https://api.dingtalk.io/topapi/attendance/getattcolumns" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=1aae6dxxxx7bf36'
```

## Respons

### Isi respons

| Nama | Tipe | Contoh | Deskripsi |
| --- | --- | --- | --- |
| request_id | String | emhw3318cdhv | ID permintaan. |
| errcode | Number | 0 | Kode pengembalian. |
| result | AttColumnsForTopVo |  | Hasil kueri. |
| columns | ColumnForTopVo[] |  | Informasi kolom laporan. |
| id | Number | 123 | ID kolom laporan. |
| type | Number | 0 | Tipe kolom laporan. |
| name | String | Jam kerja | Nama kolom laporan. |
| alias | String | 3_on_duty_user_check_result | Alias kolom laporan. |
| status | Number | 0 | Status kolom laporan. |
| sub_type | Number | 0 | Subtipe. |
| expression_id | Number | 129334038 | Bidang yang tidak digunakan lagi. Jangan gunakan bidang ini dalam logika bisnis. |
