---

Digunakan untuk mendapatkan Knowledge Base. Gunakan permintaan GET.

## Permintaan

### Informasi dasar

| Bidang | Nilai |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v2.0/wiki/workspaces/{workspaceId}` |
| Metode HTTP | GET |
| Tipe aplikasi yang didukung | appType-Internal app　appType-Third-party enterprise app |
| Izin yang diperlukan | permission-Wiki.Workspace.Read-Knowledge Base read permission |

### Header permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini.   - Untuk aplikasi internal, panggil API [Mendapatkan access token aplikasi internal](https://open.dingtalk.com/document/orgapp/obtain-the-access_token-of-an-internal-app) untuk memperolehnya. - Untuk aplikasi perusahaan pihak ketiga, panggil API [Mendapatkan access token organisasi yang diberi otorisasi untuk aplikasi pihak ketiga](https://open.dingtalk.com/document/isvapp/obtain-the-access_token-of-the-authorized-enterprise) untuk memperolehnya. |

### Parameter path

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| workspaceId | String | Ya | ID Knowledge Base:   - Untuk aplikasi internal, panggil API [Mendapatkan daftar Knowledge Base](/id/open/development/get-knowledge-base-list) untuk memperoleh bidang `workspaceId` dalam respons. - Untuk aplikasi perusahaan pihak ketiga, panggil API [Mendapatkan daftar Knowledge Base](/id/open/development/get-knowledge-base-list) untuk memperoleh bidang `workspaceId` dalam respons. |

### Parameter query

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| withPermissionRole | Boolean | Tidak | Apakah akan mengambil informasi izin:   - true: ambil - false: jangan ambil   Default: false. |
| operatorId | String | Ya | unionId dari operator. |

### Contoh permintaan

## Respons

### Isi respons

| Nama | Tipe | Deskripsi |
| --- | --- | --- |
| workspace | Object | Knowledge Base. |
| workspaceId | String | ID Knowledge Base (spaceUuid). |
| corpId | String | ID organisasi yang memiliki Knowledge Base. |
| teamId | String | ID Grup Pengetahuan yang memiliki Knowledge Base.  Kosong jika tidak dikaitkan dengan Grup Pengetahuan mana pun. |
| rootNodeId | String | ID node root (root dentryUuid). |
| name | String | Nama Knowledge Base. |
| type | String | Tipe Knowledge Base. Nilai enum:   - **TEAM**: Knowledge Base - **PERSONAL**: Dokumen Saya |
| description | String | Deskripsi Knowledge Base. |
| url | String | URL akses Knowledge Base. |
| icon | Object | Ikon Knowledge Base. |
| type | String | Tipe ikon. Nilai enum:   - **URL**: tautan - **EMOJI**: ikon emoji |
| value | String | Nilai ikon:   - Ketika type adalah URL, mengembalikan tautan ikon. - Ketika type adalah EMOJI, mengembalikan nilai Unicode ikon emoji. |
| cover | String | URL sampul Knowledge Base. |
| creatorId | String | userId pembuat Knowledge Base. |
| modifierId | String | userId pengubah Knowledge Base. |
| createTime | String | Waktu pembuatan Knowledge Base. |
| modifiedTime | String | Waktu modifikasi Knowledge Base. |
| permissionRole | String | Peran izin pemohon pada Knowledge Base. Nilai enum:   - **OWNER**: Pemilik - **MANAGER**: Manajer - **EDITOR**: Editor - **DOWNLOADER**: Penampil dengan izin unduh - **READER**: Hanya penampil - **NONE**: Tidak ada izin |
