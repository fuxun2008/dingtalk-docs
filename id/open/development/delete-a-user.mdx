Panggil API ini untuk menghapus pengguna tertentu berdasarkan ID pengguna.

## Deskripsi panggilan API

Setelah Anda berhasil menghapus pengguna dari Kontak, data berikut juga ikut dihapus:

- Pengguna dikeluarkan dari grup absensi tempat mereka berada.
- Pengguna dikeluarkan dari daftar Smart HR. Anda dapat melihat informasi pengguna tersebut di bagian karyawan yang telah resign pada Smart HR.

## Permintaan

| **Informasi dasar** | |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/topapi/v2/user/delete |
| Metode HTTP | POST |
| Tipe aplikasi yang didukung | appType-Aplikasi internal |
| Izin yang diperlukan | permission-qyapi_manage_addresslist-Izin pengelolaan data Kontak |

### Parameter kueri

| Nama | Tipe | Wajib | Contoh | Deskripsi |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | Be3xxxx | Kredensial aplikasi yang digunakan untuk memanggil API ini. Dapatkan melalui API untuk memperoleh [access_token dari aplikasi internal](/id/open/development/obtain-orgapp-token). |

### Isi permintaan

| Nama | Tipe | Wajib | Contoh | Deskripsi |
| --- | --- | --- | --- | --- |
| userid | String | Ya | uxxxx3 | ID pengguna karyawan. |

### Contoh permintaan

```bash
curl -X POST "https://api.dingtalk.io/topapi/v2/user/delete" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=0b8a6220-ef56-4427-83d5-5690431776e5' \
-d 'userid=zhangsan'
```

Java

```java
DingTalkClient client = new DefaultDingTalkClient("https://api.dingtalk.io/topapi/v2/user/delete");
OapiV2UserDeleteRequest req = new OapiV2UserDeleteRequest();
req.setUserid("user123");
OapiV2UserDeleteResponse rsp = client.execute(req, access_token);
System.out.println(rsp.getBody());
```

Python

```python
import dingtalk.api

req=dingtalk.api.OapiV2UserDeleteRequest("https://api.dingtalk.io/topapi/v2/user/delete")

req.userid="zhangsan"
try:
  resp= req.getResponse(access_token)
  print(resp)
except Exception,e:
  print(e)
```

PHP

```php
include "TopSdk.php";
date_default_timezone_set('Asia/Shanghai');

$c = new DingTalkClient(DingTalkConstant::$CALL_TYPE_OAPI, DingTalkConstant::$METHOD_POST , DingTalkConstant::$FORMAT_JSON);
$req = new OapiV2UserDeleteRequest;
$req->setUserid("zhangsan");
$resp = $c->execute($req, $access_token, "https://api.dingtalk.io/topapi/v2/user/delete");
```

C#

```csharp

OapiV2UserDeleteResponse rsp = client.Execute(req, access_token);

```

## Respons

### Isi respons

| Nama | Tipe | Contoh | Deskripsi |
| --- | --- | --- | --- |
| request_id | String | 4f9md9obopn2 | ID permintaan. |
| errcode | Number | 0 | Kode yang dikembalikan. |
| errmsg | String | Invalid userid | Pesan error yang dikembalikan saat panggilan gagal. |

### Contoh isi respons

```json
{
  "errcode": 0,
  "errmsg": "ok",
  "request_id": "4f9md9obopn2"
}
```

### Kode error

Jika terjadi error saat Anda memanggil API ini, lihat dokumen [kode error global](/id/open/development/server-api-error-codes-1) untuk solusinya.

| Kode error (errcode) | Pesan error (errmsg) | Solusi |
| --- | --- | --- |
| 33012 | Invalid userId | Periksa apakah userId sudah benar. |
| 400002 | Invalid parameter | Periksa apakah parameter dimasukkan sesuai ketentuan. |
| -1 | System busy | Coba lagi nanti. |
