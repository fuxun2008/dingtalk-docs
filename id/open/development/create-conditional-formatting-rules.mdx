---
title: "Membuat aturan pemformatan bersyarat"
description: "Panggil API ini untuk membuat aturan Pemformatan Bersyarat di Lembar Kerja tertentu yang otomatis menerapkan warna font atau latar berdasarkan nilai sel atau duplikat, ideal untuk visualisasi data."
---

Panggil API ini untuk membuat aturan Pemformatan Bersyarat di Lembar Kerja tertentu pada DingTalk Spreadsheet. Aturan ini otomatis menerapkan gaya penyorotan berdasarkan nilai sel atau status duplikat. Ini berguna untuk skenario ketika data perlu ditandai secara visual — misalnya, menyoroti sel di bawah nilai target dengan warna merah, menyoroti entri duplikat agar mudah ditinjau, atau membedakan nilai dalam rentang tertentu dengan warna latar yang ditentukan. Setelah aturan dibuat, sel yang memenuhi kondisi akan otomatis menerapkan warna font atau warna latar yang ditentukan, sehingga Anda tidak perlu mengaturnya satu per satu secara manual.

## Permintaan

### Informasi dasar

| Bidang | Nilai |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/doc/workbooks/{workbookId}/sheets/{sheetId}/conditionalFormattingRules` |
| Metode HTTP | POST |
| Jenis aplikasi yang didukung | appType-Internal app |
| Izin yang diperlukan | permission-Document.Workbook.Write-DingTalk Spreadsheet write permission |

### Header permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Panggil API [Mendapatkan access token aplikasi internal](/id/open/development/obtain-the-access-token-of-an-internal-app) untuk memperolehnya. |

### Parameter jalur

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| workbookId | String | Ya | ID File Spreadsheet. `nodeId(dentryUuid)` yang dikembalikan oleh [API Knowledge Base](/id/open/development/knowledge-base-overview) adalah `workbookId` Spreadsheet. Panggil API [Mendapatkan node](https://open.dingtalk.com/document/development/get-node) atau [Membuat dokumen Knowledge Base](/id/open/development/create-team-space-document) untuk memperolehnya. |
| sheetId | String | Ya | ID atau judul Lembar Kerja. Panggil API [Mendapatkan semua lembar kerja](/id/open/development/obtain-all-worksheets) untuk memperoleh ID dan judul Lembar Kerja. |

### Parameter kueri

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| operatorId | String | Ya | unionId operator. Panggil API [Mengueri detail pengguna](/id/open/development/query-user-details) untuk memperolehnya. Jika operator tidak memiliki izin, API mengembalikan error `The operator has no permission`. |

### Isi permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| ranges | Array of String | Ya | Alamat Sel dalam notasi A1. |
| duplicateCondition | Object | Tidak | Aturan nilai duplikat. |
| operator | String | Tidak | Operator. Saat ini hanya `duplicate` yang didukung, yang mewakili item duplikat. |
| numberCondition | Object | Tidak | Aturan Angka. |
| operator | String | Tidak | Operator perbandingan. Nilai valid:   - **equal**: Sama dengan - **not-equal**: Tidak sama dengan - **greater**: Lebih besar dari - **greater-equal**: Lebih besar dari atau sama dengan - **less**: Lebih kecil dari - **less-equal**: Lebih kecil dari atau sama dengan - **between**: Di antara dua nilai (inklusif) - **not-between**: Tidak di antara dua nilai |
| value1 | Any | Tidak | value1 — Nilai perbandingan pertama (wajib). |
| value2 | Any | Tidak | value2 — Nilai perbandingan kedua (opsional). Wajib hanya ketika `operator` adalah `between` atau `not-between`, berfungsi sebagai batas atas rentang. |
| cellStyle | Object | Tidak | Gaya Sel untuk aturan yang sedang dikonfigurasi. |
| backgroundColor | String | Tidak | Warna latar dalam notasi heksadesimal, misalnya, `#ff0000`. |
| fontColor | String | Tidak | Warna Font. |
