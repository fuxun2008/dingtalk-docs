Panggil API ini untuk menghapus file atau folder.

## Permintaan

### Informasi dasar

| Bidang | Nilai |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/storage/spaces/{spaceId}/dentries/{dentryId}` |
| Metode HTTP | DELETE |
| Tipe aplikasi yang didukung | appType-Internal app　appType-Third-party enterprise app |
| Izin yang diperlukan | permission-Storage.File.Write-Organization storage file write permission |

### Header permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Peroleh dengan cara berikut:   - Untuk aplikasi internal, panggil API [Memperoleh access token aplikasi internal](/id/open/development/obtain-the-access-token-of-an-internal-app). - Untuk aplikasi perusahaan pihak ketiga, panggil API [Memperoleh access token organisasi yang telah memberikan otorisasi ke aplikasi pihak ketiga](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1). |

### Parameter path

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| spaceId | String | Ya | ID ruang. Panggil API [Menambahkan ruang](/id/open/development/add-space) untuk memperoleh nilai parameter id. |
| dentryId | String | Ya | ID file atau folder yang akan dihapus. Panggil API [Memperoleh daftar file atau folder](/id/open/development/get-a-list-of-files-or-folders) atau [Memperoleh spaceId dan dentryId berdasarkan dentryUuid](/id/open/development/api-getdentryidbyuuid) untuk memperoleh nilai parameter id. |

### Parameter query

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| toRecycleBin | Boolean | Tidak | Apakah memindahkan item yang dihapus ke Tempat Sampah:   - **true**: Ya - **false**: Tidak. Ini adalah nilai default.   Saat ini, hanya file dan folder di ruang cloud drive yang dibuat melalui API [Membuat ruang](/id/open/development/new-space) yang mendukung pemindahan ke Tempat Sampah. |
| unionId | String | Ya | unionId dari operator. Panggil API [Mengkueri detail pengguna](/id/open/development/query-user-details) untuk memperoleh nilai parameter unionid. |

### Contoh permintaan

HTTP

```http
DELETE /v1.0/storage/spaces/85xxxxx/dentries/456xxxxx?toRecycleBin=true&unionId=chyxxxxx HTTP/1.1
Host:api.dingtalk.io
x-acs-dingtalk-access-token:xxxxx
Content-Type:application/json
```
