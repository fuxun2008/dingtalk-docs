# FAQ

## Contoh respons untuk acara sepanjang hari

Sebagai contoh, untuk acara sepanjang hari pada 1 Januari 2023, contoh waktu yang dikembalikan adalah sebagai berikut (waktu akhir adalah T+1):

```json
{
  "start" : {
    "date" : "2023-01-01"
  },
  "end" : {
    "date" : "2023-01-02"
  }
}
```
