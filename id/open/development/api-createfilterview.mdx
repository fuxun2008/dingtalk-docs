---
title: "Membuat tampilan filter"
description: "Panggil API ini untuk membuat tampilan filter pada Lembar Kerja target di DingTalk Spreadsheet, menentukan nama tampilan dan rentang filter; kriteria filter dapat dikonfigurasi per kolom."
---

Panggil API ini untuk membuat tampilan filter pada Lembar Kerja tertentu di DingTalk Spreadsheet, serta menentukan nama tampilan dan rentang filter. Setelah tampilan dibuat, Anda dapat mengonfigurasi kondisi filter untuk setiap kolom lebih lanjut.

## Deskripsi panggilan API

- Tampilan filter adalah metode pemfilteran data yang dipersonalisasi dan terpisah dari filter global. Metode ini cocok untuk skenario kolaborasi banyak pengguna, di mana pengguna yang berbeda perlu melihat subset data yang berbeda.
- Setiap Lembar Kerja mendukung hingga 20 tampilan filter.

## Permintaan

### Informasi dasar

| Bidang | Value |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/doc/workbooks/{workbookId}/sheets/{sheetId}/filterViews` |
| Metode HTTP | POST |
| Jenis aplikasi yang didukung | appType-Aplikasi internal |
| Izin yang diperlukan | permission-Document.Workbook.Write-Izin tulis DingTalk Spreadsheet |

### Header permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Panggil API [Mendapatkan access token aplikasi internal](/id/open/development/obtain-the-access-token-of-an-internal-app) untuk memperolehnya. |

### Parameter path

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| workbookId | String | Ya | ID file spreadsheet. `nodeId(dentryUuid)` yang dikembalikan oleh [Knowledge Base API](/id/open/development/knowledge-base-overview) adalah `workbookId` spreadsheet. Anda dapat memperolehnya dengan memanggil API [Get node](https://open.dingtalk.com/document/orgapp/get-node) atau [Membuat dokumen Knowledge Base](/id/open/development/create-team-space-document). |
| sheetId | String | Ya | ID atau nama Lembar Kerja. Panggil API [Mendapatkan semua Lembar Kerja](/id/open/development/obtain-all-worksheets) untuk memperoleh nilai parameter id atau name. |

### Parameter query

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| operatorId | String | Ya | unionId dari operator.   - Panggil API [Mendapatkan informasi pengguna melalui kode login senyap](/id/open/development/obtain-the-userid-of-a-user-by-using-the-log-free) untuk memperoleh nilai parameter unionid. - Panggil API [Mengkueri detail pengguna](/id/open/development/query-user-details) untuk memperoleh nilai parameter unionid.       Jika operator tidak memiliki izin, API mengembalikan error `The operator has no permission`. |

### Isi permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| name | String | Ya | Nama tampilan filter. |
| range | String | Ya | Rentang tampilan filter, dinyatakan dalam notasi A1. Misalnya, `A1:D10` menunjukkan area dari A1 hingga D10. Baris pertama dari rentang filter digunakan sebagai baris header dan tidak disertakan dalam perhitungan filter. |
| criteria | `Map<String, Object>` | Tidak | Menetapkan kondisi filter untuk setiap kolom saat tampilan dibuat. Key adalah offset kolom (relatif terhadap kolom pertama dari rentang, dimulai dari 0), dan value adalah objek kondisi filter. Jika tidak diberikan, tampilan filter kosong akan dibuat. |
|  | Object | Tidak | Kondisi filter untuk kolom saat ini. |
| filterType | String | Tidak | Tipe filter. Nilai yang valid:   - **values**: Filter berdasarkan value. - **color**: Filter berdasarkan warna. - **condition**: Filter berdasarkan kondisi. |
| visibleValues | Array of String | Tidak | Nilai yang terlihat. |
| conditions | Array | Tidak | Daftar kondisi filter saat memfilter berdasarkan kondisi. Hanya valid jika `filterType` diatur ke `condition`. Setiap objek kondisi berisi bidang `operator` dan `value`. |
| operator | String | Tidak | Operator kondisi. Nilai yang valid:   - **equal**: Sama dengan. - **not-equal**: Tidak sama dengan. - **contains**: Mengandung. - **not-contains**: Tidak mengandung. - **starts-with**: Diawali dengan. - **not-starts-with**: Tidak diawali dengan. - **ends-with**: Diakhiri dengan. - **not-ends-with**: Tidak diakhiri dengan. - **greater**: Lebih besar dari. - **greater-equal**: Lebih besar dari atau sama dengan. - **less**: Lebih kecil dari. - **less-equal**: Lebih kecil dari atau sama dengan. |
| value | String | Tidak | Nilai kondisi. |
| conditionOperator | String | Tidak | Hubungan logis antara beberapa kondisi. Nilai yang valid: `and`, `or`. Nilai default adalah `and`. Hanya valid jika `filterType` diatur ke `condition` dan beberapa kondisi diberikan. |
| backgroundColor | String | Tidak | Nilai warna (heksadesimal, misalnya, `#FF0000`) saat memfilter berdasarkan warna latar belakang. Hanya valid jika `filterType` diatur ke `color`. Gunakan salah satu antara parameter ini atau `fontColor`. |
| fontColor | String | Tidak | Nilai warna (heksadesimal, misalnya, `#FF0000`) saat memfilter berdasarkan warna font. Hanya valid jika `filterType` diatur ke `color`. Gunakan salah satu antara parameter ini atau `backgroundColor`. |
