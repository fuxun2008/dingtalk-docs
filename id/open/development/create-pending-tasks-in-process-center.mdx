Panggil API ini untuk membuat tugas Tugas bagi Persetujuan OA.

## Permintaan

### Informasi dasar

| Bidang | Nilai |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/v1.0/workflow/processCentres/tasks |
| Metode HTTP | POST |
| Jenis aplikasi yang didukung | appType-Aplikasi internal　appType-Aplikasi perusahaan pihak ketiga |
| Izin yang diperlukan | permission-qyapi_aflow-Izin pengelolaan data alur persetujuan |

### Header permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Dapatkan dengan cara berikut:   - Aplikasi internal: Panggil API [Mendapatkan access token aplikasi internal](/id/open/development/obtain-the-access-token-of-an-internal-app). - Aplikasi perusahaan pihak ketiga: Panggil API untuk mendapatkan access token organisasi yang telah memberikan otorisasi kepada Aplikasi pihak ketiga. |

### Isi permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| processInstanceId | String | Ya | ID instans alur kerja Persetujuan OA. Panggil API [Membuat instans](/id/open/development/create-a-ticket-approval-instance) untuk mendapatkan nilai `processInstanceId`. |
| activityId | String | Tidak | ID node persetujuan kustom. Ini adalah parameter kustom dengan panjang maksimum 256 karakter. |
| tasks | Array | Ya | Daftar tugas. Maksimum: 20 elemen. |
| userId | String | Tidak | ID pengguna. Panggil API [Mendapatkan daftar ID pengguna di departemen](/id/open/development/query-the-list-of-department-userids) untuk mendapatkannya. |
| url | String | Tidak | URL pengalihan item Tugas. Panjang maksimum: 1.024 karakter.  - url pada API pembuatan instans persetujuan mengarahkan ke Formulir persetujuan di aplikasi Persetujuan DingTalk. - url pada API ini mengarahkan dari Kartu Tugas terkait di halaman Tugas DingTalk. - Halaman Tugas DingTalk mendukung klien seluler dan PC. Pastikan halaman untuk url yang dikirimkan ke API ini kompatibel dengan seluler dan PC. |
| customData | String | Tidak | Data kustom pengguna. Data ini dikembalikan melalui parameter URL saat pengalihan halaman. Panjang maksimum: 500 karakter. |
| dueTimestamp | Long | Tidak | Tenggat waktu tugas, berupa Unix timestamp dalam milidetik. Jika diatur, pusat Tugas DingTalk menampilkan tenggat waktu tugas persetujuan, mendukung pengurutan berdasarkan tenggat waktu, serta mendukung pemfilteran berdasarkan tag seperti Jatuh Tempo Hari Ini dan Terlambat. |
| featureConfig | Object | Tidak | Konfigurasi integrasi Pusat Proses. Konfigurasikan entri tombol tindakan pintasan di item Tugas dan Notifikasi Kartu untuk setiap tugas. |
| features | Array | Tidak | Daftar konfigurasi. |
| name | String | Tidak | Nama modul fitur yang dapat dikustomisasi oleh pihak ketiga. Saat ini didukung:   - **CUSTOM_SHORTCUT**: Tombol tindakan pintasan di item Tugas dan Notifikasi Kartu |
| pcUrl | String | Tidak | Tautan pengalihan kustom pihak ketiga untuk PC. Panjang maksimum: 1.024 karakter. |
| mobileUrl | String | Tidak | Tautan pengalihan kustom pihak ketiga untuk seluler. Panjang maksimum: 1.024 karakter. |
| runType | String | Tidak | Mode eksekusi.  Jika features.name bernilai `CUSTOM_SHORTCUT`, nilai berikut didukung:   - **ORIGIN**: Mode native. Membuka halaman detail Tugas akan mengarahkan ke halaman detail Persetujuan resmi. - **REDIRECT**: Mode pengalihan eksternal. Membuka halaman detail Tugas akan mengarahkan ke alamat yang dikonfigurasi di pcUrl atau mobileUrl. |
| callback | Object | Tidak | Konfigurasi Callback gateway. Wajib diisi jika tombol tindakan pintasan diperlukan. API data eksternal yang dipanggil kembali melalui gateway harus didaftarkan sebagai gateway di "Manajemen Sumber Data". Untuk detailnya, lihat Membuat Sumber Data. |
| appUuid | String | Tidak | appUuid gateway. Wajib diisi jika tombol tindakan pintasan diperlukan.  Isi dengan ID organisasi dari Organisasi pemilik Sumber Data. |
| apiKey | String | Tidak | apiKey gateway. Wajib diisi jika entri tombol tindakan pintasan diperlukan. Dapatkan `apiKey` dari Sumber Data yang telah Anda buat.  - Saat gateway memanggil kembali API eksternal, DingTalk mengembalikan parameter yang diperlukan untuk pemrosesan bisnis kepada ISV sesuai skenario bisnis. Agar dapat mengurai parameter tersebut setelah menerima Permintaan callback, ISV harus mengonfigurasi key parameter yang sesuai saat membuat Sumber Data.   Contohnya, jika callback dikonfigurasi untuk modul eksekusi tugas TASK_EXECUTE (tombol Terima dan Tolak di halaman detail), DingTalk mengembalikan parameter tetap berikut: `&#123;"outResult":"agree","processInstanceId":"xxx","activityId":"xxx","corpId":"dingxxx","data":[],"remark":"Terima","title":"Permintaan pengadaan aset yang diajukan oleh xxx","taskId":111,"operator":"manager0001"&#125;`. - Saat membuat Sumber Data, ISV harus mengonfigurasi key yang akan diurai sesuai kebutuhan bisnis: outResult,processInstanceId,activityId,corpId,remark,title,taskId,operator |
| version | String | Tidak | Versi API gateway.  - Wajib diisi jika entri tombol tindakan pintasan diperlukan. - Default: 1. |
| config | String | Tidak | Konfigurasi modul fitur yang dikustomisasi oleh pihak ketiga. Panjang maksimum: 1.024 karakter. |

## Respons

### Isi respons

| Nama | Tipe | Deskripsi |
| --- | --- | --- |
| result | Array | Daftar hasil yang dikembalikan. |
| taskId | Long | ID tugas Persetujuan OA. |
| userId | String | ID pengguna penerima tugas Persetujuan OA. |
| success | Boolean | Menunjukkan apakah tugas berhasil dibuat. true menandakan Berhasil. |

### Contoh isi respons

```text
HTTP/1.1 200 OK
Content-Type:application/json

{
  "result" : [ {
    "taskId" : 1234567,
    "userId" : "manager001"
  } ],
  "success" : true
}
```
