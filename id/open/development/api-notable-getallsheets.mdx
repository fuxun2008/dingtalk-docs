Panggil API ini untuk mendapatkan semua tabel dari suatu AI Table.

## Permintaan

### Informasi dasar

| Bidang | Nilai |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/notable/bases/{baseId}/sheets` |
| Metode HTTP | GET |
| Jenis aplikasi yang didukung | appType-Aplikasi internal |
| Izin yang diperlukan | permission-Notable.Base.Read.All-Izin baca untuk aplikasi AI Table |

### Header permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Dapatkan dengan memanggil API [Mendapatkan access token dari aplikasi internal](/id/open/development/obtain-the-access-token-of-an-internal-app#). |

### Parameter jalur

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| baseId | String | Ya | ID dari AI Table. Untuk cara mendapatkannya, lihat [Struktur data](/id/open/development/data-structure#). |

### Parameter kueri

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| operatorId | String | Ya | unionId dari operator. Dapatkan dengan salah satu cara berikut:   - Panggil API [Mengkueri detail pengguna](/id/open/development/query-user-details#). - Panggil API [Mendapatkan ID pengguna dengan menggunakan kode login senyap](/id/open/development/obtain-the-userid-of-a-user-by-using-the-log-free#). |
