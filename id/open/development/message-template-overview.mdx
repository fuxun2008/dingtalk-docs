Aplikasi perusahaan pihak ketiga dapat mengirim notifikasi pesan melalui templat pesan.

Templat pesan merupakan peningkatan dari pengiriman pesan melalui Notifikasi Kerja. Templat ini memberikan pengalaman pengembangan dan konfigurasi templat pesan yang lebih sederhana dan terstandarisasi, sekaligus menawarkan kemampuan notifikasi pesan yang lebih aman, mudah dikelola, dan terkontrol di sisi pelanggan.

**Penting**

Saat menggunakan templat pesan, perhatikan hal berikut:

- Hanya **Aplikasi perusahaan pihak ketiga** yang didukung.
- Hanya templat pesan yang telah disetujui yang dapat digunakan untuk mengirim pesan Notifikasi Kerja.

## Tipe templat

Saat ini terdapat tiga tipe templat pesan yang didukung.

- Templat Markdown

  Templat Markdown menggunakan sintaks Markdown untuk mengonfigurasi dan mengirim pesan. Templat ini cocok untuk tipe pesan notifikasi murni yang tidak memerlukan tindakan. Templat Markdown memudahkan dukungan format tampilan seperti teks, gambar, dan tautan.
- Templat ActionCard

  Templat ActionCard mengirim pesan menggunakan tipe pesan ActionCard. Templat ini mendukung pesan yang menggabungkan konten dan poin tindakan, serta cocok untuk skenario yang memerlukan satu atau beberapa poin tindakan untuk menangani tugas dengan cepat di dalam pesan.

  Dibangun di atas templat Markdown, templat ActionCard mendukung gaya lompatan menyeluruh maupun lompatan mandiri.
- Templat Formulir

  Templat Formulir mengirim pesan berdasarkan tipe pesan OA. Templat ini cocok untuk menampilkan pesan seperti pesanan dan mendukung lompatan untuk melihat detail pesan.

## Alur penggunaan

Seperti ditunjukkan pada gambar berikut, mengirim Notifikasi Kerja dengan templat pesan memerlukan tindakan berikut:

1. Buat dan konfigurasikan templat pesan. Untuk detailnya, lihat [Kelola Templat Pesan](/zh/open/development/manage-message-templates).
2. Ajukan templat untuk ditinjau.
3. Panggil API untuk mengirim Notifikasi Kerja menggunakan templat. Untuk detailnya, lihat [Kirim Pesan Notifikasi Kerja Menggunakan Templat](/zh/open/development/work-notification-templating-send-notification-interface).
