description: "Setelah mengamankan data Kontak organisasi, impor sumber daya ke Compute Nest di DingTalk — panduan konfigurasi akun Alibaba Cloud, grup aplikasi, dan impor instans SLB, ECS, RDS."
---

Setelah mengamankan data Kontak organisasi, impor sumber daya ke Compute Nest.

## **Prosedur**

1. Masuk ke [Developer Console](https://open-dev.dingtalk.com/), klik **App Development** > **Third-party Enterprise App** > **Enterprise App**, lalu pilih aplikasi target untuk membuka halaman detail aplikasi.
2. Klik **App Release** > **App Deployment**, lalu pilih metode deployment yang sesuai.
3. Kaitkan akun Alibaba Cloud dengan mengklik **Select Account**:

   - Jika akun Alibaba Cloud sudah dikaitkan, pilih langsung akun Alibaba Cloud yang terdeteksi dan klik **Confirm**.
   - Jika belum ada akun Alibaba Cloud yang dikaitkan, halaman baru akan terbuka. Klik **Associate Alibaba Cloud Account** > **Confirm**. Kemudian, pada halaman app deployment, pilih ulang akun Alibaba Cloud yang terdeteksi dan klik **Confirm**. Untuk detailnya, lihat [Bind a DingTalk account to an Alibaba Cloud account](https://open.dingtalk.com/document/isvapp/bind-a-dingtalk-account-to-an-alibaba-cloud-account#).
4. Setelah memilih akun, pilih **I agree to the Compute Nest Service Security Detection Authorization Agreement**, lalu klik **Authorize Compute Nest**.
5. Klik **Asset Management** untuk membuka **App Management** Compute Nest yang terkait.
6. Buka **App Management** Compute Nest.

   Setelah membuka App Management, buat **app group** untuk wilayah terkait berdasarkan lokasi sumber daya cloud Anda. Anda dapat membuat app group untuk beberapa wilayah secara terpisah.

   Misalnya, jika sumber daya cloud Anda berada di Hangzhou, klik **Create App Group**, sesuaikan nama grup, dan pilih **East China 1 (Hangzhou)** sebagai wilayahnya. Selama pembuatan, Anda dapat memilih sumber daya cloud yang akan diimpor. Secara default, Anda sebaiknya mengimpor instans sumber daya cloud seperti SLB, ECS, RDS, dan EIP.
7. Setelah membuat app group, Anda juga dapat menggunakan **Import Resources** di bawah **Resource Management** untuk memilih sumber daya dan instans cloud yang akan diimpor.

   **Penting**
   1. Untuk menggunakan RDS Push, impor instans RDS dari wilayah **East China 1** atau **North China 3** ke aplikasi Compute Nest, lalu konfigurasikan Sumber Data push pada halaman RDS di app deployment.
   2. Wilayah dan zona yang didukung oleh SLB privat adalah sebagai berikut:

      |  |  |
      | --- | --- |
      | Wilayah | Zona |
      | East China 1 (Hangzhou) | Zone B, Zone E, Zone F, Zone G, Zone H, Zone I, Zone J, Zone K |
      | East China 2 (Shanghai) | Zone B, Zone E, Zone F, Zone G, Zone L, Zone M, Zone N, Zone I, Zone H |
      | North China 2 (Beijing) | Zone B, Zone C, Zone D, Zone E, Zone F, Zone G, Zone H, Zone I, Zone K, Zone L |
      | North China 3 (Zhangjiakou) | Zone A, Zone B, Zone C |
      | South China 1 (Shenzhen) | Zone D, Zone E, Zone F |

## **Langkah selanjutnya**

Setelah mengimpor sumber daya, Anda perlu [mengonfigurasi dan memperbarui nama domain aman](https://open.dingtalk.com/document/isvapp/configure-update-secure-domain-name).
