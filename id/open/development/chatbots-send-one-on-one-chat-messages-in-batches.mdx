Panggil API ini untuk mengirim pesan bot ke banyak obrolan Person-to-Bot (Pesan Langsung antara pengguna dan bot) secara massal. API ini cocok untuk skenario ketika Anda perlu mengirim pesan bot ke banyak pengguna (hingga 20) secara massal, seperti notifikasi organisasi dan pengiriman peringatan sistem.

## Deskripsi panggilan API

API ini mendukung bot dari aplikasi internal. Untuk informasi lebih lanjut, lihat [Konfigurasikan Bot perusahaan](/id/open/dingstart/configure-the-robot-application).

## Permintaan

### Informasi dasar

| Bidang | Nilai |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/v1.0/robot/oToMessages/batchSend |
| Metode HTTP | POST |
| Tipe aplikasi yang didukung | appType-Aplikasi internal　appType-Aplikasi perusahaan pihak ketiga |
| Izin | permission-qyapi_robot_sendmsg-Izin untuk mengirim pesan dengan bot di Organisasi Anda |

### Header permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses yang digunakan untuk memanggil API ini. Peroleh dengan cara berikut:   - Untuk aplikasi internal, panggil API [Mendapatkan access token aplikasi internal](/id/open/development/obtain-the-access-token-of-an-internal-app#). - Untuk aplikasi perusahaan pihak ketiga, panggil API [Mendapatkan access token organisasi yang diberi otorisasi ke aplikasi pihak ketiga](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#). |

### Isi permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| robotCode | String | Ya | Kode bot. Parameter ini harus menggunakan robotCode dari bot aplikasi internal. Untuk informasi lebih lanjut, lihat [ID Bot](/id/open/development/development-robot-overview#447ec33014hrl). |
| userIds | Array of String | Ya | Daftar ID pengguna yang menerima pesan. Anda dapat mengirim hingga 20 ID pengguna sekaligus. Anda dapat memperoleh ID pengguna dengan memanggil API [Query detail pengguna](/id/open/development/query-user-details#) atau API [Mendapatkan daftar ID pengguna dalam departemen](/id/open/development/query-the-list-of-department-userids#). |
| msgKey | String | Ya | Key templat pesan. Untuk informasi lebih lanjut, lihat [Tipe pesan yang didukung oleh Bot perusahaan](https://open.dingtalk.com/document/dingstart/types-of-messages-sent-by-robots#). |
| msgParam | String | Ya | Parameter templat pesan. Untuk informasi lebih lanjut, lihat [Tipe pesan yang didukung oleh Bot perusahaan](https://open.dingtalk.com/document/dingstart/types-of-messages-sent-by-robots#). |
