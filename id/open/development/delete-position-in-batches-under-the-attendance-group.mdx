Panggil API ini untuk menghapus lokasi secara massal dari grup absensi tertentu.

## Permintaan

| **Informasi dasar** | |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/topapi/attendance/group/positions/remove |
| Metode HTTP | POST |
| Tipe aplikasi yang didukung | appType-Aplikasi internal |
| Izin yang diperlukan | permission-qyapi_attendance_group_manage-Izin pengelolaan grup absensi |

### Parameter query

| Nama | Tipe | Wajib | Contoh | Deskripsi |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | 4c9ebd2b1534xxxx | Kredensial aplikasi yang digunakan untuk memanggil API ini. Dapatkan dengan memanggil API [Mendapatkan access_token aplikasi internal](/id/open/development/obtain-orgapp-token). |

### Isi permintaan

| Nama | Tipe | Wajib | Contoh | Deskripsi |
| --- | --- | --- | --- | --- |
| op_userid | String | Tidak | user01 | ID pengguna operator. |
| group_key | String | Ya | CEDDFxxxx | ID grup absensi.  **Catatan**  Jika pengenal grup absensi Anda berupa group_id, panggil API [Mengonversi groupId menjadi groupKey](/id/open/development/groupid-to-groupkey) untuk mengonversi group_id menjadi group_key. |
| position_key_list | String | Ya | C384Fxxxx | Daftar key lokasi yang akan dihapus. Dapatkan key dengan memanggil API [Mengkueri lokasi secara massal](/id/open/development/batch-query-position-under-attendance-group). Hapus hingga 100 lokasi per panggilan. |

### Contoh permintaan

```curl
curl -X POST "https://api.dingtalk.io/topapi/attendance/group/positions/remove" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=25961xxxx7912f13' \
-d 'group_key=0151E022xxxx72A1A917E876' \
-d 'op_userid=123456' \
-d 'position_key_list=%22123%22%2C%22123%22'
```

Java

```text
DingTalkClient client = new DefaultDingTalkClient("https://api.dingtalk.io/topapi/attendance/group/positions/remove");
OapiAttendanceGroupPositionsRemoveRequest req = new OapiAttendanceGroupPositionsRemoveRequest();
req.setOpUserid("user01");
req.setGroupKey("CEDDFxxxx");
req.setPositionKeyList("C384Fxxxx");
OapiAttendanceGroupPositionsRemoveResponse rsp = client.execute(req, access_token);
System.out.println(rsp.getBody());
```

## Respons

### Isi respons

| Nama | Tipe | Contoh | Deskripsi |
| --- | --- | --- | --- |
| result | Result |  | Hasil yang dikembalikan. |
| success_list | String[] | ["C384Fxxxx"] | Daftar item yang berhasil dihapus. |
| error_info_list | ErrorInfo[] |  | Daftar error. |
| failure_list | String[] | ["C384Fxxxx"] | Daftar item yang gagal dihapus. |
| msg | String | business fault | Deskripsi error. |
| code | String | 1000 | Kode error. |
| errcode | Number | 0 | Kode respons. |
| errmsg | String | ok | Deskripsi kode respons. |
| success | Boolean | true | Menunjukkan apakah panggilan berhasil.   - **true**: Berhasil - **false**: Gagal |
| request_id | String | 1493be6v5yefm | ID permintaan. |

### Contoh isi respons

```json
{
  "errcode": 0,
  "errmsg":"ok",
  "result": {
    "error_info_list": [
      {
        "code": "1000",
        "failure_list": [
          "C384Fxxxx"
        ],
        "msg": "business fault"

    ],
    "success_list": [
      "C384Fxxxx"
    ]
  },
  "success": true,
  "request_id": "1493be6v5yefm"
}
```

### Kode error

Jika panggilan mengembalikan error, cari solusinya di dokumen [Kode error global](/id/open/development/server-api-error-codes-1) berdasarkan pesan error.
