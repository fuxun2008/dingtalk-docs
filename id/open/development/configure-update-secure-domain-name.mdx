Setelah mengimpor sumber daya, konfigurasikan security domain DingTalk. Ikuti langkah pada dokumen ini untuk menyelesaikan penyiapan.

## Prasyarat

Sebelum mulai, pastikan sebuah SLB telah dibeli di akun Alibaba Cloud (deployment Compute Nest) yang terkait dengan Developer Console, dan SLB tersebut telah dikonfigurasi dengan [port listening protokol HTTP](https://help.aliyun.com/document_detail/85949.html?spm=a2c4g.86438.0.0.19195491uwAdyO). Saat ini hanya CLB yang didukung.

**Peringatan**

Jangan gunakan port HTTPS umum seperti 443 atau 8443 untuk mengalihkan HTTP ke HTTPS.

## **Langkah**

1. Masuk ke Developer Console, buka halaman detail aplikasi, lalu klik **App Release > App Self-Check**.
2. Pilih SLB jaringan privat yang akan diasosiasikan, pilih perjanjian otorisasi, lalu klik **Association**.
3. Setelah asosiasi selesai, tunggu peninjauan domain dan inisialisasi konfigurasi domain.

   **Catatan**

   Setelah mengirim permintaan pengikatan security domain, tunggu peninjauan keamanan DingTalk yang biasanya memerlukan waktu 1 hingga 2 hari kerja. Setelah disetujui, proses akan secara otomatis mengikat SLB jaringan privat ke security domain, yang memerlukan waktu 1 hingga 2 hari kerja untuk berlaku. Pantau pembaruan status. Jika permintaan ditolak, perbaiki dan kirim ulang aplikasinya.
4. Perbarui security domain di aplikasi:

   - Jika tipe push adalah SyncHTTP, gunakan security domain DingTalk pada alamat push dari URL callback.
   - Gunakan security domain DingTalk untuk domain Server API pengembang.
   - Jika aplikasi tidak dibangun dengan arsitektur front-end dan back-end yang terpisah, gunakan security domain DingTalk untuk URL halaman Beranda aplikasi.

## **Langkah berikutnya**

Deploy server aplikasi ke [ECS di Compute Nest](https://help.aliyun.com/document_detail/444595.html?spm=a2c4g.290076.0.0.60715167ZJIyYr).
