title: "Perbarui izin"
description: "Panggil API ini untuk memperbarui izin file bagi anggota di DingTalk berdasarkan uuid file, rootNodeId atau nodeId Knowledge Base, unionId operator, dan id peran."
---

Panggil API ini untuk memperbarui izin file dari pengguna izin berdasarkan informasi seperti ID yang ditentukan (uuid file, rootNodeId Knowledge Base, atau nodeId node Knowledge Base), unionId operator, dan ID peran izin.

## Permintaan

### Informasi dasar

| Bidang | Nilai |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v2.0/storage/spaces/dentries/{dentryUuid}/permissions` |
| Metode HTTP | PUT |
| Jenis aplikasi yang didukung | appType-Aplikasi internal |
| Persyaratan izin | permission-Storage.Permission.Write-Izin tulis untuk informasi otorisasi penyimpanan organisasi |

### Header permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses yang digunakan untuk memanggil API ini. Panggil API [Dapatkan access token aplikasi internal](/id/open/development/obtain-the-access-token-of-an-internal-app) untuk memperolehnya. |

### Parameter jalur

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| dentryUuid | String | Ya | Uuid file. Panggil API [Pencarian File](/id/open/development/search-for-files) atau API [Dapatkan informasi dentryUuid](/id/open/development/api-getuuidbydentryid) untuk memperoleh bidang dentryUuid dari parameter respons. |

### Parameter kueri

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| unionId | String | Ya | unionId pengguna. Panggil API [Kueri detail pengguna](/id/open/development/query-user-details) untuk memperolehnya. |

### Isi permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| roleId | String | Ya | ID peran. Nilai enum:   - **OWNER**: Pemilik, dengan cakupan izin berikut:    - PermissionPrivilegeEnum.INFO   - PermissionPrivilegeEnum.LIST   - PermissionPrivilegeEnum.PREVIEW   - PermissionPrivilegeEnum.READ   - PermissionPrivilegeEnum.WRITE   - PermissionPrivilegeEnum.DOWNLOAD   - PermissionPrivilegeEnum.ADD   - PermissionPrivilegeEnum.DELETE   - PermissionPrivilegeEnum.MODIFY   - PermissionPrivilegeEnum.COPY   - PermissionPrivilegeEnum.RENAME   - PermissionPrivilegeEnum.READ_PERMISSION   - PermissionPrivilegeEnum.WRITE_PERMISSION   - PermissionPrivilegeEnum.ASSIGN - **MANAGER**: Manajer, dengan cakupan izin berikut:    - PermissionPrivilegeEnum.INFO   - PermissionPrivilegeEnum.LIST   - PermissionPrivilegeEnum.PREVIEW   - PermissionPrivilegeEnum.READ   - PermissionPrivilegeEnum.WRITE   - PermissionPrivilegeEnum.DOWNLOAD   - PermissionPrivilegeEnum.ADD   - PermissionPrivilegeEnum.DELETE   - PermissionPrivilegeEnum.MODIFY   - PermissionPrivilegeEnum.COPY   - PermissionPrivilegeEnum.RENAME   - PermissionPrivilegeEnum.READ_PERMISSION   - PermissionPrivilegeEnum.WRITE_PERMISSION - **EDITOR**: Editor, dengan cakupan izin berikut:    - PermissionPrivilegeEnum.INFO   - PermissionPrivilegeEnum.LIST   - PermissionPrivilegeEnum.PREVIEW   - PermissionPrivilegeEnum.READ   - PermissionPrivilegeEnum.WRITE   - PermissionPrivilegeEnum.DOWNLOAD   - PermissionPrivilegeEnum.ADD - **DOWNLOADER**: Penampil dan pengunduh, dengan cakupan izin berikut:    - PermissionPrivilegeEnum.INFO   - PermissionPrivilegeEnum.LIST   - PermissionPrivilegeEnum.PREVIEW   - PermissionPrivilegeEnum.READ   - PermissionPrivilegeEnum.DOWNLOAD - **READER**: Hanya lihat, dengan cakupan izin berikut:    - PermissionPrivilegeEnum.INFO   - PermissionPrivilegeEnum.LIST   - PermissionPrivilegeEnum.PREVIEW |
| members | Array | Ya | Daftar pengguna izin. Ukuran maksimum adalah 30. |
| type | String | Ya | Tipe pengguna izin. Nilai enum:   - **ORG**: Organisasi - **DEPT**: Departemen - **TAG**: Tag kustom - **CONVERSATION**: Obrolan - **USER**: Pengguna |
| id | String | Ya | ID pengguna izin:   - Saat `type=ORG`, id adalah ID organisasi. - Saat `type=DEPT`, id adalah ID departemen. - Saat `type=TAG`, id adalah ID tag. - Saat `type=CONVERSATION`, id adalah ID obrolan. - Saat `type=USER`, id adalah ID karyawan. |
| corpId | String | Tidak | Organisasi tempat izin ini berada.       - Jika ID organisasi disediakan, izin akan otomatis dihapus saat anggota terkait keluar dari organisasi. - Saat memberType adalah dept, ID organisasi wajib diisi. |
| option | Object | Tidak | Parameter opsional. |
| duration | Long | Tidak | Periode validitas, dalam detik.       - Saat ini, hanya Ruang dengan OwnerType APP yang mendukung izin sementara. - Nilai maksimum adalah 3600. |
