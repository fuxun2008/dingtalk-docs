description: "Panggil API ini untuk mengatur opsi dropdown pada rentang sel tertentu di DingTalk Spreadsheet, mendukung teks kustom dan warna label untuk entri data yang terstandardisasi."
---

Panggil API ini untuk mengonfigurasi opsi daftar dropdown pada rentang sel tertentu di DingTalk Spreadsheet. Anda dapat menyesuaikan nilai teks dan warna label pada setiap opsi. API ini berguna untuk menstandardisasi entri data dan menyediakan opsi preset (seperti status atau kategori). Setelah dikonfigurasi, pengguna hanya dapat memilih nilai dari opsi yang telah ditentukan.

## Permintaan

### Informasi dasar

| Bidang | Nilai |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/doc/workbooks/{workbookId}/sheets/{sheetId}/ranges/{rangeAddress}/insertDropdownLists` |
| Metode HTTP | POST |
| Jenis aplikasi yang didukung | appType-Internal app |
| Izin yang diwajibkan | permission-Document.Workbook.Write-Izin tulis DingTalk Spreadsheet |

### Header permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Untuk memperolehnya, panggil API [Dapatkan access token aplikasi internal](/id/open/development/obtain-the-access-token-of-an-internal-app). |

### Parameter path

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| workbookId | String | Ya | ID file Spreadsheet. `nodeId(dentryUuid)` yang dikembalikan oleh [API Knowledge Base](/id/open/development/knowledge-base-overview) adalah `workbookId` dari Spreadsheet. Untuk memperolehnya, panggil API [Dapatkan node](https://open.dingtalk.com/document/development/get-node) atau [Buat dokumen Knowledge Base](/id/open/development/create-team-space-document). |
| sheetId | String | Ya | ID atau judul lembar kerja. Untuk memperoleh ID dan judul, panggil API [Dapatkan semua lembar kerja](/id/open/development/obtain-all-worksheets). |
| rangeAddress | String | Ya | Alamat rentang. |

### Parameter query

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| operatorId | String | Ya | unionId dari operator. Untuk memperolehnya, panggil API [Kueri detail pengguna](/id/open/development/query-user-details). Jika operator tidak memiliki izin yang diperlukan, API mengembalikan error `The operator has no permission`. |

### Isi permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| options | Array | Ya | Array dari opsi daftar dropdown. |
| value | String | Ya | Nilai opsi daftar dropdown. |
| color | String | Tidak | Warna opsi daftar dropdown, dinyatakan dalam notasi heksadesimal. Contoh, #ff0000. |
