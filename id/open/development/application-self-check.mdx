Untuk menjamin kualitas produk, selesaikan proses inspeksi mandiri sebelum Anda mengirim aplikasi untuk didaftarkan atau mempromosikannya secara eksternal.

## Pengenalan inspeksi mandiri aplikasi

Setelah Anda selesai mengembangkan aplikasi perusahaan pihak ketiga, lakukan inspeksi mandiri aplikasi:

- Inspeksi mandiri fungsi, digunakan untuk memeriksa pengaturan dasar seperti IP outbound server aplikasi dan pengaturan push.
- Tinjauan keamanan, digunakan untuk memeriksa aspek keamanan.
- Pemantauan stabilitas, digunakan untuk memeriksa stabilitas aplikasi, seperti tingkat layar kosong aplikasi dan latensi API rata-rata.

## Prosedur

1. Masuk ke [Developer Console](https://open-dev.dingtalk.com/).
2. Pilih aplikasi perusahaan pihak ketiga yang Anda buat.
3. Klik aplikasi target untuk membuka halaman detailnya, pilih **App Self-Inspection**, lalu klik **Start Check**.

   - **Function Self-Inspection**

     Digunakan untuk memeriksa pengaturan dasar aplikasi, seperti IP outbound server aplikasi, pengaturan push, dan integrasi API. Detail pemeriksaannya adalah sebagai berikut:

     |  |  |  |
     | --- | --- | --- |
     | Item Pemeriksaan | Deskripsi | Referensi |
     | Apakah IP outbound server sudah diatur | Atur IP outbound server pada informasi pengembangan aplikasi. | [Development Overview](https://open.dingtalk.com/document/isvapp/isvapp-development-overview#) |
     | Apakah tipe push yang valid sudah diatur | Selesaikan pengaturan push pada informasi pengembangan aplikasi. | [Overview](https://open.dingtalk.com/document/isvapp/callback-events-overview#) |
     | Apakah organisasi penerimaan resmi berhasil menginstal aplikasi saat ini | Instal aplikasi saat ini pada organisasi penerimaan resmi DingTalk untuk penerimaan produk selanjutnya. Klik tombol Start Check pada halaman inspeksi mandiri aplikasi, dan organisasi penerimaan resmi (CorpId: ding0ed2f6a472ab48fef5bf40eda33b7ba0, Open Platform App Review Group) otomatis menginstal aplikasi.  **Catatan**  Saat Anda mengklik tombol Start Check, pastikan layanan push aplikasi berfungsi dengan baik. | — |
     | Apakah integrasi Monitoring Center sudah selesai | Selesaikan integrasi di Monitoring Center dan hasilkan data pemantauan. | [Monitoring Center](https://open.dingtalk.com/document/isvapp/monitoring-center#) |
     | Apakah server di-deploy pada Alibaba Cloud atau Jushita | Pilih Alibaba Cloud atau Jushita sebagai metode deployment cloud aplikasi. Untuk informasi lebih lanjut, lihat dokumentasi deployment aplikasi. | [Deployment Overview](https://open.dingtalk.com/document/isvapp/deployment-overview#) |
     | Apakah versi mini program sudah dipublikasikan | Publikasikan versi mini program di manajemen versi aplikasi. | [Version Management and Publishing](https://open.dingtalk.com/document/isvapp/publish-and-install-isvapp#) |
     | Apakah domain security gateway sudah diajukan dan digunakan dalam aplikasi | Aplikasi yang terdaftar di marketplace, yaitu aplikasi yang di-deploy pada Jushita, harus menggunakan domain keamanan. | [DingTalk Security Domain](/zh/open/development/config-domain-name) |
4. Klik **Next** untuk membuka halaman **Security Review**.
5. Dengan mengacu pada [Security Access Evaluation Guide](https://open.dingtalk.com/document/isvapp/security-access-evaluation-guide#), lengkapi dan kirim materi untuk item evaluasi tinjauan keamanan pendaftaran aplikasi.
6. Setelah Anda mengirim, halaman **Stability Monitoring** akan terbuka.

   **Catatan**

   Selesaikan tinjauan stabilitas sebelum Anda mendaftarkan aplikasi ke DingTalk Marketplace. Setelah Anda mengintegrasikan sistem pemantauan stabilitas, DingTalk mengumpulkan dan menampilkan data aplikasi berikut serta memberi tahu Anda ketika data berada di bawah standar. Untuk informasi lebih lanjut, lihat [Stability Certification Standards](https://open.dingtalk.com/document/isvapp/stabilistandards#).
7. Pilih **Integrate the Stability Monitoring System**.

   |  |  |  |
   | --- | --- | --- |
   | Metrik Data | Deskripsi | Persyaratan Metrik |
   | Tingkat keberhasilan API di Monitoring Center | Lihat di Monitoring Center pada **Monitoring Metrics** -> **API Requests** -> **Success Rate**. | ≥98.99% |
   | Latensi API rata-rata di Monitoring Center | Lihat di Monitoring Center pada **Monitoring Metrics** -> **API Requests** -> **Request Latency**. | &lt;300 |
   | Tingkat error JS di Monitoring Center | Lihat di Monitoring Center pada **Monitoring Metrics** -> **JS Errors** -> **Error Count to PV Ratio**. | &lt;1.99% |
   | Tingkat layar kosong di Monitoring Center | Lihat di Monitoring Center pada **Monitoring Metrics** -> **Blank Screen Errors** -> **Blank Screen Rate**. | &lt;1.99% |
   | Tingkat keberhasilan dd.config | Tingkat keberhasilan rata-rata harian pemanggilan JSAPI **dd.config**. | ≥98.99% |
   | Tingkat keberhasilan push HTTP | Jika tipe push adalah HTTP atau SyncHttp, tingkat keberhasilan adalah tingkat DingTalk melakukan push ke URL callback selama periode statistik (**push yang memakan waktu lebih dari 1.500 ms dihitung sebagai kegagalan timeout**). | ≥98.99% |
8. Klik **Self-Inspection Complete** untuk menyelesaikan inspeksi mandiri. Setelah Anda menyelesaikan proses inspeksi mandiri aplikasi, hasilnya adalah sebagai berikut:

   Setelah aplikasi menyelesaikan inspeksi mandiri, Anda dapat mendaftarkannya ke DingTalk Marketplace atau menjalankan aktivitas promosi offline.
