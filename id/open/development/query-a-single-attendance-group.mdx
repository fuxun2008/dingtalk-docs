Panggil API ini untuk mendapatkan detail grup absensi berdasarkan ID grup absensi, seperti nama grup absensi, pemilik utama grup absensi, dan tipe absensi.

## Permintaan

| **Informasi dasar** | |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/topapi/attendance/group/query |
| Metode HTTP | POST |
| Tipe aplikasi yang didukung | appType-Aplikasi internal　appType-Aplikasi perusahaan pihak ketiga |
| Izin yang diperlukan | permission-qyapi_attendance_group_read-Izin kueri grup absensi |

### Parameter kueri

| Nama | Tipe | Wajib | Contoh | Deskripsi |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | bE74xxxx | Kredensial aplikasi yang digunakan untuk memanggil API ini.   - Untuk Aplikasi internal, panggil API [Mendapatkan access_token Aplikasi internal](/id/open/development/obtain-orgapp-token) untuk memperolehnya. - Untuk Aplikasi perusahaan pihak ketiga, panggil API Mendapatkan access_token Aplikasi perusahaan pihak ketiga untuk memperolehnya. |

### Isi permintaan

| Nama | Tipe | Wajib | Contoh | Deskripsi |
| --- | --- | --- | --- | --- |
| op_user_id | String | Ya | user123 | userId operator. |
| group_id | Number | Ya | 685935028 | ID grup absensi. Panggil API [Mendapatkan detail grup absensi secara massal](/id/open/development/batch-obtain-attendance-group-details) untuk memperoleh nilai group_id.  **Catatan**  Jika Anda memiliki pengenal grup absensi lama (group_key), panggil API [Mengonversi groupKey menjadi groupId](/id/open/development/convert-groupkey-to-groupid) untuk mengonversi group_key menjadi group_id. |

### Contoh permintaan

```curl
curl -X POST "https://api.dingtalk.io/topapi/attendance/group/query" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=65671xxxx92ddf0' \
-d 'group_id=23456' \
-d 'op_user_id=dd_dd'
```

Java

```java
DingTalkClient client = new DefaultDingTalkClient("https://api.dingtalk.io/topapi/attendance/group/query");
OapiAttendanceGroupQueryRequest req = new OapiAttendanceGroupQueryRequest();
req.setOpUserId("dd_dd");
req.setGroupId(23456L);
OapiAttendanceGroupQueryResponse rsp = client.execute(req, access_token);
System.out.println(rsp.getBody());
```

Python

```python
import dingtalk.api

req=dingtalk.api.OapiAttendanceGroupQueryRequest("https://api.dingtalk.io/topapi/attendance/group/query")

req.op_user_id="dd_dd"
req.group_id=23456
try:
  resp= req.getResponse(access_token)
  print(resp)
except Exception,e:
  print(e)
```

PHP

```php
include "TopSdk.php";
date_default_timezone_set('Asia/Shanghai');

$c = new DingTalkClient(DingTalkConstant::$CALL_TYPE_OAPI, DingTalkConstant::$METHOD_POST , DingTalkConstant::$FORMAT_JSON);

$req->setGroupId("23456");
$resp = $c->execute($req, $access_token, "https://api.dingtalk.io/topapi/attendance/group/query");
```

C#


## Respons

### Isi respons

| Nama | Tipe | Contoh | Deskripsi |
| --- | --- | --- | --- |
| result | TopSimpleGroupVO |  | Hasil yang dikembalikan. |
| name | String | Absensi | Nama grup absensi. |
| shift_ids | Number[] | [677995086] | ID shift. |
| id | Number | 685935028 | ID grup absensi. |
| wifis | String[] | ["test-inc"] | Nama Wi-Fi. |
| address_list | String[] | ["Lahan Basah Xixi"] | Alamat absensi. |
| work_day_list | Number[] | [0,1,2,3] | Hari kerja. |
| member_count | Number | 39 | Jumlah pengguna. |
| type | String | TURN | Tipe grup absensi.   - **FIXED:** Grup absensi shift tetap - **TURN:** Grup absensi berbasis shift - **NONE:** Grup absensi jam kerja fleksibel |
| url | String | https://attend.dingtalk.io/xxxx | Tautan pengalihan. |
| manager_list | String | user456 | Admin grup absensi. |
| owner_user_id | String | user01 | userId pemilik utama grup absensi. |
| success | Boolean | true | Menunjukkan apakah permintaan berhasil.   - **true**: Berhasil - **false**: Gagal |
| errcode | Number | 0 | Kode pengembalian. |
| request_id | String | 72hycvnsyykp | ID permintaan. |
