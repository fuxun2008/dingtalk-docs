description: "Panggil API DingTalk untuk memprakirakan durasi lembur, perjalanan dinas, dan cuti karyawan berdasarkan penjadwalan shift absensi, per hari kalender atau hari kerja."
---

Panggil API ini untuk menghitung di awal durasi lembur, perjalanan dinas, dan cuti karyawan berdasarkan penjadwalan shift di sistem absensi.

## Deskripsi panggilan API

Contoh: seorang karyawan dijadwalkan bekerja pada 2 November (jam masuk 09:00, jam pulang 18:00) dan libur pada 3 November.

Karyawan tersebut berencana mengambil cuti dari pukul 09:00:00 pada 2 November hingga pukul 18:00:00 pada 3 November. Panggil API ini untuk mendapatkan perkiraan durasi cuti dalam rentang tersebut. Hasilnya hanya satu hari.

- Jika karyawan tidak termasuk dalam grup absensi atau tidak memiliki jadwal shift pada tanggal cuti, durasi cuti dihitung berdasarkan waktu absensi default.
- Konfigurasikan waktu absensi default di **DingTalk seluler > Workbench > Absensi > Pengaturan > Pengaturan Lainnya > Persetujuan cuti dan absensi > Waktu Absensi Default**. Contoh:

  Seorang karyawan dijadwalkan bekerja pada 2 November (jam masuk 09:00, jam pulang 18:00) dan tidak memiliki jadwal shift pada 3 November. Shift default adalah 08:30–17:30. Karyawan tersebut berencana mengambil cuti dari pukul 09:00:00 pada 2 November hingga pukul 18:00:00 pada 3 November. Panggil API ini untuk mendapatkan perkiraan durasi cuti dalam rentang tersebut. Hasilnya 2 hari.

## Permintaan

### Informasi dasar

| Bidang | Nilai |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/v1.0/attendance/approvals/durations/calculate |
| Metode HTTP | POST |
| Tipe aplikasi yang didukung | appType-Aplikasi internal　appType-Aplikasi perusahaan pihak ketiga |
| Izin yang diperlukan | permission-qyapi_attendance_group_read-Izin kueri grup absensi |

### Header permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Dapatkan dengan cara berikut:   - Aplikasi internal: panggil API [Mendapatkan access token aplikasi internal](/id/open/development/obtain-the-access-token-of-an-internal-app). - Aplikasi perusahaan pihak ketiga: panggil API untuk mendapatkan access token organisasi yang telah memberikan otorisasi kepada Aplikasi pihak ketiga. |

### Parameter kueri

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| userId | String | Tidak | userId pengguna. |

### Isi permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| bizType | Long | Tidak | Tipe formulir persetujuan:   - 1: Lembur - 2: Perjalanan dinas - 3: Cuti |
| fromTime | String | Tidak | Waktu mulai. Waktu mulai tidak boleh lebih dari 31 hari sebelum waktu saat ini. Format yang didukung:   - 2019-08-15 - 2019-08-15 AM - 2019-08-15 12:43 |
| toTime | String | Tidak | Waktu selesai.   - Jika biz_type bernilai 1, selisih waktu selesai dengan waktu mulai tidak boleh lebih dari 1 hari. - Jika biz_type bernilai 2 atau 3, jumlah hari antara waktu mulai dan waktu selesai tidak boleh lebih dari 31.   Format yang didukung:   - 2019-08-15 - 2019-08-15 AM - 2019-08-15 12:43 |
| durationUnit | String | Tidak | Satuan durasi. Nilai yang didukung:   - day - halfDay - hour: Jika biz_type bernilai 1, hanya hour yang didukung.   Format waktu harus sesuai dengan satuan durasi:   - 2019-08-15 sesuai dengan day - 2019-08-15 AM sesuai dengan halfDay - 2019-08-15 12:43 sesuai dengan hour |
| calculateModel | Long | Tidak | Metode perhitungan:   - 0: Berdasarkan hari kalender - 1: Berdasarkan hari kerja |
| leaveCode | String | Tidak | Pengidentifikasi unik aturan cuti. Opsional. Hanya berlaku jika bizType=3 (cuti). Jika diisi, durasi dibulatkan sesuai aturan pembulatan yang dikonfigurasi untuk jenis cuti tersebut. |

| --- | --- | --- |
| result | Object | Hasil yang dikembalikan. |
| duration | double | Total durasi. Satuan bidang ini sama dengan satuan yang dikonfigurasi untuk formulir persetujuan terkait di organisasi Anda. |
| durationDetail | Array | Detail. |
| date | String | Tanggal. |
| duration | double | Durasi harian. Satuan bidang ini sama dengan satuan yang dikonfigurasi untuk formulir persetujuan terkait di organisasi Anda. |
| success | Boolean | Menunjukkan apakah panggilan API berhasil. |
