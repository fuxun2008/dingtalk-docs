---
title: "Mengatur lebar kolom secara massal"
description: "Panggil API ini untuk mengatur lebar beberapa kolom berurutan mulai dari kolom tertentu di DingTalk Spreadsheet sekaligus, cocok untuk penyesuaian massal agar sesuai tampilan konten atau tata letak cetak; nilai dibulatkan ke bilangan bulat positif."
---

Panggil API ini untuk mengatur lebar (dalam piksel) beberapa kolom berurutan di DingTalk Spreadsheet, mulai dari kolom tertentu. Fitur ini berguna saat Anda perlu menyesuaikan lebar kolom secara massal agar sesuai dengan tampilan konten atau tata letak cetak. Nilai lebar otomatis dibulatkan ke bilangan bulat positif, dan API mengembalikan informasi Lembar Kerja setelah operasi.

## Permintaan

### Informasi dasar

| Bidang | Nilai |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/doc/workbooks/{workbookId}/sheets/{sheetId}/setColumnsWidth` |
| Metode HTTP | POST |
| Jenis aplikasi yang didukung | appType-Aplikasi internal |
| Izin | permission-Document.Workbook.Write-Izin tulis DingTalk Spreadsheet |

### Header permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Untuk memperolehnya, panggil [Memperoleh access token aplikasi internal](/id/open/development/obtain-the-access-token-of-an-internal-app). |

### Parameter path

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| workbookId | String | Ya | ID file spreadsheet. `nodeId(dentryUuid)` yang dikembalikan oleh [API Knowledge Base](/id/open/development/knowledge-base-overview) adalah `workbookId` spreadsheet. Anda dapat memperolehnya dengan memanggil [Get node](https://open.dingtalk.com/document/development/get-node) atau [Membuat dokumen Knowledge Base](/id/open/development/create-team-space-document). |
| sheetId | String | Ya | ID atau judul Lembar Kerja. Panggil [Memperoleh semua Lembar Kerja](/id/open/development/obtain-all-worksheets) untuk memperoleh ID dan judul Lembar Kerja. |

### Parameter query

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| operatorId | String | Ya | unionId dari operator. Untuk memperolehnya, panggil [Kueri detail pengguna](/id/open/development/query-user-details). Jika operator tidak memiliki izin, API mengembalikan error `The operator has no permission`. |

### Isi permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| column | Integer | Ya | Indeks kolom pertama yang lebarnya akan diubah. Dimulai dari 0. |
| width | Integer | Ya | Lebar, dalam piksel. |
| columnCount | Integer | Ya | Jumlah kolom berurutan yang lebarnya akan diubah. |

### Contoh permintaan
