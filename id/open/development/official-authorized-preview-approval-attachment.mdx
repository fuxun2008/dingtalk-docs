Panggil API ini untuk memberikan otorisasi pratinjau lampiran persetujuan.

## Deskripsi panggilan API

<Note>
Gunakan API ini bersama JSAPI Drive.
</Note>

1. Dapatkan spaceId ruang Drive persetujuan. Panggil API [Dapatkan informasi ruang Drive persetujuan](/id/open/development/obtains-the-information-about-approval-nail-disk) untuk mendapatkan spaceId ruang Drive persetujuan.
2. Berdasarkan spaceId ruang Drive persetujuan, dapatkan informasi file lampiran Drive di aplikasi web (Aplikasi mikro H5) atau Mini program dengan mengunggah lampiran ke Drive atau memilih file dari Drive.
3. Dapatkan processInstanceId instans persetujuan. Panggil API [Buat instans persetujuan](/id/open/development/create-an-approval-instance) untuk mendapatkan nilai parameter InstanceId.
4. Gunakan informasi di atas untuk memanggil API ini guna memberikan izin pratinjau lampiran persetujuan kepada pengguna. Panggil API ini untuk otorisasi sebelum setiap pratinjau lampiran persetujuan.
5. Panggil API **Pratinjau file Drive** untuk menampilkan pratinjau file.

## Permintaan

### Informasi dasar

| Bidang | Nilai |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/v1.0/workflow/processInstances/spaces/authPreview |
| Metode HTTP | POST |
| Tipe aplikasi yang didukung | appType-Aplikasi internal　appType-Aplikasi perusahaan pihak ketiga |
| Persyaratan izin | permission-Workflow.Instance.Write-Izin tulis instans alur kerja |

### Header permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Cara mendapatkannya:   - Aplikasi internal: Panggil API [Dapatkan access token Aplikasi internal](/id/open/development/obtain-the-access-token-of-an-internal-app). - Aplikasi perusahaan pihak ketiga: Panggil API untuk mendapatkan access token organisasi yang diotorisasi oleh Aplikasi pihak ketiga. |

### Isi permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| userId | String | Ya | userId pengguna yang diberi otorisasi untuk melihat pratinjau lampiran. |
| agentId | Long | Tidak | agentId aplikasi:   - Aplikasi internal: Lihat informasi Agent ID. - Aplikasi perusahaan pihak ketiga: Panggil API untuk mendapatkan informasi otorisasi organisasi guna memperoleh nilai parameter `agentid`. |
| processInstanceId | String | Ya | ID instans persetujuan.   - Panggil API [Buat instans persetujuan](/id/open/development/create-an-approval-instance) untuk mendapatkan nilai parameter `InstanceId`. - Panggil API [Dapatkan daftar ID instans persetujuan](/id/open/development/obtain-an-approval-list-of-instance-ids) untuk mendapatkan nilai parameter `list`. |
| fileId | String | Ya | ID lampiran persetujuan.      fileId harus sama dengan fileId file pada komponen lampiran di instans persetujuan yang telah dibuat. Jika tidak, pesan error tanpa izin akan dikembalikan. |
| fileIdList | Array of String | Tidak | Daftar ID lampiran. Mendukung otorisasi massal. Panjang daftar maksimum adalah 20. |
| withCommentAttatchment | Boolean | Tidak | Apakah lampiran dalam komentar disertakan. Secara default, lampiran dalam komentar diabaikan. |
