Dokumen ini menjelaskan cara memanggil API obrolan grup untuk melakukan operasi obrolan grup. Pertama, buat aplikasi internal. Kemudian, gunakan API obrolan grup untuk membuat obrolan grup, mengambil informasi obrolan grup, mengelola obrolan grup, dan memodifikasi obrolan grup.

## Ikhtisar proses

Langkah 1: Dapatkan client ID dan Client Secret dari aplikasi.

Langkah 3: Dapatkan kredensial akses aplikasi dengan mengikuti [Mendapatkan access token dari aplikasi internal](/id/open/development/obtain-the-access-token-of-an-internal-app).

Langkah 4: Panggil API obrolan grup sisi server.

1. Panggil Server API untuk membuat obrolan grup guna membuat obrolan grup dan memperoleh `chatId`-nya.
2. Berdasarkan `chatId`, panggil Server API [Mengueri informasi obrolan grup](/id/open/development/obtain-a-group-session) untuk mengambil informasi obrolan grup.
3. Kelola obrolan grup menggunakan chatId-nya.

   - Berdasarkan `chatId`, panggil Server API baru [Mendapatkan OpenConversationId dari obrolan grup](/id/open/development/obtain-group-openconversationid) untuk memperoleh `openConversationId`.

     - Berdasarkan `openConversationId`, panggil Server API baru untuk menetapkan admin grup secara massal guna menetapkan admin grup secara massal.
   - Berdasarkan `chatId`, panggil Server API untuk memperbarui admin grup guna menetapkan admin grup.
   - Berdasarkan `chatId`, panggil Server API [Nonaktifkan Obrolan Pribadi](/id/open/development/set-private-chat) untuk mengontrol apakah anggota grup dapat mengobrol secara pribadi.
   - Berdasarkan `chatId`, panggil Server API [Memperbarui nama panggilan grup dari anggota grup](/id/open/development/set-a-group-nickname) untuk menetapkan nama panggilan anggota grup.
   - Berdasarkan `chatId`, panggil Server API [Mendapatkan tautan Kode QR untuk gabung obrolan](/id/open/development/obtain-a-qr-code-link). Pengguna lain di organisasi Anda dapat mengeklik tautan tersebut untuk meminta bergabung ke obrolan grup.
4. Berdasarkan `chatId`, panggil Server API untuk memperbarui obrolan grup guna memodifikasi informasi obrolan grup.

## Prasyarat

Selesaikan proses [Pembuatan dan konfigurasi aplikasi](/id/open/dingstart/create-application).

## Langkah 1: Dapatkan kredensial aplikasi

1. Pilih aplikasi target, buka halaman detail aplikasi, dan klik **Basic Information** > **Credentials and Basic Information**.
2. Dapatkan client ID dan Client Secret dari aplikasi.

## Langkah 2: Tambahkan izin API

Klik **Development Configuration** > **Manage Permissions**. Pada kotak pencarian izin, masukkan `qyapi_chat_manage`, `qyapi_chat_read`, dan `qyapi_chat_base_read` secara terpisah, lalu ajukan permintaan izin.

## Langkah 3: Dapatkan access token aplikasi

<Warning>
Untuk detail tentang perbedaan antar Server API, lihat Legacy API VS New API. Semua API berikut menggunakan Server API baru. Untuk detail unduhan SDK, lihat Server-side SDK download.
</Warning>

Berdasarkan client ID dan Client Secret yang diperoleh pada Langkah 1, dapatkan kredensial akses aplikasi dengan mengikuti [Mendapatkan access token dari aplikasi internal](/id/open/development/obtain-the-access-token-of-an-internal-app).

```java
 public void getAccessToken() throws Exception {
        Config config = new Config();
        config.protocol = "https";
        config.regionId = "central";
        com.aliyun.dingtalkoauth2_1_0.Client client = new com.aliyun.dingtalkoauth2_1_0.Client(config);
        GetAccessTokenRequest accessTokenRequest = new GetAccessTokenRequest()
                .setAppKey("din*********hgn")
                .setAppSecret("9G_O************mBkhgGIO");
        GetAccessTokenResponse accessToken = client.getAccessToken(accessTokenRequest);
        System.out.println(JSON.toJSONString(accessToken.getBody()));
    }
```
