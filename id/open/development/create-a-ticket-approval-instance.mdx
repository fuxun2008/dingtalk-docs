title: "Buat instans"
description: "Gunakan API DingTalk untuk membuat instans persetujuan tanpa alur kerja dengan kode templat, userId pengaju, dan kontrol formulir, lalu dapatkan ID instansnya."
---

Panggil API ini untuk membuat instans persetujuan tanpa alur kerja. Simpan ID instans persetujuan yang dikembalikan untuk digunakan dalam panggilan API berikutnya.

## Deskripsi panggilan API

Untuk mencegah data yang tidak valid dikirim ke open API, API ini menerapkan validasi yang lebih ketat terhadap data masuk.

- Untuk kontrol pilihan tunggal dan pilihan ganda, semua nilai opsi yang dikirim harus sudah dikonfigurasi dalam daftar opsi.
- Untuk kontrol kontak internal, userID yang dikirim harus milik anggota aktif organisasi saat ini.
- Untuk kontrol departemen, ID departemen harus berupa ID departemen yang valid di organisasi saat ini.
- Untuk kontrol formulir persetujuan terkait, ID instans yang dikirim harus berupa ID instans persetujuan yang sudah ada di organisasi saat ini.

Formulir persetujuan yang diajukan dengan melanggar aturan ini dapat gagal dibuat setelah validasi data formulir yang ditingkatkan mulai berlaku.

## Permintaan

### Informasi dasar

| Field | Nilai |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/v1.0/workflow/processCentres/instances |
| Metode HTTP | POST |
| Jenis aplikasi yang didukung | appType-Aplikasi internal　appType-Aplikasi perusahaan pihak ketiga |
| Izin yang diperlukan | permission-Workflow.Instance.Write-Izin tulis instans alur kerja |

### Header permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Dapatkan dengan cara berikut:   - Aplikasi internal: Panggil API [Dapatkan access token aplikasi internal](/id/open/development/obtain-the-access-token-of-an-internal-app). - Aplikasi perusahaan pihak ketiga: Panggil API untuk mendapatkan access token organisasi yang telah memberikan otorisasi kepada Aplikasi pihak ketiga. |

### Isi permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| processCode | String | Ya | Kode templat persetujuan. Panggil API [Dapatkan kode templat](/id/open/development/obtain-the-template-code) untuk memperoleh nilai processCode. |
| originatorUserId | String | Ya | userId pengaju instans persetujuan. |
| formComponentValueList | Array | Tidak | Daftar kontrol formulir. Untuk detailnya, lihat [Deskripsi parameter FormComponentValues](/id/open/development/oa-formcomponent-message). Jumlah elemen maksimum: 100.      API ini tidak mendukung **kontrol Lokasi** maupun **kontrol Telepon**. |
