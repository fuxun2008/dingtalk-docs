title: "Kueri status cuti"

---

Panggil API ini untuk mengkueri status cuti harian dan durasi cuti pengguna tertentu dalam organisasi tertentu pada rentang waktu yang ditentukan.

## Permintaan

| **Informasi dasar** | |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/topapi/attendance/getleavestatus |
| Metode HTTP | POST |
| Tipe aplikasi yang didukung | appType-Aplikasi internal　appType-Aplikasi perusahaan pihak ketiga |
| Izin yang diperlukan | permission-qyapi_get_attendance_data-Izin baca data absensi |

### Parameter kueri

| Nama | Tipe | Wajib | Contoh | Deskripsi |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | 6d1bxxxx | Kredensial aplikasi yang digunakan untuk memanggil API ini. Dapatkan dengan memanggil [Mendapatkan access_token Aplikasi internal](/id/open/development/obtain-orgapp-token). |

### Isi permintaan

| Nama | Tipe | Wajib | Contoh | Deskripsi |
| --- | --- | --- | --- | --- |
| userid_list | String | Ya | user456,user123 | Daftar ID pengguna yang akan dikueri. Maksimal 100 ID per permintaan. |
| start_time | Number | Ya | 1538323200000 | Waktu mulai, dalam format Unix timestamp. Rentang kueri maksimal 180 hari. |
| end_time | Number | Ya | 1546358399000 | Waktu berakhir, dalam format Unix timestamp. Rentang kueri maksimal 180 hari. |
| offset | Number | Ya | 0 | Offset paginasi, dimulai dari 0. Hanya berlaku jika diatur bersama parameter size. |
| size | Number | Ya | 10 | Ukuran halaman. Nilai maksimal: 20. Hanya berlaku jika diatur bersama parameter offset. |

### Contoh permintaan

```curl
curl -X POST "https://api.dingtalk.io/topapi/attendance/getleavestatus" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=11b9xxxxc35a' \
-d 'end_time=1546358399000' \
-d 'offset=0' \
-d 'size=10' \
-d 'start_time=1538323200000' \
-d 'userid_list=123%2C121'
```

## Respons

### Isi respons

| Nama | Tipe | Contoh | Deskripsi |
| --- | --- | --- | --- |
| errcode | Number | 0 | Kode pengembalian. |
| result | LeaveStatusListVO |  | Hasil kueri. |
| has_more | Boolean | true | Menunjukkan apakah masih ada data lainnya.   - **true**: Ya - **false**: Tidak |
| leave_status | LeaveStatusVO[] |  | Daftar status cuti. |
| duration_unit | String | percent_day | Satuan cuti:   - **percent_day**: Hari - **percent_hour**: Jam |
| duration_percent | Number | 100 | Durasi cuti dikalikan 100. Contoh: jika durasi cuti pengguna adalah 1 hari, nilai ini adalah 100. |
| end_time | Number | 1599465600000 | Waktu berakhir cuti, dalam format Unix timestamp. |
| start_time | Number | 1599372000000 | Waktu mulai cuti, dalam format Unix timestamp. |
| userid | String | user456 | ID pengguna. |
| success | Boolean | true | Menunjukkan apakah permintaan berhasil.   - **true**: Berhasil - **false**: Gagal |
| request_id | String | 5lbpbi9p1awk | ID permintaan. |
