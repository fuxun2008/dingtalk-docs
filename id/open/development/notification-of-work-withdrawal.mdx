Panggil API ini untuk menarik kembali pesan Notifikasi Kerja. Ini berlaku untuk skenario ketika sebuah aplikasi internal perlu menarik kembali pesan Notifikasi Kerja yang terkirim secara keliru.

## Deskripsi panggilan API

Anda hanya dapat menarik kembali pesan Notifikasi Kerja yang dikirim dalam 24 jam terakhir.

## Izin

Otorisasi Server API diberikan pada tingkat aplikasi. Saat Anda membuat sebuah aplikasi, izin Notifikasi pesan ditambahkan secara default.

| Jenis aplikasi | Didukung | Cara mengajukan | API Explorer Debug |
| --- | --- | --- | --- |
| Aplikasi internal | Didukung | Diaktifkan secara default. Tidak perlu pengajuan. | [Debug](https://open-dev.dingtalk.io/apiExplorer#/?devType=org&api=dingtalk.oapi.message.corpconversation.recall) |
| Aplikasi perusahaan pihak ketiga | Didukung | Diaktifkan secara default. Tidak perlu pengajuan. | [Debug](https://open-dev.dingtalk.io/apiExplorer#/?devType=isv&api=dingtalk.oapi.message.corpconversation.recall) |
| Aplikasi personal pihak ketiga | Tidak didukung | — | — |

## Permintaan

| **Informasi dasar** | |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/topapi/message/corpconversation/recall |
| HTTP Method | POST |
| Jenis aplikasi yang didukung | appType-Aplikasi internal, appType-Aplikasi perusahaan pihak ketiga |

### Parameter query

| Nama | Tipe | Wajib | Contoh | Deskripsi |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | bE74xxxx | Kredensial aplikasi yang digunakan untuk memanggil API ini.   - Untuk aplikasi internal, dapatkan dengan memanggil API untuk mendapatkan [access_token aplikasi internal](/id/open/development/obtain-orgapp-token). - Untuk aplikasi perusahaan pihak ketiga, dapatkan dengan memanggil API untuk mendapatkan access_token perusahaan pihak ketiga. |

### Isi permintaan

| Nama | Tipe | Wajib | Contoh | Deskripsi |
| --- | --- | --- | --- | --- |
| agent_id | Number | Ya | 836390886 | Agent ID dari Aplikasi mikro yang digunakan untuk mengirim pesan.   - Untuk aplikasi internal, Anda dapat menemukannya di halaman detail aplikasi pada [Developer Backend](https://open-dev.dingtalk.io/#/appMgr/inner/h5/836390886/1). - Untuk aplikasi perusahaan pihak ketiga, dapatkan dengan memanggil API untuk mendapatkan informasi otorisasi perusahaan. |
| msg_task_id | Number | Ya | 256271667526 | ID tugas yang dikembalikan oleh DingTalk saat pesan dikirim. Panggil API [Kirim Notifikasi Kerja](/id/open/development/asynchronous-sending-of-enterprise-session-messages) untuk mendapatkan nilai parameter task_id.  **Catatan**  Hanya pesan Notifikasi Kerja yang dikirim dalam 24 jam terakhir yang dapat ditarik kembali. |

### Contoh permintaan

```curl
curl -X POST "https://api.dingtalk.io/topapi/message/corpconversation/recall" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=404080xxxx4ab30' \
-d 'agent_id=1000' \
-d 'msg_task_id=2000'
```

Java

```text
DingTalkClient client = new DefaultDingTalkClient("https://api.dingtalk.io/topapi/message/corpconversation/recall");
OapiMessageCorpconversationRecallRequest req = new OapiMessageCorpconversationRecallRequest();
req.setAgentId(1000L);
req.setMsgTaskId(2000L);
OapiMessageCorpconversationRecallResponse rsp = client.execute(req, accessToken);
System.out.println(rsp.getBody());
```

## Respons

### Isi respons

| Nama | Tipe | Contoh | Deskripsi |
| --- | --- | --- | --- |
| errmsg | String | ok | Deskripsi kode pengembalian. |
| errcode | Number | 0 | Kode pengembalian. |

### Contoh isi respons

```json
{
  "errcode":0,
  "errmsg":"ok"
}
```

### Kode error

Jika terjadi error saat memanggil API ini, cari solusinya di dokumen [kode error global](/id/open/development/server-api-error-codes-1) menggunakan pesan error.

| Kode error (errorcode) | Deskripsi pesan error (errmsg) | Solusi |
| --- | --- | --- |
| 400002 | Invalid agentId or taskId | Pastikan agentId dan taskId sudah benar. |
| 500 | System error | Terjadi error sistem yang tidak diketahui. |
