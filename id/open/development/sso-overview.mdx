Login senyap memungkinkan pengguna mengakses aplikasi tanpa memasukkan nama pengguna dan kata sandi DingTalk. Aplikasi secara otomatis memperoleh identitas pengguna saat ini dan masuk ke sistem sebagai pengguna tersebut. Dengan Login senyap, developer dapat menghadirkan pengalaman autentikasi yang mulus serta meningkatkan kenyamanan dan keamanan pengguna.

## Target audiens

Dokumen ini ditujukan bagi developer jenis aplikasi berikut:

- **Aplikasi internal**: Aplikasi yang dikembangkan oleh sebuah organisasi hanya untuk digunakan oleh karyawannya sendiri.
- **Aplikasi perusahaan pihak ketiga (aplikasi ISV)**: Aplikasi SaaS yang dikembangkan oleh penyedia layanan pihak ketiga dan dipasang oleh banyak pelanggan perusahaan.
- **Sistem backend pengelolaan aplikasi**: Sistem konfigurasi dan pengelolaan yang diakses langsung oleh Admin Organisasi dari konsol admin DingTalk.

## Skenario Login senyap yang didukung

- Login senyap untuk aplikasi web (Aplikasi mikro H5)
- Login senyap untuk backend pengelolaan aplikasi
- Masuk ke aplikasi berbasis web (masuk ke situs web pihak ketiga)

  - Implementasi di dalam browser

    - Masuk dengan Pindai Kode QR
    - Masuk dengan akun dan kata sandi DingTalk

## Login senyap untuk Aplikasi internal

Ketika developer perusahaan membangun Aplikasi internal, karyawan dapat menggunakan aplikasi tersebut di dalam DingTalk dan masuk ke sistem secara otomatis tanpa memasukkan akun atau kata sandi.

Untuk langkah-langkah Login senyap, lihat Login senyap untuk aplikasi web (Aplikasi mikro H5).

| Langkah | Deskripsi |
| --- | --- |
| Langkah 1: Memperoleh authorization_code untuk Login senyap. | Pengembangan Mini program tidak didukung di PC. Untuk membangun aplikasi PC, gunakan pendekatan **Pengembangan Aplikasi mikro**. |
| Langkah 2: Memperoleh access_token. | Panggil API [Memperoleh access token Aplikasi internal](/id/open/development/obtain-the-access-token-of-an-internal-app). |
| Langkah 3: Memperoleh ID pengguna. | Panggil API [Memperoleh informasi pengguna menggunakan kode Login senyap](/id/open/development/obtain-the-userid-of-a-user-by-using-the-log-free) untuk memperoleh ID pengguna. |
| Langkah 4: Memperoleh detail pengguna. | Panggil API [Kueri detail pengguna](/id/open/development/query-user-details) untuk memperoleh detail pengguna. |

## Login senyap untuk backend pengelolaan aplikasi

Jika aplikasi Anda mengharuskan Admin Organisasi melakukan tugas konfigurasi dan pengelolaan di [konsol admin DingTalk](https://oa.dingtalk.io/), Anda perlu membangun sistem backend pengelolaan untuk aplikasi tersebut. Admin kemudian dapat mengeklik backend pengelolaan aplikasi langsung di [konsol admin DingTalk](https://oa.dingtalk.io/) dan masuk ke sistem backend Anda secara otomatis, tanpa memasukkan akun atau kata sandi.

Untuk langkah-langkah Login senyap, lihat Login senyap untuk backend pengelolaan aplikasi.

| Langkah | Deskripsi |
| --- | --- |
| Langkah 1: Memperoleh authorization_code untuk Login senyap. | Setelah Admin Organisasi masuk ke [konsol admin DingTalk](http://oa.dingtalk.io/) dan mengeklik aplikasi di **Workbench**, halaman dialihkan ke URL backend aplikasi, dan DingTalk menambahkan parameter `code` ke URL tersebut. Simpan nilai parameter `code` untuk digunakan pada langkah selanjutnya. |
| Langkah 2: Memperoleh access_token untuk Login senyap ke backend aplikasi. | Panggil API untuk memperoleh access token bagi Login senyap ke backend Aplikasi mikro, dan gunakan sebagai access_token untuk Login senyap ke backend aplikasi. |
| Langkah 3: Memperoleh informasi identitas Admin aplikasi. | Gunakan `code` yang diperoleh pada **Langkah 1** dan access_token yang diperoleh pada **Langkah 2** untuk menukarkannya dengan informasi identitas Admin aplikasi. Untuk detailnya, lihat Memperoleh informasi pengguna untuk Login senyap ke backend pengelolaan aplikasi. |
