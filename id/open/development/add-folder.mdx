Panggil API ini untuk menambahkan folder di dalam ruang penyimpanan.

## Deskripsi panggilan API

Setelah menambahkan ruang penyimpanan, panggil API ini untuk menambahkan folder di dalam ruang tersebut.

- Ketika tipe ruang penyimpanan adalah USER, semua pengguna yang memiliki izin pada ruang tersebut memiliki izin operasi. Karyawan lain harus memanggil API [Tambah izin](/id/open/development/add-permissions-file) untuk memberikan otorisasi.
- Ketika tipe ruang penyimpanan adalah APP, siapa pun yang melakukan operasi harus memanggil API [Tambah izin](/id/open/development/add-permissions-file) untuk memberikan otorisasi.

## Permintaan

### Informasi dasar

| Bidang | Nilai |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/storage/spaces/{spaceId}/dentries/{parentId}/folders` |
| Metode HTTP | POST |
| Tipe aplikasi yang didukung | appType-Aplikasi internal　appType-Aplikasi perusahaan pihak ketiga |
| Izin yang diperlukan | permission-Storage.File.Write-Izin tulis file penyimpanan organisasi |

### Header permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Dapatkan dengan cara berikut:   - Untuk aplikasi internal, panggil API [Dapatkan access token aplikasi internal](/id/open/development/obtain-the-access-token-of-an-internal-app#) untuk memperolehnya. - Untuk aplikasi perusahaan pihak ketiga, panggil API [Dapatkan access token perusahaan yang diberi otorisasi ke aplikasi pihak ketiga](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#) untuk memperolehnya. |

### Parameter jalur

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| spaceId | String | Ya | ID ruang. Panggil API [Tambah ruang](/id/open/development/add-space#) untuk memperoleh nilai parameter id. |
| parentId | String | Ya | ID direktori induk. Panggil API [Dapatkan daftar file atau folder](https://open.dingtalk.com/document/development/obtain-the-file-list-storage#) untuk memperolehnya. Untuk direktori root, atur parameter ini ke 0. |

### Parameter kueri

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| unionId | String | Ya | unionId operator. Panggil API [Kueri detail pengguna](/id/open/development/query-user-details#) untuk memperolehnya. |

### Isi permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| name | String | Ya | Nama folder. Persyaratan penamaan:- Tidak boleh ada spasi di awal atau akhir. Jika ada, spasi tersebut akan dihapus secara otomatis. - Tidak boleh mengandung karakter khusus, termasuk: tab, `*`, `"`, `<`, `>`, `|`. - Tidak boleh diakhiri dengan `.`. |
| option | Object | Tidak | Parameter opsional. |
| conflictStrategy | String | Tidak | Strategi konflik untuk nama folder.   - **AUTO_RENAME**: Ganti nama secara otomatis. Nilai default. - **OVERWRITE**: Timpa. - **RETURN_DENTRY_IF_EXISTS**: Kembalikan folder yang sudah ada. - **RETURN_ERROR_IF_EXISTS**: Kembalikan error jika folder sudah ada. |
| appProperties | Array | Tidak | Daftar properti aplikasi untuk folder saat ini. Nilai maksimum: 3. |
| name | String | Ya | Nama properti. |
| value | String | Ya | Nilai properti. |
| visibility | String | Ya | Visibilitas properti.   - **PUBLIC**: Terlihat oleh semua aplikasi. - **PRIVATE**: Hanya terlihat oleh aplikasi saat ini. |
