Panggil API ini untuk menarik kembali pesan grup internal yang dikirim oleh bot perusahaan. Fitur ini berguna untuk menarik kembali pesan bot obrolan grup yang salah kirim secara massal.

## Permintaan

### Informasi dasar

| Bidang | Nilai |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/v1.0/robot/groupMessages/recall |
| Metode HTTP | POST |
| Tipe aplikasi yang didukung | appType-Aplikasi internal　appType-Aplikasi perusahaan pihak ketiga |
| Izin yang diperlukan | permission-qyapi_robot_sendmsg-Izin bagi bot untuk mengirim pesan di dalam organisasi Anda |

### Header permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Dapatkan sebagai berikut:   - Untuk aplikasi internal, panggil API [Dapatkan access token aplikasi internal](/id/open/development/obtain-the-access-token-of-an-internal-app#). - Untuk aplikasi perusahaan pihak ketiga, panggil API [Dapatkan access token perusahaan yang diberi otorisasi untuk aplikasi pihak ketiga](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#). |

### Isi permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| openConversationId | String | Ya | ID grup. Dapatkan openConversationId obrolan grup di sisi klien melalui [chooseChat](https://open.dingtalk.com/document/development/jsapi-choose-chat#).  Nilai ini harus cocok dengan openConversationId yang digunakan saat memanggil API [Kirim pesan obrolan grup dengan bot](/id/open/development/the-robot-sends-a-group-message#). |
| robotCode | String | Ya | Kode bot. Lihat [ID Bot](https://open.dingtalk.com/document/development/robot-overview#) untuk detailnya.  Nilai ini harus cocok dengan robotCode yang digunakan saat memanggil API [Kirim pesan obrolan grup dengan bot](/id/open/development/the-robot-sends-a-group-message#). |
| processQueryKeys | Array of String | Ya | Daftar ID pesan. Dapatkan nilai-nilai ini dari bidang processQueryKey yang dikembalikan oleh API [Kirim pesan obrolan grup dengan bot](/id/open/development/the-robot-sends-a-group-message#). |
