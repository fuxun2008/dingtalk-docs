---
title: "Mendapatkan detail pengguna Akun Perusahaan dalam suatu departemen"
description: "Panggil API ini untuk mendapatkan detail pengguna Akun Perusahaan dalam departemen tertentu di DingTalk, tidak termasuk sub-departemen. Hanya untuk organisasi yang telah mengaktifkan Akun Perusahaan."
---

Panggil API ini untuk mendapatkan detail karyawan dalam departemen tertentu. Karyawan di sub-departemen tidak dapat diambil. API ini saat ini hanya tersedia untuk organisasi yang telah membeli dan mengaktifkan Akun Perusahaan.

## Permintaan

| **Informasi dasar** | |
| --- | --- |
| URL HTTP | https://oapi.dingtalk.io/topapi/v2/user/list |
| Metode HTTP | POST |
| Tipe aplikasi yang didukung | appType-Aplikasi internal, appType-Aplikasi perusahaan pihak ketiga |
| Izin yang diperlukan | permission-qyapi_get_department_member-Izin baca anggota departemen Kontak |

### Parameter query

| Nama | Tipe | Wajib | Contoh | Deskripsi |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | be3Fxxxx | Kredensial aplikasi yang digunakan untuk memanggil API ini.   - Untuk aplikasi internal, dapatkan melalui API untuk mendapatkan access_token aplikasi internal. - Untuk aplikasi perusahaan pihak ketiga, dapatkan melalui API untuk mendapatkan access_token perusahaan pihak ketiga. |

### Isi permintaan

| Nama | Tipe | Wajib | Contoh | Deskripsi |
| --- | --- | --- | --- | --- |
| dept_id | Number | Ya | 10 | ID departemen. Panggil API [Mendapatkan daftar departemen](/id/open/development/user-management-acquires-the-list-departments) untuk memperoleh nilai dept_id.  **Catatan**   - Hanya karyawan di departemen saat ini yang dikembalikan. Karyawan di sub-departemen tidak termasuk. - Untuk departemen root, isi dengan 1. |
| cursor | Number | Ya | 0 | Cursor untuk paginasi. Isi dengan 0 untuk panggilan pertama, lalu isi dengan nilai next_cursor yang dikembalikan pada panggilan berikutnya. |
| size | Number | Ya | 10 | Ukuran halaman. |
| order_field | String | Tidak | modify_desc | Aturan pengurutan untuk anggota departemen. Jika parameter ini tidak diisi, hasil diurutkan berdasarkan urutan kustom (custom) secara default.   - **entry_asc**: Urutkan berdasarkan waktu bergabung ke departemen secara menaik. - **entry_desc**: Urutkan berdasarkan waktu bergabung ke departemen secara menurun. - **modify_asc**: Urutkan berdasarkan waktu modifikasi informasi departemen secara menaik. - **modify_desc**: Urutkan berdasarkan waktu modifikasi informasi departemen secara menurun. - **custom**: Urutkan berdasarkan urutan yang ditentukan pengguna (berdasarkan pinyin jika tidak ditentukan). |
| contain_access_limit | Boolean | Tidak | false | Apakah mengembalikan karyawan dengan pembatasan akses:   - true: Kembalikan. - false: Jangan kembalikan. |
| language | String | Tidak | zh_CN | Bahasa untuk Kontak.   - **zh_CN**: Bahasa Mandarin (default). - **en_US**: Bahasa Inggris. |

### Contoh permintaan

```curl
curl -X POST "https://oapi.dingtalk.io/topapi/v2/user/list" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=8d4de2xxxx49c' \
-d 'contain_access_limit=false' \
-d 'cursor=0' \
-d 'dept_id=10' \
-d 'language=zh_CN' \
-d 'order_field=modify_desc' \
-d 'size=10'
```

Java

```text
DingTalkClient client = new DefaultDingTalkClient("https://oapi.dingtalk.io/topapi/v2/user/list");
OapiV2UserListRequest req = new OapiV2UserListRequest();
req.setDeptId(10L);
req.setCursor(0L);
req.setSize(10L);
req.setOrderField("modify_desc");
req.setContainAccessLimit(false);
req.setLanguage("zh_CN");
OapiV2UserListResponse rsp = client.execute(req, access_token);
System.out.println(rsp.getBody());
```


### Kode error

Jika error dikembalikan saat memanggil API ini, temukan solusinya di dokumen [Kode error global](/id/open/development/server-api-error-codes-1) berdasarkan pesan error.

| Kode error (errcode) | Pesan error (errmsg) | Solusi |
| --- | --- | --- |
| 400002 | Invalid parameter | Periksa apakah parameter telah diisi sesuai ketentuan. |
| 50004 | The department is not within the permission scope | Pastikan access_token memiliki izin operasi. |
| 40035 | Invalid parameter | dept_id, cursor, size, atau order_field diisi dengan tidak benar. |
| 60019 | Failed to get users from the department | Pastikan parameter terkait diisi dengan benar. |
| -1 | System busy | Coba lagi nanti. |
