---
title: "Dapatkan grup absensi pengguna"
description: "Panggil API DingTalk ini untuk mengambil grup absensi karyawan berdasarkan ID pengguna, termasuk nama grup, ID, tipe absensi, dan detail shift."
---

Panggil API ini untuk mendapatkan informasi grup absensi karyawan, termasuk nama grup absensi dan tipe absensi. Dalam satu organisasi, seorang karyawan hanya dapat menjadi anggota satu grup absensi.

## Permintaan

| **Informasi dasar** | |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/topapi/attendance/getusergroup |
| Metode HTTP | POST |
| Tipe aplikasi yang didukung | appType-Aplikasi internal　appType-Aplikasi perusahaan pihak ketiga |
| Persyaratan izin | permission-qyapi_base-Izin dasar yang diperlukan untuk memanggil API organisasi |

### Parameter query

| Nama | Tipe | Wajib | Contoh | Deskripsi |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | bE74xxxx | Kredensial aplikasi yang digunakan untuk memanggil API ini.   - Untuk Aplikasi internal, dapatkan dengan memanggil API [Dapatkan access_token Aplikasi internal](/id/open/development/obtain-orgapp-token). - Untuk Aplikasi perusahaan pihak ketiga, dapatkan dengan memanggil API Dapatkan access_token Aplikasi perusahaan pihak ketiga. |

### Isi permintaan

| Nama | Tipe | Wajib | Contoh | Deskripsi |
| --- | --- | --- | --- | --- |
| userid | String | Ya | user123 | ID pengguna karyawan di organisasi Anda. |

### Contoh permintaan

```curl
curl -X POST "https://api.dingtalk.io/topapi/attendance/getusergroup" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=04cd6xxxx91f77' \
-d 'userid=zhangsan'
```

Java

```java
DingTalkClient client = new DefaultDingTalkClient("https://api.dingtalk.io/topapi/attendance/getusergroup");
OapiAttendanceGetusergroupRequest req = new OapiAttendanceGetusergroupRequest();
req.setUserid("user123");
OapiAttendanceGetusergroupResponse rsp = client.execute(req, access_token);
System.out.println(rsp.getBody());
```

Python

```python
import dingtalk.api

req=dingtalk.api.OapiAttendanceGetusergroupRequest("https://api.dingtalk.io/topapi/attendance/getusergroup")

req.userid="zhangsan"
try:
  resp= req.getResponse(access_token)
  print(resp)
except Exception,e:
  print(e)
```

PHP

```php
include "TopSdk.php";
date_default_timezone_set('Asia/Shanghai');

$c = new DingTalkClient(DingTalkConstant::$CALL_TYPE_OAPI, DingTalkConstant::$METHOD_POST , DingTalkConstant::$FORMAT_JSON);
$req = new OapiAttendanceGetusergroupRequest;
$req->setUserid("zhangsan");
$resp = $c->execute($req, $access_token, "https://api.dingtalk.io/topapi/attendance/getusergroup");
```

C#

```csharp
IDingTalkClient client = new DefaultDingTalkClient("https://api.dingtalk.io/topapi/attendance/getusergroup");
OapiAttendanceGetusergroupRequest req = new OapiAttendanceGetusergroupRequest();

OapiAttendanceGetusergroupResponse rsp = client.Execute(req, access_token);
Console.WriteLine(rsp.Body);
```

## Respons

### Isi respons

| Nama | Tipe | Contoh | Deskripsi |
| --- | --- | --- | --- |
| result | AtGroupFullForTopVo |  | Hasil query. |
| name | String | Absensi | Nama grup absensi. |
| group_id | Number | 685935028 | ID grup absensi.  **Catatan**  Jika Anda menggunakan pengenal grup absensi lama **group_key**, panggil API [Konversi groupKey ke groupId](/id/open/development/convert-groupkey-to-groupid) untuk mengonversi **group_key** menjadi **group_id**. |
| type | String | TURN | Tipe absensi:   - **FIXED**: Penjadwalan shift tetap - **TURN**: Penjadwalan shift bergilir - **NONE**: Tanpa shift |
| classes | AtClassVo[] |  | Daftar shift dalam grup absensi. |
| class_id | Number | 678215070 | ID shift. |
| name | String | Shift A | Nama shift. |
| sections | AtSectionVo[] |  | Daftar sesi masuk dan pulang kerja dalam shift. |
| times | AtTimeVo[] |  | Daftar detail masuk dan pulang kerja dalam shift. |
| check_time | Date | 1970-01-01 19:00:00 | Waktu absen. |
| check_type | String | OnDuty | Tipe absen:   - **OnDuty**: Masuk kerja - **OffDuty**: Pulang kerja |
| across | Number | 0 | Jumlah hari yang dilintasi oleh waktu absen. |
| begin_min | Number | 30 | Batas paling awal absen sebelum waktu terjadwal, dalam menit. |
| end_min | Number | 0 | Batas paling lambat absen setelah waktu terjadwal, dalam menit. |
| setting | ClassSettingVo |  | Konfigurasi shift. |
| rest_begin_time | AtTimeVo |  | Pengaturan waktu mulai istirahat. |
| across | Number | 0 | Rentang waktu.   - **0**: Tidak melintasi hari - **1**: Melintasi hari |
| begin_min | Number | 0 | Waktu mulai. |
| end_min | Number | 0 | Waktu selesai. |
| check_time | Date | 1970-01-01 19:00:00 | Waktu mulai istirahat. |
| check_type | String | OnDuty | Tipe pengaturan:   - **OnDuty**: Mulai istirahat - **OffDuty**: Selesai istirahat |
| rest_end_time | AtTimeVo |  | Pengaturan waktu selesai istirahat. |
| across | Number | 0 | Rentang waktu. |
| begin_min | Number | 0 | Waktu mulai. |
| end_min | Number | 0 | Waktu selesai. |
| check_time | Date | 1970-01-01 20:00:00 | Waktu selesai istirahat. |
| check_type | String | OffDuty | Tipe absen:   - **OnDuty**: Mulai istirahat - **OffDuty**: Selesai istirahat |
| errcode | Number | 0 | Kode respons. |
| errmsg | String | ok | Deskripsi kode respons. |
| request_id | String | f8zybbfze3e8 | ID permintaan. |
