Panggil API ini untuk mendapatkan daftar ID semua departemen induk dari departemen tertentu. API ini tidak dibatasi oleh cakupan izin Kontak.

## Permintaan

| **Informasi dasar** | |
| --- | --- |
| URL HTTP | https://oapi.dingtalk.io/topapi/v2/department/listparentbydept |
| Metode HTTP | POST |
| Tipe aplikasi yang didukung | appType-Aplikasi internal, appType-Aplikasi perusahaan pihak ketiga |
| Izin yang diperlukan | permission-qyapi_get_department_list-Izin baca untuk informasi departemen Kontak |

### Parameter kueri

| Nama | Tipe | Wajib | Contoh | Deskripsi |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | bE74xxxx | Kredensial aplikasi yang digunakan untuk memanggil API ini.   - Untuk aplikasi internal, dapatkan melalui API untuk mendapatkan access_token aplikasi internal. - Untuk aplikasi perusahaan pihak ketiga, dapatkan melalui API untuk mendapatkan access_token perusahaan pihak ketiga. |

### Isi permintaan

| Nama | Tipe | Wajib | Contoh | Deskripsi |
| --- | --- | --- | --- | --- |
| dept_id | Number | Ya | 42xxxx36 | ID departemen yang akan dikueri. Panggil API [Mendapatkan daftar departemen](/id/open/development/user-management-acquires-the-list-departments) untuk memperoleh nilai dept_id. |

### Contoh permintaan

```curl
curl -X POST "https://oapi.dingtalk.io/topapi/v2/department/listparentbydept" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=a456xxxx13da5' \
-d 'dept_id=100'
```

## Respons

### Isi respons

| Nama | Tipe | Contoh | Deskripsi |
| --- | --- | --- | --- |
| request_id | String | 10u9dj0853fwe | ID permintaan. |
| errcode | Number | 0 | Kode pengembalian. |
| errmsg | String | Invalid department ID | Pesan error yang dikembalikan saat panggilan gagal. |
| result | DeptListParentByDeptIdResponse |  | Daftar ID departemen induk. |
| parent_id_list | Number[] | [789, 456, 123, 1] | Daftar ID semua departemen induk dari departemen tersebut.  **Catatan**  Dalam daftar yang dikembalikan, elemen pertama adalah ID departemen saat ini, dan elemen terakhir adalah ID departemen induk tingkat teratas. Tingkat departemen meningkat dari kiri ke kanan. |

### Contoh isi respons

```json
{
  "errcode": 0,
  "errmsg": "ok",
  "result": {
    "parent_id_list": [
      42xxxx36,
      1
    ]
  },
  "request_id": "ov7bc964j9pe"
}
```

### Kode error

Jika terjadi error saat Anda memanggil API ini, lihat dokumen [Kode error global](/id/open/development/server-api-error-codes-1) untuk menemukan solusi berdasarkan pesan error.

| Kode error (errcode) | Pesan error (errmsg) | Solusi |
| --- | --- | --- |
| 43007 | Authorization required | Pastikan access_token memiliki izin yang diperlukan. |
| 60003 | Department not found | Pastikan dept_id sudah benar. |
| 400002 | Invalid parameter | Pastikan parameter dimasukkan sesuai ketentuan. |
| -1 | System busy | Coba lagi nanti. |
