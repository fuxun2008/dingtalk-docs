Panggil API ini untuk memperbarui status tugas tertentu di Pusat Proses.

## Permintaan

### Informasi dasar

| Bidang | Nilai |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/v1.0/workflow/processCentres/tasks |
| Metode HTTP | PUT |
| Tipe aplikasi yang didukung | appType-Aplikasi internal　appType-Aplikasi perusahaan pihak ketiga |
| Izin | permission-qyapi_aflow-Izin manajemen data alur kerja persetujuan |

### Header permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Dapatkan dengan cara berikut:   - Aplikasi internal: Panggil API [Mendapatkan access token aplikasi internal](/id/open/development/obtain-the-access-token-of-an-internal-app). - Aplikasi perusahaan pihak ketiga: Panggil API untuk mendapatkan access token organisasi yang telah memberikan otorisasi kepada aplikasi pihak ketiga. |

### Isi permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| processInstanceId | String | Tidak | ID instans alur kerja Persetujuan OA. Panggil API [Membuat instans](/id/open/development/create-a-ticket-approval-instance) untuk mendapatkan nilai `processInstanceId`. |
| tasks | Array | Ya | Daftar tugas Persetujuan OA. Maksimum: 20 tugas. |
| taskId | Long | Ya | ID tugas Persetujuan OA. Panggil API [Mengkueri tugas Persetujuan OA yang terintegrasi melalui Pusat Proses](/id/open/development/query-oa-approval-tasks-integrated-through-process-center) untuk mendapatkan nilai taskId. |
| status | String | Ya | Status tugas target:   - **CANCELED**: Urungkan - **COMPLETED**: Selesai |
| result | String | Tidak | Hasil tugas.   - Jika status bernilai **COMPLETED**, tentukan hasil tugas:    - **AGREE**: Terima   - **REFUSE**: Tolak - Jika status bernilai **CANCELED**, jangan kirim result. |
