Panggil API ini untuk menyisipkan elemen block pada lokasi tertentu.

## Deskripsi panggilan API

Untuk mempelajari struktur data yang terkait dengan konten dokumen, lihat [Struktur data dokumen](/id/open/development/document-data-structure).

## Permintaan

### Informasi dasar

| Bidang | Nilai |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/doc/suites/documents/{docKey}/blocks` |
| Metode HTTP | POST |
| Jenis aplikasi yang didukung | appType-Aplikasi internal |
| Izin yang diperlukan | permission-Storage.File.Write-Izin tulis file penyimpanan organisasi |

### Header permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Dapatkan dengan memanggil API [Memperoleh access token aplikasi internal](/id/open/development/obtain-the-access-token-of-an-internal-app). |

### Parameter jalur

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| docKey | String | Ya | ID dokumen (`docKey` atau `dentryUuid` dari dokumen). Setelah membuat dokumen dengan memanggil API [Membuat dokumen Knowledge Base](/id/open/development/create-team-space-document), dapatkan parameter `docKey` dari respons. Untuk memperoleh `dentryUuid` dari URL dokumen, ambil contoh https://docs.dingtalk.io/i/nodes/Zxxxxa-id. `dentryUuid`-nya adalah `Zxxxxa-id`. |

### Parameter kueri

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| operatorId | String | Ya | unionId pengguna. Dapatkan parameter `unionid` dengan memanggil API [Mengueri detail pengguna](/id/open/development/query-user-details). |

### Isi permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| blockId | String | Tidak | Identifier unik dari block target. Dapatkan parameter `blockId` dengan memanggil API [Mengueri elemen block](/id/open/development/api-docblocksquery). Jika tidak ditentukan, nilai `index` yang digunakan. |
| index | Integer | Tidak | Ketika `blockId` tidak diberikan, `index` digunakan untuk menentukan lokasi block target. Sistem mencoba menemukan block pada posisi `index` di antara elemen block tingkat pertama dokumen, dengan `index` dimulai dari 0. Jika tidak ditentukan, akhir dokumen digunakan secara default. |
| where | String | Tidak | Apakah menyisipkan sebelum atau sesudah lokasi target. Nilai yang valid: - **after**: Sisipkan setelah lokasi target. Ini adalah nilai default. - **before**: Sisipkan sebelum lokasi target. |
| element | `Map<String, Any>` | Ya | Tipe BlockElement yang akan disisipkan dan atribut yang diperlukan untuk membuat tipe terkait (lihat [Struktur data elemen block](/id/open/development/block-data-structure) untuk detailnya). Strukturnya adalah sebagai berikut: ``` {   "blockType": enum(BlockType),   [blockType]: Object(CreateElementProperties), } ``` |
|  | Any | Tidak | Berisi tipe elemen dan informasi yang diperlukan untuk membuat elemen. |

### Contoh permintaan

  }
