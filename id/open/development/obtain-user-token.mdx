## Kasus penggunaan

API ini mendapatkan `accessToken` pengguna dan merupakan langkah kunci dalam menerapkan autentikasi identitas pengguna. Kasus penggunaan umum meliputi:

- Setelah pengguna masuk, tukarkan authorization code (`code`) dengan kredensial akses yang valid.
- Sebelum `accessToken` kedaluwarsa, gunakan `refreshToken` untuk memperbaruinya secara otomatis dan menghindari otorisasi ulang yang berulang.
- Aplikasi perusahaan pihak ketiga terintegrasi dengan sistem sign-in terpadu DingTalk untuk menerapkan Single Sign-On (SSO).
- Aplikasi perusahaan memanggil API terlindungi atas nama pengguna dari layanan backend-nya.

Developer harus mengelola siklus hidup `accessToken` dengan baik. Kami menyarankan untuk menyimpannya di cache secara lokal dan menyiapkan mekanisme refresh otomatis untuk memastikan panggilan API yang stabil.

<Note>
Saat menggunakan access token, perhatikan hal berikut:
</Note>

- `accessToken` berlaku selama 7.200 detik (2 jam). Permintaan berulang dalam periode validitas mengembalikan hasil yang sama dan memperbaruinya secara otomatis. Setelah kedaluwarsa, `accessToken` baru akan dikembalikan.
- `accessToken` setiap aplikasi bersifat independen. Simpan token di cache per aplikasi untuk menghindari kebingungan.

## Permintaan

| **Informasi dasar** | |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/v1.0/oauth2/userAccessToken |
| Metode HTTP | POST |
| Tipe aplikasi yang didukung | appType-Internal app appType-Third-party enterprise app appType-Third-party personal app |
| Izin yang diperlukan | permission-open_app_api_base-Basic permission to obtain user access credentials for DingTalk Open APIs |

### Isi permintaan

| Nama | Tipe | Wajib | Contoh | Deskripsi |
| --- | --- | --- | --- | --- |
| clientId | String | Ya | dingxxx | ID aplikasi. Anda dapat menggunakan AppId dari aplikasi sign-in Pindai Kode QR atau mini program personal pihak ketiga.   - Untuk aplikasi internal, kirimkan **AppKey** aplikasi. - Untuk aplikasi perusahaan pihak ketiga, kirimkan **SuiteKey** aplikasi. - Untuk aplikasi personal pihak ketiga, kirimkan **AppId** aplikasi. |
| clientSecret | String | Ya | 1234 | App secret.   - Untuk aplikasi internal, kirimkan **AppSecret** aplikasi. - Untuk aplikasi perusahaan pihak ketiga, kirimkan **SuiteSecret** aplikasi. - Untuk aplikasi personal pihak ketiga, kirimkan **AppSecret** aplikasi. |
| code | String | Tidak | abcd | Authorization code sementara OAuth 2.0. Aplikasi perusahaan pihak ketiga harus terintegrasi dengan suite otorisasi terpadu atau [Mendapatkan kredensial akses pengguna yang telah masuk](/id/open/development/obtain-identity-credentials) untuk mendapatkan authorization code sementara `authCode`. |
| refreshToken | String | Tidak | abcd | Refresh token OAuth 2.0, diperoleh dari respons API sebelumnya. Berlaku selama 30 hari. |
| grantType | String | Ya | authorization_code | - Untuk menukar authorization code dengan token, kirimkan `authorization_code`. Dalam hal ini, parameter `code` wajib diisi. - Untuk menukar refresh token dengan token baru, kirimkan `refresh_token`. Dalam hal ini, parameter `refreshToken` wajib diisi. |

### Contoh permintaan

```curl
curl -X POST 'https://api.dingtalk.io/v1.0/oauth2/userAccessToken' \
  -H 'Content-Type: application/json' \
  -d '{
    "clientId": "dingxxx",
    "clientSecret": "1234",
    "code": "abcd",
    "refreshToken": "abcd",
    "grantType": "authorization_code"
  }'
```

## Respons

### Isi respons

| Nama | Tipe | Contoh | Deskripsi |
| --- | --- | --- | --- |
| accessToken | String | abcd | accessToken yang dihasilkan, digunakan untuk autentikasi pada panggilan API berikutnya. |
| refreshToken | String | abcd | refresh_token yang dihasilkan. Gunakan refresh token ini untuk secara berkala mendapatkan accessToken pengguna. |
| expireIn | Long | 7200 | Waktu kedaluwarsa, dalam detik. |
| corpId | String | corpxxxx | ID organisasi dari organisasi yang dipilih. |

### Contoh respons

```text

Content-Type:application/json

  "accessToken" : "abcd",
  "refreshToken" : "abcd",
  "expireIn" : 7200,
  "corpId" : "corpxxxx"
}
```
