## LinkSourceInfo

Informasi data asli yang ditunjuk oleh sebuah tautan.

| Nama | Tipe | Contoh | Deskripsi |
| --- | --- | --- | --- |
| id | String | abc | ID dari file sumber yang terkait dengan pintasan (unik di dalam ruang). |
| spaceId | String | def | ID dari ruang tempat file sumber yang terkait dengan pintasan berada. |
| linkType | Long | 0 | Tipe pintasan.   - 0: pintasan umum - 1: pintasan Rapat Cepat - 2: pintasan log - 3: pintasan Rapat Cepat 2.0 |
| extension | String | docx | Ekstensi dari file sumber yang terkait dengan pintasan. |
| iconUrl | Object |  | Informasi ikon untuk pintasan non-umum. |
| small | String | def | Ikon yang disorot saat dipilih. |
| line | String | gh | Ikon daftar isi default. |
