Panggil API ini untuk menghapus kontrol akses.

## Permintaan

### Informasi dasar

| Bidang | Nilai |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/calendar/users/{userId}/calendars/{calendarId}/acls/{aclId}` |
| Metode HTTP | DELETE |
| Tipe aplikasi yang didukung | appType-Aplikasi internal　appType-Aplikasi personal pihak ketiga |
| Izin yang diperlukan | permission-Calendar.Acl.Write-Izin tulis untuk kontrol akses aplikasi Kalender |

### Header permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Dapatkan dengan cara berikut:   - Untuk aplikasi internal, panggil API [Mendapatkan access token aplikasi internal](/id/open/development/obtain-the-access-token-of-an-internal-app#). - Untuk aplikasi personal pihak ketiga, panggil API [Mendapatkan user token](/id/open/development/obtain-user-token#). |

### Parameter path

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| userId | String | Ya | unionId penyelenggara acara.   - Untuk aplikasi internal, panggil API [Kueri detail pengguna](/id/open/development/query-user-details#) untuk mendapatkan nilai unionid. - Untuk aplikasi personal pihak ketiga, panggil API [Mendapatkan profil dari kontak pengguna](/id/open/development/dingtalk-retrieve-user-information#) untuk mendapatkan nilai unionId. |
| calendarId | String | Ya | ID kalender tempat acara berada. Atur ke **primary**, yang menunjukkan kalender utama pengguna. |
| aclId | String | Ya | ID sumber daya izin. Panggil API [Mendapatkan daftar kontrol akses](/id/open/development/obtain-the-access-control-list-of-the-calendar#) untuk mendapatkan nilai aclId. |
