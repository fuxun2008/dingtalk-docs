Panggil API ini untuk menambahkan elemen inline ke akhir paragraf tertentu. Tipe elemen inline yang didukung meliputi Stiker, Gambar, dan Tautan.

## Deskripsi panggilan API

Untuk detail struktur data yang terkait dengan konten dokumen, lihat [Struktur data dokumen](/id/open/development/document-data-structure).

## Permintaan

### Informasi dasar

| Bidang | Nilai |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/doc/suites/documents/{docKey}/blocks/{blockId}/paragraph/appendElement` |
| Metode HTTP | POST |
| Jenis aplikasi yang didukung | appType-Aplikasi internal |
| Izin yang diperlukan | permission-Storage.File.Write-Izin tulis file penyimpanan organisasi |

### Header permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Dapatkan dengan memanggil API [Memperoleh access token aplikasi internal](/id/open/development/obtain-the-access-token-of-an-internal-app). |

### Parameter path

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| docKey | String | Ya | ID Dokumen (`docKey` atau `dentryUuid` dari dokumen). Setelah membuat dokumen dengan memanggil API [Membuat dokumen Knowledge Base](/id/open/development/create-team-space-document), dapatkan parameter `docKey` dari respons. Untuk memperoleh `dentryUuid` dari URL dokumen, ambil contoh https://docs.dingtalk.io/i/nodes/Zxxxxa-id: `dentryUuid` adalah `Zxxxxa-id`. |
| blockId | String | Ya | Pengidentifikasi unik dari paragraf target. Dapatkan parameter `blockId` dengan memanggil API [Mengkueri elemen block](/id/open/development/api-docblocksquery). |

### Parameter query

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| operatorId | String | Ya | unionId dari pengguna. Dapatkan nilai parameter `unionid` dengan memanggil API [Mengkueri detail pengguna](/id/open/development/query-user-details). |

### Isi permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| elementType | String | Ya | Tipe elemen inline. Untuk detail, lihat tipe elemen inline di [Struktur data elemen block](/id/open/development/block-data-structure). |
| properties | `Map<String, Any>` | Ya | Properti yang diperlukan untuk membuat elemen inline dari `elementType` yang bersangkutan. |
|  | Any | Tidak | Nilai properti. |
