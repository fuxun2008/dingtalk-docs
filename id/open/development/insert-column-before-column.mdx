Panggil API ini untuk menyisipkan satu atau beberapa kolom di sebelah kiri kolom tertentu.

## Permintaan

### Informasi dasar

| Bidang | Nilai |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/doc/workbooks/{workbookId}/sheets/{sheetId}/insertColumnsBefore` |
| Metode HTTP | POST |
| Tipe aplikasi yang didukung | appType-Internal app　appType-Third-party enterprise app |
| Izin yang diperlukan | permission-Document.Workbook.Write-DingTalk Spreadsheet write permission |

### Header permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Peroleh sebagai berikut:   - Untuk aplikasi internal, panggil API [Memperoleh access token aplikasi internal](/id/open/development/obtain-the-access-token-of-an-internal-app#). - Untuk aplikasi perusahaan pihak ketiga, panggil API [Memperoleh access token organisasi yang mengotorisasi aplikasi pihak ketiga](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#). |

### Parameter path

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| workbookId | String | Ya | ID dari file spreadsheet. `nodeId(dentryUuid)` yang dikembalikan oleh [API Knowledge Base](/id/open/development/knowledge-base-overview#) adalah `workbookId` dari spreadsheet. Anda dapat memperolehnya dengan memanggil API [Memperoleh sebuah node](https://open.dingtalk.com/document/development/get-node#) atau [Membuat dokumen Knowledge Base](/id/open/development/create-team-space-document#). |
| sheetId | String | Ya | ID atau judul dari lembar kerja.   - Untuk aplikasi internal, panggil API [Memperoleh semua lembar kerja](/id/open/development/obtain-all-worksheets#) untuk memperoleh ID, atau berikan judul lembar kerja. - Untuk aplikasi perusahaan pihak ketiga, kami sarankan untuk memberikan judul lembar kerja.   Lihat gambar di bawah untuk cara menampilkan judul lembar kerja. |

### Parameter query

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| operatorId | String | Ya | unionId dari operator. Panggil API [Memperoleh detail pengguna](/id/open/development/query-user-details#) untuk memperolehnya. |

### Isi permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| column | Long | Ya | Cursor dari kolom tertentu, dimulai dari 0. |
| columnCount | Long | Ya | Jumlah kolom yang akan disisipkan. |

### Contoh permintaan

HTTP

```http
POST /v1.0/doc/workbooks/e54Lq3xxx/sheets/Sheet1/insertColumnsBefore?operatorId=ppgAxxx HTTP/1.1
Host:api.dingtalk.io
x-acs-dingtalk-access-token:xxxxx
Content-Type:application/json

{
  "column" : 0,
  "columnCount" : 1
}
```
