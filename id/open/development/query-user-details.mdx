Panggil API ini untuk mendapatkan detail pengguna tertentu.

## Deskripsi panggilan API

API ini memungkinkan Anda mengambil detail pengguna akun biasa atau pengguna Akun Perusahaan. Karena penggunaan parameter berbeda secara signifikan antara kedua skenario tersebut, dokumentasi dipisah berdasarkan jenis akun agar lebih mudah dirujuk:

- Untuk mengambil detail pengguna akun biasa, lihat artikel ini.
- Untuk mengambil detail pengguna Akun Perusahaan, lihat [Mendapatkan detail pengguna Akun Perusahaan](/id/open/development/queries-the-details-of-a-dedicated-account).

Jika Anda perlu memperoleh izin untuk bidang seperti nomor telepon dan email, metodenya berbeda menurut Jenis aplikasi.

- Agar Aplikasi internal dapat memperoleh nomor telepon dan email pengguna, tambahkan izin untuk mengakses nomor telepon dan email di Kontak. Untuk menambahkan izin:

  Masuk ke [DingTalk Developer Console](https://open-dev.dingtalk.io/#/corpeapp) > **Internal Development** > **temukan aplikasi yang ingin Anda tambahkan izinnya** > **Kelola izin** > **Contacts Management**. Pilih **Employee phone number** dan **Mail and other Profile information**, lalu klik Minta izin.
- Agar Aplikasi perusahaan pihak ketiga dapat memperoleh nomor telepon dan email pengguna, gunakan DingTalk unified authorization suite.

## Permintaan

| **Informasi dasar** | |
| --- | --- |
| URL HTTP | https://oapi.dingtalk.io/topapi/v2/user/get |
| Metode HTTP | POST |
| Jenis aplikasi yang didukung | appType-Internal app, appType-Third-party enterprise app |
| Persyaratan izin | permission-qyapi_get_member-User information read permission |

### Parameter kueri

| Nama | Jenis | Wajib | Contoh | Deskripsi |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | bE74xxxx | Kredensial aplikasi yang digunakan untuk memanggil API ini.   - Untuk Aplikasi internal, dapatkan melalui API untuk memperoleh [access_token Aplikasi internal](/id/open/development/obtain-orgapp-token). - Untuk Aplikasi perusahaan pihak ketiga, dapatkan melalui API untuk memperoleh access_token perusahaan pihak ketiga. |

### Isi permintaan

| Nama | Jenis | Wajib | Contoh | Deskripsi |
| --- | --- | --- | --- | --- |
| userid | String | Ya | manager4220 | userid pengguna. |
| language | String | Tidak | zh_CN | Bahasa Kontak.   - **zh_CN**: Tionghoa (Default) - **en_US**: Inggris |

### Contoh permintaan

```bash
curl -X POST "https://oapi.dingtalk.io/topapi/v2/user/get" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=b97a231d-7dd8-4243-ac4e-6b75b2a1e28a' \
-d 'language=zh_CN' \
-d 'userid=zhangsan'
```

Java

```java
DingTalkClient client = new DefaultDingTalkClient("https://oapi.dingtalk.io/topapi/v2/user/get");
OapiV2UserGetRequest req = new OapiV2UserGetRequest();
req.setUserid("001");
req.setLanguage("zh_CN");
OapiV2UserGetResponse rsp = client.execute(req, access_token);
System.out.println(rsp.getBody());
```

Python

```python
import dingtalk.api

req=dingtalk.api.OapiV2UserGetRequest("https://oapi.dingtalk.io/topapi/v2/user/get")

req.userid="zhangsan"
req.language="zh_CN"
try:
	resp= req.getResponse(access_token)
	print(resp)
except Exception,e:
	print(e)
```

PHP

```php
include "TopSdk.php";
date_default_timezone_set('Asia/Shanghai');

$c = new DingTalkClient(DingTalkConstant::$CALL_TYPE_OAPI, DingTalkConstant::$METHOD_POST , DingTalkConstant::$FORMAT_JSON);
$req = new OapiV2UserGetRequest;
$req->setUserid("zhangsan");
$req->setLanguage("zh_CN");
$resp = $c->execute($req, $access_token, "https://oapi.dingtalk.io/topapi/v2/user/get");
```

C#

```csharp
IDingTalkClient client = new DefaultDingTalkClient("https://oapi.dingtalk.io/topapi/v2/user/get");
OapiV2UserGetRequest req = new OapiV2UserGetRequest();
req.Userid = "zhangsan";
req.Language = "zh_CN";
OapiV2UserGetResponse rsp = client.Execute(req, access_token);
Console.WriteLine(rsp.Body);
```

### Kode error

Jika panggilan API mengembalikan Error, cari solusinya berdasarkan Pesan error di dokumentasi [Kode error global](/id/open/development/server-api-error-codes-1).

| Kode error (errcode) | Deskripsi kode error (errmsg) | Solusi |
| --- | --- | --- |
| 33012 | Invalid userid | Periksa apakah userid sudah benar. |
| 400002 | Invalid parameter | Periksa apakah parameter dimasukkan sesuai ketentuan. |
| -1 | System busy | Coba Lagi Nanti. |
