Panggil API ini untuk membuat grup absensi.

## Permintaan

| **Informasi dasar** | |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/topapi/attendance/group/add |
| Metode HTTP | POST |
| Tipe aplikasi yang didukung | appType-Aplikasi internal |
| Izin yang diperlukan | permission-qyapi_attendance_group_manage-Izin pengelolaan grup absensi |

### Parameter query

| Nama | Tipe | Wajib | Contoh | Deskripsi |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | 4c9d5xxxx | Kredensial aplikasi untuk memanggil API ini. Dapatkan dengan memanggil API [Dapatkan access_token Aplikasi internal](/id/open/development/obtain-orgapp-token). |

### Isi permintaan

| Nama | Tipe | Wajib | Contoh | Deskripsi |

| ssid | String | Tidak | OFFICE-WiFi | SSID jaringan Wi-Fi. |

| freecheck_work_days | Number[] | Tidak | [1,2,3,4,5,6,0] | Hari kerja grup absensi jam kerja fleksibel.  **Catatan**     - 0 menunjukkan hari istirahat. - Dari kiri ke kanan, nilai dalam array mewakili penjadwalan shift untuk setiap hari dari Minggu hingga Sabtu. |
| freecheck_day_start_min_offset | Number | Tidak | 240 | Selisih dalam menit antara waktu mulai absensi grup absensi jam kerja fleksibel dan pukul 00.00 pada hari tersebut.  Contoh: 540 berarti pukul 09.00. |
| disable_check_when_rest | Boolean | Tidak | false | Menentukan apakah absen pada hari istirahat memerlukan persetujuan:   - **true**: Wajib - **false**: Tidak wajib |

### Contoh permintaan

```curl

-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=e02c4xxxx5043' \
-d 'op_user_id=123dfd' \
-d 'top_group=null'
```

## Respons

### Isi respons

| Nama | Tipe | Contoh | Deskripsi |
| --- | --- | --- | --- |
| result | TopGroupVo |  | Hasil panggilan. |
| name | String | Absensi Shift Pagi | Nama grup absensi. |
| id | Number | 712070073 | ID grup absensi. |
| success | Boolean | true | Menunjukkan apakah panggilan berhasil.   - **true**: Berhasil - **false**: Gagal |
| errcode | Number | 0 | Kode respons. |
| errmsg | String | Error sistem | Deskripsi kode respons. |
| request_id | String | 6pcx0i2ujtt9 | ID permintaan. |

### Contoh isi respons

```json
{
  "result":{
    "name":"Absensi Shift Pagi",
    "id":712070073
  },
  "errcode":0,
  "success":true,
  "errmsg":"ok",
  "request_id":"6pcx0i2ujtt9"
}
```

### Kode error

Jika panggilan mengembalikan error, cari solusinya di dokumen [Kode error global](/id/open/development/server-api-error-codes-1) berdasarkan pesan error yang diterima.
