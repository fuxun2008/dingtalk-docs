Contoh ini menjelaskan cara mengirim pesan melalui asisten grup.

1. Pilih aplikasi target dan buka halaman detail aplikasi. Klik **Basic information** > **Credentials and basic information**.
2. Peroleh Client ID dan Client Secret aplikasi.
3. Ajukan Izin API untuk mengirim pesan asisten grup.
4. Peroleh Kredensial akses aplikasi. Lihat [Memperoleh access token dari Aplikasi internal](/id/open/development/obtain-the-access-token-of-an-internal-app).
5. Pada halaman Scenario group di backend developer, ajukan [Bot](https://open-dev.dingtalk.io/fe/im#/robot/list). Setelah disetujui, peroleh parameter ID bot **robotCode**.
6. Pada halaman Scenario group di backend developer, buat [templat grup](https://open-dev.dingtalk.io/fe/im#/group/list) dan peroleh parameter ID templat grup **template_id**.
7. Ikat [Bot grup skenario](https://open-dev.dingtalk.io/fe/im#/robot/list) ke [templat grup skenario](https://open-dev.dingtalk.io/fe/im#/group/list), simpan hasil edit, dan kembali ke daftar skenario grup.
8. Buka templat grup terkait, kirim untuk ditinjau, lalu klik Publish.
9. Panggil API pembuatan grup dengan **template_id** untuk memperoleh **openConversationId**.
10. Panggil API pengiriman pesan asisten grup untuk mengirim pesan grup Bot.

## Prasyarat

Selesaikan proses [Membuat aplikasi](/id/open/dingstart/create-application).

## Langkah-langkah

1. Pilih aplikasi target dan buka halaman detail aplikasi. Klik **Basic information** > **Credentials and basic information**.
2. Peroleh Client ID dan Client Secret aplikasi.
3. Klik **Development configuration** > **Kelola izin**. Masukkan `qyapi_chat_manage` di kotak pencarian izin dan ajukan izinnya.
4. Peroleh Kredensial akses aplikasi. Lihat [Memperoleh access token dari Aplikasi internal](/id/open/development/obtain-the-access-token-of-an-internal-app). Saat memanggil API, gunakan access token untuk mengautentikasi identitas pemanggil.
5. Pada halaman Scenario group di backend developer, ajukan [Bot](https://open-dev.dingtalk.io/fe/im#/robot/list) dan peroleh parameter ID bot **robotCode**.

### Catatan

   Pengajuan Bot memerlukan peninjauan. Setelah disetujui, Anda dapat melihat ID-nya, seperti ditunjukkan pada gambar di bawah.

6. Pada halaman Scenario group di backend developer, buat [templat grup](https://open-dev.dingtalk.io/fe/im#/group/list) dan peroleh parameter ID templat grup **template_id**.

7. Ikat [Bot grup skenario](https://open-dev.dingtalk.io/fe/im#/robot/list) ke [templat grup skenario](https://open-dev.dingtalk.io/fe/im#/group/list), simpan hasil edit, dan kembali ke daftar skenario grup.

8. Buka templat grup terkait, kirim untuk ditinjau, lalu klik Publish.

### Catatan

   Peninjauan disetujui secara otomatis. Tidak diperlukan persetujuan manual.

9. Panggil API pembuatan grup dengan **template_id** untuk memperoleh **openConversationId**.
10. Panggil API pengiriman pesan asisten grup untuk mengirim pesan grup Bot.
