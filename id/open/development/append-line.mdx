---
title: "Menambahkan baris ke lembar kerja"
description: "Panggil API ini untuk menambahkan satu atau beberapa baris setelah baris data terakhir di lembar kerja DingTalk Spreadsheet; sistem otomatis menemukan baris terakhir yang berisi data dan menyisipkan baris baru di bawahnya."
---

Panggil API ini untuk menambahkan satu atau beberapa baris data setelah rekaman terakhir yang ada di lembar kerja DingTalk Spreadsheet. Sistem otomatis menemukan rekaman terakhir yang berisi data dan menyisipkan baris baru tepat di bawahnya.

## Deskripsi panggilan API

- Otomatis menemukan rekaman terakhir yang berisi data di lembar kerja dan menambahkan baris baru di bawahnya.
- Mendukung penambahan beberapa baris sekaligus melalui array dua dimensi `values`.
- Jika lembar kerja kosong, data ditulis mulai dari rekaman pertama.
- Mengembalikan rentang sel (dalam notasi A1) tempat data yang ditambahkan berada.
- Jumlah kolom pada data yang ditambahkan harus sesuai dengan jumlah kolom pada data lembar kerja yang sudah ada untuk memastikan keselarasan data.

## Permintaan

### Informasi dasar

| Bidang | Value |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/doc/workbooks/{workbookId}/sheets/{sheetId}/appendRows` |
| Metode HTTP | POST |
| Jenis aplikasi yang didukung | appType-Aplikasi internal |
| Izin | permission-Document.Workbook.Write-Izin tulis DingTalk Spreadsheet |

### Header permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Untuk memperolehnya, panggil API [Get the access token of an internal app](/id/open/development/obtain-the-access-token-of-an-internal-app). |

### Parameter path

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| workbookId | String | Ya | ID file spreadsheet. Kirim `nodeId` (dentryUuid), yang berfungsi sebagai `workbookId` spreadsheet. Anda dapat memperolehnya dengan memanggil API [Get a node](/id/open/development/get-knowledge-base-acquisition-node) atau [Create a Knowledge Base document](/id/open/development/create-team-space-document). |
| sheetId | String | Ya | ID atau judul lembar kerja. Anda dapat memperolehnya dengan memanggil API [Get all worksheets](/id/open/development/obtain-all-worksheets), atau kirim judul lembar kerja secara langsung. |

### Parameter query

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| operatorId | String | Ya | unionId operator. Anda dapat memperolehnya dengan memanggil API [Obtain user information by silent login code](/id/open/development/obtain-the-userid-of-a-user-by-using-the-log-free) atau [Query user details by userId](/id/open/development/query-user-details). |

### Isi permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| values | Array of Array | Ya | Daftar data yang akan ditambahkan. |
