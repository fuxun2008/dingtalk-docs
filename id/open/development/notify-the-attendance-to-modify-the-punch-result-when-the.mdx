Panggil API ini untuk memberi notifikasi pembatalan persetujuan. Mendukung tipe lembur, pengajuan cuti, dinas luar, perjalanan dinas, dan absen susulan.

## Deskripsi panggilan API

Setelah Anda memanggil API [Notifikasi persetujuan selesai](/id/open/development/api-processapprovefinish), formulir persetujuan yang telah diajukan mungkin perlu dibatalkan. Dalam kasus ini, panggil API ini untuk membatalkan catatan absensi yang telah diubah.

## Permintaan

| **Informasi dasar** | |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/topapi/attendance/approve/cancel |
| Metode HTTP | POST |
| Tipe aplikasi yang didukung | appType-Aplikasi internal　appType-Aplikasi perusahaan pihak ketiga |
| Izin | permission-qyapi_attendance_group_manage-Izin pengelolaan grup absensi |

### Parameter query

| Nama | Tipe | Wajib | Contoh | Deskripsi |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | bE74xxxx | Kredensial aplikasi yang digunakan untuk memanggil API ini.   - Aplikasi internal: Dapatkan dengan memanggil API [Mendapatkan access_token aplikasi internal](/id/open/development/obtain-orgapp-token). - Aplikasi perusahaan pihak ketiga: Dapatkan dengan memanggil API Mendapatkan access_token perusahaan pihak ketiga. |

### Isi permintaan

| Nama | Tipe | Wajib | Contoh | Deskripsi |
| --- | --- | --- | --- | --- |
| userid | String | Ya | manager4220 | ID pengguna karyawan. |
| approve_id | String | Ya | 2376620852 | ID persetujuan. Gunakan nilai parameter kustom approve_id dari API [Notifikasi persetujuan selesai](/id/open/development/api-processapprovefinish). |

### Contoh permintaan

```curl
curl -X POST "https://api.dingtalk.io/topapi/attendance/approve/cancel" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=95676xxxxdee' \
-d 'approve_id=1234abcd' \
-d 'userid=dd_dd'
```

Java

```java
DingTalkClient client = new DefaultDingTalkClient("https://api.dingtalk.io/topapi/attendance/approve/cancel");
OapiAttendanceApproveCancelRequest req = new OapiAttendanceApproveCancelRequest();
req.setUserid("manager4220");
req.setApproveId("2376620852");
OapiAttendanceApproveCancelResponse rsp = client.execute(req, access_token);
System.out.println(rsp.getBody());
```

Python

```python

```

## Respons

### Isi respons

| Nama | Tipe | Contoh | Deskripsi |
| --- | --- | --- | --- |
| errcode | Number | 0 | Kode pengembalian. |
| errmsg | String | ok | Deskripsi kode pengembalian. |

### Contoh isi respons

```json
{
  "errcode":0,
  "errmsg":"ok"
}
```

### Kode error

Jika API ini mengembalikan error, cari solusinya di dokumen [Kode error global](/id/open/development/server-api-error-codes-1) berdasarkan pesan error yang diterima.
