Panggil API ini untuk berlangganan peristiwa perubahan file.

## Deskripsi panggilan API

1. Di Developer Backend, buka App Event Subscription lalu aktifkan langganan peristiwa storage.

2. Panggil API ini untuk menetapkan cakupan langganan sebagai organisasi atau ruang penyimpanan tertentu.

### Catatan

   Mengaktifkan tombol langganan peristiwa storage di Developer Backend saja tidak cukup untuk menerima peristiwa callback. Anda juga harus memanggil API ini.

## Permintaan

### Informasi dasar

| Bidang | Nilai |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/v1.0/storage/events/subscribe |
| Metode HTTP | POST |
| Tipe aplikasi yang didukung | appType-Aplikasi internal　appType-Aplikasi perusahaan pihak ketiga |
| Izin yang diperlukan | permission-Storage.Event.Write-Izin tulis untuk langganan peristiwa perubahan file storage organisasi |

### Header permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Dapatkan dengan cara berikut:   - Untuk aplikasi internal, panggil API [Mendapatkan access token aplikasi internal](/id/open/development/obtain-the-access-token-of-an-internal-app#). - Untuk aplikasi perusahaan pihak ketiga, panggil API [Mendapatkan access token organisasi yang diberi otorisasi untuk aplikasi pihak ketiga](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#). |

### Parameter kueri

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| unionId | String | Ya | unionId operator. Panggil API [Mengueri detail pengguna](/id/open/development/query-user-details#) untuk mendapatkannya. |

### Isi permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| scopeId | String | Ya | ID yang sesuai dengan cakupan langganan.   - Ketika nilai parameter scope adalah ORG, scopeId sesuai dengan ID organisasi (corpId). Lihat [Konsep dasar - CorpId](/id/open/dingstart/basic-concepts-beta#section-bbk-mv0-oxd). - Ketika scope adalah SPACE, scopeId sesuai dengan ID ruang penyimpanan. Panggil API [Menambahkan ruang](/id/open/development/add-space#) untuk mendapatkan id. |
| scope | String | Ya | Cakupan langganan.   - ORG: organisasi - SPACE: ruang |

### Contoh permintaan

HTTP

```http
POST /v1.0/storage/events/subscribe?unionId=union_id HTTP/1.1
Host:api.dingtalk.io
x-acs-dingtalk-access-token:xxxxx
Content-Type:application/json

{
  "scopeId" : "SPACE",
  "scope" : "SPACE"
}
```
