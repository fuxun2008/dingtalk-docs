---
title: "Mendapatkan ringkasan shift"
description: "Ambil ringkasan semua shift absensi organisasi di DingTalk melalui API menggunakan userId operator dan paginasi berbasis cursor untuk integrasi sistem absensi."
---

Panggil API ini untuk mengkueri semua shift. Di aplikasi Absensi DingTalk, shift adalah sekumpulan aturan, seperti jam absen dan jam istirahat. Organisasi dapat mengonfigurasi beberapa shift sesuai kebutuhan bisnisnya.

## Permintaan

| **Informasi dasar** | |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/topapi/attendance/shift/list |
| Metode HTTP | POST |
| Tipe aplikasi yang didukung | appType-Aplikasi internal　appType-Aplikasi perusahaan pihak ketiga |
| Izin | permission-qyapi_attendance_group_read-Izin baca grup absensi |

### Parameter kueri

| Nama | Tipe | Wajib | Contoh | Deskripsi |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | bE74xxxx | Kredensial aplikasi yang digunakan untuk memanggil API ini.   - Untuk Aplikasi internal, dapatkan dengan memanggil [Mendapatkan access_token Aplikasi internal](/id/open/development/obtain-orgapp-token). - Untuk Aplikasi perusahaan pihak ketiga, dapatkan dengan memanggil API untuk mendapatkan access_token organisasi pihak ketiga. |

### Isi permintaan

| Nama | Tipe | Wajib | Contoh | Deskripsi |
| --- | --- | --- | --- | --- |
| op_user_id | String | Ya | manager4220 | userId operator. |
| cursor | Number | Tidak | 0 | ID cursor. Nilai awalnya adalah 0. |

### Contoh permintaan

```curl
curl -X POST "https://api.dingtalk.io/topapi/attendance/shift/list" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=e47ef3ff-ff01-4da7-8aa8-53bc0ad47be3' \
-d 'cursor=1234' \
-d 'op_user_id=dd_test'
```

Java

```java
DingTalkClient client = new DefaultDingTalkClient("https://api.dingtalk.io/topapi/attendance/shift/list");
OapiAttendanceShiftListRequest req = new OapiAttendanceShiftListRequest();
req.setOpUserId("dd_test");
req.setCursor(0L);
OapiAttendanceShiftListResponse rsp = client.execute(req, access_token);
System.out.println(rsp.getBody());
```

Python

```python
import dingtalk.api

req=dingtalk.api.OapiAttendanceShiftListRequest("https://api.dingtalk.io/topapi/attendance/shift/list")

req.op_user_id="dd_test"
req.cursor=1234
try:
	resp= req.getResponse(access_token)
	print(resp)
except Exception,e:
	print(e)
```

PHP

```php
include "TopSdk.php";
date_default_timezone_set('Asia/Shanghai');
```

C#


## Respons

### Isi respons

| Nama | Tipe | Contoh | Deskripsi |
| --- | --- | --- | --- |
| result | PageResult |  | Hasil kueri. |
| has_more | Boolean | false | Apakah masih ada data lainnya.   - **true**: Ya - **false**: Tidak |
| cursor | Number | 678215070 | Posisi cursor halaman berikutnya. |
| result | TopMinimalismShiftVo[] |  | Informasi shift.  Setiap halaman menampilkan 200 data. Hasil yang lebih dari 200 data akan dipaginasi. |
| name | String | A | Nama shift. |
| id | Number | 677995086 | ID shift. |
| success | Boolean | true | Apakah permintaan berhasil.   - **true**: Berhasil - **false**: Gagal |
| errcode | Number | 0 | Kode respons. |
| errmsg | String | ok | Deskripsi kode respons. |
| request_id | String | 1079sd06ne6zy | ID permintaan. |

### Contoh isi respons

### Kode error

Jika pemanggilan API ini mengembalikan error, cari solusinya di [Kode error global](/id/open/development/server-api-error-codes-1) berdasarkan pesan error.
