description: "Panggil API ini untuk memperbarui informasi dasar dan anggota obrolan grup tertentu berdasarkan chatid, termasuk nama grup, pemilik grup, daftar anggota, dan foto profil grup di DingTalk."
---

Panggil API ini untuk memperbarui informasi dasar dan anggota obrolan grup tertentu berdasarkan chatid. Gunakan untuk mengubah informasi terkait grup, termasuk nama grup, pemilik grup, daftar anggota, dan foto profil grup. API ini berlaku untuk skenario seperti admin grup yang mengubah pengaturan grup atau menyesuaikan anggota grup.

## Permintaan

### Informasi dasar

| Bidang | Nilai |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/v1.0/im/group/update |
| Metode HTTP | POST |
| Tipe aplikasi yang didukung | appType-Internal app |
| Izin yang wajib | permission-qyapi_chat_manage-DingTalk group basic information management permission |

### Header permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Dapatkan melalui API [Mendapatkan access token aplikasi internal](/id/open/development/obtain-the-access-token-of-an-internal-app). |

### Isi permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| chatid | String | Ya | ID obrolan grup. Dapatkan dari parameter chatid yang dikembalikan oleh API [Membuat obrolan grup](/id/open/development/create-common-group-new-version-v2).  chatid yang diperoleh dengan memanggil JSAPI frontend tidak didukung. |
| name | String | Tidak | Nama grup. Panjang: 1 hingga 20 karakter. |
| owner | String | Tidak | userId pemilik grup. Dapatkan userId melalui API [Mencari pengguna berdasarkan nomor telepon](/id/open/development/query-users-by-phone-number).  Pengguna harus merupakan salah satu anggota dalam useridlist obrolan. |
| ownerType | String | Tidak | Tipe pemilik grup.   - **emp**: Karyawan organisasi - **ext**: Kontak eksternal |
| add_useridlist | Array of String | Tidak | Daftar userId. |
| del_useridlist | Array of String | Tidak | Daftar userId. |
| add_extidlist | Array of String | Tidak | Daftar unionId. Dapatkan melalui API [Mencari detail pengguna](/id/open/development/query-users-by-phone-number). |
| del_extidlist | Array of String | Tidak | Daftar unionId. Dapatkan melalui API [Mencari detail pengguna](/id/open/development/query-users-by-phone-number). |
| icon | String | Tidak | mediaId foto profil grup. Dapatkan parameter media_id melalui API [Mengunggah file media](/id/open/development/upload-media-files). |
| managementOptions | Object | Tidak | Atribut grup. |
| mentionAllAuthority | Integer | Tidak | Cakupan penggunaan @all.   - **0** (default): Semua anggota dapat menggunakan @all. - **1**: Hanya pemilik grup yang dapat menggunakan @all. |
| showHistoryType | Integer | Tidak | Apakah anggota baru dapat melihat 100 obrolan historis terakhir.   - **1**: Diizinkan. - **0**: Tidak diizinkan.   Jika tidak ditentukan, anggota baru tidak dapat melihat obrolan historis. |
| validationType | Integer | Tidak | Apakah verifikasi diperlukan untuk bergabung ke grup.   - **0** (default): Tanpa verifikasi. - **1**: Verifikasi diperlukan. |
| searchable | Integer | Tidak | Apakah grup dapat dicari.   - 0 (default): Tidak dapat dicari. - 1: Dapat dicari. |
| chatBannedType | Integer | Tidak | Apakah mengaktifkan bisukan anggota untuk grup.   - **0** (default): Tidak dibisukan. - **1**: Bisukan Semua. |
| managementType | Integer | Tidak | Tipe kelola grup.   - **0** (default): Semua anggota dapat mengelola. - **1**: Hanya pemilik grup yang dapat mengelola. |
