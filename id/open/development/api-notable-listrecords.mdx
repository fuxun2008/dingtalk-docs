Panggil API ini untuk mengambil beberapa rekaman dari tabel tertentu di AI Table.

## Permintaan

### Informasi dasar

| Bidang | Nilai |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/notable/bases/{baseId}/sheets/{sheetIdOrName}/records/list` |
| Metode HTTP | POST |
| Jenis aplikasi yang didukung | appType-Internal app |
| Izin yang diperlukan | permission-Notable.Base.Read.All-AI Table app read permission |

### Header permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses yang digunakan untuk memanggil API ini. Untuk memperolehnya, lihat [Memperoleh access token dari aplikasi internal](/id/open/development/obtain-the-access-token-of-an-internal-app). |

### Parameter path

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| baseId | String | Ya | ID dari AI Table. Untuk memperolehnya, lihat [Struktur data](/id/open/development/data-structure). |
| sheetIdOrName | String | Ya | ID tabel atau nama tabel. Anda dapat memperoleh ID tabel melalui salah satu cara berikut:   - Panggil API [Memperoleh semua tabel](/id/open/development/api-notable-getallsheets). - Panggil API [Memperoleh sebuah tabel](/id/open/development/api-notable-getsheet). |

### Parameter kueri

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| operatorId | String | Ya | unionId dari operator. Anda dapat memperolehnya melalui salah satu cara berikut:   - Panggil API [Kueri detail pengguna](/id/open/development/query-user-details). - Panggil API [Memperoleh informasi pengguna menggunakan kode login senyap](/id/open/development/obtain-the-userid-of-a-user-by-using-the-log-free). |

### Isi permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| filter | Object | Tidak | Filter. Ketika ditetapkan, hanya rekaman yang memenuhi kondisi yang dikembalikan. |
| combination | String | Tidak | Mode kombinasi dari kondisi. Nilai yang valid:   - **and**: Semua kondisi harus terpenuhi. - **or**: Salah satu kondisi dapat terpenuhi. |
| conditions | Array | Ya | Kondisi. |
| field | String | Ya | ID field atau nama field. |
| operator | String | Ya | Operator kondisi: equal | notEqual | greater | greaterEqual | less | lessEqual | contain | notContain | empty | notEmpty. |
| value | Array of Any | Tidak | Nilai kondisi. Lihat [Format nilai rekaman](https://open.dingtalk.com/document/development/record-value-format). |
| maxResults | Integer | Tidak | Jumlah rekaman yang dikembalikan per halaman. Default: 100. Minimum: 1. Maksimum: 100. |
| nextToken | String | Tidak | Cursor paginasi yang dikembalikan oleh kueri sebelumnya. Kosongkan untuk kueri pertama. |
| fieldIdOrNames | Array of String | Tidak | Opsional. Daftar field yang akan dikembalikan. Ketika terdapat banyak field, sertakan hanya yang diperlukan untuk mengurangi ukuran respons secara signifikan. Maksimum 100 field per permintaan. |
