Panggil API ini untuk mendapatkan pengaturan mode eksekutif seorang pengguna.

## Permintaan

### Informasi dasar

| Bidang | Nilai |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/v1.0/contact/seniorSettings |
| Metode HTTP | GET |
| Jenis aplikasi yang didukung | appType-Aplikasi internal |
| Izin yang diperlukan | permission-qyapi_get_member-Izin baca untuk informasi pengguna |

### Header permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Dapatkan dengan memanggil API [Mendapatkan access token dari aplikasi internal](/id/open/development/obtain-the-access-token-of-an-internal-app#). |

### Parameter kueri

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| seniorStaffId | String | Ya | ID pengguna. Dapatkan userId dengan memanggil API [Mendapatkan informasi pengguna menggunakan kode login senyap](/id/open/development/obtain-the-userid-of-a-user-by-using-the-log-free#). |

## Respons

### Isi respons

| Nama | Tipe | Deskripsi |
| --- | --- | --- |
| seniorStaffId | String | ID pengguna. |
| protectScenes | Array of String | Daftar skenario interupsi. |
| seniorWhiteList | Array | Daftar izin eksekutif. |
| id | String | ID objek dalam daftar izin eksekutif. Nilai yang valid:   - type=1: menunjukkan userId. - type=2: menunjukkan deptId departemen. - type=3: menunjukkan roleId peran. |
| type | Integer | Tipe entri daftar izin eksekutif. Nilai yang valid:   - **1**: pengguna - **2**: departemen - **3**: peran |
| name | String | Nama objek dalam daftar izin eksekutif. Nilai yang valid:   - type=1: nama karyawan. - type=2: nama departemen. - type=3: nama peran. |

### Contoh isi respons

```text
HTTP/1.1 200 OK
Content-Type:application/json

{
  "seniorStaffId" : "userId eksekutif",
  "protectScenes" : [ "CHAT" ],
  "seniorWhiteList" : [ {
    "id" : "1234",
    "type" : 1,
    "name" : "Peran uji"
  } ]
}
```
