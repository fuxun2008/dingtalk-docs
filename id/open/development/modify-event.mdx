Panggil API ini untuk memperbarui informasi satu acara.

## Deskripsi panggilan API

- Hanya penyelenggara yang diizinkan untuk memperbarui acara. Oleh karena itu, bidang `userId` di path harus berupa unionId penyelenggara.
- Kirim hanya bidang yang perlu diperbarui dalam permintaan. Bidang yang tidak dikirim akan tetap tidak berubah.
- Setiap operasi pada partisipan acara mendukung hingga 500 pengguna, dan acara dengan hingga 5.000 partisipan didukung.
- Untuk menambah atau menghapus partisipan acara, gunakan API [Menambahkan partisipan acara](/id/open/development/add-schedule-participant#) dan [Menghapus partisipan acara](/id/open/development/delete-schedule-participant#).

## Permintaan

### Informasi dasar

| Bidang | Nilai |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/calendar/users/{userId}/calendars/{calendarId}/events/{eventId}` |
| Metode HTTP | PUT |
| Jenis aplikasi yang didukung | appType-Aplikasi internal　appType-Aplikasi perusahaan pihak ketiga　appType-Aplikasi personal pihak ketiga |
| Izin yang diperlukan | permission-Calendar.Event.Write-Izin tulis untuk acara di aplikasi Kalender |

### Header permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| x-client-token | String | Tidak | Pemeriksaan idempotensi.       - `x-client-token` yang sama menandakan permintaan yang sama. - Kedaluwarsa dalam 1 hari. |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses yang digunakan untuk memanggil API ini. Dapatkan dengan cara berikut:   - Untuk aplikasi internal, panggil API [Mendapatkan access token aplikasi internal](/id/open/development/obtain-the-access-token-of-an-internal-app#). - Untuk aplikasi perusahaan pihak ketiga, panggil API [Mendapatkan access token perusahaan yang diberi otorisasi ke aplikasi pihak ketiga](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#). - Untuk aplikasi personal pihak ketiga, panggil API [Mendapatkan user token](/id/open/development/obtain-user-token#). |

### Parameter path

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| userId | String | Ya | unionId penyelenggara acara.   - Untuk aplikasi internal dan aplikasi perusahaan pihak ketiga, panggil API [Kueri detail pengguna](/id/open/development/query-user-details#) untuk memperoleh nilai parameter `unionid`. - Untuk aplikasi personal pihak ketiga, panggil API [Mendapatkan profil pengguna dari kontak](/id/open/development/dingtalk-retrieve-user-information#) untuk memperoleh nilai parameter `unionId`. |
| calendarId | String | Ya | ID kalender tempat acara berada. Atur parameter ini ke `primary`, yang mewakili kalender utama pengguna. |
| eventId | String | Ya | ID acara. Panggil API [Kueri daftar acara](/id/open/development/query-an-event-list#) untuk memperoleh nilai parameter `id`. |

### Isi permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| summary | String | Tidak | Judul acara. |
| id | String | Ya | ID acara. |
| description | String | Tidak | Deskripsi acara. |
| start | Object | Tidak | Waktu mulai acara. |
| date | String | Tidak | Tanggal mulai acara dalam format `yyyy-MM-dd`.     - Wajib untuk acara sepanjang hari. - Harus kosong untuk acara yang bukan sepanjang hari. |
| dateTime | String | Tidak | Waktu mulai acara dalam format tanggal-waktu ISO-8601.     - Harus kosong untuk acara sepanjang hari. - Wajib untuk acara yang bukan sepanjang hari. |
| timeZone | String | Tidak | Zona waktu untuk waktu mulai acara, dalam format nama database TZ.     - Harus kosong untuk acara sepanjang hari. - Wajib untuk acara yang bukan sepanjang hari. |
| end | Object | Tidak | Waktu selesai acara.    Jumlah pengulangan (**numberOfOccurrences**) dan waktu selesai acara (**end**) tidak dapat diatur pada saat yang bersamaan. |
| date | String | Tidak | Tanggal selesai acara dalam format `yyyy-MM-dd`.     - Wajib untuk acara sepanjang hari. - Harus kosong untuk acara yang bukan sepanjang hari. |
| dateTime | String | Tidak | Waktu selesai acara dalam format tanggal-waktu ISO-8601.     - Harus kosong untuk acara sepanjang hari. - Wajib untuk acara yang bukan sepanjang hari. |
| timeZone | String | Tidak | Zona waktu untuk waktu selesai acara. Harus sama dengan zona waktu untuk waktu mulai, dalam format nama database TZ.     - Harus kosong untuk acara sepanjang hari. - Wajib untuk acara yang bukan sepanjang hari. |
| isAllDay | Boolean | Tidak | Apakah acara merupakan acara sepanjang hari.   - **true**: Ya. - **false**: Tidak. |
| recurrence | Object | Tidak | Aturan pengulangan acara. |
| pattern | Object | Tidak | Pola pengulangan. |
| type | String | Tidak | Jenis pola pengulangan.   - **daily**: Berulang setiap **interval** hari. - **weekly**: Berulang pada **daysOfWeek** setiap **interval** minggu. - **absoluteMonthly**: Berulang pada tanggal **dayOfMonth** setiap **interval** bulan. - **relativeMonthly**: Berulang pada **daysOfWeek** di minggu **index** setiap **interval** bulan. - **absoluteYearly**: Berulang setiap **interval** tahun. |
| dayOfMonth | Integer | Tidak | Menentukan tanggal dalam bulan ketika **type** pola pengulangan adalah **absoluteMonthly**. |
| daysOfWeek | String | Tidak | Menentukan hari dalam minggu dengan huruf kecil bahasa Inggris. Pisahkan beberapa nilai dengan koma. |
| index | String | Tidak | Menentukan minggu dalam bulan ketika `type` adalah `relativeMonthly`.   - **first**: Minggu pertama. - **second**: Minggu kedua. - **third**: Minggu ketiga. - **fourth**: Minggu keempat. - **last**: Minggu terakhir. |
| interval | Integer | Tidak | Interval pengulangan. Satuannya bervariasi tergantung pada `type`.      Misalnya:   - Ketika **type** adalah **daily**, ini mewakili interval N hari. - Ketika **type** adalah **absoluteYearly**, ini mewakili interval N tahun. |
| firstDayOfWeek | String | Tidak | Hari pertama dalam minggu. Nilai yang valid: sunday, monday, tuesday, wednesday, thursday, friday, saturday. Default: "sunday". |
| range | Object | Tidak | Rentang pengulangan. |
| type | String | Tidak | Jenis rentang pengulangan.   - **noEnd**: Tidak pernah berakhir. - **endDate**: Berakhir pada tanggal tertentu. - **numbered**: Berakhir setelah jumlah pengulangan tertentu. |
| endDate | String | Tidak | Waktu berakhir pengulangan.      **endDate** dan **numberOfOccurrences** tidak dapat diatur pada saat yang bersamaan. |
| numberOfOccurrences | Integer | Tidak | Jumlah pengulangan.      **endDate** dan **numberOfOccurrences** tidak dapat diatur pada saat yang bersamaan. |
| attendees | Array | Tidak | Daftar partisipan acara. |
| id | String | Tidak | unionId pengguna. |
| email | String | Tidak | Alamat email. |
| isOptional | Boolean | Tidak | Apakah partisipan bersifat opsional.   - **true**: Ya. - **false**: Tidak. |
| location | Object | Tidak | Lokasi acara. |
| displayName | String | Tidak | Nama lokasi acara. |
| extra | `Map<String, String>` | Tidak | Sekumpulan sakelar ekstensi berformat JSON. Opsional. Atributnya didefinisikan sebagai berikut:   - **noPushNotification**: Apakah akan mengirim notifikasi push DingTalk ke pengguna terkait saat acara dibuat.    - **true**: Tidak mengirim.   - **false**: Mengirim. - **noChatNotification**: Apakah akan mengirim kartu pesan langsung ke partisipan saat acara dibuat.    - **true**: Tidak mengirim.   - **false**: Mengirim. |
| reminders | Array | Tidak | Pengingat acara. Beberapa pengingat dapat ditambahkan.   - Jika parameter ini tidak dikirim, waktu pengingat default adalah:    - **Acara yang bukan sepanjang hari**: 15 menit sebelum waktu mulai.   - **Acara sepanjang hari**: pukul 9 pagi pada hari sebelum acara dimulai. - Jika data kosong dikirim, tidak ada pengingat yang dibuat. |
| method | String | Tidak | Metode pengingat.   - **dingtalk**: Pengingat dalam aplikasi di DingTalk. |
| minutes | Integer | Tidak | Mengirim pengingat N menit sebelum acara dimulai. |
| onlineMeetingInfo | Object | Tidak | Rapat video.  Mengirim bidang ini saat pembaruan akan membuat rapat video baru. Jika rapat video sudah ada, mengirim bidang ini akan menimpa yang sudah ada. |
| type | String | Tidak | Jenis rapat online.   - **dingtalk**: Rapat video DingTalk. |
| richTextDescription | Object | Tidak | Bidang teks kaya. |
| text | String | Tidak | Nilai teks kaya. |
| uiConfigs | Array | Tidak | Konfigurasi UI yang mengontrol tampilan komponen di halaman detail acara. |
| uiName | String | Ya | Nama komponen. Nilai yang valid (terus diperbarui):   - **updateEventButton**: Tombol Edit Acara. - **deleteEventButton**: Tombol Hapus Acara. - **transferEventButton**: Tombol Alihkan Acara. - **attendee**: Area partisipan. - **comment**: Area komentar acara. |
| uiStatus | String | Ya | Status komponen. Nilai yang valid:   - **hide**: Disembunyikan. - **disable**: Dinonaktifkan (didukung pada halaman detail baru; tidak didukung pada versi lama, di mana komponen disembunyikan sebagai gantinya).    Untuk komponen tombol: tidak dapat diklik.   Untuk komponen area: tidak dapat diinteraksikan. Misalnya, jika area komentar diatur ke disable, komentar tidak dapat ditulis, tetapi komentar yang sudah ada tetap terlihat. - **enable**: Tersedia (status default). |
