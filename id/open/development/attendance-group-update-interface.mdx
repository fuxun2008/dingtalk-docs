Panggil API ini untuk memperbarui informasi grup absensi berdasarkan ID grup absensi.

## Permintaan

| **Informasi dasar** | |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/topapi/attendance/group/modify |
| Metode HTTP | POST |
| Jenis aplikasi yang didukung | appType-Aplikasi internal |
| Izin yang diperlukan | permission-qyapi_attendance_group_manage-Izin pengelolaan grup absensi |

### Parameter query

| Nama | Tipe | Wajib | Contoh | Deskripsi |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | b5e95d101165xxxx | Kredensial aplikasi untuk memanggil API ini. Dapatkan kredensial ini dengan memanggil API [Mendapatkan access_token Aplikasi internal](/id/open/development/obtain-orgapp-token). |

### Isi permintaan

| Nama | Tipe | Wajib | Contoh | Deskripsi |
| --- | --- | --- | --- | --- |
| op_user_id | String | Ya | 123dfd | ID pengguna operator. |
| top_group | Object | Ya |  | Informasi grup absensi. |
| shift_vo_list | Object[] | Tidak |  | Informasi shift. |
| id | Number | Tidak | 123 | ID shift. Dapatkan nilai id dengan memanggil API [Mendapatkan ringkasan shift](/id/open/development/enterprise-shift-query-in-batches). |
| id | Number | Ya | 123 | ID grup absensi.  **Catatan**  Jika Anda menggunakan pengenal grup absensi versi lama (group_key), panggil API [Konversi groupKey ke groupId](/id/open/development/convert-groupkey-to-groupid) untuk mengonversi group_key menjadi group_id. |
| name | String | Tidak | Absensi Shift Siang | Nama grup absensi. |
| positions | Object[] | Tidak |  | Pengaturan alamat absensi. |
| address | String | Tidak | Jl. Jinger No. 21, Kawasan Industri Bioteknologi | Alamat. |
| corp_id | String | Tidak | 123dfd | CorpId Organisasi. Temukan CorpId di halaman Beranda [Developer Console](https://open-dev.dingtalk.io/#/index). |
| latitude | String | Tidak | 36.687495 | Garis lintang (maksimal 6 angka desimal). |
| longitude | String | Tidak | 101.750329 | Garis bujur (maksimal 6 angka desimal). |
| title | String | Tidak | Museum Sejarah Alam Dataran Tinggi Qinghai-Tibet | Judul lokasi absensi. |
| accuracy | String | Tidak | 0 | Akurasi.  **Catatan**  Bidang ini tidak berfungsi dan tidak memengaruhi akurasi. Bidang ini tidak digunakan lagi sejak 7 Maret 2022. |
| offset | Number | Tidak | 300 | Jangkauan absensi. |
| manager_list | String[] | Tidak | ["userId1","userId2"] | Daftar ID pengguna Sub Admin grup absensi. |
| enable_camera_check | Boolean | Tidak | true | Menentukan apakah fitur absen dengan foto diaktifkan.   - **true**: Aktif - **false** (default): Nonaktif   **Catatan**  Parameter ini tidak digunakan lagi. Gunakan parameter open_camera_check sebagai gantinya. |
| owner | String | Tidak | 123dfdf | ID pengguna penanggung jawab absensi. |
| disable_check_when_rest | Boolean | Tidak | false | Menentukan apakah absen pada hari libur memerlukan Persetujuan.   - **true**: Wajib - **false**: Tidak wajib |
| skip_holidays | Boolean | Tidak | true | Menentukan apakah hari libur nasional dilewati.   - **true** (default): Lewati - **false**: Jangan lewati |
| enable_outside_check | Boolean | Tidak | true | Menentukan apakah absensi lapangan diizinkan.   - **true** (default): Izinkan - **false**: Jangan izinkan |
| disable_check_without_schedule | Boolean | Tidak | false | Menentukan apakah karyawan dilarang absen jika tidak ada jadwal shift.   - **true**: Larang - **false**: Jangan larang |
| enable_emp_select_class | Boolean | Tidak | true | Menentukan apakah karyawan dapat memilih shift untuk absen jika tidak ada jadwal shift.   - **true**: Izinkan - **false**: Jangan izinkan |
| resource_permission_map | Object | Tidak |  | Cakupan izin Sub Admin.   - **w**: Dapat dikelola - **r**: Hanya Baca |
| camera_check | String | Tidak | w | Konfigurasikan aturan absen dengan foto. |
| over_time_rule | String | Tidak | r | Konfigurasikan aturan lembur. |
| check_position_type | String | Tidak | w | Konfigurasikan metode absen. |
| check_time | String | Tidak | r | Konfigurasikan waktu absensi. |
| group_type | String | Tidak | w | Konfigurasikan jenis absensi. |
| group_member | String | Tidak | r | Konfigurasikan anggota absensi. |
| schedule | String | Tidak | w | Penjadwalan shift karyawan. |
| out_side_check | String | Tidak | r | Konfigurasikan absensi lapangan. |
| workday_class_list | Number[] | Tidak | [12,12,12,12,0,0] | Daftar shift mingguan.  **Catatan**   - Wajib untuk absensi shift tetap. Nilai 0 menandakan hari libur. - Nilai dalam array mewakili penjadwalan shift harian dari Minggu hingga Sabtu, dari kiri ke kanan. |
| open_camera_check | Boolean | Tidak | true | Menentukan apakah fitur absen dengan foto diaktifkan.   - **true**: Aktif - **false** (default): Nonaktif |

### Contoh permintaan

```curl
curl -X POST "https://api.dingtalk.io/topapi/attendance/group/modify" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=ca21b524-0a09-4909-b6e9-af087e28a86b' \
-d 'op_user_id=123dfd' \
-d 'top_group=null'
```

## Respons

### Isi respons

| Nama | Tipe | Contoh | Deskripsi |
| --- | --- | --- | --- |
| result | Object |  | Hasil grup absensi. |
| name | String | Absensi Shift Siang | Nama grup absensi. |
| id | Number | 123 | ID grup absensi. |
| errmsg | String | 0 | Pesan error. |
| errcode | Number | ok | Kode error. |
| success | Boolean | true | Menunjukkan apakah panggilan berhasil.   - **true**: Berhasil - **false**: Gagal |

### Contoh isi respons

```json
{
  "result":{
    "name":"Absensi Shift Siang",
    "id":"123"
  },
  "errcode":0,
  "success":true,
  "errmsg":"ok"
}
```

### Kode error

Jika panggilan mengembalikan error, cari solusinya berdasarkan pesan error di dokumen [Kode error global](/id/open/development/server-api-error-codes-1).
