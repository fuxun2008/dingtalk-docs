Tabler dibangun di atas kemampuan cerdas Aplikasi Magic Wand dan menambahkan kemampuan menyerupai manusia seperti bergabung ke Kontak, obrolan satu lawan satu dan grup, menulis dokumen, serta mengikuti rapat audio dan video. Tabler terintegrasi secara mendalam ke lebih banyak skenario DingTalk untuk melayani pengguna di organisasi Anda dengan lebih efisien.

## **Informasi latar belakang**

Setelah Anda membuat Aplikasi Magic Wand, aplikasi tersebut otomatis muncul di opsi konfigurasi Tabler. Satu Tabler hanya mendukung satu Aplikasi Magic Wand.

## **Prasyarat**

- Anda telah menambahkan kemampuan Aplikasi Tabler. Untuk detailnya, lihat Menambahkan Kemampuan Aplikasi AI.
- Anda telah mengonfigurasi Aplikasi Magic Wand. Untuk informasi lebih lanjut, lihat Mengonfigurasi Aplikasi Magic Wand.

## **Prosedur**

1. Tinjau dan konfirmasi bahwa keterampilan yang dipilih di Aplikasi Magic Wand sesuai dengan harapan Anda.
2. Konfigurasikan informasi dasar, lalu klik **Simpan**.

   |  |  |
   | --- | --- |
   | **Item Konfigurasi** | **Deskripsi** |
   | Avatar Tabler | Unggah avatar Tabler. Ikon harus dalam format JPG atau PNG, minimal 240px \* 240px, rasio aspek 1:1, tidak lebih besar dari 2 MB, dan tanpa sudut membulat. Untuk spesifikasi terperinci, lihat Spesifikasi Desain Avatar Tabler. |
   | Nama Tabler | Masukkan nama Tabler hingga 20 karakter. Nama ini ditampilkan di Kontak dan dapat diubah oleh admin Kontak. |
   | Deskripsi Tabler | Berikan deskripsi lebih lanjut tentang Tabler, hingga 50 karakter. Deskripsi ini ditampilkan di profil Tabler dan dapat diubah oleh admin Kontak. |

## **Langkah selanjutnya**

Setelah berhasil menyimpan, Anda harus memublikasikan Tabler sebelum dapat digunakan. Untuk informasi lebih lanjut, lihat Memublikasikan Aplikasi AI Internal Perusahaan atau Memublikasikan Aplikasi AI Perusahaan Pihak Ketiga.
