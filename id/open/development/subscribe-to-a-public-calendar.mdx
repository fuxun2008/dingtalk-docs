Panggil API ini untuk berlangganan kalender publik.

## Deskripsi panggilan API

Sebelum memanggil API ini, pastikan pengguna memiliki izin berlangganan untuk kalender tersebut.

## Permintaan

### Informasi dasar

| Bidang | Nilai |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/calendar/users/{userId}/calendars/{calendarId}/subscribe` |
| Metode HTTP | POST |
| Tipe aplikasi yang didukung | appType-Aplikasi internal　appType-Aplikasi perusahaan pihak ketiga　appType-Aplikasi personal pihak ketiga |
| Izin yang diperlukan | permission-Calendar.Calendar.Write-Izin tulis untuk aplikasi Kalender |

### Header permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Peroleh dengan cara berikut:   - Untuk aplikasi internal, panggil API [Mendapatkan access token aplikasi internal](/id/open/development/obtain-the-access-token-of-an-internal-app#). - Untuk aplikasi perusahaan pihak ketiga, panggil API [Mendapatkan access token perusahaan yang diotorisasi untuk aplikasi pihak ketiga](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#). - Untuk aplikasi personal pihak ketiga, panggil API [Mendapatkan user token](/id/open/development/obtain-user-token#). |

### Parameter path

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| userId | String | Ya | unionId dari pelanggan.   - Untuk aplikasi internal dan aplikasi perusahaan pihak ketiga, panggil API [Kueri detail pengguna](/id/open/development/query-user-details#) untuk memperoleh nilai parameter unionid. - Untuk aplikasi personal pihak ketiga, panggil API [Mendapatkan profil Kontak pengguna](/id/open/development/dingtalk-retrieve-user-information#) untuk memperoleh nilai parameter unionId. |
| calendarId | String | Ya | ID kalender. Saat ini, tindakan berlangganan hanya mendukung kalender bertipe **subscribed**.    Pembuat kalender subscribed atau pengguna yang telah berlangganan kalender tersebut dapat memperolehnya melalui API [Kueri kalender](/id/open/development/query-a-calendar#). |

### Kode error

Jika terjadi error saat memanggil API ini, lihat dokumen [Kode error global](/id/open/development/server-api-error-codes-1) untuk menemukan solusi berdasarkan pesan error.

| HttpCode | Kode error | Pesan error | Deskripsi |
| --- | --- | --- | --- |
| 400 | permissionDenied | The user is not within the subscription scope | Pengguna tidak berada dalam cakupan langganan |
| 400 | invalidParameter | forwardErrorMessage | Parameter tidak valid |
| 400 | invalidParameter | calendarId cannot be blank | calendarId tidak boleh kosong |
| 400 | invalidParameter | calendar type invalid | Tipe kalender tidak valid |
| 400 | exceedSubscribeLimit | exceed subscribe limit | Kalender yang dilanggan melebihi batas maksimum |
