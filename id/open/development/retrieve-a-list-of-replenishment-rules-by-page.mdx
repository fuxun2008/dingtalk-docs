Panggil API ini untuk mendapatkan daftar aturan absen susulan yang dikonfigurasi di pengaturan absensi secara berhalaman, termasuk nama aturan dan ID aturan.

## Deskripsi panggilan API

Sebagai contoh, sebuah organisasi memiliki dua aturan absen susulan di manajemen aturan absensi: **Aturan absen susulan uji coba** dan **Aturan absen susulan default**.

Panggil API ini untuk mendapatkan nama aturan dan ID aturan dari kedua aturan absen susulan tersebut.

Di admin console Absensi, buka **aturan absensi** > **Aturan absen susulan** untuk melihat aturan absen susulan yang telah dikonfigurasi. Setiap aturan menampilkan **Nama aturan**, **Detail aturan** (jumlah pengajuan yang diizinkan per bulan, batas waktu mundur pengajuan absen susulan, serta tipe yang berlaku seperti absen terlewat, terlambat, atau pulang lebih awal), dan **Cakupan**, dengan tindakan **Edit** dan **Hapus**. Gunakan **Tambah aturan absen susulan** untuk membuat aturan baru.

## Permintaan

### Informasi dasar

| Bidang | Nilai |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/v1.0/attendance/adjustments |
| Metode HTTP | GET |
| Tipe aplikasi yang didukung | appType-Aplikasi internal　appType-Aplikasi perusahaan pihak ketiga |
| Izin yang diperlukan | permission-qyapi_attendance_group_read-Izin baca grup absensi |

### Header permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Dapatkan dengan cara berikut:   - Untuk Aplikasi internal, panggil API [Dapatkan access token aplikasi internal](/id/open/development/obtain-the-access-token-of-an-internal-app). - Untuk Aplikasi perusahaan pihak ketiga, panggil API untuk mendapatkan access token organisasi yang telah memberikan otorisasi kepada Aplikasi pihak ketiga. |

### Parameter kueri

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| pageNumber | Long | Ya | Nomor halaman awal.  Nilai dimulai dari 1. |
| pageSize | Long | Ya | Ukuran halaman.  Nilai maksimum adalah 50. |

### Contoh permintaan

```http
GET /v1.0/attendance/adjustments?pageNumber=1&pageSize=10 HTTP/1.1

x-acs-dingtalk-access-token:xxxxx

```

## Respons

### Isi respons

| Nama | Tipe | Deskripsi |
| --- | --- | --- |
| result | Object | Hasil yang dikembalikan. |
| pageNumber | Long | Nomor halaman saat ini. |
| totalPage | Long | Jumlah total halaman. |
| items | Array | Daftar aturan absen susulan. |
| id | Long | ID aturan absen susulan. |
| name | String | Nama aturan absen susulan. |
| settingId | Long | settingId dari aturan absen susulan. |

### Contoh isi respons

```text
HTTP/1.1 200 OK
Content-Type:application/json

{
  "result" : {
    "pageNumber" : 1,
    "totalPage" : 3,
    "items" : [ {
      "id" : 447010124,
      "name" : "Aturan absen susulan default",
      "settingId" : 447010124
    } ]
  }
}
```
