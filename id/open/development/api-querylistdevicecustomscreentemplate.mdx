Panggil API ini untuk mengkueri daftar templat layar kustom secara langsung.

## Permintaan

### Informasi dasar

| Bidang | Nilai |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/v1.0/rooms/devices/screens/templateLists |
| Metode HTTP | GET |
| Tipe aplikasi yang didukung | appType-Aplikasi internal　appType-Aplikasi perusahaan pihak ketiga |
| Izin yang diperlukan | permission-Rooms.DeviceTemplate.Read-Izin baca untuk layar kustom DingTalk Meeting Rooms |

### Header permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial API. Untuk memperolehnya, panggil API [Dapatkan token pengguna](/id/open/development/obtain-user-token#).  Saat meminta token pengguna, parameter `code` harus diperoleh melalui tautan yang dikonstruksi yang cakupannya mencakup ID pengguna maupun ID organisasi, yaitu `scope=openid corpid`. |

## Respons

### Isi respons

| Nama | Tipe | Deskripsi |
| --- | --- | --- |
| result | Object | Hasil respons. |
| deviceCustomTemplates | Array | Daftar konten templat. |
| templateId | Long | ID templat. |
| corpId | String | ID organisasi tempat templat berada. |
| logo | String | Logo templat. |
| orgName | String | Nama organisasi pada templat. |
| customDoc | String | Konten teks kustom templat. |
| bgUrl | String | URL latar belakang kustom templat. |
| bgImageList | Array of String | mediaId gambar. |
| instruction | Boolean | Apakah menampilkan instruksi. Nilai yang valid:   - true: Tampilkan - false: Jangan tampilkan |
| bgType | Integer | Tipe latar belakang kustom templat. Nilai yang valid:   - 1: Gambar - 2: URL |
| isPicTop | Integer | Apakah menampilkan bilah informasi beranda. Nilai yang valid:   - 0: Tampilkan - 1: Jangan tampilkan |
| templateName | String | Nama templat. |
| confType | Integer | Tipe templat. Nilai yang valid:   - 1: Templat default - 2: Templat kustom |
| showCalendarTitle | Boolean | Apakah menampilkan judul acara pada kartu acara. Nilai yang valid:   - true: Tampilkan - false: Jangan tampilkan |
| hideServerCodeWhenProjecting | Boolean | Apakah menyembunyikan kode transmisi selama transmisi. Nilai yang valid:   - true: Sembunyikan - false: Jangan sembunyikan |
| confSubType | Integer | Subtipe templat. Nilai yang valid:   - 1: Subtipe default |
| desensitizeUserName | Boolean | Apakah menyamarkan nama penyelenggara pada kartu acara. Nilai yang valid:   - true: Samarkan - false: Jangan samarkan |
| picturePlayInterval | Integer | Interval carousel gambar latar belakang kustom, dalam detik. |
| showCalendarCard | Boolean | Apakah menampilkan kartu acara. Nilai yang valid:   - true: Tampilkan - false: Jangan tampilkan |
| showFunctionCard | Boolean | Apakah menampilkan kartu fungsi. Nilai yang valid:   - true: Tampilkan - false: Jangan tampilkan |
| deviceTemplateMap | `Map<String, Array of String>` | Pemetaan unionId perangkat tempat templat berlaku. Key-nya adalah ID templat. |
|  | Array of String | unionId perangkat. |
| groupIdTemplateMap | `Map<String, Array of Long>` | Pemetaan ID grup tempat templat berlaku. Key-nya adalah ID templat. |
|  | Array of Long | ID grup. |
| roomIdTemplateMap | `Map<String, Array of String>` | Pemetaan ID Ruang tempat templat berlaku. Key-nya adalah ID templat. |
|  | Array of String | ID Ruang. |
