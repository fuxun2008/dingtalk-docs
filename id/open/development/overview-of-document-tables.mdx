DingTalk Spreadsheet OpenAPI menyediakan sekumpulan antarmuka RESTful yang memungkinkan developer mengoperasikan dokumen DingTalk Spreadsheet secara terprogram. Gunakan API ini untuk mengotomatiskan operasi baca/tulis data, mengelola Lembar Kerja, mencari Sel, mengunci rentang, dan lainnya. API ini cocok untuk skenario seperti sinkronisasi data, pembuatan laporan, dan otomatisasi perkantoran.

## Glosarium

### workbookId

Pengidentifikasi unik dari sebuah file Spreadsheet. Ini adalah `nodeId` (`dentryUuid`) yang dikembalikan oleh Knowledge Base API, dan juga dapat diperoleh dari URL Spreadsheet. Dapatkan dengan salah satu cara berikut:

- **Metode 1**: Dapatkan dari URL Spreadsheet.

- **Metode 2**: Dapatkan dari informasi dokumen.

- **Metode 3**: Dapatkan melalui Knowledge Base API.

  Panggil API [Dapatkan node](/id/open/development/get-knowledge-base-acquisition-node) atau [Buat dokumen Knowledge Base](/id/open/development/create-team-space-document). `nodeId` (`dentryUuid`) yang dikembalikan adalah `workbookId`.

### sheetId

ID atau nama sebuah Lembar Kerja. Dapatkan melalui API [Dapatkan semua Lembar Kerja](/id/open/development/obtain-all-worksheets), atau berikan judul Lembar Kerja secara langsung.

### rangeAddress

Alamat rentang Sel, menggunakan notasi A1.

### operatorId

`unionId` dari operator, digunakan untuk mengidentifikasi pengguna yang melakukan tindakan dan untuk memverifikasi izin.
