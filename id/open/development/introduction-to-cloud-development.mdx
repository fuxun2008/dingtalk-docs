## Pengantar

[Cloud Development Platform](https://workbench.aliyun.com/page/quickstart) adalah ruang kerja R&D berbasis cloud yang disediakan Alibaba Cloud untuk para developer. Dengan Cloud Development Platform, Anda dapat mengembangkan dan men-deploy DingTalk mini program serta H5 micro app secara online dengan cepat. **CloudIDE** berbasis browser hadir dengan lingkungan bawaan untuk bahasa umum seperti Node.js, Java, PHP, dan Python, sehingga Anda terhindar dari pekerjaan konfigurasi yang rumit. Fokus hanya pada pengembangan logika bisnis dan masuk ke mode pengembangan dengan **biaya nol** cukup dengan membuka browser. Selain itu, Anda tidak perlu membeli dan men-deploy server tradisional. Dengan layanan yang disediakan lini produk Alibaba Cloud Serverless, Anda mendapatkan operasi yang benar-benar bebas perawatan dan penagihan pay-per-call, sehingga sangat mengurangi biaya deployment dan operasional.

Cloud Development Platform menyediakan dua templat aplikasi DingTalk. Dengan kedua templat aplikasi ini, Anda dapat membuat dan mencoba aplikasi DingTalk dengan cepat.

- [DingTalk Room Reservation](https://developers.dingtalk.com/document/tutorial/quickly-build-h5-microapplications-meeting-room-reservation)
- [DingTalk Lottery Mini Program](https://developers.dingtalk.com/document/tutorial/dingtalk-lottery-applet)

### Prasyarat

Sebelum menggunakan templat aplikasi untuk mengembangkan aplikasi DingTalk, penuhi prasyarat berikut:

- Anda telah mendaftar dan mengaktifkan akun developer DingTalk serta memiliki izin Sub Admin dan developer. Jika belum, lihat [Menjadi Developer DingTalk](https://developers.dingtalk.com/document/app/become-a-dingtalk-developer#topic-2024337).
- Anda memiliki akun Alibaba Cloud dan telah menyelesaikan autentikasi nama asli. Jika belum, lihat [Daftar Akun Alibaba Cloud](https://account.aliyun.com/register/register.htm).

## Membuat aplikasi DingTalk

Pada bagian ini, Anda membuat H5 micro app di Developer Console.

1. Masuk ke [DingTalk Developer Console](https://open-dev.dingtalk.com/).

   **Catatan**

   Hanya Admin dan Sub Admin yang dapat masuk ke Developer Console.
2. Pada halaman **Developer Console**, pilih **Internal App Development**, lalu klik **Create App**.
3. Pada halaman Create App yang muncul, pilih tipe aplikasi yang ingin Anda buat, isi informasi dasar, dan pilih Self-service Development by Organization sebagai metode pengembangan. Kemudian klik Confirm untuk membuat aplikasi.
4. Setelah aplikasi dibuat, pada halaman **Basic Information**, salin **AgentId**, **AppKey**, dan **AppSecret** aplikasi untuk digunakan nanti.

## Membuat aplikasi cloud

Pada bagian ini, Anda menggunakan Cloud Development Platform untuk membuat aplikasi cloud backend.

1. Masuk ke [Cloud Development Platform](https://workbench.aliyun.com/page/quickstart) dengan akun Alibaba Cloud Anda.
2. Buat tim berdasarkan informasi berikut.

   Masukkan nama organisasi atau tim Anda, lalu klik **Complete Creation**.
3. Pada halaman **App Management**, klik **Create App** di pojok kanan atas.
4. Selesaikan pembuatan aplikasi sebagai berikut.

   1. Pada halaman Create App, klik **Accept Authorization** untuk menyelesaikan otorisasi akses sumber daya cloud, lalu klik **Next**.
   2. Konfigurasikan metode pembuatan aplikasi berdasarkan informasi berikut, lalu klik **Next**.

      - Bahasa pengembangan: Anda dapat memilih bahasa pengembangan untuk membuat aplikasi yang benar-benar baru. Saat ini Java, NodeJS, Python, dan PHP didukung.
      - Metode pembuatan: Cloud Development Platform saat ini menyediakan dua metode pembuatan.

        - Create directly
        - Create from a template
      - Sumber templat: Cloud Development Platform menyediakan banyak templat aplikasi. Anda dapat memilih templat aplikasi untuk membuat aplikasi yang sudah berisi kode templat. Di antaranya, "**DingTalk Room Reservation**" dan "**DingTalk Lottery Mini Program**" adalah dua templat yang dirancang khusus untuk aplikasi DingTalk. Membuat aplikasi dari templat sangat mengurangi beban kerja pengembangan Anda.
   3. Isi informasi dasar aplikasi, lalu klik **Next**.

      Cloud Development Platform menyediakan tiga layanan komputasi:

      - **Function Compute (FC)**: Serverless berbasis fungsi yang mendukung penagihan pay-per-call dan memungkinkan Anda memulai proyek dengan biaya nol. Instance elastis menyediakan sejumlah kuota gratis tertentu.
      - **SAE Compute Service**: Layanan komputasi Serverless berorientasi aplikasi yang menyediakan kemampuan ekosistem PaaS lengkap di lapisan aplikasi. Dengan penagihan pay-as-you-go dan migrasi microservice ke cloud yang berhambatan rendah, layanan ini secara sempurna menggabungkan arsitektur Serverless dengan arsitektur microservice.
      - **ASK Compute Service**: Layanan komputasi Serverless berorientasi kontainer yang tidak memerlukan perawatan node cluster atau perencanaan kapasitas, dan menagih sesuai kebutuhan berdasarkan spesifikasi kontainer yang dikonfigurasi. Cluster ASK menyediakan kompatibilitas Kubernetes yang komprehensif sekaligus menurunkan hambatan penggunaan Kubernetes, sehingga Anda dapat lebih fokus pada aplikasi Anda alih-alih mengelola infrastruktur yang mendasarinya.
   4. Klik **Complete** untuk menyelesaikan pembuatan aplikasi.

      **Catatan**

      Jika layanan cloud yang menjadi dependensi Anda belum diaktifkan, klik **Enable Now** pada masing-masing layanan untuk mengaktifkan layanan cloud tersebut.

## Mengembangkan aplikasi cloud

Setelah aplikasi dibuat, Anda dapat mulai mengembangkannya.

1. Klik **Online Development and Deployment** di pojok kanan atas untuk membuka CloudIDE.

   **Catatan**

   Membuka CloudIDE memerlukan waktu sekitar 3 menit. Harap tunggu dengan sabar.
2. Setelah CloudIDE dimulai, ia secara otomatis memuat kode aplikasi. Dalam keadaan awal, kode yang dimuat adalah file kode default yang disediakan oleh templat aplikasi yang Anda pilih saat membuat aplikasi. Sekarang Anda dapat memulai pekerjaan pengembangan aplikasi Anda.

## Mengonfigurasikan aplikasi cloud

Cloud Development Platform menyediakan tiga lingkungan Serverless yang konsisten—**Test Environment (TEST)**, **Staging Environment (PRE)**, dan **Production Environment (RELEASE)**—serta mendukung konfigurasi setiap lingkungan sesuai kebutuhan. Pada tab "**App Management**" -> "**App Details**" -> "**Development and Deployment**", Anda dapat memilih lingkungan yang sesuai untuk **konfigurasi aplikasi**.

1. Pada halaman **Development and Deployment**, pilih **lingkungan**, lalu klik **Deployment Configuration** di kolom Action untuk melihat konfigurasi deployment aplikasi saat ini.

   Anda dapat menggunakan konfigurasi default yang disediakan Cloud Development Platform, atau memilih konfigurasi lingkungan deployment kustom berdasarkan kebutuhan pengembangan Anda.
2. Pada halaman **Development and Deployment**, pilih **lingkungan**, lalu klik **App Configuration** di kolom Action.

   Klik **Edit** untuk menempel atau memasukkan beberapa pasangan `KEY=VALUE` sekaligus. Untuk cara memperoleh konfigurasi aplikasi umum, lihat [dokumentasi Cloud Development](https://help.aliyun.com/document_detail/177083.html?#h1-u5E38u89C1u7684u5E94u7528u914Du7F6Eu83B7u53D6u529Eu6CD53).

   Untuk cara memperoleh parameter aplikasi DingTalk umum, lihat [Konsep Dasar DingTalk Open Platform](https://developers.dingtalk.com/document/app/basic-concepts/title-wxx-amg-62k#title-wxx-amg-62k).

   **Catatan**

   Layanan database, penyimpanan file, dan middleware umum harus diaktifkan dan dikonfigurasikan ke dalam proyek Anda sesuai kebutuhan aplikasi untuk menyediakan layanan akses ke kode bisnis Anda. Cloud Development Platform tidak mengonsumsi konfigurasi layanan ini.

## Men-deploy aplikasi cloud

1. Setelah konfigurasi aplikasi selesai, klik **Online Development and Deployment** untuk membuka **CloudIDE**.
2. Klik **Deploy**, pilih lingkungan yang akan di-deploy, lalu klik **Deploy**.

   **Catatan**

   Seluruh proses deployment memerlukan waktu sekitar 5 menit. Harap tunggu dengan sabar.

   Setelah deployment selesai untuk lingkungan Test dan Staging, Cloud Development Platform mengalokasikan domain sementara gratis untuk pengujian.
3. Ikat domain kustom.

   Jika Anda perlu mengikat domain sendiri, ikuti langkah-langkah berikut.

   1. Setelah deployment berhasil, kembali ke halaman **App Details** > **Development and Deployment**, dan klik **Domain Configuration** setelah lingkungan yang sesuai. Anda dapat melihat domain yang terikat pada aplikasi. Salin **API Gateway Domain**, yaitu **alamat CNAME**.
   2. Masuk ke [Alibaba Cloud DNS Console](https://dns.console.aliyun.com/?spm=a2c4g.11186623.2.12.3b9859cbIuhfCy#/dns/domainList). Pada halaman **Domain Resolution**, klik **domain** untuk masuk ke halaman **Resolution Settings**.
   3. Klik Add Record, lalu tambahkan record berdasarkan informasi berikut.

      - **Record Type**: Pilih CNAME.
      - **Host Record**: Masukkan domain yang ingin Anda buat.
      - **Resolution Line**: Pilih resolution line Anda.
      - **Record Value**: Tempel **alamat API Gateway Domain** yang Anda salin sebelumnya.
      - **TTL**: Pertahankan nilai default atau tetapkan nilai yang Anda anggap sesuai.
   4. Setelah domain dikonfigurasi, kembali ke **Cloud Development Platform**. Pada halaman **App Details** > **Development and Deployment**, pilih lingkungan yang sesuai, klik **Domain Configuration**, lalu konfigurasikan domain yang telah Anda buat.
   5. Masuk ke CloudIDE, buka plugin pengujian deployment berlabel **WB**, lalu pilih lingkungan yang sesuai, dan klik **Deploy**.

      Setelah deployment berhasil, Anda dapat melihat pesan keberhasilan deployment di panel **Output** di sebelah kanan. Pada area yang disorot, Anda dapat melihat bahwa domain yang baru saja Anda ikat telah berhasil terikat, tetapi CNAME belum berlaku.

      Buka terminal di komputer Anda dan masukkan domain yang baru saja Anda ikat. Jika Anda melihat pesan yang serupa dengan berikut, CNAME telah berlaku.

      **Catatan**

      Waktu yang diperlukan agar berlaku bergantung pada nilai TTL yang Anda tetapkan saat membuat resolusi domain sebelumnya. Harap tunggu dengan sabar.

## Konfigurasi dan rilis aplikasi DingTalk

1. Konfigurasi mini program.

   1. Buka alat IDE mini program, buka file appconfig.js, dan ubah domain aplikasi menjadi domain sementara yang disediakan Cloud Development Platform saat aplikasi di-deploy, atau domain kustom yang Anda ikat.
   2. Masuk ke [Developer Console](https://open-dev.dingtalk.com/#/index), lalu klik **Security Center** pada halaman **App Details**, dan **Add an HTTP Security Domain**. Tetapkan HTTP security domain ke **domain sementara** yang disediakan Cloud Development Platform saat aplikasi di-deploy, atau **domain kustom** yang Anda ikat.
2. Konfigurasi H5 micro app.

   1. Masuk ke [DingTalk Developer Console](https://open-dev.dingtalk.com/#/corph5), dan klik H5 micro app yang Anda buat. Pada halaman detail aplikasi, klik **Development Management**, lalu konfigurasikan informasi berikut.

      - Server egress IP: Masukkan 255.255.255.255.
      - App home page URL: Masukkan alamat domain sementara yang dihasilkan setelah aplikasi di-deploy, atau alamat domain kustom yang Anda ikat.
3. Untuk merilis aplikasi, lihat [Manajemen Versi dan Rilis](https://developers.dingtalk.com/document/app/publish-orgapp).
