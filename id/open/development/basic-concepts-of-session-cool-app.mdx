## Proses publikasi aplikasi grup

## Alur penggunaan

Sebelum memulai, pastikan Anda telah menyelesaikan persiapan untuk [menjadi developer DingTalk](https://open.dingtalk.com/document/isvapp/become-a-dingtalk-developer#). Proses pengembangan aplikasi grup adalah sebagai berikut:

1. [Publikasikan aplikasi perusahaan pihak ketiga](https://open.dingtalk.com/document/isvapp/become-an-application-service-provider#). Kembangkan aplikasi grup berdasarkan aplikasi perusahaan pihak ketiga yang telah dipublikasikan.
2. [Konfigurasikan informasi dasar aplikasi grup](https://open.dingtalk.com/document/isvapp/configure-the-basic-information-of-the-group-application#). Di **Ekstensi Cool App** pada aplikasi perusahaan pihak ketiga, buat aplikasi grup dan konfigurasikan informasi dasarnya. Setelah aplikasi grup berhasil dibuat, Anda dapat memperoleh kode aplikasi grup.
3. [Siapkan push pesan](https://open.dingtalk.com/document/isvapp/group-application-development-and-access#). Di **Push Pesan**, kembangkan dan hubungkan Bot.
4. [Kembangkan kartu interaktif](https://open.dingtalk.com/document/isvapp/interactive-card-development-and-access#). Dengan menghubungkan Bot, Anda dapat mengirim kartu interaktif dan lainnya.
5. [Kirim untuk peninjauan dan publikasikan aplikasi grup](https://open.dingtalk.com/document/isvapp/group-application-operations#). Setelah pengembangan aplikasi grup selesai, kirim untuk peninjauan dan hubungi tim operasional untuk mempublikasikannya.
6. [Aktifkan dan gunakan aplikasi grup](https://open.dingtalk.com/document/isvapp/enable-and-use-a-group-application-cool#). Setelah aplikasi grup dipublikasikan ke Cool App Center, aktifkan aplikasi tersebut.

## API umum untuk aplikasi grup

Untuk API sisi klien aplikasi grup, lihat [Instal Cool App dan Tambahkan ke Grup](https://open.dingtalk.com/document/isvapp/install-cool-applications-and-add-them-to-the-group#).
