## Proses publikasi aplikasi grup

## Alur penggunaan

Sebelum memulai, pastikan Anda telah menyelesaikan persiapan untuk [menjadi developer DingTalk](/id/open/dingstart/become-a-dingtalk-developer). Proses pengembangan aplikasi grup adalah sebagai berikut:

1. Publikasikan aplikasi perusahaan pihak ketiga. Kembangkan aplikasi grup berdasarkan aplikasi perusahaan pihak ketiga yang telah dipublikasikan.
2. Konfigurasikan informasi dasar aplikasi grup. Di **Ekstensi Cool App** pada aplikasi perusahaan pihak ketiga, buat aplikasi grup dan konfigurasikan informasi dasarnya. Setelah aplikasi grup berhasil dibuat, Anda dapat memperoleh kode aplikasi grup.
3. Siapkan push pesan. Di **Push Pesan**, kembangkan dan hubungkan Bot.
4. Kembangkan kartu interaktif. Dengan menghubungkan Bot, Anda dapat mengirim kartu interaktif dan lainnya.
5. Kirim untuk peninjauan dan publikasikan aplikasi grup. Setelah pengembangan aplikasi grup selesai, kirim untuk peninjauan dan hubungi tim operasional untuk mempublikasikannya.
6. Aktifkan dan gunakan aplikasi grup. Setelah aplikasi grup dipublikasikan ke Cool App Center, aktifkan aplikasi tersebut.

## API umum untuk aplikasi grup

Untuk API sisi klien aplikasi grup, lihat Instal Cool App dan Tambahkan ke Grup.
