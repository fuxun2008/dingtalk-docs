---
title: "Mencari pengguna Akun Perusahaan berdasarkan nomor ponsel"
description: "Panggil API ini untuk mencari userId pengguna Akun Perusahaan berdasarkan nomor ponsel di DingTalk. Setelah karyawan keluar, userId tidak dapat lagi diambil melalui nomor ponsel."
---

Panggil API ini untuk mendapatkan ID pengguna dari pengguna Akun Perusahaan berdasarkan nomor ponsel. Jika karyawan telah keluar dari organisasi, ID pengguna tidak dapat diambil berdasarkan nomor ponsel.

## Permintaan

| **Informasi dasar** | |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/topapi/v2/user/getbymobile |
| Metode HTTP | POST |
| Tipe aplikasi yang didukung | appType-Aplikasi internal |
| Izin yang diperlukan | permission-qyapi_get_member_by_mobile-Izin untuk mendapatkan informasi dasar pengguna berdasarkan nomor ponsel |

### Parameter kueri

| Nama | Tipe | Wajib | Contoh | Deskripsi |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | be3Fxxxx | Kredensial aplikasi yang digunakan untuk memanggil API ini. Dapatkan dengan memanggil API untuk mendapatkan [access_token dari aplikasi internal](/id/open/development/obtain-orgapp-token). |

### Isi permintaan

| Nama | Tipe | Wajib | Contoh | Deskripsi |
| --- | --- | --- | --- | --- |
| mobile | String | Ya | 185xxxxx676 | Nomor ponsel pengguna. |
| support_exclusive_account_search | Boolean | Ya | true | Apakah mendukung pencarian Akun Perusahaan berdasarkan nomor ponsel.   - **true**: Didukung. - **false**: Tidak didukung.   **Catatan**     - Hanya berlaku untuk Akun Perusahaan. - Hanya Akun Perusahaan yang dibuat oleh organisasi saat ini yang dapat dicari. |

### Contoh permintaan

```curl
curl -X POST "https://api.dingtalk.io/topapi/v2/user/getbymobile" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=a16xxxxa2efbee' \
-d 'mobile=1851xxxx676' \
-d 'support_exclusive_account_search=true'
```

Java

```text
DingTalkClient client = new DefaultDingTalkClient("https://api.dingtalk.io/topapi/v2/user/getbymobile");
OapiV2UserGetbymobileRequest req = new OapiV2UserGetbymobileRequest();

OapiV2UserGetbymobileResponse rsp = client.execute(req, acces_token);
System.out.println(rsp.getBody());
```

## Respons

### Isi respons

| Nama | Tipe | Contoh | Deskripsi |
| --- | --- | --- | --- |
| request_id | String | 5w82ciuur781 | ID permintaan. |
| errcode | Number | 0 | Kode pengembalian. |
| errmsg | String | ok | Deskripsi dari kode pengembalian. |
| result | Object |  | Hasil yang dikembalikan. |
| userid | String | zhangsan | ID pengguna dari karyawan. |
| exclusive_account_userid_list | String[] | ["zxxxx","lixxxi"] | Daftar ID pengguna dari karyawan Akun Perusahaan.  **Catatan**  Hanya Akun Perusahaan yang dibuat oleh organisasi saat ini yang dikembalikan. |

### Contoh isi respons

```json
{
  "errcode":"0",
  "result":{
    "exclusive_account_userid_list":"[\"zxxxx\",\"lixxxi\"]",
    "userid":"zhangsan"
  },
  "errmsg":"ok"
}
```

### Kode error

Jika terjadi error saat memanggil API ini, temukan solusinya di dokumen [Kode error global](/id/open/development/server-api-error-codes-1) berdasarkan pesan error.

| Kode error (errcode) | Pesan error (errmsg) | Solusi |
| --- | --- | --- |
| 400002 | Invalid parameter | Pastikan parameter diisi sesuai ketentuan dalam dokumentasi di atas. |
| 40104 | Invalid mobile number in the organization | Pastikan nomor ponsel sudah benar. |
| 60121 | User not found | Pastikan informasi diisi dengan benar. |
| -1 | System busy | Coba lagi nanti. |
