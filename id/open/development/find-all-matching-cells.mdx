---

Panggil API ini untuk mencari semua sel yang berisi teks target di dalam Lembar Kerja tertentu pada DingTalk Spreadsheet, dan mengembalikan daftar posisi sel yang cocok. Ini cocok untuk skenario ketika konten tertentu perlu ditemukan secara massal dalam kumpulan data yang besar. API ini mendukung beberapa mode pencarian, termasuk pencocokan persis, sensitivitas huruf, ekspresi reguler, dan pencarian di dalam formula.

## Permintaan

### Informasi dasar

| Bidang | Nilai |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/doc/workbooks/{workbookId}/sheets/{sheetId}/findAll` |
| Metode HTTP | POST |
| Tipe aplikasi yang didukung | appType-Aplikasi internal |
| Izin yang diperlukan | permission-Document.Workbook.Read-Izin baca DingTalk Spreadsheet |

### Header permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Panggil API [Mendapatkan access token aplikasi internal](/id/open/development/obtain-the-access-token-of-an-internal-app) untuk memperolehnya. |

### Parameter path

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| workbookId | String | Ya | ID file spreadsheet. `nodeId(dentryUuid)` yang dikembalikan oleh [API Knowledge Base](/id/open/development/knowledge-base-overview) adalah `workbookId` spreadsheet. Anda dapat memperolehnya dengan memanggil API [Mendapatkan node](https://open.dingtalk.com/document/development/get-node) dan [Membuat dokumen Knowledge Base](/id/open/development/create-team-space-document). |
| sheetId | String | Ya | ID atau judul Lembar Kerja. Panggil API [Mendapatkan semua Lembar Kerja](/id/open/development/obtain-all-worksheets) untuk memperoleh ID dan judul Lembar Kerja. |

### Parameter query

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| operatorId | String | Ya | unionId operator. Panggil API [Kueri detail pengguna](/id/open/development/query-user-details) untuk memperolehnya. Jika operator tidak memiliki izin, API mengembalikan error `The operator has no permission`. |
| select | String | Tidak | Memfilter bidang yang akan dikembalikan. Jika parameter ini tidak ditentukan, semua bidang dikembalikan.   - Jika select=a1Notation, hanya bidang a1Notation yang dikembalikan. - Untuk mengembalikan beberapa bidang, pisahkan dengan koma. Misalnya, select=a1Notation,values hanya mengembalikan bidang a1Notation dan values. Menentukan parameter ini disarankan untuk meningkatkan performa dan menghindari timeout API ketika nilai kembalian tambahan ditambahkan di masa mendatang. |

### Isi permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| text | String | Ya | Teks yang akan dicari. Jika **useRegExp** diaktifkan, ini adalah pola ekspresi reguler. Contoh: "\\d+" |
| findOptions | Object | Ya | Opsi pencarian. |
| matchEntireCell | Boolean | Tidak | Apakah mencocokkan seluruh sel. Nilai yang valid:   - **true**: Ya - **false**: Tidak (default) |
| matchCase | Boolean | Tidak | Apakah pencarian bersifat sensitif huruf. Nilai yang valid:   - **true**: Ya - **false**: Tidak (default) |
| useRegExp | Boolean | Tidak | Apakah text merupakan ekspresi reguler. Nilai yang valid:   - **true**: Ya - **false**: Tidak (default) |
| matchFormulaText | Boolean | Tidak | Apakah mencari berdasarkan teks formula mentah. Nilai yang valid:   - **true**: Ya - **false**: Tidak (default)   Misalnya, jika sebuah sel diisi dengan formula "=A1+B1" dan nilai yang ditampilkan adalah 4:   - Ketika teks pencarian adalah "4" dan matchFormulaText bernilai true, sel tersebut tidak disertakan dalam hasil. - Ketika teks pencarian adalah "=A1" dan matchFormulaText bernilai true, sel tersebut disertakan dalam hasil. |
| scope | String | Tidak | Cakupan pencarian. Formatnya adalah alamat Range yang dinyatakan dalam notasi A1. |
| includeHidden | Boolean | Tidak | Apakah menyertakan sel tersembunyi, yaitu sel yang tidak terlihat akibat baris atau kolom tersembunyi, filter, grup, atau fitur sejenis. Sel yang tidak diizinkan untuk dilihat oleh pengguna tidak disertakan. Nilai yang valid:   - **true**: Ya - **false**: Tidak (default) |
| unionCells | Boolean | Ya | Apakah mengagregasi alamat sel yang ditemukan. Agregasi disarankan; jika tidak, sejumlah besar alamat mungkin dikembalikan. Nilai yang valid:   - **true**: Ya - **false**: Tidak (default) |
