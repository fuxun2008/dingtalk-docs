Panggil API ini untuk menghapus informasi Wi-Fi secara massal dari grup absensi tertentu.

## Permintaan

| **Informasi dasar** | |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/topapi/attendance/group/wifis/remove |
| Metode HTTP | POST |
| Tipe aplikasi yang didukung | appType-Aplikasi internal |
| Izin yang wajib | permission-qyapi_attendance_group_manage-Izin pengelolaan grup absensi |

### Parameter query

| Nama | Tipe | Wajib | Contoh | Deskripsi |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | 6d1bxxxx | Kredensial aplikasi yang digunakan untuk memanggil API ini. Dapatkan dengan memanggil API [Dapatkan access_token aplikasi internal](/id/open/development/obtain-orgapp-token). |

### Isi permintaan

| Nama | Tipe | Wajib | Contoh | Deskripsi |
| --- | --- | --- | --- | --- |
| op_userid | String | Tidak | user01 | userId operator. |
| group_key | String | Ya | CEDDFxxxx | ID grup absensi.  **Catatan**  Jika Anda mengidentifikasi grup absensi berdasarkan group_id, panggil API [Konversi groupId ke groupKey](/id/open/development/groupid-to-groupkey) untuk mengonversi group_id menjadi group_key. |
| wifi_key_list | String | Ya | 0151Exxxx | Wi-Fi key. Dapatkan dengan memanggil API [Kueri informasi Wi-Fi secara massal](/id/open/development/batch-query-wifi-under-attendance-group). Hapus hingga 100 entri Wi-Fi per panggilan. |

### Contoh permintaan

```curl
curl -X POST "https://api.dingtalk.io/topapi/attendance/group/wifis/remove" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=deb9baxxxx32b89' \
-d 'group_key=0151E022xxxx917E876' \
-d 'op_userid=123456' \
-d 'wifi_key_list=0151E02xxxx917E876'
```

## Respons

### Isi respons

| Nama | Tipe | Contoh | Deskripsi |
| --- | --- | --- | --- |
| result | Result |  | Daftar wifiId yang berhasil dihapus. |
| error_info_list | ErrorInfo[] |  | Daftar kegagalan. |
| failure_list | String[] | 0151EEDDDF0xxxx | Daftar error. |
| msg | String | business fault | Deskripsi error. |
| code | String | 1000 | Kode error. |
| success_list | String[] | 0151EEDDDF0xxxx | Daftar entri yang berhasil. |
| errcode | Number | 0 | Kode pengembalian. |
| errmsg | String | ok | Deskripsi kode pengembalian. |
| success | Boolean | true | Menunjukkan apakah panggilan berhasil.   - **true**: Berhasil - **false**: Gagal |
| request_id | String | 7o76z7s5cett | ID permintaan. |

### Contoh isi respons

```json
{
  "errcode": 0,
  "errmsg":"ok",
  "result": {
    "success_list": [
      "0151Exxxx",
    ]
  },
  "success": true,
  "request_id": "7o76z7s5cett"
}
```

### Kode error

Jika panggilan mengembalikan error, cari solusinya di dokumen [Kode error global](/id/open/development/server-api-error-codes-1) berdasarkan pesan error.
