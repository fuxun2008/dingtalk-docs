Panduan ini menjelaskan cara memecahkan masalah umum yang terjadi selama proses unggah file.

## Pengiriman file gagal

Unggah file terdiri dari tiga langkah. Untuk detailnya, lihat [Mendapatkan informasi unggah file](/id/open/development/obtain-file-upload-informations).

1. Dapatkan informasi unggah file.
2. Unggah file ke OSS melalui HTTP.
3. Kirim file.

### Pastikan langkah 2 (mengunggah file ke OSS) mengembalikan 200.

## Gagal mengunggah file ke OSS

Periksa kode Anda. Ganti `<authorization>`, `<x-oss-date>`, dan `<url>` dengan nilai yang dikembalikan oleh API informasi unggah file pada langkah 1. Ganti `a.txt` dengan file lokal yang ada, lalu jalankan perintah berikut:

```bash
curl -v -T a.txt \
--header "Authorization: <authorization>" \
--header "x-oss-date: <x-oss-date>" \
--url "<url>"
```

- Jika curl mengembalikan error `RequestTimeTooSkewed`, informasi unggah telah kedaluwarsa. Dapatkan kembali informasi unggah file.
- Jika curl mengembalikan 200, masalahnya ada pada kode Anda. Dokumentasi menyediakan demo dalam bahasa pemrograman terkait. Rujuk contoh yang relevan untuk memecahkan masalah kode Anda.
- Jika unggah melalui kode Anda mengembalikan `SignatureDoesNotMatch`, header HTTP request kemungkinan besar menyertakan `contentType` tambahan. Setel secara eksplisit menjadi kosong. (Anda dapat mencetak header request untuk memeriksa nilai `contentType`.)
- Jika curl tidak mengembalikan 200:

  - Jika terjadi kegagalan resolusi domain atau kegagalan koneksi, lakukan pemecahan masalah sebagai berikut:

    - `ping <domain or IP>`
    - `telnet <domain or IP> 443`
    - Hubungkan ke hotspot seluler lalu jalankan ping dan telnet, atau beralih ke jaringan lain dan coba lagi.
    - Nonaktifkan firewall di komputer Anda, lalu jalankan ping dan telnet.
    - Hubungi tim IT Anda untuk menambahkan domain publik OSS ke daftar izin. Lihat **Lampiran I** di bagian bawah dokumen ini untuk daftar domainnya.
    - Untuk penyimpanan khusus (dedicated storage), hubungi tim operasional penyimpanan khusus untuk menyelidiki masalah konektivitas jaringan.
