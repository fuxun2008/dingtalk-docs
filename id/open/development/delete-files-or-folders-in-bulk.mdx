Panggil API ini untuk menghapus file atau folder secara massal.

## Permintaan

### Informasi dasar

| Bidang | Nilai |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/storage/spaces/{spaceId}/dentries/batchRemove` |
| Metode HTTP | POST |
| Tipe aplikasi yang didukung | appType-Internal app　appType-Third-party enterprise app |
| Izin yang diperlukan | permission-Storage.File.Write-Organization storage file write permission |

### Header permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Dapatkan sebagai berikut:   - Untuk aplikasi internal, panggil API [Mendapatkan access token aplikasi internal](/id/open/development/obtain-the-access-token-of-an-internal-app). - Untuk aplikasi perusahaan pihak ketiga, panggil API [Mendapatkan access token organisasi yang diotorisasi oleh aplikasi pihak ketiga](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1). |

### Parameter jalur

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| spaceId | String | Ya | ID ruang. Panggil API [Menambahkan ruang](/id/open/development/add-space) untuk mendapatkan nilai parameter id. |

### Parameter kueri

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| unionId | String | Ya | unionId dari operator. Panggil API [Mengkueri detail pengguna](/id/open/development/query-user-details) untuk mendapatkan nilai parameter unionid. |

### Isi permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| dentryIds | Array of String | Ya | Daftar ID file atau folder. Maksimum 50 ID diperbolehkan. Panggil API [Mendapatkan daftar file atau folder](/id/open/development/get-a-list-of-files-or-folders) atau [Mendapatkan spaceId dan dentryId dari dentryUuid](/id/open/development/api-getdentryidbyuuid) untuk mendapatkan nilai parameter id. |
| option | Object | Tidak | Parameter opsional. |
| toRecycleBin | Boolean | Tidak | Apakah akan memindahkan ke Tempat Sampah.   - **true**: Pindahkan ke Tempat Sampah. - **false** (default): Jangan pindahkan ke Tempat Sampah; hapus langsung. |

### Contoh permintaan

```http
POST /v1.0/storage/spaces/457xxxxx/dentries/batchRemove?unionId=CHYxxxxx HTTP/1.1
```

## Respons

### Isi respons

| Nama | Tipe | Deskripsi |
| --- | --- | --- |
| resultItems | Array | Daftar hasil penghapusan massal. |
| spaceId | String | ID ruang dari file atau folder sumber. |
| dentryId | String | ID dari file atau folder sumber. |
| async | Boolean | Apakah ini merupakan tugas asinkron.   - **true**: Ya. - **false**: Tidak.   Jika objek target memiliki node anak, operasi diproses secara asinkron. |
| success | Boolean | Apakah operasi berhasil.   - **true**: Berhasil. - **false**: Gagal.   Bidang ini kosong untuk tugas asinkron. |
| errorCode | String | Alasan error.  Bidang ini kosong untuk tugas asinkron. |
| taskId | String | ID tugas asinkron, yang dapat digunakan untuk mengkueri status eksekusi tugas. |
