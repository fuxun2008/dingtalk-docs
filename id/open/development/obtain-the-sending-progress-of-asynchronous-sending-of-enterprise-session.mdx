Panggil API ini untuk mendapatkan progres pengiriman notifikasi kerja. Ini berguna saat organisasi Anda perlu memantau status push pesan atau menyelesaikan masalah error pengiriman pesan.

## Deskripsi panggilan API

API ini hanya mengembalikan progres pengiriman notifikasi kerja yang dikirim dalam 7 hari terakhir.

## Permintaan

| **Informasi dasar** | |
| --- | --- |
| URL HTTP | https://oapi.dingtalk.io/topapi/message/corpconversation/getsendprogress |
| Metode HTTP | POST |
| Tipe aplikasi yang didukung | appType-Aplikasi internal, appType-Aplikasi perusahaan pihak ketiga |
| Izin yang diperlukan | permission-qyapi_base-Izin dasar yang diperlukan untuk memanggil API perusahaan |

### Parameter kueri

| Nama | Tipe | Wajib | Contoh | Deskripsi |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | bE74xxxx | Kredensial aplikasi yang digunakan untuk memanggil API ini.   - Untuk aplikasi internal, dapatkan dengan memanggil API untuk mendapatkan [access_token aplikasi internal](/id/open/development/obtain-orgapp-token). - Untuk aplikasi perusahaan pihak ketiga, dapatkan dengan memanggil API untuk mendapatkan access_token perusahaan pihak ketiga. |

### Isi permintaan

| Nama | Tipe | Wajib | Contoh | Deskripsi |
| --- | --- | --- | --- | --- |
| agent_id | Number | Ya | 836390886 | Agent ID dari aplikasi mikro yang digunakan untuk mengirim pesan.   - Untuk aplikasi internal, lihat pada halaman detail aplikasi di [Developer Backend](https://open-dev.dingtalk.io/#/appMgr/inner/h5/836390886/1). - Untuk aplikasi perusahaan pihak ketiga, dapatkan dengan memanggil API untuk mendapatkan informasi otorisasi perusahaan. |
| task_id | Number | Ya | 256271667526 | ID tugas yang dikembalikan oleh DingTalk saat pesan dikirim. Panggil API [Kirim notifikasi kerja](/id/open/development/asynchronous-sending-of-enterprise-session-messages) untuk mendapatkan nilai task_id.  **Catatan**  Hanya tugas yang dibuat dalam 24 jam terakhir yang dapat dikueri. |

### Contoh permintaan

```curl
curl -X POST "https://oapi.dingtalk.io/topapi/message/corpconversation/getsendprogress" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=a0a25xxxxed3ff' \
-d 'agent_id=123' \
-d 'task_id=456'
```

```text

```

## Respons

### Isi respons

| Nama | Tipe | Contoh | Deskripsi |
| --- | --- | --- | --- |
| request_id | String | 5y2znla8tw3d | ID permintaan. |
| errcode | Number | 0 | Kode pengembalian. |
| errmsg | String | ok | Deskripsi kode pengembalian. |
| progress | AsyncSendProgress |  | Hasil yang dikembalikan. |
| progress_in_percent | Number | 100 | Persentase pemrosesan. Rentang nilai: 0 hingga 100. |
| status | Number | 2 | Status eksekusi tugas:   - **0**: Belum dimulai - **1**: Sedang berlangsung - **2**: Selesai |

### Contoh respons

```json
{
  "errcode": 0,
  "errmsg":"ok",
  "progress": {
    "progress_in_percent": 100,
    "status": 2
  },
  "request_id": "5y2znla8tw3d"
}
```

### Kode error

Jika terjadi error saat Anda memanggil API ini, lihat dokumen [Kode error global](/id/open/development/server-api-error-codes-1) untuk solusi berdasarkan pesan error.

| Kode error (errorcode) | Pesan error (errmsg) | Solusi |
| --- | --- | --- |
| 40035 | Invalid parameter | Verifikasi bahwa task_id atau agent_id sudah benar. |
| 500 | System error | Terjadi error sistem yang tidak diketahui. |
