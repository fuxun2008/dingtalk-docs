Panggil API ini untuk memulihkan item dari Tempat Sampah kembali ke lokasi aslinya.

## Permintaan

### Informasi dasar

| Bidang | Nilai |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/storage/recycleBins/{recycleBinId}/recycleItems/{recycleItemId}/restore` |
| Metode HTTP | POST |
| Tipe aplikasi yang didukung | appType-Aplikasi internal　appType-Aplikasi perusahaan pihak ketiga |
| Izin yang diperlukan | permission-Storage.RecycleBin.Write-Izin tulis untuk Tempat Sampah penyimpanan organisasi |

### Header permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses yang digunakan untuk memanggil API ini. Dapatkan sebagai berikut:   - Untuk aplikasi internal, panggil API [Memperoleh access token aplikasi internal](/id/open/development/obtain-the-access-token-of-an-internal-app#). - Untuk aplikasi perusahaan pihak ketiga, panggil API [Memperoleh access token perusahaan yang diberi otorisasi](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#). |

### Parameter path

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| recycleBinId | String | Ya | ID Tempat Sampah. Panggil API [Memperoleh informasi Tempat Sampah](/id/open/development/obtain-information-about-the-recycle-bin#) untuk mendapatkannya. |
| recycleItemId | String | Ya | ID item Tempat Sampah. Panggil API [Memperoleh daftar item Tempat Sampah](/id/open/development/gets-the-list-of-recycle-items#) untuk mendapatkan nilai parameter id. |

### Parameter query

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| unionId | String | Ya | unionId operator. Panggil API [Kueri detail pengguna](/id/open/development/query-user-details#) untuk mendapatkannya. |

### Isi permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| option | Object | Tidak | Parameter opsional. |
| conflictStrategy | String | Tidak | Strategi konflik nama file. File dengan nama yang sama mungkin sudah ada di path asli saat pemulihan.   - **AUTO_RENAME**: Ganti nama file secara otomatis. Ini adalah nilai default. - **OVERWRITE**: Timpa file yang ada. - **RETURN_DENTRY_IF_EXISTS**: Kembalikan file yang ada. - **RETURN_ERROR_IF_EXISTS**: Kembalikan error jika file sudah ada. |
