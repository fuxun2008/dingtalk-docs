---

Panggil API ini untuk mendapatkan data cuti dari laporan absensi cerdas DingTalk berdasarkan nama cuti dan ID pengguna. Data yang dikembalikan mencakup semua nilai di kolom cuti laporan dalam periode waktu tertentu. Kolom cuti bersifat dinamis, sehingga Anda wajib menentukan nama cuti untuk mendapatkan datanya.

## Deskripsi panggilan API

Untuk kemampuan akses dan pemanfaatan data lainnya, buka Data Asset Platform. Data Asset Platform (dPaaS) adalah platform pengelolaan data terpadu untuk organisasi. Dibangun di atas DingTalk, platform ini menyediakan layanan data yang aman, skalabel, dan mudah dipelihara untuk mendukung pengambilan keputusan bisnis.

## Permintaan

| **Informasi dasar** | |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/topapi/attendance/getleavetimebynames |
| Metode HTTP | POST |
| Tipe aplikasi yang didukung | Aplikasi internal, Aplikasi perusahaan pihak ketiga |
| Izin yang diperlukan | permission-qyapi_base-Izin dasar yang diperlukan untuk memanggil API organisasi |

### Parameter query

| Nama | Tipe | Wajib | Contoh | Deskripsi |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | 6d1bxxxx | Kredensial aplikasi yang digunakan untuk memanggil API ini.   - Untuk Aplikasi internal, panggil API [Dapatkan access_token Aplikasi internal](/id/open/development/obtain-orgapp-token) untuk memperolehnya. - Untuk Aplikasi perusahaan pihak ketiga, panggil API untuk mendapatkan access_token organisasi pihak ketiga untuk memperolehnya. |

### Isi permintaan

| Nama | Tipe | Wajib | Contoh | Deskripsi |
| --- | --- | --- | --- | --- |
| userid | String | Ya | manager123 | ID pengguna dari pengguna. |
| leave_names | String | Ya | Cuti tahunan | Nama cuti. Pisahkan beberapa nama dengan koma. Panjang maksimum: 20. |
| from_date | Date | Ya | 2020-09-09 12:12:12 | Waktu mulai. Data yang lebih lama dari 225 hari tidak didukung. |
| to_date | Date | Ya | 2020-09-11 12:12:12 | Waktu selesai. Selang antara waktu mulai dan waktu selesai harus dalam 31 hari. |

### Contoh permintaan

```curl
curl -X POST "https://api.dingtalk.io/topapi/attendance/getleavetimebynames" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=1b8b85xxxxx3ccfdd' \
-d 'from_date=2018-07-11+12%3A12%3A12' \
-d 'leave_names=Cuti+tahunan' \
-d 'to_date=2018-07-11+12%3A12%3A12' \
-d 'userid=zhangsan'
```

Java

```text

req.setUserid("zhangsan");
req.setLeaveNames("Cuti tahunan");
req.setFromDate(StringUtils.parseDateTime("2020-09-01 00:00:00"));
req.setToDate(StringUtils.parseDateTime("2020-09-30 00:00:00"));
OapiAttendanceGetleavetimebynamesResponse rsp = client.execute(req, access_token);
System.out.println(rsp.getBody());
```

## Respons

| --- | --- | --- | --- |

| columnvo | ColumnForTopVo |  | Informasi kolom. |
| name | String | Cuti pribadi | Nama cuti. |
| sub_type | Number | 0 | Subtipe. |
| status | Number | 0 | Status kolom. |
| alias | String | leave_ | Alias. |
| type | Number | 0 | Tipe kolom. |
