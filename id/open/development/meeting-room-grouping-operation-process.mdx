Dokumen ini menjelaskan cara membuat aplikasi internal dan menggunakan API yang disediakan oleh Ruang rapat pintar untuk membuat, memperbarui, mencari, dan menghapus grup ruang rapat.

## Hasil yang diharapkan

Hasil grup ruang rapat ditampilkan di bawah ini:

## Gambaran umum proses

Prasyarat: Selesaikan proses [Pembuatan dan konfigurasi aplikasi](/id/open/dingstart/create-application).

Langkah 1: Dapatkan Kredensial aplikasi, termasuk client ID dan Client Secret.

Langkah 2: Ajukan izin API untuk API Ruang rapat pintar.

Langkah 3: Dapatkan Kredensial akses aplikasi dengan mengikuti [Dapatkan access token aplikasi internal](/id/open/development/obtain-the-access-token-of-an-internal-app). Saat memanggil API, access token digunakan untuk mengautentikasi pemanggil.

Langkah 4: Panggil API ruang rapat:

1. Panggil Server API [Buat grup ruang rapat](/id/open/development/create-meeting-room-groups) dan dapatkan bidang `result` dari respons, yang merupakan ID grup ruang rapat.
2. Gunakan ID grup ruang rapat untuk memanggil Server API [Perbarui grup ruang rapat](/id/open/development/update-meeting-room-groups) guna memperbarui informasi grup ruang rapat.
3. Panggil Server API [Cari daftar grup ruang rapat](/id/open/development/query-meeting-rooms-groups) untuk mengambil daftar grup ruang rapat.
4. Gunakan ID grup ruang rapat untuk memanggil Server API [Cari grup ruang rapat](/id/open/development/query-meeting-room-groups) guna mengambil informasi rinci tentang satu grup ruang rapat.
5. Gunakan ID grup ruang rapat untuk memanggil Server API [Hapus grup ruang rapat](/id/open/development/delete-a-conference-room-group) guna menghapus grup ruang rapat.

## Prasyarat

Selesaikan proses [Pembuatan dan konfigurasi aplikasi](/id/open/dingstart/create-application).

## Langkah 1: Dapatkan Kredensial aplikasi

1. Pilih aplikasi target dan buka halaman detail aplikasi. Klik **Basic Information** > **Credentials and Basic Information**.
2. Dapatkan client ID dan Client Secret.

## Langkah 2: Tambahkan izin API

Klik **Development Configuration** > **Kelola izin**. Pada kotak pencarian izin, masukkan `VideoConference.Conference.Write` dan `VideoConference.Conference.Read` secara berurutan, lalu ajukan izinnya.

## Langkah 3: Dapatkan access token aplikasi

<Warning>
Untuk perbedaan antara versi Server API, lihat perbandingan API lama vs. API baru. API berikut semuanya menggunakan Server API. Untuk unduhan SDK, lihat halaman unduh SDK sisi server.
</Warning>

Gunakan client ID dan Client Secret yang diperoleh pada Langkah 1 untuk mendapatkan access token aplikasi dengan mengikuti [Dapatkan access token aplikasi internal](/id/open/development/obtain-the-access-token-of-an-internal-app).

```java
 public void getAccessToken() throws Exception {
        Config config = new Config();
        config.protocol = "https";
        config.regionId = "central";
        com.aliyun.dingtalkoauth2_1_0.Client client = new com.aliyun.dingtalkoauth2_1_0.Client(config);
        GetAccessTokenRequest accessTokenRequest = new GetAccessTokenRequest()
                .setAppKey("din*********hgn")
                .setAppSecret("9G_O************mBkhgGIO");
        GetAccessTokenResponse accessToken = client.getAccessToken(accessTokenRequest);
        System.out.println(JSON.toJSONString(accessToken.getBody()));
    }
```
