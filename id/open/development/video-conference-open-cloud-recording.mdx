Panggil API ini untuk memulai perekaman cloud untuk Rapat Video.

## Permintaan

### Informasi dasar

| Bidang | Nilai |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/conference/videoConferences/{conferenceId}/cloudRecords/start` |
| Metode HTTP | POST |
| Tipe aplikasi yang didukung | appType-Internal app　appType-Third-party enterprise app |
| Izin yang diperlukan | permission-VideoConference.Conference.Write-Video Meeting information management permission |

### Header permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Peroleh dengan cara berikut:   - Untuk Aplikasi internal, panggil API [Memperoleh access token aplikasi internal](/id/open/development/obtain-the-access-token-of-an-internal-app#). - Untuk Aplikasi perusahaan pihak ketiga, panggil API [Memperoleh access token organisasi yang diberi wewenang untuk aplikasi pihak ketiga](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#). |

### Parameter jalur

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| conferenceId | String | Ya | ID rapat. Panggil API [Membuat Rapat Video](/id/open/development/create-a-video-conference#) untuk memperoleh nilai parameter conferenceId. |

### Isi permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| unionId | String | Ya | unionId pengguna. Panggil API [Mengkueri detail pengguna](/id/open/development/query-user-details) untuk memperoleh nilai parameter unionid.  **Catatan**  Hanya Tuan Rumah rapat yang memiliki izin untuk memulai perekaman cloud. |
| smallWindowPosition | String | Tidak | Posisi jendela kecil. Nilai yang valid:   - **relative_right**: Terpisah di sebelah kanan - **float_right**: Mengambang di sebelah kanan - **float_bottom**: Mengambang di bagian bawah |
| mode | String | Tidak | Tata letak. Nilai yang valid:   - **grid**: Mode kisi - **speech**: Mode pembicara - **full_screen**: Mode layar penuh |

### Contoh permintaan

## Respons

### Isi respons

| Nama | Tipe | Deskripsi |
| --- | --- | --- |
| code | String | Kode kembalian.  **Catatan**  Jika perekaman cloud untuk Rapat Video berhasil dimulai dan panggilan API berhasil, nilai bidang ini adalah 200. |

### Contoh isi respons

```text
HTTP/1.1 200 OK
Content-Type:application/json

{
  "code" : "200"
}
```

### Kode error

Jika error dikembalikan saat Anda memanggil API ini, temukan solusinya di dokumen [Kode error global](/id/open/development/server-api-error-codes-1) berdasarkan pesan error.

| HttpCode | Kode error | Pesan error | Deskripsi |
| --- | --- | --- | --- |
| 400 | roomClosed | the meeting has ended | Ruang telah ditutup. |
| 400 | paramsError | error:%s | Error parameter. |
| 404 | recordStartError | recordStartError:%s | Gagal memulai perekaman. |
| 404 | recordStartPermissionError | permissionError:%s | Gagal memulai perekaman karena masalah izin. |
| 500 | systemError | systemError:%s | Error internal sisi server. |
