Panggil API ini untuk mendapatkan detail departemen tertentu berdasarkan ID departemennya.

## Permintaan

| **Informasi dasar** | |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/topapi/v2/department/get |
| Metode HTTP | POST |
| Tipe aplikasi yang didukung | appType-Internal app, appType-Third-party enterprise app |
| Izin yang dibutuhkan | permission-qyapi_get_department_list-Izin baca untuk informasi departemen Kontak |

### Parameter query

| Nama | Tipe | Wajib | Contoh | Deskripsi |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | bE74xxxx | Kredensial aplikasi yang digunakan untuk memanggil API ini.   - Untuk aplikasi internal, dapatkan dengan memanggil API untuk mendapatkan [access_token aplikasi internal](/id/open/development/obtain-orgapp-token). - Untuk aplikasi perusahaan pihak ketiga, dapatkan dengan memanggil API untuk mendapatkan access_token perusahaan pihak ketiga. |

### Isi permintaan

| Nama | Tipe | Wajib | Contoh | Deskripsi |
| --- | --- | --- | --- | --- |
| dept_id | Number | Ya | 100 | ID departemen. ID Departemen root adalah 1. Panggil API [Mendapatkan daftar departemen](/id/open/development/user-management-acquires-the-list-departments) untuk memperoleh nilai dept_id. |
| language | String | Tidak | zh_CN | Bahasa Kontak:   - **zh_CN** (default): Bahasa Mandarin - **en_US**: Bahasa Inggris |

### Contoh permintaan

```curl
curl -X POST "https://api.dingtalk.io/topapi/v2/department/get" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=d3daxxxx51990' \
-d 'dept_id=100' \
-d 'language=zh_CN'
```

Java

```text
DingTalkClient client = new DefaultDingTalkClient("https://api.dingtalk.io/topapi/v2/department/get");
OapiV2DepartmentGetRequest req = new OapiV2DepartmentGetRequest();
req.setDeptId(100L);
req.setLanguage("zh_CN");
OapiV2DepartmentGetResponse rsp = client.execute(req, access_token);
System.out.println(rsp.getBody());
```

Python

```python
import dingtalk.api

req=dingtalk.api.OapiV2DepartmentGetRequest("https://api.dingtalk.io/topapi/v2/department/get")

req.dept_id=100
req.language="zh_CN"
try:
  resp= req.getResponse(access_token)
  print(resp)
except Exception,e:
  print(e)
```

PHP

```php
include "TopSdk.php";
date_default_timezone_set('Asia/Shanghai');

$c = new DingTalkClient(DingTalkConstant::$CALL_TYPE_OAPI, DingTalkConstant::$METHOD_POST , DingTalkConstant::$FORMAT_JSON);

$req->setDeptId("100");
$req->setLanguage("zh_CN");
$resp = $c->execute($req, $access_token, "https://api.dingtalk.io/topapi/v2/department/get");
```

C#

```text

```

### Kode error

Jika terjadi error saat memanggil API ini, temukan solusinya berdasarkan pesan error di dokumen [Kode error global](/id/open/development/server-api-error-codes-1).

| Kode error (errcode) | Pesan error (errmsg) | Solusi |
| --- | --- | --- |
| 43007 | Authorization required | Pastikan access_token memiliki izin operasi. |
| 60003 | Corresponding department not found | Pastikan dept_id sudah benar. |
| 400002 | Invalid parameter | Pastikan parameter dimasukkan sesuai ketentuan. |
| -1 | System busy | Coba lagi nanti. |
