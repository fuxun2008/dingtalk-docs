---
title: "Memperbarui tampilan filter"
description: "Panggil API ini untuk memperbarui nama, rentang, atau kriteria filter dari tampilan filter tertentu di DingTalk Spreadsheet; semua bidang bersifat opsional dan hanya yang dikirimkan yang diperbarui."
---

Panggil API ini untuk memperbarui nama, rentang, atau kondisi filter dari tampilan filter tertentu. Semua bidang bersifat opsional, dan hanya bidang yang Anda kirimkan yang diperbarui. API ini cocok untuk menyesuaikan tampilan filter yang sudah ada—misalnya, mengganti nama tampilan agar lebih mudah dikenali, memperluas rentang filter untuk mencakup kolom data baru, atau mengubah aturan filter suatu kolom agar sesuai dengan kebutuhan bisnis terbaru.

## Permintaan

### Informasi dasar

| Bidang | Nilai |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/doc/workbooks/{workbookId}/sheets/{sheetId}/filterViews/{filterViewId}` |
| Metode HTTP | PATCH |
| Jenis aplikasi yang didukung | appType-Internal app |
| Izin yang diperlukan | permission-Document.Workbook.Write-DingTalk Spreadsheet write permission |

### Header permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Panggil API [Mendapatkan access token aplikasi internal](/id/open/development/obtain-the-access-token-of-an-internal-app) untuk memperolehnya. |

### Parameter path

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| workbookId | String | Ya | ID file Spreadsheet. `nodeId(dentryUuid)` yang dikembalikan oleh [API Knowledge Base](/id/open/development/knowledge-base-overview) adalah `workbookId` Spreadsheet. Perolehlah dengan memanggil API [Get node](https://open.dingtalk.com/document/orgapp/get-node) dan [Membuat dokumen Knowledge Base](/id/open/development/create-team-space-document). |
| sheetId | String | Ya | ID atau nama Lembar Kerja. Panggil API [Mendapatkan semua lembar kerja](/id/open/development/obtain-all-worksheets) untuk memperoleh nilai parameter id atau name. |
| filterViewId | String | Ya | ID tampilan filter. |

### Parameter query

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| operatorId | String | Ya | unionId operator.   - Panggil API [Mendapatkan ID pengguna dengan menggunakan kode login senyap](/id/open/development/obtain-the-userid-of-a-user-by-using-the-log-free) untuk memperoleh nilai parameter unionid. - Panggil API [Kueri detail pengguna](/id/open/development/query-user-details) untuk memperoleh nilai parameter unionid.       Jika operator tidak memiliki izin, API mengembalikan error `The operator has no permission`. |

### Isi permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| name | String | Tidak | Nama baru tampilan filter. Jika tidak dikirimkan, nama tidak diperbarui. |
| range | String | Tidak | Rentang baru tampilan filter, dalam notasi A1. Jika tidak dikirimkan, rentang tidak diperbarui. |
| criteria | `Map<String, Object>` | Tidak | Kondisi filter kolom yang akan diperbarui. Key adalah offset kolom (relatif terhadap kolom pertama range, dimulai dari 0), dan value adalah object kondisi filter. Hanya kolom yang dikirimkan yang diperbarui; kondisi filter kolom lain yang sudah ada tidak terpengaruh. Jika tidak dikirimkan, kondisi filter tidak diperbarui. |
|  | Object | Tidak | Object kondisi filter dari kolom saat ini. |
| filterType | String | Tidak | Tipe filter. Nilai yang valid:   - **values**: Filter berdasarkan nilai - **color**: Filter berdasarkan warna - **condition**: Filter berdasarkan kondisi |
| visibleValues | Array of String | Tidak | Nilai yang terlihat. |
| conditions | Array | Tidak | Daftar kondisi filter saat memfilter berdasarkan kondisi. Berlaku ketika `filterType` bernilai `condition`. Setiap object kondisi berisi bidang `operator` dan `value`. |
| operator | String | Tidak | Operator kondisi. Nilai yang valid:   - **equal**: Sama dengan - **not-equal**: Tidak sama dengan - **contains**: Mengandung - **not-contains**: Tidak mengandung - **starts-with**: Dimulai dengan - **not-starts-with**: Tidak dimulai dengan - **ends-with**: Diakhiri dengan - **not-ends-with**: Tidak diakhiri dengan - **greater**: Lebih besar dari - **greater-equal**: Lebih besar dari atau sama dengan - **less**: Lebih kecil dari - **less-equal**: Lebih kecil dari atau sama dengan |
| value | String | Tidak | Nilai kondisi. |
| conditionOperator | String | Tidak | Hubungan logis antara beberapa kondisi. Nilai yang valid: `and`, `or`. Nilai default: `and`. Berlaku ketika `filterType` bernilai `condition` dan beberapa kondisi ditentukan. |
| backgroundColor | String | Tidak | Nilai warna (heksadesimal, seperti `#FF0000`) saat memfilter berdasarkan warna latar belakang. Berlaku ketika `filterType` bernilai `color`. Tentukan salah satu dari bidang ini atau `fontColor`. |
| fontColor | String | Tidak | Nilai warna (heksadesimal, seperti `#FF0000`) saat memfilter berdasarkan warna font. Berlaku ketika `filterType` bernilai `color`. Tentukan salah satu dari bidang ini atau `backgroundColor`. |
