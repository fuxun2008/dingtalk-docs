Panggil API ini untuk mendapatkan ID pengguna karyawan aktif berdasarkan nomor ponselnya. Jika karyawan telah keluar dari organisasi, ID pengguna tidak dapat diambil berdasarkan nomor ponsel.

## Permintaan

| **Informasi dasar** | |
| --- | --- |
| URL HTTP | https://oapi.dingtalk.io/topapi/v2/user/getbymobile |
| Metode HTTP | POST |
| Jenis aplikasi yang didukung | appType-Internal app |
| Izin yang diperlukan | permission-qyapi_get_member_by_mobile-Izin untuk mendapatkan informasi dasar pengguna berdasarkan nomor ponsel |

### Parameter query

| Nama | Tipe | Wajib | Contoh | Deskripsi |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | be3Fxxxx | Kredensial aplikasi untuk memanggil API ini. Dapatkan melalui API untuk mendapatkan [access_token dari Aplikasi internal](/id/open/development/obtain-orgapp-token). |

### Isi permintaan

| Nama | Tipe | Wajib | Contoh | Deskripsi |
| --- | --- | --- | --- | --- |
| mobile | String | Ya | 1\*\*\*\*\*\*\*543 | Nomor ponsel pengguna. |

### Contoh permintaan

```curl
curl -X POST "https://oapi.dingtalk.io/topapi/v2/user/getbymobile" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=2015ca04-c84e-4855-9e52-330b98eb35f5' \
-d 'mobile=13800138000'
```

Java

```text
DingTalkClient client = new DefaultDingTalkClient("https://oapi.dingtalk.io/topapi/v2/user/getbymobile");
OapiV2UserGetbymobileRequest req = new OapiV2UserGetbymobileRequest();
req.setMobile("1*******543");
OapiV2UserGetbymobileResponse rsp = client.execute(req, acces_token);
System.out.println(rsp.getBody());
```

Python

```python

req.support_exclusive_account_search=true
try:
  resp= req.getResponse(access_token)
  print(resp)

  print(e)
```


```text

```

## Respons

### Isi respons

| Nama | Tipe | Contoh | Deskripsi |
| --- | --- | --- | --- |
| request_id | String | 5w82ciuur781 | ID permintaan. |
| errcode | Number | 0 | Kode pengembalian. |
| errmsg | String | ok | Deskripsi kode pengembalian. |
| result | Object |  | Hasil yang dikembalikan. |
| userid | String | zhangsan | ID pengguna karyawan. |

### Contoh respons

```json
{
  "errcode":"0",
  "result":{
    "userid":"xiaoding"
  },
  "errmsg":"ok"
}
```

### Kode error

Jika terjadi error saat memanggil API ini, lihat dokumen [Kode error global](/id/open/development/server-api-error-codes-1) untuk solusi berdasarkan pesan error.

| Kode error (errcode) | Pesan error (errmsg) | Solusi |
| --- | --- | --- |
| 400002 | Invalid parameter | Pastikan parameter diisi sesuai ketentuan dalam dokumen di atas. |
| 40104 | Invalid mobile number in the organization | Periksa apakah nomor ponsel sudah benar. |
| 60121 | User not found | Pastikan informasi diisi dengan benar. |
| -1 | System busy | Coba lagi nanti. |
