title: "Urungkan instans persetujuan"
description: "Pelajari cara memanggil API DingTalk untuk mengurungkan instans persetujuan yang sedang berjalan berdasarkan ID-nya, lengkap dengan operator dan catatan penghentian."
---

Panggil API ini untuk mengurungkan instans persetujuan yang masih berjalan.

## Deskripsi panggilan API

- Proses persetujuan tidak dapat diurungkan dalam 15 detik setelah diajukan.
- Jika parameter isSystem diatur ke false (dihentikan oleh operator tertentu), teruskan pengaju untuk mengurungkan instans persetujuan.
- API ini hanya mengurungkan instans persetujuan yang sedang berjalan. API ini tidak dapat mengurungkan instans persetujuan yang persetujuannya sudah selesai.
- Sebelum memanggil API ini, buka [DingTalk Admin Console](https://oa.dingtalk.io/?lang=id_ID) > **Workbench > Kelola Aplikasi > Aplikasi Persetujuan OA**, lalu buka **Admin Console Persetujuan OA**. Cari **Templat > Pengaturan Lanjutan > Urungkan/Ubah Formulir Persetujuan**, lalu pilih **Izinkan pengirim mengurungkan formulir persetujuan yang sedang berjalan**. Jika tidak, panggilan akan gagal dengan `errcode:820008, success:false, errmsg:Approval system error` karena Anda tidak memiliki izin untuk memproses tugas tersebut.

## Permintaan

### Informasi dasar

| Bidang | Nilai |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/v1.0/workflow/processInstances/terminate |
| Metode HTTP | POST |
| Tipe aplikasi yang didukung | appType-Aplikasi internal |
| Izin yang diperlukan | permission-Workflow.Instance.Write-Izin tulis instans alur kerja |

### Header permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Panggil API [Dapatkan access token Aplikasi internal](/id/open/development/obtain-the-access-token-of-an-internal-app) untuk mendapatkannya. |

### Isi permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| processInstanceId | String | Ya | ID instans persetujuan.   - Panggil API [Buat instans persetujuan](/id/open/development/create-an-approval-instance) untuk mendapatkan nilai parameter `InstanceId`. - Panggil API [Dapatkan daftar ID instans persetujuan](/id/open/development/obtain-an-approval-list-of-instance-ids) untuk mendapatkan nilai parameter `list`. |
| isSystem | Boolean | Tidak | Menentukan apakah tindakan dilakukan oleh sistem.   - **true**: Sistem langsung menghentikan instans. - **false**: Operator tertentu menghentikan instans (teruskan pengaju untuk mengurungkannya). |
| remark | String | Tidak | Catatan penghentian. Panjang maksimum: 1.024 karakter. |
| operatingUserId | String | Tidak | userId operator.      Parameter ini wajib jika isSystem bernilai false (teruskan pengaju untuk mengurungkan instans). |
