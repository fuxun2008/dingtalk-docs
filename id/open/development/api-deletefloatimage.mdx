Panggil API ini untuk menghapus gambar mengambang dari lembar kerja tertentu di DingTalk Spreadsheet. Penghapusan tidak dapat dibatalkan. Setelah dihapus, gambar akan dihapus dari lembar kerja dan tidak dapat dipulihkan melalui API. API ini cocok untuk skenario seperti membersihkan gambar yang tidak terpakai atau menata ulang tata letak visual sebuah lembar kerja.

## Permintaan

### Informasi dasar

| Bidang | Nilai |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/doc/workbooks/{workbookId}/sheets/{sheetId}/floatImages/{id}` |
| Metode HTTP | DELETE |
| Jenis aplikasi yang didukung | appType-Aplikasi internal |
| Izin yang diperlukan | permission-Document.Workbook.Write-Izin tulis DingTalk Spreadsheet |

### Header permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Panggil API [Memperoleh access token aplikasi internal](/id/open/development/obtain-the-access-token-of-an-internal-app) untuk memperolehnya. |

### Parameter path

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| workbookId | String | Ya | ID file spreadsheet. `nodeId(dentryUuid)` yang dikembalikan oleh [Knowledge Base API](/id/open/development/knowledge-base-overview) adalah `workbookId` spreadsheet. Anda dapat memperolehnya dengan memanggil API [Get node](https://open.dingtalk.com/document/development/get-node) dan [Membuat dokumen knowledge base](/id/open/development/create-team-space-document). |
| sheetId | String | Ya | ID atau judul lembar kerja. Panggil API [Memperoleh semua lembar kerja](/id/open/development/obtain-all-worksheets) untuk memperoleh ID dan judul lembar kerja. |
| id | String | Ya | ID gambar mengambang. Perolehlah dengan memanggil API "Kueri gambar mengambang". |

### Parameter kueri

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| operatorId | String | Ya | unionId operator. Panggil API [Kueri detail pengguna](/id/open/development/query-user-details) untuk memperolehnya. Jika operator tidak memiliki izin yang diperlukan, API mengembalikan error `The operator has no permission`. |
