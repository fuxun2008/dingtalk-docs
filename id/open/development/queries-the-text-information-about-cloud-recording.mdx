Panggil API ini untuk mengueri konten speech-to-text dari rekaman Rapat Video, termasuk konten teks, waktu mulai rekaman teks, dan waktu selesai rekaman teks.

## Deskripsi panggilan API

Jika perekaman cloud (Flash Minutes) diaktifkan untuk Rapat Video DingTalk, ucapan Anggota selama periode perekaman cloud secara otomatis dikonversi menjadi teks dan disimpan sebagai rekaman.

Sebagai contoh, Tuan Rumah sebuah Rapat mengaktifkan fitur **Meeting Recording — Cloud Recording**. Setelah Rapat selesai, Tuan Rumah menerima pesan Push tentang Perekaman Rapat. Konten speech-to-text dari Rekaman ditampilkan pada gambar berikut.

Panggil API ini untuk mengambil konten teks yang dihasilkan selama perekaman cloud, termasuk konten teks, waktu mulai rekaman teks, dan waktu selesai rekaman teks.

Saat Tuan Rumah mengaktifkan Perekaman Rapat, **Cloud Recording (Flash Minutes)** harus dipilih terlebih dahulu. Selain itu, Anggota harus telah berbicara selama periode perekaman sebelum API ini dapat dipanggil untuk mengueri konten teks dari Perekaman Rapat.

### Informasi dasar

| Bidang | Value |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/conference/videoConferences/{conferenceId}/cloudRecords/getTexts` |
| Metode HTTP | GET |
| Tipe Aplikasi yang didukung | appType-Internal app　appType-Third-party enterprise app |
| Izin yang diperlukan | permission-VideoConference.Conference.Read-Izin baca untuk informasi Rapat Video |

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |

Dapatkan sebagai berikut:   - Untuk Aplikasi internal, panggil API [Mendapatkan access token dari Aplikasi internal](/id/open/development/obtain-the-access-token-of-an-internal-app#). - Untuk Aplikasi perusahaan pihak ketiga, panggil API [Mendapatkan access token dari perusahaan yang diberi otorisasi ke aplikasi pihak ketiga](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#). |

### Parameter jalur

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| conferenceId | String | Tidak | ID Rapat. Panggil API [Membuat Rapat Video](/id/open/development/create-a-video-conference#) untuk mendapatkan nilai parameter conferenceId. |

### Parameter kueri

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| unionId | String | Tidak | unionId dari Pengguna. Panggil API [Mengueri detail pengguna](/id/open/development/query-user-details#) untuk mendapatkan nilai parameter unionid. |
| startTime | Long | Tidak | Waktu mulai dalam milidetik (seperseribu detik).  Sebagai contoh, jika parameter ini disetel ke 2000, kueri dimulai dari detik kedua perekaman. |
| direction | String | Tidak | Metode kueri:   - **0**: Kueri dilakukan dalam urutan waktu menaik. Ini adalah metode default. - **1**: Kueri dilakukan dalam urutan waktu menurun. |
| maxResults | Long | Tidak | Jumlah item per kueri. Nilai maksimum adalah 2000. |
| nextToken | Long | Tidak | Cursor paginasi.   - Untuk kueri pertama, parameter ini dapat dihilangkan. - Untuk kueri berikutnya, setel parameter ini ke nextToken yang dikembalikan oleh panggilan sebelumnya ke API ini. |
