Panggil API ini untuk mendapatkan informasi thumbnail beberapa file secara massal.

### Deskripsi API

Untuk gambar, dokumen berformat WPS (Word, Excel, dan PowerPoint), file PDF, dan file TXT yang diunggah ke ruang penyimpanan, thumbnail dibuat secara otomatis dan asinkron.

Panggil API ini untuk mendapatkan informasi thumbnail file tersimpan secara massal.

## Izin

Untuk memanggil API ini, salah satu izin berikut diperlukan.

| Jenis aplikasi | Didukung | Izin | API Explorer Debug |
| --- | --- | --- | --- |
| Aplikasi internal | Didukung | Izin baca untuk file penyimpanan organisasi | [API Explorer](https://open-dev.dingtalk.io/apiExplorer#/?devType=org&api=storage_1.0%23GetDentryThumbnails) |
| Aplikasi perusahaan pihak ketiga | Didukung | Izin baca untuk file penyimpanan organisasi | [API Explorer](https://open-dev.dingtalk.io/apiExplorer#/?devType=isv&api=storage_1.0%23GetDentryThumbnails) |
| Aplikasi personal pihak ketiga | Tidak didukung | Izin baca untuk file penyimpanan organisasi | Tidak didukung |

## Metode HTTP

```http
POST /v1.0/storage/spaces/{spaceId}/thumbnails/query?unionId=String HTTP/1.1
Host:api.dingtalk.io
x-acs-dingtalk-access-token:String
Content-Type:application/json

{
  "dentryIds" : [ "String" ]
}
```

## Parameter header

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Dapatkan sebagai berikut:   - Untuk aplikasi internal, panggil API [Mendapatkan access token aplikasi internal](/id/open/development/obtain-the-access-token-of-an-internal-app). - Untuk aplikasi perusahaan pihak ketiga, panggil API untuk mendapatkan access token organisasi yang diberi otorisasi untuk aplikasi pihak ketiga. |

## Parameter path

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| spaceId | String | Ya | ID ruang. Dapatkan nilai parameter `id` dengan memanggil API [Tambah ruang](/id/open/development/add-space). |

## Parameter query

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| unionId | String | Ya | unionId dari operator. Dapatkan dengan memanggil API [Kueri detail pengguna](/id/open/development/query-user-details). |

## Parameter body

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| dentryIds | Array of String | Ya | ID file. Jumlah maksimum adalah 30. Dapatkan nilai parameter `id` dengan memanggil API untuk mendapatkan daftar file atau folder. |

## Parameter respons

| Nama | Tipe | Deskripsi |
| --- | --- | --- |
| resultItems | Array | Daftar hasil pengambilan thumbnail. |
| spaceId | String | ID ruang tempat file berada. |
| dentryId | String | ID file. |
| success | Boolean | Apakah informasi thumbnail berhasil diambil. `true` menandakan berhasil. |
| errorCode | String | Alasan error. |
| thumbnail | Object | Informasi thumbnail. |
| width | Integer | Lebar thumbnail, dalam px. |
| height | Integer | Tinggi thumbnail, dalam px. |
| url | String | URL thumbnail. |
