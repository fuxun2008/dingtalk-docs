---
title: "Mendapatkan informasi file atau folder secara massal"
description: "Panggil API ini untuk mengambil informasi detail dari beberapa file atau folder yang ditambahkan atau diunggah ke ruang penyimpanan dalam satu permintaan batch."
---

Setelah file atau folder ditambahkan atau diunggah ke ruang penyimpanan, panggil API ini untuk mendapatkan informasinya secara massal.

## Deskripsi panggilan API

Saat mengambil informasi tentang file dan folder, bidang ukuran file dan ekstensi file tidak tersedia untuk folder.

## Permintaan

### Informasi dasar

| Bidang | Nilai |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/storage/spaces/{spaceId}/dentries/query` |
| Metode HTTP | POST |
| Tipe aplikasi yang didukung | appType-Aplikasi internal　appType-Aplikasi perusahaan pihak ketiga |
| Izin | permission-Storage.File.Read-Izin baca untuk file penyimpanan organisasi |

### Header permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses yang digunakan untuk memanggil API ini. Dapatkan sebagai berikut:   - Untuk aplikasi internal, panggil API [Mendapatkan access token aplikasi internal](/id/open/development/obtain-the-access-token-of-an-internal-app). - Untuk aplikasi perusahaan pihak ketiga, panggil API [Mendapatkan access token organisasi yang diberi otorisasi ke aplikasi pihak ketiga](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1). |

### Parameter jalur

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| spaceId | String | Ya | ID ruang. Panggil API [Menambahkan ruang](/id/open/development/add-space) untuk mendapatkan nilai parameter id. |

### Parameter kueri

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| unionId | String | Ya | unionId operator. Panggil API [Kueri detail pengguna](/id/open/development/query-user-details) untuk mendapatkan nilai parameter unionid. |

### Isi permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| dentryIds | Array of String | Ya | Daftar ID file atau folder. Maksimal 30 ID didukung. Panggil API [Mendapatkan daftar file atau folder](/id/open/development/get-a-list-of-files-or-folders) atau [Mendapatkan spaceId dan dentryId berdasarkan dentryUuid](/id/open/development/api-getdentryidbyuuid) untuk mendapatkan nilai parameter id. |
| option | Object | Tidak | Parameter opsional. |
| appIdsForAppProperties | Array of String | Tidak | Daftar ID aplikasi yang ditentukan. Maksimal 20 ID didukung. Panggil API [Mendapatkan informasi ruang](/id/open/development/get-space-information) untuk mendapatkan nilai parameter ownerId.       - Jika parameter ini ditentukan, properti file atau folder untuk aplikasi yang ditentukan akan dikembalikan. - Jika parameter ini tidak ditentukan, properti file atau folder untuk semua aplikasi akan dikembalikan. |
| withThumbnail | Boolean | Tidak | Apakah akan mengambil informasi thumbnail file.   - **true**: Ya - **false**: Tidak       Ambil sesuai kebutuhan. Mengambil thumbnail akan meningkatkan waktu respons API. |

## Respons

### Isi respons

| Nama | Tipe | Deskripsi |
| --- | --- | --- |
| resultItems | Array | Daftar informasi file atau folder yang diambil secara massal. |
| spaceId | String | ID ruang tempat file atau folder berada. |
| dentryId | String | ID file atau folder. |
| success | Boolean | Apakah file atau folder berhasil diambil. true menunjukkan berhasil. |
| errorCode | String | Alasan error. |
| dentry | Object | Informasi file atau folder. |
| id | String | ID file atau folder. |
| spaceId | String | ID ruang tempat file atau folder berada. |
| parentId | String | ID direktori induk file atau folder. ID direktori root adalah 0. |
| type | String | Tipe.   - **FILE**: File - **FOLDER**: Folder |
| name | String | Nama file atau folder. |
| size | Long | Ukuran file, dalam byte. |
| path | String | Jalur file atau folder. |
| version | Long | Nomor versi file atau folder. |
| status | String | Status.   - **NORMAL**: Normal - **DELETED**: Sampah - **EXPIRED**: Kedaluwarsa |
| extension | String | Ekstensi file. |
| creatorId | String | unionId pembuat. |
| modifierId | String | unionId pengubah. |
| createTime | String | Waktu pembuatan dalam format ISO 8601. Contoh: 2022-07-29T14:55Z. |
| modifiedTime | String | Waktu modifikasi dalam format ISO 8601. Contoh: 2022-07-29T14:55Z. |
| properties | Object | Informasi properti file atau folder. |
| readOnly | Boolean | Apakah file atau folder hanya baca.   - **true**: Ya - **false**: Tidak |
| appProperties | `Map<String, Array>` | Properti untuk aplikasi tertentu. |
|  | Array | Daftar properti. |
| name | String | Nama properti. |
| value | String | Nilai properti. |
| visibility | String | Visibilitas properti.   - **PUBLIC**: Terlihat oleh semua aplikasi - **PRIVATE**: Terlihat hanya oleh aplikasi saat ini |
| uuid | String | Bidang pengidentifikasi. |
| partitionType | String | Partisi penyimpanan:   - **PUBLIC_OSS_PARTITION**: Partisi penyimpanan OSS cloud publik - **MINI_OSS_PARTITION**: Partisi penyimpanan Mini OSS khusus |
| storageDriver | String | Tipe driver:   - **DINGTALK**: Driver penyimpanan terpadu DingTalk - **ALIDOC**: Driver penyimpanan DingTalk Docs - **SHANJI**: Driver penyimpanan Shanji - **UNKNOWN**: Driver tidak diketahui |
| thumbnail | Object | Informasi thumbnail. |
| width | Integer | Lebar thumbnail, dalam piksel. |
| height | Integer | Tinggi thumbnail, dalam piksel. |
| url | String | URL thumbnail. |

### Kode error

Jika panggilan API gagal, temukan solusinya di dokumen [Kode error global](/id/open/development/server-api-error-codes-1) berdasarkan pesan error.

| HttpCode | Kode error | Pesan error | Deskripsi |
| --- | --- | --- | --- |
| 400 | paramError | %s | Error parameter |
| 403 | permissionDenied | %s | Pengguna tidak memiliki izin untuk mengambil informasi tentang file atau folder. |
| 404 | spaceNotExist | %s | Ruang tidak ada. |
| 500 | systemError | %s | Error sistem |
| 500 | unknownError | Unknown Error | Error tidak diketahui |
| 503 | operationTimeout | %s | permintaan habis waktu |
