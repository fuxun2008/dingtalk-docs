title: "Perbarui aturan cuti"
description: "Panggil API DingTalk untuk memperbarui aturan cuti yang dibuat via API, termasuk nama cuti, satuan pengajuan, metode perhitungan durasi, dan cakupan berlaku."
---

Panggil API ini untuk memperbarui aturan dari jenis cuti tertentu.

## Deskripsi panggilan API

Aturan cuti dapat dibuat dengan dua cara, yaitu dengan memanggil API atau melalui aplikasi resmi DingTalk Attendance:

| Metode pembuatan aturan cuti | Mendukung pembaruan jenis cuti melalui API ini |
| --- | --- |
| Jenis cuti yang dibuat dengan memanggil API [Tambah aturan cuti](/id/open/development/add-holiday-rules). | Ya |
| Jenis cuti yang dibuat di aplikasi Attendance pada Admin Console.   - Dibuat secara default oleh sistem aplikasi Attendance. - Dibuat di backend aplikasi Attendance. | Tidak |

Buka halaman **Attendance** > **Manajemen Cuti** > **Aturan Cuti** untuk melihat empat aturan cuti yang sudah ada.

- Jenis cuti buatan API 1 dan jenis cuti buatan API 2 dibuat melalui API. Panggil API ini untuk memperbarui informasinya, seperti nama cuti, satuan pengajuan cuti, metode perhitungan durasi cuti, dan cakupan saldo.
- Cuti Pribadi dan Cuti Pengganti adalah jenis cuti default yang dibuat oleh sistem aplikasi Attendance. API ini tidak dapat memperbarui jenis cuti tersebut dan akan mengembalikan pesan error berikut: errcode:880015,errmsg:The specified leaveCode or userId does not exist.

<Note>
Panggil API [Kueri daftar aturan cuti](/id/open/development/holiday-type-query) untuk memeriksa aturan cuti mana saja yang dibuat melalui API.
</Note>

Di Admin Console DingTalk, buka **Manajemen Cuti** > **Aturan Cuti** untuk melihat daftar aturan cuti. Klik **+ Tambah Cuti** untuk membuat aturan baru. Setiap aturan menampilkan kolom berikut:

| Kolom | Deskripsi |
| --- | --- |
| Nama cuti | Contoh: Cuti Pribadi, Cuti Pengganti, Jenis cuti buatan API 1/2 |
| Satuan pengajuan cuti | Per jam atau Per hari |
| Metode perhitungan durasi cuti | Contoh: Hitung berdasarkan hari kerja |
| Aturan saldo | Contoh: Saldo tidak terbatas |
| Cakupan berlaku | Contoh: Seluruh perusahaan |
| Tindakan | Edit, Hapus |

Dalam contoh pada gambar, jenis cuti default Cuti Pribadi dan Cuti Pengganti dikonfigurasi dengan satuan pengajuan "Per jam", sedangkan jenis cuti yang dibuat melalui API dikonfigurasi dengan "Per hari".

## Permintaan

### Informasi dasar

| Bidang | Nilai |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/v1.0/attendance/leaves/types |
| Metode HTTP | PUT |
| Jenis aplikasi yang didukung | appType-Aplikasi internal　appType-Aplikasi perusahaan pihak ketiga |
| Izin yang diperlukan | permission-qyapi_holiday_manage-Izin manajemen cuti DingTalk |

### Header permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Cara mendapatkannya:   - Aplikasi internal: panggil API [Mendapatkan access token aplikasi internal](/id/open/development/obtain-the-access-token-of-an-internal-app). - Aplikasi perusahaan pihak ketiga: panggil API untuk mendapatkan access token organisasi yang memberikan otorisasi kepada aplikasi pihak ketiga. |

### Parameter query

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| opUserId | String | Ya | userId operator. |

### Isi permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| leaveName | String | Tidak | Nama cuti. |
| leaveViewUnit | String | Ya | Satuan pengajuan cuti.   - **day**: Hari - **halfDay**: Setengah hari - **hour**: Jam |
| bizType | String | Ya | Jenis cuti.   - **general_leave**: Cuti reguler - **lieu_leave**: Lembur yang dikonversi menjadi cuti pengganti |
| naturalDayLeave | Boolean | Tidak | Menentukan apakah durasi cuti dihitung berdasarkan hari kalender.   - **true**: Ya - **false**: Tidak     Contoh: karyawan Budi mengirimkan formulir persetujuan pengajuan cuti yang dimulai pukul 09.30 pada 11 April 2022 dan berakhir pukul 18.30 pada 18 April 2022. Tanggal 16 dan 17 April adalah hari libur Sabtu dan Minggu.   - Jika parameter ini bernilai true, formulir persetujuan menghitung 8 hari cuti, termasuk hari libur yang tidak terjadwal dan hari libur nasional. - Jika parameter ini bernilai false, formulir persetujuan menghitung 6 hari cuti, tidak termasuk hari libur yang tidak terjadwal dan hari libur nasional. |
| hoursInPerDay | Long | Tidak | Jam kerja harian yang digunakan untuk konversi, yaitu nilai parameter dibagi 100.    Contoh: jika shift karyawan memiliki 8 jam kerja, atur parameter ini ke 8\*100=800. |
| leaveCode | String | Ya | Identifier aturan cuti yang ditambahkan melalui API. leave_code harus milik jenis cuti yang ditambahkan melalui API.   - Aplikasi internal: gunakan nilai leave_code yang dikembalikan oleh API Tambah aturan cuti. - Aplikasi perusahaan pihak ketiga: gunakan nilai leave_code yang dikembalikan oleh API Tambah aturan cuti. |
| extras | String | Tidak | Aturan masa berlaku cuti pengganti.   - **validity_type**: Jenis masa berlaku    - **absolute_time**: Waktu absolut   - **relative_time**: Waktu relatif - **validity_value**: Tanggal perpanjangan    - Jika validity_type bernilai **absolute_time**, nilai ini tidak boleh kosong dan harus menggunakan format "yy-mm".   - Jika validity_type bernilai **relative_time**, nilai ini harus berupa integer yang lebih besar dari 1. |
| visibilityRules | Array | Tidak | Daftar aturan cakupan berlaku. Jika tidak ditentukan, aturan berlaku untuk seluruh perusahaan. |
| visible | Array of String | Tidak | Daftar data dalam cakupan berlaku.   - Jika type=staff, isi dengan daftar userId karyawan. - Jika type=dept, isi dengan daftar ID departemen. - Jika type=label, isi dengan daftar ID peran. |
| type | String | Tidak | Jenis aturan cakupan berlaku.   - **dept**: Departemen - **staff**: Karyawan - **label**: Peran |
| submitTimeRule | Object | Tidak | Aturan batas waktu pengiriman. |
| timeValue | Long | Tidak | Nilai batas.   - Jika timeUnit bernilai **day**, rentang yang valid adalah 0 hingga 30 hari. - Jika timeUnit bernilai **hour**, rentang yang valid adalah 0 hingga 24 jam. |
| timeUnit | String | Tidak | Satuan waktu.   - **day**: Hari - **hour**: Jam |
| timeType | String | Tidak | Jenis batas.   - **before**: Kirim sebelumnya - **after**: Kirim susulan |
| enableTimeLimit | Boolean | Tidak | Menentukan apakah batas waktu pengiriman diaktifkan.   - **true**: Aktif - **false**: Nonaktif |
| leaveCertificate | Object | Tidak | Surat keterangan cuti. |
| unit | String | Tidak | Satuan surat keterangan cuti.   - **hour**: Jam - **day**: Hari |
| duration | double | Tidak | Durasi cuti yang jika terlampaui mewajibkan surat keterangan cuti. |
| enable | Boolean | Tidak | Menentukan apakah surat keterangan cuti diwajibkan.   - **true**: Aktif - **false**: Nonaktif |
| promptInformation | String | Tidak | Teks prompt pengajuan cuti. |
