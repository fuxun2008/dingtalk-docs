Topik ini menjelaskan cara tautan pesan dibuka.

## Membuka tautan pesan di sidebar PC atau browser eksternal

Saat pengguna mengklik URL dalam sebuah pesan di klien PC, gunakan format berikut untuk mengontrol cara tautan dibuka:

```text
dingtalk://dingtalkclient/page/link?url=http%3A%2F%2Fwww.dingtalk.io&pc_slide=true
```

### Parameter

| **Parameter** | Deskripsi |
| --- | --- |
| url | Tautan yang akan dibuka. Nilainya harus dienkode dalam format URL. |
| pc_slide | - true: Membuka tautan di sidebar klien PC. - false: Membuka tautan di browser. |

## Tautan mini program

Sebuah mini program dapat mengirim pesan yang, saat diklik, mengalihkan pengguna ke mini program tersebut. Skenario yang didukung adalah sebagai berikut:

| Jenis aplikasi | Pesan Notifikasi Kerja | Pesan Grup organisasi | Pesan teks biasa |
| --- | --- | --- | --- |
| Aplikasi internal | Didukung | Tidak didukung | Tidak didukung |
| Aplikasi perusahaan pihak ketiga | Didukung | Tidak didukung | Tidak didukung |
| Aplikasi personal pihak ketiga | — | — | Didukung |

Format tautan yang digunakan untuk mengalihkan ke mini program adalah sebagai berikut:

```text
 eapp://page?query
```

Contoh: eapp://pages/index/index?param1=aa&param2=bb

### Parameter

- Format tautan ini hanya didukung ketika pesan dikirim oleh mini program. Format ini tidak didukung ketika pesan dikirim oleh aplikasi mikro.
- Untuk memastikan pengalihan berfungsi sebagaimana mestinya, publikasikan mini program target ke lingkungan produksi.
- `page` menunjukkan jalur halaman mini program, seperti `pages/index/index`. Jalur ini harus didefinisikan di bawah `pages` dalam file konfigurasi `app.json`.

### Catatan

  Untuk memastikan pengalihan berfungsi sebagaimana mestinya, publikasikan mini program target ke lingkungan produksi.

- `query` menunjukkan parameter kueri yang diteruskan ke metode `onLoad` halaman. Contohnya, `param1=aa&param2=bb`. Jika nilai parameter mengandung karakter khusus, enkode nilainya dalam format URL.
