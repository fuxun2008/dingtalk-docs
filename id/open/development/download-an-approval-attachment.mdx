title: "Unduh lampiran persetujuan"
description: "Panggil API ini untuk mendapatkan otorisasi unduhan lampiran persetujuan DingTalk berdasarkan ID instans dan fileId, lalu buat tautan unduhan file."
---

Panggil API ini untuk mendapatkan otorisasi unduhan file persetujuan dan membuat tautan unduhan.

## Deskripsi panggilan API

- Jika formulir persetujuan dikirim secara manual dari klien DingTalk dengan lampiran file lokal, alamat unduhan lampiran yang dikembalikan API ini menggunakan format #zifgs49xxxxx.file. Gunakan API ini bersama API [Mendapatkan detail satu instans persetujuan](/id/open/development/obtains-the-details-of-a-single-approval-instance-pop). Ambil fileName dan fileType lampiran dari API detail instans, lalu ganti nama dan ekstensi pada nilai #zifgs49xxxxx.file yang dikembalikan API ini. Setelah itu, lampiran dapat dibuka dengan benar.
- Ukuran file lampiran tidak boleh 0. Tautan unduhan tidak didukung untuk file kosong.

## Permintaan

### Informasi dasar

| Bidang | Nilai |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/v1.0/workflow/processInstances/spaces/files/urls/download |
| Metode HTTP | POST |
| Tipe aplikasi yang didukung | appType-Aplikasi internal　appType-Aplikasi perusahaan pihak ketiga |
| Izin | permission-Workflow.Instance.Write-Izin tulis instans alur kerja |

### Header permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Cara mendapatkannya:   - Aplikasi internal: panggil API [Mendapatkan access token aplikasi internal](/id/open/development/obtain-the-access-token-of-an-internal-app). - Aplikasi perusahaan pihak ketiga: panggil API untuk mendapatkan access token organisasi yang diotorisasi oleh aplikasi pihak ketiga. |

### Isi permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| processInstanceId | String | Ya | ID instans persetujuan.   - Panggil API [Membuat instans persetujuan](/id/open/development/create-an-approval-instance) untuk mendapatkan nilai parameter `InstanceId`. - Panggil API [Mendapatkan daftar ID instans persetujuan](/id/open/development/obtain-an-approval-list-of-instance-ids) untuk mendapatkan nilai parameter `list`. |
| fileId | String | Ya | ID file (fileId). Panggil API [Mendapatkan detail satu instans persetujuan](/id/open/development/obtains-the-details-of-a-single-approval-instance-pop) untuk mendapatkan nilai parameter `fileId`.      ID file adalah fileId dari file yang diunggah pada komponen persetujuan. Saat ini tautan unduhan tidak didukung untuk lampiran yang diunggah di komentar. |
| withCommentAttatchment | Boolean | Tidak | Menentukan apakah lampiran di komentar disertakan. Secara default, lampiran di komentar diabaikan. |

## Respons

### Isi respons

| Nama | Tipe | Deskripsi |
| --- | --- | --- |
| result | Object | Hasil yang dikembalikan. |
| spaceId | Long | ID ruang Drive. |
| fileId | String | ID file. |
| downloadUri | String | URL unduhan file.      URL unduhan berlaku selama 15 menit. |
| success | Boolean | Menunjukkan apakah panggilan API berhasil.   - **true**: Berhasil - **false**: Gagal |

### Contoh isi respons

```text
HTTP/1.1 200 OK
Content-Type:application/json

{
  "result" : {
    "spaceId" : 3996960664,
    "fileId" : "26748422566",
    "downloadUri" : "http://lippi-space-zjk.oss-cn-zhangjiakou.aliyuncs.com/xxxxx"
  },
  "success" : true
}
```
