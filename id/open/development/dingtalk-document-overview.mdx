DingTalk Docs OpenAPI menyediakan sekumpulan antarmuka RESTful yang memungkinkan developer mengoperasikan DingTalk Docs secara terprogram. Gunakan API ini untuk mengotomatiskan pembacaan dan penulisan dokumen, mengelola elemen block (buat, baca, perbarui, hapus), menjalankan operasi konten secara massal, dan lainnya. API ini cocok untuk skenario seperti pembuatan dokumen otomatis, sinkronisasi konten, dan penulisan cerdas.

## Apa itu DingTalk Docs

DingTalk Docs adalah paket perkantoran kolaboratif untuk perusahaan yang dikembangkan sendiri oleh DingTalk, bagian dari Alibaba Group. Paket ini mencakup alat penulisan online seperti dokumen, spreadsheet, dan mind map. Dalam penggunaan sehari-hari, Anda dapat mengedit dan melihat konten dokumen langsung dari komputer, ponsel, atau tablet tanpa perlu mengunduh apa pun. Semua perubahan tersimpan otomatis secara real-time.

DingTalk Docs juga terintegrasi secara mendalam dengan DingTalk, sehingga memungkinkan kolaborasi yang efisien dengan rekan kerja berdasarkan hubungan organisasi. Gunakan DingTalk Docs untuk skenario kerja sehari-hari seperti pengumpulan informasi, manajemen proyek, rapat, pelaporan bisnis, dan onboarding karyawan baru. Untuk detail selengkapnya, lihat [Panduan Pengguna DingTalk - DingTalk Docs](https://docs.dingtalk.io/i/p/Y7kmbokZp3pgGLq2/docs/od245kZmnOeW4D4L73YEWYbzxL6R0wMQ).

## Glosarium

Sebelum menggunakan DingTalk Docs OpenAPI, Anda perlu memahami konsep inti berikut:

### dentryUuid

Pengidentifikasi unik sebuah dokumen. Misalnya, pada `https://docs.dingtalk.io/i/nodes/Z90D4da-id`, `dentryUuid`-nya adalah `Z90D4da-id`.

### blockId

Pengidentifikasi unik sebuah elemen block. Dapatkan melalui API "Membuat kueri elemen block".

### operatorId

`unionId` dari operator, digunakan untuk mengidentifikasi pengguna yang melakukan operasi dan untuk memverifikasi izin.

### BlockElement

Elemen block adalah unit dasar yang menyusun konten dokumen, seperti paragraf, heading, block sorot, dan tabel.

### InlineElement

Elemen inline disematkan di dalam elemen block, seperti stiker, gambar, tautan, dan slot.
