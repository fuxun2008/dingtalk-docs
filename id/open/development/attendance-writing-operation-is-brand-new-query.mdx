Panggil API ini untuk mengkueri izin tindakan karyawan di grup absensi.

## Permintaan

### Informasi dasar

| Bidang | Nilai |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/v1.0/attendance/writePermissions/query |
| Metode HTTP | POST |
| Tipe aplikasi yang didukung | appType-Aplikasi internal　appType-Aplikasi perusahaan pihak ketiga |
| Izin yang diperlukan | permission-Attendance.Permission.Read-Izin baca informasi otorisasi absensi |

### Header permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini.   - Untuk Aplikasi internal, panggil [Mendapatkan access token Aplikasi internal](/id/open/development/obtain-the-access-token-of-an-internal-app) untuk memperolehnya. - Untuk Aplikasi perusahaan pihak ketiga, panggil API untuk mendapatkan access token organisasi yang telah memberikan otorisasi kepada Aplikasi pihak ketiga. |

### Isi permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| opUserId | String | Ya | userId karyawan. |
| category | String | Ya | Tipe sumber daya:   - **GROUP**: Grup absensi. Saat ini hanya nilai ini yang didukung. |
| resourceKey | String | Ya | Cakupan izin:   - **GROUP_MEMBER**: Atur anggota absensi - **GROUP_NAME**: Ubah nama grup absensi - **GROUP_TYPE**: Atur tipe grup absensi - **CHECK_TIME**: Atur waktu absensi - **SCHEDULE**: Penjadwalan shift karyawan - **CHECK_POSITION_TYPE**: Atur metode absen - **OVER_TIME_RULE**: Atur aturan lembur - **CAMERA_CHECK**: Aturan verifikasi foto - **OUT_SIDE_CHECK**: Atur absensi lapangan - **MANAGE**: Sub-admin grup absensi - **OWNER**: Admin utama grup absensi - **DELETE_GROUP**: Hapus grup absensi |
| entityIds | Array of Long | Ya | ID sumber daya. Jika category bernilai GROUP, masukkan ID grup absensi. Panggil [Mendapatkan grup absensi pengguna](/id/open/development/queries-a-user-attendance-group) untuk memperoleh nilai group_id. |

## Respons

### Isi respons

| Nama | Tipe | Deskripsi |
| --- | --- | --- |
| entityPermissionMap | `Map<String, Boolean>` | Hasil pemeriksaan izin.  Contoh respons: &#123;"entityPermissionMap":&#123;"key":value&#125;&#125;.   - key: ID sumber daya, yaitu nilai dari parameter permintaan entityIds. - value: Menunjukkan apakah karyawan memiliki izin tersebut.    - true: Memiliki izin.   - false: Tidak memiliki izin. |

### Contoh isi respons

```text
HTTP/1.1 200 OK
Content-Type:application/json

{
  "entityPermissionMap" : {
    "key" : true
  }
}
```
