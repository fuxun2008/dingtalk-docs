Panggil API ini untuk mengkueri daftar Wi-Fi dari grup absensi tertentu secara massal.

## Permintaan

| **Informasi dasar** | |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/topapi/attendance/group/wifis/query |
| Metode HTTP | POST |
| Tipe aplikasi yang didukung | appType-Aplikasi internal |
| Izin yang diperlukan | permission-qyapi_attendance_group_read-Izin kueri grup absensi |

### Parameter kueri

| Nama | Tipe | Wajib | Contoh | Deskripsi |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | 4c9ebd2b1534xxxx | Kredensial aplikasi yang digunakan untuk memanggil API ini. Dapatkan dengan memanggil API [Mendapatkan access_token Aplikasi internal](/id/open/development/obtain-orgapp-token). |

### Isi permintaan

| Nama | Tipe | Wajib | Contoh | Deskripsi |
| --- | --- | --- | --- | --- |
| cursor | String | Tidak | 0151E022xxxx | ID terakhir dari batch sebelumnya. Kosong secara default. |
| size | Number | Ya | 50 | Ukuran halaman. |
| op_userid | String | Tidak | user01 | ID pengguna operator. |
| group_key | String | Ya | 015xxxx | ID grup absensi.  **Catatan**  Jika pengidentifikasi grup absensi Anda adalah group_id, panggil API [Mengonversi groupId menjadi groupKey](/id/open/development/groupid-to-groupkey) untuk mengonversi group_id menjadi group_key. |

### Contoh permintaan

```curl
curl -X POST "https://api.dingtalk.io/topapi/attendance/group/wifis/query" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=698cxxxx9b13' \
-d 'cursor=0151E0xxxx17E876' \
-d 'group_key=0151Exxxx17E876' \
-d 'op_userid=123456' \
-d 'size=50'
```

## Respons

### Isi respons

| Nama | Tipe | Contoh | Deskripsi |
| --- | --- | --- | --- |
| result | DingOpenResult |  | Hasil yang dikembalikan. |
| result | Result |  | Hasil kueri daftar Wi-Fi. |
| wifi_list | Wifi[] |  | Daftar Wi-Fi. |
| mac_addr | String | 54:8D:xx:xx:xx:73 | Alamat MAC. |
| ssid | String | office-wifi | Nama Wi-Fi. |
| wifi_key | String | E4CB0xxxx | Kunci Wi-Fi. |
| has_more | Boolean | true | Apakah masih ada data lainnya.   - **true**: Ya - **false**: Tidak |
| errcode | Number | 0 | Kode pengembalian. |
| errmsg | String | ok | Deskripsi kode pengembalian. |
| success | Boolean | true | Apakah panggilan berhasil.   - **true**: Berhasil - **false**: Gagal |
| request_id | String | 155qyie8nxoqu | ID permintaan. |

### Contoh isi respons

```json
{
  "result": {
```
