Panggil API ini untuk mendapatkan ringkasan semua grup absensi di organisasi Anda per halaman, termasuk nama setiap grup absensi dan ID grup absensi yang sesuai.

## Permintaan

| **Informasi dasar** | |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/topapi/attendance/group/minimalism/list |
| Metode HTTP | POST |
| Tipe aplikasi yang didukung | appType-Aplikasi internal appType-Aplikasi perusahaan pihak ketiga |
| Izin | permission-qyapi_attendance_group_read-Izin baca grup absensi |

### Parameter query

| Nama | Tipe | Wajib | Contoh | Deskripsi |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | bE74xxxx | Kredensial aplikasi yang digunakan untuk memanggil API ini.   - Untuk Aplikasi internal, dapatkan dengan memanggil [Mendapatkan access_token Aplikasi internal](/id/open/development/obtain-orgapp-token). - Untuk Aplikasi perusahaan pihak ketiga, dapatkan dengan memanggil API untuk mendapatkan access_token organisasi pihak ketiga. |

### Isi permintaan

| Nama | Tipe | Wajib | Contoh | Deskripsi |
| --- | --- | --- | --- | --- |
| op_user_id | String | Ya | user123 | userId operator. |
| cursor | Number | Tidak | 222 | Cursor paginasi. Dapatkan dari hasil permintaan sebelumnya. Jika tidak diisi, query dimulai dari item pertama. |

### Contoh permintaan

```curl
curl -X POST "https://api.dingtalk.io/topapi/attendance/group/minimalism/list" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=6dd4xxxx94138' \
-d 'cursor=222' \
-d 'op_user_id=dd_dd'
```

Java

```text
DingTalkClient client = new DefaultDingTalkClient("https://api.dingtalk.io/topapi/attendance/group/minimalism/list");
OapiAttendanceGroupMinimalismListRequest req = new OapiAttendanceGroupMinimalismListRequest();
req.setOpUserId("manager4220");
req.setCursor(0L);
OapiAttendanceGroupMinimalismListResponse rsp = client.execute(req, access_token);
System.out.println(rsp.getBody());
```


## Respons

### Isi respons

| Nama | Tipe | Contoh | Deskripsi |
| --- | --- | --- | --- |
| result | PageResult | demo | Hasil yang dikembalikan. |
| has_more | Boolean | false | Menunjukkan apakah masih ada data lainnya.   - **true**: Ya - **false**: Tidak |
| cursor | Number | 685935028 | Posisi cursor. |
| result | TopMinimalismGroupVo[] |  | Informasi absensi. |
| name | String | Absensi | Nama grup absensi. |
| id | Number | 677765054 | ID grup absensi. |
| success | Boolean | true | Menunjukkan apakah permintaan berhasil.   - **true**: Berhasil - **false**: Gagal |
| errcode | Number | 0 | Kode pengembalian. |
| errmsg | String | ok | Deskripsi pesan error. |
| request_id | String | wv9973jntam | ID permintaan. |
