## Ringkasan alur integrasi

Artikel ini menjelaskan cara membuat aplikasi internal dan menggunakan API manajemen pengguna yang disediakan oleh **Kelola Kontak** untuk membuat, mengambil, memperbarui, dan menghapus karyawan di organisasi Anda.

Langkah 1: Peroleh kredensial aplikasi, termasuk client ID dan Client Secret.

Langkah 2: Ajukan permintaan izin API untuk Kelola Kontak.

Langkah 3: Peroleh [access_token dari aplikasi internal](/id/open/development/obtain-orgapp-token) sebagai kredensial akses aplikasi. Access token digunakan untuk mengautentikasi pemanggil saat sebuah API dipanggil.

Langkah 4: Panggil API Kontak:

1. Panggil Server API [Buat pengguna](/id/open/development/user-information-creation) untuk membuat pengguna dan memperoleh `userid`.

   - Untuk menambahkan karyawan ke Departemen root, teruskan `1` sebagai parameter. Contoh ini menambahkan karyawan ke Departemen root.
   - Untuk menambahkan karyawan ke departemen tertentu, panggil terlebih dahulu [Peroleh daftar ID subdepartemen](/id/open/development/obtain-the-list-of-sub-department-ids) untuk mendapatkan ID departemen, lalu teruskan sebagai parameter departemen saat membuat pengguna.
2. Dengan `userid`, panggil Server API [Kueri detail pengguna](/id/open/development/query-user-details) untuk mengambil informasi detail pengguna.
3. Dengan `userid`, panggil Server API [Perbarui informasi pengguna](/id/open/development/user-information-update) untuk memperbarui informasi pengguna.
4. Dengan `userid`, panggil Server API [Hapus pengguna](/id/open/development/delete-a-user) untuk menghapus pengguna.

## Prasyarat

Selesaikan alur [pembuatan dan konfigurasi aplikasi](/id/open/dingstart/create-application).

## Langkah 1: Peroleh kredensial aplikasi

1. Pilih aplikasi target untuk masuk ke halaman detail aplikasi, lalu klik **Basic information** > **Credentials and basic information**.
2. Peroleh client ID dan Client Secret.

## Langkah 2: Tambahkan izin API

Klik **Development configuration** > **Manage permissions**. Pada kotak pencarian izin, masukkan `qyapi_manage_addresslist` dan `qyapi_get_department_list`, lalu ajukan permintaan izin tersebut.

## Langkah 3: Peroleh kredensial akses aplikasi (access token)

### Penting

- Untuk perbedaan antar versi Server API, lihat API lama vs. API Baru.
- Untuk mengunduh SDK Server API, lihat Unduh SDK sisi server.

Gunakan client ID dan Client Secret yang diperoleh pada Langkah 1 untuk memperoleh [access_token dari aplikasi internal](/id/open/development/obtain-orgapp-token) sebagai kredensial akses aplikasi.

```java
public void getAccessToken() throws ApiException {
        DingTalkClient client = new DefaultDingTalkClient("https://oapi.dingtalk.io/gettoken");
        OapiGettokenRequest req = new OapiGettokenRequest();
        req.setAppkey("dingxxxxxxxxxhgn");
        req.setAppsecret("9G_xxxxxxxxxxxxxxx1JDf0Qq3nexxxxxxxxGIO");
        req.setHttpMethod("GET");
        OapiGettokenResponse rsp = client.execute(req);
        System.out.println(rsp.getBody());
    }
```
