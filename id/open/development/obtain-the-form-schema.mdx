Panggil API ini untuk mendapatkan skema formulir berdasarkan processCode.

## Permintaan

### Informasi dasar

| Bidang | Nilai |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/v1.0/workflow/forms/schemas/processCodes |
| Metode HTTP | GET |
| Jenis aplikasi yang didukung | appType-Aplikasi internal　appType-Aplikasi perusahaan pihak ketiga |
| Izin | permission-Workflow.Form.Read-Izin baca untuk templat alur kerja |

### Header permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Cara mendapatkannya:   - Aplikasi internal: Panggil API [Mendapatkan access token aplikasi internal](/id/open/development/obtain-the-access-token-of-an-internal-app). - Aplikasi perusahaan pihak ketiga: Panggil API untuk mendapatkan access token organisasi yang diotorisasi oleh Aplikasi pihak ketiga. |

### Parameter kueri

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| processCode | String | Ya | Kode unik formulir. Dapatkan dengan memanggil API [Membuat atau memperbarui templat formulir persetujuan](/id/open/development/create-an-approval-form-template), atau lihat [Ikhtisar Persetujuan OA - Glosarium](/id/open/development/workflow-overview). |
| appUuid | String | Tidak | Informasi isolasi untuk pembuatan aplikasi. |
