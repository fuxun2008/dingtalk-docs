---

Panggil API ini untuk mengambil daftar semua gambar mengambang pada Lembar Kerja tertentu di DingTalk Spreadsheet. API ini berlaku untuk skenario yang memerlukan pembacaan gambar mengambang secara massal dalam sebuah Lembar Kerja, seperti ekspor, sinkronisasi, atau audit. Isi respons berisi pengenal unik, URL gambar, posisi anchor, dan offset ukuran setiap gambar.

## Permintaan

### Informasi dasar

| Bidang | Value |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/doc/workbooks/{workbookId}/sheets/{sheetId}/floatImages` |
| Metode HTTP | POST |
| Jenis aplikasi yang didukung | appType-Aplikasi internal |
| Izin yang diperlukan | permission-Document.Workbook.Write-Izin tulis DingTalk Spreadsheet |

### Header permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Panggil API [Mendapatkan access token aplikasi internal](/id/open/development/obtain-the-access-token-of-an-internal-app) untuk memperolehnya. |

### Parameter path

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| workbookId | String | Ya | ID file spreadsheet. `nodeId(dentryUuid)` yang dikembalikan oleh [API Knowledge Base](/id/open/development/knowledge-base-overview) adalah `workbookId` dari spreadsheet. Peroleh dengan memanggil API [Mendapatkan node](https://open.dingtalk.com/document/development/get-node) dan [Membuat dokumen Knowledge Base](/id/open/development/create-team-space-document). |
| sheetId | String | Ya | ID atau judul Lembar Kerja. Panggil API [Mendapatkan semua Lembar Kerja](/id/open/development/obtain-all-worksheets) untuk memperoleh ID dan judul Lembar Kerja. |

### Parameter query

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| operatorId | String | Ya | unionId dari operator. Panggil API [Mengueri detail pengguna](/id/open/development/query-user-details) untuk memperolehnya. Jika operator tidak memiliki izin, API mengembalikan error `The operator has no permission`. |

### Isi permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| src | String | Ya | URL sumber daya dari gambar mengambang. Peroleh `resourceUrl` dengan memanggil API [Mendapatkan informasi unggah sumber daya](/id/open/development/api-getresourceuploadinfo). |
| anchor | Object | Ya | Informasi pemosisian dari gambar mengambang. |
| row | Integer | Ya | Indeks baris untuk pemosisian. Cursor dimulai dari 0. |
| col | Integer | Ya | Indeks kolom untuk pemosisian. Cursor dimulai dari 0. |
| coordinate | Object | Ya | Informasi geometri. |
| width | double | Ya | Lebar gambar, dalam piksel. |
| height | double | Ya | Tinggi gambar, dalam piksel. |
| offsetX | double | Ya | Offset horizontal relatif terhadap koordinat pemosisian, dalam piksel. |
| offsetY | double | Ya | Offset vertikal relatif terhadap koordinat pemosisian, dalam piksel. |
