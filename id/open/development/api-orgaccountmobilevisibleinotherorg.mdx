Beri izin agar bidang tertentu dari Akun Perusahaan organisasi saat ini terlihat oleh organisasi lain setelah akun tersebut bergabung dengan organisasi tersebut.

## Permintaan

### Informasi dasar

| Bidang | Nilai |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/v1.0/contact/orgAccounts/mobiles/visibleInOtherOrg |
| Metode HTTP | PUT |
| Jenis aplikasi yang didukung | appType-Aplikasi internal |
| Izin yang diperlukan | permission-Contact.OrgAccount.VisiblityInOtherOrg-Izin visibilitas data untuk Akun Perusahaan setelah bergabung dengan organisasi lain |

### Header permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Dapatkan dengan memanggil API [Mendapatkan access token dari aplikasi internal](/id/open/development/obtain-the-access-token-of-an-internal-app#). |

### Isi permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| toCorpIds | Array of String | Ya | Daftar ID organisasi (corpId) dari organisasi yang diberi izin.  Daftar corpId organisasi yang diberi izin dan userId pemanggil API tidak boleh kosong. Parameter yang tidak valid akan menyebabkan pemanggilan API gagal. |
| optUserId | String | Ya | userId pemanggil API saat ini.  Digunakan untuk audit data. Anda harus memberikan userId karyawan yang valid dari organisasi saat ini; jika tidak, pemanggilan API akan gagal. |
| fields | Array of String | Tidak | Bidang yang diberi izin:  Jika fields kosong atau merupakan koleksi kosong, hanya mobile yang diberi izin (untuk kompatibilitas mundur).   - **mobile**: Nomor ponsel dari Akun Perusahaan. - **status**: Status penonaktifan dari Akun Perusahaan. |
