Panggil API ini untuk menutup rapat video. Hanya tuan rumah rapat yang memiliki izin untuk menutupnya.

## Permintaan

### Informasi dasar

| Bidang | Nilai |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/conference/videoConferences/{conferenceId}` |
| Metode HTTP | DELETE |
| Tipe aplikasi yang didukung | appType-Aplikasi internal　appType-Aplikasi perusahaan pihak ketiga |
| Izin yang diperlukan | permission-VideoConference.Conference.Write-Izin pengelolaan informasi Rapat Video |

### Header permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses yang digunakan untuk memanggil API ini. Peroleh dengan cara berikut:   - Untuk aplikasi internal, panggil API [Memperoleh access token aplikasi internal](/id/open/development/obtain-the-access-token-of-an-internal-app#). - Untuk aplikasi perusahaan pihak ketiga, panggil API [Memperoleh access token organisasi yang mengizinkan aplikasi pihak ketiga](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#). |

### Parameter path

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| conferenceId | String | Ya | ID rapat. Panggil API [Membuat rapat video](/id/open/development/create-a-video-conference#) untuk memperoleh nilai parameter conferenceId. |

### Parameter query

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| unionId | String | Ya | Identifier unik seorang karyawan dalam cakupan Akun Perusahaan pengembang saat ini. Panggil API [Membuat kueri detail pengguna](/id/open/development/query-user-details#) untuk memperoleh nilai parameter unionid. |
