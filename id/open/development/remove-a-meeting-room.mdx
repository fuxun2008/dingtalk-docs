Panggil API ini untuk membatalkan ruang yang dipesan untuk suatu acara.

## Permintaan

### Informasi dasar

| Bidang | Nilai |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/calendar/users/{userId}/calendars/{calendarId}/events/{eventId}/meetingRooms/batchRemove` |
| Metode HTTP | POST |
| Tipe aplikasi yang didukung | appType-Aplikasi internal　appType-Aplikasi perusahaan pihak ketiga |
| Izin yang diperlukan | permission-Calendar.Event.Write-Izin tulis untuk acara di aplikasi Kalender |

### Header permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Perolehlah sebagai berikut:   - Untuk aplikasi internal, panggil API [Memperoleh access token aplikasi internal](/id/open/development/obtain-the-access-token-of-an-internal-app#). - Untuk aplikasi perusahaan pihak ketiga, panggil API [Memperoleh access token organisasi yang diberi otorisasi ke aplikasi pihak ketiga](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#). |

### Parameter path

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| userId | String | Ya | unionId penyelenggara acara. Panggil API [Kueri detail pengguna](/id/open/development/query-user-details#) untuk memperolehnya. |
| calendarId | String | Ya | ID kalender tempat acara berada. Nilainya selalu **primary**, yang mewakili kalender utama pengguna. |
| eventId | String | Ya | ID acara. Panggil API [Kueri daftar acara](/id/open/development/query-an-event-list#) untuk memperoleh nilai parameter id. |

### Isi permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| meetingRoomsToRemove | Array | Tidak | Daftar ruang yang pemesanannya perlu dibatalkan. |
| roomId | String | Tidak | roomId ruang yang pemesanannya perlu dibatalkan. Panggil API [Kueri detail tentang suatu acara](/id/open/development/query-details-about-an-event#) untuk memperoleh nilai parameter roomId. |
