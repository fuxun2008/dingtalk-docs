Panggil API ini untuk menghentikan perekaman cloud pada Rapat Video. Rapat Video tetap berlangsung normal dan tidak akan diakhiri.

## Permintaan

### Informasi dasar

| Bidang | Nilai |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/conference/videoConferences/{conferenceId}/cloudRecords/stop` |
| Metode HTTP | POST |
| Tipe aplikasi yang didukung | appType-企业内部应用　appType-第三方企业应用 |
| Persyaratan izin | permission-VideoConference.Conference.Write-视频会议信息管理权限 |

### Header permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses yang digunakan untuk memanggil API ini. Peroleh dengan salah satu cara berikut:   - Untuk aplikasi internal, panggil API [Memperoleh access token aplikasi internal](/id/open/development/obtain-the-access-token-of-an-internal-app#). - Untuk aplikasi perusahaan pihak ketiga, panggil API [Memperoleh access token perusahaan yang diberi otorisasi](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#). |

### Parameter path

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| conferenceId | String | Ya | ID Rapat. Panggil API [Membuat Rapat Video](/id/open/development/create-a-video-conference#) untuk memperoleh nilai parameter conferenceId. |

### Isi permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| unionId | String | Ya | unionId dari Pengguna. Panggil API [Kueri detail pengguna](/id/open/development/query-user-details#) untuk memperoleh nilai parameter unionid.    Hanya Tuan Rumah Rapat yang memiliki izin untuk menghentikan perekaman cloud. |
