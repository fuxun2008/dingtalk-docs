---
title: "Mendapatkan detail satu instans persetujuan"
description: "Panggil API DingTalk untuk mengambil detail instans persetujuan berdasarkan ID, termasuk judul, userId pengaju dan penyetuju, serta log aktivitas alur kerja."
---

Panggil API ini untuk mendapatkan detail instans persetujuan berdasarkan ID instansnya. Detail tersebut mencakup judul instans persetujuan, userId pengaju, userId penyetuju, dan log aktivitas.

## Permintaan

### Informasi dasar

| Bidang | Nilai |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/v1.0/workflow/processInstances |
| Metode HTTP | GET |
| Tipe aplikasi yang didukung | appType-Aplikasi internal　appType-Aplikasi perusahaan pihak ketiga |
| Izin yang diperlukan | permission-Workflow.Instance.Read-Izin baca instans alur kerja |

### Header permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Cara mendapatkannya:   - Aplikasi internal: Panggil API [Mendapatkan access token aplikasi internal](/id/open/development/obtain-the-access-token-of-an-internal-app). - Aplikasi perusahaan pihak ketiga: Panggil API untuk mendapatkan access token organisasi yang telah memberikan otorisasi kepada Aplikasi pihak ketiga. |

### Parameter kueri

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| processInstanceId | String | Ya | ID instans persetujuan.   - Panggil API [Membuat instans persetujuan](/id/open/development/create-an-approval-instance) untuk mendapatkan nilai parameter `InstanceId`. - Panggil API [Mendapatkan daftar ID instans persetujuan](/id/open/development/obtain-an-approval-list-of-instance-ids) untuk mendapatkan nilai parameter `list`. |

### Contoh permintaan

Host:api.dingtalk.io
x-acs-dingtalk-access-token:6d1bxxxx
Content-Type:application/json
