Panggil API ini untuk membuat tabel baru di dalam AI Table.

## Permintaan

### Informasi dasar

| Bidang | Nilai |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/notable/bases/{baseId}/sheets` |
| Metode HTTP | POST |
| Jenis aplikasi yang didukung | appType-Internal app |
| Izin yang diperlukan | permission-Notable.Base.Write.All-AI Table app write permission |

### Header permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Dapatkan dengan memanggil API [Mendapatkan access token dari aplikasi internal](/id/open/development/obtain-the-access-token-of-an-internal-app#). |

### Parameter jalur

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| baseId | String | Ya | ID dari AI Table. Untuk cara memperolehnya, lihat [Struktur data](/id/open/development/data-structure#). |

### Parameter kueri

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| operatorId | String | Ya | unionId dari operator. Dapatkan dengan salah satu cara berikut:   - Panggil API [Kueri detail pengguna](/id/open/development/query-user-details#). - Panggil API [Mendapatkan informasi pengguna melalui kode login senyap](/id/open/development/obtain-the-userid-of-a-user-by-using-the-log-free#). |

### Isi permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| name | String | Tidak | Nama tabel. |
| fields | Array | Tidak | Konfigurasi bidang tabel. |
| name | String | Ya | Nama field. |
| type | String | Ya | Tipe bidang. Untuk tipe yang didukung, lihat [Properti bidang](https://open.dingtalk.com/document/development/field-properties#). |
| property | `Map<String, Any>` | Tidak | Properti bidang. Untuk formatnya, lihat [Properti bidang](https://open.dingtalk.com/document/development/field-properties#). |
|  | Any | Tidak | Properti bidang. Tipe bidang yang berbeda memiliki konfigurasi properti yang berbeda. |
