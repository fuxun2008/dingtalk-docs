Panggil API ini untuk mengambil profil pengguna dari kontak organisasi.

## Permintaan

| **Informasi dasar** | |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/contact/users/{unionId}` |
| Metode HTTP | GET |
| Tipe aplikasi yang didukung | appType-Internal appappType-Third-party enterprise appappType-Third-party personal app |
| Izin yang diperlukan | permission-Contact.User.Read-Izin baca untuk profil kontak |

### Header permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil Server API. Gunakan access token pengguna individual. Untuk detailnya, lihat [Mendapatkan kredensial akses pengguna yang masuk](/id/open/development/obtain-identity-credentials). |

### Parameter path

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| unionId | String | Ya | unionId pengguna.  **Catatan**    Untuk mengambil profil pengguna yang sedang diberi otorisasi, atur unionId ke `me`. |

## Respons

### Isi respons

| Nama | Tipe | Deskripsi |
| --- | --- | --- |
| nick | String | Nama DingTalk pengguna. |
| avatarUrl | String | URL foto profil. |
| mobile | String | Nomor telepon seluler pengguna.  **Catatan**     - Aplikasi pihak ketiga milik perusahaan tidak dapat mengambil nomor telepon seluler lengkap. API ini menyamarkan nomor telepon seluler untuk aplikasi pihak ketiga milik perusahaan. Contoh: `155****3240`. - Untuk mengambil nomor telepon seluler pengguna, ajukan izin **Nomor telepon seluler personal** di [DingTalk Developer Console](https://open-dev.dingtalk.io/), seperti ditunjukkan pada gambar di bawah. |
| openId | String | openId pengguna. |
| unionId | String | unionId pengguna. |
| email | String | Alamat email personal pengguna.  **Catatan**    Tambahkan alamat email personal. |
| stateCode | String | Kode negara yang sesuai dengan nomor telepon seluler. |

### Contoh isi respons
