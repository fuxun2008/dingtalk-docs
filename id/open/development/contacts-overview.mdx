## Apa itu DingTalk Contacts

DingTalk Contacts adalah infrastruktur inti untuk pengelolaan terpadu informasi internal organisasi. Contacts merepresentasikan Struktur Organisasi dan informasi Pengguna sebuah Organisasi secara digital, memberikan kemampuan dasar bagi pengguna untuk menemukan orang dengan cepat dan berkolaborasi secara efisien.

Untuk detail fitur lebih lanjut, lihat [Panduan Pengguna DingTalk - Kontak Organisasi](https://docs.dingtalk.io/i/p/Y7kmbokZp3pgGLq2/docs/Y7kmbpxy30LLzLq2?dontjump=true#).

| **Dimensi** | **Deskripsi** |
| --- | --- |
| Esensi | Wadah representasi digital dari Struktur Organisasi |
| Bentuk | Hierarki Departemen berstruktur pohon + basis data informasi Pengguna |
| Fungsi | Pusat yang menghubungkan orang, urusan, dan sumber daya dalam sebuah Organisasi, mendukung skenario seperti alur Persetujuan, perutean pesan, dan kontrol Izin |

## Cara melihat Contacts

### Perspektif Admin Organisasi

Admin Organisasi dapat mengelola dan melihat Contacts dengan cara berikut:

- DingTalk Admin Console: Masuk ke [DingTalk Admin Console](https://oa.dingtalk.io/), lalu buka modul **Internal Contacts** untuk melakukan pengelolaan dan konfigurasi Contacts secara penuh.
- Pengaturan Contacts: Konfigurasikan fitur lanjutan seperti aturan visibilitas Contacts, Bidang kustom, dan mode Eksekutif.

### Pengguna reguler

Pengguna Organisasi reguler dapat melihat Contacts melalui endpoint berikut:

- **DingTalk for PC**: Pada klien DingTalk PC, klik tab **Contacts** untuk melihat Struktur Organisasi dan detail kontak.
- **DingTalk Mobile**: Pada aplikasi DingTalk mobile, buka halaman **Contacts** untuk menelusuri berdasarkan Departemen atau mencari berdasarkan kata kunci.
- **DingTalk for Web**: Akses fitur Contacts melalui versi web DingTalk.

## Glosarium

### ID Karyawan

Kode Bidang yang berkaitan dengan ID Karyawan adalah `job_number`. ID Karyawan seorang Karyawan dalam sebuah Organisasi tidak harus unik, sehingga tidak dapat digunakan sebagai pengenal unik Karyawan dalam Organisasi.

Admin Organisasi masuk ke [DingTalk Admin Console](https://oa.dingtalk.io/), dan pada halaman Contacts, klik **Nama Karyawan** untuk melihat ID Karyawan. Bidang ID Karyawan bersifat Opsional.

### unionId

Pengenal unik seorang pengguna dalam cakupan akun DingTalk Open Platform saat ini. Satu akun DingTalk Open Platform dapat memuat beberapa App terbuka, termasuk App suite ISV dan Aplikasi internal.

unionId dapat diperoleh dengan memanggil API [Kueri detail pengguna](/id/open/development/query-user-details).

### Grup peran dan peran

Grup peran dan Peran didefinisikan dalam Organisasi untuk memudahkan pengelolaan informasi identitas Karyawan. Seorang Karyawan dapat memegang beberapa identitas Peran secara bersamaan.

Admin Organisasi masuk ke [DingTalk Admin Console](https://oa.dingtalk.io/), buka halaman **Contacts > Internal Contacts Management**, lalu klik **Role** untuk melihat Grup peran dan Peran.

### Bidang ekstensi Contacts

Anda dapat menambahkan Bidang ekstensi ke Contacts.

Admin Organisasi masuk ke [DingTalk Admin Console](https://oa.dingtalk.io/), dan buka **Internal Contacts Settings > Contacts Information > Add Custom Field** untuk menambahkan Bidang kustom.
