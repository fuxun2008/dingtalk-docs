## Apa itu Prompt

Prompt adalah teks input yang diberikan kepada Large Language Model (LLM) yang mengarahkannya untuk menghasilkan output yang sesuai. Prompt biasanya lebih dari sekadar string yang di-hardcode—melainkan gabungan dari sebuah templat, beberapa contoh, dan input pengguna. Agar prompt lebih mudah dikelola dan digunakan, Anda biasanya menggunakan templat prompt (PromptTemplate) untuk membuat dan memeliharanya.

## Apa itu PromptTemplate

Templat prompt adalah string teks yang dapat digunakan kembali dan menghasilkan prompt dengan mengambil sekumpulan parameter dari pengguna akhir. Dengan mengganti nilai parameter dalam templat, Anda dapat dengan mudah membangun dan menggunakan prompt, mirip seperti membangun dokumen dari templat dokumen di DingTalk Docs.

Untuk membantu developer menulis dan men-debug templat prompt, aplikasi AI DingTalk menyediakan Prompt Builder. Dengan Prompt Builder, developer dapat memperlakukan Prompt sebagai sebuah Entitas untuk pengelolaan persisten, penyetelan unit, dan iterasi versi, serta membangun komponen PromptTemplate mereka sendiri untuk digunakan kembali di berbagai aplikasi dan Keterampilan. Ke depannya, Prompt Builder juga akan mendukung fitur seperti evaluasi data, optimasi otomatis, dan estimasi penggunaan. Untuk detailnya, lihat Cara Menggunakan Prompt Builder.

## **Cara Menggunakan Variabel dalam Templat Prompt**

Saat kapabilitas AI berjalan, kapabilitas tersebut menghasilkan sejumlah besar data—misalnya, openConversationId dari Obrolan Grup tempat Tabler berjalan, corpId dari Organisasi tempat pengguna berada, serta Nama dan userId pengguna. Untuk memudahkan developer mengakses nilai-nilai ini, platform pengembangan aplikasi AI menyediakan cara yang praktis untuk mengambilnya.

#### **Contoh**

- Untuk mendapatkan input pengguna, masukkan variabel `@{input}` dalam templat prompt.
- Untuk mendapatkan Nama pengguna, masukkan variabel `@{user.name}` dalam templat prompt.
- Untuk mendapatkan waktu saat ini, masukkan variabel `@{time}` dalam templat prompt.

#### **Penggunaan**

- Ekspresi nilai

  ```
  @{user.name}
  ```
- Ekspresi iterasi

  ```
  @foreach{message : aiMessages} 
    @{message.sender.nick}: @{message.summary}
  @end{}
  ```
- Ekspresi kondisional

  ```
  @if{groupConversation != null}
    Group Chat title: @{groupConversation.title}
  @else{singleConversation != null}
    Direct Message target: @{singleConversation.targetUser.name}
  @else{}
    Not currently in an IM conversation
  @end{}
  ```

#### **Variabel Sistem**

```
<!-- Input pengguna -->
@{input} 

<!-- Waktu saat ini -->
@{time} 

<!-- Informasi pengguna saat ini, mencakup nama Organisasi pengguna, corpId organisasi, Nama pengguna, dan userId pengguna -->
@{user} 

<!-- Nama pengguna di dalam Organisasi -->
@{user.name}

<!-- userId pengguna di dalam Organisasi -->
@{user.staffId}

<!-- openConversationId dari Obrolan Grup saat ini; hanya tersedia dalam skenario IM ketika berupa Obrolan Grup -->
@{groupConversation.openConversationId} 

<!-- openConversationId dari Pesan Langsung saat ini; hanya tersedia dalam skenario IM ketika berupa Pesan Langsung -->
@{singleConversation.openConversationId}
```
