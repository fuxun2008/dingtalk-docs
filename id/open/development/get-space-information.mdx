Panggil API ini untuk mendapatkan informasi sebuah ruang penyimpanan.

## Deskripsi panggilan API

Panggil API ini untuk mendapatkan detail sebuah ruang, termasuk nama ruang, kuota yang digunakan, tipe pemilik, dan lainnya.

- Ketika tipe ruang penyimpanan adalah USER, semua pengguna yang memiliki izin pada ruang tersebut memiliki izin operasi. Karyawan lain harus memanggil API [Tambah izin](/id/open/development/add-permissions-file) untuk memperoleh otorisasi.
- Ketika tipe ruang penyimpanan adalah APP, siapa pun yang melakukan operasi harus memanggil API [Tambah izin](/id/open/development/add-permissions-file) untuk memperoleh otorisasi.

## Permintaan

### Informasi dasar

| Bidang | Nilai |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/storage/spaces/{spaceId}` |
| Metode HTTP | GET |
| Jenis aplikasi yang didukung | appType-Aplikasi internal　appType-Aplikasi perusahaan pihak ketiga |
| Persyaratan izin | permission-Storage.Space.Read-Izin baca pada ruang penyimpanan organisasi |

### Header permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Dapatkan sebagai berikut:   - Untuk aplikasi internal, panggil API [Mendapatkan access token aplikasi internal](/id/open/development/obtain-the-access-token-of-an-internal-app#). - Untuk aplikasi perusahaan pihak ketiga, panggil API [Mendapatkan access token organisasi terotorisasi untuk aplikasi pihak ketiga](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#). |

### Parameter path

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| spaceId | String | Ya | ID ruang. Panggil API [Tambah ruang](/id/open/development/add-space#) untuk mendapatkan nilai parameter id. |

### Parameter query

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| unionId | String | Ya | unionId dari operator. Panggil API [Query detail pengguna](/id/open/development/query-user-details#) untuk mendapatkannya. |

| partitions | Array | Informasi kuota partisi. Nilai maksimum: 2. |

| quota | Object | Informasi kuota. |
| used | Long | Kuota yang benar-benar digunakan, dalam byte. Nilai minimum: 0.      Menunjukkan total kuota yang dikonsumsi oleh file di dalam aplikasi. Mengunggah, menyalin, dan menghapus file akan memperbarui nilai used secara sesuai. |
| max | Long | Kuota maksimum, dalam byte.       - Ketika kuota aplikasi saat ini disetel ke max, kuota aplikasi memiliki batas atas, dan nilai used tidak boleh melebihi nilai max. - Ketika kuota aplikasi saat ini tidak disetel ke max, nilainya kosong. Dalam hal ini, aplikasi berbagi sisa kuota yang tersedia milik organisasi. |
| reserved | Long | Sisa kuota yang telah dialokasikan sebelumnya, dalam byte.      Admin console dapat mengalokasikan kuota terlebih dahulu ke aplikasi atau ruang. Bidang ini menunjukkan sisa kuota yang telah dialokasikan sebelumnya, yaitu bagian yang belum digunakan dari kuota yang telah dialokasikan. Jika tidak ada kuota yang dialokasikan sebelumnya, bidang ini kosong. |
| type | String | Tipe kuota.   - **SHARE**: Kuota bersama. Dalam mode ini, Quota.max kosong, yang menunjukkan bahwa kuota organisasi digunakan bersama. - **PRIVATE**: Kuota yang dialokasikan sebelumnya (kuota khusus). Dalam mode ini, setelah Quota.max disetel, kuota bersifat eksklusif.       Gunakan kuota yang dialokasikan sebelumnya (kuota khusus) ketika Anda perlu memastikan bahwa kuota yang tersedia untuk satu aplikasi tidak terpengaruh oleh aplikasi lain. |
