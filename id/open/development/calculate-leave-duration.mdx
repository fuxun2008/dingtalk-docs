---
title: "Hitung durasi cuti"
description: "Hitung durasi cuti karyawan secara otomatis berdasarkan aturan penjadwalan shift di DingTalk dengan memanggil API ini menggunakan userid serta waktu mulai dan akhir cuti."
---

Panggil API ini untuk mendapatkan durasi cuti setiap karyawan yang dihitung secara otomatis berdasarkan aturan penjadwalan shift.

## Permintaan

| **Informasi dasar** | |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/topapi/attendance/getleaveapproveduration |
| Metode HTTP | POST |
| Tipe aplikasi yang didukung | appType-Aplikasi internal appType-Aplikasi perusahaan pihak ketiga |
| Izin yang diperlukan | permission-qyapi_base-Izin dasar yang diperlukan untuk memanggil API organisasi |

### Parameter query

| Nama | Tipe | Wajib | Contoh | Deskripsi |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | bE74xxxx | Kredensial aplikasi yang digunakan untuk memanggil API ini.   - Aplikasi internal: Dapatkan dengan memanggil [Mendapatkan access_token aplikasi internal](/id/open/development/obtain-orgapp-token). - Aplikasi perusahaan pihak ketiga: Dapatkan dengan memanggil API untuk mendapatkan access_token perusahaan pihak ketiga. |

### Isi permintaan

| Nama | Tipe | Wajib | Contoh | Deskripsi |
| --- | --- | --- | --- | --- |
| userid | String | Ya | user123 | ID pengguna karyawan di Organisasi Anda. Organisasi menggunakan bidang ini untuk mengidentifikasi pengguna secara unik. |
| from_date | Date | Ya | 2016-03-09 11:11:11 | Waktu mulai cuti. |
| to_date | Date | Ya | 2016-03-10 11:11:11 | Waktu akhir cuti. |

### Contoh permintaan

```curl
curl -X POST "https://api.dingtalk.io/topapi/attendance/getleaveapproveduration" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=6777xxxx6f4eff' \
-d 'from_date=2016-03-09+11%3A11%3A11' \
-d 'to_date=2016-03-10+11%3A11%3A11' \
-d 'userid=zhangsan'
```

Java

C#


## Respons

### Isi respons

| Nama | Tipe | Contoh | Deskripsi |
| --- | --- | --- | --- |
| result | ApproveDurationForTopVo |  | Hasil yang dikembalikan. |
| duration_in_minutes | Number | 0 | Durasi cuti, dalam menit. |
| errcode | Number | 0 | Kode pengembalian. |
| errmsg | String | ok | Deskripsi kode pengembalian. |
| request_id | String | 3ynh2gp5ndke | ID permintaan. |

### Contoh isi respons

```json
{
  "errcode": 0,
  "errmsg":"ok",
  "result": {
    "duration_in_minutes": 480
  },
  "request_id": "6porp1hqkb9k"
}
```

### Kode error

Jika panggilan ke API ini mengembalikan error, cari solusinya berdasarkan pesan error di dokumen [Kode error global](/id/open/development/server-api-error-codes-1).
