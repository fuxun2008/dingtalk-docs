title: "Mendapatkan daftar tag kontak eksternal"
description: "Panggil API ini untuk mendapatkan daftar tag kontak eksternal suatu organisasi, seperti tag pelanggan, guna mengklasifikasikan dan mengelola kontak eksternal di DingTalk."
---

Panggil API ini untuk mendapatkan tag kontak eksternal di organisasi Anda. Gunakan API ini untuk mengambil daftar tag kontak eksternal. Misalnya, jika sebuah kontak eksternal adalah pelanggan perusahaan, tag-nya bisa berupa "Pelanggan".

## Permintaan

| **Informasi dasar** | |
| --- | --- |
| URL HTTP | https://oapi.dingtalk.io/topapi/extcontact/listlabelgroups |
| Metode HTTP | POST |
| Tipe aplikasi yang didukung | appType-Aplikasi internal appType-Aplikasi perusahaan pihak ketiga |
| Izin yang diperlukan | permission-qyapi_ext_read-Izin baca untuk kontak eksternal organisasi |

### Parameter kueri

| Nama | Tipe | Wajib | Contoh | Deskripsi |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | bE74xxxx | Kredensial aplikasi yang digunakan untuk memanggil API ini.   - Untuk aplikasi internal, dapatkan melalui API untuk mendapatkan access_token aplikasi internal. - Untuk aplikasi perusahaan pihak ketiga, dapatkan melalui API untuk mendapatkan access_token perusahaan pihak ketiga. |

### Isi permintaan

| Nama | Tipe | Wajib | Contoh | Deskripsi |
| --- | --- | --- | --- | --- |
| size | Number | Tidak | 20 | Mendukung penomoran halaman. Hanya berlaku jika ditetapkan bersama parameter offset. Parameter ini menunjukkan ukuran halaman, dengan maksimum 100. |
| offset | Number | Tidak | 0 | Mendukung penomoran halaman. Hanya berlaku jika ditetapkan bersama parameter size. Parameter ini menunjukkan offset, yang dimulai dari 0. |

### Contoh permintaan

```curl
curl -X POST "https://oapi.dingtalk.io/topapi/extcontact/listlabelgroups" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=e6eaxxxxa401' \
-d 'offset=0' \
-d 'size=20'
```

Java

```text
DingTalkClient client = new DefaultDingTalkClient("https://oapi.dingtalk.io/topapi/extcontact/listlabelgroups");
OapiExtcontactListlabelgroupsRequest req = new OapiExtcontactListlabelgroupsRequest();
req.setSize(20L);
req.setOffset(0L);
OapiExtcontactListlabelgroupsResponse rsp = client.execute(req, access_token);
System.out.println(rsp.getBody());
```

### Kode error

Jika error dikembalikan saat Anda memanggil API ini, temukan solusinya di dokumen [kode error global](/id/open/development/server-api-error-codes-1) berdasarkan pesan error.

| Kode error (errcode) | Pesan error (errmsg) | Solusi |
| --- | --- | --- |
| 33009 | Invalid tokenGrantType | Periksa apakah access_token sudah benar. |
| 400043 | Invalid orgId | Periksa apakah access_token sudah benar. |
| 41101 | Invalid size | Periksa apakah ukuran halaman valid. |
| 40068 | Invalid offset | Sesuaikan offset. |
| -1 | System busy | Coba lagi nanti. |
