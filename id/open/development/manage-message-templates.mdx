Artikel ini menjelaskan cara membuat, menghapus, mengaktifkan, menonaktifkan, mengklon, menguji, dan mengonfigurasi templat pesan.

## Membuat dan mengonfigurasi templat pesan

1. Masuk ke [Developer Console](https://open-dev.dingtalk.com/?version=5.86.5#/appMgr/provider/eapp/57406/2).
2. Klik **App Development**, pilih **Aplikasi perusahaan pihak ketiga**, lalu buat mini program atau aplikasi mikro H5.
3. Pada halaman detail aplikasi, klik **Message Push**. Di area pengelolaan templat pesan, klik **Tambah**.
4. Pilih tipe templat lalu klik **Buat**.
5. Konfigurasikan templat pesan lalu klik **Simpan**.

   **Penting**

   Jika parameter templat dikonfigurasi dalam templat, parameter tersebut dimuat secara otomatis di bawah, dan Anda kemudian dapat mengonfigurasi deskripsi setiap parameter dinamis.

   Beberapa nilai dalam konten pesan berubah secara dinamis, seperti nomor pesanan, nomor telepon, dan nama produk. Nilai-nilai ini tidak dapat ditentukan saat Anda menyiapkan templat, sehingga Anda dapat menggunakan parameter templat untuk menggantinya.
6. Klik **Test**, lalu klik **Send Test Message** untuk memverifikasi bahwa templat pesan telah dikonfigurasi dengan benar.

## Mengonfigurasi templat Markdown

Templat Markdown menggunakan sintaks Markdown untuk mengonfigurasi dan mengirim pesan. Templat ini berlaku untuk pesan notifikasi murni yang tidak memerlukan tindakan.

Dengan templat Markdown, Anda dapat dengan mudah mendukung format tampilan seperti teks, gambar, dan tautan.

**Konfigurasi Templat Pesan Markdown**

| Konfigurasi | Mendukung Parameter Templat | Deskripsi |
| --- | --- | --- |
| **Nama Templat** | Tidak | Menentukan nama templat.  Beri nama berdasarkan kasus penggunaan dan tipe templat, misalnya: Templat Notifikasi Tiket Baru. |
| **Kasus Penggunaan** | Tidak | Menjelaskan kasus penggunaan templat. |
| **Gambar** | Tidak | Gambar dalam pesan. Mendukung tautan gambar atau format media\_id.  Item konfigurasi ini diatur secara terpisah, dan setiap pesan hanya mendukung satu gambar. Gambar disematkan di bagian atas. |
| **Judul Pesan** | Tidak | Judul pesan dan konten yang ditampilkan di layar pertama obrolan. |
| **Konten Pesan** | Ya | Konten pesan dalam format Markdown. Disarankan maksimum 1.000 karakter. Untuk sintaks Markdown yang didukung, lihat tabel di bawah.  **Penting**     - Sintaks Markdown templat pesan tidak mendukung heading. Artinya, format heading "# +teks heading" tidak didukung. Masukkan judul pesan secara terpisah di kotak input judul. Hanya judul tingkat pertama yang didukung. - Sintaks Markdown templat pesan tidak mendukung gambar. Artinya, format "" tidak didukung. Masukkan gambar pesan secara terpisah di kotak input gambar. Setiap pesan hanya mendukung satu gambar. |

**Sintaks Markdown**:

```text
Kutip
> Seseorang yang tidak memperjuangkan apa pun akan terjatuh untuk apa saja.
 
Tebal dan Miring
**tebal**
*miring*
 
Tautan
[ini adalah tautan](http://name.com)
 
Daftar Berpoin
- item1
- item2
 
Daftar Bernomor
1. item1
2. item2

Ganti Baris
 Ganti baris yang ditampilkan di kotak input sudah cukup. \n tidak didukung.
```

## Templat ActionCard

Templat ActionCard mengirim pesan dengan tipe pesan ActionCard. Templat ini mendukung pesan yang menggabungkan konten pesan dengan titik tindakan, dan berlaku untuk skenario yang memerlukan satu atau beberapa titik tindakan dalam pesan untuk penanganan cepat.

Berdasarkan templat Markdown, templat ActionCard mendukung gaya pengalihan keseluruhan maupun pengalihan mandiri.

**Konfigurasi Templat ActionCard**

| Konfigurasi | Mendukung Parameter Templat | Deskripsi |
| --- | --- | --- |
| **Nama Templat** | Tidak | Menentukan nama templat.  Beri nama berdasarkan kasus penggunaan dan tipe templat, misalnya: Templat Notifikasi Tiket Baru. |
| **Kasus Penggunaan** | Tidak | Menjelaskan kasus penggunaan templat. |
| **Gambar** | Tidak | Gambar dalam pesan. Mendukung tautan gambar atau format media\_id. Item konfigurasi ini diatur secara terpisah, dan setiap pesan hanya mendukung satu gambar. |
| **Judul Pesan** | Tidak | Judul pesan dan teks yang ditampilkan di daftar obrolan dan notifikasi. Maksimum 64 karakter. |
| **Konten Pesan** | Ya | Konten pesan dalam format Markdown. Disarankan maksimum 1.000 karakter. Untuk sintaks Markdown yang didukung, lihat tabel di bawah.  **Penting**     - Sintaks Markdown templat pesan tidak mendukung heading. Artinya, format heading "# +teks heading" tidak didukung. Masukkan judul pesan secara terpisah di kotak input **Judul**. Hanya judul tingkat pertama yang didukung. - Sintaks Markdown templat pesan tidak mendukung gambar. Artinya, format "" tidak didukung. Masukkan gambar pesan secara terpisah di kotak input **Gambar**. Setiap pesan hanya mendukung satu gambar. |
| **Titik Tindakan** | Ya | Pesan kartu mendukung gaya ActionCard pengalihan keseluruhan maupun gaya ActionCard pengalihan mandiri:   - Gaya ActionCard pengalihan keseluruhan mendukung satu aksi klik. Memasukkan satu konfigurasi menghasilkan gaya pengalihan keseluruhan. - Gaya ActionCard pengalihan mandiri mendukung beberapa aksi klik. Memasukkan beberapa konfigurasi menghasilkan gaya pengalihan mandiri. |
| **Tautan Titik Tindakan** | Ya | Alamat tautan tujuan pengalihan pesan saat diklik. Ketika pesan dikirim sebagai mini program, tautan ini mendukung tautan pengalihan mini program. Maksimum 500 karakter. |
| **Judul Titik Tindakan** | Ya | Judul tombol pengalihan. Maksimum 20 karakter. |

## Templat Formulir

Templat Formulir mengirim pesan berdasarkan tipe pesan OA. Templat ini berlaku untuk menampilkan pesan seperti pesanan, dan mendukung pengalihan untuk melihat detail pesan.

**Konfigurasi Templat Pesan Formulir**

| Konfigurasi | Mendukung Parameter Templat | Deskripsi |
| --- | --- | --- |
| **Nama Templat** | Tidak | Menentukan nama templat.  Beri nama berdasarkan kasus penggunaan dan tipe templat, misalnya: Templat Notifikasi Tiket Baru. |
| **Kasus Penggunaan** | Tidak | Menjelaskan kasus penggunaan templat. |
| **Konten Header Kotak Pesan** | Ya | Judul header pesan. Maksimum 10 karakter.  Berlaku saat dikirim ke obrolan biasa. Saat dikirim ke obrolan organisasi, judul ini digantikan oleh nama aplikasi mikro. |
| **Warna Latar Header Kotak Pesan** | Ya | Warna latar header pesan. Maksimum 8 karakter Inggris, di mana 2 karakter pertama menunjukkan transparansi dan 6 karakter terakhir menunjukkan nilai warna. Jangan tambahkan 0x.  Contoh: FFBBBBBB |
| **Judul Pesan** | Tidak | Judul isi pesan. Disarankan maksimum 50 karakter. |
| **Konten Pesan** | Ya | Konten isi pesan. Maksimum 3 baris ditampilkan. |
| **Gambar dalam Isi Pesan** | Tidak | Gambar dalam pesan. Mendukung tautan gambar atau format media\_id. Item konfigurasi ini diatur secara terpisah, dan setiap pesan hanya mendukung satu gambar. |
| **Konten Formulir** | Ya (judul dan nilai variabel) | Formulir isi pesan. Maksimum 6 item ditampilkan. Kotak input kiri dan kanan masing-masing mewakili kata kunci isi pesan dan nilai yang sesuai. |
| **Tautan Seluler** | Ya | Alamat tautan tujuan pengalihan pesan saat diklik. Ketika pesan dikirim sebagai mini program, tautan ini mendukung tautan pengalihan mini program. |
| **Tautan PC** | Ya | Alamat tujuan pengalihan pesan saat diklik di PC. |

## Mengonfigurasi parameter templat

Beberapa nilai dalam konten pesan berubah secara dinamis, seperti nomor pesanan, nomor telepon, dan nama produk. Nilai-nilai ini tidak dapat ditentukan saat Anda menyiapkan templat, sehingga Anda dapat menggunakan parameter templat untuk menggantinya.

Masukkan nilai aktual untuk mengganti parameter templat saat Anda mengirim Notifikasi Kerja. Parameter templat bersifat opsional dan dapat dikonfigurasi berdasarkan kebutuhan Anda.

**Format Parameter Templat**

Parameter templat menggunakan format `${parameter name}`. Parameter harus mematuhi spesifikasi berikut.

- Harus diawali dengan huruf atau garis bawah.
- Bagian selanjutnya dapat terdiri dari huruf, garis bawah, dan angka.
- Jangan menetapkan terlalu banyak parameter dinamis untuk satu pesan. Disarankan tidak lebih dari 5.

Sebagai contoh, konten pesannya adalah sebagai berikut:

```text
Produk ${product} yang Anda ikuti kini tersedia. Dapatkan selagi bisa!
```

Di sini, `${product}` adalah parameter templat dengan nama parameter `product`. Cukup masukkan nilai parameter ini saat mengirim pesan. Misalnya, masukkan `product` sebagai "Masker Sekali Pakai" saat mengirim pesan. Maka "Masker Sekali Pakai" menggantikan parameter templat $&#123;product&#125;, dan konten pesan yang akhirnya diterima pengguna adalah sebagai berikut:

```text
Produk Masker Sekali Pakai yang Anda ikuti kini tersedia. Dapatkan selagi bisa!
```

Sebuah templat pesan dapat memiliki beberapa parameter templat yang dikonfigurasi, atau tanpa parameter templat sama sekali. Aturlah berdasarkan kebutuhan aktual Anda.

**Penerjemahan ID**

Saat memasukkan parameter dinamis, penerjemahan ID didukung. Saat ini mendukung konversi ID departemen menjadi nama departemen dan konversi userId menjadi nama pengguna.

Sintaks penerjemahan ID adalah sebagai berikut:

```text
$departmentName=DEPARTMENT_ID$
$userName=USERID$
```

Di sini:

- DEPARTMENT\_ID adalah ID departemen numerik.
- USERID adalah ID pengguna dari pengguna tersebut.

Sebagai contoh:

- Ganti $departmentName=100$ dengan nama departemen yang sesuai dengan ID departemen "100", seperti "DingTalk Open Platform".
- Ganti $userName=zhangsan01$ dengan nama pengguna yang sesuai dengan ID pengguna "zhangsan01", seperti "Budi".

## Mengirim untuk ditinjau

Setelah membuat templat pesan, klik **Kirim** untuk mengirimkan templat untuk ditinjau.

## Mengaktifkan templat

Setelah templat lolos tinjauan, templat diaktifkan secara otomatis. Ketika templat pesan diaktifkan, Anda dapat mengirim pesan templat dengan memanggil API. Untuk detailnya, lihat [Menggunakan Templat untuk Mengirim Pesan Notifikasi Kerja](/zh/open/development/work-notification-templating-send-notification-interface).

## Menonaktifkan templat

Ketika Anda tidak lagi membutuhkan sebuah templat, matikan tombol aktif untuk berhenti menggunakan templat tersebut.

## Menghapus templat

Klik **Hapus** untuk menghapus sebuah templat.

## Mengklon templat

Klik **Clone** untuk menyalin sebuah templat dengan konfigurasi yang sama.

## Menguji templat

Setelah mengklik **Edit**, Anda memasuki antarmuka pengeditan templat. Klik tombol **Test** pada halaman pengeditan templat untuk menjalankan pengujian. Pengujian akan mengirim Notifikasi Kerja kepada diri Anda sendiri.
