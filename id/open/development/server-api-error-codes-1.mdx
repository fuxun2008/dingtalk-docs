title: "Kode error global"
description: "Menampilkan daftar kode error global yang dikembalikan oleh API DingTalk Open Platform, membantu developer dengan cepat menemukan dan memecahkan masalah berdasarkan kode error."
---

Saat Anda memanggil API DingTalk Open Platform, Anda menerima hasil pengembalian yang mencakup informasi kode error keberhasilan atau kegagalan. Analisis kode error untuk dengan cepat menemukan masalah dan melakukan debug.

<Note>
Berikut adalah daftar kode error umum di sisi server. Jika suatu kode error API tidak tercantum dalam kode error global, cari dalam dokumentasi API terkait. Sebagai alternatif, gunakan fungsi pencarian di sudut kanan atas untuk menemukan deskripsi kode error dan saran pemecahan masalah secara global.
</Note>
