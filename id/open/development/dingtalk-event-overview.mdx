Topik ini memperkenalkan produk Calendar, termasuk cara mengaktifkan Calendar, kemampuan API yang disediakan Calendar, dan cara mengintegrasikan kemampuan Calendar.

## Apa itu Calendar

DingTalk Calendar terintegrasi secara mendalam dengan pesan instan. Rekan kerja dapat berbagi acara, memulai rapat acara dengan mudah, dan melihat hal-hal penting sekilas, sehingga memungkinkan kolaborasi tim yang lebih efisien dan pengalaman yang baik bagi karyawan. Untuk informasi selengkapnya, lihat [Panduan Pengguna DingTalk - Calendar](https://docs.dingtalk.io/i/p/Y7kmbokZp3pgGLq2/docs/Y7kmbOpyEdYLGLq2?dontjump=true%23%23).

### Notifikasi yang tepat untuk rapat acara

Buat acara rapat dengan satu klik. Undangan dikirim langsung ke setiap partisipan sebagai pesan obrolan, memastikan tidak ada yang terlewat.

### Manajemen acara terpadu

Hubungkan dengan Alibaba Mail untuk melihat dan mengedit acara secara terpadu di dalam kalender DingTalk. Perbarui di satu tempat dan sinkronkan di mana saja, sehingga Anda tidak pernah melewatkan rapat atau jadwal.

## Cara mengaktifkan Calendar

Di perangkat seluler: Ketuk **Collaboration** > **Calendar**, atau ketuk **Calendar** di bilah alat.

Di desktop: Klik **Calendar**.

## Ikhtisar kemampuan terbuka

### Daftar API

Calendar menyediakan sekumpulan open API yang lengkap. Developer dapat menggunakan API ini untuk mengintegrasikan Calendar dengan sistem bisnis organisasi mereka.

### Catatan

1. API [New Event](/id/open/development/create-schedule), [Update Event](/id/open/development/modify-event), [Add Event Attendees](/id/open/development/add-schedule-participant), dan [Delete Event Attendees](/id/open/development/delete-schedule-participant) masing-masing mendukung hingga 500 partisipan per operasi, dan maksimum 5.000 partisipan per acara.
2. Untuk menambahkan atau menghapus partisipan acara, kami merekomendasikan penggunaan API [Add Event Attendees](/id/open/development/add-schedule-participant) dan [Delete Event Attendees](/id/open/development/delete-schedule-participant).

## Definisi sumber daya

| Atribut | Tipe | Deskripsi |
| --- | --- | --- |
| id | String | ID unik global dari acara. |
| summary | String | Judul acara. |
| description | String | Deskripsi acara. |
| start | Object | Waktu mulai acara. |
| start.date | String | Tanggal mulai acara dalam format yyyy-MM-dd. Wajib untuk acara sepanjang hari; harus kosong untuk acara non-sepanjang-hari. |
| start.dateTime | String | Waktu mulai acara dalam format tanggal-waktu ISO-8601. Wajib untuk acara non-sepanjang-hari; harus kosong untuk acara sepanjang hari. |
| start.timeZone | String | Zona waktu dari waktu mulai acara. Wajib untuk acara non-sepanjang-hari; harus kosong untuk acara sepanjang hari. |
| end | Object | Waktu akhir acara. |
| end.date | String | Tanggal akhir acara dalam format yyyy-MM-dd. Wajib untuk acara sepanjang hari; harus kosong untuk acara non-sepanjang-hari. |
| end.dateTime | String | Waktu akhir acara dalam format tanggal-waktu ISO-8601. Wajib untuk acara non-sepanjang-hari; harus kosong untuk acara sepanjang hari. |
| end.timeZone | String | Zona waktu dari waktu akhir acara. Harus sesuai dengan zona waktu dari waktu mulai, dalam format nama TZ database. Wajib untuk acara non-sepanjang-hari; harus kosong untuk acara sepanjang hari. |
| isAllDay | Boolean | Apakah acara merupakan acara sepanjang hari. |
| recurrence | Object | Aturan pengulangan acara. |
| recurrence.pattern | Object | Pola pengulangan. |
| recurrence.pattern.type | String | Tipe pola pengulangan:   - **daily**: Berulang setiap `interval` hari. - **weekly**: Berulang pada `daysOfWeek` setiap `interval` minggu. - **absoluteMonthly**: Berulang pada hari `dayOfMonth` setiap `interval` bulan. - **relativeMonthly**: Berulang pada `daysOfWeek` dari minggu `index` setiap `interval` bulan. - **absoluteYearly**: Berulang setiap `interval` tahun. |
| recurrence.pattern.dayOfMonth | Integer | Ketika `type=absoluteMonthly`, menentukan hari dalam bulan. |
| recurrence.pattern.daysOfWeek | String | Menentukan hari dalam seminggu sebagai kata bahasa Inggris huruf kecil. Pisahkan beberapa nilai dengan koma. |
| recurrence.pattern.index | String | Ketika `type=relativeMonthly`, menentukan minggu dalam bulan:   - **first** - **second** - **third** - **fourth** - **last**   `last` menunjukkan minggu terakhir dalam bulan. |
| recurrence.pattern.interval | Integer | Interval pengulangan. Satuannya bervariasi menurut tipe. Misalnya, ketika `type=daily`, intervalnya dalam hari; ketika `type=absoluteYearly`, intervalnya dalam tahun. |
| recurrence.range | Object | Rentang pengulangan. |
| recurrence.range.type | String | Tipe rentang pengulangan:   - **noEnd**: Tidak pernah berakhir. - **endDate**: Berakhir pada tanggal yang ditentukan. - **numbered**: Berakhir setelah sejumlah kemunculan yang ditentukan. |
| recurrence.range.endDate | String | Tanggal akhir pengulangan. |
| recurrence.range.numberOfOccurrences | Integer | Jumlah kemunculan. |
| attendees | Array | Daftar partisipan acara. |
| attendees.id | String | unionId dari pengguna. |
| attendees.displayName | String | Nama pengguna. |
| attendees.responseStatus | String | Status partisipan:   - **needsAction**: Tidak ada tindakan yang diambil (status default). - **accepted**: Diterima. - **declined**: Ditolak. - **tentative**: Diterima sementara. |
| attendees.self | Boolean | Apakah ini pengguna yang sedang mengoperasikan. |
| organizer | Object | Penyelenggara acara. |
| organizer.id | String | unionId dari penyelenggara. |
| organizer.displayName | String | Nama pengguna penyelenggara. |
| organizer.responseStatus | String | Status respons penyelenggara. |
| organizer.self | Boolean | Apakah ini pengguna saat ini. |
| location | Object | Lokasi acara. |
| location.displayName | String | Nama lokasi. |
| reminders | Array | Pengingat acara. |
| reminders.method | String | Metode pengingat:   - **dingtalk**: Pengingat dalam aplikasi. - **sms**: Pengingat SMS. - **phone**: Pengingat telepon. |
| reminders.minutes | String | Berapa menit sebelum acara pengingat dikirim. |
| onlineMeetingInfo | Object | Buat rapat online bersama dengan acara. |
| onlineMeetingInfo.type | String | Tipe rapat online:   - **dingtalk**: Rapat video DingTalk. |
| onlineMeetingInfo.conferenceId | String | ID rapat. |
| onlineMeetingInfo.url | String | URL rapat. |
| onlineMeetingInfo.extraInfo | Map | Informasi tambahan yang diperluas. |
| seriesMasterId | String | ID acara utama dari acara berulang. Kosong untuk acara non-berulang. |
| createTime | String | Waktu pembuatan. |
| updateTime | String | Waktu pembaruan. |
| status | String | Status acara:   - **confirmed**: Normal. - **cancelled**: Dibatalkan. |
