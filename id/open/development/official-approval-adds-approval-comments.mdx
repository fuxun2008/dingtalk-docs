title: "Menambahkan komentar persetujuan"
description: "Pelajari cara menambahkan komentar ke instans persetujuan DingTalk melalui Server API, lengkap dengan teks, gambar, dan lampiran dari Drive."
---

Panggil API ini untuk menambahkan komentar ke instans persetujuan.

## Deskripsi panggilan API

Untuk menambahkan lampiran ke komentar persetujuan, unggah file ke ruang Drive persetujuan agar mendapatkan parameter API spaceId, fileType, fileName, fileId, dan fileSize. Ikuti langkah berikut:

1. Panggil API [Mendapatkan informasi ruang Drive persetujuan](/id/open/development/obtains-the-information-about-approval-nail-disk) untuk mendapatkan izin unggah ke ruang Drive serta spaceId ruang Drive persetujuan.
2. Gunakan spaceId ruang Drive persetujuan untuk mengunggah lampiran ke Drive atau memilih file dari Drive di aplikasi web (Aplikasi mikro H5) atau Mini program guna mendapatkan informasi file lampiran Drive.

## Permintaan

### Informasi dasar

| Bidang | Nilai |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/v1.0/workflow/processInstances/comments |
| Metode HTTP | POST |
| Tipe Aplikasi yang didukung | appType-Aplikasi internal |
| Izin yang diperlukan | permission-Workflow.Instance.Write-Izin tulis instans alur kerja |

### Header permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Panggil API [Mendapatkan Access Token Aplikasi internal](/id/open/development/obtain-the-access-token-of-an-internal-app) untuk mendapatkannya. |

### Isi permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| processInstanceId | String | Ya | ID instans persetujuan:   - Panggil API [Membuat instans persetujuan](/id/open/development/create-an-approval-instance) untuk mendapatkan nilai parameter `InstanceId`. - Panggil API [Mendapatkan detail instans persetujuan](/id/open/development/obtain-an-approval-list-of-instance-ids) untuk mendapatkan nilai parameter `list`. |
| text | String | Ya | Konten komentar. Panjang maksimum: 1.024 karakter. |
| commentUserId | String | Ya | userId pemberi komentar. |
| file | Object | Tidak | File. |
| photos | Array of String | Tidak | URL gambar. |
| attachments | Array | Tidak | Daftar lampiran. Jumlah maksimum elemen daftar: 20. |
| spaceId | String | Tidak | ID ruang Drive.      Lihat deskripsi panggilan API dalam topik ini. |
| fileSize | String | Tidak | Ukuran file.      Lihat deskripsi panggilan API dalam topik ini. |
| fileId | String | Tidak | ID file. Panjang maksimum: 256 karakter.      Lihat deskripsi panggilan API dalam topik ini. |
| fileName | String | Tidak | Nama file. Panjang maksimum: 256 karakter.      Lihat deskripsi panggilan API dalam topik ini. |
| fileType | String | Tidak | Tipe file.      Lihat deskripsi panggilan API dalam topik ini. |
