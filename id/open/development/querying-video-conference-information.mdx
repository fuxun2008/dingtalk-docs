Panggil API ini untuk mengambil informasi dasar sebuah rapat, termasuk nama rapat, durasi, waktu mulai, waktu berakhir, dan total jumlah peserta.

## Permintaan

### Informasi dasar

| Bidang | Nilai |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/conference/videoConferences/{conferenceId}` |
| Metode HTTP | GET |
| Tipe aplikasi yang didukung | appType-Internal app　appType-Third-party enterprise app |
| Izin yang diperlukan | permission-VideoConference.Conference.Read-Izin baca untuk informasi rapat video |

### Header permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Dapatkan sebagai berikut:   - Untuk aplikasi internal, panggil API [Dapatkan access token aplikasi internal](/id/open/development/obtain-the-access-token-of-an-internal-app#). - Untuk aplikasi perusahaan pihak ketiga, panggil API [Dapatkan access token organisasi yang mengotorisasi aplikasi pihak ketiga](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#). |

### Parameter jalur

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| conferenceId | String | Ya | conferenceId dari rapat. Panggil API [Buat rapat video](/id/open/development/create-a-video-conference#) untuk mendapatkan conferenceId. |

## Respons

### Isi respons

| Nama | Tipe | Deskripsi |
| --- | --- | --- |
| confInfo | Object | Informasi rapat. |
| activeNum | Integer | Jumlah peserta yang saat ini berada dalam rapat. |
| attendNum | Integer | Total jumlah peserta yang bergabung ke rapat. |
| confDuration | Long | Durasi rapat, dalam milidetik.      Bidang ini dikembalikan setelah rapat berakhir. |
| conferenceId | String | ID rapat. |
| creatorId | String | unionId pengguna yang membuat rapat. |
| creatorNick | String | Nama pengguna yang membuat rapat. |
| externalLinkUrl | String | Tautan untuk bergabung ke rapat. |
| invitedNum | Integer | Jumlah orang yang diundang. |
| startTime | Long | Stempel waktu mulai rapat, dalam milidetik. |
| status | Integer | Status rapat.   - 0: Diinisialisasi - 1: Rapat berakhir - 2: Rapat dimulai |
| title | String | Judul rapat. |
| roomCode | String | Kode rapat. |
| endTime | Long | Stempel waktu berakhir rapat, dalam milidetik.      Bidang ini dikembalikan setelah rapat berakhir. |
| scheduleConferenceId | String | ID rapat yang telah dijadwalkan. |
| bizType | String | Tipe bisnis rapat:   - **0**: Rapat video instan - **3**: Rapat terjadwal - **audio_conf**: Rapat audio |
| cloudRecordStatus | Integer | Status perekaman cloud rapat:   - **0**: Tidak merekam - **1**: Sedang merekam - **2**: Perekaman dijeda - **3**: Perekaman berakhir |
| cloudRecordOwnerUnionId | String | unionId pemilik perekaman cloud. |
| minutesStatus | Integer | Status Notulen Rapat:   - **0**: Belum dimulai - **1**: Sedang merekam - **2**: Dijeda - **3**: Berakhir       Kemampuan Notulen dalam rapat telah dimigrasikan, dan bidang ini tidak lagi dikembalikan. |
| minutesOwnerUnionId | String | unionId pemilik Notulen.      Kemampuan Notulen dalam rapat telah dimigrasikan, dan bidang ini tidak lagi dikembalikan. |
| extensionAppSettings | Array | Daftar informasi kustom untuk aplikasi ekstensi tingkat rapat. |
| appId | String | Agent ID aplikasi mikro tempat cool app rapat berada. |
| appCode | String | appCode dari cool app. |
| autoOpenMode | Integer | Mode buka otomatis:   - **0**: Tidak membuka otomatis - **1**: Membuka otomatis hanya untuk tuan rumah dan co-host - **2**: Membuka otomatis untuk semua peserta |
| extensionAppBizData | String | Informasi kustom untuk aplikasi ekstensi tingkat rapat. |
