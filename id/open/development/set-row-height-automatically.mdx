Panggil API ini untuk menyesuaikan tinggi baris tertentu di DingTalk Spreadsheet secara otomatis berdasarkan ukuran font yang diberikan, sehingga konten ditampilkan sepenuhnya.

## Deskripsi panggilan API

- Menyesuaikan tinggi setiap baris dalam rentang yang ditentukan secara otomatis berdasarkan `fontWidth` (ukuran font) yang diberikan, sehingga konten ditampilkan sepenuhnya.
- Gunakan `row` (cursor baris awal) dan `rowCount` (jumlah baris) untuk menentukan rentang baris yang akan disesuaikan secara otomatis.
- Cursor baris dimulai dari 0. Artinya, cursor baris pertama adalah 0.

## Permintaan

### Informasi dasar

| Bidang | Nilai |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/doc/workbooks/{workbookId}/sheets/{sheetId}/autofitRows` |
| Metode HTTP | POST |
| Jenis aplikasi yang didukung | appType-Internal app |
| Izin yang diperlukan | permission-Document.Workbook.Write-DingTalk Spreadsheet write permission |

### Header permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses yang digunakan untuk memanggil API ini. Anda dapat memperolehnya dengan memanggil API [Mendapatkan access token aplikasi internal](/id/open/development/obtain-the-access-token-of-an-internal-app). |

### Parameter jalur

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| workbookId | String | Ya | ID file spreadsheet. `nodeId` (dentryUuid) adalah `workbookId` dari spreadsheet. Anda dapat memperolehnya dengan memanggil API [Mendapatkan node](/id/open/development/get-knowledge-base-acquisition-node) atau [Membuat dokumen Knowledge Base](/id/open/development/create-team-space-document). |
| sheetId | String | Ya | ID atau judul lembar kerja. Anda dapat memperolehnya dengan memanggil API [Mendapatkan semua lembar kerja](/id/open/development/obtain-all-worksheets), atau masukkan judul lembar kerja. |

### Parameter kueri

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| operatorId | String | Ya | unionId dari operator. Anda dapat memperolehnya dengan memanggil API [Kueri detail pengguna](/id/open/development/query-user-details). |

### Isi permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| row | Long | Ya | Nomor baris, dimulai dari 0. |
| rowCount | Long | Ya | Jumlah baris. |
| fontWidth | Long | Ya | Ukuran font. |
