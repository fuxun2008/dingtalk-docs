Panggil API ini untuk mendapatkan anggota absensi dari grup absensi berdasarkan ID grup absensi, termasuk ID departemen dan userId anggota absensi.

## Deskripsi panggilan API

Jika departemen ditetapkan sebagai anggota absensi, API mengembalikan ID departemen, tetapi tidak mengembalikan daftar pengguna di departemen tersebut.

Misalnya, jika anggota absensi mencakup **Departemen Uji** dan karyawan **Budi**, API ini mengembalikan informasi berikut:

- ID Departemen Uji, tetapi tidak termasuk daftar userId karyawan di departemen tersebut
- userId Budi

## Permintaan

| **Informasi dasar** | |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/topapi/attendance/group/member/list |
| Metode HTTP | POST |
| Tipe aplikasi yang didukung | appType-Aplikasi internal appType-Aplikasi perusahaan pihak ketiga |
| Izin | permission-qyapi_attendance_group_read-Izin kueri grup absensi |

### Parameter kueri

| Nama | Tipe | Wajib | Contoh | Deskripsi |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | bE74xxxx | Kredensial aplikasi yang digunakan untuk memanggil API ini.   - Untuk aplikasi internal, dapatkan dengan memanggil API [Mendapatkan access_token aplikasi internal](/id/open/development/obtain-orgapp-token). - Untuk aplikasi perusahaan pihak ketiga, dapatkan dengan memanggil API Mendapatkan access_token organisasi pihak ketiga. |

### Isi permintaan

| Nama | Tipe | Wajib | Contoh | Deskripsi |
| --- | --- | --- | --- | --- |
| cursor | Number | Tidak | 0 | Nilai cursor. Isi 0 untuk permintaan pertama. Default: 0. |
| op_user_id | String | Ya | user123 | userId operator. |
| group_id | Number | Ya | 98562 | ID grup absensi.  **Catatan**  Jika Anda menggunakan pengenal grup absensi lama group_key, panggil API [Mengonversi groupKey menjadi groupId](/id/open/development/convert-groupkey-to-groupid) untuk mengonversi group_key menjadi group_id. |

### Contoh permintaan

```curl
curl -X POST "https://api.dingtalk.io/topapi/attendance/group/member/list" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=51525xxxx4e1df6' \
-d 'cursor=9828' \
-d 'group_id=98562' \
-d 'op_user_id=dd_dd'
```

Java

```text
DingTalkClient client = new DefaultDingTalkClient("https://api.dingtalk.io/topapi/attendance/group/member/list");
OapiAttendanceGroupMemberListRequest req = new OapiAttendanceGroupMemberListRequest();
req.setCursor(0L);
req.setOpUserId("user123");
req.setGroupId(98562L);
OapiAttendanceGroupMemberListResponse rsp = client.execute(req, access_token);

```

## Respons

### Isi respons

| Nama | Tipe | Contoh | Deskripsi |
| --- | --- | --- | --- |
| request_id | String | zpdxhqyepfon | ID permintaan. |
| errcode | Number | 0 | Kode pengembalian. |
| success | Boolean | true | Menunjukkan apakah panggilan berhasil.   - **true**: Berhasil - **false**: Gagal |
| result | PageResult |  | Daftar hasil kueri. |
| has_more | Boolean | false | Menunjukkan apakah masih ada data lainnya.   - **true**: Ya - **false**: Tidak |
| cursor | Number | 752095318 | Cursor. |
| result | TopGroupMemberVo[] |  | Daftar userId pengguna. |
| atc_flag | String | 0 | Menunjukkan apakah wajib absensi.   - **0**: Wajib absensi - **1**: Anggota bebas absensi |
| type | String | 0 | Tipe.   - **0**: Karyawan - **1**: Departemen |
| member_id | String | user123 | ID anggota, dapat berupa userId atau deptId. |
