---

Panggil API ini untuk mengatur tinggi (dalam piksel) beberapa baris berurutan di DingTalk Spreadsheet, mulai dari baris tertentu. API ini berguna untuk menyesuaikan tinggi baris secara massal guna menyeragamkan jarak baris atau menampung tampilan teks multi-baris. Nilai tinggi otomatis dibulatkan ke bilangan bulat positif, dan API mengembalikan informasi lembar kerja setelah operasi selesai.

## Permintaan

### Informasi dasar

| Bidang | Nilai |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/doc/workbooks/{workbookId}/sheets/{sheetId}/setRowsHeight` |
| Metode HTTP | POST |
| Jenis aplikasi yang didukung | appType-Internal app |
| Izin yang diperlukan | permission-Document.Workbook.Write-DingTalk Spreadsheet write permission |

### Header permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Panggil API [Mendapatkan access token aplikasi internal](/id/open/development/obtain-the-access-token-of-an-internal-app) untuk memperolehnya. |

### Parameter path

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| workbookId | String | Ya | ID file spreadsheet. `nodeId(dentryUuid)` yang dikembalikan oleh [API Knowledge Base](/id/open/development/knowledge-base-overview) adalah `workbookId` dari spreadsheet. Panggil API [Mendapatkan node](https://open.dingtalk.com/document/development/get-node) atau [Membuat dokumen Knowledge Base](/id/open/development/create-team-space-document) untuk memperolehnya. |
| sheetId | String | Ya | ID atau judul lembar kerja. Panggil API [Mendapatkan semua lembar kerja](/id/open/development/obtain-all-worksheets) untuk memperoleh ID dan judul lembar kerja. |

### Parameter query

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| operatorId | String | Ya | unionId dari operator. Panggil API [Mengkueri detail pengguna](/id/open/development/query-user-details) untuk memperolehnya. Jika operator tidak memiliki izin yang diperlukan, API akan mengembalikan error `The operator has no permission`. |

### Isi permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| row | Long | Ya | Cursor dari baris pertama yang tingginya akan diubah. Dimulai dari 0. |
| rowCount | Long | Ya | Jumlah baris berurutan yang tingginya akan diubah. |
| height | Long | Ya | Tinggi, dalam piksel. |

### Contoh permintaan
