description: "Panggil API ini untuk mendapatkan informasi unggahan setiap part saat melakukan unggahan file multipart di DingTalk — solusi untuk mengunggah file besar secara efisien dengan metode multipart upload."
---

Panggil API ini untuk mendapatkan informasi unggahan setiap part dari sebuah file setelah file tersebut dibagi.

## Deskripsi panggilan API

Ikuti langkah-langkah berikut untuk memanggil API:

Langkah 1: Panggil API [Inisialisasi objek unggahan multipart](/id/open/development/initialize-a-multipart-upload-object) untuk mendapatkan identifier unggahan `uploadKey`.

Langkah 2: Panggil API ini untuk mendapatkan informasi unggahan setiap part dari file.

Langkah 3: Unggah setiap part dalam sebuah loop.

Langkah 4: Gunakan `uploadKey` yang diperoleh pada Langkah 1 untuk memanggil API [Commit file](/id/open/development/submittal-file) guna menyelesaikan unggahan.

Untuk contoh lengkap, lihat berikut ini:

    // Ukuran setiap part
    long partSize = 1 * 1024 * 1024L;  // 1MB
    // Inisialisasi API unggahan multipart
    InitMultipartFileUploadHeaders initMultipartFileUploadHeaders = new InitMultipartFileUploadHeaders();
    initMultipartFileUploadHeaders.xAcsDingtalkAccessToken = "accessToken";

    File file = new File(filePath);
    long fileLength = file.length();
    int partCount = (int) (fileLength / partSize) + ((fileLength % partSize != 0) ? 1 : 0);

    for (int i = 0; i < partCount; i++) {
      long startPos = i * partSize;
      long curPartSize = (i + 1 == partCount) ? (fileLength - startPos) : partSize;
      // Dapatkan informasi unggahan multipart
      GetMultipartFileUploadInfosHeaders getMultipartFileUploadInfosHeaders = new GetMultipartFileUploadInfosHeaders();
      getMultipartFileUploadInfosHeaders.xAcsDingtalkAccessToken = "accessToken";
      GetMultipartFileUploadInfosRequest getMultipartFileUploadInfosRequest = new GetMultipartFileUploadInfosRequest();
      getMultipartFileUploadInfosRequest.setUnionId(unionId);
      getMultipartFileUploadInfosRequest.setUploadKey("uploadKey yang diperoleh dari API inisialisasi unggahan multipart pada langkah 1");
      getMultipartFileUploadInfosRequest.setPartNumbers(Arrays.asList(i + 1));
      GetMultipartFileUploadInfosResponseBody.GetMultipartFileUploadInfosResponseBodyMultipartHeaderSignatureInfosHeaderSignatureInfo headerSignatureInfo = client.getMultipartFileUploadInfosWithOptions(getMultipartFileUploadInfosRequest, getMultipartFileUploadInfosHeaders, new RuntimeOptions()).body.multipartHeaderSignatureInfos.get(0).headerSignatureInfo;
            uploadPartFile(startPos, curPartSize, headerSignatureInfo, file);
        }
            // Commit file untuk menyelesaikan unggahan
            CommitFileHeaders commitFileHeaders = new CommitFileHeaders();
            commitFileHeaders.xAcsDingtalkAccessToken = "accessToken";

                .setConflictStrategy("OVERWRITE");
            CommitFileRequest commitFileRequest = new CommitFileRequest()
                .setUnionId(unionId)
                .setUploadKey("uploadKey yang diperoleh dari API inisialisasi unggahan multipart pada langkah 1")
                .setName("music.mp3")

                .setOption(commitFileRequestOption);
            CommitFileResponseBody.CommitFileResponseBodyDentry dentry = client.commitFileWithOptions("ID ruang penyimpanan", commitFileRequest, commitFileHeaders, new RuntimeOptions()).body.dentry;

    private void uploadPartFile(long start, long size, GetMultipartFileUploadInfosResponseBody.GetMultipartFileUploadInfosResponseBodyMultipartHeaderSignatureInfosHeaderSignatureInfo headerSignatureInfo, File file) throws Exception {
        InputStream inputStream = new FileInputStream(file);
        if (start > 0) {
            inputStream.skip(start);
        }

        URL url = new URL(headerSignatureInfo.getResourceUrls().get(0));
        HttpURLConnection connection = (HttpURLConnection)url.openConnection();
        connection.setDoOutput(true);
        connection.setRequestMethod("PUT");
        connection.setUseCaches(false);
        if (headerSignatureInfo.getHeaders() != null) {
            for (Map.Entry<String, String> entry : headerSignatureInfo.getHeaders().entrySet()) {
                connection.setRequestProperty(entry.getKey(), entry.getValue());
            }
        }
        connection.setReadTimeout(10000);
        connection.setConnectTimeout(10000);
        connection.connect();
        OutputStream out = connection.getOutputStream();
        byte[] buffer = new byte[1024];
        long remain = size;
        for (;remain > 0;) {
            int sizeToRead = remain < buffer.length ? (int)remain : buffer.length;
            int rsz = inputStream.read(buffer, 0, sizeToRead);
            if (rsz < 0) {
                break;
            }
            out.write(buffer, 0, rsz);
            remain -= rsz;
        }
        out.flush();
        out.close();
        int responseCode = connection.getResponseCode();
        if (responseCode == 200) {
            System.out.println("Upload succeeded");
        } else {
            System.out.println("Upload failed");
        }
        connection.disconnect();

### Isi permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| uploadKey | String | Ya | Identifier unggahan yang unik. Panggil API [Inisialisasi objek unggahan multipart](/id/open/development/initialize-a-multipart-upload-object#) untuk memperoleh `uploadKey`. |
| partNumbers | Array of Integer | Ya | ID setiap part file. Jumlah part maksimum adalah 10000, dan ukuran setiap part harus antara 100 KB dan 5 GB. Anda dapat mengirim hingga 30 ID per panggilan.    ID setiap part ditentukan oleh developer. API ini mengembalikan URL unggahan dan header untuk setiap part.  Contoh: [1,2,3,4,5] |
| option | Object | Tidak | Parameter opsional. |
| preferIntranet | Boolean | Tidak | Apakah memprioritaskan transmisi intranet. Untuk menggunakan parameter ini, Anda harus telah mengonfigurasi penyimpanan khusus dengan transmisi intranet.   - true: Ya. Ini adalah nilai default. - false: Tidak. |

| region | String | Wilayah.   - **ZHANGJIAKOU**: Zhangjiakou - **SHENZHEN**: Shenzhen - **SHANGHAI**: Shanghai - **SINGAPORE**: Singapura - **UNKNOWN**: Tidak diketahui |
| internalResourceUrls | Array of String | Daftar URL intranet.    Bidang ini saat ini tidak digunakan. Anda dapat mengabaikannya. |
