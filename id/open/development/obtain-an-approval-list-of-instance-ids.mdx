Panggil API ini untuk mengambil daftar ID instans persetujuan dari departemen terkait dalam cakupan izin Anda.

## Deskripsi panggilan API

### Catatan penting

Bagi pelanggan [OA Premium](dingtalk://dingtalkclient/page/link?url=https%3A%2F%2Fpage.dingtalk.io%2Fwow%2Fdingtalk%2Fdefault%2Fdingtalk%2FlnfR8GaRSWqNncZHSvLLx%3Fdd_mini_app_id%3D5000000004997171&web_wnd=general&width=480&height=800), API ini mendukung kueri data instans hingga 5 tahun terakhir (artinya, startTime tidak boleh lebih dari 5 tahun sebelum waktu saat ini). Tingkatkan ke OA Premium untuk membuka kemampuan ini, memenuhi kebutuhan pengembangan yang lebih lanjut, mendukung skenario bisnis kustom, dan mengakses semua OpenAPI eksklusif.

### Alur panggilan API

1. Panggil API ini untuk mendapatkan ID instans persetujuan dari suatu alur kerja persetujuan.
2. Panggil API [Mendapatkan detail satu instans persetujuan](/id/open/development/obtains-the-details-of-a-single-approval-instance-pop) untuk mendapatkan detail setiap instans persetujuan.

### Catatan penggunaan

- Jika Anda hanya mengirimkan **startTime**, nilainya tidak boleh lebih dari 120 hari sebelum waktu saat ini. Jika **endTime** tidak diisi, nilai default-nya adalah waktu saat ini.
- Jika Anda mengirimkan **startTime** dan **endTime** sekaligus, rentang waktunya tidak boleh melebihi 120 hari, dan **startTime** tidak boleh lebih dari 365 hari sebelum waktu saat ini.
- Total ID instans yang diambil secara bertahap (melalui panggilan berulang) tidak boleh melebihi 10.000.

## Permintaan

### Informasi dasar

| Bidang | Nilai |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/v1.0/workflow/processes/instanceIds/query |
| Metode HTTP | POST |
| Tipe Aplikasi yang didukung | appType-Aplikasi internal |
| Izin yang diperlukan | permission-Workflow.Instance.Read-Izin baca instans alur kerja |

### Header permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Dapatkan dengan memanggil API [Mendapatkan access token Aplikasi internal](/id/open/development/obtain-the-access-token-of-an-internal-app). |

### Isi permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| processCode | String | Ya | Kode unik alur kerja persetujuan.   - Panggil API [Membuat atau memperbarui templat formulir persetujuan](/id/open/development/create-an-approval-form-template) untuk mendapatkan nilai `processCode`. - Lihat [Glosarium - processCode](/id/open/development/workflow-overview). |
| startTime | Long | Ya | Waktu mulai instans persetujuan, dalam format Unix timestamp milidetik.    Misalnya, untuk mendapatkan formulir persetujuan yang diajukan antara 10 April 2020 dan 14 April 2020, kirimkan 1586448000000, yaitu stempel waktu untuk 10 April 2020 00:00:00. |
| endTime | Long | Tidak | Waktu berakhir instans persetujuan, dalam format Unix timestamp milidetik.    Misalnya, untuk mendapatkan formulir persetujuan yang diajukan antara 10 April 2020 dan 14 April 2020, kirimkan 1586879999000, yaitu stempel waktu untuk 14 April 2020 23:59:59. |
| nextToken | Long | Ya | Cursor paginasi.   - Untuk panggilan pertama, kirimkan 0. - Untuk panggilan berikutnya, kirimkan nextToken yang dikembalikan oleh panggilan sebelumnya. |
| maxResults | Long | Ya | Parameter paginasi yang menentukan ukuran halaman. Nilai maksimum: 20. |
| userIds | Array of String | Tidak | Daftar ID pengguna pengaju. Panjang daftar maksimum: 10. Dapatkan dengan memanggil API [Mendapatkan daftar ID pengguna di departemen](/id/open/development/query-the-list-of-department-userids). |
| statuses | Array of String | Tidak | Status instans alur kerja:   - **RUNNING**: Dalam proses persetujuan - **TERMINATED**: Ditarik - **COMPLETED**: Persetujuan selesai     Jika tidak diisi, ID instans dengan semua status akan dikembalikan. |
