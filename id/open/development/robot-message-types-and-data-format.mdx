Artikel ini menjelaskan tipe pesan dan format data untuk mengirim pesan Bot melalui API dan melalui Webhook.

## Tipe Pesan dan Format Data

Ada dua cara untuk mengirim pesan Bot: mengirimnya **melalui API** dan mengirimnya **melalui Webhook**. Metode yang berbeda mendukung tipe pesan dan format data yang berbeda pula.

**Catatan** 

Kami menyarankan untuk mengirim pesan melalui API.

| Tipe Pesan | Kirim Pesan Bot via API | Kirim Pesan Bot via Webhook |
| --- | --- | --- |
| Tipe Teks | ✅ | ✅ |
| Tipe Markdown | ✅ | ✅ |
| Tipe Gambar | ✅ | ❌ |
| Tipe ActionCard | ✅ | ✅ |
| Tipe FeedCard | ❌ | ✅ |
| Pesan Tautan | ✅ | ✅ |

## Tipe Pesan dan Format Data yang Didukung oleh Webhook

### Cakupan yang berlaku

**Catatan** 

Webhook hanya didukung dalam obrolan grup.

Untuk detail cara mengirim pesan melalui Webhook, lihat Kirim Pesan Obrolan Grup Menggunakan Webhook dengan Bot Internal dan Integrasi Bot kustom.

### Format Data

- **Tipe Teks**

  ```
  {
      "at": {
          "atMobiles": [
              "180xxxxxx"
          ],
          "atUserIds": [
              "user123"
          ],
          "isAtAll": false
      },
      "text": {
          "content": "Saya adalah diri saya sendiri, @180xxxxxx sebuah kembang api yang berbeda"
      },
      "msgtype": "text"
  }
  ```

  | **Parameter** | **Wajib** | **Tipe** | **Deskripsi** |
  | --- | --- | --- | --- |
  | msgtype | Ya | String | text. |
  | content | Ya | String | Teks pesan. |
  | atMobiles | Tidak | Array | Nomor ponsel orang yang akan di-@sebut.  **Catatan**  Konten pesan harus menyertakan "@nomor ponsel" dan digunakan bersama parameter atMobiles agar @sebut berfungsi, seperti pada contoh di atas. |
  | atUserIds | Tidak | Array | ID pengguna orang yang akan di-@sebut. |
  | isAtAll | Tidak | Boolean | Setel ke true untuk @Semua Orang; jika tidak, false. |

- **Tipe Tautan**

  ```
  {
      "msgtype": "link", 
      "link": {
          "text": "Ini adalah pesan Tautan", 
          "title": "Ini adalah pesan Tautan", 
          "picUrl": "https://img.alicdn.com/tfs/TB1NwmBEL9TBuNjy1zbXXXpepXa-2400-1218.png", 
          "messageUrl": "https://open.dingtalk.com/document/"
      }
  }
  ```

  | **Parameter** | **Tipe Parameter** | Wajib | **Deskripsi** |
  | --- | --- | --- | --- |
  | msgtype | String | Ya | Tipe pesan. Dalam kasus ini tetap link. |
  | title | String | Ya | Judul pesan. |
  | text | String | Ya | Konten pesan. Jika terlalu panjang, hanya sebagian yang ditampilkan. |
  | messageUrl | String | Ya | URL yang terbuka saat Anda mengeklik pesan. |
  | picUrl | String | Tidak | URL gambar. |

- **Tipe Markdown**

  ```
  {
       "msgtype": "markdown",
       "markdown": {
           "title":"Cuaca Hangzhou",
           "text": "#### Cuaca Hangzhou @150XXXXXXXX \n> 9 derajat, angin barat laut level 1, kualitas udara baik 89, kelembapan relatif 73% \n> \n> ###### Dipublikasikan pukul 10:20 [Cuaca](https://www.dingalk.com) \n"
       },
        "at": {
            "atMobiles": [
                "150XXXXXXXX"
            ],
            "atUserIds": [
                "user123"
            ],
            "isAtAll": false
        }
   }
  ```

  | **Parameter** | **Wajib** | **Tipe** | **Deskripsi** |
  | --- | --- | --- | --- |
  | msgtype | Ya | String | markdown. |
  | title | Ya | String | Konten yang ditampilkan di layar pertama obrolan. |
  | text | Ya | String | Konten pesan dalam format Markdown. |
  | atMobiles | Tidak | Array | Nomor ponsel orang yang akan di-@sebut.  **Catatan**  Konten pesan harus menyertakan "@nomor ponsel" dan digunakan bersama parameter atMobiles agar @sebut berfungsi, seperti pada contoh di atas. |
  | atUserIds | Tidak | Array | ID pengguna orang yang akan di-@sebut. |
  | isAtAll | Tidak | Boolean | Setel ke true untuk @Semua Orang; jika tidak, false. |

  Saat ini, hanya sebagian sintaks Markdown yang didukung. Elemen yang didukung adalah sebagai berikut:

  ```
  Judul
  # Heading 1
  ## Heading 2
  ### Heading 3
  #### Heading 4
  ##### Heading 5
  ###### Heading 6
   
  Kutip
  > A man who stands for nothing will fall for anything.
   
  Teks tebal dan miring
  **bold**
  *italic*
   
  Tautan
  [ini adalah tautan](https://www.dingtalk.com/)
   
  Gambar

   
  Daftar Berpoin
  - item1
  - item2
   
  Daftar Bernomor
  1. item1
  2. item2
  ```
- **Tipe ActionCard Lompatan Seluruh Kartu**

  ```
  {
      "msgtype": "actionCard",
      "actionCard": {
          "title": "Membangun Kedai Kopi", 
          "text": " \n #### Kedai kopi Apple yang ingin dibangun Steve Jobs 20 tahun lalu \n\n Desain Apple Store bergeser dari nuansa yang sangat berorientasi teknologi menuju nuansa yang lebih berorientasi gaya hidup, sebuah arah yang sebenarnya dapat ditelusuri kembali ke rencana Apple 20 tahun lalu untuk membangun sebuah kedai kopi",
          "singleTitle" : "Baca Selengkapnya",
          "singleURL" : "https://www.dingtalk.com/"
      }
  }
  ```

  | **Parameter** | **Wajib** | **Tipe** | **Deskripsi** |
  | --- | --- | --- | --- |
  | msgtype | Ya | String | actionCard. |
  | title | Ya | String | Konten yang ditampilkan di layar pertama obrolan. |
  | text | Ya | String | Konten pesan dalam format Markdown. |
  | singleTitle | Ya | String | Judul tombol tunggal. |
  | singleURL | Ya | String | Tautan lompatan tombol tunggal. |

- **Tipe ActionCard Lompatan Independen**

  ```
  {
      "msgtype": "actionCard",
      "actionCard": {
          "title": "Steve Jobs ingin membangun kedai kopi Apple 20 tahun lalu, dan itu adalah cikal bakal Apple Store", 
          "text": " \n\n #### Kedai kopi Apple yang ingin dibangun Steve Jobs 20 tahun lalu \n\n Desain Apple Store bergeser dari nuansa yang sangat berorientasi teknologi menuju nuansa yang lebih berorientasi gaya hidup, sebuah arah yang sebenarnya dapat ditelusuri kembali ke rencana Apple 20 tahun lalu untuk membangun sebuah kedai kopi", 
          "btnOrientation": "0", 
          "btns": [
              {
                  "title": "Konten yang bagus", 
                  "actionURL": "https://www.dingtalk.com/"
              }, 
              {
                  "title": "Tidak tertarik", 
                  "actionURL": "https://www.dingtalk.com/"
              }
          ]
      }
  }
  ```

  | **Parameter** | **Wajib** | **Tipe** | **Deskripsi** |
  | --- | --- | --- | --- |
  | msgtype | Ya | String | actionCard. |
  | title | Ya | String | Konten yang ditampilkan di layar pertama obrolan. |
  | text | Ya | String | Konten pesan dalam format Markdown. |
  | btns | Ya | Array | Tombol. |
  | title | Ya | String | Judul tombol. |
  | actionURL | Ya | String | URL yang dipicu saat Anda mengeklik tombol. |
  | btnOrientation | Tidak | String | Urutan penataan tombol.  **0**: Tombol ditata secara vertikal  **1**: Tombol ditata secara horizontal |

- **Tipe FeedCard**

  ```
  {
      "msgtype": "feedCard",
      "feedCard": {
          "links": [
              {
                  "title": "Kereta Zaman Melaju ke Depan 1", 
                  "messageURL": "https://www.dingtalk.com/", 
                  "picURL": "https://img.alicdn.com/tfs/TB1NwmBEL9TBuNjy1zbXXXpepXa-2400-1218.png"
              },
              {
                  "title": "Kereta Zaman Melaju ke Depan 2", 
                  "messageURL": "https://www.dingtalk.com/", 
                  "picURL": "https://img.alicdn.com/tfs/TB1NwmBEL9TBuNjy1zbXXXpepXa-2400-1218.png"
              }
          ]
      }
  }
  ```

  | **Parameter** | **Wajib** | **Tipe** | **Deskripsi** |
  | --- | --- | --- | --- |
  | msgtype | Ya | String | feedCard. |
  | title | Ya | String | Teks dari satu item pesan. |
  | messageURL | Ya | String | Tautan lompatan dari satu item pesan. |
  | picURL | Ya | String | URL gambar setelah satu item pesan. |

  Ketika Anda tidak ingin membalas dengan pesan di grup, gunakan format balasan berikut:

  ```
  {
      "msgtype": "empty"
  }
  ```
