Panggil API ini dari aplikasi internal untuk mendapatkan kredensial akses (access token). Saat memanggil Server API DingTalk, Anda harus menggunakan access token untuk autentikasi guna memastikan permintaan berasal dari sumber yang sah dan memiliki izin yang diperlukan.

## Deskripsi panggilan API

API ini dirancang untuk skenario integrasi sistem internal perusahaan dan digunakan untuk mendapatkan kredensial akses yang diperlukan untuk memanggil kapabilitas terbuka DingTalk. Alur penggunaan yang umum adalah sebagai berikut:

- Panggil API ini untuk mendapatkan access token saat aplikasi dimulai atau sebelum panggilan API pertama.
- Simpan access token yang diperoleh di penyimpanan lokal (seperti Redis atau cache in-memory) untuk menghindari permintaan berulang.
- Sertakan access token ini dalam semua panggilan API berikutnya yang memerlukan autentikasi.
- Atur waktu kedaluwarsa cache sedikit lebih pendek dari 7.200 detik (misalnya, 7.000 detik) untuk menerapkan mekanisme muat ulang otomatis dan mencegah kedaluwarsa kredensial akibat penyimpangan waktu.
- Hindari memanggil API ini terlalu sering dalam waktu singkat. Jika tidak, kebijakan batas laju dapat terpicu dan memengaruhi stabilitas layanan.

## Permintaan

| **Informasi dasar** | |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/v1.0/oauth2/accessToken |
| Metode HTTP | POST |
| Jenis aplikasi yang didukung | appType-Aplikasi internal |
| Izin yang diperlukan | permission-qyapi_base-Izin dasar yang diperlukan untuk memanggil API perusahaan |

### Isi permintaan

| Nama | Tipe | Wajib | Contoh | Deskripsi |
| --- | --- | --- | --- | --- |
| appKey | String | Ya | dingeqqpkv3xxxxxx | Client ID dari aplikasi internal yang dibuat. Untuk detail cara mendapatkannya, lihat dokumen [Client ID/Client Secret](/id/open/dingstart/basic-concepts-beta). |
| appSecret | String | Ya | GT-lsu-taDAxxxsTsxxxx | Client Secret dari aplikasi internal yang dibuat. Untuk detail cara mendapatkannya, lihat dokumen [Client ID/Client Secret](/id/open/dingstart/basic-concepts-beta).  **Catatan**  Jaga keamanan Client Secret dan cegah agar tidak bocor. |

### Contoh permintaan

```curl
curl -X POST 'https://api.dingtalk.io/v1.0/oauth2/accessToken' \
  -H 'Content-Type: application/json' \
  -d '{
    "appKey": "dingeqqpkv3xxxxxx",
    "appSecret": "GT-lsu-taDAxxxsTsxxxx"
  }'
```

## Respons

### Isi respons

| Nama | Tipe | Contoh | Deskripsi |
| --- | --- | --- | --- |
| accessToken | String | fw8ef8we8f76e6f7s8dxxxx | Access token yang dihasilkan.  **Catatan**  Saat menggunakan access token, perhatikan hal-hal berikut:   - Simpan access token di sisi Anda, dan simpan secara terpisah per aplikasi, karena access token setiap aplikasi internal bersifat independen. - Jangan memanggil API ini terlalu sering untuk mendapatkan kredensial. Gunakan mekanisme cache untuk mengontrol frekuensi panggilan dan menghindari pembatasan laju oleh sistem. |
| expireIn | Long | 7200 | Waktu kedaluwarsa access token, dalam detik.  **Catatan**  Access token berlaku selama 7.200 detik (2 jam). Permintaan berulang dalam periode validitas akan mengembalikan hasil yang sama dan secara otomatis memperpanjang masa berlakunya. Setelah kedaluwarsa, access token baru akan dikembalikan. |

### Contoh isi respons

```text
HTTP/1.1 200 OK
Content-Type:application/json

{
  "accessToken" : "fw8ef8we8f76e6f7s8dxxxx",
  "expireIn" : 7200
}
```
