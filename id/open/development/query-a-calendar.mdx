Panggil API ini untuk menampilkan daftar kalender milik seorang pengguna.

## Permintaan

### Informasi dasar

| Bidang | Nilai |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/calendar/users/{userId}/calendars` |
| Metode HTTP | GET |
| Tipe aplikasi yang didukung | appType-Internal app　appType-Third-party enterprise app　appType-Third-party personal app |
| Izin yang wajib | permission-Calendar.Event.Read-Izin baca untuk kalender di aplikasi Kalender |

### Header permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Dapatkan dengan cara berikut:   - Untuk aplikasi internal, panggil API [Mendapatkan access token aplikasi internal](/id/open/development/obtain-the-access-token-of-an-internal-app#). - Untuk aplikasi perusahaan pihak ketiga, panggil API [Mendapatkan access token organisasi yang mengotorisasi aplikasi pihak ketiga](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#). - Untuk aplikasi personal pihak ketiga, panggil API [Mendapatkan user token](/id/open/development/obtain-user-token#). |

### Parameter path

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| userId | String | Ya | unionId pengguna target.   - Untuk aplikasi internal atau aplikasi perusahaan pihak ketiga, panggil API [Kueri detail pengguna](/id/open/development/query-user-details#) untuk mendapatkan nilai parameter unionid. - Untuk aplikasi personal pihak ketiga, panggil API [Mendapatkan profil kontak pengguna](/id/open/development/dingtalk-retrieve-user-information#) untuk mendapatkan nilai parameter unionId. |

## Respons

### Isi respons

| Nama | Tipe | Deskripsi |
| --- | --- | --- |
| response | Object | Informasi kalender. |
| calendars | Array | Daftar kalender. |
| id | String | ID kalender. |
| summary | String | Judul kalender. |
| description | String | Deskripsi kalender. |
| timeZone | String | Nama zona waktu dalam format standar **IANA Time Zone Database**, misalnya `Asia/Shanghai`.      Zona waktu untuk acara sepanjang hari ditetapkan ke UTC. Zona waktu default untuk acara yang bukan sepanjang hari adalah `Asia/Shanghai`. |
| eTag | String | eTag dari resource acara, digunakan untuk mendeteksi apakah acara dan acara di dalamnya telah diperbarui. |
| type | String | Tipe kalender.   - **unknown**: Tipe tidak diketahui. - **primary**: Kalender utama pengguna atau aplikasi. - **subscribed**: Kalender langganan yang dibuat oleh pengguna atau aplikasi (tanpa peserta). - **shared**: Kalender bersama standar yang dibuat oleh pengguna atau aplikasi. |
| privilege | String | Informasi izin.   - **free_busy_reader**: Melihat status senggang/sibuk. - **title_reader**: Melihat judul. - **reader**: Melihat detail. - **writer**: Mengedit. - **owner**: Mengelola dan mengonfigurasi hubungan berbagi. |
