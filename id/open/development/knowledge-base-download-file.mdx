Panggil API ini untuk mendapatkan informasi unduhan file di Knowledge Base.

## Deskripsi panggilan API

Untuk mendapatkan informasi unduhan, ikuti langkah-langkah berikut:

Langkah 1: Panggil API ini untuk mendapatkan informasi unduhan file, termasuk URL unduhan dan header.

Langkah 2: Lakukan unduhan. Lihat contoh berikut:

```java
public static void main(String[] args) {
  String url = ""; // internalResourceUrls yang diperoleh dari API info unduhan.
  String path = "/Users/xxxxx/Downloads/test.txt"; // Jalur target untuk unduhan file.
  // Informasi header yang diperoleh dari API info unduhan.
  Map<String, String> headers = "" // Header yang diperoleh dari API info unduhan.
    OkHttpClient client = new OkHttpClient();
  Request request = new Request.Builder()
    .url(url)
    .headers(Headers.of(headers))
    .build();
  client.newCall(request).enqueue(new Callback() {
    @Override
    public void onFailure(Call call, IOException e) {
    }

    @Override
    public void onResponse(Call call, Response response) throws IOException {
      Sink sink = null;
      BufferedSink bufferedSink = null;
      try {
        File dest = new File(path);
        sink = Okio.sink(dest);
        bufferedSink = Okio.buffer(sink);
        bufferedSink.writeAll(response.body().source());
      } catch (Exception e) {
        e.printStackTrace();
      } finally {
        if (bufferedSink != null) {
          bufferedSink.close();
        }
        if (sink != null) {
          sink.close();
        }
      }
    }
  });
}
```

<Note>
Jika file terlalu besar dan Anda perlu mengambil sumber daya secara bersegmen, tambahkan header berikut pada contoh di atas: `headers.put("Range","bytes=0-499");`. Untuk detailnya, lihat [Mengunduh sebagian konten dengan menentukan Range](/id/open/development/use-range-download-a-part-of-content).
</Note>

## Permintaan

### Informasi dasar

| Bidang | Value |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/storage/spaces/{spaceId}/dentries/{dentryId}/downloadInfos/query` |
| Metode HTTP | POST |
| Jenis aplikasi yang didukung | appType-Aplikasi internal |
| Izin yang diperlukan | permission-Storage.DownloadInfo.Read-Izin baca untuk informasi unduhan file penyimpanan organisasi |

### Header permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Perolehnya dengan memanggil API [Mendapatkan access token aplikasi internal](/id/open/development/obtain-the-access-token-of-an-internal-app). |

### Parameter jalur

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| spaceId | String | Ya | ID ruang. Panggil API [Mendapatkan daftar node](/id/open/development/get-node-list) untuk memperoleh `dentryUuid` dari node Knowledge Base, lalu panggil API [Mendapatkan spaceId berdasarkan dentryUuid](/id/open/development/api-getdentryidbyuuid) untuk memperoleh `spaceId`. |
| dentryId | String | Ya | ID file. Panggil API [Mendapatkan daftar node](/id/open/development/get-node-list) untuk memperoleh `dentryUuid` dari node Knowledge Base, lalu panggil API [Mendapatkan spaceId berdasarkan dentryUuid](/id/open/development/api-getdentryidbyuuid) untuk memperoleh `dentryId`. |

### Parameter kueri

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| unionId | String | Ya | unionId dari operator. Perolehnya dengan memanggil API [Mengueri detail pengguna](/id/open/development/query-user-details). |

### Isi permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| option | Object | Tidak | Parameter opsional. |
| version | Long | Tidak | Versi file. Perolehnya dengan memanggil API [Mendapatkan daftar versi file](/id/open/development/obtains-a-list-of-file-versions). |
| preferIntranet | Boolean | Tidak | Apakah memprioritaskan transmisi intranet. Untuk menggunakan parameter ini, transmisi intranet penyimpanan khusus harus terkonfigurasi.   - **true** (default): Ya - **false**: Tidak |

## Respons

### Isi respons

| Nama | Tipe | Deskripsi |
| --- | --- | --- |
| protocol | String | Protokol unduhan file.   - **HEADER_SIGNATURE**: Permintaan tanda tangan header |
| headerSignatureInfo | Object | Informasi permintaan tanda tangan header.  **Catatan**  Bidang ini berlaku saat nilai bidang protocol adalah HEADER_SIGNATURE. |
| resourceUrls | Array of String | Beberapa URL unduhan. URL yang terdaftar lebih awal memiliki prioritas lebih tinggi. |
| headers | `Map<String, String>` | Informasi header permintaan. |
| expirationSeconds | Integer | Waktu kedaluwarsa, dalam detik. |
| region | String | Wilayah.   - **ZHANGJIAKOU**: Zhangjiakou - **SHENZHEN**: Shenzhen - **SHANGHAI**: Shanghai - **SINGAPORE**: Singapura - **UNKNOWN**: Tidak diketahui |
| internalResourceUrls | Array of String | URL intranet.  **Catatan**  Bidang ini saat ini tidak digunakan. Abaikan saja. |
