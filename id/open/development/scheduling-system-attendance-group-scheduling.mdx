Panggil API ini untuk menjadwalkan anggota grup absensi berbasis shift. Pastikan tipe grup absensi adalah **absensi berbasis shift**.

## Permintaan

| **Informasi dasar** | |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/topapi/attendance/group/schedule/async |
| Metode HTTP | POST |
| Tipe aplikasi yang didukung | appType-Aplikasi internal　appType-Aplikasi perusahaan pihak ketiga |
| Izin yang diperlukan | permission-qyapi_attendance_group_manage-Izin pengelolaan grup absensi |

### Parameter query

| Nama | Tipe | Wajib | Contoh | Deskripsi |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | bE74xxxx | Kredensial aplikasi yang digunakan untuk memanggil API ini.   - Untuk Aplikasi internal, panggil API [Mendapatkan access_token Aplikasi internal](/id/open/development/obtain-orgapp-token) untuk memperolehnya. - Untuk Aplikasi perusahaan pihak ketiga, panggil API untuk mendapatkan access_token organisasi pihak ketiga untuk memperolehnya. |

### Isi permintaan

| Nama | Tipe | Wajib | Contoh | Deskripsi |
| --- | --- | --- | --- | --- |
| op_user_id | String | Ya | user456 | ID pengguna operator. |
| group_id | Number | Ya | 2987 | ID grup absensi.  **Catatan**  Jika Anda menggunakan pengenal grup absensi lama group_key, panggil API [Mengonversi groupKey menjadi groupId](/id/open/development/convert-groupkey-to-groupid) untuk mengonversi group_key menjadi group_id. |
| schedules | TopScheduleParam[] | Ya |  | Detail penjadwalan shift. Contoh:   ``` &#123;   "is_rest": false,   "work_date": 1605150671000,   "shift_id": 1,   "userid": "user123" &#125; ```   **Catatan**  Panjang daftar maksimum adalah 200. |
| shift_id | Number | Ya | 1 | ID shift. Isi 1 untuk shift libur. Panggil API [Mendapatkan ringkasan shift](/id/open/development/enterprise-shift-query-in-batches) untuk memperoleh nilai id.  **Catatan**   - Jika is_rest bernilai true, isi shift_id dengan 1. - Untuk menghapus jadwal, isi shift_id dengan -2. |
| work_date | Number | Ya | 1564985177000 | Tanggal penjadwalan shift.  **Catatan**  Tanggal tidak boleh lebih awal dari 180 hari yang lalu dan tidak boleh lebih lambat dari 180 hari dari sekarang. |
| is_rest | Boolean | Tidak | false | Menentukan apakah hari tersebut merupakan hari libur:   - **true**: Hari libur  **Catatan**  Jika parameter ini bernilai true, isi shift_id dengan 1. - **false**: Bukan hari libur |
| userid | String | Ya | user123 | ID pengguna dari pengguna. |

### Contoh permintaan

```curl
curl -X POST "https://api.dingtalk.io/topapi/attendance/group/schedule/async" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=d64b3xxxx57b23' \
-d 'group_id=2987' \
-d 'op_user_id=dd_test' \
-d 'schedules=null'
```

Java

```java
DingTalkClient client = new DefaultDingTalkClient("https://api.dingtalk.io/topapi/attendance/group/schedule/async");
OapiAttendanceGroupScheduleAsyncRequest req = new OapiAttendanceGroupScheduleAsyncRequest();
req.setOpUserId("user456");
req.setGroupId(2987L);
List<TopScheduleParam> list2 = new ArrayList<TopScheduleParam>();
TopScheduleParam obj3 = new TopScheduleParam();
obj3.setShiftId(1L);
obj3.setWorkDate(1564985177000L);
obj3.setIsRest(false);
obj3.setUserid("user123");
list2.add(obj3);
req.setSchedules(list2);
OapiAttendanceGroupScheduleAsyncResponse rsp = client.execute(req, access_token);
System.out.println(rsp.getBody());
```

## Respons

### Isi respons

| Nama | Tipe | Contoh | Deskripsi |
| --- | --- | --- | --- |
| success | Boolean | true | Menunjukkan apakah permintaan berhasil.   - **true**: Berhasil - **false**: Gagal |
| errcode | Number | 0 | Kode respons. |
| errmsg | String | ok | Deskripsi kode respons. |
| request_id | String | zpd0i7dlr7bi | ID permintaan. |

### Contoh isi respons

```json
{
  "errcode":0,
  "errmsg":"ok",
  "success":true,
  "request_id":"zpd0i7dlr7bi"
}
```

Jika panggilan API mengembalikan error, cari solusinya di dokumen [Kode error global](/id/open/development/server-api-error-codes-1) berdasarkan pesan error.
