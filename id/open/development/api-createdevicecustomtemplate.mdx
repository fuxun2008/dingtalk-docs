Panggil API ini untuk membuat templat layar kustom berdasarkan nama templat.

## Permintaan

### Informasi dasar

| Bidang | Nilai |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/v1.0/rooms/devices/screens/templates |
| Metode HTTP | POST |
| Tipe aplikasi yang didukung | appType-Aplikasi internal　appType-Aplikasi perusahaan pihak ketiga |
| Izin yang diperlukan | permission-Rooms.DeviceTemplate.Write-Izin tulis untuk layar kustom Ruang Rapat DingTalk |

### Header permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial API. Panggil API [Dapatkan token pengguna](/id/open/development/obtain-user-token#) untuk memperolehnya. Saat menyusun tautan untuk memperoleh parameter `code` yang digunakan dalam permintaan mendapatkan token pengguna, `scope` harus mencakup ID pengguna dan ID organisasi, yaitu `scope=openid corpid`. |

### Isi permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| templateName | String | Ya | Nama templat. |
| logo | String | Tidak | Logo templat. Panggil API [Unggah file media](/id/open/development/upload-media-files#) untuk memperoleh mediaId setelah mengunggah gambar. Ukuran gambar: 240\*240. Ukuran satu gambar tidak boleh melebihi 1 MB. |
| orgName | String | Tidak | Nama organisasi yang ditampilkan pada templat. |
| customDoc | String | Tidak | Konten teks kustom templat. |
| bgUrl | String | Tidak | URL latar belakang kustom templat. |
| bgImgList | Array of String | Tidak | mediaId gambar. Panggil API [Unggah file media](/id/open/development/upload-media-files#) untuk memperolehnya. Anda dapat mengunggah hingga 9 gambar, dan ukuran setiap gambar tidak boleh melebihi 5 MB. |
| instruction | Boolean | Tidak | Apakah akan menampilkan instruksi:   - **true**: Tampilkan - **false**: Jangan tampilkan |
| bgType | Integer | Tidak | Tipe latar belakang kustom templat:   - **1**: Gambar - **2**: URL |
| isPicTop | Integer | Tidak | Apakah akan menampilkan bilah informasi Beranda:   - **0**: Tampilkan - **1**: Jangan tampilkan |
| hideServerCodeWhenProjecting | Boolean | Tidak | Apakah akan menyembunyikan kode casting selama casting layar:   - **true**: Sembunyikan - **false**: Jangan sembunyikan |
| showCalendarTitle | Boolean | Tidak | Apakah akan menampilkan judul acara pada kartu acara:   - **true**: Tampilkan - **false**: Jangan tampilkan |
| desensitizeUserName | Boolean | Tidak | Apakah akan menyamarkan nama pemesan pada kartu acara:   - **true**: Samarkan - **false**: Jangan samarkan |
| picturePlayInterval | Integer | Tidak | Interval carousel gambar latar belakang kustom, dalam detik. |
| showCalendarCard | Boolean | Tidak | Apakah akan menampilkan kartu acara:   - **true**: Tampilkan - **false**: Jangan tampilkan |
| showFunctionCard | Boolean | Tidak | Apakah akan menampilkan kartu fungsi:   - **true**: Tampilkan - **false**: Jangan tampilkan |
| deviceUnionIds | Array of String | Tidak | unionId perangkat. Peroleh parameter ini dengan berlangganan acara [Perubahan pengikatan perangkat-ruang](https://open.dingtalk.com/document/development/org-event-overview#). |
| groupIds | Array of Long | Tidak | ID grup. Panggil API [Kueri daftar grup ruang rapat](/id/open/development/query-meeting-rooms-groups#) untuk memperolehnya. |
| roomIds | Array of String | Tidak | ID ruang. Panggil API [Kueri daftar ruang rapat](/id/open/development/check-the-meeting-room-list#) untuk memperolehnya. |
