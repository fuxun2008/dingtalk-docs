---
title: "Mengatur admin grup secara massal"
description: "Panggil API ini untuk menetapkan atau mencabut peran admin bagi pengguna dalam obrolan grup perusahaan secara massal, cocok untuk grup besar atau restrukturisasi organisasi."
---

Panggil API ini untuk menetapkan beberapa pengguna dalam obrolan grup organisasi sebagai admin secara massal, atau untuk mencabut peran admin dari beberapa pengguna secara massal. API ini cocok untuk skenario ketika obrolan grup organisasi berukuran besar dan admin perlu disesuaikan secara massal untuk meningkatkan efisiensi pengelolaan, atau ketika struktur organisasi disesuaikan dan admin grup perlu ditetapkan ulang.

## Izin

Untuk memanggil API ini, salah satu izin berikut diperlukan.

| Jenis aplikasi | Didukung | Izin | Debugging API Explorer |
| --- | --- | --- | --- |
| Aplikasi internal | Didukung | Izin untuk mengelola informasi dasar tentang grup DingTalk | [API Explorer](https://open-dev.dingtalk.io/apiExplorer#/?devType=org&api=im_1.0%23ChatSubAdminUpdate) |
| Aplikasi perusahaan pihak ketiga | Tidak didukung | Tidak didukung | Tidak didukung |
| Aplikasi personal pihak ketiga | Tidak didukung | Tidak didukung | Tidak didukung |

## Metode HTTP

```http
POST /v1.0/im/subAdministrators HTTP/1.1
Host:api.dingtalk.io
x-acs-dingtalk-access-token:String
Content-Type:application/json

{
  "openConversationId" : "String",
  "userIds" : [ "String" ],
  "role" : Integer
}
```

## Parameter header

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Untuk mendapatkannya, panggil API [Mendapatkan access token aplikasi internal](/id/open/development/obtain-the-access-token-of-an-internal-app). |

## Parameter body

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| openConversationId | String | Ya | ID grup terbuka. Untuk mendapatkan nilai `openConversationId`, panggil API [Membuat obrolan grup](/id/open/development/create-common-group-new-version-v2). |
| userIds | Array of String | Ya | Daftar nilai `userid` karyawan dalam organisasi. Untuk mendapatkan nilai `userid_list`, panggil API [Menanyakan daftar ID pengguna departemen](/id/open/development/query-the-list-of-department-userids). |
| role | Integer | Ya | Tipe operasi. Nilai yang valid:   - **2**: Tambahkan sebagai admin. - **3**: Hapus dari admin. |

## Parameter respons

| Nama | Tipe | Deskripsi |
| --- | --- | --- |
| success | String | Apakah panggilan berhasil:   - **true**: Berhasil. - **false**: Gagal. |
