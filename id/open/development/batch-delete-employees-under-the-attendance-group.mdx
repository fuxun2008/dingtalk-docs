Panggil API ini untuk menghapus anggota dari grup absensi tertentu secara massal.

## Deskripsi panggilan API

API ini hanya menghapus anggota absensi dalam grup absensi. API ini tidak menghapus departemen yang berpartisipasi dalam absensi.

## Permintaan

| **Informasi dasar** | |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/topapi/attendance/group/users/remove |
| Metode HTTP | POST |
| Tipe aplikasi yang didukung | appType-Aplikasi internal |
| Izin | permission-qyapi_attendance_group_manage-Izin kelola grup absensi |

### Parameter query

| Nama | Tipe | Wajib | Contoh | Deskripsi |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | 4c9ebd2b153xxxx | Kredensial aplikasi yang digunakan untuk memanggil API ini. Dapatkan dengan memanggil API [Dapatkan access_token Aplikasi internal](/id/open/development/obtain-orgapp-token). |

### Isi permintaan

| Nama | Tipe | Wajib | Contoh | Deskripsi |
| --- | --- | --- | --- | --- |
| op_userid | String | Tidak | user01 | userId operator. |
| group_key | String | Ya | 0151E0223B1xxxx | ID grup absensi.  **Catatan**  Jika pengidentifikasi grup absensi Anda adalah group_id, panggil API [Konversi groupId ke groupKey](/id/open/development/groupid-to-groupkey) untuk mengonversi group_id menjadi group_key. |
| user_id_list | String[] | Ya | user01,user02 | Daftar pengguna. Maksimal 100 userId per panggilan. |

### Contoh permintaan

```curl
curl -X POST "https://api.dingtalk.io/topapi/attendance/group/users/remove" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=49ceexxxx4c192' \
-d 'group_key=0151E022xxxx917E876' \
-d 'op_userid=123456' \
-d 'user_id_list=123456%2C123457'
```

## Respons

### Isi respons

| Nama | Tipe | Contoh | Deskripsi |
| --- | --- | --- | --- |
| result | Result |  | Hasil yang dikembalikan. |
| error_info_list | ErrorInfo[] |  | Daftar error. |
| failure_list | String[] |  | Daftar item yang gagal. |
| msg | String | business fault | Deskripsi error. |
| code | String | 1000 | Kode error. |
| success_list | String[] |  | Daftar item yang berhasil. |
| errcode | Number | 0 | Kode pengembalian. |
| errmsg | String | ok | Deskripsi kode pengembalian. |
| success | Boolean | true | Menunjukkan apakah panggilan berhasil.   - **true**: Berhasil - **false**: Gagal |
| request_id | String | 47qflcctatn2 | ID permintaan. |

### Contoh isi respons

```json
{
  "errcode": 0,
  "errmsg":"ok",
  "result": {
    "success_list": [
      "user01",
      "user02"
    ]
  },
  "success": true,
  "request_id": "47qflcctatn2"
}
```

### Kode error

Jika panggilan API mengembalikan error, cari solusinya di dokumen [Kode error global](/id/open/development/server-api-error-codes-1) berdasarkan pesan error.
