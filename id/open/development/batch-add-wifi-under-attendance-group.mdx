Panggil API ini untuk menambahkan informasi Wi-Fi secara massal ke grup absensi tertentu.

## Permintaan

| **Informasi dasar** | |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/topapi/attendance/group/wifis/add |
| Metode HTTP | POST |
| Jenis aplikasi yang didukung | appType-Aplikasi internal |
| Izin | permission-qyapi_attendance_group_manage-Izin pengelolaan grup absensi |

### Parameter query

| Nama | Tipe | Wajib | Contoh | Deskripsi |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | 1eb68xxx | Kredensial aplikasi yang digunakan untuk memanggil API ini. Dapatkan dengan memanggil [Mendapatkan access_token Aplikasi internal](/id/open/development/obtain-orgapp-token). |

### Isi permintaan

| Nama | Tipe | Wajib | Contoh | Deskripsi |
| --- | --- | --- | --- | --- |
| op_userid | String | Tidak | user01 | ID pengguna operator. |
| group_key | String | Ya | 0151E0xxx | ID grup absensi.  **Catatan**  Jika pengenal grup absensi Anda berupa group_id, panggil [Mengonversi groupId menjadi groupKey](/id/open/development/groupid-to-groupkey) untuk mengonversi group_id menjadi group_key. |
| wifi_list | Wifi[] | Ya |  | Daftar Wi-Fi. Tambahkan hingga 100 entri Wi-Fi per panggilan. |
| foreign_id | String | Ya | office-wifi | ID Wi-Fi dari sisi bisnis. |
| mac_addr | String | Ya | 11:11:11:11:11:11 | Alamat MAC. |
| ssid | String | Ya | office-wifi-1 | Nama Wi-Fi. |

### Contoh permintaan

```curl
curl -X POST "https://api.dingtalk.io/topapi/attendance/group/wifis/add" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=b040xxxx34a60' \
-d 'group_key=0151E02xxxx17E876' \
-d 'op_userid=123456' \
-d 'wifi_list=null'
```

## Respons

### Isi respons

| Nama | Tipe | Contoh | Deskripsi |
| --- | --- | --- | --- |
| result | DingOpenResult |  | Informasi yang dikembalikan. |
| result | Result |  | Hasil penambahan Wi-Fi. |
| error_info_list | ErrorInfo[] |  | Daftar entri Wi-Fi yang gagal ditambahkan. |
| failure_list | Wifi[] |  | Daftar kegagalan. |
| foreign_id | String | alibaba-guest | ID Wi-Fi dari sisi bisnis. |
| mac_addr | String | 02:10:18:11:11:11 | Alamat MAC. |
| ssid | String | alibaba-guest1 | Nama MAC. |
| wifi_key | String | 01xxxxE876 | Key entri Wi-Fi yang gagal ditambahkan. |
| msg | String | business fault | Deskripsi error. |
| code | String | 1000 | Kode error. |
| success_list | Wifi[] |  | Daftar entri Wi-Fi yang berhasil ditambahkan. |
| foreign_id | String | office-wifi | ID Wi-Fi dari sisi bisnis. |
| mac_addr | String | 11:11:11:11:11:11 | Alamat MAC. |
| ssid | String | office-wifi-1 | Nama MAC. |
| wifi_key | String | 01xxxxE876 | Key entri Wi-Fi yang berhasil ditambahkan. |
| errcode | Number | 0 | Kode pengembalian. |
| errmsg | String | ok | Deskripsi kode pengembalian. |
| success | Boolean | true | Menunjukkan apakah panggilan berhasil.   - **true**: Berhasil - **false**: Gagal |
| request_id | String | wicoxqraqt0g | ID permintaan. |
