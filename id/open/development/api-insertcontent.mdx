Panggil API ini untuk menyisipkan sepotong konten pada lokasi tertentu dalam sebuah dokumen. Tipe konten mendukung Markdown.

## Deskripsi panggilan API

Lokasi penyisipan dapat berupa `children` dari node root dokumen, atau children dari sebuah `BlockElement` yang mendukung penyisipan elemen blok (seperti blok sorot atau Tabel). Lokasi penyisipan ditentukan oleh parameter `path` dan `index` secara bersamaan.

## Permintaan

### Informasi dasar

| Bidang | Nilai |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/doc/suites/documents/{documentId}/content` |
| Metode HTTP | POST |
| Jenis aplikasi yang didukung | appType-Aplikasi internal |
| Izin yang diperlukan | permission-Storage.File.Write-Izin tulis file penyimpanan organisasi |

### Header permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Peroleh dengan memanggil API [Memperoleh access token aplikasi internal](/id/open/development/obtain-the-access-token-of-an-internal-app). |

### Parameter jalur

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| documentId | String | Ya | ID Dokumen (docKey atau dentryUuid dokumen). Setelah membuat dokumen dengan memanggil API [Membuat dokumen knowledge base](/id/open/development/create-team-space-document), peroleh parameter `docKey` dari respons. Peroleh `dentryUuid` dari URL dokumen. Misalnya, pada https://docs.dingtalk.io/i/nodes/Zxxxxa-id, dentryUuid-nya adalah Zxxxxa-id. |

### Parameter kueri

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| operatorId | String | Ya | unionId pengguna. Peroleh nilai parameter unionid dengan memanggil API [Kueri detail pengguna](/id/open/development/query-user-details). |

### Isi permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| path | Array of Integer | Tidak | Lokasi penyisipan. |
| index | Integer | Tidak | Lokasi penyisipan. |
| content | Object | Ya | Konten yang akan disisipkan. |
| type | String | Ya | Tipe konten yang akan disisipkan. Saat ini hanya `markdown` yang didukung. |
| content | String | Ya | Teks konten yang akan disisipkan. |

### Contoh permintaan

HTTP

```http
POST /v1.0/doc/suites/documents/doc_id/content?operatorId=union_id HTTP/1.1
Host:api.dingtalk.io
x-acs-dingtalk-access-token:access_token
Content-Type:application/json

{
  "content" : {
    "content" : "## Heading",
    "type" : "markdown"
  }
}
```
