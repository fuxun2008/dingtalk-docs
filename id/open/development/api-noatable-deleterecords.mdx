Panggil API ini untuk menghapus beberapa rekaman dari sebuah tabel.

## Permintaan

### Informasi dasar

| Bidang | Nilai |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/notable/bases/{baseId}/sheets/{sheetIdOrName}/records/delete` |
| Metode HTTP | POST |
| Jenis aplikasi yang didukung | appType-Internal app |
| Izin | permission-Notable.Base.Write.All-AI Table app write permission |

### Header permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Dapatkan dengan memanggil API [Mendapatkan access token aplikasi internal](/id/open/development/obtain-the-access-token-of-an-internal-app#). |

### Parameter path

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| baseId | String | Ya | ID AI Table. Untuk cara mendapatkannya, lihat [Struktur data](/id/open/development/data-structure#). |
| sheetIdOrName | String | Ya | ID tabel atau nama tabel. Dapatkan ID tabel dengan salah satu cara berikut:   - Panggil API [Mendapatkan semua tabel](/id/open/development/api-notable-getallsheets#). - Panggil API [Mendapatkan sebuah tabel](/id/open/development/api-notable-getsheet#). |

### Parameter query

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| operatorId | String | Ya | unionId operator. Dapatkan dengan salah satu cara berikut:   - Panggil API [Mengambil detail pengguna](/id/open/development/query-user-details#). - Panggil API [Mendapatkan informasi pengguna melalui kode login senyap](/id/open/development/obtain-the-userid-of-a-user-by-using-the-log-free#). |

### Isi permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| recordIds | Array of String | Ya | ID rekaman. Dapatkan dengan salah satu cara berikut:   - Panggil API [Menambahkan rekaman](/id/open/development/api-notable-insertrecords#). - Panggil API [Menampilkan beberapa rekaman](/id/open/development/api-notable-listrecords#). |

```http

Host:api.dingtalk.io
```
