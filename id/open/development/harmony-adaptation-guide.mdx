Dokumen ini memandu Anda memanggil DingTalk JSAPI di HarmonyOS.

## **Langkah 1:** Upgrade SDK ke versi terbaru

Untuk memanggil JSAPI dari halaman web di HarmonyOS, upgrade [dingtalk-jsapi](https://www.npmjs.com/package/dingtalk-jsapi) ke versi terbaru (3.0.45+).

### **npm**

```
npm install dingtalk-jsapi@latest --save
```

### **yarn**

```
yarn upgrade dingtalk-jsapi --latest
```

### **pnpm**

```
pnpm update dingtalk-jsapi --latest
```

Jika paket npm yang menjadi dependensi proyek Anda bergantung pada versi lama [dingtalk-jsapi](https://www.npmjs.com/package/dingtalk-jsapi), upgrade ke versi terbaru. Gunakan konfigurasi seperti `overrides` atau `resolutions` di `package.json` untuk memaksa versi dingtalk-jsapi.

### **npm**

```
{
  "overrides": {
    "dingtalk-jsapi": "^3.0.45"
  }
}
```

### **yarn**

```
{
  "resolutions": {
    "dingtalk-jsapi": "^3.0.45"
  }
}
```

### **pnpm**

```
{
  "pnpm": {
    "overrides": {
      "dingtalk-jsapi": "^3.0.45"
    }
  }
}
```

## **Langkah 2: Periksa kompatibilitas JSAPI**

Konfirmasikan bahwa JSAPI yang menjadi dependensi proyek Anda didukung di HarmonyOS. Untuk detail dukungan, lihat bagian "**Support Notes**" pada dokumentasi JSAPI di Open Platform. Untuk JSAPI Sisi klien, lihat Ikhtisar JSAPI.

## **Langkah 3: Adaptasikan logika khusus klien**

Anda perlu menentukan apakah sistem operasi pengguna adalah HarmonyOS. Ada tiga metode:

### **Metode 1**

Gunakan SDK dingtalk-jsapi untuk menentukan apakah sistemnya adalah HarmonyOS.

```
import { env } from 'dingtalk-jsapi/core';
import { ENV_ENUM } from 'dingtalk-jsapi/lib/env';

const isHarmony = env.platform === ENV_ENUM.harmony;
```

### **Metode 2**

Pada halaman web, gunakan `navigator.userAgent` untuk menentukan apakah sistemnya adalah HarmonyOS.

```
// Menentukan apakah sistemnya adalah HarmonyOS melalui navigator.userAgent pada halaman web

const isHarmony = /OpenHarmony/i.test(navigator.userAgent)
```

### **Metode 3**

Dalam mini program, baca bidang `platform` dari `getSystemInfo` untuk menentukan apakah sistemnya adalah HarmonyOS.

```
// Dalam mini program, baca bidang platform dari getSystemInfo untuk menentukan apakah sistemnya adalah HarmonyOS.
const systemInfo = dd.getSystemInfoSync();
const isHarmony = systemInfo.platform === 'OpenHarmony';
```

Jika logika bisnis Anda menyertakan penanganan khusus untuk platform tertentu, konfirmasikan apakah logika tersebut kompatibel dengan HarmonyOS.

Ambil contoh logika khusus klien berikut. Ketika logika khusus klien serupa muncul, konfirmasikan kompatibilitasnya dengan HarmonyOS.

```
import { env } from 'dingtalk-jsapi/core';
import { ENV_ENUM } from 'dingtalk-jsapi/lib/env';

switch (env.platform) {
  case ENV_ENUM.android: {
    // Logika khusus untuk klien Android
    // ...
    break;
  }
  case ENV_ENUM.ios: {
    // Logika khusus untuk klien iOS
    // ...
    break;
  }
  default: {
    // Logika khusus untuk jenis klien lainnya

    // PERHATIAN! PERHATIAN! PERHATIAN!!!
    // Konfirmasikan di sini apakah klien HarmonyOS didukung.

    
    // ...
    
    break;
  }
}
```

## **Langkah 4:** Verifikasi pada perangkat fisik

Setelah kode diadaptasi sesuai kebutuhan, jalankan pada perangkat HarmonyOS untuk memastikan kode berfungsi sebagaimana mestinya.

1. Unduh dan instal versi terbaru [Klien HarmonyOS DingTalk](https://www.dingtalk.com/download#/).
2. Debug logika kode terkait sebagai berikut:

   |  |  |
   | --- | --- |
   | **Jenis aplikasi** | **Deskripsi** |
   | Aplikasi web (Aplikasi mikro) | Debug pada klien HarmonyOS menggunakan Alat Debugging Empat Terminal Aplikasi Mikro. |
   | Mini program | **Pratinjau Perangkat Fisik**  Debug menggunakan "Pratinjau" di Mini Program Developer Tools.      **Debugging Perangkat Fisik**  - Langkah 1: Upgrade klien DingTalk ke versi **7.6.30**+. - Langkah 2: Aktifkan kemampuan "Debugging Perangkat Fisik" untuk mini program HarmonyOS di "Menu" pada Mini Program Developer Tools.   1. Buka "Bantuan" > "Konfigurasi Lokal", masukkan konfigurasi berikut, simpan, lalu mulai ulang:      ```    &#123;      "DD_PROJECT_100": [        &#123;          "keyPath": "enableRemoteX",          "priority": 1000,          "value": true        &#125;,        &#123;          "keyPath": "supportsAppxNG",          "priority": 1000,          "value": true        &#125;      ]    &#125;    ```      2. Klik "Debugging Perangkat Fisik" dan tunggu hingga mini program selesai dikompilasi serta menghasilkan Kode QR debugging. Gunakan "Pindai" DingTalk untuk memindai kode dan mulai debugging. 3. Tampilkan hasilnya pada perangkat fisik. |
   |  |  |

## **Langkah 5: Aktifkan sakelar adaptasi HarmonyOS dan terbitkan ulang**

1. Setelah adaptasi aplikasi selesai, klik aplikasi terkait untuk membuka halaman detailnya.

   > Jika Anda belum membuat aplikasi, lihat dokumen [Buat Aplikasi](/id/open/dingstart/create-application) untuk detailnya.
2. Klik **Informasi Dasar** > **Kredensial dan Informasi Dasar**. Pada modul **Sistem Operasi**, aktifkan sakelar "HarmonyOS".

3. Setelah mengaktifkan sakelar "HarmonyOS", klik **Rilis Aplikasi** > **Manajemen dan Rilis Versi**. Pada halaman rilis, buat versi baru dan selesaikan rilisnya.

## **FAQ (Tanya Jawab)**

### **Error: [DINGTALK-JSAPI] ERROR 4040: Do not support the current environment: 'notinDingTalk'**

Jawaban: Hal ini terjadi karena dingtalk-jsapi belum di-upgrade ke versi terbaru, dan versi lama tidak mengenali klien HarmonyOS. Upgrade dingtalk-jsapi ke versi terbaru untuk mengatasinya.
