Dokumen ini membantu Anda memahami beragam kemampuan aplikasi DingTalk, termasuk mini program, aplikasi web, Cool App, dan Bot.

## **Mini program**

Mini program adalah aplikasi ringan yang digunakan di dalam DingTalk. Mini program mendukung berbagai skenario seperti kerja kantor kolaboratif, manajemen sumber daya manusia, layanan perusahaan, dan proses bisnis.

Dibandingkan dengan aplikasi web, model pengembangan mini program DingTalk mengadopsi framework pengembangan yang mirip dengan React Native dan Weex. Hal ini memungkinkan Anda menulis pengalaman berperforma setingkat Native dengan sintaks front-end yang ringkas, serta mendukung penerapan pada berbagai platform seperti iOS dan Android.

## **Aplikasi web**

Aplikasi web adalah aplikasi ringan yang dikembangkan dengan teknologi web. Aplikasi ini dapat memanggil beragam kemampuan kontrol native untuk membantu Anda mengakses kemampuan sistem ponsel secara efisien, seperti informasi perangkat dasar dan lokasi. Aplikasi web juga dapat langsung menggunakan kemampuan khusus DingTalk seperti Scan, Bagikan, dan Drive, sehingga memberi aplikasi mikro pengalaman yang mendekati kode native.

## **Cool App**

Cool App menampilkan logika aplikasi yang kompleks kepada pengguna melalui interaksi berbasis kartu dalam skenario seperti grup, dokumen, dan audio/video, sehingga memungkinkan akses yang cepat.

## **Bot**

Bot adalah kemampuan aplikasi mandiri. Bot siap digunakan langsung dan juga mendukung pengembangan lanjutan. Bot tidak perlu terikat erat dengan aplikasi atau skenario lain seperti grup. Dengan konfigurasi sederhana, gunakan Bot untuk menyampaikan informasi dan tugas bisnis demi kolaborasi yang gesit dalam skenario obrolan DingTalk.

## **Perbedaan antara mini program dan aplikasi web**

Perbedaan antara mini program dan aplikasi web adalah sebagai berikut:

|  |  |  |
| --- | --- | --- |
| **Item Perbandingan** | **Mini Program** | **Aplikasi Mikro H5** |
| **Platform yang Didukung** | Mendukung perangkat seluler dan PC   - Android - iOS - Windows - Mac | Mendukung perangkat seluler dan PC   - Android - iOS - Windows - Mac |
| **Performa Pemuatan** | Sedikit lambat saat pertama kali digunakan, cepat pada pemuatan berikutnya | Dipengaruhi banyak faktor, kurang optimal, dan cenderung lambat |
| **Performa Runtime** | Mulus, mendekati Native | Cenderung tersendat |
| **Navigasi/Peralihan Halaman** | Efek sama seperti Native | Tidak dapat mencapai efek Native |
| **Penyiapan Lingkungan Pengembangan** | Menyediakan DingTalk Developer Tools untuk pembuatan proyek yang cepat | Menyediakan DingTalk Developer Tools untuk pembuatan proyek yang cepat |
| **Debug** | Menyediakan DingTalk Developer Tools yang memungkinkan Anda men-debug sebagian besar fitur di komputer | Di komputer, Anda hanya dapat men-debug UI. Segala hal yang melibatkan DingTalk JSAPI harus di-debug pada perangkat nyata |
| **Menggunakan Komponen UI Sumber Terbuka** | Saat ini tidak didukung | Didukung |
| **Menggunakan Paket NPM** | Didukung | Didukung |
| **Organisasi Kode Modular** | Mendukung modularisasi khusus mini program | Framework seperti Vue dan React menyediakan dukungan modularisasi |
| **Gray Release** | Disediakan oleh DingTalk | Harus diimplementasikan oleh pengembang |
| **CDN** | Paket mini program berada di CDN secara default | Pengembang harus membeli sendiri layanan terkait |
| **Mengembangkan Aplikasi Pribadi** | Didukung | Tidak didukung |
| **Dukungan Aplikasi Offline** | Didukung | Didukung |
