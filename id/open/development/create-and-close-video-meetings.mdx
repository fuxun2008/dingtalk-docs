description: "Pelajari alur lengkap penggunaan Aplikasi internal untuk memanggil API rapat guna membuat, mengkueri massal, dan menutup Rapat Video di DingTalk — mencakup kredensial aplikasi, izin API, dan pengambilan accessToken."
---

Dokumen ini menjelaskan cara memanggil API rapat untuk membuat Rapat Video dan melakukan operasi terkait. Pertama, buat Aplikasi internal, lalu gunakan API rapat untuk membuat Rapat Video, menutup Rapat Video, dan mengkueri informasi Rapat Video secara massal.

## Ikhtisar proses

Prasyarat: Selesaikan proses [pembuatan dan konfigurasi aplikasi](/id/open/dingstart/create-application).

Langkah 1: Peroleh kredensial aplikasi untuk mendapatkan client ID dan Client Secret.

Langkah 2: Ajukan izin API untuk API terkait rapat.

Langkah 3: Peroleh kredensial akses aplikasi dengan mengikuti [Memperoleh access token Aplikasi internal](/id/open/development/obtain-the-access-token-of-an-internal-app). Access token digunakan untuk mengautentikasi pemanggil saat memanggil API.

Langkah 4: Panggil Server API terkait rapat.

1. Panggil Server API [Membuat Rapat Video](/id/open/development/create-a-video-conference) untuk membuat Rapat Video dan memperoleh `conferenceId` rapat.
2. Berdasarkan `conferenceId`, panggil Server API [Kueri massal informasi Rapat Video](/id/open/development/batch-query-of-video-conference-information) untuk memperoleh informasi rapat dan daftar anggota.
3. Berdasarkan `conferenceId`, panggil Server API [Memulai perekaman cloud untuk Rapat Video](/id/open/development/video-conference-open-cloud-recording) untuk memulai perekaman cloud.
4. Berdasarkan `conferenceId`, panggil Server API [Memulai perekaman cloud untuk Rapat Video](/id/open/development/video-conference-open-cloud-recording) untuk menghentikan perekaman cloud.
5. Berdasarkan `conferenceId`, panggil Server API [Menutup Rapat Video](/id/open/development/close-audio-video-conference) untuk menutup rapat.
6. Kueri informasi rekaman rapat.

   1. Berdasarkan `conferenceId`, panggil Server API [Kueri detail rekaman rapat](/id/open/development/query-recording-information) untuk mengambil informasi seperti perekam, waktu mulai perekaman, dan durasi perekaman.
   2. Berdasarkan `conferenceId`, panggil Server API [Kueri informasi video rekaman rapat](/id/open/development/queries-the-playback-information-about-a-recorded-cloud-video) untuk mengambil informasi seperti URL unduh video, ukuran file video, dan durasi video.
   3. Berdasarkan `conferenceId`, panggil Server API [Kueri informasi teks rekaman rapat](/id/open/development/queries-the-text-information-about-cloud-recording) untuk mengambil informasi seperti konten teks yang direkam, waktu mulai rekaman teks, dan waktu akhir rekaman teks.

## Prasyarat

Selesaikan proses [pembuatan dan konfigurasi aplikasi](/id/open/dingstart/create-application).

## Langkah 1: Peroleh kredensial aplikasi

1. Pilih aplikasi target untuk membuka halaman detail aplikasi, lalu klik **Basic information** > **Credentials and basic information**.
2. Peroleh client ID dan Client Secret.

## Langkah 2: Tambahkan izin API

Klik **Development configuration** > **Kelola izin**. Di kotak pencarian izin, masukkan `VideoConference.Conference.Write` dan `VideoConference.Conference.Read` secara berurutan, lalu ajukan izin.

## Langkah 3: Peroleh access token aplikasi

<Warning>
Untuk perbedaan antara Server API, lihat API lama vs. API Baru. Semua API berikut menggunakan Server API. Untuk mengunduh SDK, lihat Unduh SDK Sisi server.
</Warning>

Dengan menggunakan client ID dan Client Secret dari Langkah 1, peroleh access token aplikasi dengan mengikuti [Memperoleh access token Aplikasi internal](/id/open/development/obtain-the-access-token-of-an-internal-app).

