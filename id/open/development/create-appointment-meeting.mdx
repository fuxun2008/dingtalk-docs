Buat rapat terjadwal berdasarkan informasi seperti pembuat, judul rapat terjadwal, serta waktu mulai dan selesai.

## Permintaan

### Informasi dasar

| Bidang | Nilai |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/v1.0/conference/scheduleConferences |
| Metode HTTP | POST |
| Jenis aplikasi yang didukung | appType-Aplikasi internal　appType-Aplikasi perusahaan pihak ketiga |
| Izin yang wajib | permission-VideoConference.Conference.Write-Izin pengelolaan informasi Rapat Video |

### Header permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses yang digunakan untuk memanggil API:   - Untuk Aplikasi internal, panggil API [Dapatkan access token aplikasi internal](/id/open/development/obtain-the-access-token-of-an-internal-app) untuk memperolehnya. - Untuk Aplikasi perusahaan pihak ketiga, panggil API [Dapatkan access token organisasi yang diberi otorisasi ke aplikasi pihak ketiga](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1) untuk memperolehnya. |

### Isi permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| creatorUnionId | String | Ya | unionId dari pembuat. |
| title | String | Ya | Judul rapat terjadwal. Panjang maksimum 50 karakter. Judul yang lebih dari 50 karakter akan dipotong. Judul yang lebih dari 256 karakter menyebabkan panggilan API gagal. |
| startTime | Long | Ya | Waktu mulai rapat terjadwal, berupa stempel waktu UTC dalam milidetik. |
| endTime | Long | Ya | Waktu selesai rapat terjadwal, berupa stempel waktu UTC dalam milidetik. |
| scheduleConfSettingModel | Object | Tidak | Pengaturan rapat terjadwal. |
| hostUnionId | String | Tidak | unionId dari Tuan Rumah. |
| confAllowedCorpId | String | Tidak | ID organisasi untuk rapat internal. |
| lockRoom | Integer | Tidak | Kunci rapat:   - **0**: Buka kunci - **1**: Kunci |
| screenShareForbidden | Integer | Tidak | Mulai berbagi:   - **0**: Izinkan berbagi - **1**: Larang berbagi |
| muteOnJoin | Integer | Tidak | Bisukan pengguna saat mereka Gabung ke konferensi:   - **-1**: Aktif - **0**: Nonaktif - **6**: Bisukan otomatis saat lebih dari 6 pengguna bergabung |
| moziConfVirtualExtraSetting | Object | Tidak | Pengaturan rapat terjadwal. |
| waitingRoom | Integer | Tidak | Ruang tunggu:   - **1**: Aktif - **2**: Nonaktif |
| joinBeforeHost | Integer | Tidak | Izinkan pengguna Gabung ke konferensi sebelum Tuan Rumah:   - **0**: Nonaktif - **1**: Aktif |
| enableChat | Integer | Tidak | Obrolan dan Interaksi:   - **0**: Nonaktif - **1**: Aktif |
| lockNick | Integer | Tidak | Izinkan pengguna mengganti nama sendiri:   - **0**: Izinkan pengguna mengganti nama sendiri - **1**: Larang pengguna mengganti nama sendiri |
| lockMediaStatusMicMute | Integer | Tidak | Izinkan pengguna membunyikan mikrofon sendiri:   - **0**: Izinkan pengguna membunyikan mikrofon sendiri - **1**: Larang pengguna membunyikan mikrofon sendiri |
| moziConfExtensionAppSettings | Array | Tidak | Daftar pengaturan Aplikasi ekstensi Rapat. |
| coolAppCode | String | Tidak | appCode dari cool app. |
| autoOpenMode | Integer | Tidak | Apakah dibuka secara otomatis:   - **0**: Jangan buka otomatis - **1**: Hanya Tuan Rumah dan co-host yang dibuka otomatis - **2**: Semua pengguna dibuka otomatis |
| extensionAppBizData | String | Tidak | Informasi Kustom untuk Aplikasi ekstensi tingkat rapat. |
| enableWebAnonymousJoin | Boolean | Tidak | Apakah mendukung Login senyap untuk Gabung ke konferensi dari web:   - **true**: Didukung - **false**: Tidak didukung |
| pushAllMeetingRecords | Boolean | Tidak | Apakah mengirim semua Catatan Rapat:   - **true**: kirim semua rekaman - **false**: kirim hanya Catatan Rapat yang waktu aktualnya berada dalam rentang waktu yang direncanakan untuk rapat terjadwal.   Di luar rentang waktu yang direncanakan untuk rapat terjadwal didefinisikan sebagai: waktu mulai rapat > waktu selesai yang direncanakan untuk rapat terjadwal, atau waktu selesai rapat > waktu mulai yang direncanakan untuk rapat terjadwal. |
| pushMinutesCard | Boolean | Tidak | Apakah mengirim Kartu AI Minutes:   - **true**: kirim - **false**: jangan kirim   Dikirim secara default. |
| pushCloudRecordCard | Boolean | Tidak | Apakah mengirim Kartu AI Minutes rekaman cloud:   - **true**: kirim - **false**: jangan kirim   Dikirim secara default. |
| minutesOwnerUnionId | String | Tidak | Pemilik AI Minutes. Default-nya adalah penyelenggara rapat terjadwal. |
| cloudRecordOwnerUnionId | String | Tidak | Pemilik rekaman cloud. Default-nya adalah penyelenggara rapat terjadwal. |
| minutesSummaryTemplateType | String | Tidak | Templat yang ditentukan untuk ringkasan rekaman cloud:   - **0**: Templat resmi. - **1**: Templat Kustom. |
| minutesSummaryTemplateId | String | Tidak | - Jika `minutesSummaryTemplateType= 0`, kirim ID dari Templat resmi terkait. - Jika `minutesSummaryTemplateType = 1`, kirim ID dari Templat Kustom terkait. |
| minutesSummaryDiyTemplateVersion | String | Tidak | - Jika `minutesSummaryTemplateType = 0`, tidak diperlukan nilai. - Jika `minutesSummaryTemplateType = 1`, kirim nomor Versi dari Templat Kustom terkait. |
| hiddenOwnerNick | Boolean | Tidak | Apakah menyembunyikan Nama inisiator rekaman cloud:   - **true**: sembunyikan Nama inisiator - **false** (default): jangan sembunyikan |
| cohostUnionIds | Array of String | Tidak | unionId dari co-Host. |
| moziConfOpenRecordSetting | Object | Tidak | Pengaturan Rekam otomatis. |
| recordAutoStart | Integer | Tidak | Apakah memulai rekaman cloud secara otomatis:   - **0**: Jangan mulai otomatis - **1**: Mulai otomatis |
| recordAutoStartType | Integer | Tidak | Jenis mulai otomatis rekaman cloud:   - **0**: Mulai otomatis setelah saya bergabung sebagai Tuan Rumah - **1**: Mulai setelah orang lain bergabung sebagai co-Host - **2**: Mulai setelah siapa pun bergabung dalam peran apa pun |
| mode | String | Tidak | Tata letak rekaman rapat:   - **grid**: mode kisi, default 9 kisi (3x3) - **speech**: mode pembicara - **full_screen**: mode layar penuh - **auto_grid**: mode kisi otomatis, default maksimum kisi 4x4 - **screen_cast**: mode berbagi layar, hanya menampilkan aliran berbagi layar - **p2p**: mode Panggilan dua orang - **full_screen_and_speaker**: Konten yang dibagikan + mode pembicara |
| isFollowHost | Boolean | Tidak | Apakah mengikuti Tuan Rumah:   - **true**: ikuti - **false**: jangan ikuti |
| restrictShareMinutesSummaryOnly | Integer | Tidak | Apakah membatasi Berbagi AI Minutes hanya pada ringkasan:   - **0**: tanpa batasan - **1**: batasi |
| aiAgentSummarySetting | Object | Tidak | Pengaturan AI Minutes rapat. |
| value | String | Tidak | Apakah mengaktifkan ringkasan Asisten AI:   - **disable**: Nonaktif - **enable**: Aktif |
| receiverType | Integer | Tidak | Cakupan penerima kiriman AI Minutes setelah rapat:   - **0**: semua Anggota - **1**: hanya Dibuat oleh |
| allowAllParticipantsStart | Integer | Tidak | Apakah mengizinkan semua Anggota memulai AI Minutes:   - **0**: Tidak diizinkan - **1**: Izinkan |
| restrictShareMinutesSummaryOnly | Integer | Tidak | Apakah membatasi Berbagi AI Minutes hanya pada ringkasan:   - **0**: tanpa batasan - **1**: batasi |
| enableAiAgentStatus | Boolean | Tidak | Apakah menampilkan fitur AI Minutes:   - **true**: tampilkan - **false**: jangan tampilkan (berlaku pada DingTalk Android versi 8.3.20 atau yang lebih baru; berlaku pada iOS, PC, dan platform lainnya) |
