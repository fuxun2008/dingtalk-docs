Panggil API ini untuk memperbarui anggota grup absensi. Tambah atau hapus **anggota absensi** dan **anggota bebas absensi** untuk grup absensi tertentu.

## Permintaan

| **Informasi dasar** | |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/topapi/attendance/group/member/update |
| Metode HTTP | POST |
| Tipe aplikasi yang didukung | appType-Aplikasi internal　appType-Aplikasi perusahaan pihak ketiga |
| Izin yang diperlukan | qyapi_attendance_group_manage (Izin pengelolaan grup absensi) |

### Parameter query

| Nama | Tipe | Wajib | Contoh | Deskripsi |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | bE74xxxx | Kredensial aplikasi yang digunakan untuk memanggil API ini.   - Untuk Aplikasi internal, panggil API [Mendapatkan access_token Aplikasi internal](/id/open/development/obtain-orgapp-token) untuk memperolehnya. - Untuk Aplikasi perusahaan pihak ketiga, panggil API untuk mendapatkan access_token organisasi pihak ketiga untuk memperolehnya. |

### Isi permintaan

| Nama | Tipe | Wajib | Contoh | Deskripsi |
| --- | --- | --- | --- | --- |
| op_user_id | String | Ya | user123 | userId operator. |
| group_id | Number | Ya | 98562 | ID grup absensi.  **Catatan**  Jika Anda menggunakan pengenal grup absensi versi lama (group_key), panggil API [Konversi groupKey ke groupId](/id/open/development/convert-groupkey-to-groupid) untuk mengonversi group_key menjadi group_id. |
| schedule_flag | Number | Ya | 0 | Hari dimulainya penjadwalan shift.   - **0**: Mulai penjadwalan shift hari ini - **1**: Mulai penjadwalan shift besok |
| update_param | TopGroupMemberUpdateParam | Ya |  | Informasi pembaruan grup absensi. |
| remove_extra_users | String[] | Tidak | ["user123","user456"] | Anggota bebas absensi yang akan dihapus. Biarkan kosong jika tidak diperlukan. Maksimal 20 userId per panggilan. |
| remove_depts | String[] | Tidak | ["123","456"] | Departemen absensi yang akan dihapus. Biarkan kosong jika tidak diperlukan. Maksimal 20 ID departemen per panggilan. |
| remove_users | String[] | Tidak | ["user123","user456"] | Anggota absensi yang akan dihapus. Biarkan kosong jika tidak diperlukan. Maksimal 20 userId per panggilan. |
| add_depts | String[] | Tidak | ["123","456"] | Departemen absensi yang akan ditambahkan. Biarkan kosong jika tidak diperlukan. Maksimal 20 ID departemen per panggilan. |
| add_users | String[] | Tidak | ["user123","user456"] | Anggota absensi yang akan ditambahkan. Biarkan kosong jika tidak diperlukan. Maksimal 20 userId per panggilan. |
| add_extra_users | String[] | Tidak | ["user123","user456"] | Anggota bebas absensi yang akan ditambahkan. Biarkan kosong jika tidak diperlukan. Maksimal 20 userId per panggilan. |

### Contoh permintaan

```curl
curl -X POST "https://api.dingtalk.io/topapi/attendance/group/member/update" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=0142dxxxxa6204' \
-d 'group_id=122' \
-d 'op_user_id=dd_dd' \
-d 'schedule_flag=0' \
-d 'update_param=null'
```

Java

```java
DingTalkClient client = new DefaultDingTalkClient("https://api.dingtalk.io/topapi/attendance/group/member/update");
OapiAttendanceGroupMemberUpdateRequest req = new OapiAttendanceGroupMemberUpdateRequest();
req.setOpUserId("user123");
req.setGroupId(98562L);
req.setScheduleFlag(0L);
TopGroupMemberUpdateParam updateParam = new TopGroupMemberUpdateParam();
updateParam.setAddDepts(Arrays.asList("123"));
updateParam.setRemoveDepts(Arrays.asList("456"));
updateParam.setAddUsers(Arrays.asList("user123"));
updateParam.setAddExtraUsers(Arrays.asList("user456"));
updateParam.setRemoveExtraUsers(Arrays.asList("user789"));
updateParam.setRemoveUsers(Arrays.asList("user121"));
req.setUpdateParam(updateParam);
OapiAttendanceGroupMemberUpdateResponse rsp = client.execute(req, access_token);
System.out.println(rsp.getBody());
```

## Respons

### Isi respons

| Nama | Tipe | Contoh | Deskripsi |
| --- | --- | --- | --- |
| request_id | String | 3pgsafymemlr | ID permintaan. |
| errcode | Number | 0 | Kode respons. |
| success | Boolean | true | Menunjukkan apakah panggilan berhasil.   - **true**: Berhasil - **false**: Gagal |

### Contoh isi respons

```json
{
  "errcode": 0,
  "success": true,
  "request_id": "5sj3lgigiqm9"
}
```

### Kode error

Jika panggilan mengembalikan error, cari solusinya di dokumen [Kode error global](/id/open/development/server-api-error-codes-1) berdasarkan pesan error.
