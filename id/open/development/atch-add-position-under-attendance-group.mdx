Panggil API ini untuk menambahkan lokasi ke grup absensi tertentu secara massal.

## Permintaan

| **Informasi dasar** | |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/topapi/attendance/group/positions/add |
| Metode HTTP | POST |
| Tipe aplikasi yang didukung | appType-Aplikasi internal |
| Izin yang diperlukan | permission-qyapi_attendance_group_manage-Izin manajemen grup absensi |

### Parameter query

| Nama | Tipe | Wajib | Contoh | Deskripsi |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | 4c9ebd2b1534xxxx | Kredensial aplikasi untuk memanggil API ini. Dapatkan dengan memanggil API [Mendapatkan access_token Aplikasi internal](/id/open/development/obtain-orgapp-token). |

### Isi permintaan

| Nama | Tipe | Wajib | Contoh | Deskripsi |
| --- | --- | --- | --- | --- |
| op_userid | String | Tidak | user01 | ID pengguna operator. |
| group_key | String | Ya | 03B1Exxxx | ID grup absensi.  **Catatan**  Jika pengenal grup absensi Anda berupa group_id, panggil API [Mengonversi groupId ke groupKey](/id/open/development/groupid-to-groupkey) untuk mengonversi group_id menjadi group_key. |
| position_list | Object[] | Ya |  | Daftar posisi. Tambahkan hingga 100 lokasi per permintaan. |
| address | String | Ya | Alibaba Group Xixi Beiyuan | Deskripsi alamat. |
| foreign_id | String | Ya | 0151E23B1 | positionId yang ditentukan oleh pihak bisnis. |
| longitude | String | Ya | 120.123 | Garis bujur (maksimal 6 angka desimal). |
| latitude | String | Ya | 30.123 | Garis lintang (maksimal 6 angka desimal). |
| offset | Number | Tidak | 100 | Batas toleransi jarak lokasi absen, dalam meter. |

### Contoh permintaan

```curl
curl -X POST "https://api.dingtalk.io/topapi/attendance/group/positions/add" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=23adcxxxx46c5226' \
-d 'group_key=0151E02xxxx917E876' \
-d 'op_userid=123456' \
-d 'position_list=null'
```

Java

```java
DingTalkClient client = new DefaultDingTalkClient("https://api.dingtalk.io/topapi/attendance/group/positions/add");
OapiAttendanceGroupPositionsAddRequest req = new OapiAttendanceGroupPositionsAddRequest();
req.setOpUserid("user01");
req.setGroupKey("03B1Exxxx");
List<Position> list = new ArrayList<Position>();
Position position = new Position();
list.add(position);
position.setAddress("Alibaba Group Xixi Beiyuan");
position.setForeignId("0151E23B1");
position.setLongitude("120.123");
position.setLatitude("30.123");
position.setOffset(100);
req.setPositionList(list);
OapiAttendanceGroupPositionsAddResponse rsp = client.execute(req, access_token);
System.out.println(rsp.getBody());
```

## Respons

### Isi respons

| Nama | Tipe | Contoh | Deskripsi |
| --- | --- | --- | --- |
| result | DingOpenResult |  | Hasil yang dikembalikan. |
| result | Result |  | Hasil query. |
| error_info_list | ErrorInfo[] |  | Daftar error. |
| failure_list | Position[] |  | Daftar item yang gagal. |
| foreign_id | String | 0151E23B1xxxx | positionId yang ditentukan oleh pihak bisnis. |
| address | String | Alibaba Group Xixi Beiyuan | Deskripsi alamat. |
| latitude | String | 120.123 | Garis bujur (maksimal 6 angka desimal). |
| longitude | String | 30.123 | Garis lintang (maksimal 6 angka desimal). |
| position_key | String |  | Kunci lokasi. Kosong jika operasi gagal. |
| msg | String | kesalahan bisnis | Pesan error. |
| code | String | 1000 | Kode error. |
| success_list | Position[] |  | Daftar item yang berhasil. |
| foreign_id | String | 0151E23B1 | positionId yang ditentukan oleh pihak bisnis. |
| address | String | Alibaba Group Xixi Beiyuan | Deskripsi alamat. |
| latitude | String | 120.123 | Garis bujur (maksimal 6 angka desimal). |

| errcode | Number | 0 | Kode pengembalian. |
| errmsg | String | ok | Deskripsi kode pengembalian. |
| success | Boolean | true | Menunjukkan apakah permintaan berhasil.   - **true**: Berhasil - **false**: Gagal |
