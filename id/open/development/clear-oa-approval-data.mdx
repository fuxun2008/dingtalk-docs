Panggil API ini untuk membersihkan data terkait persetujuan.

## Permintaan

### Informasi dasar

| Bidang | Nilai |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/v1.0/workflow/processes/clean |
| Metode HTTP | POST |
| Jenis aplikasi yang didukung | appType-Aplikasi perusahaan pihak ketiga |
| Izin | permission-Workflow.Data.Clean-Izin khusus untuk pembersihan data alur kerja |

### Header permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Dapatkan kredensial ini dengan memanggil API untuk mendapatkan suiteAccessToken Aplikasi perusahaan pihak ketiga. |

### Isi permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| processCode | String | Ya | Kode unik templat. Dapatkan kode ini dengan memanggil API untuk membuat atau memperbarui templat persetujuan. |
| corpId | String | Ya | ID organisasi dari organisasi yang memberikan otorisasi. |

### Contoh permintaan

HTTP

```http
POST /v1.0/workflow/processes/clean HTTP/1.1
Host:api.dingtalk.io
x-acs-dingtalk-access-token:6d1bxxxx
Content-Type:application/json

{
  "processCode" : "PROC-EF6Yxxxxx",
  "corpId" : "ding1234"
}
```

| --- | --- | --- |
| success | Boolean | Menunjukkan apakah tindakan pembersihan berhasil. |

### Contoh isi respons

```text
HTTP/1.1 200 OK
Content-Type:application/json

{
  "success" : true
}
```

### Kode error

| 400 | processNotExist | Alur kerja persetujuan tidak ada | Alur kerja persetujuan tidak ada |
| 400 | needAuth | Otorisasi diperlukan | Otorisasi diperlukan |
| 400 | internalError | %s | Error sistem internal |
| 400 | processGetFailedByParameter | Tidak ada izin untuk mengelola alur kerja persetujuan. Periksa apakah instans persetujuan atau templat sudah benar | Tidak ada izin untuk mengelola alur kerja persetujuan. Periksa apakah instans persetujuan atau templat sudah benar |
