Panggil API ini untuk mengambil daftar pengaturan pembatasan visibilitas Kontak.

## Deskripsi panggilan API

Setelah memanggil API [Menambahkan atau mengubah pengaturan pembatasan visibilitas Kontak](/id/open/development/add-or-modify-visibility-settings-for-address-book-restrictions#), panggil API ini untuk menampilkan pengaturan pembatasan visibilitas yang telah dikonfigurasi untuk organisasi Anda secara berhalaman.

## Permintaan

### Informasi dasar

| Bidang | Nilai |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/v1.0/contact/restrictions/settings |
| Metode HTTP | GET |
| Jenis aplikasi yang didukung | appType-Aplikasi internal |
| Izin yang diperlukan | permission-Contact.Visibility.ReadWrite-Izin untuk mengelola visibilitas data Kontak |

### Header permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Dapatkan dengan memanggil API [Memperoleh access token aplikasi internal](/id/open/development/obtain-the-access-token-of-an-internal-app#). |

### Parameter kueri

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| nextToken | Long | Tidak | Cursor paginasi.   - Kosongkan parameter ini untuk panggilan pertama. - Untuk panggilan berikutnya, isi parameter ini dengan nextToken yang dikembalikan oleh panggilan sebelumnya. |
| maxResults | Integer | Tidak | Jumlah maksimum hasil yang dikembalikan. Nilai maksimum: 100. |

### Contoh permintaan

```http
GET /v1.0/contact/restrictions/settings?nextToken=1&maxResults=100 HTTP/1.1
Host:api.dingtalk.io
x-acs-dingtalk-access-token:xxxxx
```

## Respons

### Isi respons

| Nama | Tipe | Deskripsi |
| --- | --- | --- |
| hasMore | Boolean | Apakah masih ada data lain.   - true: Ya - false: Tidak |
| nextToken | Long | Cursor paginasi. |
| list | Array | Daftar pengaturan pembatasan visibilitas Kontak. |
| id | Long | ID pengaturan. |
| name | String | Nama pengaturan pembatasan visibilitas Kontak. |
| description | String | Deskripsi pembatasan visibilitas Kontak. |
| subjectUserIds | Array of String | Daftar userId yang dikenai pembatasan visibilitas Kontak. |
| subjectDeptIds | Array of Long | Daftar deptId yang dikenai pembatasan visibilitas Kontak. |
| subjectTagIds | Array of Long | Daftar roleId yang dikenai pembatasan visibilitas Kontak. |
| type | String | Tipe pembatasan.   - excludeNode: Hanya pengguna dan departemen dalam daftar izin yang terlihat. - onlySelf: Hanya pengguna itu sendiri yang terlihat. - onlySelfDeptAndChild: Hanya departemen pengguna sendiri beserta sub-departemennya yang terlihat. |
| excludeUserIds | Array of String | Daftar userId dalam daftar izin. |
| excludeDeptIds | Array of Long | Daftar deptId dalam daftar izin. |
| excludeTagIds | Array of Long | Daftar roleId dalam daftar izin. |
| active | Boolean | Apakah pengaturan sedang berlaku.   - true: Berlaku - false: Tidak berlaku |
| restrictInUserProfile | Boolean | Apakah juga membatasi tampilan halaman Profil.   - true: Ya - false: Tidak |
| restrictInSearch | Boolean | Apakah juga membatasi pencarian.   - true: Ya - false: Tidak |
