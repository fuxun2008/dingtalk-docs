Dokumen ini menjelaskan cara menerbitkan aplikasi internal DingTalk. Ikuti langkah-langkah dalam dokumen ini untuk menyelesaikan penerbitan aplikasi internal.

## **Prasyarat**

Selesaikan proses [Membuat aplikasi](https://open.dingtalk.com/document/orgapp/create-an-application).

## **Prosedur**

1. Masuk ke [Developer Console](https://open-dev.dingtalk.com/#/), lalu klik aplikasi yang dituju untuk membuka halaman detailnya.
2. Klik **App Release** > **Version Management and Release** > **Create a Version**.
3. Konfigurasikan detail versi:

   1. Nomor versi aplikasi: Masukkan nomor versi dalam format 1.0.0. Nilai minimum adalah 1.0.0, dan nilai maksimum untuk setiap segmen adalah 99 (1.99.0). Format 1.100.0 tidak didukung.
   2. Deskripsi versi: Jelaskan secara singkat perubahan pada versi ini.
   3. Konten yang akan diterbitkan: Pilih konten yang ingin Anda terbitkan.

      **Penting**

      Saat Anda menerbitkan aplikasi non-Workbench (aplikasi mini program atau aplikasi web), Anda juga harus memilih aplikasi Workbench untuk diterbitkan. Jika Anda tidak memilih aplikasi Workbench, aplikasi tersebut akan dinonaktifkan secara default, yang akan menyebabkan aplikasi live tidak dapat berfungsi dengan baik. Oleh karena itu, berhati-hatilah saat menerbitkan versi aplikasi, dan pastikan untuk memilih aplikasi Workbench agar diterbitkan secara bersamaan supaya tetap berjalan dengan baik.

      - Aplikasi Workbench: Untuk aplikasi Workbench, Anda dapat memilih mini program atau aplikasi web, dan Anda dapat memilih mini program berdasarkan versinya.

        **Catatan**

        Anda hanya dapat memilih salah satu antara mini program dan aplikasi web.
      - Bot: Terbitkan aplikasi bot yang disimpan di bawah **App Capabilities** > **Bots**.
      - Cool App: Terbitkan semua cool app yang dibuat dan dirilis di bawah **App Capabilities** > **Cool App** dalam satu operasi.
      - Aplikasi Magic Wand: Terbitkan aplikasi Magic Wand yang disimpan di bawah **App Capabilities** > **AI App** > **Magic Wand App**.
      - Digital Employee: Terbitkan Tabler yang disimpan di bawah **App Capabilities** > **AI App** > **Tabler**.
   4. Cakupan visibilitas aplikasi: Pilih visibilitas yang sesuai agar hanya pengguna atau departemen tertentu yang dapat menggunakan aplikasi.
4. Setelah konfigurasi selesai, klik **Save** > **Publish Directly** untuk menyelesaikan penerbitan aplikasi.

Setelah penerbitan selesai, Anda dapat melihat aplikasi yang telah diterbitkan dalam daftar Version Management and Release.

## **Informasi Lainnya**

Setelah aplikasi diterbitkan, Anda dapat menambahkan dan menggunakannya melalui metode berikut.

### **Aplikasi Mini Program / Aplikasi Web**

Setelah aplikasi mini program atau aplikasi web diterbitkan, Anda dapat menemukan dan menggunakan aplikasi terkait di Workbench Sisi klien.

### **Bot**

1. Buka **Sisi klien DingTalk** > Obrolan Grup yang ditentukan.
2. Klik **Pengaturan grup** untuk membuka halaman Pengaturan grup.
3. Klik **Kelola Grup** > **Bots** untuk membuka halaman kelola bot.
4. Klik Tambah Bot, lalu pilih bot terkait untuk menyelesaikan penambahan.

### **Aplikasi Magic Wand**

- **Aplikasi Magic Wand**: Setelah aplikasi Magic Wand diterbitkan, Anda dapat menggunakan Magic Wand di Sisi klien DingTalk.

  1. Buka halaman Beranda DingTalk, lalu klik "**/**" di sudut kanan atas untuk membuka halaman DingTalk Tabler.

     **Catatan**

     Sebelum menggunakan Keterampilan aplikasi Magic Wand ini, pastikan organisasi saat ini di Sisi klien DingTalk telah beralih ke organisasi yang menerbitkan aplikasi tersebut.
  2. Pada halaman Tabler, klik "**Tabler ⇋**" di sudut kiri atas, lalu pilih aplikasi Magic Wand yang baru saja Anda terbitkan dari daftar Tabler.
  3. Masukkan permintaan Anda di kotak input, lalu klik ikon Kirim. Magic Wand akan mengembalikan output dalam bentuk percakapan.
