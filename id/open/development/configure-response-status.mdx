Panggil API ini untuk menetapkan status respons dari sebuah undangan acara.

## Permintaan

### Informasi dasar

| Bidang | Nilai |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/calendar/users/{userId}/calendars/{calendarId}/events/{eventId}/respond` |
| Metode HTTP | POST |
| Tipe aplikasi yang didukung | appType-Internal app　appType-Third-party enterprise app　appType-Third-party personal app |
| Izin yang diperlukan | permission-Calendar.Event.Write-Izin tulis untuk acara di aplikasi Kalender |

### Header permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Dapatkan dengan cara berikut:   - Untuk aplikasi internal, panggil API [Memperoleh access token aplikasi internal](/id/open/development/obtain-the-access-token-of-an-internal-app#). - Untuk aplikasi perusahaan pihak ketiga, panggil API [Memperoleh access token perusahaan yang diberi otorisasi untuk menggunakan aplikasi pihak ketiga](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#). - Untuk aplikasi personal pihak ketiga, panggil API [Memperoleh token pengguna](/id/open/development/obtain-user-token#). |

### Parameter path

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| userId | String | Ya | unionId dari peserta acara.   - Untuk aplikasi internal atau aplikasi perusahaan pihak ketiga, panggil API [Kueri detail pengguna](/id/open/development/query-user-details#) untuk memperoleh nilai parameter unionid. - Untuk aplikasi personal pihak ketiga, panggil API [Memperoleh profil pengguna dari Kontak](/id/open/development/dingtalk-retrieve-user-information#) untuk memperoleh nilai parameter unionId. |
| calendarId | String | Ya | ID kalender tempat acara berada. Nilainya tetap primary, yang menunjukkan kalender utama pengguna. |
| eventId | String | Ya | ID acara. Panggil API [Kueri daftar acara](/id/open/development/query-an-event-list#) untuk memperoleh nilai parameter id. |

### Isi permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| responseStatus | String | Ya | Status respons. Nilai yang valid:   - **needsAction** (default): Tidak ada tindakan yang diambil. - **accepted**: Diterima. - **declined**: Ditolak. - **tentative**: Sementara. |
