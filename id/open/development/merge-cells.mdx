---
title: "Gabungkan sel"
description: "Panggil API ini untuk menggabungkan sel dalam rentang tertentu di DingTalk Spreadsheet, mendukung mode penuh, per baris, dan per kolom; hanya data sel kiri atas yang dipertahankan."
---

Panggil API ini untuk menggabungkan beberapa sel dalam rentang tertentu di DingTalk Spreadsheet menjadi satu sel. Fitur ini berguna untuk skenario seperti membuat judul header lintas kolom atau menggabungkan baris dengan kategori yang sama. Tiga mode penggabungan didukung: gabungkan semua, gabungkan per baris, dan gabungkan per kolom. Setelah penggabungan, hanya data di sel kiri atas yang dipertahankan, dan konten sel lainnya dihapus. API mengembalikan alamat sel yang telah digabungkan.

## Permintaan

### Informasi dasar

| Bidang | Value |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/doc/workbooks/{workbookId}/sheets/{sheetId}/ranges/{rangeAddress}/merge` |
| Metode HTTP | POST |
| Jenis aplikasi yang didukung | appType-Aplikasi internal |
| Izin | permission-Document.Workbook.Write-Izin tulis DingTalk Spreadsheet |

### Header permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Untuk memperolehnya, panggil API [Memperoleh access token aplikasi internal](/id/open/development/obtain-the-access-token-of-an-internal-app). |

### Parameter path

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| workbookId | String | Ya | ID file spreadsheet. `nodeId` (`dentryUuid`) yang dikembalikan oleh [Knowledge Base API](/id/open/development/knowledge-base-overview) adalah `workbookId` dari spreadsheet. Untuk memperolehnya, panggil API [Memperoleh node](/id/open/development/get-knowledge-base-acquisition-node) atau [Membuat dokumen Knowledge Base](/id/open/development/create-team-space-document). |
| sheetId | String | Ya | ID atau judul lembar kerja. Untuk memperoleh ID dan judul lembar kerja, panggil API [Memperoleh semua lembar kerja](/id/open/development/obtain-all-worksheets). |
| rangeAddress | String | Ya | Rentang sel yang akan digabungkan, dalam format `sel kiri atas:sel kanan bawah`. Contoh: B2:C3. |

### Parameter query

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| operatorId | String | Ya | unionId dari operator. Untuk memperolehnya, panggil API [Kueri detail pengguna](/id/open/development/query-user-details). Jika operator tidak memiliki izin, API mengembalikan error `The operator has no permission`. |

### Isi permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| mergeType | String | Tidak | Mode penggabungan. Value yang valid:   - **mergeAll**: Menggabungkan semua sel (default). - **mergeRows**: Menggabungkan per baris. Sel yang berdekatan dalam baris yang sama di rentang yang dipilih digabungkan menjadi satu sel. - **mergeColumns**: Menggabungkan per kolom. Sel yang berdekatan dalam kolom yang sama di rentang yang dipilih digabungkan menjadi satu sel. |

## Respons

### Isi respons

| Nama | Tipe | Deskripsi |
| --- | --- | --- |
| a1Notation | String | Rentang sel yang telah digabungkan, dalam format `sel kiri atas:sel kanan bawah`. Contoh: B2:C3. |

### Contoh isi respons

```text
HTTP/1.1 200 OK
Content-Type:application/json

{
  "a1Notation" : "A1:B1"
}
```
