Panggil API ini untuk menambahkan kontrol akses ke kalender tertentu.

## Permintaan

### Informasi dasar

| Bidang | Nilai |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/calendar/users/{userId}/calendars/{calendarId}/acls` |
| Metode HTTP | POST |
| Tipe aplikasi yang didukung | appType-Aplikasi internal　appType-Aplikasi personal pihak ketiga |
| Izin yang diperlukan | permission-Calendar.Acl.Write-Izin tulis kontrol akses aplikasi Kalender |

### Header permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Dapatkan dengan cara berikut:   - Untuk aplikasi internal, panggil API [Dapatkan access token aplikasi internal](/id/open/development/obtain-the-access-token-of-an-internal-app#). - Untuk aplikasi personal pihak ketiga, panggil API [Dapatkan token pengguna](/id/open/development/obtain-user-token#). |

### Parameter path

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| userId | String | Ya | unionId dari penyelenggara acara.   - Untuk aplikasi internal, panggil API [Kueri detail pengguna](/id/open/development/query-user-details#) untuk memperoleh nilai parameter unionid. - Untuk aplikasi personal pihak ketiga, panggil API [Dapatkan profil kontak pengguna](/id/open/development/dingtalk-retrieve-user-information#) untuk memperoleh nilai parameter unionId. |
| calendarId | String | Ya | ID kalender tempat acara berada. Nilainya tetap primary, yang menunjukkan kalender utama pengguna. |

### Isi permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| privilege | String | Ya | Informasi izin. Nilai yang valid:   - **free_busy_reader**: Periksa luang/sibuk. - **title_reader**: Lihat judul. - **reader**: Lihat detail. - **writer**: Buat dan edit. |
| sendMsg | Boolean | Ya | Apakah akan mengirim pesan ke pengguna yang diberi otorisasi.   - **true**: Kirim. - **false**: Jangan kirim. |
| scope | Object | Ya | Cakupan izin. |
| scopeType | String | Ya | Tipe izin. Saat ini, hanya **user** yang didukung, yang menunjukkan seorang pengguna. |
| userId | String | Ya | ID pengguna. Saat **scopeType** disetel ke **user**, masukkan **unionId** dari pengguna.  **Catatan**  Satu pengguna dapat berbagi dengan maksimal 500 pengguna. |

### Contoh permintaan
