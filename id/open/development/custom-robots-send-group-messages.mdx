Panggil API ini untuk mengirim obrolan grup menggunakan bot kustom.

## Deskripsi panggilan API

- API ini memungkinkan bot kustom mengirim obrolan di Grup Internal dan Grup Standar dalam organisasi Anda. Sebelum memanggil API ini, buat bot kustom terlebih dahulu. Untuk detailnya, lihat Mengembangkan aplikasi bot.
- Jika Anda memiliki obrolan dalam jumlah besar untuk dikirim (misalnya, peringatan pemantauan sistem), konsolidasikan informasi tersebut dan kirim ke grup sebagai ringkasan dalam obrolan markdown.
- Jika bot kustom menggunakan [pengaturan keamanan bot kustom](/id/open/dingstart/customize-robot-security-settings), tambahkan parameter `timestamp` dan `sign` saat memanggil API ini. Contoh:

  ```text
  https://oapi.dingtalk.io/robot/send?access_token=XXXXXX&timestamp=XXX&sign=XXX
  ```
- **Setiap bot dapat mengirim hingga 20 obrolan per menit ke sebuah grup. Melebihi 20 obrolan akan memicu batas laju selama 10 menit.**

## Permintaan

| **Informasi dasar** | |
| --- | --- |
| URL HTTP | https://oapi.dingtalk.io/robot/send |
| Metode HTTP | POST |
| Tipe aplikasi yang didukung | appType-Aplikasi internal appType-Aplikasi perusahaan pihak ketiga |
| Izin yang diperlukan | permission-qyapi_base-Izin dasar untuk memanggil API perusahaan |

### Parameter kueri

| Nama | Tipe | Wajib | Contoh | Deskripsi |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | BE3xxxx | Kredensial yang digunakan bot kustom untuk memanggil API.  Nilai `access_token` dari URL Webhook yang dihasilkan setelah bot kustom dipasang. Untuk detailnya, lihat [Mendapatkan URL Webhook bot kustom](/id/open/dingstart/obtain-the-webhook-address-of-a-custom-robot). |

| Nama | Tipe | Wajib | Contoh | Deskripsi |

| atUserIds | String[] | Tidak | ["user001","user002"] | `userId` anggota grup yang akan disebut dengan @.  **Catatan**  Saat menyebut anggota grup dengan @, Anda dapat menyebut hingga 50 anggota. |

| title | String | Tidak | Judul yang ditampilkan di daftar obrolan | Judul yang ditampilkan di daftar obrolan, bukan judul isi obrolan. |
| btns | Object[] | Tidak |  | Daftar informasi tombol.  **Catatan**  Wajib jika obrolan berisi lebih dari satu tombol. |

## Respons

### Isi respons

| Nama | Tipe | Contoh | Deskripsi |
| --- | --- | --- | --- |
| errmsg | String | ok | Deskripsi kode error. |
| errcode | Number | 0 | Kode error. |

### Contoh isi respons

```json
{
  "errcode":"0",
  "errmsg":"ok"
}
```

### Kode error

Jika error dikembalikan saat memanggil API ini, cari solusinya dalam dokumentasi [Kode error global](/id/open/development/server-api-error-codes-1) berdasarkan pesan error.

| Kode error (errorcode) | Deskripsi error (errmsg) | Solusi |
| --- | --- | --- |
| -1 | Sistem sibuk | Coba lagi nanti |
| 40035 | Parameter json hilang | Tambahkan json obrolan |
| 43004 | Content-Type HEADER HTTP tidak valid | Atur parameter obrolan yang spesifik |
| 400013 | Grup telah dibubarkan | Kirim obrolan ke grup lain |
| 400101 | access_token tidak ada | Pastikan access_token dieja dengan benar |
| 400102 | Bot dinonaktifkan | Hubungi admin untuk mengaktifkan bot |
| 400105 | Tipe obrolan tidak didukung | Gunakan tipe obrolan yang didukung dalam dokumentasi |
| 400106 | Bot tidak ada | Pastikan bot ada di dalam grup |
| 410100 | Batas laju dipicu karena pengiriman terlalu cepat | Kurangi laju pengiriman |
| 430101 | Berisi tautan eksternal yang tidak aman | Pastikan konten yang dikirim sesuai ketentuan |
| 430102 | Berisi teks yang tidak pantas | Pastikan konten yang dikirim sesuai ketentuan |
| 430103 | Berisi gambar yang tidak pantas | Pastikan konten yang dikirim sesuai ketentuan |
| 430104 | Berisi konten yang tidak pantas | Pastikan konten yang dikirim sesuai ketentuan |

Ketika error berikut terjadi, obrolan gagal divalidasi. Periksa pengaturan keamanan bot.

| Kode error (errorcode) | Deskripsi error (errmsg) | Solusi |
| --- | --- | --- |
| 310000 | - keywords not in content - invalid timestamp - sign not match - ip X.X.X.X not in whitelist | - Konten obrolan tidak mengandung kata kunci apa pun - Stempel waktu tidak valid - Tanda tangan tidak cocok - Alamat IP tidak ada dalam daftar izin |
