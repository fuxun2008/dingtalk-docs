Topik ini menjelaskan tipe dan kasus penggunaan notifikasi pesan, kemampuan API notifikasi pesan, serta cara mengintegrasikan API notifikasi pesan.

## Tipe notifikasi pesan

### Pesan Notifikasi Kerja

Pesan notifikasi yang di-push kepada karyawan atas nama sebuah aplikasi mikro di obrolan Notifikasi Kerja organisasi. Contohnya mencakup ucapan ulang tahun dan pengingat orientasi karyawan.

### Mengirim Notifikasi Kerja menggunakan templat

### Deskripsi

- Templat pesan hanya didukung oleh aplikasi perusahaan pihak ketiga, bukan oleh aplikasi internal.
- Hanya templat pesan yang telah lolos peninjauan yang dapat digunakan untuk mem-push pesan Notifikasi Kerja.

- Templat **Markdown**

  Templat Markdown mengonfigurasi dan mengirim pesan menggunakan sintaks Markdown. Templat ini cocok untuk pesan notifikasi murni yang tidak memerlukan tindakan apa pun. Templat Markdown dengan mudah mendukung teks, gambar, tautan, dan format tampilan lainnya.
- Templat **ActionCard**

  Templat ActionCard mengirim pesan menggunakan tipe pesan ActionCard. Templat ini mendukung pesan yang menggabungkan konten dengan titik tindakan, cocok untuk skenario ketika penerima perlu memproses pesan dengan cepat melalui satu atau beberapa titik tindakan.

  Dibangun di atas templat Markdown, templat ActionCard mendukung gaya lompatan keseluruhan maupun lompatan individual.
- Templat **Formulir**

  Templat Formulir mengirim pesan berdasarkan tipe pesan OA. Templat ini cocok untuk menampilkan pesan seperti pesanan, dan mendukung lompatan untuk melihat detail pesan.

### Alur integrasi

Seperti ditunjukkan pada gambar berikut, mengirim Notifikasi Kerja menggunakan templat pesan memerlukan langkah-langkah berikut:

1. Buat dan konfigurasikan templat pesan. Untuk informasi selengkapnya, lihat Mengelola templat pesan.
2. Kirim templat untuk peninjauan.
3. Panggil API untuk mengirim Notifikasi Kerja menggunakan templat. Untuk informasi selengkapnya, lihat [Mengirim pesan Notifikasi Kerja menggunakan templat](/id/open/development/work-notification-templating-send-notification-interface).

## Glosarium

### task_id

`task_id` adalah bidang pengidentifikasi unik untuk pesan Notifikasi Kerja. Bidang ini dikembalikan saat Anda memanggil API [Mengirim Notifikasi Kerja](/id/open/development/asynchronous-sending-of-enterprise-session-messages).

Anda dapat menggunakan `task_id` untuk memanggil API [Mendapatkan progres pengiriman pesan Notifikasi Kerja](/id/open/development/obtain-the-sending-progress-of-asynchronous-sending-of-enterprise-session) dan API [Mendapatkan hasil pengiriman pesan Notifikasi Kerja](/id/open/development/gets-the-result-of-sending-messages-asynchronously-to-the-enterprise) untuk membuat kueri progres dan hasil pengiriman pesan Notifikasi Kerja.
