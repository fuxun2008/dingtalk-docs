---

Panggil API ini untuk membuat atau memperbarui templat formulir alur kerja Persetujuan OA. Tentukan daftar kontrol formulir, lalu sistem akan membuat Proses persetujuan default.

## Deskripsi panggilan API

- Setiap organisasi dapat membuat maksimal 200 templat persetujuan resmi. Setelah batas tercapai, panggilan ke API ini akan mengembalikan error.
- Templat Persetujuan OA resmi hanya mendukung komponen persetujuan yang tercantum dalam dokumen ini. Komponen lain tidak didukung.
- Templat Persetujuan OA resmi hanya mendukung komponen persetujuan yang tercantum dalam dokumen ini. Komponen lain tidak didukung.
- Saat Anda memperbarui templat persetujuan, jika komponen yang diperbarui digunakan sebagai kondisi cabang dalam desain alur kerja, formulir templat tidak dapat diubah.

## Permintaan

### Informasi dasar

| Bidang | Nilai |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/v1.0/workflow/forms |
| Metode HTTP | POST |
| Tipe aplikasi yang didukung | appType-Aplikasi internal　appType-Aplikasi perusahaan pihak ketiga |
| Izin | permission-Workflow.Form.Write-Izin tulis templat alur kerja |

### Header permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Cara mendapatkannya:   - Aplikasi internal: Panggil API [Mendapatkan Access Token Aplikasi internal](/id/open/development/obtain-the-access-token-of-an-internal-app). - Aplikasi perusahaan pihak ketiga: Panggil API untuk mendapatkan access token organisasi yang telah memberikan otorisasi kepada Aplikasi pihak ketiga. |

### Isi permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| processCode | String | Tidak | ProcessCode formulir. Tentukan ProcessCode saat memperbarui templat formulir.    Jika Anda meneruskan **ProcessCode** untuk mengubah dan memperbarui komponen formulir, Anda tidak dapat menghapus atau mengubah kontrol yang digunakan sebagai cabang kondisional dalam desain alur kerja. Contohnya, jika formulir asli berisi **kontrol pilihan tunggal** [Tipe Karyawan] yang digunakan sebagai kondisi cabang, Anda tidak dapat mengubah tipe kontrol bidang [Tipe Karyawan] atau menghapusnya saat memperbarui formulir.   - Jika parameter ini dikosongkan, templat baru akan dibuat. - Jika parameter ini ditentukan, templat persetujuan yang sesuai dengan nilai tersebut akan diperbarui. **Cara mendapatkan process_code**: Lihat di templat persetujuan pada DingTalk Admin Console.    Caranya berbeda antara DingTalk Admin Console baru dan lama. Untuk detailnya, lihat [Ikhtisar Persetujuan OA - Glosarium - processCode](/id/open/development/workflow-overview). **DingTalk Admin Console baru**: Buka halaman edit templat persetujuan, masuk ke Pengaturan Dasar, lalu lihat di bagian bawah halaman. **DingTalk Admin Console lama**: Lihat di URL halaman edit templat persetujuan. |
| name | String | Ya | Nama templat formulir. Panjang maksimal: 200 karakter. |
| description | String | Tidak | Deskripsi templat formulir. Panjang maksimal: 300 karakter. |
| formComponents | Array | Ya | Daftar kontrol formulir. Satu formulir dapat berisi maksimal 200 komponen. |
| FormComponent | FormComponent | Ya | Daftar kontrol formulir. Untuk detailnya, lihat [Parameter FormComponent](/id/open/development/oa-formcomponent-message). |
| templateConfig | Object | Tidak | Konfigurasi atribut global formulir. |
| disableStopProcessButton | Boolean | Tidak | Menentukan apakah tombol **Nonaktifkan** di halaman daftar pengelolaan dinonaktifkan:   - **true**: Ya - **false**: Tidak |
| hidden | Boolean | Tidak | Menentukan apakah entri templat alur kerja disembunyikan secara global.   - **true**: Ya - **false**: Tidak |
| disableDeleteProcess | Boolean | Tidak | Menentukan apakah tombol **Hapus** templat dinonaktifkan.   - **true**: Ya - **false**: Tidak |
| disableFormEdit | Boolean | Tidak | Menentukan apakah fitur **Edit** formulir dinonaktifkan.   - **true**: Ya - **false**: Tidak |
| disableResubmit | Boolean | Tidak | Menentukan apakah tombol **Kirim Ulang** di halaman detail dinonaktifkan.   - **true**: Ya - **false**: Tidak |
| disableHomepage | Boolean | Tidak | Menentukan apakah templat disembunyikan di halaman Beranda.   - **true**: Ya - **false**: Tidak |
| dirId | String | Tidak | ID direktori templat. Tentukan saat membuat direktori templat. |
| originDirId | String | Tidak | ID direktori asal. Tentukan ID direktori sumber saat memperbarui direktori templat. |
