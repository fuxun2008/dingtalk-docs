Panggil API ini untuk mendapatkan detail satu acara berdasarkan ID acara.

## Permintaan

### Informasi dasar

| Bidang | Nilai |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/calendar/users/{userId}/calendars/{calendarId}/events/{eventId}` |
| Metode HTTP | GET |
| Jenis aplikasi yang didukung | appType-Aplikasi internal　appType-Aplikasi perusahaan pihak ketiga　appType-Aplikasi personal pihak ketiga |
| Izin yang diperlukan | permission-Calendar.Event.Read-Izin baca untuk acara di aplikasi Calendar |

### Header permintaan

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Dapatkan dengan cara berikut:   - Untuk aplikasi internal, panggil API [Mendapatkan access token aplikasi internal](/id/open/development/obtain-the-access-token-of-an-internal-app#). - Untuk aplikasi perusahaan pihak ketiga, panggil API [Mendapatkan access token perusahaan yang mengotorisasi aplikasi pihak ketiga](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#). - Untuk aplikasi personal pihak ketiga, panggil API [Mendapatkan user token](/id/open/development/obtain-user-token#). |

### Parameter path

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| userId | String | Ya | unionId dari pengguna pemilik acara.   - Untuk aplikasi internal dan aplikasi perusahaan pihak ketiga, panggil API [Query detail pengguna](/id/open/development/query-user-details#) untuk mendapatkan nilai unionid. - Untuk aplikasi personal pihak ketiga, panggil API [Mendapatkan profil pengguna dari Kontak](/id/open/development/dingtalk-retrieve-user-information#) untuk mendapatkan nilai unionId. |
| calendarId | String | Ya | ID kalender pemilik acara. Atur ke `primary` untuk menunjukkan kalender utama pengguna. |
| eventId | String | Ya | ID acara. Panggil API [Query daftar acara](/id/open/development/query-an-event-list#) untuk mendapatkan nilai id. |

### Parameter query

| Nama | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| maxAttendees | Long | Tidak | Jumlah maksimum peserta. Default: 100. Maksimum: 500. |

| 404 | instanceNotExist | instance not exist | Instance acara berulang tidak ada |
