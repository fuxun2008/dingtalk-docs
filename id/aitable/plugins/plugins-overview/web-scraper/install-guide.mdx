### Lingkungan yang didukung

- Chrome / Edge

### Langkah instalasi

#### Langkah 1 — Unduh ekstensi browser

> Plugin ini ditujukan untuk pembelajaran, penelitian, dan produktivitas — dirancang untuk membantu pengguna menata konten web publik dengan lebih mudah.
> Saat menggunakan plugin ini untuk mengumpulkan, menata, dan memakai data, pengguna harus mematuhi hukum dan peraturan negara serta wilayahnya, menghormati ketentuan penggunaan situs, protokol robots, serta hak sah pihak lain. Menggunakan plugin untuk tujuan apa pun yang melanggar hukum, melanggar hak, kasar, atau tidak pantas sangat dilarang — termasuk tetapi tidak terbatas pada pelanggaran privasi, hak cipta, merek dagang, atau hak hukum lain milik orang lain.
> Plugin ini disediakan hanya sebagai alat teknis. Kami tidak bertanggung jawab atas cara pengguna memakainya maupun konsekuensi apa pun yang timbul darinya. Pengguna menanggung seluruh kerugian langsung maupun tidak langsung yang timbul dari penggunaan plugin.
> Dengan menggunakan plugin ini, Anda menyatakan telah membaca, memahami, dan menyetujui sepenuhnya penafian ini. Jika Anda tidak menyetujui bagian mana pun darinya, segera hentikan penggunaan plugin.

Unduh ekstensi ke perangkat Anda, lalu **ekstrak ke dalam sebuah folder**.

#### Langkah 2 — Instal di browser Anda

Instal di Chrome:

| Langkah |
| --- |
| 1. Buka Chrome, tempel `chrome://extensions/` di bilah alamat, lalu tekan Enter untuk membuka halaman ekstensi — **atau** klik tombol **Extensions** untuk membukanya. |
| 2. Aktifkan **Developer mode** di kanan atas. |
| 3. Seret **folder Fusion yang sudah diekstrak** ke halaman ekstensi Chrome. |
| 4. Cari ekstensi Fusion yang baru dan **pastikan sudah aktif**. |
| 5. Setelah terinstal, **muat ulang** AI Table > buka panel samping > cari atau buka Web Scraper dari pusat plugin. Saat pertama kali melakukan scraping, masuk dengan akun DingTalk Anda. |

Instal di Edge:

| Langkah |
| --- |
| 1. Buka Edge, klik menu **⋯** di kanan atas, lalu pilih **Extensions**. |
| 2. Klik **Manage extensions**. |
| 3. Di halaman pengelolaan ekstensi, aktifkan **Developer mode**. |
| 4. Seret **folder Fusion** yang sudah diekstrak ke jendela browser. |
| 5. Dari pop-up ekstensi di bilah alat browser, klik **Fusion** untuk membuka panel samping Fusion. |
| 6. Masuk dengan DingTalk. Setelah masuk, kembali ke AI Table dan aktifkan Web Scraper. |
