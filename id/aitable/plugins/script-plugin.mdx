## Ikhtisar

Plugin Skrip adalah kemampuan terbuka yang disediakan AI Table. Developer dapat membuat Plugin Skrip kustom dengan menulis JS dan membagikannya kepada kolaborator.

Plugin Skrip dapat berinteraksi dengan data tabel dan menjalankan logika bisnis yang kompleks. Berbeda dengan Plugin Kustom, developer Plugin Skrip tidak perlu membangun atau men-deploy halaman terpisah. Anda dapat mengedit, menjalankan, dan mempublikasikan skrip langsung di panel samping kanan AI Table, serta menggunakan API bawaan untuk merender antarmuka plugin yang sederhana.

## Menggunakan Plugin Skrip

DingTalk menyediakan beberapa Plugin Skrip umum untuk skenario tipikal. Plugin ini juga berfungsi sebagai referensi bagi developer.

## Izin plugin

Setelah Anda mempublikasikan Plugin Skrip, pengguna AI Table berikut dapat melihat dan menggunakannya:

1. Saat Izin Lanjutan **nonaktif**: pengguna dengan izin **Edit** atau **Kelola** dapat menggunakan plugin.
2. Saat Izin Lanjutan **aktif**: hanya pengguna dengan izin **Kelola** tingkat tabel yang dapat menggunakan plugin.
