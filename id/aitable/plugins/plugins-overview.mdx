## Ikhtisar

Pusat Plugin AI Table fleksibel dan praktis. **Pustaka plugin yang lengkap** mencakup kebutuhan long-tail setiap tim — unggah lampiran massal, cari dan ganti, deduplikasi, dan banyak lagi.

Platform plugin bersifat terbuka: pengembang yang menguasai kode dapat membuat **plugin skrip** dan **plugin kustom** sesuai kebutuhan mereka sendiri. Dengan plugin, AI Table hampir bisa melakukan apa saja.

## Cara menggunakan plugin

Buka AI Table dan klik ikon **Plugin** di kanan atas. Panel samping kanan menampilkan plugin **unggulan**; klik **Plugin Market** di bagian bawah untuk menjelajahi katalog lengkap.

![](https://img.alicdn.com/imgextra/i2/O1CN01sF6In61fMqdQu4R3V_!!6000000003993-2-tps-1836-1016.png)


![](https://img.alicdn.com/imgextra/i4/O1CN01wZY2N529KV4tzGLib_!!6000000008049-2-tps-1836-1016.png)


### Menggunakan plugin

Contoh: Anda ingin mengunggah lampiran resume secara massal ke AI Table Pustaka Resume. Temukan plugin unggah massal di pusat plugin untuk mempercepatnya.

1. Klik tombol **Plugin** di kanan atas > daftar plugin, lalu klik **Plugin Market** di bagian bawah.
2. Cari **unggah massal** untuk menemukan plugin yang Anda inginkan.

![](https://img.alicdn.com/imgextra/i4/O1CN01eFBjN31OHwvmR8cbO_!!6000000001681-2-tps-1836-1016.png)

3. Arahkan kursor ke plugin dan klik **Tampilan** (atau klik area kosong) untuk membaca pengantar lengkap plugin.
4. Arahkan kursor ke plugin dan klik **Gunakan**. Panel konfigurasi terbuka di panel samping kanan.

### Membagikan plugin

1. **Rekomendasikan**: pada langkah 3 di atas, saat melihat pengantar plugin, klik **Bagikan** untuk menyalin tautan plugin yang bisa dikirim ke rekan tim.

![](https://img.alicdn.com/imgextra/i3/O1CN01ZeiUfN1HV2wjTcGee_!!6000000000762-2-tps-1836-1016.png)

2. **Penerima**: buka tautan 🔗 di browser, klik **Coba di DingTalk AI Table**, dan plugin terbuka dalam templat contoh yang bisa Anda gunakan untuk bereksperimen.

### Sematkan plugin

Untuk plugin yang sering Anda gunakan di AI Table ini, sematkan ke panel samping kanan untuk akses cepat. Arahkan kursor dan klik ikon sematkan.

![](https://img.alicdn.com/imgextra/i4/O1CN01yJn1FD1bsDIOuV3h5_!!6000000003520-2-tps-1836-1016.png)


### Menghapus plugin

Pada daftar **Digunakan**, klik **Lainnya > Hapus dari daftar** di sebelah kanan plugin untuk menghapusnya. Untuk menggunakannya kembali, Anda perlu mengaktifkannya lagi.

![](https://img.alicdn.com/imgextra/i1/O1CN01M97GUc1JVcfzRNl9F_!!6000000001034-2-tps-1836-1016.png)


## Izin plugin

Saat Izin Lanjutan **nonaktif**: siapa pun dengan izin **Edit** atau **Kelola** dapat menggunakan plugin.

Saat Izin Lanjutan **aktif**: hanya pengguna dengan izin **Kelola** tingkat tabel yang dapat menggunakan plugin.
