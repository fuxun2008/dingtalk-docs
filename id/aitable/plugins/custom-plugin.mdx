## Ikhtisar

Plugin panel samping adalah kemampuan terbuka yang disediakan AI Table. Pengembang dapat memperluas AI Table dengan membangun Plugin Kustom mereka sendiri.

Plugin berjalan di panel samping kanan AI Table dan dapat berinteraksi dengan data tabel untuk menerapkan logika bisnis yang kompleks.

Plugin menggunakan arsitektur dua halaman:

- **Script Service**: berjalan di Web Worker dan berkomunikasi dengan model data AI Table.
- **Sidebar UI**: berjalan di iframe panel samping, merender antarmuka pengguna, dan menangani interaksi.

## Izin plugin

Setelah Anda memublikasikan Plugin Kustom, pengguna AI Table berikut dapat melihat dan menggunakannya:

1. Saat Izin Lanjutan **nonaktif**: pengguna dengan izin **Edit** atau **Kelola** dapat menggunakan plugin.
2. Saat Izin Lanjutan **aktif**: hanya pengguna dengan izin **Kelola** tingkat tabel yang dapat menggunakan plugin.
