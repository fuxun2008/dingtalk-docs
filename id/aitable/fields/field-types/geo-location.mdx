# 1 Ikhtisar

Gunakan bidang **lokasi** AI Table untuk mencatat posisi dengan cepat — masukkan secara manual, cari lokasi apa pun, atau tangkap lokasi real-time di perangkat seluler.

**Skenario umum**: menangkap lokasi real-time di perangkat seluler untuk memverifikasi inspeksi, presensi, dan aktivitas sejenis.

# 2 Dasar-dasar

Pada tampilan kisi, klik ➕ **Tambah bidang** di kanan atas bilah alat, lalu pilih **Lokasi** di bawah tipe bidang. Tersedia dua metode input: **lokasi apa pun** atau **hanya real-time seluler**.

Pada **tampilan formulir**, pilih **Lokasi** dari daftar pertanyaan, lalu aktifkan **hanya real-time seluler** untuk mengumpulkan lokasi melalui formulir.

Dengan **lokasi apa pun**, klik ganda pada sel, ketik di bilah pencarian, pilih hasil, lalu konfirmasi di kanan bawah.

Dengan **hanya real-time seluler**, buka detail rekam atau tautan formulir di perangkat seluler, lalu **ketuk untuk melokasikan**.
