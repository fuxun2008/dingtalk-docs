# 1 Ikhtisar

Gunakan bidang URL untuk memasukkan tautan beserta teks tampilan secara cepat — klik untuk membuka halaman.

# 2 Dasar-dasar

## 2.1 Menambah bidang URL

1. Klik + di kanan atas batang judul.
2. Klik "Tipe bidang".
3. Pilih **URL**.

## 2.2 Mengedit URL

1. Klik dua kali pada sel.
2. Pada kotak teks bagian atas, masukkan **teks tampilan**.
3. Pada kotak teks bagian bawah, masukkan **URL** yang akan dibuka.
4. Klik Simpan.

# 3 FAQ

- **T: Apakah satu sel dapat menyimpan beberapa URL?**

  J: Tidak — setiap sel hanya menyimpan satu URL.
