# 1 Ringkasan

Tanda tangan adalah alat untuk menggambar gambar tanda tangan. Alat ini bukan tanda tangan elektronik menurut hukum tanda tangan elektronik mana pun dan **tidak memiliki kekuatan hukum** — hanya untuk keperluan pencatatan.

# 2 Dasar

Di bagian kanan atas Batang judul, klik ➕ Tambah bidang, lalu pilih **Tanda tangan** di bawah jenis bidang.

**Klik dua kali sebuah Sel** untuk membuka papan tanda tangan. Klik **Bersihkan** di kanan atas untuk mengulang, atau **Konfirmasi** di kanan bawah untuk menyimpan.
