Gunakan bidang **Angka** di AI Table untuk menyimpan nilai numerik apa pun — kuantitas, volume penjualan, jumlah hari kehadiran, dan lainnya.

## Menambahkan bidang angka

1. Klik + di kanan atas bilah judul.
2. Pilih **Angka**.

## Mengatur format angka

- Aktifkan atau nonaktifkan pemisah ribuan.
- **Format tampilan**: bilangan bulat, desimal, atau persentase.
- Pilih gaya pemisah ribuan dan desimal.
- **Singkatan**: mempersingkat angka yang sangat besar.
- Aktifkan **larang angka negatif** — saat aktif, angka negatif tidak dapat dimasukkan.

## Menampilkan mata uang

Untuk menampilkan mata uang seperti ¥1.240,88, gunakan tipe bidang [Mata uang](/aitable/fields/field-types/currency).

## Mengatur nilai default

Atur angka default untuk catatan baru.

## Aritmetika sebaris

Bidang Angka dan Mata uang menerima ekspresi sederhana `+ - * /` saat diedit — berguna untuk perhitungan cepat.

Contoh: empat rekan kerja membagi makan siang seharga ¥392 — ketik `392 / 4` di dalam sel.
