# Ringkasan

**Sinkronisasi**: dengan [Tautan Satu Arah](/id/aitable/fields/field-types/one-way-link) atau [tautan dua arah](/id/aitable/fields/field-types/two-way-link), Anda menghubungkan tabel A dan B. Bidang tautan hanya menampilkan **Bidang utama**. Untuk memunculkan **bidang lain** dari A di dalam B, gunakan **referensi tertaut**.

**Agregasi**: saat menarik nilai dari A ke B, bidang referensi tertaut juga dapat mengagregasinya — nilai asli, tanpa duplikat, jumlah, dan sebagainya.

# Dasar

## Menambahkan bidang

Klik ➕ di kanan atas bilah judul AI Table, lalu pilih **Referensi tertaut** di bawah jenis bidang.

## Mengonfigurasi referensi tertaut

**Pilih bidang tautan**: hanya **bidang Tautan Satu Arah / dua arah** di tabel saat ini yang tersedia, karena referensi tertaut bergantung pada bidang tautan.

**Pilih bidang untuk direferensikan**: hanya bidang dari tabel sumber yang tertaut. Contoh: jika bidang tautan mengarah ke tabel A, referensi hanya dapat memilih bidang di A.

**Agregasi**:

| Agregasi | Deskripsi |
| ------ | ---------------------- |
| Asli | Mereferensikan data Kolom secara langsung |
| Tanpa duplikat | Menghapus duplikat dari nilai asli |
| Jumlah | Menjumlahkan nilai asli |
| Rata-rata | Rata-rata dari nilai asli |
| Maks | Nilai terbesar dari nilai asli |
| Min | Nilai terkecil dari nilai asli |
| Hitung angka tidak kosong | Jumlah nilai numerik yang tidak kosong |
| Hitung nilai tidak kosong | Jumlah nilai tidak kosong, baik numerik maupun teks |
| Hitung berbeda | Jumlah setelah penghapusan duplikat |
| Jumlah baris | Jumlah Rekaman sumber |
| Gabungkan sebagai teks | Menggabungkan nilai yang ditampilkan dengan pemisah koma |

## Mengelola dan mengedit bidang

Klik dua kali judul bidang atau klik menu tarik-turun untuk menyalin, menempel, membekukan, dan sebagainya.
