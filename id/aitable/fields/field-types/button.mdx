# 1 Ikhtisar

Di AI Table, bidang Button dapat berfungsi sebagai **pemicu otomatisasi**. Buka tabel, klik tombol, dan tindakan yang telah diatur langsung berjalan.

**Skenario umum**:

- **Notifikasi** — pada alur kerja perbaikan, klik tombol untuk mengirim tiket perbaikan dan memberi notifikasi kepada teknisi yang ditugaskan.
- **Pembuatan grup** — pada operasional toko, klik tombol untuk membuat grup obrolan dan menuliskan kembali ID grup ke dalam tabel.
- **Alur informasi** — pada penerimaan produk, klik tombol untuk mengonfirmasi kickoff: memperbarui status tabel permintaan menjadi "Kicked off" dan menambahkan rekaman baru pada tabel manajemen proyek.

# 2 Dasar

Klik ➕ di sebelah kanan bilah judul untuk **membuat bidang**, lalu pilih **Button** di bawah tipe bidang. Pada panel konfigurasi, atur nama bidang, label tombol, warna tombol, dan toast keberhasilan.

Tindakan yang berjalan setelah klik dikonfigurasikan melalui **otomatisasi**. Otomatisasi yang tersedia mencakup tindakan umum (operasi dasar, alur kontrol, permintaan HTTP), kapabilitas AI, dan aplikasi bisnis. Lihat referensi tindakan otomatisasi.

Setelah konfigurasi, klik **Simpan dan aktifkan** di kanan atas. Klik **Riwayat proses** untuk memeriksa proses yang lampau.

# 3 Skenario dan langkah

## 3.1 Klik tombol untuk mengirim notifikasi dengan tautan

Contoh: alur kerja perbaikan.

### 3.1.1 Tampilannya

**Pengirim:**

Pada tabel teknisi, tugaskan tiket perbaikan kepada teknisi yang belum memiliki tugas, lalu klik **Button** untuk memberi notifikasi kepada mereka.

**Teknisi:**

Setelah ditugaskan, Anda menerima notifikasi berikut. Klik **Tampilan** untuk berpindah ke layar di atas, lalu klik **Perbaikan sedang berlangsung** untuk melihat detail permintaan.

### 3.1.2 Konfigurasi

Atur nama tombol.

Pilih penerima, lalu atur judul dan isi notifikasi.

## 3.2 Klik tombol untuk membuat grup

Contoh: pembuatan grup per toko.

### 3.2.1 Tampilannya

Klik tombol buat-grup, dan grup baru muncul di daftar obrolan Anda.

### 3.2.2 Konfigurasi

Atur nama tombol.

Atur nama grup, tipe, anggota, dan grup target.

Sinkronkan ID grup baru kembali ke bidang Grup.

## 3.3 Klik tombol untuk mengedit rekaman

Contoh: kickoff proyek.

### 3.3.1 Tampilannya

Klik **Konfirmasi kickoff**, status berubah menjadi **Kicked off**, dan baris baru tersinkron ke dalam tabel manajemen proyek.

### 3.3.2 Konfigurasi

Atur bidang tombol.

Pilih tabel tujuan dan petakan bidang yang disinkronkan.

Atur pembaruan, arahkan ke rekaman yang memicu tombol, lalu tentukan apa yang akan diubah.

# 4 Otomatisasi tombol vs otomatisasi kondisi

## 4.1 Perbedaan utama

| Dimensi | Otomatisasi tombol | Otomatisasi kondisi |
| --------- | ----------------- | -------------------- |
| Pemicu | Manual (klik) | Sistem (saat kondisi terpenuhi) |
| Kontrol | Diotorisasi pengguna | Digerakkan aturan |
| Waktu | Segera (keputusan manual) | Real-time / berkala (tanpa campur tangan manusia) |
| Fleksibilitas | Sekali jalan / massal | Otomatis |

## 4.2 Kapan memilih tombol daripada kondisi

| Skenario | Contoh | Nilai |
| -------- | ------- | ----- |
| Operasi sensitif yang butuh konfirmasi manusia | Persetujuan pembayaran | Menghindari kerugian akibat kesalahan sistem |
| Kasus bisnis dinamis | "Eskalasi mendesak" pada tiket dukungan, pengecekan ulang manual masalah stok | Penilaian manusia mengisi celah aturan |
| Domain dengan kepatuhan tinggi | Resep medis, tanda tangan elektronik pada dokumen hukum | Jejak audit dengan atribusi klik |
| Tugas sensitif sumber daya | Pembuatan grup massal, email massal | Menghindari pemborosan sumber daya pada otomatisasi berfrekuensi tinggi |

## 4.3 Kapan memilih kondisi daripada tombol

| Skenario | Contoh | Nilai |
| -------- | ------- | ----- |
| Real-time tinggi | Peringatan stok / harga valas | Bereaksi seketika |
| Operasi standar berulang | Sinkronisasi status pesanan | Menghemat waktu peninjauan |
| Alur terstandarisasi tanpa input manusia | Sinkronisasi absensi, pesan sambutan grup | Cepat dan menghemat waktu peninjauan |

# 5 FAQ

- T: Operasi apa saja yang didukung bidang Button?

  J: Semua tindakan otomatisasi.
- T: Apakah bidang Button dapat **disalin**?

  J: Ya, tetapi hanya judul, label, dan warna yang tersalin; otomatisasinya tidak.
- T: Siapa yang dapat mengonfigurasi atau mengeklik bidang Button?

  J: **Konfigurasikan** — tanpa izin lanjutan, pemilik dan pengguna dengan akses **kelola / edit** dapat mengonfigurasi. Dengan izin lanjutan aktif, hanya pemilik dan pengguna **kelola** yang dapat melakukannya; pengguna **edit** dapat melihat konfigurasi tetapi tidak dapat memodifikasinya.

  **Klik** — saat tombol dapat diklik, siapa pun yang dapat melihat bidang tersebut dapat mengekliknya.
- T: Bagaimana cara merekam siapa yang mengeklik tombol?

  J: Atur sebuah otomatisasi: picu pada **Saat tombol diklik**, gunakan tindakan **Perbarui rekaman**, lalu tuliskan **pengeklik tombol** ke bidang anggota.

  **Catatan**: cara ini hanya menyimpan pengeklik terbaru. Untuk riwayat lengkap, lihat riwayat revisi rekaman.
