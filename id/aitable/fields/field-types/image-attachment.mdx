## Gambar dan lampiran

Bidang **Gambar dan lampiran** menyimpan file langsung di dalam sel — foto lokasi, gambar desain, kontrak PDF, hingga laporan Excel.

Bidang ini cocok untuk manajemen aset (foto peralatan), pengarsipan kontrak (dokumen hasil pindai), persetujuan biaya (unggah faktur), dan lainnya — lengkap dengan pratinjau online dan pengelolaan massal.

### Menambahkan bidang

Di tampilan kisi, buat kolom untuk file dengan cepat:

1. Klik + di sebelah kanan header.
2. Di bagian **Bidang standar** pada menu dropdown, pilih **Gambar dan lampiran**.
3. Masukkan nama bidang (misalnya "Foto aset" atau "File terkait"), lalu simpan.

### Mengunggah dan mengelola file

Setelah membuat bidang, unggah file dengan berbagai cara:

#### 1. Unggah

Klik area kosong pada sel untuk membuka panel unggah.

- **Unggah lokal**: pilih file dari komputer atau galeri ponsel.
- **Seret dan lepas**: seret file dari desktop langsung ke dalam sel (mendukung banyak file).

#### 2. Pratinjau dan unduh

- **Pratinjau online**: klik nama file atau thumbnail di sel untuk melihat gambar, memutar video, atau membuka dokumen di jendela besar — tanpa perlu mengunduh.
- **Pratinjau mandiri**: klik **Pratinjau** di sebelah kanan sel untuk membukanya di plugin terpisah.

### Mengunduh lampiran

Buka menu di kanan atas — **Ekspor sebagai** → **Ekspor sebagai Excel** — lalu pilih opsi ekspor lampiran pada dialog.

### Lanjutan — gunakan sebagai sampul tampilan

Di tampilan **kanban** atau **galeri**, gambar pada bidang lampiran dapat diatur sebagai sampul kartu agar tampilan lebih menarik.

1. Beralih ke tampilan **kanban** atau **galeri**.
2. Klik **Pengaturan** di kanan atas.
3. Di bagian **Sampul**, pilih bidang Gambar dan lampiran yang sesuai.
4. Setelah diatur, kartu akan menggunakan gambar pertama dari bidang tersebut sebagai sampul.

# FAQ

- **T: Berapa banyak lampiran yang dapat ditampung sebuah tabel?**
  - Tidak terbatas.
- **T: Berapa banyak lampiran per sel?**
  - Hingga 100.
- **T: Jenis file apa saja yang didukung?**
  - Tidak ada batasan.
- **T: Berapa batas ukuran per file?**
  - 3 GB.
- **T: Mengapa unggahan terkadang gagal?**
  - Lampiran menggunakan penyimpanan organisasi. Kemungkinan penyebabnya:
  - Organisasi pemilik tabel kehabisan penyimpanan — unggahan ke tabel pemilik tersebut akan gagal.
  - Ada masalah jaringan saat mengunggah.
