# 1 Ikhtisar

Gunakan bidang **Alamat** di AI Table untuk memilih lokasi secara manual dalam format **provinsi / kota / kecamatan (— jalan)**.

# 2 Dasar-dasar

**Menambahkan alamat di tampilan kisi**

1. Klik + di kanan atas bilah judul.
2. Klik **Tipe bidang**.
3. Pilih **Alamat**.

**Mengatur format alamat**

Pada dropdown format, pilih **Provinsi / kota / kecamatan** atau **Provinsi / kota / kecamatan — jalan**.

**Provinsi / kota / kecamatan** hanya memungkinkan responden memilih dari daftar wilayah bawaan.

**Provinsi / kota / kecamatan — jalan** juga memerlukan teks jalan secara bebas.

**Menambahkan alamat di tampilan formulir**

1. Pilih **Alamat** dari daftar pertanyaan di sebelah kiri.
2. Pilih **format** dari dropdown di bawah pertanyaan.
