# Ikhtisar

Gunakan bidang email di AI Table untuk memvalidasi format dan menjaga data tetap rapi.

# Dasar

Tambahkan bidang: di kanan atas batang judul AI Table, klik + lalu pilih Email pada tipe bidang.

Format email divalidasi saat Anda mengetik.

# FAQ
