# 1 Ikhtisar

Gunakan bidang ini untuk **mengumpulkan nomor identitas** dengan **validasi** bawaan — nomor yang tidak valid akan ditandai dan tidak dapat disimpan.

# 2 Dasar-dasar

## 2.1 Menambahkan bidang di tampilan kisi

Klik ➕ di kanan atas batang judul AI Table, lalu pilih **Nomor identitas** pada jenis bidang.

## 2.2 Menambahkan bidang di tampilan formulir

Pada daftar pertanyaan di sebelah kiri, pilih **Nomor identitas** untuk mengumpulkan jawaban di formulir.

## 2.3 Mengelola dan mengedit bidang

Klik dua kali judul bidang atau klik menu dropdown untuk menduplikat, menghapus, membekukan, dan tindakan lainnya.

# 3 Skenario

Bidang nomor identitas terutama digunakan untuk pengumpulan informasi. Gunakan tampilan formulir untuk melindungi privasi responden. Untuk mengumpulkan melalui tampilan kisi, aktifkan **izin lanjutan**: atur **izin edit** peran ke "catatan yang terkait dengan anggota" dan atur catatan lainnya menjadi **tanpa akses**.
