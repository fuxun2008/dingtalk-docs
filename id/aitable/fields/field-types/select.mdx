Gunakan bidang **Pilihan tunggal** dan **Pilihan ganda** AI Table untuk mengelompokkan atau menandai rekaman. **Pilihan tunggal** mengizinkan satu opsi per sel; **Pilihan ganda** mengizinkan banyak opsi.

Gunakan **Pilihan tunggal** untuk kategori eksklusif dan **Pilihan ganda** untuk penandaan.

Sebagai contoh, gunakan **Pilihan tunggal** untuk bidang **Prioritas** dengan opsi P1, P2, dan P3, karena setiap tugas hanya memiliki satu prioritas.

Gunakan **Pilihan ganda** untuk bidang **Kategori ulasan** dengan opsi Fitur, Harga, Kualitas, dan Layanan, karena setiap ulasan dapat membawa banyak tag.

## Menambahkan bidang pilihan tunggal atau ganda

1. Klik + di kanan atas bilah judul.
2. Pilih **Pilihan tunggal** atau **Pilihan ganda**.

## Mengonfigurasi pilihan tunggal atau ganda

### Menambahkan opsi

Klik **Tambah opsi** untuk menambahkan satu per satu, atau **Edit massal** untuk menambahkan atau mengedit banyak opsi sekaligus.

### Mengatur ulang urutan opsi

Seret opsi untuk mengatur ulang urutannya, atau susun ulang baris di **Edit massal**.

### Menghapus opsi

Klik ikon di sebelah kanan opsi untuk menghapusnya.

### Warna opsi

Klik ikon warna di sebelah kiri opsi untuk mengubahnya.
