Setiap kolom di AI Table disebut **bidang**. Bidang menentukan tipe dan format setiap kolom sehingga data Anda tetap terstruktur dan konsisten.

## Pengenalan tipe bidang AI Table dalam 2 menit

## Bidang utama

Kolom pertama di AI Table adalah **bidang utama** — kolom ini tidak dapat dihapus atau disembunyikan. Pada AI Table versi terbaru, bidang utama bertipe **Doc** secara default. Lihat [Tabel sebagai dokumen](/id/aitable/fields/field-types/table-as-doc) untuk detailnya.

## Dasar-dasar

### Menambahkan bidang

#### **Menambahkan bidang / kolom di tampilan kisi**

1. Klik ikon ➕ di sebelah kanan bilah judul.
2. Ketik nama bidang lalu pilih tipenya.

#### **Menambahkan bidang di tampilan lain**

1. **Tampilan Kanban** — klik **Konfigurasi kartu**, lalu tambahkan bidang di bagian bawah dialog.
2. **Tampilan Galeri** — klik **Konfigurasi galeri**, lalu tambahkan bidang di bagian bawah dialog.
3. **Tampilan Kalender / Gantt** — klik **Kelola bidang**, lalu tambahkan bidang di bagian bawah dialog.

#### **Menambahkan bidang di tampilan formulir**

Saat menambahkan pertanyaan, klik **tipe bidang** yang relevan untuk menyisipkannya, lalu beralih ke **Mode edit** untuk mengeditnya.

Untuk detail formulir, lihat [Dasar-dasar formulir](/id/aitable/forms/form-basics).

### Mengedit bidang

Ada dua cara untuk mengedit bidang yang sudah ada:

1. **Klik dua kali** judul bidang untuk membuka editor.
2. **Klik kanan** judul bidang — atau arahkan kursor lalu klik dropdown — dan pilih **Edit bidang / kolom** di menu.

### Menyembunyikan / menampilkan bidang

Buka [Kelola bidang](/id/aitable/fields/field-management), lalu klik ikon di sebelah kanan nama bidang untuk **menampilkan / menyembunyikannya**.

Atau, klik kanan judul bidang (atau arahkan kursor lalu klik dropdown) dan pilih **Sembunyikan bidang / kolom**.

### Membekukan bidang / kolom

Klik kanan judul bidang (atau arahkan kursor lalu klik dropdown) dan pilih **Bekukan hingga bidang / kolom ini**.

Arahkan kursor ke **garis pembeku** lalu seret ke kiri / kanan untuk menyesuaikan rentang yang dibekukan.

Catatan: **bidang utama** dibekukan secara default dan tidak dapat dilepas bekunya.

### Mengatur ulang bidang

**Tampilan kisi** mendukung pengaturan ulang.

Seret **judul bidang** ke kiri / kanan untuk mengatur ulang.

**Mengatur ulang di tampilan lain**

Klik **Kelola bidang** (atau **Konfigurasi kartu** / **Konfigurasi galeri**), tahan bidang di sebelah kiri, lalu seret.

Catatan: bidang utama tidak dapat dipindahkan.

### Mengedit deskripsi bidang

Klik kanan judul bidang (atau arahkan kursor lalu klik dropdown) dan pilih **Edit deskripsi bidang / kolom**. Ketik deskripsi lalu klik **OK**.

### Menetapkan nilai default bidang

1. Klik dua kali judul bidang / kolom untuk membuka editor.
2. Ketik nilai default di kolom input atau dropdown.
3. Klik konfirmasi untuk menyimpan.

Nilai default berlaku untuk **seluruh tabel**, bukan hanya tampilan saat ini.

Sebagian besar bidang standar mendukung nilai default: judul, angka, mata uang, tanggal, pilihan tunggal, pilihan ganda, peringkat, progres, anggota, obrolan grup, URL, alamat, barcode, kotak centang, departemen, lokasi, telepon, email, dan teks kaya.

## FAQ

#### **T: Mengapa saya tidak bisa menghapus atau menyembunyikan bidang pertama?**

J: Bidang pertama AI Table adalah **bidang utama** — bidang ini tidak dapat dihapus, dipindahkan, diganti, atau disembunyikan, dan bidang lain tidak dapat dijadikan bidang utama.

#### **T: Bagaimana cara menampilkan bidang yang tersembunyi?**

J: Klik **Kelola bidang** di atas tabel, lalu klik ikon di sebelah kanan nama bidang untuk menampilkan / menyembunyikannya.

#### **T: Bagaimana cara melepas beku sebuah bidang?**

J: Seret **garis pembeku** untuk menyesuaikan rentang yang dibekukan. Bidang utama tidak dapat dilepas bekunya, dan melepas beku hanya satu bidang belum didukung.

#### **T: Bisakah saya meratakan nilai ke tengah pada bidang AI Table?**

J: Belum bisa.
