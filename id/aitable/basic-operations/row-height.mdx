Gunakan **Tinggi baris** pada tampilan kisi untuk menampilkan lebih banyak informasi per baris.

**Catatan**: tinggi baris **hanya tersedia pada tampilan kisi** — jenis tampilan lain tidak mendukungnya.

## Mengatur tinggi baris

Pada tampilan kisi, klik **Tinggi baris** di bilah alat, lalu pilih tinggi yang diinginkan.
Tersedia empat opsi dengan tinggi yang bertambah: **Standar**, **Sedang**, **Tinggi**, dan **Sangat tinggi**.

# FAQ

#### T: **Apakah AI Table mendukung pembungkusan teks?**

J: Belum tersedia saat ini.

#### T: **Bisakah saya mengatur tinggi hanya satu baris?**

J: Tidak. Anda hanya dapat memilih **Standar / Sedang / Tinggi / Sangat tinggi**, dan pilihan tersebut berlaku untuk semua baris.

#### T: **Bisakah saya menyeret untuk mengatur tinggi baris secara kustom?**

J: Tidak. Keempat preset tersebut adalah satu-satunya opsi — tidak ada penyeretan untuk mengubah ukuran, dan tidak ada tinggi lainnya.
