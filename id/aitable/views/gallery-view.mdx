Tampilan Galeri menampilkan bidang lampiran — gambar, PDF, dan file secara sekilas. Gunakan untuk etalase produk, toko, album pribadi, catatan perjalanan, dan jurnal foto.

## Konfigurasi Galeri

Klik **Konfigurasi Galeri**, lalu pilih bidang lampiran sebagai sampul.

Secara default, sampul menggunakan **Crop**. Beralih ke **Fit** bila diperlukan.
