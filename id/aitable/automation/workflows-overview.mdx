# Apa fungsinya

Alur kerja otomatisasi adalah aturan yang Anda tetapkan sebelumnya untuk AI Table dan berjalan secara otomatis. Atur sebuah **pemicu** dan sebuah **tindakan**, lalu AI Table menjalankan langkah berikutnya saat data berubah.

# Cara menggunakan

### Buat alur kerja

1. **Mulai dari kosong**: klik **Otomatisasi** di kanan atas AI Table → **Mulai dari kosong**.

![](https://img.alicdn.com/imgextra/i2/O1CN01WUWXDY21zhmgSkLNg_!!6000000007056-0-tps-3868-2358.jpg)

2. **Dari templat**: klik **Otomatisasi** di kanan atas → pilih sebuah templat.

   (Cocok untuk pengguna baru. Templat sudah dilengkapi pemicu dan tindakan preset, dan Anda dapat mengeditnya di atas dasar itu.)

![](https://img.alicdn.com/imgextra/i3/O1CN01l1A1My1GDM1xqegHi_!!6000000000588-0-tps-3868-2360.jpg)

3. **Pembuatan dengan satu kalimat AI**

   Fitur ini masih dalam beta tertutup. Kirim formulir untuk mengajukan: [Ajukan](https://docs.dingtalk.io/notable/share/form/v012M9qP57dYWjdmO01_K8AOC4s_odw3ubp "Apply")

![](https://img.alicdn.com/imgextra/i4/O1CN01TV3qtm28Yrt2G6CR5_!!6000000007945-0-tps-3868-2356.jpg)

### Konfigurasikan alur kerja

1. Konfigurasikan pemicu dan tindakan.

![](https://img.alicdn.com/imgextra/i3/O1CN01g0N1Op1f3c03ofDhZ_!!6000000003951-0-tps-3868-2358.jpg)

# Kelola otomatisasi

Di AI Table, Anda dapat membuat, mengubah, dan mencari alur kerja.

1. **Manajemen global**

   Klik **Otomatisasi**. Bilah sisi kiri menampilkan semua alur kerja yang terkonfigurasi untuk AI Table ini.

![](https://img.alicdn.com/imgextra/i1/O1CN01ilLQfz1QC77EGOVbe_!!6000000001939-0-tps-3868-2356.jpg)

2. **Log eksekusi**

   Pada editor alur kerja, klik **Log eksekusi** di kanan atas untuk melihat total eksekusi, keberhasilan, dan kegagalan.

![](https://img.alicdn.com/imgextra/i3/O1CN01OhfeTn1sSsrMfhoOb_!!6000000005766-0-tps-3868-2356.jpg)

3. **Aktifkan / nonaktifkan alur kerja**

   Di daftar alur kerja, gunakan sakelar untuk mengubah status: aktif = berjalan, nonaktif = dinonaktifkan.

![](https://img.alicdn.com/imgextra/i4/O1CN01KWgvxE1Yp3iiw5d8u_!!6000000003107-0-tps-3868-2358.jpg)

4. **Edit / salin / hapus alur kerja**

   Pilih sebuah alur kerja → klik **Lainnya** → edit / salin / hapus.

![](https://img.alicdn.com/imgextra/i2/O1CN01d03k5a1buxfijchI5_!!6000000003526-0-tps-3868-2354.jpg)

5.  **Atasi kesalahan**

Klik detail sebuah rekaman eksekusi untuk menyalin kesalahan dengan satu klik dan menelusuri penyebabnya.

![](https://img.alicdn.com/imgextra/i1/O1CN01hiaO8n236PC5ctfZ7_!!6000000007206-0-tps-3864-2356.jpg)

# Penghitungan jumlah eksekusi

Otomatisasi berjalan di DingTalk Connector Platform. Setiap node alur kerja mengonsumsi eksekusi node connection-flow.

### Apa itu hitungan eksekusi node?

**Eksekusi node connection-flow** (atau "eksekusi node") adalah **metrik penagihan komersial** dari DingTalk Connector Platform.

Metrik ini menghitung eksekusi node di seluruh AI Table, bot, persetujuan OA, dan connector platform untuk organisasi saat ini. Pengguna dengan akses developer dapat [lihat detail](https://open-dev.dingtalk.io/fe/connector#/overView "view details") di DingTalk Connector Platform.

### Cara melihat jumlah bulan ini

Buka **Manajemen alur kerja** untuk melihat akumulasi eksekusi organisasi pada bulan tersebut.

### Aturan penghitungan

#### Dihitung

- Node tindakan yang berhasil — 1.
- Panggilan node **Delay** — 1.
- Panggilan node **HTTP request** — 1.
- Node **Branch** — 1 per evaluasi.
- Node **Loop** dihitung sebagai 1 per eksekusi alur kerja, terlepas dari jumlah iterasi. Atur **Iterasi maksimum** dengan cermat.
- Tindakan yang tidak mengembalikan apa pun tetap dihitung sebagai eksekusi yang berhasil (misalnya, kueri direktori tanpa hasil yang cocok tetap dihitung sebagai 1).

#### Tidak dihitung

- Eksekusi acara pemicu.
- Node yang dilewati dan node yang gagal.
- Eksekusi debug.
