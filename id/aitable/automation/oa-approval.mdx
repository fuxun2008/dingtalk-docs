## Skenario

- Manufaktur: penawaran suku cadang — setiap node memerlukan persetujuan internal sebelum lanjut ke tahap berikutnya.
- Admin: permintaan peminjaman peralatan dikirim melalui formulir AI Table → persetujuan OA → saat disetujui, stok otomatis dikeluarkan dan inventaris berkurang.
- Rantai F\&B: setiap langkah pembukaan gerai baru memicu persetujuan sebelum tahap berikutnya.

## Konfigurasikan otomatisasi

Atur pemicu, lalu pilih tindakan **Start OA approval (new)**. Node baru ini mendukung penulisan status kembali.

Pilih formulir persetujuan OA yang akan ditautkan. Anda harus memiliki izin admin OA terlebih dahulu — lihat "Cara mendapatkan izin admin" di bawah.

- Pilih "started by system".
- Atau pilih "started by the button clicker".
- Petakan variabel bidang AI Table ke input formulir. Bidang lanjutan seperti Lampiran dan Departemen didukung.

Untuk menulis kembali status persetujuan ke AI Table, aktifkan **Sync status back to AI Table after approval starts**:

- Pilih tabel tujuan penulisan kembali (biasanya tabel tempat record pemicu berada).
- Pilih bidang yang akan menerima status.

## Pemetaan bidang ke OA

AI Table dan persetujuan OA adalah dua sistem yang berbeda, sehingga tipe bidang harus cocok persis. Jika tidak, persetujuan akan gagal atau masuk dalam keadaan kosong. Tipe yang didukung:

| Bidang OA | Bidang AI Table | Catatan |
| --- | --- | --- |
| Teks satu baris | ✅ Teks | |
| Teks multi-baris | ✅ Teks kaya | Format / gambar dalam teks kaya akan dihapus |
| Angka | ✅ Angka | |
| Pilihan tunggal | ✅ Pilihan tunggal | Opsi harus cocok persis |
| Pilihan ganda | ✅ Pilihan ganda | Opsi harus cocok persis |
| Kartu identitas | ✅ Kartu identitas | |
| Tanggal | ✅ Tanggal | |
| Rentang waktu | ✅ Tanggal | |
| Telepon | ✅ Telepon | |
| Lampiran | ✅ Lampiran / Gambar | Multi-lampiran didukung hingga 10 — kelebihannya tidak disinkronkan |
| Kontak | ⚠️ Hanya kontak internal | Kontak eksternal menghasilkan nilai kosong |
| Gambar | ⚠️ Tidak didukung | Gunakan bidang Lampiran di sisi OA |
| Kontak eksternal | ⚠️ Tidak didukung | |
| Tanda tangan | ❌ Tidak didukung | |
| Kontrol AI | ❌ Tidak didukung | |
| Berjenjang / Kategori | ❌ Tidak didukung | |
| Detail / Tabel | ❌ Tidak didukung | |
| Jumlah | ❌ Tidak didukung | |

## FAQ

- **Bagaimana cara membuat persetujuan OA?**
  - Lihat: [Persetujuan OA — buku panduan DingTalk](https://docs.dingtalk.io/i/p/Y7kmbokZp3pgGLq2/docs/lo1YvX0prG98keM3X7aqVPw7xzbmLdEZ "OA approval — DingTalk handbook")
- **Bagaimana cara mendapatkan izin admin OA?**
  1. Temukan admin organisasi Anda di **Kontak** → **Direktori orang**. Jelaskan alasan Anda membutuhkannya dan minta mereka memberikan **Sub-admin: izin persetujuan OA**.

  2. Admin memberikan izin melalui:
     - Buka [konsol admin DingTalk](https://login.dingtalk.io/oauth2/challenge.htm?redirect_uri=https%3A%2F%2Foa.dingtalk.io%2Fomp%2Flogin%2Fdingtalk_sso_call_back%3Fcontinue%3Dhttps%253A%252F%252Foa.dingtalk.io%252Findex.htm&response_type=code&client_id=dingoaltcsv4vlgoefhpec&scope=openid+corpid&org_type=management#/welcome "DingTalk admin console").
     - Klik **Keamanan & izin** → **Manajemen izin**.

     - Tambahkan Anda sebagai sub-admin dengan cakupan **izin persetujuan OA**.

- **Persetujuan gagal pada suatu bidang — apa yang harus dilakukan?**
  1. Periksa apakah ada bidang wajib yang masih kosong.
  2. Periksa tabel pemetaan di atas — bidang yang direferensikan harus bertipe yang didukung.
- **Saya memiliki 15 lampiran — mengapa hanya 10 yang masuk ke persetujuan OA?**

  Persetujuan OA mendukung hingga 10 lampiran — kelebihannya tidak disinkronkan.
