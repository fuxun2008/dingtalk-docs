## 1 Glosarium

Saat Anda mengklik tombol **+** dalam Otomatisasi AI Table untuk mereferensikan konten, Anda akan menjumpai istilah tertentu. Halaman ini menjelaskan variabel dan bidang yang dapat direferensikan.

### 1.1 Variabel AI Table

Klik **+** di panel kanan untuk menambahkan variabel bidang dari AI Table ini — praktis untuk mengirim daftar nilai bidang kepada seseorang atau untuk menulis kembali ID grup yang dibuat ke dalam sebuah rekaman.

![](https://img.alicdn.com/imgextra/i2/O1CN01Pw4vDo1bd6E4UTNHd_!!6000000003487-0-tps-3024-1704.jpg)


#### 1.1.1 View URL

URL dari sebuah tampilan AI Table. Buka URL untuk langsung menuju tampilan tersebut.

![](https://img.alicdn.com/imgextra/i4/O1CN01WEkSLM1POBwe7JYZn_!!6000000001830-0-tps-3024-1696.jpg)


### 1.2 Variabel rekaman

Variabel ini biasanya muncul ketika langkah sebelumnya berisi rekaman tertentu dan langkah berikutnya mereferensikannya.

#### 1.2.1 Record ID

Pengidentifikasi unik dari sebuah rekaman. Unik dalam satu tabel, tetapi dapat bertabrakan antartabel dalam database yang sama.

![](https://img.alicdn.com/imgextra/i1/O1CN01m5N2zt1iSkaRL8CFo_!!6000000004412-0-tps-3024-1700.jpg)


#### 1.2.2 Pembuat alur kerja

Orang yang mengonfigurasi Otomatisasi ini.

![](https://img.alicdn.com/imgextra/i3/O1CN018Rny1L1Q22OxD5PbI_!!6000000001917-0-tps-3024-1702.jpg)


#### 1.2.3 Waktu pemicu alur kerja

Mencakup hari ini (waktu pemicu), besok (waktu pemicu + 1 hari), dan lusa (waktu pemicu + 2 hari).

![](https://img.alicdn.com/imgextra/i1/O1CN01rjD7B31F9Ozv7o0U1_!!6000000000444-0-tps-3024-1696.jpg)


### 1.3 Bidang Lampiran

Mencakup ukuran, nama, tipe lampiran, dan URL sementara (kedaluwarsa 2 jam setelah dibuat).

![](https://img.alicdn.com/imgextra/i4/O1CN01Jbh3HU1xWcAHd7mPi_!!6000000006451-0-tps-3024-1700.jpg)


### 1.4 Bidang Grup

Gunakan ID grup untuk mengirim pesan ke grup tersebut, atau tulis ID grup ke dalam bidang Grup — ID akan ditampilkan sebagai "tautan kartu grup".

![](https://img.alicdn.com/imgextra/i2/O1CN01HTJrp31xLAGNd04Py_!!6000000006426-0-tps-3024-1700.jpg)


## 2 Kesalahan umum

### 2.1 Tabel telah dihapus — silakan konfigurasi ulang alur kerja

Penyebab: tabel telah dihapus.

Solusi: konfigurasi ulang Otomatisasi, lalu pilih tabel lain.

### 2.2 Rekaman yang ditentukan tidak ada

Penyebab: muncul pada **Perbarui rekaman** ketika rekaman target tidak ada.

Solusi: konfigurasi ulang Otomatisasi.

### 2.3 Bidang telah dihapus

Penyebab: bidang telah dihapus.

Solusi: konfigurasi ulang Otomatisasi, lalu pilih bidang lain.

### 2.4 Tabel telah mencapai batas baris — tidak dapat menambahkan rekaman

Penyebab: jumlah baris mencapai batas per tabel.

Solusi: konfigurasi ulang Otomatisasi, lalu pilih tabel lain.

### 2.5 Alur kerja dinonaktifkan saat berjalan — eksekusi dihentikan

Penyebab: pembuat alur kerja menonaktifkan alur kerja selama eksekusi.

Solusi: aktifkan kembali Otomatisasi sesuai kebutuhan.

### 2.6 Waktu permintaan HTTP habis

Penyebab: permintaan HTTP memiliki batas respons 20 detik — respons yang lebih lama akan dibatalkan.

Solusi: minta pihak upstream untuk merespons lebih cepat — mereka harus merespons dalam 20 detik agar AI Table dapat menerima hasilnya.

### 2.7 Format respons HTTP tidak valid — silakan periksa apakah sesuai dengan format respons permintaan

Penyebab: respons **Kirim permintaan HTTP** secara otomatis menyertakan nilai header Content-Type default yang tidak dapat diurai.

Solusi: hapus nilai header default, lalu coba lagi.

### 2.8 URL permintaan HTTP diblokir — pastikan dapat diakses melalui internet publik

Penyebab: permintaan HTTP tidak mendukung URL intranet.

Solusi: beralih ke URL publik.

### 2.9 Bidang lampiran ini hanya untuk seluler — silakan konfigurasi ulang

Penyebab: bidang lampiran diatur ke "hanya pengambilan foto seluler", yang tidak dapat diubah oleh Otomatisasi.

Solusi: konfigurasi ulang — hapus centang "hanya pengambilan foto seluler" pada bidang, atau pilih bidang lain.
