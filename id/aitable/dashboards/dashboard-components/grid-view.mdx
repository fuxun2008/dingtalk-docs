Sematkan tampilan kisi di dasbor untuk membawa data inti AI Table ke dalam tampilan dasbor. Gabungkan widget kisi dengan bagan analisis (garis, kolom, dan lainnya) untuk presentasi dan pengiriman end-to-end serta tingkatkan kolaborasi lintas modul.

## Menambahkan widget tampilan kisi

Di kiri atas, klik **Tambah bagan**, lalu pilih **Tampilan kisi**.

![](https://img.alicdn.com/imgextra/i2/O1CN01iQv3lg1beTPj39UO8_!!6000000003490-0-tps-376-649.jpg)


## Mengonfigurasi widget tampilan kisi

Konfigurasikan tipe/data dan gaya kustom:

**Data**: pilih sumber — tabel dan rentang data. **Semua data** mengaktifkan filter.

![](https://img.alicdn.com/imgextra/i2/O1CN01ksGV2122IU1UYOZMX_!!6000000007097-0-tps-296-307.jpg)


**Konfigurasi kisi**: grup, pengurutan, tinggi baris, serta bidang yang ditampilkan dan urutannya.

![](https://img.alicdn.com/imgextra/i1/O1CN01nS36oP1j8t1ZqQeal_!!6000000004504-0-tps-287-499.jpg)


**Gaya kustom**: warna latar belakang.

![](https://img.alicdn.com/imgextra/i2/O1CN01ks2oL21nQ4LXrd8OZ_!!6000000005083-0-tps-296-784.jpg)


## Mengelola widget tampilan kisi

Arahkan kursor ke widget untuk menampilkan ikon di kanan atas. Klik ikon tersebut untuk: konfigurasikan, ganti nama, salin, tambahkan ke pusat dasbor, salin sebagai gambar, ekspor sebagai gambar, dan hapus.

![](https://img.alicdn.com/imgextra/i1/O1CN01LBE8nm1whmCXoehWj_!!6000000006340-0-tps-918-336.jpg)


Seret sudut kanan bawah untuk mengubah ukuran. Seret bagian atas untuk memindahkan posisi.

## Hubungan dengan tampilan kisi asli

Widget tampilan kisi yang ditambahkan ke dasbor berhubungan dengan tampilan kisi asli sebagai berikut:

- Widget tidak dapat diedit.
- Saat Anda mengedit sel di tampilan kisi asli, widget diperbarui secara sinkron. "Edit" = tambah/edit/hapus rekam, tambah/edit/hapus bidang.
- Konfigurasinya independen. "Konfigurasi" = filter, grup, urutkan, tinggi baris, lebar kolom, urutan bidang, urutan rekam, dan lainnya.

## FAQ

#### **T: Apakah pengaturan filter/grup di dalam widget memengaruhi tampilan asli?**

J: Tidak. Konfigurasi widget hanya berlaku di dalam dasbor — tampilan asli tidak terpengaruh.

#### **T: Jika dasbor memiliki filter global, data apa yang ditampilkan di widget?**

J: Filter global juga berlaku untuk widget — dan bertumpuk di atas filter milik widget itu sendiri.
