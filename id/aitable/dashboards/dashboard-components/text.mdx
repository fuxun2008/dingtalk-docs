Tambahkan widget teks ke dasbor untuk menyertakan penjelasan tertulis di samping bagan — tampilkan bagan dan deskripsi dalam satu layar, ideal untuk laporan tinjauan dan catatan.

- **Laporan dan retrospektif**: sampaikan kesimpulan, perubahan data, atau anomali secara langsung — tanpa berpindah halaman saat presentasi.
- **Konteks**: jelaskan tujuan bagan, definisi metrik, dan latar belakang lainnya — agar rekan tim memahami lebih cepat.

## Menambahkan widget teks

Di kiri atas dasbor, klik **Tambah bagan**. Pada menu jenis bagan, pilih **Teks**.

![](https://img.alicdn.com/imgextra/i3/O1CN01UNiiYk1FrpPqMY8ec_!!6000000000541-0-tps-380-654.jpg)


## Mengonfigurasi widget teks

Ketik teks di dalam widget. Pilih teks untuk memformatnya — tingkat judul, perataan, ukuran font, dan lainnya.

![](https://img.alicdn.com/imgextra/i3/O1CN01aW5bLc1gxJn0PkxYs_!!6000000004208-0-tps-601-325.jpg)


Buka, edit, atau salin tautan di dalam widget teks.

![](https://img.alicdn.com/imgextra/i3/O1CN01Yf2Nq31gBgb9LVJ0v_!!6000000004104-0-tps-358-318.jpg)


## Mengelola widget teks

Arahkan kursor ke widget untuk menampilkan ikon di kanan atas. Klik ikon tersebut untuk mengonfigurasi, mengganti nama, menyalin, menyalin sebagai gambar, mengekspor sebagai gambar, atau menghapus.

![](https://img.alicdn.com/imgextra/i2/O1CN01JGVYdg25y6rrY3DQA_!!6000000007594-0-tps-545-325.jpg)


Seret sudut kanan bawah widget untuk mengubah ukuran. Seret bagian atas untuk memindahkan posisi.
