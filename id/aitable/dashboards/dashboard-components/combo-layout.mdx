## Ikhtisar

Dasbor menyediakan **widget tata letak kombinasi** — kelompokkan widget bagan melalui seret, pilih manual, atau klik-tambah untuk menyesuaikan tata letak sepenuhnya.

### Skenario umum

Kelompokkan data terkait (misalnya penjualan per wilayah) dalam satu area untuk meningkatkan kepaduan visual dan menampilkan wawasan lebih cepat.

## Cara menggunakan

### Menambah widget tata letak kombinasi

Di kiri atas, klik **Tambah bagan**, lalu pilih **Tata letak kombinasi**.

### Mengonfigurasi tata letak kombinasi

#### Metode 1: Seret

- Seret widget dasbor yang ada ke dalam atau ke luar tata letak kombinasi.

#### Metode 2: Pilih manual

- Untuk bagan di luar tata letak kombinasi: klik ikon di kanan atas, lalu pilih "pindahkan ke dalam" tata letak kombinasi saat ini.
- Untuk bagan di dalam tata letak kombinasi: klik ikon di kanan atas, lalu pilih "pindahkan ke luar" untuk mengeluarkannya dari tata letak kombinasi.

#### Metode 3: Klik-tambah

Arahkan kursor ke dalam area tata letak kombinasi hingga bilah alat atas muncul dengan **Tambah bagan**. Klik **Tambah bagan**, pilih beberapa widget dasbor sekaligus, lalu klik **Pindahkan masuk** untuk membawanya ke dalam tata letak kombinasi.

### Mengelola tata letak kombinasi

#### Bilah alat

Arahkan kursor ke dalam tata letak kombinasi, lalu klik ikon di bilah alat atas:

- **Salin**: menyalin widget tata letak kombinasi saat ini
- **Ubah warna latar belakang**: mengubah latar belakang tata letak kombinasi
- **Tambahkan ke pusat dasbor**: menambahkan widget tata letak kombinasi ke pusat dasbor
- **Salin sebagai gambar**: menyalin tata letak kombinasi sebagai gambar
- **Ekspor sebagai gambar**: mengekspor tata letak kombinasi sebagai gambar
- **Hapus**: menghapus widget tata letak kombinasi

#### Penyesuaian tata letak

- **Ubah ukuran**: pilih widget, lalu seret sudut kanan bawah untuk mengubah ukuran.
- **Ubah posisi**: seret bagian atas widget untuk memindahkannya.
