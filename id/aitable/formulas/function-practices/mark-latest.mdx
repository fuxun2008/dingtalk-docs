#### 2 Cara mengonfigurasi

Tambah bidang Waktu pembaruan terakhir — sistem mencatat waktu pembaruan terbaru dari setiap rekam.

![](https://img.alicdn.com/imgextra/i1/O1CN01jDRIBk1f3c03Q3EKV_!!6000000003951-2-tps-594-669.png)


Tambah bidang pencarian untuk mengambil waktu entri terbaru per orang.

![](https://img.alicdn.com/imgextra/i1/O1CN01x0Mhlf1iSkaPJZPrr_!!6000000004412-2-tps-770-792.png)


Tambah bidang formula untuk menandai rekam terbaru secara visual.

```javascript
IF([Last updated]=[Last filled time],"✅ entri terbaru","")
```
