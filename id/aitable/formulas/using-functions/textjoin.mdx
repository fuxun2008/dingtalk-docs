# 1 Dasar

**TEXTJOIN** menggabungkan beberapa string teks menjadi satu. Berbeda dengan penggabungan sederhana, **TEXTJOIN** memungkinkan Anda menetapkan pemisah dan, secara opsional, melewati sel kosong.

### Sintaks

```text
TEXTJOIN([delimiter], [ignore_empty], [text1], [text2])
```

**delimiter**: string atau referensi ke string yang valid — boleh kosong. Jika kosong, teks digabungkan secara langsung.

**ignore\_empty**: nilai boolean. Jika TRUE, sel kosong dalam argumen teks akan dilewati.

**text1**: teks apa pun — sebuah string atau larik string dari suatu rentang.

**text2**: teks tambahan.

### Contoh

Satu rekaman (baris): Bidang 1 = "Apple", Bidang 2 = "Banana", Bidang 3 = kosong, Bidang 4 = "Grape".

#### Contoh 1: lewati sel kosong

```text
TEXTJOIN(", ", TRUE(), [Field 1], [Field 2], [Field 3], [Field 4])
```

Hasil: **Apple, Banana, Grape**

#### Contoh 2: pertahankan sel kosong

```text
TEXTJOIN(", ", FALSE(), [Field 1], [Field 2], [Field 3], [Field 4])
```

Hasil: **Apple, Banana, , Grape**

Dengan **TEXTJOIN**, gabungkan informasi dari berbagai sumber menjadi string yang mudah dibaca dan diproses — kendalikan pemisah serta penanganan sel kosong.

# 2 Contoh skenario

### 2.1 Menggabungkan bidang

Gabungkan [Name] dan [Status] toko dengan "-".

```text
TEXTJOIN("-",TRUE(),[Name],[Status])
```
