# 1 Dasar

**ISBLANK** adalah fungsi spreadsheet yang umum (Excel, Google Sheets) untuk memeriksa apakah sebuah sel kosong. Fungsi ini mengembalikan **TRUE** saat sel kosong dan **FALSE** saat sel berisi apa pun (termasuk string kosong, hasil formula, dan lainnya).

### Sintaks

```excel formula
ISBLANK(value)
```

- **value**: sel atau ekspresi yang akan diperiksa.

### Contoh

#### Contoh 1: pemeriksaan sel kosong

[Bidang 1] pada catatan pertama tidak memiliki konten.

```excel formula
=ISBLANK([Field 1])
```

Hasil: **TRUE**

#### Contoh 2: sel berisi teks

[Bidang 1] pada catatan pertama berisi **"Hello"**.

```excel formula
=ISBLANK([Field 1])
```

Hasil: **FALSE**
