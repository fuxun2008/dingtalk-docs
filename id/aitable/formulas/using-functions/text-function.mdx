# Dasar

**TEXT** adalah fungsi AI Table yang umum digunakan untuk mengubah angka menjadi teks dengan format tertentu. Tentukan cara angka ditampilkan: tanggal, waktu, mata uang, persentase, dan lainnya.

| Format / placeholder | Arti | Contoh |
| --- | --- | --- |
| \# | Placeholder digit untuk format angka kustom | TEXT(34.56,"##.#")=34.6  TEXT(123.456,"##.##")=123.6  TEXT(78.901,"###.###")=78.901 |
| 0 | Pengisi digit untuk format angka kustom | TEXT(56.7,"0.00")=56.70  TEXT(89.12,"0.00")=89.12  TEXT(3.14,"000.00")=003.14 |
| , | Pemisah ribuan — di antara # atau 0 | TEXT(123456,"0,0")=123,456 |
| % | Persen — gunakan bersama # atau 0 | TEXT(50,"0%")=5000% |
| YYYY | Tahun penuh | TEXT("2023-5-20","YYYY")=2023  TEXT("2023-5-20","YYYY year")=2023 year |
| YY | Tahun singkat | TEXT("2023-5-20","YY")=23  TEXT("2023-5-20","Y")=23 |
| MMM | Bulan penuh | TEXT("2023-5-20","MMM")=May |
| MM | Digit bulan dengan pengisi | TEXT("2023-520","YYYY/MM")=2023/05 |
| M | Digit bulan singkat | TEXT("2023-5-20","M")=5 |
| DD | Hari dengan pengisi | TEXT("2023-5-1","DD")=01 |
| D | Hari singkat | TEXT("2023-5-1","D")=1 |
| DDDD | Nama hari penuh | TEXT("2023-5-1","DDDD")=Monday |
| DDD | Nama hari singkat | TEXT("2023-5-1","DDD")=Mon |
| hh | Jam | TEXT("19:45","hh")=19 |
| mm | Menit | TEXT("19:45","hh:mm")=19:45 |
| ss | Detik | TEXT("19:45:30","ss")=30 |

### Sintaks

```text
TEXT(value, format_text)
```

- **value**: angka atau tanggal yang akan diubah.
- **format\_text**: string format.

### Contoh

#### Contoh 1: format sebagai mata uang

[Field 1] pada record pertama berisi **1234.567**.

```text
=TEXT([Field 1], "$#,##0.00")
```

Hasil: **\$1,234.57**.

#### Contoh 2: format tanggal

[Field 1] pada record pertama berisi **2023-03-15**.

```text
=TEXT([Field 1], "mm/dd/yyyy")
```

Hasil: **03/15/2023**.

Dengan **TEXT**, ubah angka atau tanggal menjadi teks dengan format tertentu — cocok untuk laporan, label, dan output apa pun yang memerlukan format khusus.

# FAQ

- **Q**: Bagaimana cara menghilangkan waktu dan hanya menyimpan tanggal ketika sebuah fungsi mengembalikan yyyy-mm-dd hh:mm?

  **A**: Metode 1: gunakan TEXT(). Buat bidang formula baru: **TEXT([source value], "YYYY-MM-DD")**. Metode 2: klik dua kali bidang formula, ubah tipe bidang menjadi tanggal, lalu pilih format tanggal yang diinginkan.

- **Q**: TEXT() mengembalikan nilai yang tampak seperti angka, tetapi fungsi lain justru menghasilkan kesalahan saat memprosesnya. Mengapa?

  **A**: Output TEXT() berupa teks. Untuk memakainya dalam perhitungan numerik, bungkus terlebih dahulu dengan SUM() atau ABS() agar diubah kembali menjadi angka.
