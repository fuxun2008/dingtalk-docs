# 1 Dasar

**FIND** mencari sebuah nilai mulai dari posisi tertentu dan mengembalikan posisi kemunculan pertamanya. Jika tidak ditemukan, fungsi ini mengembalikan -1.

### Sintaks

```text
FIND(search_value, search_range, [start_position])
```

- **search\_value**: nilai yang dicari — peka huruf besar/kecil.
- **search\_range**: nilai, array, atau bidang tempat pencarian dilakukan.
- **start\_position**: posisi awal. Nilai defaultnya adalah 1.

### Contoh

[Bidang 1] pada rekaman pertama berisi **"Hello World"**.

#### Contoh 1: posisi "World"

```text
FIND("World", [Field 1])
```

Hasil: **7** ("World" dimulai pada posisi 7).

#### Contoh 2: mencari "o" mulai dari posisi 8

```text
FIND("o", [Field 1], 8)
```

Hasil: **9** ("o" pertama dari posisi 8 berada pada posisi 9).

Gunakan **FIND** untuk menemukan substring — berguna untuk pemrosesan dan analisis teks. Perhatikan bahwa **FIND** peka terhadap huruf besar/kecil. Untuk pencarian yang tidak peka huruf besar/kecil, gunakan **SEARCH**.

# 2 Contoh skenario

### 2.1 Pisahkan berdasarkan karakter

Bidang memiliki tiga bagian: tanggal-lokasi-toko. Pisahkan tanggalnya dengan FIND pada "-":

```text title="MID([Record name],FIND(%22-%22,[Record name],1)+1,len([Record name])"
MID([Record name],FIND("-",[Record name],1)+1,8)
```

### 2.2 Periksa berdasarkan karakter

Sesuai ketentuan, deskripsi produk harus menyebutkan alergen — gunakan FIND untuk memeriksanya:

```text
IFERROR(FIND("Allergen",[Product description],1),"Missing allergen note ❌")
```

### 2.3 Ganti sebuah substring

Ganti semua "taste" dengan "flavor" pada deskripsi produk:

```text
REPLACE([Product description], FIND("taste", [Product description]), LEN("taste"), "flavor")
```
