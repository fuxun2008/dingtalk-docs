# 1 Dasar-dasar

**IFERROR** adalah fungsi AI Table yang umum digunakan untuk memeriksa apakah suatu formula atau ekspresi mengembalikan kesalahan. Jika hasilnya berupa kesalahan (#DIV/0!, #VALUE!, #REF!, #NAME?, #NULL!, dan lainnya), fungsi ini mengembalikan nilai yang Anda tentukan. Jika tidak, fungsi ini mengembalikan hasil aslinya.

**Tipe kesalahan yang umum**

| Kesalahan | Arti |
| --- | --- |
| \#N/A | Data tidak ada |
| \#VALUE! | Bentuk formula salah atau tipe nilai salah dalam perhitungan |
| \#REF! | Referensi tidak valid — misalnya, mereferensikan bidang yang telah dihapus |
| \#DIV/0! | Pembagi bernilai 0 (tidak diperbolehkan) |
| \#NUM! | Sebuah angka dalam formula tidak valid |
| \#NAME? | Konten tidak dikenali |
| \#NULL! | Operator rentang salah atau referensi tidak valid |

### Sintaks

```text
IFERROR(value, [if_error])
```

- **value**: sel, formula, atau ekspresi yang akan diperiksa.
- **if\_error**: nilai yang dikembalikan ketika **value** menghasilkan kesalahan.

### Contoh

#### Contoh 1: menangani pembagian dengan nol

[Field 1] pada rekam pertama bernilai **0**.

```text
=IFERROR(5/[Field 1], "Kesalahan")
```

Hasil: **"Kesalahan"** (5/0 memunculkan **#DIV/0!**).

#### Contoh 2: perhitungan normal

[Field 1] pada rekam pertama bernilai **2**.

```text
=IFERROR(5/A2, "Kesalahan")
```

Hasil: **2,5** (5/2 tidak menghasilkan kesalahan). Dengan **IFERROR**, Anda dapat menangani kesalahan formula dengan baik — menjaga tabel tetap rapi sekaligus meningkatkan pengalaman pengguna dan akurasi analisis.

# 2 Contoh skenario

### 2.1 Menandai konten yang hilang

Sesuai ketentuan, deskripsi produk harus menyebutkan alergen. Gunakan FIND untuk memeriksanya.

```text
IFERROR(FIND("Alergen",[Deskripsi produk],1),"Catatan alergen tidak ada ❌")
```
