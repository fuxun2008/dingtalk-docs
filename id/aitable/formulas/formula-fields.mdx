Bidang formula adalah tipe bidang di AI Table — gunakan ekspresi fungsi yang kaya untuk kalkulasi data yang fleksibel.

## Buat bidang formula

Klik ikon **+** di sebelah kanan batang header AI Table, lalu pilih **Formula** sebagai tipe bidang.

![](https://img.alicdn.com/imgextra/i1/O1CN01Qkznx71eXYH9gb8Uf_!!6000000003881-2-tps-1032-474.png)


## Edit formula

Klik **Edit formula** untuk membuka editor formula.

![](https://img.alicdn.com/imgextra/i4/O1CN01GpkxPA1Dy7cv6C9jX_!!6000000000284-2-tps-628-433.png)


Edit formula secara langsung di kotak input bagian atas.

Pada tab **Edit formula**, rujuk bidang atau pilih fungsi berdasarkan kategori.

Pada tab **Buat formula dengan AI**, hasilkan formula dari bahasa alami. Selengkapnya: [Buat formula dengan AI](/id/aitable/formulas/ai-generate-formula).

![](https://img.alicdn.com/imgextra/i2/O1CN01Rgi2P71ulK2HVJLKi_!!6000000006077-2-tps-1080-936.png)


## Konsep

| Istilah | Arti |
| --- | --- |
| Bidang | Nilai sebuah kolom pada baris tertentu, digunakan dalam kalkulasi formula |
| Bidang seluruh kolom | Kumpulan nilai untuk seluruh kolom, digunakan dalam kalkulasi formula |
| Kurung | Digunakan dalam formula untuk merujuk tabel atau bidang AI Table |
| Operator | Simbol logika atau aritmetika yang digunakan dalam formula |
| Fungsi | Menghasilkan output yang diharapkan melalui aturan kalkulasi tertentu |
| Argumen | Angka atau teks yang terlibat dalam kalkulasi formula |
| String | Rangkaian teks yang digunakan dalam kalkulasi formula |
| Array | Kumpulan nilai |

## Operator umum

| Tipe | Operator | Arti |
| --- | --- | --- |
| Aritmetika | `+` | Menambahkan dua nilai |
| | `-` | Mengurangkan dua nilai |
| | `*` | Mengalikan dua nilai |
| | `/` | Membagi dua nilai |
| Penggabungan teks | `&` | Menggabungkan dua string; menggabungkan angka dengan teks jika salah satunya numerik |
| Logika | `>` | Lebih besar dari |
| | `>=` | Lebih besar dari atau sama dengan |
| | `<` | Lebih kecil dari |
| | `<=` | Lebih kecil dari atau sama dengan |
| | `=` | Sama dengan |
| | `!=` | Tidak sama dengan |
| | `&&` | DAN |
| | `|` | ATAU |
