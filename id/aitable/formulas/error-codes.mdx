Ketika sebuah formula tidak valid atau tidak dapat dihitung untuk baris saat ini, kode kesalahan akan muncul di dalam sel.

Kode kesalahan AI Table yang umum:

| Kode kesalahan | Arti | Contoh |
| --- | --- | --- |
| \#NULL! | **Kesalahan null.** Formula berisi operator rentang yang tidak valid atau menentukan dua rentang yang tidak berpotongan. | |
| \#DIV/0! | **Kesalahan pembagian dengan nol.** Pembagian dengan pembagi nol atau merujuk ke sel kosong. | `2/0` |
| \#REF! | **Kesalahan referensi tidak valid.** Kolom yang dirujuk telah dihapus atau diubah. | |
| \#N/A | **Kesalahan nilai tidak tersedia.** Sebuah nilai tidak tersedia untuk fungsi — pencarian tidak menemukan apa pun. | `REGEXEXTRACT("def","a")` |
| \#VALUE! | **Kesalahan nilai.** Tipe argumen atau operand salah — misalnya, teks di tempat yang seharusnya berupa angka. | `SQRT("test")` |
| \#ERROR! | **Kesalahan penguraian formula.** Formula tidak terbentuk dengan benar. | `test formula` |
| \#NUM! | **Kesalahan angka.** Nilai numerik tidak valid, atau hasil terlalu besar atau kecil untuk ditampilkan — misalnya, akar kuadrat dari angka negatif. | `SQRT(-1)` |
| \#NAME? | **Kesalahan nama tidak valid.** Teks yang tidak dikenali dalam formula — salah ketik pada fungsi atau nama. | `SUMMM()` |
| \#TOO\\_LARGE! | **Kesalahan hasil terlalu besar.** Hasil melebihi 200 item — misalnya, pencarian yang mengembalikan lebih dari 200 nilai. | |
| \#MISMATCH\\_TYPE! | **Kesalahan ketidakcocokan tipe.** Tipe hasil tidak sesuai dengan tipe kolom — umum terjadi setelah nilai aslinya diubah. | |
| \#CIRCULAR! | **Kesalahan referensi melingkar.** Formula merujuk, secara langsung atau tidak langsung, ke selnya sendiri. | |
| \#UNSUPPORT! | **Kesalahan fitur tidak didukung.** Sebuah fungsi atau fitur dalam formula belum didukung — misalnya, referensi antar-tabel. | \- |
