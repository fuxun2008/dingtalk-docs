Mengisi otomatis nilai default dalam formulir memungkinkan Anda melakukan hal-hal berikut:

**Isi otomatis nilai default**: saat toko mengirimkan tugas formulir, isi otomatis info toko agar mereka tidak salah ketik.

**Tandai saluran pengiriman**: saat pengguna mendaftar, isi otomatis kolom **Saluran sumber**.

> 📌 Gunakan generator tautan untuk membuat tautan isi otomatis secara massal: [https://store.dingtalk.io/materials/659](https://store.dingtalk.io/materials/659 "https://store.dingtalk.io/materials/659")

## Dasar-dasar

Format:
**Satu pertanyaan**: `<form share link>?prefill_<question name>=<value>`. **Beberapa pertanyaan**: `<form share link>?prefill_<question name>=<value>&prefill_<question name>=<value>`.

Contoh:
[https://docs.dingtalk.io/notable/share/form/v011GXn4BrXGJobODQ4\_hERWDMS\_7LisUkm?prefill\_标题=预设标题&prefill\_单选=选项二](https://docs.dingtalk.io/notable/share/form/v011GXn4BrXGJobODQ4_hERWDMS_7LisUkm?prefill_标题=预设标题&prefill_单选=选项二 "https://docs.dingtalk.io/notable/share/form/v011GXn4BrXGJobODQ4_hERWDMS_7LisUkm?prefill_标题=预设标题&prefill_单选=选项二")

Jenis pertanyaan yang mendukung nilai default: teks, angka, pilihan tunggal, dan pilihan ganda.

| Jenis pertanyaan  | Format                     |
| ----- | ------------------------ |
| Teks    | `<form link>?prefill_Channel=WeChat`  |
| Angka    | `<form link>?prefill_Score=1`   |
| Pilihan tunggal / ganda | `<form link>?prefill_Pick=Sneakers` |

Jika nilai default Anda mengandung karakter khusus, enkode karakter tersebut sesuai tabel berikut:

| Karakter | Terenkode |
| ---- | ------------ |
| Spasi   | %20 atau +      |
| ;    | %3B          |
| :    | %3A          |
| \\[ | %5B          |
| (    | %28          |
| )    | %29          |
| &    | %26          |
| \\\$ | %24          |
| ,    | %2C          |
| ！    | %21          |
| @    | %40          |
| ]    | %5D          |
| \{    | %7B          |
| \}    | %7D          |
| \#  | %23          |

Jika Anda tidak ingin pertanyaan yang telah diisi otomatis tampil di formulir, tambahkan `&hide_<question name>=1` ke tautan. Contoh: menyembunyikan bidang **Peninjau** pada formulir pengiriman konten:

[Form link?prefill\_Reviewer=Kato](https://docs.dingtalk.io/notable/share/form/v011GXn4BrXGJobODQ4_hERWDMS_7LisUkm?prefill_标题=预设标题&prefill_单选=选项二 "Form link?prefill_Reviewer=Kato")[&hide\_ProjectOwner=1](https://docs.dingtalk.io/notable/share/form/v011GXn4BrXGJobODQ4_hERWDMS_7LisUkm?prefill_标题=预设标题&prefill_单选=选项二 "&hide_ProjectOwner=1")

Trik ini juga memungkinkan Anda melacak saluran pengiriman. Misalnya, Anda mengumpulkan masukan tentang suatu acara dan ingin mengetahui saluran mana yang menghasilkan paling banyak pengiriman:

1. Tambahkan pertanyaan bernama **Platform pengiriman**.
2. Buka berbagi formulir, atur audiens, lalu salin tautan berbagi.
3. Tambahkan parameter sumber ke tautan. Jika sumbernya DingTalk:

   `<form link>?prefill_SubmissionPlatform=DingTalk&hide_SubmissionPlatform=1`
4. Bagikan setiap varian ke platform yang berbeda.

Nilai default yang telah diisi otomatis memungkinkan Anda melacak dengan tepat dari mana setiap pengiriman berasal.

## FAQ

#### T: **Apakah nilai default yang telah saya isi akan rusak jika saya mengganti nama pertanyaan?**

J: Ya — tautannya akan rusak. Buat ulang tautan dengan nama pertanyaan yang baru.

#### T: **Mengapa nama orang yang telah diisi otomatis tidak berlaku pada formulir AI Table?**

J: Ada beberapa kemungkinan:

- Nama tersebut duplikat di dalam organisasi.
- Orang tersebut eksternal dan tidak ada di Kontak DingTalk Anda.
- Nama salah eja — periksa kembali.

#### T: **Setelah menetapkan nilai default pada formulir AI Table, apakah setiap responden akan melihatnya?**

J: Ya. Untuk menyembunyikannya, tambahkan `&hide_<question name>=1` ke tautan.

#### T: **Saya menambahkan parameter hide tetapi pertanyaannya masih tampil di formulir. Mengapa?**

J: Kemungkinan bidang tersebut wajib diisi dan nilai default tidak berlaku. Dengan nilai default yang tidak valid, bidang wajib tetap kosong sehingga tidak dapat disembunyikan. Buat ulang nilai default.
