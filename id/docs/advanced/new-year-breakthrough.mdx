Saat memulai kerja di tahun baru, jika ingin meningkatkan nilai diri atau segera meraih pengakuan dari perusahaan, tidak ada salahnya berinisiatif mengobrol dengan atasan. DingTalk Docs menghadirkan **template Peta Pikiran "Percakapan Awal Tahun"** untuk membantu Anda meraih terobosan baru!

Klik [Tiga sudut pandang percakapan awal tahun](https://docs.dingtalk.io/i/templates/186001bc98b2b335260e6a24dba8dbab) untuk mendapatkan template, lalu manfaatkan Peta Pikiran untuk merencanakan isi percakapan secara detail.

Peta Pikiran menyediakan berbagai kemampuan pengeditan yang dapat dikombinasikan secara fleksibel untuk menyusun dan menandai poin penting. Dengan begitu, alur percakapan menjadi lebih jelas dan atasan dapat melihat lebih banyak potensi diri Anda.
