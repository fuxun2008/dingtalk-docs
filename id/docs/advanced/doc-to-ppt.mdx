Masih menggunakan PPT untuk membuat laporan dan presentasi?

Setiap kali membuat PPT,

Anda harus meratakan, menyelaraskan, dan menyesuaikan ukuran,

setelah semua itu, mata pun terasa lelah!

Yang lebih penting, saat membuat satu PPT,

separuh waktu bisa habis hanya untuk memikirkan bentuk penyajiannya,

bahkan sering kali konten kurang, tetapi bentuk yang dipaksakan!

Hari ini DingTalk Docs akan mengajarkan Anda satu trik sederhana.

Dengan Dokumen, Anda tidak hanya bisa lebih fokus pada pembuatan konten,

tetapi juga dapat menampilkan efek seperti PPT saat presentasi!

**Fitur utama yang digunakan: DingTalk Docs - Presentasi - Edit pembagian halaman presentasi**

**Ikuti panduan langkah demi langkah berikut:**

<Note>
1. Setelah menyiapkan konten di DingTalk Docs, klik "Presentasi - simbol dropdown" di pojok kanan atas, lalu pilih "Edit pembagian halaman presentasi"

2. Sesuai alur logika saat presentasi, Anda dapat mengedit konten dokumen melalui beberapa tindakan pemisahan dan penggabungan, sehingga konten dokumen tersusun menjadi kombinasi yang sesuai untuk presentasi dan berbagi

Efek animasinya sebagai berikut:

3. Klik "Putar" di pojok kanan atas untuk melihat pratinjau efeknya

4. Agar presentasi Anda lebih menarik perhatian audiens, gunakan beberapa trik berikut:

Tidak dapat menampilkan pembicara yang tepat saat melapor? Dalam mode presentasi, klik toolbar bawah - [Pengaturan presentasi], ubah nama pembagi, atau atur agar nama pembagi tidak ditampilkan

Khawatir audiens tidak menangkap poin penting konten? Saat presentasi, klik toolbar bawah untuk mengganti gaya Penunjuk Laser, membantu menekankan konten penting

Dengan mengaktifkan mode presentasi menggunakan Dokumen, Anda dapat "melihat Komentar dokumen", berdiskusi dan menganalisis lebih dalam seputar komentar, menyelesaikan perbedaan secara efisien, dan mencapai kesepakatan

Ucapkan selamat tinggal pada PPT, cukup dengan Dokumen!

Sudah paham? Ayo segera gunakan!
</Note>
