Menjelang akhir tahun, apakah Anda pusing memikirkan cara menyusun <strong>laporan akhir tahun yang berkualitas</strong>? Jangan khawatir, **DingTalk Docs hadir dengan penawaran spesial**! Tersedia beragam template laporan akhir tahun untuk berbagai peran dan skenario yang siap Anda gunakan—

## Masih bingung menyusun laporan akhir tahun? DingTalk Docs punya solusinya, 10+ template gratis siap pakai!

Di sisi kiri jendela DingTalk versi desktop, klik [Dokumen] - [Knowledge Base] - [Buat Knowledge Base], lalu pilih [Laporan Akhir Tahun] untuk mendapatkan <strong>10+ template</strong>, termasuk <strong>metode penulisan, template umum, dan template industri</strong>.

Dalam Knowledge Base laporan akhir tahun, template dilengkapi berbagai komponen DingTalk Docs seperti <strong>Sisipkan Tabel, Tugas, blok Sorot, kolom, dan roadmap</strong>. Anda dapat melihat dan mengedit template dengan bebas, sehingga dapat menyusun laporan akhir tahun yang memukau dengan mudah. Jadilah sosok paling produktif di penghujung tahun!
