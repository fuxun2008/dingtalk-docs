## Nilai fitur

Perangkat seluler mendukung tangkapan layar cerdas. Hilangkan batasan layar dan lihat semua data dengan jelas.

## Skenario penggunaan

Saat membagikan tangkapan layar di perangkat seluler, spreadsheet sering terlalu panjang sehingga tidak tertangkap seluruhnya karena keterbatasan ukuran layar ponsel. Bagaimana solusinya? DingTalk Spreadsheet di perangkat seluler mendukung tangkapan layar cerdas, **mendeteksi gerakan tangkapan layar dan menghasilkan gambar data dengan satu klik**, sehingga proses berbagi menjadi lebih praktis.

## Petunjuk penggunaan

1. Di ponsel atau iPad, saat Anda melakukan gerakan tangkapan layar, sistem otomatis mengenali area data pada Lembar Kerja saat ini dan menghasilkan Gambar data.

2. Anda dapat langsung meneruskan Gambar untuk dibagikan, atau menyimpannya ke Album ponsel.
