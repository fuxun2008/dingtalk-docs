## Nilai fitur

Atur aturan pengisian data untuk menghindari kesalahan, menstandarkan format, serta meningkatkan akurasi dan efisiensi pengumpulan data.

## Skenario penggunaan

Saat anggota tim berkolaborasi mengisi konten spreadsheet, tidak semua orang memahami persyaratan pengisian dengan baik. Akibatnya, konten spreadsheet sering keliru, sementara pemeriksaan manual memakan waktu dan tenaga. Kini, melalui fitur "Validasi Data", Anda dapat menetapkan aturan pengisian terlebih dahulu, menstandarkan format, dan mencegah kesalahan. Dengan begitu, akurasi dan efisiensi pengumpulan data meningkat sekaligus.

## Petunjuk penggunaan

Titik masuk:

1. Menu atas - Data - Validasi Data;

2. Toolbar - Validasi Data;

3. Menu klik kanan - Atur Validasi Data;

Pengaturan:

1. Klik titik masuk - Buat aturan;

2. Atur aturan: Tentukan tipe data yang diinginkan dan aturan validasi (tips input dan peringatan kesalahan);

(Validasi Data merupakan fitur kompatibilitas yang konsisten dengan aturan operasi lokal, dengan sebagian interaksi UI yang berbeda)

3. Klik Konfirmasi untuk menyimpan;

Validasi:

1. Berdasarkan aturan yang telah ditetapkan, pengguna lain dapat melihat tips input saat mengeklik sel;

2. Saat memasukkan data yang tidak sesuai dengan aturan, akan muncul pemberitahuan bahwa data tidak valid.
