Saat menyajikan data, Spreadsheet mendukung mode presentasi yang mengubah spreadsheet menjadi mode PPT hanya dengan satu klik. Fitur ini membuat penyajian data lebih lancar dan menghilangkan kerepotan membuat PPT.

## Petunjuk penggunaan

## Cara masuk ke mode presentasi

Klik **Mode presentasi** di sudut kanan atas untuk langsung mengubah Lembar Kerja menjadi mode PPT.

## Penyesuaian mode presentasi

Pada antarmuka mode presentasi, Anda dapat melakukan penyesuaian berikut:

1.  **Ukuran Font**: Klik zoom A di sudut kanan atas untuk menyesuaikan font.

2.  **Rasio antarmuka**: Gunakan kotak rasio di sudut kanan bawah untuk menyesuaikan ukuran tampilan antarmuka.

3.  **Buat tampilan filter sementara:** Pilih area target, lalu klik ikon Filter di sudut kiri atas untuk membuat tampilan filter sementara. Anda dapat membandingkan data secara horizontal dan vertikal untuk meningkatkan pemahaman audiens terhadap data.

4.  **Urutkan**: Pilih area target, lalu klik Urutkan di sudut kiri atas untuk mengurutkan area yang dipilih secara menaik atau menurun. Atau, tanpa memilih area target, klik Urutkan di sudut kiri atas untuk mengurutkan seluruh spreadsheet secara menaik atau menurun.

    (Catatan: Anda tidak dapat mengurutkan rentang yang berisi Gabungkan Sel vertikal.)

## Keluar dari mode presentasi

*   Klik tombol **"Keluar dari mode presentasi"** untuk langsung keluar.

*   Tekan F11 untuk keluar dari mode layar penuh presentasi.
