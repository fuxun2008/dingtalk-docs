Spreadsheet mendukung penyisipan lampiran untuk mengunggah file lokal, gambar, audio, video, dan berbagai jenis konten lainnya, sehingga memudahkan Anda membangun pustaka data online tim.

## Petunjuk penggunaan

1. Entri: Sisipkan - Lampiran.

2. DingTalk versi Standar membatasi penyisipan lampiran hingga 251MB, sedangkan versi Profesional mendukung penyisipan lampiran hingga 1GB.

3. Format lampiran yang mendukung pratinjau online: dokumen teks, spreadsheet, presentasi, gambar, video, dan audio. Format lainnya harus diunduh dan tidak mendukung pratinjau.
