## Nilai fitur

Mendukung penyisipan atau pembatalan tautan halaman web secara massal melalui klik kanan, sehingga pengeditan tautan menjadi lebih mudah.

## Skenario penggunaan

Saat mengedit spreadsheet, cukup klik kanan untuk menyisipkan atau menghapus tautan dengan mudah, sehingga pengeditan konten menjadi lebih efisien.

## Petunjuk penggunaan

1.  Saat sebuah sel dipilih, klik kanan untuk menampilkan pintasan "Sisipkan Tautan".

2.  Saat area yang dipilih berisi tautan, klik kanan pada opsi "Batalkan Tautan" untuk membatalkan tautan secara massal dengan cepat.
