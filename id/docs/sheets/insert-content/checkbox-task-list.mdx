Di DingTalk Spreadsheet, Anda dapat membuat daftar tugas melalui **«Sisipkan kotak centang»**.

## Petunjuk penggunaan

1.  Rancang daftar tugas yang memuat nama tugas dan penanggung jawab, lalu sisipkan satu kolom untuk menandai status penyelesaian tugas.

2.  Pilih sel kosong, lalu klik **«Kotak centang»** pada bilah alat untuk menyisipkan kotak centang.

3.  Klik «Kotak centang» untuk menambahkan kotak centang, lalu centang sesuai status penyelesaian.

Setelah diekspor, spreadsheet yang berisi kotak centang akan ditampilkan dalam bentuk TRUE dan FALSE secara lokal.
