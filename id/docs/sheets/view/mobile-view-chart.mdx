## Nilai fitur

Melihat bagan di ponsel dengan tampilan bagan membuat pengalaman menjelajah tabel terasa seperti melihat Album: mulus dan imersif.

## Skenario penggunaan

Pengalaman Kanban di perangkat seluler kini ditingkatkan sepenuhnya. Lepaskan diri dari keterbatasan layar ponsel, beralih dengan bebas ke mode tampilan bagan, dan ketuk untuk melihat bagan dalam ukuran besar tanpa melewatkan satu data pun.

## Petunjuk penggunaan

1. Pilih bagan. Menu akan menampilkan opsi untuk melihat bagan dalam ukuran besar. Ketuk untuk langsung melihatnya.

2. Ketuk bilah bawah - Tampilan - Tampilan bagan untuk masuk ke Daftar bagan yang menampilkan semua bagan pada Lembar Kerja saat ini. Pilih salah satu untuk melihatnya, lalu geser untuk berpindah antarbagan.
