Spreadsheet versi desktop mendukung penyematan baris tertentu agar selalu berada di bagian atas saat menggulir, sehingga Anda dapat menyematkan semua header dengan mudah.

## Petunjuk penggunaan

*   Sematkan baris tetap di atas: pada desktop, pilih suatu baris >> klik toolbar >> Bekukan >> baris yang Dipilih akan tersemat di bagian atas.

*   Lepas sematan baris tetap di atas: pada desktop, pilih baris yang sudah disematkan >> klik toolbar >> Bekukan >> Lepas Sematan.
