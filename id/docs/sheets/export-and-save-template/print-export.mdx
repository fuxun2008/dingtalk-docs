Di DingTalk Spreadsheet, jika Anda perlu mengirim spreadsheet kepada klien atau pihak lain melalui platform lain untuk ditinjau, gunakan fitur cetak dan ekspor.

## Petunjuk penggunaan

Cetak: Klik <strong>Menu—>Spreadsheet—>Cetak</strong> pada bilah navigasi atas untuk mencetak.

Ekspor: Klik <strong>Menu—>Spreadsheet—>Unduh sebagai</strong> pada bilah navigasi atas untuk menyimpan dengan cepat ke perangkat lokal. Pada panel ekspor, Anda dapat mengubah judul spreadsheet tujuan tanpa memengaruhi spreadsheet asli. (Saat ini DingTalk Spreadsheet mendukung ekspor ke spreadsheet lokal dalam format XLSX, CSV, TSV, dan PDF.)
