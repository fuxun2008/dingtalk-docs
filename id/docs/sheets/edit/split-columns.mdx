DingTalk Spreadsheet mendukung pemisahan satu sel menjadi beberapa kolom berdasarkan kondisi tertentu, sehingga perapian data hasil kuesioner maupun rantai pesan menjadi lebih efisien.

## Petunjuk penggunaan

Klik menu Spreadsheet - Data - Pisahkan kolom, seperti ditunjukkan pada gambar berikut:
