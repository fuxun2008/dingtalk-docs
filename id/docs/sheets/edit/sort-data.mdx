Di DingTalk Spreadsheet, gunakan «Urutkan» untuk menata ulang data dalam urutan tertentu. Ini merupakan salah satu cara penting untuk merapikan data.

## Petunjuk penggunaan

Pilih area target, lalu klik <strong>Urutkan</strong> di bilah alat. Pada menu dropdown, Anda juga dapat memilih metode pengurutan atau menggunakan «Urutkan kustom» untuk menyesuaikan urutan spreadsheet sesuai kebutuhan.

*   Data bertipe angka umumnya diurutkan berdasarkan besarnya nilai numerik secara keseluruhan.

*   Data bertipe teks umumnya diurutkan berdasarkan abjad Latin atau urutan pinyin (untuk huruf Tionghoa).

*   Tips: Untuk memperoleh hasil pengurutan yang tepat, pastikan format data telah distandarkan sebelum melakukan pengurutan.
