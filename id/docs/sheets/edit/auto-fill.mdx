Gunakan fitur "Isi otomatis" di DingTalk Spreadsheet untuk menyalin dan mengisi data dengan cepat berdasarkan aturan input yang sudah ada, sehingga pengisian data sel berpola menjadi lebih mudah. Fitur ini cocok untuk skenario input data seperti menyalin konten dan penomoran deret.

## Cara penggunaan

1.  Pilih area sel yang sebagian datanya sudah terisi sebagai dasar data untuk isi otomatis.

2.  Arahkan kursor ke sudut kanan bawah area pilihan. Kursor akan berubah menjadi bentuk **" + "**, yaitu <strong>gagang isian</strong>.

3.  Tahan gagang isian, lalu seret ke arah vertikal atau horizontal untuk mengisi data pada sel kosong di arah tersebut.

4.  Setelah gagang isian dilepas, opsi pengisian akan muncul di sudut kanan bawah area isian. Klik untuk memilih: **Salin sel, Isi deret, Isi format saja, Isi tanpa format.**
