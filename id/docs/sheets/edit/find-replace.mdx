Di Spreadsheet, gunakan fitur "Cari dan Ganti" untuk mencari dan mengganti data dengan cepat, atau tekan <strong>pintasan keyboard Ctrl + F (Mac: Cmd + F)</strong> untuk mencari data.

## Petunjuk penggunaan

1.  Di sisi paling kanan bilah alat, klik <strong>Lainnya -> "Cari dan Ganti"</strong> untuk membuka panel, lalu masukkan data yang ingin dicari pada opsi **"Cari"**. Format data mendukung teks, numerik, dan simbol.

2.  Sel yang berisi data pencarian langsung ditemukan dan disorot dengan warna kuning. Pencarian teks berbahasa Inggris tidak membedakan huruf besar dan kecil.

3.  Untuk mengganti data yang ditemukan, masukkan data pengganti pada kotak **"Ganti dengan"**, lalu klik **"Ganti"** untuk mengganti data pada sel yang dipilih, atau klik **"Ganti Semua"** untuk mengganti seluruh data yang ditemukan.
