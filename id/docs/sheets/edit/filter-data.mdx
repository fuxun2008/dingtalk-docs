Di Spreadsheet DingTalk, gunakan **「 Filter 」** untuk memilih sebagian data dari tabel berdasarkan kondisi tertentu guna dianalisis dan diolah lebih lanjut, sekaligus menyembunyikan data yang belum diperlukan.

## Petunjuk penggunaan

## Filter dasar: mengaktifkan dan menutup filter

1.  Pilih rentang sel yang ingin difilter, lalu klik **「 Filter 」** pada bilah alat untuk mengaktifkan filter.

2.  Setelah itu, **「 Tombol filter 」** akan muncul di pojok kanan atas setiap sel pada baris pertama area terpilih. Klik "Tombol filter" untuk memfilter data. Jika pada langkah sebelumnya Anda langsung mengklik "Filter" tanpa memilih area, filter akan diaktifkan untuk seluruh Lembar Kerja secara default, dan semua sel pada baris pertama Lembar Kerja akan menampilkan "Tombol filter".

3.  Klik "Filter" lagi pada bilah alat untuk menutup filter.

4.  Anda hanya dapat mengaktifkan filter pada satu rentang sel dalam Lembar Kerja pada satu waktu.

## Filter dasar: tipe filter

1.  **Filter berdasarkan nilai**: untuk memfilter jenis data tertentu dengan cepat, masukkan kata kunci pada kotak Cari. Hasil filter mencakup semua item yang mengandung kata kunci tersebut. Anda juga dapat memfilter dengan mencentang item Tidak berulang pada panel.

2.  **Filter berdasarkan kondisi**: untuk memfilter data dengan kondisi tertentu, atur Filter yang sesuai.

3.  **Filter berdasarkan warna**: untuk memfilter sel dengan warna latar atau warna Font tertentu, pilih "Filter berdasarkan warna".

4.  **Filter hanya terlihat oleh saya**: untuk menyinkronkan atau tidak menyinkronkan hasil filter, centang "Filter hanya terlihat oleh saya" pada panel filter sesuai kebutuhan.

## Filter lanjutan: tampilan filter yang tidak saling mengganggu

Jika Anda perlu memfilter secara mandiri tanpa memengaruhi tampilan data orang lain, atau jika Izin Anda pada tabel hanya dapat melihat namun Anda tetap ingin memfilter data, gunakan "Tampilan filter" untuk memfilter data.

1.  Pilih rentang sel yang ingin difilter, lalu pada bilah alat klik "**panah menu tarik-turun Filter -> Buat tampilan filter**".

    (MAC: "Filter - Lainnya", klik "Buat tampilan filter" untuk masuk ke "Antarmuka tampilan filter")

2.  Pada "Antarmuka tampilan filter", hasil pemfilteran data tidak akan disinkronkan ke tabel data asli. Anda juga dapat melakukan tindakan berikut:

    1.  Mengganti nama tampilan filter agar mudah dibedakan

    2.  Memilih ulang untuk mengubah area filter

3.  Fitur filter pada tampilan filter sama dengan operasi filter dasar, tetapi untuk sementara belum mendukung "Urutkan".
