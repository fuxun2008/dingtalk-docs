**Saat melakukan pengeditan kolaboratif online di "Spreadsheet", jika Anda tidak ingin orang lain menghapus atau mengubah data penting, atau tidak ingin data rahasia dilihat orang lain, gunakan fitur "Kunci sel / lembar kerja" untuk menguncinya.**

Izin pengguna dalam izin penguncian terdiri atas 2 jenis: membatasi pengguna untuk "mengedit" data dan membatasi pengguna untuk "melihat" data (larangan lihat).

## Petunjuk penggunaan

## 1. Kunci data: batasi izin edit pengguna

### Contoh skenario:

Sebagai kepala toko, saya perlu menghitung volume dan nilai penjualan produk yang dijual toko. Karena itu, saya membuat "Daftar penjualan kue bulan" dan meminta rekan toko mengisinya bersama. Namun, untuk kolom "Volume penjualan", "Harga satuan", dan "Jumlah", saya ingin hanya "saya dan wakil kepala toko" yang dapat mengedit dan mengubahnya, sedangkan rekan lain hanya dapat melihat. Dalam kasus ini, pengaturan dapat dilakukan melalui fitur penguncian.

|  |
| --- |
|  |

### Alur tindakan:

#### Konfirmasi area penguncian

Pilih area sel yang perlu Anda kunci. Misalnya, pada skenario di atas, kita perlu mengunci 3 kolom: "Volume penjualan", "Harga satuan", dan "Jumlah". Pilih 3 kolom tersebut dengan mouse, lalu klik **"Bilah alat — … Lainnya — Kunci — Kunci sel"** atau **"Menu klik kanan — Kunci sel"**, kemudian atur aturan penguncian.

#### Atur aturan penguncian

Berdasarkan tindakan di atas, setelah mengklik **"Kunci sel"**, akan muncul **"Jendela kunci sel"**. Kita dapat mengatur aturan pada panel:

1.  Area sel: konfirmasi atau ubah area sel yang ingin Anda kunci. Klik untuk mengubah area pilihan.

2.  Tambah orang tertentu: yaitu menambahkan orang yang memiliki izin pada area saat ini. Sama seperti pengaturan izin dokumen, klik tambah untuk memilih orang dari daftar pengguna yang telah memiliki izin kolaborasi dokumen, atau langsung cari dan tambahkan.

3.  Jadi, berdasarkan kasus di atas, sebagai kepala toko sekaligus pemilik spreadsheet, saya akan otomatis muncul dalam daftar orang tertentu. Saya perlu menambahkan "wakil kepala toko Silai" dan memberinya izin edit, sedangkan pengguna lain hanya dapat melihat.

    #### Efek penguncian dari sudut pandang pengguna lain

    |  |
    | --- |
    |  |

    #### Hal yang perlu diperhatikan

    1.  Pemilik dan admin dokumen otomatis ditampilkan dalam jendela area dan tidak dapat diubah, karena mereka memiliki izin tertinggi atas dokumen.

    2.  Saat menambahkan orang tertentu, hanya admin dan pemilik yang dapat menambahkan pengguna eksternal dokumen.

    3.  Saat menambahkan pengguna eksternal, Anda perlu terlebih dahulu memberi mereka izin keseluruhan dokumen, lalu mengatur izin area sel mereka, karena izin mengikuti prinsip pewarisan. Untuk pengguna yang sama, **izin area sel ≤ izin keseluruhan dokumen**.

    ## 2. Kunci data: batasi izin lihat pengguna

    ### Contoh skenario:

    Sebagai kepala toko, saya perlu menghitung volume dan nilai penjualan produk yang dijual toko. Karena itu, saya membuat "Daftar penjualan kue bulan" dan meminta rekan toko mengisinya bersama. Namun, untuk kolom "Volume penjualan", "Harga satuan", dan "Jumlah", saya ingin hanya "saya dan wakil kepala toko" yang dapat mengedit dan mengubahnya, sedangkan rekan lain dilarang melihat agar data inti tidak bocor. Dalam kasus ini, pengaturan juga dapat dilakukan melalui fitur penguncian.

    |  |
    | --- |
    |  |

    ### Alur tindakan:

    #### Konfirmasi area penguncian

    Sama seperti tindakan "batasi izin edit pengguna", langkah pertama adalah memilih area sel yang perlu Anda kunci, lalu klik **"Bilah alat — … Lainnya — Kunci — Kunci sel"** atau **"Menu klik kanan — Kunci sel"**, kemudian atur aturan penguncian.

    #### Atur aturan penguncian

    Jadi, berdasarkan kasus di atas, sebagai kepala toko sekaligus pemilik spreadsheet, saya akan otomatis muncul dalam daftar orang tertentu. Saya perlu menambahkan "wakil kepala toko" dan memberinya izin edit, sedangkan pengguna lain diatur menjadi <strong>larangan lihat.</strong>

    #### Efek penguncian dari sudut pandang pengguna lain

    |  |
    | --- |
    |  |

    #### Hal yang perlu diperhatikan:

    1.  Setelah mengatur "larangan lihat", pengguna tanpa izin lihat tidak hanya tidak dapat melihat data area, tetapi juga tidak dapat mengunduh atau menyalin data spreadsheet, tidak dapat melihat riwayat, dan tidak dapat memperoleh data sel yang terkunci melalui formula.

    2.  Saat menggunakan fitur "Cari / Ganti", data area yang terkunci akan otomatis diabaikan.

## 3. Melihat dan mengelola aturan penguncian yang ada

1.  Semua kolaborator dokumen spreadsheet dapat "melihat" aturan penguncian dalam spreadsheet.

2.  Hanya pembuat aturan penguncian, admin, atau pemilik dokumen spreadsheet yang dapat "mengelola" (termasuk mengedit dan mengubah) aturan penguncian.

3.  Cara melihat dan mengelola: pilih area terkunci, lalu klik "Menu klik kanan — Lihat area terkunci yang ada", atau langsung klik "Bilah alat — … Lainnya — Kunci — Lihat area terkunci yang ada" untuk memunculkan "Panel penguncian". Melalui panel ini, Anda dapat melihat semua aturan penguncian dalam lembar kerja saat ini.
