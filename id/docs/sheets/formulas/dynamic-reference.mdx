## Fungsi INDIRECT

Fungsi kutip tidak langsung INDIRECT mengurai teks menjadi kutipan rentang. Sebagai perbandingan, sebagian besar Formula biasanya mengisi kutipan secara langsung, misalnya SUM(A1:A5). Pada contoh tersebut, "A1:A5" tidak diapit tanda kutip sehingga langsung mewakili rentang kutipan A1:A5.

Umumnya, Fungsi INDIRECT digunakan bersama operator penggabung "&" atau Fungsi Teks, misalnya:
