## Teks, tanggal => numerik: fungsi VALUE atau operator matematika

Fungsi VALUE mencoba mengonversi berbagai jenis argumen menjadi numerik. Jika tidak dapat dikonversi, fungsi ini mengembalikan Kesalahan #VALUE!:

## Numerik, tanggal => teks: fungsi TEXT atau operator penggabung "&"

Fungsi TEXT menerapkan format tertentu (argumen ke-2) pada berbagai jenis data (argumen ke-1) dan mengembalikan hasil berupa teks. Ketika format yang ditentukan adalah "0", data dikonversi menjadi teks paling dasar. Contoh:

## Mengonversi ke tanggal dan waktu

Pertama, di DingTalk Spreadsheet, tanggal disimpan dalam bentuk numerik. Numerik yang dipadukan dengan "format" akan menghasilkan tanggal dan waktu. Oleh karena itu, untuk mengonversi data jenis lain menjadi tanggal, konversikan data tersebut menjadi numerik terlebih dahulu.
