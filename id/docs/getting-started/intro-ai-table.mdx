## Apa itu AI Table?

AI Table adalah alat manajemen kolaborasi data generasi baru berbasis spreadsheet, sekaligus aplikasi basis data visual online. AI Table dapat membangun hubungan asosiasi antartabel dan mendukung berbagai tampilan: Kisi, Lini Masa, Kalender, Kanban, Galeri, dan Formulir. Setiap tampilan memiliki skenario dan fungsi yang sesuai sehingga penyajian informasi dan kolaborasi multi-pengguna dalam organisasi dapat berjalan efisien.

Berbeda dengan spreadsheet konvensional, setiap kolom di AI Table memiliki tipe bidang yang seragam, dan setiap baris merupakan satu rekam data. Anda dapat mengoperasikan tampilan data melalui pengurutan, filter, dan pengelompokan. Dengan pendekatan berbasis data, AI Table mewujudkan berbagai skenario penggunaan secara optimal, seperti agregasi data, analisis kanban, manajemen tugas, dan rekapitulasi laporan.

## Skenario penggunaan AI Table

## Manajemen proyek

Menyediakan <strong>tampilan penguraian dan perencanaan tugas</strong> yang jelas dan terstruktur, sehingga anggota tim di berbagai tahap dapat memperoleh perspektif menyeluruh dengan cepat, mempercepat pengambilan keputusan, dan meningkatkan efisiensi kolaborasi.

## Manajemen inventaris

Manfaatkan kemampuan <strong>Formulir + Formula + Otomatisasi + dasbor data</strong> untuk menyajikan dan mengelola data secara menyeluruh, mencakup rekam masuk barang, detail inventaris, manajemen konsumsi, stok, hingga peringatan.

## Manajemen penjualan

Manfaatkan kemampuan <strong>Akses Terperinci</strong> untuk mengonfigurasi kontrol akses data pelanggan sensitif berdasarkan peran. Peran penjualan hanya dapat melihat informasi pelanggan yang ditanganinya.

## Bagaimana cara menggunakan AI Table?

### Membuat AI Table baru

Buka beranda AI Table di PC untuk membuat AI Table baru.

Klik buat AI Table kosong atau gunakan templat yang tersedia.

### Membagikan AI Table

Klik "Bagikan" di pojok kanan atas untuk membagikannya kepada rekan kerja dalam organisasi agar dapat berkolaborasi bersama.

### Membuat tabel baru

Di AI Table yang baru dibuat, klik Buat di pojok kiri bawah untuk membuat tabel.

Klik `...` di sisi kanan tabel untuk mengganti nama, mengedit deskripsi tabel, menyalin tabel, memindahkan, atau menghapusnya.

### Membuat tampilan baru

Klik ikon + di sisi kanan bilah judul tampilan di bagian atas untuk membuat tampilan baru.

## Sorotan fitur AI Table

### Berbagai bidang mendukung pengelompokan dan pengurutan

Setiap kolom di AI Table disebut "bidang". Bidang adalah header tabel di AI Table yang menentukan tipe dan format pengisian informasi setiap kolom sehingga data yang dimasukkan lebih terstandar dan tertata.

### Satu data, berbagai perspektif

Menyajikan data dalam berbagai tampilan adalah inti dari AI Table. Sesuai dengan tipe data dan skenario penggunaan, Anda dapat menyajikan data dalam berbagai bentuk tampilan seperti <strong>Kisi, Kanban, Lini Masa, Galeri, dan lainnya</strong>.

Ambil contoh skenario pengumpulan CV: setelah CV terkumpul, Anda dapat memfilter kandidat berdasarkan data multidimensi, menetapkan orang tertentu untuk menindaklanjuti progres wawancara, menjadwalkan waktu wawancara, dan menampilkan durasi wawancara setiap kandidat secara intuitif.

### Alur otomatisasi

Membangun alur otomatisasi dengan AI Table dapat sangat meningkatkan efisiensi dan akurasi kolaborasi, sekaligus mengurangi risiko kesalahan.

**Memicu "alur otomatisasi" setelah formulir dikirim**

Ambil contoh skenario inspeksi: ketika kondisi pengiriman adalah "anomali", alur otomatisasi AI Table terpicu untuk mengirim tiket masalah ke grup atau orang yang ditentukan.

[Alur pembuatan tiket setelah menemukan masalah](https://docs.dingtalk.io/i/nodes/G1DKw2zgV2KnvL4kFrmQ22NPJB5r9YAn)

**Balasan Otomatis ke "Pengirim"**

Ambil contoh skenario masukan: setelah masalah dikirim melalui formulir, penanggung jawab dinotifikasi secara otomatis. Setelah hasil penanganan diperbarui ke tabel, Pengirim dapat dinotifikasi secara otomatis.

Menotifikasi Pengirim secara otomatis.

### Akses Terperinci

Dengan menyesuaikan berbagai peran, Anda dapat menentukan secara tepat siapa yang dapat melihat dan mengedit setiap tabel. Ini mewujudkan pengelolaan izin yang lebih terperinci dan memperkuat perlindungan keamanan data.

### Dasbor data

Dasbor data menyajikan data AI Table secara intuitif. Dengan konfigurasi sederhana, Anda dapat memiliki dasbor bisnis dengan mudah.

### Tampilan bagan mendukung "Word Cloud"

Untuk skenario inspeksi di industri manufaktur, "penyebab ketidaksesuaian" dapat ditampilkan secara intuitif sehingga analisis data menjadi lebih akurat.

### Asosiasi data, pembaruan data dinamis

Di AI Table, mengoperasikan data terasa seperti basis data visual. Tipe bidang data setiap kolom bersifat tetap dan terstandar. AI Table mendukung berbagai tipe bidang yang hampir memenuhi semua skenario kolaborasi organisasi.

### Kolaborasi efisien

AI Table mendukung penyuntingan kolaboratif oleh banyak pengguna untuk mengelola data bersama secara efisien dan cepat.

### Mendukung impor dan unduh Excel

AI Table menambahkan fitur impor file .xlsx, sumber data lain, dan file lain di menu dokumen untuk membantu pengguna menghasilkan dan menyelesaikan entri data AI Table dengan cepat. AI Table juga mendukung ekspor cadangan data ke Excel lokal dan lampiran secara praktis dan cepat.

### Mendukung penyimpanan/pembuatan AI Table dari templat

Templat AI Table telah tersedia. Saat membuat dokumen baru, pengguna dapat memilih templat populer yang sesuai kebutuhan untuk membuat AI Table dengan sekali klik, atau memilih templat di dokumen kosong. Jika Anda memiliki dokumen bagus yang ingin disimpan sebagai templat untuk digunakan sendiri maupun orang lain, Anda juga dapat menyimpannya dengan sekali klik sebagai "Templat Saya" atau "Dokumen Tim".
