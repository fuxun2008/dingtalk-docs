Sekarang semua itu sudah didukung! DingTalk Docs mendukung pengunggahan file lokal, seperti PDF, PPT, gambar, audio, dan video. Selain itu, Rapat Cepat dan log juga dapat diimpor ke Knowledge Base hanya dengan satu klik.

Kelola pengetahuan tim dengan lebih mudah dan tertata rapi!

## Detail langkah

### Bagaimana cara menambahkan file lokal ke Knowledge Base saya?

Klik "Dokumen" di bilah sisi kiri DingTalk untuk masuk ke <strong>halaman utama</strong> Dokumen >> klik ikon di pojok kanan atas >> lalu pilih untuk mengunggah file/folder lokal. File akan tersimpan di "Dokumen Saya", dan klik untuk melihatnya.

### Bagaimana cara menambahkan file lokal ke Knowledge Base tertentu?

Pilih <strong>halaman utama</strong> Knowledge Base >> buka bilah direktori di sisi kiri >> lalu pilih untuk mengunggah file/folder lokal ke Knowledge Base tersebut.
