<Accordion title="Bagaimana cara masuk ke Knowledge Base?">

  Knowledge Base sudah tersedia sepenuhnya tanpa perlu pengajuan. Anda dapat masuk melalui jalur berikut:

  【DingTalk seluler】- 【Lainnya】 di bagian bawah - 【Dokumen】- 【Knowledge Base】.

  【DingTalk desktop】- 【Dokumen】- 【Knowledge Base】.

</Accordion>
<Accordion title="Apakah dokumen di Knowledge Base dapat dibagikan?">

  Dokumen di dalam Knowledge Base dapat dibagikan kepada pengguna di dalam maupun di luar organisasi. Berikut cara membagikannya:

  1. 【DingTalk seluler】- 【Lainnya】 di bagian bawah - 【Dokumen】- 【Knowledge Base】- ketuk 【Knowledge Base terkait】- masuk ke halaman dokumen terkait - 【...】 di kanan atas - 【Bagikan】. Anda dapat membagikannya dalam bentuk gambar panjang, kode QR, tautan, atau membagikannya ke obrolan.

  2. 【DingTalk desktop】- 【Dokumen】- 【Knowledge Base】- masuk ke halaman dokumen terkait - 【Bagikan】 di kanan atas. Anda dapat membagikannya dalam bentuk tautan atau membagikannya ke obrolan.

</Accordion>
<Accordion title="Apa itu Knowledge Base?">

  Knowledge Base adalah platform manajemen pengetahuan organisasi yang profesional dan efisien, dikembangkan secara mandiri oleh Alibaba Group. Platform ini dapat digunakan untuk membangun pustaka manajemen pengetahuan organisasi dan mendukung kolaborasi dokumen internal. Pengoperasiannya sederhana dan mudah. Setelah admin membuat sebuah Knowledge Base dan menambahkan pengguna, pengguna dapat berbagi secara bersamaan dengan sinkronisasi real-time. Pengguna tim juga dapat merekam seluruh konten hasil kolaborasi internal di dalamnya.

  【Tips】:

  1. Pengguna individu: tidak dapat menggunakan Knowledge Base. Halaman akan menampilkan permintaan untuk bergabung atau membuat organisasi.

  2. Pengguna organisasi: buat sebuah Knowledge Base dan tambahkan pengguna tim untuk berkreasi bersama serta mengumpulkan pengetahuan organisasi.

</Accordion>
<Accordion title="Format dokumen apa saja yang dapat diimpor ke Knowledge Base menjadi dokumen online?">

  Knowledge Base mendukung file dengan format berikut (maksimal 20MB per file): .docx, .xlsx, .doc, .xls, .txt, .xmind, .markdown, .mark, .md. Jalur impor file: 【DingTalk desktop】- 【Dokumen】- 【Knowledge Base】- 【masuk ke Knowledge Base terkait】- ketuk 【+】- 【Impor sebagai dokumen online】, lalu pilih file dan impor.

</Accordion>
<Accordion title="Bagaimana cara mengatur izin untuk pengguna Knowledge Base?">

  Admin Knowledge Base dapat menetapkan izin kepada pengguna. Izin yang dapat ditetapkan meliputi: Dapat mengelola, Dapat mengedit, Dapat melihat/mengunduh, Hanya dapat melihat, dan Jadikan Pemilik. Rincian izin:

  1.  **Dapat mengelola:** dapat mengedit/mengunggah/mengunduh/menghapus;

  2.  **Dapat mengedit:** dapat mengedit/mengunggah/mengunduh;

  3.  **Dapat melihat/mengunduh:** dapat mengunduh/menyalin/mencetak;

  4.  **Hanya dapat melihat:** hanya dapat melihat pratinjau online, tidak dapat menyalin/mengunduh;

  5.  **Jadikan Pemilik (hanya di desktop)**: dapat mengalihkan status Pemilik ke pengguna lain.

</Accordion>
<Accordion title="Apakah dokumen yang dihapus di Knowledge Base dapat dipulihkan?">

  Bisa. Dokumen yang dihapus akan dipindahkan ke 【Tempat Sampah】. Buka 【ikon Tempat Sampah】 di kiri bawah Knowledge Base terkait, lalu buka Tempat Sampah untuk melihat file terkait. Tips: Anda dapat melakukan 【Pulihkan】 atau 【Hapus permanen】 pada file di Tempat Sampah.

</Accordion>
<Accordion title="Apakah Knowledge Base menggunakan ruang Drive?">

  Saat ini dokumen online di dalam Knowledge Base tidak menggunakan ruang Drive.

</Accordion>
<Accordion title="Apakah Knowledge Base dapat dipindahkan?">

  Saat ini pengguna yang memiliki Izin Edit atas Knowledge Base tersebut dapat memindahkan dokumen di dalamnya ke Knowledge Base lain di dalam organisasi. Dalam satu organisasi yang sama, pemindahan seluruh Knowledge Base ke Knowledge Base lain tidak didukung; pemindahan Knowledge Base lintas organisasi juga tidak didukung.

  Tips: Saat ini operasi hanya dapat dilakukan di desktop, belum didukung di seluler. Caranya: pada pohon direktori di sebelah kiri, pilih 【...】 di sebelah kanan sebuah dokumen - 【Pindahkan ke】- 【Pilih lokasi tujuan】- 【Pindahkan】.

</Accordion>
<Accordion title="Apakah Knowledge Base berbayar?">

  Saat ini Knowledge Base dapat digunakan secara Luang.

</Accordion>
<Accordion title="Bagaimana cara melihat Editor Knowledge Base?">

  Saat ini bagian atas dokumen Knowledge Base menampilkan: Editor (mencakup semua pengguna yang pernah mengedit), Waktu pembaruan terbaru, dan jumlah pembaca (dapat menampilkan informasi detail pengguna yang membaca).

</Accordion>
