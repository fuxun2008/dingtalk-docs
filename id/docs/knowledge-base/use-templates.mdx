## 1. Apa itu template Knowledge Base?

*   Anda dapat menyimpan dokumen kerja harian sebagai "template Knowledge Base". Pengguna Knowledge Base dapat memakai "template Knowledge Base" untuk membuat dokumen dengan cepat, menjaga konsistensi format dan konten File Tim, serta meningkatkan efisiensi kolaborasi tim.

    ### 2. Bagaimana cara membuat atau menggunakan template Knowledge Base?

*   Menyimpan dokumen sebagai template Knowledge Base: klik "Lainnya…" di sudut kanan atas dokumen, klik "Simpan sebagai template", lalu klik "Simpan sebagai template Knowledge Base ini", seperti ditunjukkan pada gambar berikut:

*   Membuat dokumen menggunakan template Knowledge Base: saat membuat dokumen baru, pilih "Buat dari template", lalu klik "Dari Knowledge Base", seperti ditunjukkan pada gambar berikut:

    ### 3. Apa fungsi template Knowledge Base?

*   Menstandarkan gaya konten dokumen tim dan meningkatkan efisiensi pengguna Knowledge Base dalam mengedit konten. Misalnya, Anda dapat menyimpan dokumen laporan mingguan dan bulanan tim sebagai template Knowledge Base, atau menyimpan template proposal bisnis sebagai template Knowledge Base untuk menstandarkan format dan kontennya.
