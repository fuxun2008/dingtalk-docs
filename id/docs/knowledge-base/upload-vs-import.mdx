## Apa itu Unggah dan Impor?

### Unggah:

Mendukung pengunggahan semua jenis file lokal ke Knowledge Base, dan sebagian format mendukung pratinjau. Setelah diunggah, Anda memperoleh tautan file untuk dibagikan **tanpa mengubah format file**.

Cara mengunggah: Di <strong>halaman utama Knowledge Base</strong> \>> pilih "" pada bilah direktori kiri >> pilih untuk mengunggah file/folder lokal ke Knowledge Base tersebut.

### Impor:

Mendukung pengimporan sebagian jenis file lokal ke Knowledge Base yang **dikonversi menjadi file online**, sehingga Anda memperoleh tautan dokumen untuk dibagikan **dan dikonversi menjadi format DingTalk Docs**.

Cara mengimpor: Di <strong>halaman utama Knowledge Base</strong> \>> pilih "" pada bilah direktori kiri >> pilih 【Impor sebagai dokumen online】.

Berikut penjelasan konversi format setelah berbagai jenis file diimpor:

| **Tipe file lokal** | **Tipe file online** |
| --- | --- |
| doc, docx, markdown, mark, md, txt | DingTalk Docs |
| xls, xlsx | Spreadsheet |
| xmind | Peta Pikiran DingTalk |

## Tipe file apa saja yang didukung untuk Unggah dan Impor? Apakah ada batasan ukuran file?

File yang diunggah melalui "Unggah" <strong>mendukung pratinjau berbagai tipe file</strong>, dengan ukuran maksimal 8G per file; sedangkan "Impor" **hanya mendukung tipe dokumen**, dengan ukuran maksimal 20M per file.

Berikut perbedaan spesifiknya:

| **Metode transfer** | **Tipe file** | **Format yang mendukung pratinjau** | **Batasan ukuran** |
| --- | --- | --- | --- |
| Unggah | Dokumen | pdf, pptx, ppt, pot, potx, pps, ppsx, dps, dpt, pptm, potm, ppsm, xls, xlt, et, ett, xlsx, xltx, xlsb, xlsm, xltm, csv, doc, dot, wps, wpt, docx, dotx, docm, dotm, txt, xmind | Maksimal 8G per file |
|  | Gambar | peg, bmp, png, jpg, ico, webp |
|  | Audio/Video | 3GP, AVI, FLV, MP4, M3U8, MPG, ASF, WMV, MKV, MOV, TS, WebM, MXF, AAC, AC-3, ADPCM, AMR, DSD, MP1, MP2, MP3, PCM, RealAudio, Windows Media Audio |
|  | Lainnya | Arsip zip |
| Impor | Dokumen | docx, xlsx, doc, xls, txt, xmind, markdown, mark, md | Maksimal 20M per file |

## Skenario apa yang cocok untuk Unggah, dan skenario apa yang cocok untuk Impor?

| **Metode transfer** | **Skenario penggunaan** |
| --- | --- |
| Unggah | *   PPT dan materi dokumen tim yang sudah ada, ingin diunggah ke Knowledge Base departemen untuk dikelola secara terpusat<br />    <br />*   Gambar dan video lokal, ingin dibagikan agar dapat dilihat bersama oleh beberapa tim |
| Impor | *   Mengonversi file lokal menjadi file online |

## Apakah Unggah dan Impor menggunakan ruang penyimpanan organisasi?

"Unggah File" **menggunakan ruang penyimpanan organisasi**, sedangkan "Impor sebagai dokumen online" **tidak menggunakan ruang penyimpanan organisasi**. Berikut penjelasan spesifiknya:

| **Metode transfer** | **Objek penagihan** | **File yang diperhitungkan ke ruang penyimpanan** | **Alias** |
| --- | --- | --- | --- |
| **Unggah**<br />Mengunggah file (folder) lokal ke "Dokumen Saya" atau "Knowledge Base" | Ruang pada lokasi tujuan unggahan | Semua file yang diunggah | *   Jika langsung mengunggah folder, hanya file di dalam folder yang diperhitungkan ke ruang penyimpanan cloud, sedangkan folder itu sendiri tidak diperhitungkan;<br />    <br />*   Melihat gambar, video, file, dan lainnya milik orang lain tidak menggunakan ruang penyimpanan Anda; |
| **Impor**<br />Membuat atau mengimpor sebagai dokumen online di dalam "Dokumen Saya" atau "Knowledge Base" | 【Gratis Terbatas】Belum diperhitungkan | 【Gratis Terbatas】Belum diperhitungkan | 【Gratis Terbatas】Belum diperhitungkan |
