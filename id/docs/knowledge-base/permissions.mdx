## 1. Cara masuk ke backend pengaturan izin

*   Masuk ke backend pengaturan: di pojok kiri bawah Beranda dokumen, klik "Lainnya" - "Pengaturan organisasi", lalu pilih organisasi terkait. Anda akan masuk ke backend pengaturan izin dan dapat mengatur izin yang diperlukan, seperti ditunjukkan pada gambar berikut.

## 2. Cara menambah, mengubah, atau menghapus izin pengguna Knowledge Base

*   Di beranda Knowledge Base, klik "Pengaturan", lalu masuk ke halaman kelola melalui "Pengguna dan izin". Klik "Tambah pengguna" untuk menambahkan pengguna ke Knowledge Base. Anda dapat mengatur, mengubah, maupun menghapus izin pengguna. Tipe izin meliputi: **Dapat mengelola, Dapat mengedit, Dapat melihat/mengunduh, Hanya dapat melihat, Hapus izin**.

*   **Catatan: Saat Anda mengatur atau menghapus izin pengguna Knowledge Base melalui cara berikut, izin yang sesuai untuk semua dokumen di dalam Knowledge Base akan ikut diberikan atau dihapus secara otomatis.**

## 3. Cara menambah, mengubah, atau menghapus izin untuk satu dokumen di Knowledge Base

*   Jika Anda hanya ingin memberikan izin atas satu dokumen tertentu di dalam Knowledge Base kepada pengguna, buka dokumen terkait, klik Bagikan di pojok kanan atas, lalu buka jendela kelola izin. Klik "Tambah orang tertentu" untuk menambahkan pengguna. Izin pengguna yang telah ditambahkan juga dapat diubah atau dihapus.

## 4. Cara karyawan mengajukan izin dokumen di Knowledge Base

*   Saat membuka dokumen tanpa memiliki izin, klik untuk mengajukan izin kepada Pemilik dokumen atau Admin Knowledge Base. Anda dapat memilih izin seperti Dapat mengedit, Dapat melihat/mengunduh, atau Hanya dapat melihat.

## 5. Cara mengatur watermark keamanan Knowledge Base

*   Untuk melindungi keamanan konten dokumen, Knowledge Base mendukung dua pengaturan keamanan: **Menampilkan watermark pengunjung pada dokumen, Perlindungan anti-kebocoran**. Cara mengatur: masuk ke opsi pengaturan Knowledge Base, temukan pengaturan keamanan, lalu aktifkan fitur keamanan yang sesuai dengan kebutuhan, seperti ditunjukkan pada gambar berikut:

*   Konten watermark berupa "Nama perusahaan + Nama + 4 digit terakhir nomor ponsel".

*   Setelah perlindungan anti-kebocoran diaktifkan, Anda dapat membatasi pengguna untuk mengunduh dan mencetak, serta melarang penyalinan saat melihat DingTalk Docs.

## 6. Cara menghapus dan memulihkan dokumen di Knowledge Base

*   Setelah dokumen di dalam Knowledge Base dihapus, dokumen tersebut akan dipindahkan ke Tempat Sampah. Jika perlu memulihkan dokumen, Anda dapat melakukannya dari Tempat Sampah.
