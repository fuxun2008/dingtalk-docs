## Semua file, tersimpan di satu tempat

### 1. Penyimpanan terpusat di satu tempat

[进度: 已完成]  Di jendela obrolan DingTalk, baik video, gambar, audio, dokumen online, maupun file lokal, klik **"Tambah ke"** pada kartu file untuk membuka panel penyimpanan terpadu DingTalk Docs. Anda dapat menyimpan file ke lokasi mana pun, seperti **"Dokumen Saya", "File Tim", atau "Knowledge Base"**!

### 2. Integrasi "File Tim" pada Drive

[进度: 已完成]  DingTalk Docs mengintegrasikan "File Tim" dari Drive agar file yang dibagikan dapat diakses dan dikelola dalam satu tempat.

[进度: 已完成]  Sebaiknya simpan file lokal yang berjumlah banyak, berkapasitas besar, dan dibagikan ke tim (gambar, video, dan lainnya) di "File Tim".

### 3. Integrasi "File Saya" pada Drive

[进度: 已完成] "Dokumen Saya" mengintegrasikan "File Saya" dari Drive. Semua materi kerja untuk pembelajaran dan penggunaan pribadi dapat disimpan di dalam **"Dokumen Saya"** sehingga materi kerja pribadi terkelola dalam satu tempat.

[进度: 已完成]  Mendukung berbagai metode pengurutan serta pengaturan dengan tarik dan pindahkan, disesuaikan dengan kebiasaan pengguna lama dari dua tipe produk, yaitu Docs dan Drive.

### 4. Pengelolaan dan penyimpanan dokumen kerja harian tim di "Knowledge Base"

[进度: 已完成]  "Knowledge Base" adalah platform pengelolaan pengetahuan organisasi yang menyatukan penyimpanan, pengaliran, dan kolaborasi pengetahuan.

[进度: 已完成]   Dokumen online, spreadsheet lokal, dan file dokumen lain yang memerlukan pengeditan online kolaboratif oleh banyak orang serta pembagian dan pengaliran berulang dapat disimpan dan dikelola di **"Knowledge Base"**!

## II. Menemukan file yang dituju dengan cepat

### 1. Pencarian global

[进度: 已完成]  Masuk ke Beranda melalui **"Dokumen"** pada bilah sisi kiri DingTalk, lalu ketik kata kunci di kolom pencarian di bagian atas. Pencarian mencakup semua konten dari DingTalk Docs maupun Drive.

[进度: 已完成]  Anda juga dapat melakukan pencarian yang lebih tepat berdasarkan filter yang berbeda, seperti bidang lokasi, pembuat, dan pembagi, untuk menemukan dokumen yang dituju dengan cepat.

### 2. Bagikan

[进度: 已完成]  Menambahkan modul "Bagikan" untuk mencari secara efisien konten yang Dibagikan kepada Saya atau Dibagikan oleh Saya melalui penambahan izin, pembagian obrolan, dan cara lainnya.

### 3. Pencarian favorit

[进度: 已完成]  Simpan semua konten dari DingTalk Docs maupun Drive sebagai favorit dalam satu tempat, lalu cari file favorit dari berbagai dimensi.

## III. Pengelolaan efisien, pengaliran yang aman

### 1. Tindakan massal

[进度: 已完成] Direktori "Knowledge Base" mendukung tindakan pemindahan, penyalinan, dan penghapusan secara massal sehingga menghindari repetisi bolak-balik. Rapikan file dengan cepat agar pengelolaan pengetahuan menjadi lebih cepat dan efisien.

Metode pertama: Pada halaman direktori di bilah sisi kiri Knowledge Base, pilih simbol "Tindakan massal", centang konten yang ingin ditindak secara massal, lalu pilih ikon salin, pindahkan, atau hapus.

Metode kedua: Pada halaman direktori Beranda Knowledge Base, arahkan mouse ke depan file atau folder yang ingin ditindak secara massal hingga muncul kotak centang, lalu centang file atau folder tersebut.

### 2. Pengelolaan keamanan

[进度: 已完成] Kontrol izin keamanan ditingkatkan secara menyeluruh dengan penambahan pengaturan kontrol **"Watermark" dan "Anti-kebocoran"** untuk memperkuat keamanan data dokumen serta membuat pengelolaan izin lebih efisien.
