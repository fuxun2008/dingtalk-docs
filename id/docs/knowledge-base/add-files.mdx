Knowledge Base mendukung penambahan <strong>file lokal, File Obrolan, Rapat Cepat, dan Log Kerja</strong>, sekaligus mengumpulkan dan menata materi dari berbagai skenario agar akumulasi serta pengelolaan pengetahuan menjadi lebih praktis.

## Bagaimana cara menambahkan file lokal ke Knowledge Base?

Buka <strong>halaman utama</strong> Knowledge Base >> klik direktori di sisi kiri >> lalu pilih untuk mengunggah file atau folder lokal ke Knowledge Base tersebut.

## Bagaimana cara menambahkan File Obrolan ke Knowledge Base?

**Dokumen lokal**: Klik [Tambahkan ke…] di sudut kanan bawah Kartu dokumen, lalu pilih Knowledge Base tujuan penyimpanan.

**Dokumen online:** Klik [Tambahkan ke…] di sudut kanan bawah Kartu dokumen, lalu pilih Knowledge Base tujuan penyimpanan.

## Bagaimana cara menambahkan Rapat Cepat ke Knowledge Base?

Buka dokumen Rapat Cepat >> klik [...] di sudut kanan atas >> [Tambahkan tautan ke], lalu pilih Knowledge Base dan direktori yang sesuai.

## Bagaimana cara menambahkan Log Kerja ke Knowledge Base?

Buka Log Kerja yang ingin ditambahkan ke Knowledge Base >> klik [Tambahkan ke] >> pilih Knowledge Base dan direktori yang sesuai.

## Menambahkan file grup ke Knowledge Base secara massal?

Pada tampilan Obrolan Grup, klik [**ikon Zoom**] di bagian atas >> pilih [**File**] >> setelah jendela File grup muncul, pilih beberapa file yang ingin ditambahkan ke Knowledge Base >> klik [**Tambahkan ke**] >> pilih Knowledge Base dan direktori yang sesuai. Anda tidak hanya dapat memilih Dokumen, Spreadsheet, dan PDF, tetapi juga Folder, audio, dan lainnya.
