Migrasikan ruang Confluence ke DingTalk Knowledge Base agar organisasi Anda dapat mengumpulkan dan mengelola pengetahuan secara terpusat serta meningkatkan efisiensi kerja. Cara ini mencegah pengelolaan tersebar di berbagai platform kolaborasi kerja yang dapat menurunkan efisiensi kolaborasi.

Ekspor seluruh ruang di Confluence sebagai file zip, lalu migrasikan ke DingTalk Knowledge Base. Setelah pembacaan file selesai, konten ruang yang diimpor akan menjadi satu DingTalk Knowledge Base tersendiri.

---

## Langkah 1: Ekspor file zip dari Confluence

### Langkah ekspor versi Cloud

1) Buka ruang yang akan dimigrasikan >> pilih <strong>Space settings</strong>, lalu klik <strong>Content tools</strong> \> pilih <strong>Export</strong>

2) Pada format ekspor, centang **HTML** \>> klik <strong>Next \>></strong> pilih <strong>Normal Export</strong>

3) Setelah mengirim tugas ekspor, tunggu Confluence menyelesaikan ekspor ruang. Setelah tugas selesai, klik **here** untuk mengunduh ke perangkat lokal

_Catatan: Normal Export mengekspor seluruh knowledge base; Custom Export memungkinkan Anda memilih satu halaman tertentu untuk diekspor secara terpisah, dan proses tidak boleh terputus di tengah jalan_

---

### Langkah ekspor versi Server

1) Buka ruang yang akan dimigrasikan >> pilih <strong>Space Admin</strong>, lalu klik <strong>Content tools</strong> \> pilih <strong>Export</strong>

2) Pada format ekspor, centang **HTML** \>> klik <strong>Next \>></strong> pilih <strong>Normal Export</strong>

3) Centang halaman ruang yang akan diekspor >> setelah selesai memilih, klik <strong>Export</strong> \>> setelah ekspor selesai, klik **here** untuk mengunduh ke perangkat lokal

_Catatan:_

1.  _Tombol Space Admin biasanya berada di pojok kiri bawah halaman, dan posisinya dapat berbeda tergantung versi_

2.  _Normal Export mengekspor seluruh knowledge base; Custom Export memungkinkan Anda memilih satu halaman tertentu untuk diekspor secara terpisah, dan proses tidak boleh terputus di tengah jalan_

---

**Langkah 2: Impor ke DingTalk Knowledge Base**

1) Masuk ke **"DingTalk Docs - Knowledge Base"** \>> klik **[Impor]** di pojok kanan atas >> pilih impor ruang Confluence

2) Pada halaman pengaturan impor >> pilih <strong>file paket zip</strong> serta alamat ruang Confluence >> setelah mengisi, klik <strong>Impor</strong>

      Setelah tugas impor selesai dijalankan, ruang Confluence terkait akan muncul di daftar knowledge base

_**Catatan:**_

1.  _File paket zip adalah file zip yang diekspor pada langkah pertama_

2.  _Alamat ruang Confluence: tempel alamat salah satu halaman konten pada ruang terkait di Confluence. Setelah diimpor, tautan kutipan Confluence pada ruang asli juga akan diganti dengan tautan DingTalk Knowledge Base_

3.  _Saat ini batas maksimum impor untuk satu paket zip adalah_ _**500M**_ _._
