## I. Akses Knowledge Base

*   Versi desktop: pada bilah alat di sisi kiri DingTalk, buka Dokumen, lalu pilih Knowledge Base.

*   Versi ponsel: pada bilah menu bawah, ketuk Lainnya, pilih Dokumen, lalu buka Knowledge Base.

## II. Cara membuat Knowledge Base

*   Versi desktop: di beranda Dokumen, pilih "Knowledge Base", klik "Buat Knowledge Base", lalu pilih Knowledge Base kosong atau templat. Klik "Berikutnya" untuk melanjutkan, atur nama dan foto profil Knowledge Base, maka Knowledge Base berhasil dibuat.

## III. Cara mengubah nama dan ikon Knowledge Base

*   Saat membuat Knowledge Base, Anda dapat mengatur nama dan ikonnya.

*   Klik "…" di sisi kanan Knowledge Base, pilih Pengaturan, lalu pilih Informasi Knowledge Base. Di sini Anda juga dapat mengubah nama dan foto profil Knowledge Base.

## IV. Cara menghapus Knowledge Base

*   Untuk menghapus Knowledge Base: klik sudut kanan atas Knowledge Base untuk masuk ke "Pengaturan" - "Pengaturan Premium", klik "Hapus Knowledge Base", lalu ikuti petunjuk untuk memasukkan "nama Knowledge Base" sebagai konfirmasi. Setelah itu, penghapusan selesai.

*   **Perhatian: setelah suatu Knowledge Base dikonfirmasi untuk dihapus, semua kontennya akan terhapus dan tidak dapat dipulihkan. Lakukan dengan hati-hati.**

## V. Cara membuat file di Knowledge Base

*   Versi desktop, metode 1: buka pohon direktori di sisi kiri beranda Knowledge Base, klik "+" - "Buat Dokumen Online", lalu pilih tipe file yang ingin dibuat, seperti ditunjukkan pada gambar berikut.

## VI. Cara beralih Knowledge Base antar Organisasi/Tim

*   Semua konten yang dibuat di Knowledge Base DingTalk Docs adalah milik Organisasi/Tim. Anda hanya dapat melihat konten dokumen di dalam suatu Organisasi/Tim setelah beralih ke Organisasi/Tim tersebut.
