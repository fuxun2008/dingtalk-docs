<Note>
**Gaya satu**

Langkah 1: Masuk ke antarmuka beranda Kustom, tambahkan tata letak, lalu pilih tata letak tiga kolom.

Langkah 2: Seret modul carousel gambar ke dalam setiap tata letak secara berurutan.

Langkah 3: Klik Simpan untuk kembali ke beranda grup, lalu klik ikon pensil atau klik Tambah untuk masuk ke mode edit.

Langkah 4: Unggah Gambar, lalu konfigurasikan DingTalk Docs atau Tautan yang ingin dituju.

</Note>
Langkah 5: Setelah selesai mengedit, klik Konfirmasi untuk kembali ke beranda grup. Ubah judul kolom di bagian atas gambar, lalu konfigurasikan konten setiap kolom secara berurutan. Efek gaya ini pun tercipta!

<Note>
**Gaya dua**

Langkah 1: Masuk ke beranda Kustom, tambahkan tata letak terlebih dahulu, lalu pilih tata letak tanpa kolom.

Langkah 2: Setelah menambahkan tata letak, seret modul "Akses Cepat" ke dalam tata letak.

Langkah 3: Simpan halaman Kustom, lalu masuk ke beranda grup.

Langkah 4: Pada modul tersebut, klik Tambah konten.

Langkah 5: Setiap Akses Cepat dapat disesuaikan ikonnya (mendukung juga unggah sendiri) serta konten tujuannya.

Langkah 6: Tambahkan Akses Cepat yang ingin ditampilkan secara berurutan.

</Note>
Langkah 7: Setelah selesai menambahkan, simpan dan kembali ke beranda, lalu pilih gaya kisi. Efek tampilan ini pun tercipta!

<Note>
**Gaya tiga**

Langkah 1: Tambahkan tata letak terlebih dahulu di halaman Kustom.

Langkah 2: Seret modul konten bebas ke dalamnya, lalu klik Simpan.

Langkah 3: Kembali ke beranda grup, lalu klik Tambah.

Langkah 4: Klik Sisipkan kolom.

Langkah 5: Sisipkan kolom lagi di dalam kolom, klik ikon ＝, lalu klik ikon palet untuk menyesuaikan warna latar belakang kolom.

Langkah 6: Setiap kolom mendukung penyisipan konten seperti Gambar, Video, dan lainnya, serta dapat menyisipkan Tautan dan menyesuaikan konten teks.

Langkah 7: Setelah selesai mengisi, gunakan bilah alat untuk menyesuaikan Ukuran Font, warna, dan lainnya.

Langkah 8: Setelah menyimpan, efek ini pun tercipta. Jika membutuhkan beberapa baris, sisipkan kolom beberapa kali.

</Note>

<Note>
**Gaya empat**

Langkah 1: Klik Tambah tata letak di halaman Kustom.

Langkah 2: Seret konten bebas ke sini.

Langkah 3: Simpan halaman Kustom.

Langkah 4: Kembali ke beranda grup, lalu klik Tambah.

Langkah 5: Sisipkan kolom.

Langkah 6: Sisipkan tiga kolom; di dalam kolom juga dapat disisipkan kolom lagi.

Langkah 7: Pilih warna latar belakang dan bingkai untuk kolom.

Langkah 8: Masukkan konten ke dalam kolom, lalu klik Konfirmasi. Efek gaya ini pun tercipta!

</Note>

<Note>
**Gaya lima**

Langkah 1: Di antarmuka beranda Kustom, klik Tambah tata letak dua kolom.

Langkah 2: Seret Akses Cepat masing-masing ke dua kolom, simpan, lalu kembali ke beranda grup untuk menambahkan konten.

Langkah 3: Ikon Akses Cepat mendukung unggah gambar secara kustom.

Langkah 4: Isi konten yang ingin ditampilkan secara berurutan, lalu klik Konfirmasi.

Langkah 5: Kembali ke beranda grup, klik "…", lalu pilih gaya Kartu.

Langkah 6: Untuk kolom kedua, lakukan dengan cara yang sama, lalu pilih ikon (ikon juga mendukung pilihan warna!).

Langkah 7: Setelah selesai mengisi konten secara berurutan, klik Konfirmasi.

Langkah 8: Kembali ke beranda grup, maka efek tampilan pun terlihat.

</Note>

**Gaya-gaya di atas hanya sebagai referensi. Silakan kembangkan kreativitas Anda sepenuhnya untuk merancang gaya yang lebih indah dan praktis!**
