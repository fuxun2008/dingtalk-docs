Setelah membuat Grup Pengetahuan, kelola pengguna di dalamnya. Dengan contoh grup kosong, Anda dapat menambah dan menghapus pengguna. Anda juga dapat mengatur tipe pengguna, dan setiap tipe pengguna memiliki izin yang berbeda.

## Cara menambah/menghapus pengguna

*   Menambah pengguna: Buka daftar manajemen pengguna grup, klik "Tambah Pengguna" di kiri atas, lalu tambahkan pengguna dengan salah satu dari empat cara berikut: <strong>kontak, obrolan grup, struktur organisasi, atau impor massal</strong>. Namun, saat ini hanya penambahan pengguna dalam organisasi yang didukung, dan Pengguna eksternal tidak dapat ditambahkan.

*   Menghapus pengguna: Untuk pengguna yang sudah ditambahkan ke grup, klik tindakan "Hapus" untuk mengeluarkannya dari grup.

## Penjelasan izin peran pengguna grup

Peran pengguna grup terdiri dari: Pemilik, Admin, Pengguna, pengguna Hanya Baca (dapat mengunduh), dan pengguna Hanya Baca, dengan izin masing-masing sebagai berikut:

| Tipe peran | Izin grup |
| --- | --- |
| Pemilik | Mengalihkan grup, mengelola, mengedit halaman utama dan Knowledge Base |
| Admin | Mengelola, mengedit halaman utama dan Knowledge Base |
| Pengguna | Mengedit konten |
| Pengguna Hanya Baca (dapat mengunduh) | Melihat/mengunduh konten |
| Pengguna Hanya Baca | Hanya dapat melihat, tidak dapat mengunduh |
