DingTalk Mind mendukung penyisipan gambar dalam berbagai format, seperti PNG, JPG, dan GIF, sebagai cara ampuh untuk memperkaya kemampuan ekspresi peta pikiran.

## Petunjuk penggunaan Sisipkan Gambar

*   Menyisipkan gambar di komputer: Dalam mode "Tampilan Peta Pikiran", klik tombol "Sisipkan Gambar" pada toolbar, lalu pilih file gambar lokal untuk diunggah.

*   Anda juga dapat menyalin file gambar lokal, lalu menempelkannya dengan pintasan Command + V atau Ctrl + V.

## Menyisipkan gambar di ponsel

*   Dalam mode "Tampilan Peta Pikiran", klik tombol "Sisipkan Gambar" pada toolbar node, lalu pilih gambar dari Album sistem untuk diunggah.
