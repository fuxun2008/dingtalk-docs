## Bagaimana cara mengganti struktur tata letak, subjek, dan jenis garis?

*   Di komputer: Dalam mode "Tampilan Peta Pikiran", klik tombol di kiri atas layar untuk memunculkan panel, lalu ganti ke struktur tata letak, jenis garis, dan subjek yang Anda sukai.

*   Di ponsel: Dalam mode "Tampilan Peta Pikiran", klik tombol di kanan bawah layar untuk memunculkan panel, lalu ganti ke tata letak yang Anda sukai.
