## Edit konten

*   Untuk mengubah teks pada sebuah node, klik node tersebut untuk memilihnya dan masuk ke mode edit, lalu ubah kontennya.

*   Selain itu, klik dua kali pada node untuk langsung memilih seluruh teks agar lebih mudah diedit.

## Sisipkan node setara / node anak

*   Untuk menyisipkan node anak atau node setara setelah sebuah node, pilih dulu node tersebut, lalu klik "Sisipkan node setara" atau "Sisipkan node anak" pada toolbar yang muncul untuk menambahkan node baru.

*   Tekan tombol Enter / Tab pada keyboard untuk menyisipkan node setara / node anak dengan cepat.

## Edit konten di perangkat seluler

*   Saat mengakses peta pikiran di perangkat seluler dalam mode "Tampilan Peta Pikiran", ketuk tombol pada gambar untuk masuk ke mode edit.

## Sisipkan node setara / node anak di perangkat seluler

*   Dalam mode "Tampilan Peta Pikiran", ketuk tombol pada toolbar node untuk menyisipkan node setara / node anak.
