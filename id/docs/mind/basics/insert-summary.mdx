Gunakan [Sisipkan ringkasan] untuk menambahkan node ringkasan ke peta pikiran agar penyampaian topik konten menjadi lebih jelas.

## Pintu masuk fitur Sisipkan ringkasan

### Versi desktop

Buka **DingTalk versi desktop > Dokumen > Buat/masuk ke peta pikiran terkait >** klik **node terkait >** lalu pilih **ikon Sisipkan ringkasan**.

### Versi ponsel

Buka **DingTalk versi ponsel >** ketuk **Lainnya di bagian bawah > Dokumen > Buat/masuk ke peta pikiran terkait >** klik **node terkait > Sisipkan ringkasan**.

## Cara menggunakan Sisipkan ringkasan

*   Tambah ringkasan

*   Hapus ringkasan

> Pilih node ringkasan, lalu tekan tombol Backspace untuk menghapusnya.
