Dalam mode Tampilan Peta Pikiran, Anda dapat memperbesar dan menggulir seluruh kanvas untuk beralih dengan lebih mudah antara detail dan gambaran menyeluruh.

## Memperbesar kanvas di komputer

*   Tersedia empat cara:

1.  Ctrl + gulir mouse.

2.  Kontrol dua jari pada trackpad (untuk saat ini belum didukung di klien DingTalk Mac; buka melalui browser untuk pengalaman yang lebih baik).

3.  Ctrl + +/-.

4.  Atur pembesaran kanvas melalui alat zoom di pojok kanan bawah.

## Memindahkan kanvas di komputer

*   Tersedia lima cara:

1.  Gunakan roda gulir mouse untuk memindahkan kanvas.

2.  Kontrol dua jari pada trackpad.

3.  Tekan dan tahan tombol kanan mouse untuk menyeret kanvas.

4.  Klik ikon telapak tangan di sisi kiri untuk memindahkan kanvas.

5.  Saat kontennya cukup banyak, seret bilah gulir untuk memindahkan kanvas.

## Memperbesar kanvas di ponsel

*   Dalam mode Tampilan Peta Pikiran, cubit dengan dua jari di area kosong kanvas untuk memperbesar kanvas.

*   Setelah berhasil memperbesar dengan dua jari, rasio pembesaran saat ini akan ditampilkan di tengah layar.

## Memindahkan kanvas di ponsel

*   Dalam mode Tampilan Peta Pikiran, geser area kosong kanvas dengan satu jari untuk memindahkan kanvas.
