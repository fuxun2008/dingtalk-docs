## Edit tampilan kerangka di desktop

*   Klik tombol "Tampilan Kerangka" di sebelah kiri untuk beralih ke mode tampilan kerangka.

## Menyisipkan node setingkat

*   Pilih lokasi tempat Anda ingin menyisipkan node, lalu tekan Enter untuk menyisipkan node yang setingkat dengan lokasi yang dipilih saat ini.

## Menjorokkan satu tingkat ke kanan atau kiri

*   Pilih node yang diinginkan, tekan Tab untuk menjorokkan ke kanan, dan tekan Shift + Tab untuk menjorokkan ke kiri.

## Menghapus node

*   Pilih node yang diinginkan, lalu tekan Delete untuk menghapus kontennya. Ketika kursor berada di awal konten node, seluruh node akan dihapus dan kontennya digabungkan ke node sebelumnya.

## Memilih banyak node

*   Tekan dan tahan tombol kiri mouse, lalu semua node yang dilewati akan dipilih.

## Menyeret node

*   Tekan dan tahan titik kecil di depan node untuk menyeret node saat ini ke lokasi yang diinginkan.

## Membentangkan atau melipat

*   Arahkan mouse ke node yang diinginkan, lalu klik segitiga kecil di sebelah kiri untuk membentangkan atau melipatnya.

## Edit tampilan kerangka di ponsel

*   Klik tombol "Tampilan Kerangka" di bagian atas untuk beralih ke mode tampilan kerangka.

## Menjorokkan satu tingkat ke kanan atau kiri

Tersedia dua cara:

1.  Geser node ke kiri atau kanan untuk menjorokkannya ke arah tersebut.

2.  Klik alat jorok ke kiri atau kanan pada bilah alat.

## Membuat salinan node

*   Klik tombol buat salinan node pada bilah alat untuk menyalin node yang dipilih saat ini beserta node bawahannya.

## Membentangkan atau melipat

*   Tersedia dua cara:

1.  Pilih node yang memiliki node bawahan, lalu klik segitiga kecil di sebelah kiri node.

2.  Klik alat bentang atau lipat pada bilah alat.

## Menghapus node

*   Tersedia dua cara:

1.  Pilih node, lalu gunakan tombol hapus pada papan ketik lunak.

2.  Klik tombol hapus pada bilah alat untuk menghapus node saat ini beserta node bawahannya.

## Urungkan atau ulangi

*   Gunakan tombol urungkan atau ulangi pada bilah alat untuk mengurungkan dan mengulangi tindakan yang telah dilakukan sebelumnya.
