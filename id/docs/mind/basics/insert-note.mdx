Fitur alias adalah deskripsi tambahan untuk sebuah subjek. Jika Anda ingin memberi catatan singkat atau uraian mendetail pada suatu subjek tanpa mengganggu kerapian dan keindahan mind map, tuliskan teks tersebut ke dalam alias.

**Titik masuk fitur sisipkan alias**

*   Fitur sisipkan alias saat ini hanya tersedia di versi desktop; versi ponsel akan segera hadir. Untuk menggunakan fitur ini, klik toolbar, lalu edit alias seperti ditunjukkan pada gambar berikut:

## Cara menggunakan sisipkan alias

*   Setelah menambahkan sebuah alias, klik konten alias atau ikon [Edit alias] untuk memunculkan panel edit alias dan langsung mengeditnya.
