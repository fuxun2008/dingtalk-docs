File DingTalk Mind sangat mudah dibagikan kepada kolaborator lain. Berkat beragam pengaturan izin, file dapat memenuhi kebutuhan berbagai skenario kolaborasi.

## Petunjuk penggunaan di komputer

*   Klik tombol "Bagikan" di kanan atas. Pada panel yang muncul, atur opsi berbagi dan izin.

## Cara berbagi

*   Klik "Salin tautan" untuk menyalin tautan file saat ini ke clipboard. Tautan tersebut dapat ditempel ke dokumen lain atau jendela obrolan DingTalk.

*   Klik "Kirim ke obrolan". Pada jendela yang muncul, pilih Pesan Langsung atau Obrolan Grup yang dituju, lalu klik "Konfirmasi" untuk menyelesaikan berbagi.

*   Klik "Bagikan kode QR" untuk menyimpan kode QR alamat akses file saat ini, atau langsung meneruskannya ke jendela obrolan.

## Cara mengelola izin

*   Klik [Tambah kolaborator] untuk memberikan izin kepada orang tertentu, dengan pilihan berikut.

*   Pilih izin bagi orang yang ditambahkan. Tersedia tindakan seperti dapat diedit, dapat dilihat/diunduh, hanya dapat dilihat, dan menghapus izin.

*   Anda dapat membuka file bagi seluruh anggota di organisasi saat ini. Untuk tipe file yang cocok dibuka di organisasi saat ini, izin dapat diberikan dengan cepat.

###

*   Pada jendela yang muncul, tambahkan orang atau grup tertentu. Setelah dikonfirmasi, atur izin secara fleksibel dan kirim notifikasi kepada pihak terkait untuk menginformasikan status izin terbaru secara tepat waktu.

## Petunjuk berbagi di ponsel

*   Di ponsel, buka fitur berbagi online melalui menu di kanan atas. Fitur ini memudahkan Anda menyelesaikan pengaturan berbagi dan izin langsung di ponsel.

*   Ponsel mendukung berbagai metode berbagi:

1.  Berbagi langsung ke obrolan

2.  Salin tautan dokumen

3.  Buat kode QR

4.  Bagikan ke WeChat dan QQ

## Cara mengelola izin di ponsel

*   Setelah mengklik [Bagikan], klik [Saat ini x orang memiliki izin akses] untuk masuk ke halaman kelola izin, seperti ditunjukkan pada gambar di bawah.

*   Halaman kelola izin mendukung penambahan departemen tertentu, grup tertentu, dan pengguna tertentu.
