Tugaskan tugas kepada seseorang di dalam node Peta Pikiran untuk meningkatkan kolaborasi asinkron pada Peta Pikiran.

## Pintu masuk fitur penugasan tugas

*   Klik toolbar di sisi kiri, lalu pilih [Perluas kolaborasi] untuk melihat detail kolaborasi tugas terkait, seperti ditunjukkan pada gambar berikut:

    ## Cara menggunakan fitur

*   Klik untuk memutar video dan pelajari cara menugaskan tugas.
