Ganti nama judul file yang sudah dibuat agar lebih mudah digunakan dalam berbagai skenario penataan.

## Petunjuk penggunaan

*   Untuk mengganti nama judul, Anda perlu memiliki izin edit atau kelola pada file terkait. Pada versi desktop, klik area judul di bagian atas untuk menggantinya.

*   Pada versi ponsel, ketuk ikon [...] di pojok kanan atas, pilih Ganti nama, lalu ubah nama file pada jendela yang muncul.
