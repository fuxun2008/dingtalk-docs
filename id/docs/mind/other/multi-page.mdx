## Nilai fitur

Tambahkan beberapa kanvas langsung dalam file Peta Pikiran dan bagi berbagai subjek secara bebas, sehingga konten lebih rapi dan penyampaian ide menjadi teratur.

## Skenario penggunaan

Ding Sanduo adalah kepala departemen perencanaan acara di sebuah perusahaan periklanan. Setiap hari, ia menggunakan DingTalk Mind untuk membuat rencana pemasaran, rencana acara, dan lainnya. Satu rencana proyek memerlukan beberapa Peta Pikiran, sehingga proses berbagi dan berkolaborasi menjadi sangat merepotkan. Setelah Peta Pikiran mendukung "Mode multi-halaman", Anda dapat langsung menambahkan beberapa kanvas dalam satu file Peta Pikiran, membagi subjek secara bebas, serta mengganti nama kanvas, sehingga berbagi konten menjadi lebih mudah.

## Petunjuk penggunaan

Di bagian paling bawah kanvas Peta Pikiran, klik ikon + untuk menambahkan kanvas Peta Pikiran baru. Anda dapat menambahkan beberapa halaman, lalu menghapus atau menggantinya.
