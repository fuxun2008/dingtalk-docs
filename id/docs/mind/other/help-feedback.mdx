## Petunjuk pengiriman masukan

*   Entri fitur di desktop: klik [...] di kanan atas, lalu pilih **Bantuan & masukan** pada menu drop-down untuk mendapatkan bantuan penggunaan.

## Melihat Panduan Pengguna

*   Klik tombol "Panduan Pengguna" untuk membuka **Panduan Pengguna DingTalk**.
