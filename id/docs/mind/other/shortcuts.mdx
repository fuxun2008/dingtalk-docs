Saat membuat peta pikiran, pintasan membantu Anda memasukkan konten dengan lebih baik, mengurangi peralihan antara mouse dan keyboard, serta meningkatkan efisiensi pengetikan.

## Petunjuk penggunaan

*   Pilih satu atau beberapa node, lalu tekan pintasan. Pintasan yang tidak terkait dengan node dapat digunakan tanpa memilih konten.

## Mode tampilan peta pikiran

*   Sistem Mac OS:

| Kategori pintasan | Fungsi pintasan | Pintasan |
| --- | --- | --- |
| Umum | Sisipkan node setingkat | Enter |
|  | Sisipkan node anak | Tab |
|  | Sisipkan node induk | Shift + Tab |
|  | Hapus node | Delete, Backspace |
|  | Navigasi node | ↑↓←→ |
|  | Urungkan | ⌘ + Z |
|  | Ulangi | ⌘ + Y |
| Tindakan node | Salin node | ⌘ + C |
|  | Potong node | ⌘ + X |
|  | Tempel node | ⌘ + V |
|  | Buat salinan node | ⌘ + D |
|  | Perluas/ciutkan | ⌘ + . |
| Navigasi | Perbesar kanvas | ⌘ + + |
|  | Perkecil kanvas | ⌘ + - |
|  | Masuk mode presentasi | ⌘ + Shift + P |
|  | Asisten pintasan | Control + H |

## Mode tampilan kerangka

*   Sistem Mac OS

| Kategori pintasan | Fungsi pintasan | Pintasan |
| --- | --- | --- |
| Umum | Indentasi satu tingkat ke kanan | Tab |
|  | Indentasi satu tingkat ke kiri | Shift + Tab |
|  | Urungkan | ⌘ + Z |
|  | Ulangi | ⌘ + Y |
| Tindakan node | Sisipkan node setingkat | Enter |
|  | Hapus node | Delete, Backspace |
|  | Buat salinan node | ⌘ + D |
|  | Perluas/ciutkan | ⌘ + . |
|  | Pilih node sebelumnya | ↑ |
|  | Pilih node berikutnya | ↓ |
| Navigasi | Masuk mode presentasi | ⌘ + Shift + P |
|  | Asisten pintasan | Control + H |
