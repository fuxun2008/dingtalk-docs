**Xiaoyue sang desainer:** akhirnya tidak perlu lagi membawa prototipe cetak untuk menjelaskannya ke orang lain!

## Latar belakang

Desainer sering kali perlu menjelaskan konsep kepada orang lain, dan materi penjelasannya memuat banyak gambar serta video. Desainer juga kerap perlu mengirimkan konsep ini kepada mitra eksternal.

## Titik kendala

Saat menjelaskan konsep desain, desainer sering harus berpindah-pindah antara PPT dan file desain, terutama ketika menampilkan gambar panjang. Satu-satunya cara adalah membuka software desain untuk mempresentasikannya, dan ini sangat merepotkan.

Catatan tambahan: saat mengirimkan konsep desain ke mitra eksternal, konsep tersebut perlu dikonversi menjadi file gambar agar tidak dapat diubah.

## Setelah menggunakan Knowledge Base DingTalk

*   Baik gambar bergerak maupun video, cukup seret dan lepas untuk menyisipkannya dengan mudah. Tata letak fleksibel, teks dan gambar menyatu indah.

*   Dalam mode presentasi, gulir mulus menampilkan gambar panjang dengan sempurna.
