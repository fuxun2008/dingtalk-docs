> **Pengenalan skenario:** Saya adalah editor dokumen. Setiap dokumen yang saya buat perlu ditinjau oleh beberapa rekan untuk memastikan kontennya benar. Bagaimana caranya agar lebih efisien~

## Alur tindakan

*   **Langkah 1    Buka DingTalk Docs dan edit konten dokumen secara online**

    > Dokumen dapat dibuat baru atau dibuat dari templat.

*   **Langkah 2    Setelah selesai, klik Bagikan untuk masuk ke Kelola izin, lalu berikan izin kepada peninjau sesuai kebutuhan**

    > Mendukung penambahan izin berdasarkan orang, grup, atau departemen. Setelah izin diatur, pihak terkait akan diberi tahu melalui pesan obrolan DingTalk, dan mereka dapat langsung membuka dokumen tujuan dengan mengklik tautan "Bagikan".

*   **Langkah 3    Di akhir dokumen, buat tugas untuk menyebut (@) dan mengingatkan peninjau, lalu atur pengingat tepat waktu serta tenggat waktu agar peninjauan selesai tepat waktu**

> Mendukung pengeditan online real-time oleh beberapa orang dengan konten yang tersimpan otomatis; tugas dan acara mengirim notifikasi pengingat secara otomatis; lihat riwayat pengeditan untuk melacak progres peninjauan kapan saja. Selama proses peninjauan, peninjau dapat memanfaatkan fitur "**Komentar**" untuk berkomunikasi dengan editor kapan saja, tanpa perlu repot beralih antarmuka.

Melalui 3 langkah sederhana di atas, sebagai penanggung jawab dokumen, Anda dapat menyelesaikan pekerjaan meminta revisi dengan lancar, tanpa canggung mengirim pesan untuk menagih revisi secara langsung. Selain itu, DingTalk Docs mendukung peninjauan online oleh beberapa orang tanpa saling mengganggu progres. Silakan coba~ Gunakan DingTalk Docs untuk menyatukan kebijaksanaan banyak orang dengan cepat!

**2. Tanya: Bagaimana cara mengatur izin?**

Jawab: Di antarmuka pengeditan dokumen, klik Bagikan di kanan atas >> Undang kolaborator >> Tambah orang tertentu >> Pilih departemen, grup, atau individu dalam daftar kontak untuk menambahkan izin >> Beri tahu pihak terkait melalui pesan DingTalk.
