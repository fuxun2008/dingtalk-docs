Setiap tahun, Double 11 menjadi ujian besar bagi para pedagang e-commerce. Ajang ini tidak hanya menguji strategi operasional pedagang dalam menghadapi promo besar, tetapi juga efisiensi kolaborasi internal tim. E-commerce internet dan ritel baru selalu menjadi tipe organisasi dengan tingkat keaktifan tinggi di DingTalk. Mereka menggunakan DingTalk Docs dan Rapat Cepat untuk meningkatkan efisiensi kolaborasi dokumen, manajemen rapat, dan manajemen pengetahuan, sehingga tim dapat memenangkan pertempuran efisiensi kolaborasi dalam promo besar.

## 01 ｜ Mulai dari Knowledge Base

Persiapan promo besar biasanya dimulai dengan membuat grup obrolan. Selain Obrolan Departemen, tim juga membuat grup khusus untuk aktivitas promo besar dan perencanaan proposal. Pada tahap ini, banyak dokumen dan materi diunggah serta dikirim ke dalam grup. Berikut satu trik jitu: sebelum promo besar, buat sebuah Knowledge Base. Dokumen dan materi di grup DingTalk dapat disimpan ke Knowledge Base DingTalk Docs hanya dengan sekali klik. Selama proses penyimpanan, pilih directory tree yang sesuai agar dokumen tersimpan sekaligus terkelola dengan baik.

### Fitur inti Knowledge Base: struktur directory tree, kelola izin, simpan File grup DingTalk ke Knowledge Base dengan sekali klik

## 02 ｜ Tulis proposal rencana aktivitas yang baik dengan DingTalk Docs

Departemen perencanaan bisa dibilang merupakan departemen paling kreatif di perusahaan. Mereka sering kali perlu menciptakan berbagai tipe konten. Saat menyusun proposal dengan DingTalk Docs, gunakan garis miring "/" untuk menyisipkan berbagai elemen guna menyajikan proposal aktivitas.

### Kreasi bebas dokumen: sisipkan garis miring, Peta Pikiran, kolom, dan diagram alur untuk menyajikan proposal rencana aktivitas secara visual

## 03 ｜ Kolaborasi dokumen tim, curah pendapat, dan presentasi proposal dengan mudah

Setelah proposal rencana aktivitas selesai, tim perlu berkoordinasi dengan departemen promosi, media baru, layanan pelanggan purnajual, dan logistik untuk berdiskusi bersama. Kolaborasi lintas tim dilakukan melalui dokumen dengan menambahkan komentar teks secara real-time. Dalam proses ini, informasi produk dapat langsung dikomentari sehingga pandangan dapat diselaraskan, misalnya diskon produk, stok, dan waktu aktivitas promo besar. Setelah memberi komentar, kirim langsung obrolan DingTalk untuk mengingatkan rekan agar melihat konten tersebut. Dengan begitu, proposal aktivitas dapat difinalisasi secara efisien.

### Kolaborasi dokumen, presentasi mudah: komentar teks, mode presentasi yang seketika berubah menjadi PPT, dan edit presentasi untuk membuat konten laporan dengan mudah

[Lihat lampiran "Langkah 3: Curah pendapat, sempurnakan proposal.mp4" di DingTalk Docs.](https://docs.dingtalk.io/i/nodes/EpGBa2Lm8azvKwexf6Zx4jKMWgN7R35y?iframeQuery=anchorId%3DX02l9xwagr5dvd6uvkpjxs)

## 04 ｜ Kolaborasi dan analisis data, seimbangkan keamanan dan efisiensi, dengan notifikasi pembaruan data secara real-time

Selama masa promo besar, departemen operasional dan promosi perlu menganalisis dan menghitung data konversi uji coba berbagai produk. Data ini bersifat rahasia, sehingga hanya rekan tertentu yang memiliki izin yang boleh melihatnya di Spreadsheet. Melalui fitur penguncian Sel pada Spreadsheet DingTalk, informasi data sensitif dalam Spreadsheet dapat dilindungi, sekaligus menyeimbangkan keamanan dan efisiensi.

### Kolaborasi data Spreadsheet: kunci Sel agar data aman dan terkendali; ikuti pilihan untuk mengetahui aktivitas data terbaru secara real-time

## 05 ｜ Gunakan Rapat Cepat untuk rapat proyek dan bantu tim menyelenggarakan setiap rapat review dengan baik

Setelah setiap aktivitas promo besar berakhir, tim perlu melakukan komunikasi review terhadap hasilnya. Rapat merupakan skenario kolaborasi paling bernilai di dalam tim. Dengan Rapat Cepat, setiap orang dapat menyelenggarakan rapat dengan agenda yang telah disiapkan, pemahaman yang memadai, diskusi yang terfokus, kesimpulan yang disepakati, dan tugas tindak lanjut yang jelas.
