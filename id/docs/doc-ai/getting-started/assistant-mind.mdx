## 1. Mengenal Tabler DingTalk Docs · Peta Pikiran

<strong>DingTalk Docs</strong> bekerja sama dengan <strong>model besar Tongyi Alibaba Group</strong> untuk mengembangkan alat bantu kreasi dokumen berbasis model besar pada Peta Pikiran, yaitu alat cerdas untuk dokumen. Alat ini memberikan inspirasi dan ide kepada pengguna. Pada Peta Pikiran, alat ini otomatis menghasilkan peta pikiran lengkap berdasarkan konten node, memperluas kemampuan berpikir tanpa batas, serta menghasilkan artikel dengan sekali klik untuk menyelesaikan kreasi konten secara efisien.

## 2. Fitur utama

Saat ini tersedia 3 fitur inti: <strong>Kreasi Cerdas, Beri Saya Inspirasi, dan Hasilkan Artikel</strong>.

*   **Kreasi Cerdas:** Masukkan sebuah subjek untuk bertanya kepada AI, lalu subjek dan garis besar baru akan otomatis dibuat dengan menampilkan node kunci serta informasi penting, **membantu Anda menyusun kerangka pemikiran dengan cepat**.

*   **Beri Saya Inspirasi:** Berdasarkan subjek atau node yang sudah ada, lanjutkan kreasi dengan menampilkan konten node tingkat berikutnya, **membantu Anda menyempurnakan node peta pikiran secara cerdas**.

*   **Hasilkan Artikel:** Berdasarkan node peta pikiran, hasilkan dokumen lengkap. Anda dapat melakukan kreasi konten sekali klik per paragraf atau untuk seluruh teks, **menghasilkan satu artikel utuh dan mendukung penyimpanan sebagai dokumen online**.

## 3. Skenario penggunaan

Saat ini tersedia dukungan untuk berbagai skenario, seperti <strong>garis besar acara, panduan wisata, penataan ide, penulisan artikel, daftar barang, peta pembelajaran, rencana kerja, dan catatan pembelajaran</strong>. Anda dapat menggunakan AI kapan saja untuk meningkatkan efisiensi kerja dan belajar.

| **Skenario penggunaan** | **Fitur terkait** | **Contoh input** |
| --- | --- | --- |
| Garis besar acara | Kreasi Cerdas, Beri Saya Inspirasi | Misalnya: Garis besar konten peluncuran produk DingTalk |
| Panduan wisata | Kreasi Cerdas, Beri Saya Inspirasi | Misalnya: Panduan wisata Hangzhou |
| Penataan ide | Kreasi Cerdas, Beri Saya Inspirasi, Hasilkan Artikel | Misalnya: Cara cepat mempelajari bidang baru |
| Penulisan artikel | Kreasi Cerdas, Hasilkan Artikel | Misalnya: Mengapa anak muda mulai "menyerah pada usaha" |
| Daftar barang | Kreasi Cerdas, Beri Saya Inspirasi | Misalnya: Barang wajib untuk mendaki gunung |
| Peta pembelajaran | Kreasi Cerdas | Misalnya: Sistem pengetahuan operasional media baru |
| Rencana kerja | Kreasi Cerdas | Misalnya: Rencana kerja operasional produk kuartal kedua |
| Catatan pembelajaran | Kreasi Cerdas, Beri Saya Inspirasi | Misalnya: Apa itu pertumbuhan berbasis produk |

## 4. Cara mengaktifkan?

Pada Peta Pikiran DingTalk, di bilah alat sebelah kiri,

Anda dapat memilih **"Kreasi Cerdas" dan "Hasilkan Artikel"**.

Pilih node peta pikiran, lalu pada bilah alat mengambang,

aktifkan **"Beri Saya Inspirasi"** dari AI.
