## Apa itu koreksi cerdas?

Aktifkan pemeriksaan cerdas untuk salah ketik dan kesalahan ejaan yang umum, lalu dapatkan saran perbaikan untuk mendukung penulisan Anda.

## Skenario penggunaan

Ding Sanduo adalah staf operasional konten di departemen perencanaan yang setiap hari menggunakan DingTalk Docs untuk menulis naskah promosi, artikel kerja, dan lainnya. Setelah fitur koreksi cerdas diaktifkan, sistem akan memeriksa secara cerdas setiap salah ketik atau kesalahan ejaan yang tidak sengaja terjadi saat menulis dan memberikan saran perbaikan. Setelah penulisan selesai pun, Anda tidak perlu lagi memeriksa satu per satu, sehingga menghemat lebih banyak waktu kerja.

## Panduan penggunaan

Klik menu di pojok kiri atas bilah navigasi, pilih Alat, lalu Koreksi cerdas, dan aktifkan tombol koreksi cerdas.
