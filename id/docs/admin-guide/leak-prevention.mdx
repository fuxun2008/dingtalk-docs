Ketika Anda perlu meningkatkan tingkat kerahasiaan konten dokumen dan mencegahnya diunduh, disalin, dibuat salinannya, atau dicetak, Admin dokumen dapat mengaktifkan fitur "perlindungan anti-kebocoran" untuk mencegah kebocoran konten.

## Penjelasan cara pengaktifan

*   Setelah dokumen mengaktifkan fitur "perlindungan anti-kebocoran", sebagian atau semua orang dapat dilarang untuk menyalin, mengunduh, membuat salinan, dan mencetak.

    # Penjelasan cakupan berlakunya pengaktifan

    Knowledge Base, Folder, maupun dokumen/file tunggal semuanya dapat mengaktifkan "perlindungan anti-kebocoran". Setelah diaktifkan, berikut rincian penerapan dan dampaknya (catatan: penyalinan mencakup menyalin, mengunduh, membuat salinan, dan mencetak):

*   Jika Knowledge Base mengaktifkan "perlindungan anti-kebocoran", semua dokumen/file di dalamnya tidak dapat disalin;

*   Jika suatu Folder mengaktifkan "perlindungan anti-kebocoran" secara terpisah, semua dokumen/file di dalam Folder tersebut tidak dapat disalin;

*   Jika suatu dokumen mengaktifkan "perlindungan anti-kebocoran" secara terpisah, semua sub-dokumen dari dokumen tersebut tidak dapat disalin;

**Catatan khusus:** Ketika "Knowledge Base" atau "Folder" mengaktifkan "perlindungan anti-kebocoran", jika Admin mencentang "hanya berlaku untuk konten yang dapat dipratinjau", maka hanya dokumen/file yang dapat dipratinjau yang dibatasi (konten yang tidak dapat dipratinjau, seperti file bertipe zip, exe, dan lainnya, tetap dapat diunduh untuk memudahkan kolaborasi).
