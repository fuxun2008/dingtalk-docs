## 1. Aturan penghitungan kapasitas DingTalk Docs

| Tipe File | Perilaku penggunaan | Apakah dihitung dalam kapasitas |
| --- | --- | --- |
| File lokal | Mengunggah file di dalam DingTalk Docs. Tipe file mencakup dokumen, gambar, audio/video, file terkompresi, dan lainnya. | Dihitung |
| Dokumen online | Membuat atau mengimpor dokumen online (dokumen, spreadsheet, peta pikiran, whiteboard) di dalam DingTalk Docs, lalu mengeditnya dengan <strong>menyisipkan lampiran seperti gambar, audio/video, file terkompresi, dan file lokal</strong>, serta konten lainnya. | **Resmi dihitung**<br />**mulai 30 Juli 2023** |
| Pintasan | Menambahkan pintasan di dalam DingTalk Docs. | Tidak dihitung |

## 2. Cakupan penghitungan kapasitas DingTalk Docs

**Penghitungan kapasitas mencakup: "Dokumen Saya" dan "Knowledge Base".**

*   **Dokumen Saya:** Ruang yang dialokasikan organisasi untuk manajemen pengetahuan pribadi Anda. Gunakan ruang ini untuk mengumpulkan dan mengelola pengetahuan kerja pribadi.

*   **Knowledge Base:** Manajemen pengetahuan berbasis perusahaan, departemen, proyek, dan lainnya untuk berbagi dan berkolaborasi. Gunakan untuk mengumpulkan dan mengelola pengetahuan organisasi.

## 3. Apa itu file lokal dan apa itu dokumen online?

**File lokal:** Setelah file lokal diunggah ke Knowledge Base, format file tidak berubah. Anda memperoleh tautan file untuk dibagikan, dan sebagian format mendukung pratinjau.

**Dokumen online:** Mencakup dua jenis, yaitu membuat dokumen online dan mengimpor dokumen online.

*   Membuat dokumen online: Saat ini mendukung pembuatan tiga tipe dokumen, yaitu DingTalk Docs, Spreadsheet, dan Peta Pikiran DingTalk.

*   Mengimpor dokumen online: Sebagian tipe file lokal yang diimpor ke Knowledge Base dapat dikonversi menjadi dokumen online, memperoleh tautan dokumen untuk dibagikan, serta dikonversi ke format DingTalk Docs. Penjelasan konversi impor:

| **Tipe file lokal** | **Tipe file online** |
| --- | --- |
| doc, docx, markdown, mark, md, txt | DingTalk Docs |
| xls, xlsx | Spreadsheet |
| xmind | Peta Pikiran DingTalk |

## 4. Tipe file apa saja yang saat ini didukung untuk diunggah dan diimpor? Apakah ada batasan ukuran file?

Unggah File mendukung pratinjau berbagai tipe file, dengan ukuran maksimal 8G per file. Impor hanya mendukung tipe dokumen, dengan ukuran maksimal 20M per file. Perbedaan detailnya sebagai berikut:

| **Metode transfer** | **Tipe File** | **Format yang mendukung pratinjau** | **Batasan ukuran** |
| --- | --- | --- | --- |
| Unggah | Dokumen | pdf, pptx, ppt, pot, potx, pps, ppsx, dps, dpt, pptm, potm, ppsm, xls, xlt, et, ett, xlsx, xltx, xlsb, xlsm, xltm, csv, doc, dot, wps, wpt, docx, dotx, docm, dotm, txt, xmind | Maksimal 8G per file |
|  | Gambar | peg, bmp, png, jpg, ico, webp |
|  | Audio/video | 3GP, AVI, FLV, MP4, M3U8, MPG, ASF, WMV, MKV, MOV, TS, WebM, MXF, AAC, AC-3, ADPCM, AMR, DSD, MP1, MP2, MP3, PCM, RealAudio, Windows Media Audio |
|  | Lainnya | file terkompresi zip |
| Impor | Dokumen | docx, xlsx, doc, xls, txt, xmind, markdown, mark, md | Maksimal 20M per file |

Untuk penjelasan lebih lanjut tentang "Unggah" dan "Impor", lihat:

*   Knowledge Base mendukung unggah file lokal

*   Perbedaan antara "Unggah" dan "Impor" di Knowledge Base DingTalk Docs

## 6. Bagaimana cara memperluas kapasitas dengan berbayar?

Mengunggah file lokal di DingTalk Docs (Dokumen Saya, Knowledge Base) akan menggunakan kapasitas Drive organisasi. Menyisipkan gambar, audio/video, atau file terkompresi ke dalam dokumen online (dokumen, spreadsheet, peta pikiran, whiteboard) juga akan menggunakan kapasitas Drive organisasi. Detailnya dapat dilihat pada poin pertama di atas, "Aturan penghitungan kapasitas DingTalk Docs".

DingTalk secara default memberikan setiap organisasi 100GB kapasitas Drive organisasi gratis permanen. Jika kapasitas tidak mencukupi, organisasi dapat membelinya sendiri.
