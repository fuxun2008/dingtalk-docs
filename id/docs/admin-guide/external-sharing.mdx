Dalam artikel ini, "membagikan dokumen ke luar organisasi" secara khusus berarti menambahkan orang dari luar organisasi sebagai kolaborator.

## I. Apakah dokumen boleh dibagikan ke luar organisasi?

*   Secara default, dokumen di Organisasi Anda boleh dibagikan ke luar organisasi <strong>(yaitu, boleh menambahkan</strong> orang dari luar <strong>organisasi sebagai kolaborator)</strong>. Untuk mengubahnya, lihat bagian ketiga.

*   Secara default, hanya orang yang memiliki izin kelola dokumen yang dapat membagikan dokumen ke luar organisasi. Untuk mengubahnya, lihat bagian keempat.

*   Jika kondisinya tidak sesuai dengan ketentuan di atas, kemungkinan Admin telah mengubah konfigurasi. Lihat bagian kedua.

## II. Mengapa saya tidak bisa menambahkan orang dari luar organisasi sebagai kolaborator dokumen?

### 1) Dokumen ini dikonfigurasi untuk melarang berbagi ke luar organisasi

*   Orang yang memiliki izin kelola dokumen dapat melarang berbagi dokumen ke luar organisasi. Jika dilarang, tidak seorang pun dapat menambahkan orang dari luar organisasi sebagai kolaborator dokumen tersebut.

    ### 2) Dokumen induk dari dokumen ini dikonfigurasi untuk melarang berbagi ke luar organisasi

*   Jika dokumen induk dari dokumen ini dikonfigurasi untuk melarang berbagi ke luar organisasi, dokumen ini pun secara default dilarang dibagikan ke luar organisasi.

### 3) Knowledge Base tempat dokumen ini berada dikonfigurasi untuk melarang berbagi ke luar organisasi

*   Admin Knowledge Base dapat mengatur apakah dokumen boleh dibagikan ke luar organisasi melalui "Pengaturan keamanan" pada Knowledge Base. Jika dilarang, tidak seorang pun dapat menambahkan orang dari luar organisasi sebagai kolaborator dokumen tersebut.

### 4) Backend Admin Organisasi dikonfigurasi untuk melarang berbagi ke luar organisasi

*   Admin Organisasi dapat mengatur apakah dokumen boleh dibagikan ke luar organisasi melalui backend admin. Jika dilarang, untuk semua dokumen di Organisasi Anda, tidak seorang pun dapat menambahkan orang dari luar organisasi sebagai kolaborator.

*   Jika berbagi dilarang tetapi Super Admin diizinkan membagikan kepada siapa saja, maka selain Super Admin, tidak seorang pun dapat menambahkan orang dari luar organisasi sebagai kolaborator.

### 5) Dokumen boleh dibagikan ke luar organisasi, tetapi saya tetap tidak bisa melakukannya

*   Meskipun dokumen boleh dibagikan ke luar organisasi, mungkin ada batasan tindakan tambahan: **1) Hanya "izin kelola" yang dapat membagikan dokumen ke luar organisasi**—jika konfigurasi ini dicentang, orang tanpa izin kelola tetap tidak dapat menambahkan pengguna dari luar organisasi sebagai kolaborator; **2) Hanya pengguna di Organisasi Anda yang dapat menambahkan kolaborator**—jika konfigurasi ini dicentang dan di antara kolaborator dokumen terdapat orang dari luar organisasi, maka orang-orang dari luar organisasi tersebut tidak dapat menambahkan orang lain sebagai kolaborator.

## III. Cara melarang dokumen dibagikan ke luar organisasi

### 1) Melarang satu dokumen dibagikan ke luar organisasi

*   Orang yang memiliki izin kelola dokumen dapat melihat pintu masuk "Konfigurasi izin" pada panel berbagi.

*   Buka "Konfigurasi izin", lalu ubah konfigurasi "**Berbagi ke luar organisasi**"—atur ke larangan dengan menonaktifkannya.

*   Setelah dinonaktifkan, tidak seorang pun dapat menambahkan pengguna dari luar organisasi sebagai kolaborator dokumen.

*   Setelah dinonaktifkan, sub-dokumen dari dokumen ini juga tidak dapat dibagikan ke luar organisasi.

### 2) Melarang semua dokumen dalam Knowledge Base dibagikan ke luar organisasi

*   Admin Knowledge Base dapat mengatur apakah dokumen boleh dibagikan ke luar organisasi melalui "Pengaturan keamanan" pada Knowledge Base.

*   Jika dinonaktifkan, untuk semua dokumen dalam Knowledge Base tersebut, tidak seorang pun dapat menambahkan orang dari luar organisasi sebagai kolaborator.

### 3) Melarang semua dokumen di Organisasi Anda dibagikan ke luar organisasi

*   Admin Organisasi dapat mengatur apakah dokumen boleh dibagikan ke luar organisasi melalui backend admin. Jika dilarang, untuk semua Knowledge Base di Organisasi Anda serta konten dalam "Dokumen Saya" milik karyawan, tidak seorang pun dapat menambahkan orang dari luar organisasi sebagai kolaborator (pengaturan ini juga berlaku pada Rapat Cepat dan Catatan Cepat di Organisasi Anda).

*   Saat mengatur larangan berbagi dokumen ke luar organisasi di backend admin, Anda dapat sekaligus mencentang "Super Admin dapat membagikan kepada siapa saja". Jika dicentang, untuk semua dokumen di Organisasi Anda, hanya Super Admin yang dapat menambahkan orang dari luar organisasi sebagai kolaborator.

## IV. Hanya izinkan sebagian orang membagikan dokumen ke luar organisasi

*   Saat dokumen diizinkan dibagikan ke luar organisasi, Anda dapat menambahkan batasan tindakan tambahan.

    *   **Hanya "izin kelola" yang dapat membagikan dokumen ke luar organisasi**: jika dicentang, saat menambahkan kolaborator ke file, orang tanpa izin kelola hanya dapat menambahkan pengguna di Organisasi Anda, dan hanya orang yang memiliki izin kelola yang dapat menambahkan pengguna dari luar organisasi.

    *   **Hanya pengguna di Organisasi Anda yang dapat menambahkan kolaborator**: jika dicentang, di antara semua kolaborator dokumen, pengguna dari luar organisasi tidak dapat menambahkan kolaborator lain.

*   Kedua batasan di atas, jika dicentang pada satu dokumen, hanya berlaku untuk dokumen tersebut; jika dicentang di dalam Knowledge Base, berlaku untuk semua dokumen dalam Knowledge Base tersebut.
