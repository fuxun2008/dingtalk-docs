description: "Pahami tindakan yang dapat dilakukan setiap peran izin di DingTalk Docs—Pemilik, Admin, Editor, hingga Penampil—mulai dari pratinjau, unduh, hingga kelola kolaborator."

Docs menyediakan sistem izin yang aman, mudah digunakan, dan sederhana bagi organisasi, sehingga kolaborasi dokumen menjadi lebih mudah dan aman.

## Tindakan berdasarkan peran izin

| Izin | Pemilik | Admin | Editor | Penampil (dengan Unduh) | Penampil (Hanya Tampilan) |
|---|---|---|---|---|---|
| Pratinjau file | ✅ | ✅ | ✅ | ✅ | ✅ |
| Unduh file | ✅ | ✅ | ✅ | ✅ | ❌ |
| Teruskan dan salin | ✅ | ✅ | ✅ | ✅ | ❌ |
| Buat dokumen/unggah file | ✅ | ✅ | ✅ | ❌ | ❌ |
| Unggah file | ✅ | ✅ | ✅ | ❌ | ❌ |
| Edit file | ✅ | ✅ | ✅ | ❌ | ❌ |
| Hapus file | ✅ | ✅ | ❌ | ❌ | ❌ |
| Kelola kolaborator | ✅ | ✅ | ❌ | ❌ | ❌ |
| Alihkan kepemilikan folder | ✅ | ❌ | ❌ | ❌ | ❌ |
| Cetak cloud | ✅ | ✅ | ✅ | ✅ | ❌ |
