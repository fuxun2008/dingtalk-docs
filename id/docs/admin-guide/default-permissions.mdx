Melalui pengaturan izin default untuk dokumen baru, Anda dapat menetapkan aturan izin default saat karyawan organisasi membuat dokumen baru. Setelah dokumen dibuat, pengelola dokumen juga dapat menyesuaikannya sendiri.

## Apa itu pengaturan «Preferensi izin dokumen baru»?

*   DingTalk Docs mendukung pengaturan aturan izin yang berbeda untuk setiap dokumen (lihat konfigurasi izin berbagi, salin, unduh, komentar, dan lainnya). Admin Organisasi dapat menetapkan nilai default untuk aturan-aturan ini, yaitu «Preferensi izin dokumen baru».

*   Saat semua karyawan di Organisasi Anda membuat dokumen baru di dalam Knowledge Base, aturan izin secara default mengikuti konfigurasi «Preferensi izin dokumen baru» dan dapat disesuaikan kemudian. Selain itu, jika aturan izin dokumen induk atau Knowledge Base lebih ketat, aturan yang lebih ketat itulah yang diwarisi.

*   Contoh

    *   «Preferensi izin dokumen baru» organisasi diatur sebagai berikut:

        *   Izinkan dokumen dibagikan ke luar organisasi

        *   Pengguna dengan izin «Dapat mengedit» atau lebih tinggi dapat menambah Kolaborator

        *   Pengguna dengan izin «Dapat melihat/mengunduh» atau lebih tinggi dapat menyalin konten, membuat salinan skenario, mencetak, dan mengunduh

        *   Pengguna dengan izin «Hanya dapat melihat» atau lebih tinggi dapat memberi komentar

    *   Knowledge Base "AAA" diatur sebagai berikut:

        *   Tidak mengizinkan dokumen dibagikan ke luar organisasi (lebih ketat daripada «Preferensi izin dokumen baru» organisasi)

        *   Pengguna dengan izin «Dapat mengedit» atau lebih tinggi dapat menambah Kolaborator

        *   Pengguna dengan izin «Dapat melihat/mengunduh» atau lebih tinggi dapat menyalin konten, membuat salinan skenario, mencetak, dan mengunduh

        *   Pengguna dengan izin «Hanya dapat melihat» atau lebih tinggi dapat memberi komentar

    *   Maka, saat membuat dokumen baru di Knowledge Base "AAA", izin default-nya adalah:

        *   Tidak mengizinkan dokumen dibagikan ke luar organisasi (mengikuti aturan yang lebih ketat)

        *   Pengguna dengan izin «Dapat mengedit» atau lebih tinggi dapat menambah Kolaborator

        *   Pengguna dengan izin «Dapat melihat/mengunduh» atau lebih tinggi dapat menyalin konten, membuat salinan skenario, mencetak, dan mengunduh

        *   Pengguna dengan izin «Hanya dapat melihat» atau lebih tinggi dapat memberi komentar

## Cara mengatur «Preferensi izin dokumen»?

*   Jalur tindakan: «Konsol Admin - DingTalk Docs - Izin & Keamanan».
