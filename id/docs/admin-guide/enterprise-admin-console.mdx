Admin Organisasi dapat masuk ke admin console Organisasi untuk mengatur berbagai modul fitur, seperti <strong>Izin & keamanan</strong>, **Petunjuk penggunaan kapasitas**, **Manajemen pengguna eksternal**, dan <strong>otak data pengetahuan Organisasi</strong>.

## Izin & keamanan

Melalui pengaturan Izin & keamanan, Anda dapat mengonfigurasikan <strong>izin default untuk dokumen baru</strong>, **Bagikan eksternal**, **Siapa yang dapat menyetel dokumen menjadi publik di dalam Organisasi**, **Izin membuat Knowledge Base**, **Menyetel Knowledge Base menjadi publik di dalam Organisasi**, dan **Watermark dokumen**.

### Pengaturan izin default untuk dokumen baru

Melalui pengaturan ini, Anda dapat menentukan aturan izin default saat karyawan Organisasi membuat dokumen baru. Setelah dokumen dibuat, pengelola dokumen juga dapat menyesuaikannya sendiri.

### Bagikan eksternal

*   Mengatur apakah DingTalk Docs, Rapat Cepat, dan AI Minutes boleh dibagikan ke luar Organisasi.

*   Mengatur apakah DingTalk Docs boleh dipublikasikan secara publik ke halaman web.

### Siapa yang dapat menyetel dokumen/file menjadi publik di dalam Organisasi

Setelah dokumen disetel menjadi publik di dalam Organisasi, setiap pengguna di dalam Organisasi yang memperoleh dokumen/file dapat mengakses konten publik tersebut. Anda dapat menentukan melalui pengaturan siapa yang boleh menyetel atau membatalkan status publik dokumen/file di dalam Organisasi.

### Aktifkan watermark dokumen

Menampilkan watermark Penampil pada latar belakang dokumen untuk mencegah penyalahgunaan tangkapan layar atau untuk pelacakan di kemudian hari.

## Petunjuk penggunaan kapasitas

<strong>Perhitungan kapasitas DingTalk Docs mencakup: "Dokumen Saya" dan "Knowledge Base". Anda dapat melihat</strong> kapasitas Organisasi yang telah digunakan oleh DingTalk Docs di dalam Organisasi.

*   **Dokumen Saya:** dialokasikan oleh Organisasi untuk manajemen pengetahuan pribadi Anda, dapat digunakan untuk mengendapkan dan mengelola pengetahuan kerja pribadi. Batas kapasitas "Dokumen Saya" untuk setiap karyawan adalah 2G.

*   **Knowledge Base:** manajemen pengetahuan dengan subjek berupa Perusahaan, Departemen, proyek, dan lainnya untuk berbagi dan berkolaborasi, digunakan untuk mengendapkan dan mengelola pengetahuan Organisasi.

## Manajemen pengguna eksternal

Anda dapat melihat izin pengguna eksternal yang diundang ke dalam dokumen dan pengetahuan.

## Otak data pengetahuan Organisasi

Anda dapat melihat rincian data karyawan aktif dan dokumen aktif di dalam Organisasi.
