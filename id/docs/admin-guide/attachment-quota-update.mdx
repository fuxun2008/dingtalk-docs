Pelanggan yang terhormat, aturan perhitungan kapasitas lampiran DingTalk Docs akan disesuaikan pada 30 Juli 2023. Berikut penjelasan selengkapnya:

---

## Penjelasan perubahan

Lampiran di dalam rangkaian DingTalk Docs (Dokumen, Spreadsheet, Peta Pikiran, AI Table, Whiteboard) <strong>termasuk gambar, audio/video, file terkompresi, dan file lokal</strong> tidak lagi bebas biaya mulai 30 Juli 2023 dan resmi dihitung sebagai bagian dari kapasitas penyimpanan organisasi. Berikut contoh menyisipkan lampiran pada rangkaian Dokumen:

**Sebelumnya: lampiran yang diunggah di dalam dokumen online tidak dihitung ke penyimpanan organisasi**

**Setelahnya: resmi dihitung mulai 30 Juli 2023**

## [Dokumen] Penjelasan aturan perhitungan kapasitas DingTalk Docs

Aturan perhitungan kapasitas saat membuat, mengunggah, atau mengimpor file dengan DingTalk Docs (termasuk aplikasi rangkaian dan Knowledge Base) adalah sebagai berikut:

| Tipe File | Perilaku penggunaan | Dihitung ke kapasitas |
| --- | --- | --- |
| File lokal | Unggah file di dalam DingTalk Docs. Tipe file mencakup dokumen, gambar, audio/video, file terkompresi, dll. | Dihitung |
| Dokumen online | Buat atau impor dokumen online (Dokumen, Spreadsheet, AI Table, Presentasi, Peta Pikiran, Whiteboard) di dalam DingTalk Docs, lalu edit dengan <strong>menyisipkan lampiran seperti gambar, audio/video, file terkompresi, dan file lokal</strong>, dll. | **Mulai 30 Juli 2023**<br />**resmi dihitung** |
| Pintasan | Tambahkan pintasan di dalam DingTalk Docs. | Tidak dihitung |

Panduan penggunaan lengkap: https://docs.dingtalk.io/i/p/nb9XJlDk3dYLaGyA

## Tanya Jawab umum tentang penyesuaian perhitungan kapasitas

## Pertanyaan umum

<Note>
**T: Lampiran di dalam dokumen online mana saja yang dihitung ke kapasitas?**

J: Semua lampiran yang diunggah karyawan organisasi di dalam dokumen online pada "Dokumen Saya", "Knowledge Base", dan "Drive" akan dihitung. Dokumen online mencakup Dokumen, Spreadsheet, Peta Pikiran, AI Table, dan Whiteboard.

**T: Kapan penyesuaian mulai berlaku?**

J: Resmi dihitung ke kapasitas mulai 30 Juli 2023.

**T: Apakah lampiran di dokumen yang sudah ada akan terpengaruh, dan apakah masih bisa dibuka?**

J: Tidak terpengaruh. Namun setelah lampiran dihapus, lampiran tidak dapat diunggah kembali jika ruang penyimpanan organisasi tidak mencukupi. Anda perlu membersihkan ruang atau menambah kapasitas.

**T: Apa yang harus dilakukan jika penyimpanan organisasi menampilkan kapasitas tidak mencukupi?**

J: Hapus file untuk membersihkan ruang penyimpanan, atau beli tambahan kapasitas (cara menambah kapasitas: [klik tautan ini](https://oa.dingtalk.io/oa_welcome.htm?channel=aggregation_OA#/product_zone), masuk ke konsol OA, lalu pilih "Paket perluasan kapasitas Drive").

**T: Di mana Admin Organisasi dapat melihat rincian penggunaan kapasitas?**

J: Buka konsol OA - Data Organisasi - Penyimpanan Organisasi (alamat masuk: [https://oa.dingtalk.io/](https://oa.dingtalk.io/)).

**T: Jika penyimpanan organisasi menampilkan kapasitas tidak mencukupi, apakah DingTalk Docs masih bisa digunakan secara normal?**

J: Tindakan yang tidak dihitung ke kapasitas tetap dapat digunakan secara normal (misalnya membuat dokumen online dan mengedit konten dokumen). Pengunggahan lampiran akan terpengaruh, sehingga Anda perlu membersihkan ruang penyimpanan atau membeli tambahan kapasitas terlebih dahulu.
</Note>

## Saya seorang Admin

<Note>
**T: Di mana saya dapat melihat total kapasitas lampiran yang sudah diunggah organisasi saat ini?**

J: Total kapasitas lampiran yang sudah diunggah dapat dilihat di bagian atas halaman "Konsol Admin OA - Manajemen Dokumen dan Penyimpanan - Ruang Penyimpanan". Kapasitas lampiran ini akan ditambahkan ke kapasitas terpakai penyimpanan organisasi setelah 30 Juli. Setelah ditambahkan, jika kapasitas terpakai melebihi total kapasitas penyimpanan yang telah dibeli organisasi, hal ini akan memengaruhi tindakan pengunggahan file pada setiap aplikasi di dalam organisasi. Harap bersihkan kapasitas atau beli tambahan kapasitas terlebih dahulu.

**T: Apa yang harus dilakukan jika penyimpanan organisasi menampilkan kapasitas tidak mencukupi?**

J: Hapus file untuk membersihkan ruang penyimpanan, atau beli tambahan kapasitas. Cara membersihkan: pada bilah alat di sisi kiri antarmuka DingTalk versi desktop, klik Lainnya **"..."** >> Konsol Admin >> Drive >> Manajemen Kapasitas. Anda dapat mengelola file yang disimpan di berbagai lokasi atau oleh pengguna organisasi, atau mengirim notifikasi untuk membersihkannya.

**T: Jika kapasitas organisasi tidak mencukupi, apa yang terjadi pada lampiran yang sudah diunggah ke dokumen sebelum 30 Juli?**

J: Lampiran yang sudah diunggah tetap dapat digunakan dan tidak akan dihapus, tetapi lampiran baru tidak dapat diunggah.
</Note>

## Saya seorang karyawan pengguna

<Note>
**T: Saat menggunakan dokumen, muncul pemberitahuan ruang tidak mencukupi ketika mengunggah file. Apa yang harus dilakukan?**

J: Hubungi Admin DingTalk organisasi Anda untuk mengurangi kapasitas atau membeli tambahan kapasitas.

**T: Mengapa lampiran yang sudah dihapus dari dokumen masih menggunakan penyimpanan organisasi?**

J: Setelah dihapus, lampiran masih tersimpan di versi riwayat sehingga tetap menggunakan penyimpanan organisasi. Menghapus dokumen akan membebaskan kapasitas. Ke depannya, hal ini akan dioptimalkan agar lampiran yang telah dihapus tidak dihitung ke kapasitas.

**T: Apakah lampiran di dokumen online yang ada di Tempat Sampah menggunakan penyimpanan organisasi?**

J: Tidak menggunakan.
</Note>
