## 1. Mengapa saya tidak dapat melihat izin atau menambah kolaborator?

*   Admin Knowledge Base, folder, maupun dokumen tunggal dapat mengatur «Siapa yang dapat menambah kolaborator» (lihat gambar berikut). Jika Anda tidak memenuhi pengaturan tersebut, Anda tidak dapat melihat izin atau menambah kolaborator. Hubungi admin untuk mengubahnya.

*   Admin dokumen, file, atau folder tunggal dapat mengubahnya di «Kelola izin - Konfigurasi izin», sedangkan admin Knowledge Base dapat mengubahnya di «Pengaturan lainnya - Pengaturan keamanan». Untuk informasi selengkapnya, lihat: Penjelasan pengaturan izin dokumen.

## 2. Mengapa saya tidak dapat menambah pengguna eksternal?

Ketidakmampuan menambah pengguna eksternal dapat disebabkan oleh larangan dari organisasi, Knowledge Base, folder, atau dokumen tunggal. Untuk penyebab spesifiknya, lihat Siapa yang dapat membagikan dokumen ke luar organisasi.

## 3. Mengapa saya tidak dapat menyalin konten, membuat salinan, mencetak, mengunduh, dan sebagainya?

#### 1) «Konfigurasi izin» versi lama:

*   Admin Knowledge Base, folder, maupun dokumen tunggal dapat mengatur «Siapa yang dapat menyalin, mengunduh, membuat salinan, dan mencetak» (lihat gambar berikut). Jika Anda tidak memenuhi pengaturan tersebut, Anda tidak dapat melakukan tindakan terkait salin dan unduh, seperti menyalin, membuat salinan, menambah salinan ke, mencetak, mengunduh, dan menyimpan sebagai templat. Hubungi admin untuk mengubahnya.

*   Admin dokumen, file, atau folder tunggal dapat mengubahnya di «Kelola izin - Konfigurasi izin», sedangkan admin Knowledge Base dapat mengubahnya di «Pengaturan lainnya - Pengaturan keamanan». Untuk informasi selengkapnya, lihat: Penjelasan pengaturan izin dokumen.

#### 2) «Konfigurasi izin» versi baru:

*   Pada versi baru, fitur «Siapa yang dapat menyalin, membuat salinan, dan mencetak» ditingkatkan menjadi «Perlindungan anti-kebocoran» (lihat gambar berikut). Jika Knowledge Base, folder, atau dokumen tunggal mengaktifkan perlindungan anti-kebocoran, sebagian pengguna akan dilarang melakukan tindakan terkait salin dan unduh, seperti menyalin, membuat salinan, menambah salinan ke, mencetak, mengunduh, dan menyimpan sebagai templat, sesuai dengan pengaturan perlindungan anti-kebocoran yang spesifik. Hubungi admin untuk mengubahnya.

*   Admin dokumen, file, atau folder tunggal dapat mengubahnya di «Kelola izin - Konfigurasi izin», sedangkan admin Knowledge Base dapat mengubahnya di «Pengaturan lainnya - Pengaturan keamanan». Untuk informasi selengkapnya, lihat: Apa itu «Perlindungan anti-kebocoran» dokumen?

## 4. Mengapa saya tidak dapat mengomentari dokumen?

*   Admin Knowledge Base, folder, maupun dokumen tunggal dapat mengatur «Siapa yang dapat mengomentari» (lihat gambar berikut). Jika Anda tidak memenuhi pengaturan tersebut, Anda tidak dapat mengomentari dokumen. Hubungi admin untuk mengubahnya.

*   Admin dokumen, file, atau folder tunggal dapat mengubah konfigurasi ini di «Kelola izin - Konfigurasi izin», sedangkan admin Knowledge Base dapat mengubahnya di «Pengaturan lainnya - Pengaturan keamanan». Untuk informasi selengkapnya, lihat: Penjelasan pengaturan izin dokumen.
