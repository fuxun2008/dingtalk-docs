Dalam pengeditan dokumen sehari-hari, jika satu subjek memiliki beberapa konten terkait, tambahkan Daftar Berpoin atau Daftar Bernomor pada konten tersebut agar konten dokumen tersusun rapi dan lebih jelas berlapis.

## Petunjuk penggunaan

## Menambah daftar

Klik ikon yang sesuai di toolbar untuk menambahkan Daftar Berpoin, Daftar Bernomor, dan daftar tugas secara berurutan.

## Mengedit daftar

DingTalk Docs mendukung penggantian tipe simbol dan tipe penomoran. Klik panah kecil pada menu dropdown tindakan yang sesuai atau ikon tindakan terkait di toolbar untuk mengaturnya.
