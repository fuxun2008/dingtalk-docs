## Nilai fitur

Mengenali teks Tionghoa dan Inggris secara cerdas serta menyesuaikan spasi secara otomatis. Fitur ini menghilangkan langkah manual yang merepotkan dan membuat pengeditan konten dokumen lebih rapi.

## Skenario penggunaan

Kanshento bekerja di bagian operasional konten pada departemen perencanaan. Setiap hari, ia menggunakan DingTalk Docs untuk mengedit berbagai materi promosi, pengumuman, notifikasi, hingga dokumen administrasi perusahaan. Dengan fitur ini, teks Inggris dan angka yang berada sebelum atau sesudah teks Tionghoa otomatis diberi spasi saat menulis, tanpa perlu memeriksa format satu per satu. Hasilnya, format artikel menjadi lebih rapi dan standar, serta beban kerja pemeriksaan format berkurang.

## Cara penggunaan

Klik bilah navigasi atas, lalu pilih **...** di pojok kanan atas - **Preferensi** - **Bantuan pengeditan** - **DingTalk Docs**, kemudian aktifkan <strong>Spasi otomatis teks Tionghoa dan Inggris</strong>. Setelah diaktifkan, spasi akan otomatis ditambahkan antara teks Tionghoa dan teks Inggris/angka saat mengedit.
