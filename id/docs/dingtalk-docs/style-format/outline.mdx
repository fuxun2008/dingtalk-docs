Gunakan fitur "Outline dokumen" untuk menyusun struktur dokumen. DingTalk Docs mendeteksi judul yang diatur dalam dokumen dan menambahkannya secara otomatis ke panel outline di sisi kanan. Fitur ini membantu pembaca memahami struktur konten dengan cepat saat membaca, sekaligus membantu editor memeriksa apakah ada konten yang terlewat atau berulang saat menyesuaikan isi dokumen.

## Petunjuk penggunaan

## Menambahkan outline teks

Pilih teks yang ingin dijadikan outline dokumen, lalu klik gaya judul pada toolbar di bagian atas. Sistem akan mengatur judul tersebut sebagai outline secara otomatis.

## Melihat outline dokumen

### Desktop

Arahkan kursor ke ikon mengambang outline di sisi kanan dokumen, lalu klik untuk menyematkan outline.

### Ponsel

Fitur ini mendukung tampilan outline. Buka DingTalk Docs di ponsel, lalu ketuk **··· - Outline** di pojok kanan atas.
