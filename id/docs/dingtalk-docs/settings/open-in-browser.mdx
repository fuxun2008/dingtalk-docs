## Peningkatan fitur! DingTalk kini mendukung pengaturan untuk membuka dokumen dengan browser secara default

*   Saat menggunakan DingTalk, atur agar dokumen dibuka, dilihat, dan diedit melalui browser web sesuai kebiasaan Anda.

*   Gunakan DingTalk Docs di browser dan simpan ke bookmark hanya dengan sekali klik, sehingga lebih efisien saat mencari dan meninjau kembali dokumen.

*   Pengoperasian sederhana dan langsung dapat digunakan tanpa perlu mengubah kebiasaan; edit dokumen di browser hanya dalam 3 detik.

*   Perbarui DingTalk ke versi 6.0.15 atau yang lebih baru untuk melakukan pengaturan ini.

## Cara mengatur

*   **Sistem Windows:** Buka **DingTalk** **\>** **Foto Profil** di kiri atas **> Pengaturan & Privasi > Umum > DingTalk Docs**, lalu aktifkan «Selalu buka dokumen di browser» untuk menyelesaikan pengaturan.

*   **Sistem Mac:** Buka **DingTalk** **\>** **Foto Profil** di kiri atas **> Pengaturan & Privasi > Umum > DingTalk Docs**, lalu centang «Selalu buka dokumen di browser» untuk menyelesaikan pengaturan.
