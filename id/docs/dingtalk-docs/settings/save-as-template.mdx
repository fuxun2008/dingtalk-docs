Dalam pekerjaan sehari-hari, kita sering mengedit dokumen dengan tipe yang sama, misalnya menyusun rencana kerja, laporan kerja, atau laporan mingguan setiap tahun maupun setiap bulan. Untuk kasus seperti ini, simpan dokumen sebagai templat sesuai kebiasaan penulisan Anda agar terhindar dari kerumitan mengedit berulang dan meningkatkan efisiensi kerja. Selain itu, DingTalk Docs juga menyediakan banyak templat umum untuk mempermudah pekerjaan sehari-hari Anda.

## Petunjuk penggunaan

Klik ┇ pada bilah navigasi di sudut kanan atas dokumen **\> Simpan sebagai templat > Simpan sebagai Templat Saya** untuk menyimpan dokumen target sebagai templat. Anda dapat mengubah judul dokumen di panel yang muncul, dan judul ini tidak akan berlaku pada dokumen aslinya.

Untuk menggunakan templat yang sudah dibuat, pilih <strong>Templat Saya</strong> saat membuat dokumen baru.
