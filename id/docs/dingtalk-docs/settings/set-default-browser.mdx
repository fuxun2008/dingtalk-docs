**Pengantar**

Untuk pengalaman DingTalk Docs versi web yang lebih baik, tetapkan browser yang didukung DingTalk Docs sebagai browser default pada sistem. Berikut adalah panduan pengaturan sebagai referensi. Harap mengacu pada tampilan operasi yang sebenarnya.

## I. Sistem Windows

1.  Pilih tombol "**Start**", lalu klik "**Settings**".

2.  Pilih "**Apps**".

3.  Buka **Apps** **\>** **Default apps** **\>** **Web browser**, lalu pilih browser yang ingin dijadikan program default. Klik untuk menetapkannya sebagai default. Jika muncul kotak dialog, pilih tetap ganti. Pengaturan selesai.

## II. Sistem MacOS

*   Langkah 1: Buka **System Settings**, lalu masuk ke **Desktop & Dock**.

*   Langkah 2: Temukan browser web default, lalu pilih browser yang ingin dijadikan default, seperti pada gambar di bawah:

## III. Cara mengatur DingTalk Docs agar dibuka dengan browser secara default

Saat menggunakan DingTalk, sesuai kebiasaan pribadi, Anda dapat mengatur agar dokumen dibuka, dilihat, dan diedit menggunakan browser web.

*   **Sistem Windows:** Buka **DingTalk** **\>** **Foto Profil** di kiri atas **> Pengaturan & Privasi > Umum > DingTalk Docs**, aktifkan "Selalu buka dokumen di browser", lalu pengaturan selesai.

*   **Sistem Mac:** Buka <strong>DingTalk</strong> **\>** **Foto Profil** di kiri atas **> Pengaturan & Privasi > Umum > DingTalk Docs**, centang "Selalu buka dokumen di browser", lalu pengaturan selesai.
