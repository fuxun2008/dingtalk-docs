Saat menulis notulen rapat, daftar tugas, atau menyusun rencana kerja tim, sering kali muncul banyak tugas yang perlu ditindaklanjuti. Bagaimana memastikan "setiap hal ada tanggapannya dan setiap tugas terselesaikan"? Ubah langsung daftar tugas menjadi Tugas DingTalk di DingTalk Docs, lalu me-mention penanggung jawab terkait untuk mengingatkan mereka meninjaunya.

## Petunjuk penggunaan

Pilih lokasi dokumen tempat Anda ingin menambahkan daftar tugas, klik <strong>Daftar tugas</strong> pada bilah alat untuk membuat tugas, lalu klik ikon di ujung kanan daftar tugas dan pilih **"Konversi ke Tugas DingTalk"** untuk membuat Tugas.

## Keterangan tambahan

Tugas dapat me-mention penanggung jawab terkait, mengatur batas waktu, serta dikonversi menjadi Tugas DingTalk untuk menghasilkan pengingat tugas.
