Asosiasikan proyek DingTalk ke dalam DingTalk Docs untuk meninjau dan melacak proyek.

## Petunjuk penggunaan

Pilih lokasi untuk menambahkan Kanban proyek di dalam dokumen, klik <strong>Sisipkan—>Kanban proyek</strong> pada bilah navigasi atas, lalu pilih proyek yang ingin disisipkan pada pemilih Kanban proyek yang muncul. Lihat detail proyek langsung di dalam dokumen, seperti <strong>tugas, status, penanggung jawab</strong>, dan lainnya. Atur juga pengurutan dan filter pada Kanban proyek.
