Saat menelusuri riwayat obrolan grup, Anda dapat langsung menemukan DingTalk Docs di tab "File" dan "Dokumen" sehingga pencarian menjadi lebih mudah.

## Petunjuk penggunaan

Di dalam grup obrolan versi desktop, klik **「Riwayat Obrolan」** di pojok kanan atas, lalu cari kata kunci dokumen yang dituju untuk langsung menemukannya di **tab "File"**.
