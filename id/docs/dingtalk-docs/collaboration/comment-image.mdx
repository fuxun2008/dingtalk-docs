## Nilai fitur

Komentar sorotan teks di dalam dokumen mendukung pengunggahan gambar. Satu gambar bernilai ribuan kata, menyampaikan pesan dengan jelas dan mendukung kolaborasi yang efisien.

## Skenario penggunaan

Ding Sanduo adalah staf operasi produk di sebuah perusahaan internet. Dalam pekerjaan sehari-hari, ia menggunakan DingTalk Docs untuk berkolaborasi secara interaktif dengan rekan kerja. Setelah Komentar sorotan teks mendukung pengunggahan gambar, konten yang sulit dijelaskan dengan teks—seperti analisis data dan progres proyek—dapat langsung disisipkan sebagai gambar dalam komentar, sehingga meningkatkan efisiensi kolaborasi antar rekan kerja.

## Petunjuk penggunaan

Saat menulis Komentar, klik ikon gambar untuk menyisipkan gambar ke dalam komentar.
