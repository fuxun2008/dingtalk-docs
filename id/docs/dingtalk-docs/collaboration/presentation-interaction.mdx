Bagaimana cara berinteraksi secara efektif dengan penonton saat siaran Live atau presentasi? Pada mode presentasi DingTalk Docs, Pengguna dalam Organisasi yang sama <strong>dapat mengajukan pertanyaan interaksi langsung dengan memindai kode</strong>. Pada halaman terakhir presentasi, Anda dapat melihat pertanyaan yang diajukan secara langsung, sekaligus meninjau pertanyaan dan Isi Teks secara bersamaan, sehingga partisipasi penonton meningkat dengan mudah.

## Petunjuk penggunaan

**Cara 1**: Setelah mengaktifkan mode presentasi, buka Pengaturan presentasi pada bilah alat di bagian bawah, lalu klik **"Interaksi langsung"**. Kode QR akan muncul, dan penonton dapat memindainya untuk mengikuti interaksi.

**Cara 2**: Klik tanda panah di samping ikon presentasi pada sudut kanan atas DingTalk Docs untuk mengedit halaman presentasi, klik **"Pengaturan presentasi"** di bagian atas, lalu aktifkan **"Interaksi langsung"** pada Pengaturan presentasi.

Setelah interaksi pemindaian kode diaktifkan, penonton dapat langsung memindai kode untuk mengajukan pertanyaan dan berinteraksi, dan presenter dapat melihat pertanyaan sekaligus Isi Teks secara bersamaan, sehingga partisipasi penonton meningkat dengan mudah. Selain itu, pertanyaan yang diajukan secara langsung dapat dilihat pada halaman terakhir presentasi.
