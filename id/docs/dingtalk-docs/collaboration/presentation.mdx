Dalam rapat sehari-hari, dokumen sering digunakan untuk memimpin rapat. Dalam situasi ini, mengaktifkan mode presentasi pada dokumen memberikan tampilan dokumen yang terbaik.

## Petunjuk penggunaan

## Mengaktifkan presentasi

Klik <strong>ikon presentasi</strong> di sudut kanan atas dokumen, atau gunakan langsung <strong>Pintasan Ctrl + Shift + P (Mac: Cmd + Shift + P),</strong> maka dokumen akan masuk ke Mode presentasi.

## Beralih Mode presentasi

Mode presentasi dokumen memiliki dua cara: pemutaran gulir dokumen dan mode paginasi Slide.

Pemutaran gulir dokumen menampilkan dokumen secara mengalir. Pada mode paginasi Slide, konten dokumen ditampilkan per halaman berdasarkan node dokumen.

**Pada Mode presentasi, arahkan kursor ke posisi mana pun di bagian bawah, lalu klik satu kali untuk memunculkan kotak Pengaturan Mode presentasi, kemudian pilih ikon terkait.**

## Pengaturan gaya presentasi

### Mode siang/malam

Mode presentasi dokumen mendukung pengaturan tampilan mode siang/malam.

**Pada Mode presentasi, arahkan kursor ke posisi mana pun di bagian bawah, lalu klik satu kali untuk memunculkan kotak Pengaturan Mode presentasi, kemudian pilih ikon terkait untuk beralih.**

### Rasio zoom Tampilan

Tampilan Mode presentasi mendukung tiga pengaturan: besar, sedang, dan kecil.
**Klik ikon terkait di bagian bawah Mode presentasi untuk beralih rasio Tampilan.**

## Keluar dari presentasi

Pada Pengaturan Mode presentasi, klik <strong>Keluar dari presentasi</strong> atau gunakan <strong>Pintasan Esc</strong> untuk keluar dari fitur presentasi.
