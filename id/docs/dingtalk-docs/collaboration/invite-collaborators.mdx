## 1. Siapa yang dapat melihat atau mengedit dokumen yang baru dibuat?

*   Saat membuat dokumen di **"Dokumen Saya"**, secara default <strong>hanya Anda yang dapat melihat atau mengeditnya</strong>.

*   Saat membuat dokumen di **"Knowledge Base"**, secara default <strong>semua pengguna Knowledge Base dapat melihatnya</strong>. Izin mereka atas dokumen ini secara default diwarisi dari pengaturan "Pengguna dan Izin" pada Knowledge Base, dan dapat diubah atau disembunyikan.

*   Saat membuat sub-dokumen <strong>di bawah dokumen yang sudah ada</strong>, secara default <strong>semua kolaborator pada dokumen induk dapat melihatnya</strong> (buka "Lainnya - Kelola izin" untuk melihat semua kolaborator dokumen). Izin mereka atas sub-dokumen ini secara default diwarisi dari dokumen induk, dan dapat diubah atau disembunyikan.

## 2. Bagaimana cara mengundang kolaborator untuk melihat atau mengedit dokumen bersama?

Untuk dokumen apa pun, jika perlu <strong>dibagikan kepada orang lain</strong> untuk dilihat atau diedit bersama, undang mereka sebagai kolaborator dan tambahkan izin yang sesuai.

*   Klik "Bagikan", lalu pada kotak pencarian "Undang kolaborator", cari langsung <strong>pengguna, grup, departemen, atau peran</strong> untuk menambahkannya sebagai kolaborator.

*   Klik "Kelola izin" untuk melihat semua kolaborator dokumen saat ini, lalu klik "Tambah kolaborator" untuk menambahkan orang lain sebagai kolaborator dokumen.

## 3. Bagaimana cara mengubah izin kolaborator?

*   Buka "Lainnya - Kelola izin" atau "Bagikan - Kelola izin", lalu pada daftar "Semua kolaborator", ubah izin kolaborator atau sembunyikan kolaborator.

*   Admin Knowledge Base secara default memiliki izin untuk mengelola dokumen, dan izin ini tidak dapat diubah.

## 4. Bagaimana cara membuka dokumen untuk semua orang dalam organisasi?

*   Aktifkan "Publik dalam organisasi" agar semua pengguna dalam organisasi dapat melihat dokumen ini tanpa perlu ditambahkan sebagai kolaborator.

*   Setelah mengaktifkan "Publik dalam organisasi", atur lebih lanjut izin untuk semua pengguna dalam organisasi.
