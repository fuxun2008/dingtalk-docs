Saat berkolaborasi mengedit dokumen dengan orang lain, Anda dapat memberikan komentar pada konten dokumen dan me-@ orang terkait di dalamnya. Konten komentar menjangkau penerima secara real-time melalui notifikasi obrolan, sehingga efisien dan tepat waktu.

## Petunjuk penggunaan

DingTalk Docs mendukung komentar seluruh dokumen dan komentar seleksi teks. Anda dapat langsung mengomentari seluruh dokumen atau mengomentari konten tertentu di dalamnya.

## Tambah komentar

### Komentar seleksi teks

**Di komputer:** Pilih konten teks, lalu klik tombol <strong>Tambah komentar</strong> di sebelah kanan, atau gunakan pintasan **Ctrl+Shift+M** (Mac: **Cmd+Shift+M**) untuk memberikan komentar spesifik pada konten tersebut. Konten komentar akan ditampilkan bersama teks di area kosong sebelah kanan dokumen.

**Di perangkat seluler:** Tekan lama untuk memilih teks di dokumen, atau geser jari untuk memilih paragraf, lalu klik tombol di bagian bawah untuk memberikan komentar.

### Komentar seluruh dokumen

Gulir dokumen ke bagian paling bawah, lalu masukkan komentar seluruh dokumen pada kotak input di dasar halaman.

## Balas komentar

Klik tombol **Balas** di belakang komentar untuk membalas konten komentar tersebut. Pengirim komentar akan menerima notifikasi di obrolan DingTalk.

## Hapus komentar

Pemberi komentar hanya dapat menghapus komentarnya sendiri, bukan komentar orang lain. Klik <strong>「</strong>┇**」di pojok kanan atas komentar —> Hapus komentar** untuk menghapus konten komentar yang telah terkirim.
