## 1. Pengenalan DingTalk Docs Flash

Menemukan konten menarik saat menjelajahi situs web dan ingin menyimpannya? DingTalk Docs Flash menyimpan isi teks halaman saat ini ke DingTalk Docs dengan satu klik sehingga Anda dapat membacanya kapan saja dan di mana saja. Plugin ini juga menghapus iklan mengambang dan tautan yang tidak relevan secara otomatis. Dengan begitu, Anda terbebas dari gangguan informasi yang berantakan dan pengalaman membaca pun meningkat.

## 2. Cara menggunakan?

Saat ini DingTalk Docs Flash dapat digunakan pada browser berikut setelah paket instalasi plugin terpasang dan browser dibuka:

360 Extreme Explorer, 360 Secure Browser, browser Chrome, dan browser Edge.

## 3. Panduan instalasi plugin

## 3.1 Instal di browser Chrome

### Metode 1 (disarankan):

Instal melalui toko plugin. [Klik di sini untuk mengakses toko plugin Chrome dan menginstal](https://chrome.google.com/webstore/detail/%E9%92%89%E9%92%89%E6%96%87%E6%A1%A3%E9%97%AA%E5%AD%98/dfaldmjkfklnkenddjpikfkdnkinheke).

### Metode 2:

Langkah 1: Klik untuk mengunduh paket kompresi plugin, lalu ekstrak untuk mendapatkan file DingTalk Docs plugin.crx.

Langkah 2: Buka browser Chrome, lalu masuk ke halaman pengelolaan ekstensi melalui **ikon ⋮** di kanan atas > **Ekstensi** > **Kelola ekstensi**.

Langkah 3: Seret file DingTalk Docs plugin.crx yang diunduh pada Langkah 1 ke halaman pengelolaan ekstensi.

Catatan: Setelah instalasi selesai, ikon DingTalk Docs Flash akan muncul di antarmuka pengelolaan ekstensi. Klik ikon **Ekstensi** di bilah alat, lalu pada daftar aplikasi ekstensi, klik ikon **Sematkan** di sebelah DingTalk Docs Flash untuk menyematkan plugin di bilah alat.

## 4. Cara menggunakan DingTalk Docs Flash

## 4.1 Masuk

Pada situs web mana pun yang isinya ingin Anda simpan, klik ikon plugin DingTalk Docs Flash. Jika Anda belum masuk, plugin akan meminta Anda untuk masuk dan membuka tab baru. Masuk ke DingTalk Docs pada tab baru tersebut sebelum melanjutkan penggunaan.

## 4.2 Menyimpan konten

Jika sudah masuk, klik ikon plugin DingTalk Docs Flash, maka plugin akan mulai menyimpan halaman saat ini. Setelah disimpan, dokumen akan ditempatkan di folder **Dokumen Saya/Penyimpanan Flash** pada akun yang telah masuk.

Setelah proses penyimpanan selesai, hasilnya akan muncul di halaman, mencakup ringkasan artikel dan lokasi penyimpanan. Klik **Ubah** di sebelah kanan lokasi penyimpanan untuk langsung beralih ke pusat pribadi DingTalk Docs dan mengubah lokasi penyimpanan.

## 4.3 Memilih lokasi penyimpanan dokumen

Jika akun yang sedang masuk memiliki beberapa organisasi, klik kanan menu plugin, lalu klik **Atur lokasi dokumen Flash** untuk beralih ke pusat pribadi DingTalk Docs dan mengaturnya.

## 4.4 Masukan masalah/saran

Jika Anda mengalami masalah saat penggunaan, berikan ulasan di [Toko plugin Chrome](https://chrome.google.com/webstore/detail/%E9%92%89%E9%92%89%E6%96%87%E6%A1%A3%E9%97%AA%E5%AD%98/dfaldmjkfklnkenddjpikfkdnkinheke), atau klik kanan DingTalk Docs Flash lalu pilih <strong>Masukan masalah/saran</strong>.
