Berikut adalah pintasan yang didukung dalam dokumen saat ini. Selain itu, Anda juga dapat mengeklik ikon keyboard di sudut kanan bawah dokumen untuk menampilkan sebagian pintasan.

| Kategori | Fungsi | Mac | Windows |
| --- | --- | --- | --- |
| Format teks | Tebal | ⌘ + B | Ctrl + B |
|  | Miring | ⌘ + I | Ctrl + I |
|  | Coret | ⌘ + Shift + X | Ctrl + Shift + X |
|  | Garis Bawah | ⌘ + U | Ctrl + U |
|  | Superskrip | ⌘ + . | Ctrl + . |
|  | Subskrip | ⌘ + , | Ctrl + , |
|  | Perbesar ukuran font | `⌘ + Shift + >` | `Ctrl + Shift + >` |
|  | Perkecil ukuran font | `⌘ + Shift + <` | `Ctrl + Shift + <` |
|  | Salin format teks | ⌘ + Shift + C | Ctrl + Shift + C |
|  | Tempel format teks | ⌘ + Shift + V | Ctrl + Shift + V |
|  | Hapus Format | ⌘ + \ | Ctrl + \ |
| Sisipkan | Sebut seseorang | @ | @ |
|  | Hyperlink | ⌘ + K | Ctrl + K |
| Format paragraf | Judul | ⌘ + Option + \[1-4\] | Ctrl + Alt + \[1-4\] |
|  | Isi Teks | ⌘ + Option + 0 | Ctrl + Alt + 0 |
|  | Daftar Bernomor | ⌘ + Shift + 7 | Ctrl + Shift + 7 |
|  | Daftar Berpoin | ⌘ + Shift + 8 | Ctrl + Shift + 8 |
|  | Daftar tugas | ⌘ + Shift + Y | Ctrl + Shift + Y |
|  | Tambah inden | Tab | Tab |
|  | Kurangi inden | Shift + Tab | Shift + Tab |
|  | Rata kiri | ⌘ + Shift + L | Ctrl + Shift + L |
|  | Rata Tengah | ⌘ + Shift + E | Ctrl + Shift + E |
|  | Rata kanan | ⌘ + Shift + R | Ctrl + Shift + R |
|  | Rata kiri-kanan | ⌘ + Shift + J | Ctrl + Shift + J |
| Edit | Urungkan | ⌘ + Z | Ctrl + Z |
|  | Ulangi | ⌘ + Y | Ctrl + Y |
|  | Cari | ⌘ + F | Ctrl + F |
|  | Cari dan Ganti | ⌘ + H | Ctrl + H |
| Lainnya | Masuk mode presentasi/layar penuh | ⌘ + Shift + P | Ctrl + Shift + P |
|  | Perbesar mode presentasi | ⌘ + + | Ctrl + + |
|  | Perkecil mode presentasi | ⌘ + - | Ctrl + - |
|  | Cetak | ⌘ + P | Ctrl + P |
