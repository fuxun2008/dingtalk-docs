## Apa itu Markdown?

Markdown adalah bahasa penulisan ringan yang diciptakan oleh John Gruber, seorang blogger independen ternama. Dengan beberapa simbol sintaksis sederhana, Anda dapat menata letak sekaligus saat menulis. Ini membantu Anda fokus pada konten, menulis dengan lebih lancar dan terarah, serta meningkatkan efisiensi menulis.

## Mengapa menggunakan Markdown?

Saat menulis dengan Markdown, Anda cukup memasukkan beberapa simbol sintaksis, lalu editor menata letak secara otomatis. Manfaatnya: begitu artikel selesai ditulis, tata letaknya pun sudah rapi tanpa perlu menyesuaikan simbol, menebalkan teks, atau tindakan lain melalui bilah menu. Hal ini meningkatkan efisiensi menulis.

<Note>
## Keunggulan Markdown

**Sintaksis sederhana**

**Kompatibilitas kuat**

**Fokus pada konten**
</Note>

*   Sintaksis sederhana: sintaksis Markdown terdiri atas simbol penanda yang sederhana dan umum digunakan. Meski bukan programmer, siapa pun bisa mempelajarinya hanya dalam beberapa menit.

*   Kompatibilitas kuat: dibuka dengan editor apa pun, formatnya tetap rapi.

*   Fokus pada konten: menulis dengan Markdown membebaskan Anda dari kerumitan tata letak. Formatnya yang ringkas dan elegan membuat kedua tangan tak perlu meninggalkan keyboard, sehingga Anda dapat menikmati kesenangan menulis.

## Sorotan peningkatan Markdown DingTalk Docs

<Note>
### Cakupan dukungan
</Note>

*   Dukungan penuh untuk berbagai gaya teks seperti <strong>tebal</strong>/**miring**/**coret**/**garis bawah**/**superskrip & subskrip**/<strong>teks sorotan</strong>, dan lainnya

*   Dukungan baru untuk memasukkan **Formula** Katex, termasuk gaya inline **$a+b$** dan gaya blok **$$a+b$$**

*   Dukungan baru untuk sintaksis <strong>blok sorotan</strong>

*   Dukungan baru untuk sintaksis <strong>gambar</strong> dan <strong>tautan</strong>

*   Dukungan baru untuk sintaksis **emoji**

*   Dukungan baru untuk **\`\`\`mermaid** + **Enter** guna menyisipkan <strong>gambar teks</strong>

*   Dukungan baru untuk sintaksis <strong>tabel</strong>

*   Tempel-ubah ke Teks Kaya mendukung HTML tersemat dalam Markdown

    <Note>
    #### Optimalisasi detail
    </Note>

*   Menyediakan beragam warna blok sorotan bawaan yang dapat ditentukan dengan cepat melalui `::: + <type>`

*   Menambahkan petunjuk masukan pembantu, sehingga Anda tidak perlu menghafal banyak **sintaksis blok kode**, **tipe blok sorotan**, maupun **kode emoji**

*   Cara masukan tautan Markdown yang praktis:

    *   Mendukung **\[\]()** untuk memasukkan placeholder tautan dan otomatis fokus ke kolom judul tautan

    *   Mendukung **\[title\]()** untuk memasukkan tautan dan otomatis fokus ke kolom alamat tautan guna menyelesaikan masukan

*   Mengetik **| | |** + **Enter** akan menyisipkan tabel dua baris dua kolom dengan fokus ke sel pertama baris pertama; sedangkan **|x| |** + **Enter** akan fokus ke sel pertama baris kedua

*   Saat menempel, opsi "Ubah ke Teks Kaya" muncul saat diperlukan untuk mengubah teks Markdown ke format yang didukung DingTalk Docs

## Panduan lengkap penggunaan Markdown

DingTalk Docs mendukung sebagian besar sintaksis Markdown. Anda dapat menggunakan sintaksis Markdown saat "**Impor**", "**Ekspor**", "**Tempel**", dan "**Edit**".

| Sintaksis Markdown umum | Sintaksis Markdown lanjutan |
| --- | --- |
| *   **Judul 1-6**<br />    <br />*   **Kutip**<br />    <br />*   **Daftar**: daftar bernomor, daftar berpoin, daftar tugas, dan lainnya<br />    <br />*   **Blok kode**<br />    <br />*   **Kode inline**<br />    <br />*   **Pembatas**<br />    <br />*   **Format teks**: tebal, miring, garis bawah, coret, warna latar, superskrip & subskrip, dan lainnya | *   **Tautan**<br />    <br />*   **Gambar**<br />    <br />*   **Formula**<br />    <br />*   **Blok sorotan**<br />    <br />*   **Tabel**<br />    <br />*   **Emoji**<br />    <br />*   **Gambar teks** |

### Impor

Saat membuat dokumen, pilih "Impor sebagai dokumen online" - "Dokumen lokal", pilih file .md lokal, lalu file tersebut akan diimpor menjadi DingTalk Docs.

### Ekspor

Setelah selesai mengedit, Anda dapat mengunduhnya sebagai file md untuk menyelesaikan ekspor. Format Markdown yang saat ini didukung saat ekspor: 《⏬ Ekspor sebagai Markdown 》

### Tempel

Salin sepotong teks Markdown dari editor teks biasa atau editor Markdown, lalu tempel ke DingTalk Docs. Pada opsi tempel yang muncul, klik "Ubah ke Teks Kaya" untuk mengubahnya ke format Teks Kaya yang didukung DingTalk Docs. Format Markdown yang didukung saat tempel: 《 Tempel teks Markdown》

### Edit

Masukkan teks berformat Markdown tertentu, lalu tekan tombol pemicu yang sesuai (spasi atau Enter) untuk mengubah teks menjadi format yang bersangkutan. Format Markdown yang didukung saat edit dapat dilihat di: 《⌨️ Edit Markdown》

Silakan buka DingTalk Docs untuk melihat lampiran 《edit markdown.mp4》.

## Rekomendasi penggunaan Markdown khas DingTalk Docs

### Masukan cepat blok sorotan

Ketik tiga titik dua (mendukung karakter Mandarin maupun Inggris) + Enter untuk langsung memasukkan blok sorotan.

Dengan menambahkan tipe setelah titik dua, Anda juga bisa mengatur warnanya dengan cepat, lho~

### Masukan pembantu untuk emoji, blok sorotan, dan blok kode

Berkat masukan pembantu yang cerdas, Anda dapat memasukkan hal berikut tanpa perlu menghafal tipe kode yang rumit:

*   Kode emoji yang didukung

*   Tipe blok sorotan

*   Sintaksis blok kode

Silakan buka DingTalk Docs untuk melihat lampiran 《辅助输入.mov》.

### Cara lain memasukkan tautan

Kini mendukung penulisan umum `[title](url)`.
