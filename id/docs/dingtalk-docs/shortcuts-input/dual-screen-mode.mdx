## Nilai fitur

Dalam mode layar ganda, Anda dapat mengedit dua Dokumen secara bersamaan tanpa berpindah-pindah Halaman. Dengan begitu, proses mengedit Dokumen dan mengoreksi Konten menjadi lebih mudah dan efisien.

## Skenario penggunaan

Ding Sanduo adalah editor naskah di sebuah perusahaan media baru. Setiap hari, ia menggunakan DingTalk Docs untuk mengoreksi, meninjau berbagai naskah, dan menulis artikel. Berkat mode layar ganda DingTalk Docs, ia tidak perlu berpindah-pindah Halaman Dokumen saat mengoreksi dan meninjau naskah. Saat menulis artikel dan perlu membaca referensi, ia juga dapat melakukannya secara paralel dalam mode layar ganda, sehingga pekerjaannya menjadi lebih mudah dan efisien.

## Petunjuk penggunaan

Buka Dokumen A, lalu klik Dokumen B yang disisipkan di dalam Dokumen A untuk masuk ke mode layar ganda. Dalam mode ini, Anda dapat mengedit kedua Dokumen secara bersamaan.
