## Cara menggunakan

Setelah selesai mengedit dokumen, Anda dapat mengunduhnya sebagai file md untuk menyelesaikan ekspor.

DingTalk Docs mengikuti sintaks Markdown yang umum. Format tertentu dikonversi menjadi teks Markdown, sedangkan beberapa elemen teks khas DingTalk Docs diturunkan (downgrade). Efek spesifiknya adalah sebagai berikut:

| **Tipe** | **Konten teks** | **Format sumber Markdown** | **Hasil render Markdown** |
| --- | --- | --- | --- |
| **Judul** |  | ```text/x-markdown<br /># Judul 1<br />### Judul 2<br />### Judul 3<br />#### Judul 4<br />``` |  |
| **Gaya** |  | ```text/x-markdown<br />~~_**Tebal**_~~<br />_Miring_<br />Superskrip^111^<br />Subskrip~222~<br />==Sorot Teks==<br />`Kode Inline`  <br />~~_**Gaya Campuran**_~~<br />``` |  |
| **Tabel** |  | ```text/x-markdown<br />**Tabel tanpa penggabungan sel:**<br />\|  aaa  \|  bbb  \|  ccc  \|  ddd  \|<br />\| --- \| --- \| --- \| --- \|<br />\|  eee  \|  fff  \|  ggg  \|  hhh  \|<br />\|  iii  \|  jjj  \|  kkk  \|  lll  \|<br />**Tabel dengan penggabungan sel:**<br />\|  aaa eee  \|  bbb ccc  \|  \|  ddd  \|<br />\| --- \| --- \| --- \| --- \|<br />\|  \|  fff jjj  \|  ggg  \|  hhh  \|<br />\|  iii  \|  \|  kkk lll  \|  \|<br />\|  mm  \|  nnn ooo  \|  \|  ppp  \|<br />``` |  |
| **Daftar** |  | ```text/x-markdown<br />Daftar Bernomor:<br />1.  aaa<br />    <br />    1.  bbb<br />        <br />        1.  ccc<br />            <br />2.  ddd<br />    <br />Daftar Berpoin:<br />*   eee<br />    <br />    *   fff<br />        <br />        *   ggg<br />            <br />*   hhh<br />``` |  |
| **Tugas** |  | ```text/x-markdown<br />Tugas:<br />*   [ ] Tugas Belum Selesai  $\color{#0089FF}{@王毅博 (灯少)}$   2022-10-27 17:00:00 <br />    <br />*   [x] Tugas Selesai  $\color{#0089FF}{@王毅博 (灯少)}$  2022-10-13 17:00:00 <br />``` |  |
| **Formula** |  | ```text/x-markdown<br />Formula blok:<br />$ratio*\frac{1}{3}$<br />Formula inline:         $ratio*\frac{1}{3}$    <br />``` |  |
| **Kutip** |  | ```text/x-markdown<br />Kutip:<br />> Konten kutipan<br />``` |  |
| **Pembatas** |  | ```text/x-markdown<br />Pembatas:<br />---<br />``` |  |
| **Kolom** |  | ```text/x-markdown<br />Kolom:<br />Kolom aaa<br />Kolom bbb<br />Kolom ccc<br />``` |  |
| **Blok Sorot** |  | ```text/x-markdown<br />:::<br />Konten blok sorot<br />:::<br />``` |  |
| **Blok Kode** |  | ```text/x-markdown<br />Blok kode:<br />    function test() {<br />  		console.log(123);<br />		}<br />``` |  |
| **Tautan Biasa & Tautan Kartu** |  | ```text/x-markdown<br />Tautan biasa:<br />[Taobao](www.taobao.com)<br />Tautan kartu:<br />[Taobao](www.taobao.com)<br />``` |  |
| **Tanggal** |  | ```text/x-markdown<br />Tanggal： 2022-09-30  2022-10-06 20:30:00 <br />``` |  |
| **Video** |  | ```text/x-markdown<br />Silakan lihat lampiran "Perekaman Layar2022-09-15 09.58.15(1).mov" di DingTalk Docs<br />``` |  |
| **Lampiran** |  | ```text/x-markdown<br />Silakan lihat lampiran di DingTalk Docs<br />``` |  |
| **Konten Pihak Ketiga** |  | ```text/x-markdown<br />### Konten pihak ketiga<br />Silakan lihat Amap di DingTalk Docs<br />Xigua Video<br />[https://www.ixigua.com/iframe/6992884890526024222?autoplay=0](https://www.ixigua.com/iframe/6992884890526024222?autoplay=0)<br />``` |  |
| **framer, gist, okr, music, figma** |  | ```text/x-markdown<br />framer<br />[framer](https://framer.com/projects/Untitled--9AQKd9GpTBTv9teii1et-hswbH?tutorial=vwnd_CYKcoQ&node=augiA20Il)<br />gist<br />[gist](https://gist.github.com/airyland/5633662)<br />okr<br />Silakan lihat OKR yang disisipkan di DingTalk Docs<br />music<br />[https://music.163.com/outchain/player?type=2&id=5264842&auto=0&height=66](https://music.163.com/outchain/player?type=2&id=5264842&auto=0&height=66)<br />figma<br />[figma](https://www.figma.com/file/PtxEDSd5uYSKSzTmmaSi0q/Untitled)<br />``` |  |
| **Tabel Aplikasi** |  | ```text/x-markdown<br />Tabel Aplikasi<br />Silakan lihat tabel aplikasi yang disisipkan di DingTalk Docs<br />``` |  |
| **Gambar Teks** |  | ```text/x-markdown<br />Gambar teks<br />graph TD       A\[Christmas\] -->\|Get money\| B(Go shopping)       B --> C{Let me think}       C -->\|One\| D\[Laptop\]       C -->\|Two\| E\[iPhone\]       C -->\|Three\| F\[fa:fa-car Car\]<br />``` |  |
| **Acara, Dokumen Yuque, FBI, Kartu Organisasi** |  | ```text/x-markdown<br />Acara:<br />Silakan lihat acara di DingTalk Docs<br />Dokumen Yuque<br />[Dokumen Yuque](https://yuque.antfin.com/qiafeng.zj/uq7opv/zu3tdn)<br />FBI<br />Silakan lihat FBI yang disisipkan di DingTalk Docs<br />Kartu organisasi<br />Silakan lihat kartu organisasi yang disisipkan di DingTalk Docs<br />``` |  |
| **Tanda tangan** |  | ```text/x-markdown<br />Tanda tangan<br />``` |  |
| **AI Minutes** |  | ```text/x-markdown<br />AI Minutes<br />Silakan lihat AI Minutes di DingTalk Docs<br />``` |  |
| **processOn** |  | ```text/x-markdown<br />processOn<br />[https://www.processon.com/embed/632c0f82e401fd43463d0f39](https://www.processon.com/embed/632c0f82e401fd43463d0f39)<br />``` |  |
| **Emoji DingTalk & Emoji** |  | ```text/x-markdown<br />Emoji [Api][Balon][Bendera][Mimisan][Anjing][Menangis][Tertawa Menangis][Menutup Wajah Menangis]2. []<br />Emoji: 😅😂✅🤪😜<br />``` |  |
