## Panduan penggunaan

Saat membuat dokumen baru, pilih «Impor sebagai dokumen online», lalu pilih file .md lokal untuk mengimpornya ke DingTalk Docs.

## Format yang didukung

### Format file

Mendukung tiga jenis file berikut:

.markdown

.mark

.md

### Encoding

Saat ini hanya mendukung file dengan encoding karakter UTF-8
