Dalam banyak situasi, dokumen yang telah diedit perlu dicetak agar dapat dilihat orang lain, seperti proposal kerja sama, Panduan Pengguna, dan lainnya.

## Petunjuk penggunaan

## Cara mengakses fitur cetak

*   Di perangkat komputer, klik **【┇】** pada bilah navigasi di pojok kanan atas dokumen **—> Cetak**, atau gunakan <strong>pintasan Ctrl+P (Mac: Cmd + P)</strong> untuk membuka halaman pengaturan cetak.

*   Mendukung pengaktifan watermark dokumen (aktifkan watermark di backend organisasi): [**Admin Backend**](https://oa.dingtalk.io/) **> Manajemen Dokumen dan Penyimpanan > Izin dan Keamanan > Kontrol Keamanan Organisasi >** Aktifkan/Tutup **Watermark Dokumen**.

*   Di perangkat seluler, buka DingTalk Docs, lalu ketuk **"…" - Cetak** di pojok kanan atas.

## Izin cetak

Siapa saja yang memiliki izin akses ke dokumen dapat menggunakan fitur cetak di dalam dokumen tersebut.

## Keterangan tambahan

Elemen berikut untuk sementara belum mendukung pencetakan 1:1:

*   Kanban proyek

*   Audio/Video online

*   Formula
