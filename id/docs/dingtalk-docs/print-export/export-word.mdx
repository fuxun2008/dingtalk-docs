DingTalk Docs mendukung ekspor ke Word untuk memenuhi kebutuhan pratinjau dan edit multiformat sekaligus menyesuaikan dengan kebiasaan kerja orang lain.

## Petunjuk penggunaan

## Cara mengekspor ke Word

Klik ┇ pada bilah navigasi di pojok kanan atas dokumen, lalu pilih **Unduh ke lokal > Word** untuk mengekspor dokumen menjadi file Word di perangkat lokal. Saat ini ekspor hanya mendukung format **.docx**.

## Izin ekspor ke Word

Setiap orang yang memiliki izin akses ke dokumen dapat mengekspornya ke Word.

## Catatan tambahan

Elemen berikut belum mendukung ekspor 1:1:

*   Kanban proyek

*   Audio/video online

*   Formula
