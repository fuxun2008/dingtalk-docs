Dalam pekerjaan sehari-hari, Anda pasti pernah menghadapi situasi ketika harus mengirim dokumen pribadi kepada orang lain untuk dibaca. Untuk mencegah konten dimanipulasi sembarangan sekaligus menjaga keamanan informasi, ekspor dokumen sebagai PDF adalah solusi yang tepat.

## Petunjuk penggunaan

## Titik akses ekspor PDF

Klik ┇ pada bilah navigasi di pojok kanan atas dokumen, lalu pilih **Unduh ke lokal > PDF** untuk mengunduh dokumen sebagai file PDF di perangkat lokal. Isi teks dan Komentar dapat diekspor secara bersamaan.

## Izin untuk mengekspor PDF

Siapa pun yang memiliki izin akses ke dokumen dapat mengekspornya sebagai PDF.

## Keterangan tambahan

Elemen berikut untuk sementara belum mendukung ekspor 1:1:

*   Kanban proyek

*   Audio/Video online

*   Formula
