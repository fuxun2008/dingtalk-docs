Saat menggunakan dokumen online DingTalk, kekhawatiran seperti penghapusan atau perubahan versi yang tidak disengaja selama kolaborasi banyak pengguna sulit dihindari. Untuk meminimalkan hal ini, DingTalk Docs mendukung tampilan riwayat edit yang menyimpan rekaman revisi setiap pengguna secara real-time. Dengan begitu, Anda dapat melihat versi historis dan memulihkannya kapan saja, sehingga keamanan konten meningkat secara efektif.

## Petunjuk penggunaan

## Melihat riwayat edit

Klik **Dokumen —> sudut kanan atas** ┇ **—> Riwayat**. Panel riwayat akan muncul di sisi kanan dokumen. Di sana, Anda dapat melihat riwayat edit dokumen tersebut dan memulihkannya secara selektif.

## Memulihkan versi historis

Pada tampilan riwayat, terdapat tombol **[Pulihkan]** di sisi kanan setiap versi. Klik tombol tersebut untuk memulihkan dokumen ke versi yang bersangkutan.

## Keluar dari tampilan riwayat edit

Di sudut kiri atas tampilan riwayat terdapat sebuah tombol. Klik tombol tersebut untuk keluar, atau tekan pintasan **Esc** untuk keluar dengan cepat.

## Catatan tambahan

*   Jika dokumen telah dihapus, riwayat edit tidak dapat dilihat.

*   Jumlah hari riwayat dokumen yang dapat dilihat dan dipulihkan berbeda untuk setiap versi:

**DingTalk Versi Standar/Startup**

3 hari

**DingTalk Versi Profesional**

30 hari

**DingTalk Versi Eksklusif**

30 hari

**DingTalk Office Suite**

180 hari
