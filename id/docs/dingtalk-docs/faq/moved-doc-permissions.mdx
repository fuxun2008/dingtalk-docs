Saat Anda memindahkan dokumen di dalam Knowledge Base ke Knowledge Base lain, kolaborator dan konfigurasi izin dokumen akan berubah sesuai aturan. Berikut penjelasan detailnya:

## 1. Perubahan pada kolaborator

Kolaborator dokumen dapat disinkronkan otomatis dari direktori induk atau ditambahkan secara terpisah.

Saat Anda memindahkan sebuah dokumen (atau Folder):

*   Kolaborator yang disinkronkan otomatis dari induk lokasi asal akan dihapus.

*   Kolaborator dari induk lokasi tujuan akan disinkronkan ulang setelah pemindahan.

*   Kolaborator yang ditambahkan pengguna secara terpisah pada dokumen tetap dipertahankan.

<Note>
### Contoh

Dokumen "Catatan Rilis Fitur" perlu dipindahkan dari "Knowledge Base Penjualan" ke "Knowledge Base Layanan Pelanggan". Kolaborator dokumen akan berubah seperti berikut.

### Sebelum dipindahkan

Lokasi: Knowledge Base Penjualan / Catatan Rilis Fitur

Daftar kolaborator dokumen ini:

Manajer Penjualan Budi (diwarisi dari "Knowledge Base Penjualan")

Penanggung Jawab Teknis Andi (ditambahkan pengguna secara terpisah)

</Note>
### Setelah dipindahkan

Lokasi: Knowledge Base Layanan Pelanggan / Catatan Rilis Fitur

Daftar kolaborator dokumen ini:

~~Manajer Penjualan Budi~~~~ (disinkronkan dari "Knowledge Base Penjualan")~~ _**Kolaborator yang disinkronkan otomatis dari lokasi asal akan dihapus**_

Manajer Layanan Pelanggan Sinta (disinkronkan dari "Knowledge Base Layanan Pelanggan") _**Kolaborator dari induk lokasi tujuan akan disinkronkan ulang setelah pemindahan**_

Penanggung Jawab Teknis Andi (ditambahkan pengguna secara terpisah) _**Kolaborator yang ditambahkan pengguna secara terpisah pada dokumen tetap dipertahankan**_

## 2. Perubahan pada konfigurasi izin

Admin dokumen dapat mengatur konfigurasi izin dokumen itu sendiri, dan konfigurasi izin dokumen juga dikendalikan oleh direktori induknya. Untuk detailnya, lihat: Pengaturan izin｜Penjelasan pengaturan izin dokumen

Saat Anda memindahkan sebuah dokumen (atau Folder):

*   Kontrol izin dari induk lokasi asal berhenti berlaku.

*   Konfigurasi izin dokumen itu sendiri tetap dipertahankan.

*   Dokumen akan dikendalikan oleh konfigurasi izin dari induk lokasi tujuan setelah pemindahan.

<Note>
### Contoh

Dokumen "Catatan Rilis Fitur" perlu dipindahkan dari "Knowledge Base Penjualan" ke "Knowledge Base Layanan Pelanggan". Konfigurasi izin dokumen akan berubah seperti berikut.

### Sebelum dipindahkan

Lokasi: Knowledge Base Penjualan / Catatan Rilis Fitur

Sebagian konfigurasi dokumen ini:

Izinkan menambahkan orang di luar Organisasi sebagai kolaborator:

**Tutup** (konfigurasi yang ditambahkan pengguna secara terpisah untuk dokumen ini)

Tampilkan tanda air:

**Aktif** (dikendalikan oleh "Knowledge Base Penjualan")

Perlindungan anti-kebocoran:

Tutup (status default)

### Setelah dipindahkan

Lokasi: Knowledge Base Layanan Pelanggan / Catatan Rilis Fitur

Sebagian konfigurasi dokumen ini:

Izinkan menambahkan orang di luar Organisasi sebagai kolaborator:

**Tutup** (konfigurasi yang ditambahkan pengguna secara terpisah untuk dokumen ini) _**Konfigurasi izin dokumen itu sendiri tetap dipertahankan**_

Tampilkan tanda air:

Tutup (tidak lagi dikendalikan oleh lokasi asal, kembali ke status default) _**Kontrol izin dari induk lokasi asal berhenti berlaku**_

Perlindungan anti-kebocoran:

**Aktif** (dikendalikan oleh lokasi tujuan "Knowledge Base Layanan Pelanggan") _**Dokumen akan dikendalikan oleh konfigurasi izin dari induk lokasi tujuan setelah pemindahan**_
</Note>
