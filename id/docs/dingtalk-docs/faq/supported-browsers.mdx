DingTalk Docs versi web tidak mendukung browser dengan kernel IE. Untuk pengalaman yang lebih baik, pilih tipe browser yang didukung sesuai kebutuhan. Menetapkan browser yang didukung DingTalk Docs sebagai browser default sistem memberikan pengalaman DingTalk Docs versi web yang lancar dan lengkap.

Pelajari lebih lanjut: [Bagaimana cara mengubah browser default sistem?](/zh/docs/dingtalk-docs/settings/set-default-browser)

## IV. Cara mengubah browser default

### Sistem Windows

1.  Pilih tombol "Start", klik "Pengaturan", lalu ketik "Aplikasi default".

2.  Dari hasil pencarian, pilih "Aplikasi default".

3.  Buka Aplikasi \> Aplikasi default \> Browser web, pilih browser yang ingin ditetapkan sebagai program default, lalu klik "Tetapkan program ini sebagai default". Jika muncul kotak dialog, pilih "Tetap alihkan" untuk menyelesaikan pengaturan.
