## Penyebab masalah

Secara default, Kolaborator dokumen dengan izin "Dapat melihat/mengunduh" atau lebih tinggi dapat menyalin Isi Teks dokumen, mengunduh dokumen, mencetak dokumen, dan membuat salinan. Jika Anda memiliki izin tersebut tetapi tidak bisa menyalin, mengunduh, atau mencetak dokumen, **penyebab utamanya adalah:**

Admin dokumen atau Knowledge Base telah mengaktifkan opsi **"Hanya orang dengan izin 'Dapat mengelola' yang dapat mengunduh, membuat salinan, dan mencetak / Semua orang dilarang mengunduh, membuat salinan, dan mencetak"** pada fitur "Konfigurasi Izin", sehingga aturan default di atas tidak berlaku, seperti ditunjukkan pada gambar berikut:

Dalam kondisi ini, meskipun Pengguna memiliki izin "Dapat melihat/mengunduh" atas dokumen, ia tetap tidak bisa menyalin Isi Teks dokumen, mengunduh dokumen, mencetak dokumen, maupun membuat salinan. Pada skenario ini, Tips akan muncul saat tindakan terkait dilakukan.

## Cara mengatasi

Hubungi Admin dokumen atau Knowledge Base untuk mengubah pengaturan izin dokumen/Knowledge Base. Untuk informasi lebih lanjut tentang pengaturan izin dokumen, lihat Konfigurasi izin berbagi, salin, unduh, komentar, dan lainnya.
