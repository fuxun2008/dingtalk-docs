## Tanya: Apakah DingTalk memiliki fitur edit online?

Jawab: Ya. Gunakan paket kreasi DingTalk Docs, Spreadsheet, Peta Pikiran, Whiteboard, dan AI Table. Semuanya mendukung edit online oleh banyak orang secara bersamaan.

Klik untuk mempelajari lebih lanjut: fitur produk

## Tanya: Apa itu DingTalk Docs?

Jawab: DingTalk Docs adalah paket kolaborasi perkantoran perusahaan yang dikembangkan sendiri oleh DingTalk dari <strong>Alibaba Group</strong>, mencakup alat kreasi online dan pengelolaan dokumen seperti <strong>Dokumen, Spreadsheet, Peta Pikiran, AI Table, Whiteboard, dan Knowledge Base</strong>. Tanpa perlu mengunduh dokumen, Anda dapat langsung mengedit dan melihatnya di komputer, ponsel, maupun tablet, dengan konten yang tersimpan secara real-time. Selain itu, DingTalk Docs <strong>terintegrasi secara mendalam dengan DingTalk</strong>, sehingga Anda dapat berkolaborasi secara efisien dengan rekan kerja berdasarkan hubungan organisasi. Skenario kerja harian seperti <strong>pengumpulan informasi, manajemen proyek, rapat, pelaporan bisnis, dan onboarding karyawan baru</strong> dapat diselesaikan secara efisien melalui DingTalk Docs.

Klik untuk mempelajari lebih lanjut: [Panduan cepat DingTalk Docs](/zh/docs/dingtalk-docs/insert-content/insert-whiteboard)

## Tanya: Bagaimana cara melihat riwayat DingTalk Docs/Spreadsheet?

Jawab: Saat menggunakan DingTalk Docs/Spreadsheet, Anda dapat melihat riwayat melalui pengaturan berikut:

DingTalk Docs: pojok kanan atas — ┇ — Riwayat; atau lihat "Pertanyaan 3" di atas untuk mengatur toolbar.

Spreadsheet: pojok kanan atas ... — Riwayat. Saat ini Riwayat mendukung tampilan versi historis dan tindakan pemulihan.

## Tanya: Bagaimana cara mengunduh DingTalk Docs/Spreadsheet ke lokal?

Jawab: Buka DingTalk Docs di komputer, lalu unduh dokumen online menjadi file lokal dengan cara berikut:

DingTalk Docs: pojok kanan atas — ┇ — Unduh ke lokal. Saat ini mendukung tiga format unduhan: .docx, .pdf, dan .md. Jika toolbar tidak ditemukan, lihat "Pertanyaan 3" di atas untuk mengatur toolbar.

Spreadsheet: toolbar atas — Menu — Spreadsheet — Unduh sebagai. Pilih format file yang diinginkan untuk diunduh.

Tips: Dokumen saat ini mendukung ekspor ke Word/PDF; Spreadsheet mendukung ekspor ke format Excel/PDF/CSV/TSV.

## Tanya: Bagaimana cara mengajukan aktivasi DingTalk Docs?

Jawab: Fitur DingTalk Docs (edit online) tidak perlu diaktifkan. Cukup masuk ke DingTalk dan lakukan autentikasi organisasi untuk menggunakan fitur edit online.

## Tanya: Bagaimana cara menyisipkan gambar di DingTalk Docs?

Jawab: Saat ini DingTalk Docs mendukung penyisipan emoji, gambar, tautan video, lampiran, tautan, peta pikiran, roadmap, flowchart, dokumen online di dalam Drive/Knowledge Base, dan lainnya. Tipe penyisipan di ponsel terbatas, untuk Jenis Lainnya silakan lakukan di komputer.

**Di komputer:** Buka DingTalk Docs, toolbar atas — "+", lalu pilih Sisipkan Gambar; atau masuk ke mode edit, ketik garis miring "/", lalu pilih Sisipkan Gambar.

**Di ponsel:** Buka edit online DingTalk Docs, ketuk ikon 【Gambar】 di toolbar bagian bawah — 【Sisipkan Gambar】\【Sisipkan Tautan】. Saat ini ponsel mendukung penyisipan gambar, tabel, tautan, dan garis horizontal, tetapi tidak mendukung penyisipan file.

## Tanya: Bagaimana cara mengatur izin edit dokumen?

Jawab: Klik 【Bagikan】 di pojok kanan atas, lalu masuk ke "Kelola izin" pada "Undang Kolaborator". Fitur ini mendukung pemberian izin kepada orang tertentu, mencakup: dapat mengelola, dapat mengedit, dapat melihat/mengunduh, hanya dapat melihat, dan mencabut izin.

## Tanya: Mengapa sebagian karyawan tidak memiliki fitur edit online?

Jawab: Jika fitur edit online tidak tersedia, periksa informasi berikut:

1. DingTalk versi Lite tidak mendukung fitur edit online;

2. Edit online hanya mendukung sistem bahasa yang diatur ke Simplified Chinese/English; disarankan untuk mengganti bahasa Anda;

3. Untuk file Office yang diunggah dari lokal ke DingTalk, jika saat mengedit Anda memilih editor resmi Microsoft, Anda perlu membeli DingTalk Office Suite versi Premium untuk menggunakannya;

4. Anheng Mishield tidak kompatibel dengan produk ini; jika organisasi mengaktifkan fitur Anheng Mishield, edit online tidak dapat digunakan (perhatikan apakah ada ikon perisai kecil di pojok kanan bawah file);

5. Saat ini edit online kompatibel dengan file Word, Excel, dan PPT Office (PPT hanya mendukung edit online di komputer); file dengan format lain tidak mendukung edit online, silakan unduh terlebih dahulu untuk mengeditnya;

6. Edit online DingTalk versi Standar hanya mendukung pembukaan file di bawah 20M; jika file terlalu besar, saat mengedit akan muncul pesan seperti "Gagal mendapatkan tautan edit" atau "File terlalu besar".

## Tanya: Apakah DingTalk Docs mendukung pembukaan di browser?

Jawab: DingTalk Docs versi Web telah diluncurkan. Buka di browser dengan menyalin tautan berikut: https://docs.dingtalk.io/. Anda juga dapat mengatur dokumen agar otomatis terbuka di browser. Petunjuk pengaturan: [Buka DingTalk Docs dengan browser](/zh/docs/dingtalk-docs/settings/open-in-browser)

## Tanya: Bagaimana cara memulihkan data yang hilang?

Jawab: Buka DingTalk Docs, pojok kanan atas — ┇ — Riwayat, lalu cari versi data yang perlu dipulihkan di 【Versi Historis】. Setelah menemukannya, klik tombol 【Pulihkan】 untuk menyelesaikan pemulihan data.
