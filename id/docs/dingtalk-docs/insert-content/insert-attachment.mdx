Untuk menghemat waktu kerja, menghindari pengeditan berulang pada dokumen dengan konten serupa, dan membantu pembaca memahami istilah atau data tertentu dengan lebih baik, menyisipkan lampiran ke dalam dokumen merupakan cara yang tepat. DingTalk Docs mendukung penyisipan berbagai tipe dokumen sebagai lampiran untuk ditinjau dan diedit.

## Petunjuk penggunaan

## Menyisipkan file lokal/Drive

Klik **Sisipkan → File** pada bilah navigasi atas atau klik langsung **Unggah File** pada bilah alat. Pilih **File lokal/File Drive** dari menu drop-down untuk mengunggah lampiran dari lokasi terkait ke dalam dokumen.

## Pratinjau lampiran

File audio/video dan file Office yang disisipkan ke dalam dokumen dapat dipratinjau langsung secara online tanpa perlu diunduh.

## Pengaturan tampilan lampiran

Lampiran yang disisipkan ke dalam file mendukung pengaturan gaya tampilan yang berbeda (saat ini hanya tersedia di versi PC):

*   **Tautan ikon dan teks**

*   **Kartu ringkasan**

*   **Kartu pratinjau**

## Keterangan tambahan

Saat ini lampiran yang dapat diunggah maksimal 251M. Format file yang mendukung pratinjau online adalah sebagai berikut:

| Format gambar | jpg, jpeg, png, bmp, gif |
| --- | --- |
| Format dokumen | doc, docx, xls, xlsx, ppt, pptx, pdf |
| Format video | mp4, egg, webm, mov |
| Format audio | mp3 |
