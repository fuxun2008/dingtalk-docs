$Tambah formula$DingTalk Docs mendukung penyisipan formula matematika **Tex** ke dalam dokumen.

## Panduan penggunaan

## Menambahkan formula

1.  Klik **Sisipkan —> Formula** pada bilah navigasi atas, lalu ketik kode pada area edit formula. Formula matematika langsung ditampilkan secara real-time.

2.  Klik formula yang telah disisipkan, lalu tekan tombol **Backspace** untuk menghapusnya dengan cepat.
