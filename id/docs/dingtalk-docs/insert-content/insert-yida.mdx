## Petunjuk penggunaan

Di DingTalk Docs, Anda dapat menyisipkan <strong>tautan Yida</strong> untuk menampilkan informasi halaman Yida secara langsung sekaligus memperbaruinya secara sinkron. Gunakan menu «/», «+», atau «Sisipkan» pada dokumen untuk memilih dan menyisipkan halaman Yida terkait dengan mudah.
