## Petunjuk penggunaan

Di DingTalk Docs, Anda dapat menyisipkan aplikasi OKR pihak ketiga untuk menampilkan konten OKR tim dan individu secara langsung serta memperbaruinya secara sinkron. Setelah mengaktifkan aplikasi "Ding OKR" dan "Polaris OKR", gunakan "/" atau "+" untuk memilih dan menyisipkan aplikasi OKR terkait dengan mudah.

## Petunjuk menyisipkan Ding OKR

## 1. Salin tautan berbagi OKR

## 2. Sisipkan di DingTalk Docs

### Metode 1: Tempel tautan secara langsung

Di dalam dokumen, tekan Ctrl + V atau klik kanan untuk menempel tautan OKR. Tautan akan dikenali secara otomatis, dan Anda dapat menampilkannya sebagai tautan teks, tautan teks berikon, kartu ringkasan, atau kartu pratinjau.

### Metode 2: Sisipkan melalui menu sisipkan

Klik menu sisipkan di dalam dokumen, temukan "Ding OKR" pada daftar, masukkan tautan OKR di kolom input tautan, lalu klik Konfirmasi untuk membuat kartu pratinjau OKR.
