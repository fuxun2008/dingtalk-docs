## Panduan penggunaan

Di DingTalk Docs, Anda dapat menyisipkan aplikasi OKR pihak ketiga untuk langsung menampilkan konten OKR tim maupun individu serta memperbaruinya secara sinkron. Setelah mengaktifkan aplikasi "Dingdang OKR" dan "OKR North Star", gunakan "/" dan "+" untuk memilih dan menyisipkan aplikasi OKR terkait dengan mudah.

## Panduan penyisipan OKR North Star

## Menyalin tautan tujuan di OKR North Star

1. Arahkan kursor ke tujuan yang ingin dibagikan, lalu klik detail.

2. Pada halaman detail, klik **ikon Bagikan** di pojok kanan atas, lalu pilih **Salin ke DingTalk Docs**.

**Dua. Menyisipkan tujuan di DingTalk Docs**

Metode 1: Di dalam dokumen, tekan Ctrl + V atau klik kanan untuk menempel tautan OKR. Tautan akan dikenali otomatis, dan Anda dapat memilih untuk menampilkannya sebagai tautan teks, tautan ikon teks, kartu ringkasan, atau kartu pratinjau.

**Metode 2:** Klik menu sisip di dalam dokumen, temukan "OKR North Star" dari daftar, masukkan tautan tujuan pada kotak input tautan, lalu klik Konfirmasi untuk membuat kartu pratinjau tujuan.

**Tiga. Bagaimana cara menggunakan kartu tujuan?**

Kartu yang disisipkan memiliki fitur tampilan yang kaya untuk memenuhi berbagai skenario bisnis.
