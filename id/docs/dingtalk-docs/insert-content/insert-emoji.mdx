## Nilai fitur

Perjelas struktur artikel untuk memudahkan pemahaman konten, serta susun tata letak dokumen secara kreatif dan efisien.

## Skenario penggunaan

Bosan dengan simbol daftar tradisional berupa titik hitam kecil? Jangan khawatir, DingTalk Docs kini menambahkan seri emoji pada daftar. Tersedia berbagai pilihan kreatif agar pekerjaan tetap efisien sekaligus tampil menarik dan segar. Buka dokumen, ganti gaya daftar, dan mulai bekerja dengan cara yang menyenangkan.

## Petunjuk penggunaan

Mode ringkas

1. Masukkan Daftar Bernomor/Daftar Berpoin.

2. Klik nomor urut untuk mengganti gaya.

3. Temukan daftar emoji pada gaya Daftar Berpoin, lalu klik untuk menggantinya.

Mode profesional

1. Toolbar -- Daftar Berpoin -- Gaya -- Pilih daftar emoji.

2. Toolbar -- Daftar Bernomor.
