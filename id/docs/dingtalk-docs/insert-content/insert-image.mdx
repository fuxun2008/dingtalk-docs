Untuk membuat konten spreadsheet dalam dokumen lebih jelas, Anda dapat menggunakan fitur Sisipkan Gambar. Gambar yang disisipkan dengan tepat juga membuat tampilan dokumen lebih menarik.

## Petunjuk penggunaan

## Tambah gambar

Klik **Sisipkan—>Gambar** pada bilah navigasi atas, atau klik langsung unggah <strong>Gambar</strong> pada bilah alat untuk mengunggah gambar lokal ke dalam dokumen.

## Edit gambar

Klik gambar untuk memunculkan bilah alat gambar, lalu lakukan pengaturan yang diperlukan. Tindakan yang saat ini didukung adalah sebagai berikut:

*   Ekstrak teks dari gambar

*   Unduh gambar

*   Atur gaya gambar

*   Atur ukuran gambar

*   Potong gambar

*   Deskripsi gambar

*   Tambah tautan

*   Putar gambar

*   Rata horizontal

*   Ganti gambar
