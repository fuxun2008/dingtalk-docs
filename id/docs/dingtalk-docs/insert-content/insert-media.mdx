DingTalk Docs mendukung penyematan audio dan video online dari beragam platform pihak ketiga. Saat ini tersedia untuk **Youku**, **Xigua Video**, **Tencent Video**, **Sohu Video**, **Bilibili**, dan **NetEase Cloud Music**. Artikel ini menjelaskan cara memperoleh tautan yang dapat disematkan dari setiap platform satu per satu.

> Perhatikan: Konten yang disematkan disediakan oleh pihak ketiga, dan DingTalk Docs tidak dapat menjamin ketersediaannya dalam jangka panjang. Patuhi ketentuan penggunaan pihak ketiga serta peraturan dan kebijakan setempat.

## Youku

Di halaman pemutaran, klik **Bagikan**, lalu salin **alamat halaman** atau **kode umum**:

Format tautan penyematan adalah sebagai berikut:

```application/xml
https://v.youku.com/v_show/id_xxx==.html?xxx
或

```

## Xigua Video

Di halaman pemutaran, klik **Bagikan**, lalu salin **alamat video** (Anda juga dapat menyalin tautan langsung dari bilah alamat browser):

Format tautan penyematan adalah sebagai berikut:

```application/xml
https://www.ixigua.com/xxx
```

## Tencent Video

Di halaman pemutaran, klik **Bagikan**, lalu salin **kode penyematan** (disarankan) atau **tautan**:

Format tautan penyematan adalah sebagai berikut:

```application/xml
https://v.qq.com/x/cover/xxx/xxx.html
或

```

## Sohu Video

Di halaman pemutaran, klik **Bagikan**, lalu salin **kode umum** (tidak mendukung penguraian alamat halaman):

Format tautan penyematan adalah sebagai berikut:

```application/xml
https://v.qq.com/x/cover/xxx/xxx.html
或

```

## Bilibili

Di halaman pemutaran, klik **Bagikan**, lalu salin **alamat video** atau **kode penyematan** (Anda juga dapat menyalin tautan langsung dari bilah alamat browser):

Format tautan penyematan adalah sebagai berikut:

```application/xml
https://www.bilibili.com/video/xxx
或

```

## NetEase Cloud Music

Salin **alamat halaman lagu** (disarankan), atau klik **Buat pemutar tautan eksternal** lalu **Salin kode**:

Format tautan penyematan adalah sebagai berikut:

```application/xml
https://music.163.com/#/song?id=xxx
或

```

## Pertanyaan umum

1.  **Apakah tautan pendek didukung?**

    DingTalk Docs tidak mendukung penguraian tautan pendek dari platform pihak ketiga. Peroleh tautan penyematan sesuai petunjuk di atas.

2.  **Mengapa video yang disematkan tidak dapat diputar?**

Beberapa platform mungkin menerapkan batasan pemutaran pada konten yang disematkan. Hal ini bisa terkait dengan tipe sumber daya (misalnya, beberapa video film tidak mengizinkan pemutaran di pihak yang menyematkan), atau dengan akun Anda (misalnya, apakah Anda sudah masuk, apakah Anda anggota, dan sebagainya). Hubungi layanan pelanggan platform terkait untuk berkonsultasi. Selain itu, untuk video YouTube, pastikan jaringan Anda saat ini dapat terhubung ke situs tersebut.
