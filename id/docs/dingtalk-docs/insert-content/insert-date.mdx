DingTalk Docs mendukung penyisipan tanggal sehingga Anda tidak perlu lagi mengetik tanggal secara manual dan format tanggal pun lebih standar. Tanggal yang disisipkan juga dapat mencakup titik waktu spesifik.

## Petunjuk penggunaan

Pilih lokasi untuk menambahkan tanggal, klik <strong>Sisipkan—>Tanggal</strong> pada bilah navigasi atas, lalu pilih waktu yang diinginkan pada kalender yang muncul. Tanggal yang ditambahkan ditampilkan dengan font berwarna <strong>biru</strong>. Untuk mengubahnya, klik langsung tanggal tersebut lalu pilih ulang.

## Keterangan tambahan

*   Klik <strong>tanda panah kiri dan kanan</strong> `<` `>` pada kalender untuk berpindah bulan.

*   Klik tahun di pojok kiri atas kalender untuk berpindah tahun.

*   Centang opsi <strong>Waktu</strong> di bagian bawah kalender untuk menampilkan titik waktu spesifik setelah tanggal. Titik waktu tersebut dapat Anda sesuaikan sendiri.
