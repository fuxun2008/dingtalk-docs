## Nilai fitur

Sisipkan daftar isi dalam dokumen dengan satu klik agar struktur konten terlihat jelas dan pencarian konten lebih efisien.

## Skenario penggunaan

Ding Sanduo adalah staf administrasi yang setiap hari menggunakan DingTalk Docs untuk mengedit berbagai materi kegiatan perusahaan, catatan rapat, dokumen administrasi, dan lainnya. Dengan fitur ini, ia dapat menyisipkan daftar isi dalam dokumen dengan satu klik saat menulis. Untuk dokumen dengan teks yang panjang, daftar isi membuat struktur konten terlihat jelas. Saat mencari konten, ia tidak perlu bolak-balik membuka halaman, sehingga jauh lebih praktis.

## Petunjuk penggunaan

Klik panel Sisipkan pada bilah navigasi di bagian atas, lalu pilih Daftar isi untuk menyisipkannya ke dalam dokumen. Judul pada konten dokumen (Font ukuran 14 ke atas) akan otomatis dijadikan daftar isi.
