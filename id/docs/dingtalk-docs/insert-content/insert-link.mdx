Saat mengedit dokumen, Sisipkan Tautan sering digunakan agar pembaca dapat <strong>beralih dengan cepat</strong> ke lokasi yang ditentukan sehingga menghemat waktu membaca. Selain itu, Sisipkan Tautan juga membantu memperluas cakupan pengetahuan yang dimuat dokumen, biasanya untuk memperkenalkan tokoh terkenal, menjelaskan istilah khusus, dan sebagainya.

## Petunjuk penggunaan

## Sisipkan tautan

Pilih lokasi atau teks target tempat tautan akan disisipkan, klik bilah alat dokumen di bagian atas, lalu pilih <strong>Tautan</strong>. Jika warna font pada lokasi atau teks target berubah menjadi biru, berarti tautan berhasil disisipkan.

> Untuk menambahkan tautan halaman web, klik "Tambah tautan halaman web" di sebelah kiri guna mencoba fitur Sisipkan Tautan.

## Pengaturan terkait tautan

Pada jendela pop-up Sisipkan Tautan, Anda dapat <strong>mengatur judul</strong> untuk tautan serta memilih <strong>gaya tautan</strong>: **tautan atau kartu**.

## Batalkan sisipan tautan

Klik lokasi atau teks tempat tautan disisipkan, lalu pilih <strong>Batalkan tautan</strong> di bagian atas.
