description: "Batasi penerusan, pengunduhan, dan salin-tempel file dalam aplikasi serta cakupkan kebijakan ke karyawan, departemen, atau peran tertentu dari konsol admin."
---

Organisasi dapat mengelola operasi yang terkait dengan file dalam aplikasi, termasuk mengontrol tindakan seperti penerusan, pengunduhan, dan salin-tempel.

---

## II. Panduan pengguna

### 1. Navigasi Konsol Admin

Di panel navigasi kiri, buka **Keamanan & izin > Keamanan > Perlindungan Data > Kontrol file dalam aplikasi**

<Frame>
  <img src="https://img.alicdn.com/imgextra/i2/O1CN01IGwP7FyawDJ4WieU_!!6000000004213-2-tps-2230-1256.png" alt="Jalur navigasi Kontrol file dalam aplikasi" />
</Frame>

### 2. Administrator — Belum ada aturan yang dikonfigurasikan

Kontrol file dalam aplikasi mencakup beberapa kemampuan, meliputi klien seluler dan desktop serta melibatkan berbagai operasi file.

Dengan mengambil contoh "Unduh file ke terminal seluler":

Ketika belum dikonfigurasikan, fitur ini nonaktif.

Ketika nonaktif, perilakunya konsisten dengan pengalaman DingTalk default.

  <img src="https://img.alicdn.com/imgextra/i1/O1CN013U1WJWexblL1COcr_!!6000000003354-2-tps-591-346.png" alt="Fitur nonaktif ketika belum ada aturan yang dikonfigurasikan" />
</Frame>

### 3. Administrator — Contoh konfigurasi

<Steps>
  <Step title="Pratinjau konfigurasi kartu">
    Klik ikon info untuk melihat pratinjau efek konfigurasi kartu.

    <Frame>
      <img src="https://img.alicdn.com/imgextra/i3/O1CN01Yqm2U59fBPE1D1eJ_!!6000000004915-2-tps-596-347.png" alt="Pratinjau konfigurasi kartu" />
    </Frame>
  </Step>
  <Step title="Aktifkan fitur">
    Alihkan sakelar dan klik **Konfirmasi** di dialog untuk mengaktifkan fitur.

    <Frame>
      <img src="https://img.alicdn.com/imgextra/i2/O1CN01swUjbxK1rlH1cSHz_!!6000000005868-2-tps-798-749.png" alt="Aktifkan fitur" />
    </Frame>
  </Step>
  <Step title="Konfigurasikan cakupan yang berlaku">
    Fitur ini berlaku untuk semua karyawan secara default.

    Klik **Sunting** untuk mengonfigurasikan cakupan yang berlaku — tentukan karyawan mana yang dikenai atau dikecualikan dari kebijakan.

    Misalnya, untuk menerapkan kebijakan hanya pada Departemen Teknik, pilih **Karyawan Tertentu**, lalu gunakan pemilih kontak untuk memilih departemen tersebut.

    Pemilih kontak juga mendukung pemilihan berdasarkan peran, sehingga administrator memiliki keleluasaan untuk mengonfigurasikan sesuai kebutuhan.
