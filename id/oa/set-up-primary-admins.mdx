---
title: "Menyiapkan admin utama"
description: "Tetapkan admin utama dengan izin penuh untuk mengelola kontak, kehadiran, dan aplikasi lainnya di seluruh organisasi Anda melalui Konsol Admin."
---

**Admin utama:** Memiliki izin administratif penuh di seluruh organisasi. Dapat masuk ke Konsol Admin dan mengelola Kontak, Kehadiran, Persetujuan, Laporan, Pengumuman, dan aplikasi lain milik organisasi. Dapat juga mendelegasikan izin administratif kepada orang lain.

---

## Alur operasi

Tambahkan admin utama melalui salah satu jalur berikut:

- **Jalur 1:** Beranda > Tetapkan Admin > Tambahkan admin utama
- **Jalur 2:** Keamanan & izin > Izin > Tambahkan admin utama

<Warning>
**Catatan penting:**

- Akun yang semula membuat struktur organisasi ditetapkan sebagai admin utama **Pembuat**. Akun ini tidak dapat ditambahkan atau dihapus — hanya dapat dialihkan.
- Admin utama tanpa tag **Pembuat** adalah admin utama biasa. Mereka dapat ditambahkan atau dihapus, dan perubahan langsung berlaku.
- Hanya satu admin utama dengan tag Pembuat yang dapat ditetapkan. Jumlah maksimum admin utama biasa adalah 999.
</Warning>
