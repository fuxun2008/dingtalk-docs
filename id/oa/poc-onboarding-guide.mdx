Panduan ini ditujukan untuk penanggung jawab proyek dan administrator organisasi dari pelanggan baru di luar negeri. Panduan ini menjelaskan seluruh alur — mulai dari memilih paket di situs web, memulai uji coba gratis, mendaftarkan admin, dan membuat organisasi, hingga masuk ke Konsol Admin dan mengimpor akun perusahaan secara massal.

<Info>
  **Untuk siapa panduan ini**: Penanggung jawab proyek dan administrator organisasi pertama yang bertanggung jawab menjalankan POC (Proof of Concept) perusahaan DingTalk.
</Info>

## Ikhtisar alur

<Steps>
  <Step title="Buka situs web dan jelajahi paket">Buka situs web global DingTalk dan bandingkan paket Free / Basic / Standard / Premium.</Step>
  <Step title="Mulai uji coba gratis">Pilih paket yang sesuai dan ajukan uji coba gratis berfitur lengkap selama 30 hari.</Step>
  <Step title="Daftarkan admin pertama">Daftar, selesaikan verifikasi identitas, dan atur kata sandi.</Step>
  <Step title="Buat organisasi">Isi detail organisasi dan catat Org ID serta Organization Code.</Step>
  <Step title="Masuk ke Konsol Admin">Masuk ke Konsol Admin untuk mengonfigurasikan organisasi Anda.</Step>
  <Step title="Bangun struktur departemen">Buat departemen sesuai cakupan pengujian Anda.</Step>
  <Step title="Impor akun perusahaan secara massal">Unduh templat Excel, impor secara massal, dan periksa hasilnya secara acak.</Step>
</Steps>

## Langkah 1: Buka situs web dan pilih paket

Kunjungi situs web global DingTalk: [https://www.dingtalk.io/](https://www.dingtalk.io/) (halaman bahasa Tionghoa: [https://www.dingtalk.io/zh/](https://www.dingtalk.io/zh/)).

Situs web menawarkan empat paket. Pilih salah satu berdasarkan jumlah pengguna POC, skenario bisnis, persyaratan keamanan, kebutuhan penyimpanan, dan cakupan integrasi sistem Anda:

| Paket | Cocok untuk |
|------|----------|
| **Free** | Pengalaman produk yang siap pakai |
| **Basic** | Startup dan tim kecil — memvalidasi kemampuan inti seperti pesan, kalender, dan kolaborasi dokumen |
| **Standard** | Organisasi yang berkembang — kebijakan keamanan lebih kuat, penyimpanan cloud lebih besar, dan layanan dukungan |
| **Premium** | Organisasi menengah hingga besar — kemampuan lebih canggih dan kolaborasi lintas tim berskala besar |

## Langkah 2: Mulai uji coba gratis

Di situs web, klik **Start Free Trial**. Setiap paket berhak atas uji coba gratis berfitur lengkap selama 30 hari — tanpa kartu kredit.

<Tip>
  Jika POC Anda melibatkan Enterprise, kepatuhan data, SSO, wilayah data, atau kebutuhan khusus, Anda juga dapat mengklik **Contact Sales**: [https://www.dingtalk.io/contact-sales/](https://www.dingtalk.io/zh/contact-sales/?from=%2F)
</Tip>

**Siapkan sebelum mengajukan:**

- Nama organisasi dan negara/wilayah
- Perkiraan jumlah pengguna POC
- Waktu mulai dan periode pengujian yang direncanakan
- Skenario bisnis utama yang akan divalidasi
- Nama, email, dan nomor telepon Super Admin

<Note>
  **Contoh catatan pengajuan**: Mengajukan POC perusahaan DingTalk, ~XX pengguna, periode pengujian XX hari, berfokus pada validasi manajemen organisasi, alur kerja admin, kolaborasi rapat, dan onboarding karyawan secara massal.
</Note>

## Langkah 3: Daftarkan akun admin

Pilih salah satu metode berikut untuk mendaftar sesuai petunjuk: **email yang valid** / **akun Google** / **nomor telepon yang valid dengan kode verifikasi**. Selesaikan verifikasi identitas, atur kata sandi, dan setujui Terms of Service serta Privacy Policy.

<Tip>
  Untuk POC perusahaan, gunakan email kerja jangka panjang pelanggan sebagai akun Super Admin, dan konfigurasikan admin cadangan.
</Tip>

## Langkah 4: Buat organisasi

Pilih paket target Anda dan selesaikan alur uji coba gratis atau langganan sesuai petunjuk. Saat membuat organisasi, siapkan hal berikut:

| Kolom | Rekomendasi |
|------|----------|
| Organization Name | Gunakan nama resmi perusahaan dalam bahasa Inggris; hindari nama pribadi atau nama proyek sementara |
| Country / Region | Pilih wilayah operasi utama atau wilayah POC organisasi |
| Industry / Organization Size | Isi industri sebenarnya dan perkiraan jumlah karyawan |
| Super Admin | Gunakan email atau nomor telepon admin yang telah diverifikasi |
| Org ID | Simpan pengenal unik organisasi yang diberikan setelah pembuatan |
| Organization Code | Digunakan untuk menemukan organisasi saat masuk dengan akun perusahaan; catat terpisah dari Org ID |

<Warning>
  Setelah organisasi dibuat, pastikan untuk menyimpan **Org ID**. **Organization Code** yang diperlukan untuk masuk dengan akun perusahaan dapat dilihat oleh admin di **Security and Permission → Organization code login**.
</Warning>

## Langkah 5: Masuk ke Konsol Admin

Admin mengunjungi: [https://oa.dingtalk.io/](https://oa.dingtalk.io/)

Masukkan detail organisasi Anda sesuai petunjuk dan pilih metode login:

- Email atau nomor telepon terdaftar + kata sandi
- Nomor telepon + kode verifikasi
- Pindai kode QR dengan DingTalk seluler
- Akun perusahaan + Organization Code + kata sandi
- Akun pihak ketiga yang tertaut

Anda juga dapat masuk dari klien DingTalk: **Foto Profil → Konsol Admin**, atau **Kontak → nama organisasi → Kelola**.

<Note>
  Jika akun Anda tergabung dalam beberapa organisasi, pastikan Anda masuk ke organisasi untuk POC ini.
</Note>

## Langkah 6: Bangun struktur departemen

Di Konsol Admin, buka Kontak dan buat struktur departemen yang diperlukan POC Anda:

**Konsol Admin → Kontak (Contacts) → Manajemen Departemen → Tambah Departemen**

<Tip>
  Buat departemen tingkat atas terlebih dahulu, lalu tambahkan departemen tingkat kedua yang diperlukan untuk cakupan pengujian Anda. Nama departemen harus sesuai dengan struktur organisasi pelanggan saat ini.
</Tip>

## Langkah 7: Impor akun perusahaan secara massal via Excel

**Jalur**: Konsol Admin (Admin Console) → Kontak (Contacts) → Anggota (Members) → Edit Massal (Batch Edit) → Impor Massal (Bulk Import)

<Steps>
  <Step title="Unduh templat">Klik **Download Template** dan gunakan templat Excel standar yang diunduh dari organisasi Anda saat ini.</Step>
  <Step title="Isi detail karyawan">Ikuti baris contoh dan petunjuk dalam templat untuk mengisi detail karyawan. Hapus baris contoh sebelum mengunggah.</Step>
  <Step title="Pertahankan struktur templat">Jangan mengubah nama kolom, urutan kolom, struktur lembar kerja, atau jenis file.</Step>
  <Step title="Unggah file">Kembali ke halaman impor, klik **Upload File**, pilih file Excel yang telah diisi, lalu klik **Import**.</Step>
  <Step title="Periksa hasil secara acak">Setelah impor selesai, periksa daftar anggota secara acak berdasarkan departemen, nama, email, atau nomor telepon.</Step>
</Steps>

<Tip>
  Impor 3–5 admin dan pengguna uji terlebih dahulu. Setelah akun, penetapan departemen, dan login semuanya berfungsi dengan benar, impor sisa pengguna POC.
</Tip>

## Mengatasi masalah impor

Jika unggahan atau impor gagal:

<AccordionGroup>
  <Accordion title="Periksa catatan karyawan">Tinjau catatan karyawan yang relevan berdasarkan pesan kesalahan di layar.</Accordion>
  <Accordion title="Verifikasi kolom dan format">Pastikan kolom wajib dan format sesuai dengan petunjuk templat.</Accordion>
  <Accordion title="Verifikasi struktur templat">Pastikan Anda tidak mengubah nama kolom, urutan kolom, atau struktur lembar kerja templat.</Accordion>
  <Accordion title="Perbaiki dan coba lagi">Perbaiki catatan yang salah dan unggah kembali.</Accordion>
  <Accordion title="Atasi masalah halaman">Jika halaman berperilaku tidak normal, segarkan halaman, masuk kembali, atau coba lagi dengan Google Chrome versi terbaru.</Accordion>
</AccordionGroup>
