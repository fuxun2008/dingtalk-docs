---
title: "Panduan pengaturan notifikasi push FCM"
description: "Siapkan FCM untuk mengaktifkan notifikasi push offline pada aplikasi DingTalk khusus Anda di perangkat Android, iOS, dan Web luar negeri melalui pendaftaran dan konfigurasi Firebase."
---

FCM (Firebase Cloud Messaging) adalah solusi pesan lintas platform yang mendukung platform Android, iOS, dan Web. FCM merupakan versi yang ditingkatkan dari GCM (Google Cloud Messaging).

Jika Anda ingin Aplikasi khusus Anda menerima notifikasi push offline di perangkat luar negeri, ajukan FCM dan sediakan materi yang diperlukan.

---

## Mengajukan FCM

<Steps>
  <Step title="(1) Ajukan akun Google Developer" />

  <Step title="(2) Daftar di Firebase">
    Buat proyek dan daftarkan aplikasi di Firebase. URL pendaftaran: [https://console.firebase.google.com/](https://console.firebase.google.com/)

    Setelah membuat proyek, pilih ikon Android untuk mengonfigurasikan aplikasi Android:

    <Frame>
      <img src="https://img.alicdn.com/imgextra/i2/O1CN01guJQUNGUwyJ4JFYZ_!!6000000004619-2-tps-2123-1256.png" alt="Mengonfigurasikan aplikasi Android di Firebase" />
    </Frame>

    <Note>
      Harap perhatikan:

      - **Nama paket Android**: Masukkan nama paket DingTalk khusus yang benar
      - **Nama panggilan aplikasi (opsional)**: Masukkan nama aplikasi DingTalk khusus
    </Note>

    <Frame>
      <img src="https://img.alicdn.com/imgextra/i4/O1CN014N2vWlWwdXL4TC7e_!!6000000005741-2-tps-2202-1256.png" alt="Masukkan nama paket Android dan nama panggilan aplikasi" />
    </Frame>
  </Step>

  <Step title="(3) Unduh file konfigurasi dan unggah ke Platform Pemaketan DingTalk">
    Klik untuk mengunduh **google-services.json**. Simpan file tersebut dan kirim ke dukungan teknis DingTalk untuk konfigurasi.

    <Frame>
      <img src="https://img.alicdn.com/imgextra/i4/O1CN01WTsNUs8mi5E4TC7e_!!6000000000771-2-tps-2202-1256.png" alt="Unduh google-services.json" />
    </Frame>
  </Step>

  <Step title="(4) Akses konsol untuk mengonfigurasikan parameter tambahan">
    Lanjutkan ke langkah terakhir dan buka konsol.

    <Frame>
      <img src="https://img.alicdn.com/imgextra/i1/O1CN01eRtdR3nUVwD4TC7e_!!6000000003035-2-tps-2202-1256.png" alt="Buka konsol" />
    </Frame>
  </Step>

  <Step title="(5) Buat kunci akun layanan">
    Navigasikan ke **Project settings > Service accounts > Generate new private key**, seperti yang ditunjukkan di bawah:

    <Frame>
      <img src="https://img.alicdn.com/imgextra/i2/O1CN01XyaTT4gI23E4JFYZ_!!6000000007143-2-tps-2123-1256.png" alt="Project settings, Service accounts, Generate new private key" />
    </Frame>

    <div style={{display: 'flex', gap: '12px', justifyContent: 'center', flexWrap: 'wrap', margin: '16px 0'}}>
      <img src="https://img.alicdn.com/imgextra/i3/O1CN01FvTOvlnxBfL4Cx4G_!!6000000003179-2-tps-2073-267.png" alt="Dialog pembuatan kunci privat" style={{width: '48%', minWidth: '280px', borderRadius: '8px', boxShadow: '0 2px 12px rgba(0,0,0,0.08)', margin: 0}} />
      <img src="https://img.alicdn.com/imgextra/i1/O1CN01flqdzTN6gyB29JDC_!!6000000000826-2-tps-1059-419.png" alt="Konfirmasi pembuatan kunci privat" style={{width: '48%', minWidth: '280px', borderRadius: '8px', boxShadow: '0 2px 12px rgba(0,0,0,0.08)', margin: 0}} />
    </div>

    Setelah mengklik **Generate key**, file JSON akan otomatis dihasilkan. Simpan file tersebut dan kirim ke dukungan teknis DingTalk:

    <Frame>
      <img src="https://img.alicdn.com/imgextra/i3/O1CN017DaIO64VsrH3mOMe_!!6000000004888-2-tps-1862-550.png" alt="File JSON kunci akun layanan yang dihasilkan" />
    </Frame>
  </Step>

  <Step title="(6) Buat Realtime Database">
    Klik **Create Database**:

    <Frame>
      <img src="https://img.alicdn.com/imgextra/i1/O1CN01y5D2kVaat7H4IUjF_!!6000000003505-2-tps-2117-1256.png" alt="Create Database" />
    </Frame>

    <div style={{display: 'flex', gap: '12px', justifyContent: 'center', flexWrap: 'wrap', margin: '16px 0'}}>
      <img src="https://img.alicdn.com/imgextra/i4/O1CN01ZY57qv4yW1D29BSA_!!6000000003377-2-tps-1058-596.png" alt="Langkah penyiapan Realtime Database" style={{width: '48%', minWidth: '280px', borderRadius: '8px', boxShadow: '0 2px 12px rgba(0,0,0,0.08)', margin: 0}} />
      <img src="https://img.alicdn.com/imgextra/i4/O1CN01LrHx3qI2SvJ2A49U_!!6000000003585-2-tps-1065-851.png" alt="Langkah aturan Realtime Database" style={{width: '48%', minWidth: '280px', borderRadius: '8px', boxShadow: '0 2px 12px rgba(0,0,0,0.08)', margin: 0}} />
    </div>

    Klik **Enable**, lalu salin URL database sebagai materi pemaketan.

    <Frame>
      <img src="https://img.alicdn.com/imgextra/i2/O1CN01kTvKb6jPuaB34xka_!!6000000005412-2-tps-1517-487.png" alt="Salin URL database" />
    </Frame>
  </Step>

  <Step title="(7) Sediakan materi di atas ke DingTalk untuk konfigurasi">
    <Check>
      - google-services.json
      - File JSON kunci akun layanan
      - URL Realtime Database
    </Check>
  </Step>

  <Step title="(8) Uji FCM melalui konsol Firebase (opsional)">
    <Note>
      **Catatan: Langkah ini opsional.**
    </Note>

    Untuk memverifikasi FCM, Anda perlu menyiapkan perangkat dengan layanan push Google (perangkat Pixel direkomendasikan). Buka konsol Firebase dan pilih **Messaging**.

    <Frame>
      <img src="https://img.alicdn.com/imgextra/i2/O1CN01ySABK2oxwGK1VHQE_!!6000000002684-2-tps-741-737.png" alt="Pilih Messaging di konsol Firebase" />
    </Frame>

    Ikuti petunjuk langkah demi langkah untuk mengirim notifikasi uji. **Penting: Uji hanya sebelum ditayangkan — hindari mengirim pesan ke semua pengguna untuk mencegah gangguan layanan.**

    <Frame>
      <img src="https://img.alicdn.com/imgextra/i2/O1CN01WiRJKFczodE4IcX8_!!6000000000978-2-tps-2118-1256.png" alt="Kirim notifikasi uji" />
    </Frame>

    Setelah dikirim, perangkat akan menerima notifikasi uji, yang menandakan bahwa penyiapan FCM berhasil:

    <Frame>
      <img src="https://img.alicdn.com/imgextra/i4/O1CN01Wq3FA9W0RQC1Xfat_!!6000000004656-2-tps-760-291.png" alt="Perangkat menerima notifikasi uji" />
    </Frame>
  </Step>
</Steps>
