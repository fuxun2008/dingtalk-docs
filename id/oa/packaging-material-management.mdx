description: "Siapkan dan kirimkan aset merek seperti logo aplikasi dan nada dering untuk ditinjau sebelum memaketkan dan mengirimkan Aplikasi DingTalk khusus."

Sebelum Aplikasi khusus dapat dipaketkan dan dikirimkan, pelanggan perlu menyiapkan serangkaian aset. Aset ini harus lolos proses peninjauan sebelum pemaketan Aplikasi khusus dapat dilanjutkan.

---

## Navigasi Konsol Admin

Di panel navigasi kiri, buka **Pengaturan organisasi > Kustomisasi Aplikasi > Pemaketan Aplikasi > Pengelolaan Materi Paket**.

## Prasyarat

### Konfirmasi nama paket

| Nama | Konten yang Disediakan | Deskripsi |
| --- | --- | --- |
| Nama paket | Android: **com.alibaba.android.rimet.xxxxxx**<br />iOS: **dd.work.exclusive4xxxxxx**<br />(xxxxxx harus berupa huruf kecil, biasanya singkatan dari nama Tionghoa Aplikasi. Disarankan 6+ karakter. Contoh: dd.work.exclusive4test) | Pengidentifikasi unik untuk Aplikasi khusus |
| Nomor D-U-N-S | **Nama entitas** yang terkait dengan akun Apple Enterprise Developer | Contoh: Alibaba Cloud Computing Ltd. |

## Unggah aset

### Unggah informasi dasar

<Steps>
  <Step title="Unggah aset">
    - Klik untuk mengunggah aset logo aplikasi.
    - Setelah berhasil diunggah, pilih tipe lencana dan pratinjau efeknya di bawah. **Catatan:** Untuk menggunakan opsi "tanpa lencana", hubungi perwakilan DingTalk Anda untuk mengajukan secara terpisah — jika tidak, opsi ini tidak akan disetujui.
    - Setelah memilih tipe lencana, klik **Terapkan ke Semua Klien** untuk menerapkan logo di semua platform klien.
    - Platform berbasis Linux saat ini memerlukan pengunggahan terpisah dan tidak dapat menggunakan fitur terapkan-ke-semua.

  <Step title="Nama aplikasi">
    Masukkan nama aplikasi sesuai konvensi penamaan:

    Pada prinsipnya, aplikasi dinamai oleh pelanggan atas kebijakannya sendiri, dengan tunduk pada persyaratan berikut:

    - Nama aplikasi tidak boleh menyertakan merek pihak ketiga mana pun (terutama milik pesaing), dan tidak boleh mencampur aksara Tionghoa dengan kata atau karakter Inggris. Jika nama aplikasi memuat merek, nama dagang, atau nama perusahaan milik pelanggan sendiri, pelanggan harus menyediakan bukti hak merek dagang.
    - Hak kekayaan intelektual atas nama dan ikon aplikasi dapat dimiliki oleh pelanggan. Pelanggan wajib mengajukan pendaftaran merek dagang untuk melindungi hak tersebut atas biayanya sendiri.

    - Nada dering peringatan pesan baru dan panggilan suara mendukung kustomisasi perusahaan — aset audio dapat diunggah secara langsung.
    - Peringatan pesan baru: unggah file .mp3 ≤1 MB dan ≤1 detik.
    - Nada dering panggilan suara: unggah file .mp3 ≤10 MB dan ≤50 detik.

### iOS

- Semua aset iOS wajib, kecuali animasi splash (opsional).
- iOS memerlukan pengunggahan terpisah untuk logo persegi. Lihat spesifikasi aset di atas untuk persyaratan format.
- Untuk pemaketan in-house, pelanggan perlu mengunggah sertifikat pemaketan dan kata sandi (opsional). Untuk pemaketan ABM/UAD, hubungi layanan pelanggan untuk bantuan.
- Setelah memastikan semua aset terisi, klik **Simpan** terlebih dahulu, lalu **Kirim untuk Ditinjau**.

### Windows / Mac

Seperti di atas, setelah pelanggan mengisi aset gambar untuk Windows dan Mac sesuai persyaratan, klik **Simpan** terlebih dahulu, lalu **Kirim untuk Ditinjau**.

## Peninjauan aset

- Informasi dasar dan aset untuk kelima platform klien dikirimkan untuk ditinjau secara terpisah. Sebelum mengirim, klik **Simpan** terlebih dahulu.
- Setelah pengiriman, baik informasi dasar maupun informasi klien terkait harus lolos peninjauan sebelum melanjutkan ke langkah berikutnya pembuatan Aplikasi.
- Jika peninjauan gagal, arahkan kursor ke pesan kegagalan untuk melihat alasannya.
