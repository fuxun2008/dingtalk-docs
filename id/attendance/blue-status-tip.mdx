polished: true

<Note>
Setelah absen selesai, jika muncul tampilan "Absen telah direkam, hasil sedang dihitung", Anda tidak perlu khawatir. Pada saat itu, catatan absen Anda telah diunggah ke server DingTalk Attendance dan hasil absen sedang dihitung, sehingga mungkin ada sedikit jeda. **Tidak perlu mengulangi absen**.
</Note>

Setelah hasil absen berhasil dihitung, Beranda dan Halaman statistik pribadi akan diperbarui secara otomatis. Silakan periksa kembali nanti.
