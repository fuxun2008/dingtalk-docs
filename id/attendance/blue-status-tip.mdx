<Note>
Setelah absen selesai, jangan khawatir jika muncul tampilan "Absen telah direkam, hasil sedang dihitung". Pada saat itu, rekaman absen Anda sudah diunggah ke server Absensi dan hasil absen sedang dihitung, sehingga mungkin terjadi sedikit latensi. **Anda tidak perlu melakukan absen ulang**.
</Note>

Setelah hasil absen berhasil dihitung, Beranda dan halaman statistik pribadi akan diperbarui secara otomatis. Silakan periksa kembali beberapa saat lagi.
