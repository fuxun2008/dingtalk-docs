  <Accordion id="q1" title="Bagaimana Admin melihat saldo cuti karyawan?">

Untuk melihat kuota cuti karyawan, Admin dapat membuka **DingTalk versi desktop > Workbench > Attendance > manajemen cuti > Saldo cuti karyawan** guna memeriksa sisa cuti karyawan. Untuk mengunduh saldo cuti karyawan, klik **Ekspor** di pojok kiri atas halaman Saldo cuti karyawan.

  <Accordion id="q2" title="Mengapa pilihan tipe cuti berkurang saat mengajukan cuti?">

Jika pilihan tipe cuti berkurang saat pengguna Organisasi mengajukan cuti, atau sebagian pengguna tidak memiliki tipe cuti tertentu, lakukan pemeriksaan berikut:

*   Admin Persetujuan telah menghapus beberapa tipe cuti, sehingga pilihan tipe cuti berkurang saat pengajuan cuti.

*   Admin Persetujuan telah menetapkan cakupan berlaku untuk tipe cuti tertentu. Karyawan yang berada di luar cakupan tersebut tidak akan melihat tipe cuti terkait saat mengajukan cuti.
