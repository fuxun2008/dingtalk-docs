Absensi DingTalk versi internasional adalah **versi Standar**, ditujukan untuk skenario absensi masuk dan pulang kerja sederhana. Versi ini mendukung penjadwalan shift dan penghitungan jam kerja bagi sebagian besar Organisasi secara gratis, dengan kemampuan inti berikut:

- Pengaturan aturan absensi
- Penjadwalan shift karyawan
- Absen karyawan via ponsel dan mesin Absensi
- Persetujuan cuti dan kehadiran
- Statistik dan laporan kehadiran
- Konfirmasi absensi

## Daftar fitur versi Standar

Tabel di bawah mencantumkan fitur yang didukung versi Standar. Beberapa kemampuan memiliki batasan pada versi Standar (dicatat pada kolom "Keterangan").

| Modul fitur | Fitur | Keterangan |
| --- | --- | --- |
| Pengaturan Dasar | Kalender kerja | Menyinkronkan hari libur nasional secara otomatis, seperti Tahun Baru dan Tahun Baru Imlek (versi Standar tidak mendukung hari libur Kustom) |
| Pengaturan Dasar | Sistem jam kerja | Mendukung sistem jam kerja Standar (versi Standar tidak mendukung sistem jam kerja komprehensif dan sistem jam kerja tidak tetap) |
| Pengaturan Dasar | Persetujuan cuti dan kehadiran | Mendukung penanganan Error absensi melalui Persetujuan pengajuan cuti, keluar kantor, perjalanan dinas, absen susulan, dll. |
| Manajemen grup absensi | Pengguna absensi | Mendukung pembuatan grup absensi secara cepat berdasarkan orang, Departemen, dll.; karyawan baru yang bergabung ke Departemen disinkronkan secara otomatis |
| Manajemen grup absensi | Waktu absensi | Mendukung absensi shift tetap, absensi berbasis shift, serta jam kerja fleksibel (cukup memenuhi durasi jam kerja) |
| Manajemen grup absensi | Metode absensi | Mendukung berbagai metode seperti absensi berbasis lokasi, absensi Wi-Fi, absensi Bluetooth, dan absensi mesin Absensi |
| Manajemen grup absensi | Aturan Asosiasi | Mendukung pengaturan aturan lembur, aturan absen susulan, absensi lapangan, serta aturan keluar kantor dan perjalanan dinas per grup absensi |
| Manajemen shift | Shift tetap | Mendukung shift tetap dengan satu kali atau beberapa kali masuk dan pulang kerja per hari |
| Manajemen shift | Shift fleksibel | Mendukung datang lebih awal pulang lebih awal, datang lebih lambat pulang lebih lambat, pulang larut boleh datang terlambat keesokan harinya, dll. |
| Manajemen shift | Aturan Error | Mendukung pengaturan Error keterlambatan dan pulang lebih awal pada titik absen shift |
| Manajemen penjadwalan shift | Penjadwalan shift per orang | Mendukung penjadwalan shift per orang |
| Manajemen penjadwalan shift | Penjadwalan shift per siklus | Mendukung pengaturan 1 atau beberapa siklus untuk penjadwalan shift berulang |
| Absen karyawan | Absen mesin Absensi | Mesin Absensi DingTalk dan akses pintu mendukung absen sidik jari dan wajah |
| Absen karyawan | Absen via ponsel | Mendukung absen dengan pelacakan GPS presisi, Wi-Fi Perusahaan, dan absen Bluetooth dengan mesin Absensi |
| Manajemen absen susulan | Jumlah absen susulan | Mendukung pengaturan jumlah absen susulan per bulan |
| Manajemen absen susulan | Tipe absen susulan | Mendukung pengaturan apakah tipe Error seperti keterlambatan, pulang lebih awal, atau absen terlewat dapat diajukan absen susulan |
| Manajemen absen susulan | Batas waktu absen susulan | Mendukung pengaturan batas waktu pengajuan absen susulan |
| Manajemen lembur | Tipe lembur | Mendukung pengaturan aturan lembur hari kerja, hari libur, dan hari libur nasional secara independen |
| Manajemen lembur | Periode lembur | Mendukung pengaturan apakah lembur sebelum dan sesudah shift dihitung |
| Manajemen lembur | Metode perhitungan durasi lembur | Mendukung penghitungan berdasarkan durasi absen, durasi Persetujuan, atau durasi absen dalam periode Persetujuan |
| Manajemen lembur | Pembulatan durasi lembur | Versi Standar hanya mendukung pembulatan ke bawah |
| Manajemen lembur | Pengurangan waktu istirahat | Mendukung pengurangan berdasarkan periode waktu atau berdasarkan durasi lembur |
| Manajemen lembur | Kompensasi lembur | Mendukung konversi menjadi upah lembur atau cuti pengganti, atau dipilih sendiri oleh karyawan |
| Manajemen lembur | Peringatan risiko | Mendukung pengaturan kuota peringatan lembur harian, mingguan, dan Bulanan |
| Manajemen cuti | Pemberian cuti manual | Mendukung pemberian saldo cuti secara manual |
| Manajemen cuti | Pemberian cuti berkala | Mendukung pemberian saldo cuti Tahunan atau Bulanan sesuai aturan |
| Manajemen cuti | Konversi lembur ke cuti pengganti | Mendukung konversi otomatis menjadi cuti pengganti berdasarkan durasi lembur |
| Statistik kehadiran | Lihat statistik Tim per hari, minggu, atau bulan | Mendukung tampilan real-time rekam kehadiran dan hasil karyawan |
| Statistik kehadiran | Lihat statistik karyawan per hari, minggu, atau bulan | Mendukung karyawan melihat rekam dan hasil absensi secara mandiri |
| Laporan absensi | Rekam absen asli | Mendukung rekam absen asli, waktu absen, dan rekam dugaan kecurangan |
| Laporan absensi | Laporan statistik ringkasan | Mendukung Ekspor laporan ringkasan per hari atau bulan |
| Laporan absensi | Ubah hasil absensi | Mendukung Admin mengubah hasil absensi satu per satu atau secara massal |
| Laporan absensi | Konfirmasi absensi | Mendukung Kirim konfirmasi absensi agar karyawan segera mengonfirmasi data kehadiran |
