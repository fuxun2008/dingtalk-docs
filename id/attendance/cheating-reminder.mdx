"Notifikasi real-time kecurangan absen karyawan" merupakan fitur versi peningkatan dari Keamanan Absensi. Setelah membeli versi peningkatan dan mengaktifkan fitur ini, setiap kali karyawan melakukan kecurangan saat absen, Admin akan menerima Notifikasi pesan secara real-time di DingTalk, **maksimal tiga kali per hari**. Rekaman kecurangan lengkap dapat dilihat di "Absensi → Statistik → Anti-kecurangan → Daftar absen pelanggaran".

## Pengaturan aktivasi

<Info>
Jalur aktivasi: **Absensi → Statistik → Anti-kecurangan → Notifikasi real-time kecurangan absen karyawan**
</Info>
