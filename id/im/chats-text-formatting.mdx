Format teks kaya membuat pesan panjang lebih mudah dibaca. Gunakan saat Anda perlu berbagi pembaruan, merangkum pekerjaan, atau mengirim daftar langkah berikutnya.

Pesan berformat sangat membantu di obrolan grup, saat pembaca perlu memindai informasi dengan cepat.

## Buka toolbar format

1.  Buka sebuah percakapan.
    
2.  Klik **Aa** di kolom penulisan pesan.
    

![](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/4EZlweZLRE8ZBqxA/img/2b840945-1002-45b3-a147-e5caa2988988.png)

Toolbar teks kaya muncul di atas kotak input.

## Opsi format

| Opsi | Gunakan untuk |
| --- | --- |
| **Body** | Memilih gaya teks. |
| **Tebal** | Menekankan kata penting. |
| **Warna Teks** | Menyorot teks yang dipilih. |
| **Miring** | Menambahkan penekanan ringan. |
| **Coret** | Menandai teks yang tidak lagi berlaku. |
| **Daftar Berpoin** | Membuat daftar tanpa urutan. |
| **Daftar Bernomor** | Membuat daftar berurutan. |
| **Tautan** | Menambahkan hyperlink. |
| **Hapus Format** | Menghapus format dari teks yang dipilih. |

![](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/4EZlweZLRE8ZBqxA/img/59c00527-28a6-476a-93da-32d0d1fa8a56.png)

## Kirim pesan berformat

1.  Klik **Aa**.
    
2.  Ketik pesan Anda.
    
3.  Pilih teks yang ingin Anda format.
    
4.  Pilih opsi format dari toolbar.
    
5.  Klik **Kirim**.
    

## Tips format

*   Gunakan **Tebal** untuk poin penting atau tenggat waktu.
    
*   Gunakan daftar untuk item tindakan atau pembaruan status.
    
*   Gunakan **Tautan** saat ingin menyertakan referensi tanpa menempelkan URL panjang ke dalam pesan.
    
*   Gunakan **Hapus Format** jika teks yang disalin membawa gaya yang tidak diinginkan.
