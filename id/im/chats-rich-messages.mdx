Komposer pesan menyediakan pintasan untuk mengirim file dan memulai pekerjaan terkait langsung dari percakapan. Gunakan pintasan ini saat Anda ingin membagikan materi, membuat acara, menambahkan cuplikan kode, atau membuka alat lain tanpa keluar dari obrolan.

Pintasan komposer membantu Anda mengubah percakapan menjadi tindakan tanpa perlu beralih ke modul lain terlebih dahulu.

## Kirim file dari percakapan

1.  Buka percakapan.
    
2.  Klik ikon unggah di komposer pesan.
    
![](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/1wvqrebRvbV2vnak/img/fee3274d-e5b5-4885-818e-21105d5524ec.png)
    
3.  Pilih salah satu opsi berikut:
    
    *   **Unggah File**
        
    *   **Unggah Folder**
        
    *   **Kirim File di DingTalk Drive**
        
    *   **Kirim DingTalk Docs**
        
    
![](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/NpQlK5jwr84wLqDv/img/59c794bc-1196-4da9-bdf1-8edc4e188d79.png)
    
4.  Selesaikan pemilihan file atau dokumen.
    

Gunakan **Unggah File** untuk file lokal di komputer Anda. Gunakan **Unggah Folder** saat Anda perlu mengirim seluruh folder. Gunakan **Kirim File di DingTalk Drive** atau **Kirim DingTalk Docs** saat materi sudah tersimpan di DingTalk.

Gambar dan video di komputer Anda dapat dikirim sebagai file lokal melalui **Unggah File**.

## Buka pintasan komposer

1.  Buka percakapan.
    
2.  Klik **+** di komposer pesan.
    
3.  Pilih pintasan yang ingin Anda gunakan.
    

Menu ini mencakup **Kontak**, **Cuplikan kode**, **Dokumentasi DingTalk**, **Acara Baru**, **Konferensi Video**, dan **Email**.

## Contoh pintasan

| Pintasan | Gunakan saat |
| --- | --- |
| **Kontak** | Anda perlu membagikan atau memilih kontak dari percakapan. |
| **Cuplikan kode** | Anda ingin mengirim kode dalam format terstruktur. |
| **Dokumentasi DingTalk** | Anda ingin mengelola dokumentasi DingTalk dari obrolan. |
| **Acara Baru** | Anda ingin membuat acara yang terkait dengan diskusi. |
| **Konferensi Video** | Anda ingin memindahkan percakapan ke rapat langsung. |
| **Email** | Anda ingin memulai alur terkait email dari percakapan. |

## Telusuri file dalam percakapan

Buka percakapan dan klik ikon file/folder di sudut kanan atas.

Tindakan ini akan membuka file yang dibagikan dalam percakapan, sehingga Anda dapat menemukan materi bersama tanpa menggulir riwayat pesan.

Gunakan tampilan file saat Anda perlu menemukan materi bersama tanpa mencari melalui pesan obrolan.
