Pemilik dan admin grup dapat membuka **Kelola Grup** untuk mengelola kontrol grup lanjutan.

## Membuka Kelola Grup

1.  Buka obrolan grup.
    
2.  Klik ikon roda gigi di sudut kanan atas.
    
3.  Pilih **Kelola Grup**.

## Pengaturan lanjutan yang tersedia

Kelola Grup mencakup pengaturan untuk admin, kontrol bisukan, izin anggota, izin bergabung, alat grup, dan fitur terkait grup.

| Pengaturan | Kegunaan |
| --- | --- |
| **Admin** / **Tambah** | Menambahkan admin grup. |
| **Pengaturan Bisukan** | Membuka kontrol terkait Bisukan. |
| **Pengaturan izin grup** | Mengontrol siapa yang dapat menggunakan fitur grup tertentu. |
| **Batang Cepat Grup** | Mengelola batang cepat grup. |
| **Izin bergabung grup** | Mengelola cara anggota baru bergabung. |
| **Berapa lama anggota baru dapat melihat riwayat obrolan** | Mengelola seberapa banyak riwayat sebelumnya yang dapat dilihat anggota baru. |
| **Kalender Grup** | Membuka pengaturan kalender grup. |
| **Grup dapat menerima email** | Mengelola apakah grup dapat menerima email. |
| **Aktifkan sinkronisasi otomatis ke Drive** | Mengelola sinkronisasi otomatis ke Drive. |
| **Nonaktifkan Obrolan Pribadi** | Mengelola akses obrolan pribadi dari grup. |
| **Alihkan Kepemilikan Grup** | Mengalihkan kepemilikan ke anggota lain. |

## Pengaturan izin grup

Buka **Pengaturan izin grup** saat Anda perlu mengontrol siapa yang dapat menggunakan fitur grup tertentu.

Entri izin yang tersedia meliputi:

*   **Siapa yang dapat me-@ Semua Orang**
    
*   **Siapa yang dapat mengirim DING di grup**
    
*   **Siapa yang dapat menaruh pesan grup di paling atas**
    
*   **Siapa yang dapat menyematkan berita grup**
    
*   **Siapa yang dapat mengunggah file, folder, dan file Drive?**
    
*   **Siapa yang dapat memulai rapat video dan suara di grup**
