Gunakan **Pengaturan grup** untuk mengelola informasi grup, preferensi pribadi Anda, dan kontrol tingkat grup.

Untuk membuka Pengaturan grup, buka sebuah Obrolan Grup lalu klik ikon roda gigi di sudut kanan atas.

![](https://img.alicdn.com/imgextra/i4/O1CN01kma392VuadL4N9W8_!!6000000001089-2-tps-2154-1322.png)

## Informasi grup

Gunakan bagian informasi grup untuk mengelola detail dasar grup.

| Pengaturan | Fungsinya |
| --- | --- |
| **Nama** | Lihat atau edit nama grup. |
| **Pengumuman** | Buka pengumuman grup. |
| **Undangan Grup** | Buka opsi undangan grup. |

![](https://img.alicdn.com/imgextra/i4/O1CN01J8XsR3h8ZaF4N9W8_!!6000000000760-2-tps-2154-1322.png)

## Pengaturan grup pribadi

Pengaturan ini hanya memengaruhi pengalaman Anda sendiri di dalam grup.

| Pengaturan | Fungsinya |
| --- | --- |
| **Nama Panggilan Saya di Grup** | Tetapkan nama tampilan Anda di grup ini. |
| **Alias Grup** | Tetapkan alias lokal Anda untuk grup. |
| **Sematkan ke Atas** | Pertahankan grup di dekat bagian atas daftar obrolan Anda. |
| **Bisukan Notifikasi** | Bisukan notifikasi untuk grup ini. |

## Kelola Grup

Buka **Kelola Grup** saat Anda perlu mengelola admin, izin, aturan bergabung, atau fitur tingkat grup.

| Pengaturan | Fungsinya |
| --- | --- |
| **Admin** / **Tambah** | Tambahkan admin grup. |
| **Pengaturan Bisukan** | Buka pengaturan bisukan grup. |
| **Pengaturan izin grup** | Kontrol izin anggota untuk fitur grup. |
| **Batang Cepat Grup** | Konfigurasikan batang cepat grup. |
| **Izin bergabung grup** | Konfigurasikan cara anggota baru dapat bergabung. |
| **Berapa lama anggota baru dapat melihat riwayat obrolan** | Konfigurasikan seberapa banyak riwayat sebelumnya yang dapat dilihat anggota baru. |
| **Kalender Grup** | Buka pengaturan kalender grup. |
| **Grup dapat menerima email** | Konfigurasikan apakah grup dapat menerima email. |
| **Aktifkan sinkronisasi otomatis ke Drive** | Sinkronkan file grup ke Drive. |
| **Nonaktifkan Obrolan Pribadi** | Nonaktifkan entri obrolan pribadi dari grup. |
| **Alihkan Kepemilikan Grup** | Alihkan kepemilikan ke anggota lain. |

## Hapus pesan atau keluar dari grup

*   Untuk menghapus pesan lokal, buka Pengaturan grup > **Hapus Pesan**.
    
*   Untuk keluar dari grup, buka Pengaturan grup > **Keluar**.
