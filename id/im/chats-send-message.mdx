Gunakan penulis pesan untuk menulis, memformat, dan mengirim pesan dalam pesan langsung atau obrolan grup.

## Mengirim pesan teks

1.  Buka sebuah percakapan.
    
2.  Ketik pesan di kotak input.
    
3.  Tekan **Enter** atau klik **Kirim**.
    

Untuk menambahkan baris baru tanpa mengirim pesan, tekan **Shift + Enter**.

![](https://img.alicdn.com/imgextra/i3/O1CN01KXJFA01fr4H4N9W8_!!6000000003263-2-tps-2154-1322.png)

## Memformat pesan

Klik **Aa** pada penulis pesan untuk membuka bilah alat teks kaya.

Tersedia opsi pemformatan seperti **Body**, **Tebal**, **Warna Teks**, **Miring**, **Coret**, **Daftar Berpoin**, **Daftar Bernomor**, **Tautan**, dan **Hapus Format**.

Gunakan teks kaya untuk mengirim pembaruan terstruktur, daftar item tindakan, atau pesan yang perlu ditonjolkan.

![](https://img.alicdn.com/imgextra/i2/O1CN01jdOg1HvUt9D4N9W8_!!6000000002847-2-tps-2154-1322.png)

## Mengirim file atau dokumen

1.  Buka sebuah percakapan.
    
2.  Klik ikon unggah pada penulis pesan.
    
3.  Pilih **Unggah File**, **Unggah Folder**, **Kirim File di DingTalk Drive**, atau **Kirim DingTalk Docs**.
    
4.  Selesaikan pemilihan.
    

Gunakan menu ini untuk mengirim file lokal, folder, file dari DingTalk Drive, atau DingTalk Doc.

![](https://img.alicdn.com/imgextra/i4/O1CN01TuVrf8c5nNC4N9W8_!!6000000003339-2-tps-2154-1322.png)

## Mengirim tanpa suara atau mengunci pengiriman

1.  Ketik pesan Anda.
    
2.  Klik panah dropdown di samping **Kirim**.
    
3.  Pilih **Set silent** atau **Lock Send**.
    

Gunakan **Set silent** untuk mengirim pesan tanpa mengganggu orang lain. Gunakan **Lock Send** untuk mengirim dengan perlindungan tambahan.

![](https://img.alicdn.com/imgextra/i4/O1CN01XLmcoSUEjbI4N9W8_!!6000000000481-2-tps-2154-1322.png)

## Menggunakan pintasan penulis pesan

Klik **+** pada penulis pesan untuk membuka pintasan.

Menu ini mencakup:

*   **Kontak**
    
*   **Cuplikan kode**
    
*   **Dokumentasi DingTalk**
    
*   **Acara Baru**
    
*   **Konferensi Video**
    
*   **Email**
    

Gunakan pintasan ini untuk membuat pekerjaan terkait langsung dari percakapan.
