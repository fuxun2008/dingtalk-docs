Gunakan tindakan pesan dan percakapan untuk meninjau detail pesan atau mengatur cara suatu percakapan ditampilkan di **Messages**.

Tindakan yang tersedia bergantung pada tempat Anda membuka menu. Tindakan pesan berlaku untuk pesan tertentu dalam percakapan yang terbuka. Tindakan percakapan berlaku untuk daftar percakapan.

## Membuka tindakan pesan

1.  Buka **Messages**.
    
2.  Buka sebuah percakapan.
    
3.  Klik kanan pesan yang ingin Anda kelola.
    
4.  Pilih tindakan dari menu.
    

## Tindakan pesan

| Tindakan | Fungsinya |
| --- | --- |
| **Copy** | Menyalin isi pesan. |
| **Forward** | Membuka alur penerusan untuk pesan. |
| **Reply** | Memulai balasan atas pesan. |
| **Recall** | Menarik kembali pesan yang Anda kirim selama fitur tarik kembali masih tersedia. |
| **Re-edit** | Mengembalikan isi pesan ke kolom penulisan agar Anda dapat mengedit dan mengirimnya kembali. |
| **Multi-Choose** | Memilih beberapa pesan sekaligus untuk tindakan massal. |
| **More** | Membuka tindakan pesan tambahan bila tersedia. |

![](https://img.alicdn.com/imgextra/i3/O1CN01W0kPbZSFCAL4N9W8_!!6000000003419-2-tps-2154-1322.png)

Tindakan yang tersedia dapat berbeda menurut tipe pesan, pengirim, tipe percakapan, dan berapa lama pesan telah dikirim.

## Melihat riwayat edit pesan

Sebagian pesan juga menyertakan tombol tindakan di sisi pesan untuk riwayat edit.

1.  Buka **Messages**.
    
2.  Buka sebuah percakapan.
    
3.  Pindahkan ke pesan yang ingin Anda periksa.
    
4.  Klik tombol tindakan pesan di samping pesan.
    
5.  Pilih **Message Edit History**.
    

![](https://img.alicdn.com/imgextra/i4/O1CN01nrKkFTMe4uD4N9W8_!!6000000007502-2-tps-2154-1322.png)

Panel **Message Edit History** akan terbuka di sisi kanan percakapan.

Gunakan fitur ini saat Anda perlu memeriksa apakah suatu pesan telah diedit.

## Mengelola percakapan dari daftar percakapan

1.  Buka **Messages**.
    
2.  Cari percakapan yang ingin Anda kelola.
    
3.  Klik kanan percakapan tersebut.
    
4.  Pilih tindakan dari menu.
    

## Tindakan daftar percakapan

| Tindakan | Fungsinya |
| --- | --- |
| **Set-top session** | Menjaga percakapan tetap berada di dekat bagian atas daftar. |
| **Mark as unread** | Menandai percakapan sebagai belum dibaca. |
| **Message Do Not Disturb** | Membisukan notifikasi untuk percakapan. |
| **Do not display this session** | Menyembunyikan percakapan dari daftar. |
| **Personal Information** | Membuka profil atau informasi percakapan. |
| **Empty chat history** | Menghapus riwayat obrolan lokal untuk percakapan. |

Tindakan ini memengaruhi cara percakapan ditampilkan untuk Anda di aplikasi desktop DingTalk.

## Cara umum menggunakan tindakan percakapan

*   Gunakan **Set-top session** untuk percakapan yang sering Anda periksa.
    
*   Gunakan **Mark as unread** saat Anda perlu kembali ke suatu percakapan nanti.
    
*   Gunakan **Message Do Not Disturb** untuk percakapan yang tetap perlu dapat diakses tetapi tidak boleh mengganggu Anda.
    
*   Gunakan **Do not display this session** untuk menghapus percakapan dari daftar Anda tanpa menghapus riwayat lokalnya.
