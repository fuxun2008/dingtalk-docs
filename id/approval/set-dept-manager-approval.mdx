## 1. Panduan operasional

<Note>
Admin dapat menetapkan manajer departemen sebagai pemberi persetujuan.

Manajer departemen mengacu pada manajer yang telah diatur di dalam Kontak.

Jika manajer departemen ditetapkan sebagai pemberi persetujuan, ketika terjadi perubahan manajer di suatu departemen, cukup sesuaikan proses manajer departemen agar alur tetap berjalan normal.

Perubahan manajer departemen berlaku untuk Persetujuan yang sudah diajukan tetapi belum mengalir ke node saat ini, serta untuk pengaturan proses pada templat persetujuan.
</Note>

## 2. Prasyarat operasi

*   Hanya Admin Persetujuan yang dapat melakukan desain proses, sehingga Anda perlu menjadi Admin Persetujuan terlebih dahulu.

Untuk Pengguna non-Admin Persetujuan, buka DingTalk Persetujuan OA, klik [Pengaturan], klik [Buat Formulir persetujuan], klik [Ajukan izin Admin], lalu klik "Kirim".

Setelah Admin menerima pengingat Persetujuan yang tertunda dan menyetujuinya, Karyawan terkait akan otomatis memperoleh izin Admin Persetujuan.

## 3. Langkah-langkah operasi

### 1. Atur manajer departemen

Admin membuka [DingTalk Admin Console](https://oa.dingtalk.io) di browser untuk masuk ke Admin Console, lalu klik "Kelola Kontak" untuk membuka halaman kelola Kontak internal.

Setelah menambahkan departemen, klik "..." di sebelah nama Departemen, klik Atur manajer departemen, Pilih Pengguna yang muncul dari Kontak, lalu klik "Konfirmasi" hingga pengaturan Berhasil dilakukan.

Perlu diperhatikan: manajer departemen harus berada di dalam Departemen yang bersangkutan.

#### 2. Tetapkan manajer departemen sebagai pemberi persetujuan dalam proses persetujuan

Di Halaman **"Admin Console Persetujuan"** - **"Kelola Formulir"**, klik [**Edit**] pada kolom Tindakan Formulir.

Klik [**Desain proses**] untuk membuka antarmuka utama desain proses.

Untuk pemberi persetujuan pada node, Pilih "Manajer departemen". Anda dapat memilih tingkatan manajer departemen ke atas dari pengaju, dengan dukungan maksimal hingga tingkat ke-8.
