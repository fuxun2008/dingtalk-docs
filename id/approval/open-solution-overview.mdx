## 1. Ringkasan skema

Melalui kemampuan buka Persetujuan OA DingTalk, tersedia **empat** skema untuk mengintegrasikan sistem bisnis organisasi ke Persetujuan OA DingTalk. Skema ini memungkinkan pengajuan persetujuan dari sistem bisnis, pemrosesan persetujuan di dalam DingTalk, serta terhubung mulus dengan fitur komunikasi, tugas, dan notifikasi DingTalk. Hasilnya adalah persetujuan terpusat dan kolaborasi efisien untuk berbagai proses bisnis organisasi.

Nilai utama buka Pusat Proses Persetujuan OA DingTalk: manajemen terpusat, pengalaman terpadu, dan kolaborasi efisien.

## 2. Empat cara integrasi

Persetujuan OA DingTalk menyediakan empat skema integrasi proses organisasi untuk memenuhi beragam kebutuhan manajemen bisnis:

<Frame>

![Diagram kartu empat skema integrasi proses: proses & halaman Persetujuan OA DingTalk, proses & halaman pihak ketiga, proses pihak ketiga & halaman Persetujuan OA DingTalk, serta aplikasi kustom yang terintegrasi dengan Persetujuan OA DingTalk](https://img.alicdn.com/imgextra/i1/O1CN01xDI8xQQHp9G1wqha_!!6000000001852-2-tps-960-990.png)
</Frame>

| Cara integrasi | Deskripsi skema | Karakteristik & nilai skema | Skema integrasi |
| --- | --- | --- | --- |
| 1. Proses pihak ketiga + halaman<br />(dibuka di dalam DingTalk) | Ajukan proses di sistem bisnis, panggil API DingTalk untuk membuat proses Persetujuan OA DingTalk, lalu buka halaman detail persetujuan sistem bisnis di dalam DingTalk untuk pemrosesan | **Lebih ringan**<br />1. Integrasi sederhana; halaman sistem bisnis langsung dibuka di dalam DingTalk untuk persetujuan<br />2. Hanya mendukung tindakan dasar seperti terima dan tolak, tanpa tindakan terhubung DingTalk seperti buat grup obrolan<br />3. Mempertahankan kebiasaan pengguna terhadap proses dan halaman lama, adopsi cepat dengan biaya rendah | [Integrasi dengan proses dan halaman pihak ketiga](/id/approval/open-third-party-process) |
| 2. Proses & halaman Persetujuan OA DingTalk | Ajukan proses di sistem bisnis, panggil API DingTalk untuk membuat proses Persetujuan OA DingTalk, lalu buka halaman detail persetujuan DingTalk di dalam DingTalk untuk pemrosesan | **Lebih standar**<br />1. Integrasi terstandardisasi; gunakan kemampuan proses dan halaman OA DingTalk, terhubung mulus dengan obrolan, tugas, dan notifikasi DingTalk untuk persetujuan efisien | [Integrasi dengan proses dan halaman Persetujuan OA DingTalk](/id/approval/open-dingtalk-process) |
| 3. Proses pihak ketiga + halaman Persetujuan OA DingTalk (eksklusif DingTalk Smart OA) | Ajukan proses di sistem bisnis, panggil API DingTalk untuk merender halaman Persetujuan OA DingTalk dengan proses pihak ketiga, lalu buka halaman detail Persetujuan OA DingTalk di dalam DingTalk untuk pemrosesan | **Lebih fleksibel**<br />1. Integrasi fleksibel; menyeragamkan struktur dan tampilan formulir persetujuan dari berbagai sistem bisnis, memberikan pengalaman konsisten lintas perangkat (seluler/PC/tablet)<br />2. Tombol area tindakan persetujuan dapat dikustomisasi: terima, tolak, alihkan, cetak, dan lainnya | Segera hadir |
| 4. Aplikasi kustom organisasi terintegrasi dengan Persetujuan OA DingTalk (eksklusif DingTalk Smart OA) | Melalui API buka Persetujuan OA DingTalk, aplikasi kustom organisasi dapat memproses proses aplikasi bisnis dan proses sisi DingTalk secara terpadu dan massal di dalam aplikasi kustom | **Lebih dapat dikustomisasi**<br />1. Integrasi terkustomisasi; organisasi dapat mengustomisasi halaman dan logika fitur sesuai kebutuhan bisnis | Segera hadir |
