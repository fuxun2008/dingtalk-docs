## 1. Pengenalan fitur

Panduan ini membantu admin perusahaan atau developer mengintegrasikan **proses persetujuan dan halaman pada sistem Persetujuan OA DingTalk** dengan **sistem bisnis pihak ketiga (seperti ERP, CRM, dan sistem keuangan)**, guna mewujudkan pintu masuk terpadu, pertukaran data, dan keterhubungan proses. Melalui integrasi ini, Anda dapat meningkatkan tingkat otomatisasi perkantoran, menghindari input berulang, serta memperbaiki efisiensi kolaborasi lintas sistem.

## 2. Skenario penggunaan

Mulai proses dari sistem bisnis, panggil API resmi Persetujuan OA DingTalk untuk membuat proses Persetujuan OA DingTalk, lalu buka halaman detail persetujuan DingTalk di sisi DingTalk untuk memproses alurnya.

## 6. API yang digunakan

### 1. Formulir persetujuan

| API | Deskripsi | Spesifikasi versi baru (Server API versi baru) |
| --- | --- | --- |
