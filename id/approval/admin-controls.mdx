## 1. Detail kontrol formulir

Formulir persetujuan terdiri dari berbagai jenis kontrol yang dikelompokkan menjadi tiga kategori:

| Kategori kontrol | Kontrol yang termasuk |
| --- | --- |
| Kontrol tata letak | Kolom |
| Kontrol dasar | Bidang input satu baris, bidang input multi-baris, bidang input angka, kotak pilihan tunggal, kotak pilihan ganda, tanggal, rentang tanggal, teks deskripsi, KTP, telepon |
| Kontrol lanjutan | Kaskade/kategori, gambar, rincian/tabel, jumlah uang, lampiran, tanda tangan, kontak, departemen, lokasi saat ini, formula perhitungan, formulir persetujuan terkait, provinsi/kota/distrik, peringkat |

### 1) Kontrol tata letak

Kolom digunakan untuk mengoptimalkan efisiensi tampilan informasi pada desktop dengan membagi bidang formulir menjadi beberapa kolom yang ditampilkan berdampingan.

<Note>
Efek kolom hanya berlaku pada **desktop**; pada ponsel tetap ditampilkan dalam satu kolom. Kontrol ini tidak melibatkan pengaturan atribut, batasan data, atau pencarian.
</Note>

### 2) Kontrol dasar

Kontrol dasar berbagi item pengaturan umum berikut:

| Item pengaturan umum | Deskripsi detail |
| --- | --- |
| Judul | Judul yang ditampilkan pada formulir, maksimal 50 karakter |
| Teks tips | Teks tips abu-abu yang ditampilkan pada bidang input formulir saat belum diisi, maksimal 50 karakter |
| Default | Konten default yang ditampilkan pada bidang input formulir saat belum diisi; jika izin langkah adalah "Dapat diedit", konten bidang yang terkait dengan kontrol dapat dimodifikasi |
| Pengaturan wajib | Nonaktif secara default; setelah diaktifkan, saat mengirim formulir sistem akan memeriksa apakah bidang yang terkait sudah diisi. Jika belum diisi, formulir tidak dapat dikirim |
| Pengaturan cetak | Aktif secara default; setelah dinonaktifkan, bidang yang terkait dengan kontrol tidak akan muncul di PDF detail formulir yang diunduh atau dicetak |
