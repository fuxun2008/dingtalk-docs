## 1. Pengenalan produk

Persetujuan OA DingTalk adalah aplikasi resmi DingTalk yang menyediakan produk Persetujuan OA siap pakai. Melalui pengaturan sederhana, Anda dapat memenuhi kebutuhan persetujuan harian organisasi secara fleksibel, meningkatkan efisiensi manajemen tim dan bisnis, membantu organisasi menerapkan berbagai standar manajemen, serta mengurangi risiko operasional perusahaan.

## 2. Petunjuk penggunaan

### 2.1 Menjadi admin persetujuan

Super Admin DingTalk secara default memiliki seluruh izin operasi persetujuan. Non-Super Admin yang ingin memperoleh izin untuk mengedit formulir, membuat formulir baru, mengekspor seluruh data, dan lainnya perlu memperoleh izin operasi Sub Admin persetujuan terlebih dahulu. Ada dua cara untuk menjadi Sub Admin persetujuan:

#### 1. Super Admin menetapkan Sub Admin persetujuan

##### 1.1 Melalui ponsel

Buka Kontak, temukan organisasi Anda, ketuk "Kelola" untuk masuk ke halaman manajemen organisasi, ketuk "Pengaturan Admin" → ketuk "Atur Sub Admin".

##### 3.2 Pengaturan formulir

Atur konten formulir persetujuan, yaitu konten yang dapat dilihat dan perlu diisi saat mengajukan persetujuan.

1) Pustaka widget yang dapat ditambahkan

Mencakup berbagai widget seperti pilihan, angka, teks, dan tanggal. Klik atau seret widget di bilah kiri untuk menambahkannya ke formulir. Tekan lama dan seret widget untuk mengatur urutan secara bebas.

<Frame>

![image.png](https://img.alicdn.com/imgextra/i1/O1CN013AS6p7GKdkK5bwRq_!!6000000007809-2-tps-2764-1730.png)
</Frame>

2) Grup widget yang dapat ditambahkan

Persetujuan DingTalk juga menyediakan **grup widget absensi/HR seperti pengajuan cuti, lembur, rekrutmen, dan resign; grup widget keuangan seperti reimbursement dan pembayaran; grup widget hukum seperti kontrak dan penggunaan stempel**. Grup widget ini terhubung dengan sistem Absensi/HR Cerdas/Keuangan Cerdas/Kontrak Cerdas, sehingga saat menggunakan persetujuan dengan grup widget, data absensi, rekrutmen/resign, reimbursement/pembayaran, dan kontrak/stempel karyawan otomatis tersinkron ke sistem terkait.

Anda dapat **mengklik** atau **menyeret** grup widget yang dibutuhkan untuk menambahkannya, lalu mengatur grup widget di panel kanan. **Satu formulir hanya dapat menambahkan satu grup widget**.

3) Pengaturan dasar

Pengaturan dasar umumnya mencakup: judul widget, teks petunjuk, aturan widget (misalnya pengaturan opsi widget pilihan tunggal, pengaturan tipe widget tanggal), serta pengaturan apakah widget dicetak dan apakah wajib diisi.

| Antarmuka operasi | **Item pengaturan umum** | **Keterangan detail** |
| --- | --- | --- |
| Judul | Judul yang ditampilkan di formulir, maksimal 50 karakter |
| Teks petunjuk | Teks petunjuk abu-abu yang ditampilkan di kotak input formulir saat belum diisi, maksimal 50 karakter |
| Default | Konten default yang ditampilkan di kotak input formulir saat belum diisi. Saat izin langkah "dapat diedit", mendukung modifikasi konten bidang widget ini |
| Pengaturan Wajib | Default nonaktif; jika aktif, saat mengajukan formulir akan memvalidasi apakah bidang widget diisi dan tidak diizinkan mengajukan bila belum diisi |
| Pengaturan cetak | Default aktif; jika dinonaktifkan, bidang widget ini tidak akan muncul di PDF detail formulir yang diunduh atau dicetak |
