## 1. Ringkasan fitur

Untuk memenuhi kebutuhan developer dalam membangun aplikasi yang dipersonalisasi, mulai 1 September 2024 Persetujuan OA DingTalk secara bertahap merilis sejumlah OpenAPI eksklusif bagi pelanggan Smart OA. OpenAPI eksklusif ini menyediakan kapabilitas yang lebih kaya, menjawab kebutuhan bisnis yang lebih personal, dan mendukung pengembangan Aplikasi internal untuk berbagai skenario. Kami menyarankan developer memanfaatkan OpenAPI secara lebih tepat dan efektif untuk membangun ekosistem terbuka DingTalk yang lebih sehat.

## 2. Skenario penggunaan

<Note>
DingTalk dapat menambah, mengubah, atau menghapus cakupan maupun fungsi spesifik dari API berikut karena penyesuaian peraturan atau kebijakan, kepatuhan terhadap instruksi regulator, atau untuk menjaga keamanan layanan DingTalk. Cakupan API yang benar-benar terbuka bagi pelanggan mengacu pada informasi yang dipublikasikan di DingTalk Open Platform pada saat itu.
</Note>

### 3. Integrasi pusat proses (Grup bisnis Kustom)

### 4. Integrasi pusat proses (mode hosting Halaman persetujuan)

## 3. Langkah pengoperasian

Untuk OpenAPI eksklusif di atas, pelanggan versi Standar perlu **melakukan upgrade ke Smart OA** sebelum dapat mengajukan penggunaannya. Sebagian pelanggan yang telah berpartisipasi dalam beta publik sebelum 1 September 2024 telah memperoleh Izin memanggil OpenAPI ini. Silakan panggil sesuai aturan berikut:

| Tipe pelanggan | Berpartisipasi dalam beta publik | Terdampak? |
| --- | --- | --- |
| Pelanggan Smart OA | Sudah berpartisipasi | Tidak terdampak, tetap dapat memanggil secara normal |
| Pelanggan Smart OA | Belum berpartisipasi | Dapat memanggil setelah mengajukan Izin penggunaan API |
| Pelanggan versi Standar | Sudah berpartisipasi | Tidak dapat memanggil, perlu upgrade ke Smart OA lalu mengajukan Izin panggilan API untuk melanjutkan pemanggilan; langkah pengajuan Izin dapat merujuk pada penjelasan di bawah |
| Pelanggan versi Standar | Belum berpartisipasi | Tidak dapat memanggil, perlu upgrade ke Smart OA lalu mengajukan Izin panggilan API untuk dapat memanggil; langkah pengajuan Izin dapat merujuk pada penjelasan di bawah |

Jalur pengajuan Izin: **Developer Backend** > Pengembangan aplikasi > Aplikasi DingTalk > Buat aplikasi baru atau pilih aplikasi yang sudah ada > klik aplikasi > [Kelola izin] > [Persetujuan OA], lalu pilih Izin yang ingin diajukan:

## 4. FAQ

<AccordionGroup>
  <Accordion title="Apa aturan penagihan OpenAPI eksklusif?">

Pelanggan DingTalk versi Standar tidak dapat menggunakan OpenAPI eksklusif Smart OA. Anda perlu **upgrade ke Smart OA** terlebih dahulu sebelum dapat memanggil API ini. Penggunaan OpenAPI eksklusif akan mengurangi kuota OpenAPI Smart OA.

  </Accordion>
  <Accordion title="Apakah pelanggan versi Standar dapat melihat OpenAPI eksklusif ini?">

Mulai 1 September 2024, developer dapat melihat OpenAPI eksklusif yang telah dirilis pada dokumen developer Open Platform dan di **Developer Backend**.

  </Accordion>
</AccordionGroup>
