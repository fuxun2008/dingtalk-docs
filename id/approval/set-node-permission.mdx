## 1. Deskripsi

<Note>
Admin dapat mengatur izin tindakan node.

Izin tindakan node default: pengaju dapat mengedit; pemberi persetujuan, penerima CC, dan pelaksana hanya baca.

Dalam skenario tertentu, izin tindakan node perlu disesuaikan.

Misalnya, untuk penilaian gaji atau jenjang jabatan, sebagian informasi hanya boleh dilihat oleh pemberi persetujuan tertentu. Dalam kasus ini, bidang tertentu perlu disembunyikan dari orang tertentu.

Dalam skenario lain, misalnya peringkat proyek, sebagian informasi diisi oleh pemberi persetujuan, bukan oleh pengaju. Dalam kasus ini, pemberi persetujuan tertentu perlu diberi izin edit atas bidang peringkat.
</Note>

## 2. Prasyarat

*   Hanya Admin persetujuan yang dapat melakukan desain proses, sehingga Anda harus menjadi Admin persetujuan terlebih dahulu.

Untuk pengguna non-Admin persetujuan, buka Persetujuan OA DingTalk, klik [Pengaturan], klik [Buat formulir persetujuan], klik [Ajukan izin Admin], lalu klik "Kirim".

## 3. Titik masuk

Di halaman **"Admin Console Persetujuan"** - **"Manajemen Formulir"**, klik [**Edit**] pada tindakan formulir.

<Frame>

![Halaman Manajemen Formulir di Admin Console Persetujuan](https://img.alicdn.com/imgextra/i1/O1CN01XbUIqd5PJ7H5bBcU_!!6000000005183-2-tps-2758-1728.png)
</Frame>

Klik [**Desain proses**] untuk masuk ke antarmuka utama desain proses.

<Frame>

![Antarmuka utama desain proses](https://img.alicdn.com/imgextra/i1/O1CN01rzDmSqUAZpF5bBcY_!!6000000001097-2-tps-2758-1732.png)

## 4. Langkah-langkah

Pilih node persetujuan yang izin tindakan formulirnya perlu disesuaikan, klik "Izin tindakan formulir", pilih kontrol yang sesuai dengan konten formulir yang perlu disembunyikan, lalu ubah izinnya menjadi tersembunyi.

<Frame>

![Mengatur izin kontrol formulir menjadi tersembunyi](https://img.alicdn.com/imgextra/i1/O1CN01FTivZXHoHHC5bBcc_!!6000000004638-2-tps-2758-1736.png)
</Frame>

Pilih node persetujuan yang izin tindakan formulirnya perlu disesuaikan, klik "Izin tindakan formulir", pilih kontrol yang sesuai dengan konten yang perlu diedit, lalu ubah izinnya menjadi dapat diedit.

<Frame>

![Mengatur izin kontrol formulir menjadi dapat diedit](https://img.alicdn.com/imgextra/i3/O1CN01qQlquIlikfD5bgqC_!!6000000002645-2-tps-2762-1738.png)
