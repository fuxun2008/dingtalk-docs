## 1. FAQ

<AccordionGroup>
<Accordion title="1.1 Mengapa Halaman sematan dapat diakses di sebagian perangkat, tetapi tidak di perangkat lain?">
  Hal ini biasanya terjadi karena Halaman sematan menggunakan protokol HTTP, sedangkan platform YiDA menggunakan HTTPS.

  Demi alasan keamanan, browser membatasi jenis penyematan seperti ini. Beberapa perangkat Android dengan kebijakan keamanan yang lebih longgar mungkin masih mengizinkan akses, tetapi mayoritas perangkat dan browser terbaru akan memblokir permintaan tersebut.

  **Untuk mengatasi masalah ini, sematkan URL yang menggunakan protokol HTTPS.**
</Accordion>
<Accordion title="1.2 Apakah platform YiDA mendukung integrasi data Video, misalnya menghubungkan Kamera eksternal dan menampilkan feed-nya di platform YiDA?">
  Ya. Gunakan Komponen Iframe untuk menyematkan tautan feed Kamera langsung.

  Tambah Komponen Iframe ke halaman kustom, lalu konfigurasikan tautan feed Kamera pada panel Atribut di sebelah kanan.
</Accordion>
<Accordion title="1.3 Apakah layanan Alibaba Cloud VOD (Video on Demand) didukung? Skenarionya adalah menyediakan jendela Video bagi pelanggan untuk memantau pertumbuhan tanaman dari jarak jauh.">
  Komponen Iframe hanya menyematkan Halaman pihak ketiga. YiDA hanya berperan sebagai endpoint tampilan. Jika Halaman pihak ketiga mendukung streaming on-demand, fitur tersebut akan berfungsi.
</Accordion>
<Accordion title="1.4 Komponen HTML yang dikonfigurasi pada halaman kustom tidak menjalankan JavaScript sesuai harapan. Apakah Komponen HTML tidak mendukung impor file JS?">
  JavaScript dapat dieksekusi, tetapi harus diimpor di dalam `didmount()`.

</Accordion>
</AccordionGroup>
