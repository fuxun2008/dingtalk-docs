| **Fitur** | **Edisi Luang** | **Edisi Basic** | **Edisi Professional** | **Edisi Dedicated** |
|---|---|---|---|---|
| Halaman kustom | Tidak didukung | Tidak didukung | Didukung | Didukung |

Atur rendering bersyarat untuk setiap komponen.

Aktifkan atau nonaktifkan rendering secara langsung, atau ikat variabel untuk rendering reaktif.

**Catatan: Jika sebuah kondisi telah dikonfigurasi dan komponen tidak dirender, instance komponen yang diambil melalui API `this.$('fieldId')` akan bernilai null.**
