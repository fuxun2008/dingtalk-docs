## 1. Pengantar

**Komponen pada halaman kustom memiliki atribut konfigurasi yang lebih kaya dan fleksibel dibandingkan komponen pada halaman formulir. Untuk contoh penggunaan komponen, lihat** [**Developer Center**](/zh/open/yida/index)**.**

Komponen pada halaman kustom dikelompokkan ke dalam kategori [Tata letak], [Dasar], [Formulir], [Premium], dan [Lainnya]:

### 1.1 Komponen halaman kustom dan kegunaannya

| **Nama komponen** | **Kegunaan** |
|---|---|
| [Teks](/zh/open/yida/components/basic/text) | Menampilkan konten teks. |
| [Gambar](/zh/open/yida/components/basic/image) | Menampilkan konten gambar. |
| [Ikon](/zh/open/yida/components/basic/icon) | Memilih dari beragam gaya ikon. |
| [Tautan](/zh/open/yida/components/basic/link) | Menambahkan URL yang mengarah ke halaman terkait saat diklik. |
| [Blok tautan](/zh/open/yida/components/basic/linkBlock) | Komponen kontainer yang memicu navigasi saat elemen apa pun di dalamnya diklik. |
| [Tombol](/zh/open/yida/components/basic/button) | Memicu tindakan melalui peristiwa tombol — misalnya, klik tombol untuk mendapatkan waktu saat ini. |
| [Pemutar video](/zh/open/yida/components/basic/video) | Memutar video pada halaman dengan beragam opsi pemutaran. |
| [Dialog](/zh/open/yida/components/basic/dialog) | Digunakan pada skenario berikut:<br />• Menampilkan notifikasi kepada pengguna<br />• Meminta pengguna mengonfirmasi suatu tindakan<br />• Meminta pengguna menyelesaikan tugas tanpa berpindah halaman dan mengganggu alur kerja |
| [Drawer](/zh/open/yida/components/basic/drawer) | Digunakan pada skenario berikut:<br />• Menampilkan notifikasi kepada pengguna<br />• Meminta pengguna mengonfirmasi suatu tindakan<br />• Meminta pengguna menyelesaikan tugas tanpa berpindah halaman dan mengganggu alur kerja |
| [Spreadsheet](/zh/open/yida/components/advanced/table) | Menampilkan data dari formulir atau formulir alur kerja dalam bentuk tabel. |
| [HTML](/zh/open/yida/components/advanced/HTML) | Memungkinkan pengembangan fitur kustom. Desain halaman memerlukan pengetahuan front-end — minimal pemahaman dasar tentang HTML, CSS, dan JS. |
| [JSX](/zh/open/yida/components/advanced/JSX) | Merender komponen yang sepenuhnya kustom menggunakan kode JSX. Umumnya digunakan untuk skenario tampilan saja. |
| [Carousel](/zh/open/yida/components/advanced/slider) | Menampilkan beberapa gambar secara berulang dalam mode putaran. |
| [Tooltip balon](/zh/open/yida/components/advanced/balloon) | Saat melakukan iterasi data pada halaman kustom, konten yang panjang mungkin terpotong. Gunakan tooltip balon untuk menampilkan konten lengkap ketika kursor diarahkan. |
| Panel ciutkan | Ketika sebuah halaman memiliki terlalu banyak komponen, gunakan panel ciutkan untuk melipatnya dan mengurangi kekacauan tampilan. |
| [Banner bawah](/zh/open/yida/components/advanced/bannerContainer) | Menambahkan konten yang ditempatkan di bagian bawah halaman dengan lebar penuh. |
| [Iframe](/zh/open/yida/components/advanced/Iframe) | Menyematkan konten dari halaman web lain ke halaman designer saat ini. Umumnya digunakan untuk skenario tampilan saja. |
| [Indikator progres](/zh/open/yida/components/advanced/progress) | Menampilkan progres suatu proyek. |
| [Paginasi](/zh/open/yida/components/advanced/pagination) | Gunakan komponen ini untuk membagi data yang ditampilkan pada halaman kustom menjadi beberapa halaman. |
| [Cari](/zh/open/yida/components/advanced/search) | Saat menggunakan komponen Spreadsheet pada halaman kustom, gunakan komponen Cari untuk menemukan rekam data tertentu. |
| [Filter](/zh/open/yida/components/advanced/filter) | Saat menampilkan data dalam tabel kustom, pencarian pada bilah atas hanya dapat memfilter satu kolom. Gunakan komponen Filter untuk mencari di beberapa kolom sekaligus. |
| [Menu](/zh/open/yida/components/advanced/menu) | Gunakan halaman kustom sebagai daftar isi, dengan item menu yang mengarah ke halaman lain. |
| [Pohon](/zh/open/yida/components/advanced/tree) | Gunakan komponen pohon untuk menjelajahi suatu kategori beserta subkategorinya. |
| [Lini Masa](/zh/open/yida/components/advanced/timeLine) | Umumnya digunakan untuk menampilkan riwayat perusahaan atau tonggak penting sebuah proyek. |
| [Langkah](/zh/open/yida/components/advanced/steps) | Komponen indikator langkah untuk halaman kustom. Cocok untuk alur multi-langkah seperti input data onboarding karyawan atau registrasi akun, memberikan pengingat progres saat pengisian informasi dasar. |
