## 1. Gambaran umum

Yida menyediakan pengaturan perulangan render untuk skenario yang memerlukan perulangan render.

Data perulangan harus berupa struktur array. Array string, array angka, dan array object semuanya didukung.

### Skenario 3: Perulangan bersarang

Misalkan sumber data jarak jauh mengembalikan struktur data berikut:

```javascript
[
  {
    type: 'Saya adalah judul satu',
    detail: [
      'Konten satu',
      'Konten dua',
      'Konten tiga'
    ]
	},
  {
    type: 'Saya adalah judul satu',
    detail: [
      'Konten satu',
      'Konten dua',
      'Konten tiga'
    ]
	},
  ...
]
```

Anda dapat mengimplementasikan perulangan bersarang dua tingkat; secara analogi, tingkat N (N \< Infinity) juga didukung.

Saat dua komponen bekerja sama untuk menerapkan perulangan bersarang, bungkus keduanya dalam sebuah komponen kontainer. Atur data perulangan luar pada komponen kontainer, dan atur data perulangan dalam pada komponen di dalamnya (dalam contoh ini, komponen Teks).

## 3. Catatan

### 3.1 Menggunakan `this` di dalam perulangan

Di seluruh page builder, `this` memiliki cakupan bertingkat. Cakupan saat ini adalah `this`, cakupan induk adalah `this.$super`, dan cakupan tingkat teratas adalah `this.$top`.

Misalnya, saat menerapkan perulangan render pada kontainer formulir dengan pengidentifikasi `'fooForm'`, gunakan `this.$('fooForm').getValue()` di dalam **badan perulangan** untuk mendapatkan nilai formulir pada iterasi saat ini. Untuk mendapatkan nilai semua formulir yang di-loop, gunakan `this.$super.$('fooForm').map(item => item.getValue())`.
