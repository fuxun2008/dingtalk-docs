## 1. Mengontrol pemilihan baris Tabel dengan kode

### 1.1 Pilih Komponen Tabel dan klik "Pemilih baris"

Panel pengaturan atribut akan muncul di sisi kanan Komponen Tabel.

### 1.2 Aktifkan "Tampilkan" dan ikat sebuah variabel ke "Baris yang dipilih". Inisialisasi sebagai array kosong untuk menunjukkan bahwa tidak ada baris yang dipilih

### 1.3 Periksa sumber data Tabel untuk menemukan identifier baris unik "id". Gunakan "id" ini untuk mengontrol apakah baris saat ini dipilih

### 1.4 Ikat sebuah peristiwa ke tombol tindakan dan kontrol pemilihan baris dengan memperbarui sumber data kustom

```javascript
export function onClick(){
  this.setState({
    selectedRows: ['1'], // id dari sumber data Tabel
  });
}
```

## 2. Mengambil baris yang dipilih

### 2.1 Ikat peristiwa: Pemilih baris >> Callback perubahan pilihan

### 2.2 Untuk mengambilnya di waktu lain, buat sumber data "Variabel" dan simpan sendiri

```javascript
    export function onSelectChange(selectedRowKeys, records) {
      console.log(selectedRowKeys, records);
      this.setState({
        selectedRowsData: records,
      });
    }
```

## 4. Memperluas baris yang dirender secara default setelah mengaktifkan struktur pohon

Dalam kode edit, format data harus berupa array yang nilainya adalah kunci utama setiap baris. Ini akan memperluas baris yang bersangkutan secara default. Anda juga dapat mengikat sebuah variabel dan memperbaruinya pada setiap klik untuk mengubah secara dinamis baris mana yang diperluas secara default.
