## 1. Kasus penggunaan

Sebagai salah satu komponen produk "DingTalk Interconnection Platform", fitur "Asosiasi Organisasi" menyediakan kemampuan manajemen Struktur Organisasi yang kuat untuk organisasi menengah dan besar. Fitur ini membantu Pengguna **menghubungkan Kontak lintas organisasi, mengintegrasikan Aplikasi, serta menjalin komunikasi dan kolaborasi tanpa hambatan antara organisasi induk dan cabang**.

- Komunikasi lintas organisasi, Persetujuan bisnis, dan pelaporan pekerjaan.
- Manajemen izin multi-organisasi dengan sinkronisasi struktur Pengguna secara real-time untuk meningkatkan efisiensi manajemen.

### 2.1 Langkah pertama: Desain Formulir dasar

**Langkah-langkah:**

1. Buat formulir biasa dan beri nama "Dapatkan Info Organisasi".
2. Tambahkan Komponen Pilih dropdown, beri nama "Target", lalu tambahkan dua opsi: "Kueri Organisasi Induk" dan "Kueri Organisasi Cabang". Atur sebagai Wajib. (Lihat Gambar 2.1-1)

**Langkah-langkah:**

1. Buat formulir biasa dan beri nama "Rekam Hasil Kueri Organisasi Induk".
2. Tambahkan Komponen Teks multi-baris, beri nama "Hasil Pengembalian Konektor", lalu atur statusnya ke "Tersembunyi". (Lihat Gambar 2.1-2)

Gambar 2.1-2 Menambah dan mengonfigurasi Komponen Teks multi-baris

Gambar 2.1-3 Menambah dan mengonfigurasi Komponen subformulir

Gambar 2.1-5 Mengonfigurasi konten panel JS

```javascript
// Kode yang ditunjukkan pada Gambar 2.1-5

  let arr = [];
// Iterasi object untuk mendapatkan field yang perlu ditampilkan
  const list = obj.map(item => {
```
