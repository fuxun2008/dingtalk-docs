## 1. Kasus penggunaan

Dengan konektor bawaan "Data Catalog" di YiDA, Anda dapat mengambil statistik obrolan grup pesan instan Organisasi Anda, termasuk:

- Pengguna obrolan grup: jumlah pengguna yang mengirim pesan obrolan grup di dalam organisasi.
- Grup baru: jumlah Internal Groups baru yang dibuat di dalam organisasi.
- Grup aktif: jumlah Internal Groups di dalam organisasi tempat pesan dikirim.
- Pesan obrolan grup: jumlah pesan yang dikirim di Internal Groups di dalam organisasi.
- Internal Groups: jumlah Internal Groups saat ini di dalam organisasi.
- Department Chats: jumlah Department Chats saat ini.

## 2. Prosedur

### 2.1 Langkah 1: Desain formulir

Buat dua formulir — satu untuk memicu konektor, dan yang lain untuk menerima serta menampilkan data yang dikembalikan oleh konektor.

#### 2.1.1 Buat formulir "Query statistik obrolan grup organisasi"

**Langkah-langkah:**

1. Buat formulir biasa dan beri nama "Query statistik obrolan grup organisasi".
2. Tambah Komponen Tanggal, beri nama "Tanggal query", dan tandai sebagai wajib. (Lihat Gambar 2.1-1)

Gambar 2.1-1 Tambah dan konfigurasikan Komponen Tanggal

3. Klik tombol "Simpan" di sudut kanan atas halaman.

#### 2.1.2 Buat formulir "Detail data obrolan grup organisasi"

**Langkah-langkah:**

1. Buat formulir biasa dan beri nama "Detail data obrolan grup organisasi".
2. Tambah komponen Teks multi-baris, beri nama "Data yang dikembalikan", dan atur statusnya menjadi "Tersembunyi". (Lihat Gambar 2.1-2)

Gambar 2.1-2 Tambah dan konfigurasikan komponen Teks multi-baris

3. Tambah komponen subformulir, beri nama "Tabel detail statistik obrolan grup organisasi", dan atur statusnya menjadi "Hanya Baca". (Lihat Gambar 2.1-3)

Gambar 2.1-3 Tambah dan konfigurasikan komponen subformulir

4. Di dalam subformulir, tambah 7 komponen Teks satu baris dan beri nama "Tanggal query, Pengguna obrolan grup, Grup baru, Grup aktif, Pesan obrolan grup, Internal Groups, Department Chats". Atur status semuanya menjadi "Hanya Baca". (Lihat Gambar 2.1-4)

Gambar 2.1-4 Tambah dan konfigurasikan 7 komponen Teks satu baris di dalam subformulir

5. Tambah kode berikut di panel JS untuk memproses data. (Lihat Gambar 2.1-5)

Gambar 2.1-5 Tambah kode JS untuk memproses data

Kodenya adalah sebagai berikut:

Pastikan untuk mengganti pengidentifikasi unik komponen!

```javascript
export function didMount() {
  // Ambil data yang dikembalikan oleh konektor. "textareaField_ky16z248" adalah pengidentifikasi unik komponen Teks multi-baris. Pastikan menggantinya, jika tidak, tidak akan berfungsi!
  const str = this.$("textareaField_ky16z248").getValue();
  // Proses data
  const obj = JSON.parse(str);
  const val = obj.dataList;
  let arr = [];
  const valList = val.map(item => {
    let valObject = {};
    // Tanggal query
    // Ganti textField_ky16z24k dengan pengidentifikasi unik komponen yang Anda buat
    valObject.textField_ky16z24k = item["stat_date"];
    // Pengguna obrolan grup
    // Ganti textField_ky16z24l dengan pengidentifikasi unik komponen yang Anda buat
    valObject.textField_ky16z24l = item["4030_DAY"];
    // Grup baru
    // Ganti textField_ky16z24j dengan pengidentifikasi unik komponen yang Anda buat
    valObject.textField_ky16z24j = item["4031_DAY"];
    // Grup aktif
    // Ganti textField_ky16z24i dengan pengidentifikasi unik komponen yang Anda buat
    valObject.textField_ky16z24i = item["4032_DAY"];
    // Pesan obrolan grup
    // Ganti textField_ky16z24h dengan pengidentifikasi unik komponen yang Anda buat
    valObject.textField_ky16z24h = item["4033_DAY"];
    // Internal Groups
    // Ganti textField_ky16z24g dengan pengidentifikasi unik komponen yang Anda buat
    valObject.textField_ky16z24g = item["4034_DAY"];
    // Department Chats
    // Ganti textField_ky16z24f dengan pengidentifikasi unik komponen yang Anda buat
    valObject.textField_ky16z24f = item["4035_DAY"];
    arr.push(valObject);
  })
  // Berikan data yang telah diproses ke komponen subformulir
  // Ganti tableField_ky16z24a dengan pengidentifikasi unik komponen subformulir yang Anda buat
  this.$("tableField_ky16z24a").setValue(arr);
}
```

6. Klik tombol "Simpan" di sudut kanan atas halaman.

### 2.2 Langkah 2: Tambah konektor

Untuk pengenalan detail tentang konektor, lihat:

Kartu konten Yuque. Klik tautan untuk melihat: [https://www.yuque.com/yida/support/zevvr1](https://docs.aliwork.com/docs/yida_support/zevvr1)

Tambah konektor ke formulir "Query statistik obrolan grup organisasi" untuk terintegrasi dengan konektor DingTalk Data Catalog.

**Langkah-langkah:**

1. Di halaman Admin, pilih formulir "Query statistik obrolan grup organisasi", pilih "Integrasi & Otomatisasi", lalu klik tombol "Buat Integrasi & Otomatisasi". (Lihat Gambar 2.2-1)

Gambar 2.2-1 Titik masuk konektor

2. Buat konektor bernama "Query statistik organisasi". Pilih "Pemicu peristiwa formulir" sebagai Jenis pemicu, lalu klik "Konfirmasi". (Lihat Gambar 2.2-2)

Gambar 2.2-2 Buat konektor

3. Konfigurasikan pemicu peristiwa formulir: pilih "Buat berhasil" sebagai peristiwa pemicu, pilih "Semua data" untuk penyaringan data, lalu klik "Simpan". (Lihat Gambar 2.2-3)

Gambar 2.2-3 Konfigurasikan pemicu peristiwa formulir untuk konektor

4. Pilih aplikasi > "Data Catalog" > "Berikutnya". (Lihat Gambar 2.2-4)

Gambar 2.2-4 Pilih aplikasi konektor

5. Pilih tindakan > "Ambil statistik obrolan grup organisasi" > "Berikutnya". (Lihat Gambar 2.2-5)

Gambar 2.2-5 Pilih tindakan konektor

6. Konfigurasikan tindakan > Waktu query > "Bidang" > "Tanggal query" > "Simpan". (Lihat Gambar 2.2-6)

Gambar 2.2-6 Konfigurasikan tindakan konektor

7. Tambah node Buat Data. Di formulir "Terima statistik obrolan grup organisasi", buat satu rekam data dan atur nilai "Data yang dikembalikan konektor" menjadi "Hasil bisnis" "Bidang". (Lihat Gambar 2.2-7)

Gambar 2.2-8 Tambah dan konfigurasikan node "Buat Data"

8. Klik tombol "Simpan" di sudut kanan atas halaman, lalu klik "Publikasikan".
