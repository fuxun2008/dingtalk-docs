## 1. Kasus penggunaan

Smart Form adalah aplikasi dasar yang disediakan oleh DingTalk. Aplikasi ini cocok untuk skenario seperti survei dan pelacakan pendaftaran, serta mendukung statistik data dan unduhan. Contoh ini menunjukkan cara memicu konektor melalui pengiriman formulir di YiDA untuk mengueri informasi templat Smart Form yang dibuat oleh karyawan tertentu.

### 2.4 Langkah 4: Konfigurasikan "Tabel rekam hasil kueri"

Langkah-langkah sebelumnya menyiapkan pemanggilan konektor dan memungkinkan data yang dikembalikan konektor untuk diterima. Selanjutnya, proses data yang dikembalikan lalu tampilkan nilai yang telah diproses pada komponen di dalam subformulir "Rekam hasil kueri".

**Langkah:**

Pada halaman pengeditan formulir, salin kode berikut ke dalam fungsi `didMount` di panel aksi JS di sisi kiri halaman.

(Lihat Gambar 2.4-1.)

Gambar 2.4-1 Entri panel aksi JS dan fungsi didMount

<Note>
Kode di bawah ini dapat ditempel langsung ke panel JS. Catatan: Ganti pengenal unik setiap komponen dengan pengenal di formulir Anda.
</Note>

```javascript
// Dapatkan data yang diteruskan oleh konektor ke komponen teks multi-baris
// textareaField_kwcv17cj adalah kode unik komponen teks multi-baris "Hasil yang dikembalikan" pada halaman.
let obj = this.$('textareaField_kwcv17cj').getValue();
// Nilai obj adalah string. JSON.parse() mengonversi obj menjadi object.
  let res = JSON.parse(obj);
// Buat array kosong "arr" untuk menyimpan data yang telah diproses.
  let arr = []
// Iterasi variabel res
  const data = res.map(item=>{
    let object = {};
// Ganti kode antara "object." dan "=" pada baris 12–21 dengan pengenal unik setiap komponen di dalam subformulir.
    object.textField_kwcvykby = item.name;
    object.textField_kwcvykbz = item.memo;
    object.textField_kwcvykbx = item.form_code;
    object.textField_kwcvykc0 = item.setting.form_type === 0 ? "Formulir sekali pakai" : "Formulir berulang";
    object.textField_kwcvykc3 = item.setting.form_type === 0 ? "Formulir non-berulang" : item.setting.loop_days;
    object.textField_kwcvykc5 = item.setting.end_time ? item.setting.end_time : "Tidak ada tenggat yang ditetapkan";
    object.textField_kwcvykcb = item.setting.create_time;
    object.textField_kwcvykcc = item.setting.biz_type === 0 ? "Formulir umum" : "Formulir pendidikan";
    object.textField_kwcvykcd = item.setting.stop === false ? "Tidak dihentikan" : "Dihentikan";
    object.textField_kwcvykce = item.creator;
// Tambahkan object yang telah diproses ke array arr. Setiap object mewakili satu rekam subformulir.
    arr.push(object);
  })
// Tetapkan data array arr ke komponen subformulir
// Ganti tableField_kwd6plxz dengan pengenal unik subformulir di formulir Anda.
  this.$("tableField_kwd6plxz").setValue(arr);
```
