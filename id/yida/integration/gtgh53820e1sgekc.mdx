## 1. Kasus penggunaan

Setelah pengguna dipilih dan formulir Yida dikirim, ambil jumlah item belum dibaca karyawan tersebut di DingTalk Log untuk mempermudah pengumpulan statistik.

## 2. Prosedur

### 2.1 Langkah 1: Rancang formulir

#### 2.1.1 Buat dan konfigurasikan formulir "Kueri log belum dibaca"

Gunakan formulir ini untuk memicu tindakan Konektor dan menjalankan kueri saat data dikirim.

**Langkah-langkah:**

1. Buat formulir baru dan beri nama "Kueri log belum dibaca".
2. Tambah komponen anggota, beri nama "Pilih karyawan", lalu atur sebagai Wajib. (Lihat Gambar 2.1-1.)

Gambar 2.1-1 Tambah dan konfigurasikan komponen anggota

3. Klik Simpan di sudut kanan atas halaman.

#### 2.1.2 Buat dan konfigurasikan formulir "Catatan kueri log"

Gunakan formulir ini untuk menerima dan menampilkan data yang dikembalikan Konektor.

**Langkah-langkah:**

1. Buat formulir baru dan beri nama "Catatan kueri log".
2. Tambah komponen Teks satu baris, beri nama "Jumlah belum dibaca", lalu atur statusnya sebagai Hanya Baca. (Lihat Gambar 2.1-2.)

Gambar 2.1-2 Tambah dan konfigurasikan komponen Teks satu baris

3. Klik Simpan di sudut kanan atas halaman.

### 2.2 Langkah 2: Konfigurasikan Konektor

<Note>
Untuk penjelasan lengkap tentang Konektor Yida, lihat [Integrasi & Otomatisasi - Konektor](https://docs.aliwork.com/docs/yida_support/zevvr1).
</Note>

Gunakan Konektor untuk mengintegrasikan data DingTalk Log.

**Langkah-langkah:**

1. Di admin console, buka "Kueri log belum dibaca" >> Integrasi & Otomatisasi >> Buat Integrasi & Otomatisasi. (Lihat Gambar 2.2-1.)

Gambar 2.2-1 Entri Konektor

2. Beri nama Konektor "Kueri jumlah log belum dibaca karyawan", pilih tipe "Pemicu peristiwa formulir", lalu klik Konfirmasi. (Lihat Gambar 2.2-2.)

Gambar 2.2-2 Buat Konektor

3. Konfigurasikan pemicu peristiwa formulir: atur kondisi pemicu ke "Buat berhasil" dan filter data ke "Semua data". (Lihat Gambar 2.2-3.)

Gambar 2.2-3 Konfigurasikan peristiwa pemicu formulir

4. Pilih aplikasi Konektor: pilih "Log" sebagai aplikasi Konektor, lalu klik Berikutnya. (Lihat Gambar 2.2-4.)

Gambar 2.2-4 Pilih aplikasi Konektor

5. Pilih tindakan Konektor: pilih "Dapatkan jumlah log belum dibaca", lalu klik Berikutnya. (Lihat Gambar 2.2-5.)

Gambar 2.2-5 Pilih tindakan Konektor

6. Konfigurasikan tindakan Konektor, lalu klik Simpan. (Lihat Gambar 2.2-6.)

Gambar 2.2-6 Konfigurasikan tindakan Konektor

7. Tambah node data "Buat rekam". (Lihat Gambar 2.2-7.)

Gambar 2.2-7 Tambah node "Buat rekam"

8. Konfigurasikan node data "Buat rekam". (Lihat Gambar 2.2-8.)

Gambar 2.2-8 Konfigurasikan node "Buat rekam"

9. Klik Simpan di sudut kanan atas halaman, lalu klik Publikasikan.

### 2.3 Langkah 3: Kirim data formulir

Kirim data untuk memicu Konektor dan menerima hasil yang dikembalikan.

**Langkah-langkah:**

Isi formulir "Kueri log belum dibaca", lalu kirim. (Lihat Gambar 2.3-1.)

Gambar 2.3-1 Kirim formulir
