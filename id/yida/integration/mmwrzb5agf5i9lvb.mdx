Node data merupakan fitur inti dari Integrasi & Otomatisasi. Node ini mengoperasikan data yang dihasilkan aplikasi untuk menghasilkan hasil eksekusi yang berbeda. Node berikut tersedia saat ini:

- **Buat data**
- **Perbarui data**
- **Ambil satu rekaman**
- **Ambil beberapa rekaman**
- **Hapus data**
