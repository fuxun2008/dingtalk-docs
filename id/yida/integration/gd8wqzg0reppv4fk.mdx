YiDA Edisi Dedicated mendukung konfigurasi flow Integrasi & Otomatisasi agar berjalan secara berurutan. Setelah eksekusi berurutan diaktifkan, beberapa instance dari flow integrasi & otomatisasi yang sama dieksekusi satu per satu. Mode ini cocok untuk skenario ketika data memiliki dependensi hulu ke hilir, misalnya pengambilan dan pembaruan inventaris.

Secara default, flow integrasi & otomatisasi berjalan dalam mode **paralel**: ketika beberapa Rekam memicu flow yang sama, semuanya dieksekusi secara bersamaan. Mode ini lebih cepat dan cocok untuk flow yang instance runtime-nya tidak saling memengaruhi. Setelah eksekusi berurutan diaktifkan, beberapa Rekam dieksekusi satu per satu; kecepatannya lebih lambat, namun cocok untuk flow yang instance runtime-nya memiliki dependensi hulu ke hilir.

<Note>
Setelah eksekusi berurutan diaktifkan, beberapa instance flow integrasi & otomatisasi dieksekusi satu per satu, sehingga kecepatan eksekusi bisa relatif lambat. Aktifkan dengan cermat sesuai kebutuhan.
</Note>
