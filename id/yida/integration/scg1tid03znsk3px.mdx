## 1. Ikhtisar

Log eksekusi integrasi & otomatisasi memungkinkan Anda melihat catatan eksekusi setiap instance integrasi & otomatisasi. Log ini menampilkan parameter input/output serta pesan error untuk alur dan node yang gagal, serta mendukung coba ulang node maupun coba ulang alur untuk alur yang gagal guna membantu Anda memecahkan dan memperbaiki kesalahan.

## 2. Alur kerja

### 2.1 Mengakses log eksekusi

Pada halaman Daftar integrasi & otomatisasi, pilih alur target untuk membuka log eksekusinya.

### 2.2 Melihat daftar instance

Di jendela pop-up, Anda dapat melihat catatan eksekusi alur. Filter kesalahan berdasarkan waktu dan status.

### 2.3 Detail

Lihat detail eksekusi setiap node dalam sebuah instance, dan lakukan tindakan cepat seperti mengedit node (yang akan membuka editor alur terkait) serta mencoba ulang node.

### 2.4 Coba ulang

Pembaruan ini mendukung dua jenis coba ulang: coba ulang node dan coba ulang alur.

**Peringatan: Jika melibatkan pembaruan data, coba ulang dapat menghasilkan data yang tidak valid, yang berpotensi mengganggu operasional bisnis. Anda menanggung risiko ini atas kebijakan sendiri.**

#### 2.4.1 Coba ulang node

**Efek**: Coba ulang dimulai dari node saat ini dan berlanjut melalui alur berikutnya. Hasil eksekusi dicatat pada instance asli.

**Kasus penggunaan:**

Ketika eksekusi terhenti karena masalah koneksi node (misalnya, **timeout koneksi Konektor**), Anda dapat mencoba ulang node tersebut.

**Batasan coba ulang:**

- Hanya mendukung instance eksekusi dari satu bulan terakhir.
- Anda harus menunggu setidaknya 1 menit di antara setiap percobaan ulang. Jika tidak, pesan akan menunjukkan bahwa alur sedang diperbaiki.

#### 2.4.2 Coba ulang alur

**Efek**: Alur berjalan ulang dari node awal dan menghasilkan instance yang benar-benar baru.

**Kasus penggunaan:**

Ketika node hulu mengalami kesalahan (misalnya, gagal mengambil data), coba ulang alur setelah menyesuaikan konfigurasi node atau memastikan bahwa masalah data Formulir telah diselesaikan.

**Batasan coba ulang:**

- Hanya mendukung instance eksekusi dari satu bulan terakhir.
- Anda harus menunggu setidaknya 1 menit di antara setiap percobaan ulang. Jika tidak, pesan akan menunjukkan bahwa alur sedang diperbaiki.
