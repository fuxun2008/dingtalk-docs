Alur kerja Yida memungkinkan developer low-code menambahkan node developer bertipe **Skrip** saat merancang alur kerja atau integrasi & otomatisasi. Melalui node skrip, developer dapat menulis JavaScript untuk menyisipkan variabel statis secara manual ke dalam alur bisnis, atau memformat data yang dikembalikan node hulu, sehingga konfigurasi alur kerja menjadi lebih fleksibel.

## Kasus penggunaan

Pada tahap desain, tambahkan node skrip dan tulis kode JavaScript untuk mengambil nilai dari data masukan, memproses data perantara, dan pada akhirnya menyuntikkan data melalui object output bawaan. Dengan begitu, Anda memperoleh kemampuan pemrosesan data berbasis skrip dalam orkestrasi alur bisnis.

## Mengakses node skrip

- Metode 1: Edit formulir alur kerja > Buka halaman desain alur kerja > Pilih node Developer > Node skrip.
- Metode 2: Edit aplikasi > Integrasi & otomatisasi > Pilih alur otomatisasi target dan masuk ke konfigurasi desainnya, lalu tambahkan node skrip.

Pada node hilir dari node skrip, saat memilih tipe bidang, Anda akan melihat bidang yang sesuai dengan node output dari node skrip sebelumnya.

## Hal yang perlu diperhatikan

- Node skrip baru menggantikan node Groovy sebelumnya, dan skrip menjangkau audiens developer yang lebih luas.
- Node skrip hanya mendukung sintaks ES5; sintaks ES6 dan yang lebih baru tidak didukung.
- Pemrosesan node pembaruan batch belum didukung.
- Hindari memproses data pada skenario dengan konsumsi memori tinggi. Data yang melebihi 10 MB (saat ini ditetapkan sementara 10 MB; Yida akan menyesuaikannya berdasarkan kondisi aktual) akan memicu kesalahan batas memori. Jika penggunaan CPU melebihi 5 detik (misalnya, saat menulis infinite loop), mekanisme perlindungan otomatis akan memicu kesalahan.
- Permintaan jaringan melalui xhr dan fetch tidak didukung, begitu juga object dan fungsi tingkat atas seperti window, console, dan print.
- Mendefinisikan fungsi di dalam blok kode didukung.
- Jangan menambahkan pernyataan return di luar fungsi.
