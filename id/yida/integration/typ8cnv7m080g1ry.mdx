Node data adalah fitur inti dari Integrasi & Otomatisasi. Node data melakukan berbagai tindakan pada data yang dihasilkan aplikasi Anda. Artikel ini menjelaskan cara menggunakan node perbarui data.

## Ringkasan fitur

Node perbarui data mendukung dua mode pembaruan: **Perbarui data formulir secara langsung** dan **Perbarui data formulir berdasarkan node**:

- Perbarui data formulir secara langsung: memperbarui tabel utama atau subformulir dari formulir biasa berdasarkan aturan pencocokan yang dikonfigurasi (tabel sumber dapat berupa formulir biasa atau formulir alur kerja). Fokusnya adalah pembaruan langsung.
- Perbarui data formulir berdasarkan node: memperbarui data yang diambil oleh node Ambil satu rekaman atau Ambil beberapa rekaman. Fokusnya adalah mengambil data terlebih dahulu, lalu memperbaruinya.

Node ini didukung baik dalam alur integrasi & otomatisasi maupun alur kerja sederhana.

## Skenario penggunaan

Perbarui data formulir secara langsung memiliki batas per pembaruan, tetapi Anda dapat mengikuti pendekatan konfigurasi aturan bisnis untuk memperbarui satu subformulir dari subformulir lainnya. Perbarui data formulir berdasarkan node berfungsi sama dengan node pembaruan asli dan dapat memperbarui sekumpulan rekaman terfilter.

## Langkah

### Perbarui data formulir secara langsung

1. Masuk ke workbench YiDA dan klik My Apps.
2. Pilih aplikasi yang diperlukan, lalu buka halaman Pengaturan Aplikasi.
3. Klik Integrasi & Otomatisasi, pilih alur integrasi & otomatisasi yang telah dibuat, lalu klik Edit.
4. Arahkan kursor ke garis konektor pada node persetujuan. Tombol **+** akan muncul. Klik **+** dan pilih node Perbarui Data.
5. Pada panel konfigurasi di sebelah kanan, pilih Perbarui data formulir secara langsung, lalu klik untuk memilih tipe tabel target.
6. Konfigurasikan aturan pencocokan untuk pembaruan data.

<Note>
1. Komponen yang mendukung pencocokan: Teks satu baris, Teks multi-baris, Pilih, Dropdown select, Tanggal, dan Nomor seri. Untuk pemetaan detail, lihat Detail aturan komponen. Komponen lain belum didukung.
2. Untuk data yang memenuhi kondisi utama, hingga 100 rekaman dapat dicocokkan. Rekaman melebihi 100 tidak akan diperbarui.
</Note>

### Perbarui data formulir berdasarkan node

Jika memilih Perbarui data formulir berdasarkan node, ambil data sebelum node saat ini terlebih dahulu. Untuk detailnya, lihat [Ambil satu rekaman](/id/yida/integration/svfx3gygmo5yyu6n) atau [Ambil beberapa rekaman](https://www.yuque.com/yida/ugc9hx/gv15lyuaayfc0fyw).

1. Masuk ke workbench YiDA dan klik My Apps.
2. Pilih aplikasi yang diperlukan, lalu buka halaman Pengaturan Aplikasi.
3. Klik Integrasi & Otomatisasi, pilih alur integrasi & otomatisasi yang telah dibuat, lalu klik Edit.
4. Arahkan kursor ke garis konektor pada node persetujuan. Tombol **+** akan muncul. Klik **+** dan pilih node Perbarui Data.
5. Pada panel konfigurasi di sebelah kanan, pilih Perbarui data formulir berdasarkan node, lalu pilih data yang akan diperbarui.

## FAQ

**T: Bagaimana cara memahami parameter di sisi kiri dan kanan aturan pembaruan?**

J: Sisi kiri adalah bidang tabel target yang akan diperbarui. Sisi kanan adalah bidang sumber yang cocok.
