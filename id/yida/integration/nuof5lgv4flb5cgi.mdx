Node Buat Data adalah fitur inti dari Integrasi & Otomatisasi. Node ini menjalankan berbagai tindakan eksekusi pada data yang dihasilkan oleh aplikasi. Artikel ini menjelaskan apa itu node Buat Data.

## Prosedur

1. Masuk ke workbench YiDA dan klik **My Apps**.
2. Pilih aplikasi yang Anda inginkan, lalu buka halaman **App Settings**.
3. Klik **Integrasi & Otomatisasi**, pilih alur integrasi & otomatisasi yang ada, lalu klik **Edit**.

4. Arahkan kursor ke garis konektor node Persetujuan. Tombol **+** akan muncul. Klik **+**, lalu pilih node **Buat Data**.

<Frame>
  ![](https://gw.alicdn.com/imgextra/i4/O1CN01S3O1qmLudqF7HPvK_!!6000000005343-2-tps-3586-1996.png)
</Frame>

Ketika acara formulir atau acara aplikasi terpicu, Anda dapat membuat satu atau beberapa rekam di tabel target. Saat ini tersedia dua metode pembuatan: **Buat di formulir** dan **Buat di sub-tabel**.

<Frame>
  ![](https://gw.alicdn.com/imgextra/i1/O1CN014nsi3vAa2WD3LCbW_!!6000000003285-2-tps-1646-704.png)
</Frame>

5. Pilih metode pembuatan.

<Frame>
  ![](https://gw.alicdn.com/imgextra/i4/O1CN0128VY7plILZD3Xuvm_!!6000000002766-2-tps-1747-931.png)
</Frame>

Setelah Anda memilih metode pembuatan dan tabel target, opsi untuk membuat satu rekam atau beberapa rekam beserta pengaturan bidang akan muncul. **Buat satu rekam** dipilih secara default. Untuk membuat beberapa rekam, alihkan opsi secara manual.
