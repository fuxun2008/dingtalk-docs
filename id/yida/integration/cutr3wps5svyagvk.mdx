## 1. Kasus penggunaan

Di YiDA, kirim formulir untuk melakukan query informasi check-in karyawan, termasuk status, waktu, dan lokasi check-in.

## 2. Langkah

### 2.1 Langkah 1: Buat formulir

Buat dua formulir biasa. "Check-in Query Form" memicu konektor untuk menjalankan query, sedangkan "Query Result Record" menerima hasil yang dikembalikan konektor agar mudah ditinjau.

#### 2.1.1 Buat formulir query

**Langkah:**

1. Buat sebuah formulir biasa dan beri nama "Check-in Query Form".
2. Tambahkan dua komponen Tanggal, beri nama "Query Start Date" dan "Query End Date". Atur formatnya ke "YYYY-MM-DD HH:mm" dan tandai sebagai wajib. (Lihat Gambar 2.1-1.)

<Frame>
  ![](https://gw.alicdn.com/imgextra/i2/O1CN01s0P5kr2C4TH3th8d_!!6000000000862-2-tps-1920-955.png)
</Frame>

Gambar 2.1-1 Tambahkan dan konfigurasikan komponen Tanggal

3. Tambahkan komponen anggota dan beri nama "Employee to Query". Tandai sebagai wajib. (Lihat Gambar 2.1-2.)

<Frame>
  ![](https://gw.alicdn.com/imgextra/i1/O1CN01J5YNeLYihbG3th8d_!!6000000007129-2-tps-1920-955.png)
</Frame>

Gambar 2.1-2 Tambahkan dan konfigurasikan komponen anggota

4. Klik **Simpan** di pojok kanan atas halaman.

#### 2.1.2 Buat formulir pencatatan hasil

**Langkah:**

1. Buat sebuah formulir biasa dan beri nama "Query Result Record".
2. Tambahkan empat komponen Teks satu baris, beri nama "Connector Execution Status", "Check-in Status", "Check-in Time", dan "Check-in Location". (Lihat Gambar 2.1-3.)

<Frame>
  ![](https://gw.alicdn.com/imgextra/i1/O1CN01BDueaLEeB5E3th8d_!!6000000000287-2-tps-1920-955.png)
</Frame>

Gambar 2.1-3 Tambahkan dan konfigurasikan komponen Teks satu baris

3. Klik **Simpan** di pojok kanan atas.

### 2.2 Langkah 2: Konfigurasikan konektor formulir untuk "Check-in Query Form"

<Note>
Untuk pengenalan konektor, lihat [Integrasi & Otomatisasi - Konektor](/id/yida/integration/gqmveiswrxkgxu9s).
</Note>
