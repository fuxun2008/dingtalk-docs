## 1. Kasus penggunaan

Di YiDA, kirim formulir untuk melakukan query informasi check-in karyawan, termasuk status, waktu, dan lokasi check-in.

## 2. Langkah

### 2.1 Langkah 1: Buat formulir

Buat dua formulir biasa. "Check-in Query Form" memicu konektor untuk menjalankan query, sedangkan "Query Result Record" menerima hasil yang dikembalikan konektor agar mudah ditinjau.

#### 2.1.1 Buat formulir query

**Langkah:**

1. Buat sebuah formulir biasa dan beri nama "Check-in Query Form".
2. Tambahkan dua komponen Tanggal, beri nama "Query Start Date" dan "Query End Date". Atur formatnya ke "YYYY-MM-DD HH:mm" dan tandai sebagai wajib. (Lihat Gambar 2.1-1.)

Gambar 2.1-1 Tambahkan dan konfigurasikan komponen Tanggal

3. Tambahkan komponen anggota dan beri nama "Employee to Query". Tandai sebagai wajib. (Lihat Gambar 2.1-2.)

Gambar 2.1-2 Tambahkan dan konfigurasikan komponen anggota

4. Klik **Simpan** di pojok kanan atas halaman.

#### 2.1.2 Buat formulir pencatatan hasil

**Langkah:**

1. Buat sebuah formulir biasa dan beri nama "Query Result Record".
2. Tambahkan empat komponen Teks satu baris, beri nama "Connector Execution Status", "Check-in Status", "Check-in Time", dan "Check-in Location". (Lihat Gambar 2.1-3.)

Gambar 2.1-3 Tambahkan dan konfigurasikan komponen Teks satu baris

3. Klik **Simpan** di pojok kanan atas.

### 2.2 Langkah 2: Konfigurasikan konektor formulir untuk "Check-in Query Form"

<Note>
Untuk pengenalan konektor, lihat [Integrasi & Otomatisasi - Konektor](https://docs.aliwork.com/docs/yida_support/zevvr1).
</Note>

Dengan mengonfigurasi konektor formulir untuk "Check-in Query Form", aktifkan fitur query check-in dan tambahkan hasilnya secara otomatis ke formulir "Query Result Record".

**Langkah:**

1. Di halaman admin, pilih "Check-in Query Form", buka tab **Integrasi & Otomatisasi**, lalu klik **Create Integration & Automation**. (Lihat Gambar 2.2-1.)

Gambar 2.2-1 Entri konektor

2. Beri nama konektor "Check-in Query", atur Jenis pemicu ke "Form event trigger", lalu klik **Konfirmasi**. (Lihat Gambar 2.2-2.)

Gambar 2.2-2 Buat konektor

3. Klik node **Form event trigger**. Atur peristiwa pemicu ke "Create success" dan filter data ke "All data". (Lihat Gambar 2.2-3.)

Gambar 2.2-3 Konfigurasikan pemicu peristiwa formulir

4. Klik node **Konektor**, pilih aplikasi "Check-in", lalu klik **Berikutnya**. (Lihat Gambar 2.2-4.)

Gambar 2.2-4 Pilih aplikasi konektor

5. Atur tindakan ke "Get personal check-in record", lalu klik **Berikutnya**. (Lihat Gambar 2.2-5.)

Gambar 2.2-5 Pilih tindakan konektor

6. Konfigurasikan tindakan tersebut, lalu klik **Simpan**. (Lihat Gambar 2.2-6.)

Gambar 2.2-6 Konfigurasikan tindakan konektor

7. Arahkan kursor ke area di bawah node **Konektor**, klik **+**, lalu pilih node **Create data**. (Lihat Gambar 2.2-7.)

Gambar 2.2-7 Tambahkan node "Create data"

8. Konfigurasikan node **Create data**. Untuk metode pembuatan, pilih "Create in form" dan atur formulir ke "Query Result Record". Untuk data yang akan dibuat, pilih "Create a single record". Konfigurasikan pemetaan bidang, lalu klik Simpan. (Lihat Gambar 2.2-8.)

Gambar 2.2-8 Konfigurasikan node "Create data"

9. Konfigurasikan "Connector Execution Status" pada pengaturan bidang node **Create data**. (Lihat Gambar 2.2-9.)

Gambar 2.2-9 Konfigurasikan formula untuk bidang "Connector Execution Status"

10. Konfigurasikan "Check-in Status" pada pengaturan bidang node **Create data**. (Lihat Gambar 2.2-10.)

Gambar 2.2-10 Konfigurasikan formula untuk bidang "Check-in Status"

11. Konfigurasikan "Check-in Time" pada pengaturan bidang node **Create data**. (Lihat Gambar 2.2-11.)

Gambar 2.2-11 Konfigurasikan formula untuk bidang "Check-in Time"

12. Konfigurasikan "Check-in Location" pada pengaturan bidang node **Create data**. (Lihat Gambar 2.2-11.)

Gambar 2.2-12 Konfigurasikan formula untuk bidang "Check-in Location"

13. Klik **Simpan** di pojok kanan atas, lalu klik **Publish**.
