Node data adalah fitur inti dari Integrasi & Otomatisasi. Node ini beroperasi pada data yang dihasilkan aplikasi untuk mencapai berbagai hasil eksekusi. Node pengambilan data dibagi lebih lanjut menjadi node pengambilan satu rekam dan node pengambilan banyak rekam. Artikel ini menjelaskan cara menggunakan node pengambilan data.

## Node pengambilan satu rekam

1. Masuk ke workbench YiDA dan klik **My Apps**.
2. Pilih aplikasi yang dibutuhkan dan buka halaman **App Settings**.
3. Klik **Integrasi & Otomatisasi**, pilih alur integrasi & otomatisasi yang sudah ada, lalu klik **Edit**.

4. Arahkan kursor ke garis penghubung node persetujuan. Tombol **+** akan muncul. Klik **+**, lalu pilih node **Get Single Record**.
5. Pilih metode pengambilan data. Data dapat diambil dari sumber berikut.

## Node pengambilan banyak rekam

Node pengambilan banyak rekam bekerja mirip dengan node pengambilan satu rekam. Perbedaannya, node pengambilan satu rekam hanya mengembalikan satu rekam, sedangkan node pengambilan banyak rekam mengembalikan beberapa rekam sekaligus.

## Catatan

Perhatikan hal berikut saat menggunakan node pengambilan data:

- Jika node pengambilan satu rekam mengambil beberapa rekam, rekam pertama setelah pemfilteran akan dikembalikan berdasarkan aturan pengurutan yang dikonfigurasi.
- Node pengambilan banyak rekam dapat mengambil hingga 2.000 rekam dalam sekali jalan. (Edisi Dedicated mendukung hingga 2.000 rekam per pengambilan; edisi lain mendukung hingga 100.)
