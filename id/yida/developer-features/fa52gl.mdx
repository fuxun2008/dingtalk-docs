---
title: "Tentang didMount"
description: "Pelajari metode didMount di Yida untuk memanggil fungsi tertentu setelah Halaman selesai dimuat, termasuk pentingnya binding manual pada Halaman Kustom serta cara membedakan logika kode antara Halaman pengiriman Formulir dan Halaman detail."
polished: true
---

1. Setelah Halaman selesai dirender, fungsi berikut langsung dipanggil. Fungsi ini di-binding pada Halaman saat ini melalui Peristiwa - Pengaturan - Siklus Hidup - Halaman dimuat.

**Catatan: Halaman Kustom wajib di-binding secara manual satu kali; jika tidak, Peristiwa tersebut tidak akan terpicu.**

2. Kode di dalam didMount berjalan baik pada Halaman pengiriman Formulir maupun Halaman detail. Pada skenario tertentu, Anda perlu membedakan keduanya sebagai berikut:

```jsx
this.utils.isSubmissionPage() // Memeriksa apakah Formulir merupakan Halaman pengiriman
this.utils.isViewPage() // Memeriksa apakah Formulir merupakan Halaman detail
```
