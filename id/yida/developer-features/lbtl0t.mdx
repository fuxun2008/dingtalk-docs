<Warning>
Konfigurasi fitur berikut memerlukan keterampilan coding. Jika Anda tidak familier dengan coding, gunakan solusi zero-code sebagai gantinya.
</Warning>

## Kasus penggunaan

- Ambil data secara terjadwal ke sistem Anda untuk pemrosesan atau pengarsipan lebih lanjut.
- Integrasikan entri pengiriman formulir dan inisiasi alur kerja ke platform yang sudah ada.
- Gunakan panel aksi JS di YiDA untuk menulis kode JavaScript yang menerapkan logika bisnis kustom atau pemeriksaan kondisional.

**Direkomendasikan:** [**Developer Center**](/zh/open/yida/guide/about)

Isi bab ini:

1. Antarmuka Open API
2. Panel aksi JS — akses kode frontend
3. Memanggil API eksternal dari halaman kustom
