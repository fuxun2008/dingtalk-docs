**eagleeye-traceid** adalah identifikasi unik dari sebuah permintaan. Developer menggunakannya untuk memecahkan masalah pengguna.

**1. Buka developer tools**

<Frame>
  ![](https://gw.alicdn.com/imgextra/i1/O1CN01xsmpto1fzWE5qI8M_!!6000000007337-2-tps-2878-1568.png)
</Frame>

Pintasan: F12. Jika tidak berfungsi, ikuti langkah-langkah berikut:
1. Klik tiga titik di sudut kanan atas.
2. Klik Lainnya tools.
3. Klik Developer tools.
4. Klik Network.

**2. Cari permintaan tertentu**

<Frame>
  ![](https://gw.alicdn.com/imgextra/i3/O1CN017yvaWTIhQAF5qXns_!!6000000002873-2-tps-2880-1800.png)
</Frame>

Catatan: Hubungi developer Anda untuk memperoleh konten pencarian yang tepat.

<Frame>
  ![](https://gw.alicdn.com/imgextra/i2/O1CN01zpB4Fght3pL5qXns_!!6000000002480-2-tps-2880-1800.png)
</Frame>

**3. Peroleh traceId**

Buka Permintaan > Headers > Response Headers > eagleeye-traceid. Nilainya adalah traceId. Salin dan kirim ke developer Anda.

Jika halaman ini bermanfaat, berikan Suka.
