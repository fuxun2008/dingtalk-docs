Panggil API ini melalui `this.utils.yida.<nama fungsi>`.

## API operasi formulir

| **Nama fungsi** | **Deskripsi** | **Contoh permintaan** |
|---|---|---|
| **saveFormData** | Buat instans formulir | `// Buat instans formulirthis.utils.yida.saveFormData({  formUuid: 'FORM-xxx',  appType: pageConfig.appType,  formDataJson: JSON.stringify({    textField_m1g4dcpy: 'Teks satu baris',    textareaField_m1g4dcpz: 'Teks multi-baris',  }),}).then((res) => {  console.log('Hasil buat', res);}).catch(({ message }) => {  this.utils.toast({    title: message,    type: 'error',  });});` |
| **updateFormData** | Perbarui nilai komponen tertentu dalam formulir | `// Perbarui nilai komponen tertentu dalam formulirthis.utils.yida.updateFormData({  formInstId: 'FINST-xxx',  updateFormDataJson: JSON.stringify({    textField_m1g4dcpy: 'Teks satu baris',    textareaField_m1g4dcpz: 'Teks multi-baris',  }),  useLatestVersion: 'y',}).then((res) => {  console.log('Berhasil diperbarui');}).catch(({ message }) => {  this.utils.toast({    title: message,    type: 'error',  });});` |
| **searchFormDataIds** | Cari daftar ID instans formulir berdasarkan kriteria | `// Cari daftar ID instans formulir berdasarkan kriteriathis.utils.yida.searchFormDataIds({  formUuid: 'FORM-xxx',  currentPage: 1,  pageSize: 10,  searchFieldJson: JSON.stringify({    textField_m1g4dcpy: 'Teks satu baris',    textareaField_m1g4dcpz: 'Teks multi-baris',  }),}).then((res) => {  console.log('Hasil permintaan', res);}).catch(({ message }) => {  this.utils.toast({    title: message,    type: 'error',  });});` |
| **getFormComponentDefinationList** | Ambil definisi formulir | `// Ambil definisi formulirthis.utils.yida.getFormComponentDefinationList({  formUuid: 'FORM-xxx',  version: '',}).then((res) => {  console.log('Hasil permintaan', res);}).catch(({ message }) => {  this.utils.toast({    title: message,    type: 'error',  });});` |
| **deleteFormData** | Hapus instans formulir | `// Hapus instans formulirthis.utils.yida.deleteFormData({  formUuid: 'FORM-xxx',}).then((res) => {  console.log('Hasil permintaan', res);}).catch(({ message }) => {  this.utils.toast({    title: message,    type: 'error',  });});` |
| **getFormDataById** | Ambil detail instans formulir berdasarkan ID instans formulir | `// Ambil detail instans formulir berdasarkan ID instans formulirthis.utils.yida.getFormDataById({  formInstId: 'FINST-xxxx',}).then((res) => {  console.log('Hasil permintaan', res);}).catch(({ message }) => {  this.utils.toast({    title: message,    type: 'error',  });});` |
| **searchFormDatas** | Cari daftar detail instans formulir berdasarkan kriteria | `// Cari daftar detail instans formulir berdasarkan kriteriathis.utils.yida.searchFormDatas({  formUuid: 'FORM-xxx',  searchFieldJson:'',// Cari berdasarkan nilai komponen formulir  currentPage:'1',  pageSize:'10',  originatorId:'',// Cari berdasarkan ID Karyawan pengirim data  createFrom:'2024-01-01',  createTo:'2024-02-01',  modifiedFrom:'2024-01-01',  modifiedTo:'2024-02-01',  dynamicOrder:'',// Urutkan}).then((res) => {  console.log('Hasil permintaan', res);}).catch(({ message }) => {  this.utils.toast({    title: message,    type: 'error',  });});` |

## API operasi alur kerja

| **startInstance** | Mulai alur kerja | `// Mulai alur kerjathis.utils.yida.startProcessInstance({  formUuid: 'FORM-xxx',  processCode:'TPROC--xxx',  deptId:'',  formDataJson: JSON.stringify({    textField_xxx: 'Teks satu baris',    textareaField_xxx: 'Teks multi-baris',  }),}).then((res) => {  console.log('Hasil permintaan', res);}).catch(({ message }) => {  this.utils.toast({    title: message,    type: 'error',  });});` |
|---|---|---|
| **updateInstance** | Perbarui instans alur kerja | `// Perbarui instans alur kerjathis.utils.yida.updateProcessInstance({  processInstanceId: 'f30233fb-xxx-9ee530',  updateFormDataJson: JSON.stringify({    textField_xxx: 'Teks satu baris',    textareaField_xxx: 'Teks multi-baris',  }),}).then((res) => {  console.log('Hasil permintaan', res);}).catch(({ message }) => {  this.utils.toast({    title: message,    type: 'error',  });});` |
| **deleteInstance** | Hapus instans alur kerja | `// Hapus instans alur kerjathis.utils.yida.deleteProcessInstance({  processInstanceId: 'f30233fb-xxx-9ee530',}).then((res) => {  console.log('Hasil permintaan', res);}).catch(({ message }) => {  this.utils.toast({    title: message,    type: 'error',  });});` |
| **getInstances** | Ambil daftar detail instans berdasarkan kriteria pencarian | `// Ambil daftar detail instans berdasarkan kriteria pencarianthis.utils.yida.getProcessInstances({  formUuid:'FORM-xxx', // ID Formulir  taskId:'2199132092', // ID Tugas  instanceStatus:'RUNNING', // Status instans  approvedResult:'agree', // Hasil persetujuan  currentPage:'1',  pageSize:'10',  originatorId:'2134', // Cari berdasarkan ID Karyawan pemrakarsa alur kerja  createFrom:'2024-01-01',  createTo:'2024-02-01',  modifiedFrom:'2024-01-01',  modifiedTo:'2024-02-01',  searchFieldJson: JSON.stringify({    textField_xxx: 'Teks satu baris',    textareaField_xxx: 'Teks multi-baris',  }),}).then((res) => {  console.log('Hasil permintaan', res);}).catch(({ message }) => {  this.utils.toast({    title: message,    type: 'error',  });});` |
| **getInstanceIds** | Cari ID instans alur kerja berdasarkan kriteria | `// Ambil daftar ID instans berdasarkan kriteria pencarianthis.utils.yida.getProcessInstanceIds({  formUuid:'FORM-xxx', // ID Formulir  taskId:'2199132092', // ID Tugas  instanceStatus:'RUNNING', // Status instans  approvedResult:'agree', // Hasil persetujuan  currentPage:'1',  pageSize:'10',  originatorId:'2134', // Cari berdasarkan ID Karyawan pemrakarsa alur kerja  createFrom:'2024-01-01',  createTo:'2024-02-01',  modifiedFrom:'2024-01-01',  modifiedTo:'2024-02-01',  searchFieldJson:JSON.stringify({    textField_xxx: 'Teks satu baris',    textareaField_xxx: 'Teks multi-baris',  }),}).then((res) => {  console.log('Hasil permintaan', res);}).catch(({ message }) => {  this.utils.toast({    title: message,    type: 'error',  });});` |
| **getInstanceById** | Ambil detail instans alur kerja berdasarkan ID instans | `// Ambil detail instans alur kerja berdasarkan ID instansthis.utils.yida.getProcessInstanceById({  processInstanceId:'f30233fb-xxx-530',}).then((res) => {  console.log('Hasil permintaan', res);}).catch(({ message }) => {  this.utils.toast({    title: message,    type: 'error',  });});` |
