## 1. Latar belakang

Sebelum mempelajari cara debug halaman YiDA, perhatikan hal-hal berikut:

1. YiDA saat ini dibangun di atas ekosistem JavaScript.
2. YiDA saat ini dibangun di atas ekosistem React.
3. Sistem komponen YiDA berbasis Fusion, library komponen open-source dari Alibaba Group.

## 2. Debug JavaScript

Chrome adalah browser yang direkomendasikan untuk debug kode.

Untuk panduan langkah demi langkah, lihat [artikel ini (Bahasa Inggris)](https://developers.google.com/web/tools/chrome-devtools/javascript/?hl=zh-cn) atau [artikel ini (Bahasa Mandarin)](https://zh.javascript.info/debugging-chrome).

## 3. Debug React

Lakukan debug dengan [React Devtools](https://chrome.google.com/webstore/detail/react-developer-tools/fmkadmapgofadopljbjfkapdkoienihi).

Untuk instruksi lengkap, lihat [artikel ini](https://reactjs.org/blog/2014/01/02/react-chrome-developer-tools.html).

## 4. Debug kode JS yang ditulis di panel action

(1) Buka developer console. Di macOS, tekan Cmd + Option + I, atau klik kanan lalu pilih "Inspect". Di Windows, tekan F12, atau klik kanan lalu pilih "Inspect".

<Frame>
  ![](https://gw.alicdn.com/imgextra/i1/O1CN01pwLtlPwnvpD259gi_!!6000000001241-2-tps-1026-530.png)
</Frame>

(2) Tambah kata kunci `debugger` pada kode Anda untuk menetapkan breakpoint saat debug melalui console.

<Frame>
  ![](https://gw.alicdn.com/imgextra/i1/O1CN01i1yWKyE4avF1pIJl_!!6000000003236-2-tps-900-581.png)
</Frame>

(3) Pada perangkat mobile, gunakan `alert()` untuk menampilkan nilai saat troubleshooting.

(4) Jika muncul error di console, klik `page.js` secara langsung untuk masuk ke debug kode sumber.

<Frame>
  ![](https://gw.alicdn.com/imgextra/i2/O1CN01SIVMDG5GJ5F1wTEM_!!6000000004348-2-tps-957-769.png)
</Frame>

(5) Di console, tekan Cmd/Ctrl + P lalu cari `page.js` untuk masuk ke debug kode sumber.

<Frame>
  ![](https://gw.alicdn.com/imgextra/i1/O1CN01XSvNnEcUYnH1vSkz_!!6000000007013-2-tps-949-628.png)

(6) Untuk metode debug lainnya, lihat [https://developers.aliwork.com/docs/guide/concept/debug](/id/open/yida/guide/concept/debug).
