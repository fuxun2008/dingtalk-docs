## 1. Pengantar

Open API umumnya digunakan dalam skenario berikut:

1. Menarik data secara berkala ke sistem internal untuk diproses lebih lanjut atau diarsipkan.
2. Mengintegrasikan titik masuk pengiriman formulir dan pemicu alur kerja ke platform yang sudah ada.

Jika kebutuhan Anda sesuai dengan salah satu skenario di atas, pertimbangkan untuk memanfaatkan kemampuan Open API dari YiDA.

Saat ini, YiDA telah menerbitkan seluruh Open API di DingTalk Open Platform, sekaligus tetap mempertahankan [YiDA Open API (versi lama)](https://docs.aliwork.com/docs/yida_support/lbtl0t/rrwdug/rrwdug/agb8im). Memanggil YiDA Open API melalui DingTalk Open Platform merupakan pendekatan yang direkomendasikan.
