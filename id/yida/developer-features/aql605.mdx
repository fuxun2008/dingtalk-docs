## 1. Catatan penggunaan

### 1.1 Aturan penggabungan URL HTTP

Saat ini API tingkat App sudah didukung. Di dalam sebuah App (lintas-App juga didukung), akses API terkait menggunakan format berikut:

```text
${Domain Yida}/dingtalk/web/${Kode App} + jalur API.
```

Contohnya, untuk memanggil API "instans alur kerja – Mulai alur kerja" pada App dengan kode APP_X1X2X3X4 melalui browser, URL permintaan yang digunakan di panel data adalah (**jalur relatif sudah cukup**):

```text
/dingtalk/web/APP_X1X2X3X4/v1/process/startInstance.json
```

Lihat [II. instans alur kerja] → [1. Mulai alur kerja] untuk contoh praktik terperinci.

**Catatan: pada versi saat ini, field searchFieldJson dan dynamicOrder memerlukan nilai bertipe string. Contoh:**

```javascript
const someJson = {
	"textField_kkm9o5cd":"123"
}

// Meneruskan someJson langsung ke searchFieldJson tidak akan berfungsi. Gunakan JSON.stringify untuk mengubah object menjadi string.
const fieldJson = JSON.stringify(someJson); // '{"textField_kkm9o5cd":"123"}'
```

**Panduan skenario:**

①. Bangun Halaman alur kerja sederhana, klik Komponen yang nilainya ingin diisi dengan nilai Kustom, lalu ambil pengidentifikasi uniknya. Dalam contoh ini, pengidentifikasi unik Kotak Teks Teks satu baris adalah `textField_kkm9o5cd`.

②. Buat Halaman tampilan Premium, seret sebuah Button ke Halaman, lalu Buat Sumber Data.

Isi Nama yang mudah dipahami dan unik di Halaman ini, lalu isi URL permintaan sesuai kebutuhan bisnis Anda. Dalam contoh ini, klik Button akan memulai sebuah alur kerja, jadi URL permintaannya adalah: /alibaba/web/APP_D45S78OXJSL51QTQVHT8/v1/process/startInstance.json, di mana APP_D45S78OXJSL51QTQVHT8 adalah pengidentifikasi unik App — ganti dengan pengidentifikasi unik App Anda. Pastikan memilih POST sebagai Metode HTTP.

③. Tambah event onClick ke Button, lalu klik ikon \<> untuk menghubungkan Sumber Data jarak jauh ke Button:

Referensi: [https://developers.aliwork.com/docs/api/about](/zh/open/yida/api/about)

Tuliskan kode pengikatan berikut. Perhatikan bahwa kita mengisi nilai tetap `123` untuk kontrol Formulir Teks satu baris (pengidentifikasi unik: `textField_kkm9o5cd`).

Parameter formUuid dan processCode tersedia di [Pengaturan App] – [Data App] – [alur kerja XX] sebagai ID Formulir dan Kode alur kerja.

```javascript
export function onClick(){
  const params = {
    "processCode":"TPROC--CFYJ5HYUN89NJ1JW3IXBI7A95RXM3652O9MKK3",
    "formUuid": "FORM-CFYJ5HYUN89NJ1JW3IXBI7A95RXM3552O9MKK2",
    "formDataJson": '{"textField_kkm9o5cd":"123"}'
  }

  this.dataSourceMap.myDatasource.load(params).then((response) => {
    this.utils.dialog({
      method: 'alert', // atau confirm
      title: 'Permintaan berhasil',
      type: 'success', // Di PC, info/success/error didukung
      content: `Respons: ${response}`,
    })
  })
  console.log('onClick');
}
```

④. Setelah menulis kode, klik Button Simpan di sudut kanan atas Halaman.

⑤. Buka Halaman runtime untuk menguji peluncuran alur kerja. Klik Button, dan di alat Debug bawaan browser pada bagian Network Anda akan melihat bahwa permintaan startInstance Berhasil. Respons `da5ed25c-977b-40e0-acff-4a1c07aa6f41` adalah ID instans alur kerja yang mengidentifikasi instans alur kerja ini secara unik.

⑥. Selanjutnya, buka halaman manajemen data alur kerja terkait. Anda akan menemukan alur kerja yang baru saja dimulai, dan Konten Teks satu baris tepat sesuai nilai tetap `123` yang kita isi di kode. Semua pengujian dan verifikasi Selesai.

### 5.4 Format data Formulir sebagai nilai kembalian

Format data Formulir sebagai nilai kembalian pada dasarnya sama seperti pada "Lampiran 1 – Format data Simpan/Perbarui formulir". Perbedaannya:

- Saat dikirim, nilai Komponen Wilayah adalah ["ID Provinsi", "ID Kota", "ID Distrik"]. Sebagai nilai kembalian, nilainya adalah ["Nama Provinsi","Nama Kota","Nama Distrik"].
- Pilih, Pilih Tunggal Dropdown, Pilih Banyak, dan Pilih Banyak Dropdown diinternasionalisasi. Sebagai nilai kembalian, keempatnya mengembalikan nilai data yang sesuai dengan parameter `language` yang Anda teruskan.
