## 1. Pendahuluan

### 1.1 Gambaran fitur

Formulir adalah alat dasar di YiDA, dan semua entri serta pengumpulan data bergantung pada formulir. Oleh karena itu, formulir juga menjadi sumber data. **Formulir alur kerja**: memungkinkan data mengalir untuk persetujuan berjenjang. Izin juga dapat ditetapkan untuk mengelola data alur kerja lebih lanjut.

## 2. Titik masuk

**Titik masuk: Edit aplikasi > Manajemen halaman > ➕ > Buat formulir alur kerja.**

  ![](https://gw.alicdn.com/imgextra/i3/O1CN01Db9oMvuYtGG3fDXW_!!6000000007290-2-tps-1805-701.png)

Tersedia lima metode pembuatan: buat dari templat, buat formulir cerdas, buat halaman kosong, buat halaman dengan mengimpor Excel, dan sinkronkan dari DingTalk Base ke formulir.

## 3. Buat formulir biasa

### 3.1 Buat formulir cerdas

Klik **Buat formulir cerdas**, lalu masukkan prompt di Asisten AI, misalnya "Buat formulir alur kerja 'Permintaan kendaraan' yang berisi ID permintaan, tanggal permintaan, tipe kendaraan yang diminta, pemohon, dan alasan permintaan." Setelah menerima prompt, AI akan otomatis membuat formulir yang sesuai.

### 3.2 Buat halaman kosong

- Klik **Buat halaman kosong** untuk membuka halaman kosong di desainer formulir.

### 3.3 Buat halaman dengan mengimpor Excel

1. Klik **Buat halaman dengan mengimpor Excel**.
2. Pilih file Excel (Excel lokal) > Pratinjau data > Pengaturan formulir (pilih tipe data) > Impor data.
3. Setelah impor berhasil, Anda akan diarahkan ke halaman formulir baru.

### 3.4 Sinkronkan dari DingTalk Base ke formulir

1. Klik **Sinkronkan dari DingTalk Base ke formulir** dan konfigurasikan pengaturan sinkronisasi.

2. Popup menampilkan langkah sinkronisasi: pertama pilih dataset, lalu konfigurasikan formulir dan bidang sinkronisasi.
3. Untuk membuat dataset YiDA baru, konfigurasikan base dan tabel spesifik di dalamnya.

**Base yang tersedia:**

- 1. Base di dalam Knowledge Base Organisasi yang izin manajemennya dimiliki oleh pengguna saat ini.

### 3.5 Buat dari templat

- Di daftar templat, pilih sebuah templat dan klik **Gunakan**.
