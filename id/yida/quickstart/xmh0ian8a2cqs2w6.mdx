DingTalk YiDA menyediakan lima cara untuk membuat aplikasi. Artikel ini menjelaskan cara membuat aplikasi kosong.

## Langkah

Ikuti langkah berikut untuk membuat aplikasi kosong.

1. Masuk ke workbench YiDA.
2. Di pojok kanan atas, klik Buat aplikasi.
3. Pada halaman Buat aplikasi, klik Buat aplikasi kosong.
4. Di pojok kiri atas halaman, ganti Nama aplikasi.

<Note>
- Nama aplikasi default adalah Aplikasi tanpa judul.
- Nama aplikasi disimpan secara otomatis saat kotak input kehilangan fokus.
</Note>

Setelah aplikasi dibuat, pilih halaman untuk mulai membangun.
