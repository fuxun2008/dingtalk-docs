## 1. Pendahuluan

### 1.1 Ikhtisar fitur

Formulir merupakan alat dasar di YiDA. Semua pengumpulan dan pelaporan data bergantung pada Formulir, sehingga menjadi sumber data utama. **Formulir biasa**: mengumpulkan semua data yang dihasilkan selama operasional bisnis. Data yang terkumpul juga dapat dibagikan melalui kolaborasi berbasis izin dengan [menerbitkan](/id/yida/form/ulqab1) Izin Data kepada pengguna yang perlu mengelola data, atau kepada pengguna eksternal untuk pengumpulan data eksternal.

## 2. Titik masuk

**Titik masuk: Edit Aplikasi > Manajemen Halaman > ➕ > Buat formulir biasa.**

Anda dapat membuat Formulir dengan lima cara: buat dari templat, buat Formulir cerdas, buat Halaman kosong, impor file Excel untuk membuat Halaman, atau sinkronkan dari DingTalk Base ke Formulir.

## 3. Buat formulir biasa

### 3.1 Buat Formulir cerdas

Klik **Buat Formulir cerdas**, lalu masukkan prompt di Asisten AI, misalnya "Buat Formulir Masukan dengan kolom kepuasan, peringkat, dan komentar masukan." Setelah prompt diterima, AI secara otomatis membuat Formulir yang sesuai.

### 3.2 Buat Halaman kosong

- Klik **Buat Halaman kosong** untuk membuka desainer formulir Halaman kosong.

### 3.3 Impor file Excel untuk membuat Halaman

1. Klik **Impor Excel untuk membuat Halaman**.
2. Pilih file Excel (dari perangkat lokal Anda) > pratinjau data > konfigurasikan Formulir (pilih Tipe data) > impor data.
3. Setelah impor berhasil, Anda akan diarahkan ke Halaman Formulir baru.

### 3.4 Sinkronkan dari DingTalk Base atau Formulir persetujuan DingTalk OA ke formulir biasa YiDA

Contoh berikut menggunakan DingTalk Base:

1. Klik **Sinkronkan dari DingTalk Base ke Formulir** dan konfigurasikan Pengaturan sinkronisasi.

2. Kotak dialog akan menampilkan langkah-langkah sinkronisasi. Pertama pilih dataset, lalu konfigurasikan Formulir target dan kolomnya.
3. Untuk membuat dataset YiDA baru, konfigurasikan base dan Tabel spesifik di dalamnya.

<Note>
**Base yang tersedia:**

- 1. Base di Knowledge Base Organisasi yang izin manajemennya dimiliki pengguna saat ini.
- 2. Base yang dibuat oleh pengguna saat ini di Dokumen Saya.
</Note>

4. Untuk menggunakan dataset YiDA yang sudah ada, lihat **Buat dataset dari DingTalk Data Asset Platform** untuk langkah-langkah rincinya.

<Warning>
**Catatan: jika dataset sudah digunakan oleh sebuah Formulir, dataset tersebut tidak dapat dipilih di sini.**
</Warning>

**Klik di sini untuk melihat dokumentasi lengkap.**

### 3.5 Buat dari templat

- Di Daftar templat, pilih sebuah templat lalu klik **Gunakan**.
