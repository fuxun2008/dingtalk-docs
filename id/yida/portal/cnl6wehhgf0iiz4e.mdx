## 1. Ikhtisar fitur

Anda dapat dengan cepat melihat Metrik Tugas untuk berbagai status proses. **Secara default, data dibaca dari Yida Task Center.**

## **2. Entri fitur**

【Pilih Aplikasi apa saja】——【Edit portal】——【Komponen Metrik Tugas】

## **3. Langkah konfigurasi**

Anda dapat menyesuaikan efek akhir penggunaan komponen dengan mengonfigurasi Atribut Komponen berikut. Setelah menambahkan Komponen Metrik Tugas ke portal, Anda dapat:

### 3.1 Mengganti gaya Komponen

Klik tombol "Ganti Gaya Tampilan" untuk mengganti gaya Komponen sesuai kebutuhan. Saat ini, 3 mode tampilan berikut didukung.

### 3.2 Menyesuaikan bilah Judul

Mendukung pengaturan apakah akan "Menampilkan Judul", mengubah "Nama Judul", mengatur "Tips Bantuan", dan mengaktifkan konfigurasi "Lihat Lainnya". Setelah Diaktifkan, secara default akan mengarahkan ke Yida Task Center.

### 3.3 Mengonfigurasi Konten

Sumber Data Metrik Tugas secara default membaca data yang telah difilter di bawah setiap kategori Yida Task Center. Anda juga dapat mengonfigurasi Atribut berikut:

1. Anda dapat mengontrol apakah status tugas tertentu (Menunggu Tindakan Saya, Dibuat oleh Saya, Diproses oleh Saya, CC Kepada Saya) ditampilkan sesuai kebutuhan.
2. Mendukung konfigurasi Filter untuk Data Tugas berdasarkan "Inisiator, Waktu Inisiasi, Waktu CC, Nama aplikasi, Nama Proses".

## **4. Perhatian**

**Catatan: Hanya 1 Metrik Tugas yang dapat dikonfigurasi per Halaman.**
