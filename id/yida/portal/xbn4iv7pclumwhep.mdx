## 1. Ikhtisar

Unggah beberapa Gambar dan sematkan Tautan di dalamnya. Gambar-gambar tersebut ditampilkan dalam pemutaran berulang.

## **2. Titik masuk**

Pilih aplikasi mana pun → Edit portal → Komponen Carousel

## **3. Langkah konfigurasi**

Sesuaikan perilaku akhir Komponen dengan mengonfigurasi atribut berikut. Setelah menambahkan carousel ke portal, Anda dapat:

### 3.1 Sesuaikan bilah Judul

Kontrol apakah akan "Tampilkan Judul".

### 3.2 Konfigurasikan konten

Konfigurasikan Sumber Data dari carousel. Dua Tipe Sumber Data didukung: dinamis dan statis.

<table>
  <tr>
    <td rowSpan={5}>Sumber Data Dinamis</td>
    <td><ul><li>Sumber konten: Pilih formulir di bawah suatu aplikasi.</li></ul></td>
  </tr>
  <tr>
    <td><ul><li>Gambar carousel: Petakan ke Bidang formulir dasar yang terkait, seperti Bidang Gambar carousel.</li></ul></td>
  </tr>
  <tr>
    <td><ul><li>URL Tautan: Petakan ke Bidang formulir dasar yang terkait, seperti Bidang Tautan.</li></ul></td>
  </tr>
  <tr>
    <td><ul><li>Filter: Setelah memilih formulir, atur kondisi Filter data untuk formulir tersebut.</li></ul></td>
  </tr>
  <tr>
    <td><ul><li>Jumlah tampilan: Atur "Jumlah tampilan" untuk menampilkan jumlah maksimum Gambar carousel yang terlihat secara real time berdasarkan "Jumlah data".</li></ul></td>
  </tr>
  <tr>
    <td rowSpan={3}>Sumber Data Statis</td>
    <td><ul><li>Judul Gambar: Kustom nama Judul Gambar.</li></ul></td>

  <tr>
    <td><ul><li>URL Gambar: Unggah Gambar Kustom.</li></ul></td>
  </tr>
  <tr>
    <td><ul><li>Tautan: Kustom Tipe Tautan. Mendukung pembukaan Halaman internal atau Tautan eksternal.</li></ul></td>
  </tr>
