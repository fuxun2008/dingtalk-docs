## Spesifikasi ukuran gambar:

<Note>
Konfigurasikan gambar secara terpisah untuk setiap platform. Jika hanya mengunggah gambar PC, gambar mobile akan dipotong secara otomatis dari gambar PC.
</Note>

Spesifikasi ukuran PC:

- Untuk mencegah gambar buram, ekspor pada resolusi 3x [5760px\*720px] dan pastikan ukuran file lebih kecil dari 3 MB
- Ratakan "konten efektif" gambar latar (misalnya, teks salinan) di tengah gambar header, dan jaga agar tetap konsisten dengan lebar halaman yang ditetapkan (standar, sedang, atau ekstra lebar)
- Alias: lebar halaman, standar = 1180px; sedang = 1440px; ekstra lebar = 1920px

Spesifikasi ukuran mobile:

- Untuk mencegah gambar buram, ekspor pada resolusi 3x [1125px\*480px] dan pastikan ukuran file lebih kecil dari 3 MB
