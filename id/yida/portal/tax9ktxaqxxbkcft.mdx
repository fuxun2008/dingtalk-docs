YiDA Data Card adalah wadah visualisasi data baru. Berbeda dari laporan yang menyediakan alur kerja analisis lengkap, Data Card dapat menggabungkan grafik terfragmentasi berbasis skenario secara cepat untuk digunakan di portal YiDA. Selain itu, Kartu dilengkapi kemampuan broadcast bawaan sehingga Anda dapat menyinkronkan data sebagai snapshot ke dalam grup.

Untuk ikhtisar Data Card, lihat [Data Card](/id/yida/app-admin/cpkmxvpgchx339qq).

Untuk panduan pembuatan Data Card, lihat [Konfigurasi Kartu](/id/yida/app-admin/nosysc2swtkkph3p).

Untuk panduan penerapan Data Card, lihat [Penerapan Kartu](/id/yida/app-admin/sv1c236glf4ok4nx).
