## 1. Ikhtisar

Unggah ringkasan gambar dan teks dengan cepat untuk ditampilkan sebagai pengumuman.

## **2. Titik masuk**

Pilih aplikasi apa pun → Edit portal → Komponen Papan pengumuman

## **3. Langkah konfigurasi**

Sesuaikan perilaku akhir komponen dengan mengonfigurasikan atribut komponen berikut. Setelah menambahkan Komponen Papan pengumuman ke portal, Anda dapat melakukan hal berikut:

### 3.1 Beralih gaya komponen

Klik tombol "Beralih gaya tampilan" untuk mengganti gaya komponen sesuai kebutuhan. Saat ini tersedia 4 gaya tampilan berikut.

### 3.2 Sesuaikan batang judul

Kontrol apakah akan "Tampilkan Judul", ubah "Nama judul", atur "Tips bantuan", dan kontrol apakah akan mengaktifkan konfigurasi "Lihat Lainnya". Jika diaktifkan, atur URL pengalihan untuk "Lihat Lainnya".

### 3.3 Konfigurasikan konten

#### 3.3.1 Konfigurasikan Sumber data pengumuman

Konfigurasikan Sumber data pengumuman. Dua tipe Sumber data didukung: Sumber data dinamis dan Sumber data statis.
