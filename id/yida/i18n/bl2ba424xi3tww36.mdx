## Gambaran umum

<Note>
- Tersedia untuk YiDA edisi China, Edisi Professional (Global), dan Edisi Dedicated (Global).
- Tersedia untuk YiDA edisi Global dengan kapabilitas "Internationalization" disertakan.
</Note>

Internasionalisasi YiDA mendukung 15 bahasa, termasuk Mandarin Sederhana:

- 简体中文: Mandarin Sederhana adalah bahasa default.
- 繁体中文: Mandarin Tradisional - Hong Kong (China)
- 繁体中文（中国台湾）: Mandarin Tradisional - Taiwan (China)
- English: Inggris
- Français: Prancis
- 한국어: Korea
- 日本語: Jepang
- ไทย: Thailand
- Português: Portugis
- Español: Spanyol
- Русский: Rusia
- Tiếng Việt: Vietnam
- Bahasa Melayu: Melayu
- Bahasa Indonesia: Indonesia
- Türkçe: Turki

Tambahkan bahasa-bahasa ini melalui menu **Manajemen Multibahasa** aplikasi.

- Bangun aplikasi multibahasa.

- Bangun Ruang Kerja multibahasa: Ruang Kerja mendukung banyak bahasa. Atur bahasa yang didukung Ruang Kerja dan kelola entri multibahasa untuk portal Ruang Kerja.
- Tingkatkan aplikasi dwibahasa lama: Tingkatkan aplikasi dwibahasa lama (Mandarin dan Inggris) menjadi entri multibahasa.
- Alihkan bahasa aplikasi: Ubah bahasa aplikasi saat runtime.
- Dukungan multibahasa untuk teks platform: Dukungan multibahasa kini tersedia di area berikut saat runtime aplikasi.

## **Bangun aplikasi multibahasa**

### 1) Atur bahasa default

Saat membuat aplikasi, pilih bahasa default. Mandarin Sederhana dan Inggris didukung sebagai bahasa default. Bahasa default:

- Menjadi bahasa default untuk teks yang dimasukkan selama pengembangan aplikasi.
- Ditampilkan saat aplikasi diakses dan tidak ada teks yang diatur untuk bahasa lingkungan saat ini.

<Note>
Setelah dipilih, bahasa default tidak dapat diubah.
</Note>

### 2) Tambahkan bahasa

Buka **Pengaturan Aplikasi** > **Pengaturan Globalisasi** > **Manajemen Multibahasa** > **Pengaturan Bahasa** untuk menambahkan dan mengonfigurasi bahasa yang didukung aplikasi.

- Pengaturan bahasa berlaku untuk seluruh aplikasi.

<Frame>
  ![](https://gw.alicdn.com/imgextra/i3/O1CN01bJnFtE2BtvI5QMHK_!!6000000005945-2-tps-2672-1178.png)

Setelah mengonfigurasi beberapa bahasa, buka **Pengaturan Aplikasi** > **Pengaturan Globalisasi** > **Manajemen Multibahasa** untuk mengelola semua bahasa aplikasi di satu tempat.

- Manajemen terpadu mendukung ekstraksi massal, terjemahan sekali klik, penyuntingan, penghapusan, dan lainnya.
- Grup tingkat aplikasi baru: Pengaturan Aplikasi, Navigasi Halaman, Kartu Data.

- Grup tingkat halaman baru: Formulir, Alur Kerja, Lainnya.

## Tentukan bahasa untuk halaman silent-login

Karena halaman silent-login tidak memiliki informasi masuk pengguna, halaman tersebut tidak dapat mendeteksi preferensi bahasa masuk secara otomatis. Admin dapat menentukan bahasa untuk tautan silent-login dengan cara berikut:

Tambahkan `?__page_lang=` diikuti kode bahasa ke URL silent-login yang telah dibuat untuk menentukan bahasanya.

| Bahasa | Kode bahasa |
|---|---|
| Mandarin Sederhana | zh_CN |
| Mandarin Tradisional - Hong Kong (China) | zh_HK |
| Inggris | en_US |
| Prancis | fr_FR |
| Korea | ko_KR |
| Jepang | ja_JP |
| Thailand | th_TH |
| Portugis | pt_BR |
| Spanyol | es_419 |
| Rusia | ru_RU |

<Note>
Contoh: URL silent-login untuk Formulir "Informasi Produk" adalah https://your-domain.yidaapps.com/o/cpxx-erp

- URL Bahasa Inggris: https://your-domain.yidaapps.com/o/cpxx-erp?__page_lang=en_US
- URL Bahasa Prancis: https://your-domain.yidaapps.com/o/cpxx-erp?__page_lang=fr_FR
</Note>

## Tingkatkan teks Mandarin-Inggris lama ke kapabilitas multibahasa baru

Kapabilitas multibahasa baru YiDA mendukung 15 bahasa internasional, manajemen terpadu tingkat aplikasi untuk teks multibahasa, dan terjemahan sekali klik. Kapabilitas multibahasa juga telah diadaptasi ke seluruh modul YiDA. Aplikasi dwibahasa Mandarin-Inggris lama dapat ditingkatkan ke versi baru.

Hasil peningkatan:

| **Sebelum: Kapabilitas dwibahasa lama hanya mendukung Mandarin dan Inggris** | **Sesudah: Kapabilitas multibahasa baru** |
|---|---|
| • Mendukung Mandarin dan Inggris.<br />• Mendukung manajemen teks multibahasa untuk Formulir dan halaman Kustom. | • Mendukung 15 bahasa internasional, termasuk Mandarin, Inggris, Prancis, Jepang, Korea, Spanyol, Rusia, dan Thailand.<br />• Mendukung manajemen terpadu tingkat aplikasi untuk teks multibahasa.<br />• Mendukung terjemahan teks sekali klik ke beberapa bahasa. |

Titik masuk peningkatan:

- Jika aplikasi berisi entri dwibahasa lama, prompt peningkatan otomatis muncul di lingkungan pengembangan aplikasi.
- Di **Pengaturan Aplikasi** > **Manajemen Multibahasa**, jika aplikasi berisi teks Mandarin-Inggris lama, prompt peningkatan akan ditampilkan.
- Di halaman manajemen multibahasa halaman, jika halaman berisi teks Mandarin-Inggris lama, prompt peningkatan akan ditampilkan.

<Note>
Untuk YiDA edisi China tanpa pembelian edisi Global, kapabilitas dwibahasa baru dan manajemen terpadu tingkat aplikasi untuk teks multibahasa tersedia. Terjemahan sekali klik dan dukungan untuk bahasa lain eksklusif untuk edisi Global.
</Note>
