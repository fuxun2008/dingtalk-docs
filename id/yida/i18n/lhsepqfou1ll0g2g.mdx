## Edisi internasional vs. edisi China untuk penggunaan luar negeri

- **Edisi internasional YiDA**: Dirancang untuk pelanggan luar negeri (anak perusahaan di luar negeri). Edisi ini diterapkan dan menyimpan data di Singapura.
- **Edisi China YiDA (untuk penggunaan luar negeri)**: Dirancang untuk organisasi Tiongkok yang berekspansi ke luar negeri. Edisi ini diterapkan dan menyimpan data di Tiongkok, dengan menambahkan kemampuan internasionalisasi di atas Edisi Professional dan Edisi Dedicated.

## Zona waktu internasional

Zona waktu internasional memberikan dukungan menyeluruh bagi pengguna dalam pengelolaan zona waktu dan waktu.

- Zona Waktu Default mendukung tiga metode konfigurasi: Kustom, keterkaitan data, dan konfigurasi cepat.
- Beberapa format waktu dikonversi secara otomatis berdasarkan zona waktu, misalnya menampilkan perbedaan waktu antara UTC+8 dan UTC-8.
- Format tata letak mencakup tata letak horizontal (zona waktu di kiri, tanggal di kanan) dan tata letak vertikal (zona waktu di atas, tanggal di bawah).

## Akselerasi file global

Fitur akselerasi file global yang telah diperbarui otomatis memilih wilayah penyimpanan file berdasarkan lokasi pengguna, sehingga meningkatkan kecepatan pratinjau dan unggah file. Selain itu, pengaturan berbagi dan transfer file telah dioptimalkan untuk manajemen multi-bahasa dan kebutuhan global.

- Akselerasi file multi-wilayah ditingkatkan untuk mempercepat transfer lintas wilayah.
- Basis data penyimpanan file dipilih otomatis berdasarkan wilayah pengguna, sehingga mengoptimalkan performa pratinjau dan unggah.
- Manajemen multi-bahasa didukung untuk memenuhi kebutuhan bahasa pengguna global.

## Email internasional

Edisi China YiDA memerlukan modul ekstensi kemampuan internasionalisasi, sedangkan edisi internasional sudah menyertakannya secara default. Kotak surat Outlook dan Gmail didukung dan dapat digunakan untuk mengirim email di node Obrolan.

- Untuk membuat akun kotak surat Outlook, dapatkan authorization_code guna menyelesaikan otorisasi.
- Untuk membuat akun kotak surat Gmail, masukkan akun kotak surat dan authorization_code, lalu simpan.
- Konten email dapat menerima parameter formulir atau data Default sistem secara dinamis untuk fleksibilitas yang lebih tinggi.

## Mata uang internasional

Mata uang internasional **mendukung berbagai Mata uang internasional**. Sistem mendukung beragam jenis Mata uang (seperti USD, JPY, dan EUR), dan pengguna dapat memilih Mata uang yang sesuai kebutuhan. Daftar Dropdown Mata uang yang jelas disediakan untuk pemilihan Mata uang yang intuitif dan cepat.

## Melihat hak internasionalisasi

- Di edisi China YiDA, buka **Manajemen platform** > **Informasi dasar** > **Hak internasionalisasi** untuk melihat dan membeli hak tambahan.
- Setelah membeli hak internasionalisasi YiDA, administrator platform dapat membuka **Manajemen platform** > **Informasi dasar** untuk melihat informasi seperti jumlah pengguna berlisensi dan tanggal kedaluwarsa.
