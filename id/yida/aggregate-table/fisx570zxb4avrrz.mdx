Tabel agregat tidak dapat langsung mengoperasikan data formulir. Setelah tabel agregat berhasil dibuat, Anda dapat menggunakan hasil kalkulasinya di formulir, laporan, Integrasi & Otomatisasi, keterkaitan data, formulir terkait, dan skenario lainnya. Selain itu, Anda dapat melihat log perubahan data di halaman detail tabel agregat.

## Saluran untuk menggunakan tabel agregat

Anda dapat menggunakan tabel agregat pada skenario berikut.

| **Saluran** | **Deskripsi** | **Ilustrasi** |
|---|---|---|
| **Keterkaitan data** | Tabel agregat mendukung keterkaitan data pada formulir.<br />• Pada aturan kondisi, pilih bidang judul dari tabel agregat di sisi kanan.<br />• Pada aturan keterkaitan, pilih bidang metrik kalkulasi dari tabel agregat di sisi kanan. | |
| **Formulir terkait** | Tabel agregat mendukung asosiasi data pada formulir terkait. | |
| **Laporan** | Pilih tabel agregat secara langsung sebagai sumber data pada laporan. | |
| **Kartu data** | Pilih tabel agregat secara langsung sebagai sumber data pada kartu data. | |
| **Integrasi & Otomatisasi / Aturan bisnis** | Lakukan query data dari tabel agregat pada Integrasi & Otomatisasi dan aturan bisnis.<br />Catatan: Modifikasi atau penghapusan langsung data tabel agregat tidak didukung. | |
| **Open API** | Lakukan query hasil tabel agregat melalui Open API. | |

## Melihat log operasi data

Untuk membantu Admin melacak sumber kalkulasi dan perubahan data hasil tabel agregat, platform menyediakan fitur log perubahan data. Pada halaman detail tabel agregat, klik tombol **Tampilan** di kolom tindakan pada suatu rekam untuk melihat **log perubahannya**.
