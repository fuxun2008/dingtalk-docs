| Nomor seri | Tidak didukung | Didukung | Didukung | Didukung |

Konfigurasikan nomor seri untuk Formulir melalui [Pengaturan dasar](/id/yida/form/un4nkn).

Setelah nomor seri diaktifkan, sistem otomatis membuat nomor seri baru setiap kali instans formulir dikirimkan.

## 1. Langkah-langkah

### 1.1 Jalur konfigurasi

Halaman formulir >> Pengaturan >> Pengaturan halaman >> Pengaturan dasar >> Buat nomor seri otomatis setelah pengguna mengirim formulir atau alur kerja.

Pengaturan formulir

### 1.2 Edit format nomor seri

Klik **Edit**. Pada kotak dialog format nomor seri, konfigurasikan prefix, format tanggal, panjang minimum sufiks, zona waktu untuk penghitungan tanggal, dan aturan reset sufiks.

Konfigurasikan format nomor seri

### 1.3 Selesaikan konfigurasi

**Catatan**: Setelah mengklik **Konfirmasi** pada kotak dialog format nomor seri, klik juga tombol **Simpan** di bagian **Pengaturan dasar** agar konfigurasi berlaku.

Simpan halaman pengaturan

## 2. Hasil akhir

### 4. Nomor seri sistem dapat ditingkatkan menjadi Komponen nomor seri

Untuk formulir yang sudah mengaktifkan nomor seri sistem, Anda dapat menggantinya dengan Komponen nomor seri sehingga memperluas skenario penggunaannya.

- Klik **Sinkronkan nomor seri sistem formulir**. Setelah nomor seri sistem ditingkatkan menjadi Komponen nomor seri, Komponen tersebut dapat digunakan pada fitur seperti integrasi & otomatisasi. Namun, tindakan ini tidak dapat dibatalkan dan hanya berlaku untuk data baru yang ditambahkan pada formulir saat ini. Selain itu, logika penghitungan nomor seri akan dihitung ulang berdasarkan aturan konfigurasi Komponen. Lakukan dengan hati-hati.

Untuk konfigurasi rinci, lihat [Nomor seri](/id/yida/form/vanx1ycppgpz5rsk) baru.

| **Sebelum peningkatan: Pengaturan formulir > Nomor seri sistem** | **Setelah peningkatan: Desainer formulir > Komponen nomor seri** |
|---|---|

<Accordion title="3.3 Dapatkah saya mengedit nomor seri yang dibuat setelah formulir dikirim pada Edisi Professional?">
  Bidang nomor seri sistem bawaan tidak dapat diedit. Namun, jika nomor seri dibuat oleh sebuah fungsi pada formulir alur kerja, nomor seri yang dibuat secara sinkron tersebut dapat diedit.
</Accordion>
<Accordion title="3.4 Jika jumlah formulir yang dikirim melebihi panjang minimum sufiks sebelum waktu reset, apakah nomor seri akan dihitung ulang?">
  Tidak. Nomor seri akan otomatis dilanjutkan. Misalnya, jika panjang minimum sufiks diatur ke 1, catatan ke-10 yang dikirim akan otomatis ditampilkan sebagai 10.
</Accordion>
<Accordion title="3.5 Bagaimana cara menyisipkan nomor seri ke dalam Formulir target?">
  Nomor seri hanya dibuat oleh sistem setelah formulir dikirim, sehingga harus diisikan kembali ke dalam bidang formulir. Sisipkan nomor seri ke dalam Formulir target menggunakan salah satu metode berikut:

  Metode 1: Untuk formulir biasa, konfigurasikan [aturan bisnis](/id/yida/form/dssg6y) agar berjalan saat formulir dalam kondisi edit.

  Metode 2: Gunakan [integrasi & otomatisasi](/id/yida/integration/gqmveiswrxkgxu9s) untuk menambahkan data nomor seri ke Formulir target.
</Accordion>
