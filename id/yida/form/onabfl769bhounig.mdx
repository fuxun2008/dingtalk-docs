Fungsi **EXACT** digunakan untuk membandingkan apakah dua string benar-benar identik (case-sensitive).

## Skenario produk yang didukung

Fungsi EXACT didukung dalam skenario berikut di YiDA.

- Formulir (kolom tabel utama)
- Formulir (aturan asosiasi bisnis)
- Formulir (validasi)
- Desain alur kerja (aturan validasi)
- Integrasi & otomatisasi
- Alur kerja - Node
- Konektor

## Format

```text
EXACT(value1,value2)
```

## Deskripsi atribut

| **Atribut** | **Wajib** | **Deskripsi** |
|---|---|---|
| value1 | Ya | String yang akan dibandingkan. |

## Nilai kembalian

| **Tipe nilai kembalian** | **Deskripsi** |
|---|---|
| boolean | Hasil perbandingan.<br />• **true**: Sepenuhnya identik.<br />• **false**: Berbeda. |

## Contoh penggunaan

Seperti ditunjukkan pada gambar di bawah, gunakan fungsi `EXACT()` untuk menentukan apakah nilai yang dimasukkan pengguna adalah `Hangzhou`.

## Coba sekarang

Mengembalikan true jika kedua string benar-benar identik, jika tidak mengembalikan false.
