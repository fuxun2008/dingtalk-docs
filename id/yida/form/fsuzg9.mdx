Komponen Teks satu baris menerima input numerik seperti nomor KTP, nomor telepon, NIM, nomor induk karyawan, nomor kartu bank, dan nomor keanggotaan. Komponen ini juga menerima teks biasa.

</Note>

## Fitur dasar

Mendukung pemindaian Kode QR, penghitung karakter, penghapusan sekali klik, dan pengalihan halaman tingkat lanjut.

### Pemindaian Kode QR

#### Mode pemindaian

> Panggil fitur pemindaian DingTalk untuk menangkap data Kode QR atau barcode dengan cepat ke komponen Teks satu baris.
> 
> Umumnya digunakan untuk skenario yang memerlukan input berbasis pemindaian, seperti inspeksi perangkat dan inventarisasi aset.

Mode pemindaian

**Hasil:**

**Catatan:** Mode ini hanya didukung di aplikasi seluler DingTalk. Setelah diaktifkan, mengetuk tombol pindai di lingkungan yang tidak didukung akan menampilkan pesan yang meminta pengguna untuk membukanya di DingTalk. Hal ini tidak memengaruhi penggunaan komponen dasar.

#### Tipe pemindaian

**Tipe pemindaian yang didukung:** `Semua`, `Hanya Kode QR`, `Hanya barcode`.

**Semua:** Satu kontrol dapat mengenali `Kode QR` dan `barcode`.

Mendukung pemilihan gambar dari album untuk pengenalan.

#### Izinkan modifikasi hasil pemindaian

Secara default, hasil pemindaian dapat diedit. Jika opsi larangan modifikasi hasil pemindaian diaktifkan, output pemindaian tidak dapat diedit.

## Penggunaan tingkat lanjut

Informasi dari pemindaian Kode QR atau barcode dapat digabungkan menjadi tautan untuk memicu pengalihan halaman.

Sebagai contoh, ini berlaku untuk skenario seperti pemindaian untuk melihat detail produk atau pemindaian untuk memesan makanan.

Hasil:

**Jalur:** Teks satu baris >> Premium >> Buat sebuah tindakan dan konfigurasikan URL tetap.

**Contoh:** Saat menulis JS untuk tindakan baru, konfigurasikan URL tetap. Setelah pemindaian berhasil, informasi yang ditangkap akan diteruskan sebagai parameter URL untuk mengalihkan ke URL tetap yang telah ditentukan guna melihat detail, sehingga pengalihan halaman otomatis dapat terjadi setelah pemindaian berhasil.

Konfigurasi referensi:

**Catatan:** Perbarui bagian yang disorot dalam kode agar sesuai dengan identifier unik yang ditampilkan di sebelah kanan.

**Identifier unik:** Serupa dengan KTP untuk setiap kontrol. Setiap kontrol memiliki identifier unik yang berbeda.

**Kode JS referensi yang dapat Anda tempel dan gunakan:**

```javascript
export function onScanCodeSuccess(text) {
  const fieldId = 'editorField_klbopk6r';
  // Jika teks tidak diawali dengan http atau https, jangan tampilkan teks di bawah ini.
  if (!/^http(s)/.test(text)) {
    this.$(fieldId).setValue(null);
    return text;
  }
  const html = `<div><span style="color: #0089ff;"><a style="color: #0089ff;" href="${text}" target="_blank">Klik untuk melihat rekaman keterlacakan</a></span></div>`;
  // Tetapkan nilai
  this.$(fieldId).setValue(html);
  // Catatan: peristiwa onScanCodeSuccess harus mengembalikan text; jika tidak, nilai tidak akan terisi dengan benar.
  return text;
}
```
