## 1. Pengenalan debugging komponen

Debugging di aplikasi Yida mengacu pada **proses menemukan dan menyelesaikan masalah pada komponen kustom agar fungsinya lebih sesuai dengan kebutuhan bisnis Anda**. Debugging komponen kustom mencakup dua mode: **basic debugging** dan **app integration debugging**.

## 2. Basic debugging

Pada desainer komponen low-code, klik Pratinjau untuk menguji konfigurasi atribut sederhana seperti teks, boolean, dan angka. Ubah nilai atribut untuk melihat efeknya secara real time.

Gambar 2.1-1 Basic debugging pada sebuah komponen

<Warning>
Gunakan mode app integration debugging pada skenario berikut:

1. Semua atribut dan konfigurasi yang terkait dengan fungsi tidak dapat diuji dalam mode basic debugging.

2. Komponen yang terkait dengan data Organisasi atau Aplikasi, seperti unggah Gambar atau pemilih orang, tidak dapat diuji dalam mode basic debugging.
</Warning>

## 3. App integration debugging

Selama pengembangan komponen kustom, setiap konfigurasi yang terkait dengan `function` harus di-debug melalui **app integration debugging**. Cakupannya meliputi peninjauan nilai kembalian dan pencetakan output dari kode `console.log()` di dalam fungsi.

**Prosedur:**

1. Buat aplikasi uji.
2. Buka App Settings >> Component Management >> temukan komponen yang telah Anda kembangkan >> klik Instal >> pilih "0.1.0 (development version, component changes sync in real time)" >> klik Instal. (Lihat Gambar 3.1-1)

Gambar 3.1-1 Menginstal versi 0.1.0 dari komponen

3. Setelah instalasi selesai, buka desainer halaman, klik panel komponen, pilih Custom Components, lalu tarik komponen yang baru diinstal ke desainer halaman. Setiap perubahan pada desainer komponen akan langsung tercermin di desainer halaman secara real time. (Lihat Gambar 3.1-2)

Gambar 3.1-2 Diagram app integration debugging untuk sebuah komponen

<Warning>
1. Jangan lakukan debugging komponen di aplikasi Produksi yang sudah Live, karena dapat memengaruhi lingkungan produksi.
2. Jika komponen Anda tidak muncul di panel custom components, periksa apakah Cakupan instalasi telah diatur dengan benar.
</Warning>
