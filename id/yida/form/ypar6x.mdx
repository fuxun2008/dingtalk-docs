## 1. Kasus penggunaan

Cocok untuk skenario yang memerlukan pemilihan dua tanggal, seperti permintaan cuti, periode perjalanan dinas, atau waktu pemrosesan layanan.

<Note>
Untuk atribut Komponen, penggunaan, dan contoh, lihat [**Antarmuka komponen**](/zh/open/yida/components/interface).
</Note>

### 2.2 Menetapkan waktu tetap (nilai Default)

Tetapkan nilai tetap untuk rentang tanggal. Setelah Default diatur, komponen rentang tanggal langsung menampilkan Default yang telah dikonfigurasi. (Meskipun Default sudah diatur, tanggal tetap dapat dipilih secara manual.)

**Jalur**: Atribut >> Default

Saat mengatur Default, format bawaannya adalah "Tahun-Bulan-Hari 00:00:00", tetapi tampilan aktual Komponen mengikuti "Format" yang dikonfigurasi.

## 3. Penggunaan lanjutan

### 3.1 Menghitung selisih tanggal

Hitung selisih antara dua tanggal yang dipilih pada rentang tanggal, lalu isikan hasilnya ke Komponen numerik.

#### 3.1.1 Langkah konfigurasi

1) Pada halaman desain formulir atau formulir alur kerja, seret Komponen rentang tanggal dan Komponen numerik ke kanvas.

2) Klik Komponen numerik, lalu pilih pengeditan Formula pada bagian Default di sebelah kiri.

3) Klik Edit Formula >> pilih Fungsi waktu >> pilih Fungsi CASCADEDATEINTERVALV2. Lihat gambar di bawah untuk konfigurasi terperinci:

### 3.2 Fungsi nonaktifkan tanggal

Gunakan Fungsi kustom untuk menentukan rentang yang dapat dipilih pada rentang tanggal (mirip dengan pengaturan kustom Komponen tanggal). Cocok untuk skenario reservasi.

**Jalur**: Atribut >> Fungsi nonaktifkan tanggal >> Ikat tindakan

#### 3.2.1 Langkah konfigurasi dan contoh untuk Fungsi nonaktifkan tanggal

Agar tanggal antara 2021-04-16 hingga 2021-04-30 tidak dapat dipilih, lihat konfigurasi berikut:

Klik Ikat tindakan >> Pilih Page JS >> Klik Tambah tindakan baru >> Klik Konfirmasi.

Setelah mengklik Konfirmasi, layar berikut akan muncul. Ikuti jalur di bawah ini:

Kode berikut tersedia untuk referensi (salin langsung):

```javascript
export function disabledDate(current) {
  // Periksa apakah tanggal berada di antara 2021-02-11 dan 2021-02-17
  if (current >= new Date('2021-02-11 00:00:00') && current < new Date('2021-02-18 00:00:00')) {
    // Kembalikan true untuk menonaktifkan
    return true;
  }
  return false;
}
```

## 4. FAQ

### 4.1 Mengapa waktu diatur ulang saat saya mengubah tanggal?

Ketika format diatur ke "Tahun-Bulan-Hari-Jam-Menit" atau "Tahun-Bulan-Hari-Jam-Menit-Detik", opsi "Atur Ulang waktu setiap kali memilih tanggal" akan muncul di panel Atribut, seperti ditunjukkan di bawah ini:

Fitur ini dinonaktifkan secara default. Ketika dinonaktifkan, mengubah tanggal akan mempertahankan nilai "Jam-Menit" yang asli. Ketika diaktifkan, "Jam-Menit" akan diatur ulang ke "00:00" setiap kali tanggal diubah.

Perilaku ini sejalan dengan FAQ untuk format tampilan Komponen tanggal. Untuk detailnya, lihat [**Komponen tanggal**](/id/yida/form/alex84) dan rujuk bagian FAQ format tanggal.
