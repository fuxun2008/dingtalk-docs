## 1. Pengantar

### 1.1 Apa itu Teks Kaya

Editor Teks Kaya (Multi-function Text Editor), atau MTE, adalah editor teks WYSIWYG yang dapat disematkan di browser.

**Catatan: Komponen Teks Kaya yang baru telah menghapus fitur konfigurasi umum.**

### 1.2 Kasus penggunaan

- Ketika komponen Teks formulir Yida standar tidak dapat memenuhi kebutuhan teks yang kompleks untuk penataan gaya, tata letak, atau konfigurasi.
- Ketika mengoptimalkan gaya blok teks berukuran besar.
- Ketika pengguna perlu menyesuaikan Konten teks (DIY) dan mengunggah seluruh blok teks bergaya.

#### 2.2.1 Editor

Editor Teks Kaya konsisten dengan editor DingTalk Docs. Gunakan tombol keyboard `/`, simbol, atau ikon `+` pada halaman untuk memilih Konten yang ingin Anda Sisipkan dengan cepat. Kemampuan berikut juga didukung:

- Sisipkan Konten yang lebih kaya seperti gambar lokal atau jarak jauh, emoji, blok sorotan, dan video online.
- Sisipkan gaya tata letak seperti kolom, garis horizontal, dan kutipan di dalam editor.
- Sisipkan to-do untuk mendukung skenario di mana pengguna menyelesaikan tugas.

<Note>
**Catatan:**

1. Satu bidang Teks Kaya mendukung penyisipan beberapa tabel.
2. Anda dapat menyalin dan menempelkan data tabel dari Excel ke dalam bidang Teks Kaya **(kami menyarankan untuk menempelkan tidak lebih dari 100 baris sekaligus)**.
3. Secara default, Anda dapat menyisipkan tabel 10×10. Gunakan tombol baris dan kolom bawaan pada bidang Teks Kaya untuk menambahkan baris atau kolom.
4. Saat ini tidak ada batasan jumlah baris atau kolom, tetapi kami menyarankan maksimal 100 baris. Melebihi 100 baris, penambahan baris atau kolom menjadi lebih lambat dan memengaruhi kinerja.
5. Untuk kumpulan data besar, kami menyarankan penggunaan file Excel asli ditambah Lampiran untuk menampilkan data tabel.
</Note>
