## 1. Skenario penggunaan

Komponen Siswa digunakan pada skenario kampus K12 yang memerlukan pemilihan siswa, seperti penghargaan pengakuan siswa atau statistik nilai siswa.

## 2. Fitur dasar

### 1.2.1 Mode Pilih Banyak

Mendukung pemilihan beberapa siswa sekaligus. Jika hanya perlu memilih satu siswa, matikan tombol ini.

### 1.2.2 Pengisian data otomatis

Pengisian data otomatis memasukkan data dasar siswa yang dikelola di aplikasi Profil Siswa sekolah ke dalam Komponen aplikasi YiDA, sehingga data formulir dibuat secara otomatis.

- Fitur ini hanya tersedia saat Komponen Siswa berada dalam mode Pilih tunggal. Pengisian data otomatis tidak didukung dalam mode Pilih Banyak.
- Informasi atribut siswa dapat diisikan ke kolom yang sudah ada maupun kolom baru pada formulir.

- Informasi kartu identitas yang dikelola di Profil Siswa saat ini belum dapat digunakan untuk pengisian data otomatis.

## 3. Sumber data

Menggunakan data master ID dan nama siswa dari Kontak Sekolah.

## 4. Cakupan pengguna yang dapat dipilih

| **Peran** | **Cakupan yang dapat dipilih** |
|---|---|
| Admin / Sub Admin | Semua informasi siswa |
| Wali kelas / Guru | Semua informasi siswa |
| Orang tua | Informasi siswa yang terkait di Kontak Sekolah |
