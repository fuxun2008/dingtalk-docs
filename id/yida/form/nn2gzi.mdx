## Ringkasan fungsi

| **Nama fungsi** | **Deskripsi** |
|---|---|
| [COUNT](/id/yida/form/ygcgwobc4tewnmxr) | Menghitung total data yang diajukan untuk formulir tertentu. |
| [ADD](/id/yida/form/chzvqqza7lig19gk) | Menghitung jumlah dari beberapa nilai bidang. |
| [AVERAGE](/id/yida/form/cmntz03rxr7lvg8i) | Mengembalikan rata-rata aritmetika dari sekumpulan nilai numerik. |
| [MAX](/id/yida/form/hrmegrov95qkft01) | Mengembalikan nilai maksimum dari sekumpulan angka. |
| [MIN](/id/yida/form/tzmz5prxfk1m6ooo) | Mengembalikan nilai minimum dari sekumpulan angka. |
| [ABS](/id/yida/form/nqxuge2x337g5r7u) | Mengembalikan nilai absolut dari angka negatif. |
| [ROUND](/id/yida/form/gzx4fgcgya1g7dzv) | Membulatkan angka ke jumlah tempat desimal yang ditentukan. |
| [CEILING](/id/yida/form/pfdukipqlw5rko8s) | Membulatkan angka parameter ke atas (menjauhi nol) ke kelipatan terdekat dari basis yang ditentukan. |
| [FLOOR](/id/yida/form/gkzdswxg4g18443y) | Membulatkan angka parameter ke bawah (menuju nol) ke kelipatan terdekat dari signifikansi yang ditentukan. |
| [INT](/id/yida/form/qht3on9d40988egd) | Membulatkan angka ke bawah ke integer terdekat. |
| [LOG](/id/yida/form/bunl3zq1z68guymc) | Mengembalikan logaritma dari suatu angka ke basis yang ditentukan. |
| [MOD](/id/yida/form/smcm971lepq2nv6o) | Mengembalikan sisa dari pembagian dua Komponen numerik. |
| [POWER](/id/yida/form/biskll33337npp7d) | Menghitung hasil pemangkatan Komponen numerik. |
| [FIXED](/id/yida/form/an1t8blpsi4aue68) | Membulatkan angka ke jumlah tempat desimal yang ditentukan, memformatnya dalam notasi desimal, lalu mengembalikan hasilnya sebagai angka. |
| [SQRT](/id/yida/form/ngysm1kw31gkmbqh) | Mengembalikan akar kuadrat positif dari nilai Komponen numerik. |
| [SUM](/id/yida/form/ab2ef6nzxozn0xfe) | Menjumlahkan semua angka yang diberikan sebagai parameter dan mengembalikan hasilnya. |
| [PRODUCT](/id/yida/form/wu3xhb5ve6v0tvci) | Mengembalikan hasil bertipe floating-point presisi ganda. |
| [SUMPRODUCT](/id/yida/form/zrgy7twy6d9ry6ey) | Mengalikan elemen-elemen yang bersesuaian dalam array yang diberikan, lalu mengembalikan jumlah dari hasil perkalian tersebut. |
| [LARGE](/id/yida/form/rnyume8c4kkywdpg) | Mengembalikan nilai terbesar ke-k dalam sebuah kumpulan data. |
| [SMALL](/id/yida/form/kruy97m10v8mt3mt) | Mengembalikan nilai terkecil ke-k dalam sebuah kumpulan data. |

## Skenario umum

### Hitung jumlah total dari beberapa baris item

- Dalam skenario penggantian biaya pembelian, beberapa kategori sering kali diganti sekaligus. Untuk menghitung jumlah total dari semua baris item, ikuti langkah-langkah berikut:

(1) Tambah Komponen subformulir ke Formulir (Terkonfigurasi dengan harga satuan, kuantitas, dan jumlah), lalu tambahkan Komponen Numerik atau Teks satu baris di luar subformulir.

(2) Pada Komponen jumlah di dalam subformulir, Konfigurasikan `Subform.Unit price * Subform.Quantity`. Kemudian, pada Komponen Numerik atau Teks satu baris di luar subformulir, Konfigurasikan `SUM(Subform.Amount)`.
