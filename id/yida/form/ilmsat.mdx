Yida memungkinkan Anda mengeluarkan data konten formulir ke kertas atau media fisik lainnya melalui printer. Misalnya, cetak laporan pengeluaran atau formulir permohonan, lalu serahkan kepada manajer atau tim keuangan Anda untuk keperluan arsip.

## Mencetak satu rekaman

Ikuti langkah-langkah berikut untuk mencetak formulir.

1. Masuk ke workbench Yida dan buka halaman detail aplikasi.
2. Temukan formulir yang ingin Anda cetak, lalu klik **Manajemen data**.
3. Temukan rekaman formulir yang ingin dicetak, lalu klik untuk membuka halaman detail.
4. Di sudut kanan atas, klik **···** > **Cetak**, lalu pilih templat cetak.

5. Pilih **Tanda tangan file**, **Cetak langsung**, atau **Unduh**.

## Melihat riwayat cetak

1. Masuk ke workbench Yida dan buka halaman detail aplikasi.
2. Pilih formulir target, lalu klik **Manajemen data**.
3. Pada halaman **Manajemen data**, klik **Lainnya** > **Log Aktivitas**.

4. Klik **Riwayat cetak** untuk melihatnya.

## Cetak massal

Perbedaan antara cetak massal dan cetak satu rekaman:

- Mencetak beberapa rekaman formulir sekaligus.
- Mengunduh satu file cetak menghasilkan satu file PDF secara default.
- Mengunduh file cetak massal menghasilkan arsip ZIP yang berisi semua file cetak secara default.
- Anda dapat memilih hingga 100 rekaman per cetak massal.

Untuk melakukan cetak massal, ikuti langkah-langkah berikut:

1. Masuk ke workbench Yida dan buka halaman detail aplikasi.
2. Temukan formulir yang ingin Anda cetak, lalu klik **Manajemen data**.
3. Pilih beberapa rekaman yang akan dicetak, lalu klik **Lainnya** > **Cetak yang dipilih**.

**Catatan:**

Pada tab **Semua data** terdapat empat sub-tab: **Tugas saya**, **Ditangani oleh saya**, **Dibuat oleh saya**, dan **CC ke saya**. Tipe data halaman yang tersedia untuk difilter di setiap sub-tab ditampilkan pada tabel berikut. Beralih antara formulir atau alur kerja yang berbeda untuk mencetak data pada halaman terkait.

| **Sub-tab** | **Tipe halaman yang difilter** |
|---|---|
| Tugas saya | Instans alur kerja |
| Ditangani oleh saya | Instans alur kerja |
| Dibuat oleh saya | Instans formulir, instans alur kerja |
| CC ke saya | Instans alur kerja |
