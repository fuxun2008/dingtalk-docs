## 1. Skenario penggunaan

Komponen Pengguna mengambil data pengguna dari DingTalk Contacts dan digunakan setiap kali Anda perlu memilih orang, misalnya saat menetapkan pemohon perjalanan dinas, pemilik aset, atau staf pemeliharaan. Komponen ini juga dapat dikombinasikan dengan [**Formula**](/id/yida/form/vwncwe) dan digunakan pada formulir alur kerja untuk menetapkan approver, misalnya ketika inisiator memilih approver secara manual.

<Note>
Untuk atribut, penggunaan, dan contoh komponen, lihat [**dokumentasi komponen**](/zh/open/yida/components/interface).
</Note>

## 2. Fitur dasar

### 2.1 Mode Pilih Banyak

Izinkan pemilihan beberapa pengguna. Matikan tombol ini jika hanya satu pengguna yang boleh dipilih.

Mode Pilih Banyak

### 2.2 Pengguna default

Tetapkan pengguna tertentu sebagai nilai default agar muncul secara otomatis pada halaman pengiriman.

Atur nilai default

Saat status pengguna adalah Standar, pengguna default dapat dihapus dan pengguna lain dapat dicari serta dipilih.

Saat status pengguna diatur ke Hanya Baca, komponen tidak mengizinkan pemilihan pengguna dan hanya dapat dilihat.

### 2.3 Tampilkan ID Karyawan

Tentukan apakah ID Karyawan ditampilkan setelah nama setiap pengguna. Secara default, ID Karyawan yang ditampilkan di sini adalah UserID karyawan.

Tampilkan ID Karyawan

### 2.4 Mode Pencarian Lanjutan (komponen Pengguna baru)

Saat Anda menggunakan komponen Pengguna Yida pada klien desktop DingTalk atau di browser web, fitur Pencarian Lanjutan yang baru mendukung pemilihan pengguna berdasarkan struktur pohon Kontak serta penelusuran organisasi.

Entri pemilihan pengguna lanjutan diaktifkan secara default pada klien desktop. Klik untuk membuka dialog yang menampilkan halaman pemilihan pengguna secara Penuh.

#### 2.4.1 Skenario penggunaan

- Cari dan pilih pengguna target dengan menelusuri hierarki pohon Kontak organisasi.

## 3. Kombinasi Formula

Ada banyak cara penggunaan, misalnya mengambil nama inisiator, ID Karyawan, atau Departemen secara otomatis. Lihat dokumen [**Fungsi Lanjutan**](/id/yida/form/vwncwe) untuk detailnya.

### 3.1 Dapatkan nama pengguna yang sedang masuk

Lihat formula [**GETUSERNAME**](/id/yida/form/vwncwe).

### 3.2 Dapatkan pengguna yang sedang masuk atau atasannya

Lihat formula [**USER**](/id/yida/form/vwncwe).

## 4. Catatan

1. Komponen Pengguna dapat memilih pengguna dari seluruh Perusahaan, tetapi secara default hanya pengguna dari Departemen saat ini yang ditampilkan. Gunakan fitur Cari untuk memilih pengguna dari departemen lain.
2. Karena keterbatasan container, komponen ini tidak dapat memilih pengguna saat digunakan di dalam iframe pada klien seluler DingTalk, karena container tidak menyuntikkan JSAPI ke dalam iframe. Hindari penggunaan komponen ini pada skenario tersebut.
