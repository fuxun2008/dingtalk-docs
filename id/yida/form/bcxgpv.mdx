## 1. Komponen Lokasi

### 1.1 Apa itu komponen Lokasi

Pemilih alamat detail berbasis pembagian administratif standar Tiongkok saat ini.

### 1.2 Skenario penggunaan

- Komponen Lokasi kini mendukung positioning pada perangkat mobile, memungkinkan Anda mengisi informasi alamat dengan cepat sekaligus tetap dapat mengeditnya lebih lanjut.
- Jika alamat yang ingin dipilih kebetulan merupakan lokasi Anda saat ini, ketuk ikon positioning pada perangkat mobile (dengan izin lokasi diaktifkan). Informasi alamat akan terisi otomatis dan tetap dapat diedit setelahnya.
- Umum digunakan pada skenario pemilihan alamat, seperti alamat pengiriman dan alamat wilayah administratif.
- Komponen telah dilengkapi dengan data terbaru Provinsi / Kota / Distrik (Kabupaten) / Jalan (Kecamatan) Tiongkok. Cukup tambahkan komponen Lokasi untuk mulai menggunakannya.

## 2. Atribut

### 2.1 Tips placeholder

- Mirip dengan teks placeholder abu-abu dalam kotak input standar, digunakan untuk memberikan panduan.
- Jika tidak ada alamat default yang ditetapkan, tips placeholder akan ditampilkan. Jika sudah ditetapkan, konten alamat default akan ditampilkan terlebih dahulu.

## 4. FAQ

<AccordionGroup>
<Accordion id="q1" title="4.1 Komponen Lokasi saat ini menampilkan nama lokasi. Adakah cara untuk memperoleh informasi bujur dan lintang?">
  YiDA saat ini belum mendukung pengambilan bujur dan lintang pada komponen Lokasi. Sebelumnya, bujur dan lintang tersedia pada komponen Positioning. Komponen Lokasi saat ini hanya menyediakan kode wilayah, dan bujur serta lintang belum dapat diperoleh.
</Accordion>
<Accordion id="q2" title="4.2 Apakah garis miring pada kontrol Lokasi dapat dihilangkan? Ketika data diekstrak dan digabungkan ke bidang Teks satu baris, apakah garis miring dapat dihilangkan otomatis, misalnya menggunakan JS?">
  Setelah memperoleh informasi wilayah, Anda dapat menggunakan JS untuk memproses hasilnya dan menetapkannya ke bidang Teks satu baris untuk menghilangkan tanda "/".

  ```javascript
  // Kode referensi (terhubung ke komponen Lokasi)
  export function onChange({ value }, extra) {
    if (value.regionText) {
      let allAddress = '';
      value.regionText.map(el => {
        allAddress += el.zh_CN
      })
      allAddress += value.address
      this.$('textField_kr49k4ug').setValue(allAddress)
    }
  }
  ```
