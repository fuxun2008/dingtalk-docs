## 1. Kasus penggunaan

Komponen Kelas berlaku untuk skenario kampus K12 yang memerlukan pemilihan kelas.

## 2. Fitur dasar

### 2.1 Mode Pilih Banyak

Pilih beberapa kelas sekaligus. Untuk mengizinkan pemilihan hanya satu kelas, matikan tombol ini.

| **Mode desain formulir** | **Mode runtime formulir** |
|---|---|

### 2.2 Pengisian data

Pengisian data mengisi Atribut dasar suatu kelas ke dalam Komponen di aplikasi Yida untuk secara otomatis membuat data formulir. Atribut kelas mencakup:

- Kampus
- Jenjang akademik
- Tahun masuk

| **Mode desain formulir** | **Mode runtime formulir** |
|---|---|

## 3. Sumber data

Menggunakan master data kelas terpadu dari kontak sekolah.
