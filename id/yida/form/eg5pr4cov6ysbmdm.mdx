Tombol tindakan pada halaman daftar manajemen data merupakan tindakan konfigurasi manajemen untuk konten detail data. Atur item tindakan kustom sesuai kebutuhan bisnis.

## **Langkah**

1. Masuk ke workbench Yida dan klik My Apps.
2. Pilih aplikasi yang ingin diedit, lalu klik untuk masuk ke halaman Kelola Aplikasi.
3. Pilih formulir target, lalu klik Generate data management page.

| **Atribut** | **Deskripsi** |
|---|---|
| **Nama tindakan** | Nama kustom untuk tombol kolom tindakan. Maksimal 20 karakter. |
| **Tautan pengalihan** | Mendukung dua jenis pengalihan berikut:<br />• **Halaman dalam aplikasi**: Klik kotak input untuk memilih halaman di dalam aplikasi.<br />• **Tautan eksternal**: Tautan eksternal kustom. Cukup masukkan URL. |
| **Parameter kustom** | Tautan pengalihan mendukung konfigurasi parameter kustom, yang mendukung tiga jenis parameter berikut.<br />• **Konstanta**: Gunakan konstanta untuk menetapkan nilai tetap bagi parameter yang dibawa saat tautan dialihkan.<br />• **Bidang**: Pilih Bidang formulir dari formulir manajemen data saat ini.<br />• **Formula**: Mendukung penetapan parameter menggunakan Formula. Untuk cara menggunakan Formula, lihat [Fungsi Formula](/id/yida/form/gvtpe4). |
| **Metode buka** | Metode yang digunakan untuk membuka halaman yang dialihkan setelah pengguna mengklik tombol tindakan.<br />• **Jendela baru**: Buka halaman baru di jendela baru.<br />• **Sidebar**: Buka halaman baru di sisi kanan halaman. |

8. Klik Simpan untuk menyelesaikan konfigurasi.
9. Kembali ke halaman manajemen data untuk melihat tombol tindakan kustom yang telah dikonfigurasi.

Seperti ditunjukkan pada gambar di bawah, tombol kustom berhasil ditambahkan.
