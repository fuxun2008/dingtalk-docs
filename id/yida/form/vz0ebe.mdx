## 1. Pendahuluan

### 1.1 Ikhtisar fitur

YiDA mendukung ekspor massal data dari halaman manajemen data ke Excel. Anda dapat mengkustomisasi rentang data (baris), rentang bidang (kolom), dan format ekspor gambar/lampiran (tautan atau file).

### 1.2 Skenario penggunaan

- Ekspor data yang dibutuhkan dari backend manajemen data untuk arsip atau backup.
- Edit bidang tertentu secara massal melalui ekspor dan impor massal.

## 2. Langkah ekspor

### 2.1 Titik masuk ekspor

1) Sebagai **editor aplikasi**, masuk ke [YiDA workbench](https://www.yidaapps.com/workPlatform) dan buka aplikasi yang datanya ingin diekspor secara massal. Pilih formulir target, buka **halaman manajemen data** terkait, lalu klik tombol **Ekspor**.

<Frame>
  ![](https://gw.alicdn.com/imgextra/i1/O1CN01RrsCpPmlotD3LxN2_!!6000000005819-2-tps-1652-468.png)
</Frame>

2) Sebagai **pengguna aplikasi**, masuk ke [YiDA workbench](https://www.yidaapps.com/workPlatform). Jika memiliki **izin ekspor**, klik tombol **Ekspor**.

<Frame>
  ![](https://gw.alicdn.com/imgextra/i3/O1CN01DlNu7oYV3tG3JgtC_!!6000000004634-2-tps-1634-476.png)
</Frame>

### 2.2 Pilih data yang akan diekspor

#### 2.2.1 Ekspor semua data

1) Pilih formulir yang ingin diekspor, klik **Ekspor**, lalu pilih **Ekspor semua** untuk mengekspor seluruh data.

<Frame>
  ![](https://gw.alicdn.com/imgextra/i4/O1CN016prspt7lQFE3NT3G_!!6000000001215-2-tps-1664-566.png)
</Frame>

#### 2.2.2 Ekspor data terpilih

1) Pada formulir target, pilih satu atau beberapa rekam, lalu klik **Ekspor yang dipilih** untuk mengekspor rekam tersebut.

<Frame>
  ![](https://gw.alicdn.com/imgextra/i3/O1CN01BCRbzNysb0L3Oj64_!!6000000007101-2-tps-1674-562.png)
</Frame>

**Tip: Gunakan filter untuk mempersempit data.**

1) Klik **Filter** untuk membuka panel filter.

2) Klik **Tambah kondisi filter** dan pilih atribut filter dari daftar drop-down. Pilih atribut lalu konfigurasikan kondisinya. Filter aktif ketika atribut yang dipilih memenuhi kondisi yang ditentukan.

<Frame>
  ![](https://gw.alicdn.com/imgextra/i1/O1CN01OhP8u18hvPF3kdB6_!!6000000002933-2-tps-1848-852.png)
</Frame>

3) Tambahkan beberapa kondisi filter dan kombinasikan menggunakan logika **OR/AND**.

<Frame>
  ![](https://gw.alicdn.com/imgextra/i2/O1CN019eqiExgIKmG33ZtK_!!6000000005095-2-tps-1506-456.png)
</Frame>

4) Setelah difilter, pilih rekam yang dibutuhkan lalu ekspor data hasil filter.

### 2.3 Pengaturan ekspor

#### 2.3.1 Pengaturan ekspor

##### Atur urutan bidang

1) Jika memilih opsi 1, **Ikuti urutan bidang manajemen data saat ini**, bidang yang diekspor mengikuti urutan yang ditampilkan pada halaman manajemen data.

2) Jika memilih opsi 2, **Ikuti urutan bidang formulir**, bidang yang diekspor mengikuti urutan yang didefinisikan pada formulir.

3) Jika memilih opsi 3, **Seret untuk mengurutkan**, bidang yang diekspor mengikuti urutan yang diatur dengan menyeret.

<Frame>
  ![](https://gw.alicdn.com/imgextra/i3/O1CN01iQvXIVTIoIE4Sgqe_!!6000000007867-2-tps-2198-1042.png)
</Frame>

##### Atur rentang bidang

Mengatur rentang bidang berarti memilih kolom yang ingin diekspor sehingga bidang yang disertakan dapat dikustomisasi.

1) Masukkan kata kunci pada kolom input untuk **mencari bidang secara real time**, seperti ditunjukkan di bawah ini:

<Frame>
  ![](https://gw.alicdn.com/imgextra/i3/O1CN01mUibYNzUD3G3MD3A_!!6000000000497-2-tps-1654-738.png)
</Frame>

2) Atau, gunakan kotak centang di sebelah kiri untuk memilih bidang. Hanya bidang yang dipilih yang akan diekspor. Misalnya, jika hanya memilih Status perangkat dan Nama perangkat, file yang diekspor hanya berisi dua kolom tersebut.

<Frame>
  ![](https://gw.alicdn.com/imgextra/i4/O1CN011GOTe1IvZVG1gzCe_!!6000000007358-2-tps-834-546.png)
</Frame>

#### 2.3.2 Pengaturan lainnya

##### Ekspor gambar/lampiran

**1) Jika tidak memilih "Ekspor bidang gambar/lampiran sebagai file":**

- Gambar dan lampiran disimpan sebagai tautan online di Excel. Data disimpan sebagai URL, cocok untuk skenario kolaborasi bisnis eksternal, seperti mengirim daftar produk atau penawaran harga kepada pelanggan. Lihat contoh berikut:

- Jika file berupa gambar, klik tautan untuk pratinjau. Jika file berupa lampiran, klik tautan untuk mengunduh langsung.

**2) Jika memilih "Ekspor bidang gambar/lampiran sebagai file":** file dalam data akan diekspor bersama datanya.

- File yang diekspor dikemas sebagai arsip zip, cocok untuk skenario backup data.
- Alamat gambar/lampiran pada spreadsheet yang diekspor merupakan jalur absolut di dalam arsip zip. Klik jalur untuk membuka file terkait di folder lokal.

<Note>
Lampiran/gambar yang diunduh mempertahankan nama file aslinya — nama yang digunakan saat diunggah. Misalnya, jika file diunggah sebagai IMG_2017, file akan diekspor sebagai "IMG_2017.jpg".

Komponen yang mendukung ekspor lampiran/gambar: Unggah gambar, Lampiran, Templat Word, Tanda tangan, dan Faktur pintar.
</Note>

##### Ekspor ID instance

**Jika memilih "Ekspor ID instance"**, ID instance setiap rekam akan diekspor ke file Excel (mencakup formulir utama dan subformulir). Jika di kemudian hari perlu memperbarui data, ID instance dapat digunakan untuk mencocokkan rekam. Lihat contoh berikut:

1) Setelah mengonfigurasi parameter ekspor, klik **Konfirmasi** untuk memulai ekspor. Progres ekspor akan ditampilkan.

  ![](https://gw.alicdn.com/imgextra/i4/O1CN01uJlI7DlWVJK1bwxg_!!6000000005181-2-tps-794-330.png)

### 2.4 Format data yang diekspor

<Note>
1) Saat mengekspor spreadsheet saja, format ekspor adalah Excel, dengan nama file: **Nama formulir + "_" + stempel waktu tanggal + ekstensi file**. Contoh: Formulir inspeksi peralatan_20250218155439.xlsx.

2) Saat mengekspor data file sekaligus, format ekspor adalah arsip zip, dengan nama file: **Nama formulir + "_" + stempel waktu tanggal + ekstensi file**. Contoh:

- Formulir inspeksi peralatan_20250218152909_resources_1.zip. Setelah diekstrak:

3) Jika data yang diekspor sangat besar, sistem memecah unduhan berdasarkan ukuran data (satu file zip per 100 MB), seperti ditunjukkan di bawah ini:

<Frame>
  ![](https://gw.alicdn.com/imgextra/i2/O1CN01afBzQjpRcfD2khHo_!!6000000007380-2-tps-1356-800.png)
</Frame>

Tip: Jika lampiran satu rekam melebihi 100 MB, lampiran akan dipecah menjadi beberapa subfolder. Aturan penamaannya adalah:

- ID instance
- ID instance (lampiran instance ini terlalu besar dan telah dipecah; harap gabungkan ke folder utama)
</Note>
