Formulir YiDA mendukung impor massal data untuk membantu admin formulir memigrasikan data dengan cepat. Impor massal juga dapat memicu aturan validasi, aturan bisnis, alur integrasi & otomatisasi, notifikasi pesan, dan callback pihak ketiga yang telah dikonfigurasi pada formulir saat data diimpor. Artikel ini menjelaskan cara mengimpor data formulir secara massal.

- Komponen yang didukung: Teks satu baris, Teks multi-baris, pilih satu, dropdown pilih satu, Pilih Banyak, dropdown pilih banyak, unggah gambar, Lampiran, Pengguna, Departemen, Numerik, tanggal, rentang tanggal, subformulir, formulir terkait (tabel utama).
- Komponen yang tidak didukung: tampilan gambar-teks, Teks Kaya, pilih bertingkat, Negara/Wilayah, lokasi, Tanda tangan, formulir terkait (subtabel).
- Data yang diimpor massal ditampilkan sesuai urutan baris pada file Excel.

## Langkah-langkah

Ikuti langkah berikut untuk mengimpor data secara massal.

1. Masuk ke workbench YiDA dan buka layar manajemen halaman aplikasi.
2. Pilih formulir yang datanya ingin diimpor, lalu klik **Manajemen data** > **Impor**.

3. Konfigurasikan aturan impor.

| Opsi aturan impor | Deskripsi |
|---|---|
| Impor dipercepat | Ketika impor dipercepat diaktifkan, sistem mengimpor data Excel Anda dalam batch sehingga waktu impor berkurang secara signifikan. Gunakan opsi ini untuk skenario impor sederhana (tanpa dependensi antar-record).<br />Jangan aktifkan opsi ini untuk skenario kompleks (misalnya, ketika data yang diimpor memerlukan logika pemrosesan hulu atau hilir). |
| Metode impor | Tersedia tiga mode: hanya menambah record, hanya memperbarui record, serta menambah atau memperbarui record.<br />**Catatan**: Formulir alur kerja hanya mendukung penambahan record baru. |
| Aturan impor | Pilih opsi berikut selama impor massal:<br />• **Formulir alur kerja**: Kirim Notifikasi Kerja agar peserta alur kerja menerima notifikasi pesan.<br />• **Formulir biasa**: Picu aturan validasi, aturan bisnis, alur integrasi & otomatisasi, notifikasi pesan, dan callback pihak ketiga. |

4. Unduh templat data formulir dan edit data sesuai contoh.

<Note>
Untuk memastikan impor berjalan lancar, unduh templat terlebih dahulu dan ikuti contoh yang disediakan.
</Note>

5. Unggah file yang akan diimpor massal. Tipe file `.xls` dan `.xlsx` didukung.
6. Setelah unggahan selesai, verifikasi pratinjau data, konfigurasikan pemetaan **Bidang** dan **Pengirim** formulir, lalu klik **Impor** untuk memulai proses impor.

7. Ketika impor selesai, klik **Tutup** untuk menyelesaikan.

## Catatan

Perhatikan hal berikut saat mengunggah file Excel:

- Ukuran file tidak boleh melebihi 10 MB, dan satu sheet tidak boleh berisi lebih dari 5.000 baris.
- Hanya format file `.xls` dan `.xlsx` yang didukung.
- Pastikan header sheet yang ingin diimpor tidak berisi sel kosong; jika ada, sistem tidak akan mengimpor sheet tersebut.
- Pemfilteran data yang diimpor massal berdasarkan variabel bawaan tidak didukung.
- Formula Excel seperti `SUM` atau `=H2*J2` tidak didukung pada file impor.
- Gambar dan lampiran yang diimpor disimpan dan dihitung dalam kuota lampiran Anda.
- Tabel pivot lintas tab tidak dapat diimpor.
