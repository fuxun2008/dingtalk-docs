Dalam beberapa skenario bisnis, Izin tampilan data harus diberikan berdasarkan atribut bisnis, misalnya Wilayah atau Departemen proyek yang menjadi tanggung jawab seorang Pengguna.

Sebelum fitur ini tersedia, satu-satunya cara untuk menangani skenario tersebut adalah mengonfigurasi belasan atau lebih grup izin secara manual dengan "Pengguna Kustom + Kondisi Kustom" sesuai kebutuhan bisnis. Ketika beberapa formulir memerlukan pengaturan izin yang sama, konfigurasi tersebut harus diulang secara manual. Baik pembuatan awal maupun pemeliharaannya sama-sama merepotkan.

Dengan fitur ini, Anda cukup memelihara informasi Dasar dalam matrix izin sekali, lalu mengonfigurasi satu grup izin di pengaturan izin formulir dengan menggabungkan "Referensikan pengguna matrix" dan "Konfigurasikan kondisi matrix".

Berikut detailnya.

## Prasyarat: pelihara matrix izin dan tingkatkan ke tampilan data baru

1. Pelihara matrix izin

Di matrix izin, pelihara kondisi penugasan dan tabel matrix untuk Peran terkait. Ketika tanggung jawab atau Pengguna berubah, perbarui matrix sesuai kebutuhan. Izin data berlaku secara real time setelah pembaruan.

Untuk cara menggunakan matrix izin, [lihat panduan matrix izin](/id/yida/platform-admin/bqc0fgwy5usglvrn).

2. Gunakan tampilan data baru (Fitur ini saat ini dalam gray release. Untuk mengaktifkannya, hubungi tim dukungan Yida.)

Tingkatkan tampilan data ke Versi baru. Entri peningkatan:

Untuk pengenalan tampilan data baru, [lihat dokumentasi pembaruan Yida](https://docs.aliwork.com/docs/yida_updates/hqlg7m5vvlgs0d6k/zmztxwhgl5bbggw4).

## Mereferensikan matrix izin di izin tampilan data formulir

Saat mengonfigurasi grup izin:

- Untuk pengguna izin, Pilih "Dari matrix izin": Pilih matrix target dan Kolom Peran yang mewakili pengguna dalam grup izin saat ini.

- Untuk rentang data, Pilih "Berdasarkan kondisi matrix": gunakan aturan pencocokan kondisi antara kolom formulir dan kolom matrix untuk menentukan rentang data yang terlihat oleh setiap Pengguna.

**Tips:**

Kolom kondisi pada matrix mendukung dua tipe nilai: Departemen atau Teks kustom. Untuk mencegah aturan pencocokan yang salah, pada rilis ini pengaturan kondisi matrix untuk Izin tampilan data hanya mendukung komponen Teks Dasar pada formulir **(Teks satu baris, Teks multi-baris, Pilih, Pilih Banyak, Dropdown Select, Dropdown Multiselect) dan Komponen Departemen**.
