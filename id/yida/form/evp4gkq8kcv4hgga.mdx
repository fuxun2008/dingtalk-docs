Fungsi **XOR** merepresentasikan exclusive OR.

XOR digunakan untuk membandingkan ekspresi logika. Fungsi ini mengembalikan true hanya dalam kondisi berikut.

- Jika tepat satu ekspresi logika bernilai true dan semua ekspresi lainnya bernilai false, fungsi XOR mengembalikan true.

## Skenario produk yang didukung

Fungsi XOR didukung dalam skenario YiDA berikut.

- Formulir (field tabel utama)
- Formulir (aturan asosiasi bisnis)
- Formulir (validasi)
- Desain alur kerja (aturan validasi)
- Integrasi & otomatisasi
- Node alur kerja
- Konektor

## Format

```text
XOR(condition1,condition2....condition.N)
```

## Contoh

Seperti ditunjukkan di bawah, fungsi `XOR()` mengembalikan **true** hanya jika nilai `Numerik 1` lebih besar dari 2 dan nilai `Numerik 2` kurang dari atau sama dengan 2.
