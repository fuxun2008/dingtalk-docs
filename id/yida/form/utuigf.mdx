## 1. Skenario penggunaan

Komponen pemilih kelas cocok untuk skenario kampus K-12 yang memerlukan pemilihan kelas, misalnya evaluasi pendidikan moral kelas.

## 2. Fitur dasar

### 2.1 Mode Pilih Banyak

Pilih beberapa kelas sekaligus. Untuk membatasi pemilihan hanya pada satu kelas, nonaktifkan tombol ini.

| **Tampilan desain Formulir** | **Tampilan runtime Formulir** |
|---|---|
|  |  |

### 2.2 Pengisian data

Pengisian data secara otomatis memasukkan atribut dasar sebuah kelas ke dalam komponen di Aplikasi YiDA untuk menghasilkan data formulir. Atribut kelas mencakup:

- Kampus
- Jenjang sekolah

- Tingkat
- Wali kelas

- Jumlah siswa di kelas
- Tahun masuk

| **Tampilan desain Formulir** | **Tampilan runtime Formulir** |
|---|---|
|  |  |

## 3. Sumber data

Menggunakan data master kelas dari Kontak sekolah.
