## 1. Apa itu halaman manajemen data

Halaman manajemen data adalah ikhtisar agregat yang memudahkan Anda melihat data pengiriman Formulir.

## 2. Skenario penggunaan

Saat Anda perlu mengetahui berapa banyak entri data yang telah dikirim oleh seluruh karyawan di Organisasi Anda, buka halaman manajemen data untuk melihatnya secara langsung.

## 3. Langkah-langkah

**Jalur**: Formulir >> Buat halaman manajemen data di pojok kanan atas >> Beri nama halaman >> Konfirmasi
