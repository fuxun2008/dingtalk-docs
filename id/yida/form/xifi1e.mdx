Halaman formulir YiDA dapat dipublikasikan secara individual. Tersedia dua jenis publikasi: publikasi dalam organisasi dan publikasi publik. Artikel ini menjelaskan cara memublikasikan halaman formulir.

## Publikasikan dalam organisasi

<Steps>
  <Step title="Langkah 1">
    Masuk ke [YiDA workbench](https://www.yidaapps.com/workPlatform).
  </Step>
  <Step title="Langkah 2">
    Klik **My Apps**, pilih aplikasi target, lalu klik untuk membuka halaman detail aplikasi.
  </Step>
  <Step title="Langkah 3">
    Pilih halaman yang ingin dipublikasikan secara individual, lalu klik  > **Publish page**.
  </Step>
</Steps>

4. Klik **Publish within organization**.
5. (Opsional) Salin URL halaman secara langsung untuk digunakan di dalam organisasi Anda, atau sesuaikan URL halaman.

<Note>
- Pengguna di dalam organisasi harus masuk dan memberikan Otorisasi saat mengunjungi halaman.
- Setelah menyesuaikan URL, klik **Save**. Jika tidak, perubahan tidak akan berlaku.
</Note>

## Publikasikan secara publik

<Note>
- YiDA Paket Luang secara default tidak mendukung publikasi publik. Untuk menggunakan fitur ini, tingkatkan YiDA atau selesaikan autentikasi organisasi DingTalk terlebih dahulu.
- YiDA Dedicated mendukung pengambilan informasi identitas dasar pengguna yang telah masuk. Untuk detailnya, lihat Otorisasi untuk mengambil informasi identitas dasar pengguna.
</Note>

Setelah akses publik diaktifkan, pengguna di luar organisasi dapat mengisi formulir tanpa masuk — misalnya, survei anonim. Formulir juga dapat didistribusikan melalui saluran di luar DingTalk. Untuk prosedur publikasi, lihat [Publikasikan halaman formulir secara publik](/id/yida/app-admin/wodcbu).

## Kode QR halaman

Publikasi halaman YiDA mendukung pengunduhan Kode QR akses, sehingga pengguna seluler dapat mengunjungi halaman dengan mudah. Untuk meningkatkan kualitas visual Kode QR, YiDA juga menyediakan templat poster khusus untuk Kode QR halaman. Klik **Poster template library** untuk merancang templat khusus untuk halaman Anda.

## Hal penting yang perlu diperhatikan

Perhatikan hal berikut saat menyiapkan akses publik untuk sebuah halaman.

- Ketika data dikirim atau alur kerja dimulai melalui URL publik, pengirim atau inisiator alur kerja tercatat sebagai **Anonymous**.
- Pemeriksaan keunikan yang dikonfigurasi pada halaman tidak tersedia (artinya, batasan bahwa setiap akun hanya dapat mengirim satu kali tidak berlaku).
- Dengan akses publik diaktifkan, platform tidak membatasi halaman untuk mengakses data di formulir lain dalam aplikasi saat ini. Admin aplikasi sepenuhnya bertanggung jawab atas pengungkapan informasi yang mungkin timbul.
- Setelah akses Login senyap diaktifkan, pengiriman Obrolan Kartu ke individu atau Obrolan Grup tidak lagi didukung.
- Gambar dan lampiran secara default tidak dapat diakses dari luar organisasi. Jika akses eksternal diperlukan, ganti dengan URL CDN yang dapat diakses publik.

## FAQ

- T: Mengapa sistem menunjukkan bahwa URL berbagi sudah digunakan?

URL kustom tidak boleh berisi domain duplikat (termasuk URL yang ditetapkan oleh organisasi lain). Jika URL merupakan duplikat, URL tidak dapat disimpan dan pesan "The share URL is already in use" akan ditampilkan.
