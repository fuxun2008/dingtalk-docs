## 1. Nama file kustom

### 1.1 Apa itu nama file kustom

Nama file cetak dapat disesuaikan. Nama file dapat dibuat dari bidang-bidang berikut:

(1) Pengaju: nama pengguna yang membuat rekam.

(2) Waktu pengiriman/Waktu modifikasi: dalam format YYYY-MM-DD.

(3) Judul instance: judul rekam.

(4) Nomor seri (khusus Edisi Basic dan yang lebih tinggi): tersedia hanya jika fitur nomor seri diaktifkan pada formulir.

(5) Komponen formulir: saat ini hanya **Teks satu baris, Numerik, Radio, Dropdown pilihan tunggal, dan Pengguna** yang didukung. Komponen harus disetel sebagai **Wajib** agar dapat dipilih.

### 1.2 Langkah detail

Aturan nama file cetak berkorespondensi satu-ke-satu dengan templat cetak. Admin dapat mengatur nama file pada templat cetak yang bersangkutan.

**Jalur**: Formulir >> Manajemen Data >> Halaman Detail Data Formulir >> Cetak di pojok kanan atas >> Rekam Cetak >> Unduh >> File yang tersimpan secara lokal menggunakan nama cetak yang telah dikustomisasi.

**Catatan:**

- Nomor seri dapat digunakan sebagai bagian dari nama file hanya jika fitur nomor seri diaktifkan pada formulir.
- Jika komponen yang ditentukan tidak ada pada rekam (misalnya, ketika nomor seri baru diaktifkan tetapi rekam lama belum memilikinya), bagian yang hilang akan digantikan dengan string kosong.
- Hanya komponen yang ditandai sebagai Wajib pada formulir yang dapat digunakan dalam nama file kustom.
