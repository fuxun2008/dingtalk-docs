Fungsi **HASEMPTYTEXT** memeriksa apakah input pengguna, konten file, atau subformulir berisi string kosong.

## Skenario produk yang didukung

Fungsi HASEMPTYTEXT didukung dalam skenario YiDA berikut.

- Formulir (field tabel utama)
- Formulir (field subformulir)
- Formulir (aturan asosiasi bisnis)
- Formulir (validasi)
- Desain alur kerja (aturan validasi)
- Desain alur kerja (aksi asosiasi)
- Integrasi & otomatisasi
- Node alur kerja
- Konektor

## Sintaks

```text
HASEMPTYTEXT(value1)
```

## Atribut

| **Atribut** | **Wajib** | **Deskripsi** |
|---|---|---|
| value1 | Ya | Kotak teks, file, atau kolom subformulir yang akan diperiksa. |

## Nilai kembalian

| **Tipe kembalian** | **Deskripsi** |
|---|---|
| boolean | Apakah berisi string kosong. Nilai:<br />• **true**: berisi string kosong.<br />• **false**: tidak berisi string kosong. |

Seperti ditunjukkan di bawah, fungsi `HASEMPTYTEXT()` menentukan apakah kotak input kosong.
