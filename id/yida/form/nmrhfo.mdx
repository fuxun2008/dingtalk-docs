## 1. Cetak massal

### 1.1 Templat cetak

Pengaturan cetak saat ini hanya didukung pada Edisi Basic dan Edisi Professional. Edisi Gratis tidak mendukung konfigurasi templat cetak.

Pengaturan cetak

### 1.2 Cetak massal

Hasilkan file cetak untuk data yang dipilih berdasarkan templat cetak, lalu unduh semuanya sebagai satu paket.

**Jalur 1**: Manajemen data >> Pilih rekaman yang akan dicetak >> Tindakan lainnya >> Cetak yang dipilih >> Pilih templat cetak >> Konfirmasi.

Pilih templat cetak

Setelah proses pencetakan selesai, sistem akan menghasilkan file PDF.

Lihat data cetak yang dipilih pada Rekaman cetak. Notifikasi Kerja juga akan dikirim di dalam Organisasi. Lihat contoh berikut:

Rekaman cetak

Notifikasi Kerja

**Jalur 2**: Buka halaman Aplikasi >> halaman manajemen data / halaman Rekaman sumber >> Tindakan lainnya >> Cetak massal.

## 2. Dua cara mengunduh file cetak massal

### 2.1 Notifikasi Kerja

**Jalur**: Notifikasi Kerja >> Klik Lihat Detail >> Alihkan ke halaman unduhan lokal >> Cetak file.

Notifikasi Kerja

### 2.2 Rekaman cetak

**Jalur**: Formulir >> Manajemen data >> Rekaman cetak >> Unduh (file akan langsung diunduh ke perangkat lokal Anda).

Rekaman cetak
