## 1. Cetak massal

### 1.1 Templat cetak

Pengaturan cetak saat ini hanya didukung pada Edisi Basic dan Edisi Professional. Edisi Gratis tidak mendukung konfigurasi templat cetak.

### 1.2 Cetak massal

Hasilkan file cetak untuk data yang dipilih berdasarkan templat cetak, lalu unduh semuanya sebagai satu paket.

## 2. Dua cara mengunduh file cetak massal

### 2.1 Notifikasi Kerja

**Jalur**: Notifikasi Kerja >> Klik Lihat Detail >> Alihkan ke halaman unduhan lokal >> Cetak file.

<Frame>
  ![](https://gw.alicdn.com/imgextra/i3/O1CN014XX3rejeulI37EMJ_!!6000000005749-2-tps-1535-968.png)
</Frame>

Notifikasi Kerja

### 2.2 Rekaman cetak

**Jalur**: Formulir >> Manajemen data >> Rekaman cetak >> Unduh (file akan langsung diunduh ke perangkat lokal Anda).

<Frame>
  ![](https://gw.alicdn.com/imgextra/i1/O1CN01bswmBWSPWiD4MtjX_!!6000000001154-2-tps-2152-651.png)
