Setelah pengaturan dasar desainer formulir selesai, konfigurasikan tata letak halaman secara keseluruhan.

## 1. Ikhtisar tata letak formulir

### 1.1 Tata letak komponen

Di Yida, komponen secara default disusun dalam satu kolom.

Komponen **Kontainer tata letak**, **Grup**, dan **Subformulir (mode spreadsheet)** secara default menempati lebar 100%. Semua komponen lainnya menempati 50%, atau setengah dari lebar halaman.

Jika ingin formulir menggunakan lebar penuh 100%, gunakan **Kontainer tata letak**.

Komponen

### 1.2 Jumlah kolom

Untuk menggunakan tata letak dua kolom, klik Columns pada panel atribut pengaturan formulir.

Setelah mengaktifkan tata letak dua kolom, jika suatu komponen tertentu perlu menempati lebar penuh, klik opsi dua kolom pada pengaturan Premium komponen tersebut.

Pengaturan formulir — pengaturan PC

### 1.3 Kontainer tata letak

Komponen kontainer tata letak memungkinkan Anda menyusun halaman dengan lebih fleksibel. Selain mendukung lebar penuh 100% seperti disebutkan di atas, komponen ini juga mendukung jumlah kolom berapa pun.

Untuk konfigurasi kontainer tata letak, lihat: [Kontainer tata letak](/id/yida/form/wql6d2)

Konfigurasi tata letak

### 1.4 Menggunakan Grup

Komponen Grup memungkinkan Anda mengorganisasi formulir ke dalam grup dan menambahkan formulir grup. Komponen ini juga memungkinkan Anda menata tata letak komponen, sehingga halaman menjadi lebih menarik secara visual.

### 1.5 Mode akses

Akses Pratinjau:

Saat mengklik Pratinjau pada antarmuka formulir untuk mengakses aplikasi, Anda dapat melihat halaman konfigurasi keseluruhan dari formulir saat ini. Anda tidak dapat mengirimkan data atau mengubah pengaturan formulir, dan navigasi sidebar tidak ditampilkan. Halaman memiliki lebar tetap 1.180 piksel.

Akses Simpan:

Setelah mengklik Simpan, formulir masuk ke halaman pusat aplikasi. Saat Anda mengklik Access di bagian atas aplikasi saat ini untuk melihat formulir, navigasi sidebar akan ditampilkan. Anda dapat mengklik batang navigasi untuk melihat halaman formulir lain dan mengirimkan data, tetapi tidak dapat mengedit formulir.

### 1.6 Tampilan multi-perangkat

Untuk lima metode tata letak yang disebutkan di atas, tampilan seluler berbeda dari tampilan PC. Di perangkat seluler, semua formulir secara default menggunakan tata letak satu kolom.

Di tablet, tata letak juga otomatis menyesuaikan.
