<Warning>
Halaman manajemen data edisi berbayar mendukung pencarian 30.000 rekaman **(Edisi Gratis hanya mendukung pencarian 5.000 rekaman; lihat** **prasyarat peningkatan****)**. Jika batas ini terlampaui, Kesalahan akan muncul. Gunakan komponen Filter untuk mempersempit cakupan pencarian.
</Warning>

## 1. Ikhtisar halaman manajemen data

Halaman manajemen data menampilkan semua rekaman formulir yang telah dikirim serta menyediakan fitur seperti impor/riwayat impor, ekspor/riwayat ekspor, riwayat edit, unduhan file/riwayat unduhan, cetak/riwayat cetak, Tambah, tindakan Lainnya (edit data, hapus), pencarian, filter, pengaturan kolom tampilan, urutkan, muat ulang, dan mode layar penuh.

## 2. Ikhtisar fitur

**Jalur**: Aplikasi Saya >> klik sebuah aplikasi >> Formulir/formulir alur kerja >> Manajemen data

| **Fitur** | **Deskripsi** |
|---|---|
| [**Ekspor/Riwayat ekspor**](/id/yida/form/vz0ebe) | Ekspor rekaman yang memenuhi kriteria kueri ke file Excel. Anda dapat melihat rekaman yang telah diekspor sebelumnya di riwayat ekspor. |
| [**Impor/Riwayat impor**](/id/yida/form/andrke) | Kirim rekaman formulir secara massal untuk membantu pengirim mengirimkan banyak rekaman formulir dengan cepat. Lihat rekaman yang telah diimpor di riwayat impor. |
| **Unduhan file/Riwayat unduhan** | Pilih beberapa rekaman untuk mengunduh file-nya, dan lihat rekaman file yang telah diunduh sebelumnya di riwayat unduhan.<br />**Catatan**: Jika lampiran terlalu besar, unduhan massal akan dibagi menjadi paket berukuran masing-masing 200 MB. |
| [**Edit data/Riwayat edit**](/id/yida/form/ne8htk) | Edit rekaman secara massal di halaman manajemen data formulir. Hanya Admin yang dapat menggunakan fitur ini. Anda dapat melihat data sebelum dan sesudah pengeditan di riwayat edit. |
| [**Hapus**](/id/yida/form/fxxris) | Hapus rekaman secara massal di halaman manajemen data formulir. Hanya Admin yang dapat menggunakan fitur ini. |
| [**Cetak/Riwayat cetak**](/id/yida/form/nmrhfo) | Hasilkan file cetak untuk rekaman yang dipilih berdasarkan templat cetak dan unduh sebagai paket. Anda juga dapat melihat riwayat cetak. |
| **Urutkan** | Bila terdapat banyak rekaman, Anda dapat mengurutkannya secara menaik atau menurun berdasarkan bidang tertentu. Komponen yang didukung: Teks satu baris, Teks multi-baris, Numerik, Pilih, Peringkat, dan Tanggal. |
| [**Filter**](/id/yida/form/if3mza) | Atur Filter pada berbagai bidang untuk memfilter dan melihat rekaman. |
| [**Kolom tampilan**](/id/yida/form/lzqqf6) | Pilih bidang untuk mengonfigurasi konten yang ditampilkan pada rekaman. |
| **Muat Ulang** | Perbarui tampilan dengan cepat setelah mengimpor data. |

### 2.1 Rekaman sumber

#### 2.1.1 Salin

Formulir reguler menyediakan fitur salin cepat untuk detail rekaman tanpa konfigurasi tambahan. Cukup buka halaman detail rekaman untuk menggunakannya. Untuk formulir alur kerja, Anda perlu mengaktifkan tombol **Salin alur kerja** di Pengaturan dasar.

**Catatan:**

- Fitur ini tidak didukung di aplikasi 1.0 atau 2.0.
- Fitur ini tersedia di semua edisi YiDA.
- Bidang yang dikonfigurasi sebagai tersembunyi, dinonaktifkan, atau hanya baca tidak akan disalin.

<Accordion id="q1" title="3.1 Mengapa saat mengklik tombol Salin muncul pesan 'Tidak ada izin untuk mengakses halaman ini'?">
  Periksa apakah grup izin untuk status pengiriman formulir telah dikonfigurasi agar akun Anda diizinkan mengirim rekaman.
</Accordion>

<Accordion id="q2" title="3.2 Mengapa subformulir dapat diperluas di sebagian halaman manajemen data formulir?">
  Penyimpanan baru memperluas komponen subformulir secara default, sedangkan penyimpanan lama tidak memuatnya secara default. Karena itu, tombol Perluas subformulir tetap dipertahankan untuk penyimpanan lama.
</Accordion>

<Accordion id="q3" title="3.3 Mengapa hasil pencarian global tidak akurat?">
  Jika aplikasi saat ini menggunakan penyimpanan lama, hasil pencarian global mungkin tidak akurat. Untuk detail tentang peningkatan kemampuan pencarian, **klik di sini**.

<Accordion id="q4" title="3.4 Mengapa sebagian formulir aplikasi tidak memiliki pengaturan Admin untuk bidang filter default dan pengurutan?">
  Aplikasi dengan penyimpanan baru tidak lagi membatasi bidang mana yang dapat dicari. Secara default, semua bidang filter yang Anda tambahkan dapat dicari. Karena itu, aplikasi yang formulirnya masih memiliki tombol ini menggunakan penyimpanan lama.
</Accordion>
