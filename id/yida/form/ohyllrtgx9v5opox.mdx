<Note>
Cakupan yang didukung:

- Bilah tindakan pada halaman detail formulir reguler dan formulir alur kerja. Untuk formulir alur kerja, tombol kustom hanya muncul pada rekam persetujuan yang telah selesai.
- Tombol kustom saat ini didukung pada halaman detail dan halaman manajemen data.
</Note>

## 1. Ikhtisar

### 1.1 Ikhtisar fitur

- Tombol kustom memungkinkan Admin mendefinisikan alur bisnis yang kompleks sebagai peristiwa tombol. Pengguna kemudian dapat memicu formulir, halaman, atau alur integrasi & otomatisasi terkait melalui tombol kustom untuk menyelesaikan tugas bisnis mereka.
- Tombol kustom memberi Pengguna cara yang lebih praktis untuk menjalankan tindakan bisnis, sehingga meningkatkan efisiensi kerja secara keseluruhan.

### 1.2 Kasus penggunaan

- Skenario CRM: Pada halaman prospek pelanggan, gunakan tombol kustom "Tindak Lanjut" untuk mencatat rekam tindak lanjut dengan cepat.
- Skenario CRM: Untuk prospek di public pool, gunakan tombol kustom "Assign" untuk menetapkan "Follow-up owner" dan menyelesaikan penugasan prospek.
- Skenario manajemen pengadaan: Setelah permintaan pengadaan disetujui, gunakan tombol kustom "Create order" untuk segera menerbitkan purchase order.
- Skenario HR: Untuk karyawan masa percobaan, gunakan tombol kustom "Convert to full-time" guna mengangkat mereka menjadi karyawan tetap dengan satu klik.

#### 2.1.2. Membuat tombol kustom

- Buat tombol kustom

| **Tipe tindakan** | **Konfigurasi mode admin** | **Perilaku mode akses** |
|---|---|---|
| Isi formulir: Modifikasi formulir saat ini | Admin menentukan bidang yang akan diubah. | Pada mode akses, klik tombol untuk membuka dialog yang menampilkan bidang yang dapat diedit. |
| Isi formulir: Isi formulir terkait | Admin memilih formulir terkait yang akan diisi saat tombol diklik. | Jika formulir terkait dikonfigurasi dengan logika pengisian asosiasi, nilai bidang formulir saat ini otomatis terisi ke formulir terkait ketika tombol kustom dipicu.<br />Contoh: Pada formulir "Follow-up record", tetapkan formulir terkait "Customer" dan konfigurasikan pengisian asosiasi.<br />Hasil: Pada halaman detail formulir "Customer", klik "Fill in follow-up record".<br />Informasi dasar pelanggan otomatis terisi ke formulir "Follow-up record". |
| Jalankan alur integrasi & otomatisasi | • Anda dapat membuat alur integrasi & otomatisasi baru. Tindakan ini mengalihkan Anda ke perancang alur dan otomatis membuat alur otomatisasi dengan jenis pemicu "Manual trigger - Custom button trigger", dengan formulir saat ini terpilih sebelumnya.<br />• Jika formulir saat ini sudah memiliki alur otomatisasi bertipe "Manual trigger - Custom button trigger", Anda juga dapat memilihnya dari daftar drop-down.<br />Saat membuat alur integrasi & otomatisasi baru, Anda dapat memilih untuk membuatnya dengan jenis pemicu "Manual trigger - Custom button trigger" dan memilih formulir target. |  |

#### 2.1.3. Mengelola tombol kustom

- Edit tombol kustom: Perubahan berlaku untuk semua rekam formulir yang ada.
- Hapus tombol kustom: Menghapus tombol kustom dari bilah tindakan halaman detail hanya menghapus referensinya. Untuk menghapus tombol kustom secara permanen, hapus dari daftar manajemen tombol kustom.
- Urutkan tombol kustom: Pada halaman detail kustom, seret tombol untuk mengatur ulang urutan tombol kustom maupun tombol sistem.

### 2.2. Mode akses

#### 2.2.1. Desktop

- Area ringkasan data: menampilkan tombol sistem Salin dan Cetak.
- Bilah tindakan bawah: menampilkan tombol kustom serta tombol sistem Edit dan Hapus.

#### 2.2.2. Seluler

Baik tombol sistem maupun tombol kustom muncul pada bilah tindakan bawah. Jika jumlah tombol terlalu banyak, tombol tambahan diciutkan di bawah "Lainnya".

## Catatan

- Jumlah maksimum tombol kustom: 10.
- Izin tombol kustom mengikuti Izin akses formulir. Jika Pengguna memiliki akses ke halaman, mereka juga dapat melihat tombol kustom.
- Tipe tindakan tombol: "Modifikasi formulir saat ini".

- Tipe tindakan tombol: "Jalankan alur integrasi & otomatisasi".

- Kondisi ketersediaan tombol: Jika bidang yang dikonfigurasi pada Filter dihapus, data yang dikirimkan setelahnya tidak memiliki nilai bidang tersebut sehingga tidak memenuhi kondisi ketersediaan, dan tombol kustom tidak akan muncul.
- Klik bersamaan: Ketika beberapa Pengguna mengklik tombol tindakan pada rekam yang sama secara bersamaan, jika seseorang telah mengklik dan eksekusi sebelumnya belum selesai, klik berikutnya akan menampilkan pesan: "The button has already been clicked and is still running. Please try again later."
- Tautan pengalihan: Untuk tautan pengalihan, akses Pengguna ke target bergantung pada apakah Pengguna saat ini memiliki Izin untuk melihat halaman target.
