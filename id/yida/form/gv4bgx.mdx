<Note>
Edisi yang berlaku: edisi berbayar

**Prasyarat:**

- Arsitektur informasi lama tidak didukung.
- Penyimpanan pencarian lama tidak didukung. Kemampuan pencarian baru telah ditingkatkan.
- Edisi Luang tidak didukung.
- Hanya Formulir reguler dan formulir alur kerja yang didukung.
</Note>

## 1. Pendahuluan

### 1.1 Gambaran umum fitur

Saat menggunakan keterkaitan data Komponen, mengasosiasikan data dari Formulir lain, atau komponen formulir terkait untuk penyaringan/pengisian data, Anda dapat melakukan kueri data Formulir lintas Aplikasi. Anda harus membuat dataset lintas Aplikasi terlebih dahulu.

**Jalur**: Pengaturan Aplikasi > Manajemen Data Aplikasi > Dataset > Buat Dataset > Buat dari Lintas-Aplikasi. Untuk detail lebih lanjut, lihat [Buat dataset dari lintas-Aplikasi](/id/yida/app-admin/btrtnt).

### 1.2 Contoh skenario

Sebagian besar perusahaan mengelompokkan manajemen kontrak, manajemen proyek, manajemen keuangan, dan manajemen pengadaan ke dalam Aplikasi terpisah. Ketika staf keuangan perlu mengadakan barang, mereka harus menautkan permintaan pembelian dengan Formulir persetujuan kontrak. Tanpa kemampuan untuk melakukan kueri data lintas Aplikasi, permintaan pembelian tidak dapat ditautkan ke Formulir kontrak. YiDA kini menyediakan kemampuan untuk mengambil dan melakukan kueri data Formulir lintas Aplikasi, yang menyelesaikan masalah ini.

## 2. Gambaran umum kemampuan

Ini berlaku untuk kueri data dari Formulir lain lintas Aplikasi. Hanya kueri data tabel gabungan yang didukung.

### 2.1 Komponen yang didukung

Kueri data Formulir lintas Aplikasi saat ini mendukung Komponen berikut:

- Keterkaitan data: Teks satu baris, Teks multi-baris, Numerik, Tanggal, Unggah Gambar, Lampiran, Pengguna & Departemen, Radio, Radio dropdown, Kotak centang, Kotak centang dropdown.
- Asosiasi dengan data dari Formulir lain: Radio, Radio dropdown, Kotak centang, Kotak centang dropdown.
- Pengaturan tampilan/penyaringan data/pengisian data: formulir terkait.

### 2.2 Keterkaitan data

Saat menggunakan fitur keterkaitan data pada Komponen, baik nilai Default maupun tipe opsi mendukung pemilihan Formulir lintas Aplikasi.

<Frame>
  ![](https://gw.alicdn.com/imgextra/i1/O1CN01OFS0DBAWtvK5qI66_!!6000000000361-2-tps-2878-1428.png)
</Frame>

### 2.3 Asosiasikan data dari Formulir lain

Saat Komponen Radio, Radio dropdown, Kotak centang, atau Kotak centang dropdown digunakan untuk mengasosiasikan data dari Formulir lain, Anda dapat memilih Formulir lintas Aplikasi.

<Frame>
  ![](https://gw.alicdn.com/imgextra/i2/O1CN01xkYs25rRrFD5pHfM_!!6000000003482-2-tps-2870-1450.png)
</Frame>

### 2.4 Formulir terkait

Komponen formulir terkait dapat memilih Formulir lintas Aplikasi yang Anda miliki izinnya untuk mengaksesnya, dan dapat digunakan untuk penyaringan data serta pengisian data.

<Frame>
  ![](https://gw.alicdn.com/imgextra/i3/O1CN01z2FlER8VOLK5pXGq_!!6000000000072-2-tps-2872-1432.png)
</Frame>

### 2.5 Jumlah maksimum Formulir lintas Aplikasi

| **Edisi** | **Jumlah maksimum Formulir lintas Aplikasi per Aplikasi** |
|---|---|
| Edisi Luang | Tidak didukung. Tingkatkan edisi Anda untuk menggunakan fitur ini. |
| Edisi berbayar<br />(edisi berbayar selain Edisi Professional, seperti Edisi Basic dan Edisi Pendidikan) | 50 |
| Edisi Professional | 100 |

### 2.6 Catatan

Pembacaan data Formulir lintas Aplikasi melibatkan titik masuk seperti formula dan integrasi & otomatisasi. Untuk detailnya, lihat Pembaruan versi 27 April 2022 – Baca/tulis data Formulir lintas Aplikasi.

## 3. FAQ

### 3.1 Apakah Edisi Luang mendukung kueri data Formulir lintas Aplikasi?

Membuat dataset dari lintas-Aplikasi adalah fitur berbayar, sehingga Edisi Luang YiDA tidak mendukung kueri data Formulir lintas Aplikasi.

Untuk FAQ lainnya, lihat [Buat dataset dari lintas-Aplikasi](/id/yida/app-admin/btrtnt).
