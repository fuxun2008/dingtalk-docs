## 1. Gambaran umum log aktivitas

Kueri catatan tindakan impor, ekspor, modifikasi, unduhan file, dan cetak.

**Catatan: Batas 7 hari berlaku untuk pengunduhan berulang**, yang mencakup catatan impor, ekspor, modifikasi, unduhan file, dan cetak.

### 1.1 Kueri catatan ekspor

**Jalur**: Klik Formulir/formulir alur kerja >> Manajemen data >> Catatan ekspor

Untuk menemukan catatan ekspor dengan cepat, terapkan Filter berdasarkan nama file, status, operator, atau waktu modifikasi, seperti ditunjukkan di bawah:

Catatan ekspor

### 1.2 Kueri catatan impor

**Jalur**: Klik Formulir/formulir alur kerja >> Manajemen data >> Catatan impor

Demikian pula, untuk menemukan catatan impor dengan cepat, terapkan Filter berdasarkan nama file, status, operator, atau waktu modifikasi, seperti ditunjukkan di bawah:

Catatan impor

### 1.3 Kueri catatan cetak

**Jalur**: Klik Formulir/formulir alur kerja >> Manajemen data >> Catatan cetak

**Catatan**: Catatan cetak tidak mendukung Filter.

Catatan cetak

### 1.4 Kueri catatan modifikasi

**Jalur**: Klik Formulir/formulir alur kerja >> Manajemen data >> Catatan modifikasi

Temukan catatan modifikasi dengan cepat berdasarkan nama file, status, operator, atau waktu modifikasi, seperti ditunjukkan di bawah:

Catatan modifikasi

### 1.5 Kueri catatan unduhan file

**Jalur**: Klik Formulir/formulir alur kerja >> Manajemen data >> Catatan unduhan file

Halaman ini menampilkan catatan unduhan massal untuk **lampiran** dan **Gambar**. Terapkan Filter berdasarkan nama file, status, operator, atau waktu modifikasi, seperti ditunjukkan di bawah:

Catatan unduhan file
