### 2.2 Toolbar kiri

#### 2.2.1 Pohon outline

Pohon outline memberikan tampilan yang lebih jelas tentang tata letak halaman secara keseluruhan. Anda dapat menyeret dan melepas atau menghapus komponen secara massal langsung dari pohon outline.

<Frame>
  ![](https://gw.alicdn.com/imgextra/i3/O1CN01OwcDvCoDVPH3sYsX_!!6000000006080-2-tps-1911-886.png)
</Frame>

- Klik dua kali item pada pohon outline untuk mengubah aliasnya, sehingga memudahkan pembedaan beberapa komponen dengan tipe yang sama.
- Klik ikon "Sematkan" di sudut kanan atas untuk menyematkan panel pohon outline ke sisi kiri.
- Tahan CMD / CTRL untuk melakukan Pilih Banyak pada pohon outline.

#### 2.2.2 Pustaka komponen

Klik sebuah komponen pada pustaka komponen, lalu seret ke posisi yang diinginkan pada kanvas atau pohon outline. Anda juga dapat mengklik komponen untuk menyisipkannya langsung ke kanvas.

### 2.3 Panel konfigurasi atribut kanan

#### 2.4.1 Pengaturan atribut

Pengaturan atribut digunakan untuk mengonfigurasi Atribut umum sebuah Komponen. Perubahan diterapkan pada kanvas secara real time.

Klik \{/} untuk menerapkan [**pengikatan data**](/id/yida/form/og76m2) pada atribut saat ini, sehingga tampilan dinamis dapat diaktifkan.

**Catatan: hasil pengikatan data tidak dapat dipratinjau secara real time di dalam desainer — Anda harus melihatnya pada lingkungan Pratinjau.**

Untuk detailnya, lihat [Informasi dasar komponen](/id/yida/form/snftao).

#### 2.4.3 Premium

Premium terutama digunakan untuk mengonfigurasi komponen dengan kebutuhan khusus.

Untuk detailnya, lihat [Informasi dasar komponen](/id/yida/form/snftao).

① Pengenal unik: pengenal unik Komponen saat ini, digunakan untuk memperoleh instance Komponen tersebut dalam kode sehingga Anda dapat melakukan operasi lanjutan.

② Tampilan multi-platform: menentukan platform mana yang menampilkan Komponen saat ini. Secara Default, Komponen ditampilkan di semua platform. Jika Anda menonaktifkannya untuk platform tertentu, Komponen tidak akan dirender pada platform tersebut.

<Warning>
**Catatan: jika opsi ini dikonfigurasi, data tidak akan dikirim ke Sisi server, dan pemanggilan kode untuk memperoleh instance Komponen saat ini akan mengembalikan null.**
</Warning>

③ Pengiriman data: nilai Default adalah "Kirim hanya saat ditampilkan." Ketika "Status default" Komponen formulir diatur ke Tersembunyi, data tidak akan dikirim ke backend secara Default. Jika Anda perlu mengirim data Bidang tersembunyi, atur opsi ini ke "Selalu Kirim."

**Catatan: opsi ini bekerja bersama Atribut "Status default" Komponen.**

④ Pengaturan tindakan: digunakan untuk mengonfigurasi callback peristiwa sebuah Komponen, sehingga Anda dapat mengimplementasikan logika bisnis kompleks melalui kode. Untuk informasi lebih lanjut, lihat panduan penggunaan [**Panel tindakan**](/id/yida/form/uezmum).
