## 1. Prasyarat

Saat ini, pengeditan lampiran hanya mendukung tiga jenis dokumen Office: Word, PPT, dan Excel. Ekstensi yang didukung adalah sebagai berikut:

Seri Excel: et, xls, xlt, xlsx, xlsm, xltx, xltm, csv

Seri Word: doc, docx, txt, dot, wps, wpt, dotx, docm, dotm

Seri PPT: ppt, pptx, pptm, pptm, ppsm, pps, potx, potm, dpt, dps

**Catatan**: Selain jenis file di atas, pratinjau lampiran juga mendukung PDF.

## 2. Cara mengaktifkan pengeditan lampiran online

Untuk menggunakan pengeditan lampiran online, aktifkan terlebih dahulu tombol **Online Editing** pada Komponen Lampiran.

Seperti ditunjukkan di bawah ini:

Halaman pengeditan formulir

**Mengaktifkan tombol pengeditan online hanya akan mengaktifkan kemampuan pengeditan online untuk Formulir ini. Untuk mengedit lampiran yang telah diunggah setelah data dikirim, Anda juga harus mengonfigurasi izin.**

**Catatan**: Konfigurasi izin berbeda antara formulir dan formulir alur kerja. Lihat jalur di bawah ini.

**Formulir**: Cari Formulir target >> Pengaturan >> Izin halaman >> Status Tampilan >> Edit >> Izin bidang >> Kustom, konfigurasikan Bidang >> Aktifkan Izin Edit untuk Lampiran.

Halaman pengaturan izin formulir

**Formulir alur kerja**: Cari formulir alur kerja target >> Alur kerja >> Penyetuju >> Konten yang ditampilkan di node ini >> Pada baris Lampiran, pilih Editable (penyetuju dapat melakukan pengeditan online saat memiliki izin selama Persetujuan).

Formulir alur kerja baru

## 3. Petunjuk pengeditan online

### 3.1 Auto-save

Halaman pengeditan disimpan secara otomatis setelah setiap perubahan. Anda juga dapat menekan **Ctrl+S** untuk Simpan secara manual.

Penyimpanan manual yang terlalu sering tidak disarankan. Setiap Simpan manual akan membuat Versi baru. Sistem membatasi jumlah versi yang disimpan hingga 10, dan versi lama akan dihapus secara otomatis setelah batas ini terlampaui.

### 3.2 Catatan kolaborasi

Klik **Collaboration Records** di sudut kanan atas untuk melihat riwayat pengeditan setiap Pengguna yang telah mengerjakan Dokumen.

## 4. Catatan

- Pengeditan lampiran online hanya tersedia untuk Edisi Professional ke atas. Komponen Lampiran menyediakan fungsionalitas pengeditan online.
