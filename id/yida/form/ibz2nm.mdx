## 1. Kasus penggunaan

Pilih satu item dari beberapa opsi dropdown. Komponen ini cocok digunakan ketika terdapat banyak opsi. Konten opsi dapat dikustomisasi, dan komponen ini juga mendukung skenario seperti [**keterkaitan data**](/id/yida/form/arpur0) dan [**mengasosiasikan formulir lain**](/id/yida/form/tg64d5). Sebagai contoh, gunakan komponen Dropdown select untuk kolom seperti tipe cuti atau jenis kelamin pada formulir permohonan cuti.

Jika opsi berasal dari formulir lain dan, setelah dipilih, informasi terkait harus terisi otomatis ke dalam formulir (skenario asosiasi data) — misalnya pada skenario manajemen kontrak, saat kontrak atau pesanan dibuat dan opsi komponen formulir terkait dihubungkan dengan tabel pelanggan untuk menarik informasi pelanggan — gunakan komponen [**formulir terkait**](/id/yida/form/agd540) sebagai gantinya.

**Catatan: Panjang maksimum nilai opsi pada komponen Dropdown select adalah 255 karakter.**

### 3.3 Perbedaan antara komponen Dropdown select dan formulir terkait

Kedua komponen berbeda dalam definisi fitur dan kasus penggunaan.

#### 3.3.1 Dropdown select

**Sumber opsi**: opsi kustom, diambil dari Formulir lain, diambil dari Sumber data jarak jauh, atau diperoleh melalui keterkaitan data.

**Kasus penggunaan**: umumnya digunakan untuk skenario pemilihan opsi yang tidak memerlukan penarikan data tambahan. Sebagai contoh, gunakan komponen Dropdown select untuk kolom seperti tipe cuti atau jenis kelamin pada formulir permohonan cuti.

#### 3.3.2 Formulir terkait

**Sumber opsi**: diambil dari Formulir lain.

**Kasus penggunaan**: umumnya digunakan untuk skenario asosiasi data. Sebagai contoh, pada skenario manajemen kontrak, saat membuat kontrak atau pesanan, asosiasikan opsi komponen formulir terkait dengan tabel pelanggan untuk menarik informasi pelanggan.
