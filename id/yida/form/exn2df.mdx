## 1. Kasus penggunaan

Komponen Tahun Akademik berlaku untuk skenario K-12 yang memerlukan pemilihan sekolah. Komponen ini umumnya digunakan di sisi dinas pendidikan, misalnya saat memilih tahun akademik pendaftaran siswa.

## 2. Fitur dasar

### 2.1 Mode Pilih Banyak

Anda dapat memilih beberapa tahun akademik sekaligus. Untuk membatasi pilihan hanya pada satu tahun akademik, nonaktifkan tombol ini.

| **Tampilan desain Formulir** | **Tampilan runtime Formulir** |
|---|---|

- Jika Organisasi pendidikan ditautkan ke sekolah bawahannya melalui Asosiasi Organisasi, Komponen ini memungkinkan pemilihan sekolah-sekolah terkait tersebut. Jika dinas pendidikan telah mengelompokkan sekolah bawahannya melalui Aplikasi manajemen dinas-sekolah, Komponen ini menampilkan Daftar sekolah berdasarkan Kategori.
- Jika Organisasi pendidikan tidak memiliki sekolah bawahan yang ditautkan melalui Asosiasi Organisasi, Komponen ini hanya mengizinkan pemilihan sekolah saat ini.

**Catatan: Komponen Semester tidak mendukung pengisian data otomatis.**

## 3. Sumber Data

Menggunakan data master tahun akademik terpadu dari industri pendidikan. Data ini telah diatur sebelumnya oleh sistem dan tidak mendukung konfigurasi Kustom.
