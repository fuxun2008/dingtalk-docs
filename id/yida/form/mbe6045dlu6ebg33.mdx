Fungsi **CONCATENATE** menggabungkan beberapa string menjadi satu string.

## Skenario produk yang didukung

Fungsi **CONCATENATE** didukung pada skenario Yida berikut.

- Formulir (field tabel utama)
- Formulir (aturan asosiasi bisnis)
- Formulir (validasi)
- Desain alur kerja (aturan validasi)
- Desain alur kerja (aksi asosiasi)
- Integrasi & Otomatisasi
- Node alur kerja
- Konektor

## Format

```text
CONCATENATE(text1,text2,text3....)
```

## Atribut

| **Atribut** | **Wajib** | **Deskripsi** |
|---|---|---|
| text1,text2,text3.... | Ya | String yang akan digabungkan. Pisahkan beberapa string dengan koma. <br />**Catatan**: Apit nilai string dengan tanda kutip. |

## Nilai kembalian

| **Tipe nilai kembalian** | **Deskripsi** |
|---|---|
| Teks | String hasil penggabungan. <br />Urutan string baru mengikuti urutan atribut dalam fungsi **CONCATENATE**. <br />Contohnya, jika formulanya `CONCATENATE("a","b","c")`, hasilnya adalah `abc`. |

Hasil dari formula berikut adalah: `Yida low-code development platform`.
