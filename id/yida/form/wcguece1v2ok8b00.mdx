Artikel ini mencantumkan semua fungsi teks yang tersedia di YiDA.

## Ikhtisar fungsi

| **Nama fungsi** | **Deskripsi** |
|---|---|
| [ARRAYGET](/id/yida/form/mggsmf) | Mengembalikan nilai pada posisi yang ditentukan dalam suatu kumpulan data. |
| [CONCATENATE](/id/yida/form/mbe6045dlu6ebg33) | Menggabungkan beberapa string teks menjadi satu string teks. |
| [LEFT](/id/yida/form/xylna43s4gpoyz9k) | Mengembalikan sejumlah karakter tertentu dari awal sebuah string teks. Jika panjang teks kurang dari jumlah karakter yang ditentukan, teks asli akan dikembalikan. |
| [RIGHT](/id/yida/form/ch2gvwhzh2bn9u82) | Mengembalikan sejumlah karakter tertentu dari akhir sebuah string teks. |
| [LEN](https://docs.aliwork.com/ytnegt00zgbwos60) | Mengembalikan jumlah karakter dalam sebuah string teks. |
| [LOWER](/id/yida/form/aire3ioygvfi7vul) | Mengonversi semua huruf besar dalam sebuah string teks menjadi huruf kecil. |
| [UPPER](/id/yida/form/fm0og6ccdh0n0q2k) | Mengonversi semua huruf kecil dalam sebuah string teks menjadi huruf besar. |
| [MID](/id/yida/form/pghawu8hdwng91in) | Mengembalikan sejumlah karakter tertentu dari sebuah string teks, dimulai dari posisi yang ditentukan. |
| [PINYINHEADCHAR](/id/yida/form/dvfmdhg8i3ohg0c4) | Mengembalikan huruf pinyin pertama dari setiap karakter Tionghoa dalam sebuah string, dalam huruf besar. |
| [REPLACE](/id/yida/form/gtz0638tp96gbnhf) | Mengganti bagian dari sebuah string teks dengan string teks yang berbeda, berdasarkan jumlah karakter yang ditentukan. |
| [REPT](/id/yida/form/scd5m0bi74omfpyg) | Mengulangi teks sebanyak jumlah tertentu. |
| [RMBFORMAT](/id/yida/form/ff4mghegi9kbsc7m) | Memformat sebuah angka dalam format yuan Tionghoa (RMB). |
| [SEARCH](/id/yida/form/mhwnrwy04c03o2z4) | Mengembalikan posisi awal teks 1 di dalam teks 2. |
| [SPLIT](/id/yida/form/yf6hkwf5lzcyin93) | Membagi teks menjadi sebuah array berdasarkan pemisah yang ditentukan. Gunakan bersama ARRAYGET untuk mengambil karakter pada posisi yang ditentukan. |
| [TEXT](/id/yida/form/bt0wov266h45hpi4) | Memformat sebuah nilai sebagai teks. |
| [TRIM](/id/yida/form/tzmpoqk3e4szn7ar) | Menghapus spasi dari awal dan akhir sebuah string, tetapi mempertahankan spasi tunggal di antara kata-kata. |
| [UUID](/id/yida/form/xb7gg8vrhik5yg5s) | Menghasilkan sebuah string unik dan menetapkannya ke Bidang Teks satu baris. |
| [VALUE](/id/yida/form/awk6sfyg9vcqe1g1) | Mengonversi teks menjadi angka. Biasanya digunakan ketika data telah dimasukkan dan perlu dihitung ulang. |
