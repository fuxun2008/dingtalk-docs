## 1. Ikhtisar

YiDA kini mendukung desain label Kode QR kustom, unduh massal, serta pratinjau. Gunakan fitur ini untuk mengunduh label Kode QR yang Anda perlukan untuk sebuah Formulir secara massal.

Untuk konfigurasi label Kode QR, lihat [Label Kode QR](/id/yida/form/knk7hr).

## 2. Panduan Pengguna

Baik Admin maupun Karyawan YiDA dapat mengunduh label Kode QR, namun jalurnya berbeda sebagai berikut.

### 2.1 Unduh sebagai Admin

**Mode Edit**: Buka YiDA > Aplikasi Saya > pilih Aplikasi dan Formulir target > Manajemen Data > Unduh Label Kode QR.

**Mode Tampilan**: Buka YiDA > Pusat Aplikasi > temukan halaman manajemen data pada Aplikasi dan Formulir target > Unduh Label Kode QR.

### 2.2 Unduh sebagai Karyawan

Karyawan hanya dapat mengunduh label Kode QR dalam mode Tampilan.

**Jalur**: YiDA > Pusat Aplikasi > temukan halaman manajemen data pada Aplikasi dan Formulir target > Unduh Label Kode QR.

### 2.3 Ukuran yang tersedia

Ukuran unduhan yang tersedia bervariasi menurut gaya label. Anda dapat melihat ukuran yang tersedia saat mengonfigurasi gaya label.
