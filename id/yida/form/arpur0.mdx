## 1. Pendahuluan

### 1.1 Ikhtisar

Ketika data pada satu bidang di formulir berubah, data pada bidang lain di formulir yang sama akan berubah mengikuti. Fitur ini umumnya digunakan untuk menetapkan nilai default pada komponen.

## 2. Item konfigurasi keterkaitan data

**Tabel terkait**: Pilih tabel yang akan dikaitkan.

- Aplikasi saat ini: Formulir lain yang berada dalam Aplikasi yang sama dengan formulir saat ini. Sebuah Formulir tidak dapat menggunakan dirinya sendiri sebagai sumber untuk keterkaitan datanya sendiri.
- Lintas aplikasi: Anda dapat memilih formulir dataset lintas Aplikasi yang telah dibuat. Untuk detailnya, lihat [Mengambil data formulir lintas aplikasi](/id/yida/form/gv4bgx).

**Pengaturan bidang tertaut**: Ketika nilai bidang formulir saat ini "Nama produk" sama dengan nilai bidang Tabel terkait "Nama produk", nilai bidang formulir saat ini "Jumlah" menampilkan nilai bidang Tabel terkait "Jumlah stok".

## 4. Peningkatan kompatibilitas karakter khusus untuk kondisi keterkaitan data dropdown Pilih satu

- Sebelumnya: Jika bidang data target berisi karakter khusus, keterkaitan gagal dan logika bisnis tidak dapat dijalankan.
- Sekarang: Data target yang berisi karakter khusus seperti dan / dapat dicocokkan dengan benar.

## 5. FAQ

### 5.1 Tabel sumber berisi data, tetapi data yang tertaut tidak ditampilkan.

Keterkaitan data mengembalikan jumlah hasil yang terbatas, dan pencarian di dalam hasil yang dikembalikan saat ini belum didukung. Jika Tabel sumber berisi banyak catatan yang memenuhi kondisi—terutama banyak nilai duplikat—hasil yang diinginkan mungkin tidak muncul dalam keterkaitan.

Anda dapat mengaktifkan deduplikasi untuk mengurangi catatan duplikat pada hasil, sehingga lebih banyak data tertaut yang bermakna dapat ditampilkan.

### 5.2 Cara memicu keterkaitan data secara otomatis

<Warning>
**Catatan: Metode ini hanya berlaku untuk skenario ketika perubahan pada Komponen formulir utama memicu keterkaitan data pada formulir utama saja atau pada sub-tabel saja.**
</Warning>

```javascript
/* Kaitkan Waktu pembaruan dengan keterkaitan */
export function didMount() {
  const instanceData = this.utils.getFormInstanceData();
  const { flowData = {} } = instanceData;
  const { editMode, viewMode } = flowData;
  if (viewMode === false && editMode === true) {
    this.$('textField_vq5mqtb').getProps().onChange();
    this.utils.toast({
      title: 'Diperbarui',
      type: 'success'
    })
  }
}
```
