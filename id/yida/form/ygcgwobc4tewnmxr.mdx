Fungsi **COUNT** menghitung total pengiriman untuk formulir tertentu.

<Note>
Fungsi ini saat ini belum mendukung operasi logis.
</Note>

## Skenario produk yang didukung

Fungsi COUNT didukung dalam skenario YiDA berikut:

- Formulir (bidang tabel utama)
- Formulir (aturan asosiasi bisnis)
- Formulir (validasi)
- Desain alur kerja (aturan validasi)
- Desain alur kerja (tindakan asosiasi)
- Node alur kerja
- Konektor

## Format

```text
COUNT(formuuid)
```

## Deskripsi atribut

| **Atribut** | **Wajib** | **Deskripsi** |
|---|---|---|
| formuuid | Ya | Pengenal unik formulir. |

## Nilai kembalian

| **Tipe nilai kembalian** | **Deskripsi** |
|---|---|
| Date object | Mengembalikan jumlah total rekam formulir saat ini. |

## Contoh

Seperti ditunjukkan di bawah, gunakan fungsi `COUNT()` untuk memperoleh jumlah total rekam formulir saat ini. Nilai parameter dapat berupa ID formulir atau komponen nomor seri.
