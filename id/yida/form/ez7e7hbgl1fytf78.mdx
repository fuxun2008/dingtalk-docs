## 1. Ikhtisar fitur

Dalam skenario bisnis yang kompleks, pengguna sering kali perlu menampilkan dan mengoperasikan data secara personal, termasuk penyaringan, pengurutan, dan pengelompokan. Antarmuka yang tidak praktis atau mode tampilan tunggal tidak dapat memenuhi kebutuhan manajemen yang beragam. Untuk mengatasi hal ini, **fitur tampilan ganda pada halaman manajemen data** meningkatkan fleksibilitas manajemen data dan pengalaman pengguna. Nilai utamanya adalah:

1. Dukungan tampilan yang beragam.
2. Kustomisasi yang fleksibel.
3. Adaptasi ke berbagai skenario.
4. Efisiensi yang lebih tinggi dalam operasi data dan manajemen tugas.

## 3. Tampilan Kisi

### 3.1. Ikhtisar

Tampilan Kisi menampilkan data formulir dalam bentuk tabel.

<Frame>
  ![](https://gw.alicdn.com/imgextra/i3/O1CN01rYYFofyjptD3gys8_!!6000000000557-2-tps-1819-961.png)
</Frame>

Selain tampilan Kisi "Semua data" default, Anda dapat membuat tampilan Kisi tambahan pada halaman manajemen data. Anda dapat memfilter data berdasarkan kondisi, menampilkan atau menyembunyikan bidang, dan mengonfigurasikan tindakan kolom untuk menampilkan data dengan aturan daftar yang berbeda.

<Frame>
  ![](https://gw.alicdn.com/imgextra/i2/O1CN01lMKoT3hKdSL1CWfo_!!6000000004631-2-tps-592-1280.png)
</Frame>

### 3.2. Skenario penggunaan

Tampilan Kisi dapat menampilkan beberapa rekaman sekaligus. Gunakan tampilan ini saat Anda perlu melihat dan mengelola data dalam jumlah besar.

### 3.3. Langkah-langkah pengaturan

#### 3.3.1. Buat tampilan

Halaman manajemen data yang dihasilkan menyediakan tampilan Kisi "Semua data" default. Anda dapat menghapusnya atau membuat tampilan baru sesuai kebutuhan bisnis Anda.

#### 3.3.2. Filter data

- Tetapkan filter data untuk tampilan. Pengguna dalam tampilan ini hanya dapat melihat data yang memenuhi kondisi filter.
- Filter mendukung banyak tingkat, AND/OR, dan berbagai jenis operator. Klik untuk melihat detail operator.

<Frame>
  ![](https://gw.alicdn.com/imgextra/i3/O1CN01JNDmCcffHkB3HYPw_!!6000000003824-2-tps-1617-1271.png)
</Frame>

#### 3.3.3. Tampilkan atau sembunyikan bidang

Jalur: Pilih tampilan Kisi > Pengaturan Kisi > Tampilkan atau sembunyikan bidang.

Tetapkan bidang yang akan disembunyikan dari pengguna dalam tampilan ini. Bidang tersembunyi tidak terlihat oleh semua pengguna dalam tabel dan tidak dapat diurutkan atau difilter di sisi pengguna.

<Frame>
  ![](https://gw.alicdn.com/imgextra/i4/O1CN01KKWFWbNU2SL42FvH_!!6000000001334-2-tps-1988-1223.png)
</Frame>

1) Pengaturan Tampilkan atau sembunyikan bidang hanya berlaku dalam daftar tampilan. Pengaturan ini tidak memengaruhi halaman Rekaman sumber atau halaman pengisian untuk satu rekaman.

2) Setiap pengguna hanya dapat melihat bidang yang berada dalam izinnya dan dapat menetapkan Tampilkan bidang secara terpisah saat melihat data. Hal ini tidak dipengaruhi oleh pengaturan tampilan.

## 4. Tampilan Lini Masa

### 4.1. Ikhtisar

Lini Masa adalah bagan Batang horizontal yang menunjukkan distribusi waktu dan durasi data tugas.

Panjang dan posisi setiap batang menunjukkan tanggal mulai, tanggal berakhir, dan durasi setiap aktivitas. Batang disusun sebagai baris, sehingga Anda dapat melihat sekilas:

- Tugas apa saja yang ada
- Tanggal mulai dan berakhir setiap tugas
- Durasi setiap tugas
- Urutan dan tumpang tindih beberapa tugas

### 4.2. Skenario penggunaan

Gunakan untuk progres tugas proyek, perencanaan produksi, progres rekayasa, penjadwalan, pelacakan progres, manajemen janji temu, dan skenario serupa.

### 4.3. Langkah-langkah pengaturan

#### 4.3.1. Buat tampilan

Jalur: Manajemen Halaman > pilih formulir di menu navigasi halaman > buat halaman manajemen data > buat tampilan > buat Lini Masa.

#### 4.3.2. Rentang waktu

Di bawah Rentang waktu, tetapkan bidang Tanggal dasar untuk Lini Masa, termasuk bidang tanggal mulai dan tanggal berakhir serta skala waktu. Rekaman ditampilkan sebagai batang berdasarkan bidang ini.

- "Waktu mulai" dan "Waktu berakhir" secara default menggunakan "Waktu pembuatan" dan "Waktu modifikasi" rekaman. Anda dapat memilih komponen Tanggal atau komponen rentang tanggal dari formulir utama. Jika Anda memilih komponen rentang tanggal, "Waktu mulai" dan "Waktu berakhir" menggunakan bidang yang sama.

- Opsi skala waktu: berdasarkan tahun, kuartal, bulan, atau minggu.

#### 4.3.3. Filter data dan visibilitas bidang

- Logika filter data Lini Masa sama dengan tampilan Kisi.
- Logika visibilitas bidang Lini Masa sama dengan tampilan Kisi. Pengguna menetapkan Tampilkan bidang di daftar sisi kiri.

## 5. Pengaturan tampilan Umum

Pengaturan tampilan Umum adalah **konfigurasi tampilan default** yang ditetapkan oleh admin di backend admin. Dalam mode tampilan, pengguna dapat **mengubah pengaturan sementara**, tetapi perubahan sementara tidak dapat disimpan. Saat pengguna membuka kembali tampilan, konfigurasi default admin dipulihkan.

### 5.1. Mode admin

Di backend Kelola Aplikasi, admin mengonfigurasikan Filter, kolom dan urutan yang ditampilkan, Aturan pengurutan rekaman, tinggi baris, dan pengaturan lainnya, lalu mengklik Simpan untuk menyediakan konfigurasi tampilan default bagi mode tampilan.

  ![](https://gw.alicdn.com/imgextra/i3/O1CN01CKM3NlZA9hG42884_!!6000000002560-2-tps-1987-1265.png)

Tampilan Kisi mendukung empat gaya tinggi baris: rendah, sedang, tinggi, dan sangat tinggi.

### 5.2. Mode tampilan

Dalam mode tampilan, pengguna dapat mengubah Filter, kolom dan urutan yang ditampilkan, Aturan pengurutan rekaman, dan tinggi baris secara sementara berdasarkan konfigurasi default admin. Perubahan sementara tidak dapat disimpan. Saat pengguna membuka kembali tampilan, konfigurasi default admin dipulihkan.
