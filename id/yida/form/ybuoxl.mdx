## 1. Pendahuluan

### 1.1 Gambaran fitur

Setelah menentukan data yang akan dikumpulkan, buat formulir dan rancang sesuai kebutuhan Anda.

### 1.2 Skenario penggunaan

Tersedia dua jenis formulir. Formulir biasa mencakup fitur kolaborasi dan mendukung pengelolaan data berbasis izin. Formulir alur kerja mencakup fitur alur kerja serta mendukung desain alur kerja.

Tersedia dua cara untuk membuat formulir:

- **Buat dari kosong**
- **Buat dari templat**
- **Buat formulir dari Excel** (menggunakan header Excel sebagai komponen)

## 2. Cara membuat formulir

**Jalur**: Buka meja kerja YiDA >> Klik Aplikasi Saya atau Buat baru >> Masuk ke editor aplikasi.

### 2.1 Langkah-langkah

(1) Pada halaman App Center saat ini, klik Buat formulir kosong.

<Frame>
  ![](https://gw.alicdn.com/imgextra/i2/O1CN01grByRcYuxyJ3hjg1_!!6000000000310-2-tps-1825-872.png)
</Frame>

(2) Di bagian atas panel navigasi kiri aplikasi, klik Buat halaman, lalu pilih Buat formulir dari menu tarik-turun.

<Frame>
  ![](https://gw.alicdn.com/imgextra/i2/O1CN01KCCCZaN8R1K3iMhP_!!6000000007044-2-tps-1830-869.png)
</Frame>

<Warning>
Catatan: Setelah alur kerja berakhir, data formulir alur kerja tidak dapat diedit. Rencanakan dengan cermat.
</Warning>

## 5. Buat dari Excel

Siapkan spreadsheet Excel secara lokal, lalu impor langsung ke YiDA.

**Jalur**: Klik aplikasi target >> Buat formulir >> Impor dari Excel.

<Frame>
  ![](https://gw.alicdn.com/imgextra/i4/O1CN01InrFt0Q1QnI3hjfw_!!6000000000501-2-tps-1825-867.png)
</Frame>

<Frame>
  ![](https://gw.alicdn.com/imgextra/i4/O1CN01DcLgaheRnDF3hU4K_!!6000000006534-2-tps-1823-877.png)
</Frame>

Unggah data spreadsheet.

Untuk detail impor massal, lihat: [Impor massal](/id/yida/form/andrke).

<Note>
- Aplikasi harus dipublikasikan sebelum diimpor. Untuk detailnya, lihat Aktifkan atau nonaktifkan aplikasi.
- Formulir umumnya digunakan untuk mengumpulkan data dan tidak menyertakan proses persetujuan saat pengiriman. Jika Anda memerlukan kemampuan proses persetujuan, gunakan formulir alur kerja.
</Note>
