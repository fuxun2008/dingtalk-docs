Pengaturan umum tampilan memungkinkan admin menetapkan **konfigurasi tampilan default** di konsol admin. Pengguna dalam mode tampilan dapat melakukan **perubahan sementara** di atas baseline ini, tetapi perubahan tersebut tidak dapat disimpan. Saat pengguna dalam mode tampilan kembali, konfigurasi default yang ditetapkan admin akan dipulihkan.

### Mode admin

Di konsol admin aplikasi, admin mengonfigurasikan filter, tampilan dan urutan kolom, aturan pengurutan baris, tinggi baris, serta pengaturan lainnya, lalu klik **Simpan** untuk menyediakan konfigurasi tampilan default bagi mode tampilan.

<Frame>
  ![](https://gw.alicdn.com/imgextra/i3/O1CN01CKM3NlZA9hG42884_!!6000000002560-2-tps-1987-1265.png)
</Frame>

Tampilan Kisi mendukung empat gaya tinggi baris: Rendah, Sedang, Tinggi, dan Sangat tinggi. Konfigurasikan tinggi baris untuk setiap tampilan.

### Mode tampilan

Berdasarkan konfigurasi default admin, pengguna dalam mode tampilan dapat melakukan perubahan sementara pada filter, tampilan dan urutan kolom, aturan pengurutan baris, tinggi baris, serta pengaturan lainnya. Perubahan sementara dapat disimpan, dan konfigurasi mode tampilan terbaru akan ditampilkan saat pengguna kembali.

<Frame>
  ![](https://gw.alicdn.com/imgextra/i3/O1CN01vtqqlmyMxqD6kBPO_!!6000000006153-2-tps-3322-1640.png)
</Frame>

<Warning>
Setelah **pengunjung aplikasi** menyegarkan halaman, urutan formulir saat ini akan dipertahankan. Untuk memulihkan pengaturan default (yaitu urutan yang ditetapkan oleh editor aplikasi), buka browser dan bersihkan cache. Langkah-langkah di bawah ini menggunakan Chrome sebagai contoh.
</Warning>
