## Ikhtisar

Komponen nomor identitas memvalidasi format nomor identitas, **tetapi tidak memverifikasi keabsahan atau validitas nomor tersebut.**

| **Item konfigurasi** | **Deskripsi** | **Atribut** |
|---|---|---|
| **Judul** | Mengatur judul tampilan komponen. Mendukung konten multibahasa dan variable binding. | lable |
| **Placeholder** | Mengatur konten default yang ditampilkan di kotak input. Mendukung konten multibahasa dan variable binding. | placeholder |
| **Deskripsi** | Deskripsi yang ditampilkan di bawah komponen, umumnya digunakan untuk informasi tambahan. | tips |
| **Status** | Mengatur status komponen. Mendukung empat status: Normal, Dinonaktifkan, Hanya Baca, dan Tersembunyi. | behavior |

## Catatan

- Komponen nomor identitas hanya ditampilkan pada halaman detail formulir dan halaman manajemen data daftar (halaman manajemen data tidak mendukung tindakan Ekspor, Impor, atau edit). Komponen ini dapat digunakan pada halaman desain formulir, tetapi tidak didukung atau ditampilkan pada skenario lain.
- Komponen nomor identitas memvalidasi format nomor identitas secara otomatis. Karena data bersifat sensitif, sistem menyimpannya dalam bentuk terenkripsi. Tangani data tersebut dengan aman.
