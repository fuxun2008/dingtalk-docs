**Artikel ini menghimpun dokumen contoh yang tersedia untuk Formula Fungsi. Klik nama contoh untuk membuka halaman konfigurasi terperinci, seperti ditunjukkan pada tabel berikut:**

| **Tautan contoh** | **Fungsi yang digunakan** |
|---|---|
| Cara mengambil nama Departemen induk | DEPTNAME |
| Cara membatasi jumlah hari cuti tahunan | DAYS |
| Cara menentukan tingkat nilai berdasarkan skor | IF |
| Membuat string acak dengan panjang tetap | UUID |
| Menghitung shio secara otomatis dari nomor KTP | IF, EQ, MOD, LEN, VALUE |
| Menghitung jenis kelamin secara otomatis dari nomor KTP | IF, EQ, MID, OR |
| Menghitung provinsi secara otomatis dari nomor KTP | IF, EQ, MID, LEN, VALUE |
| Mengambil tanggal lahir dari nomor KTP | IF, EQ, MID, CONCATENATE, LEN |
| Menghitung zodiak secara otomatis dari nomor KTP | IF, EQ, MID, LEN, VALUE, GE, AND, LE |
| Menghitung usia secara otomatis dari nomor KTP | IF, EQ, LEN, VALUE, TODAY, TEXT, RIGHT, LEFT |
| Cara menyamarkan sebagian Nomor Telepon | REPLACE |
| Cara memilih pertanyaan secara acak | Implementasi kode |
| Cara mengubah teks menjadi Format tanggal | MID, DATE, TIMESTAMP |
| Menambahkan sepuluh hari secara otomatis ke sebuah tanggal | DATEDELTA, DATE, IF, ISEMPTY |
| Kalkulator pajak penghasilan pribadi terbaru | IF, AND, EQ, LE, GT |
| Cara menghitung nilai rata-rata dari beberapa juri | MAX, VALUE, ARRAYGET, SPLIT, MIN, CONCATENATE |
| Cara mengubah ukuran Judul | Implementasi kode |
| Cara mengatur Format persen | TEXT |
| Membuat alamat email secara otomatis dari nomor QQ | IF, ISEMPTY, CONCATENATE |
| Cara mengatur jumlah desimal | ROUND |
| Cara mengonversi Angka menjadi huruf kapital | RMBFORMAT, INT |
| Menangani Angka di dalam string | EQ, VALUE |
| Cara menghitung masa kerja | INT, DAYS, DATE, IF, OR, ISEMPTY |
| Izinkan setiap Pengguna mengirim hanya satu Rekam per hari | USER, SYSTIME, TIMESTAMP, TEXT, DATE, EXIST |
| Cara menghitung harga setelah diskon | SUM, IF, LT |
| Cara membagi jumlah faktur | IF, GT, AND, LE, RIGHT, LEFT, INT |
| Cara membuat nomor seri dengan Format tetap | COUNT |
| Cara mengambil informasi manajer | DEPTNAME |
| Cara mengambil waktu akhir dari rentang tanggal menggunakan Formula | MID, SEARCH |
