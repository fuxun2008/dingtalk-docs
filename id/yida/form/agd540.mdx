## 1. Formulir terkait

### 1.1 Apa itu formulir terkait

Komponen formulir terkait menautkan data dari formulir lain dan mengisi data tersebut ke komponen dalam formulir saat ini.

Komponen ini juga mendukung penyaringan saat mengambil data dari formulir terkait.

<Frame>
  ![](https://gw.alicdn.com/imgextra/i3/O1CN01yxjfYfEG01G3hzHh_!!6000000001760-2-tps-1827-866.png)
</Frame>

Komponen formulir terkait

**Catatan: Pada versi terbaru,** formulir terkait mendukung formulir lintas aplikasi.

#### 1.2 Kasus penggunaan

- Lihat data dari formulir lain di formulir saat ini dan buka dengan sekali klik.

|---|---|

| Pilih Banyak | Pilih Banyak, Pilih Banyak Dropdown, Numerik |

| Teks multi-baris | Pilih, Pilih Dropdown, Teks satu baris, Teks multi-baris, Numerik |
| Tipe lain (seperti Alamat) | Hanya tipe yang sama (seperti Alamat) |
| [Bidang sistem] ID Instance (saat ini hanya didukung untuk pengisian subformulir) | Teks satu baris |

**① Atur Filter**

- Tersedia dua tipe: nilai dan bidang.

Nilai: nilai tetap. Masukkan atau Pilih nilai di kotak input atau kontrol di sebelah kanan.

Bidang: Kondisi berubah secara dinamis berdasarkan nilai bidang pada halaman saat ini, yang memengaruhi Daftar Dropdown dan Hasil pencarian.

**Catatan:**

<Frame>
  ![](https://gw.alicdn.com/imgextra/i3/O1CN01bbTHaA7xMFD26fHA_!!6000000001756-2-tps-1038-270.png)
</Frame>

- Data terkait yang sudah Dipilih tidak terpengaruh oleh perubahan Kondisi, dan tidak dihapus meskipun Kondisi tidak lagi terpenuhi.
- Setiap bidang hanya mendukung satu set Filter. Beberapa Komponen, seperti rentang tanggal, mendukung Kondisi rentang terpisah.

<Accordion id="q5" title="T: Formulir terkait saya memiliki lebih dari 20 rekaman tetapi hanya 20 yang ditampilkan. Bagaimana cara mengakses sisanya?">
  Formulir terkait hanya menampilkan 20 rekaman secara default. Masukkan kata kunci untuk mencari konten lainnya.
</Accordion>
<Accordion id="q6" title="T: Apakah formulir terkait mendukung impor massal?">
  Ya. Untuk aturan impor, lihat https://docs.aliwork.com/docs/yida_updates/gddpov#k27QX.
</Accordion>
<Accordion id="q7" title="T: Apakah formulir terkait mendukung pengaturan deduplikasi?">
  Belum. Sebagai solusi, gunakan aturan asosiasi bisnis untuk menyinkronkan data ke tabel perantara, jaga agar data di tabel tersebut tetap unik, dan atur tabel perantara sebagai Sumber Data dari formulir terkait.
</Accordion>
<Accordion id="q8" title="T: Bagaimana jika muncul Pesan error 'Data does not meet the filter conditions'?">
  Pesan error ini disebabkan oleh spasi pada data terkait. Hapus spasi dari data terkait.
</Accordion>
<Accordion id="q9" title="T: Mengapa bidang yang dipilih pada formulir terkait ditampilkan sebagai ID instance?">
  Periksa apakah bidang tersebut disembunyikan di grup izin tampilan (Izin Lihat) formulir terkait. Jika disembunyikan, bidang menampilkan -- saat Anda memilih data terkait, dan ID instance dari rekaman ditampilkan setelah pemilihan.
</Accordion>
<Accordion id="q10" title="T: Mengapa EQ(komponen formulir terkait, 'aaa') menampilkan error?">
  Komponen formulir terkait belum dapat digunakan sebagai Kondisi dalam aturan asosiasi bisnis, seperti formula UPSERT. Dalam kasus tersebut, gunakan komponen `Pilih Dropdown` atau `Pilih Banyak Dropdown` sebagai gantinya.
</Accordion>
