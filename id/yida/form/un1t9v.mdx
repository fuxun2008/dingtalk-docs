## 1. Aturan validasi

### 1.1 Kasus penggunaan aturan validasi formulir

(1) Memvalidasi apakah data dalam formulir memenuhi aturan. Ketika aturan validasi terpenuhi, data tidak dapat dikirim; ketika aturan validasi tidak terpenuhi, pengiriman diizinkan.

(2) Teks prompt untuk memblokir pengiriman muncul saat aturan validasi terpenuhi.

(3) Aturan validasi ditulis menggunakan [**Formula Yida**](/id/yida/form/gvtpe4).

**Jalur untuk mengatur aturan validasi**: Halaman edit formulir >> Klik Pengaturan Formulir di sudut kanan atas >> Validasi formula

**Catatan**: Validasi ini saat ini tidak berlaku pada aturan integrasi & otomatisasi dan asosiasi bisnis pada formulir reguler.

## 2. Skenario kasus dan langkah operasi

### 2.1 Skenario kasus

Terdapat formulir entri informasi faktur yang mencakup empat kolom: nomor faktur, tanggal faktur, tipe faktur, dan jumlah faktur. Data hanya dapat dikirim ketika kondisi validasi berikut terpenuhi:

(1) Nomor faktur: memvalidasi keunikan

(2) Tanggal faktur berada dalam 30 hari

(3) Jumlah faktur antara 0 dan 50000

### 2.2 Langkah operasi

(1) Pengaturan Formulir >> Atribut di sebelah kanan >> Tambah formula

Atur formula validasi

Halaman edit formula

(2) Atur kondisi pertama: keunikan nomor faktur.

**Catatan**: Fungsi [**EXIST**](/id/yida/form/vwncwe) digunakan untuk memvalidasi keunikan kolom formulir (deduplikasi), menentukan apakah nilai parameter sudah ada dalam data yang telah dikirim.

Format formula: `EXIST(Invoice Number)`, yang berarti menentukan apakah nomor faktur yang dikirim kali ini sudah ada dalam data yang telah dikirim. Jika sudah ada, pengiriman diblokir; jika belum ada, pengiriman diizinkan.

Seperti ditunjukkan di bawah ini:

Menggunakan fungsi EXITS

Prompt kesalahan

(3) Klik Tambah formula dan atur kondisi kedua: tanggal faktur dalam 30 hari

Formulanya adalah: `GE(DAYS(TODAY(),DATE(Invoice Date)),30)`

Untuk informasi tentang penggunaan fungsi, lihat: [**Penggunaan Fungsi Logika**](/id/yida/form/mnx96u) [**Penggunaan Fungsi Tanggal**](/id/yida/form/dh7m8n)

Menggunakan formula GE(DAYS(TODAY(),DATE())

Prompt kesalahan

(4) Terakhir, atur kondisi validasi untuk jumlah faktur: jumlah faktur antara 0 dan 50000

Formulanya adalah: `OR(LE(Invoice Amount,0),GE(Invoice Amount,50000))`. Ini berarti ketika jumlah faktur kurang dari atau sama dengan 0 atau lebih besar dari atau sama dengan 50000, pengiriman tidak diizinkan. Untuk penggunaan fungsi, lihat: [**Penggunaan Fungsi Logika**](/id/yida/form/mnx96u)

Menggunakan formula OR(LE(),GE())

Prompt kesalahan

**Catatan**: Setelah mengatur aturan, ingatlah untuk mengklik Simpan.
