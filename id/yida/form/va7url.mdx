## 1. Apa itu pengiriman massal

Formulir alur kerja YiDA memungkinkan admin aplikasi mengirim alur kerja secara massal dengan mengunggah file Excel dari backend aplikasi.

Pengiriman massal saat ini mendukung kemampuan berikut:

(1) Mengirim alur kerja atas nama orang lain. Jika salah satu kolom dalam file Excel berisi informasi Pengirim, Anda dapat menetapkan kolom tersebut sebagai Pengirim alur kerja.

(2) Mengirim alur kerja menggunakan akun publik platform YiDA. Misalnya, saat melacak penyelesaian keluhan pengguna eksternal, Pengirim tidak boleh berupa individu, melainkan akun publik.

(3) Menetapkan penangan alur kerja secara dinamis berdasarkan kolom tertentu dalam file Excel. Misalnya, dalam file Excel yang melacak tindak lanjut pelanggan eksternal, salah satu kolom mungkin berisi pemilik tindak lanjut. Anda dapat menetapkan kolom tersebut sebagai penangan alur kerja saat pengiriman.

(4) Menghapus data yang dikirim secara massal berdasarkan batch. Jika pengiriman massal gagal atau tidak sesuai harapan, hapus data langsung berdasarkan batch.

(5) Spesifikasi format untuk data kolom Excel.

## 3. FAQ

<AccordionGroup>
<Accordion title="3.1 Mengapa pengiriman massal gagal?">
  Ketika pengiriman massal gagal, periksa hal berikut:

  (1) Apakah Aplikasi sudah dipublikasikan. Pengiriman massal hanya berfungsi setelah Aplikasi dipublikasikan.

  (2) Apakah Pengirim dikustomisasi sebagai komponen anggota pada Formulir. Jika ya, periksa apakah kotak pencarian pengguna memiliki nilai dan apakah formatnya benar.

  (3) Maksimum 1.000 record dapat diimpor sekaligus, dan ukuran file tidak boleh melebihi 20 MB.

  (4) Hanya file `*.xls` dan `*.xlsx` yang didukung.

  (5) Pastikan baris header pada sheet yang ingin Anda impor tidak memiliki sel kosong. Jika ada, data pada sheet tersebut tidak akan diimpor.

  (6) Data yang diimpor secara massal tidak mendukung kondisi filter berdasarkan "variabel bawaan".

  (7) File yang diimpor tidak mendukung kalkulasi Formula Excel seperti `SUM` atau `=H2*J2`.

  (8) Gambar dan Lampiran yang diimpor diunggah ulang ke penyimpanan dan mengonsumsi kapasitas Lampiran.
</Accordion>
