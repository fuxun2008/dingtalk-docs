## 1. Kasus penggunaan

Komponen pemilih sekolah dirancang untuk skenario K12 yang membutuhkan pemilihan sekolah, dan paling umum digunakan pada aplikasi untuk dinas pendidikan.

## 2. Fitur dasar

**Mode edit formulir:**

| **Mode edit formulir** | **Mode runtime formulir** |
|---|---|

- Jika sebuah Organisasi pendidikan telah menautkan sekolah-sekolah di bawahnya melalui asosiasi Organisasi, Komponen ini memungkinkan pengguna Pilih dari sekolah-sekolah yang terasosiasi. Jika dinas pendidikan telah mengategorikan sekolah-sekolah bawahannya melalui aplikasi manajemen dinas-sekolah, Komponen akan menampilkan daftar sekolah berdasarkan kategori.
- Jika sebuah Organisasi pendidikan belum menautkan sekolah bawahan mana pun melalui asosiasi Organisasi, Komponen hanya dapat Pilih sekolah saat ini.

## 3. Atribut

### 3.2 Mode Pilih Banyak

- Mode Pilih tunggal diaktifkan secara default. Untuk Pilih beberapa sekolah, aktifkan mode Pilih Banyak. Jika hanya satu sekolah yang perlu dipilih, nonaktifkan tombol ini.

## 4. Sumber data

Jika Organisasi saat ini telah menautkan sekolah-sekolah bawahan, semua sekolah yang terasosiasi dapat dipilih. Jika Organisasi telah mengategorikan sekolah-sekolah yang terasosiasi, sekolah akan ditampilkan berdasarkan kategori. Jika Organisasi saat ini belum menautkan sekolah bawahan mana pun, hanya Organisasi saat ini yang dapat dipilih.

## 5. Cakupan pemilihan

| **Tipe Organisasi** | **Cakupan pemilihan** |
|---|---|
| Organisasi terasosiasi | Beberapa sekolah dapat dipilih |
| Organisasi tidak terasosiasi | Tidak dapat Pilih sekolah lain |
