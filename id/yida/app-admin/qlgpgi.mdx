Pengaturan Izin aplikasi menentukan Admin untuk sebuah Aplikasi. Admin aplikasi dapat mengedit, mengonfigurasi, dan mengelola data Aplikasi. Artikel ini menjelaskan cara mengonfigurasi Izin aplikasi.

<Note>
- Edisi Gratis YiDA tidak perlu mengaktifkan Admin aplikasi. Secara default, setiap Pengguna dapat membuat Aplikasi.
- Edisi berbayar YiDA perlu mengaktifkan Admin aplikasi secara terpisah. Hanya Pengguna yang ditetapkan sebagai Admin aplikasi yang dapat membuat Aplikasi.
</Note>

## Menetapkan Admin aplikasi

1. Masuk ke workbench YiDA dan klik untuk membuka Halaman **Aplikasi Saya**.
2. Pilih Aplikasi target, lalu pilih **···** > **Pengaturan Aplikasi**.

<Frame>
  ![](https://gw.alicdn.com/imgextra/i4/O1CN01obvVNYkScUL2hAj3_!!6000000000624-2-tps-1328-681.png)
</Frame>

3. Pada menu sebelah kiri Halaman Pengaturan Aplikasi, klik **Izin aplikasi** > **Admin aplikasi**.
4. Klik **Tetapkan Pengguna** di bawah setiap Peran, Pilih Pengguna yang sesuai, lalu klik **Konfirmasi**.

<Frame>
  ![](https://gw.alicdn.com/imgextra/i1/O1CN018ljZMUzBMyJ2i3PB_!!6000000003041-2-tps-1335-862.png)
</Frame>

## Kelola izin

Kelola izin menyediakan tampilan terpusat untuk mengonfigurasi Izin di semua jenis Halaman dalam Aplikasi.

1. Masuk ke workbench YiDA, Cari Aplikasi target, dan buka Halaman **Pengaturan Aplikasi**.
2. Pada menu sebelah kiri Halaman Pengaturan Aplikasi, klik **Izin aplikasi** > **Kelola izin**.
3. Cari Halaman yang Izin-nya ingin Anda kelola dan edit di sebelah kanan.

  ![](https://gw.alicdn.com/imgextra/i4/O1CN01qvo35iot5CD5nlyk_!!6000000000728-2-tps-2858-1328.png)
</Frame>

## Detail Izin

Izin setiap Pengguna dalam sebuah Aplikasi dijelaskan di bawah ini:

| **Pengguna** | **Deskripsi** |
|---|---|
| **Super Admin Aplikasi** | Super Admin Aplikasi memiliki Izin penuh di konsol Admin aplikasi, termasuk pembangunan Aplikasi, pengeditan, konfigurasi, dan manajemen data. |
| **Admin Data** | Admin Data memiliki Izin **terkait manajemen data**, dan dapat mengelola data Aplikasi, membangun laporan, serta mengelola dataset dan layanan data. Peran ini tidak memiliki Izin untuk desain Formulir, desain alur kerja, halaman kustom, Pengaturan Halaman, atau konfigurasi Admin aplikasi. |
| **Developer** | Developer memiliki **Izin pengembangan Aplikasi kecuali manajemen data**. Peran ini tidak memiliki Izin untuk manajemen data Aplikasi, pembangunan laporan, manajemen dataset, atau konfigurasi Admin aplikasi. |

<Note>
Admin platform dan Admin aplikasi harus dikonfigurasi di Halaman **manajemen platform**. Untuk detailnya, lihat [Manajemen Izin platform](/id/yida/platform-admin/omvowq).
</Note>
