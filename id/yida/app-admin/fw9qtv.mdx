## Apa itu layanan data?

Layanan data memproses sebuah dataset dengan memilih bidang tertentu dan mengeksposnya sebagai API. Saat ini, layanan data hanya dapat dikonsumsi di dalam node kartu pada integrasi & otomatisasi atau perancang alur kerja.

<Note>
**Catatan:**

- Ketika Anda membutuhkan beberapa metrik data yang independen, pertahankan satu layanan data terpisah untuk setiap metrik dan konsumsi masing-masing secara individual di dalam integrasi & otomatisasi.
- Hanya Super Admin dan admin data yang dapat melihat dan mengelola layanan data.
- Izin:

- Cakupan konsumsi: Di node "Ambil satu rekam" atau "Ambil banyak rekam" pada integrasi & otomatisasi atau perancang alur kerja sederhana, atur sumber data ke Data Factory > Layanan Data untuk mengonsumsi data yang didefinisikan oleh layanan data.
</Note>

## Mengambil layanan data

Titik masuk: Integrasi & Otomatisasi > Perancang Alur Kerja Sederhana > node Ambil Banyak Rekam > node Ambil Satu Rekam > Dari Data Factory > Layanan Data.

Tambahkan node "Ambil banyak rekam" di dalam integrasi & otomatisasi. Ketika sumber data diatur ke **Data Factory** > **Layanan Data**, node tersebut akan mengembalikan data agregasi yang dihitung oleh layanan data.
