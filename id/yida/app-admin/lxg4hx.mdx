Platform YiDA memungkinkan Anda mengustomisasi URL akses aplikasi agar lebih mudah dipromosikan dan dibagikan. Konfigurasikan hal ini di halaman pengaturan aplikasi. Artikel ini menjelaskan cara menyiapkan URL akses kustom untuk sebuah aplikasi.

## Prosedur

1. Masuk ke workbench YiDA, lalu klik **Aplikasi Saya**.
2. Cari aplikasi yang dituju, lalu klik **···** > **Pengaturan Aplikasi** di sudut kanan bawah aplikasi untuk membuka halaman pengaturan.

  <Step title="Di halaman Pengaturan Dasar, buka bagian URL Akses, lalu masukkan URL kustom pada bidang URL Akses Aplikasi Kustom.">
    <Note>
    URL kustom hanya mendukung huruf Inggris besar dan kecil, angka, garis bawah (_), tanda hubung (-), dan garis miring (/). Jika URL yang Anda inginkan sudah dipakai, tambahkan akhiran untuk membuatnya unik. Contoh: `your_personal-address/enjoy/01`.
    </Note>
