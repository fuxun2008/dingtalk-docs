YiDA memungkinkan Anda mempublikasikan sebuah Aplikasi, atau Formulir individual di dalam Aplikasi, ke workbench Organisasi Anda. Anda juga dapat menginstal plugin Aplikasi YiDA di Obrolan Grup. Bab ini menjelaskan cara mempublikasikan Aplikasi YiDA.

Isi bab ini:

- Mempublikasikan Aplikasi
- Mempublikasikan halaman Login senyap
- Mempublikasikan halaman Formulir secara publik
- Menambahkan Aplikasi ke Grup
