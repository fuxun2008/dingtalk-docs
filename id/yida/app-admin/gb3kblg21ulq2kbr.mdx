## 1. Pendahuluan

### 1.1 Ringkasan fitur

Seiring percepatan transformasi digital perusahaan, kebutuhan akan pemrosesan dan analisis data terus meningkat. Alat pelaporan tradisional makin menunjukkan keterbatasan saat menangani volume data besar dan logika bisnis yang kompleks, terutama pada area berikut:

### 1.2 Skenario penggunaan

- Pelaporan dan analisis keuangan: Tim keuangan perlu menyusun laporan seperti laporan laba rugi, neraca, dan laporan arus kas secara berkala. QBI mengumpulkan data dan membuat laporan secara otomatis, sehingga meningkatkan akurasi sekaligus efisiensi.
- Analisis penjualan dan pemasaran: Tim penjualan perlu memantau tren pasar, perilaku pelanggan, dan pola penjualan untuk menyempurnakan strategi. QBI membantu mereka mengakses informasi tersebut dengan cepat dan melakukan analisis mendalam.
- Pemantauan performa operasional: Tim operasional perlu visibilitas real-time terhadap metrik seperti efisiensi produksi, tingkat inventaris, dan status rantai pasokan. QBI menyediakan dasbor dan peringatan real-time sehingga tim dapat segera mengidentifikasi masalah dan mengambil tindakan.

## 2. Prosedur

### 2.1 Aktifkan laporan data premium

#### 2.1.1 Aktifkan untuk aplikasi yang sudah ada

1. Setelah pelanggan melakukan pemesanan di Entitlement Center, tim dukungan YiDA mengaktifkan atau menonaktifkan fitur laporan data premium secara manual di backend.
2. Lokasi: Manajemen Platform > Informasi Dasar > Fitur Premium.

<Frame>
  ![](https://gw.alicdn.com/imgextra/i4/O1CN01Fz3YD8yHCqH6ivMk_!!6000000000879-2-tps-3312-1654.png)
</Frame>

#### 2.1.2 Aktifkan saat membuat aplikasi

1. Buka backend Kelola Aplikasi YiDA dan klik **Buat Aplikasi**.
2. Isi informasi dasar aplikasi di kotak dialog.
3. Pada dialog Buat, klik **Pengaturan Aplikasi Lainnya** dan aktifkan App-Dedicated Storage, App-Dedicated Physical Columns, App-Dedicated Environment, dan Premium Reports Isolated Database.

<Frame>
  ![](https://gw.alicdn.com/imgextra/i3/O1CN01iMjGSJ4YUnK5wpxk_!!6000000007277-2-tps-2930-1522.png)
</Frame>

<Note>
- Setelah App-Dedicated Storage diaktifkan, data aplikasi disimpan dalam mode penyimpanan khusus dan tidak dapat dikembalikan.
- Setelah App-Dedicated Physical Columns diaktifkan, rilis aplikasi mendukung physical column.
- Setelah App-Dedicated Environment diaktifkan, rilis aplikasi mendukung deployment lingkungan independen dan kemampuan sandbox multi-versi.
- Setelah Premium Reports Isolated Database diaktifkan, isolated database secara independen mendukung kemampuan laporan premium.
</Note>
