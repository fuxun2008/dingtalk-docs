Fitur persiapan data bawaan YiDA berperan sebagai alat ETL tanpa kode. Tanpa menulis SQL sedikit pun, profesional non-BI dapat mengasosiasikan, menggabungkan, mengagregasi, dan membersihkan data dari dataset YiDA mana pun, lalu menghasilkan data olahan sebagai dataset YiDA standar. Kemampuan ini memberi pengembangan low-code kekuatan untuk membuka nilai data.

Setiap node menyediakan panel konfigurasi dan papan pratinjau data tersendiri. Setiap kanvas persiapan data mendukung hingga 2 node output, dan setiap node output otomatis menghasilkan dataset yang bersesuaian.

## Batasan penggunaan

**Volume data per node dibatasi hingga 2 juta rekam.** Melebihi batas ini akan menyebabkan pemrosesan data ETL gagal.

## Node input

Node input dapat dibuat dari dataset YiDA atau Sumber Data yang sudah ada, mencakup formulir, formulir lintas aplikasi, MySQL, SQL Server, Oracle, file Excel, dan dataset lain yang sudah ada. Anda juga dapat membuat data input dengan cepat berdasarkan tabel dalam Sumber Data database.

Seret node **Input** dari panel node di sebelah kiri ke kanvas di tengah. Pilih sumber input data untuk mulai membangun alur data.

YiDA adalah platform pengembangan aplikasi low-code untuk perusahaan. YiDA mendukung data dari aplikasi YiDA, database eksternal perusahaan, file eksternal perusahaan, dan [data resmi DingTalk](/id/yida/app-admin/rgtg45e6z9vwlgso) (termasuk direktori karyawan, OA, smart HR, absensi, dan lainnya).

## Node output

Node output mendukung penulisan data ke tabel database target yang sudah ada (setiap penulisan akan menghapus data asli di tabel tersebut lalu memasukkan data baru) atau ke tabel database yang baru dibuat.

## Node asosiasi

Serupa dengan fitur asosiasi multi-tabel di YiDA, node ini melakukan penggabungan horizontal atas dua dataset atau lebih berdasarkan kondisi yang ditentukan. Node ini setara dengan operasi Gabung di SQL dan mendukung left join, inner join, serta right join.

<Note>
Gabung adalah operasi kueri database yang umum untuk menyatukan data dari dua tabel atau lebih berdasarkan kondisi yang ditentukan.

Terdapat empat tipe join utama: inner join, left join, right join, dan outer join. Setiap tipe dijelaskan di bawah ini beserta contoh kasus penggunaannya.

#### Inner join

- Definisi: Inner join hanya mengembalikan rekam yang memenuhi kondisi join di kedua tabel.
- Kasus penggunaan: Gunakan inner join saat Anda menginginkan rekam yang tersedia di kedua tabel. Misalnya, dari tabel pelanggan dan tabel pesanan, Anda hanya menginginkan rekam yang ada di kedua tabel.

#### Left join

- Definisi: Left join mengembalikan semua rekam dari tabel kiri ditambah rekam yang cocok dari tabel kanan. Jika tidak ada kecocokan di tabel kanan, kolom terkait dalam hasil akan bernilai null.
- Kasus penggunaan: Gunakan left join saat Anda ingin menyertakan semua rekam dari tabel kiri, bahkan ketika tidak ada kecocokan di tabel kanan. Misalnya, menampilkan semua pelanggan beserta pesanannya, termasuk pelanggan yang belum pernah memesan.

#### Right join

- Definisi: Right join mengembalikan semua rekam dari tabel kanan ditambah rekam yang cocok dari tabel kiri. Jika tidak ada kecocokan di tabel kiri, kolom terkait dalam hasil akan bernilai null.
- Kasus penggunaan: Serupa dengan left join, tetapi berlawanan arah. Misalnya, menampilkan semua pesanan beserta informasi pelanggan yang bersesuaian, termasuk pesanan yang informasi pelanggannya tidak tersedia.

#### Full outer join

- Definisi: Full outer join mengembalikan semua rekam yang memenuhi kondisi join, baik dari tabel kiri maupun tabel kanan. Jika tidak ada kecocokan di salah satu tabel, kolom terkait dalam hasil akan bernilai null.
- Kasus penggunaan: Gunakan full outer join saat Anda menginginkan semua rekam dari kedua tabel, terlepas ada atau tidaknya kecocokan di tabel lain. Misalnya, menampilkan semua pelanggan dan semua pesanan, termasuk pelanggan tanpa pesanan dan pesanan tanpa informasi pelanggan.
</Note>

## Node penggabungan

Menambahkan dan menggabungkan data bidang bertipe sama secara vertikal. Node ini mendukung penambahan pada tingkat baris di beberapa dataset. Sebagai fitur penumpukan data baru di YiDA, node ini setara dengan operasi Union di SQL dan memungkinkan penggabungan data secara vertikal pada tingkat baris.

## Node agregasi

Mengelompokkan data berdasarkan tipe tertentu, lalu menghitung nilai untuk setiap Grup. Metode perhitungan mencakup hitung, jumlah, maks, min, dan operasi peringkasan lainnya. Dengan mengombinasikan node agregasi dan node lainnya, Anda dapat membangun bidang metrik statistik sehingga pemrosesan hilir lebih mudah menghasilkan bidang dan data.

**Agregasi data** menyatukan data dari berbagai sumber yang tersebar, lalu menggabungkan dan menghitungnya sesuai aturan yang ditentukan untuk menghasilkan informasi yang lebih bermakna. Misalnya, dari tabel rekam penjualan yang berisi angka penjualan Harian, agregasi dapat menghasilkan total penjualan per bulan atau per tahun.

## Node pembersihan

Melakukan penyuntingan data yang lebih rinci pada data yang diterima dari node hulu. Sebagai node pemrosesan utilitas, node ini memungkinkan Anda mengganti nama bidang, mengubah tipe bidang, membuat bidang dinamis baru dengan rumus (Fx), mengonfigurasi kondisi filter data, dan lainnya.

**Berikut adalah pengetahuan dasar tentang pembersihan data untuk membantu Anda memulai dengan cepat.**
