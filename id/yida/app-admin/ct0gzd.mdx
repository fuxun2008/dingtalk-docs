Aplikasi low-code YiDA mendukung lima metode pembuatan. Artikel ini menjelaskan cara Buat Aplikasi menggunakan Excel.

## Langkah-langkah

<Steps>
  <Step title="Langkah 1">
    Masuk ke [Workbench](https://www.yidaapps.com/workPlatform) YiDA.
  </Step>
  <Step title="Langkah 2">
    Klik **Buat Aplikasi** di sudut kanan atas, lalu klik **Buat Aplikasi dari Excel** pada kotak dialog yang muncul.
  </Step>
  <Step title="Langkah 3">
    Pada halaman **Buat Aplikasi dari Excel**, **pilih file Excel**.
    Anda dapat **memilih dari templat Excel** atau **mengunggah dari lokal** untuk menambahkan file Excel.
  </Step>
  <Step title="Langkah 4">
    Pada langkah pengaturan bidang, konfigurasikan bidang formulir berdasarkan informasi berikut, lalu klik **Berikutnya**.
  </Step>
</Steps>

<Steps>
  <Step title="Pada langkah desain alur kerja, tentukan apakah akan mengaktifkan proses persetujuan">
    <Note>
    - Jika data baru memerlukan persetujuan, aktifkan proses dan lengkapi desain diagram alur. Untuk detail langkah desain alur kerja, lihat desain alur kerja.
    - Untuk Aplikasi yang dibuat dari Excel, maksimal tiga penyetuju dapat ditambahkan dalam desain alur kerja.
    </Note>
  </Step>
  <Step title="Pada langkah pengaturan Aplikasi, konfigurasikan nama Aplikasi dan izin, lalu klik Buat Aplikasi untuk menyelesaikan pembuatan Aplikasi">
  </Step>
</Steps>
