## 1. Pendahuluan

### 1.1 Ringkasan fitur

Fitur Buat formulir dari Excel memungkinkan Anda merancang formulir dengan cepat dan mudah, sekaligus mengimpor data Excel langsung ke dalam formulir untuk pengelolaan data.

### 1.2 Skenario penggunaan

Pada skenario manajemen inventaris yang mengharuskan Anda memasukkan nama produk, spesifikasi, jumlah, dan harga satuan, Anda dapat mengisi nama komponen dan data pada spreadsheet Excel untuk mengimpor informasi produk ke tabel data dasar secara cepat.

## 2. Langkah-langkah

### 2.1 Pilih file Excel

Jalur: Buat formulir >> Impor dari Excel >> Pilih file Excel

### 2.2 Pratinjau data

Pratinjau data Excel lokal secara online untuk memastikan datanya benar dan file yang dipilih sudah tepat.

### 2.3 Pengaturan formulir

Atur Nama formulir yang sedang dibuat, beserta nama dan tipe setiap komponennya.

### 2.4 Impor data

Setelah menyelesaikan langkah-langkah di atas, klik Impor di kanan bawah halaman pengaturan formulir untuk mengimpor data.

## 3. Aturan impor

File Excel yang diunggah harus memenuhi persyaratan berikut:

• Sel gabungan tidak diizinkan.

• Ukuran File tidak boleh melebihi 2 MB.

• Hanya file (\*.xls dan \*.xlsx) yang didukung.

• Pastikan baris header pada sheet yang ingin diimpor tidak memuat sel kosong. Jika ada, sistem tidak akan mengimpor data dari sheet tersebut.
