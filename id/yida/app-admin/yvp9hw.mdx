Kelola semua Sumber data formulir dari Aplikasi saat ini di satu tempat. Lihat tabel di bawah untuk detailnya:

| **Nama** | **Tujuan** |
|---|---|
| [**Dataset**](/id/yida/app-admin/roe3o1) | Kelola semua Sumber data tabel tunggal, Tabel Tampilan (asosiasi multi-tabel), Persiapan Data (solusi offline untuk data berukuran besar), serta Sumber data lintas Aplikasi (formulir) dalam Aplikasi saat ini di satu tempat. Dataset berfungsi sebagai unit kontrol data Standar YiDA untuk skenario interkoneksi data. |
| [**Tabel Tampilan**](/id/yida/app-admin/oim554) | Tabel Tampilan memproses data formulir yang ada melalui asosiasi tabel tunggal atau multi-tabel, serta mendukung mode tabel perantara untuk meningkatkan kemampuan pemrosesan data. Saat ini, skenario seperti visualisasi data laporan dan penautan formulir dapat memanggil data dari Tabel Tampilan secara langsung. |
| [**Lintas Aplikasi**](/id/yida/app-admin/btrtnt) | Juga dikenal sebagai pengambilan data lintas Aplikasi. Panggil data formulir dari Aplikasi YiDA lain ke dalam Aplikasi saat ini untuk memungkinkan interkoneksi data antar Aplikasi YiDA. |
| [**Sumber Data**](/id/yida/app-admin/duy0wi) | Sumber Data menjelaskan informasi tentang asal data. YiDA mendukung pengelolaan dan pemeliharaan Sumber data seperti file dan basis data. |
| [**Kartu Data**](/id/yida/app-admin/cpkmxvpgchx339qq) | Pembawa visualisasi data generasi baru. Berbeda dengan laporan yang memiliki alur analitis lengkap, Kartu data dengan cepat menggabungkan grafik yang terfragmentasi dan berbasis skenario untuk digunakan di portal YiDA. Kartu juga dilengkapi kemampuan siaran bawaan, yang menyinkronkan data ke grup sebagai snapshot. |
| [**Layanan Data**](/id/yida/app-admin/fw9qtv) | Layanan data memproses Dataset dengan memilih bidang tertentu dan mengonversinya menjadi layanan API. Saat ini, layanan tersebut hanya dapat digunakan dalam node Kartu dari perancang Integrasi & Otomatisasi / alur kerja. |
| [**Persiapan Data**](/id/yida/app-admin/ykemo6) | Sebelum data dianalisis dan digunakan, bersihkan, gabungkan, dan transformasikan data mentah untuk mengagregasi data yang tersebar menjadi Dataset yang terstandardisasi, sehingga mendukung analisis visual dan pengambilan keputusan berbasis data. |
