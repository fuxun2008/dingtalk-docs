Set data YiDA mendukung pembuatan menggunakan file lokal. Dengan menghubungkan file lokal yang sudah ada dengan Formulir YiDA, Anda dapat mengekstrak dan mengolah data berbasis teks maupun berbasis file secara cepat. File, sebagai Tipe yang sederhana, tidak memerlukan Sumber Data yang dibuat terpisah — Anda dapat langsung membuat set data yang sesuai dengan Sumber Data berbasis file di dalam set data.

Tipe file yang saat ini didukung mencakup file Excel .xls dan .xlsx yang umum digunakan di sistem informasi Organisasi, serta file CSV (Comma Separated Values) yang memenuhi kebutuhan pengolahan teks berskala besar. Bidang file yang diunggah diproses sebagai Tipe string secara default, dan penyesuaian Tipe bidang (Numerik, Tanggal, dll.) didukung untuk penggunaan tipe data yang lebih tepat dalam berbagai skenario.

## Langkah-langkah

Anda dapat mengikuti langkah-langkah berikut untuk Buat set data dari File lokal.

1. Masuk ke workbench YiDA dan buka halaman Pengaturan Aplikasi.
2. Klik Data Factory > Dataset secara berurutan.
3. Klik Create Dataset > From File.

  ![](https://gw.alicdn.com/imgextra/i4/O1CN01PLLvkzH2TOC2L8uo_!!6000000001218-2-tps-1153-681.png)

4. Ikuti informasi berikut untuk memilih dan Unggah File.

| **Item Konfigurasi** | **Deskripsi** |
|---|---|
| **Nama Set Data** | Masukkan nama set data, maksimal 30 karakter. |
| **Tipe File** | Pilih Tipe File dan halaman Sheet yang ingin Anda Unggah. |
| **Header** | Pilih apakah File yang Anda unggah berisi header.<br />Jika File Spreadsheet dengan header diatur sebagai tidak memiliki header, Kolom header dalam Spreadsheet akan diperlakukan sebagai Rekam data pertama dalam set data. |
| **File yang Diunggah** | Pilih File yang akan Diunggah.<br />Spreadsheet yang diunggah harus memenuhi spesifikasi berikut:<br />• **Tipe File**: Hanya file `.xlsx` **dan** `.csv` yang didukung.<br />• **Ukuran File**: Ukuran File tidak boleh melebihi **50M**. Untuk file berukuran besar, disarankan untuk Simpan Sebagai file csv dan mengunggahnya kembali.<br />• **Catatan**: Area Konten Excel **tidak boleh berisi Sel yang digabungkan atau fungsi formula**, dan **header** **tidak boleh berisi** Sel yang kosong. |

  ![](https://gw.alicdn.com/imgextra/i3/O1CN01aAMMmNFO2SG2KlUf_!!6000000006970-2-tps-1150-651.png)

5. Konfigurasikan alias Bidang dan Tipe bidang set data, lalu klik Berikutnya setelah konfigurasi Selesai.

Bidang Formulir mendukung empat tipe data: **STRING**, **INTEGER**, **DOUBLE**, dan **DATE**.

6. Pratinjau apakah data sudah benar. Jika data sudah benar, klik Konfirmasi untuk menyelesaikan pembuatan.
