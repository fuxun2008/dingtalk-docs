## Ikhtisar

Kumpulan data adalah unit pengelolaan terpadu YiDA untuk data dari formulir, tabel tampilan, persiapan data, dan Sumber lintas Aplikasi. Ini merupakan unit pengumpulan data standar di YiDA.

## Tabel tunggal sebagai kumpulan data

Gunakan data yang dikumpulkan oleh formulir yang dibuat dalam sebuah Aplikasi sebagai input data untuk menyusun laporan.

<Note>
Anda tidak perlu membuat kumpulan data Tabel tunggal secara manual. Setelah membuat formulir, datanya akan otomatis tersinkronisasi ke daftar kumpulan data.
</Note>

## Buat kumpulan data dari tabel tampilan

YiDA memproses data formulir yang ada untuk menghasilkan Tabel pengumpulan data yang terkonsolidasi (wide table) yang dapat langsung digunakan dalam laporan hilir.

Untuk detail tentang tabel tampilan, lihat [Tabel tampilan](/id/yida/app-admin/oim554).

## Buat kumpulan data dari persiapan data

Persiapan data merupakan solusi big data offline. Fitur ini mendukung unggah data Excel dan CSV serta koneksi ke database online seperti MySQL. Setelah diakselerasi melalui persiapan data, data digabungkan dan diproses untuk pembuatan laporan.

Untuk detail tentang persiapan data, lihat [Ikhtisar fitur](/id/yida/app-admin/ykemo6).

## Buat kumpulan data dari Sumber lintas Aplikasi

Pengambilan data lintas Aplikasi memungkinkan Anda memperoleh data formulir dari Aplikasi lain yang ditentukan sebagai kumpulan data. Setelah menambahkan formulir pengambilan data lintas Aplikasi, Anda dapat menggunakannya dalam skenario seperti pembuatan laporan. Saat ini hanya skenario laporan yang didukung; ke depannya, formulir lintas Aplikasi akan tersedia sebagai kumpulan data standar di lebih banyak skenario.

Untuk detail, lihat [Lintas Aplikasi](/id/yida/app-admin/btrtnt).

## Buat kumpulan data dari File

**Tujuan**: Dengan menghubungkan Sumber informasi berbasis teks yang sudah ada, Anda dapat dengan cepat mengekstrak dan memproses data dari aset informasi berbasis teks dan File. File adalah Tipe sederhana dan tidak memerlukan pembuatan Sumber Data terpisah. Anda dapat Buat kumpulan data yang didukung oleh Sumber Data Tipe File langsung di modul kumpulan data.

**Tipe yang didukung**: File Excel .xls dan .xlsx yang umum digunakan dalam sistem informasi perusahaan, serta File CSV (Comma-Separated Values) yang mendukung pemrosesan data teks skala besar.

**Optimalisasi skenario**: Bidang yang diunggah diperlakukan sebagai Tipe string secara default. Anda dapat menyesuaikan Tipe Bidang (Numerik, Tanggal, dan sebagainya) sehingga data dapat digunakan dengan Tipe data yang lebih sesuai di setiap skenario.

## Buat kumpulan data dari database

**Tujuan**: Dengan menghubungkan database cloud yang sudah ada, Anda dapat mengekstrak dan memproses data.

**Tipe yang didukung**: MySQL, SQLServer, Oracle, PostgreSQL, HologreSQL.

**Keamanan**: Selain kata sandi database yang dimasukkan saat membuat Sumber Data, seluruh transmisi kata sandi selanjutnya dienkripsi dan dilindungi untuk menjaga Keamanan informasi database secara menyeluruh.

**Optimalisasi skenario**: Driver database untuk berbagai versi MySQL dan SQLServer diurai dan diidentifikasi secara otomatis di cloud, dan driver yang cocok diterapkan secara cerdas.

## Konfigurasi Izin kumpulan data

Di daftar kumpulan data YiDA, Anda dapat mengonfigurasi Izin untuk menentukan pengguna mana yang dapat mengakses Bidang mana (atau data yang cocok dengan aturan tertentu), sehingga memungkinkan kontrol Izin di tingkat data saat runtime.

- Kumpulan data Tipe formulir menggunakan Izin formulir secara langsung.
- Untuk Tipe kumpulan data lainnya, Buka Izin dan Buat grup izin untuk mengatur Cakupan izin independen. Aturan Izin default adalah: semua orang dapat melihat data di semua Bidang.

**Jalur**: Buka halaman formulir Aplikasi > Data Aplikasi.

**Definisi kumpulan data**: Kumpulan data adalah unit pengelolaan terpadu untuk data yang dihasilkan oleh formulir standar, tabel tampilan (asosiasi multi-Tabel), persiapan data (solusi big data offline), dan formulir lintas Aplikasi. Ini merupakan unit pengumpulan data standar di YiDA.
