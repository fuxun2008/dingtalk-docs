## 1. Pengenalan

### 1.1 Gambaran fitur

Sinkronkan data formulir AI Table / Persetujuan OA untuk menjembatani AI Table / Persetujuan OA dengan YiDA, sehingga pengguna dapat merujuk data AI Table / Persetujuan OA secara langsung dari sisi YiDA.

### 1.2 Kasus penggunaan

- Penyelenggara acara dapat menggunakan AI Table / Persetujuan OA untuk mengelola setiap tahap acara — pendaftaran peserta, penjadwalan, logistik, dan lainnya. Peserta dapat mengirim masukan dan permintaan melalui formulir.
- Manajer keamanan dapat menggunakan formulir sinkronisasi AI Table untuk mencatat hasil inspeksi keselamatan, laporan insiden, dan tindakan korektif. Cara ini membantu mencegah insiden serta menjaga keselamatan dan kesejahteraan karyawan.

<Tip>
[Catatan]

Ketika data historis melebihi 10.000 rekaman dan Anda ingin semuanya disinkronkan ke formulir YiDA saat inisialisasi, saat ini tersedia dua solusi alternatif:

Opsi 1: Di bawah "Aturan sinkronisasi" — "Rentang data sinkronisasi dan Urutan", siapkan "Kondisi filter" dan perbarui melalui beberapa kali sinkronisasi manual.

Opsi 2: Setelah formulir dibuat, impor sisa data sekaligus melalui "Impor massal" ke formulir yang bersangkutan.
</Tip>

### 2.5 Melihat data

Setelah dibuat, Anda akan melihat "formulir biasa" baru yang dihasilkan di aplikasi, beserta dataset dengan nama dan tipe yang sama yang dibuat pada waktu yang sama.

Sinkronisasi pertama setelah pembuatan mungkin memerlukan beberapa menit — jika data tidak cocok dengan sumbernya, tunggu beberapa menit.

Klik "Sinkronisasi dataset" untuk melihat log sinkronisasi. Lihat ilustrasi di bawah:

Setelah pembuatan, jika Anda perlu mengedit aturan sinkronisasi atau menyegarkan data secara manual, temukan titik masuknya di bilah tindakan dropdown formulir seperti terlihat di bawah.
