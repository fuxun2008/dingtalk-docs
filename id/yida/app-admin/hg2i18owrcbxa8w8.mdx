Artikel ini menjelaskan cara membuat dataset dari database.

## Prasyarat

Sebelum membuat dataset dari database, tambahkan Sumber Data database ke Aplikasi Anda. Untuk langkah rinci, lihat [Membuat Sumber Data](https://www.yuque.com/yida/ng4ubn/ap3zy8h89xpzgfbt).

## Langkah

1. Masuk ke workbench YiDA dan buka halaman pengaturan Aplikasi.
2. Klik **Data Factory** > **Dataset**.
3. Klik **Create Dataset** > **From Database**.

## Menggunakan data database

- Di halaman laporan dan saat persiapan data, pilih dataset terkait untuk membuat laporan analisis dengan cepat.

- Contoh penggunaan data dari database MySQL tertentu dalam sebuah laporan.
