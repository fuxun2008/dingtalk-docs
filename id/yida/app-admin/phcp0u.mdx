## Skenario penerapan

- Saat perlu membuat salinan aplikasi untuk digunakan ulang atau diuji oleh sub-departemen lain
- Saat perlu melakukan konversi antara halaman formulir dan formulir alur kerja

## Menyalin aplikasi

Ikuti langkah berikut untuk menyalin aplikasi. Menyalin aplikasi umumnya digunakan untuk membuat salinan aplikasi yang akan digunakan atau diuji oleh sub-departemen lain.

1. Masuk ke workbench YiDA, lalu klik untuk membuka My Apps.
2. Pilih aplikasi yang ingin disalin, klik ikon ··· di pojok kiri bawah aplikasi, lalu pilih Copy App.

<Note>
Jika halaman **My Apps** Anda menggunakan **List mode**, klik tombol **Lainnya** pada kolom Tindakan aplikasi yang dituju.
</Note>

3. Pada kotak dialog yang muncul, masukkan nama aplikasi baru, lalu klik Konfirmasi untuk menyelesaikan penyalinan.

<Note>
- Jika sebuah aplikasi memiliki lebih dari 80 halaman, proses penyalinan dapat gagal. Berhati-hatilah saat menyalin aplikasi yang memiliki banyak halaman.
- Setelah YiDA Dedicated mengaktifkan tata kelola aplikasi, aplikasi hasil salinan berstatus Dinonaktifkan secara default.
</Note>

### Menyalin halaman lintas aplikasi

<Check>
Tindakan ini memiliki risiko (kehilangan data, Formula gagal, dll.), dan tim resmi tidak bertanggung jawab atas perbaikannya. Gunakan dengan hati-hati.
</Check>

Ikuti langkah berikut untuk menyalin halaman antar aplikasi.

1. Buka desainer formulir dari halaman asal A, tekan F12 untuk membuka console, beralih ke modul console, masukkan kode modifikasi gaya, lalu tekan Enter.

```css
// Modifikasi gaya
document.querySelector('.lc-left-area-bottom div:last-child').style.display = 'block'
```

2. Dengan langkah yang sama seperti langkah 1, buka kode sumber halaman pada halaman B.
3. Salin kode sumber halaman A ke console kode sumber halaman B, lalu klik Import schema untuk menyelesaikan penyalinan halaman lintas aplikasi.
