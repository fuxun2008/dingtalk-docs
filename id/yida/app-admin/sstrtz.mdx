Aplikasi dapat diakses melalui URL yang dihasilkan sistem atau URL kustom. Bagikan URL tersebut kepada orang lain agar mereka dapat membuka halaman aplikasi secara langsung.

## Mendapatkan tautan yang dihasilkan sistem

Ikuti langkah-langkah berikut untuk memperoleh URL aplikasi di peramban.

1. Masuk ke workbench Yida, lalu klik **Aplikasi Saya**.
2. Pilih aplikasi target dan klik untuk membuka editor aplikasi. Kemudian klik **Kunjungi** di sudut kanan atas.

3. Pada halaman akses aplikasi, salin URL peramban dari halaman tersebut.

## Mendapatkan tautan kustom

Ikuti langkah-langkah berikut untuk memperoleh URL kustom aplikasi.

1. Masuk ke workbench Yida, lalu klik **Aplikasi Saya**.
2. Pilih aplikasi target dan klik untuk membuka editor aplikasi.
3. Klik **Pengaturan aplikasi** untuk membuka halaman pengaturan.
4. Pada halaman **Pengaturan dasar**, di bagian **Pengaturan URL**, pilih **Salin tautan aplikasi** atau **Unduh Kode QR aplikasi** sesuai kebutuhan.

## Mendapatkan tautan aplikasi di klien DingTalk

Cara mendapatkan tautan aplikasi di klien DingTalk mirip dengan di peramban — buka halaman detail aplikasi terlebih dahulu. Ikuti langkah-langkah berikut untuk memperoleh URL aplikasi dari workbench DingTalk.

1. Buka **workbench DingTalk**, lalu pilih **Yida** untuk membuka halaman beranda Yida.
2. Klik **Aplikasi Saya**, lalu pilih aplikasi target untuk membuka halaman detail aplikasi.

3. Klik tombol **Bagikan** di sudut kanan atas, lalu pilih **Buka di peramban** atau **Salin tautan**.

## Membagikan tautan ke satu rekaman dari halaman manajemen data

Untuk membagikan satu rekaman dari formulir, ikuti langkah-langkah berikut.

**Aplikasi Saya** > pilih aplikasi > pilih halaman > **Manajemen data** > pilih satu rekaman > klik kanan untuk menyalin tautan

1. Masuk ke workbench Yida, lalu klik **Aplikasi Saya**.
2. Pilih aplikasi target dan klik untuk membuka editor aplikasi.
3. Pilih formulir yang datanya ingin dibagikan, lalu klik **Manajemen data**.
4. Pilih rekaman yang ingin dibagikan, lalu klik **Detail** pada kolom Tindakan.

5. Pada bilah sisi Rekaman sumber, klik **···** > **Bagikan** di sudut kanan atas, lalu klik **Salin tautan** pada dialog berbagi untuk memperoleh tautan ke rekaman saat ini.
