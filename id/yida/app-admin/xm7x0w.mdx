Kelola aplikasi dan konfigurasikan pengaturan dasar umum. Hanya admin aplikasi, admin platform, sub-admin, atau Super Admin Organisasi yang memiliki izin untuk mengelola dan mengonfigurasi aplikasi.

Daftar isi:

- Pengaturan dasar aplikasi
- Pengaturan Izin aplikasi
- Aktifkan dan nonaktifkan aplikasi
- Dapatkan tautan aplikasi
- Sesuaikan URL akses aplikasi
- Publikasikan aplikasi
