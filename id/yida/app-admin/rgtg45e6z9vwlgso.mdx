## Ikhtisar

Fitur persiapan data platform YiDA menawarkan kemampuan integrasi data yang unggul. Fitur ini sepenuhnya mendukung kombinasi dan pemrosesan mendalam atas data dari sumber internal YiDA, spreadsheet Excel, dan berbagai database (Sumber Data eksternal). Fitur ini juga memungkinkan integrasi mulus dengan data layanan resmi DingTalk, mencakup Sumber Data inti seperti Daftar Karyawan, alur Persetujuan OA, sistem Smart HR (termasuk namun tidak terbatas pada manajemen onboarding dan offboarding, operasi konfirmasi dan mutasi), serta metrik bisnis umum.

Dengan kemampuan ini, perusahaan dapat secara efisien mendorong integrasi mendalam antara pengembangan low-code dan seluruh sumber daya data perusahaan di platform YiDA, sekaligus meningkatkan efisiensi serta efektivitas pengambilan keputusan berbasis data secara signifikan.

## Minta izin

Untuk menggunakan integrasi data resmi, Super Admin aplikasi harus terlebih dahulu memperoleh Izin pengelolaan atas data terkait.

Contohnya, untuk menggunakan data Daftar Karyawan, dapatkan Izin Sub Admin untuk Smart HR. Ikuti langkah-langkah berikut:

<Steps>
  <Step title="Langkah 1">
    Masuk ke OA Admin Console sebagai Super Admin DingTalk.
  </Step>
  <Step title="Langkah 2">
    Klik Keamanan & Izin > Kelola izin > Sub Admin > Tambah Sub Admin.
  </Step>
  <Step title="Langkah 3">
    Pilih Pengguna yang akan ditambahkan, lalu Konfigurasikan Izin yang diperlukan.
  </Step>
  <Step title="Langkah 4">
    Setelah konfigurasi selesai, klik Simpan.
  </Step>
</Steps>

## Izin dataset

YiDA kini mendukung kontrol izin independen untuk semua dataset. Saat dataset dengan Izin yang telah dikonfigurasi digunakan, datanya difilter dan dikendalikan secara real-time berdasarkan pengguna (siapa yang dapat melihat), izin baris (konfigurasi aturan), dan izin kolom (Cakupan Bidang).

Seiring YiDA diterapkan pada skenario yang lebih beragam, kontrol Izin Data menjadi esensial untuk skenario konsumsi seperti laporan dan dasbor.
