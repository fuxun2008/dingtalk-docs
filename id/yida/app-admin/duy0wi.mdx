Edisi berbayar YiDA mendukung lima tipe Sumber Data, memungkinkan integrasi mendalam antara berbagai data—seperti database lokal (memerlukan akses jaringan publik) dan Spreadsheet—dengan Aplikasi YiDA. Integrasi ini meningkatkan efisiensi interoperabilitas data sekaligus menyediakan solusi integrasi data satu pintu bagi pengguna. Artikel ini menjelaskan cara menambahkan Sumber Data ke sebuah Aplikasi.

| **Kapabilitas** | **Edisi Gratis** | **Edisi Basic** | **Edisi Professional** | **Edisi Dedicated** |
|---|---|---|---|---|
| **Koneksi ke Sumber Data database utama** | Tidak didukung | Tidak didukung | 20 | 20 |
| **Jumlah Sumber Data File (cakupan Organisasi)** | Tidak didukung | 50 | 100 | 100 |

## Ikhtisar Sumber Data

Sumber Data adalah deskripsi informasi Sumber Data. Dengan terhubung ke sebuah Sumber Data, berbagai data seperti database lokal (memerlukan akses jaringan publik) dan Spreadsheet dapat diintegrasikan secara mendalam dengan Aplikasi YiDA, sehingga meningkatkan efisiensi interoperabilitas data. YiDA mendukung pengelolaan dan pemeliharaan Sumber Data seperti File dan database.

YiDA mendukung dua tipe Sumber Data berikut:

- Database relasional: MySQL (Versi 5.7 atau lebih baru), SQL Server (Versi 2012 atau lebih baru), Oracle (Versi 19c atau lebih baru), PostgreSQL (Versi 9.0 atau lebih baru), dan Hologres.
- File: File Excel dan File CSV. Untuk cara membuat dataset dari sebuah File, lihat Buat dataset dari sebuah File.

## Tambah Sumber Data

Ikuti langkah-langkah berikut untuk menambahkan Sumber Data bertipe database.

1. Masuk ke workbench YiDA dan buka Halaman Pengaturan Aplikasi.
2. Pilih Data Factory > Dataset secara berurutan, lalu klik Buat dataset.
3. Pada kotak dialog Buat Sumber Data, isi informasi database, lalu klik Konfirmasi untuk menyelesaikan pembuatan.

| **Item konfigurasi** | **Deskripsi** |
|---|---|
| **Tipe Sumber Data** | Pilih tipe database relasional yang akan ditambahkan. Lima database berikut didukung.<br />• MySQL (Versi 5.7 atau lebih baru)<br />• SQL Server (Versi 2012 atau lebih baru)<br />• Oracle (Versi 19c atau lebih baru)<br />• Postgre (Versi 9.0 atau lebih baru)<br />• Hologres |
| **Nama** | Masukkan nama untuk Sumber Data baru. Mendukung hingga 200 karakter. |
| **Alamat & port database** | Masukkan alamat akses jaringan publik database Anda dan nomor port terkait.<br />Contoh:<br />• Alamat database: aliwork<br />• Port: 3306 |
| **Akun & kata sandi** | Masukkan akun akses dan kata sandi database. |
| **Nama database** | Masukkan nama database. Mendukung hingga 30 karakter. |
| **URL** | Masukkan URL akses lengkap database.<br />**Catatan**: Parsing satu klik dengan string [JDBC](https://docs.oracle.com/middleware/1213/eventprocessing/server-administer/CEPAG.epub) didukung. URL Sumber Data tidak boleh menyertakan parameter. |
