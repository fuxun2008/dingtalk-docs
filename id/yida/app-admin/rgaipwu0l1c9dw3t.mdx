**Persiapan data** adalah fitur utama platform low-code YiDA. Fitur ini membantu pengguna perusahaan membersihkan, mengintegrasikan, dan mengubah data mentah sebelum melakukan analisis data atau membangun aplikasi. Artikel ini menjelaskan cara membuat persiapan data.

Persiapan data menggunakan solusi ETL (Extraction, Transformation, Loading) tanpa kode untuk memproses data dari aplikasi YiDA, database perusahaan eksternal, data berbasis file, dan sumber data resmi DingTalk (termasuk Roster, OA, Smart HR, Attendance, dan lainnya). Dengan membangun alur kerja pemrosesan data, fitur ini menggabungkan data yang tersebar menjadi dataset standar untuk mendukung analisis visual dan keputusan berbasis data.

## Prosedur

1. Masuk ke workbench YiDA dan buka halaman pengaturan aplikasi.
2. Klik **Data Factory** > **Data Preparation**.
3. Klik **Create Data Preparation** untuk membuka desainer persiapan data.
4. Seret node **Input** ke kanvas dan konfigurasikan **sumber input**.

Data input dapat diatur ke **dataset** atau **Sumber Data**.

| **Sumber Data** | **Bidang (tidak diperbarui secara real-time; lihat tampilan persiapan data yang sebenarnya)** |
|---|---|
| **Metrik umum** | Jumlah Kontak, jumlah pengirim log, tingkat pengiriman log, total DING terkirim, total obrolan grup, jumlah laporan pengeluaran, jumlah dokumen yang dibuat dalam 1 hari terakhir, dan lainnya |
| **Roster** | Nama karyawan, jabatan, ID Karyawan, nama departemen, tipe masa percobaan, tanggal bergabung, tanggal pengangkatan tetap, dan lainnya |
| **Persetujuan OA** | Bidang bisnis kustom pada formulir, Pengirim, waktu pengiriman, penyetuju, status persetujuan, waktu penyelesaian persetujuan, catatan persetujuan, dan lainnya |
| **Smart HR** | Tanggal bergabung, tingkat jabatan, tanggal pengangkatan tetap, tingkat setelah pengangkatan tetap, tanggal pengunduran diri, alasan pengunduran diri, dan lainnya |
| **Attendance (dalam enam bulan terakhir)** | Nama pengguna, departemen, waktu check-in, tanda lembur, tanda kehadiran yang diharapkan, nama grup kehadiran, tanda kerja lapangan, tanda check-in terlewat, dan lainnya |

5. Di bagian bawah halaman, konfigurasikan tipe bidang.

Tipe data yang didukung meliputi string, number, float, date, dan array.
