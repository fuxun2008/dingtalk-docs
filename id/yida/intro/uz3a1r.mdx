## **Workbench**

| **Istilah** | **Definisi** |
|---|---|
| [Start](https://www.yidaapps.com/start.html) | Setelah masuk ke YiDA dan mengklik Workbench, Anda akan diarahkan ke halaman Start terlebih dahulu. Halaman ini adalah pusat komprehensif tempat Anda dapat melihat ringkasan informasi penting. |
| [Galeri Templat](/id/yida/intro/le1tkr) | Jelajahi templat di Galeri Templat untuk mengetahui apa yang dapat dilakukan YiDA serta hasil yang dapat Anda capai. |
| [Solutions](https://www.yidaapps.com/isvSolution.html?spm=a1ztuy.21010213.0.0.1a3a6ddbbEe5HW) | Solusi khusus industri yang disediakan oleh Penyedia layanan bersertifikasi YiDA. Solusi ini menawarkan kustomisasi yang fleksibel, efisien, dan disesuaikan agar sepenuhnya cocok dengan bisnis Anda. |
| [App Center](https://www.yidaapps.com/appCenter.html?spm=a1z8hbp.20990513.0.0.10e13f7cNiOMcN) | Menampilkan Aplikasi yang telah dirilis di dalam YiDA atau Aplikasi templat yang telah diaktifkan. |
| [My Apps](https://docs.aliwork.com/docs/yida_support/yida_qalist/li89l7/xhnlqa/ymyz8m) | My Apps menampilkan antarmuka yang terlihat oleh Pengguna yang sedang masuk. Tampilan antarmuka berbeda-beda tergantung izin Pengguna. |
| [Task Center](https://docs.aliwork.com/docs/yida_support/yida_qalist/li89l7/xhnlqa/wpuat3) | Task Center mengagregasi Formulir atau catatan alur kerja yang telah Anda kirim di Aplikasi YiDA. Anda dapat melihat detail Formulir yang telah dikirim serta alur kerja yang memerlukan tindakan Anda. |
| [Customization Center](https://docs.aliwork.com/docs/yida_support/yida_qalist/li89l7/xhnlqa/mg2tlf) | Penyedia layanan bersertifikasi membangun Aplikasi bisnis yang disesuaikan dengan kebutuhan Organisasi Anda. ## **Formulir biasa**

| **Istilah** | **Definisi** |
|---|---|
| [Formulir biasa](/id/yida/app-admin/mff60m) | Formulir biasa terdiri dari beberapa Komponen dan digunakan untuk mengumpulkan serta mengirimkan data. |
| [Komponen](/id/yida/form/snftao) | Wadah untuk menyimpan data. Jenis Komponen yang berbeda menyimpan tipe data yang berbeda. Sebagai contoh, Komponen numerik menyimpan data numerik, dan Komponen teks menyimpan data teks. |
| [Pengeditan Formula](/id/yida/form/gvtpe4) | Saat mengisi atau mengedit data Formulir, Anda dapat mengatur nilai suatu Komponen agar dihitung otomatis berdasarkan Formula. Cara ini meningkatkan efisiensi entri data dan mengurangi kesalahan. |
| [Asosiasikan data dari Formulir lain](/id/yida/form/tg64d5) | Gunakan pengaturan Asosiasi untuk mengambil data dari formulir terkait sebagai data Formulir saat ini. |
| [Keterkaitan data](/id/yida/form/arpur0) | Ketika nilai suatu bidang dalam Formulir berubah, nilai bidang lain pada Formulir yang sama ikut berubah. Fitur ini sering digunakan untuk menetapkan nilai default Komponen. |
| [Aturan Asosiasi bisnis](/id/yida/form/ydmx04) | Aturan Asosiasi bisnis digunakan saat data pada dua Formulir saling terkait. Sebagai contoh, dalam manajemen inventaris, catatan masuk dan keluar harus diagregasi ke dalam Tabel inventaris akhir untuk ditampilkan dan ditinjau. |

## **Formulir alur kerja**

| **Istilah** | **Definisi** |
|---|---|
| [Formulir alur kerja](/id/yida/process/crwfii) | Formulir yang memiliki alur kerja. Dibandingkan dengan formulir biasa, formulir alur kerja mencakup tahap perutean alur kerja tambahan. |
| [Pengaturan alur kerja](/id/yida/process/crwfii) | Konfigurasikan aturan perutean untuk data pada formulir alur kerja, sehingga data mengalir sesuai alur kerja yang telah ditentukan. |
| [Langkah](/id/yida/process/rq8i94) | Setiap tahap dalam alur kerja disebut Langkah. Untuk setiap Langkah, Anda dapat mengonfigurasi izin visibilitas dan pengeditan Komponen, serta penyetuju, pelaksana, dan Pengguna CC. |
| [Aturan pengiriman Langkah](/id/yida/process/emt041) | Aturan pengiriman Langkah menggunakan pemeriksaan Formula untuk menentukan apakah Pengguna dapat mengirim alur kerja atau apakah penyetuju dapat memproses alur kerja saat mereka mengambil tindakan. |

## **Laporan**

| **Istilah** | **Definisi** |
|---|---|
| [Desainer laporan](https://docs.aliwork.com/docs/yida_support/yida_qalist/yxgxg6/nuk15o) | Saat Anda perlu mengagregasi data yang dikirim karyawan untuk ditinjau, Anda dapat membuat Halaman laporan dan menggunakan Komponen di desainer laporan untuk menganalisis, mengagregasi, dan mengkueri data. |
| [Komponen laporan](https://docs.aliwork.com/docs/yida_support/yida_qalist/yxgxg6) | Menampilkan data yang dikirim di Formulir sebagai bagan. |
| [Formula laporan](/id/yida/form/yrofmw) | Digunakan untuk memproses data dari Formulir asli. |
| [Kumpulan data](/id/yida/app-admin/roe3o1) | Saat Komponen bagan laporan menampilkan data, Anda perlu memilih Formulir atau formulir alur kerja di Aplikasi sebagai kumpulan data. |
| [Tabel tampilan](/id/yida/app-admin/oim554) | Tabel tampilan memproses awal data Formulir yang ada dengan mengasosiasikan satu Tabel atau beberapa Tabel. Fitur ini juga mendukung mode Tabel perantara untuk meningkatkan kemampuan pemrosesan data. Visualisasi laporan, keterkaitan Formulir, dan skenario lainnya dapat langsung mereferensikan data dari Tabel tampilan. |
| [Lintas Aplikasi](/id/yida/app-admin/btrtnt) | Juga dikenal sebagai "pengambilan data lintas Aplikasi." Fitur ini merujuk pada pemanggilan data Formulir dari Aplikasi YiDA lain di dalam Aplikasi saat ini, sehingga memungkinkan konektivitas data antar Aplikasi YiDA. |

## **Tautan eksternal**

| **Istilah** | **Definisi** |
|---|---|
| [Tautan eksternal](/id/yida/app-admin/nolqql) | Ketika Anda perlu menampilkan konten dari situs web lain, tempel URL situs web tersebut di sini. |
| [Buka di jendela baru](/id/yida/app-admin/nolqql) | Saat Anda mengklik Tautan eksternal, Tautan akan dibuka di jendela baru. |

## **halaman kustom**

| **Istilah** | **Definisi** |
|---|---|
| [halaman kustom](/id/yida/custom-page/ynk2lo) | Anda dapat menyesuaikan gaya dan menampilkan data dari semua Formulir di Aplikasi untuk fleksibilitas lebih besar dalam memenuhi kebutuhan bisnis spesifik Anda. halaman kustom lebih kompleks daripada formulir biasa dan biasanya memerlukan Konfigurasi kode. |
| [Desainer halaman kustom](/id/yida/custom-page/lo24cx) | Desainer halaman kustom terdiri dari empat bagian: **bilah tindakan atas**, **bilah alat kiri**, **kanvas tengah**, dan **panel Konfigurasi atribut kanan**. |

## **Fitur Premium**

| **Nama** | **Definisi** |
|---|---|
| [Nomor seri](/id/yida/form/rom39o) | Secara otomatis menghasilkan pengenal unik setelah data Formulir dikirim. Fitur ini umum digunakan untuk menomori item dalam skenario manajemen inventaris. |
| [Persiapan data](https://docs.aliwork.com/docs/yida_support/yida_qalist/uop0b0ndpgc0gevb/dkm8ph) | Persiapan data merujuk pada serangkaian langkah pemrosesan yang dilakukan pada sumber data dan kumpulan data sebelum analisis visual, seperti penyisipan multi-Tabel dan transformasi data. Ini merupakan langkah pendahuluan dalam analisis visual. |
| [Orkestrasi logika](https://docs.aliwork.com/docs/yida_support/yida_qalist/lmvsctyt7rxtgsrq/lbvx0y) | Dalam skenario tertentu, pengiriman Formulir memicu logika bisnis. YiDA saat ini mendukung dua alur logika bisnis inti bawaan utama—catatan dan alur kerja—beserta alur logika sekunder seperti komentar.<br />Setiap alur logika bisnis memiliki siklus hidupnya sendiri. Peristiwa dipancarkan pada setiap tahap siklus hidup dan dapat digunakan sebagai titik ekstensi. Setelah Peristiwa diterima, plugin eksekusi terkait berjalan untuk menjalankan logika bisnis tersebut. |
| [Alur kerja lanjutan](/id/yida/process/lgrp0w) | Untuk memenuhi kebutuhan alur kerja yang lebih kompleks, YiDA menyediakan desainer alur kerja lanjutan. Desainer ini mencakup hampir semua fitur desainer standar dan menambahkan kemampuan tambahan. Sebagai contoh, desainer ini mencakup Komponen seperti **cabang** dan **agregasi**. Desainer ini juga meningkatkan fitur dan pengaturan Komponen, dengan membedakan antara Pengaturan Dasar dan lanjutan. Anda dapat menyesuaikan aturan pelaksana dan strategi penyelesaian. Editor alur kerja standar dapat ditingkatkan menjadi editor alur kerja lanjutan. |
| [Callback layanan](https://docs.aliwork.com/docs/yida_support/yida_qalist/lmvsctyt7rxtgsrq/kkcdu6) | Di YiDA, setiap interaksi yang melibatkan pemanggilan layanan API dikenal sebagai Callback layanan pihak ketiga. Dukungan pemanggilan API ini memungkinkan YiDA terintegrasi dengan sistem eksternal dan bertukar data, sehingga mencegah Aplikasi YiDA menjadi silo yang terisolasi. |
| [Distribusi Aplikasi](/id/yida/app-admin/xb5ylm) | Distribusi Aplikasi membantu Penyedia layanan menerapkan Aplikasi yang dikembangkan di Organisasi mereka sendiri dengan cepat ke tenant YiDA Organisasi pelanggan. Developer Penyedia layanan juga dapat mengakses Organisasi pelanggan melalui saluran khusus untuk mengembangkan fitur yang disesuaikan dan mengonfigurasi atribut. |
| [Pendaftaran layanan](https://docs.aliwork.com/docs/yida_support/yida_qalist/lmvsctyt7rxtgsrq/ld80ev) | Pendaftaran layanan merupakan prasyarat untuk menggunakan fitur Callback layanan. Fitur ini mencakup pendaftaran API layanan pihak ketiga ke platform YiDA. Konfigurasi utama meliputi parameter input dan output API, informasi autentikasi dan enkripsi, kontrol izin, serta deskripsi API, agar API tersebut dapat dengan cepat dirujuk saat dibutuhkan. |
| [Integrasi & Otomatisasi](https://docs.aliwork.com/docs/yida_support/zevvr1) | Menyediakan peningkatan menyeluruh terhadap fitur orkestrasi logika dan mengintegrasikan Konektor DingTalk. Aplikasi resmi DingTalk, Aplikasi di ekosistem DingTalk, serta sistem internal perusahaan dapat diintegrasikan dengan YiDA secara ringan, memberikan Aplikasi YiDA interoperabilitas alami. |
| [Connector Factory](https://docs.aliwork.com/docs/yida_support/zevvr1) | Gunakan YiDA Connector Factory untuk membangun Konektor kustom bagi sistem internal atau Aplikasi pihak ketiga. |
| [Organisasi terkait](/id/yida/platform-admin/ampson) | Dengan fitur **Organisasi terkait** milik DingTalk, sebuah Organisasi dapat menautkan sub-Organisasi ke Organisasi induk. Selama proses penautan, Anda dapat memilih semua anggota atau anggota dari departemen tertentu di sub-Organisasi untuk bergabung dengan Organisasi terkait. |
| [Dasbor DataV](https://docs.aliwork.com/docs/yida_support/uz3a1r/_7/vvgk1m) | Gunakan berbagai kumpulan data yang sudah ada (termasuk lintas Aplikasi, sub-Tabel, dan Tabel tampilan) dengan lancar untuk membangun Dasbor digital yang memukau secara visual, menghadirkan dampak berbasis data yang mengesankan pada Aplikasi YiDA Anda. |
| **CorpId** | CorpId adalah pengenal unik dari sebuah Organisasi DingTalk. CorpId diperlukan untuk membeli layanan, memanggil API, dan operasi lainnya. Contoh CorpId: dingfa087xxxx55b. Anda dapat memperoleh CorpId Anda dengan salah satu cara berikut:<br />• Opsi 1: Lihat di halaman Pengaturan platform YiDA. Buka **YiDA Home** > **Pengaturan Platform** > [Informasi Dasar](https://www.yidaapps.com/platformManage/basicInfo).<br />• Opsi 2: Lihat di konsol developer DingTalk Open Platform. Untuk detailnya, lihat [dokumentasi DingTalk Open Platform](https://open.dingtalk.com/document/orgapp/basic-concepts#title-wxx-amg-62k). |
