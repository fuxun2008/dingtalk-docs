polished: true

Data yang dikumpulkan melalui formulir atau formulir alur kerja dapat dilihat, dianalisis, dan diproses melalui laporan.

Laporan menyediakan beragam gaya bagan. Gunakan Tabel Detail dan Tabel Pivot untuk melihat data rinci dan data ringkasan dari formulir atau formulir alur kerja. Gunakan bagan Batang, Garis, dan bagan lainnya untuk mengolah data serta mengungkap tren, perbandingan kategori, dan wawasan lainnya. Gunakan bagan Pai untuk menampilkan proporsi setiap bagian dalam data.
