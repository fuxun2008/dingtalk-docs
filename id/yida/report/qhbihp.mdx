## 1. Pendahuluan

Container terutama digunakan untuk tata letak dan dapat dikombinasikan dengan komponen lain.

Sorotan: Anda dapat mengatur ukuran komponen secara mandiri, tetapi tidak dapat memindahkan posisi Container (rata kiri, Rata Tengah, rata kanan).

## 2. Langkah-langkah

### 2.1 Pilih komponen

Pilih komponen Container dan seret ke designer. Setelah itu, seret komponen lain ke dalamnya.
