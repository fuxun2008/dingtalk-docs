Fungsi ini memungkinkan Anda memproses data yang dikembalikan oleh API. Klik tombol untuk menampilkan isi awal fungsi seperti di bawah ini. Parameter pertama `data` adalah data yang dikembalikan. Tulis JavaScript untuk memproses `data` dan kembalikan hasilnya.

**Contoh:**

Misalkan API mengembalikan data berikut. Anda perlu memproses kolom Numerik: kembalikan 0 jika nilainya kurang dari atau sama dengan 0, dan kembalikan 100 jika nilainya lebih besar dari 0.

Pertama, periksa bagian data dari API. `data` berupa array. Contoh di bawah berisi 4 item yang sesuai dengan 4 rekam pada Spreadsheet. Setiap item memuat 2 nilai data yang sesuai dengan 2 nilai data pada tiap rekam. Selanjutnya, tentukan nilai mana dari kedua nilai tersebut yang sesuai dengan Bidang Numerik. Pada contoh ini, karena format data Bidang Numerik dan Bidang Waktu modifikasi jelas berbeda, Anda dapat langsung mengenali bahwa **field_kr1zcs45 sesuai dengan Bidang Numerik, dan field_kr1zcs49 sesuai dengan day_Waktu modifikasi**. Jika kumpulan data berukuran besar dan sulit dikenali secara langsung, lakukan analisis melalui bidang `meta`. Cari item yang `aliasName`-nya memuat "Numerical"; `fieldId`-nya adalah **field_kr1zcs45**.

Terakhir, proses datanya.

```javascript
/**
* Terapkan pemrosesan kustom pada data yang dikembalikan
* Referensi data yang dikembalikan: https://www.yuque.com/yida/support/xgg4ps
* data: data yang dikembalikan
* extraInfo: { meta: [], cardParams: {} }, dengan meta adalah metadata data dan cardParams adalah informasi parameter Kartu
*/
function afterFetch(data, extraInfo) {
  data.forEach(item => {
    // Periksa apakah nilainya lebih besar dari 0
    if (item['field_kr1zcs45'] > 0) {
      // Jika lebih besar dari 0, atur menjadi 100
      item['field_kr1zcs45'] = 100;
    } else {
      // Jika tidak, atur menjadi 0
      item['field_kr1zcs45'] = 0;
    }
  });
  return data;
}
```
