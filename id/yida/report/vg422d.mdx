## 1. Pendahuluan

Alihkan ke URL dengan kombinasi parameter yang fleksibel, atau alihkan ke dalam kartu untuk menghasilkan efek side-drawer.

## 2. Langkah

## 3. Kasus penggunaan umum

### 3.3 Alihkan dari satu laporan ke laporan lain dengan filter yang diterapkan

#### Parameter kustom

Di laporan tujuan **Tabel Keluar**, buka Atribut Halaman, tambahkan parameter bertipe string, lalu beri nama.

#### Atur nilai default komponen filter

Atur nilai default komponen filter ke parameter kartu, lalu pilih parameter `test` yang baru saja Anda buat.

<Frame>
  ![](https://gw.alicdn.com/imgextra/i3/O1CN01Tj415GhwWUK3faxH_!!6000000005747-2-tps-1808-707.png)
</Frame>

#### Konfigurasikan pengalihan tautan

Di laporan **Tabel Masuk**, konfigurasikan tautan untuk bidang spreadsheet. Salin tautan pratinjau laporan **Tabel Keluar**, tambahkan simbol `&`, lalu gabungkan nama parameter dengan `test=` + spasi + `@bidang filter`, seperti ditunjukkan di bawah ini:

<Frame>
  ![](https://gw.alicdn.com/imgextra/i1/O1CN01hIOmYpSQzdF376Sa_!!6000000005516-2-tps-1534-606.png)
</Frame>
