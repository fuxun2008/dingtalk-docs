## 1. Pendahuluan

Alihkan ke URL dengan kombinasi parameter yang fleksibel, atau alihkan ke dalam kartu untuk menghasilkan efek side-drawer.

## 2. Langkah

### 2.1 Alihkan ke URL

| **Versi lama** | **Versi baru** |
|---|---|
| Mode buka: Pilih untuk membuka halaman baru atau memuat ulang halaman saat ini.<br />URL tautan: Masukkan URL. Tekan **Space** + **@** untuk memilih bidang, parameter, atau filter yang telah dikonfigurasi di spreadsheet dari daftar drop-down.<br />**Catatan:** @ harus diketik dalam mode input bahasa Inggris agar pemilih bidang muncul.| URL tautan: Masukkan URL. Klik Sisipkan Bidang untuk menyisipkan bidang yang dikonfigurasi di kolom spreadsheet beserta parameter filter.<br />Mode buka: Pilih **Buka halaman baru** atau **Muat ulang halaman saat ini**.|

### 2.2 Kustom

Atur Pengaturan Parameter ke Standar atau Kustom.

| **Versi lama** | **Versi baru** |
|---|---|
| | |

Konfigurasikan klik tautan kustom.

<Frame>
  ![](https://gw.alicdn.com/imgextra/i4/O1CN01VxhgYF0KwPB3UOLo_!!6000000001156-2-tps-1719-737.png)
</Frame>

Konfigurasikan parameter.

Parameter kustom: Tulis kode JS dengan kondisi if/else untuk mengendalikan pengalihan. Contoh: jangan teruskan parameter A saat nilai filter A adalah `all`, tetapi teruskan parameter tersebut saat nilai filter `<>all`.

### 3.3 Alihkan dari satu laporan ke laporan lain dengan filter yang diterapkan

#### Parameter kustom

Di laporan tujuan **Tabel Keluar**, buka Atribut Halaman, tambahkan parameter bertipe string, lalu beri nama.

#### Atur nilai default komponen filter

Atur nilai default komponen filter ke parameter kartu, lalu pilih parameter `test` yang baru saja Anda buat.

<Frame>
  ![](https://gw.alicdn.com/imgextra/i1/O1CN01Wm5X8BuNIxF3faxH_!!6000000007860-2-tps-1808-707.png)
</Frame>

#### Konfigurasikan pengalihan tautan

Di laporan **Tabel Masuk**, konfigurasikan tautan untuk bidang spreadsheet. Salin tautan pratinjau laporan **Tabel Keluar**, tambahkan simbol `&`, lalu gabungkan nama parameter dengan `test=` + spasi + `@bidang filter`, seperti ditunjukkan di bawah ini:

<Frame>
