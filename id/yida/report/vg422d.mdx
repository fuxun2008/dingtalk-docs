## 1. Pendahuluan

Alihkan ke URL dengan kombinasi parameter yang fleksibel, atau alihkan ke dalam kartu untuk menghasilkan efek side-drawer.

### 3.1 Alihkan dari laporan ke halaman rekaman sumber

#### Buat formulir biasa

Konfigurasikan bidang Kategori, Nama Produk, dan Kuantitas, lalu masukkan data.

Konfigurasi bidang formulir.

#### Buat laporan

Pilih komponen Spreadsheet, lalu konfigurasikan data set dan bidang yang akan ditampilkan. Bidang ID Instance wajib dipilih.

#### Konfigurasikan pengalihan tautan

Klik sebuah bidang, lalu konfigurasikan tautan dengan mengacu pada gambar berikut.

### 3.3 Alihkan dari satu laporan ke laporan lain dengan filter yang diterapkan

#### Parameter kustom

Di laporan tujuan **Tabel Keluar**, buka Atribut Halaman, tambahkan parameter bertipe string, lalu beri nama.

#### Atur nilai default komponen filter

Atur nilai default komponen filter ke parameter kartu, lalu pilih parameter `test` yang baru saja Anda buat.
