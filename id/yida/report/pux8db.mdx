## 1. Pendahuluan

Dua bentuk umum adalah standar dan kapsul. Tab terutama digunakan untuk tata letak dan dapat dikombinasikan dengan komponen lain.

<Frame>
  ![](https://gw.alicdn.com/imgextra/i2/O1CN01IWKV1AAHpXJ3hET6_!!6000000004909-2-tps-1821-911.png)
</Frame>

Sorot: Anda dapat mengontrol ukuran komponen, tetapi tidak dapat memindahkan posisi komponen Tab (kiri, tengah, atau kanan).

## 2. Langkah

### 2.1 Pilih komponen

Pilih komponen dan seret ke dalam designer.

Tambah komponen.

### 2.2 Konfigurasikan item tab

- Item tab: Tambah beberapa item tab. Jika terlalu banyak, konfigurasikan mode tampilan.

Mode tampilan.

Tambah item tab.

- Formulir: Merujuk pada bentuk tampilan item tab — standar, wrapped, teks, dan kapsul.
- Ukuran: Medium secara Default.

- Padding konten: Dapat disesuaikan. Default adalah 20px 20px.

Bentuk item tab.

### 2.3 Premium

#### 2.3.1 Aktifkan tiles

Mendukung drag-and-drop tiles, memudahkan penyesuaian lebar, tinggi, dan posisi bagan secara langsung.

  ![](https://gw.alicdn.com/imgextra/i2/O1CN0179Wb8IdgtaD3hU4C_!!6000000002288-2-tps-1823-869.png)

#### 2.3.2 Lazy loading

Jika diaktifkan, konten item tab hanya dimuat saat Anda beralih ke tab tersebut.

<Frame>
  ![](https://gw.alicdn.com/imgextra/i2/O1CN01AUmp6Z30BxD3rgFU_!!6000000003929-2-tps-1904-896.png)
</Frame>

#### 2.3.3 Destroy on switch

Jika Destroy on switch diaktifkan, ikon lightning loading berwarna biru akan muncul setiap kali Anda beralih tab dan data dimuat ulang, seperti ditunjukkan di bawah ini:

#### 2.3.4 Aktifkan positioning

Jika positioning diaktifkan dan Anda memilih sebuah item tab, URL browser akan menambahkan sufiks item tab tersebut. Menempelkan tautan ini akan membuka aplikasi dengan item tab saat ini terpilih secara Default.
