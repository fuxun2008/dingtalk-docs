## 1. Pendahuluan

Agregasikan data yang tersebar dalam satu bidang untuk keperluan statistik. Metode agregasi yang tersedia berbeda-beda tergantung pada tipe bidang.

## 2. Langkah

**Jalur**: Halaman laporan >> Kolom Spreadsheet >> Tombol Edit di samping bidang >> Panel Pengaturan data >> Agregasi

**String**: Hitung, Hitung (deduplikasi)

**Tanggal**: Hitung, Hitung (deduplikasi), Maksimum, Minimum

**Numerik**: Hitung, Hitung (deduplikasi), Jumlah, Rata-rata, Maksimum, Minimum
