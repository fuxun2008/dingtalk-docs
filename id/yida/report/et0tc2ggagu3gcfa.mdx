polished: true
---

Terdapat dua jenis pemfilteran bersyarat:

**Filter dalam komponen**: kondisi Filter tetap yang diterapkan pada data Komponen tertentu.

**Filter berbasis Filter**: membangun hubungan antara Komponen dan Filter, sehingga data Komponen dapat difilter berdasarkan nilai Filter.

<Warning>
Pada filter dalam komponen, untuk mewajibkan sebuah Bidang harus kosong, ikuti langkah-langkah berikut. Anda tidak perlu mengonfigurasi Formula untuk Bidang tersebut.
</Warning>
