Laporan menyediakan beragam gaya bagan. Gunakan Tabel detail dan Tabel Pivot untuk melihat data formulir atau formulir alur kerja secara rinci maupun teragregasi. Gunakan Column, Line, dan bagan lainnya untuk mengolah data serta mengungkap tren, perbandingan antarkategori, dan lainnya. Gunakan Pie untuk menampilkan proporsi setiap bagian dalam data.

| **Nama komponen** | **Tujuan** |
|---|---|
| [**Column**](/id/yida/report/xybfun) | Menampilkan **perbandingan numerik antarkategori** dengan batang vertikal atau horizontal. |
| [**Pie**](/id/yida/report/hb73mq) | Menampilkan proporsi data pada setiap Departemen. |
| [**Line**](/id/yida/report/pnsoga) | Menampilkan bagaimana data **berubah pada interval atau rentang waktu yang berkelanjutan**. Bagan ini mencerminkan tren perubahan seiring waktu atau antarkategori yang berurutan. |
| [**Bagan kombinasi Column-Line**](/id/yida/report/wfno1e) | Column memvisualisasikan perbedaan antarkelompok data dan menonjolkan perbandingan antarindividu.<br />Line menganalisis perubahan penjualan suatu produk seiring waktu untuk membantu memprediksi penjualan di masa mendatang.<br />Bagan kombinasi Column-Line menampilkan Column dan Line secara bersamaan. |
| [**Dasbor**](/id/yida/report/xgetgl) | Memungkinkan Anda mengatur ukuran Komponen dan memindahkan posisinya secara bebas (rata kiri, rata tengah, rata kanan). |
| [**Corong**](/id/yida/report/hd3q1n) | Memberikan tampilan intuitif atas tingkat konversi setiap tahap bisnis. Pada dasarnya, Corong merupakan aplikasi khusus dari analisis jalur yang berfokus pada analisis konversi jalur kritis. |
| [**Word cloud**](/id/yida/report/gtyrhp) | Membuat bagan word cloud dari data formulir. |
| [**Radar**](/id/yida/report/grr9lt) | Metode grafis yang menampilkan data multivariat dalam bagan dua dimensi, dengan tiga atau lebih variabel kuantitatif direpresentasikan pada sumbu-sumbu yang berawal dari titik yang sama. |
| [**Peta panas Kalender**](/id/yida/report/lyedo6) | Menampilkan progres pada berbagai waktu di Kalender dan menyesuaikan warna berdasarkan nilai. **Cocok untuk meninjau skenario seperti volume kode atau aktivitas kerja dalam suatu periode.** |
| [**Peta Tiongkok**](/id/yida/report/plcwtt) | Komponen peta administratif yang mendukung tingkat provinsi, kota, dan kabupaten pada Peta Tiongkok, beserta drill-down dan roll-up antartingkat tersebut. |
| [**Tabel dasar**](/id/yida/report/stqur9) | Menampilkan data formulir yang dikirimkan dalam Spreadsheet bergaya Excel. |
| [**Tabel pivot silang**](/id/yida/report/osbbht) | Salah satu visualisasi yang paling umum digunakan dalam analisis harian, serupa dengan Excel. YiDA menyediakan pivoting multi-level, kalkulasi Metrik, total dan subtotal, pemfilteran cepat, serta kemampuan lainnya. Tindakan praktis seperti mengklik Metrik untuk menampilkan data detail juga tersedia untuk dieksplorasi. |
| [**Kartu metrik dasar**](/id/yida/report/vn761o) | Konfigurasikan Metrik dan ikon untuk menampilkan nilai metrik utama beserta ikonnya. Klik ikon untuk melakukan drill-down. |
| [**Teks**](/id/yida/report/hu9aqr) | Menampilkan informasi teks dasar. |
| [**Gambar**](/id/yida/report/pyrhm5) | Menampilkan informasi gambar. |
| [**Tautan**](/id/yida/report/tst3xa) | Mengalihkan ke suatu URL dan menggabungkan parameter secara bebas. |
| [**Kontainer**](/id/yida/report/qhbihp) | Digunakan terutama untuk Tata letak dan dapat dikombinasikan dengan Komponen lain. |
| [**Pembagi kolom**](/id/yida/report/xvx3lt) | Digunakan terutama untuk Tata letak dan dapat dikombinasikan dengan Komponen lain. |
| [**Tab**](/id/yida/report/pux8db) | Dua gaya yang umum adalah standar dan kapsul. Digunakan terutama untuk Tata letak dan dapat dikombinasikan dengan Komponen lain. |
| [**Filter Waktu**](/id/yida/report/hbqowi) | Mendukung pengaturan **nilai tunggal** maupun **rentang** untuk pemfilteran. |
| [**Filter Dropdown**](/id/yida/report/is9r5k) | Mendukung mode **Pilih** dan **Pilih Banyak**, dengan Cari fuzzy di kotak input. Anda dapat mengonfigurasi Tampilkan bidang untuk membedakan bidang yang ditampilkan kepada Pengguna dari bidang yang benar-benar dikueri (misalnya, menampilkan nama Departemen sambil mengueri berdasarkan kode Departemen).<br />Juga mendukung mode **Tag** untuk pemfilteran berbasis Tag. |
| [**iFrame**](/id/yida/report/cs2lgv) | Menyematkan konten dari halaman web lain ke dalam Halaman desainer saat ini. |
