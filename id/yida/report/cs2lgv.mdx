## 1. Pendahuluan

Sematkan konten dari halaman web lain ke halaman designer Anda saat ini. Contoh berikut menyematkan URL dokumen bantuan DingTalk YiDA.

## 2. Langkah-langkah

### 2.1 Pilih komponen

Buka laporan, lalu dari menu atas pilih Others >> iFrame, dan seret ke dalam halaman.

<Frame>
  ![](https://gw.alicdn.com/imgextra/i1/O1CN01b4ZHHQrQQLL3gr3L_!!6000000004135-2-tps-1818-905.png)
</Frame>

Tambah komponen.

### 2.2 Pengaturan atribut

#### 2.2.1 URL iFrame

Klik komponen iFrame. Di panel atribut sebelah kanan, temukan iFrame URL dan masukkan URL situs resmi YiDA.

<Frame>
  ![](https://gw.alicdn.com/imgextra/i2/O1CN01TFYP3MQL9sI3g6E3_!!6000000005026-2-tps-1812-907.png)
</Frame>

Tambah URL.

<Frame>
  ![](https://gw.alicdn.com/imgextra/i4/O1CN01mGBJzR27MKH3gr2F_!!6000000007147-2-tps-1818-837.png)
</Frame>

Tampilan hasil.
