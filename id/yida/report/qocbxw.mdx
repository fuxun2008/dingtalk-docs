Report designer menyediakan sekumpulan komponen bagan yang kaya, yang diatur berdasarkan kategori. Pilih komponen yang Anda perlukan untuk mengonfigurasi analisis, agregasi, dan kueri data sesuai kebutuhan organisasi Anda.

## Gambaran umum halaman laporan

Report designer terdiri dari action bar di sisi kanan, area pemilihan komponen, page settings bar, dan area kanvas. Area kanvas berisi area filter, seperti ditunjukkan di bawah ini:

### Page settings bar

Klik Pengaturan untuk mengonfigurasi atribut keseluruhan laporan. Anda dapat mengonfigurasi tindakan yang dipicu saat halaman selesai dimuat atau saat halaman ditutup.

Klik Style untuk mengonfigurasi gaya keseluruhan laporan.

### Area pemilihan komponen

Laporan menyediakan berbagai komponen bagan. Pilih komponen sesuai kebutuhan untuk menampilkan dan menganalisis data.

### Area filter

Secara default, area kanvas berisi komponen filter dengan judul filter. Anda juga dapat menambahkan filter dropdown atau filter waktu di atasnya.

### Area tindakan di sisi kanan

Gunakan area ini untuk mengonfigurasi dataset, Bidang data yang ditampilkan, serta gaya untuk komponen laporan yang dipilih.

## FAQ

<Accordion title="Mengapa saya tidak dapat memilih Bidang pada pengaturan Tautan di bawah Bidang data?">
  Simbol @ harus diketik dalam mode bahasa Inggris (setengah lebar). Simbol Tionghoa lebar penuh tidak didukung.
</Accordion>
</AccordionGroup>

### Menggunakan tile bersama dengan komponen tata letak

Secara default, laporan YiDA mendukung penarikan tile untuk setiap komponen, sehingga memudahkan pengaturan lebar, tinggi, dan posisi bagan secara instan. Namun, saat menggunakan beberapa lapis komponen kontainer bertingkat (seperti halaman tab, kolom, atau kontainer), sebaiknya matikan sakelar tile pada kontainer terluar untuk meningkatkan performa halaman dan kecepatan pemuatan laporan secara keseluruhan.
