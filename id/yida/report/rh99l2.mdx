## 1. Pendahuluan

Yida menambahkan pemilih filter rentang pada laporan untuk memfilter Bidang bertipe Angka.

## 2. Penggunaan

### 2.1 Konfigurasikan data

Pada dataset laporan, pilih Bidang bertipe Angka (Bidang dengan ikon awalan "123" berwarna abu-abu menandakan tipe Angka).

### 2.2 Konfigurasikan gaya

Konfigurasikan aturan gaya untuk filter rentang, seperti Judul dan ukuran gaya.
