Contoh visualisasi data laporan berikut disusun berdasarkan kebutuhan umum pengguna. Klik tautan untuk melihat instruksi konfigurasi terperinci.

## Topik laporan 3.0

1. Gunakan data subformulir untuk analisis laporan
2. Lihat rekaman sumber di spreadsheet
3. Klik potongan pai untuk beralih ke daftar detail spreadsheet
4. Konfigurasikan variabel sebagai kondisi Filter di laporan
5. Lihat data yang dikirim departemen Anda di laporan
6. Tampilkan data dari beberapa tabel
7. Konfigurasikan Filter kaskade di laporan
8. Tautkan satu Filter ke beberapa formulir di laporan
9. Tampilkan rentang usia dalam bagan pai
10. Tampilkan gambar formulir yang diunggah di spreadsheet dengan klik-untuk-pratinjau
11. Gunakan tabel pivot silang untuk menampilkan rekaman penjualan toko di laporan
12. Sertakan bidang formula dalam kondisi Filter tabel tampilan
13. Konfigurasikan drill-down pada bagan pai di laporan
14. [Cara menggunakan tabel tampilan](/id/yida/app-admin/oim554)
15. Filter berdasarkan Terima dan Tolak di laporan
16. Filter rentang waktu dengan komponen Filter laporan
17. Tampilkan pengguna dalam format yang konsisten di spreadsheet laporan
18. Aktifkan panggilan satu klik di laporan

## Topik laporan 2.0

1. Gunakan fitur laporan 3.0 di laporan 2.0
2. Tampilkan gambar formulir langsung di laporan
3. Tampilkan pengguna dalam format yang konsisten di spreadsheet laporan
4. Gunakan bagan pai untuk menampilkan data berdasarkan rentang usia di laporan
5. Klik potongan pai untuk beralih ke daftar detail spreadsheet
6. Gunakan bagan pai untuk menampilkan detail di beberapa kategori
7. Gunakan dasbor untuk menampilkan kondisi fisik di laporan
8. Aktifkan panggilan satu klik di laporan YiDA
9. Batasi pengguna agar hanya dapat melihat data departemennya sendiri di laporan
10. Gunakan data subformulir untuk analisis laporan
11. Beralih dari spreadsheet laporan ke laporan lain dan Filter datanya
12. Tautkan satu Filter ke beberapa formulir di laporan
13. Konfigurasikan Filter kaskade di laporan
14. Konfigurasikan variabel sebagai kondisi Filter di laporan
15. Filter berdasarkan Terima dan Tolak di laporan
16. Filter rentang waktu dengan komponen Filter laporan
17. Hitung lintas formulir, misalnya menghitung inventaris dari rekaman pembelian dan pengiriman
18. Tampilkan progres proyek untuk statistik laporan
19. Klik data di laporan untuk beralih ke detail
