## 1. Ikhtisar

### 1.1 Ikhtisar fitur

Gunakan komponen ini untuk mengalihkan ke URL dan menggabungkan parameter secara bebas.

Sorotan: Anda dapat mengatur ukuran komponen, tetapi tidak dapat memindahkan posisi tautan (rata kiri, tengah, atau kanan).

### 1.2 Kasus penggunaan

Pada halaman tampilan data produk, konfigurasikan tautan untuk mengalihkan ke halaman detail produk saat pengguna ingin Lihat Detail.

## 2. Langkah-langkah

### 2.1 Pilih komponen

Pilih Komponen dan seret ke dalam designer.

Tambah Komponen.

### 2.2 Konfigurasikan konten

Konfigurasikan Judul tautan dan URL.

- Mendukung tampilan terpotong.

Perbandingan saat pemotongan Aktif dan nonaktif.

- Mendukung pengaturan Tipe tautan (Alihkan ke Halaman internal atau Tautan eksternal).
- Mendukung pengaturan metode pembukaan tautan.

- Mendukung parameter Kustom pada tautan (beberapa parameter dapat ditambahkan).

Tambah URL tautan.

### 2.3 Konfigurasikan gaya

Sesuaikan status Default dan Pengaturan gaya lainnya.

Konfigurasi gaya.
