## 1. Pengantar

Pengurutan Spreadsheet mengikuti urutan Bidang, sehingga Anda dapat memilih Bidang referensi untuk setiap Bidang.

## 2. Prosedur

Alur: Halaman laporan >> Pilih kolom Bidang >> Tombol Edit di samping Bidang >> Panel pengaturan data >> Urutkan

## 3. Bidang referensi

Pilih urutan naik atau turun untuk menetapkan Bidang referensi.

Seperti yang ditunjukkan di bawah ini, meskipun nama produk merupakan Bidang pertama, Anda dapat memilih untuk mengurutkan berdasarkan waktu pembuatan sehingga waktu pembuatan memperoleh prioritas pengurutan tertinggi.
