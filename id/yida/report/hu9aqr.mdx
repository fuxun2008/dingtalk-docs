## 1. Ikhtisar

### 1.1 Ikhtisar fitur

Gunakan komponen Teks untuk menampilkan informasi teks dasar.

Sorot: Anda dapat mengontrol ukuran komponen, tetapi tidak dapat memindahkan posisinya (kiri, tengah, atau kanan).

### 1.2 Skenario penggunaan

Sebagai contoh, saat memeringkat siswa berdasarkan nilai ujian, gunakan komponen Teks untuk menganalisis penyebab siswa yang berkinerja rendah dan menyusun rencana perbaikan lanjutan.

## 2. Langkah

### 2.1 Pilih komponen Teks

Pilih komponen dan seret ke desainer.

Pilih komponen.

### 2.2 Konfigurasikan konten

Di Atribut, atur konten teks, judul, status default, dan jumlah maksimum baris. Atur pengidentifikasi unik di pengaturan Premium.

Konfigurasikan konten.

### 2.3 Konfigurasikan gaya

Sesuaikan status default dan opsi gaya lainnya.
