## 1. Langkah-langkah

### 1.1 Metode 1

Setelah masuk ke YiDA, klik **Aplikasi Saya** dan buka salah satu aplikasi. Di bagian tengah area manajemen Halaman, Anda akan menemukan pintasan untuk membuat lima jenis Halaman. Pilih **Buat laporan**.

### 1.2 Metode 2

Di Halaman beranda Aplikasi, klik ikon **+** biru di pojok kiri atas, lalu pilih **Buat laporan**.

## 2. FAQ

**Q: Kapan organisasi DingTalk saya dapat mencoba laporan 3.0 yang baru?**

Laporan 3.0 sudah tersedia sepenuhnya. Fitur ini berlaku untuk laporan yang baru dibuat di Aplikasi yang baru dibangun.

**Q: Apakah Aplikasi yang sudah ada mendukung Versi laporan baru?**

Tidak. Saat ini YiDA mendukung kemampuan "pengambilan data lintas Aplikasi" untuk laporan. Anda tidak perlu mengubah Aplikasi lama — formulirnya tetap dapat digunakan — tetapi Anda dapat mengambil data dari Aplikasi lama di Aplikasi baru dan membuat laporan di sana.

**Q: Saat membuat dasbor DataV, apakah akun DingTalk dapat ditautkan dengan akun Alibaba Cloud?**

Penautan akun tidak didukung pada Versi saat ini. Namun, Anda dapat menggunakan App Secret untuk memberikan otorisasi akses ke data formulir YiDA.

**Q: Apa itu tabel tampilan?**

Tabel tampilan adalah peningkatan dari kemampuan "asosiasi multi-Tabel" yang sudah ada pada laporan. Fitur ini lebih andal, dan Tabel tampilan yang dihasilkan berfungsi sebagai dataset independen yang dapat digunakan ulang di berbagai laporan dalam Aplikasi yang sama, sehingga meningkatkan efisiensi.

**Q: Bagaimana cara meningkatkan laporan 2.0 ke 3.0?**

Peningkatan langsung tidak didukung. Anda harus membuat Aplikasi YiDA baru untuk menggunakan fitur laporan 3.0. Sebagai alternatif, lihat solusi pengambilan data lintas Aplikasi.

**Q: Mengapa laporan gagal menyinkronkan data padahal formulir memiliki nilai?**

Hal ini terjadi karena sebuah bidang ditambahkan tetapi Versinya belum diperbarui. Edit dan simpan data secara manual, atau panggil API `/v1/form/updateFormData.json` dengan `useLatestVersion=y` untuk memaksa data diperbarui ke Versi terbaru. Perlu diketahui bahwa data yang diperbarui oleh aturan asosiasi bisnis saat ini tidak memperbarui Versi formulir.

**Q: Mengapa saya tidak dapat memilih dataset?**

Periksa apakah formulir dataset memiliki lebih dari 300 bidang. Terlalu banyak bidang formulir akan memengaruhi waktu Respons API saat laporan mereferensikan dataset tersebut.

**Q: Komponen lokasi formulir menemukan sebuah kotamadya, tetapi tidak dapat ditampilkan di sisi laporan. Mengapa?**

Untuk data yang dihasilkan oleh Komponen lokasi/alamat pada formulir, kotamadya (setingkat dengan provinsi) disimpan tanpa akhiran "City" — misalnya, "北京" dan bukan "北京市".

Namun, Komponen peta China pada laporan menampilkan hingga level provinsi dan memerlukan kecocokan persis pada nama provinsi, yang harus menyertakan akhiran "市". Karena nilainya tidak cocok dengan data yang dihasilkan formulir, data tersebut tidak dapat dirender.

Saat ini Anda dapat mengatasinya dengan menggunakan Formula **casewhen** pada laporan atau dengan memproses data di **Persiapan Data** untuk menambahkan "市" agar dapat dirender.

**Q: Apakah pengurutan bahasa Mandarin pada laporan 2.0 mengikuti karakter set GBK?**

Pengurutan bahasa Mandarin pada laporan YiDA didasarkan pada urutan ASCII.

## Pertanyaan yang dikelompokkan

**Q: Masalah Izin Data pada laporan**

Ketika dataset laporan memilih subformulir, saat ini dataset tidak dibatasi oleh Izin Lihat dari Tabel sumber. Halaman manajemen data menampilkan data yang dibatasi dengan benar.

**Q: Apakah ada batasan pada grup izin Halaman dalam satu Aplikasi? Berapa jumlah maksimum grup izin yang dapat dikonfigurasi?**

Untuk semua Halaman selain formulir alur kerja dan formulir reguler, Anda dapat membuat hingga 100 grup izin. Untuk formulir alur kerja dan formulir reguler, masing-masing dapat dibuat hingga 100 grup izin Kirim dan 100 grup Izin Lihat.

**Q: Apa arti Kesalahan filter [Pengingat: Kesalahan filter engine: Kesalahan eksekusi data: Statement cancelled due to client request]?**

Kesalahan ini muncul ketika kueri laporan memakan waktu lebih dari 30 detik. Kami menyarankan Anda mengoptimalkan kondisi kueri.
