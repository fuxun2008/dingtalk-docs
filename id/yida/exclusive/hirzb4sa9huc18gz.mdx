## 1. App Vault

- Sakelar App Vault: setelah diaktifkan untuk aplikasi tertentu, aplikasi tersebut memperoleh perlindungan penuh atas data bisnisnya. Admin platform tidak lagi dapat mengakses backend aplikasi secara langsung maupun melihat data sensitifnya.
- Setelah diaktifkan, admin IT dan admin platform lainnya tidak dapat melihat aplikasi. Fitur ini cocok untuk aplikasi yang melibatkan rahasia dagang atau data sensitif, seperti kompensasi dan penggajian.

Entri konfigurasi: Backend admin > Pengaturan aplikasi > Izin aplikasi.

## 2. Zero-trust firewall

Ketika Yida di cloud perlu terhubung ke layanan integrasi & otomatisasi intranet (HTTPS) atau Sumber Data JDBC eksternal (TCP/IP) milik organisasi Anda, secara default organisasi harus mengekspos layanan tersebut ke internet publik.

Yida bekerja sama dengan teknologi zero-trust enterprise gateway dari DingTalk untuk mencegah layanan terkait terekspos langsung ke internet publik. Dengan teknologi penetrasi jaringan zero-trust, layanan inti organisasi tetap terlindungi tanpa mengorbankan kebutuhan interkoneksi bisnis.

## 3. IP network fence

Admin dapat mengontrol perilaku karyawan — seperti masuk ke DingTalk, mengunggah, dan mengunduh file — berdasarkan segmen alamat jaringan atau aplikasi. Buka [Backend admin OA](https://oa.dingtalk.io/vip2.htm#/securityGate) > **Dedicated DingTalk** > **Dedicated security > Security access > IP fence** untuk mengontrol pengunduhan Lampiran yang aman secara fleksibel di berbagai aplikasi Yida.

<Note>
Segmen IP yang dikonfigurasi di IP fence harus berupa IP publik, bukan IP privat.
</Note>

| **Sebelum** | **Sesudah** |
|---|---|
| Pengunduhan Lampiran Yida hanya dapat dinonaktifkan atau diaktifkan secara keseluruhan, tanpa kontrol per aplikasi. | Konfigurasikan kontrol Lampiran secara fleksibel dengan menggabungkan kondisi seperti **segmen IP jaringan tertentu**, **grup organisasi tertentu**, dan **aplikasi Yida tertentu**. |

## 4. Mode jalur jaringan khusus

- Dedicated DingTalk menyediakan kemampuan proxy jaringan profesional untuk jalur jaringan khusus, sehingga memungkinkan komunikasi antara jalur khusus dan internet publik dengan identitas terpercaya. Yida Dedicated mendukung kemampuan "mode proxy jalur jaringan khusus" dari Dedicated DingTalk.
