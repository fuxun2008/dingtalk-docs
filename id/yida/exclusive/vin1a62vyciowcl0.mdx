## Ikhtisar Fitur

Lingkungan Cluster Dedicated adalah solusi arsitektur hybrid cloud yang dibangun di atas fondasi produk Yida Dedicated, yang sepenuhnya memprivatisasi artefak build Aplikasi, data Aplikasi, dan layanan runtime Aplikasi.

Mode pengembangan dan desain produk tetap berjalan di cloud. Artefak build dari setiap rilis Aplikasi, yang membawa Versi tertentu, didorong ke lingkungan cluster target Organisasi berdasarkan Versi.
