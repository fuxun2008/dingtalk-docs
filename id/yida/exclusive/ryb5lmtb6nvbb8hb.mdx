YiDA Edisi Dedicated mendukung tata kelola aplikasi. Saat ini, skenario berikut telah tercakup: membuat aplikasi kosong, membuat aplikasi dari template, membuat aplikasi dari Excel, pembuatan aplikasi cerdas, dan penyalinan aplikasi. Setelah tata kelola aplikasi diaktifkan, aplikasi yang baru dibuat atau disalin berstatus Dinonaktifkan secara default. Untuk mengaktifkannya, kirim Permintaan persetujuan terlebih dahulu.

## Aktifkan tata kelola aplikasi

1. Masuk ke workbench YiDA sebagai Admin platform, buka halaman **manajemen platform**, klik **Governance Center**, lalu aktifkan **Tata kelola aplikasi**.

<Frame>
  ![](https://gw.alicdn.com/imgextra/i2/O1CN01MIKoWaIHg8G36TVx_!!6000000005999-2-tps-1529-904.png)
</Frame>

2. Aktifkan toggle tata kelola dan pilih saluran publikasi yang akan diatur.
3. Konfigurasikan Cakupan tata kelola.

Admin aplikasi dalam Cakupan tata kelola harus mengirim Permintaan persetujuan untuk mengaktifkan atau mempublikasikan aplikasi.

<Frame>
  ![](https://gw.alicdn.com/imgextra/i1/O1CN01xG68WCUbZrE36qzD_!!6000000007749-2-tps-1532-1127.png)
</Frame>

4. Konfigurasikan Proses persetujuan tata kelola.

Admin dapat menyesuaikan proses tata kelola. Klik **Edit** untuk memodifikasi Proses persetujuan bawaan platform (Formulir aplikasi itu sendiri tidak dapat diubah).

<Frame>
  ![](https://gw.alicdn.com/imgextra/i3/O1CN01x6xLmod9xFL6oy0S_!!6000000003389-2-tps-3360-1724.png)
</Frame>

## Persetujuan untuk permintaan pengaktifan

Setelah Admin mengaktifkan "Tata kelola pengaktifan", aplikasi yang baru dibuat oleh Pengguna dalam Cakupan tata kelola berstatus "Dinonaktifkan" secara default. Pengguna di luar Cakupan tata kelola tidak terpengaruh dan aplikasi mereka tetap Diaktifkan secara default.

**Untuk memudahkan Admin aplikasi dalam menguji aplikasi selama pengembangan, Admin aplikasi yang tunduk pada tata kelola pengaktifan dapat mengirim data untuk pengujian sebelum aplikasi diaktifkan.**

Untuk mengaktifkan aplikasi, Admin aplikasi harus terlebih dahulu mengirim "Permintaan pengaktifan". Aplikasi hanya dapat diaktifkan setelah permintaan disetujui.
