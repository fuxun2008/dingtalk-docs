Dedicated storage kini mendukung pemindahan Tabel fisik terkait alur kerja ke basis data kustom organisasi, sehingga organisasi dapat melakukan tata kelola dan analisis alur kerja pada dedicated storage.

Data terkait Persetujuan juga secara default disimpan di dedicated storage kustom organisasi. Pelanggan organisasi dapat memanfaatkan data alur kerja yang terus terakumulasi untuk melakukan tata kelola dan analisis alur kerja.
