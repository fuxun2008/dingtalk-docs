YiDA Dedicated adalah **platform pengembangan bisnis low-code** yang dibangun khusus untuk Organisasi Anda. Platform ini menjawab kebutuhan kustomisasi yang tidak dapat dipenuhi oleh edisi public cloud, termasuk penyimpanan data kustom, ekstensi bisnis, perlindungan Keamanan, dan analitik bisnis. Selain itu, platform ini memberikan performa produk yang lebih tinggi, solusi untuk volume data yang sangat besar, dan opsi Kebijakan Keamanan tambahan untuk meningkatkan tingkat Keamanan bisnis Anda.

## Ikhtisar solusi

YiDA Edisi Dedicated menawarkan kapabilitas upgrade cloud-native. Seluruh data bisnis aplikasi low-code disimpan di ruang penyimpanan pribadi yang ditentukan oleh pelanggan, memberikan pelanggan Keamanan eksklusif yang lebih tinggi baik untuk data maupun runtime. Platform ini juga mencakup berbagai kapabilitas ekstensi dan kustomisasi dedicated, sehingga lebih cocok untuk Organisasi menengah dan besar dengan persyaratan platform dan kebutuhan kustomisasi yang tinggi.

## Tiga kapabilitas inti

### 1. Keamanan data bisnis yang andal

- Privatisasi data: data bisnis disimpan di penyimpanan dedicated, membuat penyimpanan independen lebih andal
- Keamanan jaringan: gateway zero-trust melindungi layanan intranet Organisasi Anda
- File penting: mendukung deteksi dan kontrol pagar jaringan dengan kebijakan yang berbeda
- Audit perilaku: aktivitas direkam dengan perlindungan dedicated, dan log Organisasi dapat ditelusuri serta dicari

### 2. Kapabilitas kustomisasi dedicated yang kaya

- Peningkatan brand: bangun citra brand Organisasi Anda dengan domain kustom, logo, dan lainnya
- Kustomisasi UI: cerminkan budaya Organisasi Anda dengan gaya halaman dedicated
- Kelola Obrolan: sediakan mode Jangan Ganggu untuk eksekutif
- Kelola izin: sistem izin multi-level memenuhi kebutuhan manajemen yang dipersonalisasi

### 3. Konektivitas lintas Organisasi

- Interkoneksi Organisasi: terhubung dengan mitra dan pelanggan hulu maupun hilir
- Single Sign-On: akun dedicated DingTalk mendukung berbagai layanan IDaaS
- API + Konektor: hubungkan bisnis dan data lintas sistem

## Manfaat dan kapabilitas produk yang lebih tinggi

YiDA Dedicated menawarkan batas volume data yang lebih tinggi, mendukung lebih dari satu juta Rekam per Formulir, puluhan juta total Rekam per Organisasi, dan batas QPS konkurensi bisnis yang lebih tinggi. Platform ini juga mencakup fitur dan manfaat premium seperti interkoneksi hulu dan hilir, penyimpanan Organisasi bersama, dan Dedicated DingTalk.

Untuk informasi lebih lanjut, lihat [detail edisi produk](https://www.yidaapps.com/pricing).

  (2) Data bisnis yang dikirim oleh Pengguna dan lampiran yang diunggah dapat disimpan secara lokal.

</Accordion>

### **T: Bagaimana data diprivatisasi—penulisan langsung ke penyimpanan pribadi atau transfer dari public cloud? Apakah mencakup data terstruktur dan tidak terstruktur?**

J:

(1) Penulisan langsung; tidak ada penyimpanan di cloud.

(2) Jika Anda memiliki OSS dan database public cloud, penulisan langsung juga didukung.

(3) Data terstruktur disimpan sebagai string JSON standar.

### **T: Seperti apa bentuk data yang telah diprivatisasi? Apakah dienkripsi? Bisakah kami menggunakan data yang diprivatisasi secara langsung untuk analisis data lokal? Idealnya, bisakah kami melihat tangkapan layar sampel data yang diprivatisasi?**

J:

(1) Penyimpanan data tidak dienkripsi.

(2) Ya, Anda dapat menganalisisnya. Sebagian besar tool BI dapat mengekstrak, mendekonstruksi, dan menganalisis data tersebut.

(3) Pada skenario tertentu, Data Formulir aplikasi dapat disimpan langsung dalam kolom fisik penuh, yang mempermudah analisis statistik.

<Accordion title="T: Apa saja persyaratan privatisasi data untuk platform cloud kami?">
  J:

  (1) Untuk performa kueri dan arsitektur yang lebih baik, database bisnis untuk penyimpanan dedicated saat ini mensyaratkan PostgreSQL, versi 14 atau yang lebih baru.

  (2) Penyimpanan object saat ini mendukung OSS dari berbagai vendor utama, termasuk Alibaba Cloud OSS, Huawei Cloud OBS, dan Inspur Cloud OSS.
</Accordion>
<Accordion title="T: Dengan aplikasi di cloud dan data di on-premises, berapa perkiraan latensi untuk penyimpanan dan pembacaan data? Apakah Anda memiliki kasus deployment serupa?">
  J:

  (1) Untuk data center on-premises, latensi berkisar 20–40 ms.

  (2) Untuk cloud, latensi berkisar 3–5 ms.

  (3) Pelanggan Edisi Dedicated meliputi Sungrow dan FAW-Volkswagen.
</Accordion>
<Accordion title="T: Apakah penyimpanan File dan penyimpanan data mendukung cloud heterogen?">
  J:

  (1) Penyimpanan object File hanya mendukung Alibaba Cloud OSS, Huawei Cloud OBS, Inspur Cloud OSS, dan layanan serupa.

  (2) Penyimpanan data mendukung berbagai cloud—pilih salah satu—tetapi database PostgreSQL harus diinstal.
</Accordion>
<Accordion title="T: Apakah Edisi Dedicated mendukung persiapan data?">
  J:

  Ya, dengan syarat data Pengguna disimpan di Alibaba Cloud. Jika data disimpan secara lokal, pelanggan perlu menangani pemrosesan data offline sendiri.
</Accordion>
</AccordionGroup>

### **T: Database apa saja yang didukung?**

J: Kami merekomendasikan PostgreSQL yang open-source dan berkinerja tinggi. Di Alibaba Cloud, pilih [ApsaraDB RDS for PostgreSQL](https://www.aliyun.com/product/rds/postgresql) atau [AnalyticDB for PostgreSQL](https://www.aliyun.com/product/gpdb?spm=5176.21213303.1157856.1.56fc53c9ILED0R&scm=20140722.S_card@@%E4%BA%A7%E5%93%81@@448638.S_card0.ID_card@@%E4%BA%A7%E5%93%81@@448638-RL_ADB-OR_ser-V_2-P0_0) yang berkinerja lebih tinggi.

### **T: Apakah migrasi data historis didukung?**

J: Ya. Migrasi batch satu kali untuk data historis didukung. Pengguna juga dapat melakukan migrasi secara manual di konsol admin aplikasi YiDA di bagian Pengaturan aplikasi > Informasi dasar (Anda juga dapat memilih mode penyimpanan saat membuat aplikasi baru).

### **T: Apakah penskalaan dan sharding database didukung?**

Ya. Setelah Anda menyediakan instance database target, engineer profesional YiDA dapat membantu penskalaan elastis.

### **T: Bagaimana Keamanan transmisi data?**

Data dienkripsi sepanjang transmisi, dan seluruh data bisnis Formulir masuk ke database penyimpanan dedicated Organisasi Anda.
