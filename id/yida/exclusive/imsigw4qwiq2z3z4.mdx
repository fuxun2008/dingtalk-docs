Eksklusif Edisi Dedicated

| **Fitur** | **Free plan** | **Edisi Basic** | **Edisi Professional** | **Edisi Dedicated** |
|---|---|---|---|---|
| Log organisasi | Tidak didukung | Tidak didukung | Tidak didukung | Didukung |

## Ikhtisar

- Melalui fitur log organisasi, admin platform dapat melihat log masuk, log platform, log aplikasi, dan log operasi data organisasi mereka selama enam bulan terakhir, sehingga mendukung tata kelola perilaku platform low-code tingkat perusahaan.
- Log organisasi hanya terlihat oleh admin platform Edisi Dedicated. Fitur pemfilteran, pencarian, dan ekspor log tersedia untuk memenuhi kebutuhan audit dan tata kelola perilaku tingkat perusahaan.

## Kueri log

| Log pengembangan aplikasi:<br />• Seluruh riwayat tindakan pada aplikasi low-code dapat dikueri, misalnya pembuatan, penghapusan, penyuntingan, dan penerbitan aplikasi, serta desain dan pengelolaan halaman di dalam aplikasi. |
|---|
| Log operasi data:<br />• Data merupakan aset organisasi yang krusial, sehingga setiap operasi terhadapnya memerlukan perhatian penuh. Ekspor data massal, impor massal, maupun tindakan data yang dijalankan melalui OpenAPI platform pengembangan semuanya mendukung kueri riwayat. |
| Log platform:<br />• Meliputi pengaturan informasi dasar organisasi dan platform, pengaturan izin platform, otorisasi akun, pengelolaan peran, serta tindakan ekspor data untuk log organisasi. Seluruh riwayat tindakan tersebut mendukung kueri rekaman. |
| Log masuk:<br />• Rekaman aktivitas masuk ke sistem dan penggunaan platform low-code Yida di dalam organisasi. |

## Ekspor log

| Tetapkan kondisi ekspor: Konfigurasikan filter, lalu jalankan ekspor. Maksimal 10.000 rekaman dapat diekspor sekaligus. Untuk volume yang lebih besar, gunakan filter untuk mengekspor seluruh data secara bertahap. |
|---|
| Ekspor berhasil: Notifikasi Kerja DingTalk akan dikirimkan, dan file Excel dapat diunduh. |

## Catatan

1. Setelah Anda mengklik tombol **Ekspor log**, sistem segera menyiapkan file. Setelah siap, operator akan diberi tahu melalui Obrolan DingTalk. Periksa pesan tersebut.

2. Maksimal 10.000 rekaman dapat diekspor sekaligus. Untuk volume yang lebih besar, gunakan filter untuk mengekspor seluruh data secara bertahap.

3. Hanya admin platform Yida yang dapat mengkueri dan mengekspor informasi rinci pada log organisasi.

4. Setiap ekspor data oleh admin platform juga tercatat pada log tindakan platform seperti biasa.

5. Tautan unduhan untuk setiap file yang diekspor berlaku selama tujuh hari. Segera unduh, karena file yang telah kedaluwarsa akan otomatis dibersihkan.
