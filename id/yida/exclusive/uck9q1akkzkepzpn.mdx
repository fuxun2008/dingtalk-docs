Pengaturan aplikasi global menjawab tantangan tata kelola yang muncul saat sebuah Organisasi memiliki terlalu banyak aplikasi. Fitur ini memungkinkan Anda mengontrol item konfigurasi default aplikasi YiDA di seluruh Organisasi dan menerapkan fitur tertentu secara paksa, sehingga lebih memenuhi kebutuhan tata kelola low-code perusahaan.

## Ikhtisar fitur

Pengaturan aplikasi global memungkinkan Anda mengontrol apakah aplikasi dalam Organisasi mengaktifkan penyimpanan khusus, lingkungan cluster khusus, kolom fisik khusus, watermark aplikasi, dan kotak proteksi aplikasi. Di antaranya, penyimpanan khusus, lingkungan cluster khusus, dan kolom fisik khusus dapat diterapkan secara paksa. Setelah diterapkan secara paksa, aplikasi YiDA yang baru dibuat otomatis mengaktifkan fitur-fitur ini secara default dan tidak dapat dinonaktifkan.

### Penyimpanan khusus

- Terapkan secara paksa: Setelah Diaktifkan, semua aplikasi YiDA yang baru dibuat mengaktifkan penyimpanan khusus tingkat aplikasi secara default. Data bisnis otomatis disimpan di penyimpanan privat Organisasi. Status default ini tidak dapat dinonaktifkan setelah Diaktifkan.

<Frame>
  ![](https://gw.alicdn.com/imgextra/i2/O1CN01M2Q5EPs48PC47Hz3_!!6000000004475-2-tps-2028-745.png)
</Frame>

- Status default: Setelah Diaktifkan, penyimpanan khusus Dipilih secara default saat Anda membuat aplikasi YiDA baru.

<Frame>
  ![](https://gw.alicdn.com/imgextra/i2/O1CN01vjKldeuUqoD3p2JS_!!6000000007152-2-tps-1883-747.png)
</Frame>

### Lingkungan cluster khusus

- Terapkan secara paksa: Setelah Diaktifkan, semua aplikasi YiDA yang baru dibuat mengaktifkan efek watermark tingkat aplikasi secara default. Artefak build aplikasi, status runtime, dan data bisnis otomatis disimpan di lingkungan privat Organisasi. Status default ini tidak dapat dinonaktifkan setelah Diaktifkan.
- Status default: Setelah Diaktifkan, lingkungan cluster khusus Aktif secara default saat Anda membuat aplikasi YiDA baru.

### Penyimpanan kolom fisik

- Terapkan secara paksa: Setelah Diaktifkan, penyimpanan data Formulir untuk aplikasi YiDA yang baru dibuat beralih dari JSON ke mode kolom fisik (satu Bidang berhubungan dengan satu Kolom fisik). Status default ini tidak dapat dinonaktifkan setelah Diaktifkan.

- Status default: Setelah Diaktifkan, penyimpanan kolom fisik tingkat aplikasi Dipilih secara default saat Anda membuat aplikasi YiDA baru.

### Watermark aplikasi

- Status default: Setelah Diaktifkan, efek watermark tingkat aplikasi Aktif secara default saat Anda membuat aplikasi YiDA baru.

### Kotak proteksi aplikasi

- Status default: Setelah Diaktifkan, kotak proteksi aplikasi Aktif secara default saat Anda membuat aplikasi YiDA baru.

## Pengaturan khusus untuk aplikasi individual

- Setiap aplikasi mendukung konfigurasi berdasarkan Departemen, memungkinkan kepemilikan yang lebih rinci dan kemampuan tata kelola aplikasi.
- Di dalam setiap aplikasi, Anda dapat melihat dan mengonfigurasi fitur khusus aplikasi secara terpisah, memperkaya data master aplikasi, dan mengelola aset data low-code Organisasi.
