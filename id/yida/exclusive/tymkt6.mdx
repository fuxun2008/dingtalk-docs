Pada YiDA Edisi Dedicated, kami menyediakan kustomisasi yang lebih baik untuk penyimpanan data bisnis. Pilih pendekatan yang lebih mandiri, aman, dan terkendali untuk mewujudkan penyimpanan privat data bisnis.

## Aktifkan sesuai kebutuhan (level Aplikasi)

### 1. Aktifkan saat membuat Aplikasi baru

Saat membuat Aplikasi baru, Pilih apakah data bisnis Aplikasi disimpan di public cloud (default) atau di database hybrid cloud khusus (untuk data kritis inti).

### 2. Aktifkan secara manual untuk Aplikasi yang sudah ada

- Admin Aplikasi dapat masuk ke Pengaturan Aplikasi > Pengaturan Dasar > Konfigurasi Khusus di backend Aplikasi, lalu Pilih dan Aktifkan penyimpanan khusus untuk Aplikasi tersebut.
- Setelah diaktifkan, baik data historis maupun data baru Aplikasi tersebut akan disimpan di database khusus (PostgreSQL) dan OSS Lampiran khusus yang dikonfigurasi di manajemen platform.
- Fungsi Aplikasi ditangguhkan selama proses upgrade. Lakukan Tindakan ini pada jam Luang. Proses memakan waktu sekitar 3–10 menit dan tidak dapat dibatalkan setelah selesai. Anda dapat menghentikan upgrade secara manual selama proses berlangsung.

### 3. Upgrade dan penghentian operasi

- Mengubah konfigurasi kerangka dasar Aplikasi merupakan operasi yang memakan waktu. Jika perlu menghentikan proses di tengah jalan, hentikan secara manual. Setelah upgrade dihentikan, konfigurasi Dasar Aplikasi kembali ke Pengaturan penyimpanan cloud dan mode operasi semula.
