> V1.0 Waktu pembaruan 2024.11

Saat Anda mengonfigurasi database dedicated untuk penyimpanan dedicated, platform YiDA menambahkan sejumlah Tabel yang diperlukan ke database tersebut untuk menyimpan Data yang dihasilkan selama penggunaan YiDA. Skema Tabel ini tidak bersifat tetap — skema akan berkembang seiring pertumbuhan bisnis dan iterasi teknis, sehingga Bidang atau Tabel baru dapat ditambahkan. Umumnya, guna menghindari gangguan pada operasional bisnis Anda, Bidang yang sudah ada akan tetap dipertahankan. Meskipun demikian, platform YiDA tetap menyarankan agar Anda tidak membangun ketergantungan yang kuat pada Data ini.

Contoh penambahan indeks untuk mengatasi timeout ditunjukkan di bawah — ganti kontennya, dan tetap gunakan odin_open_application_data sebagai referensi:

```text
CREATE INDEX CONCURRENTLY idx_model_filed_textField_xxxxx ON odin_open_application_data (
        namespace_code,
        table_name,
        is_deleted,
```
