Data aplikasi di lingkungan klaster khusus tersimpan di lingkungan privat dan tidak dapat mengakses jaringan publik. Akibatnya, YiDA OpenAPI di DingTalk Open Platform tidak dapat mengambil data tersebut. Anda harus memanggil OpenAPI dari dalam lingkungan klaster. Secara garis besar, OpenAPI di lingkungan klaster sama dengan yang ada di DingTalk Open Platform, hanya berbeda pada host dan AK/SK yang digunakan.

Artikel ini menjelaskan cara memanggil YiDA OpenAPI di lingkungan klaster khusus.

<Note>
Catatan:

YiDA Dedicated saat ini membuka API layanan data frekuensi tinggi miliknya. Berdasarkan kemampuan API YiDA yang tersedia di DingTalk Open Platform per 31 Desember 2023, total tersedia 52 OpenAPI.
</Note>

## Alur pemanggilan

Pemanggilan YiDA API di lingkungan klaster serupa dengan di DingTalk Open Platform. Semua OpenAPI terkait di DingTalk Open Platform dipanggil melalui api.dingtalk.com. Untuk OpenAPI edisi klaster, cukup ganti api.dingtalk.com dengan domain YiDA edisi klaster milik organisasi Anda.

1. Dapatkan domain klaster YiDA Dedicated organisasi Anda, misalnya ddyd.corp.com.
2. Dapatkan AK dan SK edisi klaster organisasi Anda.

<Note>
Hubungi admin DingTalk organisasi Anda. Masuk ke DingTalk Open Platform, cari "YiDA Dedicated Cluster" pada bagian aplikasi internal, lalu dapatkan informasi terkait dari aplikasi bernama **YiDA Dedicated Cluster Authentication App**.
</Note>

DingTalk Open Platform menyediakan SDK dalam Java, PHP, Python, dan .NET untuk developer. OpenAPI edisi klaster mendukung cara pemanggilan yang serupa.

<Note>
Aplikasi internal dan Aplikasi perusahaan pihak ketiga menggunakan Server-side SDK yang sama. Klik salah satu tautan berikut untuk mengunduhnya.

- Aplikasi internal: Unduh Server-side SDK.
- Aplikasi perusahaan pihak ketiga: Unduh Server-side SDK.
</Note>

5. Jika Anda menggunakan SDK dari DingTalk Open Platform, terapkan perubahan berikut:

Perubahan 1: Jika domain menggunakan http, atur config.protocol = "http".

Perubahan 2: Atur client._endpoint secara eksplisit ke domain YiDA sebenarnya milik organisasi Anda.

```java
private static com.aliyun.dingtalkyida_2_0.Client createOpenApiClient() {
        Config config = new Config();
        config.regionId = "central";
        config.protocol = "http";
        config.connectTimeout = 60 * 1000;
        config.readTimeout = 60 * 1000;
        try {
            com.aliyun.dingtalkyida_2_0.Client client = new com.aliyun.dingtalkyida_2_0.Client(config);
          client._endpoint =  "your-org-private-yida-domain.com";
            return client;
        } catch (Exception e) {
            throw new RuntimeException(e);
        }
    }
```
