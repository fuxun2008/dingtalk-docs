Aturan pengiriman node menggunakan validasi formula untuk menentukan apakah pengguna dapat menjalankan suatu tindakan saat mengirimkan proses atau saat penyetuju menangani proses.

## Metode pemicu

<Note>
**Perbedaan antara eksekusi penyelesaian tugas dan eksekusi penyelesaian node**:

Jika sebuah node Persetujuan memiliki beberapa penyetuju, setiap penyetuju dihitung sebagai tugas terpisah, sedangkan node tetap satu.
</Note>

### Eksekusi penyelesaian tugas

Seperti terlihat pada gambar, aturan ini dipicu ketika tindakan aktual pada node manual adalah "Terima".

Dengan cara yang sama, "Tolak", "Simpan", dan "Kembalikan" juga dapat dikonfigurasi.

Pengaturan Premium untuk node manual

### Eksekusi penyelesaian node

Seperti terlihat pada gambar, aturan ini dipicu ketika tindakan aktual pada node manual adalah "Terima". Dengan cara yang sama, "Tolak" juga dapat dikonfigurasi.
