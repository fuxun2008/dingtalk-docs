## Izin inisiasi

Konfigurasikan izin inisiasi dan izin bidang untuk halaman inisiasi. Sesuaikan grup izin melalui Alihkan ke halaman Pengaturan formulir alur kerja.

  ![](https://gw.alicdn.com/imgextra/i1/O1CN01ZAIYgWxmk4C3tJhz_!!6000000007653-2-tps-1917-894.png)
</Frame>

## Izin bidang node

- Izin bidang untuk penyetuju dan penangan

Node penyetuju dan penangan mendukung tiga pengaturan izin: **Dapat Diedit**, **Hanya Baca**, dan **Tersembunyi**.

<Frame>
  ![](https://gw.alicdn.com/imgextra/i4/O1CN01fn56i43iDMC2BS5c_!!6000000005405-2-tps-1076-1184.png)
</Frame>

- Izin bidang untuk node CC: Node CC mendukung konfigurasi Izin Lihat bagi penerima CC, dengan dua opsi yang tersedia: Hanya Baca dan Tersembunyi.

<Frame>
  ![](https://gw.alicdn.com/imgextra/i1/O1CN01M29m19DZTmE2BxKA_!!6000000000523-2-tps-1080-1246.png)
</Frame>

## Pengaturan izin global

Atur izin bidang default dalam mode tampilan. Sesuaikan grup izin melalui Alihkan ke halaman Pengaturan formulir alur kerja.

<Frame>
  ![](https://gw.alicdn.com/imgextra/i4/O1CN01wNhc9zgBGrL3t467_!!6000000006765-2-tps-1915-888.png)

Konfigurasikan izin bidang secara global.
