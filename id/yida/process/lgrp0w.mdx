Untuk memenuhi kebutuhan alur kerja, YiDA menyediakan desainer alur kerja lanjutan. Desainer ini mendukung hampir seluruh fitur desainer standar sekaligus menyempurnakan sejumlah kemampuannya. Sebagai contoh, desainer ini menambahkan komponen percabangan dan agregasi, menyempurnakan fitur serta pengaturan komponen dengan memisahkan pengaturan dasar dan premium, memungkinkan Anda menyesuaikan aturan penyetuju dan kebijakan penyelesaian, serta mendukung peningkatan dari editor alur kerja standar ke editor alur kerja lanjutan.

<Note>
Setelah editor alur kerja standar ditingkatkan ke editor alur kerja lanjutan, Anda tidak dapat mengembalikannya ke editor alur kerja standar.
</Note>

## Desainer alur kerja

**Desainer terbagi menjadi 5 area fungsi:**

- Area ①: Area node
- Area ②: Area tindakan cepat
- Area ③: Area desain alur kerja
- Area ④: Area pengaturan atribut
- Area ⑤: Simpan dan Bantuan

### Area node

Area node menyediakan seluruh node fungsi yang didukung oleh desainer alur kerja lanjutan. Seret node ke area desain alur kerja sesuai kebutuhan.

| [**Node awal**](/id/yida/process/ek8q11) | Node awal memulai alur kerja lanjutan. Saat alur kerja dimulai, validasi formula atau tindakan asosiasi dapat terpicu. Aturan pengiriman node bertujuan menggunakan validasi formula untuk menentukan apakah pengguna dapat melakukan tindakan saat mengirimkan alur kerja atau saat penyetuju memprosesnya. |
|---|---|
| [**Node manusia**](/id/yida/process/ves9o4) | Memungkinkan Anda menyesuaikan aturan penyetuju sesuai kebutuhan. |
| [**Node otomatis**](/id/yida/process/ctns3l) | Node otomatis umumnya digunakan untuk melakukan callback melalui opsi layanan pihak ketiga. Layanan pihak ketiga harus didaftarkan terlebih dahulu sebelum dapat dipilih. |
| [**Node percabangan**](/id/yida/process/hhw27w) | Alur kerja lanjutan mendukung konfigurasi node percabangan. Saat alur kerja mencapai node percabangan, aturan yang dikonfigurasi pada node percabangan menentukan cabang mana yang akan diteruskan berikutnya, sehingga tercapai logika kondisional seperti "jika... maka...". |
| [**Node agregasi**](/id/yida/process/ee2mei) | Gunakan node agregasi ketika alur kerja memiliki beberapa cabang paralel yang harus selesai sebelum melanjutkan. Alur kerja hanya berlanjut setelah seluruh node pada garis masuk node agregasi selesai dieksekusi, sehingga menghasilkan efek menunggu. |
| [**Node CC**](/id/yida/process/ghkqiq) | Digunakan saat proses persetujuan telah dimulai dan pengguna terkait perlu melihat atau diberi tahu tentang formulir persetujuan, tetapi tidak diperlukan tindakan persetujuan. |
| [**Node akhir**](/id/yida/process/gkmvl4) | Node akhir menandai akhir dari seluruh alur kerja. Alur kerja yang dikonfigurasi dengan benar akan berjalan selangkah demi selangkah hingga mencapai node ini, yang menandakan bahwa alur kerja telah selesai. |

### Area tindakan cepat

Area tindakan cepat menyediakan pintasan umum untuk mendesain diagram alur kerja:

- Urungkan: Membatalkan penambahan atau penghapusan node dan garis pada halaman desain alur kerja saat ini.
- Potong: Memindahkan node atau garis yang dipilih ke papan klip. Gunakan pintasan tempel untuk menyalin node dan garis terkait dengan cepat.
- Salin: Menyalin garis dan node persetujuan.
- Perbesar: Memperbesar tampilan seluruh diagram alur kerja.
- Perkecil: Memperkecil tampilan seluruh diagram alur kerja.
- Kisi: Saat diaktifkan, titik-titik kisi muncul pada halaman desainer. Saat dinonaktifkan, halaman desainer menampilkan latar belakang abu-abu polos.
- Bawa ke depan: Saat beberapa node saling tumpang tindih, pindahkan node yang diperlukan ke depan.
- Kirim ke belakang: Saat beberapa node saling tumpang tindih, pindahkan node yang jarang digunakan ke belakang.

### Area desain alur kerja

Ini adalah area utama untuk mendesain diagram alur kerja. Seret node ke dalam area ini dengan bebas dan hubungkan dengan garis untuk membangun alur kerja.

### Area pengaturan atribut

Area atribut menampilkan pengaturan atribut yang didukung setiap jenis node. Di sini Anda dapat melakukan pengaturan yang dipersonalisasi dan fungsional untuk node tersebut.

### Simpan dan publikasikan alur kerja

Setelah node alur kerja dan aturan node dikonfigurasi, segera simpan dan publikasikan alur kerja. Jika tidak, data yang baru dikirimkan akan tetap menggunakan alur kerja lama.

## Atribut alur kerja

### Variabel alur kerja

Atribut dasar alur kerja menyediakan seluruh item formulir pada halaman yang sesuai dengan alur kerja untuk digunakan di desainer alur kerja. Saat Anda perlu menambahkan atribut tambahan, cukup tambahkan bidang pada desain formulir yang sesuai dengan alur kerja, dan variabel alur kerja akan dimuat secara otomatis seperti yang ditunjukkan di bawah:

### Konfigurasikan tanda tangan

YiDA mendukung fitur tanda tangan untuk node penyetuju dalam proses persetujuan alur kerja. Pengguna dapat mengatur tanda tangan mereka di aplikasi seluler agar ditampilkan selama persetujuan.

<Note>
Hasil tanda tangan elektronik tidak bersertifikat CA dan tidak memiliki kekuatan hukum.
</Note>

### Aturan penggabungan

Dengan mengonfigurasi aturan penggabungan, Anda dapat mengontrol tindakan penggabungan pada node tertentu. Alur kerja akan secara otomatis mengeksekusi atau melewati node yang memenuhi kondisi sesuai dengan pengaturan penggabungan.

Contohnya, jika Anda ingin sistem secara otomatis mengeksekusi node 2 saat node 1 dieksekusi, konfigurasikan aturan penggabungan untuk memilih tindakan yang akan dilewati dan tindakan default yang akan dieksekusi.

Catatan: Persetujuan bertingkat berarti saat sebuah node memiliki beberapa penyetuju, tugas akan diberikan kepada penyetuju tersebut satu per satu secara berurutan, dan tugas hanya diteruskan ke penyetuju berikutnya setelah penyetuju sebelumnya menyelesaikan tindakannya.
