## Layanan pihak ketiga

Saat mengonfigurasi tindakan eksekusi, Pilih layanan pihak ketiga yang telah berhasil didaftarkan, lalu tugaskan nilai kembaliannya ke variabel dalam proses.

<Note>
Layanan pihak ketiga harus didaftarkan terlebih dahulu. Untuk detailnya, lihat **Registrasi Layanan****.**
</Note>

## Pengaturan Groovy

Nilai dapat ditugaskan ke variabel dalam proses melalui Pengaturan Groovy. Cukup isi nama variabel proses dengan benar dan tuliskan nilai yang akan ditugaskan ke dalam skrip eksekusi.

<Note>
- Variabel harus didefinisikan dalam Atribut proses.
- Saat menugaskan string, tambahkan tanda kutip, misalnya "HelloWorld".
</Note>

Setelah ditugaskan, nilai ini dapat digunakan untuk evaluasi dalam aturan eksekusi online.

## Petunjuk konfigurasi tindakan eksekusi

Jika interface Callback merupakan interface HTTP, tulis interface tersebut sesuai persyaratan berikut:

- Metode HTTP harus POST.
- Parameter Permintaan ditempatkan di RequestBody.
- uuid adalah kata kunci sistem dan tidak dapat digunakan.
- Jika kunci Tanda tangan SHA256 digunakan saat registrasi layanan, tambahkan parameter callback __hmacSha256.
- md5 adalah metode Tanda tangan Default yang ditambahkan oleh callback layanan. Jika tidak ada kunci yang diatur saat registrasi layanan, sistem kami menggunakan kunci Default untuk penandatanganan. Jika kunci telah diatur, kunci yang dikonfigurasi digunakan untuk penandatanganan, dan parameter callback adalah: sign.

Lihat contoh interface callback sederhana berikut yang ditulis dalam Java:

```java
@RequestMapping(value = "/callback",method = RequestMethod.POST)
@ResponseBody
public List<String> callback(@RequestBody CallbackParam callbackParam) {
  // Format nilai kembalian: ["ID Karyawan 1","ID Karyawan 2"]; jika kembalian kosong, kembalikan null secara langsung
  List<String> result = new ArrayList<>();
  // lakukan sesuatu
  return result;
}
```
