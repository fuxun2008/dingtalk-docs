Aturan pengiriman node memungkinkan Anda menggunakan formula untuk memeriksa apakah pengguna dapat melakukan tindakan saat mengirim alur kerja atau saat penyetuju memprosesnya. Aturan ini juga dapat memicu formula asosiasi bisnis untuk memperbarui data di formulir lain.

## Konfigurasikan aturan pengiriman node

<Steps>
  <Step title="Langkah 1">
    Masuk ke [workbench YiDA](https://www.yidaapps.com/workPlatform). Pilih aplikasi target dan buka halaman **Page management**.
  </Step>
  <Step title="Langkah 2">
    Pilih formulir alur kerja, klik segitiga terbalik di sebelah Edit workflow form, lalu klik **Workflow design**.
  </Step>
</Steps>

| Item konfigurasi | Deskripsi |
|---|---|
| Nama aturan | Nama aturan pengiriman saat ini. Teks multibahasa didukung. |
| Tipe node | Aturan pengiriman dapat dikonfigurasi pada node berikut.<br />• **Node awal**: Node awal menjalankan aturan segera setelah data dikirim. Anda dapat menggunakan fungsi formula untuk mengonfigurasi **tindakan asosiasi** dan **aturan validasi**.<br />• **Node akhir**: Node akhir adalah titik akhir alur kerja. Sebuah alur kerja dapat berakhir melalui tindakan node yang berbeda, sehingga saat memilih node akhir, Anda juga harus memilih tindakan node dan mengonfigurasi aturan untuknya. Tindakan node meliputi **Terima**, **Tolak**, dan **Urungkan/Akhiri**.<br />• **Node persetujuan** dalam alur kerja: Node persetujuan adalah node penyetuju atau penangan yang didefinisikan di pengaturan alur kerja, dan Anda dapat memilihnya secara langsung. Setelah memilih node, pilih metode pemicu dan tindakan node untuk node tersebut.<br />Dua metode pemicu berikut didukung.<br /> |
| Tipe aturan | Dua tipe aturan berikut didukung.<br />• **Aturan validasi**: Aturan validasi memeriksa kondisi saat tindakan node dikirim dan dapat memblokir tindakan saat ini. Jika kondisi tidak terpenuhi, pengiriman diblokir.<br />• **Tindakan asosiasi**: Tindakan asosiasi tidak memengaruhi tindakan persetujuan dan tidak melakukan pemeriksaan. Tindakan asosiasi menjalankan formula asosiasi bisnis lain bersamaan dengan tindakan node yang dikonfigurasi, misalnya saat Anda melakukan **Terima**, **Tolak**, **Laporkan Error**, atau **Kembalikan**.<br />**Catatan**: Kami merekomendasikan konfigurasi aturan asosiasi bisnis melalui integrasi & otomatisasi, yang menyediakan tampilan kanvas agar konfigurasi lebih mudah. Untuk informasi selengkapnya, lihat [Integrasi & otomatisasi](/id/yida/integration/gqmveiswrxkgxu9s). |
