Untuk memberi tahu pengguna selain penyetuju ketika alur kerja mencapai suatu node, tambahkan notifikasi pesan. Anda dapat menyertakan tautan alur kerja di dalam notifikasi. Namun, pengguna yang bukan admin alur kerja dan tidak memiliki Izin Lihat atas instans tersebut tidak dapat membuka alur kerja.

## Menyiapkan templat pesan

Sebelum menggunakan node pesan, buat templat notifikasi pesan terlebih dahulu. Pesan teks biasa dan DingTalk Tugas keduanya didukung. Untuk detailnya, lihat [Templat notifikasi pesan](/id/yida/platform-admin/fkfhud).

## Pengaturan pesan node

**Jalur**: Node persetujuan > Premium > Pesan teks biasa

| **Tipe pesan** | **Fungsi** |
|---|---|
| **Aturan notifikasi saat tugas dibuat** | Dipicu ketika tugas persetujuan dibuat. Satu node persetujuan dapat memiliki beberapa penyetuju, dengan satu tugas persetujuan per penyetuju, dan aturan ini terpicu sekali untuk setiap tugas. |
| **Aturan notifikasi saat memasuki node** | Dipicu ketika node persetujuan dimasuki. Hanya terpicu sekali per node. |
| **Aturan notifikasi saat keluar dari node** | Dipicu ketika node persetujuan ditinggalkan. Hanya terpicu sekali per node. |
| **Aturan notifikasi saat tugas ditutup** | Dipicu ketika tugas persetujuan selesai atau dibatalkan. |
| **Aturan notifikasi berdasarkan Bidang tanggal di alur kerja** | Dipicu berdasarkan tanggal yang dipilih pada komponen Tanggal formulir. |
