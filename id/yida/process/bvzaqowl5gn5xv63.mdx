## 1. Pendahuluan

### 1.1 Ikhtisar fitur

Dengan pemantauan alur kerja terpadu, pengguna dapat mengumpulkan semua instans alur kerja yang diotorisasi pada satu halaman, menyederhanakan operasi dan meningkatkan efisiensi. Fitur ini menyediakan pemantauan terpadu untuk seluruh alur kerja, memastikan status eksekusi setiap alur kerja dapat dilacak secara real-time.

## 2. Langkah-langkah

### 2.1 Akses fitur

### 2.2 Izin peran

**Admin platform**: Dapat melihat halaman agregasi instans alur kerja untuk **Semua aplikasi** dan untuk aplikasi individual.

**Super Admin Aplikasi**: Hanya dapat melihat aplikasi yang mereka kelola.

<Warning>
Halaman pemantauan alur kerja hanya tersedia untuk peran **Admin platform** dan **Super Admin Aplikasi**.
</Warning>

### 2.3 Pemantauan alur kerja

#### 2.3.1 Lihat pemantauan alur kerja

1) Klik daftar aplikasi di sebelah kiri, lalu klik instans alur kerja tertentu untuk melihat detailnya.

2) Field yang ditampilkan untuk instans alur kerja: ID instans alur kerja, judul instans alur kerja, formulir terkait, aplikasi terkait, inisiator, waktu inisiasi, waktu modifikasi, waktu penyelesaian, status instans, hasil persetujuan, Langkah saat ini, dan operator Langkah saat ini.

<Frame>
  ![](https://gw.alicdn.com/imgextra/i4/O1CN01pRK2tfyJdnG6nSL6_!!6000000005471-2-tps-3348-1680.png)
</Frame>

#### 2.3.2 Filter dan cari

**1) Filter lanjutan**: Mendukung penyaringan multi-dimensi, meliputi judul instans alur kerja, ID, aplikasi terkait, formulir, operator Langkah saat ini, inisiator, dan status.

**3) Halaman hasil**: Secara default, hasil dari hingga 20 aplikasi akan ditampilkan. Jika hasil pencarian tidak sesuai harapan, tambahkan kondisi yang lebih spesifik di Filter lanjutan untuk mempersempit pencarian.
