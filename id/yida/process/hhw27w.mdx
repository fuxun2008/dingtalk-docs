Node cabang membagi desain alur kerja menjadi beberapa cabang. Selama kondisi aturan terpenuhi, tindakan eksekusi dari semua node cabang yang cocok akan berjalan hingga selesai. Dengan node cabang, Anda dapat mengonfigurasi kondisi cabang yang lebih kompleks dengan menggabungkan beberapa kondisi, mengatasi tantangan alur kerja yang melibatkan banyak cabang dan node. Ini memberikan Proses persetujuan Anda aturan pengajuan yang kaya dan mendukung lebih banyak skenario pengguna.

## Konfigurasikan node cabang

1. Buka halaman desain alur kerja Premium dan seret node cabang ke kanvas.
2. Klik node cabang, lalu klik tombol **Pengaturan** di sebelah **Aturan cabang** di panel Atribut di sebelah kanan.
3. Konfigurasikan aturan cabang.

4. Klik **Simpan** untuk menyelesaikan konfigurasi.

## Konfigurasikan garis penghubung node cabang

Setiap garis keluar dari node cabang harus dikaitkan dengan aturan cabang. Hanya ketika aturan terpenuhi, node setelah garis tersebut akan diaktifkan.

Jika aturan dari beberapa garis keluar terpenuhi secara bersamaan, semua node setelah garis yang cocok tersebut akan diaktifkan. Jika sebuah garis keluar tidak memiliki aturan yang dikonfigurasi, garis tersebut diaktifkan secara default.

Jika tidak ada aturan garis keluar yang terpenuhi, tidak ada satu pun node setelah node cabang yang akan diaktifkan. Jika tidak ada node lain yang sedang berjalan pada saat itu, seluruh alur kerja akan selesai.
