Alur kerja YiDA memungkinkan developer low-code menambahkan node developer **Skrip** saat mendesain alur kerja atau alur Integrasi & Otomatisasi. Node skrip menggunakan JavaScript untuk menyisipkan variabel statis secara manual ke dalam logika bisnis atau untuk memformat data yang dikembalikan oleh node upstream, sehingga memberikan kendali yang fleksibel atas konfigurasi alur bisnis.

## Kasus penggunaan

Pada tahap desain, tambahkan node skrip dan tulis kode JavaScript untuk membaca data input, memproses data antara, dan pada akhirnya menginjeksi data melalui object output bawaan. Hal ini memungkinkan pemrosesan data berbasis skrip dalam orkestrasi alur bisnis.

## Akses node skrip

- Opsi 1: Edit formulir alur kerja > buka halaman desain alur kerja > pilih node Developer > Node skrip.
- Opsi 2: Edit aplikasi > Integrasi & Otomatisasi > pilih alur Otomatisasi target, buka konfigurasi desainnya, lalu tambahkan node skrip.

## Catatan

- Node skrip baru menggantikan node Groovy sebelumnya, sehingga skrip dapat digunakan oleh khalayak developer yang lebih luas.
- Node skrip hanya mendukung sintaksis ES5. Sintaksis ES6 dan versi selanjutnya tidak didukung.
- Penanganan node pembaruan batch belum didukung.
- Hindari pemrosesan data yang membutuhkan memori dalam jumlah besar. Melebihi 10 MB (sementara; YiDA dapat menyesuaikan batas ini) akan memicu error kelebihan memori. Penggunaan CPU yang melebihi 5 detik (misalnya, infinite loop) akan memicu mekanisme perlindungan otomatis dan menimbulkan error.
- Permintaan jaringan seperti XHR dan fetch tidak didukung. Object dan fungsi tingkat atas seperti window, console, dan print tidak didukung.
- Mendefinisikan fungsi di dalam blok kode didukung.
- Jangan menambahkan pernyataan return di luar fungsi.
