Node Kartu mengirimkan Kartu interaktif ringan yang mendukung interaksi real-time dan kolaborasi multi-pengguna saat alur kerja mencapai Langkah ini. Kartu tersedia dalam dua tipe: Kartu interaktif dan Kartu Grup yang dipasang. Node Kartu biasanya muncul berpasangan, yaitu node Kirim Kartu dan node Perbarui Kartu. Artikel ini menjelaskan cara menambahkan node Kartu ke alur kerja.

## Apa itu node Kartu

Node Kartu adalah salah satu ciri khas Aplikasi dengan Cool App yang diaktifkan. Kartu interaktif YiDA adalah Kartu ringan, real-time, multi-pengguna, dan berbasis data. Kartu ini memungkinkan sistem mengirim Kartu interaktif secara otomatis selama alur kerja berjalan. Ketika pengguna mengklik tombol pada Kartu, Kartu dapat menjalankan berbagai pintasan bisnis berdasarkan tindakan yang dikonfigurasikan sebelumnya. Kartu ini cocok untuk skenario kolaborasi umum seperti tiket alert dan manajemen risiko proyek.

## Menggunakan node Kartu

<Note>
Sebelum menggunakan node Kartu dalam alur kerja untuk mengirim Cool Card, Anda harus terlebih dahulu **memublikasikan Aplikasi ke pusat Cool App kustom** dan mengaktifkan Cool App di setidaknya satu Grup. Untuk detailnya, lihat [Cool App](/id/yida/cool-app/ub4y1n).
</Note>

Artikel ini menggunakan Templat formulir alur kerja **Permintaan Perbaikan** sebagai contoh untuk menjelaskan cara mengirim Cool Card ke sebuah Grup.

  ![](https://gw.alicdn.com/imgextra/i4/O1CN01vtgKqtw3oEH6hPna_!!6000000000556-2-tps-3300-1994.png)

1. Masuk ke workbench YiDA. Pilih Aplikasi target dan buka Halaman Manajemen Halaman.
2. Klik ikon **+** di sudut kiri atas, pilih Buat formulir alur kerja > Buat dari Templat > Templat Permintaan Perbaikan, lalu klik Gunakan.
3. Pada Halaman desain formulir, klik desain alur kerja di bagian atas.
4. Arahkan kursor ke garis penghubung antar Langkah alur kerja. Tombol **+** akan muncul. Klik **+** dan pilih node Kartu > node Kirim Kartu.
