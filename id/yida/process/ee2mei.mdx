Jika alur kerja berisi beberapa cabang dan Anda ingin proses berlanjut hanya setelah semua cabang selesai, gunakan node penggabungan. Alur kerja akan berlanjut hanya setelah setiap node pada semua jalur masuk node penggabungan selesai, sehingga menciptakan efek tunggu.

**Contoh**: Saat proses review, alur berpindah ke review akhir hanya setelah review awal dan review sekunder keduanya selesai.

## Konfigurasikan node penggabungan

1. Buka halaman desain alur kerja Premium dan seret node penggabungan ke kanvas.
2. Klik node penggabungan, lalu hubungkan cabang-cabang yang ingin digabungkan ke node tersebut.

<Note>
Node setelah node penggabungan hanya diaktifkan setelah semua cabang sebelum node penggabungan selesai.
</Note>

## Contoh penggunaan

Lihat diagram alur kerja berikut:

- Alur kerja dimulai dan node review awal diaktifkan.
- Setelah review awal selesai, node Persetujuan Review Sekunder 1 dan Review Sekunder 2 keduanya diaktifkan, dan tugas otomatis dipicu.
- Setelah Review Sekunder 1 dan Review Sekunder 2 keduanya selesai, node review akhir diaktifkan.
- Setelah review akhir selesai, alur kerja berakhir.
