Node Akhir menandai titik akhir dari keseluruhan alur kerja. Alur kerja yang dikonfigurasi dengan benar berjalan langkah demi langkah hingga akhirnya mencapai node ini, yang menandakan penyelesaian. Aksi asosiasi dapat dikonfigurasi pada Node Akhir untuk dijalankan ketika hasil alur kerja adalah Terima, Tolak, dibatalkan, atau dihentikan.

## Konfigurasikan Node Akhir

1. Buka halaman desain alur kerja lanjutan.
2. Klik Node Akhir, lalu klik Premium pada panel Atribut di sebelah kanan.
3. Klik tombol Pengaturan di samping Aturan pengiriman node.

## Dokumen terkait

- Fungsi Formula
- Formula asosiasi bisnis
