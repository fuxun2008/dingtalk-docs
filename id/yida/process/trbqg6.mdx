Konfigurasi dan deskripsi penyetuju, operator, penerima CC, serta Langkah cabang di formulir alur kerja ditampilkan pada tabel berikut:

| **Tipe Langkah** | **Deskripsi** |
|---|---|
| **Langkah Mulai** | Langkah Mulai menandai awal sebuah alur kerja. Setiap Proses persetujuan mencakup satu Langkah Mulai default yang tidak dapat dihapus. Pada Langkah ini, konfigurasikan Izin bidang Formulir yang tersedia bagi pemrakarsa alur kerja. |
| **Langkah manusia** | Langkah manusia mencakup Langkah penyetuju, Langkah operator, dan Langkah penerima CC.<br />• [**Langkah penyetuju**](/id/yida/process/rq8i94): penyetuju bertanggung jawab memproses tugas Persetujuan pada Langkah ini dan wajib membuat keputusan seperti Terima atau Tolak. Satu alur kerja harus memuat minimal satu Langkah penyetuju.<br />• [**Langkah operator**](/id/yida/process/bl1oq2): Operator tidak membuat keputusan. Operator hanya perlu menyelesaikan pekerjaan yang ditugaskan, lalu mengembalikan alur kerja kepada penyetuju untuk Lanjutkan pemrosesan. Pekerjaan operator tidak terkait dengan Persetujuan.<br />• [**Langkah penerima CC**](/id/yida/process/cntvp8): Digunakan untuk Kirim Notifikasi pesan kepada penerima CC setelah penyetuju menyelesaikan Persetujuan. Penerima CC tidak perlu menyetujui atau menjalankan tugas. |
| **Langkah cabang** | Langkah cabang mencakup Langkah cabang bersyarat, Langkah cabang paralel, dan Langkah sub-alur kerja.<br />• [**Langkah cabang bersyarat**](/id/yida/process/yv8dnv): Langkah cabang bersyarat membagi desain alur kerja menjadi beberapa cabang. Selama kondisi aturan terpenuhi, tindakan eksekusi Langkah cabang terkait dijalankan secara Penuh.<br />• [**Langkah cabang paralel**](/id/yida/process/row1axsz4s0ix2vl): Langkah cabang paralel menjalankan dua atau lebih tugas cabang secara paralel. Berbeda dengan cabang bersyarat, saat Data dikirim, semua jalur tugas di bawah cabang logis dipicu selama aturan kondisi terpenuhi.<br />• [**Langkah sub-alur kerja**](/id/yida/process/xgy1wgc95g65fusy): Alur kerja YiDA memungkinkan Anda Tambah Langkah sub-alur kerja saat mendesain alur kerja saat ini. Langkah sub-alur kerja adalah Langkah khusus yang mendukung berbagai mode pemicu parameter untuk memicu formulir alur kerja Persetujuan lain yang sudah ada, sehingga alur kerja Persetujuan dapat dipisahkan dan diorganisasikan. |
| [**Langkah data**](/id/yida/integration/mmwrzb5agf5i9lvb) | Langkah data pada formulir alur kerja sama dengan Langkah data pada integrasi & otomatisasi. Untuk detailnya, lihat [Langkah data](/id/yida/integration/nl4abrm791inlvm2). |
| [**Langkah skrip**](/id/yida/process/ywnn9itpk2e52332) | Alur kerja YiDA memungkinkan Anda Tambah Langkah pengembang Script saat mendesain alur kerja saat ini atau integrasi & otomatisasi. |
| Langkah pesan | Langkah pesan mencakup Langkah Notifikasi pesan dan Langkah Notifikasi Email.<br />• [Notifikasi pesan](/id/yida/process/kvm0wu): Digunakan untuk Kirim Notifikasi Kerja DingTalk atau notifikasi Grup kepada pengguna tertentu melalui Tipe notifikasi yang dikonfigurasi ketika alur kerja mencapai Langkah tertentu.<br />• [Notifikasi Email](/id/yida/process/obvnvx): Digunakan untuk Kirim Notifikasi Email kepada pengguna tertentu melalui Templat Email yang dikonfigurasi ketika alur kerja mencapai Langkah tertentu. |
