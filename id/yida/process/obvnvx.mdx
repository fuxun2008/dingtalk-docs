Node Notifikasi Email mengirim Notifikasi Email kepada pengguna tertentu melalui Templat yang telah dikonfigurasi sebelumnya saat Proses persetujuan mencapai Langkah tertentu. Ikuti artikel ini untuk mengonfigurasi node Notifikasi Email.

## Prasyarat

Sebelum menggunakan fitur Notifikasi Email dalam Proses persetujuan, tambahkan akun Email terlebih dahulu. Untuk detailnya, lihat [Manajemen Email](/id/yida/platform-admin/dowbnvn7aasg1z07).

## Tambah node Notifikasi Email

<Steps>
  <Step title="Langkah 1">
    Masuk ke [workbench YiDA](https://www.yidaapps.com/workPlatform), pilih Aplikasi target, lalu buka halaman **Manajemen Halaman**.
  </Step>
  <Step title="Langkah 2">
    Pilih formulir alur kerja, klik panah bawah di samping Edit formulir alur kerja, lalu klik **desain alur kerja**.
  </Step>
</Steps>

<Frame>
  ![](https://gw.alicdn.com/imgextra/i2/O1CN015JUXPXX68NE6M0sg_!!6000000005875-2-tps-3130-1492.png)
</Frame>

3. Arahkan kursor ke garis penghubung antar-Langkah. Saat tombol **+** muncul, klik **+**, lalu pilih node Pesan > Kirim Email.

<Frame>
  ![](https://gw.alicdn.com/imgextra/i4/O1CN01J4tD1GaTYyL4r79I_!!6000000001145-2-tps-2392-1820.png)
</Frame>

## Konfigurasikan node Notifikasi Email

Ikuti langkah-langkah berikut untuk mengonfigurasi node Notifikasi Email.

<Steps>
  <Step title="Select the Send Mail node, and set the Mail address in the node configuration panel on the right">
    <Note>
    Jika Anda belum menambahkan akun Email, klik **Manajemen akun** di sebelah kanan untuk menambahkannya. Untuk detailnya, lihat [Manajemen Email](/id/yida/platform-admin/dowbnvn7aasg1z07).
    </Note>

    <Frame>
      ![](https://gw.alicdn.com/imgextra/i2/O1CN01pol54RctWaI5IIw4_!!6000000004630-2-tps-2608-1768.png)

    <Note>
    Bidang Kepada mendukung Bidang dari Formulir.

  </Step>
  <Step title="Set the Mail Content. Two modes are supported: Custom and message Template">
    <Note>
    Bidang dari Formulir dapat disisipkan untuk penggabungan.
    </Note>
  </Step>
  <Step title="After configuration, click Save.">
  </Step>
</Steps>
