Proses persetujuan YiDA mendukung pratinjau proses saat pengiriman. Fitur ini memungkinkan inisiator proses meninjau seluruh Proses persetujuan sebelum pengiriman. Cukup dengan kotak centang sederhana untuk mengaktifkan Push otomatis notifikasi persetujuan ke obrolan pribadi DingTalk penyetuju, secara efisien mengatasi potensi hambatan pada tahap inisiasi proses dan secara menyeluruh meningkatkan kelancaran Proses persetujuan serta pengalaman pengguna.

Pencetakan proses: Templat cetak mendukung konfigurasi untuk mencetak hanya rekaman persetujuan terbaru.

## Pratinjau persetujuan

Saat proses dimulai, sistem otomatis menampilkan **pratinjau proses** sebagai pop-up, menampilkan Pengguna yang terlibat dalam node inisiator, node penyetuju, dan node pelaksana dari Proses persetujuan.

<Note>
- Node penerima CC tidak ditampilkan di jendela pratinjau proses ini.
- Kartu pesan obrolan saat ini hanya dapat dikirim ke penyetuju yang paling dekat dengan node Pengirim dalam proses saat ini.
</Note>

## Notifikasi pesan

Pilih **Kirim ke penyetuju saat ini melalui obrolan** dan klik **Konfirmasi** untuk melakukan Push Kartu persetujuan yang sesuai ke jendela obrolan. Status proses di dalam Kartu ditampilkan sebagai "stempel".

| Sedang berlangsung | Ditolak | Belum selesai |
|---|---|---|

Klik **Lihat Detail** di dalam Kartu untuk dialihkan ke halaman formulir alur kerja untuk tindakan lebih lanjut.

<Note>
Saat ini, pratinjau data pengiriman formulir alur kerja, Progres persetujuan pada halaman Rekaman sumber, dan Proses persetujuan dalam pengujian proses semuanya mendukung tampilan alur proses lengkap.

Pengguna dapat melihat alur dan struktur seluruh proses, menampilkan setiap cabang proses dan hubungan antar node, serta memahami hubungan antar node melalui diagram topologi lengkap.

Lihat [Proses mendukung diagram alur lengkap](https://docs.aliwork.com/docs/yida_support/_2/_13/uzcgrfgcozbfzchi).
</Note>
