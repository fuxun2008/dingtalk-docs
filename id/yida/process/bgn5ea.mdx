Node inisiasi adalah titik awal dari sebuah alur kerja. Setiap Proses persetujuan memiliki node inisiasi secara Default. Node ini tidak dapat dihapus. Anda dapat mengonfigurasi Izin bidang formulir dari pemrakarsa proses.

## Ubah izin Bidang pemrakarsa

Ikuti langkah-langkah di bawah ini untuk mengubah Izin bidang formulir dari node inisiasi.

<Steps>
  <Step title="Langkah 1">
    Masuk ke [workbench YiDA](https://www.yidaapps.com/workPlatform). Pilih Aplikasi target dan buka Halaman **Manajemen Halaman** Aplikasi tersebut.
  </Step>
  <Step title="Langkah 2">
    Pilih formulir alur kerja, klik segitiga terbalik di sebelah Edit formulir alur kerja, lalu klik **desain alur kerja**.
  </Step>
</Steps>

  <Step title="Klik node Inisiasi, lalu Pilih Izin bidang">
  </Step>
  <Step title="Konfigurasikan izin untuk setiap komponen formulir. Tiga mode izin didukung: dapat diedit, Hanya Baca, dan tersembunyi">
  </Step>

Sebagai Contoh, untuk membuat bidang pasca-perbaikan dalam formulir tidak terlihat oleh pemrakarsa, atur izin Komponen yang sesuai menjadi tersembunyi.

<Frame>
  ![](https://gw.alicdn.com/imgextra/i4/O1CN01u00bIqImVLK5hz0e_!!6000000005138-2-tps-2812-1496.png)

5. Setelah menyelesaikan konfigurasi, klik **Simpan**.

Setelah Izin diatur, pemrakarsa proses tidak lagi dapat melihat Konten pasca-perbaikan saat mengirimkan formulir.

![](https://gw.alicdn.com/imgextra/i2/O1CN01ePDnAJV59XK4Bp9w_!!6000000002312-2-tps-2064-1548.png)

![](https://gw.alicdn.com/imgextra/i2/O1CN01GJhgj8KGeuC4eWYo_!!6000000000478-2-tps-2292-1338.png)

<Note>
Untuk mengubah grup izin Proses persetujuan, buka **Pengaturan Halaman** > **Pengaturan Izin** pada formulir. Untuk detailnya, lihat [Pengaturan Izin](/id/yida/process/lagbfd).
</Note>
