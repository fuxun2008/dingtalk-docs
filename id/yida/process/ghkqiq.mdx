Penerima CC memiliki Izin untuk melihat Formulir persetujuan pada node mereka, dan Anda juga dapat mengatur Konten Formulir yang dapat dilihat oleh node CC, sehingga memungkinkan kontrol Izin yang sederhana.

<Note>
Node CC tidak ditampilkan dalam rantai alur Formulir persetujuan.
</Note>

**Kasus penggunaan untuk node CC**: Setelah Proses persetujuan dimulai, Pengguna terkait perlu melihat/mengetahui Formulir persetujuan, tetapi tidak memerlukan Persetujuan.
