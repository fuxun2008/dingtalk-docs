## Prasyarat

Sebelum menggunakan skrip Groovy, pahami dasar-dasar Groovy terlebih dahulu. Untuk detailnya, lihat [tutorial Groovy W3C](https://www.w3cschool.cn/groovy/groovy_overview.html) dan [pengenalan Apache Groovy](http://www.groovy-lang.org/).

Gunakan **Permintaan Groovy** untuk penyetuju pada node Persetujuan keuangan.

`textField_kov80fx9` adalah identifikator unik dari Kotak Teks satu baris pada formulir.

**Catatan**: Saat mengedit skrip Permintaan Groovy, gunakan metode `toInteger()` karena variabel internal alur kerja berupa string.

Metode `toInteger()` Wajib digunakan secara Default. Gunakan format berikut sebagai referensi:

<Frame>
  ![](https://gw.alicdn.com/imgextra/i1/O1CN01wU0vfcPzD3F2iYc5_!!6000000005299-2-tps-1339-822.png)
</Frame>

Salin dan gunakan kode berikut secara langsung:

```javascript
if(uniqueIdOfSingleLineTextBox.toInteger()<100  {
         return['approverUserId']
    }  else  {
       return['approverUserId']
    }
```

Arti kode ini: ketika angka pada Kotak Teks satu baris kurang dari 100, arahkan Permintaan ke satu penyetuju; jika tidak, arahkan ke penyetuju lain.

Anda dapat mengembalikan beberapa penyetuju sekaligus.
