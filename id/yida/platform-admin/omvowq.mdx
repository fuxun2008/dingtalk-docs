Manajemen izin platform Yida hanya tersedia bagi Super Admin dan Sub Admin organisasi, dan terutama digunakan untuk mengelola Sub Admin platform serta App Admin.

## Kelola izin Kontak

<Steps>
  <Step title="Langkah 1">
    Masuk ke [workbench Yida](https://www.yidaapps.com/workPlatform) sebagai Admin.
  </Step>
  <Step title="Langkah 2">
    Klik tombol **manajemen platform** di pojok kanan atas untuk masuk ke halaman manajemen platform.
  </Step>
</Steps>

3. Pada menu sebelah kiri, klik Manajemen Izin Platform, lalu tentukan apakah akan mengaktifkan kedua izin berikut.

<Note>
Cakupan visibilitas kontak untuk Pengguna Organisasi di platform Yida secara default disinkronkan dari Cakupan visibilitas kontak DingTalk. Untuk menyesuaikan cakupan visibilitas, Anda harus masuk ke konsol admin DingTalk untuk melakukan perubahan. Untuk detailnya, lihat [Cara mengonfigurasi izin manajemen Kontak](https://alidocs.dingtalk.com/i/p/Y7kmbokZp3pgGLq2/docs/2X3LRMZdxkAJpdaDzrykJGgrBYeOq5Ew).
</Note>

## Kelola App Admin

Ikuti langkah-langkah berikut untuk mengelola App Admin.

<Steps>
  <Step title="Buka halaman Manajemen Izin Platform lalu klik App Admin">
    
  </Step>
  <Step title="Klik Tambah Pengguna, pilih Pengguna yang sesuai di Organisasi Anda, lalu klik Konfirmasi untuk menambahkan App Admin">
    
  </Step>
</Steps>

App Admin yang berhasil ditambahkan akan otomatis muncul di Daftar App Admin.

Untuk mencabut izin App Admin dari seorang Pengguna, cukup klik tombol **Hapus Pengguna** di samping Pengguna tersebut.

<Note>
Jika Anda ingin memberikan izin App Admin kepada Pengguna di Organisasi yang sudah memiliki akses Yida, sehingga mendorong partisipasi Penuh dalam pengembangan Aplikasi Yida, Anda juga dapat mengaktifkan Otorisasi otomatis pada halaman tersebut. Setelah Otorisasi otomatis Aktif, seluruh Pengguna Organisasi yang memiliki akses Yida akan diberikan izin App Admin.

</Note>

## Kelola Admin platform

Ikuti langkah-langkah berikut untuk mengelola Admin platform.

1. Buka halaman Manajemen Izin Platform lalu klik Admin Platform.
2. Klik Tambah Pengguna pada halaman, pilih Pengguna yang sesuai, lalu klik Konfirmasi untuk menyelesaikan pengaturan Admin platform.

<Note>
Admin Organisasi DingTalk secara otomatis disinkronkan sebagai Admin platform Yida dan memiliki izin untuk mengelola platform Yida. Untuk mengubah konfigurasi ini, buka [konsol admin DingTalk](http://oa.dingtalk.io) untuk mencabut izin terkait Yida mereka.
</Note>

## FAQ

**T: Mengapa Pengguna baru hanya melihat satu Admin saat mengajukan izin Yida, tetapi menemukan bahwa Organisasi sebenarnya memiliki beberapa Admin di pusat izin?**

J: Untuk menghindari mengganggu eksekutif Organisasi, Admin platform ditampilkan lebih dahulu saat memilih Admin. Admin Organisasi hanya ditampilkan jika tidak ada Admin platform.

**T: Mengapa saya tidak memiliki izin Yida meskipun saya adalah Super Admin/Sub Admin Kontak DingTalk?**

J: Periksa apakah Admin platform Yida sudah diatur di dalam Aplikasi Yida.

- Jika Admin platform Yida sudah diatur, izin Admin platform Yida yang diutamakan.
- Jika belum ada Admin platform Yida yang diatur, Yida secara otomatis mewarisi Super Admin dan Sub Admin dari Kontak Organisasi DingTalk.
