| **Fitur** | **Paket Luang** | **Edisi Basic** | **Edisi Professional** | **Edisi Dedicated** |
|---|---|---|---|---|
| Kuota panggilan FaaS Connector | 100 panggilan | 1.000 panggilan | 1.000 panggilan | 5.000 panggilan |

<Note>
YiDA menyediakan kuota panggilan gratis untuk setiap organisasi YiDA. Setelah kuota habis, beli tambahan di halaman [Manajemen platform YiDA](/id/yida/platform-admin/omvowq). Untuk rincian harga, lihat Paket layanan bernilai tambah.
</Note>

YiDA FaaS Connector ditenagai oleh Alibaba Cloud Function Compute (FC). Developer cukup fokus menulis kode logika bisnis tanpa perlu memikirkan penerapan server, operasional, penskalaan, atau perencanaan kapasitas. Hal ini memberikan **kemampuan cloud development** yang siap pakai bagi developer.

Developer dapat mengedit kode di **WebIDE** dan menyesuaikan Konektor YiDA dengan kebutuhan bisnis melalui **kustomisasi yang fleksibel**.

## Langkah 1: Buat konektor

<Steps>
  <Step title="Langkah 1">
    Masuk ke [YiDA workbench](https://www.yidaapps.com/workPlatform) sebagai Admin.
  </Step>
  <Step title="Langkah 2">
    Klik tombol **Manajemen platform** di pojok kanan atas untuk masuk ke halaman manajemen platform.
  </Step>
  <Step title="Langkah 3">
    Klik **Connector Factory** di menu navigasi kiri, lalu klik **Buat konektor** dan pilih FaaS Connector.
  </Step>
</Steps>

<Steps>
  <Step title="Atur nama konektor, ikon konektor, dan bahasa pengembangan, lalu klik Berikutnya">
  </Step>
  <Step title="Pada halaman Jalankan tindakan, konfigurasikan informasi dasar, permintaan API, dan respons API untuk tindakan tersebut, lalu klik Simpan">
    <Note>
    Permintaan API dan respons API mendukung penguraian JSON. Masukkan struktur data Body yang sesuai, lalu klik tombol Parse Body untuk menguraikannya.
    </Note>
  </Step>
</Steps>
