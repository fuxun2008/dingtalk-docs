Jika konektor resmi DingTalk belum memenuhi kebutuhan Anda dan Anda perlu segera mengintegrasikan aplikasi DingTalk, sistem internal, atau sistem pihak ketiga, buat konektor kustom melalui Yida Connector Factory.

## Langkah 1: Buat konektor

<Steps>
  <Step title="Langkah 1">
    Masuk ke [Yida workbench](https://www.yidaapps.com/workPlatform) sebagai Admin.
  </Step>
  <Step title="Langkah 2">
    Klik tombol **Manajemen platform** di sudut kanan atas untuk membuka halaman manajemen platform.
  </Step>
  <Step title="Langkah 3">
    Klik **Connector Factory** pada menu kiri, klik **Buat konektor**, lalu pilih Konektor HTTP.
  </Step>
</Steps>

## Langkah 2: Buat tindakan

Pada halaman tindakan, klik **Buat tindakan**, lalu konfigurasikan pengaturan berdasarkan informasi berikut.

| **Nama** | **Deskripsi** |
|---|---|
| Informasi dasar | Konfigurasikan informasi dasar untuk tindakan saat ini.<br />• **Pengenal unik**: Digunakan untuk membedakan antar tindakan.<br />• Nama tindakan: Nama dari tindakan.<br />• Deskripsi tindakan: Deskripsi dari tindakan. |
| Permintaan API | Konfigurasikan endpoint API yang dipanggil tindakan saat ini ketika dipicu.<br />• **URL permintaan**: Tautan permintaan API. Domain permintaan diisi otomatis dari domain konektor.<br />• **Metode HTTP**: Mendukung GET, POST, DELETE, PUT, HEAD, OPTIONS, PATCH, dan metode lainnya.<br />• **Query**: Parameter permintaan, biasanya ditambahkan setelah tanda tanya `?` pada URL. Klik tanda plus untuk menambahkannya.<br />• **Body**: Untuk permintaan POST dan metode serupa, bidang Body juga dapat disertakan. Mendukung parsing menggunakan JSON.<br />• **Headers**: Anda dapat menyesuaikan header permintaan tambahan di sini. Saat ini hanya konfigurasi statis yang didukung.<br />• **Path**: Variabel pada URL yang diapit kurung kurawal, seperti `{pathParam}`, dengan `pathParam` sebagai nama variabel.<br />**Catatan**: Parameter permintaan mendukung bidang sistem untuk ID pengguna yang sedang masuk dan ID organisasi. |
| Respons API | Konfigurasikan respons yang diharapkan setelah panggilan API berhasil. Mendukung parsing JSON.<br />**Catatan**: Jika API mengembalikan objek non-JSON, hasilnya tidak dapat langsung digunakan di integrasi & otomatisasi. Anda perlu mem-parsing-nya sendiri pada node skrip. |

## Langkah 3: Konfigurasikan autentikasi

Setiap konektor kustom harus memiliki skema autentikasi permintaan yang sesuai, termasuk untuk **Tanpa autentikasi**.

1. Buat akun

Pada konektor yang telah Terkonfigurasi, klik Uji untuk memilih akun autentikasi. Anda juga dapat menambahkan akun autentikasi baru pada langkah ini.

2. Masukkan nama tampilan akun, App Key, App Secret, dan informasi lainnya, lalu klik Konfirmasi.
