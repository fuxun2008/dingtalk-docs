Templat notifikasi pesan digunakan untuk mengirim notifikasi pesan DingTalk atau tugas kepada pengguna tertentu ketika alur kerja formulir mencapai langkah tertentu, berdasarkan templat notifikasi yang telah dikonfigurasi sebelumnya. Baca artikel ini untuk mempelajari cara mengonfigurasi templat notifikasi pesan.

| Fitur | Edisi Gratis | Edisi Basic | Edisi Professional | Edisi Dedicated |
|---|---|---|---|---|
| Templat notifikasi pesan | Tidak didukung | Didukung | Didukung | Didukung |

## Gunakan templat pesan

Anda dapat menggunakan templat pesan dengan dua cara berikut.

- Metode 1: Gunakan pada langkah Notifikasi pesan di desain alur kerja formulir alur kerja. Untuk detailnya, lihat langkah Notifikasi pesan.
- Metode 2: Gunakan templat pesan di pengaturan halaman formulir. Untuk detailnya, lihat Notifikasi pesan formulir.

<Note>
Formulir biasa saat ini tidak mendukung templat pesan tipe Tugas DingTalk.
</Note>

## Format variabel bawaan

Konten pesan pada templat pesan mendukung variabel yang dapat dikonfigurasi. Setiap variabel merupakan ID komponen formulir dengan format `$!{Component ID}`. Saat pesan dikirim, YiDA secara otomatis mengganti variabel tersebut dengan nilai komponen formulir.

| Variabel | Bidang | Formulir | Alur kerja |
|---|---|---|---|
| $!\{formInstId} | ID instans | ✓ | ✓ |
| $!\{formUuid} | Kode formulir | ✓ | ✓ |
| $!\{formTitle} | Nama formulir | ✓ | ✓ |
| $!\{formTitleEn} | Nama formulir dalam bahasa Inggris | ✓ | ✓ |
| $!\{title} | Judul instans formulir | ✓ | ✓ |
| $!\{titleEn} | Judul instans formulir dalam bahasa Inggris | ✓ | ✓ |
| $!\{creator} | ID karyawan pembuat | ✓ | ✓ |
| $!\{originator} | ID karyawan pemrakarsa | ✓ | ✓ |
| $!\{originatorName} | Nama pemrakarsa | ✓ | ✓ |
| $!\{originatorNameEn} | Nama pemrakarsa dalam bahasa Inggris | ✓ | ✓ |
| $!\{serialNo} | Nomor seri | ✓ | ✓ |
| $!\{createTime} | Waktu pembuatan | ✓ | ✓ |
| $!\{modifiedTime} | Waktu modifikasi | ✓ | ✓ |
| $!\{processInstStatus} | Status instans alur kerja | ✗ | ✓ |
| $!\{approvedResult} | Hasil persetujuan | ✗ | ✓ |
| $!\{approvedResultCode} | Kode hasil persetujuan | ✗ | ✓ |
