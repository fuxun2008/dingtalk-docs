Domain khusus organisasi dipilih dan diatur oleh Admin Organisasi di workbench YiDA. Domain ini merepresentasikan identitas dan merek organisasi Anda di YiDA. Domain khusus membantu memperkuat citra perusahaan dan pengenalan merek Anda secara efektif.

## Konsep dasar

Nama domain adalah string yang digunakan di internet untuk mengidentifikasi dan menemukan sumber daya seperti situs web dan server. Domain adalah alamat yang terdiri dari rangkaian karakter, dirancang agar situs web atau server mudah diakses dan diingat. Nama domain terdiri dari beberapa bagian yang dipisahkan oleh titik (`.`).

- Top-Level Domain (TLD): TLD adalah bagian terakhir dari nama Domain dan mewakili kategori, negara, atau wilayahnya. TLD yang umum meliputi .com, .org, .net, .gov, .edu, dan .cn.
- Second-Level Domain (SLD): SLD adalah bagian sebelum TLD dan disesuaikan oleh pendaftar. Sebagai contoh, dalam aliwork.com, aliwork adalah second-level domain.
- Subdomain: Subdomain adalah bagian sebelum second-level domain, digunakan untuk mengatur dan menyusun situs web lebih lanjut. Sebagai contoh, dalam xxx.aliwork.com, xxx adalah subdomain.

Domain khusus organisasi YiDA adalah subdomain di bawah second-level domain `aliwork.com`. Anda dapat menyesuaikan bagian `xxx` di `xxx.aliwork.com` sebagai subdomain Anda.

<Note>
Perhatikan hal-hal berikut saat mengubah domain khusus organisasi Anda:

- Edisi berbayar YiDA saat ini mengizinkan subdomain kustom diubah maksimal tiga kali.
- Domain organisasi digunakan bersama oleh semua aplikasi dalam organisasi. Setelah Domain diubah, URL akses semua aplikasi akan berubah.
- Jika Anda tetap menggunakan Domain lama untuk mengakses YiDA, Anda mungkin diminta untuk Masuk kembali. Setelah Masuk, Anda akan otomatis dialihkan ke Domain baru.
- Layanan apa pun yang dipanggil dari halaman menggunakan Domain tetap — seperti melalui Sumber Data, kode JS, atau konfigurasi atribut — tidak akan berfungsi lagi. Anda harus memperbaruinya ke Domain baru atau menggunakan URL relatif.
- Tautan dalam Obrolan dan item Tugas yang sudah terkirim tidak akan berubah. Anda harus Masuk kembali untuk mengaksesnya.
</Note>

## Prosedur

Ikuti langkah-langkah di bawah ini untuk mengubah domain khusus organisasi.

<Steps>
  <Step title="Langkah 1">
    Masuk ke [workbench YiDA](https://www.yidaapps.com/workPlatform) sebagai Admin.
  </Step>
  <Step title="Langkah 2">
    Klik tombol **Manajemen Platform** di sudut kanan atas untuk masuk ke halaman **Informasi Dasar** dari manajemen platform.
  </Step>
  <Step title="Langkah 3">
    Pilih **Domain Organisasi**, klik **Ubah** di bawah, lalu klik **Ubah Domain** di kotak dialog yang muncul.
  </Step>
  <Step title="Langkah 4">
    (Opsional) Di kotak dialog **Deteksi Cerdas**, pilih halaman yang akan diubah, lalu perbarui Domain di halaman tersebut.
    Anda juga dapat mengklik **Lewati Deteksi** untuk melewati deteksi saat ini dan langsung ke langkah berikutnya untuk mengubah Domain.
  </Step>
</Steps>
