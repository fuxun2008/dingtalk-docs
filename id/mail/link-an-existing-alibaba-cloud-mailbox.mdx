Super Admin atau pembuat perusahaan dapat memasukkan domain Alibaba Cloud Enterprise Mail yang sudah ada untuk menautkan kotak surat. Gunakan salah satu jalur berikut.

## Konsol Admin

Konsol Admin > Workbench di bilah sisi kiri > Kelola Aplikasi > Email > Masuk > Tautkan dan gunakan > masukkan domain email > admin memindai Kode QR dengan DingTalk di ponsel > di ponsel, masukkan nama pengguna, kata sandi, server email masuk, server email keluar, dan informasi lainnya > ketuk Selesai untuk menyelesaikan penautan.

## Seluler

Aplikasi seluler DingTalk > Lainnya > Email > ... di sudut kanan atas > Pengaturan > Tambah akun email pribadi lain > Kotak surat perusahaan yang sudah ada, Tautkan sekarang > masukkan domain Alibaba Cloud Enterprise Mail > masukkan nama pengguna, kata sandi, server email masuk, server email keluar, dan informasi lainnya > ketuk Selesai untuk menyelesaikan penautan.
