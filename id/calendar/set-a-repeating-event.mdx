Kalender mendukung pengaturan acara berulang untuk beberapa minggu ke depan sekaligus, sehingga Anda tidak perlu mengaturnya berulang kali secara manual.

### Cara mengaturnya

Buka **DingTalk Kalender**, klik **+**, lalu buat acara baru.

![](https://img.alicdn.com/imgextra/i2/O1CN011qgfhimIwkJ5VtjE_!!6000000001117-2-tps-2716-1356.png)

Di halaman acara baru, klik **Tidak berulang**. Atur siklus pengulangan menjadi harian, mingguan, bulanan, dan lainnya. Siklus pengulangan kustom juga didukung.

![](https://img.alicdn.com/imgextra/i3/O1CN01U1EowjwnI5E5VtjE_!!6000000005653-2-tps-2716-1356.png)
