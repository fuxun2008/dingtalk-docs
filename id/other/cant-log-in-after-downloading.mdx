Jika Anda tidak bisa masuk setelah mengunduh dan menginstal DingTalk — misalnya, aplikasi menyatakan bahwa akun Anda tidak ada — Anda mungkin menginstal DingDing, versi untuk Tiongkok daratan, bukan aplikasi DingTalk internasional. Ikuti langkah-langkah berikut untuk memeriksa dan mengatasi masalah ini.

## DingTalk dan DingDing adalah dua aplikasi yang berbeda

- **DingTalk** adalah versi internasional, tersedia di dingtalk.io, untuk pengguna di luar Tiongkok daratan.
- **DingDing (钉钉)** adalah versi untuk pengguna di Tiongkok daratan.

Kedua aplikasi memiliki sistem akun yang terpisah. Akun DingTalk tidak dapat digunakan untuk masuk ke DingDing, dan akun DingDing tidak dapat digunakan untuk masuk ke DingTalk. Karena namanya mirip, pencarian "DingTalk" di toko aplikasi atau di web dapat mengarahkan Anda ke DingDing.

## Periksa aplikasi yang ada di ponsel Anda

- **Nama aplikasi:** versi internasional ditampilkan sebagai **DingTalk**; versi Tiongkok daratan ditampilkan sebagai **钉钉**.
- **Sumber unduhan:** tautan unduhan resmi untuk versi internasional tersedia di <a href="https://www.dingtalk.io/download/" target="_blank" rel="noopener noreferrer">dingtalk.io/download</a>.

Jika aplikasi Anda menampilkan DingDing (钉钉), instal aplikasi DingTalk internasional melalui tautan resmi di bawah ini, lalu masuk dengan akun dingtalk.io Anda.

## Unduh aplikasi DingTalk internasional

Unduh klien DingTalk melalui tautan berikut:

- <a href="https://www.dingtalk.io/download/" target="_blank" rel="noopener noreferrer">Unduh DingTalk untuk desktop</a> — mencakup klien Windows dan macOS.
- <a href="https://aliyun-alimail-ios.oss-cn-hangzhou.aliyuncs.com/Global/DingTalk_Android.apk" target="_blank" rel="noopener noreferrer">Unduh DingTalk untuk Android</a>
- <a href="https://www.dingtalk.io/download/" target="_blank" rel="noopener noreferrer">Unduh DingTalk untuk iOS &amp; iPadOS</a>

Setelah menginstal, masuk dengan akun yang Anda buat di dingtalk.io.
