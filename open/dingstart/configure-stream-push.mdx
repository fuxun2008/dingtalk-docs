---
title: "Configure Stream Push (Recommended)"
description: "Configure Stream mode event push for an internal app in the DingTalk Developer Console to receive event subscription messages over a persistent connection, with no public callback URL required."
---

To configure Stream mode event push, follow the steps in this document to complete the integration.

## Prerequisites

- You have <a href="https://open.dingtalk.com/document/orgapp/obtain-developer-permissions" target="_blank">developer permissions</a> in the DingTalk Developer Console of your organization.
- You have an <a href="https://open.dingtalk.com/document/orgapp/create-an-application" target="_blank">internal app</a> in your DingTalk organization.
- You have completed the <a href="https://open.dingtalk.com/document/orgapp/develop-stream-mode-push-server" target="_blank">Develop a Stream mode push server (Recommended)</a> process.

## Procedure

<Steps>
<Step title="Open the app details page">
Log in to the <a href="https://open-dev.dingtalk.com/" target="_blank">Developer Console</a>, click the target app, and go to the app details page.
</Step>
<Step title="Select Stream mode push">
Click **Development Configuration > Event Subscription**, and select **Stream mode push**.
</Step>
<Step title="Verify the connection channel">
After server-side development is complete, click **Integration completed, verify the connection channel**.
</Step>
<Step title="Save">
Click **Save**. The event subscription list appears only after you save.
