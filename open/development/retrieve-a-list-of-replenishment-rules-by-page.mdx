Call this API to get a paginated list of makeup clock-in rules configured in attendance settings, including rule names and rule IDs.

## API Call Description

For example, an organization has two makeup clock-in rules in its attendance rules management: **Test makeup clock-in rule** and **Default makeup clock-in rule**.

Call this API to get the rule names and rule IDs of both makeup clock-in rules.

In the Attendance admin console, open **attendance rules** > **Makeup clock-in rules** to view the configured makeup clock-in rules. Each rule lists its **Rule name**, **Rule details** (allowed submissions per month, how far back makeup clock-in can be requested, and applicable types such as missed, late, or early-leave punches), and **Scope**, with **Edit** and **Delete** actions. Use **Add makeup clock-in rule** to create a new one.

## Request

### Basic Information

| Field | Value |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/v1.0/attendance/adjustments |
| HTTP Method | GET |
| Supported app types | appType-Internal app　appType-Third-party enterprise app |
| Required permissions | permission-qyapi_attendance_group_read-Attendance group read permission |

### Request Header

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Yes | The access credential for calling this API. Obtain it as follows:   - For an Internal app, call the [Get the access token of an internal app](/open/development/obtain-the-access-token-of-an-internal-app) API. - For a Third-party enterprise app, call the API for getting the access token of an organization that has authorized a Third-party app. |

### Query Parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| pageNumber | Long | Yes | The starting page number.  The value starts from 1. |
| pageSize | Long | Yes | The page size.  The maximum value is 50. |
