---
title: "Update a filter view"
description: "Override new data columns or modify column filter rules to reflect the latest business needs."
---

Call this API to update the name, range, or filter conditions of a specified filter view. All fields are optional, and only the fields you pass in are updated. This API is suitable for adjusting an existing filter view—for example, renaming the view for easier identification, expanding the filter range to cover new data columns, or modifying the filter rule of a column to reflect the latest business needs.

## Request

### Basic information

| Field | Value |
| --- | --- |
| HTTP URL | `https://api.dingtalk.io/v1.0/doc/workbooks/{workbookId}/sheets/{sheetId}/filterViews/{filterViewId}` |
| HTTP Method | PATCH |
| Supported app type | appType-Internal app |
| Required permissions | permission-Document.Workbook.Write-DingTalk Spreadsheet write permission |

### Request headers

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Yes | The access credential for calling this API. Call the [Get the access token of an internal app](/open/development/obtain-the-access-token-of-an-internal-app) API to obtain it. |

### Path parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| workbookId | String | Yes | The Spreadsheet file ID. The `nodeId(dentryUuid)` returned by the [Knowledge Base API](/open/development/knowledge-base-overview) is the Spreadsheet `workbookId`. Obtain it by calling the [Get node](https://open.dingtalk.com/document/orgapp/get-node) and [Create Knowledge Base document](/open/development/create-team-space-document) APIs. |
| sheetId | String | Yes | The Worksheet ID or name. Call the [Get all worksheets](/open/development/obtain-all-worksheets) API to obtain the value of the id or name parameter. |
| filterViewId | String | Yes | The ID of the filter view. |

### Query parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| operatorId | String | Yes | The unionId of the operator.   - Call the [Obtain the user ID of a user by using a silent login code](/open/development/obtain-the-userid-of-a-user-by-using-the-log-free) API to obtain the value of the unionid parameter. - Call the [Query user details](/open/development/query-user-details) API to obtain the value of the unionid parameter.       If the operator has no permission, the API returns the error `The operator has no permission`. |

### Request body

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| name | String | No | The new name of the filter view. If not passed, the name is not updated. |
| range | String | No | The new range of the filter view, in A1 notation. If not passed, the range is not updated. |
| criteria | `Map<String, Object>` | No | The column filter conditions to update. The key is the column offset (relative to the first column of range, starting from 0), and the value is the filter condition object. Only the columns passed in are updated; the existing filter conditions of other columns are not affected. If not passed, the filter conditions are not updated. |
|  | Object | No | The filter condition object of the current column. |
| filterType | String | No | The filter type. Valid values:   - **values**: Filter by value - **color**: Filter by color - **condition**: Filter by condition |
| visibleValues | Array of String | No | Visible values. |
| conditions | Array | No | The list of filter conditions when filtering by condition. Valid when `filterType` is `condition`. Each condition object contains the `operator` and `value` fields. |
| operator | String | No | The condition operator. Valid values:   - **equal**: Equal to - **not-equal**: Not equal to - **contains**: Contains - **not-contains**: Does not contain - **starts-with**: Starts with - **not-starts-with**: Does not start with - **ends-with**: Ends with - **not-ends-with**: Does not end with - **greater**: Greater than - **greater-equal**: Greater than or equal to - **less**: Less than - **less-equal**: Less than or equal to |
| value | String | No | The condition value. |
| conditionOperator | String | No | The logical relationship between multiple conditions. Valid values: `and`, `or`. Default value: `and`. Valid when `filterType` is `condition` and multiple conditions are specified. |
| backgroundColor | String | No | The color value (hexadecimal, such as `#FF0000`) when filtering by background color. Valid when `filterType` is `color`. Specify either this field or `fontColor`. |
| fontColor | String | No | The color value (hexadecimal, such as `#FF0000`) when filtering by font color. Valid when `filterType` is `color`. Specify either this field or `backgroundColor`. |
