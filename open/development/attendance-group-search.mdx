Call this API to fuzzy search attendance groups by name and get attendance group summaries, including attendance group names and IDs.

## Request

| **Basic Information** | |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/topapi/attendance/group/search |
| HTTP Method | POST |
| Supported App Types | appType-Internal app appType-Third-party enterprise app |
| Required Permissions | permission-qyapi_attendance_group_read-Attendance group read permission |

### Query Parameters

| Name | Type | Required | Example | Description |
| --- | --- | --- | --- | --- |
| access_token | String | Yes | bE74xxxx | The App credential used to call this API.   - Internal app: Call the [Get the access_token of an Internal App](/open/development/obtain-orgapp-token) API to obtain it. - Third-party enterprise app: Call the Get the access_token of a Third-Party Organization API to obtain it. |

### Request Body

| Name | Type | Required | Example | Description |
| --- | --- | --- | --- | --- |
| op_user_id | String | Yes | manager123 | The userId of the operator. |
| group_name | String | Yes | Attendance | The attendance group name. |

### Request Example

```curl
curl -X POST "https://api.dingtalk.io/topapi/attendance/group/search" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=d7689axxxx70e7a' \
-d 'group_name=%Exxxx%BA%97' \
-d 'op_user_id=dd_dd'
```

| --- | --- | --- | --- |

| id | Number | 685935028 | The attendance group ID. |
| success | Boolean | true | Indicates whether the query succeeded.   - **true**: Success - **false**: Failed |
