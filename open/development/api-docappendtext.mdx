---
title: "Append text to the end of a paragraph"
---

Call this API to append a piece of text to the end of a paragraph.

## API call description

For information about the data structures related to document content, see [Document data structures](https://open.dingtalk.io/document/development/document-data-structure).

## Request

### Basic information

| Field | Value |
| --- | --- |
| HTTP URL | `https://api.dingtalk.io/v1.0/doc/suites/documents/{docKey}/blocks/{blockId}/paragraph/appendText` |
| HTTP Method | POST |
| Supported app type | appType-Internal app |
| Required permissions | permission-Storage.File.Write-Write permission on organization storage files |

### Request header

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Yes | The access credential for calling this API. Obtain it by calling the [Get the access token of an internal app](https://open.dingtalk.io/document/development/obtain-the-access-token-of-an-internal-app) API. |

### Path parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| docKey | String | Yes | The document ID (the `docKey` or `dentryUuid` of the document). After you create a document by calling the [Create a Knowledge Base document](https://open.dingtalk.io/document/development/create-team-space-document) API, obtain the `docKey` parameter from the response. To get the `dentryUuid` from the document URL, take `https://alidocs.dingtalk.io/i/nodes/Zxxxxa-id` as an example; the `dentryUuid` is `Zxxxxa-id`. |
| blockId | String | Yes | The unique identifier of the target paragraph. Obtain the `blockId` of the paragraph by calling the [Query block elements](https://open.dingtalk.io/document/development/api-docblocksquery) API. |

### Query parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| operatorId | String | Yes | The unionId of the user. Obtain the `unionid` value by calling the [Query user details](https://open.dingtalk.io/document/development/query-user-details) API. |

### Request body

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| text | String | Yes | The text to insert. |
