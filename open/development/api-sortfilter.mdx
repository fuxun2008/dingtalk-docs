Call this API to sort data within the global filter range in ascending or descending order by a specified column. This API applies to scenarios that require ordered display of filtered data, such as arranging sales data from highest to lowest by amount, or sorting a task list by due date in ascending order.

## API call description

Sort actions permanently change the actual storage order of data records in the worksheet, not just the display order.

## Request

### Basic information

| Field | Value |
| --- | --- |
| HTTP URL | `https://api.dingtalk.io/v1.0/doc/workbooks/{workbookId}/sheets/{sheetId}/filter/sort` |
| HTTP Method | POST |
| Supported app type | appType-Internal app |
| Required permissions | permission-Document.Workbook.Write-Spreadsheet write permission |

### Request headers

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Yes | The access credential for calling this API. To obtain it, call [Obtain the access token of an internal app](/open/development/obtain-the-access-token-of-an-internal-app). |

### Path parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| workbookId | String | Yes | The spreadsheet file ID. The `nodeId(dentryUuid)` returned by the [Knowledge Base API](/open/development/knowledge-base-overview) is the spreadsheet `workbookId`. To obtain it, call [Get a node](https://open.dingtalk.com/document/orgapp/get-node) or [Create a Knowledge Base document](/open/development/create-team-space-document). |
| sheetId | String | Yes | The worksheet ID or name. To obtain the id or name parameter value, call [Get all worksheets](/open/development/obtain-all-worksheets). |

### Query parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| operatorId | String | Yes | The unionId of the operator.   - To obtain the unionid parameter value, call [Obtain user information by silent login code](/open/development/obtain-the-userid-of-a-user-by-using-the-log-free). - To obtain the unionid parameter value, call [Query user details](/open/development/query-user-details).       If the operator has no permission, the API returns the error `The operator has no permission`. |

### Request body

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| field | Object | Yes | The sorting rules object. |
| column | Long | Yes | The column offset relative to the first column of the filter range, starting from 0. |
| ascending | Boolean | No | Whether to sort in ascending order. The default is `true` (ascending). Set to `false` for descending order. |
