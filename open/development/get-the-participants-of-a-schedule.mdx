Call this API to retrieve the list of event attendees.

## Request

### Basic information

| Field | Value |
| --- | --- |
| HTTP URL | `https://api.dingtalk.io/v1.0/calendar/users/{userId}/calendars/{calendarId}/events/{eventId}/attendees` |
| HTTP Method | GET |
| Supported app types | appType-Internal app　appType-Third-party enterprise app　appType-Third-party personal app |
| Required permissions | permission-Calendar.Event.Read-Read permission for events in the Calendar app |

### Request headers

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Yes | The access credential used to call this API. Obtain it as follows:   - For an internal app, call [Get the access token of an internal app](/open/development/obtain-the-access-token-of-an-internal-app#). - For a third-party enterprise app, call [Get the access token of an organization authorized to a third-party app](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#). - For a third-party personal app, call [Get the user token](/open/development/obtain-user-token#). |

### Path parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| userId | String | Yes | The unionId of the user to whom the requested resource belongs.   - For an internal app or a third-party enterprise app, call [Query user details](/open/development/query-user-details#) to obtain the value of the unionid parameter. - For a third-party personal app, call [Get the user's profile from Contacts](/open/development/dingtalk-retrieve-user-information#) to obtain the value of the unionId parameter. |
| calendarId | String | Yes | The ID of the calendar to which the event belongs. Set it to **primary**, which represents the user's primary calendar. |
| eventId | String | Yes | The event ID. Call [Query an event list](/open/development/query-an-event-list#) to obtain the value of the id parameter. |

### Query parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| maxResults | Integer | No | The maximum number of records to return. Default: 100. Maximum: 500. |
| nextToken | String | No | The pagination cursor.      If a query cannot return all results at once, a pagination token is returned. Pass this token in the next request to retrieve the subsequent data, until the pagination token is null, which indicates that all data has been returned. |
