description: "Call this API with an attendance group ID to get the user IDs of all attendance members in the group by page."
---

Call this API to get the user IDs of all employees in an attendance group by page.

## API Call Description

If the attendance members include a department, the API returns the user IDs of the employees in that department. It does not return the department ID.

For example, the attendance members include the **Test Department** and the employee **John**. The Test Department has one employee, **Jane**. Calling this API returns the following:

- The user IDs of the employees in the Test Department (including its sub-departments), which is Jane's user ID
- John's user ID

## Request

| **Basic Information** | |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/topapi/attendance/group/memberusers/list |
| HTTP Method | POST |
| Supported App Types | Internal app, Third-party enterprise app |
| Permissions | qyapi_attendance_group_read (Attendance group query permission) |

### Query Parameters

| Name | Type | Required | Example | Description |
| --- | --- | --- | --- | --- |
| access_token | String | Yes | bE74xxxx | The App credential used to call this API.   - Internal app: Call the [Get the access_token of an internal app](/open/development/obtain-orgapp-token) API to get it. - Third-party enterprise app: Call the API for getting the access_token of a third-party enterprise to get it. |

### Request Body

| Name | Type | Required | Example | Description |
| --- | --- | --- | --- | --- |
| cursor | Number | No | 0 | The cursor value, which indicates the starting position. If not specified, the query starts from the first item. |
| op_user_id | String | Yes | user123 | The user ID of the operator. |
| group_id | Number | Yes | 98562 | The attendance group ID.  **Note**  If you use the legacy attendance group identifier group_key, call the [Convert groupKey to groupId](/open/development/convert-groupkey-to-groupid) API to convert group_key to group_id. |

## Response

### Response Body

| Name | Type | Example | Description |
| --- | --- | --- | --- |
| request_id | String | 3pgsafymemlr | The request ID. |
| errcode | Number | 0 | The return code. |
| success | Boolean | true | Indicates whether the call succeeded.   - **true**: Success - **false**: Failed |
| result | PageResult |  | The User List. |
| has_more | Boolean | false | Indicates whether more Data is available.   - **true**: Yes - **false**: No |
| cursor | Number | 1387570559 | The starting position of the next paged request. |
