---
title: "Batch Query Scheduling Summaries of Users"
description: "Query scheduling summaries for multiple users over up to 7 days, returning shift names, shift version IDs, and attendance group IDs."
---

Call this API to query the scheduling summaries of users within a specified time range, including shift names, shift version IDs, and attendance group IDs.

## Request

| **Basic Information** | |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/topapi/attendance/schedule/shift/listbydays |
| HTTP Method | POST |
| Supported app types | appType-Internal app |
| Required permissions | permission-qyapi_attendance_group_manage-Attendance group management permission |

### Query Parameters

| Name | Type | Required | Example | Description |
| --- | --- | --- | --- | --- |
| access_token | String | Yes | 57cf92xxx | The App credential used to call this API. Obtain it by calling the [Get the access_token of an Internal App](/open/development/obtain-orgapp-token) API. |

### Request Body

| Name | Type | Required | Example | Description |
| --- | --- | --- | --- | --- |
| op_user_id | String | Yes | manager123 | The user ID of the operator. |
| userids | String | Yes | user123,user456 | The list of user IDs to query. Separate multiple user IDs with commas. Each query supports a maximum of 20 user IDs. |
| from_date_time | Number | Yes | 1564985177000 | The Unix timestamp of the start date, in milliseconds.  **Note**  The time range cannot exceed 7 days. |
| to_date_time | Number | Yes | 1564985177000 | The Unix timestamp of the end date, in milliseconds.  **Note**  The time range cannot exceed 7 days. |

### Request Example

```curl
curl -X POST "https://api.dingtalk.io/topapi/attendance/schedule/shift/listbydays" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=ecff22xxxx1f8d5d' \
-d 'from_date_time=1564985177000' \
-d 'op_user_id=dd_dd' \
-d 'to_date_time=1564985177000' \
-d 'userids=dd_test%2Ctl2342'
```

## Response

### Response Body

| Name | Type | Example | Description |
| --- | --- | --- | --- |
| result | TopDayScheduleShiftVo[] |  | The list of returned results. |
| work_date | Date | 2020-12-14 00:00:00 | The workday. |
| shift_names | String[] | ["A"] | The shift names. |
| userid | String | user123 | The user ID of the user. |
| shift_versions | Number[] | [9527] | The shift version IDs. |
| shift_ids | Number[] | [9087] | The shift IDs. |
| group_id | Number | 7786 | The attendance group ID. |
| corp_id | String | dinge8xxx | The organization ID. |
| success | Boolean | true | Indicates whether the call succeeded.   - **true**: Success - **false**: Failed |
| errcode | Number | 0 | The return code. |
| errmsg | String | ok | The description of the return code. |
| request_id | String | 5fyefrdh2mf4 | The request ID. |
