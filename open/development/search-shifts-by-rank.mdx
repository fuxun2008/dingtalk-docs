---
title: "Search Shifts by Name"
description: "Call this API to run a fuzzy search on shift names and get the names and IDs of matching shifts."
---

Call this API to run a fuzzy search for shifts by name. The response includes the shift names and IDs.

## Request

| **Basic Information** | |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/topapi/attendance/shift/search |
| HTTP Method | POST |
| Supported app types | Internal app, Third-party enterprise app |
| Required permissions | qyapi_attendance_group_read (attendance group read permission) |

### Query Parameters

| Name | Type | Required | Example | Description |
| --- | --- | --- | --- | --- |
| access_token | String | Yes | 6d1bxxxx | The app credential used to call this API.   - Internal app: Call the [Get the access_token of an internal app](/open/development/obtain-orgapp-token) API to obtain it. - Third-party enterprise app: Call the Get the access_token of a third-party enterprise API to obtain it. |

### Request Body

| Name | Type | Required | Example | Description |
| --- | --- | --- | --- | --- |
| op_user_id | String | Yes | manager4220 | The userId of the operator. |
| shift_name | String | Yes | A | The shift name. |

### Request Example

```curl
curl -X POST "https://api.dingtalk.io/topapi/attendance/shift/search" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=ab85bxxxx739d5' \
-d 'op_user_id=dd_dd' \
-d 'shift_name=Regular%20Day%20Shift'
```

## Response

### Response Body

| Name | Type | Example | Description |
| --- | --- | --- | --- |
| result | TopMinimalismShiftVO[] |  | The query results. |
| name | String | Regular Day Shift | The shift name. |
| id | Number | 677995086 | The shift ID. |
| success | Boolean | true | Indicates whether the call succeeded.   - **true**: Success - **false**: Failed |
| errcode | Number | 0 | The return code. |
| errmsg | String | ok | The return code message. |
| request_id | String | 4wsw01tcq1h4 | The request ID. |
