This article introduces the features covered in the Cool App developer guides.

## **What Is a Cool App**

Make your app visible and accessible everywhere.

A Cool App is an entirely new type of scenario-based app. It integrates app features into multiple product scenarios within DingTalk, delivering an immersive experience, pioneering new interaction methods, and enhancing data-driven capabilities. It shifts the model from users searching for apps to apps reaching users, creating a new scenario-based collaboration experience.

For more details, see [Cool App](https://open.dingtalk.com/coolapp).

## **How to Develop a Cool App**

### **Develop a Group Chat Cool App**

- **Immersive experience:** Stay within the chat Context without interrupting your current work.
- **Scenario-based collaboration:** Collaborate on information in real time and efficiently around specific scenarios and tasks.
- **Instant data analysis:** Use the structured Data generated through efficient collaboration for instant analysis and actionable insights.

### **Process Overview**

Before you begin, make sure you have completed the prerequisite [Become a DingTalk Developer](https://open.dingtalk.com/document/orgapp/become-a-dingtalk-developer#). The integration flow is as follows. For details, see [Group Chat Cool App Developer Guide](/zh/open/development/group-chat-cool-app-overview).

1. [Create a Cool App](https://open.dingtalk.com/document/orgapp/create-a-process#) to complete the creation of a group chat Cool App.
2. Configure the [Quick Configuration Entry](https://open.dingtalk.com/document/orgapp/quick-configuration-entry#) content to display it in the chat quick access bar.
3. After you finish developing the group chat Cool App, [Publish and Use the Cool App](https://open.dingtalk.com/document/orgapp/save-and-publish#) to complete app release and usage.

After completing the steps above, you have developed and published a simple group chat Cool App. You can now Install the Cool App within a Group Chat and access its page through the quick access entry. You can also use the additional capabilities below to build a Cool App with an even better experience.

**Note**

Advanced Cool App development (optional)

- Configure the message Content sent by the group chat Cool App:

  - Develop [Plain Messages](https://open.dingtalk.com/document/orgapp/common-message#). Send Plain messages from the group chat Cool App Bot to implement basic message sending and management.
  - Develop [Interactive Cards](https://open.dingtalk.com/document/orgapp/flow-type-interactive-card#) to send and manage interactive Card messages and enable user Interaction.
  - Develop [Top Banner Cards](https://open.dingtalk.com/document/orgapp/resident-type-ceiling#) to send and manage top banner Card information and enable user Interaction.
- Implement advanced Interaction for group chat Bots. For details, see [Enable Bot Conversations](https://open.dingtalk.com/document/orgapp/achieve-robot-dialogue#).
- Use the Group Management APIs to integrate your app's existing features with group management. For details, see [Group Management](https://open.dingtalk.com/document/orgapp/add-a-group-member#).
- Use group chat Cool App callback events to detect when the Cool App is installed or uninstalled within a group. This lets you handle initialization and termination tasks such as onboarding guidance and Data Permissions reclamation. For details, see [Detect Group Changes (Event Subscription)](https://open.dingtalk.com/document/orgapp/group-change-awareness-event-subscription#).

### **Develop a Message Menu Cool App**

In DingTalk, press and hold a message to bring up a menu, then use the menu options to act on the message, such as forwarding it, converting it to an Event, or converting it to a task. The new quick actions in the message menu also allow developers to integrate their own capabilities and customize them for their business scenarios.

- **Message single selection view**
- **Message multiselect view**

### **Process Overview**

Before you begin, make sure you have completed the prerequisite [Become a DingTalk Developer](https://open.dingtalk.com/document/orgapp/become-a-dingtalk-developer#). The integration flow is as follows. For details, see [Guide to Integrating Message Menus](https://open.dingtalk.com/document/orgapp/guide-to-the-process-of-accessing-message-menus#).

1. Link enhancement development must be based on an Internal app. If you do not have an Internal app, you need to [Create an App](https://open.dingtalk.com/document/orgapp/create-orgapp#). If you already have one, use it directly.
2. Configure the message menu extension information. In the Cool App extension, enable extension to the message menu and configure the basic information.
3. Perform JSAPI authentication. For details, see [H5 Micro App JSAPI Authentication](https://open.dingtalk.com/document/orgapp/jsapi-authentication#).
4. Get the message Content. Call the [H5 JSAPI - Get Message Content](https://open.dingtalk.com/document/orgapp/obtain-message-content#) API to get the message Content, and develop your app based on your actual business needs.

### **Develop a Link Enhancement Cool App**

To open a target Link, you normally click the Link and jump to the target Page. The link enhancement capability converts links within DingTalk chats. Once integrated, links are automatically recognized and converted into cards. Users can view the card's Content directly and use the card's interactive capabilities to perform business actions right on the card.

- **Plain link**
- **Enhanced link**

  - **Convert an image-text link to a card to display web page information**

  - **Convert an approval link to a card for direct Interaction**

### **Process Overview**

Before you begin, make sure you have completed the prerequisite [Become a DingTalk Developer](https://open.dingtalk.com/document/orgapp/become-a-dingtalk-developer#). The integration flow is as follows. For details, see [Guide to Integrating Link Enhancement](https://open.dingtalk.com/document/orgapp/guide-for-enhancing-the-access-link-of-enterprise-internal-applications#).

Step 1: Link enhancement development must be based on an Internal app. If you do not have an Internal app, you need to [Create an App](https://open.dingtalk.com/document/orgapp/create-orgapp#). If you already have one, use it directly.

Step 2: Configure link enhancement rules. In the Cool App extension, register and configure the basic information for the link enhancement rules.

Step 3: Add test users to enable subsequent debugging of the link enhancement feature.

Step 4: Implement the business callback API to enable link enhancement callback conversion.

Step 5: Submit for release to enable link enhancement for your organization.
