title: "Batch Query Employee Leave Balance Change Records"
description: "Call this API to batch query leave balance change records for employees, including initialization, consumption, and updates. Supports pagination."

Call this API to get all leave balance change records of an employee. Records include leave balance initialization, quota consumed by the employee, and leave balance updates.

## Request

### Basic Information

| Field | Value |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/v1.0/attendance/vacations/records/query |
| HTTP Method | POST |
| Supported app types | appType-Internal app　appType-Third-party enterprise app |
| Permissions | permission-qyapi_holiday_readonly-DingTalk leave query permission |

### Request Header

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Yes | The access credential for calling this API. Get it as follows:   - Internal app: Call the [Get the access token of an internal app](/open/development/obtain-the-access-token-of-an-internal-app) API. - Third-party enterprise app: Call the API to get the access token of an organization that has authorized the third-party app. |

### Request Body

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| opUserId | String | Yes | The userId of an admin in your organization who has the OA Approval app permissions. Pass the userId of the Super Admin. Call the [Get the admin list](/open/development/query-the-administrator-list) API and use the `userId` field of the Super Admin in the response. |
| leaveCode | String | Yes | The unique identifier of the leave type. Call the [Query the leave rules list](/open/development/holiday-type-query) API to get the `leave_code` value. |
| userIds | Array of String | Yes | The list of userIds of the employees to query. Pass up to 50 userIds per call. |
| pageNumber | Long | Yes | The pagination cursor:   - For the first query, pass 0. - For subsequent queries, pass the cumulative offset from the previous query. |
| pageSize | Integer | Yes | The pagination offset. Maximum: 200. |
