---
title: "Get Attendance Report Column Definitions"
description: "Call this API to get smart attendance report column definitions, returning each column's ID, type, and name for selecting payroll columns."
---

Call this API to query the statistics of a column in the smart attendance report by column ID. Organizations can select which column values to use in payroll calculation.

## API Call Description

- This API does not return IDs for leave-related fields. To get leave-related data, call the [Get report leave data](/open/development/obtains-the-holiday-data-from-the-smart-attendance-report) API.
- Make sure the smart statistics feature is turned on.

## Request

| **Basic information** | |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/topapi/attendance/getattcolumns |
| HTTP Method | POST |
| Supported app types | appType-Internal app　appType-Third-party enterprise app |
| Required permissions | permission-qyapi_base-Basic permission required to call organization APIs |

### Query Parameters

| Name | Type | Required | Example | Description |
| --- | --- | --- | --- | --- |
| access_token | String | Yes | bE74xxxx | The App credential used to call this API.   - For an Internal app, obtain it through the [Get the access_token of an Internal app](/open/development/obtain-orgapp-token) API. - For a Third-party enterprise app, obtain it through the Get the access_token of a third-party organization API. |

## Response

### Response Body

| Name | Type | Example | Description |
| --- | --- | --- | --- |
| request_id | String | emhw3318cdhv | The request ID. |
| errcode | Number | 0 | The return code. |
| result | AttColumnsForTopVo |  | The query result. |
| columns | ColumnForTopVo[] |  | The report column information. |
| id | Number | 123 | The report column ID. |
| type | Number | 0 | The report column type. |
| name | String | Working hours | The report column name. |
| alias | String | 3_on_duty_user_check_result | The report column alias. |
| status | Number | 0 | The status of the report column. |
| sub_type | Number | 0 | The subtype. |
| expression_id | Number | 129334038 | Deprecated field. Do not use this field in business logic. |
