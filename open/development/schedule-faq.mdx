# FAQs

## Response example for an all-day event

For example, for an all-day event on January 1, 2023, the returned time example is as follows (the end time is T+1):

```json
{
  "start" : {
    "date" : "2023-01-01"
  },
  "end" : {
    "date" : "2023-01-02"
  }
}
```
