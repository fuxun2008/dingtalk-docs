## FormComponent Parameters

**formComponents** is the list of form components. Not every component supports every attribute in Props. For the attributes each control supports, see the request examples below. Some container controls, such as approval suites and detail controls, support child controls. Use children to define the type and attributes of each child control. Child controls follow the same attribute definitions as other controls. The control model is as follows:

<Warning>
General limits for form controls:
</Warning>

- componentId: The control ID. Maximum length: 64 characters.
- bizAlias: The business alias of the control. It must be unique within the form. Specify either bizAlias or componentId. Maximum length: 64 characters.
- label: The control title. Maximum length: 20 characters.
- placeholder: The input hint. Maximum length: 128 characters.
- content: The content of the TextNote control. Maximum length: 500 characters.
- The total length of a table detail control cannot exceed 65,535 characters. Keep each detail control to 100 records or fewer.

#### Common Control Attributes

```json
{
  "componentId": "TextField-12345677",   // Control ID. Unique within the form. Specify either this or bizAlias
  "required":true,  // Whether the control is required
  "label": "Single-line text",   // Control title
  "placeholder": "Enter a value",    // Input hint
  "bizAlias": "staffId", // Business alias of the control. Unique within the form. Specify either this or componentId
  "print": "0", // Whether to include the field in printing (0: not printed; 1: printable). Default: printable
  "disabled": false, // Whether the control is editable
}
```

#### Location Control

```json
{
   "componentType": "TimeAndLocationField",
   "props": {
       "label": "[\"Current Time\",\"Current Location\"]",
       "componentId": "TimeAndLocationField_1CVHM5TIIWR9C",
       "required": false,
       "mask": true
    }
}
```

#### Single-Line Input Control

```json
{
    "componentType": "TextField",
    "props": {
       "label": "Single-line input", // Control title
       "placeholder": "Enter a value", // Input hint
       "componentId": "TextField_17EZKEGSOCTC0", // Control ID. Unique within the form. No business meaning
       "required": false, // Whether the control is required. Default: optional
       "bizAlias": "staffId" // Business alias of the control. Unique within the form. Specify either this or componentId
    }
}
```

#### Multi-Line Input Control

```json
{
    "componentType": "TextareaField",
```

#### Select Control

```json
{
    "componentType": "DDSelectField",
    "props": {
        "options": [ // List of available options
        {
            "value": "Option 1",  // Display name of the option
            "key": "option_0" // Unique key within the control. Optional. The system generates one by default
        },
        {
            "value": "Option 2",
            "key": "option_1"
        },
        {
            "value": "Option 3",
            "key": "option_2"
        },
        {
            "key": "other", // Special key for the "Other" option
           "value": "Other"
        }
      ],
      "label": "Select",
      "placeholder": "Select an option",
      "componentId": "DDSelectField_14T8M4EKXAV40",
      "required": false
    }
}
```

#### Date Control

```json
 {
    "componentType": "DDDateField",
    "props": {
       "unit": "小时", // Hour. Date format. Enum values: 小时 (hour), 天 (day)
       "format": "yyyy-MM-dd HH:mm", // Date format. Optional. 小时 (hour) maps to yyyy-MM-dd HH:mm; 天 (day) maps to yyyy-MM-dd HH:mm
       "bizAlias": "",
       "label": "Date",
       "placeholder": "Select a date",
       "componentId": "DDDateField_SQL0DF3MS9C0",
       "required": false,
       "defaultValue": "2021-12-21 17:46" // Default
    }
}
```
