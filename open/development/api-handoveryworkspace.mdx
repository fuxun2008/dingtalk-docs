---
title: "Transfer Knowledge Base ownership"
---

Transfer ownership of a Knowledge Base to another user.

## Request

### Basic information

| Field | Value |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/v2.0/doc/dentries/workspace/handover |
| HTTP Method | POST |
| Supported app types | appType-Internal app |
| Required permissions | permission-SNS.Document.WorkspaceDocument.Write-SNS Knowledge Base document write permission |

### Request header

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Yes | The access credential for calling this API. Obtain it by calling the [Get the access token of an internal app](https://open.dingtalk.io/document/development/obtain-the-access-token-of-an-internal-app#) API. |

### Request body

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| param | Object | Yes | Required parameter. |
| resourceId | String | Yes | The rootNodeUUid of the Knowledge Base to be transferred. Obtain it by calling the [Batch get Knowledge Bases](https://open.dingtalk.io/document/development/batch-acquisition-of-knowledge-base#) API. |
| receiverUnionId | String | Yes | The unionId of the recipient. |
| leave | Boolean | No | Whether the current Owner leaves the Knowledge Base after the transfer. Optional. Default: false. |
