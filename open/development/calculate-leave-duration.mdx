---
title: "Calculate Leave Duration"
description: "Call this API with an employee's userId and a start and end time to calculate the employee's leave duration for that period based on scheduling rules."
---

Call this API to get each employee's leave duration, calculated automatically based on scheduling rules.

## Request

| **Basic Information** | |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/topapi/attendance/getleaveapproveduration |
| HTTP Method | POST |
| Supported app types | appType-Internal app appType-Third-party enterprise app |
| Required permissions | permission-qyapi_base-Basic permission required to call organization APIs |

### Query Parameters

| Name | Type | Required | Example | Description |
| --- | --- | --- | --- | --- |
| access_token | String | Yes | bE74xxxx | The app credential used to call this API.   - Internal app: Get it by calling [Get the access_token of an internal app](/open/development/obtain-orgapp-token). - Third-party enterprise app: Get it by calling the API that gets the access_token of a third-party enterprise. |

### Request Body

| Name | Type | Required | Example | Description |
| --- | --- | --- | --- | --- |
| userid | String | Yes | user123 | The employee's user ID in your organization. The organization uses this field to uniquely identify the user. |
| from_date | Date | Yes | 2016-03-09 11:11:11 | The start time of the leave. |
| to_date | Date | Yes | 2016-03-10 11:11:11 | The end time of the leave. |

### Request Example

```curl
curl -X POST "https://api.dingtalk.io/topapi/attendance/getleaveapproveduration" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=6777xxxx6f4eff' \
-d 'from_date=2016-03-09+11%3A11%3A11' \
-d 'to_date=2016-03-10+11%3A11%3A11' \
-d 'userid=zhangsan'
```

## Response

### Response Body

| Name | Type | Example | Description |
| --- | --- | --- | --- |
| result | ApproveDurationForTopVo |  | The returned result. |
| duration_in_minutes | Number | 0 | The leave duration, in minutes. |
| errcode | Number | 0 | The return code. |
| errmsg | String | ok | The description of the return code. |
| request_id | String | 3ynh2gp5ndke | The request ID. |
