Call this API to notify an approval undo. Supports overtime, leave request, outing, business trip, and makeup clock-in types.

## API Call Description

After you call the [Notify Approval Completion](/open/development/api-processapprovefinish) API, a submitted Approval form may need to be undone. In this case, call this API to undo the modified attendance records.

## Request

| **Basic information** | |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/topapi/attendance/approve/cancel |
| HTTP Method | POST |
| Supported app types | appType-Internal app　appType-Third-party enterprise app |
| Permissions | permission-qyapi_attendance_group_manage-Attendance group management permission |

### Query Parameters

| Name | Type | Required | Example | Description |
| --- | --- | --- | --- | --- |
| access_token | String | Yes | bE74xxxx | The App credential used to call this API.   - Internal app: Obtain it by calling the [Get the access_token of an Internal App](/open/development/obtain-orgapp-token) API. - Third-party enterprise app: Obtain it by calling the Get the access_token of a Third-Party Enterprise API. |

### Request Body

| Name | Type | Required | Example | Description |
| --- | --- | --- | --- | --- |
| userid | String | Yes | manager4220 | The employee's user ID. |
| approve_id | String | Yes | 2376620852 | The approval ID. Use the value of the custom parameter approve_id from the [Notify Approval Completion](/open/development/api-processapprovefinish) API. |

### Request Example

```curl
curl -X POST "https://api.dingtalk.io/topapi/attendance/approve/cancel" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=95676xxxxdee' \
-d 'approve_id=1234abcd' \
-d 'userid=dd_dd'
```
