Call this API to batch remove Wi-Fi information from a specified attendance group.

## Request

| **Basic Information** | |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/topapi/attendance/group/wifis/remove |
| HTTP Method | POST |
| Supported app types | appType-Internal app |
| Required permissions | permission-qyapi_attendance_group_manage-Attendance group management permission |

### Query Parameters

| Name | Type | Required | Example | Description |
| --- | --- | --- | --- | --- |
| access_token | String | Yes | 6d1bxxxx | The app credential used to call this API. Obtain it by calling the [Get the access_token of an internal app](/open/development/obtain-orgapp-token) API. |

### Request Body

| Name | Type | Required | Example | Description |
| --- | --- | --- | --- | --- |
| op_userid | String | No | user01 | The userId of the operator. |
| group_key | String | Yes | CEDDFxxxx | The attendance group ID.  **Note**  If you identify the attendance group by group_id, call the [Convert groupId to groupKey](/open/development/groupid-to-groupkey) API to convert group_id to group_key. |
| wifi_key_list | String | Yes | 0151Exxxx | The Wi-Fi keys. Obtain them by calling the [Batch query Wi-Fi information](/open/development/batch-query-wifi-under-attendance-group) API. Remove up to 100 Wi-Fi entries per call. |

### Request Example

```curl
curl -X POST "https://api.dingtalk.io/topapi/attendance/group/wifis/remove" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=deb9baxxxx32b89' \
-d 'group_key=0151E022xxxx917E876' \
-d 'op_userid=123456' \
-d 'wifi_key_list=0151E02xxxx917E876'
```

## Response

### Response Body

| Name | Type | Example | Description |
| --- | --- | --- | --- |
| result | Result |  | The list of wifiIds that were deleted successfully. |
| error_info_list | ErrorInfo[] |  | The list of failures. |
| failure_list | String[] | 0151EEDDDF0xxxx | The list of errors. |
| msg | String | business fault | The error description. |
| code | String | 1000 | The error code. |
| success_list | String[] | 0151EEDDDF0xxxx | The list of successes. |
| errcode | Number | 0 | The return code. |
| errmsg | String | ok | The return code description. |
| success | Boolean | true | Indicates whether the call succeeded.   - **true**: Success - **false**: Failed |
| request_id | String | 7o76z7s5cett | The request ID. |
