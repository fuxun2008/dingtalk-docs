---
title: "Get Shift Summaries"
description: "Call this API to query summaries of all attendance shifts in an organization by operator userId and cursor-based pagination."
---

Call this API to query all shifts. In the DingTalk Attendance app, a shift is a set of rules, such as clock-in times and break times. Organizations can configure multiple shifts based on their business needs.

## Request

| **Basic Information** | |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/topapi/attendance/shift/list |
| HTTP Method | POST |
| Supported app types | appType-Internal app　appType-Third-party enterprise app |
| Permissions | permission-qyapi_attendance_group_read-Attendance group read permission |

### Query Parameters

| Name | Type | Required | Example | Description |
| --- | --- | --- | --- | --- |
| access_token | String | Yes | bE74xxxx | The app credential used to call this API.   - For an Internal app, obtain it by calling [Get the access_token of an Internal App](/open/development/obtain-orgapp-token). - For a Third-party enterprise app, obtain it by calling the API for getting the access_token of a third-party organization. |

### Request Body

| Name | Type | Required | Example | Description |
| --- | --- | --- | --- | --- |
| op_user_id | String | Yes | manager4220 | The userId of the operator. |
| cursor | Number | No | 0 | The cursor ID. The initial value is 0. |

### Request Example

```curl
curl -X POST "https://api.dingtalk.io/topapi/attendance/shift/list" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=e47ef3ff-ff01-4da7-8aa8-53bc0ad47be3' \
-d 'cursor=1234' \
-d 'op_user_id=dd_test'
```

## Response

### Response Body

| Name | Type | Example | Description |
| --- | --- | --- | --- |
| result | PageResult |  | The query result. |
| has_more | Boolean | false | Whether more data is available.   - **true**: Yes - **false**: No |
| cursor | Number | 678215070 | The cursor position of the next page. |
| result | TopMinimalismShiftVo[] |  | The shift information.  Each page returns 200 records. Results with more than 200 records are paginated. |
| name | String | A | The shift name. |
| id | Number | 677995086 | The shift ID. |
| success | Boolean | true | Whether the request succeeded.   - **true**: Success - **false**: Failed |
| errcode | Number | 0 | The return code. |
| errmsg | String | ok | The description of the return code. |
