Call this API to grant download permission for files in the approval Drive space based on the Drive space spaceId and the file fileId.

## Request

### Basic Information

| Field | Value |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/v1.0/workflow/processInstances/spaces/files/authDownload |
| HTTP Method | POST |
| Supported app types | appType-Internal app　appType-Third-party enterprise app |
| Required permissions | permission-Workflow.Instance.Write-Workflow instance write permission |

### Request Header

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Yes | The access credential for calling this API. Obtain it as follows:   - Internal app: Call the [Get the access token of an internal app](/open/development/obtain-the-access-token-of-an-internal-app) API. - Third-party enterprise app: Call the API for obtaining the access token of an organization that authorized the third-party app. |

### Request Body

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| userId | String | Yes | The userId of the user to authorize. |
| fileInfos | Array | Yes | The list of Drive files to authorize. Batch authorization is supported. The list can contain up to 10 items. |
| fileId | String | Yes | The file fileId. Call the [Get the details of a single approval instance](/open/development/obtains-the-details-of-a-single-approval-instance-pop) API to get the `fileId` value.      The file ID is the fileId of the file uploaded in the approval component. |
| spaceId | Long | Yes | The approval Drive space spaceId. Call the [Get approval Drive space information](/open/development/obtains-the-information-about-approval-nail-disk) API to get the `spaceId` value. |
