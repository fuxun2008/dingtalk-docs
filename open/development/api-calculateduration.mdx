Call this API to pre-calculate an employee's overtime, business trip, and leave durations based on scheduling in the attendance system.

## API Call Description

For example, an employee is scheduled to work on November 2 (start time 09:00, end time 18:00) and has a day off on November 3.

The employee plans to take leave from 09:00:00 on November 2 to 18:00:00 on November 3. Call this API to get the expected leave duration within this range. The result is only one day.

- If an employee is not in an attendance group or has no shift scheduled on the leave date, the leave duration is calculated based on the default attendance time.
- Configure the default attendance time at **DingTalk mobile > Workbench > Attendance > Settings > More Settings > Leave and Attendance Approval > Default Attendance Time**. For example:

  An employee is scheduled to work on November 2 (start time 09:00, end time 18:00) and has no shift scheduled on November 3. The default shift is 08:30–17:30. The employee plans to take leave from 09:00:00 on November 2 to 18:00:00 on November 3. Call this API to get the expected leave duration within this range. The result is 2 days.

### Basic Information

| Field | Value |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/v1.0/attendance/approvals/durations/calculate |
| HTTP Method | POST |
| Supported app types | appType-Internal app　appType-Third-party enterprise app |
| Required permissions | permission-qyapi_attendance_group_read-Attendance group query permission |

### Request Header

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Yes | The access credential for calling this API. Obtain it as follows:   - Internal app: call the [Get the access token of an internal app](/open/development/obtain-the-access-token-of-an-internal-app) API. - Third-party enterprise app: call the API for getting the access token of an organization that has authorized the third-party app. |

### Query Parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| userId | String | No | The userId of the user. |

### Request Body

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| bizType | Long | No | Approval form type:   - 1: Overtime - 2: Business trip - 3: Leave |
| fromTime | String | No | Start time. The start time cannot be more than 31 days before the current time. Supported formats:   - 2019-08-15 - 2019-08-15 AM - 2019-08-15 12:43 |
| toTime | String | No | End time.   - When biz_type is 1, the end time minus the start time cannot exceed 1 day. - When biz_type is 2 or 3, the number of days between the start time and the end time cannot exceed 31.   Supported formats:   - 2019-08-15 - 2019-08-15 AM - 2019-08-15 12:43 |
| durationUnit | String | No | Duration unit. Supported values:   - day - halfDay - hour: When biz_type is 1, only hour is supported.   The time format must match the duration unit:   - 2019-08-15 corresponds to day - 2019-08-15 AM corresponds to halfDay - 2019-08-15 12:43 corresponds to hour |
| calculateModel | Long | No | Calculation method:   - 0: By calendar day - 1: By working day |
| leaveCode | String | No | Unique identifier of the leave rules. Optional. Applies only when bizType=3 (leave). If specified, the duration is rounded according to the rounding rule configured for the leave type. |
