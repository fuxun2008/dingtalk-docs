Call this API to get a paginated list of approval forms visible to an employee based on the employee's userId. Each call returns up to 100 forms.

## Request

### Basic Information

| Field | Value |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/v1.0/workflow/processes/userVisibilities/templates |
| HTTP Method | GET |
| Supported app type | appType-Internal app |
| Required permissions | permission-Workflow.Form.Read-Workflow template read permission |

### Request Header

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Yes | The access credential for calling this API. Get it by calling the [Get the access token of an Internal app](/open/development/obtain-the-access-token-of-an-internal-app) API. |

### Query Parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| userId | String | No | The userId of the employee to query. If not specified, all approval forms in the organization are returned. |
| maxResults | Long | Yes | The page size. Maximum value: 100. |
| nextToken | Long | Yes | The pagination cursor. - For the first call, set this parameter to 0. - For subsequent calls, set this parameter to the nextToken returned by the previous call. |
