---
title: "Set up the quick entry of a single-chat bot"
description: "Call this API to configure a single-chat bot's quick entry, including entry name, title, and PC and mobile redirect links, improving how quickly users can reach the bot."
---

Call this API to set up the quick entry for adding a single-chat bot. The configuration includes the entry name, title, PC redirect link, and mobile redirect link. This API is suitable for scenarios where an organization needs to quickly configure a bot entry to improve user reach.

## Request

### Basic information

| Field | Value |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/v1.0/robot/plugins/set |
| HTTP Method | POST |
| Supported app types | appType-Internal app |
| Permissions | permission-Robot.SingleChat.ReadWrite-Single-chat bot management permission |

### Request headers

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Yes | The access credential used to call this API. Obtain it by calling the [Get the access token of an internal app](/open/development/obtain-the-access-token-of-an-internal-app#) API. |

### Request body

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| robotCode | String | No | The code of the bot. See the `robotCode` section in the [Bot glossary](https://open.dingtalk.com/document/development/robot-overview#) to obtain the `robotCode`. |
| pluginInfoList | Array | No | The list of plugins. |
| pcUrl | String | No | The redirect link of the chat quick entry on the PC client. |
| mobileUrl | String | No | The redirect link of the quick entry on the mobile client. |
| name | String | Yes | The name of the quick entry. Internationalization is supported, for example, `{"en_US":"test123","zh_CN":"测试123"}`. |
| icon | String | Yes | The icon ID of the quick entry. Obtain the `mediaId` parameter by calling the [Upload media files](/open/development/upload-media-files#) API. |
