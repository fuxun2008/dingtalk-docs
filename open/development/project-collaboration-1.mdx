This topic describes the use cases of DingTalk group chat bots for project collaboration and progress synchronization.

## Basic usage — Push task progress through cards

By combining text and images, you can clearly display the current stage progress and related information, enabling transparent project collaboration.

As shown in the figure, the card supports the @ People feature to specify who is responsible for each task, providing clear visibility at a glance. The View details button at the bottom of the card also allows users to navigate to a specific page to view detailed information.

## Advanced usage — Real-time interaction with responsive cards

As shown in the figure, when a task is claimed by someone, the card can be refreshed instantly to notify others in the group that the task has been accepted.

## Advanced usage — Confirm that critical information has been received

As shown in the figure, when pushing critical information, you may want to confirm in real time whether the target users have read the information. To achieve this, you can place a Confirm receipt button at the bottom of the information card and require all recipients to click the button after reading the message. This way, the business system that pushes the information can collect and track in real time who has read the message and who has not, and then send targeted follow-up notifications.

## Advanced usage — Send a second reminder through targeted visible Chats

In many collaboration scenarios, due to the large volume of information, some users may miss certain messages. For example, a user may miss a task assignment because they did not see the message in time.

Building on the previous solution, you can take a further step. After pushing a reminder visible to all members, if the target user does not confirm receipt promptly, you can push another reminder visible only to that user in the group, urging them to accept the task and respond as soon as possible. If the user confirms receipt on this targeted message, the original card visible to all members can also be refreshed in real time to indicate that the user has confirmed.

In another scenario, if a User creates a task and assigns it to multiple Colleagues in the group, you can use the same targeted visible message logic to synchronize progress. For example, one hour after the task is created, a Card message visible only to the creator can be pushed to notify them that the task has been confirmed by all assignees.
