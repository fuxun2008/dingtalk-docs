Call this API to query an employee's action permissions in an attendance group.

## Request

### Basic Information

| Field | Value |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/v1.0/attendance/writePermissions/query |
| HTTP Method | POST |
| Supported app types | appType-Internal app　appType-Third-party enterprise app |
| Required permissions | permission-Attendance.Permission.Read-Read permission on attendance authorization information |

### Request Header

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Yes | The access credential for calling this API.   - For an Internal app, call [Get the access token of an internal app](/open/development/obtain-the-access-token-of-an-internal-app) to obtain it. - For a Third-party enterprise app, call the API that gets the access token of an organization that authorized the Third-party app. |

### Request Body

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| opUserId | String | Yes | The employee's userId. |
| category | String | Yes | The resource type:   - **GROUP**: Attendance group. Only this value is currently supported. |
| resourceKey | String | Yes | The permission scope:   - **GROUP_MEMBER**: Set attendance members - **GROUP_NAME**: Change the attendance group name - **GROUP_TYPE**: Set the attendance group type - **CHECK_TIME**: Set attendance time - **SCHEDULE**: Employee scheduling - **CHECK_POSITION_TYPE**: Set the clock-in method - **OVER_TIME_RULE**: Set overtime rules - **CAMERA_CHECK**: Photo verification rules - **OUT_SIDE_CHECK**: Set field clock-in - **MANAGE**: Attendance group sub-administrator - **OWNER**: Attendance group primary administrator - **DELETE_GROUP**: Delete the attendance group |
| entityIds | Array of Long | Yes | The resource IDs. If category is GROUP, pass the attendance group IDs. Call [Get a user's attendance group](/open/development/queries-a-user-attendance-group) to obtain the group_id value. |
