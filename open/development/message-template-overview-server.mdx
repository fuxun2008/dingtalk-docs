Message templates are an upgrade to pushing messages via Work Notifications. They provide a more streamlined and standardized development and configuration experience for message templates, while also delivering more secure, manageable, and controllable message notification capabilities to customers.

**Note**

Keep the following in mind when using message templates:

- Only **third-party enterprise apps** are supported.
- Only approved message templates can be used to push Work Notifications messages.

## Template Types

The following three message template types are currently supported.

- Markdown Template

  The Markdown template uses Markdown syntax to configure and send messages. It is suitable for pure notification messages that require no action. With the Markdown template, you can easily support text, images, links, and other display formats.
- ActionCard Template

  The ActionCard template sends messages using the ActionCard message type. It supports messages that combine content with action points, and is suitable for scenarios where one or more action points are needed to quickly handle tasks within a message.

  Building on the Markdown template, the ActionCard template supports both overall jump and independent jump styles.
- Form Template

  The Form template sends messages based on the OA message type. It is suitable for displaying messages such as orders and supports jumping to view message details.

As shown in the figure below, sending Work Notifications using message templates requires the following steps:

2. Get the template approved.
3. Call the API for sending Work Notifications with a template. For details, see [Send Work Notifications Messages Using a Template](/zh/open/development/work-notification-templating-send-notification-interface).
