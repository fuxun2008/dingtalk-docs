Call this API to batch add Wi-Fi information to a specified attendance group.

## Request

| **Basic Information** | |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/topapi/attendance/group/wifis/add |
| HTTP Method | POST |
| Supported app type | appType-Internal app |
| Permissions | permission-qyapi_attendance_group_manage-Attendance group management permission |

### Query Parameters

| Name | Type | Required | Example | Description |
| --- | --- | --- | --- | --- |
| access_token | String | Yes | 1eb68xxx | The App credential used to call this API. Obtain it by calling [Get the access_token of an Internal App](/open/development/obtain-orgapp-token). |

### Request Body

| Name | Type | Required | Example | Description |
| --- | --- | --- | --- | --- |
| op_userid | String | No | user01 | The user ID of the operator. |
| group_key | String | Yes | 0151E0xxx | The attendance group ID.  **Note**  If your attendance group identifier is group_id, call [Convert groupId to groupKey](/open/development/groupid-to-groupkey) to convert group_id to group_key. |
| wifi_list | Wifi[] | Yes |  | The Wi-Fi list. Add up to 100 Wi-Fi entries per call. |
| foreign_id | String | Yes | alibaba-inc | The business-side Wi-Fi ID. |
| mac_addr | String | Yes | 11:11:11:11:11:11 | The MAC address. |
| ssid | String | Yes | alibaba-inc1 | The name. |

### Request Example

```curl
curl -X POST "https://api.dingtalk.io/topapi/attendance/group/wifis/add" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=b040xxxx34a60' \
-d 'group_key=0151E02xxxx17E876' \
-d 'op_userid=123456' \
-d 'wifi_list=null'
```
