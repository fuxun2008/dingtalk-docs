Call this API to create a leave rule.

## API Call Description

This API creates two types of leave rules:

- General leave rules, such as personal leave and marriage leave. The balance of these rules can be modified. After you create a general leave rule with this API, the balance defaults to 0. Call the [Initialize Leave Balance](/open/development/initialize-holiday-balance) API to initialize the leave balance.
- Compensatory leave rules. For compensatory leave added with this API, the default balance rule is **Overtime duration automatically counts toward the compensatory leave balance**. You do not need to call the balance initialization API.

The equivalent settings in the DingTalk Admin Console are under **Leave Management** > **Leave Rules**. Click **Add Leave** to open the **New Leave** dialog, which contains these fields:

| Field | Description / Options |
|---|---|
| **Leave Name** | Enter the leave name |
| **New Employee Leave** | e.g. **Can take leave upon onboarding** |
| **Applicable Scope** | e.g. **Entire Company** (editable) |
| **Paid** | **Paid** or **Unpaid**; paid leave is counted as attendance in statistics |
| **Minimum Leave Unit** | e.g. **By Day** |
| **Leave Duration Calculation** | e.g. **Calculate by Working Days** (excludes the employee's rest days, such as unscheduled weekends and statutory holidays) |

The **Leave Duration Calculation Rules** section groups the **Minimum Leave Unit** and **Leave Duration Calculation** settings. Click **Save** to create the rule.
