Call this API to process a single approval task based on the specified template ID, approval instance ID, task node ID, and operator userId.

## API Call Description

1. An approval process can contain multiple approval nodes, and a single approval node can contain one or more approval tasks. Processing a single approval task does not necessarily end the approval process.

   - If the approval process has only one approver, approving or rejecting the single approval task ends the approval process.

     A typical **Approval process** runs as an ordered flow: **Submit request** (by the initiator) > **approver** > **CC recipient**.
   - If the approval process has multiple approvers, the entire approval process depends on multiple tasks.

     - Rejecting a single approval task ends the approval process.
     - Approving a single approval task moves the approval process to the next approver.

       An approval node can require multiple approvers in one of two modes: **Countersign**: all listed members must **Accept** for the node to pass. **Or-sign**: approval by any one of the listed members is enough for the node to pass.
2. To add attachments to approval comments, upload the files to the approval Drive space. This provides the API parameters spaceId, fileType, fileName, fileId, and fileSize. Obtain them as follows:

   1. Call the [Obtain Approval Drive Space Information](/open/development/obtains-the-information-about-approval-nail-disk) API to get upload permissions for the Drive space and obtain the approval Drive space spaceId.
   2. Using the approval Drive space spaceId, upload attachments to Drive or select files from Drive in a web app (H5 Micro app) or Mini program to obtain the Drive attachment file information.

### Request Body

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| processInstanceId | String | Yes | The approval instance ID:   - Call the [Create an Approval Instance](/open/development/create-an-approval-instance) API to obtain the `InstanceId` parameter value. - Call the [Obtain a List of Approval Instance IDs](/open/development/obtain-an-approval-list-of-instance-ids) API to obtain the `list` parameter value. |

| result | String | Yes | The approval action. Valid values:   - **agree**: Approve - **refuse**: Reject |
| actionerUserId | String | Yes | The operator's userId. Call the [Obtain the Details of a Single Approval Instance](/open/development/obtains-the-details-of-a-single-approval-instance-pop) API to obtain the `userId` parameter value. |

| file | Object | No | The file. |
| photos | Array of String | No | The image URLs. Maximum length: 1,024 characters. |
| attachments | Array | No | The attachment list. Maximum number of elements: 20. |
| spaceId | String | No | The Drive space ID.      See the API call description in this topic. |
| fileSize | String | No | The file size.      See the API call description in this topic. |
| fileId | String | No | The file ID. Maximum length: 256 characters.      See the API call description in this topic. |
