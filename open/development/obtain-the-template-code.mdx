Call this API to get the processCode of an approval template by its name.

## Request

### Basic Information

| Field | Value |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/v1.0/workflow/processCentres/schemaNames/processCodes |
| HTTP Method | GET |
| Supported app types | appType-Internal app　appType-Third-party enterprise app |
| Required permissions | permission-Workflow.Form.Read-Workflow template read permission |

### Request Header

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Yes | The access credential for calling this API. Get it as follows:   - Internal app: Call the [Get the access token of an internal app](/open/development/obtain-the-access-token-of-an-internal-app) API. - Third-party enterprise app: Call the API for getting the access token of an organization that authorized a third-party app. |

### Query Parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| name | String | Yes | The template name. Maximum length: 64 characters. Get it from the form template name field `name` in the request parameters of the API for creating or updating an approval template. |
