Call this API to get all approval forms that a user can manage in the current organization.

## Request

### Basic Information

| Field | Value |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/v1.0/workflow/processes/managements/templates |
| HTTP Method | GET |
| Supported app types | appType-Internal app |
| Permissions | permission-Workflow.Form.Read-Workflow template read permission |

### Request Headers

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Yes | The access credential for calling this API. Obtain it by calling the [Get the access token of an Internal app](/open/development/obtain-the-access-token-of-an-internal-app) API. |

### Query Parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| userId | String | Yes | The userId of the user.  **Note**  The user corresponding to the userId must have OA Approval permissions in the organization. |
