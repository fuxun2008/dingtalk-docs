Call this API to query the details of a shift by shift ID, such as the shift name, clock-in times, and break periods.

## Request

| **Basic Information** | |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/topapi/attendance/shift/query |
| HTTP Method | POST |
| Supported app types | appType-Internal app　appType-Third-party enterprise app |
| Permissions | permission-qyapi_attendance_group_read-Attendance group query permission |

### Query Parameters

| Name | Type | Required | Example | Description |
| --- | --- | --- | --- | --- |
| access_token | String | Yes | bE74xxxx | The App credential used to call this API.   - For an Internal app, call the [Get the access_token of an Internal App](/open/development/obtain-orgapp-token) API to obtain it. - For a Third-party enterprise app, call the Get the access_token of a Third-party Enterprise App API to obtain it. |

### Request Body

| Name | Type | Required | Example | Description |
| --- | --- | --- | --- | --- |
| op_user_id | String | Yes | user123 | The userId of the operator. |
| shift_id | Number | Yes | 678215070 | The shift ID. Call the [Get Shift Summaries](/open/development/enterprise-shift-query-in-batches) API to obtain the value of the id parameter. |

### Request Example

```curl
curl -X POST "https://api.dingtalk.io/topapi/attendance/shift/query" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=d946568c-08dd-44bf-acd3-cfc07d7829dd' \
-d 'op_user_id=dd_dd' \
-d 'shift_id=2445'
```
