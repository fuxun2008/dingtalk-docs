---
title: "Update Clock-In Time Window Settings"
description: "Call this API to update the clock-in time window settings of an attendance shift and specify whether clock-in is required at a check point."
---

Call this API to update the clock-in time settings of an attendance shift. This API currently supports only specifying whether clock-in is required at a check point.

## Request

| **Basic Information** | |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/topapi/attendance/shift/updatepunches |
| HTTP Method | POST |
| Supported App Type | appType-Internal app |
| Required Permissions | permission-qyapi_attendance_group_manage-Attendance group management permission |

### Query Parameters

| Name | Type | Required | Example | Description |
| --- | --- | --- | --- | --- |
| access_token | String | Yes | af21axxx | The App credential used to call this API. Obtain it by calling the [Get the access_token of an Internal App](/open/development/obtain-orgapp-token) API. |

### Request Body

| Name | Type | Required | Example | Description |
| --- | --- | --- | --- | --- |
| op_user_id | String | Yes | user456 | The userId of the operator. |
| punches | TopPunchVO[] | No |  | The check point information. |
| id | Number | Yes | 123 | The check point ID. Obtain the id value by calling the [Get Shift Details](/open/development/shift-query) API. |
| free_check | Boolean | Yes | true | Specifies whether clock-in is not required.   - **true**: Clock-in exemption is on. - **false**: Clock-in exemption is off. |
| shift_id | Number | Yes | 456 | The shift ID. Obtain the id value by calling the [Get Shift Summaries](/open/development/enterprise-shift-query-in-batches) API. |

### Request Example

```curl
curl -X POST "https://api.dingtalk.io/topapi/attendance/shift/updatepunches" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=16869xxx0e890' \
-d 'op_user_id=dd' \
-d 'punches=null' \
-d 'shift_id=456'
```

## Response

### Response Body

| Name | Type | Example | Description |
| --- | --- | --- | --- |
| success | Boolean | true | Indicates whether the call succeeded.   - **true**: Success - **false**: Failed |
| errcode | Number | 0 | The return code. |
| errmsg | String | System error | The error message returned when the call fails. |
| request_id | String | 5moh5icna65x | The request ID. |
