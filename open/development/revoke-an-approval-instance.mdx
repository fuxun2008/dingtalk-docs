title: "Revoke an Approval Instance"
description: "Call this API to revoke an in-progress approval instance by its approval instance ID. Optionally specify the operator and a termination remark."
---

Call this API to revoke an approval instance that is still in progress.

## API Call Description

- An approval process cannot be revoked within 15 seconds after it is initiated.
- When the isSystem parameter is set to false (terminated by a specified operator), pass the initiator to revoke the approval instance.
- This API revokes only in-progress approval instances. It cannot revoke approval instances whose approval is complete.
- Before calling this API, go to the [DingTalk Admin Console](https://oa.dingtalk.io/) > **Workbench > App Management > OA Approval App** and open the **OA Approval Admin Console**. Find **Template > Premium Settings > Undo/Modify Approval Form** and select **Allow submitter to undo in-progress approval forms**. Otherwise, the call fails with `errcode:820008, success:false, errmsg:Approval system error` because you do not have permission to process the task.

## Request

### Basic Information

| Field | Value |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/v1.0/workflow/processInstances/terminate |
| HTTP Method | POST |
| Supported app types | appType-Internal app |
| Required permissions | permission-Workflow.Instance.Write-Workflow instance write permission |

### Request Header

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Yes | The access credential for calling this API. Call the [Get the access token of an Internal app](/open/development/obtain-the-access-token-of-an-internal-app) API to obtain it. |

### Request Body

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| processInstanceId | String | Yes | The approval instance ID.   - Call the [Create an approval instance](/open/development/create-an-approval-instance) API to obtain the `InstanceId` parameter value. - Call the [Get a list of approval instance IDs](/open/development/obtain-an-approval-list-of-instance-ids) API to obtain the `list` parameter value. |
| isSystem | Boolean | No | Specifies whether the action is performed by the system.   - **true**: The system terminates the instance directly. - **false**: A specified operator terminates the instance (pass the initiator to undo it). |
| remark | String | No | The termination remark. Maximum length: 1,024 characters. |
| operatingUserId | String | No | The userId of the operator.      This parameter is required when isSystem is false (pass the initiator to undo the instance). |
