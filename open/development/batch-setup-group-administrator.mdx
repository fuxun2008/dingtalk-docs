---
title: "Set group admins in bulk"
description: "Call this API to batch assign or revoke admin roles for users in an enterprise group chat, ideal for large groups or organizational restructuring."
---

Call this API to assign multiple users in an organization's group chat as admins in bulk, or to revoke the admin role from multiple users in bulk. This API is suitable for scenarios where the organization's group chat is large and admins need to be adjusted in bulk to improve management efficiency, or when the organizational structure is adjusted and group admins need to be reassigned.

## Permissions

To call this API, one of the following permissions is required.

| App type | Supported | Permissions | API Explorer debugging |
| --- | --- | --- | --- |
| Internal app | Supported | Permissions to manage basic information about DingTalk groups | [API Explorer](https://open-dev.dingtalk.io/apiExplorer#/?devType=org&api=im_1.0%23ChatSubAdminUpdate) |
| Third-party enterprise app | Not supported | Not supported | Not supported |
| Third-party personal app | Not supported | Not supported | Not supported |

## HTTP method

```http
POST /v1.0/im/subAdministrators HTTP/1.1
Host:api.dingtalk.io
x-acs-dingtalk-access-token:String
Content-Type:application/json

{
  "openConversationId" : "String",
  "userIds" : [ "String" ],
  "role" : Integer
}
```

## Header parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Yes | The access credential for calling this API. To obtain it, call the [Get the access token of an internal app](/open/development/obtain-the-access-token-of-an-internal-app) API. |

## Body parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| openConversationId | String | Yes | The open group ID. To obtain the value of `openConversationId`, call the [Create a group chat](/open/development/create-common-group-new-version-v2) API. |
| userIds | Array of String | Yes | The list of `userid` values of employees in the organization. To obtain the value of `userid_list`, call the [Query the list of department user IDs](/open/development/query-the-list-of-department-userids) API. |
| role | Integer | Yes | The operation type. Valid values:   - **2**: Add as an admin. - **3**: Remove from admins. |

## Response parameters

| Name | Type | Description |
| --- | --- | --- |
| success | String | Whether the call was successful:   - **true**: Success. - **false**: Failed. |
