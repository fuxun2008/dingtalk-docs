---
title: "Add a folder"
---

Call this API to add a folder in a storage space.

## API call description

After adding a storage space, call this API to add a folder in the space.

- When the storage space type is USER, all users with permissions on the space have operation permissions. Other employees must call the [Add permissions](/open/development/add-permissions-file) API to grant authorization.
- When the storage space type is APP, anyone performing the operation must call the [Add permissions](/open/development/add-permissions-file) API to grant authorization.

## Request

### Basic information

| Field | Value |
| --- | --- |
| HTTP URL | `https://api.dingtalk.io/v1.0/storage/spaces/{spaceId}/dentries/{parentId}/folders` |
| HTTP Method | POST |
| Supported app types | appType-Internal app　appType-Third-party enterprise app |
| Permission required | permission-Storage.File.Write-Organization storage file write permission |

### Request header

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Yes | The access credential for calling this API. Obtain it as follows:   - For an internal app, call the [Get the access token of an internal app](/open/development/obtain-the-access-token-of-an-internal-app#) API to obtain it. - For a third-party enterprise app, call the [Get the access token of an enterprise authorized to a third-party app](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#) API to obtain it. |

### Path parameter

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| spaceId | String | Yes | The space ID. Call the [Add a space](/open/development/add-space#) API to obtain the value of the id parameter. |
| parentId | String | Yes | The parent directory ID. Call the [Get the list of files or folders](https://open.dingtalk.com/document/development/obtain-the-file-list-storage#) API to obtain it. For the root directory, set this parameter to 0. |

### Query parameter

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| unionId | String | Yes | The unionId of the operator. Call the [Query user details](/open/development/query-user-details#) API to obtain it. |

### Request body

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| name | String | Yes | The name of the folder. Naming requirements:- No leading or trailing spaces. Otherwise, they are automatically removed. - No special characters, including: tab, `*`, `"`, `<`, `>`, `|`. - Cannot end with `.`. |
| option | Object | No | Optional parameters. |
| conflictStrategy | String | No | The conflict strategy for folder names.   - **AUTO_RENAME**: Automatically rename. Default value. - **OVERWRITE**: Overwrite. - **RETURN_DENTRY_IF_EXISTS**: Return the existing folder. - **RETURN_ERROR_IF_EXISTS**: Return an error if the folder already exists. |
| appProperties | Array | No | The app property list of the current folder. Maximum value: 3. |
| name | String | Yes | The property name. |
| value | String | Yes | The property value. |
| visibility | String | Yes | The property visibility.   - **PUBLIC**: Visible to all apps. - **PRIVATE**: Visible only to the current app. |
