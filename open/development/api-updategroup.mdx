---
title: "Update a group chat"
---

Call this API to update the basic information and members of a specified group chat by chatid. Use it to modify group-related information, including the group name, group owner, member list, and group profile photo. It applies to scenarios such as a group admin modifying group settings or adjusting group members.

## Request

### Basic information

| Field | Value |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/v1.0/im/group/update |
| HTTP Method | POST |
| Supported app types | appType-Internal app |
| Required permissions | permission-qyapi_chat_manage-DingTalk group basic information management permission |

### Request headers

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Yes | The access credential for calling this API. Obtain it through the [Get the access token of an internal app](https://open.dingtalk.io/document/development/obtain-the-access-token-of-an-internal-app) API. |

### Request body

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| chatid | String | Yes | The group chat ID. Obtain it from the chatid parameter returned by the [Create a group chat](https://open.dingtalk.io/document/development/create-common-group-new-version-v2) API.  The chatid obtained by calling the frontend JSAPI is not supported. |
| name | String | No | The group name. Length: 1 to 20 characters. |
| owner | String | No | The userId of the group owner. Obtain the userId through the [Query users by phone number](https://open.dingtalk.io/document/development/query-users-by-phone-number) API.  The user must be one of the members in the useridlist of the chat. |
| ownerType | String | No | The group owner type.   - **emp**: Organization employee - **ext**: External contacts |
| add_useridlist | Array of String | No | The userId list. |
| del_useridlist | Array of String | No | The userId list. |
| add_extidlist | Array of String | No | The unionId list. Obtain it through the [Query user details](https://open.dingtalk.io/document/development/query-users-by-phone-number) API. |
| del_extidlist | Array of String | No | The unionId list. Obtain it through the [Query user details](https://open.dingtalk.io/document/development/query-users-by-phone-number) API. |
| icon | String | No | The mediaId of the group profile photo. Obtain the media_id parameter through the [Upload media files](https://open.dingtalk.io/document/development/upload-media-files) API. |
| managementOptions | Object | No | The group attributes. |
| mentionAllAuthority | Integer | No | The usage scope of @all.   - **0** (default): All members can use @all. - **1**: Only the group owner can use @all. |
| showHistoryType | Integer | No | Whether new members can view the last 100 historical chats.   - **1**: Allowed. - **0**: Not allowed.   If not specified, new members cannot view historical chats. |
| validationType | Integer | No | Whether validation is required to join the group.   - **0** (default): No validation. - **1**: Validation required. |
| searchable | Integer | No | Whether the group can be searched.   - 0 (default): Not searchable. - 1: Searchable. |
| chatBannedType | Integer | No | Whether to enable mute members for the group.   - **0** (default): Not muted. - **1**: Mute All. |
| managementType | Integer | No | The group management type.   - **0** (default): All members can manage. - **1**: Only the group owner can manage. |
