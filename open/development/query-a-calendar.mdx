Call this API to list a user's calendars.

## Request

### Basic information

| Field | Value |
| --- | --- |
| HTTP URL | `https://api.dingtalk.io/v1.0/calendar/users/{userId}/calendars` |
| HTTP Method | GET |
| Supported app types | appType-Internal app　appType-Third-party enterprise app　appType-Third-party personal app |
| Required permissions | permission-Calendar.Event.Read-Read permission for calendars in the Calendar app |

### Request headers

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Yes | The access credential for calling this API. Obtain it as follows:   - For an internal app, call the [Get the access token of an internal app](/open/development/obtain-the-access-token-of-an-internal-app#) API. - For a third-party enterprise app, call the [Get the access token of an organization authorized to a third-party app](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#) API. - For a third-party personal app, call the [Get a user token](/open/development/obtain-user-token#) API. |

### Path parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| userId | String | Yes | The unionId of the target user.   - For an internal app or a third-party enterprise app, call the [Query user details](/open/development/query-user-details#) API to obtain the value of the unionid parameter. - For a third-party personal app, call the [Get a user's contact profile](/open/development/dingtalk-retrieve-user-information#) API to obtain the value of the unionId parameter. |

### Response body

| Name | Type | Description |
| --- | --- | --- |
| response | Object | The calendar information. |
| calendars | Array | The list of calendars. |
| id | String | The calendar ID. |
| summary | String | The calendar title. |
| description | String | The calendar description. |
| timeZone | String | The time zone name in the **IANA Time Zone Database** standard format, for example, `Asia/Shanghai`.      The time zone for all-day events is fixed to UTC. The default time zone for non-all-day events is `Asia/Shanghai`. |
| eTag | String | The eTag of the event resource, used to detect whether the event and the events within it have been updated. |
| type | String | The calendar type.   - **unknown**: Unknown type. - **primary**: The primary calendar of a user or app. - **subscribed**: A subscribed calendar created by a user or app (no attendees). - **shared**: A standard shared calendar created by a user or app. |
| privilege | String | The permission information.   - **free_busy_reader**: View free/busy status. - **title_reader**: View titles. - **reader**: View details. - **writer**: Edit. - **owner**: Manage and configure sharing relationships. |
