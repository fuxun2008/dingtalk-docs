Call this API to obtain the list of nodes.

## Request

### Basic information

| Field | Value |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/v2.0/wiki/nodes |
| HTTP Method | GET |
| Supported app types | appType-Internal app　appType-Third-party enterprise app |
| Required permissions | permission-Wiki.Node.Read-Knowledge Base node read permission |

### Request headers

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Yes | The access credential for calling this API. Obtain it in one of the following ways:   - For an internal app, call the [Obtain the access token of an internal app](/open/development/obtain-the-access-token-of-an-internal-app#) API. - For a third-party enterprise app, call the [Obtain the access token of an authorized enterprise for a third-party app](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#) API. |

### Query parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| parentNodeId | String | Yes | The parent node ID (parent node dentryUuid). Obtain it from the `rootNodeId` field returned by the [Get the knowledge base list](/open/development/get-knowledge-base-list#) API. |
| nextToken | String | No | The pagination cursor. Leave it empty for the first request. |
| maxResults | Integer | No | The page size. Default: 50. Maximum: 50. |
| withPermissionRole | Boolean | No | Whether to return permission information:   - true: Return permissions. - false: Do not return permissions.     Default: false. |
| operatorId | String | Yes | The unionId of the operator. |
