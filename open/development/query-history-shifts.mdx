---

Call this API to query shift history by shift ID and version. The response includes the shift name, shift settings, clock-in times, and break times.

## Request

| **Basic information** | |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/topapi/attendance/shift/history/query |
| HTTP Method | POST |
| Supported app types | appType-Internal app |
| Permissions | permission-qyapi_attendance_group_read-Attendance group query permission |

### Query Parameters

| Name | Type | Required | Example | Description |
| --- | --- | --- | --- | --- |
| access_token | String | Yes | 73e9xxx | The app credential used to call this API. Obtain it by calling the [Get the access_token of an Internal App](/open/development/obtain-orgapp-token) API. |

### Request Body

| Name | Type | Required | Example | Description |
| --- | --- | --- | --- | --- |
| op_user_id | String | Yes | user123 | The userId of the operator. |
| shift_id | Number | Yes | 628380875 | The shift ID. Obtain the id value by calling the [Get Shift Summaries](/open/development/enterprise-shift-query-in-batches) API. |
| version | Number | Yes | 624190327 | The shift version. Obtain the shift_version value by calling the [Batch Query User Scheduling Information](/open/development/query-batch-scheduling-information) API. |

### Request Example

```curl
curl -X POST "https://api.dingtalk.io/topapi/attendance/shift/history/query" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=e56f7xxxxeb7ef1' \
-d 'op_user_id=dd_dd' \
-d 'shift_id=2445' \
-d 'version=222'
```
