Call this API to transfer an OA Approval task.

## API Call Description

<Note>
This API supports only tasks from approvals initiated through official approval or native approval processes. It does not support instance tasks created by custom approvals.
</Note>

To add an approval attachment, upload the file to the approval Drive space. This provides the spaceId, fileType, fileName, fileId, and fileSize parameters. Follow these steps:

1. Call the [Get Approval Drive Space Information](/open/development/obtains-the-information-about-approval-nail-disk) API to obtain upload permissions for the Drive space and the spaceId of the approval Drive space.
2. Using the spaceId of the approval Drive space, upload the attachment to Drive or select a file from Drive in your web app (H5 Micro app) or Mini program to obtain the information of the Drive attachment file.

## Request

### Basic Information

| Field | Value |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/v1.0/workflow/tasks/redirect |
| HTTP Method | POST |
| Supported app types | appType-Internal app　appType-Third-party enterprise app |
| Permissions | permission-Workflow.Instance.Write-Workflow instance write permission |

### Request Header

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Yes | The access credential for calling this API. Obtain it as follows:   - Internal app: Call the [Get the Access Token of an Internal App](/open/development/obtain-the-access-token-of-an-internal-app) API. - Third-party enterprise app: Call the API that obtains the access token of an organization that has authorized the Third-party app. |

### Request Body

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| taskId | Long | Yes | The OA Approval task ID. Use the taskId value returned by the [Get the Details of a Single Approval Instance](/open/development/obtains-the-details-of-a-single-approval-instance-pop) API. |
| toUserId | String | Yes | The userId of the user to whom the OA Approval task is transferred. |
| remark | String | No | The transfer remark. Maximum length: 256 characters. |
| operateUserId | String | Yes | The userId of the operator. It must match the current assignee of the task. Otherwise, verification fails. |
| actionName | String | No | The action node name. Maximum length: 128 characters. |
| file | Object | No | The file. |
| photos | Array of String | No | The image URLs. Maximum length: 1,024 characters. |
| attachments | Array | No | The attachment List. Maximum number of elements: 20. |
| spaceId | String | No | The Drive space ID.      See the API Call Description section of this document. |
| fileSize | String | No | The file size.      See the API Call Description section of this document. |
| fileId | String | No | The file ID. Maximum length: 256 characters.      See the API Call Description section of this document. |
| fileName | String | No | The file name. Maximum length: 256 characters.      See the API Call Description section of this document. |
| fileType | String | No | The file type.      See the API Call Description section of this document. |
