---
title: "Query block elements"
description: "Call this API to query first-level block elements under the document root, with filtering by start/end position and block type."
---

Call this API to query the first-level block elements under a document, that is, the block elements directly under the root node. The query supports filtering by start/end position and block type.

## API call description

For details about the data structures related to document content, see [Document data structure](/open/development/document-data-structure).

## Request

### Basic information

| Field | Value |
| --- | --- |
| HTTP URL | `https://api.dingtalk.io/v1.0/doc/suites/documents/{docKey}/blocks` |
| HTTP Method | GET |
| Supported app type | appType-Internal app |
| Required permissions | permission-Storage.File.Read-Read permission for organization storage files |

### Request headers

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Yes | The access credential used to call this API. Obtain it by calling the [Get the access token of an internal app](/open/development/obtain-the-access-token-of-an-internal-app) API. |

### Path parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| docKey | String | Yes | The document ID (the `docKey` or `dentryUuid` of the document). After you create a document by calling the [Create a Knowledge Base document](/open/development/create-team-space-document) API, obtain the `docKey` from the response. Alternatively, get the `dentryUuid` from the document URL. For example, in https://alidocs.dingtalk.io/i/nodes/Zxxxxa-id, the `dentryUuid` is Zxxxxa-id. |

### Query parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| startIndex | Integer | No | The start position. An integer greater than or equal to 0, indicating that the query starts from the `startIndex`-th block element under the document. |
| endIndex | Integer | No | The end position. An integer greater than or equal to 0, indicating that the query ends at the `endIndex`-th block element. |
| blockType | String | No | The specified block element type. For details, see [Block element data structure](/open/development/block-data-structure). |
| operatorId | String | Yes | The unionId of the user. Obtain the `unionid` parameter value by calling the [Query user details](/open/development/query-user-details) API. |

### Request example

HTTP

```http
GET /v1.0/doc/suites/documents/doc_id/blocks?startIndex=0&endIndex=1&blockType=paragraph&operatorId=union_id HTTP/1.1
Host:api.dingtalk.io
x-acs-dingtalk-access-token:7dc9ec4xxx
Content-Type:application/json
```
