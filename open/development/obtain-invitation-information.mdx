Call this API to get the invitation information of an organization.

## Request

### Basic information

| Field | Value |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/v1.0/contact/invites/infos |
| HTTP Method | GET |
| Supported app types | appType-Internal app　appType-Third-party enterprise app |
| Permissions | permission-Contact.Common.Read-Read permission for basic Contacts data |

### Request headers

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Yes | The access credential for calling this API. Obtain it in one of the following ways:   - For an internal app, call the [Get the access token of an internal app](/open/development/obtain-the-access-token-of-an-internal-app#) API. - For a third-party enterprise app, call the [Get the access token of an organization authorized to a third-party app](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#) API. |

### Query parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| inviterUserId | String | No | The userId of the inviter. For more information, see [Basic concepts - UserId](/open/dingstart/basic-concepts-beta#section-aa9-zk1-os6).  If this parameter is left empty, the userId of the current organization creator is used by default. |
| deptId | Long | No | The department ID for which to get the department invitation link. |

| searchNameInvite | Boolean | Whether to allow joining by searching the organization name.   - **true**: enabled - **false**: disabled |
| orgApplyCodeInvite | Boolean | Whether to allow joining by team code.   - **true**: enabled - **false**: disabled |
| linkInvite | Boolean | Whether to allow joining via an invitation link.   - **true**: enabled - **false**: disabled |
| inviteUrl | String | The invitation link. |
| auditType | Long | The review type.   - **0**: no review required - **1**: reviewed by an authorized Sub Admin   Applies only to department invitations. |
| empApplyJoinDept | Boolean | Whether to allow employees to join a department by scanning a QR Code.   - **true**: allowed - **false**: not allowed   Effective only when no review is required. Users already in the organization can join a department by scanning the department QR Code. |
