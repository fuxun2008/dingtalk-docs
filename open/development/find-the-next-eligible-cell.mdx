---
title: "Find a cell in a worksheet"
description: "Call this API to find the next cell in a DingTalk Spreadsheet worksheet that matches the given string and conditions, starting after the top-left of rangeAddress and optionally intersecting with findOptions.scope."
---

Find the next cell that matches the given string based on the specified conditions. The search scope covers the entire worksheet starting after the top-left cell of the specified range (that is, rangeAddress). If the `findOptions.scope` parameter is specified, the search scope is further intersected with it.

## Request

### Basic information

| Field | Value |
| --- | --- |
| HTTP URL | `https://api.dingtalk.io/v1.0/doc/workbooks/{workbookId}/sheets/{sheetId}/ranges/{rangeAddress}/findNext` |
| HTTP Method | POST |
| Supported app types | appType-Internal app |
| Required permissions | permission-Document.Workbook.Read-DingTalk Spreadsheet read permission |

### Request headers

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Yes | The access credential used to call this API. Call the [Get the access token of an internal app](/open/development/obtain-the-access-token-of-an-internal-app) API to obtain it. |

### Path parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| workbookId | String | Yes | The spreadsheet file ID. Pass `nodeId` (dentryUuid) as the spreadsheet `workbookId`. Call the [Get a node](/open/development/get-knowledge-base-acquisition-node) or [Create a Knowledge Base document](/open/development/create-team-space-document) API to obtain it. |
| sheetId | String | Yes | The ID or title of the worksheet. Call the [Get all worksheets](/open/development/obtain-all-worksheets) API to obtain the ID, or pass the worksheet title. |
| rangeAddress | String | Yes | The starting position of the search. The search starts after the top-left cell of this range (the top-left cell itself is excluded). |

### Query parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| operatorId | String | Yes | The unionId of the operator. |

### Request body

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| text | String | Yes | The text to find. |
| findOptions | Object | No | The find options. |
| matchEntireCell | Boolean | No | Whether to match the entire cell:   - **true**: Yes - **false**: No |
| matchCase | Boolean | No | Whether to match case:   - **true**: Yes - **false**: No |
| useRegExp | Boolean | No | Whether the text parameter is a regular expression:   - **true**: Yes - **false**: No |
| matchFormulaText | Boolean | No | Whether to search within formulas:   - **true**: Yes - **false**: No |
| scope | String | No | The search scope. Specify a Range address in A1 notation. |
| includeHidden | Boolean | No | Whether to include hidden cells, that is, cells made invisible by hidden rows or columns, filters, groups, and similar features. Cells the user has no permission to view are not included.   - **true**: Yes - **false**: No |
