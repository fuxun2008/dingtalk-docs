Call this API to add a comment to an approval instance.

## API Call Description

To add attachments to an approval comment, upload the files to the approval Drive space to obtain the API parameters spaceId, fileType, fileName, fileId, and fileSize. Obtain them as follows:

1. Call the [Get Approval Drive Space Information](/open/development/obtains-the-information-about-approval-nail-disk) API to obtain upload permissions for the Drive space and the spaceId of the approval Drive space.
2. Using the spaceId of the approval Drive space, upload an attachment to Drive or select a file from Drive in a web app (H5 Micro app) to obtain the Drive attachment file information.

## Request

### Basic Information

| Field | Value |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/v1.0/workflow/processInstances/comments |
| HTTP Method | POST |
| Supported App types | appType-Internal app |
| Required permissions | permission-Workflow.Instance.Write-Workflow instance write permission |

### Request Header

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Yes | The access credential for calling this API. Call the [Get the Access Token of an Internal App](/open/development/obtain-the-access-token-of-an-internal-app) API to obtain it. |

### Request Body

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| processInstanceId | String | Yes | The approval instance ID:   - Call the [Create an Approval Instance](/open/development/create-an-approval-instance) API to obtain the `InstanceId` parameter value. - Call the [Get Approval Instance Details](/open/development/obtain-an-approval-list-of-instance-ids) API to obtain the `list` parameter value. |
| text | String | Yes | The comment content. Maximum length: 1,024 characters. |
| commentUserId | String | Yes | The userId of the commenter. |
| file | Object | No | The file. |
| photos | Array of String | No | The image URLs. |
| attachments | Array | No | The attachment list. Maximum number of list elements: 20. |
| spaceId | String | No | The Drive space ID.      See the API call description in this topic. |
| fileSize | String | No | The file size.      See the API call description in this topic. |
| fileId | String | No | The file ID. Maximum length: 256 characters.      See the API call description in this topic. |
| fileName | String | No | The file name. Maximum length: 256 characters.      See the API call description in this topic. |
| fileType | String | No | The file type.      See the API call description in this topic. |
