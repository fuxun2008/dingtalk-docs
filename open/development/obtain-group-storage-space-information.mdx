---
title: "Get the storage space information of a group"
---

Call this API to get the storage space information of a specified group, including the space ID, creation time, and modification time of the group storage space.

## Request

### Basic information

| Field | Value |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/v1.0/convFile/conversations/spaces/query |
| HTTP Method | POST |
| Supported app types | appType-Internal app　appType-Third-party enterprise app |
| Required permissions | permission-ConvFile.Space.Read-Group files space read permission |

### Request headers

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Yes | The access credential for calling this API. Obtain it by calling the [Get the access token of an internal app](/open/development/obtain-the-access-token-of-an-internal-app#) API. |

### Query parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| unionId | String | Yes | The unionId of the operator. Obtain it by calling the [Query user details](/open/development/query-user-details#) API. |

### Request body

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| openConversationId | String | Yes | The openConversationId of the chat. Obtain the value of openConversationId by calling the [Create a group](https://open.dingtalk.com/document/development/create-group-session#) API. |

### Request example

HTTP

```http
POST /v1.0/convFile/conversations/spaces/query?unionId=chyxxxxx HTTP/1.1
Host:api.dingtalk.io
x-acs-dingtalk-access-token:xxxxx
Content-Type:application/json

{
  "openConversationId" : "cid9FTRQSLo+sKxxxx"
}
```
