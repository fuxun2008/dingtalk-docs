Call this API to query the attendance shift and scheduling information of all employees in your organization on a specific day.

## API Call Description

- For fixed shift attendance, only scheduling information for the next 15 days is available.
- This API is available only to organizations with fewer than 10,000 members.

## Request

| **Basic information** | |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/topapi/attendance/listschedule |
| HTTP Method | POST |
| Supported app types | appType-Internal app　appType-Third-party enterprise app |
| Required permissions | permission-qyapi_base-Basic permissions required to call organization APIs |

### Query Parameters

| Name | Type | Required | Example | Description |
| --- | --- | --- | --- | --- |
| access_token | String | Yes | bE74xxxx | The app credential used to call this API.   - For an Internal app, obtain it by calling [Get the access_token of an internal app](/open/development/obtain-orgapp-token). - For a Third-party enterprise app, obtain it by calling Get the access_token of a third-party organization. |

### Request Body

| Name | Type | Required | Example | Description |
| --- | --- | --- | --- | --- |
| workDate | Date | Yes | 2020-09-06 | The scheduling date. Only the year, month, and day are used. |
| offset | Number | No | 0 | The pagination offset, starting from 0. Takes effect only when set together with the size parameter. |
| size | Number | No | 200 | The page size. Maximum value: 200. |

### Request Example

```curl
curl -X POST "https://api.dingtalk.io/topapi/attendance/listschedule" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=b9305xxxxea83' \
-d 'offset=0' \
-d 'size=200' \
-d 'workDate=2016-03-09+11%3A11%3A11'
```

## Response

### Response Body

| Name | Type | Example | Description |
| --- | --- | --- | --- |
| result | AtScheduleListForTopVo |  | The query result. |
| schedules | AtScheduleForTopVo[] |  | The schedule list. |
| plan_id | Number | 157062792171 | The scheduling ID. |
| check_type | String | OnDuty | The clock-in type:   - **Onduty**: Clock in - **OffDuty**: Clock out |
| approve_id | Number | 1 | The approval ID.  **Note**  This parameter is not returned if there is no approval form. |
| userid | String | user01 | The user ID of the attendance user. |
| class_id | Number | 677995086 | The attendance shift ID. |
| class_setting_id | Number | 599315627 | The shift configuration ID.  **Note**  This parameter is not returned if the global configuration is used. |
| plan_check_time | Date | 2020-11-11 09:30:00 | The clock-in time. |
| group_id | Number | 685935028 | The attendance group ID. |
| changed_check_time | Date | 2020-09-06 15:36:04 | The adjusted clock-in time. |
| has_more | Boolean | false | Indicates whether there is a next page.   - **true**: Yes - **false**: No |
| errmsg | String | ok | The return code description. |
| errcode | Number | 0 | The return code. |
| request_id | String | 6ha75i2o99fj | The request ID. |
