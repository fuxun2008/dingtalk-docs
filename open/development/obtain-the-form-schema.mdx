| Supported app types | appType-Internal app　appType-Third-party enterprise app |

### Request Header

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Yes | The access credential for calling this API. ### Query Parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| processCode | String | Yes | The unique code of the form. Get it by calling the [Create or update an approval form template](/open/development/create-an-approval-form-template) API, or see [OA Approval overview - Glossary](/open/development/workflow-overview). |
| appUuid | String | No | The isolation information for app building. |
