---
title: "Create a group chat"
---

Call this API to create an Internal Group or Standard Group chat. This is suitable for scenarios where an organization needs to quickly create a group chat.

## API call description

By default, this API only supports creating an Internal Group. To create a Standard Group, contact technical support to add your app to the allowlist.

## Request

### Basic information

| Field | Value |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/v1.0/im/group/create |
| HTTP Method | POST |
| Supported app types | appType-Internal app |
| Required permissions | permission-qyapi_chat_manage-DingTalk group basic information management permission |

### Request headers

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Yes | The access credential used to call this API. Obtain it via the [Get the access token of an internal app](/open/development/obtain-the-access-token-of-an-internal-app) API. |

### Request body

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| name | String | Yes | The group name. The length must be 1 to 20 characters. |
| owner | String | Yes | The userId of the group owner. Obtain the userId via the Get user by mobile number API. |
| ownerType | String | No | The type of the group owner.   - **emp**: Organization employee - **ext**: External contact |
| useridlist | Array of String | Yes | The StaffId of the users. |
| conversationTag | Long | No | The conversation type tag. Defaults to Internal Group. To create a Standard Group, contact technical support to add your app to the allowlist.   - **0**: Standard Group - **2**: Internal Group |
| extidlist | Array of String | No | External contacts. |
| icon | String | No | The group profile photo. Pass a mediaId, which can be obtained via the [Upload media files](/open/development/upload-media-files) API. |
| managementOptions | Object | No | Additional attributes for creating the group. |
| mentionAllAuthority | Integer | No | The scope in which @all can be used.   - **0** (default): Everyone can use it. - **1**: Only the group owner can use @all. |
| showHistoryType | Integer | No | Whether new users can view the latest 100 historical messages. If not provided, they cannot view them.   - **1**: Can view. - **0**: Cannot view. |
| validationType | Integer | No | Whether to require verification to join the group. - **0** (default): No verification.   - **1**: Verification required. |
| searchable | Integer | No | Whether the group can be searched. - **0** (default): Not searchable.   - **1**: Searchable. |
| chatBannedType | Integer | No | Whether to mute members in the group.   - **0** (default): Do not mute. - **1**: Mute All. |
| managementType | Integer | No | The Group Management type.   - **0** (default): Everyone can manage. - **1**: Only the group owner can manage. |
