Call this API to get summaries of all attendance groups in your organization by page, including each attendance group name and its corresponding attendance group ID.

## Request

| **Basic Information** | |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/topapi/attendance/group/minimalism/list |
| HTTP Method | POST |
| Supported app types | appType-Internal app　appType-Third-party enterprise app |
| Permissions | permission-qyapi_attendance_group_read-Attendance group read permission |

### Query Parameters

| Name | Type | Required | Example | Description |
| --- | --- | --- | --- | --- |
| access_token | String | Yes | bE74xxxx | The app credential used to call this API.   - For an Internal app, get it by calling [Get the access_token of an Internal App](/open/development/obtain-orgapp-token). - For a Third-party enterprise app, get it by calling the API for getting the access_token of a third-party organization. |

### Request Body

| Name | Type | Required | Example | Description |
| --- | --- | --- | --- | --- |
| op_user_id | String | Yes | user123 | The userId of the operator. |
| cursor | Number | No | 222 | The pagination cursor. Get it from the result of the previous request. If omitted, the query starts from the first item. |

### Request Example

```curl
curl -X POST "https://api.dingtalk.io/topapi/attendance/group/minimalism/list" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=6dd4xxxx94138' \
-d 'cursor=222' \

```
