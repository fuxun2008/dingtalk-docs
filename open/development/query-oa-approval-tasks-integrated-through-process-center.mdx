Call this API to query a user's running approval tasks.

## API Call Description

- This API can only query To-Do task data from within the past year.
- This API queries pending To-Do tasks created for users through the Create Process Center Pending Task API. These To-Do tasks sync to DingTalk To-Do. View them in **DingTalk client > To-Do > OA Approval**.

## Request

### Basic Information

| Field | Value |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/v1.0/workflow/processCentres/todoTasks |
| HTTP Method | GET |
| Supported app types | appType-Internal app　appType-Third-party enterprise app |
| Permissions required | permission-qyapi_aflow-Approval workflow data management permission |

### Request Header

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Yes | The access credential for calling this API. Obtain it as follows:   - Internal app: Call the [Obtain the access token of an internal app](/open/development/obtain-the-access-token-of-an-internal-app) API. - Third-party enterprise app: Call the Obtain the access token of an organization authorized by a third-party app API. |

### Query Parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| userId | String | Yes | The userId of the task executor. Obtain it by calling the [Query the list of user IDs in a department](/open/development/query-the-list-of-department-userids) API. |
| pageSize | Integer | Yes | The page size. Starts from 1. Maximum value: 40. |
| pageNumber | Integer | Yes | The page number. Starts from 1. |
| createBefore | Long | No | The start time of the query.    This time cannot be more than one year before the current time. |
