Call this API to clean up approval-related data.

## Request

### Basic Information

| Field | Value |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/v1.0/workflow/processes/clean |
| HTTP Method | POST |
| Supported app type | appType-Third-party enterprise app |
| Permissions | permission-Workflow.Data.Clean-Dedicated permission for workflow data cleanup |

### Request Header

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Yes | The access credential for calling this API. Obtain it by calling the API for getting the suiteAccessToken of a Third-party enterprise app. |

### Request Body

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| processCode | String | Yes | The unique code of the template. Obtain it by calling the API for creating or updating an approval template. |
| corpId | String | Yes | The organization ID of the authorizing organization. |
