This article describes how to develop a Cool App for group chats.

## **What Is a Group Chat Cool App**

Each scenario provides its own unique Cool App interaction capabilities. The following sections describe the open capabilities and development methods for group chat Cool Apps in detail.

A Cool App can be extended into a group chat. After it is installed in a group, Group members can efficiently view and use the data and features provided by the Cool App during their conversations to complete business collaboration.

## **Core Capabilities of Group Chat Cool Apps**

For example, DingDang OKR is a group chat Cool App that has already been published. In a Group Chat scenario, it enables users to create OKRs and interact while communicating. The core interactions are shown below.

The core product experience is delivered through five key capabilities:

- **Detect the installation event — Feature: Install the Cool App**

  When users install the Cool App from the Cool App Marketplace within a group, DingDang OKR detects the OKR installation event on the DingTalk side. By detecting the installation event, it sends an onboarding guide.
- **Open a half-floating-layer page — Feature: Open OKR**

  Open a half-floating-layer page in the group through the chat quick-access bar, so that all feature interactions stay within the group.
- **Send an interactive card — Feature: Create OKR**

  After a new OKR is created through the group's quick-access entry, the new OKR content is sent to the group in real time as an interactive card.
- **Click to interact / Update the card — Feature: Like an OKR**

  Other Group members can quickly like and comment on each other through the interactive card message. All interactions are updated in real time on the interactive card seen by other Group members.
- **Send a top-banner card / Update the interactive card — Feature: OKR Top-Banner Summary**

  After an OKR is created in the group, a top-banner card is sent to the group. It permanently displays the OKR summary and updates the top-banner card in real time.

## **How to Develop a Group Chat Cool App**

## **Develop a Group Chat Cool App**

- **Immersive experience:** Stay within the chat Context without leaving, and avoid interrupting the current work.
- **Scenario-based collaboration:** Information is collaborated on in real time and efficiently around specific scenarios and tasks.
- **Instant data analysis:** Use the structured Data generated through efficient collaboration for instant analysis to form effective insights.

## **Process Overview**

Before you start, make sure you have completed the prerequisites in [Become a DingTalk Developer](https://open.dingtalk.com/document/orgapp/become-a-dingtalk-developer#). The steps are as follows:

1. [Create a group chat Cool App](https://open.dingtalk.com/document/orgapp/create-a-process#) to complete the creation of the group chat Cool App.
2. Configure the [Quick-Access Entry](https://open.dingtalk.com/document/orgapp/quick-configuration-entry#) content to display it on the chat quick-access bar.
3. **After the group chat Cool App development is complete**, [Publish and Use the Cool App](https://open.dingtalk.com/document/orgapp/save-and-publish#) to complete App publishing and usage.

After completing the above steps, you have developed and published a simple group chat Cool App. You can now install the Cool App in a group and access the Cool App page through the quick-access entry. In addition, you can use the following capabilities to build a Cool App with an even better experience.

**Note**

Advanced development of the Cool App (optional)

- Configure the message content sent by the group chat Cool App:

  - Develop a [Plain message](https://open.dingtalk.com/document/orgapp/common-message#). Send Plain messages from the group chat Cool App Bots to implement basic message sending and management.
  - Develop an [Interactive card](https://open.dingtalk.com/document/orgapp/flow-type-interactive-card#) to send and manage interactive card messages and enable interaction with users.
  - Develop a [Top-Banner Card](https://open.dingtalk.com/document/orgapp/resident-type-ceiling#) to send and manage top-banner card information and enable interaction with users.

For details, see [Detect Group Changes (Event Subscription)](https://open.dingtalk.com/document/orgapp/group-change-awareness-event-subscription#).

## **Glossary**

### **Chat Quick-Access Bar**

The chat quick-access bar is a set of App feature entries available to all members in a group. Each feature entry is called a quick-access entry. Developers can define quick-access entries within a Cool App, and display their own quick-access entries in users' groups by installing the Cool App. For details, see [Configure the Quick-Access Entry](https://open.dingtalk.com/document/orgapp/quick-configuration-entry#).

### **Interactive Card**

In Group Chat scenarios, the interactive card is a very important capability that helps integrate App features with the scenario. Through an interactive card, your App can provide some data and features to users through a message card and interact with them directly. For details, see [Interactive Card](https://open.dingtalk.com/document/orgapp/flow-type-interactive-card#).

### **Top-Banner Card**

A top-banner card is a special type of interactive card that can provide some data and features to users through a message card and interact with them directly. Both interactive cards and top-banner cards are built on the interactive card capability. For details, see [Top-Banner Card](https://open.dingtalk.com/document/orgapp/resident-type-ceiling#).
