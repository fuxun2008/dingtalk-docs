Call this API to delete a specified leave rule.

## Request

| **Basic Information** | |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/topapi/attendance/vacation/type/delete |
| HTTP Method | POST |
| Supported app types | appType-Internal app　appType-Third-party enterprise app |
| Required permissions | qyapi_holiday_manage: DingTalk leave management permission |

### Query Parameters

| Name | Type | Required | Example | Description |
| --- | --- | --- | --- | --- |
| access_token | String | Yes | bE74xxxx | The app credential used to call this API.   - For an Internal app, call [Get the access_token of an Internal App](/open/development/obtain-orgapp-token) to obtain it. - For a Third-party enterprise app, call the API for getting the access_token of a third-party organization to obtain it. |

### Request Body

| Name | Type | Required | Example | Description |
| --- | --- | --- | --- | --- |
| leave_code | String | Yes | 03747xxxx | The unique identifier of the leave rule. Call [Query the List of Leave Rules](/open/development/holiday-type-query) to obtain the leave_code value. |
| op_userid | String | Yes | user01 | The user ID of an admin in your organization who has **OA Approval** app permissions. |

## Response

### Response Body

| Name | Type | Example | Description |
| --- | --- | --- | --- |
| result | LeaveTypeVo |  | The returned result. |
| leave_code | String | 03747xxxx | The unique identifier of the leave rule. |
| leave_name | String | Annual leave | The name of the leave. |
| leave_view_unit | String | day | The unit of the leave request.   - **day**: Day - **halfDay**: Half day - **hour**: Hour |
| biz_type | String | general_leave | The leave type.   - **general_leave**: Regular leave - **lieu_leave**: Overtime converted to compensatory leave |
| natural_day_leave | Boolean | true | Whether to calculate the leave duration by calendar day.   - **true**: Calculate the leave duration by calendar day. - **false**: Do not calculate the leave duration by calendar day.  **Note**  If the value is **false**, the leave duration is calculated based on the user's scheduling during the leave period when the user submits a leave request. |
| hours_in_per_day | Number | 1000 | The working hours per day, in units of 1/100 hour.  For example, 1 day = 10 hours = 1000. |
| errcode | Number | 0 | The return code. |
| errmsg | String | ok | The description of the return code. |
| success | Boolean | true | Whether the call succeeded.   - **true**: Yes - **false**: No |
| request_id | String | xss3trk3zypq | The request ID. |
