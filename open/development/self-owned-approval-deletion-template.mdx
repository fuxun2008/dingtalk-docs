Call this API to delete an approval template created for an organization, along with the instances and to-do tasks created under the template.

## API Call Description

- For an Internal app, only the template is deleted. Instances and to-do tasks created from the template are not deleted.
- For a Third-party enterprise app, the template is deleted, along with the instances and to-do tasks created from the template.

## Request

### Basic Information

| Field | Value |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/v1.0/workflow/processCentres/schemas |
| HTTP Method | DELETE |
| Supported app types | appType-Internal app　appType-Third-party enterprise app |
| Required permissions | permission-Workflow.Form.Write-Write permission for workflow templates |

### Request Header

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Yes | The access credential for calling this API. Obtain it as follows:   - For an Internal app, call the [Get the access token of an Internal app](/open/development/obtain-the-access-token-of-an-internal-app) API. - For a Third-party enterprise app, call the API to get the access token of an organization that has authorized the Third-party app. |

### Query Parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| processCode | String | Yes | The template code.   - For an Internal app, call the [Get the template code](/open/development/obtain-the-template-code) API to obtain it. |
| cleanRunningTask | Boolean | No | Specifies whether to clean up running tasks.   - **true**: Yes - **false**: No |

### Request Example

HTTP

```http
DELETE /v1.0/workflow/processCentres/schemas?processCode=proc-abc&cleanRunningTask=false HTTP/1.1
Host:api.dingtalk.io
x-acs-dingtalk-access-token:6d1bxxxx
Content-Type:application/json
```
