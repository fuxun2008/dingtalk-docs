Call this API to query the details of all attendance groups.

## API Call Description

In the DingTalk Attendance app, an attendance group is a set of users or departments that share the same attendance rules, such as shifts and attendance locations. Organizations can create multiple attendance groups based on business needs.

<Note>
Unlike the [Get Attendance Group Details](/open/development/query-a-single-attendance-group) API, this API returns attendance group information that includes shift settings.
</Note>

To view attendance groups, go to **Attendance Group Management** in the DingTalk **Attendance** admin console. For example, a group created via the API can be a fixed-shift attendance group with a day shift of 09:00–18:00 from Monday to Friday and rest days on Saturday and Sunday.

## Request

| **Basic information** | |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/topapi/attendance/getsimplegroups |
| HTTP Method | POST |
| Supported app types | appType-Internal app appType-Third-party enterprise app |
| Permissions | permission-qyapi_base-Basic permission required to call organization APIs |

### Query Parameters

| Name | Type | Required | Example | Description |
| --- | --- | --- | --- | --- |
| access_token | String | Yes | bE74xxxx | The app credential used to call this API.   - For an Internal app, call the [Get the access_token of an Internal App](/open/development/obtain-orgapp-token) API. - For a Third-party enterprise app, call the API for getting the access_token of a third-party organization. |

### Request Body

| Name | Type | Required | Example | Description |
| --- | --- | --- | --- | --- |
| offset | Number | No | 0 | The pagination offset. Takes effect only when set together with the size parameter. The offset starts from 0. In the next call, pass the sum of size and offset from the previous call. |
| size | Number | No | 10 | The page size. Maximum value: 10. |

### Request Example

```curl
curl -X POST "https://api.dingtalk.io/topapi/attendance/getsimplegroups" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=c4a715xxxx0a0da2' \
-d 'offset=0' \
-d 'size=10'
```

| errmsg | String | ok | The description of the return code. |
| result | AtGroupListForTopVo |  | The returned result. |
| has_more | Boolean | true | Used for pagination. Indicates whether more data exists.   - **true**: Yes - **false**: No |
| groups | AtGroupForTopVo[] |  | The list of attendance groups. |

| class_name | String | A | The shift name. |

| work_day_list | String[] | ["0","12","12","12","12","12","0"] | The workday shifts of a fixed shift.  **Note**     - 0 indicates a rest day. - The values in the array, from left to right, represent the scheduling for each day from Sunday to Saturday. |
| classes_list | String[] | ["Mon, Tue, Wed, Thu, Fri Day shift 09:00-16:00 ","Sat, Sun Rest"] | The weekly shift schedule display list. |
| manager_list | String[] | ["manager4220"] | The sub-administrators of the attendance group. |
| dept_name_list | String[] | ["Marketing"] | The names of the departments in the attendance group. |
| owner_user_id | String | user456 | The primary owner of the attendance group. |
