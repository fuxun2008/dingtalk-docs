---
title: "Move a file or folder"
---

Call this API to move a file or folder to any other location.

## Request

### Basic information

| Field | Value |
| --- | --- |
| HTTP URL | `https://api.dingtalk.io/v1.0/storage/spaces/{spaceId}/dentries/{dentryId}/move` |
| HTTP Method | POST |
| Supported app types | appType-Internal app　appType-Third-party enterprise app |
| Required permissions | permission-Storage.File.Write-Enterprise storage file write permission |

### Request headers

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Yes | The access credential for calling this API. Obtain it as follows:   - For an internal app, call the [Obtain the access token of an internal app](https://open.dingtalk.io/document/development/obtain-the-access-token-of-an-internal-app) API. - For a third-party enterprise app, call the [Obtain the access token of an organization authorized to use a third-party app](https://open.dingtalk.io/document/development/obtain-the-access-token-of-the-authorized-enterprise-1) API. |

### Path parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| spaceId | String | Yes | The ID of the source space where the file or folder resides. Call the [Add a space](https://open.dingtalk.io/document/development/add-space) API to obtain the value of the id parameter. |
| dentryId | String | Yes | The ID of the file or folder to move. Call the [Get a list of files or folders](https://open.dingtalk.io/document/development/get-a-list-of-files-or-folders) API or the [Get spaceId and dentryId by dentryUuid](https://open.dingtalk.io/document/development/api-getdentryidbyuuid) API to obtain the value of the id parameter. |

### Query parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| unionId | String | Yes | The unionId of the operator. Call the [Query user details](https://open.dingtalk.io/document/development/query-user-details) API to obtain the value of the unionid parameter. |

### Request body

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| targetSpaceId | String | Yes | The ID of the target space where the file or folder will be stored. Call the [Add a space](https://open.dingtalk.io/document/development/add-space) API to obtain the value of the id parameter. |
| targetFolderId | String | Yes | The ID of the parent folder where the file or folder will be stored. Call the [Get a list of files or folders](https://open.dingtalk.io/document/development/get-a-list-of-files-or-folders) API to obtain the value of the id parameter.  For the root directory, set this parameter to 0. |
| option | Object | No | Optional parameters. |
| conflictStrategy | String | No | The name conflict strategy for files and folders.   - **AUTO_RENAME** (default): Automatically rename. - **OVERWRITE**: Overwrite. - **RETURN_DENTRY_IF_EXISTS**: Return the existing file. - **RETURN_ERROR_IF_EXISTS**: Return an error if the file already exists. |
| presevePermissions | Boolean | No | Specifies whether to retain permissions after the move.   - **true**: Yes. - **false**: No. This is the default value. |
