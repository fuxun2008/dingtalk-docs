---
title: "Get a worksheet"
---

Call this API to obtain the properties of a worksheet, including the worksheet ID, worksheet name, number of rows, and number of columns.

## Request

### Basic information

| Field | Value |
| --- | --- |
| HTTP URL | `https://api.dingtalk.io/v1.0/doc/workbooks/{workbookId}/sheets/{sheetId}` |
| HTTP Method | GET |
| Supported app type | appType-Internal app |
| Required permissions | permission-Document.Workbook.Read-Read permissions for DingTalk Spreadsheet |

### Request headers

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Yes | The access credential used to call this API. To obtain it, call the [Get the access token of an internal app](https://open.dingtalk.io/document/development/obtain-the-access-token-of-an-internal-app#) API. |

### Path parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| workbookId | String | Yes | The ID of the spreadsheet file. The `nodeId(dentryUuid)` returned by the [Knowledge Base API](https://open.dingtalk.io/document/development/knowledge-base-overview#) is the `workbookId` of the spreadsheet. You can obtain it by calling the [Get a node](https://open.dingtalk.io/document/development/get-node#) and [Create a Knowledge Base document](https://open.dingtalk.io/document/development/create-team-space-document#) APIs. |
| sheetId | String | Yes | The ID or name of the worksheet. Call the [Get all worksheets](https://open.dingtalk.io/document/development/obtain-all-worksheets#) API to obtain the value of the id or name parameter. |

### Query parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| operatorId | String | Yes | The unionId of the operator.   - Call the [Obtain the userid of a user by using the silent login code](https://open.dingtalk.io/document/development/obtain-the-userid-of-a-user-by-using-the-log-free#) API to obtain the value of the unionid parameter. - Call the [Query user details](https://open.dingtalk.io/document/development/query-user-details#) API to obtain the value of the unionid parameter.     If the operator does not have permission, the API returns the error `The operator has no permission`. |
