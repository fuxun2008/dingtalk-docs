Call this API to configure schedule information, such as clock-in locations and clock-in Wi-Fi networks.

## Request

### Basic Information

| Field | Value |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/v1.0/attendance/schedules/additionalInfo |
| HTTP Method | PUT |
| Supported app types | appType-Internal app |
| Required permissions | permission-Pro.AttendanceGroup.Write-Write permission for attendance group information |

### Request Header

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Yes | The access credential for calling this API. Call [Get the access token of an internal app](/open/development/obtain-the-access-token-of-an-internal-app) to obtain it. |

### Request Body

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| scheduleInfos | Array | Yes | The list of schedule information. |
| planId | Long | Yes | The ID of the schedule to update. Call [Query attendance schedule details of an organization](/open/development/interface-for-daily-full-query-of-attendance-scheduling-information) to obtain it. |
| wifiKeys | Array of String | No | The list of Wi-Fi networks to add. |
| positionKeys | Array of String | No | The list of locations to add. |
| retainAttendanceCheck | Boolean | No | Specifies whether to retain the attendance clock-in settings. |
| opUserId | String | Yes | The user ID of the operator. |
