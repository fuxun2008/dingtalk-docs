## What Is a Prompt

A prompt is the input text provided to a Large Language Model (LLM) that guides it to generate the corresponding output. A prompt is usually more than a hardcoded string—it is a combination of a template, some examples, and user input. To make prompts easier to manage and use, you typically use a prompt template (PromptTemplate) to create and maintain them.

## What Is a PromptTemplate

A prompt template is a reusable text string that generates a prompt by taking a set of parameters from the end user. By replacing the parameter values in the template, you can easily build and use prompts, much like building a document from a document template in DingTalk Docs.

To help developers write and debug prompt templates, DingTalk AI apps provide a Prompt Builder. With the Prompt Builder, developers can treat a Prompt as an Entity for persistent management, unit tuning, and version iteration, and build their own PromptTemplate components for reuse across different apps and Skills. In the future, the Prompt Builder will also support features such as data evaluation, automatic optimization, and usage estimation. For details, see [How to Use the Prompt Builder](https://open.dingtalk.com/document/ai-dev/how-to-use-the-prompt-word-builder#).

## **How to Use Variables in a Prompt Template**

When AI capabilities run, they generate a large amount of data—for example, the openConversationId of the Group Chat in which Tabler is running, the corpId of the Organization the user belongs to, and the user's Name and userId. To make it easier for developers to access these values, the AI app development platform provides a convenient way to retrieve them.

#### **Examples**

- To get user input, enter the variable `@{input}` in the prompt template.
- To get the user's Name, enter the variable `@{user.name}` in the prompt template.
- To get the current time, enter the variable `@{time}` in the prompt template.

#### **Usage**

- Value expression

  ```
  @{user.name}
  ```
- Iteration expression

  ```
  @foreach{message : aiMessages} 
    @{message.sender.nick}: @{message.summary}
  @end{}
  ```
- Conditional expression

  ```
  @if{groupConversation != null}
    Group Chat title: @{groupConversation.title}
  @else{singleConversation != null}
    Direct Message target: @{singleConversation.targetUser.name}
  @else{}
    Not currently in an IM conversation
  @end{}
  ```

#### **System Variables**

```
<!-- User input -->
@{input} 

<!-- Current time -->
@{time} 

<!-- Current user information, including the user's Organization name, organization corpId, user Name, and user userId -->
@{user} 

<!-- The user's Name within the Organization -->
@{user.name}

<!-- The user's userId within the Organization -->
@{user.staffId}

<!-- The openConversationId of the current Group Chat; only available in IM scenarios when it is a Group Chat -->
@{groupConversation.openConversationId} 

<!-- The openConversationId of the current Direct Message; only available in IM scenarios when it is a Direct Message -->
@{singleConversation.openConversationId}
```
