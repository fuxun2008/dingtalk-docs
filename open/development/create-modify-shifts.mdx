---
title: "Create a Shift"
description: "Call this API to create an attendance shift and configure its name, clock-in and clock-out times, check-in sections, and breaks."
---

Call this API to create a DingTalk attendance shift.

## Request

| **Basic Information** | |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/topapi/attendance/shift/add |
| HTTP Method | POST |
| Supported app types | appType-Internal app |
| Required permissions | permission-qyapi_attendance_group_manage-Attendance group management permission |

### Query Parameters

| Name | Type | Required | Example | Description |
| --- | --- | --- | --- | --- |
| access_token | String | Yes | 6d1bxxxx | The app credential used to call this API. Obtain it by calling the [Get the access_token of an internal app](/open/development/obtain-orgapp-token) API. |

### Request Body

| Name | Type | Required | Example | Description |
| --- | --- | --- | --- | --- |
| op_user_id | String | Yes | user01 | The userId of the operator. |
| shift | TopAtClassVo | Yes |  | The shift. |
| owner | String | No | user01 | The shift owner. |
| class_group_name | String | No | def | The shift group name. |
| corp_id | String | No | ding23 | The organization ID (corpId). Find it in the [Developer Console](https://open-dev.dingtalk.io/). CorpId |
| name | String | Yes | Day shift | The shift name. |
| id | Number | No | 124 | The shift ID. Obtain it by calling the [Get shift summaries](/open/development/enterprise-shift-query-in-batches) API.  **Note:** Leave id empty to create a shift. Specify id to modify an existing shift. |
| sections | TopAtSectionVo[] | Yes |  | The check-in sections. |
| times | TopAtTimeVo[] | Yes |  | The clock-in information. |
| check_type | String | Yes | OnDuty | The clock-in type:   - **OnDuty**: Clock in - **OffDuty**: Clock out |
| across | Number | Yes | 0 | Whether the time spans to the next day:   - **0**: Same day - **1**: Next day |
| end_min | Number | No | -1 | The latest allowed clock-in time, in minutes. -1 indicates no limit. |
| check_time | Date | Yes | 2020-12-02 09:00:00 | The clock-in time. |
| free_check | Boolean | No | false | Whether clock-in is exempt:   - **false**: Clock-in required - **true**: Clock-in exempt |
| begin_min | Number | No | 30 | The earliest allowed advance clock-in time, in minutes. |
| setting | TopAtClassSettingVo | No |  | The settings. |
| rest_begin_time | TopAtTimeVo | No |  | The break start. |
| check_type | String | No | OnDuty | The break type:   - **OnDuty**: Break start - **OffDuty**: Break end |
| check_time | Date | No | 2020-12-02 09:00:00 | The break clock-in time. |
| free_check | Boolean | No | false | Whether clock-in is exempt:   - **true**: Clock-in exempt - **false**: Clock-in required |
| across | Number | No | 0 | Whether the time spans to the next day. Spanning means the break falls on the next day:   - **0**: Same day - **1**: Next day |
| class_id | Number | No | 221 | The shift ID. Obtain it by calling the [Get shift summaries](/open/development/enterprise-shift-query-in-batches) API. |
| is_flexible | Boolean | No | false | Whether the shift is flexible:   - **true**: Flexible - **false**: Not flexible |
| corp_id | String | No | ding121 | The organization ID (corpId). Find it in the [Developer Console](https://open-dev.dingtalk.io/). CorpId |
| is_deleted | String | No | N | Whether the shift is deleted:   - **N**: Yes - **Y**: No |
| rest_end_time | TopAtTimeVo | No |  | The break end. |
| check_type | String | No | OffDuty | The break type:   - **OnDuty**: Break start - **OffDuty**: Break end |
| check_time | Date | No | 2020-12-02 09:00:00 | The break time. |
| free_check | Boolean | No | false | Whether clock-in is exempt:   - **false**: Clock-in required - **true**: Clock-in exempt |
| across | Number | No | 1 | Whether the time spans to the next day. Spanning means the break falls on the next day:   - **0**: Same day - **1**: Next day |
| serious_late_minutes | Number | No | 31 | The duration that counts as a serious late arrival or early leave, in minutes. |
| absenteeism_late_minutes | Number | No | 60 | The duration of a late arrival or early leave that counts as absenteeism, in minutes.  **Note**  This value must be greater than the serious late arrival duration. |
| extras | Json | No | `{"cause":"{\"type\":\"approve\",\"relatedId\":\"43494469-21a6-4111-953b-7810a709f27f\"}"}` | The extension field for shift settings. Not required for non-temporary shifts. |
| tags | String | No | temp:schedule:isv | The shift tags. Not required for non-temporary shifts. |
| service_id | Number | No | 123 | The service ID bound to Premium scheduling. Not required for non-temporary shifts. |

### Request Example

```curl
curl -X POST "https://api.dingtalk.io/topapi/attendance/shift/add" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=39cbcxxxx9058' \
-d 'op_user_id=abc' \
-d 'shift=null'
```
