A connector is a collection of trigger events and executable actions. Using the rich set of connectors in the Connector Marketplace, you can enable interconnection between heterogeneous systems.

The following is the Connector homepage, which mainly consists of **Create Connector (① in the figure)** and **Custom Connector Homepage (② in the figure)**, as shown below:

## Create a **Connector** (**①** in the Figure)

Click **Create Connector** to open the Create Connector page, as shown below:

- **Connector Name**: Required. Enter the connector name, for example: Attendance Connector.
- **Connector Description**: Enter the connector description, for example: [DingTalk Official] Attendance.
- **Selector Icon**: Set the connector icon.

**Note**

The icon must be a square JPG/PNG file, with a recommended size of 240×240 pixels.

## **Custom Connector Homepage (② in the Figure)**

Custom connectors are connectors created by the current Organization. If the **official connectors** and **third-party connectors** cannot meet your custom scenarios, your Organization can define **trigger events** and **executable actions** to build a connector.

**Note**

Custom connectors can be used only within the current Organization.

- **Action**

  The basic actions for a connector include: Settings, Copy ID, and Set Tag.

  - **Settings:** This action lets you enter the connector's basic information and edit it.
  - **More:**

    - **Copy ID:** This action provides a convenient way to copy the connector ID.
    - **Connection Credential**: Use the connector by configuring an account or the required information.
