Call this API to notify that an attendance makeup clock-in request has been approved.

## Request

| **Basic Information** | |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/topapi/attendance/approve/check |
| HTTP Method | POST |
| Supported app types | appType-Internal app　appType-Third-party enterprise app |
| Permissions | permission-qyapi_attendance_group_manage-Attendance group management permission |

### Query Parameters

| Name | Type | Required | Example | Description |
| --- | --- | --- | --- | --- |
| access_token | String | Yes | bE74xxxx | The App credential used to call this API.   - For an Internal app, call the [Get the access_token of an internal app](/open/development/obtain-orgapp-token) API to obtain it. - For a Third-party enterprise app, call the Get the access_token of a third-party organization API to obtain it. |

### Request Body

| Name | Type | Required | Example | Description |
| --- | --- | --- | --- | --- |
| userid | String | Yes | manager4220 | The user ID of the employee. |
| work_date | String | Yes | 2019-08-15 | The date of the makeup clock-in. Use the work_date value returned by the [Query user scheduling information in batches](/open/development/query-batch-scheduling-information) API. |
| punch_id | Number | Yes | 176877195378 | The ID of the shift to make up. Use the shift_id value returned by the [Query user scheduling information in batches](/open/development/query-batch-scheduling-information) API. |
| punch_check_time | String | Yes | 2019-08-15 08:00 | The scheduled clock-in time of the shift. Use the plan_check_time value returned by the [Query user scheduling information in batches](/open/development/query-batch-scheduling-information) API. |
| user_check_time | String | Yes | 2019-08-15 07:59 | The time the user clocked in. |
| approve_id | String | Yes | aasdv13124 | The ID of the approval form. This is a custom value. |
| jump_url | String | Yes | https://open.dingtalk.io/ | The redirect URL of the approval form. |
| tag_name | String | Yes | Makeup clock-in | The name of the approval form. |
