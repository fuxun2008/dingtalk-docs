Call this API to batch query the Wi-Fi list of a specified attendance group.

## Request

| **Basic Information** | |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/topapi/attendance/group/wifis/query |
| HTTP Method | POST |
| Supported app types | appType-Internal app |
| Required permissions | permission-qyapi_attendance_group_read-Attendance group query permission |

### Query Parameters

| Name | Type | Required | Example | Description |
| --- | --- | --- | --- | --- |
| access_token | String | Yes | 4c9ebd2b1534xxxx | The App credential used to call this API. Obtain it by calling the [Get the access_token of an Internal App](/open/development/obtain-orgapp-token) API. |

### Request Body

| Name | Type | Required | Example | Description |
| --- | --- | --- | --- | --- |
| cursor | String | No | 0151E022xxxx | The last ID of the previous batch. Empty by default. |
| size | Number | Yes | 50 | The page size. |
| op_userid | String | No | user01 | The user ID of the operator. |
| group_key | String | Yes | 015xxxx | The attendance group ID.  **Note**  If your attendance group identifier is group_id, call the [Convert groupId to groupKey](/open/development/groupid-to-groupkey) API to convert group_id to group_key. |

### Request Example

```curl
curl -X POST "https://api.dingtalk.io/topapi/attendance/group/wifis/query" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=698cxxxx9b13' \
-d 'cursor=0151E0xxxx17E876' \
-d 'group_key=0151Exxxx17E876' \
-d 'op_userid=123456' \
-d 'size=50'
```

## Response

### Response Body

| Name | Type | Example | Description |
| --- | --- | --- | --- |
| result | DingOpenResult |  | The returned result. |
| result | Result |  | The Wi-Fi list query result. |
| wifi_list | Wifi[] |  | The Wi-Fi list. |
| mac_addr | String | 54:8D:xx:xx:xx:73 | The MAC address. |
| ssid | String | alibaba-inc | The Wi-Fi name. |
| wifi_key | String | E4CB0xxxx | The Wi-Fi key. |
| has_more | Boolean | true | Whether more data exists.   - **true**: Yes - **false**: No |
| errcode | Number | 0 | The return code. |
| errmsg | String | ok | The description of the return code. |
| success | Boolean | true | Whether the call succeeded.   - **true**: Success - **false**: Failed |
| request_id | String | 155qyie8nxoqu | The request ID. |
