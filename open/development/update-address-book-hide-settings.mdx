title: "Create or update contact hiding settings"
description: "Business fields such as ctTagIds and excludeStaffIds."
---

Use this API to create or update contact hiding settings. Submit the business fields `name`, `description`, `objectStaffIds`, `objectDeptIds`, `objectTagIds`, and `excludeStaffIds` through a PUT request.

## API call description

In the DingTalk OA admin console, you can hide departments. This API extends the hiding capability beyond departments — **you can also hide employees and roles**.

<Note>
The hiding settings configured through this API are stored independently from those configured in the OA admin console. The final effect is the union (OR) of the two. For example, if the same department is hidden either through this API or through the OA admin console, it is hidden.
</Note>

## Request

### Basic information

| Field | Value |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/v1.0/contact/contactHideSettings |
| HTTP Method | PUT |
| Supported app types | appType-Internal app |
| Required permissions | permission-Contact.Visibility.ReadWrite-Permission to manage the visibility range of contact data |

### Request header

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Yes | The access credential used to call this API. Obtain it by calling the [Get the access token of an internal app](https://open.dingtalk.io/document/development/obtain-the-access-token-of-an-internal-app#) API. |

### Request body

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| name | String | No | The setting name. |
| description | String | No | The description of the setting. |
| objectStaffIds | Array of String | No | The list of `userId` values of the employees to hide. To obtain the `userId`, call [Get user information by silent login code](https://open.dingtalk.io/document/development/obtain-the-userid-of-a-user-by-using-the-log-free#).      The total number of elements across `objectStaffIds`, `objectDeptIds`, and `objectTagIds` cannot exceed 50. |
| objectDeptIds | Array of Long | No | The list of department IDs to hide. To obtain the `dept_id`, call [Get the department list](https://open.dingtalk.io/document/development/obtain-the-department-list-v2#).      The total number of elements across `objectStaffIds`, `objectDeptIds`, and `objectTagIds` cannot exceed 50. |
| objectTagIds | Array of Long | No | The list of `roleId` values of the roles to hide. To obtain the `id`, call [Get the role list](https://open.dingtalk.io/document/development/obtains-a-list-of-enterprise-roles#).      The total number of elements across `objectStaffIds`, `objectDeptIds`, and `objectTagIds` cannot exceed 50. |
| excludeStaffIds | Array of String | No | The list of `userId` values of the employees not affected by this hiding setting. To obtain the `userId`, call [Get user information by silent login code](https://open.dingtalk.io/document/development/obtain-the-userid-of-a-user-by-using-the-log-free#).      The total number of elements across `excludeStaffIds`, `excludeDeptIds`, and `excludeTagIds` cannot exceed 50. |
| excludeDeptIds | Array of Long | No | The list of department IDs not affected by this hiding setting. To obtain the `dept_id`, call [Get the department list](https://open.dingtalk.io/document/development/obtain-the-department-list-v2#).      The total number of elements across `excludeStaffIds`, `excludeDeptIds`, and `excludeTagIds` cannot exceed 50. |
| excludeTagIds | Array of Long | No | The list of role IDs not affected by this hiding setting. To obtain the `id`, call [Get the role list](https://open.dingtalk.io/document/development/obtains-a-list-of-enterprise-roles#).      The total number of elements across `excludeStaffIds`, `excludeDeptIds`, and `excludeTagIds` cannot exceed 50. |
| active | Boolean | No | Whether the setting is active. Valid values:   - true: active - false: inactive |
| id | Long | No | The setting ID.     - Leave it empty when creating a new setting. - Set it to the ID of the setting to update when modifying a setting. |
| hideInUserProfile | Boolean | No | Whether to also hide the user when their profile is viewed. Valid values:   - true: yes - false: no |
| hideInSearch | Boolean | No | Whether to also hide the user from search results. Valid values:   - true: yes - false: no |
