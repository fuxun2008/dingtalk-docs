Call this API to update the members of an attendance group. Add or remove **attendance members** and **attendance-exempt members** for a specified attendance group.

## Request

| **Basic Information** | |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/topapi/attendance/group/member/update |
| HTTP Method | POST |
| Supported app types | appType-Internal app　appType-Third-party enterprise app |
| Required permissions | qyapi_attendance_group_manage (Attendance group management permission) |

### Query Parameters

| Name | Type | Required | Example | Description |
| --- | --- | --- | --- | --- |
| access_token | String | Yes | bE74xxxx | The App credential used to call this API.   - For an Internal app, call the [Get the access_token of an Internal App](/open/development/obtain-orgapp-token) API to obtain it. - For a Third-party enterprise app, call the API for obtaining the access_token of a third-party organization to obtain it. |

### Request Body

| Name | Type | Required | Example | Description |
| --- | --- | --- | --- | --- |
| op_user_id | String | Yes | user123 | The userId of the operator. |
| group_id | Number | Yes | 98562 | The attendance group ID.  **Note**  If you use the legacy attendance group identifier (group_key), call the [Convert groupKey to groupId](/open/development/convert-groupkey-to-groupid) API to convert group_key to group_id. |
| schedule_flag | Number | Yes | 0 | The day from which scheduling starts.   - **0**: Start scheduling today - **1**: Start scheduling tomorrow |
| update_param | TopGroupMemberUpdateParam | Yes |  | The attendance group update information. |
| remove_extra_users | String[] | No | ["user123","user456"] | The attendance-exempt members to remove. Leave empty if not applicable. Pass up to 20 userIds per call. |
| remove_depts | String[] | No | ["123","456"] | The attendance departments to remove. Leave empty if not applicable. Pass up to 20 department IDs per call. |
| remove_users | String[] | No | ["user123","user456"] | The attendance members to remove. Leave empty if not applicable. Pass up to 20 userIds per call. |
| add_depts | String[] | No | ["123","456"] | The attendance departments to add. Leave empty if not applicable. Pass up to 20 department IDs per call. |
| add_users | String[] | No | ["user123","user456"] | The attendance members to add. Leave empty if not applicable. Pass up to 20 userIds per call. |
| add_extra_users | String[] | No | ["user123","user456"] | The attendance-exempt members to add. Leave empty if not applicable. Pass up to 20 userIds per call. |
