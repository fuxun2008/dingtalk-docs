---
title: "Check Whether the Smart Statistics Report Is Enabled"
description: "Call this API to check whether your organization enabled the attendance smart statistics report, so you know if other report APIs can be called."
---

Call this API to check whether your organization has enabled the attendance smart report. If the smart report is disabled, the other statistics report APIs cannot be called.

## Request

| **Basic Information** | |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/topapi/attendance/isopensmartreport |
| HTTP Method | POST |
| Supported app types | appType-Internal app　appType-Third-party enterprise app |
| Permissions | permission-qyapi_base-Basic permission required to call organization APIs |

### Query Parameters

| Name | Type | Required | Example | Description |
| --- | --- | --- | --- | --- |
| access_token | String | Yes | 6d1bxxxx | The App credential used to call this API.   - Internal app: Obtain it by calling the [Get the access_token of an Internal App](/open/development/obtain-orgapp-token) API. - Third-party enterprise app: Obtain it by calling the Get the access_token of a Third-party Enterprise App API. |

### Request Example

```curl
curl -X POST "https://api.dingtalk.io/topapi/attendance/isopensmartreport" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=b74b3xxxx0bb7c'
```

## Response

### Response Body

| Name | Type | Example | Description |
| --- | --- | --- | --- |
| result | IsOpenSmartReportForTopVo |  | The returned result. |
| smart_report | Boolean | true | Whether the smart statistics report is enabled:   - **true**: Enabled - **false**: Disabled |
| request_id | String | 6f9h5mh9a94i | The request ID. |
| errcode | Number | 0 | The return code. |

### Response Body Example

```json
{
  "errcode": 0,
  "result": {
    "smart_report": true
  },
  "request_id": "6f9h5mh9a94i"
}
```

### Error Codes

If the API call returns an error, find a solution in the [Global Error Codes](/open/development/server-api-error-codes-1) document based on the error message.
