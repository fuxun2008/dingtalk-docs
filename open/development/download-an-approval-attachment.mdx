Call this API to obtain download authorization for an approval file and generate a download link.

## API Call Description

- If the approval form was submitted manually from the DingTalk client with a local file attached, the attachment download address returned by this API uses the format #zifgs49xxxxx.file. Use this API together with the [Get the Details of a Single Approval Instance](/open/development/obtains-the-details-of-a-single-approval-instance-pop) API. Get the attachment's fileName and fileType from the instance details API, then replace the name and extension in the #zifgs49xxxxx.file value returned by this API. The attachment then opens correctly.
- The attachment file size cannot be 0. Download links are not supported for empty files.

## Request

### Basic Information

| Field | Value |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/v1.0/workflow/processInstances/spaces/files/urls/download |
| HTTP Method | POST |
| Supported app types | appType-Internal app　appType-Third-party enterprise app |
| Permissions | permission-Workflow.Instance.Write-Workflow instance write permission |

### Request Header

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Yes | The access credential for calling this API. Obtain it as follows:   - Internal app: call the [Get the access token of an internal app](/open/development/obtain-the-access-token-of-an-internal-app) API. - Third-party enterprise app: call the API to get the access token of an organization authorized by a third-party app. |

### Request Body

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| processInstanceId | String | Yes | The approval instance ID.   - Call the [Create an Approval Instance](/open/development/create-an-approval-instance) API to get the `InstanceId` parameter value. - Call the [Get a List of Approval Instance IDs](/open/development/obtain-an-approval-list-of-instance-ids) API to get the `list` parameter value. |
| fileId | String | Yes | The file fileId. Call the [Get the Details of a Single Approval Instance](/open/development/obtains-the-details-of-a-single-approval-instance-pop) API to get the `fileId` parameter value.      The file ID is the fileId of a file uploaded in an approval component. Download links are not currently supported for attachments uploaded in comments. |
| withCommentAttatchment | Boolean | No | Specifies whether to include attachments in comments. Attachments in comments are ignored by default. |
