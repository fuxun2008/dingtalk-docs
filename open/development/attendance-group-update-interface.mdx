---
title: "Update an Attendance Group"
description: "Call this API to update the name, clock-in address, admins, clock-in rules, and other settings of an attendance group by attendance group ID."
---

Call this API to update the information of an attendance group by attendance group ID.

## Request

| **Basic Information** | |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/topapi/attendance/group/modify |
| HTTP Method | POST |
| Supported app types | appType-Internal app |
| Required permissions | permission-qyapi_attendance_group_manage-Attendance group management permission |

### Query Parameters

| Name | Type | Required | Example | Description |
| --- | --- | --- | --- | --- |
| access_token | String | Yes | b5e95d101165xxxx | The App credential used to call this API. Obtain it by calling the [Get the access_token of an Internal App](/open/development/obtain-orgapp-token) API. |

### Request Body

| Name | Type | Required | Example | Description |
| --- | --- | --- | --- | --- |
| op_user_id | String | Yes | 123dfd | The user ID of the operator. |
| top_group | Object | Yes |  | The attendance group information. |
| shift_vo_list | Object[] | No |  | The shift information. |
| id | Number | No | 123 | The shift ID. Obtain the id value by calling the [Get Shift Summaries](/open/development/enterprise-shift-query-in-batches) API. |
| id | Number | Yes | 123 | The attendance group ID.  **Note**  If you use the legacy attendance group identifier group_key, call the [Convert groupKey to groupId](/open/development/convert-groupkey-to-groupid) API to convert group_key to group_id. |
| name | String | No | Day Shift Attendance | The attendance group name. |
| positions | Object[] | No |  | The attendance address settings. |
| address | String | No | 21 Jinger Road, Biotech Industrial Park | The address. |
| corp_id | String | No | 123dfd | The CorpId of the Organization. Find it on the Home page of the [Developer Console](https://open-dev.dingtalk.io/#/index). |
| latitude | String | No | 36.687495 | The latitude (up to 6 decimal places). |
| longitude | String | No | 101.750329 | The longitude (up to 6 decimal places). |
| title | String | No | Qinghai-Tibet Plateau Natural History Museum | The attendance location title. |
| accuracy | String | No | 0 | The accuracy.  **Note**  This field has no actual effect and does not affect accuracy. It was deprecated on March 7, 2022. |
| offset | Number | No | 300 | The attendance range. |
| manager_list | String[] | No | ["userId1","userId2"] | The list of user IDs of the attendance group Sub Admins. |
| enable_camera_check | Boolean | No | true | Specifies whether to enable photo clock-in.   - **true**: On - **false** (default): Off   **Note**  This parameter is deprecated. Use the open_camera_check parameter instead. |
| owner | String | No | 123dfdf | The user ID of the attendance group owner. |
| disable_check_when_rest | Boolean | No | false | Specifies whether clock-in on rest days requires Approval.   - **true**: Required - **false**: Not required |
| skip_holidays | Boolean | No | true | Specifies whether to skip public holidays.   - **true** (default): Skip - **false**: Do not skip |
| enable_outside_check | Boolean | No | true | Specifies whether field clock-in is allowed.   - **true** (default): Allow - **false**: Do not allow |
| disable_check_without_schedule | Boolean | No | false | Specifies whether to prohibit employees from clocking in when no shift is scheduled.   - **true**: Prohibit - **false**: Do not prohibit |
| enable_emp_select_class | Boolean | No | true | Specifies whether employees can select a shift to clock in when no shift is scheduled.   - **true**: Allow - **false**: Do not allow |
| resource_permission_map | Object | No |  | The Sub Admin permission scope.   - **w**: Manageable - **r**: Read-only |
| camera_check | String | No | w | Configure photo clock-in rules. |
| over_time_rule | String | No | r | Configure overtime rules. |
| check_position_type | String | No | w | Configure clock-in methods. |
| check_time | String | No | r | Configure attendance time. |
| group_type | String | No | w | Configure the attendance type. |
| group_member | String | No | r | Configure attendance members. |
| schedule | String | No | w | Employee scheduling. |
| out_side_check | String | No | r | Configure field clock-in. |
| workday_class_list | Number[] | No | [12,12,12,12,0,0] | The weekly shift list.  **Note**   - Required for fixed shift attendance. 0 indicates a rest day. - Values in the array represent the daily scheduling from Sunday to Saturday, from left to right. |
| open_camera_check | Boolean | No | true | Specifies whether to enable photo clock-in.   - **true**: On - **false** (default): Off |

### Request Example

```curl
curl -X POST "https://api.dingtalk.io/topapi/attendance/group/modify" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=ca21b524-0a09-4909-b6e9-af087e28a86b' \
-d 'op_user_id=123dfd' \
-d 'top_group=null'
```

## Response

### Response Body

| Name | Type | Example | Description |
| --- | --- | --- | --- |
| result | Object |  | The attendance group result. |
| name | String | Day Shift Attendance | The attendance group name. |
| id | Number | 123 | The attendance group ID. |
| errmsg | String | 0 | The error message. |
| errcode | Number | ok | The error code. |
| success | Boolean | true | Indicates whether the call succeeded.   - **true**: Success - **false**: Failed |
