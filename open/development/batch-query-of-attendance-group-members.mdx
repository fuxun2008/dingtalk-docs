title: "Get Attendance Members"
description: "Call this API to get the list of department IDs and user userIds of attendance members in an attendance group by attendance group ID."
---

Call this API to get the attendance members of an attendance group by attendance group ID, including the department IDs and the userIds of attendance members.

## API Call Description

If a department is set as an attendance member, the API returns the department ID but not the list of users in that department.

For example, if the attendance members include the **Test Department** and the employee **John**, this API returns the following information:

- The ID of the Test Department, but not the list of employee userIds in the department
- John's userId

## Request

| **Basic Information** | |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/topapi/attendance/group/member/list |
| HTTP Method | POST |
| Supported app types | appType-Internal app appType-Third-party enterprise app |
| Permissions | permission-qyapi_attendance_group_read-Attendance group query permission |

### Query Parameters

| Name | Type | Required | Example | Description |
| --- | --- | --- | --- | --- |
| access_token | String | Yes | bE74xxxx | The app credential used to call this API.   - For an internal app, obtain it by calling the [Get the access_token of an internal app](/open/development/obtain-orgapp-token) API. - For a third-party enterprise app, obtain it by calling the Get the access_token of a third-party organization API. |

### Request Body

| Name | Type | Required | Example | Description |
| --- | --- | --- | --- | --- |
| cursor | Number | No | 0 | The cursor value. Pass 0 for the first request. Default: 0. |
| op_user_id | String | Yes | user123 | The userId of the operator. |
| group_id | Number | Yes | 98562 | The attendance group ID.  **Note**  If you use the legacy attendance group identifier group_key, call the [Convert groupKey to groupId](/open/development/convert-groupkey-to-groupid) API to convert group_key to group_id. |
