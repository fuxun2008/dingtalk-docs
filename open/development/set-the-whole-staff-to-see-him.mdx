title: "Set spotlight on a participant"
description: "Call this API to spotlight or cancel spotlighting a specified participant for all attendees during a meeting."
---

During a meeting, call this API to spotlight a participant for all attendees or cancel the spotlight.

## Request

### Basic information

| Field | Value |
| --- | --- |
| HTTP URL | `https://api.dingtalk.io/v1.0/conference/videoConferences/{conferenceId}/focus` |
| HTTP Method | POST |
| Supported app types | appType-Internal app　appType-Third-party enterprise app |
| Permissions required | permission-VideoConference.Conference.Write-Video Meeting information management permission |

### Request header

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Yes | The access credential for calling this API. Obtain it in one of the following ways:   - For an internal app, call the [Get the access token of an internal app](/open/development/obtain-the-access-token-of-an-internal-app#) API. - For a third-party enterprise app, call the [Get the access token of an organization that has authorized a third-party app](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#) API. |

### Path parameter

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| conferenceId | String | Yes | The meeting ID. Call the [Create a video conference](/open/development/create-a-video-conference#) API to obtain the value of the `conferenceId` field from the response. |

### Request body

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| action | String | Yes | The action to perform:   - **focus**: Spotlight the participant for all attendees. - **un_focus**: Cancel the spotlight. |
| unionId | String | Yes | The unionId of the target user.  Required when action is set to focus. |
