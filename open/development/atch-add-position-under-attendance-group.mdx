Call this API to add locations to a specified attendance group in batches.

## Request

| **Basic Information** | |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/topapi/attendance/group/positions/add |
| HTTP Method | POST |
| Supported app types | appType-Internal app |
| Required permissions | permission-qyapi_attendance_group_manage-Attendance group management permission |

### Query Parameters

| Name | Type | Required | Example | Description |
| --- | --- | --- | --- | --- |
| access_token | String | Yes | 4c9ebd2b1534xxxx | The App credential used to call this API. Obtain it by calling the [Get the access_token of an Internal App](/open/development/obtain-orgapp-token) API. |

### Request Body

| Name | Type | Required | Example | Description |
| --- | --- | --- | --- | --- |
| op_userid | String | No | user01 | The user ID of the operator. |
| group_key | String | Yes | 03B1Exxxx | The attendance group ID.  **Note**  If your attendance group identifier is group_id, call the [Convert groupId to groupKey](/open/development/groupid-to-groupkey) API to convert group_id to group_key. |
| position_list | Object[] | Yes |  | The list of positions. Add up to 100 locations per request. |
| address | String | Yes | Alibaba Group Xixi Beiyuan | The address description. |
| foreign_id | String | Yes | 0151E23B1 | The positionId defined by the business party. |
| longitude | String | Yes | 120.123 | The longitude (up to 6 decimal places). |
| latitude | String | Yes | 30.123 | The latitude (up to 6 decimal places). |
| offset | Number | No | 100 | The allowed offset for the clock-in location, in meters. |

### Request Example

```curl
curl -X POST "https://api.dingtalk.io/topapi/attendance/group/positions/add" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=23adcxxxx46c5226' \
-d 'group_key=0151E02xxxx917E876' \
-d 'op_userid=123456' \
-d 'position_list=null'
```
