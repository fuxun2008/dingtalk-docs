---
title: "Delete a block element"
---

Call this API to delete a specific block element in a document.

## Request

### Basic information

| Field | Value |
| --- | --- |
| HTTP URL | `https://api.dingtalk.io/v1.0/doc/suites/documents/{docKey}/blocks/{blockId}` |
| HTTP Method | DELETE |
| Supported app type | appType-Internal app |
| Required permissions | permission-Storage.File.Write-Organization storage file write permission |

### Request headers

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Yes | The access credential used to call this API. Obtain it by calling the [Get the access token of an internal app](/open/development/obtain-the-access-token-of-an-internal-app) API. |

### Path parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| docKey | String | Yes | The document ID (the `docKey` or `dentryUuid` of the document). After creating a document by calling the [Create a Knowledge Base document](/open/development/create-team-space-document) API, obtain the `docKey` from the response. Obtain the `dentryUuid` from the document URL. For example, for `https://alidocs.dingtalk.io/i/nodes/Zxxxxa-id`, the `dentryUuid` is `Zxxxxa-id`. |
| blockId | String | Yes | The `blockId` of the block to delete. Obtain the `blockId` by calling the [Query block elements](/open/development/api-docblocksquery) API. |

### Query parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| operatorId | String | Yes | The unionId of the user. Obtain the unionid by calling the [Query user details](/open/development/query-user-details) API. |

### Request example

```http
DELETE /v1.0/doc/suites/documents/doc_key/blocks/block_id?operatorId=union_id HTTP/1.1
Host:api.dingtalk.io
x-acs-dingtalk-access-token:7dc9ec4xxx
Content-Type:application/json
```
