---
title: "Find all cells that match the criteria"
description: "Supports multiple search modes, including exact match, case sensitivity, regular expressions, and search within formulas."
---

Call this API to search all cells that contain the target text within a specified worksheet of a DingTalk Spreadsheet, and return the position list of matching cells. This is suitable for scenarios where specific content needs to be located in bulk within large datasets. It supports multiple search modes, including exact match, case sensitivity, regular expressions, and search within formulas.

## Request

### Basic information

| Field | Value |
| --- | --- |
| HTTP URL | `https://api.dingtalk.io/v1.0/doc/workbooks/{workbookId}/sheets/{sheetId}/findAll` |
| HTTP Method | POST |
| Supported app types | appType-Internal app |
| Permission required | permission-Document.Workbook.Read-DingTalk Spreadsheet read permission |

### Request headers

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Yes | The access credential for calling this API. Call the [Get the access token of an internal app](/open/development/obtain-the-access-token-of-an-internal-app) API to obtain it. |

### Path parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| workbookId | String | Yes | The spreadsheet file ID. The `nodeId(dentryUuid)` returned by the [Knowledge Base API](/open/development/knowledge-base-overview) is the spreadsheet `workbookId`. You can obtain it by calling the [Get node](https://open.dingtalk.com/document/development/get-node) and [Create a Knowledge Base document](/open/development/create-team-space-document) APIs. |
| sheetId | String | Yes | The worksheet ID or title. Call the [Get all worksheets](/open/development/obtain-all-worksheets) API to obtain the ID and title of the worksheet. |

### Query parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| operatorId | String | Yes | The unionId of the operator. Call the [Query user details](/open/development/query-user-details) API to obtain it. If the operator has no permission, the API returns the error `The operator has no permission`. |
| select | String | No | Filters the fields to be returned. If this parameter is not specified, all fields are returned.   - If select=a1Notation, only the a1Notation field is returned. - To return multiple fields, separate them with commas. For example, select=a1Notation,values returns only the a1Notation and values fields. Specifying this parameter is recommended to improve performance and avoid API timeouts when additional return values are added in the future. |

### Request body

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| text | String | Yes | The text to find. If **useRegExp** is enabled, this is a regular expression pattern. Example: "\\d+" |
| findOptions | Object | Yes | The find options. |
| matchEntireCell | Boolean | No | Whether to match the entire cell. Valid values:   - **true**: Yes - **false**: No (default) |
| matchCase | Boolean | No | Whether the search is case sensitive. Valid values:   - **true**: Yes - **false**: No (default) |
| useRegExp | Boolean | No | Whether text is a regular expression. Valid values:   - **true**: Yes - **false**: No (default) |
| matchFormulaText | Boolean | No | Whether to search by the raw formula text. Valid values:   - **true**: Yes - **false**: No (default)   For example, if a cell is populated with the formula "=A1+B1" and the displayed value is 4:   - When the search text is "4" and matchFormulaText is true, the cell is not included in the results. - When the search text is "=A1" and matchFormulaText is true, the cell is included in the results. |
| scope | String | No | The search scope. The format is a Range address expressed in A1 notation. |
| includeHidden | Boolean | No | Whether to include hidden cells, that is, cells made invisible by hidden rows or columns, filters, groups, or similar features. Cells that the user does not have permission to view are not included. Valid values:   - **true**: Yes - **false**: No (default) |
| unionCells | Boolean | Yes | Whether to aggregate the addresses of the found cells. Aggregation is recommended; otherwise, a large number of addresses may be returned. Valid values:   - **true**: Yes - **false**: No (default) |
