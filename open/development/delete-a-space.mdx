---
title: "Delete a space"
---

Call this API to delete a shared space of an organization.

## API call description

This API does not support deleting the All Employees folder.

## Request

### Basic information

| Field | Value |
| --- | --- |
| HTTP URL | `https://api.dingtalk.io/v1.0/drive/spaces/{spaceId}` |
| HTTP Method | DELETE |
| Supported app types | appType-Internal app　appType-Third-party enterprise app |
| Permission required | permission-Drive.Space.Write-Drive app drive space write permission |

### Request headers

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Yes | The access credential for calling this API. Obtain it as follows:   - For an internal app, call the [Get the access token of an internal app](https://open.dingtalk.io/document/development/obtain-the-access-token-of-an-internal-app#) API. - For a third-party enterprise app, call the [Get the access token of an authorized organization for a third-party app](https://open.dingtalk.io/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#) API. |

### Path parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| spaceId | String | Yes | The Drive space ID. Call the [Get a space list](https://open.dingtalk.io/document/development/queries-a-space-list#) API to obtain the value of the spaceId parameter. |

### Query parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| unionId | String | Yes | The unionId of the user. Call the [Query user details](https://open.dingtalk.io/document/development/query-user-details#) API to obtain it. |
