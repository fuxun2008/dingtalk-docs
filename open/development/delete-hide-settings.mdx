Call this API to delete contact hide settings.

## Request

### Basic information

| Field | Value |
| --- | --- |
| HTTP URL | `https://api.dingtalk.io/v1.0/contact/contactHideSettings/{settingId}` |
| HTTP Method | DELETE |
| Supported app type | appType-Internal app |
| Permissions | permission-Contact.Visibility.ReadWrite-Permission to manage the visibility scope of contacts data |

### Request header

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Yes | The access credential used to call this API. Obtain it by calling the [Obtain the access token of an internal app](/open/development/obtain-the-access-token-of-an-internal-app#) API. |

### Path parameter

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| settingId | Long | No | The setting ID. Obtain the value of the id parameter by calling [Obtain the hide settings of contacts](/open/development/obtains-the-hide-settings-of-the-address-book#). |
