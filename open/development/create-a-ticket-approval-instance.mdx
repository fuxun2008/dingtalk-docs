description: "Call this API to create a workflow-free approval instance from a template code, initiator userId, and form controls; returns the instance ID."
---

Call this API to create an approval instance without a workflow. Save the returned approval instance ID for use in subsequent API calls.

## API Call Description

To prevent invalid data from being passed to open APIs, this API will enforce stricter validation of incoming data.

- For single-select and multi-select controls, all option values passed must be configured in the option list.
- For internal contact controls, the userID passed must belong to an active member of the current organization.
- For department controls, the department ID must be a valid department ID in the current organization.
- For related approval form controls, the instance ID passed must be an existing approval instance ID in the current organization.

Approval forms initiated in violation of these rules may fail to be created once enhanced form data validation takes effect.
