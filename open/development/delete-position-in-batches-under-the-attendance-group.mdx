---

Call this API to batch delete positions from a specified attendance group.

## Request

| **Basic Information** | |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/topapi/attendance/group/positions/remove |
| HTTP Method | POST |
| Supported App Types | appType-Internal app |
| Required Permissions | permission-qyapi_attendance_group_manage-Attendance group management permission |

### Query Parameters

| Name | Type | Required | Example | Description |
| --- | --- | --- | --- | --- |
| access_token | String | Yes | 4c9ebd2b1534xxxx | The App credential used to call this API. Obtain it by calling the [Get the access_token of an Internal App](/open/development/obtain-orgapp-token) API. |

### Request Body

| Name | Type | Required | Example | Description |
| --- | --- | --- | --- | --- |
| op_userid | String | No | user01 | The user ID of the operator. |
| group_key | String | Yes | CEDDFxxxx | The attendance group ID.  **Note**  If your attendance group identifier is group_id, call the [Convert groupId to groupKey](/open/development/groupid-to-groupkey) API to convert group_id to group_key. |
| position_key_list | String | Yes | C384Fxxxx | The list of keys of the positions to delete. Obtain the keys by calling the [Batch Query Locations](/open/development/batch-query-position-under-attendance-group) API. Delete up to 100 locations per call. |

### Request Example

```curl
curl -X POST "https://api.dingtalk.io/topapi/attendance/group/positions/remove" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=25961xxxx7912f13' \
-d 'group_key=0151E022xxxx72A1A917E876' \
-d 'op_userid=123456' \
-d 'position_key_list=%22123%22%2C%22123%22'
```

## Response

### Response Body

| --- | --- | --- | --- |
| result | Result |  | The returned result. |
| success_list | String[] | ["C384Fxxxx"] | The list of successfully deleted items. |
| error_info_list | ErrorInfo[] |  | The list of errors. |
| failure_list | String[] | ["C384Fxxxx"] | The list of items that failed to be deleted. |
| msg | String | business fault | The error description. |
| code | String | 1000 | The error code. |
| errcode | Number | 0 | The return code. |
| errmsg | String | ok | The description of the return code. |
