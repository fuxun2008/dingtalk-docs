title: "Insert records"
---

Call this API to insert records into a specified table in an AI Table.

## Request

### Basic information

| Field | Value |
| --- | --- |
| HTTP URL | `https://api.dingtalk.io/v1.0/notable/bases/{baseId}/sheets/{sheetIdOrName}/records` |
| HTTP Method | POST |
| Supported app type | appType-Internal app |
| Permissions | permission-Notable.Base.Write.All-Write permission for the AI Table app |

### Request headers

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Yes | The access credential for calling this API. Call the [Get the access token of an internal app](https://open.dingtalk.io/document/development/obtain-the-access-token-of-an-internal-app) API to obtain it. |

### Path parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| baseId | String | Yes | The ID of the AI Table. For how to obtain it, see [Data structure](https://open.dingtalk.io/document/development/data-structure). |
| sheetIdOrName | String | Yes | The table ID or table name. You can obtain the table ID in either of the following ways:   - Call the [Get all tables](https://open.dingtalk.io/document/development/api-notable-getallsheets) API. - Call the [Get a table](https://open.dingtalk.io/document/development/api-notable-getsheet) API. |

### Query parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| operatorId | String | Yes | The unionId of the operator. Obtain it in either of the following ways:   - Call the [Query user details](https://open.dingtalk.io/document/development/query-user-details) API. - Call the [Obtain user information by silent login code](https://open.dingtalk.io/document/development/obtain-the-userid-of-a-user-by-using-the-log-free) API. |
| clientToken | String | No | A standard UUID v4 string used for idempotency control.   - Empty: Initiates a new request. - Non-empty: Performs an idempotent update. Repeated requests with the same value are not executed multiple times. |

### Request body

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| records | Array | Yes | The record data to be inserted. |
| fields | `Map<String, Any>` | Yes | The field values of the record, in the `Map<String, Any>` format:   - key: The field name (String type), corresponding to the field name in the table. - value: The field value (Any type). Pass a value in the appropriate format based on the field type. For details about the field value format, see [Record value format](https://open.dingtalk.io/document/development/record-value-format). |
|  | Any | No | The field value. The format varies depending on the field type. For details, see Record value format. |
