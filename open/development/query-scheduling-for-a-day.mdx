title: "Query the Scheduling Information of a User"
description: "Call this API to query the scheduling information of a specified user on a given day, based on the operator's userId, the queried user's userId, and a millisecond timestamp."
---

Call this API to query the scheduling information of a user on a specific day.

## Request

| **Basic Information** | |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/topapi/attendance/schedule/listbyday |
| HTTP Method | POST |
| Supported app types | Internal app, Third-party enterprise app |
| Permissions | qyapi_attendance_group_read (attendance group read permission) |

### Query Parameters

| Name | Type | Required | Example | Description |
| --- | --- | --- | --- | --- |
| access_token | String | Yes | bE74xxxx | The App credential used to call this API.   - Internal app: Obtain it by calling [Get the access_token of an Internal App](/open/development/obtain-orgapp-token). - Third-party enterprise app: Obtain it by calling Get the access_token of a Third-Party Enterprise App. |

### Request Body

| Name | Type | Required | Example | Description |
| --- | --- | --- | --- | --- |
| op_user_id | String | Yes | manager123 | The userId of the operator. |
| user_id | String | Yes | dd_dd | The userId of the user to query. |
| date_time | Number | Yes | 1564145519000 | The date to query, as a Unix timestamp in milliseconds. |

### Request Example

```curl
curl -X POST "https://api.dingtalk.io/topapi/attendance/schedule/listbyday" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=5d7f91f3-e22c-41ca-aee3-aa008603e00b' \
-d 'date_time=1564145519000' \
-d 'op_user_id=dd_dd' \
-d 'user_id=dd_dd'
```

### Response Body

| Name | Type | Example | Description |
| --- | --- | --- | --- |

| check_status | String | Timeout | The clock-in status:   - **Init**: Not clocked in - **Checked**: Clocked in - **Timeout**: Missed clock-in |

| id | Number | 56676915454 | The scheduling ID. |
| success | Boolean | true | Indicates whether the request succeeded.   - **true**: Success - **false**: Failed |
| errcode | Number | 0 | The return code. |
| errmsg | String | demo | The description of the return code. |
| request_id | String | 6bzhf2vn89pv | The request ID. |
