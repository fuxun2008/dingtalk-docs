---
title: "Batch set column widths"
---

Call this API to set the width (in pixels) of multiple consecutive columns in a DingTalk Spreadsheet, starting from a specified column. This is useful when you need to batch-adjust column widths to fit content display or print layouts. Width values are automatically rounded to positive integers, and the API returns the worksheet information after the operation.

## Request

### Basic information

| Field | Value |
| --- | --- |
| HTTP URL | `https://api.dingtalk.io/v1.0/doc/workbooks/{workbookId}/sheets/{sheetId}/setColumnsWidth` |
| HTTP Method | POST |
| Supported app type | appType-Internal app |
| Permissions | permission-Document.Workbook.Write-DingTalk Spreadsheet write permission |

### Request headers

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Yes | The access credential for calling this API. To obtain it, call [Get the access token of an internal app](https://open.dingtalk.io/document/development/obtain-the-access-token-of-an-internal-app). |

### Path parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| workbookId | String | Yes | The spreadsheet file ID. The `nodeId(dentryUuid)` returned by the [Knowledge Base API](https://open.dingtalk.io/document/development/knowledge-base-overview) is the spreadsheet `workbookId`. You can obtain it by calling [Get node](https://open.dingtalk.io/document/development/get-node) or [Create a Knowledge Base document](https://open.dingtalk.io/document/development/create-team-space-document). |
| sheetId | String | Yes | The worksheet ID or title. Call [Get all worksheets](https://open.dingtalk.io/document/development/obtain-all-worksheets) to obtain the ID and title of the worksheet. |

### Query parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| operatorId | String | Yes | The unionId of the operator. To obtain it, call [Query user details](https://open.dingtalk.io/document/development/query-user-details). If the operator does not have permission, the API returns the error `The operator has no permission`. |

### Request body

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| column | Integer | Yes | The index of the first column whose width to modify. Starts from 0. |
| width | Integer | Yes | The width, in pixels. |
| columnCount | Integer | Yes | The number of consecutive columns whose width to modify. |

### Request example
