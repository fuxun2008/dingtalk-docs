Call this API to update the status of specified to-do tasks in Process Center.

## Request

### Basic Information

| Field | Value |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/v1.0/workflow/processCentres/tasks |
| HTTP Method | PUT |
| Supported app types | appType-Internal app　appType-Third-party enterprise app |
| Permissions | permission-qyapi_aflow-Approval workflow data management permission |

### Request Header

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Yes | The access credential for calling this API. Obtain it as follows:   - Internal app: Call the [Get the access token of an internal app](/open/development/obtain-the-access-token-of-an-internal-app) API. - Third-party enterprise app: Call the API to get the access token of an organization that authorized the third-party app. |

### Request Body

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| processInstanceId | String | No | The ID of the OA Approval workflow instance. Call the [Create an instance](/open/development/create-a-ticket-approval-instance) API to get the `processInstanceId` value. |
| tasks | Array | Yes | The list of OA Approval tasks. Maximum: 20 tasks. |
| taskId | Long | Yes | The ID of the OA Approval task. Call the [Query OA Approval tasks integrated through Process Center](/open/development/query-oa-approval-tasks-integrated-through-process-center) API to get the taskId value. |
| status | String | Yes | The target task status:   - **CANCELED**: Undo - **COMPLETED**: Complete |
| result | String | No | The task result.   - If status is **COMPLETED**, specify the task result:    - **AGREE**: Accept   - **REFUSE**: Decline - If status is **CANCELED**, do not pass result. |
