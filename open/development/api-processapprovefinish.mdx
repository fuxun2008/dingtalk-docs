Call this API to notify DingTalk that an approval is approved. Supported types are overtime, leave, out-of-office, and business trip.

## API Call Description

For example, an employee is scheduled to work from 8:00 to 18:00 today and submits a leave request in the organization's own approval system. After the request is approved, call this API to notify DingTalk Attendance. The employee does not need to clock in today and is not marked as absent. The employee's status shows as leave. In another example, employee Xiaoding did not clock in on November 15, and the attendance statistics record this missed clock-in.

Call this API to notify DingTalk that an approval is approved. This changes Xiaoding's attendance on November 15 to leave, business trip, or overtime.

## Request

### Basic Information

| Field | Value |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/v1.0/attendance/approvals/finish |
| HTTP Method | POST |
| Supported app types | appType-Internal app　appType-Third-party enterprise app |
| Required permissions | permission-qyapi_attendance_group_read-Attendance group query permission |

Obtain it as follows:   - Internal app: call the [Get the access token of an internal app](/open/development/obtain-the-access-token-of-an-internal-app) API. - Third-party enterprise app: call the Get the access token of an organization authorized to a third-party app API. |

### Query Parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| userId | String | No | The userId of the employee. |

### Request Body

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| topCalculateApproveDurationParam | Object | No | Duration-related input parameters. |
| bizType | Long | No | Approval form type. Valid values:   - **1**: Overtime - **2**: Business trip or out-of-office - **3**: Leave |
| fromTime | String | No | Start time. The start time cannot be more than 31 days before the current time.  Supported formats:   - 2019-08-15 - 2019-08-15 AM - 2019-08-15 12:43 |
| toTime | String | No | End time.  Supported formats:   - 2019-08-15 - 2019-08-15 AM - 2019-08-15 12:43   **Note**  - The end time cannot be earlier than the start time. - The time span cannot exceed 360 days. - The number of days between the start time and the end time cannot exceed 31. - When `biz_type` is 1, the number of days between the start time and the end time cannot exceed 1. |
| durationUnit | String | No | Duration unit. Supported values:   - **day** - **halfDay** - **hour**: When `biz_type` is 1, only hour is supported.   The time format must match the duration unit:   - 2019-08-15 corresponds to day - 2019-08-15 AM corresponds to halfDay - 2019-08-15 12:43 corresponds to hour |
| calculateModel | Long | No | Calculation method:   - **0**: Calculate by calendar day - **1**: Calculate by working day |
| leaveCode | String | No | Unique identifier of the leave rule. Optional.  **Note**  Pass a non-empty value only when `bizType=3` (leave). The duration is then rounded according to the rounding rule set for the leave type. |
| timeZoneId | String | No | Time zone ID, in the format `Asia/Shanghai`. |
| tagName | String | No | Approval form type name, up to 20 characters. Supported values: 请假 (leave), 出差 (business trip), 外出 (out-of-office), 加班 (overtime). |
| subType | String | No | Subtype name, up to 64 characters.  **Note**  This parameter is required when the approval form type biz_type is 3. |
| approveId | String | No | Approval form ID, up to 100 characters. Custom value.  **Note**  Third-party enterprise apps must store this value. It is required when notifying approval revocation. Calling this API again with the same approveId performs an update. |
| jumpUrl | String | No | Redirect URL of the approval form, up to 200 characters.  **Note**  When users click the entry of a third-party enterprise app on the attendance statistics page, DingTalk redirects them to this URL. Pass the URL of the approval form details page. |
| overtimeDuration | String | No | Required when biz_type is 1. Overtime duration, in hours. |
| overTimeToMore | Long | No | Required when biz_type is 1:   - **1**: Convert overtime to compensatory leave - **2**: Convert overtime to pay |
