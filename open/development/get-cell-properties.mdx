---
title: "Get a cell range"
---

Call this API to retrieve cell attributes. Currently, you can retrieve the value, formula, display value, background color, font size, horizontal alignment, and vertical alignment of cells.

## Request

### Basic information

| Field | Value |
| --- | --- |
| HTTP URL | `https://api.dingtalk.io/v1.0/doc/workbooks/{workbookId}/sheets/{sheetId}/ranges/{rangeAddress}` |
| HTTP Method | GET |
| Supported app type | appType-Internal app |
| Required permission | permission-Document.Workbook.Read-Spreadsheet read permission |

### Request headers

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Yes | The access credential for calling this API. Obtain it by calling the [Get the access token of an internal app](/open/development/obtain-the-access-token-of-an-internal-app#) API. |

### Path parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| workbookId | String | Yes | The ID of the spreadsheet file. The `nodeId(dentryUuid)` returned by the [Knowledge Base API](/open/development/knowledge-base-overview#) is the `workbookId` of the spreadsheet. Obtain it by calling the [Get a node](https://open.dingtalk.com/document/development/get-node#) or [Create a Knowledge Base document](/open/development/create-team-space-document#) API. |
| sheetId | String | Yes | The ID or name of the worksheet. Obtain the value of the id or name parameter by calling the [Get all worksheets](/open/development/obtain-all-worksheets#) API. |
| rangeAddress | String | Yes | The range address. |

### Query parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| select | String | No | Filters the fields to return. If this parameter is not specified, all fields are returned.   - For example, `select=values` returns only the values field. - To return multiple fields, separate them with commas. For example, `select=values,formulas` returns only the values and formulas fields.     We recommend that you specify this parameter to improve performance and avoid API timeouts caused by adding return values later. |
| operatorId | String | Yes | The unionId of the operator.   - Obtain the unionid parameter value by calling the [Get user information by silent login code](/open/development/obtain-the-userid-of-a-user-by-using-the-log-free#) API. - Obtain the unionid parameter value by calling the [Query user details](/open/development/query-user-details#) API.     If the operator has no permission, the API returns the error `The operator has no permission`. |
