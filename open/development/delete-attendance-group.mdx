---
title: "Delete an Attendance Group"
description: "Call this API to delete an attendance group by its group\\key."
---

## Request

| **Basic Information** | |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/topapi/attendance/group/delete |
| HTTP Method | POST |
| Supported app types | appType-Internal app |
| Required permissions | permission-qyapi_attendance_group_manage-Attendance group management permission |

### Query Parameters

| Name | Type | Required | Example | Description |
| --- | --- | --- | --- | --- |
| access_token | String | Yes | 4c9ebd2xxxx | The App credential used to call this API. Obtain it by calling the [Get the access_token of an Internal App](/open/development/obtain-orgapp-token) API. |

### Request Body

| Name | Type | Required | Example | Description |
| --- | --- | --- | --- | --- |
| op_userid | String | No | user01 | The user ID of the operator. |
| group_key | String | Yes | 0151E02xxxx | The attendance group ID.  **Note**  If you identify attendance groups by group_id, call the [Convert groupId to groupKey](/open/development/groupid-to-groupkey) API to convert the group_id to a group_key. |

### Request Example

```curl
curl -X POST "https://api.dingtalk.io/topapi/attendance/group/delete" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=0d5exxxxf31e2da' \
-d 'group_key=0151E02xxxx1A917E876' \
-d 'op_userid=123456'
```

## Response

### Response Body

| Name | Type | Example | Description |
| --- | --- | --- | --- |
| result | String | BE8C35586xxxx | The attendance group ID. |
| success | Boolean | true | Indicates whether the call succeeded.   - **true**: Success - **false**: Failed |
| errmsg | String | ok | The description of the return code. |
| errcode | Number | 0 | The return code. |
| request_id | String | 3x1mikbgn3ca | The request ID. |
