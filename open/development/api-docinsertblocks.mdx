---
title: "Insert a block element"
---

Call this API to insert a block element at a specified location.

## API call description

To learn about the data structures related to document content, see [Document data structure](/open/development/document-data-structure).

## request

### Basic information

| Field | Value |
| --- | --- |
| HTTP URL | `https://api.dingtalk.io/v1.0/doc/suites/documents/{docKey}/blocks` |
| HTTP Method | POST |
| Supported app type | appType-Internal app |
| Permissions required | permission-Storage.File.Write-Organization storage file write permission |

### request header

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Yes | The access credential for calling this API. Obtain it by calling the [Get the access token of an internal app](/open/development/obtain-the-access-token-of-an-internal-app) API. |

### path parameter

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| docKey | String | Yes | The document ID (the `docKey` or `dentryUuid` of the document). After creating a document by calling the [Create a Knowledge Base document](/open/development/create-team-space-document) API, obtain the `docKey` parameter from the response. To obtain the `dentryUuid` from the document URL, take https://alidocs.dingtalk.io/i/nodes/Zxxxxa-id as an example. The `dentryUuid` is `Zxxxxa-id`. |

### query parameter

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| operatorId | String | Yes | The user's unionId. Obtain the `unionid` parameter by calling the [Query user details](/open/development/query-user-details) API. |

### request body

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| blockId | String | No | The unique identifier of the target block. Obtain the `blockId` parameter by calling the [Query block elements](/open/development/api-docblocksquery) API. If not specified, the `index` value is used. |
| index | Integer | No | When `blockId` is not provided, the `index` is used to locate the target block. The system tries to find the block at position `index` among the first-level block elements of the document, where `index` starts from 0. If not specified, the end of the document is used by default. |
| where | String | No | Whether to insert before or after the target location. Valid values: - **after**: Insert after the target location. This is the default value. - **before**: Insert before the target location. |
| element | `Map<String, Any>` | Yes | The BlockElement type to insert and the attributes required to create the corresponding type (see [Block element data structure](/open/development/block-data-structure) for details). The structure is as follows: ``` {   "blockType": enum(BlockType),   [blockType]: Object(CreateElementProperties), } ``` |
|  | Any | No | Contains the element type and the information required to create the element. |
