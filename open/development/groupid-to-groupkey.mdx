---
title: "Convert groupId to groupKey"
description: "If you only have the groupId field, call this API to obtain the groupKey."
---

Call this API to convert the groupId of an attendance group to a groupKey. The groupKey is the identifier field used in the new version of attendance groups. Some attendance groups require groupKey as a parameter. If you only have the groupId field of an attendance group, call this API to obtain the groupKey.

## Request

| **Basic Information** | |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/topapi/attendance/groups/idtokey |
| HTTP Method | POST |
| Supported app types | appType-Internal app appType-Third-party enterprise app |
| Required permissions | permission-qyapi_attendance_group_read-Attendance group query permission |

### Query Parameters

| Name | Type | Required | Example | Description |
| --- | --- | --- | --- | --- |
| access_token | String | Yes | 6d1bxxxx | The app credential used to call this API.   - For an Internal app, obtain it by calling the [Obtain the access_token of an Internal App](/open/development/obtain-orgapp-token) API. - For a Third-party enterprise app, obtain it by calling the Obtain the access_token of a Third-party Enterprise API. |

### Request Body

| Name | Type | Required | Example | Description |
| --- | --- | --- | --- | --- |
| op_user_id | String | No | user01 | The userId of the operator. |
| group_id | Number | Yes | 1586536 | The attendance group ID. Call the [Batch Obtain Attendance Group Details](/open/development/batch-obtain-attendance-group-details) API to obtain the group_id value. |

### Request Example

```curl
curl -X POST "https://api.dingtalk.io/topapi/attendance/groups/idtokey" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=ea55fdxxxx64242a' \
-d 'group_id=12' \
-d 'op_user_id=123'
```

```text

System.out.println(rsp.getBody());
```

## Response

### Response Body

| Name | Type | Example | Description |
| --- | --- | --- | --- |
| result | String | 0151E0223B1xxxx | The attendance group ID. |
| errcode | Number | 0 | The return code. |
| errmsg | String | ok | The description of the return code. |
| request_id | String | 3yt2gu3zz0qi | The request ID. |

