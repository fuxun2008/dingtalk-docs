After securing your organization Contacts data, import resources to Compute Nest.

## **Procedure**

1. Sign in to the [Developer Console](https://open-dev.dingtalk.com/), click **App Development** > **Third-party Enterprise App** > **Enterprise App**, and select the target app to open the app details page.
2. Click **App Release** > **App Deployment**, and select the appropriate deployment method.
3. Associate an Alibaba Cloud account by clicking **Select Account**:

   - If an Alibaba Cloud account is already associated, select the detected Alibaba Cloud account directly and click **Confirm**.
   - If no Alibaba Cloud account is associated, a new page opens. Click **Associate Alibaba Cloud Account** > **Confirm**. Then, on the app deployment page, reselect the detected Alibaba Cloud account and click **Confirm**. For details, see [Bind a DingTalk account to an Alibaba Cloud account](https://open.dingtalk.com/document/isvapp/bind-a-dingtalk-account-to-an-alibaba-cloud-account#).
4. After selecting the account, select **I agree to the Compute Nest Service Security Detection Authorization Agreement**, and click **Authorize Compute Nest**.
5. Click **Asset Management** to go to the associated Compute Nest **App Management**.
6. Open Compute Nest **App Management**.

   After opening App Management, create an **app group** for the corresponding region based on where your cloud resources are located. You can create app groups for multiple regions separately.

   For example, if your cloud resources are in Hangzhou, click **Create App Group**, customize the group name, and select **East China 1 (Hangzhou)** as the region. During creation, you can select the cloud resources to import. By default, you should import cloud resource instances such as SLB, ECS, RDS, and EIP.
7. After creating an app group, you can also use **Import Resources** under **Resource Management** to select the cloud resources and instances to import.

   **Important**
   1. To use RDS push, import RDS instances from the **East China 1** or **North China 3** region into the Compute Nest app, and then configure the push Data Source on the RDS page of the app deployment.
   2. The regions and zones supported by private SLB are as follows:

      |  |  |
      | --- | --- |
      | Region | Zone |
      | East China 1 (Hangzhou) | Zone B, Zone E, Zone F, Zone G, Zone H, Zone I, Zone J, Zone K |
      | East China 2 (Shanghai) | Zone B, Zone E, Zone F, Zone G, Zone L, Zone M, Zone N, Zone I, Zone H |
      | North China 2 (Beijing) | Zone B, Zone C, Zone D, Zone E, Zone F, Zone G, Zone H, Zone I, Zone K, Zone L |
      | North China 3 (Zhangjiakou) | Zone A, Zone B, Zone C |
      | South China 1 (Shenzhen) | Zone D, Zone E, Zone F |

## **Next Steps**

After importing the resources, you need to [configure and update the secure domain name](https://open.dingtalk.com/document/isvapp/configure-update-secure-domain-name).
