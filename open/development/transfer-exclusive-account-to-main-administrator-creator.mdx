---
title: "Transfer the Super Admin (creator) role of an Enterprise Account"
---

Call this API to transfer the organizations owned by an Enterprise Account in your organization to another Enterprise Account. If the receiving account does not belong to the organization, it will be added automatically.

## API call description

For example, DingTalk Organization A has two Enterprise Accounts, Enterprise Account A1 and Enterprise Account A2. Enterprise Account A1 is the creator of another organization named DingTalk Organization B (which can be viewed in the OA admin console of the current test organization under Security and Permissions > Super Admin list). Call this API to change the creator of DingTalk Organization B from Enterprise Account A1 to Enterprise Account A2.

## Request

### Basic information

| Field | Value |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/v1.0/contact/orgAccounts/mainAdministrators/change |
| HTTP Method | POST |
| Supported app type | appType-Internal app |
| Required permissions | permission-Contact.OrgAccountSecurity.ReadWrite-Read and write permissions for Contacts Enterprise Account security data |

### Request header

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Yes | The access credential for calling this API. Obtain it by calling the [Get the access token of an internal app](/open/development/obtain-the-access-token-of-an-internal-app#) API. |

### Request body

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| sourceUserId | String | Yes | The user ID of the source Enterprise Account. Obtain it in one of the following four ways:   - [Obtain the user ID by mobile phone number](/open/development/obtain-the-userid-of-your-mobile-phone-number#) - [Create an SSO Enterprise Account](/open/development/create-an-sso-account#) - [Create a DingTalk self-built Enterprise Account](/open/development/create-dingtalk-user-created-dedicated-account#) - [Invite Enterprise Accounts from other organizations to join](/open/development/invite-other-organization-specific-accounts-to-join#) |
| targetUserId | String | Yes | The user ID of the target dedicated account. Obtain it in one of the following four ways:   - [Obtain the user ID by mobile phone number](/open/development/obtain-the-userid-of-your-mobile-phone-number#) - [Create an SSO Enterprise Account](/open/development/create-an-sso-account#) - [Create a DingTalk self-built Enterprise Account](/open/development/create-dingtalk-user-created-dedicated-account#) - [Invite Enterprise Accounts from other organizations to join](/open/development/invite-other-organization-specific-accounts-to-join#) |
| effectCorpId | String | Yes | The organization ID of the organization to be transferred. For details, see Basic concepts - [CorpId](/open/dingstart/basic-concepts-beta#section-bbk-mv0-oxd). |
