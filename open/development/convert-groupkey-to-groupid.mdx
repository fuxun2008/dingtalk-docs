---
title: "Convert groupKey to groupId"
description: "Call this API with the operator's userId and the attendance group's group_key to convert the legacy attendance group identifier to the new groupId."
---

Call this API to convert the groupKey of an attendance group to a groupId.

## Request

| **Basic Information** | |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/topapi/attendance/groups/keytoid |
| HTTP Method | POST |
| Supported app types | Internal app, Third-party enterprise app |
| Required permissions | qyapi_attendance_group_read (Attendance group read permission) |

### Query Parameters

| Name | Type | Required | Example | Description |
| --- | --- | --- | --- | --- |
| access_token | String | Yes | bE74xxxx | The App credential used to call this API.   - Internal app: Obtain it by calling the [Get the access_token of an Internal App](/open/development/obtain-orgapp-token) API. - Third-party enterprise app: Obtain it by calling the Get the access_token of a Third-party Enterprise App API. |

### Request Body

| Name | Type | Required | Example | Description |
| --- | --- | --- | --- | --- |
| op_user_id | String | Yes | user01 | The userId of the operator. |
| group_key | String | Yes | 02B1Exxxx | The attendance group ID, which is the legacy attendance group identifier. Call the [Batch Get Attendance Group Details](/open/development/batch-obtain-attendance-group-details) API to obtain the group_id parameter value. |

### Request Example

```curl
curl -X POST "https://api.dingtalk.io/topapi/attendance/groups/keytoid" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=40bafxxxx9d3b06' \
-d 'group_key=0151E0xxxxA917E876' \
-d 'op_user_id=123'
```

## Response

### Response Body

| Name | Type | Example | Description |
| --- | --- | --- | --- |
| result | Number | 685935028 | The attendance group ID. |
| success | Boolean | true | Indicates whether the request succeeded.   - **true**: Success - **false**: Failed |
| errcode | Number | 0 | The return code. |
| errmsg | String | ok | The description of the return code. |
| request_id | String | 3yt2gu3zz0qi | The request ID. |
