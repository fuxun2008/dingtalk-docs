title: "Create an Attendance Group"
description: "Call this API to create an attendance group and configure its type, shifts, members, attendance locations, clock-in rules, and other settings."
---

Call this API to create an attendance group.

## Request

| **Basic Information** | |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/topapi/attendance/group/add |
| HTTP Method | POST |
| Supported App Types | appType-Internal app |
| Required Permissions | permission-qyapi_attendance_group_manage-Attendance group management permission |

### Query Parameters

| Name | Type | Required | Example | Description |
| --- | --- | --- | --- | --- |
| access_token | String | Yes | 4c9d5xxxx | The App credential used to call this API. Get it by calling the [Get the access_token of an Internal App](/open/development/obtain-orgapp-token) API. |

### Request Body

| Name | Type | Required | Example | Description |
| --- | --- | --- | --- | --- |
| op_user_id | String | Yes | 123dfd | The user ID of the operator. |
| top_group | TopGroupVo | Yes |  | The attendance group information. |
| owner | String | No | 123dfdf | The owner of the attendance group. |
| enable_emp_select_class | Boolean | No | true | Specifies whether to allow employees to select a shift to clock in when no shift is scheduled.   - **true**: Allow - **false**: Do not allow |
| corp_id | String | No | dingdfe | The CorpId of the organization. Get it on the Home page of the [Developer Console](https://open-dev.dingtalk.io/#/index). |
| skip_holidays | Boolean | No | true | Specifies whether to skip holidays.   - **true** (default): Skip - **false**: Do not skip |
| special_days | String | No | `{"onDuty":{1400000:123,1400001:123},"offDuty":[1400000,1400001]}` | The special date configuration. |
| enable_outside_camera_check | Boolean | No | true | Specifies whether to require a photo for field clock-in.   - **true**: On - **false** (default): Off |
| positions | `List<TopPositionVo>` | No |  | The attendance location settings. |
| address | String | No | No. 21, Jing'er Road, Biotech Industrial Park | The attendance address. |
| corp_id | String | No | 123dfd | The CorpId of the organization. Get it on the Home page of the [Developer Console](https://open-dev.dingtalk.io/#/index). |
| latitude | String | No | 36.687495 | The latitude. |
| longitude | String | No | 101.750329 | The longitude. |
| accuracy | String | No | 0 | The accuracy.  **Note**  This field has no actual effect and does not affect accuracy. It was deprecated on March 7, 2022. |
| title | String | No | Qinghai-Tibet Plateau Natural History Museum | The attendance location title. |
| modify_member | Boolean | No | true | Specifies whether the attendance group member information is modified.   - **true**: Modified - **false**: Not modified |
| type | String | Yes | TURN | The attendance group type:   - **FIXED**: Fixed shift attendance group - **TURN**: Shift-based attendance group - **NONE**: Flexible working hours attendance group |
| enable_camera_check | Boolean | No | true | Specifies whether to enable photo clock-in.   - **true**: On - **false** (default): Off |
| shift_vo_list | `List<TopShiftVo>` | No |  | The shift configuration. |
| id | Number | No | 123 | The shift ID. Get the id value by calling the [Get Shift Summaries](/open/development/enterprise-shift-query-in-batches) API. |
| enable_outside_check | Boolean | No | true | Specifies whether to allow field clock-in.   - **true** (default): Allow - **false**: Do not allow |
| members | `List<TopMemberVo>` | Yes |  | The attendance group member settings. |
| role | String | Yes | Attendance | The role. Fixed value: Attendance. |
| corp_id | String | No | 123dfd | The CorpId of the organization. Get it on the Home page of the [Developer Console](https://open-dev.dingtalk.io/#/index). |
| type | String | Yes | StaffMember | The type:   - StaffMember: User type - DeptMember: Department type |
| user_id | String | Yes | 1212jfkd | The ID:   - User: userId - Department: deptId |
| name | String | Yes | Day Shift Attendance | The attendance group name. |
| id | Number | No | 123 | The attendance group ID. |
| enable_next_day | Boolean | No | false | Specifies whether the settings take effect the next day.   - **true**: Yes - **false**: No |
| manager_list | String[] | No | ["userId1","userId2"] | The list of user IDs of the attendance group Sub Admins. |
| workday_class_list | Number[] | No | [0,12,12,12,12,12,0] | The weekly shift list.  **Note**   - Required for fixed shift attendance. 0 indicates a rest day. - From left to right, the values in the array represent the scheduling for each day from Sunday to Saturday. |
| default_class_id | Number | No | 1234 | The default shift ID.  **Note**  Required for fixed shift attendance. Get the id value by calling the [Get Shift Summaries](/open/development/enterprise-shift-query-in-batches) API. |
| offset | Number | No | 500 | The attendance range. |
| resource_permission_map | TopGroupManageRolePermissionVo | No |  | The permission scope of Sub Admins.   - **w**: Manage - **r**: Read-only |
| schedule | String | No | w | Employee scheduling. |
| group_member | String | No | w | Configure attendance members. |
| group_type | String | No | r | Configure the attendance type. |
| check_time | String | No | w | Configure the attendance time. |
| check_position_type | String | No | r | Configure the clock-in method. |
| over_time_rule | String | No | r | Configure overtime rules. |
| camera_check | String | No | w | Configure photo clock-in rules. |
| out_side_check | String | No | w | Configure field clock-in. |
| wifis | `List<TopWifiVo>` | No |  | The Wi-Fi clock-in configuration. |
| mac_addr | String | No | C0:E0:D0:E0:C0:0F | The MAC address. |
| ssid | String | No | OFFICE-WiFi | The SSID of the Wi-Fi network. |
| corp_id | String | No | 123dfd | The CorpId of the organization. Get it on the Home page of the [Developer Console](https://open-dev.dingtalk.io/#/index). |
| disable_check_without_schedule | Boolean | No | false | Specifies whether to prohibit employees from clocking in when no shift is scheduled.   - **true**: Prohibit - **false**: Do not prohibit |
| freecheck_work_days | Number[] | No | [1,2,3,4,5,6,0] | The workdays of the flexible working hours attendance group.  **Note**     - 0 indicates a rest day. - From left to right, the values in the array represent the scheduling for each day from Sunday to Saturday. |
| freecheck_day_start_min_offset | Number | No | 240 | The offset in minutes between the attendance start time of the flexible working hours attendance group and 00:00 of the day.  For example, 540 indicates 9:00. |
| disable_check_when_rest | Boolean | No | false | Specifies whether clock-in on rest days requires approval:   - **true**: Required - **false**: Not required |
