title: "Configure visibility of user attributes"
---

Call this API to configure the visibility of user attributes.

## Request

### Basic information

| Field | Value |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/v1.0/contact/staffAttributes/visibilitySettings |
| HTTP Method | POST |
| Supported app types | appType-Internal app　appType-Third-party enterprise app |
| Required permissions | permission-Contact.ReachableRule.ReadWrite-Management permission for Contacts data visibility |

### Request header

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Yes | The access credential used to call this API. Obtain it as follows:   - For an internal app, call the [Get the access token of an internal app](/open/development/obtain-the-access-token-of-an-internal-app#) API. - For a third-party enterprise app, call the [Get the access token of an enterprise authorized to a third-party app](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#) API. |

### Request body

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| id | Long | No | Setting ID.       - Leave it empty when adding a new setting. - Pass the ID of the setting to be modified when updating. |
| name | String | No | Name of the setting. |
| description | String | No | Description of the setting. |
| objectStaffIds | Array of String | No | The userId of employees for whom the fields are hidden. Obtain the userid parameter value by calling [Get the user ID by using the silent login code](/open/development/obtain-the-userid-of-a-user-by-using-the-log-free). |
| objectDeptIds | Array of Long | No | The deptId of departments for which the fields are hidden. Obtain the dept_id parameter value by calling [Get the department list](/open/development/user-management-acquires-the-list-departments). |
| objectTagIds | Array of Long | No | The roleId of roles for which the fields are hidden. Obtain the id parameter value by calling [Get the list of organization roles](/open/development/obtains-a-list-of-enterprise-roles). |
| hideFields | Array of String | No | The list of user attribute IDs to be hidden.   - When the user attribute to be hidden is a custom organization attribute, pass the attribute ID. - When the user attribute to be hidden is a system default attribute, pass the system default attribute list.       The system default attribute list is as follows:   - **name**: Name - **department**: Department - **email**: Mail - **manager**: Direct manager - **title**: Job Title - **mobile**: Mobile number - **ext_number**: Extension number - **work_station**: Work Location - **remark**: Alias - **hire_date**: Hire date - **job_number**: Employee ID |
| excludeStaffIds | Array of String | No | The userId of employees who can view the hidden fields. |
| excludeDeptIds | Array of Long | No | The deptId of departments that can view the hidden fields. |
| excludeTagIds | Array of Long | No | The roleId of roles that can view the hidden fields. |
| active | Boolean | No | Whether the setting takes effect.   - **true**: Takes effect. - **false**: Does not take effect. |
