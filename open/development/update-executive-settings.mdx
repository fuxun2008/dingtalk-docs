Call this API to configure executive mode for an employee.

## API call description

When an employee is set as an executive, only other executives, users in the executive allowlist, and the executive's contacts within the same organization can reach the executive through the intercepted scenarios. Other users cannot reach the executive. For example: userA is set as an executive with VIDEO_CALL as the intercepted scenario, and userB is added to the allowlist. userB and userC are regular employees of the same organization and are not contacts of userA. In this case, userB can initiate a video call to userA, but userC cannot.

## Request

### Basic information

| Field | Value |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/v1.0/contact/seniorSettings |
| HTTP Method | POST |
| Supported app type | appType-Internal app |
| Permissions | permission-qyapi_manage_addresslist-API access permission to maintain Contacts |

### Request header

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Yes | The access credential used to call this API. Obtain it by calling the [Get the access token of an internal app](/open/development/obtain-the-access-token-of-an-internal-app#) API. |

### Request body

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| seniorStaffId | String | Yes | The user ID of the employee to configure. |
| open | Boolean | Yes | Whether to enable executive mode. Valid values:   - **true**: Enable executive mode. - **false**: Disable executive mode. |
| permitStaffIds | Array of String | No | The list of user IDs of employees in the executive allowlist.      The total number of elements across **permitStaffIds**, **permitDeptIds**, and **permitTagIds** cannot exceed 200. |
| permitDeptIds | Array of Long | No | The department list in the executive allowlist.      The total number of elements across **permitStaffIds**, **permitDeptIds**, and **permitTagIds** cannot exceed 200. |
| permitTagIds | Array of Long | No | The role list in the executive allowlist.      The total number of elements across **permitStaffIds**, **permitDeptIds**, and **permitTagIds** cannot exceed 200. |
| protectScenes | Array of String | No | The executive intercept scenarios. Valid values:   - **DING_SMS**: SMS Ding message - **DING_MSG**: In-app Ding message - **CHAT**: IM chat (Direct Message and Group Chat) - **CONFERENCE_VIDEO**: Video Meeting - **CONFERENCE**: Audio Meeting - **VIDEO_CALL**: Video call - **CONFERENCE_VOIP**: Voice call - **CALL**: Conference call and office phone - **SEARCH**: Search within conference calls - **CALL_CENTER**: Call center |
