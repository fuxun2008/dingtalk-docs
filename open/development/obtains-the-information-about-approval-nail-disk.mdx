Call this API to get the ID of the approval Drive space and grant the current user permission to upload attachments.

## Request

### Basic Information

| Field | Value |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/v1.0/workflow/processInstances/spaces/infos/query |
| HTTP Method | POST |
| Supported app types | appType-Internal app |
| Required permissions | permission-Workflow.Instance.Write-Workflow instance write permission |

### Request Header

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Yes | The access credential for calling this API. Obtain it by calling the [Get the access token of an Internal app](/open/development/obtain-the-access-token-of-an-internal-app) API. |

### Request Body

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| userId | String | Yes | The userId of the user. |
| agentId | Long | No | The agentId of the app. For details, see the Agent ID description. |
