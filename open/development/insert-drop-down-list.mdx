---
title: "Insert dropdown lists"
---

Call this API to configure dropdown list options for a specified cell range in a DingTalk Spreadsheet. You can customize the text value and label color of each option. This API is useful for standardizing data entry and providing preset options (such as status or category). Once configured, users can only select values from the predefined options.

## Request

### Basic information

| Field | Value |
| --- | --- |
| HTTP URL | `https://api.dingtalk.io/v1.0/doc/workbooks/{workbookId}/sheets/{sheetId}/ranges/{rangeAddress}/insertDropdownLists` |
| HTTP Method | POST |
| Supported app type | appType-Internal app |
| Required permission | permission-Document.Workbook.Write-DingTalk Spreadsheet write permission |

### Request headers

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Yes | The access credential for calling this API. To obtain it, call the [Get the access token of an internal app](https://open.dingtalk.io/document/development/obtain-the-access-token-of-an-internal-app) API. |

### Path parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| workbookId | String | Yes | The Spreadsheet file ID. The `nodeId(dentryUuid)` returned by the [Knowledge Base API](https://open.dingtalk.io/document/development/knowledge-base-overview) is the `workbookId` of the Spreadsheet. To obtain it, call the [Get a node](https://open.dingtalk.io/document/development/get-node) or [Create a Knowledge Base document](https://open.dingtalk.io/document/development/create-team-space-document) API. |
| sheetId | String | Yes | The worksheet ID or title. To obtain the ID and title, call the [Get all worksheets](https://open.dingtalk.io/document/development/obtain-all-worksheets) API. |
| rangeAddress | String | Yes | The range address. |

### Query parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| operatorId | String | Yes | The unionId of the operator. To obtain it, call the [Query user details](https://open.dingtalk.io/document/development/query-user-details) API. If the operator does not have the required permission, the API returns the error `The operator has no permission`. |

### Request body

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| options | Array | Yes | The array of dropdown list options. |
| value | String | Yes | The value of the dropdown list option. |
| color | String | No | The color of the dropdown list option, expressed in hexadecimal notation. For example, #ff0000. |
