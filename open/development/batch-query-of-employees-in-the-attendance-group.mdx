---
title: "Query the List of Attendance Members"
description: "Call this API to query, page by page, the employees who are attendance members of a specified attendance group based on the attendance group's group_key."
---

Call this API to query the employees who are attendance members of a specified attendance group based on the attendance group's groupKey. If departments are configured as attendance members, this API cannot return the department IDs.

## Request

| **Basic Information** | |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/topapi/attendance/group/users/query |
| HTTP Method | POST |
| Supported app types | appType-Internal app |
| Required permissions | permission-qyapi_attendance_group_read-Attendance group query permission |

### Query Parameters

| Name | Type | Required | Example | Description |
| --- | --- | --- | --- | --- |
| access_token | String | Yes | 4c9ebd2b1534xxxx | The App credential used to call this API. Obtain it by calling the [Get the access_token of an Internal App](/open/development/obtain-orgapp-token) API. |

### Request Body

| Name | Type | Required | Example | Description |
| --- | --- | --- | --- | --- |
| size | Number | No | 50 | The page size. |
| cursor | String | Yes | 10 | The last user ID of the previous batch. Pass null or an empty value to start the query from the beginning. |
| op_userid | String | No | user01 | The user ID of the operator. |
| group_key | String | Yes | CEDDFFxxxx | The attendance group ID.  **Note**  If your attendance group identifier is group_id, call the [Convert groupId to groupKey](/open/development/groupid-to-groupkey) API to convert group_id to group_key. |

### Request Example

```curl
curl -X POST "https://api.dingtalk.io/topapi/attendance/group/users/query" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=d2ee6exxxx9266c' \
-d 'cursor=%5C%22%5C%22' \
-d 'group_key=0151Exxxx17E876' \
-d 'op_userid=123456' \
-d 'size=50'
```

## Response

### Response Body

| Name | Type | Example | Description |
| --- | --- | --- | --- |
| request_id | String | ntxswpdprw5d | The request ID. |
| result | DingOpenResult |  | The returned result. |
| result | Result |  | The query result. |
| user_list | String[] | user01 | The list of users. |
| has_more | String | false | Indicates whether more data is available.   - **true**: Yes - **false**: No |
| errcode | Number | 0 | The return code. |
| errmsg | String | ok | The description of the return code. |
| success | Boolean | true | Indicates whether the call succeeded.   - **true**: Success - **false**: Failed |
