AI capabilities are specific functions or services that accomplish a complete task by using a series of AI and engineering technologies. A complete Magic Wand app usually consists of one or more skills that work together to deliver complex and diverse AI functions and tasks.

An AI capability usually consists of components such as an execution chain, a model, prompt engineering, plugins, and AI cards. For a detailed introduction to AI capability components, see Component Introduction.

## **Prerequisites**

1. Complete the [Create an App](/open/dingstart/create-application) process.
2. Add the Magic Wand app capability. For details, see Add AI App Capabilities.

## **Procedure**

1. Find **AI App** in the left navigation bar, then click AI Capabilities to open the AI Capabilities page.
2. Create an AI capability.

   - Option 1: Create from a template. The platform provides multiple AI capability templates covering various scenarios such as recruitment, administrative consultation, language translation, and intelligent Q&A, helping you get started with AI app development quickly.
   - Option 2: Create directly. If the templates do not meet your business needs, create a blank AI capability directly and build it from scratch.

   After the skill is created, the system automatically opens the skill building page.

3. Build the AI capability.

   1. Select an execution chain that fits your business scenario. For an introduction to general execution chains and typical business scenarios.
   2. Based on the selected execution chain, select the other skill components you need. For example, the large model execution chain requires the general model and prompt template components. Therefore, select a model and a prompt template in the component panel on the left of the skill building page.
   3. Enter the parameter values for the components. If an attribute in a component is marked with "**\***", it is a required parameter; otherwise, it is optional. For a detailed introduction to each component and its parameters, see Component Introduction.
   4. Based on the dependencies between the components, connect all components by dragging to combine them into a complete execution chain, then click **Save**.
4. Configure the trigger method.

   |  |  |  |
   | --- | --- | --- |
   | **Configuration Item** | | **Description** |
   | Basic Information | AI Capability Name | The skill name, with a maximum length of 6 characters. |
   | AI Capability Description | Further description of the skill, shown to users, with a maximum length of 15 characters. |
   | Common Prompts | Prompt Title | An example title of a common question from users, used to guide users to trigger the skill. |
   | Prompt Description | An example description of a common question from users, used to guide users to trigger the skill. |
   | Associated Prompts, More Examples | | Enter more phrasings similar to the common prompts.  Note: Prompts are not shown to users and are provided only to the model to improve skill recognition. |
5. After the configuration is complete, click **Save**.
