Call this API to get a paginated list of overtime rules configured in attendance clock-in settings, including each rule's name and ID.

## API Call Description

For example, suppose your organization's attendance rules management contains three overtime rules: **Calculate overtime by clock-in time after approval**, **Calculate overtime by approval time**, and **Calculate overtime by clock-in time**.

Call this API to get the rule name and rule ID of all three overtime rules.

Overtime rules are managed under **Attendance Rules Management** > **Overtime Rules**, where you can add a rule via **Add Overtime Rule** and **Edit** or **Delete** existing ones. The three example rules behave as follows:

| Rule name | Content (workday / rest day / holiday) | Application scope |
| --- | --- | --- |
| Calculate overtime by approval time | Overtime must be approved; overtime duration is based on the approval form | Entire company (except those with other overtime rules) |
| Calculate overtime by clock-in time after approval | Overtime must be approved; based on clock-in, but cannot exceed the approval form duration | Not in use |
| Calculate overtime by clock-in time | Overtime requires no approval; overtime duration is calculated from clock-in time | Not in use |

## Request

### Basic Information

| Field | Value |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/v1.0/attendance/overtimeSettings |
| HTTP Method | GET |
| Supported app types | appType-Internal app　appType-Third-party enterprise app |
| Required permissions | permission-qyapi_attendance_group_read-Attendance group read permission |

### Request Header

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Yes | The access credential for calling this API. Obtain it as follows:   - Internal app: Call the [Get the access token of an internal app](/open/development/obtain-the-access-token-of-an-internal-app) API. - Third-party enterprise app: Call the API for getting the access token of an organization that has authorized a third-party app. |

### Query Parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| pageNumber | Long | Yes | The starting page number.  The value starts from 1. |
| pageSize | Long | Yes | The page size.  The maximum value is 50. |
