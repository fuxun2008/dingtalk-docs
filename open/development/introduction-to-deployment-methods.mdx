## **What Is Compute Nest**

Compute Nest is a service management PaaS platform open to service providers (including enterprise app service providers, IT integration service providers, delivery service providers, and managed service providers) and users. Compute Nest delivers an efficient, convenient, and secure service experience. Service providers can deploy, deliver, and manage services on Alibaba Cloud more effectively, while users can centrally manage the various services they subscribe to from different service providers on Alibaba Cloud.

## Deployment Methods

Organization Contacts (user names, user job titles, and department names) are important, sensitive Organization Data. Service providers must safeguard the security of Organization Contacts Data; otherwise, they cannot list their apps on the App Marketplace.

|  |  |  |  |  |
| --- | --- | --- | --- | --- |
| **Solution Overview** | **Deployment Method** | **Resource Requirements** | **Pros and Cons** | **Activation Method** |
| Integrate the DingTalk Security Rendering Component yourself to encrypt Contacts | Compute Nest + DingTalk Security Rendering Component | - ECS - SLB (currently only CLB is supported) - RDS - EIP | - Pros: No need to purchase Data Security Center. - Cons: Involves integration and modification costs. | - Method 1: Admin activates it in the App Marketplace - Method 2: Offline activation via product QR Code |
| Enable Data Security Center to comprehensively safeguard all Data, including Contacts Data | Compute Nest + [Data Security Center](https://help.aliyun.com/product/88674.html?spm=ding_open_doc.document.0.0.7ea04a97BcYnJr) | - ECS - SLB (currently only CLB is supported) - RDS - EIP - DSC | Pros: No integration or modification required. |
| Do not list on the App Marketplace (not recommended) | Compute Nest | - ECS - SLB (currently only CLB is supported) - RDS - EIP | Cons: Can only be promoted through your own channels. | Offline activation via product QR Code |
