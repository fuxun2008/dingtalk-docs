Call this API to create or update an approval template.

## API Call Description

- Each organization can create up to 200 templates in Process Center. After the limit is reached, calls to this API return an error.
- The DingTalk client shows only the first three fields of the template form in the approval list.
- Save the template name and the processCode returned by this API for each self-built approval workflow template you create. Other APIs require these values.
- Self-built OA Approval templates support only the approval components listed in this document. Other components are not supported.

## Request

### Basic Information

| Field | Value |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/v1.0/workflow/processCentres/schemas |
| HTTP Method | POST |
| Supported app types | appType-Internal app　appType-Third-party enterprise app |
| Required permissions | permission-Workflow.Form.Write-Workflow template write permission |

| x-acs-dingtalk-access-token | String | Yes | The access credential for calling this API. Obtain it as follows:   - Internal app: Call the API that gets the access token of an internal app. - Third-party enterprise app: Call the API that gets the access token of an organization that authorized the third-party app. |

### Request Body

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| processCode | String | No | The form ProcessCode. Specify it when you update a form template. To get the processCode value, call the [Get template code](/open/development/obtain-the-template-code) API.      If you pass ProcessCode to modify and update form components, you cannot delete or modify controls already used as conditional branches in the workflow design. For example, if the original form uses the single-select control [Employee type] as a branch condition, you cannot modify the control type of the [Employee type] field or delete it when you update this form.     - Leave this parameter empty to create a new template. - Specify this parameter to update the approval template that matches the passed value. |
