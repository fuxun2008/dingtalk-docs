Call this API to query the organizations in which an Enterprise Account holds the creator identity, and retrieve information about those organizations.

## Request

### Basic information

| Field | Value |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/v1.0/contact/orgAccounts/ownedOrganizations |
| HTTP Method | GET |
| Supported app type | appType-Internal app |
| Permissions | permission-Contact.OrgAccountSecurity.ReadWrite-Read and write permissions for Contacts Enterprise Account security data |

### Request header

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Yes | The access credential for calling this API. Obtain it by calling the [Get the access token of an internal app](/open/development/obtain-the-access-token-of-an-internal-app#) API. |

### Query parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| userId | String | Yes | The userid of the Enterprise Account. Obtain it in one of the following four ways:   - [Obtain the userid of your mobile phone number](/open/development/obtain-the-userid-of-your-mobile-phone-number#) - [Create an SSO Enterprise Account](/open/development/create-an-sso-account#) - [Create a DingTalk user-created Enterprise Account](/open/development/create-dingtalk-user-created-dedicated-account#) - [Invite Enterprise Accounts from other organizations to join](/open/development/invite-other-organization-specific-accounts-to-join#) |
