---
title: "Batch query nodes"
---

Call this API to query multiple nodes in a batch.

## Request

### Basic information

| Field | Value |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/v2.0/wiki/nodes/batchQuery |
| HTTP Method | POST |
| Supported app types | appType-Internal app　appType-Third-party enterprise app |
| Required permissions | permission-Wiki.Node.Read-Knowledge Base node read permission |

### Request headers

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Yes | The access credential for calling this API. Obtain it as follows:   - For an internal app, call the [Get the access token of an internal app](https://open.dingtalk.io/document/development/obtain-the-access-token-of-an-internal-app#) API. - For a third-party enterprise app, call the [Get the access token of an enterprise authorized to a third-party app](https://open.dingtalk.io/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#) API. |

### Query parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| operatorId | String | Yes | The unionId of the operator. |

### Request body

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| nodeIds | Array of String | Yes | The node IDs.    The maximum size is 20. |
| option | Object | No | Optional parameters. |
| withStatisticalInfo | Boolean | No | Whether to retrieve statistical information:   - **true**: Retrieve. - **false**: Do not retrieve.     The default value is false. |
| withPermissionRole | Boolean | No | Whether to retrieve permission information:   - **true**: Retrieve. - **false**: Do not retrieve.     The default value is false. |
