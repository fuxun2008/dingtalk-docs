Call this API to check whether an Organization Admin has management permissions for an app.

## Request

### Basic information

| Field | Value |
| --- | --- |
| HTTP URL | `https://api.dingtalk.io/v1.0/microApp/apps/{agentId}/users/{userId}/adminAccess` |
| HTTP Method | GET |
| Supported app type | appType-Third-party enterprise app |
| Permission requirement | permission-qyapi_get_member-Read permission for user information |

### Request header

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Yes | The access credential for calling this API. Obtain it by calling the [Get the access token of an authorized organization for a third-party app](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#) API. |

### Path parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| agentId | Long | Yes | The agentId assigned when the authorized organization installs the third-party app. Obtain the value by calling the [Get the authorization information after an organization activates an app](https://open.dingtalk.com/document/development/obtains-the-authorization-information-after-the-enterprise-activates-the-application-1#) API. |
| userId | String | Yes | The user ID of the Organization Admin of the authorized organization. Obtain the value by calling the [Get the admin list](/open/development/query-the-administrator-list#) API. |

### Request example

HTTP

```http
GET /v1.0/microApp/apps/111/users/manager1123/adminAccess HTTP/1.1
Host:api.dingtalk.io
x-acs-dingtalk-access-token:xxx
Content-Type:application/json
```
