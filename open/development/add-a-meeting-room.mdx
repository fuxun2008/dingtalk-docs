title: "Book a room"
---

Call this API to book a room for the specified event.

## Request

### Basic information

| Field | Value |
| --- | --- |
| HTTP URL | `https://api.dingtalk.io/v1.0/calendar/users/{userId}/calendars/{calendarId}/events/{eventId}/meetingRooms` |
| HTTP Method | POST |
| Supported app types | appType-Internal app　appType-Third-party enterprise app |
| Permissions | permission-Calendar.Event.Write-Write permission for events in the Calendar app |

### Request header

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Yes | The access credential used to call this API. Obtain it as follows:   - For an internal app, call the [Obtain the access token of an internal app](/open/development/obtain-the-access-token-of-an-internal-app#) API. - For a third-party enterprise app, call the [Obtain the access token of the authorized enterprise](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#) API. |

### Path parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| userId | String | Yes | The unionId of the event creator. Call the [Query user details](/open/development/query-user-details#) API to obtain it. |
| calendarId | String | Yes | The ID of the calendar that the event belongs to. The value is fixed as `primary`, which represents the user's primary calendar. |
| eventId | String | Yes | The event ID. Call the [Query an event list](/open/development/query-an-event-list#) API to obtain the value of the `id` parameter. |

### Request body

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| meetingRoomsToAdd | Array | Yes | The list of roomId values for rooms to be booked. Up to 5 rooms can be added to a single event. |
| roomId | String | No | The list of roomId values for rooms to be booked. Call the [Query the room list](/open/development/check-the-meeting-room-list#) API to obtain the values. Up to 5 rooms can be added to a single event. |

### Request example

HTTP

```http
POST /v1.0/calendar/users/U5Kxxxxx/calendars/primary/events/cnNTxxxxx/meetingRooms HTTP/1.1
Host:api.dingtalk.io
x-acs-dingtalk-access-token:xxxxx
Content-Type:application/json

{
  "meetingRoomsToAdd" : [ {
    "roomId" : "4002fxxxxx"
  } ]
}
```
