title: "Copy a document"
---

Call this API to copy a document in Knowledge Base or Drive.

## Request

### Basic information

| Field | Value |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/v2.0/doc/dentries/copy |
| HTTP Method | POST |
| Supported app type | appType-企业内部应用 |
| Required permissions | permission-SNS.Document.WorkspaceDocument.Write-SNS知识库文档写权限 |

### Request header

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Yes | The API credential. Obtain it by calling the [Get user token](https://open.dingtalk.io/document/development/obtain-user-token) API. |

### Request body

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| param | Object | Yes | The required parameter. |
| sourceDentryUuid | String | Yes | The unique identifier of the source file. Use the value of the dentryUUid field returned by the [File Search](https://open.dingtalk.io/document/development/search-for-files) API. |
| targetParentDentryUuid | String | Yes | The unique identifier of the target file. Use the value of the dentryUUid field returned by the [File Search](https://open.dingtalk.io/document/development/search-for-files) API. |
| targetPreDentryUuid | String | No | The unique identifier of the file that precedes the target (optional). Use the value of the dentryUUid field returned by the [File Search](https://open.dingtalk.io/document/development/search-for-files) API. |
