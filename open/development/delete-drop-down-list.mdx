---
title: "Delete dropdown lists"
---

Call this API to remove dropdown list configurations from a specified cell range in a DingTalk Spreadsheet. Use this API to cancel data entry constraints and restore cells to free-input mode. The deletion only removes the dropdown option definitions; existing values in the cells are not affected.

## Request

### Basic information

| Field | Value |
| --- | --- |
| HTTP URL | `https://api.dingtalk.io/v1.0/doc/workbooks/{workbookId}/sheets/{sheetId}/ranges/{rangeAddress}/deleteDropdownLists` |
| HTTP Method | POST |
| Supported app type | appType-Internal app |
| Required permissions | permission-Document.Workbook.Write-DingTalk Spreadsheet write permission |

### Request headers

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Yes | The access credential for calling this API. To obtain it, call [Get the access token of an internal app](https://open.dingtalk.io/document/development/obtain-the-access-token-of-an-internal-app). |

### Path parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| workbookId | String | Yes | The ID of the spreadsheet file. The `nodeId(dentryUuid)` returned by the [Knowledge Base API](https://open.dingtalk.io/document/development/knowledge-base-overview) is the `workbookId` of the spreadsheet. To obtain it, call [Get node](https://open.dingtalk.io/document/development/get-node) or [Create a Knowledge Base document](https://open.dingtalk.io/document/development/create-team-space-document). |
| sheetId | String | Yes | The ID or title of the worksheet. To obtain the ID and title, call [Get all worksheets](https://open.dingtalk.io/document/development/obtain-all-worksheets). |
| rangeAddress | String | Yes | The range address. |

### Query parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| operatorId | String | Yes | The unionId of the operator. To obtain it, call [Query user details](https://open.dingtalk.io/document/development/query-user-details). If the operator has no permission, the API returns the error `The operator has no permission`. |
