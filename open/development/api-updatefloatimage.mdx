Call this API to update the attributes of an existing floating image in a DingTalk Spreadsheet, including the image source, anchor position, and size offsets. Partial updates are supported—fields that are not provided retain their original values. For example, pass only `anchor` to adjust the image position without affecting other attributes. This API is suitable for adjusting the image position, replacing the image source, or modifying the display size. After a successful call, the complete attributes of the updated image are returned.

## Request

### Basic information

| Field | Value |
| --- | --- |
| HTTP URL | `https://api.dingtalk.io/v1.0/doc/workbooks/{workbookId}/sheets/{sheetId}/floatImages/{id}` |
| HTTP Method | PUT |
| Supported app type | appType-Internal app |
| Permissions required | permission-Document.Workbook.Write-DingTalk Spreadsheet write permission |

### Request headers

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Yes | The access credential for calling this API. Call the [Get the access token of an internal app](/open/development/obtain-the-access-token-of-an-internal-app) API to obtain it. |

### Path parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| workbookId | String | Yes | The ID of the Spreadsheet file. The `nodeId(dentryUuid)` returned by the [Knowledge Base API](/open/development/knowledge-base-overview) is the Spreadsheet `workbookId`. Obtain it by calling the [Get a node](https://open.dingtalk.com/document/development/get-node) or [Create a Knowledge Base document](/open/development/create-team-space-document) API. |
| sheetId | String | Yes | The ID or title of the Worksheet. Call the [Get all worksheets](/open/development/obtain-all-worksheets) API to obtain the ID and title of the Worksheet. |
| id | String | Yes | The specified floating image ID. Obtain it through the "Query floating images" API. |

### Query parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| operatorId | String | Yes | The unionId of the operator. Call the [Query user details](/open/development/query-user-details) API to obtain it. If the operator does not have permission, the API returns the error `The operator has no permission`. |

### Request body

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| src | String | No | The resource address of the floating image. Call the [Get resource upload information](/open/development/api-getresourceuploadinfo) API to obtain `resourceUrl`. |
| anchor | Object | No | The anchor position that specifies the Cell where the image is anchored. |
| row | Integer | No | The row number of the anchor (starting from 0). |
| col | Integer | No | The column number of the anchor (starting from 0). |
| coordinate | Object | No | The image size and the offset relative to the anchor Cell. |
| width | double | No | The image width, in pixels. |
| height | double | No | The image height, in pixels. |
| offsetX | double | No | The horizontal offset relative to the top-left corner of the anchor Cell, in pixels. |
| offsetY | double | No | The vertical offset relative to the top-left corner of the anchor Cell, in pixels. |
