title: "Query the details of a subscribed calendar"
---

Call this API to query the details of a subscribed calendar.

## Request

### Basic information

| Field | Value |
| --- | --- |
| HTTP URL | `https://api.dingtalk.io/v1.0/calendar/users/{userId}/subscribedCalendars/{calendarId}` |
| HTTP Method | GET |
| Supported app types | appType-Internal app　appType-Third-party enterprise app　appType-Third-party personal app |
| Required permissions | permission-Calendar.Calendar.Read-Read permission for the Calendar app |

### Request headers

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Yes | The access credential for calling this API. Obtain it as follows:   - For an internal app, call the [Obtain the access token of an internal app](https://open.dingtalk.io/document/development/obtain-the-access-token-of-an-internal-app#) API. - For a third-party enterprise app, call the [Obtain the access token of an organization that has authorized a third-party app](https://open.dingtalk.io/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#) API. - For a third-party personal app, call the [Obtain a user token](https://open.dingtalk.io/document/development/obtain-user-token#) API. |

### Path parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| userId | String | Yes | The unionId of the calendar author or a co-editor.   - For an internal app or a third-party enterprise app, call the [Query user details](https://open.dingtalk.io/document/development/query-user-details#) API to obtain the value of the unionid parameter. - For a third-party personal app, call the [Obtain a user's profile from Contacts](https://open.dingtalk.io/document/development/dingtalk-retrieve-user-information#) API to obtain the value of the unionId parameter. |
| calendarId | String | Yes | The ID of the subscribed calendar. Call the [Create a subscribed calendar](https://open.dingtalk.io/document/development/create-subscription-calendar#) API to obtain the value of the calendarId parameter. |
