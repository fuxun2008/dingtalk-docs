---
title: "Authorize Preview of Approval Attachments"
description: "Call this API to authorize a specified user to preview Drive attachments in an approval instance. Batch authorization by approval instance ID and attachment ID is supported."
---

Call this API to authorize the preview of approval attachments.

## API Call Description

<Note>
Use this API together with the Drive JSAPI.
</Note>

1. Get the spaceId of the approval Drive space. Call the [Get Approval Drive Space Information](/open/development/obtains-the-information-about-approval-nail-disk) API to get the spaceId of the approval Drive space.
2. Based on the spaceId of the approval Drive space, get the Drive attachment file information in a web app (H5 Micro app) or Mini program by uploading an attachment to Drive or selecting a file from Drive.
3. Get the approval instance processInstanceId. Call the [Create an Approval Instance](/open/development/create-an-approval-instance) API to get the value of the InstanceId parameter.
4. Using the information above, call this API to grant the user permission to preview approval attachments. Call this API for authorization before each preview of an approval attachment.
5. Call the **Preview Drive File** API to preview the file.

## Request

### Basic Information

| Field | Value |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/v1.0/workflow/processInstances/spaces/authPreview |
| HTTP Method | POST |
| Supported app types | appType-Internal app　appType-Third-party enterprise app |
| Permission requirements | permission-Workflow.Instance.Write-Workflow instance write permission |

### Request Header

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Yes | The access credential for calling this API. Obtain it as follows:   - Internal app: Call the [Get the Access Token of an Internal App](/open/development/obtain-the-access-token-of-an-internal-app) API. - Third-party enterprise app: Call the API for getting the access token of an organization authorized by a third-party app. |

### Request Body

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| userId | String | Yes | The userId of the user authorized to preview the attachment. |
| agentId | Long | No | The agentId of the app:   - Internal app: View the Agent ID information. - Third-party enterprise app: Call the API for getting organization authorization information to get the value of the `agentid` parameter. |
| processInstanceId | String | Yes | The approval instance ID.   - Call the [Create an Approval Instance](/open/development/create-an-approval-instance) API to get the value of the `InstanceId` parameter. - Call the [Get a List of Approval Instance IDs](/open/development/obtain-an-approval-list-of-instance-ids) API to get the value of the `list` parameter. |
| fileId | String | Yes | The approval attachment ID.      The fileId must match the fileId of the file in the attachment component of the created approval instance. Otherwise, a no-permission error message is returned. |
| fileIdList | Array of String | No | The list of attachment IDs. Batch authorization is supported. The maximum list length is 20. |
| withCommentAttatchment | Boolean | No | Whether to include attachments in comments. Attachments in comments are ignored by default. |
