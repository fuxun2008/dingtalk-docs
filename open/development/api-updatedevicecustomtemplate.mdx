---
title: "Update a custom screen template"
---

Update the content of a custom screen template based on its template ID.

## Request

### Basic information

| Field | Value |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/v1.0/rooms/devices/screens/templates |
| HTTP Method | PUT |
| Supported app types | appType-Internal app　appType-Third-party enterprise app |
| Required permissions | permission-Rooms.DeviceTemplate.Write-Write permission for custom screens of DingTalk Meeting Rooms |

### Request headers

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Yes | API credential. Obtain it by calling the [Get user token](https://open.dingtalk.io/document/development/obtain-user-token#) API.  When you construct the link to obtain the user token, the `code` parameter must be obtained with the scope set to user ID and organization ID, that is, `scope=openid corpid`. |

### Request body

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| templateName | String | Yes | The template name. |
| logo | String | No | The template logo. Call the [Upload media files](https://open.dingtalk.io/document/development/upload-media-files#) API to obtain the mediaId. Image dimensions: 240\*240. A single image must not exceed 1 MB. |
| orgName | String | No | The organization name displayed in the template. |
| customDoc | String | No | The custom text content of the template. |
| bgUrl | String | No | The custom background URL of the template. |
| bgImgList | Array of String | No | Image mediaIds. Call the [Upload media files](https://open.dingtalk.io/document/development/upload-media-files#) API to obtain the `media_id` response parameter. Up to 9 images can be uploaded. A single image must not exceed 5 MB. |
| instruction | Boolean | No | Whether to display the usage instructions. Default: false. Values:   - true: display - false: do not display |
| bgType | Integer | No | The custom background type of the template. Default: 1. Values:   - 1: image - 2: URL |
| isPicTop | Integer | No | Whether to display the home information bar. Default: 1. Values:   - 0: display - 1: do not display |
| hideServerCodeWhenProjecting | Boolean | No | Whether to hide the cast code during casting. Default: false. Values:   - true: hide - false: do not hide |
| showCalendarTitle | Boolean | No | Whether to display the event title on the event card. Default: false. Values:   - true: display - false: do not display |
| desensitizeUserName | Boolean | No | Whether to mask the booker's name on the event card. Default: false. Values:   - true: mask - false: do not mask |
| picturePlayInterval | Integer | No | The carousel interval, in seconds, for custom background images. |
| showCalendarCard | Boolean | No | Whether to display the event card. Default: false. Values:   - true: display - false: do not display |
| showFunctionCard | Boolean | No | Whether to display the function card. Default: false. Values:   - true: display - false: do not display |
| deviceUnionIds | Array of String | No | The device unionIds. Obtain this parameter from the [Device-to-Room binding change](https://open.dingtalk.io/document/development/org-event-overview#) event subscription. |
| groupIds | Array of Long | No | The group IDs. Call the [Query the list of Room groups](https://open.dingtalk.io/document/development/query-meeting-rooms-groups#) API to obtain them. |
| roomIds | Array of String | No | The Room IDs. Call the [Query the list of Rooms](https://open.dingtalk.io/document/development/check-the-meeting-room-list#) API to obtain them. |
| templateId | Long | Yes | The template ID. Call the [Query the list of custom screen templates](https://open.dingtalk.io/document/development/api-querydevicecustomtemplatelist#) API to obtain it. |
