Call this API to retrieve a list of approval instance IDs for relevant departments within your permission scope.

## API Call Description

### API Call Flow

1. Call this API to get the approval instance IDs for an approval workflow.
2. Call the [Get the Details of a Single Approval Instance](/open/development/obtains-the-details-of-a-single-approval-instance-pop) API to get the details of each approval instance.

### Usage Notes

- If you pass only **startTime**, it cannot be more than 120 days before the current time. If you omit **endTime**, it defaults to the current time.
- If you pass both **startTime** and **endTime**, the time range cannot exceed 120 days, and **startTime** cannot be more than 365 days before the current time.
- The total number of instance IDs retrieved in batches (through repeated calls) cannot exceed 10,000.

## Request

### Basic Information

| Field | Value |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/v1.0/workflow/processes/instanceIds/query |
| HTTP Method | POST |
| Supported App types | appType-Internal app |
| Required permissions | permission-Workflow.Instance.Read-Workflow instance read permission |

### Request Header

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Yes | The access credential for calling this API. Get it by calling the [Get the Access Token of an Internal App](/open/development/obtain-the-access-token-of-an-internal-app) API. |

### Request Body

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| processCode | String | Yes | The unique code of the approval workflow.   - Call the [Create or Update an Approval Form Template](/open/development/create-an-approval-form-template) API to get the `processCode` value. - See [Glossary - processCode](/open/development/workflow-overview). |
| startTime | Long | Yes | The start time of the approval instance, as a Unix timestamp in milliseconds.    For example, to get approval forms submitted between April 10, 2020 and April 14, 2020, pass 1586448000000, the timestamp for April 10, 2020 00:00:00. |
| endTime | Long | No | The end time of the approval instance, as a Unix timestamp in milliseconds.    For example, to get approval forms submitted between April 10, 2020 and April 14, 2020, pass 1586879999000, the timestamp for April 14, 2020 23:59:59. |
| nextToken | Long | Yes | The pagination cursor.   - For the first call, pass 0. - For subsequent calls, pass the nextToken returned by the previous call. |
| maxResults | Long | Yes | The pagination parameter specifying the page size. Maximum value: 20. |
| userIds | Array of String | No | The list of initiator user IDs. Maximum list length: 10. Get them by calling the [Get the List of User IDs in a Department](/open/development/query-the-list-of-department-userids) API. |
| statuses | Array of String | No | The workflow instance status:   - **RUNNING**: In approval - **TERMINATED**: Revoked - **COMPLETED**: Approval completed     If omitted, instance IDs in all statuses are returned. |
