---
title: "Batch Add Attendance Members"
description: "Call this API to add up to 100 employees at a time to a specified attendance group by group_key."
---

Call this API to add attendance members in batches to a specified attendance group by groupKey. This API supports adding employees only. It does not support adding departments.

## Request

| **Basic Information** | |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/topapi/attendance/group/users/add |
| HTTP Method | POST |
| Supported app type | appType-Internal app |
| Permissions | permission-qyapi_attendance_group_manage-Attendance group management permission |

### Query Parameters

| Name | Type | Required | Example | Description |
| --- | --- | --- | --- | --- |
| access_token | String | Yes | 4c9ebd2b1534xxxx | The app credential used to call this API. Obtain it by calling the [Get the access_token of an Internal App](/open/development/obtain-orgapp-token) API. |

### Request Body

| Name | Type | Required | Example | Description |
| --- | --- | --- | --- | --- |
| op_userid | String | No | user01 | The user ID of the operator. |
| group_key | String | Yes | CEDDxxxx | The attendance group ID.  **Note**  If your attendance group identifier is group_id, call the [Convert groupId to groupKey](/open/development/groupid-to-groupkey) API to convert group_id to group_key. |
| user_id_list | String[] | Yes | user02,user03 | The list of user IDs. Maximum: 100. |

### Request Example

```curl
curl -X POST "https://api.dingtalk.io/topapi/attendance/group/users/add" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=e0f3d9xxxxa9b71' \
-d 'group_key=0151E0xxxx917E876' \
-d 'op_userid=123456' \
-d 'user_id_list=123456%2C123457'
```

## Response

### Response Body

| Name | Type | Example | Description |
| --- | --- | --- | --- |
| result | Result |  | The returned result. |
| error_info_list | ErrorInfo[] |  | The list of errors. |
| failure_list | String[] |  | The list of failed entries. |
| msg | String | business fault | The error message. |
| code | String | 1000 | The error code. |
| success_list | String[] |  | The list of successful entries. |
| errcode | Number | 0 | The return code. |
| errmsg | String | ok | The description of the return code. |
| success | Boolean | true | Whether the request succeeded.   - **true**: Success - **false**: Failed |
| request_id | String | w8iju9gfb236 | The request ID. |
