Call this API to get the node information in an approval form process.

## API Call Description

### Usage Notes

Call this API to get the following node information:

- For self-selected nodes: the node name, approval type, approver settings, selection scope, approval method for multiple approvers, node activation type, and more.
- For non-self-selected nodes: the node name, approval type, approver settings, approval method for multiple approvers, node activation type, and more.

An approval node has the following configuration options:

**Type**: **Manual Approval**, **Auto Approve**, or **Auto Reject**.

**Settings** for the **approver**: **Specified Members**, **Initiator Self-Select**, **Consecutive Multi-Level Managers**, **Department Manager**, **Direct Manager**, **Role**, or **Initiator Himself**. For self-select, set a selectable **Scope** (for example, **Specified Members**) and single-person or multi-person mode.

**Approval method for multiple approvers**:

| Method | Behavior |
| --- | --- |
| Sequential | Approvers act one after another |
| Countersign | All approvers must approve |
| Or-sign | One approver's approval or rejection determines the outcome |

### Use Cases

1. Determine whether self-selected nodes exist. Use this API together with the [Create an approval instance](/open/development/create-an-approval-instance) API.

   **Note**: This API applies only when you call the **Create an approval instance** API without specifying an approval process, and reuse the approval process configured in the approval admin console.

   The approval template editor organizes configuration into four steps: **Basic Settings**, **Form Design**, **Process Design**, and **Advanced Settings**. The Process Design canvas lays out the Approval process as a top-to-bottom sequence of nodes:

   1. **Initiator** node: the person who starts the approval instance.
   2. **Self-selected node** (a node where the initiator picks the handler): shown as **Initiator self-select**.
   3. **Approver** node: the designated approver.

   A self-selected node lets the initiator choose who handles that step when submitting the request.
2. Get the node information configured in an approval template, such as the node type and node name.

### Check for Self-Selected Nodes

#### With Self-Selected Nodes

Call this API. The returned information contains a node whose `activityType` field value is `target_select`.

When you use this API together with the **Create an approval instance** API, note the following:

- Use the `actorKey` field value of the current node as the actionerKey parameter of the Create an approval instance API.
- Use the `workNo` field value in `actorSelectionRange` as the `actionerUserIds` parameter of the Create an approval instance API.

  In the Approval process designer, configure the self-selected node in the **Process Design** step (**Basic Settings** > **Form Design** > **Process Design** > **Advanced Settings**). The example flow is ordered as: **Initiator** > **Self-selected node** (type **Initiator selects**) > **Approver**.

#### Without Self-Selected Nodes

Call this API. The returned information does not contain a node whose `activityType` field value is `target_approval`.
