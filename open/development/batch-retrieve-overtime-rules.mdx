Call this API to batch query the details of overtime rule settings by multiple overtime rule IDs.

## API Call Description

For example, suppose the overtime rule in your Organization's attendance group is set to **Calculate overtime by approval time**.

In the DingTalk admin console, go to **Attendance group management** > **Modify attendance group** > **Overtime rules** > **Settings**. The general overtime rule is set to **Calculate overtime by approval time**. This setting applies to workdays, rest days, and holidays: overtime must be approved, and the overtime duration is based on the approval form.

Call this API to get the setting details of the **Calculate overtime by approval time** overtime rule, including the rule name and overtime calculation method.

In the admin console, open **Attendance rule management** > **Overtime rules** and edit an overtime rule. The **Edit overtime rule** panel contains the following settings:

| Field | Options / notes |
| --- | --- |
| **Rule name** | Up to 30 characters |
| **Application scope** | For example, the whole Organization (except those with other overtime rules) |
| **Owner** | Optional |
| Day-type tabs | **Workday**, **Rest day**, **Holiday** |
| **Allow overtime** | On/off toggle |
| **Allowed overtime period** | **Before work**, **After work** |
| **Calculation method** | **Calculate by approval duration**, or **Calculate by punch duration within the approved period** |

The rule in this example uses the **Calculate by approval duration** method.
