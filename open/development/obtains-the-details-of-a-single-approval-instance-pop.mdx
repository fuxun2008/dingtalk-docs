Call this API to get the details of an approval instance by its instance ID. The details include the approval instance title, initiator userId, approver userId, and activity log.

## Request

### Basic Information

| Field | Value |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/v1.0/workflow/processInstances |
| HTTP Method | GET |
| Supported app types | appType-Internal app　appType-Third-party enterprise app |
| Required permissions | permission-Workflow.Instance.Read-Workflow instance read permission |

### Request Header

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Yes | The access credential for calling this API. Obtain it as follows:   - Internal app: Call the [Get the access token of an internal app](/open/development/obtain-the-access-token-of-an-internal-app) API. - Third-party enterprise app: Call the API to get the access token of an organization that has authorized the third-party app. |

### Query Parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| processInstanceId | String | Yes | The approval instance ID.   - Call the [Create an approval instance](/open/development/create-an-approval-instance) API to get the `InstanceId` parameter value. - Call the [Get a list of approval instance IDs](/open/development/obtain-an-approval-list-of-instance-ids) API to get the `list` parameter value. |
