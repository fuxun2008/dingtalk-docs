title: "Get all fields"
---

Call this API to get all fields in a table.

## Request

### Basic information

| Field | Value |
| --- | --- |
| HTTP URL | `https://api.dingtalk.io/v1.0/notable/bases/{baseId}/sheets/{sheetIdOrName}/fields` |
| HTTP Method | GET |
| Supported app type | appType-Internal app |
| Required permissions | permission-Notable.Base.Read.All-Read permission for the AI Table app |

### Request headers

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Yes | The access credential for calling this API. Obtain it by calling the [Get the access token of an internal app](/open/development/obtain-the-access-token-of-an-internal-app#) API. |

### Path parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| baseId | String | Yes | The AI Table ID. For details on how to obtain it, see [Data structure](/open/development/data-structure#). |
| sheetIdOrName | String | Yes | The table ID or table name. You can obtain the table ID in either of the following ways:   - Call the [Get all tables](/open/development/api-notable-getallsheets#) API. - Call the [Get a table](/open/development/api-notable-getsheet#) API. |

### Query parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| operatorId | String | Yes | The unionId of the operator. Obtain it in either of the following ways:   - Call the [Query user details](/open/development/query-user-details#) API. - Call the [Get user information by using the silent login code](/open/development/obtain-the-userid-of-a-user-by-using-the-log-free#) API. |
