title: "Get the jsapi_ticket"
description: "When developing an H5 micro app, call this API to obtain the jsapi_ticket, generate the authentication signature, and then call dd.config to complete authentication."

## API call description

For internal apps, the jsapi_ticket is obtained per app. Cache the jsapi_ticket by appKey (with a cache expiration of 2 hours) instead of fetching it through the API for every call.

## Request

| **Basic information** | |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/v1.0/oauth2/jsapiTickets |
| HTTP Method | POST |
| Supported app types | appType-Internal app, appType-Third-party enterprise app |
| Required permissions | permission-qyapi_base-Basic permissions required to call enterprise APIs |

### Request header

| Name | Type | Required | Example | Description |
| --- | --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Yes | BExxx | The access credential for calling this API. Obtain it as follows:   - For an internal app, call the [Get the access token of an internal app](/open/development/obtain-the-access-token-of-an-internal-app) API. - For a third-party enterprise app, call the API for obtaining the access token of an organization that has authorized the third-party app. |

### Request example

HTTP

```bash
curl -X POST 'https://api.dingtalk.io/v1.0/oauth2/jsapiTickets' \
  -H 'x-acs-dingtalk-access-token: BExxx'
```
