Call this API to query the location list of a specified attendance group in batches.

## Request

| **Basic Information** | |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/topapi/attendance/group/positions/query |
| HTTP Method | POST |
| Supported app types | appType-Internal app |
| Permissions | permission-qyapi_attendance_group_read-Attendance group query permission |

### Query Parameters

| Name | Type | Required | Example | Description |
| --- | --- | --- | --- | --- |
| access_token | String | Yes | 4c9ebd2b15xxxx | The App credential used to call this API. Obtain it by calling the [Get the access_token of an Internal App](/open/development/obtain-orgapp-token) API. |

### Request Body

| Name | Type | Required | Example | Description |
| --- | --- | --- | --- | --- |
| cursor | String | No | 0151Exxxx | Leave empty for the first request. For subsequent requests when has_more is true, set cursor to the value of the last position_key in the previous request result. |
| size | Number | Yes | 50 | The page size. |
| op_userid | String | No | user01 | The user ID of the operator. |
| group_key | String | Yes | CEDDFxxxx | The attendance group ID.  **Note**  If your attendance group identifier is group_id, call the [Convert groupId to groupKey](/open/development/groupid-to-groupkey) API to convert group_id to group_key. |

### Request Example

```curl
curl -X POST "https://api.dingtalk.io/topapi/attendance/group/positions/query" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=80645xxxx3164b3' \
-d 'cursor=0151E02xxxx7E876' \
-d 'group_key=0151ExxxxA1A917E876' \
-d 'op_userid=123456' \
-d 'size=50'
```

## Response

### Response Body

| Name | Type | Example | Description |
| --- | --- | --- | --- |
| result | DingOpenResult |  | The returned result. |
| result | Result |  | The query result. |
| position_list | Position[] |  | The position list. |
| offset | Number | 100 | The allowed offset for the clock-in location. |
| address | String | Alibaba Group Xixi Campus | The address description. |
| latitude | String | 30.123 | The latitude (up to 6 decimal places). |
| longitude | String | 120.123 | The longitude (up to 6 decimal places). |
| position_key | String | 9E459Fxxxx | The unique identifier of the position. |
| has_more | Boolean | false | Whether more data exists.   - **true**: Yes - **false**: No |
| errcode | Number | 0 | The return code. |
| errmsg | String | ok | The return code description. |
| success | Boolean | true | Whether the request succeeded.   - **true**: Success - **false**: Failed |
| request_id | String | rss38gia1egs | The request ID. |
