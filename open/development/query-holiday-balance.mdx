Call this API to query leave balances by organization or employee with pagination. Each call returns up to 50 records.

## Request

| **Basic Information** | |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/topapi/attendance/vacation/quota/list |
| HTTP Method | POST |
| Supported app types | appType-Internal app appType-Third-party enterprise app |
| Required permissions | permission-qyapi_holiday_readonly-DingTalk leave read permission |

### Query Parameters

| Name | Type | Required | Example | Description |
| --- | --- | --- | --- | --- |
| access_token | String | Yes | bE74xxxx | The app credential used to call this API.   - Internal app: Obtain it by calling the [Get the access_token of an Internal App](/open/development/obtain-orgapp-token) API. - Third-party enterprise app: Obtain it by calling the API for getting a third-party enterprise's access_token. |

### Request Body

| Name | Type | Required | Example | Description |
| --- | --- | --- | --- | --- |
| leave_code | String | Yes | f84a2xxxx | The unique identifier of the leave type. Call the [Query the List of Leave Rules](/open/development/holiday-type-query) API to obtain the leave_code value. |
| op_userid | String | Yes | user01 | The user ID of an admin in your organization who has app permissions for **OA Approval**. |
| userids | String | Yes | user02,user03 | The list of employee IDs to query. |
| offset | Number | Yes | 0 | The pagination offset. Must be a non-negative integer starting from 0. |
| size | Number | Yes | 10 | The page size. Maximum value: 50. |

### Request Example

```curl
curl -X POST "https://api.dingtalk.io/topapi/attendance/vacation/quota/list" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=48acxxxx0dbdbee' \
-d 'leave_code=f84a2829-d245-4312-9ff2-0653e5b3abb2' \
-d 'offset=0' \
-d 'op_userid=zhangsan' \
-d 'size=10' \
-d 'userids=zhangsan%2Clisi'
```

## Response

### Response Body

| Name | Type | Example | Description |
| --- | --- | --- | --- |
| result | OapiLeaveQuotaUserListVo |  | The returned result. |
| has_more | Boolean | false | Indicates whether more records exist.   - **true**: More records exist. - **false**: No more records exist. |
| leave_quotas | Leavequotas[] |  | The list of leave balances. |
| userid | String | user01 | The user ID of the employee. |
| leave_code | String | f84a2xxxx | The unique identifier of the leave type. |
| quota_cycle | String | 2019 | The cycle that the quota applies to. |
| quota_id | String | f8abb2xxxx | The unique identifier of the quota. |
| start_time | Number | 1653851001000 | The start time of the leave validity period, as a timestamp in milliseconds. |
| end_time | Number | 1753851001000 | The end time of the quota validity period, as a timestamp in milliseconds. |
| quota_num_per_hour | Number | 1000 | The total quota, calculated in hours.  **Note**  When the leave type is calculated in hours, this value is not empty and is expressed in hundredths of an hour.  For example, 1000 = 10 hours. |
| quota_num_per_day | Number | 1000 | The total quota, calculated in days.  **Note**  When the leave type is calculated in days, this value is not empty and is expressed in hundredths of a day.  For example, 1000 = 10 days. |
| used_num_per_day | Number | 100 | The used quota, calculated in days.  **Note**  When the leave type is calculated in days, this value is not empty and is expressed in hundredths of a day.  For example, 100 = 1 day. |
| used_num_per_hour | Number | 1000 | The used quota, calculated in hours.  **Note**  When the leave type is calculated in hours, this value is not empty and is expressed in hundredths of an hour.  For example, 1000 = 10 hours. |
| errcode | Number | 0 | The return code. |
| errmsg | String | ok | The description of the return code. |
| success | Boolean | true | Indicates whether the call succeeded.   - **true**: Yes - **false**: No |
