---
title: "Get Attendance Report Column Values"
description: "Call this API to retrieve attendance report column values and column details by user ID, report column ID, and date range."
---

Call this API to get column value data from a DingTalk Smart Attendance report. The data includes all values of a report column within a specified time range, along with the related column information, for use by designated ISVs.

## API Call Description

- Attendance information of departed users is not available through this API. Query the attendance data of departed users in the [OA Admin Console](https://attend.dingtalk.io/portal/index.html).
- When you get the value of the "Required attendance days" field, this API only returns values within the last 15 days. For dates more than 15 days ago, the value of required attendance days is 0.

## Request

| **Basic Information** | |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/topapi/attendance/getcolumnval |
| HTTP Method | POST |
| Supported app types | appType-Internal app　appType-Third-party enterprise app |
| Permissions | permission-qyapi_base-Basic permission required to call organization APIs |

### Query Parameters

| Name | Type | Required | Example | Description |
| --- | --- | --- | --- | --- |
| access_token | String | Yes | 6d1bxxxx | The App credential used to call this API.   - For an Internal app, call the [Get the access_token of an Internal App](/open/development/obtain-orgapp-token) API to obtain it. - For a Third-party enterprise app, call the API for getting the access_token of a third-party organization to obtain it. |

### Request Body

| Name | Type | Required | Example | Description |
| --- | --- | --- | --- | --- |
| userid | String | Yes | manager4220 | The user ID of the user. |
| column_id_list | String | Yes | 129339038 | The report column ID. Call the [Get Attendance Report Column Definitions](/open/development/queries-the-enterprise-attendance-report-column) API to obtain the id parameter value. Separate multiple values with commas. Maximum length: 20. |
| from_date | Date | Yes | 2018-07-11 12:12:12 | The start time. |
| to_date | Date | Yes | 2018-07-11 12:12:12 | The end time. The interval between the start time and the end time must be within 31 days. |

### Request Example

```curl
curl -X POST "https://api.dingtalk.io/topapi/attendance/getcolumnval" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=4bfc0fxxxx3916c7' \
-d 'column_id_list=1%2C2%2C3' \
-d 'from_date=2018-07-11+12%3A12%3A12' \
-d 'to_date=2018-07-11+12%3A12%3A12' \
-d 'userid=zhangsan'
```

## Response

### Response Body

| Name | Type | Example | Description |
| --- | --- | --- | --- |
| request_id | String | 45n2azecqj21 | The request ID. |
| errcode | Number | 0 | The return code. |
| result | ColumnValListForTopVo |  | The returned result. |
| column_vals | ColumnValForTopVo[] |  | The column information and column value data. |
| column_vals | ColumnDayAndVal[] |  | The column value data. |
| date | Date | 2020-09-09 00:00:00 | The date. |
| value | String | 1.0 | The column value. |
| column_vo | ColumnForTopVo |  | The column information. |
| id | Number | 129339038 | The report column ID. |
| fixed_value | String | 0 | The fixed value.  **Note**  Some report columns have fixed values. Their values are returned only in this field and not in column_vals. |
