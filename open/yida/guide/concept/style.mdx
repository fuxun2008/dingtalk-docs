Style adjustments are inevitable during system development. YiDA offers flexible custom style capabilities for pages.

## How to Use

Custom pages support the following two ways to configure styles:

### Basic Style Settings

YiDA provides a general style configuration panel for setting basic styles visually, including layout, text, background, shadow, and border. When you change the settings in the style panel, the results appear in the visual editing area in real time.
