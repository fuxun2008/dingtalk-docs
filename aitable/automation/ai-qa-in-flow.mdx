# 1 Overview

AI Table automation supports asking the AI questions — combine field content or output from earlier automation steps with a preset prompt template to dynamically generate structured text. The result feeds into later steps, closing the loop on intelligent end-to-end workflows.

# 2 Example: ask AI

## 2.1 Add the automation

Click **Automation** in the upper-right and create a new flow. After setting the trigger, pick **Ask AI** as the action.

## 2.2 Enter and refine the prompt

Pick the AI model, enter the prompt, and decide whether to enable diversity control.

You can insert variables into the prompt — both variables from earlier automation steps and system variables.

## 2.3 Reference the generated text downstream

The AI's output is reusable in later steps — for example, in the body of an outgoing message.

Available variables: success flag, AI response, AI thinking process, error code, error message.

# 3 Example: ask an AI assistant (with custom knowledge base)

## 3.1 Add the automation

To answer based on your enterprise's custom knowledge base, try **Ask AI assistant**.

You'll need to create an AI assistant first and feed it the relevant docs. In DingTalk, click the AI assistant icon in the upper-right and create a new one.

In the AI assistant editor, attach knowledge to the assistant.

Switch to the **Skills** tab and turn on **only** the Smart Q&A toggle.

Back in the automation editor, refresh the page — the AI assistant you just created becomes available; set the skill to **Smart Q&A** to keep responses scoped to the knowledge base.
