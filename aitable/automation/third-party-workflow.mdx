# Call a Coze workflow

Use cases:

- **Content creation**: auto-write copy, generate "chicken-soup" videos.
- **Data fetching**: Douyin order sync, competitor tracking, hot-news scraping.
- **Customer support**: build smart support / shopping bots, smart tickets.
- **Image processing**: image / video recognition, content analysis & comparison.

> Imagine this workflow: when a new KOL Douyin URL is added, a Coze workflow fetches the KOL's video list (URL, download URL, cover image, audio URL, likes, comments, shares, favorites, downloads) — and writes the data back to the AI Table.

### Step 1 — go to [📎Coze workspace](https://www.coze.cn/space "📎Coze workspace") to create a workflow and grab the token + ID

- Create an app / agent on Coze ([📎Coze handbook](https://www.coze.cn/open/docs/guides/app_quickstart1 "📎Coze handbook")).

  Example: a Start → Get Douyin user video info (`douyin_user_videos_pro`) → End workflow.
  - **Get the workflow ID**: the digits after `/workflow/` in the URL — 2 in the screenshot.
  - Click Publish 1 → pick API as the publish target → click **Create personal token** 3 in the API card.
  - You're redirected to add a new personal token — confirm 4 .
  - **Copy the Token immediately** 5 from the dialog — once closed, you can't preview it again.

### Step 3 — add the **Call Coze workflow** action node

- Switch to the AI Table; paste the **Token** from the prior step 5 .
- **Workflow ID**: the digits after `/workflow/` in the workflow URL — 2 .

- Fill in the input format — **must match the workflow's Start input format**.

### Step 4 — one-click fetch the output format

- Click **Test run** — the system runs the workflow with current params; click **Auto-fill input sample** 5 to populate the JSON input form.
- If you use variables, manually enter concrete values in **Test run** to get a successful run.

### Step 5 — convert JSON output to natural language

- Add an **Ask AI** node after the **Coze workflow** node — it converts the JSON array output into natural-language text and writes it back to the AI Table.

- One test run later, you'll have the KOL URL's data populated in the AI Table.

# Call a Bailian app

Use cases:

- **Content creation**: ad copy, marketing copy, scripts.
- **Data insights**: analyze content + hot events at scale to spot business opportunities.
- **Customer support**: automated consult and issue resolution.
- **Document review**: classify and review docs (contract review, legal analysis).
- **Medical imaging**: medical image analysis to assist screening / diagnosis.

> Imagine this workflow: collect daily Douyin viral video URLs, run them through a Bailian app — Douyin Content Assistant — to fetch watermark-free videos, extract video transcript, and AI-rewrite, then write the result back to the AI Table.

### Step 1 — go to [📎](https://bailian.console.aliyun.com/ "📎")[Aliyun Bailian](https://bailian.console.aliyun.com/ "Aliyun Bailian") to create an app and get the API key

- Open Bailian, go to App Marketplace, pick an app 1 ([📎Bailian handbook](https://bailian.console.aliyun.com/?tab=doc#/doc/?type=app&url=https%3A%2F%2Fhelp.aliyun.com%2Fdocument_detail%2F2845095.html&renderType=iframe "📎Bailian handbook")).

  Example: when a new Douyin URL is added → auto-feed it to **Douyin Content Assistant** → write the AI's answer back to the AI Table.

- Open the app detail; click **Copy this app** 2 .

- The copy may require enabling the model service 3 — needs real-name verification first (return to the Aliyun homepage and click your avatar top-right to verify).

- Once copied & created, get the **App ID** — the last digits in the URL 6 .

- Click **Publish app** to get the **API Key** 5 .

- Or get it from **API-Key** at the bottom of the left nav 4 .

### Step 3 — add the **Call Bailian app** action node and one-click fetch the input format

- Switch to the AI Table; paste the **API Key** from the prior step 4, 5.
- Paste the **App ID** — the last digits in the app URL 6.

### Step 4 — one-click fetch the output format

- For JSON output: click **Test run** — system runs with current params; click **Auto-fill input sample** 5 to populate the JSON input form.
- For plain-text output: skip **Test run**; just pick **Text** as the output type.

# Call a Dify workflow (closed beta)

Dify workflows can build:

- **Customer service**: smart support / shopping bots.
- **Content generation**: blog posts, product descriptions.
- **Task automation**: integrate with task systems for project automation.
- **Data analysis**: analyze large knowledge bases, generate reports / summaries.
- **Email handling**: draft emails, social-media posts.

> Imagine this workflow: clicking a button runs Dify's professional stock-analysis on a watch list in batch.

### Step 1 — go to [📎Dify workflow page](https://cloud.dify.ai/apps "📎Dify workflow page") to grab the API key

- Create a workflow on Dify ([📎Dify handbook](https://docs.dify.ai/zh-hans/guides/workflow/readme "📎Dify handbook")) — needs a network accelerator to access.

  Example: a Start → Stock analysis → End workflow, one-click Publish 1 .

- **Be sure** to publish 2 first, then grab the Dify workflow's **API key** 3 .

### Step 3 — add the **Call Dify** action node and one-click fetch the input format

- Switch to the AI Table; paste the **API key** from the prior step 4 .
- Set a **Custom user identifier** (mainly for end-user identity tracking — easier lookup and stats).
- Once the upstream node's key is configured, click **One-click sync params** 5 — it auto-pulls the workflow's inputs.

### Step 4 — one-click fetch the output format

- Click **Test run** — system runs with current params; click **Auto-fill input sample** 5 to populate the JSON input form.
- If you use variables, manually enter concrete values in **Test run** to get a successful run.

### Step 5 — convert JSON output to natural language

- Add an **Ask AI** node after the **Dify workflow** node — it converts the JSON array output into natural-language text and writes it back to the AI Table.
