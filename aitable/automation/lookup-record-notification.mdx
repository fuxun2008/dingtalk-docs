Use AI Table automation to bundle **multiple records into a single message card** and send it to a person or group.

## Scenarios

- **Multi-task sync**: combine task records assigned to different members into one card and send it to a group or individual — easy for everyone to see what's on their plate.
- **Data alerts**: when several records cross a threshold, automation rolls them up and pings the relevant owner.

## Example 1: scheduled weekly task progress

Create a new blank workflow or use a pre-built template — open the automation editor.

The core step is "Look up records": **trigger → Look up records → Send message to user or group**.

![](/aitable/automation/lookup-record-notification/images/image_DZK7idjAn0.png)

### Configure "Look up records"

Before sending multiple records, use "Look up records" to filter the matching ones — then reference them in the send step. Specifically:

- **Set filter conditions** — pin down what counts.
- **Set lookup content** — pick which fields to surface in the card.

If nothing matches, pick **Stop workflow**.

![](/aitable/automation/lookup-record-notification/images/image_L9BC9BDODT.png)

### Configure "Send message to user or group"

Pick multiple recipients (people or groups) and customize the card title and body.

While editing the body, click the **⊕** icon to reference the lookup result — single field or combined fields.

![](/aitable/automation/lookup-record-notification/images/image_jmapVmXsYv.png)

![](/aitable/automation/lookup-record-notification/images/image_pUWTTnLAkw.png)

When you pick combined fields, the order you check them in determines the order on the card; the right-side preview updates live. Hover a reference to see its order.

![](/aitable/automation/lookup-record-notification/images/image_FT3YilrsKX.png)

![](/aitable/automation/lookup-record-notification/images/image_u9-V5P1rk4.png)

## FAQ

#### **Q: Why does my multi-record send come out incomplete?**

A: The card supports up to 50 rows, and each field shows a max of 100 characters.
