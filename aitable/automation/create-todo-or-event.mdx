## Overview

Use AI Table data and an automation flow to auto-create DingTalk calendar events — push business forward faster.

**Common scenarios:**

1. Customer bookings auto-generate calendar events — respond on time, deliver better service.
2. Auto-add meetings to your calendar — simpler scheduling, on-time meetings.

## How to use

Start by creating a new automation — see "Create an automation" for the basics.

### Configure the trigger

Pick a trigger on the right — see "Triggers and actions in automation" for the full list.

### Configure the action

In the right panel, pick **Business apps** as the category, then pick **Calendar event**.

#### Create a DingTalk calendar event

Pick action **Create DingTalk calendar event**.

Set event title, start time, end time, etc. Type them in directly, or click the **⊕** on the right of an input to insert a variable from step 1.

## FAQ

- **Q: Can I include external users in events?**

  A: No.
- **Q: How do I set the event title in an automation?**

  A: In the **Event title** input, type the name directly, or click the right-side icon to reference data from AI Table.
- **Q: When I delete a record in AI Table, does the calendar event created from it via automation get deleted too?**

  A: No.
