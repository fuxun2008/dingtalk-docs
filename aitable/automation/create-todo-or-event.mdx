## Overview

Use AI Table data and an automation flow to auto-create DingTalk to-dos or calendar events — push business forward faster.

**Common scenarios:**

1. Project tasks turn into to-dos automatically — owners get pinged in real time, team coordination speeds up.
2. Customer bookings auto-generate calendar events — respond on time, deliver better service.
3. Auto-add meetings to your calendar — simpler scheduling, on-time meetings.

## How to use

Start by creating a new automation — see "Create an automation" for the basics.

### Configure the trigger

Pick a trigger on the right — see "Triggers and actions in automation" for the full list.

### Configure the action

In the right panel, pick **Business apps** as the category, then pick **To-do** or **Calendar event**.

#### Create a DingTalk to-do

- Pick action **Create DingTalk to-do**.
- Set task title, owner, due date, etc. Type them in directly, or click the **⊕** on the right of an input to insert a variable from step 1.

Note: if the workflow author sets themselves as owner or participant, the system won't send them a to-do notification — they can find it in DingTalk to-dos.

#### Manage to-dos

Use a task ID to complete, restart, or delete a previously created to-do.

The task ID is generated when **Create to-do** runs — reference it as a step variable from that node.

**Tip:**

- Add a text field called "Task ID" to the AI Table.
- After **Create to-do**, add an **Update record** step to write the generated task ID back to the table for later reference.

#### Create a DingTalk calendar event

Pick action **Create DingTalk calendar event**.

Set event title, start time, end time, etc. Type them in directly, or click the **⊕** on the right of an input to insert a variable from step 1.

## FAQ

- **Q: Can I include external users in to-dos or events?**

  A: No.
- **Q: How do I set the event title in an automation?**

  A: In the **Event title** input, type the name directly, or click the right-side icon to reference data from AI Table.
- **Q: When I delete a record in AI Table, does the calendar event created from it via automation get deleted too?**

  A: No.
