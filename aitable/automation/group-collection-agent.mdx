## How to use

### Entry 1: Open the Automation tab at the top, click New workflow — the **Collect group messages** button shows top-right

![](/aitable/automation/group-collection-agent/images/image_s0R9q1v16w.png)

#### Entry 2: Or open the AI assistant side panel, click **Add to group chat** in the top-right, expand the settings panel, pick the AI question-collection skill, set triggers, and confirm

![](/aitable/automation/group-collection-agent/images/image_OpLCsLslc1.png)

![](/aitable/automation/group-collection-agent/images/image_TSP0Hf6wFZ.png)

![](/aitable/automation/group-collection-agent/images/image_gtq65yVOvL.png)

1. By default, "AI assistant collects when @-ed" is checked.
2. Optionally enable group-message awareness (free for now — watch official notices for end date). Three trigger types are offered:
   - Officially recommended question-collection regex:
   > #️⃣.*[？?].*|. *[请问|如何|怎么|能否|能不能|可以|有.*吗|为什么|是不是|是否|求|帮忙|指导|咨询|麻烦|图片].*
   > 💡This regex aims at recognizing questions or requests in Chinese. It has two rules joined by OR (`|`); matching either rule triggers.
   > **Rule 1 `.*[？?].*`**: by punctuation. Matches any string containing a full-width (？) or half-width (?) question mark — direct interrogative detection.
   > **Rule 2 `.*[请问|如何|...|图片].*`**: by keyword. Matches sentences containing question or request words ("请问", "如何", "帮忙", "有...吗" etc.) and any feedback with images.
   - Image: any message with an image — image is auto-added to the attachment column.
   - Keyword:
     - Keyword trigger: fires when the conversation contains specified words.
     - Regex trigger: fires when the regex matches. Example:
     ```java 
     .*（matches anything — fires on every message）
     ```

3. Optionally reply to the user "I've collected your question." after silent collection.

   ![](/aitable/automation/group-collection-agent/images/image_n66bhnsRop.png)

#### Step 2 — go to the group, send a test question

Send a real-feel question with text + image, wait a minute, then go to the AI Table — a "Question collection" sheet should auto-appear with the question, sender, category, group source, attachments, and timestamp.

![](/aitable/automation/group-collection-agent/images/image_lkKFv6NvRQ.png)

![](/aitable/automation/group-collection-agent/images/image_r952EBPkou.png)

#### Step 3 — tune the assistant: collected content types and keywords

1. Click **More settings** to enter the assistant capability config.

![](/aitable/automation/group-collection-agent/images/image_sucVGABkGL.png)

2. In **Persona**, edit what tasks the assistant handles. To change the destination sheet name and fields, edit these lines:

What's blue-underlined is the directive constraining the destination sheet's fields.

![](/aitable/automation/group-collection-agent/images/image_Vwxms3diBj.png)

Change them to what's yellow-underlined — pick the destination sheet name and field names you want.

![](/aitable/automation/group-collection-agent/images/image_KEWV5CbK5J.png)

1. To collect to a different AI Table, go to the deap platform and edit the persona by reference to the example above. The table's `dentryUuid` is the unique key for write-back — it's the blue-underlined segment in the AI Table URL.

![](/aitable/automation/group-collection-agent/images/image_qgfllhPglk.png)

1. For more deap agent platform docs, see: [Details](https://alidocs.dingtalk.com/i/p/Y7kmbokZp3pgGLq2/docs/YMyQA2dXW793K7oYukG54ykvJzlwrZgb?dontjump=true&spm=a1zb9.8233112.0.0.14643a88CP7reV "Details")

## FAQ

- **Why does assistant creation fail?**

  Your org may have disabled AI assistant in AI Assistant Management. Check at [OA admin console](https://oa.dingtalk.io "OA admin console") → AI Assistant Management.

  ![](/aitable/automation/group-collection-agent/images/image_0gxgB1j8yM.png)

  Without OA admin permission, click into the org AI assistant entry below to try creating one — if it's blocked, you'll see it.

  ![](/aitable/automation/group-collection-agent/images/image_e8h9HPZKPm.png)

  If you're on the new DingTalk, go to [https://deap.dingtalk.io/](https://deap.dingtalk.io/ "https://deap.dingtalk.io/") to create a new agent and check if it can be published. If not, your org has disabled AI assistant — contact your admin.
- **Why can't I find my org's group chats?**

  You must be the group owner or admin.
- **Followed the doc but nothing gets collected — why?**

  Send "Why didn't the automation fire?" into the group as a test. If it still doesn't fire, check whether the group is encrypted — Sanfang Mibing encryption must be off.

  ![](/aitable/automation/group-collection-agent/images/iwEcAqNwbmcDAQTRA84F0QIyBrCQPJCuf14j8Ak_P-AydOIAB9.png)
- **Edited the assistant settings but nothing changed in the group — what now?**

  Remove the assistant from the group, then re-add it — clears the in-group cache.
- **After deleting the assistant from deap, can I re-add it from AI Table?**

  Yes — re-add via the original flow. The groups where the deleted assistant was must add the new assistant from scratch.
- **If I rename the AI Table title, does it sync?**

  Not yet.
- **External-group collection supported?**

  Not yet.
- **Can the destination table name be changed? Can I add or remove fields?**
  1. In **Persona**, edit what tasks the assistant handles. To change the destination sheet name and fields, edit these lines:
     What's blue-underlined is the directive constraining the destination sheet's fields.
  ![](/aitable/automation/group-collection-agent/images/image_Vwxms3diBj.png)

  Change them to what's yellow-underlined — pick the destination sheet name and field names you want.

  ![](/aitable/automation/group-collection-agent/images/image_KEWV5CbK5J.png)
- **Why are some questions not collected?**

  Tune the regex in **Skill triggers → Group-message awareness** following the section above.
- **When does the free trial end?**

  No commercial pricing decision yet — pricing may eventually be per-token.
- **Can attachments be collected?**

  Not yet.
- **How do I stop collection?**

  Manually remove the assistant from the group.
