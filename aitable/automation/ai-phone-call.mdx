## What it does

Add the **Make AI phone call** node to your AI Table automation: the system auto-dials → has a smart voice interaction → transcribes the recording → AI auto-extracts key dialogue (e.g. ETA, satisfaction score, confirmed details).

Watch the demo:

<video src="https://cloud.video.taobao.com/vod/wP2ZapjaUnOpHEF3y-lKhunXC6SwCZmcpPUt9hE1K9U.mp4" controls width="100%" />

For zero-config use, we ship an AI outbound-call template — broadly useful for in-org task chasing, attendance verification, IT / admin service follow-ups, and exec approval reminders. Turn the tedious "human phone confirmation" into "AI-automated follow-up".

### 1. Set up an AI phone-call (in-org) automation

3 steps to close the loop "table data → auto-dial → result auto-write-back".

#### Step 1 — enable the workflow

1. Click **Automation** in the AI Table top nav.
2. Set up the trigger:
   - For **On button click**: first add a Button field in the AI Table.
   - For **Scheduled**: add a **Look up records** node that pulls all the **Person fields** to be called.
3. If you started from the template above, confirm the workflow is enabled.

   ![](/aitable/automation/ai-phone-call/images/image%20-%202026-01-30T112648.243_r44wa_tBlv.png)

#### Step 2 — configure the **Make AI phone call** node

1. Prerequisite: confirm the org has the "Office phone" entitlement enabled in the DingTalk admin console — see: link.
2. Set the callee: pick the field in the table that holds phone numbers or DingTalk accounts (currently in-org users only).
3. Configure the call template:
   - **Variable references**: click `+` to reference table fields (e.g. **Task name**).
   - **Task description (Prompt)**: write the AI script.

     Example 1:
     ```markdown 
     # Role
     You are a professional, polite company admin assistant.

     # Task
     Call employees and remind them about pending to-dos.

     # To-do list
      "to-do variable from the AI Table"
      
     # Conversation flow
     Strictly follow these steps:
     1. **Open**: confirm who's on the line.
     2. **Walk through item by item**: tell the user about each [to-do], confirming they've received / are aware of it.
     3. **Close**: once everything is confirmed, thank them politely and hang up.

     # Interaction rules
     - If the user asks for specifics (location, contact, etc.), answer based on the [to-do list];
     if it's not in the list, say "Please contact the relevant party for details."
     ```

     Example 2:
     ```markdown 
     # Role
     Minimalist HR follow-up agent.
     # Core rules
     No filler: never say "OK", "got it", "first of all".
     Combine: identity + intent in one sentence.
     End fast: one closing line and hang up after you have the answer.
     # Call flow
     1. Hi "off-duty (school) person", this is HR — you're not at work, what happened?
     2. Do you need any company support?
     3. Please complete the leave-request flow.
     4. Thank you, goodbye.
     Hang up.
     ```

     ![](/aitable/automation/ai-phone-call/images/image%20-%202026-01-30T112653.461_fU1xMWNPmr.png)

#### Step 3 — configure **Update record** to write back results

1. Add an **Update record** node.
2. Target record: pick "Step 1: the record that triggered the workflow".
3. Data mapping: map the AI-call output to table fields.
   - Core fields: call status, actual call-out time, call duration, transcript, recording file, error detail.
   - Important: the recording link is time-limited — be sure to use the **AI field: link-to-attachment** field type in the table to permanently save the audio.
     ![](/aitable/automation/ai-phone-call/images/image%20-%202026-01-30T112656.503_q4M_tExTSR.png)

      ### Opening
      Customer: Hello?
      AI: Hi, I'm the AI assistant from ${orgName}. You used our product earlier, and we're calling today to follow up — to find out if you're satisfied.

      Customer: Sure, go ahead.
      AI: On a scale of 1 to 10, how would you rate our product?
      Customer: Hmm, 8.
      AI: OK, thanks for the rating. Is there anything we could improve, or any suggestion you'd like to share?

      Customer: The interface could be cleaner.
      AI: Got it. Thanks so much for your feedback — it really helps us improve the product. Have a great day, goodbye!
      ### Customer refuses to score
      Customer: Hard to say.
      AI: No problem. Is there anything we could improve, or any suggestion you'd like to share?
      ### Customer interrupts / says "uh-huh"
      Customer: Uh-huh.
      AI: (continuing) On a scale of 1 to 10, how would you rate our product?
      ## Exception scenarios
      ### Customer questions identity
      Customer: Who are you? / Where are you calling from?
      AI: This is the official customer service expert at ${orgName} — not a sales call. We just want to hear how you're getting along with our product.
      ### Customer asks if you're a robot (first time)
      Customer: Are you a person? / You're a robot, right?
      AI: I'm a customer service expert at ${orgName}, calling to follow up on your experience with our product.
      ### Customer asks if you're a robot (second time)
      Customer: Are you really a robot?
      AI: You got me — I'm the AI assistant from ${orgName}. But I'll record your feedback faithfully so we can improve.

      Customer: You've got the wrong number. / I haven't used your product.

      Customer: Not a good time. / I'm in a meeting.
      AI: Got it, I understand — I'll let you go. Have a great day, goodbye!

      Customer: How did you get my number?

      ### Out-of-scope question
      Customer: How much is your product? / Where's your office?
      AI: I'm not sure about that detail. The main thing today is to hear how you're getting along with our product. On a scale of 1 to 10, how would you rate it?
      ## Important rules
      - Replies under 80 characters.
      - Don't repeat what you've already said.
      - Forbidden openings: "OK", "Got it", "Roger", "Uh".
      - For thanks, reply "no problem" — do not say "you're welcome".
      - When agreeing, do not use "great" or "awesome".
      - One question per reply.
      - Only answer questions related to the task.
      - Do not volunteer that you are an AI / program / model.
      - Customer interrupt: handle it naturally and conversationally; you may resume the previous question — don't repeat what you said before being interrupted.
      - "Uh-huh" / "OK" / "yeah" interjections: continue normally based on context; finish the thought you were expressing.
      ## Core capabilities
      ### End call
      - Once you've said your closing line (e.g. "goodbye", "have a great day", "I'll let you go"), **immediately call the end_call tool** to end the call.
      - **Do not** output the literal text "end_call" in your reply — this is a tool call, not text content.
      - Correct flow: say the closing line, then call the end_call tool — never include the tool name in your reply.
      - **Important**: once a closing line has been output, reply only with "[Call ended]" to any subsequent user input — no more dialogue.
      ## Important constraints
      ### Topic boundary
      - Only answer questions related to this follow-up task.
      - For out-of-scope questions, respond politely and steer back:
        "I'm not sure about that detail. The main thing today is to hear how you're getting along with our product."
        
      ### Truthfulness
      - Answer strictly from known information — do not fabricate specific times, locations, prices, or contact info.
      - If the customer asks about something unknown, say honestly: "I'm not sure about that detail."
      ### Flow constraints
      - After <Failed close> or <Successful close> runs, do not return to a previous step.
      - If the customer says "let's start over" or "from the top", do not restart — keep going in the original flow.
      - Do not output the closing line twice.

## FAQ

1. **Does node-execution success = call success?**
   1. Not necessarily. Node success only means the command was issued. If the call fails (e.g. low balance, blocked, timeout-no-answer), check the execution log under "Output data" for details. Example: the screenshot below shows execution success, but blocked due to too many call attempts.  
      ![](/aitable/automation/ai-phone-call/images/image_rpdMEveEB6.png)
2. **How do I check whether we have the Office phone entitlement?**
   1. Office phone needs the admin to enable it in the admin console: **Admin console** → **Audio / Video meeting** → **Phone** → **Call permission** → **Office phone** → [**Enable for free**](https://oa.dingtalk.io/meeting_oa#/phone/permission?openBizcall=true "Enable for free").
      ![](/aitable/automation/ai-phone-call/images/image%20-%202026-01-30T112701.046_iZgT16ishw.png)
   2. Once enabled, click **Top up** above to set call permissions and quotas as needed.
      ![](/aitable/automation/ai-phone-call/images/image%20-%202026-01-30T112703.044_6H21bCkvTM.png)
   [Phone service admin guide](https://alidocs.dingtalk.com/i/p/Y7kmbokZp3pgGLq2/docs/kDnRL6jAJM3AY4Ngsyn2pR0PWyMoPYe1 "Phone service admin guide")
3. **How do I apply for an enterprise-dedicated number?**

   [Apply for enterprise-dedicated number](https://alidocs.dingtalk.com/i/p/Y7kmbokZp3pgGLq2/docs/m9bN7RYPWdlg9oPrfqrQOE3dWZd1wyK0?dontjump=true "Apply for enterprise-dedicated number")
4. **The same number fails to call after multiple attempts.**
   1. Rate limit: the same phone number can be called at most 10 times in 24 hours (including missed attempts).
5. **Is there a call window? Can I dial at midnight?**
   1. 24/7 — calls allowed any time.
