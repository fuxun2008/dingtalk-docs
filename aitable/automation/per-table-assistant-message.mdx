## Where do I find the AI Table bot?

After the first automation message goes out, recipients see an AI bot in chat named after the AI Table.

## What can the AI Table bot do?

The bot turns important data changes, task updates, and system events from your AI Table into conversational nudges in chat — boosting team coordination and message reach. Common scenarios:

#### Project status update — ping a person or group

- **What it does**

  When core project status changes (phase advance, risk-level adjustment, hitting a key progress milestone), auto-notify the team or relevant stakeholders so info stays transparent in real time.
- **Typical triggers**
  - Single-select changes (e.g. **Project phase** flips from "Design" to "Development")
  - Status changes (e.g. **Risk level** moves from "Medium" to "High")
- **Setup**
  1. In the automation: trigger **On record change** → action **Send message to user or group**.

![](https://img.alicdn.com/imgextra/i4/O1CN01iXgJuH1vEAzKCBqVZ_!!6000000006140-2-tps-1758-1460.png)


#### Task assignment and due-date reminders

- **What it does:** When a new task is created and assigned, ping the owner; when due date approaches, auto-remind them.
- **Typical triggers**
  - Trigger when **Owner** changes from empty to a person → action **Send message to user or group**.
  - Trigger when **Due date** equals a future day (e.g. tomorrow, 3 days out) → same action.
- **Value:** Owners know about new tasks, nothing falls through, and missed deadlines drop.

![](https://img.alicdn.com/imgextra/i2/O1CN01k4fXUX1rnCokZK6Tj_!!6000000005675-2-tps-1236-1388.png)


#### Scheduled push of sales charts

- **What it does:** Push the day's livestream dashboard to the owner after every show.
- **How:** Scheduled trigger at 8:30 PM daily → send message to user or group.

![](https://img.alicdn.com/imgextra/i2/O1CN01nq1p3r1pTOS8Pp60T_!!6000000005361-2-tps-1268-1412.png)
