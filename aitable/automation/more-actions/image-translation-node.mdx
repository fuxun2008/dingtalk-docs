## What it does

Upload a product image and the automation's image translation node auto-generates a target-language image with matching layout. Currently supports: Simplified Chinese, Traditional Chinese, English, Japanese, Korean, Malay, and Arabic.

Out-of-the-box template: [https://store.dingtalk.io/materials/1346](https://store.dingtalk.io/materials/1346 "https://store.dingtalk.io/materials/1346")

## Build a workflow with this node

1. **Open the automation editor**

   Trigger: when an image is added to the table → action **Image translation** (powered by third-party Aidge — 1000 free trials available) → update record back to the original row.

   ![](/aitable/automation/more-actions/image-translation-node/images/image_sHWgiwhzM-.png)
2. **After adding the image translation node, get the credential as follows**
   - **Aidge sign-in entry**
     - Web: [https://www.aidc-ai.com/](https://www.aidc-ai.com/ "https://www.aidc-ai.com/")
   - **Web sign-up / sign-in flow:**
     - Open the URL above and click **Sign in**.
       ![](/aitable/automation/more-actions/image-translation-node/images/image_xP1YPVNE8h.png)
   - **Get and use the credential**
     - After signing in, click **Try now** on the homepage, or click your avatar in the top-right and open the console.
       ![](/aitable/automation/more-actions/image-translation-node/images/image%20(86)_cWnE5NfDxN.png)
     ![](/aitable/automation/more-actions/image-translation-node/images/image%20(87)_G9AuI5diq-.png)
     - Click **Assets** on the left → **API Key** to get the account name and key. The API Key is a permanent credential for this account, used to call the API.
       ![](/aitable/automation/more-actions/image-translation-node/images/image%20(88)_Sqxxa2JuKI.png)

- **Back in the automation editor, fill in the credential and pick the product to call**
  - Credential name: anything you like
  - Name: the API key name from Aidge
  - Key: the API key secret from Aidge
    ![](/aitable/automation/more-actions/image-translation-node/images/image%20(89)_DNDaa-X_qL.png)

## Free trial quota and usage

- All users get 1000 free trial calls upon registration. When using the connector, pick whether to use trial or paid quota — you select the quota type when filling in the credential. We recommend creating one credential each for trial and paid quotas.

  ![](/aitable/automation/more-actions/image-translation-node/images/image%20(90)_73BoYOOn4k.png)
- Check trial quota and balance on the Aidge console — open **Usage** in the left nav for free API usage details.

  ![](/aitable/automation/more-actions/image-translation-node/images/image%20(91)_HuIkJ23n9k.png)
- When the trial quota runs out, buy paid quota per product. Click **Pricing** on the homepage to see per-API pricing.

  ![](/aitable/automation/more-actions/image-translation-node/images/image%20(93)_NDSa-mF5UX.png)
- Check paid quota and balance on the same **Usage** page.
