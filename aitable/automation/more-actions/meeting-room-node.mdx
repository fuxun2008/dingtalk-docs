## Before you start: get credentials

**Prerequisites:**

- [DingTalk Open Platform access](https://open-dev.dingtalk.com/fe/app?hash=#/corp/app#/corp/app "DingTalk Open Platform access")
- [DingTalk admin console access](https://oa.dingtalk.io/index.htm#/welcome "DingTalk admin console access")

With both, you can obtain credentials (**Client ID and Client Secret**) and sync your meeting room list.

![](/aitable/automation/more-actions/meeting-room-node/images/%E6%88%AA%E5%B1%8F2025-08-24_GV3F5QBt_W)

1. **Create an AI Table micro-app.**

   Open DingTalk Open Platform — in the left nav, **DingTalk apps** → **Create cool app**.

   App console: [https://open-dev.dingtalk.com/fe/app?hash=%23%2Fcorp%2Fapp#/corp/app](https://open-dev.dingtalk.com/fe/app?hash=#/corp/app#/corp/app "DingTalk Open Platform")

   ![](/aitable/automation/more-actions/meeting-room-node/images/885c0627-2004-4a92-a137-9acfce82cb23_SAKLOqx1xX.png)
2. **Once created, open the "Credentials and basic info" tab — copy the Client ID and Client Secret.**

   ![](/aitable/automation/more-actions/meeting-room-node/images/d8256127-07dd-43c8-befe-4bfa32ed7bf1_N9F5oeSp2Y.png)
3. **Apply for the meeting credential scope.**

   In the AI Table micro-app's **Dev config**, find **Permission management** and enter:
   > ☘️VideoConference.Conference.Read
   > Click apply to enable scope access.
   ![](/aitable/automation/more-actions/meeting-room-node/images/2e812b7f-24fd-4927-b188-b5b71650d81d_CMJW59NdVd.png)

1. **How to obtain the unionId in the node.**

   Why is **unionId** required to run the node? Because the node needs a user **ID** (**unionId**) to query the meeting room list. Use the "Get department members" node to obtain a user **ID**.
