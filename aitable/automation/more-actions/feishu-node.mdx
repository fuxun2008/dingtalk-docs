**This guide is no-code — non-engineers can pick it up immediately:**

## Before you start: get a Feishu **App ID and App Secret**

1. **Go to** [**Feishu Open Platform to create a custom app**](https://open.feishu.cn/app "create a custom app on Feishu") **and obtain the App ID and App Secret**.

2. **Make sure the custom app has the relevant scopes**.

   For example, the [List child departments](https://open.feishu.cn/document/server-docs/contact-v3/department/children "List child departments") API requires the corresponding contact-related scopes.

3. **Apply for the custom app's API scopes** ([Apply for API scopes for an enterprise custom app](https://open.feishu.cn/document/server-docs/application-scope/introduction?lang=zh-CN "apply for API scopes")).
   1. Sign in to [the developer console](https://open.feishu.cn/app "developer console") and open the custom app.
   2. In the left nav, go to **Dev config > Permission management** and click **Enable scopes**.
   3. In the dialog, pick the scopes you need and click **Confirm** — the system jumps to the granted-scopes page.
