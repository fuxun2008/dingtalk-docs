The **Entitlement stats** page gives organization admins a unified view of the org's plan entitlements in **AI Table** — capacity caps, feature activation, and live usage.

From this page, admins get clear visibility into:

- The current AI Table plan and its expiration date.
- The cap and current usage for each core entitlement.
- Entitlements that need expansion or an upgrade.

That visibility supports **capacity planning, permission configuration, and upgrade decisions**.

![](/aitable/admin-console/entitlement-stats/images/image_4zIMUodv2N.png)

## How to get there

Open the DingTalk client > **More** > **Admin Console**, or visit [https://oa.dingtalk.io/#/welcome](https://oa.dingtalk.io/#/welcome "https://oa.dingtalk.io/#/welcome") directly. In the left-hand menu, open **AI Table** > **Entitlement stats**.

![](/aitable/admin-console/entitlement-stats/images/image_KCZ2NJLjuh.png)

## What's on the page

### Current plan & expiration

The top of the page shows the current AI Table plan (Business / Enterprise) along with days used and the expiration date. Admins can quickly confirm subscription status, and choose **Schedule a consultation** or **Upgrade now** before expiry.

### Entitlement alerts

When a key entitlement (rows, role count, etc.) is close to or at its limit, the system surfaces a notice. Admins can click **Schedule a consultation**.

![](/aitable/admin-console/entitlement-stats/images/image_0ymaP1WbWj.png)

## Entitlement modules

| **Type** | **Entitlement** | **Description** |
| ---------- | -------------- | --------------------------------------------------------------- |
| **Usage-based** | Automation runs | Maximum number of automation workflow node runs per month. Resets on the 1st of the next month. |
|  | Max rows per table | Number of records a single table can hold. Expandable up to 10 million rows per table. |
|  | Custom roles in Advanced Permissions | Number of custom roles that can be configured per AI Table. |
| **Feature-based** | Dashboard stats follow viewer permissions | Dashboard charts can be configured to honor the viewer's data permissions — one dashboard, different views per viewer. |
|  | Max iterations per loop node | The maximum number of times a single loop node in an automation can iterate. Loop nodes repeat the same operation until the task completes. |
|  | Cross-table dashboard analysis | Combine data from different tables of the same AI Table into a single chart for deeper, end-to-end analysis. |
|  | AI field fast lane | AI field results render faster, with less waiting — keeps work moving. |
|  | AI field scheduled refresh | Some advanced AI fields refresh on a 24-hour schedule (e.g. parcel tracking lookups, full-row summaries). |

### Expanding entitlements

#### **Expand max rows per table**

1. Click **Expand** on the **Max rows per table** card.

   ![](/aitable/admin-console/entitlement-stats/images/image_rLGU1dqw7d.png)
2. You're taken to the expansion form — submit your request from there.

   ![](/aitable/admin-console/entitlement-stats/images/image_-kbL5qqMif.png)

#### **Expand custom role count for Advanced Permissions**

1. Click **Expand** on the **Custom roles in Advanced Permissions** card.

   ![](/aitable/admin-console/entitlement-stats/images/image_GBK3XK7LbQ.png)
2. You're taken to the order page — submit the upgrade order or schedule a consultation.

   ![](/aitable/admin-console/entitlement-stats/images/image_EA0WAn6Iqz.png)

### Usage breakdown

#### **Max rows per table — usage breakdown**

1. Click **Usage breakdown** on the **Max rows per table** card.

   ![](/aitable/admin-console/entitlement-stats/images/image_TsTduB0C3P.png)
2. The table-level row usage page opens — query row usage across the organization's tables.

   ![](/aitable/admin-console/entitlement-stats/images/image_XJ97g0KWRv.png)

#### **Custom roles — usage breakdown**

1. Click **Usage breakdown** on the **Custom roles** card.

   ![](/aitable/admin-console/entitlement-stats/images/image_IfV40nihny.png)
2. The Advanced Permissions custom-role usage page opens — query custom-role usage across the organization's tables.

   ![](/aitable/admin-console/entitlement-stats/images/image_nw-n1fIFOH.png)

## Recommendations

1. Check the entitlement stats page regularly and watch core capacity trends.
2. When a progress bar turns red or an entitlement alert appears, adjust resources promptly.
3. Pick (or upgrade) the AI Table plan based on your organization's actual scale and business complexity.
