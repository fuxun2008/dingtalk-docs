## Overview

The dashboard provides a **combo layout widget** — group chart widgets via drag, manual select, or click-add to fully customize layout.

### Common Scenarios

Group related data (e.g., regional sales) in one area — improve visual cohesion and surface insights faster.

## How to Use

### Add a Combo Layout Widget

In the upper-left, click **Add chart**. Pick **Combo layout**.

### Configure the Combo Layout

#### Method 1: Drag

- Drag existing dashboard widgets into or out of the combo layout.

#### Method 2: Manual Select

- For charts outside the combo layout: click the upper-right icon — pick "move into" the current combo layout.
- For charts inside the combo layout: click the upper-right icon — pick "move out" to remove from the combo layout.

#### Method 3: Click-Add

Hover inside the combo layout area — the top toolbar appears with **Add charts**. Click **Add charts** — multi-select dashboard widgets and click **Move in** to bring them into the combo layout.

### Manage the Combo Layout

#### Toolbar

Hover inside the combo layout — click an icon in the top toolbar:

- **Copy**: copy the current combo layout widget
- **Change background color**: change the combo layout background
- **Add to dashboard center**: add the combo layout widget to dashboard center
- **Copy as image**: copy the combo layout as an image
- **Export as image**: export the combo layout as an image
- **Delete**: delete the combo layout widget

#### Layout Adjustment

- **Resize**: select the widget — drag the lower-right corner to resize.
- **Reposition**: drag the top of the widget to move it.

## FAQ

#### Q: Can a Combo Layout Be Nested Inside Another Combo Layout?

A: No.
