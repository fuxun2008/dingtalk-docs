A column chart compares numeric values across categories — bar height shows size and difference. Great for sales rankings, resource allocation, or category comparison. Quickly identify max/min values and data distribution.

## Add a column chart

In the upper-left, click **Add chart**. Pick **Column chart**.

![](https://img.alicdn.com/imgextra/i1/O1CN010vfTXx1ySmSsokPZf_!!6000000006578-0-tps-423-396.jpg)


## Configure the column chart

Configure type/data and custom style:

**Data**: pick source — table and data range. **All data** enables filters.

![](https://img.alicdn.com/imgextra/i3/O1CN018r7zT51aQRfKjxpLJ_!!6000000003324-0-tps-304-341.jpg)


**Chart**: switch chart type, pick a color theme.

![](https://img.alicdn.com/imgextra/i1/O1CN017gX5tU1kCNf5ztke0_!!6000000004647-0-tps-296-282.jpg)


**X-axis**: pick the X field, sort basis (by X value, Y value, or record order), and order (ascending/descending).

![](https://img.alicdn.com/imgextra/i2/O1CN01POJetg1I8R0aB8lBO_!!6000000000848-0-tps-300-274.jpg)


Sort basis details:

X value: sort by the X field's value — numeric, alphabetical, single/multi-select option order, etc.
Y value: sort by Y numeric value.
Record order: sort by record order in the source view.

**Y-axis**: aggregation (count of records or aggregated field value), Y content, and group aggregation.

With "count of records": only set group aggregation (none or by field).

With "aggregated field value": no grouping → multiple Y fields, each with its own aggregation (count, sum, average, max, etc.). Remove/move up/down per Y. Grouping → one Y field with one aggregation. Note: with grouping, X can't sort by Y value.

![](https://img.alicdn.com/imgextra/i2/O1CN016TsUam1FxKAW3fejW_!!6000000000553-0-tps-295-346.jpg)


![](https://img.alicdn.com/imgextra/i4/O1CN01hK8w2323bY7ufyYLA_!!6000000007274-0-tps-301-464.jpg)


**Note**: sum, max, min, average only apply to numeric fields.

**Custom style**: background color, legend position, value display, gridlines, axis labels, overlap settings, axis visibility, axis baselines, axis-tick labels, X-label angle — all configurable.

![](https://img.alicdn.com/imgextra/i2/O1CN01GVBr3U24vX1SHVCq0_!!6000000007453-0-tps-300-520.jpg)


## Manage the column chart

Hover over the chart — find the icon in the upper-right. Click for: configure, rename, copy, add to dashboard center, copy as image, export as image, delete.

![](https://img.alicdn.com/imgextra/i4/O1CN01UvQW3g1OkLUFOwUT1_!!6000000001743-0-tps-624-334.jpg)


Drag the lower-right corner to resize. Drag the top to reposition.
