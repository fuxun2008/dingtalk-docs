Embed a grid view in the dashboard — bring AI Table's core data into the dashboard view. Combine the grid widget with analysis charts (line, column, etc.) for end-to-end presentation and pushes — boost cross-module collaboration.

## Add a Grid View Widget

In the upper-left, click **Add chart**. Pick **Grid view**.

![](https://img.alicdn.com/imgextra/i2/O1CN01iQv3lg1beTPj39UO8_!!6000000003490-0-tps-376-649.jpg)


## Configure the Grid View Widget

Configure type/data and custom style:

**Data**: pick source — table and data range. **All data** enables filters.

![](https://img.alicdn.com/imgextra/i2/O1CN01ksGV2122IU1UYOZMX_!!6000000007097-0-tps-296-307.jpg)


**Grid config**: groups, sorting, row height, fields shown and order.

![](https://img.alicdn.com/imgextra/i1/O1CN01nS36oP1j8t1ZqQeal_!!6000000004504-0-tps-287-499.jpg)


**Custom style**: background color.

![](https://img.alicdn.com/imgextra/i2/O1CN01ks2oL21nQ4LXrd8OZ_!!6000000005083-0-tps-296-784.jpg)


## Manage the Grid View Widget

Hover over the widget — find the icon in the upper-right. Click for: configure, rename, copy, add to dashboard center, copy as image, export as image, delete.

![](https://img.alicdn.com/imgextra/i1/O1CN01LBE8nm1whmCXoehWj_!!6000000006340-0-tps-918-336.jpg)


Drag the lower-right corner to resize. Drag the top to reposition.

## Relationship to the Original Grid View

A grid view widget added to the dashboard relates to the original grid view as follows:

- The widget is not editable.
- When you edit cells in the original grid view, the widget updates in sync. "Edit" = add/edit/delete record, add/edit/delete field.
- Their configs are independent. "Config" = filter, group, sort, row height, column width, field order, record order, etc.

## FAQ

#### **Q: Do Filter/Group Settings Inside the Widget Affect the Original View?**

A: No. The widget's config only applies inside the dashboard — the original view isn't affected.

#### **Q: If the Dashboard Has a Global Filter, What Data Shows in the Widget?**

A: Global filters apply to the widget too — and stack on top of the widget's own filter.
