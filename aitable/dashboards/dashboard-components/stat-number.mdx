A stat number widget surfaces a field's core stat (count, sum, average) as one bold, oversized number. It condenses complex underlying data into the most direct insight — the most efficient way to display **key metrics** on a dashboard, ensuring core info is at-a-glance.

## Add a stat number

In the upper-left of the dashboard, click **Add chart**. Pick **Stat number**.

![](https://img.alicdn.com/imgextra/i2/O1CN01GYvaqu1o5HzWRuNrE_!!6000000005173-0-tps-390-393.jpg)


## Configure the stat number

The config panel covers data and aggregation.

**Data**: pick source — table and data range. **All data** enables filters.

![](https://img.alicdn.com/imgextra/i4/O1CN01BVIUOg1L5B2MLRqKn_!!6000000001247-0-tps-295-315.jpg)


**Aggregation**: switch to "stat from field value" — pick a field and how to aggregate. Depending on field type: count, distinct count, sum, average, max, min. Sum/average/max/min only apply to numeric fields.

![](https://img.alicdn.com/imgextra/i3/O1CN01SLTbIe21PWUlQupw0_!!6000000006977-0-tps-294-172.jpg)


**Custom style**: configure background color, number color, value description, and number format. Formats: number, percentage, RMB, USD — with decimal places and large-number abbreviation.

![](https://img.alicdn.com/imgextra/i3/O1CN01jl81Gg1cNME8e4wLG_!!6000000003588-0-tps-296-728.jpg)


## Manage the stat number

Hover over the widget — find the icon in the upper-right. Click for: configure, rename, copy, add to dashboard center, copy as image, export as image, delete.

![](https://img.alicdn.com/imgextra/i4/O1CN01fgb7ti1NhldqkavyP_!!6000000001602-0-tps-500-326.jpg)


Drag the lower-right corner to resize. Drag the top to reposition.
