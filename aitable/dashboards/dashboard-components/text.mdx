Add a text widget to a dashboard to add written explanation alongside charts — show chart + description on the same screen, ideal for review reports and notes.

- **Reports & retrospectives**: state conclusions, data shifts, or anomalies inline — no page switching during a presentation.
- **Context**: explain chart purpose, metric definitions, and other background — helps teammates ramp up faster.

## Add a text widget

In the upper-left of the dashboard, click **Add chart**. In the chart type menu, pick **Text**.

![](https://img.alicdn.com/imgextra/i3/O1CN01UNiiYk1FrpPqMY8ec_!!6000000000541-0-tps-380-654.jpg)


## Configure the text widget

Type text in the widget. Select text to format — heading level, alignment, font size, etc.

![](https://img.alicdn.com/imgextra/i3/O1CN01aW5bLc1gxJn0PkxYs_!!6000000004208-0-tps-601-325.jpg)


Open, edit, or copy links inside the text widget.

![](https://img.alicdn.com/imgextra/i3/O1CN01Yf2Nq31gBgb9LVJ0v_!!6000000004104-0-tps-358-318.jpg)


## Manage the text widget

Hover over the widget — find the icon in the upper-right. Click it for: configure, rename, copy, copy as image, export as image, delete.

![](https://img.alicdn.com/imgextra/i2/O1CN01JGVYdg25y6rrY3DQA_!!6000000007594-0-tps-545-325.jpg)


Drag the lower-right corner of the widget to resize. Drag the top to reposition.
