---

The ranking widget lets you **sort** and **display** table data. For example, build sales rankings, user activity rankings, or performance completion rankings — visualize how different projects or people stack up to inform decisions.

## Add a Ranking

In the dashboard top toolbar, click **Add chart**. In the type menu, pick **Ranking**.

![](https://img.alicdn.com/imgextra/i3/O1CN010wLMqS1KnJakdRvel_!!6000000001208-0-tps-370-648.jpg)


## Configure the Ranking

Configure type/data and custom style:

**Data**: pick source — table and data range. **All data** enables filters. Picking a single view skips filters and uses the view's existing setup.

![](https://img.alicdn.com/imgextra/i3/O1CN01Kqktzp1DWdrYwDORH_!!6000000000224-0-tps-296-284.jpg)


**Ranking settings**: ranking field, basis, sort order, count.

- Ranking field: pick a specific table field.
- Basis: pick a field and one of count, distinct count, sum, average, max, min. Sum/average/max/min only on numeric fields.
- Sort order: **ascending** (default) or **descending**.
- Count: how many records to show — up to 100.

![](https://img.alicdn.com/imgextra/i1/O1CN01IJiYMm25NvZveYsZj_!!6000000007515-0-tps-293-340.jpg)


**Custom style**: background color, legend, axes, and more.

## Manage the Ranking

Hover over the chart — find the icon in the upper-right. Click for: configure, rename, copy, add to dashboard center, copy as image, export as image, delete.

![](https://img.alicdn.com/imgextra/i4/O1CN018vhkxA22fqDqnA1AR_!!6000000007148-0-tps-667-330.jpg)


Drag the lower-right corner to resize. Drag the top to reposition.
