A word cloud auto-counts word frequency from intelligent analysis and visualizes via font size and color intensity. Especially good for trending word analysis, user feedback patterns, etc. — surface key terms from large-scale text data.

## Add a word cloud

In the dashboard top toolbar, click **Add chart**. In the chart type menu, pick **Word cloud**.

![](https://img.alicdn.com/imgextra/i1/O1CN01HMppvv295qP0bY4B4_!!6000000008017-0-tps-388-381.jpg)


## Configure the word cloud

Set data and custom style:

**Data**: pick the source — table and data range. Selecting **All data** enables filters.

**Keyword field**: pick the keyword field, words to hide, and whether to auto-tokenize.

**Custom style**: change chart colors.

![](https://img.alicdn.com/imgextra/i4/O1CN01KQ7btR1zkvmCX1z2s_!!6000000006753-0-tps-299-483.jpg)


## Manage the word cloud

Hover over the chart — find the icon in the upper-right. Click for: configure, rename, copy, add to dashboard center, copy as image, export as image, delete.

![](https://img.alicdn.com/imgextra/i1/O1CN011vziuv1kBSs0mqDAC_!!6000000004645-0-tps-558-328.jpg)


Drag the lower-right corner to resize. Drag the top to reposition.
