A bar chart compares numeric values and ranks across categories — horizontal bar length shows size and order. Great for category sales, project progress, or customer satisfaction rankings — quickly identify leaders/laggards and analyze category differences.

## Add a bar chart

In the upper-left, click **Add chart**. Pick **Bar chart**.

![](https://img.alicdn.com/imgextra/i2/O1CN01qjWPjB1pM47F7aitn_!!6000000005345-0-tps-381-656.jpg)


## Configure the bar chart

Configure type/data and custom style:

**Data**: pick source — table and data range. **All data** enables filters.

![](https://img.alicdn.com/imgextra/i3/O1CN01EaGwfS1y0NuKqfunk_!!6000000006516-0-tps-299-316.jpg)


**Chart**: switch chart type, pick a color theme.

![](https://img.alicdn.com/imgextra/i1/O1CN01YmQZCL23hVH9FAaXs_!!6000000007287-0-tps-296-263.jpg)


**Y-axis**: pick the Y field, sort basis (by Y value, X value, or record order), and order.

![](https://img.alicdn.com/imgextra/i4/O1CN012J00KY1fxwiT8RIvg_!!6000000004074-0-tps-294-279.jpg)


Sort basis details:

Y value: sort by the Y field's value — numeric, alphabetical, single/multi-select option order, etc.
X value: sort by X numeric value.
Record order: sort by record order in the source view.

**X-axis**: aggregation (count of records or aggregated field value), Y content, and group aggregation.

With "count of records": only set group aggregation (none or by field).

![](https://img.alicdn.com/imgextra/i3/O1CN01N8wGHz1gz9NCvsB2j_!!6000000004212-0-tps-299-282.jpg)


With "aggregated field value": no grouping → multiple Y fields, each with its own aggregation (count, sum, average, max, etc.). Remove/move up/down per Y. Grouping → one Y field with one aggregation. Note: with grouping, X can't sort by Y value.

**Note**: sum, max, min, average only apply to numeric fields.

**Custom style**: background color, legend position, value display, gridlines, axis labels, overlap settings, axis visibility, axis baselines, axis-tick labels — all configurable.

![](https://img.alicdn.com/imgextra/i2/O1CN012JdxZ61RiShmvokGG_!!6000000002145-0-tps-298-617.jpg)


## Manage the bar chart

Hover over the chart — find the icon in the upper-right. Click for: configure, rename, copy, add to dashboard center, copy as image, export as image, delete.

![](https://img.alicdn.com/imgextra/i4/O1CN01tiCvL21MQX7dtWtud_!!6000000001429-0-tps-534-322.jpg)


Drag the lower-right corner to resize. Drag the top to reposition.
