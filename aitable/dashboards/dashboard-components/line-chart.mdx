A line chart visualizes value changes over time or continuous data — points and connecting lines show trend direction and fluctuations. Great for sales trends, performance metrics, or user growth — quickly spot peaks, troughs, and long-term direction.

## Add a Line Chart

In the upper-left, click **Add chart**. Pick **Line chart**.

![](https://img.alicdn.com/imgextra/i4/O1CN011IRjdp1GrCUMD7fKj_!!6000000000675-0-tps-396-390.jpg)


## Configure the Line Chart

Configure type/data and custom style:

**Data**: pick source — table and data range. **All data** enables filters.

![](https://img.alicdn.com/imgextra/i1/O1CN01dhcppG1gnF4kAndeB_!!6000000004186-0-tps-297-344.jpg)


**Chart**: switch chart type, pick a color theme.

![](https://img.alicdn.com/imgextra/i3/O1CN01cbfpQT26L0ff8m8EM_!!6000000007644-0-tps-299-194.jpg)


**X-axis**: pick the X field, sort basis (by X value, Y value, or record order), and order.

![](https://img.alicdn.com/imgextra/i4/O1CN01kOo5gX1P5PhpL3Pg3_!!6000000001789-0-tps-298-277.jpg)


Sort basis details:

X value: sort by the X field's value — numeric, alphabetical, single/multi-select option order, etc.
Y value: sort by Y numeric value.
Record order: sort by record order in the source view.

**Y-axis**: aggregation (count of records or aggregated field value), Y content, and group aggregation.

With "count of records": only set group aggregation (none or by field).

With "aggregated field value": no grouping → multiple Y fields, each with its own aggregation (count, sum, average, max, etc.). Remove/move up/down per Y. Grouping → one Y field with one aggregation. Note: with grouping, X can't sort by Y value.

![](https://img.alicdn.com/imgextra/i3/O1CN01u2z4uA1XSmqLWmQRc_!!6000000002923-0-tps-292-338.jpg)


![](https://img.alicdn.com/imgextra/i1/O1CN01DMhpnl1DULsmlsIQ9_!!6000000000219-0-tps-294-460.jpg)


**Note**: sum, max, min, average only apply to numeric fields.

**Custom style**: background color, legend position, value display, gridlines, axis labels, overlap settings, line type, axis visibility, axis baselines, axis-tick labels, X-label angle — all configurable.

![](https://img.alicdn.com/imgextra/i1/O1CN013iVYqx1xuQlB2Vqwj_!!6000000006503-0-tps-291-772.jpg)


## Manage the Line Chart

Hover over the chart — find the icon in the upper-right. Click for: configure, rename, copy, add to dashboard center, copy as image, export as image, delete.

![](https://img.alicdn.com/imgextra/i4/O1CN012vcn4x1DY13EMQhFZ_!!6000000000227-0-tps-547-328.jpg)


Drag the lower-right corner to resize. Drag the top to reposition.
