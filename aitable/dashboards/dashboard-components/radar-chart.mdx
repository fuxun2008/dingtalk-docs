A radar chart shows how multiple metrics perform across dimensions — visualize relative relationships clearly to identify strengths and gaps.

**Common scenarios:**

1. **Employee competency review**: show communication, technical skills, teamwork, and innovation in a radar chart — managers see strengths and improvement areas at a glance.
2. **Product performance analysis**: lay out product metrics (battery life, speed, stability, etc.) on a radar chart — compare strengths/weaknesses across products.
3. **Market competitiveness**: compare market share, brand awareness, customer satisfaction, R&D investment, etc. — back strategic decisions with data.

## Add a radar chart

In the upper-left, click **Add chart**. Pick **Radar chart**.

![](https://img.alicdn.com/imgextra/i4/O1CN01R95wqR1C9SC8AAN06_!!6000000000038-0-tps-381-380.jpg)


## Configure the radar chart

Configure type/data and custom style:

**Data**: pick source — table and data range. **All data** enables filters. Picking a specific view inherits the view's filter config.

![](https://img.alicdn.com/imgextra/i4/O1CN01KjUdLs21HHMlEIBRa_!!6000000006959-0-tps-287-293.jpg)


**Chart**: switch chart type, pick a color theme.

![](https://img.alicdn.com/imgextra/i4/O1CN01ydwadf1UBtO4gtncj_!!6000000002480-0-tps-291-191.jpg)


**Category axis**: pick the category field, sort basis (by category value or record order), and order.

![](https://img.alicdn.com/imgextra/i4/O1CN01NVrUEw1HIgFiyekRM_!!6000000000735-0-tps-293-276.jpg)


Sort basis details:

Category value: sort by the category field type — numeric, alphabetical, single/multi-select option order, etc.
Record order: sort by record order in the source view.

**Value axis (series)**: aggregation (count of records or aggregated field value), value content, and group aggregation.

With "count of records": only set group aggregation (none or by field).

With "aggregated field value": no grouping → multiple value fields, each with its own aggregation (count, sum, average, max, etc.). Remove/move up/down per value. Grouping → one value field with one aggregation.

![](https://img.alicdn.com/imgextra/i3/O1CN01jtMVBo1hjrlwxGN3X_!!6000000004314-0-tps-291-279.jpg)


**Note**: sum, max, min, average only apply to numeric fields.

**Custom style**: background color, radar shape (polygon/circle), color fill on/off, legend position, value display, overlap settings, axis visibility, axis baselines, axis-tick labels — all configurable.

![](https://img.alicdn.com/imgextra/i4/O1CN01gFqQzS1EsSLKXgiSI_!!6000000000407-0-tps-298-614.jpg)


## Manage the radar chart

Hover over the chart — find the icon in the upper-right. Click for: configure, rename, copy, add to dashboard center, copy as image, export as image, delete.

![](https://img.alicdn.com/imgextra/i2/O1CN01u1QDwB20StnaOaMkR_!!6000000006849-0-tps-511-326.jpg)


Drag the lower-right corner to resize. Drag the top to reposition.
