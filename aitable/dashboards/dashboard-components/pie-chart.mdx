A pie chart shows part-to-whole relationships — sector angles and areas reveal each category's share. Great for budget allocation, market share, or user composition. Quickly identify main components and compare each category's relative weight in the whole.

## Add a pie chart

In the upper-left, click **Add chart**. Pick **Pie chart**.

![](https://img.alicdn.com/imgextra/i4/O1CN010jPJkT1Kk6oqmnLIz_!!6000000001201-0-tps-398-390.jpg)


## Configure the pie chart

**Data**: pick source — table and data range. **All data** enables filters.

![](https://img.alicdn.com/imgextra/i3/O1CN015QnLDd1r7Wm9ANfwK_!!6000000005584-0-tps-296-311.jpg)


**Chart**: switch chart type and pick a color theme.

![](https://img.alicdn.com/imgextra/i1/O1CN01Mv65AV1gLlJNjcqks_!!6000000004126-0-tps-299-202.jpg)


**Sector grouping**: set the sector field and sort basis.

![](https://img.alicdn.com/imgextra/i1/O1CN018953NH1Fz9kkQxTHA_!!6000000000557-0-tps-301-202.jpg)


Sector field value: sort by the field's value — number size, alphabetical, single/multi-select option order, etc.
Sector value: sort by the sector's numeric value.

**Sector value**: count of records, or aggregated field value.

![](https://img.alicdn.com/imgextra/i3/O1CN01cK8Eos1d4PSTs8QK6_!!6000000003682-0-tps-296-122.jpg)


![](https://img.alicdn.com/imgextra/i3/O1CN01GcE3YJ1da0mrEgYVR_!!6000000003751-0-tps-299-199.jpg)


**Custom style**: background color, legend position, value display, inner/outer radius — to match your needs.

![](https://img.alicdn.com/imgextra/i3/O1CN01xV1OVJ23F6ifajP1r_!!6000000007225-0-tps-289-318.jpg)


## Manage the pie chart

Hover over the chart — find the icon in the upper-right. Click for: configure, rename, copy, add to dashboard center, copy as image, export as image, delete.

![](https://img.alicdn.com/imgextra/i3/O1CN01Sm1VWA1wD5fI61QUr_!!6000000006273-0-tps-548-331.jpg)


Drag the lower-right corner to resize. Drag the top to reposition.
