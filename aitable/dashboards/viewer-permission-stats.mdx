## Overview

When using a dashboard, different roles or admins may need to see different data. Configuration must match the actual scenario. **Stats by viewer's permission** is one of the most common settings — when on, dashboard data follows the table permission of the current viewer.

**Example**: 4 sales regions, each with a sales lead who can only view the table for their own region. The admin wants each sales lead to also only see their region's sales data on the dashboard — for direct insight into their performance. **Stats by viewer's permission** does exactly this. Otherwise, the dashboard defaults to whole-table stats, which doesn't match.

## Configuration

### Dashboard side

1. Open the dashboard as admin.
2. Find the icon in the upper-right.
3. Click → in the dropdown, pick **Data permission**.

### Advanced permissions

1. Turn on advanced permissions first.
2. The advanced permissions panel auto-lands on the dashboard editor's permission page. You can switch to viewers or other roles — the panel always shows that dashboard's permissions.

3. Three options in dashboard data permissions:
   1. **Hide chart when data isn't viewable**: if any record in the chart's source table can't be viewed by the role, the chart is hidden.
   2. **Stats by viewer's permission**: chart stats follow the role's table-level permission. If the role can only see some records, the chart stat reflects only those.
   3. **Stats from all data**: regardless of the role's table permission, the chart aggregates the full table.
