## Overview

Share a specific dashboard via a link with a configurable viewer scope. Recipients only see what you share — they can't access other AI Table data, keeping collaboration focused and secure.

### Common Scenarios

- **External reporting and presentation**
  When reporting to clients, investors, or executives, share only the dashboard — they see clean visualized conclusions without the underlying data or sensitive details.
- **Cross-team / cross-department data sync**
  When collaborating with other departments (e.g., syncing sales data to marketing), share the dashboard for efficient delivery — the recipient can't reach your other core tables, preserving data boundaries.

## How to Use

### Enable Dashboard Sharing

1. Open AI Table, navigate to the target dashboard.
2. In the upper-right, click **Share dashboard**.

3. Toggle **Share dashboard** on.

### Preview the Share

With sharing on, click the **Preview** icon next to the share link — see the dashboard as a recipient.

### Set Viewer Permissions

Pick one of three access scopes for the share link:

- **Anyone in the organization with the link can access**: only org members with the link.
- **Only invited people can access**: specific members only.
- **Anyone on the internet with the link can access**: anyone with the link.

### Access a Shared Dashboard

1. Recipients click the share link to open the dashboard and view data.

2. Data syncs on a schedule: as the dashboard updates, the shared page refreshes to show the latest.
3. If **Allow returning to source AI Table from the shared dashboard** is on, recipients can click **Open in AI Table** to view source data and details.

## FAQ

#### Q: Who Can Share a Dashboard?

A: Only the AI Table owner or users with admin permissions.

#### Q: Can a Shared Dashboard Be Edited?

A: No — recipients can only view the dashboard.

#### Q: Do Advanced Permission Settings Affect Dashboard Sharing?

A: No. Dashboard sharing is independent of advanced permissions. A shared dashboard shows only the data visible in that dashboard — advanced permissions don't apply during sharing.
