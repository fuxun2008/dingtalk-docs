Dear users, thank you for your continued support.

The AI Table print layout has been upgraded across the board — capabilities and interaction. The result is **a smoother layout flow** and **a more consistent experience**, with **unified management for record-level and table-level layouts, layout duplication, and more layout templates**.

Starting **January 15, 2026**, Free plan users can create, view, and use layouts (table-level or single-record), and export to PDF or print directly — both individually and in batch. Business and Enterprise organizations get layout editing on top of that, with sharing and collaboration on layouts and layout views rolling out gradually. The number of users with editing rights follows the seat count purchased for AI Table overall. Existing layouts and data are unaffected.

### Plan comparison for print layout

### FAQ

**Q: Can Free plan users keep using print layout?**

A: Yes. Free plan users can create, view, and use layouts (table-level or single-record), and export to PDF or print directly — batch operations included.

**Q: Will my existing layouts be affected?**

A: No. Existing layouts and data are not affected by this change — view and use them as before.

**Q: Is the pricing per user or per organization?**

A: Per organization. Available capabilities depend on the organization's plan; the editing seat count follows the total seats purchased for AI Table.
