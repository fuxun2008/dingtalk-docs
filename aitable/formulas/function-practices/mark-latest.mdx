#### 1 What it does

Mark each person's latest daily report in the table:

![](/aitable/formulas/function-practices/mark-latest/images/image_Qd_UUFWcC-.png)

#### 2 How to configure

Add a Last updated time field — the system stamps each record's most recent update time.

![](/aitable/formulas/function-practices/mark-latest/images/image_jxOIlXyjXX.png)

Add a lookup field to fetch the latest entry time per person.

![](/aitable/formulas/function-practices/mark-latest/images/image_OzoUwKTnRe.png)

Add a formula field to visually flag the latest record.

```javascript
IF([Last updated]=[Last filled time],"✅ latest entry","")
```

![](/aitable/formulas/function-practices/mark-latest/images/image_yjpN01NaoX.png)
