## Overview

The filter component is the core interactive tool for data visualization analysis — **dynamically filter dashboard data**. Add one or more filters and users can focus on a subset of data for interactive analysis and exploration.

**Common use cases**:

- **Global filtering**: set up dashboard-wide filters on key dimensions (time, region, product line) that control all related components on the page.
- **Multi-component filter linking**: configure dedicated filters per component for layered logic — e.g., a "time" filter applies globally, then a "product line" filter narrows just the sales detail table.

## Workflow

### **Add a filter component**

1. Open the AI Table app module.
2. From the left nav, pick the page.
3. Click **+ Add component** at the bottom-left, then **Filter**.

### **Basic config**

In the right panel **Basic config**:

- **Title**
  - Default is "Filter"; rename freely.
- **Data**
  - **Table and range**: pick a specific table and data range.
    - **All data** lets you set additional filter conditions.
  - **Display field**: pick one field from the dropdown to drive the filter content.
    - Fuzzy search is supported.
- **Filter style**
  - **Style type**: depends on the field type.

    - Date fields: dropdown, inline, date picker.
    - Number fields: dropdown, inline, number.
    - Enum fields: dropdown, inline.
  - **Sort order**: ascending or descending.

  - **Selection mode**: single or multi-select.

- **Scope**
  - **Affected charts**
    - **Auto**: by default, controls all charts on the page that share the data source.
    - **Custom**: pick which charts to link manually.

  - **Linked filters**
    - **Auto**: links all same-source filters on the page.
    - **Custom**: pick which same-source filters to link.

      **Linking note**: when multiple filters apply to the same chart, conditions are joined with **AND** — all must match.

### **Custom config**

In the right panel **Custom config**:

- **Background color**

  Set the component's overall background.
- **Border**
  - **Border color**: from swatch.
  - **Border thickness**: from dropdown.
- **Selected color**

  In inline style, set the highlight color for selected options.
- **Vertical alignment**

  Top-align or center-align content within the component.

### **Component management**

- **Action menu**

  - **Configure**: open config panel.
  - **Duplicate**: copy on the same page.
  - **Copy to**: to another page in this app.
  - **Delete**: remove.
- **Resize and move**

  - **Resize**: drag the bottom-right handle.
  - **Move**: hold and drag the component.
