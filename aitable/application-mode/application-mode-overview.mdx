If you've worked with AI Table's data layer or any relational backend, you've felt this: even with the data well organized, working directly on the backend can be tedious. In practice, most collaborators and end users don't need to see the data layer at all.

## What is app mode?

**App mode** is a visual interface built on top of table data. It turns complex backend tables into clean business surfaces — your team gets work done without staring at endless columns.

What app mode is for:

- **Simplify the workflow**: show users only the info they need; cut the noise.
- **Visual polish**: a more intuitive, polished simplification of repetitive workflows.
- **Strengths**:
  - Show data from multiple tables on one screen.
  - Powerful, fast filter options for collaborators and end users.
  - Stronger analysis and display components — pivot tables, filters, buttons, and more.

## App mode UI

### **❶** App nav

Design the app's navigation. Add pages / page groups, drag to reorder.

### ❷ Component canvas

Where added components live. Drag to position and resize.

### ❸ Configuration panel

Configure component data sources, appearance, and custom layout.

### ❹ Preview / share

Preview the designed app (desktop / mobile). When ready, publish and share with the team.

## Quickstart — build an app

### Create a new app

After creating, click the app name to:

- **Rename** the app.
- **Change icon**.

### Add pages

Organize content flexibly — add pages or page groups. Click **+** to the right of the app name, or **+ Add** at the bottom of the left list, to create a page or page group.

- **Add page**: standalone page.
- **Page group**: group related pages.

### Add components

Click **+ Add component** at the bottom-left of a page:

- **Add directly**: pick a component from the library.
- **Add existing**: pick from existing data — reuse a component you already have.

### Configure a component

In the right panel:

- **Basic config**: common settings.
- **Custom config**: component-specific.

### Page layout

Drag to reposition and resize components — design the layout however you want.

### App actions

#### Preview

Click **Preview** at the top-left to see the full app.

#### Settings

Click **Appearance** at the top-right to set app title and theme color.

#### Publish and share

Click **Publish & share** to enable sharing:

- **Access**: who can open it.
- **Return setting**: whether viewers can return to the AI Table from the shared app.
- **Share methods**: multiple options.
