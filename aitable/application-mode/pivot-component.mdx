## Overview

The pivot component does multi-dimensional, dynamic data analysis and aggregation. Drag fields to group, summarize, and cross-analyze — turn complex datasets into clear, structured tables that surface value from different angles.

- **Multi-dimensional analysis**: cross-aggregate the same dataset across multiple dimensions (time, region, product category) to generate stat reports fast.
- **Dynamic pivoting**: drag rows / columns / measures and filters; see aggregation under different combinations live.
- **Business reports**: sales reports, inventory analysis, performance stats — anywhere you need group / sum / count / average aggregation.

## Workflow

### **Add a pivot table**

Two ways:

**Way 1: from AI Table app module**

1. Open the **AI Table app** module.
2. From the left nav, pick the page.
3. Click **+ Add component** at the bottom-left, then **Pivot table**.

**Way 2: from AI Table data module**

1. Open the **AI Table data** module.
2. From the left nav, pick the dashboard.
3. Click **+ Add chart**, then **Pivot table**.

### **Basic config**

After adding, in the right panel:

- **Data source**
  - Pick the table and data range to analyze.
- **Pivot config**

  Pivot config is the core. Drag-drop for multi-dim analysis.
  - **Field management**

    - Add / remove fields: drag from the left field list into the config area, or drag out to remove.
    - Search fields: fuzzy search by name — useful when there are lots of fields.
  - **Row dimensions**

    Group rows by the dragged field — vertical grouping.

    - **Actions**:
      - Drag a field into the row area to add a row dimension.
      - Drag fields up/down to adjust grouping layer order.
      - Drag a field out to remove the dimension.
    - **Display**: row totals shown by default.
  - **Column dimensions**

    Group columns by the dragged field — horizontal grouping.

    - **Actions**:
      - Drag into column area, reorder by drag, drag out to remove.
    - **Display**: column totals shown by default — adjustable in style settings.
  - **Values (measures)**

    Stat metrics. Multiple aggregation types and numeric formats supported.

    - **Actions**:
      - Drag into value area, click the icon next to a field to set aggregation and number format, drag out to remove.
    - **Aggregation**: 13 types — sum, count, distinct count, average, max, min, etc.
    - **Number format**: decimal places, percent, thousands separator, currency, etc.
    - **Set alias**: the display name in the chart.
    - **Clear alias**: revert to original name.
    - **Remove field**: drop from value area.

### **Custom config**

In the right panel **Custom config**:

- **Background color**: the component background.
- **Border color**: from swatch.
- **Border thickness**: from dropdown.
- **Column totals**: usually at the **far right** — vertically sums each column, displaying the total across all rows for that column.
- **Row totals**: usually at the **bottom** — horizontally sums each row, displaying the total across all columns for that row.

In the dashboard config, you can also set:

- **Primary color**: pivot table theme color.
- **Vertical alignment**: vertical alignment of the pivot table within the component card.

## FAQ

#### Q: How do I refresh pivot table data?

A: Pivot table data follows its data source. When the underlying table updates, the pivot component usually auto-refreshes. You can also check that the component is wired to the right data source.

#### Q: Can I put multiple fields in row / column?

A: Yes. Drag multiple fields into row or column to form multi-level groupings — finer-grained drill-down. Field order determines hierarchy.

#### Q: **Pivot result limit?**

A: Up to 20,000 cells. If you exceed that, narrow the data filter or pivot config first.
