## List component

The **list component** is the core data-display module in app building. It surfaces records from a table as a grid, cards, expandable hierarchy, etc.

Pick from these 5 list types depending on your scenario (browsing detail, summary stats, product showcase, etc.).

### 1. Standard list

The most basic and general grid form — high-density structured data.

![](/aitable/application-mode/list-component/images/image_9AF0zwQXhy.png)

- **Use cases**: order management, inventory detail, attendance records — anywhere you scan info row by row.
- **Features**: column resize, sort, show/hide — closest to the Excel experience.

### 2. Card list

Each record is a visual **card** — emphasis on imagery.

![](/aitable/application-mode/list-component/images/image_p9-6BBkJEz.png)

- **Use cases**: employee directory (avatars), product showcase (product photos), asset management (device shots).
- **Setup**: set the **cover image field** (typically an "image / attachment" field). Without it, cards show text only.

### 3. Detail list

Optimized for deep-reading single records. Usually a brief list on the left, with the selected record's full detail on the right.

![](/aitable/application-mode/list-component/images/image_-bIChfsErS.png)

- **Use cases**: resume screening, contract review, customer profile review.
- **Features**: no page jumps — switch and read everything in one screen.

### 4. Aggregate list

Like a "pivot table" or "grouped stats" — doesn't show detail, shows summary stats grouped by a dimension.

![](/aitable/application-mode/list-component/images/image_RjqadFncuX.png)

- **Use cases**: monthly sales totals, headcount by department, ticket counts by status.
- **Setup**:
  - **Aggregation field**: the dimension to group by (e.g., "Department").

### 5. Collapsible list

Multi-level expand/collapse list — fits hierarchical data.

![](/aitable/application-mode/list-component/images/image_n9DsmnKx9J.png)

- **Use cases**: project task management (parent task > subtasks), OKR (objectives > key results).
- **Features**: click the row header to expand and view records under a group — keeps the interface tidy.

## Basic config

Whichever list type you pick, the core config logic is shared.

#### Open config

Click the icon at the top-right of the component.

![](/aitable/application-mode/list-component/images/image_r8EBpxCbnK.png)

#### Basic config

In **Basic config**, set the data source.

![](/aitable/application-mode/list-component/images/image_CpNPUvBzPx.png)

- **Table**: the source table the component connects to.
- **Data range**: default filter conditions. E.g., `Status = Done` so users only see completed data.
- **Field management**:
  - **Show / hide**: click the icon next to a field to toggle visibility in the list.
  - **Reorder**: drag the icon on the left of a field to change column order.
  - **Add aggregate field**: in the right of **Field management**, click **Add aggregate field** to combine multiple fields in one display. Multiple aggregate fields supported.
    1. Enter a field title; below, choose whether to **show field name**.
    2. If the table has an image-type attachment field, pick it under **Image** and set image size.
    3. Pick fields to aggregate. Up to 5.
    4. Choose whether to highlight the first field.
    5. Click **OK** when done.![](/aitable/application-mode/list-component/images/image_tKkLZWIG1G.png)
- **Default grouping**: set the default grouping. Click **+ Group rule** in the dropdown — pick the field and direction. Multiple fields supported for nested grouping.

![](/aitable/application-mode/list-component/images/image_aoUslwH2T9.png)

- **Default sort**: set the default sort. Click **+ Sort rule** — pick field and direction. Multiple fields supported for nested sorting.

![](/aitable/application-mode/list-component/images/image_6KQMqYyatI.png)

## Custom config — interaction and style

Switch to **Custom config** to control visual style and user actions.

![](/aitable/application-mode/list-component/images/image_fEH61GsvcW.png)

#### 1. Visual style

- **Colors**: customize title font color, background, border — coordinate with the app's overall style.
- **Border thickness**: adjust the grid line weight.

#### 2. View options

What action buttons end users see.

- **Filter / Group / Sort / Find**: when checked, the corresponding buttons show in the top-right of the list — users can self-adjust the view.
  - *Tip*: for report-style apps, enable **Filter** and **Find** for retrieval.

![](/aitable/application-mode/list-component/images/image_8UlKFoct5S.png)

#### 3. Permissions

- **Allow viewing record detail**: when checked, clicking a row slides out the full record detail (including fields not in the list).

![](/aitable/application-mode/list-component/images/image_HyUbaswaQ2.png)

Clicking opens the side panel.

![](/aitable/application-mode/list-component/images/image_UMmDMs1vH6.png)

- **Allow add / delete records**: when checked, the list shows add/delete buttons.
  - With **Add record** on, you can customize the button label.
  - *Tip*: for read-only display dashboards, **uncheck** these to prevent accidental edits.

![](/aitable/application-mode/list-component/images/image_tPnnhqdE2J.png)

![](/aitable/application-mode/list-component/images/image_Cs3XAUCFxs.png)

#### 4. Pagination

- **Pages**: classic page numbers (`< 1 2 3 >`) — good when users need to jump to specific pages.
- **Scroll**: infinite scroll — auto-load more data as you scroll.

![](/aitable/application-mode/list-component/images/image_1MCgszXHxq.png)

#### 5. Advanced interaction

- **Custom buttons**: when on, add custom action buttons above the list (jump links, trigger automation, etc.).

![](/aitable/application-mode/list-component/images/image_LfW4nujK4o.png)

- **Expand row detail**: configure which fields show in the detail panel after a row is clicked.
  - Choose which fields appear in the detail.
  - Configure display mode and field display style.

![](/aitable/application-mode/list-component/images/image_SwoybBVLaA.png)

## List-type-specific config

Beyond the shared options, certain list types have their own settings:

#### 1. Card list

Cover images are central.

- **Image field**: required — pick an "image / attachment" field.
- **Display mode**: image **fills** the card or shows **fully**.
- **Title field**: pick a text field as the main title (bolded).

![](/aitable/application-mode/list-component/images/image_Bm_gO4c1ga.png)

#### 2. Detail list

Supports cover image. Detail list expands the detail panel by default — configure which fields show in the detail.

![](/aitable/application-mode/list-component/images/image_OtF1egou-z.png)

## Component management

In the app canvas:

- **Resize**: drag any of the four edges or four corners of the component.

![](/aitable/application-mode/list-component/images/image_YQg7xo9g2X.png)

- **Move**: hold the drag handle at the top and drag anywhere.
- **Duplicate / delete**: click the menu at the top-right.

![](/aitable/application-mode/list-component/images/image_P6OYyOHv38.png)

## FAQ

- Q: Why doesn't the **aggregate list** show individual rows?

  A: **Aggregate list** is for stat overviews (totals, averages). For detail, use **Standard list** with grouping, or **Collapsible list**.
- Q: Why are images cropped in the card list?

  A: Check the picked image field. Upload images in a consistent ratio (16:9, 1:1). Plus, in card config, switch between **Fill** and **Fit**.
- Q: How do I change page size?

  A: In **Custom config > Pagination**, with **Pages** mode you can usually set per-page count (10/page, 50/page). With **Scroll** mode it's auto-loaded.
- Q: Can I put multiple lists on one page?

  A: Yes. Click **Add component** to add multiple list components — connect them to different tables, or show different views of the same table (e.g., "Pending" on the left, "Done" on the right).
