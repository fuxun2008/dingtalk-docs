## Overview

- The AI Table Contacts connector one-click syncs member info from **DingTalk Contacts** to AI Table.
- Pick departments / members / fields — the system creates a new people table with real-time updates: manual refresh + hourly auto-sync.
- Imported fields can't be edited, but you can still add custom fields. On top, you can use AI Table's automation, advanced permissions, dashboards, etc.
- If you need to freely edit the sync table, you can detach sync at any time, or duplicate the sync table — the duplicate has no relationship to the source.

## Common scenarios

- **People ledger / roster management:** sync the org Contacts member info into AI Table — centralize people data for maintenance, quick lookup, and team collaboration.
- **Project member assignment:** when starting a new project, pick relevant departments / members → sync as a project member table → assign roles, link tasks. Member info is no longer scattered across groups and docs.
- **Cross-team ad-hoc squads:** events, special projects, ad-hoc work often needs people from multiple departments. Sync directly into a table — see who comes from which department and is responsible for what at a glance.
- **External collaborator management:** sync external partners, consultants, or part-time members into a unified table — distinguish identity, role, and projects, with clearer collaboration boundaries.
- **Responsibility / point-of-contact tracking:** turn "who's responsible for what, who points-of-contacts what business" into a structured people table — reduces repeat asking, group pulling, and history scrolling.

## Steps

### Step 1: open the Data sync center

In AI Table, open **Data sync center**, find and pick the **Contacts** connector, click confirm.

> 📌 Note: you need **manage permission** on the AI Table to use the Data sync center.

### Step 2: pick the departments / members to sync

Pick the departments or members to sync — the system only shows the scope where **you're a primary admin or department head**.

### Step 3: pick the fields to sync

Check the member fields to sync to AI Table — e.g., employee ID, department. Checked fields auto-become columns in the table.

### Step 4: configure data refresh / sync settings

Latest data auto-syncs to the current table by your settings — hourly or scheduled daily.

### Step 5: become a data table in AI Table

The system auto-creates a new AI Table data table and writes the chosen member data. Once synced, you can use it directly in AI Table.

### After sync

After sync, this table exists as a regular data table — you can keep using and maintaining it as needed: e.g., **add columns to extend with your own business data**, or **detach sync any time**.

### Add columns to extend with business data

You can keep adding fields to the people table — for example:

- Member role, project assignment, tags, notes.
- AI fields, formula fields.
- Project / task linked fields.

Newly added fields don't affect synced contacts data — the people table can carry both contacts info and your business info side-by-side.

### Edit sync settings

To adjust the sync (member / department scope, contact fields, sync schedule), click **Edit sync settings**.

### Manual refresh

After sync, you can trigger a one-off update at any time via **Refresh data** in the table's sync settings — sync the latest member info from Contacts into the current table.

### Detach sync

If you **no longer need to sync from Contacts**, or want to **freely adjust existing data**, click **Detach sync** in the table's sync settings. After detach, the table becomes a regular table — existing data is retained, but the original sync relationship can't be restored.

> 📌 Note: you need **manage permission** on the AI Table to find the detach entry and successfully detach.

## FAQ

#### Who can use the Contacts connector?

Currently only primary admins (excluding sub-admins) and department heads. The syncable member scope follows DingTalk Contacts admin permissions.

#### Can I edit the data in the synced table?

No — editing isn't directly supported. To freely edit the data and content, detach sync first.

#### Does the Contacts data in the table support auto-updates?

Yes. Enable scheduled sync (hourly / daily) in sync settings — the system auto-syncs the latest data from DingTalk Contacts.

#### After sync, can I add columns / fields to the table?

Yes. After sync, you can freely add fields, reorder synced fields, hide fields, etc.

#### Why don't I see some departments / members?

You can only see departments / members where you have admin permission in Contacts. To sync a wider scope, contact your admin to grant permission.

#### I'm a department head — why am I told I have no permission?

The Contacts connector only supports primary admins and members **set as Contacts department heads**. If you're told no permission, you're currently neither a department head nor a primary admin in Contacts. Confirm your Contacts admin permission with the org admin.

#### I'm a primary admin / department head — why am I still told no permission?

Confirm whether the current AI Table's **owning organization** matches the org where you have Contacts admin permission. Click the icon at the AI Table top-right → **Doc info** → check the **owning organization**.
