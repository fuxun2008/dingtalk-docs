## Overview

- OA Approval **process forms** can be synced to AI Table via the AI Table Data sync center, with multiple flexible update modes — manual or hourly auto-sync.
- Imported fields can't be edited, but you can still add custom fields. On top, you can use AI Table's automation, advanced permissions, dashboards, etc.
- If you need to freely edit the sync table, you can detach sync at any time, or duplicate the sync table — the duplicate has no relationship to the source.

## Common scenarios

- **Spend analysis:** sync reimbursement / travel / cash-advance / payment approvals over a period (monthly / quarterly / yearly) to AI Table — flexibly analyze by person, dept, project, or expense type to spot anomalies and patterns in daily spend.
- **HR management:** sync HR approvals (leave, overtime, shift change, resignation, etc.) to AI Table — one place to see attendance and changes. HR can analyze each team's workload and inform performance reviews.

## ‼️ Must-read: rules for syncing OA Approval data

### What you can sync

| Your role | **Syncable scope** |
| --- | --- |
| Submitter or approver | OA approvals where you're the submitter or approver |
| Approval process admin or has view-or-above permission | Approvals within your manageable scope. You can sync **approvals you're authorized to view**, including those not initiated by you |

⚠️ If the approval-data sync owner leaves the org, that approval flow can't sync — please re-create the data source.

### Rules when the OA Approval template changes

If the approval template is modified after sync (renaming controls, adding / removing controls, reordering, etc.), already-synced AI Table data may update incorrectly. We recommend syncing after the form config is finalized. If you must adjust the template structure later, re-create the form and re-sync.

## How to sync OA Approval data

![](/aitable/data-connectors/dingtalk-oa-approval-sync/images/2026-01-19_szRZAfiiks)

### Find the OA Approval data source

1. In the AI Table left sidebar bottom, click **+ Add / Import** → pick **Data sync center**.

   ![](/aitable/data-connectors/dingtalk-oa-approval-sync/images/image_tYvffPYd-A.png)
2. **Pick the data source**: pick or search for the **OA Approval** connector → click **Use** to enter setup.

   ![](/aitable/data-connectors/dingtalk-oa-approval-sync/images/image_Yy_CELoQZq.png)

### Sync configuration

![](/aitable/data-connectors/dingtalk-oa-approval-sync/images/image_v__KHBr0G2.png)

1. **Pick the data source**: only 1 source is available — selected by default.
2. **Parameters:** pick the approval flow to sync, set the time range — two modes:

   ![](/aitable/data-connectors/dingtalk-oa-approval-sync/images/image_lWP1LeNC6S.png)

   Note: both manual and auto updates currently support pulling only the last **1 year** of data; longer ranges are on the roadmap.
   | **Mode** | **Supported range** | **Description** |
   | --- | --- | --- |
   | Time period | Start date — End date | **In auto-update, the system uses the current date to decide whether to update. If the current date is past the end date, sync auto-stops. To keep auto-updating, manually adjust the range or remove the end date.** |
   |  | Start date — No end date | Without an end date, auto-update doesn't stop, but only the last 1 year is pulled by default. |
   | Recent | Last 7 / 30 / 365 days | Auto-syncs the recent range — **historical data outside the range is auto-cleared**. |
3. **Fields**: select all / partial fields to sync. If select-all, newly added source fields auto-sync.
4. **Sync settings**: pick which fields to sync and whether to auto-sync hourly. Click Save & Sync when done.
5. **Create** config: click Create — a sync table named after the approval form is auto-created, with a lightning badge.

## Manage data sync

![](/aitable/data-connectors/dingtalk-oa-approval-sync/images/image__IIoi_jBzz.png)

After clicking **Save & Sync**, the selected source view shows up as a data table in the AI Table left nav.

Synced tables carry a **lightning badge** — by default named after the approval form. You can rename, **duplicate**, **delete** them, and add fields for your needs. Note: synced fields also carry the lightning badge — their content can't be edited directly in AI Table, the field type can't be changed, and these fields can't be deleted.

**Note:** if you duplicate the sync table, the duplicate becomes a regular table — its content is freely editable, but it no longer has any sync relationship to the source. To **edit sync settings**, open the synced table → click the **More** icon next to the table name → click **Data sync settings**. To **manually sync data**, click **Refresh data** for a manual sync.

## Detach the sync relationship

Click **Detach sync** — the table becomes a regular table and keeps its existing data. This action can't be undone.

Note: you need **manage permission** on the sync table to find the detach entry and successfully detach.

![](/aitable/data-connectors/dingtalk-oa-approval-sync/images/image_9SMPvk67G8.png)

## FAQ

#### Q: Which OA Approval form types can serve as a data source for AI Table?

A: Currently only process forms; data forms are on the roadmap.

#### Q: What approval data can I sync in AI Table?

A:

You can sync approval data you have permission for — you can be in any of these roles:

- Approval admin: sync approvals within your manageable scope.
- Member: sync approvals where you're the **submitter** or **approver**.

#### Q: Can one AI Table sync multiple approval flows?

A: Yes — sync different approval flows to multiple data tables in the same AI Table for centralized management and categorized review.

#### Q: Can I sync a modified OA Approval form to AI Table?

A: Not currently. If a form is modified after sync, AI Table updates may be incorrect.

#### Q: Are unfinished approvals that get withdrawn synced to AI Table?

A: Yes — once an unfinished approval is withdrawn, the flow syncs to AI Table.

#### Q: Are unfinished approvals synced to AI Table?

A: Yes — once an approval is initiated, regardless of completion, it syncs to AI Table.

#### Q: Why are there duplicate rows in AI Table after syncing approvals?

A: Likely because the synced approval flow contains a detail control. If you can't adjust the approval flow, detach sync after the data syncs and manually delete duplicates.

#### Q: Why did data suddenly stop auto-updating?

A:

First check the sync settings:

- Possibility 1: **End date set**, and the current date is past it. Sync auto-stops in this case.
- Possibility 2: **No end date**, but the sync range exceeds 1 year. Currently auto-sync only supports **last 1 year of data** — anything beyond won't auto-update.

#### Q: Why is my historical data gone?

A: If sync settings use **Recent** (last 7 / 30 / 365 days), **history older than the range is auto-cleared** — only the recent data is kept.

#### **Q: Is there a row-count limit for OA Approval data sync?**

A: Yes — up to 20,000 rows. One AI Table can have at most 100 data tables.

#### Q: Can I edit the synced data?

A: No — read-only. You can't edit, delete, or add records, nor create a form view.

#### Q: Does deleting the data source affect sync?

A: After deleting the data source, already-synced data is retained, but no further sync.
