## Overview

- Sync AI Minutes data into AI Table via the AI Table Data sync center.
- Synced fields can't be edited, but you can still add custom fields. On top, you can use AI Table's automation, advanced permissions, dashboards, etc.
- If you need to freely edit the sync table, you can detach sync at any time, or duplicate the sync table — the duplicate has no effect on the original DingTalk table.

## **Common scenarios**

- Manage meeting minutes and drive task follow-ups. With AI Minutes synced to AI Table — leveraging the **AI Minutes detail link** plus **AI Minutes summary in AI fields** — generate structured meeting minutes intelligently. Categorize and manage by creator, participants, AI Minutes created date, etc., to help your team efficiently capture, organize, and archive meetings.

## Sync AI Minutes data

### Open the Data sync center

In the AI Table bottom-left, click **Add / Import** → **Data sync center**.

### Pick a data source

Pick or search for the **AI Minutes** connector → click **Use** to enter setup.

### Data source settings

1. **Pick the data source**: only 1 source is available — selected by default.
2. **Parameters**: set the sync time range. Two modes:
   1. **Recent range**: last 1 year / 30 days / 7 days.

   2. **Specific range**: set start time + end time. End time can be **No end date** for continuous, uninterrupted sync.

3. **Fields**: select all / partial fields — flexibly scope the columns. Primary keys can't be unchecked.

4. **Sync settings**: turn sync on / off. When on, pick **hourly** or **scheduled**:
   - **Hourly**: every 1 / 12 / 24 hours.
   - **Scheduled**: a fixed time point daily / weekly / monthly; configurable to skip holidays.

⚠️ Tip: if anything breaks during data-source setup, use **Data source page → Submit feedback** to report it.

### Create the sync

Once configured, click **Create** to start the sync. On success, a **lightning-badged data table** is auto-generated and the selected time range is auto-synced.

AI field setup: when creating an AI Minutes data sync, you can configure AI fields. When enabled, after sync **AI Minutes summary**, **AI speaker viewpoint extraction**, and **AI meeting QA** fields are auto-created.

[AI field quota rules](/aitable/data-connectors/dingtalk-ai-meeting-sync/ai-field-quota-rules)

⚠️ Note:

- The default table name is **My AI Minutes list** — you can rename it.
- Synced fields carry a lightning badge — you can't manually add or delete records, change field types or content, or delete fields. You can add new fields for data management.
- You can duplicate the sync table — the duplicate is a regular data table, content is editable, and it has no sync relationship with the source.

## Post-sync operations

- **Edit sync settings**

  For an existing sync table, click the icon on the right → **Data sync settings** to change synced fields, sync mechanism, or toggle auto-sync.
- **Refresh data**

  Manual sync — open the sync table, click the ⋮ More icon next to the table name → **Refresh data** to manually refetch from the source and update.
- **Detach the sync relationship**

  Click **Detach sync** — the sync table becomes editable and no longer follows the source.

### FAQ

- **Q: When AI Minutes data is updated, is it auto-synced to AI Table?**

  A: With auto-sync on, updates are synced to AI Table on the configured cycle. You can also click the icon next to the table name → **Refresh data** for a manual sync.
- **Q: What's the max number of AI Minutes records I can sync into one AI Table?**

  A: Each AI Table data table currently supports up to 20,000 rows; one AI Table can have at most 100 data tables.
- **Q: Which AI Minutes can I sync to AI Table?**

  A: AI Minutes under the **Created by me** and **Shared with me** categories — i.e., AI Minutes you have permission to view. AI Minutes you don't have permission to view aren't synced.
