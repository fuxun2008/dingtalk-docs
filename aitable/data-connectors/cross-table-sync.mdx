## Overview

With AI Table's **cross-table data source sync**, you can quickly sync or roll up data from different AI Tables into a single AI Table. Synced data is read-only — you can't directly edit it. But you can add new fields in the sync table for extra info, or remove the sync config to convert it into a regular editable table.

> ⚠️ Note: only users with manage permission on the current AI Table can find the **Data sync center** entry in the bottom-left and create a sync.

Cross-table sync fits many real scenarios:

**Project management**

Team A and Team B each maintain their own project progress sheet (AI Table). With **cross-table data source sync**, the project manager rolls both teams' progress data into a single master sheet for unified review.

**Sales data roll-up**

Different regional sales teams record their own sales data. With **cross-table data source sync**, regional data rolls up into a headquarters master sheet for org-wide analysis.

## Create a sync

### Steps

1. In the AI Table left sidebar bottom, click **+ Add / Import** → pick **Data sync center → AI Table**.
2. Configure **data sync settings** — source and sync mode.

   ![](/aitable/data-connectors/cross-table-sync/images/2026-01-15%2015.14.15_MKkJtHpnvq.gif)
   1. Parameters: pick the data source — **AI Table file → data table → view**, in order. Keyword search is supported.

      Note: filter conditions on a source view are honored — sync results follow the filter. To sync only part of the source data, set + save filter conditions on a view first, then create the sync — synced data is the filtered result.
   2. Fields: select all or partial fields to sync from the source. If select-all, newly added source fields auto-sync into the table.
   3. Sync settings: pick fields to sync and whether to auto-sync hourly. Click **Save & Sync** when done.
3. After config, click Create.

### Permissions to create a sync

| **Source AI Table — Advanced permissions** | **Required on sync table** | **Required on source table** |
| --- | --- | --- |
| Off | Manage or above | View / Download or above |
| On | Manage or above | Manage or above |

## Manage data sync

### Notes on the sync table

![](/aitable/data-connectors/cross-table-sync/images/image_jKIHEqmPu0.png)

After clicking **Save & Sync**, the selected source view shows up as a data table in the AI Table left nav.

Synced tables carry a **lightning badge** — by default named after the source. You can rename, **duplicate**, **delete** them, and add fields for your needs. Note: synced fields also carry the lightning badge — their content can't be edited directly in AI Table, the field type can't be changed, and these fields can't be deleted.

**Note:** if you duplicate the sync table, the duplicate becomes a regular table — its content is freely editable, but it no longer has any sync relationship to the source. To **edit sync settings**, open the synced table → click the **More** icon next to the table name → click **Data sync settings**. To **manually sync data**, click **Refresh data** for a manual sync.

### Permission requirements

#### Manual data refresh

| **Sync AI Table — Advanced permissions** | **Required on sync table** | **Required on source table** |
| --- | --- | --- |
| Off | Edit or above | View / Download or above |
| On | Manage or above | View / Download or above |

#### Edit sync settings

| **Sync AI Table — Advanced permissions** | **Required on sync table** | **Required on source table** |
| --- | --- | --- |
| On / Off | Manage or above | View / Download or above |

### **Detach the sync relationship**

Click **Detach sync** — the table becomes a regular table and keeps its existing data. This action can't be undone.

Note: you need **manage permission** on the sync table to find the detach entry and successfully detach.

## FAQ

#### **Q: Is there a row-count limit for cross-AI-Table sync?**

A: Yes — up to 20,000 rows. One AI Table can have at most 100 data tables.

#### **Q: What sync limits apply to different field types?**

A: The index column syncs by default and can't be removed. Workflow fields and button fields aren't supported. Auto-number, lookup, one-way / two-way linked fields convert to text after sync. Formula fields adapt to the computed result type — if no match, they fall back to text.

#### **Q: Can I edit the synced data?**

A: No — read-only. You can't edit, delete, or add records, nor create a form view.

#### **Q: Does deleting the data source affect sync?**

A: After deleting the data source, already-synced data is retained, but no further sync.

#### **Q: If the source view has filters or sorting, what shows up in AI Table?**

A: Synced data follows the view's filter — only filtered content syncs. Sort order isn't preserved.

#### Q: Will updates from sync trigger linked AI fields and automations?

A: Yes.

#### **Q: Can the sync table itself be a source?**

A: Yes.

#### **Q: Can one AI Table sync multiple data tables?**

A: Yes.

#### **Q: When does auto-sync slow down or stop?**

A: If you don't view the AI Table for 10+ days, auto-sync drops from hourly to once daily. If you don't view it for 30+ days, auto-sync stops — manually re-enable to resume.

#### **Q: Can I undo synced data?**

A: No.

#### **Q: How does an auto-number field convert after sync?**

A: It becomes text. If you need another format, use the **TEXT** function.

#### **Q: Can data tables within the same AI Table sync to each other?**

A: No.

#### **Q: Can I sync AI Tables outside my org?**

A: No.

#### **Q: If the source view is renamed, does that break an existing sync?**

A: No — sync continues normally.
