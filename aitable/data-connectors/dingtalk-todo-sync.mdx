## Overview

- Sync **todos you created** and **todos assigned to you** to AI Table — with real-time updates: manual refresh + hourly auto-sync.
- Imported fields can't be edited, but you can still add custom fields. On top, you can use AI Table's automation, advanced permissions, dashboards, etc.
- If you need to freely edit the sync table, you can detach sync at any time, or duplicate the sync table — the duplicate has no relationship to the source.

## Common scenarios

- Sync **all todos that involve you** to AI Table — manage uniformly by completion status, assignee, due date, and build a clear, real-time task board.
- For managers: approvals, reimbursements, announcements, cross-team surveys, onboarding, project follow-ups — aggregate into one table, auto-remind owners at key milestones, reduce missed tasks and back-and-forth. Quickly review the execution of tasks you created and delegated — weekly completion rate, overdue distribution, per-assignee progress — to drive team management and performance evaluation.
- For individuals: not only does it remind you to ship each task efficiently, it also clearly shows what got done well this week and what still needs work — a great helper for self-management and productivity.

## Sync todo data

1. In the AI Table left sidebar bottom, click **+ Add / Import** → pick **Data sync center**.

2. Pick the data source: pick or search for the **Todo** connector → click **Use** to enter setup.

3. Data source settings:
   1. **Pick the data source**: only 1 source is available — selected by default.

      Note: only two kinds of todo data are syncable — **todos created in the last 180 days, plus all unfinished todos (no time limit)**.
   2. **Fields**: select all / partial fields to sync from todos.
   3. **Sync settings**: turn sync on / off. When on, pick **hourly** or **scheduled**:
      - **Hourly**: every 1 / 12 / 24 hours.
      - **Scheduled**: a fixed time point daily / weekly / monthly; configurable to skip holidays.
        Note: **completed todos retain only the last 180 days of data** — older data is auto-cleared. **Unfinished todos have no time limit** — they're retained and synced indefinitely.

## Manage data sync

After clicking **Save & Sync**, the selected source view shows up as a data table in the AI Table left nav.

Synced tables carry a **lightning badge** — default name is **Synced todo task list**, but you can rename it. You can also **duplicate** / **delete** the table, and add fields to meet your data management needs. Note: synced fields also carry the lightning badge — their content can't be edited directly in AI Table, the field type can't be changed, and these fields can't be deleted.

**Note: if you duplicate the sync table, the duplicate becomes a regular table — its content is freely editable, but it no longer has any sync relationship to the source.** To **edit sync settings**, open the synced table → click the **More** icon next to the table name → click **Data sync settings**. To **manually sync data**, click **Refresh data** to do a manual sync.

## Detach the sync relationship

Click **Detach sync** — the table becomes a regular table and keeps its existing data. This action can't be undone.

Note: you need **manage permission** on the sync table to find the detach entry and successfully detach.

## FAQ

#### Q: Which todo data can I sync to AI Table?

A: Todos that involve you — i.e., where you're either the creator or the assignee.

#### Q: Why is my historical data gone?

A: **Completed todos retain only the last 180 days of data** — older data is auto-cleared. **Unfinished todos have no time limit** — they're retained and synced indefinitely.

#### Q: Does deleting the data source affect sync?

A: After deleting the data source, already-synced data is retained, but no further sync.

#### Q: Can I edit the synced data?

A: No — read-only. You can't edit, delete, or add records, nor create a form view.

#### Q: **Is there a row-count limit for todo data sync?**

A: Yes — up to 20,000 rows. One AI Table can have at most 100 data tables.
