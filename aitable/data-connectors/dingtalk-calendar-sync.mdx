## Overview

- Sync **calendars you created** and **calendars you joined** to AI Table — with real-time updates: manual refresh + hourly auto-sync.
- Imported fields can't be edited, but you can still add custom fields. On top, you can use AI Table's automation, advanced permissions, dashboards, etc.
- If you need to freely edit the sync table, you can detach sync at any time, or duplicate the sync table — the duplicate has no relationship to the source.

## Common scenarios

- Sync **all calendar items that involve you** to AI Table — manage uniformly by event status, organizer, created time. Plus, **sync the linked AI Minutes link** of an associated calendar — combined with AI fields, auto-generate AI Minutes summaries to build a clear, interconnected, easily searchable / reviewable calendar management system.
- For managers: get a unified view of team members' calendars and meeting distribution; quickly identify key meetings and high-frequency events; combined with AI-generated AI Minutes summaries, learn meeting outcomes efficiently — reduces repeat follow-ups and missed info.
- For individuals: centrally manage all your calendars and meeting records; one-click view historical AI Minutes and key takeaways; auto-distill TODOs — helps you review meetings, plan time, and drive work more efficiently.

## Sync data scope

You can sync only your own calendar, protecting employee privacy. You don't have permission to sync others' calendars in the org.

## Sync calendar data

1. In the AI Table left sidebar bottom, click **+ Add / Import** → pick **Data sync center**.

2. Pick the data source: pick or search for the **Calendar** connector → click **Use** to enter setup.

3. Data source settings:
   1. **Pick the data source**: only 1 source is available — selected by default.

      Note: only the last year's calendars (counted by **start time**) are syncable.
   2. **Parameters**: pick the calendar start-time range to sync — the system only syncs events that start within this range.
   3. **Fields**: select all / partial fields to sync from the calendar.
   4. **Sync settings**: turn sync on / off. When on, pick **hourly** or **scheduled**:
      - **Hourly**: every 1 / 12 / 24 hours.
      - **Scheduled**: a fixed time point daily / weekly / monthly; configurable to skip holidays.
        Note: **calendars retain only the last year's data** — older data is auto-cleared.

## Manage data sync

After clicking **Save & Sync**, the selected source view shows up as a data table in the AI Table left nav.

Synced tables carry a **lightning badge** — default name is **Calendar list**, but you can rename it. You can also **duplicate** / **delete** the table, and add fields to meet your data management needs. Note: synced fields also carry the lightning badge — their content can't be edited directly in AI Table, the field type can't be changed, and these fields can't be deleted.

**Note: if you duplicate the sync table, the duplicate becomes a regular table — its content is freely editable, but it no longer has any sync relationship to the source. To edit sync settings**, open the synced table → click the **More** icon next to the table name → click **Data sync settings**. To **manually sync data**, click **Refresh data** to do a manual sync.

## Detach the sync relationship

Click **Detach sync** — the table becomes a regular table and keeps its existing data. This action can't be undone.

Note: you need **manage permission** on the sync table to find the detach entry and successfully detach.

## FAQ

#### Q: Can a manager sync subordinates' data in AI Table?

A: No — managers can't sync all of a subordinate's data; only calendar data involving the manager themselves (including events where the manager is a participant) can be synced.

#### Q: Why is my historical data gone?

A: Calendar data synced to AI Table retains only the last 180 days — older data is auto-cleared.

#### Q: Does deleting the data source affect sync?

A: After deleting the data source, already-synced data is retained, but no further sync.

#### Q: Can I edit the synced data?

A: No — read-only. You can't edit, delete, or add records, nor create a form view.

#### Q: Is there a row-count limit for data sync?

A: Yes — up to 20,000 rows. One AI Table can have at most 100 data tables.
