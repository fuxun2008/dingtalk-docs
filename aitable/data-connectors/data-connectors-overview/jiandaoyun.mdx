## Prep: link your Jiandaoyun account

Account application guide: [https://hc.jiandaoyun.com/open/10992](https://hc.jiandaoyun.com/open/10992 "https://hc.jiandaoyun.com/open/10992")

**Sign in first** to Jiandaoyun. Newcomers can claim a trial in the admin backend.

![](/aitable/data-connectors/data-connectors-overview/jiandaoyun/images/image_98uLlc9NeR.png)

Get the API Key — open [https://www.jiandaoyun.com/open#/key/api_key](https://www.jiandaoyun.com/open#/key/api_key "https://www.jiandaoyun.com/open#/key/api_key"), create an API Key, and copy it.

![](/aitable/data-connectors/data-connectors-overview/jiandaoyun/images/image_UiVgSMrb5Z.png)

## Open the Data sync center

In the AI Table bottom-left, click **Add / Import** → **Data sync center**.

![](/aitable/data-connectors/data-connectors-overview/jiandaoyun/images/image_gJNkUq9c5u.png)

Open the Data sync center.

![](/aitable/data-connectors/data-connectors-overview/jiandaoyun/images/image_Dw_LPLZj2q.png)

## Pick a data source

Pick or search for the **Jiandaoyun** connector → click **Use** to enter the data source settings.

![](/aitable/data-connectors/data-connectors-overview/jiandaoyun/images/image_Qpw4GAqpY5.png)

## Data source settings

### **Pick the data source**

Only 1 source is available — selected by default.

![](/aitable/data-connectors/data-connectors-overview/jiandaoyun/images/image_zXFYt_m1N-.png)

### **Account setup**

Name is up to you; add the prepped API Key (see Prep above).

![](/aitable/data-connectors/data-connectors-overview/jiandaoyun/images/image_haP2o_nmHp.png)

### **Fields**

Select all / partial fields — flexibly scope the columns in the table. Primary keys can't be unchecked.

### **Sync settings**

![  ](/aitable/data-connectors/data-connectors-overview/jiandaoyun/images/20250823142129_ZKB82IJEn5.jpg)

Turn sync on / off. When on, pick **hourly** or **scheduled**:

- **Hourly**: every 1 / 12 / 24 hours.
- **Scheduled**: a fixed time point daily / weekly / monthly; configurable to skip holidays.

  Tip: if anything breaks during connector setup, use **Connector page → Submit feedback** to report it.

## Click Create to start syncing

Once the connector is configured, click **Create** to begin the sync. On success, a new sync table is auto-added.

![](/aitable/data-connectors/data-connectors-overview/jiandaoyun/images/image_XDybbmjY5R.png)

## Post-sync operations

- **Edit sync settings**

  For an existing sync table, click the icon on the right → **Data sync settings** to change synced fields, sync mechanism, or toggle auto-sync.
- **Manual refresh**

  Open the sync table, click the ⋮ More icon next to the table name → **Refresh data** to manually refetch from the source and update.
- **Detach the sync relationship**

  Click **Detach sync** — the sync table becomes editable and no longer follows the source.

![](/aitable/data-connectors/data-connectors-overview/jiandaoyun/images/image_NRnOfkXqMV.png)
