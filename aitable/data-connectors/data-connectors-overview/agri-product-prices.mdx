## Prep: Aliyun account setup

1. Click the link from Lianzhuo Data to apply for an account: [https://market.aliyun.com/detail/cmapi00044839#sku=yuncode3883900001](https://market.aliyun.com/detail/cmapi00044839#sku=yuncode3883900001 "https://market.aliyun.com/detail/cmapi00044839#sku=yuncode3883900001")

2. Copy the AppCode.

## Open the Data sync center

In the AI Table bottom-left, click **Add / Import** → **Data sync center**.

## Pick a data source

Pick or search for **Agri-product price data**, click **Use** to enter the data sync settings.

## Data source settings

1. **Pick the data source**: only 1 source is available — selected by default.
2. **Account setup**: name is up to you; paste the App Code from Step 1.

3. **Parameters**: configure China admin region and agri-product L3 category — see the example list:

   [China admin regions (county-level) and agri-product L3 categories](/aitable/data-connectors/data-connectors-overview/agri-product-prices/cn-regions-and-categories)
4. **Fields**: select all / partial fields — flexibly scope the columns in the table. Primary keys can't be unchecked.
5. **Sync settings**: turn sync on / off. When on, pick **hourly** or **scheduled**:
   - **Hourly**: every 1 / 12 / 24 hours.
   - **Scheduled**: a fixed time point daily / weekly / monthly; configurable to skip holidays.

     Tip: if anything breaks during connector setup, use **Data source page → Submit feedback** to report it.

## Click Create to start syncing

Once the connector is configured, click **Create** to begin the sync. On success, a new sync table is auto-added.

## Post-sync operations

1. **Edit sync settings**

   For an existing sync table, click the icon on the right → **Data sync settings** to change synced fields, sync mechanism, or toggle auto-sync.
2. **Manual refresh**

   Open the sync table, click the ⋮ More icon next to the table name → **Refresh data** to manually refetch from the source and update.
3. **Detach the sync relationship**

   Click **Detach sync** — the sync table becomes editable and no longer follows the source.
