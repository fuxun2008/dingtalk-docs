## Prep: get the Access Token to set up the account

Steps to get the Access Token:

1. Open Qingflow → Plugin Center: [https://qingflow.com/center/plugin#3](https://qingflow.com/center/plugin#3 "https://qingflow.com/center/plugin#3"). Click **Third-party connector** → **OPEN API** → **Configure**.

   ![](/aitable/data-connectors/data-connectors-overview/qingflow/images/image_RIrpz5o4cS.png)

   ![](/aitable/data-connectors/data-connectors-overview/qingflow/images/image_zNtONDjpm9.png)
2. Get the Access Token: a super-admin Access Token has workspace-creator permission and can call all openAPI endpoints except `code登评论`. For sub-admin permission scope, click **Learn more** → see Qingflow's full config: [https://exiao.yuque.com/ixwxsb/bgzs0e/onnrnp9i7nihz5l8](https://exiao.yuque.com/ixwxsb/bgzs0e/onnrnp9i7nihz5l8 "https://exiao.yuque.com/ixwxsb/bgzs0e/onnrnp9i7nihz5l8").

   ![](/aitable/data-connectors/data-connectors-overview/qingflow/images/image_AQ8Ly769Z7.png)

## Open the Data sync center

In the AI Table bottom-left, click **Add / Import** → **Data sync center**.

![](/aitable/data-connectors/data-connectors-overview/qingflow/images/image_7GDJX22gfM.png)

Open the Data sync center.

![](/aitable/data-connectors/data-connectors-overview/qingflow/images/image_nC7xX4HUsy.png)

## Pick a data source

Pick or search for the **Qingflow** connector → click **Use** to enter connector setup.

![](/aitable/data-connectors/data-connectors-overview/qingflow/images/image_0G--q2S3EO.png)

## Data source settings

1. **Pick the data source**: only 1 source is available — selected by default.
2. **Account setup**: name is up to you; paste the Access Token from Step 1.

   ![](/aitable/data-connectors/data-connectors-overview/qingflow/images/image_1NxLUIlKTr.png)
3. **Fields**: select all / partial fields. Primary keys can't be unchecked.
4. **Sync settings**: turn sync on / off. When on, pick **hourly** or **scheduled**:
   - **Hourly**: every 1 / 12 / 24 hours.
   - **Scheduled**: a fixed time point daily / weekly / monthly; configurable to skip holidays.

     Tip: if anything breaks during connector setup, use **Data source page → Submit feedback** to report it.

![](/aitable/data-connectors/data-connectors-overview/qingflow/images/image_3ITBBayEJu.png)

## Click Create to start syncing

Once the connector is configured, click **Create** to begin the sync. On success, a new sync table is auto-added.

## Post-sync operations

1. **Edit sync settings**

   For an existing sync table, click the icon on the right → **Data sync settings** to change synced fields, sync mechanism, or toggle auto-sync.
2. **Manual refresh**

   Open the sync table, click the ⋮ More icon next to the table name → **Refresh data** to manually refetch from the source and update.
3. **Detach the sync relationship**

   Click **Detach sync** — the sync table becomes editable and no longer follows the source.
