## Prep: register and sign in to Aliyun

Before you start, make sure you have an Aliyun account.

1. Open Aliyun: [https://www.aliyun.com](https://www.aliyun.com "https://www.aliyun.com") — click **Sign in** in the top-right.

   ![](/aitable/data-connectors/data-connectors-overview/alibaba-cloud/images/image_vBlrWgQiwO.png)
2. Sign in with phone, Aliyun, Alipay, or DingTalk account.

   ![](/aitable/data-connectors/data-connectors-overview/alibaba-cloud/images/image_BZ1dz8Vs7v.png)

## Get an Aliyun AccessKey

### What is an AccessKey

The access key (AK for short) is the long-lived access credential Aliyun provides — a key pair of AccessKey ID + AccessKey Secret.

1. Click your avatar in the top-right; under **Permissions & security**, choose **AccessKey**.

   ![](/aitable/data-connectors/data-connectors-overview/alibaba-cloud/images/image_8PFtnVxQxr.png)
2. Recommended: use **RAM user + AccessKey** for the connection — avoid using your cloud account's key.
   > Since the primary account has overly broad permissions, in production avoid creating an AccessKey on the primary account — use a RAM user with the right permissions instead.
   > ![](/aitable/data-connectors/data-connectors-overview/alibaba-cloud/images/image_Plq55VzGmC.png)
3. In the left nav, pick **Identity management** → **Users**. If there's no user yet, click **Create user**.

   ![](/aitable/data-connectors/data-connectors-overview/alibaba-cloud/images/image_VkTfb8jVKg.png)
4. Click **Add permission** — grant the `AliyunRAMFullAccess` (RAM admin) system policy so the user can create and manage RAM-user AccessKeys; or grant at least OSS read-only — `AliyunOSSReadOnlyAccess`.

   ![](/aitable/data-connectors/data-connectors-overview/alibaba-cloud/images/image_IkOV9DT3Gf.png)

   ![](/aitable/data-connectors/data-connectors-overview/alibaba-cloud/images/image_Keb4jiBJEX.png)
5. After granting, find the target **RAM user** in the user list and click its name.

   ![](/aitable/data-connectors/data-connectors-overview/alibaba-cloud/images/image_khrGer3Huo.png)
6. Under **Authentication management** → **AccessKey**, click **Create AccessKey**.

   ![](/aitable/data-connectors/data-connectors-overview/alibaba-cloud/images/image_yWTMrOY6tt.png)

> Each RAM user can have up to 2 **AccessKeys**. Use one for normal access; create the second when rotating, to replace the old one.

1. In the dialog, read the AccessKey use cases & recommendations, and pick the better credential plan. Check **I confirm I must create an AccessKey**, then click **Continue**.

   ![](/aitable/data-connectors/data-connectors-overview/alibaba-cloud/images/image_LxGBJrWkrR.png)
2. In the Create AccessKey dialog, save the AccessKey ID and AccessKey Secret, then click **OK**. The AccessKey Secret is only shown at creation — keep it safe.

   ![](/aitable/data-connectors/data-connectors-overview/alibaba-cloud/images/image_URcHRmjYpB.png)

> Detailed AccessKey creation guide: [https://help.aliyun.com/en/ram/user-guide/create-an-accesskey-pair?spm=5176.2020520153.console-base_help.dexternal.2a9a336aqdUEYd#task-2245479](https://help.aliyun.com/en/ram/user-guide/create-an-accesskey-pair?spm=5176.2020520153.console-base_help.dexternal.2a9a336aqdUEYd#task-2245479 "https://help.aliyun.com/en/ram/user-guide/create-an-accesskey-pair?spm=5176.2020520153.console-base_help.dexternal.2a9a336aqdUEYd#task-2245479")
