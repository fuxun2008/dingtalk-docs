  Recommended: review the [Data sync center](/aitable/data-connectors/data-connectors-overview) first to understand connector basics, then proceed.

## Prep: link your Jinshuju account

1. Open the link, click to get your account info: [https://open.jinshuju.net/#/api_v1/authentication](https://open.jinshuju.net/#/api_v1/authentication "https://open.jinshuju.net/#/api_v1/authentication")

2. Enable API access.

3. Copy the **App Key** and **App Secret**. You need a paid upgrade or a Pro trial to enable API access.

## Open the Data sync center

In the AI Table bottom-left, click **Add / Import** → **Data sync center**.

Open the Data sync center.

## Pick a data source

Pick or search for the **Jinshuju** connector → click **Use** to enter connector setup.

## Data source settings

1. **Pick the data source**: only 1 source is available — selected by default.
2. **Account setup**: name is up to you; paste the API Key and API Secret prepped in Step 1.

3. **Fields**: select all / partial fields. Primary keys can't be unchecked.
4. **Sync settings**: turn sync on / off. When on, pick **hourly** or **scheduled**:
   - **Hourly**: every 1 / 12 / 24 hours.
   - **Scheduled**: a fixed time point daily / weekly / monthly; configurable to skip holidays.

     Tip: if anything breaks during connector setup, use **Data source page → Submit feedback** to report it.

## Click Create to start syncing

Once the connector is configured, click **Create** to begin the sync. On success, a new sync table is auto-added.

## Post-sync operations

- **Edit sync settings**

  For an existing sync table, click the icon on the right → **Data sync settings** to change synced fields, sync mechanism, or toggle auto-sync.
- **Manual refresh**

  Open the sync table, click the ⋮ More icon next to the table name → **Refresh data** to manually refetch from the source and update.
- **Detach the sync relationship**

  Click **Detach sync** — the sync table becomes editable and no longer follows the source.
