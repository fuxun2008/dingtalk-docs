---

AI Table supports the Aliyun Resource Management connector to sync **resource-tag data** under your Aliyun account — for unified management of cloud resources, tag taxonomies, and ownership info in AI Table.

This guide walks you through the full Aliyun → AI Table sync flow: account prep, key acquisition, parameter config, and field reference.

---
## 1. Prep

Before you start, confirm:

- A registered Aliyun account you can sign in to.
- The account has **Resource Management** enabled.
- The current account or a RAM sub-account has Resource-Management read-only permissions.
- You have AI Table access.

For account safety, **prefer a RAM sub-account + AccessKey** rather than primary-account keys.

---
## 2. Get AccessKey ID and AccessKey Secret

AI Table uses an AccessKey to call the Aliyun Resource Management API — create one in the Aliyun console first.

### Steps

1. Open Aliyun ([https://www.aliyun.com](https://www.aliyun.com "https://www.aliyun.com")) and sign in.
2. Open the **RAM (Access Control)** console.
3. In the left menu, click **Users** — create or pick an existing RAM user.
4. Grant the user Resource-Management read-only permissions.
5. Open that RAM user's **Authentication management** page and create an AccessKey.
6. Copy and securely save:
   - **AccessKey ID**
   - **AccessKey Secret**

> Note: AccessKey Secret is shown only once at creation — save it immediately.

---
## 3. Create the Aliyun Resource Management data source in AI Table

1. Open AI Table.
2. Click **Data sync center** at the top.
3. Search for **Aliyun**.
4. Pick the **Aliyun Resource Management** connector.

---
## 4. Data source settings

Currently supported data source type:

- **Resource tag list**

  Sync all cloud resources and their tag info under the current account.

Confirm and continue.

---
## 5. Account settings

Fill in your Aliyun account credentials:

- **Account name**: a custom label to distinguish multiple Aliyun accounts in AI Table.
- **AccessKey ID**: from the Aliyun console.
- **AccessKey Secret**: from the Aliyun console.

Click **OK** when done.

> AI Table encrypts AccessKey info at rest — used only for this data source's sync.

---
## 6. Parameters

### Endpoint / Region

Specifies which region's resource data to sync.

- Example: China North 1 (Qingdao).
- Resources in different regions sync separately.
- If your account spans multiple regions, create one data source per region.

---
## 7. Fields

Pick the fields you want to sync into AI Table.

### Currently supported

| Field | Description |
| --- | --- |
| Resource ARN | Globally unique cloud resource identifier |
| Tag key | Resource tag key |
| Tag value | Resource tag value |
| Tag type | Tag source type (system tag / custom tag etc.) |

You can:

- Check **Select all** to sync all fields.
- Or only check business-relevant fields — for resource categorization, ownership, or cost analysis.

---
## 8. Sync settings

- **Off (default)**

  Data updates only on creation or manual sync.
- **On**

  System auto-syncs latest resource-tag data on the configured cadence.

For frequent resource churn or tag-governance scenarios, turn on auto-sync.

---
## 9. Done — view data

1. Click **Create** in the bottom-right.
2. AI Table starts pulling Aliyun Resource Management data.
3. Once complete, view the resource tag list in AI Table.
4. Use cases:
   - Cloud resource inventory.
   - Tag-rule governance.
   - Resource ownership and cost analysis.

---
## 10. FAQ

### Sync fails or no-permission error — what do I do?

Confirm the RAM user has Resource-Management permissions, and double-check the AccessKey was entered correctly.

### Why are some resources missing?

Confirm the selected region is correct — resources in different regions need separate syncs.

### Is the AccessKey safe?

AI Table encrypts AccessKey info at rest — used only by this data source, never exposed externally.
