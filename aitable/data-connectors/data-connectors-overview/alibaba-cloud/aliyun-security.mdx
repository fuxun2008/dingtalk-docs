AI Table supports the **Aliyun Security Center connector** to sync **security alert data** under your Aliyun account — for unified management of cloud security risks, alert events, and handling status.

This guide walks you through:

- Sign in to the Aliyun console.
- Get AccessKey ID and AccessKey Secret.
- Create the Aliyun Security Center data source in AI Table.
- Configure parameters and fields, complete the sync.

## 1. Prep

Before you start, confirm:

- A registered Aliyun account you can sign in to.
- The account has **Security Center** enabled.
- The account has at least read-only Security Center permissions.
- You have AI Table access.

> ⚠️ Prefer a **RAM sub-account + AccessKey** rather than primary-account keys.

## 2. Get the Aliyun AccessKey

AI Table calls the Aliyun Security Center API via AccessKey — create one in the Aliyun console first.

### 1. Sign in to the Aliyun console

1. Open Aliyun: [https://www.aliyun.com](https://www.aliyun.com "https://www.aliyun.com").
2. Click **Sign in** in the top-right.
3. Sign in with your Aliyun account.

### 2. Create or get the AccessKey (RAM user recommended)

1. After sign-in, open **RAM (Access Control)**.
2. Pick **Users** in the left menu.
3. Create or pick an existing RAM user.
4. Grant Security Center permissions (at minimum read-only):
   - Example: Security Center read-only.
5. Open **Authentication management**.
6. Create an AccessKey.
7. Copy and save:
   - **AccessKey ID**
   - **AccessKey Secret**

> ⚠️ AccessKey Secret is only shown once at creation — save it.

## 3. Create the Aliyun Security Center data source in AI Table

### 1. Open the Data sync center

1. Open AI Table.
2. Click **Data sync center** at the top.
3. Search for **Aliyun**.
4. Pick **Aliyun Security Center**.

## 4. Data source settings

Currently supported data source type:

- **Alert list**

  Sync Security Center alert records under the current Aliyun account.

Pick it and continue.

## 5. Account settings

Link your Aliyun account.

### Field reference

| Field | Description |
| --- | --- |
| Account name | Custom label to distinguish multiple Aliyun accounts in AI Table |
| AccessKey ID | From the Aliyun console |
| AccessKey Secret | From the Aliyun console |

Click **Confirm** when done.

> 🔒 AI Table encrypts AccessKey info at rest — used only for this data source.

## 6. Parameters

### 1. Region (required)

Specifies the Security Center data region.

- Example: `Domestic regions`.
- Different regions correspond to different Security Center data scopes.

### 2. Start time (required)

The sync window's start point.

Options:

- Recent time.
- Specific time point.

### 3. Time range (required)

Sync time span for alerts.

- Example: last 7 days / last 30 days.
- Larger range = more data.

## 8. Sync settings

### Modes

- **Off (default)**

  Data updates only on creation or manual trigger.
- **On**

  System auto-syncs the latest alert data on the configured cadence.

> Recommended for security monitoring or on-call rotations.

## 9. Done — view data

1. Click **Create** in the bottom-right.
2. AI Table starts pulling Security Center alert data.
3. Once complete, view the alert list in AI Table.
4. Use the data for:
   - Security risk stats.
   - Alert tracking and handling.
   - Multi-account security analysis.

## 10. FAQ

#### Q1: Permission denied or sync failed?

- Confirm the RAM user has Security Center permissions.
- Check the AccessKey was entered correctly.

#### Q2: Why does the alert count differ from the console?

- Check the time range setting.
- Different regions have different alert data.

#### Q3: Is the AccessKey safe?

- AI Table encrypts AccessKey info at rest.
- Used only by this data source — never exposed externally.
