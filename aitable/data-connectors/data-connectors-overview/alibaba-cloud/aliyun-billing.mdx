title: "Sync Aliyun Billing data"
description: "Sync Aliyun Billing bill and order data to AI Table via the Data sync center — enabling cloud cost analysis, expense reconciliation, and finance management with a RAM sub-account AccessKey."
---

AI Table supports the **Aliyun Billing connector** to sync **bill data** and **order data** under your Aliyun account — for cost analysis, expense reconciliation, and finance management.

This guide walks you through:

- Sign in to the Aliyun console.
- Get AccessKey ID and AccessKey Secret.
- Create the Aliyun Billing data source in AI Table.
- Configure parameters and fields, complete the sync.

---
## Prep

Before you start, confirm:

- A registered Aliyun account you can sign in to.
- The account has Billing / Bill service enabled.
- The account has at least read-only Billing permissions.
- You have AI Table access.

> ⚠️ Prefer a **RAM sub-account + AccessKey** rather than primary-account keys.

---
## Get the Aliyun AccessKey

AI Table calls the Aliyun Billing API via AccessKey — create one in the Aliyun console first.

For details, see **Aliyun official services**.

### 1. Sign in to the Aliyun console

1. Open Aliyun: [https://www.aliyun.com](https://www.aliyun.com "https://www.aliyun.com").
2. Click **Sign in** in the top-right.
3. Sign in with your Aliyun account.

---
### 2. Create or get the AccessKey (RAM user recommended)

1. After sign-in, open **RAM (Access Control)**.
2. Pick **Users** in the left menu.
3. Create or pick an existing RAM user.
4. Grant Billing permissions (read-only is enough):
   - Example: `AliyunBSSOpenApiReadOnlyAccess`.
5. Open **Authentication management**.
6. Create an AccessKey.
7. Copy and save:
   - **AccessKey ID**
   - **AccessKey Secret**

> ⚠️ AccessKey Secret is only shown once at creation — save it.

---
## Create the Aliyun Billing data source in AI Table

### 1. Open the Data sync center

1. Open AI Table.
2. Click **Data sync center** in the bottom-left.
3. Search for **Aliyun**.
4. Pick **Aliyun Billing**.

---
## Data source settings

In **Data source**, pick the data type to sync:

### Supported data source types

- **Aliyun Billing · Bill list**

  Sync account-level bill detail data.
- **Aliyun Billing · Order list**

  Sync order info under the account (new purchase, renewal, upgrade, etc.).

Each data source must be created separately.

---
## Account settings

Link your Aliyun account.

### Field reference

| Field | Description |
| --- | --- |
| Account name | Custom label to distinguish multiple Aliyun accounts |
| AccessKey ID | From the Aliyun console |
| AccessKey Secret | From the Aliyun console |

Click **Confirm** when done.

> 🔒 AI Table encrypts AccessKey info at rest — used only for this data source.

---
## Parameters

### 1. Endpoint / Region (required)

Specifies the billing data site.

- Example: `China`.
- Different regions correspond to different bill and order data.

---
### 2. Billing period / Time range (required)

Specifies the sync window for billing data.

#### Bill list common config

- Period format: `YYYY-MM`.

  Example: `2025-12`.
- Pick a single billing month.

#### Order list common config

- Time range type: recent / specific.
- Example: last 7 days, last 30 days.

---
### 3. Bill / Order type (optional)

Filter by data type.

#### Common order types

- New purchase (New).
- Renewal (Renew).
- Upgrade (Upgrade).
- Downgrade (Downgrade).
- Refund (Refund).
- Convert (Convert).
- Change OS (ChangeOperatingSystem).

---
### 4. Payment status (optional)

Filter orders or bills by payment status.

---

- Check **Select all** to sync all fields.

---
## Sync settings

### Modes

- **Off (default)**

  Data updates only on creation or manual refresh.
- **On**

  System auto-syncs the latest billing data on the configured cadence.

> Recommended for monthly reconciliation or cost monitoring.

---
## Done — view data

1. Click **Create** in the bottom-right.
2. AI Table starts pulling Aliyun Billing data.
3. Once complete, view the bill or order list in AI Table.
4. Use the data for:
   - Cost analysis.
   - Finance reconciliation.
   - Cloud resource cost breakdown and stats.

---
## FAQ

#### Q1: Permission denied or sync failed?

- Confirm the RAM user has Billing permissions.
- Check the AccessKey was entered correctly.

#### Q2: Bill amount differs from the console?

- Check the billing period setting.
- Different APIs return either detail or summary bills.

#### Q3: Is the AccessKey safe?

- AI Table encrypts AccessKey info at rest.
- Used only by this data source — never exposed externally.
