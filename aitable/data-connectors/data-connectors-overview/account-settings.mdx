## Find the data source to connect

1. In the AI Table bottom-left, click **+ Add / Import**.
2. Pick **Data sync center** to enter.
3. Pick the data source you want.

![](/aitable/data-connectors/data-connectors-overview/account-settings/images/2025-09-17%2020.49.06_MSRylEIn_W.gif)

## Configure the data source

1. **Pick the data source**: only 1 source is available — selected by default.
2. **Account setup**: name is up to you; add the prepped Aliyun App Code.
3. **Parameters**: some connectors need params — e.g. for **Weather forecast**, specify the province / municipality and city.
4. **Fields**: select all / partial fields. The primary field[^note1] can't be unchecked.
5. **Sync settings**: turn sync on / off. When on, pick **hourly** or **scheduled**:
   - **Hourly**: every 1 / 12 / 24 hours.
   - **Scheduled**: a fixed time point daily / weekly / monthly; configurable to skip holidays.
6. Click **Create** to finish data-source configuration. A new sync table is auto-added immediately.

## Post-sync operations

- **Edit sync settings**

  For an existing sync table, click the icon on the right → **Data sync settings** to change synced fields, sync mechanism, or toggle auto-sync.
- **Manual refresh**

  Open the sync table, click the ⋮ More icon next to the table name → **Refresh data** to manually refetch from the source and update.
- **Detach the sync relationship**

  Click **Detach sync** — the sync table becomes editable and no longer follows the source.

![](/aitable/data-connectors/data-connectors-overview/account-settings/images/image_92wVrrUvFp.png)

[^note1]: The first column of an AI Table is called the **primary field** — it can't be deleted or hidden.
