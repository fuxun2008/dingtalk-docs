  Recommended: review the [Data sync center](/aitable/data-connectors/data-connectors-overview) first to understand connector basics, then proceed.

⚠️ Only public-cloud Teambition is supported. Privately-deployed Teambition can't be synced for now.

⚠️ The AI Table's owning organization must be the same as the project's organization — otherwise the Teambition account login can't reach your configured project, and you'll see "invalid account, auth failed".

## Prep: get the project ID

1. In the DingTalk desktop sidebar bottom, click **More** → **Add more apps**.

   ![](/aitable/data-connectors/data-connectors-overview/teambition/images/image_g7cNuvH6hg.png)
2. In the Business digitalization area, find Project — click to add Teambition to the DingTalk sidebar.

   ![](/aitable/data-connectors/data-connectors-overview/teambition/images/image_quUvRO88me.png)
3. Open Teambition, create a new project, open its view. In the top-right of the page, click **Menu** → **Copy link**.

   ![](/aitable/data-connectors/data-connectors-overview/teambition/images/image_ZWmb5ZOm-D.png)
4. From the copied link, take the project ID after `project/`.

   ![](/aitable/data-connectors/data-connectors-overview/teambition/images/image_Uy4_8FeRah.png)

## Open the Data sync center

In the AI Table bottom-left, click **Add / Import** → **Data sync center**.

![](/aitable/data-connectors/data-connectors-overview/teambition/images/image_hm_BtRGD9P.png)

## Pick a data source

Pick or search for the **Teambition** connector → click **Use** to enter the data source settings.

![](/aitable/data-connectors/data-connectors-overview/teambition/images/image_C0VpBIrIWX.png)

## Data source settings

![](/aitable/data-connectors/data-connectors-overview/teambition/images/image_QD_2KAtzwD.png)

1. **Pick the data source**: only 1 source is available — selected by default.
2. **Account setup**: name is up to you; paste the project ID prepped in Step 1.
3. **Fields**: select all / partial fields. Primary keys can't be unchecked.
4. **Sync settings**: turn sync on / off. When on, pick **hourly** or **scheduled**:

   ![](/aitable/data-connectors/data-connectors-overview/teambition/images/image_OlVSVUfnuE.png)
   - **Hourly**: every 1 / 12 / 24 hours.
   - **Scheduled**: a fixed time point daily / weekly / monthly; configurable to skip holidays.

     Tip: if anything breaks during connector setup, use **Data source page → Submit feedback** to report it.

## Click Create to start syncing

Once the connector is configured, click **Create** to begin the sync. On success, a new sync table is auto-added.

![](/aitable/data-connectors/data-connectors-overview/teambition/images/image_Utf0z6n8QL.png)

## Post-sync operations

- **Edit sync settings**

  For an existing sync table, click the icon on the right → **Data sync settings** to change synced fields, sync mechanism, or toggle auto-sync.
- **Manual refresh**

  Open the sync table, click the ⋮ More icon next to the table name → **Refresh data** to manually refetch from the source and update.
- **Detach the sync relationship**

  Click **Detach sync** — the sync table becomes editable and no longer follows the source.

![](/aitable/data-connectors/data-connectors-overview/teambition/images/image_nVA8EP4pyG.png)
