## Prep

Before using this connector, enable an API account in the TAPD **Company management** backend, and get one set of **API account** + **API secret**, plus the **project ID** of the project you want to sync — to authorize AI Table to read your TAPD data.

> 📌 The TAPD API is a TAPD commercial module — only available in **TAPD Enterprise**. **Company admins** can apply for a 90-day trial under **Company management → Open integration → API account management**.

1. Apply for and view the API account / API secret. Sign in to TAPD as a company admin → **Company management → Open integration → API account management** → apply and enable. Once enabled, you can view the org's **API account** and **API secret**.

![](/aitable/data-connectors/data-connectors-overview/tapd/images/截屏2026-05-08%2021.24.10_kI1xgTe6g2.png)

> 📌 **Note**: API account and API secret can access all the org's project data — keep them safe and don't leak them. To revoke, reset the API secret in **API account management**; the original secret takes effect immediately upon reset.

1. Get the project ID. Each data-source sync task needs a **project ID** to tell the connector which project space to sync from. Sign in to TAPD → open the matching project space → top-right **Settings → Basic info → Project info** to view the project ID.

> 📌 One data source supports only one project ID. To sync data from multiple projects, repeat the data-source creation.

## Pick a data source

In AI Table → **Data sync center** → search for **TAPD** → click **Use** to enter connector setup.

![](/aitable/data-connectors/data-connectors-overview/tapd/images/截屏2026-05-09%2010.42.01_JBHpZsE2mr.png)

## Data source settings

1. **Link the TAPD account**: on first use, click **Link account** → fill API account + API secret in the dialog.

![](/aitable/data-connectors/data-connectors-overview/tapd/images/截屏2026-05-08%2021.45.47_qRTdh2bslW.png)

After filling, click **OK** — account info is saved in the current data source. Later, you can **switch accounts** or **edit account info** from the account card on the data source page.

1. **Pick the data table to sync**: each data-source config supports only one table. To sync multiple tables, repeat the data-source creation. Currently supported tables:

| Data table | Description |
| --- | --- |
| TAPD Iteration list | Sync all iterations in a given project that match the query |
| TAPD Bug list | Sync all bugs in a given project that match the query |
| TAPD Story list | Sync all stories in a given project that match the query |
| TAPD Task list | Sync all tasks in a given project that match the query |

After picking a table, the connector auto-loads its config. Pick the data scope you want to fetch.

1. **Fields**: pick the fields you want to sync — primary keys are checked by default and can't be unchecked.

## Click Create to start syncing

After the above, click **Save & Sync** — the connector starts syncing.

![](/aitable/data-connectors/data-connectors-overview/tapd/images/截屏2026-05-08%2021.50.22_3N1KyHauux.png)

## Done — view your data

Once sync completes, the new table shows up in the AI Table left sidebar. It exists as a "sync table" — supported follow-ups:

- **Edit sync settings**

  In the data table's right-side More menu, pick **Data sync settings** to adjust the field selection and sync params.
- **Manual refresh**

  In the data table's right-side More menu, click **Refresh data** — the connector immediately re-calls the TAPD API and refreshes the current table.
- **Detach the sync relationship**

  In the data table's right-side More menu, click **Detach sync** — the sync table becomes a regular editable table, no longer following the TAPD source.
- **Add custom fields**

  Without affecting synced fields, you can add custom fields in AI Table (notes, tags, AI fields, etc.) — custom fields aren't overwritten by sync.
