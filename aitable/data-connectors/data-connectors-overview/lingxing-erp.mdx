## Prep

Before using this connector, enable the open API in the Lingxing ERP backend, and get one set of **App ID** + **App Secret** to authorize AI Table to read your Lingxing data.

1. Sign in to Lingxing ERP as a super admin → **Settings → Business config → Basics → Open API**.

> If the "Open API" entry isn't shown under Business config, contact Lingxing support to enable open-platform permission for your account.

> 📌 First-time use of the open API: sign in as a super admin to **Open API** — you need to provide a backup email to receive notifications about open-API releases from Lingxing.

1. View the org's AppID and AppSecret. Add them under **API account management**.

> 📌 **Note**: this App ID + App Secret can access all the org's data — handle with care, don't leak. To revoke, click **Reset** to invalidate and generate a new auth code, or limit the auth code's validity.

1. Revoke / reset credentials.

To revoke an existing AppSecret (e.g., when a user leaves), sign in to Lingxing ERP as a super admin → **Settings → Business config → Basics → Open API → API account management** → click **Reset** for the AppSecret. The original AppSecret is invalidated immediately when a new one is generated; or click Disable to block the current App ID + AppSecret from accessing data. After reset, also update the account info in AI Table with the new App ID + AppSecret.

## Pick a data source

In AI Table → **Data sync center** → search for **Lingxing ERP** → click **Use** to enter connector setup.

## Data source settings

1. **Link the Lingxing account**: on first use, click **Link account** → fill App ID + App Secret in the dialog:

After filling, click **OK** — account info is saved in the current data source. Later, you can **switch accounts** or **edit account info** from the account card on the data source page.

1. **Pick the data table to sync**: each data-source config supports only one table. To sync multiple tables, repeat the data-source creation. Currently supported tables:

| Data table | Description | Lingxing ERP source |

| Multi-platform sales statistics | Sync sales / order count / revenue — daily / weekly / monthly / yearly aggregation | Stats → Sales analytics → Sales statistics |
| MSKU-level product performance | Sync MSKU-level sales, revenue, gross profit, etc. | Stats → Sales analytics → Product performance |
| ASIN-level product performance | Sync ASIN-level sales, revenue, gross profit, etc. | Stats → Sales analytics → Product performance |
| MSKU-level order profit | Sync MSKU-level order profit, including revenue, gross profit, ad spend | Stats → Profit stats → Order profit |
| Settlement center — settlement summary | Sync Amazon settlement center summary data — sales, refunds, expenses, transfers | Finance → Financial settlement → Settlement center |
| Settlement center — transaction details | Sync Amazon settlement center transaction details — filterable by source | Finance → Financial settlement → Settlement center |
| MSKU-level profit report | Sync MSKU-level profit report — revenue, ad costs, storage fees, gross profit | Finance → Financial reports → Profit report |
| Warehouse inventory details | Sync local / overseas warehouse inventory — qty, cost, age | Warehouse → Inventory → Inventory details |
| FBA inventory list | Sync FBA inventory — sellable, in-transit, age, cost | Warehouse → Inventory → FBA inventory details |
| FBA shipment list | Sync FBA shipments — status, item details, address | FBA → Shipments → FBA shipments |

After picking a table, the connector auto-loads its config. Pick the data scope you want to fetch.

1. **Business parameter settings**: required parameters differ per table. Common ones:
   - **Stats date range**: for tables with a time dimension (sales, profit, orders). Two modes — "natural-day range" and "rolling last-N-days range" (the latter auto-shifts the range each sync to today).
   - **Shop filter**: pick one or more authorized Lingxing shops to sync only their data; leave empty to sync all authorized shops on this account.
2. **Fields**: click **Next** — the field list for the selected table loads. Pick fields to sync — primary keys are checked by default and can't be unchecked.

## Click Create to start syncing

After the above, click **Save & Sync** — the connector starts syncing.

## Done — view your data

Once sync completes, the new table shows up in the AI Table left sidebar. It exists as a "sync table" — supported follow-ups:

- **Edit sync settings**

  In the data table's right-side More menu, pick **Data sync settings** to adjust the field selection and sync params.
- **Manual refresh**

  In the data table's right-side More menu, click **Refresh data** — the connector immediately re-calls the Lingxing API and refreshes the current table.
- **Detach the sync relationship**

  In the data table's right-side More menu, click **Detach sync** — the sync table becomes a regular editable table, no longer following the Lingxing source.
- **Add custom fields**

  Without affecting synced fields, you can add custom fields in AI Table (notes, tags, AI fields, etc.) — custom fields aren't overwritten by sync.

## FAQ

### Q1. I can't find the "Open API" entry in the Lingxing ERP backend.

"Open API" is part of Lingxing's open-platform capabilities — sign in with the **super admin account** and look under **Settings → Business config → Basics**. If it's still missing, contact Lingxing to confirm whether your org has open-platform permission enabled.

### Q2. I get an "AppID or AppSecret invalid" error.

Check in this order:

1. Confirm AppID and AppSecret are from the **same org's** open API backend → **API info**, and haven't been reset.
2. Confirm the credentials weren't pasted with stray spaces, newlines, or other invisible characters.
3. Confirm the connector service's **egress IP** has been added to Lingxing's IP allowlist (contact AI Table official support to resolve).
