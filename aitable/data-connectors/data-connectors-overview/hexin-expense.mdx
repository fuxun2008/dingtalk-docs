  Recommended: review the Data sync center first to understand connector basics, then proceed.

## Prep

Before using this connector, enable the open API in the Hexin Expense backend, and get one set of **App Key** + **App Security** to authorize AI Table to read Hexin Expense data.

1. Sign in to the Hexin Expense (formerly Yikuaibao) backend → **App Center → App Store → search "Open API (new)"** → pick the matching item.

1. Open the Open API (new) detail page → click **Item config** to get the org's **App Key** (access account) and **App Security** (access password).

> 📌 **Note**: App Key and App Security can access all the org's data — keep them safe and don't leak them. To revoke, **disable** under **Open API (new)**; the existing App Key and App Security take effect immediately upon disabling.

1. Revoke / reset credentials.

   To revoke an existing App Key + App Security (e.g., when a user leaves), an admin can go to **App Center → App Store → Open API (new) → Item config** and click **Disable**. The existing App Key and App Security take effect immediately upon disabling. Once disabled, you can create a new key — also update the account info in AI Table with the new App Key + App Security.

> 📌 For details on the open API, see the [Hexin Open Platform official docs](https://docs.ekuaibao.com/docs/open-api/getting-started/question-answer "Hexin Open Platform official docs").

## Pick a data source

In AI Table → **Data sync center** → search for **Hexin Expense** → click **Use** to enter connector setup.

## Data source settings

1. **Link the Hexin Expense account**: on first use, click **Link account** → fill App Key + App Security in the dialog:

After filling, click **OK** — account info is saved in the current data source. Later, you can **switch accounts** or **edit account info** from the account card on the data source page.

1. **Pick the data table to sync**: each data-source config supports only one table. To sync multiple tables, repeat the data-source creation. Currently supported tables:

| Data table | Description |
| --- | --- |
| Hexin Expense — Budget bag list | Sync budget-bag info |
| Hexin Expense — Reimbursement records | Sync reimbursement records and amounts |
| Hexin Expense — Loan record list | Sync loan record info |
| Hexin Expense — Application list | Sync application record info |

After picking a table, the connector auto-loads its config. Pick the data scope you want to fetch.

1. **Fields**: after picking a table, the connector loads its field list. Pick the fields you want to sync — primary keys are checked by default and can't be unchecked.

## Click Create to start syncing

After the above, click **Save & Sync** — the connector starts syncing.

## Done — view your data

Once sync completes, the new table shows up in the AI Table left sidebar. It exists as a "sync table" — supported follow-ups:

- **Edit sync settings**

  In the data table's right-side More menu, pick **Data sync settings** to adjust the field selection and sync params.
- **Manual refresh**

  In the data table's right-side More menu, click **Refresh data** — the connector immediately re-calls the Hexin Expense API and refreshes the current table.
- **Detach the sync relationship**

  In the data table's right-side More menu, click **Detach sync** — the sync table becomes a regular editable table, no longer following the Hexin Expense source.
- **Add custom fields**

  Without affecting synced fields, you can add custom fields in AI Table (notes, tags, AI fields, etc.) — custom fields aren't overwritten by sync.
