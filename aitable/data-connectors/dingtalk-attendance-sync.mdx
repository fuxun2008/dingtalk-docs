## Overview

- The Attendance **daily statistics report** can be synced into AI Table via the AI Table Data sync center, with real-time updates: manual refresh + hourly auto-sync.
- Imported fields can't be edited, but you can still add custom fields. On top, you can use AI Table's automation, advanced permissions, dashboards, etc.
- If you need to freely edit the sync table, you can detach sync at any time, or duplicate the sync table — the duplicate has no relationship to the source.

## Common scenarios

- Help managers track team attendance in real time and improve people management efficiency. Sync attendance records, leave info, absence data, etc.; combined with AI Table dashboards, data analytics, and automation — apply to anomaly tracking, attendance-rate analysis, performance scoring, etc.

## Sync Attendance data

1. In the AI Table left sidebar bottom, click **+ Add / Import** → pick **Data sync center**.

2. Pick the data source: pick or search for the **Attendance** connector → click **Use** to enter setup.

3. Data source settings — sync attendance data by attendance group.

   1. **Pick the data source**: only 1 source is available — selected by default.
   2. **Parameters**
      1. Supported member filter: sync by attendance group — pick one or more groups.
      2. Set the sync time range — two modes.
         Note: both manual and auto updates currently support pulling only the last 1 year of data; longer ranges are on the roadmap.
         | **Mode** | **Supported range** | **Description** |
         | --- | --- | --- |
         | Time period (note: both manual and auto updates currently only pull last 1 year of data) | Start date — End date | **In auto-update, the system uses the current date to decide whether to update. If the current date is past the end date, sync auto-stops. To keep auto-updating, manually adjust the range or remove the end time.** |
         |  | Start date — No end date | Without an end date, auto-update doesn't stop, but only the last 1 year is pulled by default. |
         | Recent | Last 7 days / Last 30 days / Last year | Auto-syncs the recent range — **historical data outside the range is auto-cleared**. |
   3. **Fields**: select all / partial fields to sync from the source. If select-all, newly added source fields auto-sync into the table.
   4. **Sync settings**: pick which fields to sync and whether to auto-sync hourly. Click Save & Sync when done.
4. **Create** config: click Create — a sync table named after the attendance group is auto-added, with a lightning badge.

Sync rules

| **Role of the user creating the sync** | **Syncable data scope** |
| --- | --- |
| Member of the attendance group | Only your own attendance data |
| Primary admin | All attendance data in the org; can see all attendance groups |
| Department head + sub-admin authorized  Note: the manageable scope must be set   | Attendance data of manageable members in the group. Manageable members: the people range you manage as department head, plus yourself. |
| Has manage permission for the attendance group | **As long as the manageable scope includes any member of the group, you can sync the entire group's attendance data** |
| Primary owner / sub-owner of the attendance group (set in the group config) | Attendance data of all members in the manageable group |

#### Permission changes after sync is created

If the creator of an existing attendance sync loses manage permission, sync is terminated immediately and a sync-error notification is shown — please re-create the sync with another user who has attendance manage permission.

### How to set Attendance permissions for AI Table sync

[DingTalk admin console](https://oa.dingtalk.io/index.htm#/welcome "DingTalk admin console")

1. Set as **primary admin**: Security & permissions → Permission management → Primary admin → Add primary admin

1. Set **manage permission for the attendance group**: Security & permissions → Permission management → Sub-admin → Add sub-admin / management group → Manageable scope

## Manage data sync

After clicking **Save & Sync**, the selected source view shows up as a data table in the AI Table left nav.

Synced tables carry a **lightning badge** — you can rename them. You can also **duplicate** / **delete** the table, and add fields to meet your data management needs. Note: synced fields also carry the lightning badge — their content can't be edited directly in AI Table, the field type can't be changed, and these fields can't be deleted.

**Note:** if you duplicate the sync table, the duplicate becomes a regular table — its content is freely editable, but it no longer has any sync relationship to the source. To **edit sync settings**, open the synced table → click the **More** icon next to the table name → click **Data sync settings**. To **manually sync data**, click **Refresh data** for a manual sync.

## Detach the sync relationship

Click **Detach sync** — the table becomes a regular table and keeps its existing data. This action can't be undone.

Note: you need **manage permission** on the sync table to find the detach entry and successfully detach.

## FAQ

#### Q: To sync an attendance group's data into AI Table, what permissions do I need?

A:

To successfully sync an attendance group's data, you need any one of:

- Be a member of the group — only your own data syncs.
- Be a **primary admin** — all org attendance data syncs.
- Be a **sub-admin** whose manageable scope includes any member of the group — all group members' data syncs.

#### Q: Why did data suddenly stop auto-updating?

A:

First check the sync settings:

- Possibility 1: **End date set**, and the current date is past it. Sync auto-stops in this case.
- Possibility 2: **No end date**, but the sync range exceeds 1 year. Currently auto-sync only supports **last 1 year of data** — anything beyond won't auto-update.

#### Q: Why is my historical data gone?

A: If sync settings use **Recent** (last 7 / 30 / 365 days), **history older than the range is auto-cleared** — only the recent data is kept.

#### Q: Does deleting the data source affect sync?

A: After deleting the data source, already-synced data is retained, but no further sync.

#### **Q: Is there a row-count limit for attendance data sync?**

A: Yes — up to 20,000 rows. One AI Table can have at most 100 data tables.

#### Q: Can I edit the synced data?

A: No — read-only. You can't edit, delete, or add records, nor create a form view.
