## What is the Data sync center

- The AI Table Data sync center provides a variety of data sources to bridge data between systems and sync into AI Table.
- Each connector can periodically auto-pull data from the source on a configured cadence into an AI Table data table. You can also trigger a manual sync.
- Data sync center:
  - DingTalk products: sync from other AI Tables, DingTalk Spreadsheet, OA Approval, Attendance, Contacts, AI Minutes, Todos, etc.
  - Databases: bridge other database tables — MySQL, etc.
  - Third-party sources: bridge external data via APIs — weather, ERP (Kingdee, Jushuitan, etc.), e-commerce platforms (Business Advisor, Taobao, JD, etc.), business systems (OA, BI, CRM, etc.).
  - Custom connector: formerly the custom-sync app — orgs can define their own data source to sync internal-system data into AI Table.

## Data sync operations

### Create a sync

Pick a connector — for example, **Sync from another AI Table** — click **Use** to open the connector setup page.

1. Pick the data source: only 1 source is available — selected by default.
2. Parameters: pick the AI Table data table view to sync. Other connectors may not need this.
3. Fields:
   - All fields — newly added source fields auto-sync.
   - Specific fields — pick what you need.
4. Sync settings: turn sync on / off. Currently **hourly sync** is supported; **more flexible scheduling is rolling out**. Two modes — hourly or scheduled:
   - **Hourly**: every 1 / 12 / 24 hours.
   - **Scheduled**: a fixed time point daily / weekly / monthly; configurable to skip holidays.

### Sync auto-creates a data table

Once synced, a data table (the "sync table") is auto-created. You can keep using AI Table's views, dashboards, automation, workflows, etc., but synced fields aren't editable.

1. Add fields / columns: extend the synced fields with reference / link / formula columns.
2. Synced fields / columns / records can't be modified, added, or deleted.

### Edit sync settings

Open the synced table → click the ⋮ More icon next to the table name → **Data sync settings**.

You can change synced fields and sync mechanism, and turn auto-sync on / off.

Note: AI Table, DingTalk Spreadsheet, OA Approval, Attendance, and Business Advisor — these 5 DingTalk first-party sources currently support hourly sync only; **fixed-time scheduling is rolling out**. Other first-party sources already support it.

### Manual refresh

Open the synced table → click the ⋮ More icon next to the table name → **Refresh data** triggers a manual sync — re-fetches from the source and updates the current table.

### Detach the sync relationship

Click **Detach sync** — the sync table becomes editable and no longer follows the source.

## Using third-party data sources

### Prep: link the data-source account

Connectors can link third-party API accounts — currently Aliyun, Jinshuju, Jiandaoyun, etc. — to fetch data via API.

### Open the Data sync center

1. In the AI Table bottom-left, click **Add / Import**.
2. Pick **Data sync center** to enter the connector center.
3. Pick the data source you want.

### Configure the data source

1. Pick the data source: only 1 source is available — selected by default.
2. Account: customize an account name and add your prepared Aliyun App Code.
3. Parameters: some connectors require parameters — e.g., **Weather forecast** needs province / city.
4. Fields: select all / partial fields. The primary field can't be unchecked.
5. Sync settings: turn sync on / off. When on — hourly or scheduled:
   - **Hourly**: every 1 / 12 / 24 hours.
   - **Scheduled**: a fixed time point daily / weekly / monthly; configurable to skip holidays.
6. Click **Create** — config is done; a sync table is added immediately.

### Org-shared data source

Use the org-shared data source feature to publish AI Table data tables as the org's source of truth. Other users in the org can sync the source to their own AI Tables for use and analysis — improving data flow within the org. Click to view [Org-shared data source](/aitable/data-connectors/org-shared-source).

### FAQ

- **Q: Can I create an internet-wide shared AI Table data source and publish it to the Data sync center?**

  A: Yes — very welcome. See the [**AI Table data source dev guide**](https://docs.dingtalk.io/i/nodes/1OQX0akWmBejogd0TAlmRyQGVGlDd3mE "AI Table data source dev guide") for details, and contact us.
- **Q: Can I sync data from internal-org apps to AI Table?**

  A: Yes — you'll need a custom connector. See the [**AI Table data source dev guide**](https://docs.dingtalk.io/i/nodes/1OQX0akWmBejogd0TAlmRyQGVGlDd3mE "AI Table data source dev guide") and use the [**AI in-org publish guide**](https://docs.dingtalk.io/i/nodes/vNG4YZ7JnpyN1Mo0uEKQXpb2W2LD0oRE "AI in-org publish guide") to publish a data-source plugin.
