## Overview

Org admins can set the **third-party plugin permission** for the AI Table plugin center. With it on, AI Table managers and editors can use third-party plugins from the plugin center for a wide range of business scenarios.

## Turn the permission on

Sign in to the admin console at [https://oa.dingtalk.io/](https://oa.dingtalk.io/ "https://oa.dingtalk.io/") and go to **Doc & Storage Management > Permissions & Security > Permission Settings**. Click **Edit**, check **Enable AI Table plugin permission**, and save.

Once enabled, members of the org can use third-party plugins in the AI Table plugin center. Third-party plugins can read and write AI Table data via the server-side API.
