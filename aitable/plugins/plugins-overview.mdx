## Overview

AI Table's plugin center is flexible and convenient. **A rich plugin library** covers the long-tail needs of every team — batch attachment uploads, find-and-replace, deduplication, and more.

The plugin platform is open: developers with code chops can build **script plugins** and **custom plugins** tailored to their own needs. With plugins, AI Table can do almost anything.

## How to use plugins

Open an AI Table and click the **Plugins** icon at the top-right. The right side panel shows **featured** plugins; click **Plugin Market** at the bottom to browse the full catalog.

![](https://img.alicdn.com/imgextra/i2/O1CN01sF6In61fMqdQu4R3V_!!6000000003993-2-tps-1836-1016.png)


![](https://img.alicdn.com/imgextra/i4/O1CN01wZY2N529KV4tzGLib_!!6000000008049-2-tps-1836-1016.png)


### Using a plugin

For example: you want to bulk-upload résumé attachments to a Resume Library AI Table. Find a batch-upload plugin in the plugin center to speed it up.

1. Click the **Plugins** button at the top-right > plugin list, then click **Plugin Market** at the bottom.
2. Search **batch upload** to find the plugin you want.

![](https://img.alicdn.com/imgextra/i4/O1CN01eFBjN31OHwvmR8cbO_!!6000000001681-2-tps-1836-1016.png)

3. Hover over the plugin and click **View** (or click the empty area) to read the plugin's full intro.
4. Hover over the plugin and click **Use**. The configuration panel opens in the right side panel.

### Sharing a plugin

1. **Recommend it**: in step 3 above, while viewing the plugin's intro, click **Share** to copy a plugin link to send to teammates.

![](https://img.alicdn.com/imgextra/i3/O1CN01ZeiUfN1HV2wjTcGee_!!6000000000762-2-tps-1836-1016.png)

2. **The recipient**: open the link 🔗 in a browser, click **Try in DingTalk AI Table**, and the plugin opens in a sample template you can play with.

### Pin a plugin

For plugins you use often in this AI Table, pin them to the right side panel for quick access. Hover and click the pin icon.

![](https://img.alicdn.com/imgextra/i4/O1CN01yJn1FD1bsDIOuV3h5_!!6000000003520-2-tps-1836-1016.png)


### Remove a plugin

In the **Used** list, click **More > Remove from list** on the right of a plugin to remove it. To use it again, you'll need to enable it again.

![](https://img.alicdn.com/imgextra/i1/O1CN01M97GUc1JVcfzRNl9F_!!6000000001034-2-tps-1836-1016.png)


## Plugin permissions

When Advanced Permissions is **off**: anyone with **Edit** or **Manage** can use plugins.

When Advanced Permissions is **on**: only users with table-level **Manage** can use plugins.
