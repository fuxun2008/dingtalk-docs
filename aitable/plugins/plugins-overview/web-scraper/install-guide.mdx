Download the extension to your machine and **unzip it into a folder**.

#### Step 2 — Install in Your Browser

Install in Chrome:

| Step |
| --- |
| 1. Open Chrome, paste `chrome://extensions/` into the address bar and press Enter to open the extensions page — **or** click the **Extensions** button to open it. |
| 2. Toggle **Developer mode** at the top-right. |
| 3. Drag the **unzipped Fusion folder** onto the Chrome extensions page. |
| 4. Find the new Fusion extension and **make sure it's enabled**. |
| 5. Once installed, **refresh** AI Table > open the side panel > search or open Web Scraper from the plugin center. The first time you scrape, sign in with your DingTalk account. |

Install in Edge:

| Step |
| --- |
| 1. Open Edge, click the **⋯** menu at the top-right and choose **Extensions**. |
| 2. Click **Manage extensions**. |
| 3. On the extensions management page, turn on **Developer mode**. |
| 4. Drag the unzipped **Fusion folder** into the browser window. |
| 5. From the extensions popup in the browser toolbar, click **Fusion** to open the Fusion side panel. |
| 6. Sign in with DingTalk. Once signed in, return to AI Table and enable Web Scraper. |
