title: "Rich Text"
description: "Store mixed content — images, links, and formatted text — in a single cell."
---

The AI Table **Rich text** field stores mixed content: images, links, and formatted text. Use it when a plain text field cannot represent the content you need.

## Add a Rich Text Field

1. Click **+** in the upper-right of the title bar.
2. Pick **Rich text**.

## When to Use

- Long-form notes with headings, bold, and lists.
- Cells that need inline images alongside text.
- Reference links to external resources.

For records that combine free-form sections, tables, and large attachments, consider [Table as doc](/aitable/fields/field-types/table-as-doc) instead.
