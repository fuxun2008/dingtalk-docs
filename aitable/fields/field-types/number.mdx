Use the AI Table **Number** field to store any numeric value — quantity, sales volume, attendance days, etc.

## Add a Number Field

1. Click + in the upper-right of the title bar.
2. Pick **Number**.

## Set Number Format

- Toggle the thousands separator.
- **Display format**: integer, decimal, or percentage.
- Pick the thousands and decimal separator styles.
- **Abbreviation**: shorten very large numbers.
- Toggle **disallow negative numbers** — when on, negatives can't be entered.

## Display Currency

To display currency such as ¥1240.88, use the [Currency](/aitable/fields/field-types/currency) field type instead.

## Set a Default Value

You can set a default number for new records.

## Inline Arithmetic

Number and Currency fields accept simple `+ - * /` expressions when editing — handy for quick calculations.

Example: four colleagues split a ¥392 lunch — type `392 / 4` in the cell.
