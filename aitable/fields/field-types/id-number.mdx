# 1 Overview

Use this field for **collecting ID numbers** with built-in **validation** — invalid IDs are flagged and can't be saved.

# 2 Basics

## 2.1 Add a Field in Grid View

Click ➕ in the upper-right of the AI Table title bar — pick **ID number** under field types.

## 2.2 Add a Field in Form View

In the question list on the left, pick ID number — use it to collect responses in the form.

## 2.3 Manage and Edit the Field

Double-click the field title or click the dropdown — duplicate, delete, freeze, etc.

# 3 Scenarios

The ID number field is mainly for information collection — using a form view protects respondent privacy. To collect via grid view instead, turn on **advanced permissions**: set role **edit permission** to "records related to the member" and set other records to **no access**.
