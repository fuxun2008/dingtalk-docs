# 1 Overview

Use the rating field to display values as stars, hearts, or thumbs-up icons — make scoring intuitive.

# 2 Basics

## 2.1 Add a Field

In a grid view, click + in the upper-right of the AI Table title bar — pick Rating under field types.

In a **form view**, click "Add question" on the left — set icon, score, and two-level labels in the form editor.

## 2.2 Configure the Field

**Icon**: pick stars, hearts, numbers, etc.

**Score**: customize the value range.

**Two-level labels**: e.g., satisfaction, likelihood, agreement, etc.
