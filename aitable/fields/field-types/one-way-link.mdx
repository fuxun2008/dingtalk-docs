# Overview

Use the One-way link field to link records from another table — click to view a record's full row without switching context.

**Note**: a one-way or two-way link cell only displays the **primary field** of the linked record. To surface other fields, use [Linked reference](/aitable/fields/field-types/linked-reference).

# Basics

## Add a one-way link

Click ➕ in the upper-right of the title bar — pick **One-way link** under field types.

## Configure the one-way link

### Pick the table to link

Pick a table from the dropdown — cross-AI Table linking isn't supported yet.

### Toggles

**Allow multiple records**: lets a cell link to multiple records.

**Filter records by view**: the records on offer match the fields shown in the chosen view — adjust the view's visible fields to update the link list automatically.

## Add and view linked records

Click a cell and check the records to link — confirm to display the **primary field** of each in the cell. **Click a primary field** to view the full record. Use the dropdown to view all records, or use the toggle in the upper-right to **show only selected**.

## Quickly create and link a new record

If you have **add-record permission** on the linked table, you can add a new record there directly while linking.

Open the cell dropdown — click **➕** in the lower-left to add a new record in the linked table.

In the blank record card, fill in details and click **Close card** in the upper-right — the new record syncs to both the linked table and the current list.

Check it and confirm in the lower-right.

## Remove a linked record

**Method 1**: click the cell once — click **×** on the right of the record to remove.

**Method 2**: double-click the cell, uncheck records in the dialog, and confirm.

**Note**: removing the link does not affect the source record.

## Jump to the linked table

When adding linked records, the linked table's name shows above the search bar — click to jump. The destination is the view chosen in **Filter records by view**.

# FAQ

- **Q: Can a cell link multiple records?**

  A: Yes — toggle on **Allow multiple records** in the field configuration.
