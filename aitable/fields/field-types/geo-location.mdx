# 1 Overview

Use the AI Table **location** field to record positions quickly — manual entry, search any location, or capture real-time location on mobile.

**Common scenarios**: capture real-time location on mobile to verify inspections, check-ins, and similar.

# 2 Basics

In a grid view, click ➕ **Add field** in the upper-right of the toolbar — pick **Location** under field types. Input methods: **any location** or **mobile real-time only**.

In a **form view**, pick **Location** from the question list — toggle **mobile real-time only** to collect location via the form.

With **any location**, double-click the cell — type in the search bar, pick a result, and confirm in the lower-right.

With **mobile real-time only**, on mobile, open the record detail or form link and **tap to locate**.

# 3 FAQ

- **Q: Can a single cell hold multiple locations?**

  A: No.
- **Q: Does switching input method affect existing entries?**

  A: No.
