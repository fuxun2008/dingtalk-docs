## Overview

Use the Progress field to enter a number and display progress as a bar.

## Basics

### Add a field

Click + in the upper-right of the AI Table title bar — pick **Progress** under field types.

![](/aitable/fields/field-types/progress/images/image_lJ5-azyQMQ.png)

### Configure the field

You can configure:

1. **Number format**: percentage (default) or number.
2. **Decimal places**: integer (default), 1, 2, or 3.
3. **Color**: single, gradient, or multi-segment.

Toggle **Custom progress range** to set custom start and target values:

![](/aitable/fields/field-types/progress/images/image_TExRUv4_oi.png)

## Enter progress

Two ways to enter progress:

1. Double-click a cell and type a number — it becomes a progress bar. With percentage format, omit the `%`. To show 10%, type `10`.

![](/aitable/fields/field-types/progress/images/DingTalk录屏_2025-03-24%20101250_1gvdGgSoEA.gif)

2. Hover the bar and drag the slider, or click anywhere on the bar to set progress.

## Convert from other fields

**Via copy**: select a cell, press **Cmd + C / Ctrl + C** or right-click **Copy**, and paste into a progress cell — it converts automatically. Note: with percentage format, values > 1 show as more than 100% — pasting `10` shows `1000%`.

**Via field type edit**: double-click the column title, or click the dropdown — pick **Progress** under field types.

![](/aitable/fields/field-types/progress/images/DingTalk录屏_2025-03-24%20103648_CBT0fx_d9l.gif)

# FAQ

- **Q: Can I convert other fields directly to a progress field?**

  A: Yes. Numeric long-text, number fields, single-select fields with numeric content, or formula fields that return numbers can all convert directly.
- **Q: Can I customize the progress range?**

  A: Yes — set custom start and target values in the field menu. Note: the range doesn't restrict the values you can type into the cell.
