Use the AI Table **Member** field to record people — project leads, points of contact, owners, etc.

Note: only org members and DingTalk contacts can be picked — DingTalk users not yet added as contacts can't be selected.

## Add a Member Field

Click + in the upper-right of the title bar — pick **Member**.

## Member Field Options

**Show nickname**: members show as **name** + nickname.

**Show external tag**: if a member is outside the org, an **External** tag appears after the name.

**Allow multiple members**: whether a cell can hold multiple members.

**Extra info**: sync member info — department, manager, employee ID, title, member type, email — into the table (available only when multiple members is off).

## Default Member

Set a default member to fill in when a record is created.

## Grant Access and Notify on Add

When adding a member, check **Grant access and notify** — they immediately get view permission and receive an @ mention.

## Convert Name / Email / Phone to Member

Double-click the title of a field with email / phone / employee ID / name — pick **Edit field**, change the type to **Member**. In the dialog, choose whether to **save the converted member info to a new field** (off by default) and confirm.

## Quick Notify

Hover a member's name in a cell — click @ **Notify them** to send an @ mention.

## FAQ

#### **Q: Why Can't I Add Multiple Members to a Cell?**

A: **Allow multiple members** may be off. Toggle it on in field configuration to add multiple members per cell.

#### **Q: Are There Limits When Converting to Member?**

A: Up to **3,000** members per phone-to-member conversion at a time.

#### **Q: Why Does Converting Name / Email / Phone to Member Fail?**

A: Possible reasons:

1. **Search restriction**: if the org admin has disabled search by email or phone, conversion fails.
2. **Multiple members in one cell**: if a cell contains multiple names or member-related values, the system can't convert.
3. **Duplicate names**: if a former employee shares a name with a current one, conversion fails.
4. **Mismatched input**: the name typed may differ from the org admin's record (typos, extra spaces, formatting). Double-check and retry.
5. **Former employees**: when pasting a former employee's name into a Member field:
   - Conversion succeeds if the current user has prior message history with them.
   - Otherwise, it fails.

#### **Q: After Converting Name / Email / Phone to Member, Does the Person Get a Notification?**

A: No.

#### **Q: If the Member Doesn't Have Read Access to the AI Table, Do They Still Get Notified?**

A: No. If they don't have read access, they won't receive any notification.
