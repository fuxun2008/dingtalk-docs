# 1 Overview

Use the URL field to quickly enter a link with display text — click to open the page.

# 2 Basics

## 2.1 Add a URL field

1. Click + in the upper-right of the title bar.
2. Click "Field type".
3. Pick **URL**.

![](/aitable/fields/field-types/link/images/image_2LDpITloGy.png)

## 2.2 Edit the URL

1. Double-click the cell.
2. In the top text box, enter the **display text**.
3. In the bottom text box, enter the **URL** to open.
4. Click Save.

![](/aitable/fields/field-types/link/images/image_fDEW65diB3.png)

# 3 FAQ

- **Q: Can a single cell hold multiple URLs?**

  A: No — each cell holds one URL.
