# 1 Overview

Use the AI Table **Address** field to manually pick a location in **province / city / district (— street)** format.

# 2 Basics

**Add an address in grid view**

1. Click + in the upper-right of the title bar.
2. Click **Field type**.
3. Pick **Address**.

![](/aitable/fields/field-types/administrative-region/images/image_eA7LaA8vDQ.png)

**Set address format**

In the format dropdown, pick **Province / city / district** or **Province / city / district — street**.

**Province / city / district** lets respondents pick from the built-in region list only.

**Province / city / district — street** also requires a free-text street.

![](/aitable/fields/field-types/administrative-region/images/image_Jh5nmJZWa7.png)

**Add an address in form view**

1. Pick **Address** from the question list on the left.
2. Pick **format** from the dropdown below the question.

![](/aitable/fields/field-types/administrative-region/images/image_cBtUr16sg3.png)

# 3 FAQ

- **Q: Can a single cell hold multiple addresses?**

  A: No.
- **Q: Does switching format affect existing entries?**

  A: No.
