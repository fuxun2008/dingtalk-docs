Use the AI Table **Single select** and **Multi-select** fields to categorize or tag records. **Single select** allows one option per cell; **Multi-select** allows multiple.

**Single select** is for exclusive categories; **Multi-select** is for tagging.

For example, a **Priority** field with options P1, P2, P3 — each task gets exactly one priority — use **Single select**.

![](/aitable/fields/field-types/select/images/image__O40cs7mwY.png)

A **Review category** field with options Feature, Price, Quality, Service — each review can carry multiple tags — use **Multi-select**.

![](/aitable/fields/field-types/select/images/image_KKgPwy86jB.png)

## Add a single/multi-select field

1. Click + in the upper-right of the title bar.
2. Pick **Single select** or **Multi-select**.

![](/aitable/fields/field-types/select/images/image_ezSpvPpyH9.png)

## Configure single/multi-select

### Add options

Click **Add option** for one at a time, or **Bulk edit** to add or edit many at once.

![](/aitable/fields/field-types/select/images/image_RzgOtYaFan.png)

### Reorder options

Drag to reorder, or rearrange the lines in **Bulk edit**.

![](/aitable/fields/field-types/select/images/image_EDGZ9OHonF.png)

### Delete an option

Click the icon on the right of an option to delete it.

### Option color

Click the color icon on the left of an option to change it.
