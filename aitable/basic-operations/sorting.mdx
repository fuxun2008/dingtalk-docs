Sort rules order your data the way you want.

## Add a sort rule

1. Click **Sort** in the view's top toolbar.
2. Click **Add sort rule**.

A sort rule has two parts: the **field** to sort by, and the **direction**.

## Sort directions

- **A → Z** / **Z → A**: for text fields, sort alphabetically forward or reverse.
- **Option order** / **Reverse option order**: for single / multi-select, sort by the field's option order, forward or reverse.
- **0 → 9** / **9 → 0**: for number fields, sort ascending or descending.
- **Earliest → Latest** / **Latest → Earliest**: for date fields, sort by date.

## Multi-rule sorting

Add multiple sort rules. Data sorts layer by layer in the order rules appear.

## Remove a sort rule

Click the icon to the right of the rule.

# FAQ

#### Q: **Who can add, edit, or remove sort rules?**

With Advanced Permissions off: the AI Table owner and anyone with **Manage** or **Edit** access can add, edit, or remove.

With Advanced Permissions on: the owner and **Manage** users can; **Edit** users can sort only on fields they have access to.

Note: when a view is locked, no one can change sort.

#### Q: **Will sort in one view sync to other views?**

A: No — sort applies only to the current view.

#### Q: **How do I reorder columns in a kanban view?**

A: Sort only changes card order within each column. To reorder columns themselves left-to-right, drag the column header.
