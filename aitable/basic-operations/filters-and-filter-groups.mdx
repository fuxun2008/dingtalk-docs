Use **filters** in a view to show only records that match a condition.

## Filters

### Add a filter

1. Click **Filter** in the view's top toolbar.
2. Click **Add filter**.

![](/aitable/basic-operations/filters-and-filter-groups/images/image_5RmhMFcevB.png)

### Remove a filter

Click the icon to the right of a filter to remove it.

![](/aitable/basic-operations/filters-and-filter-groups/images/image_N8XzHCdqHy.png)

### Multi-condition filtering

You can add multiple filters and freely pick **AND** / **OR** logic between them.

![](/aitable/basic-operations/filters-and-filter-groups/images/image_0SxLTZSnCB.png)

## Filter groups

Once you've got the basics down, you'll hit cases like: filtering for several different result sets at once, or wanting more flexible combinations between rules. That's where **filter groups** come in.

### Why filter groups?

A single filter can express one or several simple rules — `Status = Done` or `Status = In progress`. That covers a lot, but when the logic gets messy — multiple departments, multiple statuses, multiple owners all at once — flat filters can't model that. **Filter groups** let you break conditions into clear, logical sub-groups and connect those groups with **AND** / **OR**, so the system reads your intent correctly and returns what you actually wanted.

## How to use filter groups

#### Entry

1. Click **Filter** in the view's top toolbar.
2. Click **Add filter group**.

![](/aitable/basic-operations/filters-and-filter-groups/images/image_T5rjjO9-e9.png)

### Creating a filter group

Two ways:

1. **Method 1**: from the current set of filters, click **+ Add filter group** to spin up a new group. AI Table adds a new layer below your current filters — you can keep nesting more granular structure on top of the existing rules.

![](/aitable/basic-operations/filters-and-filter-groups/images/image_mD01oWLeYt.png)

2. **Method 2**: inside an existing group, keep adding new groups. Click the **+** in the group, then **+ Add filter group**. This creates another layer inside the group — the second nesting level. **Max nesting is 2 levels.**

![](/aitable/basic-operations/filters-and-filter-groups/images/image_Z7lmb0yPiI.png)

### Notes

1. **Max 2 levels of nesting**: once at level 2, **Add filter group** is grayed out — you can't go deeper.
2. **2 levels is enough for most complex needs**: combining different group levels with **AND** / **OR** gives you flexible composite filters.

   ![](/aitable/basic-operations/filters-and-filter-groups/images/image_5TQfVsqrVY.png)
3. **Each group can have multiple filters but only one logic operator**: each group is either **AND** or **OR** — no mixing within a group.

# FAQ

#### Q: **Who can add, edit, or remove filters?**

A: **Basic permissions**: Owner / Admin / Editor can. **Advanced permissions**: only Owner and Admin can. Once a view is locked, no one can edit.

#### Q: **If I set filters in the current view, do other views show the same results?**

A: No — filters apply only to the **current view**, saved independently.

#### Q: **Will filters reset on refresh or reopen?**

A: Public views: unsaved filters are temporary; saved filters persist. Private views: changes are saved automatically.
