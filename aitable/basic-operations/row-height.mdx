Use **Row height** in the grid view to fit more info per row.

**Note**: row height is **grid view only** — other view types don't support it.

## Set Row Height

In a grid view, click **Row height** in the toolbar and pick a height.
Four options, increasing height: **Standard**, **Medium**, **Tall**, **Extra tall**.

# FAQ

#### Q: **Does AI Table Support Text Wrapping?**

A: Not currently.

#### Q: **Can I Set the Height of a Single Row?**

A: No. You can only pick **Standard / Medium / Tall / Extra tall**, and the choice applies to every row.

#### Q: **Can I Drag to Set Custom Row Height?**

A: No. The four presets are the only options — no drag-to-resize, no other heights.
