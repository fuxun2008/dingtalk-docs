Hover over the divider in the column header to adjust column width.

![](https://img.alicdn.com/imgextra/i2/O1CN01JeU8I223wcLU5p71R_!!6000000007320-2-tps-1258-848.png)


## How to adjust

- Drag: resize directly.
- Right-click: open the resize menu.
- Double-click: auto-fit this column.
- ⌘ + double-click: auto-fit all columns.

![](https://img.alicdn.com/imgextra/i1/O1CN01QhjHPn1yhtXE9fhun_!!6000000006611-2-tps-1254-896.png)


The right-click menu has:

- Auto-fit column width
- Match left column
- Match right column
- Auto-fit all column widths
- Distribute columns evenly
- Sync column width

Note: **Sync column width** propagates the current width across every grid view that shows this column — keeps the column consistent everywhere and saves you from resizing in each view.

## Bulk resize

Hold `cmd/ctrl` and click column headers to multi-select. Drag any boundary in the selection to resize all selected columns.

Hold `shift` and click column headers to select a range. Drag any boundary to resize all of them.
