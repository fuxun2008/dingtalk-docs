---

When you collect data on a recurring schedule, **per-cycle split** can move data from past cycles into separate **historical-cycle tables**. For closed orders, completed inspections, ended check-ins — store the past in split tables and view / search them read-only, freeing up live compute.

## Basics

1. Open the form view and click **⚙ Settings** at the top-right.
2. Turn on **Recurring reminder**.
3. In the panel, turn on **Split per cycle**.

![](/aitable/forms/form-rotation/images/image_I7-jepgTlJ.png)

At the end of each cycle, a stats table for that cycle's historical-cycle data shows up in the AI Table list. Click to see the full detail.

## What you can / can't do in historical-cycle tables

| Feature           | Behavior                                                          |
| ------------ | ---------------------------------------------------------------- |
| Edit           | - Historical-cycle tables are read-only.                                                      |
| Find / filter / group / sort  | - Find: yes.  - Filter: no.  - Group: no.  - Sort: no.       |
| One-way / two-way link / lookup | - Existing links in the current-cycle table carry over to the split unchanged.  - Historical-cycle tables can't create new links, and other tables can't link to them.           |
| Formulas           | - Formulas in historical-cycle records stop updating.  - Current-cycle records can't reference or link to records in historical-cycle tables in formulas.            |
| Dashboards          | - Historical-cycle data shows in dashboards.  - When a cycle ends and data moves to history, dashboard data switches to the new current cycle's data. |
| Advanced Permissions         | - After a split, you must manually update Advanced Permissions to grant access to the historical cycle.                               |
| Automation          | - Historical-cycle tables don't trigger automations, can't be edited by automations, and can't be referenced or queried.                             |
| OpenAPI      | - You can pull historical-cycle data via the API.                                                     |
| Revision history         | - Historical-cycle tables don't support revision restore.                                                |
| Export           | - Historical-cycle tables can be downloaded.                                                      |
| Copy / paste         | - Copy a row: yes. Copy the whole table: no.  - Cut and paste: no.                                    |
| Mobile          | - Historical-cycle data is viewable on mobile.                                                     |
| Sharing           | - With Advanced Permissions off, anyone with view access can read the historical-cycle data.                                    |
