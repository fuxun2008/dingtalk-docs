AI Table supports importing **Excel files** and automatically detects data formats during import, converting each column into the most appropriate field type.

## Import an Excel file as a new AI Table

1. From the AI Table home page, select **Import Excel / online spreadsheet**.
2. Select an **Excel file (`.xlsx` or `.csv`)** to upload.

![](https://img.alicdn.com/imgextra/i4/O1CN01MlcaWR1ScL1e2ZG3n_!!6000000002267-2-tps-2316-1284.png)


## Import into the current AI Table

1. With an existing AI Table open, click **+ New / Import** in the bottom-left corner.
2. Choose **Import Excel (`.xlsx`, `.csv`)** to upload.

![](https://img.alicdn.com/imgextra/i1/O1CN011EkaU71P8cTiRrUEw_!!6000000001796-2-tps-1250-502.png)

## Import Excel data into an existing table

There are three ways to import data from an Excel file into an existing table:

1. In the left sidebar, open a table's right-side menu and choose **Import Excel**.

2. In the left sidebar, click **+ Add / Import** → **Import Excel** → **Import into existing table**, then pick the target table.

3. Inside an open table view, click the arrow next to **Add record** and choose **Import Excel**.

## Report an import issue

If your Excel data lands in AI Table garbled or incomplete, you can [submit the file](https://docs.dingtalk.io/notable/share/form/v01ZWGl05mj7a2d5n34_hERWDMS_YxEpVMk "Submit a file") and we'll take a look.
