AI Table supports importing **Excel files**. After import, AI Table automatically detects data formats and converts each column into the most suitable field type.

## Import an Excel file as a new AI Table

1. From the AI Table home page, choose **Import Excel / online spreadsheet**.
2. Select an **Excel file (`.xlsx` or `.csv`)** to upload.

![](/aitable/getting-started/import-excel/images/image_ikmnXBcbOL.png)

## Import into the current AI Table

1. With an existing AI Table open, click **+ New / Import** in the bottom-left corner.
2. Choose **Import Excel (`.xlsx`, `.csv`)** to upload.

![](/aitable/getting-started/import-excel/images/image_dETw52wjkq.png)

## Append Excel data into an existing table

There are three ways to append data from an Excel file into a specific table:

1. In the left sidebar, open a table's right-side menu and choose **Import Excel**.

   ![](/aitable/getting-started/import-excel/images/image_sppDYH-R5f.png)
2. In the left sidebar, click **+ Add / Import** → **Import Excel** → **Import into existing table**, then pick the target table.

   ![](/aitable/getting-started/import-excel/images/image_ErDP7BCee7.png)
3. Inside an open table view, click the arrow next to **Add record** and choose **Import Excel**.

   ![](/aitable/getting-started/import-excel/images/image_YXBUr8j-u3.png)

## Report an import issue

If your Excel data lands in AI Table garbled or incomplete, you can [submit the file](https://alidocs.dingtalk.com/notable/share/form/v01ZWGl05mj7a2d5n34_hERWDMS_YxEpVMk "Submit a file") and we'll take a look.
