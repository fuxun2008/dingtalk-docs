The pivot view is a powerful data analysis tool — pull core insights from massive datasets fast. Unlike standard tables, drag fields for multi-dimensional aggregation.

## Overview

- **Drag-driven config**: drag fields into rows, columns, or values — zero-friction stat setup.
- **Multi-dimensional analysis**: multiple row / column levels, flexible cross-analysis.
- **Flexible aggregation**: built-in sum, count, average, max, min, etc.
- **Detail drill-down**: click any value cell to see the underlying records.

In a high-velocity livestream commerce environment, the ops team produces massive detail every day. Traditional reports are often laggy and one-dimensional. Pivot views turn raw livestream rows into actionable daily ops reports.

## Workflow

### Create a pivot view

1. Open AI Table, click the **+ New view** icon at the right of the view bar.
2. Pick **Pivot view** to enter the config.

### Configure the pivot

Use the right panel to define structure:

- **Data range**: defaults to **All data**. Click **Filter** in the toolbar to narrow.
- **Rows / columns**:
  - **Rows**: drag fields here — values become row labels, multi-level nesting supported.
  - **Columns**: drag fields here — values become column labels.
  - **Values**: numeric or non-numeric stat fields.
    - **Number**: sum, count, average, max, min.
    - **Non-numeric**: count, distinct count.
- **Totals**: at the bottom of the config, toggle row totals and column totals on/off.

### Sort

Sort by row or column name:

1. Click the icon next to a field in row / column.
2. Pick ascending or descending.
3. The pivot updates live.

## Drill-down

Pivot view shows aggregates **and** lets you trace back to the source.

1. Click any **stat value cell** in the pivot.
2. The **Detail** panel pops up — all underlying records.
