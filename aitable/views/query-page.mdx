## 1 About query pages

A **query page** is a special view that lets external users query data without entering AI Table. Configure query conditions — users enter info (phone, order number) to view matching records.

Use it for payslip queries, shipment tracking, exam result release — fast info distribution with strict privacy. Each user only sees their own data.

### 1.1 Create a query page

Generate a query page from existing table data fast.

1. Click **+ New view** at the right of the view bar.
2. Pick **Query page** in the dropdown — generates from the current table.

### 1.2 Edit and style

Customize the page to fit your scenario.

- **Title and description**: click directly to edit.

- **Theme**: click the **Theme** icon in the top-right to upload a brand cover or pick a preset, plus layout options.

### 1.3 Set query conditions

Define which fields users query by.

1. Click **Add query condition** in the middle of the page.
2. Check fields to use as query conditions ("Submission date", "Product rating").

> Note: attachment and button fields don't support query conditions.

To reorder or delete conditions, hover the card and drag the icon, or click the delete icon.

Some conditions can be required.

1. In **Settings**, click **Required query fields**.
2. Check the required fields.

### 1.4 Permissions and more custom config

Click **Settings** at the top-right of the query page for security and interaction config.

#### 1.4.1 Visible fields

Control which fields show in query results. For "Salary query", once a user enters "Employee ID", only "Net pay" and "Pay period" show — not internal notes.

- **Readable**: visible in results.
- **Hidden**: not shown.
- **Editable**: user can edit the field in results (premium feature).

The result page shows up to 7 fields. To view full record detail, click the icon on the right of each record.

#### 1.4.2 Query scope

Limit queryable records. E.g., only allow querying products where "Spec" = "Bundle", or "Submitter" = "self".

#### 1.4.3 Who can query

Set access by sensitivity:

- **Anyone in the org with the link**: internal employees only.
- **Anyone on the internet with the link**: open to all — for external info.
- **Specific members or groups**: invited only.

#### 1.4.4 Query customization

Toggle conditions as required. If unchecked, queries run regardless of whether the field is filled.
