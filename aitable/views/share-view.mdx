## What is a shared view?

Sharing a single view independently means sharing **one view** from an AI Table file with specific recipients, not the whole table. With filters and field visibility, you control exactly what the recipient sees and hide irrelevant or sensitive info. The shared view stays in sync with the source table — no manual updates.

Shared views are read-only — not for collaborative editing.

## Common scenarios

- **External collaboration**: working with external teams, share only the view they need. The source table's complex structure and data stay private.
- **Better mobile viewing**: if the full table is unwieldy on mobile, share a view tailored to the info recipients need — clean, focused, easy to scan and report.

## How to share a view

Click **Share view** at the top of any view's config to share the current view.

Once on, additional settings:

- Allow recipients to copy data from the shared view.
- Allow recipients to jump back to the source table.

## Who can share a view?

- Without advanced permissions: owner, admins, and editors can share.
- With advanced permissions: only owner and admins can share.

## Visibility scopes

Pick the access scope:

- Anyone in the org with the link.
- Invited recipients only.
- Anyone on the internet with the link.

## Display rules for shared views

- **Visible in shared view**: original grouping (and its results), original sort (and its results), row height.
- **Hidden in shared view**: fields hidden by field config, records hidden by filters, the original filter conditions themselves.

Recipients can't edit view config, but they can configure their own view based on visible data — hide fields, filter, group, sort, change row height, search. Their changes do not propagate to the source table.

## Embed in a page

### What's it for?

Embed a shared view into another web page so recipients can view content without opening AI Table.

### How to use

After clicking **Share view**, go to **Embed** to get the code, then paste it into any page where you want the view to appear.

You can also toggle **Show view actions**. Off hides actions like add record, field management, filter, group, sort, cell coloring.
