Print layout is a formatted output capability that **turns structured AI Table data into a form suited for reading, printing, archiving, and delivery**. Unlike grid views, print layout focuses on page layout, content presentation, and output standards — fits business documents, formal reports, customer profiles, etc.

Print layout supports unified config via **Create print layout view**, or **direct entry from a single record** to generate a record-level layout fast.

## Overview

- **Formatted display**: clearer, more readable layout — lifts data professionalism and readability.
- **Whole-table or single-record**: list-style reports for the whole table (table layout) or detail documents for one or several records (record layout).
- **Flexible structure**: configure layout and content freely for different output needs.
- **Collaborative management**: team sharing, no rebuild, consistent format.
- **Print and archive friendly**: paper printing, PDF export, offline workflows, formal materials.

## Common scenarios

In daily business, lots of data **needs to be both managed and formally output**. Print layout turns structured AI Table data into formal content for reading, printing, and delivery fast.

For example:

- Generate **standardized service tickets** from work order data — print on-site for the technician, signed by the customer.
- Compile customer profiles, follow-ups, and quotes into **formal customer visit packets** — saves doc rework.
- Print **shipping notes, receipt notes, inventory sheets** for offline use — cuts manual transcribing.
- Generate **inspection records, equipment check sheets, visitor logs** for offline use and archiving.
- Output **interview registration, employee info, training sign-in sheets** for on-site fill-in and unified management.
- Generate **daily / weekly reports, ops summaries** from live data fast.

With print layout, teams **don't need a separate design / DTP tool** to **produce uniform, standardized business materials from live data** — minus rework and manual layout cost.

## Record layout

Record layout fits **single-record detail display and formal output** — turns a record's field values into a readable, printable form.

Compared to table layout, record layout fits **work orders, customer profiles, inspection records, service tickets, interview forms** — assemble a single business record into a complete detail page.

### Highlights

- **Single record** focused.
- Fits **detail reading and formal output**.
- Generates **standalone layout content** based on the current record.
- Updates with the source data.
- Use for **printing, archiving, offline signatures, business workflows**.

![](/aitable/views/print-layout/images/image_DBeONffWlA.png)

## Table layout

Table layout fits multi-record display and bulk output — present records from a table as lists, reports, or rosters.

Compared to record layout, table layout fits **daily / weekly reports, order lists, shipping detail, inventory sheets, customer lists** — view, print, and archive a batch of data.

### Highlights

- **Whole-table** focused.
- Display **multiple records** at once.
- Fits **reports, lists, summary scenarios**.
- Updates with the source data.
- Use for **bulk printing, formal output, offline workflows**.

## Workflow

### Create a print layout view

1. Open AI Table, click the **+ New view** icon at the right of the view bar.
2. Pick **Print layout** plugin to create a **print layout view**.
3. In the view, click **New layout** to create layout content.
4. Choose:
   - **Table layout**: reports, lists, multi-record summaries.
   - **Record layout**: work orders, profiles, detail documents.

![](/aitable/views/print-layout/images/2026-05-07%2014.06.24_aajtl7vPzi.gif)

### Open print layout from a record

1. Open a record's detail in AI Table.
2. Click **Print layout** in the top-right.
3. The system auto-generates the corresponding record layout from the current record.
4. Adjust layout, fields, and structure.

![](/aitable/views/print-layout/images/2026-05-07%2014.07.10_C-jZmOeUEO.gif)

### Create a layout

1. In the print layout view, locate the **Table layout** or **Record layout** area.
2. Click **New layout** in the top-right.
3. Enter the layout editor.
4. Configure content and page layout per layout — fits diverse output needs.

![](/aitable/views/print-layout/images/2026-05-07%2014.28.32_TeVuXyuTaj.gif)

### Edit a layout

1. In a layout, click **Edit** in the top-right.
2. Adjust table content, structure, and zones directly on the page.
3. Edits auto-save.
4. Click **Done** to exit edit mode and save.

Note: **Edit layout** is a Premium / Ultimate-only feature. Contact your admin to purchase / enable.

![](/aitable/views/print-layout/images/2026-05-07%2014.16.21_HP5cWPCAA3.gif)

### Set layout visibility

New layouts default to **Personal layout** — only the creator sees them.

For team use, switch to **Shared layout**.

- **Personal layout**: creator only — fits temporary or personal use.
- **Shared layout**: visible to anyone with table access — fits team-wide use.

After switching, the team uses one layout — no rebuild, consistent format.

> ⚠️ Only the creator can change visibility or edit the layout.

![](/aitable/views/print-layout/images/2026-05-07%2014.19.03_mxSSk6i-6D.gif)

### Duplicate a layout

1. In a layout, click **More** in the top-right.
2. Pick **Duplicate layout**.
3. A copy is generated.
4. Defaults to **Personal layout** — keep editing as needed.

![](/aitable/views/print-layout/images/2026-05-07%2014.22.05_1wIW0U2XSX.gif)

### Delete a layout

1. In a layout, click **More** in the top-right.
2. Pick **Delete layout**.
3. Confirm.

![](/aitable/views/print-layout/images/2026-05-07%2014.20.13_OUlNJD_kZ2.gif)

> ⚠️ Only admins and the creator can delete a layout.

### Print

1. Open the layout.
2. Click **Print** in the top-right.
3. Print preview opens automatically.
4. Confirm layout and pagination, then print or export.

Note: confirm content, pagination, and presentation before printing — avoid truncation.

![](/aitable/views/print-layout/images/2026-05-07%2014.33.40_oCRgdO49cB.gif)

### Export PDF

1. Open the layout.
2. Click **Export PDF** in the top-right.
3. The system generates a PDF.
4. Download to share, archive, or print.

Note: PDF reflects current layout — confirm layout / pagination first.

![](/aitable/views/print-layout/images/2026-05-07%2014.34.58_PuaIoYTYyE.gif)

### Auto data sync

Layout content stays in sync with AI Table data in real time.

When records update, the layout updates automatically — no rebuild.

For example:

- Edit customer info → customer profile layout updates automatically.
- Change order status → order list layout updates accordingly.
- Add or delete records → table layout reflects the change.

### Permission rules

Layout data display **inherits the table's data permissions and advanced permissions**.

Members without the data permission won't see the data in the layout.

For example:

- Members without **table view permission** can't see the layout.
- Fields hidden by **field permissions** don't show in the layout.
- Records limited by **record permissions** don't appear in the layout.

Note: **Shared layout** only means the layout itself is shared — actual data visibility still follows current AI Table permissions.

## FAQ

#### Why can't I see a layout?

If the layout is **Personal**, only the creator sees it. **Shared layouts** require AI Table access.

#### Why can't others see a layout I created?

New layouts default to **Personal** — only the creator. Switch to **Shared** for team access.

#### Why can't I edit a layout?

Only the **creator** can edit. Contact the creator to make changes.

#### Why can't I change layout visibility?

Only the **creator** can change visibility.

#### Do I need to regenerate the layout after data updates?

No. Layout data stays in sync with AI Table data in real time.

#### What happens to layouts when the creator leaves?

Layouts aren't deleted on member departure — they remain viewable.

For **Shared layouts**, admins can keep viewing and deleting. For **Personal layouts**, after the member leaves, no one else can edit / manage. Switch long-lived layouts to **Shared** before departure.

#### Why do collaborators see different content?

Layout data display follows each user's data permissions. Different members may see different fields and records.

#### Why can't I see certain fields?

Layout data display **inherits each user's current AI Table permissions**. Without view permission for a field, the field doesn't show.

#### Can I recover a deleted layout?

Not yet — be careful when deleting.
