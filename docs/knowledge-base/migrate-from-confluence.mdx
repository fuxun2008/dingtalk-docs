title: "Migrate from Confluence"
description: "Export a Confluence space as a zip file and import it into DingTalk Docs Knowledge Base in a few steps — supporting both Cloud and Server editions — to consolidate enterprise knowledge in one centralized platform."
---

Migrate Confluence spaces to DingTalk Knowledge Base to achieve true one-stop knowledge accumulation and management for your organization, and boost work efficiency. Avoid fragmented management across different collaboration platforms that drags down productivity.

You can export an entire space in Confluence as a zip file and migrate it to DingTalk Knowledge Base. Once the file is parsed, the imported space content becomes a standalone DingTalk Knowledge Base.

---

## Step 1: Export a zip file from Confluence

### Export steps for Cloud version

1) Open the space you want to migrate, select **Space settings**, click **Content tools**, and then choose **Export**.

2) Select **HTML** as the export format, click **Next**, and then choose **Normal Export**.

3) After submitting the export task, wait for Confluence to export the space. Once the task is complete, click **here** to download the file locally.

*Note: Normal Export exports the entire knowledge base; Custom Export lets you export a single page, and the process cannot be paused.*

---

### Export steps for Server version

1) Open the space you want to migrate, select **Space administration**, click **Content tools**, and then choose **Export**.

2) Select **HTML** as the export format, click **Next**, and then choose **Normal Export**.

3) Select the space pages to export, click **Export**, and once the export is complete, click **here** to download the file locally.

*Note:*

1. *The Space administration button is usually in the lower-left corner of the page. Its location may vary across versions.*

2. *Normal Export exports the entire knowledge base; Custom Export lets you export a single page, and the process cannot be paused.*

---

## Step 2: Import to DingTalk Knowledge Base

1) Go to **DingTalk Docs - Knowledge Base**, click **Import** in the upper-right corner, and select Import Confluence Space.

2) On the import settings page, select the **zip file** and enter the Confluence space URL, then click **Import**.

After the import task is complete, the corresponding Confluence space appears in your Knowledge Base list.

***Note:***

1. *The zip file is the one exported in Step 1.*

2. *Confluence space URL: Paste the URL of any content page from the corresponding space in the original Confluence. After import, all Confluence reference links in the original space are replaced with DingTalk Knowledge Base links.*

3. *Currently, the upload limit for a single zip file is **500 MB**.*
