title: "How to add files to a Knowledge Base"
description: "Add files to a Knowledge Base from multiple sources — local disk, chat messages, Quick Meeting notes, and work logs — in just a few clicks, centralizing materials from all scenarios for easier knowledge management."
---

The Knowledge Base supports adding **local files, Chat Files, Quick Meeting notes, and logs**, making it easy to organize and store materials across multiple scenarios for more efficient knowledge management.

## How to add local files to a Knowledge Base

Open the **Home page** of the Knowledge Base >> click the "" in the left Table of contents >> select and upload a local file or Folder to the Knowledge Base.

## How to add Chat Files to a Knowledge Base

**Local document**: Click [Add to…] in the lower-right corner of the document Card, then select the target Knowledge Base.

**Online document:** Click [Add to…] in the lower-right corner of the document Card, then select the target Knowledge Base.

## How to add a Quick Meeting to a Knowledge Base

Open the Quick Meeting document >> click [...] in the upper-right corner >> select [Add link to], then choose the target Knowledge Base and Table of contents.

## How to add logs to a Knowledge Base

Open the log you want to add to the Knowledge Base >> click [Add to] >> select the target Knowledge Base and Table of contents.

## How to add Group files to a Knowledge Base in bulk

In the Group Chat window, click the **Zoom icon** at the top >> select **** >> open the Group files dialog, select multiple files to add to the Knowledge Base >> click **[Add to]** >> choose the target Knowledge Base and Table of contents. You can add not only documents, Spreadsheets, and PDFs, but also Folders, audio files, and more.
