## 1. What is a Knowledge Base template?

*   Save daily work documents as Knowledge Base templates. Knowledge Base members can use these templates to quickly create documents, keeping team file formats and content consistent and improving team collaboration efficiency.

## 2. How to create and use a Knowledge Base template

*   Save a document as a Knowledge Base template: On the document, click **More…** in the upper-right corner, click **Save as template**, and then click **Save as template for this Knowledge Base**.

*   Create a document from a Knowledge Base template: When creating a new document, select **Create from template**, and then click **From Knowledge Base**.

## 3. What are the benefits of Knowledge Base templates?

*   Knowledge Base templates standardize the style of team document content and improve the editing efficiency of Knowledge Base members. For example, you can save team weekly reports or monthly reports as Knowledge Base templates, or save a business plan template as a Knowledge Base template to standardize the format and content.
