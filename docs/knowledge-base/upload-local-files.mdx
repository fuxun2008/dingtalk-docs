*   Want to share local images and videos with multiple teams?

*   Want to consolidate Quick Meetings, logs, and other content into your projects?

...

Now you can do all of this! DingTalk Docs supports uploading local files such as PDFs, PPTs, images, audio, and video. You can also import Quick Meetings and logs into Knowledge Base with one click.

Make team knowledge management effortless and well-organized!

## Action Details

### How to Add Local Files to My Knowledge Base?

Click "Docs" in the left sidebar of DingTalk to enter the Docs **homepage** >> click the icon in the upper-right corner >> select to upload a local file or folder. The file is saved to "My Docs". Click it to view.

### How to Add Local Files to a Specific Knowledge Base?

Select the Knowledge Base **homepage** >> click "" in the left Table of contents bar >> select to upload a local file or folder to this Knowledge Base.
