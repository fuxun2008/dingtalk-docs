## 1. All files, centralized in one place

### Centralized storage in one place

In DingTalk Chat, whether it is a video, image, audio, online document, or local file, click **More** on the file card to launch the unified DingTalk Docs save panel. You can save the file to **My Docs**, **Team Files**, **Knowledge Base**, or any other location.

### Integrated with Drive Team Files

DingTalk Docs integrates Drive Team Files, providing one-stop access to and management of shared files.

We recommend storing large quantities of large local files (such as images and videos) shared by the team in Team Files.

### Integrated with Drive My Files

My Docs integrates Drive My Files. Personal work materials for individual learning and use can all be stored in **My Docs** for one-stop management.

Multiple sorting methods and drag-and-drop organization are supported, accommodating the habits of both Docs and Drive long-time users.

### Knowledge Base for daily team document management and storage

Knowledge Base is an enterprise knowledge management platform that integrates knowledge accumulation, transfer, and collaboration.

For online documents, local spreadsheets, and other files that require multi-user collaborative online editing and repeated sharing, choose **Knowledge Base** for storage and management.

## 2. Quickly find target files

### Global search

Open the Home page from the **Document** entry in the left sidebar of DingTalk. Enter a keyword in the top search bar to search all content from DingTalk Docs and Drive.

You can also use filters such as location, creator, and sharer to perform precise searches and quickly locate the target document.

### Share

A new Share module enables efficient retrieval of content shared with you or shared by you through methods such as adding permissions and chat sharing.

### Find favorites

Favorite all content from DingTalk Docs or Drive in one place, and find favorite files from multiple dimensions.

## 3. Efficient management and secure transfer

### Bulk actions

The Knowledge Base table of contents supports bulk move, copy, and delete actions, eliminating repetitive back-and-forth operations. Organize files quickly and make knowledge management faster and more efficient.

Method 1: On the left sidebar table of contents of the Knowledge Base, click the bulk action icon, select the content to act on in bulk, and then choose the copy, move, or delete icon.

Method 2: On the Knowledge Base Home table of contents, hover over a file or folder to display a checkbox. Select the checkboxes of the files or folders you want to act on in bulk.

### Security management

Security permission controls have been upgraded with new **Watermark** and **Leak Prevention** settings to strengthen document data security and make permission management more efficient.

| **Security level** | **Steps** |
| --- | --- |
| Security configuration for all documents in the organization | On DingTalk desktop, go to **Document** > **More** (bottom) > **Organization settings** to enter the admin console, and configure it under **Permissions and security** in the collaboration product settings.<br />\*This setting is available to admins only. |
| Security configuration for all documents in a Knowledge Base | Go to the Knowledge Base admin console > **Security settings** to configure.<br />\*This setting is available to Knowledge Base admins only. |
| Security configuration for a single document | On a single document, go to **Manage permissions** and click **Permission configuration**.<br />\*This setting is available to the document owner and managers only. |
