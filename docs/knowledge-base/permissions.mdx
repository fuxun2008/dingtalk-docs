---
title: "Manage Knowledge Base Permissions"
description: "Manage Knowledge Base permissions at three levels: adding members and assigning roles for the entire Knowledge Base, setting per-document access independently, and configuring global permissions from the organization admin console."
---

## 1. How to Access the Permissions Console

*   Access the Settings console: On the Document Home page, click **More** in the lower-left corner, then select **Organization settings** and choose your organization to open the permissions console.

## 2. How to Add, Modify, or Remove Knowledge Base User Permissions

*   On the Knowledge Base home page, click **Settings** and go to **Users and permissions** to open the management page. Click **Add user** to add users to the Knowledge Base and configure their permissions. You can also modify or delete these permissions. The available permission types are: **Can manage, Can edit, Can view/download, View only, and Remove permissions**.

*   **Note: When you grant or revoke Knowledge Base user permissions using the methods below, the corresponding permissions for all documents within the Knowledge Base are granted or revoked at the same time.**

## 3. How to Add, Modify, or Remove Permissions for a Single Document in a Knowledge Base

*   To grant a user access to a single document within a Knowledge Base, open the document, click **Share** in the upper-right corner to open the permissions window, and then click **Add specified user** to add users. You can also modify or remove permissions for users who already have access.

## 4. How Employees Apply for Document Permissions Within a Knowledge Base

*   When you open a document without access, you can request permissions from the document Owner or the Knowledge Base Admin. Available permissions include Can edit, Can view/download, and View only.

## 5. How to Set a Security Watermark for the Knowledge Base

*   To protect document Content, the Knowledge Base supports two security settings: **Display visitor watermark on documents** and **Leak prevention**. To configure: open the Knowledge Base settings, locate the security settings, and turn on the security features you need.

*   The watermark displays the Company Name + Name + last 4 digits of the mobile number.

*   When Leak prevention is on, users are restricted from downloading or printing, and copying is disabled when viewing DingTalk Docs.

## 6. How to Delete and Restore Documents in a Knowledge Base

*   When you delete a document from a Knowledge Base, it is moved to the Recycle Bin. To restore the document, go to the Recycle Bin and restore it from there.
