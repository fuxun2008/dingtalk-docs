## 1. Knowledge Base entry

*   Desktop: DingTalk left toolbar — Open Docs — Select Knowledge Base

*   Mobile: Bottom menu bar — More — Tap Docs — Knowledge Base

## 2. How to create a Knowledge Base

*   Desktop: On the Docs Home page, go to Knowledge Base, click Create Knowledge Base, choose a blank or template Knowledge Base, click Next to create, then set the Knowledge Base name and Profile Photo to complete creation.

## 3. How to modify the Knowledge Base name and icon

*   When creating a Knowledge Base, you can set its name and icon.

*   Click the "…" icon on the right side of the Knowledge Base, select Settings, then choose Knowledge Base Info. You can also find the settings to modify the Knowledge Base name and Profile Photo here.

## 4. How to delete a Knowledge Base

*   Delete a Knowledge Base: Click the upper-right corner of the Knowledge Base to enter Settings — Premium Settings, click Delete Knowledge Base, follow the prompts to enter the "Knowledge Base name" to confirm, and the deletion will be completed.

*   **Note: Once a Knowledge Base is confirmed for deletion, all Content will be deleted and cannot be recovered. Proceed with caution.**
