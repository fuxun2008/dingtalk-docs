Dear customer, the attachment storage calculation rules for DingTalk Docs will be updated on July 30, 2023. Details are as follows:

---

## [Pin] Change description:

Attachments within the DingTalk Docs suite (Document, Spreadsheet, Mind Map, AI Table, Whiteboard), ++**including images, audio and video files, compressed files, and local files**++, will no longer be exempt from storage limits starting July 30, 2023, and will be officially counted toward your organization's storage capacity. Taking the Document suite as an example, attachment insertion is illustrated below:

**Before: Attachments uploaded within online documents are not counted toward organization storage.**

**After: Officially counted starting July 30, 2023.**

## [Document] DingTalk Docs storage calculation rules:

The storage calculation rules for creating, uploading, and importing files in DingTalk Docs (including suite apps and Knowledge Base) are as follows:

| File Type | Usage behavior | Counted toward storage |
| --- | --- | --- |
| Local file | Upload files in DingTalk Docs. File types include documents, images, audio and video files, compressed files, etc. | Counted |
| Online document | Create or import online documents (Document, Spreadsheet, AI Table, Presentation, Mind Map, Whiteboard) in DingTalk Docs, and edit them by ++**inserting attachments such as images, audio and video files, compressed files, and local files**++. | **Officially counted starting**<br />**July 30, 2023** |
| Shortcut | Add a shortcut in DingTalk Docs. | Not counted |

For the detailed user manual, see: [https://alidocs.dingtalk.com/i/p/nb9XJlDk3dYLaGyA](https://docs.dingtalk.io/i/p/nb9XJlDk3dYLaGyA)

## [Bubble] FAQs on storage calculation updates

## General questions

<Note>
**Q: Which attachments in online documents will be counted toward storage?**

A: All attachments uploaded by employees within online documents in "My Docs", "Knowledge Base", and "Drive" will be counted. Online documents include Document, Spreadsheet, Mind Map, AI Table, and Whiteboard.

**Q: When will the update take effect?**

A: Officially counted starting July 30, 2023.

**Q: Will attachments in existing documents be affected, and can they still be opened?**

A: They will not be affected. However, after an attachment is deleted, you will not be able to re-upload it if your organization's storage space is insufficient. You will need to clear up space or upgrade your storage.

**Q: What should I do if my organization's storage is running out?**

A: You can delete files to free up space or purchase additional storage. (To upgrade: [Click this link](https://oa.dingtalk.io/oa_welcome.htm?channel=aggregation_OA#/product_zone) to sign in to the OA console and select the "Drive storage upgrade plan".)

**Q: Where can Organization Admins view storage usage details?**

A: Open the OA console > Organization Data > Organization Storage. (Sign-in URL: [https://oa.dingtalk.com/](https://oa.dingtalk.io/))

**Q: Can I still use DingTalk Docs normally if my organization's storage is running out?**

A: Actions that do not count toward storage can be performed normally (such as creating online documents and editing document content). Uploading attachments will be affected. You need to clear up storage or purchase additional storage first.
</Note>

## I am an Admin

<Note>
**Q: Where can I see the total size of attachments my organization has uploaded?**

A: You can view the total uploaded attachment size at the top of the "OA Admin Console > Document and Storage Management > Storage Space" page. After July 30, this portion of attachment storage will be added to your organization's used storage. If the total used storage then exceeds the storage you have purchased, file uploads across all apps within your organization will be affected. Please clear up storage or purchase additional storage in advance.

**Q: What should I do if my organization's storage is running out?**

A: You can delete files to free up space or purchase additional storage. To clear storage: In the DingTalk desktop client, click **"..."** (More) on the left toolbar > Admin Console > Drive > Storage Management. You can then manage or send notifications to clear files stored in different locations or saved by organization users.

**Q: What happens to attachments uploaded to documents before July 30 if my organization's storage is insufficient?**

A: Existing attachments will remain available and will not be deleted, but you will not be able to upload new attachments.
</Note>

## I am an employee user

<Note>
**Q: What should I do if I receive an "insufficient space" message when uploading a file in a document?**

A: Contact your organization's DingTalk Admin to delete files or purchase additional storage.

**Q: I deleted attachments from a document. Why are they still taking up organization storage?**

A: After an attachment is deleted, it still exists in historical versions and therefore continues to occupy organization storage. Deleting the document will release the storage. We plan to optimize this so that deleted attachments no longer count toward storage.

**Q: Do attachments in online documents in the Recycle Bin take up organization storage?**

A: No, they do not.
</Note>
