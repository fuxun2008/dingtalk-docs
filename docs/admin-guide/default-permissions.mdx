Configure default permissions for new documents to define the default permission rules that apply when employees create documents. After creation, the document owner can also adjust these settings.

## What are "Permission preferences for new documents"?

*   DingTalk Docs supports configuring different permission rules for individual documents (see Permission settings for Share, Copy, Download, Comments, and more). Organization Admins can set default values for these rules, known as "Permission preferences for new documents."

*   When any employee in your organization creates a document in a Knowledge Base, the permission rules will default to the "Permission preferences for new documents" configuration, and can be adjusted later. If the parent document or Knowledge Base has stricter permission rules, the stricter rules will still apply.

*   Example

    *   The organization's "Permission preferences for new documents" is configured as follows:

        *   Allow documents to be shared outside the organization

        *   People with "Can edit" permissions or above can add Collaborators

        *   People with "Can view/download" permissions or above can copy content, copy scene templates, print, and download

        *   People with "View only" permissions or above can comment

    *   Knowledge Base "AAA" is configured as follows:

        *   Do not allow documents to be shared outside the organization (stricter than the organization's "Permission preferences for new documents")

        *   People with "Can edit" permissions or above can add Collaborators

        *   People with "Can view/download" permissions or above can copy content, copy scene templates, print, and download

        *   People with "View only" permissions or above can comment

    *   When a new document is created in Knowledge Base "AAA", the default permissions are:

        *   Do not allow documents to be shared outside the organization (the stricter rule applies)

        *   People with "Can edit" permissions or above can add Collaborators

        *   People with "Can view/download" permissions or above can copy content, copy scene templates, print, and download

        *   People with "View only" permissions or above can comment
