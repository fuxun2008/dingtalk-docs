title: "Docs Permission Details"

---

Docs provides organizations with a secure, easy-to-use, and simple permission system, helping them collaborate on documents more easily and safely.

## Actions by Permission Role

| Permission | Owner | Admin | Editor | Viewer (with Download) | Viewer (View Only) |
|---|---|---|---|---|---|
| Preview files | ✅ | ✅ | ✅ | ✅ | ✅ |
| Download files | ✅ | ✅ | ✅ | ✅ | ❌ |
| Forward and copy | ✅ | ✅ | ✅ | ✅ | ❌ |
| Create documents/upload files | ✅ | ✅ | ✅ | ❌ | ❌ |
| Upload files | ✅ | ✅ | ✅ | ❌ | ❌ |
| Edit files | ✅ | ✅ | ✅ | ❌ | ❌ |
| Delete files | ✅ | ✅ | ❌ | ❌ | ❌ |
| Manage collaborators | ✅ | ✅ | ❌ | ❌ | ❌ |
| Transfer folder ownership | ✅ | ❌ | ❌ | ❌ | ❌ |
| Cloud printing | ✅ | ✅ | ✅ | ✅ | ❌ |
