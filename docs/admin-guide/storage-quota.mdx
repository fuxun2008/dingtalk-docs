## 1. DingTalk Docs capacity calculation rules

| File Type | Usage Behavior | Counted Toward Capacity |
| --- | --- | --- |
| Local file | Upload files within DingTalk Docs, including documents, images, audio/video, archives, etc. | Counted |
| Online document | Create or import online documents (documents, spreadsheets, mind maps, whiteboards) within DingTalk Docs. ++**Attachments inserted during editing, including images, audio/video, archives, and local files**++ are also counted. | **Officially counted starting July 30, 2023** |
| Shortcut | Add a shortcut within DingTalk Docs. | Not counted |

## 2. Scope of DingTalk Docs capacity calculation

**Capacity calculation covers: "My Docs" and "Knowledge Base".**

*   **My Docs:** Allocated to you by the organization for personal knowledge management, used for individual work knowledge accumulation and management.

*   **Knowledge Base:** Knowledge management organized by company, department, project, etc., used for sharing, collaboration, and organizational knowledge accumulation and management.

## 3. What are local files and online documents?

**Local files:** After being uploaded to the Knowledge Base, local files retain their original format. You can obtain a file link to share them, and some formats support preview.

**Online documents:** Include both newly created online documents and imported online documents.

*   Create online document: Currently supports creating three document types — DingTalk Docs, Spreadsheet, and DingTalk Mind.

*   Import online document: Certain types of local files can be imported into the Knowledge Base and converted to online documents. You can obtain a document link to share them, and they are converted into DingTalk Docs format. Format conversion details:

| **Local File Type** | **Online File Type** |
| --- | --- |
| doc, docx, markdown, mark, md, txt | DingTalk Docs |
| xls, xlsx | Spreadsheet |
| xmind | DingTalk Mind |

## 4. Which file types are currently supported for upload and import? Is there a file size limit?

Uploaded files support previews for multiple file types, with a maximum size of 8 GB per file. Import only supports document types, with a maximum size of 20 MB per file. The differences are as follows:

| **Transfer Method** | **File Type** | **Supported Preview Formats** | **Size Limit** |
| --- | --- | --- | --- |
| Upload | Document | pdf, pptx, ppt, pot, potx, pps, ppsx, dps, dpt, pptm, potm, ppsm, xls, xlt, et, ett, xlsx, xltx, xlsb, xlsm, xltm, csv, doc, dot, wps, wpt, docx, dotx, docm, dotm, txt, xmind | Up to 8 GB per file |
|  | Image | jpeg, bmp, png, jpg, ico, webp |
|  | Audio/Video | 3GP, AVI, FLV, MP4, M3U8, MPG, ASF, WMV, MKV, MOV, TS, WebM, MXF, AAC, AC-3, ADPCM, AMR, DSD, MP1, MP2, MP3, PCM, RealAudio, Windows Media Audio |
|  | Other | zip archive |
| Import | Document | docx, xlsx, doc, xls, txt, xmind, markdown, mark, md | Up to 20 MB per file |

## 6. How do I purchase additional capacity?

Uploading local files to DingTalk Docs (My Docs, Knowledge Base) consumes organization Drive capacity. Inserting images, audio/video, or archives in online documents (documents, spreadsheets, mind maps, whiteboards) also consumes organization Drive capacity. For details, see Section 1, "DingTalk Docs capacity calculation rules" above.

DingTalk grants every organization 100 GB of permanently free Drive capacity by default. If this is insufficient, the organization can purchase additional capacity.
