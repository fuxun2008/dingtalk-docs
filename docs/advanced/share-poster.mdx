When it comes to **designing a poster**, a task many of us dread,

is anyone else like me,

always putting it off until the last minute, then pulling an all-nighter to barely get it done?

That's not because I'm lazy!

Creating a poster means I have to **write the copy**, **gather materials**, and then **arrange the layout**.

And! I have to know how to use design tools such as **Photoshop, Sketch, and Figma**!

But with DingTalk Docs, you can quickly create a poster

even without any design software!

Wouldn't you rather use the time you save to study (~~or slack off~~)?

**Key features used:** **Page settings, high-definition long image, and Highlight block**

**Step-by-step tutorial:**

<Note>
[Priority 1] Create a new DingTalk Doc.

[Priority 2] **Hide the document information.** Hover over the title, click "Page settings," and turn off the title and information bar.

[Priority 3] **Adjust to a poster layout.** In the Layout section of the top-left menu, adjust the document margins and select Narrow.

[Priority 4] **Set the document background color.** Set a background color for the entire document. From the top-left menu, select View > Document background > Fill color (the primary color of your poster).

[Priority 5] **Set up the headline and body text modules.** Insert your poster header image (which you may need to create yourself), then insert a Highlight block to set the background color for the title bar and content bar. Alternatively, type the text first, hover over it, and select Set paragraph color to apply the desired background color to the text.

[Priority 6] **Insert a Divider** to separate different content sections.

[Priority 7] **Generate the image.** Click the "..." in the top-right corner > Download > High-definition long image. Select "Desktop version," choose a style, and click Save image. A beautifully designed poster will be ready in no time!

That's it — a perfect long-image poster, done in just three minutes.

Got it? Give it a try!
</Note>
