Dear users,

When creating work documents, do you still scroll up to the Insert menu every time you need to add an image, a table, or other content?

If you insert content frequently, you end up jumping back and forth between the Body Text and the Insert toolbar.

Today's DingTalk Docs tip solves that problem for you.

Master the "/" shortcut—the key to the document toolbox—

and enjoy a smoother, more seamless authoring experience.

Time to learn!

**Key feature:** **Type "/" in the document Body Text**

<Note>
While editing text in a document, when you need to insert a highlight block, Document, Image, Spreadsheet, and more, simply type "/" in the Body Text to bring up the Insert list. From there, pick any element to drop it straight into your document.

Master "/" and make your content creation even smoother.
</Note>

Got it? Give it a try now!
