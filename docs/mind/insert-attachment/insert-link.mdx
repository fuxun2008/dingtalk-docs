Add links to nodes to enrich Mind Map content and enhance expressiveness.

## Entry point for the Insert Link feature

*   Entry point: Click a node, then select the Add Link icon on the toolbar, as shown below.

## How to add a link

*   Select the node where you want to add a link, then click the link tool on the toolbar.

*   Enter the link in the address input field.

*   Click Confirm to insert the link.

## How to modify a link

*   Select the node whose link you want to modify, then click the link tool on the toolbar.

*   Enter the new link in the address input field.

*   Click Confirm to complete the link modification.

## How to remove a link

*   Select the node whose link you want to modify, then click the link tool on the toolbar.

*   Click Remove Link to remove the previously added link.
