DingTalk Mind supports inserting images in various formats, such as PNG, JPG, and GIF, making it a powerful tool to enhance the expressiveness of mind maps.

## How to Insert Images

*   Insert an image on desktop: In Mind Map view mode, click the Insert Image button on the toolbar to select a local image file to upload.

*   You can also copy a local image file directly and paste it using the shortcut Command + V or Ctrl + V.

## Insert Images on Mobile

*   In Mind Map view mode, tap the Insert Image button on the node toolbar to select an image from your device Album and upload it.
