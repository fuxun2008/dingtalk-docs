The emphasis feature distinguishes and highlights subjects. Use it to draw attention to a specific subject without making the content look abrupt or cluttered.

## Access the emphasis feature

This feature is currently only available on desktop; the mobile version is coming soon. Select a subject and use the emphasis options on the toolbar.

## How to use emphasis

*   Apply bold, italic, or underline to text.

*   Apply background color highlighting to text.

*   Clear all styles with one click.
