The Alias feature provides supplementary descriptions for a Subject. Use it to add brief notes or detailed explanations without affecting the neatness of your mind map.

## Entry point for inserting an alias

Insert Alias is currently available on desktop only; mobile support is coming soon. To use this feature, click the toolbar and edit the alias.

## How to insert an alias

After adding an alias, click the alias content or the **Edit Alias** icon to open the alias editing panel and edit directly.
