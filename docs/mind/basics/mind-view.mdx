---
title: "Edit a Mind Map View"
description: "Learn the core editing operations in DingTalk Mind's mind map view, including editing node text, inserting sibling or child nodes, and touch-based editing on mobile, so you can quickly build and adjust mind map structures."
---

## Edit Content

*   To modify the text of a node, click the node to select it and enter edit mode, then make your changes.

*   You can also double-click a node to select all text at once for easier editing.

## Insert a Sibling or Child Node

*   To insert a child or sibling node after a specific node, select the node first, then click **Insert sibling node** or **Insert child node** in the toolbar that appears.

*   Press **Enter** or **Tab** on your keyboard to quickly insert a sibling or child node.

## Edit Content on Mobile

*   When accessing a mind map on a mobile device, in **Mind Map view** mode, tap a node and then tap the edit button on the node toolbar to enter edit mode.

## Insert a Sibling or Child Node on Mobile

*   In **Mind Map view** mode, select a node and tap the **Insert sibling node** or **Insert child node** button on the node toolbar.
