Use Insert summary to add summary nodes to your mind map, making the content theme clearer.

## Entry Point for Insert Summary

### Desktop

Open **DingTalk desktop > Document > Create or open the target mind map >** click **the target node >** select **the Insert summary icon**.

### Mobile

Open **DingTalk mobile >** tap **More** at the bottom **> Document > Create or open the target mind map >** tap **the target node > Insert summary**.

## How to Use Insert Summary

*   Add a summary: Select the target node and choose the **Insert summary** icon on the toolbar (see the entry points above).

*   Delete a summary: Select the summary node and press Backspace to delete it.
