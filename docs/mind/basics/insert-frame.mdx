The frame feature creates an enclosed area around subjects. Use frames to highlight and emphasize specific subjects, or to convey special concepts to readers, by grouping these subjects together and adding annotations. You can also use frames to associate subjects that share the same attributes.

## Entry point for inserting a frame

This feature is only supported on desktop; mobile support is coming soon. Click the toolbar and select **Frame** to insert a frame.

## Guide to using frames

*   Delete a frame: Hover over a frame and press the Delete key to remove it.

*   Add frame text: Hover over a frame to display the add text icon. Click it to enter text.
