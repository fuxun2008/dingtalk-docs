The outline feature creates an enclosed area around subjects. Use outlines to highlight and emphasize specific subjects, or to convey special concepts to readers, by grouping these subjects together and adding annotations. You can also use outlines to associate subjects that share the same attributes.

## Entry point for inserting an outline

This feature is only supported on desktop. Mobile support is coming soon. Click the toolbar and select **Outline** to insert an outline, as shown below:

## Guide to using outlines

*   Delete an outline: Hover over an outline and press the Delete key to remove it.

*   Add outline text: Hover over an outline to display the add text icon. Click it to enter text.
