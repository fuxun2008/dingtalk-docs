## Edit in outline view on desktop

*   Click the Outline view button on the left to switch to outline view mode.

## Insert a sibling node

*   Select the position where you want to insert a node, then press Enter to insert a node at the same level as the currently selected position.

## Indent right/left by one level

*   Select the target node, press Tab to indent right, or press Shift + Tab to indent left.

## Delete a node

*   Select the target node and press Delete to remove its content. When the cursor is at the very beginning of the node content, the entire node will be deleted and its content will be merged into the previous node.

## Multiselect nodes

*   Press and hold the left mouse button, and drag across the nodes to select them.

## Drag a node

*   Press and hold the small dot in front of a node to drag it to the desired position.

## Expand/collapse

*   Hover over the target node and click the small triangle on the left to expand or collapse it.

## Edit in outline view on mobile

*   Tap the Outline view button at the top to switch to outline view mode.

## Indent right/left by one level

Two methods are supported:

1.  Swipe left or right on the node you want to indent to indent it left or right.

2.  Tap the indent left/right tool on the toolbar.

## Create a node duplicate

*   Tap the Create node duplicate button on the toolbar to duplicate the currently selected node along with its child nodes.

## Expand/collapse

*   Two methods are supported:

1.  Select a node with child nodes, then tap the small triangle to the left of the node.

2.  Tap the expand/collapse tool on the toolbar.

## Delete a node

*   Two methods are supported:

1.  Select the node and use the delete key on the soft keyboard.

2.  Tap the Delete button on the toolbar to delete the current node along with its child nodes.

## Undo/redo

*   Use the Undo/Redo buttons on the toolbar to undo or redo previous actions.
