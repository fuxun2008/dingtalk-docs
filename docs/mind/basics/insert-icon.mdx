Add icons to a node to visually enhance it (for example, set tags, priorities, emojis, or tasks).

## Add an icon

*   Click the **Add mark** Button on the node toolbar to open the icon panel, then click an icon to insert it into the node.

*   Icons are divided into four types: Tag, Priority, Emoji, and Task. You can insert up to one icon of each type into a node.

*   If the node already contains an icon of a certain type, clicking another icon of the same type will Replace the current one. For example, the Selected node already has a Task icon. Clicking the third Task icon on the panel replaces the existing icon.

*   Click **Remove all marks** on the panel to clear all icons from the node.

## Replace or delete an icon with shortcuts

*   After inserting an icon into a node, click the icon directly to open a pop-up panel where you can quickly Replace or Delete it.

## Edit icons on mobile

*   In DingTalk Mind mode, select a node and tap the Button on the toolbar to open the icon panel. The insertion rules are the same as on desktop.

*   Tap an icon on the node to open the icon panel for editing.
