Rename the title of a created file for easier organization across various scenarios.

## Instructions

*   Renaming the title requires Edit or admin Permissions for the current file. On desktop, click the title area at the top to rename the title.

*   On mobile, tap the [...] icon in the upper-right corner, select Rename, and edit the File Name in the pop-up window.
