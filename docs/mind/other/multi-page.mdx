description: "DingTalk Mind's multi-page mode lets you create multiple named canvases within a single file, freely splitting topics across pages so complex project plans can be organized and shared from one place."
---

## Value

Add multiple canvases directly within a mind map file to freely split different subjects, organize content more clearly, and present your ideas in an orderly way.

## Use case

Ding Sanduo heads the campaign planning department at an advertising agency and uses DingTalk Mind daily to create marketing plans, campaign proposals, and more. Previously, a single project proposal required multiple mind maps, making sharing and collaboration inconvenient. With the multi-page mode now supported in Mind Map, you can add multiple canvases within a single mind map file, split subjects freely, and rename canvases, making content sharing easier.

## Instructions

At the bottom of the mind map canvas, click the + icon to add a new canvas. You can add multiple pages, as well as delete or rename them.
