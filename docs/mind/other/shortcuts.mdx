When creating a mind map, shortcuts help you input content more efficiently by reducing the need to switch between mouse and keyboard.

## Usage Notes

*   Select one or more nodes, then press the shortcut. Shortcuts unrelated to nodes can be used without selecting any content.

## Mind Map View Mode

*   macOS:

| Category | Function | Shortcut |
| --- | --- | --- |
| Common | Insert sibling node | Enter |
|  | Insert child node | Tab |
|  | Insert parent node | Shift + Tab |
|  | Delete node | Delete, Backspace |
|  | Node navigation | ↑↓←→ |
|  | Undo | ⌘ + Z |
|  | Redo | ⌘ + Y |
| Node actions | Copy node | ⌘ + C |
|  | Cut node | ⌘ + X |
|  | Paste node | ⌘ + V |
|  | Duplicate node | ⌘ + D |
|  | Expand/Collapse | ⌘ + . |
| Navigation | Zoom in | ⌘ + + |
|  | Zoom out | ⌘ + - |
|  | Enter presentation mode | ⌘ + Shift + P |
|  | Shortcut helper | Control + H |
