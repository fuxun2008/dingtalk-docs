In DingTalk Mind, use the Comments feature to comment on node content and @mention users, so information flows freely across your team.

## Entry point

*   Click **Expand Comments** in the left toolbar to view all comments.

## How to add a comment

*   Select the node you want to comment on, then click the Insert Comment button in the toolbar.

*   In the Text Box on the right panel that appears, enter your comment on the Selected node.

*   You can also click the @ Button, or type the @ symbol directly, to Select the user you want to notify.

## Comment Notifications and locating

*   After a comment is sent, a notification is sent to the @mentioned user in the DingTalk Chat window.

*   Click **View Now** to automatically jump to the node where the comment was posted. The right panel also scrolls to the corresponding comment.
