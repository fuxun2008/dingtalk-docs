## Value

Inline comments in documents support image uploads. A picture is worth a thousand words, enabling clear expression and efficient collaboration.

## Use case

Ding Sanduo is a product operations specialist at an internet company. In daily work, he uses DingTalk Docs to interact and collaborate with colleagues. Now that inline comments support image uploads, content that is hard to express in words—such as data analysis or project progress—can be conveyed directly by inserting images into comments, improving collaboration efficiency among colleagues.

## Instructions

When adding a comment, click the image icon to insert an image into the comment.
