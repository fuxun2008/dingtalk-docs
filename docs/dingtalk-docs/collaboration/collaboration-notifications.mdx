## Value

Document blue-bar notifications are now available in the IM Chats list, helping you stay on top of collaboration messages for efficient work.

## Use case

Too busy to check document collaboration in time? When someone @mentions you in a document, a blue-bar notification appears in the IM Chats list so you can spot collaboration messages at a glance.

## How it works

When you receive a document message notification, a blue-bar notification for the latest message appears in the IM Chats list.
