## Value

In dual-screen mode, two documents can be edited at the same time, eliminating the need to switch between pages and making editing and proofreading more efficient.

## Use cases

Ding Sanduo is a copy editor at a new media company who uses DingTalk Docs daily to proofread and review various manuscripts and write articles. With dual-screen mode in DingTalk Docs, there is no need to switch between document pages when proofreading or reviewing manuscripts. When writing articles, reference materials can also be consulted in sync within dual-screen mode, making work easier and more efficient.

## Instructions

Open Document A, then click Document B inserted within Document A to enter dual-screen mode. In dual-screen mode, both documents can be edited simultaneously.
