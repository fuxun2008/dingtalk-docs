The shortcuts currently supported in Docs are listed below. You can also click the keyboard icon in the bottom-right corner of a document to display some of the shortcuts.

| Category | Function | Mac | Windows |
| --- | --- | --- | --- |
| Text formatting | Bold | ⌘ + B | Ctrl + B |
|  | Italic | ⌘ + I | Ctrl + I |
|  | Strikethrough | ⌘ + Shift + X | Ctrl + Shift + X |
|  | Underline | ⌘ + U | Ctrl + U |
|  | Superscript | ⌘ + . | Ctrl + . |
|  | Subscript | ⌘ + , | Ctrl + , |
|  | Increase font size | `⌘ + Shift + >` | `Ctrl + Shift + >` |
|  | Decrease font size | `⌘ + Shift + <` | `Ctrl + Shift + <` |
|  | Copy text formatting | ⌘ + Shift + C | Ctrl + Shift + C |
|  | Paste text formatting | ⌘ + Shift + V | Ctrl + Shift + V |
|  | Clear Formatting | ⌘ + \ | Ctrl + \ |
| Insert | Mention someone | @ | @ |
|  | Hyperlink | ⌘ + K | Ctrl + K |
| Paragraph formatting | Title | ⌘ + Option + \[1-4\] | Ctrl + Alt + \[1-4\] |
|  | Body Text | ⌘ + Option + 0 | Ctrl + Alt + 0 |
|  | Numbered List | ⌘ + Shift + 7 | Ctrl + Shift + 7 |
|  | Bulleted List | ⌘ + Shift + 8 | Ctrl + Shift + 8 |
|  | Task list | ⌘ + Shift + Y | Ctrl + Shift + Y |
|  | Increase indent | Tab | Tab |
|  | Decrease indent | Shift+tab | Shift+tab |
|  | Align left | ⌘ + Shift + L | Ctrl + Shift + L |
|  | Center Align | ⌘ + Shift + E | Ctrl + Shift + E |
|  | Align right | ⌘ + Shift + R | Ctrl + Shift + R |
|  | Justify | ⌘ + Shift + J | Ctrl + Shift + J |
| Edit | Undo | ⌘ + Z | Ctrl + Z |
|  | Redo | ⌘ + Y | Ctrl + Y |
|  | Find | ⌘ + F | Ctrl + F |
|  | Find and Replace | ⌘ + H | Ctrl + H |
| Other | Enter presentation mode/full screen | ⌘ + Shift + P | Ctrl + Shift + P |
|  | Zoom in (presentation mode) | ⌘ + + | Ctrl + + |
|  | Zoom out (presentation mode) | ⌘ + - | Ctrl + - |
|  | Print | ⌘ + P | Ctrl + P |
