## User guide

When creating a document, select Import as online document, then choose a local .md file to import it into DingTalk Docs.

## Supported formats

### File formats

The following three file formats are supported:

.markdown

.mark

.md

### Encoding

Only files encoded with the UTF-8 character set are supported.
