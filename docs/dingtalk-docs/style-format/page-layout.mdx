Different documents require different page layouts for daily work. Page layout is one of the key options for document formatting.

## Instructions

### Set Page Margins

In the top navigation bar, select **Menu - Layout - Margins** to set the page margins of the document.

### Set Page Orientation

In the top navigation bar, select **Menu - Layout - Orientation** to set the document to portrait or landscape.

### Set Page Size

In the top navigation bar, select **Menu - Layout - Page size** to set the document to Standard, Extra wide, or Full width.
