Consistent or well-structured paragraph formatting enhances the tidiness of a document and improves visual appeal.

## Instructions

### Change Paragraph Alignment

Select the paragraph you want to change, then choose an alignment option from the top toolbar, or click **Menu > Format > Horizontal align** in the top navigation bar and select the desired alignment.

### Change Line Spacing

Select the lines you want to change, click the **Line height** option in the toolbar, and choose a line spacing value. Alternatively, click **Menu > Format > Line spacing** in the top navigation bar and select the desired spacing value.

### Adjust Text Indentation

Select the text line you want to indent (you can place the cursor anywhere on the line), then click the **Indent** icon in the toolbar to decrease or increase the indentation. You can also use the shortcuts **Ctrl + [** or **Ctrl + ]**. Alternatively, click **Menu > Format > Indent** in the top navigation bar, and select Increase indent or Decrease indent.
