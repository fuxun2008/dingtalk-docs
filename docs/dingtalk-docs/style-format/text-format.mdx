Formatting text adds variety to your documents. Apply different formats based on content to create a clear visual hierarchy, helping readers quickly identify key points and better understand the content.

## Instructions

DingTalk Docs supports the following text formats:

Text formats include font, font size, bold, italic, underline, strikethrough, superscript, subscript, font color, and text highlight color.

## Adjust font and font size

*   Select the target text, then click the **font box** in the toolbar to choose a font.

*   Select the target text, then click the **font size box** to adjust the font size. You can also use **A**^**+**^ and **A**^**\-**^ for quick adjustments. Each click changes the font size by 2 points.

    ## Adjust text style

    You can apply bold, italic, underline, strikethrough, superscript, and subscript from the menu bar, or select the target content and apply the formatting directly.

    ## Adjust text color

*   Click **Font Color**, then select a font color from the pop-up color panel.

*   Click **Text Highlight Color**, then select a highlight color from the pop-up color panel.
