When editing documents, if a single subject contains multiple items, add a bullet list or numbered list to organize the content in order and make the hierarchy clearer.

## Instructions

## Add a list

In the toolbar, click the corresponding icon to add a Bullet List, Numbered List, or task list.

## Edit a list

DingTalk Docs supports changing the bullet style and Numbering type. Click the dropdown arrow next to the corresponding action in the toolbar, or click the action icon, to configure the settings.
