---

**DingTalk Docs** is deeply integrated with DingTalk to make collaboration more efficient. DingTalk Docs lets you mention others with @ inside a document. **Type @ + username directly** in the Body Text or Comments to send a DingTalk chat notification, reminding the recipient to review the document or comment. Recipients can click the chat notification to jump straight to the target area of the document. Activity plans or Important documents that previously required a dedicated Meeting can now be discussed and edited by multiple people anytime, anywhere in DingTalk Docs—dramatically boosting daily productivity.

## Instructions

1.  Place the cursor where you want to mention someone in the document and **type "@"**. The Contacts panel opens automatically. Select the User you want to mention, and then choose the recipients to notify.

2.  Click **Send** in the dialog to notify the recipients via DingTalk chat to review or comment. Recipients can click the DingTalk chat notification to jump directly to the specified location in the document.
