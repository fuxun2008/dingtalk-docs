Associate DingTalk Project with a DingTalk Docs document to support project review and tracking.

## Instructions

In the document, select the location where you want to add the project Kanban. Click **Insert -> Project Kanban** on the top navigation bar, then select the project you want to insert in the Project Kanban picker. The project details, such as **tasks, status, and assignees**, are displayed directly within the document. You can also configure Sort and Filter settings on the project Kanban.
