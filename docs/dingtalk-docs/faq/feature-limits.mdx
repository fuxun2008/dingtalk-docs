## Common Limits for DingTalk Docs

---

### How Many Users Can Simultaneously Edit a Single DingTalk Document Online?

Answer: The number of concurrent online editors for DingTalk files follows these rules: DingTalk Standard/Startup Edition: 25 users; DingTalk Professional Edition: 50 users; DingTalk Exclusive Edition: 200 users.

_(Note: If multiple users edit the same Location simultaneously, the content saved by the system is based on the most recent edit.)_

### How Many Users Can Simultaneously Read a Single Document?

Answer: There is no limit on the number of concurrent viewers.

### What Is the Maximum File Size for Uploading or Previewing a Single File in DingTalk Docs?

Answer: Both Upload and Preview File Size limits are 251 MB.

### What Is the Maximum Attachment Size in DingTalk Docs?

Answer: The maximum Attachment size in DingTalk Docs is 3 GB.

### How Many Characters Can a Single DingTalk Document Contain?

Answer: 500,000 characters.

### What Is the Export Limit for DingTalk Docs?

Answer: The Export will Fail if it takes longer than 30 seconds.

## Common Limits for Spreadsheet

---

### What Is the Worksheet Limit for a Single Spreadsheet?

Answer: 1,000 Worksheets.

### What Is the Size Limit for a Single Attachment?

Answer: The Attachment size limit for Standard Edition is 251 MB, and for DingTalk Professional Edition is 1 GB.

### What Is the Size Limit for a Single Image?

Answer: 20 MB.

### How Many Users Can Simultaneously Edit a Single Spreadsheet?

Answer: A single Spreadsheet supports up to 800 concurrent online editors.

### How Many Conditional Formatting Rules Are Supported in a Single Worksheet?

Answer: 200.

### What Is the Maximum Number of Cells in a Single Spreadsheet?

Answer: 5 million Cells.

### What Is the Maximum Number of Characters That Can Be Added to a Single Cell?

Answer: 50,000.

### What Are the Export/Import Limits for a Single Spreadsheet?

*   Import: xlsx and xls files under 20 MB

*   Export: Up to 200 Images can be exported per Spreadsheet; any additional Images will be replaced with placeholders.

### How Many Function Formulas Are Supported in Spreadsheet?

Answer: 405.

## Common Limits for DingTalk Mind

---

### How Many Nodes Can Be Inserted into a Single Mind Map?

Answer: There is no limit, but we recommend no more than 1,000 nodes for optimal performance.

### How Many Users Can Simultaneously Edit a DingTalk Mind Map?

Answer: There is no limit.

## Common Limits for Knowledge Base

---

### What Is the Creation Limit for Knowledge Bases?

Answer: There is no limit.

### What Is the Maximum Number of Users That Can Be Added to a Single Knowledge Base?

Answer: 2,000 Users.

### How Many Folders Can Be Created Under a Single Knowledge Base Table of Contents?

Answer: There is no limit.

### How Many Documents, Spreadsheets, or Mind Maps Can Be Created in a Single Folder?

Answer: There is no limit.

### What Is the Document Storage Limit for Knowledge Base?

Answer: Each Organization receives 100 GB of Free initial storage, with paid expansion available. [Learn more](https://docs.dingtalk.io/i/p/nb9XJowOkBRPmyAp/docs/3KLw95QMzkb8gRX5wpANJAjrymPeEN2q)

### How Many Files and Folders Can Be Uploaded or Imported at Once?

Answer: 100.

## Common Limits for Drive

---

### What Is the Storage Capacity of Drive?

Answer: Each Organization receives 100 GB of Free initial storage, with paid expansion available. [Learn more](https://docs.dingtalk.io/i/p/nb9XJowOkBRPmyAp/docs/3KLw95QMzkb8gRX5wpANJAjrymPeEN2q)

### How Many Files and Folders Can Be Stored in My Space?

Answer: The default capacity limit for an Employee's "Drive - My Files" is 2 GB. The Organization Admin can manually adjust this in the admin console.
