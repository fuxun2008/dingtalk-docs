---
title: "How to view edit history"
description: "Track and restore DingTalk Docs edit history to prevent accidental data loss in collaborative editing."
---

When working on DingTalk online documents, you may worry about accidental deletions or incorrect edits during multi-user collaboration. To minimize such risks, DingTalk Docs supports viewing edit history. It saves each user's revisions in real time, lets you view previous versions at any time, and supports selective rollback, effectively enhancing content security.

## Instructions

### View edit history

Click **Document** → **┇ in the upper-right corner** → **History**. The history panel appears on the right side of the document, where you can view the edit history of the document and selectively roll back to a previous version.

### Restore a previous version

In the history view, click the **Restore** button next to the corresponding version to revert the document to that version.

### Exit the edit history view

In the upper-left corner of the history view, click the exit button to leave the view. You can also press **Esc** to exit quickly.

## Additional notes

*   If a document has been deleted, its edit history cannot be viewed.

*   The number of days for which version history can be viewed and restored varies by edition:

**DingTalk Standard / Startup Edition**

3 days

**DingTalk Professional Edition**

30 days

**DingTalk Exclusive Edition**

30 days

**DingTalk Office Suite**

180 days
