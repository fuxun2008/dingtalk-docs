The web version of DingTalk Docs does not support browsers based on the IE engine. For a better experience with DingTalk Docs, choose a supported browser type as needed. Setting a supported browser as the default in your system delivers a smooth and complete DingTalk Docs web experience.

Learn more: [How to change the system default browser](/zh/docs/dingtalk-docs/settings/set-default-browser)

## 1. Windows

| **System version** | **Supported browsers** |
| --- | --- |
| **Windows 7, 8, 8.1, and 10** | *   [Chrome](https://www.google.cn/chrome/): version 63.0 or later <br />    <br />*   [Microsoft Edge](https://www.microsoft.com/zh-cn/edge) (new version) <br />    <br />*   [QQ Browser](https://browser.qq.com/) (Speed mode): version 10.0 or later <br />    <br />*   [360 Speed Browser](https://browser.360.cn/ee/) (Speed mode) |
| **Windows XP** | *   [360 Speed Browser](https://browser.360.cn/ee/) (Speed mode) |

## 4. How to change the default browser

### Windows

1.  Click the Start Button, click Settings, and then type "Default apps."

2.  In the search results, select Default apps.

3.  Go to Apps > Default apps > Web browser, select the browser you want to set as the default, click Set this program as default, and click Switch anyway when prompted to Complete the setup.
