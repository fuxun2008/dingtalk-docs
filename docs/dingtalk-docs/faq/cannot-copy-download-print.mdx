---
title: "Why Can I Still Not Copy, Download, or Print a Document Even with View/Download Permission?"
description: "FAQ: why you cannot copy, download, or print a document even with View/Download permission. Typically, an admin has restricted these operations via security permission settings. Contact your document or Knowledge Base admin to restore access."
---

## Cause

By default, Collaborators with View/Download permission or higher can copy body text, download, print, and create copies of a document. If you have the permission but still cannot copy, download, or print the document, **the main reason is:**

The document or Knowledge Base Admin has set **"Only users with Manage permission can download, create copies, and print / No one can download, create copies, or print"** in the Permissions configuration, which overrides the default rules.

In this case, even if a User has View/Download permission for the document, they cannot copy the body text, download, print, or create copies. When attempting these actions, a prompt will appear.

## Solution

Contact the document or Knowledge Base Admin to update the permission Settings for the document or Knowledge Base. For more information about document permission Settings, see Permissions configuration for sharing, copying, downloading, and commenting.
