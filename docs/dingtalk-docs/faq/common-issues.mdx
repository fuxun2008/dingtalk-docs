## Q: Does DingTalk Offer Online Editing?

A: Yes. DingTalk offers a creation suite including DingTalk Docs, Spreadsheet, Mind Map, Whiteboard, and AI Table, all of which support real-time collaborative editing.

## Q: What Is DingTalk Docs?

A: DingTalk Docs is an enterprise collaboration office suite independently developed by **Alibaba Group** DingTalk. It includes online creation and document management tools such as **Docs, Spreadsheet, Mind Map, AI Table, Whiteboard, and Knowledge Base**. No downloads are required—edit and view files directly on your computer, phone, or tablet, with content saved in real time. DingTalk Docs is also **deeply integrated with DingTalk**, enabling efficient collaboration with colleagues based on your organizational structure. Daily work scenarios such as **information collection, project management, meetings, business reports, and employee onboarding** can all be efficiently completed through DingTalk Docs.

## Q: How Do I Configure the Document Toolbar Style?

A: Click "┇" in the upper-right corner, then go to "Preferences" — "Interface Preferences" — "Top Toolbar". You can choose a two-row toolbar, single-row toolbar, or no toolbar based on your preferences.

## Q: How Do I View the History of DingTalk Docs/Spreadsheet?

A: When using DingTalk Docs or Spreadsheet, you can view the history through the following settings:

DingTalk Docs: Upper-right corner — ┇ — History. Alternatively, refer to "Question 3" above to configure the toolbar.

Spreadsheet: Upper-right corner ... — History. History currently supports viewing previous versions and restoring them.

## Q: How Do I Download DingTalk Docs/Spreadsheet to My Local Device?

A: Open DingTalk Docs on the desktop client and download the online document as a local file using the following methods:

DingTalk Docs: Upper-right corner — ┇ — Download to local. Currently, .docx, .pdf, and .md formats are supported. If you cannot find the toolbar, refer to "Question 3" above to configure it.

Spreadsheet: Top toolbar — Menu — Spreadsheet — Download as. Select the desired file format to download.

Tips: Docs currently supports exporting to Word/PDF. Spreadsheet currently supports exporting to Excel/PDF/CSV/TSV formats.

## Q: How Do I Activate DingTalk Docs?

A: The DingTalk Docs (online editing) feature does not require activation. Simply sign in to DingTalk and complete organization authentication to use online editing.

## Q: How Do I Insert Images in DingTalk Docs?

A: DingTalk Docs currently supports inserting emojis, images, video links, attachments, links, DingTalk Mind, roadmaps, flowcharts, online documents from Drive/Knowledge Base, links, and more. The mobile client supports fewer insertion types—use the desktop client for more types.

**Desktop client:** Open DingTalk Docs, click "+" in the top toolbar, and select Insert Image. Alternatively, enter edit mode, type a slash "/", and select Insert Image.

**Mobile client:** Open DingTalk Docs online editing, tap the icon in the bottom toolbar — [Insert Image] \ [Insert Link]. The mobile client currently supports inserting images, tables, links, and horizontal lines, but does not support inserting files.

## Q: How Do I Configure Document Edit Permissions?

A: Click [Share] in the upper-right corner, go to "Manage permissions" under "Invite collaborators". You can assign permissions to specific users, including: Manage, Edit, View/Download, View only, and Remove permission.

## Q: Why Don't Some Employees Have Online Editing?

A: If online editing is unavailable, please verify the following:

1. DingTalk Lite does not support online editing.

2. Online editing only supports system languages set to Simplified Chinese or English. We recommend switching the language accordingly.

3. For Office files uploaded locally to DingTalk, if you choose to edit with the official Microsoft editor, you must purchase the DingTalk Office Suite Premium Edition.

4. Anheng MiDun is not compatible with this product. If your organization has enabled Anheng MiDun, online editing will not be available (check whether there is a small shield icon in the lower-right corner of the file).

5. Online editing currently supports Microsoft Office Word, Excel, and PPT files (PPT online editing is only available on the desktop client). Files in other formats do not support online editing—please download them before editing.

6. DingTalk Standard online editing only supports opening files smaller than 20 MB. If a file is too large, you may see messages such as "Failed to get edit link" or "File too large".

## Q: Can DingTalk Docs Be Opened in a Browser?

A: The DingTalk Docs web version is now available. You can copy the link and open it in a browser at: https://docs.dingtalk.io/. You can also set documents to open automatically in a browser. For instructions, see: [Open DingTalk Docs in a browser](/docs/dingtalk-docs/settings/open-in-browser)

## Q: How Do I Recover Lost Data?

A: Open DingTalk Docs, click ┇ in the upper-right corner — History, and find the version you want to restore under [Version history]. Once located, click the [Restore] button to complete the recovery.
