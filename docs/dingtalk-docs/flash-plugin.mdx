## 1. About DingTalk Docs Flash

Found great content while browsing the web and want to save it? DingTalk Docs Flash lets you save the body text of the current page to DingTalk Docs in one click, so you can read it anytime, anywhere. It also automatically removes floating ads and irrelevant links, freeing you from clutter and enhancing your reading experience.

## 2. How to use it

DingTalk Docs Flash currently supports the following browsers. Install the plugin package, then open the browser to start using it:

360 Speed Browser, 360 Secure Browser, Chrome, and Edge.

## 3. Plugin installation guide

## 3.1 Install on Chrome

### Method 1 (Recommended):

Install from the plugin store. [Click here to visit the Chrome Web Store](https://chrome.google.com/webstore/detail/%E9%92%89%E9%92%89%E6%96%87%E6%A1%A3%E9%97%AA%E5%AD%98/dfaldmjkfklnkenddjpikfkdnkinheke).

### Method 2:

Step 1: Click to download the plugin package, then unzip it to obtain the DingTalk Docs Plugin.crx file.

Step 2: Open Chrome and go to the **⋮ icon** in the top-right corner > **Extensions** > **Manage Extensions** to access the extension management page.

Step 3: Drag the DingTalk Docs Plugin.crx file from Step 1 into the extension management page.

Note: After installation, the DingTalk Docs Flash icon will appear on the extension management page. Click the **Extensions** icon on the toolbar, then click the **Pin** icon next to DingTalk Docs Flash in the extension list to pin the plugin to the toolbar.

## 4. How to use DingTalk Docs Flash

## 4.1 Sign in

On any website whose content you want to flash-save, click the DingTalk Docs Flash plugin icon. If you are not signed in, the plugin will prompt you to sign in and open a new tab. Sign in to DingTalk Docs in the new tab, then continue using the plugin.

## 4.2 Flash save

Once signed in, click the DingTalk Docs Flash plugin icon and the plugin will start saving the current page. Saved documents are stored under the **My Docs / Flash Saves** folder of the signed-in account.

After the flash save is complete, a result popup will appear on the page showing the article summary and save location. Click **Edit** to the right of the save location to open the DingTalk Docs personal center and change the save location.

## 4.3 Choose a save location

If your signed-in account belongs to multiple organizations, right-click the plugin menu and click **Set Flash Save Location** to open the DingTalk Docs personal center and configure the setting.
