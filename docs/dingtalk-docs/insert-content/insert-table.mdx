When working in a document, you may need to insert a table to present data more intuitively.

## Instructions

## Add a table

In the toolbar, click **Insert > Table**, or click the **Insert Table icon** in the toolbar. Then select the number of rows and columns to insert a table into the document.

## Delete a table

Select the table you want to delete, click the icon in the top-left corner of the table, and then click Delete. You can also right-click and choose **Delete rows/columns > Delete Table**.

## Add or delete rows and columns

### Add rows or columns

Hover over the space between header rows or columns to show the insert icon, and click it to quickly add a row or column. You can also right-click and select **Insert a row above/below** or **Insert a column to the left/right**.

### Delete rows or columns

Select the row or column you want to delete, click the **shaded area in the header** of the row or column to show the delete icon, and click it to remove the row or column. You can also select the row or column and then right-click and choose **Delete selected row/column**.

## Merge and unmerge cells

### Merge Cells

Select the cells you want to merge, then click the **Merge Cells icon** in the toolbar to merge them.

### Unmerge Cells

Select a merged cell, then click the unmerge option in the toolbar to split it back into separate cells.

## Adjust the table

### Fill a cell with color

Select a cell, or an entire row or column, then click the **Cell background color** option in the toolbar to change the cell color.

### Set cell borders

Select a cell, or an entire row or column, then click **Table borders** in the toolbar to set the color and line style of the cell borders.

### Adjust row height or column width

Select the border of the row or column you want to adjust. Click and drag it to resize.

### Set table alignment

*   **Apply to all cells:** Click the icon in the top-left corner of the table to quickly select the entire table, then click **Align** in the toolbar to apply the alignment uniformly.

*   **Apply to specific rows or columns:** Select the target row, column, or cell, then click **Align** in the toolbar.

### Wrap content within a cell

Select the target cell and press **Enter** to quickly insert a line break.
