## Value

Structure your articles clearly, aid comprehension, and combine creativity with efficiency in document layout.

## Use cases

Tired of the traditional bullet point? Don't worry. DingTalk Docs lists now include an emoji series, offering a variety of creative options that blend efficient work with aesthetic appeal. Open a document, switch to a new list style, and bring fun into your workflow.

## Instructions

Quick mode

1. Enter a Numbered List or Bulleted List.

2. Click the list marker to switch styles.

3. Find the emoji list in the Bulleted List styles and click to switch.

Advanced mode

1. Toolbar — Bulleted List — Style — Select emoji list.

2. Toolbar — Numbered List.
