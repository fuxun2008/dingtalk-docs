To make spreadsheets within a document more intuitive, you can use the Insert Image feature. Adding images can also enhance the document's visual appeal.

## Add an image

In the top navigation bar, click **Insert > Image**, or click **Image** on the toolbar to upload a local image to the document.

## Edit an image

Click an image to open the image toolbar and configure the relevant settings. The following actions are currently supported:

*   Extract text from the image

*   Download the image

*   Set the image style

*   Set the image size

*   Crop the image

*   Image description

*   Add a link

*   Rotate the image

*   Horizontal alignment

*   Replace the image
