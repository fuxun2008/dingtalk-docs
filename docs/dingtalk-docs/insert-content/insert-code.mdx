---
title: "Insert code"
description: "DingTalk Docs code block: insert syntax-highlighted code via Insert > Code block on the toolbar. Supports 50 programming languages with switchable light and dark themes, ideal for technical documentation and developer guides."
---

DingTalk Docs supports inserting code blocks into documents. Click **Insert > Code block** on the toolbar to insert a code block. 50 programming languages are supported, and code blocks can be styled with Light or Dark themes.
