DingTalk Docs supports inserting **Tex** mathematical formulas into documents.

## Add a formula

1.  Click **Insert > Formula** in the top navigation bar, then type the code in the formula editor area to see the corresponding mathematical formula in real time.

2.  Click an inserted formula and press **Backspace** to delete it quickly.
