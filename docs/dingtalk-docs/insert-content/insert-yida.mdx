## Instructions

In DingTalk Docs, insert a **YiDA link** to display YiDA page information directly with synchronized updates. Use the Doc shortcuts "/", "+", or "Insert" to quickly select and insert the corresponding YiDA page.

## 1. Copy the YiDA page link

<Note>
Currently, only **YiDA publicly accessible pages** and **DataV pages** are supported. Other YiDA page links are not yet supported.
</Note>

## 2. Insert in DingTalk Docs

In your DingTalk Doc, use the shortcuts "/", "+", or **Insert** to open the insertion panel, select **YiDA**, and paste the YiDA page link copied above.

## 3. Content displayed in the Card

1.  The DataV page is rendered as an embedded dashboard card.

2.  The YiDA Standard Form / Process Form page is rendered as an embedded form card.
