title: "Insert attachments"

---

Inserting attachments into a document saves time, eliminates duplicate editing of documents with the same content, and helps readers better understand specific terms or data. DingTalk Docs supports inserting different types of documents as attachments for viewing and editing.

## Insert local or Drive files

Click **Insert > File** in the top navigation bar, or click **Upload File** in the toolbar. From the drop-down menu, select **Local file** or **Drive file** to upload the attachment from the corresponding location to the document.

## Attachment preview

Audio, video, and Office files inserted into the document can be previewed online directly, without downloading.

## Attachment view settings

Attachments inserted into the document support different display styles (currently available on PC only):

*   **Icon text link**

*   **Summary card**

*   **Preview card**

## Additional notes

The maximum file size supported for upload is currently 251 MB. The file formats supported for online preview are as follows:

| Image formats | jpg, jpeg, png, bmp, gif |
| --- | --- |
| Document formats | doc, docx, xls, xlsx, ppt, pptx, pdf |
| Video formats | mp4, egg, webm, mov |
| Audio formats | mp3 |
