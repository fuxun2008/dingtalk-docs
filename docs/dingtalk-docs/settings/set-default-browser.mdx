**Overview**

For a better DingTalk Docs web experience, set a DingTalk Docs-supported browser as the default browser on your system. The instructions below are for reference only. Refer to the actual interface for accurate steps.

## 1. Windows

1.  Click the **Start** button, then click **Settings**.

2.  Select **Apps**.

3.  Go to **Apps** **\>** **Default apps** **\>** **Web browser**, select the browser you want to set as default, click **Set this program as default**, and click **Switch anyway** when prompted to complete the setup.

## 2. macOS

*   Step 1: Open **System Settings** and go to **Desktop & Dock**.

*   Step 2: Locate **Default web browser** and select the browser you want to use by default.

## 3. How to set the default browser for opening DingTalk Docs

When using DingTalk, you can choose to open, view, and edit documents in a web browser based on your preferences.

*   **Windows:** Open **DingTalk** **\>** click the **Profile Photo** in the upper-left corner **> Settings & Privacy > General > DingTalk Docs**, then turn on **Always open documents in browser** to complete the setup.

*   **macOS:** Open **DingTalk** **\>** click the **Profile Photo** in the upper-left corner **> Settings & Privacy > General > DingTalk Docs**, then select **Always open documents in browser** to complete the setup.
