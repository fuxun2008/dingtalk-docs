Edited documents often need to be printed for others to view, such as cooperation proposals or user guides.

## Instructions

## Print entry point

*   On desktop, click the **【┇】** in the navigation bar at the top right of the document **—> Print**, or use the **Shortcut Ctrl+P (Mac: Cmd + P)** to enter the print settings page.

*   Document watermark is supported (enable watermark in the organization admin console). [**Admin Console**](https://oa.dingtalk.io/) **> Document and Storage Management > Permissions and Security > Organization Security Management >** Turn **Document Watermark** On/Off.

*   On mobile, open DingTalk Docs, and tap **"…" - Print** in the top right corner.

## Print permissions

Anyone with access to the document can use the print feature.

## Additional notes

The following elements do not currently support 1:1 printing:

*   Project Kanban

*   Online audio/Video

*   Formula
