During daily work, you may need to send personal documents to others for review. To prevent the content from being tampered with and to protect information security, exporting documents as PDF is an effective solution to these workplace concerns.

## Entry Point for Exporting PDF

Click the ┇ icon in the top-right navigation bar of the document **> Download to local >** **PDF** to download the document as a local PDF file. Body Text and Comments can be exported simultaneously.

## Permissions for Exporting PDF

Anyone with access permissions to the document can export it as a PDF.

## Additional Notes

The following elements do not currently support 1:1 export:

*   Kanban

*   Online audio/Video

*   Formula
