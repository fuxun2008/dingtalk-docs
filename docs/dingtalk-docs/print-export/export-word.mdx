DingTalk Docs supports exporting documents to Word, enabling multi-format preview and editing to fit different working habits.

## Export to Word Entry

In the navigation bar at the top right of the document, click ┇ **> Download to local >** **Word** to export the document as a local Word file. Currently, only the **.docx** format is supported.

## Export to Word Permissions

Anyone with access to the document can export it to Word.

## Additional Notes

The following elements do not yet support 1:1 export:

*   Project Kanban

*   Online audio/video

*   Formula
