title: "Export as Long Image"
description: "DingTalk Docs export as long image: convert your entire document into a scrollable screenshot for easy sharing on messaging platforms, printing, or archiving — no format conversion needed."
---

When you need to share a document with others through another platform or print and post the document content elsewhere, exporting it as an image is a simple and direct option.

## Entry Point for Exporting a Long Image

In the navigation bar at the top right of the document, click ┇ **> Download > HD long image** to open the long image export panel.

The long image export supports two preview modes: **Desktop and Mobile**. You can also choose whether to display the **Title, Author, Last edited time, and Document QR Code** as needed. In addition, different style settings are supported.

## Permissions for Exporting a Long Image

Anyone with access to the document can use the long image export feature.

## Additional Notes

The following elements do not yet support 1:1 long image export:

*   Project Kanban

*   Online audio/video

*   Formulas
