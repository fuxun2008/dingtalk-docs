### 2. Data teleporter: Link to cells or worksheets

Supported platforms: Windows, Mac

As a project manager using a spreadsheet for project management, you typically set up a worksheet as the master Kanban along with multiple worksheets for task details. How do you quickly open the corresponding details from a project name on the master Kanban?

As a top sales representative using a spreadsheet for customer management, how do you quickly view the customer profile from a customer name in the order list?

Now you can try **"Insert Link — Cell / Worksheet"** to index the data you want anytime, anywhere.

You can link to any cell in a spreadsheet for point-to-point navigation, or link to any worksheet for point-to-multiple navigation. Open Spreadsheet now, use "Insert Link" to access your data teleporter, and give it a try.
