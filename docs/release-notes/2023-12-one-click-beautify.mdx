## Say goodbye to manual hassle—automatic heading numbering keeps everything neat and orderly!

Trigger automatic heading numbering with Markdown. When you add, delete, or move headings, the numbers update automatically, improving editing efficiency and making the document structure clearer.

</Note>
[🎬 **Click to watch the feature video**](https://cloud.video.taobao.com/play/u/null/p/1/e/6/t/1/442624364306.mp4)
<Note>

</Note>
[Bulb] Availability: Mac/Windows users

[Notebook] How to use:

1. Markdown is supported. In heading format, type "1." to trigger numbering.

2. Combine the heading with a Numbered List type for the complete automatic heading numbering experience.
