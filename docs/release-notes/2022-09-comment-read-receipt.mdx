title: "2022.09 DingTalk Docs adds Read status for comments"
description: "September 2022 update: Mobile navigation moves to the top bar for a more intuitive layout; comments show read status; iPad gains split-screen editing; Spreadsheet on mobile adds a navigation handle."
---

**DingTalk Docs | New mobile navigation page delivers a dual upgrade in usability and visual experience**

The mobile navigation page of DingTalk Docs has been redesigned, with the navigation bar moved from the bottom to the top. This aligns better with user intuition and provides more content space for quickly viewing document information.

💡 Availability | Mobile

📖 How to use: On mobile, access the document home page from the **Collaboration** tab.
---

**DingTalk Docs | Read status for comments delivers more timely feedback**

Ever leave a comment on a document and hear nothing back? DingTalk Docs has been upgraded so that @ People mentions in comments now display Read and Unread status, helping you track feedback and work more efficiently.

💡 Availability | Desktop

📖 How to use: When you @ a person in a DingTalk Docs comment, a small circle appears. Once the mentioned person opens the document and sees the comment, the circle changes to ☑️ to indicate Read.
---

**DingTalk Docs | Split-screen and full-screen support for Docs on iPad**

DingTalk Docs is now optimized for iPad. While editing a document on iPad, you can enable split screen with one tap for a more convenient creation experience.

💡 Availability | iPad

📖 How to use: While entering text on iPad, select the split-screen option in the upper-left corner.

## Spreadsheet | Mobile "navigation handle" for a smoother, more enjoyable experience

Tired of tapping the wrong Cell while browsing or editing spreadsheets on mobile? The mobile experience of Spreadsheet now includes a "navigation handle" on the keyboard. Drag the handle to quickly switch between cells, reducing mis-taps and improving editing efficiency.

💡 Availability | Mobile

📖 How to use:

Entry point: In Spreadsheet on mobile, open the keyboard. The navigation handle appears in the center of the keyboard.

Press and drag to quickly switch between cells.

## DingTalk Calendar | Mobile widget support

The mobile app now supports home screen widgets and iOS 16 lock screen widgets, so you can see Important events at a glance and stay organized.

💡 Availability: Mobile

📖 How to use:

Long-press an empty area on the iOS home screen, then tap the "+" icon in the upper-left corner.

Search for "DingTalk" and select the DingTalk Calendar widget.

Tap **Add Widget** to place it on the home screen.
---

**DingTalk Mail | Mobile home screen widget support**

Add the widget with one tap to quickly browse your inbox and jump to read or compose emails, making mail handling more efficient.

💡 Availability: Mobile

📖 How to use:

1. Long-press an empty area on the iOS home screen, then tap the "+" icon in the upper-left corner.

2. Search for "DingTalk" and select the DingTalk Mail widget.

3. Tap **Add Widget** to place it on the home screen.
