**Release notes**

DingTalk Docs

DingTalk now supports offline access. Edits sync automatically once your network is restored — no manual action required.

DingTalk Docs "Columns" upgraded again for easier layout and formatting.

Improved experience: Smoother row and column drag-and-drop in tables.

Public publishing now supports "Content Outline" for quick navigation.

DingTalk AI Table

## DingTalk Docs

---
## Open and use DingTalk offline. Edits sync automatically once you're back online — no manual action required.

New | DingTalk Docs mobile now supports offline editing, free from location and network constraints.

Whether you're flying, on a high-speed train, or in transit during a business trip, you can still browse and edit documents and spreadsheets on mobile under offline or weak-network conditions. Your edits sync automatically once your network is restored.

[Bulb] Availability: Android, iOS, and Pad users.

[Notebook] How to use: Switch your phone to airplane mode and open DingTalk Docs to try it out.
---

## DingTalk Docs "Columns" upgraded again for easier layout and formatting

Improved | The column handle lets you quickly add, delete, and move columns, making content creation and layout smoother.

DingTalk Docs columns now feature a column handle that makes it easier to add columns to the left or right. You can also drag to reposition or delete the current column for more flexible layout.

[Bulb] Availability: Mac and Windows users.

[Notebook] How to use:

1. Click a column in the document to display the column handle.

2. Click the column handle to add a column to the left or right, or delete an unwanted column from the toolbar.

3. Select the column handle with your mouse to move the column.
---

## Improved experience: Smoother row and column drag-and-drop in tables

Improved | Eliminates the pain points of dragging rows and columns, making table adjustments effortless.

Rows and columns in inserted tables have been optimized to help you clearly distinguish between them, easily select the target row or column, and quickly drag it to the desired position.

[Bulb] Availability: Mac and Windows users.

[Notebook] How to use: Insert a table in DingTalk Docs, select a row or column, then press and drag to move it.
---

## Public publishing now supports "Content Outline" for quick navigation

New | Publicly published documents now display a content outline so readers can clearly understand the structure.

Want to quickly understand the structure of a publicly published document and get key information at a glance? DingTalk Docs now adds a content outline to externally published documents, giving readers a clear view of the content and letting them jump to the target section instantly.

[Bulb] Availability: Mac and Windows users.

[Notebook] How to use: Set the corresponding heading tiers in the document and publish it publicly. The outline will be generated automatically.
---

**Document cards now show your closest collaborators, giving you a clear view of document activity**

**New | Chat document cards clearly display readers, so you can see collaboration details without opening the document**

Chat cards now show document readers in a personalized way, surfacing the two users you've most recently or closely collaborated with. See at a glance who has read or updated the document.

[Bulb] Availability: Android, iOS, Mac, and Windows users.

[Notebook] Close collaborator information appears in the following scenarios:

1. A close collaborator has read the document or given a like (likes are not shown on mobile).

2. A close collaborator has made updates since you last opened the document.

3. More than 10 people have viewed the document, but no close collaborators are involved.

## DingTalk AI Table

---
## Grid now supports pasting content and converting it directly to matching fields, making it easier to turn spreadsheet content into AI Table fields

New | Quickly convert spreadsheet content into AI Table fields with copy-paste, reducing repetitive work and making field editing more efficient.

Grid now supports pasting from Excel, text, AI Table, and Spreadsheet, with automatic conversion to matching fields. The first row can be set as the header, making field editing easier and more efficient.

[Bulb] Availability: Android and iOS users (DingTalk Professional and Exclusive Edition entitlement).

[Notebook] How to use: Copy from Excel, select a cell in AI Table, then paste.
