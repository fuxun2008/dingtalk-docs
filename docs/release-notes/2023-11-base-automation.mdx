## Calendar

---
## Introducing "Unscheduled": capture tasks first, set times later for more flexible To-Do management

In DingTalk Calendar, you can view all uncompleted To-Dos across DingTalk and set due times to display them on the Calendar view. This makes scheduling important meetings and events more flexible while ensuring no To-Do is missed.

[▶️ Watch the video to learn more](https://cloud.video.taobao.com/play/u/null/p/1/e/6/t/1/438176348744.mp4)

💡 Availability: Mac/Windows users

📓 How to use:

In the top-right corner of Calendar, click "Unscheduled" to view all To-Dos without a due time.

In "Unscheduled," view To-Do details, jump to the full To-Do view, and set due times.

Once a due time is set, the To-Do appears on the Calendar view, making it easy to track all items by time.
