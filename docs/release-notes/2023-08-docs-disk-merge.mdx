## DingTalk Docs

---
## New | Deep integration of Drive's Team Files and My Files for one-stop file management!

DingTalk Docs and Drive now share a unified entry point. DingTalk Docs integrates Drive's Team Files for one-stop access and management of Shared Files. My Docs integrates Drive's My Files for one-stop management of your personal work materials, making content management more efficient and convenient.

💡 Supported on: Android / iOS / Mac / Windows

📓 How to use: On the left toolbar of the DingTalk home page, click Docs to view My Docs and Team Files.

---

## Improved | Sort document editors by contribution to highlight key contributors

Editors can now be sorted by their contribution to the document, helping you quickly find the main contributors and making team collaboration more efficient.


💡 Supported on: Mac / Windows

📓 How to use: Open a document and click Edit in the top info bar.

---

## New | Personalize your document Preferences to take full control of the interface!

Documents now support personalized Preferences, including interface preferences, new document styles, default modes, and edit assistance, to meet your individual needs.


💡 Supported on: Mac / Windows

📓 How to use: Open a document, click More in the top right, and open Preferences.

---

## Improved | New top toolbar on iPad for efficient creation on the go!

A new top toolbar is added to the DingTalk Docs iPad client, improving the iPad experience.


💡 Supported on: iPad

📓 How to use: Open a document on iPad.

---

## Improved | Quickly locate PDF and PPT files for twice the search efficiency

When searching files, you can now filter by PDF and PPT File Types for richer search options and double the efficiency.


💡 Supported on: Android / iOS / Mac / Windows

📓 How to use: On the Recent or Shared page of the Docs home, click the document type.

---

## Improved | Save file cards to multiple locations in one go—become a file organization pro

When organizing Chat Files, want to save the same file to different locations? Chat File cards now support saving copies to multiple locations in Drive or DingTalk Docs, making file organization more convenient and efficient.


💡 Supported on: Android / iOS / Mac / Windows

📓 How to use: In a chat, you can repeatedly add copies from the card or save to the last-used location.

---

## Improved | Document cards now show clearer permissions, ending downgrade confusion and keeping your documents secure

Still puzzled why "Can manage" permission on a document card is downgraded to "Can edit"? Drive and DingTalk Docs permission levels are now aligned, helping you avoid downgrade confusion. The "Can manage" permission is now displayed and unmodifiable Granular Access permissions are hidden. When you can't modify another user's permissions, a tip is shown to make permission management more efficient and clear.


💡 Supported on: Android / iOS / Mac / Windows

📓 How to use: Share a document card and manage the recipient's permissions.

## AI Table

---
## Improved | New fields now get auto-generated names, freeing your hands and boosting creativity

The Field name used to be a required entry when creating a new Field, which felt clunky and inefficient. Now, when you create a new Field, you no longer need to manually enter a name—it's generated automatically for greater efficiency and convenience.


💡 Supported on: Android / iOS / Mac / Windows (DingTalk Professional and Exclusive Edition benefits)

📓 How to use: When creating a Field, simply click Confirm without entering a Field name.

---

## Improved | No more manual refresh—dashboards auto-update when data changes, keeping you on top of insights

Want to access the latest data with minimal manual effort? When a Table in DingTalk AI Table is updated, the Dashboard auto-refreshes for real-time data sync, freeing your hands and boosting productivity.


💡 Supported on: Android / iOS / Mac / Windows (DingTalk Professional and Exclusive Edition benefits)

📓 How to use: Charts on the Dashboard auto-update when data changes.

---

## Improved | Attachment images now fit row height, eliminating manual adjustments for more efficient layouts

When uploading images and other attachments in AI Table, how do you display images more completely and clearly? Attachments now automatically fill the entire Cell based on row height, displaying files more completely and clearly so you can see content at a glance.


💡 Supported on: Android / iOS / Mac / Windows (DingTalk Professional and Exclusive Edition benefits)

📓 How to use: After adding an image attachment, adjust the row height in the Grid.

---

## New | Tired of reconfiguring duplicates? Dashboards now support copy for twice the data organization efficiency

Want to easily create a Dashboard duplicate without the tedious configuration process? AI Table now supports copying Dashboards, allowing you to quickly create duplicates and skip reconfiguration for more efficient data handling.


💡 Supported on: Android / iOS / Mac / Windows (DingTalk Professional and Exclusive Edition benefits)

📓 How to use: On the left-side Dashboard, click [...], then click Duplicate dashboard.

---

## New | Quickly filter your preferred time periods and easily filter out data you don't need

New time-based Filter conditions are added, including this week, this month, last week, earlier than, and later than, helping you quickly filter data.


💡 Supported on: Mac / Windows (DingTalk Professional and Exclusive Edition benefits)

📓 How to use: On a View, click Filter, select a Date field, and click the filter configuration for the Date field.

---

## New | Cross-table data linking in one step—no more frequent table switching

Use the Related Lookup field to reference data across Tables. Quickly link Records from other Tables into your current Table without switching back and forth.


💡 Supported on: Mac / Windows; Read-only on Android / iOS (DingTalk Professional and Exclusive Edition benefits)

📓 How to use: Make sure the Table has a Linked field. Create a new Field, choose Field type [Related Lookup], then select the target Table, Referenced fields, and reference method.

---

## New | No more vlookup functions for data lookup! Easily find and reference data with zero learning curve

Use the Lookup field to quickly find and link cross-table data, making data handling more efficient and convenient.


💡 Supported on: Mac / Windows (DingTalk Professional and Exclusive Edition benefits)

📓 How to use: Create a new Field, choose Field type "Lookup", and configure the conditions.

---

## New | Easily track AI Table activity logs for smoother, more efficient collaboration

You can now view the full History to see Team User activity logs, making changes traceable and decisions evidence-based.


💡 Supported on: Mac / Windows (DingTalk Professional and Exclusive Edition benefits)

📓 How to use: Click "..." in the top right of the document to view the History.

## Calendar

---
## New | Diverse event reminder options to meet your personal needs and precisely notify members

When creating an Event, you can now choose between "Direct Message" and "App pop-up" notification methods to deliver event information to participants more precisely and ensure no key meetings are missed.

##

💡 Supported on: Mac / Windows

📓 How to use: On the New Event page, after adding participants, choose a notification method.

---

## New | Newly upgraded event details page—easily get key meeting info, never miss an important meeting

Information layout on the Event page is optimized for clearer distinction and management of events, making it easier to view key meeting details such as time, location, and agenda.


💡 Supported on: Mac / Windows

📓 How to use: On Calendar desktop or mobile, click an event to view the new details page.

---

## New | Keep your events secure and confidential for smoother event security management

When you create an Event, it defaults to the current Organization. If you add external participants, a security reminder appears. When the event organizer leaves the company, the event is automatically transferred to the next participant. If all internal members leave, the event is automatically canceled to ensure organization data is not leaked.


💡 Supported on: Android / iOS / Mac / Windows

📓 How to use:

When creating an Event, the default Organization is your primary Organization.

For Events that belong to the Organization, you can add external participants. They are marked as external participants with corresponding security reminders.

If a member leaves the Organization, ownership of the Event is transferred to the next participant within the same Organization. If all internal members leave, the Event is automatically canceled.

## New | Week view on large-screen devices to handle your weekly schedule with ease

Week view is now supported on iPad and Android devices (with a resolution width of 1080 or above), allowing you to clearly view your weekly Event information and plan your week efficiently.


💡 Supported on: Mac / Windows

📓 How to use: On iPad or Android devices with a width of 1080 or above, switch to Week view in the View switcher.
