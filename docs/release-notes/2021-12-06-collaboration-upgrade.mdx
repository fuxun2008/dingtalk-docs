## DingTalk Docs

### 1. Text: column layout

Feature value: split document content into columns.

Key actions: slash command — Insert column.

### 2. Text: template button

Feature value: quickly create document content templates.

Key actions:

In minimal mode, enter the slash command — Insert — Template button.

In professional mode, click the top menu — Insert — Template button.

### 3. Spreadsheet: insert attachment

Feature value: supports uploading multiple file types, making it easy to build online team resources.

Key actions: Insert — Attachment. Local files, images, audio, and video are all supported.

### 4. Spreadsheet: forms support PDF export and printing (desktop only)

Feature value: supports real-time preview, custom layout styles, lossless data export, and easy spreadsheet archiving.

Key actions: top bar — Spreadsheet — Export PDF or Print.

[Open DingTalk Docs to view the attachment "DingTalk Spreadsheet adds online printing-done'.mp4".](https://docs.dingtalk.io/i/nodes/Xzr6RBgD3LYJnak7roz1VZPnyElvd7e9?iframeQuery=anchorId%3DX02ky0xb55dmuph4pmxfr)

### 5. Spreadsheet: pin a row to the top (desktop only)

Feature value: the most powerful freeze ever — pin all your headers.

Key actions: select a row, click the toolbar — Freeze — pin the selected row to the top.

Feature value: upgrade content into a beautiful "note" with one click.

Key actions: Notes page — share icon in the top right — Generate.

## Calendar

### 1. Event settings support optional members

Feature value: synchronize events while letting members choose whether to attend.

Key actions: when adding members to an event, you can add them as Optional members.

### 2. Event response supports Tentative status

Feature value: events can be marked as Tentative for more precise response status.

Key actions: receive the event card — select Tentative.

## Drive

### 1. Group files support pinning

Feature value: pin key files for easier access.

Key actions: in Group files — More, click Pin for me.

### 2. Group storage limit can be set individually (supported on the web OA backend)

Feature value: enables fine-grained control over group file storage capacity.

Key actions: OA backend — Drive — Storage Management — Group files, set the storage limit for an individual group.

[Open DingTalk Docs to view the attachment "Drive flexibly sets group storage limit-done.mp4".](https://docs.dingtalk.io/i/nodes/Xzr6RBgD3LYJnak7roz1VZPnyElvd7e9?iframeQuery=anchorId%3DX02ky0xb55dgw9fyaonog)

### 3. Quickly find folders in chats

Feature value: chat file search supports sorting by "folder type first", improving search efficiency.

Key actions: Chat Files list — Sort — Folder type first.

## DingTalk Project Teambition

### 1. Projects support the [DingTalk Docs] app

Feature value: integrates with DingTalk Docs to accumulate project knowledge.

Key actions: project owners or admins can click [ + ] in the project navigation bar to enable the [DingTalk Docs] app.
