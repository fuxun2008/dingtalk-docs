## Spreadsheet | Data Validation: standardize entries and prevent data errors

When team members collaborate on a spreadsheet, not everyone is familiar with the entry requirements, which often leads to incorrect input — and manual checking is time-consuming and labor-intensive. With the Data Validation feature, you can preset entry rules and standardize the input format to prevent errors, improving both accuracy and efficiency in data collection.

[Open DingTalk Docs to view the attachment "Final draft - Spreadsheet Data Validation settings.mp4".](https://docs.dingtalk.io/i/nodes/lo1YvX0prG98k9A14X5YVPw7xzbmLdEZ?iframeQuery=anchorId%3DX02l7ensit48vbevw8lpip)

<Note>
💡 Supported on: Desktop

📖 How to use:

**Entry points**:

1. Top bar -- Data -- Data Validation.

2. Toolbar -- Data Validation.

3. Right-click menu -- Data Validation.

**Settings**:

1. Click an entry point -- Create rule.

2. Configure the rule: set the data type and validation rule (input tips and error warnings).

(Data Validation is a compatibility feature. It follows the same rules as local operations, but some UI interactions may differ.)

3. Click Confirm to save.

**Validation:**

1. Based on the preset rules, other users will see input tips when they click a cell.

2. If the entered data does not match the preset rule, an "invalid data" prompt appears.
</Note>
