## Interactive presentations: engage your audience and gather resonance and Feedback effortlessly

New | Document presentation mode now supports live Interaction, making it easier to liven up the atmosphere

How can you interact effectively with your audience during a Live broadcast or a presentation? In DingTalk Docs presentation mode, Users within the same Organization can scan a QR code to ask questions in real time. The last page of the presentation displays the questions raised on site, and you can view the questions alongside the Body Text, making it easy to boost audience engagement.

</Note>
[Tip] Available on: Mac/Windows

[Notebook] How to use:

Presentation mode -- bottom toolbar -- Presentation settings -- Live Interaction

Presentation mode -- Edit presentation pages -- Presentation settings -- Live Interaction

## Capture every moment of knowledge! "One-click Add" makes Saving knowledge quick and easy

New | Add a Knowledge Base or group Chats Card to another Knowledge Base Table of contents

When a Colleague Shares a Team group or learning Knowledge Base in chat and you want to Save it for quick access later, DingTalk Docs now lets you Add the Link directly from a Knowledge Base or group Chats Card to another Knowledge Base Table of contents. Keep related Content together and jump in to read more easily.

</Note>
[Tip] Available on: Android/iOS/Mac/Windows

[Notebook] How to use: Tap "Add to" on the Chats Card to open the document picker Component, then Add it to a Knowledge Base Table of contents.
<Note>

## New "Document Hunter" feature: find the documents you need with ease

New | Search Chat History on PC now supports finding DingTalk Docs

Want to quickly Find documents in group chat history? The DingTalk Docs experience has been upgraded. When you Search chat history, DingTalk Docs results now appear under the "File" and "Document" tabs, making them easier to locate.

</Note>
[Tip] Available on: Mac/Windows

[Notebook] How to use: PC DingTalk chat window -- Search Chat History
<Note>
---

## A new way to create: Insert a Whiteboard into your Document to spark inspiration

New | DingTalk Docs now supports inserting a Whiteboard, adding another channel for inspired creation

DingTalk Whiteboard, designed for multi-user online Collaboration and gathering creative ideas, can now be inserted into DingTalk Docs. It supports flowcharts and discussion boards, and is great for scenarios like brainstorming and graphic drawing.

</Note>
[Tip] Available on: Mac/Windows

[Notebook] How to use: On PC: Insert panel, or +, or /bb -- find "Whiteboard" -- click to Insert the Whiteboard.
