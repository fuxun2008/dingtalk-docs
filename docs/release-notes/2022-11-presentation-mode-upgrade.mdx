## DingTalk Docs | Presentation mode supports custom sharer name, letting you set the presenter flexibly.

When a document is edited by multiple users, the wrong presenter shows up during the report? With the new **Custom sharer** feature, you can customize the sharer name in presentation mode, or even hide the sharer entirely. Even when multiple users edit the document, you can freely set who appears as the current presenter.


💡 Available on: Desktop

📖 How to use:

DingTalk Docs → Presentation mode → Bottom toolbar → Presentation settings → Edit sharer

DingTalk Docs → Presentation mode → Edit slides → Presentation settings → Edit sharer

---

## DingTalk Docs | New Laser Pointer effect in presentation mode keeps your audience focused on the key points.

Worried that your audience may miss the key points during a presentation? The brand-new **Laser Pointer** style helps emphasize key content. Whether you're presenting in person or sharing via screen Cast online, it keeps your audience focused and in sync with your delivery.


💡 Available on: Desktop

📖 How to use: DingTalk Docs → Present (top right) → (Laser Pointer is on by default) → Bottom toolbar → Switch Laser Pointer styles

---

## DingTalk Docs | Presentation mode supports viewing inline comments, helping you resolve disagreements efficiently.

When you start presentation mode in a document, you can now **view document comments**. During your presentation, you can discuss and analyze content around the comments, efficiently resolve disagreements, and reach consensus for a more productive session.


💡 Available on: Desktop

📖 How to use: DingTalk Docs → Present (top right) → Bottom toolbar → Open Comments


## Spreadsheet | Split-screen / full-screen editing on iPad delivers a larger workspace and higher productivity.

Good news for Apple fans! As hybrid work continues to grow, more people are using iPad to work on spreadsheets. Want a larger workspace on a small screen? Spreadsheet on iPad now supports **split-screen / full-screen editing**, letting you freely resize the spreadsheet and enjoy full-screen editing on iPad—maximizing productivity even on a small screen!


💡 Available on: iPad

📖 How to use:

Open Spreadsheet on iPad.

Tap the arrow in the top left to enter full screen; tap again to exit.

## Spreadsheet | Export and download directly from online editing

Spreadsheet experience has been improved. While editing a spreadsheet online, you can now export and download directly, with greatly enhanced compatibility for a smoother work experience.


💡 Available on: Desktop

📖 How to use:

Select a local spreadsheet and click Online editing.

When using the native editor, go to the top bar → Spreadsheet, and use the new **Download as** option.

---

## Spreadsheet | Better compatibility: unprotect worksheets when editing local files online.

Have you ever opened a local Excel file in DingTalk only to find the worksheet locked and unable to be edited online? Don't worry—this release improves Spreadsheet compatibility. Even when a local Excel file has worksheet protection, you can now **right-click to Unprotect worksheet** directly, for a smoother online editing experience.


💡 Available on: Desktop

📖 How to use:

Select a local spreadsheet and click Online editing.

When using the native editor, if the spreadsheet has worksheet protection, right-click the worksheet to see the option to unprotect it.

When you choose to unprotect, you'll be reminded that the password cannot be reset afterward, but you can use the lock feature instead.


## Quick Meeting | Join as a participant to view to-dos and see task details clearly.

When you set up a to-do task in Quick Meeting and participants need more details, they can now **join as a participant to get view permission for the to-do**, giving them a clear understanding of the task and ensuring effective execution.


💡 Available on: Desktop

📖 How to use:

Open a to-do you don't have access to in Quick Meeting; you'll be prompted to join as a participant and view the to-do details.

Join as a to-do participant and open the to-do details.

## Quick Meeting | Import only incomplete to-dos for clearer, more focused task tracking!

Need to check task status during a meeting? When using Flash Recap to import to-dos, you can now **import only incomplete to-dos**, focusing the review and discussion on outstanding tasks. This streamlines the meeting and improves efficiency.

## DingTalk Teambition | Time Tracking app improvements

Teambition now **offers more granular field constraints for Time Tracking**, making management easier.


**Scenario 1:** Project members often forget to fill in work hours when creating tasks? This improvement lets you set the work-hours field as required when creating a task.


**Scenario 2:** Members forget to fill in work hours when moving a task to the next stage? This improvement requires the **Work hours** field to be filled in before a task can transition.


**Scenario 3:** Project members often forget to fill in **Work progress** when submitting **Actual hours**? This improvement makes **Work progress** required when reporting **Actual hours**, so other members can quickly understand the details behind reported time.


💡 Available on: Desktop

📖 How to use:

Scenario 1: Enable the **Time Tracking** app → Configure task type → Find the organization-level fields **Planned hours** and **Actual hours** → Click **…** and select **Set as required field** to configure.

Scenario 2: Go to workflow rule configuration → Select **Trigger condition** → **Required fields** → Add the **Planned hours** or **Actual hours** field.

Scenario 3: Enable the project **Time Tracking** app → **Menu** → **More settings** → **Time settings** → Turn on the **Actual hours - Work progress required** toggle.
