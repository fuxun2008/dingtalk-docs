**Updated version: 6.3.25**

**DingTalk Docs**

<Note>
## 1. Text: Heading content collapsible; list sub-items collapsible (desktop only)

Value: Collapse heading content to make the document outline clearer.

How to use: Hover over the left side of a heading or list item. A collapse triangle appears, allowing you to collapse the child content.

## 2. Spreadsheet: Mobile syncs filters configured on desktop

Value: Aligned experience across platforms. Filters configured on desktop can be adjusted flexibly on mobile.

How to use:

1. Set up filters on desktop Spreadsheet.

2. After opening the Spreadsheet on mobile, tap the existing filter entry to adjust the Filter.

\*Before this update, mobile did not support using existing filters.

Note: After the update, mobile does not support creating new filters; it can only use existing filters created on PC.

## 3. Spreadsheet: Remove Duplicates (desktop only)

Value: Efficiently deduplicate repeated data entries and extract unique values with one click.

How to use:

Entry: Toolbar > Duplicates > Remove Duplicates

Locate duplicates: Select the deduplication area and click the entry. Duplicate entries are highlighted in real time.

Post-processing: Delete directly, or paste the deduplicated results to another location without affecting the original data (key highlight).

## 4. Spreadsheet: Text to Columns (desktop only)

Value: Split a Cell into multiple Columns by criteria, making survey results, sign-up messages, and data organization more efficient.

How to use: Menu bar > Data > Text to Columns

[Please go to DingTalk Docs to view the attachment "DingTalk Spreadsheet Text to Columns.mp4".](https://docs.dingtalk.io/i/nodes/65ALkBedOKwVBO5qDgooJZq43Nxzop2P?iframeQuery=anchorId%3DX02kzdlikevn9ncw5j074c)

## 5. Spreadsheet: Custom Sort (desktop only)

Value: Supports partial sorting and multi-criteria sorting for more flexible Sort.

How to use: Toolbar Sort > Custom Sort

## 6. Logs: Insert richer content (desktop only)

Value: Insert code blocks, flowcharts, roadmaps, mind maps, and more rich content when writing logs.

How to use: Write log > Insert

## 7. Mind Map: Task assignment

Value: Quickly assign work tasks and track status to help plans move forward and land.

How to use: Click the "Task" button on the top-left toolbar to open the task panel. Select a node to assign a task.

[Please go to DingTalk Docs to view the attachment "DingTalk Mind Task Assignment.mp4".](https://docs.dingtalk.io/i/nodes/65ALkBedOKwVBO5qDgooJZq43Nxzop2P?iframeQuery=anchorId%3DX02kzdlikev7utynetstvm)

## 8. Mind Map: Node emphasis

Value: Apply emphasis styles to nodes with one click to quickly highlight key content in the Mind Map.

How to use: Select a node > click the "Font emphasis" button on the toolbar > choose an emphasis style from the pop-up.

[Please go to DingTalk Docs to view the attachment "DingTalk Mind Node Emphasis.mp4".](https://docs.dingtalk.io/i/nodes/65ALkBedOKwVBO5qDgooJZq43Nxzop2P?iframeQuery=anchorId%3DX02kzdlikevwxnd3z4ndcq)

## 9. Notes: Rich Text, Multiselect, Reply to Notes (mobile only)

Value: Supports converting more message types to Notes.

How to use: In Chats, long-press a Rich Text or Reply message to show the Notes entry. In Multiselect mode, a "Save as Notes" Button is available.

## 10. Notes: Create Notes during a Live (desktop only)

Value: Create Notes directly during a Live to capture key points.

How to use: During a Live, click "...". In the drop-down menu, click "Notes".

[Please go to DingTalk Docs to view the attachment "Create Notes While Watching a Live.mp4".](https://docs.dingtalk.io/i/nodes/65ALkBedOKwVBO5qDgooJZq43Nxzop2P?iframeQuery=anchorId%3DX02kzdlikevxos7ae12iwb)
</Note>

### Calendar

<Note>
## Calendar supports sign-out

Value: Events support sign-out, making meeting management more convenient.

How to use: The Event organizer can initiate sign-out. Attendees can scan to sign out. After the meeting, export the sign-in and sign-out records with one click for easy attendance tracking.
</Note>

### Drive

<Note>
## Support for OFD domestic file format icons

Value: DingTalk Drive supports icons for domestic Xinchuang file formats.
</Note>

### Mail

<Note>
## 1. Device management (Mail web only / paid Alibaba Enterprise Mail)

Value: Track sign-in devices and set trusted devices for easier passwordless Authentication.

How to use: View sign-in devices and set trusted devices on the device management page.

## 2. Archive upgrade (Mail admin console only / paid Alibaba Enterprise Mail)

Value: 5-year archive service is separately authorized, with clearer Search to better meet enterprise needs for Mail Compliance and Search & Discover.

How to use:

After clicking the On button, Mail from the past 5 years is automatically archived to better meet enterprise Mail Compliance requirements.

Super Admin and archive admin Permissions are separated. An archive admin must be set separately, ensuring stricter data Security.

## 3. Mail transfer rules (Mail admin console only / paid Alibaba Enterprise Mail)

Value: Upgraded rule definition capabilities, with new features such as "Decline and provide reason". Organizations can flexibly configure Mail transfer monitoring rules based on actual scenarios to ensure information Security.

How to use: Configure Mail monitoring Forwarding Rules, Mail outbound review rules, and Mail inbound Filter Rules.
</Note>

### DingTalk Project

<Note>
## 1. Projects can be linked to "DingTalk Group Chat"

Value: Users can enable the "Chat" App in a project and link multiple DingTalk Group Chats.

How to use: "Project" > Add app > "Chat"

## 2. "My Tasks" newly launched

Value: Users can manage all project tasks and free-floating tasks not belonging to any project in "My Tasks".

How to use: "Project" Home > "My Tasks" / "Shortcut"

## 3. "Project" entry moved from "More" to the DingTalk side navigation

Value: Easier access to "Project".

How to use: DingTalk left navigation bar > "Project"

## 4. Optimized process for unlinking DingTalk Docs from a project

Value: If a user accidentally links the wrong Team space, they can quickly unlink it.

How to use: "Project" > "Docs" App > "Settings" > "Unlink"

## 5. Push "Project Daily Report" to DingTalk Group Chat

Value: Group Chats linked to a project support pushing project daily reports into the group.

How to use: "Chat App" > "Group Chat Settings" > "Push Project Daily Report"
</Note>
