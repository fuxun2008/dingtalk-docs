## A new tool for data referencing: cross-spreadsheet references make data updates clearer and more accurate

New | Spreadsheet now supports cross-spreadsheet data references — update one table, sync many

Whenever you update data, do you find yourself constantly switching between related spreadsheets or manually copying data over? This inefficiency can turn data processing into a daily nightmare. Now, with cross-spreadsheet references in DingTalk Spreadsheet, you can sync data across multiple tables in a single step.


💡 Availability: Mac and Windows users

📖 How to use: Full functionality is available on desktop; mobile only displays referenced data

1. Entry: Top menu of the spreadsheet > Data > Cross-spreadsheet reference

2. Create a reference: Users can select online spreadsheets within the current organization that they have View Permission and Download access (or higher) to (local spreadsheets are not supported yet).

3. Confirm to start the reference.

4. The first reference requires the user to allow reading the latest data; once allowed, the referenced data is displayed.

5. Referenced data is for display only and cannot be edited; any modifications will trigger an error.

## New field type for AI Table: Formula field with functions for more efficient and convenient data processing

New | Formula field added to DingTalk AI Table, with rich functions for accurate data calculation

Want to calculate AI Table data quickly and accurately when tracking sales, procurement, or similar information? The new Formula field in DingTalk AI Table automatically calculates data using a rich set of functions, making data processing more efficient and convenient.


💡 Availability: Mac and Windows users; mobile is read-only (DingTalk Professional Edition and Exclusive Edition benefit)

📖 How to use:

Formula results are calculated automatically and cannot be modified

## AI Table experience optimization: arrange your data the way you want, with full management flexibility

Improved | View-only users can also filter, sort, and group data in AI Table

View-only users can now filter, sort, group, and perform other view-related actions in AI Table without affecting other people's views. This meets the browsing needs and habits of different roles, providing clearer structure for efficient management and helping you focus on your target data.


💡 Availability: Mac and Windows users; mobile is read-only (DingTalk Professional Edition and Exclusive Edition benefit)

📖 How to use:

1. Applies to users with View or View-only permissions.

2. Available actions: filter, sort, group, find, comment, adjust row height, and more.

3. The first time a user performs any of these actions, a one-time message appears: "Actions performed in read-only mode will not be saved or affect other users." This message is shown only once to avoid disruption.
