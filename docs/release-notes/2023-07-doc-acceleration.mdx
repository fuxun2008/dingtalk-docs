## DingTalk Docs

---
## New | Turn on the Booster to open documents faster

Slow to open long documents? Turn on the Booster to boost document opening speed and performance, making content creation and preview smoother.

[Bulb] Available on: Mac and Windows

[Notebook] How to use: Click the rocket icon in the lower-right corner of a DingTalk Doc to turn it on.
---

## New | Add titles to code blocks for clearer content

Code blocks inserted in documents now support titles, can be expanded or collapsed freely, and can be quickly switched between dark and light themes to fit different scenarios.

[Bulb] Available on: Mac and Windows

[Notebook] How to use: Insert a code block in a DingTalk Doc, then set the title, select a theme, and collapse it as needed.
---

## Improved | Indent block-level elements for cleaner layouts and clearer hierarchy

All block-level elements inserted in documents — including tables, columns, and highlight blocks — now support indentation, making layouts cleaner and the hierarchy more distinct.

[Bulb] Available on: Mac and Windows

[Notebook] How to use: Select a block-level element and choose "Indent" from its menu.
---

## Improved | Higher batch organization limit for clearer and more efficient file management

The batch organization limit for Group Chat files has been raised to 500. You can now view upload progress and results in the transfer panel, making file management clearer and more efficient.

[Bulb] Available on: Android, iOS, Mac, and Windows

[Notebook] How to use: Batch select Chat Files or Drive files to add to Knowledge Base, move, and more.

## Calendar

---
## New | Select a time zone when creating an event to align meeting times

You can now select a time zone when setting the event time. When time zones differ, participants can view the converted time, helping everyone align on the meeting time and avoid missing important meetings.

[Bulb] Available on: Android, iOS, Mac, and Windows

[Notebook] How to use: On the New Event page, select a time zone and switch between zones as needed. When viewing an event, if the organizer's and participant's time zones differ, participants can see the original time before conversion.
---

## New | Add an agenda when creating an event to skip repetitive steps and prepare materials faster

When creating an event, you can add an agenda, enter agenda titles, and @ owners to prepare materials in advance. This skips repetitive steps and helps keep meetings running efficiently.

[Bulb] Available on: Mac and Windows

[Notebook] How to use:

Add Agenda: On the Calendar desktop New Event page, add an agenda, enter the agenda title, and @ the owner.

Delete agenda: Press the Delete key on your keyboard to remove an entered agenda.
