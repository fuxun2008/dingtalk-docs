## AI Table Granular Access preview launched—verify permissions from multiple role perspectives to safeguard data security

AI Table introduces a Granular Access preview feature. Admins can view the current AI Table from the perspective of different roles to verify whether Granular Access settings are correctly configured, ensuring information security.

</Note>
[Lightbulb] Availability: Mac, Windows, and Web users

[Notebook] How to use: In the Granular Access panel, click Preview at the bottom.
<Note>
---

## Copy AI Table record links with one click—jump directly to the record location for easier data discussions!

AI Table now supports copying record links, enabling quick sharing and locating of data and making team collaboration more efficient and convenient.

</Note>
[Lightbulb] Availability: Android, iOS, Mac, Windows, and Web users

[Notebook] How to use: In an AI Table, select the record you want to share, right-click, and choose Copy record link.
<Note>
---

## Field descriptions added to AI Table—understand fields accurately and enter data efficiently

AI Table fields now support descriptions, improving data clarity, lowering the cost of understanding information, and enabling efficient team collaboration.

</Note>
[Lightbulb] Availability: Android, iOS, Mac, Windows, and Web users

[Notebook] How to use: In an AI Table, expand the list next to the field name and click Edit field description.
<Note>
---

## User fields integrate with DingTalk Contacts—retrieve comprehensive user information with one click for easier information management!

User fields can be extended based on DingTalk Contacts, allowing you to retrieve a user's manager, department, employee ID, mail, and more with one click. User information is just a tap away, making collaboration tighter and work smoother!

</Note>
[Lightbulb] Availability: iOS, Mac, Windows, Web, and Android users

[Notebook] How to use: When configuring a User field, enable Show more information in the settings panel.
<Note>
---

## Flexibly control data display order, accelerate information analysis, and keep every piece of data in order!

Conditions configured in the Sort and Group panels now support custom ordering. Flexible configuration optimizes information presentation and analysis efficiency, making data management more effective!

</Note>
[Lightbulb] Availability: Mac, Windows, and Web users

[Notebook] How to use: In the Group or Sort panel, drag conditions directly to adjust their order.
<Note>
---

## Create AI Table copies with structure only—streamline workflows and improve data processing efficiency

When creating a copy of an AI Table, you can now copy only the table structure. This makes template reuse and structural adjustments easier, simplifies data migration, and improves data processing efficiency.

</Note>
[Lightbulb] Availability: iOS, Mac, Windows, Web, and Android users

[Notebook] How to use: When creating an AI Table copy, select AI Table structure only to quickly create the copy.
<Note>
---

## Quickly create AI Table copies with Granular Access automatically synced—accelerate team collaboration workflows

When creating an AI Table copy, the configured Granular Access settings can be carried over, eliminating repetitive setup and boosting team collaboration efficiency.

</Note>
[Lightbulb] Availability: Mac, Windows, and Web users

[Notebook] How to use: When creating an AI Table copy, if Granular Access has already been configured on the source table, the settings will be automatically synced to the new copy—no need to reconfigure.

## [Magic wand] DingTalk Calendar

---
<Note>
## Auto-subscribe to the organization-wide calendar: automatically sync important events so you never miss key schedules!

Organization admins can create an "Organization-wide calendar" to publish events such as holiday schedules and organization training with one click. All members of the organization automatically subscribe to and receive the calendar, making team information sharing more efficient and convenient.

</Note>
[Lightbulb] Availability: Android, iOS, Mac, and Windows users

[Notebook] How to use: Go to Calendar → select Organization-wide calendar → + Create organization-wide calendar, then fill in the details to create the organization's calendar. Once the organization-wide calendar is added to DingTalk Calendar, you can view it under Subscribed calendars.
