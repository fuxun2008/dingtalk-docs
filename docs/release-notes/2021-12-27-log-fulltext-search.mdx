## DingTalk Docs

## Text: Highlight blocks support more style settings (desktop only)

What's new: Highlight blocks now support border and background color settings, and emojis can be hidden. You can also nest highlight blocks within highlight blocks, add columns, and more—meeting advanced document editing needs.

How to use:

1. Entry: In Lite mode, use the slash command - Insert highlight block; in Pro mode, go to the top menu - Insert - Highlight block.

2. Effect: Highlight blocks support 10 border styles and 30 background colors, letting you freely create rich styles.

[Please go to DingTalk Docs to view the attachment "DingTalk Docs Highlight Block Style Upgrade.mp4".](https://docs.dingtalk.io/i/nodes/ROGpvEna5YQWmaNng1XeW4ykmK3zoB27?iframeQuery=anchorId%3DX02kzdlldzid8xka1aug4v)

## 2. Text: Online documents support art card display (desktop only)

What's new: Adds rich display views for online cards, making documents look more elegant.

How to use: 1. Add an online document. 2. In the card type selector at the top-right corner of the document, select Art card.

[Please go to DingTalk Docs to view the attachment "DingTalk Docs Online Document Art Card Support.mp4".](https://docs.dingtalk.io/i/nodes/ROGpvEna5YQWmaNng1XeW4ykmK3zoB27?iframeQuery=anchorId%3DX02kzdlldzi7cw1fj0xsht)

## 3. Spreadsheet: Filter visible only to me (desktop only)

What's new: Decide whether filter results sync to other users with a single click.

How to use: A new "Filter visible only to me" toggle has been added to the filter panel.

[Please go to DingTalk Docs to view the attachment "12 DingTalk Spreadsheet Filter Visible Only to Me.mp4".](https://docs.dingtalk.io/i/nodes/ROGpvEna5YQWmaNng1XeW4ykmK3zoB27?iframeQuery=anchorId%3DX02kzdlldzou9a5tdtsgop)

## 4. Spreadsheet: Set column type (configurable on desktop; viewable on mobile)

What's new: Preset entry rules to collect data faster and more accurately.

How to use: On desktop, hover over the header of any column to see a dropdown arrow. Click the arrow to set or clear the column type.

[Please go to DingTalk Docs to view the attachment "11 DingTalk Spreadsheet Column Type Settings.mp4".](https://docs.dingtalk.io/i/nodes/ROGpvEna5YQWmaNng1XeW4ykmK3zoB27?iframeQuery=anchorId%3DX02kzdlldzoc4s9o8te9u)

## 5. Spreadsheet: Cell history (desktop only)

What's new: View cell history to keep track of edits and deletions, with a clear audit trail for every change.

How to use: Right-click a cell - View History. (Note: Up to 1,000 entries are displayed; only data-level additions, deletions, and edits are shown, excluding row and column structure changes.)

## 6. Spreadsheet: Record-by-record entry on desktop

What's new: Each record can be expanded into a vertical form, allowing you to view and edit content in a more spacious layout.

How to use: On desktop, a small arrow appears in the header of each record. Click the arrow to expand the record as a form.

## 7. Quick Share: Create a new cloud document and share it instantly

What's new: Meets Quick Share needs across more scenarios.

How to use: Select Quick Share document - Create a new cloud document (Online document / Spreadsheet / Mind Map / Whiteboard) and share it instantly.

## 8. Mind Map: Multiselect and drag (desktop only)

What's new: Move nodes in bulk with ease.

How to use: Drag-select multiple nodes, then drag the selected nodes under another node.

## 9. Mind Map: Find and replace (desktop only)

What's new: Adds the previously missing Find and replace feature, allowing users to quickly locate text content.

How to use: Press the shortcut (Mac: Cmd+F, Win: Ctrl+F) to open the Find and replace panel.

### 10. Logs: Full-text search

What's new: Quickly find and locate logs by keyword.

How to use: DingTalk - Search - Log type.

## 11. Logs: One-click review (desktop only)

What's new: Review the past week's work in one click while writing a log.

How to use: Write log - Review.

### Drive

### 1. Improved automatic file handover rules for departing employees

What's new: Files from departing employees are handed over layer by layer, reducing interruptions to Organization Admins.

How to use: After an employee leaves, files in their DingTalk Drive Team Files and My Files are handed over by default in the following priority order: "Other folder admins > Employee's direct manager > Organization Super Admin".

[Please go to DingTalk Docs to view the attachment "DingTalk Drive Departing Employee File Handover Rule Improvement (1).mp4".](https://docs.dingtalk.io/i/nodes/ROGpvEna5YQWmaNng1XeW4ykmK3zoB27?iframeQuery=anchorId%3DX02kzdlldzpqzc13kp1z3h)

## 2. Super Admins can view names of Internal Groups synced to Drive in the OA admin console (web/OA admin console only)

What's new: Helps Admins manage group file capacity.

How to use: OA admin console - Drive - Capacity management - Group files. You can see the names of Internal Groups that have been synced to the organization's Drive.

### 3. Improved bulk operation experience

What's new: During bulk operations, items that cannot be processed are automatically filtered out, so selecting unsupported items no longer blocks the bulk operation.

How to use: Perform bulk operations—Download, Move, Copy, Delete—on the File List within the Drive app.

[Please go to DingTalk Docs to view the attachment "DingTalk Drive Bulk File Operation Improvement (2).mp4".](https://docs.dingtalk.io/i/nodes/ROGpvEna5YQWmaNng1XeW4ykmK3zoB27?iframeQuery=anchorId%3DX02kzdlldzppje9llslkwg)
