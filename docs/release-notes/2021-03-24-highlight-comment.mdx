## "Spreadsheet"

## 🎉 Release notes

## 1. Data security upgraded! "Lock: Restrict view"

Supported platforms: Windows, Mac desktop

The "Lock Permission" feature in Spreadsheet, on top of restricting member editing, **adds a powerful new capability: restrict member viewing!** It is ideal for scenarios such as **finance collecting confidential data, HR collecting personal profiles, and sales managing performance data**, ensuring data security and control.

For example, as a store manager, I need to track product sales volume and amount. So I created a "Mooncake Sales List" and invited store partners to fill it in together. However, for important marketing data such as "Sales Volume", "Unit Price", and "Amount", I want only "myself and the deputy manager" to be able to edit and modify, while other partners are restricted from viewing — to prevent core data leaks and ensure data security. Here's how to set it up:

1.  Select the cell range you want to lock and click "Lock Cell".

2.  In the dialog, under "Specified people", add the "Store Manager and Deputy Manager" as "Can view" or "Can edit".

3.  In the "Others" menu of the dialog, set "Restrict view".

This way, from the perspective of other regular staff, they will not be able to view the confidential data in the corresponding area.

| **If the lock overlay interferes with normal data viewing and editing, you can toggle the overlay through "Hide/Show Lock Overlay".** |
| --- |

**Note:**

*   After setting "Restrict view", members without view permission cannot, in addition to viewing the area data:

    *   Download or copy spreadsheet data.

    *   View history.

    *   Retrieve locked cell data via formulas.

*   When using "Find / Replace", the locked area data is ignored by default.

*   The user guide for "Lock Permission" can also be viewed by clicking **"Toolbar - Lock - User Guide"**.

## 2. Deduplication! "Highlight Duplicates" is finally here

Supported platforms: Windows, Mac desktop

When collecting data daily, you no longer need to worry about duplicate entries affecting organization efficiency, because "Highlight Duplicates" is here! Simply select the column you want to check for duplicates, turn on **"Toolbar - Highlight Duplicates"**, and all duplicate data will be revealed.

Meanwhile, partners who are accustomed to using "Conditional Formatting" can also highlight duplicates via "Conditional Formatting - Highlight Cells - Duplicates".
