## DingTalk Docs: Edit two documents simultaneously in dual-screen mode

> Available on: Desktop

</Note>
    **Value**

In dual-screen mode, you can edit two documents at the same time without switching between pages, making it easier to edit and proofread content efficiently.

    **How to use**

Open Document A, then click on Document B inserted in Document A to enter dual-screen mode (both documents can be edited simultaneously).

    **Use case**

Ding Sanduo is a content editor at a new media company. She uses DingTalk Docs daily to proofread and review various drafts and write articles, and she often inserts related documents into her main document. With dual-screen mode, both documents can be edited at the same time, eliminating the need to switch back and forth when proofreading or reviewing drafts—making work easier and more efficient.

## Spreadsheet: Date filtering with automatic grouping by year and month

> Available on: Desktop supports the full workflow; Mobile supports message notifications only

</Note>
    **Value**

When using value filtering in Spreadsheet, dates can be automatically grouped by year and month, making information filtering more efficient and convenient.

If the selected range contains data in date format, the dates will be automatically aggregated by year and month in the filter panel.

    **Use case**

Ding Sanduo is an administrative asset manager who uses Spreadsheet daily to log company asset check-ins and check-outs. Sometimes she needs to filter records from a long time ago, and searching one by one wastes a lot of time. Now, when using value filtering in Spreadsheet, dates in the list are automatically grouped by year and month, allowing her to quickly filter asset records for specific periods—making spreadsheet use much more convenient and efficient.

## DingTalk Calendar: Events now support organization attribution for safer management

> Available on: Desktop / Mobile

</Note>
    **Value**

Internal organization events are restricted to organization employees only. Employees automatically exit internal events after leaving the organization, and one-click creation of internal meeting groups makes meeting event management more efficient and secure.

    **How to use**

1. When organization members select participants from the same organization to schedule an event, the calendar can be marked as an internal organization event.

2. Internal events do not support adding external participants.

3. Departed users can no longer view their former organization's events in DingTalk Calendar, and unfinished events are transferred from the departed organization member to the next participant.

4. Internal events can launch internal meeting groups and Quick Meetings within the same organization.

5. Event sharing is restricted to events within the same organization, ensuring more secure management.

    **Use case**

Ding Sanduo is a sales manager at a real estate company. She uses DingTalk Calendar daily to create events for internal team meetings and to communicate with clients on various projects. With this feature, internal organization events and meetings are limited to internal employees only, and she can launch and create internal meeting groups with one click. This helps avoid information and data leaks caused by inadvertently inviting external participants.

## DingTalk Project: Mobile DingTalk supports private chat push for task comments with @ mentions

> Available on: Desktop, Mobile

</Note>
    **Value**

Enhances single-point reach for task comments. For tasks under an organization bound to DingTalk, when you @ a user in a comment, the message can be pushed to the user via DingTalk private chat. The user can view the task content directly in the DingTalk private chat interface, ensuring no key information is missed.

    **How to use**

Go to the **Tasks** page, edit the communication content in the **Dialog box**, and select **DingTalk private chat notify @ user** when sending.

    **Use case**

Ding Sanduo is a member of the design team. Daily design file revisions require frequent communication with the supervisor and colleagues from other departments within tasks. Because design content sometimes needs repeated adjustments, excessive Message notifications can cause some users to overlook important messages. With this feature, key messages are pushed directly to the private chat of the @ mentioned user, effectively preventing critical information from being missed due to message overload.
