**Version: 6.5.5**

**DingTalk Docs**

**1. Entry point: Send DingTalk Docs from the chat window**

Value: Send DingTalk Docs directly in a chat (WPS documents not included).

How to use: On desktop, click "Send DingTalk Doc" on the chat toolbar. On mobile, tap the + icon in the chat box and select DingTalk Doc.

**2. Entry point: New "Find document" plugin in group chats**

Value: Quickly locate documents in a chat (including DingTalk Docs and WPS documents).

How to use: Click the "Find document" plugin in an Internal Group.

**3. Spreadsheet: Group multiple rows and columns (Desktop)**

Value: Combine data as needed, expand and collapse across multiple tiers, and organize data in a structured way to keep your spreadsheets tidy.

How to use: Select rows or columns and right-click to see "Group". Other actions are the same as desktop Excel.

**4. Spreadsheet: File slimming (Desktop)**

Value: Clean up invalid data to make spreadsheets smoother and improve collaboration efficiency.

How to use: Top menu > Spreadsheet > File slimming.

**5. Spreadsheet: Dropdown List supports referencing a data range (Desktop)**

Value: Reference a specified range as a Dropdown List, with options updated dynamically.

How to use: Entry point: Dropdown List > More settings.

**6. Spreadsheet: View detailed spreadsheet information (Desktop)**

Value: Adds information about who has viewed and edited the spreadsheet, as well as the data within it.

How to use: Entry point: Top-left > Spreadsheet > View spreadsheet info.

**7. Log: Brand-new Comments experience (Desktop)**

Value: Clear contextual replies, at a glance.

How to use: In View Log, see the Comments list and reply directly.

**8. Log: Title optimization (Desktop)**

Value: From the log Title, quickly view all logs in that category by user or template.

How to use: View Log.

**9. Quick Notes: Start Quick Notes in a document with real-time Voice-to-text (Desktop / Web)**

Value: Real-time Voice-to-text frees your hands so you can focus on content creation.

How to use: Click "More" on the document toolbar and select "Quick Notes". Or type "/" in the Body Text and select "Quick Notes".

**Quick Meeting**

**1. Quick Meeting: Quickly create from the Calendar entry point (Desktop)**

Value: Start a Quick Meeting from multiple places, including the Calendar. When sending the invitation, you can add the agenda and @ Users for thorough pre-meeting preparation.

How to use: When creating a Calendar event, select "Quick Meeting".

**2. Quick Meeting: Multiple Meeting templates for an easy start (Desktop)**

Value: Multiple Meeting templates are available. You can create recurring Quick Meetings and save Custom templates to easily kick off every Meeting.

How to use: Select the desired template when creating an Event.

**3. Quick Meeting: New three-column Layout**

Value: New meeting controls, agenda, and minutes panels make operations more flexible and keep meetings more focused.

**Calendar**

## DingTalk Calendar supports setting a default Event duration

Value: Participants can view organizer changes on the Calendar reminder Card at a glance.

How to use: Set the default Event duration in Calendar Settings. When creating an Event, the default duration follows the user setting.

**Drive**

## Added the new "Organization Storage" App to the main navigation in OA Admin (Web)

Value: Provides unified storage services for the Organization, making it easier for Admins to manage storage Space.

How to use: OA Admin > Organization Data > Organization Storage. The Super Admin can view the Organization's storage usage, allocate storage Space to Apps, and fine-tune storage capacity for specific Apps.

(Currently supports fine-grained management for Drive, Group files, and Approval. More Apps will be supported later.)

**Mail**

## 1. Global Search for archived Mail (Alibaba Mail Business plan - Web)

Value: Search archived Mail globally by keywords and other criteria for easier retrieval.

How to use: The archive Admin signs in to the domain management console and clicks Premium Apps > Mail Archive > Search archived Mail.

## 2. Mobile verification required when setting Mail Rules (Alibaba Mail Business plan - Web)

Value: Mobile verification is required when setting Mail Rules such as Auto Forwarding, improving account Security.

How to use: Sign in to the web Mail, click Settings > Mail Settings.

## 3. Third-party client Security password (Alibaba Mail Business plan - Web)

Value: Once enabled, users must use the third-party client Security password when accessing Mail via a third-party client, enhancing account Security.

How to use: Sign in to the Alibaba Mail web Settings page, select Account and Security > Account Security, and turn on the third-party client Security password.

**DingTalk Project (Teambition)**

## 1. "My Tasks" and "Shortcuts" support grouping by project

Value: Provides richer cross-project task Views and management capabilities.

How to use: Go to My Tasks or Shortcuts and choose to Group by project.

**2. Quick create in "My Tasks" supports adding a "Project"**

Value: Create and dispatch tasks to different projects more easily.

How to use: Go to the "My Tasks" page, click Quick Create Task at the top, then click "Project" to Select one directly.

## 3. "My Tasks" and "Shortcuts" add a toggle to show or hide subtasks

Value: Flexibly choose whether to show subtasks, covering more use cases.

How to use: In "My Tasks" or "Shortcuts", click "View" and find the toggle in the dropdown menu.

**4. Tasks can be shared to DingTalk groups**

Value: Jump straight into task details and discuss tasks anytime, anywhere.

How to use: On the new task detail page, click the Share Button in the top right, choose Share to DingTalk Chat, and Select the target DingTalk group.

## 5. Grid supports grouped View (Desktop)

Value: Categorize tasks across different dimensions, combined with Filter and Sort for better task management.

How to use: Click "Group" on the toolbar within a project, then Select the Field to Group by.

**6. Recurring tasks upgraded**

Value: Provides finer-grained settings, improving the usability of recurring tasks in real-world scenarios.

How to use: Open the DingTalk Project App > Task detail page, select the Repeat settings icon, and Customize the Repeat rules.

**Organization Wiki**

## Add workbench Apps to entry details

Value: Display related App information in entry details to help users discover and use the App more easily.

How to use: On the "Add/Edit Entry" page, select the "Add" Button under "Related Apps", and choose the workbench App for the current entry from the dropdown menu.
