**Release version: 6.3.35**

**DingTalk Docs**

## 1. Docs: Set a cover image

Value: Add a simple cover image to your document.

Key actions: Above the document title, click "Add cover" and select a recommended background image or upload one of your own.

**2. Docs: Quickly apply one of six image styles, with precise width and height controls**

Value: Use the image toolbar to quickly apply styles, and use the image settings panel to precisely adjust width and height.

Key actions: 1. Click the image to open the toolbar above it. 2. Click style settings to quickly apply image styles.

3. Click advanced settings to fine-tune width, height, style, and more.

**3. Logs: Add log templates to groups (desktop)**

Value: Access commonly used log templates from a group in one click.

Key actions: Log template management.

**4. Logs: Group reports upgraded to group logs**

Value: Upgraded group log management—support for linking multiple templates and a streamlined management flow.

Key actions: Group logs plugin.

**5. Mind Map: Outline menu**

Value: In outline note mode, you can also apply emphasis, bold, insert icons and images, and more.

Key actions: Enter outline mode and click the small dot before a node to open the menu for the available actions.

**6. Mind Map: Frames**

Value: Add a frame around multiple related nodes to group and annotate them.

Key actions: Select multiple nodes, then click the "Frame" button on the toolbar to add a frame.

### Mail

## 1. Device management (Alibaba Mail Business plan - web)

Value: 1. Track sign-in devices for greater security. 2. Mark trusted devices to skip sign-in verification for greater convenience.

Key actions: 1. View sign-in devices on the device management page. 2. Mark devices as trusted.

**2. Archive upgrade (Alibaba Mail Business plan - web)**

Value: A 5-year archive service with separate authorization and clearer search to better meet organizational needs for mail compliance, search, and discovery.

Key actions: 1. Click the On button to automatically archive mail from the past 5 years, better meeting organizational compliance requirements. 2. Super Admin and archive admin permissions are separated. An archive admin must be set separately for stricter data security.

**3. Mail transfer rules (Alibaba Mail Business plan - web)**

Value: Rule definition capabilities have been upgraded with new features such as "Decline and provide reason," so organizations can flexibly configure mail transfer monitoring rules based on their actual scenarios to safeguard information security.

Key actions: 1. Configure mail monitoring Forwarding Rules. 2. Configure outbound mail review rules. 3. Configure inbound mail Filter Rules.

### Calendar

## Calendar card notifications highlight changed elements (desktop)

Value: Attendees can see at a glance the information changed by the organizer on the calendar reminder card.

Key actions: When the organizer changes event time, location, or other information, attendees receive a notification on desktop with tags marking the changed elements, so attendees can clearly identify what has been updated.

### Drive

## Share list displays files from "Shared with me" and "Shared by me" in a flat view

Value: The share list shows specific files from "Shared with me" and "Shared by me" in a flat view and hides each file's path, making Collaboration more efficient and information more secure.

Key actions: Drive > Share > Shared with me / Shared by me: View specific files shared with you or shared by you without needing to know the file path (previously you had to drill down from the top-level Folder).

### DingTalk Project

## 1. "My tasks" supports filtering by "Project" (DingTalk client)

Value: More dimensions for filtering tasks, enabling more efficient and precise management.

Key actions: Open the Filter Component and click "Project" to make a Selection.

**2. Tasks support DingTalk Docs fields and linking to DingTalk Docs (TB web / DingTalk client / DingTalk mobile)**

Value: Link related documents to tasks for richer task information.

Key actions: 1. Configure the task Type and add the premium DingTalk Docs Field. In the task, select a DingTalk document from the current Organization. 2. In the task, select "Linked Content" > "Add from resources" > "DingTalk Docs."

**3. Grid supports Grouping (TB web / DingTalk client)**

Value: Classify tasks by different dimensions and combine with filtering and sorting to better manage tasks.

Key actions: In the project toolbar, click "Group" and select the Field to group by.

**4. Toolbar interaction improvements (TB web / DingTalk client)**

Value: Frequently used features are surfaced for easier high-frequency Actions.

Key actions: 1. When the Kanban Column is by task status, the workflow has been moved from the secondary menu to the toolbar and is highlighted. 2. In all views, the task tier menu has been moved out of "..." to the toolbar, with "Subtasks only" highlighted when active. In Kanban, "Card Fields" has been moved into "...".

**5. Project "Group Chat" configuration interaction improvements (DingTalk client)**

Value: The "Group Chat" configuration entry is surfaced so users can find it easily.

Key actions: Open the project chat app.

**6. "Admin console" structure improvements (TB web / DingTalk client / DingTalk mobile)**

Value: Clearer information structure and a friendlier interaction experience.

Key actions: Open "Admin console" / "Configuration center."

### Organization Wiki

## Support dynamic configuration for Internal Groups and service groups

Value: Allow people outside the organization to view organization entries, improving the efficiency of external Q&A and technical support.

Key actions: In the workbench, click the Organization Wiki app, select entry management, and for a single entry or in bulk, set visibility to internal groups or service groups.
