## DingTalk Docs | Group Knowledge Base launched, keeping group documents and files organized for efficient team knowledge management and accumulation

Are group materials too scattered and hard to organize? Is permission control a hassle? Group Knowledge Base is now available, letting you ++**build a small knowledge base for each group and manage file/document permissions in detail**++, so your group can produce, accumulate, and share knowledge with ease.

</Note>
💡 Available on | All four platforms

📖 How to use:

You can bind an existing DingTalk Docs Knowledge Base to a Group Chat, or create a new Knowledge Base from a Template.

DingTalk group types currently supported: Internal Group and Department Chat.

Support for External Chat, All-staff Chat, and More Types will be rolled out soon.

## DingTalk Docs | Support for "DingTalk Jinbu" and "Alibaba Sans" fonts

Created by DingTalk in partnership with Hanyi Fonts, the ++**original DingTalk-branded "DingTalk Jinbu" font**++ is now ++**permanently free to use**++ in DingTalk Docs. "Alibaba Sans" is also available for free switching.

</Note>
💡 Available on | Desktop

📖 How to use:

Entry point: On desktop, open a Document and choose "Double-row toolbar" - "Font settings". The single-row toolbar and the no-toolbar mode do not support font switching.

If the font is not installed, opening the font menu will prompt you to "Download font". After downloading, you can switch to the new font.

If you have not installed the font but receive a Document containing Jinbu font from someone else, the font will be downloaded automatically to ensure proper display and use.

## Spreadsheet | Edit local spreadsheets online and launch data collection for easier handling of sensitive data

With Spreadsheet's "Collect data" feature, ++**entries are invisible to other respondents and results are automatically aggregated back into the Spreadsheet**++ — perfect for collecting sensitive data. Want to use it in local spreadsheet documents too? It's now supported. You can launch data collection from local spreadsheets, making management and statistics more efficient.

</Note>
💡 Available on | Desktop

📖 How to use:

When you Select a local spreadsheet and click "Edit online", the "Collaboration - Collect data" entry appears in the top bar.

The usage is exactly the same as in Spreadsheet. For details, see >>[Launch data collection](https://docs.dingtalk.io/i/p/Y7kmbokZp3pgGLq2/docs/mM3zoYAw1Rr8DkZ39lR2JnZ07y9NpXxD?dontjump=true).

## Spreadsheet | Upload multiple images to a cell via paste

Spreadsheet experience improvement: ++**when uploading multiple images to a cell**++, you can now paste them directly instead of clicking the "Upload" button, making the action more convenient.

</Note>
💡 Available on | Desktop

📖 How to use: Place the cursor over the cell upload area and paste the images directly.

When editing a spreadsheet, you often need to insert multiple links in a single cell. Spreadsheet has been upgraded to ++**support multiple links per cell and a mix of text and links**++, making everyday work more convenient.

</Note>
💡 Available on | All four platforms

📖 How to use: You can now Paste multiple links directly into a Cell.

## AI Table | Insert Link supports custom display text (Professional and Exclusive Edition benefit)

Previously, inserted links displayed only the URL, which made information hard to read. AI Table now ++**supports setting custom display text for links**++, so link previews are more informative.

</Note>
💡 Available on | All four platforms

📖 How to use:

Double-click a "Link type" cell to open the link input menu.

Enter the URL in the link field and the display text in the text field.

The text-styled link is now set.

## DingTalk Whiteboard | Material library now supports "Knowledge Base materials" and "My materials"

Save Template insights distilled from brainstorming sessions, or creative results produced during your work. On DingTalk Whiteboard, you can Select any object on the canvas and ++**save it as My material or Knowledge Base material**++ for easy reuse next time.

</Note>
💡 Available on | Desktop (Read-only on mobile)

📖 How to use:

1. Entry point: Select an element on the whiteboard, then choose "Add to material library" from the right-click menu.

2. Save scope:

Knowledge Base Admin: Can save to Knowledge Base materials, available to all Knowledge Base users.

Knowledge Base user: Can save to My materials, visible only to themselves.

3. Custom material names are supported.

4. Added materials can be deleted.
