## DingTalk Docs supports embedded spreadsheets for efficient and intuitive data processing

DingTalk Docs now supports embedding spreadsheets, letting you calculate, filter, and sort data directly within documents. Boost data processing efficiency and presentation, making data clear and simple.

[Lightbulb] Availability: Android, iOS, Mac, Windows, and Web users

[Notebook] How to use: In DingTalk Docs, click Insert at the top and select Spreadsheet.
---

## Jump directly to group chats from DingTalk Docs for amplified collaboration efficiency

You can now jump to or join group chats from DingTalk Docs, or sync document information to group chats. This strengthens the connection between documents and group chats, enabling one-click join-chat capability for project documents, guide documents, and product promotion documents, making team collaboration smoother.

[Lightbulb] Availability: Configurable on Mac and Windows; runs on Android, iOS, Mac, Windows, and Web

[Notebook] How to use: In DingTalk Docs, click Insert at the top and select Group Chat from the insert panel.
---

## Smart summaries for embedded documents and files put key takeaways at a glance

Embedded documents and files in DingTalk Docs now support smart summaries. Extract the essence of a file with one click to quickly grasp the core information, significantly improving reading and work efficiency.

[Lightbulb] Availability: Mac, Windows, and Web users

[Notebook] How to use: Select the embedded document, click the toolbar of the embedded document, and then click Smart Summary.
---

## Documents now generate digital human videos for more engaging content delivery

Generate digital human videos from documents with one click, quickly turning text into vivid videos to easily meet short-video distribution needs and make content more compelling.

[Lightbulb] Availability: Mac, Windows, and Web users

[Notebook] How to use: In DingTalk Docs, click "..." in the top-right corner, click Download to local, and select Generate AI Video.

## [Magic wand] DingTalk AI Table

---
## "Recognize personal ID" action now accurately identifies 8 ID types for more efficient data extraction

The "Recognize personal ID" automation action now supports 7 additional ID types, enabling fast and accurate information recognition. This greatly improves work efficiency and makes data processing more convenient.

[Lightbulb] Availability: Mac, Windows, and Web users

[Notebook] How to use: When designing an AI Table automation workflow, select Doc AI in the workflow designer, choose Recognize personal ID, and select the type.
---

## Dashboards support digital big-screen mode to intuitively display key data

The dashboard digital big-screen mode is now live. View chart data at a glance and intuitively display key metrics to support efficient decision-making and make data insights more vivid and powerful.

[Lightbulb] Availability: Mac, Windows, and Web users

[Notebook] How to use: In an AI Table dashboard, click Big-screen mode in the top-right corner.
---

## Granular Access supports controlling view edit permissions to precisely safeguard data security

AI Table data security is upgraded again with precise control over view edit permissions. Improve team collaboration efficiency while ensuring data security, making information management more flexible and controllable.

[Lightbulb] Availability: Mac, Windows, and Web users

[Notebook] How to use: In the AI Table Granular Access panel, view the view action permissions and configure them as needed.
---

## Send DingTalk chats action supports combined fields for precise notification delivery

When setting up an AI Table automation action, if the previous action is "Find records" and the next action is "Send DingTalk chats," you can now send combined fields in the message content, sending multiple records as a combined message to create personalized message content.

[Lightbulb] Availability: Mac, Windows, and Web users

[Notebook] How to use: When designing an AI Table automation workflow, if the previous action is Find records, then in the next "Send DingTalk chats" action, click Insert variable when editing the notification content, and select Combined records.
---

## Mobile now supports Find records, letting you reach target data with a single tap

The AI Table mobile app now supports Find records, allowing you to precisely locate target data anytime, anywhere, and efficiently view and analyze data, making mobile work more efficient.

[Lightbulb] Availability: Mac, Windows, and Web users

[Notebook] How to use: In DingTalk AI Table, click "..." in the top-right corner and select Search.
---

## New "Ask AI" automation action provides quick access to key information

A new "Ask AI" action is now available for AI Table automation. Generate text on demand or get answers to questions, significantly boosting work efficiency.

[Lightbulb] Availability: Mac, Windows, and Web users

[Notebook] How to use: When designing an AI Table automation workflow, select Doc AI in the workflow designer, then select Ask AI.
---

## Granular Access is seamlessly copied with tables, eliminating repetitive configuration

When creating a copy of an AI Table, the configured Granular Access settings are copied along with it, eliminating repetitive configuration, improving team collaboration efficiency, and making work more efficient.

[Lightbulb] Availability: Mac, Windows, and Web users

[Notebook] How to use: When creating a copy of an AI Table, if Granular Access has been set on the source AI Table, the Granular Access settings will be automatically synced to the copy after creation, with no need to reconfigure.
---

## Conditions in the Sort and Group panels can be reordered for clearer analysis results

Conditions set in the Sort and Group panels now support custom ordering, with flexible configuration to optimize information presentation and analysis efficiency, making data management more efficient.

[Lightbulb] Availability: Mac, Windows, and Web users

[Notebook] How to use: In the Group/Sort panel, drag conditions directly to adjust their order.
---

## Mail, Phone, and Name can be converted to User fields for more efficient user information organization

If a field contains information such as names, phone numbers, or email addresses, converting the field type to User field will automatically match the information to corresponding members in the organization, making information consolidation easy and collaboration more convenient.

[Lightbulb] Availability: Mac, Windows, and Web users

[Notebook] How to use: When a field contains information such as names, phone numbers, or email addresses, edit the field directly and change the field type to User field.
---

## AI Table supports adding subrecords for clearer information hierarchy

AI Table now supports subrecords, making it easy to set record tiers and build a clear data structure, presenting information at a glance and making management more efficient and convenient.

[Lightbulb] Availability: Mac, Windows, and Web users

[Notebook] How to use: Select a record and right-click to bring up the menu, then click Add subrecord.
---

## Grid field More menu supports freezing up to that field for easier data viewing

AI Table now supports quickly freezing up to a target column, making it easy to lock key information and browse data more efficiently.

[Lightbulb] Availability: Mac, Windows, and Web users

[Notebook] How to use: Select the field name to be frozen, click the dropdown triangle next to the name to bring up the menu, and select Freeze up to this field/column.
---

## Select and Multiselect fields support Reference options for smoother data linkage management

Select and Multiselect fields now support Reference options, enabling data linkage to efficiently improve work efficiency and make collaboration more seamless.

[Lightbulb] Availability: Mac, Windows, and Web users

[Notebook] How to use: Select the Select or Multiselect field to modify. Click "Modify field," choose "Reference options," select the target Table and Field, set the reference conditions, and save the configuration to easily enable option references.
---

## New Formula editor in AI Table makes data analysis smarter and more efficient

The AI Table Formula editor has been upgraded with a clearer, more intuitive layout design, making formula writing less cumbersome. A new formula example library helps you get started quickly and process data more efficiently and conveniently.

[Lightbulb] Availability: Mac, Windows, and Web users

[Notebook] How to use: In the edit panel of the AI Table formula field, click Edit formula to view the latest Formula editor.

## Custom document handover rules ensure zero loss of important materials

Organizations can customize handover rules for documents of departing members and perform batch operations on pending member documents. Important documents won't be lost, handovers become more efficient, and management costs are reduced.

**Requires DingTalk Office Suite Flagship Enterprise plan or above.** **Click to learn more >>**

[Lightbulb] Availability: Mac, Windows, and Web users

Document action logs comprehensively record action traces, including new permissions, public publishing, and admin actions, supporting precise traceability and accountability. They provide a solid evidence base for security control, making actions traceable and accountability evidence-based.

**Requires DingTalk Office Suite Flagship Enterprise plan or above.** **Click to learn more >>**

[Lightbulb] Availability: Mac, Windows, and Web users

[Notebook] How to use: Go to the Admin Console, and click Documents and Organization Storage -> Log query.
