## DingTalk Docs

---
## A smoother My Docs experience with seamless page navigation

Clicking My Docs in the main navigation no longer opens a new page, reducing back-and-forth navigation for a smoother and more convenient experience.

[Bulb] Availability: Mac and Windows users

[Notebook] How to use: On the DingTalk Docs home page, click My Docs.
---

## Sort My Docs and Knowledge Base files in multiple ways for clearer organization

My Docs and Knowledge Base now support sorting by name, created time, update time, and more, helping you efficiently manage and locate materials and keep your documents well organized.

[Bulb] Availability: Mac and Windows users

[Notebook] How to use:

On the My Docs page: Click the sort icon in the top-right corner to open the sort panel and select a sorting method.

On the Knowledge Base page: Click Table of contents in the sidebar to open the sort panel and select a sorting method.
---

## Switch between Edit and Read modes faster for smoother creation

Quickly switch between Edit and Read modes without scrolling to reposition. The smoother transition keeps your creative flow uninterrupted and boosts productivity.

[Bulb] Availability: Mac and Windows users

[Notebook] How to use: Open DingTalk Docs and click the toggle in the top-right corner to switch between Read and Edit modes.
