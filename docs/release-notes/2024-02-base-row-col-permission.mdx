## ✨ AI Table

## Granular Access now supports fine-grained row and column control | AI Table now lets you set row and column edit and view permissions, strengthening data security

The Granular Access feature in AI Table now includes row and column data permission settings. Different roles can now configure view, add, and edit permissions for fields, as well as Table access permissions. This ensures only authorized users can view or edit specific information, strengthening data security. Activate the Office Suite Enterprise plan or above (click to learn more about Office Suite) to configure settings under Granular Access in AI Table.

**😊** **Recommended scenarios:**

Organization managers: Set specific row and column data access permissions for different departments to protect sensitive information from unauthorized viewing or modification.

Finance teams: Set edit permissions on key rows and columns of financial reports to ensure data accuracy and integrity, preventing unauthorized changes.

Educational institutions: Apply row and column permission management to student records, protecting student privacy while allowing teachers to access necessary educational information.

💡 Availability: Mac and Windows users (Office Suite Enterprise plan or above)

📓 How to use: Click Granular Access, click Create role, and select "Edit - Custom scope".
---

## Granular Access now supports exporting viewable data | What you see is what you get, making data management easier

After roles are configured through Granular Access in AI Table, non-Admin users can also export all data visible to them, making information management more efficient and convenient.

**😊** **Recommended scenarios:**

Financial audits: Granular Access in AI Table ensures only authorized data is processed, protecting sensitive information. One-click export delivers clear, efficient financial reports that provide solid data support for organizational decision-making.

Human resources: HR managers can export employee performance and development information with one click, supporting accurate talent planning and training needs analysis while safeguarding employee privacy. This makes HR management more humane and efficient.

💡 Availability: Mac and Windows users (DingTalk Professional Edition, Dedicated Edition, and standalone paid edition)

📓 How to use: In AI Table, click More in the upper-right corner and select Download Excel.
---

## Improved download field experience | Export download fields in Grid view order for easier data organization

When a Table has multiple Grid views, the download field feature now exports data in the order of the first Grid view, ensuring consistency in exported data and saving time on re-sorting.

**😊** **Recommended scenarios:**

Project managers: Export project status reports with one click and ensure every team member sees consistent information layouts, promoting team communication and project progress.

Human resources: Maintain consistent report formats across various HR tasks—from recruitment to training and assessment—boosting professionalism in personnel management.

Supply chain: When exporting order, shipping, and receiving records, a unified report format clarifies every link in the supply chain, improving overall operational efficiency.

💡 Availability: Mac and Windows users (DingTalk Professional Edition, Dedicated Edition, and standalone paid edition)

📓 How to use: In AI Table, click More in the upper-right corner and select Download Excel.
---

## Copy Table structure separately | Copy only the Table structure with one click, no manual data cleanup needed

When copying a Table, you can now choose to copy only the current table style without manually clearing the original data. Reuse table frameworks quickly and simply.

**😊** **Recommended scenarios:**

Project teams: When launching a new project, directly copy the table style from a previous project to instantly start a new dataset, saving time on clearing old data.

Sales teams: When preparing new sales reports, quickly copy existing report styles to maintain professionalism and consistency.

Retail managers: When creating new inventory stocktaking sheets, directly copy past table layouts to start a new round of stocktaking and simplify the process.

💡 Availability: Mac and Windows users (DingTalk Professional Edition, Dedicated Edition, and standalone paid edition)

📓 How to use: Click "More" on the Table, click "Copy Table", and select Copy structure only.

## Automation now supports time from filled records | Say goodbye to manual monitoring; scheduled automated reminders help you manage tasks

Automation now supports referencing time from "Filled records" and setting Time-Based Triggers for messages. Say goodbye to manual monitoring and free up your time and energy—let the automation system serve you on schedule.

**😊** **Recommended scenarios:**

Project managers: Automatically track project milestone dates and trigger reminders at key moments to ensure projects are completed on time.

Marketing: Automatically monitor advertising campaign start and end times to ensure marketing activities are timely and effective.

Event planning: Set automatic reminders for key event milestones—from booking venues to sending invitations—keeping everything on track.

💡 Availability: Mac and Windows users (DingTalk Professional Edition, Dedicated Edition, and standalone paid edition)

📓 How to use: Click Automation, click Trigger, and select "When the time in a record is reached".

**Timeline and Calendar views now support Title configuration | Customize view content for clearer information display**

You can now freely modify the field displayed at the front of each row in Timeline view and the Title field shown in Calendar view, making information display more flexible.

**😊** **Recommended scenarios:**

Project planning: Adjust the key information displayed at the front of Timeline rows based on different project stages to keep the team focused.

Event planning: Display event titles, key dates, and highlight colors on the Calendar view to quickly grasp upcoming highlights and deadlines.

Project managers: Adjust the Timeline to reflect important construction milestones, making resource allocation and progress monitoring more efficient.

💡 Availability: Mac and Windows users (DingTalk Professional Edition, Dedicated Edition, and standalone paid edition)

📓 How to use:

1. Open Timeline, access Field management, and modify the Title display field in Timeline configuration.

2. Open Calendar, access Field management, and modify the Title display field in Calendar configuration.
