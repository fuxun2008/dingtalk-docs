## What Is AI Table?

AI Table is a next-generation, table-based data collaboration tool. It is an online, visual database application. AI Table lets you build relationships between tables and supports multiple views: Grid, Timeline, Calendar, Kanban, Gallery, and Form. Each view has its own scenarios and features, helping you efficiently present information and enable multi-user collaboration across your organization.

Unlike traditional spreadsheets, every column in AI Table has a unified field type, and every record is a single data entry. You can sort, filter, group, and otherwise operate on data views. With this data-driven approach, AI Table is ideal for data aggregation, dashboard analysis, task management, and report consolidation.

## How to Use AI Table

### Create an AI Table

On the PC client, go to the AI Table Home page. You can create a blank AI Table or start from an existing template.

### Share an AI Table

Click **Share** in the upper-right corner to share with colleagues in your organization for collaboration.

### Create a Table

In the new AI Table, click **Create** in the lower-left corner to create a Table.

Click `...` on the right side of the Table to rename it, edit its description, copy it, move it, or delete it.

### Create a View

Click the **+** icon to the right of the view tabs at the top to create a view.

## Highlight Features of AI Table

### Multiple Field Types with Grouping and Sorting

Each column in AI Table is called a Field. Fields are the headers of an AI Table—they define the type and format of every column, keeping your data structured and consistent.

### One Dataset, Multiple Perspectives

Multi-view presentation is the soul of AI Table. Depending on your data type and use case, you can present data in different views such as **Grid, Kanban, Timeline, and Gallery**.

Take resume collection for example: after gathering resumes, you can filter candidates across multiple dimensions, assign owners to track interview progress, schedule interviews, and visualize each candidate's interview cycle time at a glance.

### Automation Workflows

Building automation workflows with AI Table dramatically improves collaboration efficiency and accuracy while reducing the risk of errors.

**Trigger an Automation after form submission**

Take an inspection scenario as an example: when a submission is marked **Exception**, AI Table Automation triggers a problem ticket sent to the designated group or person.

[Create a ticket workflow after an issue is detected](https://docs.dingtalk.io/i/nodes/G1DKw2zgV2KnvL4kFrmQ22NPJB5r9YAn)

**Auto Reply to the Submitter**

For a feedback scenario: after a question is submitted via a form, the handler is notified automatically. Once the resolution is updated in the table, the submitter is automatically notified.

### Granular Access

Define custom roles to precisely control who can view and edit each Table. This enables finer-grained permission management and stronger data security.

### Dashboards

Dashboards visualize your AI Table data. With simple configuration, you can quickly build a business overview.

### Charts Support "Word Cloud"

For manufacturing inspection scenarios, you can intuitively display "reasons for non-compliance," enabling more precise data analysis.

### Data Linking with Dynamic Updates

In AI Table, working with data is like using a visual database. Every column has a fixed, standardized field type, and AI Table supports a wide range of field types to cover almost every enterprise collaboration scenario.

### Efficient Collaboration

AI Table supports multi-user collaborative editing, making joint data management fast and efficient.

### Import and Download Excel

AI Table now supports importing .xlsx files, other data sources, and other files from the document menu, helping you quickly populate an AI Table. You can also export data to local Excel files and back up attachments, making the process fast and convenient.

### Save and Create AI Table Templates

AI Table templates are available. When creating a new document, you can choose a popular template that matches your needs to create an AI Table in one click, or pick a template from a blank document. If you have a great document you want to save as a template for yourself or others, save it to **My Templates** or **Team Documents** with one click.
