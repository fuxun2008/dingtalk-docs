**DingTalk Docs: more efficient content collaboration with DingTalk Docs**

*   Slash commands that connect everything

*   Smart authoring, powered by AI Minutes

*   Presentation mode that turns documents into slides instantly

*   One-click connection to office apps

*   Create and share long images and videos in one click

*   Open links for unlimited expression

**Spreadsheet: secure and efficient collaborative online spreadsheets**

*   Smooth real-time collaboration for thousands of users

*   Compatible with Office Excel

*   Lock cells for fine-grained permissions

*   6 major function categories and 400+ mainstream formulas

*   Pivot tables and rich charts

*   Cell comments for focused communication

*   Filter views that work independently without interference

**DingTalk AI Table: project management collaboration beyond boundaries**

*   Easy to use—if you can use a spreadsheet, you can build a management system

*   Rich views: generate Timelines, Calendars, Kanban boards, Galleries, and more in one click

*   Manage data more efficiently with structured organization

*   Clear data analysis with one-click Dashboard generation

*   Strong collaboration capabilities: Comments, @ People, date reminders, and multiple notification options keep every task on track

**DingTalk Mind: a collaborative graphical thinking tool**

*   Rich structures and diverse themes

*   One-click assignment for efficient execution

*   Engaging presentations with bullet-chat interaction

*   Versatile sharing via images and links

*   Online comments with notifications delivered straight to chats

*   Switch between Outline and Mind Map in one click

**Knowledge Base: one-stop enterprise knowledge management and accumulation**

*   Transfer scattered files in one click

*   Link documents to documents with bidirectional references

*   Organize knowledge with structured tables of contents

*   Comprehensive permission management

*   Public publishing with approval for secure information release

*   Book library for structured knowledge management

**DingTalk Whiteboard: multi-user collaboration that sets inspiration free**

*   Rich elements for unlimited creativity

*   Borderless canvas for sparking ideas

*   Optimized for iPad with flexible editing for paperless work

*   Multi-user collaboration for efficient communication across distances.
