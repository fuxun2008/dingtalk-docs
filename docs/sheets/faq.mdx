<AccordionGroup>
  <Accordion title="Why can't I edit a spreadsheet online in DingTalk?">
    Encrypted Excel files cannot be edited online.
  </Accordion>
  <Accordion title="How do I make filtered data visible only to myself?">
    Use the filter view feature on the toolbar. Path: Click **Filter** on the toolbar > **Create filter**. When filtering data, select **Only visible to me** for the filter results.
  </Accordion>
  <Accordion title="How do I change the permissions so that all users can view the spreadsheet?">
    If the permission scope is set to "Entire spreadsheet", click **Share** in the top-right corner to set user permissions.
  </Accordion>
  <Accordion title="How do I @ someone outside my organization in a spreadsheet?">
    Mentioning Contacts outside your organization is supported. Enter @ in a Cell to quickly select users outside your organization.
  </Accordion>
  <Accordion title="Where can I view the version History of a spreadsheet?">
    Click the navigation bar in the top-left corner, then go to **Menu > Spreadsheet >** **History**.
  </Accordion>
  <Accordion title="How do I download a DingTalk Spreadsheet?">
    Open the file, then click **Menu > Spreadsheet > Download as** in the top navigation bar to quickly save it locally.
  </Accordion>
  <Accordion title="What is the maximum number of Worksheets that can be created in an online Spreadsheet?">
    Up to 1,000 Worksheets are currently supported. For a better experience, we recommend not creating too many Worksheets in a single Spreadsheet.
  </Accordion>
  <Accordion title="How do I add Annotations to a specific spreadsheet?">
    Click a Cell, then right-click to add a comment.
  </Accordion>
  <Accordion title="Can the Find feature in a spreadsheet search across all Workbooks?">
    The Find feature currently only searches within the current Worksheet.
  </Accordion>
  <Accordion title="Can I print a Spreadsheet directly?">
    Yes. Click **Menu > Spreadsheet > Print** in the top navigation bar to print quickly.
  </Accordion>
</AccordionGroup>
