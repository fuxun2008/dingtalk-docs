## Value

The Watch selection feature in Spreadsheet sends timely alerts when Data is added, removed, or modified, enabling smoother and more responsive User Collaboration.

## Use case

Ding Sanduo is an administrative clerk who regularly uses Spreadsheet to consolidate office supply requests from different Departments. With the Watch selection feature enabled, Department leads Submit their office supply requests directly in the Spreadsheet. Whenever a Cell is updated, Ding Sanduo immediately receives a DingTalk Message notification, removing the need for separate reminders. This reduces communication overhead and boosts Collaboration efficiency.

## How to use

*   In the Spreadsheet toolbar at the top, click [Menu] in the upper-left corner - [Collaboration] - [Watch selection] - [Watch cells]. Select the area you want to watch, and choose the Colleagues to notify when Data is updated (you can select Users from the Knowledge Base that contains the Spreadsheet).

*   In addition, if a Spreadsheet contains multiple sheets but you only want to watch one of them, open the target sheet and click [Collaboration] - [Watch selection] - [Watch worksheet].
