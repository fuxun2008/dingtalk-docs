title: "Edit rows or columns"
description: "DingTalk Sheets row and column editing: insert, delete, hide rows or columns, and adjust row height or column width via the right-click menu or toolbar to organize your spreadsheet layout efficiently."
---

In DingTalk Spreadsheet, you can insert, delete, hide, and set row height or column width for rows and columns to better organize the spreadsheet layout.

## Insert rows or columns

1.  Select the target row or column.

2.  Open the right-click menu, find Insert Row or Column, specify the direction and number of rows or columns to insert, and click Insert.

3.  Insert rows at the bottom: When the current number of rows is insufficient, scroll to the bottom of the spreadsheet to insert rows in bulk.

## Delete rows or columns

1.  Select the target row or column.

2.  Open the right-click menu and choose **Delete selected row or column**.

## Hide rows or columns

For data that you do not want to display temporarily but do not want to delete, use the "Hide" function for rows or columns to hide them temporarily.

1.  Select the target row or column, then **open the right-click menu and choose Hide row or column**.

2.  An icon appears next to hidden rows or columns. Click the icon again to unhide them.

## Set row height or column width

1.  Select the target row or column.

2.  Open the right-click menu, find Column width or Row height, and enter the desired value.

## Auto-fit row height or column width

If the selected cell already contains data or an inserted image, you can also choose **"Auto-fit row height or column width"**. The row height or column width then adjusts automatically based on the width and height of the content.
