DingTalk Spreadsheet supports inserting comments in cells. With Cell comments, you can add aliases directly to content and @ Users for real-time collaboration, improving the efficiency of content creation and editing.

## Instructions

*   Cell comments: Select a cell, right-click, and choose **Add comment**.

*   When you @ a User in a comment, the recipient is notified in the message window. Click the message to open the Spreadsheet and view the comment.

Notes:

1.  When you @ another User, the recipient receives a Message notification via DingTalk Direct Message from the comment author.

2.  Cell comments support inserting Emoji.

3.  You can add follow-up comments or replies to the same Cell.

4.  Click **Toolbar - Comments - View all comments**, or use the right-side panel to view all comments in the current Worksheet.

5.  You can only Delete comments you have posted. Deleted comments cannot be recovered.

6.  In the comment List on the right, you can view resolved comments and reopen them to resume the discussion.
