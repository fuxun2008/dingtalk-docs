---

In DingTalk Spreadsheet, the entire spreadsheet file is called a **Workbook**, and each workbook can contain multiple **Worksheets**. You can add, delete, and edit worksheets.

## Create

Click the icon in the bottom bar to create a new worksheet. The new worksheet is placed after the current worksheet by default.

## Edit a worksheet

**Rename**: Double-click the worksheet name, or right-click and select **Rename** to change the worksheet name. The name cannot duplicate an existing one.

**Copy a worksheet**: Select the worksheet you want to copy, then right-click and select **Copy**.

**Move a worksheet**: Select the worksheet you want to move, then drag it with your mouse, or right-click and select **Move left / Move right**.

## Hide a worksheet

Select the worksheet you want to hide temporarily, then right-click and select **Hide**. To display it again, click the icon on the left to expand all worksheets, then click the hidden worksheet to unhide it.

## Search worksheets

When there are more than 10 worksheets, a search entry appears. You can search worksheets by keyword.
