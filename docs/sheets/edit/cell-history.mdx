title: "Cell history"
description: "DingTalk Sheets cell history lets you right-click any cell to view up to 1,000 records of data additions, edits, and deletions — giving you a full audit trail of content changes without row or column structural changes."
---

Spreadsheet supports viewing cell history, so every edit and deletion is traceable and every change has a clear record.

## Instructions

1. Entry: Right-click a cell and select View History.

2. Up to 1,000 records are displayed.

3. Only data-level additions, deletions, and modifications are shown. Changes to row or column structure are not included.
