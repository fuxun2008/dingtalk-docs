## Feature value

After updating spreadsheet content, select specific recipients to send message notifications, with support for editing the message content. Keep updates visible and ensure every change is accounted for.

## Use case

Ding Sanduo is a product manager at an internet company. He uses Spreadsheet daily to track the launch progress of new product features and collaborates with Department Colleagues to fill in information. Delays in syncing information can sometimes affect overall project Progress. With the "Form update notification" feature, users can receive spreadsheet update Notifications instantly and select specific recipients to send message notifications, avoiding disturbing unrelated personnel.

## Instructions

Entry point: Top navigation bar — right side of the Save status — Notify others.

Available User list: Users in the current permission panel (top-right corner) with Document View Permission or above. Searching for users is not yet supported.

Default selected Users: The Chat object from the previous level and the Document creator. If a selection has been made before, the previous selection will be retained.
