In DingTalk Spreadsheet, use Sort to rearrange data in a specified order. This is an essential way to organize your data.

## Instructions

Select the target range and click **Sort** in the toolbar. From the drop-down menu, choose a sort method. Custom sort is also supported, allowing you to adjust the spreadsheet order based on your needs.

*   Number-type data is generally sorted by overall numerical value.

*   Text-type data is generally sorted by English letters or the alphabetical order of Chinese pinyin.

*   Tips: To get accurate sort results, standardize the data format before sorting.
