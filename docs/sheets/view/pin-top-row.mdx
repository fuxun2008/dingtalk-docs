description: "DingTalk Sheets Pin to Top on desktop: select any row and use the Freeze toolbar menu to keep it fixed at the top while scrolling — ideal for pinning header rows or key summary rows. Unpin with a single click."
---

Spreadsheet on desktop lets you keep specific records fixed at the top while scrolling, making it easy to pin all your headers in place.

## Instructions

*   Pin records to the top: On desktop, select a record >> click the toolbar >> Freeze >> Pin selected record to the top.

*   Unpin records: On desktop, select the pinned record >> click the toolbar >> Freeze >> Unpin.
