## Value

View charts on mobile with the Chart view. Browsing spreadsheets feels like flipping through an album, delivering an immersive and smooth experience.

## Use cases

The mobile Kanban experience has been fully upgraded. Break free from the limits of mobile screens, switch Chart view modes freely, and tap to view a full-size chart so you never miss any data.

## Instructions

1. Select a chart. A menu tip will indicate that you can view the full-size chart. Tap to view it directly.

2. Tap the bottom bar — View — Chart view to open the chart list, which displays all charts in the current Worksheet. Select any chart to view it, and swipe to switch between charts.
