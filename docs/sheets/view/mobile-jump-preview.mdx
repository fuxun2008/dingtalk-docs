## Value

Spreadsheet on mobile supports double-tap preview for faster content viewing.

## Use cases

Previously, double-tapping a cell on mobile would always enter edit mode. Spreadsheet has now been upgraded so that for cells containing images, links, or attachments, **double-tapping opens a preview directly**, making content easier to view.

## Instructions

1. Double-tap an image, link, or attachment in the Spreadsheet on your mobile device.

2. The image opens at full size, the link opens its URL, or the attachment opens in preview.
