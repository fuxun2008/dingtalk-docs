---
title: "Set text styles"
description: "DingTalk Sheets text styles: apply bold, italic, underline, strikethrough, font color, and cell fill color from the toolbar or menu to emphasize key data and improve the readability and visual appeal of your spreadsheet."
---

Adjusting text styles highlights key information, makes the subject stand out, and diversifies the display of Spreadsheet content. It helps readers quickly grasp key points and better understand the Spreadsheet. Thoughtful text formatting also enhances the visual appeal of your Spreadsheet.

## Style 1: Bold

Bold enlarges the text and intensifies the font color, making it more visually prominent. It is commonly applied to the first row, first column, or title of a Spreadsheet—similar to how titles are bolded in Documents as a standard practice.

Select the target Cell, then click **Menu > Format > Text style > Bold** at the top. Alternatively, select the target Text and click **Bold** in the toolbar for quicker access.

## Style 2: Italic

Select the target Cell, then click **Menu > Format > Text style > Bold** at the top. Alternatively, select the target Text and click **Italic** in the toolbar for quicker access.

## Style 3: Underline

Underline is typically used to emphasize key points within the text.

Select the target Cell, then click **Menu > Format > Text style > Underline** at the top. Alternatively, select the target Text and click **Underline** in the toolbar for quicker access.

## Style 4: Strikethrough

**(Shortcut: Ctrl + Shift + X) (Mac: Cmd + Shift + X)**

Strikethrough is typically used to indicate revisions to existing content or for Approval purposes.

Select the target Cell, then click **Menu > Format > Text style > Strikethrough** at the top. Alternatively, select the target Text and click **Strikethrough** in the toolbar, or press Ctrl + Shift + X for quicker access.
