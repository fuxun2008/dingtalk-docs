When processing and beautifying spreadsheets, you often need to make large-scale changes to colors, fonts, and formats. Modifying cells one by one is tedious and time-consuming. The Format Painter lets you complete these operations quickly and easily, eliminating the need to handle each cell individually.

## Instructions

## Format Painter

*   First, select the source Cell whose format you want to copy.

*   Then, click **Format Painter** on the left side of the toolbar. The format of the source Cell is copied immediately. When the cursor turns into a brush shape, the format has been copied successfully.

*   Finally, select the target Cell to apply the format. Click once, and the copied format is applied to the target Cell. The target Cell instantly takes on the same format as the source Cell, indicating that the Format Painter has been applied successfully.

## Clear Formatting

*   First, select the target Cell to be cleared.

*   Then, click **Clear Formatting** on the left side of the toolbar, **or use the shortcut Ctrl + / (Mac: Cmd + /)** to complete the action efficiently. Alternatively, **right-click and choose Clear > Clear Formatting.**
