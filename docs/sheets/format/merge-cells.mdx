When creating spreadsheets, you often need to organize subjects and categories. A single title may cover multiple entries, so you need to merge the cells that hold the title. Merging cells is commonly used when formatting the first row or column.

## Merge Cells

Select the target cells to merge, and then click **Merge Cells** on the toolbar to merge the cells instantly.

## Additional Notes

*   Two or more cells that have already been merged cannot be merged again. To continue merging, unmerge them first and then perform the merge.

*   When merging two or more cells with different text content, the system retains only the text in the top-left cell by default. All other text will be cleared.

## Unmerge

Select a merged cell. The Merge Cells button on the toolbar changes to **Unmerge Cells**. Click it to unmerge the cells.

## Additional Notes

*   Unmerge supports batch operations. You can select multiple merged cells and unmerge them at the same time.

*   After unmerging, the text remains in the top row by default, and the alignment stays unchanged.
