Spreadsheet supports three text wrapping options: **Overflow, Wrap Text, and Clip**. Wrapping options are typically used for cells with large amounts of text. By adjusting the wrapping option, all text remains visible at a glance without being hidden, and spreadsheet size stays under control.

## Overflow

Displays text that exceeds the cell width in the adjacent cells.

Select the target cell, click **Menu** —> **Format** at the top, and then select **Alignment —> Overflow** from the drop-down menu. Alternatively, select the target text and click **Wrap Text —> Overflow** in the toolbar for a quick adjustment.

## Wrap Text

Automatically breaks long text in a cell based on the cell width and continues the text on the next line within the same cell.

Select the target cell, click **Menu** —> **Format** at the top, and then select **Alignment —> Wrap Text** from the drop-down menu. Alternatively, select the target text and click **Overflow —> Wrap Text** in the toolbar for a quick adjustment.

## Clip

Hides text that exceeds the cell width.

Select the target cell, click **Menu** —> **Format** at the top, and then select **Alignment —> Clip** from the drop-down menu. Alternatively, select the target text and click **Wrap Text —> Clip** in the toolbar for a quick adjustment. Clip is generally used for non-essential text in a spreadsheet.
