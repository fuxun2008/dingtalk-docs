## Feature value

Tired of entering repetitive data in spreadsheets? The new AutoComplete input feature automatically matches content, reducing data entry workload, maintaining data consistency, and improving efficiency.

## Use cases

Ding Sanduo is an administrative clerk who uses DingTalk Spreadsheet daily to track HR records, event schedules, and expense reimbursements for the Company. With the AutoComplete input feature in DingTalk Spreadsheet, when entering Content in a Cell, the system automatically matches existing entries based on the keywords typed, enabling one-click selection. This improves data entry efficiency and ensures consistency across entered Data.

## Instructions

When you enter content in a Cell, the system automatically matches existing content in the current Column based on the keywords typed, allowing you to select with one click.
