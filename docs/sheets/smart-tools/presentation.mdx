When delivering data reports, Spreadsheet supports Presentation mode, which turns a Spreadsheet into a PPT with one click. This makes data reporting smoother and saves you the hassle of creating slides.

## Instructions

### How to enter Presentation mode

Click **Presentation mode** in the upper-right corner to instantly turn your Worksheet into a PPT.

### Adjustments in Presentation mode

In the Presentation mode interface, you can make the following adjustments:

1.  **Font Size**: Click the zoom A icon in the upper-right corner to adjust the Font.

2.  **Interface scale**: Use the scale box in the lower-right corner to resize the display interface.

3.  **Create a temporary Filter View**: Select the target area, then click the Filter icon in the upper-left corner to create a temporary Filter View. This lets you compare Data horizontally and vertically, helping the audience better understand the Data.

4.  **Sort**: Select the target area and click Sort in the upper-left corner to arrange the selection in ascending or descending order. Alternatively, without selecting an area, click Sort in the upper-left corner to apply ascending or descending order to the entire Spreadsheet.

    (Note: You cannot Sort a range that contains vertically merged cells.)

### Exit Presentation mode

*   Click the **"Exit Presentation mode"** button in the upper-left corner to exit immediately.

*   Press F11 to exit full-screen Presentation mode.
