## INDIRECT function

The INDIRECT function parses text into a range reference. In most formulas, references are typically entered directly, such as SUM(A1:A5), where A1:A5 is not wrapped in quotation marks and directly represents the range A1:A5.

INDIRECT is generally used in combination with the concatenation operator "&" or text functions.

**Example:** In cell C1 of a "Summary" sheet, the INDIRECT parameter is concatenated into the text "Apples!B:B". After being parsed by the INDIRECT function, it references column B of the "Apples" sheet, and the SUM function then calculates the "Total sales".
