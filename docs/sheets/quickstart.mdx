DingTalk Spreadsheet is an online collaborative spreadsheet developed in-house by DingTalk, an Alibaba Group product. With Spreadsheet, you can work with others on spreadsheets in DingTalk or in a browser. It supports day-to-day data tracking, online co-editing, and customizable permissions to keep your data secure.

*   For example, product operations teams often need to plan and roll out campaigns. These campaigns involve many small, interconnected tasks. **Use a project management spreadsheet** to plan and track the campaign, coordinate developers, testers, product managers, and operations staff, and execute the plan smoothly.

*   For example, as a store manager, you need to track product sales volume and revenue. You create a Product Sales List and invite store staff to fill it in together. However, for key sales data such as Volume, Unit Price, and Amount, you want only the store manager and deputy manager to edit, and want to hide these fields from everyone else. This **prevents leakage of core data and keeps your data secure.**

With DingTalk Spreadsheet, three core capabilities deliver both **efficient collaboration** and **data security**, helping you balance productivity and protection when working with documents.

## ｜01 Data permissions and security

## Easily lock down important and sensitive data

When multiple employees edit the same spreadsheet online, use the **Lock permissions** feature to assign different permissions to different roles. This lets people enter data efficiently while keeping it secure.

*   Lock Edit Permission: lock important data so only designated users can edit it.

*   Lock View Permission: lock sensitive data so other users cannot view it.

The same spreadsheet looks different to each role: the store manager can configure view permissions per employee, while regular store staff can only view and edit the data they are allowed to see.

## ｜02 Present data clearly and beautifully

## Stay on top of the latest data and let your data speak

Build a wide range of complex spreadsheets, including Line, Pie, bar, and dynamic Charts. Create stunning data visualizations to take on virtually any reporting challenge.

**Conditional Formatting lets your data speak:** highlight cell ranges that match specific rules with custom styles and formats, making it easier to find and identify data at a glance.

**Zebra striping for instant polish:** apply a Spreadsheet style with one click to beautify smaller tables and present data more attractively.

**Data visualization Charts:** turn existing Data into visual Charts for clearer presentation.

## 📲 How to use DingTalk Spreadsheet

*   Desktop: in DingTalk, click **Document** on the left toolbar, then **+ Create**, then **Spreadsheet**.

*   Mobile: in DingTalk, tap **More** on the bottom toolbar, then **Document**, tap **+** in the lower-right corner, and select Create DingTalk Spreadsheet.
