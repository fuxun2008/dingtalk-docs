## Value

Dropdown List options support Multiselect, enabling more comprehensive Content annotation.

## Use Cases

Dropdown List options make it easy to quickly enter repeated values, but annotating multiple repeated items at the same time used to be difficult. Spreadsheet's Dropdown List now offers a new Multiselect feature. With Multiselect enabled, a Cell can hold two or more annotations at once, freely combined and added.

## Instructions

Setup steps:

1. Insert > Dropdown List.

1. Dropdown List Settings > Multiselect.

How to use:

1. Click to expand the Dropdown List and select multiple Tags.
