## Value

Insert or bulk remove web links with a right-click for more convenient link editing.

## Use cases

When editing a Spreadsheet, right-click to easily insert or delete links, making content editing more efficient.

## Instructions

1.  Select a Cell, then right-click to access the new "Insert Link" shortcut.

2.  When the selection contains links, right-click and select "Remove Link" to bulk remove links quickly.
