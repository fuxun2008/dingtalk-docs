---
title: "Set Date Reminders Efficiently"
description: "DingTalk Sheets date reminders: insert an event reminder via the menu, then pick a date or specific time from the calendar panel to quickly populate a cell — ideal for project timelines, task lists, and work plans."
---

In Spreadsheet, click **Menu -> Insert -> Event Reminder**. Select a date from the calendar to quickly enter date-formatted data into a cell. By default, the data appears as a date. To display a specific time along with the date, select the Include time checkbox at the bottom of the calendar panel. This feature is ideal for project management spreadsheets, task lists, work plans, and similar scenarios.

## Instructions

1.  Create a task list and insert a column to represent the completion time.

2.  Select a blank cell and click **Menu -> Insert -> Event Reminder** on the top navigation bar. The **Date picker panel** appears below the cell.

3.  Select a date or a specific time point as needed.
