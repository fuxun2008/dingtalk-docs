In Spreadsheet, use Insert Link to add other data content as hyperlinks, helping you find content quickly. The following link types are supported: URL addresses, other cells, and other worksheets.

## Instructions

## Insert a link

### Standard URL

1.  Select the cell where you want to insert the link, then click **Insert - Link** on the top navigation bar.

2.  Enter the title text to be displayed externally in the **Title** field.

3.  Enter or paste the link address in the **Address** field.

4.  Click **Confirm** to complete the link.

### Link to another cell in the same spreadsheet

1.  Select the cell where you want to insert the link, then click **Insert - Link** on the top navigation bar.

2.  In the Address field, select Link to Cell.

3.  Use the Range Selector to manually enter or directly select a cell.

4.  Modify the Title, then click Confirm to complete the link.

5.  Click the link to redirect to the corresponding cell.

|  |
| --- |
|  |

### Link to another worksheet

1.  Select the cell where you want to insert the link, then click Insert - Link on the top navigation bar.

2.  In the Address field, select Link to Worksheet, then choose an existing worksheet in the current spreadsheet.

3.  Click Confirm to complete the link.

4.  Click the link to redirect to the corresponding worksheet.

|  |
| --- |
|  |

### Edit or cancel a link

1.  Select the link in the cell to expand the **Link panel**.

2.  The **Link panel** supports the following actions:

*   **Edit**: Click to modify the link.

*   **Copy**: Click to copy the link address with one click.

*   **Cancel**: Click to cancel the link attribute of the current cell. The content entered in the cell will not be deleted.
