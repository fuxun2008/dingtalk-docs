Customize the home page to showcase your group's team culture, Knowledge Base, and members. This helps users understand team activities, stay updated, and quickly access frequently used documents to boost Team collaboration efficiency.

## How to Build the Knowledge Group Home Page

On the group Home page, click **Layout** on the right to enter the Custom Home page editor. Set up the Home page by adding layouts, inserting modules, and configuring visibility Permissions.

### Add a Layout

After adding a layout, you can insert the modules you want to display and configure their Content. Four layout styles are currently supported. Select the one that best fits the type of Content you want to display.

### Add Modules to a Layout

After adding a layout, drag the required modules from the Component panel into the layout. For example, to add a carousel module, drag it in and configure the module Title. Once saved, you can configure the module Content on the Home page.

### Configure Module Content

After saving and returning to the Home page, configure the Content of the newly added modules. For example, if you added a carousel module in the previous step, you can set the Title, Upload Images, display text, and redirect Links.
