<AccordionGroup>
  <Accordion id="q1" title="What is the difference between Knowledge Group and Knowledge Base?">
    Both Knowledge Group and Knowledge Base are platforms that provide collaboration and management capabilities.

    The difference is that Knowledge Group is a superset of Knowledge Base. A Knowledge Group can consist of multiple Knowledge Bases, effectively aggregating scattered information. In addition to basic uses such as content creation, team collaboration, and knowledge accumulation, it also supports building a team or organization culture homepage to shape a learning-oriented organizational culture. More features are waiting for you to explore.
  </Accordion>
  <Accordion id="q2" title="How do I move an existing Knowledge Base in DingTalk Docs into a Knowledge Group?">
    There are currently two ways to add it.

    *   Option 1: Import from within the Knowledge Group. On the homepage guide box that appears when you first turn on the group, select [Import existing Knowledge Base] to import in bulk. However, only Knowledge Bases for which you are the Admin and that have not yet been added to a group can be imported.
    * Option 2: Move from within the Knowledge Base. On the homepage of the Knowledge Base you want to move, click in the top right corner, then [Advanced settings], and select the group under [Assign to Group].
  </Accordion>
  <Accordion id="q3" title="Can I import an external product manual into a Knowledge Base within a Knowledge Group?">
    Yes. On the Knowledge Base options screen of the Group, click [Import] and select [Import Confluence Space] to move content from a Confluence space.
  </Accordion>
  <Accordion id="q4" title="Where is the Group entry point on mobile? How do I use it?">
    Go to [DingTalk mobile] - [More] - [Docs] - [Knowledge Group], then select the target Group to create and manage it.
  </Accordion>
  <Accordion id="q5" title="I am the Admin of a Group. Will I automatically have permissions for every Knowledge Base in the group?">
    Yes. Knowledge Bases within a group inherit group user permissions by default, so the Group Admin also has management permissions for the Knowledge Bases within the group.
  </Accordion>
  <Accordion id="q6" title="Can I add External users to a Group?">
    Adding External users is not currently supported.
  </Accordion>
  <Accordion id="q7" title="How do I bulk add users from the Organization Structure with permissions to a Knowledge Group or Knowledge Base?">
    To add to a Knowledge Group: On the group user options screen, the Admin can click [Add user] - [Select from Organization] and choose the users to add.

    To add to a Knowledge Base: On the Knowledge Base options screen, select the Knowledge Base you want to add users to, click [...] - , then select [Users and permissions] - [Add user] - [Select from Organization]. Note that this is only supported for Knowledge Bases where you are the creator.
  </Accordion>
  <Accordion id="q8" title="When an Employee leaves the Organization, will they be automatically removed from the Group?">
    Yes.
  </Accordion>
  <Accordion id="q9" title="After the Owner of a Knowledge Group leaves, how can ownership be transferred?">
    Two transfer methods are currently supported.

    *   Active transfer: The current Owner is generally the Admin by default. On the group user options screen, the individual can use the [Transfer] action to select a recipient from Contacts or the Organization Structure and transfer management permissions to another person with one click.
    *   Passive transfer: After the Owner leaves, the Organization Admin can sign in to the DingTalk Admin Console ([https://oa.dingtalk.io/](https://oa.dingtalk.io/)) to transfer the Employee's assets, including Groups. Select the relevant content to complete the transfer.
  </Accordion>
  <Accordion id="q10" title="Is there a limit on the number of Knowledge Bases in a Knowledge Group? Will they count toward storage capacity?">
    Up to 200.
  </Accordion>
  <Accordion id="q11" title="Can multiple Department Groups be created within a single Department?">
    Multiple Knowledge Groups can be created within a Department based on Organization Structure tiers. However, only one Knowledge Group can be created or bound per Organization Structure node.
  </Accordion>
  <Accordion id="q12" title="How do I enable Knowledge Group?">
    Knowledge Group is currently in invite-only beta. To try it out, contact DingTalk customer support to request access.
  </Accordion>
</AccordionGroup>
