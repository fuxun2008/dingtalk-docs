**Q: What is the difference between Knowledge Group and Knowledge Base?**

A: Both Knowledge Group and Knowledge Base are platforms that provide collaboration and management capabilities.

The difference is that Knowledge Group is a superset of Knowledge Base. A Knowledge Group can consist of multiple Knowledge Bases, effectively aggregating scattered information. In addition to basic uses such as content creation, team collaboration, and knowledge accumulation, it also supports building a team or organization culture homepage to shape a learning-oriented organizational culture. More features are waiting for you to explore.

**Q: How do I move an existing Knowledge Base in DingTalk Docs into a Knowledge Group?**

A: There are currently two ways to add it.

*   Option 1: Import from within the Knowledge Group. On the homepage guide box that appears when you first turn on the group, select [Import existing Knowledge Base] to import in bulk. However, only Knowledge Bases for which you are the Admin and that have not yet been added to a group can be imported.

*   Option 2: Move from within the Knowledge Base. On the homepage of the Knowledge Base you want to move, click ⚙️ in the top right corner, then [Advanced settings], and select the group under [Assign to Group].

**Q: Can I import an external product manual into a Knowledge Base within a Knowledge Group?**

A: Yes. On the Knowledge Base options screen of the Group, click [Import] and select [Import Confluence Space] to move content from a Confluence space.

**Q: Where is the Group entry point on mobile? How do I use it?**

A: Go to [DingTalk mobile] - [More] - [Docs] - [Knowledge Group], then select the target Group to create and manage it.

**Q: I am the Admin of a Group. Will I automatically have permissions for every Knowledge Base in the group?**

A: Yes. Knowledge Bases within a group inherit group user permissions by default, so the Group Admin also has management permissions for the Knowledge Bases within the group.

**Q: Can I add External users to a Group?**

A: Adding External users is not currently supported.

**Q: How do I bulk add users from the Organization Structure with permissions to a Knowledge Group or Knowledge Base?**

A: To add to a Knowledge Group: On the group user options screen, the Admin can click [Add user] - [Select from Organization] and choose the users to add.

To add to a Knowledge Base: On the Knowledge Base options screen, select the Knowledge Base you want to add users to, click [...] - ⚙️, then select [Users and permissions] - [Add user] - [Select from Organization]. Note that this is only supported for Knowledge Bases where you are the creator.

**Q: When an Employee leaves the Organization, will they be automatically removed from the Group?**

A: Yes.

**Q: After the Owner of a Knowledge Group leaves, how can ownership be transferred?**

A: Two transfer methods are currently supported.

*   Active transfer: The current Owner is generally the Admin by default. On the group user options screen, the individual can use the [Transfer] action to select a recipient from Contacts or the Organization Structure and transfer management permissions to another person with one click.

*   Passive transfer: After the Owner leaves, the Organization Admin can sign in to the DingTalk Admin Console ([https://oa.dingtalk.io/](https://oa.dingtalk.io/)) to transfer the Employee's assets, including Groups. Select the relevant content to complete the transfer.

**Q: Is there a limit on the number of Knowledge Bases in a Knowledge Group? Will they count toward storage capacity?**

A: Up to 200.

**Q: Can multiple Department Groups be created within a single Department?**

A: Multiple Knowledge Groups can be created within a Department based on Organization Structure tiers. However, only one Knowledge Group can be created or bound per Organization Structure node.

**Q: How do I enable Knowledge Group?**

A: Knowledge Group is currently in invite-only beta. To try it out, contact DingTalk customer support to request access.
