## What is smart proofreading?

Turn on smart proofreading to detect common typos and spelling errors, and receive suggested corrections to safeguard your writing.

## Use cases

Ding Sanduo is a content operations specialist in the planning department who uses DingTalk Docs every day to write promotional copy and work articles. With smart proofreading turned On, any typos or spelling errors that slip in during writing are automatically detected, and suggested corrections are provided. There is no need to review the text line by line after writing, which saves significant working time.

## How to use

Click the menu in the top-left corner of the navigation bar, Select **Tools** > **Smart proofreading**, and then Open the smart proofreading toggle.

## Proofreading examples

Smart proofreading covers four broad error categories with the following subtypes:

*   **Character errors:** missing character, extra character, wrong character, reversed characters, misuse of traditional characters.
*   **Word errors:** word misuse, variant forms, idiom errors, common personal name errors, common place name errors, organization name errors, English spelling errors.
*   **Grammar errors:** part-of-speech misuse, missing sentence elements.
*   **Punctuation errors:** missing punctuation, extra punctuation, incorrect punctuation, mismatched punctuation pairs.
