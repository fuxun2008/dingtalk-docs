## 1. What is DingTalk Whiteboard AI

In DingTalk Whiteboard, the DingTalk AI Assistant powers a wide range of content creation, including one-click PPT generation, image creation, and smart writing. Let AI spark your creativity, collaborate with team members online, and share resources — turning Whiteboard AI into your "right-hand helper" for content creation and boosting team productivity.

## 2. Key features and use cases

DingTalk Whiteboard currently offers **three core features: Presentation (PPT) generation, image generation, and text generation**, covering content creation needs across various scenarios. It also supports real-time multi-user collaboration, combined with rich templates and design elements, to make content creation easier.

<Note>
### 🪧 Generate presentations

**Create a PPT with a single sentence for richer expression.** Spending too much effort on summary and report decks? Let AI generate PPTs for you instantly in Whiteboard.
</Note>

<Note>
### 🖼️ Generate images

**Produce rich assets and unlock unlimited creativity.** How can you express your ideas more vividly? Let AI quickly generate all kinds of images in Whiteboard.
</Note>

<Note>
### 📃 Generate text

**Create content intelligently and produce high-quality copy effortlessly.** Lost for direction in your creative work? Let AI provide a steady stream of inspiration in Whiteboard.
</Note>

## 3. How to enable

Go to the DingTalk Docs [home page](https://docs.dingtalk.io/i/desktop), create or open a whiteboard, and find the DingTalk AI Assistant at the top of the left toolbar. Click it to launch Whiteboard AI, then choose the feature that matches the content you want to create and let AI complete it for you.

<Steps>
  <Step title="Open DingTalk Docs and create a whiteboard">
    Go to the DingTalk Docs home page and create a new whiteboard.
  </Step>
  <Step title="Launch Whiteboard AI">
    Select the AI Assistant from the top of the left toolbar to launch Whiteboard AI.
  </Step>
  <Step title="Pick a feature and create">
    Choose the feature that matches the content you want to create and let AI complete it for you.
  </Step>
</Steps>

## 4. Frequently asked questions

### 1. How to try Doc AI

Customers who receive a targeted invitation to DingTalk Doc AI can use the invitation code provided by DingTalk to claim trial access on the invitation page.

### 2. Does Doc AI have client / version / organization requirements?

Supported clients: Doc AI currently **only supports the PC client** (**including both the DingTalk app and web browsers**).

Supported DingTalk versions: for the best experience, upgrade to the latest version of DingTalk.

### 3. Are there usage limits for Doc AI?

Customers **enrolled** in the targeted invitation program for the DingTalk Doc smart assistant **have no usage time limit during the trial period. Any changes will be communicated via official notifications**.

### 4. Release date and pricing of Doc AI

DingTalk Doc AI is in active beta and is currently only available to selected DingTalk Professional Edition and Dedicated Edition customers through targeted invitations. Stay tuned for official announcements on release date and pricing.
