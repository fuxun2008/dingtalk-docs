## 1. What is DingTalk Docs AI?

DingTalk Docs AI (Doc AI for short) is an AI-powered document authoring tool jointly developed by **DingTalk Docs** and the **Alibaba Group Tongyi large language model**. It helps users **generate text, tables, images,** and other document content. With Doc AI, you can **unleash your creativity and create with ease**.

## 2. Key features

In addition to **Free-form writing**, Doc AI provides **six categories** of features: **assisted writing, image generation, table generation, fast content generation and rewriting, and document-based content generation**. These features meet content creation needs across various scenarios and improve writing efficiency and quality. Details are as follows:

| **Feature category** | **Description** | **Example input** |
| --- | --- | --- |
| **Free-form writing** | ##### Quick Q&A that delivers ideas and inspiration efficiently<br />> Enter any instruction to ask Doc AI a question | How was the Earth formed?<br />Will black holes ever disappear? ... |
| **Assisted writing** | ##### Rich scenarios to intelligently generate multiple types of document content<br />> Brainstorming, marketing planning, creative stories, promotional copy, job descriptions, summary reports, competitive analysis, pros and cons analysis, product descriptions, press releases, contracts, outlines, to-do lists, emails, articles, poems | Select a specific creation type, then enter the topic<br />Brainstorming: Beijing spring outing, Asian Games environmental campaign themes<br />Competitive analysis: New energy vehicles vs. gasoline vehicles<br />Promotional copy: Write a post about a spring kiwi beverage<br />Press release: Applications of AIGC technology... |
| **Fast content generation and rewriting** | ##### Versatile styles that transform content into different expressions<br />> Generate summaries, identify to-dos, continue writing, polish, enrich content, condense content, rewrite tone... | — |
| **Image generation** | ##### Save time and effort by generating vivid and engaging image assets<br />> Generate images based on keywords or scene descriptions | Sleeping kitten, running car,<br />sunny beach, walking on Mars... |
| **Table generation** | ##### Clear and intuitive visualized data tables<br />> Have Doc AI list the information you want to compare in a table | Pros and cons of new energy vehicles,<br />differences between cities in China... |
| **Document-based content generation** | **Evidence-based, generating content from real-world work documents**<br />> Generate more accurate content intelligently based on existing work documents | Weekly / daily / work report summary and analysis<br />Meeting Minutes highlights |

## 5. Quickstart

When using Doc AI, follow the steps below to improve your creation efficiency. Detailed steps:

1.  **Launch Doc AI:** Open DingTalk Docs and launch it by typing "/" or from the toolbar.

2.  **Enter a writing instruction:** Enter information in the Doc AI input box and select the desired feature type. Let AI complete the content creation for you.

3.  **Refine the output:** After AI generates content, you can choose "Regenerate" or "Continue writing" to adjust the content.

4.  **Confirm the result:** Once satisfied with the result, confirm it and apply it to the document.

## 7. FAQ

## 1. How to try Doc AI

Customers who receive a targeted invitation to DingTalk Docs AI can use the invitation code from DingTalk to claim trial access on the invitation page.

## 2. Are there any client / version / organization requirements for Doc AI?

Supported clients: Currently, documents **support only the desktop client** (**including the DingTalk client and browser**), with partial capabilities available on mobile.

Supported DingTalk version: For the best experience, upgrade to the latest version of DingTalk.

## 3. Are there usage limits for Doc AI?

Currently, customers **enrolled** in the targeted invitation for the DingTalk Docs AI assistant **have no usage limits during the beta period. Any changes will be subject to official notice**.

## 4. When will Doc AI be released, and how is it billed?

DingTalk Docs AI is in active internal beta and is currently offered by invitation only to select DingTalk Professional Edition and Dedicated Edition customers. Stay tuned for release timing and pricing details.
