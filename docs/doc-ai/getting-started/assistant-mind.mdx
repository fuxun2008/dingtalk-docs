## 1. About DingTalk Docs AI · Mind Map

Jointly developed by **DingTalk Docs** and the **Alibaba Group Tongyi large language model**, this document-assisted authoring tool, powered by a large language model, is now available in Mind Map. It provides creative inspiration and ideas, automatically generates a complete mind map based on node content, expands thinking capabilities, and can also generate full articles in one click for efficient content creation.

## 2. Key features

Three core features are currently available: **Smart creation, Inspire me, and Generate article**.

*   **Smart creation:** Enter a subject to ask the AI, and a new subject and outline will be created automatically, showing key nodes and important information to **help you quickly build a thinking framework**.

*   **Inspire me:** Continue creating from an existing subject or node, listing the content of the next-level nodes to **help you intelligently enrich the mind map nodes**.

*   **Generate article:** Generate a complete document based on mind map nodes. Create content paragraph by paragraph or for the entire article with one click, **producing a complete article that can be saved as an online document**.

## 4. How to enable

In DingTalk Mind, the left-hand toolbar

allows you to choose **Smart creation** or **Generate article**.

Select a mind map node, and from the floating toolbar

launch the AI feature **Inspire me**.

## 6. FAQ

## How to try DingTalk Mind AI

Customers who receive a targeted invitation for DingTalk Mind AI can use the invitation code provided by DingTalk to claim trial access on the invitation page.

## 2. Are there any client, version, or organization requirements for Mind Map AI?

Supported clients: Mind Map AI is currently **available on PC only** (**including the DingTalk desktop client and web browsers**).

Supported DingTalk versions: For the best experience, upgrade to the latest version of DingTalk.

## 3. Is there a usage limit for Mind Map AI?

Customers **participating** in the targeted invitation for the DingTalk Docs Smart Assistant currently have **no usage time limits during the trial period. Any changes will be announced via official notifications**.

## 4. When will Mind Map AI be released and how will it be billed?

DingTalk Mind AI is currently in an active beta phase, available only by targeted invitation to selected DingTalk Professional Edition and Exclusive Edition customers. Stay tuned for details on the release date and pricing.
