## 1. About DingTalk Docs Doc AI · Knowledge Base Q&A

DingTalk Docs Knowledge Base integrates large model capabilities to generate a dedicated model for the current Knowledge Base within the scope of permission control, enabling every organization to have its own smart Doc assistant. It helps every employee access Knowledge Base content more efficiently, improves knowledge production and consumption, and builds a learning organization.

## 2. Key features

After enabling the Knowledge Base smart assistant, it automatically learns the **DingTalk Docs and PDF** content in the current Knowledge Base. It also syncs automatically after add, delete, or edit operations. You can view PDF files directly in the DingTalk Chat window and open the smart assistant to ask it questions. It will quickly extract key information from the PDF and intelligently summarize an answer, making it easier to read papers, books, and contracts.

## 3. Use cases

The Knowledge Base smart assistant helps you quickly access team knowledge. It applies to a wide range of work scenarios such as work summaries, knowledge Q&A, new-hire onboarding, organization wiki, and product manuals. It intelligently reads, analyzes, and summarizes team knowledge, becoming a dedicated knowledge assistant for every organization.

## 4. How to enable and disable

*   **First-time enablement:** Go to the Home page of a Knowledge Base where you have Admin permissions, select "AI Assistant" in the bottom-right corner, and click Enable Now to activate it.

## 5. FAQ

## Knowledge Base documents are permission-controlled. Will Q&A bypass permissions?

No. Answers are only provided when the asker has permission to access the document.

## How long does it take on average to learn a Knowledge Base?

Generally, learning completes within 1 to 5 minutes, and never exceeds 40 minutes. If learning takes too long, please send feedback.

## Which file types are supported? When will doc and xls be supported?

Currently, DingTalk Docs and PDF are supported. Other formats will be supported as soon as possible.

## Does it support context-based Q&A? When will this be supported?

Not yet supported. This capability is on the roadmap.

## 5. Is there a usage limit for the Doc smart assistant?

For customers **participating** in the DingTalk Docs smart assistant **invitation-only program, there is no usage time limit during the trial period. Any changes will be subject to official notifications**.

## 6. What is the release date and pricing model for the Doc smart assistant?

The DingTalk Docs smart assistant is currently in active beta and is available only by invitation to selected DingTalk Professional Edition and Dedicated Edition customers. Please stay tuned for the release date and pricing details.
