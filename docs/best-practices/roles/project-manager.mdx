**Zhiji, DingTalk project manager:** I finally found a great tool for managing project documents. Information syncs in real time, formatting stays consistent, and project documentation is captured as the project moves forward.

## Background

Every DingTalk release iteration is a project that spans multiple business lines. Throughout the process, the project manager must communicate with various roles across multiple teams to gather the latest progress. At the same time, the project manager needs to share these updates with all project users immediately. Once the project is complete, all related process documents must be archived in one place.

## Pain Points

1.  Because each team inserts different types of content, formats are often inconsistent and submission tools vary, making it time-consuming and tedious to consolidate information.

2.  Various note-taking tools have been tried for analysis and organization. Some do not support both mobile and desktop, and others do not support multi-user sharing or permissions settings.

3.  After the project is complete, content submitted by users and notes must be archived together, which is both time-consuming and prone to omissions.

## After Adopting DingTalk Knowledge Base

*   At project kickoff, the project manager creates the project Knowledge Base in advance using a template and shares the link to the Group Chat with one click to start collaboration quickly.

*   During the project, project users update content concurrently based on their permissions. Formats stay consistent, the project manager does not need to consolidate information separately, and task progress is reported in real time.

*   After the project is complete, documents are already archived in a structured and standardized way, with no extra organization required.
