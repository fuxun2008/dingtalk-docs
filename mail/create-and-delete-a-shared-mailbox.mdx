---
title: "Create and Delete a Shared Mailbox"
description: "Learn how admins create a shared mailbox for up to 200 members, add members from contacts, let them switch to it in DingTalk Mail, and delete shared mailboxes when no longer needed."
---

A shared mailbox allows members to share a mailbox and handle emails more efficiently. Admins can set up a shared mailbox for up to **200 members** to use simultaneously. This feature is available only to members with an assigned DingTalk Enterprise Mail account. Members can switch between their DingTalk Enterprise Mail account and the shared mailbox to manage emails. They can sign in to the shared mailbox directly from DingTalk for PC without entering a password and have permission to perform mailbox operations for that account.

## Create a Shared Mailbox

<Steps>
  <Step title="Open Shared Mailbox management">
    In the admin console, under **App Management**, go to **Mail > Organization Account Management > Shared Mailbox**.
  </Step>
  <Step title="Create a shared mailbox">
    Click **Create Shared Mailbox**. Enter the mailbox name in **Name** and the email address prefix in **Email Address**.
  </Step>
  <Step title="Add members">
    Under **Department**, click **+ Add from Contacts**.
  </Step>
  <Step title="Confirm">
    Click **Confirm** to create the shared mailbox.

    <Frame>
      <img src="https://img.alicdn.com/imgextra/i3/O1CN01wkEd3z9c2bE58jcg_!!6000000005903-2-tps-2532-1150.png" alt="Create a shared mailbox and add members from contacts" />
    </Frame>
  </Step>
  <Step title="Members switch to the shared mailbox">
    After being added, members can sign in to DingTalk, open Mail, and click the dropdown in the upper-left corner to select a shared mailbox assigned to them.

    Click the shared mailbox to switch directly to that account. Members can then view emails in the shared mailbox and send emails on its behalf.
  </Step>
</Steps>

<Warning>
After creating a shared mailbox, do not assign a member a DingTalk Enterprise Mail account with the same email address prefix as the shared mailbox. Doing so changes the shared mailbox's type and removes its sharing relationships.
</Warning>

## Delete a Shared Mailbox

<Steps>
  <Step title="Open Shared Mailbox management">
    In the admin console, under **App Management**, go to **Mail > Organization Account Management > Shared Mailbox**.
  </Step>
  <Step title="Select and delete">
    Select the checkbox next to the shared mailbox you want to delete, then click **Delete** in the upper-right corner.

    <Frame>
      <img src="https://img.alicdn.com/imgextra/i2/O1CN01i0BGuBuaVJE54xYM_!!6000000002723-2-tps-2502-1416.png" alt="Delete a shared mailbox" />
    </Frame>
  </Step>
</Steps>

<Note>
The deleted mailbox is moved to **Deleted Accounts**.
</Note>
