This article explains what a third-party client security password is and how to use it.

<Note>
This feature is disabled by default. Contact your administrator to enable it in the email management section of the DingTalk admin console. For details, see [Manage Third-Party Clients](/mail/manage-third-party-clients).
</Note>

## What Is a Third-Party Client Security Password?

A third-party client security password is a separate password used to sign in to a DingTalk Enterprise Mail account through a third-party client, such as Outlook or Foxmail. It helps improve security when sending and receiving emails through these clients.

## Create and Use the Password

<Steps>
  <Step title="Open Third-party client security">
    Sign in to DingTalk Enterprise Mail. Go to **Settings > Accounts > Account Security**. Find the **Third-party client security** section.

    <Frame>
      <img src="https://img.alicdn.com/imgextra/i2/O1CN0114LgD0lhrCC4hXvM_!!6000000001241-2-tps-2316-1540.png" alt="Third-party client security section in Account Security" />
    </Frame>
  </Step>
  <Step title="Create an app password">
    Click **Create an app password**. In the **Generate Third-Party client security password** window, click **Copy** to copy the generated password, enter a device name in **Device**, then click **Confirm**.

    <Warning>
    This password is displayed only once. Copy it before clicking **Confirm**. Once entered in the client, you can continue using it without memorizing it. Do not disclose it. To sign in on a new device, generate a new password.
    </Warning>

    <Frame>
      <img src="https://img.alicdn.com/imgextra/i3/O1CN01Yy6CozE0gVB4hXvM_!!6000000002691-2-tps-2316-1540.png" alt="Copy the generated password and enter a device name" />
    </Frame>
  </Step>
  <Step title="Sign in from the client">
    Paste the copied password into the password field in Outlook, Foxmail, or another third-party client to sign in. If you no longer want to use this password, delete its entry from the password list to stop using it.

    <Frame>
      <img src="https://img.alicdn.com/imgextra/i1/O1CN01Pfg1niTmv7B5U8Vm_!!6000000004903-2-tps-2702-1540.png" alt="Password list for third-party client security passwords" />
    </Frame>
  </Step>
</Steps>

<Warning>
To protect your email account, do not disclose your third-party client security password.
</Warning>
