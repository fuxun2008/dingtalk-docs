The enterprise primary administrator, or creator, can enter an existing Alibaba Cloud Enterprise Mail domain to link the mailbox. Use one of the following paths.

## Admin Console

Admin console > Workbench in the left sidebar > App management > Mail > Enter > Link and use > enter the mail domain > the administrator scans the QR code with DingTalk on mobile > on mobile, enter the username, password, incoming mail server, outgoing mail server, and other information > tap Done to complete linking.

## Mobile

DingTalk mobile app > More > Mail > ... in the upper-right corner > Settings > Add another personal email account > Existing enterprise mailbox, Link now > enter the Alibaba Cloud Enterprise Mail domain > enter the username, password, incoming mail server, outgoing mail server, and other information > tap Done to complete linking.
