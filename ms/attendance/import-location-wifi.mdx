## 1. Gambaran keseluruhan ciri

Pengguna dalam Organisasi Anda boleh daftar masuk dari peranti mudah alih di lokasi tetap atau melalui sambungan Wi-Fi tetap. Semasa mengonfigurasi kehadiran berasaskan lokasi atau daftar masuk Wi-Fi, Admin boleh guna **Import/Eksport Pukal Kaedah Daftar Masuk** untuk **menambah lokasi kehadiran dan rangkaian Wi-Fi kehadiran** secara pukal.

## 2. Kes penggunaan

*   Pekerja daftar masuk dari peranti mudah alih.

*   Pekerja daftar masuk di lokasi tetap.

## 3. Aliran kerja

### Import pukal lokasi kehadiran dan rangkaian Wi-Fi

<Steps>
  <Step>

Muat turun templat helaian elektronik. Pada desktop DingTalk, pergi ke **Workbench > Attendance > Attendance Group Management > Edit attendance group > Clock-in Method settings > Export Clock-in Methods** untuk mendapatkan templat berserta sebarang maklumat lokasi atau Wi-Fi yang sedia ada.

<Frame caption="Contoh: laluan untuk eksport kaedah daftar masuk">
![Titik masuk eksport kaedah daftar masuk pada desktop DingTalk](https://img.alicdn.com/imgextra/i3/O1CN01cD2fyrRJLnL27XzV_!!6000000003898-2-tps-1045-588.png)
</Frame>

<Note>
**Nota:**

Bagi kedua-dua kehadiran berasaskan lokasi dan daftar masuk Wi-Fi, ahli kumpulan kehadiran boleh melengkapkan daftar masuk mereka selagi satu kaedah dipenuhi. Pelbagai kaedah daftar masuk boleh wujud serentak, bergantung pada kaedah yang dipilih oleh Admin Organisasi.
</Note>

  </Step>
  <Step>

Isi helaian elektronik. Masukkan atau edit maklumat dalam helaian Excel mengikut keperluan, kemudian Simpan fail setelah maklumat betul.

<Frame caption="Contoh: halaman kemasukan helaian elektronik tempatan">
![Helaian Excel menunjukkan medan lokasi kehadiran dan Wi-Fi](https://img.alicdn.com/imgextra/i1/O1CN01zGLTiiJFYpK1yU2a_!!6000000003228-2-tps-973-523.png)
</Frame>

  </Step>
  <Step>

Import kaedah daftar masuk. Pada desktop DingTalk, pergi ke **Workbench > Attendance > Attendance Group Management > Edit attendance group > Clock-in Method settings > Import Clock-in Methods** untuk mengimport maklumat lokasi kehadiran atau Wi-Fi. Buat masa ini, hanya format Excel disokong.

<Frame caption="Contoh: laluan untuk import kaedah daftar masuk">
![Titik masuk import kaedah daftar masuk pada desktop DingTalk](https://img.alicdn.com/imgextra/i3/O1CN01cD2fyrRJLnL27XzV_!!6000000003898-2-tps-1045-588.png)
</Frame>

  </Step>
</Steps>
## 4. Soalan Lazim

<AccordionGroup>
  <Accordion id="q1" title="Semasa import pukal lokasi kehadiran, mesej 'A cell in the Office Address worksheet cannot be empty and must be a number' muncul. Bagaimana saya boleh membetulkannya?">

Ini berlaku kerana setiap medan wajib dalam helaian elektronik import mesti diisi. Lengkapkan helaian elektronik sebelum mengimport.

  </Accordion>
  <Accordion id="q2" title="Bagaimana saya boleh mendapatkan latitud dan longitud?">

Pada **desktop DingTalk**, pergi ke **Workbench > Attendance > Attendance Group Management > Edit attendance group > Clock-in Method settings > Add Location** untuk melihat latitud dan longitud.

  </Accordion>
  <Accordion id="q3" title="Mengapakah lokasi kehadiran yang telah dikonfigurasi sebelum ini hilang selepas import?">

Import lokasi kehadiran akan menulis ganti data sedia ada. Untuk mengekalkan alamat sedia ada, jangan padam alamat tersebut dalam Excel selepas eksport. Tambah entri baharu di atas data sedia ada sebelum mengimport.

  </Accordion>
  <Accordion id="q4" title="Berapa banyak kumpulan kehadiran boleh ditambah oleh sesebuah organisasi? Berapa banyak rangkaian Wi-Fi dan alamat boleh ditetapkan?">

Sesebuah organisasi boleh menambah sehingga **10,000 kumpulan kehadiran**, dengan **sehingga 5,000 pengguna** bagi setiap kumpulan kehadiran. Setiap kumpulan kehadiran boleh mempunyai sehingga **1,000 rangkaian Wi-Fi dan alamat**.

  </Accordion>
</AccordionGroup>
