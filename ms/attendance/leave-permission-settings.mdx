## 1. Gambaran keseluruhan

**Selepas naik taraf ke kebenaran Smart Leave**, anda boleh mengkonfigurasi kebenaran pengurusan cuti secara berasingan, termasuk **skop pengurusan** dan **kebenaran terperinci**. Sub Admin tidak lagi memerlukan kebenaran Kelulusan OA—cukup pilih kebenaran **Smart Leave**, dan mereka boleh menetapkan peraturan cuti melalui **DingTalk Mobile/Desktop > Workbench > Smart Leave**.

## 2. Senario penggunaan

*   **Hierarki yang jelas:** Dalam organisasi dengan struktur kompleks dan banyak jabatan, pengurus pada Tier berbeza menyelia skop pembuatan keputusan yang berbeza.

*   **Taburan geografi:** Bagi syarikat multinasional atau merentas serantau, cawangan di lokasi berbeza mungkin mengikut dasar HR masing-masing, jadi kebenaran pengurusan cuti perlu selaras dengan peraturan syarikat setempat.

## 3. Cara menggunakan

### Naik taraf kebenaran pengurusan cuti

**Pengguna sedia ada**: Untuk naik taraf, buka **DingTalk Desktop > Workbench > Smart HR > Leave Home**. Pada Kad **Leave Management Permission Upgrade** yang dipaparkan, pilih **Upgrade for Free** dan tunggu sehingga proses naik taraf selesai.

<Note>
**Nota:** Selepas naik taraf, Sub Admin Kelulusan OA sedia ada akan menerima kebenaran pengurusan cuti secara automatik, dan anda juga boleh mengkonfigurasi kebenaran terperinci di bawah Urus kebenaran. Admin Kelulusan baharu perlu memilih kebenaran Smart Leave secara manual untuk mengakses pengurusan cuti.
</Note>

### Tetapkan kebenaran pengurusan cuti

Buka [**Admin Console**](https://oa.dingtalk.io) **> Security & Permissions > Urus kebenaran > Sub Admin >** klik **Edit** untuk kumpulan admin berkenaan **>** klik **Edit** di bawah Kebenaran aplikasi Rasmi DingTalk **> Smart Leave** untuk mengkonfigurasikan kebenaran pengurusan cuti terperinci bagi Sub Admin yang berbeza.

<Note>
Kebenaran Smart Leave termasuk:

1. Cipta peraturan cuti

2. Ubah suai peraturan cuti

3. Padam peraturan cuti

4. Ubah kuota cuti
</Note>

## 4. Soalan Lazim

<AccordionGroup>
  <Accordion id="q1" title="Bolehkah saya menetapkan kebenaran pengurusan cuti terperinci tanpa naik taraf ke Smart Leave?">

Jika anda belum naik taraf ke Smart Leave, Admin Kelulusan mempunyai kebenaran pengurusan cuti secara lalai, dan kebenaran pengurusan cuti terperinci tidak boleh dikonfigurasikan. Selepas naik taraf ke Smart Leave, jika Sub Admin perlu mengakses pengurusan cuti melalui Kelulusan OA, mereka mesti mempunyai kedua-dua kebenaran Kelulusan OA dan Smart Leave. Admin yang diberi kuasa boleh membuka **Admin Console > Security & Permissions > Urus kebenaran > Sub Admin >** klik **Edit** untuk kumpulan admin berkenaan **>** kemudian klik **Edit** di bawah Kebenaran aplikasi Rasmi DingTalk untuk mengkonfigurasikan kebenaran berkaitan.
