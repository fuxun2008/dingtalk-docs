Guna **Tetapan kumpulan** untuk mengurus maklumat kumpulan, keutamaan peribadi anda, dan kawalan peringkat kumpulan.

Untuk membuka Tetapan kumpulan, buka satu sembang kumpulan dan klik ikon gear di penjuru kanan atas.

![](https://img.alicdn.com/imgextra/i4/O1CN01kma392VuadL4N9W8_!!6000000001089-2-tps-2154-1322.png)

## Maklumat kumpulan

Guna bahagian maklumat kumpulan untuk mengurus butiran asas kumpulan.

| Tetapan | Fungsinya |
| --- | --- |
| **Nama** | Papar atau edit nama kumpulan. |
| **Notis** | Buka notis kumpulan. |
| **Jemputan Kumpulan** | Buka pilihan jemputan kumpulan. |

![](https://img.alicdn.com/imgextra/i4/O1CN01J8XsR3h8ZaF4N9W8_!!6000000000760-2-tps-2154-1322.png)

## Tetapan kumpulan peribadi

Tetapan ini hanya menjejaskan pengalaman anda sendiri dalam kumpulan.

| Tetapan | Fungsinya |
| --- | --- |
| **Nama Panggilan Saya dalam Kumpulan** | Tetapkan nama paparan anda dalam kumpulan ini. |
| **Alias Kumpulan** | Tetapkan alias tempatan anda untuk kumpulan. |
| **Sematkan di Atas** | Kekalkan kumpulan berhampiran bahagian atas senarai perbualan anda. |
| **Senyapkan Notifikasi** | Senyapkan notifikasi untuk kumpulan ini. |

## Urus Kumpulan

Buka **Urus Kumpulan** apabila anda perlu mengurus admin, kebenaran, peraturan penyertaan, atau ciri peringkat kumpulan.

| Tetapan | Fungsinya |
| --- | --- |
| **Admin** / **Tambah** | Tambah admin kumpulan. |
| **Tetapan Senyap** | Buka tetapan senyap kumpulan. |
| **Tetapan kebenaran kumpulan** | Kawal kebenaran ahli untuk ciri kumpulan. |
| **Bar Pantas Kumpulan** | Konfigurasikan bar pantas kumpulan. |
| **Kebenaran sertai kumpulan** | Konfigurasikan cara ahli baharu boleh menyertai. |
| **Berapa lama ahli baharu boleh melihat sejarah sembang mereka** | Konfigurasikan sejarah terdahulu yang boleh dilihat oleh ahli baharu. |
| **Kalendar Kumpulan** | Buka tetapan kalendar kumpulan. |
| **Kumpulan boleh menerima mel** | Konfigurasikan sama ada kumpulan boleh menerima mel. |
| **Aktifkan penyegerakan automatik ke Ding Drive** | Segerakkan fail kumpulan ke Ding Drive. |
| **Lumpuhkan Sembang Peribadi** | Nyahaktifkan titik masuk sembang peribadi daripada kumpulan. |
| **Pindahkan Pemilikan Kumpulan** | Serahkan pemilikan kepada ahli lain. |

## Kosongkan mesej atau tinggalkan kumpulan

*   Untuk mengosongkan mesej tempatan, buka Tetapan kumpulan > **Kosongkan Mesej**.
    
*   Untuk meninggalkan kumpulan, buka Tetapan kumpulan > **Tinggalkan**.
