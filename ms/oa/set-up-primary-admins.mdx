title: "Menyediakan Admin Utama"
description: "Ketahui cara melantik admin utama dengan kebenaran penuh untuk mengurus kenalan, kehadiran dan aplikasi lain di seluruh organisasi anda melalui Admin Console."
---

**Admin Utama:** Mempunyai kebenaran pentadbiran penuh di seluruh organisasi. Boleh log masuk ke Admin Console dan mengurus Kenalan, Kehadiran, Kelulusan, Laporan, Pengumuman, serta aplikasi lain organisasi. Juga boleh mewakilkan kebenaran pentadbiran kepada orang lain.

---

## Aliran Operasi

Tambah admin utama melalui salah satu laluan berikut:

- **Laluan 1:** Laman Utama > Lantik Admin > Tambah admin utama
- **Laluan 2:** Keselamatan & kebenaran > Kebenaran > Tambah admin utama

<Warning>
**Nota Penting:**

- Akaun yang pada asalnya mencipta Struktur Organisasi ditetapkan sebagai admin utama **Pencipta**. Akaun ini tidak boleh ditambah atau dipadam — ia hanya boleh dipindahkan.
- Admin utama tanpa tag **Pencipta** ialah admin utama biasa. Mereka boleh ditambah atau dipadam, dan perubahan berkuat kuasa serta-merta.
- Hanya satu admin utama dengan tag Pencipta boleh ditetapkan. Bilangan maksimum admin utama biasa ialah 999.
</Warning>
