title: "Cara Log Masuk ke Admin Console"
description: "Log masuk ke DingTalk Admin Console sebagai admin organisasi melalui pelayar web atau klien desktop untuk mengurus ahli, dasar keselamatan, dan ciri perusahaan."
---

Admin Console ialah entri bersepadu untuk admin organisasi mengkonfigurasikan dan menguruskan organisasi DingTalk mereka. Melalui Admin Console, anda boleh menguruskan ahli, menetapkan dasar keselamatan, dan mengkonfigurasikan pelbagai ciri perusahaan.

---

## Siapa Boleh Log Masuk

Hanya admin organisasi boleh log masuk ke Admin Console. Ahli biasa tiada akses kepadanya.

## Kaedah Log Masuk

### Kaedah 1: Log Masuk Web

<Steps>
  <Step title="Buka Admin Console">
    Buka pelayar dan lawati [https://oa.dingtalk.io/](https://oa.dingtalk.io/)
  </Step>
  <Step title="Selesaikan log masuk">
    Pilih mana-mana kaedah berikut untuk menyelesaikan log masuk:

    - Log masuk e-mel: Masukkan e-mel dan kata laluan yang didaftarkan
    - Log masuk Nombor Telefon: Masukkan Nombor Telefon dan log masuk melalui Kod Pengesahan
    - Log masuk Kod QR: Buka DingTalk pada telefon bimbit anda dan imbas Kod QR pada halaman
    - Log masuk Akaun Syarikat: Gunakan akaun yang diperuntukkan oleh syarikat anda
    - Log masuk akaun pihak ketiga: Log masuk melalui akaun pihak ketiga yang dipautkan

### Kaedah 2: Akses daripada Klien Desktop

Jika anda telah memasang klien desktop DingTalk, anda boleh mengakses Admin Console dengan pantas melalui salah satu daripada dua kaedah berikut:

- Entri 1: Klik avatar di sudut kiri atas → Klik **Admin Console** dalam menu lungsur
- Entri 2: Pergi ke **Kenalan** → Klik **Nama Organisasi** → Klik **Panel Admin**

Selepas mengklik, anda akan diarahkan secara automatik ke halaman web Admin Console.

## Gambaran Keseluruhan Halaman Utama

Selepas log masuk, anda akan memasuki halaman utama Admin Console.

Klik avatar di sudut kanan atas untuk log keluar. Klik butang Bahasa untuk menukar Bahasa Admin Console.

Bahagian kiri mengandungi Bar navigasi ciri, manakala bahagian kanan memaparkan gambaran keseluruhan data asas organisasi dan entri akses pantas.
