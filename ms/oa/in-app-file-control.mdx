---
title: "Kawalan Fail Dalam Aplikasi"
description: "Sekat perkongsian, muat turun dan salin-tampal fail dalam aplikasi, serta tetapkan skop dasar mengikut pekerja, jabatan atau peranan tertentu melalui Admin Console."
---

Organisasi boleh mengurus operasi berkaitan fail dalam aplikasi, termasuk mengawal tindakan seperti perkongsian, muat turun dan salin-tampal.

---

## II. Panduan Pengguna

### 1. Navigasi Admin Console

Pada panel navigasi kiri, pergi ke **Security & permission > Security > Data Protection > In-App File Control**

### 2. Admin — Tiada Peraturan Dikonfigurasi

Kawalan Fail Dalam Aplikasi merangkumi pelbagai keupayaan, meliputi kedua-dua klien mudah alih dan desktop serta melibatkan pelbagai operasi fail.

Mengambil "Muat turun fail ke terminal mudah alih" sebagai contoh:

Apabila belum dikonfigurasi, ciri ini dinyahaktifkan.

Apabila dinyahaktifkan, tingkah laku adalah selaras dengan pengalaman lalai DingTalk.

### 3. Admin — Contoh Konfigurasi

<Steps>
  <Step title="Pratonton konfigurasi kad">
    Klik ikon maklumat untuk pratonton kesan konfigurasi kad.

    <Frame>
      <img src="https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/2M9qP5jDGXzw4O01/img/57da27e5-76f0-44bf-8169-82be2ef67f51.png" alt="Pratonton konfigurasi kad" />
    </Frame>
  </Step>
  <Step title="Aktifkan ciri">
    Togol suis dan klik **Sahkan** pada dialog untuk mengaktifkan ciri ini.

    <Frame>
      <img src="https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/2M9qP5jDGXzw4O01/img/9594a727-5866-4891-ba5a-86565ccfb8c4.png" alt="Aktifkan ciri" />
    </Frame>
  </Step>
  <Step title="Konfigurasikan skop yang berkenaan">
    Ciri ini terpakai kepada semua pekerja secara lalai.

    Klik **Edit** untuk mengonfigurasikan skop yang berkenaan — nyatakan pekerja mana dasar ini terpakai atau dikecualikan.

    Sebagai contoh, untuk menggunakan dasar ini hanya pada Jabatan Kejuruteraan, pilih **Specific Employees**, kemudian gunakan pemilih kenalan untuk memilih jabatan tersebut.

    Pemilih kenalan turut menyokong pemilihan mengikut peranan, memberikan fleksibiliti kepada admin untuk mengonfigurasi mengikut keperluan.
