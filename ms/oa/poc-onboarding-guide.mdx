Panduan ini ditujukan untuk ketua projek dan admin organisasi bagi pelanggan baharu di luar negara. Ia merangkumi keseluruhan aliran — daripada memilih pelan di laman web, memulakan percubaan percuma, mendaftarkan admin, dan mencipta organisasi, sehingga log masuk ke Admin Console dan mengimport akaun perusahaan secara pukal.

<Info>
  **Untuk siapa panduan ini**: Ketua projek dan admin organisasi pertama yang bertanggungjawab memacu POC (Proof of Concept) perusahaan DingTalk.
</Info>

## Gambaran keseluruhan aliran

<Steps>
  <Step title="Buka laman web dan terokai pelan">Buka laman web global DingTalk dan bandingkan pelan Free / Basic / Standard / Premium.</Step>
  <Step title="Mulakan percubaan percuma">Pilih pelan yang sesuai dan mohon percubaan percuma berciri penuh selama 30 hari.</Step>
  <Step title="Daftarkan admin pertama">Daftar, selesaikan pengesahan identiti, dan tetapkan kata laluan.</Step>
  <Step title="Cipta organisasi">Isi butiran organisasi dan rekodkan Org ID serta Organization Code.</Step>
  <Step title="Log masuk ke Admin Console">Masuk ke Admin Console untuk mengkonfigurasikan organisasi anda.</Step>
  <Step title="Bina struktur jabatan">Cipta jabatan berdasarkan skop ujian anda.</Step>
  <Step title="Import akaun perusahaan secara pukal">Muat turun templat Excel, import secara pukal, dan semak hasil secara rawak.</Step>
</Steps>

## Langkah 1: Buka laman web dan pilih pelan

Lawati laman web global DingTalk: [https://www.dingtalk.io/](https://www.dingtalk.io/) (halaman bahasa Cina: [https://www.dingtalk.io/zh/](https://www.dingtalk.io/zh/)).

Laman web menawarkan empat pelan. Pilih satu berdasarkan bilangan pengguna POC, senario perniagaan, keperluan keselamatan, keperluan storan, dan skop integrasi sistem anda:

| Pelan | Sesuai untuk |
|------|----------|
| **Free** | Pengalaman produk sedia guna |
| **Basic** | Syarikat permulaan dan pasukan kecil — mengesahkan keupayaan teras seperti pemesejan, kalendar, dan kolaborasi dokumen |
| **Standard** | Organisasi yang sedang berkembang — dasar keselamatan lebih kukuh, storan awan lebih besar, dan perkhidmatan sokongan |
| **Premium** | Organisasi bersaiz sederhana hingga besar — keupayaan lebih canggih dan kolaborasi merentas pasukan berskala besar |

## Langkah 2: Mulakan percubaan percuma

Di laman web, klik **Start Free Trial**. Setiap pelan layak mendapat percubaan percuma berciri penuh selama 30 hari — tanpa kad kredit.

<Tip>
  Jika POC anda melibatkan Enterprise, pematuhan data, SSO, wilayah data, atau keperluan tersuai, anda juga boleh klik **Contact Sales**: [https://www.dingtalk.io/contact-sales/](https://www.dingtalk.io/zh/contact-sales/?from=%2F)
</Tip>

**Sediakan sebelum memohon:**

- Nama organisasi dan negara/wilayah
- Anggaran bilangan pengguna POC
- Masa mula dan tempoh ujian yang dirancang
- Senario perniagaan utama yang perlu disahkan
- Nama, e-mel, dan nombor telefon Super Admin

<Note>
  **Contoh nota permohonan**: Memohon POC perusahaan DingTalk, ~XX pengguna, tempoh ujian XX hari, memfokus pada pengesahan pengurusan organisasi, aliran kerja admin, kolaborasi mesyuarat, dan onboarding pekerja secara pukal.
</Note>

## Langkah 3: Daftarkan akaun admin

Pilih salah satu kaedah berikut untuk mendaftar mengikut arahan: **e-mel yang sah** / **akaun Google** / **nombor telefon yang sah dengan kod pengesahan**. Selesaikan pengesahan identiti, tetapkan kata laluan, dan terima Terms of Service serta Privacy Policy.

<Tip>
  Untuk POC perusahaan, gunakan e-mel kerja jangka panjang pelanggan sebagai akaun Super Admin, dan konfigurasikan admin sandaran.
</Tip>

## Langkah 4: Cipta organisasi

Pilih pelan sasaran anda dan selesaikan aliran percubaan percuma atau langganan mengikut arahan. Semasa mencipta organisasi, sediakan yang berikut:

| Medan | Cadangan |
|------|----------|
| Organization Name | Gunakan nama rasmi syarikat dalam bahasa Inggeris; elakkan nama peribadi atau nama projek sementara |
| Country / Region | Pilih wilayah operasi utama atau wilayah POC organisasi |
| Industry / Organization Size | Isi industri sebenar dan anggaran bilangan pekerja |
| Super Admin | Gunakan e-mel atau nombor telefon admin yang telah disahkan |
| Org ID | Simpan pengecam unik organisasi yang diberikan selepas penciptaan |
| Organization Code | Digunakan untuk mengesan organisasi semasa log masuk dengan akaun perusahaan; rekodkan berasingan daripada Org ID |

<Warning>
  Selepas organisasi dicipta, pastikan anda menyimpan **Org ID**. **Organization Code** yang diperlukan untuk log masuk dengan akaun perusahaan boleh dilihat oleh admin di bawah **Security and Permission → Organization code login**.
</Warning>

## Langkah 5: Log masuk ke Admin Console

Admin melawati: [https://oa.dingtalk.io/](https://oa.dingtalk.io/)

Masukkan butiran organisasi anda mengikut arahan dan pilih kaedah log masuk:

- E-mel atau nombor telefon berdaftar + kata laluan
- Nombor telefon + kod pengesahan
- Imbas kod QR dengan DingTalk mudah alih
- Akaun perusahaan + Organization Code + kata laluan
- Akaun pihak ketiga yang dipautkan

Anda juga boleh masuk daripada klien DingTalk: **Foto Profil → Admin Console**, atau **Kenalan → nama organisasi → Urus**.

<Note>
  Jika akaun anda tergolong dalam beberapa organisasi, pastikan anda masuk ke organisasi untuk POC ini.
</Note>

## Langkah 6: Bina struktur jabatan

Di Admin Console, buka Kenalan dan cipta struktur jabatan yang diperlukan POC anda:

**Admin Console → Kenalan (Contacts) → Pengurusan Jabatan → Tambah Jabatan**

<Tip>
  Cipta jabatan peringkat atas dahulu, kemudian tambah jabatan peringkat kedua yang diperlukan untuk skop ujian anda. Nama jabatan hendaklah sepadan dengan struktur organisasi pelanggan semasa.
</Tip>

## Langkah 7: Import akaun perusahaan secara pukal melalui Excel

**Laluan**: Admin Console → Kenalan (Contacts) → Ahli (Members) → Edit Pukal (Batch Edit) → Import Pukal (Bulk Import)

<Steps>
  <Step title="Muat turun templat">Klik **Download Template** dan gunakan templat Excel standard yang dimuat turun daripada organisasi anda semasa.</Step>
  <Step title="Isi butiran pekerja">Ikuti baris contoh dan arahan dalam templat untuk mengisi butiran pekerja. Padamkan baris contoh sebelum memuat naik.</Step>
  <Step title="Kekalkan struktur templat">Jangan ubah nama lajur, susunan lajur, struktur lembaran kerja, atau jenis fail.</Step>
  <Step title="Muat naik fail">Kembali ke halaman import, klik **Upload File**, pilih fail Excel yang telah diisi, kemudian klik **Import**.</Step>
  <Step title="Semak hasil secara rawak">Selepas import selesai, semak senarai ahli secara rawak berdasarkan jabatan, nama, e-mel, atau nombor telefon.</Step>
</Steps>

<Tip>
  Import 3–5 admin dan pengguna ujian dahulu. Setelah akaun, penetapan jabatan, dan log masuk semuanya berfungsi dengan betul, import baki pengguna POC.
</Tip>

## Menyelesaikan masalah import

Jika muat naik atau import gagal:

<AccordionGroup>
  <Accordion title="Semak rekod pekerja">Tinjau rekod pekerja yang berkaitan berdasarkan mesej ralat di skrin.</Accordion>
  <Accordion title="Sahkan medan dan format">Pastikan medan wajib dan format sepadan dengan arahan templat.</Accordion>
  <Accordion title="Sahkan struktur templat">Pastikan anda tidak mengubah nama lajur, susunan lajur, atau struktur lembaran kerja templat.</Accordion>
  <Accordion title="Betulkan dan cuba semula">Betulkan rekod yang salah dan muat naik semula.</Accordion>
  <Accordion title="Tangani masalah halaman">Jika halaman berkelakuan luar biasa, segarkan halaman, log masuk semula, atau cuba semula dengan Google Chrome versi terkini.</Accordion>
</AccordionGroup>
