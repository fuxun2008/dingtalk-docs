Panggil API ini untuk mendapatkan ringkasan semua kumpulan kehadiran dalam organisasi Anda mengikut halaman, termasuk nama setiap kumpulan kehadiran dan ID kumpulan kehadiran yang sepadan.

## Permintaan

| **Maklumat asas** | |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/topapi/attendance/group/minimalism/list |
| Kaedah HTTP | POST |
| Jenis aplikasi yang disokong | appType-Aplikasi dalaman　appType-Aplikasi perusahaan pihak ketiga |
| Kebenaran | permission-qyapi_attendance_group_read-Kebenaran baca kumpulan kehadiran |

### Parameter query

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | bE74xxxx | Kelayakan aplikasi yang digunakan untuk memanggil API ini.   - Bagi Aplikasi dalaman, dapatkannya dengan memanggil [Dapatkan access_token Aplikasi dalaman](/ms/open/development/obtain-orgapp-token). - Bagi Aplikasi perusahaan pihak ketiga, dapatkannya dengan memanggil API untuk mendapatkan access_token organisasi pihak ketiga. |

### Isi permintaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| op_user_id | String | Ya | user123 | userId pengendali. |
| cursor | Number | Tidak | 222 | Cursor penomboran halaman. Dapatkannya daripada hasil permintaan sebelumnya. Jika tidak diisi, query bermula daripada item pertama. |

### Contoh permintaan

```curl
curl -X POST "https://api.dingtalk.io/topapi/attendance/group/minimalism/list" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=6dd4xxxx94138' \
-d 'cursor=222' \
-d 'op_user_id=dd_dd'
```

Java

```java
DingTalkClient client = new DefaultDingTalkClient("https://api.dingtalk.io/topapi/attendance/group/minimalism/list");
OapiAttendanceGroupMinimalismListRequest req = new OapiAttendanceGroupMinimalismListRequest();
req.setOpUserId("manager4220");
req.setCursor(0L);
OapiAttendanceGroupMinimalismListResponse rsp = client.execute(req, access_token);
System.out.println(rsp.getBody());
```

Python

```python
import dingtalk.api

req=dingtalk.api.OapiAttendanceGroupMinimalismListRequest("https://api.dingtalk.io/topapi/attendance/group/minimalism/list")

req.op_user_id="dd_dd"

try:
  resp= req.getResponse(access_token)

  print(e)
```



## Respons

### Isi respons

| Nama | Jenis | Contoh | Penerangan |
| --- | --- | --- | --- |
| result | PageResult | demo | Hasil yang dikembalikan. |
| has_more | Boolean | false | Menunjukkan sama ada terdapat lagi data.   - **true**: Ya - **false**: Tidak |
| cursor | Number | 685935028 | Kedudukan cursor. |
| result | TopMinimalismGroupVo[] |  | Maklumat kehadiran. |
| name | String | Kehadiran | Nama kumpulan kehadiran. |
| id | Number | 677765054 | ID kumpulan kehadiran. |
| success | Boolean | true | Menunjukkan sama ada permintaan berjaya.   - **true**: Berjaya - **false**: Gagal |
| errcode | Number | 0 | Kod pemulangan. |
| errmsg | String | ok | Penerangan mesej ralat. |
| request_id | String | wv9973jntam | ID permintaan. |
