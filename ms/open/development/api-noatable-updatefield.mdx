Panggil API ini untuk mengemas kini medan dalam jadual.

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/notable/bases/{baseId}/sheets/{sheetIdOrName}/fields/{fieldIdOrName}` |
| Kaedah HTTP | PUT |
| Jenis aplikasi disokong | appType-Internal app |
| Kebenaran diperlukan | permission-Notable.Base.Write.All-AI Table app write permission |

### Header permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Dapatkan dengan memanggil API [Dapatkan access token aplikasi dalaman](/open/development/obtain-the-access-token-of-an-internal-app#). |

### Parameter laluan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| baseId | String | Ya | ID AI Table. Untuk cara mendapatkannya, lihat [Struktur data](/open/development/data-structure#). |
| sheetIdOrName | String | Ya | ID jadual atau nama jadual. Anda boleh mendapatkan ID jadual melalui salah satu cara berikut:   - Panggil API [Dapatkan semua jadual](/open/development/api-notable-getallsheets#). - Panggil API [Dapatkan satu jadual](/open/development/api-notable-getsheet#). |
| fieldIdOrName | String | Ya | ID medan atau nama medan. Dapatkan ID medan dengan memanggil API [Dapatkan semua medan](/open/development/api-noatable-getallfields#). |

### Parameter kueri

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| operatorId | String | Ya | unionId pengendali. Dapatkan melalui salah satu cara berikut:   - Panggil API [Tanyakan butiran pengguna](/open/development/query-user-details#). - Panggil API [Dapatkan maklumat pengguna melalui kod log masuk senyap](/open/development/obtain-the-userid-of-a-user-by-using-the-log-free#). |

### Isi permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| name | String | Ya | Nama medan. |
| property | `Map<String, Any>` | Tidak | Sifat medan. Untuk format khusus, lihat [Sifat medan](https://open.dingtalk.com/document/development/field-properties#). |
|  | Any | Tidak | Sifat medan. |
