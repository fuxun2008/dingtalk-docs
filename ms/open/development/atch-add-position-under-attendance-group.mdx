Panggil API ini untuk menambah lokasi ke kumpulan kehadiran tertentu secara pukal.

## Permintaan

| **Maklumat asas** | |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/topapi/attendance/group/positions/add |
| Kaedah HTTP | POST |
| Jenis aplikasi yang disokong | appType-Aplikasi dalaman |
| Kebenaran yang diperlukan | permission-qyapi_attendance_group_manage-Kebenaran pengurusan kumpulan kehadiran |

### Parameter pertanyaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | 4c9ebd2b1534xxxx | Kelayakan aplikasi yang digunakan untuk memanggil API ini. Dapatkannya dengan memanggil API [Dapatkan access_token Aplikasi dalaman](/ms/open/development/obtain-orgapp-token). |

### Isi permintaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| op_userid | String | Tidak | user01 | ID pengguna bagi operator. |
| group_key | String | Ya | 03B1Exxxx | ID kumpulan kehadiran.  **Nota**  Jika pengecam kumpulan kehadiran anda ialah group_id, panggil API [Tukar groupId kepada groupKey](/ms/open/development/groupid-to-groupkey) untuk menukar group_id kepada group_key. |
| position_list | Object[] | Ya |  | Senarai lokasi. Tambah sehingga 100 lokasi bagi setiap permintaan. |
| address | String | Ya | Alibaba Group Xixi Beiyuan | Penerangan alamat. |
| foreign_id | String | Ya | 0151E23B1 | positionId yang ditakrifkan oleh pihak perniagaan. |
| longitude | String | Ya | 120.123 | Longitud (sehingga 6 tempat perpuluhan). |
| latitude | String | Ya | 30.123 | Latitud (sehingga 6 tempat perpuluhan). |
| offset | Number | Tidak | 100 | Julat ofset yang dibenarkan bagi lokasi daftar masuk, dalam meter. |

### Contoh permintaan

```curl
curl -X POST "https://api.dingtalk.io/topapi/attendance/group/positions/add" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=23adcxxxx46c5226' \
-d 'group_key=0151E02xxxx917E876' \
-d 'op_userid=123456' \
-d 'position_list=null'
```

Java

```text
DingTalkClient client = new DefaultDingTalkClient("https://api.dingtalk.io/topapi/attendance/group/positions/add");
OapiAttendanceGroupPositionsAddRequest req = new OapiAttendanceGroupPositionsAddRequest();
req.setOpUserid("user01");
req.setGroupKey("03B1Exxxx");
List<Position> list = new ArrayList<Position>();
Position position = new Position();
list.add(position);
position.setAddress("Alibaba Group Xixi Beiyuan");
position.setForeignId("0151E23B1");
position.setLongitude("120.123");
position.setLatitude("30.123");
position.setOffset(100);
req.setPositionList(list);
OapiAttendanceGroupPositionsAddResponse rsp = client.execute(req, access_token);
System.out.println(rsp.getBody());
```

## Respons

### Isi respons

| Nama | Jenis | Contoh | Penerangan |
| --- | --- | --- | --- |
| result | DingOpenResult |  | Hasil yang dikembalikan. |
| result | Result |  | Hasil pertanyaan. |
| error_info_list | ErrorInfo[] |  | Senarai ralat. |
| failure_list | Position[] |  | Senarai item yang gagal. |
| foreign_id | String | 0151E23B1xxxx | positionId yang ditakrifkan oleh pihak perniagaan. |
| address | String | Alibaba Group Xixi Beiyuan | Penerangan alamat. |
| latitude | String | 120.123 | Longitud (sehingga 6 tempat perpuluhan). |
| longitude | String | 30.123 | Latitud (sehingga 6 tempat perpuluhan). |
| position_key | String |  | Kunci lokasi. Kosong jika operasi gagal. |
| msg | String | ralat perniagaan | Mesej ralat. |
| code | String | 1000 | Kod ralat. |
| success_list | Position[] |  | Senarai item yang berjaya. |
| foreign_id | String | 0151E23B1 | positionId yang ditakrifkan oleh pihak perniagaan. |
| address | String | Alibaba Group Xixi Beiyuan | Penerangan alamat. |
| latitude | String | 120.123 | Longitud (sehingga 6 tempat perpuluhan). |
| longitude | String | 30.123 | Latitud (sehingga 6 tempat perpuluhan). |
| position_key | String | 9E459D1xxxx | Pengecam unik lokasi. |
| errcode | Number | 0 | Kod pemulangan. |
| errmsg | String | ok | Penerangan kod pemulangan. |
| success | Boolean | true | Menunjukkan sama ada permintaan berjaya.   - **true**: Berjaya - **false**: Gagal |
| request_id | String | rndx5wfzebph | ID permintaan. |
