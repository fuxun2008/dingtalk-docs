---
title: "Tambah baris ke helaian kerja"
description: "Panggil API ini untuk menambah baris data secara automatik ke penghujung Helaian Kerja DingTalk Spreadsheet tanpa perlu mengesan lokasi baris terakhir."
---

Panggil API ini untuk menambah satu atau lebih baris data selepas rekod terakhir yang sedia ada dalam Helaian Kerja DingTalk Spreadsheet. Sistem akan mengesan secara automatik rekod terakhir yang mengandungi data dan memasukkan baris baharu sejurus di bawahnya.

## Penerangan panggilan API

- Mengesan secara automatik rekod terakhir yang mengandungi data dalam helaian kerja dan menambah baris baharu di bawahnya.
- Menyokong penambahan berbilang baris sekali gus melalui array dua dimensi `values`.
- Jika helaian kerja kosong, data akan ditulis bermula daripada rekod pertama.
- Mengembalikan julat sel (dalam notasi A1) tempat data yang ditambah berada.
- Bilangan lajur dalam data yang ditambah hendaklah sepadan dengan bilangan lajur dalam data helaian kerja sedia ada untuk memastikan penjajaran data.

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/doc/workbooks/{workbookId}/sheets/{sheetId}/appendRows` |
| Kaedah HTTP | POST |
| Jenis aplikasi yang disokong | appType-Aplikasi dalaman |
| Kebenaran | permission-Document.Workbook.Write-Kebenaran tulis DingTalk Spreadsheet |

### Header permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Untuk mendapatkannya, panggil API [Dapatkan access token aplikasi dalaman](/open/development/obtain-the-access-token-of-an-internal-app). |

### Parameter laluan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| workbookId | String | Ya | ID fail spreadsheet. Hantar `nodeId` (dentryUuid), yang berfungsi sebagai `workbookId` spreadsheet. Anda boleh mendapatkannya dengan memanggil API [Dapatkan nod](/open/development/get-knowledge-base-acquisition-node) atau [Cipta dokumen Knowledge Base](/open/development/create-team-space-document). |
| sheetId | String | Ya | ID atau tajuk helaian kerja. Anda boleh mendapatkannya dengan memanggil API [Dapatkan semua helaian kerja](/open/development/obtain-all-worksheets), atau hantar terus tajuk helaian kerja. |

### Parameter pertanyaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| operatorId | String | Ya | unionId pengendali. Anda boleh mendapatkannya dengan memanggil API [Dapatkan maklumat pengguna melalui kod log masuk senyap](/open/development/obtain-the-userid-of-a-user-by-using-the-log-free) atau API [Tanya butiran pengguna melalui userId](/open/development/query-user-details). |

### Isi permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| values | Array of Array | Ya | Senarai data yang akan ditambah. |
