---
title: "Semak sama ada laporan statistik pintar diaktifkan"
description: "Panggil API DingTalk ini untuk menyemak sama ada organisasi anda telah mengaktifkan laporan statistik pintar kehadiran sebelum memanggil API laporan statistik yang lain."
---

Panggil API ini untuk menyemak sama ada organisasi anda telah mengaktifkan laporan pintar kehadiran. Jika laporan pintar dinyahaktifkan, API laporan statistik yang lain tidak boleh dipanggil.

## Permintaan

| **Maklumat asas** | |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/topapi/attendance/isopensmartreport |
| Kaedah HTTP | POST |
| Jenis aplikasi yang disokong | appType-Aplikasi dalaman appType-Aplikasi perusahaan pihak ketiga |
| Kebenaran | permission-qyapi_base-Kebenaran asas yang diperlukan untuk memanggil API organisasi |

### Parameter query

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | 6d1bxxxx | Kelayakan aplikasi yang digunakan untuk memanggil API ini.   - Aplikasi dalaman: Dapatkannya dengan memanggil API [Dapatkan access_token aplikasi dalaman](/ms/open/development/obtain-orgapp-token). - Aplikasi perusahaan pihak ketiga: Dapatkannya dengan memanggil API Dapatkan access_token aplikasi perusahaan pihak ketiga. |

### Contoh permintaan

```curl
curl -X POST "https://api.dingtalk.io/topapi/attendance/isopensmartreport" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=b74b3xxxx0bb7c'
```

Java

```text

```

## Respons

### Isi respons

| Nama | Jenis | Contoh | Penerangan |
| --- | --- | --- | --- |
| result | IsOpenSmartReportForTopVo |  | Hasil yang dikembalikan. |
| smart_report | Boolean | true | Sama ada laporan statistik pintar diaktifkan:   - **true**: Diaktifkan - **false**: Dinyahaktifkan |
| request_id | String | 6f9h5mh9a94i | ID permintaan. |
| errcode | Number | 0 | Kod pemulangan. |

### Contoh isi respons

```json
{
  "errcode": 0,
  "result": {
    "smart_report": true
  },
  "request_id": "6f9h5mh9a94i"
}
```

### Kod ralat

Jika panggilan API mengembalikan ralat, cari penyelesaian dalam dokumen [Kod ralat global](/ms/open/development/server-api-error-codes-1) berdasarkan mesej ralat.
