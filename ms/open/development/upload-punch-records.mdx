Panggil API ini untuk memuat naik rekod leret kad atau pengecaman wajah daripada sistem kehadiran pihak ketiga ke DingTalk Attendance sebagai rekod daftar masuk DingTalk.

## Permintaan

| **Maklumat asas** | |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/topapi/attendance/record/upload |
| Kaedah HTTP | POST |
| Jenis aplikasi yang disokong | appType-Aplikasi dalaman |
| Kebenaran yang diperlukan | permission-Pro.AttendanceRecord.Write-Kebenaran tulis untuk rekod daftar masuk kehadiran |

### Parameter pertanyaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | af21axxx | Kelayakan aplikasi yang digunakan untuk memanggil API ini. Dapatkannya dengan memanggil [Dapatkan access_token bagi Aplikasi dalaman](/ms/open/development/obtain-orgapp-token). |

### Isi permintaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| userid | String | Ya | user123 | ID pengguna bagi pekerja yang rekod daftar masuknya ingin dimuat naik. |
| device_name | String | Ya | Kehadiran Pintu Timur | Nama peranti Kehadiran. Nilai ini tersuai, contohnya 123456. |
| device_id | String | Ya | abc123456 | ID peranti Kehadiran. Nilai ini tersuai, contohnya abcde. |
| photo_url | String | Tidak | https://xxx.com/xxx.png | URL gambar alias daftar masuk. URL ini mesti boleh diakses secara umum. |
| user_check_time | Number | Ya | 1587020403000 | Masa pekerja mendaftar masuk, dalam milisaat.  **Nota**   - Parameter ini mesti dalam milisaat. - Hantar tarikh dalam tempoh 180 hari yang lalu. |

### Contoh permintaan

```curl
curl -X POST "https://api.dingtalk.io/topapi/attendance/record/upload" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=0927xxxx3e28ea' \
-d 'device_id=abc123456' \
-d 'device_name=Kehadiran%20Pintu%20Timur' \
-d 'photo_url=https%3A%2F%2Fxxx.com%2Fxxx.png' \
-d 'user_check_time=1587020403000' \
-d 'userid=dd_dd'
```

Java

```text
DingTalkClient client = new DefaultDingTalkClient("https://api.dingtalk.io/topapi/attendance/record/upload");
OapiAttendanceRecordUploadRequest req = new OapiAttendanceRecordUploadRequest();
req.setUserid("dd_dd");
req.setDeviceName("Kehadiran Pintu Timur");
req.setDeviceId("abc123456");
req.setPhotoUrl("https://xxx.com/xxx.png");
req.setUserCheckTime(1587020403000L);
OapiAttendanceRecordUploadResponse rsp = client.execute(req, access_token);
System.out.println(rsp.getBody());
```

## Respons

### Isi respons

| Nama | Jenis | Contoh | Penerangan |
| --- | --- | --- | --- |
| success | Boolean | true | Menunjukkan sama ada panggilan berjaya. |
| errcode | Number | 0 | Kod pemulangan. |
| errmsg | String | ok | Penerangan kod pemulangan. |
| request_id | String | ktoftehkz2bt | ID permintaan. |

### Contoh isi respons

```json
{
  "errcode":0,
  "success":true,
  "request_id" : "3ynh2gp5ndke"
}
```

### Kod ralat

Jika panggilan ke API ini gagal, cari penyelesaian berdasarkan mesej ralat dalam dokumen [Kod ralat global](/ms/open/development/server-api-error-codes-1).
