title: "Dapatkan maklumat pengguna melalui kod log masuk senyap"
description: "Panggil API DingTalk untuk mendapatkan maklumat pengguna melalui kod log masuk senyap bagi mengenal pasti pengguna semasa dalam aplikasi klien DingTalk."
---

## Permintaan

| **Maklumat asas** | |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/topapi/v2/user/getuserinfo |
| Kaedah HTTP | POST |
| Jenis aplikasi yang disokong | appType-Aplikasi dalamanappType-Aplikasi perusahaan pihak ketiga |
| Kebenaran yang diperlukan | permission-qyapi_base-Kebenaran asas diperlukan untuk memanggil API perusahaan |

### Parameter pertanyaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | 6ed1bxxx | Kelayakan aplikasi yang digunakan untuk memanggil API ini.   - Untuk aplikasi dalaman, dapatkan melalui API untuk mendapatkan [access_token aplikasi dalaman](/open/development/obtain-orgapp-token). - Untuk aplikasi perusahaan pihak ketiga, dapatkan melalui API untuk mendapatkan access_token perusahaan pihak ketiga. |

### Isi permintaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| code | String | Ya | bab02f63c1e030fbbxxxx | authorization_code log masuk senyap. Untuk cara mendapatkannya, rujuk:   - authorization_code log masuk senyap untuk mini program - authorization_code log masuk senyap untuk aplikasi mikro   **Nota**  authorization_code ini sah selama 5 minit dan hanya boleh digunakan sekali. |

### Contoh permintaan

```curl
curl -X POST "https://api.dingtalk.io/topapi/v2/user/getuserinfo" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=417124xxxx2a3c270d5' \
-d 'code=123456'
```

Java

```text
DingTalkClient client = new DefaultDingTalkClient("https://api.dingtalk.io/topapi/v2/user/getuserinfo");
OapiV2UserGetuserinfoRequest req = new OapiV2UserGetuserinfoRequest();
req.setCode("bab02f63c1e030fbbxxxx");
OapiV2UserGetuserinfoResponse rsp = client.execute(req, access_token);
System.out.println(rsp.getBody());
```


Node.js

```javascript

  const config = new Config()
  config.serverUrl = 'https://api.dingtalk.io/topapi/v2/user/getuserinfo'
```

## Respons

### Isi respons

| Nama | Jenis | Contoh | Penerangan |
| --- | --- | --- | --- |
| request_id | String | e8krly4vyiln | ID permintaan. |
| errcode | Number | 0 | Kod pemulangan**.** |
| errmsg | String | ok | Penerangan teks bagi kod pemulangan. |
| result | UserGetByCodeResponse |  | Hasil yang dikembalikan. |
| userid | String | user456 | ID pengguna bagi pengguna. |
| device_id | String | 12drtfxxxxx | ID peranti. |
| sys | Boolean | true | Menunjukkan sama ada pengguna ialah admin.   - **true**: Ya - **false**: Tidak |
| sys_level | Number | 1 | Tahap admin.   - **1**: Super Admin - **2**: Sub Admin - **100**: Bos - **0**: Lain-lain (seperti pekerja biasa) |
| associated_unionid | String | N2o5U3axxxx | unionId yang dikaitkan dengan pengguna. |
| unionid | String | gliiW002zUxxxx | unionId bagi pengguna. |
| name | String | Zhang xx | Nama pengguna. |

### Kod ralat

Jika ralat dikembalikan semasa anda memanggil API ini, cari penyelesaiannya dalam dokumen [Kod ralat global](/open/development/server-api-error-codes-1) berdasarkan mesej ralat.
