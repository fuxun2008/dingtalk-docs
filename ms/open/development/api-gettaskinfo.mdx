title: "Get task status"
description: "Panggil API ini untuk menanyakan status pelaksanaan tugas melalui Task, biasa digunakan bersama-sama dengan API salin dokumen."
---

Tanyakan status tugas mengikut Task ID. API ini boleh digunakan bersama-sama dengan API salin dokumen.

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v2.0/doc/task/info/{taskId}` |
| Kaedah HTTP | GET |
| Jenis aplikasi yang disokong | appType-Aplikasi dalaman |
| Kebenaran yang diperlukan | permission-SNS.Document.WorkspaceDocument.Read-Kebenaran baca dokumen SNS Knowledge Base |

### Pengepala permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses yang digunakan untuk memanggil API ini. Dapatkannya dengan memanggil API [Dapatkan access token aplikasi dalaman](/ms/open/development/obtain-the-access-token-of-an-internal-app#). |

### Parameter laluan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| taskId | String | Ya | ID Tugas. Dapatkannya dengan memanggil API [Salin dokumen](/ms/open/development/api-copydoc#). |

### Contoh permintaan

HTTP

```http
GET /v2.0/doc/task/info/12345678 HTTP/1.1
Host:api.dingtalk.io
x-acs-dingtalk-access-token:example-token
Content-Type:application/json
```

## Respons

### Isi respons

| Nama | Jenis | Penerangan |
| --- | --- | --- |
| taskId | String | ID Tugas. |
| status | Integer | Status tugas:   - **-1**: Belum diproses - **0**: Sedang diproses - **1**: Berjaya - **2**: Sebahagian gagal - **3**: Semua gagal - **4**: Gagal |
| totalCount | Integer | Jumlah keseluruhan tugas. |
| succCount | Integer | Bilangan tugas yang berjaya. |
| failCount | Integer | Bilangan tugas yang gagal. |
