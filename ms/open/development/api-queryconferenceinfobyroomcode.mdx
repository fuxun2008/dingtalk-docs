Panggil API ini untuk menanyakan maklumat mesyuarat mengikut roomCode mesyuarat dan parameter penomboran.

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/conference/roomCodes/{roomCode}/infos` |
| Kaedah HTTP | GET |
| Jenis aplikasi yang disokong | appType-Aplikasi dalaman　appType-Aplikasi perusahaan pihak ketiga |
| Kebenaran diperlukan | permission-VideoConference.Conference.Read-Kebenaran membaca maklumat Mesyuarat Video |

### Header permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses yang digunakan untuk memanggil API ini. Dapatkan seperti berikut:   - Bagi Aplikasi dalaman, panggil API [Dapatkan access token aplikasi dalaman](/open/development/obtain-the-access-token-of-an-internal-app#). - Bagi Aplikasi perusahaan pihak ketiga, panggil API [Dapatkan access token organisasi yang dibenarkan untuk aplikasi pihak ketiga](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#). |

### Parameter laluan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| roomCode | String | Ya | Kod Mesyuarat. |

### Parameter kueri

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| nextToken | String | Tidak | Cursor penomboran. |
| maxResults | Integer | Tidak | Saiz halaman. |

### Contoh permintaan

HTTP

```http
GET /v1.0/conference/roomCodes/4272xxxxx/infos?nextToken=0&maxResults=10 HTTP/1.1
Host:api.dingtalk.io
x-acs-dingtalk-access-token:1803b054eb783eb6a4030369xxx10476
Content-Type:application/json
```

## Respons

### Isi respons

| Nama | Jenis | Penerangan |
| --- | --- | --- |
| nextToken | String | Cursor penomboran. |
| hasMore | Boolean | Sama ada hasil selanjutnya tersedia. |
| totalCount | Integer | Jumlah bilangan hasil. |
| conferenceList | Array | Senarai maklumat mesyuarat. Jika kod mesyuarat berkaitan dengan Tempah Mesyuarat atau mesyuarat berulang, kod mesyuarat tersebut mungkin sepadan dengan beberapa instans mesyuarat. |
| conferenceId | String | ID mesyuarat. |
| title | String | Tajuk mesyuarat. |
| roomCode | String | Kod Mesyuarat. |
| externalLinkUrl | String | Pautan untuk Sertai persidangan. |
| status | Integer | Status mesyuarat:   - 0: Dimulakan - 1: Mesyuarat tamat - 2: Mesyuarat dimulakan |
| startTime | Long | Cap masa mula mesyuarat, dalam milisaat. |
| endTime | Long | Cap masa tamat mesyuarat, dalam milisaat. Dikembalikan selepas mesyuarat tamat. |
| confDuration | Long | Tempoh mesyuarat, dalam milisaat. Dikembalikan selepas mesyuarat tamat. |
| creatorId | String | unionId Pencipta mesyuarat. |
| creatorNick | String | Nama Pencipta mesyuarat. |
| scheduleConferenceId | String | ID Tempah Mesyuarat. |
| bizType | String | Jenis perniagaan mesyuarat:   - 0: Mesyuarat Video Segera - 3: Tempah Mesyuarat - audio_conf: Mesyuarat Audio |

| 400 | missingRoomCode | missingRoomCode | Kod mesyuarat tiada |
| 400 | paramError | paramError | Ralat parameter |
| 403 | noPermission | noPermission | Tiada kebenaran |
| 500 | systemError | systemError | Ralat sistem |
