## Parameter FormComponent

**formComponents** ialah senarai komponen borang. Tidak semua komponen menyokong setiap atribut dalam Props. Untuk atribut yang disokong oleh setiap kawalan, rujuk contoh permintaan di bawah. Sesetengah kawalan bekas, seperti suite kelulusan dan kawalan butiran, menyokong kawalan anak. Gunakan children untuk mentakrifkan jenis dan atribut setiap kawalan anak. Kawalan anak mengikut takrifan atribut yang sama seperti kawalan lain. Model kawalan adalah seperti berikut:

<Warning>
Had umum untuk kawalan borang:
</Warning>

- componentId: ID kawalan. Panjang maksimum: 64 aksara.
- bizAlias: Alias perniagaan kawalan. Nilai ini mesti unik dalam borang. Tentukan sama ada bizAlias atau componentId. Panjang maksimum: 64 aksara.
- label: Tajuk kawalan. Panjang maksimum: 20 aksara.
- placeholder: Petunjuk input. Panjang maksimum: 128 aksara.
- content: Kandungan kawalan TextNote. Panjang maksimum: 500 aksara.
- Jumlah panjang kawalan butiran jadual tidak boleh melebihi 65,535 aksara. Hadkan setiap kawalan butiran kepada 100 rekod atau kurang.

#### Atribut kawalan biasa

```json
{
  "componentId": "TextField-12345677",   // ID kawalan. Unik dalam borang. Tentukan sama ada ini atau bizAlias
  "required":true,  // Sama ada kawalan ini wajib
  "label": "Teks satu baris",   // Tajuk kawalan
  "placeholder": "Masukkan nilai",    // Petunjuk input
  "bizAlias": "staffId", // Alias perniagaan kawalan. Unik dalam borang. Tentukan sama ada ini atau componentId
  "print": "0", // Sama ada medan disertakan semasa cetak (0: tidak dicetak; 1: boleh dicetak). Lalai: boleh dicetak
  "disabled": false, // Sama ada kawalan boleh diedit
}
```

## Parameter FormComponentValues

Takrifkan nilai dengan tepat mengikut komponen yang digunakan semasa anda mencipta templat. Rujuk [Parameter FormComponent](#900adc505f44g) untuk memberikan nilai kepada komponen borang:

### Kawalan lokasi

```json
{
    "name": "[\"Masa Semasa\",\"Lokasi Semasa\"]", // Label kawalan
    "value": "[\"2025-05-27 14:27:20\",120.021195,30.281506,\"Alibaba Group Xixi Campus Zone C, 960-1 Wenyi West Road, Yuhang District, Hangzhou, Zhejiang\",100]"
}
```
