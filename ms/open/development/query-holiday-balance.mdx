title: "Tanya baki cuti"
description: "Gunakan API DingTalk ini untuk menyemak baki cuti pekerja mengikut jenis cuti dan ID pekerja dengan penomboran halaman, sehingga 50 rekod bagi setiap panggilan."
---

Panggil API ini untuk menyemak baki cuti mengikut organisasi atau pekerja dengan penomboran halaman. Setiap panggilan mengembalikan sehingga 50 rekod.

## Permintaan

| **Maklumat asas** | |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/topapi/attendance/vacation/quota/list |
| Kaedah HTTP | POST |
| Jenis aplikasi yang disokong | appType-Aplikasi dalaman　appType-Aplikasi perusahaan pihak ketiga |
| Kebenaran yang diperlukan | permission-qyapi_holiday_readonly-Kebenaran baca cuti DingTalk |

### Parameter pertanyaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | bE74xxxx | Kelayakan aplikasi yang digunakan untuk memanggil API ini.   - Aplikasi dalaman: Dapatkannya dengan memanggil API [Dapatkan access_token Aplikasi dalaman](/ms/open/development/obtain-orgapp-token). - Aplikasi perusahaan pihak ketiga: Dapatkannya dengan memanggil API Dapatkan access_token Aplikasi perusahaan pihak ketiga. |

### Isi permintaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| leave_code | String | Ya | f84a2xxxx | Pengecam unik jenis cuti. Panggil API [Tanya senarai peraturan cuti](/ms/open/development/holiday-type-query) untuk mendapatkan nilai leave_code. |
| op_userid | String | Ya | user01 | ID pengguna admin dalam organisasi anda yang mempunyai kebenaran aplikasi untuk **Kelulusan OA**. |
| userids | String | Ya | user02,user03 | Senarai ID pekerja yang hendak disemak. |
| offset | Number | Ya | 0 | Ofset penomboran halaman. Mesti integer bukan negatif bermula daripada 0. |
| size | Number | Ya | 10 | Saiz halaman. Nilai maksimum: 50. |

### Contoh permintaan

```curl
curl -X POST "https://api.dingtalk.io/topapi/attendance/vacation/quota/list" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=48acxxxx0dbdbee' \
-d 'leave_code=f84a2829-d245-4312-9ff2-0653e5b3abb2' \
-d 'offset=0' \
-d 'op_userid=zhangsan' \
-d 'size=10' \
-d 'userids=zhangsan%2Clisi'
```

Java

```java
DingTalkClient client = new DefaultDingTalkClient("https://api.dingtalk.io/topapi/attendance/vacation/quota/list");
OapiAttendanceVacationQuotaListRequest req = new OapiAttendanceVacationQuotaListRequest();
req.setLeaveCode("f84a2xxxx");
req.setOpUserid("user01");
req.setUserids("user02,user03");
req.setOffset(0L);
req.setSize(10L);
OapiAttendanceVacationQuotaListResponse rsp = client.execute(req, access_token);
System.out.println(rsp.getBody());
```

## Respons

### Isi respons

| Nama | Jenis | Contoh | Penerangan |
| --- | --- | --- | --- |
| result | OapiLeaveQuotaUserListVo |  | Hasil yang dikembalikan. |
| has_more | Boolean | false | Menunjukkan sama ada terdapat lebih banyak rekod.   - **true**: Terdapat lebih banyak rekod. - **false**: Tiada lagi rekod. |
| leave_quotas | Leavequotas[] |  | Senarai baki cuti. |
| userid | String | user01 | ID pengguna pekerja. |
| leave_code | String | f84a2xxxx | Pengecam unik jenis cuti. |
| quota_cycle | String | 2019 | Kitaran yang terpakai bagi kuota. |
| quota_id | String | f8abb2xxxx | Pengecam unik kuota. |
| start_time | Number | 1653851001000 | Masa mula tempoh sah cuti, sebagai cap masa dalam milisaat. |
| end_time | Number | 1753851001000 | Masa tamat tempoh sah kuota, sebagai cap masa dalam milisaat. |
| quota_num_per_hour | Number | 1000 | Jumlah kuota, dikira dalam jam.  **Nota**  Apabila jenis cuti dikira dalam jam, nilai ini tidak kosong dan dinyatakan dalam perseratus jam.  Contohnya, 1000 = 10 jam. |
| quota_num_per_day | Number | 1000 | Jumlah kuota, dikira dalam hari.  **Nota**  Apabila jenis cuti dikira dalam hari, nilai ini tidak kosong dan dinyatakan dalam perseratus hari.  Contohnya, 1000 = 10 hari. |
| used_num_per_day | Number | 100 | Kuota yang telah digunakan, dikira dalam hari.  **Nota**  Apabila jenis cuti dikira dalam hari, nilai ini tidak kosong dan dinyatakan dalam perseratus hari.  Contohnya, 100 = 1 hari. |
| used_num_per_hour | Number | 1000 | Kuota yang telah digunakan, dikira dalam jam.  **Nota**  Apabila jenis cuti dikira dalam jam, nilai ini tidak kosong dan dinyatakan dalam perseratus jam.  Contohnya, 1000 = 10 jam. |
| errcode | Number | 0 | Kod pemulangan. |
| errmsg | String | ok | Penerangan kod pemulangan. |
| success | Boolean | true | Menunjukkan sama ada panggilan berjaya.   - **true**: Ya - **false**: Tidak |
