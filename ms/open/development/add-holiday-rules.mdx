Panggil API ini untuk mencipta peraturan cuti.

## Penerangan panggilan API

API ini mencipta dua jenis peraturan cuti:

- Peraturan cuti am, seperti cuti peribadi dan cuti perkahwinan. Baki bagi peraturan ini boleh diubah. Selepas anda mencipta peraturan cuti am dengan API ini, baki cuti ditetapkan kepada 0 secara lalai. Panggil API [Mulakan baki cuti](/ms/open/development/initialize-holiday-balance) untuk memulakan baki cuti.
- Peraturan cuti ganti. Bagi cuti ganti yang ditambah melalui API ini, peraturan baki lalai ialah **Tempoh kerja lebih masa dikira secara automatik ke dalam baki cuti ganti**. Anda tidak perlu memanggil API permulaan baki.

Tetapan yang setara dalam DingTalk Admin Console terletak di **Pengurusan Cuti** > **Peraturan Cuti**. Klik **Tambah Cuti** untuk membuka dialog **Cuti Baharu** yang mengandungi medan berikut:

| Medan | Penerangan / Pilihan |
|---|---|
| **Nama Cuti** | Masukkan nama cuti |
| **Cuti Pekerja Baharu** | Contoh: **Boleh mengambil cuti sebaik sahaja menyertai syarikat** |
| **Skop Berkenaan** | Contoh: **Seluruh Syarikat** (boleh disunting) |
| **Berbayar** | **Berbayar** atau **Tidak Berbayar**; cuti berbayar dikira sebagai kehadiran dalam statistik |
| **Unit Cuti Minimum** | Contoh: **Mengikut Hari** |
| **Pengiraan Tempoh Cuti** | Contoh: **Kira Mengikut Hari Bekerja** (tidak termasuk hari rehat pekerja, seperti hujung minggu tanpa jadual syif dan cuti umum) |

Bahagian **Peraturan Pengiraan Tempoh Cuti** menghimpunkan tetapan **Unit Cuti Minimum** dan **Pengiraan Tempoh Cuti**. Klik **Simpan** untuk mencipta peraturan.

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/v1.0/attendance/leaves/types |
| Kaedah HTTP | POST |
| Jenis aplikasi yang disokong | appType-Aplikasi dalaman　appType-Aplikasi perusahaan pihak ketiga |
| Kebenaran yang diperlukan | permission-qyapi_holiday_manage-Kebenaran pengurusan cuti DingTalk |

### Pengepala permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Dapatkannya seperti berikut:   - Aplikasi dalaman: panggil API [Dapatkan access token aplikasi dalaman](/ms/open/development/obtain-the-access-token-of-an-internal-app). - Aplikasi perusahaan pihak ketiga: panggil API untuk mendapatkan access token organisasi yang telah memberi kebenaran kepada aplikasi pihak ketiga. |

### Parameter pertanyaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| opUserId | String | Ya | userId pentadbir. Pentadbir ini juga mesti mempunyai kebenaran pengurusan bagi aplikasi Kelulusan OA.  Jika syarat ini tidak dipenuhi, API akan mengembalikan ralat yang menunjukkan bahawa pentadbir jabatan tidak wujud. |

### Isi permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| leaveName | String | Ya | Nama peraturan cuti. |
| leaveViewUnit | String | Ya | Unit tempoh cuti.   - **day**: Hari - **halfDay**: Separuh hari - **hour**: Jam |
| bizType | String | Ya | Jenis cuti.   - **general_leave**: Cuti am - **lieu_leave**: Kerja lebih masa kepada cuti ganti   Sesebuah organisasi hanya boleh mempunyai satu peraturan kerja lebih masa kepada cuti ganti. |
| naturalDayLeave | Boolean | Ya | Menentukan sama ada tempoh cuti dikira mengikut hari kalendar.   - **true**: Ya - **false**: Tidak   Sebagai contoh, pekerja bernama Ahmad menghantar borang Kelulusan permohonan cuti dengan masa mula 11 Apr 2022, 09:30 dan masa tamat 18 Apr 2022, 18:30. 16 Apr dan 17 Apr ialah hujung minggu (hari rehat).   - Jika parameter ini true, permohonan cuti dikira sebagai 8 hari. Ini termasuk hari rehat pekerja tanpa jadual syif dan cuti umum. - Jika parameter ini false, permohonan cuti dikira sebagai 6 hari. Ini tidak termasuk hari rehat pekerja tanpa jadual syif dan cuti umum. |
| hoursInPerDay | Long | Ya | Waktu kerja sehari yang digunakan untuk penukaran. Nilai sebenar ialah nilai parameter dibahagi dengan 100.  Sebagai contoh, jika syif seorang pekerja mempunyai 8 jam waktu kerja, tetapkan parameter ini kepada 8\*100=800. |
| extras | String | Tidak | Peraturan tempoh sah cuti ganti.   - **validity_type**: Jenis tempoh sah    - **absolute_time**: Masa mutlak   - **relative_time**: Masa relatif - **validity_value**: Tarikh lanjutan    - Jika validity_type ialah **absolute_time**, nilai ini tidak boleh kosong dan mesti menggunakan format "yy-mm".   - Jika validity_type ialah **relative_time**, nilai ini mesti integer yang lebih besar daripada 1.   Parameter ini wajib apabila jenis cuti biz_type ialah **lieu_leave**. |
| paidLeave | Boolean | Tidak | Menentukan sama ada cuti ini berbayar. |
| paidLeave | Boolean | Tidak | Menentukan sama ada cuti ini berbayar. |
| visibilityRules | Array | Tidak | Senarai peraturan skop berkenaan. Jika tidak dinyatakan, peraturan ini terpakai kepada seluruh syarikat. |
| visible | Array of String | Tidak | Senarai data dalam skop berkenaan.   - Jika type=staff, hantar senarai userId pekerja. - Jika type=dept, hantar senarai ID jabatan. - Jika type=label, hantar senarai ID peranan. |
| type | String | Tidak | Jenis peraturan skop berkenaan.   - **dept**: Jabatan - **staff**: Pekerja - **label**: Peranan |
| whenCanLeave | String | Tidak | Bila cuti boleh diambil.  Medan ini khusus untuk aplikasi perusahaan pihak ketiga.   - **entry**: Boleh diambil sebaik sahaja menyertai syarikat. - **formal**: Boleh diambil selepas tamat tempoh percubaan. |
| leaveTimeCeilMinUnit | String | Tidak | Unit minimum yang digunakan semasa membundarkan tempoh cuti ke atas.  Medan ini khusus untuk aplikasi perusahaan pihak ketiga.   - **hour**: Jam. Kurang daripada 1 jam dikira sebagai 1 jam. - **halfHour**: Setengah jam. Kurang daripada setengah jam dikira sebagai setengah jam. |
| leaveTimeCeil | Boolean | Tidak | Menentukan sama ada tempoh cuti dibundarkan ke atas.  Medan ini khusus untuk aplikasi perusahaan pihak ketiga. |
| minLeaveHour | double | Tidak | Tempoh cuti minimum (terpakai apabila unit cuti ialah jam). Jika tempoh cuti kurang daripada nilai ini, nilai ini akan digunakan.  Medan ini khusus untuk aplikasi perusahaan pihak ketiga. |
| submitTimeRule | Object | Tidak | Peraturan had masa penghantaran. |
| timeValue | Long | Tidak | Nilai had.   - Jika timeUnit ialah day, julat sah ialah 0 hingga 30 hari. - Jika timeUnit ialah hour, julat sah ialah 0 hingga 24 jam. |
| timeUnit | String | Tidak | Unit masa.   - **day**: Hari - **hour**: Jam |
| timeType | String | Tidak | Jenis had.   - **before**: Hantar lebih awal - **after**: Hantar secara retroaktif |
| enableTimeLimit | Boolean | Tidak | Menentukan sama ada had masa penghantaran diaktifkan.   - **true**: Hidup - **false**: Mati |
| leaveCertificate | Object | Tidak | Sijil cuti. |
| unit | String | Tidak | Unit tempoh untuk mewajibkan sijil cuti.   - **hour**: Jam - **day**: Hari |
| duration | double | Tidak | Tempoh cuti yang melebihinya memerlukan sijil cuti.   - Jika unit ialah day, sijil cuti diperlukan bagi cuti yang melebihi satu hari. - Jika unit ialah hour, sijil cuti diperlukan bagi cuti yang melebihi satu jam.   Apabila permohonan cuti yang dihantar melebihi tempoh yang ditetapkan, medan sijil cuti akan dipaparkan secara automatik dalam borang Kelulusan. |
| enable | Boolean | Tidak | Menentukan sama ada sijil cuti diaktifkan.   - **true**: Hidup - **false**: Mati |
| promptInformation | String | Tidak | Teks prompt cuti. |
| maxLeaveTime | Long | Tidak | Tempoh cuti maksimum (terpakai apabila unit cuti ialah jam atau hari).  Medan ini khusus untuk aplikasi perusahaan pihak ketiga. |
| leaveHourCeil | String | Tidak | Cara membundarkan tempoh cuti:  Medan ini khusus untuk aplikasi perusahaan pihak ketiga.   - **up**: Bundarkan ke atas - **down**: Bundarkan ke bawah - **none**: Tiada pembundaran |
| freedomLeave | Boolean | Tidak | Jenis cuti yang tidak memerlukan kawalan baki (seperti cuti peribadi).  Medan ini khusus untuk aplikasi perusahaan pihak ketiga. |
