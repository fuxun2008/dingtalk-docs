Panggil API ini untuk mencari syif secara kabur mengikut nama. Respons mengandungi nama dan ID syif.

## Permintaan

| **Maklumat asas** | |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/topapi/attendance/shift/search |
| Kaedah HTTP | POST |
| Jenis aplikasi yang disokong | appType-Aplikasi dalaman　appType-Aplikasi perusahaan pihak ketiga |
| Kebenaran yang diperlukan | qyapi_attendance_group_read (kebenaran baca kumpulan kehadiran) |

### Parameter pertanyaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | 6d1bxxxx | Kelayakan aplikasi yang digunakan untuk memanggil API ini.   - Aplikasi dalaman: Panggil API [Dapatkan access_token aplikasi dalaman](/ms/open/development/obtain-orgapp-token) untuk mendapatkannya. - Aplikasi perusahaan pihak ketiga: Panggil API Dapatkan access_token aplikasi perusahaan pihak ketiga untuk mendapatkannya. |

### Isi permintaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| op_user_id | String | Ya | manager4220 | userId pengendali. |
| shift_name | String | Ya | A | Nama syif. |

### Contoh permintaan

```curl
curl -X POST "https://api.dingtalk.io/topapi/attendance/shift/search" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=ab85bxxxx739d5' \
-d 'op_user_id=dd_dd' \
-d 'shift_name=Syif%20Siang%20Biasa'
```

Java

```java
DingTalkClient client = new DefaultDingTalkClient("https://api.dingtalk.io/topapi/attendance/shift/search");
OapiAttendanceShiftSearchRequest req = new OapiAttendanceShiftSearchRequest();
req.setOpUserId("dd_dd");
req.setShiftName("Syif Siang Biasa");
OapiAttendanceShiftSearchResponse rsp = client.execute(req, access_token);
System.out.println(rsp.getBody());
```

Python

```python
import dingtalk.api

req=dingtalk.api.OapiAttendanceShiftSearchRequest("https://api.dingtalk.io/topapi/attendance/shift/search")

req.op_user_id="dd_dd"
req.shift_name="Syif Siang Biasa"
try:
	resp= req.getResponse(access_token)

	print(e)
```

PHP

```php

date_default_timezone_set('Asia/Shanghai');

$c = new DingTalkClient(DingTalkConstant::$CALL_TYPE_OAPI, DingTalkConstant::$METHOD_POST , DingTalkConstant::$FORMAT_JSON);

$req->setShiftName("Syif Siang Biasa");

```


## Respons

### Isi respons

| Nama | Jenis | Contoh | Penerangan |
| --- | --- | --- | --- |
| result | TopMinimalismShiftVO[] |  | Hasil pertanyaan. |
| name | String | Syif Siang Biasa | Nama syif. |
| id | Number | 677995086 | ID syif. |
| success | Boolean | true | Menunjukkan sama ada panggilan berjaya.   - **true**: Berjaya - **false**: Gagal |
| errcode | Number | 0 | Kod pulangan. |
| errmsg | String | ok | Mesej kod pulangan. |
| request_id | String | 4wsw01tcq1h4 | ID permintaan. |

### Contoh isi respons

```json
{
  "errcode": 0,
  "errmsg":"ok",
  "result": [
    {
      "id": 677995086,
      "name": "Syif Siang Biasa"
    }
  ],
  "success": true,
  "request_id": "4wsw01tcq1h4"
}
```

### Kod ralat

Jika panggilan mengembalikan ralat, cari penyelesaian berdasarkan mesej ralat dalam dokumen [Kod ralat global](/ms/open/development/server-api-error-codes-1).
