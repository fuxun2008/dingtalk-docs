Panggil API ini untuk mendapatkan maklumat lakaran kenit berbilang fail secara pukal.

### Penerangan API

Bagi imej, dokumen format WPS (Word, Excel, dan PowerPoint), fail PDF, dan fail TXT yang dimuat naik ke ruang storan, lakaran kenit dijana secara automatik dan tak segerak (asynchronous).

Panggil API ini untuk mendapatkan maklumat lakaran kenit fail yang disimpan secara pukal.

## Kebenaran

Untuk memanggil API ini, salah satu kebenaran berikut diperlukan.

| Jenis aplikasi | Disokong | Kebenaran | API Explorer Nyahpepijat |
| --- | --- | --- | --- |
| Aplikasi dalaman | Disokong | Kebenaran baca untuk fail storan organisasi | [API Explorer](https://open-dev.dingtalk.io/apiExplorer#/?devType=org&api=storage_1.0%23GetDentryThumbnails) |
| Aplikasi perusahaan pihak ketiga | Disokong | Kebenaran baca untuk fail storan organisasi | [API Explorer](https://open-dev.dingtalk.io/apiExplorer#/?devType=isv&api=storage_1.0%23GetDentryThumbnails) |
| Aplikasi peribadi pihak ketiga | Tidak disokong | Kebenaran baca untuk fail storan organisasi | Tidak disokong |

## Kaedah HTTP

```http
POST /v1.0/storage/spaces/{spaceId}/thumbnails/query?unionId=String HTTP/1.1
Host:api.dingtalk.io
x-acs-dingtalk-access-token:String
Content-Type:application/json

{
  "dentryIds" : [ "String" ]
}
```

## Parameter header

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Dapatkan seperti berikut:   - Untuk aplikasi dalaman, panggil API [Dapatkan access token aplikasi dalaman](/open/development/obtain-the-access-token-of-an-internal-app). - Untuk aplikasi perusahaan pihak ketiga, panggil API untuk mendapatkan access token organisasi yang diberi kuasa untuk aplikasi pihak ketiga. |

## Parameter path

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| spaceId | String | Ya | ID ruang. Dapatkan nilai parameter `id` dengan memanggil API [Tambah ruang](/open/development/add-space). |

## Parameter query

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| unionId | String | Ya | unionId pengendali. Dapatkan dengan memanggil API [Semak butiran pengguna](/open/development/query-user-details). |

## Parameter body

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| dentryIds | Array of String | Ya | ID fail. Bilangan maksimum ialah 30. Dapatkan nilai parameter `id` dengan memanggil API untuk mendapatkan senarai fail atau folder. |

## Parameter respons

| Nama | Jenis | Penerangan |
| --- | --- | --- |
| resultItems | Array | Senarai hasil pengambilan lakaran kenit. |
| spaceId | String | ID ruang tempat fail berada. |
| dentryId | String | ID fail. |
| success | Boolean | Sama ada maklumat lakaran kenit berjaya diperoleh. `true` menunjukkan berjaya. |
| errorCode | String | Sebab ralat. |
| thumbnail | Object | Maklumat lakaran kenit. |
| width | Integer | Lebar lakaran kenit, dalam px. |
| height | Integer | Tinggi lakaran kenit, dalam px. |
| url | String | URL lakaran kenit. |
