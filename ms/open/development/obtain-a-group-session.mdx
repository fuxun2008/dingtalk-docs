Panggil API ini untuk mendapatkan tetapan kumpulan dan maklumat ahli. API ini sesuai digunakan apabila pentadbir kumpulan ingin melihat tetapan kumpulan dan maklumat ahli, atau membuat keputusan pengurusan kumpulan.

## Permintaan

| **Maklumat asas** | |
| --- | --- |
| URL HTTP | https://oapi.dingtalk.io/chat/get |
| Kaedah HTTP | GET |
| Jenis aplikasi disokong | appType-Aplikasi dalaman |
| Kebenaran diperlukan | permission-qyapi_chat_read-Kebenaran baca maklumat asas kumpulan DingTalk |

### Parameter pertanyaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | 6d1bxxxx | Kelayakan aplikasi yang digunakan untuk memanggil API ini. Dapatkan melalui API untuk mendapatkan [access_token aplikasi dalaman](/ms/open/development/obtain-orgapp-token). |
| chatid | String | Ya | chate39f540dxxxx | ID sembang kumpulan.   - Hanya menyokong chatid yang dikembalikan oleh API Bahagian pelayan [Cipta sembang kumpulan](/ms/open/development/create-common-group-new-version-v2). - Tidak menyokong chatid yang diperoleh dengan memanggil JSAPI bahagian hadapan. |

### Contoh permintaan

```curl
curl -X GET "https://oapi.dingtalk.io/chat/get" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=0d7e495xxxxa3f694fd6e' \
-d 'chatid=chatid'
```

Java

```text
DingTalkClient client = new DefaultDingTalkClient("https://oapi.dingtalk.io/chat/get");
OapiChatGetRequest req = new OapiChatGetRequest();
req.setChatid("chate39f540dxxxx");
req.setHttpMethod("GET");
OapiChatGetResponse rsp = client.execute(req, access_token);
System.out.println(rsp.getBody());
```

Python

```python
import dingtalk.api

req=dingtalk.api.OapiChatGetRequest("https://oapi.dingtalk.io/chat/get")

req.chatid="chatid"
try:
  resp= req.getResponse(access_token)
  print(resp)
except Exception,e:
  print(e)
```

PHP

```php
include "TopSdk.php";
date_default_timezone_set('Asia/Shanghai');

$c = new DingTalkClient(DingTalkConstant::$CALL_TYPE_OAPI, DingTalkConstant::$METHOD_GET , DingTalkConstant::$FORMAT_JSON);
$req = new OapiChatGetRequest;
$req->setChatid("chatid");
$resp = $c->execute($req, $access_token, "https://oapi.dingtalk.io/chat/get");
```

C#

```text
IDingTalkClient client = new DefaultDingTalkClient("https://oapi.dingtalk.io/chat/get");
OapiChatGetRequest req = new OapiChatGetRequest();
req.Chatid = "chatid";
req.SetHttpMethod("GET");
OapiChatGetResponse rsp = client.Execute(req, access_token);
Console.WriteLine(rsp.Body);
```

## Respons

### Isi respons

| Nama | Jenis | Contoh | Penerangan |
| --- | --- | --- | --- |
| errcode | Number | 0 | Kod pemulangan. |
| errmsg | String | ok | Penerangan kod pemulangan. |
| chat_info | ChatInfo |  | Maklumat sembang kumpulan. |
| name | String | Sembang Seluruh Kakitangan | Nama kumpulan. |
| owner | String | manager4220 | userId pemilik kumpulan. |
| useridlist | String[] | ["user123","manager4220"] | Senarai userId ahli kumpulan. |
| conversationTag | Number | 2 | Jenis perbualan:   - **2**: Kumpulan organisasi. |
| chatBannedType | Number | 0 | Sama ada Bisukan ahli diaktifkan untuk kumpulan:   - **0** (lalai): Tidak dibisukan. - **1**: Bisukan Semua. |
| searchable | Number | 0 | Sama ada kumpulan boleh dicari:   - **0** (lalai): Tidak boleh dicari. - **1**: Boleh dicari. |
| validationType | Number | 0 | Sama ada pengesahan diperlukan untuk menyertai kumpulan:   - **0** (lalai): Tiada pengesahan. - **1**: Pengesahan diperlukan. |
| mentionAllAuthority | Number | 0 | Skop @all:   - **0** (lalai): Tersedia untuk semua orang. - **1**: Hanya pemilik kumpulan boleh menggunakan @all. |
| managementType | Number | 0 | Jenis pengurusan kumpulan:   - **0** (lalai): Semua orang boleh mengurus. - **1**: Hanya pemilik kumpulan boleh mengurus. |
| showHistoryType | Number | 0 | Sama ada ahli baharu boleh melihat 100 sembang terdahulu terakhir:   - **1**: Boleh dilihat. - **0**: Tidak boleh dilihat.  Jika tiada nilai dihantar, ahli baharu tidak boleh melihat. |
| icon | String | @lADPDfJ6Q7LLejDNAljNAlg | mediaID bagi Gambar Profil kumpulan. |
| status | Number | 1 | Status.   - 1: Normal. - 2: Dibubarkan. |

### Kod ralat

Jika berlaku ralat semasa memanggil API ini, cari penyelesaiannya dalam dokumen [Kod ralat global](/ms/open/development/server-api-error-codes-1) berdasarkan mesej ralat.

| Kod ralat (errorcode) | Mesej ralat (errmsg) | Penyelesaian |
| --- | --- | --- |
| 43007 | Tiada kebenaran untuk memanggil API ini. | Sahkan sama ada access_token dijana oleh Aplikasi semasa. |
| 49000 | Parameter chatid diperlukan. | Berikan chatid. |
| 40001 | Token tidak sah. | Sahkan sama ada access_token adalah betul. |
| 70001 | Organisasi tidak wujud. | Sahkan sama ada parameter adalah betul. |
| 40016 | chatid tidak sah. | Sahkan bahawa access_token dan chatid tergolong dalam Organisasi yang sama. |
| -1 | Sistem sibuk. | Cuba lagi kemudian. |
