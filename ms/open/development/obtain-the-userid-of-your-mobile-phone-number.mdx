---
title: "Tanya pengguna Akaun Syarikat mengikut nombor mudah alih"
description: "Ketahui cara memanggil API DingTalk untuk menanya userId pengguna Akaun Syarikat menggunakan nombor mudah alih; userId tidak lagi boleh diperoleh selepas pekerja meninggalkan organisasi."
---

Panggil API ini untuk mendapatkan ID pengguna Akaun Syarikat menggunakan nombor mudah alih. Jika pekerja telah meninggalkan organisasi, ID pengguna tidak lagi boleh diperoleh melalui nombor mudah alih.

## Permintaan

| **Maklumat asas** | |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/topapi/v2/user/getbymobile |
| Kaedah HTTP | POST |
| Jenis aplikasi yang disokong | appType-Aplikasi dalaman |
| Kebenaran diperlukan | permission-qyapi_get_member_by_mobile-Kebenaran untuk mendapatkan maklumat asas pengguna mengikut nombor mudah alih |

### Parameter pertanyaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | be3Fxxxx | Kelayakan aplikasi yang digunakan untuk memanggil API ini. Dapatkan dengan memanggil API untuk mendapatkan [access_token aplikasi dalaman](/ms/open/development/obtain-orgapp-token). |

### Isi permintaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| mobile | String | Ya | 185xxxxx676 | Nombor mudah alih pengguna. |
| support_exclusive_account_search | Boolean | Ya | true | Sama ada menyokong carian Akaun Syarikat mengikut nombor mudah alih.   - **true**: Disokong. - **false**: Tidak disokong.   **Nota**     - Hanya terpakai untuk Akaun Syarikat. - Hanya Akaun Syarikat yang dicipta oleh organisasi semasa boleh dicari. |

### Contoh permintaan

```curl
curl -X POST "https://api.dingtalk.io/topapi/v2/user/getbymobile" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=a16xxxxa2efbee' \
-d 'mobile=1851xxxx676' \
-d 'support_exclusive_account_search=true'
```

## Respons

### Isi respons

| Nama | Jenis | Contoh | Penerangan |
| --- | --- | --- | --- |
| request_id | String | 5w82ciuur781 | ID permintaan. |
| errcode | Number | 0 | Kod pulangan. |
| errmsg | String | ok | Penerangan kod pulangan. |
| result | Object |  | Hasil yang dipulangkan. |
| userid | String | zhangsan | ID pengguna pekerja. |
| exclusive_account_userid_list | String[] | ["zxxxx","lixxxi"] | Senarai ID pengguna bagi pekerja Akaun Syarikat.  **Nota**  Hanya Akaun Syarikat yang dicipta oleh organisasi semasa akan dipulangkan. |

### Contoh isi respons

```json
{
  "errcode":"0",
  "result":{
    "exclusive_account_userid_list":"[\"zxxxx\",\"lixxxi\"]",
    "userid":"zhangsan"
  },
  "errmsg":"ok"
}
```

### Kod ralat

Jika ralat berlaku semasa memanggil API ini, cari penyelesaian dalam dokumen [Kod ralat global](/ms/open/development/server-api-error-codes-1) berdasarkan mesej ralat.

| Kod ralat (errcode) | Mesej ralat (errmsg) | Penyelesaian |
| --- | --- | --- |
| 400002 | Invalid parameter | Sahkan bahawa parameter diisi mengikut keperluan dokumentasi di atas. |
| 40104 | Invalid mobile number in the organization | Sahkan bahawa nombor mudah alih adalah betul. |
| 60121 | User not found | Sahkan bahawa maklumat diisi dengan betul. |
| -1 | System busy | Cuba lagi kemudian. |
