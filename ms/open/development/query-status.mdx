---
title: "Tanya status cuti"
description: "Gunakan API DingTalk untuk menyemak status dan tempoh cuti harian pengguna mengikut senarai ID pengguna, dengan penomboran dan julat masa sehingga 180 hari."
---

Panggil API ini untuk menyemak status cuti harian dan tempoh cuti bagi pengguna tertentu dalam organisasi tertentu bagi julat masa yang ditetapkan.

## Permintaan

| **Maklumat asas** | |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/topapi/attendance/getleavestatus |
| Kaedah HTTP | POST |
| Jenis aplikasi yang disokong | appType-Aplikasi dalaman appType-Aplikasi perusahaan pihak ketiga |
| Kebenaran yang diperlukan | permission-qyapi_get_attendance_data-Kebenaran membaca data kehadiran |

### Parameter pertanyaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | 6d1bxxxx | Kelayakan aplikasi yang digunakan untuk memanggil API ini. Dapatkannya dengan memanggil [Dapatkan access_token Aplikasi dalaman](/ms/open/development/obtain-orgapp-token). |

### Isi permintaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| userid_list | String | Ya | user456,user123 | Senarai ID pengguna yang hendak ditanya. Maksimum 100 ID bagi setiap permintaan. |
| start_time | Number | Ya | 1538323200000 | Masa mula, dalam format Unix timestamp. Julat pertanyaan boleh mencapai sehingga 180 hari. |
| end_time | Number | Ya | 1546358399000 | Masa tamat, dalam format Unix timestamp. Julat pertanyaan boleh mencapai sehingga 180 hari. |
| offset | Number | Ya | 0 | Ofset penomboran, bermula daripada 0. Hanya berkuat kuasa apabila ditetapkan bersama parameter size. |
| size | Number | Ya | 10 | Saiz halaman. Nilai maksimum: 20. Hanya berkuat kuasa apabila ditetapkan bersama parameter offset. |

### Contoh permintaan

```curl
curl -X POST "https://api.dingtalk.io/topapi/attendance/getleavestatus" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=11b9xxxxc35a' \
-d 'end_time=1546358399000' \
-d 'offset=0' \
-d 'size=10' \
-d 'start_time=1538323200000' \
-d 'userid_list=123%2C121'
```

Java

```text

```

## Respons

### Isi respons

| Nama | Jenis | Contoh | Penerangan |
| --- | --- | --- | --- |
| errcode | Number | 0 | Kod pemulangan. |
| result | LeaveStatusListVO |  | Hasil pertanyaan. |
| has_more | Boolean | true | Menunjukkan sama ada terdapat lebih banyak data.   - **true**: Ya - **false**: Tidak |
| leave_status | LeaveStatusVO[] |  | Senarai status cuti. |
| duration_unit | String | percent_day | Unit cuti:   - **percent_day**: Hari - **percent_hour**: Jam |
| duration_percent | Number | 100 | Tempoh cuti didarab dengan 100. Contohnya, jika tempoh cuti pengguna ialah 1 hari, nilai ini ialah 100. |
| end_time | Number | 1599465600000 | Masa tamat cuti, dalam format Unix timestamp. |
| start_time | Number | 1599372000000 | Masa mula cuti, dalam format Unix timestamp. |
| userid | String | user456 | ID pengguna. |
| success | Boolean | true | Menunjukkan sama ada permintaan berjaya.   - **true**: Berjaya - **false**: Gagal |
| request_id | String | 5lbpbi9p1awk | ID permintaan. |
