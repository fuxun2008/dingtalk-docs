Panggil API ini untuk menanya butiran kalendar yang dilanggan.

## Request

### Maklumat asas

| Field | Value |
| --- | --- |
| HTTP URL | `https://api.dingtalk.io/v1.0/calendar/users/{userId}/subscribedCalendars/{calendarId}` |
| HTTP Method | GET |
| Jenis aplikasi disokong | appType-Aplikasi dalaman　appType-Aplikasi perusahaan pihak ketiga　appType-Aplikasi peribadi pihak ketiga |
| Kebenaran diperlukan | permission-Calendar.Calendar.Read-Kebenaran Telah dibaca untuk aplikasi Calendar |

### Request headers

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Dapatkan seperti berikut:   - Untuk aplikasi dalaman, panggil API [Dapatkan access token aplikasi dalaman](/ms/open/development/obtain-the-access-token-of-an-internal-app#). - Untuk aplikasi perusahaan pihak ketiga, panggil API [Dapatkan access token organisasi yang telah memberi kuasa kepada aplikasi pihak ketiga](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#). - Untuk aplikasi peribadi pihak ketiga, panggil API [Dapatkan user token](/ms/open/development/obtain-user-token#). |

### Path parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| userId | String | Ya | unionId pencipta kalendar atau editor bersama.   - Untuk aplikasi dalaman atau aplikasi perusahaan pihak ketiga, panggil API [Tanya butiran pengguna](/ms/open/development/query-user-details#) untuk mendapatkan nilai parameter unionid. - Untuk aplikasi peribadi pihak ketiga, panggil API [Dapatkan profil pengguna daripada Kenalan](/ms/open/development/dingtalk-retrieve-user-information#) untuk mendapatkan nilai parameter unionId. |
| calendarId | String | Ya | ID kalendar yang dilanggan. Panggil API [Cipta kalendar langganan](/ms/open/development/create-subscription-calendar#) untuk mendapatkan nilai parameter calendarId. |
