Panggil API ini untuk mencipta atau mengemas kini templat kelulusan.

## Penerangan panggilan API

- Setiap organisasi boleh mencipta sehingga 200 templat dalam Pusat Proses. Selepas had ini dicapai, panggilan API ini akan mengembalikan ralat.
- Klien DingTalk hanya memaparkan tiga medan pertama borang templat dalam senarai kelulusan.
- Simpan nama templat dan processCode yang dikembalikan oleh API ini bagi setiap templat aliran kerja kelulusan sendiri yang anda cipta. API lain memerlukan nilai ini.
- Templat Kelulusan OA sendiri hanya menyokong komponen kelulusan yang disenaraikan dalam dokumen ini. Komponen lain tidak disokong.

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/v1.0/workflow/processCentres/schemas |
| Kaedah HTTP | POST |
| Jenis aplikasi yang disokong | appType-Aplikasi dalaman　appType-Aplikasi perusahaan pihak ketiga |
| Kebenaran yang diperlukan | permission-Workflow.Form.Write-Kebenaran tulis templat aliran kerja |

### Pengepala permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Dapatkannya seperti berikut:   - Aplikasi dalaman: Panggil API untuk mendapatkan access token aplikasi dalaman. - Aplikasi perusahaan pihak ketiga: Panggil API untuk mendapatkan access token organisasi yang memberikan kebenaran kepada aplikasi pihak ketiga. |

### Isi permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| processCode | String | Tidak | ProcessCode borang. Nyatakannya apabila anda mengemas kini templat borang. Untuk mendapatkan nilai processCode, panggil API [Dapatkan kod templat](/ms/open/development/obtain-the-template-code).      Jika anda menghantar ProcessCode untuk mengubah suai dan mengemas kini komponen borang, anda tidak boleh memadam atau mengubah suai kawalan yang telah digunakan sebagai cabang bersyarat dalam reka bentuk aliran kerja. Contohnya, jika borang asal menggunakan kawalan pilihan tunggal [Jenis pekerja] sebagai syarat cabang, anda tidak boleh mengubah suai jenis kawalan medan [Jenis pekerja] atau memadamnya semasa mengemas kini borang ini.     - Biarkan parameter ini kosong untuk mencipta templat baharu. - Nyatakan parameter ini untuk mengemas kini templat kelulusan yang sepadan dengan nilai yang dihantar. |
| name | String | Ya | Nama templat borang. Panjang maksimum: 200 aksara. |
| description | String | Tidak | Penerangan templat borang. Panjang maksimum: 300 aksara. |
| formComponents | Array | Ya | Senarai kawalan borang. Kawalan yang disokong disenaraikan di bawah. Satu borang boleh mengandungi sehingga 200 komponen.  Untuk butiran tentang jenis kawalan yang disokong, lihat **Nota tambahan tentang parameter FormComponent** dalam dokumen ini.   - **TextField**: Input satu baris - **TextareaField**: Input berbilang baris - **NumberField**: Input nombor - **DDSelectField**: Pilihan tunggal - **DDMultiSelectField**: Pilih Banyak - **DDDateField**: Kawalan tarikh - **DDDateRangeField**: Kawalan julat masa - **TextNote**: Kawalan nota teks - **DDPhotoField**: Kawalan imej - **MoneyField**: Kawalan jumlah - **TableField**: Kawalan butiran (kawalan jadual) - **DDAttachment**: Lampiran - **InnerContactField**: Kawalan kenalan - **RelateField**: Borang kelulusan berkaitan - **AddressField**: Kawalan wilayah/bandar/daerah - **StarRatingField**: Kawalan penilaian - **DepartmentField**: Kawalan jabatan |
| FormComponent | FormComponent | Ya | Kawalan borang. Untuk kawalan yang disokong, lihat [Penerangan parameter FormComponent](/ms/open/development/oa-formcomponent-message). Satu borang boleh mengandungi sehingga 200 komponen. |
| processFeatureConfig | Object | Tidak | Konfigurasi integrasi Pusat Proses. |
| features | Array | Tidak | Senarai konfigurasi. |
| name | String | Tidak | Nama modul ciri yang boleh disesuaikan oleh pihak ketiga. Nilai yang disokong:   - **TASK_EXECUTE**: Modul pelaksanaan tugas, iaitu butang Terima dan Tolak pada halaman butiran - **SYNC_BOXSTER**: Cara tugas disegerakkan ke To-Do - **CUSTOM_SHORTCUT**: Butang tindakan pintasan dalam item To-Do dan notifikasi kad - **AFFILIATION_DIR**: Menentukan kumpulan perniagaan To-Do |
| pcUrl | String | Tidak | Pautan ubah hala tersuai pihak ketiga untuk PC. Panjang maksimum: 1,024 aksara. |
| mobileUrl | String | Tidak | Pautan ubah hala tersuai pihak ketiga untuk peranti mudah alih. Panjang maksimum: 1,024 aksara. |
| runType | String | Tidak | Mod larian. Apabila features.name ialah `TASK_EXECUTE`, nilai yang disokong:   - **ORIGIN**: Larian asli. Ciri ini berjalan dalam aplikasi Kelulusan rasmi dan mencetuskan API Callback yang dikonfigurasikan dalam callback. - **REDIRECT**: Larian ubah hala luaran. Ciri ini berjalan pada alamat pihak ketiga, dan pengguna diubah hala ke alamat yang dikonfigurasikan dalam pcUrl atau mobileUrl.   Apabila features.name ialah `SYNC_BOXSTER`, nilai yang disokong:   - **DEFAULT**: Menyegerakkan tugas kelulusan ke To-Do secara lalai. - **OUTBIZ_CUSTOM**: Tidak menyegerakkan ke To-Do. Pihak perniagaan melaksanakan pengendalian tersuai.   Apabila features.name ialah `CUSTOM_SHORTCUT`, nilai yang disokong:   - **ORIGIN**: Larian asli. Membuka halaman butiran To-Do akan mengubah hala ke halaman butiran aplikasi Kelulusan rasmi. - **REDIRECT**: Larian ubah hala luaran. Membuka halaman butiran To-Do akan mengubah hala ke alamat yang dikonfigurasikan dalam pcUrl atau mobileUrl.   Apabila features.name ialah `AFFILIATION_DIR`, nilai yang disokong:   - **OUTBIZ_CUSTOM**: Menentukan kumpulan To-Do. Pihak perniagaan menentukan kategori item To-Do. |
| callback | Object | Tidak | Konfigurasi Callback get laluan. Wajib apabila runType ialah ORIGIN.  Daftarkan semua API data luaran yang dipanggil semula oleh get laluan sebagai get laluan dalam "Pengurusan Sumber Data". Untuk butiran, lihat Cipta sumber data. |
| appUuid | String | Tidak | appUuid get laluan. Wajib apabila runType ialah ORIGIN.  Hantar ID organisasi (corpId) bagi organisasi yang mencipta sumber data. |
| apiKey | String | Tidak | apiKey get laluan. Wajib apabila runType ialah ORIGIN. Dapatkan `apiKey` daripada sumber data yang telah dicipta.       - Apabila get laluan memanggil API luaran, DingTalk mengembalikan parameter yang diperlukan untuk pemprosesan perniagaan, bergantung pada senario perniagaan. Untuk menghuraikan parameter ini selepas menerima permintaan Callback, ISV mesti mengkonfigurasikan kunci parameter yang sepadan semasa mencipta sumber data.   Contohnya, apabila Callback dikonfigurasikan untuk modul TASK_EXECUTE (butang Terima dan Tolak pada halaman butiran), DingTalk mengembalikan parameter tetap berikut: `&#123;"outResult":"agree","processInstanceId":"xxx","activityId":"xxx","corpId":"dingxxx","data":[],"remark":"Setuju","title":"Permohonan aset yang dihantar oleh xxx","taskId":111,"operator":"manager0001"&#125;`. - Semasa mencipta sumber data, ISV mesti mengkonfigurasikan kunci yang diperlukan untuk penghuraian berdasarkan keperluan perniagaan: outResult,processInstanceId,activityId,corpId,remark,title,taskId,operator |
| version | String | Tidak | Versi API get laluan.       - Wajib apabila runType ialah ORIGIN. - Lalai: 1. |
| config | String | Tidak | Konfigurasi modul ciri yang disesuaikan oleh pihak ketiga. |
| templateConfig | Object | Tidak | Konfigurasi templat Pusat Proses. |
| hidden | Boolean | Tidak | Sama ada templat disembunyikan:   - **true**: Templat tersembunyi - **false**: Bukan templat tersembunyi |
| createInstanceMobileUrl | String | Tidak | URL mudah alih untuk mencipta borang. Panjang maksimum: 1,024 aksara. |
| createInstancePcUrl | String | Tidak | URL PC untuk mencipta borang. Panjang maksimum: 1,024 aksara. |
| templateEditUrl | String | Tidak | URL penyuntingan templat. Panjang maksimum: 1,024 aksara. |
| disableSendCard | Boolean | Tidak | Sama ada untuk menyahaktifkan notifikasi kad mesej semasa mencipta tugas belum selesai dalam Pusat Proses:   - **true**: Dinyahaktifkan. Tiada notifikasi kad mesej dihantar. - **false**: Lalai. Tidak dinyahaktifkan. Notifikasi kad mesej dihantar. |
