---

Panggil API ini untuk mencipta pengguna Akaun Syarikat terbina DingTalk. API ini hanya tersedia untuk organisasi yang telah membeli dan mengaktifkan ciri ini.

## Permintaan

| **Maklumat asas** | |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/topapi/v2/user/create |
| Kaedah HTTP | POST |
| Jenis aplikasi disokong | appType-Aplikasi dalaman |
| Kebenaran diperlukan | permission-qyapi_manage_addresslist-Kebenaran pengurusan data Kenalan |

### Parameter pertanyaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | BE3xxxx | Kelayakan aplikasi yang digunakan untuk memanggil API ini. Dapatkan melalui API untuk mendapatkan [access_token aplikasi dalaman](/open/development/obtain-orgapp-token). |

### Isi permintaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| userid | String | Tidak | zhangsan | Pengecam unik Pekerja (tidak boleh diubah suai), panjang 1 hingga 64 aksara.  **Nota**   - Mesti unik dalam Organisasi Anda. - Jika tidak dinyatakan, userId akan dijana secara automatik. |
| exclusive_account | Boolean | Ya | true | Mesti ditetapkan kepada true, menunjukkan bahawa Akaun Syarikat akan dicipta.  **Nota**  Hanya terpakai untuk Akaun Syarikat. |
| exclusive_account_type | String | Ya | dingtalk | Mesti ditetapkan kepada dingtalk, menunjukkan Akaun Syarikat terbina DingTalk.  **Nota**  Hanya terpakai untuk Akaun Syarikat terbina DingTalk. |
| login_id | String | Ya | login_id3 | Nama log masuk bagi Akaun Syarikat terbina DingTalk.  **Nota**  Jangan sertakan maklumat seperti Nombor Telefon atau pautan e-mel untuk mengelakkan mesej SMS pendaftaran disekat oleh pembekal telekomunikasi. |
| init_password | String | Ya | init_password220 | Kata laluan awal bagi Akaun Syarikat terbina DingTalk. Kata laluan awal mesti mengandungi sekurang-kurangnya 8 aksara.  **Nota**   - Kata laluan tidak boleh terdiri sepenuhnya daripada huruf atau digit sahaja. - Jangan sertakan maklumat seperti Nombor Telefon, e-mel atau pautan untuk mengelakkan mesej SMS pendaftaran disekat oleh pembekal telekomunikasi. |
| send_password_to_user | Boolean | Tidak | false | Sama ada untuk menghantar kelayakan akaun. Nilai lalai: false.   - **false**: Jangan hantar. - **true**: Hantar.   **Nota**   - Apabila menghantar, mesej SMS dihantar ke Nombor Telefon Pekerja atau e-mel dihantar ke alamat e-mel peribadi. - Apabila parameter ini ditetapkan kepada **true**, parameter `init_password` diperlukan; jika tidak, tiada mesej akan dihantar. |
| name | String | Ya | Zhang San | Nama Pekerja, dengan panjang maksimum 80 aksara. |
| dept_id_list | String | Ya | "2,3,4" | Senarai ID jabatan yang menjadi Milik Pekerja tersebut. Pisahkan pelbagai ID jabatan dengan koma (`,`). Maksimum 100 ID jabatan boleh dihantar bagi setiap panggilan. |
| telephone | String | Tidak | 010-86123456-2345 | Nombor sambungan, dengan panjang maksimum 50 aksara.  **Nota**  Nombor sambungan mesti unik dalam Organisasi Anda. |
| job_number | String | Tidak | 4 | ID Pekerja, dengan panjang maksimum 50 aksara. |
| title | String | Tidak | Technical Director | Jawatan, dengan panjang maksimum 200 aksara. |
| email | String | Tidak | test@xxx.com | E-mel peribadi Pekerja, dengan panjang maksimum 50 aksara.  **Nota**  E-mel Pekerja mesti unik dalam Organisasi Anda. |
| org_email | String | Tidak | test@xxx.com | E-mel Syarikat Pekerja, dengan panjang maksimum 100 aksara.  **Nota**  Medan ini hanya berkuat kuasa apabila Pekerja telah mengaktifkan E-mel Syarikat. |
| org_email_type | String | Tidak | profession | Jenis E-mel Syarikat Pekerja:   - **profession:** Edisi Standard. - **base:** Edisi Basic. |
| work_place | String | Tidak | Future Park | Lokasi Kerja, dengan panjang maksimum 100 aksara. |
| remark | String | Tidak | Alias information | Alias, dengan panjang maksimum 2,000 aksara. |
| dept_order_list | Object[] | Tidak |  | Susunan Pekerja dalam setiap jabatan. |
| dept_id | Number | Tidak | 2 | ID jabatan. |
| order | Number | Tidak | 1 | Susunan Pekerja dalam jabatan. Nilai yang lebih besar menunjukkan kedudukan yang lebih tinggi. |
| dept_title_list | Object[] | Tidak |  | Jawatan Pekerja dalam setiap jabatan. |
| dept_id | Number | Tidak | 2 | ID jabatan. |
| title | String | Tidak | Senior Product Manager | Jawatan Pekerja dalam jabatan tersebut. |
| extension | String | Tidak | `{"Hobby":"Travel","Age":"24"}` | Atribut lanjutan. Pelbagai Atribut boleh ditetapkan, dengan panjang maksimum 2,000 aksara. **Nota**   - Maksimum 10 Atribut lanjutan boleh dipaparkan pada peranti mudah alih. - Sebelum menggunakan parameter ini, tambah Atribut tersebut dalam [Admin Console DingTalk](https://oa.dingtalk.io/index_new.htm#/setting/contactInfo) terlebih dahulu, kemudian panggil API untuk menetapkan nilai. - Nilai medan ini menyokong jenis pautan. Pautan menyokong kad bebas (wildcard) pemboleh ubah yang digantikan secara automatik. Kad bebas yang disokong pada masa ini ialah userid dan corpid. Contoh: `{"Hobby":"[Hobby](http://www.dingtalk.io?userid=#userid#&corpid=#corpid#)"}`. |
| senior_mode | Boolean | Tidak | false | Sama ada untuk mengaktifkan mod eksekutif. Nilai lalai: false.   - **true**: Aktifkan.  **Nota**    - Apabila diaktifkan, Nombor Telefon disembunyikan daripada semua Pekerja.   - Pekerja biasa tidak boleh menghantar DING atau memulakan panggilan perniagaan DingTalk kepada eksekutif.   - Eksekutif boleh saling menghantar DING dan memulakan panggilan perniagaan DingTalk antara satu sama lain. - **false**: Jangan aktifkan. |
| hired_date | Number | Tidak | 1597573616828 | Tarikh diambil bekerja, dalam format Unix timestamp (dalam milisaat). |
| manager_userid | String | Tidak | 001 | userId bagi penyelia terus. |
| exclusive_mobile | String | Tidak | +86-13412341234 | Nombor Telefon bagi Akaun Syarikat.  **Nota**  Hanya terpakai untuk Akaun Syarikat. |
| avatarMediaId | String | Tidak | @lALPDfmVUw19YdrNA-jNA-g | Semasa mencipta Akaun Syarikat untuk Organisasi Anda, anda boleh menyatakan MediaId Gambar Profil. Hanya format jpg dan png disokong.  Dapatkan dengan memanggil API [Muat naik fail media](/open/development/upload-media-files).  **Nota**  Hanya terpakai untuk Akaun Syarikat. |
| nickname | String | Tidak | Name | Semasa mencipta Akaun Syarikat untuk Organisasi Anda, anda boleh menyatakan Nama.  **Nota**  Hanya terpakai untuk Akaun Syarikat. |

## Respons

### Isi respons

| Nama | Jenis | Contoh | Penerangan |
| --- | --- | --- | --- |
| errcode | Number | 0 | Kod ralat. 0 menunjukkan kejayaan. |
| errmsg | String | ok | Mesej ralat. |
| result | Object |  | Hasil yang dikembalikan. |
| userid | String | zhangsan | ID Pekerja. |
| unionId | String | xxxx | ID unik Pekerja. |

### Contoh isi respons

```json
{
  "errcode":"0",
  "result":{
    "unionId":"xxxx",
    "userid":"zhangsan"
  },
  "errmsg":"ok"
}
```

### Kod ralat

Jika ralat dikembalikan semasa memanggil API ini, rujuk dokumen [Kod ralat global](/open/development/server-api-error-codes-1) untuk mencari penyelesaian berdasarkan Mesej ralat.
