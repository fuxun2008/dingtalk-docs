Panggil API ini untuk menetapkan skop pengurusan ahli peranan.

## Permintaan

| **Maklumat asas** | |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/topapi/role/scope/update |
| Kaedah HTTP | POST |
| Jenis aplikasi disokong | appType-Aplikasi dalaman |
| Kebenaran diperlukan | permission-qyapi_manage_addresslist-Kebenaran pengurusan data Kenalan |

### Parameter query

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | Be3xxxx | Kelayakan aplikasi untuk memanggil API ini. Dapatkan melalui API untuk mendapatkan [access_token aplikasi dalaman](/open/development/obtain-orgapp-token). |

### Isi permintaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| userid | String | Ya | EMP123 | ID pengguna pekerja dalam organisasi. |
| role_id | Nombor | Ya | 12345 | ID peranan. Panggil API [Dapatkan senarai peranan organisasi](/open/development/obtains-a-list-of-enterprise-roles) untuk mendapatkan nilai parameter id. |
| dept_ids | String | Tidak | 1231 | Senarai ID jabatan. Pisahkan pelbagai ID jabatan dengan koma. Maksimum 50 ID jabatan disokong. Jika dibiarkan kosong, skop ditetapkan kepada semua pengguna. |

### Contoh permintaan

```curl
curl -X POST "https://api.dingtalk.io/topapi/role/scope/update" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=3100xxxx2280f5' \
-d 'dept_ids=1231' \
-d 'role_id=12345' \
-d 'userid=EMP123'
```

Java

```text
DingTalkClient client = new DefaultDingTalkClient("https://api.dingtalk.io/topapi/role/scope/update");
OapiRoleScopeUpdateRequest req = new OapiRoleScopeUpdateRequest();
req.setUserid("EMP123");
req.setRoleId(12345L);
req.setDeptIds("1231,2423");
OapiRoleScopeUpdateResponse rsp = client.execute(req, access_token);
System.out.println(rsp.getBody());
```

Python

```python

req=dingtalk.api.OapiRoleScopeUpdateRequest("https://api.dingtalk.io/topapi/role/scope/update")

```

## Respons

### Isi respons

| Nama | Jenis | Contoh | Penerangan |
| --- | --- | --- | --- |
| errcode | Nombor | 0 | Kod pemulangan. |
| errmsg | String | ok | Penerangan kod pemulangan. |
| request_id | String | 4pe0h4hlsit9 | ID permintaan. |

### Contoh isi respons

```json
{
  "errcode":"0",
  "errmsg":"ok",
  "request_id":"4pe0h4hlsit9"
}
```

### Kod ralat

Jika ralat dikembalikan semasa memanggil API ini, cari penyelesaian dalam dokumen [Kod ralat global](/open/development/server-api-error-codes-1) berdasarkan mesej ralat.

| Kod ralat (errcode) | Penerangan kod ralat (errmsg) | Penyelesaian |
| --- | --- | --- |
| 40003 | Invalid userId | Sahkan bahawa userId adalah betul. |
| 34018 | role_id cannot be empty | Berikan roleId. |
| 60301 | Invalid role_id | Sahkan bahawa role_id adalah betul. |
| 60003 | Department does not exist | Sahkan bahawa dept_ids adalah betul. |
| 46004 | Employee is not in the organization | Sahkan bahawa parameter adalah betul. |
| 400002 | Invalid parameter | Sahkan bahawa parameter permintaan adalah betul. |
| -1 | System busy | Cuba Lagi kemudian. |
