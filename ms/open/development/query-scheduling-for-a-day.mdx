Panggil API ini untuk menanya maklumat penjadualan syif pengguna pada hari tertentu.

## Permintaan

| **Maklumat Asas** | |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/topapi/attendance/schedule/listbyday |
| Kaedah HTTP | POST |
| Jenis aplikasi yang disokong | Aplikasi dalaman, Aplikasi perusahaan pihak ketiga |
| Kebenaran | qyapi_attendance_group_read (kebenaran baca kumpulan kehadiran) |

### Parameter pertanyaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | bE74xxxx | Kelayakan aplikasi yang digunakan untuk memanggil API ini.   - Aplikasi dalaman: Dapatkan dengan memanggil [Dapatkan access_token Aplikasi dalaman](/ms/open/development/obtain-orgapp-token). - Aplikasi perusahaan pihak ketiga: Dapatkan dengan memanggil Dapatkan access_token Aplikasi perusahaan pihak ketiga. |

### Isi permintaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| op_user_id | String | Ya | manager123 | userId pengendali. |
| user_id | String | Ya | dd_dd | userId pengguna yang hendak ditanya. |
| date_time | Number | Ya | 1564145519000 | Tarikh yang hendak ditanya, dalam bentuk Unix timestamp dalam milisaat. |

### Contoh permintaan

```curl
curl -X POST "https://api.dingtalk.io/topapi/attendance/schedule/listbyday" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=5d7f91f3-e22c-41ca-aee3-aa008603e00b' \
-d 'date_time=1564145519000' \
-d 'op_user_id=dd_dd' \
-d 'user_id=dd_dd'
```

## Respons

### Isi respons

| Nama | Jenis | Contoh | Penerangan |
| --- | --- | --- | --- |
| result | TopScheduleVo[] |  | Hasil pertanyaan. |
| check_type | String | OnDuty | Jenis kehadiran:   - **Onduty**: Daftar masuk untuk mula kerja - **OffDuty**: Daftar masuk untuk tamat kerja |
| approve_type | String | demo | Jenis kelulusan.  **Nota**  Medan ini tidak dikembalikan jika tiada borang kelulusan pada hari tersebut. |
| gmt_modified | Date | 2020-11-10 14:33:13 | Masa pengubahsuaian terakhir. |
| gmt_create | Date | 2020-10-26 03:26:59 | Masa dicipta. |
| corp_id | String | dinge8xxxx | ID organisasi (corpId). Lihat ID ini di Laman Utama [Konsol Pembangun](https://open-dev.dingtalk.io/). |
| check_date_time | Date | 2020-11-10 14:33:13 | Masa daftar masuk pekerja. |
| group_id | Number | 394775001 | ID kumpulan kehadiran. |
| class_name | String | dsdsd | Nama syif. |
| user_id | String | dd_test | userId pengguna. |
| approve_biz_type | Number | demo | Jenis kelulusan cuti dan kehadiran yang terikat pada penjadualan syif:   - **1**: Kerja lebih masa - **2**: Perjalanan perniagaan - **3**: Cuti   **Nota**  Medan ini tidak dikembalikan jika tiada borang kelulusan pada hari tersebut. |
| approve_id | Number | 123 | ID borang kelulusan yang terikat pada penjadualan syif.  **Nota**  Medan ini tidak dikembalikan jika tiada borang kelulusan pada hari tersebut. |
| class_setting_id | Number | 297490031 | ID tetapan syif yang dikaitkan dengan penjadualan syif.  **Nota**  Medan ini tidak dikembalikan jika tetapan global digunakan. |
| approve_tag_name | String | Cuti | Nama borang kelulusan cuti dan kehadiran yang terikat pada penjadualan syif.  **Nota**  Medan ini tidak dikembalikan jika tiada borang kelulusan pada hari tersebut. |
| features | String | `{\"dataSource\":\"adminSetting\",\"flexMinutes\":[60,60],\"overtimeSettingId\":221375127,\"punchId\":524588947}` | Medan lanjutan.   - **dataSource**: Medan ini tidak mempunyai makna praktikal buat masa ini. - **flexMinutes**: Masa fleksibel yang dibenarkan oleh tetapan syif untuk datang lewat dan pulang lewat, atau datang awal dan pulang awal, dalam minit. - **punchId**: ID titik daftar masuk yang sepadan. - **overtimeSettingId**: ID peraturan kerja lebih masa. |
| class_id | Number | 370370019 | ID syif. |
| check_status | String | Timeout | Status daftar masuk:   - **Init**: Belum daftar masuk - **Checked**: Telah daftar masuk - **Timeout**: Daftar masuk terlepas |
| work_date | Date | 2020-11-10 00:00:00 | Hari bekerja, iaitu hari khusus bagi penjadualan syif. |
| check_end_time | Date | 2020-09-08 09:30:00 | Masa tamat tetingkap daftar masuk. |
| is_rest | String | N | Sama ada hari tersebut ialah hari rehat:   - **Y**: Dijadualkan sebagai hari rehat - **N**: Bukan hari rehat |
| check_begin_time | Date | 2020-09-08 09:00:00 | Masa mula tetingkap daftar masuk. |
| real_plan_time | Date | 2020-09-08 10:00:00 | Masa pengguna sepatutnya mendaftar masuk selepas pelarasan waktu kerja fleksibel diaktifkan untuk titik daftar masuk. |
| id | Number | 56676915454 | ID penjadualan syif. |
| success | Boolean | true | Menunjukkan sama ada permintaan berjaya.   - **true**: Berjaya - **false**: Gagal |
| errcode | Number | 0 | Kod pemulangan. |
| errmsg | String | demo | Penerangan kod pemulangan. |
| request_id | String | 6bzhf2vn89pv | ID permintaan. |
