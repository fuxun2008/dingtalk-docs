# Dapatkan senarai ID subjabatan

## Penerangan panggilan API

- API ini tidak dihadkan oleh skop kebenaran.
- API ini hanya menyokong pendapatan senarai ID bagi jabatan pada peringkat seterusnya sahaja.

Sebagai contoh, jika anda memanggil API ini untuk mendapatkan senarai ID subjabatan bagi Jabatan root, hasilnya ialah [123,666]. Subjabatan di bawah Jabatan 1 dan Jabatan 2 tidak boleh diperoleh.

## Permintaan

| **Maklumat asas** | |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/topapi/v2/department/listsubid |
| Kaedah HTTP | POST |
| Jenis aplikasi yang disokong | appType-Aplikasi dalaman, appType-Aplikasi perusahaan pihak ketiga |
| Kebenaran | permission-qyapi_get_department_list-Kebenaran Telah dibaca untuk maklumat jabatan Kenalan |

### Parameter pertanyaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | bE74xxxx | Kelayakan aplikasi yang digunakan untuk memanggil API ini.   - Bagi aplikasi dalaman, dapatkannya melalui API untuk mendapatkan [access_token aplikasi dalaman](/ms/open/development/obtain-orgapp-token). - Bagi aplikasi perusahaan pihak ketiga, dapatkannya melalui API untuk mendapatkan access_token perusahaan pihak ketiga. |

### Isi permintaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| dept_id | Number | Ya | 1 | ID Jabatan induk. Masukkan 1 untuk Jabatan root. Untuk mendapatkan nilai dept_id, panggil API [Dapatkan senarai jabatan](/ms/open/development/user-management-acquires-the-list-departments). |

### Contoh permintaan

```curl
curl -X POST "https://api.dingtalk.io/topapi/v2/department/listsubid" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=0dcxxxx108dcd028' \
-d 'dept_id=100'
```

Java

```text
DingTalkClient client = new DefaultDingTalkClient("https://api.dingtalk.io/topapi/v2/department/listsubid");
OapiV2DepartmentListsubidRequest req = new OapiV2DepartmentListsubidRequest();
req.setDeptId(100L);
OapiV2DepartmentListsubidResponse rsp = client.execute(req, access_token);
System.out.println(rsp.getBody());
```

Python

```python
import dingtalk.api

req=dingtalk.api.OapiV2DepartmentListsubidRequest("https://api.dingtalk.io/topapi/v2/department/listsubid")

  resp= req.getResponse(access_token)

  print(e)
```


## Respons

### Isi respons

| Nama | Jenis | Contoh | Penerangan |
| --- | --- | --- | --- |
| request_id | String | 48vhxdnwhve6 | ID permintaan. |
| errcode | Number | 0 | Kod pemulangan. |
| errmsg | String | Invalid department ID | Mesej ralat yang dikembalikan apabila panggilan gagal. |
| result | DeptListSubIdResponse |  | Hasil yang dikembalikan. |
| dept_id_list | Number[] | [2,3,4,5] | Senarai subjabatan. |

### Kod ralat

Jika berlaku ralat semasa memanggil API ini, rujuk dokumen [Kod ralat global](/ms/open/development/server-api-error-codes-1) untuk mencari penyelesaian berdasarkan mesej ralat.

| Kod ralat (errcode) | Mesej ralat (errmsg) | Penyelesaian |
| --- | --- | --- |
| 60003 | The corresponding department is not found | Sahkan bahawa dept_id adalah betul. |
| 400002 | Invalid parameter | Sahkan bahawa parameter dimasukkan seperti yang diperlukan. |
| -1 | System busy | Cuba Lagi kemudian. |
