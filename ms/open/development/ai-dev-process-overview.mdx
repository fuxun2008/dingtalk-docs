## Gambaran keseluruhan proses pembangunan untuk aplikasi AI pihak ketiga

### **Prasyarat**

1. Anda telah melengkapkan pendaftaran sebagai penyedia penyelesaian produk.
2. Anda telah mendapatkan kebenaran pembangun. Untuk maklumat lanjut, lihat Dapatkan Kebenaran Pembangun.

### **Had Penggunaan**

Platform pembangunan aplikasi AI kini berada dalam fasa ujian jemputan sahaja. Anda hanya boleh membangunkan aplikasi AI dan mencubanya melalui organisasi ujian, tetapi tidak boleh menerbitkannya secara terus. Untuk menerbitkan aplikasi AI, anda perlu membangunkan bersama aplikasi mini program atau aplikasi web. Untuk maklumat lanjut, lihat (Pilihan) Uji App dan Uji Sendiri App.

### **Gambaran keseluruhan proses**

1. [Cipta App](/ms/open/dingstart/create-application)
2. Tambah Keupayaan Aplikasi AI
3. (Pilihan) Tambah Pembangun
4. Bangunkan App

   1. Bina Keupayaan AI
   2. Konfigurasikan App Magic Wand
   3. Konfigurasikan Tabler
5. Terbitkan Aplikasi AI

   1. Pantau App
   2. Lancarkan App
   3. [Terbitkan Aplikasi AI](/zh/open/development/publish-application)
   4. Konfigurasikan Tabler
   5. Uji Sendiri App
