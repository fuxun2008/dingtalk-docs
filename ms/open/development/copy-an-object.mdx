Panggil API ini untuk menyalin fail atau folder ke ruang atau folder lain.

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/storage/spaces/{spaceId}/dentries/{dentryId}/copy` |
| Kaedah HTTP | POST |
| Jenis aplikasi disokong | appType-Aplikasi dalaman　appType-Aplikasi perusahaan pihak ketiga |
| Kebenaran | permission-Storage.File.Write-Kebenaran tulis fail storan organisasi |

### Pengepala permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Dapatkan dengan cara berikut:   - Untuk aplikasi dalaman, panggil API [Dapatkan access token aplikasi dalaman](/ms/open/development/obtain-the-access-token-of-an-internal-app). - Untuk aplikasi perusahaan pihak ketiga, panggil API [Dapatkan access token organisasi yang diberi kuasa untuk aplikasi pihak ketiga](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1). |

### Parameter laluan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| spaceId | String | Ya | ID ruang sumber tempat fail atau folder berada. Panggil API [Tambah ruang](/ms/open/development/add-space) untuk mendapatkan nilai parameter id. |
| dentryId | String | Ya | ID fail atau folder yang akan disalin. Panggil API [Dapatkan senarai fail atau folder](/ms/open/development/get-a-list-of-files-or-folders) atau API [Dapatkan spaceId dan dentryId mengikut dentryUuid](/ms/open/development/api-getdentryidbyuuid) untuk mendapatkan nilai parameter id. |

### Parameter pertanyaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| unionId | String | Ya | unionId pengendali. Panggil API [Tanya butiran pengguna](/ms/open/development/query-user-details) untuk mendapatkan nilai parameter unionid. |

### Isi permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| targetSpaceId | String | Ya | ID ruang sasaran. Panggil API [Tambah ruang](/ms/open/development/add-space) untuk mendapatkan nilai parameter id. |
| targetFolderId | String | Ya | ID folder induk di lokasi sasaran. Panggil API [Dapatkan senarai fail atau folder](/ms/open/development/get-a-list-of-files-or-folders) untuk mendapatkan nilai parameter id. |
| option | Object | Tidak | Parameter pilihan. |
| conflictStrategy | String | Tidak | Strategi konflik penamaan untuk fail dan folder:   - **AUTO_RENAME** (lalai): Namakan semula secara automatik. - **OVERWRITE**: Tulis ganti. - **RETURN_DENTRY_IF_EXISTS**: Kembalikan fail sedia ada. - **RETURN_ERROR_IF_EXISTS**: Kembalikan ralat jika fail sudah wujud. |
