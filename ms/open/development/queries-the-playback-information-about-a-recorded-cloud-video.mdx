Panggil API ini untuk menanya maklumat video rakaman mesyuarat, termasuk URL muat turun video, saiz fail video, dan tempoh video.

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/conference/videoConferences/{conferenceId}/cloudRecords/videos/getPlayInfos` |
| Kaedah HTTP | GET |
| Jenis aplikasi yang disokong | appType-Aplikasi dalaman　appType-Aplikasi perusahaan pihak ketiga |
| Kebenaran yang diperlukan | permission-VideoConference.Conference.Read-Kebenaran baca maklumat Mesyuarat Video |

### Header permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses yang digunakan untuk memanggil API ini. Dapatkan seperti berikut:   - Untuk aplikasi dalaman, panggil API [Dapatkan access token aplikasi dalaman](/open/development/obtain-the-access-token-of-an-internal-app#). - Untuk aplikasi perusahaan pihak ketiga, panggil API [Dapatkan access token perusahaan yang diberi kuasa kepada aplikasi pihak ketiga](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#). |

### Parameter laluan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| conferenceId | String | Ya | ID mesyuarat. Panggil API [Cipta mesyuarat video](/open/development/create-a-video-conference#) untuk mendapatkan nilai parameter conferenceId. |

### Parameter kueri

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| unionId | String | Ya | unionId pengguna. Panggil API [Tanya butiran pengguna](/open/development/query-user-details#) untuk mendapatkan nilai parameter unionid. |
| mediaId | String | Ya | ID fail media. Panggil API [Tanya butiran rakaman mesyuarat](/open/development/query-recording-information#) untuk mendapatkan nilai parameter mediaId. |
| regionId | String | Ya | ID wilayah. Panggil API [Tanya butiran rakaman mesyuarat](/open/development/query-recording-information#) untuk mendapatkan nilai parameter regionId. |
