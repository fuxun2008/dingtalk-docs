Topik ini menerangkan cara pautan mesej dibuka.

## Buka pautan mesej dalam bar sisi PC atau pelayar luaran

Apabila pengguna mengklik URL dalam mesej pada klien PC, gunakan format berikut untuk mengawal cara pautan dibuka:

```text
dingtalk://dingtalkclient/page/link?url=http%3A%2F%2Fwww.dingtalk.io&pc_slide=true
```

### Parameter

| **Parameter** | Penerangan |
| --- | --- |
| url | Pautan yang hendak dibuka. Nilai mesti dikodkan URL. |
| pc_slide | - true: Buka pautan dalam bar sisi klien PC. - false: Buka pautan dalam pelayar. |

## Pautan mini program

Sesebuah mini program boleh menghantar mesej yang, apabila diklik, mengalihkan pengguna ke mini program tersebut. Senario yang disokong adalah seperti berikut:

| Jenis aplikasi | Mesej Notifikasi Kerja | Mesej kumpulan Organisasi | Mesej teks biasa |
| --- | --- | --- | --- |
| Aplikasi dalaman | Disokong | Tidak disokong | Tidak disokong |
| Aplikasi perusahaan pihak ketiga | Disokong | Tidak disokong | Tidak disokong |
| Aplikasi peribadi pihak ketiga | — | — | Disokong |

Format pautan yang digunakan untuk mengalihkan ke mini program adalah seperti berikut:

```text
 eapp://page?query
```

Contoh: eapp://pages/index/index?param1=aa&param2=bb

### Parameter

- Format pautan ini hanya disokong apabila mesej dihantar oleh mini program. Ia tidak disokong apabila mesej dihantar oleh aplikasi mikro.
- Untuk memastikan pengalihan berfungsi seperti yang dijangkakan, terbitkan mini program sasaran ke persekitaran produksi.
- `page` menunjukkan laluan halaman mini program, seperti `pages/index/index`. Laluan ini mesti ditakrifkan di bawah `pages` dalam fail konfigurasi `app.json`.

### Nota

  Untuk memastikan pengalihan berfungsi seperti yang dijangkakan, terbitkan mini program sasaran ke persekitaran produksi.

- `query` menunjukkan parameter pertanyaan yang dihantar kepada kaedah `onLoad` bagi halaman tersebut. Contohnya, `param1=aa&param2=bb`. Jika nilai parameter mengandungi aksara khas, kodkan URL nilai tersebut.
