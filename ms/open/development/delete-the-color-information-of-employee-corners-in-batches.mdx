Panggil API ini untuk mengalih keluar peranan daripada berbilang pekerja secara pukal.

## Permintaan

| **Maklumat asas** | |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/topapi/role/removerolesforemps |
| Kaedah HTTP | POST |
| Jenis aplikasi yang disokong | appType-Aplikasi dalaman |
| Kebenaran diperlukan | permission-qyapi_manage_addresslist-Kebenaran pengurusan data Kenalan |

### Parameter pertanyaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | 6ed1bxxx | Kelayakan aplikasi yang digunakan untuk memanggil API ini. Dapatkan melalui API untuk mendapatkan [access_token bagi aplikasi dalaman](/ms/open/development/obtain-orgapp-token). |

### Isi permintaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| roleIds | String | Ya | 1507113578 | Senarai roleIds peranan. Panggil API [Dapatkan senarai peranan](/ms/open/development/obtains-a-list-of-enterprise-roles) untuk mendapatkannya.  Panjang senarai maksimum ialah 20. Pisahkan berbilang roleIds dengan koma (,). |
| userIds | String | Ya | user100 | ID pengguna Pekerja. Panggil [Tanya pengguna mengikut Nombor Telefon](/ms/open/development/query-users-by-phone-number) untuk mendapatkan userId.  Panjang senarai maksimum ialah 100. Pisahkan berbilang userIds dengan koma (,). |

### Contoh permintaan

```curl
curl -X POST "https://api.dingtalk.io/topapi/role/removerolesforemps" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=e56eb45d-4b5a-4284-bdcf-cbc5284e188a' \
-d 'roleIds=1507113578' \
-d 'userIds=user100'
```

## Respons

### Isi respons

| Nama | Jenis | Contoh | Penerangan |
| --- | --- | --- | --- |
| errcode | Number | 0 | Kod pemulangan. |
| errmsg | String | ok | Penerangan kod pemulangan. |
| request_id | String | 10c1rigbngrp5 | ID permintaan. |

### Contoh isi respons

```json
{
  "errcode":0,
  "request_id":"10c1rigbngrp5"
}
```

### Kod ralat

Jika ralat dikembalikan semasa anda memanggil API ini, cari penyelesaian dalam dokumen [Kod ralat global](/ms/open/development/server-api-error-codes-1) berdasarkan mesej ralat.

| Kod ralat (errcode) | Mesej ralat (errmsg) | Penyelesaian |
| --- | --- | --- |
| 33011 | Invalid roleIds | Semak sama ada roleIds adalah betul. |
| 33012 | Invalid userId | Semak sama ada userId adalah betul. |
| -1 | System busy | Cuba Lagi kemudian. |
