## Alat Swalayan

Jika anda menghadapi masalah semasa pembangunan, kami mengesyorkan anda membaca dokumentasi berkaitan terlebih dahulu atau menggunakan alat swalayan untuk menyahpepijat dan mengesan API yang perlu disahkan.

- Alat Nyahpepijat Server API
- Alat Nyahpepijat Pembangunan Mini Program
- Alat Nyahpepijat Frontend Aplikasi Mikro

## Sokongan Teknikal

**Untuk memberikan anda kualiti perkhidmatan yang lebih baik dan mengurangkan masa menunggu, kami mengesyorkan anda cuba menyelesaikan isu menggunakan alat swalayan terlebih dahulu. Jika isu masih berterusan, anda boleh mendapatkan bantuan melalui saluran berikut.**

1. Log masuk ke [Developer Console](https://open-dev.dingtalk.com).
2. Klik **Tabler** di penjuru bawah kanan.

3. Selepas mengklik Tabler, anda boleh menaip soalan anda dalam kotak input untuk mendapatkan bantuan. Jika jawapan Tabler tidak menyelesaikan isu anda, klik Ticket Center di bawah untuk menghantar tiket.

4. Hantar tiket.

   **Nota**
   1. Semasa menghantar tiket perkhidmatan, jika anda menghadapi isu panggilan API, sertakan CorpID organisasi, dokumentasi API, requestID, dan butiran ralat lain.
   2. Selepas anda menghantar tiket perkhidmatan, sistem akan mencipta sembang kumpulan secara automatik dan menugaskan sokongan teknikal (dalam waktu perniagaan). Klik Sertai Sembang dalam senarai tiket untuk menyertai sembang kumpulan dan berkomunikasi.
   3. Untuk menambah pengguna lain ke dalam sembang kumpulan, lakukan sendiri. Laluan: Tindakan Pantas Sembang Tiket > Butiran Tiket > Butang Tambah Orang (hanya pengguna dalam organisasi yang sama disokong).

   Selepas memasuki halaman, anda boleh melihat dan menguruskan isu yang telah anda hantar.

## **Gambaran Keseluruhan Sistem Tiket**

Sistem tiket telah menaik taraf komponen perkhidmatan sokongannya untuk memudahkan rekod dan tindakan susulan isu, dalam usaha memberikan pembangun pengalaman perkhidmatan yang lebih baik.

- **Ticket Center: Menghimpunkan semua tiket di bawah organisasi semasa, supaya kemajuan pengendalian jelas dilihat sekali pandang.**

- **Ticket Chat: Dalam waktu perniagaan (09:00 hingga 18:00 pada hari bekerja), sembang tiket DingTalk khusus akan dicipta dalam masa sejam untuk setiap isu yang dihantar. Klik butang "Sertai Sembang" dalam senarai tiket untuk berkomunikasi secara lancar dengan kakitangan perkhidmatan melalui sembang kumpulan. Ini mengurangkan langkah komunikasi dan menjadikan pengendalian isu lebih cekap.**

- **Service Timeline: Setiap proses pengendalian isu direkodkan pada garis masa, dan semua sejarah sembang sepanjang proses tersebut disimpan, menjadikan keseluruhan kitaran hayat pengendalian isu jelas dan telus.**

- **Pengesahan dan Penilaian: Selepas kakitangan perkhidmatan memberikan penyelesaian, kad tiket-selesai akan dihantar ke sembang kumpulan. Jika anda mengesahkan penyelesaian tersebut berkesan, klik **Diselesaikan**; jika anda tidak menerima penyelesaian tersebut buat masa ini, klik **Belum Diselesaikan**, dan kakitangan perkhidmatan akan terus membuat tindakan susulan sehingga isu diselesaikan.**

- **Selepas isu diselesaikan, anda boleh menilai perkhidmatan yang diberikan oleh kakitangan perkhidmatan.**

## Nota

**Untuk membantu kami mengesan dan menyelesaikan isu dengan pantas, kami mengesyorkan anda memberikan maklumat pembangunan berikut semasa menghantar maklum balas, termasuk tetapi tidak terhad kepada:**

- Jenis aplikasi atau senario yang sedang anda bangunkan

  - Aplikasi dalaman
  - Aplikasi perusahaan pihak ketiga
  - Aplikasi peribadi pihak ketiga
  - Pembangunan Workbench
  - Keupayaan terbuka sembang, dan lain-lain
- Penerangan terperinci tentang isu dan tangkapan skrin berkaitan
- Nama syarikat dan CorpId
- Untuk isu panggilan Server API, sertakan yang berikut:

  - URL API yang diminta
  - Butiran parameter
  - Hasil sebenar yang dikembalikan
  - Hasil dijangka yang dikembalikan
- Untuk isu panggilan API frontend, sertakan yang berikut:

  - Model telefon
  - Sistem pengendalian telefon
  - Versi DingTalk yang digunakan
  - Parameter panggilan API
  - Hasil sebenar yang dikembalikan
  - Hasil dijangka yang dikembalikan
