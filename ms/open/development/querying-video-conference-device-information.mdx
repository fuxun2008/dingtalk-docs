Panggil API ini untuk menanyakan maklumat peranti mesyuarat video.

## Penerangan panggilan API

Sebelum memanggil API ini, langgan peristiwa [Perubahan pengikatan peranti-bilik](https://open.dingtalk.com/document/development/org-event-overview#) melalui [Langganan peristiwa](https://open.dingtalk.com/document/development/event-subscription-overview#).

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/v1.0/rooms/devices |
| Kaedah HTTP | GET |
| Jenis aplikasi disokong | appType-Aplikasi dalaman |
| Kebenaran | permission-VideoConference.Conference.Read-Kebenaran membaca maklumat mesyuarat video |

### Header permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Untuk mendapatkan nilai ini, panggil API [Dapatkan access token aplikasi dalaman](/ms/open/development/obtain-the-access-token-of-an-internal-app#). |

### Parameter pertanyaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| operatorUnionId | String | Ya | unionId operator yang melakukan pertanyaan. Untuk mendapatkan nilai ini, panggil API [Menanyakan butiran pengguna](/ms/open/development/query-user-details#). |
| deviceId | String | Tidak | ID peranti yang hendak ditanya. Dapatkan nilai ini dengan melanggan peristiwa [Perubahan pengikatan peranti-bilik](https://open.dingtalk.com/document/development/org-event-overview#).  Nyatakan sama ada `deviceId` atau `deviceUnionId`. |
| deviceUnionId | String | Tidak | unionId peranti yang hendak ditanya. Dapatkan nilai ini dengan melanggan peristiwa [Perubahan pengikatan peranti-bilik](https://open.dingtalk.com/document/development/org-event-overview#).  Nyatakan sama ada `deviceId` atau `deviceUnionId`. |

### Contoh permintaan

HTTP

```http
GET /v1.0/rooms/devices?operatorUnionId=lmvxxxxx&deviceId=1234&deviceUnionId=lmvUxxxxx HTTP/1.1
Host:api.dingtalk.io
x-acs-dingtalk-access-token:xxxxx
Content-Type:application/json
```

### Kod ralat

Jika ralat berlaku semasa memanggil API ini, cari penyelesaian mengikut mesej ralat dalam dokumen [Kod ralat global](/ms/open/development/server-api-error-codes-1).

| HttpCode | Kod ralat | Mesej ralat | Penerangan |
| --- | --- | --- | --- |
| 400 | device.not.found | device not found | Peranti tidak wujud. |
| 400 | param.error | param error | Parameter operatorUnionId kosong. |
| 403 | no.permission | no permission | Tiada kebenaran pertanyaan. |
| 500 | system.error | system error | Ralat sistem. |
