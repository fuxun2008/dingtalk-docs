Panggil API ini untuk mengemas kini maklumat kumpulan bilik, termasuk nama kumpulan dan ID kumpulan induk.

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/v1.0/rooms/groups |
| Kaedah HTTP | PUT |
| Jenis aplikasi yang disokong | appType-Aplikasi dalaman　appType-Aplikasi perusahaan pihak ketiga |
| Kebenaran yang diperlukan | permission-VideoConference.Conference.Write-Kebenaran pengurusan maklumat Mesyuarat Video |

### Header permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Dapatkan seperti berikut:   - Untuk aplikasi dalaman, panggil API [Dapatkan access token aplikasi dalaman](/open/development/obtain-the-access-token-of-an-internal-app#). - Untuk aplikasi perusahaan pihak ketiga, panggil API [Dapatkan access token organisasi yang memberi kebenaran kepada aplikasi pihak ketiga](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#). |

### Isi permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| unionId | String | Ya | unionId bagi pengendali. Panggil API [Tanya butiran pengguna](/open/development/query-user-details#) untuk mendapatkannya. |
| groupName | String | Tidak | Nama kumpulan yang dikemas kini. |
| groupId | Long | Ya | ID kumpulan. Panggil API [Tanya senarai kumpulan bilik](/open/development/query-meeting-rooms-groups#) untuk mendapatkannya. |

### Contoh permintaan

HTTP

```http
PUT /v1.0/rooms/groups HTTP/1.1
Host:api.dingtalk.io
x-acs-dingtalk-access-token:xxxxx
Content-Type:application/json

{
  "unionId" : "2iPOxxxxx",
  "groupName" : "Kumpulan Ujian",
  "groupId" : 172
}
```

## Respons

### Isi respons

| Nama | Jenis | Penerangan |
| --- | --- | --- |
| result | Boolean | Menunjukkan sama ada kemas kini berjaya. `true` menunjukkan berjaya. |

### Contoh isi respons

```text
HTTP/1.1 200 OK
Content-Type:application/json

{
  "result" : true
}
```

### Kod ralat

Jika ralat berlaku semasa anda memanggil API ini, cari penyelesaian dalam dokumen [Kod ralat global](/open/development/server-api-error-codes-1) berdasarkan mesej ralat.

| HttpCode | Kod ralat | Mesej ralat | Penerangan |
| --- | --- | --- | --- |
| 400 | param.error | Ralat Parameter | Ralat parameter yang hilang |
| 400 | group.not.found | Kumpulan Tidak Ditemui | Kumpulan tidak wujud |
| 400 | user.not.admin | Pengguna Bukan Admin | Pengguna bukan admin |
| 400 | org.not.found | Organisasi Tidak Ditemui | Organisasi tidak dapat ditemui |
| 500 | system.error | Ralat Sistem | Ralat sistem |
