Panggil API ini untuk mencipta sembang Kumpulan Dalaman atau Kumpulan Standard. Ini sesuai untuk senario di mana organisasi perlu mencipta sembang kumpulan dengan pantas.

## Penerangan panggilan API

Secara lalai, API ini hanya menyokong penciptaan Kumpulan Dalaman. Untuk mencipta Kumpulan Standard, hubungi sokongan teknikal untuk menambah aplikasi anda ke Senarai Dibenarkan.

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/v1.0/im/group/create |
| Kaedah HTTP | POST |
| Jenis aplikasi disokong | appType-Aplikasi dalaman |
| Kebenaran diperlukan | permission-qyapi_chat_manage-Kebenaran urus maklumat asas kumpulan DingTalk |

### Header permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses yang digunakan untuk memanggil API ini. Dapatkan melalui API [Dapatkan access token aplikasi dalaman](/ms/open/development/obtain-the-access-token-of-an-internal-app). |

### Isi permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| name | String | Ya | Nama kumpulan. Panjang mestilah 1 hingga 20 aksara. |
| owner | String | Ya | userId pemilik kumpulan. Dapatkan userId melalui API Dapatkan pengguna mengikut nombor mudah alih. |
| ownerType | String | Tidak | Jenis pemilik kumpulan.   - **emp**: Pekerja organisasi - **ext**: Kenalan luaran |
| useridlist | Array of String | Ya | StaffId pengguna. |
| conversationTag | Long | Tidak | Tag Jenis perbualan. Lalai kepada Kumpulan Dalaman. Untuk mencipta Kumpulan Standard, hubungi sokongan teknikal untuk menambah aplikasi anda ke Senarai Dibenarkan.   - **0**: Kumpulan Standard - **2**: Kumpulan Dalaman |
| extidlist | Array of String | Tidak | Kenalan luaran. |
| icon | String | Tidak | Gambar Profil kumpulan. Hantar mediaId, yang boleh diperoleh melalui API [Muat naik fail media](/ms/open/development/upload-media-files). |
| managementOptions | Object | Tidak | Atribut tambahan untuk mencipta kumpulan. |
| mentionAllAuthority | Integer | Tidak | Skop di mana @all boleh digunakan.   - **0** (lalai): Semua orang boleh menggunakannya. - **1**: Hanya pemilik kumpulan boleh menggunakan @all. |
| showHistoryType | Integer | Tidak | Sama ada pengguna baharu boleh melihat 100 mesej lampau terkini. Jika tidak dinyatakan, mereka tidak boleh melihatnya.   - **1**: Boleh lihat. - **0**: Tidak boleh lihat. |
| validationType | Integer | Tidak | Sama ada pengesahan diperlukan untuk menyertai kumpulan. - **0** (lalai): Tiada pengesahan.   - **1**: Pengesahan diperlukan. |
| searchable | Integer | Tidak | Sama ada kumpulan boleh dicari. - **0** (lalai): Tidak boleh dicari.   - **1**: Boleh dicari. |
| chatBannedType | Integer | Tidak | Sama ada untuk Bisukan ahli dalam kumpulan.   - **0** (lalai): Jangan bisukan. - **1**: Bisukan Semua. |
| managementType | Integer | Tidak | Jenis Urus Kumpulan.   - **0** (lalai): Semua orang boleh urus. - **1**: Hanya pemilik kumpulan boleh urus. |

### Kod ralat

Jika ralat berlaku semasa memanggil API ini, cari penyelesaian dalam dokumen [Kod ralat global](/ms/open/development/server-api-error-codes-1) berdasarkan mesej ralat.

| HttpCode | Kod ralat | Mesej ralat | Penerangan |
| --- | --- | --- | --- |
| 400 | parameter.invalid | Invalid input parameter | Hantar parameter wajib seperti yang ditetapkan oleh API. |
| 400 | permession.checkFailed | Permission check failed | Semakan kebenaran gagal. |
| 400 | permession.checkFailed | The group owner is not within the app visibility scope | Pemilik kumpulan berada di luar skop keterlihatan aplikasi. |
| 500 | system.error | Try again. If it always fails, submit a ticket | Cuba lagi. Jika sentiasa gagal, hantar tiket. |
