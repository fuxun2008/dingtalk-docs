---
title: "Kemas kini gambar terapung"
description: "Panggil API ini untuk mengemas kini atribut gambar terapung dalam DingTalk Spreadsheet, termasuk sumber gambar, kedudukan sauh, dan ofset saiz, dengan sokongan kemas kini separa yang mengekalkan nilai asal medan yang tidak ditetapkan."
---

Panggil API ini untuk mengemas kini atribut gambar terapung sedia ada dalam DingTalk Spreadsheet, termasuk sumber gambar, kedudukan sauh, dan ofset saiz. Kemas kini separa disokong—medan yang tidak diberikan akan mengekalkan nilai asal. Contohnya, hantar hanya `anchor` untuk melaraskan kedudukan gambar tanpa menjejaskan atribut lain. API ini sesuai untuk melaraskan kedudukan gambar, menggantikan sumber gambar, atau mengubah suai saiz paparan. Selepas panggilan berjaya, atribut lengkap gambar yang dikemas kini akan dikembalikan.

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/doc/workbooks/{workbookId}/sheets/{sheetId}/floatImages/{id}` |
| Kaedah HTTP | PUT |
| Jenis aplikasi disokong | appType-Aplikasi dalaman |
| Kebenaran diperlukan | permission-Document.Workbook.Write-Kebenaran tulis DingTalk Spreadsheet |

### Header permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Panggil API [Dapatkan access token aplikasi dalaman](/ms/open/development/obtain-the-access-token-of-an-internal-app) untuk mendapatkannya. |

### Parameter laluan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| workbookId | String | Ya | ID fail Spreadsheet. `nodeId(dentryUuid)` yang dikembalikan oleh [API Knowledge Base](/ms/open/development/knowledge-base-overview) adalah `workbookId` Spreadsheet. Dapatkan melalui API [Dapatkan nod](https://open.dingtalk.com/document/development/get-node) atau [Cipta dokumen Knowledge Base](/ms/open/development/create-team-space-document). |
| sheetId | String | Ya | ID atau tajuk Helaian Kerja. Panggil API [Dapatkan semua helaian kerja](/ms/open/development/obtain-all-worksheets) untuk mendapatkan ID dan tajuk Helaian Kerja. |
| id | String | Ya | ID gambar terapung yang ditentukan. Dapatkan melalui API "Query floating images". |

### Parameter pertanyaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| operatorId | String | Ya | unionId pengendali. Panggil API [Query user details](/ms/open/development/query-user-details) untuk mendapatkannya. Jika pengendali tidak mempunyai kebenaran, API akan mengembalikan ralat `The operator has no permission`. |

### Isi permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| src | String | Tidak | Alamat sumber gambar terapung. Panggil API [Dapatkan maklumat muat naik sumber](/ms/open/development/api-getresourceuploadinfo) untuk mendapatkan `resourceUrl`. |
| anchor | Object | Tidak | Kedudukan sauh yang menentukan Sel tempat gambar disauh. |
| row | Integer | Tidak | Nombor baris sauh (bermula dari 0). |
| col | Integer | Tidak | Nombor lajur sauh (bermula dari 0). |
| coordinate | Object | Tidak | Saiz gambar dan ofset relatif kepada Sel sauh. |
| width | double | Tidak | Lebar gambar, dalam piksel. |
| height | double | Tidak | Tinggi gambar, dalam piksel. |
| offsetX | double | Tidak | Ofset mendatar relatif kepada penjuru kiri atas Sel sauh, dalam piksel. |
| offsetY | double | Tidak | Ofset menegak relatif kepada penjuru kiri atas Sel sauh, dalam piksel. |
