---

Panggil API ini untuk mengemas kini nama panggilan ahli kumpulan dalam sembang. Ini sesuai untuk senario apabila pentadbir kumpulan menyeragamkan nama panggilan ahli atau apabila ahli menukar nama panggilan sendiri.

## Permintaan

| **Maklumat asas** | |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/topapi/chat/updategroupnick |
| Kaedah HTTP | POST |
| Jenis aplikasi yang disokong | appType-Aplikasi dalaman |
| Kebenaran diperlukan | permission-qyapi_chat_manage-Kebenaran pengurusan maklumat asas kumpulan DingTalk |

### Parameter Query

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | beE3xxxx | Kelayakan aplikasi yang digunakan untuk memanggil API ini. Dapatkan melalui API untuk mendapatkan [access_token aplikasi dalaman](/ms/open/development/obtain-orgapp-token). |

### Isi permintaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| userid | String | Ya | user123 | userId ahli kumpulan yang nama panggilannya hendak dikemas kini. Anda boleh mendapatkan userId ahli melalui API [Dapatkan maklumat sembang kumpulan](/ms/open/development/obtain-a-group-session). |
| chatid | String | Ya | chate3929fxxxx | ID sembang kumpulan. Anda boleh mendapatkan nilai chatid melalui API untuk mencipta kumpulan. |
| group_nick | String | Ya | Pembantu DingTalk | Nama panggilan ahli dalam kumpulan. |

### Contoh permintaan

```curl
curl -X POST "https://api.dingtalk.io/topapi/chat/updategroupnick" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=61a72xxxx8d62' \
-d 'chatid=0' \
-d 'group_nick=nick' \
-d 'userid=0'
```

Java

```text
DingTalkClient client = new DefaultDingTalkClient("https://api.dingtalk.io/topapi/chat/updategroupnick");
OapiChatUpdategroupnickRequest req = new OapiChatUpdategroupnickRequest();
req.setUserid("user123");
req.setChatid("chate39f540d572b71cf97a556d95929fxxxx");
req.setGroupNick("Pembantu DingTalk");
OapiChatUpdategroupnickResponse rsp = client.execute(req, access_token);
System.out.println(rsp.getBody());
```


## Respons

### Isi respons

| Nama | Jenis | Contoh | Penerangan |
| --- | --- | --- | --- |
| errcode | Number | 0 | Kod pemulangan. |
| errmsg | String | ok | Penerangan kod pemulangan. |
| success | Boolean | true | Menunjukkan sama ada tindakan berjaya.   - **true**: Berjaya - **false**: Gagal |
| request_id | String | id1aatxt9mco | ID permintaan. |

### Contoh respons

```json
{
  "errcode": 0,
  "errmsg": "ok",
  "success": true,
  "request_id": "id1aatxt9mco"
}
```

### Kod ralat

Jika ralat dikembalikan apabila anda memanggil API ini, rujuk dokumen [Kod ralat global](/ms/open/development/server-api-error-codes-1) untuk mencari penyelesaian berdasarkan mesej ralat.

| Kod ralat (errorcode) | Mesej ralat (errmsg) | Penyelesaian |
| --- | --- | --- |
| 40003 | userid tidak sah | Sahkan userid dimasukkan dengan betul. |
| 34001 | chatid tidak sah | Sahkan chatid adalah betul. |
| 41049 | Mengandungi kandungan yang dilarang | Ubah nama panggilan yang anda masukkan. |
| 60124 | Pengguna tiada dalam kumpulan berkenaan | Kemas kini pengguna dalam kumpulan. |
| 400002 | Ralat parameter | Semak bahawa parameter dimasukkan mengikut keperluan di atas. |
| 400001 | Ralat sistem | Cuba lagi kemudian. |
