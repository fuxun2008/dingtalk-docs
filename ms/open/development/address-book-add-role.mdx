Panggil API ini untuk mencipta peranan baharu.

## Permintaan

| **Maklumat asas** | |
| --- | --- |
| URL HTTP | https://oapi.dingtalk.io/role/add_role |
| Kaedah HTTP | POST |
| Jenis aplikasi yang disokong | appType-Aplikasi dalaman |
| Kebenaran yang diperlukan | permission-qyapi_manage_addresslist-Kebenaran pengurusan data Kenalan |

### Parameter pertanyaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | 6d1bxxxx | Kelayakan aplikasi yang digunakan untuk memanggil API ini. Dapatkan dengan memanggil API untuk mendapatkan [access_token aplikasi dalaman](/ms/open/development/obtain-orgapp-token). |

### Isi permintaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| roleName | String | Ya | Service | Nama peranan. |
| groupId | Number | Ya | 1507113595 | ID kumpulan peranan.   - Jika kumpulan peranan yang disasarkan sudah wujud, panggil API [Dapatkan senarai peranan](/ms/open/development/obtains-a-list-of-enterprise-roles) untuk mendapatkannya. - Jika kumpulan peranan belum dicipta, panggil dahulu API [Cipta kumpulan peranan](/ms/open/development/add-a-role-group) untuk mencipta satu dan mendapatkan IDnya. |

### Contoh permintaan

```curl
curl -X POST "https://oapi.dingtalk.io/role/add_role" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=2e3f55xxxx6e34' \
-d 'groupId=11' \
-d 'roleName=test'
```

Java

```text
DingTalkClient client = new DefaultDingTalkClient("https://oapi.dingtalk.io/role/add_role");
OapiRoleAddRoleRequest req = new OapiRoleAddRoleRequest();
req.setRoleName("Test1");
req.setGroupId(1507113595L);
OapiRoleAddRoleResponse rsp = client.execute(req, access_token);
System.out.println(rsp.getBody());
```

Python

```python
import dingtalk.api

req=dingtalk.api.OapiRoleAddRoleRequest("https://oapi.dingtalk.io/role/add_role")

req.roleName="test"
req.groupId=11
try:
  resp= req.getResponse(access_token)
  print(resp)
except Exception,e:
  print(e)
```

PHP

```php
include "TopSdk.php";
date_default_timezone_set('Asia/Shanghai');

$c = new DingTalkClient(DingTalkConstant::$CALL_TYPE_OAPI, DingTalkConstant::$METHOD_POST , DingTalkConstant::$FORMAT_JSON);
$req = new OapiRoleAddRoleRequest;
$req->setRoleName("test");
$req->setGroupId("11");
$resp = $c->execute($req, $access_token, "https://oapi.dingtalk.io/role/add_role");
```

C#

```text
IDingTalkClient client = new DefaultDingTalkClient("https://oapi.dingtalk.io/role/add_role");
OapiRoleAddRoleRequest req = new OapiRoleAddRoleRequest();
req.RoleName = "test";
req.GroupId = 11L;
OapiRoleAddRoleResponse rsp = client.Execute(req, access_token);
Console.WriteLine(rsp.Body);
```

## Respons

### Isi respons

| Nama | Jenis | Contoh | Penerangan |
| --- | --- | --- | --- |
| roleId | Number | 1688611118 | ID peranan. |
| errcode | Number | 0 | Kod pulangan. |
| errmsg | String | ok | Penerangan kod pulangan. |

### Contoh isi respons

```json
{
  "errcode":0,
  "roleId":1688611118,
  "errmsg":"ok"
}
```

### Kod ralat

Jika ralat dikembalikan semasa anda memanggil API ini, cari penyelesaiannya dalam dokumen [Kod ralat global](/ms/open/development/server-api-error-codes-1) berdasarkan mesej ralat.

| Kod ralat (errcode) | Mesej ralat (errmsg) | Penyelesaian |
| --- | --- | --- |
| 34018 | The role cannot be empty | Sediakan kedua-dua roleName dan groupId. |
| 34020 | Invalid groupId | Semak sama ada groupId adalah betul. |
| 34021 | The role name already exists | Semak sama ada roleName adalah betul. |
| -1 | System busy | Cuba lagi kemudian. |
