---
title: "Gabungkan Sel"
description: "Panggil API ini untuk menggabungkan sel dalam julat yang ditentukan pada Helaian Kerja DingTalk, menyokong mod penuh, mengikut baris, dan mengikut lajur; hanya data sel kiri atas yang dikekalkan."
---

Panggil API ini untuk menggabungkan beberapa sel dalam julat yang ditentukan pada Helaian Kerja DingTalk menjadi satu sel. Ini berguna untuk senario seperti mencipta tajuk pengepala merentas lajur atau menggabungkan baris dengan kategori yang sama. Tiga mod gabungan disokong: gabungkan semua, gabungkan mengikut baris, dan gabungkan mengikut lajur. Selepas digabungkan, hanya data pada sel kiri atas dikekalkan, dan kandungan sel lain akan dikosongkan. API ini mengembalikan alamat sel yang telah digabungkan.

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/doc/workbooks/{workbookId}/sheets/{sheetId}/ranges/{rangeAddress}/merge` |
| Kaedah HTTP | POST |
| Jenis aplikasi disokong | appType-Aplikasi dalaman |
| Kebenaran | permission-Document.Workbook.Write-Kebenaran tulis Helaian Kerja DingTalk |

### Pengepala permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Untuk mendapatkannya, panggil API [Dapatkan access token aplikasi dalaman](/ms/open/development/obtain-the-access-token-of-an-internal-app). |

### Parameter laluan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| workbookId | String | Ya | ID fail Helaian Kerja. `nodeId` (`dentryUuid`) yang dikembalikan oleh [API Knowledge Base](/ms/open/development/knowledge-base-overview) adalah `workbookId` bagi Helaian Kerja tersebut. Untuk mendapatkannya, panggil API [Dapatkan nod](/ms/open/development/get-knowledge-base-acquisition-node) atau [Cipta dokumen Knowledge Base](/ms/open/development/create-team-space-document). |
| sheetId | String | Ya | ID atau tajuk Helaian Kerja. Untuk mendapatkan ID dan tajuk Helaian Kerja, panggil API [Dapatkan semua Helaian Kerja](/ms/open/development/obtain-all-worksheets). |
| rangeAddress | String | Ya | Julat sel yang hendak digabungkan, dalam format `sel kiri atas:sel kanan bawah`. Contoh: B2:C3. |

### Parameter kueri

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| operatorId | String | Ya | unionId pengendali. Untuk mendapatkannya, panggil API [Tanya butiran pengguna](/ms/open/development/query-user-details). Jika pengendali tidak mempunyai kebenaran, API ini akan mengembalikan ralat `The operator has no permission`. |

### Isi permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| mergeType | String | Tidak | Mod gabungan. Nilai yang sah:   - **mergeAll**: Gabungkan semua sel (lalai). - **mergeRows**: Gabungkan mengikut baris. Sel bersebelahan pada baris yang sama dalam julat yang dipilih akan digabungkan menjadi satu sel. - **mergeColumns**: Gabungkan mengikut lajur. Sel bersebelahan pada lajur yang sama dalam julat yang dipilih akan digabungkan menjadi satu sel. |
