Panggil API ini untuk mencipta kumpulan peranan.

## Permintaan

| **Maklumat asas** | |
| --- | --- |
| URL HTTP | https://oapi.dingtalk.io/role/add_role_group |
| Kaedah HTTP | POST |
| Jenis aplikasi disokong | appType-Aplikasi dalaman |
| Kebenaran diperlukan | permission-qyapi_manage_addresslist-Kebenaran pengurusan data Kenalan |

### Parameter kueri

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | 6d1bxxxx | Kelayakan aplikasi yang digunakan untuk memanggil API ini. Dapatkannya melalui API untuk mendapatkan [access_token bagi aplikasi dalaman](/open/development/obtain-orgapp-token). |

### Isi permintaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| name | String | Ya | Manufacturing | Nama kumpulan peranan. |

### Contoh permintaan

```curl
curl -X POST "https://oapi.dingtalk.io/role/add_role_group" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=e9df3de5-2ccb-4aaf-a685-04ba09fe746d' \
-d 'name=%E5%90%8D%E7%A7%B0'
```

Java

```text
  DingTalkClient client = new DefaultDingTalkClient("https://oapi.dingtalk.io/role/add_role_group");
  OapiRoleAddrolegroupRequest req = new OapiRoleAddrolegroupRequest();
  req.setName("Manufacturing");
  OapiRoleAddrolegroupResponse rsp = client.execute(req, access_token);
  System.out.println(rsp.getBody());
```

Python

```python
import dingtalk.api

req=dingtalk.api.OapiRoleAddrolegroupRequest("https://oapi.dingtalk.io/role/add_role_group")

req.name="Name"
try:
  resp= req.getResponse(access_token)

except Exception,e:
  print(e)
```

## Respons

### Isi respons

| Nama | Jenis | Contoh | Penerangan |
| --- | --- | --- | --- |
| errcode | Nombor | 0 | Kod pemulangan. |
| errmsg | String | ok | ID kod pemulangan. |
| groupId | Nombor | 1560985325 | ID kumpulan peranan yang dicipta. |

### Contoh isi respons

```json
{
  "errcode":0,
  "groupId":1560985325,
  "errmsg":"ok"
}
```

### Kod ralat

Jika ralat berlaku semasa anda memanggil API ini, rujuk dokumen [Kod ralat global](/open/development/server-api-error-codes-1) untuk mencari penyelesaian berdasarkan mesej ralat.
