Panggil API ini untuk mendapatkan maklumat asas pengguna melalui kod kebenaran log masuk senyap.

## Permintaan

| **Maklumat asas** | |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/v1.0/sns/getuserinfo_bycode |
| Kaedah HTTP | POST |
| Jenis aplikasi yang disokong | appType-Internal appappType-Third-party enterprise app |
| Kebenaran | permission-open_app_api_base-Basic permission to obtain the user access credential for DingTalk open APIs |

### Parameter pertanyaan

| Nama | **Jenis** | Wajib | Penerangan |
| --- | --- | --- | --- |
| accessKey | String | Ya | AppId aplikasi. |
| timestamp | String | Ya | Cap masa semasa, dalam milisaat. |
| signature | String | Ya | Nilai tandatangan yang dikira menggunakan algoritma HmacSHA256, dengan timestamp+"\n"+AppSecret sebagai rentetan tandatangan dan AppSecret sebagai kunci penandatanganan. |

### Isi permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| tmp_auth_code | String | Ya | Kod kebenaran log masuk senyap yang diberikan oleh pengguna kepada aplikasi terbuka DingTalk. Dapatkan dengan memanggil JSAPI `dd.getAuthCode`. Rujuk kod kebenaran log masuk senyap untuk butiran lanjut. |

### Contoh permintaan

```curl
curl -X POST "https://api.dingtalk.io/v1.0/sns/getuserinfo_bycode" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'tmp_auth_code=abcdef'
```

Java

```java
DefaultDingTalkClient  client = new DefaultDingTalkClient("https://api.dingtalk.io/v1.0/sns/getuserinfo_bycode");
// Jika kelas ini tiada dalam SDK anda, muat turun SDK versi terkini
OapiSnsGetuserinfoBycodeRequest req = new OapiSnsGetuserinfoBycodeRequest();
req.setTmpAuthCode("4a2c5695b78738d495f47b5fee9160cd");
OapiSnsGetuserinfoBycodeResponse response = client.execute(req,"yourAppId","yourAppSecret");
```

Python

```python
import dingtalk.api

req = dingtalk.api.OapiSnsGetuserinfoBycodeRequest("https://api.dingtalk.io/v1.0/sns/getuserinfo_bycode")
req.tmp_auth_code = "abcdef"
try:
  resp = req.getResponse("yourAppId", "yourAppSecret")
  print(resp)
except Exception as e:
  print(e)
```

PHP

```php
include "TopSdk.php";
date_default_timezone_set('Asia/Shanghai');

$c = new DingTalkClient(DingTalkConstant::$CALL_TYPE_OAPI, DingTalkConstant::$METHOD_POST , DingTalkConstant::$FORMAT_JSON);
$req = new OapiSnsGetuserinfoBycodeRequest;
$req->setTmpAuthCode("abcdef");
$resp = $c->execute($req,"yourAppId","yourAppSecret", "https://api.dingtalk.io/v1.0/sns/getuserinfo_bycode");
```

C#

```csharp
IDingTalkClient client = new DefaultDingTalkClient("https://api.dingtalk.io/v1.0/sns/getuserinfo_bycode");
OapiSnsGetuserinfoBycodeRequest req = new OapiSnsGetuserinfoBycodeRequest();
req.TmpAuthCode = "abcdef";
OapiSnsGetuserinfoBycodeResponse rsp = client.Execute(req, "yourAppId", "yourAppSecret");
Console.WriteLine(rsp.Body);
```

### Kod ralat

Jika berlaku ralat semasa memanggil API ini, rujuk dokumen [kod ralat global](/ms/open/development/server-api-error-codes-1) untuk mencari penyelesaian berdasarkan mesej ralat.

| **Kod ralat** | **Penerangan** |
| --- | --- |
| 853002 | Parameter timestamp tidak sah. Nilainya berbeza lebih daripada 1 minit daripada masa semasa pada server DingTalk. |
| 853001 | Format parameter timestamp tidak betul. Ia mesti berupa masa semasa dalam milisaat. |
| 853003 | Parameter accessKey tidak sah. Ia mesti berupa appId yang wujud pada Open Platform DingTalk. |
| 853004 | Parameter signature tidak betul dan tidak sepadan dengan tandatangan yang dikira oleh server DingTalk. Ambil perhatian bahawa parameter ini mesti di-urlEncode semasa dihantar. |
