Panggil API ini untuk mengemas kini kenalan luaran organisasi anda.

## Permintaan

| **Maklumat asas** | |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/topapi/extcontact/update |
| Kaedah HTTP | POST |
| Jenis aplikasi yang disokong | appType-Aplikasi dalaman |
| Kebenaran diperlukan | permission-qyapi_ext_write-Kebenaran tulis untuk kenalan luaran |

### Parameter pertanyaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | 6d1bxxxx | Kelayakan aplikasi yang digunakan untuk memanggil API ini. Dapatkannya melalui API untuk mendapatkan [access_token aplikasi dalaman](/ms/open/development/obtain-orgapp-token). |

### Isi permintaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| contact | OpenExtContact | Ya |  | Maklumat kenalan luaran. |
| title | String | Tidak | Development Engineer | Jawatan. |
| label_ids | Nombor[] | Ya | [1,2,3] | Senarai tag. Panggil API [Dapatkan senarai kenalan luaran](/ms/open/development/obtain-the-external-contact-list) untuk menanyakan maklumat tag.  Rujuk [Cara menyesuaikan kumpulan tag untuk organisasi](https://tms.dingtalk.io/markets/dingtalk/biaoqianzu) untuk menambah tag tersuai.  Maksimum 20 labelId boleh dihantar bagi setiap panggilan. |
| share_dept_ids | Nombor[] | Tidak | [420606536] | ID jabatan untuk dikongsi. Panggil API [Dapatkan senarai ID subjabatan](/ms/open/development/obtain-the-list-of-sub-department-ids) untuk mendapatkannya.  Maksimum 20 ID jabatan boleh dihantar bagi setiap panggilan. |
| address | String | Tidak | Beijing | Alamat. |
| remark | String | Tidak | Technical Lead | Alias. |
| follower_user_id | String | Ya | 023420013645 | userId Pemilik. |
| name | String | Ya | Zhang xx | Nama kenalan luaran. |
| user_id | String | Ya | 123420013632 | userId kenalan luaran. Panggil API [Dapatkan senarai kenalan luaran](/ms/open/development/obtain-the-external-contact-list) untuk mendapatkannya. |
| company_name | String | Tidak | DingTalk | Nama organisasi kenalan luaran. |
| share_user_ids | String[] | Tidak | ["023420013644"] | Senarai userId pekerja untuk dikongsi.  Maksimum 20 labelId boleh dihantar bagi setiap panggilan. |

### Contoh permintaan

```curl
curl -X POST "https://api.dingtalk.io/topapi/extcontact/update" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=34ddexxxx6c95' \
-d 'contact=null'
```

## Respons

### Isi respons

| Nama | Jenis | Contoh | Penerangan |
| --- | --- | --- | --- |
| errcode | Nombor | 0 | Kod pemulangan. |
| request_id | String | 8n3mksu5hqzy | ID permintaan. |

### Contoh isi respons

```json
{
  "errcode":0,
  "request_id": "8n3mksu5hqzy""
}
```

### Kod ralat

Jika ralat berlaku semasa anda memanggil API ini, cari penyelesaian dalam dokumen [Kod ralat global](/ms/open/development/server-api-error-codes-1) berdasarkan mesej ralat.

| Kod ralat (errcode) | Mesej ralat (errmsg) | Penyelesaian |
| --- | --- | --- |
| 33009 | tokenGrantType tidak sah | Semak sama ada access_token adalah betul. |
| 40036 | Parameter kosong | Semak sama ada semua parameter wajib telah diisi. |
| 40003 | userId tidak sah | Semak sama ada userId adalah betul. |
| 60112 | Nama pengguna tidak sah | Semak sama ada nama pengguna adalah betul. |
| 60121 | Pengguna berkaitan tidak ditemui | Semak sama ada maklumat pengguna adalah betul. |
| 60204 | Tag diperlukan untuk kenalan luaran | Isikan label_ids untuk kenalan luaran. |
| 43007 | Kebenaran diperlukan | Semak sama ada access_token mempunyai kebenaran untuk melaksanakan operasi ini. |
| 60103 | Nombor mudah alih tidak sah | Semak sama ada nombor mudah alih adalah betul. |
| 60200 | Kenalan luaran sudah wujud | Semak sama ada maklumat kenalan luaran adalah betul. |
| 60203 | Bilangan kenalan luaran melebihi had | Buang beberapa kenalan luaran. |
| -1 | Sistem sibuk | Cuba Lagi kemudian. |
