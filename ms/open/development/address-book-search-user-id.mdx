# Cari ID pengguna

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/v1.0/contact/users/search |
| Kaedah HTTP | POST |
| Jenis aplikasi yang disokong | appType-Aplikasi dalaman　appType-Aplikasi perusahaan pihak ketiga |
| Kebenaran diperlukan | permission-qyapi_addresslist_search-Kebenaran untuk mencari Kenalan organisasi |

### Pengepala permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses yang digunakan untuk memanggil API ini. Dapatkannya seperti berikut:   - Untuk aplikasi dalaman, panggil API [Dapatkan access token aplikasi dalaman](/open/development/obtain-the-access-token-of-an-internal-app#). - Untuk aplikasi perusahaan pihak ketiga, panggil API [Dapatkan access token organisasi yang dibenarkan untuk aplikasi pihak ketiga](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#). |

### Isi permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| queryWord | String | Ya | Nama pengguna, nama dalam pinyin, atau nama Bahasa Inggeris. |
| offset | Integer | Ya | Nombor halaman. |
| size | Integer | Ya | Saiz halaman. |
| fullMatchField | Integer | Tidak | Menentukan sama ada padanan tepat dilakukan.   - **1**: Padan tepat dengan nama pengguna.   Jika parameter ini tidak dinyatakan, padanan kabur akan dilakukan pada nama pengguna secara lalai. |

### Contoh permintaan

HTTP

```http
POST /v1.0/contact/users/search HTTP/1.1
Host:api.dingtalk.io
x-acs-dingtalk-access-token:BExxx
Content-Type:application/json

{
  "queryWord" : "Ahmad",
  "offset" : 0,
  "size" : 10,
  "fullMatchField" : 1
}
```

## Respons

### Isi respons

| Nama | Jenis | Penerangan |
| --- | --- | --- |
| hasMore | Boolean | Menunjukkan sama ada terdapat lebih banyak data.   - true: Ya - false: Tidak |
| totalCount | Long | Jumlah bilangan rekod. |
| list | Array of String | ID pengguna. |

### Contoh isi respons

```text
HTTP/1.1 200 OK
Content-Type:application/json

{
  "hasMore" : false,
  "totalCount" : 2,
  "list" : [ "220141953" ]
}
```
