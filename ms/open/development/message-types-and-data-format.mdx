Topik ini menerangkan jenis notifikasi mesej dan format data dalam DingTalk.

## Jenis notifikasi mesej DingTalk

**Mesej Notifikasi Kerja**: Mesej notifikasi yang dihantar kepada pekerja bagi pihak aplikasi mikro dalam sembang Notifikasi Kerja sesebuah organisasi. Contohnya termasuk ucapan hari lahir dan peringatan onboarding.

## Mesej teks (text)

```json
{
    "msgtype": "text",
    "text": {
        "content": "Notifikasi mesyuarat bulanan"
    }
}
```

### Parameter

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| msgtype | String | Ya | text | Jenis mesej. Tetapkan kepada `text` untuk mesej teks. |
| content | String | Ya | Notifikasi mesyuarat bulanan | Kandungan mesej. Disyorkan sehingga 500 aksara. |

## Mesej gambar

```json
{
    "msgtype": "image",
    "image": {
        "media_id": "@lADOADmaWMzazQKA"
    }
}
```

### Parameter

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| msgtype | String | Ya | image | Jenis mesej. Tetapkan kepada `image` untuk mesej gambar. |
| media_id | String | Ya | @lADOADmaWMzazQKA | ID media. Panggil API [Muat naik fail media](/ms/open/development/upload-media-files) untuk mendapatkan nilai parameter `mediaId`. Saiz 600 x 400 piksel dengan nisbah bidang 3:2 disyorkan. |

## Mesej Markdown

```json
{
    "msgtype": "markdown",
    "markdown": {
        "title": "Kandungan yang dipaparkan pada skrin pertama sembang",
        "text": "# Ini teks yang menyokong markdown   \n   ## Tajuk 2    \n   * Item senarai 1   \n  "
    }
}
```

### Sintaks Markdown

```text
Tajuk
# Tajuk 1
## Tajuk 2
### Tajuk 3
#### Tajuk 4
##### Tajuk 5
###### Tajuk 6
 
Petikan
> Seseorang yang tidak berpegang pada apa-apa akan mudah terpengaruh oleh apa sahaja.
 
Tebal, Condong
**tebal**
*condong*
 
Pautan
[ini adalah pautan](http://name.com)
 
Gambar

 
Senarai Berbulet
- item1
- item2
 
Senarai Bernombor
1. item1
2. item2

Baris baharu
  \n  (Disyorkan menambah 2 ruang sebelum dan selepas \n)
```

### Parameter

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| msgtype | String | Ya | markdown | Jenis mesej. Panggil API [Muat naik fail media](/ms/open/development/upload-media-files) untuk mendapatkan nilai ini. Tetapkan kepada `markdown` untuk mesej Markdown. |
| title | String | Ya | Ujian tajuk | Kandungan yang dipaparkan pada skrin pertama sembang. |
| text | String | Ya | Ujian kandungan | Mesej berformat Markdown. Panjang maksimum ialah 5,000 aksara. |

### Contoh mesej

## Mesej kad

Mesej kad menyokong gaya ActionCard pengalihan keseluruhan dan gaya ActionCard pengalihan berasingan:

- Gaya ActionCard pengalihan keseluruhan menyokong satu tindakan klik. Parameter `single_title` dan `single_url` diperlukan.

  ```json lines
  {
      "msgtype": "action_card",
      "action_card": {
          "title": "Teks yang dipaparkan dalam senarai sembang dan notifikasi",
          "markdown": "Kandungan badan dalam format Markdown",
          "single_title": "Lihat Perincian",
          "single_url": "https://open.dingtalk.com"
      }
  }
  ```
- Gaya ActionCard pengalihan berasingan menyokong pelbagai tindakan klik. Parameter `btn_orientation` dan `btn_json_list` diperlukan.

  ```json lines
  {
      "msgtype": "action_card",
      "action_card": {
          "title": "Teks yang dipaparkan dalam senarai sembang dan notifikasi",
          "markdown": "Kandungan badan dalam format Markdown",
          "btn_orientation": "1",
          "btn_json_list": [
              {
                  "title": "Butang satu",
                  "action_url": "https://www.taobao.com"
              },
              {
                  "title": "Butang dua",
                  "action_url": "https://www.tmall.com"
              }
          ]
      }
  }
  ```

### Parameter

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| msgtype | String | Ya | action_card | Jenis mesej. Tetapkan kepada `action_card` untuk mesej kad. |
| action_card.markdown | String | Ya | Kandungan badan dalam format Markdown | Kandungan mesej. Markdown disokong. Ikut sintaks Markdown standard. Disyorkan sehingga 1,000 aksara. |
| action_card.title | String | Tidak | Ujian tajuk | Teks yang dipaparkan dalam senarai sembang dan notifikasi. |
| action_card.single_title | String | Tidak | Lihat Perincian | Tajuk yang digunakan bersama gaya ActionCard pengalihan keseluruhan. Mesti ditetapkan bersama `single_url`. Panjang maksimum ialah 20 aksara.  **Nota**  Bagi gaya ActionCard pengalihan keseluruhan, **single_title** dan **single_url** diperlukan. |
| action_card.single_url | String | Tidak | https://open.dingtalk.com | URL yang dibuka apabila mesej diklik. Panggil API [Muat naik fail media](/ms/open/development/upload-media-files) untuk mendapatkan nilai ini. Apabila mesej dihantar kepada Mini program, URL pengalihan Mini program turut disokong. Panjang maksimum ialah 500 aksara. |
| action_card.btn_orientation | String | Tidak | 0 | Susun atur butang yang digunakan bersama gaya ActionCard pengalihan berasingan:   - **0**: menegak - **1**: mendatar  Mesti ditetapkan bersama `btn_json_list`. |
| action_card.btn_json_list | JSONArray | Tidak |  | Senarai butang yang digunakan bersama gaya ActionCard pengalihan berasingan. Mesti ditetapkan bersama `btn_orientation`. Jumlah panjang tidak boleh melebihi 1,000 aksara.  **Nota**  Bagi gaya ActionCard pengalihan berasingan, `btn_json_list` dan `btn_orientation` diperlukan. |
| action_card.btn_json_list.title | String | Tidak | Dua butang | Tajuk butang yang digunakan bersama gaya ActionCard pengalihan berasingan. Panjang maksimum ialah 20 aksara. |
| action_card.btn_json_list.action_url | String | Tidak | https://www.tmall.com | URL pengalihan yang digunakan bersama gaya ActionCard pengalihan berasingan. Panjang maksimum ialah 700 aksara. |
