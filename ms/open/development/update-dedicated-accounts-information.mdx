Panggil API ini untuk mengemas kini maklumat pengguna dalaman bagi Akaun Syarikat yang ditentukan. Hanya tersedia untuk organisasi yang telah membeli dan mengaktifkan Akaun Syarikat.

## Permintaan

| **Maklumat asas** | |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/topapi/v2/user/update |
| Kaedah HTTP | POST |
| Jenis aplikasi disokong | appType-Aplikasi dalaman |
| Kebenaran diperlukan | permission-qyapi_manage_addresslist-Kebenaran pengurusan data Kenalan |

### Parameter kueri

| Nama | Jenis | Wajib | Contoh | Keterangan |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | be3Fxxxx | Kelayakan aplikasi yang digunakan untuk memanggil API ini. Dapatkannya melalui API untuk mendapatkan access_token bagi Aplikasi dalaman. |

### Isi permintaan

Selepas Nombor Telefon disembunyikan, ia disembunyikan pada halaman Profil, tetapi anda masih boleh menghantar DING dan memulakan panggilan perniagaan DingTalk kepada pekerja ini. - **false**: Jangan sembunyikan. |
| telephone | String | Tidak | 010-86123456-2345 | Nombor sambungan. Maksimum 50 aksara.  **Nota**  Nombor sambungan adalah Unik dan tidak boleh berulang dalam Organisasi Anda. |

| title | String | Tidak | Pengarah Teknikal | Jawatan. Maksimum 200 aksara. |
| email | String | Tidak | test@xxx.com | Mel Pekerja. Maksimum 50 aksara.  **Nota**  Mel pekerja adalah Unik dan tidak boleh berulang dalam Organisasi Anda. |

Jika hanya 1 dihantar, 9 yang lain akan dikosongkan. - Sebelum menggunakan parameter ini, tambah Atribut dalam [**DingTalk Admin Console**](https://oa.dingtalk.io/index.htm#/setting#setOrgInfo) > **Tetapan** > **Maklumat Kenalan**. - Nilai medan ini menyokong input jenis Pautan, dan Pautan menyokong penggantian automatik bagi kad bebas pemboleh ubah. | language | String | Tidak | zh_CN | Bahasa Kenalan. Nilai:   - **zh_CN**: Bahasa Cina (Lalai). - **en_US**: Bahasa Inggeris. |

Akaun Syarikat Single Sign-On tidak disokong.  **Nota**  Jangan sertakan maklumat Kenalan seperti Nombor Telefon, alamat e-mel, atau Pautan bagi mengelakkan mesej SMS disekat oleh pembawa telekomunikasi. |
| init_password | String | Tidak | init_password220 | Kata laluan awal untuk Akaun Syarikat DingTalk. Mesti sekurang-kurangnya 8 aksara.  **Nota**   - Tidak boleh terdiri sepenuhnya daripada huruf atau nombor. - Hanya Akaun Syarikat DingTalk boleh mengemas kini medan ini. Akaun Syarikat Single Sign-On tidak disokong. - Jangan sertakan maklumat Kenalan seperti Nombor Telefon, alamat e-mel, atau Pautan bagi mengelakkan mesej SMS disekat oleh pembawa telekomunikasi. |
| send_password_to_user | Boolean | Tidak | false | Sama ada hendak Hantar kelayakan akaun. Lalai ialah false.   - **false**: Jangan Hantar - **true**: Hantar   **Nota**   - Apabila parameter ini **true**, parameter `init_password` adalah Wajib; jika tidak, kelayakan tidak akan dihantar. - Semasa menghantar, mesej SMS akan dihantar ke Nombor Telefon pekerja atau e-mel akan dihantar ke mel peribadi pekerja. - Hanya Akaun Syarikat DingTalk menyokong penetapan medan ini. Akaun Syarikat Single Sign-On tidak disokong. |
| exclusive_mobile | String | Tidak | 150xxxxxxx | Nombor Telefon Akaun Syarikat. |
| avatarMediaId | String | Tidak | @lALPDfmVUw19YdrNA-jNA-g | Apabila mengemas kini Akaun Syarikat untuk organisasi semasa, anda boleh menentukan MediaId Gambar Profil. Hanya format jpg dan png disokong. Dapatkannya melalui API Muat naik Fail media.  **Nota**  Menyokong Akaun Syarikat Tersuai dan Akaun Syarikat Single Sign-On. |
| nickname | String | Tidak | Name | Nama Akaun Syarikat.  **Nota**  Menyokong Akaun Syarikat Tersuai dan Akaun Syarikat Single Sign-On. |
| dept_position_list | DeptPosition[] | Tidak |  | Maklumat jawatan dalam jabatan. |
| extension_i18n | Json | Tidak | `{"hobby":{"zh_CN":"travel","en_US":"travel","aJP":"travel"}}` | Nilai antarabangsa bagi Atribut lanjutan. |

## Respons

### Isi respons

| Nama | Jenis | Contoh | Keterangan |
| --- | --- | --- | --- |
| errcode | Number | 0 | Kod pemulangan. 0 menunjukkan Berjaya. |
| errmsg | String | User not found | Mesej ralat yang dikembalikan apabila Panggilan gagal. |

### Contoh isi respons

```json
{
  "errcode":0,
  "errmsg":"ok",
  "request_id":"55o5i31j4cg8"
}
```

### Kod ralat

Jika ralat berlaku semasa memanggil API ini, rujuk dokumen [Kod ralat global](/open/development/server-api-error-codes-1) untuk penyelesaian.
