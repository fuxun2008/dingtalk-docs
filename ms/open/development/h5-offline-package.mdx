## Apakah Pakej Luar Talian

Pakej luar talian menggabungkan sumber statik dalam halaman, termasuk HTML, JavaScript, dan CSS, ke dalam satu arkib termampat. Apabila pengguna membuka aplikasi, Bahagian klien memuat turun pakej luar talian secara tempatan, kemudian memuatkannya terus daripada storan tempatan melalui Client-side DingTalk. Ini meminimumkan kesan persekitaran rangkaian terhadap Aplikasi mikro H5 DingTalk.

## Had Integrasi

- Hanya tersedia pada peranti mudah alih, dan versi Bahagian klien mestilah 6.5.20 atau lebih baharu.
- Jumlah saiz keseluruhan sumber luar talian yang dimuat naik tidak boleh melebihi 10 MB.

## Langkah Integrasi

### Langkah 1: Aktifkan Ciri Pakej Luar Talian Aplikasi Mikro

1. Log masuk ke [DingTalk Developer Console](https://open-dev.dingtalk.com/).
2. Pilih aplikasi yang anda ingin aktifkan pakej luar talian.
3. Pada bar navigasi, klik **Pengurusan Versi dan Pelepasan**. Pada halaman **Pengurusan Versi dan Pelepasan**, klik butang **Pengurusan Pakej Luar Talian**, kemudian klik **Sahkan**.

### Langkah 2: Bungkus Pakej Luar Talian

1. Dalam projek anda, pasang [dingtalk-h5package-opensdk](https://www.npmjs.com/package/dingtalk-h5package-opensdk) melalui npm.

   ```
   npm install dingtalk-h5package-opensdk --save-dev
   ```
2. Dalam projek anda, cipta fail konfigurasi pakej luar talian `localresource.json`. Berikut adalah Contoh:

   ```
   {
     "miniAppId": "ID pakej luar talian untuk dibungkus",
     // Pemetaan antara URL sumber dalam talian dengan fail atau direktori tempatan. Key ialah laluan URL sumber dalam talian yang sepadan dengan sumber tempatan, dan value ialah direktori sumber tempatan.
     "assets": {
       // Value ialah direktori. Konfigurasi ini menambah sumber di bawah direktori ./dist ke laluan https://www.example.com/myapp.
       "https://www.example.com/myapp": "./dist"
     },
     // Senarai URL luaran yang bergantung.
     "externalAssets": [
       "https://unpkg.com/react@16.7.0/umd/react.production.min.js",
       "https://unpkg.com/vue@3.2.45/dist/vue.global.js",
       "https://unpkg.com/jquery@3.6.1/dist/jquery.js"
     ]
   }
   ```
3. Jalankan arahan pembungkusan dalam projek anda untuk menghasilkan fail sumber bernama `${offlinePackageId}.zip` secara tempatan.

   ```
   npx h5package pack
   ```

### Langkah 3: Muat Naik Pakej Luar Talian

Pada halaman **Pengurusan Versi dan Pelepasan**, klik **Sila muat naik pakej sumber H5 (.zip, .tar, .tar.gz)**, pilih sumber arkib daripada Langkah 2, dan tunggu pakej luar talian dihuraikan.

### Langkah 4: Lepaskan Pakej Luar Talian

Pilih versi sasaran pakej luar talian, klik butang **Lepaskan**, kemudian klik **Sahkan Pelepasan**.

## Cara Menggunakan

Dalam parameter pertanyaan URL perniagaan, tambahkan medan `dd_mini_app_id`. Dapatkan nilainya daripada **ID Pakej Luar Talian** pada halaman **Pengurusan Pakej Luar Talian**.

Contoh:

URL biasa: https://www.example.com/myapp/index.html

URL pakej luar talian: https://www.example.com/myapp/index.html?dd_mini_app_id=500000000xxxxx

## Alat Nyahpepijat

DingTalk menyediakan alat nyahpepijat untuk pakej luar talian. Ciri utamanya ialah **menyemak maklumat pakej luar talian tempatan pada telefon** dan **DevTools untuk halaman pakej luar talian H5**.

Keperluan versi Bahagian klien untuk menggunakan alat nyahpepijat: Android 6.5.35 atau lebih baharu; iOS 6.5.35 atau lebih baharu.

Cara menggunakan alat ini: Imbas Kod QR berikut dengan Client-side DingTalk.

Selepas mengimbas Kod QR, anda akan masuk ke halaman utama alat nyahpepijat.

### Diagnosis Halaman H5

Cara diagnosis halaman berfungsi: Apabila halaman pakej luar talian H5 dibuka, bekas (container) menyuntik DevTools ke dalam halaman untuk memantau cara halaman berjalan.

Langkah:

1. Klik **Diagnosis Halaman H5**.
2. Masukkan URL pakej luar talian H5 yang hendak diaktifkan.
3. Klik **Mula Diagnosis** untuk masuk ke halaman diagnosis.

### Semakan Pakej Luar Talian Tempatan

Langkah:

1. Klik **Pertanyaan Pakej Luar Talian Tempatan**.
2. Masukkan `miniAppId`, iaitu ID pakej luar talian.
3. Klik **Papar Maklumat Pakej Luar Talian**.
