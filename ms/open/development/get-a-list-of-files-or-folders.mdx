Panggil API ini untuk mendapatkan senarai fail atau folder dalam satu ruang.

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| HTTP URL | `https://api.dingtalk.io/v1.0/storage/spaces/{spaceId}/dentries` |
| Kaedah HTTP | GET |
| Jenis aplikasi disokong | appType-Aplikasi dalaman　appType-Aplikasi perusahaan pihak ketiga |
| Kebenaran diperlukan | permission-Storage.File.Read-Kebenaran baca untuk fail storan perusahaan |

### Header permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Dapatkan seperti berikut:   - Untuk aplikasi dalaman, panggil API [Dapatkan access token aplikasi dalaman](/open/development/obtain-the-access-token-of-an-internal-app#). - Untuk aplikasi perusahaan pihak ketiga, panggil API [Dapatkan access token perusahaan yang diberi kuasa kepada aplikasi pihak ketiga](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#). |

### Parameter laluan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| spaceId | String | Ya | ID ruang. Panggil API [Tambah ruang](/open/development/add-space#) untuk mendapatkan nilai parameter id. |

### Parameter pertanyaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| parentId | String | Ya | ID direktori induk. Untuk direktori root, tetapkan parameter ini kepada 0. Panggil API [Dapatkan senarai fail atau folder](#) untuk mendapatkan nilai parameter parentId. |
| nextToken | String | Tidak | Cursor penomboran halaman.   - Biarkan parameter ini kosong untuk panggilan pertama. - Untuk panggilan seterusnya, hantar nextToken yang dikembalikan oleh panggilan sebelumnya. |
| maxResults | Integer | Tidak | Bilangan entri setiap halaman. Nilai maksimum ialah 50. |
| orderBy | String | Tidak | Medan penyusunan.   - **MODIFIED_TIME**: masa pengubahsuaian terakhir. Nilai lalai. - **CREATE_TIME**: masa dicipta. - **NAME**: nama. - **SIZE**: saiz. |
| order | String | Tidak | Peraturan penyusunan.   - **ASC**: menaik. - **DESC**: menurun. Nilai lalai. |
| withThumbnail | Boolean | Tidak | Sama ada untuk mendapatkan pautan sementara bagi thumbnail fail. Dapatkan mengikut keperluan kerana ia memberi kesan kepada masa respons API.   - true: dapatkan. - false: jangan dapatkan. Nilai lalai. |
| unionId | String | Ya | unionId operator. Panggil API [Tanya butiran pengguna](/open/development/query-user-details#) untuk mendapatkannya. |
