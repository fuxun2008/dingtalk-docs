description: "Panggil API DingTalk ini untuk menjadualkan syif ahli kumpulan kehadiran berasaskan syif secara pukal — tetapkan syif atau hari rehat mengikut tarikh bagi setiap pengguna."
---

Panggil API ini untuk menjadualkan syif ahli kumpulan kehadiran berasaskan syif. Pastikan jenis kumpulan kehadiran ialah **kehadiran berasaskan syif**.

## Permintaan

| **Maklumat asas** | |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/topapi/attendance/group/schedule/async |
| Kaedah HTTP | POST |
| Jenis aplikasi yang disokong | appType-Aplikasi dalaman appType-Aplikasi perusahaan pihak ketiga |
| Kebenaran yang diperlukan | permission-qyapi_attendance_group_manage-Kebenaran pengurusan kumpulan kehadiran |

### Parameter query

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | bE74xxxx | Kelayakan aplikasi yang digunakan untuk memanggil API ini.   - Bagi Aplikasi dalaman, panggil API [Dapatkan access_token Aplikasi dalaman](/ms/open/development/obtain-orgapp-token) untuk mendapatkannya. - Bagi Aplikasi perusahaan pihak ketiga, panggil API untuk mendapatkan access_token organisasi pihak ketiga. |

### Isi permintaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| op_user_id | String | Ya | user456 | ID pengguna bagi operator. |
| group_id | Number | Ya | 2987 | ID kumpulan kehadiran.  **Nota**  Jika anda menggunakan pengecam kumpulan kehadiran lama group_key, panggil API [Tukar groupKey kepada groupId](/ms/open/development/convert-groupkey-to-groupid) untuk menukar group_key kepada group_id. |
| schedules | TopScheduleParam[] | Ya |  | Butiran penjadualan syif. Contoh:   ``` &#123;   "is_rest": false,   "work_date": 1605150671000,   "shift_id": 1,   "userid": "user123" &#125; ```   **Nota**  Panjang maksimum senarai ialah 200. |
| shift_id | Number | Ya | 1 | ID syif. Hantar 1 untuk syif rehat. Panggil API [Dapatkan ringkasan syif](/ms/open/development/enterprise-shift-query-in-batches) untuk mendapatkan nilai id.  **Nota**   - Apabila is_rest ialah true, hantar 1 untuk shift_id. - Untuk mengosongkan jadual, hantar -2 untuk shift_id. |
| work_date | Number | Ya | 1564985177000 | Tarikh penjadualan syif.  **Nota**  Tarikh tidak boleh lebih awal daripada 180 hari yang lalu dan tidak boleh melebihi 180 hari dari sekarang. |
| is_rest | Boolean | Tidak | false | Menentukan sama ada hari tersebut ialah hari rehat:   - **true**: Hari rehat  **Nota**  Apabila parameter ini ialah true, hantar 1 untuk shift_id. - **false**: Bukan hari rehat |
| userid | String | Ya | user123 | ID pengguna bagi pengguna. |

### Contoh permintaan

```curl
curl -X POST "https://api.dingtalk.io/topapi/attendance/group/schedule/async" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=d64b3xxxx57b23' \
-d 'group_id=2987' \
-d 'op_user_id=dd_test' \
-d 'schedules=null'
```

Java

```text
DingTalkClient client = new DefaultDingTalkClient("https://api.dingtalk.io/topapi/attendance/group/schedule/async");
OapiAttendanceGroupScheduleAsyncRequest req = new OapiAttendanceGroupScheduleAsyncRequest();
req.setOpUserId("user456");
req.setGroupId(2987L);
List<TopScheduleParam> list2 = new ArrayList<TopScheduleParam>();
TopScheduleParam obj3 = new TopScheduleParam();
obj3.setShiftId(1L);
obj3.setWorkDate(1564985177000L);
obj3.setIsRest(false);
obj3.setUserid("user123");
list2.add(obj3);
req.setSchedules(list2);
OapiAttendanceGroupScheduleAsyncResponse rsp = client.execute(req, access_token);
System.out.println(rsp.getBody());
```

## Respons

### Isi respons

| Nama | Jenis | Contoh | Penerangan |
| --- | --- | --- | --- |
| success | Boolean | true | Menunjukkan sama ada permintaan berjaya.   - **true**: Berjaya - **false**: Gagal |
| errcode | Number | 0 | Kod pemulangan. |
| errmsg | String | ok | Penerangan kod pemulangan. |
| request_id | String | zpd0i7dlr7bi | ID permintaan. |

### Contoh isi respons

```json
{
  "errcode":0,
  "errmsg":"ok",
  "success":true,
  "request_id":"zpd0i7dlr7bi"
}
```

Jika panggilan API mengembalikan ralat, cari penyelesaian dalam dokumen [Kod ralat global](/ms/open/development/server-api-error-codes-1) berdasarkan mesej ralat.
