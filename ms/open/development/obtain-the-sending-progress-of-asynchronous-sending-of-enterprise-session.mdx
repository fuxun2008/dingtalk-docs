Panggil API ini untuk mendapatkan kemajuan penghantaran notifikasi kerja. Ini berguna apabila organisasi anda perlu memantau status tolak mesej atau menyelesaikan masalah ralat penghantaran mesej.

## Penerangan panggilan API

API ini hanya mengembalikan kemajuan penghantaran notifikasi kerja yang dihantar dalam tempoh 7 hari lepas.

## Permintaan

| **Maklumat asas** | |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/topapi/message/corpconversation/getsendprogress |
| Kaedah HTTP | POST |
| Jenis aplikasi disokong | appType-Aplikasi dalaman, appType-Aplikasi perusahaan pihak ketiga |
| Kebenaran diperlukan | permission-qyapi_base-Kebenaran asas diperlukan untuk memanggil API perusahaan |

### Parameter pertanyaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | bE74xxxx | Kelayakan aplikasi yang digunakan untuk memanggil API ini.   - Untuk aplikasi dalaman, dapatkan dengan memanggil API untuk mendapatkan [access_token aplikasi dalaman](/ms/open/development/obtain-orgapp-token). - Untuk aplikasi perusahaan pihak ketiga, dapatkan dengan memanggil API untuk mendapatkan access_token perusahaan pihak ketiga. |

### Isi permintaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| agent_id | Number | Ya | 836390886 | Agent ID aplikasi mikro yang digunakan untuk menghantar mesej.   - Untuk aplikasi dalaman, lihat pada halaman butiran aplikasi di [Developer Backend](https://open-dev.dingtalk.io/#/appMgr/inner/h5/836390886/1). - Untuk aplikasi perusahaan pihak ketiga, dapatkan dengan memanggil API untuk mendapatkan maklumat kebenaran perusahaan. |
| task_id | Number | Ya | 256271667526 | ID tugas yang dikembalikan oleh DingTalk semasa mesej dihantar. Panggil API [Hantar notifikasi kerja](/ms/open/development/asynchronous-sending-of-enterprise-session-messages) untuk mendapatkan nilai task_id.  **Nota**  Hanya tugas yang dicipta dalam tempoh 24 jam lepas boleh disoal.  |

### Contoh permintaan

```curl
curl -X POST "https://api.dingtalk.io/topapi/message/corpconversation/getsendprogress" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=a0a25xxxxed3ff' \
-d 'agent_id=123' \
-d 'task_id=456'
```

Java

```text
DingTalkClient client = new DefaultDingTalkClient("https://api.dingtalk.io/topapi/message/corpconversation/getsendprogress");
OapiMessageCorpconversationGetsendprogressRequest req = new OapiMessageCorpconversationGetsendprogressRequest();
req.setAgentId(123L);
req.setTaskId(456L);
OapiMessageCorpconversationGetsendprogressResponse rsp = client.execute(req, accessToken);
System.out.println(rsp.getBody());
```

## Respons

### Isi respons

| Nama | Jenis | Contoh | Penerangan |
| --- | --- | --- | --- |
| request_id | String | 5y2znla8tw3d | ID permintaan. |
| errcode | Number | 0 | Kod pemulangan. |
| errmsg | String | ok | Penerangan kod pemulangan. |
| progress | AsyncSendProgress |  | Keputusan yang dikembalikan. |
| progress_in_percent | Number | 100 | Peratusan pemprosesan. Julat nilai: 0 hingga 100. |
| status | Number | 2 | Status pelaksanaan tugas:   - **0**: Belum bermula - **1**: Sedang dijalankan - **2**: Selesai |

### Contoh respons

```json
{
  "errcode": 0,
  "errmsg":"ok",
  "progress": {
    "progress_in_percent": 100,
    "status": 2
  },
  "request_id": "5y2znla8tw3d"
}
```

### Kod ralat

Jika ralat dikembalikan semasa anda memanggil API ini, rujuk dokumen [Kod ralat global](/ms/open/development/server-api-error-codes-1) untuk penyelesaian berdasarkan mesej ralat.

| Kod ralat (errorcode) | Mesej ralat (errmsg) | Penyelesaian |
| --- | --- | --- |
| 40035 | Invalid parameter | Sahkan bahawa task_id atau agent_id adalah betul. |
| 500 | System error | Ralat sistem yang tidak diketahui berlaku. |
