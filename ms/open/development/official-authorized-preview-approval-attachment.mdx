Panggil API ini untuk memberi kebenaran pratonton lampiran kelulusan.

## Penerangan panggilan API

<Note>
Gunakan API ini bersama JSAPI Drive.
</Note>

1. Dapatkan spaceId ruang Drive kelulusan. Panggil API [Dapatkan maklumat ruang Drive kelulusan](/ms/open/development/obtains-the-information-about-approval-nail-disk) untuk mendapatkan spaceId ruang Drive kelulusan.
2. Berdasarkan spaceId ruang Drive kelulusan, dapatkan maklumat fail lampiran Drive dalam aplikasi web (Aplikasi mikro H5) dengan memuat naik lampiran ke Drive atau memilih fail daripada Drive.
3. Dapatkan processInstanceId instans kelulusan. Panggil API [Cipta instans kelulusan](/ms/open/development/create-an-approval-instance) untuk mendapatkan nilai parameter InstanceId.
4. Gunakan maklumat di atas untuk memanggil API ini bagi memberi pengguna kebenaran pratonton lampiran kelulusan. Panggil API ini untuk kebenaran sebelum setiap kali lampiran kelulusan dipratonton.
5. Panggil API **Pratonton fail Drive** untuk mempratonton fail.

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/v1.0/workflow/processInstances/spaces/authPreview |
| Kaedah HTTP | POST |
| Jenis aplikasi yang disokong | appType-Aplikasi dalaman　appType-Aplikasi perusahaan pihak ketiga |
| Keperluan kebenaran | permission-Workflow.Instance.Write-Kebenaran tulis Instans aliran kerja |

### Pengepala permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Dapatkannya seperti berikut:   - Aplikasi dalaman: Panggil API [Dapatkan Access Token aplikasi dalaman](/ms/open/development/obtain-the-access-token-of-an-internal-app). - Aplikasi perusahaan pihak ketiga: Panggil API untuk mendapatkan access token organisasi yang diberi kebenaran oleh Aplikasi pihak ketiga. |

### Isi permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| userId | String | Ya | userId pengguna yang diberi kebenaran untuk mempratonton lampiran. |
| agentId | Long | Tidak | agentId aplikasi:   - Aplikasi dalaman: Lihat maklumat Agent ID. - Aplikasi perusahaan pihak ketiga: Panggil API untuk mendapatkan maklumat kebenaran organisasi bagi memperoleh nilai parameter `agentid`. |
| processInstanceId | String | Ya | ID instans kelulusan.   - Panggil API [Cipta instans kelulusan](/ms/open/development/create-an-approval-instance) untuk mendapatkan nilai parameter `InstanceId`. - Panggil API [Dapatkan senarai ID instans kelulusan](/ms/open/development/obtain-an-approval-list-of-instance-ids) untuk mendapatkan nilai parameter `list`. |
| fileId | String | Ya | ID lampiran kelulusan.      fileId mesti sepadan dengan fileId fail dalam komponen lampiran instans kelulusan yang telah dicipta. Jika tidak, mesej ralat tiada kebenaran akan dikembalikan. |
| fileIdList | Array of String | Tidak | Senarai ID lampiran. Kebenaran pukal disokong. Panjang maksimum senarai ialah 20. |
| withCommentAttatchment | Boolean | Tidak | Sama ada lampiran dalam komen turut disertakan. Secara lalai, lampiran dalam komen diabaikan. |
