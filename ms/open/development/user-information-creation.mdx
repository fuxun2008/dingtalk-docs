Panggil API ini untuk mencipta pengguna baharu.

## Penerangan panggilan API

API ini menyokong pencipta pengguna biasa atau pengguna Akaun Syarikat. Oleh sebab penggunaan parameter berbeza dengan ketara antara kedua-dua senario ini, dokumentasi dibahagikan mengikut jenis akaun untuk kejelasan:

- Untuk mencipta pengguna biasa, rujuk artikel ini.
- Untuk mencipta pengguna Akaun Syarikat (hanya tersedia untuk organisasi yang telah membeli dan mengaktifkan ciri ini), rujuk artikel berikut:

  - [Cipta Akaun Syarikat SSO](/open/development/create-an-sso-account)
  - [Cipta Akaun Syarikat khusus DingTalk](/open/development/create-dingtalk-user-created-dedicated-account)
  - [Jemput Akaun Syarikat daripada organisasi lain untuk menyertai](/open/development/invite-other-organization-specific-accounts-to-join)

## Permintaan

| **Maklumat asas** | |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/topapi/v2/user/create |
| Kaedah HTTP | POST |
| Jenis aplikasi disokong | appType-Aplikasi dalaman |
| Kebenaran diperlukan | permission-qyapi_manage_addresslist-Kebenaran pengurusan data Kenalan |

### Parameter query

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | BE3xxxx | Kelayakan aplikasi untuk memanggil API ini. Perolehinya dengan memanggil API yang mendapatkan [access_token bagi aplikasi dalaman](/open/development/obtain-orgapp-token). |

### Isi permintaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| userid | String | Tidak | zhangsan | Pengecam unik pekerja (tidak boleh diubah suai). Mesti unik dalam organisasi anda. Panjang mesti antara 1 hingga 64 aksara. Jika tidak dinyatakan, userid akan dijana secara automatik. |
| name | String | Ya | Zhang San | Nama pekerja. Maksimum 80 aksara. |
| mobile | String | Ya | 185xxxx | Nombor mudah alih. Mesti unik dalam organisasi anda dan tidak boleh berulang.  - Untuk nombor antarabangsa atau nombor dari Hong Kong (China), Macao (China), atau Taiwan (China), gunakan format +xx-xxxxxx. - Jika syarikat didaftarkan di luar tanah besar China, gunakan format +86-xxxxxx semasa menambah pengguna.  **Nota**  Log masuk ke [DingTalk Admin Console](https://oa.dingtalk.io) untuk melihat alamat berdaftar organisasi. |
| hide_mobile | Boolean | Tidak | false | Sama ada untuk menyembunyikan nombor mudah alih:  - **true**: Sembunyi. Selepas nombor mudah alih disembunyikan, ia tidak dipaparkan pada halaman Profil, tetapi pengguna lain masih boleh menghantar DING dan memulakan panggilan perniagaan DingTalk percuma. - **false**: Jangan sembunyi. |
| telephone | String | Tidak | 010-86123456-2345 | Nombor sambungan. Maksimum 50 aksara.  **Nota**  Nombor sambungan mesti unik dalam organisasi anda. |
| job_number | String | Tidak | 4 | ID Pekerja. Maksimum 50 aksara. |
| title | String | Tidak | Pengarah Teknikal | Jawatan. Maksimum 200 aksara. |
| email | String | Tidak | test@xxx.com | E-mel peribadi pekerja. Maksimum 50 aksara.  **Nota**  Alamat e-mel pekerja mesti unik dalam organisasi anda. |
| org_email | String | Tidak | test@xxx.com | E-mel Syarikat bagi pekerja. Maksimum 100 aksara.  **Nota**  Medan ini hanya berkuat kuasa jika E-mel Syarikat telah diaktifkan untuk pekerja tersebut. |
| org_email_type | String | Tidak | profession | Jenis E-mel Syarikat bagi pekerja.  - **profession:** Standard - **base:** Asas |
| work_place | String | Tidak | Future Park | Lokasi Kerja. Maksimum 100 aksara. |
| remark | String | Tidak | Alias | Alias. Maksimum 2000 aksara. |
| dept_id_list | String | Ya | "2,3,4" | Senarai ID jabatan tempat pekerja berada. Sehingga 100 ID jabatan boleh dihantar setiap panggilan. |
| dept_order_list | Object[] | Tidak |  | Susunan pekerja dalam jabatan berkaitan. |
| dept_id | Number | Tidak | 2 | ID jabatan. |
| order | Number | Tidak | 1 | Susunan pekerja dalam jabatan. |
| dept_title_list | Object[] | Tidak |  | Jawatan pekerja dalam jabatan berkaitan. |
| dept_id | Number | Tidak | 2 | ID jabatan. |
| title | String | Tidak | Pengurus Produk Kanan | Jawatan pekerja dalam jabatan. |
| extension | Object | Tidak | `{"Hobby":"Travel","Age":"24"}` | Atribut extension. Beberapa atribut boleh dikonfigurasikan. Maksimum 2000 aksara.  **Nota**  - Sehingga 10 atribut extension boleh dipaparkan pada peranti mudah alih. - Sebelum menggunakan parameter ini, tambah atribut dalam [DingTalk Admin Console](https://oa.dingtalk.io/index_new.htm#/setting/contactInfo) > Tetapan Kenalan Dalaman > Urus Medan Ahli, kemudian panggil API untuk menetapkan nilainya. Untuk butiran lanjut, lihat **Tentang parameter extension** di bawah. - Nilai medan ini menyokong jenis pautan, dan pautan menyokong penggantian automatik kad bebas pemboleh ubah. Kad bebas yang disokong pada masa ini termasuk: userid dan corpid. Contoh: `{"Hobby":"[Hobby](http://www.dingtalk.io?userid=#userid#&corpid=#corpid#)"}` - **Penting:** Menambah atribut baharu secara terus akan menulis ganti nilai atribut sedia ada. Dapatkan atribut sedia ada terlebih dahulu, tambahkan atribut baharu padanya, kemudian lakukan kemas kini penuh. |
| senior_mode | Boolean | Tidak | false | Sama ada untuk mengaktifkan mod eksekutif. Lalai: false.  - **true**: Aktifkan.  **Nota**    - Apabila diaktifkan, nombor mudah alih disembunyikan daripada semua pekerja.   - Pekerja biasa tidak boleh menghantar DING atau memulakan panggilan perniagaan DingTalk kepada pengguna ini.   - Eksekutif boleh menghantar DING dan memulakan panggilan perniagaan DingTalk antara satu sama lain. - **false**: Jangan aktifkan. |
| hired_date | Number | Tidak | 1597573616828 | Tarikh mula bekerja, sebagai Unix timestamp dalam milisaat. |
| manager_userid | String | Tidak | 001 | userId bagi penyelia terus. |
| login_email | String | Tidak | test@xxx.com | Alamat e-mel log masuk.  **Nota**  Medan ini hanya berkenaan untuk akaun e-mel. Menetapkan medan ini untuk akaun bukan e-mel tidak memberi kesan. |
| dept_position_list | DeptPosition[] | Tidak |  | Maklumat jawatan dalam jabatan. |
| extension_i18n | Json | Tidak | `{"Hobby": {"zh_CN": "Travel", "en_US": "Travel", "aJP": "Trip"}}` | Nilai antarabangsa bagi atribut extension. |

### Contoh permintaan

```bash

-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \

-d 'name=John' \
-d 'mobile=13800138000' \
-d 'dept_id_list=%5C%222%2C3%2C4%5C%22'
```

## Respons

### Isi respons

| Nama | Jenis | Contoh | Penerangan |
| --- | --- | --- | --- |
| errcode | Number | 0 | Kod ralat. 0 menunjukkan kejayaan. |
| errmsg | String | ok | Mesej ralat. |
| result | Object |  | Hasil yang dikembalikan. |
| userid | String | zhangsan | ID Pekerja. |
| unionId | String | xxxx | ID unik pekerja. |

### Contoh isi respons

```json
{
  "errcode":"0",
  "result":{
    "unionId":"xxxx",
    "userid":"zhangsan"
  },
  "errmsg":"ok"
}
```

### Kod ralat

Jika ralat berlaku semasa memanggil API ini, rujuk dokumen [Kod ralat global](/open/development/server-api-error-codes-1) untuk penyelesaian berdasarkan mesej ralat.

## Tentang parameter extension

Untuk memaparkan atribut pengguna yang dikonfigurasikan dalam medan **extension**, lengkapkan langkah berikut.

1. Log masuk ke [DingTalk Admin Console](https://login.dingtalk.io/).
2. Klik Tetapan Kenalan Dalaman, kemudian klik **Urus Medan Ahli** > **Tambah Medan Tersuai**.
