Panggil API ini untuk menyemak butiran tetapan peraturan kerja lebih masa secara pukal berdasarkan beberapa ID peraturan kerja lebih masa.

## Penerangan panggilan API

Sebagai contoh, katakan peraturan kerja lebih masa dalam kumpulan kehadiran organisasi anda ditetapkan kepada **Kira kerja lebih masa mengikut masa kelulusan**.

Dalam Admin Console DingTalk, pergi ke **Pengurusan kumpulan kehadiran** > **Ubah suai kumpulan kehadiran** > **Peraturan kerja lebih masa** > **Tetapan**. Peraturan kerja lebih masa umum ditetapkan kepada **Kira kerja lebih masa mengikut masa kelulusan**. Tetapan ini terpakai pada hari bekerja, hari rehat dan cuti umum: kerja lebih masa mesti diluluskan, dan tempoh kerja lebih masa adalah berdasarkan borang kelulusan.

Panggil API ini untuk mendapatkan butiran tetapan peraturan kerja lebih masa **Kira kerja lebih masa mengikut masa kelulusan**, termasuk nama peraturan dan kaedah pengiraan kerja lebih masa.

Dalam Admin Console, buka **Pengurusan peraturan kehadiran** > **Peraturan kerja lebih masa** dan edit satu peraturan kerja lebih masa. Panel **Edit peraturan kerja lebih masa** mengandungi tetapan berikut:

| Medan | Pilihan / nota |
| --- | --- |
| **Nama peraturan** | Sehingga 30 aksara |
| **Skop penggunaan** | Contohnya, seluruh Organisasi (kecuali mereka yang mempunyai peraturan kerja lebih masa lain) |
| **Pemilik** | Pilihan |
| Tab jenis hari | **Hari bekerja**, **Hari rehat**, **Cuti umum** |
| **Benarkan kerja lebih masa** | Togol hidup/mati |
| **Tempoh kerja lebih masa yang dibenarkan** | **Sebelum kerja**, **Selepas kerja** |
| **Kaedah pengiraan** | **Kira mengikut tempoh kelulusan**, atau **Kira mengikut tempoh daftar masuk dalam tempoh yang diluluskan** |

Peraturan dalam contoh ini menggunakan kaedah **Kira mengikut tempoh kelulusan**.

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/v1.0/attendance/overtimeSettings/query |
| Kaedah HTTP | POST |
| Jenis aplikasi yang disokong | appType-Aplikasi dalaman　appType-Aplikasi perusahaan pihak ketiga |
| Kebenaran | permission-qyapi_attendance_group_read-Kebenaran pertanyaan kumpulan kehadiran |

### Pengepala permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Dapatkannya seperti berikut:   - Aplikasi dalaman: Panggil API [Dapatkan access token aplikasi dalaman](/ms/open/development/obtain-the-access-token-of-an-internal-app). - Aplikasi perusahaan pihak ketiga: Panggil API untuk mendapatkan access token Organisasi yang diberi kebenaran kepada Aplikasi pihak ketiga. |

### Isi permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| overtimeSettingIds | Array of Long | Tidak | ID tetapan peraturan kerja lebih masa. Panggil API [Tanya maklumat penjadualan syif pengguna](/ms/open/development/query-scheduling-for-a-day) untuk mendapatkannya daripada medan overtimeSettingId dalam features. |
