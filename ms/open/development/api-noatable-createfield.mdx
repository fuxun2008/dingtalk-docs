Panggil API ini untuk mencipta medan dalam jadual.

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/notable/bases/{baseId}/sheets/{sheetIdOrName}/fields` |
| Kaedah HTTP | POST |
| Jenis aplikasi yang disokong | appType-Aplikasi dalaman |
| Kebenaran yang diperlukan | permission-Notable.Base.Write.All-Kebenaran tulis aplikasi AI Table |

### Header permintaan

| Nama | Jenis | Wajib | Keterangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Dapatkan dengan memanggil API [Dapatkan access token aplikasi dalaman](/ms/open/development/obtain-the-access-token-of-an-internal-app#). |

### Parameter laluan

| Nama | Jenis | Wajib | Keterangan |
| --- | --- | --- | --- |
| baseId | String | Ya | ID AI Table. Untuk mendapatkannya, rujuk [Struktur data](/ms/open/development/data-structure#). |
| sheetIdOrName | String | Ya | ID jadual atau nama jadual. Dapatkan ID jadual melalui salah satu cara berikut:   - Panggil API [Dapatkan semua jadual](/ms/open/development/api-notable-getallsheets#). - Panggil API [Dapatkan jadual](/ms/open/development/api-notable-getsheet#). |

### Parameter kueri

| Nama | Jenis | Wajib | Keterangan |
| --- | --- | --- | --- |
| operatorId | String | Ya | unionId pengendali. Dapatkan melalui salah satu cara berikut:   - Panggil API [Tanya butiran pengguna](/ms/open/development/query-user-details#). - Panggil API [Dapatkan maklumat pengguna melalui kod log masuk senyap](/ms/open/development/obtain-the-userid-of-a-user-by-using-the-log-free#). |

### Isi permintaan

| Nama | Jenis | Wajib | Keterangan |
| --- | --- | --- | --- |
| name | String | Ya | Nama medan. |
| property | `Map<String, Any>` | Tidak | Atribut medan. Untuk butiran format, rujuk [Sifat medan](https://open.dingtalk.com/document/development/field-properties#). |
|  | Any | Tidak | Atribut medan. |
| type | String | Ya | Jenis medan. |
