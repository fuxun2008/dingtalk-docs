---
title: "Dapatkan pengguna mengikut nombor mudah alih"
description: "Panggil API ini untuk menanyakan userId pekerja aktif mengikut nombor mudah alih di DingTalk. userId pekerja yang telah berhenti tidak boleh diperoleh melalui nombor mudah alih."
---

Panggil API ini untuk mendapatkan ID pengguna pekerja aktif mengikut nombor mudah alih mereka. Jika pekerja tersebut telah meninggalkan organisasi, ID pengguna tidak boleh diperoleh melalui nombor mudah alih.

## Permintaan

| **Maklumat asas** | |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/topapi/v2/user/getbymobile |
| Kaedah HTTP | POST |
| Jenis aplikasi yang disokong | appType-Aplikasi dalaman |
| Kebenaran diperlukan | permission-qyapi_get_member_by_mobile-Kebenaran untuk mendapatkan maklumat asas pengguna mengikut nombor mudah alih |

### Parameter pertanyaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | be3Fxxxx | Kelayakan aplikasi untuk memanggil API ini. Dapatkan melalui API untuk mendapatkan [access_token bagi aplikasi dalaman](/open/development/obtain-orgapp-token). |

### Isi permintaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| mobile | String | Ya | 1\*\*\*\*\*\*\*543 | Nombor mudah alih pengguna. |

### Contoh permintaan

```curl
curl -X POST "https://api.dingtalk.io/topapi/v2/user/getbymobile" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=2015ca04-c84e-4855-9e52-330b98eb35f5' \
-d 'mobile=13800138000'
```

Java

```text
DingTalkClient client = new DefaultDingTalkClient("https://api.dingtalk.io/topapi/v2/user/getbymobile");
OapiV2UserGetbymobileRequest req = new OapiV2UserGetbymobileRequest();
req.setMobile("1*******543");
OapiV2UserGetbymobileResponse rsp = client.execute(req, acces_token);
System.out.println(rsp.getBody());
```

Python

```python

```

```text

```

## Respons

### Isi respons

| Nama | Jenis | Contoh | Penerangan |
| --- | --- | --- | --- |
| request_id | String | 5w82ciuur781 | ID permintaan. |
| errcode | Number | 0 | Kod pulangan. |
| errmsg | String | ok | Penerangan kod pulangan. |
| result | Object |  | Hasil yang dipulangkan. |
| userid | String | zhangsan | ID pengguna bagi pekerja. |

### Contoh respons

```json
{
  "errcode":"0",
  "result":{
    "userid":"xiaoding"
  },
  "errmsg":"ok"
}
```

### Kod ralat

Jika berlaku ralat semasa memanggil API ini, rujuk dokumen [Kod ralat global](/open/development/server-api-error-codes-1) untuk penyelesaian berdasarkan mesej ralat.

| Kod ralat (errcode) | Mesej ralat (errmsg) | Penyelesaian |
| --- | --- | --- |
| 400002 | Invalid parameter | Pastikan parameter diisi mengikut keperluan seperti dalam dokumen di atas. |
| 40104 | Invalid mobile number in the organization | Semak sama ada nombor mudah alih tersebut betul. |
| 60121 | User not found | Sahkan bahawa maklumat telah diisi dengan betul. |
| -1 | System busy | Cuba Lagi kemudian. |
