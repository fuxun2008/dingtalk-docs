Panggil API ini untuk mencipta kumpulan bilik.

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/v1.0/rooms/groups |
| Kaedah HTTP | POST |
| Jenis aplikasi yang disokong | appType-Aplikasi dalaman　appType-Aplikasi perusahaan pihak ketiga |
| Kebenaran yang diperlukan | permission-VideoConference.Conference.Write-Kebenaran pengurusan maklumat Mesyuarat Video |

### Header permintaan

| Nama | Jenis | Wajib | Penjelasan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Dapatkan seperti berikut:   - Untuk aplikasi dalaman, panggil API [Dapatkan access token aplikasi dalaman](/ms/open/development/obtain-the-access-token-of-an-internal-app#). - Untuk aplikasi perusahaan pihak ketiga, panggil API [Dapatkan access token organisasi yang telah memberi kebenaran kepada aplikasi pihak ketiga](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#). |

### Isi permintaan

| Nama | Jenis | Wajib | Penjelasan |
| --- | --- | --- | --- |
| unionId | String | Ya | unionId pengendali. Panggil API [Semak maklumat terperinci pengguna](/ms/open/development/query-user-details#) untuk mendapatkannya. |
| groupName | String | Tidak | Nama kumpulan. |
| parentGroupId | Long | Ya | ID kumpulan induk. Masukkan 0 untuk menunjukkan kumpulan akar. Panggil API [Semak senarai kumpulan bilik](/ms/open/development/query-meeting-rooms-groups#) untuk mendapatkannya. |
