Panggil API ini untuk mendapatkan ID pengguna semua pekerja dalam kumpulan kehadiran mengikut halaman.

## Penerangan panggilan API

Jika ahli kehadiran termasuk jabatan, API ini memulangkan ID pengguna pekerja dalam jabatan tersebut. API ini tidak memulangkan ID jabatan.

Contohnya, ahli kehadiran termasuk **Jabatan Ujian** dan pekerja **Ahmad**. Jabatan Ujian mempunyai seorang pekerja, iaitu **Siti**. Memanggil API ini akan memulangkan yang berikut:

- ID pengguna pekerja dalam Jabatan Ujian (termasuk subjabatannya), iaitu ID pengguna Siti
- ID pengguna Ahmad

## Permintaan

| **Maklumat asas** | |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/topapi/attendance/group/memberusers/list |
| Kaedah HTTP | POST |
| Jenis aplikasi yang disokong | Aplikasi dalaman, Aplikasi perusahaan pihak ketiga |
| Kebenaran | qyapi_attendance_group_read (Kebenaran pertanyaan kumpulan kehadiran) |

### Parameter pertanyaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | bE74xxxx | Kelayakan aplikasi yang digunakan untuk memanggil API ini.   - Aplikasi dalaman: Panggil API [Dapatkan access_token aplikasi dalaman](/ms/open/development/obtain-orgapp-token) untuk mendapatkannya. - Aplikasi perusahaan pihak ketiga: Panggil API untuk mendapatkan access_token perusahaan pihak ketiga. |

### Isi permintaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| cursor | Number | Tidak | 0 | Nilai cursor yang menunjukkan kedudukan permulaan. Jika tidak dinyatakan, pertanyaan bermula daripada item pertama. |
| op_user_id | String | Ya | user123 | ID pengguna pengendali. |
| group_id | Number | Ya | 98562 | ID kumpulan kehadiran.  **Nota**  Jika anda menggunakan pengecam kumpulan kehadiran lama group_key, panggil API [Tukar groupKey kepada groupId](/ms/open/development/convert-groupkey-to-groupid) untuk menukar group_key kepada group_id. |

### Contoh permintaan

```curl
curl -X POST "https://api.dingtalk.io/topapi/attendance/group/memberusers/list" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=e6e94xxxxeb7b3' \
-d 'cursor=9828' \
-d 'group_id=98562' \
-d 'op_user_id=dd_dd'
```

Java

```text
DingTalkClient client = new DefaultDingTalkClient("https://api.dingtalk.io/topapi/attendance/group/memberusers/list");
OapiAttendanceGroupMemberusersListRequest req = new OapiAttendanceGroupMemberusersListRequest();
req.setCursor(0L);
req.setOpUserId("user123");
req.setGroupId(98562L);
OapiAttendanceGroupMemberusersListResponse rsp = client.execute(req, access_token);
System.out.println(rsp.getBody());
```

## Respons

### Isi respons

| Nama | Jenis | Contoh | Penerangan |
| --- | --- | --- | --- |
| request_id | String | 3pgsafymemlr | ID permintaan. |
| errcode | Number | 0 | Kod pulangan. |
| success | Boolean | true | Menunjukkan sama ada panggilan berjaya.   - **true**: Berjaya - **false**: Gagal |
| result | PageResult |  | Senarai pengguna. |
| has_more | Boolean | false | Menunjukkan sama ada terdapat lebih banyak data.   - **true**: Ya - **false**: Tidak |
| cursor | Number | 1387570559 | Kedudukan permulaan bagi permintaan halaman seterusnya. |
| result | String[] | ["user123","user456"] | Senarai ID pengguna dalam kumpulan kehadiran. |

### Contoh isi respons

```json
{
  "errcode": 0,
  "result": {

    "has_more": false,
    "result": [
      "user123",
      "user456"
    ]
  },
  "success": true,
  "request_id": "146drwo74wiss"
}
```
