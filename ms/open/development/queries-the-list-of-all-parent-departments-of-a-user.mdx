Panggil API ini untuk menanya semua jabatan induk yang dimiliki oleh pengguna tertentu. API ini tidak dihadkan oleh Skop kebenaran Kenalan.

## Permintaan

| **Maklumat asas** | |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/topapi/v2/department/listparentbyuser |
| Kaedah HTTP | POST |
| Jenis aplikasi disokong | appType-Aplikasi dalamanappType-Aplikasi perusahaan pihak ketiga |
| Kebenaran diperlukan | permission-qyapi_get_department_list-Kebenaran baca untuk maklumat jabatan Kenalan |

### Parameter pertanyaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | bE74xxxx | Kelayakan aplikasi yang digunakan untuk memanggil API ini.   - Untuk Aplikasi dalaman, dapatkan melalui API untuk mendapatkan access_token bagi Aplikasi dalaman. - Untuk Aplikasi perusahaan pihak ketiga, dapatkan melalui API untuk mendapatkan access_token bagi perusahaan pihak ketiga. |

### Isi permintaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| userid | String | Ya | 100 | ID pengguna bagi pengguna yang hendak ditanya. |

### Contoh permintaan

```curl
curl -X POST "https://api.dingtalk.io/topapi/v2/department/listparentbyuser" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=f3c2f4xxxxf65767' \
-d 'userid=100'
```

## Respons

### Isi respons

| Nama | Jenis | Contoh | Penerangan |
| --- | --- | --- | --- |
| errcode | Number | 0 | Kod pulangan. |
| request_id | String | nfe328zf67ec | ID permintaan. |
| errmsg | String | Invalid userid | Mesej ralat yang dikembalikan apabila Panggilan gagal. |
| result | DeptListParentByUserResponse |  | Hasil yang dikembalikan. |
| parent_list | DeptParentResponse[] |  | Koleksi senarai jabatan induk. |
| parent_dept_id_list | Number[] | [456, 123, 1] | Senarai jabatan induk. |

### Kod ralat

Jika Ralat berlaku semasa memanggil API ini, cari penyelesaian dalam dokumen [Kod ralat global](/open/development/server-api-error-codes-1) berdasarkan Mesej ralat.

| Kod ralat (errcode) | Mesej ralat (errmsg) | Penyelesaian |
| --- | --- | --- |
| 43007 | Kebenaran diperlukan | Sahkan bahawa access_token mempunyai Kebenaran yang diperlukan. |
| 33012 | userId tidak sah | Sahkan bahawa userId adalah betul. |
| 400002 | Parameter tidak sah | Sahkan bahawa parameter dimasukkan seperti yang diperlukan. |
| -1 | Sistem sibuk | Cuba Lagi kemudian. |
