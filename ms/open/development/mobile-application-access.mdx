Log Masuk DingTalk untuk aplikasi mudah alih adalah sistem log masuk Kebenaran OAuth 2.0 DingTalk yang dibina berdasarkan [standard protokol OAuth 2.0](https://oauth.net/2/).

**Nota**

- Pada masa ini, Log Masuk DingTalk pada aplikasi mudah alih hanya menyokong kaedah log masuk asli, yang memerlukan pengguna memasang Bahagian klien DingTalk.
- Untuk aplikasi Android, pastikan butang Log Masuk DingTalk kelihatan pada setiap masa. Apabila telefon pengguna tidak memasang Bahagian klien DingTalk, bimbing pengguna untuk memuat turun dan memasangnya.

## Kes Penggunaan

Apabila seorang Pekerja menggunakan Aplikasi yang dibangunkan secara dalaman oleh Organisasi mereka, mereka perlu log masuk dengan akaun dan kata laluan. Untuk memudahkan log masuk, tambahkan butang DingTalk terus pada halaman log masuk supaya Pekerja dapat log masuk ke Aplikasi menggunakan akaun DingTalk mereka.

Gambar di bawah menunjukkan halaman log masuk klien BOC International. Pengguna yang mempunyai akaun DingTalk dan telah memasang Bahagian klien DingTalk boleh log masuk terus dengan Kebenaran DingTalk, tanpa memasukkan akaun dan kata laluan.

## Arahan

Apabila Aplikasi anda perlu menggunakan Log Masuk DingTalk, tambahkan Aplikasi DingTalk dahulu pada **DingTalk Open Platform**, kemudian integrasikan Permintaan log masuk kebenaran menggunakan SDK yang disediakan oleh DingTalk Open Platform. Selepas anda mengintegrasikan SDK dengan betul dan memperoleh Skop kebenaran yang berkaitan (skop kebenaran; pada masa ini, DingTalk hanya menyokong log masuk kebenaran dan mendapatkan maklumat Asas pengguna), Aplikasi mudah alih pembangun akan melancarkan Aplikasi DingTalk secara tempatan pada peranti untuk log masuk kebenaran. Selepas pengguna DingTalk mengesahkan, DingTalk akan melancarkan Aplikasi mudah alih pembangun dan menghantar parameter tiket kebenaran sementara `code`. Kemudian, panggil API maklumat pengguna peribadi DingTalk untuk mendapatkan maklumat Asas pengguna yang log masuk, termasuk Nombor Telefon, Nama DingTalk, URL Gambar Profil DingTalk, dan lain-lain.
