## Gambaran keseluruhan aliran integrasi

Artikel ini menerangkan cara mencipta aplikasi dalaman dan menggunakan API pengurusan pengguna yang disediakan oleh **pengurusan Kenalan** untuk mencipta, mendapatkan semula, mengemas kini, dan memadam pekerja dalam organisasi anda.

Langkah 1: Dapatkan kelayakan aplikasi, termasuk client ID dan Client Secret.

Langkah 2: Mohon kebenaran API untuk pengurusan Kenalan.

Langkah 3: Dapatkan access_token aplikasi dalaman sebagai kelayakan akses aplikasi. Access token digunakan untuk mengesahkan pemanggil apabila sesuatu API dipanggil.

Langkah 4: Panggil API Kenalan:

1. Panggil Server API [Cipta pengguna](/open/development/user-information-creation) untuk mencipta pengguna dan mendapatkan `userid`.

   - Untuk menambah pekerja ke Jabatan root, hantar `1` sebagai parameter. Contoh ini menambah pekerja ke Jabatan root.
   - Untuk menambah pekerja ke jabatan tertentu, panggil dahulu [Dapatkan senarai ID subjabatan](/open/development/obtain-the-list-of-sub-department-ids) untuk mendapatkan ID jabatan, kemudian hantar sebagai parameter jabatan semasa mencipta pengguna.
2. Dengan `userid`, panggil Server API [Tanya butiran pengguna](/open/development/query-user-details) untuk mendapatkan semula maklumat terperinci pengguna.
3. Dengan `userid`, panggil Server API [Kemas kini maklumat pengguna](/open/development/user-information-update) untuk mengemas kini maklumat pengguna.
4. Dengan `userid`, panggil Server API [Padam pengguna](/open/development/delete-a-user) untuk memadam pengguna.

## Prasyarat

Lengkapkan aliran [pembuatan dan konfigurasi aplikasi](/open/dingstart/create-application).

## Langkah 1: Dapatkan kelayakan aplikasi

1. Pilih aplikasi sasaran untuk masuk ke halaman butiran aplikasi, dan klik **Maklumat asas** > **Kelayakan dan maklumat asas**.
2. Dapatkan client ID dan Client Secret.

## Langkah 2: Tambah kebenaran API

Klik **Konfigurasi pembangunan** > **Urus kebenaran**. Dalam kotak carian kebenaran, masukkan `qyapi_manage_addresslist` dan `qyapi_get_department_list`, kemudian mohon kebenaran tersebut.

## Langkah 3: Dapatkan kelayakan akses aplikasi (access token)

### Penting

- Untuk perbezaan antara versi Server API, lihat API lama berbanding API baharu.
- Untuk memuat turun SDK Server API, lihat Muat turun SDK bahagian pelayan.

Gunakan client ID dan Client Secret yang diperoleh dalam Langkah 1 untuk mendapatkan access_token aplikasi dalaman sebagai kelayakan akses aplikasi.

```java
public void getAccessToken() throws ApiException {
        DingTalkClient client = new DefaultDingTalkClient("https://oapi.dingtalk.io/gettoken");
        OapiGettokenRequest req = new OapiGettokenRequest();
        req.setAppkey("dingxxxxxxxxxhgn");
        req.setAppsecret("9G_xxxxxxxxxxxxxxx1JDf0Qq3nexxxxxxxxGIO");
        req.setHttpMethod("GET");
        OapiGettokenResponse rsp = client.execute(req);
        System.out.println(rsp.getBody());
    }
```
