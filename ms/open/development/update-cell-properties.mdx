Panggil API ini untuk mengemas kini maklumat sel, termasuk nilai sel, warna latar belakang, pautan hiper, saiz fon, jajaran mendatar, jajaran menegak, dan lain-lain.

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/doc/workbooks/{workbookId}/sheets/{sheetId}/ranges/{rangeAddress}` |
| Kaedah HTTP | PUT |
| Jenis aplikasi yang disokong | appType-Aplikasi dalaman　appType-Aplikasi perusahaan pihak ketiga |
| Kebenaran diperlukan | permission-Document.Workbook.Write-Kebenaran tulis DingTalk Spreadsheet |

### Header permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Dapatkan seperti berikut:   - Untuk aplikasi dalaman, panggil API [Dapatkan access token aplikasi dalaman](/ms/open/development/obtain-the-access-token-of-an-internal-app). - Untuk aplikasi perusahaan pihak ketiga, panggil API [Dapatkan access token organisasi yang diberi kuasa untuk aplikasi pihak ketiga](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1). |

### Parameter laluan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| workbookId | String | Ya | ID fail Buku Kerja. `nodeId(dentryUuid)` yang dikembalikan oleh API [Knowledge Base](/ms/open/development/knowledge-base-overview) ialah `workbookId` bagi Buku Kerja tersebut. Dapatkan dengan memanggil API [Dapatkan nod](https://open.dingtalk.com/document/development/get-node) atau API [Cipta dokumen Knowledge Base](/ms/open/development/create-team-space-document). |
| sheetId | String | Ya | ID atau nama Helaian Kerja.   - Untuk aplikasi dalaman, panggil API [Dapatkan semua Helaian Kerja](/ms/open/development/obtain-all-worksheets) untuk mendapatkan nilai `id` atau `name`. - Untuk aplikasi perusahaan pihak ketiga, panggil API [Cipta Helaian Kerja](/ms/open/development/create-a-worksheet) untuk mendapatkan `id` dan `name`. |
| rangeAddress | String | Ya | Alamat julat. |

### Parameter kueri

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| operatorId | String | Ya | unionId pengendali. Panggil API [Tanya butiran pengguna](/ms/open/development/query-user-details) untuk mendapatkannya.      Jika pengendali tidak mempunyai kebenaran, API akan mengembalikan ralat `The operator has no permission`. |

### Contoh permintaan

HTTP

```http
PUT /v1.0/doc/workbooks/e54Lqxxxxx/sheets/Sheet1/ranges/A1:B1?operatorId=ppgAQuxxxxx HTTP/1.1
Host:api.dingtalk.io
x-acs-dingtalk-access-token:f86e0bxxx
Content-Type:application/json

{
  "horizontalAlignments" : [ [ "general" ] ],
  "numberFormat" : "@",
  "wordWrap" : "autoWrap",
  "values" : [ [ "text" ] ],
  "complexValues" : [ [ "text" ] ],
  "backgroundColors" : [ [ "#ff0000" ] ],
  "fontColors" : [ [ "#000000" ] ],
  "fontSizes" : [ [ 14 ] ],
  "fontWeights" : [ [ "bold" ] ],
  "hyperlinks" : [ [ {
    "type" : "path",
    "link" : "https://www.dingtalk.io",
    "text" : "DingTalk"
  } ] ],
  "verticalAlignments" : [ [ "middle" ] ]
}
```

## Respons

### Isi respons

| Nama | Jenis | Penerangan |
| --- | --- | --- |
| a1Notation | String | Alamat julat yang telah dikemas kini. |

### Contoh isi respons

```text
HTTP/1.1 200 OK
Content-Type:application/json

{
  "a1Notation" : "A1"
}
```
