---
title: "Tetapkan kriteria penapis"
description: "Panggil API ini untuk menetapkan atau mengemas kini kriteria penapis bagi lajur tertentu dalam penapis global, sesuai untuk mengawal ketepatan skop keterlihatan satu lajur."
---

Panggil API ini untuk menetapkan atau mengemas kini kriteria penapis bagi lajur tertentu dalam penapis global. Ini sesuai untuk senario yang memerlukan kawalan tepat terhadap skop data yang boleh dilihat bagi satu lajur.

## Penerangan panggilan API

Kriteria yang baharu dikonfigurasikan akan menggantikan sebarang kriteria penapis sedia ada bagi lajur tersebut, dan rekod yang tidak memenuhi kriteria akan disembunyikan secara automatik.

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/doc/workbooks/{workbookId}/sheets/{sheetId}/filter/setColumnFilterCriteria` |
| Kaedah HTTP | POST |
| Jenis aplikasi yang disokong | appType-Aplikasi dalaman |
| Kebenaran | permission-Document.Workbook.Write-Kebenaran tulis DingTalk Spreadsheet |

### Pengepala permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Untuk mendapatkannya, panggil API [Dapatkan access token aplikasi dalaman](/ms/open/development/obtain-the-access-token-of-an-internal-app). |

### Parameter laluan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| workbookId | String | Ya | ID fail spreadsheet. `nodeId(dentryUuid)` yang dikembalikan oleh [API Knowledge Base](/ms/open/development/knowledge-base-overview) ialah `workbookId` spreadsheet tersebut. Untuk mendapatkannya, panggil API [Dapatkan node](https://open.dingtalk.com/document/orgapp/get-node) atau [Cipta dokumen Knowledge Base](/ms/open/development/create-team-space-document). |
| sheetId | String | Ya | ID atau nama Helaian Kerja. Untuk mendapatkan nilai parameter id atau name, panggil API [Dapatkan semua Helaian Kerja](/ms/open/development/obtain-all-worksheets). |

### Parameter pertanyaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| operatorId | String | Ya | unionId pengendali.   - Untuk mendapatkan nilai parameter unionid, panggil API [Dapatkan maklumat pengguna menggunakan kod Log masuk senyap](/ms/open/development/obtain-the-userid-of-a-user-by-using-the-log-free). - Untuk mendapatkan nilai parameter unionid, panggil API [Tanya butiran pengguna](/ms/open/development/query-user-details).       Jika pengendali tidak mempunyai kebenaran, API akan mengembalikan ralat `The operator has no permission`. |

### Isi permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| column | Long | Ya | Ofset lajur relatif kepada lajur pertama dalam julat penapis, bermula daripada 0. Contohnya, jika julat penapis ialah `B1:E10`, `column=0` mewakili lajur B, dan `column=1` mewakili lajur C. |
| filterCriteria | Object | Ya | Objek kriteria penapis. |
| filterType | String | Ya | Jenis penapis. Nilai sah:   - **values**: tapis mengikut nilai - **color**: tapis mengikut warna - **condition**: tapis mengikut syarat |
| visibleValues | Array of String | Tidak | Nilai yang boleh dilihat. |
| backgroundColor | String | Tidak | Warna yang boleh dilihat apabila menapis mengikut warna latar belakang, dalam format heksadesimal (seperti `#FF0000`). Apabila `filterType` ialah `color`, sama ada `backgroundColor` atau `fontColor` diperlukan. |
| fontColor | String | Tidak | Warna yang boleh dilihat apabila menapis mengikut warna fon, dalam format heksadesimal (seperti `#00FF00`). Apabila `filterType` ialah `color`, sama ada `backgroundColor` atau `fontColor` diperlukan. |
| conditions | Array | Tidak | Senarai syarat apabila menapis mengikut syarat. Maksimum 2 syarat disokong. Parameter ini diperlukan apabila `filterType` ialah `condition`. |
| operator | String | Tidak | Operator syarat. Nilai sah:   - **equal**: sama dengan - **not-equal**: tidak sama dengan - **contains**: mengandungi - **not-contains**: tidak mengandungi - **starts-with**: bermula dengan - **not-starts-with**: tidak bermula dengan - **ends-with**: berakhir dengan - **not-ends-with**: tidak berakhir dengan - **greater**: lebih besar daripada - **greater-equal**: lebih besar atau sama dengan - **less**: kurang daripada - **less-equal**: kurang atau sama dengan |
| value | String | Tidak | Nilai perbandingan. |
| conditionOperator | String | Tidak | Hubungan logik antara beberapa syarat. Nilai sah: **and**: DAN (lalai) **or**: ATAU. Parameter ini berkuat kuasa apabila `conditions` mengandungi 2 syarat. |
