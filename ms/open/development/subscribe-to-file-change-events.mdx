Panggil API ini untuk melanggan peristiwa perubahan fail.

## Penerangan panggilan API

1. Di Developer Backend, pergi ke App Event Subscription dan aktifkan langganan peristiwa storan.

2. Panggil API ini untuk menentukan skop langganan sebagai organisasi atau ruang storan tertentu.

### Nota

   Mengaktifkan suis langganan peristiwa storan di Developer Backend sahaja tidak mencukupi untuk menerima peristiwa callback. Anda juga perlu memanggil API ini.

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/v1.0/storage/events/subscribe |
| Kaedah HTTP | POST |
| Jenis aplikasi disokong | appType-Aplikasi dalaman　appType-Aplikasi perusahaan pihak ketiga |
| Kebenaran diperlukan | permission-Storage.Event.Write-Kebenaran tulis untuk langganan peristiwa perubahan fail storan organisasi |

### Pengepala permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Dapatkan seperti berikut:   - Untuk aplikasi dalaman, panggil API [Dapatkan access token aplikasi dalaman](/ms/open/development/obtain-the-access-token-of-an-internal-app#). - Untuk aplikasi perusahaan pihak ketiga, panggil API [Dapatkan access token organisasi yang dibenarkan untuk aplikasi pihak ketiga](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#). |

### Parameter query

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| unionId | String | Ya | unionId bagi pengendali. Panggil API [Tanyakan butiran pengguna](/ms/open/development/query-user-details#) untuk mendapatkannya. |

### Isi permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| scopeId | String | Ya | ID yang berkaitan dengan skop langganan.   - Apabila nilai parameter scope ialah ORG, scopeId sepadan dengan ID organisasi (corpId). Lihat [Konsep asas - CorpId](/ms/open/dingstart/basic-concepts-beta#section-bbk-mv0-oxd). - Apabila scope ialah SPACE, scopeId sepadan dengan ID ruang storan. Panggil API [Tambah ruang](/ms/open/development/add-space#) untuk mendapatkan id. |
| scope | String | Ya | Skop langganan.   - ORG: organisasi - SPACE: ruang |

### Contoh permintaan

HTTP

```http
POST /v1.0/storage/events/subscribe?unionId=union_id HTTP/1.1
Host:api.dingtalk.io
x-acs-dingtalk-access-token:xxxxx
Content-Type:application/json

{
  "scopeId" : "SPACE",
  "scope" : "SPACE"
}
```

| Nama | Jenis | Penerangan |
| --- | --- | --- |
| success | Boolean | Sama ada operasi berjaya. true menunjukkan berjaya. |

### Contoh isi respons

```text
HTTP/1.1 200 OK
Content-Type:application/json

{
  "success" : true
}
```

| 500 | systemError | %s | Ralat sistem |
