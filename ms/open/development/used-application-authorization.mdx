## Langkah 1: Cipta aplikasi DingTalk

1. Log masuk ke [DingTalk Developer Console](https://open-dev.dingtalk.io/#/corpeapp).
2. Klik App Development dan cipta aplikasi dalaman atau aplikasi perusahaan pihak ketiga.
3. Pada halaman butiran aplikasi, dapatkan Client ID (dahulunya App Key/SuiteKey) dan Client Secret (dahulunya App Secret/SuiteSecret) aplikasi tersebut.

## Langkah 2: Dapatkan kredensial akses aplikasi

Panggil API [Get the access token of an internal app](/open/development/obtain-the-access-token-of-an-internal-app) atau API Get the access token of a third-party app's authorized organization untuk menjana access token.
