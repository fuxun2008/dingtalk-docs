---
title: "Kemas kini paparan penapis"
description: "Ketahui cara mengemas kini nama, julat dan syarat penapis paparan penapis DingTalk Spreadsheet melalui API, sesuai untuk menyesuaikan paparan sedia ada."
---

Panggil API ini untuk mengemas kini nama, julat atau syarat penapis bagi paparan penapis tertentu. Semua medan adalah pilihan, dan hanya medan yang anda hantar akan dikemas kini. API ini sesuai untuk menyesuaikan paparan penapis sedia ada—contohnya, menamakan semula paparan untuk memudahkan pengenalan, mengembangkan julat penapis untuk merangkumi lajur data baharu, atau mengubah suai peraturan penapis bagi sesuatu lajur supaya selari dengan keperluan perniagaan terkini.

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/doc/workbooks/{workbookId}/sheets/{sheetId}/filterViews/{filterViewId}` |
| Kaedah HTTP | PATCH |
| Jenis aplikasi disokong | appType-Aplikasi dalaman |
| Kebenaran diperlukan | permission-Document.Workbook.Write-Kebenaran tulis DingTalk Spreadsheet |

### Header permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Panggil API [Dapatkan access token aplikasi dalaman](/open/development/obtain-the-access-token-of-an-internal-app) untuk mendapatkannya. |

### Parameter laluan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| workbookId | String | Ya | ID fail Spreadsheet. `nodeId(dentryUuid)` yang dikembalikan oleh [API Knowledge Base](/open/development/knowledge-base-overview) ialah `workbookId` Spreadsheet. Dapatkannya dengan memanggil API [Dapatkan nod](https://open.dingtalk.com/document/orgapp/get-node) dan [Cipta dokumen Knowledge Base](/open/development/create-team-space-document). |
| sheetId | String | Ya | ID atau nama Helaian Kerja. Panggil API [Dapatkan semua helaian kerja](/open/development/obtain-all-worksheets) untuk mendapatkan nilai parameter id atau name. |
| filterViewId | String | Ya | ID paparan penapis. |

### Parameter pertanyaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| operatorId | String | Ya | unionId pengendali operasi.   - Panggil API [Dapatkan ID pengguna dengan menggunakan kod log masuk senyap](/open/development/obtain-the-userid-of-a-user-by-using-the-log-free) untuk mendapatkan nilai parameter unionid. - Panggil API [Tanya butiran pengguna](/open/development/query-user-details) untuk mendapatkan nilai parameter unionid.       Jika pengendali operasi tidak mempunyai kebenaran, API akan mengembalikan ralat `The operator has no permission`. |

### Isi permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| name | String | Tidak | Nama baharu paparan penapis. Jika tidak dihantar, nama tidak akan dikemas kini. |
| range | String | Tidak | Julat baharu paparan penapis, dalam notasi A1. Jika tidak dihantar, julat tidak akan dikemas kini. |
| criteria | `Map<String, Object>` | Tidak | Syarat penapis lajur yang hendak dikemas kini. Key ialah ofset lajur (relatif kepada lajur pertama dalam range, bermula dari 0), dan value ialah objek syarat penapis. Hanya lajur yang dihantar akan dikemas kini; syarat penapis sedia ada bagi lajur lain tidak terjejas. Jika tidak dihantar, syarat penapis tidak akan dikemas kini. |
|  | Object | Tidak | Objek syarat penapis bagi lajur semasa. |
| filterType | String | Tidak | Jenis penapis. Nilai yang sah:   - **values**: Tapis mengikut nilai - **color**: Tapis mengikut warna - **condition**: Tapis mengikut syarat |
| visibleValues | Array of String | Tidak | Nilai yang kelihatan. |
| conditions | Array | Tidak | Senarai syarat penapis apabila menapis mengikut syarat. Sah apabila `filterType` ialah `condition`. Setiap objek syarat mengandungi medan `operator` dan `value`. |
| operator | String | Tidak | Operator syarat. Nilai yang sah:   - **equal**: Sama dengan - **not-equal**: Tidak sama dengan - **contains**: Mengandungi - **not-contains**: Tidak mengandungi - **starts-with**: Bermula dengan - **not-starts-with**: Tidak bermula dengan - **ends-with**: Berakhir dengan - **not-ends-with**: Tidak berakhir dengan - **greater**: Lebih besar daripada - **greater-equal**: Lebih besar daripada atau sama dengan - **less**: Lebih kecil daripada - **less-equal**: Lebih kecil daripada atau sama dengan |
| value | String | Tidak | Nilai syarat. |
| conditionOperator | String | Tidak | Hubungan logik antara pelbagai syarat. Nilai yang sah: `and`, `or`. Nilai lalai: `and`. Sah apabila `filterType` ialah `condition` dan pelbagai syarat ditentukan. |
| backgroundColor | String | Tidak | Nilai warna (heksadesimal, seperti `#FF0000`) apabila menapis mengikut warna latar belakang. Sah apabila `filterType` ialah `color`. Tentukan sama ada medan ini atau `fontColor`. |
| fontColor | String | Tidak | Nilai warna (heksadesimal, seperti `#FF0000`) apabila menapis mengikut warna fon. Sah apabila `filterType` ialah `color`. Tentukan sama ada medan ini atau `backgroundColor`. |

| range | String | Julat paparan penapis yang telah dikemas kini, dalam notasi A1. |

### Contoh isi respons

```text
HTTP/1.1 200 OK
Content-Type:application/json

{
  "id" : "fv-xxxxx",
  "name" : "Penapis data jualan",
  "range" : "A1:E20"
}
```
