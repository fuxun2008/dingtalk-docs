| space | [SpaceModel](#SpaceModel) |  | Maklumat Knowledge Base. |
| dentryUuid | String | m0Xwxxxxx | Pengecam unik global nod. |
| dentryType | String | file | Jenis nod.   - file: fail - folder: folder. |
| extension | String | adoc | Sambungan fail.  **Nota**    Hanya dikembalikan untuk fail. |
| name | String | DingTalk Docs.adoc | Nama nod. |
| url | String | https://xxx.yy | URL akses nod. |
| path | String | Test Organization/Test Knowledge Base/abc | Laluan nod. |
| hasChildren | Boolean | false | Sama ada nod mempunyai nod anak. |
| updater | Object |  | Maklumat Terakhir diubah oleh. |

| visitorInfo | Object |  | Kebenaran dan maklumat lain pelawat pada nod semasa. |
| spaceActions | Array of String | PUBLIC_SHARE_SPACE,GET_SPACE | Senarai tindakan bagi ruang.   - PUBLIC_SHARE_SPACE: terbitkan Knowledge Base secara awam - HANDOVER_WORKSPACE: serahkan ruang - UPDATE_SPACE: kemas kini maklumat asas ruang - GET_SPACE: tanya maklumat asas ruang - GET_SPACE_SECURITY: tanya tetapan keselamatan ruang - DELETE_SPACE: padam ruang secara kekal - MANAGE_SPACE_SECURITY: urus tetapan keselamatan ruang - GET_SPACE_MEMBER: tanya pengguna ruang - MANAGE_SPACE_PIN: urus penyematan ruang - USE_SPACE_TEMPLATE: cipta menggunakan templat ruang - RECYCLE_SPACE: arkibkan ruang - GET_SPACE_TEMPLATE: tanya dan pratonton templat ruang - RECOVER_SPACE: pulihkan ruang - MANAGE_SPACE_TEMPLATE: urus templat ruang - MANAGE_SPACE_MEMBER: urus pengguna ruang - RENAME_SPACE: namakan semula ruang |
| dentryActions | Array of String | COPY_DENTRY, GET_DENTRY_MEMBER | Senarai tindakan bagi nod.   - GET_DENTRY: tanya maklumat asas nod - LIST_CHILD: senaraikan nod anak - CREATE_CHILD: cipta nod anak - RENAME_DENTRY: namakan semula nod - MOVE_DENTRY: alihkan nod - COPY_DENTRY: salin nod - RECYCLE_DENTRY: kitar semula nod - RECOVER_DENTRY: pulihkan nod - DELETE_DENTRY: padam nod - GET_DENTRY_MEMBER: dapatkan senarai pengguna nod - MANAGE_DENTRY_MEMBER: urus pengguna nod - PREVIEW: pratonton dokumen - CONTENT_COPY: salin kandungan - DOWNLOAD_ATTACHMENT: muat turun lampiran, gambar, dan sumber lain dalam dokumen - EXPORT: eksport ke format lain - EXPORT_IMAGE: eksport sebagai gambar panjang - UPLOAD_ATTACHMENT: muat naik lampiran, gambar, dan sumber lain dalam dokumen - EDIT: edit dokumen - READ_HISTORY: paparkan versi sejarah - EDIT_HISTORY: edit versi sejarah - SAVE_AS: simpan sebagai - SAVE_AS_TEMPLATE: simpan sebagai templat - LINK_SHARE: kongsi melalui pautan atau kad - PUBLIC_SHARE: kongsi secara awam - CHANGE_PERMISSION_MODE: tukar mod kebenaran - TEMPORARY_SHARE_NODE: kongsi sementara nod - DOWNLOAD: muat turun - UPLOAD: muat naik - SAVE_AS_QUICK_LINK: simpan sebagai pintasan - SEND_COPY_FILE: hantar salinan - CLOUD_PRINT: cetakan awan - MANAGE_SECURITY_SETTING: urus tetapan keselamatan - UPLOAD_FOLDER: muat naik folder - IMPORT: import - IMPORT_FOLDER: import folder |
| roleCode | String | 5 | Peranan akses pengguna semasa untuk ruang ini.   - 0: tiada kebenaran - 1: paparan sahaja - 2: paparan/muat turun - 3: edit - 4: urus - 5: pemilik |

## LinkSourceInfo

Maklumat data asal yang dirujuk oleh pautan.

| Nama | Jenis | Contoh | Penerangan |
| --- | --- | --- | --- |
| id | String | abc | ID fail sumber yang dikaitkan dengan pintasan (unik dalam ruang). |
| spaceId | String | def | ID ruang tempat fail sumber yang dikaitkan dengan pintasan berada. |
| linkType | Long | 0 | Jenis pintasan.   - 0: pintasan umum - 1: pintasan Mesyuarat Segera - 2: pintasan log - 3: pintasan Mesyuarat Segera 2.0 |
| extension | String | docx | Sambungan fail sumber yang dikaitkan dengan pintasan. |
| iconUrl | Object |  | Maklumat ikon untuk pintasan bukan umum. |
| small | String | def | Ikon yang diserlahkan apabila dipilih. |
| line | String | gh | Ikon kandungan lalai. |
