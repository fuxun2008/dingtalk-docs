## Struktur data

- Base, iaitu dokumen AI Table.

  - `baseId` mengenal pasti secara unik dokumen AI Table. Anda boleh mendapatkan `baseId` melalui cara berikut.

    | **Dapatkan daripada URL** | **Dapatkan daripada panel maklumat dokumen** | **Dapatkan melalui API lain**  Panggil API [Get node list](/open/development/get-node-list). **Nota**  Apabila AI Table dicipta, nilai `docType` ialah `BASE`. |
    | --- | --- | --- |
- Sheet (jadual). Dokumen AI Table biasanya mengandungi beberapa jadual, dan mesti mengandungi sekurang-kurangnya satu jadual.

  - Semua API yang perlu mengakses jadual boleh menggunakan sama ada `sheetId` atau `sheetName` sebagai parameter input.
  - Anda boleh mendapatkan `sheetId` dengan memanggil API [Get all tables](/open/development/api-notable-getallsheets).

### Nota

    `sheetId` hanya unik dalam dokumen tersebut dan bukan unik secara global.
  - `sheetName` ialah nama jadual yang boleh dilihat di bahagian hadapan, seperti `Task management` dalam rajah di bawah.
- Medan. Setiap lajur dalam jadual ialah medan, dan jadual biasanya mengandungi beberapa medan.

  - Semua API yang perlu mengakses medan boleh menggunakan sama ada `fieldId` atau `fieldName` sebagai parameter input.
  - Anda boleh mendapatkan `fieldId` dengan memanggil API [Get all fields](/open/development/api-noatable-getallfields).

### Nota

    `fieldId` hanya unik dalam dokumen tersebut dan bukan unik secara global.
  - `fieldName` ialah nama medan yang boleh dilihat di bahagian hadapan, seperti `Priority` dalam rajah di bawah.
  - Lajur pertama bagi setiap jadual ialah "medan utama". Ia hanya menyokong jenis medan tertentu dan tidak boleh dipadamkan. Untuk melihat jenis medan yang disokong:

    - Buka mana-mana AI Table.
    - Edit medan utama.
    - Lihat jenis medan yang boleh dikonfigurasikan.
- Rekod. Setiap baris dalam jadual ialah rekod, dan jadual biasanya mengandungi beberapa rekod.

  - Semua API yang perlu mengakses rekod mesti menggunakan `recordId`.
  - Anda boleh mendapatkan `recordId` dengan memanggil API seperti [Insert records](/open/development/api-notable-insertrecords) atau [List records](/open/development/api-notable-listrecords).

### Nota

    `recordId` hanya unik dalam dokumen tersebut dan bukan unik secara global.

## Atribut medan

Kawasan atribut medan ditunjukkan dalam rajah di bawah.

Untuk atribut yang disokong oleh pelbagai jenis medan, rujuk jadual berikut.

| **Nama medan** | **Jenis (type)** | **Atribut (property)** |
| --- | --- | --- |
| Teks | text | Tiada |
| Nombor | number | Nilai `formatter`: `INT` / `FLOAT_1` / `FLOAT_2` / `FLOAT_3` / `FLOAT_4` (kekalkan N tempat perpuluhan) / `THOUSAND` / `THOUSAND_FLOAT` (pemisah ribuan) / `PERCENT` / `PERCENT_FLOAT` (peratus) |
| Mata wang | currency | `currencyType`: `CNY` / `HKD` / `USD` / `EUR` / `GBP` / `MOP` / `VND` / `JPY` / `KRW` / `AED` / `AUD` / `BRL` / `CAD` / `CHF` / `INR` / `IDR` / `MXN` / `MYR` / `PHP` / `PLN` / `RUB` / `SGD` / `THB` / `TRY` / `TWD`; nilai `formatter`: `INT` / `FLOAT_1` … `FLOAT_4` |
| Pilih | singleSelect | `{ choices: [{ name: "optionName1" }, { name: "optionName2" }] }` |
| Pilih Banyak | multipleSelect | Sama seperti "Pilih". |
| Tarikh | date | Nilai `formatter`: `YYYY-MM-DD` / `YYYY-MM-DD HH:mm` / `YYYY/MM/DD` / `YYYY/MM/DD HH:mm` |
| Pengguna | user | `{ multiple: boolean }` (pilih banyak disokong; lalai kepada true) |
| Jabatan | department | `{ multiple: boolean }` (pilih banyak disokong; lalai kepada true) |
| Lampiran | attachment | Tiada |
| Pautan Sehala | unidirectionalLink | `{ multiple: boolean, linkedSheetId: "xxx" }` (`linkedSheetId` ialah ID jadual terpaut) |
| Pautan Dua Hala | bidirectionalLink | `{ multiple: boolean, linkedSheetId: "xxx", linkedFieldId: "yyy" }` (jangan hantar `linkedFieldId` semasa mencipta medan) |
| Pautan | url | Tiada |

## Format nilai rekod

Paparan nilai rekod (juga dikenali sebagai nilai medan) ditunjukkan dalam rajah di bawah.

Untuk format yang digunakan oleh pelbagai jenis medan, rujuk jadual berikut.

| **Nama medan** | **Jenis (type)** | **Nilai tetapan (format yang digunakan semasa menyisipkan atau mengemas kini rekod)** | **Nilai pulangan (format yang dikembalikan apabila nilai rekod dikembalikan)** |
| --- | --- | --- | --- |
| Teks | text | `"TextString"` (string) | `"TextString"` (string) |
| Nombor | number | `123` (menyokong integer / float / string) | `"123"` (nilai berangka dikembalikan sebagai string) |
| Mata wang | currency | `123` (menyokong integer / float / string) | `"123"` (nilai berangka dikembalikan sebagai string) |
| Pilih | singleSelect | `"optionName1"` (nama pilihan) | `{ "id": "id", "name": "optionName1" }` (id ialah ID pilihan; name ialah nama pilihan) |
| Pilih Banyak | multipleSelect | `["optionName1", "optionName2"]` (nama pilihan) | `[{ "id": "id1", "name": "optionName1" }, { "id": "id2", "name": "optionName2" }]` |
| Tarikh | date | `1688601600000` (cap masa) atau `"2023-12-20 03:00"` (string ISO 8601) | `1688601600000` (cap masa) |
| Pengguna | user | `[{ unionId: "xxx" }]` | `[{ unionId: "xxx" }]` |
| Jabatan | department | `[{ deptId: "xxx" }]` | `[{ deptId: "xxx" }]` |
| Lampiran | attachment | Untuk maklumat lanjut, rujuk [Upload attachment](/open/development/upload-attachment). | `[{ "filename": "image.xlsx", "size": 92250, "type": "xls", "url": "xxx" }]`  **Nota**  `url` ialah pautan capaian lampiran. Apabila lampiran ialah dokumen dalam talian, pautan tersebut menunjuk kepada dokumen dalam talian dan tidak akan tamat tempoh. Apabila lampiran ialah jenis fail lain, pautan tersebut ialah pautan muat turun dengan **tempoh sah terhad**, dan menjadi tidak boleh diakses selepas suatu tempoh masa. |
| Pautan Sehala | unidirectionalLink | `{ "linkedRecordIds": ["xxx", "yyy"] }` | `{ "linkedRecordIds": ["xxx", "yyy"] }`  **Nota**  Atribut medan mengandungi `sheetId` yang terpaut. Bersama `recordId` yang dikembalikan di sini, anda boleh memanggil API [Get record](/open/development/api-getrecord) untuk mendapatkan nilai rekod terpaut. |
| Pautan Dua Hala | bidirectionalLink | `{ "linkedRecordIds": ["xxx", "yyy"] }` | `{ "linkedRecordIds": ["xxx", "yyy"] }` |
| Pautan | url | `{ "text": "Dingtalk", "link": "https://dingtalk.io" }` | `{ "text": "Dingtalk", "link": "https://dingtalk.io" }` |
