---
title: "Create a conditional formatting rule"
description: "Panggil API ini untuk mencipta peraturan pemformatan bersyarat dalam Helaian Kerja yang ditentukan, yang secara automatik menggunakan warna fon atau latar belakang berdasarkan nilai sel atau pendua, sesuai untuk senario visualisasi data."
---

Panggil API ini untuk mencipta peraturan Pemformatan Bersyarat dalam Helaian Kerja yang ditentukan bagi Buku Kerja DingTalk. Peraturan ini secara automatik menggunakan gaya penyerlahan berdasarkan nilai sel atau status pendua. Ini berguna untuk senario di mana data perlu ditandakan secara visual — contohnya, menyerlahkan sel yang bernilai di bawah sasaran dengan warna merah, menyerlahkan entri pendua untuk semakan mudah, atau membezakan nilai dalam julat tertentu dengan warna latar belakang yang ditetapkan. Setelah peraturan dicipta, sel yang memenuhi syarat akan secara automatik menggunakan warna fon atau warna latar belakang yang ditentukan, tanpa perlu menetapkannya secara manual satu per satu.

## Request

### Basic information

| Field | Value |
| --- | --- |
| HTTP URL | `https://api.dingtalk.io/v1.0/doc/workbooks/{workbookId}/sheets/{sheetId}/conditionalFormattingRules` |
| HTTP Method | POST |
| Supported app type | appType-Aplikasi dalaman |
| Required permissions | permission-Document.Workbook.Write-Kebenaran tulis DingTalk Spreadsheet |

### Pengepala permintaan

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Yes | Kredensial akses untuk memanggil API ini. Panggil API [Get the access token of an internal app](/ms/open/development/obtain-the-access-token-of-an-internal-app) untuk mendapatkannya. |

### Parameter laluan

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| workbookId | String | Yes | ID Fail Spreadsheet. `nodeId(dentryUuid)` yang dikembalikan oleh [Knowledge Base API](/ms/open/development/knowledge-base-overview) ialah `workbookId` Spreadsheet tersebut. Panggil API [Get node](https://open.dingtalk.com/document/development/get-node) atau [Create Knowledge Base document](/ms/open/development/create-team-space-document) untuk mendapatkannya. |
| sheetId | String | Yes | ID atau tajuk Helaian Kerja. Panggil API [Get all worksheets](/ms/open/development/obtain-all-worksheets) untuk mendapatkan ID dan tajuk Helaian Kerja. |

### Parameter pertanyaan

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| operatorId | String | Yes | unionId pengendali. Panggil API [Query user details](/ms/open/development/query-user-details) untuk mendapatkannya. Jika pengendali tidak mempunyai kebenaran, API akan mengembalikan ralat `The operator has no permission`. |

### Isi permintaan

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| ranges | Array of String | Yes | Alamat Sel dalam notasi A1. |
| duplicateCondition | Object | No | Peraturan nilai pendua. |
| operator | String | No | Operator. Buat masa ini, hanya `duplicate` disokong, yang mewakili item pendua. |
| numberCondition | Object | No | Peraturan Nombor. |
| operator | String | No | Operator perbandingan. Nilai yang sah:   - **equal**: Sama dengan - **not-equal**: Tidak sama dengan - **greater**: Lebih besar daripada - **greater-equal**: Lebih besar daripada atau sama dengan - **less**: Kurang daripada - **less-equal**: Kurang daripada atau sama dengan - **between**: Antara dua nilai (termasuk kedua-duanya) - **not-between**: Tidak berada antara dua nilai |
| value1 | Any | No | value1 — Nilai perbandingan pertama (wajib). |
| value2 | Any | No | value2 — Nilai perbandingan kedua (pilihan). Ia diperlukan hanya apabila `operator` ialah `between` atau `not-between`, sebagai had atas julat tersebut. |
| cellStyle | Object | No | Gaya Sel bagi peraturan yang sedang dikonfigurasi. |
| backgroundColor | String | No | Warna latar belakang dalam notasi heksadesimal, contohnya, `#ff0000`. |
| fontColor | String | No | Warna Fon. |
