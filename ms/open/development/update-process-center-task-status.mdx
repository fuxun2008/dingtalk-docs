Panggil API ini untuk mengemas kini status tugasan tertentu dalam Pusat Proses.

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/v1.0/workflow/processCentres/tasks |
| Kaedah HTTP | PUT |
| Jenis aplikasi yang disokong | appType-Aplikasi dalaman　appType-Aplikasi perusahaan pihak ketiga |
| Kebenaran | permission-qyapi_aflow-Kebenaran pengurusan data aliran kerja kelulusan |

### Pengepala permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Dapatkannya seperti berikut:   - Aplikasi dalaman: Panggil API [Dapatkan access token aplikasi dalaman](/ms/open/development/obtain-the-access-token-of-an-internal-app). - Aplikasi perusahaan pihak ketiga: Panggil API untuk mendapatkan access token organisasi yang telah memberikan kebenaran kepada Aplikasi pihak ketiga. |

### Isi permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| processInstanceId | String | Tidak | ID Instans aliran kerja Kelulusan OA. Panggil API [Cipta instans](/ms/open/development/create-a-ticket-approval-instance) untuk mendapatkan nilai `processInstanceId`. |
| tasks | Array | Ya | Senarai tugasan Kelulusan OA. Maksimum: 20 tugasan. |
| taskId | Long | Ya | ID tugasan Kelulusan OA. Panggil API [Tanya tugasan Kelulusan OA yang disepadukan melalui Pusat Proses](/ms/open/development/query-oa-approval-tasks-integrated-through-process-center) untuk mendapatkan nilai taskId. |
| status | String | Ya | Status sasaran tugasan:   - **CANCELED**: Batalkan - **COMPLETED**: Selesai |
| result | String | Tidak | Keputusan tugasan.   - Jika status ialah **COMPLETED**, nyatakan keputusan tugasan:    - **AGREE**: Terima   - **REFUSE**: Tolak - Jika status ialah **CANCELED**, jangan hantar result. |
