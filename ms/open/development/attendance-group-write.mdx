Panggil API ini untuk mencipta kumpulan kehadiran.

## Permintaan

| **Maklumat asas** | |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/topapi/attendance/group/add |
| Kaedah HTTP | POST |
| Jenis aplikasi yang disokong | appType-Aplikasi dalaman |
| Kebenaran yang diperlukan | permission-qyapi_attendance_group_manage-Kebenaran pengurusan kumpulan kehadiran |

### Parameter pertanyaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | 4c9d5xxxx | Kelayakan aplikasi yang digunakan untuk memanggil API ini. Dapatkannya dengan memanggil API [Dapatkan access_token bagi Aplikasi dalaman](/ms/open/development/obtain-orgapp-token). |

| freecheck_work_days | Number[] | Tidak | [1,2,3,4,5,6,0] | Hari bekerja bagi kumpulan kehadiran waktu kerja fleksibel.  **Nota**     - 0 menandakan hari rehat. - Dari kiri ke kanan, nilai dalam array mewakili penjadualan syif bagi setiap hari dari Ahad hingga Sabtu. |

```curl
-d 'top_group=null'
```

## Respons

### Isi respons

| Nama | Jenis | Contoh | Penerangan |
| --- | --- | --- | --- |
| result | TopGroupVo |  | Hasil panggilan. |
| name | String | Kehadiran Syif Siang | Nama kumpulan kehadiran. |
| id | Number | 712070073 | ID kumpulan kehadiran. |
| success | Boolean | true | Menunjukkan sama ada panggilan berjaya.   - **true**: Berjaya - **false**: Gagal |
| errcode | Number | 0 | Kod pulangan. |
| errmsg | String | Ralat sistem | Penerangan kod pulangan. |
| request_id | String | 6pcx0i2ujtt9 | ID permintaan. |

Jika panggilan mengembalikan ralat, cari penyelesaian dalam dokumen [Kod ralat global](/ms/open/development/server-api-error-codes-1) berdasarkan mesej ralat.
