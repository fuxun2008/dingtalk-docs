---
title: "Kemas kini helaian kerja"
description: "Panggil API ini untuk mengemas kini atribut meta helaian kerja tertentu dalam DingTalk Spreadsheet, termasuk nama, keterlihatan, dan baris atau lajur beku, dengan pelbagai atribut boleh dikemas kini dalam satu permintaan."
---

Panggil API ini untuk mengubah suai metadata helaian kerja tertentu dalam DingTalk Spreadsheet, termasuk nama helaian kerja, keterlihatan, dan bilangan baris serta lajur beku. API ini sesuai untuk mengurus konfigurasi helaian kerja secara programatik dan menyokong kemas kini pelbagai atribut dalam satu permintaan. ID helaian kerja dikembalikan selepas kemas kini.

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/doc/workbooks/{workbookId}/sheets/{sheetId}` |
| Kaedah HTTP | PUT |
| Jenis aplikasi disokong | appType-Aplikasi dalaman |
| Kebenaran | permission-Document.Workbook.Write-Kebenaran tulis DingTalk Spreadsheet |

### Pengepala permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Untuk mendapatkan kredensial, panggil API [Dapatkan access token aplikasi dalaman](/open/development/obtain-the-access-token-of-an-internal-app). |

### Parameter laluan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| workbookId | String | Ya | ID fail spreadsheet. `nodeId(dentryUuid)` yang dikembalikan oleh [Knowledge Base API](/open/development/knowledge-base-overview) ialah `workbookId` bagi spreadsheet tersebut. Untuk mendapatkannya, panggil API [Get node](https://open.dingtalk.com/document/development/get-node) atau [Create a Knowledge Base document](/open/development/create-team-space-document). |
| sheetId | String | Ya | ID atau tajuk helaian kerja. Untuk mendapatkan id dan tajuk helaian kerja, panggil API [Get all worksheets](/open/development/obtain-all-worksheets). |

### Parameter kueri

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| operatorId | String | Ya | unionId bagi operator. Untuk mendapatkannya, panggil API [Query user details](/open/development/query-user-details). Jika operator tidak mempunyai kebenaran yang diperlukan, API mengembalikan ralat `The operator has no permission`. |

### Isi permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| frozenRowCount | Long | Tidak | Indeks baris di mana baris dibekukan. Bermula dari 1. Nilai 0 bermaksud tiada baris dibekukan. Contohnya, tetapkan nilai ini kepada 3 untuk membekukan baris 1 hingga 3. |
| frozenColumnCount | Long | Tidak | Indeks lajur di mana lajur dibekukan. Bermula dari 1. Nilai 0 bermaksud tiada lajur dibekukan. Contohnya, tetapkan nilai ini kepada 3 untuk membekukan lajur 1 hingga 3. |
| visibility | String | Tidak | Sama ada hendak menyembunyikan helaian kerja. Nilai yang sah:   - **visible**: Tunjukkan. - **hidden**: Sembunyikan. |
| name | String | Tidak | Nama baharu helaian kerja. |
