Panggil API ini untuk memadam gambar terapung daripada helaian kerja tertentu dalam DingTalk Spreadsheet. Pemadaman ini tidak boleh dibuat asal. Setelah dipadam, gambar akan dialih keluar daripada helaian kerja dan tidak boleh dipulihkan melalui API. API ini sesuai untuk senario seperti membersih gambar yang tidak digunakan atau menyusun semula susun atur visual helaian kerja.

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/doc/workbooks/{workbookId}/sheets/{sheetId}/floatImages/{id}` |
| Kaedah HTTP | DELETE |
| Jenis aplikasi yang disokong | appType-Aplikasi dalaman |
| Kebenaran diperlukan | permission-Document.Workbook.Write-Kebenaran menulis DingTalk Spreadsheet |

### Pengepala permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Panggil API [Dapatkan access token aplikasi dalaman](/ms/open/development/obtain-the-access-token-of-an-internal-app) untuk mendapatkannya. |

### Parameter laluan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| workbookId | String | Ya | ID fail hamparan. `nodeId(dentryUuid)` yang dikembalikan oleh [API Knowledge Base](/ms/open/development/knowledge-base-overview) adalah `workbookId` hamparan tersebut. Anda boleh mendapatkannya dengan memanggil API [Dapatkan nod](https://open.dingtalk.com/document/development/get-node) dan [Cipta dokumen knowledge base](/ms/open/development/create-team-space-document). |
| sheetId | String | Ya | ID atau tajuk helaian kerja. Panggil API [Dapatkan semua helaian kerja](/ms/open/development/obtain-all-worksheets) untuk mendapatkan ID dan tajuk helaian kerja. |
| id | String | Ya | ID gambar terapung. Dapatkan dengan memanggil API "Query floating images". |

### Parameter pertanyaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| operatorId | String | Ya | unionId pengendali. Panggil API [Query user details](/ms/open/development/query-user-details) untuk mendapatkannya. Jika pengendali tidak mempunyai kebenaran yang diperlukan, API akan mengembalikan ralat `The operator has no permission`. |
