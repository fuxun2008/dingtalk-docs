---
title: "Dapatkan ringkasan syif"
description: "Panggil API DingTalk ini untuk mendapatkan ringkasan semua syif kehadiran dalam organisasi menggunakan userId pengendali dan penomboran halaman berasaskan cursor."
---

Panggil API ini untuk menyemak semua syif. Dalam aplikasi Kehadiran DingTalk, syif ialah satu set peraturan, seperti waktu daftar masuk dan waktu rehat. Organisasi boleh mengkonfigurasikan berbilang syif mengikut keperluan perniagaan.

## Permintaan

| **Maklumat asas** | |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/topapi/attendance/shift/list |
| Kaedah HTTP | POST |
| Jenis aplikasi yang disokong | appType-Aplikasi dalaman　appType-Aplikasi perusahaan pihak ketiga |
| Kebenaran | permission-qyapi_attendance_group_read-Kebenaran baca kumpulan kehadiran |

### Parameter pertanyaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | bE74xxxx | Kelayakan aplikasi yang digunakan untuk memanggil API ini.   - Bagi Aplikasi dalaman, dapatkannya dengan memanggil [Dapatkan access_token Aplikasi dalaman](/ms/open/development/obtain-orgapp-token). - Bagi Aplikasi perusahaan pihak ketiga, dapatkannya dengan memanggil API untuk mendapatkan access_token organisasi pihak ketiga. |

### Isi permintaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| op_user_id | String | Ya | manager4220 | userId pengendali. |
| cursor | Number | Tidak | 0 | ID cursor. Nilai awal ialah 0. |

### Contoh permintaan

```curl
curl -X POST "https://api.dingtalk.io/topapi/attendance/shift/list" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=e47ef3ff-ff01-4da7-8aa8-53bc0ad47be3' \
-d 'cursor=1234' \
-d 'op_user_id=dd_test'
```

Java

```java
DingTalkClient client = new DefaultDingTalkClient("https://api.dingtalk.io/topapi/attendance/shift/list");
OapiAttendanceShiftListRequest req = new OapiAttendanceShiftListRequest();
req.setOpUserId("dd_test");
req.setCursor(0L);
OapiAttendanceShiftListResponse rsp = client.execute(req, access_token);
System.out.println(rsp.getBody());
```

Python

```python
import dingtalk.api

req=dingtalk.api.OapiAttendanceShiftListRequest("https://api.dingtalk.io/topapi/attendance/shift/list")

req.op_user_id="dd_test"
req.cursor=1234
try:
	resp= req.getResponse(access_token)
	print(resp)
except Exception,e:
	print(e)
```

PHP

```php
include "TopSdk.php";
date_default_timezone_set('Asia/Shanghai');

$c = new DingTalkClient(DingTalkConstant::$CALL_TYPE_OAPI, DingTalkConstant::$METHOD_POST , DingTalkConstant::$FORMAT_JSON);
$req = new OapiAttendanceShiftListRequest;
$req->setOpUserId("dd_test");
$req->setCursor("1234");
$resp = $c->execute($req, $access_token, "https://api.dingtalk.io/topapi/attendance/shift/list");
```

C#

```csharp
IDingTalkClient client = new DefaultDingTalkClient("https://api.dingtalk.io/topapi/attendance/shift/list");
OapiAttendanceShiftListRequest req = new OapiAttendanceShiftListRequest();

```

## Respons

### Isi respons

| Nama | Jenis | Contoh | Penerangan |
| --- | --- | --- | --- |
| result | PageResult |  | Hasil pertanyaan. |
| has_more | Boolean | false | Sama ada terdapat lebih banyak data.   - **true**: Ya - **false**: Tidak |
| cursor | Number | 678215070 | Kedudukan cursor bagi halaman seterusnya. |
| result | TopMinimalismShiftVo[] |  | Maklumat syif.  Setiap halaman mengembalikan 200 rekod. Hasil yang melebihi 200 rekod dipaparkan mengikut halaman. |
| name | String | A | Nama syif. |
| id | Number | 677995086 | ID syif. |
| success | Boolean | true | Sama ada permintaan berjaya.   - **true**: Berjaya - **false**: Gagal |
| errcode | Number | 0 | Kod pulangan. |
| errmsg | String | ok | Penerangan kod pulangan. |
| request_id | String | 1079sd06ne6zy | ID permintaan. |

### Contoh isi respons

### Kod ralat

Jika panggilan API ini mengembalikan ralat, cari penyelesaian dalam [Kod ralat global](/ms/open/development/server-api-error-codes-1) berdasarkan mesej ralat.
