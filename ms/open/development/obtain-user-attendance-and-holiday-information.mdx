Panggil API ini untuk menyemak maklumat cuti pekerja dalam julat masa yang ditetapkan.

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/v1.0/attendance/holidays |
| Kaedah HTTP | POST |
| Jenis aplikasi yang disokong | appType-Aplikasi dalaman　appType-Aplikasi perusahaan pihak ketiga |
| Kebenaran yang diperlukan | permission-qyapi_attendance_group_read-Kebenaran pertanyaan kumpulan kehadiran |

### Pengepala permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Dapatkannya seperti berikut:   - Aplikasi dalaman: Panggil API [Dapatkan access token aplikasi dalaman](/ms/open/development/obtain-the-access-token-of-an-internal-app). - Aplikasi perusahaan pihak ketiga: Panggil API untuk mendapatkan access token organisasi yang telah memberikan kebenaran kepada aplikasi pihak ketiga. |

### Isi permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| userIds | Array of String | Ya | Senarai pekerja. |
| workDateFrom | Long | Ya | Tarikh mula. |
| workDateTo | Long | Ya | Tarikh tamat. |

### Contoh permintaan

## Respons

### Isi respons

| Nama | Jenis | Penerangan |
| --- | --- | --- |
| result | Array | Senarai cuti pekerja. |
| userId | String | ID pengguna pekerja. |
| holidays | Array | Senarai cuti. |
| workDate | Long | Tarikh. |
| holidayName | String | Nama cuti. |
| holidayType | String | Jenis cuti:   - festival: Cuti umum - rest: Hari cuti ganti - overtime: Hari kerja lebih masa |
| realWorkDate | Long | Hari cuti ganti. Medan ini hanya mempunyai nilai apabila jenis cuti ialah hari kerja lebih masa. |

### Contoh isi respons

```text
HTTP/1.1 200 OK
Content-Type:application/json

{
  "result" : [ {
    "userId" : "fdfi3435",
    "holidays" : [ {
      "workDate" : 1613059200000,
      "holidayName" : "Tahun Baru Cina",
      "holidayType" : "festival",
      "realWorkDate" : 1612627200000
    } ]
  } ]
}
```
