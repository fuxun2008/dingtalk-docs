Panggil API ini untuk menghantar mesej teks biasa daripada bot dalam perbualan satu lawan satu.

## Penerangan panggilan API

API ini hanya boleh digunakan dalam senario coolapp mesej terus. Untuk maklumat lanjut, lihat [Coolapp mesej terus](https://open.dingtalk.com/document/dingstart/private-chat-coolapp-overview#).

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/v1.0/robot/privateChatMessages/send |
| Kaedah HTTP | POST |
| Jenis aplikasi yang disokong | appType-Aplikasi dalaman　appType-Aplikasi perusahaan pihak ketiga |
| Keperluan kebenaran | permission-qyapi_robot_sendmsg-Kebenaran untuk bot dalam organisasi anda menghantar mesej |

### Pengepala permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses yang digunakan untuk memanggil API ini. Dapatkan seperti berikut:   - Untuk aplikasi dalaman, panggil API [Dapatkan access token aplikasi dalaman](/ms/open/development/obtain-the-access-token-of-an-internal-app#). - Untuk aplikasi perusahaan pihak ketiga, panggil API [Dapatkan access token organisasi yang telah memberikan kebenaran kepada aplikasi pihak ketiga](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#). |

### Isi permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| msgParam | String | Ya | Parameter templat mesej. Untuk maklumat lanjut, lihat [Jenis mesej yang dihantar oleh bot organisasi](https://open.dingtalk.com/document/dingstart/types-of-messages-sent-by-robots#). |
| msgKey | String | Ya | Kunci templat mesej. Untuk maklumat lanjut, lihat [Jenis mesej yang dihantar oleh bot organisasi](https://open.dingtalk.com/document/dingstart/types-of-messages-sent-by-robots#). |
| openConversationId | String | Ya | ID perbualan. Dapatkan nilai OpenConversationId dengan memanggil [Pasang coolapp secara pukal ke perbualan mesej terus](https://open.dingtalk.com/document/development/batch-chat-session#) atau dengan mendengar [Peristiwa coolapp mesej terus](https://open.dingtalk.com/document/development/org-event-overview#260a4e7084gs2). |
| robotCode | String | Ya | Kod bot. Gunakan robotCode bot organisasi untuk parameter ini. Untuk maklumat lanjut, lihat [ID Bot](https://open.dingtalk.com/document/development/robot-overview#). |
| coolAppCode | String | Ya | Kod coolapp. |
