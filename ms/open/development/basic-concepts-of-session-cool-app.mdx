## Proses Penerbitan Aplikasi Kumpulan

## Aliran Penggunaan

Sebelum anda mula, pastikan anda telah melengkapkan persediaan untuk [menjadi pembangun DingTalk](/open/dingstart/become-a-dingtalk-developer). Proses pembangunan aplikasi kumpulan adalah seperti berikut:

1. Terbitkan Aplikasi perusahaan pihak ketiga. Bangunkan aplikasi kumpulan berdasarkan Aplikasi perusahaan pihak ketiga yang telah diterbitkan.
2. Konfigurasikan maklumat asas aplikasi kumpulan. Dalam **Cool App Extension** bagi Aplikasi perusahaan pihak ketiga, cipta aplikasi kumpulan dan konfigurasikan maklumat asasnya. Selepas aplikasi kumpulan berjaya dicipta, anda boleh dapatkan kod aplikasi kumpulan.
3. Sediakan Tolak mesej. Dalam **Tolak Mesej**, bangunkan dan ikat Bot.
4. Bangunkan kad interaktif. Dengan mengikat Bot, anda boleh menghantar kad interaktif dan lain-lain.
5. Hantar untuk semakan dan terbitkan aplikasi kumpulan. Selepas pembangunan aplikasi kumpulan selesai, hantar untuk semakan dan hubungi pasukan operasi untuk menerbitkannya.
6. Aktifkan dan gunakan aplikasi kumpulan. Sebaik sahaja aplikasi kumpulan diterbitkan ke Cool App Center, aktifkannya.

## API Biasa untuk Aplikasi Kumpulan

Untuk API bahagian klien bagi aplikasi kumpulan, lihat Pasang Cool App dan Tambahkannya ke Kumpulan.
