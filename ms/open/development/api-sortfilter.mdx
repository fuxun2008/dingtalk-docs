---

Panggil API ini untuk menyusun data dalam julat penapis global secara menaik atau menurun mengikut lajur tertentu. API ini sesuai untuk senario yang memerlukan paparan tersusun bagi data yang ditapis, seperti menyusun data jualan daripada jumlah tertinggi ke terendah, atau menyusun senarai tugasan mengikut tarikh akhir secara menaik.

## Penerangan panggilan API

Tindakan penyusunan mengubah secara kekal susunan storan sebenar rekod data dalam Helaian Kerja, bukan sekadar susunan paparan.

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/doc/workbooks/{workbookId}/sheets/{sheetId}/filter/sort` |
| Kaedah HTTP | POST |
| Jenis aplikasi disokong | appType-Aplikasi dalaman |
| Kebenaran diperlukan | permission-Document.Workbook.Write-Kebenaran tulis Spreadsheet |

### Header permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Untuk mendapatkannya, panggil [Dapatkan access token aplikasi dalaman](/open/development/obtain-the-access-token-of-an-internal-app). |

### Parameter laluan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| workbookId | String | Ya | ID fail Spreadsheet. `nodeId(dentryUuid)` yang dikembalikan oleh [Knowledge Base API](/open/development/knowledge-base-overview) ialah `workbookId` bagi Spreadsheet tersebut. Untuk mendapatkannya, panggil [Dapatkan nod](https://open.dingtalk.com/document/orgapp/get-node) atau [Cipta dokumen Knowledge Base](/open/development/create-team-space-document). |
| sheetId | String | Ya | ID atau nama Helaian Kerja. Untuk mendapatkan nilai parameter id atau name, panggil [Dapatkan semua Helaian Kerja](/open/development/obtain-all-worksheets). |

### Parameter kueri

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| operatorId | String | Ya | unionId bagi operator.   - Untuk mendapatkan nilai parameter unionid, panggil [Dapatkan maklumat pengguna melalui kod log masuk senyap](/open/development/obtain-the-userid-of-a-user-by-using-the-log-free). - Untuk mendapatkan nilai parameter unionid, panggil [Tanya butiran pengguna](/open/development/query-user-details).       Jika operator tidak mempunyai kebenaran, API akan mengembalikan ralat `The operator has no permission`. |

### Isi permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| field | Object | Ya | Objek peraturan penyusunan. |
| column | Long | Ya | Offset lajur relatif kepada lajur pertama dalam julat penapis, bermula dari 0. |
| ascending | Boolean | Tidak | Sama ada menyusun secara menaik. Lalai ialah `true` (menaik). Tetapkan kepada `false` untuk susunan menurun. |
