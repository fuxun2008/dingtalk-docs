Panggil API ini untuk mendapatkan spaceId dan dentryId sesuatu fail berdasarkan dentryUuid.

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v2.0/doc/dentries/{dentryUuid}/queryDentryId` |
| Kaedah HTTP | GET |
| Jenis aplikasi yang disokong | appType-Aplikasi dalaman　appType-Aplikasi perusahaan pihak ketiga |
| Kebenaran | permission-Document.WorkspaceDocument.Read-Kebenaran membaca dokumen Knowledge Base |

### Header permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Dapatkan seperti berikut:   - Untuk aplikasi dalaman, panggil API [Dapatkan access token aplikasi dalaman](/open/development/obtain-the-access-token-of-an-internal-app). - Untuk aplikasi perusahaan pihak ketiga, panggil API [Dapatkan access token organisasi yang diberi kuasa kepada aplikasi pihak ketiga](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1). |

### Parameter laluan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| dentryUuid | String | Ya | UUID fail semasa. |

### Parameter kueri

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| operatorId | String | Ya | unionId bagi pengendali. Untuk mendapatkan nilai unionid, panggil API [Tanya butiran pengguna](/open/development/query-user-details). |
