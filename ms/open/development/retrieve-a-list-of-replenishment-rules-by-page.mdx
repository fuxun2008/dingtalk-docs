Panggil API ini untuk mendapatkan senarai berhalaman peraturan daftar masuk susulan yang dikonfigurasi dalam tetapan kehadiran, termasuk nama peraturan dan ID peraturan.

## Penerangan panggilan API

Sebagai contoh, sebuah organisasi mempunyai dua peraturan daftar masuk susulan dalam pengurusan peraturan kehadiran: **Peraturan daftar masuk susulan ujian** dan **Peraturan daftar masuk susulan lalai**.

Panggil API ini untuk mendapatkan nama peraturan dan ID peraturan bagi kedua-dua peraturan daftar masuk susulan tersebut.

Dalam Admin Console Kehadiran, buka **peraturan kehadiran** > **Peraturan daftar masuk susulan** untuk melihat peraturan daftar masuk susulan yang telah dikonfigurasi. Setiap peraturan memaparkan **Nama peraturan**, **Butiran peraturan** (bilangan permohonan yang dibenarkan sebulan, tempoh maksimum ke belakang untuk memohon daftar masuk susulan, dan jenis yang berkenaan seperti daftar masuk tertinggal, lewat atau pulang awal) dan **Skop**, bersama tindakan **Edit** dan **Padam**. Gunakan **Tambah peraturan daftar masuk susulan** untuk mencipta peraturan baharu.

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/v1.0/attendance/adjustments |
| Kaedah HTTP | GET |
| Jenis aplikasi yang disokong | appType-Aplikasi dalaman　appType-Aplikasi perusahaan pihak ketiga |
| Kebenaran yang diperlukan | permission-qyapi_attendance_group_read-Kebenaran membaca kumpulan kehadiran |

### Pengepala permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Dapatkannya seperti berikut:   - Bagi Aplikasi dalaman, panggil API [Dapatkan access token aplikasi dalaman](/ms/open/development/obtain-the-access-token-of-an-internal-app). - Bagi Aplikasi perusahaan pihak ketiga, panggil API untuk mendapatkan access token organisasi yang telah memberi kebenaran kepada Aplikasi pihak ketiga. |

### Parameter pertanyaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| pageNumber | Long | Ya | Nombor halaman permulaan.  Nilai bermula daripada 1. |
| pageSize | Long | Ya | Saiz halaman.  Nilai maksimum ialah 50. |

### Contoh permintaan

```http
GET /v1.0/attendance/adjustments?pageNumber=1&pageSize=10 HTTP/1.1
Host:api.dingtalk.io
x-acs-dingtalk-access-token:xxxxx
Content-Type:application/json
```

## Respons

### Isi respons

| Nama | Jenis | Penerangan |
| --- | --- | --- |
| result | Object | Hasil yang dikembalikan. |
| pageNumber | Long | Nombor halaman semasa. |
| totalPage | Long | Jumlah bilangan halaman. |
| items | Array | Senarai peraturan daftar masuk susulan. |
| id | Long | ID peraturan daftar masuk susulan. |
| name | String | Nama peraturan daftar masuk susulan. |
| settingId | Long | settingId bagi peraturan daftar masuk susulan. |

### Contoh isi respons

```text
HTTP/1.1 200 OK
Content-Type:application/json

{
  "result" : {
    "pageNumber" : 1,
    "totalPage" : 3,
    "items" : [ {
      "id" : 447010124,
      "name" : "Peraturan daftar masuk susulan lalai",
      "settingId" : 447010124
    } ]
  }
}
```
