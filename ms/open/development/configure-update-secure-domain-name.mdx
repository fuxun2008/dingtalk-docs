# Konfigurasikan dan Kemas Kini Domain Keselamatan

## Prasyarat

Sebelum anda mula, pastikan SLB telah dibeli di bawah akaun Alibaba Cloud (penggunaan Compute Nest) yang dikaitkan dengan Developer Console, dan SLB tersebut dikonfigurasikan dengan [port pendengaran protokol HTTP](https://help.aliyun.com/document_detail/85949.html?spm=a2c4g.86438.0.0.19195491uwAdyO). Buat masa ini, hanya CLB yang disokong.

**Amaran**

Jangan gunakan port HTTPS biasa seperti 443 atau 8443 untuk mengalihkan HTTP kepada HTTPS.

## **Langkah**

1. Log masuk ke Developer Console, pergi ke halaman butiran aplikasi, dan klik **App Release > App Self-Check**.
2. Pilih SLB rangkaian persendirian untuk dikaitkan, pilih perjanjian kebenaran, kemudian klik **Association**.
3. Selepas perkaitan selesai, tunggu semakan domain dan permulaan konfigurasi domain.

   **Nota**

   Selepas anda menghantar permintaan pengikatan domain keselamatan, tunggu semakan keselamatan DingTalk, yang biasanya mengambil masa 1 hingga 2 hari bekerja. Setelah diluluskan, proses tersebut akan mengikat SLB rangkaian persendirian secara automatik kepada domain keselamatan, yang mengambil masa 1 hingga 2 hari bekerja untuk berkuat kuasa. Pantau kemas kini status. Jika permintaan ditolak, semak semula dan hantar permohonan sekali lagi.
4. Kemas kini domain keselamatan dalam aplikasi:

   - Jika jenis push ialah SyncHTTP, gunakan domain keselamatan DingTalk pada alamat push URL callback.
   - Gunakan domain keselamatan DingTalk untuk domain Server API pihak pemaju.
   - Jika aplikasi tidak dibina dengan seni bina hujung depan dan belakang yang dipisahkan, gunakan domain keselamatan DingTalk untuk URL halaman utama aplikasi.

## **Langkah Seterusnya**

Gunakan pelayan aplikasi kepada [ECS dalam Compute Nest](https://help.aliyun.com/document_detail/444595.html?spm=a2c4g.290076.0.0.60715167ZJIyYr).
