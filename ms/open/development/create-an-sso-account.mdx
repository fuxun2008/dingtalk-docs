# Cipta Akaun Syarikat SSO

## Permintaan

| **Maklumat asas** | |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/topapi/v2/user/create |
| Kaedah HTTP | POST |
| Jenis aplikasi disokong | appType-Aplikasi dalaman |
| Kebenaran diperlukan | permission-qyapi_manage_addresslist-Kebenaran pengurusan Kenalan |

### Parameter kueri

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | BE3xxxx | Kelayakan aplikasi yang digunakan untuk memanggil API ini. Dapatkan melalui API [Dapatkan access_token aplikasi dalaman](/ms/open/development/obtain-orgapp-token). |

### Isi permintaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| userid | String | Tidak | zhangsan | Pengenal unik pekerja (tidak boleh diubah suai). Panjang 1 hingga 64 aksara.  **Nota**     - Mesti unik dalam Organisasi Anda. - Jika tidak dinyatakan, userid akan dijana secara automatik. |
| exclusive_account | Boolean | Ya | true | Mesti ditetapkan kepada true, yang menandakan Akaun Syarikat akan dicipta.  **Nota**  Hanya terpakai untuk Akaun Syarikat. |
| exclusive_account_type | String | Tidak | sso | Mesti ditetapkan kepada sso, yang menandakan Akaun Syarikat SSO.  **Nota**  Hanya terpakai untuk Akaun Syarikat SSO. |
| name | String | Ya | Zhang San | Nama pekerja. Sehingga 80 aksara. |
| dept_id_list | String | Ya | "2,3,4" | Senarai ID jabatan yang menjadi tempat pekerja ini. Pisahkan beberapa ID jabatan dengan koma (`,`). Sehingga 100 ID jabatan setiap panggilan. |
| telephone | String | Tidak | 010-86123456-2345 | Nombor sambungan. Sehingga 50 aksara.  **Nota**  Nombor sambungan mesti unik dalam Organisasi Anda. |
| job_number | String | Tidak | 4 | ID Pekerja. Sehingga 50 aksara. |
| title | String | Tidak | Pengarah Teknikal | Jawatan. Sehingga 200 aksara. |
| email | String | Tidak | test@xxx.com | Alamat e-mel peribadi pekerja. Sehingga 50 aksara.  **Nota**  Alamat e-mel mesti unik dalam Organisasi Anda. |
| org_email | String | Tidak | test@xxx.com | E-mel Syarikat pekerja. Sehingga 100 aksara.  **Nota**  Medan ini hanya berkuat kuasa apabila pekerja mengaktifkan E-mel Syarikat. |
| org_email_type | String | Tidak | profession | Jenis E-mel Syarikat pekerja:   - **profession:** Edisi Standard. - **base:** Edisi Basic. |
| work_place | String | Tidak | Future Park | Lokasi Kerja. Sehingga 100 aksara. |
| remark | String | Tidak | Maklumat alias | Alias. Sehingga 2,000 aksara. |
| dept_order_list | Object[] | Tidak |  | Susunan pekerja dalam jabatan yang berkaitan. |
| dept_id | Number | Tidak | 2 | ID jabatan. |
| order | Number | Tidak | 1 | Susunan pekerja dalam jabatan. Semakin besar nilai, semakin tinggi kedudukan. |
| dept_title_list | Object[] | Tidak |  | Jawatan pekerja dalam jabatan yang berkaitan. |
| dept_id | Number | Tidak | 2 | ID jabatan. |
| title | String | Tidak | Pengurus Produk Kanan | Jawatan pekerja dalam jabatan tersebut. |
| extension | Object | Tidak | `{"Hobby":"Travel","Age":"24"}` | Atribut lanjutan. Beberapa atribut boleh ditetapkan. Sehingga 2,000 aksara.**Nota**   - Sehingga 10 atribut lanjutan boleh dipaparkan pada peranti mudah alih. - Sebelum menggunakan parameter ini, tambah atribut dalam [DingTalk admin console](https://oa.dingtalk.io/index_new.htm#/setting/contactInfo), kemudian panggil API untuk menetapkan nilai. Contohnya, pada halaman **Contacts** > **Internal Contacts Settings** > **Contacts Information**, klik butang **Add Custom Field**. - Nilai medan ini menyokong jenis pautan. Pautan menyokong penggantian automatik kad liar pemboleh ubah. Kad liar yang disokong sekarang ialah userid dan corpid. Contohnya, `{"Hobby":"[Hobby](http://www.dingtalk.io?userid=#userid#&corpid=#corpid#)"}`. |
| senior_mode | Boolean | Tidak | false | Sama ada untuk mengaktifkan mod eksekutif. Lalai: false.   - **true**: Diaktifkan.  **Nota**      - Apabila diaktifkan, nombor telefon mudah alih disembunyikan daripada semua pekerja.   - Pekerja biasa tidak boleh menghantar DING atau memulakan DingTalk Business Call kepada eksekutif.   - Eksekutif boleh menghantar DING dan memulakan DingTalk Business Call antara satu sama lain. - **false**: Dinyahaktifkan. |
| hired_date | Number | Tidak | 1597573616828 | Tarikh mula bekerja. Unix timestamp dalam milisaat. |
| manager_userid | String | Tidak | 001 | userId Penyelia Langsung. |
| exclusive_mobile | String | Tidak | +86-13412341234 | Nombor Telefon mudah alih Akaun Syarikat.  **Nota**  Hanya terpakai untuk Akaun Syarikat. |
| avatarMediaId | String | Tidak | @lALPDfmVUw19YdrNA-jNA-g | MediaId Gambar Profil boleh dinyatakan semasa mencipta Akaun Syarikat untuk Organisasi Anda. Hanya format jpg dan png disokong.  Dapatkan dengan memanggil API [Muat naik fail media](/ms/open/development/upload-media-files).  **Nota**  Hanya terpakai untuk Akaun Syarikat. |
| nickname | String | Tidak | Nickname | Nama boleh dinyatakan semasa mencipta Akaun Syarikat untuk Organisasi Anda.  **Nota**  Hanya terpakai untuk Akaun Syarikat. |

### Contoh permintaan

```curl
curl -X POST "https://api.dingtalk.io/topapi/v2/user/create" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=871c1df6-bcd5-4acb-b2e9-815b7246d85c' \
-d 'userid=zhangsan'
-d 'exclusive_account=true' \
-d 'name=John' \
-d 'dept_id_list=2,3,4'
```

## Respons

### Isi respons

| Nama | Jenis | Contoh | Penerangan |
| --- | --- | --- | --- |
| errcode | Number | 0 | Kod ralat. 0 menandakan berjaya. |
| errmsg | String | ok | Mesej ralat. |
| result | Object |  | Hasil yang dikembalikan. |
| userid | String | zhangsan | ID Pekerja. |
| unionId | String | xxxx | ID unik pekerja. |

### Contoh isi respons

```json
{
  "errcode":"0",
  "result":{
    "unionId":"xxxx",
    "userid":"zhangsan"
  },
  "errmsg":"ok"
}
```

### Kod ralat

Jika ralat berlaku semasa memanggil API ini, cari penyelesaian berdasarkan mesej ralat dalam dokumentasi [Kod ralat global](/ms/open/development/server-api-error-codes-1).
