Panggil API ini untuk mengalih keluar pengguna yang ditentukan daripada peserta acara.

## Penerangan panggilan API

Setiap operasi peserta menyokong sehingga 500 pengguna pada satu masa, dan menyokong acara dengan sehingga 5,000 peserta.

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/calendar/users/{userId}/calendars/{calendarId}/events/{eventId}/attendees/batchRemove` |
| Kaedah HTTP | POST |
| Jenis aplikasi yang disokong | appType-Aplikasi dalaman　appType-Aplikasi perusahaan pihak ketiga　appType-Aplikasi peribadi pihak ketiga |
| Kebenaran diperlukan | permission-Calendar.Event.Write-Kebenaran tulis pada acara dalam aplikasi Kalendar |

### Pengepala permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-client-token | String | Tidak | Semakan kesamaan (idempotency).       - `x-client-token` yang sama menunjukkan permintaan yang sama. - Tamat tempoh selepas 1 hari. |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Dapatkan seperti berikut:   - Untuk aplikasi dalaman, panggil API [Dapatkan access token aplikasi dalaman](/open/development/obtain-the-access-token-of-an-internal-app#). - Untuk aplikasi perusahaan pihak ketiga, panggil API [Dapatkan access token perusahaan yang diberi kuasa](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#). - Untuk aplikasi peribadi pihak ketiga, panggil API [Dapatkan token pengguna](/open/development/obtain-user-token#). |

### Parameter laluan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| userId | String | Ya | unionId pencipta acara.   - Untuk aplikasi dalaman dan aplikasi perusahaan pihak ketiga, panggil API [Tanya butiran pengguna](/open/development/query-user-details#) untuk mendapatkan nilai parameter unionid. - Untuk aplikasi peribadi pihak ketiga, panggil API [Dapatkan profil pengguna daripada Kenalan](/open/development/dingtalk-retrieve-user-information#) untuk mendapatkan nilai parameter unionId. |
| calendarId | String | Ya | ID kalendar yang menjadi milik acara ini. Tetapkan kepada `primary`, yang mewakili kalendar utama pengguna. |
| eventId | String | Ya | ID acara. Panggil API [Tanya senarai acara](/open/development/query-an-event-list#) untuk mendapatkan nilai parameter id. |

### Isi permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| attendeesToRemove | Array | Tidak | Senarai peserta acara yang akan dialih keluar. |
| id | String | Tidak | unionId pengguna.   - Untuk aplikasi dalaman dan aplikasi perusahaan pihak ketiga, panggil API [Tanya butiran pengguna](/open/development/query-user-details#) untuk mendapatkan nilai parameter unionid. - Untuk aplikasi peribadi pihak ketiga, panggil API [Dapatkan profil pengguna daripada Kenalan](/open/development/dingtalk-retrieve-user-information#) untuk mendapatkan nilai parameter unionId. |
