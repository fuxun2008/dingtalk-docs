---
title: "Kemas kini ahli kehadiran"
description: "Panggil API DingTalk ini untuk menambah atau mengalih keluar ahli kehadiran, ahli dikecualikan kehadiran dan jabatan dalam kumpulan kehadiran secara pukal."
---

Panggil API ini untuk mengemas kini ahli kumpulan kehadiran. Tambah atau alih keluar **ahli kehadiran** dan **ahli dikecualikan kehadiran** bagi kumpulan kehadiran yang ditetapkan.

## Permintaan

| **Maklumat asas** | |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/topapi/attendance/group/member/update |
| Kaedah HTTP | POST |
| Jenis aplikasi yang disokong | appType-Aplikasi dalaman　appType-Aplikasi perusahaan pihak ketiga |
| Kebenaran yang diperlukan | qyapi_attendance_group_manage (Kebenaran pengurusan kumpulan kehadiran) |

### Parameter pertanyaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | bE74xxxx | Kelayakan aplikasi yang digunakan untuk memanggil API ini.   - Bagi Aplikasi dalaman, panggil API [Dapatkan access_token Aplikasi dalaman](/ms/open/development/obtain-orgapp-token) untuk mendapatkannya. - Bagi Aplikasi perusahaan pihak ketiga, panggil API untuk mendapatkan access_token organisasi pihak ketiga. |

### Isi permintaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| op_user_id | String | Ya | user123 | userId pengendali. |
| group_id | Number | Ya | 98562 | ID kumpulan kehadiran.  **Nota**  Jika anda menggunakan pengecam kumpulan kehadiran lama (group_key), panggil API [Tukar groupKey kepada groupId](/ms/open/development/convert-groupkey-to-groupid) untuk menukar group_key kepada group_id. |
| schedule_flag | Number | Ya | 0 | Hari permulaan penjadualan syif.   - **0**: Mulakan penjadualan syif hari ini - **1**: Mulakan penjadualan syif esok |
| update_param | TopGroupMemberUpdateParam | Ya |  | Maklumat kemas kini kumpulan kehadiran. |
| remove_extra_users | String[] | Tidak | ["user123","user456"] | Ahli dikecualikan kehadiran yang hendak dialih keluar. Biarkan kosong jika tidak berkenaan. Hantar sehingga 20 userId bagi setiap panggilan. |
| remove_depts | String[] | Tidak | ["123","456"] | Jabatan kehadiran yang hendak dialih keluar. Biarkan kosong jika tidak berkenaan. Hantar sehingga 20 ID jabatan bagi setiap panggilan. |
| remove_users | String[] | Tidak | ["user123","user456"] | Ahli kehadiran yang hendak dialih keluar. Biarkan kosong jika tidak berkenaan. Hantar sehingga 20 userId bagi setiap panggilan. |
| add_depts | String[] | Tidak | ["123","456"] | Jabatan kehadiran yang hendak ditambah. Biarkan kosong jika tidak berkenaan. Hantar sehingga 20 ID jabatan bagi setiap panggilan. |
| add_users | String[] | Tidak | ["user123","user456"] | Ahli kehadiran yang hendak ditambah. Biarkan kosong jika tidak berkenaan. Hantar sehingga 20 userId bagi setiap panggilan. |
| add_extra_users | String[] | Tidak | ["user123","user456"] | Ahli dikecualikan kehadiran yang hendak ditambah. Biarkan kosong jika tidak berkenaan. Hantar sehingga 20 userId bagi setiap panggilan. |

### Contoh permintaan

```curl
curl -X POST "https://api.dingtalk.io/topapi/attendance/group/member/update" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=0142dxxxxa6204' \
-d 'group_id=122' \
-d 'op_user_id=dd_dd' \
-d 'schedule_flag=0' \
-d 'update_param=null'
```

Java

```java
DingTalkClient client = new DefaultDingTalkClient("https://api.dingtalk.io/topapi/attendance/group/member/update");
OapiAttendanceGroupMemberUpdateRequest req = new OapiAttendanceGroupMemberUpdateRequest();
req.setOpUserId("user123");
req.setGroupId(98562L);
req.setScheduleFlag(0L);
TopGroupMemberUpdateParam updateParam = new TopGroupMemberUpdateParam();
updateParam.setAddDepts(Arrays.asList("123"));
updateParam.setRemoveDepts(Arrays.asList("456"));
updateParam.setAddUsers(Arrays.asList("user123"));
updateParam.setAddExtraUsers(Arrays.asList("user456"));
updateParam.setRemoveExtraUsers(Arrays.asList("user789"));
updateParam.setRemoveUsers(Arrays.asList("user121"));
req.setUpdateParam(updateParam);
OapiAttendanceGroupMemberUpdateResponse rsp = client.execute(req, access_token);
System.out.println(rsp.getBody());
```

## Respons

### Isi respons

| Nama | Jenis | Contoh | Penerangan |
| --- | --- | --- | --- |
| request_id | String | 3pgsafymemlr | ID permintaan. |
| errcode | Number | 0 | Kod pulangan. |
| success | Boolean | true | Menunjukkan sama ada panggilan berjaya.   - **true**: Berjaya - **false**: Gagal |

### Contoh isi respons

```json
{
  "errcode": 0,
  "success": true,
  "request_id": "5sj3lgigiqm9"
}
```
