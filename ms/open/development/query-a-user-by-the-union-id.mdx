# Dapatkan ID pengguna melalui unionId

## Penerangan panggilan API

unionId ialah pengenal unik yang diberikan kepada seorang pekerja dalam skop Akaun Syarikat pembangun semasa, dijana oleh sistem:

- unionId bagi pekerja yang sama berbeza antara Akaun Syarikat pembangun yang berlainan.
- Dalam Akaun Syarikat pembangun yang sama, unionId adalah unik dan tidak berubah. Sebagai contoh, pelbagai aplikasi yang dibangunkan oleh penyedia perkhidmatan yang sama, atau pelbagai akaun aplikasi dalam senario seperti log masuk melalui Imbas Kod QR, semuanya berkongsi unionId yang sama.

## Permintaan

| **Maklumat asas** | |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/topapi/user/getbyunionid |
| Kaedah HTTP | POST |
| Jenis aplikasi yang disokong | appType-Aplikasi dalaman, appType-Aplikasi perusahaan pihak ketiga |
| Kebenaran yang diperlukan | permission-qyapi_get_member-Kebenaran membaca maklumat pengguna |

### Parameter pertanyaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | be3Fxxxx | Kelayakan aplikasi yang digunakan untuk memanggil API ini.  **Nota**  Jika unionId diperoleh melalui **Log masuk senyap**, anda tidak boleh menggunakan token yang diperoleh daripada log masuk senyap untuk memanggil API ini. Anda mesti mendapatkan token baharu menggunakan API di bawah.   - Untuk aplikasi dalaman, dapatkan access_token melalui API untuk mendapatkan [access_token aplikasi dalaman](/ms/open/development/obtain-orgapp-token). - Untuk aplikasi perusahaan pihak ketiga, dapatkan access_token melalui API untuk mendapatkan access_token perusahaan pihak ketiga. |

### Isi permintaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| unionid | String | Ya | z21HjQliSzpw0Yxxxx | Pengenal unik seorang pekerja dalam skop Akaun Syarikat pembangun semasa. Ia dijana oleh sistem dan kekal tidak berubah. Anda boleh mendapatkan unionId dengan memanggil [Dapatkan ID pengguna melalui kod log masuk senyap](/ms/open/development/obtain-the-userid-of-a-user-by-using-the-log-free). |

### Contoh permintaan

```curl
curl -X POST "https://api.dingtalk.io/topapi/user/getbyunionid" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=6348d21e-fb41-4745-a214-95bcf8c118f0' \
-d 'unionid=z21HjQliSzpw0YWCNxmii6u2Os62cZ62iSZ'
```

Java

```text

OapiUserGetbyunionidRequest req = new OapiUserGetbyunionidRequest();

OapiUserGetbyunionidResponse rsp = client.execute(req, access_token);
System.out.println(rsp.getBody());
```

## Respons

### Isi respons

| Nama | Jenis | Contoh | Penerangan |
| --- | --- | --- | --- |
| request_id | String | zcqi5450rpit | ID permintaan. |
| errcode | Number | 0 | Kod pemulangan. |
| errmsg | String | ok | Penerangan kod pemulangan. |
| result | UserGetByUnionIdResponse |  | Hasil yang dipulangkan. |
| contact_type | Number | 0 | Jenis kenalan:   - **0**: Pekerja dalaman - **1**: Kenalan luaran |
| userid | String | zhangsan | ID pengguna bagi pengguna tersebut. |

### Contoh isi respons

```json
{
  "errcode":"0",
  "errmsg":"ok",
  "result":{
   "contact_type":"0",
   "userid":"zhangsan"
  },
  "request_id": "zcqi5450rpit"
}
```

### Kod ralat

Jika berlaku ralat semasa memanggil API ini, cari penyelesaian mengikut mesej ralat dalam dokumen [Kod ralat global](/ms/open/development/server-api-error-codes-1).

| Kod ralat (errcode) | Mesej ralat (errmsg) | Penyelesaian |
| --- | --- | --- |
| 60121 | Pekerja berkaitan tidak ditemui. | Semak sama ada unionId adalah betul. |
| 400002 | Parameter tidak sah. | Semak sama ada unionId adalah betul. |
| -1 | Sistem sedang sibuk. | Cuba Lagi kemudian. |
