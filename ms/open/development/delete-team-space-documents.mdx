Panggil API ini untuk memadam dokumen atau folder dalam ruang pasukan.

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/doc/workspaces/{workspaceId}/docs/{nodeId}` |
| Kaedah HTTP | DELETE |
| Jenis aplikasi disokong | appType-Aplikasi dalaman |
| Kebenaran diperlukan | permission-Document.WorkspaceDocument.Write-Kebenaran tulis dokumen Knowledge Base |

### Header permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses yang digunakan untuk memanggil API ini. Untuk mendapatkannya, panggil API [Dapatkan access token aplikasi dalaman](/ms/open/development/obtain-the-access-token-of-an-internal-app). |

### Parameter laluan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| workspaceId | String | Ya | ID ruang pasukan. Untuk mendapatkannya, panggil API [Cipta Knowledge Base](/ms/open/development/new-knowledge-base) atau API [Dapatkan senarai Knowledge Base](/ms/open/development/get-knowledge-base-list) dan gunakan nilai medan workspaceId. |
| nodeId | String | Ya | ID nod ruang pasukan. Anda boleh menghantar sama ada ID dokumen atau ID folder. Untuk mendapatkannya, panggil API [Cipta dokumen Knowledge Base](/ms/open/development/create-team-space-document) dan gunakan nilai parameter nodeId. |

### Parameter kueri

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| operatorId | String | Ya | unionId pengguna yang memulakan permintaan padam. Untuk mendapatkannya, panggil API [Tanya butiran pengguna](/ms/open/development/query-user-details) dan gunakan nilai parameter unionid. |

### Kod ralat

Jika ralat berlaku semasa anda memanggil API ini, cari penyelesaiannya dalam dokumen [Kod ralat global](/ms/open/development/server-api-error-codes-1) berdasarkan mesej ralat.

| HttpCode | Kod ralat | Mesej ralat | Penerangan |
| --- | --- | --- | --- |
| 400 | invalidRequest.inputArgs.invalid | Method parameter validation failed | Pengesahan parameter kaedah gagal. Semak sama ada terdapat parameter wajib yang tiada atau sama ada unionId sah. |
| 400 | invalidRequest.workspaceNode.notInWorkspace | The node is not in the Knowledge Base | Nod tersebut tiada dalam Knowledge Base. |
| 403 | forbidden.user.notInOrg | The operating user is not in the organization | Pengguna yang menjalankan operasi tiada dalam organisasi. |
| 403 | forbidden.accessDenied | The user does not have operation permission | Pengguna tidak mempunyai kebenaran operasi. |
| 404 | invalidRequest.resource.notFound | The resource is not found | Knowledge Base, nod, atau sumber lain tidak dijumpai. |
| 404 | invalidRequest.document.deleted | The Knowledge Base node has been deleted | Nod Knowledge Base telah dipadam. |
| 404 | invalidRequest.workspace.deleted | The Knowledge Base has been deleted | Knowledge Base telah dipadam. |
| 500 | internalError | Internal system error | Ralat sistem dalaman. |
