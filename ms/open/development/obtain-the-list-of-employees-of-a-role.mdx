Panggil API ini untuk mendapatkan senarai pengguna bagi peranan tertentu.

## Permintaan

| **Maklumat asas** | |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/topapi/role/simplelist |
| Kaedah HTTP | POST |
| Jenis aplikasi yang disokong | appType-Aplikasi dalamanappType-Aplikasi perusahaan pihak ketiga |
| Kebenaran yang diperlukan | permission-qyapi_get_department_member-Kebenaran Telah dibaca untuk pengguna jabatan dalam Kenalan |

### Parameter pertanyaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | bE74xxxx | Kelayakan aplikasi yang digunakan untuk memanggil API ini.   - Bagi aplikasi dalaman, dapatkan melalui API untuk mendapatkan [access_token aplikasi dalaman](/open/development/obtain-orgapp-token). - Bagi aplikasi perusahaan pihak ketiga, dapatkan melalui API untuk mendapatkan access_token perusahaan pihak ketiga. |

### Isi permintaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| role_id | Number | Ya | 1203141 | ID peranan. Untuk mendapatkan nilai ini, panggil API [Dapatkan senarai peranan](/open/development/obtains-a-list-of-enterprise-roles) dan gunakan nilai parameter `id`. |
| size | Number | Tidak | 20 | Saiz halaman.  **Nota**  Parameter ini hanya berkuat kuasa apabila ditetapkan bersama parameter `offset`. Nilai lalai ialah 20 dan nilai maksimum ialah 100. |
| offset | Number | Tidak | 0 | Ofset penomboran halaman.  **Nota**  Parameter ini hanya berkuat kuasa apabila ditetapkan bersama parameter `size`. Ofset bermula daripada 0. |

### Contoh permintaan

```curl
curl -X POST "https://api.dingtalk.io/topapi/role/simplelist" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=d1812xxxxc53245' \
-d 'offset=0' \
-d 'role_id=1203141' \
-d 'size=20'
```

Java

```text
DingTalkClient client = new DefaultDingTalkClient("https://api.dingtalk.io/topapi/role/simplelist");
OapiRoleSimplelistRequest req = new OapiRoleSimplelistRequest();
req.setRoleId(1203141L);
req.setSize(20L);
req.setOffset(0L);
OapiRoleSimplelistResponse rsp = client.execute(req, access_token);
System.out.println(rsp.getBody());
```

Python

```python
import dingtalk.api

req=dingtalk.api.OapiRoleSimplelistRequest("https://api.dingtalk.io/topapi/role/simplelist")

req.role_id=1203141
req.offset=0
req.size=20
try:
  resp= req.getResponse(access_token)
  print(resp)
except Exception,e:
  print(e)
```

## Respons

### Isi respons

| Nama | Jenis | Contoh | Penerangan |
| --- | --- | --- | --- |
| request_id | String | f6249uw1kuus | ID permintaan. |
| errcode | Number | 0 | Kod pemulangan. |
| errmsg | String | ok | Penerangan kod pemulangan. |
| result | PageVo |  | Keputusan pertanyaan. |
| hasMore | Boolean | true | Menunjukkan sama ada terdapat lebih banyak data. |
| list | OpenEmpSimple[] |  | Senarai pengguna yang ditetapkan kepada peranan tersebut. |
| userid | String | manager4220 | ID pengguna bagi pengguna tersebut. |
| name | String | Ahmad | Nama pengguna tersebut. |
| manageScopes | OrgDeptVo[] |  | Skop pengurusan. |
| dept_id | Number | 11 | ID jabatan. |
| name | String | Jabatan Pemeriksaan Disiplin | Nama jabatan. |

### Kod ralat

Jika ralat berlaku semasa anda memanggil API ini, cari penyelesaiannya dalam dokumen [Kod ralat global](/open/development/server-api-error-codes-1) berdasarkan mesej ralat.

| Kod ralat (errorcode) | Mesej ralat (errmsg) | Penyelesaian |
| --- | --- | --- |
| 33011 | Invalid roleId | Semak sama ada roleId adalah betul. |
| 40069 | Invalid size | Laraskan saiz halaman. |
| 40068 | Invalid offset | Laraskan ofset. |
| 400001 | System error | Cuba Lagi kemudian. |
