Panggil API ini untuk menambah peranan bagi pelbagai pekerja secara pukal. Peranan dalam kumpulan "Lalai", termasuk Pemilik, Penyelia, Super Admin, dan Sub Admin, tidak boleh ditambah.

## Permintaan

| **Maklumat asas** | |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/topapi/role/addrolesforemps |
| Kaedah HTTP | POST |
| Jenis aplikasi yang disokong | appType-Aplikasi dalaman |
| Kebenaran yang diperlukan | permission-qyapi_manage_addresslist-Kebenaran pengurusan data Kenalan |

### Parameter pertanyaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| access_token | String | Wajib | 6d1bxxxx | Kelayakan aplikasi yang digunakan untuk memanggil API ini. Dapatkan melalui API untuk mendapatkan [access_token aplikasi dalaman](/ms/open/development/obtain-orgapp-token). |

### Isi permintaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| roleIds | String | Wajib | 1507113584 | Senarai ID peranan (roleId). Panggil API [Dapatkan senarai peranan](/ms/open/development/obtains-a-list-of-enterprise-roles) untuk mendapatkannya.  Pisahkan berbilang nilai roleId dengan koma (,). Sehingga 20 nilai dibenarkan. |
| userIds | String | Wajib | user1 | userId Pekerja. Panggil [Tanya pengguna mengikut Nombor Telefon](/ms/open/development/query-users-by-phone-number) untuk mendapatkannya.  Pisahkan berbilang nilai userId dengan koma (,). Sehingga 20 nilai dibenarkan. |

### Contoh permintaan

```curl
curl -X POST "https://api.dingtalk.io/topapi/role/addrolesforemps" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=8f577dxxxx76f2a3a2' \
-d 'roleIds=1507113584' \
-d 'userIds=user1'
```

## Respons

### Isi respons

| Nama | Jenis | Contoh | Penerangan |
| --- | --- | --- | --- |
| errcode | Nombor | 0 | Kod pulangan. |
| errmsg | String | ok | Penerangan kod pulangan. |
| request_id | String | emhw6ma4xmeg | ID permintaan. |

### Contoh isi respons

```json
{
  "errcode": 0,
  "request_id": "emhw6ma4xmeg"
}
```

### Kod ralat

Jika ralat berlaku semasa anda memanggil API ini, rujuk dokumen [Kod ralat global](/ms/open/development/server-api-error-codes-1) untuk mencari penyelesaian berdasarkan mesej ralat.

| Kod ralat (errcode) | Mesej ralat (errmsg) | Penyelesaian |
| --- | --- | --- |
| 33011 | roleIds tidak sah | Semak sama ada roleIds adalah betul. |
| 33012 | userIds tidak sah | Semak sama ada nilai userId adalah betul. |
| 12012 | Organisasi tidak wujud | Semak sama ada access_token adalah betul. |
| 1002 | Sistem sibuk | Cuba Lagi kemudian. |
