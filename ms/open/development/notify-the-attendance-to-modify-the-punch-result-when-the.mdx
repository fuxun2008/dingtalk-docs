Panggil API ini untuk memaklumkan pembatalan kelulusan. Menyokong jenis kerja lebih masa, permohonan cuti, keluar pejabat, perjalanan perniagaan dan daftar masuk susulan.

## Penerangan panggilan API

Selepas anda memanggil API [Maklumkan penyelesaian kelulusan](/ms/open/development/api-processapprovefinish), borang kelulusan yang telah dihantar mungkin perlu dibatalkan. Dalam keadaan ini, panggil API ini untuk membatalkan rekod kehadiran yang telah diubah suai.

## Permintaan

| **Maklumat asas** | |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/topapi/attendance/approve/cancel |
| Kaedah HTTP | POST |
| Jenis aplikasi yang disokong | appType-Aplikasi dalaman appType-Aplikasi perusahaan pihak ketiga |
| Kebenaran | permission-qyapi_attendance_group_manage-Kebenaran pengurusan kumpulan kehadiran |

### Parameter pertanyaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | bE74xxxx | Kelayakan aplikasi yang digunakan untuk memanggil API ini.   - Aplikasi dalaman: Dapatkan dengan memanggil API [Dapatkan access_token aplikasi dalaman](/ms/open/development/obtain-orgapp-token). - Aplikasi perusahaan pihak ketiga: Dapatkan dengan memanggil API Dapatkan access_token aplikasi perusahaan pihak ketiga. |

### Isi permintaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| userid | String | Ya | manager4220 | ID pengguna pekerja. |
| approve_id | String | Ya | 2376620852 | ID kelulusan. Gunakan nilai parameter tersuai approve_id daripada API [Maklumkan penyelesaian kelulusan](/ms/open/development/api-processapprovefinish). |

### Contoh permintaan

```curl
curl -X POST "https://api.dingtalk.io/topapi/attendance/approve/cancel" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=95676xxxxdee' \
-d 'approve_id=1234abcd' \
-d 'userid=dd_dd'
```

Java

```text
DingTalkClient client = new DefaultDingTalkClient("https://api.dingtalk.io/topapi/attendance/approve/cancel");
OapiAttendanceApproveCancelRequest req = new OapiAttendanceApproveCancelRequest();
req.setUserid("manager4220");
req.setApproveId("2376620852");
OapiAttendanceApproveCancelResponse rsp = client.execute(req, access_token);
System.out.println(rsp.getBody());
```

## Respons

### Isi respons

| Nama | Jenis | Contoh | Penerangan |
| --- | --- | --- | --- |
| errcode | Number | 0 | Kod pemulangan. |
| errmsg | String | ok | Penerangan kod pemulangan. |

### Contoh isi respons

```json
{
  "errcode":0,
  "errmsg":"ok"
}
```

### Kod ralat

Jika API ini memulangkan ralat, cari penyelesaian dalam dokumen [Kod ralat global](/ms/open/development/server-api-error-codes-1) berdasarkan mesej ralat.
