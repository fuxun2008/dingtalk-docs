Panggil API ini untuk mendapatkan semua borang kelulusan yang boleh diurus oleh pengguna dalam organisasi semasa.

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/v1.0/workflow/processes/managements/templates |
| Kaedah HTTP | GET |
| Jenis aplikasi yang disokong | appType-Aplikasi dalaman |
| Kebenaran | permission-Workflow.Form.Read-Kebenaran baca templat aliran kerja |

### Header permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Dapatkannya dengan memanggil API [Dapatkan access token Aplikasi dalaman](/ms/open/development/obtain-the-access-token-of-an-internal-app). |

### Parameter pertanyaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| userId | String | Ya | userId pengguna.  **Nota**  Pengguna yang sepadan dengan userId mesti mempunyai kebenaran Kelulusan OA dalam organisasi. |

### Contoh permintaan

HTTP

```http
GET /v1.0/workflow/processes/managements/templates?userId=manager7078 HTTP/1.1
Host:api.dingtalk.io
x-acs-dingtalk-access-token:6d1bxxxx
Content-Type:application/json
```

## Respons

### Isi respons

| Nama | Jenis | Penerangan |
| --- | --- | --- |
| result | Array | Senarai templat. |
| iconName | String | Nama ikon templat. |
| flowTitle | String | Nama templat. |
| processCode | String | Kod templat. |
| newProcess | Boolean | Sama ada templat ialah templat baharu.   - **true**: Ya - **false**: Tidak |
| gmtModified | String | Masa pengubahsuaian. |
| attendanceType | Integer | Jenis kehadiran yang dikaitkan. Nilai yang sah:   - **0**: Tiada - **1**: Permintaan daftar masuk susulan - **2**: Permohonan cuti |
| iconUrl | String | URL ikon. |
| success | Boolean | Sama ada panggilan API berjaya.   - **true**: Berjaya - **false**: Gagal |

### Contoh isi respons

```text
HTTP/1.1 200 OK
Content-Type:application/json

    "attendanceType" : 0,
    "iconUrl" : "https://gw.alicdn.com/tfs/xxxx-112-112.png"

}
```
