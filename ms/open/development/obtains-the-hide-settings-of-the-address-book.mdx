Panggil API ini untuk mendapatkan senarai tetapan sembunyi Kenalan secara bersayap muka surat (pagination).

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/v1.0/contact/contactHideSettings |
| Kaedah HTTP | GET |
| Jenis aplikasi yang disokong | appType-Aplikasi dalaman |
| Kebenaran | permission-Contact.Visibility.ReadWrite-Kebenaran pengurusan keterlihatan data Kenalan |

### Header permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses yang digunakan untuk memanggil API ini. Dapatkan dengan memanggil API [Dapatkan access token aplikasi dalaman](/open/development/obtain-the-access-token-of-an-internal-app#). |

### Parameter query

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| nextToken | Long | Tidak | Cursor pagination.   - Untuk panggilan pertama, tetapkan parameter ini kepada 0. - Untuk panggilan seterusnya, hantar nilai nextToken yang dikembalikan oleh panggilan sebelumnya. |
| maxResults | Integer | Tidak | Saiz halaman. Nilai maksimum: 100. |

### Contoh permintaan

### Isi respons

| --- | --- | --- |
| hasMore | Boolean | Menunjukkan sama ada terdapat lebih banyak data.   - true: Ya - false: Tidak |
| nextToken | Long | Cursor untuk halaman seterusnya. Rentetan kosong menunjukkan pagination telah tamat. |
| list | Array | Senarai tetapan sembunyi Kenalan. |
| name | String | Nama tetapan. |
| description | String | Penerangan tetapan. |
| objectStaffIds | Array of String | Senarai userId pekerja yang disembunyikan. |
| objectDeptIds | Array of Long | Senarai ID Jabatan yang disembunyikan. |
| objectTagIds | Array of Long | Senarai ID Peranan yang disembunyikan. |
| excludeStaffIds | Array of String | Senarai userId pengguna yang tidak terjejas oleh tetapan sembunyi ini. |
| excludeDeptIds | Array of Long | Senarai ID Jabatan yang tidak terjejas oleh tetapan sembunyi ini. |
| excludeTagIds | Array of Long | Senarai ID Peranan yang tidak terjejas oleh tetapan sembunyi ini. |
| active | Boolean | Menunjukkan sama ada peraturan ini aktif.   - true: Aktif - false: Tidak aktif |
| id | Long | ID tetapan. |
