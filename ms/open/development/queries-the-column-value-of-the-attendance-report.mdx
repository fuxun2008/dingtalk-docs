---
title: "Dapatkan nilai lajur laporan kehadiran"
description: "Panggil API DingTalk ini untuk mendapatkan nilai dan maklumat lajur laporan kehadiran Smart Attendance mengikut ID pengguna, ID lajur dan julat masa."
---

Panggil API ini untuk mendapatkan data nilai lajur daripada laporan kehadiran DingTalk Smart Attendance. Data ini merangkumi semua nilai bagi sesuatu lajur laporan dalam julat masa yang ditetapkan, berserta maklumat lajur yang berkaitan, untuk digunakan oleh ISV yang ditetapkan.

## Penerangan panggilan API

- Maklumat kehadiran pengguna yang telah meninggalkan organisasi tidak boleh diperoleh melalui API ini. Semak data kehadiran pengguna tersebut di [OA Admin Console](https://attend.dingtalk.io/portal/index.html).
- Apabila anda mendapatkan nilai medan "Hari kehadiran wajib", API ini hanya memulangkan nilai dalam tempoh 15 hari terakhir. Bagi tarikh yang melebihi 15 hari lalu, nilai hari kehadiran wajib ialah 0.

## Permintaan

| **Maklumat asas** | |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/topapi/attendance/getcolumnval |
| Kaedah HTTP | POST |
| Jenis aplikasi yang disokong | appType-Aplikasi dalaman appType-Aplikasi perusahaan pihak ketiga |
| Kebenaran | permission-qyapi_base-Kebenaran asas yang diperlukan untuk memanggil API organisasi |

### Parameter query

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | 6d1bxxxx | Kelayakan aplikasi yang digunakan untuk memanggil API ini.   - Bagi Aplikasi dalaman, panggil API [Dapatkan access_token Aplikasi dalaman](/ms/open/development/obtain-orgapp-token) untuk mendapatkannya. - Bagi Aplikasi perusahaan pihak ketiga, panggil API untuk mendapatkan access_token organisasi pihak ketiga. |

### Isi permintaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| userid | String | Ya | manager4220 | ID pengguna bagi pengguna tersebut. |
| column_id_list | String | Ya | 129339038 | ID lajur laporan. Panggil API [Dapatkan definisi lajur laporan kehadiran](/ms/open/development/queries-the-enterprise-attendance-report-column) untuk mendapatkan nilai parameter id. Pisahkan berbilang nilai dengan koma. Panjang maksimum: 20. |
| from_date | Date | Ya | 2018-07-11 12:12:12 | Masa mula. |
| to_date | Date | Ya | 2018-07-11 12:12:12 | Masa tamat. Selang antara masa mula dengan masa tamat mestilah dalam lingkungan 31 hari. |

### Contoh permintaan

```curl
curl -X POST "https://api.dingtalk.io/topapi/attendance/getcolumnval" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=4bfc0fxxxx3916c7' \
-d 'column_id_list=1%2C2%2C3' \
-d 'from_date=2018-07-11+12%3A12%3A12' \
-d 'to_date=2018-07-11+12%3A12%3A12' \
-d 'userid=zhangsan'
```

Java

```text
DingTalkClient client = new DefaultDingTalkClient("https://api.dingtalk.io/topapi/attendance/getcolumnval");
OapiAttendanceGetcolumnvalRequest req = new OapiAttendanceGetcolumnvalRequest();
req.setUserid("manager4220");
req.setColumnIdList("129339038");
req.setFromDate(StringUtils.parseDateTime("2020-09-07 12:12:12"));
req.setToDate(StringUtils.parseDateTime("2020-09-09 12:12:12"));
OapiAttendanceGetcolumnvalResponse rsp = client.execute(req, access_token);
System.out.println(rsp.getBody());
```

## Respons

### Isi respons

| Nama | Jenis | Contoh | Penerangan |
| --- | --- | --- | --- |
| request_id | String | 45n2azecqj21 | ID permintaan. |
| errcode | Number | 0 | Kod pulangan. |
| result | ColumnValListForTopVo |  | Hasil yang dipulangkan. |
| column_vals | ColumnValForTopVo[] |  | Maklumat lajur dan data nilai lajur. |
| column_vals | ColumnDayAndVal[] |  | Data nilai lajur. |
| date | Date | 2020-09-09 00:00:00 | Tarikh. |
| value | String | 1.0 | Nilai lajur. |
| column_vo | ColumnForTopVo |  | Maklumat lajur. |
| id | Number | 129339038 | ID lajur laporan. |
| fixed_value | String | 0 | Nilai tetap.  **Nota**  Sesetengah lajur laporan mempunyai nilai tetap. Nilainya hanya dipulangkan dalam medan ini dan tidak dalam column_vals. |

### Kod ralat

Jika ralat berlaku semasa anda memanggil API ini, cari penyelesaian dalam dokumen [Kod ralat global](/ms/open/development/server-api-error-codes-1) berdasarkan mesej ralat.
