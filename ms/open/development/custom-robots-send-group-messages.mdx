Panggil API ini untuk menghantar sembang kumpulan menggunakan bot tersuai.

## Penerangan panggilan API

- API ini membolehkan bot tersuai menghantar sembang dalam Kumpulan Dalaman dan Kumpulan Standard dalam Organisasi Anda. Sebelum memanggil API ini, cipta bot tersuai. Untuk maklumat lanjut, lihat Membangunkan aplikasi bot.
- Jika anda mempunyai jumlah sembang yang besar untuk dihantar (contohnya, makluman pemantauan sistem), gabungkan maklumat tersebut dan hantar ke kumpulan sebagai ringkasan dalam sembang markdown.
- Jika bot tersuai menggunakan [tetapan keselamatan bot tersuai](/open/dingstart/customize-robot-security-settings), tambahkan parameter `timestamp` dan `sign` semasa memanggil API ini. Contoh:

  ```text
  https://oapi.dingtalk.io/robot/send?access_token=XXXXXX&timestamp=XXX&sign=XXX
  ```
- **Setiap bot boleh menghantar sehingga 20 sembang setiap minit ke satu kumpulan. Melebihi 20 sembang akan mencetuskan had kadar selama 10 minit.**

## Permintaan

| **Maklumat asas** | |
| --- | --- |
| URL HTTP | https://oapi.dingtalk.io/robot/send |
| Kaedah HTTP | POST |
| Jenis aplikasi disokong | appType-Aplikasi dalaman appType-Aplikasi perusahaan pihak ketiga |
| Kebenaran yang diperlukan | permission-qyapi_base-Kebenaran asas untuk memanggil API perusahaan |

### Parameter pertanyaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | BE3xxxx | Kelayakan yang digunakan oleh bot tersuai untuk memanggil API.  Nilai `access_token` daripada URL Webhook yang dijana selepas bot tersuai dipasang. Untuk maklumat lanjut, lihat [Dapatkan URL Webhook bot tersuai](/open/dingstart/obtain-the-webhook-address-of-a-custom-robot). |

### Isi permintaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| msgtype | String | Ya | text | Jenis sembang. Untuk jenis sembang yang disokong oleh bot tersuai, lihat Jenis sembang yang disokong oleh bot tersuai. |
| msgUuid | String | Tidak | 123 | Kunci kealihdayaan (idempotency key) untuk sembang, digunakan untuk mengawal kealihdayaan.  **Nota**  Kes penggunaan biasa: apabila panggilan API tamat masa atau mengembalikan ralat yang tidak dikenali, cuba semula dengan `msgUuid` yang sama untuk mengelakkan penghantaran sembang berganda. |
| text | Object | Tidak |  | Sembang teks. |
| content | String | Tidak | DingTalk makes progress happen | Kandungan sembang teks. |
| at | Object | Tidak |  | Maklumat tentang ahli kumpulan yang disebut dengan @. |
| isAtAll | Boolean | Tidak | false | Sama ada untuk menyebut @Semua Orang.   - true: Ya - false: Tidak |
| atMobiles | String[] | Tidak | ["15xxx,18xxx"] | Nombor mudah alih ahli kumpulan yang disebut dengan @. |
| atUserIds | String[] | Tidak | ["user001","user002"] | `userId` ahli kumpulan yang disebut dengan @.  **Nota**  Apabila menyebut ahli kumpulan dengan @, anda boleh menyebut sehingga 50 ahli. |
| link | Object | Tidak |  | Sembang pautan. |
| messageUrl | String | Tidak | https://www.dingtalk.io | URL yang dialihkan apabila sembang diketik. |
| title | String | Tidak | This is the title | Tajuk sembang pautan. |
| picUrl | String | Tidak | @aubHxxxxx | URL imej dalam sembang pautan. Kami mengesyorkan menggunakan API [Muat naik fail media](/open/development/upload-media-files) untuk mendapatkannya. |
| text | String | Tidak | The content of the link chat | Kandungan sembang pautan. |
| markdown | Object | Tidak |  | Sembang markdown. |
| text | String | Tidak | markdown chat content | Kandungan teks sembang markdown. |
| title | String | Tidak | The title shown in the chat list | Tajuk yang dipaparkan dalam senarai sembang, bukan tajuk isi sembang. |
| actionCard | Object | Tidak |  | Sembang actionCard. |
| hideAvatar | String | Tidak | 1 | Sama ada untuk memaparkan Gambar Profil Penghantar.   - 0: Paparkan Gambar Profil Penghantar - 1: Sembunyikan Gambar Profil Penghantar |
| btnOrientation | String | Tidak | 1 | Susun atur butang dalam sembang.   - 0: Butang disusun secara menegak - 1: Butang disusun secara melintang |
| singleURL | String | Tidak | https://www.dingtalk.io | URL yang dicetuskan apabila butang `singleTitle` diketik.  **Nota**  Wajib apabila sembang hanya mengandungi satu butang. |
| singleTitle | String | Tidak | This is a button | Pilihan butang tunggal. (Apabila ini dan `singleURL` ditetapkan, `btns` tidak berkuat kuasa.)  **Nota**  Wajib apabila sembang hanya mengandungi satu butang. |
| text | String | Tidak | Chat content | Kandungan isi sembang actionCard. Sintaks markdown disokong. |
| title | String | Tidak | The title shown in the chat list | Tajuk yang dipaparkan dalam senarai sembang, bukan tajuk isi sembang. |
| btns | Object[] | Tidak |  | Senarai maklumat butang.  **Nota**  Wajib apabila sembang mengandungi lebih daripada satu butang. |
| actionURL | String | Tidak | https://www.dingtalk.io | URL yang dialihkan oleh butang. |
| title | String | Tidak | This is a button | Teks yang dipaparkan pada butang. |
| feedCard | Object | Tidak |  | Sembang feedCard. |
| links | Object[] | Tidak |  | Senarai kandungan sembang feedCard. |
| picURL | String | Tidak | @aubHxxxxx | URL imej bagi setiap item dalam sembang feedCard. Kami mengesyorkan menggunakan API [Muat naik fail media](/open/development/upload-media-files) untuk mendapatkannya. |
| messageURL | String | Tidak | https://www.dingtalk.io | URL alihan bagi setiap item dalam sembang feedCard. |
| title | String | Tidak | Chat title | Tajuk bagi setiap item dalam sembang feedCard. |

### Contoh permintaan

```curl
curl -X POST "https://oapi.dingtalk.io/robot/send" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=c370586xxxxd65d506' \
-d 'actionCard=null' \
-d 'at=null' \
-d 'feedCard=null' \
-d 'link=null' \
-d 'markdown=null' \
-d 'msgtype=text' \
-d 'text=null'
```

## Respons

### Isi respons

| Nama | Jenis | Contoh | Penerangan |
| --- | --- | --- | --- |
| errmsg | String | ok | Penerangan kod ralat. |
| errcode | Number | 0 | Kod ralat. |

### Contoh isi respons

```json
{
  "errcode":"0",
  "errmsg":"ok"
}
```

### Kod ralat

Jika ralat dikembalikan semasa memanggil API ini, cari penyelesaian dalam dokumentasi [Kod ralat global](/open/development/server-api-error-codes-1) berdasarkan mesej ralat.

| Kod ralat (errorcode) | Penerangan ralat (errmsg) | Penyelesaian |
| --- | --- | --- |
| -1 | Sistem sibuk | Cuba semula kemudian |
| 40035 | Parameter json hilang | Tambahkan json sembang |
| 43004 | HTTP HEADER Content-Type tidak sah | Tetapkan parameter sembang yang khusus |
| 400013 | Kumpulan telah dibubarkan | Hantar sembang ke kumpulan lain |
| 400101 | access_token tidak wujud | Sahkan bahawa access_token dieja dengan betul |
| 400102 | Bot dinyahaktifkan | Hubungi Admin untuk mengaktifkan bot |
| 400105 | Jenis sembang tidak disokong | Gunakan jenis sembang yang disokong dalam dokumentasi |
| 400106 | Bot tidak wujud | Sahkan bahawa bot berada dalam kumpulan |
| 410100 | Had kadar dicetuskan akibat penghantaran terlalu pantas | Kurangkan kadar penghantaran |
| 430101 | Mengandungi pautan luaran yang tidak selamat | Sahkan bahawa kandungan yang dihantar mematuhi peraturan |
| 430102 | Mengandungi teks yang tidak sesuai | Sahkan bahawa kandungan yang dihantar mematuhi peraturan |
| 430103 | Mengandungi imej yang tidak sesuai | Sahkan bahawa kandungan yang dihantar mematuhi peraturan |
| 430104 | Mengandungi kandungan yang tidak sesuai | Sahkan bahawa kandungan yang dihantar mematuhi peraturan |

Apabila ralat berikut berlaku, sembang gagal disahkan. Semak tetapan keselamatan bot.

| Kod ralat (errorcode) | Penerangan ralat (errmsg) | Penyelesaian |
| --- | --- | --- |
| 310000 | - keywords not in content - invalid timestamp - sign not match - ip X.X.X.X not in whitelist | - Kandungan sembang tidak mengandungi sebarang kata kunci - Cap masa tidak sah - Tandatangan tidak sepadan - Alamat IP tidak dalam Senarai Dibenarkan |
