title: "Cari semua sel yang sepadan dengan kriteria"
description: "Panggil API ini untuk mencari dalam Helaian Kerja DingTalk Spreadsheet bagi semua sel yang mengandungi teks sasaran dan dapatkan lokasinya, dengan sokongan padanan tepat, sensitiviti huruf, regular expression, dan carian dalam formula."
---

Panggil API ini untuk mencari semua sel yang mengandungi teks sasaran dalam Helaian Kerja tertentu bagi DingTalk Spreadsheet, dan dapatkan senarai kedudukan sel yang sepadan. Ini sesuai untuk senario yang memerlukan kandungan tertentu dikesan secara pukal dalam set data yang besar. Ia menyokong pelbagai mod carian, termasuk padanan tepat, sensitiviti huruf, regular expression, dan carian dalam formula.

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/doc/workbooks/{workbookId}/sheets/{sheetId}/findAll` |
| Kaedah HTTP | POST |
| Jenis aplikasi yang disokong | appType-Aplikasi dalaman |
| Kebenaran diperlukan | permission-Document.Workbook.Read-Kebenaran baca DingTalk Spreadsheet |

### Header permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Panggil API [Dapatkan access token aplikasi dalaman](/open/development/obtain-the-access-token-of-an-internal-app) untuk mendapatkannya. |

### Parameter laluan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| workbookId | String | Ya | ID fail Spreadsheet. `nodeId(dentryUuid)` yang dikembalikan oleh [Knowledge Base API](/open/development/knowledge-base-overview) ialah `workbookId` Spreadsheet tersebut. Anda boleh mendapatkannya dengan memanggil API [Dapatkan nod](https://open.dingtalk.com/document/development/get-node) dan [Cipta dokumen Knowledge Base](/open/development/create-team-space-document). |
| sheetId | String | Ya | ID atau tajuk Helaian Kerja. Panggil API [Dapatkan semua Helaian Kerja](/open/development/obtain-all-worksheets) untuk mendapatkan ID dan tajuk Helaian Kerja tersebut. |

### Parameter pertanyaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| operatorId | String | Ya | unionId pengendali. Panggil API [Query maklumat terperinci pengguna](/open/development/query-user-details) untuk mendapatkannya. Jika pengendali tidak mempunyai kebenaran, API akan mengembalikan ralat `The operator has no permission`. |
| select | String | Tidak | Menapis medan yang dikembalikan. Jika parameter ini tidak dinyatakan, semua medan akan dikembalikan.   - Jika select=a1Notation, hanya medan a1Notation dikembalikan. - Untuk mengembalikan pelbagai medan, pisahkan dengan koma. Contohnya, select=a1Notation,values hanya mengembalikan medan a1Notation dan values. Disyorkan untuk menyatakan parameter ini bagi meningkatkan prestasi dan mengelakkan API timeout apabila nilai kembalian tambahan ditambah pada masa hadapan. |

### Isi permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| text | String | Ya | Teks yang hendak dicari. Jika **useRegExp** diaktifkan, ini ialah corak regular expression. Contoh: "\\d+" |
| findOptions | Object | Ya | Pilihan carian. |
| matchEntireCell | Boolean | Tidak | Sama ada hendak padankan keseluruhan sel. Nilai sah:   - **true**: Ya - **false**: Tidak (lalai) |
| matchCase | Boolean | Tidak | Sama ada carian sensitif huruf besar/kecil. Nilai sah:   - **true**: Ya - **false**: Tidak (lalai) |
| useRegExp | Boolean | Tidak | Sama ada text adalah regular expression. Nilai sah:   - **true**: Ya - **false**: Tidak (lalai) |
| matchFormulaText | Boolean | Tidak | Sama ada hendak mencari berdasarkan teks formula mentah. Nilai sah:   - **true**: Ya - **false**: Tidak (lalai)   Contohnya, jika satu sel diisi dengan formula "=A1+B1" dan nilai yang dipaparkan ialah 4:   - Apabila teks carian ialah "4" dan matchFormulaText ialah true, sel tersebut tidak disertakan dalam hasil. - Apabila teks carian ialah "=A1" dan matchFormulaText ialah true, sel tersebut disertakan dalam hasil. |
| scope | String | Tidak | Skop carian. Formatnya ialah alamat Range dalam notasi A1. |
| includeHidden | Boolean | Tidak | Sama ada hendak sertakan sel tersembunyi, iaitu sel yang tidak dapat dilihat kerana baris atau lajur tersembunyi, penapis, kumpulan, atau ciri yang serupa. Sel yang pengguna tidak mempunyai kebenaran untuk melihat tidak akan disertakan. Nilai sah:   - **true**: Ya - **false**: Tidak (lalai) |
| unionCells | Boolean | Ya | Sama ada hendak agregatkan alamat sel yang ditemui. Agregasi adalah disyorkan; jika tidak, sejumlah besar alamat mungkin dikembalikan. Nilai sah:   - **true**: Ya - **false**: Tidak (lalai) |
