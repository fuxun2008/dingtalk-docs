## Proses Pembangunan Sambungan Kumpulan

## Pengenalan kepada proses pembangunan sambungan kumpulan

Sebelum bermula, pastikan anda telah melengkapkan persediaan untuk [Menjadi Pembangun DingTalk](/ms/open/dingstart/become-a-dingtalk-developer). Proses pembangunan aplikasi kumpulan adalah seperti berikut:

1. Bangunkan Aplikasi Dalaman. Pembangunan sambungan kumpulan mesti berdasarkan aplikasi dalaman. Jika anda belum mempunyai aplikasi dalaman, cipta satu aplikasi. Jika anda sudah mempunyainya, anda boleh terus menggunakannya.
2. Konfigurasikan Tolak Mesej. Dalam **Tolak Mesej**, ikat dan bangunkan Bot.
3. Konfigurasikan Maklumat Asas Sambungan Kumpulan. Dalam **Sambungan Cool App** aplikasi dalaman, aktifkan sambungan kumpulan dan konfigurasikan maklumat asasnya. Selepas berjaya dicipta, anda boleh mendapatkan kod aplikasi sambungan kumpulan.
4. Bangunkan Kad Interaktif (pilihan). Dengan mengikat Bot, anda boleh menghantar Kad interaktif dan banyak lagi.
5. Aktifkan Aplikasi Sambungan Kumpulan. Selepas pembangunan aplikasi kumpulan selesai, anda perlu **menambahkannya ke dalam kumpulan** dan mengaktifkannya di Pusat Cool App.
6. Gunakan Aplikasi Sambungan Kumpulan. Dalam bar aplikasi kumpulan bagi Kumpulan Dalaman, lihat dan gunakan Cool App tersebut.

## API biasa untuk sambungan kumpulan

Untuk API biasa bagi sambungan kumpulan, sila rujuk API Biasa untuk Sambungan Kumpulan.

Untuk API Bahagian Klien sambungan kumpulan, sila rujuk Pasang Cool App dan Tambahkannya ke dalam Kumpulan.
