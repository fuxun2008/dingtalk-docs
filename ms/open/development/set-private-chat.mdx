Panggil API ini untuk mengawal sama ada Ahli kumpulan boleh saling menambah sebagai Kenalan dan memulakan sembang peribadi. Ia sesuai untuk senario apabila Kumpulan Dalaman perlu menyekat komunikasi antara ahli atau melindungi keselamatan maklumat.

## Permintaan

| **Maklumat asas** | |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/topapi/chat/member/friendswitch/update |
| Kaedah HTTP | POST |
| Jenis aplikasi yang disokong | appType-Aplikasi dalaman |
| Kebenaran Wajib | permission-qyapi_chat_manage-Kebenaran pengurusan maklumat asas Kumpulan DingTalk |

### Parameter pertanyaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| access_token | string | Ya | 6d1bxxxx | Kelayakan aplikasi untuk memanggil API ini. Dapatkan melalui API untuk mendapatkan access_token bagi Aplikasi dalaman. |

### Isi permintaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| chatid | string | Ya | chatdafe234xxxx | ID Sembang bagi Organisasi. Dapatkan dengan salah satu cara berikut:   - Panggil API Bahagian pelayan untuk mencipta Kumpulan bagi mendapatkan nilai parameter chatid. - Panggil API chooseChat Bahagian klien untuk mendapatkan nilai parameter chatId. |
| is_prohibit | Boolean | Ya | true | Sama ada hendak mengaktifkan suis sekatan.   - **true**: Aktifkan suis sekatan. - **false**: Nyahaktifkan suis sekatan. |

### Contoh permintaan

```curl
curl -X POST "https://api.dingtalk.io/topapi/chat/member/friendswitch/update" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=774fdexxxx4bdd68c' \
-d 'chatid=chatdafe234sdf3sdf' \
-d 'is_prohibit=true'
```

Java

```text
DingTalkClient client = new DefaultDingTalkClient("https://api.dingtalk.io/topapi/chat/member/friendswitch/update");
OapiChatMemberFriendswitchUpdateRequest req = new OapiChatMemberFriendswitchUpdateRequest();
req.setChatid("chatdafe234xxxx");
req.setIsProhibit(true);
OapiChatMemberFriendswitchUpdateResponse rsp = client.execute(req, access_token);
System.out.println(rsp.getBody());
```

## Respons

### Isi respons

| Nama | Jenis | Contoh | Penerangan |
| --- | --- | --- | --- |
| success | Boolean | true | Sama ada konfigurasi berjaya.   - **true**: Berjaya. - **false**: Gagal. |
| errcode | Nombor | 0 | Kod pemulangan. |
| errmsg | string | ok | Penerangan kod pemulangan. |
| request_id | string | 10c0wc48i6qzz | ID Permintaan. |

### Contoh respons

```json
{
  "success":true,
  "errcode":0,
  "errmsg":"ok",
  "request_id":"10c0wc48i6qzz"
}
```

### Kod ralat

Jika Ralat dikembalikan semasa anda memanggil API ini, rujuk dokumentasi [Kod ralat global](/open/development/server-api-error-codes-1) untuk penyelesaian.

| Kod ralat (errorcode) | Mesej ralat (errmsg) | Penyelesaian |
| --- | --- | --- |
| 34001 | chatid tidak sah | Semak sama ada chatid memenuhi keperluan. |
| 40036 | Parameter kosong | Sahkan bahawa semua parameter Wajib telah disediakan. |
| 400001 | Ralat sistem | Cuba Lagi kemudian. |
