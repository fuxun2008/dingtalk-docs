Panggil API ini untuk menambah folder dalam ruang storan.

## Penerangan panggilan API

Selepas menambah ruang storan, panggil API ini untuk menambah folder dalam ruang tersebut.

- Apabila jenis ruang storan ialah USER, semua pengguna yang mempunyai kebenaran pada ruang tersebut mempunyai kebenaran operasi. Pekerja lain perlu memanggil API [Tambah kebenaran](/ms/open/development/add-permissions-file) untuk memberikan kebenaran.
- Apabila jenis ruang storan ialah APP, sesiapa yang melakukan operasi perlu memanggil API [Tambah kebenaran](/ms/open/development/add-permissions-file) untuk memberikan kebenaran.

## Permintaan

### Asas

| Medan | Nilai |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/storage/spaces/{spaceId}/dentries/{parentId}/folders` |
| Kaedah HTTP | POST |
| Jenis aplikasi yang disokong | appType-Aplikasi dalaman　appType-Aplikasi perusahaan pihak ketiga |
| Kebenaran diperlukan | permission-Storage.File.Write-Kebenaran tulis fail storan organisasi |

### Pengepala permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Dapatkan seperti berikut:   - Untuk aplikasi dalaman, panggil API [Dapatkan access token aplikasi dalaman](/ms/open/development/obtain-the-access-token-of-an-internal-app#) untuk mendapatkannya. - Untuk aplikasi perusahaan pihak ketiga, panggil API [Dapatkan access token organisasi yang diberi kuasa kepada aplikasi pihak ketiga](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#) untuk mendapatkannya. |

### Parameter laluan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| spaceId | String | Ya | ID ruang. Panggil API [Tambah ruang](/ms/open/development/add-space#) untuk mendapatkan nilai parameter id. |
| parentId | String | Ya | ID direktori induk. Panggil API [Dapatkan senarai fail atau folder](https://open.dingtalk.com/document/development/obtain-the-file-list-storage#) untuk mendapatkannya. Untuk direktori root, tetapkan parameter ini kepada 0. |

### Parameter pertanyaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| unionId | String | Ya | unionId pengendali. Panggil API [Tanya butiran pengguna](/ms/open/development/query-user-details#) untuk mendapatkannya. |

### Isi permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| name | String | Ya | Nama folder. Keperluan penamaan:- Tiada ruang di hadapan atau di belakang. Jika ada, ia akan dialih keluar secara automatik. - Tiada aksara khas, termasuk: tab, `*`, `"`, `<`, `>`, `|`. - Tidak boleh berakhir dengan `.`. |
| option | Object | Tidak | Parameter pilihan. |
| conflictStrategy | String | Tidak | Strategi konflik untuk nama folder.   - **AUTO_RENAME**: Namakan semula secara automatik. Nilai lalai. - **OVERWRITE**: Tulis ganti. - **RETURN_DENTRY_IF_EXISTS**: Kembalikan folder sedia ada. - **RETURN_ERROR_IF_EXISTS**: Kembalikan ralat jika folder sudah wujud. |
| appProperties | Array | Tidak | Senarai sifat aplikasi bagi folder semasa. Nilai maksimum: 3. |
| name | String | Ya | Nama sifat. |
| value | String | Ya | Nilai sifat. |
| visibility | String | Ya | Keterlihatan sifat.   - **PUBLIC**: Boleh dilihat oleh semua aplikasi. - **PRIVATE**: Hanya boleh dilihat oleh aplikasi semasa. |
