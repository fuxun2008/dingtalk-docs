Panggil API ini untuk mendapatkan senarai peranan.

## Permintaan

| **Maklumat asas** | |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/topapi/role/list |
| Kaedah HTTP | POST |
| Jenis aplikasi disokong | appType-Aplikasi dalaman, appType-Aplikasi perusahaan pihak ketiga |
| Kebenaran | permission-qyapi_get_department_list-Kebenaran Telah dibaca untuk maklumat jabatan Kenalan |

### Parameter query

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | 6ed1bxxx | Kelayakan aplikasi yang digunakan untuk memanggil API ini.   - Bagi aplikasi dalaman, dapatkan melalui API untuk mendapatkan [access_token aplikasi dalaman](/ms/open/development/obtain-orgapp-token). - Bagi aplikasi perusahaan pihak ketiga, dapatkan melalui API untuk mendapatkan access_token perusahaan pihak ketiga. |

### Isi permintaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| size | Nombor | Tidak | 20 | Menyokong pertanyaan bersegmen (pagination). Hanya berkuat kuasa apabila ditetapkan bersama parameter offset. Parameter ini mewakili saiz halaman. Lalai ialah 20. Maksimum ialah 200. |
| offset | Nombor | Tidak | 0 | Menyokong pertanyaan bersegmen (pagination). Hanya berkuat kuasa apabila ditetapkan bersama parameter size. Parameter ini mewakili offset, bermula daripada 0. |

### Contoh permintaan

```curl
curl -X POST "https://api.dingtalk.io/topapi/role/list" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=a0a639xxxx2998' \
-d 'offset=0' \
-d 'size=20'
```

Java

```text
DingTalkClient client = new DefaultDingTalkClient("https://api.dingtalk.io/topapi/role/list");
OapiRoleListRequest req = new OapiRoleListRequest();
req.setSize(20L);
req.setOffset(0L);
OapiRoleListResponse rsp = client.execute(req, access_token);
System.out.println(rsp.getBody());
```

Python

```python
import dingtalk.api

req=dingtalk.api.OapiRoleListRequest("https://api.dingtalk.io/topapi/role/list")

req.size=20
req.offset=0
try:
  resp= req.getResponse(access_token)
  print(resp)
except Exception,e:
  print(e)
```

PHP

```php
include "TopSdk.php";
date_default_timezone_set('Asia/Shanghai');

$c = new DingTalkClient(DingTalkConstant::$CALL_TYPE_OAPI, DingTalkConstant::$METHOD_POST , DingTalkConstant::$FORMAT_JSON);
$req = new OapiRoleListRequest;
$req->setSize("20");
$req->setOffset("0");
$resp = $c->execute($req, $access_token, "https://api.dingtalk.io/topapi/role/list");
```

C#

```text
IDingTalkClient client = new DefaultDingTalkClient("https://api.dingtalk.io/topapi/role/list");
OapiRoleListRequest req = new OapiRoleListRequest();
req.Size = 20L;
req.Offset = 0L;
OapiRoleListResponse rsp = client.Execute(req, access_token);
Console.WriteLine(rsp.Body);
```

## Respons

### Isi respons

| Nama | Jenis | Contoh | Penerangan |
| --- | --- | --- | --- |
| request_id | String | ii8a42qgzu7e | ID permintaan. |
| errcode | Nombor | 0 | Kod pulangan. |
| errmsg | String | ok | Penerangan kod pulangan. |
| result | PageVo |  | Senarai hasil. |
| hasMore | Boolean | false | Sama ada terdapat lebih banyak data. |
| list | OpenRoleGroup[] |  | Senarai kumpulan peranan. |
| name | String | Default | Nama kumpulan peranan. |
| groupId | Nombor | 1507113577 | ID kumpulan peranan. |
| roles | OpenRole[] |  | Senarai peranan. |
| name | String | Admin | Nama peranan. |
| id | Nombor | 1507113578 | ID peranan. |

### Kod ralat

Jika ralat dikembalikan semasa anda memanggil API ini, cari penyelesaian dalam dokumen [Kod ralat global](/ms/open/development/server-api-error-codes-1) berdasarkan mesej ralat.

| Kod ralat (errcode) | Mesej ralat (errmsg) | Penyelesaian |
| --- | --- | --- |
| 400043 | Invalid orgId | Semak sama ada access_token adalah betul. |
| 40069 | Invalid size | Laraskan saiz halaman. |
| 40068 | Invalid offset | Laraskan offset. |
| 400001 | System error | Cuba Lagi kemudian. |
