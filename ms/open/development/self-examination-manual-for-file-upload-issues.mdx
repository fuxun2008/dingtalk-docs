Panduan ini menerangkan cara menyelesaikan isu biasa yang dihadapi semasa muat naik fail.

## Penghantaran fail gagal

Muat Naik Fail terdiri daripada tiga langkah. Untuk maklumat lanjut, lihat [Dapatkan maklumat muat naik fail](/open/development/obtain-file-upload-informations).

1. Dapatkan maklumat muat naik fail.
2. Muat naik fail ke OSS melalui HTTP.
3. Hantar fail.

### Sahkan bahawa Langkah 2 (memuat naik fail ke OSS) mengembalikan 200.

## Gagal memuat naik fail ke OSS

Semak kod anda. Gantikan `<authorization>`, `<x-oss-date>`, dan `<url>` dengan nilai yang dikembalikan oleh API maklumat muat naik fail dalam Langkah 1. Gantikan `a.txt` dengan fail sedia ada tempatan, kemudian jalankan arahan berikut:

```bash
curl -v -T a.txt \
--header "Authorization: <authorization>" \
--header "x-oss-date: <x-oss-date>" \
--url "<url>"
```

- Jika curl mengembalikan ralat `RequestTimeTooSkewed`, maklumat muat naik telah tamat tempoh. Dapatkan semula maklumat muat naik fail.
- Jika curl mengembalikan 200, isu tersebut terletak pada kod anda. Dokumentasi menyediakan demo dalam bahasa yang berkaitan. Rujuk contoh yang berkaitan untuk menyelesaikan masalah pada kod anda.
- Jika muat naik kod anda mengembalikan `SignatureDoesNotMatch`, kemungkinan besar pengepala permintaan HTTP mengandungi `contentType` tambahan. Tetapkannya kepada kosong secara eksplisit. (Anda boleh mencetak pengepala permintaan untuk memeriksa nilai `contentType`.)
- Jika curl tidak mengembalikan 200:

  - Jika kegagalan resolusi domain atau kegagalan sambungan dilaporkan, selesaikan masalah seperti berikut:

    - `ping <domain atau IP>`
    - `telnet <domain atau IP> 443`
    - Sambung ke hotspot mudah alih dan jalankan ping serta telnet, atau tukar ke rangkaian lain dan cuba lagi.
    - Nyahaktifkan firewall pada komputer anda, kemudian jalankan ping dan telnet.
    - Hubungi pasukan IT anda untuk memasukkan domain awam OSS ke dalam Senarai Dibenarkan. Lihat **Lampiran I** di bahagian bawah dokumen ini untuk senarai domain.
    - Untuk storan khusus, hubungi pasukan operasi storan khusus untuk menyiasat isu sambungan rangkaian.
