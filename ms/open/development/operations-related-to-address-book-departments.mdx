Topik ini menerangkan cara mencipta aplikasi dalaman dan menggunakan API pengurusan jabatan yang disediakan oleh Kenalan untuk mencipta, mendapatkan, mengemas kini, dan memadam jabatan dalam Organisasi Anda.

## Hasil yang dijangka

Maklumat jabatan dipaparkan seperti berikut:

## Aliran integrasi

1. Dapatkan kelayakan aplikasi untuk memperoleh client ID dan Client Secret.
2. Mohon kebenaran API yang berkaitan dengan pengurusan Kenalan.
3. Dapatkan Kredensial akses untuk memperoleh `access_token` bagi Aplikasi dalaman. Apabila anda memanggil API, access token digunakan untuk mengesahkan pemanggil.
4. Panggil API Kenalan:

   1. Panggil Server API [Cipta jabatan](/open/development/address-book-creation-department-established-department) untuk mencipta jabatan dan mendapatkan `dept_id`.

      - Untuk mencipta Subjabatan di bawah Jabatan root, tetapkan `parent_id` kepada 1. Contoh ini mencipta Subjabatan di bawah Jabatan root.
      - Untuk mencipta Subjabatan di bawah jabatan lain, panggil dahulu [Dapatkan Senarai jabatan](/open/development/user-management-acquires-the-list-departments) untuk memperoleh ID jabatan, dan kemudian gunakannya sebagai nilai `parent_id`.
   2. Panggil Server API [Dapatkan butiran jabatan](/open/development/query-department-details0-v2) dengan `dept_id` untuk mendapatkan butiran jabatan.
   3. Panggil Server API [Kemas kini jabatan](/open/development/address-book-update-department) dengan `dept_id` untuk mengemas kini maklumat jabatan.
   4. Panggil Server API [Padam jabatan](/open/development/address-book-deletion-department) dengan `dept_id` untuk memadam jabatan.

## Prasyarat

Aliran [Cipta dan konfigurasikan aplikasi](/open/dingstart/create-application) telah selesai.

## Langkah 1: Dapatkan kelayakan aplikasi

1. Pilih aplikasi sasaran dan pergi ke halaman butiran aplikasi. Klik **Maklumat asas** > **Kelayakan dan maklumat asas**.
2. Dapatkan client ID dan Client Secret.

## Langkah 2: Tambah kebenaran API

Klik **Konfigurasi pembangunan** > **Urus kebenaran**. Dalam kotak carian kebenaran, masukkan `qyapi_manage_addresslist` dan `qyapi_get_department_list`, dan kemudian mohon kebenaran tersebut.

## Langkah 3: Dapatkan access token

### Penting

- Untuk maklumat lanjut tentang perbezaan antara API lama dan Server API baharu, lihat API lama berbanding API baharu.
- Untuk memuat turun SDK Server API, lihat Muat turun SDK Bahagian pelayan.

Gunakan client ID dan Client Secret yang diperoleh dalam Langkah 1 untuk mendapatkan `access_token` bagi Aplikasi dalaman.

```java
public void getAccessToken() throws ApiException {
        DingTalkClient client = new DefaultDingTalkClient("https://oapi.dingtalk.io/gettoken");
        OapiGettokenRequest req = new OapiGettokenRequest();
        req.setAppkey("dingxxxxxxxxxhgn");
        req.setAppsecret("9G_xxxxxxxxxxxxxxx1JDf0Qq3nexxxxxxxxGIO");
        req.setHttpMethod("GET");
        OapiGettokenResponse rsp = client.execute(req);
        System.out.println(rsp.getBody());
    }
```

## Langkah 4: Panggil API Kenalan

1. Panggil Server API [Cipta jabatan](/open/development/address-book-creation-department-established-department) untuk mencipta jabatan dan mendapatkan `dept_id`.

   ```java lines
   public void deptCreate() throws ApiException {
           DingTalkClient client = new DefaultDingTalkClient("https://api.dingtalk.io/topapi/v2/department/create");
           OapiV2DepartmentCreateRequest req = new OapiV2DepartmentCreateRequest();
           req.setParentId(1L);
           req.setOuterDept(true);
           req.setHideDept(false);
           req.setCreateDeptGroup(true);
           req.setOrder(1L);
           req.setName("1019 Test Department");
           req.setSourceIdentifier("1019 Test Department");
           req.setOuterPermitUsers("manager7675,01472825524039877041");
           req.setOuterDeptOnlySelf(true);
           OapiV2DepartmentCreateResponse rsp = client.execute(req, "access_token");
           System.out.println(rsp.getBody());
       }
   ```

   - Untuk mencipta Subjabatan di bawah Jabatan root, tetapkan `parent_id` kepada 1. Contoh ini mencipta Subjabatan di bawah Jabatan root.
   - Untuk mencipta Subjabatan di bawah jabatan lain, panggil dahulu [Dapatkan Senarai jabatan](/open/development/user-management-acquires-the-list-departments) untuk memperoleh ID jabatan, dan kemudian gunakannya sebagai nilai `parent_id`.

     ```java lines
     public void departmentList() throws ApiException {

             req.setLanguage("zh_CN");
             OapiV2DepartmentListsubResponse rsp = client.execute(req, "access_token");
             System.out.println(rsp.getBody());
         }
     ```

4. Panggil Server API [Padam jabatan](/open/development/address-book-deletion-department) dengan `dept_id` untuk memadam jabatan.

   ```java lines
    public void deptDelete() throws ApiException {
           DingTalkClient client = new DefaultDingTalkClient("https://api.dingtalk.io/topapi/v2/department/delete");
           OapiV2DepartmentDeleteRequest req = new OapiV2DepartmentDeleteRequest();
           req.setDeptId(724960197L);

   ```

   **Nota**
   - Jabatan tidak boleh dipadam jika ia mengandungi pengguna atau jika mana-mana Subjabatannya mengandungi pengguna.
   - Jabatan tersebut dan semua Subjabatannya akan dipadam.
   - Selepas jabatan dipadam, Sembang Jabatan yang berkaitan akan dibubarkan secara automatik.
