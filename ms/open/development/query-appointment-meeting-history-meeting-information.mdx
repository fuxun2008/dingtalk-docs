Tanyakan maklumat sejarah mesyuarat bagi mesyuarat yang ditempah dan telah bermula. Maklumat mesyuarat terkini akan dikembalikan.

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/conference/videoConferences/scheduleConferences/{scheduleConferenceId}` |
| Kaedah HTTP | GET |
| Jenis aplikasi yang disokong | appType-Aplikasi dalaman　appType-Aplikasi perusahaan pihak ketiga |
| Kebenaran | permission-VideoConference.Conference.Read-Kebenaran membaca maklumat Mesyuarat Video |

### Header permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses yang digunakan untuk memanggil API ini:   - Untuk aplikasi dalaman, panggil API [Get the access token of an internal app](/open/development/obtain-the-access-token-of-an-internal-app) untuk mendapatkannya. - Untuk aplikasi perusahaan pihak ketiga, panggil API [Get the access token of an authorized organization for a third-party app](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1) untuk mendapatkannya. |

### Parameter laluan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| scheduleConferenceId | String | Ya | ID mesyuarat yang ditempah. Anda boleh mendapatkannya daripada medan `scheduleConferenceId` yang dikembalikan oleh API [Create a booked meeting](/open/development/create-appointment-meeting). |

### Parameter pertanyaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| nextToken | String | Tidak | Kedudukan untuk mula membaca. Biarkan kosong untuk mula dari awal. |
| maxResults | Integer | Tidak | Bilangan maksimum rekod data yang dibaca dalam permintaan ini. |

## Respons

### Isi respons

| Nama | Jenis | Penerangan |
| --- | --- | --- |
| totalCount | Integer | Jumlah bilangan rekod data yang sepadan dengan syarat permintaan. Parameter ini bersifat pilihan dan mungkin tidak dikembalikan secara lalai. |
| nextToken | String | Kedudukan yang dibaca oleh panggilan ini. Nilai kosong menunjukkan semua data telah dibaca. |
| conferenceList | Array | Senarai mesyuarat. |
| conferenceId | String | ID mesyuarat. |
| title | String | Tajuk mesyuarat. |
| roomCode | String | Nombor mesyuarat. |
| status | Integer | Status mesyuarat:   - **0**: Belum bermula - **1**: Telah tamat - **2**: Sedang berlangsung |
| startTime | Long | Masa mula mesyuarat, sebagai cap masa UTC dalam milisaat. |
| endTime | Long | Masa tamat mesyuarat, sebagai cap masa UTC dalam milisaat. |
