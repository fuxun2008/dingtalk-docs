Panggil API ini untuk menanya senarai rekod peletakan jawatan Organisasi Anda, termasuk tarikh peletakan jawatan, Nombor Telefon, dan cara setiap pekerja yang telah meletak jawatan meninggalkan organisasi.

## Penerangan panggilan API

Sebagai contoh, dalam Aplikasi Smart HR sesebuah organisasi, rekod peletakan jawatan dari 1 Jun 2022 hingga 7 Jun 2022 ditunjukkan seperti di bawah. Tarikh peletakan jawatan pekerja Xiaoding 2 ialah 7 Jun 2022, dan tarikh peletakan jawatan DingTalk Test ialah 7 Jun 2022.

Panggil API ini untuk menanya rekod peletakan jawatan dari 1 Jun 2022 hingga 7 Jun 2022, dan anda boleh mendapatkan maklumat seperti masa pekerja Xiaoding 2 dan DingTalk Test meninggalkan organisasi, Nombor Telefon mereka, dan cara mereka meninggalkan organisasi.

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/v1.0/contact/empLeaveRecords |
| Kaedah HTTP | GET |
| Jenis aplikasi yang disokong | appType-Aplikasi dalaman |
| Kebenaran diperlukan | permission-Contact.Common.Read-Kebenaran Baca untuk data Kenalan asas |

### Pengepala permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Untuk mendapatkannya, panggil API [Dapatkan access token aplikasi dalaman](/ms/open/development/obtain-the-access-token-of-an-internal-app#). |

### Parameter pertanyaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| startTime | String | Ya | Masa mula. Format: `YYYY-MM-DDTHH:mm:ssZ` (ISO 8601/RFC 3339). |
| endTime | String | Tidak | Masa tamat. Format: `YYYY-MM-DDTHH:mm:ssZ` (ISO 8601/RFC 3339). - Jika parameter ini tidak dinyatakan, masa mula mesti dalam lingkungan 365 hari daripada masa semasa. - Jika parameter ini dinyatakan, jarak antara masa mula dan masa tamat tidak boleh melebihi 365 hari. |
| nextToken | String | Tidak | Cursor penomboran halaman. - Untuk pertanyaan pertama, tetapkan parameter ini kepada 0. - Untuk pertanyaan seterusnya, tetapkan parameter ini kepada nilai nextToken yang dikembalikan oleh panggilan sebelumnya kepada API ini. |
| maxResults | Integer | Ya | Bilangan maksimum entri setiap halaman. Nilai maksimum: 50. |

### Contoh permintaan

## Respons

### Isi respons

| Nama | Jenis | Penerangan |
| --- | --- | --- |
| nextToken | String | Token penomboran halaman untuk permintaan seterusnya. |
| records | Array | Senarai rekod peletakan jawatan. |
| userId | String | userId pekerja. |
| name | String | Nama pekerja. |
| stateCode | String | Kod dail antarabangsa. |
| mobile | String | Nombor Telefon. |
| leaveTime | String | Masa pekerja meninggalkan organisasi. Format: `YYYY-MM-DDTHH:mm:ssZ` (ISO 8601/RFC 3339). |
| leaveReason | String | Cara pekerja meninggalkan organisasi. Nilai sah: - **oapi**: Dipadam melalui panggilan API. - **cancel**: Akaun dibatalkan. - **leave**: Peletakan jawatan secara sukarela. - **unknown**: Sebab tidak diketahui. - **delete**: Dipadam oleh admin. |
