title: "Query text content of a meeting recording"
description: "Call this API to query the speech-to-text content of a video meeting recording, including text content, recording start time, and recording end time."
---

Panggil API ini untuk menanyakan kandungan speech-to-text bagi rakaman Mesyuarat Video, termasuk kandungan teks, masa mula rekod teks, dan masa tamat rekod teks.

## Penerangan panggilan API

Jika rakaman awan (Flash Minutes) diaktifkan untuk Mesyuarat Video DingTalk, pertuturan Ahli semasa tempoh rakaman awan akan ditukar secara automatik kepada teks dan disimpan sebagai rekod.

Contohnya, Tuan Rumah sesuatu Mesyuarat mengaktifkan ciri **Meeting Recording — Cloud Recording**. Selepas Mesyuarat tamat, Tuan Rumah menerima mesej push tentang Rakaman Mesyuarat. Kandungan speech-to-text bagi Rekod tersebut ditunjukkan dalam rajah berikut.

Panggil API ini untuk mendapatkan kandungan teks yang dihasilkan semasa rakaman awan, termasuk kandungan teks, masa mula rekod teks, dan masa tamat rekod teks.

Apabila Tuan Rumah mengaktifkan Meeting Recording, **Cloud Recording (Flash Minutes)** perlu dipilih terlebih dahulu. Selain itu, Ahli mestilah telah bercakap semasa tempoh rakaman sebelum API ini boleh dipanggil untuk menanyakan kandungan teks bagi Rakaman Mesyuarat.

| --- | --- | --- | --- |
