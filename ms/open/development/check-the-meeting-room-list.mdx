title: "Query the list of rooms"
description: "Call this API to query the list of meeting rooms, returning each room's name, capacity, and location information."
---

Panggil API ini untuk menanya senarai bilik, termasuk nama bilik, kapasiti, dan lokasi.

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/v1.0/rooms/meetingRoomLists |
| Kaedah HTTP | GET |
| Jenis aplikasi yang disokong | appType-Aplikasi dalaman　appType-Aplikasi perusahaan pihak ketiga |
| Kebenaran diperlukan | permission-VideoConference.Conference.Read-Kebenaran membaca untuk maklumat Mesyuarat Video |

### Header permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Dapatkan seperti berikut:   - Untuk aplikasi dalaman, panggil API [Dapatkan access token aplikasi dalaman](/ms/open/development/obtain-the-access-token-of-an-internal-app#). - Untuk aplikasi perusahaan pihak ketiga, panggil API [Dapatkan access token bagi organisasi yang diberi kuasa kepada aplikasi pihak ketiga](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#). |

### Parameter pertanyaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| nextToken | Long | Tidak | Cursor penomboran halaman.   - Biarkan parameter ini kosong untuk panggilan pertama. - Untuk panggilan seterusnya, hantar nextToken yang dikembalikan oleh panggilan sebelumnya. |
| maxResults | Integer | Tidak | Saiz halaman. Lalai: 20. Maksimum: 100. |
| unionId | String | Ya | unionId bagi operator. Dapatkan dengan memanggil API [Menanya butiran pengguna](/ms/open/development/query-user-details#). |

### Contoh permintaan

## Respons

### Isi respons

| Nama | Jenis | Penerangan |
| --- | --- | --- |
| hasMore | Boolean | Sama ada terdapat lagi hasil.   - **true**: Ya - **false**: Tidak |
| nextToken | Long | Cursor penomboran halaman. |
| result | Array | Senarai bilik. |
| roomId | String | ID bilik. |
| roomStaffId | String | ID Pekerja bagi bilik dalam organisasi.      Medan simpanan. Tidak digunakan buat masa ini. |
| corpId | String | ID Organisasi (CorpId) tempat bilik ini dimiliki. |
| roomName | String | Nama bilik. |
| roomStatus | Integer | Status bilik.   - **0**: Boleh dilihat oleh semua ahli - **1**: Hanya boleh dilihat oleh pentadbir - **2**: Boleh dilihat oleh pengguna terpilih |
| roomLabels | Array | Senarai tag bilik. |
| labelId | Long | ID tag.   - **1**: TV - **2**: Telefon - **3**: Projektor - **4**: Whiteboard - **5**: Mesyuarat Video |
| labelName | String | Nama tag. |
| roomCapacity | Integer | Kapasiti bilik. |
| roomLocation | Object | Lokasi bilik. |
| title | String | Nama lokasi bilik. |
| desc | String | Maklumat lokasi terperinci bagi bilik. |
| roomPicture | String | Gambar bilik. |
| isvRoomId | String | ID bilik luaran bagi pemanggil. |
| roomGroup | Object | Maklumat kumpulan bilik. |
| groupId | Long | ID kumpulan. |
| groupName | String | Nama kumpulan. |
| parentId | Long | ID kumpulan induk. |
