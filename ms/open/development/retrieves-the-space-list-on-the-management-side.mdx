# Dapatkan maklumat ruang tertentu mengikut spaceId

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/v1.0/drive/managements/spaces/query |
| Kaedah HTTP | POST |
| Jenis aplikasi yang disokong | appType-Aplikasi dalaman　appType-Aplikasi perusahaan pihak ketiga |
| Keperluan kebenaran | permission-Drive.SpaceManage.Read-Kebenaran baca untuk maklumat pengurusan ruang aplikasi Drive |

### Pengepala permintaan

| Nama | Jenis | Wajib | Keterangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Dapatkan menggunakan salah satu cara berikut:   - Untuk aplikasi dalaman, panggil API [Dapatkan access token aplikasi dalaman](/ms/open/development/obtain-the-access-token-of-an-internal-app). - Untuk aplikasi perusahaan pihak ketiga, panggil API [Dapatkan access token organisasi yang diberi kebenaran kepada aplikasi pihak ketiga](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1). |

### Isi permintaan

| Nama | Jenis | Wajib | Keterangan |
| --- | --- | --- | --- |
| spaceIds | Array of String | Ya | Senarai ID ruang. Anda boleh memasukkan sehingga 30 ID. Panggil API [Dapatkan senarai ruang](/ms/open/development/queries-a-space-list) untuk mendapatkannya. |
| unionId | String | Ya | unionId pengguna. Panggil API [Tanya butiran pengguna](/ms/open/development/query-user-details) untuk mendapatkannya. |

### Contoh permintaan

HTTP

```http
POST /v1.0/drive/managements/spaces/query HTTP/1.1
Host:api.dingtalk.io
x-acs-dingtalk-access-token:2db66caxxxx
Content-Type:application/json

{
  "spaceIds" : [ "123" ],
  "unionId" : "sKUPRiijxxxxx"
}
```

## Respons

### Isi respons

| Nama | Jenis | Keterangan |
| --- | --- | --- |
| spaces | Array | Senarai ruang. |
| spaceId | String | ID ruang. |
| spaceName | String | Nama ruang. |
| spaceType | String | Jenis ruang.   - **personal**: Ruang peribadi - **org**: Ruang organisasi |
| quota | Long | Kuota keseluruhan ruang.   - **-1**: Kuota ruang tidak terhad. Jika ruang mempunyai atribut organisasi, ia tidak boleh melebihi kuota ruang organisasi. |
| usedQuota | Long | Kuota ruang yang telah digunakan. |
| permissionMode | String | Mod kebenaran. Nilai yang sah:   - **acl**: Kebenaran ACL - **custom**: Kebenaran Tersuai |
| createTime | String | Masa dicipta, dalam format ISO 8601, contohnya 2022-07-29T14:55Z. |
| modifyTime | String | Masa diubah suai, dalam format ISO 8601, contohnya 2022-07-29T14:55Z. |

### Contoh isi respons

```text
HTTP/1.1 200 OK
Content-Type:application/json

{
  "spaces" : [ {
    "spaceId" : "123456789",
    "spaceName" : "Folder dikongsi Zhang San",
    "spaceType" : "org",
    "quota" : 2147483648,
    "usedQuota" : 640445953,
    "permissionMode" : "acl",
    "createTime" : "2016-02-28T10:47:08Z",
    "modifyTime" : "2021-03-29T14:20:36Z"
  } ]
}
```
