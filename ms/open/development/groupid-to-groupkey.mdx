---

Panggil API ini untuk menukar groupId kumpulan kehadiran kepada groupKey. groupKey ialah medan pengecam yang digunakan dalam versi baharu kumpulan kehadiran. Sesetengah kumpulan kehadiran memerlukan groupKey sebagai parameter. Jika anda hanya mempunyai medan groupId kumpulan kehadiran, panggil API ini untuk mendapatkan groupKey.

## Permintaan

| **Maklumat asas** | |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/topapi/attendance/groups/idtokey |
| Kaedah HTTP | POST |
| Jenis aplikasi yang disokong | appType-Aplikasi dalaman appType-Aplikasi perusahaan pihak ketiga |
| Kebenaran yang diperlukan | permission-qyapi_attendance_group_read-Kebenaran pertanyaan kumpulan kehadiran |

### Parameter pertanyaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | 6d1bxxxx | Kelayakan aplikasi yang digunakan untuk memanggil API ini.   - Untuk Aplikasi dalaman, dapatkannya dengan memanggil API [Dapatkan access_token Aplikasi dalaman](/ms/open/development/obtain-orgapp-token). - Untuk Aplikasi perusahaan pihak ketiga, dapatkannya dengan memanggil API Dapatkan access_token Perusahaan Pihak Ketiga. |

### Isi permintaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| op_user_id | String | Tidak | user01 | userId pengendali. |
| group_id | Number | Ya | 1586536 | ID kumpulan kehadiran. Panggil API [Dapatkan butiran kumpulan kehadiran secara pukal](/ms/open/development/batch-obtain-attendance-group-details) untuk mendapatkan nilai group_id. |

### Contoh permintaan

```curl
curl -X POST "https://api.dingtalk.io/topapi/attendance/groups/idtokey" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=ea55fdxxxx64242a' \
-d 'group_id=12' \
-d 'op_user_id=123'
```

Java

```text
DingTalkClient client = new DefaultDingTalkClient("https://api.dingtalk.io/topapi/attendance/groups/idtokey");
OapiAttendanceGroupsIdtokeyRequest req = new OapiAttendanceGroupsIdtokeyRequest();
req.setOpUserId("user01");
req.setGroupId(1586536L);
OapiAttendanceGroupsIdtokeyResponse rsp = client.execute(req, access_token);
System.out.println(rsp.getBody());
```

Python

```python

  resp= req.getResponse(access_token)

```


## Respons

### Isi respons

| Nama | Jenis | Contoh | Penerangan |
| --- | --- | --- | --- |
| result | String | 0151E0223B1xxxx | ID kumpulan kehadiran. |
| errcode | Number | 0 | Kod pemulangan. |
| errmsg | String | ok | Penerangan kod pemulangan. |
| request_id | String | 3yt2gu3zz0qi | ID permintaan. |

### Contoh isi respons

```json
{
  "errcode":0,
  "result":0151E0223B1xxxx,
  "errmsg":"ok",
  "request_id":"3yt2gu3zz0qi"
}
```

### Kod ralat

Jika panggilan API ini memulangkan ralat, cari penyelesaian dalam dokumen [Kod ralat global](/ms/open/development/server-api-error-codes-1) berdasarkan mesej ralat.
