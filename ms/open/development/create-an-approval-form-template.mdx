Panggil API ini untuk mencipta atau mengemas kini templat borang aliran kerja Kelulusan OA. Nyatakan senarai kawalan borang dan jana Proses kelulusan lalai.

## Penerangan panggilan API

- Setiap organisasi boleh mencipta sehingga 200 templat kelulusan rasmi. Panggilan ke API ini akan mengembalikan ralat selepas had dicapai.
- Templat Kelulusan OA rasmi hanya menyokong komponen kelulusan yang disenaraikan dalam dokumen ini. Komponen lain tidak disokong.
- Templat Kelulusan OA rasmi hanya menyokong komponen kelulusan yang disenaraikan dalam dokumen ini. Komponen lain tidak disokong.
- Semasa mengemas kini templat kelulusan, jika komponen yang dikemas kini digunakan sebagai syarat cabang dalam reka bentuk aliran kerja, borang templat tidak boleh diubah suai.

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/v1.0/workflow/forms |
| Kaedah HTTP | POST |
| Jenis aplikasi yang disokong | appType-Aplikasi dalaman　appType-Aplikasi perusahaan pihak ketiga |
| Kebenaran | permission-Workflow.Form.Write-Kebenaran tulis templat aliran kerja |

### Pengepala permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Dapatkannya seperti berikut:   - Aplikasi dalaman: Panggil API [Dapatkan Access Token Aplikasi dalaman](/ms/open/development/obtain-the-access-token-of-an-internal-app). - Aplikasi perusahaan pihak ketiga: Panggil API yang mendapatkan access token organisasi yang telah memberi kebenaran kepada Aplikasi pihak ketiga. |

### Isi permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| processCode | String | Tidak | ProcessCode borang. Nyatakan ProcessCode apabila mengemas kini templat borang.    Jika anda menghantar **ProcessCode** untuk mengubah suai dan mengemas kini komponen borang, kawalan yang digunakan sebagai cabang bersyarat dalam reka bentuk aliran kerja tidak boleh dipadam atau diubah suai. Contohnya, jika borang asal mengandungi **kawalan pilihan tunggal** [Jenis Pekerja] yang digunakan sebagai syarat cabang, jenis kawalan medan [Jenis Pekerja] tidak boleh ditukar atau dipadam semasa mengemas kini borang.   - Jika parameter ini dibiarkan kosong, templat baharu akan dicipta. - Jika parameter ini dinyatakan, templat kelulusan yang sepadan dengan nilai tersebut akan dikemas kini. **Cara mendapatkan process_code**: Lihat dalam templat kelulusan di DingTalk Admin Console.    Kaedahnya berbeza antara DingTalk Admin Console baharu dan lama. Untuk butiran, lihat [Gambaran keseluruhan Kelulusan OA - Glosari - processCode](/ms/open/development/workflow-overview). **DingTalk Admin Console baharu**: Buka halaman penyuntingan templat kelulusan, pergi ke Tetapan Asas dan lihat di bahagian bawah halaman. **DingTalk Admin Console lama**: Lihat dalam URL halaman penyuntingan templat kelulusan. |
| name | String | Ya | Nama templat borang. Panjang maksimum: 200 aksara. |
| description | String | Tidak | Penerangan templat borang. Panjang maksimum: 300 aksara. |
| formComponents | Array | Ya | Senarai kawalan borang. Satu borang boleh mengandungi sehingga 200 komponen. |
| FormComponent | FormComponent | Ya | Senarai kawalan borang. Untuk butiran, lihat [Parameter FormComponent](/ms/open/development/oa-formcomponent-message). |
| templateConfig | Object | Tidak | Konfigurasi atribut global borang. |
| disableStopProcessButton | Boolean | Tidak | Menentukan sama ada butang **Nyahaktifkan** pada halaman senarai pengurusan dinyahaktifkan:   - **true**: Ya - **false**: Tidak |
| hidden | Boolean | Tidak | Menentukan sama ada entri templat aliran kerja disembunyikan secara global.   - **true**: Ya - **false**: Tidak |
| disableDeleteProcess | Boolean | Tidak | Menentukan sama ada butang **Padam** templat dinyahaktifkan.   - **true**: Ya - **false**: Tidak |
| disableFormEdit | Boolean | Tidak | Menentukan sama ada ciri **Sunting** borang dinyahaktifkan.   - **true**: Ya - **false**: Tidak |
| disableResubmit | Boolean | Tidak | Menentukan sama ada butang **Hantar Semula** pada halaman butiran dinyahaktifkan.   - **true**: Ya - **false**: Tidak |
| disableHomepage | Boolean | Tidak | Menentukan sama ada templat disembunyikan pada halaman Utama.   - **true**: Ya - **false**: Tidak |
| dirId | String | Tidak | ID direktori templat. Nyatakan ID ini apabila mencipta direktori templat. |
| originDirId | String | Tidak | ID direktori asal. Nyatakan ID direktori sumber apabila mengemas kini direktori templat. |
