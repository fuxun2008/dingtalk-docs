## Request

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/v1.0/conference/orgConferences |
| HTTP Method | GET |
| Jenis aplikasi yang disokong | appType-Internal app　appType-Third-party enterprise app |
| Kebenaran | permission-VideoConference.Conference.Read-Kebenaran Baca untuk maklumat Mesyuarat Video |

### Request headers

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Dapatkan seperti berikut:   - Untuk Aplikasi dalaman, panggil API [Dapatkan access token Aplikasi dalaman](/ms/open/development/obtain-the-access-token-of-an-internal-app#). - Untuk Aplikasi perusahaan pihak ketiga, panggil API [Dapatkan access token organisasi yang memberi kebenaran kepada Aplikasi pihak ketiga](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#). |

### Parameter query

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| nextToken | String | Tidak | Cursor pagination. |
| maxResults | Integer | Tidak | Saiz halaman. |

| endTime | Long | Masa tamat mesyuarat. |
