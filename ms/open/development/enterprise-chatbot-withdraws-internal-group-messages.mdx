Panggil API ini untuk menarik balik mesej Kumpulan Dalaman yang dihantar oleh Bot organisasi. Ini berguna untuk menarik balik secara pukal Mesej Bot Sembang Kumpulan yang dihantar secara tersilap.

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/v1.0/robot/groupMessages/recall |
| Kaedah HTTP | POST |
| Jenis Aplikasi yang disokong | appType-Aplikasi dalaman　appType-Aplikasi perusahaan pihak ketiga |
| Kebenaran diperlukan | permission-qyapi_robot_sendmsg-Kebenaran untuk Bot menghantar mesej dalam Organisasi Anda |

### Pengepala permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Dapatkan seperti berikut:   - Untuk Aplikasi dalaman, panggil API [Dapatkan access token Aplikasi dalaman](/open/development/obtain-the-access-token-of-an-internal-app#). - Untuk Aplikasi perusahaan pihak ketiga, panggil API [Dapatkan access token organisasi yang diberi kuasa untuk Aplikasi pihak ketiga](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#). |

### Isi permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| openConversationId | String | Ya | ID kumpulan. Dapatkan openConversationId Sembang Kumpulan di bahagian klien melalui [chooseChat](https://open.dingtalk.com/document/development/jsapi-choose-chat#).  Ia mesti sepadan dengan openConversationId yang digunakan semasa memanggil API [Hantar mesej Sembang Kumpulan dengan Bot](/open/development/the-robot-sends-a-group-message#). |
| robotCode | String | Ya | Kod Bot. Rujuk [ID Bot](https://open.dingtalk.com/document/development/robot-overview#) untuk maklumat lanjut.  Ia mesti sepadan dengan robotCode yang digunakan semasa memanggil API [Hantar mesej Sembang Kumpulan dengan Bot](/open/development/the-robot-sends-a-group-message#). |
| processQueryKeys | Array of String | Ya | Senarai ID mesej. Dapatkan nilai ini daripada medan processQueryKey yang dikembalikan oleh API [Hantar mesej Sembang Kumpulan dengan Bot](/open/development/the-robot-sends-a-group-message#). |

### Isi respons

| Nama | Jenis | Penerangan |
| --- | --- | --- |
| successResult | Array of String | Senarai ID mesej yang berjaya ditarik balik.  **Nota**  Tiada gesaan dipaparkan dalam tetingkap sembang apabila Mesej Bot ditarik balik. |
| failedResult | `Map<String, String>` | Senarai ID mesej yang gagal ditarik balik, beserta sebab bagi setiap kegagalan. |

```text

}
```
