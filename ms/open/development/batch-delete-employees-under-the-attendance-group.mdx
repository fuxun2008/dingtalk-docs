Panggil API ini untuk memadam ahli secara pukal daripada kumpulan kehadiran yang ditentukan.

## Penerangan panggilan API

API ini hanya memadam ahli kehadiran dalam kumpulan kehadiran. API ini tidak memadam jabatan yang mengambil bahagian dalam kehadiran.

## Permintaan

| **Maklumat asas** | |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/topapi/attendance/group/users/remove |
| Kaedah HTTP | POST |
| Jenis aplikasi yang disokong | appType-Aplikasi dalaman |
| Kebenaran | permission-qyapi_attendance_group_manage-Kebenaran pengurusan kumpulan kehadiran |

### Parameter query

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | 4c9ebd2b153xxxx | Kelayakan aplikasi yang digunakan untuk memanggil API ini. Dapatkannya dengan memanggil API [Dapatkan access_token Aplikasi dalaman](/ms/open/development/obtain-orgapp-token). |

### Isi permintaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| op_userid | String | Tidak | user01 | userId pengendali. |
| group_key | String | Ya | 0151E0223B1xxxx | ID kumpulan kehadiran.  **Nota**  Jika pengecam kumpulan kehadiran anda ialah group_id, panggil API [Tukar groupId kepada groupKey](/ms/open/development/groupid-to-groupkey) untuk menukar group_id kepada group_key. |
| user_id_list | String[] | Ya | user01,user02 | Senarai pengguna. Hantar sehingga 100 userId bagi setiap panggilan. |

### Contoh permintaan

```curl
curl -X POST "https://api.dingtalk.io/topapi/attendance/group/users/remove" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=49ceexxxx4c192' \
-d 'group_key=0151E022xxxx917E876' \
-d 'op_userid=123456' \
-d 'user_id_list=123456%2C123457'
```

Java

```text
DingTalkClient client = new DefaultDingTalkClient("https://api.dingtalk.io/topapi/attendance/group/users/remove");
OapiAttendanceGroupUsersRemoveRequest req = new OapiAttendanceGroupUsersRemoveRequest();
req.setOpUserid("user01");
req.setGroupKey("0151E0223B1xxxx");
req.setUserIdList("user01,user02");
OapiAttendanceGroupUsersRemoveResponse rsp = client.execute(req, access_token);
System.out.println(rsp.getBody());
```

## Respons

### Isi respons

| Nama | Jenis | Contoh | Penerangan |
| --- | --- | --- | --- |
| result | Result |  | Hasil yang dikembalikan. |
| error_info_list | ErrorInfo[] |  | Senarai ralat. |
| failure_list | String[] |  | Senarai item yang gagal. |
| msg | String | business fault | Penerangan ralat. |
| code | String | 1000 | Kod ralat. |
| success_list | String[] |  | Senarai item yang berjaya. |
| errcode | Number | 0 | Kod pemulangan. |
| errmsg | String | ok | Penerangan kod pemulangan. |
| success | Boolean | true | Menunjukkan sama ada panggilan berjaya.   - **true**: Berjaya - **false**: Gagal |
| request_id | String | 47qflcctatn2 | ID permintaan. |

### Contoh isi respons

```json
{
  "errcode": 0,
  "errmsg":"ok",
  "result": {
    "success_list": [
      "user01",
      "user02"
    ]
  },
  "success": true,
  "request_id": "47qflcctatn2"
}
```

### Kod ralat

Jika panggilan API mengembalikan ralat, cari penyelesaian dalam dokumen [Kod ralat global](/ms/open/development/server-api-error-codes-1) berdasarkan mesej ralat.
