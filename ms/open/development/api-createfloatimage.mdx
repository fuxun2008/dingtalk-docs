title: "Cipta imej terapung"
description: "Panggil API ini untuk mendapatkan senarai semua imej terapung pada helaian kerja tertentu dalam DingTalk Spreadsheet, termasuk pengecam unik, URL, kedudukan sauh, dan offset saiz setiap imej."
---

Panggil API ini untuk mendapatkan senarai semua imej terapung dalam helaian kerja tertentu bagi DingTalk Spreadsheet. API ini sesuai untuk senario yang memerlukan pembacaan pukal imej terapung dalam sesuatu helaian kerja, seperti eksport, penyegerakan, atau audit. Isi respons mengandungi pengecam unik, URL imej, kedudukan sauh, dan offset saiz bagi setiap imej.

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/doc/workbooks/{workbookId}/sheets/{sheetId}/floatImages` |
| Kaedah HTTP | POST |
| Jenis aplikasi disokong | appType-Aplikasi dalaman |
| Kebenaran diperlukan | permission-Document.Workbook.Write-Kebenaran tulis DingTalk Spreadsheet |

### Header permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Panggil API [Dapatkan access token aplikasi dalaman](/ms/open/development/obtain-the-access-token-of-an-internal-app) untuk mendapatkannya. |

### Parameter laluan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| workbookId | String | Ya | ID fail spreadsheet. `nodeId(dentryUuid)` yang dikembalikan oleh [API Knowledge Base](/ms/open/development/knowledge-base-overview) adalah `workbookId` bagi spreadsheet tersebut. Dapatkan melalui panggilan API [Get node](https://open.dingtalk.com/document/development/get-node) dan [Cipta dokumen Knowledge Base](/ms/open/development/create-team-space-document). |
| sheetId | String | Ya | ID atau tajuk helaian kerja. Panggil API [Dapatkan semua Helaian Kerja](/ms/open/development/obtain-all-worksheets) untuk mendapatkan ID dan tajuk helaian kerja. |

### Parameter kueri

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| operatorId | String | Ya | unionId bagi operator. Panggil API [Tanya butiran pengguna](/ms/open/development/query-user-details) untuk mendapatkannya. Jika operator tidak mempunyai kebenaran, API akan mengembalikan ralat `The operator has no permission`. |

### Isi permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| src | String | Ya | URL sumber bagi imej terapung. Dapatkan `resourceUrl` dengan memanggil API [Dapatkan maklumat muat naik sumber](/ms/open/development/api-getresourceuploadinfo). |
| anchor | Object | Ya | Maklumat kedudukan bagi imej terapung. |
| row | Integer | Ya | Indeks baris untuk kedudukan. Cursor bermula dari 0. |
| col | Integer | Ya | Indeks lajur untuk kedudukan. Cursor bermula dari 0. |
| coordinate | Object | Ya | Maklumat geometri. |
| width | double | Ya | Lebar imej, dalam piksel. |
| height | double | Ya | Tinggi imej, dalam piksel. |
| offsetX | double | Ya | Offset mendatar relatif kepada koordinat kedudukan, dalam piksel. |
| offsetY | double | Ya | Offset menegak relatif kepada koordinat kedudukan, dalam piksel. |
