Sebelum memanggil API berkaitan Kenalan, anda perlu menambah kebenaran API Kenalan terlebih dahulu. Gunakan API ini untuk mendapatkan skop kebenaran Kenalan.

## Penerangan panggilan API

<Warning>
API yang diterangkan dalam topik ini merupakan Server API lama (legacy). Untuk butiran cara memanggilnya, rujuk Legacy APIs vs. new APIs.
</Warning>

Untuk API berkaitan Kenalan, admin perlu memohon kebenaran API yang berkaitan terlebih dahulu di [DingTalk Developer Console](https://open-dev.dingtalk.io/#/index) dan menetapkan skop Kenalan yang boleh diakses oleh API tersebut.

Seperti yang ditunjukkan dalam rajah di bawah, access_token bagi aplikasi semasa hanya mempunyai kebenaran Kenalan untuk mengurus jabatan A. Pembangun boleh memanggil API ini terlebih dahulu untuk melihat skop kebenaran Kenalan aplikasi tersebut. Semasa memanggil API Kenalan, pembangun hanya boleh mendapatkan semula maklumat Kenalan pekerja dalam skop yang dibenarkan. Percubaan untuk mendapatkan semula maklumat Kenalan pekerja di luar skop yang dibenarkan akan mengembalikan ralat `The department or employee is not within the authorization scope`.

## Permintaan

| **Maklumat asas** | |
| --- | --- |
| URL HTTP | https://oapi.dingtalk.io/auth/scopes |
| Kaedah HTTP | GET |
| Jenis aplikasi disokong | appType-Aplikasi dalaman, appType-Aplikasi perusahaan pihak ketiga |
| Keperluan kebenaran | permission-qyapi_base-Kebenaran asas yang diperlukan untuk memanggil API perusahaan |

### Parameter pertanyaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | 6ed1bxxx | Kelayakan aplikasi yang digunakan untuk memanggil API ini.   - Bagi aplikasi dalaman, dapatkan melalui API untuk mendapatkan [access_token aplikasi dalaman](/ms/open/development/obtain-orgapp-token). - Bagi aplikasi perusahaan pihak ketiga, dapatkan melalui API untuk mendapatkan access_token perusahaan pihak ketiga. |

### Contoh permintaan

```curl
curl -X GET "https://oapi.dingtalk.io/auth/scopes" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=2314cdxxxxbcd10713'
```

Java

```text
DingTalkClient client = new DefaultDingTalkClient("https://oapi.dingtalk.io/auth/scopes");
OapiAuthScopesRequest req = new OapiAuthScopesRequest();
req.setHttpMethod("GET");
OapiAuthScopesResponse rsp = client.execute(req, access_token);
System.out.println(rsp.getBody());
```

Python

```python
import dingtalk.api

req=dingtalk.api.OapiAuthScopesRequest("https://oapi.dingtalk.io/auth/scopes")
try:
	resp= req.getResponse(access_token)
	print(resp)
except Exception,e:
	print(e)
```

PHP

```php
include "TopSdk.php";
date_default_timezone_set('Asia/Shanghai');

$c = new DingTalkClient(DingTalkConstant::$CALL_TYPE_OAPI, DingTalkConstant::$METHOD_GET , DingTalkConstant::$FORMAT_JSON);
$req = new OapiAuthScopesRequest;
$resp = $c->execute($req, $access_token, "https://oapi.dingtalk.io/auth/scopes");
```

C#

```text
IDingTalkClient client = new DefaultDingTalkClient("https://oapi.dingtalk.io/auth/scopes");
OapiAuthScopesRequest req = new OapiAuthScopesRequest();
req.SetHttpMethod("GET");
OapiAuthScopesResponse rsp = client.Execute(req, access_token);
Console.WriteLine(rsp.Body);
```

## Respons

### Isi respons

| Nama | Jenis | Contoh | Penerangan |
| --- | --- | --- | --- |
| auth_org_scopes | AuthOrgScopes |  | Maklumat kebenaran. |
| authed_user | String[] | ["user1","user"] | Senarai ID pengguna pekerja yang dibenarkan mendapatkan semula maklumat Kenalan. |
| authed_dept | Number[] | [1,2,3] | Senarai ID jabatan yang dibenarkan mendapatkan semula maklumat Kenalan. |
| auth_user_field | String[] | ["name","email"] | Medan pengguna perusahaan yang boleh didapatkan semula dengan kebenaran. |
| errmsg | String | ok | Penerangan kod pemulangan. |
| errcode | Number | 0 | Kod pemulangan. |

### Contoh isi respons

### Kod ralat

Jika berlaku ralat semasa memanggil API ini, rujuk dokumen [Global error codes](/ms/open/development/server-api-error-codes-1) untuk penyelesaian berdasarkan mesej ralat.
