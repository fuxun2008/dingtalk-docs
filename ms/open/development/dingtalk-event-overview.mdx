Topik ini memperkenalkan produk Calendar, termasuk cara mengaktifkan Calendar, keupayaan API yang didedahkan oleh Calendar, dan cara menyepadukan keupayaan Calendar.

## Apakah itu Calendar

DingTalk Calendar disepadukan secara mendalam dengan pemesejan segera. Rakan sekerja boleh berkongsi acara, memulakan mesyuarat acara dengan mudah, dan melihat perkara penting sekali imbas, membolehkan kerjasama pasukan yang lebih cekap dan pengalaman yang baik untuk pekerja. Untuk maklumat lanjut, lihat [Panduan Pengguna DingTalk - Calendar](https://docs.dingtalk.io/i/p/Y7kmbokZp3pgGLq2/docs/Y7kmbOpyEdYLGLq2?dontjump=true%23%23).

### Notifikasi tepat untuk mesyuarat acara

Cipta acara mesyuarat dengan satu klik. Jemputan dihantar terus kepada setiap peserta sebagai mesej sembang, memastikan tiada apa yang terlepas.

### Pengurusan acara bersepadu

Sambung dengan Alibaba Mail untuk melihat dan mengedit acara secara bersepadu dalam kalendar DingTalk. Kemas kini di satu tempat dan segerakkan ke mana-mana, supaya anda tidak akan terlepas sebarang mesyuarat atau jadual.

## Cara mengaktifkan Calendar

Pada mudah alih: Ketik **Collaboration** > **Calendar**, atau ketik **Calendar** pada bar alat.

Pada desktop: Klik **Calendar**.

## Gambaran keseluruhan keupayaan terbuka

### Senarai API

Calendar menyediakan set open API yang lengkap. Pembangun boleh menggunakan API ini untuk menyepadukan Calendar dengan sistem perniagaan organisasi mereka.

### Nota

1. API [Acara Baharu](/ms/open/development/create-schedule), [Update event](/ms/open/development/modify-event), [Add event attendees](/ms/open/development/add-schedule-participant), dan [Delete event attendees](/ms/open/development/delete-schedule-participant) masing-masing menyokong sehingga 500 peserta bagi setiap operasi, dan maksimum 5,000 peserta bagi setiap acara.
2. Untuk menambah atau mengeluarkan peserta acara, kami mengesyorkan penggunaan API [Add event attendees](/ms/open/development/add-schedule-participant) dan [Delete event attendees](/ms/open/development/delete-schedule-participant).

## Definisi sumber

| Attribute | Type | Description |
| --- | --- | --- |
| id | String | ID unik global bagi acara. |
| summary | String | Tajuk acara. |
| description | String | Penerangan acara. |
| start | Object | Masa mula acara. |
| start.date | String | Tarikh mula acara dalam format yyyy-MM-dd. Wajib untuk acara sepanjang hari; mesti kosong untuk acara bukan sepanjang hari. |
| start.dateTime | String | Masa mula acara dalam format tarikh-masa ISO-8601. Wajib untuk acara bukan sepanjang hari; mesti kosong untuk acara sepanjang hari. |
| start.timeZone | String | Zon waktu bagi masa mula acara. Wajib untuk acara bukan sepanjang hari; mesti kosong untuk acara sepanjang hari. |
| end | Object | Masa tamat acara. |
| end.date | String | Tarikh tamat acara dalam format yyyy-MM-dd. Wajib untuk acara sepanjang hari; mesti kosong untuk acara bukan sepanjang hari. |
| end.dateTime | String | Masa tamat acara dalam format tarikh-masa ISO-8601. Wajib untuk acara bukan sepanjang hari; mesti kosong untuk acara sepanjang hari. |
| end.timeZone | String | Zon waktu bagi masa tamat acara. Mesti sepadan dengan zon waktu masa mula, dalam format nama pangkalan data TZ. Wajib untuk acara bukan sepanjang hari; mesti kosong untuk acara sepanjang hari. |
| isAllDay | Boolean | Sama ada acara ini adalah acara sepanjang hari. |
| recurrence | Object | Peraturan pengulangan acara. |
| recurrence.pattern | Object | Corak pengulangan. |
| recurrence.pattern.type | String | Jenis corak pengulangan:   - **daily**: Berulang setiap `interval` hari. - **weekly**: Berulang pada `daysOfWeek` setiap `interval` minggu. - **absoluteMonthly**: Berulang pada hari `dayOfMonth` setiap `interval` bulan. - **relativeMonthly**: Berulang pada `daysOfWeek` bagi minggu `index` setiap `interval` bulan. - **absoluteYearly**: Berulang setiap `interval` tahun. |
| recurrence.pattern.dayOfMonth | Integer | Apabila `type=absoluteMonthly`, menetapkan hari dalam bulan. |
| recurrence.pattern.daysOfWeek | String | Menetapkan hari dalam minggu sebagai perkataan bahasa Inggeris huruf kecil. Pisahkan berbilang nilai dengan koma. |
| recurrence.pattern.index | String | Apabila `type=relativeMonthly`, menetapkan minggu dalam bulan:   - **first** - **second** - **third** - **fourth** - **last**   `last` menandakan minggu terakhir dalam bulan. |
| recurrence.pattern.interval | Integer | Selang pengulangan. Unitnya berbeza mengikut jenis. Sebagai contoh, apabila `type=daily`, selang dalam hari; apabila `type=absoluteYearly`, selang dalam tahun. |
| recurrence.range | Object | Julat pengulangan. |
| recurrence.range.type | String | Jenis julat pengulangan:   - **noEnd**: Tidak pernah tamat. - **endDate**: Tamat pada tarikh yang ditetapkan. - **numbered**: Tamat selepas bilangan kejadian yang ditetapkan. |
| recurrence.range.endDate | String | Tarikh tamat bagi pengulangan. |
| recurrence.range.numberOfOccurrences | Integer | Bilangan kejadian. |
| attendees | Array | Senarai peserta acara. |
| attendees.id | String | unionId pengguna. |
| attendees.displayName | String | Nama pengguna. |
| attendees.responseStatus | String | Status peserta:   - **needsAction**: Tiada tindakan diambil (status lalai). - **accepted**: Diterima. - **declined**: Ditolak. - **tentative**: Diterima secara sementara. |
| attendees.self | Boolean | Sama ada ini adalah pengguna operasi semasa. |
| organizer | Object | Penganjur acara. |
| organizer.id | String | unionId penganjur. |
| organizer.displayName | String | Nama pengguna penganjur. |
| organizer.responseStatus | String | Status respons penganjur. |
| organizer.self | Boolean | Sama ada ini adalah pengguna semasa. |
| location | Object | Lokasi acara. |
| location.displayName | String | Nama lokasi. |
| reminders | Array | Peringatan acara. |
| reminders.method | String | Kaedah peringatan:   - **dingtalk**: Peringatan dalam aplikasi. - **sms**: Peringatan SMS. - **phone**: Peringatan panggilan telefon. |
| reminders.minutes | String | Berapa minit sebelum acara peringatan dihantar. |
| onlineMeetingInfo | Object | Cipta mesyuarat dalam talian bersama acara. |
| onlineMeetingInfo.type | String | Jenis mesyuarat dalam talian:   - **dingtalk**: Mesyuarat Video DingTalk. |
| onlineMeetingInfo.conferenceId | String | ID mesyuarat. |
| onlineMeetingInfo.url | String | URL mesyuarat. |
| onlineMeetingInfo.extraInfo | Map | Maklumat lanjutan tambahan. |
| seriesMasterId | String | ID acara induk bagi acara berulang. Kosong untuk acara bukan berulang. |
| createTime | String | Masa dicipta. |
| updateTime | String | Masa kemas kini. |
| status | String | Status acara:   - **confirmed**: Normal. - **cancelled**: Dibatalkan. |
