Panggil API ini untuk mengalih keluar konfigurasi Senarai Lungsur daripada julat sel tertentu dalam DingTalk Spreadsheet. Gunakan API ini untuk membatalkan kekangan kemasukan data dan memulihkan sel kepada mod input bebas. Penghapusan ini hanya mengalih keluar takrifan pilihan senarai lungsur; nilai sedia ada dalam sel tidak terjejas.

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/doc/workbooks/{workbookId}/sheets/{sheetId}/ranges/{rangeAddress}/deleteDropdownLists` |
| Kaedah HTTP | POST |
| Jenis aplikasi disokong | appType-Aplikasi dalaman |
| Kebenaran diperlukan | permission-Document.Workbook.Write-Kebenaran tulis DingTalk Spreadsheet |

### Header permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Untuk mendapatkannya, panggil [Dapatkan access token aplikasi dalaman](/open/development/obtain-the-access-token-of-an-internal-app). |

### Parameter laluan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| workbookId | String | Ya | ID fail spreadsheet. `nodeId(dentryUuid)` yang dikembalikan oleh [API Knowledge Base](/open/development/knowledge-base-overview) adalah `workbookId` bagi spreadsheet tersebut. Untuk mendapatkannya, panggil [Dapatkan node](https://open.dingtalk.com/document/development/get-node) atau [Cipta dokumen Knowledge Base](/open/development/create-team-space-document). |
| sheetId | String | Ya | ID atau tajuk Helaian Kerja. Untuk mendapatkan ID dan tajuk, panggil [Dapatkan semua Helaian Kerja](/open/development/obtain-all-worksheets). |
| rangeAddress | String | Ya | Alamat julat. |

### Parameter pertanyaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| operatorId | String | Ya | unionId pengendali. Untuk mendapatkannya, panggil [Tanya butiran pengguna](/open/development/query-user-details). Jika pengendali tidak mempunyai kebenaran, API akan mengembalikan ralat `The operator has no permission`. |
