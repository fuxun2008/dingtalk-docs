Dokumen ini menunjukkan cara mencipta aplikasi dalaman dan menggunakan API yang disediakan oleh Bilik Mesyuarat Pintar untuk mencipta, mengemas kini, menanya, dan memadam bilik mesyuarat.

## Hasil yang dijangka

Bilik mesyuarat dipaparkan seperti berikut:

## Gambaran keseluruhan proses

Prasyarat: Selesaikan proses [Cipta dan konfigurasi aplikasi](/open/dingstart/create-application).

Langkah 1: Dapatkan maklumat kelayakan aplikasi, termasuk client ID dan Client Secret.

Langkah 2: Mohon kebenaran API untuk Bilik Mesyuarat Pintar.

Langkah 3: Dapatkan kredensial akses aplikasi dengan mengikuti [Dapatkan access token aplikasi dalaman](/open/development/obtain-the-access-token-of-an-internal-app). Access token digunakan untuk mengesahkan pemanggil semasa memanggil API.

Langkah 4: Panggil API bilik mesyuarat:

1. Panggil Server API [Cipta bilik mesyuarat](/open/development/create-a-meeting-room). Medan `result` yang dikembalikan oleh API ialah ID bilik mesyuarat.
2. Dengan ID bilik mesyuarat, panggil Server API [Kemas kini maklumat bilik mesyuarat](/open/development/update-meeting-room-information) untuk mengemas kini maklumat bilik mesyuarat.
3. Panggil Server API [Tanya senarai bilik mesyuarat](/open/development/check-the-meeting-room-list) untuk mendapatkan senarai bilik mesyuarat.
4. Dengan ID bilik mesyuarat, panggil Server API [Tanya butiran bilik mesyuarat](/open/development/check-meeting-room-details) untuk mendapatkan butiran bilik mesyuarat tertentu.
5. Dengan ID bilik mesyuarat, panggil Server API [Padam bilik mesyuarat](/open/development/delete-a-meeting-room) untuk memadam bilik mesyuarat.

## Prasyarat

Selesaikan proses [Cipta dan konfigurasi aplikasi](/open/dingstart/create-application).

## Langkah 1: Dapatkan kelayakan aplikasi

1. Pilih aplikasi sasaran dan pergi ke halaman butiran aplikasi. Klik **Maklumat asas** > **Kelayakan dan maklumat asas**.
2. Dapatkan client ID dan Client Secret.

## Langkah 2: Tambah kebenaran API

Klik **Konfigurasi pembangunan** > **Urus kebenaran**. Dalam kotak carian kebenaran, masukkan `VideoConference.Conference.Write` dan `VideoConference.Conference.Read` masing-masing, kemudian mohon kebenaran tersebut.

## Langkah 3: Dapatkan access token

<Warning>
Untuk butiran tentang perbezaan antara versi Server API, lihat perbandingan antara API lama dan API baharu. Semua titik akhir berikut menggunakan Server API. Untuk butiran muat turun SDK, lihat muat turun SDK Bahagian pelayan.
</Warning>

Menggunakan client ID dan Client Secret daripada Langkah 1, dapatkan kredensial akses aplikasi dengan mengikuti [Dapatkan access token aplikasi dalaman](/open/development/obtain-the-access-token-of-an-internal-app).

```java
 public void getAccessToken() throws Exception {
        Config config = new Config();
        config.protocol = "https";
        config.regionId = "central";
        com.aliyun.dingtalkoauth2_1_0.Client client = new com.aliyun.dingtalkoauth2_1_0.Client(config);
        GetAccessTokenRequest accessTokenRequest = new GetAccessTokenRequest()
                .setAppKey("din*********hgn")
                .setAppSecret("9G_O************mBkhgGIO");
        GetAccessTokenResponse accessToken = client.getAccessToken(accessTokenRequest);
        System.out.println(JSON.toJSONString(accessToken.getBody()));
    }
```
