Panggil API ini untuk memadam acara yang ditentukan.

## Penerangan panggilan API

- Apabila penganjur memadam acara (URL mengandungi unionId penganjur), semua peserta menerima notifikasi pembatalan acara, dan acara tersebut dialih keluar daripada kalendar semua peserta.
- Apabila seorang peserta memadam acara (URL mengandungi unionId peserta tersebut), acara hanya dialih keluar daripada kalendar peserta itu sahaja; peserta acara lain tidak terjejas.

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/calendar/users/{userId}/calendars/{calendarId}/events/{eventId}` |
| Kaedah HTTP | DELETE |
| Jenis aplikasi disokong | appType-Aplikasi dalaman　appType-Aplikasi perusahaan pihak ketiga　appType-Aplikasi peribadi pihak ketiga |
| Kebenaran diperlukan | permission-Calendar.Event.Write-Kebenaran tulis untuk acara dalam aplikasi Calendar |

### Header permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-client-token | String | Tidak | Semakan idempoten.     - Permintaan dengan `x-client-token` yang sama dianggap sebagai permintaan yang sama. - Tamat tempoh dalam 1 hari. |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Dapatkan seperti berikut:   - Untuk aplikasi dalaman, panggil API [Dapatkan access token aplikasi dalaman](/open/development/obtain-the-access-token-of-an-internal-app#). - Untuk aplikasi perusahaan pihak ketiga, panggil API [Dapatkan access token perusahaan yang dibenarkan untuk aplikasi pihak ketiga](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#). - Untuk aplikasi peribadi pihak ketiga, panggil API [Dapatkan token pengguna](/open/development/obtain-user-token#). |

### Parameter laluan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| userId | String | Ya | unionId pengguna yang memiliki acara yang akan dipadam.   - Untuk aplikasi dalaman dan aplikasi perusahaan pihak ketiga, panggil API [Tanya butiran pengguna](/open/development/query-user-details#) untuk mendapatkan nilai `unionid`. - Untuk aplikasi peribadi pihak ketiga, panggil API [Dapatkan profil pengguna daripada Kenalan](/open/development/dingtalk-retrieve-user-information#) untuk mendapatkan nilai `unionId`. |
| calendarId | String | Ya | ID kalendar tempat acara berada. Tetapkan kepada `primary`, yang mewakili kalendar utama pengguna. |
| eventId | String | Ya | ID acara. Panggil API [Acara Baharu](https://open.dingtalk.com/document/development/create-event#) atau API [Tanya senarai acara](/open/development/query-an-event-list#) untuk mendapatkan nilai `id`. |

### Parameter pertanyaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| pushNotification | Boolean | Tidak | Sama ada untuk memaparkan peringatan pop timbul.   - true: Ya - false: Tidak |
