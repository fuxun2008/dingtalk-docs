Panggil API ini untuk memaklumkan sistem kehadiran agar melaksanakan tindakan tukar syif selepas kelulusan tukar syif diberikan. Pengguna boleh menukar syif dengan diri sendiri atau dengan pengguna lain.

## Penerangan panggilan API

Kekangan berikut terpakai untuk tukar syif:

- Kedua-dua pihak mesti tergolong dalam kumpulan kehadiran berasaskan syif.
- Kedua-dua pihak mesti mempunyai syif atau hari rehat yang dijadualkan pada tarikh tukar dan tarikh tukar balik.
- Masa daftar masuk selepas tukar syif tidak boleh berkonflik. Contohnya, syif pada 1hb ialah 08:00-22:00 dan syif pada 2hb ialah 10:00-09:00 (hari berikutnya). Jika syif pada 1hb dan 2hb ditukar, syif pada 1hb menjadi 10:00-09:00 (hari berikutnya) dan syif pada 2hb menjadi 08:00-22:00. Dalam kes ini, julat masa daftar masuk pada 1hb bertindih dengan waktu kerja pada 2hb. Keadaan ini dipanggil konflik masa daftar masuk.
- Tukar syif tidak boleh dibatalkan.

## Permintaan

| **Maklumat asas** | |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/topapi/attendance/approve/schedule/switch |
| Kaedah HTTP | POST |
| Jenis aplikasi yang disokong | appType-Aplikasi dalaman　appType-Aplikasi perusahaan pihak ketiga |
| Kebenaran yang diperlukan | permission-qyapi_attendance_group_manage-Kebenaran pengurusan kumpulan kehadiran |

### Parameter pertanyaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | bE74xxxx | Kelayakan aplikasi yang digunakan untuk memanggil API ini.   - Untuk Aplikasi dalaman, panggil API [Dapatkan access_token Aplikasi dalaman](/ms/open/development/obtain-orgapp-token) untuk mendapatkannya. - Untuk Aplikasi perusahaan pihak ketiga, panggil API Dapatkan access_token Organisasi pihak ketiga untuk mendapatkannya. |

### Isi permintaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| userid | String | Ya | manager123 | ID pengguna pemohon. |
| switch_date | String | Ya | 2019-09-08 | Tarikh tukar syif yang dimohon. Syif atau hari rehat yang dijadualkan mesti wujud pada tarikh ini. |
| reback_date | String | Ya | 2019-09-09 | Tarikh tukar balik. Syif atau hari rehat yang dijadualkan mesti wujud pada tarikh ini.  **Nota**  Jika pemohon tukar syif dan pengguna sasaran ialah orang yang sama, tarikh tukar balik adalah wajib. |
| apply_userid | String | Ya | manager123 | ID pengguna pemohon tukar syif. Hanya pengguna dalam kumpulan kehadiran berasaskan syif disokong. |
| target_userid | String | Ya | user123 | ID pengguna sasaran. Hanya pengguna dalam kumpulan kehadiran berasaskan syif disokong. |
| approve_id | String | Ya | 2376620852 | ID borang kelulusan. Ini ialah nilai parameter tersuai. |
| apply_shift_id | Number | Ya | 1234566 | ID syif pemohon tukar syif pada tarikh tukar. Panggil API [Pertanyaan pukal maklumat penjadualan syif pengguna](/ms/open/development/query-batch-scheduling-information) untuk mendapatkan nilai shift_id. |
| target_shift_id | Number | Ya | 1234566 | ID syif pengguna sasaran pada tarikh tukar. Panggil API [Pertanyaan pukal maklumat penjadualan syif pengguna](/ms/open/development/query-batch-scheduling-information) untuk mendapatkan nilai shift_id. |
| reback_apply_shift_id | Number | Ya | 1234566 | ID syif pemohon tukar syif pada tarikh tukar balik. Panggil API [Pertanyaan pukal maklumat penjadualan syif pengguna](/ms/open/development/query-batch-scheduling-information) untuk mendapatkan nilai shift_id. |
| reback_target_shift_id | Number | Ya | 1234566 | ID syif pengguna sasaran pada tarikh tukar balik. Panggil API [Pertanyaan pukal maklumat penjadualan syif pengguna](/ms/open/development/query-batch-scheduling-information) untuk mendapatkan nilai shift_id. |

### Contoh permintaan

```curl
curl -X POST "https://api.dingtalk.io/topapi/attendance/approve/schedule/switch" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=82683xxxxc28be8' \
-d 'apply_shift_id=123' \
-d 'apply_userid=dd_dd' \
-d 'approve_id=asdasdjashd' \
-d 'reback_apply_shift_id=789' \
-d 'reback_date=2019-09-09' \
-d 'reback_target_shift_id=897' \
-d 'switch_date=2019-09-08' \
-d 'target_shift_id=456' \
-d 'target_userid=aa_aa' \
-d 'userid=dd_dd'
```

