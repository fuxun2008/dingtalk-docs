---

Dapatkan pautan muat turun sementara bagi fail dalam mesej bot.

## Penerangan panggilan API

1. Apabila pengguna menghantar mesej gambar, suara, video, fail, atau Teks Kaya kepada bot, dapatkan kod muat turun sementara `downloadCode` daripada maklumat yang dikembalikan oleh bot kepada pembangun melalui Callback.
2. Gunakan kod muat turun sementara `downloadCode` untuk memanggil API ini dan mendapatkan pautan muat turun sementara bagi gambar, suara, fail, atau video dalam mesej tersebut.
3. Akses pautan muat turun sementara untuk mendapatkan Kandungan fail.

### Penerangan

- Dalam Sembang Kumpulan: Apabila ahli kumpulan @ bot, bot tidak menyokong penerimaan mesej suara, fail, atau video.
- Dalam sembang satu-lawan-satu antara pengguna: Bot tidak menyokong penerimaan mesej suara, fail, atau video.
- Dalam sembang satu-lawan-satu antara pengguna dan bot: Bot menyokong penerimaan mesej suara, fail, dan video.

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/v1.0/robot/messageFiles/download |
| Kaedah HTTP | POST |
| Jenis aplikasi yang disokong | appType-Aplikasi dalaman　appType-Aplikasi perusahaan pihak ketiga |
| Kebenaran diperlukan | permission-qyapi_robot_sendmsg-Kebenaran untuk menghantar mesej daripada bot dalam Organisasi Anda |

### Pengepala permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Dapatkan seperti berikut:   - Untuk aplikasi dalaman, panggil API [Dapatkan access token bagi aplikasi dalaman](/ms/open/development/obtain-the-access-token-of-an-internal-app#). - Untuk aplikasi perusahaan pihak ketiga, panggil API [Dapatkan access token bagi perusahaan yang diberi kuasa oleh aplikasi pihak ketiga](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#). |

### Isi permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| downloadCode | String | Ya | Kod muat turun yang dikembalikan oleh bot kepada pembangun selepas pengguna menghantar mesej fail kepada bot. Untuk maklumat lanjut, lihat [Bot menerima mesej](/ms/open/development/receive-message#). |
| robotCode | String | Ya | Kod bot. Untuk maklumat lanjut, lihat [ID Bot](https://open.dingtalk.com/document/development/robot-overview#). |
