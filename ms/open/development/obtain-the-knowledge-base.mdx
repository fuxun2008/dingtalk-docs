Digunakan untuk mendapatkan Knowledge Base. Gunakan permintaan GET.

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v2.0/wiki/workspaces/{workspaceId}` |
| Kaedah HTTP | GET |
| Jenis aplikasi yang disokong | appType-Aplikasi dalaman　appType-Aplikasi perusahaan pihak ketiga |
| Kebenaran diperlukan | permission-Wiki.Workspace.Read-Kebenaran baca Knowledge Base |

### Header permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini.   - Untuk aplikasi dalaman, panggil API [Dapatkan access token aplikasi dalaman](https://open.dingtalk.com/document/orgapp/obtain-the-access_token-of-an-internal-app) untuk mendapatkannya. - Untuk aplikasi perusahaan pihak ketiga, panggil API [Dapatkan access token organisasi yang diberi kuasa untuk aplikasi pihak ketiga](https://open.dingtalk.com/document/isvapp/obtain-the-access_token-of-the-authorized-enterprise) untuk mendapatkannya. |

### Parameter laluan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| workspaceId | String | Ya | ID Knowledge Base:   - Untuk aplikasi dalaman, panggil API [Dapatkan senarai Knowledge Base](/open/development/get-knowledge-base-list) untuk mendapatkan medan `workspaceId` dalam respons. - Untuk aplikasi perusahaan pihak ketiga, panggil API [Dapatkan senarai Knowledge Base](/open/development/get-knowledge-base-list) untuk mendapatkan medan `workspaceId` dalam respons. |

### Parameter pertanyaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| withPermissionRole | Boolean | Tidak | Sama ada untuk mendapatkan maklumat kebenaran:   - true: dapatkan - false: jangan dapatkan   Lalai: false. |
| operatorId | String | Ya | unionId bagi operator. |

### Contoh permintaan

Content-Type:application/json

## Respons

### Isi respons

| Nama | Jenis | Penerangan |
| --- | --- | --- |
| workspace | Object | Knowledge Base tersebut. |
| workspaceId | String | ID Knowledge Base (spaceUuid). |
| corpId | String | ID Organisasi tempat Knowledge Base itu berada. |
| teamId | String | ID Kumpulan Pengetahuan tempat Knowledge Base itu berada.  Kosong jika tidak dikaitkan dengan mana-mana Kumpulan Pengetahuan. |
| rootNodeId | String | ID nod root (root dentryUuid). |
| name | String | Nama Knowledge Base. |
| type | String | Jenis Knowledge Base. Nilai enum:   - **TEAM**: Knowledge Base - **PERSONAL**: Dokumen Saya |
| description | String | Penerangan Knowledge Base. |
| url | String | URL akses Knowledge Base. |
| icon | Object | Ikon Knowledge Base. |
| type | String | Jenis ikon. Nilai enum:   - **URL**: pautan - **EMOJI**: ikon emoji |
| value | String | Nilai ikon:   - Apabila type ialah URL, mengembalikan pautan ikon. - Apabila type ialah EMOJI, mengembalikan nilai Unicode bagi ikon emoji. |
| cover | String | URL kulit hadapan (cover) Knowledge Base. |
| creatorId | String | userId pencipta Knowledge Base. |
| modifierId | String | userId pengubah suai Knowledge Base. |
| createTime | String | Masa dicipta bagi Knowledge Base. |
| modifiedTime | String | Masa pengubahsuaian bagi Knowledge Base. |
| permissionRole | String | Peranan kebenaran pemohon terhadap Knowledge Base. Nilai enum:   - **OWNER**: Pemilik - **MANAGER**: Pengurus - **EDITOR**: Editor - **DOWNLOADER**: Pemapar dengan kebenaran muat turun - **READER**: Pemapar sahaja - **NONE**: Tiada kebenaran |
