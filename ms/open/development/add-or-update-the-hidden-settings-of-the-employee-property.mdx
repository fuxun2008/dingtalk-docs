---
title: "Configure visibility of user attributes"
description: "Call this API to configure or update the visibility of user attribute fields, controlling whether specific attributes are exposed to other members."
---

Panggil API ini untuk mengonfigurasikan keterlihatan atribut pengguna.

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/v1.0/contact/staffAttributes/visibilitySettings |
| Kaedah HTTP | POST |
| Jenis aplikasi disokong | appType-Aplikasi dalaman　appType-Aplikasi perusahaan pihak ketiga |
| Kebenaran diperlukan | permission-Contact.ReachableRule.ReadWrite-Kebenaran pengurusan untuk keterlihatan data Kenalan |

### Pengepala permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses yang digunakan untuk memanggil API ini. Dapatkan seperti berikut:   - Untuk aplikasi dalaman, panggil API [Dapatkan access token aplikasi dalaman](/ms/open/development/obtain-the-access-token-of-an-internal-app#). - Untuk aplikasi perusahaan pihak ketiga, panggil API [Dapatkan access token bagi perusahaan yang diberi kuasa kepada aplikasi pihak ketiga](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#). |

### Isi permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| id | Long | Tidak | ID tetapan.       - Biarkan kosong apabila menambah tetapan baharu. - Berikan ID tetapan yang hendak diubah suai apabila mengemas kini. |
| name | String | Tidak | Nama tetapan. |
| description | String | Tidak | Penerangan tetapan. |
| objectStaffIds | Array of String | Tidak | userId pekerja yang mana medan tersebut disembunyikan. Dapatkan nilai parameter userid dengan memanggil [Dapatkan ID pengguna menggunakan kod log masuk senyap](/ms/open/development/obtain-the-userid-of-a-user-by-using-the-log-free). |
| objectDeptIds | Array of Long | Tidak | deptId jabatan yang mana medan tersebut disembunyikan. Dapatkan nilai parameter dept_id dengan memanggil [Dapatkan senarai jabatan](/ms/open/development/user-management-acquires-the-list-departments). |
| objectTagIds | Array of Long | Tidak | roleId peranan yang mana medan tersebut disembunyikan. Dapatkan nilai parameter id dengan memanggil [Dapatkan senarai peranan organisasi](/ms/open/development/obtains-a-list-of-enterprise-roles). |
| hideFields | Array of String | Tidak | Senarai ID atribut pengguna yang hendak disembunyikan.   - Apabila atribut pengguna yang hendak disembunyikan ialah atribut organisasi tersuai, berikan ID atribut tersebut. - Apabila atribut pengguna yang hendak disembunyikan ialah atribut lalai sistem, berikan senarai atribut lalai sistem.       Senarai atribut lalai sistem adalah seperti berikut:   - **name**: Nama - **department**: Jabatan - **email**: E-mel - **manager**: Penyelia terus - **title**: Jawatan - **mobile**: Nombor telefon bimbit - **ext_number**: Nombor sambungan - **work_station**: Lokasi Kerja - **remark**: Alias - **hire_date**: Tarikh mula bekerja - **job_number**: ID Pekerja |
| excludeStaffIds | Array of String | Tidak | userId pekerja yang boleh melihat medan yang disembunyikan. |
| excludeDeptIds | Array of Long | Tidak | deptId jabatan yang boleh melihat medan yang disembunyikan. |
| excludeTagIds | Array of Long | Tidak | roleId peranan yang boleh melihat medan yang disembunyikan. |
| active | Boolean | Tidak | Sama ada tetapan ini berkuat kuasa.   - **true**: Berkuat kuasa. - **false**: Tidak berkuat kuasa. |
