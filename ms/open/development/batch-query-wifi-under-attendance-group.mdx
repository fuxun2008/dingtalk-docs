description: "Panggil API DingTalk ini untuk membuat pertanyaan pukal senarai Wi-Fi bagi kumpulan kehadiran berdasarkan ID kumpulan, dengan sokongan penomboran untuk pengurusan kehadiran yang cekap."
---

Panggil API ini untuk membuat pertanyaan pukal senarai Wi-Fi bagi kumpulan kehadiran yang ditentukan.

## Permintaan

| **Maklumat asas** | |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/topapi/attendance/group/wifis/query |
| Kaedah HTTP | POST |
| Jenis aplikasi yang disokong | appType-Aplikasi dalaman |
| Kebenaran yang diperlukan | permission-qyapi_attendance_group_read-Kebenaran pertanyaan kumpulan kehadiran |

### Parameter pertanyaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | 4c9ebd2b1534xxxx | Kelayakan aplikasi yang digunakan untuk memanggil API ini. Dapatkan dengan memanggil API [Dapatkan access_token Aplikasi dalaman](/ms/open/development/obtain-orgapp-token). |

### Isi permintaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| cursor | String | Tidak | 0151E022xxxx | ID terakhir kelompok sebelumnya. Kosong secara lalai. |
| size | Number | Ya | 50 | Saiz halaman. |
| op_userid | String | Tidak | user01 | ID pengguna bagi pengendali. |
| group_key | String | Ya | 015xxxx | ID kumpulan kehadiran.  **Nota**  Jika pengecam kumpulan kehadiran anda ialah group_id, panggil API [Tukar groupId kepada groupKey](/ms/open/development/groupid-to-groupkey) untuk menukar group_id kepada group_key. |

### Contoh permintaan

```curl
curl -X POST "https://api.dingtalk.io/topapi/attendance/group/wifis/query" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=698cxxxx9b13' \
-d 'cursor=0151E0xxxx17E876' \
-d 'group_key=0151Exxxx17E876' \
-d 'op_userid=123456' \
-d 'size=50'
```

## Respons

### Isi respons

| Nama | Jenis | Contoh | Penerangan |
| --- | --- | --- | --- |
| result | DingOpenResult |  | Hasil yang dikembalikan. |
| result | Result |  | Hasil pertanyaan senarai Wi-Fi. |
| wifi_list | Wifi[] |  | Senarai Wi-Fi. |
| mac_addr | String | 54:8D:xx:xx:xx:73 | Alamat MAC. |
| ssid | String | alibaba-inc | Nama Wi-Fi. |
| wifi_key | String | E4CB0xxxx | Kunci Wi-Fi. |
| has_more | Boolean | true | Sama ada terdapat lebih banyak data.   - **true**: Ya - **false**: Tidak |
| errcode | Number | 0 | Kod pemulangan. |
| errmsg | String | ok | Penerangan kod pemulangan. |
| success | Boolean | true | Sama ada panggilan berjaya.   - **true**: Berjaya - **false**: Gagal |
| request_id | String | 155qyie8nxoqu | ID permintaan. |

### Contoh isi respons

```json
{
  "result": {
```
