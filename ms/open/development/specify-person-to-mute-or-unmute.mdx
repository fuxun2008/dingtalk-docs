Semasa mesyuarat, panggil API ini untuk membisukan atau menyahbisukan pengguna yang ditetapkan.

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/conference/videoConferences/{conferenceId}/members/mute` |
| Kaedah HTTP | POST |
| Jenis aplikasi disokong | appType-Aplikasi dalaman　appType-Aplikasi perusahaan pihak ketiga |
| Kebenaran diperlukan | permission-VideoConference.Conference.Write-Kebenaran pengurusan maklumat Mesyuarat Video |

### Pengepala permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses yang digunakan untuk memanggil API ini. Dapatkannya seperti berikut:   - Untuk aplikasi dalaman, panggil API [Dapatkan access token aplikasi dalaman](/ms/open/development/obtain-the-access-token-of-an-internal-app#). - Untuk aplikasi perusahaan pihak ketiga, panggil API [Dapatkan access token organisasi yang diberi kuasa kepada aplikasi pihak ketiga](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#). |

### Parameter laluan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| conferenceId | String | Ya | ID mesyuarat. Panggil API [Cipta mesyuarat video](/ms/open/development/create-a-video-conference#) untuk mendapatkan medan `conferenceId` daripada respons. |

### Isi permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| action | String | Ya | Jenis tindakan:   - **mute**: Bisukan. - **un_mute**: Nyahbisukan. |
| userList | Array | Ya | Senarai pengguna yang hendak dikenakan tindakan.  Buat masa ini, hanya satu pengguna dibenarkan. |
| unionId | String | Ya | unionId pengguna. |
| participantId | String | Tidak | ID peserta bagi pengguna.  Digunakan dalam senario berbilang peranti. Jika tidak dinyatakan, semua peranti pengguna dikawal. |
