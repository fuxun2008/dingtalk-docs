---
title: "Get the information of an async task in storage"
description: "Call this API to query the execution status and result of async tasks in storage, applicable to async operations such as batch moving, copying, or deleting folders that contain child nodes."
---

Panggil API ini untuk mendapatkan maklumat tugas async dalam storan, termasuk sama ada tugas async tersebut telah selesai dan sama ada ia berjaya. Contohnya, apabila melakukan pergerakan pukal fail atau folder, penyalinan pukal fail atau folder, atau pemadaman pukal fail atau folder, operasi tersebut berjalan secara async jika objek sasaran mengandungi nod anak.

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/storage/tasks/{taskId}` |
| Kaedah HTTP | GET |
| Jenis aplikasi yang disokong | appType-Aplikasi dalaman　appType-Aplikasi perusahaan pihak ketiga |
| Kebenaran yang diperlukan | permission-Storage.Task.Read-Kebenaran Telah dibaca untuk tugas storan organisasi |

### Header permintaan

| Nama | Jenis | Wajib | Penjelasan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses yang digunakan untuk memanggil API ini. Dapatkan seperti berikut:   - Untuk aplikasi dalaman, panggil API [Get the access token of an internal app](/ms/open/development/obtain-the-access-token-of-an-internal-app#). - Untuk aplikasi perusahaan pihak ketiga, panggil API [Get the access token of an authorized organization for a third-party app](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#). |

### Parameter laluan (path)

| Nama | Jenis | Wajib | Penjelasan |
| --- | --- | --- | --- |
| taskId | String | Ya | ID Tugas async dalam storan. Panggil API [Bulk move files or folders](/ms/open/development/bulk-move-files-or-folders#) untuk mendapatkan nilai parameter taskId.  Contohnya, ID Tugas async untuk operasi pergerakan pukal fail atau folder. |

### Parameter query

| Nama | Jenis | Wajib | Penjelasan |
| --- | --- | --- | --- |
| unionId | String | Ya | unionId bagi operator. Panggil API [Query user details](/ms/open/development/query-user-details#) untuk mendapatkannya. |

## Respons

### Isi respons

| Nama | Jenis | Penjelasan |
| --- | --- | --- |
| task | Object | Maklumat tugas. |
| id | String | ID Tugas. |
| status | String | Status tugas.   - **INIT**: Dimulakan - **IN_PROGRESS**: Sedang berjalan - **SUCCESS**: Berjaya - **FAIL**: Gagal |
| totalCount | Long | Jumlah bilangan sub-tugas. |
| successCount | Long | Bilangan sub-tugas yang berjaya. |
| failCount | Long | Bilangan sub-tugas yang gagal. |
| failMessage | String | Sebab kegagalan tugas. |
| beginTime | String | Masa mula tugas, dalam format ISO 8601. Contohnya, 2022-07-29T14:55Z. |
| endTime | String | Masa Tamatkan tugas, dalam format ISO 8601. Contohnya, 2022-07-29T14:55Z. |
