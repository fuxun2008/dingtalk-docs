Panggil API ini untuk mendapatkan senarai bot dalam kumpulan.

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/v1.0/robot/groups/robots/query |
| HTTP Method | POST |
| Jenis aplikasi disokong | appType-Aplikasi dalaman |
| Kebenaran diperlukan | permission-qyapi_chat_manage-Kebenaran pengurusan maklumat asas kumpulan DingTalk |

### Pengepala permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Untuk mendapatkannya, panggil API [Dapatkan access token aplikasi dalaman](/ms/open/development/obtain-the-access-token-of-an-internal-app#). |

### Isi permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| openConversationId | String | Ya | ID kumpulan. Bagi kumpulan yang dicipta daripada templat kumpulan, panggil API [Cipta kumpulan](https://open.dingtalk.com/document/development/create-a-scene-group-v2#) untuk mendapatkan nilai parameter `open_conversation_id`. |

## Respons

### Isi respons

| Nama | Jenis | Penerangan |
| --- | --- | --- |
| chatbotInstanceVOList | Array | Senarai bot yang dikembalikan. |
| robotCode | String | Kod bot. Rujuk bahagian [Glosari Bot - robotCode](https://open.dingtalk.com/document/development/robot-overview#) untuk mendapatkan `robotCode`. |
| name | String | Nama bot. |
| downloadIconURL | String | Pautan muat turun untuk Gambar Profil bot. |
| openRobotType | Integer | Jenis bot:   - **1**: Bot templat awam, seperti Bot tersuai atau Xinzhi Weather. - **2**: Bot aplikasi dalaman. - **3**: Bot aplikasi perusahaan pihak ketiga. - **4**: Bot kumpulan senario. |

### Contoh isi respons

```text
HTTP/1.1 200 OK
Content-Type:application/json

{
  "chatbotInstanceVOList" : [ {
    "robotCode" : "dingcdsjfXXXXX",
    "name" : "Bot",
    "downloadIconURL" : "https://img.alicdn.comXXXXXX.jpg",
    "openRobotType" : 1
  } ]
}
```
