Log masuk senyap membolehkan pengguna mengakses aplikasi tanpa memasukkan nama pengguna dan kata laluan DingTalk mereka. Aplikasi tersebut akan mendapatkan identiti pengguna semasa secara automatik dan log masuk ke sistem sebagai pengguna itu. Dengan log masuk senyap, pembangun dapat memberikan pengalaman pengesahan yang lancar serta meningkatkan kemudahan dan keselamatan pengguna.

## Khalayak sasaran

Dokumen ini disediakan untuk pembangun jenis aplikasi berikut:

- **Aplikasi dalaman**: Aplikasi yang dibangunkan oleh organisasi untuk kegunaan pekerjanya sendiri sahaja.
- **Aplikasi perusahaan pihak ketiga (Aplikasi ISV)**: Aplikasi SaaS yang dibangunkan oleh penyedia perkhidmatan pihak ketiga dan dipasang oleh pelbagai pelanggan perusahaan.
- **Sistem backend pengurusan aplikasi**: Sistem konfigurasi dan pengurusan yang diakses terus oleh Admin Organisasi daripada DingTalk admin console.

## Senario log masuk senyap yang disokong

- Log masuk senyap untuk aplikasi web (aplikasi mikro H5)
- Log masuk senyap untuk backend pengurusan aplikasi
- Log masuk berasaskan web ke aplikasi (log masuk ke laman web pihak ketiga)

  - Pelaksanaan dalam pelayar

    - Log masuk dengan Imbas Kod QR
    - Log masuk dengan akaun dan kata laluan DingTalk

## Log masuk senyap untuk aplikasi dalaman

Apabila pembangun perusahaan membina aplikasi dalaman, pekerja boleh menggunakan aplikasi tersebut dalam DingTalk dan log masuk ke sistem secara automatik tanpa memasukkan akaun atau kata laluan.

Untuk langkah log masuk senyap, rujuk Log masuk senyap untuk aplikasi web (aplikasi mikro H5).

| Langkah | Penerangan |
| --- | --- |
| Langkah 1: Dapatkan authorization_code log masuk senyap. | Pembangunan mini program tidak disokong pada PC. Untuk membina aplikasi PC, gunakan pendekatan **pembangunan aplikasi mikro**. |
| Langkah 2: Dapatkan access_token. | Panggil API [Dapatkan access token aplikasi dalaman](/open/development/obtain-the-access-token-of-an-internal-app). |
| Langkah 3: Dapatkan ID pengguna. | Panggil API [Dapatkan maklumat pengguna menggunakan kod log masuk senyap](/open/development/obtain-the-userid-of-a-user-by-using-the-log-free) untuk mendapatkan ID pengguna. |
| Langkah 4: Dapatkan butiran pengguna. | Panggil API [Tanya butiran pengguna](/open/development/query-user-details) untuk mendapatkan butiran pengguna. |

## Log masuk senyap untuk backend pengurusan aplikasi

Jika aplikasi anda memerlukan Admin Organisasi melaksanakan tugas konfigurasi dan pengurusan dalam [DingTalk admin console](https://oa.dingtalk.io/), anda perlu membina sistem pengurusan backend untuk aplikasi tersebut. Admin kemudiannya boleh mengklik backend pengurusan aplikasi terus dalam [DingTalk admin console](https://oa.dingtalk.io/) dan log masuk ke sistem backend anda secara automatik, tanpa memasukkan akaun atau kata laluan.

Untuk langkah log masuk senyap, rujuk Log masuk senyap untuk backend pengurusan aplikasi.

| Langkah | Penerangan |
| --- | --- |
| Langkah 1: Dapatkan authorization_code log masuk senyap. | Selepas Admin Organisasi log masuk ke [DingTalk admin console](http://oa.dingtalk.io/) dan mengklik aplikasi pada **Workbench**, halaman akan diarahkan semula ke URL backend aplikasi, dan DingTalk akan menambah parameter `code` pada URL tersebut. Simpan nilai parameter `code` untuk digunakan pada langkah seterusnya. |
| Langkah 2: Dapatkan access_token untuk log masuk senyap ke backend aplikasi. | Panggil API untuk mendapatkan access token bagi log masuk senyap ke backend aplikasi mikro, dan gunakannya sebagai access_token untuk log masuk senyap ke backend aplikasi. |
| Langkah 3: Dapatkan maklumat identiti Admin aplikasi. | Gunakan `code` yang diperoleh dalam **Langkah 1** dan access_token yang diperoleh dalam **Langkah 2** untuk menukar kepada maklumat identiti Admin aplikasi. Untuk butiran lanjut, rujuk Dapatkan maklumat pengguna untuk log masuk senyap ke backend pengurusan aplikasi. |
