Panggil API ini untuk menambah Kenalan luaran ke Organisasi Anda.

## Permintaan

| **Maklumat asas** | Butiran |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/topapi/extcontact/create |
| Kaedah HTTP | POST |
| Jenis aplikasi disokong | appType-Aplikasi dalaman |
| Kebenaran diperlukan | permission-qyapi_ext_write-Kebenaran menulis untuk Kenalan luaran |

### Parameter pertanyaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | 6d1bxxxx | Kelayakan aplikasi yang digunakan untuk memanggil API ini. Dapatkannya melalui API untuk mendapatkan [access_token bagi Aplikasi dalaman](/ms/open/development/obtain-orgapp-token). |

### Isi permintaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| contact | OpenExtContact | Ya |  | Maklumat Kenalan luaran. |
| title | String | Tidak | Development Engineer | Jawatan. |
| label_ids | Number[] | Ya | [1561077317,1561077310] | Senarai tag. Panggil API [Dapatkan senarai tag Kenalan luaran](/ms/open/development/obtains-a-list-of-external-contact-tags) untuk menanyakan maklumat tag.  Rujuk [Cara menyesuaikan kumpulan tag untuk Organisasi](https://tms.dingtalk.io/markets/dingtalk/biaoqianzu) untuk menambah tag tersuai. Maksimum 20 ID label boleh dihantar setiap panggilan. |
| share_dept_ids | Number[] | Tidak | [1,2,3] | ID Jabatan untuk dikongsi. Panggil API [Dapatkan senarai ID Subjabatan](/ms/open/development/obtain-the-list-of-sub-department-ids) untuk mendapatkannya. Maksimum 20 ID Jabatan boleh dihantar setiap panggilan. |
| address | String | Tidak | Beijing | Alamat. |
| remark | String | Tidak | Manager Wang | Alias. |
| follower_user_id | String | Ya | manager4220 | ID pengguna Pemilik. Gunakan API [Tanya pengguna mengikut Nombor Telefon](/ms/open/development/query-users-by-phone-number) untuk mendapatkan ID pengguna. Maksimum 20 ID pengguna boleh dihantar setiap panggilan. |
| name | String | Ya | Zhang xx | Nama Kenalan luaran. |
| state_code | String | Ya | 86 | Kod negara bagi Nombor Telefon. |
| company_name | String | Tidak | DingTalk | Nama Syarikat bagi Kenalan luaran. |
| share_user_ids | String[] | Tidak | ["023420013644"] | Senarai ID pengguna kakitangan untuk dikongsi. Gunakan API [Tanya pengguna mengikut Nombor Telefon](/ms/open/development/query-users-by-phone-number) untuk mendapatkan ID pengguna. Maksimum 20 ID pengguna boleh dihantar setiap panggilan. |
| mobile | String | Ya | 130xxxx8888 | Nombor Telefon bagi Kenalan luaran. |

### Contoh permintaan

```curl
curl -X POST "https://api.dingtalk.io/topapi/extcontact/create" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=d5f0efxxxx9fa9e1' \
-d 'contact=null'
```

Java

```text
DingTalkClient client = new DefaultDingTalkClient("https://api.dingtalk.io/topapi/extcontact/create");
OapiExtcontactCreateRequest req = new OapiExtcontactCreateRequest();
OapiExtcontactCreateRequest.OpenExtContact contact = new OapiExtcontactCreateRequest.OpenExtContact();
contact.setTitle("Development Engineer");
contact.setLabelIds(Arrays.asList(1561077317L,1561077310L));
contact.setShareDeptIds(Arrays.asList(1L,2L,3L));
contact.setFollowerUserId("manager4220");
contact.setName("Zhang xx");
contact.setStateCode("86");
contact.setCompanyName("DingTalk");
contact.setShareUserIds(Arrays.asList("023420013644"));
contact.setMobile("130xxxx8888");
req.setContact(contact);
OapiExtcontactCreateResponse rsp = client.execute(req, access_token);
System.out.println(rsp.getBody());
```

## Respons

### Isi respons

| Nama | Jenis | Contoh | Penerangan |
| --- | --- | --- | --- |
| userid | String | 123420013632 | ID pengguna Kenalan luaran. |
| errcode | Number | 0 | Kod pemulangan. |
| errmsg | String | ok | Penerangan kod pemulangan. |
| request_id | String | 6idz5ss49kkj | ID Permintaan. |

### Contoh respons

```json
{
  "errcode":0,
  "userid":"011250026469774889",
  "request_id":"6idz5ss49kkj"
}
```

### Kod ralat

Jika Ralat dikembalikan semasa anda memanggil API ini, rujuk dokumen [Kod ralat global](/ms/open/development/server-api-error-codes-1) untuk penyelesaian berdasarkan Mesej ralat.

| Kod ralat (errcode) | Mesej ralat (errmsg) | Penyelesaian |
| --- | --- | --- |
| 33009 | Invalid tokenGrantType | Semak sama ada access_token sah. |
| 40036 | The parameter is empty. | Semak sama ada semua parameter Wajib di atas telah disediakan. |
| 60103 | Invalid phone number | Semak sama ada Nombor Telefon adalah betul. |
| 60204 | An external contact tag is required. | Berikan nilai untuk label_ids. |
| 60205 | The external contact feature is not enabled. | Aktifkan ciri Kenalan luaran selepas mendapat surat kebenaran pengguna. |
| 43007 | Authorization required | Semak sama ada access_token mempunyai Kebenaran yang diperlukan. |
| 60112 | Invalid user name | Semak sama ada nama pengguna adalah betul. |
| 22005 | The external contact already exists. | Semak sama ada Nombor Telefon bagi Kenalan luaran adalah betul. |
| -1 | The system is busy. | Cuba Lagi kemudian. |
