---
title: "Tetapkan lebar lajur secara pukal"
description: "Panggil API ini untuk menetapkan lebar lajur berturutan bermula daripada lajur tertentu dalam DingTalk Spreadsheet sekali gus, sesuai untuk pelarasan pukal bagi paparan kandungan atau susun atur cetakan; nilai dibundarkan kepada integer positif."
---

Panggil API ini untuk menetapkan lebar (dalam piksel) beberapa lajur berturutan dalam DingTalk Spreadsheet, bermula daripada lajur tertentu. Ini berguna apabila anda perlu melaraskan lebar lajur secara pukal untuk memenuhi paparan kandungan atau susun atur cetakan. Nilai lebar dibundarkan secara automatik kepada integer positif, dan API ini mengembalikan maklumat Helaian Kerja selepas operasi tersebut.

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/doc/workbooks/{workbookId}/sheets/{sheetId}/setColumnsWidth` |
| Kaedah HTTP | POST |
| Jenis aplikasi disokong | appType-Aplikasi dalaman |
| Kebenaran | permission-Document.Workbook.Write-Kebenaran tulis DingTalk Spreadsheet |

### Header permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Untuk mendapatkannya, panggil [Dapatkan access token aplikasi dalaman](/open/development/obtain-the-access-token-of-an-internal-app). |

### Parameter laluan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| workbookId | String | Ya | ID fail spreadsheet. `nodeId(dentryUuid)` yang dikembalikan oleh [API Knowledge Base](/open/development/knowledge-base-overview) ialah `workbookId` spreadsheet tersebut. Anda boleh mendapatkannya dengan memanggil [Dapatkan nod](https://open.dingtalk.com/document/development/get-node) atau [Cipta dokumen Knowledge Base](/open/development/create-team-space-document). |
| sheetId | String | Ya | ID atau tajuk Helaian Kerja. Panggil [Dapatkan semua Helaian Kerja](/open/development/obtain-all-worksheets) untuk mendapatkan ID dan tajuk Helaian Kerja. |

### Parameter pertanyaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| operatorId | String | Ya | unionId pengendali. Untuk mendapatkannya, panggil [Semak butiran pengguna](/open/development/query-user-details). Jika pengendali tidak mempunyai kebenaran, API mengembalikan ralat `The operator has no permission`. |

### Isi permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| column | Integer | Ya | Indeks lajur pertama yang lebarnya hendak diubah. Bermula daripada 0. |
| width | Integer | Ya | Lebar, dalam piksel. |
| columnCount | Integer | Ya | Bilangan lajur berturutan yang lebarnya hendak diubah. |
