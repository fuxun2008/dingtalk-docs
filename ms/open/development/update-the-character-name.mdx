description: "Ketahui cara memanggil API untuk mengemas kini nama peranan di DingTalk. Peranan dalam kumpulan Default seperti pemilik, penyelia, Super Admin dan Sub Admin tidak boleh diubah."
---

Panggil API ini untuk mengemas kini nama peranan. API ini tidak membenarkan anda mengubah peranan dalam kumpulan "Default", termasuk Orang bertanggungjawab, Penyelia, Super Admin, dan Sub Admin.

## Permintaan

| **Maklumat asas** | |
| --- | --- |
| HTTP URL | https://oapi.dingtalk.io/role/update_role |
| Kaedah HTTP | POST |
| Jenis aplikasi disokong | appType-Aplikasi dalaman |
| Kebenaran diperlukan | permission-qyapi_manage_addresslist-Kebenaran pengurusan data Kenalan |

### Parameter pertanyaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | 6d1bxxxx | Kelayakan aplikasi yang digunakan untuk memanggil API ini. Dapatkan melalui API untuk mendapatkan [access_token aplikasi dalaman](/open/development/obtain-orgapp-token). |

### Isi permintaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| roleId | Number | Ya | 1560985325 | ID peranan yang hendak dikemas kini. Anda boleh mendapatkannya dengan memanggil API [Get role list](/open/development/obtains-a-list-of-enterprise-roles). Peranan dalam kumpulan "Default" tidak boleh diubah, termasuk: Orang bertanggungjawab, Penyelia, Super Admin, dan Sub Admin. |
| roleName | String | Ya | Pembuatan pakaian | Nama peranan baharu. |

### Contoh permintaan

```curl
curl -X POST "https://oapi.dingtalk.io/role/update_role" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=bb0d689c-e415-4fa5-b5d8-e16741e12b87' \
-d 'roleId=1' \
-d 'roleName=11'
```

Java

```text
DingTalkClient client = new DefaultDingTalkClient("https://oapi.dingtalk.io/role/update_role");
OapiRoleUpdateRoleRequest req = new OapiRoleUpdateRoleRequest();
req.setRoleId(1560985325L);
req.setRoleName("Pembuatan pakaian");
OapiRoleUpdateRoleResponse rsp = client.execute(req, access_token);
System.out.println(rsp.getBody());
```

Python

```python
import dingtalk.api

req=dingtalk.api.OapiRoleUpdateRoleRequest("https://oapi.dingtalk.io/role/update_role")

req.roleId=1
req.roleName="11"
try:
  resp= req.getResponse(access_token)
  print(resp)
except Exception,e:
  print(e)
```

PHP

```php
include "TopSdk.php";
date_default_timezone_set('Asia/Shanghai');

$c = new DingTalkClient(DingTalkConstant::$CALL_TYPE_OAPI, DingTalkConstant::$METHOD_POST , DingTalkConstant::$FORMAT_JSON);

$req->setRoleId("1");
$req->setRoleName("11");
$resp = $c->execute($req, $access_token, "https://oapi.dingtalk.io/role/update_role");
```

C#

```text

OapiRoleUpdateRoleResponse rsp = client.Execute(req, access_token);

```

## Respons

### Isi respons

| Nama | Jenis | Contoh | Penerangan |
| --- | --- | --- | --- |
| errcode | Number | 0 | Kod pulangan. |
| errmsg | String | ok | Penerangan kod pulangan. |

### Contoh isi respons

```json
{
  "errcode":0,
  "errmsg":"ok"
}
```

### Kod ralat

Jika berlaku ralat semasa memanggil API ini, rujuk dokumen [Kod ralat global](/open/development/server-api-error-codes-1) untuk mencari penyelesaian berdasarkan mesej ralat.

| Kod ralat (errcode) | Mesej ralat (errmsg) | Penyelesaian |
| --- | --- | --- |
| 660000 | Parameter kosong | Lengkapkan parameter yang tiada. |
| 33011 | roleId tidak sah | Semak sama ada roleId betul. |
| -1 | Sistem sibuk | Cuba Lagi kemudian. |
