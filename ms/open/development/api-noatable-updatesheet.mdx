Panggil API ini untuk mengemas kini maklumat jadual.

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| HTTP URL | `https://api.dingtalk.io/v1.0/notable/bases/{baseId}/sheets/{sheetIdOrName}` |
| HTTP Method | PUT |
| Jenis aplikasi disokong | appType-Aplikasi dalaman |
| Kebenaran diperlukan | permission-Notable.Base.Write.All-Kebenaran tulis aplikasi AI Table |

### Header permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Untuk mendapatkannya, panggil API [Dapatkan access token aplikasi dalaman](/open/development/obtain-the-access-token-of-an-internal-app#). |

### Parameter laluan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| baseId | String | Ya | ID AI Table. Untuk maklumat lanjut tentang cara mendapatkannya, lihat [Struktur data](/open/development/data-structure#). |
| sheetIdOrName | String | Ya | ID atau nama jadual. Anda boleh mendapatkan ID jadual dengan salah satu cara berikut:   - Panggil API [Dapatkan semua jadual](/open/development/api-notable-getallsheets#). - Panggil API [Dapatkan jadual](/open/development/api-notable-getsheet#). |

### Parameter kueri

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| operatorId | String | Ya | unionId pengendali. Anda boleh mendapatkannya dengan salah satu cara berikut:   - Panggil API [Dapatkan butiran pengguna](/open/development/query-user-details#). - Panggil API [Dapatkan maklumat pengguna melalui kod log masuk senyap](/open/development/obtain-the-userid-of-a-user-by-using-the-log-free#). |

### Isi permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| name | String | Ya | Nama baharu jadual. |

### Contoh permintaan

HTTP

```http
PUT /v1.0/notable/bases/qnYxxx/sheets/Table?operatorId=xxxxx HTTP/1.1
Host:api.dingtalk.io
x-acs-dingtalk-access-token:xxxxx
Content-Type:application/json

{
  "name" : "Table2"
}
```

## Respons

### Isi respons

| Nama | Jenis | Penerangan |
| --- | --- | --- |
| id | String | ID jadual. |
| name | String | Nama jadual. |

### Contoh isi respons

```text
HTTP/1.1 200 OK
Content-Type:application/json

{
  "id" : "xxxxx",
  "name" : "Table"
}
```

### Kod ralat

Jika ralat dikembalikan semasa anda memanggil API ini, cari penyelesaiannya dalam dokumen [Kod ralat global](/open/development/server-api-error-codes-1) berdasarkan mesej ralat.

| HttpCode | Kod ralat | Mesej ralat | Penerangan |
| --- | --- | --- | --- |
| 500 | internalError | Pelayan mengalami ralat dalaman dan tidak dapat menyelesaikan permintaan anda. Sila cuba lagi kemudian. | Ralat sistem. |
| 500 | unknownError | Ralat Tidak Diketahui | Ralat tidak diketahui. |
| 400 | invalidRequest.inputArgs.invalid | %s | Parameter permintaan tidak sah. Rujuk mesej ralat untuk maklumat lanjut. |
| 400 | invalidRequest.document.stillInitializing | Dokumen sedang diinisialisasi. Sila cuba lagi kemudian | Dokumen sedang diinisialisasi. Cuba lagi kemudian. |
| 400 | invalidRequest.document.broken | Dokumen rosak dan pelayan tidak dapat menyelesaikan permintaan anda. | Dokumen rosak. |
| 403 | forbidden.operationIllegal | %s | Tiada kebenaran. |
| 403 | invalidRequest.document.typeIllegal | %s | Jenis dokumen tidak disokong. Semak baseId. |
| 404 | invalidRequest.document.notFound | Gagal mencari sumber yang diminta menggunakan baseId yang diberikan. Pastikan baseId yang diberikan sah dan operatorId mempunyai kebenaran untuk mengaksesnya. | Dokumen tidak wujud. |
| 404 | invalidRequest.resource.notFound | %s | Sumber tidak wujud. Data tidak wujud atau telah dipadam secara kekal. |
| 504 | service.timeout | Pelayan sibuk dan tidak dapat menyelesaikan permintaan anda. Sila cuba lagi kemudian. | Permintaan tamat masa. |
