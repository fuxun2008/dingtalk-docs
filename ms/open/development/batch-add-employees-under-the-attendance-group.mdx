Panggil API ini untuk menambah ahli kehadiran secara pukal ke kumpulan kehadiran tertentu menggunakan groupKey. API ini hanya menyokong penambahan pekerja. Penambahan jabatan tidak disokong.

## Permintaan

| **Maklumat asas** | |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/topapi/attendance/group/users/add |
| Kaedah HTTP | POST |
| Jenis aplikasi yang disokong | appType-Aplikasi dalaman |
| Kebenaran | permission-qyapi_attendance_group_manage-Kebenaran pengurusan kumpulan kehadiran |

### Parameter query

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | 4c9ebd2b1534xxxx | Kelayakan aplikasi yang digunakan untuk memanggil API ini. Dapatkan kelayakan ini dengan memanggil API [Dapatkan access_token Aplikasi dalaman](/ms/open/development/obtain-orgapp-token). |

### Isi permintaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| op_userid | String | Tidak | user01 | ID pengguna bagi operator. |
| group_key | String | Ya | CEDDxxxx | ID kumpulan kehadiran.  **Nota**  Jika pengecam kumpulan kehadiran anda ialah group_id, panggil API [Tukar groupId kepada groupKey](/ms/open/development/groupid-to-groupkey) untuk menukar group_id kepada group_key. |
| user_id_list | String[] | Ya | user02,user03 | Senarai ID pengguna. Maksimum: 100. |

### Contoh permintaan

```curl
curl -X POST "https://api.dingtalk.io/topapi/attendance/group/users/add" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=e0f3d9xxxxa9b71' \
-d 'group_key=0151E0xxxx917E876' \
-d 'op_userid=123456' \
-d 'user_id_list=123456%2C123457'
```

Java

```java
DingTalkClient client = new DefaultDingTalkClient("https://api.dingtalk.io/topapi/attendance/group/users/add");
OapiAttendanceGroupUsersAddRequest req = new OapiAttendanceGroupUsersAddRequest();
req.setOpUserid("user01");
req.setGroupKey("CEDDxxxx");
req.setUserIdList("user02,user03");
OapiAttendanceGroupUsersAddResponse rsp = client.execute(req, access_token);
System.out.println(rsp.getBody());
```

## Respons

### Isi respons

| Nama | Jenis | Contoh | Penerangan |
| --- | --- | --- | --- |
| result | Result |  | Hasil yang dikembalikan. |
| error_info_list | ErrorInfo[] |  | Senarai ralat. |
| failure_list | String[] |  | Senarai entri yang gagal. |
| msg | String | business fault | Mesej ralat. |
| code | String | 1000 | Kod ralat. |
| success_list | String[] |  | Senarai entri yang berjaya. |
| errcode | Number | 0 | Kod pemulangan. |
| errmsg | String | ok | Penerangan kod pemulangan. |
| success | Boolean | true | Sama ada permintaan berjaya.   - **true**: Berjaya - **false**: Gagal |
| request_id | String | w8iju9gfb236 | ID permintaan. |

### Contoh isi respons

```json
{
  "errcode": 0,
  "result": {
    "success_list": [
      "user456",
      "manager4220"
    ]
  },
  "success": true,
  "request_id": "w8iju9gfb236"
}
```

### Kod ralat

Jika panggilan API ini mengembalikan ralat, cari penyelesaian dalam dokumen [Kod ralat global](/ms/open/development/server-api-error-codes-1) berdasarkan mesej ralat.
