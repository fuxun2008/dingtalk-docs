Panggil API ini untuk mencipta helaian kerja baharu dalam dokumen hamparan.

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/doc/workbooks/{workbookId}/sheets` |
| Kaedah HTTP | POST |
| Jenis aplikasi yang disokong | appType-Aplikasi dalaman　appType-Aplikasi perusahaan pihak ketiga |
| Kebenaran yang diperlukan | permission-Document.Workbook.Write-Kebenaran tulis Hamparan DingTalk |

### Header permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Dapatkannya seperti berikut:   - Bagi aplikasi dalaman, panggil API [Dapatkan access token aplikasi dalaman](/open/development/obtain-the-access-token-of-an-internal-app#). - Bagi aplikasi perusahaan pihak ketiga, panggil API [Dapatkan access token organisasi yang diberi kebenaran untuk aplikasi pihak ketiga](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#). |

### Parameter laluan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| workbookId | String | Ya | ID fail hamparan. `nodeId(dentryUuid)` yang dikembalikan oleh [API Knowledge Base](/open/development/knowledge-base-overview#) adalah `workbookId` bagi hamparan tersebut. Dapatkannya dengan memanggil API [Dapatkan nod](https://open.dingtalk.com/document/development/get-node#) atau [Cipta dokumen Knowledge Base](/open/development/create-team-space-document#). |

### Parameter kueri

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| operatorId | String | Ya | unionId bagi pengendali. Dapatkannya dengan memanggil API [Tanya butiran pengguna](/open/development/query-user-details#).    Jika pengendali tidak mempunyai kebenaran yang diperlukan, API akan mengembalikan ralat `The operator has no permission`. |

### Isi permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| name | String | Ya | Nama helaian kerja.    Jika nama helaian kerja yang ditentukan bercanggah dengan nama sedia ada, ia akan dinamakan semula secara automatik kepada nilai yang sah. |

| name | String | Nama helaian kerja. |
| id | String | ID helaian kerja. |

```text

Content-Type:application/json

  "visibility" : "visible",
  "name" : "Sheet1",
  "id" : "st-xxxxx"
}
```
