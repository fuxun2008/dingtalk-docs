---
title: "Tetapkan admin kumpulan secara pukal"
description: "Ketahui cara memanggil API untuk melantik atau membatalkan peranan admin pengguna dalam sembang kumpulan perusahaan secara pukal di DingTalk — sesuai untuk kumpulan besar atau penyusunan semula organisasi."
---

Panggil API ini untuk melantik beberapa pengguna dalam sembang kumpulan organisasi sebagai admin secara pukal, atau membatalkan peranan admin bagi beberapa pengguna secara pukal. API ini sesuai untuk senario apabila sembang kumpulan organisasi besar dan admin perlu diselaraskan secara pukal untuk meningkatkan kecekapan pengurusan, atau apabila struktur organisasi disusun semula dan admin kumpulan perlu ditetapkan semula.

## Kebenaran

Untuk memanggil API ini, salah satu daripada kebenaran berikut diperlukan.

| Jenis aplikasi | Disokong | Kebenaran | Penyahpepijatan API Explorer |
| --- | --- | --- | --- |
| Aplikasi dalaman | Disokong | Kebenaran untuk mengurus maklumat asas kumpulan DingTalk | [API Explorer](https://open-dev.dingtalk.io/apiExplorer#/?devType=org&api=im_1.0%23ChatSubAdminUpdate) |
| Aplikasi perusahaan pihak ketiga | Tidak disokong | Tidak disokong | Tidak disokong |
| Aplikasi peribadi pihak ketiga | Tidak disokong | Tidak disokong | Tidak disokong |

## Kaedah HTTP

```http
POST /v1.0/im/subAdministrators HTTP/1.1
Host:api.dingtalk.io
x-acs-dingtalk-access-token:String
Content-Type:application/json

{
  "openConversationId" : "String",
  "userIds" : [ "String" ],
  "role" : Integer
}
```

## Parameter header

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Untuk mendapatkannya, panggil API [Dapatkan access token bagi aplikasi dalaman](/ms/open/development/obtain-the-access-token-of-an-internal-app). |

## Parameter body

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| openConversationId | String | Ya | ID kumpulan terbuka (open group ID). Untuk mendapatkan nilai `openConversationId`, panggil API [Cipta sembang kumpulan](/ms/open/development/create-common-group-new-version-v2). |
| userIds | Array of String | Ya | Senarai nilai `userid` pekerja dalam organisasi. Untuk mendapatkan nilai `userid_list`, panggil API [Tanya senarai ID pengguna jabatan](/ms/open/development/query-the-list-of-department-userids). |
| role | Integer | Ya | Jenis operasi. Nilai yang sah:   - **2**: Tambah sebagai admin. - **3**: Buang daripada admin. |

## Parameter respons

| Nama | Jenis | Penerangan |
| --- | --- | --- |
| success | String | Sama ada panggilan berjaya:   - **true**: Berjaya. - **false**: Gagal. |
