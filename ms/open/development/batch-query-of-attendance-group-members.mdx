Panggil API ini untuk mendapatkan ahli kehadiran bagi sesuatu kumpulan kehadiran berdasarkan ID kumpulan kehadiran, termasuk ID jabatan dan userId ahli kehadiran.

## Penerangan panggilan API

Jika jabatan ditetapkan sebagai ahli kehadiran, API ini memulangkan ID jabatan tetapi tidak memulangkan senarai pengguna dalam jabatan tersebut.

Contohnya, jika ahli kehadiran merangkumi **Jabatan Ujian** dan pekerja **Ahmad**, API ini memulangkan maklumat berikut:

- ID Jabatan Ujian, tetapi tidak termasuk senarai userId pekerja dalam jabatan tersebut
- userId Ahmad

## Permintaan

| **Maklumat asas** | |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/topapi/attendance/group/member/list |
| Kaedah HTTP | POST |
| Jenis aplikasi yang disokong | appType-Aplikasi dalaman appType-Aplikasi perusahaan pihak ketiga |
| Kebenaran | permission-qyapi_attendance_group_read-Kebenaran pertanyaan kumpulan kehadiran |

### Parameter pertanyaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | bE74xxxx | Kelayakan aplikasi yang digunakan untuk memanggil API ini.   - Bagi Aplikasi dalaman, dapatkannya dengan memanggil API [Dapatkan access_token Aplikasi dalaman](/ms/open/development/obtain-orgapp-token). - Bagi Aplikasi perusahaan pihak ketiga, dapatkannya dengan memanggil API Dapatkan access_token organisasi pihak ketiga. |

### Isi permintaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| cursor | Number | Tidak | 0 | Nilai cursor. Hantar 0 untuk permintaan pertama. Lalai: 0. |
| op_user_id | String | Ya | user123 | userId pengendali. |
| group_id | Number | Ya | 98562 | ID kumpulan kehadiran.  **Nota**  Jika anda menggunakan pengecam kumpulan kehadiran lama group_key, panggil API [Tukar groupKey kepada groupId](/ms/open/development/convert-groupkey-to-groupid) untuk menukar group_key kepada group_id. |

### Contoh permintaan

```curl
curl -X POST "https://api.dingtalk.io/topapi/attendance/group/member/list" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=51525xxxx4e1df6' \
-d 'cursor=9828' \
-d 'group_id=98562' \
-d 'op_user_id=dd_dd'
```

Java

```text
DingTalkClient client = new DefaultDingTalkClient("https://api.dingtalk.io/topapi/attendance/group/member/list");
OapiAttendanceGroupMemberListRequest req = new OapiAttendanceGroupMemberListRequest();
req.setCursor(0L);
req.setOpUserId("user123");
req.setGroupId(98562L);
OapiAttendanceGroupMemberListResponse rsp = client.execute(req, access_token);
System.out.println(rsp.getBody());
```

## Respons

### Isi respons

| Nama | Jenis | Contoh | Penerangan |
| --- | --- | --- | --- |
| request_id | String | zpdxhqyepfon | ID permintaan. |
| errcode | Number | 0 | Kod pulangan. |
| success | Boolean | true | Menunjukkan sama ada panggilan berjaya.   - **true**: Berjaya - **false**: Gagal |
| result | PageResult |  | Senarai hasil pertanyaan. |
| has_more | Boolean | false | Menunjukkan sama ada terdapat lebih banyak data.   - **true**: Ya - **false**: Tidak |
| cursor | Number | 752095318 | Cursor. |
| result | TopGroupMemberVo[] |  | Senarai userId pengguna. |
| atc_flag | String | 0 | Menunjukkan sama ada kehadiran diperlukan.   - **0**: Kehadiran diperlukan - **1**: Ahli yang dikecualikan daripada kehadiran |
| type | String | 0 | Jenis.   - **0**: Pekerja - **1**: Jabatan |
| member_id | String | user123 | ID ahli, iaitu userId atau deptId. |
