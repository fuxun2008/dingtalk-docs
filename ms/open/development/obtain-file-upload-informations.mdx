Panggil API ini untuk mendapatkan maklumat muat naik fail.

## Penerangan panggilan API

### Penerangan

- Jika parameter `spaceId` disediakan semasa memuat naik fail, gunakan API [Dapatkan maklumat muat naik fail](https://open.dingtalk.com/document/development/obtain-storage-upload-information#).
- Jika parameter `dentryUuid` atau `uuid` disediakan semasa memuat naik fail, dokumen ini disyorkan.

Aliran panggilan API adalah seperti berikut:

Langkah 1: Panggil API ini untuk mendapatkan nilai parameter `resourceUrls` dan `headers` yang diperlukan untuk muat naik fail.

Langkah 2: Muat naik fail menggunakan kaedah tandatangan pengepala OSS. Rujuk contoh berikut:

    reader.BaseStream.Seek(0, SeekOrigin.Begin);

Langkah 3: Panggil API [Hantar fail](/ms/open/development/submittal-file) untuk melengkapkan muat naik fail.

### Penerangan

- Apabila jenis ruang storan ialah USER, pengguna yang mempunyai kebenaran ke atas ruang tersebut mempunyai kebenaran tindakan. Pekerja lain perlu memanggil API [Tambah kebenaran](/ms/open/development/add-permissions-file) untuk kebenaran akses.
- Apabila jenis ruang storan ialah APP, sesiapa yang melakukan tindakan perlu memanggil API [Tambah kebenaran](/ms/open/development/add-permissions-file) untuk kebenaran akses.

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v2.0/storage/spaces/files/{parentDentryUuid}/uploadInfos/query` |
| Kaedah HTTP | POST |
| Jenis aplikasi yang disokong | appType-Aplikasi dalaman　appType-Aplikasi perusahaan pihak ketiga |
| Kebenaran diperlukan | permission-Storage.UploadInfo.Read-Kebenaran membaca maklumat muat naik fail storan organisasi |

### Pengepala permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Dapatkan dengan cara berikut:   - Untuk aplikasi dalaman, panggil API [Dapatkan access token aplikasi dalaman](/ms/open/development/obtain-the-access-token-of-an-internal-app#). - Untuk aplikasi perusahaan pihak ketiga, panggil API [Dapatkan access token organisasi yang diberi kebenaran untuk aplikasi pihak ketiga](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#). |

### Parameter laluan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| parentDentryUuid | String | Ya | dentryUuid bagi nod induk. Panggil API [Cari fail](/ms/open/development/search-for-files#) atau [Dapatkan maklumat dentryUuid](/ms/open/development/api-getuuidbydentryid#) untuk mendapatkan nilai medan `dentryUuid` yang dikembalikan.    Untuk direktori root ruang, hantar dentryUuid direktori root ruang tersebut. |

### Parameter pertanyaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| unionId | String | Ya | unionId bagi pengendali. Panggil API [Tanya butiran pengguna](/ms/open/development/query-user-details#) untuk mendapatkannya. |

### Isi permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| protocol | String | Ya | Mengembalikan maklumat yang diperlukan untuk protokol muat naik yang berbeza berdasarkan protokol yang ditentukan.   - **HEADER_SIGNATURE**: Tandatangan pengepala |
| option | Object | Tidak | Parameter pilihan. |
| storageDriver | String | Tidak | Jenis pemacu storan fail.    Buat masa ini, hanya DINGTALK disokong. |
| preCheckParam | Object | Tidak | Medan untuk pra-semakan. Digunakan untuk mengesahkan nama fail, integriti fail, dan kapasiti. |
| size | Long | Tidak | Saiz fail, digunakan untuk pengesahan berkaitan kapasiti. Jika tidak disediakan, tiada pengesahan dilakukan. |
| name | String | Tidak | Nama fail (digunakan untuk semakan kesahihan nama fail dan konflik nama fail). Peraturan: - Ruang di hujung depan dan belakang tidak dibenarkan dan akan dialih keluar secara automatik. - Tidak boleh mengandungi aksara khas, termasuk: tab, `*`, `"`, `<`, `>`, `|`. - Tidak boleh berakhir dengan `.`. |
| preferRegion | String | Tidak | Wilayah pilihan:   - **ZHANGJIAKOU**: Zhangjiakou - **SHENZHEN**: Shenzhen - **SHANGHAI**: Shanghai - **SINGAPORE**: Singapore - **UNKNOWN**: Tidak diketahui     Menentukan wilayah tempat sumber lebih diutamakan untuk disimpan, membolehkan ciri seperti muat naik berdekatan. |
| preferIntranet | Boolean | Tidak | Sama ada mengutamakan penghantaran intranet. Parameter ini memerlukan penghantaran intranet storan khusus dikonfigurasikan.   - **true**: Ya (lalai) - **false**: Tidak |
