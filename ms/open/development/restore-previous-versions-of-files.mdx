Panggil API ini untuk memulihkan versi sejarah bagi sesuatu fail.

## Penerangan panggilan API

Contohnya, fail bernama **test.txt** kini berada pada versi 5. Panggil API ini untuk memulihkan fail tersebut kepada versi 3. Selepas panggilan berjaya, versi terkini test.txt menjadi 6, dan kandungannya adalah sama seperti versi 3.

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/storage/spaces/{spaceId}/dentries/{dentryId}/versions/{version}/revert` |
| Kaedah HTTP | POST |
| Jenis aplikasi yang disokong | appType-Aplikasi dalaman　appType-Aplikasi perusahaan pihak ketiga |
| Kebenaran yang diperlukan | permission-Storage.File.Write-Kebenaran Tulis untuk fail storan organisasi |

### Pengepala permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Dapatkan seperti berikut:   - Bagi aplikasi dalaman, panggil API [Dapatkan access token aplikasi dalaman](/ms/open/development/obtain-the-access-token-of-an-internal-app). - Bagi aplikasi perusahaan pihak ketiga, panggil API [Dapatkan access token organisasi yang dibenarkan untuk aplikasi pihak ketiga](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1). |

### Parameter laluan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| spaceId | String | Ya | ID ruang. Panggil API [Tambah ruang](/ms/open/development/add-space) untuk mendapatkan nilai parameter `id`. |
| dentryId | String | Ya | ID fail. Panggil API [Dapatkan senarai fail atau folder](/ms/open/development/get-a-list-of-files-or-folders) atau [Dapatkan spaceId dan dentryId melalui dentryUuid](/ms/open/development/api-getdentryidbyuuid) untuk mendapatkan nilai parameter `id`. |
| version | Long | Ya | Nombor versi fail yang hendak dipulihkan. Nilai minimum ialah 0. |

### Parameter pertanyaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| unionId | String | Ya | unionId bagi pengendali. Panggil API [Semak butiran pengguna](/ms/open/development/query-user-details) untuk mendapatkan nilai parameter `unionid`. |

### Contoh permintaan

HTTP

```http
POST /v1.0/storage/spaces/854xxxxx/dentries/655xxxxx/versions/1/revert?unionId=chyxxxxx HTTP/1.1
Host:api.dingtalk.io
x-acs-dingtalk-access-token:xxxxx
Content-Type:application/json

{ }
```

## Respons

### Isi respons

| Nama | Jenis | Penerangan |
| --- | --- | --- |
| success | Boolean | Sama ada operasi berjaya.   - **true**: Berjaya - **false**: Gagal |

### Contoh isi respons

```text
HTTP/1.1 200 OK
Content-Type:application/json

{
  "success" : true
}
```

### Kod ralat

Jika berlaku ralat semasa memanggil API ini, rujuk dokumen [Kod ralat global](/ms/open/development/server-api-error-codes-1) untuk mencari penyelesaian berdasarkan mesej ralat.

| HttpCode | Kod ralat | Mesej ralat | Penerangan |
| --- | --- | --- | --- |
| 400 | operationConcurrentControl | %s | Kawalan konkurensi |
| 400 | paramError | %s | Ralat parameter |
| 403 | permissionDenied | %s | Pengguna tidak mempunyai kebenaran untuk mendapatkan maklumat fail atau folder |
| 500 | systemError | %s | Ralat sistem |
| 500 | unknownError | Unknown Error | Ralat tidak diketahui |
| 503 | operationTimeout | %s | Permintaan tamat masa |
