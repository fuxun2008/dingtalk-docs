---
title: "Insert dropdown lists"
description: "Panggil API ini untuk menetapkan pilihan senarai lungsur bagi julat sel tertentu dalam Helaian Kerja DingTalk, menyokong teks tersuai dan warna label untuk kemasukan data yang piawai."
---

Panggil API ini untuk mengkonfigurasikan pilihan senarai lungsur bagi julat sel tertentu dalam Helaian Kerja DingTalk. Anda boleh menyesuaikan nilai teks dan warna label bagi setiap pilihan. API ini berguna untuk menyeragamkan kemasukan data dan menyediakan pilihan pratetap (seperti status atau kategori). Setelah dikonfigurasikan, pengguna hanya boleh memilih nilai daripada pilihan yang telah ditetapkan.

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/doc/workbooks/{workbookId}/sheets/{sheetId}/ranges/{rangeAddress}/insertDropdownLists` |
| Kaedah HTTP | POST |
| Jenis aplikasi disokong | appType-Aplikasi dalaman |
| Kebenaran diperlukan | permission-Document.Workbook.Write-Kebenaran tulis Helaian Kerja DingTalk |

### Pengepala permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Untuk mendapatkannya, panggil API [Dapatkan access token aplikasi dalaman](/ms/open/development/obtain-the-access-token-of-an-internal-app). |

### Parameter laluan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| workbookId | String | Ya | ID fail Helaian Kerja. `nodeId(dentryUuid)` yang dikembalikan oleh API [Knowledge Base](/ms/open/development/knowledge-base-overview) ialah `workbookId` bagi Helaian Kerja tersebut. Untuk mendapatkannya, panggil API [Dapatkan nod](https://open.dingtalk.com/document/development/get-node) atau [Cipta dokumen Knowledge Base](/ms/open/development/create-team-space-document). |
| sheetId | String | Ya | ID atau tajuk helaian kerja. Untuk mendapatkan ID dan tajuk, panggil API [Dapatkan semua helaian kerja](/ms/open/development/obtain-all-worksheets). |
| rangeAddress | String | Ya | Alamat julat. |

### Parameter pertanyaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| operatorId | String | Ya | unionId bagi pengendali. Untuk mendapatkannya, panggil API [Query user details](/ms/open/development/query-user-details). Jika pengendali tidak mempunyai kebenaran yang diperlukan, API akan mengembalikan ralat `The operator has no permission`. |

### Isi permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| options | Array | Ya | Array bagi pilihan senarai lungsur. |
| value | String | Ya | Nilai bagi pilihan senarai lungsur. |
| color | String | Tidak | Warna bagi pilihan senarai lungsur, dinyatakan dalam notasi perenambelasan. Contohnya, #ff0000. |
