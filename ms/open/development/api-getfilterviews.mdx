---
title: "Dapatkan senarai paparan penapis"
description: "Panggil API ini untuk mendapatkan semua paparan penapis pada Helaian Kerja yang ditentukan, mengembalikan ID, nama, julat, dan syarat penapis bagi setiap paparan, sesuai untuk menyenaraikan atau membaca konfigurasi paparan secara kelompok."
---

Panggil API ini untuk mendapatkan senarai semua paparan penapis pada Helaian Kerja yang ditentukan. Respons akan mengembalikan ID, nama, julat, dan syarat penapis bagi setiap paparan penapis. Gunakan API ini untuk menyenaraikan paparan sedia ada sebelum menguruskan atau menukar paparan penapis, atau untuk membaca konfigurasi paparan penapis secara kelompok bagi pemprosesan lanjut dalam program anda.

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/doc/workbooks/{workbookId}/sheets/{sheetId}/filterViews` |
| Kaedah HTTP | GET |
| Jenis aplikasi disokong | appType-Aplikasi dalaman |
| Kebenaran diperlukan | permission-Document.Workbook.Read-Kebenaran baca Spreadsheet |

### Header permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses yang digunakan untuk memanggil API ini. Panggil API [Dapatkan access token aplikasi dalaman](/open/development/obtain-the-access-token-of-an-internal-app) untuk mendapatkannya. |

### Parameter laluan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| workbookId | String | Ya | ID fail Spreadsheet. `nodeId(dentryUuid)` yang dikembalikan oleh [API Knowledge Base](/open/development/knowledge-base-overview) ialah `workbookId` bagi Spreadsheet tersebut. Dapatkan nilai ini dengan memanggil API [Dapatkan nod](https://open.dingtalk.com/document/orgapp/get-node) atau [Cipta dokumen Knowledge Base](/open/development/create-team-space-document). |
| sheetId | String | Ya | ID atau nama Helaian Kerja. Panggil API [Dapatkan semua Helaian Kerja](/open/development/obtain-all-worksheets) untuk mendapatkan nilai parameter id atau name.  **Nota**  Jika Helaian Kerja tidak mempunyai paparan penapis, API akan mengembalikan array kosong. |

### Parameter pertanyaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| operatorId | String | Ya | unionId pengendali.   - Panggil API [Dapatkan maklumat pengguna melalui kod Log masuk senyap](/open/development/obtain-the-userid-of-a-user-by-using-the-log-free) untuk mendapatkan unionId. - Panggil API [Tanya butiran pengguna](/open/development/query-user-details) untuk mendapatkan unionId.       Jika pengendali tidak mempunyai kebenaran, API akan mengembalikan ralat `The operator has no permission`. |

## Respons

### Isi respons

| Nama | Jenis | Penerangan |
| --- | --- | --- |
| filterViews | Array | Senarai paparan penapis. Mengembalikan array kosong jika tiada paparan penapis wujud. |
| id | String | Pengecam unik bagi paparan penapis. |
| name | String | Nama paparan penapis. |
| range | String | Julat paparan penapis dalam notasi A1. |
| criteria | `Map<String, Object>` | Syarat penapis bagi setiap Lajur. Kunci ialah offset Lajur (relatif kepada Medan utama julat, bermula dari 0), dan nilai ialah objek syarat penapis. Mengembalikan objek kosong `{}` apabila tiada syarat penapis wujud. |
|  | Object | Syarat penapis. |
| filterType | String | Jenis penapis. Nilai yang sah: `values` (tapis mengikut nilai), `condition` (tapis mengikut syarat), `color` (tapis mengikut warna). |
| visibleValues | Array of String | Nilai yang kelihatan. |
| conditions | Array | Senarai syarat penapis apabila menapis mengikut syarat. Berkuat kuasa apabila `filterType` ialah `condition`. Setiap objek syarat mengandungi Medan `operator` dan `value`. |
| operator | String | Operator Syarat. Nilai yang sah:   - **equal** - **not-equal** - **contains** - **not-contains** - **starts-with** - **not-starts-with** - **ends-with** - **not-ends-with** - **greater** - **greater-equal** - **less** - **less-equal** |
| value | String | Nilai Syarat. |
| conditionOperator | String | Hubungan logik antara beberapa Syarat. Nilai yang sah: `and`, `or`. Nilai Lalai: `and`. Berkuat kuasa apabila `filterType` ialah `condition` dan beberapa Syarat ditentukan. |
| backgroundColor | String | Nilai warna (heksadesimal, seperti `#FF0000`) apabila menapis mengikut warna latar belakang. Berkuat kuasa apabila `filterType` ialah `color`. Saling eksklusif dengan `fontColor`. |
| fontColor | String | Nilai warna (heksadesimal, seperti `#FF0000`) apabila menapis mengikut warna Fon. Berkuat kuasa apabila `filterType` ialah `color`. Saling eksklusif dengan `backgroundColor`. |
