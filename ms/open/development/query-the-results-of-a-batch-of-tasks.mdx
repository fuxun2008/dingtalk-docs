---
title: "Tanya keputusan daftar masuk penjadualan syif"
description: "Gunakan API DingTalk ini untuk menyemak keputusan daftar masuk penjadualan syif secara pukal mengikut ID jadual dan dapatkan jenis kehadiran, masa daftar masuk dirancang dan banyak lagi."
---

Panggil API ini untuk menyemak keputusan daftar masuk penjadualan syif mengikut ID jadual dan dapatkan jenis kehadiran, masa daftar masuk yang dirancang, masa pengubahsuaian terakhir dan maklumat lain.

## Permintaan

| **Maklumat asas** | |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/topapi/attendance/schedule/result/listbyids |
| Kaedah HTTP | POST |
| Jenis aplikasi yang disokong | appType-Aplikasi dalaman　appType-Aplikasi perusahaan pihak ketiga |
| Kebenaran yang diperlukan | permission-qyapi_attendance_group_read-Kebenaran pertanyaan kumpulan kehadiran |

### Parameter pertanyaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | bE74xxxx | Kelayakan aplikasi yang digunakan untuk memanggil API ini.   - Bagi Aplikasi dalaman, dapatkannya dengan memanggil API [Dapatkan access_token Aplikasi dalaman](/ms/open/development/obtain-orgapp-token). - Bagi Aplikasi perusahaan pihak ketiga, dapatkannya dengan memanggil API Dapatkan access_token Aplikasi perusahaan pihak ketiga. |

### Isi permintaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| op_user_id | String | Ya | manager123 | userId operator. |
| schedule_ids | String | Ya | 144872188723,144872188722 | ID jadual. Panggil API [Tanya butiran penjadualan syif kehadiran organisasi](/ms/open/development/interface-for-daily-full-query-of-attendance-scheduling-information) untuk mendapatkan nilai parameter plan_id. Asingkan berbilang ID jadual dengan koma. Setiap panggilan menyokong sehingga 100 ID jadual. |

### Contoh permintaan

```curl
curl -X POST "https://api.dingtalk.io/topapi/attendance/schedule/result/listbyids" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=711cexxxx8ce772' \
-d 'op_user_id=dd_dd' \
-d 'schedule_ids=1234%2C3214'
```

Java

```java
DingTalkClient client = new DefaultDingTalkClient("https://api.dingtalk.io/topapi/attendance/schedule/result/listbyids");
OapiAttendanceScheduleResultListbyidsRequest req = new OapiAttendanceScheduleResultListbyidsRequest();
req.setOpUserId("user456");
req.setScheduleIds("16xxxx530,160xxxx12");
OapiAttendanceScheduleResultListbyidsResponse rsp = client.execute(req, access_token);
System.out.println(rsp.getBody());
```

Python


## Respons

### Isi respons

| Nama | Jenis | Contoh | Penerangan |
| --- | --- | --- | --- |
| result | TopScheduleResultVo[] | demo | Hasil pertanyaan. |
| check_type | String | OnDuty | Jenis kehadiran:   - **Onduty**: Daftar masuk - **OffDuty**: Daftar keluar |
| gmt_modified | Date | 2020-11-11 19:03:21 | Masa pengubahsuaian terakhir. |
| plan_check_time | Date | 2020-11-11 19:03:20 | Masa daftar masuk yang dirancang. |
| corp_id | String | dingxxxxx1c1 | ID organisasi. |
| base_check_time | Date | 2020-11-11 19:03:00 | Masa daftar masuk yang dirancang selepas dilaraskan oleh peraturan seperti kelewatan dan pulang awal yang dibenarkan. |
| group_id | Number | 67xxxx4 | ID kumpulan kehadiran. |
| gmt_create | Date | 2020-11-11 19:03:21 | Masa dicipta. |
| user_id | String | user123 | userId pengguna. |
| work_date | Date | 2020-11-11 00:00:00 | Hari bekerja, iaitu hari khusus bagi jadual tersebut. |
| id | Number | 11xxxx19 | ID keputusan daftar masuk. |
| location_result | String | Normal | Keputusan lokasi daftar masuk:   - **Normal**: Daftar masuk biasa - **NotSigned**: Belum daftar masuk - **Outside**: Kerja luar |
| is_legal | String | Y | Menunjukkan sama ada daftar masuk mempunyai ralat:   - **N**: Tidak - **Y**: Ya |
| time_result | String | Normal | Keputusan masa daftar masuk:   - **Normal**: Daftar masuk biasa - **NotSigned**: Belum daftar masuk - **Late**: Kelewatan - **SeriousLate**: Kelewatan serius - **Absenteeism**: Ponteng kerja akibat kelewatan - **Early**: Pulang awal |
| record_id | Number | 48xxxx644 | Rekod daftar masuk. |
| user_check_time | Date | 2020-11-11 19:03:20 | Masa daftar masuk. |
| schedule_id | Number | 5672xxxx63 | ID jadual. |
| success | Boolean | true | Menunjukkan sama ada permintaan berjaya.   - **true**: Berjaya - **false**: Gagal |
| errcode | Number | 0 | Kod pemulangan. |
| errmsg | String | ok | Penerangan kod pemulangan. |
| request_id | String | 6k9c3cvix353 | ID permintaan. |
