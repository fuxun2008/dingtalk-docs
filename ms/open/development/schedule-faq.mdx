# Soalan Lazim

## Contoh respons untuk peristiwa sepanjang hari

Sebagai contoh, bagi peristiwa sepanjang hari pada 1 Januari 2023, contoh masa yang dikembalikan adalah seperti berikut (masa tamat ialah T+1):

```json
{
  "start" : {
    "date" : "2023-01-01"
  },
  "end" : {
    "date" : "2023-01-02"
  }
}
```
