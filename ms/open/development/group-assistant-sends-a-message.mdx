Contoh ini menerangkan cara menghantar mesej melalui pembantu kumpulan.

1. Pilih aplikasi disasarkan dan pergi ke halaman butiran aplikasi. Klik **Maklumat asas** > **Kelayakan dan maklumat asas**.
2. Dapatkan Client ID dan Client Secret aplikasi.
3. Buat permintaan untuk kebenaran API bagi menghantar mesej pembantu kumpulan.
4. Dapatkan kredensial akses aplikasi. Lihat [Dapatkan access token aplikasi dalaman](/ms/open/development/obtain-the-access-token-of-an-internal-app).
5. Pada halaman Kumpulan Senario di bahagian belakang pembangun, buat permintaan [Bot](https://open-dev.dingtalk.io/fe/im#/robot/list). Setelah diluluskan, dapatkan parameter ID bot **robotCode**.
6. Pada halaman Kumpulan Senario di bahagian belakang pembangun, cipta [templat kumpulan](https://open-dev.dingtalk.io/fe/im#/group/list) dan dapatkan parameter ID templat kumpulan **template_id**.
7. Kaitkan [Bot kumpulan senario](https://open-dev.dingtalk.io/fe/im#/robot/list) kepada [templat kumpulan senario](https://open-dev.dingtalk.io/fe/im#/group/list), simpan suntingan, dan kembali ke senarai senario kumpulan.
8. Buka templat kumpulan berkaitan, hantar untuk semakan, dan klik Terbitkan.
9. Panggil API cipta kumpulan dengan **template_id** untuk mendapatkan **openConversationId**.
10. Panggil API hantar mesej pembantu kumpulan untuk menghantar mesej kumpulan Bot.

## Prasyarat

Selesaikan proses [Cipta aplikasi](/ms/open/dingstart/create-application).

## Langkah

1. Pilih aplikasi disasarkan dan pergi ke halaman butiran aplikasi. Klik **Maklumat asas** > **Kelayakan dan maklumat asas**.
2. Dapatkan Client ID dan Client Secret aplikasi.
3. Klik **Konfigurasi pembangunan** > **Urus kebenaran**. Masukkan `qyapi_chat_manage` dalam kotak carian kebenaran dan buat permintaan untuk kebenaran tersebut.
4. Dapatkan kredensial akses aplikasi. Lihat [Dapatkan access token aplikasi dalaman](/ms/open/development/obtain-the-access-token-of-an-internal-app). Semasa memanggil API, gunakan access token untuk mengesahkan identiti pemanggil.
5. Pada halaman Kumpulan Senario di bahagian belakang pembangun, buat permintaan [Bot](https://open-dev.dingtalk.io/fe/im#/robot/list) dan dapatkan parameter ID bot **robotCode**.

### Nota

   Membuat permintaan Bot memerlukan semakan. Setelah diluluskan, anda boleh melihat ID tersebut, seperti yang ditunjukkan dalam rajah di bawah.

6. Pada halaman Kumpulan Senario di bahagian belakang pembangun, cipta [templat kumpulan](https://open-dev.dingtalk.io/fe/im#/group/list) dan dapatkan parameter ID templat kumpulan **template_id**.

7. Kaitkan [Bot kumpulan senario](https://open-dev.dingtalk.io/fe/im#/robot/list) kepada [templat kumpulan senario](https://open-dev.dingtalk.io/fe/im#/group/list), simpan suntingan, dan kembali ke senarai senario kumpulan.

8. Buka templat kumpulan berkaitan, hantar untuk semakan, dan klik Terbitkan.

### Nota

   Semakan diluluskan secara automatik. Tiada kelulusan manual diperlukan.

9. Panggil API cipta kumpulan dengan **template_id** untuk mendapatkan **openConversationId**.
10. Panggil API hantar mesej pembantu kumpulan untuk menghantar mesej kumpulan Bot.
