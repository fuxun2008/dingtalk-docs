Panggil API ini untuk memadam pengguna tertentu mengikut ID pengguna.

## Penerangan panggilan API

Selepas anda berjaya memadam pengguna daripada Kenalan, data berikut turut dipadam:

- Pengguna dikeluarkan daripada kumpulan kehadiran yang mereka anggotai.
- Pengguna dikeluarkan daripada senarai kakitangan Smart HR. Anda boleh melihat maklumat pengguna di bawah pekerja yang telah berhenti dalam Smart HR.

## Permintaan

| **Maklumat asas** | |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/topapi/v2/user/delete |
| Kaedah HTTP | POST |
| Jenis aplikasi yang disokong | appType-Aplikasi dalaman |
| Kebenaran diperlukan | permission-qyapi_manage_addresslist-Kebenaran pengurusan data Kenalan |

### Parameter pertanyaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | Be3xxxx | Kelayakan aplikasi yang digunakan untuk memanggil API ini. Dapatkannya melalui API untuk mendapatkan [access_token aplikasi dalaman](/open/development/obtain-orgapp-token). |

### Isi permintaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| userid | String | Ya | uxxxx3 | ID pengguna pekerja tersebut. |

### Contoh permintaan

```bash
curl -X POST "https://api.dingtalk.io/topapi/v2/user/delete" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=0b8a6220-ef56-4427-83d5-5690431776e5' \
-d 'userid=zhangsan'
```

Java

```java
DingTalkClient client = new DefaultDingTalkClient("https://api.dingtalk.io/topapi/v2/user/delete");
OapiV2UserDeleteRequest req = new OapiV2UserDeleteRequest();
req.setUserid("user123");
OapiV2UserDeleteResponse rsp = client.execute(req, access_token);
System.out.println(rsp.getBody());
```

Python

```python
import dingtalk.api

req=dingtalk.api.OapiV2UserDeleteRequest("https://api.dingtalk.io/topapi/v2/user/delete")

req.userid="zhangsan"
try:
  resp= req.getResponse(access_token)
  print(resp)
except Exception,e:
  print(e)
```

PHP

```php
include "TopSdk.php";
date_default_timezone_set('Asia/Shanghai');

$c = new DingTalkClient(DingTalkConstant::$CALL_TYPE_OAPI, DingTalkConstant::$METHOD_POST , DingTalkConstant::$FORMAT_JSON);
$req = new OapiV2UserDeleteRequest;
$req->setUserid("zhangsan");
$resp = $c->execute($req, $access_token, "https://api.dingtalk.io/topapi/v2/user/delete");
```

C#

```csharp
IDingTalkClient client = new DefaultDingTalkClient("https://api.dingtalk.io/topapi/v2/user/delete");
OapiV2UserDeleteRequest req = new OapiV2UserDeleteRequest();
req.Userid = "zhangsan";
OapiV2UserDeleteResponse rsp = client.Execute(req, access_token);
Console.WriteLine(rsp.Body);
```

## Respons

### Isi respons

| Nama | Jenis | Contoh | Penerangan |
| --- | --- | --- | --- |
| request_id | String | 4f9md9obopn2 | ID permintaan tersebut. |
| errcode | Number | 0 | Kod pemulangan. |
| errmsg | String | Invalid userid | Mesej ralat yang dikembalikan apabila panggilan gagal. |

### Contoh isi respons

```json
{
  "errcode": 0,
  "errmsg": "ok",
  "request_id": "4f9md9obopn2"
}
```

### Kod ralat

Jika ralat dikembalikan semasa anda memanggil API ini, rujuk dokumen [kod ralat global](/open/development/server-api-error-codes-1) untuk penyelesaian.

| Kod ralat (errcode) | Mesej ralat (errmsg) | Penyelesaian |
| --- | --- | --- |
| 33012 | Invalid userId | Semak sama ada userId adalah betul. |
| 400002 | Invalid parameter | Semak sama ada parameter dimasukkan mengikut keperluan. |
| -1 | System busy | Cuba Lagi kemudian. |
