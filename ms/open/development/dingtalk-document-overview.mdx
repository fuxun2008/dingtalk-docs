DingTalk Docs OpenAPI menyediakan satu set antara muka RESTful yang membolehkan pembangun mengendalikan DingTalk Docs secara programatik. Gunakan API ini untuk mengautomasikan operasi baca dan tulis dokumen, menguruskan elemen blok (cipta, telah dibaca, kemas kini, padam), menjalankan operasi kandungan secara kelompok, dan banyak lagi. Ia sesuai untuk senario seperti penjanaan dokumen automatik, penyegerakan kandungan, dan penulisan pintar.

## Apakah itu DingTalk Docs

DingTalk Docs ialah suite pejabat kolaboratif perusahaan yang dibangunkan sendiri oleh DingTalk, sebahagian daripada Alibaba Group. Ia merangkumi alat penciptaan dalam talian seperti dokumen, hamparan, dan peta minda. Dalam penggunaan harian, edit dan lihat kandungan dokumen terus daripada komputer, telefon bimbit, atau tablet tanpa perlu memuat turun apa-apa. Semua perubahan disimpan secara automatik dalam masa nyata.

DingTalk Docs turut disepadukan secara mendalam dengan DingTalk, membolehkan kerjasama yang cekap dengan rakan sekerja berdasarkan hubungan organisasi. Gunakan DingTalk Docs untuk senario kerja harian seperti pengumpulan maklumat, pengurusan projek, mesyuarat, pelaporan perniagaan, dan orientasi kakitangan baharu. Untuk maklumat lanjut, sila rujuk [Panduan Pengguna DingTalk - DingTalk Docs](https://docs.dingtalk.io/i/p/Y7kmbokZp3pgGLq2/docs/od245kZmnOeW4D4L73YEWYbzxL6R0wMQ).

## Glosari

Sebelum menggunakan DingTalk Docs OpenAPI, anda perlu memahami konsep teras berikut:

### dentryUuid

Pengecam unik bagi sesuatu dokumen. Sebagai contoh, dalam `https://docs.dingtalk.io/i/nodes/Z90D4da-id`, `dentryUuid` ialah `Z90D4da-id`.

### blockId

Pengecam unik bagi elemen blok. Dapatkan melalui API "Tanya elemen blok".

### operatorId

`unionId` bagi pengendali, digunakan untuk mengenal pasti pengguna yang melaksanakan operasi dan mengesahkan kebenaran.

### BlockElement

Elemen blok ialah unit asas yang membentuk kandungan dokumen, seperti perenggan, tajuk, blok sorot, dan jadual.

### InlineElement

Elemen inline ialah elemen yang disarangkan di dalam elemen blok, seperti stiker, imej, pautan, dan slot.
