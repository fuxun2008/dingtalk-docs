Panggil API ini untuk mencipta pintasan kepada Knowledge Base atau fail pada lokasi tertentu.

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/v2.0/doc/resource/shortcut/create |
| Kaedah HTTP | POST |
| Jenis aplikasi disokong | appType-Aplikasi dalaman |
| Kebenaran diperlukan | permission-snsapi_base-Kebenaran asas diperlukan untuk memanggil SNS API |

### Pengepala permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Dapatkan dengan memanggil API [Dapatkan token pengguna](/ms/open/development/obtain-user-token). |

### Isi permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| param | Object | Ya | Parameter wajib. |
| sourceResourceId | String | Ya | ID lokasi sumber asal. Boleh berupa dentryUUid atau rootNodeUUid. Gunakan nilai dentryUUid yang dikembalikan oleh API [Carian Fail](/ms/open/development/search-for-files). |
| sourceResourceType | String | Ya | Jenis sumber asal:   - **DENTRY**: Fail - **WORKSPACE**: Knowledge Base |
| targetResourceId | String | Ya | ID lokasi sasaran. Boleh berupa dentryUUid atau rootNodeUUid. Gunakan nilai dentryUUid yang dikembalikan oleh API [Carian Fail](/ms/open/development/search-for-files). |
| targetResourceType | String | Ya | Jenis sumber sasaran:   - **DENTRY**: Fail - **WORKSPACE**: Knowledge Base |
| targetResourceName | String | Tidak | Nama pintasan. Pilihan. Jika tidak dinyatakan, nama sumber asal akan digunakan secara lalai. |

### Contoh permintaan

```http
POST /v2.0/doc/resource/shortcut/create HTTP/1.1
Host:api.dingtalk.io
```
