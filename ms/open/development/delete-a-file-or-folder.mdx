Panggil API ini untuk memadam fail atau folder.

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/storage/spaces/{spaceId}/dentries/{dentryId}` |
| Kaedah HTTP | DELETE |
| Jenis aplikasi yang disokong | appType-Aplikasi dalaman　appType-Aplikasi perusahaan pihak ketiga |
| Kebenaran diperlukan | permission-Storage.File.Write-Kebenaran tulis fail storan organisasi |

### Pengepala permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Dapatkan dengan cara berikut:   - Untuk aplikasi dalaman, panggil API [Dapatkan access token aplikasi dalaman](/open/development/obtain-the-access-token-of-an-internal-app). - Untuk aplikasi perusahaan pihak ketiga, panggil API [Dapatkan access token organisasi yang telah memberi kuasa kepada aplikasi pihak ketiga](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1). |

### Parameter laluan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| spaceId | String | Ya | ID ruang. Panggil API [Tambah ruang](/open/development/add-space) untuk mendapatkan nilai parameter id. |
| dentryId | String | Ya | ID fail atau folder yang akan dipadam. Panggil API [Dapatkan senarai fail atau folder](/open/development/get-a-list-of-files-or-folders) atau [Dapatkan spaceId dan dentryId melalui dentryUuid](/open/development/api-getdentryidbyuuid) untuk mendapatkan nilai parameter id. |

### Parameter pertanyaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| toRecycleBin | Boolean | Tidak | Sama ada item yang dipadam dialihkan ke Tong Sampah:   - **true**: Ya - **false**: Tidak. Ini ialah nilai lalai.   Pada masa ini, hanya fail dan folder dalam ruang drive awan yang dicipta melalui API [Cipta ruang](/open/development/new-space) yang menyokong pengalihan ke Tong Sampah. |
| unionId | String | Ya | unionId pengendali. Panggil API [Tanya butiran pengguna](/open/development/query-user-details) untuk mendapatkan nilai parameter unionid. |

### Contoh permintaan

HTTP

```http
DELETE /v1.0/storage/spaces/85xxxxx/dentries/456xxxxx?toRecycleBin=true&unionId=chyxxxxx HTTP/1.1
Host:api.dingtalk.io
x-acs-dingtalk-access-token:xxxxx
Content-Type:application/json
```

| --- | --- | --- |
| async | Boolean | Sama ada tugas ini adalah asinkron.   - **true**: Ya - **false**: Tidak |
| taskId | String | ID Tugas, digunakan untuk menanyakan status pelaksanaan tugas. |

```text

}
```
