Panggil API ini untuk menghantar fail ke perbualan yang ditetapkan.

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/v1.0/convFile/conversations/files/send |
| HTTP Method | POST |
| Jenis aplikasi disokong | appType-Aplikasi dalaman |
| Kebenaran diperlukan | permission-ConvFile.File.Send-Kebenaran hantar fail kumpulan |

### Header permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses yang digunakan untuk memanggil API ini. Dapatkan dengan memanggil API [Obtain the access token of an internal app](/open/development/obtain-the-access-token-of-an-internal-app#). |

### Parameter query

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| unionId | String | Ya | unionId pengendali. Dapatkan dengan memanggil API [Query user details](/open/development/query-user-details#). |

### Isi permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| spaceId | String | Ya | ID ruang. Dapatkan nilai parameter id dengan memanggil API [Add a space](/open/development/add-space#). |
| dentryId | String | Ya | ID fail. Dapatkan nilai parameter id dengan memanggil API [Obtain the list of files or folders](https://open.dingtalk.com/document/development/obtain-the-file-list-storage#). |
| openConversationId | String | Ya | openConversationId perbualan sasaran. Dapatkan nilai parameter openConversationId dengan memanggil API [Create a group](https://open.dingtalk.com/document/development/create-group-session#). |

## Respons

### Isi respons

| Nama | Jenis | Penerangan |
| --- | --- | --- |
| file | Object | Maklumat tentang fail yang dihantar ke perbualan sasaran. |
| id | String | ID fail. |
| conversationId | String | ID perbualan tempat fail itu berada. |
| spaceId | String | ID ruang tempat fail itu berada. |
| parentId | String | ID folder induk fail. ID folder root ialah 0. |
| type | String | Jenis fail.   - **FILE**: fail - **FOLDER**: folder |
| name | String | Nama fail. |
| size | Long | Saiz fail, dalam bait. |
| path | String | Laluan fail. |
| version | Long | Nombor versi fail. |
| status | String | Status fail.   - **NORMAL**: normal - **DELETED**: dipadam - **EXPIRED**: luput |
| extension | String | Sambungan fail. |
| creatorId | String | unionId pencipta fail. |
| modifierId | String | unionId pengubah suai fail. |
| createTime | String | Masa penciptaan fail, dalam format ISO 8601. Contoh: 2022-07-29T14:55Z. |
| modifiedTime | String | Masa pengubahsuaian terakhir fail, dalam format ISO 8601. Contoh: 2022-07-29T14:55Z. |
| uuid | String | Medan pengecam. |
