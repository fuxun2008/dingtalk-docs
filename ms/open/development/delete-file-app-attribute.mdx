Padam nilai sifat aplikasi pada fail.

## Penerangan panggilan API

- Apabila jenis ruang storan ialah USER, semua pengguna yang mempunyai kebenaran ke atas ruang tersebut mempunyai kebenaran operasi. Pekerja lain perlu memanggil API [Tambah kebenaran](/ms/open/development/add-permissions-file) untuk mendapatkan kebenaran akses.
- Apabila jenis ruang storan ialah APP, sesiapa yang melaksanakan operasi ini perlu memanggil API [Tambah kebenaran](/ms/open/development/add-permissions-file) untuk mendapatkan kebenaran akses.

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/storage/spaces/{spaceId}/dentries/{dentryId}/appProperties/remove` |
| Kaedah HTTP | POST |
| Jenis aplikasi disokong | appType-Aplikasi dalaman　appType-Aplikasi perusahaan pihak ketiga |
| Keperluan kebenaran | permission-Storage.File.Write-Kebenaran tulis fail storan organisasi |

### Pengepala permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Dapatkan seperti berikut:   - Bagi aplikasi dalaman, panggil API [Dapatkan access token aplikasi dalaman](/ms/open/development/obtain-the-access-token-of-an-internal-app). - Bagi aplikasi perusahaan pihak ketiga, panggil API [Dapatkan access token organisasi yang diberi kebenaran kepada aplikasi pihak ketiga](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1). |

### Parameter laluan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| spaceId | Long | Ya | ID ruang. Panggil API [Tambah ruang](/ms/open/development/add-space) untuk mendapatkan nilai parameter id. |
| dentryId | Long | Ya | ID fail atau folder. Panggil API [Dapatkan senarai fail atau folder](/ms/open/development/get-a-list-of-files-or-folders) atau [Dapatkan spaceId dan dentryId melalui dentryUuid](/ms/open/development/api-getdentryidbyuuid) untuk mendapatkan nilai parameter id. |

### Parameter pertanyaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| unionId | String | Ya | unionId pengendali. Panggil API [Tanya butiran pengguna](/ms/open/development/query-user-details) untuk mendapatkan nilai parameter unionid. |

### Isi permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| propertyNames | Array of String | Ya | Senarai nama sifat aplikasi bagi fail atau folder. Bilangan maksimum ialah 3. |

## Respons

### Isi respons

| Nama | Jenis | Penerangan |
| --- | --- | --- |
| success | Boolean | Sama ada penghapusan berjaya.   - **true**: Berjaya - **false**: Gagal |

### Contoh isi respons

```text
HTTP/1.1 200 OK
Content-Type:application/json

{
  "success" : true
}
```
