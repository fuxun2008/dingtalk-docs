Panggil API ini untuk mencipta dokumen atau folder dalam Knowledge Base.

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| HTTP URL | `https://api.dingtalk.io/v1.0/doc/workspaces/{workspaceId}/docs` |
| HTTP Method | POST |
| Jenis aplikasi disokong | appType-Aplikasi dalaman　appType-Aplikasi perusahaan pihak ketiga |
| Kebenaran | permission-Document.WorkspaceDocument.Write-Kebenaran tulis dokumen Knowledge Base |

### Header permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Dapatkan seperti berikut:   - Untuk aplikasi dalaman, panggil API [Dapatkan access token aplikasi dalaman](/open/development/obtain-the-access-token-of-an-internal-app#). - Untuk aplikasi perusahaan pihak ketiga, panggil API [Dapatkan access token perusahaan yang diberi kuasa kepada aplikasi pihak ketiga](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#). |

### Parameter laluan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| workspaceId | String | Ya | ID Knowledge Base. Dapatkan nilai medan `workspaceId` dengan memanggil API [Cipta Knowledge Base](/open/development/new-knowledge-base#) atau API [Dapatkan senarai Knowledge Base](/open/development/get-knowledge-base-list#). |

### Isi permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| name | String | Ya | Nama dokumen. |
| docType | String | Ya | Jenis dokumen. Nilai sah:   - **DOC**: Dokumen - **WORKBOOK**: Spreadsheet - **MIND**: Peta Minda - **FOLDER**: Folder |
| operatorId | String | Ya | unionId pengguna. Dapatkan dengan memanggil API [Tanya butiran pengguna](/open/development/query-user-details#). |
| parentNodeId | String | Tidak | ID nod induk. Dapatkan nilai parameter `DentryModel` dengan memanggil API [Dapatkan senarai nod](/open/development/get-node-list#). Jika tidak dinyatakan, dokumen akan dicipta dalam direktori root secara lalai.      Nod induk boleh berupa folder atau dokumen biasa. |
| templateId | String | Tidak | ID templat dokumen. |
| templateType | String | Tidak | Jenis templat dokumen. Nilai sah:   - **public_template**: Cadangan - **team_template**: Templat pasukan - **user_template**: Templat peribadi |
