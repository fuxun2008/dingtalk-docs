---

Panggil API ini untuk menyediakan entri pantas bagi menambah Bot sembang tunggal. Konfigurasi ini termasuk nama entri, tajuk, pautan pengalihan PC, dan pautan pengalihan mudah alih. API ini sesuai untuk senario di mana organisasi perlu mengkonfigurasi entri Bot dengan pantas bagi meningkatkan capaian pengguna.

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/v1.0/robot/plugins/set |
| Kaedah HTTP | POST |
| Jenis aplikasi disokong | appType-Aplikasi dalaman |
| Kebenaran | permission-Robot.SingleChat.ReadWrite-Kebenaran pengurusan Bot sembang tunggal |

### Header permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses yang digunakan untuk memanggil API ini. Dapatkan dengan memanggil API [Dapatkan access token aplikasi dalaman](/ms/open/development/obtain-the-access-token-of-an-internal-app#). |

### Isi permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| robotCode | String | Tidak | Kod Bot. Rujuk bahagian `robotCode` dalam [Glosari Bot](https://open.dingtalk.com/document/development/robot-overview#) untuk mendapatkan `robotCode`. |
| pluginInfoList | Array | Tidak | Senarai plugin. |
| pcUrl | String | Tidak | Pautan pengalihan entri pantas sembang pada klien PC. |
| mobileUrl | String | Tidak | Pautan pengalihan entri pantas pada klien mudah alih. |
| name | String | Ya | Nama entri pantas. Penyetempatan disokong, contohnya `{"en_US":"test123","zh_CN":"测试123"}`. |
| icon | String | Ya | ID ikon entri pantas. Dapatkan parameter `mediaId` dengan memanggil API [Muat naik fail media](/ms/open/development/upload-media-files#). |
