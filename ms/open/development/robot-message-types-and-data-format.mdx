## Jenis Mesej dan Format Data

Terdapat dua cara untuk menghantar Mesej Bot: menghantar **melalui API** dan menghantar **melalui Webhook**. Kaedah yang berbeza menyokong jenis mesej dan format data yang berbeza.

**Nota** 

Kami mengesyorkan penghantaran mesej melalui API.

| Jenis Mesej | Hantar Mesej Bot melalui API | Hantar Mesej Bot melalui Webhook |
| --- | --- | --- |
| Jenis Teks | ✅ | ✅ |
| Jenis Markdown | ✅ | ✅ |
| Jenis Gambar | ✅ | ❌ |
| Jenis ActionCard | ✅ | ✅ |
| Jenis FeedCard | ❌ | ✅ |
| Mesej Pautan | ✅ | ✅ |

## Jenis Mesej dan Format Data yang Disokong oleh Webhook

### Skop Berkenaan

**Nota** 

Webhook hanya disokong dalam Sembang Kumpulan.

Untuk perincian tentang cara menghantar mesej melalui Webhook, lihat Hantar Mesej Sembang Kumpulan Menggunakan Webhook dengan Bot Dalaman dan Integrasi Bot Tersuai.

### Format Data

- **Jenis Teks**

  ```
  {
      "at": {
          "atMobiles": [
              "180xxxxxx"
          ],
          "atUserIds": [
              "user123"
          ],
          "isAtAll": false
      },
      "text": {
          "content": "Saya adalah diri saya, @180xxxxxx sejenis bunga api yang berbeza"
      },
      "msgtype": "text"
  }
  ```

  | **Parameter** | **Wajib** | **Jenis** | **Keterangan** |
  | --- | --- | --- | --- |
  | msgtype | Ya | String | text. |
  | content | Ya | String | Teks mesej. |
  | atMobiles | Tidak | Array | Nombor telefon bimbit orang yang hendak disebut (@mention).  **Nota**  Kandungan mesej mesti mengandungi "@nombor telefon bimbit" dan digunakan bersama-sama parameter atMobiles supaya sebutan (@mention) berkesan, seperti contoh di atas. |
  | atUserIds | Tidak | Array | ID pengguna orang yang hendak disebut (@mention). |
  | isAtAll | Tidak | Boolean | Tetapkan kepada true untuk @Semua Orang; jika tidak, false. |

- **Jenis Pautan**

  ```
  {
      "msgtype": "link", 
      "link": {
          "text": "Ini adalah mesej Link", 
          "title": "Ini adalah mesej Link", 
          "picUrl": "https://img.alicdn.com/tfs/TB1NwmBEL9TBuNjy1zbXXXpepXa-2400-1218.png", 
          "messageUrl": "https://open.dingtalk.com/document/"
      }
  }
  ```

  | **Parameter** | **Jenis Parameter** | Wajib | **Keterangan** |
  | --- | --- | --- | --- |
  | msgtype | String | Ya | Jenis mesej. Ditetapkan kepada link dalam kes ini. |
  | title | String | Ya | Tajuk mesej. |
  | text | String | Ya | Kandungan mesej. Jika terlalu panjang, hanya sebahagian dipaparkan. |
  | messageUrl | String | Ya | URL yang dibuka apabila anda klik mesej. |
  | picUrl | String | Tidak | URL Gambar. |

- **Jenis Markdown**

  ```
  {
       "msgtype": "markdown",
       "markdown": {
           "title":"Cuaca Hangzhou",
           "text": "#### Cuaca Hangzhou @150XXXXXXXX \n> 9 darjah, angin barat laut tahap 1, kualiti udara baik 89, kelembapan relatif 73% \n> \n> ###### Diterbitkan pada 10:20 [Cuaca](https://www.dingalk.com) \n"
       },
        "at": {
            "atMobiles": [
                "150XXXXXXXX"
            ],
            "atUserIds": [
                "user123"
            ],
            "isAtAll": false
        }
   }
  ```

  | **Parameter** | **Wajib** | **Jenis** | **Keterangan** |
  | --- | --- | --- | --- |
  | msgtype | Ya | String | markdown. |
  | title | Ya | String | Kandungan yang dipaparkan pada skrin pertama sembang. |
  | text | Ya | String | Kandungan mesej dalam format Markdown. |
  | atMobiles | Tidak | Array | Nombor telefon bimbit orang yang hendak disebut (@mention).  **Nota**  Kandungan mesej mesti mengandungi "@nombor telefon bimbit" dan digunakan bersama-sama parameter atMobiles supaya sebutan (@mention) berkesan, seperti contoh di atas. |
  | atUserIds | Tidak | Array | ID pengguna orang yang hendak disebut (@mention). |
  | isAtAll | Tidak | Boolean | Tetapkan kepada true untuk @Semua Orang; jika tidak, false. |

  Pada masa ini, hanya sebahagian sintaks Markdown disokong. Elemen yang disokong adalah seperti berikut:

  ```
  Tajuk
  # Tajuk 1
  ## Tajuk 2
  ### Tajuk 3
  #### Tajuk 4
  ##### Tajuk 5
  ###### Tajuk 6
   
  Petikan
  > Seseorang yang tidak berpendirian akan mudah terpengaruh oleh apa sahaja.
   
  Teks tebal dan condong
  **tebal**
  *condong*
   
  Pautan
  [ini adalah pautan](https://www.dingtalk.com/)
   
  Gambar

   
  Senarai Berbulet
  - item1
  - item2
   
  Senarai Bernombor
  1. item1
  2. item2
  ```
- **Jenis ActionCard Lompat Seluruh Kad**

  ```
  {
      "msgtype": "actionCard",
      "actionCard": {
          "title": "Bina Kedai Kopi", 
          "text": " \n #### Kedai kopi Apple yang ingin dibina oleh Steve Jobs 20 tahun lalu \n\n Reka bentuk Apple Store beralih daripada nuansa yang berat pada teknologi kepada nuansa yang lebih berorientasikan gaya hidup, satu hala tuju yang sebenarnya boleh dikesan kembali kepada rancangan Apple 20 tahun lalu untuk membina sebuah kedai kopi",
          "singleTitle" : "Baca Selanjutnya",
          "singleURL" : "https://www.dingtalk.com/"
      }
  }
  ```

  | **Parameter** | **Wajib** | **Jenis** | **Keterangan** |
  | --- | --- | --- | --- |
  | msgtype | Ya | String | actionCard. |
  | title | Ya | String | Kandungan yang dipaparkan pada skrin pertama sembang. |
  | text | Ya | String | Kandungan mesej dalam format Markdown. |
  | singleTitle | Ya | String | Tajuk butang tunggal. |
  | singleURL | Ya | String | Pautan lompat butang tunggal. |

- **Jenis ActionCard Lompat Berasingan**

  ```
  {
      "msgtype": "actionCard",
      "actionCard": {
          "title": "Steve Jobs ingin membina kedai kopi Apple 20 tahun lalu, dan ia merupakan perintis kepada Apple Store", 
          "text": " \n\n #### Kedai kopi Apple yang ingin dibina oleh Steve Jobs 20 tahun lalu \n\n Reka bentuk Apple Store beralih daripada nuansa yang berat pada teknologi kepada nuansa yang lebih berorientasikan gaya hidup, satu hala tuju yang sebenarnya boleh dikesan kembali kepada rancangan Apple 20 tahun lalu untuk membina sebuah kedai kopi", 
          "btnOrientation": "0", 
          "btns": [
              {
                  "title": "Kandungan yang bagus", 
                  "actionURL": "https://www.dingtalk.com/"
              }, 
              {
                  "title": "Tidak berminat", 
                  "actionURL": "https://www.dingtalk.com/"
              }
          ]
      }
  }
  ```

  | **Parameter** | **Wajib** | **Jenis** | **Keterangan** |
  | --- | --- | --- | --- |
  | msgtype | Ya | String | actionCard. |
  | title | Ya | String | Kandungan yang dipaparkan pada skrin pertama sembang. |
  | text | Ya | String | Kandungan mesej dalam format Markdown. |
  | btns | Ya | Array | Butang. |
  | title | Ya | String | Tajuk butang. |
  | actionURL | Ya | String | URL yang dicetuskan apabila anda klik butang. |
  | btnOrientation | Tidak | String | Susunan aturan butang.  **0**: Butang disusun secara menegak  **1**: Butang disusun secara mendatar |

- **Jenis FeedCard**

  ```
  {
      "msgtype": "feedCard",
      "feedCard": {
          "links": [
              {
                  "title": "Kereta Api Zaman Terus Bergerak Maju 1", 
                  "messageURL": "https://www.dingtalk.com/", 
                  "picURL": "https://img.alicdn.com/tfs/TB1NwmBEL9TBuNjy1zbXXXpepXa-2400-1218.png"
              },
              {
                  "title": "Kereta Api Zaman Terus Bergerak Maju 2", 
                  "messageURL": "https://www.dingtalk.com/", 
                  "picURL": "https://img.alicdn.com/tfs/TB1NwmBEL9TBuNjy1zbXXXpepXa-2400-1218.png"
              }
          ]
      }
  }
  ```

  | **Parameter** | **Wajib** | **Jenis** | **Keterangan** |
  | --- | --- | --- | --- |
  | msgtype | Ya | String | feedCard. |
  | title | Ya | String | Teks bagi satu item mesej. |
  | messageURL | Ya | String | Pautan lompat bagi satu item mesej. |
  | picURL | Ya | String | URL gambar selepas satu item mesej. |

  Apabila anda tidak mahu membalas dengan mesej dalam kumpulan, gunakan format balasan berikut:

  ```
  {
      "msgtype": "empty"
  }
  ```
