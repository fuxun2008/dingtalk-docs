title: "Muat turun lampiran kelulusan"
description: "Gunakan API DingTalk ini untuk mendapatkan kebenaran muat turun lampiran kelulusan berdasarkan ID instans dan fileId, serta menjana pautan muat turun fail."
---

Panggil API ini untuk mendapatkan kebenaran muat turun fail kelulusan dan menjana pautan muat turun.

## Penerangan panggilan API

- Jika borang kelulusan dihantar secara manual daripada klien DingTalk dengan fail tempatan sebagai lampiran, alamat muat turun lampiran yang dikembalikan oleh API ini menggunakan format #zifgs49xxxxx.file. Gunakan API ini bersama API [Dapatkan butiran satu instans kelulusan](/ms/open/development/obtains-the-details-of-a-single-approval-instance-pop). Dapatkan fileName dan fileType lampiran daripada API butiran instans, kemudian ganti nama dan sambungan dalam nilai #zifgs49xxxxx.file yang dikembalikan oleh API ini. Lampiran kemudiannya boleh dibuka dengan betul.
- Saiz fail lampiran tidak boleh 0. Pautan muat turun tidak disokong untuk fail kosong.

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/v1.0/workflow/processInstances/spaces/files/urls/download |
| Kaedah HTTP | POST |
| Jenis aplikasi yang disokong | appType-Aplikasi dalaman　appType-Aplikasi perusahaan pihak ketiga |
| Kebenaran | permission-Workflow.Instance.Write-Kebenaran tulis instans aliran kerja |

### Pengepala permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Dapatkan seperti berikut:   - Aplikasi dalaman: panggil API [Dapatkan access token aplikasi dalaman](/ms/open/development/obtain-the-access-token-of-an-internal-app). - Aplikasi perusahaan pihak ketiga: panggil API untuk mendapatkan access token organisasi yang diberi kebenaran oleh aplikasi pihak ketiga. |

### Isi permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| processInstanceId | String | Ya | ID instans kelulusan.   - Panggil API [Cipta instans kelulusan](/ms/open/development/create-an-approval-instance) untuk mendapatkan nilai parameter `InstanceId`. - Panggil API [Dapatkan senarai ID instans kelulusan](/ms/open/development/obtain-an-approval-list-of-instance-ids) untuk mendapatkan nilai parameter `list`. |
| fileId | String | Ya | fileId fail. Panggil API [Dapatkan butiran satu instans kelulusan](/ms/open/development/obtains-the-details-of-a-single-approval-instance-pop) untuk mendapatkan nilai parameter `fileId`.      ID fail ialah fileId bagi fail yang dimuat naik dalam komponen kelulusan. Pautan muat turun belum disokong untuk lampiran yang dimuat naik dalam komen. |
| withCommentAttatchment | Boolean | Tidak | Menentukan sama ada lampiran dalam komen turut disertakan. Secara lalai, lampiran dalam komen diabaikan. |

## Respons

### Isi respons

| Nama | Jenis | Penerangan |
| --- | --- | --- |
| result | Object | Hasil yang dikembalikan. |
| spaceId | Long | ID ruang Drive. |
| fileId | String | ID fail. |
| downloadUri | String | URL muat turun fail.      URL muat turun sah selama 15 minit. |
| success | Boolean | Menunjukkan sama ada panggilan API berjaya.   - **true**: Berjaya - **false**: Gagal |

### Contoh isi respons

```text
HTTP/1.1 200 OK
Content-Type:application/json

{
  "result" : {
    "spaceId" : 3996960664,
    "fileId" : "26748422566",
    "downloadUri" : "http://lippi-space-zjk.oss-cn-zhangjiakou.aliyuncs.com/xxxxx"
  },
  "success" : true
}
```
