Panggil API ini untuk memadam pengguna daripada senarai sekat tempahan bilik.

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/v1.0/rooms/bookings/blacklist/remove |
| Kaedah HTTP | POST |
| Jenis aplikasi yang disokong | appType-Internal app　appType-Third-party enterprise app |
| Kebenaran | permission-VideoConference.Conference.Write-Video Meeting information management permission |

### Header permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kelayakan akses yang digunakan untuk memanggil API ini. Dapatkan seperti berikut:   - Untuk aplikasi dalaman, panggil API [Dapatkan access token aplikasi dalaman](/open/development/obtain-the-access-token-of-an-internal-app#). - Untuk aplikasi perusahaan pihak ketiga, panggil API [Dapatkan access token organisasi yang dibenarkan untuk aplikasi pihak ketiga](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#). |

### Isi permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| blacklistUnionIds | Array of String | Tidak | unionId bagi pengguna dalam senarai sekat. Bilangan unionId tidak boleh melebihi 100. |
| unionId | String | Tidak | unionId bagi operator. |

### Contoh permintaan

HTTP

```http
POST /v1.0/rooms/bookings/blacklist/remove HTTP/1.1
Host:api.dingtalk.io
x-acs-dingtalk-access-token:xxxxx
Content-Type:application/json

{
  "blacklistUnionIds" : [ "2iPOLxxxxx" ],
  "unionId" : "2iPOLxxxxx"
}
```
