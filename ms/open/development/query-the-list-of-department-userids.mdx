# Dapatkan senarai ID pengguna sesuatu jabatan

## Penerangan panggilan API

- API ini tidak dihadkan oleh skop kebenaran Kenalan.
- **Mendapatkan ID pengguna semua pekerja dalam organisasi Anda sekali gus tidak disokong.** Untuk mendapatkan ID pengguna semua pekerja dalam organisasi Anda, gunakan kaedah berikut:

  - Panggil API [Get department list](/open/development/user-management-acquires-the-list-departments) dan lintasi peringkat demi peringkat untuk mendapatkan semua ID jabatan dalam skop yang dibenarkan.
  - Panggil API yang diterangkan dalam dokumen ini untuk mendapatkan ID pengguna pekerja dalam setiap jabatan.

## Permintaan

| **Maklumat asas** | |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/topapi/user/listid |
| Kaedah HTTP | POST |
| Jenis aplikasi yang disokong | appType-Aplikasi dalaman, appType-Aplikasi perusahaan pihak ketiga |
| Kebenaran diperlukan | permission-qyapi_get_member-Baca maklumat pengguna |

### Parameter pertanyaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | bE74xxxx | Kelayakan aplikasi yang digunakan untuk memanggil API ini.   - Bagi aplikasi dalaman, dapatkan melalui API untuk mendapatkan [access_token aplikasi dalaman](/open/development/obtain-orgapp-token). - Bagi aplikasi perusahaan pihak ketiga, dapatkan melalui API untuk mendapatkan access_token perusahaan pihak ketiga. |

### Isi permintaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| dept_id | Nombor | Ya | 100 | deptId bagi jabatan tersebut. Anda boleh memanggil [Get department list](/open/development/user-management-acquires-the-list-departments) untuk mendapatkan deptId.  **Nota**  Bagi jabatan root, tetapkan parameter ini kepada 1. |

### Contoh permintaan

```curl
curl -X POST "https://api.dingtalk.io/topapi/user/listid" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=03987655-598f-4f7a-8fc3-aaf257c47c27' \
-d 'dept_id=100'
```

Java

```text
DingTalkClient client = new DefaultDingTalkClient("https://api.dingtalk.io/topapi/user/listid");
OapiUserListidRequest req = new OapiUserListidRequest();
req.setDeptId(100L);
OapiUserListidResponse rsp = client.execute(req, access_token);
System.out.println(rsp.getBody());
```

Python

```python
import dingtalk.api

req=dingtalk.api.OapiUserListidRequest("https://api.dingtalk.io/topapi/user/listid")

req.dept_id=100
try:
  resp= req.getResponse(access_token)
  print(resp)
except Exception,e:
  print(e)
```

PHP

```php
include "TopSdk.php";
date_default_timezone_set('Asia/Shanghai');

$c = new DingTalkClient(DingTalkConstant::$CALL_TYPE_OAPI, DingTalkConstant::$METHOD_POST , DingTalkConstant::$FORMAT_JSON);
$req = new OapiUserListidRequest;
$req->setDeptId("100");
$resp = $c->execute($req, $access_token, "https://api.dingtalk.io/topapi/user/listid");
```

C#

```text
IDingTalkClient client = new DefaultDingTalkClient("https://api.dingtalk.io/topapi/user/listid");
OapiUserListidRequest req = new OapiUserListidRequest();
req.DeptId = 100L;
OapiUserListidResponse rsp = client.Execute(req, access_token);
Console.WriteLine(rsp.Body);
```

## Respons

### Isi respons

| Nama | Jenis | Contoh | Penerangan |
| --- | --- | --- | --- |
| request_id | String | 4f9kasjdhop | ID permintaan. |
| errcode | Nombor | 0 | Kod pemulangan. |
| errmsg | String | ok | Penerangan bagi kod pemulangan. |
| result | ListUserByDeptResponse |  | Hasil respons. |
| userid_list | String[] | ["zxxxx","lixxxi"] | Senarai ID pengguna bagi jabatan yang dinyatakan. |

### Contoh respons

```json
{
  "errcode": 0,
  "errmsg":"ok",
  "result": {
    "userid_list": [
      "usxxx",
      "manager4xxx",
      "10203029011xxxx",
      "usexxx"
    ]
  },
  "request_id": "3naksldjh0dk"
}
```

### Kod ralat

Jika berlaku ralat semasa Anda memanggil API ini, rujuk dokumen [Global error codes](/open/development/server-api-error-codes-1) untuk mencari penyelesaian berdasarkan mesej ralat.

| Kod ralat (errcode) | Mesej ralat (errmsg) | Penyelesaian |
| --- | --- | --- |
| 60003 | Department not found | Sahkan bahawa dept_id adalah betul. |
| 400002 | Invalid parameter | Sahkan bahawa parameter adalah sah. |
| -1 | System busy | Cuba Lagi kemudian. |
