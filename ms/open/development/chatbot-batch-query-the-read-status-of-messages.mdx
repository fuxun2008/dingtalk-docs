---

Panggil API ini untuk batch query status baca mesej Bot yang dihantar dalam perbualan satu-lawan-satu antara pengguna dan Bot. Ini berguna untuk senario komunikasi dalaman apabila anda perlu mengesahkan sama ada sesuatu mesej telah dibaca dalam tempoh 24 jam.

## Penerangan panggilan API

- Anda boleh query status baca untuk sehingga 20 penerima bagi satu mesej perbualan satu-lawan-satu pada satu masa.
- Jika anda menghantar permintaan HTTP secara langsung, URL-encode parameter `processQueryKey` terlebih dahulu, kemudian tambahkan nilai yang telah di-encode pada URL.

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/v1.0/robot/oToMessages/readStatus |
| HTTP Method | GET |
| Jenis aplikasi disokong | appType-Aplikasi dalaman　appType-Aplikasi perusahaan pihak ketiga |
| Kebenaran diperlukan | permission-qyapi_robot_sendmsg-Kebenaran untuk menghantar mesej daripada Bot dalam organisasi anda |

### Header permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses yang digunakan untuk memanggil API ini. Perolehinya seperti berikut:   - Untuk aplikasi dalaman, panggil API [Get the access token of an internal app](/open/development/obtain-the-access-token-of-an-internal-app#). - Untuk aplikasi perusahaan pihak ketiga, panggil API [Get the access token of an authorized enterprise for a third-party app](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#). |

### Parameter query

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| robotCode | String | Ya | Kod Bot. Untuk maklumat lanjut, lihat [Bot ID](/open/development/development-robot-overview#447ec33014hrl). |
| processQueryKey | String | Ya | Pengecam unik mesej. Anda boleh perolehinya daripada medan `processQueryKey` yang dikembalikan oleh API [Batch send bot messages in one-on-one chats](/open/development/chatbots-send-one-on-one-chat-messages-in-batches#).    Anda boleh query status baca menggunakan `processQueryKey` dalam tempoh 24 jam selepas mesej dihantar. Query tidak disokong selepas 24 jam. |

### Contoh permintaan

Host:api.dingtalk.io

Content-Type:application/json

| messageReadInfoList | Array | Status baca mesej. |
| name | String | Nama penerima mesej. |
| userId | String | userId penerima mesej. |

| readTimestamp | Long | Belum disokong buat masa ini. |
