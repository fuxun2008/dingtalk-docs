Topik ini menerangkan jenis mesej dan format data yang disokong oleh Bot untuk menghantar mesej, serta format data untuk mesej yang diterima oleh Bot.

## Hantar mesej dengan Bot

### Jenis mesej

Anda boleh menghantar Mesej Bot melalui dua cara: dengan **memanggil API** atau menggunakan **Webhook**. Jenis mesej dan format data yang disokong berbeza mengikut kaedah.

<Note>
Kami mengesyorkan anda menghantar mesej dengan memanggil API.
</Note>

| Jenis mesej | Hantar melalui API | Hantar melalui Webhook |
| --- | --- | --- |
| Teks | ✅ | ✅ |
| Markdown | ✅ | ✅ |
| Gambar | ✅ | ❌ |
| ActionCard | ✅ | ✅ |
| FeedCard | ❌ | ✅ |
| Link | ✅ | ✅ |
| Audio | ✅ | ❌ |
| Fail | ✅ | ❌ |
| Video | ✅ | ❌ |

### Kaedah 1: Panggil API

### Penting

- Mesej Bot dalam sembang Mesej Terus antara pengguna dan Bot: menyokong **penghantaran dan penerimaan** gambar, mesej suara, dan fail.
- Mesej Bot dalam Sembang Kumpulan: Bot boleh **menghantar** gambar, mesej suara, video, dan fail. **Walau bagaimanapun, pengguna tidak boleh @ Bot untuk menghantar mesej suara, video, atau fail kepadanya dalam Sembang Kumpulan.**

#### API yang tersedia

- [Hantar mesej Mesej Terus dalam kelompok](/open/development/chatbots-send-one-on-one-chat-messages-in-batches)
- [Hantar mesej Sembang Kumpulan dengan Bot](/open/development/the-robot-sends-a-group-message)

#### Format data

- **Kunci templat mesej**: pengecam unik yang digunakan apabila pembangun menghantar mesej. Ia membolehkan kod merujuk dengan pantas kepada templat mesej yang telah ditetapkan.
- **Parameter templat mesej**: data sebenar yang digunakan untuk menggantikan placeholder yang telah ditetapkan dalam templat mesej. Contohnya, apabila kunci templat mesej ialah `sampleText`, anda perlu menetapkan nilai medan `content`.
- **Contoh**: contoh HTTP berikut menunjukkan cara Bot aplikasi dalaman menghantar mesej **teks** kepada **kumpulan**:

  - Kunci templat mesej: `"msgKey" : "sampleText"`
  - Parameter templat mesej: `"msgParam" : "{\"content\":\"DingTalk, where progress happens\"}"`

Untuk maklumat lanjut, lihat [Hantar mesej Sembang Kumpulan dengan Bot](/open/development/the-robot-sends-a-group-message).

```http
POST /v1.0/robot/groupMessages/send HTTP/1.1
Host:api.dingtalk.io
x-acs-dingtalk-access-token:<your access token>
Content-Type:application/json

{
  "msgParam" : "{\"content\":\"DingTalk, where progress happens\"}",
  "msgKey" : "sampleText",
  "openConversationId" : "cid6KeBBLov********",
  "robotCode" : "dingue4kfzdxbyn*******"
}
```

### Kaedah 2: Gunakan Webhook

<Note>
Webhook hanya disokong dalam Sembang Kumpulan.
</Note>

Untuk maklumat mengenai penghantaran mesej melalui Webhook, lihat [Balasan Bot dan hantar mesej](/open/dingstart/robot-reply-and-send-messages) dan [Cipta Bot tersuai](/open/dingstart/custom-bot-creation-and-installation).

#### Mesej teks

```json
{
    "at": {
        "atMobiles": [
            "180xxxxxx"
        ],
        "atUserIds": [
            "user123"
        ],
        "isAtAll": false
    },
    "text": {
        "content": "Saya adalah diri saya, @180xxxxxx adalah percikan yang berbeza"
    },
    "msgtype": "text"
}
```

| **Parameter** | **Wajib** | **Jenis** | **Keterangan** |
| --- | --- | --- | --- |
| msgtype | Ya | String | text. |
| content | Ya | String | Teks mesej. |
| atMobiles | Tidak | Array | Nombor telefon bimbit pengguna yang hendak di-@.  **Nota**  Tambah nombor telefon bimbit pengguna yang hendak di-@ dalam `content`. Hanya ahli kumpulan boleh di-@. Nombor telefon bimbit bukan ahli akan disamarkan. |
| atUserIds | Tidak | Array | ID pengguna bagi pengguna yang hendak di-@.  **Nota**  Tambah ID pengguna bagi pengguna yang hendak di-@ dalam `content`. |
| isAtAll | Tidak | Boolean | Tetapkan ke true untuk @ semua orang; jika tidak, tetapkan ke false. |

## Terima mesej dengan Bot

Apabila pengguna @ Bot kumpulan atau menghantar Mesej Terus kepada Bot, DingTalk menghantar mesej yang diterima ke perkhidmatan callback Bot yang dikonfigurasikan oleh pembangun.

Contoh berikut menggunakan jenis mesej teks. Jika anda menggunakan callback HTTP, DingTalk menyampaikan mesej dengan permintaan POST.

```json
  "conversationId": "cid6EUxxxxsg==",
  "atUsers": [
    {
      "dingtalkId": "xxx",
      "staffId":"xxx",
      "unionId":"edxxx34"
    }
  ],
  "chatbotCorpId": "ding9733d095*******6cb783455b",
  "chatbotUserId": "$:LWCP_xxxxr5",
  "msgId": "msgrK2xxxxU+riw==",
  "senderNick": "Xiao Ding",
  "isAdmin": true,
  "senderStaffId": "0147xxxx8602",
  "sessionWebhookExpiredTime": 1708332604316,
  "createAt": 1708327204136,
  "senderCorpId": "ding9733d095*******6cb783455b",
  "conversationType": "2",
  "senderId": "$:LWCP_v1xxxxBv1MhAv9",
  "conversationTitle": "Kumpulan Uji",
  "isInAtList": true,
  "sessionWebhook": "https://oapi.dingtalk.io/robot/sendBySession?session=66d7c695a9xxxxdeb885",
  "text": {
    "content": " text"
  },

```

| **Parameter** | **Jenis** | **Keterangan** |
| --- | --- | --- |
| senderPlatform | String | Platform dari mana mesej dihantar. |
| conversationId | String | ID Sembang. |
| atUsers | Array of Object | Maklumat tentang pengguna yang di-@.   - **dingtalkId**: ID disulitkan bagi pengguna yang di-@. - **staffId**: ID pengguna bagi pengguna yang di-@. Medan ini kosong untuk Pengguna luaran dalam Sembang Luaran. - **unionId**: unionId bagi pengguna yang di-@. |
| chatbotCorpId | String | ID Organisasi disulitkan bagi organisasi yang memiliki Bot. |
| chatbotUserId | String | ID Bot disulitkan. |
| msgId | String | ID mesej disulitkan. |
| senderNick | String | Nama penghantar. |
| isAdmin | Boolean | Sama ada penghantar ialah Admin:   - true: ya - false: tidak   Berkuat kuasa selepas Bot diterbitkan. Jika tidak, medan ini tidak dikembalikan. |
| senderStaffId | String | ID pengguna bagi ahli yang @ Bot dalam Kumpulan Dalaman. Jika tidak, medan ini tidak dikembalikan. |
| senderUnionId | String | unionId bagi penghantar. |
| sessionWebhookExpiredTime | Long | Masa tamat tempoh URL Webhook bagi perbualan semasa. |

| senderCorpId | String | ID Organisasi bagi penghantar dalam Kumpulan Dalaman. |
| conversationType | String | Jenis perbualan:   - **1**: Mesej Terus - **2**: Sembang Kumpulan |
| senderId | String | ID penghantar disulitkan. |
| conversationTitle | String | Tajuk perbualan. Hanya tersedia dalam Sembang Kumpulan. |
| isInAtList | Boolean | Sama ada Bot berada dalam senarai @. |
| sessionWebhook | String | URL Webhook bagi perbualan semasa. |
| text | Object | Teks mesej:   - content: kandungan mesej yang diterima oleh Bot.   Medan ini hanya wujud apabila jenis mesej ialah text. |
| msgtype | String | Jenis mesej:   - text: Mesej teks - richText: Mesej Teks Kaya - picture: Mesej gambar - audio: Mesej suara - video: Mesej video - file: Mesej fail   Untuk format khusus bagi setiap jenis, lihat **Jenis mesej** di bawah. |
| robotCode | String | Kod Bot.  Bot tersuai tidak mempunyai robotCode. |

### Jenis mesej

Bot pada masa ini boleh menerima mesej daripada jenis berikut: teks, suara, gambar, fail, video, dan Teks Kaya. Medan bagi setiap jenis mesej diterangkan di bawah. Selain daripada medan jenis mesej dan Kandungan Mel, parameternya adalah sama seperti dalam jadual di atas.

#### Mesej teks

```json
{
  "msgtype": "text",
  "text": {
    "content": "Hello"
  }
}
```

| **Parameter** | **Jenis** | **Keterangan** |
| --- | --- | --- |
| msgtype | String | Jenis mesej:   - **text**: Mesej teks |
| text | Object | Teks mesej:   - **content**: kandungan mesej yang diterima oleh Bot. |

#### Mesej Teks Kaya

```json
{
  "msgtype": "richText",
  "content": {
    "richText": [
      {
        "text": "Hello"
      },
      {
        "downloadCode": "mIofN681YE3f*************JkVBG2vhj4Q9、d2tn/t6XxjaB6UxxxxOVnYYbn1aMT/n3JFgb4i64X3TFxxxxGWxJPR/egKS8syvGzxxxxOO/FYLor2Q==",
        "type": "picture"
      }
    ]
  }
}
```

| Nama | Jenis | Keterangan |
| --- | --- | --- |
| msgtype | String | Jenis mesej:   - **richText**: Teks Kaya |
| content | Object | Kandungan mesej. |
| richText | Array of Object | Senarai Teks Kaya.  **Nota**  Senarai mesej boleh mengandungi:   - **text**: Mesej teks - **picture**: Mesej gambar  Gunakan downloadCode gambar untuk mendapatkan URL muat turun sementara dengan memanggil Server API [Muat turun kandungan fail bagi mesej yang diterima oleh Bot](/open/development/download-the-file-content-of-the-robot-receiving-message). |

#### Mesej gambar

```json
{
```

### Kandungan berkaitan

Jika anda memilih mod HTTP sebagai mod penerimaan mesej semasa [mencipta Bot aplikasi dalaman](/open/dingstart/configure-the-robot-application), parameter header HTTP yang ditunjukkan di bawah disertakan bersama Kandungan Mel apabila Bot menerima mesej:

```json
{
  "Content-Type": "application/json; charset=utf-8",
  "timestamp": "1577262236757",
  "sign":"xxxxxxxxxx"
}
```

| **Parameter** | **Keterangan** |
| --- | --- |
| timestamp | Cap masa apabila mesej dihantar, dalam milisaat. |
| sign | Nilai Tandatangan. |

Anda mesti mengesahkan timestamp dan sign dalam header untuk mengesahkan bahawa permintaan tersebut adalah permintaan sah daripada DingTalk dan mencegah pihak ketiga daripada menyamar sebagai DingTalk untuk memanggil perkhidmatan HTTPS anda. Peraturan pengesahan adalah seperti berikut:

- Jika perbezaan antara timestamp dan cap masa sistem semasa melebihi 1 jam, permintaan tersebut dianggap tidak sah.
- Jika sign tidak sepadan dengan nilai Tandatangan yang anda kira, permintaan tersebut dianggap tidak sah.

Permintaan hanya dianggap sah apabila kedua-dua timestamp dan sign lulus pengesahan.

Gunakan algoritma HmacSHA256 untuk mengira Tandatangan, kemudian kodkan dengan Base64 untuk mendapatkan nilai Tandatangan akhir. Contoh:

```java
import javax.crypto.Mac;
import javax.crypto.spec.SecretKeySpec;
import org.apache.commons.codec.binary.Base64;

public class Test {
    public static void main(String[] args) throws Exception {
        Long timestamp = 1577262236757L;
        String appSecret = "this is a secret";
        String stringToSign = timestamp + "\n" + appSecret;
        Mac mac = Mac.getInstance("HmacSHA256");
        mac.init(new SecretKeySpec(appSecret.getBytes("UTF-8"), "HmacSHA256"));
        byte[] signData = mac.doFinal(stringToSign.getBytes("UTF-8"));
        String sign = new String(Base64.encodeBase64(signData));
        System.out.println(sign);
    }
}
```

| **Item konfigurasi** | **Keterangan** |
| --- | --- |
| timestamp | Cap masa semasa, dalam milisaat. |
| appSecret | Client Secret bagi aplikasi tersebut. Untuk maklumat lanjut, lihat [Client Secret](/open/dingstart/basic-concepts-beta). |
