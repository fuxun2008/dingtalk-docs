Panggil API ini untuk menyisipkan elemen sekat pada lokasi yang ditentukan.

## Penerangan panggilan API

Untuk mengetahui struktur data yang berkaitan dengan kandungan dokumen, lihat [Struktur data dokumen](/ms/open/development/document-data-structure).

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/doc/suites/documents/{docKey}/blocks` |
| Kaedah HTTP | POST |
| Jenis aplikasi disokong | appType-Aplikasi dalaman |
| Kebenaran diperlukan | permission-Storage.File.Write-Kebenaran tulis fail storan organisasi |

### Pengepala permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Dapatkan dengan memanggil API [Dapatkan access token aplikasi dalaman](/ms/open/development/obtain-the-access-token-of-an-internal-app). |

### Parameter laluan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| docKey | String | Ya | ID Dokumen (`docKey` atau `dentryUuid` dokumen). Selepas mencipta dokumen dengan memanggil API [Cipta dokumen Knowledge Base](/ms/open/development/create-team-space-document), dapatkan parameter `docKey` daripada respons. Untuk mendapatkan `dentryUuid` daripada URL dokumen, ambil https://docs.dingtalk.io/i/nodes/Zxxxxa-id sebagai contoh. `dentryUuid` ialah `Zxxxxa-id`. |

### Parameter pertanyaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| operatorId | String | Ya | unionId pengguna. Dapatkan parameter `unionid` dengan memanggil API [Tanya butiran pengguna](/ms/open/development/query-user-details). |

### Isi permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| blockId | String | Tidak | Pengecam unik bagi sekat sasaran. Dapatkan parameter `blockId` dengan memanggil API [Tanya elemen sekat](/ms/open/development/api-docblocksquery). Jika tidak dinyatakan, nilai `index` akan digunakan. |
| index | Integer | Tidak | Apabila `blockId` tidak diberikan, `index` digunakan untuk menentukan lokasi sekat sasaran. Sistem cuba mencari sekat pada kedudukan `index` dalam kalangan elemen sekat peringkat pertama dokumen, dengan `index` bermula daripada 0. Jika tidak dinyatakan, penghujung dokumen digunakan secara lalai. |
| where | String | Tidak | Sama ada hendak menyisip sebelum atau selepas lokasi sasaran. Nilai sah: - **after**: Sisip selepas lokasi sasaran. Ini ialah nilai lalai. - **before**: Sisip sebelum lokasi sasaran. |
| element | `Map<String, Any>` | Ya | Jenis BlockElement yang hendak disisip dan atribut yang diperlukan untuk mencipta jenis berkaitan (lihat [Struktur data elemen sekat](/ms/open/development/block-data-structure) untuk butiran). Strukturnya adalah seperti berikut: ``` {   "blockType": enum(BlockType),   [blockType]: Object(CreateElementProperties), } ``` |
|  | Any | Tidak | Mengandungi jenis elemen dan maklumat yang diperlukan untuk mencipta elemen tersebut. |

### Contoh permintaan

HTTP

```http
POST /v1.0/doc/suites/documents/doc_id/blocks?operatorId=union_id HTTP/1.1
Host:api.dingtalk.io
x-acs-dingtalk-access-token:7dc9ec4xxx
Content-Type:application/json

{
  "blockId" : "block_id",
  "index" : 1,
  "where" : "after",
  "element" : {
    "blockType" : "paragraph",
    "paragraph" : {
      "text" : "foo"
    }
  }
}
```

## Respons

### Isi respons

| Nama | Jenis | Penerangan |
| --- | --- | --- |
| success | Boolean | Sama ada permintaan berjaya. |
| result | Object | Hasil permintaan. |
| data | `Map<String, Any>` | Elemen yang disisip. |
|  | Any | Butiran mengenai elemen tersebut. |

### Contoh isi respons

```text
HTTP/1.1 200 OK
Content-Type:application/json

{
  "success": true,
  "result": {
    "data": {
      "blockType": "paragraph",
      "paragraph": {
        "text": "foo"
      },
      "id": "lmoasis2f3wxmwyyyy",
      "index": 2,
    }
  }
}
```

### Kod ralat

Jika ralat dikembalikan semasa anda memanggil API ini, cari penyelesaiannya dalam dokumentasi [Kod ralat global](/ms/open/development/server-api-error-codes-1) berdasarkan mesej ralat.

| HttpCode | Kod ralat | Mesej ralat | Penerangan |
| --- | --- | --- | --- |
| 400 | paramError | %s | Ralat parameter. |
| 400 | invalidRequest.inputArgs.invalid | %s | Ralat parameter. Rujuk mesej ralat untuk butiran lanjut. |
| 403 | forbidden.accessDenied | %s | Tiada kebenaran. |
| 403 | forbidden.acrossOrg | %s | Permintaan tidak sah. Semak sama ada dokumen yang anda cuba akses adalah milik organisasi yang dinyatakan oleh access token. |
| 404 | docNotExist | %s | Dokumen tidak wujud. |
| 404 | invalidRequest.resource.notFound | %s | Sumber yang diminta tidak dapat dijumpai. |
| 500 | forbidden.operationIllegal | %s | Operasi yang diminta tidak sah. |
| 500 | systemError | %s | Perkhidmatan sedang sibuk. Cuba lagi kemudian. |
| 500 | unknownError | Unknown Error | Ralat tidak diketahui. |
| 503 | operationTimeout | %s | Permintaan tamat masa. |
