Panggil API ini untuk mendapatkan senarai nod.

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/v2.0/wiki/nodes |
| Kaedah HTTP | GET |
| Jenis aplikasi disokong | appType-Aplikasi dalaman　appType-Aplikasi perusahaan pihak ketiga |
| Kebenaran diperlukan | permission-Wiki.Node.Read-Kebenaran baca nod Knowledge Base |

### Header permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Dapatkan melalui salah satu cara berikut:   - Untuk aplikasi dalaman, panggil API [Dapatkan access token aplikasi dalaman](/ms/open/development/obtain-the-access-token-of-an-internal-app#). - Untuk aplikasi perusahaan pihak ketiga, panggil API [Dapatkan access token perusahaan yang diberi kuasa untuk aplikasi pihak ketiga](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#). |

### Parameter kueri

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| parentNodeId | String | Ya | ID nod induk (dentryUuid nod induk). Dapatkan daripada medan `rootNodeId` yang dikembalikan oleh API [Dapatkan senarai knowledge base](/ms/open/development/get-knowledge-base-list#). |
| nextToken | String | Tidak | Cursor pagination. Biarkan kosong untuk permintaan pertama. |
| maxResults | Integer | Tidak | Saiz halaman. Lalai: 50. Maksimum: 50. |
| withPermissionRole | Boolean | Tidak | Sama ada untuk mengembalikan maklumat kebenaran:   - true: Kembalikan kebenaran. - false: Jangan kembalikan kebenaran.     Lalai: false. |
| operatorId | String | Ya | unionId pengendali. |

## Respons

### Isi respons

| Nama | Jenis | Penerangan |
| --- | --- | --- |
| nodes | Array | Senarai nod. Saiz maksimum: 50. |
| nodeId | String | ID nod (dentryUuid). |
| workspaceId | String | ID knowledge base (spaceUuid). |
| name | String | Nama. |
| size | Long | Saiz. |
| type | String | Jenis. Nilai enum:   - **FILE**: Fail - **FOLDER**: Folder |
| category | String | Kategori. Nilai enum:   - **ALIDOC**: DingTalk Docs - **DOCUMENT**: Dokumen tempatan - **IMAGE**: Gambar - **VIDEO**: Video - **AUDIO**: Audio - **ARCHIVE**: Fail arkib - **OTHER**: Jenis lain |
| extension | String | Sambungan fail. |
| url | String | URL akses. |
| creatorId | String | userId pencipta. |
| modifierId | String | userId pengubah suai terakhir. |
| createTime | String | Masa dicipta. |
| modifiedTime | String | Masa pengubahsuaian. |
| hasChildren | Boolean | Sama ada nod mempunyai nod anak:   - **true**: Ya - **false**: Tidak |
| statisticalInfo | Object | Maklumat statistik. |
| wordCount | Long | Kiraan perkataan. |
| permissionRole | String | Peranan kebenaran pengguna semasa pada nod knowledge base. Nilai enum:   - **OWNER**: Pemilik - **MANAGER**: Pengurus - **EDITOR**: Editor - **DOWNLOADER**: Pemapar dengan kebenaran muat turun - **READER**: Hanya lihat - **NONE**: Tiada kebenaran |
| nextToken | String | Cursor pagination. Nilai bukan kosong menunjukkan terdapat lebih banyak data. |
