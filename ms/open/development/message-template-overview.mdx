Templat mesej ialah peningkatan kepada Push mesej melalui Notifikasi Kerja. Ia menyediakan pengalaman pembangunan dan konfigurasi yang lebih ringkas dan piawai untuk templat mesej, sambil menawarkan keupayaan pemberitahuan mesej yang lebih selamat, boleh diurus, dan boleh dikawal di pihak pelanggan.

**Penting**

Apabila menggunakan templat mesej, ambil perhatian perkara berikut:

- Hanya **Aplikasi perusahaan pihak ketiga** disokong.
- Hanya templat mesej yang telah diluluskan boleh digunakan untuk Push mesej Notifikasi Kerja.

## Jenis Templat

Tiga jenis templat mesej berikut disokong pada masa ini.

- Templat Markdown

  Templat Markdown menggunakan sintaks Markdown untuk mengkonfigurasikan dan menghantar mesej. Ia sesuai untuk jenis mesej pemberitahuan tulen yang tidak memerlukan sebarang tindakan. Templat Markdown memudahkan sokongan format paparan seperti teks, imej, dan pautan.
- Templat ActionCard

  Templat ActionCard menghantar mesej menggunakan jenis mesej ActionCard. Ia menyokong mesej yang menggabungkan kandungan dan titik tindakan, dan sesuai untuk senario yang memerlukan satu atau lebih titik tindakan untuk mengendalikan tugas dengan cepat dalam sesuatu mesej.

  Berdasarkan templat Markdown, templat ActionCard menyokong kedua-dua gaya lompat keseluruhan dan lompat bebas.
- Templat Borang

  Templat Borang menghantar mesej berdasarkan jenis mesej OA. Ia sesuai untuk memaparkan mesej seperti pesanan dan menyokong lompat untuk paparan butiran mesej.

## Proses Penggunaan

Seperti yang ditunjukkan dalam rajah berikut, menghantar Notifikasi Kerja dengan templat mesej memerlukan tindakan berikut:

1. Cipta dan konfigurasikan templat mesej. Untuk butiran lanjut, lihat [Urus Templat Mesej](/zh/open/development/manage-message-templates).
2. Hantar templat untuk disemak.
3. Panggil API untuk menghantar Notifikasi Kerja menggunakan templat. Untuk butiran lanjut, lihat [Hantar Mesej Notifikasi Kerja Menggunakan Templat](/zh/open/development/work-notification-templating-send-notification-interface).
