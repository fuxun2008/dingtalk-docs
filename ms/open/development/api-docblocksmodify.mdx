Panggil API ini untuk mengemas kini kandungan atau atribut mana-mana elemen sekat tunggal dalam dokumen.

## Penerangan panggilan API

- Ini pada dasarnya adalah operasi PATCH (bukan idempoten). Hanya medan yang dihantar akan dikemas kini; medan yang tidak dihantar akan kekal tidak berubah.
- Buat masa ini, hanya elemen sekat jenis perenggan yang boleh dikemas kini.

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/doc/suites/documents/{documentId}/blocks/{blockId}` |
| Kaedah HTTP | PUT |
| Jenis aplikasi disokong | appType-Aplikasi dalaman |
| Kebenaran diperlukan | permission-Storage.File.Write-Kebenaran tulis fail storan organisasi |

### Pengepala permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses yang digunakan untuk memanggil API ini. Dapatkan dengan memanggil API [Dapatkan access token aplikasi dalaman](/ms/open/development/obtain-the-access-token-of-an-internal-app). |

### Parameter laluan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| documentId | String | Ya | ID Dokumen (`docKey` atau `dentryUuid` dokumen). Selepas mencipta dokumen dengan memanggil API [Cipta dokumen Knowledge Base ruang pasukan](/ms/open/development/create-team-space-document), dapatkan parameter `docKey` daripada respons. Untuk mendapatkan `dentryUuid` daripada URL dokumen, ambil https://docs.dingtalk.io/i/nodes/Zxxxxa-id sebagai contoh, di mana `dentryUuid` ialah Zxxxxa-id. |
| blockId | String | Ya | Pengecam unik bagi perenggan sasaran. Dapatkan parameter `blockId` bagi perenggan ini dengan memanggil API [Pertanyaan elemen sekat](/ms/open/development/api-docblocksquery). |

### Parameter pertanyaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| operatorId | String | Ya | unionId pengguna. Dapatkan nilai parameter unionid dengan memanggil API [Pertanyaan butiran pengguna](/ms/open/development/query-user-details). |

### Isi permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| element | `Map<String, Any>` | Ya | Jenis BlockElement bagi elemen sekat yang hendak dikemas kini serta atribut yang diperlukan untuk jenis berkaitan (lihat [Struktur data elemen sekat](/ms/open/development/block-data-structure) untuk butiran). Strukturnya adalah seperti berikut:   ``` {   "blockType": enum(BlockType),   [blockType]: Object(ElementProperties), } ``` |
|  | Any | Tidak | Atribut elemen sekat yang hendak dikemas kini. |

### Contoh permintaan

HTTP

```http
PUT /v1.0/doc/suites/documents/doc_id/blocks/block_id?operatorId=union_id HTTP/1.1
Host:api.dingtalk.io
x-acs-dingtalk-access-token:access_token
Content-Type:application/json

{
  "element" : {
    "blockType" : "paragraph",
    "paragraph" : {
      "folded": true
    }
  }
}
```
