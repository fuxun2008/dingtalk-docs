---
title: "Tanya senarai ahli kehadiran"
description: "Gunakan API DingTalk ini untuk menyemak senarai ahli kehadiran dalam kumpulan kehadiran tertentu secara berhalaman berdasarkan group_key — sesuai untuk penyegerakan data pekerja."
---

Panggil API ini untuk menyemak pekerja yang merupakan ahli kehadiran bagi kumpulan kehadiran tertentu berdasarkan groupKey kumpulan kehadiran tersebut. Jika jabatan dikonfigurasi sebagai ahli kehadiran, API ini tidak dapat mengembalikan ID jabatan.

## Permintaan

| **Maklumat asas** | |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/topapi/attendance/group/users/query |
| Kaedah HTTP | POST |
| Jenis aplikasi yang disokong | appType-Aplikasi dalaman |
| Kebenaran yang diperlukan | permission-qyapi_attendance_group_read-Kebenaran pertanyaan kumpulan kehadiran |

### Parameter pertanyaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | 4c9ebd2b1534xxxx | Kelayakan aplikasi yang digunakan untuk memanggil API ini. Dapatkannya dengan memanggil API [Dapatkan access_token Aplikasi dalaman](/ms/open/development/obtain-orgapp-token). |

### Isi permintaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| size | Number | Tidak | 50 | Saiz halaman. |
| cursor | String | Ya | 10 | ID pengguna terakhir daripada kelompok sebelumnya. Hantar null atau nilai kosong untuk memulakan pertanyaan dari awal. |
| op_userid | String | Tidak | user01 | ID pengguna bagi pengendali. |
| group_key | String | Ya | CEDDFFxxxx | ID kumpulan kehadiran.  **Nota**  Jika pengecam kumpulan kehadiran anda ialah group_id, panggil API [Tukar groupId kepada groupKey](/ms/open/development/groupid-to-groupkey) untuk menukar group_id kepada group_key. |

### Contoh permintaan

```curl
curl -X POST "https://api.dingtalk.io/topapi/attendance/group/users/query" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=d2ee6exxxx9266c' \
-d 'cursor=%5C%22%5C%22' \
-d 'group_key=0151Exxxx17E876' \
-d 'op_userid=123456' \
-d 'size=50'
```

Java

```java
DingTalkClient client = new DefaultDingTalkClient("https://api.dingtalk.io/topapi/attendance/group/users/query");
OapiAttendanceGroupUsersQueryRequest req = new OapiAttendanceGroupUsersQueryRequest();
req.setSize(50L);
req.setCursor("10");
req.setOpUserid("user01");
req.setGroupKey("CEDDFFxxxx");
OapiAttendanceGroupUsersQueryResponse rsp = client.execute(req, access_token);
System.out.println(rsp.getBody());
```

## Respons

### Isi respons

| Nama | Jenis | Contoh | Penerangan |
| --- | --- | --- | --- |
| request_id | String | ntxswpdprw5d | ID permintaan. |
| result | DingOpenResult |  | Hasil yang dikembalikan. |
| result | Result |  | Hasil pertanyaan. |
| user_list | String[] | user01 | Senarai pengguna. |
| has_more | String | false | Menunjukkan sama ada terdapat lebih banyak data.   - **true**: Ya - **false**: Tidak |
| errcode | Number | 0 | Kod pengembalian. |
| errmsg | String | ok | Penerangan kod pengembalian. |
| success | Boolean | true | Menunjukkan sama ada panggilan berjaya.   - **true**: Berjaya - **false**: Gagal |

### Contoh isi respons

```json
{
  "result": {
    "errcode": 0,
    "errmsg":"ok",
    "result": {
      "has_more": "false",
      "user_list": [
        "user01"
      ]
    },
    "success": true
  },
  "request_id": "ntxswpdprw5d"
}
```

### Kod ralat

Jika panggilan API ini mengembalikan ralat, gunakan mesej ralat untuk mencari penyelesaian dalam dokumen [Kod ralat global](/ms/open/development/server-api-error-codes-1).
