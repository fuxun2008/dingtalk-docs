Panggil API ini untuk mendapatkan maklumat muat turun bagi fail dalam ruang storan.

## Penerangan panggilan API

Langkah 1: Panggil API ini untuk mendapatkan maklumat muat turun fail, termasuk URL muat turun dan pengepala.

Langkah 2: Laksanakan muat turun. Lihat contoh berikut:

```java
public static void main(String[] args) {
        String url = ""; // internalResourceUrls yang dikembalikan oleh API dapatkan maklumat muat turun.
        String path = "/Users/xxxxx/Downloads/test.txt"; // Laluan sasaran untuk muat turun fail.
        // Pengepala yang dikembalikan oleh API dapatkan maklumat muat turun.
        Map<String, String> headers = "" // Pengepala yang diperoleh daripada API dapatkan maklumat muat turun.
        OkHttpClient client = new OkHttpClient();
        Request request = new Request.Builder()
                .url(url)
                .headers(Headers.of(headers))
                .build();
        client.newCall(request).enqueue(new Callback() {
            @Override
            public void onFailure(Call call, IOException e) {
            }

            @Override
            public void onResponse(Call call, Response response) throws IOException {
                Sink sink = null;
                BufferedSink bufferedSink = null;
                try {
                    File dest = new File(path);
                    sink = Okio.sink(dest);
                    bufferedSink = Okio.buffer(sink);
                    bufferedSink.writeAll(response.body().source());
                } catch (Exception e) {
                    e.printStackTrace();
                } finally {
                    if (bufferedSink != null) {
                        bufferedSink.close();
                    }
                    if (sink != null) {
                        sink.close();
                    }
                }
            }
        });
    }
```

<Note>
Jika fail terlalu besar dan anda perlu mendapatkannya secara berperingkat, tambah medan headers dalam contoh di atas: `headers.put("Range","bytes=0-499");`. Untuk maklumat lanjut, lihat [Muat turun sebahagian kandungan dengan menentukan Range](/ms/open/development/use-range-download-a-part-of-content).
</Note>

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/storage/spaces/{spaceId}/dentries/{dentryId}/downloadInfos/query` |
| Kaedah HTTP | POST |
| Jenis aplikasi disokong | appType-Aplikasi dalaman |
| Kebenaran diperlukan | permission-Storage.DownloadInfo.Read-Kebenaran membaca untuk maklumat muat turun fail storan organisasi |

### Pengepala permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Dapatkannya dengan memanggil API [Dapatkan access token aplikasi dalaman](/ms/open/development/obtain-the-access-token-of-an-internal-app#). |

### Parameter laluan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| spaceId | String | Ya | ID ruang. Panggil API [Tambah ruang](/ms/open/development/add-space#) untuk mendapatkan nilai parameter id. |
| dentryId | String | Ya | ID fail. Panggil API [Dapatkan senarai fail atau folder](/ms/open/development/get-a-list-of-files-or-folders#) atau API [Dapatkan spaceId melalui dentryUuid](/ms/open/development/api-getdentryidbyuuid#) untuk mendapatkan nilai parameter id. |

### Parameter pertanyaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| unionId | String | Ya | unionId bagi operator. Panggil API [Pertanyaan butiran pengguna](/ms/open/development/query-user-details#) untuk mendapatkannya. |

### Isi permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| option | Object | Tidak | Parameter pilihan. |
| version | Long | Tidak | Nombor versi fail. Panggil API [Dapatkan senarai versi fail](/ms/open/development/obtains-a-list-of-file-versions#) untuk mendapatkan versi. |
| preferIntranet | Boolean | Tidak | Sama ada menggunakan penghantaran intranet secara keutamaan. Parameter ini memerlukan penghantaran intranet storan khusus dikonfigurasi. - true: Ya (lalai) - false: Tidak |

## Respons

### Isi respons

| Nama | Jenis | Penerangan |
| --- | --- | --- |
| protocol | String | Protokol muat turun fail. - **HEADER_SIGNATURE**: Permintaan tandatangan pengepala |
| headerSignatureInfo | Object | Maklumat permintaan tandatangan pengepala. Medan ini berkuat kuasa apabila nilai medan protocol ialah HEADER_SIGNATURE. |
| resourceUrls | Array of String | Pelbagai URL muat turun. URL yang disenaraikan terlebih dahulu mempunyai keutamaan lebih tinggi. |
| headers | `Map<String, String>` | Maklumat pengepala permintaan. |
| expirationSeconds | Integer | Masa tamat tempoh, dalam saat. |
| region | String | Wilayah. - **ZHANGJIAKOU**: Zhangjiakou - **SHENZHEN**: Shenzhen - **SHANGHAI**: Shanghai - **SINGAPORE**: Singapura - **UNKNOWN**: Tidak diketahui |
| internalResourceUrls | Array of String | URL intranet. Medan ini pada masa ini tiada kes penggunaan. Abaikan. |
