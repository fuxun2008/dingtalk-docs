Panggil API ini untuk mengemas kini sifat aplikasi bagi fail atau folder.

## Penerangan panggilan API

Maklumat sifat aplikasi yang dihantar dalam API disahkan berdasarkan nama sifat.

- Jika nama sifat sedia ada bagi fail atau folder sepadan dengan nama sifat yang dihantar, API akan mengemas kini sifat tersebut.
- Jika nama sifat sedia ada bagi fail atau folder tidak sepadan dengan nama sifat yang dihantar, API akan menambah sifat tersebut.

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/storage/spaces/{spaceId}/dentries/{dentryId}/appProperties` |
| Kaedah HTTP | PUT |
| Jenis aplikasi disokong | appType-Aplikasi dalaman　appType-Aplikasi perusahaan pihak ketiga |
| Kebenaran diperlukan | permission-Storage.File.Write-Kebenaran tulis untuk fail storan organisasi |

### Pengepala permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Dapatkannya seperti berikut:   - Untuk aplikasi dalaman, panggil API [Dapatkan access token aplikasi dalaman](/open/development/obtain-the-access-token-of-an-internal-app). - Untuk aplikasi perusahaan pihak ketiga, panggil API [Dapatkan access token organisasi yang diberi kuasa untuk aplikasi pihak ketiga](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1). |

### Parameter laluan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| spaceId | Long | Ya | ID ruang. Panggil API [Tambah ruang](/open/development/add-space) untuk mendapatkan nilai parameter id. |
| dentryId | Long | Ya | ID fail atau folder. Panggil API [Dapatkan senarai fail atau folder](/open/development/get-a-list-of-files-or-folders) atau API [Dapatkan spaceId dan dentryId mengikut dentryUuid](/open/development/api-getdentryidbyuuid) untuk mendapatkan nilai parameter id. |

### Parameter pertanyaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| unionId | String | Ya | unionId bagi pengendali. Panggil API [Tanya butiran pengguna](/open/development/query-user-details) untuk mendapatkan nilai parameter unionid. |

### Isi permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| appProperties | Array | Ya | Senarai sifat aplikasi. Nilai maksimum ialah 3. |
| name | String | Ya | Nama sifat.       - Jika nama sifat sudah wujud, maklumat sifat sedia ada akan dikemas kini. - Jika nama sifat belum wujud, maklumat sifat akan ditambah. |
| value | String | Ya | Nilai sifat. |
| visibility | String | Ya | Skop keterlihatan sifat.   - **PUBLIC**: Sifat boleh dilihat oleh semua aplikasi. - **PRIVATE**: Sifat hanya boleh dilihat oleh aplikasi pemiliknya. Ini ialah nilai lalai. |

| --- | --- | --- |
| success | Boolean | Sama ada kemas kini ini berjaya.   - **true**: Berjaya - **false**: Gagal |

```text

}
```
