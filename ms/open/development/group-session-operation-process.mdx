Dokumen ini menerangkan cara memanggil API Sembang Kumpulan untuk melaksanakan operasi Sembang Kumpulan. Mula-mula, cipta aplikasi dalaman. Kemudian, gunakan API Sembang Kumpulan untuk mencipta Sembang Kumpulan, mendapatkan maklumat Sembang Kumpulan, menguruskan Sembang Kumpulan, dan mengubah suai Sembang Kumpulan.

## Gambaran keseluruhan proses

Langkah 1: Dapatkan client ID dan Client Secret aplikasi.

Langkah 3: Dapatkan kelayakan akses aplikasi dengan mengikut [Dapatkan access token aplikasi dalaman](/ms/open/development/obtain-the-access-token-of-an-internal-app).

Langkah 4: Panggil API Sembang Kumpulan bahagian pelayan.

1. Panggil Server API untuk mencipta Sembang Kumpulan bagi mencipta Sembang Kumpulan dan mendapatkan `chatId`-nya.
2. Berdasarkan `chatId`, panggil Server API [Tanya maklumat Sembang Kumpulan](/ms/open/development/obtain-a-group-session) untuk mendapatkan maklumat Sembang Kumpulan.
3. Urus Sembang Kumpulan dengan menggunakan chatId-nya.

   - Berdasarkan `chatId`, panggil Server API baharu [Dapatkan OpenConversationId Sembang Kumpulan](/ms/open/development/obtain-group-openconversationid) untuk mendapatkan `openConversationId`.

     - Berdasarkan `openConversationId`, panggil Server API baharu untuk menetapkan pentadbir kumpulan secara pukal bagi menetapkan pentadbir kumpulan secara pukal.
   - Berdasarkan `chatId`, panggil Server API untuk mengemas kini pentadbir kumpulan bagi menetapkan pentadbir kumpulan.
   - Berdasarkan `chatId`, panggil Server API [Lumpuhkan Sembang Peribadi](/ms/open/development/set-private-chat) untuk mengawal sama ada Ahli kumpulan boleh bersembang secara peribadi.
   - Berdasarkan `chatId`, panggil Server API [Kemas kini nama panggilan kumpulan bagi ahli kumpulan](/ms/open/development/set-a-group-nickname) untuk menetapkan nama panggilan ahli kumpulan.
   - Berdasarkan `chatId`, panggil Server API [Dapatkan pautan Kod QR sertai sembang](/ms/open/development/obtain-a-qr-code-link). Pengguna lain dalam Organisasi Anda boleh mengklik pautan untuk memohon menyertai Sembang Kumpulan.
4. Berdasarkan `chatId`, panggil Server API untuk mengemas kini Sembang Kumpulan bagi mengubah suai maklumat Sembang Kumpulan.

## Prasyarat

Selesaikan proses [Penciptaan dan konfigurasi aplikasi](/ms/open/dingstart/create-application).

## Langkah 1: Dapatkan kelayakan aplikasi

1. Pilih aplikasi sasaran, pergi ke halaman butiran aplikasi, dan klik **Maklumat Asas** > **Kelayakan dan Maklumat Asas**.
2. Dapatkan client ID dan Client Secret aplikasi.

## Langkah 2: Tambah kebenaran API

Klik **Konfigurasi Pembangunan** > **Urus kebenaran**. Dalam kotak carian kebenaran, masukkan `qyapi_chat_manage`, `qyapi_chat_read`, dan `qyapi_chat_base_read` secara berasingan, dan mohon kebenaran tersebut.

## Langkah 3: Dapatkan access token aplikasi

<Warning>
Untuk butiran tentang perbezaan antara Server API, lihat API lama VS API Baharu. Semua API berikut menggunakan Server API baharu. Untuk butiran muat turun SDK, lihat Muat turun SDK bahagian pelayan.
</Warning>

Berdasarkan client ID dan Client Secret yang diperoleh pada Langkah 1, dapatkan kelayakan akses aplikasi dengan mengikut [Dapatkan access token aplikasi dalaman](/ms/open/development/obtain-the-access-token-of-an-internal-app).

```java
 public void getAccessToken() throws Exception {
        Config config = new Config();
        config.protocol = "https";
        config.regionId = "central";
        com.aliyun.dingtalkoauth2_1_0.Client client = new com.aliyun.dingtalkoauth2_1_0.Client(config);
        GetAccessTokenRequest accessTokenRequest = new GetAccessTokenRequest()
                .setAppKey("din*********hgn")
                .setAppSecret("9G_O************mBkhgGIO");
        GetAccessTokenResponse accessToken = client.getAccessToken(accessTokenRequest);
        System.out.println(JSON.toJSONString(accessToken.getBody()));
    }
```
