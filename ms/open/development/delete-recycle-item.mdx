Panggil API ini untuk memadam item tertentu daripada Tong Sampah.

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/storage/recycleBins/{recycleBinId}/recycleItems/{recycleItemId}` |
| Kaedah HTTP | DELETE |
| Jenis aplikasi yang disokong | appType-Aplikasi dalaman　appType-Aplikasi perusahaan pihak ketiga |
| Kebenaran yang diperlukan | permission-Storage.RecycleBin.Write-Kebenaran tulis untuk Tong Sampah storan organisasi |

### Header permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Dapatkan seperti berikut:   - Untuk aplikasi dalaman, panggil API [Dapatkan access token aplikasi dalaman](/open/development/obtain-the-access-token-of-an-internal-app#). - Untuk aplikasi perusahaan pihak ketiga, panggil API [Dapatkan access token organisasi yang memberi kebenaran kepada aplikasi pihak ketiga](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#). |

### Parameter laluan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| recycleBinId | String | Ya | ID Tong Sampah. Dapatkan dengan memanggil API [Dapatkan maklumat Tong Sampah](/open/development/obtain-information-about-the-recycle-bin#). |
| recycleItemId | String | Ya | ID item tong sampah. Dapatkan nilai parameter `id` dengan memanggil API [Dapatkan senarai item tong sampah](/open/development/gets-the-list-of-recycle-items#). |

### Parameter kueri

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| unionId | String | Ya | unionId operator. Dapatkan dengan memanggil API [Tanya butiran pengguna](/open/development/query-user-details#). |

### Contoh permintaan

```http
DELETE /v1.0/storage/recycleBins/pQy3R7xxxxx/recycleItems/2190xxxxx?unionId=chyxxxxx HTTP/1.1
Host:api.dingtalk.io

Content-Type:application/json
```

| --- | --- | --- |
| success | Boolean | Sama ada operasi berjaya.   - **true**: Berjaya - **false**: Gagal |

### Contoh isi respons

```text
HTTP/1.1 200 OK
Content-Type:application/json

{
  "success" : true
}
```

Jika ralat dikembalikan semasa anda memanggil API ini, cari penyelesaiannya dalam dokumen [Kod ralat global](/open/development/server-api-error-codes-1) berdasarkan mesej ralat.
