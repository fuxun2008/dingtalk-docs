Dapatkan komponen borang yang ditetapkan sebagai syarat.

## Penerangan panggilan API

Selepas penyedia penyelesaian mencipta templat kelulusan untuk organisasi melalui API Cipta Templat Kelulusan, organisasi tersebut boleh mengkonfigurasikan proses kelulusan dalam Admin Console Kelulusan. Semasa konfigurasi, komponen borang boleh ditetapkan sebagai syarat proses. ISV tidak boleh mengemas kini komponen borang yang ditetapkan sebagai syarat proses. Panggil API ini untuk menyemak komponen borang yang ditetapkan sebagai syarat proses.

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/v1.0/workflow/processes/conditions/components |
| Kaedah HTTP | GET |
| Jenis aplikasi yang disokong | appType-Aplikasi perusahaan pihak ketiga |
| Kebenaran yang diperlukan | permission-Workflow.Form.Read-Kebenaran membaca templat aliran kerja. |

### Pengepala permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Dapatkannya dengan memanggil API untuk mendapatkan access token organisasi yang telah memberikan kebenaran kepada aplikasi pihak ketiga. |

### Parameter pertanyaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| processCode | String | Ya | Kod unik proses kelulusan. Dapatkannya dengan memanggil API [Cipta atau kemas kini templat borang kelulusan](/ms/open/development/create-an-approval-form-template) atau daripada [Gambaran keseluruhan Kelulusan OA - Glosari](/ms/open/development/workflow-overview). |
| agentId | Long | Tidak | agentId aplikasi.   - Untuk aplikasi dalaman, dapatkannya pada halaman butiran aplikasi dalam [Konsol Pembangun](https://open-dev.dingtalk.io/#/). - Untuk aplikasi perusahaan pihak ketiga, dapatkannya dengan memanggil API untuk mendapatkan maklumat kebenaran organisasi. |

### Contoh permintaan

HTTP

```http
GET /v1.0/workflow/processes/conditions/components?processCode=PROC-xxx&agentId=10 HTTP/1.1
Host:api.dingtalk.io
x-acs-dingtalk-access-token:6d1bxxxx
Content-Type:application/json
```

## Respons

### Isi respons

| Nama | Jenis | Penerangan |
| --- | --- | --- |
| result | Array | Hasil yang dikembalikan. |
| id | String | ID borang. |
| label | String | Nama borang. |

### Contoh isi respons

```text
HTTP/1.1 200 OK
Content-Type:application/json

{
  "result" : [ {
    "id" : "TextField",
    "label" : "Medan teks"
  } ]
}
```

### Kod ralat

Jika panggilan API mengembalikan ralat, cari penyelesaian dalam dokumen [Kod ralat global](/ms/open/development/server-api-error-codes-1) berdasarkan mesej ralat.

| HttpCode | Kod ralat | Mesej ralat | Penerangan |
| --- | --- | --- | --- |
| 400 | invalidProcessCode | processCode templat kelulusan tidak boleh kosong | processCode templat kelulusan tidak boleh kosong |
| 400 | processNotExist | Proses kelulusan tidak wujud | Proses kelulusan tidak wujud |
| 400 | needAuth | Kebenaran diperlukan | Kebenaran diperlukan |
| 400 | internalError | %s | Ralat dalaman sistem |
| 400 | invalidAgentId | agentId tidak sah | agentId tidak sah |
| 500 | systemError | Ralat sistem | Ralat sistem |
