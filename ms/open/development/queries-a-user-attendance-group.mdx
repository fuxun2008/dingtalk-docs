---
title: "Dapatkan kumpulan kehadiran pengguna"
description: "Panggil API DingTalk ini untuk mendapatkan kumpulan kehadiran pekerja melalui ID pengguna, termasuk nama, ID, jenis kehadiran dan butiran syif."
---

Panggil API ini untuk mendapatkan maklumat kumpulan kehadiran seorang pekerja, termasuk nama kumpulan kehadiran dan jenis kehadiran. Seorang pekerja hanya boleh menyertai satu kumpulan kehadiran dalam sesebuah organisasi.

## Permintaan

| **Maklumat asas** | |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/topapi/attendance/getusergroup |
| Kaedah HTTP | POST |
| Jenis aplikasi yang disokong | appType-Aplikasi dalaman appType-Aplikasi perusahaan pihak ketiga |
| Keperluan kebenaran | permission-qyapi_base-Kebenaran asas yang diperlukan untuk memanggil API organisasi |

### Parameter pertanyaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | bE74xxxx | Kelayakan aplikasi yang digunakan untuk memanggil API ini.   - Bagi Aplikasi dalaman, dapatkannya dengan memanggil API [Dapatkan access_token Aplikasi dalaman](/ms/open/development/obtain-orgapp-token). - Bagi Aplikasi perusahaan pihak ketiga, dapatkannya dengan memanggil API Dapatkan access_token Aplikasi perusahaan pihak ketiga. |

### Isi permintaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| userid | String | Ya | user123 | ID pengguna pekerja dalam Organisasi Anda. |

### Contoh permintaan

```curl
curl -X POST "https://api.dingtalk.io/topapi/attendance/getusergroup" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=04cd6xxxx91f77' \
-d 'userid=zhangsan'
```

Java

```text
DingTalkClient client = new DefaultDingTalkClient("https://api.dingtalk.io/topapi/attendance/getusergroup");
OapiAttendanceGetusergroupRequest req = new OapiAttendanceGetusergroupRequest();
req.setUserid("user123");
OapiAttendanceGetusergroupResponse rsp = client.execute(req, access_token);
System.out.println(rsp.getBody());
```

Python

```python
import dingtalk.api

req=dingtalk.api.OapiAttendanceGetusergroupRequest("https://api.dingtalk.io/topapi/attendance/getusergroup")

req.userid="zhangsan"
try:
  resp= req.getResponse(access_token)
  print(resp)
except Exception,e:
  print(e)
```

PHP

```php
include "TopSdk.php";
date_default_timezone_set('Asia/Shanghai');

$c = new DingTalkClient(DingTalkConstant::$CALL_TYPE_OAPI, DingTalkConstant::$METHOD_POST , DingTalkConstant::$FORMAT_JSON);
$req = new OapiAttendanceGetusergroupRequest;
$req->setUserid("zhangsan");
$resp = $c->execute($req, $access_token, "https://api.dingtalk.io/topapi/attendance/getusergroup");
```

C#

```text
IDingTalkClient client = new DefaultDingTalkClient("https://api.dingtalk.io/topapi/attendance/getusergroup");
OapiAttendanceGetusergroupRequest req = new OapiAttendanceGetusergroupRequest();
req.Userid = "zhangsan";
OapiAttendanceGetusergroupResponse rsp = client.Execute(req, access_token);
Console.WriteLine(rsp.Body);
```

## Respons

### Isi respons

| Nama | Jenis | Contoh | Penerangan |
| --- | --- | --- | --- |
| result | AtGroupFullForTopVo |  | Hasil pertanyaan. |
| name | String | Kehadiran | Nama kumpulan kehadiran. |
| group_id | Number | 685935028 | ID kumpulan kehadiran.  **Nota**  Jika anda menggunakan pengecam kumpulan kehadiran lama **group_key**, panggil API [Tukar groupKey kepada groupId](/ms/open/development/convert-groupkey-to-groupid) untuk menukar **group_key** kepada **group_id**. |
| type | String | TURN | Jenis kehadiran:   - **FIXED**: Penjadualan syif tetap - **TURN**: Penjadualan syif bergilir - **NONE**: Tiada syif |
| classes | AtClassVo[] |  | Senarai syif dalam kumpulan kehadiran. |
| class_id | Number | 678215070 | ID syif. |
| name | String | Syif A | Nama syif. |
| sections | AtSectionVo[] |  | Senarai bahagian masuk kerja dan tamat kerja dalam syif. |
| times | AtTimeVo[] |  | Senarai butiran masuk kerja dan tamat kerja dalam syif. |
| check_time | Date | 1970-01-01 19:00:00 | Masa daftar masuk. |
| check_type | String | OnDuty | Jenis daftar masuk:   - **OnDuty**: Masuk kerja - **OffDuty**: Tamat kerja |
| across | Number | 0 | Bilangan hari yang direntasi oleh masa daftar masuk. |
| begin_min | Number | 30 | Masa daftar masuk terawal yang dibenarkan sebelum masa yang dijadualkan, dalam minit. |
| end_min | Number | 0 | Masa daftar masuk terlewat yang dibenarkan selepas masa yang dijadualkan, dalam minit. |
| setting | ClassSettingVo |  | Konfigurasi syif. |
| rest_begin_time | AtTimeVo |  | Tetapan permulaan rehat. |
| across | Number | 0 | Rentang masa.   - **0**: Tidak merentasi hari - **1**: Merentasi hari |
| begin_min | Number | 0 | Masa mula. |
| end_min | Number | 0 | Masa tamat. |
| check_time | Date | 1970-01-01 19:00:00 | Masa permulaan rehat. |
| check_type | String | OnDuty | Jenis tetapan:   - **OnDuty**: Permulaan rehat - **OffDuty**: Tamat rehat |
| rest_end_time | AtTimeVo |  | Tetapan masa tamat rehat. |
| across | Number | 0 | Rentang masa. |
| begin_min | Number | 0 | Masa mula. |
| end_min | Number | 0 | Masa tamat. |
| check_time | Date | 1970-01-01 20:00:00 | Masa tamat rehat. |
| check_type | String | OffDuty | Jenis daftar masuk:   - **OnDuty**: Permulaan rehat - **OffDuty**: Tamat rehat |
| errcode | Number | 0 | Kod pemulangan. |
| errmsg | String | ok | Penerangan kod pemulangan. |
| request_id | String | f8zybbfze3e8 | ID permintaan. |
