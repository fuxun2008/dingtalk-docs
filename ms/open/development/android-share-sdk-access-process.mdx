## Persediaan

Sebelum mengintegrasikan perkongsian DingTalk pada Android, lengkapkan persediaan berikut:

- Sediakan persekitaran pembangunan Android.
- Muat turun [Android SDK](https://files.alicdn.com/tpsservice/e76b61f0c65ddda660bb07f265c35b19.zip).
- Pasang klien DingTalk versi 2.7.0 atau lebih tinggi.

## Langkah 1: **Integrasikan perkongsian DingTalk**

1. Log masuk ke [Developer Console](https://open-dev.dingtalk.com/#/shareMan), kemudian pergi ke halaman butiran aplikasi.
2. Pada halaman butiran aplikasi, klik **Log Masuk dan Perkongsian DingTalk** untuk membuka halaman log masuk dan perkongsian.

3. Dalam bahagian **Integrasikan Perkongsian**, klik **Edit** di sebelah kanan.
4. Aktifkan **Perkongsian Android**, masukkan **Nama Pakej Android** dan **Tandatangan Android** secara berurutan, kemudian klik Simpan.

   **Nota**

   Untuk cara mendapatkan tandatangan, rujuk Kaedah Tandatangan.

## Langkah 2: Sediakan persekitaran pembangunan

Sediakan persekitaran pembangunan menggunakan salah satu kaedah berikut.

- Kaedah 1: Kebergantungan Gradle

  Tambah `compile 'com.alibaba.android:ddsharesdk:1.1.0'` ke dalam `dependencies` fail `build.gradle` modul.
- Kaedah 2: Import fail JAR secara terus

  1. Cipta projek Android bernama DDShareDemo, cipta direktori libs dalam projek tersebut, dan salin fail JAR yang dimuat turun ke direktori tersebut, seperti ditunjukkan di bawah:

  2. Tambah fail JAR dalam direktori libs ke dalam kebergantungan projek.

## Langkah 3: **Gunakan SDK dalam kod anda**

Jika aplikasi anda perlu menerima permintaan yang dihantar oleh DingTalk, atau menerima respons kepada permintaan yang dihantar ke DingTalk, lakukan langkah berikut:

1. Cipta direktori `ddshare` di bawah direktori yang sepadan dengan nama pakej anda.

   Kemudian tambah atribut **exported** dalam fail `AndroidManifest` dan tetapkan kepada **true**.

2. Laksanakan antara muka **IDDAPIEventHandler**. Respons DingTalk dikembalikan ke kaedah onResp melalui Callback.

   Berikut ialah kod contoh untuk kaedah onResp:

   ```
   public void onResp(BaseResp baseResp) {
       int errCode = baseResp.mErrCode;
       Log.d("lzc" , "errorCode==========>"+errCode);
       String errMsg = baseResp.mErrStr;
       Log.d("lzc" , "errMsg==========>"+errMsg);
       if(baseResp.getType() == ShareConstant.COMMAND_SENDAUTH_V2 && (baseResp instanceof SendAuth.Resp)){
           SendAuth.Resp authResp = (SendAuth.Resp) baseResp;
           switch (errCode){
               case BaseResp.ErrCode.ERR_OK:
                   Toast.makeText(this, "Kebenaran berjaya. authorization_code ialah: "+authResp.code, Toast.LENGTH_SHORT).show();
                   break;
               case BaseResp.ErrCode.ERR_USER_CANCEL:
                   Toast.makeText(this, "Kebenaran dibatalkan", Toast.LENGTH_SHORT).show();
                   break;
               default:
                   Toast.makeText(this, "Ralat kebenaran"+baseResp.mErrStr, Toast.LENGTH_SHORT).show();
                   break;
           }
       }else{
           switch (errCode){
               case BaseResp.ErrCode.ERR_OK:
                   Toast.makeText(this, "Perkongsian berjaya", Toast.LENGTH_SHORT).show();
                   break;
               case BaseResp.ErrCode.ERR_USER_CANCEL:
                   Toast.makeText(this, "Perkongsian dibatalkan", Toast.LENGTH_SHORT).show();
                   break;
               default:
                   Toast.makeText(this, "Perkongsian gagal"+baseResp.mErrStr, Toast.LENGTH_SHORT).show();
                   break;
           }
       }
       finish();
   }
   ```
3. Dalam kelas **DDShareActivity**, hantar intent yang diterima dan objek yang melaksanakan antara muka **IDDAPIEventHandler** kepada kaedah handleIntent bagi antara muka **IDDShareApi**. Kemudian, apabila aplikasi anda meminta respons DingTalk, DingTalk akan mengembalikannya dengan memanggil kaedah onResp.

   ```
   private IDDShareApi mIDDShareApi;

   @Override
   protected void onCreate(Bundle savedInstanceState) {
       super.onCreate(savedInstanceState);
       Log.d("lzc" ,"onCreate==========>");
       try {
           // Export aktiviti ditetapkan kepada true, jadi bungkus dalam blok try untuk mengelakkan serangan penafian perkhidmatan (denial-of-service) oleh pihak ketiga
           mIDDShareApi = DDShareApiFactory.createDDShareApi(this, Constant.APP_ID, false);
           mIDDShareApi.handleIntent(getIntent(), this);
       } catch (Exception e) {
           e.printStackTrace();
           Log.d("lzc" , "e===========>"+e.toString());
       }
   }
   ```
4. Tentukan sama ada peranti semasa menyokong perkongsian.

   - Tentukan sama ada DingTalk dipasang pada peranti semasa.

     ```
     findViewById(R.id.ding_install_check).setOnClickListener(new View.OnClickListener() {
         @Override
         public void onClick(View view) {
             boolean isInstalled = iddShareApi.isDDAppInstalled();
             Toast.makeText(MainActivity.this, "Dipasang===>" + isInstalled, Toast.LENGTH_SHORT).show();
         }
     });
     ```
   - Tentukan sama ada peranti semasa menyokong perkongsian ke DingTalk (DingTalk dipasang dan versi DingTalk menyokong perkongsian).

     ```
     findViewById(R.id.share_support_check).setOnClickListener(new View.OnClickListener() {
         @Override
         public void onClick(View view) {
             boolean isSupport = iddShareApi.isDDSupportAPI();
             Toast.makeText(MainActivity.this ,"Menyokong perkongsian ke Kenalan===>"+isSupport ,Toast.LENGTH_SHORT ).show();
         }
     });
     ```
5. Jenis perkongsian yang disokong.

   Teks, Gambar, Pautan, dan jenis sampul merah Alipay yang istimewa disokong. Untuk penggunaan khusus, rujuk sampel **Android SDK** yang dimuat turun.
