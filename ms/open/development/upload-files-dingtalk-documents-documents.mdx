Dokumen ini memandu anda memuat naik fail tempatan ke direktori Dokumen Saya dalam DingTalk Docs.

## Gambaran keseluruhan

### Apa yang akan anda pelajari

Tutorial ini menunjukkan kepada pembangun cara memuat naik fail tempatan ke direktori Dokumen Saya dalam DingTalk Docs.

### Matlamat

Membantu pembangun menguasai dengan cepat cara memuat naik fail tempatan ke direktori Dokumen Saya dalam DingTalk Docs.

### Khalayak sasaran

Semua pembangun DingTalk.

## Prasyarat

- Anda telah memperoleh kebenaran pembangun.
- Anda telah memasang IDE atau alat pembangunan lain.
- Anda telah memasang [Node.js](https://nodejs.org/en/download) dan melengkapkan [persediaan persekitaran](https://m.runoob.com/nodejs/nodejs-install-setup.html).
- Anda telah memasang [Maven](https://maven.apache.org/) dan melengkapkan [persediaan persekitaran](https://maven.apache.org/install.html).
- Anda telah memasang [JDK](https://www.oracle.com/java/technologies/downloads/?er=221886) dan melengkapkan [persediaan persekitaran](https://docs.oracle.com/en/java/javase/24/install/overview-jdk-installation.html).

## Aliran pembangunan

1. Panggil API [Dapatkan maklumat Knowledge Base Dokumen Saya](/open/development/get-my-documents) untuk mendapatkan ID nod root bagi Dokumen Saya, iaitu Parameter respons `rootNodeId` (parentDentryUuid).
2. Panggil API [Dapatkan maklumat muat naik fail](/open/development/obtain-file-upload-informations) untuk mendapatkan nilai parameter `resourceUrls` dan `headers` yang diperlukan untuk memuat naik fail.
3. Muat naik fail menggunakan kaedah Tandatangani permintaan header OSS:

   Java

   ```java lines
   import java.io.*;
   import java.net.HttpURLConnection;
   import java.net.URL;
   public void test(){
                  // Dapatkan resourceUrls daripada respons API
                   String resourceUrl = "resourceUrls returned by the API above";
                 // Dapatkan headers daripada respons API
                   Map<String, String> headers = "headers returned by the API above";
                   URL url = new URL(resourceUrl);
                   HttpURLConnection connection = (HttpURLConnection)url.openConnection();
                  if (headers != null) {
                   for (Map.Entry<String, String> entry : headers.entrySet()) {
                       connection.setRequestProperty(entry.getKey(), entry.getValue());
                   }
               }
                   connection.setDoOutput(true);
                   connection.setRequestMethod("PUT");
                   connection.setUseCaches(false);
                   connection.setReadTimeout(10000);
                   connection.setConnectTimeout(10000);
                   connection.connect();
                   OutputStream out = connection.getOutputStream();
                   InputStream is = new FileInputStream(new File("/Users/xxxxx/Desktop/test-file.xls"));
                   byte[] b =new byte[1024];
                   int temp;
                   while ((temp=is.read(b))!=-1){
                          out.write(b,0,temp);
                   }
                   out.flush();
                   out.close();
                   int responseCode = connection.getResponseCode();
                   connection.disconnect();
                   if (responseCode == 200) {
                       System.out.println("Upload succeeded");
                    } else {
                       System.out.println("Upload failed");
                    }
   }
   ```

   C#

   ```java lines
   public static string HttpRequest(string url, string filePath, Dictionary<string, string> headers) {

       FileStream fileStream = new FileStream(filePath, FileMode.Open, FileAccess.Read, FileShare.Read);
       BinaryReader reader = new BinaryReader(fileStream);
       reader.BaseStream.Seek(0, SeekOrigin.Begin);
       byte[] datas = reader.ReadBytes((int)reader.BaseStream.Length);
       HttpWebRequest request = (HttpWebRequest)WebRequest.Create(url);
       request.Method = "PUT";
       request.Timeout = 150000;
       foreach (var header in headers) {
           request.Headers.Add($"{header.Key}", $"{header.Value}");
       }
       Stream requestStream = null;
       string responseStr = null;
       try {
           if (datas != null) {
               request.ContentLength = datas.Length;
               requestStream = request.GetRequestStream();
               requestStream.Write(datas, 0, datas.Length);
               requestStream.Close();
           } else {
               request.ContentLength = 0;
           }
           HttpWebResponse response = request.GetResponse() as HttpWebResponse;
           responseStr = response.Headers.GetValues("x-oss-request-id")[0];
       } catch (Exception ex) {
           Console.WriteLine("error");
       } finally {
           request = null;
           requestStream = null;
       }
       return responseStr;
   }
   ```

4. Panggil API [Hantar fail](/open/development/submittal-file) untuk memuat naik fail ke direktori Dokumen Saya dalam DingTalk Docs.

## Langkah 1: Cipta aplikasi

1. Log masuk ke [Developer Console](https://open-dev.dingtalk.io/#/).
2. Klik **App Development** > **Internal app** > **DingTalk App** > **Create App**.
3. Isikan maklumat aplikasi.

   | **Item** | **Wajib** | **Penerangan** |
   | --- | --- | --- |
   | **Nama aplikasi** | Ya | Masukkan nama aplikasi. Panjang minimum ialah 2 aksara. |
   | **Penerangan aplikasi** | Ya | Terangkan secara ringkas produk atau perkhidmatan yang disediakan oleh aplikasi. Panjang minimum ialah 4 aksara. |
   | **Ikon aplikasi** | Tidak | Muat naik ikon aplikasi. Ikon mesti dalam format JPG atau PNG, sekurang-kurangnya 240 px \* 240 px, dengan nisbah aspek 1:1, tanpa sudut bulat, dan tidak melebihi 2 MB. |
4. Klik **Save** untuk masuk ke halaman butiran aplikasi.

Selepas penciptaan, klik **Basic Information** > **Credentials and Basic Information** untuk melihat Client ID dan Client Secret.

> *Nota: Simpan Client ID dan Client Secret untuk kegunaan kemudian.*

## Langkah 2: Konfigurasikan aplikasi web

1. Pada halaman butiran aplikasi, klik **App Capabilities** > **Add App Capability**.
2. Pilih untuk menambah aplikasi web.
3. Konfigurasikan maklumat aplikasi web (H5):

   | **Item** | **Penerangan** |
   | --- | --- |
   | URL laman utama aplikasi | Masukkan URL laman utama. Contoh ini menggunakan: `http://localhost:5173?corpid=$CORPID$` untuk ujian seterusnya. Contoh ini hanya untuk ujian tempatan. |
   | URL laman utama PC | |

   Selepas konfigurasi, klik Save.

## Langkah 3: Mohon kebenaran API

1. Pada halaman butiran aplikasi, klik **Development Configuration** > **Manage permissions** untuk masuk ke halaman permohonan kebenaran.
2. Dalam kotak carian kebenaran, masukkan `Wiki.Workspace.Read`, `Storage.UploadInfo.Read`, dan `Storage.File.Write` secara berasingan, dan mohon setiap Kebenaran API.

   > Jika anda bukan Admin Organisasi atau tidak mempunyai kebenaran pembangunan aplikasi, permohonan kebenaran memerlukan kelulusan daripada Admin Organisasi.

## Langkah 4: Terbitkan aplikasi

1. Selepas mengonfigurasikan aplikasi, terbitkannya. Pada halaman butiran aplikasi, klik **App Release** > **Version Management and Release**.
2. Klik **Create New Version** untuk masuk ke halaman butiran versi.
3. Konfigurasikan maklumat versi:

   | **Item** | **Penerangan** |
   | --- | --- |
   | Nombor versi aplikasi | Masukkan nombor versi aplikasi. Nilai lalai boleh diterima. |
   | Penerangan versi | Masukkan penerangan versi. Anda boleh menyesuaikannya. |
   | Kandungan untuk diterbitkan | Keupayaan aplikasi yang dipaparkan dalam Workbench: <br /> - Pilih aplikasi web |

   Selepas konfigurasi, klik Save di bawah.
4. Dalam dialog kejayaan, klik Publish Directly.

   > *Jika anda bukan Admin Organisasi, penerbitan aplikasi memerlukan kelulusan daripada Admin Organisasi. Penerbitan khusus untuk diri sendiri tidak memerlukan kelulusan admin.*

## Langkah 5: Bina perkhidmatan

1. Pastikan langkah-langkah di atas telah selesai dan anda telah memperoleh parameter yang diperlukan untuk menjalankan demo di bawah.
2. Muat turun demo [doc-demo.zip](https://help-static-aliyun-doc.aliyuncs.com/file-manage-files/zh-CN/20250704/bpihcw/doc-demo.zip).
3. Buka IDE anda dan import demo yang telah dimuat turun.

   > Kod contoh dipecahkan kepada backend (direktori kod backend) dan frontend (direktori kod frontend).

4. Buka direktori kod backend. Dalam direktori resources, edit fail `application.properties`, dan masukkan `clientId (Client ID aplikasi)` dan `clientSecret (Client Secret aplikasi)`.

5. Klik untuk memulakan perkhidmatan backend.

   **Nota**
   - Sebelum memulakan perkhidmatan backend, pastikan Maven dan JDK dipasang dengan betul dan persekitaran berkaitan telah dikonfigurasikan. Jika anda memasang IDE buat kali pertama, edit fail konfigurasi berkaitan dalam IDE.
   - Pastikan port 5173 dan 8080 tidak sedang digunakan.

6. Buka direktori kod frontend, edit `vite.config.ts`, dan masukkan `clientId (Client ID aplikasi)` yang betul.

7. Klik kanan pada fail projek frontend dan pilih **Terminal** untuk membukanya.

8. Dalam tetingkap terminal, jalankan arahan berikut:

   1. `npm install`
   2. `npm run dev`

      > Nota: Pada Windows, gunakan `npm run dev:raw` semasa memulakan.
9. Perkhidmatan frontend dan backend kini berjaya dijalankan.

## Langkah 6: Uji aplikasi

1. Log masuk ke klien DingTalk dan pilih organisasi tempat aplikasi berada.

2. Klik **Workbench** > **Add**, cari aplikasi organisasi yang anda cipta di atas, dan tambahkannya.

3. Buka aplikasi dalam Workbench, kemudian klik **Select Local File** untuk memuat naik.

   > Saiz fail mestilah kurang daripada 50 MB.

4. Selepas memilih fail, klik **Submit** untuk melengkapkan muat naik.

5. Selepas muat naik selesai, buka fail untuk melihat kandungan yang telah dimuat naik.
