title: "Batalkan instans kelulusan"
description: "Panggil API DingTalk untuk membatalkan instans kelulusan yang sedang berjalan menggunakan ID instans, dengan pilihan untuk menetapkan pengendali dan catatan penamatan."
---

Panggil API ini untuk membatalkan instans kelulusan yang masih dalam proses.

## Penerangan panggilan API

- Proses kelulusan tidak boleh dibatalkan dalam tempoh 15 saat selepas dimulakan.
- Apabila parameter isSystem ditetapkan kepada false (ditamatkan oleh pengendali yang ditetapkan), hantar pemohon untuk membatalkan instans kelulusan.
- API ini hanya membatalkan instans kelulusan yang sedang berjalan. API ini tidak boleh membatalkan instans kelulusan yang kelulusannya telah selesai.
- Sebelum memanggil API ini, pergi ke [DingTalk Admin Console](https://oa.dingtalk.io/) > **Workbench > Urus Aplikasi > Aplikasi Kelulusan OA** dan buka **Admin Console Kelulusan OA**. Cari **Templat > Tetapan Lanjutan > Batalkan/Ubah Suai Borang kelulusan** dan pilih **Benarkan penghantar membatalkan borang kelulusan yang sedang berjalan**. Jika tidak, panggilan akan gagal dengan `errcode:820008, success:false, errmsg:Approval system error` kerana anda tiada kebenaran untuk memproses tugasan tersebut.

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/v1.0/workflow/processInstances/terminate |
| Kaedah HTTP | POST |
| Jenis aplikasi yang disokong | appType-Aplikasi dalaman |
| Kebenaran yang diperlukan | permission-Workflow.Instance.Write-Kebenaran tulis instans aliran kerja |

### Pengepala permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Panggil API [Dapatkan access token Aplikasi dalaman](/ms/open/development/obtain-the-access-token-of-an-internal-app) untuk mendapatkannya. |

### Isi permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| processInstanceId | String | Ya | ID instans kelulusan.   - Panggil API [Cipta instans kelulusan](/ms/open/development/create-an-approval-instance) untuk mendapatkan nilai parameter `InstanceId`. - Panggil API [Dapatkan senarai ID instans kelulusan](/ms/open/development/obtain-an-approval-list-of-instance-ids) untuk mendapatkan nilai parameter `list`. |
| isSystem | Boolean | Tidak | Menentukan sama ada tindakan dilaksanakan oleh sistem.   - **true**: Sistem menamatkan instans secara terus. - **false**: Pengendali yang ditetapkan menamatkan instans (hantar pemohon untuk membatalkannya). |
| remark | String | Tidak | Catatan penamatan. Panjang maksimum: 1,024 aksara. |
| operatingUserId | String | Tidak | userId pengendali.      Parameter ini wajib apabila isSystem ialah false (hantar pemohon untuk membatalkan instans). |
