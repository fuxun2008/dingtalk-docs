---

Panggil API ini untuk menyemak sama ada jabatan atau pekerja milik kumpulan kehadiran.

## Penerangan panggilan API

- Jika anda menyemak senarai pekerja, API ini memulangkan nilai userId pekerja dalam kumpulan kehadiran.
- Jika anda menyemak senarai jabatan, API ini memulangkan ID jabatan dalam kumpulan kehadiran. API ini tidak memulangkan senarai userId pekerja dalam jabatan tersebut.

Contohnya, ahli kehadiran bagi sesuatu kumpulan kehadiran terdiri daripada **Jabatan Ujian** dan pekerja **Ahmad**. Jabatan Ujian mempunyai pekerja bernama Ali. API memulangkan keputusan berikut bagi jabatan atau pengguna yang berbeza:

- Jika anda menyemak userId Ali, API ini tidak memulangkan userId Ali.
- Jika anda menyemak userId Ahmad, API ini memulangkan userId Ahmad.
- Jika anda menyemak ID Jabatan Ujian, API ini memulangkan ID Jabatan Ujian.
- Jika anda menyemak sama ada Ahmad dan Ali berada dalam kumpulan kehadiran, API ini memulangkan userId Ahmad.

## Permintaan

| **Maklumat asas** | |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/topapi/attendance/group/member/listbyids |
| Kaedah HTTP | POST |
| Jenis aplikasi yang disokong | appType-Aplikasi dalaman appType-Aplikasi perusahaan pihak ketiga |
| Kebenaran | permission-qyapi_attendance_group_read-Kebenaran pertanyaan kumpulan kehadiran |

### Parameter pertanyaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | 6d1bxxxx | - Bagi aplikasi dalaman, panggil API [Dapatkan access_token aplikasi dalaman](/ms/open/development/obtain-orgapp-token) untuk mendapatkannya. - Bagi aplikasi perusahaan pihak ketiga, panggil API Dapatkan access_token perusahaan pihak ketiga untuk mendapatkannya. |

### Isi permintaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| op_user_id | String | Ya | dd_dd | userId pengendali. |
| group_id | Number | Ya | 98562 | ID kumpulan kehadiran.  **Nota**  Jika anda menggunakan pengecam kumpulan kehadiran lama group_key, panggil API [Tukar groupKey kepada groupId](/ms/open/development/convert-groupkey-to-groupid) untuk menukar group_key kepada group_id. |
| member_ids | String | Ya | user123,user456 | ID ahli. Setiap ID boleh berupa userId atau deptId. Pisahkan berbilang ID dengan koma (,). Setiap panggilan menyokong maksimum 20 nilai. |
| member_type | Number | Ya | 0 | Jenis ahli:   - **0**: Pekerja - **1**: Jabatan |

### Contoh permintaan

```curl
curl -X POST "https://api.dingtalk.io/topapi/attendance/group/member/listbyids" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=9bacfaxxxx71260' \
-d 'group_id=1234' \
-d 'member_ids=dd_dd' \
-d 'member_type=0' \
-d 'op_user_id=dd_dd'
```

Java

```text
DingTalkClient client = new DefaultDingTalkClient("https://api.dingtalk.io/topapi/attendance/group/member/listbyids");
OapiAttendanceGroupMemberListbyidsRequest req = new OapiAttendanceGroupMemberListbyidsRequest();
req.setOpUserId("user123");
req.setMemberIds("user123,user456");
req.setMemberType(0L);
req.setGroupId(68593L);
OapiAttendanceGroupMemberListbyidsResponse rsp = client.execute(req, access_token);
System.out.println(rsp.getBody());
```

## Respons

### Isi respons

| Nama | Jenis | Contoh | Penerangan |
| --- | --- | --- | --- |
| request_id | String | z81tif88lkot | ID permintaan. |
| errmsg | String | ok | Penerangan kod pulangan. |
| errcode | Number | 0 | Kod pulangan. |
| success | Boolean | true | Menunjukkan sama ada panggilan berjaya.   - **true**: Berjaya - **false**: Gagal |
| result | String[] | ["user123","user456"] | ID ahli yang milik kumpulan kehadiran. Setiap ID boleh berupa userId atau deptId. |

### Contoh isi respons

```json
{
  "errcode": 0,
  "errmsg":"ok",
  "result": [
    "user123",
    "user456"
  ],
  "success": true,
  "request_id": "4nvsqf4ij2xq"
}
```

### Kod ralat

Jika panggilan API memulangkan ralat, cari penyelesaian dalam dokumen [Kod ralat global](/ms/open/development/server-api-error-codes-1) berdasarkan mesej ralat.
