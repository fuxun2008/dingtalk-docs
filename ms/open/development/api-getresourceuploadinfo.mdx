title: "Get resource upload information"
description: "Call this API to query the upload address for a specified document resource, with request parameters and response details."

Panggil API ini untuk mendapatkan semula URL muat naik bagi sumber tertentu dalam dokumen.

## Penerangan panggilan API

Sumber merujuk kepada lampiran seperti gambar atau fail dalam dokumen. API ini biasanya digunakan bersama-sama dengan API muat naik lampiran produk lain.

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/doc/docs/resources/{docId}/uploadInfos/query` |
| Kaedah HTTP | POST |
| Jenis aplikasi disokong | appType-Aplikasi dalaman |
| Kebenaran | permission-Storage.File.Read-Kebenaran baca fail storan organisasi |

### Pengepala permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses yang digunakan untuk memanggil API ini. Dapatkan dengan memanggil API [Dapatkan access token aplikasi dalaman](/ms/open/development/obtain-the-access-token-of-an-internal-app#). |

### Parameter laluan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| docId | String | Ya | ID Dokumen (dentryUuid/documentId/workbookId/baseId). Dapatkan dengan salah satu cara berikut:   - Panggil API [Cipta dokumen Knowledge Base](/ms/open/development/create-team-space-document#). - Panggil API [Dapatkan senarai nod](/ms/open/development/get-node-list#). |

### Parameter pertanyaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| operatorId | String | Ya | unionId pengendali. Dapatkan dengan memanggil API [Pertanyaan butiran pengguna](/ms/open/development/query-user-details#) atau API [Dapatkan maklumat pengguna menggunakan kod log masuk senyap](/ms/open/development/obtain-the-userid-of-a-user-by-using-the-log-free#). |

### Isi permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| size | Long | Ya | Saiz sumber, dalam bait. |
| mediaType | String | Ya | Jenis sumber. Untuk nilai yang sah, lihat [Jenis MIME](https://developer.mozilla.org/en-US/docs/Web/HTTP/Guides/MIME_types/Common_types). |
| resourceName | String | Ya | Nama sumber. |

### Contoh permintaan

HTTP

```http
POST /v1.0/doc/docs/resources/xxxxx/uploadInfos/query?operatorId=xxxxx HTTP/1.1
Host:api.dingtalk.io
x-acs-dingtalk-access-token:xxxxx
Content-Type:application/json

{
  "size" : 200,
  "mediaType" : "image/jpeg",
  "resourceName" : "logo.jpg"
}
```
