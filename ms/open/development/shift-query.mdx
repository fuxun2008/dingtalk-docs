---
title: "Dapatkan butiran syif"
description: "Gunakan API DingTalk ini untuk mendapatkan butiran syif berdasarkan ID syif — termasuk nama syif, masa daftar masuk dan tempoh rehat — bagi mengurus kehadiran dengan tepat."
---

Panggil API ini untuk mendapatkan butiran syif berdasarkan ID syif, seperti nama syif, masa daftar masuk dan tempoh rehat.

## Permintaan

| **Maklumat asas** | |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/topapi/attendance/shift/query |
| Kaedah HTTP | POST |
| Jenis aplikasi yang disokong | appType-Aplikasi dalaman, appType-Aplikasi perusahaan pihak ketiga |
| Kebenaran | permission-qyapi_attendance_group_read-Kebenaran pertanyaan kumpulan kehadiran |

### Parameter pertanyaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | bE74xxxx | Kelayakan aplikasi yang digunakan untuk memanggil API ini.   - Bagi Aplikasi dalaman, panggil API [Dapatkan access_token Aplikasi dalaman](/ms/open/development/obtain-orgapp-token) untuk mendapatkannya. - Bagi Aplikasi perusahaan pihak ketiga, panggil API Dapatkan access_token Aplikasi perusahaan pihak ketiga untuk mendapatkannya. |

### Isi permintaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| op_user_id | String | Ya | user123 | userId pengendali. |
| shift_id | Number | Ya | 678215070 | ID syif. Panggil API [Dapatkan ringkasan syif](/ms/open/development/enterprise-shift-query-in-batches) untuk mendapatkan nilai parameter id. |

### Contoh permintaan

```curl
curl -X POST "https://api.dingtalk.io/topapi/attendance/shift/query" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=d946568c-08dd-44bf-acd3-cfc07d7829dd' \
-d 'op_user_id=dd_dd' \
-d 'shift_id=2445'
```

Java

```text
DingTalkClient client = new DefaultDingTalkClient("https://api.dingtalk.io/topapi/attendance/shift/query");
OapiAttendanceShiftQueryRequest req = new OapiAttendanceShiftQueryRequest();
req.setOpUserId("user123");
req.setShiftId(678215070L);
OapiAttendanceShiftQueryResponse rsp = client.execute(req, access_token);
System.out.println(rsp.getBody());
```

Python

```python
import dingtalk.api

req=dingtalk.api.OapiAttendanceShiftQueryRequest("https://api.dingtalk.io/topapi/attendance/shift/query")

req.op_user_id="dd_dd"
req.shift_id=2445
try:
  resp= req.getResponse(access_token)
  print(resp)
except Exception,e:
  print(e)
```

PHP

```php
include "TopSdk.php";
date_default_timezone_set('Asia/Shanghai');

$c = new DingTalkClient(DingTalkConstant::$CALL_TYPE_OAPI, DingTalkConstant::$METHOD_POST , DingTalkConstant::$FORMAT_JSON);
$req = new OapiAttendanceShiftQueryRequest;
$req->setOpUserId("dd_dd");
$req->setShiftId("2445");
$resp = $c->execute($req, $access_token, "https://api.dingtalk.io/topapi/attendance/shift/query");
```

C#

```text
IDingTalkClient client = new DefaultDingTalkClient("https://api.dingtalk.io/topapi/attendance/shift/query");
OapiAttendanceShiftQueryRequest req = new OapiAttendanceShiftQueryRequest();
req.OpUserId = "dd_dd";
req.ShiftId = 2445L;
OapiAttendanceShiftQueryResponse rsp = client.Execute(req, access_token);
Console.WriteLine(rsp.Body);
```

## Respons

### Isi respons

| Nama | Jenis | Contoh | Penerangan |
| --- | --- | --- | --- |
| result | TopShiftVo |  | Butiran syif. |
| shift_group_name | String | Syif kehadiran | Nama kumpulan syif. |
| corp_id | String | dinge87f1xxxx | ID organisasi. |
| shift_setting | TopShiftSettingVo |  | Tetapan syif. |
| shift_id | Number | 678215070 | ID syif. |
| gmt_modified | Date | 2020-09-06 15:49:27 | Masa syif terakhir diubah suai. |
| corp_id | String | dinge87f1xxxx | ID organisasi. |
| work_time_minutes | Number | 600 | Tempoh bekerja, dalam minit. Nilai -1 menunjukkan ciri ini dinyahaktifkan. |
| id | Number | 233840112 | ID tetapan syif. |
| attend_days | String | 12 | Bilangan hari kehadiran bagi syif ini. |
| gmt_create | Date | 2020-09-06 15:49:27 | Masa dicipta. |
| name | String | B | Nama syif. |
| id | Number | 678215070 | ID syif. |
| sections | TopSectionVo[] |  | Bahagian daftar masuk. |
| punches | TopPunchVo[] |  | Titik daftar masuk. |
| check_type | String | OnDuty | Jenis daftar masuk:   - **OnDuty**: Daftar masuk - **OffDuty**: Daftar keluar |
| end_min | Number | -1 | Masa daftar masuk terlewat yang dibenarkan.  Nilai dalam minit. Tambah nilai ini pada masa daftar masuk untuk mengira masa daftar masuk terlewat. |
| across | Number | 0 | Sama ada masa daftar masuk jatuh pada hari berikutnya:   - **0**: Hari yang sama - **1**: Hari berikutnya |
| check_time | Date | 1970-01-01 19:00:00 | Masa daftar masuk, dalam format Unix timestamp. Hanya jam, minit dan saat yang bermakna. |
| permit_minutes | Number | 0 | Tempoh pulang awal atau kelewatan yang dibenarkan, dalam minit. |
| free_check | Boolean | false | Sama ada dikecualikan daripada daftar masuk:   - **true**: Dikecualikan daripada daftar masuk - **false**: Daftar masuk diwajibkan |
| id | Number | 33928201 | ID titik daftar masuk. |
| begin_min | Number | 20 | Masa terawal yang dibenarkan untuk daftar masuk lebih awal, dalam minit. |
| absenteeism_late_minutes | String | -1 | Tempoh pulang awal atau kelewatan yang dikira sebagai ponteng kerja, dalam minit. |
| serious_late_minutes | String | -1 | Tempoh pulang awal atau kelewatan yang dikira sebagai serius, dalam minit. |
| rests | TopRestVo[] |  | Maklumat tempoh rehat. |
| check_type | String | OnDuty | Jenis rehat:   - **OnDuty**: Rehat bermula - **OffDuty**: Rehat tamat |
| across | Number | 1 | Sama ada masa rehat jatuh pada hari berikutnya:   - **0**: Hari yang sama - **1**: Hari berikutnya |
| check_time | String | 1970-01-01 05:00:00 | Masa rehat. |
| id | Number | 33928203 | ID titik rehat. |
| id | Number | 22979360 | ID bahagian daftar masuk. Satu pasangan daftar masuk dan daftar keluar membentuk satu bahagian. Satu syif boleh mengandungi beberapa bahagian. |
| shift_group_id | Number | demo | ID kumpulan syif. |
| owner | String | user123 | userId pemilik syif. |
| success | Boolean | true | Sama ada panggilan berjaya.   - **true**: Berjaya - **false**: Gagal |
| errcode | Number | 0 | Kod pemulangan. |
| errmsg | String | demo | Penerangan kod pemulangan. |
