Panggil API ini untuk mencipta item Tugasan bagi Kelulusan OA.

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/v1.0/workflow/processCentres/tasks |
| Kaedah HTTP | POST |
| Jenis aplikasi yang disokong | appType-Aplikasi dalaman　appType-Aplikasi perusahaan pihak ketiga |
| Kebenaran yang diperlukan | permission-qyapi_aflow-Kebenaran pengurusan data aliran kelulusan |

### Pengepala permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Dapatkan kredensial seperti berikut:   - Aplikasi dalaman: Panggil API [Dapatkan access token aplikasi dalaman](/ms/open/development/obtain-the-access-token-of-an-internal-app). - Aplikasi perusahaan pihak ketiga: Panggil API untuk mendapatkan access token organisasi yang telah memberikan kebenaran kepada Aplikasi pihak ketiga. |

### Isi permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| processInstanceId | String | Ya | ID Instans aliran kerja Kelulusan OA. Panggil API [Cipta instans](/ms/open/development/create-a-ticket-approval-instance) untuk mendapatkan nilai `processInstanceId`. |
| activityId | String | Tidak | ID nod kelulusan tersuai. Ini ialah parameter tersuai dengan panjang maksimum 256 aksara. |
| tasks | Array | Ya | Senarai tugasan. Maksimum: 20 elemen. |
| userId | String | Tidak | ID pengguna. Panggil API [Dapatkan senarai ID pengguna dalam jabatan](/ms/open/development/query-the-list-of-department-userids) untuk mendapatkannya. |
| url | String | Tidak | URL ubah hala item Tugasan. Panjang maksimum: 1,024 aksara.  - url dalam API penciptaan instans kelulusan mengubah hala ke Borang kelulusan dalam aplikasi Kelulusan DingTalk. - url dalam API ini mengubah hala daripada Kad Tugasan yang berkaitan pada halaman Tugasan DingTalk. - Halaman Tugasan DingTalk menyokong klien mudah alih dan PC. Pastikan halaman bagi url yang dihantar kepada API ini serasi dengan mudah alih dan PC. |
| customData | String | Tidak | Data pengguna tersuai. Data ini dikembalikan melalui parameter URL semasa ubah hala halaman. Panjang maksimum: 500 aksara. |
| dueTimestamp | Long | Tidak | Masa tamat tempoh tugasan, dalam bentuk Unix timestamp (milisaat). Apabila ditetapkan, pusat Tugasan DingTalk memaparkan masa tamat tempoh tugasan kelulusan, menyokong pengisihan mengikut masa tamat tempoh dan menyokong penapisan mengikut tag seperti Tamat Hari Ini dan Lewat Tempoh. |
| featureConfig | Object | Tidak | Konfigurasi integrasi Pusat Proses. Konfigurasikan, bagi setiap tugasan, entri butang tindakan pintasan dalam item Tugasan dan Notifikasi Kad. |
| features | Array | Tidak | Senarai konfigurasi. |
| name | String | Tidak | Nama modul ciri yang boleh disesuaikan oleh pihak ketiga. Yang disokong pada masa ini:   - **CUSTOM_SHORTCUT**: Butang tindakan pintasan dalam item Tugasan dan Notifikasi Kad |
| pcUrl | String | Tidak | Pautan ubah hala tersuai pihak ketiga untuk PC. Panjang maksimum: 1,024 aksara. |
| mobileUrl | String | Tidak | Pautan ubah hala tersuai pihak ketiga untuk mudah alih. Panjang maksimum: 1,024 aksara. |
| runType | String | Tidak | Mod jalanan.  Apabila features.name ialah `CUSTOM_SHORTCUT`, nilai berikut disokong:   - **ORIGIN**: Mod asli. Membuka halaman butiran Tugasan akan mengubah hala ke halaman butiran Kelulusan rasmi. - **REDIRECT**: Mod ubah hala luaran. Membuka halaman butiran Tugasan akan mengubah hala ke alamat yang dikonfigurasi dalam pcUrl atau mobileUrl. |
| callback | Object | Tidak | Konfigurasi Callback gateway. Wajib apabila butang tindakan pintasan diperlukan. API data luaran yang dipanggil semula melalui gateway mesti didaftarkan sebagai gateway dalam "Pengurusan Sumber Data". Untuk butiran, rujuk Cipta Sumber Data. |
| appUuid | String | Tidak | appUuid gateway. Wajib apabila butang tindakan pintasan diperlukan.  Hantar ID organisasi bagi Organisasi yang memiliki Sumber Data tersebut. |
| apiKey | String | Tidak | apiKey gateway. Wajib apabila entri butang tindakan pintasan diperlukan. Dapatkan `apiKey` daripada Sumber Data yang anda cipta.  - Apabila gateway memanggil semula API luaran, DingTalk mengembalikan parameter yang diperlukan untuk pemprosesan perniagaan kepada ISV berdasarkan senario perniagaan. Untuk menghuraikan parameter ini selepas menerima Permintaan Callback, ISV mesti mengkonfigurasikan kunci parameter yang berkaitan semasa mencipta Sumber Data.   Contohnya, apabila Callback dikonfigurasikan untuk modul pelaksanaan tugasan TASK_EXECUTE (butang Terima dan Tolak pada halaman butiran), DingTalk mengembalikan parameter tetap berikut: `&#123;"outResult":"agree","processInstanceId":"xxx","activityId":"xxx","corpId":"dingxxx","data":[],"remark":"Terima","title":"Permohonan perolehan aset yang diserahkan oleh xxx","taskId":111,"operator":"manager0001"&#125;`. - Semasa mencipta Sumber Data, ISV mesti mengkonfigurasikan kunci yang perlu dihuraikan berdasarkan keperluan perniagaan: outResult,processInstanceId,activityId,corpId,remark,title,taskId,operator |
| version | String | Tidak | Versi API gateway.  - Wajib apabila entri butang tindakan pintasan diperlukan. - Lalai: 1. |
| config | String | Tidak | Konfigurasi modul ciri yang disesuaikan oleh pihak ketiga. Panjang maksimum: 1,024 aksara. |

| --- | --- | --- |
| result | Array | Senarai hasil yang dikembalikan. |
