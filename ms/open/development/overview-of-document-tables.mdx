DingTalk Spreadsheet OpenAPI menyediakan satu set antara muka RESTful yang membolehkan pembangun mengendalikan Dokumen DingTalk Spreadsheet secara programatik. Gunakan API ini untuk mengautomasikan operasi baca/tulis data, mengurus Helaian Kerja, mencari Sel, mengunci julat, dan banyak lagi. Ia sesuai untuk senario seperti penyegerakan data, penjanaan Laporan, dan Automasi pejabat.

## Glosari

### workbookId

Pengecam unik bagi fail spreadsheet. Ia adalah `nodeId` (`dentryUuid`) yang dikembalikan oleh API Knowledge Base, dan juga boleh diperoleh daripada URL spreadsheet. Dapatkan dengan salah satu cara berikut:

- **Kaedah 1**: Dapatkan daripada URL spreadsheet.

- **Kaedah 2**: Dapatkan daripada maklumat Dokumen.

- **Kaedah 3**: Dapatkan melalui API Knowledge Base.

  Panggil API [Dapatkan nod](/open/development/get-knowledge-base-acquisition-node) atau [Cipta Dokumen Knowledge Base](/open/development/create-team-space-document). `nodeId` (`dentryUuid`) yang dikembalikan ialah `workbookId`.

### sheetId

ID atau Nama Helaian Kerja. Dapatkan melalui API [Dapatkan Semua Helaian Kerja](/open/development/obtain-all-worksheets), atau hantar Tajuk Helaian Kerja secara terus.

### rangeAddress

Alamat julat Sel, menggunakan notasi A1.

### operatorId

`unionId` bagi pengendali, digunakan untuk mengenal pasti pengguna yang melaksanakan Tindakan dan mengesahkan Kebenaran.
