Panggil API ini untuk memulakan rakaman awan bagi mesyuarat video.

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/conference/videoConferences/{conferenceId}/cloudRecords/start` |
| Kaedah HTTP | POST |
| Jenis aplikasi yang disokong | appType-Aplikasi dalaman　appType-Aplikasi perusahaan pihak ketiga |
| Kebenaran diperlukan | permission-VideoConference.Conference.Write-Kebenaran pengurusan maklumat Mesyuarat Video |

### Pengepala permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Dapatkan seperti berikut:   - Untuk Aplikasi dalaman, panggil API [Dapatkan access token aplikasi dalaman](/ms/open/development/obtain-the-access-token-of-an-internal-app#). - Untuk Aplikasi perusahaan pihak ketiga, panggil API [Dapatkan access token organisasi yang diberi kuasa untuk aplikasi pihak ketiga](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#). |

### Parameter laluan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| conferenceId | String | Ya | ID mesyuarat. Panggil API [Cipta mesyuarat video](/ms/open/development/create-a-video-conference#) untuk mendapatkan nilai parameter conferenceId. |

### Isi permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| unionId | String | Ya | unionId pengguna. Panggil API [Dapatkan butiran pengguna](/ms/open/development/query-user-details) untuk mendapatkan nilai parameter unionid.  **Nota**  Hanya Tuan Rumah mesyuarat yang mempunyai kebenaran untuk memulakan rakaman awan. |
| smallWindowPosition | String | Tidak | Kedudukan tetingkap kecil. Nilai yang sah:   - **relative_right**: Terpisah di sebelah kanan - **float_right**: Terapung di sebelah kanan - **float_bottom**: Terapung di bahagian bawah |
| mode | String | Tidak | Susun atur. Nilai yang sah:   - **grid**: Mod Grid - **speech**: Mod Penceramah - **full_screen**: Mod Skrin Penuh |

### Kod ralat

Jika ralat dikembalikan semasa anda memanggil API ini, cari penyelesaiannya dalam dokumen [Kod ralat global](/ms/open/development/server-api-error-codes-1) berdasarkan mesej ralat.

| HttpCode | Kod ralat | Mesej ralat | Penerangan |

| 400 | paramsError | error:%s | Ralat parameter. |
| 404 | recordStartError | recordStartError:%s | Gagal memulakan rakaman. |
| 404 | recordStartPermissionError | permissionError:%s | Gagal memulakan rakaman disebabkan isu kebenaran. |
| 500 | systemError | systemError:%s | Ralat dalaman bahagian pelayan. |
