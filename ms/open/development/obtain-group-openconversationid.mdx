# Dapatkan OpenConversationId sesuatu sembang kumpulan

## Penerangan panggilan API

Jika anda tidak menyimpan OpenConversationId semasa memanggil API [Cipta sembang kumpulan](https://open.dingtalk.com/document/development/create-group-session#), anda boleh memanggil API ini untuk mendapatkan semula OpenConversationId menggunakan chatId.

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/im/chat/{chatId}/convertToOpenConversationId` |
| Kaedah HTTP | POST |
| Jenis aplikasi disokong | appType-Aplikasi dalaman |
| Kebenaran diperlukan | permission-qyapi_chat_read-Kebenaran Telah dibaca untuk maklumat asas Kumpulan DingTalk |

### Pengepala permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Dapatkan dengan memanggil API [Dapatkan access token aplikasi dalaman](/open/development/obtain-the-access-token-of-an-internal-app#). |

### Parameter laluan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| chatId | String | Ya | chatId Sembang Kumpulan. Dapatkan nilai chatId dengan memanggil API [Cipta sembang kumpulan](https://open.dingtalk.com/document/development/create-group-session#). |
