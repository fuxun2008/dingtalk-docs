Panggil API ini untuk memadam penapis global pada Helaian Kerja tertentu supaya semua rekod yang tersembunyi akibat syarat penapis dipaparkan semula. Ini sesuai untuk senario yang memerlukan anda mengosongkan keadaan penapis semasa dan memulihkan paparan data penuh—contohnya, membuang penapis sebelum mengeksport data bagi memastikan set data penuh dieksport.

## Penerangan panggilan API

Selepas panggilan berjaya, syarat penapis dan keadaan susunan semua lajur turut dikosongkan.

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/doc/workbooks/{workbookId}/sheets/{sheetId}/deleteFilter` |
| Kaedah HTTP | POST |
| Jenis aplikasi disokong | appType-Aplikasi dalaman |
| Kebenaran diperlukan | permission-Document.Workbook.Write-Kebenaran menulis DingTalk Spreadsheet |

### Pengepala permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Panggil API [Dapatkan access token aplikasi dalaman](/open/development/obtain-the-access-token-of-an-internal-app) untuk mendapatkannya. |

### Parameter laluan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| workbookId | String | Ya | ID fail spreadsheet. `nodeId(dentryUuid)` yang dikembalikan oleh [API Knowledge Base](/open/development/knowledge-base-overview) ialah `workbookId` bagi spreadsheet tersebut. Anda boleh mendapatkannya dengan memanggil API [Dapatkan nod](https://open.dingtalk.com/document/orgapp/get-node) dan [Cipta dokumen Knowledge Base](/open/development/create-team-space-document). |
| sheetId | String | Ya | ID atau nama Helaian Kerja. Panggil API [Dapatkan semua Helaian Kerja](/open/development/obtain-all-worksheets) untuk mendapatkan nilai parameter id atau name. |

### Parameter pertanyaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| operatorId | String | Ya | unionId pengendali.   - Panggil API [Dapatkan maklumat pengguna menggunakan kod log masuk senyap](/open/development/obtain-the-userid-of-a-user-by-using-the-log-free) untuk mendapatkan nilai parameter unionid. - Panggil API [Tanya butiran pengguna](/open/development/query-user-details) untuk mendapatkan nilai parameter unionid.       Jika pengendali tidak mempunyai kebenaran, API akan mengembalikan ralat `The operator has no permission`. |

### Kod ralat

Jika panggilan API mengembalikan ralat, semak penyelesaian dalam dokumentasi [Kod ralat global](/open/development/server-api-error-codes-1) berdasarkan mesej ralat tersebut.

| HttpCode | Kod ralat | Mesej ralat | Penerangan |
| --- | --- | --- | --- |
| 400 | invalidRequest.inputArgs.invalid | %s | Parameter permintaan tidak sah. Semak mesej ralat. |
| 400 | invalidRequest.inputArgs.workbookIdIllegal | The workbookId is illegal. | workbookId tidak sah. |
| 400 | invalidRequest.resource.notWorkbook | %s | Jenis dokumen tidak disokong. Semak workbookId. |
| 400 | invalidRequest.document.stillInitializing | The document is still initializing. Please try again later. | Dokumen masih dalam proses inisialisasi. Cuba lagi kemudian. |
| 403 | forbidden.accessDenied | The operator has no permission. | Pengguna semasa tidak mempunyai kebenaran untuk operasi ini. |
| 403 | forbidden.acrossOrg | %s | Permintaan tidak sah. Semak sama ada dokumen yang cuba diakses adalah milik Organisasi yang ditentukan oleh access token. |
| 403 | forbidden.operationIllegal | %s | Operasi yang diminta tidak sah. Semak mesej ralat. |
| 403 | forbidden.document.sizeOverLimit | The document size is over limit and the server is unable to complete your request. Retry is unlikely to work unless the document size is decreased. | Kandungan spreadsheet terlalu besar. Cuba kurangkan kandungan. |
| 404 | invalidRequest.resource.notFound | %s | Permintaan gagal. Sumber yang diminta tidak dapat ditemui. |
| 500 | serviceBusy | The server is busy and unable to complete your request. Please try again later. | Perkhidmatan sedang sibuk. Cuba lagi kemudian. |
| 500 | internalError | The server encountered an internal error and was unable to complete your request. Please try again later. | Ralat dalaman pelayan berlaku. Cuba lagi kemudian. |
