Panggil API ini untuk mendapatkan semua rekod perubahan baki cuti seseorang pekerja. Rekod merangkumi permulaan baki cuti, kuota yang digunakan oleh pekerja dan kemas kini baki cuti.

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/v1.0/attendance/vacations/records/query |
| Kaedah HTTP | POST |
| Jenis aplikasi yang disokong | appType-Aplikasi dalaman　appType-Aplikasi perusahaan pihak ketiga |
| Kebenaran | permission-qyapi_holiday_readonly-Kebenaran pertanyaan cuti DingTalk |

### Pengepala permintaan

| Nama | Jenis | Wajib | Keterangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Dapatkannya seperti berikut:   - Aplikasi dalaman: Panggil API [Dapatkan access token aplikasi dalaman](/ms/open/development/obtain-the-access-token-of-an-internal-app). - Aplikasi perusahaan pihak ketiga: Panggil API untuk mendapatkan access token organisasi yang telah memberikan kebenaran kepada aplikasi pihak ketiga. |

### Isi permintaan

| Nama | Jenis | Wajib | Keterangan |
| --- | --- | --- | --- |
| opUserId | String | Ya | userId admin dalam Organisasi Anda yang mempunyai Kebenaran aplikasi Kelulusan OA. Hantar userId Super Admin. Panggil API [Dapatkan senarai admin](/ms/open/development/query-the-administrator-list) dan gunakan medan `userId` Super Admin dalam respons. |
| leaveCode | String | Ya | Pengecam unik jenis cuti. Panggil API [Pertanyaan senarai peraturan cuti](/ms/open/development/holiday-type-query) untuk mendapatkan nilai `leave_code`. |
| userIds | Array of String | Ya | Senarai userId pekerja yang hendak ditanya. Hantar sehingga 50 userId bagi setiap panggilan. |
| pageNumber | Long | Ya | Kursor penomboran:   - Untuk pertanyaan pertama, hantar 0. - Untuk pertanyaan seterusnya, hantar offset kumulatif daripada pertanyaan sebelumnya. |
| pageSize | Integer | Ya | Offset penomboran. Maksimum: 200. |

## Respons

### Isi respons

| Nama | Jenis | Keterangan |
| --- | --- | --- |
| result | Object | Hasil yang dikembalikan. |
| hasMore | Boolean | Sama ada terdapat lebih banyak hasil.   - **true**: Terdapat lebih banyak hasil. - **false**: Tiada lagi hasil. |
| leaveRecords | Array | Senarai rekod penggunaan cuti. |
| userId | String | userId pekerja. |
| leaveCode | String | Pengecam unik jenis cuti. |
| recordId | String | Pengecam unik rekod penggunaan cuti. |
| quotaId | String | Pengecam unik kuota cuti. |
| calType | String | Jenis pengiraan.   - **insert**: Rekod baharu - **add**: Ditambah - **delete**: Dipadam - **update**: Dikemas kini - **null** (atau medan tidak dikembalikan): Digunakan oleh permohonan cuti |
| startTime | Long | Masa mula tempoh sah kuota atau permohonan cuti, sebagai Cap masa dalam milisaat. |
| endTime | Long | Masa tamat tempoh sah kuota atau permohonan cuti, sebagai Cap masa dalam milisaat. |
| leaveViewUnit | String | Unit paparan.   - **day**: Hari - **hour**: Jam |
| leaveReason | String | Sebab. |
| leaveRecordType | String | Jenis rekod cuti.   - **leave**: Permohonan cuti - **update**: Kemas kini kuota - **modify_quota**: Permulaan baki atau kemas kini baki |
| leaveStatus | String | Status permohonan cuti.   - **init**: Permohonan cuti sedang menunggu. - **success**: Permohonan cuti diluluskan. - **refuse**: Permohonan cuti ditolak. - **abort**: Permohonan cuti ditarik balik. - **revoke**: Permohonan cuti telah diluluskan, kemudian permohonan pembatalannya diterima. |
| recordNumPerDay | Long | Kuota yang digunakan, dikira dalam hari.   - **Nota**  Apabila jenis cuti dikira mengikut hari, nilai ini tidak kosong dan diukur dalam perseratus hari. Contohnya, 1000 = 10 hari. |
| recordNumPerHour | Long | Kuota yang digunakan, dikira dalam jam.   - **Nota**  Apabila jenis cuti dikira mengikut jam, nilai ini tidak kosong dan diukur dalam perseratus jam. Contohnya, 1000 = 10 jam. |
| gmtCreate | Long | Masa dicipta rekod, sebagai Cap masa dalam milisaat. |
| gmtModified | Long | Masa pengubahsuaian rekod, sebagai Cap masa dalam milisaat. |
| opUserId | String | ID pengendali rekod. |
| success | Boolean | Sama ada permintaan berjaya.   - **true**: Ya - **false**: Tidak |

### Kod ralat

Jika panggilan API ini gagal, cari penyelesaian dalam dokumen [Kod ralat global](/ms/open/development/server-api-error-codes-1) berdasarkan mesej ralat.

| HttpCode | Kod ralat | Mesej ralat | Keterangan |
| --- | --- | --- | --- |
| 400 | userNotExist | Pengguna tidak wujud | Pengguna tidak wujud. |
| 400 | leaveOpuserIdIsNotAdmin | Bukan admin hanya boleh membuat pertanyaan maklumat sendiri | Bukan admin hanya boleh membuat pertanyaan maklumat sendiri. |
| 400 | leaveTypeNotFound | Jenis cuti tidak ditemui | Jenis cuti tidak ditemui. |
| 400 | paramterInvalid | Ralat parameter | Parameter opUserId dan userId tidak boleh kosong. |
| 400 | leaveUserIdListMax | Maksimum 50 rekod boleh ditanya pada satu masa | Tanya sehingga 50 userId pekerja pada satu masa. |
| 400 | pageIndexIllegal | Ralat parameter penomboran | Parameter penomboran mestilah integer bukan negatif bermula daripada 0. |
| 400 | pageSizeIllegal | Saiz halaman melebihi had | Saiz halaman maksimum ialah 200. |
| 400 | noPermission | Tiada kebenaran akses | Tiada kebenaran akses. |
