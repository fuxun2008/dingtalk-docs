Panggil API ini untuk memaklumkan DingTalk bahawa sesuatu kelulusan telah diluluskan. Jenis yang disokong ialah kerja lebih masa, cuti, keluar pejabat dan perjalanan perniagaan.

## Penerangan panggilan API

Contohnya, seorang pekerja dijadualkan bekerja dari 8:00 hingga 18:00 hari ini. Pekerja itu menghantar permohonan cuti melalui sistem kelulusan organisasi sendiri. Selepas permohonan diluluskan, panggil API ini untuk memaklumkan DingTalk Attendance. Pekerja tidak perlu daftar masuk hari ini dan tidak ditanda sebagai tidak hadir. Status pekerja dipaparkan sebagai cuti. Dalam contoh lain, pekerja Xiaoding tidak daftar masuk pada 15 November, dan statistik kehadiran merekodkan daftar masuk terlepas ini.

Panggil API ini untuk memaklumkan DingTalk bahawa sesuatu kelulusan telah diluluskan. Tindakan ini menukar kehadiran Xiaoding pada 15 November kepada cuti, perjalanan perniagaan atau kerja lebih masa.

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/v1.0/attendance/approvals/finish |
| Kaedah HTTP | POST |
| Jenis aplikasi yang disokong | appType-Aplikasi dalaman　appType-Aplikasi perusahaan pihak ketiga |
| Kebenaran yang diperlukan | permission-qyapi_attendance_group_read-Kebenaran pertanyaan kumpulan kehadiran |

### Pengepala permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Dapatkannya seperti berikut:   - Aplikasi dalaman: panggil API [Dapatkan access token aplikasi dalaman](/ms/open/development/obtain-the-access-token-of-an-internal-app). - Aplikasi perusahaan pihak ketiga: panggil API Dapatkan access token organisasi yang diberi kebenaran kepada aplikasi pihak ketiga. |

### Parameter pertanyaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| userId | String | Tidak | userId pekerja. |

### Isi permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| topCalculateApproveDurationParam | Object | Tidak | Parameter input berkaitan tempoh. |
| bizType | Long | Tidak | Jenis borang kelulusan. Nilai yang sah:   - **1**: Kerja lebih masa - **2**: Perjalanan perniagaan atau keluar pejabat - **3**: Cuti |
| fromTime | String | Tidak | Masa mula. Masa mula tidak boleh lebih daripada 31 hari sebelum masa semasa.  Format yang disokong:   - 2019-08-15 - 2019-08-15 AM - 2019-08-15 12:43 |
| toTime | String | Tidak | Masa tamat.  Format yang disokong:   - 2019-08-15 - 2019-08-15 AM - 2019-08-15 12:43   **Nota**  - Masa tamat tidak boleh lebih awal daripada masa mula. - Julat masa tidak boleh melebihi 360 hari. - Bilangan hari antara masa mula dan masa tamat tidak boleh melebihi 31. - Apabila `biz_type` ialah 1, bilangan hari antara masa mula dan masa tamat tidak boleh melebihi 1. |
| durationUnit | String | Tidak | Unit tempoh. Nilai yang disokong:   - **day** - **halfDay** - **hour**: Apabila `biz_type` ialah 1, hanya hour disokong.   Format masa mesti sepadan dengan unit tempoh:   - 2019-08-15 sepadan dengan day - 2019-08-15 AM sepadan dengan halfDay - 2019-08-15 12:43 sepadan dengan hour |
| calculateModel | Long | Tidak | Kaedah pengiraan:   - **0**: Kira mengikut hari kalendar - **1**: Kira mengikut hari bekerja |
| leaveCode | String | Tidak | Pengecam unik peraturan cuti. Pilihan.  **Nota**  Hantar nilai yang tidak kosong hanya apabila `bizType=3` (cuti). Tempoh kemudian dibundarkan mengikut peraturan pembundaran yang ditetapkan untuk jenis cuti tersebut. |
| timeZoneId | String | Tidak | ID zon waktu, dalam format `Asia/Shanghai`. |
| tagName | String | Tidak | Nama jenis borang kelulusan, maksimum 20 aksara. Nilai yang disokong: 请假 (cuti), 出差 (perjalanan perniagaan), 外出 (keluar pejabat), 加班 (kerja lebih masa). |
| subType | String | Tidak | Nama subjenis, maksimum 64 aksara.  **Nota**  Parameter ini wajib apabila jenis borang kelulusan biz_type ialah 3. |
| approveId | String | Tidak | ID borang kelulusan, maksimum 100 aksara. Nilai tersuai.  **Nota**  Aplikasi perusahaan pihak ketiga mesti menyimpan nilai ini. Nilai ini wajib semasa memaklumkan pembatalan kelulusan. Panggilan semula API ini dengan approveId yang sama akan melaksanakan kemas kini. |
| jumpUrl | String | Tidak | URL ubah hala borang kelulusan, maksimum 200 aksara.  **Nota**  Apabila pengguna mengklik entri aplikasi perusahaan pihak ketiga pada halaman statistik kehadiran, DingTalk mengubah hala mereka ke URL ini. Hantar URL halaman butiran borang kelulusan. |
| overtimeDuration | String | Tidak | Wajib apabila biz_type ialah 1. Tempoh kerja lebih masa, dalam jam. |
| overTimeToMore | Long | Tidak | Wajib apabila biz_type ialah 1:   - **1**: Tukar kerja lebih masa kepada cuti ganti - **2**: Tukar kerja lebih masa kepada bayaran |

```java
                });
                if (!AlibabaCloud.TeaUtil.Common.Empty(err.Code) && !AlibabaCloud.TeaUtil.Common.Empty(err.Message))
                {
                    // err mengandungi atribut code dan message untuk membantu pembangun mengenal pasti masalah
                }
            }
        }

    }
}
```

## Respons

### Isi respons

| Nama | Jenis | Penerangan |
| --- | --- | --- |
| result | Object | Hasil yang dikembalikan. |
| duration | double | Jumlah tempoh. Unit medan ini sepadan dengan unit yang ditetapkan untuk borang kelulusan berkaitan dalam organisasi anda. |
| durationDetail | Array | Butiran. |
| date | String | Tarikh kelulusan diluluskan. |
| duration | double | Tempoh harian. |
| success | Boolean | Sama ada panggilan API berjaya. |

### Contoh isi respons

```text
HTTP/1.1 200 OK
Content-Type:application/json

{
  "result" : {
    "duration" : 2,
    "durationDetail" : [ {
      "date" : "2019-08-15",
      "duration" : 1
    } ]
  },
  "success" : true
}
```
