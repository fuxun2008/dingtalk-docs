---
title: "Semak Kendiri Aplikasi Anda"
description: "Pelajari langkah semak kendiri aplikasi DingTalk sebelum penyenaraian, termasuk tetapan IP pelayan, jenis push, dan metrik kestabilan yang diperlukan."
---

## **Prosedur**

1. Log masuk ke [Developer Console](https://open-dev.dingtalk.com/), kemudian klik aplikasi yang disasarkan untuk membuka halaman butirannya.
2. Pada halaman butiran aplikasi, klik **App Release > App Self-Check**.
3. Klik Mula Semak untuk melengkapkan semak kendiri ciri.

   | Item Semakan | Penerangan |
   | --- | --- |
   | Sama ada IP keluar pelayan telah ditetapkan | Tetapkan IP keluar pelayan dalam **Konfigurasi Pembangunan > Pusat Keselamatan** aplikasi. |
   | Sama ada URL halaman utama aplikasi atau Admin Console menggunakan HTTPS | URL halaman utama aplikasi atau Admin Console mesti menggunakan protokol HTTPS. |
   | Sama ada jenis push yang sah telah ditetapkan | Lengkapkan tetapan push dalam maklumat pembangunan aplikasi. Jika anda menggunakan push SyncHTTP, URL callback mesti menggunakan [domain selamat DingTalk](/open/development/configure-update-secure-domain-name). |
   | Sama ada Monitoring Center telah disambungkan | Sambung ke Monitoring Center dan jana data pemantauan. |
   | Sama ada pelayan dilancarkan di Alibaba Cloud | Pilih kaedah pelancaran yang betul. |
4. Selepas semak kendiri ciri selesai, klik **Seterusnya** untuk meneruskan ke semakan keselamatan. Rujuk Security Access Evaluation, kemudian isi dan hantar bahan untuk item penilaian semakan keselamatan yang diperlukan bagi penyenaraian aplikasi.
5. Selepas penghantaran, pergi ke halaman pemantauan kestabilan. Untuk keperluan terperinci, rujuk Stability Certification Standards.

   | **Metrik Data** | **Penerangan** | **Keperluan Metrik** |
   | --- | --- | --- |
   | Kadar kejayaan API dalam Monitoring Center | Lihat dalam Monitoring Center di bawah **Metrik Pemantauan** > **Permintaan API** > **Kadar Kejayaan**. | ≥98.99% |
   | Kependaman purata API dalam Monitoring Center | Lihat dalam Monitoring Center di bawah **Metrik Pemantauan** > **Permintaan API** > **Kependaman Permintaan**. | &lt;300 |
   | Kadar ralat JS dalam Monitoring Center | Lihat dalam Monitoring Center di bawah **Metrik Pemantauan** > **Ralat JS** > **Nisbah Bilangan Ralat kepada PV**. | &lt;1.99% |
   | Kadar skrin kosong dalam Monitoring Center | Lihat dalam Monitoring Center di bawah **Metrik Pemantauan** > **Ralat Skrin Kosong** > **Kadar Skrin Kosong**. | &lt;1.99% |
   | Kadar kejayaan dd.config | Kadar kejayaan purata harian bagi panggilan kepada SAPI **dd.config**. | ≥98.99% |
   | Kadar kejayaan push HTTP | Apabila jenis push ialah Stream atau SyncHttp, ini merujuk kepada kadar kejayaan push DingTalk ke URL callback dalam tempoh statistik (**push yang mengambil masa lebih daripada 1,500 ms dikira sebagai kegagalan timeout**). | ≥98.99% |
6. Selepas pemantauan kestabilan selesai, klik **Semak Kendiri Selesai**, kemudian **Hantar untuk Penyenaraian**.

## **Langkah Seterusnya**

Selepas menghantar aplikasi anda untuk penyenaraian, isi maklumat penyenaraian aplikasi. Rujuk List Your Product.
