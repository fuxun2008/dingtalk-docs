Panggil API ini untuk membuat pertanyaan pukal maklumat penjadualan syif pekerja pada hari tertentu.

## Permintaan

| **Maklumat asas** | |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/topapi/attendance/schedule/listbyusers |
| Kaedah HTTP | POST |
| Jenis aplikasi yang disokong | appType-Aplikasi dalaman　appType-Aplikasi perusahaan pihak ketiga |
| Kebenaran yang diperlukan | qyapi_attendance_group_read: Kebenaran pertanyaan kumpulan kehadiran |

### Parameter pertanyaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | bE74xxxx | Kelayakan aplikasi yang digunakan untuk memanggil API ini. <br/>- Bagi Aplikasi dalaman, dapatkannya dengan memanggil [Dapatkan access_token Aplikasi dalaman](/ms/open/development/obtain-orgapp-token). <br/>- Bagi Aplikasi perusahaan pihak ketiga, dapatkannya dengan memanggil API yang mendapatkan access_token organisasi pihak ketiga. |

### Isi permintaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| op_user_id | String | Ya | user456 | ID pengguna pengendali. |
| userids | String | Ya | user123 | Senarai ID pengguna yang hendak ditanya. Pisahkan berbilang ID pengguna dengan koma. Hantar maksimum 50 ID pengguna pada satu masa. |
| from_date_time | Number | Ya | 1565591096000 | Tarikh mula, dalam format Unix timestamp (milisaat). <br/>**Nota** <br/>- Selang antara masa mula dengan masa tamat tidak boleh melebihi 7 hari. <br/>- Masa pertanyaan mestilah dalam tempoh 180 hari yang lalu. |
| to_date_time | Number | Ya | 1565591096000 | Tarikh tamat, dalam format Unix timestamp (milisaat). <br/>**Nota** <br/>- Selang antara masa mula dengan masa tamat tidak boleh melebihi 7 hari. <br/>- Masa pertanyaan mestilah dalam tempoh 180 hari yang lalu. |

### Contoh permintaan

```curl
curl -X POST "https://api.dingtalk.io/topapi/attendance/schedule/listbyusers" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=9ad3xxxx82a10' \
-d 'from_date_time=1565591096000' \
-d 'op_user_id=dd_dd' \
-d 'to_date_time=1565591096000' \
-d 'userids=dd_dd%2Cduogui'
```

## Respons

### Isi respons

| Nama | Jenis | Contoh | Penerangan |
| --- | --- | --- | --- |
| result | TopScheduleVo[] | demo | Hasil pertanyaan. |
| check_type | String | OnDuty | Jenis kehadiran: <br/>- **Onduty**: Daftar masuk pada permulaan waktu kerja <br/>- **OffDuty**: Daftar keluar pada akhir waktu kerja |
| plan_check_time | Date | 2021-01-14 09:00:00 | Masa daftar masuk yang dijadualkan. |
| group_id | Number | 394775001 | ID kumpulan kehadiran. |
| userid | String | user456 | ID pengguna. |
| approve_id | Number | 1234 | ID borang kelulusan yang dikaitkan dengan jadual. <br/>**Nota** <br/>Medan ini tidak dikembalikan jika tiada borang kelulusan untuk hari tersebut. |
| work_date | Date | 2021-01-14 00:00:00 | Hari bekerja, iaitu hari khusus bagi jadual tersebut. |
| id | Number | 56676915454 | ID jadual. |
| shift_version | Number | 588655171 | Versi syif. |
| shift_id | Number | 677995086 | ID syif. Nilai 0 menunjukkan hari rehat. |
| is_rest | String | N | Menunjukkan sama ada hari tersebut ialah hari rehat: <br/>- **Y**: Hari tersebut dijadualkan sebagai hari rehat <br/>- **N**: Hari tersebut bukan hari rehat |
| success | Boolean | true | Menunjukkan sama ada permintaan berjaya. <br/>- **true**: Berjaya <br/>- **false**: Gagal |
| errcode | Number | 0 | Kod pemulangan. |
| errmsg | String | ok | Mesej pemulangan. |
| request_id | String | qkqbwcw3bq2 | ID permintaan. |
