Panggil API ini untuk memadam syif kehadiran berdasarkan ID syif.

## Permintaan

| **Maklumat asas** | |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/topapi/attendance/shift/delete |
| Kaedah HTTP | POST |
| Jenis aplikasi yang disokong | appType-Aplikasi dalaman |
| Kebenaran yang diperlukan | permission-qyapi_attendance_group_manage-Kebenaran pengurusan kumpulan kehadiran |

### Parameter pertanyaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | af21xxx | Kelayakan aplikasi yang digunakan untuk memanggil API ini. Dapatkannya dengan memanggil API [Dapatkan access_token Aplikasi dalaman](/ms/open/development/obtain-orgapp-token). |

### Isi permintaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| op_user_id | String | Ya | user123 | userId pengendali. |
| shift_id | Number | Ya | 2423 | ID syif. Dapatkan nilai parameter id dengan memanggil API [Dapatkan ringkasan syif](/ms/open/development/enterprise-shift-query-in-batches). |

### Contoh permintaan

```curl
curl -X POST "https://api.dingtalk.io/topapi/attendance/shift/delete" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=032bc0xxxxc460ee' \
-d 'op_user_id=abc' \
-d 'shift_id=2423'
```

Java

```text
DingTalkClient client = new DefaultDingTalkClient("https://api.dingtalk.io/topapi/attendance/shift/delete");
OapiAttendanceShiftDeleteRequest req = new OapiAttendanceShiftDeleteRequest();
req.setOpUserId("user456");
req.setShiftId(2423L);
OapiAttendanceShiftDeleteResponse rsp = client.execute(req, access_token);
System.out.println(rsp.getBody());
```


## Respons

### Isi respons

| Nama | Jenis | Contoh | Penerangan |
| --- | --- | --- | --- |
| errmsg | String | Ralat sistem | Mesej ralat yang dikembalikan apabila panggilan gagal. |
| errcode | Number | 0 | Kod pemulangan. |
| success | Boolean | true | Menunjukkan sama ada panggilan berjaya.   - **true**: Berjaya - **false**: Gagal |
| request_id | String | 16apb7hw85jjw | ID permintaan. |

### Contoh isi respons

```json
{
  "errcode": 0,
  "success": true,
  "request_id": "3lupjm5o0j7g"
}
```

### Kod ralat

Jika panggilan mengembalikan ralat, cari penyelesaian dalam dokumen [Kod ralat global](/ms/open/development/server-api-error-codes-1) berdasarkan mesej ralat.
