Panggil API ini untuk mendapatkan maklumat semua Helaian Kerja dalam spreadsheet yang ditetapkan, termasuk ID Helaian Kerja dan nama Helaian Kerja.

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/doc/workbooks/{workbookId}/sheets` |
| Kaedah HTTP | GET |
| Jenis aplikasi disokong | appType-Aplikasi dalaman |
| Kebenaran diperlukan | permission-Document.Workbook.Read-Kebenaran baca spreadsheet |

### Header permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses yang digunakan untuk memanggil API ini. Dapatkan dengan memanggil API [Dapatkan access token aplikasi dalaman](/ms/open/development/obtain-the-access-token-of-an-internal-app#). |

### Parameter laluan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| workbookId | String | Ya | ID fail spreadsheet. `nodeId(dentryUuid)` yang dikembalikan oleh [API Knowledge Base](/ms/open/development/knowledge-base-overview#) adalah `workbookId` bagi spreadsheet tersebut. Dapatkan dengan memanggil API [Dapatkan nod](https://open.dingtalk.com/document/development/get-node#) dan [Cipta dokumen Knowledge Base](/ms/open/development/create-team-space-document#). |

### Parameter kueri

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| operatorId | String | Ya | unionId bagi operator.   - Dapatkan nilai parameter unionid dengan memanggil API [Dapatkan maklumat pengguna melalui kod log masuk senyap](/ms/open/development/obtain-the-userid-of-a-user-by-using-the-log-free#). - Dapatkan nilai parameter unionid dengan memanggil API [Tanya butiran pengguna](/ms/open/development/query-user-details#).     Jika operator tidak mempunyai kebenaran yang diperlukan, API akan mengembalikan ralat `The operator has no permission`. |

GET /v1.0/doc/workbooks/e54Lq3xxx/sheets?operatorId=ppgAxxx HTTP/1.1

x-acs-dingtalk-access-token:xxxxx
