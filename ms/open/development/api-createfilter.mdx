title: "Cipta penapis"
description: "Panggil API ini untuk mencipta penapis global dengan julat yang ditentukan pada helaian kerja sasaran dalam Hamparan DingTalk, sesuai untuk senario penapisan peringkat rekod seperti memaparkan data mengikut wilayah atau status."
---

Panggil API ini untuk mencipta penapis global pada helaian kerja yang ditentukan dalam Hamparan DingTalk dan menetapkan julat penapis. Ini sesuai untuk senario yang memerlukan penapisan rekod terhadap data hamparan, seperti hanya memaparkan data bagi wilayah atau status tertentu dalam laporan jualan.

## Penerangan panggilan API

- Selepas panggilan berjaya, anda boleh memanggil API untuk menetapkan kriteria penapis bagi mengkonfigurasikan peraturan penapis untuk setiap lajur. Rekod yang tidak memenuhi kriteria akan disembunyikan secara automatik.
- Setiap helaian kerja hanya boleh mempunyai satu penapis global. Jika penapis sudah wujud, ralat akan dikembalikan.

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/doc/workbooks/{workbookId}/sheets/{sheetId}/createFilter` |
| Kaedah HTTP | POST |
| Jenis aplikasi disokong | appType-Aplikasi dalaman |
| Kebenaran | permission-Document.Workbook.Write-Kebenaran tulis Hamparan DingTalk |

### Pengepala permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Panggil API [Dapatkan access token aplikasi dalaman](/ms/open/development/obtain-the-access-token-of-an-internal-app) untuk mendapatkannya. |

### Parameter laluan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| workbookId | String | Ya | ID fail hamparan. `nodeId(dentryUuid)` yang dikembalikan oleh API [Knowledge Base](/ms/open/development/knowledge-base-overview) adalah `workbookId` bagi hamparan tersebut. Anda boleh memanggil API [Dapatkan nod](https://open.dingtalk.com/document/orgapp/get-node) dan [Cipta dokumen Knowledge Base pasukan](/ms/open/development/create-team-space-document) untuk mendapatkannya. |
| sheetId | String | Ya | ID atau nama helaian kerja. Panggil API [Dapatkan semua helaian kerja](/ms/open/development/obtain-all-worksheets) untuk mendapatkan nilai parameter id atau name. |

### Parameter pertanyaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| operatorId | String | Ya | unionId bagi pengendali.   - Panggil API [Dapatkan maklumat pengguna melalui kod log masuk senyap](/ms/open/development/obtain-the-userid-of-a-user-by-using-the-log-free) untuk mendapatkan nilai parameter unionid. - Panggil API [Pertanyaan butiran pengguna](/ms/open/development/query-user-details) untuk mendapatkan nilai parameter unionid.       Jika pengendali tidak mempunyai kebenaran, API akan mengembalikan ralat `The operator has no permission`. |

### Isi permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| range | String | Ya | Julat penapis, dalam notasi A1. Contohnya, `A1:D10` menunjukkan kawasan daripada A1 hingga D10. Rekod pertama dalam julat penapis dianggap sebagai rekod tajuk dan tidak disertakan dalam pengiraan penapis. |
| criteria | `Map<String, Object>` | Tidak | Pilihan. Menetapkan kriteria penapis bagi setiap lajur semasa mencipta penapis. Kunci ialah offset lajur (string bermula daripada 0, relatif kepada medan utama julat penapis), dan nilai ialah objek kriteria penapis (FilterCriteria) bagi lajur tersebut. Jika tidak diberikan, penapis kosong akan dicipta. |
|  | Object | Tidak | Kriteria penapis bagi lajur semasa. |
| filterType | String | Tidak | Jenis penapis. Nilai yang sah:   - **values**: Penapis mengikut nilai. - **color**: Penapis mengikut warna. - **condition**: Penapis mengikut syarat. |
| visibleValues | Array of String | Tidak | Nilai yang boleh dilihat. |
| conditions | Array | Tidak | Array syarat penapis. Maksimum 2 syarat dibenarkan. Diperlukan hanya apabila `filterType` ialah `condition`. |
| operator | String | Tidak | Operator syarat. Nilai yang sah:   - **equal**: Sama dengan. - **not-equal**: Tidak sama dengan. - **contains**: Mengandungi. - **not-contains**: Tidak mengandungi. - **starts-with**: Bermula dengan. - **not-starts-with**: Tidak bermula dengan. - **ends-with**: Berakhir dengan. - **not-ends-with**: Tidak berakhir dengan. - **greater**: Lebih besar daripada. - **greater-equal**: Lebih besar daripada atau sama dengan. - **less**: Kurang daripada. - **less-equal**: Kurang daripada atau sama dengan. |
| value | String | Tidak | Nilai syarat. |
| conditionOperator | String | Tidak | Hubungan antara pelbagai syarat: `"and"` (lalai) atau `"or"`. Diperlukan hanya apabila `filterType` ialah `condition`. |
| backgroundColor | String | Tidak | Penapis mengikut warna latar belakang. Nilai warna perenambelasan, seperti `"#FF0000"`. Diperlukan hanya apabila `filterType` ialah `color`. |
| fontColor | String | Tidak | Penapis mengikut warna fon. Nilai warna perenambelasan, seperti `"#0000FF"`. Diperlukan hanya apabila `filterType` ialah `color`. |
