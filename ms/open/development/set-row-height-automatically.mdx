Panggil API ini untuk melaraskan secara automatik ketinggian baris yang ditentukan dalam Hamparan DingTalk berdasarkan saiz fon yang diberikan, untuk memastikan kandungan dipaparkan dengan lengkap.

## Penerangan panggilan API

- Secara automatik melaraskan ketinggian baris bagi setiap baris dalam julat yang ditentukan berdasarkan `fontWidth` (saiz fon) yang diberikan, untuk memastikan kandungan dipaparkan dengan lengkap.
- Gunakan `row` (cursor baris permulaan) dan `rowCount` (bilangan baris) untuk menentukan julat baris yang perlu dilaraskan secara automatik.
- Cursor baris bermula daripada 0. Ini bermakna cursor baris pertama adalah 0.

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/doc/workbooks/{workbookId}/sheets/{sheetId}/autofitRows` |
| Kaedah HTTP | POST |
| Jenis aplikasi yang disokong | appType-Aplikasi dalaman |
| Kebenaran yang diperlukan | permission-Document.Workbook.Write-Kebenaran tulis Hamparan DingTalk |

### Pengepala permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses yang digunakan untuk memanggil API ini. Anda boleh mendapatkannya dengan memanggil API [Dapatkan access token aplikasi dalaman](/open/development/obtain-the-access-token-of-an-internal-app). |

### Parameter laluan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| workbookId | String | Ya | ID fail hamparan. `nodeId` (dentryUuid) adalah `workbookId` bagi hamparan tersebut. Anda boleh mendapatkannya dengan memanggil API [Dapatkan nod](/open/development/get-knowledge-base-acquisition-node) atau [Cipta dokumen Knowledge Base](/open/development/create-team-space-document). |
| sheetId | String | Ya | ID atau tajuk helaian kerja. Anda boleh mendapatkannya dengan memanggil API [Dapatkan semua helaian kerja](/open/development/obtain-all-worksheets), atau masukkan tajuk helaian kerja tersebut. |

### Parameter pertanyaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| operatorId | String | Ya | unionId pengendali. Anda boleh mendapatkannya dengan memanggil API [Pertanyaan butiran pengguna](/open/development/query-user-details). |

### Isi permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| row | Long | Ya | Nombor baris, bermula daripada 0. |
| rowCount | Long | Ya | Bilangan baris. |
| fontWidth | Long | Ya | Saiz fon. |
