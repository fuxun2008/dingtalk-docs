Dokumen dalam talian ialah struktur pokok yang terdiri daripada pelbagai elemen blok. Jenis BlockElement yang berbeza boleh menyarangkan jenis elemen yang berbeza di dalamnya. Contohnya, blok Callout boleh menyarangkan mana-mana `BlockElement`, manakala blok Paragraph hanya boleh menyarangkan InlineElement.

Struktur data bagi satu elemen blok adalah seperti berikut:

```json
{
  "blockType": enum(BlockType),             // Jenis elemen blok. Lihat enum `BlockType` di bahagian bawah dokumen ini.
  /**
   * Berikut adalah semua jenis Block yang disokong, seperti Heading dan Paragraph.
   * Setiap jenis Block mempunyai property sendiri.
  */
  "blockquote": Object(Callout),
  "callout": Object(Callout),
  "columns": Object(Columns),
  "heading": Object(Heading),
  "paragraph": Object(Paragraph),
  "orderedList": Object(OrderedList)
  "unorderedList": Object(UnorderedList),
  "table": Object(Table),
  // Setiap jenis Block menyokong BlockChildren tersendiri. Lihat penerangan `children` di bawah setiap jenis Block.

  "children": BlockChildren[ ],

}
```

## Struktur data elemen blok

Dokumen dalam talian ialah struktur pokok yang terdiri daripada pelbagai **elemen blok**. Jenis elemen blok yang berbeza menyokong jenis elemen anak bersarang yang berbeza:

- `children` bagi `callout` dan `columns` mestilah merupakan **array BlockElement**.
- `children` bagi `paragraph`, `heading`, `orderedList`, `unorderedList`, dan `blockquote` mestilah merupakan **array InlineElement**.
- `table` pada masa ini tidak menyokong penetapan `children`.

### Enum BlockType

| Nilai enum | Penerangan |
| --- | --- |
| paragraph | Blok perenggan. |
| heading | Blok tajuk. |
| blockquote | Blok petik. |
| callout | Blok callout. |
| columns | Blok lajur. |
| orderedList | Blok senarai bernombor. |
| unorderedList | Blok senarai berbulet. |
| table | Blok jadual hamparan. |
| tableRow | Blok baris jadual (anak bagi blok table). |
| tableCell | Blok sel jadual (anak bagi blok table). |

> Jenis elemen yang tidak disokong akan mengembalikan `Undefined` secara seragam.

### Perenggan

```json
{
  "blockType": "paragraph",
  "paragraph": {
    "text": "Kandungan teks perenggan",
    "indent": { "left": 32 },
    "folded": false
  },
  "children": [InlineElement]
}
```

| Nama medan | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| text | string | Tidak | Kandungan teks bagi perenggan. |
| indent | object(Indent) | Tidak | Nilai inden. `left` mestilah integer yang lebih besar daripada 0. |
| folded | boolean | Tidak | Sama ada untuk melipat perenggan (melipat elemen blok dengan nilai inden yang lebih besar daripada perenggan semasa). |

- `children`: **array InlineElement**.
- Objek `paragraph` **tidak boleh ditinggalkan**. Apabila kandungan kosong, hantar `{}`.

### Tajuk

```json
{
  "blockType": "heading",
  "heading": {
    "level": 1,
    "text": "Tajuk tahap 1"
  },
  "children": [InlineElement]
}
```

| Nama medan | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| text | string | Tidak | Kandungan teks bagi tajuk. |
| level | integer(enum) | Tidak | Tahap tajuk. Julat nilai: `1` hingga `6`. 1 menunjukkan tajuk tahap 1. |

- `children`: **array InlineElement**.

### Petik

```json
{
  "blockType": "blockquote",
  "blockquote": {
    "text": "Kandungan petikan",
    "indent": { "left": 32 }
  },
  "children": [InlineElement]
}
```

| Nama medan | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| text | string | Tidak | Teks di dalam petikan. |
| indent | object(Indent) | Tidak | Nilai inden khusus. |

- `children`: **array InlineElement**.

### Blok Callout

```json
{
  "blockType": "callout",
  "callout": {
    "sticker": "灯泡",  // Mentol
    "showstk": true,
    "color": "#333333",
    "border": "#FFD700",
    "bgcolor": "#FFF9C4"
  },
  "children": [BlockElement]
}
```

| Nama medan | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| sticker | string(enum Emoji) | Tidak | Kod Emoji. Lihat [Nilai enum Emoji](/ms/open/development/enumeration-values-of-emojis). |
| showstk | boolean | Tidak | Sama ada untuk memaparkan emoji. |
| color | string | Tidak | Warna teks. |
| border | string | Tidak | Warna sempadan. |
| bgcolor | string | Tidak | Warna latar belakang. |

- `children`: **array BlockElement** (InlineElement tidak dibenarkan).

### Lajur

```json
{
  "blockType": "columns",
  "columns": {
    "size": 2,
    "noFill": false
  },
  "children": [BlockElement]
}
```

| Nama medan | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| size | number | Tidak | Bilangan lajur. |
| noFill | boolean | Tidak | Sama ada untuk mengisi warna latar belakang secara automatik. |

- `children`: **array BlockElement** (InlineElement tidak dibenarkan).

### Senarai Bernombor

```json
{
  "blockType": "orderedList",
  "orderedList": {
    "list": {
      "listId": "list-001",
      "level": 0,
      "listStyleType": "decimal",
      "listStyle": {
        "format": "decimal",
        "text": "%1.",
        "align": "left"
      },
      "symbolStyle": {
        "bold": false
      }
    },
    "indent": { "left": 32 }
  },
  "children": [InlineElement]
}
```

| Nama medan | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| list | object(ListObject) | Ya | Atribut khusus bagi senarai bernombor. Lihat [ListObject](#e6621bc176irg). |
| indent | object(Indent) | Tidak | Nilai inden. `left` mestilah integer yang lebih besar daripada 0. |

- `children`: **array InlineElement**.

### Senarai Berbulet

```json
{
  "blockType": "unorderedList",
  "unorderedList": {
    "list": {
      "listId": "list-002",
      "level": 0,
      "listStyleType": "disc",
      "listStyle": {
        "format": "disc",
        "text": "%1",
        "align": "left"
      },
      "symbolStyle": {
        "bold": false
      }
    },
    "indent": { "left": 32 }
  },
  "children": [InlineElement]
}
```

| Nama medan | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| list | object(ListObject) | Ya | Atribut khusus bagi senarai berbulet. Lihat [ListObject](#e6621bc176irg). |
| indent | object(Indent) | Tidak | Nilai inden. `left` mestilah integer yang lebih besar daripada 0. |

- `children`: **array InlineElement**.

### Jadual Hamparan

```json
{
  "blockType": "table",
  "table": {
    "rolSize": 3,
    "colSize": 4,
    "cells": [
      ["Row1-Col1", "Row1-Col2", "Row1-Col3", "Row1-Col4"],
      ["Row2-Col1", "Row2-Col2", "Row2-Col3", "Row2-Col4"],
      ["Row3-Col1", "Row3-Col2", "Row3-Col3", "Row3-Col4"]
    ]
  }
}
```

| Nama medan | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| rolSize | number | Ya | Bilangan baris. |
| colSize | number | Ya | Bilangan lajur. |
| cells | String[][] | Tidak | Kandungan teks sel. Array String dua dimensi. |

- `children`: **Tidak disokong**. Penetapan children pada masa ini tidak dibenarkan.

## Struktur data InlineElement

Elemen inline digunakan dalam `children` bagi elemen blok berasaskan teks (perenggan, tajuk, senarai, dan sebagainya).

### Enum InlineType

| Nilai enum | Penerangan |
| --- | --- |
| text | Teks. |
| sticker | Emoji. |
| image | Gambar. |
| link | Pautan. |

### Teks

```json
{
  "text": "Teks merah tebal",
  "sz": 16,
  "color": "red",
  "highlight": "yellow",
  "bold": true,
  "italic": false,
  "stike": false,
  "underline": false,
  "fonts": "monospace"
}
```

| Nama medan | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| text | string | Ya | Kandungan teks. |
| sz | number | Tidak | Saiz fon (unit lalai: px). |
| color | string | Tidak | Warna teks. |
| highlight | string | Tidak | Warna latar belakang sorotan. |
| bold | boolean | Tidak | Sama ada untuk menggunakan tebal. |
| italic | boolean | Tidak | Sama ada untuk menggunakan condong. |
| stike | boolean | Tidak | Sama ada untuk menggunakan coretan. |
| underline | boolean | Tidak | Sama ada untuk menggunakan garis bawah. |
| fonts | string(enum Fonts) | Tidak | Fon. Nilai enum:   - **monospace**: fon monospace - **STSong**: STSong - **Microsoft YaHei**: Microsoft YaHei - **FangSong_GB2312**: FangSong GB2312 - **Helvetica**: Helvetica - **Helvetica Neue**: Helvetica Neue - **Consolas**: Consolas - **宋体**: SimSun - **Impact**: Impact - **sanrif**: sanrif - **Calibri**: Calibri |

### Emoji

```json
{
  "elementType": "sticker",
  "properties": {
    "code": "大笑"  // Ketawa besar
  }
}
```

| Nama medan | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| code | string(enum Emoji) | Ya | Kod Emoji. Lihat [Nilai enum Emoji](/ms/open/development/enumeration-values-of-emojis). |

### Gambar

```json
{
  "elementType": "image",
  "properties": {
    "src": "https://example.com/image.jpg"
  }
}
```

| Nama medan | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| src | string | Tidak | URL sumber gambar. |

### Pautan

```json
{
  "elementType": "link",
  "properties": {
    "href": "https://example.com"
  },
  "children": [
    { "text": "Klik untuk membuka pautan" }
  ]
}
```

| Nama medan | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| href | string | Tidak | URL pautan. |

- `children`: **array Text**. Apabila memasukkan pautan, `children` mesti ditetapkan dan mengandungi sekurang-kurangnya satu nod teks yang `text`-nya tidak kosong.

## Struktur data biasa

### Indent

| Nama medan | Jenis | Wajib | Penerangan | Contoh |
| --- | --- | --- | --- | --- |
| left | number | Tidak | Nilai inden khusus. Mestilah integer yang lebih besar daripada 0, jika tidak ralat akan dikembalikan. | `32` |

---

### ListObject

| Nama medan | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| listId | string | Tidak | ID senarai semasa. Apabila memasukkan senarai bernombor berbilang tahap, pastikan `listId` adalah konsisten merentasi kumpulan senarai berbilang tahap yang sama, jika tidak paparan akan menjadi tidak betul. |
| level | number | Ya | Tahap senarai (bermula daripada 0). |
| listStyleType | string | Ya | Jenis gaya senarai. |
| listStyle | object(ListStyle) | Ya | Gaya senarai khusus. Lihat [ListStyle](#bad921c2ebc3h). |
| symbolStyle | object(SymbolStyle) | Tidak | Gaya simbol senarai. Lihat [SymbolStyle](#b16d5427cbutg). |

---

### ListStyle

| Nama medan | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| format | string | Ya | Format senarai berbucu. |
| text | string | Ya | Teks. |
| align | string | Ya | Penjajaran, seperti `left`, `center`, atau `right`. |

---

### SymbolStyle

| Nama medan | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| sz | number | Tidak | Saiz fon bagi simbol senarai berbucu. |

| fonts | string | Tidak | Format fon bagi simbol senarai berbucu. |
| color | string | Tidak | Warna fon bagi simbol senarai berbucu. |
| bold | boolean | Tidak | Sama ada untuk menggunakan tebal. |
| strike | boolean | Tidak | Sama ada untuk memaparkan coretan. |
| italic | boolean | Tidak | Sama ada untuk memaparkan condong. |
