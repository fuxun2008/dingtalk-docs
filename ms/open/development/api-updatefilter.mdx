---

Panggil API ini untuk mengemas kini secara pukal syarat penapis bagi pelbagai lajur dalam penapis global sekaligus. API ini sesuai untuk senario di mana anda perlu menetapkan, mengubah, atau mengosongkan peraturan penapis bagi pelbagai lajur secara serentak. Contohnya, dalam laporan analisis data, anda boleh menapis mengikut pengguna, julat jumlah, dan warna label merentas pelbagai dimensi pada masa yang sama.

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/doc/workbooks/{workbookId}/sheets/{sheetId}/filter/updateFilter` |
| Kaedah HTTP | POST |
| Jenis aplikasi disokong | appType-Aplikasi dalaman |
| Kebenaran diperlukan | permission-Document.Workbook.Write-Kebenaran tulis DingTalk Spreadsheet |

### Header permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Panggil API [Dapatkan access token aplikasi dalaman](/open/development/obtain-the-access-token-of-an-internal-app) untuk mendapatkannya. |

### Parameter laluan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| workbookId | String | Ya | ID fail Spreadsheet. `nodeId(dentryUuid)` yang dikembalikan oleh [API Knowledge Base](/open/development/knowledge-base-overview) ialah `workbookId` Spreadsheet. Anda boleh mendapatkannya dengan memanggil API [Dapatkan nod](https://open.dingtalk.com/document/orgapp/get-node) dan [Cipta dokumen Knowledge Base](/open/development/create-team-space-document). |
| sheetId | String | Ya | ID atau nama Helaian Kerja. Panggil API [Dapatkan semua helaian kerja](/open/development/obtain-all-worksheets) untuk mendapatkan nilai parameter id atau name. |

### Parameter pertanyaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| operatorId | String | Ya | unionId pengendali.   - Panggil API [Dapatkan maklumat pengguna menggunakan kod log masuk senyap](/open/development/obtain-the-userid-of-a-user-by-using-the-log-free) untuk mendapatkan nilai parameter unionid. - Panggil API [Tanya maklumat terperinci pengguna](/open/development/query-user-details) untuk mendapatkan nilai parameter unionid.       Jika pengendali tidak mempunyai kebenaran, API akan mengembalikan ralat `The operator has no permission`. |

### Isi permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| criteria | `Map<String, Object>` | Ya | Peta daripada offset lajur kepada syarat penapis. Kunci ialah offset lajur (string bermula daripada 0, relatif kepada lajur pertama julat penapis). Nilai ialah objek syarat penapis untuk lajur tersebut, atau `null` (yang mengosongkan syarat untuk lajur tersebut). |
|  | Object | Tidak | Syarat penapis untuk lajur semasa. |
| filterType | String | Tidak | Jenis penapis. Nilai sah:   - **values**: Tapis mengikut nilai. - **color**: Tapis mengikut warna. - **condition**: Tapis mengikut syarat. |
| visibleValues | Array of String | Tidak | Nilai yang boleh dilihat. |
| conditions | Array | Tidak | Array syarat penapis. Sehingga 2 dibenarkan. Diperlukan hanya apabila `filterType` ialah `condition`. |
| operator | String | Tidak | Operator syarat. Nilai sah:   - **equal**: Sama dengan. - **not-equal**: Tidak sama dengan. - **contains**: Mengandungi. - **not-contains**: Tidak mengandungi. - **starts-with**: Bermula dengan. - **not-starts-with**: Tidak bermula dengan. - **ends-with**: Berakhir dengan. - **not-ends-with**: Tidak berakhir dengan. - **greater**: Lebih besar daripada. - **greater-equal**: Lebih besar daripada atau sama dengan. - **less**: Kurang daripada. - **less-equal**: Kurang daripada atau sama dengan. |
| value | String | Tidak | Nilai syarat. |
| conditionOperator | String | Tidak | Hubungan antara pelbagai syarat. Tetapkan kepada `"and"` (lalai) atau `"or"`. Diperlukan hanya apabila `filterType` ialah `condition`. |
| backgroundColor | String | Tidak | Tapis mengikut warna latar belakang. Nilai warna heksadesimal, seperti `"#FF0000"`. Hantar hanya apabila `filterType` ialah `color`. |
| fontColor | String | Tidak | Tapis mengikut warna fon. Nilai warna heksadesimal, seperti `"#0000FF"`. Hantar hanya apabila `filterType` ialah `color`. |
