---

Panggil API ini untuk mendapatkan tempoh cuti setiap pekerja yang dikira secara automatik berdasarkan peraturan penjadualan syif.

## Permintaan

| **Maklumat asas** | |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/topapi/attendance/getleaveapproveduration |
| Kaedah HTTP | POST |
| Jenis aplikasi yang disokong | appType-Aplikasi dalaman appType-Aplikasi perusahaan pihak ketiga |
| Kebenaran yang diperlukan | permission-qyapi_base-Kebenaran asas yang diperlukan untuk memanggil API organisasi |

### Parameter query

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | bE74xxxx | Kelayakan aplikasi yang digunakan untuk memanggil API ini.   - Aplikasi dalaman: Dapatkannya dengan memanggil [Dapatkan access_token aplikasi dalaman](/ms/open/development/obtain-orgapp-token). - Aplikasi perusahaan pihak ketiga: Dapatkannya dengan memanggil API yang mendapatkan access_token perusahaan pihak ketiga. |

### Isi permintaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| userid | String | Ya | user123 | ID pengguna pekerja dalam Organisasi Anda. Organisasi menggunakan medan ini untuk mengenal pasti pengguna secara unik. |
| from_date | Date | Ya | 2016-03-09 11:11:11 | Masa mula cuti. |
| to_date | Date | Ya | 2016-03-10 11:11:11 | Masa tamat cuti. |

### Contoh permintaan

```curl
curl -X POST "https://api.dingtalk.io/topapi/attendance/getleaveapproveduration" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=6777xxxx6f4eff' \
-d 'from_date=2016-03-09+11%3A11%3A11' \
-d 'to_date=2016-03-10+11%3A11%3A11' \
-d 'userid=zhangsan'
```

## Respons

### Isi respons

| Nama | Jenis | Contoh | Penerangan |
| --- | --- | --- | --- |
| result | ApproveDurationForTopVo |  | Hasil yang dikembalikan. |
| duration_in_minutes | Number | 0 | Tempoh cuti, dalam minit. |
| errcode | Number | 0 | Kod pemulangan. |
| errmsg | String | ok | Penerangan kod pemulangan. |
| request_id | String | 3ynh2gp5ndke | ID permintaan. |

### Contoh isi respons

```json
{
  "errcode": 0,
  "errmsg":"ok",
  "result": {
    "duration_in_minutes": 480
  },
  "request_id": "6porp1hqkb9k"
}
```

### Kod ralat

Jika panggilan API ini mengembalikan ralat, cari penyelesaian berdasarkan mesej ralat dalam dokumen [Kod ralat global](/ms/open/development/server-api-error-codes-1).
