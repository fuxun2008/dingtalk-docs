description: "Panggil API DingTalk ini untuk meramal nod dalam proses kelulusan, dan dapatkan nama nod, jenis kelulusan serta penyokong. Semak juga sama ada nod pilih sendiri wujud."
---

Panggil API ini untuk mendapatkan maklumat nod dalam proses borang kelulusan.

## Penerangan panggilan API

### Nota penggunaan

Panggil API ini untuk mendapatkan maklumat nod yang berikut:

- Untuk nod pilih sendiri: nama nod, jenis kelulusan, tetapan penyokong, skop pilihan, kaedah kelulusan bagi berbilang penyokong, jenis pengaktifan nod dan lain-lain.
- Untuk nod bukan pilih sendiri: nama nod, jenis kelulusan, tetapan penyokong, kaedah kelulusan bagi berbilang penyokong, jenis pengaktifan nod dan lain-lain.

Nod kelulusan mempunyai pilihan konfigurasi yang berikut:

**Jenis**: **Kelulusan Manual**, **Lulus Automatik** atau **Tolak Automatik**.

**Tetapan** untuk **penyokong**: **Ahli Ditetapkan**, **Pemohon Pilih Sendiri**, **Pengurus Berbilang Peringkat Berturutan**, **Ketua Jabatan**, **Penyelia Terus**, **Peranan** atau **Pemohon Sendiri**. Untuk pilih sendiri, tetapkan **Skop** yang boleh dipilih (contohnya, **Ahli Ditetapkan**) dan mod seorang atau berbilang orang.

**Kaedah kelulusan bagi berbilang penyokong**:

| Kaedah | Tingkah laku |
| --- | --- |
| Berturutan | Penyokong bertindak seorang demi seorang |
| Tandatangan bersama | Semua penyokong mesti bersetuju |
| Tandatangan atau | Kelulusan atau penolakan seorang penyokong menjadi keputusan |

### Kes penggunaan

1. Tentukan sama ada nod pilih sendiri wujud. Gunakan API ini bersama API [Mulakan instans kelulusan](/ms/open/development/create-an-approval-instance).

   **Nota**: API ini hanya terpakai apabila anda memanggil API **Mulakan instans kelulusan** tanpa menetapkan proses kelulusan, dan menggunakan semula proses kelulusan yang dikonfigurasi dalam konsol pentadbir kelulusan.

   Editor templat kelulusan menyusun konfigurasi kepada empat langkah: **Tetapan Asas**, **Reka Bentuk Borang**, **Reka Bentuk Proses** dan **Tetapan Lanjutan**. Kanvas Reka Bentuk Proses memaparkan proses kelulusan sebagai jujukan nod dari atas ke bawah:

   1. Nod **Pemohon**: orang yang memulakan instans kelulusan.
   2. **Nod pilih sendiri** (nod tempat pemohon memilih pelaksana): dipaparkan sebagai **Pemohon pilih sendiri**.
   3. Nod **Penyokong**: penyokong yang ditetapkan.

   Nod pilih sendiri membolehkan pemohon memilih pelaksana bagi langkah tersebut semasa menghantar permintaan.
2. Dapatkan maklumat nod yang dikonfigurasi dalam templat kelulusan, seperti jenis nod dan nama nod.

### Semak nod pilih sendiri

#### Dengan nod pilih sendiri

Panggil API ini. Maklumat yang dikembalikan mengandungi nod yang nilai medan `activityType` ialah `target_select`.

Apabila anda menggunakan API ini bersama API **Mulakan instans kelulusan**, ambil perhatian perkara berikut:

- Gunakan nilai medan `actorKey` bagi nod semasa sebagai parameter actionerKey untuk API Mulakan instans kelulusan.
- Gunakan nilai medan `workNo` dalam `actorSelectionRange` sebagai parameter `actionerUserIds` untuk API Mulakan instans kelulusan.

  Dalam pereka bentuk Proses kelulusan, konfigurasikan nod pilih sendiri dalam langkah **Reka Bentuk Proses** (**Tetapan Asas** > **Reka Bentuk Borang** > **Reka Bentuk Proses** > **Tetapan Lanjutan**). Aliran contoh disusun seperti berikut: **Pemohon** > **Nod pilih sendiri** (jenis **Pemohon memilih**) > **Penyokong**.

#### Tanpa nod pilih sendiri

Panggil API ini. Maklumat yang dikembalikan tidak mengandungi nod yang nilai medan `activityType` ialah `target_approval`.

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/v1.0/workflow/processes/forecast |
| Kaedah HTTP | POST |
| Jenis aplikasi yang disokong | appType-Aplikasi dalaman　appType-Aplikasi perusahaan pihak ketiga |
| Kebenaran yang diperlukan | permission-Workflow.Instance.Write-Kebenaran tulis instans aliran kerja |

### Pengepala permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Dapatkannya seperti berikut:   - Aplikasi dalaman: panggil API [Dapatkan access token aplikasi dalaman](/ms/open/development/obtain-the-access-token-of-an-internal-app). - Aplikasi perusahaan pihak ketiga: panggil API Dapatkan access token organisasi yang diberi kuasa oleh aplikasi pihak ketiga. |
