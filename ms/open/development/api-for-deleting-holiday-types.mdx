Panggil API ini untuk memadam peraturan cuti yang ditetapkan.

## Permintaan

| **Maklumat asas** | |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/topapi/attendance/vacation/type/delete |
| Kaedah HTTP | POST |
| Jenis aplikasi yang disokong | Aplikasi dalaman, Aplikasi perusahaan pihak ketiga |
| Kebenaran yang diperlukan | qyapi_holiday_manage: Kebenaran pengurusan cuti DingTalk |

### Parameter query

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | bE74xxxx | Kelayakan aplikasi yang digunakan untuk memanggil API ini.   - Bagi Aplikasi dalaman, panggil [Dapatkan access_token Aplikasi dalaman](/ms/open/development/obtain-orgapp-token) untuk mendapatkannya. - Bagi Aplikasi perusahaan pihak ketiga, panggil API untuk mendapatkan access_token organisasi pihak ketiga. |

### Isi permintaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| leave_code | String | Ya | 03747xxxx | Pengecam unik peraturan cuti. Panggil [Query senarai peraturan cuti](/ms/open/development/holiday-type-query) untuk mendapatkan nilai leave_code. |
| op_userid | String | Ya | user01 | ID pengguna admin dalam Organisasi Anda yang mempunyai kebenaran aplikasi **Kelulusan OA**. |

### Contoh permintaan

```curl
curl -X POST "https://api.dingtalk.io/topapi/attendance/vacation/type/delete" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=3acaxxxxa30a2' \
-d 'leave_code=037477axxxxae5e7973' \
-d 'op_userid=03085665764167'
```


## Respons

### Isi respons

| Nama | Jenis | Contoh | Penerangan |
| --- | --- | --- | --- |
| result | LeaveTypeVo |  | Hasil yang dikembalikan. |
| leave_code | String | 03747xxxx | Pengecam unik peraturan cuti. |
| leave_name | String | Cuti tahunan | Nama cuti. |
| leave_view_unit | String | day | Unit permohonan cuti.   - **day**: Hari - **halfDay**: Separuh hari - **hour**: Jam |
| biz_type | String | general_leave | Jenis cuti.   - **general_leave**: Cuti biasa - **lieu_leave**: Kerja lebih masa ditukar kepada cuti ganti |
| natural_day_leave | Boolean | true | Sama ada tempoh cuti dikira mengikut hari kalendar.   - **true**: Kira tempoh cuti mengikut hari kalendar. - **false**: Jangan kira tempoh cuti mengikut hari kalendar.  **Nota**  Jika nilainya **false**, tempoh cuti dikira berdasarkan penjadualan syif pengguna dalam tempoh cuti semasa pengguna menghantar permohonan cuti. |
| hours_in_per_day | Number | 1000 | Waktu kerja sehari, dalam unit 1/100 jam.  Contohnya, 1 hari = 10 jam = 1000. |
| errcode | Number | 0 | Kod pemulangan. |
| errmsg | String | ok | Penerangan kod pemulangan. |
| success | Boolean | true | Sama ada panggilan berjaya.   - **true**: Ya - **false**: Tidak |
| request_id | String | xss3trk3zypq | ID permintaan. |

### Contoh isi respons

```json
{
  "errcode": 0,
  "errmsg":"ok",
  "result": {
    "biz_type": "general_leave",
    "hours_in_per_day": 1000,
    "leave_code": "03747xxxx",
    "leave_name": "Cuti tahunan",
    "leave_view_unit": "day",
    "natural_day_leave": true
  },
  "success": true,
  "request_id": "xss3trk3zypq"
}
```
