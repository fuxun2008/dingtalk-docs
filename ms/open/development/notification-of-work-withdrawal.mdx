Panggil API ini untuk menarik balik mesej Notifikasi Kerja. Ini sesuai untuk senario di mana aplikasi dalaman perlu menarik balik mesej Notifikasi Kerja yang tersalah hantar.

## Penerangan panggilan API

Anda hanya boleh menarik balik mesej Notifikasi Kerja yang dihantar dalam tempoh 24 jam terakhir.

## Kebenaran

Kebenaran Server API diberikan pada peringkat aplikasi. Apabila anda mencipta aplikasi, kebenaran Pemberitahuan mesej ditambah secara lalai.

| Jenis aplikasi | Disokong | Cara memohon | API Explorer Debug |
| --- | --- | --- | --- |
| Aplikasi dalaman | Disokong | Diaktifkan secara lalai. Tiada permohonan diperlukan. | [Debug](https://open-dev.dingtalk.io/apiExplorer#/?devType=org&api=dingtalk.oapi.message.corpconversation.recall) |
| Aplikasi perusahaan pihak ketiga | Disokong | Diaktifkan secara lalai. Tiada permohonan diperlukan. | [Debug](https://open-dev.dingtalk.io/apiExplorer#/?devType=isv&api=dingtalk.oapi.message.corpconversation.recall) |
| Aplikasi peribadi pihak ketiga | Tidak disokong | — | — |

## Permintaan

| **Maklumat asas** | |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/topapi/message/corpconversation/recall |
| Kaedah HTTP | POST |
| Jenis aplikasi disokong | appType-Aplikasi dalaman, appType-Aplikasi perusahaan pihak ketiga |
| Kebenaran diperlukan | permission-qyapi_base-Kebenaran asas diperlukan untuk memanggil API perusahaan |

### Parameter query

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | bE74xxxx | Kelayakan aplikasi yang digunakan untuk memanggil API ini.   - Untuk aplikasi dalaman, dapatkan dengan memanggil API untuk mendapatkan [access_token aplikasi dalaman](/open/development/obtain-orgapp-token). - Untuk aplikasi perusahaan pihak ketiga, dapatkan dengan memanggil API untuk mendapatkan access_token perusahaan pihak ketiga. |

### Isi permintaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| agent_id | Number | Ya | 836390886 | Agent ID bagi Aplikasi mikro yang digunakan untuk menghantar mesej.   - Untuk aplikasi dalaman, anda boleh mendapatkannya di halaman butiran aplikasi dalam [Developer Backend](https://open-dev.dingtalk.io/#/appMgr/inner/h5/836390886/1). - Untuk aplikasi perusahaan pihak ketiga, dapatkan dengan memanggil API untuk mendapatkan maklumat kebenaran perusahaan. |
| msg_task_id | Number | Ya | 256271667526 | ID Tugas yang dikembalikan oleh DingTalk semasa mesej dihantar. Panggil API [Hantar Notifikasi Kerja](/open/development/asynchronous-sending-of-enterprise-session-messages) untuk mendapatkan nilai parameter task_id.  **Nota**  Hanya mesej Notifikasi Kerja yang dihantar dalam tempoh 24 jam terakhir boleh ditarik balik. |

### Contoh permintaan

```curl
curl -X POST "https://api.dingtalk.io/topapi/message/corpconversation/recall" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=404080xxxx4ab30' \
-d 'agent_id=1000' \
-d 'msg_task_id=2000'
```

Java

```text
DingTalkClient client = new DefaultDingTalkClient("https://api.dingtalk.io/topapi/message/corpconversation/recall");
OapiMessageCorpconversationRecallRequest req = new OapiMessageCorpconversationRecallRequest();
req.setAgentId(1000L);
req.setMsgTaskId(2000L);
OapiMessageCorpconversationRecallResponse rsp = client.execute(req, accessToken);
System.out.println(rsp.getBody());
```


## Respons

### Isi respons

| Nama | Jenis | Contoh | Penerangan |
| --- | --- | --- | --- |
| errmsg | String | ok | Penerangan kod pemulangan. |
| errcode | Number | 0 | Kod pemulangan. |

### Contoh isi respons

```json
{
  "errcode":0,
  "errmsg":"ok"
}
```

### Kod ralat

Jika berlaku ralat semasa memanggil API ini, cari penyelesaiannya dalam dokumen [kod ralat global](/open/development/server-api-error-codes-1) menggunakan mesej ralat.

| Kod ralat (errorcode) | Penerangan mesej ralat (errmsg) | Penyelesaian |
| --- | --- | --- |
| 400002 | Invalid agentId or taskId | Sahkan bahawa agentId dan taskId adalah betul. |
| 500 | System error | Berlaku ralat sistem yang tidak diketahui. |
