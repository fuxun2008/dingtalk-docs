Kosongkan semua kandungan, termasuk kandungan sel dan gaya.

## Penerangan panggilan API

Panggil API ini untuk mengosongkan semua kandungan dalam julat yang dinyatakan, termasuk format dan data. Hasilnya sama seperti operasi yang ditunjukkan dalam rajah di bawah.

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/doc/workbooks/{workbookId}/sheets/{sheetId}/ranges/{rangeAddress}/clear` |
| Kaedah HTTP | POST |
| Jenis aplikasi yang disokong | appType-Aplikasi dalaman　appType-Aplikasi perusahaan pihak ketiga |
| Kebenaran diperlukan | permission-Document.Workbook.Write-Kebenaran tulis DingTalk Spreadsheet |

### Header permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Dapatkan seperti berikut:   - Bagi aplikasi dalaman, panggil API [Dapatkan access token aplikasi dalaman](/open/development/obtain-the-access-token-of-an-internal-app#). - Bagi aplikasi perusahaan pihak ketiga, panggil API [Dapatkan access token perusahaan yang diberi kuasa kepada aplikasi pihak ketiga](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#). |

### Parameter laluan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| workbookId | String | Ya | ID fail spreadsheet. `nodeId(dentryUuid)` yang dikembalikan oleh [API Knowledge Base](/open/development/knowledge-base-overview#) ialah `workbookId` bagi spreadsheet tersebut. Dapatkan dengan memanggil API [Dapatkan nod](https://open.dingtalk.com/document/development/get-node#) dan [Cipta dokumen Knowledge Base](/open/development/create-team-space-document#). |
| sheetId | String | Ya | ID atau tajuk Helaian Kerja.   - Bagi aplikasi dalaman, panggil API [Dapatkan semua Helaian Kerja](/open/development/obtain-all-worksheets#) untuk mendapatkan ID, atau hantar tajuk Helaian Kerja. - Bagi aplikasi perusahaan pihak ketiga, kami mengesyorkan agar anda menghantar tajuk Helaian Kerja.   Langkah untuk melihat tajuk Helaian Kerja ditunjukkan dalam rajah di bawah. |
| rangeAddress | String | Ya | Julat sel yang hendak dikosongkan, dalam format `sel kiri-atas julat:sel kanan-bawah julat`.  Contohnya, B2:C3 menunjukkan julat seperti dalam rajah di bawah. |

### Parameter query

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| operatorId | String | Ya | unionId bagi operator. Panggil API [Query maklumat terperinci pengguna](/open/development/query-user-details#) untuk mendapatkannya. |
