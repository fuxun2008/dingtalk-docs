Panggil API ini untuk mencipta jabatan baharu.

## Permintaan

| **Maklumat asas** | |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/topapi/v2/department/create |
| Kaedah HTTP | POST |
| Jenis aplikasi yang disokong | appType-Aplikasi dalaman |
| Kebenaran yang diperlukan | permission-qyapi_manage_addresslist-Kebenaran pengurusan data Kenalan |

### Parameter pertanyaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | bE74xxxx | Kelayakan aplikasi yang digunakan untuk memanggil API ini. Dapatkannya melalui API untuk mendapatkan [access_token bagi aplikasi dalaman](/open/development/obtain-orgapp-token). |

### Isi permintaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| name | String | Ya | Development Department | Nama jabatan. Panjangnya mestilah 1 hingga 64 aksara. Aksara "-" dan "," tidak dibenarkan. |
| parent_id | Number | Ya | 10 | ID jabatan induk. ID jabatan root ialah 1. |
| hide_dept | Boolean | Tidak | true | Sama ada untuk menyembunyikan jabatan ini:   - **true**: Sembunyikan jabatan. Selepas disembunyikan, jabatan ini tidak dipaparkan dalam kenalan syarikat. - **false (Lalai)**: Paparkan jabatan. |
| dept_permits | String | Tidak | "123,456" | Senarai jabatan lain yang dibenarkan untuk melihat jabatan ini. Jumlah keseluruhan tidak boleh melebihi 50. Nilai ini berkuat kuasa apabila **hide_dept** ditetapkan kepada **true**. |
| user_permits | String | Tidak | "user123,manager222" | Senarai userId pengguna yang dibenarkan untuk melihat jabatan ini. Jumlah keseluruhan tidak boleh melebihi 50. Nilai ini berkuat kuasa apabila **hide_dept** ditetapkan kepada **true**. |
| outer_dept | Boolean | Tidak | true | Sama ada untuk menyekat ahli jabatan ini daripada melihat kenalan:   - **true**: Aktifkan sekatan. Selepas diaktifkan, ahli jabatan ini hanya boleh melihat kenalan dalam skop yang ditentukan. - **false (Lalai)**: Tiada sekatan. |
| outer_dept_only_self | Boolean | Tidak | false | Sama ada ahli jabatan ini hanya boleh melihat kenalan bagi jabatan mereka sendiri dan jabatan bawahan:   - **true**: Hanya boleh melihat kenalan bagi jabatan mereka sendiri dan jabatan bawahan. - **false**: Tidak boleh melihat sebarang kenalan, dan hanya boleh melihat diri mereka sendiri dalam kenalan.   Parameter ini berkuat kuasa apabila **outer_dept** ditetapkan kepada **true**. |
| outer_permit_users | String | Tidak | "manager123,user123" | Senarai userId pengguna kenalan yang dibenarkan untuk dilihat oleh ahli jabatan ini. Jumlah keseluruhan tidak boleh melebihi 50. Parameter ini berkuat kuasa apabila **outer_dept** ditetapkan kepada **true**. |
| outer_permit_depts | String | Tidak | "456,123" | Senarai ID jabatan kenalan yang dibenarkan untuk dilihat oleh ahli jabatan ini. Jumlah keseluruhan tidak boleh melebihi 50. Parameter ini berkuat kuasa apabila **outer_dept** ditetapkan kepada **true**. |
| create_dept_group | Boolean | Tidak | true | Sama ada untuk mencipta kumpulan perusahaan yang dikaitkan dengan jabatan ini. Nilai lalai ialah **false**, bermaksud tiada kumpulan dicipta. |
| auto_approve_apply | Boolean | Tidak | false | Sama ada untuk menerima permintaan menyertai jabatan ini secara lalai:   - **true:** Permintaan untuk menyertai jabatan ini diterima secara lalai. - **false:** Permintaan untuk menyertai jabatan ini perlu diluluskan oleh admin yang mempunyai kebenaran yang diperlukan. |
| order | Number | Tidak | 10 | Nilai susunan dalam jabatan induk. Nilai order yang lebih kecil meletakkan jabatan lebih tinggi dalam susunan. |
| source_identifier | String | Tidak | HR Department | Medan pengenal jabatan. Pembangun boleh menggunakan medan ini untuk mengenal pasti jabatan secara unik dan memetakannya kepada jabatan dalam senarai kenalan luaran di luar DingTalk. |

### Contoh permintaan

```curl
curl -X POST "https://api.dingtalk.io/topapi/v2/department/create" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=d5ca5xxxxa8' \
-d 'parent_id=10' \
-d 'outer_dept=true' \
-d 'hide_dept=true' \
-d 'create_dept_group=true' \
-d 'order=10' \
-d 'name=HR' \
-d 'source_identifier=HR%20Department' \
-d 'dept_permits=3%2C4%2C5' \
-d 'user_permits=100%2C200' \
-d 'outer_permit_users=500%2C600' \
-d 'outer_permit_depts=6%2C7%2C8' \
-d 'outer_dept_only_self=true'
```

Java

```text
DingTalkClient client = new DefaultDingTalkClient("https://api.dingtalk.io/topapi/v2/department/create");
OapiV2DepartmentCreateRequest req = new OapiV2DepartmentCreateRequest();
req.setParentId(10L);
req.setOuterDept(true);
req.setHideDept(true);
req.setCreateDeptGroup(true);
req.setOrder(10L);
req.setName("HR");
req.setSourceIdentifier("HR Department");
req.setDeptPermits("3,4,5");
req.setUserPermits("100,200");
req.setOuterPermitUsers("500,600");
req.setOuterPermitDepts("6,7,8");
req.setOuterDeptOnlySelf(true);
OapiV2DepartmentCreateResponse rsp = client.execute(req, access_token);
System.out.println(rsp.getBody());
```

## Respons

### Isi respons

| Nama | Jenis | Contoh | Penerangan |
| --- | --- | --- | --- |
| request_id | String | 6iq4zcul5zjp | ID permintaan. |
| errcode | Number | 0 | Kod pemulangan. |
| errmsg | String | ok | Penerangan kod pemulangan. |
| result | DeptCreateResponse |  | Hasil panggilan. |
| dept_id | Number | 100 | ID jabatan. |

### Contoh isi respons

```json
{
  "errcode": 0,
  "errmsg":"ok",
  "result": {
    "dept_id": 41xxxx76
  },
  "request_id": "6iq4zcul5zjp"
}
```

### Kod ralat

Jika ralat berlaku semasa anda memanggil API ini, cari penyelesaiannya dalam dokumen [Kod ralat global](/open/development/server-api-error-codes-1) berdasarkan mesej ralat.

| Kod ralat (errcode) | Mesej ralat (errmsg) | Penyelesaian |
| --- | --- | --- |
| 40035 | Invalid parameter | Pastikan parameter diisi mengikut keperluan dokumen di atas. |
| 43007 | Authorization required | Pastikan access_token mempunyai kebenaran yang diperlukan untuk tindakan ini. |
| 60004 | Parent department does not exist | Semak sama ada parent_id adalah betul. |
| 600109 | Invalid visible ID list | Semak sama ada senarai kelihatan memenuhi keperluan. |
| -1 | System busy | Cuba Lagi kemudian. |
