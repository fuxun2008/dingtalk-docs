Panggil API ini untuk mendapatkan senarai kenalan luaran sesebuah organisasi.

## Permintaan

| **Maklumat asas** | |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/topapi/extcontact/list |
| HTTP Method | POST |
| Jenis aplikasi yang disokong | appType-Aplikasi dalamanappType-Aplikasi perusahaan pihak ketiga |
| Kebenaran yang diperlukan | permission-qyapi_ext_read-Kebenaran baca untuk kenalan luaran |

### Parameter pertanyaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | 6d1bxxxx | Kelayakan aplikasi yang digunakan untuk memanggil API ini.   - Untuk aplikasi dalaman, dapatkan dengan memanggil API untuk mendapatkan [access_token bagi aplikasi dalaman](/ms/open/development/obtain-orgapp-token). - Untuk aplikasi perusahaan pihak ketiga, dapatkan dengan memanggil API untuk mendapatkan access_token bagi perusahaan pihak ketiga. |

### Isi permintaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| size | Number | Tidak | 20 | Menyokong pertanyaan bermuka surat. Parameter ini berkuat kuasa hanya apabila ditetapkan bersama parameter offset. Ia menunjukkan saiz halaman, dengan maksimum 100. |
| offset | Number | Tidak | 0 | Menyokong pertanyaan bermuka surat. Parameter ini berkuat kuasa hanya apabila ditetapkan bersama parameter size. Ia menunjukkan ofset, bermula daripada 0. |

### Contoh permintaan

```curl
curl -X POST "https://api.dingtalk.io/topapi/extcontact/list" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=b5039xxxx8bcc' \
-d 'offset=0' \
-d 'size=20'
```

Java

```text
DingTalkClient client = new DefaultDingTalkClient("https://api.dingtalk.io/topapi/extcontact/list");
OapiExtcontactListRequest req = new OapiExtcontactListRequest();
req.setSize(20L);
req.setOffset(0L);
OapiExtcontactListResponse rsp = client.execute(req, access_token);
System.out.println(rsp.getBody());
```

Python

```python
import dingtalk.api

req=dingtalk.api.OapiExtcontactListRequest("https://api.dingtalk.io/topapi/extcontact/list")

req.offset=0
req.size=20
try:
  resp= req.getResponse(access_token)
  print(resp)
except Exception,e:
  print(e)
```

PHP

```php
include "TopSdk.php";
date_default_timezone_set('Asia/Shanghai');

$c = new DingTalkClient(DingTalkConstant::$CALL_TYPE_OAPI, DingTalkConstant::$METHOD_POST , DingTalkConstant::$FORMAT_JSON);
$req = new OapiExtcontactListRequest;
$req->setOffset("0");
$req->setSize("20");
$resp = $c->execute($req, $access_token, "https://api.dingtalk.io/topapi/extcontact/list");
```

C#

```text
IDingTalkClient client = new DefaultDingTalkClient("https://api.dingtalk.io/topapi/extcontact/list");
OapiExtcontactListRequest req = new OapiExtcontactListRequest();
req.Offset = 0L;
req.Size = 20L;
OapiExtcontactListResponse rsp = client.Execute(req, access_token);
Console.WriteLine(rsp.Body);
```

| --- | --- | --- | --- |
| results | OpenExtContact[] |  | Hasil pertanyaan. |

### Kod ralat

Jika ralat dikembalikan semasa anda memanggil API ini, cari penyelesaiannya dalam dokumen [Kod ralat global](/ms/open/development/server-api-error-codes-1) berdasarkan mesej ralat.

| Kod ralat (errcode) | Mesej ralat (errmsg) | Penyelesaian |
| --- | --- | --- |
| 33009 | Invalid tokenGrantType | Semak sama ada access_token betul. |
| 40069 | Invalid size | Laraskan saiz halaman. |
| 40068 | Invalid offset | Laraskan ofset. |
| 400001 | System error | Cuba lagi kemudian. |
