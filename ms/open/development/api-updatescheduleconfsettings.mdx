## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/v1.0/conference/scheduleConferences/settings |
| Kaedah HTTP | PUT |
| Jenis aplikasi yang disokong | appType-Aplikasi dalaman　appType-Aplikasi perusahaan pihak ketiga |
| Kebenaran diperlukan | permission-VideoConference.Conference.Write-Kebenaran pengurusan maklumat Mesyuarat Video |

| Nama | Jenis | Wajib | Penerangan |

| mode | String | Tidak | Susun atur rakaman mesyuarat:   - **grid**: Mod grid, secara lalai 9-grid (3x3) - **speech**: Mod penceramah - **full_screen**: Mod skrin penuh - **auto_grid**: Mod grid automatik, secara lalai sehingga 4x4 grid - **screen_cast**: Mod perkongsian skrin, hanya strim perkongsian skrin dipaparkan - **p2p**: Mod panggilan dua orang - **full_screen_and_speaker**: Kandungan dikongsi + mod penceramah |
| isFollowHost | Boolean | Tidak | Sama ada untuk mengikut Tuan Rumah:   - **true**: Ikut - **false**: Jangan ikut |
| restrictShareMinutesSummaryOnly | Integer | Tidak | Sama ada untuk mengehadkan perkongsian Minit Mesyuarat kepada ringkasan sahaja:   - **0**: Tiada sekatan - **1**: Dihadkan |
| aiAgentSummarySetting | Object | Tidak | Tetapan AI Minutes mesyuarat. |
| value | String | Tidak | Sama ada untuk mengaktifkan ringkasan Pembantu AI:   - **disable**: Tidak aktif - **enable**: Aktif |
| receiverType | Integer | Tidak | Skop penerima untuk push Minit Mesyuarat selepas mesyuarat:   - **0**: Semua ahli mesyuarat - **1**: Pencipta sahaja |
| allowAllParticipantsStart | Integer | Tidak | Sama ada untuk membenarkan semua ahli mesyuarat memulakan:   - **0**: Tidak benarkan - **1**: Benarkan |
| restrictShareMinutesSummaryOnly | Integer | Tidak | Sama ada untuk mengehadkan perkongsian Minit Mesyuarat kepada ringkasan sahaja:   - **0**: Tiada sekatan - **1**: Dihadkan |
| enableAiAgentStatus | Boolean | Tidak | Sama ada untuk memaparkan fungsi AI Minutes:   - **true**: Paparkan - **false**: Sembunyikan (berkesan pada DingTalk Android versi 8.3.20 atau lebih baru; berkesan pada iOS, PC dan klien lain) |
