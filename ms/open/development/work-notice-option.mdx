Topik ini menerangkan cara memanggil API berkaitan Notifikasi Kerja untuk menghantar, menyemak, dan menarik balik mesej.

## Hasil yang dijangka

Rajah berikut menunjukkan hasil penghantaran Notifikasi Kerja.

## Gambaran keseluruhan aliran integrasi

Dokumen ini menerangkan proses mencipta Aplikasi dalaman dan menggunakan API berkaitan kehadiran untuk menghantar Notifikasi Kerja.

Prasyarat: Selesaikan aliran [Penciptaan dan konfigurasi aplikasi](/open/dingstart/create-application).

Langkah 1: Dapatkan Kelayakan aplikasi, termasuk client ID dan Client Secret.

Langkah 2: Mohon Kebenaran API untuk API Notifikasi Kerja.

Langkah 3: Dapatkan Kredensial akses (access_token) Aplikasi dalaman. access token digunakan untuk mengesahkan pemanggil semasa memanggil API.

Langkah 4: Panggil API Notifikasi Kerja:

1. Panggil Server API [Hantar Notifikasi Kerja](/open/development/asynchronous-sending-of-enterprise-session-messages) untuk menghantar Notifikasi Kerja dan mendapatkan ID Tugas unik `task_id` bagi mesej tersebut.
2. Dengan ID Tugas unik `task_id`, panggil Server API [Dapatkan kemajuan penghantaran Notifikasi Kerja](/open/development/obtain-the-sending-progress-of-asynchronous-sending-of-enterprise-session) untuk menyemak kemajuan penghantaran.
3. Dengan ID Tugas unik `task_id`, panggil Server API [Dapatkan hasil penghantaran Notifikasi Kerja](/open/development/gets-the-result-of-sending-messages-asynchronously-to-the-enterprise) untuk melihat hasil penghantaran.
4. Dengan ID Tugas unik `task_id`, panggil Server API [Kemas kini bar status Notifikasi Kerja](/open/development/update-work-notification-status-bar) untuk mengemas kini Notifikasi Kerja.
5. Dengan ID Tugas unik `task_id`, panggil Server API [Tarik Balik Notifikasi Kerja](/open/development/notification-of-work-withdrawal) untuk menarik balik Notifikasi Kerja.

## Prasyarat

Selesaikan aliran [Penciptaan dan konfigurasi aplikasi](/open/dingstart/create-application).

## Langkah 1: Dapatkan Kelayakan aplikasi

1. Pilih aplikasi sasaran untuk membuka halaman butiran aplikasi, kemudian klik **Maklumat asas** > **Kelayakan dan maklumat asas**.
2. Dapatkan client ID dan Client Secret.

## Langkah 2: Tambah Kebenaran API

Kebenaran API diaktifkan secara lalai. Tiada permohonan diperlukan.

## Langkah 3: Dapatkan access token aplikasi

<Warning>
Untuk maklumat lanjut tentang perbezaan antara versi Server API, rujuk perbandingan antara API lama dan API baharu. Semua API berikut ialah Server API. Untuk maklumat lanjut tentang cara memuat turun SDK, rujuk Muat turun SDK bahagian pelayan.
</Warning>

Gunakan client ID dan Client Secret yang diperoleh dalam Langkah 1 untuk mendapatkan access_token bagi Aplikasi dalaman.

```java
public void getAccessToken() throws ApiException {
        DingTalkClient client = new DefaultDingTalkClient("https://oapi.dingtalk.io/gettoken");
        OapiGettokenRequest req = new OapiGettokenRequest();
        req.setAppkey("dingxxxxxxxxxhgn");
        req.setAppsecret("9G_xxxxxxxxxxxxxxx1JDf0Qq3nexxxxxxxxGIO");
        req.setHttpMethod("GET");
        OapiGettokenResponse rsp = client.execute(req);
        System.out.println(rsp.getBody());
}
```

## Langkah 4: Panggil Server API berkaitan

4. Dengan ID Tugas unik `task_id`, panggil Server API [Kemas kini bar status Notifikasi Kerja](/open/development/update-work-notification-status-bar) untuk mengemas kini Notifikasi Kerja.

```java
/**
 * Rujukan warna status kelulusan
 * Diterima 0xFF78C06E
 * Ditolak 0xFFF65E5E
 * Ditarik balik 0xFF858E99
 * Menunggu kelulusan 0xFFFF9D46
 */
 public void updateWorkNoticeStatus() throws ApiException {
        DingTalkClient client = new DefaultDingTalkClient("https://api.dingtalk.io/topapi/message/corpconversation/status_bar/update");
        OapiMessageCorpconversationStatusBarUpdateRequest request = new OapiMessageCorpconversationStatusBarUpdateRequest();
        request.setAgentId(1068622214L);
        request.setStatusValue("Diterima");
        request.setStatusBg("0xFF78C06E");
        request.setTaskId(313382528774L);
        OapiMessageCorpconversationStatusBarUpdateResponse response = client.execute(request, "access_token");
        System.out.println(JSON.toJSONString(response));
    }
```
