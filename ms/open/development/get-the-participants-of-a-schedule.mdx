Panggil API ini untuk mendapatkan senarai peserta acara.

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/calendar/users/{userId}/calendars/{calendarId}/events/{eventId}/attendees` |
| Kaedah HTTP | GET |
| Jenis aplikasi yang disokong | appType-Aplikasi dalaman　appType-Aplikasi perusahaan pihak ketiga　appType-Aplikasi peribadi pihak ketiga |
| Kebenaran yang diperlukan | permission-Calendar.Event.Read-Kebenaran membaca untuk acara dalam aplikasi Kalendar |

### Header permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses yang digunakan untuk memanggil API ini. Dapatkan seperti berikut:   - Untuk aplikasi dalaman, panggil [Dapatkan access token aplikasi dalaman](/open/development/obtain-the-access-token-of-an-internal-app#). - Untuk aplikasi perusahaan pihak ketiga, panggil [Dapatkan access token organisasi yang diberi kuasa kepada aplikasi pihak ketiga](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#). - Untuk aplikasi peribadi pihak ketiga, panggil [Dapatkan token pengguna](/open/development/obtain-user-token#). |

### Parameter laluan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| userId | String | Ya | unionId pengguna yang memiliki sumber yang diminta.   - Untuk aplikasi dalaman atau aplikasi perusahaan pihak ketiga, panggil [Tanya butiran pengguna](/open/development/query-user-details#) untuk mendapatkan nilai parameter unionid. - Untuk aplikasi peribadi pihak ketiga, panggil [Dapatkan profil pengguna daripada Kenalan](/open/development/dingtalk-retrieve-user-information#) untuk mendapatkan nilai parameter unionId. |
| calendarId | String | Ya | ID kalendar yang memiliki acara tersebut. Tetapkan kepada **primary**, yang mewakili kalendar utama pengguna. |
| eventId | String | Ya | ID acara. Panggil [Tanya senarai acara](/open/development/query-an-event-list#) untuk mendapatkan nilai parameter id. |

### Parameter pertanyaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| maxResults | Integer | Tidak | Bilangan maksimum rekod yang dikembalikan. Lalai: 100. Maksimum: 500. |
| nextToken | String | Tidak | Cursor penomboran halaman.      Jika pertanyaan tidak dapat mengembalikan semua hasil sekaligus, token penomboran halaman akan dikembalikan. Sertakan token ini dalam permintaan seterusnya untuk mendapatkan data seterusnya, sehingga token penomboran halaman bernilai null, yang menandakan semua data telah dikembalikan. |

Content-Type:application/json
