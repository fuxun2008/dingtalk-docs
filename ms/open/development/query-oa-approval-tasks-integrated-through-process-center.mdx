Panggil API ini untuk menanya tugasan kelulusan pengguna yang sedang berjalan.

## Penerangan panggilan API

- API ini hanya boleh menanya data Tugasan dalam tempoh setahun yang lalu.
- API ini menanya Tugasan belum selesai yang dicipta untuk pengguna melalui API Cipta tugasan belum selesai Pusat Proses. Tugasan ini disegerakkan ke Tugasan DingTalk. Lihat tugasan tersebut di **Klien DingTalk > Tugasan > Kelulusan OA**.

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/v1.0/workflow/processCentres/todoTasks |
| Kaedah HTTP | GET |
| Jenis aplikasi yang disokong | appType-Aplikasi dalaman　appType-Aplikasi perusahaan pihak ketiga |
| Kebenaran diperlukan | permission-qyapi_aflow-Kebenaran pengurusan data aliran kerja kelulusan |

### Pengepala permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Dapatkan seperti berikut:   - Aplikasi dalaman: Panggil API [Dapatkan access token aplikasi dalaman](/ms/open/development/obtain-the-access-token-of-an-internal-app). - Aplikasi perusahaan pihak ketiga: Panggil API Dapatkan access token organisasi yang dibenarkan oleh aplikasi pihak ketiga. |

### Parameter pertanyaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| userId | String | Ya | userId pelaksana tugasan. Dapatkan dengan memanggil API [Tanya senarai ID pengguna dalam jabatan](/ms/open/development/query-the-list-of-department-userids). |
| pageSize | Integer | Ya | Saiz halaman. Bermula daripada 1. Nilai maksimum: 40. |
| pageNumber | Integer | Ya | Nombor halaman. Bermula daripada 1. |
| createBefore | Long | Tidak | Masa mula pertanyaan.    Masa ini tidak boleh melebihi setahun sebelum masa semasa. |

### Contoh permintaan

```http
GET /v1.0/workflow/processCentres/todoTasks?userId=manager001&pageSize=1&pageNumber=1&createBefore=1660036833411 HTTP/1.1
Host:api.dingtalk.io
x-acs-dingtalk-access-token:xxxx
Content-Type:application/json
```

## Respons

### Isi respons

| Nama | Jenis | Penerangan |
| --- | --- | --- |
| requestId | String | ID permintaan. |
| taskPage | Object | Hasil yang dipaparkan mengikut halaman. |
| hasMore | Boolean | Menunjukkan sama ada terdapat halaman seterusnya.   - **true**: Ya - **false**: Tidak |
| list | Array | Senarai tugasan. |
| taskId | Long | ID tugasan Kelulusan OA. |
| activityId | String | ID kumpulan Tugasan. |
| userId | String | userId pemohon tugasan. |
| status | String | Status tugasan. |
| result | String | Hasil pemprosesan tugasan.   - **agree**: Terima - **refuse**: Tolak |
| createTime | Long | Masa dicipta tugasan Kelulusan OA. |
| finishTime | String | Masa selesai tugasan Kelulusan OA. |
| processInstanceId | String | ID instans aliran kerja. |
