---
title: "Get a cell range"
description: "Panggil API ini untuk mendapatkan sifat sel dalam Spreadsheet DingTalk, termasuk nilai, formula, nilai paparan, warna latar belakang, saiz fon, serta penjajaran mendatar dan menegak."
---

Panggil API ini untuk mendapatkan atribut sel. Pada masa ini, anda boleh mendapatkan nilai, formula, nilai paparan, warna latar belakang, saiz fon, penjajaran mendatar, dan penjajaran menegak bagi sel.

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/doc/workbooks/{workbookId}/sheets/{sheetId}/ranges/{rangeAddress}` |
| Kaedah HTTP | GET |
| Jenis aplikasi yang disokong | appType-Aplikasi dalaman |
| Kebenaran diperlukan | permission-Document.Workbook.Read-Kebenaran baca spreadsheet |

### Header permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Dapatkan dengan memanggil API [Dapatkan access token aplikasi dalaman](/open/development/obtain-the-access-token-of-an-internal-app#). |

### Parameter laluan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| workbookId | String | Ya | ID fail spreadsheet. `nodeId(dentryUuid)` yang dikembalikan oleh [API Knowledge Base](/open/development/knowledge-base-overview#) ialah `workbookId` bagi spreadsheet tersebut. Dapatkan dengan memanggil API [Dapatkan nod](https://open.dingtalk.com/document/development/get-node#) atau [Cipta dokumen Knowledge Base](/open/development/create-team-space-document#). |
| sheetId | String | Ya | ID atau nama Helaian Kerja. Dapatkan nilai parameter id atau name dengan memanggil API [Dapatkan semua Helaian Kerja](/open/development/obtain-all-worksheets#). |
| rangeAddress | String | Ya | Alamat julat. |

### Parameter kueri

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| select | String | Tidak | Menapis medan yang perlu dikembalikan. Jika parameter ini tidak ditetapkan, semua medan akan dikembalikan.   - Sebagai contoh, `select=values` hanya mengembalikan medan values. - Untuk mengembalikan berbilang medan, pisahkan dengan koma. Sebagai contoh, `select=values,formulas` hanya mengembalikan medan values dan formulas.     Kami mengesyorkan anda menetapkan parameter ini untuk meningkatkan prestasi dan mengelakkan tamat masa (timeout) API yang disebabkan oleh penambahan nilai kembalian pada masa hadapan. |
| operatorId | String | Ya | unionId bagi operator.   - Dapatkan nilai parameter unionid dengan memanggil API [Dapatkan maklumat pengguna melalui kod Log masuk senyap](/open/development/obtain-the-userid-of-a-user-by-using-the-log-free#). - Dapatkan nilai parameter unionid dengan memanggil API [Tanya butiran pengguna](/open/development/query-user-details#).     Jika operator tidak mempunyai kebenaran, API akan mengembalikan ralat `The operator has no permission`. |
