Topik ini menerangkan apa itu storan, keupayaan Storage API, dan sumber berkaitan.

## Apa itu storan

Storage API menyediakan penyelesaian pengurusan data yang pintar dan selamat untuk organisasi serta memenuhi keperluan senario kerjasama pejabat yang berpusat pada storan fail. Keupayaan teras termasuk tetapi tidak terhad kepada muat naik, muat turun, pengurusan dan pemindahan fail, pratonton dan penyuntingan dalam talian bagi format fail utama, serta pengurusan kebenaran. Anda boleh menggunakan Storage API untuk membina apa sahaja daripada lampiran aplikasi ringkas hinggalah produk cloud drive dengan ciri lengkap.

Selepas aplikasi anda mengintegrasikan Storage API, anda boleh:

- Memindahkan fail secara cekap antara aplikasi anda dengan aplikasi DingTalk yang lain.
- Memenuhi keperluan tadbir urus fail bagi Pentadbir Organisasi. Untuk maklumat lanjut, lihat [DingTalk admin console](https://oa.dingtalk.io/dingtalk-enterprise-storage.htm#/).

## Rujukan sumber

- Sumber **Space** mengandungi atribut berikut:

  | Atribut | Jenis | Keterangan |
  | --- | --- | --- |
  | spaceId | string | ID ruang. |
  | spaceName | string | Nama ruang. |
  | spaceType | string | Jenis ruang.  - **USER**: ruang pengguna - **APP**: ruang aplikasi |
  | quota | int64 | Kapasiti keseluruhan ruang.  **Nota**  Nilai -1 menunjukkan ruang tidak mempunyai had kuota. Jika ruang mempunyai atribut organisasi, kuota tidak boleh melebihi kuota ruang organisasi. |
  | usedQuota | int64 | Kapasiti ruang yang telah digunakan. |
  | createTime | string (iso8601) | Masa dicipta. |
  | modifyTime | string (iso8601) | Masa pengubahsuaian. |
- Sumber **File and folder** mengandungi atribut berikut:

  | Atribut | Jenis | Keterangan |
  | --- | --- | --- |
  | id | string | ID fail atau folder. |
  | spaceId | string | ID ruang. |
  | path | string | Laluan fail atau folder dalam ruang tersebut. |
  | status | string | Status.  - **NORMAL**: normal - **DELETED**: dipadam - **EXPIRED**: tamat tempoh |
  | partitionType | string | Partition storan.  - **PUBLIC_OSS_PARTITION**: partition storan OSS awan awam - **MINI_OSS_PARTITION**: partition storan MiniOSS khusus |
  | parentId | string | ID folder induk. |
  | fileType | string | Jenis fail.  - **FILE**: fail - **FOLDER**: folder |
  | extension | string | Sambungan nama fail. |
- Sumber **Permission** mengandungi atribut berikut:

  | Atribut | Jenis | Keterangan |
  | --- | --- | --- |
  | id | string | ID pengguna kebenaran.  - Jika parameter type ialah **ORG**, tetapkan parameter ini kepada **corpId** organisasi. - Jika parameter type ialah **DEPT**, tetapkan parameter ini kepada **deptId** jabatan. Panggil API [Dapatkan Senarai jabatan](/ms/open/development/user-management-acquires-the-list-departments) untuk mendapatkan nilai dept_id. - Jika parameter type ialah **TAG**, tetapkan parameter ini kepada **nama tag**. - Jika parameter type ialah **CONVERSATION**, tetapkan parameter ini kepada **openConversationId** bagi sembang tersebut, yang diperoleh melalui API cipta Sembang Kumpulan atau API cipta kumpulan senario. - Jika parameter type ialah **USER**, tetapkan parameter ini kepada **unionId** pengguna. Panggil API [Query user details](/ms/open/development/query-user-details) untuk mendapatkan nilai unionid. |
  | roleId | string | ID peranan kebenaran.  - **OWNER**: pemilik - **MANAGER**: pengurus - **EDITOR**: editor - **DOWNLOADER**: pemuat turun - **READER**: pemapar |
  | type | string | Jenis pengguna kebenaran:  - **ORG**: organisasi - **DEPT**: jabatan - **TAG**: tag tersuai - **CONVERSATION**: sembang - **USER**: pengguna |
  | duration | string | Tempoh sah kebenaran, dalam saat. Nilai lalai ialah -1, yang menunjukkan sah selama-lamanya.  - Tempoh sah kebenaran berkuat kuasa apabila jenis ruang bagi kebenaran yang diberikan ialah APP. - Tempoh sah kebenaran tidak berkuat kuasa apabila jenis ruang bagi kebenaran yang diberikan ialah USER, dan secara lalai adalah sah selama-lamanya. |
