---
title: "Menyemak status baca mesej sembang kumpulan bot organisasi"
description: "Panggil API ini untuk menyemak status penghantaran mesej sembang kumpulan bot organisasi serta userId ahli yang telah membaca mesej berkenaan di DingTalk."
---

Panggil API ini untuk mendapatkan maklumat seperti status penghantaran mesej dan userId pengguna yang telah membaca mesej tersebut. Sebagai contoh, selepas bot organisasi menghantar mesej sembang kumpulan dalam Kumpulan Dalaman, anda boleh menggunakan API ini untuk menyemak userId pengguna yang telah membaca mesej tersebut.

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/v1.0/robot/groupMessages/query |
| Kaedah HTTP | POST |
| Jenis aplikasi disokong | appType-Aplikasi dalaman　appType-Aplikasi perusahaan pihak ketiga |
| Kebenaran diperlukan | permission-qyapi_robot_sendmsg-Kebenaran untuk bot dalaman menghantar mesej |

### Pengepala permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Dapatkan seperti berikut:   - Untuk aplikasi dalaman, panggil API [Dapatkan access token aplikasi dalaman](/ms/open/development/obtain-the-access-token-of-an-internal-app#). - Untuk aplikasi perusahaan pihak ketiga, panggil API [Dapatkan access token organisasi yang dibenarkan untuk aplikasi pihak ketiga](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#). |

### Isi permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| openConversationId | String | Tidak | ID kumpulan. Dapatkan openConversationId sesuatu sembang kumpulan melalui JSAPI [chooseChat](https://open.dingtalk.com/document/development/jsapi-choose-chat#) di bahagian klien.  Nilai ini mesti sama dengan openConversationId yang digunakan dalam API [Hantar mesej sembang kumpulan dengan bot](/ms/open/development/the-robot-sends-a-group-message#). |
| robotCode | String | Tidak | Kod bot. Untuk maklumat lanjut, lihat [ID Bot](https://open.dingtalk.com/document/development/robot-overview#).  Nilai ini mesti sama dengan robotCode yang digunakan dalam API [Hantar mesej sembang kumpulan dengan bot](/ms/open/development/the-robot-sends-a-group-message#). |
| processQueryKey | String | Ya | Pengecam unik mesej. Dapatkan daripada medan processQueryKey dalam respons API [Hantar mesej sembang kumpulan dengan bot](/ms/open/development/the-robot-sends-a-group-message#). |
| maxResults | Long | Tidak | Bilangan item setiap halaman untuk pertanyaan berhalaman. Nilai maksimum ialah 200. |
| nextToken | String | Tidak | Cursor penghalaman. Biarkan kosong untuk memulakan pertanyaan dari halaman pertama. |
