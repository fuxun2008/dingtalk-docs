description: "Panggil API DingTalk ini untuk mendapatkan senarai peraturan cuti organisasi anda, termasuk nama cuti, unit cuti dan sumber cuti, bagi menyegerakkan data kehadiran dengan mudah."
---

Panggil API ini untuk menyemak senarai peraturan cuti dalam organisasi anda, termasuk nama cuti dan unit cuti.

## Permintaan

| **Maklumat asas** | |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/topapi/attendance/vacation/type/list |
| Kaedah HTTP | POST |
| Jenis aplikasi yang disokong | appType-Aplikasi dalaman　appType-Aplikasi perusahaan pihak ketiga |
| Kebenaran yang diperlukan | permission-qyapi_holiday_readonly-Kebenaran baca cuti DingTalk |

### Parameter pertanyaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | bE74xxxx | Kelayakan aplikasi yang digunakan untuk memanggil API ini.   - Bagi Aplikasi dalaman, dapatkannya dengan memanggil API [Dapatkan access_token Aplikasi dalaman](/ms/open/development/obtain-orgapp-token). - Bagi Aplikasi perusahaan pihak ketiga, dapatkannya dengan memanggil API untuk mendapatkan access_token organisasi pihak ketiga. |

### Isi permintaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| op_userid | String | Ya | user01 | ID pengguna Admin dalam organisasi anda yang mempunyai Kebenaran aplikasi untuk Aplikasi **Kelulusan OA**. |
| vacation_source | String | Tidak | all | Sumber cuti. Nilai yang sah:   - **"all"**: Mengembalikan semua jenis cuti. - **""**: Mengembalikan hanya jenis cuti yang dicipta dengan memanggil API untuk menambah peraturan cuti. |

### Contoh permintaan

```curl
curl -X POST "https://api.dingtalk.io/topapi/attendance/vacation/type/list" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=43aexxxxd897cd9' \
-d 'op_userid=03085665764167' \
-d 'vacation_source=all'
```

Java

```java
DingTalkClient client = new DefaultDingTalkClient("https://api.dingtalk.io/topapi/attendance/vacation/type/list");
OapiAttendanceVacationTypeListRequest req = new OapiAttendanceVacationTypeListRequest();
req.setOpUserid("user01");
req.setVacationSource("all");
OapiAttendanceVacationTypeListResponse rsp = client.execute(req, access_token);
System.out.println(rsp.getBody());
```

Python

```python
import dingtalk.api

req=dingtalk.api.OapiAttendanceVacationTypeListRequest("https://api.dingtalk.io/topapi/attendance/vacation/type/list")

req.vacation_source="all"

  resp= req.getResponse(access_token)

```



## Respons

### Isi respons

| Nama | Jenis | Contoh | Penerangan |
| --- | --- | --- | --- |
| request_id | String | 3k4z2hq8pv2x | ID permintaan. |
| errcode | Number | 0 | Kod pulangan. |
| errmsg | String | ok | Penerangan kod pulangan. |
| success | Boolean | true | Menunjukkan sama ada permintaan berjaya.   - **true**: Ya - **false**: Tidak |
| result | Result[] |  | Hasil yang dikembalikan. |
| leave_code | String | 037477sdfsxxxx | Pengecam unik peraturan cuti. |
| leave_name | String | Cuti tahunan | Nama cuti. |
| leave_view_unit | String | day | Unit cuti.   - **day**: Hari - **halfDay**: Separuh hari - **hour**: Jam |
| leave_certificate | LeaveCertificateVo |  | Sijil cuti. |
| leave_certificate.unit | String | hour | Unit sijil cuti.   - **hour**: Jam - **day**: Hari |
| leave_certificate.duration | Number | 1 | Tempoh cuti yang melebihinya memerlukan sijil cuti. |
| leave_certificate.enable | Boolean | false | Menunjukkan sama ada sijil cuti diaktifkan.   - **true**: Aktif - **false**: Tidak aktif |
| leave_certificate.prompt_information | String | Maklumat cuti | Teks prompt yang dipaparkan untuk permohonan cuti. |
| submit_time_rule | SubmitTimeRuleVo |  | Peraturan penghantaran berhad masa. |
| submit_time_rule.time_value | Number | 18 | Nilai had.   - Apabila timeUnit ialah **day**, julat yang sah ialah 0 hingga 30 hari. - Apabila timeUnit ialah **hour**, julat yang sah ialah 0 hingga 24 jam. |
| submit_time_rule.time_unit | String | hour | Unit masa.   - **day**: Hari - **hour**: Jam |
| submit_time_rule.time_type | String | before | Jenis had.   - **before**: Hantar lebih awal - **after**: Hantar secara retrospektif |
| submit_time_rule.enable_time_limit | Boolean | false | Menunjukkan sama ada penghantaran berhad masa diaktifkan.   - **true**: Aktif - **false**: Tidak aktif |
| biz_type | String | general_leave | Jenis cuti.   - **general_leave**: Cuti biasa - **lieu_leave**: Kerja lebih masa ditukar kepada cuti ganti |
| natural_day_leave | String | true | Menunjukkan sama ada tempoh cuti dikira mengikut hari kalendar.   - **true**: Kira tempoh cuti mengikut hari kalendar. - **false**: Jangan kira tempoh cuti mengikut hari kalendar.  **Nota**  Apabila nilainya **false**, tempoh cuti dikira berdasarkan penjadualan syif pengguna sepanjang tempoh cuti semasa pengguna menghantar permohonan cuti. |
| validity_type | String | absolute_time | Jenis kesahan.   - **absolute_time**: Masa mutlak - **relative_time**: Masa relatif |
| validity_value | String | 12-31 | Tarikh lanjutan.   - Apabila validity_type ialah **absolute_time**, nilai ini tidak kosong dan menggunakan format "yy-mm". - Apabila validity_type ialah **relative_time**, nilai ini ialah integer yang lebih besar daripada 1. |
| hours_in_per_day | Number | 1000 | Waktu kerja sehari, dalam unit 1/100 jam.  Contohnya: 1 hari = 10 jam = 1000. |
| source | String | inner | Sumber cuti.   - **external**: Cuti tersuai yang dicipta melalui Open API - **inner**: Cuti yang dicipta dalam Admin Console OA |
