Panggil API ini untuk menambah kawalan akses pada kalendar yang ditentukan.

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/calendar/users/{userId}/calendars/{calendarId}/acls` |
| Kaedah HTTP | POST |
| Jenis aplikasi disokong | appType-Aplikasi dalaman　appType-Aplikasi peribadi pihak ketiga |
| Kebenaran diperlukan | permission-Calendar.Acl.Write-Kebenaran tulis kawalan akses aplikasi Kalendar |

### Pengepala permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Dapatkan dengan cara berikut:   - Untuk aplikasi dalaman, panggil API [Dapatkan access token aplikasi dalaman](/open/development/obtain-the-access-token-of-an-internal-app#). - Untuk aplikasi peribadi pihak ketiga, panggil API [Dapatkan token pengguna](/open/development/obtain-user-token#). |

### Parameter laluan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| userId | String | Ya | unionId penganjur acara.   - Untuk aplikasi dalaman, panggil API [Tanya perincian pengguna](/open/development/query-user-details#) untuk mendapatkan nilai parameter unionid. - Untuk aplikasi peribadi pihak ketiga, panggil API [Dapatkan profil kenalan pengguna](/open/development/dingtalk-retrieve-user-information#) untuk mendapatkan nilai parameter unionId. |
| calendarId | String | Ya | ID kalendar milik acara ini. Nilai ditetapkan kepada primary, yang menandakan kalendar utama pengguna. |

### Isi permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| privilege | String | Ya | Maklumat kebenaran. Nilai yang sah:   - **free_busy_reader**: Semak lapang/sibuk. - **title_reader**: Lihat tajuk. - **reader**: Lihat Perincian. - **writer**: Cipta dan edit. |
| sendMsg | Boolean | Ya | Sama ada untuk menghantar mesej kepada pengguna yang diberi kebenaran.   - **true**: Hantar. - **false**: Jangan hantar. |
| scope | Object | Ya | Skop kebenaran. |
| scopeType | String | Ya | Jenis kebenaran. Buat masa ini, hanya **user** disokong, yang menandakan seorang pengguna. |
| userId | String | Ya | ID pengguna. Apabila **scopeType** ditetapkan kepada **user**, masukkan **unionId** pengguna tersebut.  **Nota**  Seorang pengguna boleh berkongsi dengan maksimum 500 pengguna. |
