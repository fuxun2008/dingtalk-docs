Panggil API ini untuk mendapatkan berbilang rekod daripada jadual tertentu dalam AI Table.

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/notable/bases/{baseId}/sheets/{sheetIdOrName}/records/list` |
| Kaedah HTTP | POST |
| Jenis aplikasi disokong | appType-Aplikasi dalaman |
| Kebenaran diperlukan | permission-Notable.Base.Read.All-Kebenaran baca aplikasi AI Table |

### Header permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses yang digunakan untuk memanggil API ini. Untuk mendapatkannya, lihat [Dapatkan access token aplikasi dalaman](/open/development/obtain-the-access-token-of-an-internal-app). |

### Parameter laluan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| baseId | String | Ya | ID AI Table. Untuk mendapatkannya, lihat [Struktur data](/open/development/data-structure). |
| sheetIdOrName | String | Ya | ID jadual atau nama jadual. Anda boleh mendapatkan ID jadual dengan salah satu cara berikut:   - Panggil API [Dapatkan semua jadual](/open/development/api-notable-getallsheets). - Panggil API [Dapatkan satu jadual](/open/development/api-notable-getsheet). |

### Parameter pertanyaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| operatorId | String | Ya | unionId pengendali. Anda boleh mendapatkannya dengan salah satu cara berikut:   - Panggil API [Menanyakan butiran pengguna](/open/development/query-user-details). - Panggil API [Dapatkan maklumat pengguna menggunakan kod log masuk senyap](/open/development/obtain-the-userid-of-a-user-by-using-the-log-free). |

### Isi permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| filter | Object | Tidak | Penapis (filter). Apabila ditetapkan, hanya rekod yang memenuhi syarat akan dikembalikan. |
| combination | String | Tidak | Mod gabungan syarat. Nilai yang sah:   - **and**: Semua syarat mesti dipenuhi. - **or**: Mana-mana syarat boleh dipenuhi. |
| conditions | Array | Ya | Syarat-syarat. |
| field | String | Ya | ID medan atau nama medan. |
| operator | String | Ya | Operator syarat: equal | notEqual | greater | greaterEqual | less | lessEqual | contain | notContain | empty | notEmpty. |
| value | Array of Any | Tidak | Nilai syarat. Lihat [Format nilai rekod](https://open.dingtalk.com/document/development/record-value-format). |
| maxResults | Integer | Tidak | Bilangan rekod yang dikembalikan setiap halaman. Lalai: 100. Minimum: 1. Maksimum: 100. |
| nextToken | String | Tidak | Cursor pagination yang dikembalikan oleh pertanyaan sebelumnya. Biarkan kosong untuk pertanyaan pertama. |
| fieldIdOrNames | Array of String | Tidak | Pilihan. Senarai medan yang perlu dikembalikan. Apabila terdapat banyak medan, hantar hanya medan yang diperlukan untuk mengurangkan saiz respons dengan ketara. Maksimum 100 medan setiap permintaan. |

## Respons

### Isi respons

| Nama | Jenis | Penerangan |
| --- | --- | --- |
| hasMore | Boolean | Menunjukkan sama ada terdapat lebih banyak data. |
| nextToken | String | Cursor pagination. |
| records | Array | Senarai rekod. |
| id | String | ID rekod. |
| fields | `Map<String, Any>` | Nilai medan. |
|  | Any | Nilai medan. |
| createdBy | Object | Pencipta. |
| unionId | String | unionId pencipta. |
| lastModifiedBy | Object | Pengubah suai terakhir. |
| unionId | String | unionId pengubah suai terakhir. |
| createdTime | Long | Masa dicipta. |
| lastModifiedTime | Long | Masa pengubahsuaian terakhir. |

### Contoh respons

```text
HTTP/1.1 200 OK
Content-Type:application/json

{
  "hasMore" : true,
  "nextToken" : "nextToken",
  "records" : [ {
    "id" : "qkexxx",

      "unionId" : "union_id"
    },
    "lastModifiedBy" : {
```
