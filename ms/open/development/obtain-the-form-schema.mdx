Panggil API ini untuk mendapatkan skema borang melalui processCode.

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/v1.0/workflow/forms/schemas/processCodes |
| Kaedah HTTP | GET |
| Jenis aplikasi yang disokong | appType-Aplikasi dalaman　appType-Aplikasi perusahaan pihak ketiga |
| Kebenaran | permission-Workflow.Form.Read-Kebenaran baca untuk templat aliran kerja |

### Pengepala permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Dapatkannya seperti berikut:   - Aplikasi dalaman: Panggil API [Dapatkan access token aplikasi dalaman](/ms/open/development/obtain-the-access-token-of-an-internal-app). - Aplikasi perusahaan pihak ketiga: Panggil API untuk mendapatkan access token organisasi yang diberi kebenaran oleh aplikasi pihak ketiga. |

### Parameter pertanyaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| processCode | String | Ya | Kod unik borang. Dapatkannya dengan memanggil API [Cipta atau kemas kini templat borang kelulusan](/ms/open/development/create-an-approval-form-template), atau rujuk [Gambaran keseluruhan Kelulusan OA - Glosari](/ms/open/development/workflow-overview). |
| appUuid | String | Tidak | Maklumat pengasingan untuk pembinaan aplikasi. |

| gmtCreate | String | Cap masa bagi masa dicipta. |
| gmtModified | String | Cap masa bagi masa pengubahsuaian. |
