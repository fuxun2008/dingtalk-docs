Panggil API ini untuk mendapatkan keputusan daftar masuk sebenar pekerja dalam organisasi anda.

## Penerangan panggilan API

- API ini tidak menyokong pertanyaan data yang lebih lama daripada enam bulan.
- Untuk mendapatkan data daftar masuk yang terperinci, seperti lokasi daftar masuk, panggil API [Dapatkan butiran daftar masuk](/ms/open/development/attendance-clock-in-record-is-open).
- Penyegerakan data kehadiran mungkin tertangguh. Jika terdapat data yang tiada, cuba lagi kemudian.
- **Jika pengguna mempunyai jadual kerja pada hari tersebut tetapi tidak mendaftar masuk, API ini memulangkan titik semakan yang dijadualkan untuk hari tersebut dan bukannya hasil kosong**.

Sebagai contoh, katakan organisasi anda menjadualkan seorang pekerja untuk mendaftar masuk sekali pada 9:00 dan sekali pada 18:00. Walaupun pekerja tersebut mendaftar masuk beberapa kali dalam tempoh ini, API ini hanya memulangkan dua rekod: keputusan daftar masuk pagi dan keputusan daftar masuk petang.

## Permintaan

| **Maklumat asas** | |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/attendance/list |
| Kaedah HTTP | POST |
| Jenis aplikasi yang disokong | appType-Aplikasi dalaman　appType-Aplikasi perusahaan pihak ketiga |
| Kebenaran yang diperlukan | qyapi_attendance_isv_query_result (Kebenaran membaca data kehadiran organisasi); qyapi_get_attendance_data (Kebenaran membaca data kehadiran) |

### Parameter pertanyaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | 6d1bxxxx | Kelayakan aplikasi yang digunakan untuk memanggil API ini.   - Aplikasi dalaman: Panggil API [Dapatkan access_token Aplikasi dalaman](/ms/open/development/obtain-orgapp-token). - Aplikasi perusahaan pihak ketiga: Panggil API Dapatkan access_token Aplikasi perusahaan pihak ketiga. |

### Isi permintaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| workDateFrom | String | Ya | 2020-11-07 08:00:00 | Hari bekerja permulaan untuk pertanyaan rekod daftar masuk kehadiran. Format: yyyy-MM-dd HH:mm:ss. Anda boleh menetapkan HH:mm:ss kepada 00:00:00. API memulangkan keputusan bagi tarikh ini dari 00:00 hingga 24:00.  Sebagai contoh, jika anda menghantar "2021-12-01 10:00", API memulangkan keputusan kehadiran bagi sepanjang hari 1 Disember.  **Penting**  Selang antara workDateFrom dan workDateTo  tidak boleh melebihi 7 hari (termasuk). |
| workDateTo | String | Ya | 2020-11-11 08:00:00 | Hari bekerja akhir untuk pertanyaan rekod daftar masuk kehadiran. Format: "yyyy-MM-dd HH:mm:ss". Anda boleh menetapkan HH:mm:ss kepada 00:00:00. API memulangkan keputusan bagi tarikh ini dari 00:00 hingga 24:00.  Sebagai contoh, jika anda menghantar "2021-12-01 19:00", API memulangkan keputusan kehadiran bagi sepanjang hari 1 Disember.  **Penting**  Selang antara workDateFrom dan workDateTo  tidak boleh melebihi 7 hari (termasuk). |
| userIdList | String[] | Ya | ["manager4220"] | Senarai userId pekerja dalam organisasi anda. Maksimum: 50.  **Penting**  Pastikan nilai userId adalah betul. Jika tidak, API ini memulangkan hasil kosong. |
| offset | Number | Ya | 0 | Titik permulaan untuk mengambil data kehadiran. Hantar 0 untuk permintaan pertama. Jika terdapat lebih banyak data, tetapkan offset dalam permintaan seterusnya kepada offset sebelumnya + limit. Nilai bertambah secara berturutan: 0, 1, 2 dan seterusnya. |
| limit | Number | Ya | 50 | Bilangan rekod kehadiran yang hendak diambil. Maksimum: 50. |
| isI18n | Boolean | Tidak | true | Menentukan sama ada API digunakan oleh organisasi luar negara:   - **true**: Digunakan pada platform antarabangsa - **false** (lalai): Digunakan pada platform China |

### Contoh permintaan

```curl
curl -X POST "https://api.dingtalk.io/attendance/list" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=713b06xxxxd4cbdf4' \
-d 'isI18n=true' \
-d 'limit=100' \
-d 'offset=0' \
-d 'userIdList=1' \
-d 'workDateFrom=yyyy-MM-dd+hh%3Amm%3Ass' \
-d 'workDateTo=yyyy-MM-dd+hh%3Amm%3Ass'
```

Java

```java
DingTalkClient client = new DefaultDingTalkClient("https://api.dingtalk.io/attendance/list");
OapiAttendanceListRequest req = new OapiAttendanceListRequest();
req.setWorkDateFrom("2020-11-07 08:00:00");
req.setWorkDateTo("2020-11-11 08:00:00");
req.setUserIdList(Arrays.asList("manager"));
req.setOffset(0L);
req.setLimit(10L);
req.setIsI18n(true);
OapiAttendanceListResponse rsp = client.execute(req, access_token);
System.out.println(rsp.getBody());
```

## Respons

### Isi respons

| Nama | Jenis | Contoh | Penerangan |
| --- | --- | --- | --- |
| recordresult | Recordresult[] |  | Rekod daftar masuk. |
| sourceType | String | USER | Sumber data:   - **USER**: Daftar masuk oleh pengguna - **BOSS**: Diperbetulkan oleh pengurus - **APPROVE**: Sistem kelulusan - **SYSTEM**: Sistem kehadiran - **AUTO_CHECK**: Daftar masuk automatik |
| baseCheckTime | Date | 1599378660000 | Masa asas yang digunakan untuk mengira kelewatan dan pulang awal. |
| userCheckTime | Date | 1599378681000 | Masa daftar masuk sebenar, dalam milisaat. |
| procInstId | String | 59f77e82-6625-4a31-b434 | ID instans kelulusan yang berkaitan. Jika medan ini tidak kosong, rekod daftar masuk berkaitan dengan kelulusan seperti permohonan cuti atau permohonan kerja lebih masa. |
| approveId | Number | 2376620852 | ID kelulusan yang berkaitan. Jika medan ini tidak kosong, rekod daftar masuk berkaitan dengan kelulusan seperti permohonan cuti atau permohonan kerja lebih masa. |
| locationResult | String | Normal | Keputusan lokasi:   - **Normal**: Dalam julat - **Outside**: Luar julat - **NotSigned**: Tidak mendaftar masuk |
| timeResult | String | Normal | Keputusan daftar masuk:   - **Normal**: Normal - **Early**: Pulang awal - **Late**: Kelewatan - **SeriousLate**: Kelewatan serius - **Absenteeism**: Kelewatan yang dikira sebagai ponteng kerja - **NotSigned**: Tidak mendaftar masuk |
| checkType | String | OnDuty | Jenis kehadiran:   - **OnDuty**: Daftar masuk - **OffDuty**: Daftar keluar |
| userId | String | manager4220 | userId pekerja yang mendaftar masuk. |
| workDate | Date | 1599321600000 | Hari bekerja. |
| recordId | Number | 43002777448 | ID rekod daftar masuk. |
| planId | Number | 145342017988 | ID jadual kerja. |
| groupId | Number | 685935028 | ID kumpulan kehadiran. |
| id | Number | 101135139831 | ID unik. |
| hasMore | Boolean | false | Parameter penomboran halaman yang menunjukkan sama ada terdapat lebih banyak data.   - **true**: Ya - **false**: Tidak |
| errmsg | String | ok | Penerangan kod pulangan. |
| errcode | Number | 0 | Kod pulangan. |
