Panggil API ini untuk menanya senarai acara pengguna dalam julat masa tertentu. Anda boleh mendapatkan maklumat seperti tajuk acara, tarikh mula, masa mula, tarikh tamat, dan masa tamat.

## Penerangan panggilan API

- Perbezaan antara API ini dengan API **Query event list** terletak pada cara acara berulang dikendalikan. API ini mengembangkan semua acara berulang dalam julat pertanyaan berdasarkan peraturan pengulangan, tetapi tidak benar-benar menjana instance yang berkaitan dalam pangkalan data. Contohnya, jika terdapat acara berulang harian bermula pada 1 Januari, tarikh semasa ialah 4 Januari, dan julat pertanyaan ialah dari 1 Januari hingga 10 Januari, API ini mengembalikan semua acara berulang dari 1 Januari hingga 10 Januari, manakala API [Query event list](/ms/open/development/query-an-event-list#) tidak mengembalikan acara selepas 4 Januari.
- Anda boleh menentukan sama ada sesuatu acara adalah instance daripada acara berulang dengan menyemak sama ada `seriesMasterId` bagi objek acara yang dikembalikan kosong.

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/calendar/users/{userId}/calendars/{calendarId}/eventsview` |
| Kaedah HTTP | GET |
| Jenis aplikasi disokong | appType-Internal app　appType-Third-party enterprise app　appType-Third-party personal app |
| Kebenaran diperlukan | permission-Calendar.Event.Read-Kebenaran baca untuk acara dalam aplikasi Calendar |

### Header permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Dapatkan seperti berikut:   - Untuk aplikasi dalaman, panggil API [Obtain the access token of an internal app](/ms/open/development/obtain-the-access-token-of-an-internal-app#). - Untuk aplikasi perusahaan pihak ketiga, panggil API [Obtain the access token of an enterprise that authorizes a third-party app](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#). - Untuk aplikasi peribadi pihak ketiga, panggil API [Obtain user token](/ms/open/development/obtain-user-token#). |

### Parameter laluan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| userId | String | Ya | unionId pengguna yang ingin ditanya.   - Untuk aplikasi dalaman dan aplikasi perusahaan pihak ketiga, panggil API [Query user details](/ms/open/development/query-user-details#) untuk mendapatkan nilai parameter `unionid`. - Untuk aplikasi peribadi pihak ketiga, panggil API [Obtain a user's profile from Contacts](/ms/open/development/dingtalk-retrieve-user-information#) untuk mendapatkan nilai parameter `unionId`. |
| calendarId | String | Ya | ID kalendar yang menjadi milik acara tersebut. Panggil API [Query calendars](/ms/open/development/query-a-calendar#) untuk menanya acara bagi pengguna semasa. Gunakan kata kunci **primary** untuk merujuk kepada kalendar utama pengguna semasa. |

### Parameter pertanyaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| timeMin | String | Tidak | Tanya acara yang masa tamatnya >= TimeMin. Format menggunakan format tarikh-masa ISO-8601. |
| timeMax | String | Tidak | Tanya acara yang masa mulanya `< timeMax`. Format menggunakan format tarikh-masa ISO-8601. |
| maxResults | Integer | Tidak | Bilangan maksimum rekod yang dikembalikan. Nilai maksimum ialah 100, dan nilai lalai ialah 100. |
| maxAttendees | Integer | Tidak | Bilangan peserta yang dikembalikan bagi setiap acara. Nilai lalai ialah 100, dan nilai maksimum ialah 100. Jika bilangan peserta melebihi 100 dan anda perlu mendapatkan semua peserta, gunakan API [Get event attendees](/ms/open/development/get-the-participants-of-a-schedule#). |
| nextToken | String | Tidak | Cursor penomboran halaman.      Jika satu pertanyaan tidak dapat mengembalikan semua hasil, token penomboran halaman akan dikembalikan. Sertakan token ini dalam pertanyaan seterusnya untuk mendapatkan data berikutnya, sehingga token penomboran halaman bernilai null, yang menunjukkan semua data telah ditanya. |

| text | String | Kandungan penerangan teks kaya. |
| meetingRooms | Array | Bilik mesyuarat. |
| roomId | String | roomId bagi bilik mesyuarat. |
| responseStatus | String | Status respons bagi bilik mesyuarat.   - **accepted**: Diterima - **tentative**: Menunggu kelulusan - **declined**: Kelulusan ditolak |
| displayName | String | Nama bilik mesyuarat. |
