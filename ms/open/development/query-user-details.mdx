Panggil API ini untuk mendapatkan butiran pengguna yang ditentukan.

## Penerangan panggilan API

API ini membolehkan anda menanyakan butiran pengguna akaun biasa atau pengguna Akaun Syarikat. Oleh kerana penggunaan parameter berbeza dengan ketara antara kedua-dua senario, dokumentasi ini dibahagikan mengikut jenis akaun untuk rujukan yang lebih mudah:

- Untuk menanyakan butiran pengguna akaun biasa, rujuk artikel ini.
- Untuk menanyakan butiran pengguna Akaun Syarikat, lihat [Dapatkan butiran pengguna Akaun Syarikat](/open/development/queries-the-details-of-a-dedicated-account).

Jika anda perlu mendapatkan kebenaran untuk medan seperti nombor telefon dan e-mel, kaedahnya berbeza mengikut jenis Aplikasi.

- Untuk Aplikasi dalaman mendapatkan nombor telefon dan e-mel pengguna, tambah kebenaran untuk mengakses nombor telefon dan e-mel dalam Contacts. Untuk menambah kebenaran ini:

  Log masuk ke [DingTalk Developer Console](https://open-dev.dingtalk.io/#/corpeapp) > **Internal Development** > **cari aplikasi yang ingin anda tambah kebenaran** > **Manage permissions** > **Contacts Management**. Pilih **Employee phone number** dan **Mail and other Profile information**, kemudian klik Request permission.
- Untuk Aplikasi perusahaan pihak ketiga mendapatkan nombor telefon dan e-mel pengguna, gunakan suite kebenaran bersepadu DingTalk.

## Permintaan

| **Maklumat asas** | |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/topapi/v2/user/get |
| Kaedah HTTP | POST |
| Jenis aplikasi disokong | appType-Aplikasi dalaman, appType-Aplikasi perusahaan pihak ketiga |
| Keperluan kebenaran | permission-qyapi_get_member-Kebenaran baca maklumat pengguna |

### Parameter query

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | bE74xxxx | Kelayakan aplikasi yang digunakan untuk memanggil API ini.   - Untuk Aplikasi dalaman, dapatkan melalui API untuk mendapatkan access_token Aplikasi dalaman. - Untuk Aplikasi perusahaan pihak ketiga, dapatkan melalui API untuk mendapatkan access_token perusahaan pihak ketiga. |

### Isi permintaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| userid | String | Ya | manager4220 | userid pengguna. |
| language | String | Tidak | zh_CN | Bahasa Contacts.   - **zh_CN**: Bahasa Cina (Lalai) - **en_US**: Bahasa Inggeris |

### Contoh permintaan

```bash
curl -X POST "https://api.dingtalk.io/topapi/v2/user/get" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=b97a231d-7dd8-4243-ac4e-6b75b2a1e28a' \
-d 'language=zh_CN' \
-d 'userid=zhangsan'
```

Java

```java
DingTalkClient client = new DefaultDingTalkClient("https://api.dingtalk.io/topapi/v2/user/get");
OapiV2UserGetRequest req = new OapiV2UserGetRequest();
req.setUserid("001");
req.setLanguage("zh_CN");
OapiV2UserGetResponse rsp = client.execute(req, access_token);
System.out.println(rsp.getBody());
```

Python

```python
import dingtalk.api

req=dingtalk.api.OapiV2UserGetRequest("https://api.dingtalk.io/topapi/v2/user/get")

req.userid="zhangsan"
req.language="zh_CN"
try:
	resp= req.getResponse(access_token)
	print(resp)
except Exception,e:
	print(e)
```

PHP

```php
include "TopSdk.php";
date_default_timezone_set('Asia/Shanghai');

$c = new DingTalkClient(DingTalkConstant::$CALL_TYPE_OAPI, DingTalkConstant::$METHOD_POST , DingTalkConstant::$FORMAT_JSON);
$req = new OapiV2UserGetRequest;
$req->setUserid("zhangsan");
$req->setLanguage("zh_CN");
$resp = $c->execute($req, $access_token, "https://api.dingtalk.io/topapi/v2/user/get");
```

C#

```csharp
IDingTalkClient client = new DefaultDingTalkClient("https://api.dingtalk.io/topapi/v2/user/get");
OapiV2UserGetRequest req = new OapiV2UserGetRequest();
req.Userid = "zhangsan";
req.Language = "zh_CN";
OapiV2UserGetResponse rsp = client.Execute(req, access_token);
Console.WriteLine(rsp.Body);
```

### Kod ralat

Jika panggilan API mengembalikan Ralat, cari penyelesaian mengikut mesej ralat dalam dokumentasi [Kod ralat global](/open/development/server-api-error-codes-1).

| Kod ralat (errcode) | Penerangan kod ralat (errmsg) | Penyelesaian |
| --- | --- | --- |
| 33012 | Invalid userid | Semak sama ada userid adalah betul. |
| 400002 | Invalid parameter | Semak sama ada parameter dimasukkan mengikut keperluan. |
| -1 | System busy | Cuba Lagi kemudian. |
