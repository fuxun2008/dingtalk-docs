Panggil API ini untuk menambah sekeping teks ke penghujung perenggan.

## Penerangan panggilan API

Untuk maklumat tentang struktur data berkaitan kandungan dokumen, lihat [Struktur data dokumen](/open/development/document-data-structure).

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/doc/suites/documents/{docKey}/blocks/{blockId}/paragraph/appendText` |
| Kaedah HTTP | POST |
| Jenis aplikasi disokong | appType-Aplikasi dalaman |
| Kebenaran diperlukan | permission-Storage.File.Write-Kebenaran Tulis pada fail storan organisasi |

### Pengepala permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Dapatkan dengan memanggil API [Dapatkan access token aplikasi dalaman](/open/development/obtain-the-access-token-of-an-internal-app). |

### Parameter laluan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| docKey | String | Ya | ID Dokumen (`docKey` atau `dentryUuid` bagi dokumen tersebut). Selepas anda mencipta dokumen dengan memanggil API [Cipta dokumen Knowledge Base](/open/development/create-team-space-document), dapatkan parameter `docKey` daripada respons. Untuk mendapatkan `dentryUuid` daripada URL dokumen, ambil `https://docs.dingtalk.io/i/nodes/Zxxxxa-id` sebagai contoh; `dentryUuid` ialah `Zxxxxa-id`. |
| blockId | String | Ya | Pengecam unik bagi perenggan sasaran. Dapatkan `blockId` perenggan dengan memanggil API [Tanya elemen blok](/open/development/api-docblocksquery). |

### Parameter pertanyaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| operatorId | String | Ya | unionId pengguna. Dapatkan nilai `unionid` dengan memanggil API [Tanya butiran pengguna](/open/development/query-user-details). |

### Isi permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| text | String | Ya | Teks yang hendak disisip. |

### Contoh permintaan

HTTP

```http
POST /v1.0/doc/suites/documents/doc_id/blocks/block_id/paragraph/appendText?operatorId=union_id HTTP/1.1
Host:api.dingtalk.io
x-acs-dingtalk-access-token:7dc9ec4xxx
Content-Type:application/json

{
  "text" : "text"
}
```

## Respons

### Isi respons

| Nama | Jenis | Penerangan |
| --- | --- | --- |
| success | Boolean | Sama ada permintaan berjaya. |
| result | Object | Keputusan permintaan. |
| data | `Map<String, Any>` | Kandungan elemen selepas teks ditambah. |
|  | Any | Keputusan yang dikembalikan. |

### Contoh isi respons

```text
HTTP/1.1 200 OK
Content-Type:application/json

{
  "success" : true,
  "result" : {
    "data" : {
      "text" : "abctext"
    }
  }
}
```

### Kod ralat

Jika ralat dikembalikan semasa anda memanggil API ini, cari penyelesaian dalam dokumen [Kod ralat global](/open/development/server-api-error-codes-1) berdasarkan mesej ralat.

| HttpCode | Kod ralat | Mesej ralat | Penerangan |
| --- | --- | --- | --- |
| 400 | paramError | %s | Ralat parameter. |
| 400 | invalidRequest.inputArgs.invalid | %s | Ralat parameter. Lihat mesej ralat untuk butiran. |
| 403 | forbidden.accessDenied | %s | Tiada kebenaran. |
| 403 | forbidden.acrossOrg | %s | Permintaan tidak sah. Semak sama ada dokumen sasaran adalah milik organisasi yang ditentukan oleh access token. |
| 404 | docNotExist | %s | Dokumen tidak wujud. |
| 404 | invalidRequest.resource.notFound | %s | Sumber yang diminta tidak dapat ditemui. |
| 500 | forbidden.operationIllegal | %s | Operasi yang diminta tidak sah. |
| 500 | systemError | %s | Perkhidmatan sedang sibuk. Cuba lagi kemudian. |
| 500 | unknownError | Unknown Error | Ralat tidak diketahui. |
| 503 | operationTimeout | %s | Permintaan tamat masa. |
