description: "Call this API to query the members of a video meeting by page."

Panggil API ini untuk menanyakan ahli mesyuarat video mengikut halaman.

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/conference/videoConferences/{conferenceId}/members` |
| Kaedah HTTP | GET |
| Jenis aplikasi disokong | appType-Aplikasi dalaman　appType-Aplikasi perusahaan pihak ketiga |
| Kebenaran diperlukan | permission-VideoConference.Conference.Read-Kebenaran baca mesyuarat video |

### Header permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses yang digunakan untuk memanggil API ini.   - Untuk aplikasi dalaman, panggil API [Dapatkan access token aplikasi dalaman](/open/development/obtain-the-access-token-of-an-internal-app) untuk mendapatkannya. - Untuk aplikasi perusahaan pihak ketiga, panggil API untuk mendapatkan access token bagi organisasi yang memberi kebenaran kepada aplikasi pihak ketiga tersebut. |

### Parameter laluan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| conferenceId | String | Ya | conferenceId bagi mesyuarat tersebut. Anda boleh mendapatkannya dengan memanggil API [Cipta mesyuarat video](/open/development/create-a-video-conference). |

### Parameter pertanyaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| nextToken | String | Tidak | Cursor pagination.   - Jika anda memanggil API ini buat kali pertama, biarkan parameter ini kosong atau tetapkan kepada 0. - Untuk panggilan seterusnya, tetapkan parameter ini kepada nextToken yang dikembalikan oleh panggilan sebelumnya. |
| maxResults | Integer | Tidak | Bilangan maksimum entri setiap halaman. Nilai lalai: 128. Tiada had atas. |

### Contoh permintaan

```http
GET /v1.0/conference/videoConferences/6323dxxxxx/members?nextToken=0&maxResults=20 HTTP/1.1
```

## Respons

### Isi respons

| Nama | Jenis | Penerangan |
| --- | --- | --- |
| memberModels | Array | Senarai ahli. |
| unionId | String | unionId bagi ahli. |
| conferenceId | String | ID mesyuarat video. |
| userNick | String | Nama ahli. |
| joinTime | Long | Cap masa ketika ahli menyertai mesyuarat, dalam milisaat. |
| leaveTime | Long | Cap masa ketika ahli meninggalkan mesyuarat, dalam milisaat. |
| duration | Long | Tempoh masa dalam mesyuarat, dalam milisaat. |
| host | Boolean | Sama ada ahli tersebut adalah tuan rumah.   - true: Ya - false: Tidak |
| attendStatus | Integer | Status ahli.   - 1: Dimulakan - 2: Sedang memanggil - 3: Aktif (dalam mesyuarat) - 4: Gagal menyertai (panggilan ditolak, dan lain-lain) - 5: Dikeluarkan - 6: Telah meninggalkan mesyuarat |
| outerOrgMember | Boolean | Sama ada ahli tersebut berasal dari luar organisasi yang memiliki mesyuarat.   - true: Ya - false: Tidak       Medan ini tidak dikembalikan jika ahli semasa tergolong dalam organisasi yang memiliki mesyuarat. |
| pstnJoin | Boolean | Sama ada ahli menyertai mesyuarat melalui nombor telefon.   - true: Ya - false: Tidak |
| coHost | Boolean | Sama ada ahli tersebut adalah tuan rumah bersama.   - true: Ya - false: Tidak |
| nextToken | String | Cursor pagination. |
| totalCount | Integer | Jumlah bilangan entri. |
