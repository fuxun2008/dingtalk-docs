---
title: "Dapatkan maklumat pratonton atau edit fail"
description: "Panggil API ini untuk mendapatkan pautan pratonton atau edit bagi fail dalam ruang storan, membolehkan pengguna yang dibenarkan melihat atau mengedit fail melalui pautan tersebut."
---

Panggil API ini untuk mendapatkan pautan pratonton atau edit bagi fail dalam ruang storan. Pengguna yang mempunyai kebenaran yang diperlukan boleh melihat atau mengedit fail melalui pautan tersebut.

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/storage/spaces/{spaceId}/dentries/{dentryId}/openInfos/query` |
| Kaedah HTTP | POST |
| Jenis aplikasi disokong | appType-Aplikasi dalaman　appType-Aplikasi perusahaan pihak ketiga |
| Kebenaran diperlukan | permission-Storage.File.Read-Kebenaran baca fail storan organisasi |

### Header permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Dapatkan seperti berikut:   - Untuk aplikasi dalaman, panggil API [Dapatkan access token aplikasi dalaman](/open/development/obtain-the-access-token-of-an-internal-app). - Untuk aplikasi perusahaan pihak ketiga, panggil API [Dapatkan access token organisasi yang dibenarkan kepada aplikasi pihak ketiga](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1). |

### Parameter laluan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| spaceId | String | Ya | ID ruang. Panggil API [Tambah ruang](/open/development/add-space) untuk mendapatkan nilai parameter id. |
| dentryId | String | Ya | ID fail. Panggil API [Dapatkan senarai fail atau folder](/open/development/get-a-list-of-files-or-folders) atau [Dapatkan spaceId dan dentryId melalui dentryUuid](/open/development/api-getdentryidbyuuid) untuk mendapatkan nilai parameter id. |

### Parameter query

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| unionId | String | Ya | unionId bagi pengendali. Panggil API [Semak butiran pengguna](/open/development/query-user-details) untuk mendapatkan nilai parameter unionid. |

### Isi permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| option | Object | Tidak | Parameter pilihan. |
| version | Long | Tidak | Nombor versi bagi fail yang ditentukan. Panggil API [Dapatkan senarai fail atau folder](/open/development/get-a-list-of-files-or-folders) untuk mendapatkan nilai parameter id. |
| type | String | Tidak | Mod buka fail:   - **PREVIEW**: Pratonton. Nilai lalai. - **EDIT**: Edit. |
| waterMark | Boolean | Tidak | Sama ada tera air diperlukan:   - **true**: Diperlukan. - **false**: Tidak diperlukan. Nilai lalai.   Pada masa ini, hanya fail berformat WPS (Word, Excel, PPT, PDF) menyokong tera air. |
| checkLogin | Boolean | Tidak | Sama ada status log masuk DingTalk perlu disemak. Parameter ini hanya berkuat kuasa apabila nilai type ialah PREVIEW.   - **true**: Semak. Status log masuk DingTalk disahkan semasa memasuki halaman. Jika pengguna belum log masuk, halaman akan dialihkan ke halaman log masuk, kemudian meneruskan ke halaman semasa selepas berjaya log masuk. - **false** (lalai): Jangan semak. Status log masuk DingTalk tidak disahkan semasa memasuki halaman, tetapi sekatan berikut dikenakan:    - Menyokong format dokumen asas (Word, Excel, PPT, PDF), sebahagian format gambar (jpg, jpeg, jpe, png, gif, bmp, pcx, jiff, tiff, tif, ico, fax, wbmp, webp), dan semua jenis fail audio dan video. Tindakan Hantar semula, Edit dalam talian, Muat turun, dan tindakan lain di penjuru kanan atas tetingkap pratonton tidak disokong.   - Setelah diperoleh, pautan hanya boleh diakses sekali (bagi setiap sesi pelayar).   - Setelah diperoleh, pautan akan tamat tempoh secara automatik selepas 5 minit tidak digunakan. |
