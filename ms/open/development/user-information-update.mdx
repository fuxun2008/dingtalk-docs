Panggil API ini untuk mengemas kini maklumat pengguna yang ditentukan.

## Penerangan panggilan API

API ini mengemas kini maklumat akaun pengguna biasa atau pengguna Akaun Syarikat. Oleh sebab penggunaan parameter berbeza dengan ketara antara kedua-dua senario ini, dokumentasi dibahagikan mengikut jenis akaun untuk rujukan yang lebih mudah:

- Untuk mengemas kini maklumat pengguna biasa, rujuk dokumen ini.
- Untuk mengemas kini maklumat pengguna Akaun Syarikat, rujuk [Kemas kini maklumat pengguna Akaun Syarikat](/ms/open/development/update-dedicated-accounts-information).

## Permintaan

| **Maklumat asas** | |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/topapi/v2/user/update |
| Kaedah HTTP | POST |
| Jenis aplikasi disokong | appType-Aplikasi dalaman |
| Kebenaran diperlukan | permission-qyapi_manage_addresslist-Kebenaran pengurusan data Kenalan |

### Parameter pertanyaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | be3Fxxxx | Kelayakan aplikasi yang digunakan untuk memanggil API ini. Dapatkan melalui API untuk mendapatkan [access_token aplikasi dalaman](/ms/open/development/obtain-orgapp-token). |

### Isi permintaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| userid | String | Ya | user123 | ID pengguna bagi pekerja. |
| name | String | Tidak | Zhang San | Nama pekerja. Panjang maksimum: 80 aksara. |
| hide_mobile | Boolean | Tidak | false | Sama ada untuk menyembunyikan Nombor Telefon:   - **true**: Sembunyikan. Setelah disembunyikan, Nombor Telefon disembunyikan pada halaman profil, tetapi pengguna lain masih boleh menghantar DING dan membuat panggilan perniagaan DingTalk percuma kepada pengguna ini. - **false**: Jangan sembunyikan. |
| telephone | String | Tidak | 010-86123456-2345 | Nombor sambungan. Panjang maksimum: 50 aksara.  **Nota**  Nombor sambungan mesti unik dalam Organisasi Anda. |
| job_number | String | Tidak | 4 | ID Pekerja. Panjang maksimum: 50 aksara. |
| manager_userid | String | Tidak | 0001 | ID pengguna bagi penyelia terus. |
| title | String | Tidak | Pengarah Teknikal | Jawatan. Panjang maksimum: 200 aksara. |
| email | String | Tidak | test@xxx.com | E-mel pekerja. Panjang maksimum: 50 aksara.  **Nota**  E-mel pekerja mesti unik dalam Organisasi Anda. |
| org_email | String | Tidak | test@xxx.com | E-mel Syarikat bagi pekerja.  **Nota**  Medan ini hanya berkuat kuasa apabila E-mel Syarikat pekerja tersebut telah diaktifkan. |
| work_place | String | Tidak | Future Park | Lokasi Kerja. Panjang maksimum: 100 aksara. |
| remark | String | Tidak | Maklumat catatan | Alias. Panjang maksimum: 2,000 aksara. |
| dept_id_list | String | Tidak | "2,3,4" | Senarai ID jabatan yang menjadi milik pengguna. |
| dept_order_list | DeptOrder[] | Tidak |  | Susunan pekerja dalam setiap jabatan. |
| dept_id | Number | Tidak | 2 | ID jabatan. |
| order | Number | Tidak | 1 | Susunan pekerja dalam jabatan tersebut. Nilai yang lebih besar meletakkan pekerja lebih tinggi dalam senarai. |
| extension | Number | Tidak | `{"Hobby":"Travel","Age":"24"}` | Atribut sambungan. Panjang maksimum: 2,000 aksara.  **Nota**   - Paling banyak 10 atribut sambungan boleh dipaparkan pada peranti mudah alih. - Jika seorang pekerja mempunyai 10 medan atribut sambungan yang dikonfigurasi, semua 10 medan tersebut mesti dihantar semasa kemas kini, walaupun nilainya tidak berubah. Jika anda hanya menghantar satu medan, sembilan medan lain akan dikosongkan. - Sebelum menggunakan parameter ini, tambah atribut tersebut dalam [**DingTalk Admin Console**](https://oa.dingtalk.io/index.htm#/setting#setOrgInfo) > **Kenalan** > **Tetapan kenalan dalaman** > **Urus medan pengguna**. - Nilai medan ini menyokong jenis pautan, dan pautan tersebut menyokong penggantian automatik bagi kad bebas pembolehubah. Kad bebas yang disokong pada masa ini ialah: userid dan corpid. Contoh: `[Alamat nombor meja](http://www.dingtalk.io?userid=#userid#&corpid=#corpid#)`. |
| ext_attrs_update_mode | Number | Tidak | 1 | Mod kemas kini untuk medan atribut sambungan tersuai:   - 0: Mod tulis ganti - 1: Mod tambah   Lalai ialah tulis ganti. |
| senior_mode | Boolean | Tidak | false | Sama ada untuk mengaktifkan mod eksekutif. Lalai: false.   - **true**: Aktifkan.  **Nota**      - Apabila diaktifkan, Nombor Telefon disembunyikan daripada semua pekerja.   - Pekerja biasa tidak boleh menghantar DING atau membuat panggilan perniagaan DingTalk kepada pengguna ini.   - Eksekutif boleh menghantar DING dan membuat panggilan perniagaan DingTalk antara satu sama lain. - **false**: Jangan aktifkan. |
| hired_date | Number | Tidak | 1597573616828 | Tarikh diambil bekerja. Unix timestamp, dalam milisaat. |
| language | String | Tidak | zh_CN | Bahasa Kenalan:   - **zh_CN**: Bahasa Cina (lalai). - **en_US**: Bahasa Inggeris. |
| force_update_fields | String | Tidak | manager_userid | Medan yang perlu dipaksa kemas kini. Menyokong pengosongan medan yang ditentukan. Pisahkan berbilang medan dengan koma. Medan yang disokong pada masa ini: `manager_userid`. |
| dept_position_list | DeptPosition[] | Tidak |  | Maklumat kedudukan dalam jabatan. |
| extension_i18n | Json | Tidak | `{"Hobby": {"zh_CN": "旅游", "en_US": "travel", "aJP": "旅行"}}` | Nilai antarabangsa bagi atribut sambungan. |

### Contoh permintaan

```bash
curl -X POST "https://api.dingtalk.io/topapi/v2/user/update" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=c6c3c34d-23dd-4da7-9901-0af1ebceaf80' \
-d 'name=John' \
-d 'telephone=010-86123456-2345' \
-d 'hide_mobile=false' \
-d 'userid=zhangsan'
```

Java

```java
req.setJobNumber("4");
req.setManagerUserid("0001");
req.setTitle("Technical Director");
req.setEmail("test@xxx.com");
req.setOrgEmail("test@xxx.com");
req.setWorkPlace("Future Park");
req.setRemark("Remark");
req.setDeptIdList("2,3,4");
List<DeptOrder> list2 = new ArrayList<DeptOrder>();
DeptOrder obj3 = new DeptOrder();
list2.add(obj3);
obj3.setDeptId(2L);
obj3.setOrder(1L);

req.setExtension("{\"Hobby\":\"Travel\",\"Age\":\"24\"}");
```


## Respons

### Isi respons

| Nama | Jenis | Contoh | Penerangan |
| --- | --- | --- | --- |
| errcode | Number | 0 | Kod pulangan. 0 menunjukkan Berjaya. |
| errmsg | String | User not found | Mesej ralat yang dikembalikan apabila Panggilan gagal. |

### Contoh isi respons

```json
{
  "errcode": 0,
  "request_id": "55o5i31j4cg8"
}
```

### Kod ralat

Jika ralat dikembalikan semasa anda memanggil API ini, rujuk dokumen [Kod ralat global](/ms/open/development/server-api-error-codes-1) untuk mencari penyelesaian.
