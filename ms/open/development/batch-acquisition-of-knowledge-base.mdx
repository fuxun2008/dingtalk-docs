Gunakan API ini untuk mendapatkan Knowledge Base secara kelompok. Semasa memanggil API, hantar permintaan POST yang mengandungi medan perniagaan seperti `workspaceIds`, `option`, dan `withPermissionRole`.

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/v2.0/wiki/workspaces/batchQuery |
| Kaedah HTTP | POST |
| Jenis aplikasi disokong | appType-Aplikasi dalaman　appType-Aplikasi perusahaan pihak ketiga |
| Kebenaran diperlukan | permission-Wiki.Workspace.Read-Kebenaran baca Knowledge Base |

### Pengepala permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses yang digunakan untuk memanggil API ini. Dapatkan seperti berikut:   - Untuk aplikasi dalaman, panggil API [Dapatkan access token aplikasi dalaman](/ms/open/development/obtain-the-access-token-of-an-internal-app#). - Untuk aplikasi perusahaan pihak ketiga, panggil API [Dapatkan access token organisasi yang diberi kuasa kepada aplikasi pihak ketiga](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#). |

### Parameter pertanyaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| operatorId | String | Ya | unionId bagi operator. |

### Isi permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| workspaceIds | Array of String | Ya | ID Knowledge Base. Panggil API [Dapatkan senarai Knowledge Base](/ms/open/development/get-knowledge-base-list#) dan dapatkan nilai medan `workspaceId` daripada respons.  Saiz maksimum ialah 20. |
| option | Object | Tidak | Parameter pilihan. |
| withPermissionRole | Boolean | Tidak | Sama ada untuk mengembalikan maklumat kebenaran:   - **true**: Kembalikan - **false**: Jangan kembalikan   Lalai: false. |
