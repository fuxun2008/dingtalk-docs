Panggil API ini untuk mendapatkan senarai Knowledge Base berdasarkan unionId operator.

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/v2.0/wiki/workspaces |
| Kaedah HTTP | GET |
| Jenis aplikasi yang disokong | appType-Aplikasi dalaman　appType-Aplikasi perusahaan pihak ketiga |
| Kebenaran yang diperlukan | permission-Wiki.Workspace.Read-Kebenaran membaca Knowledge Base |

### Header permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Dapatkan seperti berikut:   - Untuk aplikasi dalaman, panggil API [Get the access token of an internal app](/open/development/obtain-the-access-token-of-an-internal-app#). - Untuk aplikasi perusahaan pihak ketiga, panggil API [Get the access token of an organization authorized to a third-party app](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#). |

### Parameter query

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| nextToken | String | Tidak | Cursor pagination. Biarkan kosong untuk permintaan pertama. |
| maxResults | Integer | Tidak | Saiz halaman. Lalai ialah 30. Maksimum ialah 30. |
| orderBy | String | Tidak | Susunan pengisihan. Nilai enum:   - **VIEW_TIME_DESC**: Susun mengikut masa tontonan secara menurun. - **CREATE_TIME_DESC**: Susun mengikut masa dicipta secara menurun. - **MODIFIED_TIME_DESC**: Susun mengikut masa pengubahsuaian secara menurun. |
| withPermissionRole | Boolean | Tidak | Sama ada untuk turut menyoal kebenaran:   - true: Soal. - false: Jangan soal.   Lalai ialah false. |
| operatorId | String | Ya | unionId operator. |

### Contoh permintaan

| url | String | URL akses Knowledge Base. |
| icon | Object | Ikon Knowledge Base. |
| type | String | Jenis ikon. Nilai enum:   - **URL**: Pautan. - **EMOJI**: Ikon emoji. |

| creatorId | String | userId pencipta Knowledge Base. |
| modifierId | String | userId pengubah suai Knowledge Base. |
| createTime | String | Masa dicipta Knowledge Base. |
| modifiedTime | String | Masa pengubahsuaian Knowledge Base. |
| permissionRole | String | Peranan kebenaran pemohon terhadap Knowledge Base. Nilai enum:   - **OWNER**: Pemilik. - **MANAGER**: Pengurus. - **EDITOR**: Editor. - **DOWNLOADER**: Pemapar dengan kebenaran muat turun. - **READER**: Hanya boleh dipapar. - **NONE**: Tiada kebenaran. |
| nextToken | String | Cursor pagination. Nilai yang tidak kosong menunjukkan terdapat lebih banyak data yang tersedia. |
