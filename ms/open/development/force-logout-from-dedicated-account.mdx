title: "Paksa log keluar Akaun Syarikat"
description: "Panggil API ini untuk memaksa log keluar Akaun Syarikat tertentu dalam DingTalk dan segera menamatkan sesi log masuk semasa pengguna."

Panggil API ini untuk memaksa log keluar Akaun Syarikat yang ditentukan.

## Penerangan panggilan API

Dalam senario tertentu yang memerlukan paksaan log keluar Akaun Syarikat secara segera, panggil API ini untuk melaksanakan paksaan log keluar tersebut.

Selepas log keluar, DingTalk pada pihak pengguna akan dipaparkan seperti berikut:

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/v1.0/contact/orgAccounts/signOut |
| Kaedah HTTP | POST |
| Jenis aplikasi yang disokong | appType-Internal app |
| Kebenaran diperlukan | permission-Contact.OrgAccountSecurity.ReadWrite-Read and write permissions for Contacts Enterprise Account security data |

### Pengepala permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Dapatkan dengan memanggil [Dapatkan access token aplikasi dalaman](/open/development/obtain-the-access-token-of-an-internal-app). |

### Isi permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| userId | String | Ya | ID pengguna bagi Akaun Syarikat. Dapatkan melalui salah satu daripada empat kaedah berikut:   - [Dapatkan ID pengguna melalui nombor telefon bimbit](/open/development/obtain-the-userid-of-your-mobile-phone-number) - [Cipta Akaun Syarikat SSO](/open/development/create-an-sso-account) - [Cipta Akaun Syarikat yang dicipta oleh DingTalk](/open/development/create-dingtalk-user-created-dedicated-account) - [Jemput Akaun Syarikat daripada organisasi lain untuk menyertai](/open/development/invite-other-organization-specific-accounts-to-join) |
| reason | String | Tidak | Sebab untuk memaksa log keluar Akaun Syarikat (dipaparkan dalam log audit Admin Console DingTalk). |
| reasonI18nForEmployee | `Map<String, String>` | Tidak | - Sebab untuk memaksa log keluar Akaun Syarikat (dipaparkan kepada pekerja). - Contoh: `{"zh_CN":"Reason for logging out","en_US":"Reason for logging out"}` - Bahasa yang disokong merujuk kepada bahasa semasa klien DingTalk. Contohnya: `zh_CN`, `zh_HK`, `zh_TW`, `en_US`, `ja_JP`, `vi_VN`, `fr_FR`, `ru_RU`, `ko_KR`, `es_LA`, `tr_TR`, `pt_BR`, `ms_MY`, `id_ID`, `th_TH`. |
