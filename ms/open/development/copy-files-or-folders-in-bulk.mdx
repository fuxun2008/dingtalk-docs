Panggil API ini untuk menyalin fail atau folder secara pukal ke ruang atau folder lain.

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/storage/spaces/{spaceId}/dentries/batchCopy` |
| Kaedah HTTP | POST |
| Jenis aplikasi yang disokong | appType-Internal app　appType-Third-party enterprise app |
| Kebenaran yang diperlukan | permission-Storage.File.Write-Storage file write permission |

### Header permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Dapatkan seperti berikut:   - Untuk aplikasi dalaman, panggil API [Obtain the access token of an internal app](/open/development/obtain-the-access-token-of-an-internal-app). - Untuk aplikasi perusahaan pihak ketiga, panggil API [Obtain the access token of the authorized enterprise](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1). |

### Parameter laluan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| spaceId | String | Ya | ID ruang tempat fail atau folder sumber berada. Panggil API [Add space](/open/development/add-space) untuk mendapatkan nilai parameter id. |

### Parameter pertanyaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| unionId | String | Ya | unionId bagi pengendali. Panggil API [Query user details](/open/development/query-user-details) untuk mendapatkan nilai parameter unionid. |

### Isi permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| targetSpaceId | String | Ya | ID ruang tempat fail atau folder sasaran berada. Panggil API [Add space](/open/development/add-space) untuk mendapatkan nilai parameter id. |
| targetFolderId | String | Ya | ID folder sasaran. ID folder root ialah 0. Panggil API [Get a list of files or folders](/open/development/get-a-list-of-files-or-folders) untuk mendapatkan nilai parameter id. |
| dentryIds | Array of String | Ya | Senarai ID fail atau folder sumber. Sehingga 3 ID boleh ditetapkan. Panggil API [Get a list of files or folders](/open/development/get-a-list-of-files-or-folders) atau [Get the spaceId and dentryId by dentryUuid](/open/development/api-getdentryidbyuuid) untuk mendapatkan nilai parameter id. |
| option | Object | Tidak | Parameter pilihan. |
| conflictStrategy | String | Tidak | Strategi untuk mengendalikan konflik nama fail atau folder.   - **AUTO_RENAME** (lalai): Namakan semula secara automatik. - **OVERWRITE**: Tulis ganti. - **RETURN_DENTRY_IF_EXISTS**: Kembalikan fail sedia ada. - **RETURN_ERROR_IF_EXISTS**: Kembalikan ralat jika fail sudah wujud. |

## Respons

### Isi respons

| Nama | Jenis | Penerangan |
| --- | --- | --- |
| resultItems | Array | Senarai hasil operasi salinan pukal bagi fail atau folder. |
| spaceId | String | ID ruang tempat fail atau folder sumber berada. |
| dentryId | String | ID fail atau folder sumber. |
| async | Boolean | Menunjukkan sama ada tugas ini bersifat asynchronous.   - **true**: Ya. - **false**: Tidak.   Jika folder yang dikendalikan mempunyai nod anak, operasi ini diproses secara asynchronous. |
| success | Boolean | Menunjukkan sama ada operasi berjaya.   - **true**: Berjaya. - **false**: Gagal.   Medan ini tidak dikembalikan untuk tugas asynchronous. |
| errorCode | String | Sebab ralat. Medan ini tidak dikembalikan untuk tugas asynchronous. |
| taskId | String | ID tugas asynchronous, yang boleh digunakan untuk menyemak status pelaksanaan tugas. |
| targetSpaceId | String | ID ruang sasaran. Medan ini dikembalikan untuk operasi synchronous dan asynchronous, kecuali dalam kes kegagalan. |
| targetDentryId | String | ID fail atau folder selepas disalin. Medan ini dikembalikan untuk operasi synchronous dan asynchronous, kecuali dalam kes kegagalan. |
