Panggil API ini untuk mencipta syif kehadiran DingTalk.

## Permintaan

| **Maklumat asas** | |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/topapi/attendance/shift/add |
| Kaedah HTTP | POST |
| Jenis aplikasi yang disokong | appType-Aplikasi dalaman |
| Kebenaran yang diperlukan | permission-qyapi_attendance_group_manage-Kebenaran pengurusan kumpulan kehadiran |

### Parameter pertanyaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | 6d1bxxxx | Kelayakan aplikasi yang digunakan untuk memanggil API ini. Dapatkannya dengan memanggil API [Dapatkan access_token aplikasi dalaman](/ms/open/development/obtain-orgapp-token). |

### Isi permintaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| op_user_id | String | Ya | user01 | userId pengendali. |
| shift | TopAtClassVo | Ya |  | Syif. |
| owner | String | Tidak | user01 | Pemilik syif. |
| class_group_name | String | Tidak | def | Nama kumpulan syif. |
| corp_id | String | Tidak | ding23 | ID organisasi (corpId). Cari ID ini di [Konsol Pembangun](https://open-dev.dingtalk.io/). CorpId |
| name | String | Ya | Syif siang | Nama syif. |
| id | Number | Tidak | 124 | ID syif. Dapatkannya dengan memanggil API [Dapatkan ringkasan syif](/ms/open/development/enterprise-shift-query-in-batches).  **Nota**  Biarkan id kosong untuk mencipta syif. Nyatakan id untuk mengubah suai syif sedia ada. |
| sections | TopAtSectionVo[] | Ya |  | Seksyen daftar masuk. |
| times | TopAtTimeVo[] | Ya |  | Maklumat daftar masuk. |
| check_type | String | Ya | OnDuty | Jenis daftar masuk:   - **OnDuty**: Daftar masuk - **OffDuty**: Daftar keluar |
| across | Number | Ya | 0 | Sama ada masa merentasi ke hari berikutnya:   - **0**: Hari yang sama - **1**: Hari berikutnya |
| end_min | Number | Tidak | -1 | Masa daftar masuk terlewat yang dibenarkan, dalam minit. -1 bermaksud tiada had. |
| check_time | Date | Ya | 2020-12-02 09:00:00 | Masa daftar masuk. |
| free_check | Boolean | Tidak | false | Sama ada dikecualikan daripada daftar masuk:   - **false**: Daftar masuk diperlukan - **true**: Dikecualikan daripada daftar masuk |
| begin_min | Number | Tidak | 30 | Masa terawal yang dibenarkan untuk daftar masuk lebih awal, dalam minit. |
| setting | TopAtClassSettingVo | Tidak |  | Tetapan. |
| rest_begin_time | TopAtTimeVo | Tidak |  | Permulaan waktu rehat. |
| check_type | String | Tidak | OnDuty | Jenis rehat:   - **OnDuty**: Rehat bermula - **OffDuty**: Rehat tamat |
| check_time | Date | Tidak | 2020-12-02 09:00:00 | Masa daftar masuk rehat. |
| free_check | Boolean | Tidak | false | Sama ada dikecualikan daripada daftar masuk:   - **true**: Dikecualikan daripada daftar masuk - **false**: Daftar masuk diperlukan |
| across | Number | Tidak | 0 | Sama ada masa merentasi ke hari berikutnya. Merentasi bermaksud waktu rehat jatuh pada hari berikutnya:   - **0**: Hari yang sama - **1**: Hari berikutnya |
| class_id | Number | Tidak | 221 | ID syif. Dapatkannya dengan memanggil API [Dapatkan ringkasan syif](/ms/open/development/enterprise-shift-query-in-batches). |
| is_flexible | Boolean | Tidak | false | Sama ada syif adalah fleksibel:   - **true**: Fleksibel - **false**: Tidak fleksibel |
| corp_id | String | Tidak | ding121 | ID organisasi (corpId). Cari ID ini di [Konsol Pembangun](https://open-dev.dingtalk.io/). CorpId |
| is_deleted | String | Tidak | N | Sama ada syif telah dipadam:   - **N**: Ya - **Y**: Tidak |
| rest_end_time | TopAtTimeVo | Tidak |  | Penamat waktu rehat. |
| check_type | String | Tidak | OffDuty | Jenis rehat:   - **OnDuty**: Rehat bermula - **OffDuty**: Rehat tamat |
| check_time | Date | Tidak | 2020-12-02 09:00:00 | Masa rehat. |
| free_check | Boolean | Tidak | false | Sama ada dikecualikan daripada daftar masuk:   - **false**: Daftar masuk diperlukan - **true**: Dikecualikan daripada daftar masuk |
| across | Number | Tidak | 1 | Sama ada masa merentasi ke hari berikutnya. Merentasi bermaksud waktu rehat jatuh pada hari berikutnya:   - **0**: Hari yang sama - **1**: Hari berikutnya |
| serious_late_minutes | Number | Tidak | 31 | Tempoh yang dikira sebagai kelewatan atau pulang awal yang serius, dalam minit. |
| absenteeism_late_minutes | Number | Tidak | 60 | Tempoh kelewatan atau pulang awal yang dikira sebagai ponteng kerja, dalam minit.  **Nota**  Nilai ini mesti lebih besar daripada tempoh kelewatan serius. |
| extras | Json | Tidak | `{"cause":"{\"type\":\"approve\",\"relatedId\":\"43494469-21a6-4111-953b-7810a709f27f\"}"}` | Medan lanjutan untuk tetapan syif. Tidak diperlukan untuk syif bukan sementara. |
| tags | String | Tidak | temp:schedule:isv | Tag syif. Tidak diperlukan untuk syif bukan sementara. |
| service_id | Number | Tidak | 123 | ID perkhidmatan yang terikat dengan penjadualan syif Premium. Tidak diperlukan untuk syif bukan sementara. |

### Contoh permintaan

```curl
curl -X POST "https://api.dingtalk.io/topapi/attendance/shift/add" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=39cbcxxxx9058' \
-d 'op_user_id=abc' \
-d 'shift=null'
```

## Respons

### Isi respons

| Nama | Jenis | Contoh | Penerangan |
| --- | --- | --- | --- |
| result | TopAtClassVo |  | Maklumat syif. |
| id | Number | 706715401 | ID syif. |
| name | String | A1 | Nama syif. |
| errmsg | String | ok | Penerangan kod pemulangan. |
| errcode | Number | 0 | Kod pemulangan. |
| success | Boolean | true | Sama ada panggilan berjaya:   - **true**: Berjaya - **false**: Gagal |
| request_id | String | wp2oh4e4vlbu | ID permintaan. |

### Contoh isi respons

```json
{
  "errcode": 0,
  "errmsg":"ok",
  "result": {
    "id": 706715401,
    "name": "A1"
  },
  "success": true,
  "request_id": "wp2oh4e4vlbu"
}
```

Jika panggilan API mengembalikan ralat, cari penyelesaian dalam Dokumen [Kod ralat global](/ms/open/development/server-api-error-codes-1) berdasarkan mesej ralat.
