Panggil API ini untuk mencipta instans kelulusan tanpa aliran kerja. Simpan ID instans kelulusan yang dikembalikan untuk digunakan dalam panggilan API seterusnya.

## Penerangan panggilan API

API ini mengenakan pengesahan yang lebih ketat terhadap data masuk untuk menghalang data tidak sah dihantar kepada API terbuka.

- Untuk kawalan pilihan tunggal dan pilihan berbilang, setiap nilai pilihan yang dihantar mesti dikonfigurasi dalam senarai pilihan.
- Untuk kawalan kenalan dalaman, userID yang dihantar mesti milik ahli aktif organisasi semasa.
- Untuk kawalan jabatan, ID jabatan mesti merupakan ID jabatan yang sah dalam organisasi semasa.
- Untuk kawalan borang kelulusan berkaitan, ID instans yang dihantar mesti merupakan ID instans kelulusan sedia ada dalam organisasi semasa.

Borang kelulusan yang dimulakan tanpa mematuhi peraturan ini mungkin gagal dicipta selepas pengesahan data borang yang dipertingkatkan berkuat kuasa.

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/v1.0/workflow/processCentres/instances |
| Kaedah HTTP | POST |
| Jenis aplikasi yang disokong | appType-Aplikasi dalaman　appType-Aplikasi perusahaan pihak ketiga |
| Kebenaran yang diperlukan | permission-Workflow.Instance.Write-Kebenaran tulis instans aliran kerja |

### Pengepala permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Dapatkannya seperti berikut:   - Aplikasi dalaman: Panggil API [Dapatkan access token aplikasi dalaman](/ms/open/development/obtain-the-access-token-of-an-internal-app). - Aplikasi perusahaan pihak ketiga: Panggil API untuk mendapatkan access token organisasi yang telah memberikan kebenaran kepada aplikasi pihak ketiga. |
