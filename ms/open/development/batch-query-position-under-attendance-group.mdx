---

Panggil API ini untuk mendapatkan senarai lokasi bagi kumpulan kehadiran yang ditetapkan secara berkelompok.

## Permintaan

| **Maklumat asas** | |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/topapi/attendance/group/positions/query |
| Kaedah HTTP | POST |
| Jenis aplikasi yang disokong | appType-Aplikasi dalaman |
| Kebenaran | permission-qyapi_attendance_group_read-Kebenaran pertanyaan kumpulan kehadiran |

### Parameter pertanyaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | 4c9ebd2b15xxxx | Kelayakan aplikasi yang digunakan untuk memanggil API ini. Dapatkannya dengan memanggil API [Dapatkan access_token Aplikasi dalaman](/ms/open/development/obtain-orgapp-token). |

### Isi permintaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| cursor | String | Tidak | 0151Exxxx | Biarkan kosong untuk permintaan pertama. Untuk permintaan seterusnya apabila has_more ialah true, tetapkan cursor kepada nilai position_key terakhir dalam hasil permintaan sebelumnya. |
| size | Number | Ya | 50 | Saiz halaman. |
| op_userid | String | Tidak | user01 | ID pengguna bagi pengendali. |
| group_key | String | Ya | CEDDFxxxx | ID kumpulan kehadiran.  **Nota**  Jika pengecam kumpulan kehadiran anda ialah group_id, panggil API [Tukar groupId kepada groupKey](/ms/open/development/groupid-to-groupkey) untuk menukar group_id kepada group_key. |

### Contoh permintaan

```curl
curl -X POST "https://api.dingtalk.io/topapi/attendance/group/positions/query" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=80645xxxx3164b3' \
-d 'cursor=0151E02xxxx7E876' \
-d 'group_key=0151ExxxxA1A917E876' \
-d 'op_userid=123456' \
-d 'size=50'
```

Java

```java
DingTalkClient client = new DefaultDingTalkClient("https://api.dingtalk.io/topapi/attendance/group/positions/query");
OapiAttendanceGroupPositionsQueryRequest req = new OapiAttendanceGroupPositionsQueryRequest();
req.setCursor("0151Exxxx");
req.setSize(50L);
req.setOpUserid("user01");
req.setGroupKey("CEDDFxxxx");
OapiAttendanceGroupPositionsQueryResponse rsp = client.execute(req, access_token);
System.out.println(rsp.getBody());
```

## Respons

### Isi respons

| Nama | Jenis | Contoh | Penerangan |
| --- | --- | --- | --- |
| result | DingOpenResult |  | Hasil yang dikembalikan. |
| result | Result |  | Hasil pertanyaan. |
| position_list | Position[] |  | Senarai lokasi. |
| offset | Number | 100 | Julat ofset yang dibenarkan bagi lokasi daftar masuk. |
| address | String | Kampus Xixi Alibaba Group | Penerangan alamat. |
| latitude | String | 30.123 | Latitud (sehingga 6 tempat perpuluhan). |
| longitude | String | 120.123 | Longitud (sehingga 6 tempat perpuluhan). |
| position_key | String | 9E459Fxxxx | Pengecam unik lokasi. |
| has_more | Boolean | false | Sama ada terdapat lebih banyak data.   - **true**: Ya - **false**: Tidak |
| errcode | Number | 0 | Kod pemulangan. |
| errmsg | String | ok | Penerangan kod pemulangan. |
| success | Boolean | true | Sama ada permintaan berjaya.   - **true**: Berjaya - **false**: Gagal |
| request_id | String | rss38gia1egs | ID permintaan. |

### Contoh isi respons

```json
{
  "result": {
    "errcode": 0,
    "errmsg":"ok",
    "result": {

```
