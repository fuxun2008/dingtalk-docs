Panggil API ini untuk menyemak senarai pekerja dalam organisasi Anda yang tidak log masuk ke DingTalk pada tarikh yang ditetapkan.

## Penerangan panggilan API

- Panggil API ini selepas jam 9:00 pagi untuk mendapatkan data hari sebelumnya.
- API ini hanya memulangkan senarai pekerja yang tidak log masuk ke DingTalk dalam tempoh sebulan yang lalu.

## Permintaan

| **Maklumat asas** | |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/topapi/inactive/user/v2/get |
| Kaedah HTTP | POST |
| Jenis aplikasi disokong | appType-Aplikasi dalaman |
| Kebenaran diperlukan | permission-qyapi_liveness_base-Kebenaran untuk mengakses data aktiviti organisasi |

### Parameter pertanyaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | 6d1bxxxx | Kelayakan aplikasi yang digunakan untuk memanggil API ini. Dapatkan dengan memanggil API untuk mendapatkan [access_token bagi aplikasi dalaman](/open/development/obtain-orgapp-token). |

### Isi permintaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| is_active | Boolean | Ya | false | Sama ada pengguna aktif:   - **false**: Tidak log masuk - **true**: Sudah log masuk |
| dept_ids | String | Tidak | 1,2,3 | Senarai ID jabatan. Dapatkan dengan memanggil [Dapatkan senarai jabatan](/open/development/user-management-acquires-the-list-departments). Jika dibiarkan kosong, keseluruhan organisasi akan disemak. |
| offset | Nombor | Ya | 1 | Menyokong penomboran halaman. Berkuat kuasa hanya apabila ditetapkan bersama parameter size. Parameter ini menunjukkan offset, bermula daripada 0. |
| size | Nombor | Ya | 100 | Menyokong penomboran halaman. Berkuat kuasa hanya apabila ditetapkan bersama parameter offset. Parameter ini menunjukkan saiz halaman. Nilai maksimum ialah 100. |
| query_date | String | Ya | 20200101 | Tarikh pertanyaan. Format ialah yyyyMMdd. |

### Contoh permintaan

```curl
curl -X POST "https://api.dingtalk.io/topapi/inactive/user/v2/get" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=2146ca78-23af-4580-9335-883348ff9a54' \
-d 'dept_ids=%5C%222%2C3%2C4%5C%22' \
-d 'is_active=false' \
-d 'offset=0' \
-d 'query_date=20200101' \
-d 'size=100'
```

Java

```text
DingTalkClient client = new DefaultDingTalkClient("https://api.dingtalk.io/topapi/inactive/user/v2/get");
OapiInactiveUserV2GetRequest req = new OapiInactiveUserV2GetRequest();
req.setIsActive(false);
req.setDeptIds("1,2,3");
req.setOffset(0L);
req.setSize(100L);
req.setQueryDate("20200101");
OapiInactiveUserV2GetResponse rsp = client.execute(req, access_token);
System.out.println(rsp.getBody());
```

## Respons

### Isi respons

| Nama | Jenis | Contoh | Penerangan |
| --- | --- | --- | --- |
| result | PageVo |  | Hasil yang dipulangkan. |
| next_cursor | Nombor | 1000 | Offset bagi halaman seterusnya. |
| list | String[] | ["user123","user456"] | Senarai pengguna yang tidak log masuk. |
| has_more | Boolean | false | Sama ada terdapat lagi data. |
| errmsg | String | ok | Penerangan kod pemulangan. |
| errcode | Nombor | 0 | Kod pemulangan. |
| request_id | String | o565d47xy9cz | ID permintaan. |

### Contoh isi respons


### Kod ralat

Jika berlaku ralat semasa memanggil API ini, rujuk dokumen [Kod ralat global](/open/development/server-api-error-codes-1) untuk mencari penyelesaian berdasarkan mesej ralat.

| Kod ralat (errcode) | Mesej ralat (errmsg) | Penyelesaian |
| --- | --- | --- |
| 400002 | Invalid parameter | Semak sama ada parameter wajib memenuhi keperluan. |
| 40069 | Invalid size | Semak saiz halaman. |
| 40068 | Invalid offset | Laraskan offset. |
| 400002 | Invalid parameter format | Semak format parameter input. |
| -1 | System busy | Cuba lagi kemudian. |
