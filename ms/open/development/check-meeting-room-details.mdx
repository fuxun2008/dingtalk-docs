Panggil API ini untuk menanya butiran bilik mesyuarat, termasuk nama bilik, kapasiti dan lokasi.

## Request

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/rooms/meetingRooms/{roomId}` |
| Kaedah HTTP | GET |
| Jenis aplikasi disokong | appType-Aplikasi dalaman　appType-Aplikasi perusahaan pihak ketiga |
| Kebenaran diperlukan | permission-VideoConference.Conference.Read-Kebenaran membaca maklumat mesyuarat video |

### Header permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses yang digunakan untuk memanggil API ini. Dapatkannya seperti berikut:  Untuk aplikasi dalaman, panggil API [Dapatkan access token aplikasi dalaman](/open/development/obtain-the-access-token-of-an-internal-app).  Untuk aplikasi perusahaan pihak ketiga, panggil API [Dapatkan access token organisasi yang diberi kuasa untuk aplikasi pihak ketiga](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1). |

### Parameter laluan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| roomId | String | Ya | ID bilik mesyuarat. Panggil API [Tanya senarai bilik mesyuarat](/open/development/check-the-meeting-room-list) untuk mendapatkannya. |

### Parameter kueri

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| unionId | String | Ya | unionId pengendali. Panggil API [Tanya butiran pengguna](/open/development/query-user-details) untuk mendapatkannya. |

## Respons

### Isi respons

| Nama | Jenis | Penerangan |
| --- | --- | --- |
| result | Object | Butiran bilik mesyuarat. |
| roomId | String | ID bilik mesyuarat. |
| roomStaffId | String | ID pekerja perusahaan bagi bilik mesyuarat. Medan terpelihara. Tidak digunakan. |
| corpId | String | ID Organisasi perusahaan pemilik bilik mesyuarat ini. |
| roomName | String | Nama bilik mesyuarat. |
| roomStatus | Integer | Status bilik mesyuarat:   - **0**: Tersedia untuk semua pengguna - **1**: Tersedia untuk pentadbir sahaja - **2**: Tersedia untuk pengguna tertentu |
| roomLabels | Array | Senarai tag bilik mesyuarat. |
| labelId | Long | ID tag:   - **1**: TV - **2**: Telefon - **3**: Projektor - **4**: Whiteboard - **5**: Mesyuarat Video |
| labelName | String | Nama tag. |
| roomCapacity | Integer | Kapasiti bilik mesyuarat. |
| roomLocation | Object | Maklumat lokasi bilik mesyuarat. |
| title | String | Nama lokasi bilik mesyuarat. |
| desc | String | Maklumat terperinci lokasi bilik mesyuarat. |
| roomPicture | String | Gambar bilik mesyuarat. |
| isvRoomId | String | ID bilik mesyuarat luaran pemanggil. |
| roomGroup | Object | Maklumat kumpulan bilik mesyuarat. |
| groupId | Long | ID kumpulan. |
| groupName | String | Nama kumpulan. |
| parentId | Long | ID kumpulan induk. |
| deviceUnionIds | Array of String | Senarai unionId. |
| reservationAuthority | Object | Kebenaran tempahan yang dikonfigurasikan untuk bilik mesyuarat apabila roomStatus ditetapkan kepada kebenaran separa. |
| authorizedMembers | Array | Senarai pengguna yang mempunyai kebenaran. |
| memberId | String | ID pengguna. Ditetapkan berdasarkan memberType:  User: unionId pengguna. Panggil API [Tanya butiran pengguna](/open/development/query-user-details) untuk mendapatkannya.  Department: ID jabatan, dept_id. Panggil API [Dapatkan senarai jabatan](https://open.dingtalk.com/document/development/obtain-the-department-list-v2) untuk mendapatkannya. |
| memberType | String | Jenis pengguna:   - **User**: pengguna - **Department**: jabatan |
| memberName | String | Nama pengguna:   - **User**: nama pengguna - **Department**: nama jabatan |
| enableCycleReservation | Boolean | Sama ada bilik mesyuarat menyokong tempahan berulang:   - **true**: Ya - **false**: Tidak |
| roomUnionId | String | unionId bilik mesyuarat. |
| extensionConfig | Object | Konfigurasi tambahan untuk bilik mesyuarat. |
| openReservation | Boolean | Sama ada bilik mesyuarat dibuka untuk tempahan:   - **true**: Ya - **false**: Tidak |
| maxReservationTimeInterval | Integer | Tempoh maksimum bagi satu tempahan, dalam minit. Nilai 0 menunjukkan tiada had. |
| minReservationTimeInterval | Integer | Tempoh minimum bagi satu tempahan, dalam minit. |
| advanceReservation | Object | Tempoh tempahan awal yang paling awal dibenarkan. |
| advanceReservationTime | Integer | Nilai khusus bagi masa tempahan awal. Unit ditentukan oleh medan advanceReservationTimeUnit. |
| advanceReservationTimeUnit | String | Unit masa:   - **days**: Hari - **weeks**: Minggu - **months**: Bulan - **years**: Tahun |
| advanceBookTimeFormat | String | Jam khusus. |
| reservationCloseDetail | Object | Butiran penutupan tempahan. |
| taskStartTime | Long | Masa mula penutupan tempahan. Cap masa dalam milisaat. |
| taskEndTime | Long | Masa tamat penutupan tempahan. Cap masa dalam milisaat. Nilai kosong menunjukkan penutupan kekal. |
| closeReason | String | Sebab penutupan tempahan. |
| contactUnionId | String | unionId kenalan. |
| contactNick | String | Nama kenalan. |
| sendNotify | Boolean | Sama ada untuk menghantar notifikasi kepada pekerja yang telah menempah bilik mesyuarat. |
| approvalSwitch | Boolean | Sama ada suis kelulusan diaktifkan:   - **true**: Aktif - **false**: Tidak aktif |
| approvalType | Integer | Jenis kelulusan:   - **1**: Kelulusan standard - **2**: Kelulusan tersuai |
| roomDescription | String | Penerangan bilik mesyuarat. |
