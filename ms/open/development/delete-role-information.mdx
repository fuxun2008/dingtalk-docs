Panggil API ini untuk memadam peranan yang ditentukan mengikut role ID.

## Penerangan panggilan API

- Sebelum memanggil API ini, pastikan semua pekerja yang dikaitkan dengan peranan tersebut telah dikeluarkan daripada peranan itu.
- Peranan di bawah kumpulan peranan lalai tidak boleh dipadam.

## Permintaan

| **Maklumat asas** | |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/topapi/role/deleterole |
| Kaedah HTTP | POST |
| Jenis aplikasi disokong | appType-Internal app |
| Kebenaran diperlukan | permission-qyapi_manage_addresslist-Contacts data management permission |

### Parameter query

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | 6ed1xxxx | Kelayakan aplikasi untuk memanggil API ini. Dapatkan melalui API untuk mendapatkan [access_token bagi aplikasi dalaman](/open/development/obtain-orgapp-token). |

### Isi permintaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| role_id | Number | Ya | 1581321999 | ID peranan yang hendak dipadam. Panggil API [Get role list](/open/development/obtains-a-list-of-enterprise-roles) untuk mendapatkannya.  Peranan dalam kumpulan "Default" tidak boleh diubah suai, termasuk: Owner, Manager, Super Admin, dan Sub Admin. |

### Contoh permintaan

```curl
curl -X POST "https://api.dingtalk.io/topapi/role/deleterole" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=f5326exxxxbe8d071' \
-d 'role_id=11'
```

Java

```text
DingTalkClient client = new DefaultDingTalkClient("https://api.dingtalk.io/topapi/role/deleterole");
OapiRoleDeleteroleRequest req = new OapiRoleDeleteroleRequest();
req.setRoleId(1581321999L);
OapiRoleDeleteroleResponse rsp = client.execute(req, access_token);
System.out.println(rsp.getBody());
```

Python

```python
import dingtalk.api

req=dingtalk.api.OapiRoleDeleteroleRequest("https://api.dingtalk.io/topapi/role/deleterole")

req.role_id=11
try:
  resp= req.getResponse(access_token)
  print(resp)
except Exception,e:
  print(e)
```

PHP

```php

date_default_timezone_set('Asia/Shanghai');

```

## Respons

### Isi respons

| Nama | Jenis | Contoh | Penerangan |
| --- | --- | --- | --- |
| errcode | Number | 0 | Kod pemulangan. |
| errmsg | String | ok | Penerangan kod pemulangan. |
| request_id | String | zw9fhpj3m32u | ID permintaan. |

### Contoh isi respons

```json
{
  "errcode":"0",
  "request_id":"zw9fhpj3m32u"
}
```

### Kod ralat

Jika ralat dikembalikan semasa memanggil API ini, rujuk dokumen [Kod ralat global](/open/development/server-api-error-codes-1) untuk mencari penyelesaian berdasarkan mesej ralat.

| Kod ralat (errcode) | Mesej ralat (errmsg) | Penyelesaian |
| --- | --- | --- |
| 33011 | Invalid role_id | Sahkan bahawa role_id adalah betul. |
| 23004 | Editing system tags is not allowed | Sahkan bahawa role_id sah. |
| 1002 | System busy | Cuba lagi kemudian. |
