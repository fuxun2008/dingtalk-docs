---
title: "Dapatkan butiran kumpulan kehadiran"
description: "Panggil API DingTalk ini untuk mendapatkan butiran kumpulan kehadiran melalui ID, termasuk nama, pemilik utama dan jenis kehadiran syif tetap, syif atau fleksibel."
---

Panggil API ini untuk mendapatkan butiran kumpulan kehadiran berdasarkan ID kumpulan kehadiran, seperti nama kumpulan kehadiran, pemilik utama kumpulan kehadiran dan jenis kehadiran.

## Permintaan

| **Maklumat asas** | |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/topapi/attendance/group/query |
| Kaedah HTTP | POST |
| Jenis aplikasi yang disokong | appType-Aplikasi dalaman　appType-Aplikasi perusahaan pihak ketiga |
| Kebenaran yang diperlukan | permission-qyapi_attendance_group_read-Kebenaran pertanyaan kumpulan kehadiran |

### Parameter pertanyaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | bE74xxxx | Kelayakan aplikasi yang digunakan untuk memanggil API ini.   - Bagi Aplikasi dalaman, panggil API [Dapatkan access_token Aplikasi dalaman](/ms/open/development/obtain-orgapp-token) untuk mendapatkannya. - Bagi Aplikasi perusahaan pihak ketiga, panggil API Dapatkan access_token Perusahaan Pihak Ketiga untuk mendapatkannya. |

### Isi permintaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| op_user_id | String | Ya | user123 | userId pengendali. |
| group_id | Number | Ya | 685935028 | ID kumpulan kehadiran. Panggil API [Dapatkan butiran kumpulan kehadiran secara pukal](/ms/open/development/batch-obtain-attendance-group-details) untuk mendapatkan nilai group_id.  **Nota**  Jika anda mempunyai pengecam kumpulan kehadiran lama (group_key), panggil API [Tukar groupKey kepada groupId](/ms/open/development/convert-groupkey-to-groupid) untuk menukar group_key kepada group_id. |

### Contoh permintaan

```curl
curl -X POST "https://api.dingtalk.io/topapi/attendance/group/query" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=65671xxxx92ddf0' \
-d 'group_id=23456' \
-d 'op_user_id=dd_dd'
```

Java

```java
DingTalkClient client = new DefaultDingTalkClient("https://api.dingtalk.io/topapi/attendance/group/query");
OapiAttendanceGroupQueryRequest req = new OapiAttendanceGroupQueryRequest();
req.setOpUserId("dd_dd");
req.setGroupId(23456L);
OapiAttendanceGroupQueryResponse rsp = client.execute(req, access_token);
System.out.println(rsp.getBody());
```

Python

```python
import dingtalk.api

req=dingtalk.api.OapiAttendanceGroupQueryRequest("https://api.dingtalk.io/topapi/attendance/group/query")

req.op_user_id="dd_dd"
req.group_id=23456
try:
  resp= req.getResponse(access_token)
  print(resp)
except Exception,e:
  print(e)
```

PHP

```php
include "TopSdk.php";
date_default_timezone_set('Asia/Shanghai');

$c = new DingTalkClient(DingTalkConstant::$CALL_TYPE_OAPI, DingTalkConstant::$METHOD_POST , DingTalkConstant::$FORMAT_JSON);
$req = new OapiAttendanceGroupQueryRequest;
$req->setOpUserId("dd_dd");
$req->setGroupId("23456");
$resp = $c->execute($req, $access_token, "https://api.dingtalk.io/topapi/attendance/group/query");
```

C#

```csharp
IDingTalkClient client = new DefaultDingTalkClient("https://api.dingtalk.io/topapi/attendance/group/query");
OapiAttendanceGroupQueryRequest req = new OapiAttendanceGroupQueryRequest();
req.OpUserId = "dd_dd";
req.GroupId = 23456L;
OapiAttendanceGroupQueryResponse rsp = client.Execute(req, access_token);
Console.WriteLine(rsp.Body);
```

## Respons

### Isi respons

| Nama | Jenis | Contoh | Penerangan |
| --- | --- | --- | --- |
| result | TopSimpleGroupVO |  | Hasil yang dikembalikan. |
| name | String | Kehadiran | Nama kumpulan kehadiran. |
| shift_ids | Number[] | [677995086] | ID syif. |
| id | Number | 685935028 | ID kumpulan kehadiran. |
| wifis | String[] | ["test-inc"] | Nama Wi-Fi. |
| address_list | String[] | ["Tanah Bencah Xixi"] | Alamat kehadiran. |
| work_day_list | Number[] | [0,1,2,3] | Hari bekerja. |
| member_count | Number | 39 | Bilangan pengguna. |
| type | String | TURN | Jenis kumpulan kehadiran.   - **FIXED:** Kumpulan kehadiran syif tetap - **TURN:** Kumpulan kehadiran berasaskan syif - **NONE:** Kumpulan kehadiran waktu kerja fleksibel |
| url | String | https://attend.dingtalk.io/xxxx | Pautan ubah hala. |
| manager_list | String | user456 | Pentadbir kumpulan kehadiran. |
| owner_user_id | String | user01 | userId pemilik utama kumpulan kehadiran. |
| success | Boolean | true | Menunjukkan sama ada permintaan berjaya.   - **true**: Berjaya - **false**: Gagal |
| errcode | Number | 0 | Kod pemulangan. |
| request_id | String | 72hycvnsyykp | ID permintaan. |
