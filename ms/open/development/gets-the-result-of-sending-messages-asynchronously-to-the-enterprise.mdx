Panggil API ini untuk menanyakan hasil penghantaran mesej Pemberitahuan Kerja.

## Penerangan panggilan API

API ini sesuai untuk senario di mana anda perlu mengesahkan sama ada mesej Pemberitahuan Kerja telah berjaya dihantar kepada pengguna tertentu. Contohnya, selepas jabatan HR sesebuah Organisasi menghantar pemberitahuan penting, anda mungkin perlu mengesahkan sama ada Pekerja telah menerimanya.

### Nota

- API ini hanya mengembalikan hasil penghantaran mesej Pemberitahuan Kerja yang dihantar dalam tempoh 24 jam yang lalu.
- API ini tidak menyokong senarai penerima yang melebihi 100 pengguna. Jika tidak, sistem akan mengembalikan **Call timeout**.

## Permintaan

| **Maklumat asas** | |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/topapi/message/corpconversation/getsendresult |
| Kaedah HTTP | POST |
| Jenis aplikasi yang disokong | appType-Aplikasi dalaman appType-Aplikasi perusahaan pihak ketiga |
| Kebenaran yang diperlukan | permission-qyapi_base-Kebenaran asas diperlukan untuk memanggil API perusahaan |

### Parameter pertanyaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | bE74xxxx | Kelayakan aplikasi untuk memanggil API ini.   - Bagi Aplikasi dalaman, dapatkan melalui API untuk mendapatkan [access_token bagi Aplikasi dalaman](/ms/open/development/obtain-orgapp-token). - Bagi Aplikasi perusahaan pihak ketiga, dapatkan melalui API untuk mendapatkan access_token bagi perusahaan pihak ketiga. |

### Isi permintaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| agent_id | Number | Ya | 836390886 | Agent ID bagi Aplikasi mikro yang digunakan untuk menghantar mesej.   - Bagi Aplikasi dalaman, lihat pada halaman butiran aplikasi di [bahagian belakang pembangun](https://open-dev.dingtalk.io/#/appMgr/inner/h5/836390886/1). image - Bagi Aplikasi perusahaan pihak ketiga, dapatkan dengan memanggil API untuk mendapatkan maklumat kebenaran perusahaan. |
| task_id | Number | Ya | 256271667526 | ID Tugas yang dikembalikan oleh DingTalk semasa mesej dihantar. Panggil API [Hantar Pemberitahuan Kerja](/ms/open/development/asynchronous-sending-of-enterprise-session-messages) untuk mendapatkan nilai task_id.  **Nota**  Hanya tugas yang dicipta dalam tempoh 24 jam yang lalu boleh ditanya. |

### Contoh permintaan

```curl
curl -X POST "https://api.dingtalk.io/topapi/message/corpconversation/getsendresult" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=cfe36xxxxd8dbce' \
-d 'agent_id=123' \
-d 'task_id=456'
```


## Respons

### Isi respons

| Nama | Jenis | Contoh | Penerangan |
| --- | --- | --- | --- |
| send_result | AsyncSendResult |  | Hasil yang dikembalikan. |
| invalid_user_id_list | String[] | ["manager4220",user123"] | ID pengguna yang tidak sah. |
| forbidden_user_id_list | String[] | ["manager4220",user123"] | ID pengguna yang sebenarnya tidak dihantar disebabkan oleh Had kadar akibat penghantaran mesej yang terlalu kerap atau berlebihan.  Penerima yang tidak terjejas oleh Had kadar masih berjaya dihantar.  Peraturan Had kadar termasuk:   - Menghantar kandungan yang sama kepada pengguna yang sama hanya dibenarkan sekali sehari. - Bagi Aplikasi yang sama menghantar mesej kepada pengguna yang sama:    - Bagi Aplikasi perusahaan pihak ketiga, had harian ialah 100 mesej setiap pengguna.   - Bagi Aplikasi dalaman, had harian ialah 500 mesej setiap pengguna. |
| failed_user_id_list | String[] | ["manager4220",user123"] | ID pengguna yang gagal menerima mesej. |
| read_user_id_list | String[] | ["manager4220",user123"] | ID pengguna yang telah dibaca mesej. |
| unread_user_id_list | String[] | ["manager4220",user123"] | ID pengguna yang belum membaca mesej. |
| invalid_dept_id_list | Number[] | [1,2,3] | ID Jabatan yang tidak sah. |
| forbidden_list | SendForbiddenModel[] |  | Sebab khusus mengapa Push dilarang. |
| code | String | 143105 | Kod Had kadar.   - 143105 menunjukkan had harian mesej yang di-Push kepada seorang pengguna oleh Aplikasi dalaman telah melebihi had. - 143106 menunjukkan Aplikasi dalaman telah menghantar mesej pendua kepada seorang pengguna. |
| count | Number | 1 | Ambang Had kadar. |
| userid | String | user123 | ID pengguna bagi Pekerja yang terjejas oleh Had kadar. |
| errcode | Number | 0 | Kod pemulangan. |
| errmsg | String | ok | Penerangan kod pemulangan. |
| request_id | String | 6pcvwp6jcows | ID permintaan. |
