description: "Panggil API ini untuk mencipta atau mengemas kini tetapan penyembunyian kenalan melalui permintaan PUT, dengan menghantar medan seperti name, description, objectStaffIds, objectDeptIds, objectTagIds, dan excludeStaffIds."
---

Gunakan API ini untuk mencipta atau mengemas kini tetapan penyembunyian kenalan. Hantar medan perniagaan `name`, `description`, `objectStaffIds`, `objectDeptIds`, `objectTagIds`, dan `excludeStaffIds` melalui permintaan PUT.

## Penerangan panggilan API

Dalam OA Admin Console DingTalk, anda boleh menyembunyikan jabatan. API ini memperluaskan keupayaan penyembunyian melangkaui jabatan — **anda juga boleh menyembunyikan pekerja dan peranan**.

<Note>
Tetapan penyembunyian yang dikonfigurasi melalui API ini disimpan secara berasingan daripada yang dikonfigurasi dalam OA Admin Console. Kesan akhir ialah gabungan (OR) daripada kedua-duanya. Sebagai contoh, jika jabatan yang sama disembunyikan sama ada melalui API ini atau melalui OA Admin Console, jabatan tersebut akan disembunyikan.
</Note>

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/v1.0/contact/contactHideSettings |

| Kebenaran yang diperlukan | permission-Contact.Visibility.ReadWrite-Kebenaran untuk menguruskan julat keterlihatan data kenalan |
