title: "Get details of a single event"
description: "Call this API to query the details of a single event by event ID."

Panggil API ini untuk mendapatkan butiran acara tunggal berdasarkan ID acara.

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/calendar/users/{userId}/calendars/{calendarId}/events/{eventId}` |
| Kaedah HTTP | GET |
| Jenis aplikasi yang disokong | appType-Aplikasi dalaman　appType-Aplikasi perusahaan pihak ketiga　appType-Aplikasi peribadi pihak ketiga |
| Kebenaran yang diperlukan | permission-Calendar.Event.Read-Kebenaran baca untuk acara dalam aplikasi Kalendar |

### Header permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Perolehnya seperti berikut:   - Untuk aplikasi dalaman, panggil API [Mendapatkan access token aplikasi dalaman](/open/development/obtain-the-access-token-of-an-internal-app#). - Untuk aplikasi perusahaan pihak ketiga, panggil API [Mendapatkan access token perusahaan yang telah memberi kuasa kepada aplikasi pihak ketiga](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#). - Untuk aplikasi peribadi pihak ketiga, panggil API [Mendapatkan token pengguna](/open/development/obtain-user-token#). |

### Parameter laluan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| userId | String | Ya | unionId pengguna yang menjadi milik acara tersebut.   - Untuk aplikasi dalaman dan aplikasi perusahaan pihak ketiga, panggil API [Query butiran pengguna](/open/development/query-user-details#) untuk mendapatkan nilai unionid. - Untuk aplikasi peribadi pihak ketiga, panggil API [Dapatkan profil pengguna daripada Kenalan](/open/development/dingtalk-retrieve-user-information#) untuk mendapatkan nilai unionId. |
| calendarId | String | Ya | ID kalendar yang menjadi milik acara tersebut. Tetapkan kepada `primary` untuk menunjukkan kalendar utama pengguna. |
| eventId | String | Ya | ID acara. Panggil API [Query senarai acara](/open/development/query-an-event-list#) untuk mendapatkan nilai id. |

### Parameter kueri

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| maxAttendees | Long | Tidak | Bilangan maksimum peserta. Lalai: 100. Maksimum: 500. |

### Kod ralat

Jika panggilan API mengembalikan ralat, cari penyelesaiannya dalam dokumen [Kod ralat global](/open/development/server-api-error-codes-1) berdasarkan mesej ralat tersebut.

| HttpCode | Kod ralat | Mesej ralat | Penerangan |
| --- | --- | --- | --- |
| 400 | invalidParameter | forwardErrorMessage | Parameter tidak sah |
| 404 | instanceNotExist | instance not exist | Instans acara berulang tidak wujud |
| 404 | itemNotFound | forwardErrorMessage | Acara yang ditentukan tidak dapat ditemui |
