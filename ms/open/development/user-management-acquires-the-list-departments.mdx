title: "Dapatkan senarai jabatan"
description: "Panggil API ini untuk mendapatkan maklumat asas subjabatan peringkat terdekat di bawah jabatan yang ditentukan; pengambilan rekursif semua peringkat subjabatan tidak disokong."
---

Panggil API ini untuk mendapatkan maklumat asas jabatan peringkat seterusnya. API ini hanya mengembalikan maklumat asas subjabatan peringkat terdekat bagi jabatan semasa. Ia tidak mengembalikan semua subjabatan merentasi setiap peringkat.

## Permintaan

| **Maklumat asas** | |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/topapi/v2/department/listsub |
| Kaedah HTTP | POST |
| Jenis aplikasi disokong | appType-Aplikasi dalamanappType-Aplikasi perusahaan pihak ketiga |
| Kebenaran | permission-qyapi_get_department_list-Kebenaran Baca untuk maklumat jabatan dalam Kenalan |

### Parameter pertanyaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | bE74xxxx | Kelayakan aplikasi yang digunakan untuk memanggil API ini.   - Bagi aplikasi dalaman, dapatkannya dengan memanggil API untuk mendapatkan [access_token aplikasi dalaman](/ms/open/development/obtain-orgapp-token). - Bagi aplikasi perusahaan pihak ketiga, dapatkannya dengan memanggil API untuk mendapatkan access_token perusahaan pihak ketiga. |

### Isi permintaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| dept_id | Number | Tidak | 1 | ID Jabatan induk. Panggil API [Dapatkan senarai jabatan](#) untuk mendapatkan nilai parameter dept_id. |
| language | String | Tidak | zh_CN | Bahasa Kenalan:   - **zh_CN** (Lalai): Bahasa Cina - **en_US**: Bahasa Inggeris |

### Contoh permintaan

```curl
curl -X POST "https://api.dingtalk.io/topapi/v2/department/listsub" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=6846xxxx0cc781' \
-d 'dept_id=100' \
-d 'language=zh_CN'
```

Java

```text
DingTalkClient client = new DefaultDingTalkClient("https://api.dingtalk.io/topapi/v2/department/listsub");
OapiV2DepartmentListsubRequest req = new OapiV2DepartmentListsubRequest();
req.setDeptId(1L);
req.setLanguage("zh_CN");
OapiV2DepartmentListsubResponse rsp = client.execute(req, access_token);
System.out.println(rsp.getBody());
```

## Respons

### Isi respons

| Nama | Jenis | Contoh | Penerangan |
| --- | --- | --- | --- |
| request_id | String | 5um7ykyaalsj | ID permintaan. |
| errcode | Number | 0 | Kod pemulangan. |
| errmsg | String | Invalid access_token | Mesej ralat yang dikembalikan apabila Panggilan gagal. |
| result | DeptBaseResponse[] |  | Senarai jabatan. |
| dept_id | Number | 100 | ID jabatan. |
| name | String | HR | Nama jabatan. |
| parent_id | Number | 50 | ID Jabatan induk. |
| create_dept_group | Boolean | true | Sama ada untuk mencipta sembang organisasi yang berkaitan dengan jabatan ini pada masa yang sama:   - **true**: Cipta - **false**: Jangan cipta |
| auto_add_user | Boolean | false | Selepas Sembang Jabatan dicipta, sama ada ahli baharu yang menyertai jabatan tersebut ditambah secara automatik ke dalam sembang:   - **true**: Ditambah secara automatik - **false**: Tidak ditambah |

### Kod ralat

Jika panggilan API mengembalikan ralat, cari penyelesaian dalam dokumen [Kod ralat global](/ms/open/development/server-api-error-codes-1) berdasarkan Mesej ralat.

| Kod ralat (errcode) | Mesej ralat (errmsg) | Penyelesaian |
| --- | --- | --- |
| 60003 | Department not found | Sahkan bahawa dept_id adalah betul. |
| 400002 | Invalid parameter | Sahkan bahawa parameter dimasukkan seperti yang dikehendaki. |
| -1 | System busy | Cuba Lagi kemudian. |
