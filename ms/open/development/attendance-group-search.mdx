Panggil API ini untuk mencari kumpulan kehadiran secara kabur (fuzzy search) mengikut nama dan mendapatkan ringkasan kumpulan kehadiran, termasuk nama dan ID kumpulan kehadiran.

## Permintaan

| **Maklumat asas** | |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/topapi/attendance/group/search |
| Kaedah HTTP | POST |
| Jenis aplikasi yang disokong | appType-Aplikasi dalaman appType-Aplikasi perusahaan pihak ketiga |
| Kebenaran yang diperlukan | permission-qyapi_attendance_group_read-Kebenaran membaca kumpulan kehadiran |

### Parameter pertanyaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | bE74xxxx | Kelayakan aplikasi yang digunakan untuk memanggil API ini.   - Aplikasi dalaman: Panggil API [Dapatkan access_token Aplikasi dalaman](/ms/open/development/obtain-orgapp-token) untuk mendapatkannya. - Aplikasi perusahaan pihak ketiga: Panggil API Dapatkan access_token Organisasi Pihak Ketiga untuk mendapatkannya. |

### Isi permintaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| op_user_id | String | Ya | manager123 | userId pengendali. |
| group_name | String | Ya | Kehadiran | Nama kumpulan kehadiran. |

### Contoh permintaan

```curl
curl -X POST "https://api.dingtalk.io/topapi/attendance/group/search" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=d7689axxxx70e7a' \
-d 'group_name=%Exxxx%BA%97' \
-d 'op_user_id=dd_dd'
```

Java

```text
DingTalkClient client = new DefaultDingTalkClient("https://api.dingtalk.io/topapi/attendance/group/search");
OapiAttendanceGroupSearchRequest req = new OapiAttendanceGroupSearchRequest();
req.setOpUserId("manager123");
req.setGroupName("Kehadiran");
OapiAttendanceGroupSearchResponse rsp = client.execute(req, access_token);
System.out.println(rsp.getBody());
```


## Respons

### Isi respons

| Nama | Jenis | Contoh | Penerangan |
| --- | --- | --- | --- |
| result | TopMinimalismGroupVO[] |  | Hasil pertanyaan. |
| name | String | Kehadiran | Nama kumpulan kehadiran. |
| id | Number | 685935028 | ID kumpulan kehadiran. |
| success | Boolean | true | Menunjukkan sama ada pertanyaan berjaya.   - **true**: Berjaya - **false**: Gagal |
| errcode | Number | 0 | Kod pemulangan. |
| request_id | String | 750mu3wy9fu | ID permintaan. |

### Contoh isi respons

```json
{
  "errcode": 0,
  "result": [
    {
      "id": 685935028,
      "name": "Kehadiran"
    }
  ],
  "success": true,
  "request_id": "750muu3wy9fu"
}
```

### Kod ralat

Jika panggilan API ini memulangkan ralat, cari penyelesaian berdasarkan mesej ralat dalam dokumen [Kod ralat global](/ms/open/development/server-api-error-codes-1).
