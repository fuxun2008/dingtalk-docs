description: "Panggil API DingTalk ini untuk mendapatkan senarai ID instans kelulusan secara berhalaman, ditapis mengikut kod aliran kerja, julat masa, pemohon dan status."
---

Panggil API ini untuk mendapatkan senarai ID instans kelulusan bagi jabatan berkaitan dalam skop kebenaran anda.

## Penerangan panggilan API

### Aliran panggilan API

1. Panggil API ini untuk mendapatkan ID instans kelulusan bagi sesuatu aliran kerja kelulusan.
2. Panggil API [Dapatkan butiran satu instans kelulusan](/ms/open/development/obtains-the-details-of-a-single-approval-instance-pop) untuk mendapatkan butiran setiap instans kelulusan.

### Nota penggunaan

- Jika anda hanya menghantar **startTime**, nilainya tidak boleh melebihi 120 hari sebelum masa semasa. Jika **endTime** tidak dihantar, nilai lalainya ialah masa semasa.
- Jika anda menghantar **startTime** dan **endTime**, julat masa tidak boleh melebihi 120 hari, dan **startTime** tidak boleh melebihi 365 hari sebelum masa semasa.
- Jumlah ID instans yang diperoleh secara berkelompok (melalui panggilan berulang) tidak boleh melebihi 10,000.

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/v1.0/workflow/processes/instanceIds/query |
| Kaedah HTTP | POST |
| Jenis Aplikasi yang disokong | appType-Aplikasi dalaman |
| Kebenaran yang diperlukan | permission-Workflow.Instance.Read-Kebenaran baca instans aliran kerja |

### Pengepala permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Dapatkannya dengan memanggil API [Dapatkan Access Token aplikasi dalaman](/ms/open/development/obtain-the-access-token-of-an-internal-app). |

### Isi permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| processCode | String | Ya | Kod unik aliran kerja kelulusan.   - Panggil API [Cipta atau kemas kini templat borang kelulusan](/ms/open/development/create-an-approval-form-template) untuk mendapatkan nilai `processCode`. - Rujuk [Glosari - processCode](/ms/open/development/workflow-overview). |
| startTime | Long | Ya | Masa mula instans kelulusan, dalam bentuk Unix timestamp (milisaat).    Contohnya, untuk mendapatkan borang kelulusan yang dihantar antara 10 Apr 2020 hingga 14 Apr 2020, hantar 1586448000000, iaitu cap masa bagi 10 Apr 2020 00:00:00. |
| endTime | Long | Tidak | Masa tamat instans kelulusan, dalam bentuk Unix timestamp (milisaat).    Contohnya, untuk mendapatkan borang kelulusan yang dihantar antara 10 Apr 2020 hingga 14 Apr 2020, hantar 1586879999000, iaitu cap masa bagi 14 Apr 2020 23:59:59. |
| nextToken | Long | Ya | Cursor penomboran halaman.   - Bagi panggilan pertama, hantar 0. - Bagi panggilan seterusnya, hantar nextToken yang dikembalikan oleh panggilan sebelumnya. |
| maxResults | Long | Ya | Parameter penomboran yang menetapkan saiz halaman. Nilai maksimum: 20. |
| userIds | Array of String | Tidak | Senarai ID pengguna pemohon. Panjang senarai maksimum: 10. Dapatkannya dengan memanggil API [Dapatkan senarai ID pengguna dalam jabatan](/ms/open/development/query-the-list-of-department-userids). |
| statuses | Array of String | Tidak | Status instans aliran kerja:   - **RUNNING**: Dalam kelulusan - **TERMINATED**: Ditarik balik - **COMPLETED**: Kelulusan selesai     Jika tidak dihantar, ID instans dalam semua status akan dikembalikan. |
