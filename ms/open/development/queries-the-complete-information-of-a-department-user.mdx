Panggil API ini untuk mendapatkan butiran pengguna dalam jabatan yang ditentukan.

## Penerangan panggilan API

- API ini hanya mengembalikan butiran pengguna dalam jabatan yang ditentukan. Pengguna dalam sub-jabatan tidak dikembalikan.
- API ini boleh mengembalikan butiran sama ada pengguna akaun biasa atau pengguna Akaun Syarikat dalam sesuatu jabatan. Oleh sebab penggunaan parameter berbeza dengan ketara antara kedua-dua senario, dokumentasi ini dibahagikan mengikut jenis akaun untuk kejelasan:

  - Untuk mendapatkan butiran pengguna akaun biasa dalam jabatan, rujuk dokumen ini.
  - Untuk mendapatkan butiran pengguna Akaun Syarikat dalam jabatan (biasanya pengguna DingTalk Perusahaan), lihat [Dapatkan butiran pengguna Akaun Syarikat dalam jabatan](/open/development/queries-account-details).

## Permintaan

| **Maklumat asas** | |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/topapi/v2/user/list |
| Kaedah HTTP | POST |
| Jenis aplikasi yang disokong | appType-Aplikasi dalaman, appType-Aplikasi perusahaan pihak ketiga |
| Kebenaran yang diperlukan | permission-qyapi_get_department_member-Kebenaran membaca ahli jabatan dalam Kenalan |

### Parameter pertanyaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | bE74xxxx | Kelayakan aplikasi yang digunakan untuk memanggil API ini.   - Untuk aplikasi dalaman, dapatkan melalui API untuk mendapatkan [access_token aplikasi dalaman](/open/development/obtain-orgapp-token). - Untuk aplikasi perusahaan pihak ketiga, dapatkan melalui API untuk mendapatkan access_token perusahaan pihak ketiga. |

### Isi permintaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| dept_id | Number | Ya | 10 | ID jabatan. Panggil [Dapatkan senarai jabatan](/open/development/user-management-acquires-the-list-departments) untuk mendapatkannya. Untuk jabatan root, tetapkan parameter ini kepada 1.  **Nota**  Hanya pengguna dalam jabatan semasa yang dikembalikan. Pengguna dalam sub-jabatan tidak disertakan. |
| cursor | Number | Ya | 0 | Cursor untuk pertanyaan bersegi. Tetapkan kepada 0 untuk panggilan pertama, kemudian gunakan nilai `next_cursor` yang dikembalikan oleh panggilan sebelumnya. |
| size | Number | Ya | 10 | Saiz halaman. |
| order_field | String | Tidak | modify_desc | Peraturan penyusunan untuk ahli jabatan. Jika tidak dinyatakan, lalai adalah penyusunan tersuai (`custom`):   - **entry_asc**: susun mengikut masa menyertai jabatan secara menaik. - **entry_desc**: susun mengikut masa menyertai jabatan secara menurun. - **modify_asc**: susun mengikut masa pengubahsuaian maklumat jabatan secara menaik. - **modify_desc**: susun mengikut masa pengubahsuaian maklumat jabatan secara menurun. - **custom**: susun mengikut susunan tersuai pengguna (atau mengikut pinyin jika tidak ditentukan). |
| contain_access_limit | Boolean | Tidak | false | Sama ada untuk mengembalikan pengguna dengan akses terhad:   - true: kembalikan. - false: jangan kembalikan. |
| language | String | Tidak | zh_CN | Bahasa untuk Kenalan:   - **zh_CN**: Bahasa Cina (lalai). - **en_US**: Bahasa Inggeris. |

### Contoh permintaan

```curl
curl -X POST "https://api.dingtalk.io/topapi/v2/user/list" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=834f6b00-25b8-4484-a89d-595d1f7fa0a7' \
-d 'contain_access_limit=false' \
-d 'cursor=0' \
-d 'dept_id=10' \
-d 'language=zh_CN' \
-d 'order_field=modify_desc' \
-d 'size=10'
```

Java

```text
DingTalkClient client = new DefaultDingTalkClient("https://api.dingtalk.io/topapi/v2/user/list");
OapiV2UserListRequest req = new OapiV2UserListRequest();
req.setDeptId(1L);
req.setCursor(0L);
req.setSize(10L);
req.setOrderField("modify_desc");
req.setContainAccessLimit(false);
req.setLanguage("zh_CN");
OapiV2UserListResponse rsp = client.execute(req, "");
System.out.println(rsp.getBody());
```

Python

```python

```


### Kod ralat

Jika ralat dikembalikan semasa anda memanggil API ini, cari penyelesaiannya dalam [Kod ralat global](/open/development/server-api-error-codes-1) berdasarkan mesej ralat.

| Kod ralat (errcode) | Mesej ralat (errmsg) | Penyelesaian |
| --- | --- | --- |
| 400002 | Invalid parameter | Semak sama ada parameter diisi mengikut keperluan. |
| 50004 | The department is out of the permission scope | Semak sama ada access_token mempunyai kebenaran operasi. |
| 40035 | Invalid parameter | Nilai dept_id, cursor, size, atau order_field tidak memenuhi keperluan. |
| 60019 | Failed to get users from the department | Semak sama ada parameter berkaitan diisi dengan betul. |
| -1 | System busy | Cuba Lagi kemudian. |
