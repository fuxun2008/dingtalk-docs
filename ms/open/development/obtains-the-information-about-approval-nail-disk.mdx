Panggil API ini untuk mendapatkan ID ruang Drive kelulusan dan memberi pengguna semasa kebenaran untuk memuat naik lampiran.

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/v1.0/workflow/processInstances/spaces/infos/query |
| Kaedah HTTP | POST |
| Jenis aplikasi yang disokong | appType-Aplikasi dalaman |
| Kebenaran yang diperlukan | permission-Workflow.Instance.Write-Kebenaran tulis Instans aliran kerja |

### Pengepala permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Dapatkannya dengan memanggil API [Dapatkan access token Aplikasi dalaman](/ms/open/development/obtain-the-access-token-of-an-internal-app). |

### Isi permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| userId | String | Ya | userId pengguna. |
| agentId | Long | Tidak | agentId aplikasi. Untuk butiran, rujuk penerangan Agent ID. |

### Contoh permintaan

HTTP

```http
POST /v1.0/workflow/processInstances/spaces/infos/query HTTP/1.1
Host:api.dingtalk.io
x-acs-dingtalk-access-token:6d1bxxxx
Content-Type:application/json

{
  "userId" : "user123",
  "agentId" : 8345000
}
```

## Respons

### Isi respons

| Nama | Jenis | Penerangan |
| --- | --- | --- |
| result | Object | Hasil yang dikembalikan. |
| spaceId | Long | ID ruang Drive. |
| success | Boolean | Menunjukkan sama ada panggilan API berjaya.   - **true**: Berjaya - **false**: Gagal |

### Contoh isi respons

```text
HTTP/1.1 200 OK
Content-Type:application/json

{
  "result" : {
    "spaceId" : 3996960664
  },
  "success" : true
}
```
