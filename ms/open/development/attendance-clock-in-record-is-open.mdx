Panggil API ini untuk mendapatkan butiran daftar masuk sebenar pekerja dalam organisasi anda.

## Penerangan panggilan API

- API ini tidak menyokong pertanyaan data yang melebihi 180 hari.
- Jika anda hanya memerlukan keputusan daftar masuk tanpa data terperinci, panggil API [Dapatkan keputusan daftar masuk](/ms/open/development/open-attendance-clock-in-data).
- Penyegerakan data kehadiran mungkin tertangguh. Jika terdapat data yang tiada, cuba lagi kemudian.
- **Jika pengguna mempunyai syif berjadual pada hari tertentu tetapi tidak membuat daftar masuk, API ini mengembalikan data kosong**.
- API ini mengembalikan semua butiran daftar masuk, termasuk data daftar masuk bagi senario yang memerlukan pengesahan kedua, seperti kelewatan. Rekod ini ialah daftar masuk yang tidak sah. Selepas mendapatkan data, tapis rekod ini mengikut senario perniagaan anda. Beri perhatian kepada parameter output `invalidRecordType`, `isLegal` dan `invalidRecordMsg`.

Contohnya, organisasi menjadualkan pekerja untuk membuat daftar masuk pada pukul 9:00 dan 18:00. Jika pekerja membuat daftar masuk beberapa kali dalam tempoh tersebut, API ini mengembalikan semua rekod daftar masuk.

Untuk melihat data daftar masuk mentah yang sama dalam konsol Kehadiran, pergi ke **Statistik Kehadiran** > **Pengurusan Laporan** > **Rekod Mentah**. Setiap rekod memaparkan lajur berikut: **Nama**, **Kumpulan kehadiran**, **Jabatan**, **Nombor pekerja**, **Jawatan**, **Tarikh kehadiran**, **Masa kehadiran** (masa syif berjadual), **Masa daftar masuk** dan **Keputusan daftar masuk**. Keputusan seperti *daftar masuk susulan diluluskan* menunjukkan bahawa rekod tersebut berasal daripada pembetulan yang diluluskan, bukan daftar masuk secara langsung.

## Permintaan

| **Maklumat asas** | |
| --- | --- |
| URL HTTP | https://oapi.dingtalk.io/attendance/listRecord |
| Kaedah HTTP | POST |
| Jenis aplikasi yang disokong | appType-Aplikasi dalaman　appType-Aplikasi perusahaan pihak ketiga |
| Kebenaran yang diperlukan | permission-qyapi_get_attendance_data-Kebenaran membaca data kehadiran |

### Parameter pertanyaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | bE74xxxx | Kelayakan aplikasi yang digunakan untuk memanggil API ini.   - Bagi aplikasi dalaman, panggil API [Dapatkan access_token aplikasi dalaman](/ms/open/development/obtain-orgapp-token) untuk mendapatkannya. - Bagi aplikasi perusahaan pihak ketiga, panggil API Dapatkan access_token aplikasi perusahaan pihak ketiga untuk mendapatkannya. |

### Isi permintaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| userIds | List | Ya | ["user456","user123"] | Senarai ID pekerja dalam organisasi anda. Maksimum: 50.  **Penting**  Pastikan nilai userId adalah betul. Jika tidak, API ini mengembalikan data kosong. |
| checkDateFrom | String | Ya | 2020-09-07 00:00:00 | Hari kerja permulaan untuk pertanyaan rekod daftar masuk kehadiran. Format: yyyy-MM-dd hh:mm:ss.  Contohnya, jika anda menghantar "2021-12-01 10:00:00", daftar masuk pekerja pada pukul 09:00 tidak dikembalikan.  **Penting**  Jarak antara parameter workDateFrom dan workDateTo  tidak boleh melebihi 7 hari (termasuk). |
| checkDateTo | String | Ya | 2020-09-08 00:00:00 | Hari kerja akhir untuk pertanyaan rekod daftar masuk kehadiran. Format: yyyy-MM-dd hh:mm:ss.  Contohnya, jika anda menghantar "2021-12-01 18:00:00", daftar masuk pekerja pada pukul 19:00 tidak dikembalikan.  **Penting**  Jarak antara parameter workDateFrom dan workDateTo  tidak boleh melebihi 7 hari (termasuk). |
| isI18n | Boolean | Tidak | true | Menentukan sama ada organisasi ialah organisasi luar negara:   - **true**: Digunakan pada platform luar negara - **false** (lalai): Digunakan pada platform China |

### Contoh permintaan

```curl
curl -X POST "https://oapi.dingtalk.io/attendance/listRecord" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=7258e1c9-af43-411c-b3f4-bcb069bfbb93' \
-d 'checkDateFrom=2018-01-01' \
-d 'checkDateTo=2018-01-01' \
-d 'isI18n=true' \
-d 'userIds=%221%22%2C%222%22'
```

Java

```java
DingTalkClient client = new DefaultDingTalkClient("https://oapi.dingtalk.io/attendance/listRecord");
OapiAttendanceListRecordRequest req = new OapiAttendanceListRecordRequest();
req.setUserIds(Arrays.asList("user123","user456"));
req.setCheckDateFrom("2020-11-07 08:00:00");
req.setCheckDateTo("2020-11-12 08:00:00");
req.setIsI18n(false);
OapiAttendanceListRecordResponse rsp = client.execute(req, access_token);
System.out.println(rsp.getBody());
```

Python

```python
import dingtalk.api

req=dingtalk.api.OapiAttendanceListRecordRequest("https://oapi.dingtalk.io/attendance/listRecord")

req.userIds="[\"1\",\"2\"]"

req.checkDateTo="2018-01-01"
req.isI18n=true

	resp= req.getResponse(access_token)
	print(resp)
except Exception,e:
	print(e)
```

