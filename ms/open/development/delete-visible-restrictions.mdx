Panggil API ini untuk memadam tetapan sekatan keterlihatan Kenalan mengikut ID-nya.

## Penerangan panggilan API

Selepas memanggil API [Tambah atau ubah suai tetapan sekatan keterlihatan Kenalan](/ms/open/development/add-or-modify-visibility-settings-for-address-book-restrictions#), anda boleh memanggil API ini untuk memadam tetapan sekatan keterlihatan Kenalan.

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/contact/restrictions/settings/{settingId}` |
| Kaedah HTTP | DELETE |
| Jenis aplikasi disokong | appType-Aplikasi dalaman |
| Kebenaran | permission-Contact.Visibility.ReadWrite-Kebenaran untuk mengurus skop keterlihatan data Kenalan |

### Pengepala permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Dapatkan melalui API [Dapatkan access token aplikasi dalaman](/ms/open/development/obtain-the-access-token-of-an-internal-app#). |

### Parameter laluan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| settingId | Long | Ya | ID peraturan sekatan. Dapatkan melalui API [Dapatkan senarai tetapan sekatan keterlihatan Kenalan](/ms/open/development/gets-a-list-of-address-book-limit-visibility-settings#). |

### Contoh permintaan

HTTP

```http
DELETE /v1.0/contact/restrictions/settings/1001 HTTP/1.1
Host:api.dingtalk.io
x-acs-dingtalk-access-token:token
Content-Type:application/json
```

### Contoh isi respons

  "result" : true
}
