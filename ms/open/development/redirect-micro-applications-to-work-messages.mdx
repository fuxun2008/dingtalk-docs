Dokumen ini menerangkan cara mengalihkan ke Aplikasi mikro DingTalk dengan mengklik Notifikasi Kerja yang telah dihantar.

## Prasyarat

Selesaikan prosedur [Cipta aplikasi](/ms/open/dingstart/create-application).

## Prosedur

1. Pilih aplikasi sasaran, pergi ke halaman butiran aplikasi, dan klik **Basic Information** > **Credentials and Basic Information**.
2. Dapatkan Client ID dan Client Secret aplikasi.
3. Aplikasi dalaman mempunyai Kebenaran API Notifikasi Kerja diaktifkan secara lalai. Anda tidak perlu menghantar permohonan secara manual.
4. Dapatkan kredensial akses untuk memperoleh access_token bagi aplikasi dalaman tersebut. Apabila anda memanggil API, identiti pemanggil disahkan menggunakan access token.
5. Panggil API [Hantar Notifikasi Kerja](/ms/open/development/asynchronous-sending-of-enterprise-session-messages) untuk menghantar Notifikasi Kerja kepada pengguna sasaran. Pengguna perlu mengklik mesej untuk mencetuskan pengalihan, jadi jenis mesej yang sesuai ialah mesej pautan, mesej OA, dan mesej Kad. Untuk butiran lanjut, lihat [Jenis notifikasi mesej](/ms/open/development/message-types-and-data-format).

## Alihkan ke aplikasi web (Aplikasi mikro H5) dengan mengklik Notifikasi Kerja

1. Panggil API [Hantar Notifikasi Kerja](/ms/open/development/asynchronous-sending-of-enterprise-session-messages). Pilih mesej pautan, mesej OA, atau mesej Kad sebagai format Notifikasi Kerja. Ketiga-tiga jenis mesej ini menyokong pengalihan.
2. Untuk cara membina pautan pengalihan, lihat [Penerangan pautan mesej](/ms/open/development/message-link-description). Contoh berikut menunjukkan cara membina pautan bagi setiap satu daripada tiga jenis mesej tersebut. Untuk format penghantaran mesej yang lengkap, lihat [Jenis notifikasi mesej](/ms/open/development/message-types-and-data-format).

   | **Parameter** | Penerangan |
   | --- | --- |
   | corpid | - Bagi aplikasi web (Aplikasi mikro H5) dalaman, parameter ini ialah nilai corpid bagi organisasi tempat aplikasi mikro semasa berada. - Bagi aplikasi web (Aplikasi mikro H5) Aplikasi perusahaan pihak ketiga, parameter ini ialah nilai corpid bagi organisasi yang telah memberi kebenaran kepada aplikasi semasa. |
   | container_type | Kaedah yang digunakan untuk membuka pautan (nilai tetap): - **work_platform**: Buka pautan dalam Workbench. |
   | app_id | - Bagi Aplikasi mikro H5 dalaman, tetapkan parameter ini kepada 0_agentId, iaitu gabungan digit 0, garis bawah, dan agentId. Untuk melihat agentId, lihat Agent ID. - Bagi Aplikasi mikro H5 Aplikasi perusahaan pihak ketiga, tetapkan parameter ini kepada nilai appId bagi aplikasi mikro pihak ketiga semasa. Untuk melihat appId, lihat App ID. |
   | redirect_type | Dalam senario ini, tetapkan kepada **jump** (nilai tetap). |
   | redirect_url | URL sasaran untuk dialihkan. Ia **mesti di-urlEncoded**. |

### Contoh

```text
dingtalk://dingtalkclient/action/openapp?corpid=corpidOfEnterprise&container_type=work_platform&app_id=appId&redirect_type=jump&redirect_url=redirectUrl
```

### Contoh membina pautan pengalihan untuk mesej pautan

```text
"messageUrl": "dingtalk://dingtalkclient/action/openapp?corpid=corpidOfEnterprise&container_type=work_platform&app_id=appId&redirect_type=jump&redirect_url=redirectUrl"
```

### Contoh membina pautan pengalihan untuk mesej OA

```text
"message_url": "dingtalk://dingtalkclient/action/openapp?corpid=corpidOfEnterprise&container_type=work_platform&app_id=appId&redirect_type=jump&redirect_url=redirectUrl"
```

### Contoh membina pautan pengalihan untuk mesej Kad

Mesej Kad menyokong gaya ActionCard pengalihan seluruh kad dan gaya ActionCard pengalihan butang berasingan:

- Gaya ActionCard pengalihan seluruh kad

  ```text
  "single_url": "dingtalk://dingtalkclient/action/openapp?corpid=corpidOfEnterprise&container_type=work_platform&app_id=appId&redirect_type=jump&redirect_url=redirectUrl"
  ```
- Gaya ActionCard pengalihan butang berasingan

  ```text
  "action_url": "dingtalk://dingtalkclient/action/openapp?corpid=corpidOfEnterprise&container_type=work_platform&app_id=appId&redirect_type=jump&redirect_url=redirectUrl"
  ```
