## Cipta dan Konfigurasikan Templat Mesej

1. Log masuk ke [Konsol Pembangun](https://open-dev.dingtalk.com/?version=5.86.5#/appMgr/provider/eapp/57406/2).
2. Klik **Pembangunan Aplikasi**, pilih **Aplikasi perusahaan pihak ketiga**, dan cipta mini program atau aplikasi mikro H5.
3. Pada halaman butiran aplikasi, klik **Tolak Mesej**. Dalam area pengurusan templat mesej, klik **Tambah**.
4. Pilih jenis templat dan klik **Cipta**.
5. Konfigurasikan templat mesej dan klik **Simpan**.

   **Penting**

   Jika parameter templat dikonfigurasikan dalam templat, ia akan dimuatkan secara automatik di bawah, dan anda kemudiannya boleh mengkonfigurasikan penerangan bagi setiap parameter dinamik.

   Sesetengah nilai dalam kandungan mesej berubah secara dinamik, seperti nombor pesanan, nombor telefon dan nama produk. Nilai ini tidak dapat ditentukan semasa anda menyediakan templat, jadi anda boleh menggunakan parameter templat untuk menggantikannya.
6. Klik **Uji**, kemudian klik **Hantar Mesej Ujian** untuk mengesahkan bahawa templat mesej dikonfigurasikan dengan betul.

## Konfigurasikan Templat Markdown

Templat Markdown menggunakan sintaks Markdown untuk mengkonfigurasikan dan menghantar mesej. Ia sesuai untuk mesej notifikasi tulen yang tidak memerlukan sebarang tindakan.

Dengan templat Markdown, anda boleh menyokong format paparan seperti teks, gambar dan pautan dengan mudah.

**Konfigurasi Templat Mesej Markdown**

| Konfigurasi | Menyokong Parameter Templat | Penerangan |
| --- | --- | --- |
| **Nama Templat** | Tidak | Menetapkan nama templat.  Namakannya berdasarkan kes penggunaan dan jenis templat, contohnya: Templat Notifikasi Tiket Baharu. |
| **Kes Penggunaan** | Tidak | Menerangkan kes penggunaan templat. |
| **Gambar** | Tidak | Gambar dalam mesej. Menyokong format pautan gambar atau media_id.  Item konfigurasi ini ditetapkan secara berasingan, dan setiap mesej hanya menyokong satu gambar. Gambar disemat di bahagian atas. |
| **Tajuk Mesej** | Tidak | Tajuk mesej dan kandungan yang dipaparkan pada skrin pertama sembang. |
| **Kandungan Mesej** | Ya | Kandungan mesej dalam format Markdown. Maksimum 1,000 aksara disyorkan. Untuk sintaks Markdown yang disokong, lihat jadual di bawah.  **Penting**     - Sintaks Markdown templat mesej tidak menyokong tajuk perenggan. Iaitu, format tajuk "# +teks tajuk" tidak disokong. Masukkan tajuk mesej secara berasingan dalam kotak input tajuk. Hanya tajuk peringkat pertama disokong. - Sintaks Markdown templat mesej tidak menyokong gambar. Iaitu, format "" tidak disokong. Masukkan gambar mesej secara berasingan dalam kotak input gambar. Setiap mesej hanya menyokong satu gambar. |

**Sintaks Markdown**:

```text
Petik
> Seseorang yang tidak berpegang pada apa-apa akan mudah terpedaya oleh apa sahaja.
 
Tebal dan Condong
**tebal**
*condong*
 
Pautan
[ini adalah pautan](http://name.com)
 
Senarai Berbulet
- item1
- item2
 
Senarai Bernombor
1. item1
2. item2

Pemisah Baris
 Pemisah baris yang ditunjukkan dalam kotak input adalah mencukupi. \n tidak disokong.
```

## Templat ActionCard

Templat ActionCard menghantar mesej jenis mesej ActionCard. Ia menyokong mesej yang menggabungkan kandungan mesej dengan titik tindakan, dan sesuai untuk senario di mana satu atau lebih titik tindakan dalam mesej diperlukan untuk pengendalian pantas.

Berdasarkan templat Markdown, templat ActionCard menyokong kedua-dua gaya pengalihan keseluruhan dan gaya pengalihan berasingan.

**Konfigurasi Templat ActionCard**

| Konfigurasi | Menyokong Parameter Templat | Penerangan |
| --- | --- | --- |
| **Nama Templat** | Tidak | Menetapkan nama templat.  Namakannya berdasarkan kes penggunaan dan jenis templat, contohnya: Templat Notifikasi Tiket Baharu. |
| **Kes Penggunaan** | Tidak | Menerangkan kes penggunaan templat. |
| **Gambar** | Tidak | Gambar dalam mesej. Menyokong format pautan gambar atau media_id. Item konfigurasi ini ditetapkan secara berasingan, dan setiap mesej hanya menyokong satu gambar. |
| **Tajuk Mesej** | Tidak | Tajuk mesej dan teks yang dipaparkan dalam senarai sembang dan notifikasi. Maksimum 64 aksara. |
| **Kandungan Mesej** | Ya | Kandungan mesej dalam format Markdown. Maksimum 1,000 aksara disyorkan. Untuk sintaks Markdown yang disokong, lihat jadual di bawah.  **Penting**     - Sintaks Markdown templat mesej tidak menyokong tajuk perenggan. Iaitu, format tajuk "# +teks tajuk" tidak disokong. Masukkan tajuk mesej secara berasingan dalam kotak input **Tajuk**. Hanya tajuk peringkat pertama disokong. - Sintaks Markdown templat mesej tidak menyokong gambar. Iaitu, format "" tidak disokong. Masukkan gambar mesej secara berasingan dalam kotak input **Gambar**. Setiap mesej hanya menyokong satu gambar. |
| **Titik Tindakan** | Ya | Mesej kad menyokong kedua-dua gaya ActionCard pengalihan keseluruhan dan gaya ActionCard pengalihan berasingan:   - Gaya ActionCard pengalihan keseluruhan menyokong satu tindakan klik. Memasukkan satu konfigurasi menghasilkan gaya pengalihan keseluruhan. - Gaya ActionCard pengalihan berasingan menyokong pelbagai tindakan klik. Memasukkan pelbagai konfigurasi menghasilkan gaya pengalihan berasingan. |
| **Pautan Titik Tindakan** | Ya | Alamat pautan yang dialihkan oleh mesej apabila diklik. Apabila mesej dihantar sebagai mini program, ia menyokong pautan pengalihan mini program. Maksimum 500 aksara. |
| **Tajuk Titik Tindakan** | Ya | Tajuk butang pengalihan. Maksimum 20 aksara. |

## Templat Borang

Templat Borang menghantar mesej berdasarkan jenis mesej OA. Ia sesuai untuk memaparkan mesej seperti pesanan, dan menyokong pengalihan untuk melihat butiran mesej.

**Konfigurasi Templat Mesej Borang**

| Konfigurasi | Menyokong Parameter Templat | Penerangan |
| --- | --- | --- |
| **Nama Templat** | Tidak | Menetapkan nama templat.  Namakannya berdasarkan kes penggunaan dan jenis templat, contohnya: Templat Notifikasi Tiket Baharu. |
| **Kes Penggunaan** | Tidak | Menerangkan kes penggunaan templat. |
| **Kandungan Pengepala Kotak Mesej** | Ya | Tajuk pengepala mesej. Maksimum 10 aksara.  Ia sah apabila dihantar ke sembang biasa. Apabila dihantar ke sembang organisasi, ia digantikan dengan nama aplikasi mikro. |
| **Warna Latar Belakang Pengepala Kotak Mesej** | Ya | Warna latar belakang pengepala mesej. Maksimum 8 aksara Inggeris, di mana 2 aksara pertama menunjukkan ketelusan dan 6 aksara terakhir menunjukkan nilai warna. Jangan tambah 0x.  Contoh: FFBBBBBB |
| **Tajuk Mesej** | Tidak | Tajuk kandungan mel. Maksimum 50 aksara disyorkan. |
| **Kandungan Mesej** | Ya | Kandungan bagi kandungan mel. Maksimum 3 baris dipaparkan. |
| **Gambar dalam Kandungan Mel** | Tidak | Gambar dalam mesej. Menyokong format pautan gambar atau media_id. Item konfigurasi ini ditetapkan secara berasingan, dan setiap mesej hanya menyokong satu gambar. |
| **Kandungan Borang** | Ya (tajuk dan nilai pembolehubah) | Borang bagi kandungan mel. Maksimum 6 item dipaparkan. Kotak input kiri dan kanan masing-masing mewakili kata kunci kandungan mel dan nilai sepadannya. |
| **Pautan Mudah Alih** | Ya | Alamat pautan yang dialihkan oleh mesej apabila diklik. Apabila mesej dihantar sebagai mini program, ia menyokong pautan pengalihan mini program. |
| **Pautan PC** | Ya | Alamat yang dialihkan oleh mesej apabila diklik pada PC. |

## Konfigurasikan Parameter Templat

Sesetengah nilai dalam kandungan mesej berubah secara dinamik, seperti nombor pesanan, nombor telefon dan nama produk. Nilai ini tidak dapat ditentukan semasa anda menyediakan templat, jadi anda boleh menggunakan parameter templat untuk menggantikannya.

Masukkan nilai sebenar untuk menggantikan parameter templat apabila anda menghantar Notifikasi Kerja. Parameter templat adalah pilihan dan boleh dikonfigurasikan berdasarkan keperluan anda.

**Format Parameter Templat**

Parameter templat menggunakan format `${parameter name}`. Parameter mesti mematuhi spesifikasi berikut.

- Mesti bermula dengan huruf atau garis bawah.
- Bahagian selebihnya boleh terdiri daripada huruf, garis bawah dan nombor.
- Jangan tetapkan terlalu banyak parameter dinamik untuk satu mesej. Tidak lebih daripada 5 disyorkan.

Sebagai contoh, kandungan mesej adalah seperti berikut:

```text
Produk ${product} yang anda ikuti kini tersedia. Dapatkan sekarang selagi masih ada stok!
```

Di sini, `${product}` ialah parameter templat dengan nama parameter `product`. Cukup masukkan nilai parameter ini semasa menghantar mesej. Sebagai contoh, masukkan `product` sebagai "Pelitup Muka Pakai Buang" semasa menghantar mesej. Kemudian "Pelitup Muka Pakai Buang" menggantikan parameter templat $&#123;product&#125;, dan kandungan mesej yang akhirnya diterima oleh pengguna adalah seperti berikut:

```text
Produk Pelitup Muka Pakai Buang yang anda ikuti kini tersedia. Dapatkan sekarang selagi masih ada stok!
```

Satu templat mesej boleh mempunyai beberapa parameter templat yang dikonfigurasikan, atau tiada langsung parameter templat. Tetapkannya berdasarkan keperluan sebenar anda.

**Terjemahan ID**

Apabila memasukkan parameter dinamik, terjemahan ID disokong. Pada masa ini, ia menyokong penukaran ID jabatan kepada nama jabatan dan penukaran userId kepada nama pengguna.

Sintaks terjemahan ID adalah seperti berikut:

```text
$departmentName=DEPARTMENT_ID$
$userName=USERID$
```

Di sini:

- DEPARTMENT_ID ialah ID jabatan berbentuk nombor.
- USERID ialah ID pengguna bagi pengguna tersebut.

Sebagai contoh:

- Ganti $departmentName=100$ dengan nama jabatan yang sepadan dengan ID jabatan "100", seperti "Platform Terbuka DingTalk".
- Ganti $userName=zhangsan01$ dengan nama pengguna yang sepadan dengan ID pengguna "zhangsan01", seperti "John".

## Hantar untuk Semakan

Selepas mencipta templat mesej, klik **Hantar** untuk menghantar templat tersebut untuk semakan.

## Aktifkan Templat

Selepas templat lulus semakan, ia akan diaktifkan secara automatik. Apabila templat mesej diaktifkan, anda boleh menghantar mesej templat dengan memanggil API. Untuk butiran lanjut, lihat [Gunakan Templat untuk Menghantar Mesej Notifikasi Kerja](/zh/open/development/work-notification-templating-send-notification-interface).

## Nyahaktifkan Templat

Apabila anda tidak lagi memerlukan templat, matikan togol pengaktifan untuk berhenti menggunakan templat tersebut.

## Padam Templat

Klik **Padam** untuk memadam templat.

## Klon Templat

Klik **Klon** untuk menyalin templat dengan konfigurasi yang sama.

## Uji Templat

Selepas mengklik **Edit**, anda akan memasuki antara muka penyuntingan templat. Klik butang **Uji** pada halaman penyuntingan templat untuk menjalankan ujian. Ujian ini menghantar Notifikasi Kerja kepada diri anda sendiri.
