---
title: "Kosongkan kriteria paparan penapis"
description: "Panggil API ini untuk mengosongkan kriteria penapis bagi lajur tertentu dalam paparan penapis yang ditetapkan, sesuai untuk senario yang perlu mengekalkan status penapis lajur lain dalam paparan penapis peribadi."
---

Panggil API ini untuk mengosongkan kriteria penapis bagi lajur tertentu dalam paparan penapis, supaya lajur tersebut tidak lagi terlibat dalam pengiraan penapis. Ini sesuai apabila anda ingin membuang peraturan penapis satu lajur dalam paparan penapis peribadi sambil mengekalkan status penapis lajur lain.

## Penerangan panggilan API

Operasi kosongkan hanya memberi kesan kepada paparan penapis semasa dan tidak memberi kesan kepada penapis global atau paparan penapis lain.

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/doc/workbooks/{workbookId}/sheets/{sheetId}/filterViews/{filterViewId}/clearColumnFilterCriteria` |
| Kaedah HTTP | POST |
| Jenis aplikasi disokong | appType-Aplikasi dalaman |
| Kebenaran diperlukan | permission-Document.Workbook.Write-Kebenaran tulis DingTalk Spreadsheet |

### Pengepala permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Dapatkan dengan memanggil API [Dapatkan access token aplikasi dalaman](/open/development/obtain-the-access-token-of-an-internal-app). |

### Parameter laluan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| workbookId | String | Ya | ID fail spreadsheet. `nodeId(dentryUuid)` yang dikembalikan oleh [API Knowledge Base](/open/development/knowledge-base-overview) ialah `workbookId` spreadsheet. Dapatkan dengan memanggil API [Dapatkan nod](https://open.dingtalk.com/document/orgapp/get-node) dan [Cipta dokumen Knowledge Base](/open/development/create-team-space-document). |
| sheetId | String | Ya | ID atau nama Helaian Kerja. Dapatkan nilai parameter id atau name dengan memanggil API [Dapatkan semua Helaian Kerja](/open/development/obtain-all-worksheets). |
| filterViewId | String | Ya | ID bagi paparan penapis. |

### Parameter pertanyaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| operatorId | String | Ya | unionId bagi operator.   - Dapatkan nilai parameter unionid dengan memanggil API [Dapatkan maklumat pengguna melalui kod log masuk senyap](/open/development/obtain-the-userid-of-a-user-by-using-the-log-free). - Dapatkan nilai parameter unionid dengan memanggil API [Tanya butiran pengguna](/open/development/query-user-details).       Jika operator tidak mempunyai kebenaran, API akan mengembalikan ralat `The operator has no permission`. |

### Isi permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| column | Long | Ya | Offset lajur berbanding lajur pertama dalam julat paparan penapis, bermula daripada 0. Contohnya, jika julat paparan penapis ialah `B1:E10`, maka `column=0` mewakili lajur B, dan `column=1` mewakili lajur C. |

### Contoh permintaan

HTTP

```http
POST /v1.0/doc/workbooks/e54Lq3xxx/sheets/Sheet1/filterViews/fv-xxxxx/clearColumnFilterCriteria?operatorId=ppgAxxx HTTP/1.1
Host:api.dingtalk.io
x-acs-dingtalk-access-token:f86e0bxxx
Content-Type:application/json

{
  "column" : 0
}
```
