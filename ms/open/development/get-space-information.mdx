Panggil API ini untuk mendapatkan maklumat ruang storan.

## Penerangan panggilan API

Panggil API ini untuk mendapatkan butiran ruang, termasuk nama ruang, kuota digunakan, jenis pemilik, dan lain-lain.

- Apabila jenis ruang storan adalah USER, semua pengguna yang mempunyai kebenaran ke atas ruang tersebut mempunyai kebenaran operasi. Pekerja lain perlu memanggil API [Tambah kebenaran](/ms/open/development/add-permissions-file) untuk diberikan kebenaran.
- Apabila jenis ruang storan adalah APP, sesiapa yang menjalankan operasi perlu memanggil API [Tambah kebenaran](/ms/open/development/add-permissions-file) untuk diberikan kebenaran.

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/storage/spaces/{spaceId}` |
| Kaedah HTTP | GET |
| Jenis aplikasi disokong | appType-Aplikasi dalaman　appType-Aplikasi perusahaan pihak ketiga |
| Keperluan kebenaran | permission-Storage.Space.Read-Kebenaran baca ke atas ruang storan organisasi |

### Header permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Dapatkan seperti berikut:   - Untuk aplikasi dalaman, panggil API [Dapatkan access token aplikasi dalaman](/ms/open/development/obtain-the-access-token-of-an-internal-app#). - Untuk aplikasi perusahaan pihak ketiga, panggil API [Dapatkan access token organisasi yang diberi kuasa untuk aplikasi pihak ketiga](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#). |

### Parameter laluan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| spaceId | String | Ya | ID ruang. Panggil API [Tambah ruang](/ms/open/development/add-space#) untuk mendapatkan nilai parameter id. |

### Parameter pertanyaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| unionId | String | Ya | unionId operator. Panggil API [Pertanyaan butiran pengguna](/ms/open/development/query-user-details#) untuk mendapatkannya. |

| quota | Object | Maklumat kuota. |
| used | Long | Kuota sebenar digunakan, dalam bait. Nilai minimum: 0.      Menunjukkan jumlah kuota yang digunakan oleh fail di bawah aplikasi tersebut. Memuat naik, menyalin, dan memadam fail akan mengemas kini nilai used secara automatik. |
| max | Long | Kuota maksimum, dalam bait.       - Apabila kuota aplikasi semasa ditetapkan kepada max, kuota aplikasi mempunyai had atas, dan nilai used tidak boleh melebihi nilai max. - Apabila kuota aplikasi semasa tidak ditetapkan kepada max, nilai ini kosong. | reserved | Long | Baki kuota pra-peruntukan, dalam bait.      Admin Console boleh memperuntukkan kuota terlebih dahulu kepada aplikasi atau ruang. | type | String | Jenis kuota.   - **SHARE**: Kuota dikongsi. Dalam mod ini, Quota.max kosong, menunjukkan kuota organisasi dikongsi. - **PRIVATE**: Kuota pra-peruntukan (kuota khusus). Dalam mod ini, selepas Quota.max ditetapkan, kuota tersebut adalah eksklusif.       Gunakan kuota pra-peruntukan (kuota khusus) apabila anda perlu memastikan kuota tersedia bagi sesebuah aplikasi tidak terjejas oleh aplikasi lain. |
