Panggil API ini untuk menambah Akaun Syarikat daripada organisasi lain ke dalam Organisasi Anda.

## Penerangan panggilan API

Menambah Akaun Syarikat daripada organisasi lain ke dalam Organisasi Anda hanya tersedia untuk organisasi yang telah membeli dan mengaktifkan ciri ini.

Ambil perhatian perkara berikut apabila memanggil API ini untuk menambah Akaun Syarikat daripada organisasi lain ke dalam Organisasi Anda:

1. API ini tidak menyokong penambahan akaun bukan Akaun Syarikat daripada organisasi lain.
2. Organisasi lain tersebut mesti memanggil API [Beri kebenaran Akaun Syarikat untuk menyertai berbilang organisasi](/open/development/authorize-a-dedicated-account-to-join-multiple-organizations) untuk memberi kebenaran kepada Akaun Syarikat mereka menyertai Organisasi Anda. Setelah kebenaran selesai, organisasi lain tersebut telah membenarkan Organisasi Anda menambah Akaun Syarikat mereka ke dalam Organisasi Anda.
3. Selepas panggilan API ini berjaya, Akaun Syarikat daripada organisasi lain tersebut akan ditambah terus ke dalam Organisasi Anda. Tiada pengesahan tambahan daripada Akaun Syarikat diperlukan. (Setelah kebenaran dalam Langkah 2 selesai, organisasi lain tersebut dianggap telah menerima, dan tiada penerimaan peringkat akaun selanjutnya diperlukan.)

## Permintaan

| **Maklumat asas** | |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/topapi/v2/user/create |
| Kaedah HTTP | POST |
| Jenis aplikasi disokong | appType-Aplikasi dalaman |
| Kebenaran Wajib | permission-qyapi_manage_addresslist-Kebenaran pengurusan data Kenalan |

### Parameter pertanyaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| access_token | string | Ya | BE3xxxx | Kelayakan aplikasi yang digunakan untuk memanggil API ini. Dapatkan melalui API untuk mendapatkan access_token bagi Aplikasi dalaman. |

### Isi permintaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| userid | string | Tidak | zhangsan | Pengecam unik Pekerja (tidak boleh diubah). Panjang: 1–64 aksara.  **Nota**   - Mesti unik dalam Organisasi Anda. - Jika tidak diberikan, ID pengguna akan dijana secara automatik. |
| outer_exclusive_corpid | string | Ya | ding12345 | ID organisasi Milik Akaun Syarikat yang akan ditambah. |
| outer_exclusive_userid | string | Ya | user01 | ID pengguna Milik Akaun Syarikat yang akan ditambah. |
| name | string | Ya | Zhang San | Nama Pekerja. Panjang maksimum: 80 aksara. |
| dept_id_list | string | Ya | "2,3,4" | Senarai ID Jabatan Milik Pekerja tersebut. Pisahkan berbilang ID Jabatan dengan tanda koma Inggeris `,`. Maksimum 100 ID Jabatan boleh dihantar bagi setiap panggilan. |
| telephone | string | Tidak | 010-86123456-2345 | Nombor sambungan. Panjang maksimum: 50 aksara.  **Nota**  Nombor sambungan adalah Unik dan tidak boleh berulang dalam Organisasi Anda. |
| job_number | string | Tidak | 4 | ID Pekerja. Panjang maksimum: 50 aksara. |
| title | string | Tidak | Technical Director | Jawatan. Panjang maksimum: 200 aksara. |
| email | string | Tidak | test@xxx.com | E-mel peribadi Pekerja. Panjang maksimum: 50 aksara.  **Nota**  E-mel Pekerja adalah Unik dan tidak boleh berulang dalam Organisasi Anda. |
| org_email | string | Tidak | test@xxx.com | E-mel Syarikat Pekerja. Panjang maksimum: 100 aksara.  **Nota**  Medan ini hanya berkuat kuasa apabila Pekerja telah mengaktifkan E-mel Syarikat. |
| org_email_type | string | Tidak | profession | Jenis E-mel Syarikat Pekerja:   - **profession:** Edisi Standard. - **base:** Edisi Basic. |
| work_place | string | Tidak | Future Park | Lokasi Kerja. Panjang maksimum: 100 aksara. |
| remark | string | Tidak | Alias information | Alias. Panjang maksimum: 2000 aksara. |
| dept_order_list | object[] | Tidak |  | Susunan Pekerja dalam setiap Jabatan. |
| dept_id | Nombor | Tidak | 2 | ID Jabatan. |
| order | Nombor | Tidak | 1 | Susunan Pekerja dalam Jabatan tersebut. Nilai yang lebih besar menunjukkan kedudukan yang lebih tinggi dalam Susunan. |
| dept_title_list | object[] | Tidak |  | Jawatan Pekerja dalam setiap Jabatan. |
| dept_id | Nombor | Tidak | 2 | ID Jabatan. |
| title | string | Tidak | Senior Product Manager | Jawatan Pekerja dalam Jabatan tersebut. |
| extension | string | Tidak | `{"hobby":"travel","age":"24"}` | Atribut Tambahan. Berbilang Atribut boleh ditetapkan. Panjang maksimum: 2000 aksara. **Nota**   - Maksimum 10 Atribut Tambahan boleh dipaparkan pada peranti mudah alih. - Sebelum menggunakan parameter ini, tambah Atribut tersebut dalam [DingTalk Admin Console](https://oa.dingtalk.io/index_new.htm#/setting/contactInfo), kemudian panggil API untuk menetapkan nilai. - Medan ini menyokong nilai jenis Pautan. Pautan juga menyokong kad bebas pemboleh ubah untuk penggantian automatik. Kad bebas yang disokong pada masa ini ialah userid dan corpid. Contohnya: `{"hobby":"[hobby](http://www.dingtalk.io?userid=#userid#&corpid=#corpid#)"}`. |
| senior_mode | boolean | Tidak | false | Sama ada hendak mengaktifkan mod eksekutif. Lalai: false.   - **true**: Aktifkan.  **Nota**    - Setelah diaktifkan, nombor telefon disembunyikan daripada semua Pekerja.   - Pekerja biasa tidak boleh menghantar DING kepada atau memulakan panggilan perniagaan DingTalk dengan pengguna ini.   - Eksekutif boleh saling menghantar DING dan memulakan panggilan perniagaan DingTalk antara satu sama lain. - **false**: Nyahaktifkan. |
| hired_date | Nombor | Tidak | 1597573616828 | Tarikh diambil bekerja. Unix timestamp, dalam milisaat. |
| manager_userid | string | Tidak | 001 | ID pengguna Penyelia terus. |

### Contoh permintaan

```curl
curl -X POST "https://api.dingtalk.io/topapi/v2/user/create" \
  -H 'Content-Type: application/x-www-form-urlencoded;charset=utf-8' \
  -d 'access_token=YOUR_ACCESS_TOKEN' \
  -d 'outer_exclusive_corpid=ding12345' \
  -d 'outer_exclusive_userid=user01' \
  -d 'name=Zhang San' \
  -d 'dept_id_list=2,3,4' \
  -d 'userid=zhangsan' \
  -d 'telephone=010-86123456-2345' \
  -d 'job_number=4' \
  -d 'title=Technical Director' \
  -d 'email=test@xxx.com' \
  -d 'work_place=Future Park' \
  -d 'remark=Alias information'
```

## Respons

### Isi respons

| Nama | Jenis | Contoh | Penerangan |
| --- | --- | --- | --- |
| errcode | Nombor | 0 | Kod ralat. 0 menunjukkan Berjaya. |
| errmsg | string | ok | Mesej ralat. |
| result | object |  | Hasil yang dikembalikan. |
| userid | string | zhangsan | ID pengguna Pekerja. |
| unionId | string | xxxx | unionId Pekerja. |

### Contoh isi respons

```json
{
  "errcode":"0",
  "result":{
    "unionId":"xxxx",
    "userid":"zhangsan"
  },
  "errmsg":"ok"
}
```

### Kod ralat

Jika ralat berlaku semasa memanggil API ini, rujuk dokumen [Kod ralat global](/open/development/server-api-error-codes-1) untuk mencari penyelesaian berdasarkan Mesej ralat.
