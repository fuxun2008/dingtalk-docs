---

Panggil API ini untuk mengemas kini tetapan masa daftar masuk bagi syif kehadiran. Pada masa ini, API ini hanya menyokong penetapan sama ada daftar masuk diwajibkan pada titik semakan.

## Permintaan

| **Maklumat asas** | |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/topapi/attendance/shift/updatepunches |
| Kaedah HTTP | POST |
| Jenis aplikasi yang disokong | appType-Aplikasi dalaman |
| Kebenaran yang diperlukan | permission-qyapi_attendance_group_manage-Kebenaran pengurusan kumpulan kehadiran |

### Parameter query

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | af21axxx | Kelayakan aplikasi yang digunakan untuk memanggil API ini. Dapatkannya dengan memanggil API [Dapatkan access_token Aplikasi dalaman](/ms/open/development/obtain-orgapp-token). |

### Isi permintaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| op_user_id | String | Ya | user456 | userId pengendali. |
| punches | TopPunchVO[] | Tidak |  | Maklumat titik semakan. |
| id | Number | Ya | 123 | ID titik semakan. Dapatkan nilai id dengan memanggil API [Dapatkan butiran syif](/ms/open/development/shift-query). |
| free_check | Boolean | Ya | true | Menentukan sama ada daftar masuk tidak diwajibkan.   - **true**: Pengecualian daftar masuk diaktifkan. - **false**: Pengecualian daftar masuk dinyahaktifkan. |
| shift_id | Number | Ya | 456 | ID syif. Dapatkan nilai id dengan memanggil API [Dapatkan ringkasan syif](/ms/open/development/enterprise-shift-query-in-batches). |

### Contoh permintaan

```curl
curl -X POST "https://api.dingtalk.io/topapi/attendance/shift/updatepunches" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=16869xxx0e890' \
-d 'op_user_id=dd' \
-d 'punches=null' \
-d 'shift_id=456'
```

```java
punchVO.setId(373271823L);
```


## Respons

### Isi respons

| Nama | Jenis | Contoh | Penerangan |
| --- | --- | --- | --- |
| success | Boolean | true | Menunjukkan sama ada panggilan berjaya.   - **true**: Berjaya - **false**: Gagal |
| errcode | Number | 0 | Kod pemulangan. |
| errmsg | String | Ralat sistem | Mesej ralat yang dikembalikan apabila panggilan gagal. |
| request_id | String | 5moh5icna65x | ID permintaan. |

### Contoh isi respons

```json
{
  "errcode": 0,
  "success": true,
  "request_id": "ed67bcymo0bw"
}
```

### Kod ralat

Jika ralat berlaku semasa memanggil API ini, cari penyelesaiannya dalam dokumen [Kod ralat global](/ms/open/development/server-api-error-codes-1) berdasarkan mesej ralat.
