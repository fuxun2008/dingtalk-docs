Panggil API ini untuk mendapatkan maklumat asas mengenai mesyuarat, termasuk nama mesyuarat, tempoh, masa mula, masa tamat, dan jumlah bilangan peserta.

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/conference/videoConferences/{conferenceId}` |
| Kaedah HTTP | GET |
| Jenis aplikasi disokong | appType-Aplikasi dalaman　appType-Aplikasi perusahaan pihak ketiga |
| Kebenaran diperlukan | permission-VideoConference.Conference.Read-Kebenaran baca untuk maklumat mesyuarat video |

### Pengepala permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Dapatkan seperti berikut:   - Untuk aplikasi dalaman, panggil API [Dapatkan access token aplikasi dalaman](/ms/open/development/obtain-the-access-token-of-an-internal-app#). - Untuk aplikasi perusahaan pihak ketiga, panggil API [Dapatkan access token organisasi yang memberi kuasa kepada aplikasi pihak ketiga](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#). |

### Parameter laluan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| conferenceId | String | Ya | conferenceId bagi mesyuarat. Panggil API [Cipta mesyuarat video](/ms/open/development/create-a-video-conference#) untuk mendapatkan conferenceId. |

| minutesOwnerUnionId | String | unionId pemilik Minit Mesyuarat.      Keupayaan Minit dalam mesyuarat telah dimigrasikan, dan medan ini tidak lagi dikembalikan. |
| extensionAppSettings | Array | Senarai maklumat tersuai untuk aplikasi lanjutan peringkat mesyuarat. |
| appId | String | Agent ID bagi aplikasi mikro yang menjadi milik cool app mesyuarat. |
| appCode | String | appCode bagi cool app tersebut. |
| autoOpenMode | Integer | Mod buka automatik:   - **0**: Jangan buka secara automatik - **1**: Buka secara automatik hanya untuk tuan rumah dan rakan tuan rumah - **2**: Buka secara automatik untuk semua peserta |
