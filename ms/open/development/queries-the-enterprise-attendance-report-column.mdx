title: "Dapatkan definisi lajur laporan kehadiran"
description: "Panggil API DingTalk ini untuk mendapatkan ID, jenis dan nama setiap lajur laporan kehadiran pintar, supaya organisasi boleh memilih lajur bagi pengiraan gaji."
---

Panggil API ini untuk menyemak statistik sesuatu lajur dalam laporan kehadiran pintar berdasarkan ID lajur. Organisasi boleh memilih nilai lajur yang hendak digunakan dalam pengiraan gaji.

## Penerangan panggilan API

- API ini tidak memulangkan ID bagi medan berkaitan cuti. Untuk mendapatkan data berkaitan cuti, panggil API [Dapatkan data cuti laporan](/ms/open/development/obtains-the-holiday-data-from-the-smart-attendance-report).
- Pastikan ciri statistik pintar telah diaktifkan.

## Permintaan

| **Maklumat asas** | |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/topapi/attendance/getattcolumns |
| Kaedah HTTP | POST |
| Jenis aplikasi yang disokong | appType-Aplikasi dalaman　appType-Aplikasi perusahaan pihak ketiga |
| Kebenaran yang diperlukan | permission-qyapi_base-Kebenaran asas yang diperlukan untuk memanggil API organisasi |

### Parameter query

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | bE74xxxx | Kelayakan aplikasi yang digunakan untuk memanggil API ini.   - Bagi Aplikasi dalaman, dapatkannya melalui API [Dapatkan access_token Aplikasi dalaman](/ms/open/development/obtain-orgapp-token). - Bagi Aplikasi perusahaan pihak ketiga, dapatkannya melalui API Dapatkan access_token organisasi pihak ketiga. |

### Contoh permintaan

```curl
curl -X POST "https://api.dingtalk.io/topapi/attendance/getattcolumns" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=1aae6dxxxx7bf36'
```

## Respons

### Isi respons

| Nama | Jenis | Contoh | Penerangan |
| --- | --- | --- | --- |
| request_id | String | emhw3318cdhv | ID permintaan. |
| errcode | Number | 0 | Kod pemulangan. |
| result | AttColumnsForTopVo |  | Hasil query. |
| columns | ColumnForTopVo[] |  | Maklumat lajur laporan. |
| id | Number | 123 | ID lajur laporan. |
| type | Number | 0 | Jenis lajur laporan. |
| name | String | Waktu kerja | Nama lajur laporan. |
| alias | String | 3_on_duty_user_check_result | Alias lajur laporan. |
| status | Number | 0 | Status lajur laporan. |
| sub_type | Number | 0 | Subjenis. |
| expression_id | Number | 129334038 | Medan yang tidak lagi digunakan. Jangan gunakan medan ini dalam logik perniagaan. |
