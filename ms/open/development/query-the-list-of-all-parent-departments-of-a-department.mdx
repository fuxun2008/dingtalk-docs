Panggil API ini untuk mendapatkan senarai ID bagi semua Jabatan induk bagi jabatan yang ditentukan. API ini tidak dihadkan oleh Skop kebenaran Kenalan.

## Permintaan

| **Maklumat asas** | |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/topapi/v2/department/listparentbydept |
| Kaedah HTTP | POST |
| Jenis aplikasi yang disokong | appType-Aplikasi dalaman, appType-Aplikasi perusahaan pihak ketiga |
| Kebenaran diperlukan | permission-qyapi_get_department_list-Kebenaran Telah dibaca untuk maklumat jabatan Kenalan |

### Parameter pertanyaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | bE74xxxx | Kelayakan aplikasi yang digunakan untuk memanggil API ini.   - Bagi Aplikasi dalaman, dapatkan melalui API untuk mendapatkan [access_token Aplikasi dalaman](/ms/open/development/obtain-orgapp-token). - Bagi Aplikasi perusahaan pihak ketiga, dapatkan melalui API untuk mendapatkan access_token perusahaan pihak ketiga. |

### Isi permintaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| dept_id | Number | Ya | 42xxxx36 | ID jabatan yang hendak disoal. Panggil API [Dapatkan senarai jabatan](/ms/open/development/user-management-acquires-the-list-departments) untuk mendapatkan nilai dept_id. |

### Contoh permintaan

```curl
curl -X POST "https://api.dingtalk.io/topapi/v2/department/listparentbydept" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=a456xxxx13da5' \
-d 'dept_id=100'
```

## Respons

### Isi respons

| Nama | Jenis | Contoh | Penerangan |
| --- | --- | --- | --- |
| request_id | String | 10u9dj0853fwe | ID permintaan. |
| errcode | Number | 0 | Kod pulangan. |
| errmsg | String | Invalid department ID | Mesej ralat yang dikembalikan apabila Panggilan gagal. |
| result | DeptListParentByDeptIdResponse |  | Senarai ID Jabatan induk. |
| parent_id_list | Number[] | [789, 456, 123, 1] | Senarai ID bagi semua Jabatan induk bagi jabatan tersebut.  **Nota**  Dalam senarai yang dikembalikan, elemen pertama ialah ID jabatan semasa, dan elemen terakhir ialah ID Jabatan induk peringkat teratas. Tahap jabatan meningkat dari kiri ke kanan. |

### Contoh isi respons

```json
{
  "errcode": 0,
  "errmsg": "ok",
  "result": {
    "parent_id_list": [
      42xxxx36,
      1
    ]
  },
  "request_id": "ov7bc964j9pe"
}
```

### Kod ralat

Jika Ralat dikembalikan apabila anda memanggil API ini, rujuk dokumen [Kod ralat global](/ms/open/development/server-api-error-codes-1) untuk mencari penyelesaian berdasarkan Mesej ralat.

| Kod ralat (errcode) | Mesej ralat (errmsg) | Penyelesaian |
| --- | --- | --- |
| 43007 | Kebenaran diperlukan | Pastikan access_token mempunyai Kebenaran yang diperlukan. |
| 60003 | Jabatan tidak ditemui | Pastikan dept_id adalah betul. |
| 400002 | Parameter tidak sah | Pastikan parameter dimasukkan seperti yang diperlukan. |
| -1 | Sistem Sibuk | Cuba Lagi kemudian. |
