Panggil API ini untuk menulis ganti keseluruhan kandungan dokumen dalam format Markdown.

## Kebenaran

Untuk memanggil API ini, salah satu kebenaran berikut diperlukan.

| Jenis aplikasi | Disokong | Kebenaran | Debug API Explorer |
| --- | --- | --- | --- |
| Aplikasi dalaman | Disokong | Kebenaran tulis untuk fail storan organisasi | [API Explorer](https://open-dev.dingtalk.io/apiExplorer#/?devType=org&api=doc_1.0%23DocUpdateContent) |
| Aplikasi perusahaan pihak ketiga | Tidak disokong | Tidak disokong | Tidak disokong |
| Aplikasi peribadi pihak ketiga | Tidak disokong | Tidak disokong | Tidak disokong |

## Kaedah HTTP

```http
POST /v1.0/doc/suites/documents/{docKey}/overwriteContent?operatorId=String HTTP/1.1
Host:api.dingtalk.io
x-acs-dingtalk-access-token:String
Content-Type:application/json

{
  "dataType" : "String",
  "content" : "String"
}
```

## Parameter header

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses yang digunakan untuk memanggil API ini. Dapatkan dengan memanggil API [Dapatkan access token aplikasi dalaman](/open/development/obtain-the-access-token-of-an-internal-app). |

## Parameter path

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| docKey | String | Ya | ID Dokumen (`docKey` atau `dentryUuid` bagi dokumen tersebut). Selepas mencipta dokumen dengan memanggil API [Cipta dokumen Knowledge Base](/open/development/create-team-space-document), dapatkan parameter `docKey` daripada respons.  **Nota**  Dapatkan `dentryUuid` daripada URL dokumen. Contohnya, dalam https://docs.dingtalk.io/i/nodes/Z9xxxxa-id, `dentryUuid` ialah `Z9xxxxa-id`. |

## Parameter query

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| operatorId | String | Ya | unionId pengguna. Dapatkan nilai parameter `unionid` dengan memanggil API [Tanya butiran pengguna](/open/development/query-user-details). |

## Parameter body

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| dataType | String | Tidak | Format data bagi kandungan yang akan ditulis ganti. Nilai sah:   - **markdown**: Kandungan yang akan ditulis ganti dalam format markdown. Ini ialah nilai lalai. |
| content | String | Ya | String kandungan yang hendak ditulis. Nota:   - Jika `dataType` ialah **markdown**, ini mestilah string berformat markdown. - Panjang maksimum ialah 50,000 aksara. |

## Parameter respons

| Nama | Jenis | Penerangan |
| --- | --- | --- |
| success | Boolean | Sama ada permintaan berjaya. |
| result | Object | Hasil permintaan. |
| data | `Map<String, Any>` | Hasil permintaan. |
|  | Any | Hasil permintaan. |
