---
title: "Tetapkan ketinggian pelbagai baris"
description: "Panggil API ini untuk menetapkan ketinggian baris berturut-turut bermula daripada baris tertentu dalam DingTalk Spreadsheet secara pukal, sesuai untuk penyeragaman jarak baris atau memuatkan teks pelbagai baris; nilai dibundarkan kepada integer positif."
---

Panggil API ini untuk menetapkan ketinggian (dalam piksel) bagi beberapa baris berturut-turut dalam DingTalk Spreadsheet, bermula daripada baris tertentu. API ini berguna untuk menyelaraskan ketinggian baris secara pukal bagi menyeragamkan jarak baris atau memuatkan paparan teks pelbagai baris. Nilai ketinggian dibundarkan secara automatik kepada integer positif, dan API ini mengembalikan maklumat helaian kerja selepas tindakan dilakukan.

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/doc/workbooks/{workbookId}/sheets/{sheetId}/setRowsHeight` |
| Kaedah HTTP | POST |
| Jenis aplikasi disokong | appType-Aplikasi dalaman |
| Kebenaran diperlukan | permission-Document.Workbook.Write-Kebenaran tulis DingTalk Spreadsheet |

### Header permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Panggil API [Dapatkan access token aplikasi dalaman](/ms/open/development/obtain-the-access-token-of-an-internal-app) untuk mendapatkannya. |

### Parameter laluan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| workbookId | String | Ya | ID fail hamparan. `nodeId(dentryUuid)` yang dikembalikan oleh [API Knowledge Base](/ms/open/development/knowledge-base-overview) ialah `workbookId` bagi hamparan tersebut. Panggil API [Dapatkan nod](https://open.dingtalk.com/document/development/get-node) atau [Cipta dokumen Knowledge Base](/ms/open/development/create-team-space-document) untuk mendapatkannya. |
| sheetId | String | Ya | ID atau tajuk helaian kerja. Panggil API [Dapatkan semua helaian kerja](/ms/open/development/obtain-all-worksheets) untuk mendapatkan ID dan tajuk helaian kerja. |

### Parameter pertanyaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| operatorId | String | Ya | unionId bagi pengendali. Panggil API [Query maklumat terperinci pengguna](/ms/open/development/query-user-details) untuk mendapatkannya. Jika pengendali tidak mempunyai kebenaran yang diperlukan, API mengembalikan ralat `The operator has no permission`. |

### Isi permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| row | Long | Ya | Cursor bagi baris pertama yang ketinggiannya hendak diubah. Bermula daripada 0. |
| rowCount | Long | Ya | Bilangan baris berturut-turut yang ketinggiannya hendak diubah. |
| height | Long | Ya | Ketinggian, dalam piksel. |
