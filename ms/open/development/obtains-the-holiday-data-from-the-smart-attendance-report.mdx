Panggil API ini untuk mendapatkan data cuti daripada laporan kehadiran pintar DingTalk berdasarkan nama cuti dan ID pengguna. Data yang dikembalikan merangkumi semua nilai dalam lajur cuti laporan bagi tempoh masa yang ditetapkan. Lajur cuti adalah dinamik, jadi anda mesti menetapkan nama cuti untuk mendapatkan data.

## Penerangan panggilan API

Untuk lebih banyak keupayaan akses dan penggunaan data, pergi ke Data Asset Platform. Data Asset Platform (dPaaS) ialah platform pengurusan data bersepadu untuk organisasi. Dibina di atas DingTalk, platform ini menyediakan perkhidmatan data yang selamat, boleh diskalakan dan mudah diselenggara bagi menyokong keputusan perniagaan.

## Permintaan

| **Maklumat asas** | |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/topapi/attendance/getleavetimebynames |
| Kaedah HTTP | POST |
| Jenis aplikasi yang disokong | Aplikasi dalaman, Aplikasi perusahaan pihak ketiga |
| Kebenaran yang diperlukan | permission-qyapi_base-Kebenaran asas yang diperlukan untuk memanggil API organisasi |

### Parameter query

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | 6d1bxxxx | Kelayakan aplikasi yang digunakan untuk memanggil API ini.   - Bagi Aplikasi dalaman, panggil API [Dapatkan access_token Aplikasi dalaman](/ms/open/development/obtain-orgapp-token) untuk mendapatkannya. - Bagi Aplikasi perusahaan pihak ketiga, panggil API untuk mendapatkan access_token organisasi pihak ketiga. |

### Isi permintaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| userid | String | Ya | manager123 | ID pengguna bagi pengguna tersebut. |
| leave_names | String | Ya | Cuti tahunan | Nama cuti. Pisahkan berbilang nama dengan koma. Panjang maksimum: 20. |
| from_date | Date | Ya | 2020-09-09 12:12:12 | Masa mula. Data yang lebih lama daripada 225 hari tidak disokong. |
| to_date | Date | Ya | 2020-09-11 12:12:12 | Masa tamat. Selang antara masa mula dan masa tamat mestilah dalam lingkungan 31 hari. |

### Contoh permintaan

```curl
curl -X POST "https://api.dingtalk.io/topapi/attendance/getleavetimebynames" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=1b8b85xxxxx3ccfdd' \
-d 'from_date=2018-07-11+12%3A12%3A12' \
-d 'leave_names=Cuti+tahunan' \
-d 'to_date=2018-07-11+12%3A12%3A12' \
-d 'userid=zhangsan'
```

Java

```text
DingTalkClient client = new DefaultDingTalkClient("https://api.dingtalk.io/topapi/attendance/getleavetimebynames");

req.setUserid("zhangsan");
req.setLeaveNames("Cuti tahunan");
req.setFromDate(StringUtils.parseDateTime("2020-09-01 00:00:00"));
req.setToDate(StringUtils.parseDateTime("2020-09-30 00:00:00"));
OapiAttendanceGetleavetimebynamesResponse rsp = client.execute(req, access_token);
System.out.println(rsp.getBody());
```

## Respons

### Isi respons

| Nama | Jenis | Contoh | Penerangan |
| --- | --- | --- | --- |
| result | ColumnValListForTopVo |  | Hasil yang dikembalikan. |
| columns | ColumnValForTopVo[] |  | Maklumat lajur dan data nilai lajur. |
| columnvo | ColumnForTopVo |  | Maklumat lajur. |
| name | String | Cuti peribadi | Nama cuti. |
| sub_type | Number | 0 | Subjenis. |
| status | Number | 0 | Status lajur. |
| alias | String | leave_ | Alias. |
| type | Number | 0 | Jenis lajur. |
| columnvals | ColumnDayAndVal[] |  | Data nilai lajur. |
| value | String | 1.0 | Nilai harian. |
| date | Date | 2020-09-09 12:12:12 | Masa mula. |
| errcode | Number | 0 | Kod pemulangan. |
| request_id | String | whv0fhtk8cnc | ID permintaan. |
