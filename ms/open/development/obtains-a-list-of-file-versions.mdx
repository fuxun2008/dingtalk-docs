Panggil API ini untuk mendapatkan senarai versi fail.

## Penerangan panggilan API

Apabila anda memanggil API [Hantar fail](/ms/open/development/submittal-file) dalam ruang storan, jika polisi nama fail ditetapkan kepada `OVERWRITE`, memuat naik fail dengan nama yang sama akan menjana versi sejarah bagi fail tersebut.

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| HTTP URL | `https://api.dingtalk.io/v1.0/storage/spaces/{spaceId}/dentries/{dentryId}/versions` |
| Kaedah HTTP | GET |
| Jenis aplikasi yang disokong | appType-Aplikasi dalaman　appType-Aplikasi perusahaan pihak ketiga |
| Keperluan kebenaran | permission-Storage.File.Read-Kebenaran baca fail storan organisasi |

### Header permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Dapatkan seperti berikut:   - Untuk aplikasi dalaman, panggil API [Dapatkan access token aplikasi dalaman](/ms/open/development/obtain-the-access-token-of-an-internal-app). - Untuk aplikasi perusahaan pihak ketiga, panggil API [Dapatkan access token perusahaan yang diberi kuasa bagi aplikasi pihak ketiga](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1). |

### Parameter laluan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| spaceId | String | Ya | ID ruang. Panggil API [Tambah ruang](/ms/open/development/add-space) untuk mendapatkan nilai parameter id. |
| dentryId | String | Ya | ID fail. Panggil API [Dapatkan senarai fail atau folder](/ms/open/development/get-a-list-of-files-or-folders) atau [Dapatkan spaceId dan dentryId melalui dentryUuid](/ms/open/development/api-getdentryidbyuuid) untuk mendapatkan nilai parameter id. |

### Parameter pertanyaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| nextToken | String | Tidak | Cursor penomboran halaman.   - Untuk pertanyaan pertama, biarkan parameter ini kosong. - Untuk pertanyaan seterusnya, hantar nextToken yang dikembalikan oleh panggilan sebelumnya. |
| maxResults | Integer | Tidak | Bilangan entri setiap halaman. Lalai: 100. Maksimum: 100. |
| unionId | String | Ya | unionId pengendali. Panggil API [Pertanyaan butiran pengguna](/ms/open/development/query-user-details) untuk mendapatkan nilai parameter unionid. |

| nextToken | String | Cursor penomboran halaman.      Jika medan ini tidak kosong, terdapat lebih banyak data yang tersedia. |
