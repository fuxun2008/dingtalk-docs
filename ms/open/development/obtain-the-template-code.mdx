Panggil API ini untuk mendapatkan processCode templat kelulusan berdasarkan namanya.

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/v1.0/workflow/processCentres/schemaNames/processCodes |
| Kaedah HTTP | GET |
| Jenis aplikasi yang disokong | appType-Aplikasi dalaman　appType-Aplikasi perusahaan pihak ketiga |
| Kebenaran yang diperlukan | permission-Workflow.Form.Read-Kebenaran baca templat aliran kerja |

### Pengepala permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Dapatkan kredensial seperti berikut:   - Aplikasi dalaman: Panggil API [Dapatkan access token aplikasi dalaman](/ms/open/development/obtain-the-access-token-of-an-internal-app). - Aplikasi perusahaan pihak ketiga: Panggil API untuk mendapatkan access token Organisasi yang telah memberikan kebenaran kepada Aplikasi pihak ketiga. |

### Parameter pertanyaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| name | String | Ya | Nama templat. Panjang maksimum: 64 aksara. Dapatkan nilai ini daripada medan nama templat borang `name` dalam parameter permintaan API untuk mencipta atau mengemas kini templat kelulusan. |

### Contoh permintaan

HTTP

```http
GET /v1.0/workflow/processCentres/schemaNames/processCodes?name=Nama HTTP/1.1
Host:api.dingtalk.io
x-acs-dingtalk-access-token:6d1bxxxx
Content-Type:application/json
```

### Isi respons

| Nama | Jenis | Penerangan |
| --- | --- | --- |
| result | Object | Maklumat templat borang. |
| processCode | String | Kod templat borang. |
| gmtModified | String | Masa kemas kini. |

### Contoh isi respons

```text
HTTP/1.1 200 OK
Content-Type:application/json

  "result" : {
    "processCode" : "PROC-abcdef-example",
    "gmtModified" : "2024-03-22T11:50Z"
  }
}
```
