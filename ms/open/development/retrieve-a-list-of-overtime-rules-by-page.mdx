Panggil API ini untuk mendapatkan senarai peraturan kerja lebih masa yang dikonfigurasi dalam tetapan daftar masuk kehadiran mengikut halaman, termasuk nama dan ID setiap peraturan.

## Penerangan panggilan API

Sebagai contoh, katakan pengurusan peraturan kehadiran Organisasi Anda mengandungi tiga peraturan kerja lebih masa: **Kira kerja lebih masa berdasarkan masa daftar masuk selepas kelulusan**, **Kira kerja lebih masa berdasarkan masa kelulusan** dan **Kira kerja lebih masa berdasarkan masa daftar masuk**.

Panggil API ini untuk mendapatkan nama peraturan dan ID peraturan bagi ketiga-tiga peraturan kerja lebih masa tersebut.

Peraturan kerja lebih masa diurus di bawah **Pengurusan Peraturan Kehadiran** > **Peraturan Kerja Lebih Masa**. Di sini, anda boleh menambah peraturan melalui **Tambah Peraturan Kerja Lebih Masa**, serta **Edit** atau **Padam** peraturan sedia ada. Ketiga-tiga peraturan contoh berfungsi seperti berikut:

| Nama peraturan | Kandungan (hari bekerja / hari rehat / cuti umum) | Skop penggunaan |
| --- | --- | --- |
| Kira kerja lebih masa berdasarkan masa kelulusan | Kerja lebih masa memerlukan kelulusan; tempoh kerja lebih masa adalah berdasarkan borang kelulusan | Seluruh syarikat (kecuali mereka yang mempunyai peraturan kerja lebih masa lain) |
| Kira kerja lebih masa berdasarkan masa daftar masuk selepas kelulusan | Kerja lebih masa memerlukan kelulusan; berdasarkan daftar masuk, tetapi tidak boleh melebihi tempoh dalam borang kelulusan | Tidak digunakan |
| Kira kerja lebih masa berdasarkan masa daftar masuk | Kerja lebih masa tidak memerlukan kelulusan; tempoh kerja lebih masa dikira daripada masa daftar masuk | Tidak digunakan |

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/v1.0/attendance/overtimeSettings |
| Kaedah HTTP | GET |
| Jenis aplikasi yang disokong | appType-Aplikasi dalaman　appType-Aplikasi perusahaan pihak ketiga |
| Kebenaran yang diperlukan | permission-qyapi_attendance_group_read-Kebenaran baca kumpulan kehadiran |

### Pengepala permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Dapatkannya seperti berikut:   - Aplikasi dalaman: Panggil API [Dapatkan access token aplikasi dalaman](/ms/open/development/obtain-the-access-token-of-an-internal-app). - Aplikasi perusahaan pihak ketiga: Panggil API untuk mendapatkan access token organisasi yang telah memberikan kebenaran kepada Aplikasi pihak ketiga. |

### Parameter pertanyaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| pageNumber | Long | Ya | Nombor halaman permulaan.  Nilai bermula daripada 1. |
| pageSize | Long | Ya | Saiz halaman.  Nilai maksimum ialah 50. |

## Respons

### Isi respons

| Nama | Jenis | Penerangan |
| --- | --- | --- |
| result | Object | Hasil yang dikembalikan. |
| pageNumber | Long | Nombor halaman semasa. |
| totalPage | Long | Jumlah bilangan halaman. |
| items | Array | Senarai peraturan kerja lebih masa. |
| id | Long | ID peraturan kerja lebih masa. |
| name | String | Nama peraturan kerja lebih masa. |
| settingId | Long | settingId bagi peraturan kerja lebih masa. |

### Contoh isi respons

```text
HTTP/1.1 200 OK
Content-Type:application/json

{
  "result" : {
    "pageNumber" : 1,
    "totalPage" : 10,
    "items" : [ {
      "id" : 221375127,
      "name" : "Kira kerja lebih masa berdasarkan masa kelulusan",
      "settingId" : 221375127
    } ]
  }
}
```
