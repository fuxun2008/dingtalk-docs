---
title: "Tanya maklumat kumpulan kehadiran berdasarkan groupKey"
description: "Panggil API DingTalk ini dengan groupKey untuk mendapatkan julat daftar masuk, tetapan kehadiran luar pejabat dan keperluan kelulusan sesuatu kumpulan kehadiran."
---

API ini mendapatkan maklumat kumpulan kehadiran berdasarkan groupKey kumpulan kehadiran. Maklumat ini termasuk julat daftar masuk, sama ada kehadiran luar pejabat dibenarkan dan sama ada kehadiran luar pejabat memerlukan kelulusan.

## Permintaan

| **Maklumat asas** | |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/topapi/attendance/group/get |
| Kaedah HTTP | POST |
| Jenis aplikasi yang disokong | appType-Aplikasi dalaman |
| Kebenaran yang diperlukan | permission-qyapi_attendance_group_read-Kebenaran baca kumpulan kehadiran |

### Parameter pertanyaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | 4c9ebd2b1534xxxx | Kelayakan aplikasi untuk memanggil API ini. Dapatkannya dengan memanggil [Dapatkan access_token Aplikasi dalaman](/ms/open/development/obtain-orgapp-token). |

### Isi permintaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| op_userid | String | Tidak | user123 | ID pengguna bagi pengendali. |
| group_key | String | Ya | 02B1Exxxx | groupKey kumpulan kehadiran.  **Nota**  Jika pengecam kumpulan kehadiran anda ialah group_id, panggil [Tukar groupId kepada groupKey](/ms/open/development/groupid-to-groupkey) untuk menukar group_id kepada group_key. |

### Contoh permintaan

```curl
curl -X POST "https://api.dingtalk.io/topapi/attendance/group/get" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=9d319xxxx6e5f0' \
-d 'group_key=0151E0xxxx2A1A917' \
-d 'op_userid=123456'
```

Java

```text
DingTalkClient client = new DefaultDingTalkClient("https://api.dingtalk.io/topapi/attendance/group/get");
OapiAttendanceGroupGetRequest req = new OapiAttendanceGroupGetRequest();
req.setOpUserid("123456");
req.setGroupKey("0151E022xxxxx1A917");
OapiAttendanceGroupGetResponse rsp = client.execute(req, access_token);
System.out.println(rsp.getBody());
```

Python

```python
import dingtalk.api

req=dingtalk.api.OapiAttendanceGroupGetRequest("https://api.dingtalk.io/topapi/attendance/group/get")

req.op_userid="123456"

try:
  resp= req.getResponse(access_token)

  print(e)
```

PHP

```php
include "TopSdk.php";
date_default_timezone_set('Asia/Shanghai');

```

C#

```text

req.GroupKey = "0151E0xxxxA1A917";

```

## Respons

### Isi respons

| Nama | Jenis | Contoh | Penerangan |
| --- | --- | --- | --- |
| result | Object |  | Hasil maklumat kumpulan kehadiran. |
| name | String | Kumpulan kehadiran ujian 1 | Nama kumpulan kehadiran. |
| ext | String |  | Medan lanjutan dalam format JSON. |
| location_offset | Nombor | 100 | Julat daftar masuk, dalam meter.  **Nota**  Medan ini tidak lagi digunakan. Gunakan offset yang dikembalikan oleh [Tanya lokasi secara pukal](/ms/open/development/batch-query-position-under-attendance-group). |
| group_key | String | 0151E0223B1EDDDF00DD6B7F72A1A917 | groupKey kumpulan kehadiran. |
| enable_face_check | Boolean | false | Sama ada daftar masuk dengan senyuman diaktifkan.   - **true**: Aktif - **false** (lalai): Tidak aktif |
| enable_face_beauty | Boolean | false | Sama ada penapis kecantikan diaktifkan.   - **true**: Aktif - **false** (lalai): Tidak aktif |
| enable_camera_check | Boolean | false | Sama ada daftar masuk dengan foto diaktifkan.   - **true**: Aktif - **false** (lalai): Tidak aktif |
| enable_outside_check | Boolean | false | Sama ada kehadiran luar pejabat dibenarkan.   - **true**: Dibenarkan - **false** (lalai): Tidak dibenarkan |
| enable_outside_apply | Boolean | false | Sama ada kehadiran luar pejabat memerlukan kelulusan.   - **true**: Diperlukan - **false** (lalai): Tidak diperlukan |
| outside_check_approve_mode | Nombor | 0 | Mod kelulusan bagi kehadiran luar pejabat.   - **-1** (lalai): Tidak aktif - **0**: Lulus dahulu, kemudian daftar masuk - **1**: Daftar masuk dahulu, kemudian lulus |
| enable_outside_remark | Boolean | false | Sama ada kehadiran luar pejabat memerlukan catatan.   - **true**: Diperlukan - **false** (lalai): Tidak diperlukan |
| enable_outside_camera_check | Boolean | false | Sama ada kehadiran luar pejabat memerlukan catatan foto.   - **true**: Diperlukan - **false** (lalai): Tidak diperlukan |
| forbid_hide_outside_address | Boolean | true | Sama ada pekerja dilarang menyembunyikan alamat terperinci.   - **true** (lalai): Dilarang - **false**: Tidak dilarang |
| enable_outside_update_normal_check | Boolean | false | Sama ada rekod kehadiran luar pejabat boleh mengemas kini rekod daftar masuk biasa.   - **true**: Dibenarkan - **false** (lalai): Tidak dibenarkan |
| enable_trim_distance | Boolean | false | Sama ada pelarasan halus jarak lokasi dibenarkan.   - **true**: Dibenarkan - **false** (lalai): Tidak dibenarkan |
| trim_distance | Nombor | 50 | Julat pelarasan halus lokasi, dalam meter. |
| errmsg | String | ok | Mesej ralat yang dikembalikan. |
| success | Boolean | true | Sama ada permintaan berjaya.   - **true**: Berjaya - **false**: Gagal |
| errcode | Nombor | 0 | Kod ralat. |
