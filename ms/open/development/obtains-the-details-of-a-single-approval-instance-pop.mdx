---
title: "Dapatkan butiran satu instans kelulusan"
description: "Panggil API DingTalk ini untuk mendapatkan butiran instans kelulusan melalui ID, termasuk tajuk, userId pemohon dan penyokong, serta log aktiviti."
---

Panggil API ini untuk mendapatkan butiran instans kelulusan berdasarkan ID instans. Butiran yang dikembalikan termasuk tajuk instans kelulusan, userId pemohon, userId penyokong dan Log Aktiviti.

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/v1.0/workflow/processInstances |
| Kaedah HTTP | GET |
| Jenis aplikasi yang disokong | appType-Aplikasi dalaman　appType-Aplikasi perusahaan pihak ketiga |
| Kebenaran yang diperlukan | permission-Workflow.Instance.Read-Kebenaran membaca instans aliran kerja |

### Pengepala permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Dapatkan kredensial seperti berikut:   - Aplikasi dalaman: Panggil API [Dapatkan access token aplikasi dalaman](/ms/open/development/obtain-the-access-token-of-an-internal-app). - Aplikasi perusahaan pihak ketiga: Panggil API untuk mendapatkan access token organisasi yang telah memberi kebenaran kepada Aplikasi pihak ketiga. |

### Parameter pertanyaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| processInstanceId | String | Ya | ID instans kelulusan.   - Panggil API [Cipta instans kelulusan](/ms/open/development/create-an-approval-instance) untuk mendapatkan nilai parameter `InstanceId`. - Panggil API [Dapatkan senarai ID instans kelulusan](/ms/open/development/obtain-an-approval-list-of-instance-ids) untuk mendapatkan nilai parameter `list`. |
