Panggil API ini untuk menarik balik mesej Bot dalam perbualan satu-lawan-satu secara pukal berdasarkan ID perbualan, robot code, dan senarai ID mesej. API ini sesuai untuk senario di mana mesej yang dihantar kepada Organisasi Anda perlu ditarik balik akibat kesilapan.

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/v1.0/robot/privateChatMessages/batchRecall |
| Kaedah HTTP | POST |
| Jenis aplikasi yang disokong | appType-Internal app　appType-Third-party enterprise app |
| Kebenaran diperlukan | permission-qyapi_robot_sendmsg-Permission for bots to send messages within your organization |

### Pengepala permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Dapatkan seperti berikut:   - Untuk aplikasi dalaman, panggil API [Dapatkan access token aplikasi dalaman](/open/development/obtain-the-access-token-of-an-internal-app#). - Untuk aplikasi perusahaan pihak ketiga, panggil API [Dapatkan access token organisasi yang telah memberikan kebenaran kepada aplikasi pihak ketiga](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#). |

### Isi permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| openConversationId | String | Ya | ID perbualan. Nilai ini mesti sama dengan openConversationId yang digunakan dalam API [Hantar mesej teks biasa dalam perbualan satu-lawan-satu melalui Bot](/open/development/the-robot-sends-ordinary-messages-in-a-person-to-person-conversation#) atau API [Cipta dan hantar kad](https://open.dingtalk.com/document/development/create-and-deliver-cards#). |
| robotCode | String | Ya | Kod Bot. Untuk maklumat lanjut, lihat [ID Bot](https://open.dingtalk.com/document/development/robot-overview#).  Nilai ini mesti sama dengan robotCode yang digunakan dalam API [Hantar mesej teks biasa dalam perbualan satu-lawan-satu melalui Bot](/open/development/the-robot-sends-ordinary-messages-in-a-person-to-person-conversation#). |
| processQueryKeys | Array of String | Ya | ID mesej.   - Untuk aplikasi dalaman, dapatkan nilai parameter `processQueryKey` dengan memanggil API [Cipta dan hantar kad](https://open.dingtalk.com/document/development/create-and-deliver-cards#) atau API [Hantar mesej teks biasa dalam perbualan satu-lawan-satu melalui Bot](/open/development/the-robot-sends-ordinary-messages-in-a-person-to-person-conversation#). |
