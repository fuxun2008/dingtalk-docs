description: "Panggil API kehadiran DingTalk untuk memaklumkan bahawa daftar masuk susulan pekerja telah diluluskan, dengan userId, tarikh, ID syif dan borang kelulusan."
---

Panggil API ini untuk memaklumkan bahawa permintaan daftar masuk susulan kehadiran telah diluluskan.

## Permintaan

| **Maklumat asas** | |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/topapi/attendance/approve/check |
| Kaedah HTTP | POST |
| Jenis aplikasi yang disokong | appType-Aplikasi dalaman appType-Aplikasi perusahaan pihak ketiga |
| Kebenaran | permission-qyapi_attendance_group_manage-Kebenaran pengurusan kumpulan kehadiran |

### Parameter pertanyaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | bE74xxxx | Kelayakan aplikasi yang digunakan untuk memanggil API ini.   - Bagi Aplikasi dalaman, panggil API [Dapatkan access_token aplikasi dalaman](/ms/open/development/obtain-orgapp-token) untuk mendapatkannya. - Bagi Aplikasi perusahaan pihak ketiga, panggil API Dapatkan access_token organisasi pihak ketiga untuk mendapatkannya. |

### Isi permintaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| userid | String | Ya | manager4220 | ID pengguna pekerja. |
| work_date | String | Ya | 2019-08-15 | Tarikh daftar masuk susulan. Gunakan nilai work_date yang dikembalikan oleh API [Tanya maklumat penjadualan syif pengguna secara pukal](/ms/open/development/query-batch-scheduling-information). |
| punch_id | Number | Ya | 176877195378 | ID syif yang perlu disusulkan. Gunakan nilai shift_id yang dikembalikan oleh API [Tanya maklumat penjadualan syif pengguna secara pukal](/ms/open/development/query-batch-scheduling-information). |
| punch_check_time | String | Ya | 2019-08-15 08:00 | Masa daftar masuk yang dijadualkan bagi syif tersebut. Gunakan nilai plan_check_time yang dikembalikan oleh API [Tanya maklumat penjadualan syif pengguna secara pukal](/ms/open/development/query-batch-scheduling-information). |
| user_check_time | String | Ya | 2019-08-15 07:59 | Masa pengguna membuat daftar masuk. |
| approve_id | String | Ya | aasdv13124 | ID borang kelulusan. Nilai ini ditetapkan secara tersuai. |
| jump_url | String | Ya | https://open.dingtalk.io/ | URL ubah hala borang kelulusan. |
| tag_name | String | Ya | Daftar masuk susulan | Nama borang kelulusan. |

### Contoh permintaan

```curl
curl -X POST "https://api.dingtalk.io/topapi/report/create?access_token=YOUR_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "create_report_param": {
   
    }
  }'
```

Java

```bash
curl -X POST "https://api.dingtalk.io/topapi/attendance/approve/check" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=1eddxxxxca1a1' \
-d 'approve_id=aasdv13124' \
-d 'jump_url=https%3A%2F%2Fxxx.xxx' \
-d 'punch_check_time=2019-08-15+08%3A00' \
-d 'punch_id=12345' \
-d 'tag_name=Daftar+masuk+susulan' \
-d 'user_check_time=2019-08-15+07%3A59' \
-d 'userid=dd_dd' \
-d 'work_date=2019-08-15'
```

Python

```python
import dingtalk.api

req=dingtalk.api.OapiAttendanceApproveCheckRequest("https://api.dingtalk.io/topapi/attendance/approve/check")

req.userid="dd_dd"
req.work_date="2019-08-15"
req.punch_id=12345
req.punch_check_time="2019-08-15 08:00"
req.user_check_time="2019-08-15 07:59"
req.approve_id="aasdv13124"
req.jump_url="https://xxx.xxx"
req.tag_name="Daftar masuk susulan"
try:
  resp= req.getResponse(access_token)
  print(resp)
except Exception,e:
  print(e)
```

PHP

```php

```

## Respons

### Isi respons

| Nama | Jenis | Contoh | Penerangan |
| --- | --- | --- | --- |
| errcode | Number | 0 | Kod pemulangan. |
| errmsg | String | ok | Penerangan kod pemulangan. |

### Contoh isi respons

```json
{
  "errcode":0,
  "errmsg":"ok"
}
```

### Kod ralat

Jika panggilan mengembalikan ralat, cari penyelesaian dalam dokumen [Kod ralat global](/ms/open/development/server-api-error-codes-1) berdasarkan mesej ralat.
