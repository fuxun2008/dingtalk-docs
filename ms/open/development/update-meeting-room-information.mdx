Panggil API ini untuk mengemas kini maklumat Bilik.

## Penerangan panggilan API

Mengemas kini maklumat Bilik. Hanya Admin dengan kebenaran Urus Aplikasi pada Bilik Mesyuarat Pintar dibenarkan melakukan tindakan ini.

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/v1.0/rooms/meetingRooms |
| Kaedah HTTP | PUT |
| Jenis aplikasi disokong | appType-Aplikasi dalaman　appType-Aplikasi perusahaan pihak ketiga |
| Kebenaran diperlukan | permission-VideoConference.Conference.Write-Kebenaran pengurusan maklumat Mesyuarat Video |

### Pengepala permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Dapatkan seperti berikut:   - Untuk Aplikasi dalaman, panggil API [Dapatkan access token aplikasi dalaman](/open/development/obtain-the-access-token-of-an-internal-app). - Untuk Aplikasi perusahaan pihak ketiga, panggil API [Dapatkan access token organisasi yang dibenarkan](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1). |

### Isi permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| unionId | String | Ya | unionId pengendali. Panggil API [Semak butiran pengguna](/open/development/query-user-details) untuk mendapatkannya. |
| roomId | String | Ya | ID Bilik. Panggil API [Semak senarai bilik mesyuarat](/open/development/check-the-meeting-room-list) untuk mendapatkannya. |
| roomName | String | Tidak | Nama Bilik. |
| roomCapacity | Integer | Tidak | Kapasiti Bilik. |
| roomPicture | String | Tidak | Gambar Bilik. |
| roomStatus | Integer | Tidak | Status Bilik.   - **0**: Tersedia untuk semua pengguna - **1**: Tersedia untuk Admin sahaja - **2**: Tersedia untuk pengguna dibenarkan tertentu |
| roomLocation | Object | Tidak | Maklumat Lokasi Bilik. |
| title | String | Tidak | Tajuk Lokasi Bilik. |
| desc | String | Tidak | Maklumat terperinci Lokasi Bilik. |
| roomLabelIds | Array of Long | Tidak | ID Tag.   - **1**: TV - **2**: Telefon - **3**: Projektor - **4**: Whiteboard - **5**: Mesyuarat Video |
| isvRoomId | String | Tidak | ID Bilik luaran bagi pemanggil. Pemanggil boleh memasukkan ID Bilik daripada sistem mereka sendiri.      Jika pemanggil tidak perlu mengaitkan dengan Bilik luaran, Nombor Bilik fizikal Organisasi boleh dimasukkan sebaliknya. |
| groupId | Long | Tidak | ID Kumpulan yang menjadi milik Bilik. Panggil API [Semak senarai Kumpulan bilik mesyuarat](/open/development/query-meeting-rooms-groups) untuk mendapatkannya. |
| reservationAuthority | Object | Tidak | Kebenaran tempahan yang dikonfigurasi untuk Bilik apabila roomStatus ditetapkan kepada kebenaran separa. |
| authorizedMembers | Array | Tidak | Senarai Pengguna dibenarkan. |
| memberId | String | Tidak | ID Pengguna, dikonfigurasi berdasarkan memberType:   - **User**: unionId Pengguna. Panggil API [Semak butiran pengguna](/open/development/query-user-details) untuk mendapatkannya. - **Department**: ID Jabatan (dept_id). Panggil API [Dapatkan senarai jabatan](https://open.dingtalk.com/document/development/obtain-the-department-list-v2) untuk mendapatkan nilai parameter dept_id. |
| memberType | String | Tidak | Jenis Pengguna:   - **User**: pengguna - **Department**: jabatan |
| memberName | String | Tidak | Nama Pengguna:   - **User**: Nama Pengguna - **Department**: Nama Jabatan |
| enableCycleReservation | Boolean | Tidak | Sama ada Bilik menyokong tempahan berulang:   - **true**: Ya - **false**: Tidak |
| openReservation | Boolean | Tidak | Sama ada Bilik dibuka untuk tempahan:   - **true**: Ya - **false**: Tidak |
| roomDescription | String | Tidak | Penerangan Bilik. |
