Panggil API ini untuk mendapatkan maklumat sibuk/lapang bagi bilik tertentu.

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/calendar/users/{userId}/meetingRooms/schedules/query` |
| Kaedah HTTP | POST |
| Jenis aplikasi yang disokong | appType-Aplikasi dalaman　appType-Aplikasi perusahaan pihak ketiga |
| Kebenaran yang diperlukan | permission-Calendar.Event.Read-Kebenaran baca untuk acara dalam aplikasi Calendar |

### Header permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Dapatkan seperti berikut:   - Untuk aplikasi dalaman, panggil API [Dapatkan access token aplikasi dalaman](/ms/open/development/obtain-the-access-token-of-an-internal-app#). - Untuk aplikasi perusahaan pihak ketiga, panggil API [Dapatkan access token organisasi yang diberi kuasa kepada aplikasi pihak ketiga](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#). |

### Parameter laluan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| userId | String | Ya | unionId pengguna yang memiliki sumber untuk permintaan ini. Panggil API [Tanya butiran pengguna](/ms/open/development/query-user-details#) untuk mendapatkannya. |

### Isi permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| roomIds | Array of String | Ya | Senarai roomId untuk ditanya. Panggil API [Tanya senarai bilik](/ms/open/development/check-the-meeting-room-list#) untuk mendapatkannya. Kami mengesyorkan bilangan roomId tidak melebihi 5. |
| startTime | String | Ya | Masa mula pertanyaan, dalam format ISO 8601. Contoh: 2022-07-29T14:55Z. |
| endTime | String | Ya | Masa tamat pertanyaan, dalam format ISO 8601. Contoh: 2022-07-29T14:55Z. |

| dateTime | String | Masa tamat acara, dalam format ISO 8601. Contoh: 2022-07-29T14:55Z. |
