---
title: "Send a file link to a chat"
description: "Call this API to send a file link to a specified chat so that members can access the file quickly."
---

Panggil API ini untuk menghantar pautan fail kepada sembang yang ditentukan.

## Permintaan

### Maklumat Asas

| Medan | Nilai |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/v1.0/convFile/conversations/files/links/send |
| Kaedah HTTP | POST |
| Jenis aplikasi disokong | appType-Aplikasi dalaman |
| Kebenaran diperlukan | permission-ConvFile.File.Send-Kebenaran hantar fail kumpulan |

### Pengepala permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Dapatkan dengan memanggil API [Dapatkan access token aplikasi dalaman](/open/development/obtain-the-access-token-of-an-internal-app#). |

### Parameter pertanyaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| unionId | String | Ya | unionId bagi pengendali. Dapatkan dengan memanggil API [Tanya butiran pengguna](/open/development/query-user-details#). |

### Isi permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| spaceId | String | Ya | ID ruang tempat fail berada. Dapatkan dengan memanggil API [Tambah ruang](/open/development/add-space#). |
| dentryId | String | Ya | ID fail. Dapatkan nilai parameter `id` dengan memanggil API [Dapatkan senarai fail atau folder](https://open.dingtalk.com/document/development/obtain-the-file-list-storage#). |
| openConversationId | String | Ya | openConversationId bagi sembang sasaran. Dapatkan nilai parameter `openConversationId` dengan memanggil API [Cipta kumpulan](https://open.dingtalk.com/document/development/create-group-session#). |

### Contoh permintaan

## Respons

### Isi respons

| Nama | Jenis | Penerangan |
| --- | --- | --- |
| file | Object | Maklumat pautan fail yang dihantar ke sembang sasaran. |
| id | String | ID fail. |
| conversationId | String | openConversationId bagi sembang tempat fail berada. |
| spaceId | String | ID ruang tempat fail berada. |
| parentId | String | ID folder induk tempat fail berada. ID folder root ialah 0. |
| type | String | Jenis fail.   - **FILE**: fail - **FOLDER**: folder |
| name | String | Nama fail. |
| size | Long | Saiz fail, dalam bait. |
| path | String | Laluan fail. |
| version | Long | Nombor versi fail. |
| status | String | Status fail.   - **NORMAL**: normal - **DELETED**: dipadam - **EXPIRED**: tamat tempoh |
| extension | String | Sambungan fail. |
| creatorId | String | unionId pencipta fail. |
| modifierId | String | unionId pengubah suai fail. |
| createTime | String | Masa fail dicipta, dalam format ISO 8601. Contoh: 2022-07-29T14:55Z. |
| modifiedTime | String | Masa fail terakhir diubah suai, dalam format ISO 8601. Contoh: 2022-07-29T14:55Z. |
| uuid | String | Medan pengecam. |
