Panggil API ini untuk menyemak sejarah syif berdasarkan ID syif dan versi. Respons mengandungi nama syif, tetapan syif, masa daftar masuk dan masa rehat.

## Permintaan

| **Maklumat asas** | |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/topapi/attendance/shift/history/query |
| Kaedah HTTP | POST |
| Jenis aplikasi yang disokong | appType-Aplikasi dalaman |
| Kebenaran | permission-qyapi_attendance_group_read-Kebenaran pertanyaan kumpulan kehadiran |

### Parameter pertanyaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | 73e9xxx | Kelayakan aplikasi yang digunakan untuk memanggil API ini. Dapatkannya dengan memanggil API [Dapatkan access_token Aplikasi dalaman](/ms/open/development/obtain-orgapp-token). |

### Isi permintaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| op_user_id | String | Ya | user123 | userId pengendali. |
| shift_id | Number | Ya | 628380875 | ID syif. Dapatkan nilai id dengan memanggil API [Dapatkan ringkasan syif](/ms/open/development/enterprise-shift-query-in-batches). |
| version | Number | Ya | 624190327 | Versi syif. Dapatkan nilai shift_version dengan memanggil API [Pertanyaan pukal maklumat penjadualan syif pengguna](/ms/open/development/query-batch-scheduling-information). |

### Contoh permintaan

```curl
curl -X POST "https://api.dingtalk.io/topapi/attendance/shift/history/query" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=e56f7xxxxeb7ef1' \
-d 'op_user_id=dd_dd' \
-d 'shift_id=2445' \
-d 'version=222'
```

Java

```java
DingTalkClient client = new DefaultDingTalkClient("https://api.dingtalk.io/topapi/attendance/shift/history/query");
OapiAttendanceShiftHistoryQueryRequest req = new OapiAttendanceShiftHistoryQueryRequest();
req.setOpUserId("user456");
req.setShiftId(715390132L);
req.setVersion(624190327L);
OapiAttendanceShiftHistoryQueryResponse rsp = client.execute(req, access_token);
System.out.println(rsp.getBody());
```

Python

```python

```

```php
date_default_timezone_set('Asia/Shanghai');
```

C#

```csharp

OapiAttendanceShiftHistoryQueryRequest req = new OapiAttendanceShiftHistoryQueryRequest();
```

## Respons

### Isi respons

| Nama | Jenis | Contoh | Penerangan |
| --- | --- | --- | --- |
| result | TopShiftVo |  | Hasil pertanyaan. |
| shift_group_name | String | Syif siang biasa | Nama kumpulan syif. |
| corp_id | String | dinge87fxxx | ID organisasi (corpId). |
| shift_setting | TopShiftSettingVo |  | Tetapan syif. |
| shift_id | Number | 628380875 | ID syif. |
| gmt_modified | Date | 2021-01-14 14:21:03 | Masa syif terakhir diubah suai. |
| corp_id | String | dinge87fxxx | ID organisasi (corpId). |
| is_deleted | String | N | Penanda pemadaman. |
| work_time_minutes | Number | 480 | Tempoh kerja, dalam minit. Nilai -1 menunjukkan ciri ini dinyahaktifkan. |
| id | Number | 350530359 | ID tetapan syif. Tidak digunakan buat masa ini. |
| attend_days | String | 21 | Bilangan hari kehadiran bagi syif ini. |
| gmt_create | Date | 2021-01-14 14:18:08 | Masa penciptaan. |
| name | String | Syif siang biasa | Nama syif. |
| id | Number | 241120079 | ID syif. |
| sections | TopSectionVo[] |  | Bahagian daftar masuk. |
| punches | TopPunchVo[] |  | Titik daftar masuk. |
| check_type | String | OnDuty | Jenis daftar masuk:   - **OnDuty**: Daftar masuk - **OffDuty**: Daftar keluar |
| end_min | Number | 1 | Kelewatan maksimum yang dibenarkan untuk daftar masuk, dalam minit. |
| across | Number | 0 | Sama ada syif merentasi ke hari berikutnya:   - **0**: Tidak merentasi ke hari berikutnya - **1**: Merentasi ke hari berikutnya |
| check_time | Date | 1970-01-01 09:00:00 | Masa daftar masuk. |
| permit_minutes | Number | 60 | Tempoh yang dibenarkan untuk kelewatan atau pulang awal. |
| free_check | Boolean | false | Sama ada dikecualikan daripada daftar masuk:   - **true**: Daftar masuk tidak diperlukan - **false**: Daftar masuk diperlukan |
| id | Number | 376955859 | ID titik daftar masuk. Tidak digunakan buat masa ini. |
| begin_min | Number | demo | Tempoh paling awal yang dibenarkan untuk daftar masuk lebih awal, dalam minit. |
| work_time_minutes | Number | 480 | Tempoh kerja, dalam minit. |
| rests | TopRestVo[] |  | Bahagian rehat. |
| check_type | String | OnDuty | Jenis rehat:   - **OnDuty**: Rehat bermula - **OffDuty**: Rehat tamat |
| across | Number | 0 | Sama ada rehat merentasi ke hari berikutnya, iaitu masa rehat jatuh pada hari berikutnya:   - **0**: Tidak merentasi ke hari berikutnya - **1**: Merentasi ke hari berikutnya |
| check_time | Date | 1970-01-01 12:00:00 | Masa rehat. |
| id | Number | 376955861 | ID titik rehat. |
| id | Number | 22979360 | ID bahagian daftar masuk. Setiap pasangan daftar masuk dan daftar keluar membentuk satu bahagian. Satu syif boleh mempunyai beberapa bahagian. |
| shift_group_id | Number | 22979 | ID kumpulan syif. |
| success | Boolean | true | Sama ada panggilan berjaya.   - **true**: Berjaya - **false**: Gagal |
| errcode | Number | 0 | Kod pemulangan. |
| errmsg | String | ok | Penerangan kod pemulangan. |
| request_id | String | q3ef3y3sogkd | ID permintaan. |
