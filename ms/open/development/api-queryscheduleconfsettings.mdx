Tanya tetapan mesyuarat berjadual mengikut ID mesyuarat.

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/v1.0/conference/scheduleConferences/settings |
| HTTP Method | GET |
| Jenis aplikasi yang disokong | appType-Internal appappType-Third-party enterprise app |
| Kebenaran yang diperlukan | permission-VideoConference.Conference.Read-Read permission for Video Meeting information |

### Header permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses yang digunakan untuk memanggil API ini. Dapatkan seperti berikut:   - Untuk aplikasi dalaman, panggil API [Dapatkan access token aplikasi dalaman](/ms/open/development/obtain-the-access-token-of-an-internal-app#). - Untuk aplikasi perusahaan pihak ketiga, panggil API [Dapatkan access token organisasi yang dibenarkan untuk aplikasi pihak ketiga](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#). |

### Parameter kueri

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| scheduleConferenceId | String | Ya | ID mesyuarat berjadual. Dapatkan daripada medan `scheduleConferenceId` yang dikembalikan oleh API [Cipta mesyuarat berjadual](/ms/open/development/create-appointment-meeting#). |

## Respons

### Isi respons

| Nama | Jenis | Penerangan |
| --- | --- | --- |
| scheduleConfSettingModel | Object | Tetapan mesyuarat berjadual. |
| hostUnionId | String | unionId tuan rumah. |
| cohostUnionIds | Array of String | unionId untuk co-host. |
| confAllowedCorpId | String | ID organisasi untuk mesyuarat dalaman. |
| lockRoom | Integer | Kunci mesyuarat:   - 0: buka kunci - 1: kunci |
| screenShareForbidden | Integer | Perkongsian:   - 0: benarkan perkongsian - 1: larang perkongsian |
| muteOnJoin | Integer | Bisukan pengguna apabila mereka menyertai persidangan:   - -1: aktif - 0: nyahaktif - 6: bisukan secara automatik apabila lebih daripada 6 pengguna menyertai |
| moziConfVirtualExtraSetting | Object | Tetapan mesyuarat berjadual. |
| waitingRoom | Integer | Bilik menunggu:   - 0: nyahaktif - 1: aktif |
| joinBeforeHost | Integer | Sertai mesyuarat sebelum tuan rumah:   - 0: nyahaktif - 1: aktif |
| enableChat | Integer | Sembang dan interaksi:   - 0: nyahaktif - 1: aktif |
| lockNick | Integer | Namakan semula diri sendiri:   - 0: benarkan pengguna menamakan semula diri mereka - 1: larang pengguna daripada menamakan semula diri mereka |
| lockMediaStatusMicMute | Integer | Nyahbisukan diri sendiri:   - 0: benarkan pengguna menyahbisukan diri mereka - 1: larang pengguna daripada menyahbisukan diri mereka |
| moziConfExtensionAppSettings | Array | Senarai tetapan aplikasi sambungan mesyuarat. |
| clientId | String | clientId aplikasi terbuka DingTalk. |
| coolAppCode | String | Kod CoolApp. Cari kod CoolApp di bawah Aplikasi mikro dalam Konsol Pembangun. |
| autoOpenMode | String | Mod buka automatik:   - 0: jangan buka secara automatik - 1: buka secara automatik hanya untuk tuan rumah dan co-host - 2: buka secara automatik untuk semua pengguna |
| extensionAppBizData | String | Data tersuai untuk aplikasi sambungan skop mesyuarat. |
| enableWebAnonymousJoin | Boolean | Sama ada log masuk senyap disokong untuk menyertai mesyuarat daripada web:   - true: disokong - false: tidak disokong |
