title: "Terima atau tolak tugasan kelulusan"
description: "Panggil API DingTalk ini untuk menerima atau menolak satu tugasan kelulusan berdasarkan ID instans, ID tugas dan userId pengendali, lengkap dengan komen dan lampiran."
---

Panggil API ini untuk memproses satu tugasan kelulusan berdasarkan ID templat, ID instans kelulusan, ID nod tugasan dan userId pengendali yang ditentukan.

## Penerangan panggilan API

1. Satu proses kelulusan boleh mengandungi beberapa nod kelulusan, dan satu nod kelulusan boleh mengandungi satu atau lebih tugasan kelulusan. Memproses satu tugasan kelulusan tidak semestinya menamatkan proses kelulusan.

   - Jika proses kelulusan hanya mempunyai seorang penyokong, tindakan menerima atau menolak tugasan kelulusan tersebut akan menamatkan proses kelulusan.

     **Proses kelulusan** yang lazim berjalan mengikut aliran tertib: **Hantar permintaan** (oleh pemohon) > **penyokong** > **penerima CC**.
   - Jika proses kelulusan mempunyai beberapa penyokong, keseluruhan proses kelulusan bergantung pada beberapa tugasan.

     - Menolak satu tugasan kelulusan akan menamatkan proses kelulusan.
     - Menerima satu tugasan kelulusan akan menggerakkan proses kelulusan kepada penyokong seterusnya.

       Satu nod kelulusan boleh memerlukan beberapa penyokong dalam salah satu daripada dua mod: **Kelulusan bersama**: semua ahli yang disenaraikan mesti **Terima** supaya nod tersebut lulus. **Kelulusan mana-mana satu**: kelulusan oleh mana-mana seorang ahli yang disenaraikan sudah memadai untuk nod tersebut lulus.
2. Untuk menambah lampiran pada komen kelulusan, muat naik fail ke ruang Drive kelulusan. Langkah ini menyediakan parameter API spaceId, fileType, fileName, fileId dan fileSize. Dapatkan parameter tersebut seperti berikut:

   1. Panggil API [Dapatkan maklumat ruang Drive kelulusan](/ms/open/development/obtains-the-information-about-approval-nail-disk) untuk mendapatkan kebenaran Muat naik bagi ruang Drive dan mendapatkan spaceId ruang Drive kelulusan.
   2. Gunakan spaceId ruang Drive kelulusan untuk memuat naik lampiran ke Drive atau memilih fail daripada Drive dalam aplikasi web (Aplikasi mikro H5) bagi mendapatkan maklumat fail lampiran Drive.

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/v1.0/workflow/processInstances/execute |
| Kaedah HTTP | POST |
| Jenis aplikasi yang disokong | appType-Aplikasi dalaman |
| Kebenaran yang diperlukan | permission-Workflow.Instance.Write-Kebenaran tulis instans aliran kerja |

### Pengepala permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Panggil API [Dapatkan Access Token aplikasi dalaman](/ms/open/development/obtain-the-access-token-of-an-internal-app) untuk mendapatkannya. |

### Isi permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| processInstanceId | String | Ya | ID instans kelulusan:   - Panggil API [Cipta instans kelulusan](/ms/open/development/create-an-approval-instance) untuk mendapatkan nilai parameter `InstanceId`. - Panggil API [Dapatkan senarai ID instans kelulusan](/ms/open/development/obtain-an-approval-list-of-instance-ids) untuk mendapatkan nilai parameter `list`. |
| remark | String | Tidak | Komen kelulusan. Panjang maksimum: 1,024 aksara. Boleh dibiarkan kosong. |
| result | String | Ya | Tindakan kelulusan. Nilai yang sah:   - **agree**: Terima - **refuse**: Tolak |
| actionerUserId | String | Ya | userId pengendali. Panggil API [Dapatkan butiran instans kelulusan tunggal](/ms/open/development/obtains-the-details-of-a-single-approval-instance-pop) untuk mendapatkan nilai parameter `userId`. |
| taskId | Long | Ya | ID tugas. Panggil API [Dapatkan butiran instans kelulusan tunggal](/ms/open/development/obtains-the-details-of-a-single-approval-instance-pop) untuk mendapatkan nilai parameter `taskId`. |
| file | Object | Tidak | Fail. |
| photos | Array of String | Tidak | URL gambar. Panjang maksimum: 1,024 aksara. |
| attachments | Array | Tidak | Senarai lampiran. Bilangan elemen maksimum: 20. |
| spaceId | String | Tidak | ID ruang Drive.      Rujuk penerangan panggilan API dalam topik ini. |
| fileSize | String | Tidak | Saiz fail.      Rujuk penerangan panggilan API dalam topik ini. |
| fileId | String | Tidak | ID fail. Panjang maksimum: 256 aksara.      Rujuk penerangan panggilan API dalam topik ini. |
| fileName | String | Tidak | Nama fail. Panjang maksimum: 256 aksara.      Rujuk penerangan panggilan API dalam topik ini. |
| fileType | String | Tidak | Jenis fail.      Rujuk penerangan panggilan API dalam topik ini. |

### Kod ralat

Jika panggilan API mengembalikan ralat, cari penyelesaian dalam dokumen [Kod ralat global](/ms/open/development/server-api-error-codes-1) berdasarkan mesej ralat.

| HttpCode | Kod ralat | Mesej ralat | Penerangan |
| --- | --- | --- | --- |
| 400 | invalidParameter | Ralat parameter untuk menerima atau menolak tugasan kelulusan | Ralat parameter untuk menerima atau menolak tugasan kelulusan |
| 400 | needAuth | Tiada kebenaran untuk menerima atau menolak kelulusan | Tiada kebenaran untuk menerima atau menolak kelulusan |
| 400 | invalidAgentId | ID Aplikasi mikro tidak sah | ID Aplikasi mikro tidak sah |
| 400 | aflowProcessNotExist | Aliran kerja kelulusan tidak wujud | Aliran kerja kelulusan tidak wujud |
| 400 | invalidInstanceId | ID instans kelulusan tidak boleh kosong | ID instans kelulusan tidak boleh kosong |
| 400 | invalidInstanceExecuteActionerUserId | Terima atau tolak tugasan kelulusan: userId pengendali tidak boleh kosong | Terima atau tolak tugasan kelulusan: userId pengendali tidak boleh kosong |
| 400 | invalidInstanceExecuteTaskId | Terima atau tolak tugasan kelulusan: ID nod tugasan tidak boleh kosong | Terima atau tolak tugasan kelulusan: ID nod tugasan tidak boleh kosong |
| 400 | invalidInstanceExecuteResult | Terima atau tolak tugasan kelulusan: tindakan kelulusan wajib diisi dan mestilah agree atau refuse | Terima atau tolak tugasan kelulusan: tindakan kelulusan wajib diisi dan mestilah agree atau refuse |
| 400 | aflowProcessFormDataIsNull | Data borang aliran kerja kosong | Data borang aliran kerja kosong |
| 400 | aflowProcessInstStatusException | Ralat status borang kelulusan | Ralat status borang kelulusan |
| 400 | aflowProcessInstCanNotBeExecuted | Ralat status kelulusan. Tindakan tidak dapat dilaksanakan | Ralat status kelulusan. Tindakan tidak dapat dilaksanakan |
| 400 | internalError | %s | Ralat sistem dalaman |
| 400 | userNotExist | Pengguna tidak wujud | Pengguna tidak wujud |
| 500 | systemError | Ralat sistem | Ralat sistem |
