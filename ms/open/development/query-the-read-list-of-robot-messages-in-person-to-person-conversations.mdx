Panggil API ini untuk menanyakan senarai bacaan Mesej Bot dalam perbualan satu-ke-satu berdasarkan ID kumpulan, kod Bot, dan ID mesej. API ini sesuai digunakan untuk senario yang memerlukan pengesahan sama ada mesej Bot telah dibaca semasa komunikasi Mesej Terus antara pengguna dalam Organisasi Anda.

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/v1.0/robot/privateChatMessages/query |
| HTTP Method | POST |
| Jenis aplikasi yang disokong | appType-Aplikasi dalaman　appType-Aplikasi perusahaan pihak ketiga |
| Kebenaran yang diperlukan | permission-qyapi_robot_sendmsg-Kebenaran untuk Bot dalam Organisasi Anda menghantar mesej |

### Header permintaan

| Nama | Jenis | Wajib | Keterangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Dapatkan nilai ini seperti berikut:   - Untuk aplikasi dalaman, panggil API [Dapatkan access token aplikasi dalaman](/open/development/obtain-the-access-token-of-an-internal-app#). - Untuk aplikasi perusahaan pihak ketiga, panggil API [Dapatkan access token organisasi yang dibenarkan untuk aplikasi pihak ketiga](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#). |

### Isi permintaan

| Nama | Jenis | Wajib | Keterangan |
| --- | --- | --- | --- |
| openConversationId | String | Tidak | ID perbualan terbuka untuk perbualan satu-ke-satu. Dapatkan nilainya dengan memanggil [Pasang Mini App secara pukal ke dalam perbualan Mesej Terus](https://open.dingtalk.com/document/development/batch-chat-session#) dan melanggan [Peristiwa pengurusan perbualan](https://open.dingtalk.com/document/development/org-event-overview#260a4e7084gs2) untuk mendapatkan OpenConversationId. |
| robotCode | String | Tidak | Kod Bot. Untuk butiran, lihat [ID Bot](https://open.dingtalk.com/document/development/robot-overview#). |
| processQueryKey | String | Ya | ID mesej. Dapatkan nilai `processQueryKey` dengan memanggil API [Cipta dan hantar kad](https://open.dingtalk.com/document/development/create-and-deliver-cards#) atau API [Hantar mesej teks biasa melalui Bot dalam perbualan satu-ke-satu](/open/development/the-robot-sends-ordinary-messages-in-a-person-to-person-conversation#). |
| maxResults | Long | Tidak | Bilangan item setiap halaman dalam pertanyaan berhalaman. |
| nextToken | String | Tidak | Kredensial penghalaman yang disulitkan yang dikembalikan daripada pertanyaan sebelumnya. Biarkan kosong untuk pertanyaan pertama. |
