Panggil API ini untuk mengemas kini maklumat jabatan.

## Permintaan

| **Maklumat asas** | |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/topapi/v2/department/update |
| Kaedah HTTP | POST |
| Jenis aplikasi disokong | appType-Aplikasi dalaman |
| Kebenaran diperlukan | permission-qyapi_manage_addresslist-Kebenaran pengurusan data Kenalan |

### Parameter pertanyaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | bE74xxxx | Kelayakan aplikasi yang digunakan untuk memanggil API ini. Dapatkannya melalui API untuk mendapatkan [access_token bagi aplikasi dalaman](/open/development/obtain-orgapp-token). |

### Isi permintaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| dept_id | Number | Ya | 100 | ID jabatan. Anda boleh memanggil API [Dapatkan senarai jabatan](/open/development/user-management-acquires-the-list-departments) untuk mendapatkan nilai dept_id. |
| parent_id | Number | Tidak | 2 | ID jabatan induk. ID jabatan root ialah 1. Anda boleh memanggil API [Dapatkan senarai jabatan](/open/development/user-management-acquires-the-list-departments) untuk mendapatkan nilai parent_id. |
| hide_dept | Boolean | Tidak | true | Sama ada hendak menyembunyikan jabatan ini:   - **true**: sembunyikan jabatan.  Selepas disembunyikan, jabatan tidak akan muncul dalam kenalan syarikat. - **false**: tunjukkan jabatan.   Jika tiada nilai diberikan, tetapan semasa kekal tidak berubah. |
| dept_permits | String | Tidak | 123,456 | Senarai jabatan lain yang dibenarkan melihat jabatan ini.  Nilai ini berkuat kuasa apabila **hide_dept** ditetapkan kepada **true**.  **Nota**  Jumlah keseluruhan senarai ini ditambah senarai user_permits tidak boleh melebihi 50. |
| user_permits | String | Tidak | user123,manager222 | Senarai ID pengguna yang dibenarkan melihat jabatan ini.  Nilai ini berkuat kuasa apabila **hide_dept** ditetapkan kepada **true**.  **Nota**  Jumlah keseluruhan senarai ini ditambah senarai dept_permits tidak boleh melebihi 50. |
| create_dept_group | Boolean | Tidak | true | Sama ada hendak mencipta sembang organisasi yang dikaitkan dengan jabatan ini. Nilai lalai ialah false, bermaksud tiada sembang dicipta.  Jika tiada nilai diberikan, tetapan semasa kekal tidak berubah. |
| order | Number | Tidak | 10 | Nilai susunan dalam jabatan induk. Nilai order yang lebih kecil menduduki kedudukan lebih tinggi. |
| name | String | Tidak | HR | Nama jabatan. Panjangnya mestilah 1 hingga 64 aksara. Aksara '-', '，', dan ',' tidak dibenarkan. |
| source_identifier | String | Tidak | HR Department | Medan pengecam jabatan. Pembangun boleh menggunakan medan ini untuk mengenal pasti jabatan secara unik dan memetakannya kepada jabatan dalam kenalan DingTalk luaran.  **Nota**  Medan ini tidak dipaparkan dalam maklumat jabatan pada konsol pengurusan organisasi. |
| outer_dept | Boolean | Tidak | true | Sama ada hendak mengehadkan ahli jabatan ini daripada melihat kenalan:   - **true**: aktifkan sekatan. Setelah diaktifkan, ahli jabatan ini hanya boleh melihat kenalan dalam skop yang ditetapkan. - **false**: tiada sekatan.   Jika tiada nilai diberikan, tetapan semasa kekal tidak berubah. |
| outer_permit_users | String | Tidak | user123,manager123 | Senarai ID pengguna dalam kenalan yang dibenarkan dilihat oleh ahli jabatan ini.  Parameter ini berkuat kuasa apabila **outer_dept** ditetapkan kepada **true**.  **Nota**  Jumlah keseluruhan senarai ini ditambah senarai outer_permit_depts tidak boleh melebihi 50. |
| outer_permit_depts | String | Tidak | 123,456 | Senarai ID jabatan dalam kenalan yang dibenarkan dilihat oleh ahli jabatan ini.  Parameter ini berkuat kuasa apabila **outer_dept** ditetapkan kepada **true**.  **Nota**  Jumlah keseluruhan senarai ini ditambah senarai outer_permit_users tidak boleh melebihi 50. |
| outer_dept_only_self | Boolean | Tidak | true | Sama ada ahli jabatan ini hanya boleh melihat kenalan bagi jabatan sendiri dan sub-jabatan:   - **true**: hanya boleh melihat kenalan bagi jabatan sendiri dan sub-jabatan. - **false**: tidak boleh melihat semua kenalan, dan hanya boleh melihat diri sendiri dalam kenalan.   Parameter ini berkuat kuasa apabila **outer_dept** ditetapkan kepada **true**.  Jika tiada nilai diberikan, tetapan semasa kekal tidak berubah. |
| language | String | Tidak | zh_CN | Bahasa kenalan:   - **zh_CN**: Bahasa Cina. - **en_US**: Bahasa Inggeris. |
| auto_add_user | Boolean | Tidak | false | Selepas sembang jabatan dicipta, sama ada ahli baharu yang menyertai jabatan tersebut secara automatik ditambah ke dalam sembang:   - **true**: sertai sembang secara automatik. - **false**: jangan sertai sembang secara automatik.   Jika tiada nilai diberikan, tetapan semasa kekal tidak berubah. |
| auto_approve_apply | Boolean | Tidak | false | Sama ada hendak meluluskan permohonan untuk menyertai jabatan ini secara automatik:   - **true:** permohonan untuk menyertai jabatan ini diluluskan secara automatik. - **false:** permohonan untuk menyertai jabatan ini mesti diluluskan oleh admin yang mempunyai kebenaran berkaitan. |
| dept_manager_userid_list | String | Tidak | manager220 | Senarai ID pengguna bagi pengurus jabatan. Pisahkan berbilang ID pengguna dengan koma.  **Nota**  Pengurus jabatan mestilah ahli jabatan semasa. Jika tidak, API akan mengembalikan ralat **userId does not exist**. |
| group_contain_sub_dept | Boolean | Tidak | true | Sama ada sembang jabatan merangkumi sub-jabatan:   - **true**: rangkumi. - **false**: jangan rangkumi.   Jika tiada nilai diberikan, tetapan semasa kekal tidak berubah. |
| group_contain_outer_dept | Boolean | Tidak | true | Sama ada sembang jabatan merangkumi jabatan sumber luar (outsourced):   - **true**: rangkumi. - **false**: jangan rangkumi.   Jika tiada nilai diberikan, tetapan semasa kekal tidak berubah.  **Nota**  Jabatan sumber luar hanya boleh melihat jabatannya sendiri, dan tidak boleh melihat jabatan lain atau orang lain. |
| group_contain_hidden_dept | Boolean | Tidak | true | Sama ada sembang jabatan merangkumi jabatan tersembunyi:   - **true**: rangkumi. - **false**: jangan rangkumi.   Jika tiada nilai diberikan, tetapan semasa kekal tidak berubah. |
| org_dept_owner | String | Tidak | 100 | ID pengguna bagi pemilik sembang organisasi.  **Nota**  Pemilik kumpulan mestilah ahli jabatan semasa. |
| force_update_fields | String | Tidak | dept_manager_userid_list | Medan yang perlu dikemas kini secara paksa. Ini menyokong pengosongan medan yang ditentukan. Pisahkan berbilang medan dengan koma. Medan yang disokong pada masa ini ialah: `dept_manager_userid_list`. |
| code | String | Tidak | 10000 | Kod jabatan. Panjang maksimum ialah 30 aksara.  **Nota**  Medan ini hanya boleh ditetapkan melalui API ini. |

### Contoh permintaan

```curl
curl -X POST "https://api.dingtalk.io/topapi/v2/department/update" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=c6391xxxxb574' \
-d 'dept_id=100' \
-d 'parent_id=2' \
-d 'hide_dept=true' \
-d 'user_permits=100%2C200'
-d 'dept_permits=3%2C4%2C5' \
-d 'language=zh_CN' \
-d 'code=10000'
```

Java

```text
DingTalkClient client = new DefaultDingTalkClient("https://api.dingtalk.io/topapi/v2/department/update");
OapiV2DepartmentUpdateRequest req = new OapiV2DepartmentUpdateRequest();
req.setDeptId(100L);
req.setParentId(2L);
req.setOuterDept(true);
req.setHideDept(true);
req.setCreateDeptGroup(true);
req.setOrder(10L);
req.setName("HR");
req.setSourceIdentifier("HR Department");
req.setDeptPermits("123,456");
req.setUserPermits("user123,manager222");
req.setOuterPermitUsers("user100,user200");
req.setOuterPermitDepts("123,456");
req.setOuterDeptOnlySelf(true);
req.setLanguage("zh_CN");
req.setAutoAddUser(false);
req.setDeptManagerUseridList("manager200");
req.setGroupContainSubDept(true);
req.setGroupContainOuterDept(true);
req.setGroupContainHiddenDept(true);
req.setOrgDeptOwner("100");
OapiV2DepartmentUpdateResponse rsp = client.execute(req, access_token);
System.out.println(rsp.getBody());
```

## Respons

### Isi respons

| Nama | Jenis | Contoh | Penerangan |
| --- | --- | --- | --- |
| errcode | Number | 0 | Kod pulangan. |
| errmsg | String | ok | Penerangan bagi kod pulangan. |
| request_id | String | 6iq4zcul5zjp | ID permintaan. |

### Contoh isi respons

```json
{
 "errcode":0,
 "errmsg":"ok",
 "request_id": "6iq4zcul5zjp"
}
```

### Kod ralat

Jika ralat dikembalikan semasa anda memanggil API ini, rujuk dokumentasi [Kod ralat global](/open/development/server-api-error-codes-1) untuk mencari penyelesaian berdasarkan mesej ralat.

| Kod ralat (errcode) | Mesej ralat (errmsg) | Penyelesaian |
| --- | --- | --- |
| 43007 | Kebenaran tidak mencukupi | Sahkan sama ada access_token mempunyai kebenaran yang diperlukan untuk operasi ini. |
| 40009 | ID jabatan tidak sah | Sahkan sama ada dept_id adalah betul. |
| 60018 | Jabatan root tidak boleh dikemas kini | Gunakan dept_id yang lain. |
| 60003 | Jabatan tidak ditemui | Sahkan sama ada dept_id adalah betul. |
| 60001 | Nama jabatan tidak sah | Sahkan sama ada nama jabatan adalah betul. |
| 40011 | Order tidak sah | Sahkan sama ada nilai order adalah sah. |
| 60004 | Jabatan induk tidak wujud | Sahkan sama ada parent_id adalah betul. |
| 60010 | Terdapat gelung dalam ID jabatan | Tetapkan semula ID jabatan. |
| 60109 | Senarai ID boleh lihat tidak sah | Sahkan sama ada senarai boleh lihat adalah sah. |
| 40031 | Senarai userId tidak sah | Sahkan sama ada userId adalah betul. |
| 40093 | Pemilik sembang organisasi tidak sah | Sahkan sama ada ID pengguna bagi pemilik sembang organisasi adalah betul. |
| 60510 | Gagal menetapkan kebenaran jabatan | Sahkan sama ada parameter adalah sah. |
| -1 | Sistem sibuk | Cuba lagi kemudian. |
