title: "Cari sel dalam Helaian Kerja"
description: "Panggil API ini untuk mencari sel seterusnya dalam Helaian Kerja DingTalk Spreadsheet yang sepadan dengan string dan syarat yang diberikan, bermula selepas sudut kiri atas rangeAddress dan secara pilihan bersilang dengan findOptions.scope."
---

Cari sel seterusnya yang sepadan dengan string yang diberikan berdasarkan syarat yang ditetapkan. Skop carian meliputi keseluruhan Helaian Kerja bermula selepas sel kiri atas bagi julat yang ditetapkan (iaitu, rangeAddress). Jika parameter `findOptions.scope` ditetapkan, skop carian akan disilangkan lagi dengannya.

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/doc/workbooks/{workbookId}/sheets/{sheetId}/ranges/{rangeAddress}/findNext` |
| Kaedah HTTP | POST |
| Jenis aplikasi disokong | appType-Aplikasi dalaman |
| Kebenaran diperlukan | permission-Document.Workbook.Read-Kebenaran baca DingTalk Spreadsheet |

### Pengepala permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses yang digunakan untuk memanggil API ini. Panggil API [Dapatkan access token aplikasi dalaman](/ms/open/development/obtain-the-access-token-of-an-internal-app) untuk mendapatkannya. |

### Parameter laluan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| workbookId | String | Ya | ID fail Spreadsheet. Hantar `nodeId` (dentryUuid) sebagai `workbookId` Spreadsheet. Panggil API [Dapatkan nod](/ms/open/development/get-knowledge-base-acquisition-node) atau [Cipta dokumen Knowledge Base](/ms/open/development/create-team-space-document) untuk mendapatkannya. |
| sheetId | String | Ya | ID atau tajuk Helaian Kerja. Panggil API [Dapatkan semua Helaian Kerja](/ms/open/development/obtain-all-worksheets) untuk mendapatkan ID, atau hantar tajuk Helaian Kerja. |
| rangeAddress | String | Ya | Kedudukan permulaan carian. Carian bermula selepas sel kiri atas julat ini (sel kiri atas itu sendiri tidak termasuk). |

### Parameter kueri

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| operatorId | String | Ya | unionId bagi operator. |

### Isi permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| text | String | Ya | Teks yang hendak dicari. |
| findOptions | Object | Tidak | Pilihan carian. |
| matchEntireCell | Boolean | Tidak | Sama ada hendak memadankan keseluruhan sel:   - **true**: Ya - **false**: Tidak |
| matchCase | Boolean | Tidak | Sama ada hendak memadankan huruf besar/kecil (case):   - **true**: Ya - **false**: Tidak |
| useRegExp | Boolean | Tidak | Sama ada parameter text merupakan regular expression:   - **true**: Ya - **false**: Tidak |
| matchFormulaText | Boolean | Tidak | Sama ada hendak mencari di dalam formula:   - **true**: Ya - **false**: Tidak |
| scope | String | Tidak | Skop carian. Nyatakan alamat Range dalam notasi A1. |
| includeHidden | Boolean | Tidak | Sama ada hendak menyertakan sel tersembunyi, iaitu sel yang tidak kelihatan disebabkan oleh baris atau lajur tersembunyi, penapis (filter), kumpulan (group), dan ciri-ciri lain yang serupa. Sel yang pengguna tiada kebenaran untuk melihatnya tidak disertakan.   - **true**: Ya - **false**: Tidak |
