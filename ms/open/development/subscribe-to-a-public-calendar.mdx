Panggil API ini untuk melanggan kalendar awam.

## Penerangan panggilan API

Sebelum memanggil API ini, pastikan pengguna mempunyai kebenaran langganan untuk kalendar tersebut.

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/calendar/users/{userId}/calendars/{calendarId}/subscribe` |
| Kaedah HTTP | POST |
| Jenis aplikasi disokong | appType-Aplikasi dalaman　appType-Aplikasi perusahaan pihak ketiga　appType-Aplikasi peribadi pihak ketiga |
| Kebenaran diperlukan | permission-Calendar.Calendar.Write-Kebenaran tulis untuk aplikasi Kalendar |

### Header permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Dapatkan seperti berikut:   - Untuk aplikasi dalaman, panggil API [Dapatkan access token aplikasi dalaman](/ms/open/development/obtain-the-access-token-of-an-internal-app#). - Untuk aplikasi perusahaan pihak ketiga, panggil API [Dapatkan access token perusahaan yang diberi kuasa untuk aplikasi pihak ketiga](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#). - Untuk aplikasi peribadi pihak ketiga, panggil API [Dapatkan token pengguna](/ms/open/development/obtain-user-token#). |

### Parameter laluan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| userId | String | Ya | unionId bagi pelanggan.   - Untuk aplikasi dalaman dan aplikasi perusahaan pihak ketiga, panggil API [Semak butiran pengguna](/ms/open/development/query-user-details#) untuk mendapatkan nilai parameter unionid. - Untuk aplikasi peribadi pihak ketiga, panggil API [Dapatkan profil Kenalan pengguna](/ms/open/development/dingtalk-retrieve-user-information#) untuk mendapatkan nilai parameter unionId. |
| calendarId | String | Ya | ID kalendar. Buat masa ini, tindakan langganan hanya menyokong kalendar berjenis **subscribed**.    Pencipta kalendar yang dilanggan atau pengguna yang telah melanggan kalendar tersebut boleh mendapatkannya melalui API [Semak kalendar](/ms/open/development/query-a-calendar#). |

### Kod ralat

Jika ralat berlaku semasa memanggil API ini, rujuk dokumen [Kod ralat global](/ms/open/development/server-api-error-codes-1) untuk mencari penyelesaian berdasarkan mesej ralat.

| HttpCode | Kod ralat | Mesej ralat | Penerangan |
| --- | --- | --- | --- |
| 400 | permissionDenied | Pengguna tidak berada dalam skop langganan | Pengguna tidak berada dalam skop langganan |
| 400 | invalidParameter | forwardErrorMessage | Parameter tidak sah |
| 400 | invalidParameter | calendarId tidak boleh dibiarkan kosong | calendarId tidak boleh kosong |
| 400 | invalidParameter | Jenis kalendar tidak sah | Jenis kalendar tidak sah |
| 400 | exceedSubscribeLimit | Melebihi had langganan | Kalendar yang dilanggan melebihi had maksimum |
