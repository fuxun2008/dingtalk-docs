Beri kebenaran medan tertentu bagi Akaun Syarikat organisasi semasa supaya dapat dilihat oleh organisasi lain selepas akaun tersebut menyertai organisasi tersebut.

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/v1.0/contact/orgAccounts/mobiles/visibleInOtherOrg |
| Kaedah HTTP | PUT |
| Jenis aplikasi disokong | appType-Aplikasi dalaman |
| Kebenaran diperlukan | permission-Contact.OrgAccount.VisiblityInOtherOrg-Kebenaran keterlihatan data untuk Akaun Syarikat selepas menyertai organisasi lain |

### Pengepala permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Dapatkan dengan memanggil API [Dapatkan access token bagi aplikasi dalaman](/open/development/obtain-the-access-token-of-an-internal-app#). |

### Isi permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| toCorpIds | Array of String | Ya | Senarai ID organisasi (corpId) bagi organisasi yang diberi kebenaran.  Senarai corpId organisasi yang diberi kebenaran dan userId pemanggil API tidak boleh kosong. Parameter tidak sah akan menyebabkan panggilan API gagal. |
| optUserId | String | Ya | userId pemanggil API semasa.  Digunakan untuk audit data. Anda mesti memberikan userId pekerja yang sah daripada organisasi semasa; jika tidak, panggilan API akan gagal. |
| fields | Array of String | Tidak | Medan yang diberi kebenaran:  Jika fields kosong atau merupakan koleksi kosong, hanya mobile yang diberi kebenaran (untuk keserasian ke belakang).   - **mobile**: Nombor telefon bimbit bagi Akaun Syarikat. - **status**: Status penyahaktifan Akaun Syarikat. |
