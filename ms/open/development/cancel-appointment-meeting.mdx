Batalkan mesyuarat yang ditempah berdasarkan ID-nya.

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/v1.0/conference/scheduleConferences/cancel |
| Kaedah HTTP | POST |
| Jenis aplikasi disokong | appType-Internal app　appType-Third-party enterprise app |
| Kebenaran diperlukan | permission-VideoConference.Conference.Write-Video Meeting information management permission |

### Pengepala permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Dapatkan seperti berikut:   - Untuk aplikasi dalaman, panggil API [Dapatkan access token aplikasi dalaman](/open/development/obtain-the-access-token-of-an-internal-app#). - Untuk aplikasi perusahaan pihak ketiga, panggil API [Dapatkan access token organisasi yang dibenarkan untuk aplikasi pihak ketiga](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#). |

### Isi permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| scheduleConferenceId | String | Ya | ID mesyuarat yang ditempah. Dapatkan daripada medan `scheduleConferenceId` yang dikembalikan oleh API [Cipta mesyuarat tempahan](/open/development/create-appointment-meeting#). |
| creatorUnionId | String | Ya | unionId bagi pencipta mesyuarat yang ditempah. |

### Contoh permintaan

```http
POST /v1.0/conference/scheduleConferences/cancel HTTP/1.1
Host:api.dingtalk.io
x-acs-dingtalk-access-token:xxxxx
Content-Type:application/json

{
  "scheduleConferenceId" : "2a489xxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx",
  "creatorUnionId" : "qzR1iSMDvzR9iP7Pxxxxxxxxxxxx"
}
```
