---
title: "Dapatkan senarai tag kenalan luaran"
description: "Ketahui cara memanggil API DingTalk untuk mendapatkan senarai tag kenalan luaran organisasi, seperti tag pelanggan, bagi mengklasifikasikan dan menguruskan kenalan luaran dengan lebih tersusun."
---

Panggil API ini untuk mendapatkan tag kenalan luaran dalam organisasi Anda. Gunakan API ini untuk mendapatkan senarai tag kenalan luaran. Sebagai contoh, jika kenalan luaran ialah pelanggan syarikat, tagnya mungkin "Pelanggan".

## Permintaan

| **Maklumat asas** | |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/topapi/extcontact/listlabelgroups |
| Kaedah HTTP | POST |
| Jenis aplikasi disokong | appType-Aplikasi dalaman appType-Aplikasi perusahaan pihak ketiga |
| Kebenaran diperlukan | permission-qyapi_ext_read-Kebenaran baca untuk kenalan luaran organisasi |

### Parameter pertanyaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | bE74xxxx | Kelayakan aplikasi yang digunakan untuk memanggil API ini.   - Untuk aplikasi dalaman, dapatkan melalui API untuk mendapatkan [access_token aplikasi dalaman](/ms/open/development/obtain-orgapp-token). - Untuk aplikasi perusahaan pihak ketiga, dapatkan melalui API untuk mendapatkan access_token perusahaan pihak ketiga. |

### Isi permintaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| size | Number | Tidak | 20 | Menyokong penomboran halaman. Hanya berkuat kuasa apabila ditetapkan bersama parameter offset. Parameter ini menunjukkan saiz halaman, dengan maksimum 100. |
| offset | Number | Tidak | 0 | Menyokong penomboran halaman. Hanya berkuat kuasa apabila ditetapkan bersama parameter size. Parameter ini menunjukkan offset, bermula daripada 0. |

### Contoh permintaan

```curl
curl -X POST "https://api.dingtalk.io/topapi/extcontact/listlabelgroups" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=e6eaxxxxa401' \
-d 'offset=0' \
-d 'size=20'
```

Java

```text
DingTalkClient client = new DefaultDingTalkClient("https://api.dingtalk.io/topapi/extcontact/listlabelgroups");
OapiExtcontactListlabelgroupsRequest req = new OapiExtcontactListlabelgroupsRequest();
req.setSize(20L);
req.setOffset(0L);
OapiExtcontactListlabelgroupsResponse rsp = client.execute(req, access_token);
System.out.println(rsp.getBody());
```

Python

```python
import dingtalk.api

req=dingtalk.api.OapiExtcontactListlabelgroupsRequest("https://api.dingtalk.io/topapi/extcontact/listlabelgroups")

req.size=20
req.offset=0
try:
  resp= req.getResponse(access_token)
  print(resp)

  print(e)
```

```php

```


## Respons

### Isi respons

| Nama | Jenis | Contoh | Penerangan |
| --- | --- | --- | --- |
| results | OpenLabelGroup[] |  | Hasil pertanyaan. |
| name | String | Jenis | Nama kumpulan tag. |
| color | Number | -15220075 | Warna kumpulan tag. |
| labels | OpenLabel[] |  | Senarai tag. |
| name | String | Pelanggan | Nama tag. |
| id | Number | 1026002 | ID tag. |
| errcode | Number | 0 | Kod pemulangan. |
| request_id | String | 8n3mksu5hqzy | ID permintaan. |

### Kod ralat

Jika ralat dikembalikan semasa anda memanggil API ini, cari penyelesaiannya dalam dokumen [kod ralat global](/ms/open/development/server-api-error-codes-1) berdasarkan mesej ralat.

| Kod ralat (errcode) | Mesej ralat (errmsg) | Penyelesaian |
| --- | --- | --- |
| 33009 | Invalid tokenGrantType | Semak sama ada access_token betul. |
| 400043 | Invalid orgId | Semak sama ada access_token betul. |
| 41101 | Invalid size | Semak sama ada saiz halaman sah. |
| 40068 | Invalid offset | Laraskan offset. |
| -1 | System busy | Cuba lagi kemudian. |
