Panggil API ini untuk mengemas kini maklumat kalendar langganan tunggal.

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/calendar/users/{userId}/subscribedCalendars/{calendarId}` |
| Kaedah HTTP | PUT |
| Jenis aplikasi disokong | appType-Aplikasi dalaman　appType-Aplikasi perusahaan pihak ketiga　appType-Aplikasi peribadi pihak ketiga |
| Kebenaran diperlukan | permission-Calendar.Calendar.Write-Kebenaran Write untuk aplikasi Calendar |

### Header permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Dapatkan seperti berikut:   - Untuk aplikasi dalaman, panggil [Dapatkan access token aplikasi dalaman](/open/development/obtain-the-access-token-of-an-internal-app#). - Untuk aplikasi perusahaan pihak ketiga, panggil [Dapatkan access token organisasi yang diberi kuasa untuk aplikasi pihak ketiga](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#). - Untuk aplikasi peribadi pihak ketiga, panggil [Dapatkan user token](/open/development/obtain-user-token#). |

### Parameter laluan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| calendarId | String | Ya | ID kalendar langganan. Panggil [Cipta kalendar langganan](/open/development/create-subscription-calendar#) untuk mendapatkan nilai parameter calendarId. |
| userId | String | Ya | unionId pencipta kalendar atau editor bersama.   - Untuk aplikasi dalaman dan aplikasi perusahaan pihak ketiga, panggil [Tanya butiran pengguna](/open/development/query-user-details#) untuk mendapatkan nilai parameter unionid. - Untuk aplikasi peribadi pihak ketiga, panggil [Dapatkan profil pengguna Contacts](/open/development/dingtalk-retrieve-user-information#) untuk mendapatkan nilai parameter unionId. |

### Isi permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| name | String | Tidak | Tajuk kalendar langganan. |
| description | String | Tidak | Penerangan kalendar langganan. |
| managers | Array of String | Tidak | Senarai unionId editor bersama kalendar.   - Untuk aplikasi dalaman dan aplikasi perusahaan pihak ketiga, panggil [Tanya butiran pengguna](/open/development/query-user-details#) untuk mendapatkan nilai parameter unionid. - Untuk aplikasi peribadi pihak ketiga, panggil [Dapatkan profil pengguna Contacts](/open/development/dingtalk-retrieve-user-information#) untuk mendapatkan nilai parameter unionId. |
| subscribeScope | Object | Tidak | Skop langganan kalendar. |
| unionIds | Array of String | Tidak | unionId pengguna yang boleh melanggan kalendar ini.   - Untuk aplikasi dalaman dan aplikasi perusahaan pihak ketiga, panggil [Tanya butiran pengguna](/open/development/query-user-details#) untuk mendapatkan nilai parameter unionid. - Untuk aplikasi peribadi pihak ketiga, panggil [Dapatkan profil pengguna Contacts](/open/development/dingtalk-retrieve-user-information#) untuk mendapatkan nilai parameter unionId. |
| openConversationIds | Array of String | Tidak | Senarai OpenConversationId kumpulan yang boleh melanggan kalendar ini.   - Untuk aplikasi dalaman, panggil [Dapatkan OpenConversationId sembang kumpulan](/open/development/obtain-group-openconversationid#) untuk mendapatkan nilai parameter openConversationId. - Untuk aplikasi perusahaan pihak ketiga, panggil [Cipta kumpulan](https://open.dingtalk.com/document/development/create-a-scene-group-v2#) untuk mendapatkan nilai parameter open_conversation_id.        - Anda mesti menghantar OpenConversationId kumpulan yang menjadi milik pencipta peristiwa langganan. - Untuk aplikasi peribadi pihak ketiga, parameter ini tidak diperlukan. |
| corpIds | Array of String | Tidak | Senarai corpId organisasi yang boleh melanggan kalendar ini. Log masuk ke [DingTalk Developer Console](https://open-dev.dingtalk.io/#/) dan lihat ID organisasi anda pada halaman Laman Utama.      Anda mesti menghantar corpId organisasi yang menjadi milik pencipta peristiwa langganan. |
