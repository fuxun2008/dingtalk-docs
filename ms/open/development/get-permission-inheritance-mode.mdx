Panggil API ini untuk mendapatkan mod pewarisan kebenaran berdasarkan UUID fail dan unionId pengendali.

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| HTTP URL | `https://api.dingtalk.io/v2.0/storage/spaces/dentries/{dentryUuid}/permissions/inheritances` |
| Kaedah HTTP | GET |
| Jenis aplikasi yang disokong | appType-Aplikasi dalaman |
| Kebenaran | permission-Storage.Permission.Read-Kebenaran baca untuk maklumat kebenaran storan organisasi |

### Pengepala permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses yang digunakan untuk memanggil API ini. Untuk mendapatkannya, panggil API [Dapatkan access token bagi aplikasi dalaman](/ms/open/development/obtain-the-access-token-of-an-internal-app). |

### Parameter laluan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| dentryUuid | String | Ya | UUID fail. Untuk mendapatkannya, panggil API [Carian Fail](/ms/open/development/search-for-files) atau [Dapatkan maklumat dentryUuid](/ms/open/development/api-getuuidbydentryid) dan ambil nilai medan `dentryUuid` daripada respons. |

### Parameter pertanyaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| unionId | String | Ya | unionId pengguna. Untuk mendapatkannya, panggil API [Semak maklumat terperinci pengguna](/ms/open/development/query-user-details) dan ambil nilai parameter unionid. |

### Contoh permintaan

```http
GET /v2.0/storage/spaces/dentries/EpGxxxxR35y/permissions/inheritances?unionId=tXguN3xxxxAiEiE HTTP/1.1
Host:api.dingtalk.io
```

## Respons

### Isi respons

| Nama | Jenis | Penerangan |
| --- | --- | --- |
| inheritance | String | Mod pewarisan kebenaran. Nilai enum:   - **PASS_ON**: Teruskan. Fail (folder) semasa mewarisi kebenaran daripada semua nod induk dan menggabungkannya dengan kebenaran yang ditetapkan pada fail (folder) semasa. Bagi pengguna yang sama, tahap kebenaran tertinggi digunakan. - **BREAK**: Putus. Pewarisan kebenaran diputuskan pada nod semasa.        - Break tidak disokong untuk OWNER dan MANAGER. - Ini ialah mod pewarisan kebenaran lalai. |

### Contoh isi respons

```text
HTTP/1.1 200 OK
Content-Type:application/json

{
  "inheritance" : "PASS_ON"
}
```
