Dokumen ini menerangkan cara memanggil API berkaitan acara untuk mengurus peserta acara. Pertama, cipta aplikasi dalaman. Kemudian, gunakan API yang disediakan untuk acara bagi mencipta acara, menambah peserta acara, mendapatkan semula peserta acara, menetapkan status respons jemputan, dan mengeluarkan peserta acara.

## Hasil yang dijangka

- Selepas acara berjaya dicipta, hasilnya dipaparkan seperti yang ditunjukkan di bawah.

- Antara muka untuk menambah peserta acara dipaparkan seperti yang ditunjukkan di bawah.

- Status respons acara dipaparkan seperti yang ditunjukkan di bawah.

## Gambaran keseluruhan aliran integrasi

Dokumen ini menunjukkan cara mencipta aplikasi dalaman dan kemudian menggunakan API yang disediakan untuk acara bagi mengurus peserta acara.

Prasyarat: Lengkapkan aliran [Penciptaan dan konfigurasi aplikasi](/ms/open/dingstart/create-application).

Langkah 1: Dapatkan semula kelayakan Aplikasi, termasuk client ID dan Client Secret.

Langkah 2: Mohon kebenaran API untuk API berkaitan acara.

Langkah 3: Dapatkan kredensial akses Aplikasi dengan mengikuti [Dapatkan access token aplikasi dalaman](/ms/open/development/obtain-the-access-token-of-an-internal-app). Access token digunakan untuk mengesahkan identiti pemanggil semasa memanggil API.

Langkah 4: Panggil API berkaitan acara di bahagian pelayan.

1. Panggil Server API [Acara Baharu](/ms/open/development/create-schedule) untuk mencipta acara dan mendapatkan semula `id` acara.
2. Berdasarkan `id` acara, panggil Server API [Tambah peserta acara](/ms/open/development/add-schedule-participant) untuk menambah peserta acara.
3. Berdasarkan `id` acara, panggil Server API [Dapatkan peserta acara](/ms/open/development/get-the-participants-of-a-schedule) untuk mendapatkan semula maklumat peserta.
4. Berdasarkan `id` acara, panggil Server API [Tetapkan status respons jemputan acara](/ms/open/development/configure-response-status) untuk menetapkan status respons jemputan peserta.
5. Berdasarkan `id` acara, panggil Server API [Padam Peserta Acara](/ms/open/development/delete-schedule-participant) untuk mengeluarkan peserta acara.

## Prasyarat

Lengkapkan aliran [Penciptaan dan konfigurasi aplikasi](/ms/open/dingstart/create-application).

## Langkah 1: Dapatkan semula kelayakan Aplikasi

1. Pilih aplikasi sasaran untuk membuka halaman butirannya, dan klik **Maklumat asas** > **Kelayakan dan maklumat asas**.
2. Dapatkan semula client ID dan Client Secret.

## Langkah 2: Tambah kebenaran API

Klik **Konfigurasi pembangunan** > **Urus kebenaran**. Dalam kotak carian kebenaran, masukkan `Calendar.Event.Write` dan `Calendar.Event.Read` masing-masing, dan mohon setiap kebenaran.

## Langkah 3: Dapatkan access token

<Warning>
Untuk perbezaan antara Server API, lihat API lama berbanding API baharu. Semua API berikut menggunakan Server API. Untuk muat turun SDK, lihat Muat turun SDK bahagian pelayan.
</Warning>

Gunakan client ID dan Client Secret daripada Langkah 1 untuk mendapatkan access_token bagi aplikasi dalaman.

    }
