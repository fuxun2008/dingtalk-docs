---

Panggil API ini untuk mencipta ruang baharu dalam cloud drive organisasi Anda. Dalam ruang tersebut, anda boleh mencipta folder, memuat naik fail, dan melaksanakan tindakan lain.

## Penerangan panggilan API

### Tentang ruang storan

- Ruang storan adalah sebahagian daripada cloud drive organisasi Anda, tetapi ruang yang dicipta melalui API ini tidak dipaparkan pada cloud drive di Bahagian klien.
- Ruang storan menggunakan kapasiti cloud drive organisasi Anda.

### Jenis ruang storan

- Ruang pengguna (USER): Fail dalam ruang ini hanya boleh diberikan kebenaran kekal, dan pemberi kebenaran mesti memiliki kebenaran pengurusan untuk memberikan akses.
- Ruang aplikasi (APP): Fail dalam ruang ini hanya boleh diberikan kebenaran sementara, dan pemberi kebenaran tidak perlu memiliki kebenaran pengurusan.

| 400 | paramError.sceneId | %s | Ralat parameter - sceneId. |
