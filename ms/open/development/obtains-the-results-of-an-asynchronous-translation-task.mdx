Panggil API ini untuk menyemak hasil kerja terjemahan yang telah dihantar.

## Penerangan panggilan API

### Gambaran keseluruhan API

1. Bina dokumen yang hendak diterjemahkan, seperti contoh berikut.

### Nota

   Hanya fail .xlsx, .xls, .csv, dan .txt disokong.

2. Panggil API [Muat naik fail dalam satu langkah](https://open.dingtalk.com/document/isvapp/single-step-file-upload) untuk mendapatkan `media_id`.
3. Panggil API [Terjemah ID Kenalan secara asinkron](/ms/open/development/asynchronous-address-book-file-content-translation) untuk mendapatkan ID kerja terjemahan.

### Nota

   Selepas anda memanggil API Terjemah ID Kenalan secara asinkron, jika fail berjaya diterjemahkan, satu pemberitahuan callback kerja asinkron akan dicetuskan.
4. Panggil API ini untuk mendapatkan pautan muat turun fail yang telah diterjemahkan.

### Nota

   Adalah disyorkan pautan muat turun fail yang dikembalikan dirujuk menggunakan `<a> tag`. Atribut `download` tidak boleh dinyatakan (disebabkan isu keserasian pelayar).
5. Pengguna memuat turun fail tersebut, kandungannya seperti contoh berikut.

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/v1.0/contact/files/translateResults |
| Kaedah HTTP | GET |
| Jenis aplikasi disokong | appType-Aplikasi perusahaan pihak ketiga |
| Kebenaran | permission-qyapi_get_member-Kebenaran baca maklumat pengguna |

### Pengepala permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Dapatkan dengan memanggil API [Dapatkan access token organisasi yang diberi kebenaran kepada aplikasi pihak ketiga](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#). |

### Parameter query

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| jobId | String | Ya | ID kerja terjemahan asinkron. Dapatkan nilai parameter `jobId` dengan memanggil API [Terjemah ID Kenalan secara asinkron](/ms/open/development/asynchronous-address-book-file-content-translation#). |

| Nama | Jenis | Penerangan |
| --- | --- | --- |
| status | String | Hasil kerja terjemahan. Nilai yang sah:   - **0**: Kerja sedang dalam proses. - **1**: Kerja telah berjaya diproses. - **2**: Pemprosesan kerja gagal. |
| url | String | URL kandungan fail yang telah diterjemahkan.    URL ini mesti dibuka di pihak pengguna selepas Kebenaran OAuth 2.0. |
