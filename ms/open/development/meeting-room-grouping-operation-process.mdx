Dokumen ini menerangkan cara mencipta aplikasi dalaman dan menggunakan API yang disediakan oleh Bilik Mesyuarat Pintar untuk mencipta, mengemas kini, menanya, dan memadam kumpulan bilik mesyuarat.

## Hasil yang dijangka

Hasil kumpulan bilik mesyuarat ditunjukkan seperti berikut:

## Gambaran keseluruhan proses

Prasyarat: Selesaikan proses [Cipta dan konfigurasi aplikasi](/ms/open/dingstart/create-application).

Langkah 1: Dapatkan Kelayakan aplikasi, termasuk client ID dan Client Secret.

Langkah 2: Mohon kebenaran API untuk API Bilik Mesyuarat Pintar.

Langkah 3: Dapatkan kredensial akses aplikasi dengan mengikuti [Dapatkan access token aplikasi dalaman](/ms/open/development/obtain-the-access-token-of-an-internal-app). Semasa memanggil API, access token digunakan untuk mengesahkan identiti pemanggil.

Langkah 4: Panggil API bilik mesyuarat:

1. Panggil Server API [Cipta kumpulan bilik mesyuarat](/ms/open/development/create-meeting-room-groups) dan dapatkan medan `result` daripada Respons, iaitu ID kumpulan bilik mesyuarat.
2. Gunakan ID kumpulan bilik mesyuarat untuk memanggil Server API [Kemas kini kumpulan bilik mesyuarat](/ms/open/development/update-meeting-room-groups) bagi mengemas kini maklumat kumpulan bilik mesyuarat.
3. Panggil Server API [Tanya senarai kumpulan bilik mesyuarat](/ms/open/development/query-meeting-rooms-groups) untuk mendapatkan senarai kumpulan bilik mesyuarat.
4. Gunakan ID kumpulan bilik mesyuarat untuk memanggil Server API [Tanya kumpulan bilik mesyuarat](/ms/open/development/query-meeting-room-groups) bagi mendapatkan maklumat terperinci tentang satu kumpulan bilik mesyuarat.
5. Gunakan ID kumpulan bilik mesyuarat untuk memanggil Server API [Padam kumpulan bilik mesyuarat](/ms/open/development/delete-a-conference-room-group) bagi memadam kumpulan bilik mesyuarat.

## Prasyarat

Selesaikan proses [Cipta dan konfigurasi aplikasi](/ms/open/dingstart/create-application).

## Langkah 1: Dapatkan Kelayakan aplikasi

1. Pilih Aplikasi sasaran dan pergi ke halaman butiran Aplikasi. Klik **Maklumat Asas** > **Kelayakan dan Maklumat Asas**.
2. Dapatkan client ID dan Client Secret.

## Langkah 2: Tambah kebenaran API

Klik **Konfigurasi Pembangunan** > **Urus kebenaran**. Dalam kotak carian kebenaran, masukkan `VideoConference.Conference.Write` dan `VideoConference.Conference.Read` masing-masing, kemudian mohon kebenaran tersebut.

## Langkah 3: Dapatkan access token Aplikasi

<Warning>
Untuk perbezaan antara versi Server API, lihat perbandingan API lama berbanding API baharu. Semua API berikut menggunakan Server API. Untuk Muat turun SDK, lihat halaman Muat turun SDK Bahagian pelayan.
</Warning>

Gunakan client ID dan Client Secret yang diperoleh dalam Langkah 1 untuk mendapatkan access token Aplikasi dengan mengikuti [Dapatkan access token aplikasi dalaman](/ms/open/development/obtain-the-access-token-of-an-internal-app).

```java
 public void getAccessToken() throws Exception {
        Config config = new Config();
        config.protocol = "https";
        config.regionId = "central";
        com.aliyun.dingtalkoauth2_1_0.Client client = new com.aliyun.dingtalkoauth2_1_0.Client(config);
        GetAccessTokenRequest accessTokenRequest = new GetAccessTokenRequest()
                .setAppKey("din*********hgn")
                .setAppSecret("9G_O************mBkhgGIO");
        GetAccessTokenResponse accessToken = client.getAccessToken(accessTokenRequest);
        System.out.println(JSON.toJSONString(accessToken.getBody()));
    }
```
