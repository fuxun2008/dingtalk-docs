---

Panggil API ini untuk menambah atau mengubah suai tetapan yang menyekat pekerja, jabatan, atau peranan daripada melihat Kenalan.

## Penerangan panggilan API

Dalam Admin Console OA DingTalk, anda boleh menyekat ahli sesebuah jabatan daripada melihat Kenalan. API ini memperluaskan keupayaan tersebut. Ia boleh menyekat bukan sahaja ahli jabatan, tetapi juga pekerja individu dan peranan, daripada melihat Kenalan.

<Note>
Tetapan sekatan kebolehlihatan yang dikonfigurasikan melalui API ini disimpan secara berasingan daripada tetapan yang dikonfigurasikan dalam Admin Console OA. Kesan akhirnya adalah gabungan OR logik antara kedua-duanya. Sebagai contoh, jika jabatan yang sama ditetapkan kepada "hanya lihat diri sendiri" sama ada melalui API ini atau Admin Console OA, jabatan tersebut akan disekat untuk hanya melihat diri sendiri.
</Note>

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/v1.0/contact/restrictions/settings |
| Kaedah HTTP | PUT |
| Jenis aplikasi disokong | appType-Aplikasi dalaman |
| Kebenaran diperlukan | permission-Contact.Visibility.ReadWrite-Kebenaran untuk mengurus skop kebolehlihatan data Kenalan |

### Pengepala permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Dapatkan dengan memanggil API [Dapatkan Access Token aplikasi dalaman](/open/development/obtain-the-access-token-of-an-internal-app#). |

### Isi permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| id | Long | Tidak | ID tetapan.   - Jangan hantar parameter ini apabila menambah tetapan baharu. - Untuk mengubah suai tetapan sedia ada, nyatakan parameter ini. Dapatkan ID dengan memanggil API [Dapatkan senarai tetapan sekatan kebolehlihatan Kenalan](/open/development/gets-a-list-of-address-book-limit-visibility-settings#). |
| name | String | Tidak | Nama tetapan. |
| description | String | Tidak | Penerangan tetapan. |
| subjectUserIds | Array of String | Tidak | Senarai ID pengguna yang kebolehlihatan Kenalannya disekat. Dapatkan `userid` dengan memanggil API [Dapatkan senarai ID pengguna jabatan](/open/development/query-the-list-of-department-userids#).      Jumlah keseluruhan elemen merentasi `subjectUserIds`, `subjectDeptIds`, dan `subjectTagIds` tidak boleh melebihi 50. |
| subjectDeptIds | Array of Long | Tidak | Senarai ID jabatan yang kebolehlihatan Kenalannya disekat. Dapatkan `dept_id` dengan memanggil API [Dapatkan senarai jabatan](https://open.dingtalk.com/document/development/obtain-the-department-list-v2#).      Jumlah keseluruhan elemen merentasi `subjectUserIds`, `subjectDeptIds`, dan `subjectTagIds` tidak boleh melebihi 50. |
| subjectTagIds | Array of Long | Tidak | Senarai ID peranan yang kebolehlihatan Kenalannya disekat. Dapatkan ID peranan dengan memanggil API [Dapatkan senarai peranan](/open/development/obtains-a-list-of-enterprise-roles#).      Jumlah keseluruhan elemen merentasi `subjectUserIds`, `subjectDeptIds`, dan `subjectTagIds` tidak boleh melebihi 50. |
| type | String | Ya | Jenis sekatan. Nilai yang sah:   - **onlySelf**: Hanya boleh melihat diri sendiri. Tidak boleh melihat mana-mana jabatan atau pengguna lain. - **onlySelfDeptAndChild**: Hanya boleh melihat jabatan pengguna sendiri dan sub-jabatannya. Tidak boleh melihat mana-mana jabatan atau pengguna lain. - **excludeNode**: Nilai lalai. Hanya boleh melihat jabatan dan pengguna dalam Senarai Dibenarkan.       Senarai Dibenarkan berkuat kuasa hanya apabila parameter ini ditetapkan kepada `excludeNode`. |
| excludeUserIds | Array of String | Tidak | ID pengguna dalam Senarai Dibenarkan. Dapatkan `userid` dengan memanggil API [Dapatkan senarai ID pengguna jabatan](/open/development/query-the-list-of-department-userids#).       - Jumlah keseluruhan elemen merentasi `excludeUserIds`, `excludeDeptIds`, dan `excludeTagIds` tidak boleh melebihi 50. - Senarai Dibenarkan berkuat kuasa hanya apabila `type` ditetapkan kepada `excludeNode`. |
| excludeDeptIds | Array of Long | Tidak | ID jabatan dalam Senarai Dibenarkan. Dapatkan dengan memanggil API [Dapatkan senarai jabatan](https://open.dingtalk.com/document/development/obtain-the-department-list-v2#).       - Jumlah keseluruhan elemen merentasi `excludeUserIds`, `excludeDeptIds`, dan `excludeTagIds` tidak boleh melebihi 50. - Senarai Dibenarkan berkuat kuasa hanya apabila `type` ditetapkan kepada `excludeNode`. |
| excludeTagIds | Array of Long | Tidak | ID peranan dalam Senarai Dibenarkan. Dapatkan dengan memanggil API [Dapatkan senarai peranan](/open/development/obtains-a-list-of-enterprise-roles#).       - Jumlah keseluruhan elemen merentasi `excludeUserIds`, `excludeDeptIds`, dan `excludeTagIds` tidak boleh melebihi 50. - Senarai Dibenarkan berkuat kuasa hanya apabila `type` ditetapkan kepada `excludeNode`. |
| active | Boolean | Tidak | Sama ada tetapan ini berkuat kuasa.   - true: Berkuat kuasa. - false: Tidak berkuat kuasa. |
| restrictInUserProfile | Boolean | Tidak | Sama ada turut menyekat kebolehlihatan pada halaman Profil.   - true: Ya. - false: Tidak.       Apabila diaktifkan, mengetik Gambar Profil pekerja yang berada di luar skop kebolehlihatan dalam Klien DingTalk tidak akan memaparkan maklumat profil pengguna tersebut dalam Organisasi semasa. |
| restrictInSearch | Boolean | Tidak | Sama ada turut menyekat carian.   - true: Ya. - false: Tidak.       Apabila diaktifkan, mencari pekerja yang berada di luar skop kebolehlihatan dalam Klien DingTalk tidak akan memulangkan sebarang hasil. |

                if (!AlibabaCloud.TeaUtil.Common.Empty(err.Code) && !AlibabaCloud.TeaUtil.Common.Empty(err.Message))
                {
                    // err mengandungi atribut code dan message, yang membantu mengesan isu semasa pembangunan.
                }
            }
        }

    }
}
