---
title: "Remove permissions"
description: "Call this API to remove member permissions on Knowledge Base spaces, nodes, and Drive files by file uuid, operator unionId, and permission id."
---

Panggil API ini untuk mengalih keluar kebenaran pengguna daripada Knowledge Base, nod Knowledge Base, atau fail Drive, berdasarkan UUID fail, unionId pengendali, dan ID kebenaran.

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v2.0/storage/spaces/dentries/{dentryUuid}/permissions/remove` |
| Kaedah HTTP | POST |
| Jenis aplikasi disokong | appType-Aplikasi dalaman |
| Skop kebenaran | permission-Storage.Permission.Write-Kebenaran Tulis untuk maklumat kebenaran storan organisasi |

### Pengepala permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Untuk mendapatkan nilai ini, panggil API [Dapatkan access token aplikasi dalaman](/open/development/obtain-the-access-token-of-an-internal-app). |

### Parameter laluan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| dentryUuid | String | Ya | UUID fail. Untuk mendapatkan nilai ini, panggil API [Carian Fail](/open/development/search-for-files) atau API [Dapatkan dentryUuid](/open/development/api-getuuidbydentryid), dan baca medan `dentryUuid` daripada respons. |

### Parameter pertanyaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| unionId | String | Ya | unionId pengguna. |

### Isi permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| roleId | String | Ya | ID peranan. Nilai enum:   - **OWNER**: Pemilik. Termasuk skop kebenaran berikut:    - PermissionPrivilegeEnum.INFO   - PermissionPrivilegeEnum.LIST   - PermissionPrivilegeEnum.PREVIEW   - PermissionPrivilegeEnum.READ   - PermissionPrivilegeEnum.WRITE   - PermissionPrivilegeEnum.DOWNLOAD   - PermissionPrivilegeEnum.ADD   - PermissionPrivilegeEnum.DELETE   - PermissionPrivilegeEnum.MODIFY   - PermissionPrivilegeEnum.COPY   - PermissionPrivilegeEnum.RENAME   - PermissionPrivilegeEnum.READ_PERMISSION   - PermissionPrivilegeEnum.WRITE_PERMISSION   - PermissionPrivilegeEnum.ASSIGN - **MANAGER**: Pengurus. Termasuk skop kebenaran berikut:    - PermissionPrivilegeEnum.INFO   - PermissionPrivilegeEnum.LIST   - PermissionPrivilegeEnum.PREVIEW   - PermissionPrivilegeEnum.READ   - PermissionPrivilegeEnum.WRITE   - PermissionPrivilegeEnum.DOWNLOAD   - PermissionPrivilegeEnum.ADD   - PermissionPrivilegeEnum.DELETE   - PermissionPrivilegeEnum.MODIFY   - PermissionPrivilegeEnum.COPY   - PermissionPrivilegeEnum.RENAME   - PermissionPrivilegeEnum.READ_PERMISSION   - PermissionPrivilegeEnum.WRITE_PERMISSION - **EDITOR**: Editor. Termasuk skop kebenaran berikut:    - PermissionPrivilegeEnum.INFO   - PermissionPrivilegeEnum.LIST   - PermissionPrivilegeEnum.PREVIEW   - PermissionPrivilegeEnum.READ   - PermissionPrivilegeEnum.WRITE   - PermissionPrivilegeEnum.DOWNLOAD   - PermissionPrivilegeEnum.ADD - **DOWNLOADER**: Pemapar dengan kebenaran muat turun. Termasuk skop kebenaran berikut:    - PermissionPrivilegeEnum.INFO   - PermissionPrivilegeEnum.LIST   - PermissionPrivilegeEnum.PREVIEW   - PermissionPrivilegeEnum.READ   - PermissionPrivilegeEnum.DOWNLOAD - **READER**: Hanya paparan. Termasuk skop kebenaran berikut:    - PermissionPrivilegeEnum.INFO   - PermissionPrivilegeEnum.LIST   - PermissionPrivilegeEnum.PREVIEW |
| members | Array | Ya | Senarai ahli kebenaran. Sehingga 30 ahli disokong. |
| type | String | Ya | Jenis ahli kebenaran. Nilai enum:   - **ORG**: Organisasi - **DEPT**: Jabatan - **TAG**: Tag tersuai - **CONVERSATION**: Sembang - **USER**: Pengguna |
| id | String | Ya | ID ahli kebenaran:   - Apabila `type=ORG`, nilainya ialah ID organisasi. - Apabila `type=DEPT`, nilainya ialah ID jabatan. - Apabila `type=TAG`, nilainya ialah ID tag. - Apabila `type=CONVERSATION`, nilainya ialah ID sembang. - Apabila `type=USER`, nilainya ialah userId pekerja. |
| corpId | String | Tidak | Organisasi yang memiliki kebenaran ini.       - Jika ID organisasi diberikan, kebenaran akan dialih keluar secara automatik apabila ahli berkenaan meninggalkan organisasi tersebut. - Jika `memberType` ialah `dept`, ID organisasi diperlukan. |
