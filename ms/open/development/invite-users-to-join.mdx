---
title: "Menjemput pengguna menyertai mesyuarat"
description: "Panggil API ini untuk menjemput pengguna baharu menyertai mesyuarat yang sedang berlangsung di DingTalk; penerima jemputan akan menerima notifikasi untuk menyertai mesyuarat."
---

Semasa mesyuarat berlangsung, jemput pengguna baharu untuk menyertai mesyuarat. Selepas API ini dipanggil, pengguna yang dijemput akan menerima notifikasi untuk menyertai mesyuarat.

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/conference/videoConferences/{conferenceId}/users/invite` |
| Kaedah HTTP | POST |
| Jenis aplikasi disokong | appType-Internal app　appType-Third-party enterprise app |
| Kebenaran diperlukan | permission-VideoConference.Conference.Write-Video Meeting information management permission |

### Pengepala permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Dapatkan seperti berikut:   - Untuk aplikasi dalaman, panggil API [Dapatkan access token aplikasi dalaman](/ms/open/development/obtain-the-access-token-of-an-internal-app#). - Untuk aplikasi perusahaan pihak ketiga, panggil API [Dapatkan access token perusahaan yang diberi kuasa kepada aplikasi pihak ketiga](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#). |

### Parameter laluan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| conferenceId | String | Tidak | ID mesyuarat. Panggil API [Cipta mesyuarat video](/ms/open/development/create-a-video-conference#) untuk mendapatkan medan `conferenceId` daripada respons. |

### Isi permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| unionId | String | Tidak | unionId bagi pengendali operasi.  Jika medan ini tidak dinyatakan, nama penjemput tidak akan dapat dipaparkan dalam notifikasi panggilan. |
| inviteeList | Array | Tidak | Senarai penerima jemputan. |
| unionId | String | Tidak | unionId bagi pengguna yang dijemput. |
| nick | String | Ya | Nama penerima jemputan. |
| phoneInviteeList | Array | Tidak | Senarai penerima jemputan yang dikenal pasti melalui nombor telefon. |
| phoneNumber | String | Tidak | Nombor Telefon pengguna yang dijemput. |
| nick | String | Tidak | Nama penerima jemputan. |
