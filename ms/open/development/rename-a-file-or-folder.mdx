Panggil API ini untuk menamakan semula fail atau folder. Direktori root ruang storan tidak boleh dinamakan semula.

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/storage/spaces/{spaceId}/dentries/{dentryId}/rename` |
| Kaedah HTTP | POST |
| Jenis aplikasi disokong | appType-Aplikasi dalaman　appType-Aplikasi perusahaan pihak ketiga |
| Kebenaran diperlukan | permission-Storage.File.Write-Kebenaran menulis fail storan organisasi |

### Pengepala permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses yang digunakan untuk memanggil API ini. Dapatkan seperti berikut:   - Untuk aplikasi dalaman, panggil API [Dapatkan access token aplikasi dalaman](/open/development/obtain-the-access-token-of-an-internal-app). - Untuk aplikasi perusahaan pihak ketiga, panggil API [Dapatkan access token organisasi yang diberi kuasa untuk aplikasi pihak ketiga](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1). |

### Parameter laluan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| spaceId | String | Ya | ID ruang. Panggil API [Tambah ruang](/open/development/add-space) untuk mendapatkan nilai parameter `id`. |
| dentryId | String | Ya | ID fail atau folder. Panggil API [Dapatkan senarai fail atau folder](/open/development/get-a-list-of-files-or-folders) atau [Dapatkan spaceId dan dentryId melalui dentryUuid](/open/development/api-getdentryidbyuuid) untuk mendapatkan nilai parameter `id`.  Direktori root ruang storan tidak boleh dinamakan semula, jadi parameter ini tidak menyokong nilai 0. |

### Parameter pertanyaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| unionId | String | Ya | unionId operator. Panggil API [Tanya butiran pengguna](/open/development/query-user-details) untuk mendapatkan nilai parameter `unionid`. |

### Isi permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| newName | String | Ya | Nama baharu bagi fail atau folder. Peraturan penamaan:- Ruang di hadapan dan belakang akan dibuang secara automatik. - Tidak boleh mengandungi aksara khas, termasuk: tab, `*`, `"`, `<`, `>`, `|`. - Tidak boleh berakhir dengan `.`. |

### Contoh permintaan

```http
POST /v1.0/storage/spaces/854xxxxx/dentries/645xxxxx/rename?unionId=cHtUYxxxxx HTTP/1.1
Host:api.dingtalk.io

Content-Type:application/json

{
  "newName" : "Test"
}
```

## Respons

### Isi respons

| Nama | Jenis | Penerangan |
| --- | --- | --- |
| dentry | Object | Senarai maklumat fail atau folder. |
| id | String | ID fail atau folder. |
| spaceId | String | ID ruang yang menjadi milik fail atau folder tersebut. |
| parentId | String | ID direktori induk. Untuk direktori root, parameter ini bernilai 0. |
| type | String | Jenis:   - **FILE**: fail - **FOLDER**: folder |
| name | String | Nama selepas penamaan semula. |
| size | Long | Saiz fail, dalam byte.  Medan ini tidak dikembalikan untuk folder. |
| path | String | Laluan fail atau folder. |
| version | Long | Versi. |
| status | String | Status:   - **NORMAL**: normal - **DELETED**: dipadam - **EXPIRED**: telah tamat tempoh |
| extension | String | Sambungan fail.  Medan ini tidak dikembalikan untuk folder. |
| creatorId | String | unionId pencipta. |
| modifierId | String | unionId pengubah suai. |
| createTime | String | Masa dicipta, dalam format ISO 8601. Contoh: 2022-07-29T14:55Z. |
| modifiedTime | String | Masa pengubahsuaian, dalam format ISO 8601. Contoh: 2022-07-29T14:55Z. |
| properties | Object | Atribut. |
| readOnly | Boolean | Sama ada fail atau folder adalah baca sahaja:   - **true**: ya - **false**: tidak |
| appProperties | `Map<String, Array>` | Atribut khusus aplikasi. |
|  | Array | Senarai atribut. |
| name | String | Nama atribut. |
| value | String | Nilai atribut. |
| visibility | String | Keterlihatan atribut:   - **PUBLIC**: dapat dilihat oleh semua ruang - **PTIVATE**: hanya dapat dilihat oleh ruang semasa |
| uuid | String | Medan pengenal. |
| partitionType | String | Partition storan:   - **PUBLIC_OSS_PARTITION**: partition storan OSS awan awam - **MINI_OSS_PARTITION**: partition storan MiniOSS khusus |
| storageDriver | String | Jenis pemacu:   - **DINGTALK**: pemacu storan bersepadu DingTalk - **ALIDOC**: pemacu storan DingTalk Docs - **UNKNOWN**: pemacu tidak diketahui |
