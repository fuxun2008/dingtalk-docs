Panggil API ini untuk mencipta entri senarai sekat tempahan bilik.

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/v1.0/rooms/bookings/blacklist |
| Kaedah HTTP | POST |
| Jenis aplikasi disokong | appType-Aplikasi dalaman　appType-Aplikasi perusahaan pihak ketiga |
| Kebenaran diperlukan | permission-VideoConference.Conference.Write-Kebenaran pengurusan maklumat Mesyuarat Video |

### Pengepala permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses yang digunakan untuk memanggil API ini. Perolehnya seperti berikut:   - Untuk aplikasi dalaman, panggil API [Dapatkan access token aplikasi dalaman](/open/development/obtain-the-access-token-of-an-internal-app#). - Untuk aplikasi perusahaan pihak ketiga, panggil API [Dapatkan access token organisasi yang memberi kebenaran kepada aplikasi pihak ketiga](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#). |

### Isi permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| unionId | String | Ya | unionId pengendali. |
| blacklistUnionId | String | Ya | unionId pengguna yang disekat. |
| startTime | Long | Ya | Masa mula sekatan, sebagai cap masa UTC dalam milisaat. |
| endTime | Long | Tidak | Masa tamat sekatan, sebagai cap masa UTC dalam milisaat. Biarkan kosong untuk menyekat secara kekal. |
| memo | String | Tidak | Alias. |
