Panggil API ini untuk pra-kira tempoh kerja lebih masa, perjalanan perniagaan dan cuti seseorang pekerja berdasarkan penjadualan syif dalam sistem kehadiran.

## Penerangan panggilan API

Contohnya, seorang pekerja dijadualkan bekerja pada 2 November (masa mula 09:00, masa tamat 18:00) dan bercuti rehat pada 3 November.

Pekerja tersebut merancang untuk mengambil cuti dari 09:00:00 pada 2 November hingga 18:00:00 pada 3 November. Panggil API ini untuk mendapatkan jangkaan tempoh cuti dalam julat ini. Hasilnya hanya satu hari.

- Jika pekerja tidak berada dalam mana-mana kumpulan kehadiran atau tiada syif dijadualkan pada tarikh cuti, tempoh cuti dikira berdasarkan masa kehadiran lalai.
- Konfigurasikan masa kehadiran lalai di **DingTalk mudah alih > Workbench > Kehadiran > Tetapan > Lain-lain Tetapan > Kelulusan Cuti dan Kehadiran > Masa Kehadiran Lalai**. Contohnya:

  Seorang pekerja dijadualkan bekerja pada 2 November (masa mula 09:00, masa tamat 18:00) dan tiada syif dijadualkan pada 3 November. Syif lalai ialah 08:30–17:30. Pekerja tersebut merancang untuk mengambil cuti dari 09:00:00 pada 2 November hingga 18:00:00 pada 3 November. Panggil API ini untuk mendapatkan jangkaan tempoh cuti dalam julat ini. Hasilnya ialah 2 hari.

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/v1.0/attendance/approvals/durations/calculate |
| Kaedah HTTP | POST |
| Jenis aplikasi yang disokong | appType-Aplikasi dalaman　appType-Aplikasi perusahaan pihak ketiga |
| Kebenaran yang diperlukan | permission-qyapi_attendance_group_read-Kebenaran pertanyaan kumpulan kehadiran |

### Pengepala permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Dapatkannya seperti berikut:   - Aplikasi dalaman: panggil API [Dapatkan access token aplikasi dalaman](/ms/open/development/obtain-the-access-token-of-an-internal-app). - Aplikasi perusahaan pihak ketiga: panggil API untuk mendapatkan access token organisasi yang telah memberikan kebenaran kepada aplikasi pihak ketiga tersebut. |

### Parameter pertanyaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| userId | String | Tidak | userId pengguna. |

### Isi permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| bizType | Long | Tidak | Jenis borang kelulusan:   - 1: Kerja lebih masa - 2: Perjalanan perniagaan - 3: Cuti |
| fromTime | String | Tidak | Masa mula. Masa mula tidak boleh lebih daripada 31 hari sebelum masa semasa. Format yang disokong:   - 2019-08-15 - 2019-08-15 AM - 2019-08-15 12:43 |
| toTime | String | Tidak | Masa tamat.   - Apabila biz_type ialah 1, masa tamat tolak masa mula tidak boleh melebihi 1 hari. - Apabila biz_type ialah 2 atau 3, bilangan hari antara masa mula dan masa tamat tidak boleh melebihi 31.   Format yang disokong:   - 2019-08-15 - 2019-08-15 AM - 2019-08-15 12:43 |
| durationUnit | String | Tidak | Unit tempoh. Nilai yang disokong:   - day - halfDay - hour: Apabila biz_type ialah 1, hanya hour disokong.   Format masa mesti sepadan dengan unit tempoh:   - 2019-08-15 sepadan dengan day - 2019-08-15 AM sepadan dengan halfDay - 2019-08-15 12:43 sepadan dengan hour |
| calculateModel | Long | Tidak | Kaedah pengiraan:   - 0: Mengikut hari kalendar - 1: Mengikut hari bekerja |
| leaveCode | String | Tidak | Pengecam unik peraturan cuti. Pilihan. Hanya terpakai apabila bizType=3 (cuti). Jika dinyatakan, tempoh akan dibundarkan mengikut peraturan pembundaran yang dikonfigurasi untuk jenis cuti tersebut. |
