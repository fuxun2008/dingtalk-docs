Panggil API ini untuk mengemas kini maklumat kumpulan kehadiran berdasarkan ID kumpulan kehadiran.

## Permintaan

| **Maklumat asas** | |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/topapi/attendance/group/modify |
| Kaedah HTTP | POST |
| Jenis aplikasi yang disokong | appType-Aplikasi dalaman |
| Kebenaran yang diperlukan | permission-qyapi_attendance_group_manage-Kebenaran pengurusan kumpulan kehadiran |

### Parameter pertanyaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | b5e95d101165xxxx | Kelayakan aplikasi yang digunakan untuk memanggil API ini. Dapatkannya dengan memanggil API [Dapatkan access_token Aplikasi dalaman](/ms/open/development/obtain-orgapp-token). |

### Isi permintaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| op_user_id | String | Ya | 123dfd | ID pengguna operator. |
| top_group | Object | Ya |  | Maklumat kumpulan kehadiran. |
| shift_vo_list | Object[] | Tidak |  | Maklumat syif. |
| id | Number | Tidak | 123 | ID syif. Dapatkan nilai id dengan memanggil API [Dapatkan ringkasan syif](/ms/open/development/enterprise-shift-query-in-batches). |
| id | Number | Ya | 123 | ID kumpulan kehadiran.  **Nota**  Jika anda menggunakan pengecam kumpulan kehadiran lama group_key, panggil API [Tukar groupKey kepada groupId](/ms/open/development/convert-groupkey-to-groupid) untuk menukar group_key kepada group_id. |
| name | String | Tidak | Kehadiran Syif Siang | Nama kumpulan kehadiran. |
| positions | Object[] | Tidak |  | Tetapan alamat kehadiran. |
| address | String | Tidak | 21 Jalan Jinger, Taman Perindustrian Bioteknologi | Alamat. |
| corp_id | String | Tidak | 123dfd | CorpId Organisasi. Cari maklumat ini di halaman Utama [Konsol Pembangun](https://open-dev.dingtalk.io/#/index). |
| latitude | String | Tidak | 36.687495 | Latitud (sehingga 6 tempat perpuluhan). |
| longitude | String | Tidak | 101.750329 | Longitud (sehingga 6 tempat perpuluhan). |
| title | String | Tidak | Muzium Sejarah Alam Dataran Tinggi Qinghai-Tibet | Tajuk lokasi kehadiran. |
| accuracy | String | Tidak | 0 | Ketepatan.  **Nota**  Medan ini tidak mempunyai kesan sebenar dan tidak menjejaskan ketepatan. Medan ini tidak lagi digunakan sejak 7 Mac 2022. |
| offset | Number | Tidak | 300 | Julat kehadiran. |
| manager_list | String[] | Tidak | ["userId1","userId2"] | Senarai ID pengguna Sub Admin kumpulan kehadiran. |
| enable_camera_check | Boolean | Tidak | true | Menentukan sama ada daftar masuk dengan foto diaktifkan.   - **true**: Hidup - **false** (lalai): Mati   **Nota**  Parameter ini tidak lagi digunakan. Gunakan parameter open_camera_check sebagai ganti. |
| owner | String | Tidak | 123dfdf | ID pengguna penyelia kehadiran. |
| disable_check_when_rest | Boolean | Tidak | false | Menentukan sama ada daftar masuk pada hari rehat memerlukan Kelulusan.   - **true**: Wajib - **false**: Tidak wajib |
| skip_holidays | Boolean | Tidak | true | Menentukan sama ada cuti umum dilangkau.   - **true** (lalai): Langkau - **false**: Jangan langkau |
| enable_outside_check | Boolean | Tidak | true | Menentukan sama ada kehadiran luar pejabat dibenarkan.   - **true** (lalai): Benarkan - **false**: Jangan benarkan |
| disable_check_without_schedule | Boolean | Tidak | false | Menentukan sama ada pekerja dilarang membuat daftar masuk apabila tiada syif dijadualkan.   - **true**: Larang - **false**: Jangan larang |
| enable_emp_select_class | Boolean | Tidak | true | Menentukan sama ada pekerja boleh memilih syif untuk membuat daftar masuk apabila tiada syif dijadualkan.   - **true**: Benarkan - **false**: Jangan benarkan |
| resource_permission_map | Object | Tidak |  | Skop kebenaran Sub Admin.   - **w**: Boleh diurus - **r**: Baca Sahaja |
| camera_check | String | Tidak | w | Konfigurasikan peraturan daftar masuk dengan foto. |
| over_time_rule | String | Tidak | r | Konfigurasikan peraturan kerja lebih masa. |
| check_position_type | String | Tidak | w | Konfigurasikan kaedah daftar masuk. |
| check_time | String | Tidak | r | Konfigurasikan masa kehadiran. |
| group_type | String | Tidak | w | Konfigurasikan jenis kehadiran. |
| group_member | String | Tidak | r | Konfigurasikan ahli kehadiran. |
| schedule | String | Tidak | w | Penjadualan syif pekerja. |
| out_side_check | String | Tidak | r | Konfigurasikan kehadiran luar pejabat. |
| workday_class_list | Number[] | Tidak | [12,12,12,12,0,0] | Senarai syif mingguan.  **Nota**   - Wajib untuk kehadiran syif tetap. 0 menunjukkan hari rehat. - Nilai dalam array mewakili penjadualan syif harian dari Ahad hingga Sabtu, dari kiri ke kanan. |
| open_camera_check | Boolean | Tidak | true | Menentukan sama ada daftar masuk dengan foto diaktifkan.   - **true**: Hidup - **false** (lalai): Mati |

### Contoh permintaan

```curl

-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=ca21b524-0a09-4909-b6e9-af087e28a86b' \
-d 'op_user_id=123dfd' \
-d 'top_group=null'
```

## Respons

### Isi respons

| Nama | Jenis | Contoh | Penerangan |
| --- | --- | --- | --- |
| result | Object |  | Hasil kumpulan kehadiran. |
| name | String | Kehadiran Syif Siang | Nama kumpulan kehadiran. |
| id | Number | 123 | ID kumpulan kehadiran. |
| errmsg | String | 0 | Mesej ralat. |
| errcode | Number | ok | Kod ralat. |
| success | Boolean | true | Menunjukkan sama ada panggilan berjaya.   - **true**: Berjaya - **false**: Gagal |

### Contoh isi respons

```json
{
  "result":{
    "name":"Kehadiran Syif Siang",
    "id":"123"
  },
  "errcode":0,
  "success":true,
  "errmsg":"ok"
}
```

### Kod ralat

Jika panggilan mengembalikan ralat, cari penyelesaian berdasarkan mesej ralat dalam dokumen [Kod ralat global](/ms/open/development/server-api-error-codes-1).
