---
title: "Dapatkan butiran pengguna Akaun Syarikat dalam satu jabatan"
description: "Panggil API ini untuk mendapatkan butiran pengguna Akaun Syarikat dalam jabatan tertentu, tidak termasuk sub-jabatan. Hanya untuk organisasi yang telah mengaktifkan Akaun Syarikat."
---

Panggil API ini untuk mendapatkan butiran pekerja dalam jabatan tertentu. Pekerja dalam sub-jabatan tidak boleh diambil. API ini pada masa ini hanya tersedia untuk organisasi yang telah membeli dan mengaktifkan Akaun Syarikat.

## Permintaan

| **Maklumat asas** | |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/topapi/v2/user/list |
| Kaedah HTTP | POST |
| Jenis aplikasi disokong | appType-Aplikasi dalaman, appType-Aplikasi perusahaan pihak ketiga |
| Kebenaran diperlukan | permission-qyapi_get_department_member-Kebenaran baca ahli jabatan Kenalan |

### Parameter query

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | be3Fxxxx | Kelayakan aplikasi yang digunakan untuk memanggil API ini.   - Untuk aplikasi dalaman, dapatkan melalui API untuk mendapatkan [access_token aplikasi dalaman](/open/development/obtain-orgapp-token). - Untuk aplikasi perusahaan pihak ketiga, dapatkan melalui API untuk mendapatkan access_token perusahaan pihak ketiga. |

### Isi permintaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| dept_id | Number | Ya | 10 | ID jabatan. Panggil API [Dapatkan senarai jabatan](/open/development/user-management-acquires-the-list-departments) untuk mendapatkan nilai dept_id.  **Nota**   - Hanya pekerja dalam jabatan semasa dikembalikan. Pekerja dalam sub-jabatan tidak disertakan. - Untuk jabatan root, hantar nilai 1. |
| cursor | Number | Ya | 0 | Cursor untuk penomboran halaman. Hantar 0 untuk panggilan pertama, kemudian hantar nilai next_cursor yang dikembalikan dalam panggilan seterusnya. |
| size | Number | Ya | 10 | Saiz halaman. |
| order_field | String | Tidak | modify_desc | Peraturan penyusunan untuk ahli jabatan. Jika parameter ini tidak dihantar, hasil disusun mengikut susunan tersuai (custom) secara lalai.   - **entry_asc**: Susun mengikut susunan menaik masa menyertai jabatan. - **entry_desc**: Susun mengikut susunan menurun masa menyertai jabatan. - **modify_asc**: Susun mengikut susunan menaik masa pengubahsuaian maklumat jabatan. - **modify_desc**: Susun mengikut susunan menurun masa pengubahsuaian maklumat jabatan. - **custom**: Susun mengikut susunan tetapan pengguna (mengikut pinyin jika tidak ditetapkan). |
| contain_access_limit | Boolean | Tidak | false | Sama ada untuk mengembalikan pekerja dengan sekatan akses:   - true: Kembalikan mereka. - false: Jangan kembalikan mereka. |
| language | String | Tidak | zh_CN | Bahasa untuk Kenalan.   - **zh_CN**: Bahasa Cina (lalai). - **en_US**: Bahasa Inggeris. |

### Contoh permintaan

```curl
curl -X POST "https://api.dingtalk.io/topapi/v2/user/list" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=8d4de2xxxx49c' \
-d 'contain_access_limit=false' \
-d 'cursor=0' \
-d 'dept_id=10' \
-d 'language=zh_CN' \
-d 'order_field=modify_desc' \
-d 'size=10'
```

Java

```text
DingTalkClient client = new DefaultDingTalkClient("https://api.dingtalk.io/topapi/v2/user/list");
OapiV2UserListRequest req = new OapiV2UserListRequest();
req.setDeptId(10L);
req.setCursor(0L);
req.setSize(10L);
req.setOrderField("modify_desc");
req.setContainAccessLimit(false);
req.setLanguage("zh_CN");
OapiV2UserListResponse rsp = client.execute(req, access_token);
System.out.println(rsp.getBody());
```

Python

```python
import dingtalk.api

req=dingtalk.api.OapiV2UserListRequest("https://api.dingtalk.io/topapi/v2/user/list")

req.dept_id=10
req.cursor=0
req.size=10
req.order_field="modify_desc"
req.contain_access_limit=false
req.language="zh_CN"
try:
  resp= req.getResponse(access_token)
  print(resp)
except Exception,e:
  print(e)
```

PHP

```php

date_default_timezone_set('Asia/Shanghai');

$req->setCursor("0");
$req->setSize("10");

```

C#

```text
IDingTalkClient client = new DefaultDingTalkClient("https://api.dingtalk.io/topapi/v2/user/list");
OapiV2UserListRequest req = new OapiV2UserListRequest();
```

### Kod ralat

Jika ralat dikembalikan semasa memanggil API ini, cari penyelesaian dalam dokumen [Kod ralat global](/open/development/server-api-error-codes-1) berdasarkan mesej ralat.

| Kod ralat (errcode) | Mesej ralat (errmsg) | Penyelesaian |
| --- | --- | --- |
| 400002 | Invalid parameter | Semak sama ada parameter diisi seperti yang diperlukan. |
| 50004 | The department is not within the permission scope | Pastikan access_token mempunyai kebenaran operasi. |
| 40035 | Invalid parameter | dept_id, cursor, size, atau order_field diisi dengan salah. |
| 60019 | Failed to get users from the department | Pastikan parameter berkaitan diisi dengan betul. |
| -1 | System busy | Cuba lagi kemudian. |
