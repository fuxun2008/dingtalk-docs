title: "Dapatkan penapis"
description: "Panggil API ini untuk mendapatkan semula penapis global yang sedang aktif pada helaian kerja yang ditentukan, mengembalikan ID penapis, julat, dan syarat bagi setiap lajur, sesuai untuk mengesahkan status penapis atau membaca konfigurasi."
---

Panggil API ini untuk menanyakan penapis global yang sedang berkuat kuasa pada helaian kerja yang ditentukan. Respons akan mengembalikan ID penapis, julat penapis, dan syarat penapis yang ditetapkan bagi setiap lajur. Ini berguna untuk mengesahkan status penapis semasa sebelum mengubah suai syarat penapis, atau untuk membaca konfigurasi penapis secara programatik bagi pemprosesan selanjutnya.

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/doc/workbooks/{workbookId}/sheets/{sheetId}/filter/getFilter` |
| Kaedah HTTP | GET |
| Jenis aplikasi yang disokong | appType-企业内部应用 |
| Kebenaran yang diperlukan | permission-Document.Workbook.Read-钉钉表格读权限 |

### Pengepala permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Panggil API [Dapatkan access token bagi aplikasi dalaman](/ms/open/development/obtain-the-access-token-of-an-internal-app) untuk mendapatkannya. |

### Parameter laluan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| workbookId | String | Ya | ID fail hamparan. `nodeId(dentryUuid)` yang dikembalikan oleh [API Knowledge Base](/ms/open/development/knowledge-base-overview) ialah `workbookId` bagi hamparan tersebut. Panggil API [Dapatkan nod](/ms/open/development/get-knowledge-base-acquisition-node) atau [Cipta dokumen Knowledge Base](/ms/open/development/create-team-space-document) untuk mendapatkannya. |
| sheetId | String | Ya | ID atau nama helaian kerja. Panggil API [Dapatkan semua Helaian Kerja](/ms/open/development/obtain-all-worksheets) untuk mendapatkan nilai parameter `id` atau `name`.  **Nota**  Jika tiada penapis wujud pada helaian kerja tersebut, API akan mengembalikan ralat 404. |

### Parameter pertanyaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| operatorId | String | Ya | unionId bagi pengendali.   - Panggil API [Dapatkan maklumat pengguna melalui kod Log masuk senyap](/ms/open/development/obtain-the-userid-of-a-user-by-using-the-log-free) untuk mendapatkan nilai parameter `unionid`. - Panggil API [Tanya butiran pengguna](/ms/open/development/query-user-details) untuk mendapatkan nilai parameter `unionid`.       Jika pengendali tidak mempunyai Kebenaran, API akan mengembalikan ralat `The operator has no permission`. |

## Respons

### Isi respons

| Nama | Jenis | Penerangan |
| --- | --- | --- |
| id | String | Pengecam unik bagi penapis. |
| range | String | Julat penapis dalam notasi A1. |
| criteria | `Map<String, Object>` | Pemetaan syarat penapis bagi semua lajur. Kunci ialah offset lajur (relatif kepada lajur pertama dalam julat penapis, bermula dari 0), dan nilai ialah objek syarat penapis bagi lajur tersebut. Jika tiada syarat penapis ditetapkan, objek kosong `{}` akan dikembalikan. |
|  | Object | Syarat penapis bagi lajur semasa. |
| filterType | String | Jenis penapis. Nilai yang sah:   - **values**: menapis mengikut nilai. - **color**: menapis mengikut warna. - **condition**: menapis mengikut syarat. |
| visibleValues | Array of String | Nilai yang kelihatan. |
| conditions | Array | Senarai syarat apabila menapis mengikut syarat. Hanya dikembalikan apabila `filterType` ialah `condition`. |
| operator | String | Operator syarat. Nilai yang sah:   - **equal**: sama dengan. - **not-equal**: tidak sama dengan. - **contains**: mengandungi. - **not-contains**: tidak mengandungi. - **starts-with**: bermula dengan. - **not-starts-with**: tidak bermula dengan. - **ends-with**: berakhir dengan. - **not-ends-with**: tidak berakhir dengan. - **greater**: lebih besar daripada. - **greater-equal**: lebih besar daripada atau sama dengan. - **less**: lebih kecil daripada. - **less-equal**: lebih kecil daripada atau sama dengan. |
| value | String | Nilai syarat. |
| conditionOperator | String | Hubungan logik antara beberapa syarat (`and` atau `or`). Hanya dikembalikan apabila `filterType` ialah `condition`. |
| backgroundColor | String | Warna yang kelihatan apabila menapis mengikut warna latar belakang, dalam format heksadesimal. Hanya dikembalikan apabila `filterType` ialah `color` dan penapisan dilakukan mengikut warna latar belakang. |
| fontColor | String | Warna yang kelihatan apabila menapis mengikut warna Fon, dalam format heksadesimal. Hanya dikembalikan apabila `filterType` ialah `color` dan penapisan dilakukan mengikut warna Fon. |
