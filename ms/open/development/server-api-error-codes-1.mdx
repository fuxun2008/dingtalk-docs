---
title: "Kod ralat global"
description: "Menyenaraikan kod ralat global yang dikembalikan oleh API Platform Terbuka DingTalk, membantu pembangun mengesan dan menyelesaikan Issue dengan cepat mengikut kod ralat."
---

Apabila anda memanggil API Platform Terbuka DingTalk, anda akan menerima keputusan pemulangan yang mengandungi maklumat kod ralat kejayaan atau kegagalan. Analisis kod ralat untuk mengesan Issue dengan cepat dan menyahpepijat.

<Note>
Berikut adalah senarai kod ralat bahagian pelayan yang biasa. Jika kod ralat API tidak disenaraikan dalam kod ralat global, cari dalam dokumen API yang berkaitan. Selain itu, gunakan fungsi carian di sebelah kanan atas untuk mencari huraian kod ralat dan cadangan penyelesaian masalah secara global.
</Note>
