Panggil API ini untuk menambah komen pada instans kelulusan.

## Penerangan panggilan API

Untuk menambah lampiran pada komen kelulusan, muat naik fail ke ruang Drive kelulusan untuk mendapatkan parameter API spaceId, fileType, fileName, fileId dan fileSize. Dapatkan parameter tersebut seperti berikut:

1. Panggil API [Dapatkan maklumat ruang Drive kelulusan](/ms/open/development/obtains-the-information-about-approval-nail-disk) untuk mendapatkan kebenaran muat naik bagi ruang Drive dan spaceId ruang Drive kelulusan.
2. Gunakan spaceId ruang Drive kelulusan untuk memuat naik lampiran ke Drive, atau pilih fail daripada Drive dalam aplikasi web (Aplikasi mikro H5) atau Mini program, untuk mendapatkan maklumat fail lampiran Drive.

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/v1.0/workflow/processInstances/comments |
| Kaedah HTTP | POST |
| Jenis Aplikasi yang disokong | appType-Aplikasi dalaman |
| Kebenaran yang diperlukan | permission-Workflow.Instance.Write-Kebenaran tulis instans aliran kerja |

### Pengepala permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Panggil API [Dapatkan Access Token Aplikasi dalaman](/ms/open/development/obtain-the-access-token-of-an-internal-app) untuk mendapatkannya. |

### Isi permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| processInstanceId | String | Ya | ID instans kelulusan:   - Panggil API [Cipta instans kelulusan](/ms/open/development/create-an-approval-instance) untuk mendapatkan nilai parameter `InstanceId`. - Panggil API [Dapatkan butiran instans kelulusan](/ms/open/development/obtain-an-approval-list-of-instance-ids) untuk mendapatkan nilai parameter `list`. |
| text | String | Ya | Kandungan komen. Panjang maksimum: 1,024 aksara. |
| commentUserId | String | Ya | userId pengulas. |
| file | Object | Tidak | Fail. |
| photos | Array of String | Tidak | URL gambar. |
| attachments | Array | Tidak | Senarai lampiran. Bilangan maksimum elemen senarai: 20. |
| spaceId | String | Tidak | ID ruang Drive.      Rujuk penerangan panggilan API dalam topik ini. |
| fileSize | String | Tidak | Saiz fail.      Rujuk penerangan panggilan API dalam topik ini. |
| fileId | String | Tidak | ID fail. Panjang maksimum: 256 aksara.      Rujuk penerangan panggilan API dalam topik ini. |
| fileName | String | Tidak | Nama fail. Panjang maksimum: 256 aksara.      Rujuk penerangan panggilan API dalam topik ini. |
| fileType | String | Tidak | Jenis fail.      Rujuk penerangan panggilan API dalam topik ini. |
