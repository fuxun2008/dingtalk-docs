Panggil API ini untuk mendapatkan senarai borang kelulusan yang boleh dilihat oleh pekerja berdasarkan userId pekerja tersebut, secara berhalaman. Setiap panggilan mengembalikan sehingga 100 borang.

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/v1.0/workflow/processes/userVisibilities/templates |
| Kaedah HTTP | GET |
| Jenis aplikasi yang disokong | appType-Aplikasi dalaman |
| Kebenaran yang diperlukan | permission-Workflow.Form.Read-Kebenaran membaca templat aliran kerja |

### Pengepala permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Dapatkannya dengan memanggil API [Dapatkan access token Aplikasi dalaman](/ms/open/development/obtain-the-access-token-of-an-internal-app). |

### Parameter pertanyaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| userId | String | Tidak | userId pekerja yang hendak ditanya. Jika tidak dinyatakan, semua borang kelulusan dalam Organisasi akan dikembalikan. |
| maxResults | Long | Ya | Saiz halaman. Nilai maksimum: 100. |
| nextToken | Long | Ya | Cursor penomboran. - Untuk panggilan pertama, tetapkan parameter ini kepada 0. - Untuk panggilan seterusnya, tetapkan parameter ini kepada nextToken yang dikembalikan oleh panggilan sebelumnya. |

### Contoh permintaan

HTTP

```http
GET /v1.0/workflow/processes/userVisibilities/templates?userId=manager7078&maxResults=10&nextToken=0 HTTP/1.1
Host:api.dingtalk.io
x-acs-dingtalk-access-token:6d1bxxxx
Content-Type:application/json
```

## Respons

### Isi respons

| Nama | Jenis | Penerangan |
| --- | --- | --- |
| result | Object | Hasil yang dikembalikan. |
| processList | Array | Senarai borang yang boleh dilihat. |
| name | String | Nama borang. |
| url | String | URL borang. |
| iconUrl | String | URL ikon. |
| processCode | String | Pengecam unik borang. |
| dirId | String | ID Kumpulan yang mengandungi templat. |
| dirName | String | Nama Kumpulan yang mengandungi templat. |
| nextToken | Long | Cursor penomboran. Nilai yang tidak kosong menunjukkan masih terdapat data lain. |

### Contoh isi respons

```text
HTTP/1.1 200 OK
Content-Type:application/json

{
  "result" : {
    "processList" : [ {
      "name" : "Permohonan Barangan",
      "url" : "https://aflow.dingtalk.io/dingtalk/mobile/homepage.htm?xxxx",
      "iconUrl" : "https://gw.xxxx/T-102-102.png",
      "processCode" : "PROC-YMLA1-xxxx-11WFJ-1",
      "dirId" : "12347899",
      "dirName" : "Pengurusan Kewangan"
    } ],
    "nextToken" : 10
  }
}
```
