Panggil API ini untuk mengaktifkan Akaun Syarikat yang ditentukan.

## Penerangan panggilan API

Akaun Syarikat jenis Single Sign-On pada masa ini hanya boleh diuruskan melalui API. Bagi Akaun Syarikat yang dicipta sendiri, anda juga boleh menguruskannya dalam admin console organisasi, seperti yang ditunjukkan di bawah:

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/v1.0/contact/orgAccounts/enable |
| Kaedah HTTP | POST |
| Jenis aplikasi yang disokong | appType-Aplikasi dalaman |
| Kebenaran diperlukan | permission-Contact.OrgAccountSecurity.ReadWrite-Kebenaran baca dan tulis untuk data keselamatan Akaun Syarikat Kenalan |

### Pengepala permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Dapatkannya dengan memanggil API [Dapatkan access token aplikasi dalaman](/open/development/obtain-the-access-token-of-an-internal-app#). |

### Isi permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| userId | String | Ya | ID pengguna bagi Akaun Syarikat. Anda boleh mendapatkannya melalui empat cara berikut:   - [Cari Akaun Syarikat pengguna mengikut nombor telefon bimbit](/open/development/obtain-the-userid-of-your-mobile-phone-number#) - [Cipta Akaun Syarikat SSO](/open/development/create-an-sso-account#) - [Cipta Akaun Syarikat khas buatan sendiri DingTalk](/open/development/create-dingtalk-user-created-dedicated-account#) - [Jemput Akaun Syarikat daripada organisasi lain untuk menyertai](/open/development/invite-other-organization-specific-accounts-to-join#) |

### Contoh permintaan

HTTP

```http
POST /v1.0/contact/orgAccounts/enable HTTP/1.1
Host:api.dingtalk.io
x-acs-dingtalk-access-token:BExxx
Content-Type:application/json

{
  "userId" : "user123"
}
```
