Panggil API ini untuk menyerahkan tugasan Kelulusan OA.

## Penerangan panggilan API

<Note>
API ini hanya menyokong tugasan daripada kelulusan yang dimulakan melalui kelulusan rasmi atau proses kelulusan asli. API ini tidak menyokong tugasan instans yang dicipta oleh kelulusan tersuai.
</Note>

Untuk menambah lampiran kelulusan, muat naik fail ke ruang Drive kelulusan. Langkah ini memberikan parameter spaceId, fileType, fileName, fileId dan fileSize. Ikuti langkah berikut:

1. Panggil API [Dapatkan maklumat ruang Drive kelulusan](/ms/open/development/obtains-the-information-about-approval-nail-disk) untuk mendapatkan kebenaran muat naik bagi ruang Drive dan spaceId ruang Drive kelulusan.
2. Gunakan spaceId ruang Drive kelulusan untuk memuat naik lampiran ke Drive atau pilih fail daripada Drive dalam aplikasi web (Aplikasi mikro H5) anda bagi mendapatkan maklumat fail lampiran Drive.

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/v1.0/workflow/tasks/redirect |
| Kaedah HTTP | POST |
| Jenis aplikasi yang disokong | appType-Aplikasi dalaman　appType-Aplikasi perusahaan pihak ketiga |
| Kebenaran | permission-Workflow.Instance.Write-Kebenaran tulis instans aliran kerja |

### Pengepala permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Dapatkannya seperti berikut:   - Aplikasi dalaman: Panggil API [Dapatkan Access Token bagi Aplikasi dalaman](/ms/open/development/obtain-the-access-token-of-an-internal-app). - Aplikasi perusahaan pihak ketiga: Panggil API yang mendapatkan access token bagi organisasi yang telah memberikan kebenaran kepada Aplikasi pihak ketiga. |

### Isi permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| taskId | Long | Ya | ID tugasan Kelulusan OA. Gunakan nilai taskId yang dikembalikan oleh API [Dapatkan butiran satu instans kelulusan](/ms/open/development/obtains-the-details-of-a-single-approval-instance-pop). |
| toUserId | String | Ya | userId pengguna yang akan menerima tugasan Kelulusan OA yang diserahkan. |
| remark | String | Tidak | Catatan penyerahan. Panjang maksimum: 256 aksara. |
| operateUserId | String | Ya | userId pengendali. Nilai ini mesti sepadan dengan penerima tugasan semasa. Jika tidak, pengesahan akan gagal. |
| actionName | String | Tidak | Nama nod tindakan. Panjang maksimum: 128 aksara. |
| file | Object | Tidak | Fail. |
| photos | Array of String | Tidak | URL gambar. Panjang maksimum: 1,024 aksara. |
| attachments | Array | Tidak | Senarai lampiran. Bilangan elemen maksimum: 20. |
| spaceId | String | Tidak | ID ruang Drive.      Rujuk bahagian Penerangan panggilan API dalam dokumen ini. |
| fileSize | String | Tidak | Saiz fail.      Rujuk bahagian Penerangan panggilan API dalam dokumen ini. |
| fileId | String | Tidak | ID fail. Panjang maksimum: 256 aksara.      Rujuk bahagian Penerangan panggilan API dalam dokumen ini. |
| fileName | String | Tidak | Nama fail. Panjang maksimum: 256 aksara.      Rujuk bahagian Penerangan panggilan API dalam dokumen ini. |
| fileType | String | Tidak | Jenis fail.      Rujuk bahagian Penerangan panggilan API dalam dokumen ini. |
