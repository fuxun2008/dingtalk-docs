---

Panggil API ini untuk mendapatkan butiran semua kumpulan kehadiran.

## Penerangan panggilan API

Dalam aplikasi Kehadiran DingTalk, kumpulan kehadiran ialah sekumpulan pengguna atau jabatan yang berkongsi peraturan kehadiran yang sama, seperti syif dan lokasi kehadiran. Organisasi boleh mencipta beberapa kumpulan kehadiran mengikut keperluan perniagaan.

<Note>
Berbeza daripada API [Dapatkan butiran kumpulan kehadiran](/ms/open/development/query-a-single-attendance-group), API ini memulangkan maklumat kumpulan kehadiran yang merangkumi tetapan syif.
</Note>

Untuk melihat kumpulan kehadiran, buka **Pengurusan Kumpulan Kehadiran** dalam konsol admin **Kehadiran** DingTalk. Sebagai contoh, kumpulan yang dicipta melalui API boleh menjadi kumpulan kehadiran syif tetap dengan syif siang 09:00–18:00 dari Isnin hingga Jumaat dan hari rehat pada Sabtu dan Ahad.

## Permintaan

| **Maklumat asas** | |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/topapi/attendance/getsimplegroups |
| Kaedah HTTP | POST |
| Jenis aplikasi yang disokong | appType-Aplikasi dalaman　appType-Aplikasi perusahaan pihak ketiga |
| Kebenaran | permission-qyapi_base-Kebenaran asas yang diperlukan untuk memanggil API organisasi |

### Parameter pertanyaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | bE74xxxx | Kelayakan aplikasi yang digunakan untuk memanggil API ini.   - Untuk Aplikasi dalaman, panggil API [Dapatkan access_token Aplikasi dalaman](/ms/open/development/obtain-orgapp-token). - Untuk Aplikasi perusahaan pihak ketiga, panggil API untuk mendapatkan access_token organisasi pihak ketiga. |

### Isi permintaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| offset | Number | Tidak | 0 | Ofset penomboran halaman. Hanya berkuat kuasa apabila ditetapkan bersama parameter size. Ofset bermula daripada 0. Dalam panggilan seterusnya, hantar jumlah size dan offset daripada panggilan sebelumnya. |
| size | Number | Tidak | 10 | Saiz halaman. Nilai maksimum: 10. |

### Contoh permintaan

```curl
curl -X POST "https://api.dingtalk.io/topapi/attendance/getsimplegroups" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=c4a715xxxx0a0da2' \
-d 'offset=0' \
-d 'size=10'
```

Java

```java
DingTalkClient client = new DefaultDingTalkClient("https://api.dingtalk.io/topapi/attendance/getsimplegroups");
OapiAttendanceGetsimplegroupsRequest req = new OapiAttendanceGetsimplegroupsRequest();
req.setOffset(0L);
req.setSize(10L);
OapiAttendanceGetsimplegroupsResponse rsp = client.execute(req, access_token);
System.out.println(rsp.getBody());
```

Python

```python
import dingtalk.api

req=dingtalk.api.OapiAttendanceGetsimplegroupsRequest("https://api.dingtalk.io/topapi/attendance/getsimplegroups")

req.offset=0
req.size=10
try:
  resp= req.getResponse(access_token)
  print(resp)
except Exception,e:
  print(e)
```

PHP

```php
include "TopSdk.php";
date_default_timezone_set('Asia/Shanghai');

$c = new DingTalkClient(DingTalkConstant::$CALL_TYPE_OAPI, DingTalkConstant::$METHOD_POST , DingTalkConstant::$FORMAT_JSON);
$req = new OapiAttendanceGetsimplegroupsRequest;
$req->setOffset("0");
$req->setSize("10");
$resp = $c->execute($req, $access_token, "https://api.dingtalk.io/topapi/attendance/getsimplegroups");
```

C#

```csharp
IDingTalkClient client = new DefaultDingTalkClient("https://api.dingtalk.io/topapi/attendance/getsimplegroups");
OapiAttendanceGetsimplegroupsRequest req = new OapiAttendanceGetsimplegroupsRequest();
req.Offset = 0L;
req.Size = 10L;
OapiAttendanceGetsimplegroupsResponse rsp = client.Execute(req, access_token);
Console.WriteLine(rsp.Body);
```
