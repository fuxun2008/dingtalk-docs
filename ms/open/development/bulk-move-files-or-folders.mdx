Panggil API ini untuk memindahkan fail atau folder secara kelompok ke mana-mana lokasi lain.

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/storage/spaces/{spaceId}/dentries/batchMove` |
| Kaedah HTTP | POST |
| Jenis aplikasi disokong | appType-Aplikasi dalaman　appType-Aplikasi perusahaan pihak ketiga |
| Kebenaran diperlukan | permission-Storage.File.Write-Kebenaran tulis fail storan organisasi |

### Pengepala permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Dapatkan seperti berikut:   - Untuk aplikasi dalaman, panggil API [Dapatkan access token aplikasi dalaman](/open/development/obtain-the-access-token-of-an-internal-app). - Untuk aplikasi perusahaan pihak ketiga, panggil API [Dapatkan access token organisasi yang memberi kuasa kepada aplikasi pihak ketiga](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1). |

### Parameter laluan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| spaceId | String | Ya | ID ruang tempat fail atau folder sumber berada. Panggil API [Tambah ruang](/open/development/add-space) untuk mendapatkan nilai parameter `id`. |

### Parameter pertanyaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| unionId | String | Ya | unionId bagi pengendali (operator). Panggil API [Tanya butiran pengguna](/open/development/query-user-details) untuk mendapatkan nilai parameter `unionid`. |

### Isi permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| targetSpaceId | String | Ya | ID ruang sasaran. Panggil API [Tambah ruang](/open/development/add-space) untuk mendapatkan nilai parameter `id`. |
| targetFolderId | String | Ya | ID folder sasaran. ID direktori root ialah `0`. Panggil API [Dapatkan senarai fail atau folder](/open/development/get-a-list-of-files-or-folders) untuk mendapatkan nilai. |
| dentryIds | Array of String | Ya | Senarai ID fail atau folder sumber. Sehingga 30 item disokong. Panggil API [Dapatkan senarai fail atau folder](/open/development/get-a-list-of-files-or-folders) atau [Dapatkan spaceId dan dentryId melalui dentryUuid](/open/development/api-getdentryidbyuuid) untuk mendapatkan nilai parameter `id`. |
| option | Object | Tidak | Parameter pilihan. |
| conflictStrategy | String | Tidak | Strategi konflik nama untuk fail atau folder.   - **AUTO_RENAME**: namakan semula secara automatik. Nilai lalai. - **OVERWRITE**: tulis ganti. - **RETURN_DENTRY_IF_EXISTS**: kembalikan fail sedia ada. - **RETURN_ERROR_IF_EXISTS**: kembalikan ralat jika fail sudah wujud. |
| preservePermissions | Boolean | Tidak | Sama ada untuk mengekalkan kebenaran selepas pemindahan.   - **true**: kekalkan. - **false** (lalai): jangan kekalkan. |
