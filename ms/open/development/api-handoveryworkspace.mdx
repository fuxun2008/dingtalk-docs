Serahkan pemilikan Knowledge Base kepada pengguna lain.

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/v2.0/doc/dentries/workspace/handover |
| Kaedah HTTP | POST |
| Jenis aplikasi disokong | appType-Aplikasi dalaman |
| Kebenaran diperlukan | permission-SNS.Document.WorkspaceDocument.Write-Kebenaran menulis dokumen SNS Knowledge Base |

### Pengepala permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Dapatkan dengan memanggil API [Get the access token of an internal app](/open/development/obtain-the-access-token-of-an-internal-app#). |

### Isi permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| param | Object | Ya | Parameter wajib. |
| resourceId | String | Ya | rootNodeUUid bagi Knowledge Base yang hendak diserahkan. Dapatkan dengan memanggil API [Batch get Knowledge Bases](/open/development/batch-acquisition-of-knowledge-base#). |
| receiverUnionId | String | Ya | unionId penerima. |
| leave | Boolean | Tidak | Sama ada Pemilik semasa meninggalkan Knowledge Base selepas penyerahan. Pilihan. Lalai: false. |
