Panggil API ini untuk mendapatkan maklumat nod berdasarkan unionId pengendali dan URL dokumen.

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/v2.0/wiki/nodes/queryByUrl |
| Kaedah HTTP | POST |
| Jenis aplikasi yang disokong | appType-Aplikasi dalaman　appType-Aplikasi perusahaan pihak ketiga |
| Kebenaran yang diperlukan | permission-Wiki.Node.Read-Kebenaran baca nod Knowledge Base |

### Header permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Dapatkan seperti berikut:   - Untuk aplikasi dalaman, panggil API [Dapatkan access token aplikasi dalaman](/ms/open/development/obtain-the-access-token-of-an-internal-app#). - Untuk aplikasi perusahaan pihak ketiga, panggil API [Dapatkan access token perusahaan yang diberi kuasa kepada aplikasi pihak ketiga](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#). |

### Parameter query

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| operatorId | String | Ya | unionId pengendali. Dapatkan dengan memanggil API [Query butiran pengguna](/ms/open/development/query-user-details#). |

### Isi permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| url | String | Ya | URL dokumen. |
| option | Object | Tidak | Parameter pilihan. |
| withStatisticalInfo | Boolean | Tidak | Sama ada untuk mengembalikan maklumat statistik:   - **true**: Ya - **false** (lalai): Tidak |
| withPermissionRole | Boolean | Tidak | Sama ada untuk mengembalikan maklumat kebenaran:   - **true**: Ya - **false** (lalai): Tidak |
