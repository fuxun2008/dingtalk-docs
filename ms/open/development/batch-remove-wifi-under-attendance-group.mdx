---
title: "Alih keluar maklumat Wi-Fi secara pukal"
description: "Alih keluar maklumat Wi-Fi secara pukal daripada kumpulan kehadiran DingTalk melalui API dengan ID kumpulan dan kunci Wi-Fi, sehingga 100 entri setiap panggilan."
---

Panggil API ini untuk mengalih keluar maklumat Wi-Fi secara pukal daripada kumpulan kehadiran yang ditetapkan.

## Permintaan

| **Maklumat asas** | |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/topapi/attendance/group/wifis/remove |
| Kaedah HTTP | POST |
| Jenis aplikasi yang disokong | appType-Aplikasi dalaman |
| Kebenaran yang diperlukan | permission-qyapi_attendance_group_manage-Kebenaran pengurusan kumpulan kehadiran |

### Parameter pertanyaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | 6d1bxxxx | Kelayakan aplikasi yang digunakan untuk memanggil API ini. Dapatkannya dengan memanggil API [Dapatkan access_token aplikasi dalaman](/ms/open/development/obtain-orgapp-token). |

### Isi permintaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| op_userid | String | Tidak | user01 | userId pengendali. |
| group_key | String | Ya | CEDDFxxxx | ID kumpulan kehadiran.  **Nota**  Jika anda mengenal pasti kumpulan kehadiran menggunakan group_id, panggil API [Tukar groupId kepada groupKey](/ms/open/development/groupid-to-groupkey) untuk menukar group_id kepada group_key. |
| wifi_key_list | String | Ya | 0151Exxxx | Kunci Wi-Fi. Dapatkannya dengan memanggil API [Tanya maklumat Wi-Fi secara pukal](/ms/open/development/batch-query-wifi-under-attendance-group). Alih keluar sehingga 100 entri Wi-Fi bagi setiap panggilan. |

### Contoh permintaan

```curl
curl -X POST "https://api.dingtalk.io/topapi/attendance/group/wifis/remove" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=deb9baxxxx32b89' \
-d 'group_key=0151E022xxxx917E876' \
-d 'op_userid=123456' \
-d 'wifi_key_list=0151E02xxxx917E876'
```

Java

```text
DingTalkClient client = new DefaultDingTalkClient("https://api.dingtalk.io/topapi/attendance/group/wifis/remove");
OapiAttendanceGroupWifisRemoveRequest req = new OapiAttendanceGroupWifisRemoveRequest();
req.setOpUserid("user01");
req.setGroupKey("CEDDFxxxx");
req.setWifiKeyList("0151Exxxx");
OapiAttendanceGroupWifisRemoveResponse rsp = client.execute(req, access_token);
System.out.println(rsp.getBody());
```

## Respons

### Isi respons

| Nama | Jenis | Contoh | Penerangan |
| --- | --- | --- | --- |
| result | Result |  | Senarai wifiId yang berjaya dipadam. |
| error_info_list | ErrorInfo[] |  | Senarai kegagalan. |
| failure_list | String[] | 0151EEDDDF0xxxx | Senarai ralat. |
| msg | String | business fault | Penerangan ralat. |
| code | String | 1000 | Kod ralat. |
| success_list | String[] | 0151EEDDDF0xxxx | Senarai yang berjaya. |
| errcode | Number | 0 | Kod pemulangan. |
| errmsg | String | ok | Penerangan kod pemulangan. |
| success | Boolean | true | Menunjukkan sama ada panggilan berjaya.   - **true**: Berjaya - **false**: Gagal |
| request_id | String | 7o76z7s5cett | ID permintaan. |

### Contoh isi respons

```json
{
  "errcode": 0,
  "errmsg":"ok",
  "result": {
    "success_list": [
      "0151Exxxx",
    ]
  },
  "success": true,
  "request_id": "7o76z7s5cett"
}
```

### Kod ralat

Jika panggilan mengembalikan ralat, cari penyelesaian dalam dokumen [Kod ralat global](/ms/open/development/server-api-error-codes-1) berdasarkan mesej ralat.
