---
title: "Dapatkan maklumat fail atau folder secara pukal"
description: "Panggil API DingTalk ini untuk mendapatkan maklumat terperinci berbilang fail atau folder yang ditambah atau dimuat naik ke ruang storan dalam satu permintaan pukal."
---

Selepas fail atau folder ditambah atau dimuat naik ke ruang storan, panggil API ini untuk mendapatkan maklumat pukal fail atau folder tersebut.

## Penerangan panggilan API

Semasa mendapatkan maklumat fail dan folder, medan saiz fail dan sambungan fail tidak tersedia untuk folder.

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| HTTP URL | `https://api.dingtalk.io/v1.0/storage/spaces/{spaceId}/dentries/query` |
| Kaedah HTTP | POST |
| Jenis aplikasi disokong | appType-Aplikasi dalaman　appType-Aplikasi perusahaan pihak ketiga |
| Kebenaran | permission-Storage.File.Read-Kebenaran baca untuk fail storan organisasi |

### Pengepala permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses yang digunakan untuk memanggil API ini. Dapatkan seperti berikut:   - Untuk aplikasi dalaman, panggil API [Dapatkan access token aplikasi dalaman](/open/development/obtain-the-access-token-of-an-internal-app). - Untuk aplikasi perusahaan pihak ketiga, panggil API [Dapatkan access token organisasi yang diberi kuasa kepada aplikasi pihak ketiga](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1). |

### Parameter laluan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| spaceId | String | Ya | ID ruang. Panggil API [Tambah ruang](/open/development/add-space) untuk mendapatkan nilai parameter id. |

### Parameter pertanyaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| unionId | String | Ya | unionId pengendali. Panggil API [Tanya butiran pengguna](/open/development/query-user-details) untuk mendapatkan nilai parameter unionid. |

### Isi permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| dentryIds | Array of String | Ya | Senarai ID fail atau folder. Menyokong sehingga 30 ID. Panggil API [Dapatkan senarai fail atau folder](/open/development/get-a-list-of-files-or-folders) atau [Dapatkan spaceId dan dentryId melalui dentryUuid](/open/development/api-getdentryidbyuuid) untuk mendapatkan nilai parameter id. |
| option | Object | Tidak | Parameter pilihan. |
| appIdsForAppProperties | Array of String | Tidak | Senarai ID aplikasi tertentu. Menyokong sehingga 20 ID. Panggil API [Dapatkan maklumat ruang](/open/development/get-space-information) untuk mendapatkan nilai parameter ownerId.       - Jika parameter ini ditetapkan, sifat fail atau folder untuk aplikasi tertentu akan dikembalikan. - Jika parameter ini tidak ditetapkan, sifat fail atau folder untuk semua aplikasi akan dikembalikan. |
| withThumbnail | Boolean | Tidak | Sama ada hendak mendapatkan maklumat lakaran kenit (thumbnail) fail.   - **true**: Ya - **false**: Tidak       Dapatkan mengikut keperluan. Mendapatkan lakaran kenit meningkatkan masa respons API. |
