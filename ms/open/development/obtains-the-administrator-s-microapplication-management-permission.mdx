Panggil API ini untuk mendapatkan kebenaran urus aplikasi bagi seorang admin.

## Penerangan panggilan API

Sebelum memanggil API ini, pastikan perkara berikut:

- Aplikasi ini dibangunkan oleh penyedia penyelesaian produk. Dapatkan AppId pada halaman butiran aplikasi di [**DingTalk Developer Backend**](https://open-dev.dingtalk.io/#/appMgr/provider/eapp/53642/1) **> Aplikasi perusahaan pihak ketiga**.
- Sebelum memanggil API ini, anda boleh memanggil API [Tanya senarai admin](/ms/open/development/query-the-administrator-list) untuk mendapatkan ID admin bagi organisasi semasa.

## Permintaan

| **Maklumat asas** | |
| --- | --- |
| URL HTTP | https://oapi.dingtalk.io/user/can_access_microapp |
| Kaedah HTTP | GET |
| Jenis aplikasi disokong | appType-Aplikasi perusahaan pihak ketiga |
| Keperluan kebenaran | permission-qyapi_get_member-Kebenaran Telah dibaca untuk maklumat pengguna |

### Parameter pertanyaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| access_token | string | Ya | 6d1bxxxx | Kelayakan aplikasi untuk memanggil API ini. Diperoleh melalui API untuk mendapatkan access_token perusahaan pihak ketiga. |
| appId | Nombor | Ya | 2000121xxxx | ID aplikasi. Dapatkan AppID pada halaman butiran aplikasi di [**DingTalk Developer Backend**](https://open-dev.dingtalk.io/#/appMgr/provider/eapp/53642/1) **> Aplikasi perusahaan pihak ketiga**. |
| userId | string | Ya | 2000121xxxx | ID pengguna admin yang hendak ditanya. Panggil API [Tanya senarai admin](/ms/open/development/query-the-administrator-list) untuk mendapatkan nilai parameter userid. |

### Contoh permintaan

```curl
curl -X GET "https://oapi.dingtalk.io/user/can_access_microapp" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=c54ee841-199a-459e-8146-3d08c1830a10' \
-d 'appId=1' \
-d 'userId=1'
```

Java

```text

req.setUserId("1");
req.setHttpMethod("GET");

```

## Respons

### Isi respons

| Nama | Jenis | Contoh | Penerangan |
| --- | --- | --- | --- |
| request_id | string | 4f9md9obopn2 | ID permintaan. |
| errcode | Nombor | 0 | Kod pemulangan. |
| errmsg | string | Ralat sistem | Penerangan kod pemulangan. |
| canAccess | boolean | true | Sama ada pengguna mempunyai kebenaran pengurusan:   - **true**: mempunyai kebenaran pengurusan. - **false**: tidak mempunyai kebenaran pengurusan. |

### Contoh isi respons

```json
{
  "errcode":0,
  "canAccess":"true",
  "request_id":"4f9md9obopn2"
}
```

### Kod ralat

Jika ralat dikembalikan semasa memanggil API ini, cari penyelesaian dalam dokumen [Kod ralat global](/ms/open/development/server-api-error-codes-1) berdasarkan Mesej ralat.
