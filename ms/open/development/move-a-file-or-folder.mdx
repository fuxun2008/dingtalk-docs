Panggil API ini untuk mengalihkan fail atau folder ke lokasi lain.

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/storage/spaces/{spaceId}/dentries/{dentryId}/move` |
| Kaedah HTTP | POST |
| Jenis aplikasi yang disokong | appType-Aplikasi dalaman　appType-Aplikasi perusahaan pihak ketiga |
| Kebenaran yang diperlukan | permission-Storage.File.Write-Kebenaran menulis fail storan Enterprise |

### Header permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Dapatkan seperti berikut:   - Untuk aplikasi dalaman, panggil API [Dapatkan access token aplikasi dalaman](/open/development/obtain-the-access-token-of-an-internal-app). - Untuk aplikasi perusahaan pihak ketiga, panggil API [Dapatkan access token organisasi yang dibenarkan menggunakan aplikasi pihak ketiga](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1). |

### Parameter laluan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| spaceId | String | Ya | ID ruang sumber tempat fail atau folder berada. Panggil API [Tambah ruang](/open/development/add-space) untuk mendapatkan nilai parameter id. |
| dentryId | String | Ya | ID fail atau folder yang hendak dialihkan. Panggil API [Dapatkan senarai fail atau folder](/open/development/get-a-list-of-files-or-folders) atau API [Dapatkan spaceId dan dentryId mengikut dentryUuid](/open/development/api-getdentryidbyuuid) untuk mendapatkan nilai parameter id. |

### Parameter pertanyaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| unionId | String | Ya | unionId bagi pengendali operasi. Panggil API [Tanya butiran pengguna](/open/development/query-user-details) untuk mendapatkan nilai parameter unionid. |

### Isi permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| targetSpaceId | String | Ya | ID ruang sasaran tempat fail atau folder akan disimpan. Panggil API [Tambah ruang](/open/development/add-space) untuk mendapatkan nilai parameter id. |
| targetFolderId | String | Ya | ID folder induk tempat fail atau folder akan disimpan. Panggil API [Dapatkan senarai fail atau folder](/open/development/get-a-list-of-files-or-folders) untuk mendapatkan nilai parameter id.  Untuk direktori root, tetapkan parameter ini kepada 0. |
| option | Object | Tidak | Parameter pilihan. |
| conflictStrategy | String | Tidak | Strategi konflik nama untuk fail dan folder.   - **AUTO_RENAME** (lalai): Namakan semula secara automatik. - **OVERWRITE**: Tulis ganti. - **RETURN_DENTRY_IF_EXISTS**: Pulangkan fail sedia ada. - **RETURN_ERROR_IF_EXISTS**: Pulangkan ralat jika fail sudah wujud. |
| presevePermissions | Boolean | Tidak | Menentukan sama ada hendak mengekalkan kebenaran selepas pengalihan.   - **true**: Ya. - **false**: Tidak. Ini ialah nilai lalai. |
