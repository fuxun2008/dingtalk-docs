Topik ini menerangkan cara menghantar mesej sembang kumpulan menggunakan Bot aplikasi.

## Penerangan panggilan API

API ini menyokong Bot aplikasi dalaman. Untuk maklumat lanjut, lihat [Cipta Bot aplikasi dalaman](/ms/open/dingstart/configure-the-robot-application#).

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/v1.0/robot/groupMessages/send |
| Kaedah HTTP | POST |
| Jenis aplikasi yang disokong | appType-Aplikasi dalaman　appType-Aplikasi perusahaan pihak ketiga |
| Kebenaran diperlukan | permission-qyapi_robot_sendmsg-Kebenaran untuk menghantar mesej dengan Bot dalam organisasi Anda |

### Header permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses yang digunakan untuk memanggil API ini. Dapatkan seperti berikut:   - Untuk Aplikasi dalaman, panggil API [Dapatkan access token Aplikasi dalaman](/ms/open/development/obtain-the-access-token-of-an-internal-app#). - Untuk Aplikasi perusahaan pihak ketiga, panggil API [Dapatkan access token organisasi yang dibenarkan untuk Aplikasi pihak ketiga](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#). |

### Isi permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| msgParam | String | Ya | Parameter templat mesej. Untuk maklumat lanjut, lihat [Jenis mesej untuk Bot organisasi](https://open.dingtalk.com/document/orgapp/types-of-messages-sent-by-robots#). Panjang tidak boleh melebihi 15,000 bait. |
| msgKey | String | Ya | Kunci templat mesej. Untuk maklumat lanjut, lihat [Jenis mesej untuk Bot organisasi](https://open.dingtalk.com/document/dingstart/types-of-messages-sent-by-robots#). |
| openConversationId | String | Ya | ID sembang:   - Untuk Kumpulan Dalaman    - Untuk mendapatkan ID Kumpulan Dalaman yang baharu dicipta, Aplikasi dalaman boleh memanggil API [Cipta Kumpulan Dalaman](https://open.dingtalk.com/document/development/create-group-session#). Untuk mendapatkan ID Kumpulan Dalaman sedia ada, panggil [chooseChat](https://open.dingtalk.com/document/development/jsapi-choose-chat#). - Untuk kumpulan senario    - Aplikasi dalaman boleh memanggil API [Cipta kumpulan senario](https://open.dingtalk.com/document/development/create-a-scene-group-v2#). Untuk mendapatkan ID kumpulan senario sedia ada, gunakan JSAPI [chooseChat](https://open.dingtalk.com/document/orgapp/jsapi-choose-chat#). |
| robotCode | String | Ya | Kod Bot. Untuk maklumat lanjut, lihat [ID Bot](/ms/open/development/development-robot-overview#). |
| coolAppCode | String | Tidak | Kod cool app Sembang Kumpulan. Untuk maklumat lanjut, lihat [Cool app Sembang Kumpulan](https://open.dingtalk.com/document/dingstart/configuration-group-chat-quick-entry#).    Parameter ini **wajib** apabila Bot dipasang melalui cool app Sembang Kumpulan. |
