Panggil API ini untuk memulakan berbilang baki cuti biasa bagi seorang pekerja.

## Penerangan panggilan API

Jenis cuti ganti tidak perlu dimulakan melalui API ini. Tempoh kerja lebih masa ditukar secara automatik kepada tempoh cuti ganti. Peraturan cuti boleh dicipta dengan 2 cara, iaitu melalui panggilan API atau melalui aplikasi rasmi DingTalk Attendance:

| Kaedah penciptaan peraturan cuti | Kemas kini jenis cuti yang disokong oleh API ini |
| --- | --- |
| Jenis cuti yang dicipta melalui panggilan API [Tambah peraturan cuti](/ms/open/development/add-holiday-rules). | Disokong |
| Jenis cuti yang dicipta dalam aplikasi Attendance di Admin Console.   - Dicipta secara lalai oleh sistem aplikasi Attendance. - Dicipta melalui bahagian belakang aplikasi Attendance. | Tidak disokong |

## Permintaan

| **Maklumat asas** | |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/topapi/attendance/vacation/quota/init |
| Kaedah HTTP | POST |
| Jenis aplikasi yang disokong | appType-Aplikasi dalaman appType-Aplikasi perusahaan pihak ketiga |
| Keperluan kebenaran | permission-qyapi_holiday_manage-Kebenaran pengurusan cuti DingTalk |

### Parameter pertanyaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | bE74xxxx | Kelayakan aplikasi yang digunakan untuk memanggil API ini.   - Bagi Aplikasi dalaman, dapatkannya dengan memanggil API [Dapatkan access_token Aplikasi dalaman](/ms/open/development/obtain-orgapp-token). - Bagi Aplikasi perusahaan pihak ketiga, dapatkannya dengan memanggil API untuk mendapatkan access_token organisasi pihak ketiga. |

### Isi permintaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| op_userid | String | Ya | manager1 | ID pengguna admin dalam Organisasi Anda yang mempunyai kebenaran aplikasi untuk **Kelulusan OA**. |
| leave_quotas | LeaveQuotas | Ya |  | Rekod baki cuti yang hendak dimulakan. |
| userid | String | Ya | zhangsan | ID pengguna pekerja. |
| end_time | Number | Ya | 1653851001000 | Masa tamat tempoh sah kuota, dalam bentuk cap masa dalam milisaat. |
| start_time | Number | Ya | 1553851001000 | Masa mula tempoh sah kuota, dalam bentuk cap masa dalam milisaat. |
| leave_code | String | Ya | f84a282xxxx | Pengecam unik jenis cuti.  **Nota**   - Pemulaan disokong bagi jenis cuti yang ditambah melalui panggilan API [Tambah peraturan cuti](/ms/open/development/add-holiday-rules). - Pemulaan tidak disokong bagi jenis cuti terbina dalam organisasi. |
| reason | String | Tidak | Diimport oleh admin | Sebab tindakan. |
| quota_num_per_day | Number | Tidak | 100 | Jumlah kuota yang dikira dalam hari.  **Nota**  Apabila jenis cuti dikira dalam hari, nilai ini tidak boleh kosong dan diukur dalam perseratus hari.  Contohnya, 1000 = 10 hari. |
| quota_num_per_hour | Number | Tidak | 100 | Jumlah kuota yang dikira dalam jam.  **Nota**  Apabila jenis cuti dikira dalam jam, nilai ini tidak boleh kosong dan diukur dalam perseratus jam.  Contohnya, 1000 = 10 jam. |
| quota_cycle | String | Tidak | 2019 | Kitaran yang terpakai bagi kuota.  **Nota**  Format mestilah "yyyy". |

### Contoh permintaan

```curl
curl -X POST "https://api.dingtalk.io/topapi/attendance/vacation/quota/init" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=d82be2bxxxx023' \
-d 'leave_quotas=null' \
-d 'op_userid=zhangsan'
```

Java

```text
DingTalkClient client = new DefaultDingTalkClient("https://api.dingtalk.io/topapi/attendance/vacation/quota/init");
OapiAttendanceVacationQuotaInitRequest req = new OapiAttendanceVacationQuotaInitRequest();
req.setOpUserid("zhangsan");
List<LeaveQuotas> list = new ArrayList<LeaveQuotas>();
LeaveQuotas leaveQuotas = new LeaveQuotas();
list.add(leaveQuotas);
leaveQuotas.setUserid("user1");
leaveQuotas.setEndTime(1653851001000L);
leaveQuotas.setStartTime(1553851001000L);
leaveQuotas.setLeaveCode("f84a2829-xxxx0653");
leaveQuotas.setReason("Diimport oleh admin");
leaveQuotas.setQuotaNumPerDay(100L);
leaveQuotas.setQuotaNumPerHour(100L);
leaveQuotas.setQuotaCycle("2019");
req.setLeaveQuotas(list);
OapiAttendanceVacationQuotaInitResponse rsp = client.execute(req, access_token);
System.out.println(rsp.getBody());
```

## Respons

### Isi respons

| Nama | Jenis | Contoh | Penerangan |
| --- | --- | --- | --- |
| result | Result[] |  | Hasil yang dikembalikan. |
| reason | String | Kuota yang dikira dalam hari tidak boleh kosong | Sebab kegagalan. |
| quota | Quota |  | Rekod yang gagal. |
| leave_code | String | f84a2829-xxxx0653 | Pengecam unik jenis cuti. |
| userid | String | user1 | ID pengguna pekerja. |
| quota_cycle | String | 2019 | Kitaran yang terpakai bagi kuota. |
| errcode | Number | 0 | Kod pemulangan. |
| errmsg | String | ok | Mesej ralat yang dikembalikan apabila panggilan gagal. |
| success | Boolean | true | Menunjukkan sama ada permintaan berjaya.   - **true**: Ya - **false**: Tidak |
| request_id | String | zq4aec1jton8 | ID permintaan. |

### Contoh isi respons

```json
{
  "errcode": 0,
  "result": [
    {
      "quota": {
        "leave_code": "f84a2829-xxxx0653",

  "request_id": "zq4aec1jton8"

```

### Kod ralat

Jika panggilan mengembalikan ralat, cari penyelesaian berdasarkan mesej ralat dalam dokumen [Kod ralat global](/ms/open/development/server-api-error-codes-1).
