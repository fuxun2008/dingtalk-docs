Dokumen ini menerangkan cara memuat naik lampiran dalam AI Table.

Cara memuat naik lampiran dalam AI Table adalah serupa dengan tindakan yang ditunjukkan di bawah.

Memuat naik lampiran melibatkan tiga langkah:

1. Dapatkan maklumat muat naik. Untuk butiran, lihat API [Get resource upload information](/open/development/api-getresourceuploadinfo).
2. Muat naik fail tempatan ke `uploadUrl` yang dikembalikan pada langkah 1. Gunakan permintaan `PUT` untuk memuat naik fail tempatan.

   Berikut adalah contoh menggunakan arahan `cURL` (simbol @ dalam contoh ini diperlukan).

   ```bash
   curl -X PUT -H "Content-Type: image/jpeg" --data-binary @/path/to/your/image.jpg {uploadUrl returned in step 1}
   ```
3. Panggil API [Insert records](/open/development/api-notable-insertrecords) dan [Update multiple records](/open/development/api-noatable-updaterecords) untuk menulis lampiran ke dalam AI Table.

   Format nilai rekod adalah seperti berikut.

   ```json lines
   [
     {
         "filename": "pikaqiu.jpg", // resourceName yang dihantar pada langkah 1
         "size": 200, // size yang dihantar pada langkah 1
         "type": "image/jpeg", // mediaType yang dihantar pada langkah 1
         "url": "xxx"，// resourceUrl yang dikembalikan pada langkah 1. Nota: ini bukan uploadUrl. Contohnya, /core/api/resources/img/xxx
         "resourceId": "xxx" // resourceId yang dikembalikan pada langkah 1. Contohnya, 9ee6c515-4ebd-47a0-b8c3-5383c4241d84
     }
   ]
   ```
