# Gambaran Keseluruhan

Topik ini menerangkan fail media, keupayaan API yang tersedia untuk fail media, dan cara mengintegrasikan API fail media.

## Apa itu fail media

### Lokasi penyimpanan fail media

Ruang storan yang digunakan oleh ciri ini adalah kawasan storan khusus yang disediakan oleh DingTalk kepada organisasi. Ia bukan sebahagian daripada ruang Drive organisasi. Fail yang dimuat naik melalui API ciri ini tidak menggunakan ruang Drive organisasi.

### Kesahihan penyimpanan

Tidak terdapat had masa untuk tempoh penyimpanan fail oleh ciri ini. Selagi organisasi DingTalk tidak dibubarkan, `media_id` yang dikembalikan semasa memuat naik fail akan kekal sah untuk digunakan secara berterusan.

## Gambaran keseluruhan keupayaan terbuka

Fail media menyediakan set keupayaan API terbuka yang komprehensif. Pembangun boleh menggunakan API ini untuk mengintegrasikan fail media dengan sistem perniagaan organisasi mereka.
