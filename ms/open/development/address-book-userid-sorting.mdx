# Susun ID pengguna dalam Kenalan

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/v1.0/contact/users/sort |
| Kaedah HTTP | POST |
| Jenis aplikasi disokong | appType-Aplikasi perusahaan pihak ketiga |
| Kebenaran diperlukan | permission-qyapi_get_member-Kebenaran baca untuk maklumat pengguna |

### Pengepala permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Dapatkan dengan memanggil [Dapatkan access token organisasi yang diberi kuasa untuk aplikasi pihak ketiga](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#). |

### Isi permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| userIdList | Array of String | Ya | ID pengguna. Dapatkan nilai parameter userid dengan memanggil [Dapatkan ID pengguna menggunakan kod log masuk senyap](/ms/open/development/obtain-the-userid-of-a-user-by-using-the-log-free#). |
| sortType | Integer | Tidak | Kaedah susunan. Nilai sah:   - **0**: Susun mengikut pinyin nama secara menaik. - **1**: Susun mengikut pinyin nama secara menurun. |
