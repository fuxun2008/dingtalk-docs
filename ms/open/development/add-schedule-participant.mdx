Panggil API ini untuk menambah peserta kepada satu peristiwa.

## Penerangan panggilan API

Setiap operasi peserta menyokong sehingga 500 orang, dan menyokong peristiwa dengan sehingga 5,000 peserta.

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/calendar/users/{userId}/calendars/{calendarId}/events/{eventId}/attendees` |
| Kaedah HTTP | POST |
| Jenis aplikasi yang disokong | appType-Aplikasi dalaman　appType-Aplikasi perusahaan pihak ketiga　appType-Aplikasi peribadi pihak ketiga |
| Kebenaran diperlukan | permission-Calendar.Event.Write-Kebenaran tulis untuk peristiwa dalam aplikasi Kalendar |

### Header permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-client-token | String | Tidak | Semakan idempoten.       - `x-client-token` yang sama menunjukkan permintaan yang sama. - Tamat tempoh selepas 1 hari. |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Dapatkan seperti berikut:   - Untuk aplikasi dalaman, panggil API [Dapatkan access token aplikasi dalaman](/open/development/obtain-the-access-token-of-an-internal-app#). - Untuk aplikasi perusahaan pihak ketiga, panggil API [Dapatkan access token perusahaan yang diberi kuasa kepada aplikasi pihak ketiga](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#). - Untuk aplikasi peribadi pihak ketiga, panggil API [Dapatkan token pengguna](/open/development/obtain-user-token#). |

### Parameter laluan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| userId | String | Ya | unionId pencipta peristiwa.   - Untuk aplikasi dalaman atau aplikasi perusahaan pihak ketiga, panggil API [Tanya butiran pengguna](/open/development/query-user-details#) untuk mendapatkan nilai parameter unionid. - Untuk aplikasi peribadi pihak ketiga, panggil API [Dapatkan profil pengguna daripada Kenalan](/open/development/dingtalk-retrieve-user-information#) untuk mendapatkan nilai parameter unionId. |
| calendarId | String | Ya | ID kalendar yang menjadi milik peristiwa tersebut. Tetapkan kepada `primary` untuk menunjukkan kalendar utama pengguna. |
| eventId | String | Ya | ID peristiwa. Panggil API [Tanya senarai peristiwa](/open/development/query-an-event-list#) untuk mendapatkan nilai parameter id. |

### Isi permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| attendeesToAdd | Array | Ya | Senarai peserta yang perlu ditambah. |
| id | String | Tidak | unionId peserta.   - Untuk aplikasi dalaman atau aplikasi perusahaan pihak ketiga, panggil API [Tanya butiran pengguna](/open/development/query-user-details#) untuk mendapatkan nilai parameter unionid. - Untuk aplikasi peribadi pihak ketiga, panggil API [Dapatkan profil pengguna daripada Kenalan](/open/development/dingtalk-retrieve-user-information#) untuk mendapatkan nilai parameter unionId. |
| isOptional | Boolean | Tidak | Menentukan sama ada peserta adalah pilihan.   - **true**: Ya. - **false**: Tidak. |
| pushNotification | Boolean | Tidak | Menentukan sama ada untuk menghantar peringatan pop-up. |
| chatNotification | Boolean | Tidak | Menentukan sama ada untuk menghantar peringatan Mesej Terus. |
