Panggil API ini untuk mendapatkan senarai rata semua fail dan folder dalam satu ruang.

## Permintaan

### Maklumat asas

| Field | Value |
| --- | --- |
| HTTP URL | `https://api.dingtalk.io/v1.0/storage/spaces/{spaceId}/dentries/listAll` |
| HTTP Method | POST |
| Jenis aplikasi disokong | appType-Aplikasi dalaman　appType-Aplikasi perusahaan pihak ketiga |
| Kebenaran diperlukan | permission-Storage.File.Read-Kebenaran baca untuk fail storan organisasi |

### Pengepala permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Dapatkan seperti berikut:   - Untuk aplikasi dalaman, panggil API [Obtain the access token of an internal app](/open/development/obtain-the-access-token-of-an-internal-app#). - Untuk aplikasi perusahaan pihak ketiga, panggil API [Obtain the access token of an authorized organization for a third-party app](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#). |

### Parameter laluan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| spaceId | String | Ya | ID ruang. Panggil API [Add a space](/open/development/add-space#) dan gunakan nilai parameter `id` yang dikembalikan. |

### Parameter pertanyaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| unionId | String | Ya | unionId pengendali. Panggil API [Query user details](/open/development/query-user-details#) untuk mendapatkannya. |

### Isi permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| option | Object | Tidak | Parameter pilihan. |
| nextToken | String | Tidak | Cursor pagination.   - Untuk panggilan pertama, jangan hantar parameter ini. - Untuk panggilan seterusnya, hantar nextToken yang dikembalikan dalam panggilan sebelumnya. |
| maxResults | Integer | Tidak | Bilangan entri setiap halaman. Lalai: 50. Maksimum: 50. |
| order | String | Tidak | Peraturan penyusunan. Buat masa ini, hanya penyusunan mengikut masa pengubahsuaian disokong.   - **ASC** (lalai): tertib menaik - **DESC**: tertib menurun   - Apabila menyusun mengikut tertib menaik, jika fail berubah semasa pagination, data pendua mungkin diperoleh. - Apabila menyusun mengikut tertib menurun, jika fail berubah semasa pagination, data mungkin hilang. |
| withThumbnail | Boolean | Tidak | Sama ada untuk mendapatkan pautan lakaran kecil (thumbnail) fail.   - **true**: Ya - **false** (lalai): Tidak   Dapatkan mengikut keperluan. Mendapatkan lakaran kecil meningkatkan masa respons API. |
