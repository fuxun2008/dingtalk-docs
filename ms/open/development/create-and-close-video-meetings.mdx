title: "Cipta, pertanyakan, dan tutup mesyuarat video"
description: "Menunjukkan aliran hujung ke hujung penggunaan aplikasi dalaman untuk memanggil API mesyuarat bagi mencipta, mempertanyakan secara kelompok, dan menutup mesyuarat video, meliputi kelayakan aplikasi, kebenaran API, dan perolehan access token."
---

Dokumen ini menerangkan cara memanggil API mesyuarat untuk mencipta mesyuarat video dan melaksanakan operasi berkaitan. Pertama, cipta aplikasi dalaman, kemudian gunakan API mesyuarat untuk mencipta mesyuarat video, menutup mesyuarat video, dan mempertanyakan maklumat mesyuarat video secara kelompok.

## Gambaran keseluruhan proses

Prasyarat: Lengkapkan proses [cipta dan konfigurasi aplikasi](/ms/open/dingstart/create-application).

Langkah 1: Dapatkan kelayakan aplikasi untuk memperoleh client ID dan Client Secret.

Langkah 2: Mohon kebenaran API untuk API berkaitan mesyuarat.

Langkah 3: Dapatkan kredensial akses aplikasi dengan mengikuti [Dapatkan access token bagi aplikasi dalaman](/ms/open/development/obtain-the-access-token-of-an-internal-app). Access token digunakan untuk mengesahkan pemanggil apabila memanggil API.

Langkah 4: Panggil Server API berkaitan mesyuarat.

1. Panggil Server API [Cipta mesyuarat video](/ms/open/development/create-a-video-conference) untuk mencipta mesyuarat video dan mendapatkan `conferenceId` mesyuarat.
2. Berdasarkan `conferenceId`, panggil Server API [Pertanyaan kelompok maklumat mesyuarat video](/ms/open/development/batch-query-of-video-conference-information) untuk mendapatkan maklumat mesyuarat dan senarai ahli.
3. Berdasarkan `conferenceId`, panggil Server API [Mulakan rakaman awan untuk mesyuarat video](/ms/open/development/video-conference-open-cloud-recording) untuk memulakan rakaman awan.
4. Berdasarkan `conferenceId`, panggil Server API [Mulakan rakaman awan untuk mesyuarat video](/ms/open/development/video-conference-open-cloud-recording) untuk menghentikan rakaman awan.
5. Berdasarkan `conferenceId`, panggil Server API [Tutup mesyuarat video](/ms/open/development/close-audio-video-conference) untuk menutup mesyuarat.
6. Pertanyaan maklumat rakaman mesyuarat.

   1. Berdasarkan `conferenceId`, panggil Server API [Pertanyaan butiran rakaman mesyuarat](/ms/open/development/query-recording-information) untuk mendapatkan maklumat seperti perakam, masa mula rakaman, dan tempoh rakaman.
   2. Berdasarkan `conferenceId`, panggil Server API [Pertanyaan maklumat video rakaman mesyuarat](/ms/open/development/queries-the-playback-information-about-a-recorded-cloud-video) untuk mendapatkan maklumat seperti URL muat turun video, saiz fail video, dan tempoh video.
   3. Berdasarkan `conferenceId`, panggil Server API [Pertanyaan maklumat teks rakaman mesyuarat](/ms/open/development/queries-the-text-information-about-cloud-recording) untuk mendapatkan maklumat seperti kandungan teks rakaman, masa mula rekod teks, dan masa tamat rekod teks.

## Prasyarat

Lengkapkan proses [cipta dan konfigurasi aplikasi](/ms/open/dingstart/create-application).

## Langkah 1: Dapatkan kelayakan aplikasi

1. Pilih aplikasi sasaran untuk membuka halaman butiran aplikasi, dan klik **Maklumat asas** > **Kelayakan dan maklumat asas**.
2. Dapatkan client ID dan Client Secret.

## Langkah 2: Tambah kebenaran API

Klik **Konfigurasi pembangunan** > **Urus kebenaran**. Dalam kotak carian kebenaran, masukkan `VideoConference.Conference.Write` dan `VideoConference.Conference.Read` masing-masing, dan mohon kebenaran tersebut.

## Langkah 3: Dapatkan access token aplikasi

<Warning>
Untuk perbezaan antara Server API, lihat API lama berbanding API baharu. Semua API berikut menggunakan Server API. Untuk muat turun SDK, lihat Muat Turun SDK Bahagian Pelayan.
</Warning>

Menggunakan client ID dan Client Secret daripada Langkah 1, dapatkan access token aplikasi dengan mengikuti [Dapatkan access token bagi aplikasi dalaman](/ms/open/development/obtain-the-access-token-of-an-internal-app).

```java
 public void getAccessToken() throws Exception {

                .setAppKey("din*********hgn")
                .setAppSecret("9G_O************mBkhgGIO");
        GetAccessTokenResponse accessToken = client.getAccessToken(accessTokenRequest);
        System.out.println(JSON.toJSONString(accessToken.getBody()));
    }
```
