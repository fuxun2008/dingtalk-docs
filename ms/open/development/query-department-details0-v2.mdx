---

Panggil API ini untuk mendapatkan butiran jabatan yang ditentukan mengikut ID jabatannya.

## Permintaan

| **Maklumat asas** | |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/topapi/v2/department/get |
| Kaedah HTTP | POST |
| Jenis aplikasi disokong | appType-Aplikasi dalaman, appType-Aplikasi perusahaan pihak ketiga |
| Kebenaran diperlukan | permission-qyapi_get_department_list-Kebenaran Baca untuk maklumat jabatan Kenalan |

### Parameter pertanyaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | bE74xxxx | Kelayakan aplikasi yang digunakan untuk memanggil API ini.   - Untuk aplikasi dalaman, dapatkannya dengan memanggil API untuk mendapatkan [access_token aplikasi dalaman](/ms/open/development/obtain-orgapp-token). - Untuk aplikasi perusahaan pihak ketiga, dapatkannya dengan memanggil API untuk mendapatkan access_token perusahaan pihak ketiga. |

### Isi permintaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| dept_id | Number | Ya | 100 | ID jabatan. ID jabatan root ialah 1. Panggil API [Dapatkan senarai jabatan](/ms/open/development/user-management-acquires-the-list-departments) untuk mendapatkan nilai dept_id. |
| language | String | Tidak | zh_CN | Bahasa Kenalan:   - **zh_CN** (lalai): Bahasa Cina - **en_US**: Bahasa Inggeris |

### Contoh permintaan

```curl
curl -X POST "https://api.dingtalk.io/topapi/v2/department/get" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=d3daxxxx51990' \
-d 'dept_id=100' \
-d 'language=zh_CN'
```

Java

```text
DingTalkClient client = new DefaultDingTalkClient("https://api.dingtalk.io/topapi/v2/department/get");
OapiV2DepartmentGetRequest req = new OapiV2DepartmentGetRequest();
req.setDeptId(100L);
req.setLanguage("zh_CN");
OapiV2DepartmentGetResponse rsp = client.execute(req, access_token);
System.out.println(rsp.getBody());
```

Python

```python
import dingtalk.api

req=dingtalk.api.OapiV2DepartmentGetRequest("https://api.dingtalk.io/topapi/v2/department/get")

req.dept_id=100
req.language="zh_CN"
try:
  resp= req.getResponse(access_token)
  print(resp)
except Exception,e:
  print(e)
```

PHP

```php
include "TopSdk.php";
date_default_timezone_set('Asia/Shanghai');

$c = new DingTalkClient(DingTalkConstant::$CALL_TYPE_OAPI, DingTalkConstant::$METHOD_POST , DingTalkConstant::$FORMAT_JSON);
$req = new OapiV2DepartmentGetRequest;
$req->setDeptId("100");
$req->setLanguage("zh_CN");
$resp = $c->execute($req, $access_token, "https://api.dingtalk.io/topapi/v2/department/get");
```

C#

```text
IDingTalkClient client = new DefaultDingTalkClient("https://api.dingtalk.io/topapi/v2/department/get");
OapiV2DepartmentGetRequest req = new OapiV2DepartmentGetRequest();
req.DeptId = 100L;
req.Language = "zh_CN";
OapiV2DepartmentGetResponse rsp = client.Execute(req, access_token);
Console.WriteLine(rsp.Body);
```

## Respons

### Isi respons

| Nama | Jenis | Contoh | Penerangan |
| --- | --- | --- | --- |
| request_id | String | 4e7ljtq91rgo | ID permintaan. |
| errcode | Number | 0 | Kod pulangan. |
| errmsg | String | ok | Mesej ralat. |
| result | DeptGetResponse |  | Butiran jabatan. |

| source_identifier | String | HR | Medan pengecam jabatan.  **Nota**  Parameter ini tidak dikembalikan untuk aplikasi perusahaan pihak ketiga. |

| auto_add_user | Boolean | false | Sama ada pengguna baharu yang menyertai jabatan ditambah secara automatik ke Sembang Jabatan selepas sembang dicipta:   - **true**: Menyertai sembang secara automatik - **false**: Tidak menyertai sembang secara automatik |
| tags | String | campus | Tag jabatan pendidikan:   - **campus**: Kampus - **period**: Tempoh - **grade**: Gred - **class**: Kelas   **Nota**  Parameter ini tidak dikembalikan untuk aplikasi perusahaan pihak ketiga. |
| from_union_org | Boolean | false | Sama ada jabatan berasal daripada organisasi yang berkaitan:   - **true**: Ya - **false**: Tidak   **Nota**  Parameter ini tidak dikembalikan untuk aplikasi perusahaan pihak ketiga. |
| order | Number | 10 | Nilai susunan dalam jabatan induk. |
| dept_group_chat_id | String | 123 | ID Sembang Jabatan. |
| group_contain_sub_dept | Boolean | true | Sama ada Sembang Jabatan merangkumi sub-jabatan:   - **true**: Termasuk - **false**: Tidak termasuk |
| org_dept_owner | String | 80 | ID pengguna pemilik kumpulan sembang perusahaan. |
| dept_manager_userid_list | String[] | ["5","6","7","8"] | Senarai ID pengguna ketua jabatan. |
| outer_dept | Boolean | true | Sama ada untuk menyekat ahli jabatan ini daripada melihat Kenalan:   - **true**: Sekatan diaktifkan. Selepas diaktifkan, ahli jabatan ini hanya boleh **melihat Kenalan bagi jabatan/pengguna tertentu sahaja**. - **false**: Tiada sekatan |
| outer_permit_depts | Number[] | [500,600] | Senarai ID jabatan yang boleh dilihat oleh pekerja jabatan.  **Nota**  Apabila organisasi menyekat ahli jabatan ini daripada melihat Kenalan, nilai **outer_dept** dikembalikan.   - **Sekatan diaktifkan pada ahli jabatan ini melihat Kenalan** (iaitu, **outer_dept** ialah **true**): outer_permit_depts menunjukkan **senarai ID jabatan** bagi **jabatan/pengguna tertentu** yang boleh dilihat oleh ahli.   **Nota**  Sebagai contoh, organisasi menyekat ahli jabatan ini daripada melihat Kenalan, dan ahli jabatan ini ditetapkan untuk hanya melihat Kenalan bagi 2 jabatan tertentu dan 2 pekerja tertentu. ID jabatan bagi Jabatan Ujian 1 ialah 1 dan ID jabatan bagi Jabatan Ujian 2 ialah 2.  Apabila memanggil API ini, nilai outer_permit_depts yang diperoleh ialah [1,2]. Senarai pekerja tidak dikembalikan, iaitu, maklumat Pekerja Xiaoding 1 dan Pekerja Xiaoding 2 tidak dikembalikan.   - **Sekatan tidak diaktifkan pada ahli jabatan ini melihat Kenalan** (iaitu, **outer_dept** ialah **false**): Medan outer_permit_depts tidak dikembalikan. |
| outer_permit_users | String[] | ["78","79"] | Senarai ID pengguna pekerja yang boleh dilihat oleh pekerja jabatan.  **Nota**  Apabila organisasi menyekat ahli jabatan ini daripada melihat Kenalan, nilai **outer_dept** dikembalikan.     - **Sekatan diaktifkan pada ahli jabatan ini melihat Kenalan** (iaitu, **outer_dept** ialah **true**): outer_permit_users menunjukkan **senarai ID pengguna pekerja** bagi **jabatan/pengguna tertentu** yang boleh dilihat oleh ahli.   **Nota**  Sebagai contoh, organisasi menyekat ahli jabatan ini daripada melihat Kenalan, dan ahli jabatan ini ditetapkan untuk hanya melihat Kenalan bagi 2 jabatan tertentu dan 2 pekerja tertentu. ID pengguna bagi Pekerja Xiaoding 1 ialah 001 dan ID pengguna bagi Pekerja Xiaoding 2 ialah 002.  Apabila memanggil API ini, nilai outer_permit_users yang diperoleh ialah ["001","002"]. Senarai jabatan tidak dikembalikan, iaitu, maklumat Jabatan Ujian 1 dan Jabatan Ujian 2 tidak dikembalikan.   - **Sekatan tidak diaktifkan pada ahli jabatan ini melihat Kenalan** (iaitu, **outer_dept** ialah **false**): Medan outer_permit_users tidak dikembalikan. |
| user_permits | String[] | ["5","9"] | Senarai ID pengguna pekerja bagi jabatan tersembunyi.  **Nota**  Apabila organisasi mengaktifkan penyembunyian jabatan ini, nilai **hide_dept** dikembalikan.   - **Sembunyikan jabatan ini diaktifkan** (iaitu, hide_dept ialah true): user_permits menunjukkan **senarai ID pengguna pekerja** yang **dibenarkan dilihat oleh jabatan/pengguna tertentu**.  **Nota**  Sebagai contoh, organisasi mengaktifkan penyembunyian jabatan ini dan menetapkan 2 jabatan dan 2 pekerja untuk dapat melihat jabatan/pengguna tertentu. ID pengguna bagi Pekerja Xiaoding 1 ialah 001 dan ID pengguna bagi Pekerja Xiaoding 2 ialah 002.  Apabila memanggil API ini, nilai user_permits yang diperoleh ialah ["001","002"]. Senarai jabatan tidak dikembalikan, iaitu, maklumat Jabatan Ujian 1 dan Jabatan Ujian 2 tidak dikembalikan. - **Sembunyikan jabatan ini tidak diaktifkan** (iaitu, hide_dept ialah false): Medan user_permits tidak dikembalikan. |
| hide_dept | Boolean | false | Sama ada untuk mengaktifkan penyembunyian jabatan ini:   - **true**: Sembunyikan jabatan ini diaktifkan. Anda boleh menetapkan skop penyembunyian, seperti menyembunyikan daripada semua pengguna dan jabatan, atau membenarkan kebolehlihatan kepada jabatan/pengguna tertentu. - **false**: Sembunyikan jabatan ini dinyahaktifkan. Iaitu, jabatan dipaparkan dalam Kenalan syarikat. |
| dept_permits | Number[] | [3,4,5] | Senarai ID jabatan bagi jabatan tersembunyi.  **Nota**  Apabila organisasi mengaktifkan penyembunyian jabatan ini, nilai **hide_dept** dikembalikan.   - **Sembunyikan jabatan ini diaktifkan** (iaitu, hide_dept ialah true): dept_permits menunjukkan **senarai ID jabatan** yang **dibenarkan dilihat oleh jabatan/pengguna tertentu**.  **Nota**  Sebagai contoh, organisasi mengaktifkan penyembunyian jabatan ini dan menetapkan 2 jabatan dan 2 pekerja untuk dapat melihat jabatan/pengguna tertentu. ID jabatan bagi Jabatan Ujian 1 ialah 1 dan ID jabatan bagi Jabatan Ujian 2 ialah 2.  Apabila memanggil API ini, nilai dept_permits yang diperoleh ialah [1,2]. Senarai pekerja tidak dikembalikan, iaitu, maklumat Pekerja Xiaoding 1 dan Pekerja Xiaoding 2 tidak dikembalikan. - **Sembunyikan jabatan ini tidak diaktifkan** (iaitu, hide_dept ialah false): Medan dept_permits tidak dikembalikan. |

### Kod ralat

Jika ralat berlaku semasa memanggil API ini, cari penyelesaian mengikut mesej ralat dalam dokumen [Kod ralat global](/ms/open/development/server-api-error-codes-1).

| Kod ralat (errcode) | Mesej ralat (errmsg) | Penyelesaian |
| --- | --- | --- |
| 43007 | Authorization required | Sahkan bahawa access_token mempunyai kebenaran operasi. |
| 60003 | Corresponding department not found | Sahkan bahawa dept_id adalah betul. |
| 400002 | Invalid parameter | Sahkan bahawa parameter dimasukkan mengikut keperluan. |
| -1 | System busy | Cuba lagi kemudian. |
