Panggil API ini untuk mendapatkan Skop kebenaran Kenalan bagi seorang Admin.

## Permintaan

| **Maklumat Asas** | |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/topapi/user/get_admin_scope |
| Kaedah HTTP | POST |
| Jenis Aplikasi disokong | appType-Aplikasi dalaman, appType-Aplikasi perusahaan pihak ketiga |
| Kebenaran diperlukan | permission-qyapi_get_member-Kebenaran Telah dibaca untuk maklumat pengguna |

### Parameter pertanyaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | bE74xxxx | Kelayakan aplikasi yang digunakan untuk memanggil API ini.   - Untuk Aplikasi dalaman, dapatkan melalui API untuk mendapatkan [access_token bagi Aplikasi dalaman](/open/development/obtain-orgapp-token). - Untuk Aplikasi perusahaan pihak ketiga, dapatkan melalui API untuk mendapatkan access_token bagi perusahaan pihak ketiga. |

### Isi permintaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| userid | String | Ya | manger123 | ID pengguna bagi Admin. Panggil API [Dapatkan Senarai Admin](/open/development/query-the-administrator-list) untuk mendapatkan ID Admin dalam Organisasi semasa anda. |

### Contoh permintaan

```curl
curl -X POST "https://api.dingtalk.io/topapi/user/get_admin_scope" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=f928c8b2-5f41-4c92-908a-01fee1f20450' \
-d 'userid=manager7078'
```

Java

```text
DingTalkClient client = new DefaultDingTalkClient("https://api.dingtalk.io/topapi/user/get_admin_scope");
OapiUserGetAdminScopeRequest req = new OapiUserGetAdminScopeRequest();
req.setUserid("manger123");
OapiUserGetAdminScopeResponse rsp = client.execute(req, access_token);
System.out.println(rsp.getBody());
```

Python

```python
import dingtalk.api

req=dingtalk.api.OapiUserGetAdminScopeRequest("https://api.dingtalk.io/topapi/user/get_admin_scope")

req.userid="manager7078"
try:
  resp= req.getResponse(access_token)
  print(resp)
except Exception,e:
  print(e)
```

PHP

```php
include "TopSdk.php";
date_default_timezone_set('Asia/Shanghai');

$c = new DingTalkClient(DingTalkConstant::$CALL_TYPE_OAPI, DingTalkConstant::$METHOD_POST , DingTalkConstant::$FORMAT_JSON);
$req = new OapiUserGetAdminScopeRequest;
$req->setUserid("manager7078");
$resp = $c->execute($req, $access_token, "https://api.dingtalk.io/topapi/user/get_admin_scope");
```

C#

```text
IDingTalkClient client = new DefaultDingTalkClient("https://api.dingtalk.io/topapi/user/get_admin_scope");
OapiUserGetAdminScopeRequest req = new OapiUserGetAdminScopeRequest();
req.Userid = "manager7078";
OapiUserGetAdminScopeResponse rsp = client.Execute(req, access_token);
Console.WriteLine(rsp.Body);
```

## Respons

### Isi respons

| Nama | Jenis | Contoh | Penerangan |
| --- | --- | --- | --- |
| request_id | String | zpucraudovy0 | ID permintaan. |
| errcode | Number | 0 | Kod pulangan. |
| errmsg | String | ok | Penerangan kod pulangan. |
| dept_ids | Number[] | [1] | Senarai ID Jabatan yang boleh diurus oleh Admin. |

### Contoh isi respons

```json
{
  "dept_ids": [
    1
  ],
  "errcode": 0,
  "errmsg": "ok",
  "request_id": "zpucraudovy0"
}
```

### Kod ralat

Jika Ralat dikembalikan semasa anda memanggil API ini, cari penyelesaian dalam dokumen [Kod ralat global](/open/development/server-api-error-codes-1) berdasarkan Mesej ralat.

| Kod ralat (errcode) | Mesej ralat (errmsg) | Penyelesaian |
| --- | --- | --- |
| 60121 | Pekerja tidak ditemui | Sahkan sama ada userId adalah betul. |
| 40036 | Parameter kosong | Sahkan bahawa semua parameter Wajib disediakan. |
| 400001 | Ralat sistem | Cuba Lagi kemudian. |
