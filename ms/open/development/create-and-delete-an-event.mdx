## Gambaran keseluruhan aliran integrasi

Dokumen ini menunjukkan cara mencipta aplikasi dalaman dan kemudian menggunakan API yang disediakan oleh Kalendar untuk mencipta, mengubah suai, menanya butiran satu acara, dan memadam acara.

Prasyarat: Lengkapkan aliran [Cipta dan konfigurasikan aplikasi](/open/dingstart/create-application).

Langkah 1: Dapatkan maklumat kelayakan aplikasi, termasuk client ID dan Client Secret.

Langkah 2: Mohon kebenaran API untuk API berkaitan Kalendar.

Langkah 3: Dapatkan kredensial akses aplikasi [Dapatkan access token bagi aplikasi dalaman](/open/development/obtain-the-access-token-of-an-internal-app). Semasa memanggil API, gunakan access token untuk mengesahkan pemanggil.

Langkah 4: Panggil Server API untuk Kalendar:

1. Panggil Server API [Acara Baharu](/open/development/create-schedule) untuk mencipta satu acara. Dapatkan `id` acara.
2. Berdasarkan `id` acara, panggil Server API [Ubah suai acara](/open/development/modify-event) untuk mengubah suai maklumat acara.
3. Berdasarkan `id` acara, panggil Server API [Tanya butiran tentang satu acara](/open/development/query-details-about-an-event) untuk mendapatkan butiran acara.
4. Berdasarkan `id` acara, panggil Server API [Padam Acara](/open/development/delete-event) untuk memadam acara yang telah dicipta.

## Prasyarat

Lengkapkan aliran [Cipta dan konfigurasikan aplikasi](/open/dingstart/create-application).

## Langkah 1: Dapatkan kelayakan aplikasi

1. Pilih aplikasi sasaran untuk masuk ke halaman butiran aplikasi, kemudian klik **Maklumat asas** > **Kelayakan dan maklumat asas**.
2. Dapatkan client ID dan Client Secret.

## Langkah 2: Tambah kebenaran API

Klik **Konfigurasi pembangunan** > **Urus kebenaran**. Dalam kotak carian kebenaran, masukkan `Calendar.Event.Write` dan `Calendar.Event.Read` masing-masing, kemudian mohon kebenaran tersebut.

## Langkah 3: Dapatkan access token aplikasi

<Warning>
Untuk butiran tentang perbezaan antara Server API, sila lihat Server API lama berbanding API baharu. Semua API di bawah menggunakan Server API. Untuk butiran muat turun SDK, sila lihat Muat turun SDK bahagian pelayan.
</Warning>

Gunakan client ID dan Client Secret daripada Langkah 1 untuk mendapatkan [access_token bagi aplikasi dalaman](/open/development/obtain-orgapp-token).

```java
 public void getAccessToken() throws Exception {
        Config config = new Config();
        config.protocol = "https";
        config.regionId = "central";
        com.aliyun.dingtalkoauth2_1_0.Client client = new com.aliyun.dingtalkoauth2_1_0.Client(config);
        GetAccessTokenRequest accessTokenRequest = new GetAccessTokenRequest()
                .setAppKey("ding*********hgn")
                .setAppSecret("9G_O**********xamBkhgGIO");
        GetAccessTokenResponse accessToken = client.getAccessToken(accessTokenRequest);
        System.out.println(JSON.toJSONString(accessToken.getBody()));
    }
```

<Note>
Dua senario pemadaman berikut disokong:
</Note>

- Apabila penganjur memadam acara (parameter userId dalam laluan menggunakan unionId penganjur), semua peserta akan menerima notifikasi pembatalan acara, dan acara tersebut dialih keluar daripada kalendar semua peserta.
- Apabila seorang peserta memadam acara (parameter userId dalam laluan menggunakan unionId peserta tersebut), acara hanya dialih keluar daripada kalendar peserta itu sendiri, dan peserta acara yang lain tidak terjejas.
