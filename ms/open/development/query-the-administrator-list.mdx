Panggil API ini untuk menanyakan senarai admin.

## Penerangan panggilan API

API ini tidak dihadkan oleh Skop kebenaran Kenalan.

## Permintaan

| **Maklumat asas** | |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/topapi/user/listadmin |
| Kaedah HTTP | POST |
| Jenis aplikasi disokong | appType-Aplikasi dalamanappType-Aplikasi perusahaan pihak ketiga |
| Kebenaran diperlukan | permission-qyapi_get_member-Kebenaran membaca maklumat pengguna |

### Parameter pertanyaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | bE74xxxx | Kelayakan aplikasi yang digunakan untuk memanggil API ini.   - Untuk Aplikasi dalaman, dapatkan melalui API untuk mendapatkan access_token Aplikasi dalaman. - Untuk Aplikasi perusahaan pihak ketiga, dapatkan melalui API untuk mendapatkan access_token perusahaan pihak ketiga. |

### Contoh permintaan

```curl
curl -X POST "https://api.dingtalk.io/topapi/user/listadmin" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=ba1dfdcc-8a86-4b95-bcb8-af2f9f91ae12'
```

Java

```text
DingTalkClient client = new DefaultDingTalkClient("https://api.dingtalk.io/topapi/user/listadmin");
OapiUserListadminRequest req = new OapiUserListadminRequest();
OapiUserListadminResponse rsp = client.execute(req, access_token);
System.out.println(rsp.getBody());
```

Python

```python
import dingtalk.api

req=dingtalk.api.OapiUserListadminRequest("https://api.dingtalk.io/topapi/user/listadmin")
try:
  resp= req.getResponse(access_token)
  print(resp)
except Exception,e:
  print(e)
```

PHP

```php
include "TopSdk.php";
date_default_timezone_set('Asia/Shanghai');

$c = new DingTalkClient(DingTalkConstant::$CALL_TYPE_OAPI, DingTalkConstant::$METHOD_POST , DingTalkConstant::$FORMAT_JSON);
$req = new OapiUserListadminRequest;
$resp = $c->execute($req, $access_token, "https://api.dingtalk.io/topapi/user/listadmin");
```

C#

```text
IDingTalkClient client = new DefaultDingTalkClient("https://api.dingtalk.io/topapi/user/listadmin");
OapiUserListadminRequest req = new OapiUserListadminRequest();
OapiUserListadminResponse rsp = client.Execute(req, access_token);
Console.WriteLine(rsp.Body);
```

## Respons

### Isi respons

| Nama | Jenis | Contoh | Penerangan |
| --- | --- | --- | --- |
| request_id | String | 4f9md9obopn2 | ID permintaan. |
| errcode | Number | 0 | Kod pulangan. |
| errmsg | String | ok | Penerangan kod pulangan. |
| result | ListAdminResponse[] |  | Hasil yang dikembalikan. |
| userid | String | 203xxxx1 | userid admin tersebut. |
| sys_level | Number | 1 | Peranan admin:   - **1**: Super Admin - **2**: Sub Admin |

### Contoh isi respons

```json
{
  "errcode": 0,
  "errmsg":"ok",
  "result": [
    {
      "sys_level": 2,

  "request_id": "4f9md9obopn2"
}
```

### Kod ralat

Jika ralat berlaku semasa anda memanggil API ini, cari penyelesaiannya dalam dokumen [Kod ralat global](/ms/open/development/server-api-error-codes-1) berdasarkan mesej ralat.

| Kod ralat (errcode) | Mesej ralat (errmsg) | Penyelesaian |
| --- | --- | --- |
| 43007 | Authorization required | Semak sama ada access_token mempunyai kebenaran untuk melakukan tindakan tersebut. |
| -1 | System busy | Cuba lagi kemudian. |
