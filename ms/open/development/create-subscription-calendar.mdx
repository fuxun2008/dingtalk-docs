Panggil API ini untuk mencipta kalendar langganan.

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/calendar/users/{userId}/subscribedCalendars` |
| Kaedah HTTP | POST |
| Jenis aplikasi yang disokong | appType-Aplikasi dalaman　appType-Aplikasi perusahaan pihak ketiga　appType-Aplikasi peribadi pihak ketiga |
| Kebenaran yang diperlukan | permission-Calendar.Calendar.Write-Kebenaran tulis untuk aplikasi Kalendar |

### Pengepala permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses yang digunakan untuk memanggil API ini. Dapatkan seperti berikut:   - Untuk aplikasi dalaman, panggil API [Dapatkan access token aplikasi dalaman](/open/development/obtain-the-access-token-of-an-internal-app#). - Untuk aplikasi perusahaan pihak ketiga, panggil API [Dapatkan access token bagi perusahaan yang memberi kebenaran kepada aplikasi pihak ketiga](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#). - Untuk aplikasi peribadi pihak ketiga, panggil API [Dapatkan token pengguna](/open/development/obtain-user-token#). |

### Parameter laluan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| userId | String | Ya | unionId bagi pencipta kalendar.   - Untuk aplikasi dalaman atau aplikasi perusahaan pihak ketiga, panggil API [Tanya butiran pengguna](/open/development/query-user-details#) untuk mendapatkan nilai parameter unionid. - Untuk aplikasi peribadi pihak ketiga, panggil API [Dapatkan profil kenalan pengguna](/open/development/dingtalk-retrieve-user-information#) untuk mendapatkan nilai parameter unionId. |

### Isi permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| name | String | Ya | Nama kalendar langganan. |
| description | String | Tidak | Penerangan kalendar langganan. Panjang maksimum: 1,024 aksara. |
| managers | Array of String | Tidak | Nilai unionId bagi penyunting bersama kalendar langganan.   - Untuk aplikasi dalaman atau aplikasi perusahaan pihak ketiga, panggil API [Tanya butiran pengguna](/open/development/query-user-details#) untuk mendapatkan nilai parameter unionid. - Untuk aplikasi peribadi pihak ketiga, panggil API [Dapatkan profil kenalan pengguna](/open/development/dingtalk-retrieve-user-information#) untuk mendapatkan nilai parameter unionId. |
| subscribeScope | Object | Ya | Objek yang boleh melanggan kalendar ini. |
| unionIds | Array of String | Tidak | Nilai unionId bagi pengguna yang boleh melanggan kalendar ini.   - Untuk aplikasi dalaman atau aplikasi perusahaan pihak ketiga, panggil API [Tanya butiran pengguna](/open/development/query-user-details#) untuk mendapatkan nilai parameter unionid. - Untuk aplikasi peribadi pihak ketiga, panggil API [Dapatkan profil kenalan pengguna](/open/development/dingtalk-retrieve-user-information#) untuk mendapatkan nilai parameter unionId. |
| openConversationIds | Array of String | Tidak | Senarai OpenConversationId bagi kumpulan yang boleh melanggan kalendar ini.   - Untuk aplikasi dalaman, panggil API [Dapatkan OpenConversationId bagi Sembang Kumpulan](/open/development/obtain-group-openconversationid#) untuk mendapatkan nilai parameter openConversationId. - Untuk aplikasi perusahaan pihak ketiga, panggil API [Cipta kumpulan](https://open.dingtalk.com/document/development/create-a-scene-group-v2#) untuk mendapatkan nilai parameter open_conversation_id.   - unionId pencipta acara mestilah tergolong dalam kumpulan yang dinyatakan dalam openConversationIds atau organisasi yang dinyatakan dalam corpIds. - Parameter ini tidak diperlukan untuk aplikasi peribadi pihak ketiga. |
| corpIds | Array of String | Tidak | Senarai corpId organisasi yang boleh melanggan kalendar ini. Log masuk ke [Konsol Pembangun DingTalk](https://open-dev.dingtalk.io/#/) dan lihat ID organisasi anda pada Laman Utama.  unionId pencipta acara mestilah tergolong dalam organisasi yang dinyatakan oleh corpId atau kumpulan yang dinyatakan dalam openConversationIds. |
