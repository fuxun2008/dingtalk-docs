API ini membatalkan tugasan belum selesai secara pukal dalam Pusat Proses. Hantar permintaan POST dengan medan perniagaan seperti processInstanceId, activityId dan activityIds.

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/v1.0/workflow/processCentres/tasks/cancel |
| Kaedah HTTP | POST |
| Jenis aplikasi yang disokong | appType-Aplikasi dalaman　appType-Aplikasi perusahaan pihak ketiga |
| Kebenaran | permission-Workflow.Instance.Write-Kebenaran tulis instans aliran kerja |

### Pengepala permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Dapatkan kredensial ini seperti berikut:   - Untuk Aplikasi dalaman, panggil API [Dapatkan access token aplikasi dalaman](/ms/open/development/obtain-the-access-token-of-an-internal-app). - Untuk Aplikasi perusahaan pihak ketiga, panggil API untuk mendapatkan access token organisasi yang telah memberi kebenaran kepada aplikasi pihak ketiga. |

### Isi permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| processInstanceId | String | Ya | ID instans aliran kerja Kelulusan OA. Panggil API [Cipta instans](/ms/open/development/create-a-ticket-approval-instance) untuk mendapatkan nilai processInstanceId. |
| activityId | String | Ya | ID kumpulan tugasan. Dapatkan ID ini dengan memanggil API [Cipta tugasan belum selesai dalam Pusat Proses](/ms/open/development/create-pending-tasks-in-process-center). Panjang maksimum: 512 aksara.  Tetapkan nilai ini secara eksplisit semasa memanggil API untuk mencipta tugasan belum selesai dalam Pusat Proses. |
| activityIds | Array of String | Tidak | Senarai ID kumpulan tugasan. Dapatkan ID ini dengan memanggil API [Cipta tugasan belum selesai dalam Pusat Proses](/ms/open/development/create-pending-tasks-in-process-center). |
