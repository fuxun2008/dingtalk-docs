Panggil API ini untuk mendapatkan maklumat asas pengguna dalam jabatan tertentu.

## Penerangan panggilan API

- API ini hanya mengembalikan medan userId dan name pengguna. Untuk mendapatkan maklumat lengkap pengguna, lihat [Dapatkan maklumat lengkap pengguna jabatan](/ms/open/development/queries-the-complete-information-of-a-department-user).
- API ini hanya mengembalikan maklumat asas pengguna dalam jabatan semasa. Maklumat pengguna dalam sub-jabatan tidak dikembalikan.

## Permintaan

| **Maklumat asas** | |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/topapi/user/listsimple |
| Kaedah HTTP | POST |
| Jenis aplikasi yang disokong | appType-Aplikasi dalaman appType-Aplikasi perusahaan pihak ketiga |
| Kebenaran | permission-qyapi_get_department_member-Kebenaran Telah dibaca untuk pengguna jabatan Kenalan |

### Parameter pertanyaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | bE74xxxx | Kelayakan aplikasi yang digunakan untuk memanggil API ini.   - Untuk aplikasi dalaman, dapatkan melalui API yang mendapatkan [access_token aplikasi dalaman](/ms/open/development/obtain-orgapp-token). - Untuk aplikasi perusahaan pihak ketiga, dapatkan melalui API yang mendapatkan access_token perusahaan pihak ketiga. |

### Isi permintaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| dept_id | Nombor | Ya | 10 | ID jabatan. Untuk jabatan root, hantar 1. Panggil [Dapatkan senarai jabatan](/ms/open/development/user-management-acquires-the-list-departments) untuk mendapatkan nilai dept_id. |
| cursor | Nombor | Ya | 0 | Cursor untuk penomboran halaman. Hantar 0 untuk permintaan pertama, dan hantar nilai next_cursor daripada respons untuk permintaan seterusnya. |
| size | Nombor | Ya | 10 | Saiz halaman. Nilai maksimum ialah 100. |
| order_field | String | Tidak | modify_desc | Peraturan penyusunan bagi pengguna jabatan. Nilai lalai ialah **custom**.   - **entry_asc**: susun mengikut masa menyertai jabatan secara menaik. - **entry_desc**: susun mengikut masa menyertai jabatan secara menurun. - **modify_asc**: susun mengikut masa pengubahsuaian maklumat jabatan secara menaik. - **modify_desc**: susun mengikut masa pengubahsuaian maklumat jabatan secara menurun. - **custom**: penyusunan tersuai (disusun mengikut pinyin jika tidak ditentukan). |
| contain_access_limit | Boolean | Tidak | false | Sama ada untuk mengembalikan pengguna yang mempunyai akses terhad.   - **true**: Ya - **false**: Tidak |
| language | String | Tidak | zh_CN | Bahasa Kenalan.   - **zh_CN**: Bahasa Cina (lalai). - **en_US**: Bahasa Inggeris. |

### Contoh permintaan

```curl
curl -X POST "https://api.dingtalk.io/topapi/user/listsimple" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=c1f2d110-4e7c-4536-a340-06652613e0c1' \
-d 'contain_access_limit=false' \
-d 'cursor=0' \
-d 'dept_id=10' \
-d 'language=zh_CN' \
-d 'order_field=modify_desc' \
-d 'size=10'
```

Java

```text
DingTalkClient client = new DefaultDingTalkClient("https://api.dingtalk.io/topapi/user/listsimple");
OapiUserListsimpleRequest req = new OapiUserListsimpleRequest();
req.setDeptId(10L);
req.setCursor(0L);
req.setSize(10L);
req.setOrderField("modify_desc");
req.setContainAccessLimit(false);
req.setLanguage("zh_CN");
OapiUserListsimpleResponse rsp = client.execute(req, access_token);
System.out.println(rsp.getBody());
```

## Respons

### Isi respons

| Nama | Jenis | Contoh | Penerangan |
| --- | --- | --- | --- |
| request_id | String | 4f9md9obopn2 | ID permintaan. |
| errcode | Nombor | 0 | Kod pemulangan. 0 menunjukkan kejayaan. |
| errmsg | String | ok | Penerangan kod pemulangan. |
| result | PageResult |  | Hasil yang dikembalikan. |
| has_more | Boolean | true | Sama ada terdapat lebih banyak data.   - **true**: Ya - **false**: Tidak |
| next_cursor | Nombor | 10 | Cursor untuk halaman seterusnya. Jika has_more bernilai false, tiada lagi data bernombor halaman yang tersedia. |
| list | ListUserSimpleResponse[] |  | Senarai maklumat pengguna. |
| userid | String | zxxxxx | userid pengguna. |
| name | String | Zhang San | Nama pengguna. |

### Kod ralat

Jika ralat berlaku semasa anda memanggil API ini, cari penyelesaiannya dalam dokumen [Kod ralat global](/ms/open/development/server-api-error-codes-1) berdasarkan mesej ralat.

| Kod ralat (errcode) | Mesej ralat (errmsg) | Penyelesaian |
| --- | --- | --- |
| 400002 | Invalid parameter | Pastikan parameter diisi mengikut keperluan di atas. |
| 60003 | The department is not found | Pastikan ID jabatan adalah betul. |
| 40069 | Invalid size | Laraskan saiz halaman. |
| 40068 | Invalid offset | Laraskan offset. |
| -1 | System busy | Cuba Lagi kemudian. |
