description: "Panggil API ini untuk menyerahkan organisasi yang dimiliki oleh Akaun Syarikat kepada Akaun Syarikat lain, dengan penerima secara automatik menyertai organisasi jika belum menjadi ahli."
---

Panggil API ini untuk menyerahkan organisasi yang dimiliki oleh Akaun Syarikat dalam Organisasi Anda kepada Akaun Syarikat lain. Jika akaun penerima tidak tergolong dalam organisasi tersebut, ia akan ditambahkan secara automatik.

## Penerangan panggilan API

Sebagai contoh, Organisasi DingTalk A mempunyai dua Akaun Syarikat, iaitu Akaun Syarikat A1 dan Akaun Syarikat A2. Akaun Syarikat A1 adalah pencipta organisasi lain yang dinamakan Organisasi DingTalk B (yang boleh dilihat dalam OA admin console organisasi ujian semasa di bawah Keselamatan dan Kebenaran > Senarai Super Admin). Panggil API ini untuk menukar pencipta Organisasi DingTalk B daripada Akaun Syarikat A1 kepada Akaun Syarikat A2.

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/v1.0/contact/orgAccounts/mainAdministrators/change |
| Kaedah HTTP | POST |
| Jenis aplikasi disokong | appType-Aplikasi dalaman |
| Kebenaran diperlukan | permission-Contact.OrgAccountSecurity.ReadWrite-Kebenaran baca dan tulis untuk data keselamatan Akaun Syarikat Kenalan |

### Pengepala permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Dapatkan dengan memanggil API [Dapatkan access token aplikasi dalaman](/open/development/obtain-the-access-token-of-an-internal-app#). |

### Isi permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| sourceUserId | String | Ya | ID pengguna Akaun Syarikat sumber. Dapatkan dengan salah satu daripada empat cara berikut:   - [Dapatkan ID pengguna melalui nombor telefon mudah alih](/open/development/obtain-the-userid-of-your-mobile-phone-number#) - [Cipta Akaun Syarikat SSO](/open/development/create-an-sso-account#) - [Cipta Akaun Syarikat bina sendiri DingTalk](/open/development/create-dingtalk-user-created-dedicated-account#) - [Jemput Akaun Syarikat daripada organisasi lain untuk menyertai](/open/development/invite-other-organization-specific-accounts-to-join#) |
| targetUserId | String | Ya | ID pengguna akaun khusus sasaran. Dapatkan dengan salah satu daripada empat cara berikut:   - [Dapatkan ID pengguna melalui nombor telefon mudah alih](/open/development/obtain-the-userid-of-your-mobile-phone-number#) - [Cipta Akaun Syarikat SSO](/open/development/create-an-sso-account#) - [Cipta Akaun Syarikat bina sendiri DingTalk](/open/development/create-dingtalk-user-created-dedicated-account#) - [Jemput Akaun Syarikat daripada organisasi lain untuk menyertai](/open/development/invite-other-organization-specific-accounts-to-join#) |
| effectCorpId | String | Ya | ID organisasi bagi organisasi yang akan diserahkan. Untuk maklumat lanjut, lihat Konsep asas - [CorpId](/open/dingstart/basic-concepts-beta#section-bbk-mv0-oxd). |
