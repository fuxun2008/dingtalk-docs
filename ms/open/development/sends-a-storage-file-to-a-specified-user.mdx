Panggil API ini untuk menghantar fail kepada pengguna tertentu sebagai aplikasi.

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/v1.0/convFile/apps/conversations/files/send |
| Kaedah HTTP | POST |
| Jenis aplikasi yang disokong | appType-Aplikasi dalaman　appType-Aplikasi perusahaan pihak ketiga |
| Kebenaran diperlukan | permission-ConvFile.File.Send-Kebenaran menghantar fail Kumpulan |

### Pengepala permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Dapatkan melalui salah satu kaedah berikut:   - Untuk aplikasi dalaman, panggil API [Dapatkan access token aplikasi dalaman](/open/development/obtain-the-access-token-of-an-internal-app#). - Untuk aplikasi perusahaan pihak ketiga, panggil API [Dapatkan access token organisasi yang diberi kuasa kepada aplikasi pihak ketiga](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#). |

### Parameter kueri

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| unionId | String | Ya | unionId bagi pengguna yang menerima fail. Untuk mendapatkan nilai ini, panggil API [Tanya butiran pengguna](/open/development/query-user-details#). |

### Isi permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| spaceId | String | Ya | ID ruang tempat fail berada. Panggil API [Tambah ruang](/open/development/add-space#) untuk mendapatkan nilai parameter id. |
| dentryId | String | Ya | ID fail. Panggil API [Dapatkan senarai fail atau folder](https://open.dingtalk.com/document/development/obtain-the-file-list-storage#) untuk mendapatkan nilai parameter id. |

## Respons

### Isi respons

| Nama | Jenis | Penerangan |
| --- | --- | --- |
| file | Object | Maklumat tentang fail yang dihantar ke perbualan sasaran. |
| id | String | ID fail. |
| conversationId | String | ID perbualan tempat fail berada. |
| spaceId | String | ID ruang tempat fail berada. |
| parentId | String | ID folder induk tempat fail berada. Bagi folder root, parameter ini bernilai 0. |
| type | String | Jenis fail.   - **FILE**: Fail - **FOLDER**: Folder       API ini hanya boleh menghantar fail. |
| name | String | Nama fail. |
| size | Long | Saiz fail, dalam bait. |
| path | String | Laluan fail. |
| version | Long | Versi fail. |
| status | String | Status fail.   - **NORMAL**: Normal - **DELETED**: Dipadam - **EXPIRED**: Tamat tempoh |
| extension | String | Sambungan fail. |
| creatorId | String | unionId pencipta. |
| modifierId | String | unionId pengubah suai. |
| createTime | String | Masa penciptaan dalam format ISO 8601. Contohnya, 2022-07-29T14:55Z. |
| modifiedTime | String | Masa pengubahsuaian dalam format ISO 8601. Contohnya, 2022-07-29T14:55Z. |
| uuid | String | uuid perniagaan.      API ini tidak mengembalikan medan ini. |
