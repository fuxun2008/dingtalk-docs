Panggil API ini untuk mengemas kini status mesej Notifikasi Kerja OA.

## Penerangan panggilan API

- API ini direka untuk Notifikasi Kerja OA dan mengemas kini status kelulusan secara real-time.
- API ini hanya boleh mengemas kini bar status bagi Notifikasi Kerja yang dihantar dalam tempoh 7 hari lepas.

## Permintaan

| **Maklumat asas** | |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/topapi/message/corpconversation/status_bar/update |
| HTTP Method | POST |
| Jenis aplikasi yang disokong | appType-Internal appappType-Third-party enterprise app |
| Kebenaran yang diperlukan | permission-qyapi_base-Basic permissions required to call enterprise APIs |

### Parameter query

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | bE74xxxx | Kelayakan aplikasi yang digunakan untuk memanggil API ini.   - Bagi aplikasi dalaman, dapatkan dengan memanggil API untuk mendapatkan [access_token aplikasi dalaman](/open/development/obtain-orgapp-token). - Bagi aplikasi perusahaan pihak ketiga, dapatkan dengan memanggil API untuk mendapatkan access_token perusahaan pihak ketiga. |

### Isi permintaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| agent_id | Number | Ya | 123 | AgentId aplikasi mikro yang digunakan untuk menghantar mesej.   - Bagi aplikasi dalaman, lihat pada halaman butiran aplikasi di [Developer Backend](https://open-dev.dingtalk.io/#/appMgr/inner/h5/836390886/1). - Bagi aplikasi perusahaan pihak ketiga, dapatkan dengan memanggil API untuk mendapatkan maklumat kebenaran perusahaan. |
| task_id | Number | Ya | 11 | ID tugas Notifikasi Kerja. Dapatkan nilai task_id dengan memanggil API [Hantar Notifikasi Kerja](/open/development/asynchronous-sending-of-enterprise-session-messages). |
| status_value | String | Ya | Accepted | Nilai bar status. |
| status_bg | String | Tidak | 0xFF78C06E | Warna latar belakang bar status. Kami syorkan format 0xFF diikuti dengan nilai warna enam digit. |

### Contoh permintaan

```curl
curl -X POST "https://api.dingtalk.io/topapi/message/corpconversation/status_bar/update" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=e4bbxxxxe7683' \
-d 'agent_id=123' \
-d 'status_bg=0xFFF65E5E' \
-d 'status_value=Completed' \
-d 'task_id=1111'
```

Java

```text
DingTalkClient client = new DefaultDingTalkClient("https://api.dingtalk.io/topapi/message/corpconversation/status_bar/update");
OapiMessageCorpconversationStatusBarUpdateRequest req = new OapiMessageCorpconversationStatusBarUpdateRequest();
req.setAgentId(123L);
req.setTaskId(1111L);
req.setStatusValue("Completed");
req.setStatusBg("0xFFF65E5E");
OapiMessageCorpconversationStatusBarUpdateResponse rsp = client.execute(req, access_token);
System.out.println(rsp.getBody());
```

### Kod ralat

Jika ralat berlaku semasa anda memanggil API ini, cari mesej ralat dalam dokumen [Kod ralat global](/open/development/server-api-error-codes-1) untuk mendapatkan penyelesaian.

| Kod ralat (errorcode) | Mesej ralat (errmsg) | Penyelesaian |
| --- | --- | --- |
| 40056 | Invalid agentid | Sahkan bahawa agentId adalah betul. |
| 40035 | Invalid parameter | Sahkan bahawa taskId adalah betul. |
| 41052 | Too many recipients in this delivery; sending results will no longer be returned. | - Kurangkan bilangan penerima bagi Notifikasi Kerja tersebut. - Semak sama ada Notifikasi Kerja tersebut telah selesai dihantar. Ralat ini berlaku jika penghantaran masih dalam proses. |
| 500 | System error | Berlaku ralat sistem yang tidak diketahui. |
