---
title: "Hantar mesej bot secara pukal kepada berbilang perbualan mesej terus"
description: "Panggil API ini untuk menghantar mesej bot secara pukal kepada sehingga 20 perbualan bot satu-lawan-satu, sesuai untuk notifikasi organisasi dan penghantaran amaran sistem."
---

Panggil API ini untuk menghantar mesej bot secara pukal kepada berbilang perbualan Person-to-Bot (Direct Message antara pengguna dan bot). API ini sesuai untuk senario yang memerlukan penghantaran mesej bot kepada berbilang pengguna (sehingga 20 orang) secara pukal, seperti notifikasi organisasi dan penghantaran amaran sistem.

## Penerangan panggilan API

API ini menyokong bot bagi aplikasi dalaman. Untuk maklumat lanjut, lihat [Konfigurasikan bot organisasi](/ms/open/dingstart/configure-the-robot-application).

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/v1.0/robot/oToMessages/batchSend |
| Kaedah HTTP | POST |
| Jenis aplikasi yang disokong | appType-Aplikasi dalaman　appType-Aplikasi perusahaan pihak ketiga |
| Kebenaran | permission-qyapi_robot_sendmsg-Kebenaran untuk menghantar mesej menggunakan bot dalam organisasi Anda |

### Pengepala permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses yang digunakan untuk memanggil API ini. Dapatkan dengan cara berikut:   - Untuk aplikasi dalaman, panggil API [Dapatkan access token bagi aplikasi dalaman](/ms/open/development/obtain-the-access-token-of-an-internal-app#). - Untuk aplikasi perusahaan pihak ketiga, panggil API [Dapatkan access token organisasi yang diberi kuasa kepada aplikasi pihak ketiga](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#). |

### Isi permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| robotCode | String | Ya | Kod bot. Parameter ini mesti menggunakan robotCode bagi bot aplikasi dalaman. Untuk maklumat lanjut, lihat [ID Bot](/ms/open/development/development-robot-overview#447ec33014hrl). |
| userIds | Array of String | Ya | Senarai ID pengguna yang menerima mesej. Anda boleh menghantar sehingga 20 ID pengguna pada satu masa. Anda boleh mendapatkan ID pengguna dengan memanggil API [Tanya butiran pengguna](/ms/open/development/query-user-details#) atau API [Dapatkan senarai ID pengguna dalam jabatan](/ms/open/development/query-the-list-of-department-userids#). |
| msgKey | String | Ya | Kunci templat mesej. Untuk maklumat lanjut, lihat [Jenis mesej yang disokong oleh bot organisasi](https://open.dingtalk.com/document/dingstart/types-of-messages-sent-by-robots#). |
| msgParam | String | Ya | Parameter templat mesej. Untuk maklumat lanjut, lihat [Jenis mesej yang disokong oleh bot organisasi](https://open.dingtalk.com/document/dingstart/types-of-messages-sent-by-robots#). |
