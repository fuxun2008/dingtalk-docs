Panggil API ini untuk menghantar pemberitahuan kerja menggunakan templat mesej.

## Penerangan panggilan API

<Warning>
Sebelum memanggil API ini, pastikan templat mesej telah dikonfigurasikan dan diaktifkan dalam bahagian belakang pembangun. Untuk butiran, lihat Cipta dan konfigurasikan templat mesej.
</Warning>

- Bilangan maksimum penerima bagi setiap penghantaran ialah 1,000.
- Bilangan maksimum penerima bagi setiap minit ialah 5,000.
- Hanya satu mesej dengan kandungan yang sama boleh dihantar kepada pekerja yang sama setiap hari.
- Setiap pekerja boleh menerima maksimum 100 mesej setiap hari.

## Permintaan

| **Maklumat asas** | |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/topapi/message/corpconversation/sendbytemplate |
| Kaedah HTTP | POST |
| Jenis aplikasi disokong | appType-Aplikasi perusahaan pihak ketiga |
| Kebenaran | permission-qyapi_base-Kebenaran asas diperlukan untuk memanggil API perusahaan |

### Parameter pertanyaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | Be3xxxx | Kelayakan aplikasi untuk memanggil API ini. Dapatkan dengan memanggil API untuk mendapatkan access_token bagi perusahaan pihak ketiga. |

### Isi permintaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| agent_id | Number | Ya | 948060598 | agentid bagi aplikasi. Panggil API untuk mendapatkan maklumat kebenaran perusahaan untuk mendapatkannya. |
| template_id | String | Ya | e27a9eed42b34a14a2xxxx | ID templat mesej. Lihat pada halaman **Pengurusan Pembangunan** aplikasi anda dalam [bahagian belakang pembangun](https://open-dev.dingtalk.io/#/isveapp). |
| userid_list | String | Tidak | "123,456" | Senarai ID pengguna penerima. Panjang maksimum senarai ialah 5,000. |
| dept_id_list | String | Tidak | 421897262 | Senarai ID jabatan penerima. Panjang maksimum senarai ialah 500.  **Penting**  **dept_id_list** dan **userid_list** tidak boleh kosong serentak. |
| data | String | Tidak | `{"name":"Taobao 6","name2":"http://www.taobao.com"}` | Nilai yang diberikan kepada parameter dinamik templat mesej. **Nota**  Kedua-dua key dan value mestilah string. |

### Contoh permintaan

```curl
curl -X POST "https://api.dingtalk.io/topapi/message/corpconversation/sendbytemplate" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=bdefeb04-96ad-40d9-bb92-a62a99d2e8d3' \
-d 'agent_id=123' \
-d 'data=%7B%5C%22Name%5C%22%3A%5C%22John%5C%22%7D' \
-d 'dept_id_list=%5C%22123%2C456%5C%22' \
-d 'template_id=xxxx' \
-d 'userid_list=%5C%22123%2C456%5C%22'
```

## Respons

### Isi respons

| Nama | Jenis | Contoh | Penerangan |
| --- | --- | --- | --- |
| errmsg | String | ok | Penerangan kod pemulangan. |
| errcode | Number | 0 | Kod pemulangan. |
| task_id | Number | 282632271040 | ID tugas penghantaran tak segerak yang dicipta. |
| request_id | String | 52izpwz1p0iw | ID permintaan. |

### Contoh isi respons

```json
{
  "errcode": 0,
  "errmsg": "ok",
  "task_id": 282632271040,
  "request_id": "52izpwz1p0iw"
}
```

### Kod ralat

Jika ralat dikembalikan semasa memanggil API ini, cari penyelesaian dalam dokumen [Kod ralat global](/ms/open/development/server-api-error-codes-1) berdasarkan mesej ralat.

| Kod ralat (errorcode) | Penerangan mesej ralat (errmsg) | Penyelesaian |
| --- | --- | --- |
| 885001 | Templat mesej tidak wujud. | Sahkan sama ada templat mesej adalah betul. |
| 885006 | Templat mesej tidak tersedia. | Templat mesej mesti diluluskan terlebih dahulu. |
| 400002 | agentId tidak sah. | Sahkan sama ada agentId adalah betul. |
| 500 | Ralat sistem. | Ralat sistem yang tidak diketahui berlaku. |
