Panggil API ini untuk memadam paparan penapis tertentu beserta semua syarat penapisnya pada helaian kerja yang dinyatakan. Ini berguna untuk membersihkan paparan penapis yang tidak lagi diperlukan—contohnya, mengalih keluar paparan penapisan data sementara selepas projek tamat, atau memadam paparan lama untuk membebaskan ruang apabila had 20 paparan penapis bagi setiap helaian kerja tercapai.

## Penerangan panggilan API

Pemadaman ini tidak menjejaskan penapis global atau paparan penapis lain.

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/doc/workbooks/{workbookId}/sheets/{sheetId}/filterViews/{filterViewId}` |
| Kaedah HTTP | DELETE |
| Jenis aplikasi yang disokong | appType-Aplikasi dalaman |
| Kebenaran yang diperlukan | permission-Document.Workbook.Write-Kebenaran tulis DingTalk Spreadsheet |

### Header permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Panggil API [Dapatkan access token aplikasi dalaman](/ms/open/development/obtain-the-access-token-of-an-internal-app) untuk mendapatkannya. |

### Parameter laluan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| workbookId | String | Ya | ID fail spreadsheet. `nodeId(dentryUuid)` yang dikembalikan oleh [Knowledge Base API](/ms/open/development/knowledge-base-overview) adalah `workbookId` spreadsheet tersebut. Dapatkannya dengan memanggil API [Dapatkan nod](https://open.dingtalk.com/document/orgapp/get-node) dan [Cipta dokumen Knowledge Base](/ms/open/development/create-team-space-document). |
| sheetId | String | Ya | ID atau nama helaian kerja. Panggil API [Dapatkan semua helaian kerja](/ms/open/development/obtain-all-worksheets) untuk mendapatkan nilai parameter `id` atau `name`. |
| filterViewId | String | Ya | ID paparan penapis. |

### Parameter pertanyaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| operatorId | String | Ya | unionId pengendali.   - Panggil API [Dapatkan maklumat pengguna melalui kod log masuk senyap](/ms/open/development/obtain-the-userid-of-a-user-by-using-the-log-free) untuk mendapatkan nilai parameter `unionid`. - Panggil API [Semak butiran pengguna](/ms/open/development/query-user-details) untuk mendapatkan nilai parameter `unionid`.       Jika pengendali tidak mempunyai kebenaran yang diperlukan, API akan mengembalikan ralat `The operator has no permission`. |
