---
title: "Cipta paparan penapis"
description: "Panggil API ini untuk mencipta paparan penapis pada Helaian Kerja sasaran dalam DingTalk Spreadsheet, dengan menetapkan nama paparan dan julat penapis; syarat penapis boleh dikonfigurasikan mengikut lajur selepas itu."
---

Panggil API ini untuk mencipta paparan penapis pada Helaian Kerja yang ditentukan dalam DingTalk Spreadsheet, dan untuk menetapkan nama paparan serta julat penapis. Selepas paparan dicipta, anda boleh mengkonfigurasikan syarat penapis lanjut untuk setiap lajur.

## Penerangan panggilan API

- Paparan penapis ialah kaedah penapisan data yang diperibadikan, berasingan daripada penapis global. Ia sesuai untuk senario kerjasama pelbagai pengguna di mana pengguna berbeza perlu melihat subset data yang berbeza.
- Setiap Helaian Kerja menyokong sehingga 20 paparan penapis.

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/doc/workbooks/{workbookId}/sheets/{sheetId}/filterViews` |
| Kaedah HTTP | POST |
| Jenis aplikasi disokong | appType-Aplikasi dalaman |
| Kebenaran diperlukan | permission-Document.Workbook.Write-Kebenaran tulis DingTalk Spreadsheet |

### Header permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kredensial akses untuk memanggil API ini. Panggil API [Dapatkan access token aplikasi dalaman](/open/development/obtain-the-access-token-of-an-internal-app) untuk mendapatkannya. |

### Parameter laluan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| workbookId | String | Ya | ID fail Spreadsheet. `nodeId(dentryUuid)` yang dikembalikan oleh [API Knowledge Base](/open/development/knowledge-base-overview) ialah `workbookId` Spreadsheet. Anda boleh mendapatkannya dengan memanggil API [Get node](https://open.dingtalk.com/document/orgapp/get-node) atau [Cipta dokumen knowledge base](/open/development/create-team-space-document). |
| sheetId | String | Ya | ID atau nama Helaian Kerja. Panggil API [Dapatkan semua Helaian Kerja](/open/development/obtain-all-worksheets) untuk mendapatkan nilai parameter id atau name. |

### Parameter pertanyaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| operatorId | String | Ya | unionId pengendali. - Panggil API [Dapatkan maklumat pengguna melalui kod Log masuk senyap](/open/development/obtain-the-userid-of-a-user-by-using-the-log-free) untuk mendapatkan nilai parameter unionid. - Panggil API [Query user details](/open/development/query-user-details) untuk mendapatkan nilai parameter unionid.       Jika pengendali tidak mempunyai kebenaran, API akan mengembalikan ralat `The operator has no permission`. |

### Isi permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| name | String | Ya | Nama paparan penapis. |
| range | String | Ya | Julat paparan penapis, dinyatakan dalam notasi A1. Contohnya, `A1:D10` menunjukkan kawasan dari A1 hingga D10. Baris pertama julat penapis digunakan sebagai baris pengepala dan tidak disertakan dalam pengiraan penapis. |
| criteria | `Map<String, Object>` | Tidak | Menetapkan syarat penapis untuk setiap lajur semasa paparan dicipta. Kunci ialah offset lajur (relatif kepada lajur pertama julat, bermula dari 0), dan nilai ialah objek syarat penapis. Jika tidak diberikan, paparan penapis kosong akan dicipta. |
|  | Object | Tidak | Syarat penapis untuk lajur semasa. |
| filterType | String | Tidak | Jenis penapis. Nilai sah:   - **values**: Tapis mengikut nilai. - **color**: Tapis mengikut warna. - **condition**: Tapis mengikut syarat. |
| visibleValues | Array of String | Tidak | Nilai yang boleh dilihat. |
| conditions | Array | Tidak | Senarai syarat penapis apabila menapis mengikut syarat. Hanya sah apabila `filterType` ditetapkan kepada `condition`. Setiap objek syarat mengandungi medan `operator` dan `value`. |
| operator | String | Tidak | Operator syarat. Nilai sah:   - **equal**: Sama dengan. - **not-equal**: Tidak sama dengan. - **contains**: Mengandungi. - **not-contains**: Tidak mengandungi. - **starts-with**: Bermula dengan. - **not-starts-with**: Tidak bermula dengan. - **ends-with**: Berakhir dengan. - **not-ends-with**: Tidak berakhir dengan. - **greater**: Lebih besar daripada. - **greater-equal**: Lebih besar atau sama dengan. - **less**: Kurang daripada. - **less-equal**: Kurang atau sama dengan. |
| value | String | Tidak | Nilai syarat. |
| conditionOperator | String | Tidak | Hubungan logik antara pelbagai syarat. Nilai sah: `and`, `or`. Nilai lalai ialah `and`. Hanya sah apabila `filterType` ditetapkan kepada `condition` dan pelbagai syarat diberikan. |
| backgroundColor | String | Tidak | Nilai warna (heksadesimal, contohnya `#FF0000`) apabila menapis mengikut warna latar belakang. Hanya sah apabila `filterType` ditetapkan kepada `color`. Gunakan sama ada parameter ini atau `fontColor`. |
| fontColor | String | Tidak | Nilai warna (heksadesimal, contohnya `#FF0000`) apabila menapis mengikut warna fon. Hanya sah apabila `filterType` ditetapkan kepada `color`. Gunakan sama ada parameter ini atau `backgroundColor`. |
