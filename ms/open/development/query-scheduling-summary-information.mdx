Panggil API ini untuk menyemak ringkasan penjadualan syif pengguna dalam julat masa yang ditetapkan, termasuk nama syif, ID versi syif dan ID kumpulan kehadiran.

## Permintaan

| **Maklumat asas** | |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/topapi/attendance/schedule/shift/listbydays |
| Kaedah HTTP | POST |
| Jenis aplikasi yang disokong | appType-Aplikasi dalaman |
| Kebenaran yang diperlukan | permission-qyapi_attendance_group_manage-Kebenaran pengurusan kumpulan kehadiran |

### Parameter pertanyaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | 57cf92xxx | Kelayakan aplikasi yang digunakan untuk memanggil API ini. Dapatkannya dengan memanggil API [Dapatkan access_token Aplikasi dalaman](/ms/open/development/obtain-orgapp-token). |

### Isi permintaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| op_user_id | String | Ya | manager123 | ID pengguna bagi pengendali. |
| userids | String | Ya | user123,user456 | Senarai ID pengguna yang hendak ditanya. Pisahkan berbilang ID pengguna dengan koma. Setiap pertanyaan menyokong maksimum 20 ID pengguna. |
| from_date_time | Number | Ya | 1564985177000 | Unix timestamp bagi tarikh mula, dalam milisaat.  **Nota**  Julat masa tidak boleh melebihi 7 hari. |
| to_date_time | Number | Ya | 1564985177000 | Unix timestamp bagi tarikh tamat, dalam milisaat.  **Nota**  Julat masa tidak boleh melebihi 7 hari. |

### Contoh permintaan

```curl
curl -X POST "https://api.dingtalk.io/topapi/attendance/schedule/shift/listbydays" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=ecff22xxxx1f8d5d' \
-d 'from_date_time=1564985177000' \
-d 'op_user_id=dd_dd' \
-d 'to_date_time=1564985177000' \
-d 'userids=dd_test%2Ctl2342'
```

## Respons

### Isi respons

| Nama | Jenis | Contoh | Penerangan |
| --- | --- | --- | --- |
| result | TopDayScheduleShiftVo[] |  | Senarai hasil yang dikembalikan. |
| work_date | Date | 2020-12-14 00:00:00 | Hari bekerja. |
| shift_names | String[] | ["A"] | Nama syif. |
| userid | String | user123 | ID pengguna bagi pengguna. |
| shift_versions | Number[] | [9527] | ID versi syif. |
| shift_ids | Number[] | [9087] | ID syif. |
| group_id | Number | 7786 | ID kumpulan kehadiran. |
| corp_id | String | dinge8xxx | ID organisasi. |
| success | Boolean | true | Menunjukkan sama ada panggilan berjaya.   - **true**: Berjaya - **false**: Gagal |
| errcode | Number | 0 | Kod pemulangan. |
| errmsg | String | ok | Penerangan kod pemulangan. |
| request_id | String | 5fyefrdh2mf4 | ID permintaan. |
