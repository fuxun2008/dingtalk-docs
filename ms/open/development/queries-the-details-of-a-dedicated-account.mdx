title: "Dapatkan butiran pengguna Akaun Syarikat"
description: "Panggil API ini untuk mendapatkan butiran pengguna Akaun Syarikat di DingTalk, termasuk profil, jabatan, dan e-mel, khusus untuk organisasi yang mengaktifkan Akaun Syarikat."
---

Panggil API ini untuk mendapatkan maklumat terperinci pengguna Akaun Syarikat yang ditentukan. API ini hanya tersedia untuk organisasi yang telah membeli dan mengaktifkan Akaun Syarikat.

## Penerangan panggilan API

Cara untuk mendapatkan kebenaran seperti nombor telefon bimbit dan e-mel berbeza mengikut jenis aplikasi.

- Aplikasi dalaman

  Untuk mendapatkan maklumat nombor telefon bimbit dan e-mel pengguna, aplikasi dalaman perlu menambah kebenaran untuk mengakses nombor telefon bimbit dan e-mel dalam Kenalan. Untuk menambah kebenaran:

  Log masuk ke [DingTalk Developer Platform](https://open-dev.dingtalk.io/#/corpeapp) > **Internal development** > cari aplikasi yang memerlukan kebenaran tersebut > **Manage permissions** > **Contacts management**, pilih **Mobile number information of employees** dan **Email and other profile information**, kemudian klik Mohon kebenaran.

- Aplikasi perusahaan pihak ketiga

## Permintaan

| **Maklumat asas** | |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/topapi/v2/user/get |
| Kaedah HTTP | POST |
| Jenis aplikasi disokong | appType-Aplikasi dalaman, appType-Aplikasi perusahaan pihak ketiga |
| Kebenaran diperlukan | permission-qyapi_get_member-Kebenaran membaca maklumat pengguna |

### Parameter kueri

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | be3Fxxxx | Kelayakan aplikasi untuk memanggil API ini.   - Untuk aplikasi dalaman, dapatkan melalui API untuk mendapatkan [access_token aplikasi dalaman](/open/development/obtain-orgapp-token). - Untuk aplikasi perusahaan pihak ketiga, dapatkan melalui API untuk mendapatkan access_token perusahaan pihak ketiga. |

### Isi permintaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| userid | String | Ya | manager4220 | ID pengguna bagi pengguna tersebut. |
| language | String | Tidak | zh_CN | Bahasa untuk Kenalan.   - **zh_CN**: Bahasa Cina (lalai) - **en_US**: Bahasa Inggeris |
| login_id | String | Tidak | test | Nama log masuk. Apabila medan ini tidak kosong, userid akan diabaikan.  **Nota**  Carian mengikut nama log masuk hanya disokong untuk Akaun Syarikat terbina DingTalk milik Organisasi Anda. |

### Contoh permintaan

```curl
curl -X POST "https://api.dingtalk.io/topapi/v2/user/get" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=a894388c-a1b9-4ab4-8623-99cd0502019f' \
-d 'language=zh_CN' \
-d 'login_id=zhangsan' \
-d 'userid=zhangsan'
```

Java

```text
DingTalkClient client = new DefaultDingTalkClient("https://api.dingtalk.io/topapi/v2/user/get");
OapiV2UserGetRequest req = new OapiV2UserGetRequest();
req.setUserid("zhangsan");
req.setLanguage("zh_CN");
req.setLoginId("zhangsan");
OapiV2UserGetResponse rsp = client.execute(req, access_token);
System.out.println(rsp.getBody());
```

Python

```python
import dingtalk.api

req=dingtalk.api.OapiV2UserGetRequest("https://api.dingtalk.io/topapi/v2/user/get")

req.userid="zhangsan"
req.language="zh_CN"
req.login_id="zhangsan"
try:
  resp= req.getResponse(access_token)
  print(resp)
except Exception,e:
  print(e)
```

PHP

```php
include "TopSdk.php";
date_default_timezone_set('Asia/Shanghai');

$c = new DingTalkClient(DingTalkConstant::$CALL_TYPE_OAPI, DingTalkConstant::$METHOD_POST , DingTalkConstant::$FORMAT_JSON);
$req = new OapiV2UserGetRequest;
$req->setUserid("zhangsan");
$req->setLanguage("zh_CN");
$req->setLoginId("zhangsan");
$resp = $c->execute($req, $access_token, "https://api.dingtalk.io/topapi/v2/user/get");
```

C#

```text
IDingTalkClient client = new DefaultDingTalkClient("https://api.dingtalk.io/topapi/v2/user/get");
OapiV2UserGetRequest req = new OapiV2UserGetRequest();
req.Userid = "zhangsan";
req.Language = "zh_CN";
req.LoginId = "zhangsan";
OapiV2UserGetResponse rsp = client.Execute(req, access_token);
Console.WriteLine(rsp.Body);
```

### Kod ralat

Jika ralat berlaku semasa memanggil API ini, cari penyelesaian dalam dokumen [Global error codes](/open/development/server-api-error-codes-1) berdasarkan mesej ralat tersebut.

| Kod ralat (errcode) | Mesej ralat (errmsg) | Penyelesaian |
| --- | --- | --- |
| 33012 | Invalid userId | Semak sama ada userId adalah betul. |
| 400002 | Invalid parameter | Sahkan bahawa parameter dimasukkan seperti yang diperlukan. |
| -1 | The system is busy | Cuba lagi kemudian. |
