Dokumen ini memperkenalkan jenis dan senario penggunaan pemberitahuan mesej yang berbeza, keupayaan API pemberitahuan mesej, dan cara mengintegrasikannya.

## Jenis Pemberitahuan Mesej

DingTalk menyediakan jenis pemberitahuan mesej berikut:

- **Hantar Notifikasi Kerja Menggunakan Templat:**

  Templat mesej merupakan peningkatan kepada cara Aplikasi perusahaan pihak ketiga menghantar mesej melalui Notifikasi Kerja. Ia menyediakan keupayaan pembangunan dan konfigurasi templat mesej yang lebih ringkas dan piawai, sekaligus menawarkan keupayaan pemberitahuan mesej yang lebih selamat, terurus dan terkawal di pihak pelanggan. Untuk maklumat lanjut, lihat [Gambaran Keseluruhan Templat Mesej](/zh/open/development/message-template-overview).

  **Nota**

  Templat mesej hanya disokong untuk Aplikasi perusahaan pihak ketiga, bukan untuk Aplikasi dalaman.

- **Mesej Notifikasi Kerja**:

  Ini merupakan mesej pemberitahuan yang dihantar kepada pekerja atas nama Aplikasi mikro dalam sembang Notifikasi Kerja Organisasi Anda, seperti ucapan hari lahir dan peringatan onboarding.

## Keupayaan API Pemberitahuan Mesej

### Senarai API Pemberitahuan Mesej Terbuka

Pemberitahuan mesej menawarkan keupayaan API yang kaya. Melalui API tersebut, pembangun boleh mengintegrasikan pemberitahuan mesej dengan sistem perniagaan organisasi mereka.

**Notifikasi Kerja**

| API | Penerangan | Spesifikasi Baharu (Server API Baharu) | Spesifikasi Lama (Server API) |
| --- | --- | --- | --- |
| Hantar Notifikasi Kerja | Menghantar mesej Notifikasi Kerja. | - | [Hantar Notifikasi Kerja](/zh/open/development/asynchronous-sending-of-enterprise-session-messages) |
| Kemas Kini Bar Status Notifikasi Kerja | Mengemas kini status mesej Notifikasi Kerja OA. | - | [Kemas Kini Bar Status Notifikasi Kerja](/zh/open/development/update-work-notification-status-bar) |
| Dapatkan Kemajuan Penghantaran Mesej Notifikasi Kerja | Mendapatkan kemajuan penghantaran mesej Notifikasi Kerja. | - | [Dapatkan Kemajuan Penghantaran Mesej Notifikasi Kerja](/zh/open/development/obtain-the-sending-progress-of-asynchronous-sending-of-enterprise-session) |
| Dapatkan Keputusan Penghantaran Mesej Notifikasi Kerja | Menyemak keputusan penghantaran mesej Notifikasi Kerja. | - | [Dapatkan Keputusan Penghantaran Mesej Notifikasi Kerja](/zh/open/development/gets-the-result-of-sending-messages-asynchronously-to-the-enterprise) |
| Tarik Balik Mesej Notifikasi Kerja | Menarik balik mesej Notifikasi Kerja. | - | [Tarik Balik Mesej Notifikasi Kerja](/zh/open/development/notification-of-work-withdrawal) |

## Cara Mengintegrasikan Keupayaan API Pemberitahuan Mesej

DingTalk menyediakan contoh aliran integrasi untuk API pemberitahuan mesej.

- Alihkan ke Mini Program DingTalk daripada Notifikasi Kerja
- [Alihkan ke Aplikasi Mikro DingTalk daripada Notifikasi Kerja](/zh/open/development/redirect-micro-applications-to-work-messages)

## Glosari

### task_id

`task_id` ialah medan pengecam unik bagi mesej Notifikasi Kerja. Ia dikembalikan apabila anda memanggil API [Hantar Notifikasi Kerja](/zh/open/development/asynchronous-sending-of-enterprise-session-messages).

Gunakan `task_id` untuk memanggil API [Dapatkan Kemajuan Penghantaran Mesej Notifikasi Kerja](/zh/open/development/obtain-the-sending-progress-of-asynchronous-sending-of-enterprise-session) dan API [Dapatkan Keputusan Penghantaran Mesej Notifikasi Kerja](/zh/open/development/gets-the-result-of-sending-messages-asynchronously-to-the-enterprise) untuk menyemak kemajuan dan keputusan penghantaran mesej Notifikasi Kerja.
