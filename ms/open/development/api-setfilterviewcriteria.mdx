---
title: "Tetapkan syarat paparan penapis"
description: "Ketahui cara memanggil API untuk menetapkan atau mengemas kini syarat penapis bagi lajur tertentu dalam paparan penapis DingTalk Spreadsheet, sesuai untuk mengawal skop keterlihatan data dengan tepat dalam paparan penapis peribadi."
---

Panggil API ini untuk menetapkan atau mengemas kini syarat penapis bagi satu lajur dalam paparan penapis yang ditentukan. Ini berguna apabila anda perlu mengawal skop data yang boleh dilihat bagi satu lajur secara tepat dalam paparan penapis peribadi, seperti hanya memaparkan projek yang anda miliki dalam paparan kerja peribadi, atau menapis tugasan keutamaan tinggi mengikut label warna tertentu.

## Penerangan panggilan API

Syarat paparan penapis hanya menjejaskan paparan semasa dan tidak mengubah data yang dilihat oleh pengguna lain.

## Permintaan

### Maklumat asas

| Medan | Nilai |
| --- | --- |
| URL HTTP | `https://api.dingtalk.io/v1.0/doc/workbooks/{workbookId}/sheets/{sheetId}/filterViews/{filterViewId}/setColumnFilterCriteria` |
| Kaedah HTTP | POST |
| Jenis aplikasi yang disokong | appType-Aplikasi dalaman |
| Kebenaran yang diperlukan | permission-Document.Workbook.Write-Kebenaran tulis DingTalk Spreadsheet |

### Header permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | Ya | Kelayakan akses untuk memanggil API ini. Panggil API [Dapatkan access token aplikasi dalaman](/open/development/obtain-the-access-token-of-an-internal-app) untuk mendapatkannya. |

### Parameter laluan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| workbookId | String | Ya | ID fail spreadsheet. `nodeId(dentryUuid)` yang dikembalikan oleh [API Knowledge Base](/open/development/knowledge-base-overview) ialah `workbookId` bagi spreadsheet tersebut. Dapatkannya dengan memanggil API [Dapatkan nod](https://open.dingtalk.com/document/orgapp/get-node) dan [Cipta dokumen knowledge base](/open/development/create-team-space-document). |
| sheetId | String | Ya | ID atau nama Helaian Kerja. Panggil API [Dapatkan semua Helaian Kerja](/open/development/obtain-all-worksheets) untuk mendapatkan nilai parameter id atau name. |
| filterViewId | String | Ya | ID paparan penapis. |

### Parameter kueri

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| operatorId | String | Ya | unionId bagi pengendali.   - Panggil API [Dapatkan maklumat pengguna menggunakan kod Log masuk senyap](/open/development/obtain-the-userid-of-a-user-by-using-the-log-free) untuk mendapatkan nilai parameter unionid. - Panggil API [Tanya butiran pengguna](/open/development/query-user-details) untuk mendapatkan nilai parameter unionid.       Jika pengendali tiada kebenaran, API akan mengembalikan `The operator has no permission`. |

### Isi permintaan

| Nama | Jenis | Wajib | Penerangan |
| --- | --- | --- | --- |
| column | Long | Ya | Ofset lajur berbanding lajur pertama dalam julat paparan penapis, bermula daripada 0. Contohnya, jika julat paparan penapis ialah `B1:E10`, `column=0` mewakili lajur B dan `column=1` mewakili lajur C. |
| filterCriteria | Object | Ya | Object syarat penapis. |
| filterType | String | Ya | Jenis penapis. Nilai yang sah:   - **values**: tapis mengikut nilai - **color**: tapis mengikut warna - **condition**: tapis mengikut syarat |
| visibleValues | Array of String | Tidak | Nilai yang boleh dilihat. |
| backgroundColor | String | Tidak | Warna latar belakang yang boleh dilihat apabila menapis mengikut warna latar belakang, dalam format heksadesimal (seperti `#FF0000`). Apabila `filterType` ialah `color`, sama ada `backgroundColor` atau `fontColor` diperlukan. |
| fontColor | String | Tidak | Warna fon yang boleh dilihat apabila menapis mengikut warna fon, dalam format heksadesimal (seperti `#00FF00`). Apabila `filterType` ialah `color`, sama ada `backgroundColor` atau `fontColor` diperlukan. |
| conditions | Array | Tidak | Senarai syarat apabila menapis mengikut syarat. Maksimum 2 syarat dibenarkan. Diperlukan apabila `filterType` ialah `condition`. |
| operator | String | Tidak | Operator syarat. Nilai yang sah:   - **equal**: sama dengan - **not-equal**: tidak sama dengan - **contains**: mengandungi - **not-contains**: tidak mengandungi - **starts-with**: bermula dengan - **not-starts-with**: tidak bermula dengan - **ends-with**: berakhir dengan - **not-ends-with**: tidak berakhir dengan - **greater**: lebih besar daripada - **greater-equal**: lebih besar daripada atau sama dengan - **less**: lebih kecil daripada - **less-equal**: lebih kecil daripada atau sama dengan |
| value | String | Tidak | Nilai syarat. |
| conditionOperator | String | Tidak | Hubungan logik antara beberapa syarat. Nilai yang sah: \* **and**: AND (lalai) \* **or**: OR. Berkuat kuasa apabila `conditions` mengandungi 2 syarat. |
