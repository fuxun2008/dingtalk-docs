Panggil API ini untuk menanya maklumat syif kehadiran dan penjadualan syif semua pekerja dalam organisasi anda pada hari tertentu.

## Penerangan panggilan API

- Bagi kehadiran syif tetap, hanya maklumat penjadualan syif bagi 15 hari seterusnya tersedia.
- API ini hanya tersedia untuk organisasi yang mempunyai kurang daripada 10,000 ahli.

## Permintaan

| **Maklumat asas** | |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/topapi/attendance/listschedule |
| Kaedah HTTP | POST |
| Jenis aplikasi yang disokong | appType-Aplikasi dalaman appType-Aplikasi perusahaan pihak ketiga |
| Kebenaran yang diperlukan | permission-qyapi_base-Kebenaran asas yang diperlukan untuk memanggil API organisasi |

### Parameter pertanyaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | bE74xxxx | Kelayakan aplikasi yang digunakan untuk memanggil API ini.   - Bagi Aplikasi dalaman, dapatkannya dengan memanggil [Dapatkan access_token aplikasi dalaman](/ms/open/development/obtain-orgapp-token). - Bagi Aplikasi perusahaan pihak ketiga, dapatkannya dengan memanggil Dapatkan access_token organisasi pihak ketiga. |

### Isi permintaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| workDate | Date | Ya | 2020-09-06 | Tarikh penjadualan syif. Hanya tahun, bulan dan hari digunakan. |
| offset | Number | Tidak | 0 | Ofset penomboran, bermula daripada 0. Hanya berkuat kuasa apabila ditetapkan bersama parameter size. |
| size | Number | Tidak | 200 | Saiz halaman. Nilai maksimum: 200. |

### Contoh permintaan

```curl
curl -X POST "https://api.dingtalk.io/topapi/attendance/listschedule" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=b9305xxxxea83' \
-d 'offset=0' \
-d 'size=200' \
-d 'workDate=2016-03-09+11%3A11%3A11'
```

Java

```text
DingTalkClient client = new DefaultDingTalkClient("https://api.dingtalk.io/topapi/attendance/listschedule");
OapiAttendanceListscheduleRequest req = new OapiAttendanceListscheduleRequest();
req.setWorkDate(StringUtils.parseDateTime("2016-03-09 11:11:11"));
req.setOffset(0L);
req.setSize(200L);
OapiAttendanceListscheduleResponse rsp = client.execute(req, access_token);
System.out.println(rsp.getBody());
```


C#

```text
IDingTalkClient client = new DefaultDingTalkClient("https://api.dingtalk.io/topapi/attendance/listschedule");
OapiAttendanceListscheduleRequest req = new OapiAttendanceListscheduleRequest();
req.WorkDate = DateTime.Parse("2016-03-09 11:11:11");
req.Offset = 0L;

OapiAttendanceListscheduleResponse rsp = client.Execute(req, access_token);
Console.WriteLine(rsp.Body);
```

## Respons

### Isi respons

| Nama | Jenis | Contoh | Penerangan |
| --- | --- | --- | --- |
| result | AtScheduleListForTopVo |  | Hasil pertanyaan. |
| schedules | AtScheduleForTopVo[] |  | Senarai jadual. |
| plan_id | Number | 157062792171 | ID penjadualan syif. |
| check_type | String | OnDuty | Jenis daftar masuk:   - **Onduty**: Daftar masuk - **OffDuty**: Daftar keluar |
| approve_id | Number | 1 | ID kelulusan.  **Nota**  Parameter ini tidak dikembalikan jika tiada borang kelulusan. |
| userid | String | user01 | ID pengguna bagi pengguna kehadiran. |
| class_id | Number | 677995086 | ID syif kehadiran. |
| class_setting_id | Number | 599315627 | ID konfigurasi syif.  **Nota**  Parameter ini tidak dikembalikan jika konfigurasi global digunakan. |
| plan_check_time | Date | 2020-11-11 09:30:00 | Masa daftar masuk. |
| group_id | Number | 685935028 | ID kumpulan kehadiran. |
| changed_check_time | Date | 2020-09-06 15:36:04 | Masa daftar masuk yang telah dilaraskan. |
| has_more | Boolean | false | Menunjukkan sama ada terdapat halaman seterusnya.   - **true**: Ya - **false**: Tidak |
| errmsg | String | ok | Penerangan kod pemulangan. |
| errcode | Number | 0 | Kod pemulangan. |
| request_id | String | 6ha75i2o99fj | ID permintaan. |
