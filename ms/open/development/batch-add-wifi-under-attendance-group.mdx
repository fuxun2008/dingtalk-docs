---

Panggil API ini untuk menambah maklumat Wi-Fi secara pukal ke kumpulan kehadiran yang ditetapkan.

## Permintaan

| **Maklumat asas** | |
| --- | --- |
| URL HTTP | https://api.dingtalk.io/topapi/attendance/group/wifis/add |
| Kaedah HTTP | POST |
| Jenis aplikasi yang disokong | appType-Aplikasi dalaman |
| Kebenaran | permission-qyapi_attendance_group_manage-Kebenaran pengurusan kumpulan kehadiran |

### Parameter query

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| access_token | String | Ya | 1eb68xxx | Kelayakan aplikasi yang digunakan untuk memanggil API ini. Dapatkannya dengan memanggil [Dapatkan access_token Aplikasi dalaman](/ms/open/development/obtain-orgapp-token). |

### Isi permintaan

| Nama | Jenis | Wajib | Contoh | Penerangan |
| --- | --- | --- | --- | --- |
| op_userid | String | Tidak | user01 | ID pengguna bagi pengendali. |
| group_key | String | Ya | 0151E0xxx | ID kumpulan kehadiran.  **Nota**  Jika pengecam kumpulan kehadiran anda ialah group_id, panggil [Tukar groupId kepada groupKey](/ms/open/development/groupid-to-groupkey) untuk menukar group_id kepada group_key. |
| wifi_list | Wifi[] | Ya |  | Senarai Wi-Fi. Tambah sehingga 100 entri Wi-Fi setiap panggilan. |
| foreign_id | String | Ya | alibaba-inc | ID Wi-Fi di pihak perniagaan. |
| mac_addr | String | Ya | 11:11:11:11:11:11 | Alamat MAC. |
| ssid | String | Ya | alibaba-inc1 | Nama. |

### Contoh permintaan

```curl
curl -X POST "https://api.dingtalk.io/topapi/attendance/group/wifis/add" \
-H 'Content-Type:application/x-www-form-urlencoded;charset=utf-8' \
-d 'access_token=b040xxxx34a60' \
-d 'group_key=0151E02xxxx17E876' \
-d 'op_userid=123456' \
-d 'wifi_list=null'
```

## Respons

### Isi respons

| Nama | Jenis | Contoh | Penerangan |
| --- | --- | --- | --- |
| result | DingOpenResult |  | Maklumat yang dikembalikan. |
| result | Result |  | Hasil penambahan Wi-Fi. |
| error_info_list | ErrorInfo[] |  | Senarai entri Wi-Fi yang gagal ditambah. |
| failure_list | Wifi[] |  | Senarai kegagalan. |
| foreign_id | String | alibaba-guest | ID Wi-Fi di pihak perniagaan. |
| mac_addr | String | 02:10:18:11:11:11 | Alamat MAC. |
| ssid | String | alibaba-guest1 | Nama MAC. |
| wifi_key | String | 01xxxxE876 | Kunci entri Wi-Fi yang gagal ditambah. |
| msg | String | ralat perniagaan | Penerangan ralat. |
| code | String | 1000 | Kod ralat. |
| success_list | Wifi[] |  | Senarai entri Wi-Fi yang berjaya ditambah. |
| foreign_id | String | alibaba-inc | ID Wi-Fi di pihak perniagaan. |
| mac_addr | String | 11:11:11:11:11:11 | Alamat MAC. |
| ssid | String | alibaba-inc1 | Nama MAC. |
| wifi_key | String | 01xxxxE876 | Kunci entri Wi-Fi yang berjaya ditambah. |
| errcode | Number | 0 | Kod pemulangan. |
| errmsg | String | ok | Penerangan kod pemulangan. |
| success | Boolean | true | Sama ada panggilan berjaya.   - **true**: Berjaya - **false**: Gagal |
| request_id | String | wicoxqraqt0g | ID permintaan. |
