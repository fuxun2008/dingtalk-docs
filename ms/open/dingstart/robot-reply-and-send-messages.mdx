Jika anda perlu melaksanakan pembalasan bot atau penghantaran mesej bot, ikuti langkah-langkah dalam dokumen ini untuk membangunkan pembalasan bot atau penghantaran mesej bot.

## Latar Belakang

Membalas mesej dengan bot pada dasarnya adalah proses yang sama dengan menghantar mesej dengan bot. Oleh itu, dalam dokumen ini, membalas dan menghantar mempunyai maksud yang sama.

Mesej boleh dihantar melalui Server API atau Webhook. Bahagian berikut memperkenalkan kedua-dua kaedah ini.

## Prasyarat

1. Selesaikan proses [Cipta aplikasi](/ms/open/dingstart/create-application).
2. Selesaikan proses menambah keupayaan aplikasi.

## Hantar mesej melalui Webhook

### Hantar mesej melalui Webhook

<Note>
Menghantar mesej melalui webhook menyokong ciri @. Lihat contoh integrasi di bawah untuk maklumat lanjut.
</Note>

1. Hantar mesej melalui URL Webhook bot aplikasi:

   1. Dalam [Bot menerima mesej](/ms/open/dingstart/robot-receive-message), dapatkan URL Webhook bot aplikasi dalam kumpulan. Untuk maklumat lanjut, lihat [Dapatkan Webhook bot aplikasi](/ms/open/development/faq-robot).
   2. Persediaan persekitaran pembangunan Java:

      - Import SDK Java. Untuk SDK dalam bahasa lain, lihat muat turun SDK Bahagian pelayan warisan.

        ```xml lines
        <dependency>
            <groupId>com.aliyun</groupId>
            <artifactId>alibaba-dingtalk-service-sdk</artifactId>
            <version>2.0.0</version>
        </dependency>
        ```
   3. Contoh kod integrasi:

      ```java lines
      public void sendMessageWebhook() throws ApiException {
              DingTalkClient client = new DefaultDingTalkClient("{ Webhook url }");
              OapiRobotSendRequest request = new OapiRobotSendRequest();
              request.setMsgtype("text");
              OapiRobotSendRequest.Text text = new OapiRobotSendRequest.Text();
              text.setContent("Test text message");
              request.setText(text);
              OapiRobotSendRequest.At at = new OapiRobotSendRequest.At();
              at.setAtUserIds(Arrays.asList("4525xxxxxxxxx7041"));
              at.setIsAtAll(false);
              request.setAt(at);
              OapiRobotSendResponse response = client.execute(request);
              System.out.println(response.getBody());
      }
      ```

      Untuk jenis mesej lain, lihat jenis mesej yang disokong oleh penghantaran mesej Bot tersuai.
2. Hantar mesej melalui medan sessionWebhook yang dikembalikan apabila bot menerima mesej.

   1. Dapatkan URL sessionWebhook daripada data JSON yang dikembalikan dalam [Bot menerima mesej](/ms/open/dingstart/robot-receive-message).
   2. Persediaan persekitaran pembangunan Java:

      - Import SDK Java. Untuk SDK dalam bahasa lain, lihat muat turun SDK Bahagian pelayan warisan.

        ```xml lines
        <dependency>
            <groupId>com.aliyun</groupId>
            <artifactId>alibaba-dingtalk-service-sdk</artifactId>
            <version>2.0.0</version>
        </dependency>
        ```
   3. Contoh kod integrasi:

      ```java lines
      public void sendMessageWebhook() throws ApiException {
              DingTalkClient client = new DefaultDingTalkClient("{ SessionWebhook url }");
              OapiRobotSendRequest request = new OapiRobotSendRequest();
              request.setMsgtype("text");
              OapiRobotSendRequest.Text text = new OapiRobotSendRequest.Text();
              text.setContent("Test text message");
              request.setText(text);
              OapiRobotSendRequest.At at = new OapiRobotSendRequest.At();
              at.setAtUserIds(Arrays.asList("4525xxxxxxxxx7041"));
              at.setIsAtAll(false);
              request.setAt(at);
              OapiRobotSendResponse response = client.execute(request);
              System.out.println(response.getBody());
      }
      ```

      Untuk jenis mesej lain, lihat jenis mesej yang disokong oleh penghantaran mesej Bot tersuai.
