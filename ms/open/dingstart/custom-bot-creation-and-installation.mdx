Untuk menghantar mesej dalam Kumpulan Standard atau Sembang Luaran, ikut langkah dalam dokumen ini untuk mencipta bot tersuai.

<Warning>
Bot tersuai hanya menyokong penghantaran mesej dalam kumpulan. Mesej Langsung tidak disokong.
</Warning>

## Prosedur

1. Log masuk ke Bahagian klien DingTalk dan pilih Sembang Kumpulan yang anda mahu tambahkan bot.
2. Buka Sembang Kumpulan dan klik ikon **Tetapan kumpulan** di penjuru kanan atas.

3. Dalam bahagian Urus Kumpulan, klik **Bot** > **Tambah Bot**, dan pilih Bot tersuai.

4. Klik **Tambah** dan konfigurasikan maklumat bot:

   | **Item** | **Penerangan** |
   | --- | --- |
   | Gambar Profil Bot | Klik ikon edit untuk Muat naik Gambar Profil bot. |
   | Nama Bot | Masukkan nama untuk bot. |
   | Tetapan Keselamatan | Jenis Tetapan Keselamatan: - Kata kunci tersuai - Tandatangani permintaan - Alamat IP (julat) Untuk butiran tentang Tetapan Keselamatan, lihat [Tetapan keselamatan bot tersuai](/ms/open/dingstart/customize-robot-security-settings). |
   | (Pilihan) Aktifkan mekanisme Outgoing | Apabila Bot kumpulan disebut dengan @, mesej dihantar ke perkhidmatan luaran yang ditetapkan, dan Respons daripada perkhidmatan luaran boleh dikembalikan ke Sembang Kumpulan. Untuk jenis mesej dan format Data yang diterima oleh bot, lihat Penerimaan mesej bot. |

   Selepas konfigurasi, pilih **Perkhidmatan Bot Tersuai dan Penafian** dan klik **Selesai**.

## Langkah seterusnya

Untuk menghantar mesej menggunakan bot tersuai, lihat Dokumen berikut:

- Hantar mesej Sembang Kumpulan dengan bot tersuai
