Sebelum anda mula membangunkan aplikasi, Admin Organisasi mesti memberikan kebenaran pembangun kepada pembangun. Pembangun dengan identiti berbeza boleh membangunkan jenis aplikasi yang berbeza.

|  |  |  |
| --- | --- | --- |
| **Pembangun** | **Jenis Aplikasi Dibangunkan** | **Organisasi Berkaitan** |
| Pembangun dalaman | Aplikasi dalaman yang dibina oleh organisasi | Bangunkan aplikasi dalaman yang dibina oleh organisasi sebagai pekerja dalaman. |
| Pembangun daripada penyedia penyelesaian | Aplikasi perusahaan pihak ketiga  Bangunkan aplikasi dalaman secara delegasi | Untuk membangunkan aplikasi perusahaan pihak ketiga atau aplikasi tersuai untuk organisasi sebagai pembangun daripada penyedia penyelesaian, organisasi anda mesti melengkapkan pengesahan penyedia penyelesaian. Untuk butiran lanjut, lihat [Panduan Proses Kerjasama Penuh](/zh/open/development/isv-cooperation-guide). |

## Prosedur

Admin Organisasi memberikan kebenaran pembangun kepada pembangun dengan mengikuti langkah berikut:

**Nota**

Selepas memohon kebenaran pembangun, pembangun boleh log masuk untuk membangunkan, memuat naik, dan menerbitkan aplikasi.

1. Admin Organisasi log masuk ke [OA Admin Console](https://oa.dingtalk.com/index.htm#/safety/subAccount).

2. Dalam Admin Console, pilih **Keselamatan & Kebenaran** > **Urus Kebenaran**, kemudian klik **Kumpulan Pengurusan** untuk membuka halaman **Kumpulan Pengurusan**.

3. Klik **Tambah Kumpulan Pengurusan**.

4. Pada halaman **Edit Kumpulan Pengurusan**, isikan medan berikut, kemudian klik **Simpan**.

- **Nama kumpulan pengurusan:** Masukkan nama kumpulan pengurusan.
- **Pengguna:** Tetapkan pengguna kepada kumpulan pengurusan.
- **Skop pengurusan:** Pilih skop pengurusan.
- **Tetapkan kebenaran:** Pilih kebenaran yang berkaitan.

5. Pembangun log masuk ke [Developer Console](https://open-dev.dingtalk.com/#/index) untuk membangunkan aplikasi.
