Untuk membangunkan Bot yang menerima mesej, ikut langkah-langkah dalam dokumen ini untuk melengkapkan pembangunan bahagian pelayan bagi penerimaan mesej.

## Latar belakang

Bot boleh menerima mesej dalam dua mod: mod Stream dan mod HTTP. Dokumen ini menerangkan cara menerima mesej dalam kedua-dua mod tersebut.

## Prasyarat

1. Lengkapkan proses [Cipta aplikasi](/ms/open/dingstart/create-application).
2. Lengkapkan proses menambah keupayaan aplikasi.

## Prosedur

### Mod Stream (disyorkan)

> Untuk bahasa pengaturcaraan lain, rujuk dokumentasi mod Stream Bahagian pelayan.

1. Sediakan persekitaran pembangunan Java:

- Runtime: JDK 1.8 atau lebih tinggi
- Pasang Java SDK:

  Tambahkan dependency ke fail `pom.xml` projek anda atau muat turun pakej JAR yang berkaitan. Anda boleh melihat dan memuat turun versi SDK terkini [di sini](https://s01.oss.sonatype.org/?spm=openapi-amp.sdkpublish.0.0.78cefAyIfAyImO#nexus-search;quick~app-stream-client).

  ```xml lines
  <dependency>
    <groupId>com.dingtalk.open</groupId>
    <artifactId>app-stream-client</artifactId>
    <version>{sdk-version}</version>
  </dependency>
  ```

2. Contoh integrasi bahagian pelayan:

   ```java lines
   public class BotExample {

     public static void main(String[] args) {
       OpenDingTalkClient client = OpenDingTalkStreamClientBuilder
                   .custom()
                   .credential(new AuthClientCredential("${ClientId}", "${ClientSecret}"))
                   .registerCallbackListener("${topic}", new RobotMsgCallbackConsumer())
                   .build();
        client.start();
     }

     public static class RobotMsgCallbackConsumer implements OpenDingTalkCallbackListener<JSONObject, JSONObject> {

       /*
        * @param request
        * @return
        */
       @Override
       public JSONObject execute(JSONObject request) {
           System.out.println(JSON.toJSONString(request));
           try {
               JSONObject text = request.getJSONObject("text");
               if (text != null) {
                   // Kandungan mesej yang diterima oleh Bot
                   String msg = text.getString("content").trim();
                   String openConversationId = request.getString("conversationId");
               }
           } catch (Exception e) {
               log.error("receive group message by robot error:" +e.getMessage(), e);
           }
           return new JSONObject();
       }
     } 
   }
   ```

   | **Nama** | **Penerangan** |
   | --- | --- |
   | ClientId | ClientId bagi Kelayakan Aplikasi dalaman. |
   | ClientSecret | ClientSecret bagi Kelayakan Aplikasi dalaman. |
   | topic | Nama callback Bot. Nilai tetap: `/v1.0/im/bot/messages/get`. |
3. Selepas pembangunan selesai, [tambah Bot ke dalam kumpulan](/ms/open/dingstart/add-robot-to-group). Apabila anda menghantar "Hello" dengan @ Bot, pelayan akan menerima mesej dalam format berikut:

### Mod HTTP

1. Sediakan persekitaran pembangunan Java:

   - Runtime: JDK 1.7 atau lebih tinggi
2. Contoh integrasi bahagian pelayan:

     	// Nilai value = "/robots" di bawah menentukan URL penerimaan mesej Bot yang dikonfigurasi kemudian, contohnya: https://example.com/robots
       @RequestMapping(value = "/robots", method = RequestMethod.POST)
       public String helloRobots(@RequestBody(required = false) JSONObject json) {
           System.out.println(json);
