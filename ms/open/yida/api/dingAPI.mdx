DingTalk menawarkan pelbagai keupayaan JSAPI, seperti dialog asli, maklumat peranti, dan imbasan Kod QR. Pembangun YiDA boleh memanfaatkan API asli ini untuk memberikan pengalaman pengguna yang lebih baik.

* [Senarai Fungsi JSAPI DingTalk](https://open.dingtalk.com/document/orgapp/jsapi-overview-client-org)
* Untuk asas pembangun DingTalk, lihat [Konsep Asas](/ms/open/dingstart/basic-concepts-beta).

<Warning>
Ambil perhatian perkara berikut apabila memanggil JSAPI DingTalk:
* Dalam aplikasi YiDA, `window.dd` tidak dijamin wujud (buat masa ini, hanya klien mudah alih memuatkan sumber warisan). Muatkannya secara manual.
* Dalam aplikasi YiDA, anda boleh memanggil API yang memerlukan Pengesahan walaupun tanpa mengkonfigurasi `dd.config`. Gunakan API ini dengan berhati-hati.
* Dapatkan parameter `corpId` yang diperlukan untuk panggilan JSAPI dengan `const { corpId } = window.pageConfig || {};`.
</Warning>

## Panduan penggunaan

### Langkah 1: Muatkan Sumber JSAPI DingTalk Secara Asinkron
Oleh sebab `window.dd` tidak dijamin wujud dalam halaman YiDA, muatkan skrip JSAPI DingTalk secara manual dalam cangkuk kitaran hayat `didMount`:

```js
export function didMount() {
  this.utils.loadScript('https://g.alicdn.com/dingding/dingtalk-jsapi/3.0.25/dingtalk.open.js');
}
```
Setelah sumber dimuatkan, panggil fungsi JSAPI melalui `window.dd`.

### Langkah 2: Panggil JSAPI DingTalk
Selepas JSAPI DingTalk dimuatkan, panggil API DingTalk melalui `window.dd` daripada panel tindakan:

```js
export function isDingTalk() {
  return window.navigator && /dingtalk/i.test(window.navigator.userAgent)
}

export function dingAlert() {
  if (window.dd && this.isDingTalk()) {
    window.dd.device.notification.alert({
      message: "Test",
      title: "Tips", // can be empty
      buttonName: "Got it",
      onSuccess: function () {
      },
      onFail: function (err) { }
    });
  }
}
```

<Warning>
Banyak kaedah JSAPI DingTalk mesti dipanggil dari dalam aplikasi. Sahkan bahawa pengguna berada dalam klien DingTalk sebelum memanggilnya:
```js
export function isDingTalk() {
  return window.navigator && /dingtalk/i.test(window.navigator.userAgent)
}
```
</Warning>
