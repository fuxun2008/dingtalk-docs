Selain API terbuka untuk panggilan bahagian klien, platform YiDA juga menyediakan API terbuka yang menyokong panggilan bahagian pelayan. Untuk butiran lanjut, sila lihat [dokumentasi Platform Terbuka DingTalk](https://open.dingtalk.com/document/orgapp-server/yida-overview).

## Panduan Pengguna

Ikuti langkah-langkah di bawah untuk menggunakan API terbuka bahagian pelayan YiDA:

<Tip>
Platform Terbuka DingTalk menawarkan pelbagai jenis aplikasi, dan cara anda menggunakan API terbuka bahagian pelayan berbeza mengikut jenis aplikasi. Untuk butiran lanjut, sila lihat [Pengenalan kepada Jenis Aplikasi DingTalk](https://open.dingtalk.com/document/orgapp/untitled-document-1689231271995).
</Tip>

### Langkah 1: Cipta Aplikasi DingTalk

- Untuk mencipta aplikasi dalaman, sila lihat [Gambaran Keseluruhan Proses Pembangunan Aplikasi Dalaman](https://open.dingtalk.com/document/orgapp/overview-of-development-process).
- Untuk mencipta aplikasi perusahaan pihak ketiga, sila lihat [Gambaran Keseluruhan Aplikasi Perusahaan Pihak Ketiga](https://open.dingtalk.com/document/isvapp/isv-cooperation-guide).

### Langkah 2: Tambah Kebenaran Panggilan API

Selepas aplikasi dicipta, hanya API log masuk dan notifikasi mesej diaktifkan secara lalai. Tambahkan kebenaran API yang diperlukan mengikut keperluan pembangunan anda.

- Untuk aplikasi dalaman, sila lihat [Tambah Kebenaran Panggilan API](/open/development/add-api-permission).
- Untuk aplikasi perusahaan pihak ketiga, sila lihat [Tambah Kebenaran Panggilan API](https://open.dingtalk.com/document/isvapp-server/add-interface-call-permissions?#topic-2149187).

### Langkah 3: Dapatkan access_token untuk Aplikasi

access_token berfungsi sebagai kelayakan identiti. Semasa memanggil API, gunakan access_token untuk mengesahkan identiti pemanggil.

- Untuk aplikasi dalaman, sila lihat [Dapatkan access_token bagi Aplikasi Dalaman](https://open.dingtalk.com/document/orgapp-server/obtain-the-access_token-of-an-internal-app#topic-2056397).
- Untuk aplikasi perusahaan pihak ketiga, sila lihat [Dapatkan access_token bagi Perusahaan yang Dibenarkan](https://open.dingtalk.com/document/isvapp-server/obtain-the-access_token-of-the-authorized-enterprise?#topic-2056409).
