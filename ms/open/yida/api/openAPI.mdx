YiDA menyediakan keupayaan remote API yang membolehkan anda memanggil antara muka asinkron berasaskan HTTP (untuk butiran, lihat [dokumentasi remote API](/open/yida/guide/concept/datasource)). YiDA juga menyediakan beberapa remote API terbina dalam untuk mengendalikan data YiDA.

<Warning>
Open API YiDA memerlukan pengesahan, jadi ia tidak boleh dipanggil terus daripada halaman log masuk senyap (silent-login). Salurkan panggilan ini melalui fungsi FaaS atau perkhidmatan backend anda sendiri.
</Warning>

## Nota Penggunaan API

### Laluan Permintaan

YiDA menyediakan API pada peringkat aplikasi. Dalam sesebuah aplikasi, panggil remote API (panggilan merentas aplikasi disokong) menggunakan format URL berikut:

```bash
# Anda boleh dapatkan kod aplikasi pada halaman Penggunaan & Operasi di bawah Tetapan Aplikasi.
# Untuk laluan antara muka, rujuk dokumentasi di bawah. API berbeza menggunakan laluan antara muka yang berbeza.
"/dingtalk/web/${appCode}/${interfacePath}"
```

<Tip>
Semasa menulis kod permintaan API pada platform YiDA, gunakan laluan relatif seperti di bawah supaya anda tidak perlu mengemas kini kod anda apabila subdomain organisasi berubah.

```bash
/dingtalk/web/APP_X1X2X3X4/v1/form/searchFormDatas.json
```

</Tip>

### Struktur Respons

Remote API YiDA mengembalikan struktur respons berikut:

```typescript
interface IResponse {
  success: boolean; // Sama ada permintaan berjaya
  result?: object | array | string; // Kandungan respons apabila permintaan berjaya
  errorMsg?: string; // Mesej ralat
  errorCode?: string; // Kod ralat
  errorLevel?: number; // Tahap ralat
}
```

## API Borang

Platform YiDA menyediakan halaman jenis borang untuk mengumpul data borang. API Borang membolehkan anda mencipta, membaca, mengemas kini, dan memadam data borang. "Instans borang" di sini merujuk kepada satu rekod dalam set data borang.

### Cipta Instans Borang

- Laluan antara muka: `/v1/form/saveFormData.json`
- Kaedah permintaan: `POST`
- Parameter (`formDataJson` mesti disiri-hantarkan dengan `JSON.stringify()`):

| Parameter    | Penerangan | Wajib | Contoh                                                                | Nota                                                                              |
| :----------- | :--------- | :---- | :--------------------------------------------------------------------- | :--------------------------------------------------------------------------------- |
| formUuid     | ID Borang  | Ya    | FORM-NJYJZELV8YZRDEI2N5IQ7L6VEDMR1VE9GMPCJB                            |                                                                                    |
| appType      | ID Aplikasi | Ya   | APP_DR4OK27ZKL5N22B907E8                                               |                                                                                    |
| formDataJson | Data borang | Ya   | `{"textField_jcpm6agt": "Baris tunggal", "employeeField_jcos0sar": ["workno"]}` | Lihat [Lampiran 1: Format Data Borang untuk Simpan/Kemas Kini](#format-data-borang-untuk-simpankemas-kini). |

- Contoh respons:

```json
{
  "result": "FINST-EF6Y93URN2UZ1SBPLIP9NAV6HR2GEO1Z4ZCHSCJ0",
  "success": true
}
```

### Kemas Kini Nilai Komponen dalam Borang

- Antara muka: `/v1/form/updateFormData.json`
- Kaedah permintaan: `POST`
- Parameter:

| Parameter          | Penerangan                                | Wajib | Contoh                                        | Nota                                                                                                                                                                                                              |
| :----------------- | :----------------------------------------- | :---- | :--------------------------------------------- | :----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| formInstId         | ID rekod borang untuk dikemas kini         | Ya    | FINST-NJYJZELVVYZRVGJHR7M6FJW3ESJN1P1TCNPCJ9   |                                                                                                                                                                                                                    |
| updateFormDataJson | Nilai komponen borang untuk dikemas kini   | Ya    | `{"employeeField_jcpm5gy2": ["xxxxx", "yyyyy"]}` | Lihat [Lampiran 1: Format Data Borang untuk Simpan/Kemas Kini](#format-data-borang-untuk-simpankemas-kini). Komponen yang disertakan dalam permintaan akan dikemas kini; komponen yang tidak disertakan kekal tidak berubah. ## API Aliran Kerja

Borang aliran kerja adalah satu lagi keupayaan teras platform YiDA. API Aliran Kerja membolehkan anda mengendalikan instans aliran kerja.

### Mulakan Aliran Kerja

- Laluan antara muka: `/v1/process/startInstance.json`
- Kaedah permintaan: `POST`
- Parameter:

| Parameter    | Penerangan                              | Wajib | Contoh                                                                             | Nota                                                                          |
| :----------- | :--------------------------------------- | :---- | :---------------------------------------------------------------------------------- | :----------------------------------------------------------------------------- |
| processCode  | Kod aliran kerja                            | Ya    | TPROC--EF6Y4G8WO2FN0SUB43TDQ3CGC3FMFQ1G9400RCJ4 (boleh didapati dalam URL halaman mula berasingan) |                                                                                |
| formUuid     | ID Borang                                  | Ya    | FORM-EF6Y4G8WO2FN0SUB43TDQ3CGC3FMFQ1G9400RCJ3 (boleh didapati dalam URL halaman mula berasingan)  |                                                                                |
| formDataJson | Data borang                                | Ya    |                                                                                     | Lihat [Lampiran 1: Format Data Borang untuk Simpan/Kemas Kini](#format-data-borang-untuk-simpankemas-kini). |

```json
{
```

- Setiap komponen dalam borang mempunyai ID unik (boleh dilihat pada panel "Advanced" di sebelah kanan komponen dalam Pereka bentuk halaman), dan setiap komponen menggunakan format data tetap. - Semasa menyimpan atau mengemas kini data borang, hantar nilai borang sebagai string JSON dalam format `Map<String, Object>`. Kunci ialah ID komponen, dan nilai ialah nilai komponen tersebut. Format nilai untuk setiap komponen adalah seperti berikut:

### Format Nilai Komponen untuk Carian Bersyarat

- Setiap komponen dalam borang mempunyai ID unik (boleh dilihat pada panel "Advanced" di sebelah kanan komponen dalam Pereka bentuk halaman), dan setiap komponen mempunyai format carian tersendiri. Komponen borang berikut menyokong carian: input baris tunggal, input berbilang baris, nombor, radio, pilihan lungsur, pilih banyak, pilih banyak lungsur, tarikh, julat tarikh, pemilih pengguna, pemilih wilayah, pemilih jabatan, pilihan berperingkat, dan subborang.
- Semasa mencari, gunakan format `Map<String, Object>` untuk menyatakan syarat carian bagi setiap komponen. Kunci ialah ID komponen, dan nilai ialah nilai carian bagi komponen tersebut. Jenis carian dan format nilai untuk setiap komponen adalah seperti berikut:

| Jenis komponen      | Jenis data    | Format data                                                                 | Nota                                                                                                                                    |
| :------------------ | :----------- | :-------------------------------------------------------------------------- | :--------------------------------------------------------------------------------------------------------------------------------------- |
| Input baris tunggal   | String       | "danhang"                                                                   | Carian kabur.                                                                                                                            |
| Input berbilang baris    | String       | "duohang"                                                                   | Carian kabur.                                                                                                                            |
| Input nombor        | Array string | ["1", "10"]                                                                 | Carian julat. Nilai pertama ialah minimum; nilai kedua ialah maksimum.                                                                         |
| Radio               | String       | "Pilihan 1"                                                                  | Padanan tepat.                                                                                                                             |
| Pilihan lungsur     | String       | "Pilihan 1"                                                                  |                                                                                                                                          |
| Pilih Banyak         | Array string | ["Pilihan 2"]                                                                | Carian array. Nilai carian mesti menjadi subset nilai pilih banyak.                                                                |
| Pilih banyak lungsur | Array string | ["Pilihan 2"]                                                               | Carian array. Nilai carian mesti menjadi subset nilai pilih banyak.                                                                |
| Komponen tarikh      | Array string | ["1514736000000", "1517414399000"]                                          | Carian julat. Nilai pertama ialah cap masa tarikh mula; nilai kedua ialah cap masa tarikh akhir.                                                 |
| Julat tarikh          | Array        | [["1514736000000", "1517414399000"], ["1514736000000", "1517414399000"]]    | Carian julat. Array pertama ialah julat carian bagi permulaan julat tarikh; kedua ialah julat carian bagi penghujungnya.          |
| Pemilih pengguna         | Array string | ["xxxxx", "yyyyy"]                                                          | ["xxxxx", "yyyyyy"]—padanan tepat. Nilai mesti padan tepat, dan susunan ID pekerja mesti sama.                              |

### Format Objek Butiran Instans Aliran Kerja

- Setiap komponen dalam borang mempunyai ID unik (boleh dilihat pada panel "Advanced" di sebelah kanan komponen dalam Pereka bentuk halaman), dan setiap komponen mempunyai format carian tersendiri. ### Format Data Borang sebagai Nilai Respons

Format data borang untuk nilai respons pada dasarnya sama seperti [Lampiran 1: Format Data Borang untuk Simpan/Kemas Kini](#format-data-borang-untuk-simpankemas-kini), dengan perbezaan berikut:

- Pada input, nilai komponen wilayah ialah ["ID Negeri", "ID Bandar", "ID Daerah"]. Dalam respons, ia ialah ["Nama negeri", "Nama bandar", "Nama daerah"].
- Komponen radio, pilihan lungsur, pilih banyak, dan pilih banyak lungsur menyokong pengantarabangsaan. Respons mengembalikan nilai data yang sepadan dengan parameter bahasa yang anda hantar.
