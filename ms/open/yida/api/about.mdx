Platform YiDA menawarkan pelbagai penyelesaian Open API yang kaya untuk pembangun. Senario yang berbeza memerlukan Open API yang berbeza untuk memenuhi keperluan perniagaan tertentu. Perbezaan dan senario penggunaan setiap Open API digariskan seperti berikut:

- **YiDA JS-API** — Digunakan terutamanya untuk memanggil API fungsi bahagian klien dalam senario panel tindakan atau pengikatan pemboleh ubah dalam pereka bentuk YiDA, seperti pemformatan string dan mendapatkan nilai komponen borang. Untuk butiran lanjut, lihat [Dokumentasi YiDA JS-API](/ms/open/yida/api/yidaAPI).
- **Cross-app Data Source API** — Digunakan terutamanya dalam konfigurasi remote API dalam pereka bentuk YiDA untuk melaksanakan operasi CRUD pada data aplikasi YiDA, seperti membuat pertanyaan data borang dan memulakan proses. Untuk butiran lanjut, lihat [Dokumentasi Cross-app Data Source API](/ms/open/yida/api/openAPI).
- **DingTalk JS-API** — Digunakan terutamanya oleh produk yang dibina untuk memanggil JSAPI yang disediakan oleh klien DingTalk dalam DingTalk, seperti dialog asli dan mendapatkan maklumat peranti. Untuk butiran lanjut, lihat [Dokumentasi DingTalk JS-API](/ms/open/yida/api/dingAPI).
- **Server-side Open API** — Digunakan terutamanya untuk memanggil Open API YiDA daripada bahagian pelayan. Fungsinya pada dasarnya sama seperti Cross-app Data Source API, tetapi kerana ia disasarkan untuk panggilan bahagian pelayan, ia merangkumi satu langkah pengesahan tambahan. Untuk butiran lanjut, lihat [Dokumentasi Server-side Open API](/ms/open/yida/api/serverAPI).
