## Kes Penggunaan

Untuk mendapatkan dan memaparkan data daripada halaman borang atau proses dalam Halaman tersuai, ikuti langkah-langkah dalam dokumen ini untuk memaparkan maklumat produk pada Halaman tersuai.

## Langkah-langkah

### Langkah 1: Dapatkan Data Borang yang Dihantar

Lawati halaman [YiDA Server OpenAPI](/ms/open/yida/api/openAPI) untuk menyemak semua remote API (OpenAPI) yang disediakan oleh YiDA, dan cari API pertanyaan Data Borang.

### Langkah 2: Konfigurasikan Sumber Data

- Tambah Sumber Data — Susun endpoint API berdasarkan dokumentasi OpenAPI dan konfigurasikan URL permintaan, contohnya: `/dingtalk/web/APP_M14MKG7F402M1Q7H2MGO/v1/form/searchFormDatas.json`.

- Konfigurasikan parameter — Tambahkan formUuid borang sasaran ke dalam parameter permintaan.

- Dapatkan formUuid — Cari formUuid bagi setiap borang dalam Aplikasi semasa pada halaman berikut.

- Simpan Sumber Data dan pratonton hasilnya.
