Jenis sifat komponen dan setter menawarkan pelbagai pilihan konfigurasi kepada pengguna untuk memenuhi keperluan yang pelbagai. Jenis sifat dan setter saling berkaitan seperti yang ditunjukkan dalam jadual di bawah.

| **Jenis Sifat** | **Nama Setter** | **Penerangan** | **Ilustrasi** |
| --- | --- | --- | --- |
| **Teks** | TextSetter | Setter teks: gaya biasa untuk komponen jenis teks yang menerima input teks standard. | |
|  | I18nSetter | Komponen yang baru diseret tidak mengaktifkan pengantarabangsaan (internationalization) secara lalai. Untuk mengaktifkannya, klik butang pengantarabangsaan di bahagian atas panel tetapan sifat. Editor akan dibuka, membolehkan anda mencipta entri pengantarabangsaan baharu atau mencari entri sedia ada untuk diikat. Bagi entri yang sudah diikat, klik butang pengantarabangsaan untuk mengedit teks pengantarabangsaan bagi bahasa berkaitan secara terus. | |
|  | DateSetter | Menyediakan pemilih tarikh dan memaparkan masa yang dipilih sebagai Cap masa pada halaman. | |
|  | ChoiceSetter | Sifat komponen tersuai dipaparkan sebagai pilihan dalam panel sifat. Apabila anda memilih pilihan yang berbeza, kandungan komponen pada halaman akan dikemas kini kepada nilai pilihan yang telah ditetapkan. | |
|  | ImageSetter |  | |
| **boolean** | BoolSetter | Sifat komponen tersuai dipaparkan sebagai suis dalam panel sifat pada halaman reka bentuk borang. Apabila diaktifkan, kandungan komponen memaparkan `true`; apabila dinyahaktifkan, ia memaparkan `false`. | |
| **Nombor** | NumberSetter | Borang tersuai berkelakuan seperti komponen Numerik YiDA, menyekat sebarang input selain nombor. Nilai yang dimasukkan dalam panel sifat akan dipaparkan dalam kandungan komponen. | |
| **object** | JsonSetter | Membolehkan anda memasukkan nilai sifat komponen sebagai kod berformat object, yang dipaparkan dalam kandungan komponen sebagai `[object Object]`. | |
| **array** | OptionsSetter | Menjana object array ringkas, biasanya digunakan untuk mengkonfigurasi pilihan dalam senarai lungsur turun (dropdown). | |
|  | ListSetter | Menjana komponen object kompleks yang memerlukan konfigurasi yang lebih lanjut. | |
|  | JsonSetter | Sama seperti setter object JsonSetter | Kesan yang sama seperti setter object JsonSetter |
| **Fungsi** | ActionSetter | Mengkonfigurasikan fungsi Callback. Apabila ActionSetter dipilih, dalam mod penggunaan sifat tersebut menjadi tetapan tindakan di bawah "Premium". | |
|  | CodeSetter | Mengkonfigurasikan fungsi Callback. Berbeza dengan ActionSetter, dalam mod penggunaan ia menjana kotak kod secara terus. | |
| **Elemen** | SlotSetter | Mencipta komponen jenis bekas (container) yang membolehkan komponen lain diseret ke dalamnya. Untuk menggunakannya, isytiharkan sifat terlebih dahulu dan pilih SlotSetter, kemudian seret komponen "Slot Placeholder" ke dalamnya dan ikatkannya kepada sifat yang diisytiharkan. | |
