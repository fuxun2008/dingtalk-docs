## 1. Tidak dapat mencari fungsi Padam

Fungsi Padam tidak tersedia semasa tempoh beta dan mungkin masih tidak tersedia selepas pelancaran rasmi. Pemadaman menimbulkan isu kebergantungan yang kompleks dan tidak diperlukan pada masa ini. Pendekatan keseluruhan akan mengikut model yang serupa dengan [https://www.npmjs.com/](https://www.npmjs.com/).

### 2. Bagaimana untuk memahami komponen perniagaan?

Rujuk [panduan](/ms/open/yida/guide/keywords) ini.

## 3. Struktur komponen

Komponen terdiri daripada paparan dan atributnya. Di pihak pengguna, ubah atribut komponen untuk menjadikannya memaparkan paparan yang berbeza.
Paparan terbahagi kepada dua kategori: paparan reka bentuk dan paparan masa jalan. Dalam kebanyakan kes, paparan reka bentuk dan paparan masa jalan boleh digunakan semula.

Di pihak pembekal, anda perlu membina paparan dan atribut secara berasingan.

## 4. Bolehkah aplikasi dengan komponen tersuai diagihkan kepada organisasi lain dan dibuka secara normal?

Ya.
Selepas aplikasi dengan komponen tersuai diagihkan kepada organisasi lain, organisasi tersebut boleh menggunakan komponen tersebut secara normal tetapi tidak dapat mengemas kininya. Untuk mengemas kini komponen, penyedia perkhidmatan mesti memasang semula versi baharu dalam aplikasi yang diagihkan melalui penyelenggaraan jarak jauh. Jika komponen diabstrakkan dengan baik, ini sebahagiannya menangani keperluan untuk mengemas kini aplikasi selepas pengagihan.

## 5. Bagaimana untuk mengakses atribut komponen tersuai dalam halaman?

Komponen tersuai berfungsi sama seperti Komponen asas. Gunakan `this.$('fieldId').get('propName')` untuk mendapatkan atribut komponen yang berkaitan.

## 6. Bagaimana untuk mengemas kini atribut komponen tersuai dalam halaman?

Komponen tersuai berfungsi sama seperti Komponen asas. Gunakan `this.$('fieldId').set('propName', propValue)` untuk mengemas kini atribut komponen yang berkaitan.
Sebagai alternatif, gunakan pendekatan pengikatan pemboleh ubah Sumber Data.

## 7. Bagaimana untuk mendapatkan komponen halaman dalam komponen dan menghubungkannya dengan komponen dalam halaman?

Tambah atribut jenis Fungsi pada komponen tersuai untuk berfungsi sebagai Panggilan balik peristiwa.
Pada halaman, gunakan Panggilan balik peristiwa ini untuk menghubungkannya dengan komponen lain pada halaman.
Di dalam komponen, panggil callback ini pada masa yang sesuai dengan memanggil `this.props.xxx()`, contohnya semasa peristiwa komponen atau dalam `DidMount` komponen.
Petua: Atribut jenis Fungsi boleh mempunyai nilai lalai dan boleh ditetapkan sebagai tersembunyi.

## 8. Bagaimana untuk memadam komponen tersuai?
Pemadaman komponen tidak disokong pada masa ini, kerana pemadaman menimbulkan isu kebergantungan yang kompleks. Pendekatan keseluruhan akan mengikut model yang serupa dengan [https://www.npmjs.com/](https://www.npmjs.com/).

## 9. Bagaimana untuk menyahpasang komponen tersuai?
Penyahpasangan komponen tidak disokong pada masa ini, kerana ia akan menjejaskan aplikasi sedia ada. Ciri ini akan dipertimbangkan dalam iterasi akan datang.

## 10. Adakah komponen tersuai menyokong pemasangan pakej NPM pihak ketiga?

Tidak buat masa ini. Sebaliknya, gunakan pemuatan sumber CDN secara dinamik.

```javascript
function loadScript(src, callback) {
  if (!src) {
    return;
  }
  const node = document.createElement('script');
  node.src = src;
  node.addEventListener('load', callback, false);
  document.head.appendChild(node);
}
function loadCss(url) {
  const linkElement = document.createElement('link');
  linkElement.rel = 'stylesheet';
  linkElement.href = url;
  document.body.appendChild(linkElement);
}

    // kod anda
  });
})();
```

J: Semak Skop pemasangan.

## 12. Bagaimana untuk menghantar data dalam borang menggunakan komponen tersuai?

J: Komponen tersuai YiDA tidak menyokong komponen borang pada masa ini. Untuk menghantar data, isikan komponen borang sedia ada sebagai alternatif. Contohnya, isytiharkan atribut dengan pengecam unik, hantar pengecam unik borang sedia ada semasa menggunakannya, dan tulis semula data yang diperlukan ke borang sedia ada melalui peristiwa di pihak komponen.

## 13. Penerangan versi komponen

Komponen dibahagikan kepada **versi pembangunan** dan **versi rasmi**.
Penomboran versi komponen tersuai YiDA mengikut [penomboran versi semantik](https://semver.org/lang/zh-CN/) dengan konvensyen tambahan.

1. `0.1.0` ialah versi pembangunan lalai. Versi pembangunan sentiasa disegerakkan dengan pereka bentuk komponen secara masa nyata untuk penyahpepijatan.
1. `1.x.x` ialah versi rasmi selepas pelepasan, yang mengunci fungsi versi semasa untuk memastikan kestabilan dalam Produksi. **Oleh itu, aplikasi Produksi mesti memasang versi rasmi `1.x.x` selepas pelepasan.**
