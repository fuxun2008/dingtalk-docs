Untuk senario yang memerlukan rendering berulang, serupa dengan pendekatan berikut dalam React, YiDA menyediakan pilihan konfigurasi **Data Gelung**. Dengan mengikat pemboleh ubah, anda boleh melaksanakan rendering berulang dengan mudah:
```js
function NameList() {
  const names = [{
    name: 'Jack'
  }, {
    name: 'Rose'
  }];
	return (
  	<div>
    {
      names.map((item, index) => (
        <span>{ `No.${index}: ${item.name}` }</span>
      ))
    }
    </div>
  );
}
```

## Konfigurasikan
Data gelung mestilah array—array string, array nombor, dan array object semuanya disokong. Konfigurasikan gelung melalui tetapan Data Gelung dalam Atribut Premium:

Anda boleh mengikat data gelung dengan dua cara:
* **Tetapan Statik** — Konfigurasikan data array statik untuk dirender.
* **Pengikatan Pemboleh Ubah** — Ikat pemboleh ubah untuk mendapatkan data gelung daripada pemboleh ubah global atau API jauh.

Setelah gelung dikonfigurasikan, komponen di dalam badan gelung boleh mengakses struktur dalaman data gelung melalui dua konteks suntikan berikut:
* **this.item** — Dapatkan data gelung untuk rekod semasa.
* **this.index** — Dapatkan indeks gelung untuk rekod semasa (bermula daripada 0).

Untuk senario gelung bersarang, sesuaikan nama pemboleh ubah lelaran dan nama pemboleh ubah indeks untuk menentukan butiran suntikan konteks dan mengelakkan konflik, seperti yang ditunjukkan di bawah:
