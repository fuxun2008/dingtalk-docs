Nyahpepijat adalah penting semasa pembangunan Halaman tersuai. Platform YiDA menyediakan kaedah nyahpepijat berikut:

## Tekan cmd/ctrl + P dalam Konsol Pelayar, Buka page.js, dan Tambahkan Titik Henti Secara Langsung untuk Nyahpepijat

## Buka Panel Nyahpepijat Layan Diri
Pembangun boleh menambahkan parameter `__showDevtools` pada URL halaman untuk mengaktifkan panel nyahpepijat ([penyusunan pautan layan diri](https://demo.aliwork.com/o/debug_by_self?__showDevtools=true)). Contohnya: [https://www.aliwork.com/bench/feedback?__showDevtools](https://www.aliwork.com/bench/feedback?__showDevtools).

Melalui panel nyahpepijat, pembangun boleh:
* Paparan pemboleh ubah Sumber Data
* Paparan data borang
* Paparan permintaan yang gagal
* Laporkan log ralat

Yang paling penting, panel nyahpepijat menjadikan nyahpepijat mudah alih sangat mudah.

## Aktifkan Schema workbench (Import/Eksport Skema)
Di penjuru kiri bawah Pereka bentuk borang YiDA, terdapat butang tersembunyi yang mengaktifkan Schema workbench. Anda boleh menjana halaman dengan pantas dengan mengimport skema dalam Schema workbench, dan anda juga boleh mengedit skema secara terus dalam workbench untuk menentukan borang dengan pantas melalui pengubahsuaian skema. Cukup tambahkan parameter `__debug` pada URL pautan reka bentuk untuk mengaktifkannya ([penyusunan pautan layan diri](https://demo.aliwork.com/o/debug_by_self?__showDevtools=true)), seperti yang ditunjukkan di bawah:

## Nyahpepijat Mudah Alih/Dalam Aplikasi Menggunakan vConsole
Buka panel tindakan bagi halaman yang perlu dinyahpepijat dan masukkan kod berikut di bahagian atas. Kemudian akses halaman tersebut untuk mula nyahpepijat.
Nota: Padam kod ini selepas nyahpepijat selesai.
```javascript
  const vConsole = 'https://g.alicdn.com/code/lib/vConsole/3.11.2/vconsole.min.js';
  const js = document.createElement('script');
  js.src = vConsole;
  document.body.append(js);
  js.onload = function() {
    window.vConsole = new window.VConsole();
  };
```
