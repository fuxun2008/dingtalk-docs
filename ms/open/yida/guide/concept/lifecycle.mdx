Seperti React, Halaman Tersuai YiDA turut menyediakan keupayaan kitaran hayat halaman. Pelaksanaannya dipermudahkan dan hanya menyokong dua Hooks kitaran hayat berikut. Tulis logik JS yang berkaitan dalam panel tindakan untuk menjalankan tugas apabila Halaman dipasang atau dinyahpasang:
* **didMount** — Bersamaan dengan componentDidMount React. Dipanggil selepas Halaman dipaparkan buat kali pertama.
* **willUnmount** — Bersamaan dengan componentWillUnmount React. Dipanggil sebelum Halaman dinyahpasang.

## Kes Penggunaan
Contoh berikut menunjukkan cara menggunakan Hooks kitaran hayat. Konfigurasikan fungsi kitaran hayat halaman dalam panel tindakan untuk melaksanakan operasi berikut:
* Dengar peristiwa resize Dokumen selepas Halaman dipasang.
* Keluarkan lebar Halaman semasa dalam Masa Real melalui kaedah onResize.
* Alih keluar pendengar peristiwa resize Dokumen sebelum Halaman dinyahpasang.

Lihat kod berkaitan di bawah:
```js
export function didMount() {
  console.log(`「Page JS」: Current page URL ${location.href}`);

  window.addEventListener('resize', this.onResize);
}

export function willUnmount() {
  window.removeEventListener('resize', this.onResize);

}

export function onResize() {
  const width = document.documentElement.clientWidth;
  console.log(`current width: ${width}`);
}
```
