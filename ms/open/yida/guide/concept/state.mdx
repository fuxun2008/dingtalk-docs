Pemboleh ubah global dalam YiDA adalah serupa dengan konsep state React. Ia digunakan terutamanya untuk pengurusan keadaan peringkat halaman, dan pembangun boleh menukar keadaan global serta mencetuskan pemaparan semula halaman dengan memanggil API yang berkaitan.

## Cipta Pemboleh Ubah Global
Cipta pemboleh ubah global dengan menambahkannya dalam panel Sumber Data.

Semasa mencipta pemboleh ubah global, tentukan perkara berikut:
* **Nama** — Mengisytiharkan nama pemboleh ubah global. Mesti mematuhi konvensyen penamaan pemboleh ubah JavaScript.
* **Penerangan** — Menyediakan penerangan bagi pemboleh ubah global. Penerangan ini akan dipaparkan semasa pengikatan pemboleh ubah.
* **Data** — Menetapkan nilai awal pemboleh ubah global. Menyokong jenis asas JavaScript seperti string, boolean, dan object.

<Tip>
YiDA menyediakan pemboleh ubah global lalai `urlParams` untuk mendapatkan parameter daripada URL halaman semasa. Akses parameter URL melalui `this.state.urlParams.xxx`, dengan `xxx` ialah nama parameter. Jika parameter tersebut tidak wujud, nilainya ialah `undefined`.
</Tip>

## API
YiDA menyediakan dua API untuk membaca dan menulis pemboleh ubah global.

### Telah dibaca
Dalam panel pengikatan pemboleh ubah dan panel tindakan, dapatkan pemboleh ubah global halaman menggunakan API berikut. Dalam senario pengikatan pemboleh ubah, tinggalkan `this` dan gunakan `state.xxx` secara terus:
```js
const name = this.state.name;
```

### Kemas kini
Gunakan API `setState` untuk menukar pemboleh ubah global halaman dan mencetuskan pemaparan semula halaman (serupa dengan `setState` React), seperti ditunjukkan di bawah:
```js
this.setState({
  name: 'Jack'
});
```

<Warning>
API `setState` YiDA kelihatan konsisten dengan API React tetapi mempunyai sedikit perbezaan:
* API `setState` YiDA tidak menyediakan keupayaan Callback, jadi anda tidak boleh menghantar fungsi Callback seperti dalam `setState` React.
* API `setState` YiDA menggunakan model data reaktif. Oleh itu, anda boleh mengakses state baharu sejurus selepas memanggil `setState`, seperti ditunjukkan di bawah:
```js
// Anggap this.state.name ialah 'Alice' sebelum memanggil setState
this.setState({
  name: 'Bob'
});

// Mencetak: Bob
console.log(this.state.name); 

```

</Warning>
