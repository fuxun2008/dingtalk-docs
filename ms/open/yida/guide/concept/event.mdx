Pengendalian acara ialah salah satu logik yang paling biasa dalam pembangunan sistem. YiDA menyediakan keupayaan pengikatan tindakan pengguna Umum, bersama panel tindakan untuk menulis logik pengendalian JS. Untuk melaksanakan pengendalian acara, biasanya terdapat dua langkah berikut:
* Tambah Konfigurasi pengikatan tindakan pada Komponen (hampir setiap Komponen menawarkan pilihan pengikatan tindakan yang berkaitan).
* Laksanakan logik pengendalian tindakan dalam panel tindakan.

<Tip>
Semasa mengikat tindakan, Pengguna boleh Konfigurasikan parameter untuknya, seperti yang ditunjukkan di bawah. Parameter yang Dikonfigurasi boleh dibaca dalam Fungsi pelaksana melalui `this.params.xxx`, dengan `xxx` ialah nama parameter yang ditetapkan oleh Pengguna.

Cara membaca parameter:
```js
export function onClick(){
  const { name, age } = this.params
  console.log(name, age);
}
```
</Tip>

## Kes penggunaan
Berikut ialah Contoh mudah pengendalian acara:
Dengar Peristiwa klik Butang dan paparkan dialog pop-up untuk memaparkan maklumat berkaitan. Untuk melaksanakan ciri pengendalian acara, Pengguna perlu melakukan dua langkah berikut:
* Ikat Peristiwa Tindakan Pengguna Kepada Komponen. Seperti yang ditunjukkan di bawah, kami mengikat peristiwa `onClick` Kepada Komponen Butang.
* Laksanakan logik pengendalian acara yang berkaitan dalam panel tindakan. Apabila Pengguna mengklik Butang, kami memaparkan dialog pop-up untuk memaparkan ucapan (`state.name` ialah pemboleh ubah global yang kami tetapkan, dengan nilai awal "Xiaoming").

Apabila Pengguna mengklik butang Pratonton di penjuru kanan atas, kesan Pratonton berikut akan dipaparkan. Apabila Pengguna mengklik Butang Hello, program akan memaparkan dialog yang menunjukkan "Helo Xiaoming".
