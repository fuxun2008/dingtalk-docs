Anda mungkin mahu sesuatu komponen dipaparkan hanya dalam keadaan tertentu, seperti pendekatan berikut dalam React. YiDA menyediakan tetapan **Render Condition** yang membolehkan anda mengawal keterlihatan komponen dengan mudah melalui pengikatan pemboleh ubah:
```js
function HelloText({showName, name}) {
	return (
  	<div>
    {showName && (<span>{name}</span>)} // Gunakan showName untuk menentukan sama ada komponen teks nama dipaparkan
    </div>
  );
}
```

## Konfigurasikan
Setiap komponen mempunyai sifat **Render Condition** dalam tetapan Premium-nya, yang mengawal rendering bersyarat komponen tersebut.

Syarat rendering lalai ialah `true`. Biasanya, anda menggunakan pengikatan pemboleh ubah untuk menetapkan syarat rendering.

<Tip>
Komponen yang telah dikonfigurasi syarat rendering akan memaparkan ikon cabang dalam pepohon Outline, menunjukkan sifat Render Condition telah ditetapkan.

</Tip>

## Kes penggunaan
Contoh mudah berikut menunjukkan cara menggunakan rendering bersyarat.

Kawal keterlihatan komponen teks melalui parameter URL. Apabila parameter `showName` wujud dalam URL, komponen tersebut dipaparkan; jika tidak, ia disembunyikan. Konfigurasikan seperti berikut:
* Tetapkan sifat Render Condition komponen teks menggunakan pengikatan pemboleh ubah.

* Ikat pemboleh ubah global `state.urlParams.showName` kepada sifat Render Condition komponen teks untuk menentukan sama ada komponen teks dirender berdasarkan parameter URL.
