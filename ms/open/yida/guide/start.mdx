### Langkah 3: Seret Masuk Komponen dan Konfigurasikan Atribut

Demo kita sangat ringkas dan hanya mengandungi tiga Komponen. Seret Komponen tersebut daripada panel pustaka Komponen ke atas kanvas. Untuk pilihan konfigurasi Komponen yang lebih lanjut, lihat [Dokumentasi Komponen](/ms/open/yida/components/layout/tabsLayout):

- **Medan Input** — Digunakan untuk memasukkan nama. Tetapkan atribut `Title` kepada "Name".
- **Butang** — Digunakan untuk membaca nama yang dimasukkan dan menjana ucapan salam. Tetapkan atribut `Title` kepada "Generate".
- **Teks** — Digunakan untuk memaparkan ucapan salam. Untuk penampilan yang lebih baik, tetapkan margin atas kepada 20px dan Saiz Fon kepada 20px dalam panel gaya, seperti ditunjukkan di bawah.

### Langkah 5: Ikat Peristiwa Klik Butang

Apabila pengguna klik butang, kita perlu membaca kandungan medan input dan memaparkan ucapan salam yang dijana di bawahnya. Bahagian ini menerangkan cara mengikat Peristiwa dan menjana ucapan salam:

**1.** Ikat Peristiwa klik pada butang. Seperti ditunjukkan di bawah, satu fungsi JS akan dijana secara automatik dalam panel tindakan selepas pengikatan (anda juga boleh menyesuaikan nama fungsi).

**2.** Gunakan API getValue untuk membaca kandungan medan input. YiDA menyediakan pelbagai [YiDA JSAPI](/ms/open/yida/api/yidaAPI) yang lengkap. Seperti ditunjukkan di bawah, dapatkan input pengguna menggunakan pengecam unik bagi Komponen medan input:

**3.** Bina ucapan salam, kemudian gunakan API setState untuk mengemas kini pemboleh ubah global dan mencetuskan render semula halaman. Kod lengkap untuk onClick adalah seperti berikut:

```js
export function onClick() {
  // Dapatkan nilai daripada medan input nama
  const name = this.$('textField_kzdxqcod').getValue();

  // Kemas kini pemboleh ubah global
  this.setState({
    helloWord: `Hello ${name} !`,
  });
}
```
