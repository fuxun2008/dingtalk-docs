## Bila Hendak Digunakan

- Biasanya digunakan dalam senario Maklum Balas pengguna.

## Contoh Komponen

## Atribut Komponen

| Atribut | Penerangan | Jenis | Lalai |
|---|---|---|---|
| `allowHalf` | Sama ada penilaian separuh bintang disokong | `boolean` | `false` |
| `behavior` | Status paparan komponen borang | [Behavior](/open/yida/components/interface#behavior) | `'NORMAL'` |
| `count` | Jumlah Kira bintang penilaian | `number` | `5` |
| `label` | Tajuk komponen borang | `string` | - |
| `labelAlign` | Lokasi Tajuk komponen borang | `'left' \| 'top'` | `'top'` |
| `labelColOffset` | Kedudukan ofset Tajuk. Nilai ini ialah nilai grid, dengan 1 mewakili 1/24 | `number` | `0` |
| `labelColSpan` | Lebar Tajuk. Nilai ini ialah nilai grid, dengan 1 mewakili 1/24 | `number` | `4` |
| `labelTextAlign` | Penjajaran Tajuk komponen borang | `'left' \| 'right'` | `'right'` |
| `labelTipsIcon` | Ikon Entri untuk Petua Tajuk komponen borang. Berkuat kuasa apabila labelTipsTypes ditetapkan kepada **Teks** atau **render** | `string` | - |
| `labelTipsRender` | Kaedah render Tersuai untuk Petua Tajuk komponen borang. Berkuat kuasa apabila labelTipsTypes ditetapkan kepada **render** | `(props: IComponentProps) => ReactNode` | - |
| `labelTipsText` | Teks Petua Tajuk komponen borang. Berkuat kuasa apabila labelTipsTypes ditetapkan kepada **Teks** | `string` | - |
| `labelTipsTypes` | Tetapan Jenis untuk Petua Tajuk komponen borang | [LabelTipsTypes](/open/yida/components/interface#labeltipstypes) | `'none'` |
| `onChange` | Dicetuskan apabila pengguna mengklik satu penilaian | `({ value: number }) => void` | - |
| `onHoverChange` | Dicetuskan apabila pengguna menuding pada satu penilaian | `(value: number) => void` | - |
| `showGrade` | Sama ada memaparkan skor | `boolean` | `false` |
| `size` | Saiz komponen borang | [Size](/open/yida/components/interface#size) | `'medium'` |
| `tips` | Penerangan komponen borang, dipaparkan di bawah kawalan | `string` | - |
| `validation` | Tetapan pengesahan komponen borang. Untuk butiran, lihat [Dokumen Pengesahan Borang](/open/yida/guide/concept/validation) | [Validation[]](/open/yida/components/interface#validation) | `[]` |
| `value` | Nilai Lalai komponen borang | `number` | `2.5` |
| `wrapperColOffset` | Kedudukan ofset komponen borang. Nilai ini ialah nilai grid, dengan 1 mewakili 1/24 | `number` | `0` |
| `wrapperColSpan` | Lebar komponen borang. Nilai ini ialah nilai grid, dengan 1 mewakili 1/24 | `number` | `0` |
