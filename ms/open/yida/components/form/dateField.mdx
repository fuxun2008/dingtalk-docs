## Bila Hendak Digunakan

- Untuk memasukkan atau memilih tarikh tertentu. Apabila pengguna perlu memasukkan tarikh, mereka boleh klik kotak input standard untuk membuka panel tarikh bagi tujuan pemilihan.

## Contoh Komponen

## Atribut Komponen

| Atribut | Penerangan | Jenis | Lalai |
|---|---|---|---|
| `behavior` | Keadaan paparan komponen borang | [Behavior](/open/yida/components/interface#behavior) | `'NORMAL'` |
| `disabledDate` | Sekatan tersuai. Berkuat kuasa apabila atribut **type** ditetapkan kepada `custom`. | `(current: number)=> boolean` | - |
| `end` | Masa tamat tarikh. Berkuat kuasa apabila atribut **type** ditetapkan kepada `duration`. | `number` | - |
| `format` | Format tarikh | `'YYYY' \| 'YYYY-MM' \| 'YYYY-MM-DD'\| 'YYYY-MM-DD HH:mm'\| 'YYYY-MM-DD HH:mm:ss'` | `'YYYY-MM-DD'` |
| `hasClear` | Sama ada butang kosongkan dipaparkan | `boolean` | `true` |
| `label` | Tajuk komponen borang | `string` | - |
| `labelAlign` | Lokasi tajuk komponen borang | `'left' \| 'top'` | `'top'` |
| `labelColOffset` | Menetapkan kedudukan ofset tajuk. Nilai ini ialah nilai grid, dengan 1 mewakili 1/24. | `number` | `0` |
| `labelColSpan` | Menetapkan lebar tajuk. Nilai ini ialah nilai grid, dengan 1 mewakili 1/24. | `number` | `4` |
| `labelTextAlign` | Penjajaran tajuk komponen borang | `'left' \| 'right'` | `'right'` |
| `labelTipsIcon` | Ikon entri bagi tip tajuk komponen borang. Berkuat kuasa apabila `labelTipsTypes` ditetapkan kepada **text** atau **render**. | `string` | - |
| `labelTipsRender` | Kaedah pemaparan tersuai bagi tip tajuk komponen borang. Berkuat kuasa apabila `labelTipsTypes` ditetapkan kepada **render**. | `(props: IComponentProps) => ReactNode` | - |
| `labelTipsText` | Teks tip bagi tajuk komponen borang. Berkuat kuasa apabila `labelTipsTypes` ditetapkan kepada **text**. | `string` | - |
| `labelTipsTypes` | Tetapan jenis bagi tip tajuk komponen borang | [LabelTipsTypes](/open/yida/components/interface#labeltipstypes) | `'none'` |
| `onChange` | Peristiwa yang dicetuskan apabila nilai komponen berubah | `({value: number})=> void` | - |
| `onOk` | Peristiwa yang dicetuskan apabila Sahkan diklik | `({value: number})=> void` | - |
| `onVisibleChange` | Peristiwa yang dicetuskan apabila lapisan timbul dipaparkan atau disembunyikan | `(visible: boolean) => void` | - |
| `placeholder` | Tip pemegang tempat | `string` | `'Please select'` |
| `resetTime` | Sama ada masa ditetapkan semula setiap kali tarikh dipilih | `boolean` | `false` |
| `returnType` | Jenis pulangan bagi tarikh | `'timestamp' \| 'string' \| 'moment'` | `'timestamp'` |
| `size` | Saiz komponen borang | [Size](/open/yida/components/interface#size) | `'medium'` |
| `start` | Masa mula tarikh. Berkuat kuasa apabila atribut **type** ditetapkan kepada `duration`. | `number` | - |
| `tips` | Penerangan komponen borang, dipaparkan di bawah kawalan | `string` | - |
| `type` | Julat sekatan masa | `'none' \| 'beforeToday' \| 'afterToday'\| 'duration'\| 'custom'` | `'none'` |
| `validation` | Tetapan pengesahan bagi komponen borang. Untuk maklumat lanjut, lihat [dokumentasi pengesahan borang](/open/yida/guide/concept/validation). | [Validation[]](/open/yida/components/interface#validation) | `[]` |
| `value` | Nilai lalai bagi pemilih tarikh | `number` | - |
| `wrapperColOffset` | Menetapkan kedudukan ofset komponen borang. Nilai ini ialah nilai grid, dengan 1 mewakili 1/24. | `number` | `0` |
| `wrapperColSpan` | Menetapkan lebar komponen borang. Nilai ini ialah nilai grid, dengan 1 mewakili 1/24. | `number` | `0` |
