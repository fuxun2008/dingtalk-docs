## Bila Hendak Digunakan

- Pemilih nombor yang mengesahkan dan membetulkan nilai input secara automatik.

## Contoh Komponen

## Atribut Komponen

| Atribut | Penerangan | Jenis | Lalai |
|---|---|---|---|
| `behavior` | Status paparan komponen borang | [Behavior](/ms/open/yida/components/interface#behavior) | `'NORMAL'` |
| `innerAfter` | Teks unit untuk medan input nombor | `string` | - |
| `innerBefore` | Teks awalan untuk komponen borang | `string` | - |
| `label` | Tajuk komponen borang | `string` | - |
| `labelAlign` | Lokasi tajuk komponen borang | `'left' \| 'top'` | `'top'` |
| `labelColOffset` | Kedudukan ofset tajuk. Nilai menggunakan unit grid, dengan 1 mewakili 1/24 | `number` | `0` |
| `labelColSpan` | Lebar tajuk. Nilai menggunakan unit grid, dengan 1 mewakili 1/24 | `number` | `4` |
| `labelTextAlign` | Penjajaran tajuk komponen borang | `'left' \| 'right'` | `'right'` |
| `labelTipsIcon` | Ikon entri untuk petua tajuk komponen borang. Berkuat kuasa apabila labelTipsTypes ditetapkan kepada **text** atau **render** | `string` | - |
| `labelTipsRender` | Kaedah pemaparan tersuai untuk petua tajuk komponen borang. Berkuat kuasa apabila labelTipsTypes ditetapkan kepada **render** | `(props: IComponentProps) => ReactNode` | - |
| `labelTipsText` | Teks petua tajuk komponen borang. Berkuat kuasa apabila labelTipsTypes ditetapkan kepada **text** | `string` | - |
| `labelTipsTypes` | Tetapan jenis untuk petua tajuk komponen borang | [LabelTipsTypes](/ms/open/yida/components/interface#labeltipstypes) | `'none'` |
| `onChange` | Peristiwa perubahan nilai komponen borang | `({value: number}) => void` | - |
| `placeholder` | Teks pemegang tempat untuk komponen borang | `string` | `'Enter a number'` |
| `precision` | Bilangan tempat perpuluhan. Nilai yang dibenarkan: 0 - 20 | `number` | `0` |
| `size` | Saiz komponen borang | [Size](/ms/open/yida/components/interface#size) | `'medium'` |
| `thousandsSeparators` | Sama ada hendak menggunakan pemisah ribuan | `boolean` | `false` |
| `tips` | Penerangan komponen borang, dipaparkan di bawah kawalan | `string` | - |
| `validation` | Tetapan pengesahan komponen borang. Untuk butiran, lihat [dokumentasi pengesahan borang](/ms/open/yida/guide/concept/validation) | [Validation[]](/ms/open/yida/components/interface#validation) | `[]` |
| `value` | Nilai lalai komponen borang | `number` | - |
| `wrapperColOffset` | Kedudukan ofset komponen borang. Nilai menggunakan unit grid, dengan 1 mewakili 1/24 | `number` | `0` |
| `wrapperColSpan` | Lebar komponen borang. Nilai menggunakan unit grid, dengan 1 mewakili 1/24 | `number` | `0` |
