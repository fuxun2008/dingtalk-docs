## Bila Digunakan

- Pilihan Lata terdiri daripada pemilih dan panel lata. Komponen lata disembunyikan sebagai lapisan popup dan biasanya digunakan dalam senario Borang.

## Contoh Komponen

## Sifat Komponen

| Atribut | Penerangan | Jenis | Lalai |
|---|---|---|---|
| `behavior` | Keadaan paparan komponen borang | [Behavior](/ms/open/yida/components/interface#behavior) | `'NORMAL'` |
| `columnsNum` | Tahap lata | `number` | `0` |
| `dataSource` | Sumber Data | [CascadeDataSource[]](/ms/open/yida/components/interface#cascadedatasource) | `[{ "value": "part", "label": { "type": "i18n", "en_US": "dep", "zh_CN": "部门" }, "children": [{ "value": "part_a", "label": "Department A" }, { "value": "part_b", "label": "Department B" } ] }, { "value": "product", "label": "Product", "children": [{ "value": "product_a", "label": "Product A" }, { "value": "product_b", "label": "Product B" } ] } ]` |
| `expandTriggerType` | Kelakuan Pencetus | `'click' \| 'hover'` | `click` |
| `hasArrow` | Sama ada untuk memaparkan anak panah dropdown | `boolean` | `true` |
| `hasBorder` | Sama ada untuk memaparkan sempadan | `boolean` | `true` |
| `hasClear` | Sama ada untuk memaparkan Butang kosongkan | `boolean` | `true` |
| `isLoadData` | Sama ada untuk mengaktifkan pemuatan asinkron | `boolean` | `false` |
| `label` | Tajuk komponen borang | `string` | - |
| `labelAlign` | Lokasi Tajuk komponen borang | `'left' \| 'top'` | `'top'` |
| `labelColOffset` | Menetapkan kedudukan ofset Tajuk. Nilai ini dalam unit grid, dengan 1 mewakili 1/24 | `number` | `0` |
| `labelColSpan` | Menetapkan lebar ruang letak Tajuk. Nilai ini dalam unit grid, dengan 1 mewakili 1/24 | `number` | `4` |
| `labelTextAlign` | Penjajaran Tajuk komponen borang | `'left' \| 'right'` | `'right'` |
| `labelTipsIcon` | Ikon Entri untuk petua Tajuk komponen borang. Berkuat kuasa apabila labelTipsTypes ditetapkan kepada **text** atau **render** | `string` | - |
| `labelTipsRender` | Kaedah render Tersuai untuk petua Tajuk komponen borang. Berkuat kuasa apabila labelTipsTypes ditetapkan kepada **render** | `(props: IComponentProps) => ReactNode` | - |
| `labelTipsText` | Teks petua untuk Tajuk komponen borang. Berkuat kuasa apabila labelTipsTypes ditetapkan kepada **text** | `string` | - |
| `labelTipsTypes` | Tetapan Jenis petua untuk Tajuk komponen borang | [LabelTipsTypes](/ms/open/yida/components/interface#labeltipstypes) | `'none'` |
| `listStyle` | Gaya Senarai | `React.CSSProperties` | `{}` |
| `loadData` | Fungsi loadData | `( node: object ) => Promise<CascadeDataSource[]>` | - |
| `notFoundContent` | Kandungan yang dipaparkan apabila tiada Data tersedia | `string` | `'No data'` |
| `onChange` | Dicetuskan apabila nilai berubah | `({ value: string \| array, data: object \| array , extra: object }) => void` | - |
| `onVisibleChange` | Dicetuskan apabila keterlihatan lapisan popup berubah | `( visible : boolean ) => void` | - |
| `optionAutoWidth` | Sama ada untuk mengaktifkan lebar automatik untuk pilihan. Disokong hanya pada PC | `boolean` | `false` |
| `placeholder` | Petua ruang letak | `string` | `'Please select'` |
| `showSearch` | Sama ada untuk memaparkan kotak Carian | `boolean` | `false` |
| `size` | Saiz komponen borang | [Size](/ms/open/yida/components/interface#size) | `'medium'` |
| `tips` | Penerangan komponen borang, dipaparkan di bawah kawalan | `string` | - |
| `validation` | Tetapan pengesahan untuk komponen borang. Untuk butiran, lihat [dokumentasi pengesahan borang](/ms/open/yida/guide/concept/validation) | [Validation[]](/ms/open/yida/components/interface#validation) | `[]` |
| `value` | Nilai nod terakhir dalam Sumber Data | `string` | `'part_b'` |
| `wrapperColOffset` | Menetapkan kedudukan ofset komponen borang. Nilai ini dalam unit grid, dengan 1 mewakili 1/24 | `number` | `0` |
| `wrapperColSpan` | Menetapkan lebar ruang letak komponen borang. Nilai ini dalam unit grid, dengan 1 mewakili 1/24 | `number` | `0` |
