description: "Panduan konfigurasi komponen input TextField DingTalk YiDA, termasuk atribut seperti placeholder dan pengesahan format. Komponen input teks satu baris paling biasa digunakan dalam borang."
polished: true
---

## Bila Hendak Digunakan

- Gunakan komponen ini untuk senario input maklumat berasaskan teks.

## Contoh Komponen

## Atribut Komponen

| Atribut | Penerangan | Jenis | Lalai |
|---|---|---|---|
| `addonAfter` | Kandungan yang dilampirkan selepas input. | `string` | - |
| `addonBefore` | Kandungan yang dilampirkan sebelum input. | `string` | - |
| `autoFocus` | Sama ada untuk mengaktifkan fokus automatik. | `boolean` | `false` |
| `autoHeight` | Mengaktifkan ketinggian automatik untuk input pelbagai baris. Berkuat kuasa apabila **htmlType** ditetapkan kepada textarea. | `boolean` | `false` |
| `behavior` | Keadaan paparan komponen borang. | [Behavior](/open/yida/components/interface#behavior) | `'NORMAL'` |
| `hasClear` | Sama ada untuk memaparkan butang kosongkan. | `boolean` | `true` |
| `hasLimitHint` | Sama ada untuk memaparkan kiraan aksara. | `boolean` | `false` |
| `htmlType` | Menetapkan jenis input. input: teks satu baris; textarea: teks pelbagai baris; password: input kata laluan. | `'input' \| 'textarea' \| 'password'` | `input` |
| `label` | Tajuk komponen borang. | `string` | - |
| `labelAlign` | Lokasi tajuk komponen borang. | `'left' \| 'top'` | `'top'` |
| `labelColOffset` | Menetapkan ofset tajuk. Nilai menggunakan sistem grid, dengan 1 mewakili 1/24. | `number` | `0` |
| `labelColSpan` | Menetapkan lebar tajuk. Nilai menggunakan sistem grid, dengan 1 mewakili 1/24. | `number` | `4` |
| `labelTextAlign` | Penjajaran tajuk komponen borang. | `'left' \| 'right'` | `'right'` |
| `labelTipsIcon` | Ikon entri untuk petua tajuk komponen borang. Berkuat kuasa apabila labelTipsTypes ditetapkan kepada **text** atau **render**. | `string` | - |
| `labelTipsRender` | Kaedah render tersuai untuk petua tajuk komponen borang. Berkuat kuasa apabila labelTipsTypes ditetapkan kepada **render**. | `(props: IComponentProps) => ReactNode` | - |
| `labelTipsText` | Teks petua untuk tajuk komponen borang. Berkuat kuasa apabila labelTipsTypes ditetapkan kepada **text**. | `string` | - |
| `labelTipsTypes` | Jenis petua untuk tajuk komponen borang. | [LabelTipsTypes](/open/yida/components/interface#labeltipstypes) | `'none'` |
| `maxLength` | Menetapkan kiraan aksara maksimum. | `number` | `200` |
| `onChange` | Peristiwa yang dicetuskan apabila nilai input berubah. | `({ value: string }) => void` | - |
| `onPressEnter` | Peristiwa yang dicetuskan apabila kekunci Enter ditekan dalam input. | `() => void` | - |
| `onScanCodeError` | Peristiwa yang dicetuskan apabila imbasan input gagal. | `(errorMsg: string) => void` | - |
| `onScanCodeSuccess` | Peristiwa yang dicetuskan apabila imbasan input berjaya. | `(text: string) => void` | - |
| `placeholder` | Teks placeholder. | `string` | `'Please enter'` |
| `rows` | Ketinggian input pelbagai baris. Berkuat kuasa apabila **htmlType** ditetapkan kepada textarea. | `number` | `4` |
| `scanCode` | Sama ada untuk mengaktifkan mod imbasan (hanya disokong dalam aplikasi mudah alih DingTalk). | [ScanCodeConfig](/open/yida/components/interface#scancodeconfig) \| boolean | `false` |
| `size` | Saiz komponen borang. | [Size](/open/yida/components/interface#size) | `'medium'` |
| `state` | Menetapkan keadaan input. | `'error' \| 'loading' \| 'success' \| ''` | `''` |
| `tips` | Penerangan komponen borang, dipaparkan di bawah kawalan. | `string` | - |
| `trim` | Sama ada untuk memangkas ruang kosong di hadapan dan belakang secara automatik. | `boolean` | `false` |
| `validation` | Tetapan pengesahan untuk komponen borang. Untuk butiran, lihat [dokumentasi pengesahan borang](/open/yida/guide/concept/validation). | [Validation[]](/open/yida/components/interface#validation) | `[]` |
| `validationType` | Format pengesahan untuk nilai input. | `'text' \| 'mobile' \| 'email' \| 'url' \| 'chineseID' \| 'password'` | `'text'` |
| `value` | Menetapkan nilai lalai input. | `string` | - |
| `wrapperColOffset` | Menetapkan ofset komponen borang. Nilai menggunakan sistem grid, dengan 1 mewakili 1/24. | `number` | `0` |
| `wrapperColSpan` | Menetapkan lebar komponen borang. Nilai menggunakan sistem grid, dengan 1 mewakili 1/24. | `number` | `0` |
