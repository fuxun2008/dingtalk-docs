## Bila hendak digunakan

- Digunakan untuk senario penghantaran subborang.

## Definisi jenis
### Struktur konfigurasi item tindakan tersuai

```ts
interface Action {
  content: string; // Label item tindakan
  callback: ({index: number, groupId: string, itemValue: any, actionKey: string }) => void; // Callback klik
  render: ({index: number, groupId: string, itemValue: any, actionKey: string }) => ReactNode; // Render tersuai
}
```

## Atribut komponen

| Atribut | Penerangan | Jenis | Lalai |
