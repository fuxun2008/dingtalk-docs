## Bila Hendak Digunakan
- Untuk menentukan pelaksana pada halaman.
- Untuk membenarkan pengguna mendaftarkan maklumat Profil.

## Contoh Komponen

## Sifat Komponen

| Atribut | Penerangan | Jenis | Lalai |
|---|---|---|---|
| `beforeSearch` | Memproses parameter sebelum menghantar permintaan carian untuk pengguna. Berkuat kuasa apabila atribut **dataType** ialah url. | `(params: Record<string, string>) => Record<string, string>` | - |
| `beforeSearchTeam` | Memproses parameter sebelum menghantar permintaan carian untuk organisasi. Berkuat kuasa apabila atribut **dataType** ialah url. | `(params: Record<string, string>) => Record<string, string>` | - |
| `behavior` | Status paparan komponen borang. | [Behavior](/open/yida/components/interface#behavior) | `'NORMAL'` |
| `closeOnSelect` | Sama ada hendak Tutup selepas pemilihan. | `boolean` | `false` |
| `dataSource` | Data Pengguna. Berkuat kuasa apabila **dataType** ialah dataSource. | `any[]` | - |
| `dataType` | Jenis data. url: permintaan URL HTTP; DataSource: Sumber Data. | `'url' \| 'dataSource'` | `'url'` |
| `emplIdInLabel` | Sama ada memaparkan ID Pekerja dalam keputusan Dipilih. | `boolean` | `true` |
| `fetchDataOnMount` | Sama ada meminta URL HTTP secara automatik selepas halaman dimuatkan. | `boolean` | `true` |
| `fit` | Pemprosesan keputusan Data async. Berkuat kuasa apabila atribut **dataType** ialah url. | `(response: any) => any` | - |
| `hasClear` | Memaparkan butang kosongkan. | `boolean` | `true` |
| `hasOrderNum` | Memaparkan jawatan utama dan serentak. | `boolean` | - |
| `hiddenSelected` | - | `boolean` | - |
| `label` | Tajuk komponen borang. | `string` | - |
| `labelAlign` | Kedudukan Tajuk komponen borang. | `'left' \| 'top'` | `'top'` |
| `labelColOffset` | Menetapkan kedudukan ofset Tajuk. Nilai adalah unit grid, dengan 1 mewakili 1/24. | `number` | `0` |
| `labelColSpan` | Menetapkan lebar placeholder Tajuk. Nilai adalah unit grid, dengan 1 mewakili 1/24. | `number` | `4` |
| `labelTextAlign` | Kaedah Jajarkan untuk Tajuk komponen borang. | `'left' \| 'right'` | `'right'` |
| `labelTipsIcon` | Ikon Entri untuk maklumat Petua Tajuk komponen borang. Berkuat kuasa apabila labelTipsTypes ialah **text** atau **render**. | `string` | - |
| `labelTipsRender` | Kaedah render Tersuai untuk maklumat Petua Tajuk komponen borang. Berkuat kuasa apabila labelTipsTypes ialah **render**. | `(props: IComponentProps) => ReactNode` | - |
| `labelTipsText` | Teks maklumat Petua Tajuk komponen borang. Berkuat kuasa apabila labelTipsTypes ialah **text**. | `string` | - |
| `labelTipsTypes` | Tetapan Jenis untuk maklumat Petua Tajuk komponen borang. | [LabelTipsTypes](/open/yida/components/interface#labeltipstypes) | `'none'` |
| `multiple` | Aktifkan mod Pilih Banyak. | `boolean` | `false` |
| `orderNum` | Apabila 0, menggunakan mod pemilihan pengguna (hanya memaparkan maklumat jawatan utama). Apabila bukan sifar, menggunakan mod pemilihan jawatan (mendedahkan butiran jawatan serentak yang banyak). | `string` | - |
| `placeholder` | Petua placeholder untuk kotak carian pengguna. | `string` | `'Sila Pilih'` |
| `renderOption` | Medan render pilihan Tersuai. | `(option: any) => string` | - |
| `renderSelection` | Medan render Tersuai selepas pemilihan. | `(option: any) => string` | - |
| `searchDelay` | Kelewatan Cari, dalam ms. | `number` | `100` |
| `showAllSub` | Memaparkan Semua Ahli. | `boolean` | - |
| `showAvater` | Sama ada memaparkan Gambar Profil dalam popup pemilihan. | `boolean` | `true` |
| `showDeptDesc` | Sama ada memaparkan penerangan Jabatan. | `boolean` | `true` |
| `showEmplId` | Sama ada kotak carian pengguna memaparkan ID Pekerja. | `boolean` | `false` |
| `showJobDesc` | Sama ada memaparkan penerangan Jawatan. | `boolean` | `true` |
| `showSub` | Memaparkan orang bawahan. | `boolean` | `false` |
| `size` | Saiz komponen borang. | [Size](/open/yida/components/interface#size) | `'medium'` |
| `subUrl` | URL HTTP async untuk orang bawahan. URL perkhidmatan Tersuai yang digunakan semasa mencari semua Ahli dan orang bawahan. Lalai kepada URL HTTP utama. | `string` | - |
| `tips` | Maklumat penerangan komponen borang, dipaparkan di bawah kawalan. | `string` | - |
| `url` | URL HTTP async untuk maklumat pengguna. Berkuat kuasa apabila atribut **dataType** ialah url. | `string` | - |
| `validation` | Tetapan pengesahan komponen borang. Untuk butiran, lihat [Dokumen Pengesahan Borang](/open/yida/guide/concept/validation). | [Validation[]](/open/yida/components/interface#validation) | `[]` |
| `value` | Nilai Lalai bagi komponen semasa. | `any[]` | - |
| `wrapperColOffset` | Menetapkan kedudukan ofset komponen borang. Nilai adalah unit grid, dengan 1 mewakili 1/24. | `number` | `0` |
| `wrapperColSpan` | Menetapkan lebar placeholder komponen borang. Nilai adalah unit grid, dengan 1 mewakili 1/24. | `number` | `0` |
