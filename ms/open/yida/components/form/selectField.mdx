## Bila Hendak Digunakan

Gunakan untuk menggantikan select asli dan memilih satu pilihan daripada set pilihan yang terhad. Keupayaan teras ialah pemilihan.

## Contoh Komponen

## Sifat Komponen

| Atribut | Penerangan | Jenis | Lalai |
|---|---|---|---|
| `autoWidth` | Sama ada menu dropdown sejajar dengan selektor. | `boolean` | `true` |
| `behavior` | Keadaan paparan komponen borang. | [Behavior](/ms/open/yida/components/interface#behavior) | `'NORMAL'` |
| `dataSource` | Konfigurasikan pilihan. | [DataSource[]](/ms/open/yida/components/interface#datasource) | `[ { "text": "Option 1", "value": "1" }, { "text": "Option 2", "value": "2" }, { "text": "Option 3", "value": "3" } ]` |
| `filter` | Kaedah penapisan tempatan. Berkuat kuasa hanya apabila penapisan tempatan diaktifkan. | `(value: string, data: DataSource) => boolean` | - |
| `filterLocal` | Sama ada penapisan tempatan disokong. Matikan apabila sumber data adalah jauh (remote). | `boolean` | - |
| `hasArrow` | Sama ada anak panah dropdown dipaparkan. | `boolean` | `true` |
| `hasBorder` | Sama ada sempadan dipaparkan. | `boolean` | `true` |
| `hasClear` | Sama ada butang kosongkan dipaparkan. | `boolean` | `true` |
| `label` | Tajuk komponen borang. | `string` | - |
| `labelAlign` | Kedudukan tajuk komponen borang. | `'left' \| 'top'` | `'top'` |
| `labelColOffset` | Kedudukan ofset tajuk. Nilai menggunakan unit grid, di mana 1 mewakili 1/24. | `number` | `0` |
| `labelColSpan` | Lebar kawasan tajuk. Nilai menggunakan unit grid, di mana 1 mewakili 1/24. | `number` | `4` |
| `labelTextAlign` | Penjajaran teks tajuk komponen borang. | `'left' \| 'right'` | `'right'` |
| `labelTipsIcon` | Ikon entri petua tajuk. Berkuat kuasa apabila labelTipsTypes ditetapkan kepada **text** atau **render**. | `string` | - |
| `labelTipsRender` | Kaedah render tersuai untuk petua tajuk. Berkuat kuasa apabila labelTipsTypes ditetapkan kepada **render**. | `(props: IComponentProps) => ReactNode` | - |
| `labelTipsText` | Kandungan teks petua tajuk. Berkuat kuasa apabila labelTipsTypes ditetapkan kepada **text**. | `string` | - |
| `labelTipsTypes` | Jenis petua tajuk. | [LabelTipsTypes](/ms/open/yida/components/interface#labeltipstypes) | `'none'` |
| `notFoundContent` | Teks yang dipaparkan apabila tiada pilihan yang sepadan. | `string` | `'Please enter'` |
| `onChange` | Peristiwa yang dicetuskan apabila nilai komponen berubah. | `(value: string) => void` | - |
| `onRemove` | Peristiwa yang dicetuskan apabila satu nilai dialih keluar. | `(item: object) => void` | - |
| `onSearch` | Peristiwa yang dicetuskan apabila nilai kotak carian berubah. | `(keyword: string) => void` | - |
| `onVisibleChange` | Peristiwa yang dicetuskan apabila dropdown ditunjukkan atau disembunyikan. | `(visible: boolean) => void` | - |
| `placeholder` | Teks placeholder komponen borang. | `string` | `'Please select'` |
| `searchDelay` | Kelewatan carian dalam milisaat. | `number` | `300` |
| `showSearch` | Sama ada carian diaktifkan selepas dropdown dikembangkan. Sentiasa true dalam mod tag. | `boolean` | `true` |
| `size` | Saiz komponen borang. | [Size](/ms/open/yida/components/interface#size) | `'medium'` |
| `tips` | Teks penerangan komponen borang, dipaparkan di bawah kawalan. | `string` | - |
| `useDetailValue` | Sama ada menggunakan jenis object \{label, value} untuk nilai. | `boolean` | `false` |
| `validation` | Tetapan pengesahan borang. Untuk butiran, lihat [dokumentasi pengesahan borang](/ms/open/yida/guide/concept/validation). | [Validation[]](/ms/open/yida/components/interface#validation) | `[]` |
| `value` | Nilai lalai komponen semasa. | `string` | - |
| `wrapperColOffset` | Kedudukan ofset komponen borang. Nilai menggunakan unit grid, di mana 1 mewakili 1/24. | `number` | `0` |
| `wrapperColSpan` | Lebar kawasan komponen borang. Nilai menggunakan unit grid, di mana 1 mewakili 1/24. | `number` | `0` |
