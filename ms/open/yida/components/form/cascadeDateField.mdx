## Bila Digunakan

- Masukkan atau pilih julat tarikh. Apabila pengguna perlu memasukkan julat tarikh, klik kotak input standard untuk membuka panel tarikh dan membuat pilihan.

## Contoh Komponen

## Atribut Komponen

| Atribut | Penerangan | Jenis | Lalai |
|---|---|---|---|
| `behavior` | Status paparan komponen borang | [Behavior](/open/yida/components/interface#behavior) | `'NORMAL'` |
| `disabledDate` | Sekatan tersuai. Berkuat kuasa apabila atribut **type** ditetapkan kepada tersuai | `(current: number)=> boolean` | - |
| `format` | Format paparan komponen julat tarikh | `'YYYY' \| 'YYYY-MM' \| 'YYYY-MM-DD' \| 'YYYY-MM-DD HH:mm' \| 'YYYY-MM-DD HH:mm'YYY-MM-DD HH:mm:ss` | `'YYY-MM-DD'` |
| `hasClear` | Sama ada untuk menunjukkan butang kosongkan | `boolean` | `true` |
| `label` | Tajuk komponen borang | `string` | - |
| `labelAlign` | Lokasi tajuk komponen borang | `'left' \| 'top'` | `'top'` |
| `labelColOffset` | Lokasi ofset tajuk. Nilai menggunakan sistem grid, dengan 1 mewakili 1/24 | `number` | `0` |
| `labelColSpan` | Lebar yang diduduki oleh tajuk. Nilai menggunakan sistem grid, dengan 1 mewakili 1/24 | `number` | `4` |
| `labelTextAlign` | Penjajaran tajuk komponen borang | `'left' \| 'right'` | `'right'` |
| `labelTipsIcon` | Ikon entri untuk petua tajuk komponen borang. Berkuat kuasa apabila labelTipsTypes ditetapkan kepada **text** atau **render** | `string` | - |
| `labelTipsRender` | Kaedah render tersuai untuk petua tajuk komponen borang. Berkuat kuasa apabila labelTipsTypes ditetapkan kepada **render** | `(props: IComponentProps) => ReactNode` | - |
| `labelTipsText` | Teks petua untuk tajuk komponen borang. Berkuat kuasa apabila labelTipsTypes ditetapkan kepada **text** | `string` | - |
| `labelTipsTypes` | Jenis petua tajuk komponen borang | [LabelTipsTypes](/open/yida/components/interface#labeltipstypes) | `'none'` |
| `onChange` | Peristiwa yang dicetuskan apabila nilai komponen berubah | `({value：object}) => void` | - |
| `onOk` | Peristiwa yang dicetuskan apabila Sahkan diklik | `(value: object) => void` | - |
| `onVisibleChange` | Peristiwa yang dicetuskan apabila panel timbul ditunjukkan atau disembunyikan | `(visible：boolean) => void` | - |
| `placeholder` | Teks placeholder komponen borang | `string` | `'Please select'` |
| `ranges` | Pilihan julat pantas | `()=> number[]` | - |
| `resetTime` | Sama ada untuk menetapkan semula masa setiap kali tarikh dipilih | `boolean` | `false` |
| `returnType` | Jenis pemulangan julat tarikh | `'timestamp' \| 'string' \| 'moment'` | `'timestamp'` |
| `size` | Saiz komponen borang | [Size](/open/yida/components/interface#size) | `'medium'` |
| `tips` | Penerangan komponen borang, dipaparkan di bawah kawalan | `string` | - |
| `validation` | Tetapan pengesahan borang. Untuk maklumat lanjut, lihat [dokumentasi pengesahan borang](/open/yida/guide/concept/validation) | [Validation[]](/open/yida/components/interface#validation) | `[]` |
| `value` | Nilai lalai komponen borang | `number[]` | - |
| `wrapperColOffset` | Lokasi ofset komponen borang. Nilai menggunakan sistem grid, dengan 1 mewakili 1/24 | `number` | `0` |
| `wrapperColSpan` | Lebar yang diduduki oleh komponen borang. Nilai menggunakan sistem grid, dengan 1 mewakili 1/24 | `number` | `0` |
