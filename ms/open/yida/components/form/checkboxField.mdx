## Bila Digunakan

- Apabila anda perlu memilih beberapa item daripada sekumpulan pilihan.
- Apabila digunakan secara bersendirian, Kotak semak boleh mewakili pertukaran antara dua keadaan, serupa dengan suis. Perbezaannya ialah menukar suis mencetuskan perubahan keadaan dengan segera, manakala Kotak semak biasanya digunakan untuk penandaan keadaan dan berfungsi bersama tindakan Hantar.

## Atribut Komponen

| Atribut | Penerangan | Jenis | Lalai |
|---|---|---|---|
| `behavior` | Keadaan paparan komponen borang | [Behavior](/ms/open/yida/components/interface#behavior) | `'NORMAL'` |
| `dataSource` | Mengkonfigurasikan pilihan | [DataSource[]](/ms/open/yida/components/interface#datasource) | `[ { "text": "Pilihan 1", "value": "1" }, { "text": "Pilihan 2", "value": "2" }, { "text": "Pilihan 3", "value": "3" } ]` |
| `iconPosition` | Kedudukan ikon pada mudah alih | `'left' \| 'right'` | `'left'` |
| `itemDirection` | Arah susun atur pilihan pada PC | `'hoz' \| 'ver'` | `'hoz'` |
| `label` | Tajuk komponen borang | `string` | - |
| `labelAlign` | Kedudukan tajuk komponen borang | `'left' \| 'top'` | `'top'` |
| `labelColOffset` | Kedudukan ofset tajuk. Nilai mengikut sistem grid, dengan 1 mewakili 1/24. | `number` | `0` |
| `labelColSpan` | Lebar tajuk. Nilai mengikut sistem grid, dengan 1 mewakili 1/24. | `number` | `4` |
| `labelTextAlign` | Penjajaran teks tajuk komponen borang | `'left' \| 'right'` | `'right'` |
| `labelTipsIcon` | Ikon untuk entri petua tajuk komponen borang. Berkuat kuasa apabila labelTipsTypes ialah **text** atau **render**. | `string` | - |
| `labelTipsRender` | Kaedah render tersuai untuk petua tajuk komponen borang. Berkuat kuasa apabila labelTipsTypes ialah **render**. | `(props: IComponentProps) => ReactNode` | - |
| `labelTipsText` | Teks petua untuk tajuk komponen borang. Berkuat kuasa apabila labelTipsTypes ialah **text**. | `string` | - |
| `labelTipsTypes` | Jenis petua untuk tajuk komponen borang | [LabelTipsTypes](/ms/open/yida/components/interface#labeltipstypes) | `'none'` |
| `onChange` | Acara yang dicetuskan apabila nilai komponen berubah | `(value: string[]) => void` | - |
| `size` | Saiz komponen borang | [Size](/ms/open/yida/components/interface#size) | `'medium'` |
| `tips` | Penerangan komponen borang, dipaparkan di bawah kawalan | `string` | - |
| `useDrawerInMobile` | Gaya susun atur pada mudah alih. Apabila true, pilihan disusun atur sebaris; apabila false, laci bawah digunakan. | `boolean` | `false` |
| `validation` | Tetapan pengesahan untuk komponen borang. Untuk butiran, lihat [dokumentasi pengesahan borang](/ms/open/yida/guide/concept/validation). | [Validation[]](/ms/open/yida/components/interface#validation) | `[]` |
| `value` | Nilai lalai komponen semasa | `string[]` | - |
| `wrapperColOffset` | Kedudukan ofset komponen borang. Nilai mengikut sistem grid, dengan 1 mewakili 1/24. | `number` | `0` |
| `wrapperColSpan` | Lebar komponen borang. Nilai mengikut sistem grid, dengan 1 mewakili 1/24. | `number` | `0` |
