description: "Panduan komponen ImageField untuk muat naik gambar di YiDA, termasuk had bilangan gambar dan tetapan pratonton, bagi memuat naik serta menghantar aset gambar dalam borang."
polished: true

## Bila Digunakan

- Digunakan dalam senario yang memerlukan muat naik dan penghantaran aset gambar.

## Contoh Komponen

## Atribut Komponen

| Atribut | Penerangan | Jenis | Lalai |
|---|---|---|---|
| `accept` | Menetapkan jenis gambar yang diterima untuk dimuat naik (pisahkan pelbagai nilai dengan koma). | `string` | `'image/*'` |
| `autoUpload` | Sama ada muat naik secara automatik. Apabila dinyahaktifkan, panggil `this.$('fieldId').startUpload()` secara manual untuk memulakan muat naik. | `boolean` | `true` |
| `beforeUpload` | Peristiwa yang dicetuskan sebelum muat naik. | `(file: object, options: object) => void` | - |
| `behavior` | Keadaan paparan komponen borang. | [Behavior](/open/yida/components/interface#behavior) | `'NORMAL'` |
| `buttonSize` | Saiz butang muat naik. | `'small' \| 'medium' \| 'large'` | `'medium'` |
| `buttonText` | Menetapkan kandungan butang. Hanya berkesan pada PC. | `string` | `'Upload File'` |
| `buttonType` | Jenis butang muat naik. | `'primary' \| 'secondary' \| 'normal'` | `'primary'` |
| `customUploadPane` | Panel tersuai. | `() => ReactNode` | - |
| `data` | Menetapkan parameter tambahan yang disertakan semasa muat naik. | `object` | `{}` |
| `formatter` | Peristiwa pemprosesan data. | `(response: any) => any` | - |
| `label` | Tajuk komponen borang. | `string` | - |
| `labelAlign` | Kedudukan tajuk komponen borang. | `'left' \| 'top'` | `'top'` |
| `labelColOffset` | Menetapkan kedudukan ofset tajuk. Nilai ini adalah nilai grid, dengan 1 mewakili 1/24. | `number` | `0` |
| `labelColSpan` | Menetapkan lebar yang diduduki oleh tajuk. Nilai ini adalah nilai grid, dengan 1 mewakili 1/24. | `number` | `4` |
| `labelTextAlign` | Penjajaran tajuk komponen borang. | `'left' \| 'right'` | `'right'` |
| `labelTipsIcon` | Ikon bagi titik masuk petua tajuk komponen borang. Berkesan apabila `labelTipsTypes` ditetapkan kepada **text** atau **render**. | `string` | - |
| `labelTipsRender` | Kaedah rendering tersuai untuk petua tajuk komponen borang. Berkesan apabila `labelTipsTypes` ditetapkan kepada **render**. | `(props: IComponentProps) => ReactNode` | - |
| `labelTipsText` | Teks petua bagi tajuk komponen borang. Berkesan apabila `labelTipsTypes` ditetapkan kepada **text**. | `string` | - |
| `labelTipsTypes` | Menetapkan jenis petua untuk tajuk komponen borang. | [LabelTipsTypes](/open/yida/components/interface#labeltipstypes) | `'none'` |
| `limit` | Menetapkan bilangan maksimum fail yang boleh dimuat naik. | `number` | `9` |
| `maxFileSize` | Menetapkan saiz maksimum bagi setiap fail (MB). | `number` | `50` |
| `multiple` | Sama ada menyokong muat naik pelbagai gambar. | `boolean` | `true` |
| `name` | Nama yang dihantar ke pihak pelayan semasa muat naik. | `string` | - |
| `normalListType` | Menetapkan gaya senarai. | `'text' \| 'image'` | `'image'` |
| `onCancel` | Peristiwa yang dicetuskan apabila pengguna klik untuk membatalkan muat naik. | `() => void` | - |
| `onChange` | Peristiwa yang dicetuskan apabila nilai komponen berubah. | `({ value: object }) => void` | - |
| `onDragLeave` | Peristiwa yang dicetuskan apabila seretan meninggalkan komponen. | `() => void` | - |
| `onDragOver` | Peristiwa yang dicetuskan apabila seretan melepasi komponen. | `() => void` | - |
| `onDrop` | Peristiwa yang dicetuskan apabila seretan selesai pada komponen. | `() => void` | - |
| `onError` | Peristiwa yang dicetuskan apabila nilai komponen gagal dimuat naik. | `(file: object, value: array) => void` | - |
| `onProgress` | Peristiwa yang dicetuskan semasa komponen sedang memuat naik. | `() => void` | - |
| `onRemove` | Peristiwa yang dicetuskan apabila pengguna klik untuk mengalih keluar nilai komponen. | `(file: object) => void` | - |
| `onSelect` | Peristiwa yang dicetuskan apabila nilai komponen dipilih. | `(file: object) => void` | - |
| `onSuccess` | Peristiwa yang dicetuskan apabila nilai komponen berjaya dimuat naik. | `(file: object, value: array) => void` | - |
| `onlyCameraUpload` | Benarkan muat naik hanya melalui kamera. Ciri ini pada masa ini hanya disokong pada klien mudah alih DingTalk. Apabila diaktifkan, fungsi muat naik akan dinyahaktifkan secara automatik pada klien mudah alih bukan DingTalk. | `boolean` | `false` |
| `size` | Saiz komponen borang. | [Size](/open/yida/components/interface#size) | `'medium'` |
| `timeout` | Menetapkan had masa muat naik, dalam ms. | `number` | `0` |
| `tips` | Penerangan komponen borang, dipaparkan di bawah kawalan. | `string` | - |
| `type` | Menetapkan jenis muat naik. Hanya berkesan pada PC. | `'normal' \| 'drag' \| 'card'` | `'normal'` |
| `validation` | Tetapan pengesahan komponen borang. Untuk maklumat lanjut, lihat [Dokumentasi Pengesahan Borang](/open/yida/guide/concept/validation). | [Validation[]](/open/yida/components/interface#validation) | `[]` |
| `value` | Nilai lalai. | `array` | - |
| `withCredentials` | Menetapkan sama ada permintaan dibenarkan membawa cookie. | `boolean` | `false` |
| `wrapperColOffset` | Menetapkan kedudukan ofset komponen borang. Nilai ini adalah nilai grid, dengan 1 mewakili 1/24. | `number` | `0` |
| `wrapperColSpan` | Menetapkan lebar yang diduduki oleh komponen borang. Nilai ini adalah nilai grid, dengan 1 mewakili 1/24. | `number` | `0` |
