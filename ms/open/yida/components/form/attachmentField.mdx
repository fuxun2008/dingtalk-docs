## Bila Perlu Digunakan

- Gunakan komponen ini untuk senario muat naik dan penyerahan fail.

## Contoh Komponen

## Atribut Komponen

| Atribut | Penerangan | Jenis | Lalai |
|---|---|---|---|
| `accept` | Menetapkan jenis fail yang dibenarkan untuk dimuat naik (pisahkan berbilang nilai dengan koma), contohnya, .doc, .docx, .pdf. | `string` | - |
| `autoUpload` | Sama ada memuat naik secara automatik. Apabila dinyahaktifkan, anda perlu memanggil this.$('fieldId').startUpload() secara manual untuk memulakan muat naik. | `boolean` | `true` |
| `beforeUpload` | Peristiwa pemprosesan sebelum muat naik. | `(file: object, options: object) => void` | - |
| `behavior` | Keadaan paparan komponen borang. | [Behavior](/open/yida/components/interface#behavior) | `'NORMAL'` |
| `buttonSize` | Menetapkan saiz butang. | `'small' \| 'medium' \| 'large'` | `'medium'` |
| `buttonText` | Menetapkan kandungan butang. | `string` | `'Muat Naik Fail'` |
| `buttonType` | Menetapkan jenis butang. | `'primary' \| 'secondary' \| 'normal'` | `'primary'` |
| `customUploadPane` | Panel tersuai. | `() => ReactNode` | - |
| `data` | Menetapkan parameter tambahan yang disertakan pada muat naik. | `Record<string, string>` | `{}` |
| `formatter` | Peristiwa pemprosesan data. | `(response: any) => any` | - |
| `headers` | Menetapkan header permintaan untuk muat naik. | `Record<string, string>` | `{}` |
| `label` | Tajuk komponen borang. | `string` | - |
| `labelAlign` | Kedudukan tajuk komponen borang. | `'left' \| 'top'` | `'top'` |
| `labelColOffset` | Menetapkan kedudukan ofset tajuk. Nilai dalam unit grid, di mana 1 mewakili 1/24. | `number` | `0` |
| `labelColSpan` | Menetapkan lebar ruang letak tajuk. Nilai dalam unit grid, di mana 1 mewakili 1/24. | `number` | `4` |
| `labelTextAlign` | Penjajaran tajuk komponen borang. | `'left' \| 'right'` | `'right'` |
| `labelTipsIcon` | Ikon untuk entri petua tajuk komponen borang. Berkuat kuasa apabila labelTipsTypes ditetapkan kepada **text** atau **render**. | `string` | - |
| `labelTipsRender` | Kaedah render tersuai untuk petua tajuk komponen borang. Berkuat kuasa apabila labelTipsTypes ditetapkan kepada **render**. | `(props: IComponentProps) => ReactNode` | - |
| `labelTipsText` | Kandungan teks petua tajuk komponen borang. Berkuat kuasa apabila labelTipsTypes ditetapkan kepada **text**. | `string` | - |
| `labelTipsTypes` | Tetapan jenis untuk petua tajuk komponen borang. | [LabelTipsTypes](/open/yida/components/interface#labeltipstypes) | `'none'` |
| `limit` | Menetapkan bilangan maksimum fail yang boleh dimuat naik. | `number` | `9` |
| `maxFileSize` | Menetapkan saiz maksimum bagi setiap fail (dalam MB). | `number` | `50` |
| `multiple` | Sama ada muat naik berbilang fail disokong. | `boolean` | `true` |
| `name` | Nama yang dihantar ke bahagian pelayan semasa muat naik. | `string` | - |
| `onCancel` | Peristiwa dicetuskan apabila pengguna membatalkan muat naik. | `() => void` | - |
| `onChange` | Peristiwa dicetuskan apabila nilai komponen berubah. | `({ value: object }) => void` | - |
| `onDragLeave` | Peristiwa dicetuskan apabila tindakan seret meninggalkan komponen. | `() => void` | - |
| `onDragOver` | Peristiwa dicetuskan apabila tindakan seret melalui komponen. | `() => void` | - |
| `onDrop` | Peristiwa dicetuskan apabila tindakan seret selesai pada komponen. | `() => void` | - |
| `onError` | Peristiwa dicetuskan apabila muat naik komponen gagal. | `(file: object, value: array) => void` | - |
| `onProgress` | Peristiwa dicetuskan semasa komponen sedang memuat naik. | `() => void` | - |
| `onRemove` | Peristiwa dicetuskan apabila pengguna mengalih keluar fail yang telah dimuat naik. | `(file: object) => void` | - |
| `onSelect` | Peristiwa dicetuskan apabila fail dipilih. | `(file: object) => void` | - |
| `onSuccess` | Peristiwa dicetuskan apabila muat naik komponen berjaya. | `(file: object, value: array) => void` | - |
| `size` | Saiz komponen borang. | [Size](/open/yida/components/interface#size) | `'medium'` |
| `timeout` | Menetapkan tempoh masa tamat muat naik dalam milisaat. | `number` | `0` |
| `tips` | Penerangan komponen borang. Dipaparkan di bawah kawalan. | `string` | - |
| `type` | Menetapkan jenis muat naik. Hanya berkuat kuasa pada PC. | `'normal' \| 'drag'` | `'normal'` |
| `validation` | Tetapan pengesahan untuk komponen borang. Untuk maklumat lanjut, lihat [dokumentasi pengesahan borang](/open/yida/guide/concept/validation). | [Validation[]](/open/yida/components/interface#validation) | `[]` |
| `value` | Nilai lalai. | `array` | - |
| `withCredentials` | Sama ada membenarkan permintaan membawa cookie. | `boolean` | `false` |
| `wrapperColOffset` | Menetapkan kedudukan ofset komponen borang. Nilai dalam unit grid, di mana 1 mewakili 1/24. | `number` | `0` |
| `wrapperColSpan` | Menetapkan lebar ruang letak komponen borang. Nilai dalam unit grid, di mana 1 mewakili 1/24. | `number` | `0` |
