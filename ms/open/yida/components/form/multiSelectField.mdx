## Bila Digunakan

- Gunakannya untuk menggantikan elemen select asli bagi memilih daripada set pilihan yang telah ditetapkan. Keupayaan terasnya ialah pemilihan.

## Contoh Komponen

## Atribut Komponen

| Atribut | Penerangan | Jenis | Lalai |
|---|---|---|---|
| `autoWidth` | Sama ada menu lungsur sejajar dengan lebar selektor | `boolean` | `true` |
| `behavior` | Keadaan paparan komponen borang | [Behavior](/open/yida/components/interface#behavior) | `'NORMAL'` |
| `dataSource` | Mengkonfigurasikan pilihan | [DataSource[]](/open/yida/components/interface#datasource) | `[ { "text": "Pilihan 1", "value": "1" }, { "text": "Pilihan 2", "value": "2" }, { "text": "Pilihan 3", "value": "3" } ]` |
| `filter` | Kaedah penapisan tempatan; hanya tersedia apabila penapisan tempatan diaktifkan | `(value: string[], data: DataSource) => boolean` | - |
| `filterLocal` | Nyahaktifkan pilihan ini apabila sumber data adalah jauh (remote). Mengembalikan nilai Boolean yang menentukan sama ada pilihan tersebut dikekalkan | `boolean` | `true` |
| `hasArrow` | Sama ada memaparkan anak panah menu lungsur | `boolean` | `true` |
| `hasBorder` | Sama ada memaparkan sempadan | `boolean` | `true` |
| `hasSelectAll` | Sama ada mengaktifkan ciri Pilih Semua | `boolean` | `false` |
| `label` | Tajuk komponen borang | `string` | - |
| `labelAlign` | Kedudukan tajuk komponen borang | `'left' \| 'top'` | `'top'` |

| `labelTextAlign` | Penjajaran tajuk komponen borang | `'left' \| 'right'` | `'right'` |
| `labelTipsIcon` | Ikon untuk entri petua tajuk komponen borang. Berkuat kuasa apabila `labelTipsTypes` ditetapkan kepada **text** atau **render** | `string` | - |
| `labelTipsRender` | Kaedah render tersuai untuk petua tajuk komponen borang. Berkuat kuasa apabila `labelTipsTypes` ditetapkan kepada **render** | `(props: IComponentProps) => ReactNode` | - |
| `labelTipsText` | Teks petua untuk tajuk komponen borang. Berkuat kuasa apabila `labelTipsTypes` ditetapkan kepada **text** | `string` | - |
| `labelTipsTypes` | Jenis petua yang dipaparkan untuk tajuk komponen borang | [LabelTipsTypes](/open/yida/components/interface#labeltipstypes) | `'none'` |
| `notFoundContent` | Teks yang dipaparkan apabila tiada hasil dijumpai | `string` | - |
| `onChange` | Peristiwa yang dicetuskan apabila nilai komponen berubah. `actionType` menunjukkan jenis pencetus. Nilai yang tersedia: `'itemClick'`, `'enter'`, `'change'` | `({value: string, actionType:string, item:Data}) => void` | - |
| `onRemove` | Peristiwa yang dicetuskan apabila nilai dipadam | `(item: DataSource) => void` | - |
| `onSearch` | Peristiwa yang dicetuskan apabila nilai dalam kotak carian berubah | `(keyword: string) => void` | - |
| `onVisibleChange` | Peristiwa yang dicetuskan apabila lapisan pop timbul dipaparkan atau disembunyikan | `(visible: boolean) => void` | - |
| `onVisibleChange` | Peristiwa yang dicetuskan apabila lapisan pop timbul dipaparkan atau disembunyikan | `(visible: boolean) => void` | - |
| `placeholder` | Teks placeholder komponen borang | `string` | `'Sila pilih'` |
| `searchDelay` | Kelewatan carian, dalam milisaat | `number` | `300` |
| `showSearch` | Sama ada carian diaktifkan selepas dikembangkan. Ditetapkan kepada `true` dalam mod tag | `boolean` | `true` |

| `size` | Saiz komponen borang | [Size](/open/yida/components/interface#size) | `'medium'` |

| `value` | Nilai lalai komponen semasa | `string[]` | - |
