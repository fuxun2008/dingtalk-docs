## Bila Hendak Digunakan

- Digunakan untuk senario yang memerlukan input teks dalam jumlah besar, di mana kawasan input perlu lebih besar daripada input teks standard.

## Contoh Komponen

## Atribut Komponen

| Atribut | Penerangan | Jenis | Lalai |
|---|---|---|---|
| `addonAfter` | Kandungan yang ditambah selepas input. | `string` | - |
| `addonBefore` | Kandungan yang ditambah sebelum input pelbagai baris. | `string` | - |
| `autoFocus` | Sama ada untuk mengaktifkan fokus automatik. | `boolean` | `false` |
| `autoHeight` | Sama ada untuk mengaktifkan ketinggian automatik bagi input pelbagai baris. | `boolean` | `false` |
| `behavior` | Keadaan paparan komponen borang. | [Behavior](/ms/open/yida/components/interface#behavior) | `'NORMAL'` |
| `cutString` | Sama ada untuk memangkas string apabila melebihi maxLength. | `boolean` | `false` |
| `hasClear` | Sama ada untuk mengaktifkan butang kosongkan pada teks pelbagai baris. | `boolean` | `true` |
| `hasLimitHint` | Sama ada untuk memaparkan kiraan aksara bagi teks pelbagai baris. | `boolean` | `false` |
| `label` | Tajuk komponen borang. | `string` | - |
| `labelAlign` | Kedudukan tajuk komponen borang. | `'left' \| 'top'` | `'top'` |
| `labelColOffset` | Kedudukan offset tajuk. Nilai ini adalah nilai grid, di mana 1 mewakili 1/24. | `number` | `0` |
| `labelColSpan` | Lebar tajuk. Nilai ini adalah nilai grid, di mana 1 mewakili 1/24. | `number` | `4` |
| `labelTextAlign` | Penjajaran tajuk komponen borang. | `'left' \| 'right'` | `'right'` |
| `labelTipsIcon` | Ikon entri untuk petua tajuk komponen borang. Berkesan apabila labelTipsTypes ditetapkan kepada **text** atau **render**. | `string` | - |
| `labelTipsRender` | Kaedah render tersuai untuk petua tajuk komponen borang. Berkesan apabila labelTipsTypes ditetapkan kepada **render**. | `(props: IComponentProps) => ReactNode` | - |
| `labelTipsText` | Teks petua untuk tajuk komponen borang. Berkesan apabila labelTipsTypes ditetapkan kepada **text**. | `string` | - |
| `labelTipsTypes` | Tetapan jenis untuk petua tajuk komponen borang. | [LabelTipsTypes](/ms/open/yida/components/interface#labeltipstypes) | `'none'` |
| `maxLength` | Had aksara bagi teks pelbagai baris. | `number` | - |
| `onChange` | Peristiwa yang dicetuskan apabila nilai komponen berubah. | `({ value: string }) => void` | - |
| `placeholder` | Teks placeholder untuk komponen borang. | `string` | `Sila masukkan` |
| `rows` | Ketinggian teks pelbagai baris. Hanya berkesan pada PC. | `number` | `4` |
| `size` | Saiz komponen borang. | [Size](/ms/open/yida/components/interface#size) | `'medium'` |
| `state` | Keadaan input. | `'error' \| 'loading' \| 'success' \| ''` | `''` |
| `tips` | Penerangan komponen borang, dipaparkan di bawah kawalan. | `string` | - |
| `trim` | Sama ada untuk memangkas ruang kosong di hadapan dan belakang secara automatik. | `boolean` | `false` |
| `validation` | Tetapan pengesahan untuk komponen borang. Untuk butiran lanjut, sila rujuk [dokumentasi pengesahan borang](/ms/open/yida/guide/concept/validation). | [Validation[]](/ms/open/yida/components/interface#validation) | `[]` |
| `value` | Nilai lalai komponen semasa. | `string` | - |
| `wrapperColOffset` | Kedudukan offset komponen borang. Nilai ini adalah nilai grid, di mana 1 mewakili 1/24. | `number` | `0` |
| `wrapperColSpan` | Lebar komponen borang. Nilai ini adalah nilai grid, di mana 1 mewakili 1/24. | `number` | `0` |
