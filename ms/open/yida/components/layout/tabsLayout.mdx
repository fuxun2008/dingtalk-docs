Komponen TabsLayout membolehkan pengguna bertukar antara pelbagai sub-tugasan, paparan, atau mod. Ia berfungsi sebagai navigasi global dan merupakan area utama untuk memaparkan serta menukar antara ciri global.

## Bila hendak digunakan
- Apabila anda perlu mengkategorikan atau memisahkan kandungan halaman.
- Apabila anda perlu memadatkan kawalan halaman untuk memanfaatkan ruang halaman dengan lebih baik.

## Contoh Komponen

## Atribut Komponen

| Atribut | Penerangan | Jenis | Lalai |
|---|---|---|---|
| `contentPadding` | Menetapkan inner padding bagi area kandungan. Masukkan nilai CSS padding. | `string` | `'20px 20px'` |
| `excessMode` | Mod gelangsar apabila terlalu banyak tab. `slide`: gelangsar; `dropdown`: pemilihan dropdown. | `'slide' \| 'dropdown'` | `'slide'` |
| `extraRender` | Memaparkan kandungan tambahan pada bar navigasi. | `() => ReactNode` | - |
| `items` | Menetapkan item aktif lalai, item dinyahaktifkan, dan label tab. | [TabItem[]](/ms/open/yida/components/interface#tabitem) | - |
| `needBadge` | Mengaktifkan lencana (badge). | `boolean` | `false` |
| `onTabChange` | Acara penukaran tab. | `(activeIndex: number, key: string) => void` | - |
| `renderBadge` | Memaparkan lencana (badge). | `(tabItem: object) => ReactNode` | - |
| `shape` | Menetapkan bentuk tab. | `'pure' \| 'wrapped' \| 'text' \| 'capsule'` | `'pure'` |
| `size` | Saiz item tab. | `'small' \| 'medium'` | `'medium'` |
| `tabPosition` | Kedudukan tab navigasi. | `'top' \| 'bottom' \| 'left' \| 'right'` | `'top'` |
| `tabRender` | Fungsi pemaparan tab tersuai. | `(key: string, props: object) => ReactNode` | - |
