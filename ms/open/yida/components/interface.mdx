Dokumen ini menyenaraikan jenis sifat biasa yang digunakan oleh komponen YiDA. Gunakan API berikut untuk membaca atau menetapkan sifat komponen yang ditentukan dalam panel tindakan (lihat [API Komponen Biasa](/ms/open/yida/api/yidaAPI#common-component-apis) untuk butiran):

```js
// Dapatkan nilai sifat komponen
export function getAttribute(){
  // Dapatkan sifat content bagi komponen Teks dan cetak ke konsol
  const content = this.$('text_kyz78exo').get('content')
  console.log( `text content: ${content}` );
}

// Tetapkan nilai sifat komponen
export function setAttribute(){
  // Tetapkan sifat maxLine bagi komponen Teks
  this.$('text_kyz78exo').set('maxLine', 5);
}
```

## Jenis Asas

### I18n
Konfigurasi untuk rentetan antarabangsaan.

```ts
inerface I18n {
  zh_CN: string;
  en_US: string;
  type: 'i18n';
}
```

## Sifat Asas Borang

### Behavior
Keadaan paparan bagi kawalan borang:
* NORMAL - Paparan biasa.
* DISABLED - Dinyahaktifkan.
* READONLY - Baca Sahaja.
* HIDDEN - Tersembunyi.

```ts
type Behavior = 'NORMAL' | 'DISABLED' | 'READONLY' | 'HIDDEN';
```

### Size
Saiz kawalan borang.

```ts
type Size = 'small' | 'medium' | 'large';
```

### LabelTipsTypes
Jenis petua yang dipaparkan di sebelah tajuk kawalan borang.
* none - Tiada.
* text - Teks.
* render - Rendering tersuai.

```ts
type LabelTipsTypes = 'none' | 'text' | 'render';
```

### Validation
Peraturan pengesahan bagi kawalan borang.

```ts
interface Validation {
  type: 'required' | 'minValue' | 'maxValue' | 'minLength' | 'maxLength' | 'customValidate'; // Jenis pengesahan
  message: string | I18n; // Mesej ralat
  param: number | (value: any) => boolean; // Parameter pengesahan. Apabila type ialah customValidate, ini ialah fungsi tersuai.
}
```

## Jenis Sumber Data Berkaitan Komponen

### DataSource
Format pilihan untuk komponen pemilihan seperti dropdown, pilih tunggal, dan pilih berbilang.

```ts
interface DataSource {
  text: string | I18n; // Kandungan paparan
  value: string; // Data yang dihantar
}
```

### CascadeDataSource
Format pilihan untuk komponen dengan struktur bersarang berbilang peringkat, seperti pilih lata (cascading select).

```ts
interface CascadeDataSource {
  label: string | I18n; // Kandungan paparan
  value: string; // Data yang dihantar
  chidren?: CascadeDataSource[]
}
```

### SliderDataSource
Konfigurasi data untuk komponen karusel imej.

```ts
interface SliderDataSource {
  src: string; // URL imej karusel
  title?: string | I18n; // Tajuk karusel
  link?: string; // Pautan pengalihan apabila imej diklik
}
```

### StepsDataSource
Konfigurasi data untuk komponen langkah.

```ts
interface StepsDataSource {
  title: string;
  content: string;
  status?: '' | 'wait' | 'process' | 'finish'; // Status langkah semasa
  customSwitcher?: boolean; // Sama ada untuk mengaktifkan rendering tersuai
  customRender?: (item: StepsDataSource) => ReactNode; // Fungsi rendering tersuai
  icon?: string; // Ikon langkah
  percent?: number; // Peratusan kemajuan langkah semasa. Nombor antara 1 dan 100.
  disabled?: boolean; // Sama ada langkah dinyahaktifkan
}
```

### TimelineDataSource
Konfigurasi data untuk komponen garis masa.

```ts
interface TimelineDataSource {
  title: string | I18n; // Tajuk
  time: string; // Masa
  icon?: string; // Ikon untuk dipaparkan
  state?: '' | 'process' | 'success' | 'error'; // Status nod semasa
  timeLeft?: () => ReactNode; // Paparan masa di sebelah kiri
  doc?: () => ReactNode; // Nod garis masa tersuai. Mengatasi sifat icon.
  content?: () => ReactNode; // Kandungan tersuai di sebelah kanan
}
```

### TreeDataSource
Konfigurasi data untuk komponen pokok.

```ts
interface TreeDataSource {
  key: string;
  label: string;
  children?: TreeDataSource[]; // Nod anak
}
```

### MenuDataSource
Konfigurasi data untuk komponen menu.

```ts
interface MenuDataSource {
  label: string;
  key: string;
  chidlren?: MenuDataSource[]; // Nod anak
}
```

### SearchDataSource
Konfigurasi data untuk kotak carian.

```ts
interface SearchDataSource {
  label: string;
  value: string;
}
```

### TabItem

```ts
interface TabItem {
  title: string; // Nama tab
  primaryKey: string; // Pengecam unik bagi tab
  disabled?: boolean; // Sama ada tab dinyahaktifkan

```

### TableColumn
Konfigurasi lajur bagi komponen Hamparan.

```ts
interface TableColumn {
  dataKey: string; // Medan data
  title: string | I18n; // Tajuk pengepala lajur
  width?: string; // Lebar lajur. Boleh dalam px atau %.
  dataType: 'text' | 'link' | 'file' | 'image' | 'timestamp' | 'cascadeTimestamp' | 'employee' | 'money' | 'moneyRange' | 'enum' | 'custom'; // Jenis data
  float?: '' | 'left' | 'right'; // Pengapungan imej (berkuat kuasa hanya dalam mod kad mudah alih)
  imageProps?: React.CSSProperties; // Gaya imej
  imageWrapProps?: React.CSSProperties; // Gaya bekas imej
  imageOnClick?: (e: Event, column: number) => void; // Callback klik imej
  enumBadgeType?: '' | 'color' | 'background'; // Gaya enum
  enumData?: any; // Data enum
  editType?: 'text' | 'link' | 'file' | 'image' | 'timestamp' | 'cascadeTimestamp' | 'employee' | 'money' | 'moneyRange' | 'enum' | 'custom'; // Format edit
  timeFormatter?: 'YYYY-MM-DD HH:mm:ss' | 'YYYY-MM-DD HH:mm' | 'YYYY-MM-DD' | 'YYYY-MM' | 'YYYY'; // Format masa
  align?: 'left' | 'center' | 'right'; // Jajaran
  lock?: 'none' | 'left' | 'right'; // Kunci lajur
  groupName?: string; // Tajuk kumpulan
  message?: string; // Petua pengguna
  sortable?: boolean; // Sama ada lajur boleh diisih
  highlight?: boolean; // Sama ada untuk menyorot. Berkuat kuasa hanya dalam mod kad mudah alih.
  hidden?: boolean; // Sama ada lajur disembunyikan.
  resizable?: boolean; // Sama ada lebar lajur boleh dilaraskan. Mesti digunakan bersama-sama dengan peristiwa yang dicetuskan apabila lebar lajur ditetapkan semula.
  titleRender?: (title: string) => ReactNode; // Rendering tajuk tersuai
  render?: (value: any, index: number, rowData) => ReactNode; // Rendering kandungan tersuai
  canEdit?: boolean; // Sama ada lajur boleh diedit
  renderField?: (props: any, value: any, rowData: any) => ReactNode; // Rendering tersuai dalam keadaan edit
  editProps?: any; // Konfigurasi edit
  filters?: {
    label: string;
    value: string;
  }[];
  filterMode?: 'multiple' | 'single'; // Mod penapis
}

```

  colspan?: number;

### ScanCodeConfig
Konfigurasi mod imbasan pada klien DingTalk. Klien DingTalk menyokong mod imbasan berikut:
* barCode - Kod bar.
* qrCode - Kod QR.
* all - Semua yang di atas.

```ts
interface ScanCodeConfig {
  enable: boolean;
  type: 'all' | 'barCode' | 'qrCode';
  editable: boolean; // Sama ada hasil imbasan boleh diubah suai
}
```

### UploadConfig
Konfigurasi muat naik imej untuk komponen Teks Kaya.

```ts
interface UploadConfig {
  inputName?: string; // Atribut name bagi input fail untuk muat naik. Lalai kepada file.
  actionUrl: string; // Endpoint muat naik
  formatResult?: (response: any) => any; // Pemprosesan data respons
  errorCallback?: () => void; // Callback ralat
  progressCallback?: () => void; // Callback kemajuan muat naik
  headers?: Record<string, string>; // Konfigurasi pengepala permintaan untuk muat naik imej
}
```
