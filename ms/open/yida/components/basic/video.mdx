## Bila Hendak Digunakan

- Kawalan video untuk memainkan sumber video native HTML seperti mp4 dan mov.

## Contoh Komponen

## Sifat Komponen

| Atribut | Penerangan | Jenis | Lalai |
|---|---|---|---|
| `autoplay` | Main automatik. Mungkin tidak berfungsi dalam sesetengah senario. | `boolean` | `false` |
| `canPlayThrough` | Dicetuskan apabila video selesai dimuatkan dan sedia untuk dimainkan. | `(ctx: object) => void` | - |
| `controls` | Bar kawalan. | `boolean` | `true` |
| `controlsList` | Menyesuaikan bar kawalan native. | `'nodownload' \| 'nofullscreen' \| 'noremoteplayback' \| 'disablePictureInPicture'` | - |
| `loop` | Main balik gelung. Sama ada video dimulakan semula secara automatik selepas ia tamat. | `boolean` | `false` |
| `muted` | Sama ada video dibisukan. | `boolean` | `false` |
| `onEnded` | Dicetuskan apabila video tamat. | `(ctx: object) => void` | - |
| `onEnterFullscreen` | Dicetuskan apabila memasuki mod skrin penuh. | `(ctx: object) => void` | - |
| `onError` | Dicetuskan apabila ralat main balik berlaku. | `(ctx: object) => void` | - |
| `onExitFullscreen` | Dicetuskan apabila keluar daripada mod skrin penuh. | `(ctx: object) => void` | - |
| `onPause` | Dicetuskan apabila video dijeda. | `(ctx: object) => void` | - |
| `onPlay` | Dicetuskan apabila main balik bermula. | `(ctx: object) => void` | - |
| `pipControls` | Gambar dalam gambar. Hanya berfungsi dalam Chrome dan Safari; tidak disokong dalam Firefox atau pada peranti mudah alih. | `boolean` | `false` |
| `playbackRate` | Senarai kelajuan main balik. | `array` | `[ 0.8, 1, 1.5, 2 ]` |
| `playbackRateControls` | Sama ada memaparkan kawalan kelajuan main balik. | `boolean` | `false` |
| `poster` | URL imej poster. | `string` | - |
| `sizeFit` | Mod paskan paparan. | `'contain' \| 'fill' \| 'cover' \| 'scale-dowm' \| 'none'` | `'contain'` |
| `timeUpdate` | Dicetuskan apabila masa main balik dikemas kini. | `(ctx: object) => void` | - |
| `title` | Tajuk native. Menetapkan atribut `title` native HTML, yang dipaparkan apabila tetikus berada di atasnya. | `string` | - |
| `url` | URL video. | `string` | `'https://cloud.video.taobao.com/play/u/1804320196/p/1/e/6/t/1/287344840104.mp4'` |
| `volume` | Tahap kelantangan. Minimum ialah 0; maksimum ialah 1. | `number` | `1` |
| `volumeControls` | Sama ada memaparkan kawalan kelantangan. | `boolean` | `true` |
