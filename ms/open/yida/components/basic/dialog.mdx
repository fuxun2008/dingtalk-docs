## Bila digunakan

Dialog ialah tetingkap bantuan yang membolehkan pengguna melaksanakan tindakan ringkas, mengesahkan maklumat, atau menerima maklum balas dengan pantas tanpa perlu keluar daripada aliran kerja utama.

## Contoh komponen

## Atribut komponen

| Atribut | Penerangan | Jenis | Lalai |
|---|---|---|---|
| `afterClose` | Acara yang dicetuskan selepas dialog ditutup. | `() => void` | - |
| `afterOpen` | Acara yang dicetuskan selepas dialog dibuka. | `() => void` | - |
| `autoFocus` | Sama ada untuk fokus secara automatik pada medan borang dalaman apabila dialog dibuka. | `boolean` | `true` |
| `cancelText` | Teks bagi butang Batal. | `string` | `'Cancel'` |
| `closeable` | Cara dialog boleh ditutup. `esc`: tekan kekunci ESC untuk menutup; `mask`: klik topeng untuk menutup. | `'esc' \| 'mask'` | `'esc'` |
| `confirmState` | Keadaan butang Sahkan. | `'NORMAL' \| 'DISABLED' \| 'LOADING'` | `'NORMAL'` |
| `confirmStyle` | Gaya butang Sahkan. Rujuk [dokumentasi komponen Button](/ms/open/yida/components/basic/button#component-properties). | `'primary' \| 'warning' \| 'ghostLight' \| 'ghostDark'` | `'primary'` |
| `confirmText` | Teks bagi butang Sahkan. | `string` | `'Confirm'` |
| `footer` | Sama ada untuk memaparkan butang footer. | `boolean` | `true` |
| `footerActions` | Susunan lalai butang footer. `cancel` mewakili butang Batal, dan `ok` mewakili butang Sahkan. | `'cancel,ok' \| 'cancel,ok' \| 'ok' \| 'cancel'` | `'cancel,ok'` |
| `footerAlign` | Penjajaran butang Sahkan dan Batal dalam dialog. | `'left' \| 'center' \| 'right'` | `'right'` |
| `hasMask` | Sama ada untuk memaparkan topeng. | `boolean` | `true` |
| `height` | Tinggi dialog. | `number` | - |
| `onCancel` | Acara yang dicetuskan apabila butang Batal diklik. | `() => void` | - |
| `onClose` | Acara yang dicetuskan apabila dialog ditutup. | `() => void` | - |
| `onOk` | Acara yang dicetuskan apabila butang Sahkan diklik. | `() => void` | - |
| `onOpen` | Acara yang dicetuskan apabila dialog dibuka. | `() => void` | - |
| `title` | Tajuk dialog. | `string` | `'Dialog Title'` |
| `visible` | Sama ada dialog dipaparkan. | `boolean` | `false` |
| `width` | Lebar dialog. | `number` | - |
