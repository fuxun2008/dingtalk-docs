Memaparkan aliran maklumat berasaskan masa secara menegak.

## Bila Hendak Digunakan

- Apabila satu siri maklumat perlu disusun dari atas ke bawah mengikut urutan kronologi.
- Apabila garis masa diperlukan untuk menghubungkan maklumat secara visual.

## Atribut Komponen

| Atribut | Penerangan | Jenis | Lalai |
|---|---|---|---|
| `animation` | Sama ada hendak mengaktifkan animasi | `boolean` | `true` |
| `dataSource` | Mengkonfigurasi data garis masa | [TimelineDataSource[]](/open/yida/components/interface#timelinedatasource) | `[ { title: { zh_CN: "春天", en_US: "Spring", type: "i18n", }, time: "2021-03-10", }, { title: { zh_CN: "夏天", en_US: "Summer", type: "i18n", }, time: "2016-06-11", }, { title: { zh_CN: "秋天", en_US: "Autumn", type: "i18n", }, time: "2016-09-09", }, { title: { zh_CN: "冬天", en_US: "Winter", type: "i18n", }, time: "2016-12-08", }, ]` |
| `fold` | Mengkonfigurasi lipatan data | `any[]` | `[ { foldArea: [1, 2], foldShow: false, }, ]` |
