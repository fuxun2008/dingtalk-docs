## Bila Digunakan

- Menu navigasi adalah nadi bagi sesebuah laman web. Pengguna bergantung padanya untuk bergerak antara halaman. Menu secara amnya terbahagi kepada navigasi atas dan navigasi sisi. Navigasi atas menyediakan kategori dan ciri global, manakala navigasi sisi menawarkan struktur berbilang peringkat untuk menyusun senibina laman.

## Sifat Komponen

| Atribut | Penerangan | Jenis | Lalai |
|---|---|---|---|
| `dataSource` | Sumber Data bagi menu | [MenuDataSource[]](/ms/open/yida/components/interface#menudatasource) | `[ { label: "Item Menu 1", key: "key1", children: [ { label: "Pilihan 1", key: "key1-1", tag: { text: "Dimulakan", color: "blue", }, }, { label: "Pilihan 2", key: "key1-2", }, ], }, { isDivider: true, }, { label: "Item Menu 2", key: "key2", children: [ { label: "Pilihan 1", key: "key2-1", }, { label: "Pilihan 2", key: "key2-2", }, ], }, { label: "Item Menu 3", key: "key3", disabled: true, }, ]` |
| `direction` | Arah paparan menu peringkat pertama | `'ver' \| 'hoz'` | - |
| `footer` | Pengaki menu tersuai | `string` | - |
| `header` | Pengepala menu tersuai | `string` | - |
| `mode` | Mod pembukaan submenu | `'inline' \| 'popup'` | `inline` |
| `onItemClick` | Acara yang dicetuskan apabila item menu diklik | `(key: string, item: MenuDataSource, event: any) => void` | - |
| `onSelect` | Acara yang dicetuskan apabila item menu dipilih atau dinyahpilih | `(selectedKeys: string[], extraObj: any) => void` | - |
| `popupAlign` | Mod jajaran lapisan popup | `'follow' \| 'outside'` | `'follow'` |
| `selectMode` | Mod pemilihan komponen Menu | `'single' \| 'multiple' \| false` | `false` |
| `triggerType` | Tingkah laku Pencetus untuk membuka submenu | `'click' \| 'hover'` | `'click'` |
