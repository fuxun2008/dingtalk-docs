Komponen banner bawah membolehkan anda menambah kandungan di bahagian bawah halaman. Kandungan tersebut tetap di bahagian bawah halaman dan meliputi lebar penuh.

## Bila Digunakan

- Apabila anda perlu menambah kandungan di bahagian bawah halaman, seperti maklumat hak cipta.

## Contoh Komponen

## Sifat Komponen

| Sifat | Penerangan | Jenis | Lalai |
|---|---|---|---|
| `autoWidth` | Sama ada untuk mengaktifkan lebar adaptif | `boolean` | `false` |
| `containerWidth` | Lebar bekas dalam px atau %, contohnya, 100px atau 50% | `string` | - |
| `contentWidth` | Lebar kandungan dalam px atau %, contohnya, 100px atau 50% | `string` | - |
| `extra` | Kandungan tersuai | `ReactNode` | - |
| `getRefContainer` | Bekas pemasangan tersuai | `() => React.HTMLElement` | - |
| `layout` | Mod susun atur: `h` untuk mendatar, `v` untuk menegak | `'h' \| 'v'` | `'h'` |
