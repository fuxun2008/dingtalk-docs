## Bila Hendak Digunakan

- Gunakan untuk mencari data halaman atau borang.

## Contoh Komponen

## Atribut Komponen

| Atribut | Penerangan | Jenis | Lalai |
|---|---|---|---|
| `autoFocus` | Sama ada untuk fokus automatik. | `boolean` | `false` |
| `dataSource` | Menetapkan nilai Senarai Lungsur untuk kotak carian. | [SearchDataSource[]](/ms/open/yida/components/interface#searchdatasource) | `[ { "label": "Tmall", "value": "value1" }, { "label": "Taobao", "value": "value2" }, { "label": "Alibaba Group", "value": "value3" } ]` |
| `defaultFilterValue` | Menetapkan nilai lalai pemilih apabila butang pemilih diaktifkan. | `string` | `'one'` |
| `defaultValue` | Nilai lalai kotak carian. | `string` | - |
| `disabled` | Sama ada untuk menyahaktifkan komponen. | `boolean` | `false` |
| `filter` | Menetapkan nilai Senarai Lungsur untuk pemilih. | [SearchDataSource[]](/ms/open/yida/components/interface#searchdatasource) | `[ { "label": "one", "value": "one" }, { "label": "two", "value": "two" }, { "label": "three", "value": "three" } ]` |
| `hasClear` | Sama ada untuk memaparkan butang kosongkan. | `boolean` | `false` |
| `isFilter` | Sama ada untuk mengaktifkan pemilih. | `boolean` | `false` |
| `onChange` | Dicetuskan apabila nilai komponen berubah. | `(value: string) => void` | - |
| `onFilterChange` | Dicetuskan apabila nilai pemilih berubah. | `(filterValue: string) => void` | - |
| `onSearch` | Dicetuskan apabila butang carian diklik. | `(value: string) => void` | - |
| `placeholder` | Placeholder lalai kotak carian. | `string` | `'Please enter'` |
| `searchText` | Teks pada butang carian. | `string` | `'Search'` |
| `shape` | Bentuk kotak carian. | `'normal' \| 'simple'` | `'normal'` |
| `size` | Saiz. | `'medium' \| 'large'` | `'medium'` |
| `type` | Jenis gaya carian. | `'normal' \| 'primary' \| 'secondary' \| 'dark'` | `'normal'` |
