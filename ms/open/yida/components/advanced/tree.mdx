## Bila digunakan

- Gunakan komponen Tree untuk memaparkan data hierarki dalam jumlah besar. Interaksi kembang/kuncup serta pemilihan berkait menjadikan data mudah dimanipulasi.

## Sifat komponen

| Sifat | Penerangan | Jenis | Lalai |
|---|---|---|---|
| `canDrop` | Acara yang dicetuskan untuk menentukan sama ada nod boleh berfungsi sebagai sasaran lepas (drop target). | `(info: any) => boolean` | - |
| `checkStrictly` | Menjadikan kotak semak dikawal sepenuhnya (fully controlled). | `boolean` | `false` |
| `checkStrictly` | Menentukan cara nod yang dipilih dikembalikan. `all`: mengembalikan semua nod yang dipilih. `parent`: hanya mengembalikan nod induk apabila semua nod anak dipilih. `child`: hanya mengembalikan nod anak apabila semua nod anak dipilih. | `'all' \| 'parent' \| 'child'` | `'parent'` |
| `checkStrictly` | Menjadikan kotak semak dikawal sepenuhnya (fully controlled). | `boolean` | `false` |
| `checkable` | Sama ada memaparkan kotak semak. | `boolean` | `false` |
| `checkedKeys` | Nod yang dipilih secara lalai. | `string[]` | `['0-0-0']` |
| `checkedKeys` | Nod yang disemak secara lalai. | `string[]` | `["0-0-0"]` |
| `dataSource` | Data nod. | [TreeDataSource[]](/open/yida/components/interface#treedatasource) | `[ { key: "0-0", label: "0-0", children: [ { key: "0-0-0", label: "0-0-0", children: [ { key: "0-0-0-0", label: "0-0-0-0", children: [ { key: "0-0-0-0-0", label: "0-0-0-0-0", }, ], }, { key: "0-0-0-1", label: "0-0-0-1", }, ], }, { key: "0-0-1", label: "0-0-1", children: [ { key: "0-0-1-0", label: "0-0-1-0", }, { key: "0-0-1-1", label: "0-0-1-1", }, ], }, ], }, ]` |
| `defaultExpandAll` | Kembangkan semua nod secara lalai. | `boolean` | `true` |
| `defaultExpandedKeys` | Nod yang dikembangkan secara lalai. | `string[]` | `['0-0-0']` |
| `draggable` | Sama ada seretan disokong. | `boolean` | `false` |
| `editable` | Sama ada penyuntingan disokong. | `boolean` | `false` |
| `expandedKeys` | Nod yang dikembangkan. | `string[]` | `['0-0-0']` |
| `isLoadData` | Sama ada mengaktifkan pemuatan tak segerak (asynchronous). | `boolean` | `false` |
| `loadData` | Acara yang dicetuskan semasa pemuatan tak segerak. | `(data: TreeDataSource) => Promise<TreeDataSource[]>` | - |
| `multiple` | Sama ada pilih banyak (multiselect) disokong. | `boolean` | `false` |
| `onCheck` | Acara yang dicetuskan apabila kotak semak dipilih atau dikosongkan. | `(checkedKeys: string[], extra: any) => void` | - |
| `onDragEnd` | Acara yang dicetuskan apabila seretan berakhir. | `(info: any) => void` | - |
| `onDragEnter` | Acara yang dicetuskan apabila nod yang diseret memasuki nod sasaran. | `(info: any) => void` | - |
| `onDragLeave` | Acara yang dicetuskan apabila nod yang diseret meninggalkan nod sasaran. | `(info: any) => void` | - |
| `onDragOver` | Acara yang dicetuskan apabila nod yang diseret bergerak di atas nod sasaran. | `(info: any) => void` | - |
| `onDragStart` | Acara yang dicetuskan apabila seretan nod bermula. | `(info: any) => void` | - |
| `onDrop` | Acara yang dicetuskan apabila nod yang diseret dilepaskan di dalam, sebelum, atau selepas nod sasaran. | `(info: any) => void` | - |
| `onEditFinish` | Acara yang dicetuskan apabila penyuntingan kandungan nod selesai. | `(key: string, label: string, node: TreeDataSource) => void` | - |
| `onExpand` | Acara yang dicetuskan apabila nod dikembangkan atau dikuncupkan. | `(expandedKeys: string[], extra: any) => void` | - |
| `onSelect` | Acara yang dicetuskan apabila nod dipilih atau nyahdipilih. | `(selectedKeys: string[], extra: any) => void` | - |
| `processDataSource` | Fungsi pra-pemprosesan data. | `(data: any) => TreeDataSource[]` | - |
| `selectable` | Sama ada nod boleh dipilih. | `boolean` | `true` |
| `selectedKeys` | Nod yang dipilih secara lalai. | `string[]` | `['0-0-0']` |
| `showLine` | Sama ada memaparkan garis penghubung antara nod. | `boolean` | `true` |
