Slider ialah komponen yang memaparkan beberapa item kandungan secara mendatar pada halaman dalam bentuk tayangan slaid.

## Bila Digunakan

- Item karusel adalah bebas antara satu sama lain, tanpa hubungan logik dalam kandungan atau data.
- Karusel imej tunggal: biasanya digunakan untuk memaparkan sepanduk promosi dan berfungsi sebagai modul dengan kedudukan yang agak tetap.
- Karusel imej pelbagai: digunakan untuk menyemak imbas maklumat unit.

## Sifat Komponen

| Atribut | Penerangan | Jenis | Lalai |
|---|---|---|---|
| `animation` | Memilih jenis kesan peralihan. slide: gelangsar mendatar; fade: peralihan pudar. | `'slide' \| 'fade'` | `'slide'` |
| `arrowDirection ` | Mengawal arah paparan anak panah. | `'hoz' \|'ver'` | `'hoz'` |
| `arrowPosition` | Mengawal kedudukan anak panah. | `'inner' \| 'outer'` | `'inner'` |
| `arrowSize` | Mengawal saiz anak panah. | `'medium' \| 'large'` | `'medium'` |
| `arrows` | Sama ada untuk mengaktifkan anak panah untuk item karusel. | `boolean` | `true` |
| `autoplay` | Memilih sama ada untuk main automatik item karusel. | `boolean` | `false` |
| `autoplaySpeed` | Kelajuan main automatik item karusel, dalam ms. | `number` | `3000` |
| `centerMode` | Sama ada untuk mengaktifkan mod tengah. | `boolean` | `false` |
| `diyContents` | Data input untuk mod tersuai. Hanya berkuat kuasa apabila **isDiy** ditetapkan kepada true. | `any[]` | `[]` |
| `diyContentsRender` | Fungsi render untuk mod tersuai. Hanya berkuat kuasa apabila **isDiy** ditetapkan kepada true. | `(item: any, index: number) => ReactNode` | - |
| `dots` | Sama ada untuk mengaktifkan titik navigasi. | `boolean` | `true` |
| `dotsDirection` | Kedudukan paparan titik navigasi. | `'hoz' \| 'ver'` | `'hoz'` |
| `focusOnSelect` | Dalam mod karusel imej pelbagai, secara automatik menengahkan item selepas diklik dan dipilih. | `boolean` | `false` |
| `images` | Mengkonfigurasikan item karusel. | [SliderDataSource[]](/open/yida/components/interface#sliderdatasource) | `[]` |
| `isDiy` | Mengaktifkan mod tersuai. | `boolean` | `false` |
| `lazyLoad` | Sama ada untuk mengaktifkan mod pemuatan lambat. | `boolean` | `false` |
| `margin` | Mengawal jarak antara item karusel. | `number` | `10` |
| `slideDirection` | Mengawal arah gelangsar. | `'hoz' \| 'ver'` | `'hoz'` |
| `slideImageHeight` | Ketinggian gambar karusel, dalam px atau sebagai peratusan. | `string` | `'300px'` |
| `slideImageHeightAuto` | Mengaktifkan ketinggian adaptif untuk item karusel (nisbah bidang dikekalkan untuk gambar). | `boolean` | `false` |
| `slideImageWidth` | Menetapkan lebar item karusel. | `string` | `'100%'` |
| `slidesToScroll` | Mengawal bilangan item karusel yang gelangsar pada masa yang sama. | `number` | `1` |
| `slidesToShow` | Mengawal bilangan item karusel yang dipaparkan pada masa yang sama. Berkuat kuasa apabila atribut **type** ditetapkan kepada multi. | `number` | `2` |
| `speed` | Kelajuan gelangsar, dalam ms. | `number` | `500` |
| `triggerType` | Kaedah pencetus untuk navigasi titik. | `'click' \| 'hover'` | `'click'` |
| `type` | Mengkonfigurasikan mod karusel. single: karusel item tunggal; multi: karusel item pelbagai. | `'single' \| 'multi'` | `'single'` |
