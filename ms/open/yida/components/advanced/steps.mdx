Bar navigasi yang membimbing pengguna menyelesaikan sesuatu tugas langkah demi langkah.

## Bila Digunakan

- Apabila sesuatu tugas kompleks atau melibatkan urutan pergantungan, pecahkannya kepada satu siri langkah untuk memudahkannya.

## Contoh Komponen

## Sifat Komponen

| Atribut | Penerangan | Jenis | Lalai |
|---|---|---|---|
| `animation` | Sama ada animasi diaktifkan | `boolean` | `true` |
| `contentRender` | Pemaparan tersuai untuk kandungan | `(item: StepsDataSource, index: number)=> ReactNode` | - |
| `current` | Langkah semasa | `number` | `1` |
| `dataSource` | Data langkah | [StepsDataSource[]](/open/yida/components/interface#stepsdatasource) | `[ { "title": "langkah1", "content": "Buka pintu peti sejuk" }, { "title": "langkah2", "content": "Masukkan gajah ke dalam peti sejuk" }, { "title": "langkah3", "content": "Tutup pintu peti sejuk" } ]` |
| `direction` | Arah paparan bar langkah | `'horizontal' \| 'vertical'` | `'horizontal'` |
| `labelPlacement` | Susun atur kandungan | `'horizontal' \| 'vertical'` | `'vertical'` |
| `onClick` | Acara yang dicetuskan apabila langkah diklik | `(index: number) => void` | - |
| `readOnly` | Sama ada mod Baca Sahaja diaktifkan | `boolean` | `false` |
| `shape` | Jenis paparan bar langkah | `'circle' \| 'arrow' \| 'dot'` | `'circle'` |
