Jika anda tidak dapat log masuk selepas memuat turun dan memasang DingTalk — contohnya, aplikasi menyatakan bahawa akaun anda tidak wujud — anda mungkin telah memasang DingDing, versi untuk tanah besar China, bukannya aplikasi DingTalk antarabangsa. Ikuti langkah di bawah untuk menyemak dan menyelesaikan masalah ini.

## DingTalk dan DingDing ialah dua aplikasi yang berbeza

- **DingTalk** ialah versi antarabangsa, tersedia di dingtalk.io, untuk pengguna di luar tanah besar China.
- **DingDing (钉钉)** ialah versi untuk pengguna di tanah besar China.

Kedua-dua aplikasi mempunyai sistem akaun yang berasingan. Akaun DingTalk tidak boleh digunakan untuk log masuk ke DingDing, dan akaun DingDing tidak boleh digunakan untuk log masuk ke DingTalk. Oleh sebab namanya hampir sama, carian "DingTalk" di gedung aplikasi atau di web boleh membawa anda ke DingDing.

## Semak aplikasi yang ada pada telefon anda

- **Nama aplikasi:** versi antarabangsa dipaparkan sebagai **DingTalk**; versi tanah besar China dipaparkan sebagai **钉钉**.
- **Sumber muat turun:** pautan muat turun rasmi untuk versi antarabangsa tersedia di <a href="https://www.dingtalk.io/download/" target="_blank" rel="noopener noreferrer">dingtalk.io/download</a>.

Jika aplikasi anda memaparkan DingDing (钉钉), pasang aplikasi DingTalk antarabangsa melalui pautan rasmi di bawah, kemudian log masuk dengan akaun dingtalk.io anda.

## Muat turun aplikasi DingTalk antarabangsa

Muat turun klien DingTalk melalui pautan berikut:

- <a href="https://www.dingtalk.io/download/" target="_blank" rel="noopener noreferrer">Muat turun DingTalk untuk desktop</a> — merangkumi klien Windows dan macOS.
- <a href="https://aliyun-alimail-ios.oss-cn-hangzhou.aliyuncs.com/Global/DingTalk_Android.apk" target="_blank" rel="noopener noreferrer">Muat turun DingTalk untuk Android</a>

Selepas memasang, log masuk dengan akaun yang anda cipta di dingtalk.io.
