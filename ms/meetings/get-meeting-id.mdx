**ID mesyuarat** membantu anda menyertai Mesyuarat Video tertentu dengan pantas dan berkomunikasi secara cekap merentas organisasi.

---

## Dapatkan ID Mesyuarat di Desktop

### Dapatkan ID Mesyuarat untuk Mesyuarat Berjadual

Selepas menjadualkan mesyuarat, atau selepas mengklik mesyuarat berjadual daripada Kalendar atau halaman Mesyuarat, buka pop-up butiran mesyuarat >> klik ikon **Salin** di sebelah ID mesyuarat yang dijana secara automatik di penjuru kanan atas.

![](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/Yvenve56z2BE1loy/img/d0ef6cf0-5868-4991-935b-ebaae9cf958b.png)

### Dapatkan ID Mesyuarat Semasa Mesyuarat

Semasa mesyuarat, tuding kursor pada **Maklumat Mesyuarat** di penjuru kiri atas >> klik butang **Salin** di sebelah ID mesyuarat, atau klik **Salin Maklumat Penyertaan**.

![](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/Yvenve56z2BE1loy/img/eaa219f7-6d84-4a4f-a8fe-6a003f6a4852.png?x-oss-process=image/crop,x_91,y_162,w_3921,h_2726/ignore-error,1)

## Dapatkan ID Mesyuarat di Mudah Alih

### Dapatkan ID Mesyuarat untuk Mesyuarat Berjadual

Selepas menjadualkan mesyuarat, atau selepas mengetik mesyuarat berjadual daripada Kalendar atau halaman Mesyuarat, buka halaman butiran mesyuarat >> ketik butang **Salin** di sebelah ID mesyuarat.

![](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/Yvenve56z2BE1loy/img/447ac704-4b32-45af-82a1-3cb8e04b7f5d.png?x-oss-process=image/crop,x_0,y_14,w_982,h_1004/ignore-error,1)

### Dapatkan ID Mesyuarat Semasa Mesyuarat

Mulakan atau sertai mesyuarat >> pada skrin mesyuarat, ketik **Maklumat Mesyuarat** di bahagian atas >> ketik butang **Salin** di sebelah ID mesyuarat.

![](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/Yvenve56z2BE1loy/img/b68f919a-453b-4d8e-b5af-a3ecc38c0af2.png)
