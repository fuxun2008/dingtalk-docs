DingTalk Meetings Web iframe Integration Guide

## DingTalk Meetings Web iframe Integration Guide

DingTalk Meetings Web boleh disematkan ke dalam laman web perniagaan anda menggunakan **iframe** untuk menyokong senario perkhidmatan tersuai seperti temu duga, pengambilan pekerja, dan latihan korporat.

## Ketersediaan

1.  DingTalk Meetings Web diperlukan.
    
2.  Versi berbayar diperlukan, seperti Meeting Membership, Cloud Meeting Room, Professional, atau Edisi Dedicated.
    

Pelan berbayar DingTalk Meetings menyediakan mesyuarat tanpa had masa dan lebih 10 manfaat tambahan. Pengguna boleh membeli atau memohon khidmat runding melalui halaman pembelian DingTalk Meetings yang berkaitan.

## Kes Penggunaan: Temu Duga dan Pengambilan Pekerja

Dengan integrasi iframe DingTalk Meetings, anda boleh menyematkan antara muka mesyuarat di mana-mana bahagian laman web temu duga dan menukar paparan pada bila-bila masa. Anda juga boleh menyembunyikan butang atau ciri yang tidak diperlukan mengikut kes penggunaan, menjadikan kawalan kebenaran lebih mudah.

## Cara Mengintegrasikannya ke dalam Laman Web

Menyematkan melalui iframe adalah mudah. Sisipkan tag iframe DingTalk Meetings ke dalam halaman HTML.

Contoh asas:

```html
<iframe 
  src="https://meeting.dingtalk.io/app/room?linkId={:linkId}" 
  allow="camera; microphone; display-capture">
</iframe>
```

Selepas mengintegrasikan DingTalk Meetings Web melalui iframe, anda boleh menggunakan parameter URL dan penghantaran mesej untuk menyesuaikan UI dan mendapatkan maklumat semasa mesyuarat. Untuk mengetahui API khusus, mohon dokumentasi pembangun lengkap melalui saluran khidmat runding DingTalk.

## UI Tersuai

Ciri ini menyokong konfigurasi tersuai untuk memaparkan atau menyembunyikan komponen UI pada halaman mesyuarat, seperti butang Kongsi atau butang Jemput.

Contoh:

```html
<iframe 
  src="https://meeting.dingtalk.io/app/room?linkId={:linkId}&invite=0&screen_share=0" 
  allow="camera; microphone; display-capture">
</iframe>

<!-- Butang kongsi dan jemput disembunyikan melalui parameter URL. -->
```
