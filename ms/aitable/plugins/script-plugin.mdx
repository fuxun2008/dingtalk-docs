## Overview

Plugin Skrip ialah keupayaan terbuka yang didedahkan oleh AI Table. Pembangun boleh membina Plugin Skrip tersuai dengan menulis JS, dan berkongsinya dengan kolaborator mereka.

Plugin Skrip boleh berinteraksi dengan data jadual dan melaksanakan logik perniagaan yang kompleks. Berbanding dengan Plugin Tersuai, pembangun Plugin Skrip tidak perlu membina atau menggunakan halaman berasingan — anda boleh mengedit, menjalankan, dan menerbitkan skrip terus dalam panel sisi kanan AI Table, serta menggunakan API terbina dalam untuk memaparkan antara muka pengguna plugin yang ringkas.

## Menggunakan Plugin Skrip

DingTalk menyediakan beberapa Plugin Skrip biasa yang sedia digunakan untuk senario lazim; ini juga berfungsi sebagai rujukan untuk pembangun.

## Kebenaran Plugin

Setelah anda menerbitkan Plugin Skrip anda, pengguna AI Table berikut boleh melihat dan menggunakannya:

1. Apabila Kebenaran Lanjutan **Tidak Aktif**: pengguna dengan kebenaran **Edit** atau **Urus** boleh menggunakan plugin.
2. Apabila Kebenaran Lanjutan **Aktif**: hanya pengguna dengan kebenaran **Urus** peringkat jadual boleh menggunakan plugin.
