## Gambaran keseluruhan

Pusat Plugin AI Table fleksibel dan mudah digunakan. **Pustaka plugin yang lengkap** merangkumi pelbagai keperluan khusus setiap pasukan — muat naik lampiran pukal, Cari dan Ganti, penyahduplikatan dan banyak lagi.

Platform plugin ini terbuka: pembangun yang mahir coding boleh membina **Plugin Skrip** dan **plugin tersuai** mengikut keperluan masing-masing. Dengan plugin, AI Table boleh melakukan hampir apa sahaja.

## Cara menggunakan plugin

Buka AI Table dan klik ikon **Plugin** di penjuru kanan atas. Panel sisi kanan memaparkan plugin **pilihan**; klik **Pasaran Plugin** di bahagian bawah untuk melayari katalog penuh.

![](https://img.alicdn.com/imgextra/i2/O1CN01sF6In61fMqdQu4R3V_!!6000000003993-2-tps-1836-1016.png)


![](https://img.alicdn.com/imgextra/i4/O1CN01wZY2N529KV4tzGLib_!!6000000008049-2-tps-1836-1016.png)


### Menggunakan plugin

Contohnya: anda ingin memuat naik lampiran resume secara pukal ke dalam AI Table Perpustakaan Resume. Cari plugin muat naik pukal dalam Pusat Plugin untuk mempercepatkan proses ini.

1. Klik butang **Plugin** di penjuru kanan atas > senarai plugin, kemudian klik **Pasaran Plugin** di bahagian bawah.
2. Cari **muat naik pukal** untuk mencari plugin yang anda perlukan.

![](https://img.alicdn.com/imgextra/i4/O1CN01eFBjN31OHwvmR8cbO_!!6000000001681-2-tps-1836-1016.png)

3. Tuding kursor pada plugin dan klik **Paparan** (atau klik ruang kosong) untuk membaca pengenalan penuh plugin tersebut.
4. Tuding kursor pada plugin dan klik **Guna**. Panel konfigurasi akan dibuka dalam panel sisi kanan.

### Berkongsi plugin

1. **Cadangkan**: dalam langkah 3 di atas, semasa melihat pengenalan plugin, klik **Kongsi** untuk menyalin pautan plugin bagi dihantar kepada rakan sepasukan.

![](https://img.alicdn.com/imgextra/i3/O1CN01ZeiUfN1HV2wjTcGee_!!6000000000762-2-tps-1836-1016.png)

2. **Penerima**: buka pautan 🔗 dalam pelayar, klik **Cuba dalam DingTalk AI Table**, dan plugin tersebut akan dibuka dalam templat contoh yang boleh anda cuba.

### Sematkan plugin

Untuk plugin yang kerap anda gunakan dalam AI Table ini, sematkan ke panel sisi kanan untuk akses pantas. Tuding kursor dan klik ikon sematkan.

![](https://img.alicdn.com/imgextra/i4/O1CN01yJn1FD1bsDIOuV3h5_!!6000000003520-2-tps-1836-1016.png)


### Buang plugin

Dalam senarai **Telah Digunakan**, klik **Lain-lain > Buang daripada senarai** di sebelah kanan plugin untuk membuangnya. Untuk menggunakannya semula, anda perlu mengaktifkannya semula.

![](https://img.alicdn.com/imgextra/i1/O1CN01M97GUc1JVcfzRNl9F_!!6000000001034-2-tps-1836-1016.png)


## Kebenaran plugin

Apabila Kebenaran Lanjutan **dimatikan**: sesiapa dengan kebenaran **Edit** atau **Urus** boleh menggunakan plugin.

Apabila Kebenaran Lanjutan **diaktifkan**: hanya pengguna dengan kebenaran **Urus** peringkat jadual boleh menggunakan plugin.
