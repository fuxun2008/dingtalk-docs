### Persekitaran Yang Disokong

- Chrome / Edge

### Langkah Pemasangan

#### Langkah 1 — Muat Turun Sambungan Pelayar

> Plugin ini adalah untuk tujuan pembelajaran, penyelidikan, dan produktiviti — ia direka untuk membantu pengguna menyusun kandungan web yang boleh diakses secara awam dengan lebih mudah.
> Semasa menggunakan plugin ini untuk mengumpul, menyusun, dan menggunakan data, pengguna mesti mematuhi undang-undang dan peraturan negara dan wilayah masing-masing, serta mesti menghormati terma penggunaan laman web, protokol robots, dan hak sah pihak lain. Penggunaan plugin untuk sebarang tujuan yang menyalahi undang-undang, melanggar hak, menyalahgunakan, atau tidak wajar adalah dilarang sama sekali — termasuk tetapi tidak terhad kepada pelanggaran privasi, hak cipta, tanda dagangan, atau sebarang hak sah pihak lain.
> Plugin ini disediakan semata-mata sebagai alat teknikal. Kami tidak bertanggungjawab ke atas penggunaan khusus oleh pengguna atau sebarang akibat yang timbul daripadanya. Pengguna menanggung semua kerugian langsung atau tidak langsung yang timbul daripada penggunaan plugin ini.
> Dengan menggunakan plugin ini, anda mengesahkan bahawa anda telah membaca, memahami, dan bersetuju sepenuhnya dengan penafian ini. Jika anda tidak bersetuju dengan mana-mana bahagiannya, hentikan penggunaan plugin ini dengan serta-merta.

Muat turun sambungan ke komputer anda dan **nyahzip ke dalam satu folder**.

#### Langkah 2 — Pasang pada Pelayar Anda

Pasang pada Chrome:

| Langkah |
| --- |
| 1. Buka Chrome, tampal `chrome://extensions/` pada bar alamat dan tekan Enter untuk membuka halaman sambungan — **atau** klik butang **Extensions** untuk membukanya. |
| 2. Togol **Developer mode** di penjuru kanan atas. |
| 3. Seret **folder Fusion yang telah dinyahzip** ke halaman sambungan Chrome. |
| 4. Cari sambungan Fusion yang baharu dan **pastikan ia diaktifkan**. |
| 5. Selepas selesai dipasang, **muat semula** AI Table > buka panel sisi > cari atau buka Web Scraper daripada pusat plugin. Pada kali pertama mengimbas, log masuk dengan akaun DingTalk anda. |

Pasang pada Edge:

| Langkah |
| --- |
| 1. Buka Edge, klik menu **⋯** di penjuru kanan atas dan pilih **Extensions**. |
| 2. Klik **Manage extensions**. |
| 3. Pada halaman pengurusan sambungan, aktifkan **Developer mode**. |
| 4. Seret **folder Fusion** yang telah dinyahzip ke dalam tetingkap pelayar. |
| 5. Daripada tetingkap timbul sambungan pada bar alat pelayar, klik **Fusion** untuk membuka panel sisi Fusion. |
| 6. Log masuk dengan DingTalk. Selepas berjaya log masuk, kembali ke AI Table dan aktifkan Web Scraper. |
