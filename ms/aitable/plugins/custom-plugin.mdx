## Gambaran keseluruhan

Plugin panel sisi ialah keupayaan terbuka yang didedahkan oleh AI Table. Pembangun boleh melanjutkan AI Table dengan membina Plugin Tersuai mereka sendiri.

Plugin berjalan dalam panel sisi kanan AI Table dan boleh berinteraksi dengan data jadual untuk melaksanakan logik perniagaan yang kompleks.

Plugin menggunakan seni bina dua halaman:

- **Script Service**: berjalan dalam Web Worker; berkomunikasi dengan model data AI Table.
- **Sidebar UI**: berjalan dalam iframe panel sisi; memaparkan antara muka pengguna dan mengendalikan interaksi.

## Kebenaran Plugin

Setelah anda menerbitkan Plugin Tersuai anda, pengguna AI Table berikut boleh melihat dan menggunakannya:

1. Dengan Kebenaran Lanjutan **dimatikan**: pengguna dengan kebenaran **Edit** atau **Urus** boleh menggunakan plugin.
2. Dengan Kebenaran Lanjutan **dihidupkan**: hanya pengguna dengan kebenaran **Urus** peringkat jadual yang boleh menggunakan plugin.

## FAQ

#### S: Apakah bezanya dengan Skrip Plugin?

J: Skrip Plugin membolehkan anda menulis sekumpulan kod dalam kotak input dan menjalankannya terus. Plugin Tersuai memerlukan anda melancarkan perkhidmatan anda sendiri.

#### S: API terbuka AI Table manakah yang boleh saya panggil daripada perkhidmatan yang saya lancarkan?
