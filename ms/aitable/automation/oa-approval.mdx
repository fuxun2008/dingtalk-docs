## Senario

- Pembuatan: bidaan alat ganti — setiap nod memerlukan pengesahan dalaman sebelum diteruskan.
- Admin: permintaan pinjaman peralatan dihantar melalui borang AI Table → kelulusan OA → apabila diluluskan, stok automatik dikeluarkan dan inventori dikurangkan.
- Rangkaian F\&B: setiap langkah pembukaan cawangan baharu mencetuskan kelulusan sebelum fasa seterusnya.

## Konfigurasikan Automasi

Tetapkan pencetus, kemudian pilih tindakan **Mulakan kelulusan OA (baharu)** — nod baharu ini menyokong penulisan semula status.

Pilih borang kelulusan OA yang hendak dipautkan (anda perlu ada kebenaran admin OA terlebih dahulu — lihat "Cara memohon kebenaran admin" di bawah).

- Pilih "dimulakan oleh sistem"
- Atau pilih "dimulakan oleh pengklik butang"
- Petakan pembolehubah medan AI Table kepada input borang — medan lanjutan seperti Lampiran dan Jabatan turut disokong

Untuk menulis semula status kelulusan ke AI Table, hidupkan **Segerakkan status semula ke AI Table selepas kelulusan bermula**:

- Pilih jadual yang hendak ditulis semula (biasanya jadual tempat rekod pencetus berada).
- Pilih medan yang akan menerima status.

## Pemetaan Medan Kepada OA

Oleh kerana AI Table dan kelulusan OA adalah dua sistem yang berasingan, jenis medan mesti sepadan tepat — jika tidak, kelulusan akan gagal atau tiba dalam keadaan kosong. Jenis yang disokong:

| Medan OA | Medan AI Table | Nota |
| --- | --- | --- |
| Teks satu baris | ✅ Teks | |
| Teks pelbagai baris | ✅ Teks Kaya | Pemformatan / gambar dalam teks kaya akan digugurkan |
| Nombor | ✅ Nombor | |
| Pilihan tunggal | ✅ Pilihan tunggal | Pilihan mesti sepadan tepat |
| Pilihan berbilang | ✅ Pilihan berbilang | Pilihan mesti sepadan tepat |
| Kad pengenalan | ✅ Kad pengenalan | |
| Tarikh | ✅ Tarikh | |
| Julat masa | ✅ Tarikh | |
| Telefon | ✅ Telefon | |
| Lampiran | ✅ Lampiran / Gambar | Lampiran berbilang disokong sehingga 10 — lebihan tidak disegerakkan |
| Kenalan | ⚠️ Hanya kenalan dalaman | Kenalan luaran akan mengembalikan nilai kosong |
| Gambar | ⚠️ Tidak disokong | Gunakan medan Lampiran di pihak OA |
| Kenalan luaran | ⚠️ Tidak disokong | |
| Tandatangan | ❌ Tidak disokong | |
| Kawalan AI | ❌ Tidak disokong | |
| Lata / Kategori | ❌ Tidak disokong | |
| Perincian / Jadual | ❌ Tidak disokong | |
| Jumlah | ❌ Tidak disokong | |

## Soalan Lazim

- **Bagaimana saya mencipta kelulusan OA?**
  - Lihat: [Kelulusan OA — buku panduan DingTalk](https://docs.dingtalk.io/i/p/Y7kmbokZp3pgGLq2/docs/lo1YvX0prG98keM3X7aqVPw7xzbmLdEZ "Kelulusan OA — buku panduan DingTalk")
- **Bagaimana saya mendapatkan kebenaran admin OA?**
  1. Cari admin organisasi anda di **Kenalan** → **Direktori orang** — terangkan sebab anda memerlukannya dan minta mereka memberikan **Sub-admin: Kebenaran kelulusan OA**.

  2. Admin memberikan kebenaran melalui:
     - Buka [Admin Console DingTalk](https://login.dingtalk.io/oauth2/challenge.htm?redirect_uri=https%3A%2F%2Foa.dingtalk.io%2Fomp%2Flogin%2Fdingtalk_sso_call_back%3Fcontinue%3Dhttps%253A%252F%252Foa.dingtalk.io%252Findex.htm&response_type=code&client_id=dingoaltcsv4vlgoefhpec&scope=openid+corpid&org_type=management#/welcome "Admin Console DingTalk").
     - Klik **Keselamatan & kebenaran** → **Pengurusan kebenaran**.

     - Tambah anda sebagai sub-admin dengan skop **Kebenaran kelulusan OA**.

- **Kelulusan mengalami ralat pada satu medan — apa yang perlu dilakukan?**
  1. Semak sama ada mana-mana medan wajib kosong.
  2. Semak jadual pemetaan di atas — medan yang dirujuk mesti daripada jenis yang disokong.
- **Saya ada 15 lampiran — kenapa hanya 10 muncul dalam kelulusan OA?**

  Kelulusan OA menyokong sehingga 10 lampiran sahaja — lebihan tidak disegerakkan.
