Pra-isi nilai lalai dalam borang membolehkan anda melakukan perkara seperti:

**Pra-isi nilai lalai**: apabila sebuah kedai menghantar tugasan borang, isi maklumat kedai secara automatik supaya mereka tidak tersilap taip.

**Tag saluran penyerahan**: apabila pengguna mendaftar, isi lajur **Saluran sumber** secara automatik.

> 📌 Gunakan penjana pautan untuk mencipta pautan pra-isi secara pukal: [https://store.dingtalk.io/materials/659](https://store.dingtalk.io/materials/659 "https://store.dingtalk.io/materials/659")

## Asas

Format:
**Soalan tunggal**: `<form share link>?prefill_<question name>=<value>`. **Berbilang soalan**: `<form share link>?prefill_<question name>=<value>&prefill_<question name>=<value>`.

Contoh:
[https://docs.dingtalk.io/notable/share/form/v011GXn4BrXGJobODQ4\_hERWDMS\_7LisUkm?prefill\_标题=预设标题&prefill\_单选=选项二](https://docs.dingtalk.io/notable/share/form/v011GXn4BrXGJobODQ4_hERWDMS_7LisUkm?prefill_标题=预设标题&prefill_单选=选项二 "https://docs.dingtalk.io/notable/share/form/v011GXn4BrXGJobODQ4_hERWDMS_7LisUkm?prefill_标题=预设标题&prefill_单选=选项二")

Jenis soalan yang menyokong nilai lalai: teks, nombor, pilihan tunggal, pelbagai pilihan.

| Jenis soalan  | Format                     |
| ----- | ------------------------ |
| Teks    | `<form link>?prefill_Channel=WeChat`  |
| Nombor    | `<form link>?prefill_Score=1`   |
| Pilihan tunggal / pelbagai pilihan | `<form link>?prefill_Pick=Sneakers` |

Jika nilai lalai anda mengandungi aksara khas, kodkannya mengikut jadual berikut:

| Aksara | Dikodkan |
| ---- | ------------ |
| Ruang   | %20 or +      |
| ;    | %3B          |
| :    | %3A          |
| \\[ | %5B          |
| (    | %28          |
| )    | %29          |
| &    | %26          |
| \\\$ | %24          |
| ,    | %2C          |
| ！    | %21          |
| @    | %40          |
| ]    | %5D          |
| \{    | %7B          |
| \}    | %7D          |
| \#  | %23          |

Jika anda tidak mahu soalan yang telah dipra-isi dipaparkan pada borang, tambahkan `&hide_<question name>=1` pada pautan tersebut. Contoh: sembunyikan medan **Pengulas** pada borang penyerahan kandungan:

[Form link?prefill\_Reviewer=Kato](https://docs.dingtalk.io/notable/share/form/v011GXn4BrXGJobODQ4_hERWDMS_7LisUkm?prefill_标题=预设标题&prefill_单选=选项二 "Form link?prefill_Reviewer=Kato")[&hide\_ProjectOwner=1](https://docs.dingtalk.io/notable/share/form/v011GXn4BrXGJobODQ4_hERWDMS_7LisUkm?prefill_标题=预设标题&prefill_单选=选项二 "&hide_ProjectOwner=1")

Helah ini juga membolehkan anda menjejaki saluran penyerahan. Katakan anda sedang mengumpul maklum balas mengenai satu acara dan ingin mengetahui saluran mana yang menghasilkan penyerahan paling banyak:

1. Tambah satu soalan bernama **Platform penyerahan**.
2. Buka perkongsian borang, tetapkan khalayak, dan salin pautan perkongsian.
3. Tambah parameter sumber pada pautan tersebut. Jika sumbernya ialah DingTalk:

   `<form link>?prefill_SubmissionPlatform=DingTalk&hide_SubmissionPlatform=1`
4. Kongsi setiap varian ke platform yang berbeza.

Nilai lalai yang dipra-isi ini membolehkan anda menjejaki dengan tepat dari mana setiap penyerahan berasal.

## Soalan Lazim

#### S: **Adakah Nilai Lalai Pra-isi Saya Akan Rosak Jika Saya Namakan Semula Soalan?**

J: Ya — pautan tersebut akan rosak. Bina semula pautan itu dengan nama soalan yang baharu.

#### S: **Mengapa Nama Orang yang Dipra-isi Tidak Berkuat Kuasa dalam Borang AI Table?**

J: Beberapa kemungkinan:

- Nama itu berganda dalam organisasi.
- Orang itu adalah luaran dan tiada dalam Kenalan DingTalk anda.
- Nama itu tersilap eja — semak semula.

#### S: **Selepas Menetapkan Nilai Lalai dalam Borang AI Table, Adakah Setiap Responden Akan Melihatnya?**

J: Ya. Untuk menyembunyikannya, tambahkan `&hide_<question name>=1` pada pautan tersebut.

#### S: **Saya Telah Menambah Parameter Sembunyi tetapi Soalan Masih Dipaparkan pada Borang. Mengapa?**

J: Kemungkinan besar medan itu wajib dan nilai lalai tidak berkesan. Dengan nilai lalai yang tidak sah, medan wajib itu kekal kosong, jadi ia tidak boleh disembunyikan. Tetapkan semula nilai lalai tersebut.
