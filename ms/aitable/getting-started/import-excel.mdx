AI Table menyokong import **fail Excel** dan mengesan format data secara automatik semasa proses import, menukar setiap lajur kepada jenis medan yang paling sesuai.

## Import fail Excel sebagai AI Table baharu

1. Dari halaman utama AI Table, pilih **Import Excel / hamparan dalam talian**.
2. Pilih **fail Excel (`.xlsx` atau `.csv`)** untuk dimuat naik.

![](https://img.alicdn.com/imgextra/i4/O1CN01MlcaWR1ScL1e2ZG3n_!!6000000002267-2-tps-2316-1284.png)


## Import ke dalam AI Table semasa

1. Dengan AI Table sedia ada dibuka, klik **+ Baharu / Import** di penjuru bawah kiri.
2. Pilih **Import Excel (`.xlsx`, `.csv`)** untuk dimuat naik.

![](https://img.alicdn.com/imgextra/i1/O1CN011EkaU71P8cTiRrUEw_!!6000000001796-2-tps-1250-502.png)

## Import data Excel ke dalam jadual sedia ada

Terdapat tiga cara untuk import data daripada fail Excel ke dalam jadual sedia ada:

1. Dalam bar sisi kiri, buka menu sebelah kanan sesuatu jadual dan pilih **Import Excel**.

2. Dalam bar sisi kiri, klik **+ Tambah / Import** → **Import Excel** → **Import ke dalam jadual sedia ada**, kemudian pilih jadual sasaran.

3. Di dalam paparan jadual yang dibuka, klik anak panah di sebelah **Tambah rekod** dan pilih **Import Excel**.

## Melaporkan isu import

Jika data Excel anda muncul kucar-kacir atau tidak lengkap dalam AI Table, anda boleh [hantar fail tersebut](https://docs.dingtalk.io/notable/share/form/v01ZWGl05mj7a2d5n34_hERWDMS_YxEpVMk "Hantar fail") dan kami akan menyemaknya.
