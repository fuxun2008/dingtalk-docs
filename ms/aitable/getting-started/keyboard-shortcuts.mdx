title: "Pintasan Papan Kekunci"
description: "Rujukan lengkap pintasan papan kekunci untuk AI Table — merangkumi Pembantu AI, batalkan/buat semula, pemilihan berbilang sel, kembangkan rekod, simpan paparan, dan banyak lagi untuk Windows dan macOS."

Gunakan pintasan papan kekunci ini untuk bergerak lebih pantas dalam AI Table:

| Tindakan                                               | Windows                              | macOS                            |
| ----------------------------------------------------- | ------------------------------------ | -------------------------------- |
| Buka Pembantu AI                                       | `Ctrl` + `/`                         | `⌘` + `/`                        |
| Batalkan                                               | `Ctrl` + `Z`                         | `⌘` + `Z`                        |
| Buat Semula                                            | `Ctrl` + `Shift` + `Z`               | `⌘` + `Shift` + `Z`              |
| Potong                                                 | `Ctrl` + `X`                         | `⌘` + `X`                        |
| Kosongkan kandungan sel                                | `Del`                                | `Del`                            |
| Kembangkan pemilihan ke atas / bawah / kiri / kanan    | `Shift` + `↑/↓/←/→`                  | `Shift` + `↑/↓/←/→`              |
| Kembangkan pemilihan ke tepi jadual                    | `Ctrl` + `Shift` + `↑/↓/←/→`         | `⌘` + `Shift` + `↑/↓/←/→`        |
| Tambah rekod di bawah                                  | `Shift` + `Enter`                    | `Shift` + `Enter`                |
| Pilih semua                                            | `Ctrl` + `A`                         | `⌘` + `A`                        |
| Komen                                                  | `Ctrl` + `Shift` + `M`               | `⌘` + `Shift` + `M`              |
| Simpan konfigurasi paparan                             | `Ctrl` + `S`                         | `⌘` + `S`                        |
| Cari                                                   | `Ctrl` + `F`                         | `⌘` + `F`                        |
| Kembangkan sel teks                                    | `Shift` + `Space`                    | `Shift` + `Space`                |
| Buka butiran rekod dalam panel sisi                    | `Space`                              | `Space`                          |
| Tutup panel sisi butiran rekod                         | `Esc`                                | `Esc`                            |
| Tatal ke bahagian bawah paparan                        | `Ctrl` + `↓`                         | `⌘` + `↓`                        |
| Tatal ke bahagian atas paparan                         | `Ctrl` + `↑`                         | `⌘` + `↑`                        |
| Rekod sebelumnya (dalam panel butiran)                 | `Ctrl` + `Shift` + `↑`               | `⌘` + `Shift` + `↑`              |
| Rekod seterusnya (dalam panel butiran)                 | `Ctrl` + `Shift` + `↓`               | `⌘` + `Shift` + `↓`              |
| Togol bar sisi kiri                                    | `Ctrl` + `\\`                        | `⌘` + `\\`                       |
| Tatal secara menegak                                   | `Mouse wheel`                        | `Mouse wheel`                    |
| Tatal secara mendatar                                  | `Shift` + `Mouse wheel`              | `Shift` + `Mouse wheel`          |
