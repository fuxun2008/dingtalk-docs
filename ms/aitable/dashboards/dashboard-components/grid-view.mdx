Benamkan paparan grid dalam papan pemuka — bawa data teras AI Table ke dalam paparan papan pemuka. Gabungkan widget grid dengan carta analisis (garisan, lajur, dan lain-lain) untuk persembahan dan penyebaran hujung ke hujung — tingkatkan kerjasama merentas modul.

## Tambah Widget Paparan Grid

Di bahagian atas kiri, klik **Add chart**. Pilih **Grid view**.

![](https://img.alicdn.com/imgextra/i2/O1CN01iQv3lg1beTPj39UO8_!!6000000003490-0-tps-376-649.jpg)


## Konfigurasikan Widget Paparan Grid

Konfigurasikan jenis/data dan gaya tersuai:

**Data**: pilih sumber — jadual dan julat data. **All data** mengaktifkan penapis.

![](https://img.alicdn.com/imgextra/i2/O1CN01ksGV2122IU1UYOZMX_!!6000000007097-0-tps-296-307.jpg)


**Konfigurasi grid**: kumpulan, susunan, ketinggian baris, medan yang dipaparkan dan susunannya.

![](https://img.alicdn.com/imgextra/i1/O1CN01nS36oP1j8t1ZqQeal_!!6000000004504-0-tps-287-499.jpg)


**Gaya tersuai**: warna latar belakang.

![](https://img.alicdn.com/imgextra/i2/O1CN01ks2oL21nQ4LXrd8OZ_!!6000000005083-0-tps-296-784.jpg)


## Urus Widget Paparan Grid

Tuding kursor pada widget — cari ikon di bahagian atas kanan. Klik untuk: konfigurasikan, namakan semula, salin, tambah ke pusat papan pemuka, salin sebagai gambar, eksport sebagai gambar, padam.

![](https://img.alicdn.com/imgextra/i1/O1CN01LBE8nm1whmCXoehWj_!!6000000006340-0-tps-918-336.jpg)


Seret bucu bawah kanan untuk mengubah saiz. Seret bahagian atas untuk mengubah kedudukan.

## Hubungan dengan Paparan Grid Asal

Widget paparan grid yang ditambah ke papan pemuka berhubung dengan paparan grid asal seperti berikut:

- Widget tidak boleh diedit.
- Apabila anda mengedit sel dalam paparan grid asal, widget dikemas kini secara serentak. "Edit" = tambah/edit/padam rekod, tambah/edit/padam medan.
- Konfigurasi mereka adalah berasingan. "Konfigurasi" = penapis, kumpulan, susunan, ketinggian baris, lebar lajur, susunan medan, susunan rekod, dan lain-lain.

## Soalan Lazim

#### **S: Adakah Tetapan Penapis/Kumpulan Dalam Widget Menjejaskan Paparan Asal?**

J: Tidak. Konfigurasi widget hanya terpakai dalam papan pemuka — paparan asal tidak terjejas.

#### **S: Jika Papan Pemuka Mempunyai Penapis Global, Data Apakah yang Dipaparkan dalam Widget?**

J: Penapis global turut terpakai pada widget — dan bertindan dengan penapis widget itu sendiri.
