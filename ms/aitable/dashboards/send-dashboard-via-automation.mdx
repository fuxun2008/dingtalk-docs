## Gambaran Keseluruhan

Dalam AI Table, konfigurasikan aliran automasi untuk push Papan Pemuka sebagai mesej gambar mengikut jadual — pastikan pasukan sentiasa selaras dengan data terkini.

### Senario Biasa

- **Kumpulan kerja projek**

  Jadualkan Papan Pemuka kemajuan atau kualiti projek supaya dihantar secara automatik ke kumpulan projek — penyegerakan data yang cekap.
- **Ringkasan eksekutif**

  Push Papan Pemuka perniagaan teras secara harian/mingguan kepada pihak pengurusan — konteks keputusan berfrekuensi tinggi.
- **Laporan perkhidmatan pelanggan**

  Hantar secara automatik Papan Pemuka perkhidmatan khusus kepada pelanggan utama mengikut jadual — tingkatkan ketelusan dan imej profesional.

## Langkah

1. Klik **Scheduled push** di bahagian atas kanan Papan Pemuka untuk membuka tetapan. Tetapkan jadual dan penerima secara terus.

2. Klik **More config** untuk masuk ke editor automasi. Konfigurasikan syarat pencetus (sekali sahaja atau berkala), penerima, dan kandungan mesej.

3. Aktifkan automasi. Penerima akan menerima push Papan Pemuka dalam sembang DingTalk.

## Soalan Lazim

#### S: Siapa Yang Boleh Konfigurasikan Push Papan Pemuka Berjadual?

J: Hanya pemilik AI Table atau pengguna dengan kebenaran admin.

#### S: Adakah Push Papan Pemuka Bersifat Live?

J: Tidak — snapshot mencerminkan data pada saat push dilakukan.
