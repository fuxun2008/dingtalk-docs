Setiap lajur dalam AI Table dipanggil **medan**. Medan menentukan jenis dan format setiap lajur, memastikan data anda kekal tersusun dan konsisten.

## Pengenalan 2 minit tentang jenis medan AI Table

## Medan utama

Lajur pertama dalam AI Table ialah **medan utama** — medan ini tidak boleh dipadam atau disembunyikan. Dalam AI Table versi terkini, medan utama secara lalai menggunakan jenis **Doc**. Lihat [Jadual sebagai dokumen](/aitable/fields/field-types/table-as-doc) untuk maklumat lanjut.

## Asas

### Tambah medan

#### **Tambah medan / lajur dalam paparan Grid**

1. Klik ikon ➕ di sebelah kanan bar tajuk.
2. Taipkan nama medan dan pilih jenisnya.

#### **Tambah medan dalam paparan lain**

1. **Paparan Kanban** — klik **Konfigurasi kad**; tambah medan di bahagian bawah dialog.
2. **Paparan Galeri** — klik **Konfigurasi galeri**; tambah medan di bahagian bawah dialog.
3. **Paparan Kalendar / Gantt** — klik **Urus medan**; tambah medan di bahagian bawah dialog.

#### **Tambah medan dalam paparan Borang**

Semasa menambah soalan, klik **jenis medan** yang berkaitan untuk menyisipkannya; tukar ke **mod Edit** untuk menyunting.

Untuk maklumat lanjut tentang borang, lihat [Asas borang](/aitable/forms/form-basics).

### Edit medan

Terdapat dua cara untuk mengedit medan sedia ada:

1. **Klik dua kali** pada tajuk medan untuk membuka editor.
2. **Klik kanan** pada tajuk medan — atau arahkan tetikus dan klik dropdown — pilih **Edit medan / lajur** dalam menu.

### Sembunyi / papar medan

Buka [Urus medan](/aitable/fields/field-management) — klik ikon di sebelah kanan nama medan untuk **memapar / menyembunyikan** medan tersebut.

Atau klik kanan pada tajuk medan (atau arahkan tetikus dan klik dropdown) — pilih **Sembunyikan medan / lajur**.

### Bekukan medan / lajur

Klik kanan pada tajuk medan (atau arahkan tetikus dan klik dropdown) — pilih **Bekukan sehingga medan / lajur ini**.

Arahkan tetikus ke **garis pembekuan** dan seret ke kiri / kanan untuk melaraskan julat beku.

Nota: **medan utama** dibekukan secara lalai dan tidak boleh dinyahbekukan.

### Susun semula medan

**Paparan Grid** menyokong penyusunan semula.

Seret **tajuk medan** ke kiri / kanan untuk menyusun semula.

**Susun semula dalam paparan lain**

Klik **Urus medan** (atau **Konfigurasi kad** / **Konfigurasi galeri**), tahan medan di sebelah kiri dan seret.

Nota: medan utama tidak boleh dipindahkan.

### Edit penerangan medan

Klik kanan pada tajuk medan (atau arahkan tetikus dan klik dropdown) — pilih **Edit penerangan medan / lajur**. Taipkan penerangan dan klik **OK**.

### Tetapkan nilai lalai medan

1. Klik dua kali pada tajuk medan / lajur untuk membuka editor.
2. Taipkan nilai lalai dalam medan input atau dropdown.
3. Klik sahkan untuk menyimpan.

Nilai lalai terpakai untuk **keseluruhan jadual**, bukan hanya paparan semasa.

Kebanyakan medan biasa menyokong nilai lalai: tajuk, nombor, mata wang, tarikh, pilihan tunggal, pilihan berbilang, penilaian, kemajuan, ahli, sembang kumpulan, URL, alamat, kod bar, kotak semak, jabatan, lokasi, telefon, e-mel, teks kaya.

## Soalan lazim

#### **S: Mengapa saya tidak boleh memadam atau menyembunyikan medan pertama?**

J: Medan pertama dalam AI Table ialah **medan utama** — medan ini tidak boleh dipadam, dipindahkan, digantikan, atau disembunyikan, dan medan lain tidak boleh dinaikkan taraf menjadi medan utama.

#### **S: Bagaimana saya memaparkan medan yang tersembunyi?**

J: Klik **Urus medan** di atas jadual — klik ikon di sebelah kanan nama medan untuk memapar / menyembunyikan.

#### **S: Bagaimana saya menyahbekukan medan?**

J: Seret **garis pembekuan** untuk melaraskan julat beku. Medan utama tidak boleh dinyahbekukan, dan menyahbekukan medan tunggal masih belum disokong.

#### **S: Bolehkah saya menjajarkan nilai ke tengah dalam medan AI Table?**

J: Belum lagi.
