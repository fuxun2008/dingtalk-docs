# 1 Gambaran keseluruhan

Tandatangan ialah utiliti untuk melukis imej tandatangan. Ia bukan tandatangan elektronik di bawah mana-mana undang-undang tandatangan elektronik dan **tidak mempunyai kesan undang-undang** — hanya untuk tujuan rekod.

# 2 Asas

Di bahagian kanan atas bar tajuk, klik ➕ Tambah medan — di bawah jenis medan, pilih **Tandatangan**.

**Dwiklik sel** untuk membuka pad tandatangan. Klik **Kosongkan** di bahagian kanan atas untuk buat semula, atau **Sahkan** di bahagian kanan bawah untuk simpan.
