# 1 Gambaran keseluruhan

Guna medan ini untuk **mengumpul nombor kad pengenalan** dengan **pengesahan** terbina dalam — nombor tidak sah akan ditanda dan tidak boleh disimpan.

# 2 Asas

## 2.1 Tambah Medan dalam Paparan Grid

Klik ➕ di sebelah kanan atas bar tajuk AI Table — pilih **Nombor kad pengenalan** di bawah jenis medan.

## 2.2 Tambah Medan dalam Paparan Borang

Dalam senarai soalan di sebelah kiri, pilih Nombor kad pengenalan — guna untuk mengumpul respons dalam borang.

## 2.3 Urus dan Edit Medan

Dwiklik tajuk medan atau klik dropdown — duplikasi, padam, bekukan, dan lain-lain.

# 3 Senario

Medan nombor kad pengenalan terutamanya digunakan untuk pengumpulan maklumat — menggunakan paparan borang melindungi privasi responden. Untuk mengumpul melalui paparan grid sebaliknya, hidupkan **kebenaran lanjutan**: tetapkan **Kebenaran Edit** peranan kepada "rekod berkaitan ahli tersebut" dan tetapkan rekod lain kepada **tiada akses**.
