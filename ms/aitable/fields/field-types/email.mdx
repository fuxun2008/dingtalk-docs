# Gambaran keseluruhan

Gunakan medan e-mel AI Table untuk mengesahkan format dan memastikan entri kekal bersih.

# Asas

Tambah medan: di bahagian atas kanan bar tajuk AI Table, klik + dan pilih Email di bawah jenis medan.

Format e-mel disahkan semasa anda menaip.

# Soalan Lazim

- **S: Bolehkah satu sel menyimpan beberapa alamat e-mel?**

  J: Tidak — memasukkan e-mel baharu akan menggantikan e-mel sebelumnya.
