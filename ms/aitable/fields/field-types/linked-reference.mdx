# Gambaran keseluruhan

**Penyegerakan**: dengan [Pautan Sehala](/aitable/fields/field-types/one-way-link) atau [pautan dua hala](/aitable/fields/field-types/two-way-link), anda sambungkan Jadual A dan B. Medan pautan hanya tunjuk **medan utama** — untuk papar **medan lain** daripada A dalam B, guna **rujukan terpaut**.

**Pengagregatan**: semasa tarik nilai daripada A ke B, medan rujukan terpaut juga boleh mengagregatkannya — nilai asal, dinyahduakan, jumlah, dan sebagainya.

# Asas

## Tambah medan

Klik ➕ di bahagian atas kanan bar tajuk AI Table — pilih **Rujukan terpaut** di bawah jenis medan.

## Konfigurasikan rujukan terpaut

**Pilih medan pautan**: hanya medan **Pautan Sehala / pautan dua hala** dalam jadual semasa — rujukan terpaut bergantung pada medan pautan.

**Pilih medan untuk dirujuk**: hanya medan daripada jadual sumber terpaut. Contoh: jika medan pautan menunjuk ke Jadual A, rujukan hanya boleh pilih medan dalam A.

**Pengagregatan**:

| Pengagregatan | Penerangan |
| ------ | ---------------------- |
| Asal | Rujuk data lajur secara terus |
| Dinyahduakan | Padam pendua daripada nilai asal |
| Jumlah | Tambah semua nilai asal |
| Purata | Purata nilai asal |
| Maks | Nilai terbesar daripada nilai asal |
| Min | Nilai terkecil daripada nilai asal |
| Kira nombor bukan kosong | Kiraan nilai berangka yang bukan kosong |
| Kira nilai bukan kosong | Kiraan nilai bukan kosong, sama ada berangka atau teks |
| Kira berbeza | Kiraan selepas dinyahduakan |
| Kira baris | Kiraan Rekod sumber |
| Gabungkan sebagai teks | Sertai nilai yang dipaparkan dengan pemisah koma |

## Urus dan edit medan

Klik dua kali pada Tajuk medan atau klik menu lungsur — Salin, Tampal, bekukan, dan sebagainya.
