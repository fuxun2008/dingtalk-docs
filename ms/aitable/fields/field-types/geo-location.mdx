# 1 Gambaran keseluruhan

Gunakan medan **Lokasi** AI Table untuk merekod kedudukan dengan pantas — input manual, cari mana-mana lokasi, atau tangkap lokasi masa nyata di mudah alih.

**Senario biasa**: tangkap lokasi masa nyata di mudah alih untuk mengesahkan pemeriksaan, daftar masuk, dan sebagainya.

# 2 Asas

Dalam paparan grid, klik ➕ **Tambah medan** di bahagian atas kanan bar alat — pilih **Lokasi** di bawah jenis medan. Kaedah input: **mana-mana lokasi** atau **masa nyata mudah alih sahaja**.

Dalam **paparan borang**, pilih **Lokasi** daripada senarai soalan — togol **masa nyata mudah alih sahaja** untuk mengumpul lokasi melalui borang.

Dengan **mana-mana lokasi**, dwiklik sel — taip dalam bar carian, pilih satu hasil, dan sahkan di bahagian bawah kanan.

Dengan **masa nyata mudah alih sahaja**, pada peranti mudah alih, buka butiran rekod atau pautan borang dan **ketik untuk mengesan lokasi**.

# 3 Soalan lazim

- **S: Bolehkah satu sel menyimpan pelbagai lokasi?**

  J: Tidak.
- **S: Adakah menukar kaedah input menjejaskan entri sedia ada?**

  J: Tidak.
