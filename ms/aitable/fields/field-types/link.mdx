# 1 Gambaran keseluruhan

Guna medan URL untuk masukkan pautan dengan teks paparan dengan pantas — klik untuk buka halaman.

# 2 Asas

## 2.1 Tambah medan URL

1. Klik + di bahagian kanan atas bar tajuk.
2. Klik "Jenis medan".
3. Pilih **URL**.

## 2.2 Edit URL

1. Dwiklik sel.
2. Dalam kotak teks di bahagian atas, masukkan **teks paparan**.
3. Dalam kotak teks di bahagian bawah, masukkan **URL** yang hendak dibuka.
4. Klik Simpan.

# 3 Soalan lazim

- **S: Bolehkah satu sel menyimpan beberapa URL?**

  J: Tidak — setiap sel hanya boleh menyimpan satu URL.
