AI Table membolehkan anda menetapkan medan utama (lajur pertama) kepada jenis **Dokumen** — setiap rekod menjadi dokumen, menjadikan jadual anda pangkalan data mesra dokumen.

# Apakah kegunaan jenis Dokumen?

### **Pengurusan Influencer**

Jika anda menguruskan operasi di syarikat e-dagang secara langsung (livestream commerce) dan menggunakan AI Table untuk menguruskan influencer, jadual dahulunya hanya menyimpan maklumat berstruktur — nama pengguna, bilangan pengikut, niche. Kini, buka baris tersebut dan cipta profil bergambar penuh untuk setiap influencer terus dalam rekod yang sama.

### **Pengurusan Projek**

Klik mana-mana tugas untuk melihat / mengedit butiran penuh — tulis spesifikasi terus dalam jadual penjejakan projek anda.

### **Pengurusan Produk**

Klik mana-mana rekod produk untuk melihat / mengedit penerangan penuh.

### Knowledge Base

Setiap AI Table kini menjadi Knowledge Base secara automatik.

# Asas

### Menaik Taraf Jadual Sedia Ada kepada "Jadual sebagai Dokumen"

Dwiklik nama medan pertama untuk membuka editor — pilih **Dokumen** sebagai jenis untuk mengaktifkan **jadual sebagai dokumen**.

Jadual baharu dilengkapi ciri ini secara lalai. Ikon dokumen dipaparkan di sebelah teks dalam lajur pertama.

Ikon ini membezakan antara "belum ada dokumen" dengan "dokumen telah dicipta".

## Edit Dokumen

Klik butang **Paparan** pada medan pertama mana-mana baris untuk mengembangkan rekod. Klik kawasan kosong di bahagian bawah panel butiran sebelah kanan untuk mula menulis — sebaik sahaja anda menaip, dokumen rekod tersebut akan dicipta.

Taip "/" untuk memaparkan alat dokumen; bar alat dokumen turut dipaparkan di bahagian atas — pengalaman mengedit adalah sama seperti DingTalk Docs.

### Edit dalam Mod Dokumen

Klik ikon di penjuru kanan atas dan pilih **Buka sebagai dokumen** — beralih ke mod pengeditan dokumen penuh.

Mod dokumen membuka semua ciri DingTalk Docs. Suntingan dan komen disegerakkan antara kedua-dua paparan.

## Tukar Cara Rekod Dikembangkan

Klik ikon di sebelah kanan nama paparan untuk membuka tetapan paparan — tukar gaya paparan rekod.

AI Table menyokong tiga cara untuk mengembangkan rekod:

1. Paparan dalam panel sisi kanan
2. Paparan dalam modal
3. Paparan sebagai halaman penuh

## Kongsi

Klik **Kongsi** di penjuru kanan atas — pilih **Hantar ke sembang** atau **Salin pautan rekod**.

## Kebenaran

Kebenaran lanjutan untuk "jadual sebagai dokumen" dibahagikan kepada tiga bahagian:

1. **Tajuk** — kebenaran **paparan** secara lalai; anda juga boleh mengaktifkan **tambah** dan **edit**.
2. **Medan** — paparan mengikut kebenaran medan; hanya kebenaran **urus** boleh menambah medan.
   | Paparan | Tambah | Edit | Kelakuan |
   | ---- | --- | ---- | -------- |
   | ❌ | ❌ | ❌ | Medan disembunyikan |
   | ✅ | ✅ | ❌ | Medan dipaparkan; klik memaparkan "tidak boleh diedit" |
   | ✅ | ✅ | ✅ | Medan dipaparkan; dwiklik untuk mengedit seperti biasa |
3. **Dokumen** — kandungan mewarisi kebenaran tajuk secara lalai. Maklumat ahli kumpulan peranan disegerakkan ke kebenaran dokumen; kebenaran dokumen boleh diedit di dalam dokumen tersebut. Kebenaran berkuat kuasa adalah yang lebih tinggi antara kebenaran lanjutan dan kebenaran dokumen.

Nota: pengguna dengan kebenaran **tambah** tetapi tanpa **edit** boleh mengedit semasa penciptaan pertama, kemudian hanya boleh melihat selepas itu.

| **Kebenaran lanjutan** | **Kebenaran kandungan dokumen** | **Kelakuan** |
| ----------------------- | ----------------------- | ------------ |
| Tiada | Tidak boleh melihat | Tidak boleh membuka dokumen — digesa untuk memohon akses |
|      | Boleh melihat | Boleh melihat kandungan dokumen |
|      | Boleh mengedit | Boleh mengedit kandungan dokumen |
| Paparan / Edit | Tidak boleh melihat | Tajuk dan medan yang boleh diakses dipaparkan, tiada kandungan |
|             | Boleh melihat | Tajuk, medan yang boleh diakses, dan kandungan dipaparkan |
|             | Boleh mengedit | Tajuk, medan yang boleh diakses, dan kandungan dipaparkan (boleh diedit) |

### Paparan Dokumen

| **Kebenaran tajuk** | **Kebenaran kandungan medan** | **Kebenaran kandungan** | **Kelakuan** |
| -------------- | ---------------------- | ------------- | ------------ |
| ❌ | ❌ | ❌ | Tidak boleh membuka dokumen — digesa untuk memohon akses |
| ❌ | ❌ | ✅ | Kandungan dipaparkan (tajuk boleh dilihat, tidak boleh diedit) |
| ❌ | ✅ | ❌ | Tidak wujud |
| ✅ | ❌ | ❌ | Tajuk dipaparkan; selebihnya memaparkan "kebenaran lanjutan diaktifkan" |
| ❌ | ✅ | ✅ | Tidak wujud |
| ✅ | ❌ | ✅ | Tajuk dan kandungan dipaparkan; selebihnya memaparkan "kebenaran lanjutan diaktifkan" |
| ✅ | ✅ | ❌ | Tajuk dan kandungan medan dipaparkan; selebihnya memaparkan "kebenaran lanjutan diaktifkan" |
| ✅ | ✅ | ✅ | Tajuk, kandungan medan, dan kandungan dipaparkan |
