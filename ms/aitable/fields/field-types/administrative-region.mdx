# 1 Gambaran keseluruhan

Gunakan medan **Alamat** AI Table untuk memilih lokasi secara manual mengikut format **wilayah / bandar / daerah (— jalan)**.

# 2 Asas

**Tambah alamat dalam paparan grid**

1. Klik + di penjuru kanan atas bar tajuk.
2. Klik **Jenis medan**.
3. Pilih **Alamat**.

**Tetapkan format alamat**

Dalam menu lungsur format, pilih **Wilayah / bandar / daerah** atau **Wilayah / bandar / daerah — jalan**.

**Wilayah / bandar / daerah** membolehkan responden memilih hanya daripada senarai wilayah terbina dalam.

**Wilayah / bandar / daerah — jalan** turut memerlukan nama jalan dalam bentuk teks bebas.

**Tambah alamat dalam paparan borang**

1. Pilih **Alamat** daripada senarai soalan di sebelah kiri.
2. Pilih **format** daripada menu lungsur di bawah soalan.
