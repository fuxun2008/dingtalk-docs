Medan Formula ialah satu jenis medan dalam AI Table — gunakan fungsi formula yang kaya untuk pengiraan data yang fleksibel.

## Cipta Medan Formula

Klik ikon **+** di sebelah kanan bar tajuk AI Table, pilih **Formula** sebagai jenis medan.

![](https://img.alicdn.com/imgextra/i1/O1CN01Qkznx71eXYH9gb8Uf_!!6000000003881-2-tps-1032-474.png)


## Edit Formula

Klik **Edit formula** — editor formula akan dibuka.

![](https://img.alicdn.com/imgextra/i4/O1CN01GpkxPA1Dy7cv6C9jX_!!6000000000284-2-tps-628-433.png)


Edit formula terus dalam kotak input di bahagian atas.

Dalam tab **Formula edit**, rujuk medan atau pilih fungsi mengikut kategori.

Dalam tab **AI generate formula**, jana formula daripada bahasa semula jadi — butiran: [Jana formula dengan AI](/ms/aitable/formulas/ai-generate-formula).

![](https://img.alicdn.com/imgextra/i2/O1CN01Rgi2P71ulK2HVJLKi_!!6000000006077-2-tps-1080-936.png)


## Konsep

| Istilah | Maksud |
| --- | --- |
| Medan | Nilai lajur pada baris tertentu, digunakan dalam pengiraan formula |
| Medan seluruh lajur | Kumpulan nilai bagi keseluruhan lajur, digunakan dalam pengiraan formula |
| Kurungan | Digunakan dalam formula untuk merujuk jadual atau medan AI Table |
| Operator | Simbol logik atau aritmetik yang digunakan dalam formula |
| Fungsi | Menghasilkan output yang dijangka melalui peraturan pengiraan tertentu |
| Argumen | Nombor atau teks yang terlibat dalam pengiraan formula |
| String | Satu urutan teks yang digunakan dalam pengiraan formula |
| Array | Kumpulan nilai |

## Operator Biasa

| Jenis | Operator | Maksud |
| --- | --- | --- |
| Aritmetik | `+` | Tambah dua nilai |
| | `-` | Tolak dua nilai |
| | `*` | Darab dua nilai |
| | `/` | Bahagi dua nilai |
| Gabungan teks | `&` | Gabungkan dua string; gabungkan nombor dengan teks apabila salah satu bersifat numerik |
| Logik | `>` | Lebih besar daripada |
| | `>=` | Lebih besar atau sama dengan |
| | `<` | Kurang daripada |
| | `<=` | Kurang atau sama dengan |
| | `=` | Sama dengan |
| | `!=` | Tidak sama dengan |
| | `&&` | DAN |
| | `|` | ATAU |
