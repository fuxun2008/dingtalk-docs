#### 2 Cara Konfigurasikan

Tambah medan masa Kemas Kini Terakhir — sistem akan mencatat cap masa kemas kini terkini bagi setiap rekod.

![](https://img.alicdn.com/imgextra/i1/O1CN01jDRIBk1f3c03Q3EKV_!!6000000003951-2-tps-594-669.png)


Tambah medan carian untuk mendapatkan masa entri terkini bagi setiap orang.

![](https://img.alicdn.com/imgextra/i1/O1CN01x0Mhlf1iSkaPJZPrr_!!6000000004412-2-tps-770-792.png)


Tambah medan formula untuk menanda rekod terkini secara visual.

```javascript
IF([Kemas Kini Terakhir]=[Masa Isian Terakhir],"✅ entri terkini","")
```

![](https://img.alicdn.com/imgextra/i4/O1CN01dQcoU124thRDrljsz_!!6000000007449-2-tps-591-405.png)
