Apabila Formula tidak sah atau tidak dapat dikira untuk baris semasa, Kod ralat akan dipaparkan dalam Sel tersebut.

Kod ralat AI Table yang biasa ditemui:

| Kod ralat | Maksud | Contoh |
| --- | --- | --- |
| \#NULL! | **Ralat null.** Formula mengandungi operator julat yang tidak sah atau menentukan dua julat yang tidak bersilang. | |
| \#DIV/0! | **Ralat bahagi dengan sifar.** Pembahagian dengan pembahagi sifar atau merujuk kepada Sel kosong. | `2/0` |
| \#REF! | **Ralat rujukan tidak sah.** Lajur yang dirujuk telah dipadam atau diubah. | |
| \#N/A | **Ralat nilai tidak tersedia.** Nilai tidak tersedia untuk Fungsi tersebut — Carian tidak menemui sebarang hasil. | `REGEXEXTRACT("def","a")` |
| \#VALUE! | **Ralat nilai.** Jenis argumen atau operan yang salah — contohnya, Teks digunakan apabila Nombor diperlukan. | `SQRT("test")` |
| \#ERROR! | **Ralat penghuraian Formula.** Formula tidak dibentuk dengan betul. | `test formula` |
| \#NUM! | **Ralat Nombor.** Nilai berangka tidak sah, atau hasil terlalu besar atau kecil untuk dipaparkan — contohnya, punca kuasa dua bagi nombor negatif. | `SQRT(-1)` |
| \#NAME? | **Ralat Nama tidak sah.** Teks tidak dikenali dalam Formula — kesilapan menaip pada nama Fungsi. | `SUMMM()` |
| \#TOO\\_LARGE! | **Ralat hasil terlalu besar.** Hasil melebihi 200 item — contohnya, Carian yang mengembalikan lebih daripada 200 nilai. | |
| \#MISMATCH\\_TYPE! | **Ralat Jenis tidak sepadan.** Jenis hasil tidak sepadan dengan Jenis Lajur — biasa berlaku selepas nilai asal diubah. | |
| \#CIRCULAR! | **Ralat rujukan bulatan.** Formula merujuk, secara langsung atau tidak langsung, kepada Selnya sendiri. | |
| \#UNSUPPORT! | **Ralat ciri tidak disokong.** Fungsi atau ciri dalam Formula belum disokong lagi — contohnya, rujukan silang Jadual. | \- |
