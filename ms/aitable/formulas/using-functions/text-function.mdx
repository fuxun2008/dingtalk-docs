# Asas

**TEXT** ialah fungsi AI Table yang biasa digunakan — menukar nombor kepada teks dalam format yang ditetapkan. Tentukan cara nombor dipaparkan: tarikh, masa, mata wang, peratusan, dan sebagainya.

| Format / placeholder | Maksud | Contoh |
| --- | --- | --- |
| \# | Placeholder digit untuk format nombor tersuai | TEXT(34.56,"##.#")=34.6  TEXT(123.456,"##.##")=123.6  TEXT(78.901,"###.###")=78.901 |
| 0 | Digit pad untuk format nombor tersuai | TEXT(56.7,"0.00")=56.70  TEXT(89.12,"0.00")=89.12  TEXT(3.14,"000.00")=003.14 |
| , | Pemisah ribuan — antara # atau 0 | TEXT(123456,"0,0")=123,456 |
| % | Peratus — guna bersama # atau 0 | TEXT(50,"0%")=5000% |
| YYYY | Tahun penuh | TEXT("2023-5-20","YYYY")=2023  TEXT("2023-5-20","YYYY year")=2023 year |
| YY | Tahun ringkas | TEXT("2023-5-20","YY")=23  TEXT("2023-5-20","Y")=23 |
| MMM | Bulan penuh | TEXT("2023-5-20","MMM")=May |
| MM | Digit bulan berpad | TEXT("2023-520","YYYY/MM")=2023/05 |
| M | Digit bulan ringkas | TEXT("2023-5-20","M")=5 |
| DD | Hari berpad | TEXT("2023-5-1","DD")=01 |
| D | Hari ringkas | TEXT("2023-5-1","D")=1 |
| DDDD | Hari minggu penuh | TEXT("2023-5-1","DDDD")=Monday |
| DDD | Hari minggu ringkas | TEXT("2023-5-1","DDD")=Mon |
| hh | Jam | TEXT("19:45","hh")=19 |
| mm | Minit | TEXT("19:45","hh:mm")=19:45 |
| ss | Saat | TEXT("19:45:30","ss")=30 |

### Sintaks

```text
TEXT(value, format_text)
```

- **value**: nombor atau tarikh yang hendak ditukar.
- **format\_text**: rentetan format.

### Contoh

#### Contoh 1: Format sebagai Mata Wang

[Field 1] dalam rekod pertama ialah **1234.567**.

```text
=TEXT([Field 1], "$#,##0.00")
```

Hasil: **\$1,234.57**.

#### Contoh 2: Format Tarikh

[Field 1] dalam rekod pertama ialah **2023-03-15**.

```text
=TEXT([Field 1], "mm/dd/yyyy")
```

Hasil: **03/15/2023**.

Dengan **TEXT**, tukar nombor atau tarikh kepada teks dengan format tertentu — sesuai untuk laporan, label, dan sebarang output yang memerlukan format khusus.

# Soalan Lazim

- **S**: Bagaimana saya boleh buang masa dan kekalkan hanya tarikh apabila sesuatu fungsi memulangkan yyyy-mm-dd hh:mm?

  **J**: Kaedah 1: gunakan TEXT(). Medan formula baharu: **TEXT([nilai sumber], "YYYY-MM-DD")**. Kaedah 2: dwiklik medan formula, tukar jenis medan kepada tarikh, dan pilih format tarikh yang dikehendaki.

- **S**: TEXT() memulangkan nilai yang kelihatan seperti nombor, tetapi fungsi lain memberikan ralat apabila menggunakannya. Kenapa?

  **J**: Output TEXT() adalah teks. Untuk menggunakannya dalam pengiraan berangka, bungkus dahulu dengan SUM() atau ABS() untuk menukarnya semula kepada nombor.
