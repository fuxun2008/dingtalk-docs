# 1 Asas

**TEXTJOIN** menggabungkan pelbagai rentetan teks menjadi satu. Berbeza dengan penggabungan mudah, **TEXTJOIN** membolehkan anda menetapkan pembatas dan secara pilihan melangkau sel kosong.

### Sintaks

```text
TEXTJOIN([delimiter], [ignore_empty], [text1], [text2])
```

**delimiter**: rentetan atau rujukan kepada rentetan yang sah — boleh dibiarkan kosong. Jika kosong, teks digabungkan secara terus.

**ignore\_empty**: nilai boolean. Jika TRUE, sel kosong dalam argumen teks akan dilangkau.

**text1**: sebarang teks — rentetan atau array rentetan daripada julat.

**text2**: teks tambahan.

### Contoh

Rekod tunggal (baris): Medan 1 = "Epal", Medan 2 = "Pisang", Medan 3 = kosong, Medan 4 = "Anggur".

#### Contoh 1: Langkau Kosong

```text
TEXTJOIN(", ", TRUE(), [Medan 1], [Medan 2], [Medan 3], [Medan 4])
```

Hasil: **Epal, Pisang, Anggur**

#### Contoh 2: Kekalkan Kosong

```text
TEXTJOIN(", ", FALSE(), [Medan 1], [Medan 2], [Medan 3], [Medan 4])
```

Hasil: **Epal, Pisang, , Anggur**

Dengan **TEXTJOIN**, gabungkan maklumat daripada pelbagai sumber menjadi satu rentetan yang mudah dibaca dan diproses — kawal pembatas dan pengendalian sel kosong.

# 2 Contoh Senario

### 2.1 Gabungkan Medan

Gabungkan [Nama] dan [Status] kedai menggunakan "-".

```text
TEXTJOIN("-",TRUE(),[Nama],[Status])
```
