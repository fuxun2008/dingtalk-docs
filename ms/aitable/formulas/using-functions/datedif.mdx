**DATEDIF** mengira perbezaan antara dua tarikh dalam AI Table — mengembalikan hasil dalam tahun, bulan, atau hari. Sesuai untuk senario yang memerlukan pengiraan tarikh yang tepat.

# 1 Asas

### Sintaks

```text
DATEDIF([start_date], [end_date], unit)
```

- **start\_date**: tarikh mula.
- **end\_date**: tarikh tamat.
- **unit**: unit masa untuk nilai pulangan:
  - **"Y"**: bilangan tahun penuh antara tarikh.
  - **"M"**: bilangan bulan penuh antara tarikh.
  - **"D"**: bilangan hari antara tarikh.
  - **"MD"**: abaikan tahun dan bulan — hari sahaja.
  - **"YM"**: abaikan tahun — bulan sahaja.
  - **"YD"**: abaikan tahun — hari sahaja.

### Contoh

Dua medan tarikh: [Tarikh mula], [Tarikh tamat].

#### Contoh 1: Bilangan tahun penuh antara dua tarikh

```text
=DATEDIF([Tarikh mula], [Tarikh tamat], "Y")
```

#### Contoh 2: Bilangan hari antara dua tarikh

```text
=DATEDIF([Tarikh mula], [Tarikh tamat], "D")
```

# 2 Contoh Senario

### 2.1 Masa Kitaran

Kira jurang masa antara [Dihantar pada] dan [Dilaksanakan pada] untuk menilai kelajuan tindak balas kedai.

```text
DATEDIF([Dihantar pada],[Dilaksanakan pada],"D")
```

### 2.2 Baki Hari

Kira bilangan hari antara [Tarikh semakan] dan hari ini untuk tujuan perancangan.

```excel formula
DATEDIF(TODAY(),[Tarikh semakan],"D")
```

# 3 Soalan Lazim

- **S**: DATEDIF memulangkan "#ERROR!" — apakah masalahnya?

  **J**: Semak sama ada tarikh tamat lebih awal daripada tarikh mula. Jika ya, pengiraan akan menghasilkan ralat atau nilai negatif.
