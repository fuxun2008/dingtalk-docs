## Format Paparan Formula

**Format paparan** menghidupkan data — menukar hasil formula kepada elemen visual seperti **bar kemajuan**, **penilaian**, **mata wang**.

Sebelum ini, hasil formula hanya boleh dipaparkan sebagai teks biasa atau nombor. Dengan format paparan, jadual kelihatan lebih menarik — dan akhirnya menyelesaikan masalah lama iaitu "bar kemajuan tidak dikemas kini secara automatik mengikut data".

### Tetapkan Format Paparan

Konfigurasikan semasa mencipta atau kemas kini medan formula sedia ada.

1. Klik header lajur medan formula untuk membuka panel konfigurasi.
2. Klik menu lungsur **Format paparan**.
3. Pilih gaya berdasarkan jenis data hasil (contohnya, **Kemajuan**).
4. Konfigurasikan parameter mengikut format (warna, format, dan sebagainya).
5. Klik Sahkan.

### Senario Utama dan Konfigurasi

#### 1. Bar Kemajuan Projek Kemas Kini Automatik

**Masalah**: dengan medan **Kemajuan** biasa, anda perlu menyeret peratusan secara manual. Apabila bilangan tugas berubah, bar tidak dikemas kini — kos penyelenggaraan tinggi.

**Penyelesaian**: kira kadar penyelesaian melalui formula, paparkan sebagai bar kemajuan.

- **Formula**: `[Pre-order Quantity] / [Target Quantity]`
- **Format**: pilih **Kemajuan**.
- **Parameter**: aktifkan **Julat kemajuan tersuai**, tetapkan permulaan kepada `0`, sasaran kepada `1` (= 100%).
- **Hasil**: apabila "tugas selesai" dikemas kini, bar bergerak secara automatik — tiada edit manual diperlukan.

#### 2. Penilaian Prestasi / Kepuasan

**Senario**: purata wajaran merentas dimensi (kemahiran, komunikasi, pengalaman) — dipaparkan sebagai bintang.

- **Formula**: `AVERAGE([Skills], [Communication], [Experience])`
- **Format**: pilih **Penilaian**.
- **Parameter**: nilai maksimum = 10.
- **Hasil**: dipaparkan sebagai ⭐ — mudah dibaca.

#### 3. Pemformatan Mata Wang

**Senario**: jumlah jualan dipaparkan sebagai `289710` — tanpa simbol, tanpa pemisah ribuan.

- **Formula**: `[Live price] * [Pre-sale qty]`
- **Format**: pilih **Mata wang**.
- **Parameter**: simbol `¥`, 2 tempat perpuluhan.
- **Hasil**: `¥ 289,710.00` — kemas untuk kegunaan kewangan.

### Format yang Disokong

Sistem menyediakan format berbeza berdasarkan jenis data output formula:

| Format | Jenis diperlukan | Contoh |
| --- | --- | --- |
| **Nombor** | nombor | `1,000.00` |
| **Mata wang** | nombor | `¥ 299.00` |
| **Tarikh** | tarikh / cap masa | `2026-01-22` |
| **Kemajuan** | nombor (biasanya 0-1 atau 0-100) | 80 |
| **Penilaian** | nombor | ⭐⭐⭐⭐⭐ |

### Nota

#### 1. Semakan Padanan Jenis

Bukan semua formula boleh menggunakan sebarang format. Jika output adalah teks (contohnya, `CONCATENATE("Name", "Address")`), memaksa format **Kemajuan** atau **Penilaian** akan menyebabkan ralat.

- **Mesej**: **Tidak dapat dikira. Sila tukar format.**
- **Penyelesaian**: tukar semula kepada **Lalai** atau **Teks**.

#### 2. Tukar kepada Jenis Medan Lain

Untuk membekukan data dan menghentikan pengiraan automatik, tukar jenis medan.

- Langkah: dwiklik header → **Jenis medan** → pilih **Nombor** atau jenis lain.
- **Risiko**: selepas penukaran, medan kehilangan fungsi pengiraan automatik — hanya nilai semasa kekal sebagai data statik.

### Soalan Lazim

- **S**: Mengapa medan formula saya tidak boleh memilih format **Kemajuan**?

  **J**: Semak sama ada output formula adalah **nombor**. Jika ia mengandungi gabungan teks (contohnya, `Text`), sistem menganggapnya sebagai teks — tidak boleh dipaparkan sebagai bar kemajuan.

- **S**: Bolehkah saya menyeret bar kemajuan yang dijana formula seperti bar biasa?

  **J**: Tidak. Nilai formula dikawal sepenuhnya oleh pengiraan — **edit manual tidak disokong**. Untuk kemajuan manual, gunakan medan Kemajuan biasa.

- **S**: Mengapa hasil tarikh daripada formula dipaparkan sebagai nombor panjang?

  **J**: Tarikh disimpan sebagai nombor cap masa. Dalam **Format paparan**, pilih **Tarikh** — ia akan ditukar kepada format yang mudah dibaca seperti "YYYY-MM-DD".
