---
title: "Pautkan Peti Mel Alibaba Cloud Sedia Ada"
description: "Ketahui cara Super Admin atau pencipta memautkan domain E-mel Syarikat Alibaba Cloud sedia ada ke DingTalk Mail melalui Admin Console atau aplikasi mudah alih DingTalk."
---

Pentadbir utama syarikat, atau pencipta, boleh memasukkan domain E-mel Syarikat Alibaba Cloud sedia ada untuk memautkan peti mel. Gunakan salah satu kaedah berikut.

## Admin Console

Admin Console > Workbench di bar sisi kiri > Urus Aplikasi > Mel > Masuk > Pautkan dan guna > masukkan domain mel > admin mengimbas Kod QR menggunakan DingTalk pada peranti mudah alih > pada peranti mudah alih, masukkan nama pengguna, kata laluan, pelayan mel masuk, pelayan mel keluar, dan maklumat lain > ketik Selesai untuk melengkapkan pautan.

## Mudah alih

Aplikasi mudah alih DingTalk > Lain-lain > Mel > ... di penjuru kanan atas > Tetapan > Tambah akaun e-mel peribadi lain > Peti mel syarikat sedia ada, Pautkan sekarang > masukkan domain E-mel Syarikat Alibaba Cloud > masukkan nama pengguna, kata laluan, pelayan mel masuk, pelayan mel keluar, dan maklumat lain > ketik Selesai untuk melengkapkan pautan.
