## Gambaran Keseluruhan Model

- Object model Pengguna standard

```text
{
"corpId":"ID organisasi",
"label":"Nama (ID Pekerja)",
"avatar":"URL Gambar Profil",
"key":"userid",
"businessWorkNo":"Akaun kerja"
}
```

- Object model Jabatan standard

```text
{
	"label":"Nama jabatan semasa",
	"key":"ID jabatan"
}
```

## UserBuilder

### Ungkapan

```text
UserBuilder(["userid","userid"]  |  ${memberComponent[{},{}]} )
```

<Warning>
Penerangan formula: Fungsi pembina Pengguna. Menjana koleksi model Pengguna yang sepadan dengan senarai userid atau komponen ahli yang diberikan.
</Warning>

### Parameter Input

```text
(["userid","userid"]  atau  ${memberComponent[{},{}]} )
```

### Nilai Pulangan

```text
[{object Pengguna},{object Pengguna}]
```

### Contoh

```text
UserBuilder(["some_userid_123"])

// Mengembalikan
[{user1}]
```

## DirectorBuilder

### Ungkapan

```text
DirectorBuilder( "" | "userid", level )
```

<Warning>
Penerangan formula: Fungsi pembina pengurus. Mengembalikan pengurus tahap ke-level bagi pengguna yang sedang log masuk atau bagi pengguna yang ditentukan. Parameter level mestilah >= 1. Mengembalikan koleksi model Pengguna bagi pengurus yang sepadan; berbilang pengurus akan dikembalikan jika pengguna tersebut tergolong dalam berbilang jabatan.
</Warning>

### Parameter Input

- Parameter 1: userid yang mengenal pasti pengguna sasaran. Hantar "" untuk menggunakan pengguna yang sedang log masuk.
- Parameter 2: level. Mengembalikan pengurus tahap ke-level. Hanya sah apabila level >= 1.

### Nilai Pulangan

- Object model Pengguna standard bagi pengurus: [\{object Pengguna},\{object Pengguna}]

### Contoh

```text
DirectorBuilder("",2)

// Mengembalikan
[{user1},{user2}]
```

## DeptBuilder

### Ungkapan

```text
DeptBuilder(tiada parameter | userid | komponen ahli pilihan tunggal)
```

<Warning>
Penerangan formula: Fungsi pembina Jabatan. Mendapatkan object model Jabatan yang ditentukan berdasarkan syarat input. Formula ini tidak menyokong subform.
</Warning>

### Parameter Input

Parameter 1 (tiga mod):

- Tiada parameter: jabatan langsung bagi pengguna yang sedang log masuk.
- userid: jabatan langsung bagi ID pengguna yang ditentukan.
- Komponen ahli pilihan tunggal: jabatan langsung bagi pengguna yang dirujuk oleh komponen ahli tersebut.

### Nilai Pulangan

- Object model Jabatan standard: [object Jabatan, object Jabatan]. Seorang pengguna boleh tergolong dalam berbilang jabatan pada masa yang sama.

### Contoh

```text
DeptBuilder("")
// Mengembalikan
[{dept},{user2}]
```

## GetObjectField

### Ungkapan

```text
GetObjectField(model object JSON standard, "fieldKey")
```

<Warning>
Penerangan formula: GetObjectField **ialah fungsi utiliti. JsonObject ialah format storan object standard serba guna yang menyusun data secara dalaman menggunakan struktur key:value. GetObjectField mengembalikan nilai bagi key yang ditentukan daripada object JSON standard yang diberikan.**

**Nota: Tidak disokong di dalam subform.**
</Warning>

### Parameter Input

- Parameter 1: JsonObject standard yang hendak dibaca.
- Parameter 2: fieldKey. Key atribut peringkat pertama bagi object dalam parameter 1.

### Nilai Pulangan

- Nilai yang sepadan dengan key atribut object tersebut. Jenis lalai ialah Teks.

### Contoh

```text
GetObjectField( GetArrayItem(UserBuilder(memberComponent), 1) ,"label")

// Contoh data komponen ahli:
[{"label":"John (ID Pekerja 11)","key":"userid123"},{"label":"Mary (ID Pekerja 22)","key":"userid124"}]

// Mengembalikan

"John (ID Pekerja 11)"
```

## GetArrayItem

### Ungkapan

```text
GetArrayItem(jenis JsonArray standard, n)
```

<Warning>
Penerangan formula: GetArrayItem **ialah fungsi utiliti. JsonArray ialah format storan koleksi array standard serba guna di mana setiap unit adalah JsonObject atau JsonArray standard. GetArrayItem mengembalikan unit data ke-n (sama ada JsonObject atau JsonArray) daripada JsonArray standard yang diberikan.** n >= 1, di mana n = 1 merujuk kepada unit data pertama.
</Warning>

### Parameter Input

- Parameter 1: Jenis JsonArray standard.
- Parameter 2: n. Mengembalikan object unit data ke-n dalam array tersebut.

### Nilai Pulangan

- Unit data ke-n dalam parameter 1. Jenisnya boleh jadi JsonObject atau JsonArray.

### Contoh

```text
GetArrayItem(memberComponent, 1)
```

<Note>
Contoh data komponen ahli:

[\{"label":"John (ID Pekerja 11)","key":"userid123"},\{"label":"Mary (ID Pekerja 22)","key":"userid124"}]
</Note>

### Pulangan

```text
""
{"label":"John (ID Pekerja 11)","key":"userid123"}
```
