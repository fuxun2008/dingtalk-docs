Artikel ini menyenaraikan semua fungsi matematik dalam YiDA, berserta senario penggunaan lazimnya.

## Gambaran Keseluruhan Fungsi

| **Nama fungsi** | **Penerangan** |
|---|---|
| [COUNT](/ms/yida/form/ygcgwobc4tewnmxr) | Mengira jumlah bilangan rekod data yang dihantar untuk Borang yang ditentukan. |
| [ADD](/ms/yida/form/chzvqqza7lig19gk) | Mengira jumlah nilai bagi beberapa Medan. |
| [AVERAGE](/ms/yida/form/cmntz03rxr7lvg8i) | Memulangkan min aritmetik bagi satu set nilai Numerik. |
| [MAX](/ms/yida/form/hrmegrov95qkft01) | Memulangkan nilai maksimum dalam satu set nombor. |
| [MIN](/ms/yida/form/tzmz5prxfk1m6ooo) | Memulangkan nilai minimum dalam satu set nombor. |
| [ABS](/ms/yida/form/nqxuge2x337g5r7u) | Memulangkan nilai mutlak bagi suatu nombor apabila ia negatif. |
| [ROUND](/ms/yida/form/gzx4fgcgya1g7dzv) | Membundarkan nombor kepada bilangan tempat perpuluhan yang ditentukan. |
| [CEILING](/ms/yida/form/pfdukipqlw5rko8s) | Membundarkan nombor parameter ke atas (menjauhi sifar) kepada gandaan terdekat bagi asas yang ditentukan. |
| [FLOOR](/ms/yida/form/gkzdswxg4g18443y) | Membundarkan nombor parameter ke bawah (menghampiri sifar) kepada gandaan kesignifikanan terdekat. |
| [INT](/ms/yida/form/qht3on9d40988egd) | Membundarkan nombor ke bawah kepada integer terdekat. |
| [LOG](/ms/yida/form/bunl3zq1z68guymc) | Memulangkan logaritma bagi suatu nombor kepada asas yang ditentukan. |
| [MOD](/ms/yida/form/smcm971lepq2nv6o) | Memulangkan baki daripada pembahagian dua Komponen Numerik. |
| [POWER](/ms/yida/form/biskll33337npp7d) | Mengira hasil bagi Komponen Numerik yang dikuasakan. |
| [FIXED](/ms/yida/form/an1t8blpsi4aue68) | Membundarkan nombor kepada bilangan tempat perpuluhan yang ditentukan, memformatkannya dalam tatatanda perpuluhan, dan memulangkan hasilnya sebagai nombor. |
| [SQRT](/ms/yida/form/ngysm1kw31gkmbqh) | Memulangkan punca kuasa dua positif bagi nilai Komponen Numerik. |
| [SUM](/ms/yida/form/ab2ef6nzxozn0xfe) | Menambah semua nombor yang dihantar sebagai parameter dan memulangkan jumlahnya. |
| [PRODUCT](/ms/yida/form/wu3xhb5ve6v0tvci) | Memulangkan hasil bertaip float ketepatan berganda. |
| [SUMPRODUCT](/ms/yida/form/zrgy7twy6d9ry6ey) | Mendarab elemen yang berkaitan dalam tatasusunan yang diberikan dan memulangkan jumlah hasil darab tersebut. |
| [LARGE](/ms/yida/form/rnyume8c4kkywdpg) | Memulangkan nilai terbesar ke-k dalam satu set data. |
| [SMALL](/ms/yida/form/kruy97m10v8mt3mt) | Memulangkan nilai terkecil ke-k dalam satu set data. |

## Senario Lazim

### Kira Jumlah Amaun Merentasi Beberapa Item Garisan

- Dalam senario tuntutan bayaran balik pembelian, pelbagai kategori sering dituntut bersama-sama. Untuk mengira jumlah amaun merentasi semua item Garisan, ikuti langkah berikut:

<Frame>
  ![](https://gw.alicdn.com/imgextra/i3/O1CN01GIOe5rjSSjL3iUV8_!!6000000006415-2-tps-1831-859.png)
</Frame>

(1) Tambah Komponen subborang pada Borang (Dikonfigurasi dengan harga seunit, kuantiti, dan amaun), dan Tambah Komponen Numerik atau Teks satu baris di luar subborang.

<Frame>
  ![](https://gw.alicdn.com/imgextra/i2/O1CN01QzPuro99myD3hU4C_!!6000000006335-2-tps-1823-869.png)
</Frame>

(2) Dalam Komponen amaun di dalam subborang, Konfigurasikan `Subborang.Harga seunit * Subborang.Kuantiti`. Kemudian, dalam Komponen Numerik atau Teks satu baris di luar subborang, Konfigurasikan `SUM(Subborang.Amaun)`.

<Frame>
  ![](https://gw.alicdn.com/imgextra/i1/O1CN01XTfDGU3LNrC3i75d_!!6000000002461-2-tps-1828-869.png)
</Frame>

Hasilnya ditunjukkan dalam animasi di bawah.
