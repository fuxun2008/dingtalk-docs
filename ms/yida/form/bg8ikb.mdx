<Warning>
Edisi berbayar bagi halaman pengurusan data menyokong carian sehingga 30,000 rekod **(pelan Percuma hanya menyokong carian sehingga 5,000 rekod; lihat** **prasyarat naik taraf****)**. Jika had ini melebihi, satu ralat akan dipaparkan. Gunakan komponen Filter untuk mengecilkan skop carian.
</Warning>

## 1. Gambaran Keseluruhan Halaman Pengurusan Data

Halaman pengurusan data memaparkan semua rekod borang yang telah dihantar dan menyediakan ciri-ciri seperti import/sejarah import, eksport/sejarah eksport, sejarah edit, muat turun fail/sejarah muat turun, cetak/sejarah cetak, Tambah, Lain-lain (edit data, padam), cari, filter, tetapan lajur paparan, susun, muat semula, dan skrin penuh.

## 2. Gambaran Keseluruhan Ciri

**Laluan**: Aplikasi Saya >> klik satu aplikasi >> Borang/Borang aliran kerja >> Pengurusan data

| **Ciri** | **Penerangan** |
|---|---|
| [**Eksport/Sejarah eksport**](/yida/form/vz0ebe) | Eksport rekod yang memenuhi kriteria pertanyaan ke fail Excel. Anda boleh melihat rekod yang pernah dieksport dalam sejarah eksport. |
| [**Import/Sejarah import**](/yida/form/andrke) | Hantar rekod borang secara pukal untuk membantu penghantar menghantar pelbagai rekod borang dengan cepat. Lihat rekod yang diimport dalam sejarah import. |
| **Muat turun fail/Sejarah muat turun** | Pilih pelbagai rekod untuk memuat turun fail mereka, dan lihat rekod fail yang pernah dimuat turun dalam sejarah muat turun.<br />**Nota**: Jika lampiran terlalu besar, muat turun pukal akan dipecahkan kepada pakej sebanyak 200 MB setiap satu. |
| [**Edit data/Sejarah edit**](/yida/form/ne8htk) | Edit rekod secara pukal pada halaman pengurusan data borang. Hanya Admin boleh menggunakan ciri ini. Anda boleh melihat data sebelum dan selepas diedit dalam sejarah edit. |
| [**Padam**](/yida/form/fxxris) | Padam rekod secara pukal pada halaman pengurusan data borang. Hanya Admin boleh menggunakan ciri ini. |
| [**Cetak/Sejarah cetak**](/yida/form/nmrhfo) | Jana fail cetakan untuk rekod yang dipilih berdasarkan templat cetakan dan muat turun sebagai satu pakej. Anda juga boleh melihat sejarah cetakan. |
| **Susun** | Apabila terdapat banyak rekod, susun mengikut susunan menaik atau menurun berdasarkan medan tertentu. Komponen yang disokong: Teks satu baris, Teks pelbagai baris, Numerik, Pilih, Penilaian, dan Tarikh. |
| [**Filter**](/yida/form/if3mza) | Tetapkan syarat penapisan pada medan yang berbeza untuk menapis dan melihat rekod. |
| [**Lajur paparan**](/yida/form/lzqqf6) | Pilih medan untuk mengkonfigurasikan kandungan yang dipaparkan bagi rekod. |
| **Muat Semula** | Kemas kini paparan dengan cepat selepas mengimport data. |

### 2.1 Rekod Sumber

#### 2.1.1 Salin

Borang biasa menyediakan ciri salin pantas untuk butiran rekod tanpa memerlukan konfigurasi tambahan. Cuma buka halaman butiran rekod untuk menggunakannya. Bagi borang aliran kerja, aktifkan butang **Salin aliran kerja** dalam Tetapan Asas.

**Nota:**

- Ciri ini tidak disokong dalam aplikasi 1.0 atau 2.0.
- Ia tersedia dalam semua edisi YiDA.
- Medan yang dikonfigurasikan sebagai tersembunyi, dinyahaktifkan, atau baca sahaja tidak akan disalin.

<Accordion id="q2" title="3.2 Mengapakah subborang boleh dikembangkan pada sesetengah halaman pengurusan data borang?">
  Storan baharu mengembangkan komponen subborang secara lalai, manakala storan lama tidak memuatkannya secara lalai. Oleh itu, butang Kembangkan subborang dikekalkan untuk storan lama.
</Accordion>
<Accordion id="q3" title="3.3 Mengapakah hasil carian global tidak tepat?">
  Jika aplikasi semasa menggunakan storan lama, hasil carian global mungkin tidak tepat. Untuk butiran lanjut tentang penambahbaikan keupayaan carian, lihat **nota naik taraf**.
