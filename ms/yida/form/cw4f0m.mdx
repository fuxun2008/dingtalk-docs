## 1. Kes Penggunaan

Komponen Pelajar digunakan dalam senario kampus K12 di mana pelajar perlu dipilih, seperti anugerah pengiktirafan pelajar atau statistik markah pelajar.

## 2. Ciri Asas

### 1.2.1 Mod Pilih Banyak

Mod ini menyokong pemilihan berbilang pelajar. Jika anda hanya perlu memilih seorang pelajar, matikan pilihan ini.

### 1.2.2 Auto-Isi Data

Auto-isi data mengisi data asas pelajar yang diselenggara dalam aplikasi Profil Pelajar sekolah ke dalam komponen aplikasi YiDA, dan secara automatik menjana data borang.

- Ciri ini hanya tersedia apabila komponen Pelajar berada dalam mod pilih tunggal. Auto-isi data tidak disokong dalam mod Pilih Banyak.
- Maklumat atribut pelajar boleh diisi ke dalam medan sedia ada atau medan baharu pada borang.

- Buat masa ini, maklumat kad pengenalan yang diselenggara dalam Profil Pelajar tidak boleh digunakan untuk auto-isi data.

## 3. Sumber Data

Komponen ini menggunakan data induk ID pelajar dan nama daripada Kenalan Sekolah.

## 4. Skop Pengguna yang Boleh Dipilih

| **Peranan** | **Skop yang boleh dipilih** |
|---|---|
| Admin / Sub Admin | Semua maklumat pelajar |
| Guru kelas / Guru | Semua maklumat pelajar |
| Ibu bapa | Maklumat pelajar yang berkaitan dalam Kenalan Sekolah |
