## 1. Senario Yang Sesuai

Gunakan Komponen Tarikh apabila pengguna perlu memilih tarikh atau masa, seperti rekod kerja lebih masa atau perjalanan perniagaan. Komponen Tarikh sentiasa menggunakan masa tempatan.

[Maklumat asas Komponen](/ms/yida/form/snftao)

<Note>
Untuk Atribut, penggunaan dan Contoh Komponen, sila rujuk [**rujukan antara muka**](/ms/open/yida/components/interface).
</Note>

## 2. Ciri Asas

Anda boleh Konfigurasikan nilai lalai tarikh, Format tarikh, kosongkan dengan satu klik, julat tarikh, dan julat Tersuai Premium.

### 2.1 Tetapkan Masa Tetap dan Format Tarikh

#### 2.1.1 Nilai Lalai (Masa Tetap)

Komponen Tarikh menyokong nilai lalai. Selepas ditetapkan, nilai lalai akan dipaparkan apabila Borang dibuka. Anda masih boleh Pilih tarikh lain secara manual.

**Laluan**: Komponen >> Atribut >> Lalai

**Nota**: Nilai lalai disimpan sebagai "YYYY-MM-DD", tetapi nilai yang dipaparkan dalam Komponen mengikut Format yang anda Konfigurasikan.

Contoh:

### 2.2 Julat Masa Boleh Pilih

Anda boleh mengehadkan julat masa boleh Pilih, yang berguna untuk senario seperti permohonan cuti dan kerja lebih masa.

#### 2.2.1 Contoh Senario Julat Masa

Untuk mengehadkan pengguna supaya hanya boleh memohon cuti dari hari ini dan seterusnya, Tetapkan julat masa kepada "Boleh Pilih dari hari ini dan seterusnya (termasuk hari ini)". Tarikh sebelum hari ini akan dipaparkan berwarna kelabu dan tidak boleh dipilih. Julat lain berfungsi dengan cara yang sama.

### 3.6 Melaksanakan Jam dengan Saat Berdetik

Anda boleh menggunakan JavaScript untuk membina ini. Tambah Komponen Tarikh pada Borang, kemudian Salin kod berikut ke dalam kaedah `didMount()` supaya ia dimuatkan secara Lalai.

Nota: Pengecam Unik di bawah mesti sepadan dengan Pengecam Unik Komponen Tarikh.

<Frame>
  ![](https://gw.alicdn.com/imgextra/i3/O1CN01uPHxL3yzJWI3sBSs_!!6000000001234-2-tps-1908-886.png)
</Frame>

```javascript
 setInterval( function(){
var dt = new Date();
var y = dt.getFullYear();
var M = dt.getMonth()+ 1;
var d = dt.getDate();
var h = dt.getHours();
var m = dt.getMinutes();
var s = dt.getSeconds();
//alert("Current time: " + y + "-"+M+"-"+d +" "+ h + ":" + m + ":" + s);
 document.getElementById( "uniqueIdentifier").innerHTML = "Current time: " + y + "-" + M + "-" + d + " " + h + ":" + m + ":" + s
 }, 1000);
```
