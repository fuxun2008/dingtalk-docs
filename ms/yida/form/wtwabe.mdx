## 1. Gambaran Keseluruhan

### 1.1 Gambaran Keseluruhan Ciri

Borang ialah alat asas dalam YiDA. Semua pengumpulan dan kemasukan data bergantung pada borang, yang berfungsi sebagai sumber data.

YiDA menawarkan dua jenis borang:

**Borang biasa**: Mengumpul semua data yang dihasilkan semasa operasi perniagaan. Data yang dikumpul boleh dikongsi dengan pelbagai kolaborator yang berbeza. Anda boleh [menerbitkan](/yida/form/ulqab1) Kebenaran Data kepada ahli dalaman yang perlu mengurus data tersebut, atau kepada ahli luaran untuk pengumpulan data luaran.

**Borang aliran kerja**: Membolehkan data mengalir dari bawah ke atas melalui pelbagai peringkat kelulusan. Kebenaran juga boleh ditetapkan untuk mengurus data aliran kerja dengan lebih lanjut.

Perbezaan utama antara borang biasa dan borang aliran kerja ialah borang aliran kerja memerlukan kelulusan langkah demi langkah serta konfigurasi aliran kerja.

### 1.2 Senario Penggunaan

- Borang biasa: tinjauan dan statistik, pendaftaran dalam talian, laporan jualan, tempahan mesyuarat, penerimaan perolehan, kemasukan pesanan, daftar masuk Kod QR, dan banyak lagi.
- Borang aliran kerja: kelulusan perbelanjaan, laporan kerja, penghantaran tugas, permohonan cuti pekerja, permintaan barang, permintaan pembaikan, pengumpulan Maklum Balas, dan banyak lagi.

### 1.3 Ketersediaan

Borang ialah ciri YiDA Percuma dan tersedia untuk pengguna pada semua pelan.

Pengguna pelan Percuma dihadkan kepada 20,000 rekod data dan storan lampiran sebanyak 20 GB. Untuk maklumat lanjut, lihat dasar harga YiDA.

## 2. Cara Mencipta Borang

Selepas mencipta aplikasi YiDA, anda boleh mencipta borang biasa atau borang aliran kerja melalui cara berikut:

Kaedah 1: Buka aplikasi yang baru dicipta, pergi ke Urus Halaman, dan pilih Cipta borang atau Cipta borang aliran kerja.

## 3. Persediaan Borang

Selepas mencipta borang, anda boleh mula mengkonfigurasikannya. Persediaan untuk borang aliran kerja dan borang biasa sedikit berbeza — borang aliran kerja memerlukan langkah Reka bentuk aliran kerja tambahan.

(1) Borang biasa

<Frame>
  ![](https://gw.alicdn.com/imgextra/i3/O1CN01aYBq466EJNK3icJK_!!6000000006124-2-tps-1832-878.png)
</Frame>

Langkah persediaan: Buka reka bentuk borang >> Pilih Komponen yang ingin anda gunakan >> Simpan.

(2) Borang aliran kerja

<Frame>
  ![](https://gw.alicdn.com/imgextra/i1/O1CN01lnG24HJLXuK3iMhV_!!6000000006715-2-tps-1830-875.png)
</Frame>

Langkah persediaan: Buka Tetapan borang >> Pilih Komponen yang ingin anda gunakan >> Simpan >> Reka bentuk aliran kerja >> Konfigurasikan Langkah seperti penyokong, pelaksana, dan penerima CC >> Simpan >> Terbitkan aliran kerja.

<Frame>
  ![](https://gw.alicdn.com/imgextra/i2/O1CN01TQBeHGDvkmH3iziy_!!6000000003489-2-tps-1835-877.png)
</Frame>

Selepas melengkapkan langkah-langkah di atas, terbitkan aplikasi supaya ahli boleh mengakses borang dan memasukkan data. Admin boleh melihat data yang dihantar dalam Urus data.

### 3.1 Reka Bentuk Borang

Halaman reka bentuk borang dibahagikan kepada tiga bahagian, seperti ditunjukkan di bawah:

<Frame>
  ![](https://gw.alicdn.com/imgextra/i4/O1CN01x6FfjZ57VKE3ik7F_!!6000000004597-2-tps-1833-880.png)
</Frame>

Pemilihan Komponen: pilih Komponen. Komponen yang berbeza menyimpan jenis data yang berbeza.

Area kanvas: susun atur dan susunan Komponen.

Atribut Komponen: konfigurasikan atribut untuk Komponen individu dan untuk borang secara keseluruhan.

### 3.2 Reka Bentuk Aliran Kerja

Reka bentuk aliran kerja hanya terpakai untuk borang aliran kerja. Borang biasa tidak memerlukan langkah ini.

<Frame>
  ![](https://gw.alicdn.com/imgextra/i4/O1CN010wuNcMrO8GJ3izj1_!!6000000003405-2-tps-1835-880.png)
</Frame>

Pemilihan jenis Langkah: pilih penyokong, pelaksana, atau Langkah penerima CC berdasarkan senario anda.

<Frame>
  ![](https://gw.alicdn.com/imgextra/i4/O1CN01jFGgrDKEHWJ3j7Wx_!!6000000002545-2-tps-1836-883.png)
</Frame>

Konfigurasi pengguna Langkah dan Kebenaran: konfigurasikan peraturan pengguna untuk penyokong, pelaksana, dan penerima CC, serta Kebenaran medan dan Kebenaran kelulusan.

### 3.3 Simpan Borang

Bagi kedua-dua borang biasa dan borang aliran kerja, selepas mengkonfigurasikan Komponen dalam reka bentuk borang, klik Simpan di sudut kanan atas untuk selesai mencipta borang.

<Frame>
  ![](https://gw.alicdn.com/imgextra/i1/O1CN01YVZiebSiyOB3jFKj_!!6000000006964-2-tps-1837-876.png)
</Frame>

### 3.4 Terbitkan Aliran Kerja

Borang aliran kerja mengandungi Langkah Lalai di mana pemohon ditetapkan sebagai penyokong. Ini mengelakkan aliran kerja daripada tergendala sekiranya Admin terlupa mengkonfigurasikan Langkah. Anda boleh menyesuaikan Langkah mengikut keperluan. Selepas menyesuaikan Langkah, klik Terbitkan pada halaman aliran kerja supaya perubahan berkuat kuasa.

<Warning>
Nota: Langkah aliran kerja yang baru diterbitkan hanya terpakai untuk data yang dihantar selepas penerbitan. Data yang dihantar sebelum ini akan terus mengikut peraturan aliran kerja yang terdahulu.
</Warning>

<Frame>
  ![](https://gw.alicdn.com/imgextra/i4/O1CN01UC0Y8OnkeIB3izix_!!6000000000365-2-tps-1835-876.png)
</Frame>

## 4. Urus Data

Selepas pekerja menghantar data melalui borang, Admin yang mempunyai kebenaran Urus Aplikasi boleh Import, Eksport, Edit, Padam, Paparan, dan Cetak data yang dihantar dalam Urus data. Kini terdapat dua titik masuk ke Urus data:

Entri 1: Buka borang atau borang aliran kerja >> Edit borang atau borang aliran kerja >> Urus data.

<Frame>
  ![](https://gw.alicdn.com/imgextra/i1/O1CN01JremgILUCwI3izit_!!6000000001964-2-tps-1835-872.png)
