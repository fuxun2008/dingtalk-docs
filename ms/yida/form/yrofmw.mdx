## 1. Kes Penggunaan

Kadangkala data borang mentah perlu diproses dengan logik tersuai sebelum dapat dipaparkan.

Contohnya:

- Data borang dihantar oleh setiap pekerja secara individu, tetapi laporan perlu menunjukkan bilangan pekerja yang menghantar borang setiap hari. Ini memerlukan fungsi COUNT() untuk mengira hasil sebelum dipaparkan.
- Pengguna ingin menambah medan tersuai pada borang dan menghubungkannya dengan pautan hiperteks untuk navigasi halaman. Senario ini juga sesuai menggunakan medan formula tersuai.

Untuk memenuhi keperluan ini, kaji dahulu formula yang disediakan YiDA untuk laporan. Formula ini terbahagi kepada kategori berikut:

- Logik
- Pemprosesan string
- Agregat
- Array

## 4. Logik

### CASEWHEN

**Penggunaan 1**: CASEWHEN(\<syarat>,\<nilai>,\<syarat>,\<nilai>.....), setara dengan sintaks CASE WHEN dalam SQL.

**Contoh**: CASEWHEN(\<Medan Jantina>="Lelaki","lelaki",\<Medan Jantina>="Perempuan","perempuan"). Nilai "Lelaki" digantikan dengan "lelaki", dan nilai "Perempuan" digantikan dengan "perempuan".

**Penggunaan 2**: CASEWHEN(\<syarat>,\<nilai>,\<syarat>,\<nilai>.....\<nilai>), setara dengan sintaks CASE WHEN dalam SQL.

**Contoh**: CASEWHEN(\<Medan Jantina>="Lelaki","lelaki","perempuan"). Nilai "Lelaki" digantikan dengan "lelaki", dan sebarang nilai lain digantikan dengan "perempuan".

## 5. Pemprosesan String

### LEN

**Penggunaan**: LEN([Medan string]). Mengembalikan panjang string.

**Contoh**: LEN("ujian") mengembalikan 5. LEN("测试") mengembalikan 2, kerana setiap aksara Cina dikira sebagai satu aksara, sama seperti aksara Inggeris.

### LEFT

**Penggunaan**: LEFT(\<Medan ukuran>,\< n >). Mengembalikan string sepanjang n aksara bermula daripada aksara pertama di sebelah kiri nilai \<medan>.

**Contoh**: LEFT(Medan1,3). Jika Medan1 ialah "ABCDEF", nilai yang dikembalikan ialah "ABC".

### RIGHT

**Penggunaan**: RIGHT(\<Medan ukuran>,\< n >). Mengembalikan string sepanjang n aksara dikira daripada sebelah kanan nilai \<medan>.

**Contoh**: RIGHT(Medan1,3) mengembalikan "DEF" apabila Medan1 ialah "ABCDEF".

### MID

**Penggunaan**: MID(\<Medan ukuran>, \< mula >, \< n >). Mengembalikan string sepanjang n aksara bermula daripada aksara ke-mula di sebelah kiri nilai \<medan>.

**Contoh**: MID(Medan1, 3, 3) mengembalikan "CDE" apabila Medan1 ialah "ABCDEF".

### POS

**Penggunaan**: POS(\<Medan ukuran>,\<Substring>). Mengembalikan kedudukan \<substring> dalam \<teks>. Mengembalikan 0 jika tiada padanan ditemui.

**Contoh**: POS(Medan1,"DE") mengembalikan 4 apabila Medan1 ialah "ABCDEF".

### UPPER

**Penggunaan**: UPPER(\<Medan ukuran>). Menukar nilai \<medan> kepada huruf besar.

**Contoh**: UPPER(Medan1) mengembalikan "ABCDEF" apabila Medan1 ialah "AbcdeF".

### LOWER

**Penggunaan**: LOWER(\<Medan ukuran>). Menukar nilai \<medan> kepada huruf kecil.

**Contoh**: LOWER(Medan1) mengembalikan "abcdef" apabila Medan1 ialah "AbcdeF".

### VAL

**Penggunaan**: VAL(\<Medan ukuran>). Menukar nilai \<medan> daripada jenis teks kepada jenis numerik.

**Contoh**: VAL(Medan1) mengembalikan 123 apabila Medan1 ialah "123".

### LEFTTRIM

**Penggunaan**: LEFTTRIM(\<Medan ukuran>). Membuang ruang kosong di hadapan nilai \<medan>.

**Contoh**: LEFTTRIM(Medan1) mengembalikan "ABC" apabila Medan1 ialah "  ABC".

### RIGHTTRIM

**Penggunaan**: RIGHTTRIM(\<Medan ukuran>). Membuang ruang kosong di belakang nilai \<medan>.

**Contoh**: RIGTTRIM(Medan1) mengembalikan "ABC" apabila Medan1 ialah "ABC  ".

### NUMBERTOSTRING

**Penggunaan**: NUMBERTOSTRING(\<Numerik>). Menukar data numerik kepada string.

**Contoh**: NUMBERTOSTRING(Medan1) mengembalikan "12345" apabila Medan1 ialah "12345 ".

### SPLITPART

**Penggunaan**: SPLITPART(\<Medan string>, pembatas, kedudukan substring). Membahagikan string mengikut "pembatas" kepada N substring (N bersamaan bilangan pembatas ditambah 1). Kedudukan substring dikira bermula daripada 1 (kiri ke kanan) atau daripada -1 (kanan ke kiri).

**Contoh**: SPLITPART(\<Medan1>,A,2) mengembalikan "BCD" apabila Medan1 ialah "ABCDABHABC". Menetapkan kedudukan substring kepada -5 turut mengembalikan "BCD".

### CONCAT

**Penggunaan**: CONCAT(\<medan>,\<medan>,.....). Menggabungkan beberapa medan menjadi satu string. Parameter input mestilah medan jenis string.

**Contoh**: CONCAT(\<Medan1>,\<Medan2>) mengembalikan "ABCD" apabila Medan1 ialah "A" dan Medan2 ialah "BCD".

### REPLACE

**Penggunaan**: REPLACE([string], [string carian], [string ganti]). Mengembalikan string yang telah digantikan.

**Contoh**: REPLACE([Medan1], [Medan2], [Medan3]) mengembalikan "a12345efg" apabila Medan1 ialah "abcdefg", Medan2 ialah "bcd", dan Medan3 ialah "12345".

### STRINGTONUMBER

Formula laporan pemprosesan string baharu `STRINGTONUMBER()` menukar nombor jenis teks kepada jenis numerik.

Formula ini kini hanya disokong pada halaman laporan. Gunakannya seperti berikut:

```javascript
// Medan mestilah nombor jenis teks.
STRINGTONUMBER(<Medan>)
```

## 7. Tarikh dan Masa

### NOW

**Penggunaan**: NOW(). Mengembalikan masa semasa, tepat hingga ke saat.

**Contoh**: Diabaikan.

### STRINGTODATE

**Penggunaan**: STRINGTODATE(\<medan>,\<format>). Menukar string kepada nilai tarikh/masa.

**Contoh**: STRINGTODATE("1989-09-27","yyyy-MM") mengembalikan "198909".

Format bagi kedua-dua fungsi di atas mengikut konvensyen pemformatan Java. Jenis format yang disokong ialah:

yyyy: Tahun

MM: Bulan

dd: Hari

hh: Jam 12 jam (1-12)

HH: Jam 24 jam (0-23)

mm: Minit

ss: Saat

### DATEADD

**Penggunaan**: `DATEADD(<Medan tarikh>,<offset>,<unit masa>)`. Menambah \<offset> mengikut **\<unit masa>** yang ditentukan pada \<medan tarikh>.

- Nilai unit masa:

- Offset ialah nombor tertentu untuk ditambah atau ditolak. Nilai positif menambah; nilai negatif menolak.

**Contoh 1:**

Jika nilai komponen tarikh dalam borang ialah "20200901", maka `DATEADD(Komponen tarikh,10,"DAY") = 20200911`.

**Contoh 2:**

Jika nilai komponen tarikh dalam borang ialah "20200901", maka `DATEADD(Komponen tarikh,-1,"DAY") = 20200831`.

<Note>
Format paparan tarikh lalai ialah `yyyyMMdd`. Untuk menukar format paparan tarikh, rujuk contoh dalam [**Fungsi DATEFORMAT**](/ms/yida/form/yrofmw).
</Note>

### DATEDIFF

**Penggunaan**: DATEDIFF(\<Medan masa 1>,\<Medan masa 2>,\<unit masa>). Mengembalikan perbezaan antara medan masa 1 dan medan masa 2 mengikut unit masa yang ditentukan.

Pilihan unit masa:

- YEAR       Tahun
- MONTH    Bulan
- DAY        Hari
- HOUR      Jam
- MINUTE   Minit
- SECOND  Saat

**Contoh**: DATEDIFF(Komponen tarikh 1, Komponen tarikh 2, "DAY"). Mengembalikan bilangan hari antara kedua-dua komponen tarikh.

**Nota: Parameter hanya menyokong komponen tarikh. Nilai tarikh tetap tidak boleh dimasukkan terus dalam formula.**

Jika nilai tarikh dalam komponen tarikh pada borang ialah "2020-02-14" dan hari ini ialah "2020-02-16", maka

DATEDIFF(NOW(), Tarikh penghantaran, "DAY") = 2

DATEDIFF(Tarikh penghantaran, NOW(), "DAY") = -2

### DATEFORMAT

**Penggunaan**: DATEFORMAT(\<Medan tarikh>,\<format masa>). Memformat tarikh menjadi string.

Format bagi kedua-dua fungsi di atas mengikut konvensyen pemformatan Java. Jenis format yang disokong ialah:

- yyyy: Tahun
- MM: Bulan
- dd: Hari
- hh: Jam 12 jam (1-12)
- HH: Jam 24 jam (0-23)
- mm: Minit
- ss: Saat

**Contoh 1:**

DATEFORMAT(\<Medan tarikh>,"yyyy-MM-dd"). Jika nilai medan tarikh ialah 4 Ogos 1989, nilai yang dikembalikan ialah 1989-08-04. Anda juga boleh menukar pembatas "-" kepada "/" atau aksara lain.

**Contoh 2:**

DATEFORMAT(\<Medan tarikh>,"yyyy-MM-dd HH:mm:ss"). Jika nilai medan tarikh ialah 1:30 PM pada 1 September 2020, nilai yang dikembalikan ialah 2020-09-01 13:30:00. Anda juga boleh menukar pembatas "-" dan ":" kepada "/", "年", "月", "日", atau aksara lain.

### FROMUNIXTIME

**Penggunaan**: Menukar nilai masa Unix berbentuk numerik kepada nilai tarikh.

Pengisytiharan fungsi:

```sql
datetime fromunixtime(bigint unixtime)
```

Penerangan parameter:

- unixtime: Jenis Bigint, dalam saat, nilai tarikh/masa berformat Unix. Jika input berjenis string, double, atau decimal, ia akan ditukar secara tersirat kepada bigint sebelum pengiraan.
- Nilai kembali: Nilai tarikh jenis Datetime. Mengembalikan NULL apabila unixtime ialah NULL.

Contoh:

```sql
fromunixtime(123456789) = 1973-11-30 05:33:09
```

### WEEK

**Penggunaan**: WEEK([tarikh], [hari mula (pilihan)]). Mengira minggu ke berapa dalam tahun bagi tarikh tersebut. Jika hari mula tidak dinyatakan, hari pertama minggu secara lalai ialah Isnin. Nilai hari mula 1-7 menunjukkan Isnin hingga Ahad masing-masing sebagai hari pertama minggu.

**Contoh**: WEEK([Tarikh],) mengembalikan "20202" apabila nilai medan ialah "2020-01-08". Hari mula adalah pilihan dan secara lalai kosong.

### QUARTER

**Penggunaan**: QUARTER([tarikh], [tahun fiskal (pilihan)]). Mengira suku tahun ke berapa bagi tarikh tersebut. Tahun fiskal: 1 menggunakan statistik tahun fiskal (bermula pada April); 0 menggunakan tahun kalendar.

**Contoh**: QUARTER([Medan1], 0) mengembalikan "1" apabila Medan1 ialah "2020-02-02".

**Contoh**: ArrayCat(\<Pilih Banyak atau medan array lain 1>,\<Pilih Banyak atau medan array lain 2>,...) mengembalikan "Produk, Kejuruteraan, Perniagaan, Kakitangan Produk, Kakitangan Kejuruteraan, Kakitangan Perniagaan" apabila Medan1 ialah "Produk, Kejuruteraan, Perniagaan" dan Medan2 ialah "Kakitangan Produk, Kakitangan Kejuruteraan, Kakitangan Perniagaan".

## 9. Statistik

### ROUND

**Penggunaan**: ROUND(\<medan>,\<ketepatan>). Membundarkan medan kepada bilangan tempat perpuluhan yang ditentukan.

**Contoh**: ROUND(\<Medan1>,\<ketepatan>). Jika Medan1 ialah "12.33333" dan ketepatannya 2, nilai yang dikembalikan ialah "12.33".

### MOD

**Penggunaan**: MOD(\<medan>,\<medan>). Operasi modulo (baki). Mengembalikan nilai modulo (atau baki).

Nota: Untuk mendapatkan hasil bahagi, gunakan operator aritmetik /. Contohnya, 6/4 mengembalikan hasil bahagi 1 dengan baki 2.

Contoh: MOD(\<Medan1>,\<Medan2>). Jika Medan1 ialah "6" dan Medan2 ialah "4", nilai yang dikembalikan ialah "2".

### ParseDouble

**Penggunaan**: ParseDouble(\<medan>). Menukar string atau integer kepada nombor titik terapung.

**Contoh**: ParseDouble(\<medan>). Jika nilai medan ialah 3 atau "3", hasilnya ialah 3.0.

### ParseInt

**Penggunaan**: ParseInt(\<medan>). Menukar string atau nombor titik terapung kepada integer.

**Contoh**: ParseInt(\<medan>). Jika nilai medan ialah 3.2 atau "3.2", hasilnya ialah 3.
