## 1. Gambaran Keseluruhan Borang

Tetapan asas merangkumi ciri berikut: ① Nama halaman  ② Peraturan penghantaran  ③ Alihkan ke halaman selepas penghantaran  ④ Push ke "Task Center - Dicipta oleh saya"  ⑤ Tajuk rekod

⑥ Nombor siri Borang/aliran kerja  ⑦ Sembunyikan navigasi

### 2.1 Penggunaan

#### 2.1.1 Nama Halaman

Tajuk rekod merujuk kepada nama halaman Borang. Anda boleh mengubahnya dengan dua cara.

Nota: Menukar nama Borang hanya memberi kesan kepada rekod yang dihantar selepas itu. Nama Borang yang dihantar sebelum ini kekal tidak berubah.

<Frame>
  ![](https://gw.alicdn.com/imgextra/i4/O1CN01e8KEuwshLrE3rQdQ_!!6000000000999-2-tps-1902-878.png)
</Frame>

**Laluan 1**: Klik Borang sasaran >> klik ikon gear untuk Tetapan >> tukar nama. Lihat kesan di bawah:

Tetapan ikon gear Borang.

<Frame>
  ![](https://gw.alicdn.com/imgextra/i2/O1CN010935bS3KQ3D3pXZ1_!!6000000000624-2-tps-1887-872.png)
</Frame>

**Laluan 2**: Klik Borang sasaran >> Edit Borang >> Reka Bentuk Borang >> klik ikon edit di sebelah nama Borang di penjuru kiri atas. Laluan ini juga membolehkan anda menetapkan nama Bahasa Inggeris Borang. Lihat kesan di bawah:

Ubah suai nama Borang.

#### 2.1.2 Peraturan Penghantaran

Anda boleh menetapkan peraturan penghantaran Borang kepada "Hanya satu penghantaran dibenarkan bagi setiap akaun". Apabila diaktifkan, akaun yang sama tidak boleh menghantar berbilang instans. (Ciri ini Dinyahaktifkan secara lalai; aktifkan secara manual jika perlu.)

**Nota**: Peraturan penghantaran tidak terpakai kepada data yang diimport secara pukal daripada Excel.

#### 2.1.3 Alihkan ke Halaman Selepas Penghantaran

Selepas anda mengaktifkan "Alihkan ke halaman selepas penghantaran" dan mengkonfigurasi peraturan pengalihan, pengguna akan dialihkan ke halaman yang ditetapkan selepas menghantar Borang.

**Nota**: Dalam konfigurasi peraturan pengalihan, pemboleh ubah Borang hanya boleh diperoleh daripada komponen berikut: Teks satu baris, Input nombor, Select, dan Dropdown select.

#### 2.1.5 Tajuk Rekod

Format nama halaman lalai ialah: "[Pemohon] memulakan [Nama halaman]". Anda boleh menyesuaikan nama paparan halaman. **Nota**:

1. Hanya komponen berikut boleh digunakan untuk membentuk nama paparan (komponen mesti ditetapkan sebagai wajib): Teks satu baris, Nombor, Select, dan Dropdown select.

2. Menukar nama paparan halaman hanya memberi kesan kepada rekod yang baharu dihantar. Rekod yang dihantar sebelum ini mengekalkan nama halaman asal.

**Laluan**: Tetapan Borang >> Tetapan >> Tetapan halaman >> Tetapan asas >> Tajuk rekod >> klik **Edit** Tersuai >> konfigurasikan dalam editor pop timbul.

### 2.2 Tetapan Khusus untuk Borang Aliran Kerja

Item konfigurasi berikut hanya tersedia pada halaman Borang aliran kerja, dan tidak pada halaman Borang data biasa.

- Tindakan halaman aliran kerja
- Pengguna rundingan aliran kerja
- Alihkan ke selepas tindakan Kelulusan Selesai

## 3. Soalan Lazim

<AccordionGroup>
<Accordion id="q1" title="4.1 Mengapakah Admin masih boleh melihat sejarah perubahan dan entri Komen selepas disembunyikan dalam tindakan halaman Tetapan Asas?">
  Menguruskan komen dan menyembunyikan rekod perubahan dalam Tetapan Asas tidak terpakai kepada admin aplikasi atau admin sistem. Ia hanya berkuat kuasa bagi pengguna dengan kebenaran biasa.
</Accordion>
<Accordion id="q2" title="4.2 Bolehkah Butang Padam Borang diikat kepada parameter bersyarat?">
  **Senario sebenar**: Sebagai contoh, anda ingin mengesahkan medan "berdaftar"—jika sesuatu rekod berdaftar, ia tidak boleh dipadam. Senario: Semasa memadam, semak sama ada data medan tersebut "berdaftar". Jika "Ya", nombor bilik mesti diubah suai terlebih dahulu sebelum rekod boleh dipadam; jika tidak, pemadaman tidak dibenarkan.

  <Frame>
    ![](https://gw.alicdn.com/imgextra/i2/O1CN01NtjaTt1kOPD23165_!!6000000004917-2-tps-1009-868.png)
  </Frame>

  Oleh kerana acara Padam tidak dapat ditangkap, keperluan ini tidak dapat dilaksanakan.
</Accordion>
<Accordion id="q3" title="4.3 Mengapakah mengubah suai nama paparan halaman tidak memberi sebarang kesan?">
  Menukar tajuk instans tidak terpakai kepada rekod yang telah dihantar. Hanya rekod yang baharu dihantar mengikut peraturan tajuk instans yang baharu.
</Accordion>
<Accordion id="q4" title="4.4 Mengapakah saya menerima mesej 'Borang sasaran untuk dialihkan telah Dipadam' semasa menghantar Borang?">
  Semak Tetapan halaman Borang >> Tetapan asas >> Alihkan ke halaman selepas penghantaran, dan sahkan sama ada Borang sasaran sebenarnya telah dipilih.
</Accordion>
</AccordionGroup>
