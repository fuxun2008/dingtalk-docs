**NETWORKDAYS** 函数用于计算两个日期之间的工作日天数。

## 支持的产品场景

NETWORKDAYS 函数支持以下 YiDA 场景。

- Borang（主表字段）
- Borang（业务关联规则）
- Borang（校验）
- Reka bentuk aliran kerja（校验规则）
- Reka bentuk aliran kerja（关联动作）
- Integrasi & Automasi
- 工作流节点
- Penyambung

## Format

```text
WORKDAY(start_time,end_time,holidays)
```

## Atribut Description

| **Atribut** | **Wajib** | **Description** |
|---|---|---|
| start_time | Ya | 开始时间的时间戳。您可以直接使用 Date 组件的值。 |
| end_time | Ya | 结束时间的时间戳。您可以直接使用 Date 组件的值。<br />开始时间与结束时间的间隔不得超过 50,000 天，否则将返回空值。 |
| holidays | 否 | 需要从计算中排除的日期，格式为 `yyyy-MM-dd`。您可以指定多个日期，以逗号分隔。<br />例如，您可以指定不同省、市、自治区或国家/地区的法定假日及非法定假日。 |

## Return Value

| **Return value type** | **Description** |
|---|---|
| Numerik | 返回的工作日天数。 |
