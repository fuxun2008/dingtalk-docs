Fungsi ini biasanya digunakan untuk mengesahkan bahawa pilihan pengguna atau pilihan opsyen dalam satu medan kekal terkandung sepenuhnya dalam pilihan yang lebih luas dalam borang dan aliran kerja YiDA.

## Senario Produk yang Disokong

Fungsi SUBSET disokong dalam senario YiDA berikut:

- Borang (peraturan perkaitan perniagaan)
- Borang (pengesahan)
- Reka bentuk aliran kerja (peraturan pengesahan)
- Reka bentuk aliran kerja (tindakan perkaitan)
- Integrasi dan automasi
- Nod aliran kerja
- Penyambung

## Format

```text
SUBSET(arrayA,arrayB)
```

## Nilai Pulangan

| **Jenis nilai pulangan** | **Penerangan** |
|---|---|
| Boolean | Sama ada set B ialah subset bagi set A. Nilai:<br />• **true**: Set B ialah subset bagi set A.<br />• **false**: Set B bukan subset bagi set A. |

## Contoh

Seperti yang ditunjukkan di bawah, penyerahan borang disekat apabila Pengguna B ialah subset bagi Pengguna A.

## Cuba Sendiri

Penyerahan borang disekat apabila Kotak semak 2 ialah subset bagi Kotak semak 1.
