## 1. Pengenalan

### 1.1 Gambaran Keseluruhan

Apabila data satu medan dalam borang berubah, data medan lain dalam borang yang sama turut berubah mengikutnya. Ini biasanya digunakan untuk menetapkan nilai lalai bagi komponen.

## 2. Item Konfigurasi Keterkaitan Data

## 3. Jenis Komponen yang Menyokong Keterkaitan Data

**Nota: Komponen alamat dan borang berkaitan hanya boleh digunakan sebagai peraturan syarat. Borang berkaitan memetik medan maklumat utama yang dikonfigurasikan di dalamnya.**

## 5. Soalan Lazim

### 5.1 Jadual Sumber Mengandungi Data, tetapi Data Terpaut Tidak Dipaparkan.

Keterkaitan data mengembalikan bilangan hasil yang terhad, dan carian dalam kalangan hasil yang dikembalikan tidak disokong buat masa ini. Jika jadual sumber mengandungi banyak rekod yang memenuhi syarat—terutamanya banyak nilai berulang—hasil yang dikehendaki mungkin tidak muncul dalam keterkaitan.

Anda boleh mengaktifkan penyahduplikatan untuk mengurangkan rekod berulang dalam hasil, yang membolehkan lebih banyak data terpaut yang bermakna dipaparkan.

### 5.2 Cara Mencetuskan Keterkaitan Data Secara Automatik

<Warning>
**Nota: Kaedah ini hanya terpakai untuk senario di mana perubahan pada komponen borang utama mencetuskan keterkaitan data pada borang utama sahaja atau pada sub-jadual sahaja.**
</Warning>

```javascript
/* Ikatkan Masa kemas kini dengan keterkaitan */
export function didMount() {
  const instanceData = this.utils.getFormInstanceData();
  const { flowData = {} } = instanceData;
  const { editMode, viewMode } = flowData;
  if (viewMode === false && editMode === true) {
    this.$('textField_vq5mqtb').getProps().onChange();
    this.utils.toast({
      title: 'Dikemas kini',
      type: 'success'
    })
  }
}
```
