Bahagian berikut menerangkan cara tetapan Paparan lalai dikonfigurasikan dalam mod Admin dan cara pelarasan sementara berfungsi dalam mod Paparan.

### Mod Admin

Dalam admin console aplikasi, Admin Konfigurasikan penapis, paparan dan susunan lajur, peraturan penyusunan baris, ketinggian baris, dan tetapan lain, kemudian klik **Simpan** untuk menyediakan konfigurasi Paparan lalai bagi mod Paparan.

  ![](https://gw.alicdn.com/imgextra/i3/O1CN01CKM3NlZA9hG42884_!!6000000002560-2-tps-1987-1265.png)
</Frame>


Paparan Grid menyokong empat gaya ketinggian baris: Rendah, Sederhana, Tinggi, dan Sangat tinggi. Konfigurasikan ketinggian baris untuk setiap Paparan.

### Mod Paparan

Berdasarkan konfigurasi lalai Admin, pengguna dalam mod Paparan boleh membuat perubahan sementara pada penapis, paparan dan susunan lajur, peraturan penyusunan baris, ketinggian baris, dan tetapan lain. Perubahan sementara boleh disimpan, dan konfigurasi mod Paparan terkini akan dipaparkan apabila pengguna kembali.

  ![](https://gw.alicdn.com/imgextra/i3/O1CN01vtqqlmyMxqD6kBPO_!!6000000006153-2-tps-3322-1640.png)

<Warning>
Selepas **pelawat aplikasi** menyegar semula halaman, susunan borang semasa akan dikekalkan. Untuk memulihkan tetapan lalai (iaitu, susunan yang ditentukan oleh editor aplikasi), buka pelayar dan kosongkan cache. Langkah di bawah menggunakan Chrome sebagai Contoh.
</Warning>
