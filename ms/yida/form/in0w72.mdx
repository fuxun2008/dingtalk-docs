## 1. Apa Itu Subborang

Komponen bekas lanjutan yang membolehkan anda menambah komponen Teks, Numerik, Tarikh, dan komponen lain di dalamnya. Contohnya, gunakan subborang apabila anda perlu menambah beberapa entri produk semasa entri data produk.

## 2. Kes Penggunaan

Subborang biasanya digunakan untuk senario entri data seperti pesanan keluar, pesanan masuk, dan pesanan jualan. Perincian produk dalam senario ini boleh direkodkan dalam subborang, dan anda boleh menambah baris mengikut keperluan berdasarkan data yang perlu dimasukkan.

<Note>
Untuk atribut, penggunaan, dan contoh komponen, sila lihat [**rujukan ini**](/ms/open/yida/components/interface).
</Note>

### 5.10 Komponen Tersembunyi dalam Subborang Mengembalikan Null

Semasa memproses subborang, `value` bagi atribut tersembunyi ditetapkan semula. Ia dikonfigurasikan sebagai null, jadi menetapkan nilai subborang berkeadaan tersembunyi ke subborang lain akan mengembalikan null.

### 5.14 Bagaimana Saya Mendapatkan Medan yang Baru Berubah Semasa onChange Subborang Dicetuskan

Apabila data subborang berubah, acara onChange subborang dicetuskan bukan sahaja oleh penyuntingan sel tetapi juga oleh pengiraan formula, keterkaitan data, atau penetapan nilai luaran. Untuk mengenal pasti perubahan tersebut, gunakan parameter `extra` bagi acara onChange subborang untuk mendapatkan medan yang baru berubah, dan parameter `changes` untuk mendapatkan nilainya.

**Kod contoh:**

```javascript
// onChange subborang
export function onTableChange({ value, extra }) {
  const { fieldId, changes = {} } = extra || {};
  // Semak sama ada medan nama item telah berubah
  if (fieldId && fieldId === 'pengecam unik medan nama item dalam subborang') {
    // Tambah logik yang perlu dilaksanakan selepas medan berubah di sini
    console.log(changes.value);
  }
}
```

### 5.15 Bagaimana Saya Mengemas Kini Medan Lain dalam Baris Semasa Apabila Komponen di Dalam Subborang Berubah

Gunakan API subborang `updateItemValue` untuk mengemas kini medan lain dalam baris semasa subborang.

<Note>
Nota: API ini hanya boleh digunakan dalam acara komponen subborang, bukan dalam acara komponen di dalam subborang.
</Note>

**Kod contoh:**

```javascript
// onChange subborang
export function onTableChange({ value, extra }) {
  const { formGroupId, from, tableFieldId, fieldId, changes = {} } = extra || {};
  // Diperlukan untuk mengelakkan gelung tak terhingga yang disebabkan oleh pencetusan semula onChange selepas menggunakan updateItemValue untuk mengemas kini data subborang
  if (from === 'setItemValue') { return; }
  const tableField = this.$(tableFieldId); // Dapatkan definisi subborang
  // Semak sama ada medan nama item telah berubah
  if (fieldId && fieldId === 'pengecam unik medan nama item dalam subborang') {
    tableField.updateItemValue(formGroupId, {
      'pengecam unik komponen lain dalam baris semasa': 'nilai yang dikemas kini',
    }); // Kemas kini nilai komponen lain dalam baris semasa
  }
}
```

**Hasil:**

Selepas anda memasukkan nama item, nilai **Nama item** ditetapkan kepada **Salinan nama item** dalam baris semasa.
