## 1. Kes Penggunaan

![](https://gw.alicdn.com/imgextra/i4/O1CN01pkMjJfkSe5E2b876_!!6000000005004-2-tps-1280-720.png)


**Penyediaan data** merupakan ciri utama platform low-code YiDA. Ia membantu pengguna perusahaan membersih, mengintegrasi, dan mentransformasi data mentah sebelum menjalankan analisis data atau membina aplikasi. Penyediaan data menggunakan pendekatan ETL (Extraction Transformation Loading) sifar-kod untuk memproses data daripada aplikasi YiDA, pangkalan data perusahaan luaran, data berasaskan fail, dan sumber data rasmi DingTalk (termasuk Senarai Pekerja, OA, Smart HR, dan Kehadiran). Dengan membina saluran pemprosesan data, ia menggabungkan data yang bertaburan menjadi dataset yang piawai bagi menyokong analisis visual dan pembuatan keputusan berasaskan data.

## 4. Pemprosesan Logik

### CASEWHEN

**Penggunaan 1**: CASEWHEN(\<syarat>,\<nilai>,\<syarat>,\<nilai>...). Setara dengan sintaks CASE WHEN dalam SQL.

**Contoh**: CASEWHEN(\<Medan Jantina>="Lelaki","lelaki",\<Medan Jantina>="Perempuan","perempuan"). Nilai "Lelaki" digantikan dengan "lelaki", dan nilai "Perempuan" digantikan dengan "perempuan".

**Penggunaan 2**: CASEWHEN(\<syarat>,\<nilai>,\<syarat>,\<nilai>...\<nilai>). Setara dengan sintaks CASE WHEN dalam SQL.

**Contoh**: CASEWHEN(\<Medan Jantina>="Lelaki","lelaki","perempuan"). Nilai "Lelaki" digantikan dengan "lelaki", dan sebarang nilai lain digantikan dengan "perempuan".

## 5. Pemprosesan Teks

### LEN

**Penggunaan**: LEN([medan string]). Mengembalikan panjang string tersebut.

**Contoh**: LEN("test") mengembalikan 4. LEN("测试") mengembalikan 2. Satu aksara Cina dikira sebagai satu aksara Inggeris.

### LEFT

**Penggunaan**: LEFT(\<medan ukuran>,\< n >). Mengembalikan string sepanjang n bermula dari aksara pertama di sebelah kiri nilai \<medan>.

**Contoh**: LEFT(Medan1,3) mengembalikan "ABC" apabila nilai Medan1 ialah "ABCDEF".

### RIGHT

**Penggunaan:** RIGHT(\<medan ukuran>,\< n >). Mengembalikan string sepanjang n dikira dari sebelah kanan nilai \<medan>.

**Contoh**: RIGHT(Medan1,3) mengembalikan "DEF" apabila nilai Medan1 ialah "ABCDEF".

### MID

**Penggunaan**: MID(\<medan ukuran>, \< mula >, \< n >). Mengembalikan string sepanjang n bermula dari aksara ke-mula (dikira dari kiri) nilai \<medan>.

**Contoh**: MID(Medan1, 3, 3) mengembalikan "CDE" apabila nilai Medan1 ialah "ABCDEF".

### POS

**Penggunaan**: POS(\<medan ukuran>,\<substring>). Mengembalikan kedudukan \<substring> dalam \<teks>. Mengembalikan 0 jika tiada padanan ditemui.

**Contoh**: POS(Medan1,"DE") mengembalikan 4 apabila nilai Medan1 ialah "ABCDEF".

### UPPER

**Penggunaan**: UPPER(\<medan ukuran>). Menukar nilai \<medan> kepada huruf besar.

**Contoh**: UPPER(Medan1) mengembalikan "ABCDEF" apabila nilai Medan1 ialah "AbcdeF".

### LOWER

**Penggunaan**: LOWER(\<medan ukuran>). Menukar nilai \<medan> kepada huruf kecil.

**Contoh**: LOWER(Medan1) mengembalikan "abcdef" apabila nilai Medan1 ialah "AbcdeF".

### VAL

**Penggunaan**: VAL(\<medan ukuran>). Menukar nilai \<medan> jenis teks kepada jenis nombor.

**Contoh**: VAL(Medan1) mengembalikan 123 apabila nilai Medan1 ialah "123".

### LEFTTRIM

**Penggunaan**: LEFTTRIM(\<medan ukuran>). Membuang ruang di hadapan nilai \<medan>.

**Contoh**: LEFTTRIM(Medan1) mengembalikan "ABC" apabila nilai Medan1 ialah " ABC".

### RIGHTTRIM

**Penggunaan**: RIGHTTRIM(\<medan ukuran>). Membuang ruang di belakang nilai \<medan>.

**Contoh**: RIGHTTRIM(Medan1) mengembalikan "ABC" apabila nilai Medan1 ialah "ABC ".

### NUMBERTOSTRING

**Penggunaan**: NUMBERTOSTRING(\<nombor>). Menukar data nombor kepada string.

**Contoh**: NUMBERTOSTRING(Medan1) mengembalikan "12345" apabila nilai Medan1 ialah "12345 ".

### SPLITPART

**Penggunaan**: SPLITPART(\<medan string>, pembatas, kedudukan substring). Membahagikan string kepada N substring mengikut pembatas (di mana N bersamaan bilangan pembatas tambah 1). Kedudukan substring dikira daripada 1 (kiri ke kanan) atau daripada -1 (kanan ke kiri).

**Contoh**: SPLITPART(\<Medan1>,A,2) mengembalikan "BCD" apabila nilai Medan1 ialah "ABCDABHABC". Menetapkan kedudukan substring kepada -5 juga mengembalikan "BCD".

### CONCAT

**Penggunaan**: CONCAT(\<medan>,\<medan>,...). Menggabungkan beberapa medan menjadi satu string. Parameter input mestilah medan jenis string.

**Contoh**: CONCAT(\<Medan1>,\<Medan2>) mengembalikan "ABCD" apabila nilai Medan1 ialah "A" dan nilai Medan2 ialah "BCD".

### REPLACE

**Penggunaan**: REPLACE([string], [string carian], [string penggantian]). Mengembalikan string selepas penggantian.

**Contoh**: REPLACE([Medan1], [Medan2], [Medan3]) mengembalikan "a12345efg" apabila Medan1 ialah "abcdefg", Medan2 ialah "bcd", dan Medan3 ialah "12345".

## 6. Pemprosesan Masa

### NOW

**Penggunaan**: NOW(). Mengembalikan masa semasa, tepat hingga ke saat.

**Contoh**: Tiada

### DATEFORMAT

**Penggunaan**: DATEFORMAT(\<Medan tarikh>,\<format masa>). Memformat tarikh sebagai string.

Format bagi kedua-dua fungsi mengikut konvensyen pemformatan tarikh Java. Jenis format yang disokong adalah:

- yyyy: Tahun
- MM: Bulan
- dd: Hari
- hh: Jam 12 (1-12)
- HH: Jam 24 (0-23)
- mm: Minit
- ss: Saat

**Contoh 1:**

DATEFORMAT(\<Medan tarikh>,"yyyy-MM-dd"). Jika nilai medan tarikh ialah 4 Ogos 1989, nilai yang dikembalikan ialah 1989-08-04. Pembatas "-" boleh digantikan dengan "/" atau aksara lain.

**Contoh 2:**

DATEFORMAT(\<Medan tarikh>,"yyyy-MM-dd HH:mm:ss"). Jika nilai medan tarikh ialah 1 September 2020, 1:30:00 PM, nilai yang dikembalikan ialah 2020-09-01 13:30:00. Pembatas "-" dan ":" boleh digantikan dengan "/" atau dengan aksara seperti "tahun", "bulan", "hari".

### DATEADD

**Penggunaan:** `DATEADD(<Medan Masa>,<offset>,<granulariti masa>)`. Menambah \<offset> mengikut **\<granulariti masa>** yang ditentukan kepada \<Medan Masa>.

- Nilai granulariti masa:

- Offset ialah nombor tertentu untuk ditambah atau ditolak. Nilai positif menambah, dan nilai negatif menolak.

**Contoh 1:**

Jika nilai Komponen Tarikh ialah "20200901", maka `DATEADD(Komponen Tarikh,10,"DAY") = 20200911`.

**Contoh 2:**

Jika nilai Komponen Tarikh ialah "20200901", maka `DATEADD(Komponen Tarikh,-1,"DAY") = 20200831`.

<Note>
Format paparan tarikh lalai ialah `yyyyMMdd`. Untuk menukar format paparan, rujuk contoh dalam [**fungsi DATEFORMAT**](/yida/form/sk0p7euqper7qr7l).
</Note>

### DATEDIFF

**Penggunaan**: DATEDIFF(\<Medan Masa 1>,\<Medan Masa 2>,\<granulariti masa>). Mengembalikan perbezaan antara Medan Masa 1 dan Medan Masa 2 pada granulariti masa yang ditentukan.

Pilihan granulariti masa:

- YEAR       Tahun
- MONTH    Bulan
- DAY        Hari
- HOUR      Jam
- MINUTE   Minit
- SECOND  Saat

**Contoh**: DATEDIFF(Komponen Tarikh 1, Komponen Tarikh 2,"DAY") mengembalikan bilangan hari antara kedua-dua komponen tarikh.

**Nota: Parameter hanya menyokong komponen tarikh. Nilai tarikh tetap tidak boleh dimasukkan terus dalam formula.**

Andaikan nilai Komponen Tarikh ialah "2020-02-14" dan hari ini ialah "2020-02-16". Maka:

DATEDIFF(NOW(), Tarikh dimasukkan,"DAY") = 2

DATEDIFF(Tarikh dimasukkan, NOW(),"DAY") = -2

### FROMUNIXTIME

**Penggunaan**: Menukar nilai masa Unix berbentuk nombor kepada nilai tarikh.

Pengisytiharan fungsi:

```sql
datetime fromunixtime(bigint unixtime)
```

Penerangan parameter:

- unixtime: Jenis Bigint. Bilangan saat dalam format tarikh-masa Unix. Nilai jenis string, double, atau decimal akan ditukar secara tersirat kepada bigint sebelum operasi dilakukan.
- Nilai pulangan: Jenis Datetime. Mengembalikan NULL jika unixtime adalah NULL.

Contoh:

```sql
fromunixtime(123456789) = 1973-11-30 05:33:09
```

### WEEK

**Penggunaan**: WEEK([tarikh], [hari mula (pilihan)]). Mengira minggu dalam tahun bagi tarikh yang diberikan. Jika hari mula tidak dinyatakan, Isnin digunakan sebagai hari pertama minggu secara lalai. Nilai hari mula 1-7 menunjukkan Isnin hingga Ahad sebagai hari pertama minggu.

**Contoh**: WEEK([tarikh],) mengembalikan "20202" apabila nilai medan ialah "2020-01-08". Hari mula boleh diabaikan dan lalai kepada kosong.

### QUARTER

**Penggunaan**: QUARTER([tarikh], [penanda tahun fiskal (pilihan)]). Mengira suku tahun bagi tarikh yang diberikan. Tetapkan penanda tahun fiskal kepada 1 untuk menggunakan tahun fiskal (bermula dari April) atau 0 untuk menggunakan tahun kalendar.

**Contoh**: QUARTER([Medan1], 0) mengembalikan "1" apabila nilai Medan1 ialah "2020-02-02".

## 7. Statistik Asas

### ROUND

**Penggunaan**: ROUND(\<medan>,\<ketepatan>). Membundarkan medan kepada bilangan tempat perpuluhan yang ditentukan.

**Contoh**: ROUND(\<Medan1>,\<ketepatan>) mengembalikan "12.33" apabila nilai Medan1 ialah "12.33333" dan ketepatan ialah 2.

### MOD

**Penggunaan**: MOD(\<medan>,\<medan>). Melakukan operasi modulo dan mengembalikan baki.

Nota: Untuk mendapatkan hasil bahagi bagi suatu pembahagian, gunakan operator aritmetik /. Contohnya, 6/4 mengembalikan hasil bahagi 1 dengan baki 2.

Contoh: MOD(\<Medan1>,\<Medan2>) mengembalikan "2" apabila nilai Medan1 ialah "6" dan nilai Medan2 ialah "4".

### ParseDouble

**Penggunaan**: ParseDouble(\<medan>). Menukar string atau integer kepada nombor titik terapung.

**Contoh**: ParseDouble(\<medan>) mengembalikan 3.0 apabila nilai medan ialah 3 atau "3".

### ParseInt

**Penggunaan**: ParseInt(\<medan>). Menukar string atau nombor titik terapung kepada integer.

**Contoh**: ParseInt(\<medan>) mengembalikan 3 apabila nilai medan ialah 3.2 atau "3.2".

## 8. Array

### ArrayToString

**Penggunaan**: ArrayToString(\<medan array>,[pembatas (pilihan)]). Menukar array kepada string.

**Contoh**: ArrayToString(\<Medan1>,\<Medan2>) mengembalikan "Jabatan Produk-Jabatan Tech-Jabatan Perniagaan" apabila nilai Medan1 ialah "[Jabatan Produk, Jabatan Tech, Jabatan Perniagaan]" dan nilai Medan2 ialah "-". Jika Medan2 kosong, ia mengembalikan "Jabatan Produk,Jabatan Tech,Jabatan Perniagaan".

### StringToArray

**Penggunaan**: StringToArray(\<medan string>,[pembatas (pilihan)]). Menghurai string menjadi array.

**Contoh**: StringToArray(\<Medan1>,\<Medan2>) mengembalikan "[Jabatan Produk, Jabatan Tech, Jabatan Perniagaan]" apabila nilai Medan1 ialah "Jabatan Produk-Jabatan Tech-Jabatan Perniagaan" dan nilai Medan2 ialah "-".
