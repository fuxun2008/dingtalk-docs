**Artikel ini menyenaraikan dokumen kes yang tersedia untuk formula Fungsi. Klik nama kes untuk melompat ke halaman konfigurasi terperinci, seperti ditunjukkan di bawah:**

| **Pautan kes** | **Fungsi yang terlibat** |
|---|---|
| Dapatkan nama Jabatan induk | DEPTNAME |
| Hadkan hari cuti tahunan | DAYS |
| Tentukan tahap gred berdasarkan skor | IF |
| Jana string rawak dengan panjang tetap | UUID |
| Kira secara automatik zodiak Cina daripada nombor kad pengenalan | IF, EQ, MOD, LEN, VALUE |
| Kira secara automatik jantina daripada nombor kad pengenalan | IF, EQ, MID, OR |
| Kira secara automatik wilayah daripada nombor kad pengenalan | IF, EQ, MID, LEN, VALUE |
| Dapatkan tarikh lahir daripada nombor kad pengenalan | IF, EQ, MID, CONCATENATE, LEN |
| Kira secara automatik zodiak (perbintangan) daripada nombor kad pengenalan | IF, EQ, MID, LEN, VALUE, GE, AND, LE |
| Kira secara automatik umur daripada nombor kad pengenalan | IF, EQ, LEN, VALUE, TODAY, TEXT, RIGHT, LEFT |
| Samarkan sebahagian daripada Nombor Telefon | REPLACE |
| Pilih soalan secara rawak | Pelaksanaan kod |
| Tukar teks kepada Format tarikh | MID, DATE, TIMESTAMP |
| Tambah sepuluh hari secara automatik kepada tarikh | DATEDELTA, DATE, IF, ISEMPTY |
| Kalkulator cukai pendapatan peribadi terkini | IF, AND, EQ, LE, GT |
| Kira purata skor merentasi beberapa hakim | MAX, VALUE, ARRAYGET, SPLIT, MIN, CONCATENATE |
| Tukar saiz Tajuk | Pelaksanaan kod |
| Tetapkan Format peratusan | TEXT |
| Jana secara automatik alamat e-mel daripada nombor QQ | IF, ISEMPTY, CONCATENATE |
| Tetapkan bilangan tempat perpuluhan | ROUND |
| Tukar Nombor kepada huruf besar | RMBFORMAT, INT |
| Bekerja dengan Nombor di dalam string | EQ, VALUE |
| Kira tahun perkhidmatan | INT, DAYS, DATE, IF, OR, ISEMPTY |
| Benarkan setiap pengguna Hantar hanya satu rekod setiap hari | USER, SYSTIME, TIMESTAMP, TEXT, DATE, EXIST |
| Kira harga diskaun | SUM, IF, LT |
| Pisahkan jumlah invois | IF, GT, AND, LE, RIGHT, LEFT, INT |
| Jana nombor siri dalam Format tetap | COUNT |
| Dapatkan pengurus | DEPTNAME |
| Dapatkan masa Tamatkan bagi julat tarikh menggunakan formula | MID, SEARCH |
