## 1. Pengenalan

### 1.1 Gambaran Keseluruhan Ciri

Setelah anda mengesahkan data yang hendak dikumpulkan, cipta borang dan reka bentuknya mengikut keperluan anda.

### 1.2 Kes Penggunaan

Dua jenis borang tersedia. Borang biasa termasuk ciri kolaborasi dan menyokong pengurusan data berasaskan kebenaran. Borang aliran kerja termasuk ciri aliran kerja dan menyokong reka bentuk aliran kerja.

Terdapat tiga cara untuk mencipta borang:

- **Cipta dari kosong**
- **Cipta daripada templat**
- **Cipta borang daripada Excel** (menggunakan pengepala Excel sebagai komponen)

## 2. Cara Mencipta Borang

**Laluan**: Buka Workbench YiDA >> Klik Aplikasi Saya atau Cipta baharu >> Masuk ke editor aplikasi.

### 2.1 Langkah

(1) Pada halaman Pusat Aplikasi semasa, klik Cipta borang kosong.

<Frame>
  ![](https://gw.alicdn.com/imgextra/i2/O1CN01grByRcYuxyJ3hjg1_!!6000000000310-2-tps-1825-872.png)
</Frame>


(2) Di bahagian atas panel navigasi sebelah kiri aplikasi, klik Cipta halaman, kemudian pilih Cipta borang daripada menu lungsur.

<Frame>
  ![](https://gw.alicdn.com/imgextra/i2/O1CN01KCCCZaN8R1K3iMhP_!!6000000007044-2-tps-1830-869.png)
</Frame>


<Warning>
Nota: Selepas aliran kerja tamat, data borang aliran kerja tidak boleh disunting. Rancang dengan sewajarnya.
</Warning>

## 5. Cipta daripada Excel

Sediakan hamparan Excel secara tempatan, kemudian import terus ke dalam YiDA.

**Laluan**: Klik aplikasi sasaran >> Cipta borang >> Import daripada Excel.

<Frame>
  ![](https://gw.alicdn.com/imgextra/i4/O1CN01InrFt0Q1QnI3hjfw_!!6000000000501-2-tps-1825-867.png)
</Frame>

Import borang daripada Excel.

<Frame>
  ![](https://gw.alicdn.com/imgextra/i4/O1CN01DcLgaheRnDF3hU4K_!!6000000006534-2-tps-1823-877.png)
</Frame>

Muat naik data hamparan.

Untuk butiran mengenai import pukal, rujuk [Import pukal](/yida/form/andrke).

<Note>
- Aplikasi mesti diterbitkan sebelum import. Untuk butiran, rujuk Aktifkan atau nyahaktifkan aplikasi.
- Borang biasanya digunakan untuk mengumpul data dan tidak termasuk proses kelulusan semasa penyerahan. Jika anda memerlukan keupayaan proses kelulusan, gunakan borang aliran kerja.
</Note>
