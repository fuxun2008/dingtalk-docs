## Edit Pukal Ringkas

Ikuti langkah berikut untuk mengedit data secara pukal.

1. Log masuk ke workbench YiDA dan buka aplikasi yang datanya ingin anda edit secara pukal.
2. Pilih borang sasaran dan klik **Pengurusan data**.
3. Klik **Lain-lain** > **Edit pukal**, kemudian pilih rekod yang ingin diedit.

Anda boleh mengedit data borang dengan cepat melalui tiga cara berikut.

  ![](https://gw.alicdn.com/imgextra/i1/O1CN010cFuqbBmuMH7G9qo_!!6000000006673-2-tps-3576-1894.png)

<Warning>
📌**Nota:**

- Hanya **pentadbir aplikasi** dan **pentadbir data aplikasi** boleh mengakses **halaman pengurusan data** (paparan pengurusan) untuk membuat suntingan.
- Pengguna aplikasi tidak boleh menggunakan ciri ini. Mereka boleh mengedit data melalui **Muat naik Excel** sebagai gantinya.
- Sehingga 1,000 rekod boleh diedit pada satu masa. Apabila kurang daripada 50 rekod diedit, pemberitahuan mesej dan peraturan perkaitan perniagaan boleh dicetuskan.
- Edit pukal mesti dilakukan dalam paparan pengurusan pada halaman pengurusan data borang berkaitan. Halaman berbilang paparan tidak disokong.
</Warning>

4. Dalam kotak dialog, **pilih medan yang ingin diedit** dan tetapkan nilai baharu.
5. Pilih sama ada untuk mencetuskan peraturan pengesahan, peraturan perniagaan, aliran Integrasi & Automasi, pemberitahuan mesej, dan panggilan balik perkhidmatan pihak ketiga.

<Note>
Hanya tersedia apabila kurang daripada 50 rekod diedit.
</Note>

6. Klik **Sahkan suntingan**.

## Langkah Berjaga-jaga

- Hanya **borang** menyokong edit pukal. Borang aliran kerja tidak disokong.
- Data borang yang dipadankan tidak boleh diubah semasa edit pukal sedang berjalan. Jalankan edit pukal semasa waktu tidak sibuk.
- Edit pukal tidak boleh dibatalkan dan tidak mencetuskan formula borang atau keterkaitan data. Teruskan dengan berhati-hati.
- Hanya komponen berikut disokong: Teks satu baris, Teks pelbagai baris, Numerik, Pilih, Pilihan lungsur, Kotak semak, Kotak semak lungsur, Tarikh, Jabatan, Pengguna, Muat naik gambar, dan Lampiran. Dalam aplikasi 2.0, komponen Pengguna, Muat naik gambar, dan Lampiran tidak menyokong edit pukal.
- Edit pukal mengambil masa untuk berjalan. Pemberitahuan DingTalk akan dihantar sebaik sahaja suntingan selesai.
- Hanya satu edit pukal boleh berjalan pada borang yang sama pada satu masa. Tunggu sehingga edit pukal sebelumnya selesai sebelum memulakan yang seterusnya.
- Satu rekod sepadan dengan satu syarat padanan, dan satu syarat padanan boleh digunakan untuk berbilang rekod. Sehingga 1,000 rekod boleh diedit bagi setiap edit pukal.
- Subborang tidak menyokong edit pukal. Walau bagaimanapun, pengesahan subborang yang ketat dinyahaktifkan semasa edit pukal, jadi borang utama masih boleh diedit apabila subborang wujud. Sebagai contoh, jika fail Excel tempatan mengandungi kandungan berformat subborang, kandungan borang utama masih boleh diimport dan diedit seperti biasa.
