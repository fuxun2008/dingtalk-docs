Semasa import, data yang diimport secara pukal boleh mencetuskan peraturan pengesahan sedia ada pada borang, peraturan perniagaan, aliran Integrasi & Automasi, Pemberitahuan mesej, dan panggilan balik pihak ketiga—sama seperti jika rekod tersebut dihantar secara manual.

- Jenis Komponen yang disokong: Teks satu baris, Teks pelbagai baris, Pilih, dropdown pilih tunggal, Pilih Banyak, dropdown pilih banyak, muat naik gambar, Lampiran, Pengguna, Jabatan, Numerik, Tarikh, julat tarikh, subborang, borang berkaitan (jadual utama).
- Jenis Komponen yang tidak disokong: paparan imej-teks, Teks Kaya, pilih lata (cascade), Negara/Wilayah, lokasi, Tandatangan, borang berkaitan (subjadual).
- Data yang diimport secara pukal dipaparkan mengikut susunan baris dalam fail Excel.

## Langkah-langkah

Ikuti langkah-langkah berikut untuk mengimport data secara pukal.

1. Log masuk ke Workbench YiDA dan buka skrin pengurusan Halaman aplikasi.
2. Pilih borang yang hendak diimport data, kemudian klik **Pengurusan data** > **Import**.

3. Konfigurasikan peraturan import.

| Pilihan peraturan import | Penerangan |
|---|---|
| Import dipercepatkan | Apabila import dipercepatkan diaktifkan, sistem mengimport data Excel anda secara berkumpulan, yang mempercepatkan masa import dengan ketara. Gunakan untuk senario import mudah tanpa kebergantungan antara rekod.<br />Jangan aktifkan pilihan ini untuk senario kompleks, contohnya apabila data yang diimport memerlukan logik pemprosesan huluan atau hiliran. |
| Kaedah import | Tiga mod tersedia: hanya tambah rekod, hanya kemas kini rekod, dan tambah atau kemas kini rekod.<br />**Nota**: Borang aliran kerja hanya menyokong penambahan rekod baharu. |
| Peraturan import | Anda boleh memilih pilihan berikut semasa import pukal:<br />• **Borang aliran kerja**: Hantar Notifikasi Kerja supaya peserta aliran kerja menerima pemberitahuan mesej.<br />• **Borang biasa**: Cetuskan peraturan pengesahan, peraturan perniagaan, aliran Integrasi & Automasi, Pemberitahuan mesej, dan panggilan balik pihak ketiga. |

## Keperluan Format Excel

Import pukal mesti mengikut dengan tepat format yang diperlukan bagi setiap Komponen. Data dalam format yang salah akan gagal diimport.

Keperluan format Excel untuk setiap Komponen YiDA adalah seperti berikut:

| **Komponen** | **Format** | **Contoh** |
|---|---|---|
| **Teks satu baris**<br />**Teks pelbagai baris** | Kandungan berformat teks dalam hamparan. | Ini adalah contoh teks satu baris |
| **Numerik** | Kandungan berformat nombor dalam hamparan. | 1234 |
| **Pilih**<br />**Dropdown pilih tunggal** | Teks. Apabila fail Excel mengandungi lebih daripada 100 pilihan untuk medan pilih, lajur tersebut tidak boleh diimport ke dalam Komponen Pilih atau dropdown pilih tunggal. | Pilihan A |
| **Pilih Banyak**<br />**Dropdown pilih banyak** | Apabila fail Excel mengandungi lebih daripada 100 pilihan, lajur tersebut tidak boleh diimport ke dalam Komponen Pilih Banyak atau dropdown pilih banyak. Buat masa ini hanya satu pilihan boleh diimport bagi setiap baris. Pisahkan pilihan dengan koma Bahasa Inggeris `,`. Jika nilai pilihan mengandungi `,`, escape sebagai `,`. | Pilihan A,Pilihan B |
| **Tarikh** | Komponen Tarikh buat masa ini hanya menyokong format berikut:<br />• yyyy-MM-dd HH:mm:ss<br />• yyyy-MM-dd HH:mm<br />• yyyy-MM-dd HH<br />• yyyy-MM-dd<br />• yyyy-MM<br />• yyyy | Contoh tarikh:<br />• 2022-12-31 23:50:59<br />• 2022-12-31 23:50<br />• 2022-12-31 23<br />• 2022-12-31<br />• 2022-12<br />• 2022 |
| **Julat tarikh** | Komponen julat tarikh buat masa ini hanya menyokong format berikut:<br />• yyyy-MM-dd HH:mm:ss_yyyy-MM-dd HH:mm:ss<br />• yyyy-MM-dd HH:mm_yyyy-MM-dd HH:mm<br />• yyyy-MM-dd HH_yyyy-MM-dd HH<br />• yyyy-MM-dd_yyyy-MM-dd<br />• yyyy-MM_yyyy-MM<br />• yyyy_yyyy | Contoh julat tarikh:<br />• 2022-12-31 23:50:59_2022-12-31 23:50:59<br />• 2022-12-31 23:50_2022-12-31 23:50<br />• 2022-12-31 23_2022-12-31 23<br />• 2022-12-31_2022-12-31<br />• 2022-12_2022-12<br />• 2022_2022 |
| **Jabatan** | Sertakan laluan penuh daripada Jabatan peringkat teratas, dengan memisahkan Jabatan induk dan anak menggunakan `-`. Pisahkan pelbagai Jabatan dengan koma Bahasa Inggeris `,`.<br />Nilai disahkan semasa import. Baris yang gagal pengesahan akan direkodkan sebagai ralat. | Pilih banyak Jabatan:<br />DingTalk-YiDA-Produk YiDA,DingTalk-YiDA-Operasi YiDA<br />Pilih tunggal Jabatan:<br />DingTalk-YiDA-Produk YiDA |
| **Pengguna** | Maklumat Pengguna menyokong dua format: **Nama Pekerja + ID Pekerja** dan **Nama Pekerja + ID pengguna**.<br />• Apabila import menggunakan ID Pekerja, gunakan format `Nama1(IDPekerja),Nama2(IDPekerja2)`. | **Lampiran** | URL Lampiran yang hendak diimport. URL mesti memenuhi keperluan berikut:<br />• Mesti bermula dengan `http://` atau `https://`.<br />• Pisahkan pelbagai URL dengan koma Bahasa Inggeris `,`.<br />• URL mesti boleh diakses secara umum tanpa parameter pengesahan tambahan. Biarkan sel kosong jika sumber tidak tersedia.<br />• Format Fail tidak disahkan secara lalai, dan Pratonton tidak disokong.<br />• Format import dan eksport adalah konsisten. Contohnya, Lampiran yang dihantar melalui borang boleh dieksport dan kemudian diimport pukal semula dengan berjaya. | `https://img.alicdn.com/imgextra/i3/O1CN01XcfOQL1Gc4xwrXIP6_!!6000000000642-2-tps-1636-800.png` |
| **Muat naik gambar** | URL Gambar yang hendak diimport. URL Gambar mesti memenuhi keperluan berikut:<br />• Mesti bermula dengan `http://` atau `https://`.<br />• Pisahkan pelbagai URL dengan koma Bahasa Inggeris `,`.<br />• URL mesti boleh diakses secara umum tanpa parameter pengesahan tambahan. Biarkan sel kosong jika sumber tidak tersedia.<br />• Hanya format `.png`, `.jpg`, `.jpeg`, dan `.gif` disokong. Pratonton disokong.<br />• Baris yang gagal pengesahan akan direkodkan sebagai ralat.<br />• Format import dan eksport adalah konsisten. Contohnya, Gambar yang dihantar melalui borang boleh dieksport dan kemudian diimport pukal semula dengan berjaya. | URL Gambar |
| **Borang berkaitan** | Import borang berkaitan menyokong dua format: "**Tajuk[ID Instance]**" dan "**maklumat utama**". | Tajuk borang berkaitan[FINST-GO766481LI61UXEQCX2YV7JUGRKW2EVCZD64L0]<br />**atau**<br />Maklumat utama borang berkaitan |

## Nota

Ambil perhatian perkara berikut semasa memuat naik fail Excel:

- Saiz Fail tidak boleh melebihi 10 MB, dan satu helaian tidak boleh mengandungi lebih daripada 5,000 baris.
- Hanya format Fail `.xls` dan `.xlsx` disokong.
- Pastikan pengepala helaian yang hendak diimport tidak mengandungi sel kosong; jika tidak, sistem tidak akan mengimport helaian tersebut.
- Menapis data yang diimport secara pukal mengikut pemboleh ubah terbina dalam tidak disokong.
- Formula Excel seperti `SUM` atau `=H2*J2` tidak disokong dalam fail import.
- Gambar dan Lampiran yang diimport akan disimpan dan dikira ke dalam Kuota Lampiran anda.
- Jadual Pivot rentas-tab tidak boleh diimport.
