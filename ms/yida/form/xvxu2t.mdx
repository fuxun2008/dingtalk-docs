## 1. Gambaran Keseluruhan Log Aktiviti

Anda boleh membuat pertanyaan rekod bagi tindakan Import, Eksport, pengubahsuaian, Muat turun Fail, dan Cetak.

<Frame>
  ![](https://gw.alicdn.com/imgextra/i4/O1CN01kT5LdzbkdaG5oH9e_!!6000000000734-2-tps-2862-1164.png)
</Frame>

**Nota: Had 7 hari dikenakan untuk muat turun berulang**, merangkumi rekod Import, rekod Eksport, rekod pengubahsuaian, rekod Muat turun Fail, dan rekod Cetak.

<Frame>
  ![](https://gw.alicdn.com/imgextra/i4/O1CN01uz04GTu7T7B5qHxQ_!!6000000000694-2-tps-2878-890.png)
</Frame>

### 1.1 Pertanyaan Rekod Eksport

**Laluan**: Klik Borang/Borang aliran kerja >> Pengurusan data >> Rekod eksport

Untuk mencari rekod Eksport dengan cepat, Tapis mengikut Nama fail, status, operator, atau Masa Diubah, seperti ditunjukkan di bawah:

<Frame>
  ![](https://gw.alicdn.com/imgextra/i2/O1CN0152GzobOKZFG5q2PW_!!6000000004538-2-tps-2876-1130.png)
</Frame>

Rekod eksport

### 1.2 Pertanyaan Rekod Import

**Laluan**: Klik Borang/Borang aliran kerja >> Pengurusan data >> Rekod import

Sama halnya, untuk mencari rekod Import dengan cepat, Tapis mengikut Nama fail, status, operator, atau Masa Diubah, seperti ditunjukkan di bawah:

<Frame>
  ![](https://gw.alicdn.com/imgextra/i4/O1CN01T13jyPan9kI5qI1w_!!6000000004410-2-tps-2878-1170.png)
</Frame>

Rekod import

### 1.3 Pertanyaan Rekod Cetak

**Laluan**: Klik Borang/Borang aliran kerja >> Pengurusan data >> Rekod cetak

**Nota**: Rekod cetak tidak boleh Ditapis.

<Frame>
  ![](https://gw.alicdn.com/imgextra/i3/O1CN01qhIedUMSvHH5qHxg_!!6000000008039-2-tps-2878-906.png)
</Frame>

Rekod cetak

### 1.4 Pertanyaan Rekod Pengubahsuaian

**Laluan**: Klik Borang/Borang aliran kerja >> Pengurusan data >> Rekod pengubahsuaian

Rekod pengubahsuaian boleh dicari dengan cepat mengikut Nama fail, status, operator, atau Masa Diubah, seperti ditunjukkan di bawah:

<Frame>
  ![](https://gw.alicdn.com/imgextra/i2/O1CN01VDd9MTeMuUG5q2OW_!!6000000007512-2-tps-2876-1068.png)
</Frame>

Rekod pengubahsuaian

### 1.5 Pertanyaan Rekod Muat Turun Fail

**Laluan**: Klik Borang/Borang aliran kerja >> Pengurusan data >> Rekod muat turun fail

Halaman ini memaparkan rekod muat turun pukal bagi **lampiran** dan **imej**. Tapis mengikut Nama fail, status, operator, atau Masa Diubah, seperti ditunjukkan di bawah:

<Frame>
  ![](https://gw.alicdn.com/imgextra/i4/O1CN01yBcewuLufWD5qI10_!!6000000000816-2-tps-2878-1112.png)
</Frame>
