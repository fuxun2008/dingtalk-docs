Komponen Teks satu baris boleh menangkap input berangka seperti nombor kad pengenalan, nombor telefon, nombor pelajar, nombor pekerja, nombor kad bank, dan nombor keahlian. Ia juga boleh menerima teks biasa.

## Ciri Asas

Menyokong imbasan Kod QR, pengira aksara, kosongkan sekali klik, dan pengalihan halaman lanjutan.

### Imbasan Kod QR

#### Mod Imbasan

> Panggil fungsi imbasan DingTalk untuk menangkap data Kod QR atau kod bar dengan pantas ke dalam komponen Teks satu baris.
> 
> Biasa digunakan untuk senario yang memerlukan input berasaskan imbasan, seperti pemeriksaan peranti dan inventori aset.

#### Jenis Imbasan

**Jenis imbasan yang disokong:** `Semua`, `Hanya Kod QR`, `Hanya kod bar`.

**Semua:** Satu kawalan tunggal boleh mengecam kedua-dua `Kod QR` dan kod bar.

Menyokong pemilihan Gambar dari Album untuk pengecaman.

#### Benarkan Pengubahsuaian Hasil Imbasan

Maklumat yang diimbas boleh diubah suai secara lalai. Jika pilihan untuk melarang pengubahsuaian hasil imbasan diaktifkan, output imbasan tidak boleh disunting.

## Penggunaan Lanjutan

Maklumat yang diperoleh melalui imbasan Kod QR atau kod bar boleh digabungkan menjadi Pautan untuk mencetuskan pengalihan halaman.

Sebagai contoh, ini terpakai pada senario seperti mengimbas untuk melihat butiran produk atau mengimbas untuk membuat pesanan makanan.

Hasil:

<Frame>
  ![](https://gw.alicdn.com/imgextra/i4/O1CN01AZOnGllQWKI1SNne_!!6000000002376-2-tps-718-292.png)
</Frame>

**Laluan:** Teks satu baris >> Premium >> Cipta Tindakan dan konfigurasikan URL tetap.

**Contoh:** Semasa menulis JS untuk Tindakan baharu, konfigurasikan URL tetap. Apabila imbasan berjaya, maklumat yang ditangkap akan dihantar sebagai parameter URL untuk mengalihkan ke URL tetap yang telah ditetapkan bagi melihat butiran, membolehkan pengalihan halaman automatik selepas imbasan berjaya.

Konfigurasi rujukan:

<Frame>
  ![](https://gw.alicdn.com/imgextra/i3/O1CN01DdFyeZPSbfK3sYsf_!!6000000000093-2-tps-1911-894.png)
</Frame>

**Nota:** Kemas kini bahagian yang diserlahkan dalam kod agar sepadan dengan pengecam unik yang ditunjukkan di sebelah kanan.

**Pengecam unik:** Serupa dengan kad pengenalan bagi setiap kawalan. Setiap kawalan mempunyai pengecam unik yang berbeza.

<Frame>
  ![](https://gw.alicdn.com/imgextra/i4/O1CN01THsOeGmbnYC3sYsh_!!6000000005471-2-tps-1911-896.png)
</Frame>

**Kod JS rujukan yang boleh anda tampal dan guna:**

```javascript
export function onScanCodeSuccess(text) {
  const fieldId = 'editorField_klbopk6r';
  // Jika teks tidak bermula dengan http atau https, jangan paparkan teks di bawah.
  if (!/^http(s)/.test(text)) {
    this.$(fieldId).setValue(null);
    return text;
  }
  const html = `<div><span style="color: #0089ff;"><a style="color: #0089ff;" href="${text}" target="_blank">Klik untuk melihat rekod kebolehkesanan</a></span></div>`;
  // Tetapkan nilai
  this.$(fieldId).setValue(html);
  // Nota: peristiwa onScanCodeSuccess mesti mengembalikan text; jika tidak, nilai tidak akan diisi dengan betul.
  return text;
}
```
