Artikel ini menyenaraikan semua fungsi teks yang tersedia dalam YiDA.

## Gambaran Keseluruhan Fungsi

| **Nama fungsi** | **Penerangan** |
|---|---|
| [ARRAYGET](/yida/form/mggsmf) | Mengembalikan nilai pada kedudukan yang ditentukan dalam set data. |
| [CONCATENATE](/yida/form/mbe6045dlu6ebg33) | Menggabungkan beberapa string teks menjadi satu string. |
| [LEFT](/yida/form/xylna43s4gpoyz9k) | Mengembalikan bilangan aksara yang ditentukan dari permulaan string teks. Jika teks tersebut lebih pendek daripada panjang yang ditentukan, teks asal akan dikembalikan. |
| [RIGHT](/yida/form/ch2gvwhzh2bn9u82) | Mengembalikan bilangan aksara yang ditentukan dari hujung string teks. |
| LEN | Mengembalikan bilangan aksara dalam string teks. |
| [LOWER](/yida/form/aire3ioygvfi7vul) | Menukar semua huruf besar dalam string teks kepada huruf kecil. |
| [UPPER](/yida/form/fm0og6ccdh0n0q2k) | Menukar semua huruf kecil dalam string teks kepada huruf besar. |
| [MID](/yida/form/pghawu8hdwng91in) | Mengembalikan bilangan aksara yang ditentukan daripada string teks, bermula pada kedudukan yang ditentukan. |
| [PINYINHEADCHAR](/yida/form/dvfmdhg8i3ohg0c4) | Mengembalikan huruf pinyin pertama bagi setiap aksara Cina dalam string, dalam huruf besar. |
| [REPLACE](/yida/form/gtz0638tp96gbnhf) | Menggantikan sebahagian daripada string teks dengan string lain, berdasarkan bilangan aksara yang ditentukan. |
| [REPT](/yida/form/scd5m0bi74omfpyg) | Mengulang teks sebanyak bilangan yang ditentukan. |
| [RMBFORMAT](/yida/form/ff4mghegi9kbsc7m) | Memformat nombor dalam format Yuan China (RMB). |
| [SEARCH](/yida/form/mhwnrwy04c03o2z4) | Mengembalikan kedudukan permulaan teks 1 dalam teks 2. |
| [SPLIT](/yida/form/yf6hkwf5lzcyin93) | Membahagikan teks kepada array berdasarkan pembatas yang ditentukan. Gunakan bersama ARRAYGET untuk mendapatkan aksara pada kedudukan yang ditentukan. |
| [TEXT](/yida/form/bt0wov266h45hpi4) | Memformat nilai sebagai teks. |
| [TRIM](/yida/form/tzmpoqk3e4szn7ar) | Mengalih keluar ruang dari permulaan dan hujung string, sambil mengekalkan satu ruang antara setiap perkataan. |
| [UUID](/yida/form/xb7gg8vrhik5yg5s) | Menjana string unik dan menetapkannya kepada medan teks satu baris. |
| [VALUE](/yida/form/awk6sfyg9vcqe1g1) | Menukar teks kepada nombor. Biasanya digunakan apabila data telah dimasukkan dan perlu dikira semula. |
