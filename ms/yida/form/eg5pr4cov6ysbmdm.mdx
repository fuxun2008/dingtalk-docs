Butang tindakan pada halaman senarai pengurusan data merupakan tindakan pengurusan dan konfigurasi bagi butiran data. Anda boleh menetapkan item tindakan tersuai berdasarkan keperluan perniagaan anda.

## **Langkah**

1. Log masuk ke workbench YiDA dan klik Aplikasi Saya.
2. Pilih aplikasi yang ingin anda edit dan klik untuk masuk ke halaman Urus Aplikasi.
3. Pilih borang sasaran, kemudian klik Jana halaman pengurusan data.

| **Atribut** | **Penerangan** |
|---|---|
| **Nama tindakan** | Nama tersuai untuk butang lajur tindakan. Maksimum 20 aksara. |
| **Pautan pengalihan** | Menyokong dua jenis pengalihan berikut:<br />• **Halaman dalam aplikasi**: Klik kotak input untuk memilih halaman dalam aplikasi.<br />• **Pautan luaran**: Pautan luaran tersuai. Masukkan URL secara terus. |
| **Parameter tersuai** | Anda boleh mengonfigurasi parameter tersuai untuk pautan pengalihan. Tiga jenis parameter berikut disokong:<br />• **Pemalar**: Tetapkan nilai tetap untuk parameter yang dibawa apabila pautan mengalih.<br />• **Medan**: Pilih medan borang daripada borang pengurusan data semasa.<br />• **Formula**: Tetapkan parameter menggunakan formula. Untuk cara menggunakan formula, lihat [Fungsi formula](/yida/form/gvtpe4). |
| **Kaedah buka** | Cara halaman sasaran dibuka selepas pengguna mengklik butang tindakan.<br />• **Tetingkap baharu**: Membuka halaman baharu dalam tetingkap baharu.<br />• **Bar sisi**: Membuka halaman baharu di sebelah kanan halaman. |

8. Klik Simpan untuk melengkapkan konfigurasi.
9. Kembali ke halaman pengurusan data untuk melihat butang tindakan tersuai yang telah dikonfigurasi.

Seperti yang ditunjukkan dalam rajah di bawah, butang tersuai telah berjaya ditambah.
