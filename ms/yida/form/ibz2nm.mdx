## 1. Kes Penggunaan

Pilih satu item daripada pelbagai opsyen dropdown. Komponen ini sesuai apabila terdapat banyak opsyen. Anda boleh menyesuaikan kandungan opsyen, dan ia juga menyokong senario seperti [**keterkaitan data**](/ms/yida/form/arpur0) dan [**mengaitkan borang lain**](/ms/yida/form/tg64d5). Contohnya, gunakan komponen Dropdown select untuk medan seperti jenis cuti atau jantina dalam borang permohonan cuti.

Jika opsyen berasal daripada borang lain dan, selepas pemilihan, maklumat berkaitan perlu diisi ke dalam borang (senario perkaitan data)—contohnya, dalam senario pengurusan kontrak di mana kontrak atau pesanan dicipta dan opsyen komponen borang berkaitan dikaitkan dengan jadual pelanggan untuk menarik masuk maklumat pelanggan—gunakan komponen [**borang berkaitan**](/ms/yida/form/agd540) sebagai gantinya.

**Nota: Panjang maksimum nilai opsyen dalam komponen Dropdown select ialah 255 aksara.**

<Note>
Untuk atribut komponen, penggunaan, dan contoh, lihat [**Antara muka komponen**](/ms/open/yida/components/interface).

### 3.2 Nilai Opsyen dan Nilai Paparan Boleh Berbeza

Nilai opsyen dan nilai paparan boleh berbeza, memberikan anda fleksibiliti untuk senario seperti sokongan berbilang bahasa atau menukar nilai paparan.

Nilai opsyen dan nilai paparan.

### 3.3 Perbezaan Antara Komponen Dropdown Select dan Borang Berkaitan

Kedua-dua komponen ini berbeza dari segi definisi ciri dan kes penggunaan.

#### 3.3.1 Dropdown Select

**Sumber opsyen**: Opsyen tersuai, diperoleh daripada borang lain, diperoleh daripada sumber data jauh, atau diperoleh melalui keterkaitan data.

**Kes penggunaan**: Biasanya digunakan untuk senario pemilihan opsyen yang tidak memerlukan penarikan data tambahan. Contohnya, gunakan komponen Dropdown select untuk medan seperti jenis cuti atau jantina dalam borang permohonan cuti.

#### 3.3.2 Borang Berkaitan

**Sumber opsyen**: Diperoleh daripada borang lain.

**Kes penggunaan**: Biasanya digunakan untuk senario perkaitan data. Contohnya, dalam senario pengurusan kontrak, apabila mencipta kontrak atau pesanan, kaitkan opsyen komponen borang berkaitan dengan jadual pelanggan untuk menarik masuk maklumat pelanggan.
