### 2.3 Penerangan

Penerangan memberikan maklumat tambahan mengenai komponen, dan sering digunakan untuk menerangkan fungsi, Skop, atau arahan pengisiannya. Anda boleh memasukkan Teks atau Sisipkan Pautan.

### 2.4 Status

Tetapkan status lalai komponen medan. Anda juga boleh mengawal status melalui Kebenaran.

Contohnya:

<Frame>
  ![](https://gw.alicdn.com/imgextra/i2/O1CN01TFYO5SXPyEH3sJGr_!!6000000002098-2-tps-1909-892.png)
</Frame>

Status komponen.

- **Normal**: Boleh dilihat dan boleh disunting.

- **Nyahaktifkan**: Boleh dilihat tetapi tidak boleh disunting. Berbeza daripada Baca Sahaja, atribut medan masih dipaparkan.

- **Baca Sahaja**: Boleh dilihat tetapi tidak boleh disunting.

- **Tersembunyi**: Medan tidak boleh dilihat dan tidak boleh disunting.

#### 2.6.6 Fungsi Tersuai (Pengesahan Premium)

Kemahiran pengekodan asas adalah disyorkan, tetapi bukan pembangun juga boleh menggunakan semula sampel kod di bawah.

**Contoh 1**: Semak sama ada input mengandungi "雨" (hujan).

**Nota**: Mesej ralat untuk pengesahan fungsi tersuai adalah wajib; jika tidak, pengesahan mungkin tidak berfungsi.

<Frame>
  ![](https://gw.alicdn.com/imgextra/i1/O1CN01cDUSMWBaDaK3sR4i_!!6000000006979-2-tps-1910-890.png)
</Frame>

Konfigurasikan fungsi tersuai.

Anda boleh menyalin kod JavaScript berikut sebagai rujukan:

<Frame>
  ![](https://gw.alicdn.com/imgextra/i1/O1CN01EmFiYKL5TjI3rB1t_!!6000000002611-2-tps-1900-893.png)
</Frame>

```javascript
// Sama ada input mengandungi "雨" (hujan)
function validateRule(value) {
  if (value.indexOf('雨') > -1) {
    return true;
  }
  return false;
}
```

**Contoh 2**: Semak sama ada input bermula dengan "杭州" (Hangzhou).

```javascript
// Sama ada input bermula dengan "杭州" (Hangzhou)
function validateRule(value) {
  if (/^杭州/.test(value)) {
    return true;
  }
  return false;
}
```

**Contoh tambahan:**

```javascript
// Sama ada input mengandungi ruang
function validateRule(value) {
  if(/s/.test(value)){
    return false;
  }
  return true;
}
```

```javascript
// Sama ada input ialah nombor kad bank (semakan panjang asas)
function validateRule(value) {
  var regExp = /^([1-9]{1})(d{15}|d{18})$/;
  return regExp.test(value)
}
```

```javascript
// Sama ada input ialah nombor kad bank standard (kad UnionPay China Tanah Besar)
function validateRule(value) {
  value = (value + '').replace(/D+/g, '')
  const regExp = /^([1-9])(d{15}|d{18})$/
  // Semak bahawa ia tidak bermula dengan 0 dan mempunyai panjang yang betul
  if (!regExp.test(value)) {
    return false
  }
  value = value.split('').reverse();
  let total = 0
  for (let i = 0; i < value.length; i++) {
    value[i] = parseInt(value[i]);
    total += i % 2 ? 2 * value[i] - (value[i] > 4 ? 9 : 0) : value[i];
  }
  if (total === 0) {
    return false;
  }
  return (total % 10) === 0;
 }
```

Penghargaan khas kepada @n233333 atas penyelesaian pengesahan kad bank yang ringkas ini.

## 3. Premium

### 3.1 Pengecam Unik

Pengecam unik medan semasa digunakan untuk penyimpanan data pada bahagian belakang YiDA dan untuk kawalan secara pengaturcaraan. Ia berfungsi seperti kad pengenalan bagi setiap komponen—setiap komponen mempunyai pengecam unik yang berbeza. Ia secara amnya tidak perlu diubah, dan nilai lalainya dijana oleh sistem.

<Note>
Pengecam unik medan (fieldId) ialah cara YiDA merujuk kepada medan tersebut. Mengubahnya akan menjejaskan mana-mana Formula, penyimpanan data (data juga mungkin hilang), dan rujukan fungsi JS yang menggunakan medan ini. Kami amat **tidak menggalakkan** anda mengubahnya.
</Note>

### 3.5 Padam dan Salin

**Petua: Padam komponen dengan berhati-hati, kerana memadam medan borang boleh menyebabkan Formula, peraturan perkaitan perniagaan, dan konfigurasi lain menjadi tidak sah.**

**Jika apl anda masih dalam pembinaan, belum dilancarkan secara langsung, dan belum mempunyai sebarang data, memadam medan tidak akan memberi banyak kesan.**

**Jika apl anda sudah dilancarkan secara langsung dan mempunyai data, kami tidak menggalakkan anda memadam medan. Berbuat demikian boleh menyebabkan Formula dan peraturan perkaitan perniagaan yang telah Dikonfigurasi menjadi tidak sah, serta boleh menyebabkan data medan berkaitan hilang. Sebaliknya, tetapkan medan tersebut sebagai medan Tersembunyi. Untuk berbuat demikian:**
