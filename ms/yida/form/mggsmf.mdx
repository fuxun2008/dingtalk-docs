## Senario produk yang disokong

Fungsi ARRAYGET disokong dalam senario YiDA berikut:

- Borang (medan jadual utama)
- Borang (peraturan perkaitan perniagaan)
- Borang (pengesahan)
- Reka bentuk aliran kerja (peraturan pengesahan)
- Reka bentuk aliran kerja (tindakan berkaitan)
- Integrasi dan automasi
- Nod aliran kerja
- Penyambung

## Sintaks

```text
ARRAYGET(array, k)
```

## Penerangan atribut

| **Atribut** | **Wajib** | **Penerangan** |
|---|---|---|
| array | Ya | Set data untuk mendapatkan semula data. Jenis Array. |
| k | Ya | Kedudukan elemen dalam set data, bermula daripada 1. |

## Nilai pulangan

| **Jenis pulangan** | **Penerangan** |
|---|---|
| Teks | Nilai pada kedudukan tertentu dalam set data. |
