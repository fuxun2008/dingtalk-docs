### 1.2 Kes Penggunaan

- Komponen Lokasi menyokong kedudukan pada peranti mudah alih, membolehkan anda mengisi maklumat alamat dengan pantas sambil masih membenarkan penyuntingan lanjut.
- Jika alamat yang ingin anda pilih ialah lokasi semasa anda, ketik ikon kedudukan pada peranti mudah alih (dengan kebenaran lokasi diaktifkan). Alamat akan diisi secara automatik dan kekal boleh disunting.
- Biasa digunakan untuk senario pemilihan alamat seperti alamat penghantaran dan alamat wilayah pentadbiran.
- Komponen ini telah dipramuat dengan data terkini Wilayah / Bandar / Daerah (Kaunti) / Jalan (Kampung) China. Cukup tambah Komponen Lokasi untuk mula menggunakannya.

## 2. Atribut

### 2.1 Petua Ruang Letak

- Serupa dengan teks ruang letak kelabu dalam kotak input standard, digunakan untuk memberikan panduan.
- Jika tiada alamat lalai ditetapkan, petua ruang letak akan dipaparkan. Jika tidak, kandungan alamat lalai diutamakan.

<Accordion id="q2" title="4.2 Bolehkah garis miring dalam kawalan Lokasi dialih keluar? Apabila data diambil dan digabungkan ke dalam medan Teks satu baris, bolehkah garis miring dialih keluar secara automatik, contohnya menggunakan JS?">
  Selepas mendapatkan maklumat wilayah, gunakan JS untuk memproses hasil dan menetapkannya kepada medan Teks satu baris untuk mengalih keluar "/".

  ```javascript
  // Kod rujukan (diikat kepada Komponen Lokasi)
  export function onChange({ value }, extra) {
    if (value.regionText) {
      let allAddress = '';
      value.regionText.map(el => {
        allAddress += el.zh_CN
      })
      allAddress += value.address
      this.$('textField_kr49k4ug').setValue(allAddress)
    }
  }
  ```
