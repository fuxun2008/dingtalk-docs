**UUID** menjana string rawak.

## Senario Disokong

Fungsi UUID tersedia dalam senario YiDA berikut:

- Borang (Medan Jadual utama)
- Borang (peraturan Perkaitan perniagaan)
- Borang (pengesahan)
- Reka bentuk aliran kerja (peraturan pengesahan)
- Reka bentuk aliran kerja (Tindakan Perkaitan)
- Integrasi & Automasi
- Nod aliran kerja
- Penyambung

## Sintaks

```text
UUID()
```

## Nilai Pulangan

| **Jenis pulangan** | **Penerangan** |
|---|---|
| Teks | String rawak yang dijana. |

Jana string unik dan tetapkannya kepada Medan input satu baris.
