## 1. Peraturan Pengesahan

### 1.1 Kes Penggunaan Peraturan Pengesahan Borang

(1) Semak sama ada data dalam borang memenuhi peraturan yang ditetapkan. Apabila peraturan pengesahan dicetuskan, data tidak boleh dihantar; apabila tidak dicetuskan, penghantaran dibenarkan.

(2) Teks prompt untuk menyekat penghantaran akan muncul apabila peraturan pengesahan dicetuskan.

(3) Peraturan pengesahan ditulis menggunakan [**formula YiDA**](/ms/yida/form/gvtpe4).

**Laluan untuk menetapkan peraturan pengesahan**: Halaman edit borang >> klik Tetapan Borang di penjuru kanan atas >> Pengesahan formula.

**Nota**: Pengesahan ini pada masa ini tidak berkuat kuasa dalam Integrasi & Automasi atau peraturan perkaitan perniagaan bagi borang biasa.

## 2. Senario Kes dan Langkah Operasi

### 2.1 Senario Kes

Borang kemasukan maklumat invois mengandungi empat medan: nombor invois, tarikh invois, jenis invois dan amaun invois. Data hanya boleh dihantar apabila semua syarat pengesahan berikut dipenuhi:

(1) Nombor invois: sahkan keunikan.

(2) Tarikh invois berada dalam tempoh 30 hari.

(3) Amaun invois berada antara 0 dan 50,000.

### 2.2 Langkah Operasi

(1) Pergi ke Tetapan Borang >> Atribut di sebelah kanan >> Tambah formula.

Halaman edit formula.

(2) Tetapkan syarat pertama: keunikan nombor invois.

**Nota**: Fungsi [**EXIST**](/ms/yida/form/vwncwe) mengesahkan keunikan medan borang (penyahduaan) dengan menyemak sama ada nilai parameter sudah wujud dalam data yang dihantar.

Format formula: `EXIST(Invoice Number)`. Ini menyemak sama ada nombor invois yang dihantar sudah wujud dalam data yang dihantar. Jika sudah wujud, penghantaran disekat; jika tidak, penghantaran dibenarkan.

Seperti ditunjukkan di bawah:

Menggunakan fungsi EXIST.

Prompt ralat.

(3) Klik Tambah formula dan tetapkan syarat kedua: tarikh invois dalam tempoh 30 hari.

Formulanya ialah: `GE(DAYS(TODAY(),DATE(Invoice Date)),30)`.

Untuk butiran penggunaan fungsi, lihat [**Penggunaan fungsi logik**](/ms/yida/form/mnx96u) dan [**Penggunaan fungsi tarikh**](/ms/yida/form/dh7m8n).

</Frame>

Menggunakan formula GE(DAYS(TODAY(),DATE())).

Prompt ralat.

(4) Akhir sekali, tetapkan syarat pengesahan untuk amaun invois: amaun invois antara 0 dan 50,000.

Formulanya ialah: `OR(LE(Invoice Amount,0),GE(Invoice Amount,50000))`. Ini bermakna penghantaran tidak dibenarkan apabila amaun invois kurang daripada atau sama dengan 0, atau lebih besar daripada atau sama dengan 50,000. Untuk penggunaan fungsi, lihat [**Penggunaan fungsi logik**](/ms/yida/form/mnx96u).

Kaedah: Konfigurasikan fungsi `EXIST(Product Category)` dalam area pengesahan borang.
