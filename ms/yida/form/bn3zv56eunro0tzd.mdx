# ISOWEEKNUM

**ISOWEEKNUM** 函数用于获取指定日期的 ISO 周数。ISO 周数根据 ISO 8601 标准来确定某一周在一年中的位置。

ISO 8601 规定每周从星期一开始，每年的第一周是包含该公历年第一个星期四的那一周。

**ISOWEEKNUM** 函数用于获取指定日期的 ISO 周数。ISO 周数根据 ISO 8601 标准来确定某一周在一年中的位置。

ISO 8601 规定每周从星期一开始，每年的第一周是包含该公历年第一个星期四的那一周。

## 支持的产品场景

ISOWEEKNUM 函数可用于以下 YiDA 场景。

- Form（主表 Field）
- Form（业务 Association rule）
- Form（validation）
- workflow design（validation rule）
- workflow design（Association Action）
- integration & automation
- Workflow node
- Connector

## Format

```text
ISOWEEKNUM(date)
```

## Attribute 说明

| **Attribute** | **Required** | **说明** |
|---|---|---|
| date | Yes | Time object。 |

## Back Value

| **Back value Type** | **说明** |
|---|---|
| Number | 返回该日期的 ISO 周数。 |
