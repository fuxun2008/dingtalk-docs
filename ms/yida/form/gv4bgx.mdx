<Note>
Edisi berkenaan: edisi berbayar

**Prasyarat:**

- Seni bina maklumat lama tidak disokong.
- Storan carian lama tidak disokong. Keupayaan carian baharu telah dinaik taraf.
- Pelan Percuma tidak disokong.
- Hanya borang biasa dan borang aliran kerja disokong.
</Note>

## 1. Pengenalan

### 1.1 Gambaran Keseluruhan Ciri

Apabila menggunakan keterkaitan data komponen, mengaitkan data daripada borang lain, atau komponen borang berkaitan untuk penapisan data/pengisian data, anda boleh membuat pertanyaan data borang merentas aplikasi. Anda perlu mencipta set data merentas aplikasi terlebih dahulu.

**Laluan**: Tetapan Aplikasi > Pengurusan Data Aplikasi > Set Data > Cipta Set Data > Cipta daripada Merentas Aplikasi. Untuk maklumat lanjut, lihat [Cipta set data daripada merentas aplikasi](/yida/app-admin/btrtnt).

### 1.2 Contoh Senario

Kebanyakan syarikat mengumpulkan pengurusan kontrak, pengurusan projek, pengurusan kewangan, dan pengurusan perolehan ke dalam aplikasi berasingan. Apabila kakitangan kewangan perlu memperoleh barangan, mereka mesti mengaitkan permintaan pembelian dengan borang kelulusan kontrak. Tanpa keupayaan membuat pertanyaan data merentas aplikasi, permintaan pembelian tidak dapat dikaitkan dengan borang kontrak. YiDA kini menyediakan keupayaan untuk mendapatkan dan membuat pertanyaan data borang merentas aplikasi, yang menyelesaikan isu ini.

## 2. Gambaran Keseluruhan Keupayaan

Ini terpakai untuk membuat pertanyaan data daripada borang lain merentas aplikasi. Hanya pertanyaan data jadual bercantum disokong.

### 2.1 Komponen yang Disokong

Pertanyaan data borang merentas aplikasi kini menyokong komponen berikut:

- Keterkaitan data: Teks satu baris, Teks pelbagai baris, Numerik, Tarikh, Muat naik gambar, Lampiran, Pengguna & Jabatan, Radio, Radio lungsur, Kotak semak, Kotak semak lungsur.
- Perkaitan dengan data daripada borang lain: Radio, Radio lungsur, Kotak semak, Kotak semak lungsur.
- Tetapan paparan/penapisan data/pengisian data: Borang berkaitan.

### 2.2 Keterkaitan Data

Apabila menggunakan ciri keterkaitan data pada komponen, kedua-dua nilai Lalai dan jenis pilihan menyokong pemilihan borang merentas aplikasi.

<Frame>
  ![](https://gw.alicdn.com/imgextra/i1/O1CN01OFS0DBAWtvK5qI66_!!6000000000361-2-tps-2878-1428.png)

### 2.3 Kaitkan Data daripada Borang Lain

Apabila komponen Radio, Radio lungsur, Kotak semak, atau Kotak semak lungsur digunakan untuk mengaitkan data daripada borang lain, anda boleh memilih borang merentas aplikasi.

<Frame>
  ![](https://gw.alicdn.com/imgextra/i2/O1CN01xkYs25rRrFD5pHfM_!!6000000003482-2-tps-2870-1450.png)
</Frame>

### 2.4 Borang Berkaitan

Komponen borang berkaitan boleh memilih borang merentas aplikasi yang anda mempunyai kebenaran untuk mengaksesnya, dan boleh digunakan untuk penapisan data dan pengisian data.

<Frame>
  ![](https://gw.alicdn.com/imgextra/i3/O1CN01z2FlER8VOLK5pXGq_!!6000000000072-2-tps-2872-1432.png)
</Frame>

### 2.5 Bilangan Maksimum Borang Merentas Aplikasi

| **Edisi** | **Bilangan maksimum borang merentas aplikasi bagi setiap aplikasi** |
|---|---|
| Pelan Percuma | Tidak disokong. Naik taraf edisi anda untuk menggunakan ciri ini. |
| Edisi berbayar<br />(edisi berbayar selain Edisi Profesional, seperti Edisi Basic dan Edisi Pendidikan) | 50 |
| Edisi Profesional | 100 |

### 2.6 Nota

Pembacaan data borang merentas aplikasi melibatkan titik masuk seperti formula dan Integrasi & Automasi. Untuk maklumat lanjut, lihat Kemas kini versi 27 April 2022 – Baca/tulis data borang merentas aplikasi.

## 3. Soalan Lazim

### 3.1 Adakah Pelan Percuma Menyokong Pertanyaan Data Borang Merentas Aplikasi?

Mencipta set data daripada merentas aplikasi merupakan ciri berbayar, jadi Pelan Percuma YiDA tidak menyokong pertanyaan data borang merentas aplikasi.

Untuk soalan lazim lanjut, lihat [Cipta set data daripada merentas aplikasi](/yida/app-admin/btrtnt).
