Gunakan glosari ini sebagai rujukan pantas apabila anda perlu mengesahkan maksud istilah YiDA tertentu semasa membina atau mengkonfigurasi aplikasi anda.

## **Workbench**

| **Istilah** | **Definisi** |
|---|---|
| [Mula](https://www.yidaapps.com/start.html) | Selepas anda log masuk ke YiDA dan klik Workbench, anda akan tiba di halaman Mula dahulu. Halaman ini merupakan hab komprehensif tempat anda boleh melihat gambaran keseluruhan maklumat penting. |
| [Galeri Templat](/yida/intro/le1tkr) | Semak imbas templat dalam Galeri Templat untuk melihat apa yang boleh dilakukan oleh YiDA dan hasil yang boleh anda capai. |
| [Penyelesaian](https://www.yidaapps.com/isvSolution.html?spm=a1ztuy.21010213.0.0.1a3a6ddbbEe5HW) | Penyelesaian khusus industri yang disediakan oleh penyedia perkhidmatan bertauliah YiDA. Mereka menawarkan penyesuaian yang fleksibel, cekap, dan disesuaikan untuk memastikan penyelesaian akhir benar-benar sesuai dengan perniagaan anda. |
| [Pusat Aplikasi](/yida/exclusive/fcax011ixce3bywe) | Memaparkan aplikasi yang telah dikeluarkan dalam YiDA atau aplikasi templat yang telah diaktifkan. |
| Aplikasi Saya | Aplikasi Saya memaparkan antara muka yang boleh dilihat oleh pengguna yang sedang log masuk. Antara muka ini berbeza berdasarkan kebenaran pengguna. |
| [Pusat Tugasan](/yida/process/hg13tb) | Pusat Tugasan mengagregatkan borang dan rekod aliran kerja yang telah anda hantar dalam aplikasi YiDA. Anda boleh melihat butiran borang yang dihantar dan aliran kerja yang memerlukan tindakan anda. |
| Pusat Penyesuaian | Penyedia perkhidmatan bertauliah membina aplikasi perniagaan yang disesuaikan dengan keperluan Organisasi Anda. Untuk menyediakan perkhidmatan yang lebih meluas dan berkualiti tinggi, kami telah menambahkan titik masuk penyesuaian pada halaman Mula YiDA. |
| Pusat Bantuan | Panduan Pengguna YiDA, termasuk video, kajian kes, dan dokumentasi terperinci. |
| [Versi](/yida/process/daeh3v) | Bagi penyewa YiDA yang diaktifkan selepas 7 Januari 2021, halaman ini memaparkan edisi anda: Pelan Percuma, Edisi Basic, atau Edisi Profesional. |
| [Pengurusan platform](/yida/platform-admin/omvowq) | Titik masuk untuk mengkonfigurasikan kebenaran admin platform, templat mesej, peranan, dan kenalan. |

## **Borang Biasa**

| **Istilah** | **Definisi** |
|---|---|
| [Borang biasa](/yida/app-admin/mff60m) | Borang biasa terdiri daripada beberapa komponen dan digunakan untuk mengumpul dan menghantar data. |
| [Komponen](/yida/form/snftao) | Bekas untuk menyimpan data. Jenis komponen yang berbeza menyimpan jenis data yang berbeza. Contohnya, komponen numerik menyimpan data numerik, dan komponen teks menyimpan data teks. |
| [Penyuntingan formula](/yida/form/gvtpe4) | Semasa mengisi atau menyunting data borang, anda boleh menetapkan nilai komponen dikira secara automatik berdasarkan formula. Ini meningkatkan kecekapan kemasukan data dan mengurangkan ralat. |
| [Kaitkan data daripada borang lain](/yida/form/tg64d5) | Gunakan tetapan perkaitan untuk menarik data daripada borang berkaitan ke dalam borang semasa. |
| [Keterkaitan data](/yida/form/arpur0) | Apabila nilai satu medan dalam borang berubah, nilai medan lain dalam borang yang sama akan berubah mengikutnya. Ini sering digunakan untuk menetapkan nilai lalai bagi komponen. |
| [Peraturan perkaitan perniagaan](/yida/form/ydmx04) | Peraturan perkaitan perniagaan digunakan apabila data dalam dua borang saling berkaitan. Contohnya, dalam pengurusan inventori, rekod masuk dan keluar mesti diagregatkan ke dalam jadual inventori akhir untuk dipaparkan dan disemak. |

## **Borang Aliran Kerja**

| **Istilah** | **Definisi** |
|---|---|
| [Borang aliran kerja](/yida/process/crwfii) | Borang yang mempunyai aliran kerja. Berbanding dengan borang biasa, borang aliran kerja mempunyai peringkat penghalaan aliran kerja tambahan. |
| [Tetapan aliran kerja](/yida/process/crwfii) | Konfigurasikan peraturan penghalaan bagi data dalam borang aliran kerja supaya data mengalir mengikut aliran kerja yang telah ditetapkan. |
| [Langkah](/yida/process/rq8i94) | Setiap peringkat dalam aliran kerja dipanggil langkah. Untuk setiap langkah, anda boleh mengkonfigurasikan keterlihatan dan kebolehsuntingan komponen, serta penyokong, pelaksana, dan pengguna CC. |
| [Peraturan penghantaran langkah](/yida/process/emt041) | Peraturan penghantaran langkah menggunakan semakan formula untuk menentukan sama ada pengguna boleh menghantar aliran kerja atau penyokong boleh memproses aliran kerja apabila mereka mengambil tindakan. |

## **Laporan**

| **Istilah** | **Definisi** |
|---|---|
| [Pereka bentuk laporan](/yida/report/qocbxw) | Apabila anda perlu mengagregatkan data yang dihantar oleh pekerja untuk semakan, cipta halaman laporan dan gunakan komponen dalam pereka bentuk laporan untuk menganalisis, mengagregatkan, dan menanya data. |
| Komponen laporan | Memaparkan data yang dihantar dalam borang sebagai carta. |
| [Formula laporan](/yida/form/yrofmw) | Digunakan untuk memproses data daripada borang asal. |
| [Set data](/yida/app-admin/roe3o1) | Apabila komponen carta laporan memaparkan data, pilih borang atau Borang aliran kerja dalam aplikasi sebagai set data. |
| [Jadual paparan](/yida/app-admin/oim554) | Jadual paparan memproses data borang sedia ada terlebih dahulu dengan mengaitkan satu jadual atau beberapa jadual. Ia juga menyokong mod jadual perantaraan untuk meningkatkan pemprosesan data. Visualisasi laporan, keterkaitan borang, dan senario lain boleh merujuk data daripada jadual paparan secara langsung. |
| [Merentas aplikasi](/yida/app-admin/btrtnt) | Juga dikenali sebagai "pengambilan data merentas aplikasi." Ia merujuk kepada memanggil data borang daripada aplikasi YiDA lain dalam aplikasi semasa, membolehkan kesalinghubungan data merentas aplikasi YiDA. |

## **Pautan Luaran**

| **Istilah** | **Definisi** |
|---|---|
| [Pautan luaran](/yida/app-admin/nolqql) | Apabila anda perlu memaparkan kandungan daripada laman web lain, tampal URL laman web di sini. |
| [Buka dalam tetingkap baharu](/yida/app-admin/nolqql) | Membuka pautan luaran dalam tetingkap baharu apabila diklik. |

## **Halaman Tersuai**

| **Istilah** | **Definisi** |
|---|---|
| [Halaman tersuai](/yida/custom-page/ynk2lo) | Sesuaikan gaya dan paparkan data daripada semua borang dalam aplikasi untuk fleksibiliti yang lebih besar dalam memenuhi keperluan perniagaan khusus anda. Halaman tersuai lebih kompleks berbanding borang biasa dan biasanya memerlukan konfigurasi kod. |
| [Pereka bentuk halaman tersuai](/yida/custom-page/lo24cx) | Pereka bentuk halaman tersuai terdiri daripada empat bahagian: **bar tindakan atas**, **bar alat kiri**, **kanvas tengah**, dan **panel konfigurasi atribut kanan**. |

## **Ciri Premium**

| **Nama** | **Definisi** |
|---|---|
| [Nombor siri](/yida/form/rom39o) | Menjana pengenal unik secara automatik selepas data borang dihantar. Ia biasa digunakan untuk menomborkan item dalam senario pengurusan inventori. |
| [Penyediaan data](/yida/app-admin/rgaipwu0l1c9dw3t) | Penyediaan data merujuk kepada siri langkah pemprosesan yang dilakukan pada sumber data dan set data sebelum analisis visual, seperti penyisipan multi-jadual dan transformasi data. Ia merupakan langkah awal dalam analisis visual. |
| Orkestrasi logik | Dalam senario tertentu, penghantaran borang mencetuskan logik perniagaan. YiDA kini menyokong dua aliran logik perniagaan teras terbina dalam—rekod dan aliran kerja—bersama aliran logik sekunder seperti komen.<br />Setiap aliran logik perniagaan mempunyai kitaran hayatnya sendiri. Peristiwa dipancarkan pada setiap peringkat kitaran hayat dan boleh digunakan sebagai titik lanjutan. Setelah peristiwa diterima, plugin pelaksanaan yang berkaitan akan dijalankan untuk melaksanakan logik perniagaan. |
| [Aliran kerja lanjutan](/yida/process/lgrp0w) | Untuk memenuhi keperluan aliran kerja lanjutan, YiDA menyediakan pereka bentuk aliran kerja lanjutan. Ia meliputi hampir semua ciri pereka bentuk standard dan menambah keupayaan tambahan. Contohnya, ia merangkumi komponen seperti **cabang** dan **agregasi**. Ia juga meningkatkan ciri dan tetapan komponen, membezakan antara tetapan asas dan lanjutan. Anda boleh menyesuaikan peraturan pelaksana dan strategi penyelesaian. Editor aliran kerja standard boleh dinaik taraf kepada editor aliran kerja lanjutan. |
| Callback perkhidmatan | Dalam YiDA, sebarang interaksi yang melibatkan pemanggilan perkhidmatan API dikenali sebagai callback perkhidmatan pihak ketiga. Sokongan untuk panggilan API ini membolehkan YiDA berintegrasi dengan sistem luaran dan menukar data, mengelakkan aplikasi YiDA daripada menjadi silo terpencil. |
| [Pengedaran aplikasi](/yida/app-admin/xb5ylm) | Pengedaran aplikasi membantu penyedia perkhidmatan melancarkan aplikasi yang dibangunkan dalam organisasi mereka sendiri dengan pantas kepada penyewa YiDA organisasi pelanggan. Pembangun penyedia perkhidmatan juga boleh mengakses organisasi pelanggan melalui saluran khusus untuk membangunkan ciri tersuai dan mengkonfigurasikan atribut. |
| Pendaftaran perkhidmatan | Pendaftaran perkhidmatan adalah prasyarat untuk menggunakan ciri callback perkhidmatan. Ia melibatkan pendaftaran API perkhidmatan pihak ketiga dengan platform YiDA. Konfigurasi utama termasuk parameter input dan output API, maklumat pengesahan dan penyulitan, kawalan kebenaran, dan penerangan API, supaya API boleh dirujuk dengan pantas apabila diperlukan. |
| [Integrasi & Automasi](/yida/integration/gqmveiswrxkgxu9s) | Menyediakan naik taraf keseluruhan kepada ciri orkestrasi logik dan mengintegrasikan Penyambung DingTalk. Aplikasi rasmi DingTalk, aplikasi dalam ekosistem DingTalk, dan sistem milik perusahaan sendiri boleh diintegrasikan dengan YiDA secara ringan, memberikan aplikasi YiDA interoperasi asli. |
| [Connector Factory](/yida/integration/gqmveiswrxkgxu9s) | Gunakan Connector Factory YiDA untuk membina penyambung tersuai bagi sistem dalaman atau aplikasi pihak ketiga. |
| [Organisasi berkaitan](/yida/platform-admin/ampson) | Dengan ciri **Organisasi berkaitan** DingTalk, sesebuah organisasi boleh mengaitkan sub-organisasi dengan organisasi induk. Semasa perkaitan, anda boleh memilih semua ahli atau ahli jabatan tertentu dalam sub-organisasi untuk menyertai organisasi berkaitan. |
| Papan pemuka DataV | Gunakan pelbagai set data yang telah ditetapkan (termasuk merentas aplikasi, sub-jadual, dan jadual paparan) dengan lancar untuk membina papan pemuka digital yang menarik secara visual, memberikan impak berasaskan data yang mengagumkan kepada aplikasi YiDA anda. |
| **CorpId** | CorpId ialah pengenal unik bagi organisasi DingTalk. Ia diperlukan untuk membeli perkhidmatan, memanggil API, dan operasi lain. CorpId kelihatan seperti: dingfa087xxxx55b. Anda boleh mendapatkan CorpId anda melalui salah satu cara berikut:<br />• Pilihan 1: Lihat pada halaman tetapan platform YiDA. Pergi ke **Laman Utama YiDA** > **Tetapan Platform** > [Maklumat Asas](https://www.yidaapps.com/platformManage/basicInfo).<br />• Pilihan 2: Lihat dalam konsol pembangun DingTalk Open Platform. Untuk butiran lanjut, sila rujuk dokumentasi DingTalk Open Platform. |
