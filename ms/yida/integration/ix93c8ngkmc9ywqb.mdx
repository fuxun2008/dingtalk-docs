## 1. Kes Penggunaan

Organisasi Perkaitan biasanya digunakan dalam senario berikut:

- Komunikasi merentas organisasi, Kelulusan perniagaan, dan pelaporan kerja.
- Pengurusan kebenaran pelbagai organisasi dengan penyegerakan struktur pengguna masa nyata untuk kecekapan pengurusan yang lebih tinggi.

**Langkah:**

```javascript
// Kod ditunjukkan dalam Rajah 2.1-5
// Dapatkan data Komponen Teks pelbagai baris dan tetapkan kepada pemboleh ubah res.
// Gantikan "textareaField_kwlgqhti" dengan pengecam unik Komponen Teks pelbagai baris yang anda cipta.
const res = this.$("textareaField_kwlgqhti").getValue();
// Tukar format data daripada string kepada object.
  let obj = JSON.parse(res);
// Cipta array kosong bernama arr untuk menyimpan data yang telah diproses.
  let arr = [];
// Ulangi object untuk mendapatkan Medan yang perlu dipaparkan.
  const list = obj.map(item => {
    let object = {};
// "textField_kwlgqhtk" dan "textField_kwlgqhtl" adalah pengecam unik bagi dua Komponen Teks satu baris di dalam subborang.
// Gantikan dengan pengecam unik Komponen Teks satu baris yang anda cipta.
    object.textField_kwlgqhtk = item.union_org_name;
    object.textField_kwlgqhtl = item.union_corpid;
    arr.push(object);
  })
// Tulis semula data arr yang telah diproses ke dalam Komponen subborang.
// "tableField_kwlgqhtj" adalah pengecam unik Komponen subborang.
// Gantikan dengan pengecam unik Komponen subborang yang anda cipta.
  this.$("tableField_kwlgqhtj").setValue(arr);
```
