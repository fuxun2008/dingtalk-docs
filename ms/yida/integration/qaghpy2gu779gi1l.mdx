## Langkah

Ikuti langkah-langkah di bawah untuk menggunakan penyambung rasmi dalam Integrasi & Automasi atau borang aliran kerja.

1. Log masuk ke Workbench YiDA.
2. Pilih aplikasi sasaran dan pergi ke halaman **Integrasi & Automasi**.
3. Pilih aliran integrasi & automasi sedia ada dan klik **Edit**.

  <Step title="Tuding kursor ke atas garis penghubung sesuatu Langkah. Apabila butang + muncul, klik butang itu dan pilih Penyambung.">
  </Step>
  <Step title="Dalam panel konfigurasi penyambung di sebelah kanan, pilih DingTalk Rasmi, kemudian pilih penyambung yang ingin anda gunakan.">
  </Step>

Sebagai contoh, gunakan penyambung **Mulakan Instans** di bawah Kelulusan OA.

6. Konfigurasikan tindakan pelaksanaan untuk penyambung tersebut.

Sebagai contoh, konfigurasikan tindakan pelaksanaan untuk penyambung Mulakan Instans.

  ![](https://gw.alicdn.com/imgextra/i1/O1CN0143LbB9TxGZI5Rs9A_!!6000000001126-2-tps-2684-1996.png)

7. Apabila selesai, klik **Simpan**.

## Penyambung Rasmi Disokong

DingTalk kini menyediakan 24 aplikasi rasmi. Setiap aplikasi menawarkan tindakan pelaksanaan yang berbeza untuk mencapai hasil yang berbeza.

| **Nama aplikasi** | **Fungsi** |
|---|---|
| [**Tugasan**](/ms/yida/integration/vs2cqwywsanvmg3o) | Cipta Tugasan DingTalk secara automatik. |
| **Acara** | Cipta Peristiwa. |
| **Perbualan** | Hantar mesej kepada kumpulan organisasi. Nod ini mesti digunakan bersama-sama dengan nod Kumpulan Senario. |
| [**Kumpulan Senario**](/ms/yida/integration/wh85s70zssv2gnck) | Cipta kumpulan senario baharu. |
| [**Mesyuarat Video (jadualkan)**](/ms/yida/integration/qwlh57zqlr4e7047)<br />[**Mesyuarat Video (mula)**](/ms/yida/integration/zx7hyx0awsq2zfb9) | Mulakan atau jadualkan Mesyuarat Video. |
| [**Kehadiran**](/ms/yida/integration/te5kym9fz7u9x8dq) | Cipta kumpulan senario baharu. |
| [**Kenalan**](/ms/yida/integration/ncdt7p3g2db6d11n) | Kemas kini, cipta, atau padam maklumat pengguna dalam Kenalan DingTalk. |
| [**Smart HR**](/ms/yida/integration/imnxrgek49qmqfux) | Tambah maklumat pekerja pra-onboarding selepas satu peristiwa dicetuskan. |
| [**Kumpulan Sembang**](/ms/yida/integration/iqqlaphgykttuihb) | Tambah atau alih keluar ahli kumpulan dan cipta sembang kumpulan. Hanya kumpulan organisasi boleh dicipta; kumpulan standard tidak disokong. |
| **Daftar Masuk** | Dapatkan rekod daftar masuk pekerja. |
| [**Pengisian Borang Pintar**](/ms/yida/integration/og32nngcyadrao3k) | Dapatkan templat pengisian borang pengguna. |
| **Urus Aplikasi** | Tetapkan keterlihatan sesuatu aplikasi. |
| **Log** | Dapatkan kiraan log belum dibaca. |
| **Organisasi Berkaitan** | Dapatkan organisasi cabang atau organisasi induk. |
| **Jadual Kandungan Data** | Dapatkan statistik sembang kumpulan organisasi. |
| **Drive** | Cipta Ruang. |
| **Tugasan 2.0** | Cipta Tugasan. |
| **Meja Perkhidmatan Pekerja** | Hantar mesej peribadi melalui pembantu perkhidmatan. |
| **AI** | Terjemah kandungan antara bahasa, seperti bahasa Cina kepada bahasa Inggeris. |
| [**Pengumuman**](/ms/yida/portal/ik3610wn0kc5twhv) | Terbitkan pengumuman. |
| **Bot** | Hantar mesej menggunakan bot yang ditentukan. |
