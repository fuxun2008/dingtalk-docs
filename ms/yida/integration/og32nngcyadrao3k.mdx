## 1. Kes Penggunaan

Smart Form ialah aplikasi asas yang disediakan oleh DingTalk. Ia sesuai untuk senario seperti tinjauan dan penjejakan pendaftaran, serta menyokong statistik data dan muat turun. Contoh ini menunjukkan cara penghantaran borang dalam YiDA mencetuskan Penyambung yang menyoal templat Smart Form yang dicipta oleh pekerja tertentu.

### 2.4 Langkah 4: Konfigurasikan "Jadual rekod keputusan pertanyaan"

Langkah-langkah sebelum ini menyediakan panggilan Penyambung dan membolehkan data yang dikembalikan diterima. Seterusnya, proses data yang dikembalikan dan paparkan nilai yang telah diproses dalam komponen di dalam subborang "Rekod keputusan pertanyaan".

**Langkah:**

Pada halaman penyuntingan borang, salin kod berikut ke dalam fungsi `didMount` dalam Panel Tindakan JS di sebelah kiri halaman.

(Lihat Rajah 2.4-1.)

<Frame>
  ![](https://gw.alicdn.com/imgextra/i1/O1CN01fhdVBFt0nJG3th8X_!!6000000001381-2-tps-1920-949.png)
</Frame>

Rajah 2.4-1 Kemasukan Panel Tindakan JS dan fungsi didMount

<Note>
Anda boleh menampal kod di bawah terus ke dalam panel JS. Nota: anda mesti menggantikan pengecam unik komponen.
</Note>

```javascript
// Dapatkan data yang dihantar oleh Penyambung ke dalam komponen teks pelbagai baris.
// textareaField_kwcv17cj ialah kod unik komponen teks pelbagai baris "Keputusan yang dikembalikan" pada halaman.
let obj = this.$('textareaField_kwcv17cj').getValue();
// Nilai obj ialah string. JSON.parse() menukar obj kepada object.
  let res = JSON.parse(obj);
// Cipta array kosong "arr" untuk menyimpan data yang telah diproses.
  let arr = []
// Ulangi (iterate) pemboleh ubah res.
  const data = res.map(item=>{
    let object = {};
// Gantikan kod antara "object." dan "=" pada baris 12–21 dengan pengecam unik setiap komponen di dalam subborang.
    object.textField_kwcvykby = item.name;
    object.textField_kwcvykbz = item.memo;
    object.textField_kwcvykbx = item.form_code;
    object.textField_kwcvykc0 = item.setting.form_type === 0 ? "Borang sekali sahaja" : "Borang berulang";
    object.textField_kwcvykc3 = item.setting.form_type === 0 ? "Borang tidak berulang" : item.setting.loop_days;
    object.textField_kwcvykc5 = item.setting.end_time ? item.setting.end_time : "Tiada tarikh akhir ditetapkan";
    object.textField_kwcvykcb = item.setting.create_time;
    object.textField_kwcvykcc = item.setting.biz_type === 0 ? "Borang umum" : "Borang pendidikan";
    object.textField_kwcvykcd = item.setting.stop === false ? "Tidak ditamatkan" : "Ditamatkan";
    object.textField_kwcvykce = item.creator;
// Tambah object yang telah diproses ke dalam array arr. Setiap object mewakili satu rekod subborang.
    arr.push(object);
  })
// Tetapkan data array arr kepada komponen subborang.
// Gantikan tableField_kwd6plxz dengan pengecam unik subborang dalam borang anda.
  this.$("tableField_kwd6plxz").setValue(arr);
```
