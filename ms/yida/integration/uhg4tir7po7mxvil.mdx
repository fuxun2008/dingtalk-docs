Ciri ini hanya boleh menanyakan data sebelum tarikh semasa.

Sebagai contoh, jika hari ini ialah 1 Disember 2021, anda hanya boleh menanyakan data sebelum 1 Disember.
</Warning>

## 1. Kes Penggunaan

Dengan penyambung ini, anda boleh mendapatkan statistik sembang kumpulan organisasi berikut:

- Pengguna sembang kumpulan: bilangan pengguna yang menghantar mesej sembang kumpulan dalam organisasi.
- Kumpulan baharu: bilangan Kumpulan Dalaman baharu yang dicipta dalam organisasi.
- Kumpulan aktif: bilangan Kumpulan Dalaman yang mempunyai mesej dihantar dalam organisasi.
- Mesej sembang kumpulan: bilangan mesej yang dihantar dalam Kumpulan Dalaman dalam organisasi.
- Kumpulan Dalaman: bilangan semasa Kumpulan Dalaman dalam organisasi.
- Perbualan Jabatan: bilangan semasa Perbualan Jabatan.

## 2. Prosedur

### 2.1 Langkah 1: Reka Bentuk Borang

Cipta dua borang — satu untuk mencetuskan penyambung, dan satu lagi untuk menerima serta memaparkan data yang dikembalikan oleh penyambung.

#### 2.1.1 Cipta Borang "Pertanyaan Statistik Sembang Kumpulan Organisasi"

**Langkah:**

1. Cipta borang biasa dan namakannya "Pertanyaan statistik sembang kumpulan organisasi".
2. Tambah komponen Tarikh, namakannya "Tarikh pertanyaan", dan tandakannya sebagai wajib. (Lihat Rajah 2.1-1)

Rajah 2.1-5 Tambah kod JS untuk memproses data

Kod adalah seperti berikut:

Pastikan anda menggantikan pengecam unik komponen.

```javascript
export function didMount() {
  // Dapatkan data yang dikembalikan oleh penyambung. "textareaField_ky16z248" ialah pengecam unik komponen Teks pelbagai baris. Pastikan anda menggantikannya, jika tidak ia tidak akan berfungsi!
  const str = this.$("textareaField_ky16z248").getValue();
  // Proses data
  const obj = JSON.parse(str);
  const val = obj.dataList;
  let arr = [];
  const valList = val.map(item => {
    let valObject = {};
    // Tarikh pertanyaan
    // Gantikan textField_ky16z24k dengan pengecam unik komponen yang anda cipta
    valObject.textField_ky16z24k = item["stat_date"];
    // Pengguna sembang kumpulan
    // Gantikan textField_ky16z24l dengan pengecam unik komponen yang anda cipta
    valObject.textField_ky16z24l = item["4030_DAY"];
    // Kumpulan baharu
    // Gantikan textField_ky16z24j dengan pengecam unik komponen yang anda cipta
    valObject.textField_ky16z24j = item["4031_DAY"];
    // Kumpulan aktif
    // Gantikan textField_ky16z24i dengan pengecam unik komponen yang anda cipta
    valObject.textField_ky16z24i = item["4032_DAY"];
    // Mesej sembang kumpulan
    // Gantikan textField_ky16z24h dengan pengecam unik komponen yang anda cipta
    valObject.textField_ky16z24h = item["4033_DAY"];
    // Kumpulan Dalaman
    // Gantikan textField_ky16z24g dengan pengecam unik komponen yang anda cipta
    valObject.textField_ky16z24g = item["4034_DAY"];
    // Perbualan Jabatan
    // Gantikan textField_ky16z24f dengan pengecam unik komponen yang anda cipta
    valObject.textField_ky16z24f = item["4035_DAY"];
    arr.push(valObject);
  })
  // Berikan data yang telah diproses kepada komponen subborang
  // Gantikan tableField_ky16z24a dengan pengecam unik komponen subborang yang anda cipta
  this.$("tableField_ky16z24a").setValue(arr);
}
```

6. Klik **Simpan** di penjuru kanan atas halaman.
