Contoh ini menunjukkan keseluruhan proses langkah demi langkah: mencipta borang, mengkonfigurasikan integrasi penyambung, dan memulangkan keputusan seperti sama ada seorang pekerja telah daftar masuk, masa daftar masuk, dan lokasi daftar masuk.

## Prasyarat

Sebelum anda bermula, cipta satu aplikasi. Untuk langkah terperinci, lihat [Cipta aplikasi](/yida/app-admin/oncnoy).

## Gambaran Keseluruhan Proses

Dalam artikel ini, anda akan mencipta dua borang biasa: satu untuk merekod keputusan pertanyaan, dan satu lagi untuk mencetuskan penyambung. Langkah-langkahnya adalah seperti berikut:

- Langkah 1: Cipta borang keputusan pertanyaan
- Langkah 2: Cipta borang pertanyaan daftar masuk
- Langkah 3: Konfigurasikan Integrasi & Automasi
- Langkah 4: Terima data dalam borang keputusan pertanyaan
- Langkah 5: Uji dan sahkan

### Hasil Dijangka

Hasil akhir yang dicapai dalam artikel ini ditunjukkan di bawah.

## Langkah 1: Cipta Borang Keputusan Pertanyaan

1. Log masuk ke Workbench YiDA, pilih aplikasi sasaran, dan klik untuk membuka halaman penyuntingan aplikasi.
2. Klik **+** > **Cipta borang biasa**, pilih **Cipta halaman kosong**, dan namakan semula borang tersebut kepada **Keputusan Pertanyaan**.
3. Seret komponen **Teks satu baris**, komponen **Subborang**, dan komponen **Pengguna** ke kawasan kanvas tengah.
4. Namakan semula komponen **Pengguna** kepada **Pengguna Daftar Masuk**.
5. Namakan semula komponen **Teks satu baris** kepada **Penampan Data Penyambung**, dan tetapkan keterlihatannya kepada Tersembunyi.

6. Namakan semula komponen **Subborang** kepada **Rekod Daftar Masuk**.
7. Seret tiga komponen **Teks satu baris** ke dalam komponen **Subborang**.
8. Namakan semula ketiga-tiga komponen **Teks satu baris** tersebut kepada **Masa Daftar Masuk**, **Lokasi Daftar Masuk**, dan **Alias Daftar Masuk**.
9. Klik **Simpan** di penjuru kanan atas untuk menyelesaikan konfigurasi.

## Langkah 2: Cipta **Borang Pertanyaan Daftar Masuk**

1. Pada halaman penyuntingan aplikasi, klik **+** > **Cipta Borang aliran kerja**, pilih **Cipta halaman kosong**, dan namakan semula borang tersebut kepada **Pertanyaan Daftar Masuk**.
2. Seret dua komponen **Tarikh** dan satu komponen ahli ke kawasan kanvas tengah.
3. Namakan semula kedua-dua komponen **Tarikh** tersebut kepada **Masa Mula** dan **Masa Tamatkan**, tetapkan peraturan pengesahan kepada **Wajib**, dan tetapkan format kepada **YYYY-MM-DD HH:mm:ss**.

<Frame>
  ![](https://gw.alicdn.com/imgextra/i1/O1CN01Oq8yDvUmg7B3LSEv_!!6000000002850-2-tps-1648-805.png)
</Frame>

4. Namakan semula komponen **Pengguna** kepada **Pengguna Daftar Masuk** dan tetapkan peraturan pengesahan kepada **Wajib**.
5. Klik **Simpan** di penjuru kanan atas untuk menyelesaikan konfigurasi asas borang.

## Langkah 4: Terima Data dalam Borang Keputusan Pertanyaan

1. Buka halaman penyuntingan borang keputusan pertanyaan.
2. Buka **Panel Tindakan JS**, tambah kod berikut, dan ubah suai mengikut komen.

```javascript
export function didMount() {
  // Tukar textField_lw4ffhbf kepada ID komponen bagi komponen Penampan Data Penyambung.
  const str = this.$("textField_lw4ffhbf").getValue();

  const value = JSON.parse(str);
  // Tukar tableField_lw5sacjc kepada ID komponen bagi subborang tersebut.
  this.$('tableField_lw5sacjc').setValue(value);

}
```

3. Klik **Simpan** di penjuru kanan atas untuk menyelesaikan konfigurasi.

## Langkah 5: Uji dan Sahkan

1. Buka halaman penyuntingan aplikasi, klik borang **Keputusan Pertanyaan**, dan klik **Jana halaman pengurusan data** di sebelah kanan.
2. Tetapkan **Nama Halaman** dan **Kumpulan** untuk halaman pengurusan data tersebut.
3. Klik **Akses** di penjuru kanan atas untuk membuka aplikasi tersebut.
4. Klik **Pertanyaan Daftar Masuk**, masukkan maklumat pengguna daftar masuk dan julat masa untuk ditanya, dan klik **Hantar**.
5. Buka halaman pengurusan data borang keputusan untuk melihat hasilnya.

Seperti yang ditunjukkan dalam rajah di bawah, rekod daftar masuk pengguna telah berjaya ditanya.
