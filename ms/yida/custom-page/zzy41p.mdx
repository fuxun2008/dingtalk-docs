## 1. Gambaran Keseluruhan

YiDA menyediakan tetapan rendering berulang untuk senario yang memerlukan rendering berulang.

Data gelung mestilah array. Array string, array nombor, dan array object semuanya disokong.

## 2. Kes Penggunaan

### Senario 1: Data Gelung Statik

Tentukan array statik dalam **Data gelung**. Di dalam badan gelung, gunakan `this.item` untuk mengakses nilai gelung semasa dan `this.index` untuk mengakses indeks gelung semasa. Anda juga boleh menyesuaikan `item` dan `index` dengan mengedit **Parameter gelung** — contohnya, menukarnya kepada `content` dan `idx`.

### Senario 3: Gelung Bersarang

Andaikan sumber data jauh mengembalikan struktur data berikut:

```javascript
[
  {
    type: 'I am title one',
    detail: [
      'Content one',
      'Content two',
      'Content three'
    ]
	},
  {
    type: 'I am title one',
    detail: [
      'Content one',
      'Content two',
      'Content three'
    ]
	},
  ...
]
```

## 3. Nota

### 3.1 Menggunakan `this` Dalam Gelung

Di seluruh pembina halaman, `this` mempunyai skop berperingkat. Skop semasa ialah `this`, skop induk ialah `this.$super`, dan skop peringkat teratas ialah `this.$top`.

Contohnya, apabila menerapkan rendering berulang pada bekas borang dengan pengecam borang `'fooForm'`, di dalam **badan gelung**, gunakan `this.$('fooForm').getValue()` untuk mendapatkan nilai borang gelung semasa. Untuk mendapatkan nilai semua borang yang digelungkan, gunakan `this.$super.$('fooForm').map(item => item.getValue())`.
