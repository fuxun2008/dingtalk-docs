## 1. Kes Penggunaan

Untuk melihat subkategori di bawah sesuatu kategori, tambahkan komponen pokok pada Halaman tersuai.

<Note>
Untuk atribut, penggunaan, dan contoh komponen, lihat [**Rujukan komponen pokok**](/ms/open/yida/components/advanced/tree).
</Note>

## 3. Prosedur

### 3.1 Cipta Borang Biasa

Cipta borang biasa dan tambahkan beberapa komponen Teks satu baris. Edit setiap Tajuk dalam panel Atribut di sebelah kanan, kemudian klik Simpan.

### 3.2 Cipta Halaman Tersuai

Pada halaman pemilihan Templat, klik Langkau untuk membuka editor Halaman tersuai. Seret komponen pokok dan komponen butang ke atas kanvas.

### 3.3 Cipta Remote API

Pada Halaman tersuai, klik Sumber Data di sebelah kiri dan cipta remote API baharu. Konfigurasikan nama, URL Permintaan, Parameter permintaan, dan pemprosesan datanya.

URL Permintaan: [API platform YiDA (boleh dipanggil terus daripada Sumber data halaman)](/ms/yida/developer-features/aql605)

Contoh: [https://www.yidaapps.com/dingtalk/web/](https://www.yidaapps.com/dingtalk/web/)APP-XXXXXX/v1/form/searchFormDatas.json

Parameter permintaan `formUuid` boleh didapati dalam Tetapan aplikasi di penjuru kanan atas Laman Utama. Setiap borang mempunyai ID Unik — salin dan tampalkannya ke dalam Parameter permintaan.

Dalam bahagian pemprosesan data, cari kod di bawah fungsi Callback penyempurnaan permintaan dan kemas kini pengecam selepas `dataMap`. Pengecam ini berasal daripada komponen Teks satu baris pada borang. Tampalkannya, kemudian klik Simpan.
