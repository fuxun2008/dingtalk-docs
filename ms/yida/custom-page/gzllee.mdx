Komponen Steps ialah komponen Premium bagi halaman tersuai.

## 1. Kes Penggunaan

Komponen Steps bagi halaman tersuai sangat sesuai untuk membina borang seperti entri maklumat kakitangan yang dihantar dan Daftar maklumat Log masuk. Ia juga membantu mengingatkan pengguna tentang kemajuan semasa mengisi maklumat asas.

<Note>
Untuk atribut komponen, penggunaan dan contoh, lihat [**Komponen Steps**](/open/yida/components/advanced/steps).
</Note>

### 2.1 Atribut Langkah Semasa

Jenis Nombor yang mengawal status data langkah pada langkah semasa. Apabila status semua data langkah adalah Lalai, langkah semasa menunjukkan status sedang berjalan, langkah sebelumnya menunjukkan Selesai, dan langkah seterusnya menunjukkan menunggu.

Mod Baca Sahaja ditutup secara Lalai, yang membenarkan pengguna mengklik nod langkah untuk melaksanakan Tindakan Tersuai yang ditetapkan padanya.

Apabila mod Baca Sahaja Aktif, nod langkah tidak boleh diklik, dan tindakan tersuai tidak akan dicetuskan.

```javascript
/**
* onClick Button
*/
export function onClick() {
  let formCurrent = this.state.formCurrent
  switch (formCurrent) {
    //Pada klik pertama, formCurrent adalah 0
    case 0:
        this.$("block_1").set("behavior", "HIDDEN")
        this.$("block_2").set("behavior", "NORMAL")
        this.setState({
          formCurrent: formCurrent + 1
        })
      break;
    case 1:
        this.$("block_2").set("behavior", "HIDDEN")
        //Berjaya atau Gagal secara rawak. Kemudian, anda boleh memanggil Sumber Data dan menggunakan hasil Permintaan yang dikembalikan untuk menentukan Berjaya atau Gagal.
        const isSuccess = Math.random() < 0.5 ? "block_3_type" : "block_4_type";
        console.log(isSuccess)
        this.setState({
          formCurrent: formCurrent + 1,
          [isSuccess]: "NORMAL",
          action: "HIDDEN"
        })
      break;
    case 2:
    //Tetapkan Semula nilai komponen dalam kontena 1 kepada kosong
      this.$("textField_ktjfxslga").reset()
      this.$("textField_ktjfxslh").reset()
      this.$("textField_ktjfxslj").reset()
      this.$("textField_ktjfxslk").reset()
      this.$("textareaField_ktjfxslm").reset()
    //Tetapkan Semula nilai komponen dalam kontena 2 kepada kosong
      this.$("textField_ktjfxsln").reset()
      this.$("textField_ktjfxslo").reset()
      this.$("textField_ktjwwsj5").reset()
      this.$("textareaField_ktjfxsls").reset()

    //Tunjukkan kontena 1, sembunyikan kontena 2
      this.$("block_1").set("behavior", "NORMAL")
      this.$("block_2").set("behavior", "HIDDEN")
      this.setState({
        formCurrent: 0,
        action: "NORMAL",
        block_3_type: "HIDDEN",
        block_4_type: "HIDDEN"
      })
      break;
  }
}
```
