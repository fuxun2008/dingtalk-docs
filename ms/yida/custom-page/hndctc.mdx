## 1. Soalan Lazim

<AccordionGroup>
<Accordion id="q1" title="1.1 Mengapakah halaman terbenam boleh diakses pada sesetengah peranti tetapi tidak pada peranti lain?">
  Ini biasanya berlaku kerana halaman terbenam menggunakan protokol HTTP, manakala platform YiDA menggunakan HTTPS.

  Atas sebab keselamatan, pelayar mengehadkan jenis pembenaman ini. Sesetengah peranti Android dengan dasar keselamatan yang lebih longgar mungkin masih membenarkan akses, tetapi kebanyakan peranti dan pelayar terkini menyekat permintaan sedemikian.

  **Untuk menyelesaikan isu ini, benamkan URL yang menggunakan protokol HTTPS.**
</Accordion>
<Accordion id="q2" title="1.2 Adakah platform YiDA menyokong integrasi data video, seperti menyambungkan kamera luaran dan memaparkan strimnya pada platform YiDA?">
  Ya. Gunakan komponen Iframe untuk membenamkan pautan strim langsung kamera.

  Tambah komponen Iframe pada Halaman tersuai, kemudian konfigurasikan pautan strim kamera dalam panel Atribut di sebelah kanan.
</Accordion>
<Accordion id="q3" title="1.3 Adakah ia menyokong perkhidmatan Alibaba Cloud VOD (Video on Demand)? Senarionya adalah menyediakan tetingkap video kepada pelanggan untuk memantau pertumbuhan tanaman dari jauh.">
  Komponen Iframe hanya membenamkan halaman pihak ketiga. YiDA bertindak semata-mata sebagai titik akhir paparan. Jika halaman pihak ketiga menyokong strim tuntut, maka strim tuntut akan berfungsi.
</Accordion>
<Accordion id="q4" title="1.4 Komponen HTML yang dikonfigurasikan pada Halaman tersuai tidak melaksanakan JavaScript seperti yang dijangkakan. Adakah komponen HTML tidak menyokong import fail JS?">
  JavaScript boleh dilaksanakan, tetapi ia mesti diimport di dalam `didmount()`.

</Accordion>
</AccordionGroup>
