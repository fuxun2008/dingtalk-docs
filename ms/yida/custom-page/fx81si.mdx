## 3. Menetapkan Format Edit Medan kepada Dropdown

### 3.2 Kemas Kini Konfigurasi Edit

**Kod rujukan:**

```javascript
{
  "rules": [],
  "placeholder": "",
  "__sid__": "param_kqrr5pkb",
    // Berikut adalah item pilihan
  "dataSource": [
    {
      "text": "1",
      "value": "1"
    },
    {
      "text": "2",
      "value": "2"
    }
  ]
}
```

## 4. Mengembangkan Baris yang Dipaparkan secara Lalai Selepas Mendayakan Struktur Pokok

Dalam kod edit, format data mestilah array yang nilainya adalah kunci utama bagi setiap baris. Ini akan mengembangkan baris yang berkaitan secara lalai. Anda juga boleh mengikat pembolehubah dan mengemas kininya pada setiap klik untuk menukar secara dinamik baris mana yang dikembangkan secara lalai.
