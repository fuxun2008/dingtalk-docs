## 1. Pengenalan dan Laluan Konfigurasi

Pengecam unik render (key) berfungsi berdasarkan prinsip yang sama seperti atribut `key` bagi komponen dalam React. Kedua-duanya mengenal pasti komponen secara unik semasa proses render atau apabila komponen ditukar.

**Laluan**: Pada halaman tersuai, klik mana-mana komponen >> **Premium** di sebelah kanan >> **Sama ada hendak dirender** >> **Pengecam unik render**.

Konfigurasi ini biasanya digunakan bersama-sama dengan ciri **Sama ada hendak dirender** dan **Gelung**.

## 2. Kes Penggunaan

### 2.1 Menukar Antara Komponen Jenis Sama

Dalam senario berikut, apabila **Hobi** ditetapkan kepada **Permainan**, **Permainan Kegemaran** dipaparkan; apabila **Hobi** ditetapkan kepada **Sukan**, **Sukan Kegemaran** dipaparkan.

<Frame>
  ![](https://gw.alicdn.com/imgextra/i3/O1CN01c57zqpmnmrF3ANNM_!!6000000004416-2-tps-1560-588.png)
</Frame>

Konfigurasikannya seperti berikut:

1. Tambah sumber data pembolehubah: `hobby`.
2. Tetapkan pengecam borang bagi **Permainan Kegemaran** kepada `game`, dan ikat **Sama ada hendak dirender** kepada pembolehubah `state.hobby === 'Games'`.

<Frame>
  ![](https://gw.alicdn.com/imgextra/i3/O1CN01cPxbe9PJBDD4OPPa_!!6000000002392-2-tps-2164-738.png)
</Frame>

3. Tetapkan pengecam borang bagi **Sukan Kegemaran** kepada `sport`, dan ikat **Sama ada hendak dirender** kepada pembolehubah `state.hobby === 'Sports'`.
4. Konfigurasikan tindakan `onChange` untuk **Hobi**.

```javascript
export function onChagne({ value, actionType, item }) {
  this.setState({
  	hobby: value,
  });
}
```

5. Ikat tindakan `onClick` kepada butang **Hantar**.

```javascript
export function submit() {
	console.log(this.$('form').getValue());
}
```

Dengan konfigurasi di atas (tanpa pengecam unik render ditetapkan), penukaran hobi memang menukar Kotak Teks di bawah. Walau bagaimanapun, apabila data dihantar, medan `sport` masih mengandungi nilai daripada **Permainan Kegemaran** walaupun **Sukan** dipilih.

Sebab: **Apabila menukar antara komponen Kotak Teks tanpa key ditetapkan, rangka kerja yang mendasari akan "menggunakan semula" komponen sebelum penukaran berlaku.**

Untuk membetulkan ini, konfigurasikan **Pengecam unik render** untuk kedua-dua komponen.
