### 1.1 Komponen Halaman Tersuai dan Tujuannya

![](https://gw.alicdn.com/imgextra/i3/O1CN01GmoGbQthNQL5q2U0_!!6000000001489-2-tps-2876-1408.png)


| **Nama komponen** | **Tujuan** |
|---|---|
| [Teks](/ms/open/yida/components/basic/text) | Paparkan kandungan teks. |
| [Gambar](/ms/open/yida/components/basic/image) | Paparkan kandungan gambar. |
| [Ikon](/ms/open/yida/components/basic/icon) | Pilih daripada pelbagai gaya ikon. |
| [Pautan](/ms/open/yida/components/basic/link) | Tambah URL yang menavigasi ke halaman sasaran apabila diklik. |
| [Sekat Pautan](/ms/open/yida/components/basic/linkBlock) | Komponen bekas yang mencetuskan navigasi apabila mana-mana elemen di dalamnya diklik. |
| [Butang](/ms/open/yida/components/basic/button) | Cetuskan tindakan melalui peristiwa butang — sebagai contoh, klik butang untuk mendapatkan masa semasa. |
| [Pemain Video](/ms/open/yida/components/basic/video) | Main video pada halaman dengan pelbagai pilihan main balik. |
| [Dialog](/ms/open/yida/components/basic/dialog) | Gunakan dalam senario berikut:<br />• Memaparkan pemberitahuan kepada pengguna<br />• Memerlukan pengguna mengesahkan tindakan<br />• Memerlukan pengguna melengkapkan tugas tanpa meninggalkan halaman dan mengganggu aliran kerja |
| [Laci](/ms/open/yida/components/basic/drawer) | Gunakan dalam senario berikut:<br />• Memaparkan pemberitahuan kepada pengguna<br />• Memerlukan pengguna mengesahkan tindakan<br />• Memerlukan pengguna melengkapkan tugas tanpa meninggalkan halaman dan mengganggu aliran kerja |
| [Hamparan](/ms/open/yida/components/advanced/table) | Paparkan data daripada borang atau Borang aliran kerja dalam jadual. |
| [HTML](/ms/open/yida/components/advanced/HTML) | Membolehkan pembangunan ciri tersuai. Reka bentuk halaman memerlukan pengetahuan bahagian hadapan (front-end) — sekurang-kurangnya pemahaman kerja tentang HTML, CSS, dan JS. |
| [JSX](/ms/open/yida/components/advanced/JSX) | Menghasilkan komponen tersuai sepenuhnya menggunakan kod JSX. Biasanya digunakan untuk senario paparan sahaja. |
| [Karusel](/ms/open/yida/components/advanced/slider) | Menunjukkan pelbagai gambar secara berulang dalam paparan gelung. |
| [Petunjuk Belon](/ms/open/yida/components/advanced/balloon) | Apabila menggelung data pada Halaman tersuai, kandungan long mungkin dipangkas. Gunakan Petunjuk belon untuk memaparkan kandungan penuh apabila tetikus dialih ke atasnya. |
| Panel Kuncup | Apabila sesuatu halaman mengandungi terlalu banyak komponen, gunakan panel kuncup untuk melipatnya dan mengurangkan kekusutan visual. |
| [Sepanduk Bawah](/ms/open/yida/components/advanced/bannerContainer) | Tambah kandungan yang ditetapkan di bahagian bawah halaman merentasi lebar penuh. |
| [Iframe](/ms/open/yida/components/advanced/Iframe) | Benamkan kandungan daripada halaman web lain ke dalam halaman pereka bentuk semasa. Biasanya digunakan untuk senario paparan sahaja. |
| [Penunjuk Kemajuan](/ms/open/yida/components/advanced/progress) | Tunjukkan Kemajuan sesuatu projek. |
| [Penomboran Halaman](/ms/open/yida/components/advanced/pagination) | Nomborkan halaman data yang dipaparkan pada Halaman tersuai. |
| [Cari](/ms/open/yida/components/advanced/search) | Apabila komponen Hamparan digunakan pada Halaman tersuai, gunakan komponen Cari untuk mencari rekod tertentu. |
| [Penapis](/ms/open/yida/components/advanced/filter) | Apabila memaparkan data dalam jadual tersuai, carian bar atas hanya boleh menapis mengikut satu Lajur. Gunakan komponen Penapis untuk mencari merentasi berbilang Lajur. |
| [Menu](/ms/open/yida/components/advanced/menu) | Gunakan Halaman tersuai sebagai jadual kandungan, dengan item menu yang menavigasi ke halaman lain. |
| [Pepohon](/ms/open/yida/components/advanced/tree) | Semak imbas Kategori dan subkategorinya dalam struktur pepohon. |
| [Garis Masa](/ms/open/yida/components/advanced/timeLine) | Biasanya digunakan untuk memaparkan Sejarah Syarikat atau pencapaian penting sesuatu projek. |
| [Langkah](/ms/open/yida/components/advanced/steps) | Komponen penunjuk langkah untuk Halaman tersuai. Sesuai untuk aliran berbilang langkah seperti Entri data pengambilan kakitangan baharu atau pendaftaran akaun, memberikan peringatan Kemajuan untuk mengisi maklumat asas. |
