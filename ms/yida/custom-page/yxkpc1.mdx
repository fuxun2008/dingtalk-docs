## 1. Kes Penggunaan

Gunakan Komponen Pagination apabila Halaman tersuai mengandungi data yang ingin anda paparkan merentasi berbilang halaman.

<Note>
Untuk atribut Komponen, penggunaan dan Contoh, lihat [rujukan Komponen Pagination](/ms/open/yida/components/advanced/pagination).

## 3. Langkah

### 3.1 Cipta Borang Biasa

Seret Komponen Teks satu baris ke dalam borang dan klik Simpan. Kembali ke Laman Utama Aplikasi dan tambah beberapa data contoh ke borang.

### 3.2 Cipta Halaman Tersuai

Seret Komponen bekas ke Halaman tersuai, kemudian tambah Komponen teks dan Komponen Pagination di dalam bekas tersebut. Gunakan pepohon garis besar untuk menyemak cara Komponen tersebut disarangkan.

Halaman tersuai

### 3.3 Cipta Sumber Data Remote

Pada Halaman tersuai, klik Sumber Data di sebelah kiri, pilih Tambah, dan cipta remote API. Namakan semula mengikut keperluan.

Sumber Data Halaman tersuai

Klik URL Permintaan dan tukar kepada endpoint API yang diperlukan:

'/$\{window.pageConfig.appType || window.g_config.appKey}/v1/form/searchFormDatas.json'

Untuk butiran lanjut, lihat dokumentasi API: [API platform YiDA (boleh dipanggil terus daripada Sumber Data halaman)](/ms/yida/developer-features/aql605)

Ubah suai parameter Permintaan, atau klik Tambah untuk menambah satu yang baharu. Seperti yang ditunjukkan dalam dokumentasi, nama parameter ialah formUuid.

Nilai parameter: Laman Utama Aplikasi >> Tetapan Aplikasi >> Penggunaan dan operasi >> pilih ID borang yang berkaitan

Tetapan Aplikasi

Klik tanda tambah di sebelah Pengendalian Data untuk mencipta fungsi Callback penyelesaian Permintaan, kemudian klik Simpan.

### 3.5 Ikat Pemboleh Ubah

Klik Komponen teks pada Halaman tersuai dan cari pengikatan pemboleh ubah untuk Kandungan di sebelah kanan. Masukkan this.item.formData. diikuti dengan pengecam Unik bagi Komponen Teks satu baris dalam borang biasa.

Untuk mencari formData: pada halaman edit, klik Pratonton, klik kanan dan pilih Inspect, buka konsol, dan cari formData.

### 3.7 Cipta Tindakan

Klik Komponen Pagination dan cari Tetapan Tindakan di bahagian bawah kanan. Klik Cipta Tindakan dan cipta dua Tindakan (dalam Contoh ini, perubahan nombor halaman dan perubahan saiz halaman). Setelah Tindakan dicipta, panel JS akan dibuka secara automatik di sebelah kiri. Tulis kod di sana untuk memuat semula Sumber Data.

```javascript
export function didMount() {
  console.log(`Page JS: URL halaman semasa ${location.href}`);
  // console.log(`Page JS: parameter id halaman semasa ialah ${this.state.urlParams.id}`);
  // Untuk lebih banyak API berkaitan this, lihat: https://developers.aliwork.com/
  // document.title = window.loginUser.userName + ' | YiDA';

 }
/**
* Pagination onChange
* @param currentPagination Nombor halaman semasa
*/
export function onChange(currentPagination) {
  let params = {
    currentPage: currentPagination
  };
  this.dataSourceMap.dp4.load(params);
  console.log('onChange', currentPagination);
}

/**
* Pagination onPageSizeChange
* @param pageSize Bilangan rekod setiap halaman selepas perubahan

export function onPageSizeChange(pageSize) {
  this.setState({
    pageSizeA: pageSize

  let params = {

  console.log('onPageSizeChange', pageSize);
```

### 3.8 Ikat Pemboleh Ubah (Jumlah Kira Rekod dan Nombor Halaman Semasa)

(1) Klik pengikatan pemboleh ubah untuk jumlah Kira rekod di sebelah kanan Komponen Pagination dan masukkan state.searchFormDatas.totalCount (totalCount ialah jumlah bilangan rekod). Klik Sahkan.

<Frame>
  ![](https://gw.alicdn.com/imgextra/i2/O1CN01yfzhCLAUdlF39kRI_!!6000000004762-2-tps-1555-921.png)
</Frame>

(2) Klik pengikatan pemboleh ubah untuk nombor halaman semasa dan masukkan state.searchFormDatas.currentPage (currentPage ialah halaman semasa). Klik Sahkan.

### 3.9 Ikat Pemboleh Ubah pageSize

Klik pengikatan pemboleh ubah untuk pageSize dan gunakan ungkapan ternary dalam kod JS: state.pageSizeA?state.pageSize:5 untuk menentukan bilangan rekod yang boleh dipaparkan pada halaman semasa.
