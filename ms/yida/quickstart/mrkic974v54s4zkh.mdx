## 1. Pengenalan

### 1.1 Gambaran Keseluruhan Ciri

Borang ialah alat asas dalam YiDA, dan semua kemasukan serta pengumpulan data bergantung padanya. Oleh itu, Borang juga berfungsi sebagai sumber data. **Borang aliran kerja**: membolehkan data mengalir ke atas peringkat demi peringkat untuk Kelulusan bertingkat. Anda juga boleh menetapkan Kebenaran untuk mengurus data aliran kerja dengan lebih lanjut.

## 2. Titik Kemasukan

**Titik kemasukan: Edit Aplikasi > Pengurusan Halaman > ➕ > Cipta Borang aliran kerja.**

  ![](https://gw.alicdn.com/imgextra/i3/O1CN01Db9oMvuYtGG3fDXW_!!6000000007290-2-tps-1805-701.png)

Lima kaedah penciptaan disediakan: cipta daripada templat, cipta borang pintar, cipta halaman kosong, cipta halaman dengan mengimport Excel, dan segerakkan daripada DingTalk Base ke borang.

## 3. Cipta Borang Biasa

### 3.1 Cipta Borang Pintar

Klik **Cipta borang pintar**, kemudian masukkan Prompt dalam Pembantu AI, seperti "Bina Borang aliran kerja 'Permintaan Kenderaan' yang mengandungi ID Permintaan, Tarikh Permintaan, Jenis Kenderaan yang Diminta, Pemohon, dan Sebab Permintaan." Berdasarkan Prompt tersebut, AI akan secara automatik mencipta Borang yang berkaitan.

### 3.2 Cipta Halaman Kosong

- Klik **Cipta halaman kosong** untuk membuka halaman kosong dalam Pereka bentuk borang.

### 3.3 Cipta Halaman dengan Mengimport Excel

1. Klik **Cipta halaman dengan mengimport Excel**.
2. Pilih fail Excel (Excel tempatan) > Pratonton data > Tetapan borang (pilih Jenis data) > Import data.
3. Selepas import berjaya, anda akan dialihkan ke halaman borang baharu.

### 3.4 Segerakkan daripada DingTalk Base ke Borang

1. Klik **Segerakkan daripada DingTalk Base ke borang** dan konfigurasikan Tetapan penyegerakan.

2. Popup memaparkan langkah penyegerakan: pilih set data dahulu, kemudian konfigurasikan borang segerak dan medan.
3. Untuk mencipta set data YiDA baharu, konfigurasikan Base dan Jadual tertentu di dalamnya.

**Base yang tersedia:**

- 2. Base yang Dicipta oleh pengguna semasa dalam Dokumen Saya.
