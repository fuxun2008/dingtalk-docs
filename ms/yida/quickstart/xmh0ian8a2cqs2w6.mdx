DingTalk YiDA menawarkan lima cara untuk mencipta aplikasi. Artikel ini menerangkan cara mencipta aplikasi kosong.

## Langkah

Ikuti langkah berikut untuk mencipta aplikasi kosong.

1. Log masuk ke Workbench YiDA.
2. Di penjuru kanan atas, klik **Cipta aplikasi**.
3. Pada halaman **Cipta aplikasi**, klik **Cipta aplikasi kosong**.
4. Di penjuru kiri atas halaman, namakan semula aplikasi.

<Note>
- Nama aplikasi lalai ialah aplikasi Tanpa tajuk.
- Nama aplikasi disimpan secara automatik apabila kotak input kehilangan fokus.
</Note>

Setelah aplikasi dicipta, pilih halaman untuk mula membina.
