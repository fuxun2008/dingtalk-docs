Selepas mengetahui tentang YiDA, ikuti langkah-langkah dalam artikel ini untuk log masuk.

## Langkah 1: Daftar Akaun

Ikuti langkah-langkah berikut untuk mendaftar DingTalk.

1. Buka laman web rasmi YiDA dalam pelayar anda.
2. Klik butang Daftar di penjuru kanan atas untuk membuka halaman pendaftaran akaun.

<Frame>
  ![](https://gw.alicdn.com/imgextra/i4/O1CN01nWUMGqX2utG3GnVa_!!6000000006153-2-tps-1611-959.png)
</Frame>

3. Baca Konvensyen DingTalk, Terma Perkhidmatan DingTalk, dan perjanjian lain. Jika anda menerimanya, pilih "Saya telah membaca dan menerima Konvensyen DingTalk, Terma Perkhidmatan DingTalk, Dasar Privasi DingTalk, dan Perjanjian Organisasi DingTalk."
4. Dalam medan input di tengah halaman, masukkan nombor mudah alih yang ingin anda gunakan untuk mendaftar akaun DingTalk. Kemudian klik Daftar.

<Note>
Jika anda menggunakan nombor mudah alih dari luar China tanah besar, pilih negara atau wilayah yang berkaitan terlebih dahulu. Kemudian masukkan nombor mudah alih anda dan ikut arahan pada skrin untuk melengkapkan pendaftaran.
</Note>

## Langkah 2: Log Masuk ke YiDA

Ikuti langkah-langkah berikut untuk log masuk ke YiDA.

<Frame>
  ![](https://gw.alicdn.com/imgextra/i4/O1CN018CW4r6ZRBFJ3GnQ6_!!6000000003682-2-tps-1611-619.png)
</Frame>

1. Pergi ke laman web rasmi YiDA.
2. Klik butang Log masuk di penjuru kanan atas untuk membuka halaman Pengesahan Identiti Bersatu DingTalk.

3. Pilih salah satu kaedah berikut untuk log masuk ke YiDA.

<Note>
Ekosistem DingTalk kini menyokong status log masuk bersatu. Jika anda sudah log masuk ke klien DingTalk, DingTalk Admin Console, DingTalk Developer Console, DingTalk Docs, atau produk rasmi lain, YiDA akan mengesan status log masuk anda secara automatik apabila anda mengaksesnya. Anda tidak perlu log masuk semula.
</Note>
