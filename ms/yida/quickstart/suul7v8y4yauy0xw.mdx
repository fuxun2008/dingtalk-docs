## 1. Pengenalan

### 1.1 Gambaran Keseluruhan Ciri

Borang ialah alat asas dalam YiDA. Semua pengumpulan data dan pelaporan bergantung pada borang, yang berfungsi sebagai sumber data utama. **Borang biasa**: mengumpul semua data yang dijana semasa operasi perniagaan. Anda juga boleh berkongsi data yang dikumpul melalui kerjasama berasaskan kebenaran dengan [menerbitkan](/yida/form/ulqab1) Kebenaran Data kepada pengguna yang perlu menguruskan data tersebut, atau kepada pengguna luaran untuk pengumpulan data luaran.

## 2. Titik Kemasukan

**Titik kemasukan: Edit Aplikasi > Pengurusan Halaman > ➕ > Cipta borang biasa.**

Anda boleh mencipta borang dengan lima cara: daripada templat, sebagai borang pintar, daripada halaman kosong, dengan mengimport fail Excel, atau dengan menyegerakkan daripada DingTalk Base.

## 3. Cipta Borang Biasa

### 3.1 Cipta Borang Pintar

Klik **Cipta borang pintar**, kemudian masukkan Prompt dalam Pembantu AI, seperti "Cipta Borang Maklum Balas dengan medan untuk kepuasan, penilaian, dan komen maklum balas." Selepas Prompt dihantar, AI akan menjana borang yang berkaitan secara automatik.

### 3.2 Cipta Halaman Kosong

- Klik **Cipta halaman kosong** untuk membuka Pereka bentuk borang halaman kosong.

### 3.3 Import Fail Excel untuk Mencipta Halaman

1. Klik **Import Excel untuk mencipta halaman**.
2. Pilih fail Excel daripada peranti tempatan anda, pratonton data, konfigurasikan borang (pilih jenis data), kemudian import data tersebut.
3. Selepas import berjaya, anda akan dialihkan ke halaman borang baharu.

### 3.4 Segerakkan daripada DingTalk Base atau Borang Kelulusan OA DingTalk ke Borang Biasa YiDA

Contoh berikut menggunakan DingTalk Base:

1. Klik **Segerakkan daripada DingTalk Base ke borang** dan konfigurasikan Tetapan penyegerakan.

2. Kotak dialog akan memaparkan langkah penyegerakan. Mula-mula, pilih set data, kemudian konfigurasikan borang sasaran dan medan.
3. Untuk mencipta set data YiDA baharu, konfigurasikan base dan jadual tertentu di dalamnya.

**Base yang tersedia:**

- 1. Base dalam Knowledge Base Organisasi yang pengguna semasa mempunyai kebenaran pengurusan.

### 3.5 Cipta daripada Templat

- Dalam senarai templat, pilih templat dan klik **Guna**.
