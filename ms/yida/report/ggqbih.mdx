## 1. Langkah-langkah

### 1.1 Kaedah 1

Selepas memasuki YiDA, klik **Aplikasi Saya** dan buka satu aplikasi. Di bahagian tengah kawasan pengurusan halaman, anda akan menemui pintasan pantas untuk mencipta lima jenis halaman. Pilih **Cipta Laporan**.

## 2. Soalan Lazim

**S: Bilakah organisasi DingTalk saya boleh mencuba laporan 3.0 yang baharu?**

Laporan 3.0 kini tersedia sepenuhnya. Ia digunakan untuk laporan yang baru dicipta dalam aplikasi yang baru dibina.

**S: Adakah aplikasi sedia ada menyokong versi laporan baharu?**

Tidak. YiDA kini menyokong "capaian data merentas aplikasi" untuk laporan. Anda tidak perlu mengubah suai aplikasi lama—borang mereka masih boleh digunakan—tetapi anda boleh mendapatkan data daripada aplikasi lama dalam aplikasi baharu dan membina laporan di sana.

**S: Semasa mencipta papan pemuka DataV, bolehkah akaun DingTalk dipautkan dengan akaun Alibaba Cloud?**

Pautan akaun tidak disokong dalam versi semasa. Walau bagaimanapun, anda boleh menggunakan App Secret untuk memberi kebenaran akses kepada data borang YiDA.

**S: Apakah jadual paparan?**

Jadual paparan merupakan penambahbaikan ciri bagi keupayaan "perkaitan pelbagai jadual" yang sedia ada dalam laporan. Ia lebih berkuasa, dan jadual paparan yang dijana berfungsi sebagai set data bebas yang boleh diguna semula merentas laporan berbeza dalam aplikasi yang sama, sekali gus meningkatkan kecekapan.

**S: Bagaimanakah saya menaik taraf laporan 2.0 kepada 3.0?**

Naik taraf terus tidak disokong. Anda perlu mencipta aplikasi YiDA baharu untuk menggunakan ciri laporan 3.0. Sebagai alternatif, rujuk penyelesaian capaian data merentas aplikasi.

**S: Mengapakah laporan gagal menyegerakkan data apabila borang mempunyai nilai?**

Ini berlaku kerana satu medan telah ditambah tetapi versi tidak dikemas kini. Edit dan simpan data secara manual, atau panggil API `/v1/form/updateFormData.json` dengan `useLatestVersion=y` untuk memaksa data dikemas kini kepada versi terkini. Perhatikan bahawa data yang dikemas kini melalui peraturan perkaitan perniagaan pada masa ini tidak mengemas kini versi borang.

**S: Mengapakah saya tidak boleh memilih set data?**

Semak sama ada borang set data mempunyai lebih daripada 300 medan. Terlalu banyak medan borang akan menjejaskan masa respons API apabila laporan merujuk set data tersebut.

**S: Komponen lokasi borang mengesan sebuah munisipaliti, tetapi ia tidak dapat dipaparkan pada bahagian laporan. Mengapa?**

Bagi data yang dijana oleh komponen lokasi/alamat borang, munisipaliti (pada tahap yang sama seperti wilayah) disimpan tanpa akhiran "市" ("Bandar")—contohnya, "北京" dan bukan "北京市".

Walau bagaimanapun, komponen peta China dalam laporan memaparkan data sehingga ke peringkat wilayah dan memerlukan padanan tepat pada nama wilayah, yang mesti menyertakan akhiran "市". Oleh sebab nilai tersebut tidak sepadan dengan data yang dijana oleh borang, data itu tidak dapat dipaparkan.

Sebagai langkah penyelesaian sementara, gunakan Formula **casewhen** laporan, atau proses data dalam **Penyediaan Data** untuk menambahkan "市" supaya ia boleh dipaparkan.

**S: Adakah pengisihan bahasa Cina dalam laporan 2.0 mengikut set aksara GBK?**

Pengisihan bahasa Cina dalam laporan YiDA adalah berdasarkan susunan ASCII.

## Soalan Berkumpulan

**S: Isu Kebenaran Data dalam laporan**

Apabila set data laporan memilih subborang, ia pada masa ini tidak dihadkan oleh Kebenaran Lihat bagi Jadual sumber. Halaman pengurusan data memaparkan data terhad tersebut dengan betul.

**S: Adakah terdapat had bagi kumpulan kebenaran halaman dalam sesebuah aplikasi? Berapakah bilangan kumpulan kebenaran maksimum yang boleh dikonfigurasi?**

Bagi semua halaman selain borang aliran kerja dan borang biasa, anda boleh mencipta sehingga 100 kumpulan kebenaran. Bagi borang aliran kerja dan borang biasa, anda boleh mencipta sehingga 100 kumpulan kebenaran Hantar dan 100 kumpulan Kebenaran Lihat masing-masing.

**S: Apakah maksud ralat penapis [Peringatan: Ralat penapis enjin: Ralat pelaksanaan data: Statement dibatalkan disebabkan permintaan klien]?**

Ralat ini muncul apabila pertanyaan laporan mengambil masa lebih daripada 30 saat. Kami mengesyorkan anda mengoptimumkan syarat pertanyaan anda.
