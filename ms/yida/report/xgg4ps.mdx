Dalam fungsi ini, anda boleh memproses data yang dikembalikan oleh API. Klik butang untuk melihat badan fungsi awal seperti yang ditunjukkan di bawah. Parameter pertama `data` ialah data yang dikembalikan. Tulis JavaScript untuk memproses `data` dan kembalikan hasilnya.

**Contoh:**

Andaikan API mengembalikan data di bawah. Anda perlu memproses lajur Numerik: kembalikan 0 apabila nilai kurang daripada atau sama dengan 0, dan kembalikan 100 apabila nilai lebih besar daripada 0.

Mula-mula, periksa bahagian data API. `data` ialah satu array. Contoh di bawah mengandungi 4 item, sepadan dengan 4 rekod dalam Spreadsheet. Setiap item mengandungi 2 nilai data, sepadan dengan 2 nilai data dalam setiap rekod. Seterusnya, tentukan yang mana antara 2 nilai tersebut sepadan dengan Medan Numerik. Dalam contoh ini, oleh sebab format data bagi Medan Numerik dan Medan Masa Diubah jelas berbeza, anda boleh mengenal pasti dengan sekali pandang bahawa **field_kr1zcs45 sepadan dengan Medan Numerik, dan field_kr1zcs49 sepadan dengan day_Modified time**. Jika set data terlalu besar dan sukar dikenal pasti dengan sekali pandang, analisis menggunakan medan `meta`. Cari item yang `aliasName`-nya mengandungi "Numerical"; `fieldId`-nya ialah **field_kr1zcs45**.

Akhir sekali, proses data tersebut.

```javascript
/**
* Gunakan pemprosesan tersuai pada data yang dikembalikan
* Rujukan data yang dikembalikan: https://www.yuque.com/yida/support/xgg4ps
* data: data yang dikembalikan
* extraInfo: { meta: [], cardParams: {} }, dengan meta ialah metadata data dan cardParams ialah maklumat parameter Kad
*/
function afterFetch(data, extraInfo) {
  data.forEach(item => {
    // Semak sama ada nilai lebih besar daripada 0
    if (item['field_kr1zcs45'] > 0) {
      // Jika lebih besar daripada 0, tetapkan kepada 100
      item['field_kr1zcs45'] = 100;
    } else {
      // Jika tidak, tetapkan kepada 0
      item['field_kr1zcs45'] = 0;
    }
  });
  return data;
}
```
