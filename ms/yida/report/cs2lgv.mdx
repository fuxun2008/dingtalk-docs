## 1. Pengenalan

Benamkan Kandungan daripada halaman web lain ke dalam Halaman pereka bentuk semasa anda. Contoh berikut membenamkan URL Dokumen Bantuan DingTalk YiDA.

## 2. Langkah-Langkah

### 2.1 Pilih Komponen

Buka Laporan, kemudian daripada menu atas, Pilih Lain-lain >> iFrame dan seret ke dalam Halaman.

<Frame>
  ![](https://gw.alicdn.com/imgextra/i1/O1CN01b4ZHHQrQQLL3gr3L_!!6000000004135-2-tps-1818-905.png)
</Frame>

Tambah Komponen.

### 2.2 Tetapan Atribut

#### 2.2.1 URL iFrame

Klik Komponen iFrame. Dalam panel Atribut di sebelah kanan, cari URL iFrame dan masukkan URL laman web rasmi YiDA.

<Frame>
  ![](https://gw.alicdn.com/imgextra/i2/O1CN01TFYP3MQL9sI3g6E3_!!6000000005026-2-tps-1812-907.png)
</Frame>

Tambah URL.

<Frame>
  ![](https://gw.alicdn.com/imgextra/i4/O1CN01mGBJzR27MKH3gr2F_!!6000000007147-2-tps-1818-837.png)
</Frame>

Kesan paparan.

#### 2.2.2 Premium

Memaparkan pengecam Unik bagi Komponen.
