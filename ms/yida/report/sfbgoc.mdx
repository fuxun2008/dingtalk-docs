## 1. Pengenalan

### 1.1 Gambaran Keseluruhan Ciri

Pada peta haba, tetapkan nilai **Paksi X**, **Paksi Y**, dan **Numerik**, kemudian gunakan warna melalui gaya bersyarat berdasarkan paksi X, paksi Y, dan nilai numerik.

Ciri utama: Kawal saiz komponen secara bebas dan alihkan komponen ke mana-mana kedudukan (jajar kiri, jajar tengah, atau jajar kanan).

### 1.2 Keperluan Asas

Keperluan asas untuk peta haba adalah seperti berikut:

| **Paksi X** | **Paksi Y** | **Numerik** |
|---|---|---|
| 1 medan | 1 medan | 1 medan |

## 2. Prosedur

### 2.1 Pilih Komponen dan Konfigurasikan Set Data

Pilih set data.

#### 2.2 Pilih Medan untuk Dipaparkan pada Carta

Seret medan daripada panel kanan ke **Paksi X**, **Paksi Y**, dan **Numerik**.

**Anda boleh sama ada memilih medan terus daripada set data atau menjananya dengan formula. Untuk butiran tentang penggunaan formula, sila lihat** [Formula laporan](/yida/form/yrofmw).

Pilih data.

### 2.2 Tetapan Gaya

Tetapan gaya.

#### 2.2.1 Paksi X

- Paparan paksi: Tunjuk atau sembunyikan paksi.
- Tajuk: Tunjuk atau sembunyikan tajuk paksi. Dimatikan secara lalai. Apabila diaktifkan, masukkan tajuk untuk dipaparkan. Jika tiada tajuk dimasukkan, nama medan akan digunakan.

Konfigurasikan paksi X.

#### 2.2.2 Label

Konfigurasikan tetapan label paksi, termasuk warna, saiz, dan sudut putaran.

- Sudut putaran (kedudukan automatik): Tetapkan sudut putaran label paksi. Aktifkan kedudukan automatik untuk memutarkan label secara automatik berdasarkan susun atur halaman (disyorkan).
- Jarak automatik: Laraskan jarak antara label paksi secara automatik. Disyorkan.

Konfigurasi label.

#### 2.2.3 Susunan Teks

Sesuaikan susunan teks. Label dipaparkan mengikut susunan nama label paksi yang anda masukkan, dipisahkan dengan koma (","), seperti ditunjukkan di bawah:

Susunan teks.

Sama seperti tetapan paksi X, seperti ditunjukkan di bawah:

Tetapan paksi Y.
