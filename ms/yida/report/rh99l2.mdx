## 1. Pengenalan

Gunakan penapis julat untuk membolehkan pelihat laporan menyempitkan data dengan menetapkan nilai minimum dan maksimum untuk Medan Jenis Nombor, seperti menapis pesanan dalam julat harga tertentu.

## 2. Penggunaan

### 2.1 Konfigurasikan Data

Dalam set data laporan, pilih Medan Jenis Nombor. Medan yang didahului dengan ikon "123" berwarna kelabu adalah Jenis Nombor.

### 2.2 Konfigurasikan Gaya

Konfigurasikan peraturan gaya untuk penapis julat, seperti Tajuk dan saiz gaya.
