## 1. Pengenalan

Agregatkan data yang berselerak di bawah satu medan untuk analisis statistik. Kaedah pengagregatan yang tersedia bergantung pada jenis medan.

## 2. Langkah

**Laluan**: Halaman Laporan >> Lajur Hamparan >> Butang Edit di sebelah medan >> Panel tetapan data >> Pengagregatan

**String**: Kira, Kira (dinyahduplikasi)

**Tarikh**: Kira, Kira (dinyahduplikasi), Maksimum, Minimum

**Numerik**: Kira, Kira (dinyahduplikasi), Jumlah, Purata, Maksimum, Minimum
