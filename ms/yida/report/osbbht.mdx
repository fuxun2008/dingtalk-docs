## 1. Gambaran Keseluruhan

Jadual silang ialah salah satu format visualisasi yang paling kerap digunakan dalam analisis harian, serupa dengan Excel. YiDA menyokong pemangsian pelbagai peringkat, pengiraan metrik, jumlah keseluruhan dan subjumlah, penapisan pantas, dan banyak lagi. Tindakan praktikal tambahan—seperti mengklik metrik untuk memaparkan data terperinci yang mendasari—juga tersedia.

### 1.1 Senario Contoh

Contohnya, apabila anda perlu menganalisis maklumat merentasi pelbagai dimensi—seperti menjejaki pendapatan harian, perbelanjaan, dan jumlah keseluruhan gudang mengikut kehalusan masa dalam laporan—gunakan jadual silang untuk menyesuaikan analisis perniagaan anda.

### 1.2 Langkah Teras

- Langkah 1: Pada tab Data, pilih senarai data yang hendak disertakan dalam analisis.
- Langkah 2: Pilih dimensi baris (hanya satu medan dibenarkan).
- Langkah 3: Pilih dimensi lajur (pelbagai medan disokong, membolehkan analisis silang berbilang lajur dengan baris yang dipilih dalam Langkah 2).
- Langkah 4: Pilih metrik (medan berangka disyorkan; apabila medan berangka digunakan, jumlah akan dijumlahkan secara automatik).

## 2. Konfigurasi Asas

### 2.1 Rujuk [Jadual Asas]

#### 2.1.1 Kaitkan Set Data

**Laluan**: Klik Laporan >> Hamparan >> Jadual pangsi silang >> Data >> Set Data >> Pilih set data.

#### 2.1.2 Pilih Senarai Medan

(1) Pilih lajur terus daripada set data, atau jana lajur menggunakan formula. Untuk mempelajari cara menggunakan formula, [**lihat tutorial**](/yida/form/yrofmw).

(2) Tarik medan daripada borang.

## 3. Konfigurasi Premium

Berbanding dengan jadual asas, **konfigurasi Premium** bagi jadual silang terutamanya menambah pilihan **baris** dan **lajur** dalam tetapan gaya.

#### 3.1 Nota Asas

- Penomboran halaman tidak disokong (pastikan data berada dalam had yang boleh dipaparkan oleh satu halaman apabila boleh).
- Saiz: Dipaparkan sebagai besar secara lalai.
- Konfigurasi tinggi tidak disokong (laraskan dengan menyeret jubin).

#### 3.2 Konfigurasi Item Lalai

Setelah nilai lalai ditetapkan, dimensi baris, dimensi lajur, dan metrik akan memuatkan maklumat medan yang berkaitan secara automatik dan menanyakan data semasa pratonton dan paparan.

- Baris: Menyokong satu medan.
- Lajur: Menyokong pelbagai medan.
- Metrik: Menyokong pelbagai medan. Penerokaan terperinci (drill-down) diaktifkan secara lalai; klik data senarai untuk membuka halaman butiran.

#### 3.3 Konfigurasi Asas

- Penapis pertanyaan bagi jadual silang boleh dikonfigurasikan dan dipaparkan secara lalai.
- Ciri penapis belum disokong lagi.
- Bilangan maksimum lajur boleh dikonfigurasikan.
- Pengepala metrik boleh ditunjukkan atau disembunyikan.
- Gaya jalur zebra diaktifkan secara lalai.

#### 3.4 Konfigurasi Ringkasan

**Jumlah baris**: Diaktifkan secara lalai; boleh dimatikan.

**Kedudukan jumlah baris**: Boleh dikonfigurasikan; secara lalai di bahagian akhir.

**Jumlah lajur**: Diaktifkan secara lalai.

## 4. Nota

- Bilangan maksimum lajur yang ditanya tidak boleh melebihi 1,000; prestasi rendering halaman mungkin merosot melebihi had tersebut.
- Jadual pangsi silang tidak menyokong penomboran halaman. Prestasi rendering halaman mungkin merosot bagi jadual dengan lebih daripada 2,000 rekod data.

## 5. Soalan Lazim

### 5.1 Mengapa Tiada Entri Eksport Selepas Butang Eksport Butiran Diaktifkan?

Jika anda telah mengesahkan bahawa Eksport butiran diaktifkan, semak sama ada butang penerokaan terperinci (drill-down) bagi medan metrik berada dalam keadaan Aktif. Entri eksport butiran hanya muncul apabila penerokaan terperinci diaktifkan.
