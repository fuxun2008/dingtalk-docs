Setiap carta mempunyai tujuan tertentu, seperti menunjukkan perbandingan numerik antara kategori, melihat perkadaran setiap bahagian, atau mencerminkan cara sesuatu berubah mengikut masa."

Bahagian ini mengelompokkan komponen laporan mengikut fungsi—jadual untuk melihat data mentah atau data yang diagregatkan, carta untuk menganalisis trend dan perbandingan, dan komponen susun atur untuk menstrukturkan halaman—supaya anda dapat mencari dengan cepat komponen yang sesuai dengan keperluan pelaporan anda.

| **Nama komponen** | **Tujuan** |
|---|---|
| [**Lajur**](/yida/report/xybfun) | Menggunakan bar menegak atau mendatar untuk menunjukkan **perbandingan numerik antara kategori**. |
| [**Carta Pai**](/yida/report/hb73mq) | Digunakan untuk melihat perkadaran data bagi setiap jabatan. |
| [**Garisan**](/yida/report/pnsoga) | Memaparkan cara data **berubah dalam selang masa atau tempoh masa yang berterusan**. Ia mencerminkan trend perubahan sesuatu mengikut masa atau merentasi kategori tersusun. |
| [**Carta gabungan Lajur-Garisan**](/yida/report/wfno1e) | Lajur menggambarkan perbezaan antara kumpulan data dan menekankan perbandingan antara individu.<br />Garisan menganalisis cara jualan sesuatu produk berubah mengikut masa, membantu meramalkan jualan pada masa hadapan.<br />Carta gabungan Lajur-Garisan memaparkan Lajur dan Garisan pada masa yang sama. |
| [**Papan Pemuka**](/yida/report/xgetgl) | Membolehkan anda mengawal saiz komponen dan menggerakkan kedudukan komponen dengan bebas (jajaran kiri, Jajaran Tengah, jajaran kanan). |
| [**Corong**](/yida/report/hd3q1n) | Memberikan paparan intuitif tentang tahap penukaran bagi setiap peringkat perniagaan. Dalam erti kata lain, Corong ialah aplikasi khusus analisis laluan, yang tertumpu terutamanya pada analisis penukaran laluan kritikal. |
| [**Awan kata**](/yida/report/gtyrhp) | Menjana carta awan kata daripada data borang. |
| [**Radar**](/yida/report/grr9lt) | Kaedah grafik yang memaparkan data pelbagai pemboleh ubah dalam bentuk carta dua dimensi, mewakili tiga atau lebih pemboleh ubah kuantitatif pada paksi yang bermula dari titik yang sama. |
| [**Peta haba kalendar**](/yida/report/lyedo6) | Memaparkan kemajuan pada masa yang berbeza dalam bentuk kalendar dan menyesuaikan warna berdasarkan nilai. **Sesuai untuk menyemak senario seperti jumlah kod atau aktiviti kerja dalam sesuatu tempoh masa.** |
| [**Peta China**](/yida/report/plcwtt) | Komponen peta pentadbiran yang menyokong peringkat wilayah, bandar, dan daerah bagi Peta China, serta keupayaan penelusuran terperinci (drill-down) dan penggulungan semula (roll-up) antara peringkat tersebut. |
| [**Jadual asas**](/yida/report/stqur9) | Memaparkan data borang yang dihantar dalam bentuk hamparan bergaya Excel. |
| [**Jadual pangsi silang**](/yida/report/osbbht) | Salah satu visualisasi yang paling kerap digunakan dalam analisis harian, serupa dengan Excel. YiDA menyediakan pemangsian berbilang peringkat, pengiraan metrik, jumlah keseluruhan dan jumlah kecil, penapisan pantas, dan keupayaan lain. Tindakan mudah seperti mengklik metrik untuk mendedahkan data terperinci turut tersedia untuk diterokai. |
| [**Kad metrik asas**](/yida/report/vn761o) | Konfigurasikan metrik dan ikon untuk memaparkan nilai metrik utama dan ikon, dengan sokongan penelusuran terperinci (drill-down) melalui klik ikon. |
| [**Teks**](/yida/report/hu9aqr) | Digunakan untuk memaparkan maklumat teks asas. |
| [**Gambar**](/yida/report/pyrhm5) | Digunakan untuk memaparkan maklumat gambar. |
| [**Pautan**](/yida/report/tst3xa) | Digunakan untuk mengalihkan ke URL dan menggabungkan parameter secara bebas. |
| [**Bekas**](/yida/report/qhbihp) | Digunakan terutamanya untuk susun atur, dan boleh digabungkan dengan komponen lain. |
| [**Pisahan lajur**](/yida/report/xvx3lt) | Digunakan terutamanya untuk susun atur, dan boleh digabungkan dengan komponen lain. |
| [**Tab**](/yida/report/pux8db) | Dua gaya biasa ialah standard dan kapsul. Digunakan terutamanya untuk susun atur, dan boleh digabungkan dengan komponen lain. |
| [**Penapis Masa**](/yida/report/hbqowi) | Menyokong tetapan **nilai tunggal** dan **julat** untuk penapisan. |
| [**Penapis tarik turun**](/yida/report/is9r5k) | Menyokong tetapan **Pilih** dan **Pilih Banyak**, dengan carian kabur dalam kotak input. Anda boleh mengkonfigurasikan Papar medan untuk membezakan antara medan yang dipaparkan kepada pengguna dan medan yang sebenarnya ditanyakan (contohnya, memaparkan nama jabatan sambil menanyakan mengikut kod jabatan).<br />Turut menyokong mod **Tag** untuk penapisan berasaskan Tag. |
| [**iFrame**](/yida/report/cs2lgv) | Membenamkan kandungan daripada halaman web lain ke dalam Halaman pereka bentuk semasa. |
