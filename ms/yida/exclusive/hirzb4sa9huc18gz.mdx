## 1. App Vault

- Suis App Vault: Setelah diaktifkan untuk aplikasi tertentu, aplikasi tersebut mencapai perlindungan data perniagaan sepenuhnya. Admin platform tidak lagi boleh mengakses bahagian belakang aplikasi secara langsung atau melihat data aplikasi yang sensitif.
- Selepas pengaktifan, IT dan admin platform lain tidak dapat melihat aplikasi tersebut. Ini sesuai untuk aplikasi yang melibatkan rahsia perdagangan atau data sensitif, seperti pampasan dan gaji pekerja.

Entri konfigurasi: Bahagian belakang admin > Tetapan aplikasi > Kebenaran aplikasi.

## 2. Tembok Api Sifar-Kepercayaan

Apabila YiDA di atas awan perlu menyambung ke perkhidmatan Integrasi & Automasi (HTTPS) intranet organisasi anda atau perkhidmatan Sumber Data JDBC (TCP/IP) luaran, organisasi mesti mendedahkan perkhidmatan ini di internet awam secara lalai.

YiDA bekerjasama dengan teknologi get laluan perusahaan sifar-kepercayaan DingTalk untuk mengelakkan perkhidmatan berkaitan daripada terdedah secara langsung kepada internet awam. Dengan menggunakan teknologi penembusan rangkaian sifar-kepercayaan, ia melindungi perkhidmatan teras organisasi sambil tetap memenuhi keperluan interkoneksi perniagaan.

## 3. Pagar Rangkaian IP

Admin boleh mengawal tingkah laku pekerja seperti log masuk ke DingTalk, memuat naik, dan memuat turun fail berdasarkan segmen alamat rangkaian atau aplikasi. Pergi ke [bahagian belakang admin OA](https://oa.dingtalk.io/vip2.htm#/securityGate) > **DingTalk Khusus** > **Keselamatan Khusus > Akses keselamatan > Pagar IP** untuk mengawal muat turun lampiran selamat secara fleksibel bagi pelbagai aplikasi YiDA.

<Note>
Segmen IP yang dikonfigurasikan dalam pagar IP mestilah IP awam, bukan IP peribadi.
</Note>

## 4. Mod Talian Rangkaian Khusus

- DingTalk Khusus menyediakan keupayaan proksi rangkaian profesional untuk talian rangkaian khusus, membolehkan komunikasi antara talian khusus dan internet awam di bawah identiti yang dipercayai. YiDA Dedicated menyokong keupayaan "mod proksi talian rangkaian khusus" DingTalk Khusus.
