## Aktifkan Mengikut Keperluan (Peringkat Aplikasi)

### 1. Aktifkan Semasa Mencipta Aplikasi Baharu

Semasa mencipta aplikasi baharu, pilih sama ada data perniagaan aplikasi disimpan dalam awan awam (lalai) atau dalam pangkalan data awan hibrid khusus (disyorkan untuk data kritikal teras).

<Frame>
  ![](https://gw.alicdn.com/imgextra/i2/O1CN01YcUklqcXK8L5nlzW_!!6000000002622-2-tps-2858-1376.png)
</Frame>


### 2. Aktifkan Secara Manual untuk Aplikasi Sedia Ada

- Sebagai Admin Aplikasi, pergi ke Tetapan Aplikasi > Tetapan Asas > Konfigurasi Khusus dalam bahagian belakang aplikasi, kemudian pilih dan aktifkan storan khusus untuk aplikasi tersebut.
- Selepas anda mengaktifkannya, kedua-dua data sejarah dan data masa depan bagi aplikasi tersebut disimpan dalam pangkalan data PostgreSQL khusus dan OSS lampiran khusus yang dikonfigurasi dalam pengurusan platform.
- Fungsi aplikasi digantung sementara semasa proses naik taraf, jadi lakukan tindakan ini pada waktu tidak sibuk. Proses ini mengambil masa lebih kurang 3–10 minit dan tidak boleh dibatalkan selepas selesai. Anda boleh menghentikan naik taraf secara manual semasa ia sedang berjalan.

### 3. Operasi Naik Taraf dan Henti

- Menukar konfigurasi rangka kerja asas aplikasi ialah operasi yang mengambil masa lama. Untuk menghentikan proses di tengah jalan, hentikannya secara manual. Selepas anda menghentikan naik taraf, konfigurasi asas aplikasi akan kembali kepada tetapan storan awan dan mod operasi asal.
