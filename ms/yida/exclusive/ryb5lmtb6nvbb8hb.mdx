Topik ini menerangkan cara admin platform mengaktifkan dan mengkonfigurasikan governance aplikasi dalam Edisi YiDA Dedicated, serta cara admin aplikasi menyelesaikan Proses kelulusan untuk mengaktifkan atau menerbitkan aplikasi di bawah governance.

## Aktifkan Governance Aplikasi

1. Log masuk ke Workbench YiDA sebagai admin platform, pergi ke halaman **pengurusan platform**, klik **Governance Center**, dan aktifkan togol **Governance aplikasi**.

<Frame>
  ![](https://gw.alicdn.com/imgextra/i2/O1CN01MIKoWaIHg8G36TVx_!!6000000005999-2-tps-1529-904.png)
</Frame>

2. Aktifkan togol governance dan pilih saluran penerbitan yang hendak diuruskan.
3. Konfigurasikan Skop governance.

Admin aplikasi dalam Skop governance perlu menghantar permintaan kelulusan untuk mengaktifkan atau menerbitkan aplikasi.

<Frame>
  ![](https://gw.alicdn.com/imgextra/i1/O1CN01xG68WCUbZrE36qzD_!!6000000007749-2-tps-1532-1127.png)
</Frame>

4. Konfigurasikan Proses kelulusan governance.

Admin boleh menyesuaikan proses governance. Klik **Edit** untuk mengubah suai Proses kelulusan pratetap platform (borang permohonan itu sendiri tidak boleh diubah suai).

<Frame>
  ![](https://gw.alicdn.com/imgextra/i3/O1CN01x6xLmod9xFL6oy0S_!!6000000003389-2-tps-3360-1724.png)
</Frame>

## Kelulusan untuk Permintaan Aktifkan

Selepas admin menukar "Governance Aktifkan" kepada Aktif, aplikasi yang baru dicipta oleh pengguna dalam Skop governance akan menjadi "Dinyahaktifkan" secara lalai. Pengguna di luar Skop governance tidak terjejas, dan aplikasi mereka kekal Diaktifkan secara lalai.

**Untuk memudahkan admin aplikasi menguji aplikasi semasa pembangunan, admin aplikasi yang tertakluk kepada governance pengaktifan boleh Hantar Data untuk ujian aplikasi sebelum aplikasi itu Diaktifkan.**

Untuk mengaktifkan aplikasi, admin aplikasi perlu menghantar "Permintaan Aktifkan" terlebih dahulu. Aplikasi hanya boleh Diaktifkan selepas permintaan itu diluluskan.
