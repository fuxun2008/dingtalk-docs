Topik ini menerangkan cara pentadbir Organisasi boleh Konfigurasikan tetapan aplikasi global, termasuk cara Aktifkan storan khusus, persekitaran kluster khusus, dan ciri governans lain untuk Aplikasi merentasi Organisasi.

## Gambaran Keseluruhan Ciri

Tetapan Aplikasi Global membolehkan anda mengawal sama ada Aplikasi dalam Organisasi mengaktifkan storan khusus, persekitaran kluster khusus, Lajur fizikal khusus, tera air Aplikasi, dan kotak perlindungan Aplikasi. Antaranya, storan khusus, persekitaran kluster khusus, dan Lajur fizikal khusus boleh dikuatkuasakan. Setelah dikuatkuasakan, Aplikasi YiDA yang baharu Dicipta akan mengaktifkan ciri ini secara Lalai dan tidak boleh dimatikan.

### Storan Khusus

- Kuatkuasakan: Apabila diaktifkan, semua Aplikasi YiDA yang baharu Dicipta akan mengaktifkan storan khusus peringkat Aplikasi secara Lalai. Data perniagaan akan disimpan secara automatik dalam storan persendirian Organisasi. Keadaan Lalai ini tidak boleh dimatikan setelah diaktifkan.

<Frame>
  ![](https://gw.alicdn.com/imgextra/i2/O1CN01M2Q5EPs48PC47Hz3_!!6000000004475-2-tps-2028-745.png)
</Frame>

- Keadaan Lalai: Apabila diaktifkan, storan khusus akan Dipilih secara Lalai apabila anda Cipta Aplikasi YiDA baharu.

### Persekitaran Kluster Khusus

- Kuatkuasakan: Apabila diaktifkan, semua Aplikasi YiDA yang baharu Dicipta akan mengaktifkan kesan tera air peringkat Aplikasi secara Lalai. Artifak binaan, keadaan masa jalan (runtime), dan data perniagaan Aplikasi akan disimpan secara automatik dalam persekitaran persendirian Organisasi. Keadaan Lalai ini tidak boleh dimatikan setelah diaktifkan.
- Keadaan Lalai: Apabila diaktifkan, persekitaran kluster khusus akan diaktifkan secara Lalai apabila anda Cipta Aplikasi YiDA baharu.

### Storan Lajur Fizikal

- Kuatkuasakan: Apabila diaktifkan, storan data Borang bagi Aplikasi YiDA yang baharu Dicipta akan bertukar daripada mod JSON kepada mod Lajur fizikal (satu Medan dipetakan kepada satu Medan Lajur fizikal). Keadaan Lalai ini tidak boleh dimatikan setelah diaktifkan.

### Tera Air Aplikasi

- Keadaan Lalai: Apabila diaktifkan, kesan tera air peringkat Aplikasi akan diaktifkan secara Lalai apabila anda Cipta Aplikasi YiDA baharu.

### Kotak Perlindungan Aplikasi

- Keadaan Lalai: Apabila diaktifkan, kotak perlindungan Aplikasi akan diaktifkan secara Lalai apabila anda Cipta Aplikasi YiDA baharu.

## Tetapan Khusus untuk Aplikasi Individu

- Setiap Aplikasi menyokong konfigurasi mengikut Jabatan, membolehkan pemilikan yang lebih terperinci dan governans Aplikasi.
- Dalam setiap Aplikasi, anda boleh melihat dan Konfigurasikan ciri khususnya secara berasingan, memperkaya data induk Aplikasi, serta menguruskan aset data low-code Organisasi.
