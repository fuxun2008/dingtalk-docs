Data aplikasi dalam persekitaran kluster khusus (dedicated) disimpan dalam persekitaran peribadi dan tidak boleh mengakses rangkaian awam. Akibatnya, YiDA OpenAPI pada Platform Terbuka DingTalk tidak dapat mengambil data ini. Anda mesti memanggil OpenAPI dari dalam persekitaran kluster. OpenAPI persekitaran kluster pada dasarnya sama seperti pada Platform Terbuka DingTalk, hanya berbeza pada host dan AK/SK yang diperlukan.

Artikel ini menerangkan cara memanggil YiDA OpenAPI dalam persekitaran kluster khusus (dedicated).

<Note>
Nota:

YiDA Dedicated kini mendedahkan API perkhidmatan data berfrekuensi tinggi. Berdasarkan keupayaan YiDA API yang tersedia pada Platform Terbuka DingTalk sehingga 31 Disember 2023, sebanyak 52 OpenAPI tersedia.
</Note>

## Aliran Panggilan

Memanggil YiDA API dalam persekitaran kluster adalah serupa dengan memanggilnya pada Platform Terbuka DingTalk. Semua OpenAPI berkaitan pada Platform Terbuka DingTalk dipanggil melalui api.dingtalk.com. Untuk OpenAPI edisi kluster, hanya gantikan api.dingtalk.com dengan domain YiDA edisi kluster Organisasi Anda.

1. Dapatkan domain kluster khusus (dedicated) YiDA Organisasi Anda, contohnya, ddyd.corp.com.
2. Dapatkan AK dan SK bagi edisi kluster Organisasi Anda.

<Note>
Hubungi admin DingTalk Organisasi Anda. Log masuk ke Platform Terbuka DingTalk, cari "YiDA Dedicated Cluster" di bawah aplikasi dalaman, dan dapatkan maklumat berkaitan daripada aplikasi bernama **YiDA Dedicated Cluster Authentication App**.
</Note>

Platform Terbuka DingTalk menyediakan SDK dalam Java, PHP, Python, dan .NET untuk pembangun. OpenAPI edisi kluster menyokong panggilan yang serupa.

5. Jika anda menggunakan SDK Platform Terbuka DingTalk, buat perubahan berikut:

Perubahan 1: Jika domain menggunakan http, tetapkan config.protocol = "http".

Perubahan 2: Tetapkan client._endpoint secara eksplisit kepada domain YiDA sebenar Organisasi Anda.

```java
private static com.aliyun.dingtalkyida_2_0.Client createOpenApiClient() {
        Config config = new Config();
        config.regionId = "central";
        config.protocol = "http";
        config.connectTimeout = 60 * 1000;
        config.readTimeout = 60 * 1000;
        try {
            com.aliyun.dingtalkyida_2_0.Client client = new com.aliyun.dingtalkyida_2_0.Client(config);
          client._endpoint =  "your-org-private-yida-domain.com";
            return client;
        } catch (Exception e) {
            throw new RuntimeException(e);
        }
    }
```
