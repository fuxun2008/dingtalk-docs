Pendekatan ini membolehkan anda menggunakan semula data yang telah disimpan dalam pangkalan data luaran secara terus dalam Aplikasi anda, tanpa perlu memasukkan semula rekod secara manual.

## Prasyarat

Sebelum mencipta set data daripada pangkalan data, tambah Sumber Data pangkalan data ke Aplikasi anda. Untuk langkah terperinci, lihat Cipta Sumber Data.

## Langkah

1. Log masuk ke Workbench YiDA dan pergi ke halaman tetapan Aplikasi.
2. Klik **Data Factory** > **Set Data**.
3. Klik **Cipta Set Data** > **Daripada Pangkalan Data**.
