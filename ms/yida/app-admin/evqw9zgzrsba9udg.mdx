**Ciri ini eksklusif untuk laporan Premium Data.**

Pangkalan Data Pengasingan ialah "pangkalan data lanjutan" **yang direka khusus untuk pelanggan yang telah mengaktifkan Premium Data Workbench YiDA** (keupayaan analisis Premium Data). Tujuannya adalah untuk **menyegerakkan senarai lajur fizikal borang dan data instans berkaitan secara masa nyata daripada pangkalan data khusus asal ke Pangkalan Data Pengasingan ini** untuk aplikasi di bawah sesebuah organisasi yang telah dinaik taraf kepada Pangkalan Data Pengasingan (**aplikasi mesti mengaktifkan keupayaan storan khusus dan lajur fizikal terlebih dahulu**). Seterusnya, ia berfungsi sebagai sumber data utama untuk pertanyaan dan analisis data dalam Ruang Aplikasi tersebut, **mengurangkan tekanan pertanyaan pada pangkalan data khusus asal dan meringankan kesan prestasi terhadap perniagaan storan khusus asal YiDA.**

#### Senario Aplikasi

Pangkalan Data Pengasingan Data sesuai untuk situasi berikut:

- Keperluan analisis Premium Data: Apabila sesebuah organisasi perlu menjalankan pertanyaan kompleks dan analisis data, Pangkalan Data Pengasingan meningkatkan kecekapan dan prestasi.
- Pemprosesan data berskala besar: Untuk aplikasi dengan jumlah data yang besar, Pangkalan Data Pengasingan mengagihkan tekanan pertanyaan dengan berkesan dan mengelakkan bebanan berlebihan pada pangkalan data asal.
- Pengalaman pengguna yang dioptimumkan: Dengan mengalihkan tugas pertanyaan dan analisis ke Pangkalan Data Pengasingan, pengguna mendapat kelajuan respons yang lebih pantas semasa mengakses aplikasi dalam pangkalan data asal.

#### Penerangan Ciri

<Note>
1. Pangkalan Data Pengasingan pada masa ini eksklusif untuk pelanggan yang telah mengaktifkan Premium Data Workbench (keupayaan analisis Premium Data).
2. Aplikasi hanya boleh dinaik taraf dengan keupayaan Pangkalan Data Pengasingan selepas konfigurasi Pangkalan Data Pengasingan disempurnakan di bawah storan khusus organisasi.
3. Menaik taraf aplikasi kepada keupayaan Pangkalan Data Pengasingan adalah serupa dengan lajur fizikal; kedua-duanya memerlukan migrasi data sedia ada, yang mengambil sedikit masa.
4. Terdapat 3 tempat di mana aplikasi boleh dinaik taraf kepada Pangkalan Data Pengasingan:

(1) Pilih Pangkalan Data Pengasingan semasa mencipta aplikasi.

#### Soalan Lazim

- S: Masa migrasi data — Berapa lamakah masa yang diperlukan untuk menaik taraf aplikasi kepada Pangkalan Data Pengasingan? J: Menaik taraf kepada Pangkalan Data Pengasingan melibatkan migrasi data sedia ada, dan masa sebenar bergantung pada jumlah data. Rancang lebih awal dan peruntukkan masa yang mencukupi untuk migrasi tersebut.
- S: Penukaran instans pangkalan data — Bagaimanakah saya mengubah suai rentetan sambungan, jenis, atau nama pangkalan data? J: Anda boleh mengubah suai maklumat ini melalui ciri penukaran migrasi automatik. Perhatikan bahawa setiap penukaran akan mencetuskan migrasi data sedia ada, jadi anggarkan masa yang diperlukan terlebih dahulu.
- S: Pengubahsuaian nama pengguna dan kata laluan — Bagaimanakah saya mengubah suai nama pengguna dan kata laluan pangkalan data? J: Pengubahsuaian terus nama pengguna dan kata laluan tidak disokong pada masa ini. Jika perlu, cipta nama pangkalan data baharu dalam instans pangkalan data, ubah suai hanya nama pangkalan data dan kata laluan akaun, kemudian cetuskan penukaran migrasi automatik. Jika pengubahsuaian benar-benar perlu, hubungi sokongan teknikal YiDA.
- S: Kesan prestasi — Adakah Pangkalan Data Pengasingan menjejaskan prestasi sistem? J: Pangkalan Data Pengasingan pada dasarnya bertujuan untuk mengurangkan tekanan pertanyaan pada pangkalan data khusus asal, dan secara teorinya, tidak akan menjejaskan prestasi keseluruhan sistem secara negatif. Sebaliknya, ia membantu meningkatkan kestabilan sistem dan kelajuan respons.
