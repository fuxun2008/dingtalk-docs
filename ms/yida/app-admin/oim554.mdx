## Gambaran Keseluruhan Jadual Paparan

Jadual paparan memproses awal data borang sedia ada melalui perkaitan jadual tunggal atau jadual berbilang. Ia juga menyokong mod jadual perantaraan untuk meningkatkan keupayaan pemprosesan data. Pada masa ini, data jadual paparan boleh digunakan secara terus dalam senario seperti visualisasi data laporan dan pautan borang.

## Prosedur

Anda boleh mencipta set data daripada jadual paparan dalam mod jadual tunggal atau jadual berbilang. Rujuk bahagian berikut untuk mencipta jadual.

### Set Data Jadual Tunggal

Set data jadual tunggal membolehkan anda memilih mana-mana medan dalam satu jadual. Untuk menambah medan kiraan, pergi ke fx untuk mentakrifkan formula.

## Urus Kebenaran

Secara lalai, jadual paparan menggunakan semua data baris dan lajur daripada setiap medan yang dipilih dalam borang sumber, mengabaikan kawalan kebenaran lihat borang tersebut.

- Walau bagaimanapun, jadual paparan menyokong penapisan kebenaran peringkat baris yang berasingan.
- Pada masa hadapan, jadual paparan akan menyokong sistem kebenaran berasingan berdasarkan **set data** yang berorientasikan pemodelan data.
- Pelanggan dengan keperluan kebenaran data yang ketat perlu menggunakan ciri ini dengan berhati-hati pada peringkat ini.
