## Gambaran keseluruhan

Set data ialah unit pengurusan bersepadu YiDA untuk data daripada borang, paparan jadual, penyediaan data dan sumber merentas aplikasi. Ia merupakan unit pengumpulan data standard dalam YiDA.

## Jadual tunggal sebagai set data

Guna data yang dikumpul oleh borang yang dibina dalam aplikasi sebagai input untuk membina laporan.

<Note>
Anda tidak perlu mencipta set data jadual tunggal secara manual. Selepas anda mencipta borang, datanya akan disegerakkan secara automatik ke senarai set data.
</Note>

## Cipta set data daripada paparan jadual

YiDA memproses data borang sedia ada menjadi jadual data konsolidasi (jadual lebar) yang boleh anda gunakan terus dalam laporan hiliran.

Untuk maklumat lanjut tentang paparan jadual, lihat [Paparan jadual](/ms/yida/app-admin/oim554).

## Cipta set data daripada penyediaan data

Penyediaan data ialah penyelesaian data besar luar talian. Ia menyokong muat naik data Excel dan CSV serta sambungan ke pangkalan data dalam talian seperti MySQL. Selepas dipercepatkan melalui penyediaan data, data digabungkan dan diproses untuk penciptaan laporan.

Untuk maklumat lanjut tentang penyediaan data, lihat [Gambaran keseluruhan ciri](/ms/yida/app-admin/ykemo6).

## Cipta set data daripada sumber merentas aplikasi

Pengambilan data merentas aplikasi membolehkan anda mengambil data borang daripada aplikasi lain yang ditetapkan sebagai set data. Selepas anda menambah borang pengambilan data merentas aplikasi, anda boleh menggunakannya dalam senario seperti penciptaan laporan. Buat masa ini, hanya senario laporan yang disokong; pada masa hadapan, borang merentas aplikasi akan tersedia sebagai set data standard dalam lebih banyak senario.

Untuk maklumat lanjut, lihat [Merentas aplikasi](/ms/yida/app-admin/btrtnt).

## Cipta set data daripada fail

**Tujuan**: Sambungkan sumber maklumat berasaskan teks sedia ada untuk mengekstrak dan memproses data daripada aset teks dan fail dengan pantas. Fail adalah jenis yang mudah dan tidak memerlukan Sumber Data yang berasingan. Anda boleh mencipta set data berasaskan fail secara terus dalam modul set data.

**Jenis yang disokong**: Fail Excel .xls dan .xlsx yang lazim digunakan dalam sistem maklumat perusahaan, serta fail CSV (Comma-Separated Values) yang menyokong pemprosesan data teks berskala besar.

**Pengoptimuman senario**: Medan yang dimuat naik dianggap sebagai jenis string secara lalai. Anda boleh melaraskan jenis medan (Numerik, Tarikh, dan sebagainya) supaya data menggunakan jenis yang paling sesuai dalam setiap senario.

## Cipta set data daripada pangkalan data

**Tujuan**: Sambungkan pangkalan data awan sedia ada untuk mengekstrak dan memproses data.

**Jenis yang disokong**: MySQL, SQLServer, Oracle, PostgreSQL, HologreSQL.

**Keselamatan**: Kecuali kata laluan pangkalan data yang dimasukkan semasa mencipta Sumber Data, semua penghantaran kata laluan seterusnya disulitkan untuk melindungi maklumat pangkalan data hujung ke hujung.

**Pengoptimuman senario**: Pemacu pangkalan data untuk pelbagai versi MySQL dan SQLServer dihurai dan dikenal pasti secara automatik di awan, dan pemacu yang sepadan diterapkan secara pintar.

## Konfigurasi kebenaran set data

Dalam senarai set data YiDA, konfigurasikan kebenaran untuk menentukan pengguna mana yang boleh mengakses medan mana (atau data yang sepadan dengan peraturan tertentu), membolehkan kawalan kebenaran peringkat data pada masa jalan.

- Set data jenis borang mewarisi kebenaran borang secara terus.
- Bagi jenis set data lain, pergi ke Kebenaran dan cipta kumpulan kebenaran untuk menetapkan skop kebenaran yang berasingan. Peraturan lalai ialah: semua orang boleh melihat data dalam semua medan.

**Laluan**: Pergi ke halaman borang aplikasi > Data Aplikasi.

**Takrifan set data**: Set data ialah unit pengurusan bersepadu untuk data yang dihasilkan oleh borang standard, paparan jadual (gabungan berbilang jadual), penyediaan data (penyelesaian data besar luar talian) dan borang merentas aplikasi. Ia merupakan unit pengumpulan data standard dalam YiDA.
