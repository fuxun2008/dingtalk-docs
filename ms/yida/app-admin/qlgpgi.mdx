Tetapan kebenaran aplikasi menentukan siapa yang dilantik sebagai admin aplikasi, dengan memberikan pengguna tersebut kebenaran untuk mengedit, mengonfigurasikan, dan mengurus data dalam aplikasi.

<Note>
- Pelan Percuma YiDA tidak memerlukan pengaktifan admin aplikasi. Secara lalai, setiap pengguna boleh mencipta aplikasi.
- Pelan YiDA berbayar memerlukan admin aplikasi diaktifkan secara berasingan. Hanya pengguna yang dilantik sebagai admin aplikasi boleh mencipta aplikasi.
</Note>

## Tetapkan Admin Aplikasi

1. Log masuk ke YiDA Workbench dan buka halaman **Aplikasi Saya**.
2. Pilih aplikasi yang disasarkan, kemudian pilih **···** > **Tetapan Aplikasi**.

<Frame>
  ![](https://gw.alicdn.com/imgextra/i4/O1CN01obvVNYkScUL2hAj3_!!6000000000624-2-tps-1328-681.png)
</Frame>

3. Dalam menu sebelah kiri pada halaman Tetapan Aplikasi, klik **Kebenaran Aplikasi** > **Admin Aplikasi**.
4. Klik **Tetapkan pengguna** di bawah setiap peranan, pilih pengguna yang sesuai, dan klik **Sahkan**.

<Frame>
  ![](https://gw.alicdn.com/imgextra/i1/O1CN018ljZMUzBMyJ2i3PB_!!6000000003041-2-tps-1335-862.png)
</Frame>

## Urus Kebenaran

Urus Kebenaran menyediakan paparan berpusat untuk mengonfigurasikan kebenaran bagi semua jenis halaman dalam aplikasi.

1. Log masuk ke YiDA Workbench, cari aplikasi yang disasarkan, dan buka halaman **Tetapan Aplikasi**.
2. Dalam menu sebelah kiri pada halaman Tetapan Aplikasi, klik **Kebenaran Aplikasi** > **Urus Kebenaran**.
3. Cari halaman yang kebenarannya ingin anda urus, dan edit kebenaran tersebut di sebelah kanan.

  ![](https://gw.alicdn.com/imgextra/i4/O1CN01qvo35iot5CD5nlyk_!!6000000000728-2-tps-2858-1328.png)

## Butiran Kebenaran

Kebenaran yang tersedia untuk setiap pengguna dalam aplikasi diterangkan seperti berikut:

| **Pengguna** | **Penerangan** |
|---|---|
| **App Super Admin** | Mempunyai kebenaran penuh dalam Admin Console Aplikasi, termasuk pembinaan aplikasi, pengeditan, konfigurasi, dan pengurusan data. |
| **Data Admin** | Hanya mempunyai **kebenaran pengurusan data**. Boleh mengurus data aplikasi, membina laporan, dan mengurus set data serta perkhidmatan data. Tidak boleh mengakses reka bentuk borang, reka bentuk aliran kerja, halaman tersuai, tetapan halaman, atau konfigurasi admin aplikasi. |
| **Developer** | Mempunyai **kebenaran pembangunan aplikasi, tidak termasuk pengurusan data**. Tidak boleh mengakses pengurusan data aplikasi, pembinaan laporan, pengurusan set data, atau konfigurasi admin aplikasi. |

<Note>
Admin platform dan admin aplikasi mesti dikonfigurasikan pada halaman **pengurusan platform**. Untuk maklumat lanjut, sila lihat [Pengurusan kebenaran platform](/ms/yida/platform-admin/omvowq).
</Note>
