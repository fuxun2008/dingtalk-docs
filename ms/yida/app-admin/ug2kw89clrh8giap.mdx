Selepas mencipta aplikasi, rujuk artikel ini untuk mengubah suai maklumat asas, penerangan, tema, pautan navigasi, URL akses dan tetapan lain.

## Langkah

1. Log masuk ke Workbench YiDA dan buka halaman **Aplikasi Saya**.
2. Pilih aplikasi sasaran, kemudian pilih **···** > **Tetapan aplikasi**.

3. Dalam menu sebelah kiri, pilih **Tetapan asas**, kemudian edit maklumat asas aplikasi mengikut keperluan.
