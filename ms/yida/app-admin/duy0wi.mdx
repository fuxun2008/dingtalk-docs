| **Keupayaan** | **Edisi Percuma** | **Edisi Basic** | **Edisi Profesional** | **Edisi Dedicated** |
|---|---|---|---|---|
| **Sambung ke Sumber Data pangkalan data arus perdana** | Tidak disokong | Tidak disokong | 20 | 20 |
| **Bilangan Sumber Data Fail (skop Organisasi)** | Tidak disokong | 50 | 100 | 100 |

## Gambaran keseluruhan Sumber Data

Sumber data ialah huraian maklumat sumber data. Dengan menyambung ke sumber data, pelbagai data seperti pangkalan data setempat (memerlukan akses rangkaian awam) dan hamparan boleh disepadukan secara mendalam dengan aplikasi YiDA, sekali gus meningkatkan kecekapan interoperabiliti data. YiDA kini menyokong pengurusan dan penyelenggaraan sumber data seperti fail dan pangkalan data.

YiDA menyokong dua jenis sumber data berikut:

- Pangkalan data hubungan: MySQL (versi 5.7 atau lebih baharu), SQL Server (versi 2012 atau lebih baharu), Oracle (versi 19c atau lebih baharu), PostgreSQL (versi 9.0 atau lebih baharu), Hologres.
- Fail: fail Excel, fail CSV. Untuk cara mencipta set data daripada fail, lihat Cipta set data daripada Fail.

## Tambah Sumber Data

Ikuti langkah di bawah untuk menambah sumber data jenis pangkalan data.

1. Log masuk ke workbench YiDA dan pergi ke Halaman Tetapan Aplikasi.
2. Pilih Kilang Data > Set Data secara berurutan, kemudian klik Cipta set data.
3. Dalam kotak dialog Cipta Sumber Data, isikan maklumat pangkalan data dan klik Sahkan untuk melengkapkan penciptaan.

| **Item konfigurasi** | **Penerangan** |
|---|---|
| **Jenis Sumber Data** | Pilih jenis pangkalan data hubungan yang hendak ditambah. Lima pangkalan data berikut disokong.<br />• MySQL (versi 5.7 atau lebih baharu)<br />• SQL Server (versi 2012 atau lebih baharu)<br />• Oracle (versi 19c atau lebih baharu)<br />• Postgre (versi 9.0 atau lebih baharu)<br />• Hologres |
| **Nama** | Masukkan nama untuk sumber data baharu. Sehingga 200 aksara disokong. |
| **Alamat pangkalan data & port** | Masukkan alamat akses rangkaian awam pangkalan data anda dan nombor port yang berkaitan.<br />Contohnya:<br />• Alamat pangkalan data: aliwork<br />• Port: 3306 |
| **Akaun & kata laluan** | Masukkan akaun akses dan kata laluan untuk pangkalan data. |
| **Nama pangkalan data** | Masukkan nama pangkalan data. Sehingga 30 aksara disokong. |
| **URL** | Masukkan URL akses penuh pangkalan data.<br />**Nota**: Penghuraian sekali klik menggunakan rentetan [JDBC](https://docs.oracle.com/middleware/1213/eventprocessing/server-administer/CEPAG.epub) disokong. URL sumber data tidak boleh membawa parameter. |
