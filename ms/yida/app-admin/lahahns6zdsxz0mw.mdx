Jenis fail yang disokong pada masa ini termasuk fail Excel `.xls` dan `.xlsx` yang biasa digunakan dalam sistem maklumat organisasi, serta fail CSV (Comma Separated Values) yang sesuai untuk pemprosesan teks berskala besar. Medan fail yang dimuat naik diproses sebagai string secara lalai, dan pelarasan jenis medan (numerik, tarikh, dan lain-lain) disokong supaya anda dapat menggunakan jenis data yang betul dalam setiap senario.

## Langkah

Ikuti langkah di bawah untuk mencipta set data daripada fail tempatan.

1. Log masuk ke workbench YiDA dan buka halaman Tetapan Aplikasi.
2. Klik Data Factory > Set Data.
3. Klik Cipta Set Data > Daripada Fail.

<Frame>
  ![](https://gw.alicdn.com/imgextra/i4/O1CN01PLLvkzH2TOC2L8uo_!!6000000001218-2-tps-1153-681.png)
</Frame>

4. Rujuk maklumat berikut untuk memilih dan memuat naik fail.

| **Item Konfigurasi** | **Penerangan** |
|---|---|
| **Nama Set Data** | Masukkan nama set data, sehingga 30 aksara. |
| **Jenis Fail** | Pilih Jenis Fail dan helaian yang anda ingin muat naik. |
| **Pengepala** | Nyatakan sama ada fail yang dimuat naik mengandungi pengepala.<br />Jika fail hamparan dengan pengepala ditetapkan sebagai tiada pengepala, lajur pengepala dalam hamparan akan dianggap sebagai rekod data pertama dalam set data. |
| **Fail Dimuat Naik** | Pilih fail untuk dimuat naik.<br />Hamparan yang dimuat naik mesti memenuhi keperluan berikut:<br />• **Jenis Fail**: Hanya fail `.xlsx` **dan** `.csv` disokong.<br />• **Saiz Fail**: Saiz fail tidak boleh melebihi **50M**. Untuk fail besar, simpan sebagai fail CSV dan muat naik semula.<br />• **Nota**: Kawasan kandungan Excel **tidak boleh mengandungi sel bergabung atau fungsi formula**, dan **pengepala** **tidak boleh mengandungi** sel kosong. |

<Frame>
  ![](https://gw.alicdn.com/imgextra/i3/O1CN01aAMMmNFO2SG2KlUf_!!6000000006970-2-tps-1150-651.png)
</Frame>

5. Konfigurasikan alias medan dan jenis medan set data, kemudian klik Seterusnya apabila selesai.

Medan borang menyokong empat jenis data: **STRING**, **INTEGER**, **DOUBLE**, dan **DATE**.

<Frame>
  ![](https://gw.alicdn.com/imgextra/i3/O1CN01BuN5LMUBrKI2L8ws_!!6000000005472-2-tps-1153-809.png)
</Frame>

6. Pratonton data untuk mengesahkan ia betul. Jika data betul, klik Sahkan untuk menyelesaikan penciptaan.
