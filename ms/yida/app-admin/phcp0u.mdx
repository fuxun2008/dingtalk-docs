## Senario Yang Berkenaan

- Apabila anda perlu menjana salinan aplikasi untuk digunakan semula atau diuji oleh sub-jabatan lain
- Apabila anda perlu menukar antara halaman borang dan borang aliran kerja

## Salin Aplikasi

Ikuti langkah-langkah di bawah untuk menyalin aplikasi. Menyalin aplikasi biasanya digunakan untuk menjana salinan aplikasi untuk digunakan atau diuji oleh sub-jabatan lain.

1. Log masuk ke workbench YiDA, kemudian klik untuk masuk ke Aplikasi Saya.
2. Pilih aplikasi yang ingin anda salin, klik ··· di penjuru kiri bawah aplikasi tersebut, dan pilih Salin Aplikasi.

<Note>
Jika halaman **Aplikasi Saya** anda berada dalam **mod Senarai**, klik **Lain-lain** dalam lajur Tindakan bagi aplikasi sasaran.
</Note>

  ![](https://gw.alicdn.com/imgextra/i2/O1CN01KuOUbO846UI2HcOu_!!6000000001113-2-tps-1125-739.png)
</Frame>

3. Dalam dialog yang dipaparkan, masukkan nama untuk aplikasi baharu, dan klik Sahkan untuk melengkapkan penyalinan.

<Frame>
  ![](https://gw.alicdn.com/imgextra/i2/O1CN01kuD6Y7u4yVE2USTn_!!6000000000459-2-tps-1227-764.png)
</Frame>

<Note>
- Jika sesebuah aplikasi mengandungi lebih daripada 80 halaman, penyalinan mungkin gagal. Berhati-hati semasa menyalin aplikasi yang mengandungi bilangan halaman yang sangat banyak.
- Selepas YiDA Dedicated mengaktifkan tadbir urus Aplikasi, aplikasi yang disalin berada dalam keadaan dinyahaktifkan secara lalai.
</Note>

### Salin Halaman Merentas Aplikasi

<Check>
Tindakan ini membawa risiko (seperti kehilangan data atau kegagalan formula), dan pasukan rasmi tidak bertanggungjawab untuk pembaikan. Gunakan dengan berhati-hati.
</Check>

Ikuti langkah-langkah di bawah untuk menyalin halaman merentas aplikasi.

1. Buka pereka bentuk borang bagi halaman asal A, tekan F12 untuk membuka konsol, tukar ke modul konsol, masukkan kod pengubahsuaian gaya, dan tekan Enter.

<Frame>
  ![](https://gw.alicdn.com/imgextra/i3/O1CN01cpDGsKtgInL3ldeg_!!6000000002852-2-tps-1856-1006.png)
</Frame>

```css
// Pengubahsuaian gaya
document.querySelector('.lc-left-area-bottom div:last-child').style.display = 'block'
```

2. Menggunakan langkah yang sama seperti langkah 1, buka kod sumber halaman pada halaman B.
3. Salin kod sumber halaman A ke dalam konsol kod sumber halaman B, dan klik Import Schema untuk melengkapkan penyalinan halaman merentas aplikasi.
