Jadual berikut menerangkan setiap keupayaan pengurusan sumber data secara terperinci:

| **Nama** | **Tujuan** |
|---|---|
| [**Set Data**](/ms/yida/app-admin/roe3o1) | Urus semua sumber data jadual tunggal, jadual paparan (perkaitan berbilang jadual), penyediaan data (penyelesaian luar talian data besar), dan sumber data merentas aplikasi (borang) bagi aplikasi semasa di satu tempat. Set Data berfungsi sebagai unit kawalan data standard YiDA untuk senario keterhubungan data. |
| [**Jadual Paparan**](/ms/yida/app-admin/oim554) | Jadual paparan memproses data borang sedia ada melalui perkaitan jadual tunggal atau berbilang jadual, dan turut menyokong mod jadual perantaraan untuk memperkukuh pemprosesan data. Senario seperti visualisasi laporan dan pautan borang boleh memanggil data daripada jadual paparan secara terus. |
| [**Merentas Aplikasi**](/ms/yida/app-admin/btrtnt) | Juga dikenali sebagai capaian data merentas aplikasi. Panggil data borang daripada aplikasi YiDA lain dalam aplikasi semasa untuk membolehkan keterhubungan data merentas aplikasi YiDA. |
| [**Sumber Data**](/ms/yida/app-admin/duy0wi) | Sumber data menerangkan dari mana data berasal. YiDA menyokong pengurusan dan penyelenggaraan sumber data seperti fail dan pangkalan data. |
| [**Kad Data**](/ms/yida/app-admin/cpkmxvpgchx339qq) | Pembawa visualisasi data baharu. Berbeza daripada laporan yang mempunyai saluran analisis yang lengkap, kad data menggabungkan carta berasaskan senario yang berserak dengan pantas untuk digunakan dalam portal YiDA. Kad juga dilengkapi keupayaan siaran terbina dalam yang menyegerakkan data kepada kumpulan sebagai gambar seketika. |
| [**Perkhidmatan Data**](/ms/yida/app-admin/fw9qtv) | Perkhidmatan data memproses set data dengan memilih medan tertentu dan menukarkannya kepada perkhidmatan API. Ia pada masa ini hanya boleh digunakan dalam nod Kad pereka bentuk Integrasi & Automasi/aliran kerja. |
| [**Penyediaan Data**](/ms/yida/app-admin/ykemo6) | Sebelum dianalisis dan digunakan, bersihkan, gabungkan, dan ubah data mentah untuk mengagregatkan data yang berselerak menjadi set data yang piawai, bagi menyokong analisis visual dan membuat keputusan berdasarkan data. |
