title: "Tetapan Aplikasi"
description: "Memperkenalkan Urus Aplikasi dan tetapan Asas, termasuk konfigurasi asas aplikasi, persediaan kebenaran, mengaktifkan dan menyahaktifkan aplikasi, serta panduan operasi berkaitan."
polished: true
---

Urus aplikasi dan konfigurasikan tetapan asas umum. Hanya admin aplikasi, admin platform, sub-admin, atau Super Admin bagi Organisasi mempunyai kebenaran untuk mengurus dan mengkonfigurasikan aplikasi.

Kandungan:

- Tetapan asas aplikasi
- Tetapan kebenaran aplikasi
- Aktifkan dan nyahaktifkan aplikasi
- Dapatkan pautan aplikasi
- Sesuaikan URL akses aplikasi
- Terbitkan aplikasi
