Silang aplikasi, juga dikenali sebagai pengambilan data silang aplikasi, membolehkan sesuatu aplikasi menarik data borang daripada aplikasi YiDA lain untuk mewujudkan saling hubungan data antara aplikasi tersebut. **Buat masa ini, hanya data borang daripada aplikasi lain dalam Organisasi Anda disokong.**

## Kes Penggunaan

### Silo Data

- Apabila kerumitan perniagaan meningkat dan penggunaan low-code semakin mendalam, organisasi sering menjalankan pelbagai aplikasi YiDA untuk menangani senario perniagaan yang berbeza.

- Apabila data tidak dapat mengalir antara aplikasi, silo data timbul di peringkat aplikasi YiDA dalam organisasi.
- Komunikasi silang aplikasi dan pengambilan data menjadikan pengurusan digital operasi perniagaan lebih sistematik.

### Perkongsian Data Antara Laporan Lama dan Baharu

Semasa melancarkan ciri produk baharu, kami mengambil pendekatan yang berhati-hati terhadap penaiktarafan automatik aplikasi sedia ada bagi memastikan kestabilan. Keupayaan baharu—seperti laporan YiDA baharu dan senarai perkaitan—terpakai kepada aplikasi yang baru dicipta terlebih dahulu.

Sebagai contoh, untuk menggunakan laporan baharu:

- Cipta "Aplikasi B" baharu tanpa menjejaskan borang dalam "Aplikasi A" sedia ada anda.
- Dalam "Aplikasi B", konfigurasikan **Silang Aplikasi** untuk mengambil data borang yang diperlukan daripada "Aplikasi A".
- Dalam "Aplikasi B", pilih data seperti biasa untuk membina laporan anda.

### Perkongsian Data Antara Aplikasi Lama dan Baharu

Oleh sebab seni bina teras YiDA telah dinaik taraf sepenuhnya, versi lama tidak lagi diselenggara. Walau bagaimanapun, sebilangan kecil aplikasi YiDA lama kekal dalam penyelenggaraan jangka panjang. YiDA terus meneroka penyelesaian supaya rakan kongsi awal YiDA dapat memanfaatkan ciri baharu semaksimum mungkin.

**Sebelum ini**

- Pengguna perlu mencipta aplikasi baharu dan membina semula setiap borang dari awal.

**Sekarang**

- YiDA menyokong penciptaan set data daripada borang silang aplikasi. Dengan keupayaan silang aplikasi, anda boleh berkongsi data antara aplikasi lama dan baharu dengan mudah.

## Langkah

1. Log masuk ke workbench YiDA dan buka halaman tetapan aplikasi.
2. Klik **Data Factory** > **Set Data**.
3. Klik **Cipta set data** > **Daripada silang aplikasi**.
