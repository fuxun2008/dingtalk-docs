## Langkah

Ikuti langkah di bawah untuk menerbitkan aplikasi YiDA ke workbench organisasi anda.

<Note>
Hanya Admin Organisasi boleh menerbitkan aplikasi YiDA ke workbench DingTalk. Jika anda bukan Admin Organisasi, hubungi Admin Organisasi anda untuk menerbitkan aplikasi tersebut.
</Note>

### PC

1. Log masuk ke workbench YiDA dan klik **My Apps**.
2. Cari aplikasi yang ingin anda terbitkan, kemudian klik **···** > **App Settings**.

<Note>

### Mudah alih

1. Buka DingTalk pada peranti mudah alih anda, pergi ke workbench organisasi anda, dan ketik **YiDA** untuk membuka workbench YiDA.
2. Ketik **App Center** > **Created by Me**, kemudian ketik aplikasi yang ingin anda terbitkan untuk membuka halaman butirannya.
3. Ketik **···** di penjuru kanan atas, kemudian ketik **Publish to Workbench** di bawah App Management untuk melengkapkan proses penerbitan.

## Soalan Lazim

**S: Bagaimana saya berkongsi satu borang ke sembang kumpulan?**

YiDA menyediakan pilihan terbina dalam untuk menambah halaman ke kumpulan. Di penjuru kanan atas borang, klik **More** > **Add this page to group**.

<Frame>
  ![](https://gw.alicdn.com/imgextra/i1/O1CN019uP4Z6s2SuE3tBtu_!!6000000005660-2-tps-1916-882.png)
</Frame>

<Note>
Menambah ke kumpulan tidak disokong melalui pelayar. Akses aplikasi menggunakan klien DingTalk untuk menambahkannya.
</Note>

<Frame>
  ![](https://gw.alicdn.com/imgextra/i4/O1CN01hXJG9Bzqy4F3jN8Q_!!6000000004424-2-tps-1838-864.png)
</Frame>

**S: Bagaimana saya menukar kedudukan paparan aplikasi pada workbench DingTalk, atau mengeluarkan aplikasi?**

J: Pada aplikasi mudah alih DingTalk, pergi ke **Workbench** > **YiDA**, cari kumpulan yang mengandungi aplikasi tersebut, ketik **Manage** > **Sort Apps**, kemudian tekan lama satu aplikasi untuk menyusun semula kedudukannya.

<Frame>
  ![](https://gw.alicdn.com/imgextra/i4/O1CN01d8EoAQX3eYC3mtgG_!!6000000001836-2-tps-1866-926.png)
</Frame>

<Note>
Jika butang Manage tidak kelihatan, anda bukan admin bagi organisasi DingTalk semasa. Minta admin untuk melakukan tindakan ini.
</Note>

**S: Bagaimana saya mengeluarkan aplikasi yang tidak diperlukan daripada workbench?**

**J: Laluan**: Aplikasi mudah alih DingTalk > **Workbench** > **YiDA** > cari kumpulan yang mengandungi aplikasi tersebut > **Manage** > ketik bar merah pada aplikasi untuk mengeluarkannya.

<Note>
Tindakan ini hanya mengeluarkan aplikasi daripada workbench; ia tidak memadam aplikasi YiDA itu sendiri.
</Note>

<Frame>
  ![](https://gw.alicdn.com/imgextra/i3/O1CN01apNimcmKf3K0velV_!!6000000004491-2-tps-458-943.png)
</Frame>

**S: Bagaimana saya menjadikan aplikasi yang diterbitkan hanya boleh dilihat oleh pengguna tertentu?**

**J: Laluan**: Aplikasi mudah alih DingTalk > **Workbench** > **YiDA** > cari kumpulan yang mengandungi aplikasi tersebut > **Manage** > ketik **Visible to all** di bawah aplikasi tersebut.

<Frame>
  ![](https://gw.alicdn.com/imgextra/i2/O1CN01qwzTEGi2fTC0w9z8_!!6000000004756-2-tps-462-948.png)
</Frame>

**S: Bagaimana saya menerbitkan ke workbench tersuai DingTalk?**

<Frame>
  ![](https://gw.alicdn.com/imgextra/i2/O1CN01aT8qscesE5G0wHn4_!!6000000002786-2-tps-463-951.png)

J: Buat masa ini, YiDA hanya menyokong penerbitan ke kumpulan tersuai bagi workbench standard. Untuk menerbitkan ke workbench tersuai DingTalk, terbitkan aplikasi ke workbench standard terlebih dahulu, kemudian pautkan pintasan ini ke dalam workbench tersuai.

**S: Penerbitan gagal apabila skop keterlihatan ditetapkan kepada "Only me". Apa yang perlu saya lakukan?**

J: Apabila keterlihatan ditetapkan kepada "Only me", tukar **My Apps** kepada pengurusan manual untuk menjadikan aplikasi tersebut kelihatan.

- 1. Pada workbench, bahagian aplikasi menyokong dua mod: "Manual management" dan "Recently Used". Lalainya ialah "Recently Used". Untuk melihat aplikasi yang telah diterbitkan, tukar kepada "Manual management" seperti ditunjukkan dalam video. 2. Aplikasi yang diterbitkan di bawah kategori "My Apps" pada workbench tidak dianggap "diterbitkan", jadi status penerbitan tidak berubah.
