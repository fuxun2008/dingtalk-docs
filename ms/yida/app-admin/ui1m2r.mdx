Halaman log masuk senyap dalam aplikasi YiDA boleh diterbitkan secara individu ke workbench dalaman organisasi anda, atau ditukar menjadi tinjauan untuk diedarkan secara luaran. Artikel ini menerangkan cara menerbitkan halaman borang secara individu.

## Prosedur

Terbitkan halaman borang menggunakan salah satu kaedah berikut.

### Kaedah 1: Terbitkan melalui Aplikasi Web DingTalk Open Platform

<Steps>
  <Step title="Langkah 1">
    Log masuk ke [workbench YiDA](https://www.yidaapps.com/workPlatform).
  </Step>
  <Step title="Langkah 2">
    Klik **My apps**, kemudian pilih dan buka aplikasi sasaran untuk melihat halaman butirannya.
  </Step>
  <Step title="Langkah 3">
    Pilih halaman yang hendak diterbitkan, kemudian klik <Icon <img className="inline-icon" src="https://gw.alicdn.com/imgextra/i3/O1CN01aOJXYIVdCrB02GUA_!!6000000003690-2-tps-18-12.png" width="18" alt="" /> icon="ellipsis" /> > **Publish page**.
  </Step>
</Steps>

<Frame>
  ![](https://gw.alicdn.com/imgextra/i2/O1CN01nt2rax09UAK2L8vI_!!6000000002773-2-tps-1153-711.png)
</Frame>

4. Pilih **Publish within organization** dan salin **access URL** halaman tersebut.
5. Log masuk ke backend pembangun DingTalk Open Platform, cipta aplikasi dalaman, dan aktifkan keupayaan aplikasi web.

<Note>
Untuk langkah mencipta aplikasi, rujuk dokumentasi Open Platform.
</Note>

6. Masukkan pautan halaman pada medan URL laman utama aplikasi web, kemudian klik **Save**.

<Frame>
  ![](https://gw.alicdn.com/imgextra/i1/O1CN01yv6BPHeHbqK5SsNY_!!6000000002981-2-tps-2692-1208.png)
</Frame>

7. Klik **Publish app** > **Version management and publish** > **Create new version**.
8. Konfigurasikan maklumat versi dan skop kebolehlihatan, kemudian klik **Save** untuk melengkapkan penerbitan.

<Frame>
  ![](https://gw.alicdn.com/imgextra/i3/O1CN01IwFXNFdCisE5EWka_!!6000000003695-2-tps-2578-1590.png)
</Frame>

### Kaedah 2: Cipta Pintasan Borang pada Workbench

Cipta pintasan ke halaman borang pada workbench DingTalk daripada aplikasi mudah alih DingTalk.

1. Dapatkan access URL halaman borang. Rujuk Kaedah 1 untuk butiran lanjut.
2. Buka workbench dalam aplikasi mudah alih DingTalk dan ketik **Add**.
3. Pilih **Custom app**, kemudian ketik **Connect to workbench**.
4. Masukkan maklumat aplikasi, kemudian ketik **Add** untuk selesai.
