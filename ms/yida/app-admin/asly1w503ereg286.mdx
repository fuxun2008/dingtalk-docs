## 1. Pengenalan

### 1.1 Gambaran Keseluruhan Ciri

Segerakkan data AI Table / borang Kelulusan OA untuk menghubungkan AI Table / Kelulusan OA dengan YiDA, supaya pengguna dapat merujuk data AI Table / Kelulusan OA secara terus di pihak YiDA.

### 1.2 Kes Penggunaan

- Penganjur acara boleh menggunakan AI Table / Kelulusan OA untuk menguruskan setiap peringkat acara — pendaftaran peserta, penjadualan syif, logistik, dan banyak lagi. Peserta boleh menghantar maklum balas dan permintaan melalui borang.
- Pengurus keselamatan boleh menggunakan borang segerak AI Table untuk merekodkan hasil pemeriksaan keselamatan, laporan insiden, dan tindakan pembetulan. Ini membantu mencegah insiden serta melindungi keselamatan dan kesejahteraan pekerja.

<Tip>
[Nota]

Apabila data sejarah melebihi 10,000 rekod dan anda mahu kesemuanya disegerakkan ke dalam borang YiDA semasa permulaan, terdapat dua penyelesaian sementara pada masa ini:

Pilihan 1: Di bawah "Peraturan segerak" — "Skop data segerak dan Susun", tetapkan "Syarat penapis" dan kemas kini merentas beberapa larian segerak manual.

Pilihan 2: Selepas borang dicipta, bawa masuk baki data sekali gus melalui "Import Pukal" ke dalam borang yang berkaitan.
</Tip>

### 2.5 Lihat Data

Setelah dicipta, anda akan melihat "borang biasa" baharu dalam aplikasi, berserta set data dengan nama dan jenis yang sama yang turut dijana pada masa yang sama.

Segerak pertama selepas penciptaan mungkin mengambil masa beberapa minit — jika data tidak sepadan dengan sumber, tunggu sebentar.

Klik "Segerak Set Data" untuk melihat log segerak. Lihat ilustrasi di bawah:

Selepas penciptaan, jika anda perlu mengedit peraturan segerak atau memuat semula data secara manual, cari titik masuk dalam bar tindakan lungsur borang seperti ditunjukkan di bawah.
