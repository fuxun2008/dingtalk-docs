**Penyediaan data** ialah ciri utama platform low-code YiDA. Ia membantu pengguna perusahaan membersihkan, mengintegrasikan, dan mengubah data mentah sebelum menjalankan analisis data atau membina aplikasi. Artikel ini menerangkan cara mencipta penyediaan data.

Penyediaan data menggunakan penyelesaian ETL (Extraction, Transformation, Loading) tanpa kod untuk memproses data daripada aplikasi YiDA, pangkalan data perusahaan luaran, data berasaskan fail, dan sumber data rasmi DingTalk (termasuk Roster, OA, Smart HR, Kehadiran, dan lain-lain). Dengan membina aliran kerja pemprosesan data, ia menyatukan data yang berselerak menjadi set data piawai yang menyokong analisis visual dan membuat keputusan berdasarkan data.

## Prosedur

1. Log masuk ke workbench YiDA dan buka halaman tetapan aplikasi.
2. Klik **Data Factory** > **Penyediaan Data**.
3. Klik **Cipta Penyediaan Data** untuk membuka pereka bentuk penyediaan data.
4. Seret nod **Input** ke atas kanvas dan konfigurasikan **sumber input**.

Tetapkan data input kepada **set data** atau **Sumber Data**.

| **Sumber Data** | **Medan (tidak dikemas kini secara masa nyata; rujuk paparan sebenar penyediaan data)** |
|---|---|
| **Metrik umum** | Bilangan Kenalan, bilangan penghantar log, kadar penghantaran log, jumlah DING dihantar, jumlah perbualan kumpulan, bilangan laporan perbelanjaan, bilangan dokumen dicipta dalam 1 hari terakhir, dan lain-lain |
| **Roster** | Nama pekerja, jawatan, ID Pekerja, nama jabatan, jenis percubaan, tarikh pengambilan, tarikh pengesahan jawatan, dan lain-lain |
| **Kelulusan OA** | Medan perniagaan tersuai borang, Penghantar, masa penghantaran, penyokong, status kelulusan, masa selesai kelulusan, rekod kelulusan, dan lain-lain |
| **Smart HR** | Tarikh pengambilan, tahap jawatan, tarikh pengesahan jawatan, tahap pengesahan jawatan, tarikh perletakan jawatan, sebab perletakan jawatan, dan lain-lain |
| **Kehadiran (dalam tempoh enam bulan terakhir)** | Nama pengguna, jabatan, masa daftar masuk, penanda kerja lebih masa, penanda kehadiran dijangka, nama kumpulan kehadiran, penanda kerja luar, penanda tidak daftar masuk, dan lain-lain |
