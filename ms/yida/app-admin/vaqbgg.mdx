## 1. Pengenalan

### 1.1 Gambaran Keseluruhan Ciri

Mencipta borang daripada Excel membolehkan anda mereka bentuk borang dengan pantas dan mengimport data Excel terus ke dalamnya untuk pengurusan data yang lancar.

### 1.2 Kes Penggunaan

Dalam senario pengurusan inventori yang memerlukan kemasukan nama produk, spesifikasi, kuantiti dan harga unit, masukkan nama Komponen dan data dalam hamparan Excel untuk mengimport maklumat produk dengan pantas ke dalam jadual data asas.

## 2. Langkah-langkah

### 2.1 Pilih Fail Excel

Laluan: Cipta borang >> Import daripada Excel >> Pilih fail Excel

### 2.2 Pratonton Data

## 3. Peraturan Import

Fail Excel yang dimuat naik mesti memenuhi keperluan berikut:

• Sel yang digabungkan tidak dibenarkan.

• Saiz Fail tidak boleh melebihi 2 MB.

• Hanya fail *.xls dan *.xlsx disokong.

• Pastikan baris pengepala helaian tidak mengandungi sel kosong. Jika tidak, sistem tidak akan mengimport data daripada helaian tersebut.
