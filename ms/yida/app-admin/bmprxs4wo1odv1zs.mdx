Selain menggunakan Templat, Excel, AI, dan mencipta aplikasi kosong, anda juga boleh menyesuaikan aplikasi.

## Langkah-langkah

1. Log masuk ke Workbench YiDA.
2. Klik Cipta Aplikasi di penjuru kanan atas.
3. Dalam kotak dialog Cipta Aplikasi yang dipaparkan, klik Saya ingin berunding tentang penyesuaian di penjuru kiri bawah kotak dialog tersebut.
