Nod automatik terutamanya digunakan untuk memberikan data pihak ketiga kepada pemboleh ubah proses dengan mengkonfigurasikan Tindakan pelaksanaan, sama ada melalui pendaftaran perkhidmatan atau Groovy.

## Perkhidmatan Pihak Ketiga

Semasa mengkonfigurasikan Tindakan pelaksanaan, anda boleh Pilih perkhidmatan pihak ketiga yang telah berjaya didaftarkan. Kemudian berikan nilai pulangan perkhidmatan pihak ketiga tersebut kepada pemboleh ubah proses.

<Note>
Perkhidmatan pihak ketiga mesti didaftarkan terlebih dahulu. Untuk maklumat lanjut, lihat **Pendaftaran Perkhidmatan**.
</Note>

## Tetapan Groovy

Anda boleh memberikan nilai kepada pemboleh ubah proses melalui Tetapan Groovy. Masukkan nama pemboleh ubah proses yang betul dan tulis nilai yang hendak diberikan dalam skrip pelaksanaan.

<Note>
- Pemboleh ubah mesti ditakrifkan dalam Atribut proses.
- Tanda petikan mesti ditambah semasa memberikan nilai string, contohnya "HelloWorld".
</Note>

Selepas penetapan, nilai ini boleh digunakan untuk penilaian dalam peraturan pelaksanaan dalam talian.

## Arahan Konfigurasi Tindakan Pelaksanaan

Jika antara muka callback ialah antara muka HTTP, ia mesti memenuhi keperluan berikut:

- Kaedah HTTP mesti POST.
- Parameter Permintaan mesti diletakkan dalam RequestBody.
- uuid ialah kata kunci sistem dan tidak boleh digunakan.
- Jika kunci Tandatangan SHA256 digunakan semasa pendaftaran perkhidmatan, parameter callback __hmacSha256 mesti ditambah.
- md5 ialah kaedah Tandatangan Lalai yang ditambah oleh callback perkhidmatan. Jika tiada kunci ditetapkan semasa pendaftaran perkhidmatan, kunci Lalai sistem digunakan untuk menandatangani. Jika kunci ditetapkan, kunci yang Dikonfigurasi digunakan untuk menandatangani, dan parameter callback ialah sign.

Rujuk contoh mudah antara muka callback berikut yang ditulis dalam Java:

```java
@RequestMapping(value = "/callback",method = RequestMethod.POST)
@ResponseBody
public List<String> callback(@RequestBody CallbackParam callbackParam) {
  // Format nilai pulangan: ["ID Pekerja 1","ID Pekerja 2"]; jika pulangan kosong, pulangkan null secara terus
  List<String> result = new ArrayList<>();
  // do something
  return result;
}
```
