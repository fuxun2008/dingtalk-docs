Dalam pereka bentuk aliran kerja lanjutan, apabila anda mengkonfigurasikan peraturan penyokong untuk nod tugas pengguna, memilih **Peraturan lain** akan mendedahkan pilihan **Permintaan Groovy**. Tulis skrip Groovy untuk mengawal penyokong berdasarkan keperluan perniagaan anda.

## Prasyarat

Sebelum menggunakan skrip Groovy, biasakan diri anda dengan Groovy. Untuk maklumat lanjut, lihat [tutorial Groovy W3C](https://www.w3cschool.cn/groovy/groovy_overview.html) dan [pengenalan Apache Groovy](http://www.groovy-lang.org/).

Gunakan **Permintaan Groovy** untuk penyokong nod kelulusan kewangan.

`textField_kov80fx9` ialah pengecam unik bagi Kotak Teks Satu Baris pada borang.

**Nota**: Semasa menyunting skrip Permintaan Groovy, gunakan kaedah `toInteger()` kerana pembolehubah aliran kerja dalaman adalah rentetan (string).

Kaedah `toInteger()` adalah Wajib secara Lalai. Gunakan Format berikut sebagai rujukan:

<Frame>
  ![](https://gw.alicdn.com/imgextra/i1/O1CN01wU0vfcPzD3F2iYc5_!!6000000005299-2-tps-1339-822.png)
</Frame>

Salin dan gunakan kod berikut secara terus:

```javascript
if(uniqueIdOfSingleLineTextBox.toInteger()<100  {
         return['approverUserId']
    }  else  {
       return['approverUserId']
    }
```

Kod ini bermaksud: apabila Nombor dalam Kotak Teks Satu Baris kurang daripada 100, hala Permintaan Kepada seorang penyokong; jika tidak, hala Kepada penyokong lain.

Anda boleh mengembalikan pelbagai penyokong.
