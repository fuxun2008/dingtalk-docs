Topik ini menerangkan cara menambah dan menggunakan nod skrip, serta cara nod hiliran boleh menggunakan data yang dikeluarkannya.

## Kes Penggunaan

Semasa reka bentuk, tambah nod skrip dan tulis JavaScript untuk membaca data input, memproses data perantaraan, dan menyuntik hasilnya melalui object output terbina dalam. Ini membolehkan pemprosesan data berskrip dalam orkestrasi aliran perniagaan.

## Akses Nod Skrip

- Pilihan 1: Edit borang aliran kerja, buka halaman reka bentuk aliran kerja, dan pilih **Nod pembangun** > **Nod skrip**.
- Pilihan 2: Edit aplikasi, pergi ke **Integrasi & Automasi**, pilih aliran automasi sasaran, buka konfigurasi reka bentuknya, dan tambah nod skrip.

## Nota

- Nod skrip baharu menggantikan nod Groovy sebelumnya, menjadikan penskripan boleh diakses oleh lebih ramai pembangun.
- Nod skrip hanya menyokong sintaks ES5. ES6 dan seterusnya tidak disokong.
- Pengendalian nod kemas kini kelompok belum disokong lagi.
- Elakkan pemprosesan data yang memerlukan sejumlah besar memori. Melebihi 10 MB (sementara; YiDA mungkin melaraskan had ini) akan mencetuskan ralat memori berlebihan. Penggunaan CPU melebihi 5 saat (contohnya, akibat gelung tak terhingga) akan mencetuskan mekanisme perlindungan automatik dan menimbulkan ralat.
- Permintaan rangkaian seperti XHR dan fetch tidak disokong. Object dan fungsi peringkat atas seperti `window`, `console`, dan `print` tidak disokong.
- Mentakrifkan fungsi di dalam blok kod disokong.
- Jangan tambah pernyataan return di luar fungsi.
