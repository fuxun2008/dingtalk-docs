</Steps>

3. Dalam menu sebelah kiri, klik Pengurusan Kebenaran Platform, kemudian tentukan sama ada anda mahu mengaktifkan dua kebenaran berikut.

## Urus Admin Platform

Ikuti langkah-langkah di bawah untuk mengurus Admin Platform.

1. Pergi ke halaman Pengurusan Kebenaran Platform dan klik Admin Platform.
2. Klik Tambah Pengguna, pilih pengguna yang berkaitan, kemudian klik Sahkan untuk melengkapkan persediaan Admin Platform.

<Note>
Admin organisasi DingTalk disegerakkan secara automatik sebagai Admin Platform YiDA dan boleh mengurus platform YiDA. Untuk menukar konfigurasi ini, pergi ke [Admin Console DingTalk](http://oa.dingtalk.io) dan batalkan kebenaran berkaitan YiDA mereka.
</Note>

## Soalan Lazim

**S: Mengapakah pengguna baharu hanya melihat satu Admin apabila memohon kebenaran YiDA, walaupun pusat kebenaran menunjukkan bahawa organisasi mempunyai beberapa Admin?**

J: Untuk mengelakkan gangguan kepada eksekutif organisasi, Admin Platform dipaparkan dahulu semasa memilih Admin. Admin organisasi hanya dipaparkan apabila tiada Admin Platform wujud.

**S: Mengapakah saya tidak mempunyai kebenaran YiDA walaupun saya adalah Super Admin atau Sub Admin bagi Kenalan DingTalk?**

J: Semak sama ada Admin Platform YiDA telah ditetapkan dalam Aplikasi YiDA.

- Jika Admin Platform YiDA telah ditetapkan, kebenaran Admin Platform YiDA diutamakan.
- Jika tiada Admin Platform YiDA ditetapkan, YiDA akan secara automatik mewarisi Super Admin dan Sub Admin daripada Kenalan organisasi DingTalk.
