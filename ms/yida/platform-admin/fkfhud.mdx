Templat pemberitahuan mesej menghantar pemberitahuan mesej DingTalk atau tugasan kepada pengguna yang ditetapkan apabila aliran kerja borang mencapai langkah tertentu, berdasarkan templat yang telah dikonfigurasikan sebelumnya. Rujuk artikel ini untuk mempelajari cara mengonfigurasikan templat pemberitahuan mesej.

| Ciri | Pelan percuma | Edisi Basic | Edisi Profesional | Edisi Dedicated |
|---|---|---|---|---|
| Templat pemberitahuan mesej | Tidak disokong | Disokong | Disokong | Disokong |

## Guna Templat Mesej

Anda boleh menggunakan templat mesej dengan dua cara:

- Kaedah 1: Gunakannya dalam langkah Pemberitahuan mesej pada Reka bentuk aliran kerja bagi Borang aliran kerja. Untuk butiran lanjut, rujuk langkah Pemberitahuan mesej.
- Kaedah 2: Gunakannya dalam Tetapan halaman borang. Untuk butiran lanjut, rujuk Pemberitahuan mesej borang.

<Note>
Borang biasa kini tidak menyokong templat mesej Tugasan DingTalk.
</Note>

## Format Pemboleh Ubah Terbina Dalam

Kandungan mesej dalam templat mesej menyokong pemboleh ubah yang boleh dikonfigurasikan. Setiap pemboleh ubah ialah ID komponen borang, dalam format `$!{Component ID}`. Apabila mesej dihantar, YiDA secara automatik menggantikan pemboleh ubah tersebut dengan nilai komponen borang.

| Pemboleh ubah | Medan | Borang | Aliran kerja |
|---|---|---|---|
| $!\{formInstId} | ID Instans | ✓ | ✓ |
| $!\{formUuid} | Kod borang | ✓ | ✓ |
| $!\{formTitle} | Nama borang | ✓ | ✓ |
| $!\{formTitleEn} | Nama borang dalam bahasa Inggeris | ✓ | ✓ |
| $!\{title} | Tajuk instans borang | ✓ | ✓ |
| $!\{titleEn} | Tajuk instans borang dalam bahasa Inggeris | ✓ | ✓ |
| $!\{creator} | ID Pekerja pencipta | ✓ | ✓ |
| $!\{originator} | ID Pekerja pemohon | ✓ | ✓ |
| $!\{originatorName} | Nama pemohon | ✓ | ✓ |
| $!\{originatorNameEn} | Nama pemohon dalam bahasa Inggeris | ✓ | ✓ |
| $!\{serialNo} | Nombor siri | ✓ | ✓ |
| $!\{createTime} | Masa dicipta | ✓ | ✓ |
| $!\{modifiedTime} | Masa pengubahsuaian | ✓ | ✓ |
| $!\{processInstStatus} | Status instans aliran kerja | ✗ | ✓ |
| $!\{approvedResult} | Keputusan kelulusan | ✗ | ✓ |
| $!\{approvedResultCode} | Kod keputusan kelulusan | ✗ | ✓ |
