## 1. Pengenalan

### 1.1 Gambaran Keseluruhan Ciri

Matrix kebenaran menyediakan pengurusan tetapan kebenaran yang dipacu data, membolehkan operasi kelompok dan penggunaan semula untuk meningkatkan kecekapan. Ia memberikan organisasi platform yang lebih selamat, cekap, dan fleksibel untuk pengurusan data dan kawalan akses.

<Frame>
  ![](https://gw.alicdn.com/imgextra/i1/O1CN01LIZDtcT7WRJ4OujA_!!6000000002583-2-tps-2168-1112.png)
</Frame>

Sebagai contoh, sebuah syarikat internet besar mempunyai pusat kewangan korporat, dan beberapa kakitangan kewangan dalam pusat tersebut menyokong pelbagai lini perniagaan yang berbeza. Dalam kes ini, proses kelulusan kewangan perlu mengambil kira skop tanggungjawab dan hubungan pelaporan fungsian.

Sebelum ini, senario kompleks sebegini memerlukan penambahan cabang bersyarat pada aliran kerja.

<Frame>
  ![](https://gw.alicdn.com/imgextra/i3/O1CN01tEhjZq4woQD3rQdr_!!6000000000768-2-tps-1902-905.png)
</Frame>

Dengan matrix kebenaran, anda boleh menyelenggara peraturan sekali sahaja dan merujuknya berkali-kali di pelbagai tempat, tanpa perlu menambah cabang serupa pada aliran kerja. Satu nod sahaja ditambah dengan peraturan padanan akan memberikan hasil yang sama.

<Frame>
  ![](https://gw.alicdn.com/imgextra/i1/O1CN01Lf5lrDNs4RD2BZmp_!!6000000000976-2-tps-1077-770.png)

### 1.2 Kes Penggunaan

- Penetapan peranan yang fleksibel: Cipta peranan berdasarkan keperluan perniagaan tertentu dan tetapkan kebenaran yang berkaitan kepada setiap peranan. Ahli pasukan kemudiannya boleh bekerjasama dengan bebas dalam skop kebenaran mereka tanpa risiko kebocoran atau penyalahgunaan data.

### 1.3 Gambaran Keseluruhan Konsep

#### 1.3.1 Tentang Matrix Kebenaran

Matrix kebenaran terdiri daripada tiga bahagian: maklumat asas, pengepala matrix, dan butiran matrix.

#### 1.3.2 Maklumat Asas Matrix Kebenaran

Maklumat asas termasuk **nama matrix** dan **penerangan matrix**.

#### 1.3.3 Konsep Pengepala Matrix

<Frame>
  ![](https://gw.alicdn.com/imgextra/i1/O1CN01QAs1gy7j2dH2ARVH_!!6000000008134-2-tps-1068-611.png)

Pengepala matrix terdiri daripada lajur syarat dan lajur peranan:

- Lajur syarat: Tentukan syarat-syarat di mana matrix kebenaran berkuat kuasa (contohnya, projek x jabatan membentuk kombinasi syarat untuk penetapan peranan). Minimum 1, maksimum 10.
- Lajur peranan: Tentukan orang yang bertanggungjawab di bawah syarat yang diberikan. Anda boleh memilih pengguna daripada organisasi anda. Minimum 1, maksimum 50.

## 2. Langkah Operasi

Matrix kebenaran menyatukan penetapan peranan yang biasa digunakan di seluruh organisasi anda, supaya anda boleh merujuknya dengan satu klik dalam senario seperti aliran kerja dan kebenaran, sekali gus mengurangkan kos pengurusan dan konfigurasi. Bahagian ini menerangkan konsep asas dan penggunaan matrix kebenaran.

<Note>
Hanya admin platform yang boleh melakukan operasi ini.
</Note>

#### 2.4.3 Peraturan Import Kelompok

Fail Excel yang dimuat naik mestilah memenuhi keperluan berikut:

- Jika kaedah import ialah "Hanya tambah data baharu", templat import hanya mengandungi medan pengepala matrix, tanpa sebarang data matrix.
- Jika kaedah import ialah "Hanya kemas kini data", templat import mengandungi pengepala dan semua data matrix semasa, ditambah satu lajur ID Baris tambahan.

<Note>
**Nota: ID Baris** ialah kunci utama unik yang digunakan untuk mengemas kini data. Jangan ubah suai nilai ini. Sebarang perubahan akan menyebabkan kemas kini gagal.
</Note>

- Pastikan pengepala fail import sepadan dengan pengepala matrix semasa. Jika tidak, import akan gagal.
- Fail import tidak boleh melebihi 10 MB.
- Hanya fail \*.xls dan \*.xlsx disokong.
- Pastikan fail Excel anda memenuhi keperluan berikut:

- Hanya satu tugas import boleh dijalankan pada satu-satu masa untuk satu matrix.
- Jika data yang diimport mengandungi jabatan atau pengguna, input mestilah mengikut format di bawah, dan data tersebut mestilah sah.

Nota peraturan aplikasi matrix:

- Jika terdapat pelbagai peraturan aplikasi, pengguna akan dipadankan dalam matrix yang dipilih menggunakan logik DAN untuk menentukan operator bagi nod semasa.
- Jika beberapa pengguna sepadan dengan peraturan aplikasi matrix, semua pengguna yang sepadan akan menjadi operator bagi nod semasa, dan konfigurasi "mod berbilang penyokong" menentukan cara nod tersebut berkuat kuasa.
- Jika tiada pengguna sepadan dengan peraturan aplikasi matrix, nod semasa akan dikendalikan mengikut konfigurasi "penyokong adalah kosong" miliknya.

<Note>
- Jika sumber medan bagi syarat matrix ialah Jabatan, senarai lungsur medan borang hanya memaparkan komponen Jabatan daripada borang semasa.
- Anda boleh menambah sehingga 20 peraturan aplikasi matrix.
</Note>
