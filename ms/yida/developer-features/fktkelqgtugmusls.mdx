Panggil API ini menggunakan `this.utils.yida.<nama fungsi>`.

## API Operasi Borang

| **Nama Fungsi** | **Penerangan** | **Contoh Permintaan** |
|---|---|---|
| **saveFormData** | Cipta instans borang | `// Cipta instans borangthis.utils.yida.saveFormData({  formUuid: 'FORM-xxx',  appType: pageConfig.appType,  formDataJson: JSON.stringify({    textField_m1g4dcpy: 'Teks satu baris',    textareaField_m1g4dcpz: 'Teks pelbagai baris',  }),}).then((res) => {  console.log('Keputusan cipta', res);}).catch(({ message }) => {  this.utils.toast({    title: message,    type: 'error',  });});` |
| **updateFormData** | Kemas kini nilai komponen yang ditentukan dalam borang | `// Kemas kini nilai komponen yang ditentukan dalam borangthis.utils.yida.updateFormData({  formInstId: 'FINST-xxx',  updateFormDataJson: JSON.stringify({    textField_m1g4dcpy: 'Teks satu baris',    textareaField_m1g4dcpz: 'Teks pelbagai baris',  }),  useLatestVersion: 'y',}).then((res) => {  console.log('Kemas kini berjaya');}).catch(({ message }) => {  this.utils.toast({    title: message,    type: 'error',  });});` |
| **searchFormDataIds** | Cari ID instans borang mengikut kriteria | `// Cari ID instans borang mengikut kriteriathis.utils.yida.searchFormDataIds({  formUuid: 'FORM-xxx',  currentPage: 1,  pageSize: 10,  searchFieldJson: JSON.stringify({    textField_m1g4dcpy: 'Teks satu baris',    textareaField_m1g4dcpz: 'Teks pelbagai baris',  }),}).then((res) => {  console.log('Keputusan permintaan', res);}).catch(({ message }) => {  this.utils.toast({    title: message,    type: 'error',  });});` |
| **getFormComponentDefinationList** | Dapatkan definisi borang | `// Dapatkan definisi borangthis.utils.yida.getFormComponentDefinationList({  formUuid: 'FORM-xxx',  version: '',}).then((res) => {  console.log('Keputusan permintaan', res);}).catch(({ message }) => {  this.utils.toast({    title: message,    type: 'error',  });});` |
| **deleteFormData** | Padam instans borang | `// Padam instans borangthis.utils.yida.deleteFormData({  formUuid: 'FORM-xxx',}).then((res) => {  console.log('Keputusan permintaan', res);}).catch(({ message }) => {  this.utils.toast({    title: message,    type: 'error',  });});` |
| **getFormDataById** | Dapatkan butiran instans borang mengikut ID instans borang | `// Dapatkan butiran instans borang mengikut ID instans borangthis.utils.yida.getFormDataById({  formInstId: 'FINST-xxxx',}).then((res) => {  console.log('Keputusan permintaan', res);}).catch(({ message }) => {  this.utils.toast({    title: message,    type: 'error',  });});` |
| **searchFormDatas** | Cari butiran instans borang mengikut kriteria | `// Cari butiran instans borang mengikut kriteriathis.utils.yida.searchFormDatas({  formUuid: 'FORM-xxx',  searchFieldJson:'',// Cari mengikut nilai komponen borang  currentPage:'1',  pageSize:'10',  originatorId:'',// Cari mengikut ID Pekerja penghantar data  createFrom:'2024-01-01',  createTo:'2024-02-01',  modifiedFrom:'2024-01-01',  modifiedTo:'2024-02-01',  dynamicOrder:'',// Susun}).then((res) => {  console.log('Keputusan permintaan', res);}).catch(({ message }) => {  this.utils.toast({    title: message,    type: 'error',  });});` |

## API Operasi Aliran Kerja

| **startInstance** | Mulakan aliran kerja | `// Mulakan aliran kerjathis.utils.yida.startProcessInstance({  formUuid: 'FORM-xxx',  processCode:'TPROC--xxx',  deptId:'',  formDataJson: JSON.stringify({    textField_xxx: 'Teks satu baris',    textareaField_xxx: 'Teks pelbagai baris',  }),}).then((res) => {  console.log('Keputusan permintaan', res);}).catch(({ message }) => {  this.utils.toast({    title: message,    type: 'error',  });});` |
|---|---|---|
| **updateInstance** | Kemas kini instans aliran kerja | `// Kemas kini instans aliran kerjathis.utils.yida.updateProcessInstance({  processInstanceId: 'f30233fb-xxx-9ee530',  updateFormDataJson: JSON.stringify({    textField_xxx: 'Teks satu baris',    textareaField_xxx: 'Teks pelbagai baris',  }),}).then((res) => {  console.log('Keputusan permintaan', res);}).catch(({ message }) => {  this.utils.toast({    title: message,    type: 'error',  });});` |
| **deleteInstance** | Padam instans aliran kerja | `// Padam instans aliran kerjathis.utils.yida.deleteProcessInstance({  processInstanceId: 'f30233fb-xxx-9ee530',}).then((res) => {  console.log('Keputusan permintaan', res);}).catch(({ message }) => {  this.utils.toast({    title: message,    type: 'error',  });});` |
| **getInstances** | Dapatkan butiran instans aliran kerja mengikut kriteria carian | `// Dapatkan butiran instans aliran kerja mengikut kriteria carianthis.utils.yida.getProcessInstances({  formUuid:'FORM-xxx', // ID Borang  taskId:'2199132092', // ID Tugas  instanceStatus:'RUNNING', // Status instans  approvedResult:'agree', // Keputusan kelulusan  currentPage:'1',  pageSize:'10',  originatorId:'2134', // Cari mengikut ID Pekerja pemohon aliran kerja  createFrom:'2024-01-01',  createTo:'2024-02-01',  modifiedFrom:'2024-01-01',  modifiedTo:'2024-02-01',  searchFieldJson: JSON.stringify({    textField_xxx: 'Teks satu baris',    textareaField_xxx: 'Teks pelbagai baris',  }),}).then((res) => {  console.log('Keputusan permintaan', res);}).catch(({ message }) => {  this.utils.toast({    title: message,    type: 'error',  });});` |
| **getInstanceIds** | Cari ID instans aliran kerja mengikut kriteria | `// Cari ID instans aliran kerja mengikut kriteriathis.utils.yida.getProcessInstanceIds({  formUuid:'FORM-xxx', // ID Borang  taskId:'2199132092', // ID Tugas  instanceStatus:'RUNNING', // Status instans  approvedResult:'agree', // Keputusan kelulusan  currentPage:'1',  pageSize:'10',  originatorId:'2134', // Cari mengikut ID Pekerja pemohon aliran kerja  createFrom:'2024-01-01',  createTo:'2024-02-01',  modifiedFrom:'2024-01-01',  modifiedTo:'2024-02-01',  searchFieldJson:JSON.stringify({    textField_xxx: 'Teks satu baris',    textareaField_xxx: 'Teks pelbagai baris',  }),}).then((res) => {  console.log('Keputusan permintaan', res);}).catch(({ message }) => {  this.utils.toast({    title: message,    type: 'error',  });});` |
| **getInstanceById** | Dapatkan butiran instans aliran kerja mengikut ID instans | `// Dapatkan butiran instans aliran kerja mengikut ID instansthis.utils.yida.getProcessInstanceById({  processInstanceId:'f30233fb-xxx-530',}).then((res) => {  console.log('Keputusan permintaan', res);}).catch(({ message }) => {  this.utils.toast({    title: message,    type: 'error',  });});` |
