---
title: "Tentang didMount"
description: "Kaedah untuk memanggil Fungsi tertentu selepas Halaman selesai dimuatkan, termasuk kepentingan pengikatan manual pada Halaman Tersuai. Turut menerangkan cara menjalankan logik kod yang berbeza berdasarkan sama ada Borang semasa adalah Halaman penyerahan atau Halaman butiran."
polished: true
---

1. Selepas Halaman selesai dipaparkan, Fungsi berikut akan dipanggil dengan serta-merta. Fungsi ini diikat di bawah Halaman semasa > Tetapan > Kitaran Hayat > Peristiwa Halaman Dimuatkan.

**Nota: Halaman Tersuai perlu diikat secara manual sekali; jika tidak, Peristiwa tidak akan tercetus.**

  ![](https://gw.alicdn.com/imgextra/i2/O1CN01jwJhh3D1uoK3vD1o_!!6000000003908-2-tps-1932-1856.png)
</Frame>

2. Kod di dalam didMount akan dijalankan pada kedua-dua Halaman penyerahan Borang dan Halaman butiran. Dalam senario tertentu, anda perlu membezakan antara kedua-duanya seperti berikut:

```jsx
this.utils.isSubmissionPage() // Semak sama ada Borang adalah Halaman penyerahan
this.utils.isViewPage() // Semak sama ada Borang adalah Halaman butiran
```
