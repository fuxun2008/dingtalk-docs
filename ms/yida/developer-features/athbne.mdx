## 1. Latar Belakang

Bahagian ini menerangkan motivasi di sebalik lelaran ini, yang disasarkan kepada pembangun YiDA seperti penyedia perkhidmatan ISV atau pengguna YiDA yang perlu memanggil API secara langsung.

## 2. Senarai Kandungan Lelaran
