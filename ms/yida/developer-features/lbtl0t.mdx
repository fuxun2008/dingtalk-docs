<Warning>
Konfigurasi ciri berikut memerlukan kemahiran pengekodan. Jika anda tidak biasa dengan pengekodan, gunakan penyelesaian tanpa kod sebagai gantinya.
</Warning>

## Kes Penggunaan

- Ambil data mengikut jadual dan hantarkannya ke sistem anda sendiri untuk pemprosesan atau pengarkiban selanjutnya.
- Integrasikan entri penyerahan borang dan permulaan aliran kerja ke dalam platform sedia ada anda.
- Gunakan panel tindakan JS dalam YiDA untuk menulis kod JavaScript yang melaksanakan logik perniagaan tersuai atau pemeriksaan bersyarat.

**Disyorkan:** [**Pusat Pembangun**](/ms/open/yida/guide/about)

Kandungan bab ini:

1. Open API
2. Akses kod bahagian hadapan melalui panel tindakan JS
3. Memanggil API luaran daripada halaman tersuai
