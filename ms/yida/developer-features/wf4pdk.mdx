## 1. Latar Belakang

Sebelum anda mempelajari cara menyahpepijat Halaman YiDA, perhatikan perkara berikut:

1. YiDA pada masa ini dibina berdasarkan ekosistem JavaScript.
2. YiDA pada masa ini dibina berdasarkan ekosistem React.
3. Sistem Komponen YiDA pada masa ini berasaskan Fusion, sebuah pustaka Komponen sumber terbuka daripada Alibaba Group.

## 2. Nyahpepijat JavaScript

Chrome ialah pelayar yang disyorkan untuk menyahpepijat kod.

Untuk panduan langkah demi langkah, rujuk [artikel ini (Bahasa Inggeris)](https://developers.google.com/web/tools/chrome-devtools/javascript/?hl=zh-cn) atau [artikel ini (Bahasa Cina)](https://zh.javascript.info/debugging-chrome).

## 3. Nyahpepijat React

Nyahpepijat dengan [React Devtools](https://chrome.google.com/webstore/detail/react-developer-tools/fmkadmapgofadopljbjfkapdkoienihi).

Untuk arahan terperinci, lihat [artikel ini](https://reactjs.org/blog/2014/01/02/react-chrome-developer-tools.html).

## 4. Nyahpepijat Kod JS yang Ditulis dalam Panel Tindakan

(1) Buka konsol pembangun. Pada macOS, tekan Cmd + Option + I, atau klik kanan dan pilih "Inspect". Pada Windows, tekan F12, atau klik kanan dan pilih "Inspect".

<Frame>
  ![](https://gw.alicdn.com/imgextra/i1/O1CN01pwLtlPwnvpD259gi_!!6000000001241-2-tps-1026-530.png)
</Frame>

(2) Tambah kata kunci `debugger` dalam kod anda untuk menetapkan titik putus (breakpoint) bagi penyahpepijatan konsol.

<Frame>
  ![](https://gw.alicdn.com/imgextra/i1/O1CN01i1yWKyE4avF1pIJl_!!6000000003236-2-tps-900-581.png)
</Frame>

(3) Pada peranti mudah alih, gunakan `alert()` untuk memaparkan nilai bagi tujuan penyelesaian masalah.

(4) Jika Ralat muncul dalam konsol, klik `page.js` untuk terus masuk ke penyahpepijatan kod Sumber.

<Frame>
  ![](https://gw.alicdn.com/imgextra/i2/O1CN01SIVMDG5GJ5F1wTEM_!!6000000004348-2-tps-957-769.png)
</Frame>

(5) Dalam konsol, tekan Cmd/Ctrl + P dan Cari `page.js` untuk masuk ke penyahpepijatan kod Sumber.

<Frame>
  ![](https://gw.alicdn.com/imgextra/i1/O1CN01XSvNnEcUYnH1vSkz_!!6000000007013-2-tps-949-628.png)
</Frame>

(6) Untuk kaedah penyahpepijatan selanjutnya, lihat [https://developers.aliwork.com/docs/guide/concept/debug](/ms/open/yida/guide/concept/debug).
