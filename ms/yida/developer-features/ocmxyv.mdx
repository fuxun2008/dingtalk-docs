## 2. Input Kod dalam Panel Tindakan

Fungsi yang diisytiharkan dengan `export` dikenali oleh panel tindakan dan boleh dipilih serta dipanggil daripadanya.

Rujuk kod berikut:

```javascript
/**
 * Fungsi utiliti tersuai; tidak menggunakan konteks (this)
 */
function something() {
  alert('something')
}

/**
 * @title Tindakan tersuai A
 * Boleh menggunakan konteks (this)
 */
export function custom_action_a() {
  alert('custom action a')
}

/**
 * @title Tindakan tersuai B
 */
export function custom_action_b() {
  something(); // Panggil fungsi utiliti tersuai
  this.custom_action_a(); // Panggil fungsi tindakan tersuai
}
```

**Nota:**

<Warning>
Hanya pengisytiharan yang sepadan dengan `export function xxx() {}` dikenali dalam panel tindakan Komponen. Nama kaedah yang dieksport mestilah unik.
</Warning>

Untuk mendapatkan atau memanggil tindakan dalam panel secara manual, panggil terus `this.methodName();`.

### 2.1 Pengikatan Tindakan dalam Panel Tindakan

Kebanyakan Komponen dalam YiDA menyokong pengikatan tindakan.

Pengikatan tindakan menghubungkan Tindakan sesuatu Komponen dengan fungsi yang ditakrifkan dalam panel tindakan.

## 5. Penambahbaikan API Subborang

### 5.1 Dapatkan Data Subborang

```javascript
const subFormInst = this.$('subformUniqueId');
console.log(subFormInst.getValue()); // Dapatkan keseluruhan senarai data subborang
// Mula-mula, dapatkan pengecam baris
const items = subFormInst.getItems(); //  ["tfitem_1", "tfitem_2"]
items.forEach(item => {
  const rowData = subFormInst.getItemValue(item); // Dapatkan data baris
  console.log(rowData['subformInnerComponentUniqueId']); // Dapatkan data medan bagi baris yang ditentukan
});
```

### 5.2 Kesan Perubahan Subborang

Apabila data subborang berubah, selain daripada penyuntingan pada peringkat Sel, pengiraan Formula, keterkaitan data, dan penetapan nilai luaran juga akan mencetuskan Peristiwa onChange subborang. Untuk membantu anda mengenal pasti sumber perubahan tersebut, `changes.fieldId` menunjukkan Sel mana yang datanya berubah.

```javascript
// Peristiwa terikat subborang
export function onChange({value, extra}) {
  const { formGroupId, from, changes = {} } = extra || {};

  // Semak sama ada medan peranti berubah
 	if (changes.fieldId === 'subformDeviceFieldUniqueId') {
  // Tambah logik yang perlu dilaksanakan selepas perubahan subborang di sini
  };
}
```

### 5.3 Kemas Kini Data Baris Berkaitan Apabila Data dalam Jadual Berubah

Gunakan API `updateItemValue` untuk menetapkan nilai ke Sel.

Sebagai contoh, apabila peranti berubah, gunakan API ini untuk mengisi maklumat lain dalam subborang semasa.

```javascript
// Peristiwa terikat subborang
export function onChange({value, extra}) {
  const { formGroupId, from, changes } = extra || {};
  if (from === 'setItemValue') return; // Elakkan gelung tak terhingga apabila updateItemValue mencetuskan onChange semula

  // Kendalikan perubahan data satu baris
  const tableField = this.$('subformUniqueId');

  // Semak sama ada medan peranti berubah
 	if (changes.fieldId === 'subformDeviceFieldUniqueId') {
  		getDeviceInfo() // API tersuai untuk mendapatkan maklumat peranti
    			.then((data) => {
      				tableField.updateItemValue(formGroupId, {
                'numberField_l00o018a': data.price, // Kemas kini harga peranti
                'textareaField_kysd3grq': data.description, // Kemas kini keterangan peranti
              });
      		})
  };
}
```

Anda tidak perlu lagi menetapkan nilai satu demi satu melalui `getComponent().setValue` seperti sebelum ini. Pendekatan tersebut tidak dapat menjamin kemas kini Borang yang lengkap dalam senario tak segerak.

## 6. Ralat Biasa

### 6.1 Tidak Dapat Membaca Sifat '$' bagi Undefined.

  ![](https://gw.alicdn.com/imgextra/i1/O1CN017GTI2DcKaDF2hvV1_!!6000000006912-2-tps-1334-473.png)

```diff
export function didMount(){
	console.log('Memasuki kaedah ujian');
-  test1()  // Memanggil dengan cara ini akan menyebabkan ralat seperti di atas.
+  this.test1() // Panggilan yang betul. Prinsipnya mudah: konteks mesti disalurkan melalui this.
}

export function test1(){
	console.log(this.$('abc').getValue());
}
```

### 6.2 Permintaan Ini Telah Disekat; Kandungan Mesti Dihantar Melalui HTTPS

Domain YiDA ialah https://www.yidaapps.com. Disebabkan sekatan keselamatan pelayar, hanya titik akhir HTTPS boleh diminta; titik akhir HTTP tidak dibenarkan. Titik akhir setempat seperti http://192.168.xxx juga disekat.

**Penting:**

Untuk menyediakan perkhidmatan API, titik akhir anda mesti memenuhi keperluan berikut:

1. Gunakan protokol HTTPS dengan sijil yang sah.

2. Benarkan [**akses silang-domain**](http://www.ruanyifeng.com/blog/2016/04/cors.html) daripada www.yidaapps.com. Jika tidak, ralat dasar silang-tapak akan berlaku.
