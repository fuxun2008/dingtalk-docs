## 1. Pengenalan

Open API terutamanya digunakan dalam senario berikut:

1. Menarik data secara berkala ke dalam sistem dalaman untuk penambahbaikan atau pengarkiban.
2. Mengintegrasikan titik masuk penyerahan borang dan permulaan aliran kerja ke dalam platform sedia ada.

Jika kes penggunaan anda sepadan dengan mana-mana senario di atas, pertimbangkan untuk menggunakan keupayaan Open API YiDA.

Pada masa ini, YiDA telah menerbitkan semua Open API di DingTalk Open Platform, sambil masih mengekalkan YiDA Open API (versi lama). Memanggil YiDA Open API melalui DingTalk Open Platform adalah kaedah yang disyorkan.
