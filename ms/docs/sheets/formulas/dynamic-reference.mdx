## Fungsi INDIRECT

Fungsi INDIRECT menghurai teks kepada rujukan julat. Dalam kebanyakan formula, rujukan biasanya dimasukkan secara terus, seperti SUM(A1:A5), dengan A1:A5 tidak dibungkus dalam tanda petik dan secara langsung mewakili julat A1:A5.

INDIRECT biasanya digunakan bersama-sama dengan operator penggabungan "&" atau fungsi teks.

**Contoh:** Dalam Sel C1 helaian "Ringkasan", parameter INDIRECT digabungkan menjadi teks "Epal!B:B". Selepas dihurai oleh fungsi INDIRECT, ia merujuk kepada Lajur B helaian "Epal", dan fungsi SUM kemudian mengira "Jumlah jualan".
