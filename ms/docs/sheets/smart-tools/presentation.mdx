Semasa membentangkan laporan data, Spreadsheet menyokong Mod Persembahan, yang menukar Spreadsheet kepada PPT dengan satu klik. Ini menjadikan laporan data lebih lancar dan menjimatkan masa anda daripada perlu mencipta slaid.

## Arahan

### Cara Memasuki Mod Persembahan

Klik **Mod persembahan** di penjuru kanan atas untuk menukar Helaian Kerja anda kepada PPT secara serta-merta.

### Pelarasan dalam Mod Persembahan

Dalam antara muka Mod Persembahan, anda boleh membuat pelarasan berikut:

1.  **Saiz Fon**: Klik ikon zum A di penjuru kanan atas untuk melaraskan Fon.

2.  **Skala antara muka**: Guna kotak skala di penjuru kanan bawah untuk mengubah saiz antara muka paparan.

3.  **Cipta Paparan Penapis sementara**: Pilih area sasaran, kemudian klik ikon Penapis di penjuru kiri atas untuk mencipta Paparan Penapis sementara. Ini membolehkan anda membandingkan Data secara mendatar dan menegak, membantu audiens memahami Data dengan lebih baik.

4.  **Susun**: Pilih area sasaran dan klik Susun di penjuru kiri atas untuk menyusun pilihan mengikut tertib menaik atau menurun. Sebagai alternatif, tanpa memilih sebarang area, klik Susun di penjuru kiri atas untuk menggunakan tertib menaik atau menurun kepada keseluruhan Spreadsheet.

    (Nota: Anda tidak boleh Susun julat yang mengandungi sel bercantum secara menegak.)

### Keluar daripada Mod Persembahan

*   Klik butang **"Keluar daripada Mod persembahan"** di penjuru kiri atas untuk keluar dengan segera.

*   Tekan F11 untuk keluar daripada Mod Persembahan skrin penuh.
