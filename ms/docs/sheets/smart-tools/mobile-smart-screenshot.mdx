## Value

Tangkap skrin pintar pada mudah alih untuk mengatasi had skrin dan melihat semua data dengan jelas.

## Use Cases

Apabila berkongsi tangkapan skrin pada mudah alih, Spreadsheet mungkin terlalu panjang untuk ditangkap sepenuhnya, menyebabkan anda terhad oleh saiz skrin. Aplikasi mudah alih DingTalk Spreadsheet menyokong tangkap skrin pintar: **cetuskan gerak isyarat tangkap skrin untuk menjana imej data dengan sekali ketik** bagi memudahkan perkongsian.

## Instructions

1. Pada telefon bimbit atau iPad, cetuskan gerak isyarat tangkap skrin untuk mengesan kawasan data dalam Helaian Kerja semasa secara automatik dan menjana imej data.

2. Hantar semula dan Kongsi terus, atau simpan Gambar yang dijana ke Album telefon anda.
