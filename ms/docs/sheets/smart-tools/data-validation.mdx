## Nilai

Tetapkan peraturan untuk kemasukan data bagi mengelakkan ralat input, menyeragamkan format, dan meningkatkan ketepatan serta kecekapan pengumpulan Data.

## Kes Penggunaan

Apabila Pengguna Pasukan bekerjasama mengisi Spreadsheet, tidak semua orang biasa dengan keperluan kemasukan data, yang sering menyebabkan ralat input. Semakan manual pula memakan masa dan tenaga. Dengan ciri Pengesahan Data, anda boleh menetapkan peraturan kemasukan terlebih dahulu untuk menyeragamkan format, mengelakkan ralat, serta meningkatkan ketepatan dan kecekapan pengumpulan Data.

## Arahan

Titik akses:

1. Menu atas — Data — Pengesahan Data.

2. Bar alat — Pengesahan Data.

3. Menu klik kanan — Tetapkan Pengesahan Data.

Tetapan:

1. Buka salah satu titik akses dan klik Cipta peraturan.

2. Konfigurasikan peraturan: pilih Jenis data yang dikehendaki dan peraturan pengesahan (Petua input dan Amaran Ralat).

(Pengesahan Data ialah ciri keserasian. Peraturan adalah selaras dengan Tindakan tempatan, tetapi sesetengah interaksi UI mungkin berbeza.)

3. Klik Sahkan untuk Simpan.

Pengesahan:

1. Berdasarkan peraturan yang telah ditetapkan, Pengguna lain akan melihat Petua input apabila mereka mengklik Sel.

2. Jika Data yang dimasukkan tidak sepadan dengan peraturan yang ditetapkan, mesej Data tidak sah akan dipaparkan.
