Dalam DingTalk Spreadsheet, anda boleh mencipta senarai tugasan menggunakan **Sisip Kotak Semak**.

## Arahan

1.  Reka bentuk senarai tugasan dengan nama tugasan dan penerima tugasan, kemudian sisipkan Lajur untuk menunjukkan status penyiapan tugasan.

2.  Pilih Sel kosong dan klik **Kotak Semak** pada bar alat untuk menyisipkan Kotak Semak.

3.  Klik Kotak Semak untuk menogolnya mengikut status penyiapan tugasan.

Selepas mengeksport Spreadsheet yang mengandungi kotak semak, kotak semak tersebut akan dipaparkan secara tempatan sebagai nilai TRUE dan FALSE.
