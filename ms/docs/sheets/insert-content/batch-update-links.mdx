## Nilai

Sisip atau padam pautan web secara pukal dengan klik kanan untuk edit pautan yang lebih mudah.

## Kes Penggunaan

Semasa mengedit Spreadsheet, klik kanan untuk menyisip atau memadam pautan dengan mudah, menjadikan edit kandungan lebih cekap.

## Arahan

1.  Pilih satu Sel, kemudian klik kanan untuk mengakses pintasan baharu "Sisipkan Pautan".

2.  Apabila pilihan mengandungi pautan, klik kanan dan pilih "Buang Pautan" untuk memadam pautan secara pukal dengan pantas.
