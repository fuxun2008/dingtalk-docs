Spreadsheet di desktop membolehkan anda mengekalkan rekod tertentu tetap di atas semasa menatal, memudahkan anda menyematkan semua pengepala anda di tempatnya.

## Arahan

*   Sematkan rekod ke atas: Pada desktop, pilih satu rekod >> klik bar alat >> Bekukan >> Sematkan rekod dipilih ke atas.

*   Nyahsemat rekod: Pada desktop, pilih rekod yang disematkan >> klik bar alat >> Bekukan >> Nyahsemat.
