## Value

Lihat carta pada peranti mudah alih menggunakan Paparan Carta. Melayari helaian kerja terasa seperti membelek album, memberikan pengalaman yang mengasyikkan dan lancar.

## Use Cases

Pengalaman Kanban pada peranti mudah alih kini telah dipertingkatkan sepenuhnya. Bebaskan diri daripada batasan skrin mudah alih, tukar mod Paparan Carta dengan bebas, dan ketik untuk melihat carta bersaiz penuh supaya anda tidak terlepas sebarang data.

## Instructions

1. Pilih carta. Petua menu akan menunjukkan bahawa anda boleh melihat carta bersaiz penuh. Ketik untuk melihatnya terus.

2. Ketik bar bawah — Paparan — Paparan Carta untuk membuka senarai carta, yang memaparkan semua carta dalam Helaian Kerja semasa. Pilih mana-mana carta untuk melihatnya, dan leret untuk bertukar antara carta.
