Dalam Spreadsheet, gunakan **Filter** untuk memilih sebahagian data daripada Jadual mengikut syarat tertentu bagi tujuan analisis dan pemprosesan lanjut, sambil menyembunyikan data yang tidak diperlukan buat masa ini.

## Filter Asas: Hidupkan dan matikan Filter

1.  Pilih julat Sel yang ingin ditapis, kemudian klik **Filter** pada bar alat untuk menghidupkan Filter.

2.  Satu **butang Filter** akan muncul di penjuru kanan atas setiap Sel pada baris pertama julat yang dipilih. Klik butang Filter untuk mula menapis. Jika anda mengklik Filter tanpa memilih julat pada langkah sebelumnya, keseluruhan Helaian Kerja akan ditapis secara lalai, dan butang Filter akan muncul pada setiap Sel di baris pertama Helaian Kerja.

3.  Klik Filter pada bar alat sekali lagi untuk mematikan Filter.

4.  Anda hanya boleh menghidupkan Filter untuk satu julat Sel dalam satu Helaian Kerja pada satu-satu masa.

## Filter Asas: Jenis Filter

1.  **Filter mengikut nilai**: Untuk menapis satu kategori data dengan pantas, masukkan kata kunci dalam kotak Cari. Keputusan filter akan memaparkan semua item yang mengandungi kata kunci tersebut. Anda juga boleh menapis dengan memilih nilai unik dalam panel.

2.  **Filter mengikut syarat**: Untuk menapis data yang memenuhi kriteria tertentu, tetapkan Syarat filter yang berkaitan.

3.  **Filter mengikut warna**: Untuk menapis Sel mengikut warna latar belakang atau warna Fon, pilih Filter mengikut warna.

4.  **Filter hanya kelihatan kepada saya**: Untuk menentukan sama ada keputusan filter diselaraskan atau tidak diselaraskan, pilih "Filter hanya kelihatan kepada saya" dalam panel filter mengikut keperluan.

## Filter Lanjutan: Paparan Filter Tanpa Gangguan

Jika anda perlu menapis secara berasingan tanpa menjejaskan paparan data pengguna lain, atau jika anda hanya mempunyai Kebenaran lihat sahaja pada Spreadsheet tetapi masih mahu menapis data, gunakan Paparan filter untuk menapis data.

1.  Pilih julat Sel yang ingin ditapis, kemudian klik anak panah dropdown di sebelah **Filter** pada bar alat, dan pilih **Cipta paparan filter**.

    (Pada Mac: klik **Filter > Lain-lain**, kemudian klik **Cipta paparan filter** untuk masuk ke antara muka paparan filter.)

2.  Dalam antara muka paparan filter, keputusan filter tidak akan diselaraskan ke Jadual asal. Anda juga boleh melakukan tindakan berikut:

    1.  Namakan semula paparan filter untuk memudahkan pengenalpastian.

    2.  Pilih semula atau tukar julat filter.

3.  Fungsi filter dalam paparan filter berfungsi sama seperti Filter Asas, tetapi Susun masih belum disokong.
