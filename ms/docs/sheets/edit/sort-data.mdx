Dalam DingTalk Spreadsheet, gunakan Susun untuk menyusun semula data mengikut susunan yang ditetapkan. Ini merupakan cara penting untuk mengatur data anda.

## Arahan

Pilih julat sasaran dan klik **Susun** pada bar alat. Daripada menu lungsur, pilih kaedah susunan. Susunan tersuai turut disokong, membolehkan anda menyesuaikan susunan hamparan mengikut keperluan anda.

*   Data jenis Nombor secara umumnya disusun mengikut nilai numerik keseluruhan.

*   Data jenis Teks secara umumnya disusun mengikut abjad Inggeris atau susunan abjad pinyin bagi bahasa Cina.

*   Petua: Untuk mendapatkan hasil susunan yang tepat, seragamkan format data sebelum menyusun.
