Gunakan Isi Auto dalam DingTalk Spreadsheet untuk salin dan isi sel dengan pantas berdasarkan corak input data sedia ada. Ciri ini membantu anda melengkapkan kemasukan data sel berdasarkan corak, sesuai untuk senario seperti penyalinan kandungan dan penomboran bersiri.

## Cara Menggunakan

1.  Pilih julat sel yang sudah mengandungi sebahagian data. Ini menjadi asas data untuk isi auto.

2.  Halakan tetikus anda ke sudut kanan bawah julat yang dipilih. Cursor bertukar menjadi bentuk **"+"**, dikenali sebagai **pemegang isi**.

3.  Tahan pemegang isi dan seret secara menegak atau mendatar untuk mengisi data ke sel kosong pada arah tersebut.

4.  Selepas melepaskan pemegang isi, ikon pilihan isi akan muncul di sudut kanan bawah kawasan yang diisi. Klik ikon tersebut untuk memilih: **Salin sel, Isi siri, Isi format sahaja, atau Isi tanpa format.**
