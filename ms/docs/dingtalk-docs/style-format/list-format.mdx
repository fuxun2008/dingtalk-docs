Semasa mengedit dokumen, jika satu subjek mengandungi pelbagai item, tambah Senarai Berbucu atau Senarai Bernombor untuk menyusun kandungan mengikut urutan dan menjadikan hierarki lebih jelas.

## Arahan

### Menambah Senarai

Pada bar alat, klik ikon berkenaan untuk menambah Senarai Berbucu, Senarai Bernombor, atau Senarai tugasan.

### Mengedit Senarai

DingTalk Docs menyokong penukaran gaya bucu dan Jenis penomboran. Klik anak panah lungsur di sebelah tindakan berkenaan pada bar alat, atau klik ikon tindakan, untuk mengonfigurasikan tetapan.
