DingTalk Docs menyokong pembenaman audio dan video daripada pelbagai platform pihak ketiga, termasuk **Youku**, **Xigua Video**, **Tencent Video**, **Sohu Video**, **Bilibili**, dan **NetEase Cloud Music**. Artikel ini menerangkan cara mendapatkan pautan boleh benam daripada setiap platform.

> Nota: Kandungan yang dibenamkan disediakan oleh pihak ketiga. DingTalk Docs tidak dapat menjamin ketersediaannya dalam jangka panjang. Patuhi terma penggunaan pihak ketiga tersebut serta undang-undang dan peraturan tempatan yang berkenaan.

## Youku

Pada halaman main balik, klik **Kongsi**, kemudian salin **URL halaman** atau **kod sejagat**:

Format pautan boleh benam adalah seperti berikut:

```application/xml
https://v.youku.com/v_show/id_xxx==.html?xxx
or
<iframe src='https://player.youku.com/embed/xxx'></iframe>
```

## Xigua Video

Pada halaman main balik, klik **Kongsi**, kemudian salin **URL video** (anda juga boleh menyalin URL terus daripada bar alamat pelayar):

Format pautan boleh benam adalah seperti berikut:

```application/xml
https://www.ixigua.com/xxx
```

## Tencent Video

Pada halaman main balik, klik **Kongsi**, kemudian salin **kod benam** (disyorkan) atau **pautan**:

Format pautan boleh benam adalah seperti berikut:

```application/xml
https://v.qq.com/x/cover/xxx/xxx.html
or
<iframe src="https://v.qq.com/txp/iframe/player.html?vid=xxx"></iframe>
```

## Sohu Video

Pada halaman main balik, klik **Kongsi**, kemudian salin **kod sejagat** (penghuraian URL halaman tidak disokong):

Format pautan boleh benam adalah seperti berikut:

```application/xml
https://v.qq.com/x/cover/xxx/xxx.html
or
<iframe src="https://tv.sohu.com/s/sohuplayer/iplay.html?vid=xxx"></iframe>
```

## Bilibili

Pada halaman main balik, klik **Kongsi**, kemudian salin **URL video** atau **kod benam** (anda juga boleh menyalin URL terus daripada bar alamat pelayar):

Format pautan boleh benam adalah seperti berikut:

```application/xml
https://www.bilibili.com/video/xxx
or
<iframe src="//player.bilibili.com/player.html?aid=xxx&bvid=xxx"> </iframe>
```

## NetEase Cloud Music

Salin **URL halaman trek tunggal** (disyorkan), atau klik **Jana pemain luaran** kemudian **Salin kod**:

Format pautan boleh benam adalah seperti berikut:

```application/xml
https://music.163.com/#/song?id=xxx
or
<iframe src="//music.163.com/outchain/player?type=2&id=xxx"></iframe>
```

## Tukar Pautan yang Ditampal kepada Kad Audio atau Video

Apabila anda menampal pautan yang disokong daripada **Xigua**, **Bilibili**, **YouTube**, atau **NetEase Cloud Music**, pilih **Kad pratonton** dalam menu tampal untuk menukar pautan tersebut terus kepada kad audio atau video yang dibenamkan.

## Soalan Lazim

1.  **Adakah pautan pendek disokong?**

    DingTalk Docs tidak menghuraikan pautan pendek pihak ketiga. Dapatkan pautan boleh benam seperti yang diterangkan di atas.

2.  **Mengapa video yang dibenamkan tidak dapat dimainkan?**

Sesetengah platform mengehadkan main balik kandungan yang dibenamkan. Ini mungkin bergantung pada jenis sumber (contohnya, sesetengah filem tidak boleh dimainkan oleh pembenam), atau status akaun anda (contohnya, sama ada anda telah log masuk atau memiliki keahlian). Hubungi khidmat pelanggan platform berkenaan untuk maklumat lanjut. Selain itu, pastikan rangkaian anda boleh mencapai YouTube apabila membenamkan video YouTube.
