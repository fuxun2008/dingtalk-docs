Untuk menjadikan hamparan dalam dokumen lebih intuitif, anda boleh menggunakan ciri Sisipkan Gambar. Menambah gambar juga dapat meningkatkan daya tarikan visual dokumen.

## Tambah Gambar

Pada bar navigasi atas, klik **Sisip > Gambar**, atau klik **Gambar** pada bar alat untuk memuat naik gambar tempatan ke dalam dokumen.

## Edit Gambar

Klik satu gambar untuk membuka bar alat gambar dan konfigurasikan tetapan berkaitan. Tindakan berikut kini disokong:

*   Ekstrak teks daripada gambar

*   Muat turun gambar

*   Tetapkan gaya gambar

*   Tetapkan saiz gambar

*   Potong gambar

*   Penerangan gambar

*   Tambah pautan

*   Putar gambar

*   Jajaran mendatar

*   Ganti gambar
