title: "Sisip Kod"
description: "DingTalk Docs: sisip kod dengan penyorotan sintaks melalui Sisip > Sekat kod pada bar alat. Menyokong 50 bahasa pengaturcaraan dengan tema Terang dan Gelap yang boleh ditukar, sesuai untuk dokumentasi teknikal dan panduan pembangun."
---

DingTalk Docs menyokong penyisipan sekat kod ke dalam dokumen. Klik **Sisip > Sekat kod** pada bar alat untuk menyisipkan sekat kod. 50 bahasa pengaturcaraan disokong, dan sekat kod boleh digayakan dengan tema Terang atau Gelap.
