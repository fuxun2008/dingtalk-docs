## 1. Tentang DingTalk Docs Flash

Terjumpa kandungan menarik semasa melayari web dan ingin menyimpannya? DingTalk Docs Flash membolehkan anda menyimpan teks kandungan halaman semasa ke DingTalk Docs dengan satu klik, supaya anda boleh membacanya bila-bila masa, di mana-mana sahaja. Ia juga menyingkirkan iklan terapung dan pautan tidak relevan secara automatik, membebaskan anda daripada kekusutan dan meningkatkan pengalaman membaca.

## 2. Cara Menggunakannya

DingTalk Docs Flash kini menyokong pelayar-pelayar berikut. Pasang pakej plugin, kemudian buka pelayar untuk mula menggunakannya:

360 Speed Browser, 360 Secure Browser, Chrome, dan Edge.

## 3. Panduan Pemasangan Plugin

## 3.1 Pasang pada Chrome

### Kaedah 1 (Disyorkan):

Pasang daripada kedai plugin. [Klik di sini untuk melawat Chrome Web Store](https://chrome.google.com/webstore/detail/%E9%92%89%E9%92%89%E6%96%87%E6%A1%A3%E9%97%AA%E5%AD%98/dfaldmjkfklnkenddjpikfkdnkinheke).

### Kaedah 2:

Langkah 1: Klik untuk memuat turun pakej plugin, kemudian nyahzip untuk mendapatkan fail DingTalk Docs Plugin.crx.

Langkah 2: Buka Chrome dan pergi ke **ikon ⋮** di penjuru kanan atas > **Extensions** > **Manage Extensions** untuk mengakses halaman pengurusan sambungan.

Langkah 3: Seret fail DingTalk Docs Plugin.crx daripada Langkah 1 ke halaman pengurusan sambungan.

Nota: Selepas pemasangan, ikon DingTalk Docs Flash akan muncul pada halaman pengurusan sambungan. Klik ikon **Extensions** pada bar alat, kemudian klik ikon **Pin** di sebelah DingTalk Docs Flash dalam senarai sambungan untuk menyematkan plugin pada bar alat.

## 4. Cara Menggunakan DingTalk Docs Flash

## 4.1 Log Masuk

Pada mana-mana laman web yang kandungannya ingin anda simpan secara pantas, klik ikon plugin DingTalk Docs Flash. Jika anda belum log masuk, plugin akan meminta anda log masuk dan membuka tab baharu. Log masuk ke DingTalk Docs dalam tab baharu tersebut, kemudian teruskan menggunakan plugin.

## 4.2 Simpan Pantas

Selepas log masuk, klik ikon plugin DingTalk Docs Flash dan plugin akan mula menyimpan halaman semasa. Dokumen yang disimpan disimpan di bawah folder **Dokumen Saya / Simpanan Pantas** akaun yang log masuk.

Selepas simpanan pantas selesai, tetingkap timbul keputusan akan muncul pada halaman menunjukkan ringkasan artikel dan lokasi simpanan. Klik **Edit** di sebelah kanan lokasi simpanan untuk membuka pusat peribadi DingTalk Docs dan menukar lokasi simpanan.

## 4.3 Pilih Lokasi Simpanan

Jika akaun yang log masuk milik beberapa organisasi, klik kanan menu plugin dan klik **Set Flash Save Location** untuk membuka pusat peribadi DingTalk Docs dan mengonfigurasikan tetapan tersebut.

## 4.4 Maklum Balas Isu dan Cadangan

Jika anda menghadapi sebarang isu, tinggalkan ulasan pada [Chrome Web Store](https://chrome.google.com/webstore/detail/%E9%92%89%E9%92%89%E6%96%87%E6%A1%A3%E9%97%AA%E5%AD%98/dfaldmjkfklnkenddjpikfkdnkinheke), atau klik kanan DingTalk Docs Flash dan pilih **Report an Issue/Suggestion**.
