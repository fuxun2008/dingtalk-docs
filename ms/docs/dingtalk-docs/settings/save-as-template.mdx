Dalam kerja seharian, anda sering perlu mengedit dokumen jenis yang sama, seperti menulis pelan kerja tahunan atau bulanan, ringkasan, atau laporan mingguan. Dalam situasi sedemikian, simpan dokumen anda sebagai templat berdasarkan tabiat penulisan anda sendiri untuk mengelakkan penyuntingan berulang dan meningkatkan kecekapan. Selain itu, DingTalk Docs menyediakan pelbagai templat umum untuk menyokong kerja harian anda.

## Arahan

Pada bar navigasi di bahagian kanan atas dokumen, klik ┇ **> Simpan sebagai templat > Simpan sebagai templat saya** untuk menyimpan dokumen berkenaan sebagai templat. Dalam panel yang dipaparkan, anda boleh mengedit tajuk dokumen tanpa menjejaskan dokumen asal.

Apabila mencipta dokumen baharu, pilih **Templat saya** untuk menggunakan templat yang telah anda cipta.
