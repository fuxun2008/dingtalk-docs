**Gambaran Keseluruhan**

Untuk pengalaman web DingTalk Docs yang lebih baik, tetapkan pelayar yang disokong DingTalk Docs sebagai pelayar lalai pada sistem anda. Arahan di bawah adalah untuk rujukan sahaja. Rujuk antara muka sebenar untuk langkah yang tepat.

## 1. Windows

1.  Klik butang **Start**, kemudian klik **Settings**.

2.  Pilih **Apps**.

3.  Pergi ke **Apps** **\>** **Default apps** **\>** **Web browser**, pilih pelayar yang anda ingin tetapkan sebagai lalai, klik **Set this program as default**, dan klik **Switch anyway** apabila diminta untuk melengkapkan persediaan.

## 2. macOS

*   Langkah 1: Buka **System Settings** dan pergi ke **Desktop & Dock**.

*   Langkah 2: Cari **Default web browser** dan pilih pelayar yang anda ingin gunakan secara lalai.

## 3. Cara Menetapkan Pelayar Lalai untuk Membuka DingTalk Docs

Semasa menggunakan DingTalk, anda boleh memilih untuk membuka, melihat, dan mengedit dokumen dalam pelayar web mengikut keutamaan anda.

*   **Windows:** Buka **DingTalk** **\>** klik **Gambar Profil** di sudut kiri atas **> Settings & Privacy > General > DingTalk Docs**, kemudian hidupkan **Always open documents in browser** untuk melengkapkan persediaan.

*   **macOS:** Buka **DingTalk** **\>** klik **Gambar Profil** di sudut kiri atas **> Settings & Privacy > General > DingTalk Docs**, kemudian pilih **Always open documents in browser** untuk melengkapkan persediaan.
