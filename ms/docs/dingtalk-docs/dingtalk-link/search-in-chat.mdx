Cari DingTalk Docs terus di bawah tab **Fail** dan **Dokumen** dalam Sejarah Sembang untuk carian yang lebih pantas.

## Arahan

Dalam Sembang Kumpulan di desktop, klik **Sejarah Sembang** di penjuru kanan atas, kemudian cari kata kunci dokumen yang disasarkan. Dokumen tersebut akan dipaparkan terus di bawah tab **Fail**.
