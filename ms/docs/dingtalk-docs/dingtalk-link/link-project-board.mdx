Kaitkan DingTalk Project dengan dokumen DingTalk Docs untuk menyokong semakan dan penjejakan projek.

## Arahan

Dalam dokumen, pilih lokasi tempat anda ingin menambah Kanban projek. Klik **Sisip -> Project Kanban** pada bar navigasi atas, kemudian pilih projek yang ingin anda sisipkan dalam pemilih Project Kanban. Butiran projek, seperti **tugasan, status, dan pemegang tugas**, dipaparkan terus dalam dokumen. Anda juga boleh konfigurasikan tetapan Susun dan Tapis pada Kanban projek.
