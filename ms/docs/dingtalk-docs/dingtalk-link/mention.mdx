**DingTalk Docs** disepadukan secara mendalam dengan DingTalk untuk menjadikan kerjasama lebih cekap. DingTalk Docs membolehkan anda menyebut orang lain dengan @ di dalam dokumen. **Taip @ + nama pengguna terus** dalam Teks Kandungan atau Komen untuk menghantar notifikasi chat DingTalk, mengingatkan penerima untuk menyemak dokumen atau komen tersebut. Penerima boleh klik notifikasi chat untuk terus melompat ke area sasaran dalam dokumen. Rancangan Aktiviti atau dokumen Penting yang sebelum ini memerlukan Mesyuarat khas kini boleh dibincang dan disunting oleh ramai orang pada bila-bila masa, di mana-mana sahaja dalam DingTalk Docs—meningkatkan produktiviti harian secara ketara.

## Arahan

1.  Letakkan cursor pada lokasi yang anda ingin sebut seseorang dalam dokumen dan **taip "@"**. Panel Kenalan akan terbuka secara automatik. Pilih Pengguna yang anda ingin sebut, kemudian pilih penerima untuk dinotifikasikan.

2.  Klik **Hantar** dalam dialog untuk memberitahu penerima melalui chat DingTalk supaya menyemak atau memberi komen. Penerima boleh klik notifikasi chat DingTalk untuk terus melompat ke lokasi yang ditentukan dalam dokumen.
