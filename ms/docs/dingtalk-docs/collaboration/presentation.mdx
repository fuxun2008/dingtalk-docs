Dokumen sering digunakan dalam mesyuarat harian. Menukar dokumen kepada Mod persembahan memberikan pengalaman persembahan yang terbaik.

## Mulakan persembahan

Klik **ikon persembahan** di penjuru kanan atas dokumen, atau gunakan **pintasan Ctrl + Shift + P (Mac: Cmd + Shift + P)** untuk memasuki Mod persembahan.

## Tukar gaya persembahan

Mod persembahan menawarkan dua gaya paparan: main gulung dan mod muka surat Slaid.

Main gulung mempersembahkan dokumen sebagai aliran skrol berterusan. Dalam mod muka surat Slaid pula, dokumen dipaparkan mengikut muka surat berdasarkan nod dokumen.

**Dalam Mod persembahan, tuding ke mana-mana bahagian di bahagian bawah skrin dan klik sekali untuk memaparkan panel Tetapan persembahan, kemudian buat pilihan anda.**

## Tetapan gaya persembahan

### Mod siang/malam

Mod persembahan menyokong kedua-dua paparan mod siang dan malam.

**Dalam Mod persembahan, tuding ke mana-mana bahagian di bahagian bawah skrin dan klik sekali untuk memaparkan panel Tetapan persembahan, kemudian tukar mod tersebut.**

### Nisbah Zum paparan

Mod persembahan menyokong tiga saiz Paparan: besar, sederhana, dan kecil.
**Di bahagian bawah Mod persembahan, klik ikon untuk menukar antara nisbah Paparan.**

## Keluar daripada persembahan

Dalam tetapan Mod persembahan, klik **Keluar daripada persembahan**, atau tekan **Esc** untuk keluar daripada persembahan.
