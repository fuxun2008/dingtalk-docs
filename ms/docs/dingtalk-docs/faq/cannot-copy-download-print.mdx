## Punca

Secara lalai, Kolaborator dengan kebenaran Paparan/Muat turun atau lebih tinggi boleh menyalin Teks Kandungan, memuat turun, mencetak, dan mencipta salinan dokumen. Jika anda mempunyai kebenaran tersebut tetapi masih tidak dapat menyalin, memuat turun, atau mencetak dokumen, **sebab utamanya ialah:**

Admin dokumen atau Knowledge Base telah menetapkan **"Hanya pengguna dengan kebenaran Urus boleh muat turun, cipta salinan, dan cetak / Tiada sesiapa boleh muat turun, cipta salinan, atau cetak"** dalam konfigurasi Kebenaran, yang mengatasi peraturan lalai.

Dalam kes ini, walaupun Pengguna mempunyai kebenaran Paparan/Muat turun untuk dokumen tersebut, mereka tidak dapat menyalin Teks Kandungan, memuat turun, mencetak, atau mencipta salinan. Apabila cuba melakukan tindakan ini, satu prompt akan dipaparkan.

## Penyelesaian

Hubungi Admin dokumen atau Knowledge Base untuk mengemas kini Tetapan kebenaran bagi dokumen atau Knowledge Base tersebut. Untuk maklumat lanjut tentang Tetapan kebenaran dokumen, lihat Konfigurasi kebenaran untuk perkongsian, penyalinan, muat turun, dan komen.
