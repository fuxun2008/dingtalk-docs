Versi web DingTalk Docs tidak menyokong penyemak imbas berasaskan enjin IE. Untuk pengalaman yang lebih baik dengan DingTalk Docs, pilih jenis penyemak imbas yang disokong mengikut keperluan. Menetapkan penyemak imbas yang disokong sebagai lalai dalam sistem anda memberikan pengalaman web DingTalk Docs yang lancar dan lengkap.

Ketahui lebih lanjut: [Menukar Penyemak Imbas Lalai](/docs/dingtalk-docs/settings/set-default-browser)

## 1. Windows

| **Versi sistem** | **Penyemak imbas yang disokong** |
| --- | --- |
| **Windows 7, 8, 8.1, dan 10** | *   [Chrome](https://www.google.cn/chrome/): versi 63.0 atau lebih baharu <br />    <br />*   [Microsoft Edge](https://www.microsoft.com/zh-cn/edge) (versi baharu) <br />    <br />*   [QQ Browser](https://browser.qq.com/) (mod Pantas): versi 10.0 atau lebih baharu <br />    <br />*   [360 Speed Browser](https://browser.360.cn/ee/) (mod Pantas) |
| **Windows XP** | *   [360 Speed Browser](https://browser.360.cn/ee/) (mod Pantas) |

## 4. Cara Menukar Penyemak Imbas Lalai

### Windows

1.  Klik Butang Mula, klik Tetapan, kemudian taip "Aplikasi lalai."

2.  Dalam Hasil carian, pilih Aplikasi lalai.

3.  Pergi ke Aplikasi > Aplikasi lalai > Penyemak imbas web, pilih penyemak imbas yang anda ingin tetapkan sebagai lalai, klik Tetapkan program ini sebagai lalai, dan klik Tukar juga apabila diminta untuk Selesai persediaan.

### macOS

*   Langkah 1: Buka **Tetapan** dan klik **Umum**.

*   Langkah 2: Cari **Penyemak imbas web lalai** dan pilih penyemak imbas yang anda ingin gunakan sebagai lalai.
