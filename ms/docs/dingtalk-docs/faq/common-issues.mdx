## S: Adakah DingTalk Menawarkan Edit Dalam Talian?

J: Ya. DingTalk menawarkan rangkaian penciptaan yang merangkumi DingTalk Docs, Spreadsheet, Mind Map, Whiteboard, dan AI Table, yang semuanya menyokong edit kolaboratif secara masa nyata.

Klik untuk maklumat lanjut: Ciri produk

## S: Apakah Itu DingTalk Docs?

J: DingTalk Docs ialah rangkaian pejabat kolaborasi perusahaan yang dibangunkan secara bebas oleh **Alibaba Group** DingTalk. Ia merangkumi alat penciptaan dan pengurusan dokumen dalam talian seperti **Docs, Spreadsheet, Mind Map, AI Table, Whiteboard, dan Knowledge Base**. Tiada muat turun diperlukan—edit dan lihat fail terus di komputer, telefon, atau tablet anda, dengan kandungan disimpan secara masa nyata. DingTalk Docs juga **disepadukan secara mendalam dengan DingTalk**, membolehkan kerjasama yang cekap dengan rakan sekerja berdasarkan struktur organisasi anda. Senario kerja harian seperti **pengumpulan maklumat, pengurusan projek, mesyuarat, laporan perniagaan, dan onboarding pekerja** semuanya boleh diselesaikan dengan cekap melalui DingTalk Docs.

Klik untuk maklumat lanjut: [Panduan permulaan pantas DingTalk Docs](/docs/dingtalk-docs/insert-content/insert-whiteboard)

## S: Bagaimana Saya Konfigurasikan Gaya Bar Alat Dokumen?

J: Klik "┇" di penjuru kanan atas, kemudian pergi ke "Keutamaan" — "Keutamaan Antara Muka" — "Bar Alat Atas". Anda boleh memilih bar alat dua baris, bar alat satu baris, atau tiada bar alat mengikut keutamaan anda.

## S: Bagaimana Saya Melihat Sejarah DingTalk Docs/Spreadsheet?

J: Semasa menggunakan DingTalk Docs atau Spreadsheet, anda boleh melihat sejarah melalui tetapan berikut:

DingTalk Docs: Penjuru kanan atas — ┇ — Sejarah. Sebagai alternatif, rujuk "Soalan 3" di atas untuk mengkonfigurasikan bar alat.

Spreadsheet: Penjuru kanan atas ... — Sejarah. Sejarah kini menyokong paparan versi terdahulu dan pemulihannya.

## S: Bagaimana Saya Muat Turun DingTalk Docs/Spreadsheet ke Peranti Lokal Saya?

J: Buka DingTalk Docs pada klien desktop dan muat turun dokumen dalam talian sebagai fail lokal menggunakan kaedah berikut:

DingTalk Docs: Penjuru kanan atas — ┇ — Muat turun ke lokal. Buat masa ini, format .docx, .pdf, dan .md disokong. Jika anda tidak dapat mencari bar alat, rujuk "Soalan 3" di atas untuk mengkonfigurasikannya.

Spreadsheet: Bar alat atas — Menu — Spreadsheet — Muat turun sebagai. Pilih format fail yang dikehendaki untuk dimuat turun.

Petua: Docs kini menyokong eksport ke Word/PDF. Spreadsheet kini menyokong eksport ke format Excel/PDF/CSV/TSV.

## S: Bagaimana Saya Mengaktifkan DingTalk Docs?

J: Ciri DingTalk Docs (edit dalam talian) tidak memerlukan pengaktifan. Cukup log masuk ke DingTalk dan lengkapkan pengesahan organisasi untuk menggunakan edit dalam talian.

## S: Bagaimana Saya Menyisipkan Gambar dalam DingTalk Docs?

J: DingTalk Docs kini menyokong penyisipan emoji, gambar, pautan video, lampiran, pautan, DingTalk Mind, peta jalan (roadmap), carta alir, dokumen dalam talian daripada Drive/Knowledge Base, pautan, dan banyak lagi. Klien mudah alih menyokong lebih sedikit jenis penyisipan—gunakan klien desktop untuk lebih banyak jenis.

**Klien desktop:** Buka DingTalk Docs, klik "+" pada bar alat atas, dan pilih Sisipkan Gambar. Sebagai alternatif, masuk ke mod edit, taip sengkang miring "/", dan pilih Sisipkan Gambar.

**Klien mudah alih:** Buka edit dalam talian DingTalk Docs, ketik ikon pada bar alat bawah — [Sisipkan Gambar] \ [Sisipkan Pautan]. Klien mudah alih kini menyokong penyisipan gambar, jadual, pautan, dan garis mendatar, tetapi tidak menyokong penyisipan fail.

## S: Bagaimana Saya Mengkonfigurasikan Kebenaran Edit Dokumen?

J: Klik [Kongsi] di penjuru kanan atas, pergi ke "Urus kebenaran" di bawah "Jemput kolaborator". Anda boleh menetapkan kebenaran kepada pengguna tertentu, termasuk: Urus, Edit, Lihat/Muat turun, Lihat sahaja, dan Buang kebenaran.

## S: Mengapa Sesetengah Pekerja Tidak Mempunyai Edit Dalam Talian?

J: Jika edit dalam talian tidak tersedia, sila semak perkara berikut:

1. DingTalk Lite tidak menyokong edit dalam talian.

2. Edit dalam talian hanya menyokong bahasa sistem yang ditetapkan kepada Bahasa Cina Ringkas atau Bahasa Inggeris. Kami mengesyorkan agar anda menukar bahasa sewajarnya.

3. Untuk fail Office yang dimuat naik secara lokal ke DingTalk, jika anda memilih untuk mengedit menggunakan editor rasmi Microsoft, anda perlu membeli DingTalk Office Suite Premium Edition.

4. Anheng MiDun tidak serasi dengan produk ini. Jika organisasi anda telah mengaktifkan Anheng MiDun, edit dalam talian tidak akan tersedia (semak sama ada terdapat ikon perisai kecil di penjuru kanan bawah fail).

5. Edit dalam talian kini menyokong fail Microsoft Office Word, Excel, dan PPT (edit dalam talian PPT hanya tersedia pada klien desktop). Fail dalam format lain tidak menyokong edit dalam talian—sila muat turun sebelum mengedit.

6. Edit dalam talian DingTalk Standard hanya menyokong pembukaan fail yang lebih kecil daripada 20 MB. Jika saiz fail terlalu besar, anda mungkin melihat mesej seperti "Gagal mendapatkan pautan edit" atau "Fail terlalu besar".

## S: Bolehkah DingTalk Docs Dibuka dalam Pelayar?

J: Versi web DingTalk Docs kini tersedia. Anda boleh menyalin pautan dan membukanya dalam pelayar di: https://docs.dingtalk.io/. Anda juga boleh menetapkan dokumen supaya dibuka secara automatik dalam pelayar. Untuk arahan, lihat: [Buka DingTalk Docs dalam pelayar](/docs/dingtalk-docs/settings/open-in-browser)

## S: Bagaimana Saya Memulihkan Data yang Hilang?

J: Buka DingTalk Docs, klik ┇ di penjuru kanan atas — Sejarah, dan cari versi yang anda ingin pulihkan di bawah [Sejarah Versi]. Setelah dijumpai, klik butang [Pulihkan] untuk melengkapkan pemulihan.
