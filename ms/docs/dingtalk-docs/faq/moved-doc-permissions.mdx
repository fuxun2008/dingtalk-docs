---
title: "Kebenaran Selepas Memindahkan Dokumen"
description: "Ketahui cara Kebenaran berubah apabila memindahkan dokumen antara Knowledge Base di DingTalk — kolaborator warisan daripada induk asal dialih keluar dan digantikan dengan kolaborator induk baharu, manakala kolaborator yang ditambah terus pada dokumen dikekalkan."
---

Apabila anda perlu memindahkan dokumen daripada satu Knowledge Base ke Knowledge Base lain, Tetapan Kolaborator dan Kebenaran dokumen tersebut turut berubah. Butirannya adalah seperti berikut:

## 1. Perubahan pada Kolaborator

Kolaborator sesebuah dokumen boleh diselaraskan secara automatik daripada direktori induk atau ditambah secara individu.

Apabila anda Memindahkan dokumen (atau Folder):

*   Kolaborator yang diselaraskan secara automatik daripada induk Lokasi asal dialih keluar.

*   Selepas pemindahan, Kolaborator diselaraskan semula daripada induk Lokasi sasaran.

*   Kolaborator yang ditambah secara individu pada dokumen oleh pengguna dikekalkan.

<Note>
### Contoh:

Dokumen "Nota Keluaran" dipindahkan daripada "Knowledge Base Jualan" ke "Knowledge Base Perkhidmatan Pelanggan". Kolaborator dokumen tersebut berubah seperti berikut:

### Sebelum Pemindahan

Lokasi: Knowledge Base Jualan / Nota Keluaran

Kolaborator dokumen ini:

Pengurus Jualan Wang (diwarisi daripada "Knowledge Base Jualan")

Ketua Teknikal Zhang (ditambah secara individu oleh pengguna)

### Selepas Pemindahan

Lokasi: Knowledge Base Perkhidmatan Pelanggan / Nota Keluaran

Kolaborator dokumen ini:

~~Pengurus Jualan Wang~~ ~~(diselaraskan daripada "Knowledge Base Jualan")~~ _**Kolaborator yang diselaraskan secara automatik daripada Lokasi asal dialih keluar**_

Pengurus Perkhidmatan Pelanggan Li (diselaraskan daripada "Knowledge Base Perkhidmatan Pelanggan") _**Selepas pemindahan, Kolaborator diselaraskan semula daripada induk Lokasi sasaran**_

Ketua Teknikal Zhang (ditambah secara individu oleh pengguna) _**Kolaborator yang ditambah secara individu pada dokumen oleh pengguna dikekalkan**_
</Note>

## 2. Perubahan pada Tetapan Kebenaran

Admin sesebuah dokumen boleh Konfigurasikan Tetapan Kebenaran dokumen itu sendiri. Pada masa yang sama, Tetapan Kebenaran dokumen tersebut turut dikawal oleh direktori induk. Untuk Tetapan khusus, rujuk: Tetapan Kebenaran | Panduan Tetapan Kebenaran Dokumen.

Apabila anda Memindahkan dokumen (atau Folder):

*   Kawalan Kebenaran daripada induk Lokasi asal tidak lagi terpakai.

*   Tetapan Kebenaran dokumen itu sendiri dikekalkan.

*   Selepas pemindahan, dokumen tertakluk kepada Tetapan Kebenaran induk Lokasi sasaran.

<Note>
### Contoh:

Dokumen "Nota Keluaran" dipindahkan daripada "Knowledge Base Jualan" ke "Knowledge Base Perkhidmatan Pelanggan". Tetapan Kebenaran dokumen tersebut berubah seperti berikut:

### Sebelum Pemindahan

Lokasi: Knowledge Base Jualan / Nota Keluaran

Tetapan Dipilih untuk dokumen ini:

Benarkan orang luar Organisasi ditambah sebagai Kolaborator:

**Off** (Dikonfigurasi secara individu untuk dokumen ini oleh pengguna)

Tunjukkan tera air:

**On** (dikawal oleh "Knowledge Base Jualan")

Perlindungan anti-kebocoran:

Off (keadaan Lalai)

### Selepas Pemindahan

Lokasi: Knowledge Base Perkhidmatan Pelanggan / Nota Keluaran

Tetapan Dipilih untuk dokumen ini:

Benarkan orang luar Organisasi ditambah sebagai Kolaborator:

**Off** (Dikonfigurasi secara individu untuk dokumen ini oleh pengguna) _**Tetapan Kebenaran dokumen itu sendiri dikekalkan**_

Tunjukkan tera air:

Off (tidak lagi dikawal oleh Lokasi asal; dikembalikan kepada keadaan Lalai) _**Kawalan Kebenaran daripada induk Lokasi asal tidak lagi terpakai**_

Perlindungan anti-kebocoran:

**On** (dikawal oleh "Knowledge Base Perkhidmatan Pelanggan" sasaran) _**Selepas pemindahan, dokumen tertakluk kepada Tetapan Kebenaran induk Lokasi sasaran**_
</Note>
