## Nilai

Dalam mod skrin berkembar, dua dokumen boleh diedit pada masa yang sama, menghapuskan keperluan untuk bertukar antara halaman serta menjadikan proses mengedit dan menyemak lebih cekap.

## Kes Penggunaan

Ding Sanduo ialah editor salinan di sebuah syarikat media baharu yang menggunakan DingTalk Docs setiap hari untuk menyemak dan menyunting pelbagai manuskrip serta menulis artikel. Dengan mod skrin berkembar dalam DingTalk Docs, tidak perlu lagi bertukar antara halaman dokumen semasa menyemak atau menyunting manuskrip. Semasa menulis artikel, bahan rujukan juga boleh dirujuk secara serentak dalam mod skrin berkembar, menjadikan kerja lebih mudah dan cekap.

## Arahan

Buka Dokumen A, kemudian klik Dokumen B yang disisipkan dalam Dokumen A untuk masuk ke mod skrin berkembar. Dalam mod skrin berkembar, kedua-dua dokumen boleh diedit secara serentak.
