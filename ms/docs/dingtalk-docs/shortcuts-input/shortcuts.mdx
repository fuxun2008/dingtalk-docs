---
title: "Pintasan"
description: "Rujukan lengkap pintasan papan kekunci DingTalk Docs untuk Mac dan Windows — format teks, gaya perenggan, sisipan, edit dan mod persembahan, boleh diakses terus dari mana-mana dokumen."
---

Pintasan yang disokong dalam Docs pada masa ini disenaraikan di bawah. Anda juga boleh klik ikon papan kekunci di sudut kanan bawah dokumen untuk memaparkan sebahagian daripada pintasan tersebut.

| Kategori | Fungsi | Mac | Windows |
| --- | --- | --- | --- |
| Pemformatan teks | Tebal | ⌘ + B | Ctrl + B |
|  | Condong | ⌘ + I | Ctrl + I |
|  | Coretan | ⌘ + Shift + X | Ctrl + Shift + X |
|  | Garis Bawah | ⌘ + U | Ctrl + U |
|  | Superskrip | ⌘ + . | Ctrl + . |
|  | Subskrip | ⌘ + , | Ctrl + , |
|  | Tambah saiz fon | `⌘ + Shift + >` | `Ctrl + Shift + >` |
|  | Kurangkan saiz fon | `⌘ + Shift + <` | `Ctrl + Shift + <` |
|  | Salin format teks | ⌘ + Shift + C | Ctrl + Shift + C |
|  | Tampal format teks | ⌘ + Shift + V | Ctrl + Shift + V |
|  | Kosongkan Format | ⌘ + \ | Ctrl + \ |
| Sisip | Sebut seseorang | @ | @ |
|  | Hiperpautan | ⌘ + K | Ctrl + K |
| Pemformatan perenggan | Tajuk | ⌘ + Option + \[1-4\] | Ctrl + Alt + \[1-4\] |
|  | Teks Kandungan | ⌘ + Option + 0 | Ctrl + Alt + 0 |
|  | Senarai Bernombor | ⌘ + Shift + 7 | Ctrl + Shift + 7 |
|  | Senarai Berbulet | ⌘ + Shift + 8 | Ctrl + Shift + 8 |
|  | Senarai tugasan | ⌘ + Shift + Y | Ctrl + Shift + Y |
|  | Tambah inden | Tab | Tab |
|  | Kurangkan inden | Shift+tab | Shift+tab |
|  | Jajar kiri | ⌘ + Shift + L | Ctrl + Shift + L |
|  | Jajaran Tengah | ⌘ + Shift + E | Ctrl + Shift + E |
|  | Jajar kanan | ⌘ + Shift + R | Ctrl + Shift + R |
|  | Jajar rata | ⌘ + Shift + J | Ctrl + Shift + J |
| Edit | Batalkan | ⌘ + Z | Ctrl + Z |
|  | Buat Semula | ⌘ + Y | Ctrl + Y |
|  | Cari | ⌘ + F | Ctrl + F |
|  | Cari dan Ganti | ⌘ + H | Ctrl + H |
| Lain-lain | Masuk mod persembahan/skrin penuh | ⌘ + Shift + P | Ctrl + Shift + P |
|  | Zum masuk (mod persembahan) | ⌘ + + | Ctrl + + |
|  | Zum keluar (mod persembahan) | ⌘ + - | Ctrl + - |
|  | Cetak | ⌘ + P | Ctrl + P |
