---

## Panduan Pengguna

Semasa mencipta dokumen, pilih Import sebagai dokumen dalam talian, kemudian pilih fail .md tempatan untuk mengimportnya ke DingTalk Docs.

## Format yang Disokong

### Format Fail

Tiga format fail berikut disokong:

.markdown

.mark

.md

### Pengekodan

Hanya fail yang dikodkan dengan set aksara UTF-8 disokong.
