## Apa Itu Markdown?

Markdown ialah bahasa penulisan ringan yang dicipta oleh blogger bebas terkenal, John Gruber. Dengan beberapa peraturan sintaks berasaskan simbol yang mudah, anda boleh memformat kandungan semasa menulis. Ini membolehkan anda fokus pada teks itu sendiri, menulis dengan lebih lancar, kekal fokus pada hasil kerja, dan meningkatkan kecekapan penulisan anda.

## Mengapa Guna Markdown?

Semasa menulis dalam Markdown, anda hanya perlu menaip beberapa simbol sintaks dan editor akan memformat kandungan anda secara automatik. Manfaatnya: apabila anda selesai menulis artikel, format juga sudah siap. Anda tidak perlu lagi menggunakan bar menu untuk menukar gaya aksara, menebalkan teks dan sebagainya. Ini meningkatkan kecekapan penulisan anda.

<Note>
## Kelebihan Markdown

**Sintaks mudah**

**Keserasian tinggi**

**Fokus pada kandungan**
</Note>

*   Sintaks mudah: Sintaks Markdown menggunakan simbol penanda yang mudah dan lazim. Malah bukan pengaturcara pun boleh mempelajarinya dalam beberapa minit sahaja.

*   Keserasian tinggi: Buka fail dalam mana-mana editor dan format akan kekal terpelihara.

*   Fokus pada kandungan: Dengan Markdown, anda tidak perlu risau tentang format. Formatnya yang bersih dan elegan membolehkan tangan anda kekal di papan kekunci dan membantu anda menikmati keseronokan menulis.

## Sorotan Penambahbaikan Markdown DingTalk Docs

<Note>
### Skop Sokongan
</Note>

*   Sokongan penuh untuk pelbagai gaya teks, termasuk **tebal**, **condong**, **coretan**, **garis bawah**, **superskrip dan subskrip**, serta **teks disorot**.

*   Sokongan baharu untuk **formula** Katex, termasuk gaya inline **$a+b$** dan gaya blok **$$a+b$$**.

*   Sokongan baharu untuk sintaks **blok anotasi**.

*   Sokongan baharu untuk sintaks **gambar** dan **pautan**.

*   Sokongan baharu untuk sintaks **emoji**.

*   Sokongan baharu untuk menyisipkan **rajah teks** melalui **\`\`\`mermaid** + **Enter**.

*   Sokongan baharu untuk sintaks **jadual**.

*   Tampal-ke-Teks Kaya menyokong Markdown dengan HTML terbenam.

    <Note>
    #### Penambahbaikan terperinci
    </Note>

*   Warna blok anotasi terbina dalam yang boleh ditetapkan dengan pantas melalui `::: + <type>`.

*   Petunjuk bantuan input baharu, jadi anda tidak perlu lagi menghafal pelbagai **sintaks blok kod**, **jenis blok anotasi**, atau **kod emoji**.

*   Input Markdown mesra pengguna untuk pautan:

    *   Gunakan **\[\]()** untuk menyisipkan pemegang tempat pautan, dengan fokus automatik pada kotak input tajuk pautan.

    *   Gunakan **\[title\]()** untuk menyisipkan pautan, dengan fokus automatik pada kotak input URL pautan untuk melengkapkan input.

*   Menaip **| | |** + **Enter** menyisipkan jadual dua baris dua lajur dengan fokus pada sel pertama baris pertama. Menaip **|x| |** + **Enter** menetapkan fokus pada sel pertama baris kedua.

*   Semasa menampal, pilihan "Tukar kepada Teks Kaya" akan muncul apabila sesuai, membolehkan anda menukar teks Markdown kepada format yang disokong oleh DingTalk Docs.

## Panduan Pengguna Markdown

DingTalk Docs menyokong kebanyakan sintaks Markdown. Anda boleh menggunakan Markdown semasa **Import**, **Eksport**, **Tampal**, atau **Edit**.

| Sintaks Markdown biasa | Sintaks Markdown lanjutan |
| --- | --- |
| *   **Tajuk 1-6**<br />    <br />*   **Petik**<br />    <br />*   **Senarai**: Senarai Bernombor, Senarai Berbulet, senarai tugasan dan banyak lagi<br />    <br />*   **Blok kod**<br />    <br />*   **Kod inline**<br />    <br />*   **Pemisah**<br />    <br />*   **Format teks**: Tebal, Condong, Garis Bawah, Coretan, warna latar belakang, superskrip dan subskrip, dan banyak lagi | *   **Pautan**<br />    <br />*   **Gambar**<br />    <br />*   **Formula**<br />    <br />*   **Blok anotasi**<br />    <br />*   **Jadual**<br />    <br />*   **Emoji**<br />    <br />*   **Rajah teks** |

### Import

Semasa mencipta dokumen, pilih "Import sebagai Dokumen Dalam Talian" - "Dokumen Tempatan", kemudian pilih fail .md tempatan untuk mengimportnya sebagai dokumen DingTalk Docs.

### Eksport

Selepas mengedit, anda boleh memuat turun dokumen sebagai fail .md untuk mengeksportnya. Untuk format Markdown yang disokong semasa eksport pada masa ini, rujuk "⏬ Eksport sebagai Markdown".

### Tampal

Salin sekeping teks Markdown daripada editor teks biasa atau editor Markdown, kemudian tampalkannya ke dalam DingTalk Docs. Dalam pilihan tampal yang dipaparkan, klik "Tukar kepada Teks Kaya" untuk menukarnya kepada format Teks Kaya yang disokong oleh DingTalk Docs. Untuk format Markdown yang disokong semasa menampal, rujuk " Tampal teks Markdown".

### Edit

Taip teks berformat Markdown tertentu dan tekan kekunci pencetus yang berkaitan (Space atau Enter) untuk menukar teks tersebut kepada format yang sepadan. Untuk format Markdown yang disokong semasa mengedit, rujuk "⌨️ Edit Markdown".

Pergi ke DingTalk Docs untuk melihat lampiran "edit markdown.mp4".

## Teknik Markdown DingTalk Docs yang Disyorkan

### Sisip Blok Anotasi dengan Pantas

Taip tiga titik bertindih (kedua-dua titik bertindih Bahasa Inggeris dan Cina disokong) + Enter untuk menyisipkan blok anotasi.

Tambah jenis selepas titik bertindih untuk menetapkan warna dengan pantas.

### Bantuan Input untuk Emoji, Blok Anotasi, dan Blok Kod

Bantuan input pintar membolehkan anda memasukkan yang berikut tanpa perlu menghafal kod atau jenis yang kompleks:

*   Kod emoji yang disokong

*   Jenis blok anotasi

*   Sintaks blok kod

Pergi ke DingTalk Docs untuk melihat lampiran "Input assist.mov".

### Input Alternatif untuk Pautan

Sintaks biasa `[title](url)` kini disokong.

Pergi ke DingTalk Docs untuk melihat lampiran "Screen Recording 2022-09-06 5.45.34 PM.mov".

### Sisip Rajah Teks dengan Pantas

\`\`\`mermaid + Enter

Tambah rajah teks sama seperti menambah blok kod.

Pergi ke DingTalk Docs untuk melihat lampiran "Screen Recording 2022-09-28 11.35.08 AM.mov".
