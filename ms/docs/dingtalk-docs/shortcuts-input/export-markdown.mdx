## Cara menggunakan

Selepas selesai mengedit dokumen, anda boleh muat turun fail tersebut sebagai fail .md untuk melengkapkan proses eksport.

DingTalk Docs mematuhi sintaks Markdown standard. Format yang disokong akan ditukar kepada teks Markdown, manakala elemen unik DingTalk Docs akan diturunkan secara sesuai (graceful degradation). Pemetaan terperinci ditunjukkan seperti berikut:
