Templat persembahan DingTalk Mind menyokong penjanaan sekali klik untuk animasi peralihan dan susun atur, menjadikan gambar rajah logik yang ringkas kelihatan menonjol dalam persembahan anda.

Ia juga menyokong ciri seperti bullet screen komen dan peta mini.

## Entri Mod Persembahan

Klik ikon persembahan di penjuru kanan atas untuk masuk ke mod persembahan.

## Cara Menggunakan Mod Persembahan

### Mulakan Persembahan

[Buka DingTalk Docs untuk melihat lampiran "Enter Presentation.mp4".](https://docs.dingtalk.io/i/nodes/QjXmLRyz4G5VGno4j3GPWZpaD19v6NK2?iframeQuery=anchorId%3DX02mfdmi3rgzlmnf0ikr6)

### Animasi Peralihan

[Buka DingTalk Docs untuk melihat lampiran "Transition Animations.mp4".](https://docs.dingtalk.io/i/nodes/QjXmLRyz4G5VGno4j3GPWZpaD19v6NK2?iframeQuery=anchorId%3DX02mfdmkyf1z9pjnuqp78j)

### Peta Mini untuk Menjejak Kemajuan Semasa

Peta mini dipaparkan semasa mod persembahan untuk membantu anda menjejak subjek yang sedang menjadi fokus.
