Eksport Peta Minda anda sebagai gambar untuk perkongsian dan pengedaran yang lebih mudah.

## Cara mengakses ciri Eksport Gambar

Klik ikon [...] di penjuru kanan atas, kemudian pilih [Muat turun sebagai] daripada menu lungsur.

## Cara menggunakan ciri Eksport Gambar

[Lawati DingTalk Docs untuk melihat lampiran "Export as image.mp4".](https://docs.dingtalk.io/i/nodes/B6L5QAmawMPJMagjDKKlJq1z09lnK3kb?iframeQuery=anchorId%3DX02mfdp8fr53195qolt3sa)
