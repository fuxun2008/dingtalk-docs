---
title: "Gambaran Keseluruhan Pintasan"
description: "Ketahui pintasan papan kekunci untuk DingTalk Mind Map yang membantu anda menyisip, memadam dan mengurus nod dengan lebih pantas tanpa perlu bertukar antara tetikus dan papan kekunci."
---

Apabila mencipta peta minda, pintasan membantu anda memasukkan kandungan dengan lebih cekap dengan mengurangkan keperluan untuk bertukar antara tetikus dan papan kekunci.

## Nota Penggunaan

*   Pilih satu atau lebih nod, kemudian tekan pintasan. Pintasan yang tidak berkaitan dengan nod boleh digunakan tanpa memilih sebarang kandungan.

## Mod Paparan Peta Minda

*   macOS:

| Kategori | Fungsi | Pintasan |
| --- | --- | --- |
| Umum | Sisip nod adik-beradik | Enter |
|  | Sisip nod anak | Tab |
|  | Sisip nod induk | Shift + Tab |
|  | Padam nod | Delete, Backspace |
|  | Navigasi nod | ↑↓←→ |
|  | Batalkan | ⌘ + Z |
|  | Buat Semula | ⌘ + Y |
| Tindakan nod | Salin nod | ⌘ + C |
|  | Potong nod | ⌘ + X |
|  | Tampal nod | ⌘ + V |
|  | Duplikat nod | ⌘ + D |
|  | Kembang/Kuncupkan | ⌘ + . |
| Navigasi | Zum masuk | ⌘ + + |
|  | Zum keluar | ⌘ + - |
|  | Masuk mod persembahan | ⌘ + Shift + P |
|  | Pembantu pintasan | Control + H |
