title: "Zum dan gerakkan kanvas"
description: "Ketahui cara zum dan tatal keseluruhan kanvas dalam mod Paparan Peta Minda DingTalk untuk beralih antara paparan terperinci dan gambaran keseluruhan dengan pantas."
---

Dalam mod Paparan Peta Minda, zum dan tatal keseluruhan kanvas untuk beralih antara butiran dan gambaran keseluruhan.

## Zum kanvas di desktop

*   Empat kaedah kini disokong:

1.  Ctrl + tatal tetikus.

2.  Gerak isyarat dua jari pada trackpad (belum disokong pada klien DingTalk Mac; buka dalam pelayar web untuk pengalaman yang lebih baik).

3.  Pintasan papan kekunci Ctrl + +/-.

4.  Gunakan alat zum di penjuru bawah kanan untuk mengawal zum kanvas.

## Gerakkan kanvas di desktop

*   Lima kaedah kini disokong:

1.  Tatal roda tetikus untuk menggerakkan kanvas.

2.  Gunakan gerak isyarat dua jari pada trackpad.

3.  Tahan butang kanan tetikus dan seret untuk menggerakkan kanvas.

4.  Klik ikon tangan di sebelah kiri untuk menggerakkan kanvas.

5.  Apabila kandungan banyak, seret bar tatal untuk menggerakkan kanvas.

## Zum kanvas di mudah alih

*   Dalam mod Paparan Peta Minda, cubit dengan dua jari pada area kosong kanvas untuk zum.

*   Selepas cubit-untuk-zum berjaya, nisbah zum semasa dipaparkan di tengah skrin.

## Gerakkan kanvas di mudah alih

*   Dalam mod Paparan Peta Minda, leret dengan satu jari pada area kosong kanvas untuk menggerakkannya.
