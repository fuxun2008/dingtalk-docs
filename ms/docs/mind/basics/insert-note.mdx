Ciri Alias menyediakan penerangan tambahan untuk Subjek. Gunakan ciri ini untuk menambah nota ringkas atau penerangan terperinci tanpa menjejaskan kekemasan Peta Minda anda.

## Titik Masuk untuk Sisip Alias

Sisip Alias kini hanya tersedia pada desktop; sokongan mudah alih akan disediakan tidak lama lagi. Untuk menggunakan ciri ini, klik bar alat dan edit alias.

## Cara Sisip Alias

Selepas menambah alias, klik kandungan alias atau ikon **Edit Alias** untuk membuka panel edit alias dan mengeditnya terus.
