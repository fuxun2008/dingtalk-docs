## Sorotan

✔️ Gunakan keupayaan penyuntingan DingTalk Docs yang berkuasa untuk mencipta pengumuman yang lebih kemas.

✔️ Import DingTalk Doc ke dalam pengumuman dengan satu klik untuk mengekalkan format sedia ada sepenuhnya — tiada pelarasan manual diperlukan.

✔️ Gunakan DingTalk Docs untuk menyusun dan menyimpan semua kandungan pengumuman secara berstruktur.

## Langkah

### Langkah 1: Cipta DingTalk Doc dalam Knowledge Base dan Edit Kandungan Pengumuman

Dengan cara ini, pengumuman turut disimpan sebagai dokumen dalam Knowledge Base, menjadikannya mudah dicari dan disemak kemudian.

### Langkah 2: Terbitkan Pengumuman Selepas Mengedit Kandungan dalam DingTalk Docs

#### Kaedah 1:

1. Klik menu "┇" di penjuru kanan atas dokumen dan pilih "Terbitkan pengumuman" untuk terus melompat ke aplikasi Pengumuman dan menerbitkan pengumuman menggunakan dokumen ini.

\*Nota: Entri "Terbitkan pengumuman" dalam dokumen hanya tersedia untuk "Pentadbir Organisasi yang turut mempunyai kebenaran Edit atau lebih tinggi bagi dokumen tersebut".

2. Apabila anda memasuki aplikasi Pengumuman melalui cara ini, dokumen tersebut akan dimuatkan terlebih dahulu secara automatik ke dalam kandungan pengumuman — tiada keperluan untuk mengimportnya semula.

#### Kaedah 2:

1. Buka aplikasi Pengumuman, pilih untuk menggunakan "DingTalk Docs", dan import dokumen pengumuman yang telah disediakan.

2. Pilih dokumen pengumuman yang telah disediakan dan import.

3. Selepas import, anda boleh teruskan mengedit pengumuman.

Selepas mengimport dokumen, anda boleh terus mengedit berdasarkan kandungan sedia ada. Anda juga boleh klik "Ganti dokumen" di penjuru kanan atas untuk memilih dokumen lain sebagai pengumuman. Dokumen baharu yang dipilih akan menggantikan dokumen yang diimport sebelum ini.

Selepas mengedit, ikut proses penerbitan pengumuman standard untuk menetapkan skop penerima dan butiran lain, dan pengumuman anda sedia untuk dihantar!
