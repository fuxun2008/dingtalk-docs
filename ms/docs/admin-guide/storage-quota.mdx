<Note>
**Lampiran (gambar, video, fail, dan sebagainya) dalam dokumen dalam talian DingTalk akan mula dikira secara rasmi ke dalam kapasiti storan organisasi bermula 30 Julai 2023. Sila pantau perubahan kapasiti sewajarnya.**

Rujuk arahan berikut untuk panduan melihat kapasiti dan membeli tambahan kapasiti.
</Note>

## 1. Peraturan Pengiraan Kapasiti DingTalk Docs

| Jenis Fail | Tingkah Laku Penggunaan | Dikira ke Dalam Kapasiti |
| --- | --- | --- |
| Fail tempatan | Muat naik fail dalam DingTalk Docs, termasuk dokumen, gambar, audio/video, arkib, dan sebagainya. | Dikira |
| Dokumen dalam talian | Cipta atau import dokumen dalam talian (dokumen, hamparan, peta minda, whiteboard) dalam DingTalk Docs. **Lampiran yang disisipkan semasa penyuntingan, termasuk gambar, audio/video, arkib, dan fail tempatan** juga dikira. | **Dikira secara rasmi bermula 30 Julai 2023** |
| Pintasan | Tambah pintasan dalam DingTalk Docs. | Tidak dikira |

## 2. Skop Pengiraan Kapasiti DingTalk Docs

**Pengiraan kapasiti merangkumi: "Dokumen Saya" dan "Knowledge Base".**

*   **Dokumen Saya:** Diperuntukkan kepada anda oleh organisasi untuk pengurusan pengetahuan peribadi, digunakan untuk pengumpulan dan pengurusan pengetahuan kerja individu.

*   **Knowledge Base:** Pengurusan pengetahuan yang disusun mengikut syarikat, jabatan, projek, dan sebagainya, digunakan untuk perkongsian, kerjasama, serta pengumpulan dan pengurusan pengetahuan organisasi.

## 3. Apakah Fail Tempatan dan Dokumen Dalam Talian?

**Fail tempatan:** Selepas dimuat naik ke Knowledge Base, fail tempatan mengekalkan format asalnya. Anda boleh mendapatkan pautan fail untuk berkongsi, dan sesetengah format menyokong pratonton.

**Dokumen dalam talian:** Merangkumi dokumen dalam talian yang baharu dicipta serta dokumen dalam talian yang diimport.

*   Cipta dokumen dalam talian: Kini menyokong penciptaan tiga jenis dokumen — DingTalk Docs, Spreadsheet, dan DingTalk Mind.

*   Import dokumen dalam talian: Jenis fail tempatan tertentu boleh diimport ke Knowledge Base dan ditukar menjadi dokumen dalam talian. Anda boleh mendapatkan pautan dokumen untuk berkongsi, dan fail tersebut ditukar kepada format DingTalk Docs. Butiran penukaran format:

| **Jenis Fail Tempatan** | **Jenis Fail Dalam Talian** |
| --- | --- |
| doc, docx, markdown, mark, md, txt | DingTalk Docs |
| xls, xlsx | Spreadsheet |
| xmind | DingTalk Mind |

## 4. Jenis Fail Manakah Yang Kini Disokong Untuk Muat Naik dan Import? Adakah Terdapat Had Saiz Fail?

Fail yang dimuat naik menyokong pratonton untuk pelbagai jenis fail, dengan saiz maksimum 8 GB setiap fail. Import hanya menyokong jenis dokumen, dengan saiz maksimum 20 MB setiap fail. Perbezaannya adalah seperti berikut:

| **Kaedah Pemindahan** | **Jenis Fail** | **Format Pratonton Yang Disokong** | **Had Saiz** |
| --- | --- | --- | --- |
| Muat naik | Dokumen | pdf, pptx, ppt, pot, potx, pps, ppsx, dps, dpt, pptm, potm, ppsm, xls, xlt, et, ett, xlsx, xltx, xlsb, xlsm, xltm, csv, doc, dot, wps, wpt, docx, dotx, docm, dotm, txt, xmind | Sehingga 8 GB setiap fail |
|  | Gambar | jpeg, bmp, png, jpg, ico, webp |
|  | Audio/Video | 3GP, AVI, FLV, MP4, M3U8, MPG, ASF, WMV, MKV, MOV, TS, WebM, MXF, AAC, AC-3, ADPCM, AMR, DSD, MP1, MP2, MP3, PCM, RealAudio, Windows Media Audio |
|  | Lain-lain | arkib zip |
| Import | Dokumen | docx, xlsx, doc, xls, txt, xmind, markdown, mark, md | Sehingga 20 MB setiap fail |

Untuk maklumat lanjut tentang "Muat naik" dan "Import", rujuk:

*   Knowledge Base menyokong muat naik fail tempatan

*   Perbezaan antara "Muat naik" dan "Import" dalam Knowledge Base DingTalk Docs

## 5. Di Manakah Admin Organisasi Boleh Melihat Butiran Penggunaan Kapasiti?

Buka OA Admin Console > Document & Storage Management > Storage Space (URL log masuk: [https://oa.dingtalk.io/](https://oa.dingtalk.io/)).

## 6. Bagaimana Cara Membeli Tambahan Kapasiti?

Memuat naik fail tempatan ke DingTalk Docs (Dokumen Saya, Knowledge Base) menggunakan kapasiti Drive organisasi. Menyisipkan gambar, audio/video, atau arkib dalam dokumen dalam talian (dokumen, hamparan, peta minda, whiteboard) juga menggunakan kapasiti Drive organisasi. Untuk butiran lanjut, rujuk Bahagian 1, "Peraturan pengiraan kapasiti DingTalk Docs" di atas.

DingTalk memberikan setiap organisasi 100 GB kapasiti Drive percuma secara kekal secara lalai. Jika ini tidak mencukupi, organisasi boleh membeli tambahan kapasiti.
