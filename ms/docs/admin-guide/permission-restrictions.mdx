## 1. Mengapa Saya Tidak Boleh Melihat Kebenaran atau Menambah Kolaborator?

*   Admin Knowledge Base, Folder, dan dokumen atau fail individu boleh mengkonfigurasikan Siapa boleh menambah kolaborator. Jika anda tidak memenuhi syarat ini, anda tidak boleh melihat kebenaran atau menambah kolaborator. Hubungi admin untuk membuat perubahan.

*   Admin dokumen, fail, atau folder individu boleh menukar tetapan ini di Urus kebenaran - Konfigurasi kebenaran. Admin Knowledge Base boleh menukarnya di Tetapan lain - Tetapan keselamatan. Untuk maklumat lanjut, lihat Tetapan kebenaran dokumen.

## 2. Mengapa Saya Tidak Boleh Menambah Pengguna Luar?

Pengguna luar mungkin dihadkan oleh organisasi, Knowledge Base, folder, atau dokumen atau fail individu. Untuk butiran, lihat Siapa boleh berkongsi dokumen di luar organisasi.

## 3. Mengapa Saya Tidak Boleh Menyalin Kandungan, Membuat Salinan, Mencetak, atau Memuat Turun?

#### 1) Versi Lama Konfigurasi Kebenaran

*   Admin Knowledge Base, Folder, dan dokumen atau fail individu boleh mengkonfigurasikan Siapa boleh menyalin, memuat turun, membuat salinan, atau mencetak. Jika anda tidak memenuhi syarat ini, anda tidak boleh menyalin, membuat salinan, menambah salinan ke, mencetak, memuat turun, menyimpan sebagai templat, atau melakukan tindakan lain berkaitan salinan dan muat turun. Hubungi admin untuk membuat perubahan.

*   Admin dokumen, fail, atau folder individu boleh menukar tetapan ini di Urus kebenaran - Konfigurasi kebenaran. Admin Knowledge Base boleh menukarnya di Tetapan lain - Tetapan keselamatan. Untuk maklumat lanjut, lihat Tetapan kebenaran dokumen.

#### 2) Versi Baharu Konfigurasi Kebenaran

*   Dalam versi baharu, Siapa boleh menyalin, melihat, membuat salinan, atau mencetak telah dinaik taraf kepada Pencegahan Kebocoran. Jika Pencegahan Kebocoran diaktifkan pada Knowledge Base, folder, atau dokumen individu, sesetengah pengguna akan dihadkan daripada menyalin, membuat salinan, menambah salinan ke, mencetak, memuat turun, menyimpan sebagai templat, dan tindakan lain berkaitan salinan dan muat turun, berdasarkan tetapan Pencegahan Kebocoran yang khusus. Hubungi admin untuk membuat perubahan.

*   Admin dokumen, fail, atau folder individu boleh menukar tetapan ini di Urus kebenaran - Konfigurasi kebenaran. Admin Knowledge Base boleh menukarnya di Tetapan lain - Tetapan keselamatan. Untuk maklumat lanjut, lihat Apakah itu Pencegahan Kebocoran untuk dokumen?

## 4. Mengapa Saya Tidak Boleh Mengulas Dokumen?

*   Admin Knowledge Base, Folder, dan dokumen atau fail individu boleh mengkonfigurasikan Siapa boleh mengulas. Jika anda tidak memenuhi syarat ini, anda tidak boleh mengulas dokumen tersebut. Hubungi admin untuk membuat perubahan.

*   Admin dokumen, fail, atau folder individu boleh menukar tetapan ini di Urus kebenaran - Konfigurasi kebenaran. Admin Knowledge Base boleh menukarnya di Tetapan lain - Tetapan keselamatan. Untuk maklumat lanjut, lihat Tetapan kebenaran dokumen.
