Dalam artikel ini, "berkongsi dokumen di luar organisasi anda" merujuk secara khusus kepada penambahan orang di luar organisasi anda sebagai Kolaborator.

## 1. Bolehkah Dokumen Dikongsi di Luar Organisasi Anda?

*   Secara lalai, dokumen dalam organisasi anda boleh dikongsi di luar organisasi **(iaitu, orang di luar Organisasi Anda boleh ditambah sebagai Kolaborator)**. Untuk mengubah tetapan ini, rujuk bahagian 3.

*   Secara lalai, hanya orang yang mempunyai kebenaran Urus untuk sesuatu dokumen boleh mengongsikannya di luar organisasi anda. Untuk mengubah tetapan ini, rujuk bahagian 4.

*   Jika tingkah laku tidak sepadan dengan penerangan di atas, kemungkinan Admin telah mengubah konfigurasi tersebut. Rujuk bahagian 2.

## 2. Mengapa Saya Tidak Boleh Menambah Orang di Luar Organisasi Saya sebagai Kolaborator?

### 1) Dokumen Dikonfigurasi untuk Tidak Membenarkan Perkongsian di Luar Organisasi Anda

*   Orang yang mempunyai kebenaran Urus untuk sesuatu dokumen boleh menyahaktifkan perkongsian di luar organisasi anda. Apabila dinyahaktifkan, tiada sesiapa boleh menambah orang di luar organisasi anda sebagai Kolaborator pada dokumen tersebut.

### 2) Dokumen Induk Dikonfigurasi untuk Tidak Membenarkan Perkongsian di Luar Organisasi Anda

*   Jika dokumen induk dikonfigurasi untuk tidak membenarkan perkongsian di luar organisasi anda, dokumen tersebut juga tidak dibenarkan secara lalai.

### 3) Knowledge Base yang Mengandungi Dokumen Itu Dikonfigurasi untuk Tidak Membenarkan Perkongsian di Luar Organisasi Anda

*   Admin Knowledge Base boleh memilih sama ada membenarkan dokumen dikongsi di luar organisasi anda di bawah "Tetapan keselamatan" Knowledge Base tersebut. Apabila dinyahaktifkan, tiada sesiapa boleh menambah orang di luar organisasi anda sebagai Kolaborator pada dokumen dalam Knowledge Base itu.

### 4) Admin Console Organisasi Dikonfigurasi untuk Tidak Membenarkan Perkongsian di Luar Organisasi Anda

*   Admin Organisasi boleh memilih sama ada membenarkan dokumen dikongsi di luar organisasi anda daripada admin console. Apabila dinyahaktifkan, tiada sesiapa boleh menambah orang di luar organisasi anda sebagai Kolaborator pada mana-mana dokumen dalam organisasi anda.

*   Jika perkongsian tidak dibenarkan tetapi Super Admin dibenarkan berkongsi dengan sesiapa sahaja, hanya Super Admin sahaja yang boleh menambah orang di luar organisasi anda sebagai Kolaborator.

### 5) Perkongsian di Luar Organisasi Anda Dibenarkan, Tetapi Saya Masih Tidak Boleh Melakukan Tindakan Tersebut

*   Walaupun perkongsian di luar organisasi anda dibenarkan, sekatan tambahan mungkin dikenakan: **1) Hanya pengguna dengan kebenaran Urus boleh berkongsi dokumen di luar organisasi anda.** Jika pilihan ini dipilih, pengguna tanpa kebenaran Urus tidak boleh menambah orang di luar organisasi anda sebagai Kolaborator. **2) Hanya pengguna dalam organisasi anda boleh menambah Kolaborator.** Jika pilihan ini dipilih dan terdapat Kolaborator dari luar organisasi anda, Kolaborator luaran tersebut tidak boleh menambah Kolaborator lain.

## 3. Cara Menyekat Perkongsian Dokumen di Luar Organisasi Anda

### 1) Sekat Perkongsian untuk Satu Dokumen

*   Pengguna dengan kebenaran Urus boleh mengakses "Tetapan kebenaran" daripada panel Kongsi.

*   Buka "Tetapan kebenaran" dan ubah pilihan "**Perkongsian luaran**". Matikan untuk menyahaktifkannya.

*   Setelah dinyahaktifkan, tiada sesiapa boleh menambah orang di luar organisasi anda sebagai Kolaborator pada dokumen tersebut.

*   Setelah dinyahaktifkan, sub-dokumen bagi dokumen ini juga tidak boleh dikongsi di luar organisasi anda.

### 2) Sekat Perkongsian untuk Semua Dokumen dalam Knowledge Base

*   Admin Knowledge Base boleh memilih sama ada membenarkan dokumen dikongsi di luar organisasi anda di bawah "Tetapan keselamatan" Knowledge Base tersebut.

*   Apabila dinyahaktifkan, tiada sesiapa boleh menambah orang di luar organisasi anda sebagai Kolaborator pada mana-mana dokumen dalam Knowledge Base tersebut.

### 3) Sekat Perkongsian untuk Semua Dokumen dalam Organisasi Anda

*   Admin Organisasi boleh memilih sama ada membenarkan dokumen dikongsi di luar organisasi anda daripada admin console. Apabila dinyahaktifkan, tiada sesiapa boleh menambah orang di luar organisasi anda sebagai Kolaborator pada mana-mana dokumen dalam mana-mana Knowledge Base atau dalam "Dokumen Saya" mana-mana pekerja. (Tetapan ini turut terpakai kepada Mesyuarat Segera dan Nota Segera dalam organisasi anda.)

*   Semasa menyahaktifkan perkongsian luaran dalam admin console, anda juga boleh memilih "Super Admin boleh berkongsi dengan sesiapa sahaja." Jika dipilih, hanya Super Admin sahaja yang boleh menambah orang di luar organisasi anda sebagai Kolaborator pada mana-mana dokumen dalam organisasi anda.

## 4. Benarkan Hanya Pengguna Tertentu Berkongsi Dokumen di Luar Organisasi Anda

*   Apabila perkongsian di luar organisasi anda dibenarkan, anda boleh menambah sekatan berikut:

    *   **Hanya pengguna dengan kebenaran Urus boleh berkongsi dokumen di luar organisasi anda**: Jika dipilih, semasa menambah Kolaborator pada sesuatu fail, pengguna tanpa kebenaran Urus hanya boleh menambah pengguna dalam organisasi anda. Hanya pengguna dengan kebenaran Urus boleh menambah orang di luar organisasi anda.

    *   **Hanya pengguna dalam organisasi anda boleh menambah Kolaborator**: Jika dipilih, mana-mana Kolaborator dari luar organisasi anda tidak boleh menambah Kolaborator lain.

*   Apabila dipilih pada satu dokumen, sekatan hanya terpakai kepada dokumen tersebut. Apabila dipilih pada Knowledge Base, sekatan terpakai kepada semua dokumen dalam Knowledge Base tersebut.
