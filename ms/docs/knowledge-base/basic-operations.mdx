---

## 1. Kemasukan Knowledge Base

*   Desktop: Bar alat kiri DingTalk — Buka Docs — Pilih Knowledge Base

*   Mobile: Bar menu bawah — Lain-lain — Ketik Docs — Knowledge Base

## 2. Cara Mencipta Knowledge Base

*   Desktop: Pada halaman Laman Utama Docs, pergi ke Knowledge Base, klik Cipta Knowledge Base, pilih Knowledge Base kosong atau Templat, klik Seterusnya untuk mencipta, kemudian tetapkan nama Knowledge Base dan Gambar Profil untuk melengkapkan penciptaan.

## 3. Cara Mengubah Suai Nama dan Ikon Knowledge Base

*   Semasa mencipta Knowledge Base, anda boleh menetapkan nama dan ikonnya.

*   Klik ikon "…" di sebelah kanan Knowledge Base, pilih Tetapan, kemudian pilih Maklumat Knowledge Base. Anda juga boleh mencari tetapan untuk mengubah suai nama Knowledge Base dan Gambar Profil di sini.

## 4. Cara Memadam Knowledge Base

*   Padam Knowledge Base: Klik penjuru kanan atas Knowledge Base untuk masuk ke Tetapan — Tetapan Premium, klik Padam Knowledge Base, ikut arahan untuk memasukkan "nama Knowledge Base" bagi mengesahkan, dan pemadaman akan selesai.

*   **Nota: Setelah pemadaman Knowledge Base disahkan, semua Kandungan akan dipadam dan tidak dapat dipulihkan. Sila teruskan dengan berhati-hati.**

## 5. Cara Mencipta Fail dalam Knowledge Base

*   Kaedah desktop 1: Pergi ke halaman Laman Utama Knowledge Base, buka Kandungan (Table of contents) di sebelah kiri, klik "+" — Cipta dokumen dalam talian, dan pilih Jenis Fail yang ingin anda cipta.

*   Kaedah mobile: Buka Knowledge Base, ketik "+" di penjuru kanan bawah, dan pilih Jenis Fail yang ingin anda cipta daripada tetingkap terapung.

## 6. Cara Menukar Knowledge Base bagi Organisasi/Organisasi/Pasukan

*   Semua Kandungan yang dicipta dalam Knowledge Base DingTalk Docs adalah Milik Organisasi/Organisasi/Pasukan tersebut. Anda mesti menukar kepada Organisasi/Organisasi/Pasukan semasa untuk melihat Kandungan Dokumen berkenaan.
