## Apa itu Muat Naik dan Import?

### Muat Naik:

Muat naik sebarang jenis fail tempatan ke Knowledge Base, dengan sokongan pratonton untuk format terpilih. Selepas muat naik, dapatkan pautan fail untuk dikongsi **tanpa mengubah format fail**.

Cara memuat naik: Pada **halaman utama Knowledge Base** >> klik "" dalam kandungan di sebelah kiri >> pilih untuk memuat naik fail atau folder tempatan ke Knowledge Base.

### Import:

Import jenis fail tempatan tertentu ke Knowledge Base, **menukarnya menjadi fail dalam talian**. Dapatkan pautan dokumen untuk dikongsi, **dengan fail ditukar kepada format DingTalk Docs**.

Cara mengimport: Pada **halaman utama Knowledge Base** >> klik "" dalam kandungan di sebelah kiri >> pilih **Import sebagai dokumen dalam talian**.

Penukaran format untuk jenis fail berbeza selepas import adalah seperti berikut:

| **Jenis fail tempatan** | **Jenis fail dalam talian** |
| --- | --- |
| doc, docx, markdown, mark, md, txt | DingTalk Docs |
| xls, xlsx | Spreadsheet |
| xmind | DingTalk Mind |

## Jenis Fail Apakah yang Disokong oleh Muat Naik dan Import? Adakah Terdapat Had Saiz Fail?

Muat Naik **menyokong pratonton untuk pelbagai jenis fail**, dengan maksimum 8 GB setiap fail. Import **hanya menyokong jenis dokumen**, dengan maksimum 20 MB setiap fail.

Perbezaannya adalah seperti berikut:

| **Kaedah** | **Jenis Fail** | **Format pratonton disokong** | **Had saiz** |
| --- | --- | --- | --- |
| Muat Naik | Dokumen | pdf, pptx, ppt, pot, potx, pps, ppsx, dps, dpt, pptm, potm, ppsm, xls, xlt, et, ett, xlsx, xltx, xlsb, xlsm, xltm, csv, doc, dot, wps, wpt, docx, dotx, docm, dotm, txt, xmind | Maksimum 8 GB setiap fail |
|  | Gambar | jpeg, bmp, png, jpg, ico, webp |
|  | Audio dan video | 3GP, AVI, FLV, MP4, M3U8, MPG, ASF, WMV, MKV, MOV, TS, WebM, MXF, AAC, AC-3, ADPCM, AMR, DSD, MP1, MP2, MP3, PCM, RealAudio, Windows Media Audio |
|  | Lain-lain | arkib zip |
| Import | Dokumen | docx, xlsx, doc, xls, txt, xmind, markdown, mark, md | Maksimum 20 MB setiap fail |

## Bilakah Anda Perlu Menggunakan Muat Naik dan Bilakah Perlu Menggunakan Import?

| **Kaedah** | **Kes penggunaan** |
| --- | --- |
| Muat Naik | *   Pindahkan PPT dan bahan dokumen pasukan sedia ada ke Knowledge Base jabatan untuk pengurusan berpusat.<br />    <br />*   Kongsi gambar dan video tempatan dengan pelbagai pasukan. |
| Import | *   Tukar fail tempatan menjadi fail dalam talian. |

## Adakah Muat Naik dan Import Menggunakan Storan Organisasi?

**Muat Naik Fail** **menggunakan storan organisasi**, manakala **Import sebagai dokumen dalam talian** **tidak menggunakan storan organisasi**. Butirannya adalah seperti berikut:

| **Kaedah** | **Sasaran pengebilan** | **Fail yang dikira dalam storan** | **Nota** |
| --- | --- | --- | --- |
| **Muat Naik**<br />Muat naik fail atau folder tempatan ke Dokumen Saya atau Knowledge Base | Ruang di lokasi muat naik | Semua fail yang dimuat naik | *   Apabila memuat naik folder secara terus, hanya fail di dalam folder dikira ke arah storan awan; folder itu sendiri tidak dikira.<br />    <br />*   Melihat gambar, video, dan fail milik orang lain tidak menggunakan storan anda. |
| **Import**<br />Cipta atau Import sebagai dokumen dalam talian dalam Dokumen Saya atau Knowledge Base | [Percuma untuk masa terhad] Tidak dikira | [Percuma untuk masa terhad] Tidak dikira | [Percuma untuk masa terhad] Tidak dikira |
