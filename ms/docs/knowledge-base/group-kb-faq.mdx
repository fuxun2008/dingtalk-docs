<AccordionGroup>
  <Accordion id="q1" title="Bagaimana cara saya mengakses Knowledge Base?">
    Knowledge Base tersedia sepenuhnya. Tiada permohonan diperlukan. Aksesnya melalui laluan berikut:

    Pada aplikasi mudah alih DingTalk, ketik **More** di bahagian bawah, kemudian pergi ke **Docs** > **Knowledge Base**.

    Pada aplikasi desktop DingTalk, pergi ke **Docs** > **Knowledge Base**.
  </Accordion>
  <Accordion id="q2" title="Bolehkah dokumen dalam Knowledge Base dikongsi?">
    Dokumen dalam Knowledge Base boleh dikongsi dengan pengguna dalam atau luar Organisasi Anda. Untuk berkongsi dokumen:

    1. Pada aplikasi mudah alih DingTalk, ketik **More** di bahagian bawah, kemudian pergi ke **Docs** > **Knowledge Base**. Ketik knowledge base yang disasarkan, buka dokumen, ketik ikon **...** di penjuru kanan atas, dan ketik **Share**. Anda boleh berkongsi dokumen sebagai gambar panjang, kod QR, pautan, atau dengan menghantarnya ke sembang.

    2. Pada aplikasi desktop DingTalk, pergi ke **Docs** > **Knowledge Base**. Buka dokumen yang disasarkan dan klik **Share** di penjuru kanan atas. Anda boleh berkongsi dokumen sebagai pautan atau dengan menghantarnya ke sembang.
  </Accordion>
  <Accordion id="q3" title="Apakah itu Knowledge Base?">
    Knowledge Base ialah platform pengurusan pengetahuan perusahaan yang profesional dan cekap, dibangunkan oleh Alibaba Group. Ia membantu organisasi membina hab pengurusan pengetahuan dan membolehkan kolaborasi dokumen dalaman. Ia mudah dan senang digunakan. Selepas admin mencipta knowledge base dan menambah pengguna, ramai orang boleh berkongsinya dengan penyegerakan masa nyata. Ahli pasukan boleh menggunakannya untuk merekod semua kandungan yang dihasilkan melalui kolaborasi dalaman.

    **Petua:**

    1. Pengguna peribadi: Knowledge Base tidak tersedia. Halaman akan meminta pengguna untuk menyertai atau mencipta organisasi.

    2. Pengguna organisasi: Cipta knowledge base dan tambah ahli pasukan untuk berkolaborasi membinanya serta mengumpul pengetahuan organisasi.
  </Accordion>
  <Accordion id="q4" title="Format fail yang manakah boleh diimport ke dalam Knowledge Base sebagai dokumen dalam talian?">
    Knowledge Base menyokong format fail berikut (maksimum 20 MB setiap fail): .docx, .xlsx, .doc, .xls, .txt, .xmind, .markdown, .mark, .md. Untuk mengimport fail, pada aplikasi desktop DingTalk, pergi ke **Docs** > **Knowledge Base**, buka knowledge base yang disasarkan, klik **+** > **Import as online document**, kemudian pilih dan import fail tersebut.
  </Accordion>
  <Accordion id="q5" title="Bagaimana cara saya menetapkan kebenaran untuk pengguna Knowledge Base?">
    Admin knowledge base boleh memberikan kebenaran kepada pengguna. Kebenaran yang tersedia ialah: Can manage, Can edit, Can view/download, Can view only, dan Set as owner. Butiran kebenaran:

    1.  **Can manage:** Edit, muat naik, muat turun, dan padam.

    2.  **Can edit:** Edit, muat naik, dan muat turun.

    3.  **Can view/download:** Muat turun, salin, dan cetak.

    4.  **Can view only:** Hanya pratonton dalam talian. Menyalin dan memuat turun tidak dibenarkan.

    5.  **Set as owner (hanya desktop):** Serahkan pemilikan kepada pengguna lain.
  </Accordion>
  <Accordion id="q6" title="Bolehkah dokumen yang dipadam dalam Knowledge Base dipulihkan?">
    Boleh. Dokumen yang dipadam akan dipindahkan ke **Recycle Bin**. Untuk mencarinya, buka knowledge base yang disasarkan dan klik ikon **Recycle Bin** di penjuru kiri bawah. Petua: Anda boleh **Restore** fail dalam Recycle Bin atau **Permanently delete** fail tersebut.
  </Accordion>
  <Accordion id="q7" title="Adakah Knowledge Base menggunakan storan DingTalk Drive?">
    Tidak. Dokumen dalam talian dalam Knowledge Base tidak menggunakan storan DingTalk Drive.
  </Accordion>
  <Accordion id="q8" title="Bolehkah Knowledge Base dipindahkan?">
    Pengguna dengan Kebenaran Edit untuk sesuatu knowledge base boleh memindahkan dokumen daripadanya ke knowledge base lain dalam organisasi yang sama. Memindahkan keseluruhan knowledge base ke dalam knowledge base lain dalam organisasi yang sama tidak disokong. Memindahkan knowledge base merentasi organisasi juga tidak disokong.

    Petua: Tindakan ini pada masa ini hanya disokong pada aplikasi desktop dan tidak tersedia pada aplikasi mudah alih. Untuk memindahkan dokumen, dalam jadual kandungan di sebelah kiri, klik ikon **...** di sebelah dokumen yang disasarkan, kemudian pilih **Move to** > lokasi sasaran > **Move**.
  </Accordion>
  <Accordion id="q9" title="Adakah Knowledge Base percuma?">
    Ya. Knowledge Base pada masa ini percuma untuk digunakan.
  </Accordion>
  <Accordion id="q10" title="Bagaimana cara saya melihat editor bagi sesuatu knowledge base?">
    Bahagian atas setiap dokumen knowledge base memaparkan editor (semua pengguna yang telah mengedit dokumen tersebut), masa kemas kini terakhir, dan bilangan pembaca (berserta butiran setiap pembaca).
  </Accordion>
