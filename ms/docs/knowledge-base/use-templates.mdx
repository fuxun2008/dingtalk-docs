## 1. Apakah Templat Knowledge Base?

*   Simpan dokumen kerja harian sebagai templat Knowledge Base. Ahli Knowledge Base boleh menggunakan templat ini untuk mencipta dokumen dengan pantas, memastikan format dan kandungan fail pasukan konsisten serta meningkatkan kecekapan kerjasama pasukan.

## 2. Cara Mencipta dan Menggunakan Templat Knowledge Base

*   Simpan dokumen sebagai templat Knowledge Base: Pada dokumen, klik **Lain-lain…** di penjuru kanan atas, klik **Simpan sebagai templat**, kemudian klik **Simpan sebagai templat untuk Knowledge Base ini**.

*   Cipta dokumen daripada templat Knowledge Base: Semasa mencipta dokumen baharu, pilih **Cipta daripada templat**, kemudian klik **Daripada Knowledge Base**.

## 3. Apakah Manfaat Templat Knowledge Base?

*   Templat Knowledge Base menyeragamkan gaya kandungan dokumen pasukan dan meningkatkan kecekapan penyuntingan ahli Knowledge Base. Contohnya, anda boleh menyimpan laporan mingguan atau laporan bulanan pasukan sebagai templat Knowledge Base, atau menyimpan templat pelan perniagaan sebagai templat Knowledge Base untuk menyeragamkan format dan kandungan.
