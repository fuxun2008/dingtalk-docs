Knowledge Base menyokong penambahan **fail tempatan, Fail Sembang, nota Mesyuarat Segera, dan log**, menjadikannya mudah untuk menyusun dan menyimpan bahan merentasi pelbagai senario bagi pengurusan pengetahuan yang lebih cekap.

## Cara menambah fail tempatan ke dalam Knowledge Base

Buka **Laman Utama** Knowledge Base >> klik "" pada Table of contents di sebelah kiri >> pilih dan muat naik fail tempatan atau Folder ke dalam Knowledge Base.

## Cara menambah Fail Sembang ke dalam Knowledge Base

**Dokumen tempatan**: Klik [Add to…] di penjuru kanan bawah Kad dokumen, kemudian pilih Knowledge Base sasaran.

**Dokumen dalam talian:** Klik [Add to…] di penjuru kanan bawah Kad dokumen, kemudian pilih Knowledge Base sasaran.

## Cara menambah Mesyuarat Segera ke dalam Knowledge Base

Buka dokumen Mesyuarat Segera >> klik [...] di penjuru kanan atas >> pilih [Add link to], kemudian pilih Knowledge Base dan Table of contents sasaran.

## Cara menambah log ke dalam Knowledge Base

Buka log yang ingin anda tambahkan ke dalam Knowledge Base >> klik [Add to] >> pilih Knowledge Base dan Table of contents sasaran.

## Cara menambah Fail Kumpulan ke dalam Knowledge Base secara pukal

Dalam tetingkap Sembang Kumpulan, klik **ikon Zum** di bahagian atas >> pilih **** >> buka dialog Fail kumpulan, pilih beberapa fail untuk ditambah ke dalam Knowledge Base >> klik **[Add to]** >> pilih Knowledge Base dan Table of contents sasaran. Anda boleh menambah bukan sahaja Dokumen, Spreadsheet, dan PDF, tetapi juga Folder, fail audio, dan lain-lain.
