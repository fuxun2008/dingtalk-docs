...

Kini anda boleh melakukan semua ini! DingTalk Docs menyokong muat naik fail tempatan seperti PDF, PPT, imej, audio, dan video. Anda juga boleh mengimport Quick Meetings dan log ke Knowledge Base dengan sekali klik.

Jadikan pengurusan pengetahuan pasukan mudah dan tersusun!

## Butiran tindakan

### Bagaimana untuk menambah fail tempatan ke Knowledge Base saya?

Klik "Docs" pada bar sisi kiri DingTalk untuk masuk ke **laman utama** Docs >> klik ikon di penjuru kanan atas >> pilih untuk memuat naik fail atau folder tempatan. Fail akan disimpan dalam "Dokumen Saya". Klik untuk melihatnya.

### Bagaimana untuk menambah fail tempatan ke Knowledge Base tertentu?

Pilih **laman utama** Knowledge Base >> klik "" pada bar Jadual Kandungan sebelah kiri >> pilih untuk memuat naik fail atau folder tempatan ke Knowledge Base ini.
