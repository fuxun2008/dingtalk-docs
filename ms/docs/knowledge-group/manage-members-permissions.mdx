Selepas anda mencipta Kumpulan Pengetahuan, urus penggunanya. Menggunakan kumpulan kosong sebagai contoh, anda boleh menambah atau mengeluarkan pengguna, serta menetapkan jenis pengguna yang berkaitan dengan kebenaran yang berbeza.

## Cara menambah atau mengeluarkan pengguna

*   Tambah pengguna: Pergi ke senarai pengurusan pengguna kumpulan dan klik **Tambah pengguna** di sudut kiri atas. Anda boleh menambah pengguna melalui empat kaedah: **Kenalan, Sembang Kumpulan, struktur organisasi, atau import pukal**. Buat masa ini, hanya pengguna dalam organisasi boleh ditambah. Pengguna luar tidak boleh ditambah.

*   Keluarkan pengguna: Bagi pengguna yang telah ditambah ke dalam kumpulan, klik **Sembunyikan perbualan** di bawah Tindakan untuk mengeluarkan pengguna daripada kumpulan.

## Kebenaran peranan Kumpulan Pengetahuan

Peranan dalam Kumpulan Pengetahuan termasuk: Pemilik, Admin, Ahli, Pengguna Baca Sahaja (dengan muat turun), dan Pengguna Baca Sahaja. Kebenaran yang berkaitan adalah seperti berikut:

| Peranan | Kebenaran kumpulan |
| --- | --- |
| Pemilik | Serahkan kumpulan, urus kumpulan, edit halaman utama dan Knowledge Base |
| Admin | Urus kumpulan, edit halaman utama dan Knowledge Base |
| Ahli | Edit kandungan |
| Pengguna Baca Sahaja (dengan muat turun) | Papar dan muat turun kandungan |
| Pengguna Baca Sahaja | Hanya papar, tiada muat turun |

## Knowledge Base mewarisi pengguna kumpulan secara lalai

Knowledge Base dalam sesebuah kumpulan mewarisi kebenaran pengguna kumpulan secara lalai. Untuk mengkonfigurasikan kebenaran secara berasingan bagi Knowledge Base dalam sesebuah kumpulan, pergi ke **Pengguna dan kebenaran** dalam Knowledge Base tersebut.
