---
title: "Padu padankan susun atur kreatif"
description: "Terokai lima gaya susun atur kreatif untuk halaman Kumpulan Pengetahuan DingTalk menggunakan editor laman utama tersuai, lengkap dengan contoh langkah demi langkah."
---

Berikut adalah lima gaya susun atur kreatif yang boleh anda padu padankan. Setiap gaya dibina langkah demi langkah menggunakan editor laman utama tersuai.

<Note>
**Gaya 1**

Langkah 1: Masuk ke skrin laman utama tersuai, tambah susun atur, dan pilih susun atur tiga lajur.

Langkah 2: Seret modul karusel ke dalam setiap lajur satu demi satu.

Langkah 3: Klik Simpan untuk kembali ke laman utama pasukan. Klik ikon pensel atau klik Tambah untuk masuk ke mod penyuntingan.

Langkah 4: Muat naik gambar dan konfigurasikan dokumen DingTalk Docs atau pautan untuk dialihkan ke.

</Note>
Langkah 5: Selepas menyunting, klik Sahkan untuk kembali ke laman utama pasukan. Anda boleh mengedit tajuk setiap lajur di atas gambar. Konfigurasikan kandungan setiap lajur satu demi satu untuk mencapai gaya ini!


<Note>
**Gaya 2**

Langkah 1: Masuk ke laman utama tersuai, tambah susun atur dahulu, dan pilih susun atur satu lajur.

Langkah 2: Selepas menambah susun atur, seret modul "Entri Pantas" ke dalam susun atur.

Langkah 3: Simpan halaman tersuai dan masuk ke laman utama pasukan.

Langkah 4: Dalam modul ini, klik Tambah Kandungan.

Langkah 5: Untuk setiap entri pantas, anda boleh menyesuaikan ikon (muat naik ikon sendiri juga disokong) dan sasaran alihan.

Langkah 6: Tambah entri pantas yang ingin anda paparkan satu demi satu.

</Note>
Langkah 7: Selepas menambahnya, simpan dan kembali ke laman utama, kemudian pilih gaya grid untuk mencapai kesan paparan ini!


<Note>
**Gaya 3**

Langkah 1: Tambah susun atur dahulu pada halaman tersuai.

Langkah 2: Seret modul kandungan bebas ke dalamnya, kemudian simpan.

Langkah 3: Kembali ke laman utama pasukan dan klik Tambah.

Langkah 4: Klik Sisipkan Lajur.

Langkah 5: Teruskan menyisipkan lajur di dalam lajur tersebut. Klik simbol =, kemudian klik ikon palet untuk melaraskan warna latar belakang lajur.

Langkah 6: Setiap lajur menyokong penyisipan gambar, video, dan kandungan lain. Anda juga boleh menyisipkan pautan dan menyesuaikan kandungan teks.

Langkah 7: Selepas mengisi kandungan, anda boleh menggunakan bar alat untuk menyesuaikan Saiz Fon, warna, dan lain-lain.

Langkah 8: Selepas menyimpan, anda boleh mencapai kesan ini. Untuk menambah beberapa baris, sisipkan lajur beberapa kali.

</Note>

<Note>
**Gaya 4**

Langkah 1: Pada halaman tersuai, klik Tambah Susun Atur.

Langkah 2: Seret modul kandungan bebas ke sini.

Langkah 3: Simpan halaman tersuai.

Langkah 4: Kembali ke laman utama pasukan dan klik Tambah.

Langkah 5: Sisipkan lajur.

Langkah 6: Sisipkan tiga lajur. Anda boleh terus menyisipkan lajur di dalam lajur.

Langkah 7: Pilih warna latar belakang dan sempadan untuk lajur.

Langkah 8: Masukkan kandungan dalam lajur dan klik Sahkan untuk mencapai kesan gaya tersebut!

</Note>

<Note>
**Gaya 5**

Langkah 1: Pada skrin laman utama tersuai, klik untuk menambah susun atur dua lajur.

Langkah 2: Seret modul entri pantas ke dalam setiap dua lajur. Simpan dan kembali ke laman utama pasukan untuk menambah kandungan.

Langkah 3: Ikon entri pantas menyokong muat naik gambar tersuai.

Langkah 4: Isi kandungan yang ingin anda paparkan satu demi satu, kemudian klik Sahkan.

Langkah 5: Kembali ke laman utama pasukan, klik "…", dan pilih gaya kad.

Langkah 6: Untuk lajur kedua, ikut langkah yang sama dan pilih ikon (ikon juga menyokong pemilihan warna!).

Langkah 7: Selepas mengisi semua kandungan, klik Sahkan.

Langkah 8: Kembali ke laman utama pasukan untuk melihat kesan paparan.

</Note>

**Gaya-gaya di atas hanya untuk rujukan. Bebaskan kreativiti anda dan reka susun atur yang lebih cantik dan praktikal!**
