<AccordionGroup>
  <Accordion id="q1" title="Apakah perbezaan antara Kumpulan Pengetahuan dan Knowledge Base?">
    Kedua-dua Kumpulan Pengetahuan dan Knowledge Base merupakan platform yang menyediakan keupayaan kolaborasi dan pengurusan.

    Perbezaannya ialah Kumpulan Pengetahuan merupakan superset kepada Knowledge Base. Satu Kumpulan Pengetahuan boleh terdiri daripada beberapa Knowledge Base, sekali gus menggabungkan maklumat yang bertaburan secara berkesan. Selain kegunaan asas seperti penciptaan kandungan, kolaborasi pasukan, dan pengumpulan pengetahuan, ia juga menyokong pembinaan laman utama budaya pasukan atau Organisasi bagi membentuk budaya organisasi yang berorientasikan pembelajaran. Lebih banyak ciri menanti untuk anda terokai.
  </Accordion>
  <Accordion id="q2" title="Bagaimana saya memindahkan Knowledge Base sedia ada dalam DingTalk Docs ke dalam Kumpulan Pengetahuan?">
    Terdapat dua cara untuk menambahkannya pada masa ini.

    *   Pilihan 1: Import dari dalam Kumpulan Pengetahuan. Pada kotak panduan laman utama yang dipaparkan semasa anda mengaktifkan kumpulan buat kali pertama, pilih [Import Knowledge Base sedia ada] untuk mengimport secara pukal. Walau bagaimanapun, hanya Knowledge Base yang anda merupakan Admin dan belum ditambahkan ke mana-mana kumpulan boleh diimport.
    * Pilihan 2: Pindah dari dalam Knowledge Base. Pada laman utama Knowledge Base yang ingin anda pindahkan, klik di penjuru kanan atas, kemudian [Tetapan lanjutan], dan pilih kumpulan di bawah [Tetapkan kepada Kumpulan].
  </Accordion>
  <Accordion id="q3" title="Bolehkah saya import manual produk luaran ke dalam Knowledge Base dalam sesuatu Kumpulan Pengetahuan?">
    Boleh. Pada skrin pilihan Knowledge Base bagi Kumpulan tersebut, klik [Import] dan pilih [Import Ruang Confluence] untuk memindahkan kandungan daripada ruang Confluence.
  </Accordion>
  <Accordion id="q4" title="Di manakah entri Kumpulan pada peranti mudah alih? Bagaimana cara menggunakannya?">
    Pergi ke [DingTalk mudah alih] - [Lain-lain] - [Docs] - [Kumpulan Pengetahuan], kemudian pilih Kumpulan yang disasarkan untuk mencipta dan mengurusnya.
  </Accordion>
  <Accordion id="q5" title="Saya ialah Admin sesuatu Kumpulan. Adakah saya akan secara automatik mendapat kebenaran untuk setiap Knowledge Base dalam kumpulan tersebut?">
    Ya. Knowledge Base dalam sesuatu kumpulan mewarisi kebenaran pengguna kumpulan secara lalai, jadi Admin kumpulan juga mempunyai kebenaran pengurusan untuk Knowledge Base dalam kumpulan tersebut.
  </Accordion>
  <Accordion id="q6" title="Bolehkah saya menambah pengguna Luaran ke dalam sesuatu Kumpulan?">
    Penambahan pengguna Luaran tidak disokong pada masa ini.
  </Accordion>
  <Accordion id="q7" title="Bagaimana saya menambah pengguna daripada Struktur Organisasi secara pukal dengan kebenaran ke dalam Kumpulan Pengetahuan atau Knowledge Base?">
    Untuk menambah ke dalam Kumpulan Pengetahuan: Pada skrin pilihan pengguna kumpulan, Admin boleh klik [Tambah pengguna] - [Pilih daripada Organisasi] dan pilih pengguna yang ingin ditambah.

    Untuk menambah ke dalam Knowledge Base: Pada skrin pilihan Knowledge Base, pilih Knowledge Base yang ingin anda tambah pengguna, klik [...] - , kemudian pilih [Pengguna dan kebenaran] - [Tambah pengguna] - [Pilih daripada Organisasi]. Ambil perhatian bahawa ini hanya disokong untuk Knowledge Base yang anda merupakan pencipta.
  </Accordion>
  <Accordion id="q8" title="Apabila seorang Pekerja meninggalkan Organisasi, adakah mereka akan dialih keluar secara automatik daripada Kumpulan?">
    Ya.
  </Accordion>
  <Accordion id="q9" title="Selepas Pemilik sesuatu Kumpulan Pengetahuan meninggalkan Organisasi, bagaimana pemilikan boleh diserahkan?">
    Dua kaedah penyerahan disokong pada masa ini.

    *   Penyerahan aktif: Pemilik semasa secara amnya merupakan Admin secara lalai. Pada skrin pilihan pengguna kumpulan, individu tersebut boleh menggunakan tindakan [Serahkan] untuk memilih penerima daripada Kenalan atau Struktur Organisasi dan menyerahkan kebenaran pengurusan kepada orang lain dengan satu klik.
    *   Penyerahan pasif: Selepas Pemilik meninggalkan Organisasi, Admin Organisasi boleh log masuk ke DingTalk Admin Console ([https://oa.dingtalk.io/](https://oa.dingtalk.io/)) untuk menyerahkan aset Pekerja tersebut, termasuk Kumpulan. Pilih kandungan yang berkaitan untuk melengkapkan penyerahan.
  </Accordion>
  <Accordion id="q10" title="Adakah terdapat had bilangan Knowledge Base dalam sesuatu Kumpulan Pengetahuan? Adakah ia dikira dalam kapasiti storan?">
    Sehingga 200.
  </Accordion>
  <Accordion id="q11" title="Bolehkah beberapa Kumpulan Jabatan dicipta dalam satu Jabatan?">
    Beberapa Kumpulan Pengetahuan boleh dicipta dalam satu Jabatan berdasarkan tahap Struktur Organisasi. Walau bagaimanapun, hanya satu Kumpulan Pengetahuan boleh dicipta atau diikat bagi setiap nod Struktur Organisasi.
  </Accordion>
  <Accordion id="q12" title="Bagaimana saya mengaktifkan Kumpulan Pengetahuan?">
    Kumpulan Pengetahuan kini berada dalam fasa beta khas jemputan. Untuk mencubanya, hubungi khidmat pelanggan DingTalk untuk memohon akses.
  </Accordion>
