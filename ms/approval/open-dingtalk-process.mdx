## 1. Gambaran keseluruhan ciri

Panduan ini membimbing Admin Organisasi dan pembangun tentang cara mengintegrasikan **proses Kelulusan dan halaman dalam sistem DingTalk OA** dengan **sistem perniagaan pihak ketiga (seperti ERP, CRM, dan sistem kewangan)** untuk menyediakan titik masuk bersepadu, interoperabiliti data, dan penyelarasan proses. Integrasi ini meningkatkan tahap automasi pejabat organisasi Anda, menghapuskan kemasukan data berulang, dan meningkatkan kecekapan kerjasama merentas sistem.

## 2. Senario yang berkaitan

Mulakan proses dari sistem perniagaan Anda, panggil API rasmi DingTalk Kelulusan OA untuk mencipta proses Kelulusan OA DingTalk, dan buka halaman butiran Kelulusan DingTalk pada pihak DingTalk untuk mengendalikan proses tersebut.

4.  Setelah instans Kelulusan dimulakan, pengguna boleh pergi ke Pusat Kelulusan DingTalk untuk melihat empat senarai Kelulusan (Belum Selesai, Telah Dikendalikan, Dimulakan, Diterima), mencari Data instans Kelulusan, melaksanakan Tindakan Kelulusan, dan banyak lagi.

5.  **Tambah Lampiran ulasan Kelulusan:** Untuk menambah Lampiran ulasan Kelulusan, mula-mula Muat naik Fail ke Ruang Drive Kelulusan, kemudian panggil Server API baharu — **Tambah ulasan kelulusan**. Untuk panduan terperinci, lihat: **Mengulas dan membatalkan proses Kelulusan**.

    1.  Panggil Server API baharu — **Dapatkan maklumat Ruang Drive Kelulusan** — untuk mendapatkan Kebenaran Muat Naik bagi Ruang Drive dan mendapatkan spaceId Ruang Drive Kelulusan.

    2.  Panggil JSAPI pada Bahagian klien — **Muat naik lampiran ke Drive / Pilih fail daripada Drive** — untuk mendapatkan maklumat asas Fail. Aliran ini menggunakan **JSAPI Explorer** untuk demonstrasi.

    3.  Setelah Anda mendapat spaceId Ruang Drive Kelulusan, gunakan `instanceId` instans Kelulusan untuk memanggil Server API baharu — **Tambah ulasan kelulusan** — untuk menambah ulasan pada borang Kelulusan.

6.  **Pratonton dan Muat Turun Lampiran Kelulusan:** Untuk pratonton atau muat turun Lampiran, panggil Server API — **Benarkan Muat Turun fail Drive Kelulusan** — dan API **Benarkan pratonton Lampiran Kelulusan** untuk membenarkan Fail Drive Kelulusan, kemudian panggil Server API — **Muat Turun Lampiran** — untuk mendapatkan `downloadUri` fail bagi tujuan Muat turun. Untuk panduan terperinci, lihat: **Aliran tindakan untuk Lampiran Kelulusan**.

7.  **Terima atau tolak tugasan Kelulusan:** penyokong boleh menerima atau menolak tugasan Kelulusan secara manual melalui Pusat Kelulusan DingTalk atau Pusat Tugasan DingTalk, atau sistem perniagaan boleh memanggil Server API baharu — **Dapatkan butiran satu instans kelulusan** — dengan `instanceId` instans Kelulusan untuk mendapatkan butiran instans Kelulusan dan `taskId` setiap nod tugasan Kelulusan.

8.  Dengan `instanceId` instans Kelulusan dan `taskId` nod tugasan yang berkaitan, panggil Server API baharu — **Terima atau tolak tugasan kelulusan** — untuk bertindak ke atas tugasan Kelulusan. Setelah setiap nod Kelulusan menerima, borang Kelulusan diluluskan.

Apabila status borang Kelulusan berubah, Kelulusan OA boleh menghantar Peristiwa callback seperti **Perubahan status tugasan Kelulusan** dan **Perubahan status instans Kelulusan** kepada sistem perniagaan, membolehkan aplikasi perusahaan berintegrasi dengan lebih mendalam dengan platform DingTalk untuk perkongsian maklumat dan penyelarasan perniagaan. Untuk panduan terperinci, lihat: **panduan operasi langganan peristiwa**.

## 6. API yang digunakan

### 1. Borang kelulusan

| API | Penerangan | Standard baharu (Server API baharu) |
| --- | --- | --- |
| Cipta atau kemas kini templat kelulusan | Cipta atau kemas kini templat borang proses Kelulusan OA; Anda boleh menentukan senarai komponen borang dan menjana proses Kelulusan Lalai. | **Cipta atau kemas kini templat borang kelulusan** |
| Dapatkan skema borang | Dapatkan maklumat skema borang berkaitan berdasarkan processCode. | **Dapatkan skema borang** |
| Dapatkan maklumat nod proses borang Kelulusan | Dapatkan maklumat nod proses borang Kelulusan. | **Dapatkan maklumat nod proses borang Kelulusan** |
| Dapatkan senarai borang kelulusan yang boleh dilihat oleh pengguna tertentu | Dapatkan senarai bermuka surat borang kelulusan yang boleh dilihat oleh Pengguna berdasarkan ID pengguna mereka. | **Dapatkan senarai borang kelulusan yang boleh dilihat oleh pengguna tertentu** |
| Dapatkan semua borang yang boleh diurus bagi organisasi semasa | Dapatkan semua borang kelulusan yang boleh diurus bagi Organisasi semasa. | **Dapatkan semua borang yang boleh diurus bagi organisasi semasa** |
