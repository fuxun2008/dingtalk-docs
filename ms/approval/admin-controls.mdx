## 1. Butiran kawalan borang

Borang kelulusan terdiri daripada pelbagai kawalan, dikumpulkan kepada tiga kategori:

| Kategori kawalan | Kawalan disertakan |
| --- | --- |
| Kawalan susun atur | Pembahagian lajur |
| Kawalan asas | Input satu baris, Input berbilang baris, Input numerik, Pilih Tunggal, Pilih Banyak, Tarikh, Julat tarikh, Teks penerangan, Kad pengenalan, Telefon |
| Kawalan lanjutan | Lata/Kategori, Gambar, Perincian/Hamparan, Amaun, Lampiran, Tandatangan, Kenalan, Jabatan, Lokasi semasa, Formula Pengiraan, Borang Kelulusan Berkaitan, Wilayah/Bandar/Daerah, Penilaian |

### 1) Kawalan susun atur

Pembahagian lajur meningkatkan kepadatan maklumat pada desktop dengan menyusun Medan borang ke dalam beberapa lajur secara bersebelahan.

<Note>
Pembahagian lajur hanya berkuat kuasa pada **desktop** sahaja; bahagian mudah alih tetap dipaparkan dalam satu lajur. Kawalan ini tiada Tetapan Atribut, kekangan data, atau Cari.
</Note>

### 2) Kawalan asas

Kawalan asas berkongsi tetapan sepunya berikut:

| Tetapan sepunya | Keterangan |
| --- | --- |
| Tajuk | Tajuk yang dipaparkan pada borang. Sehingga 50 aksara |
| Teks ruang letak | Teks petunjuk kelabu yang dipaparkan di dalam input kosong pada borang. Sehingga 50 aksara |
| Lalai | Kandungan Lalai yang dipaparkan di dalam input kosong pada borang. Apabila Kebenaran Langkah ditetapkan kepada "Boleh Edit", nilai medan yang terikat kepada kawalan ini boleh diubah suai |
| Tetapan wajib | Dimatikan secara lalai. Apabila Diaktifkan, medan yang terikat kepada kawalan ini disahkan semasa penghantaran borang, dan penghantaran akan disekat jika medan itu kosong |
| Tetapan cetak | Diaktifkan secara lalai. Apabila dimatikan, medan yang terikat kepada kawalan ini dikecualikan daripada PDF butiran borang yang dimuat turun atau dicetak |
