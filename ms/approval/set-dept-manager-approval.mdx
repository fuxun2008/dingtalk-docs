## 1. Gambaran keseluruhan

<Note>
Admin boleh menetapkan ketua jabatan sebagai penyokong.

Ketua jabatan merujuk kepada pengurus yang ditetapkan dalam Kenalan.

Apabila ketua jabatan ditetapkan sebagai penyokong, jika ketua jabatan berubah, Proses kelulusan akan terus berjalan seperti biasa—cukup kemas kini ketua jabatan sahaja.

Perubahan ketua jabatan akan berkuat kuasa untuk Kelulusan yang telah dimulakan tetapi belum sampai ke nod semasa, serta pada Tetapan proses dalam templat kelulusan.
</Note>

## 2. Prasyarat

*   Hanya Admin Kelulusan yang boleh melakukan reka bentuk proses, jadi anda perlu menjadi Admin Kelulusan terlebih dahulu.

Jika anda bukan Admin Kelulusan, buka Kelulusan OA DingTalk, klik [Tetapan], klik [Cipta Borang kelulusan], klik [Mohon Kebenaran Admin], dan klik "Hantar".

Setelah Admin menerima Peringatan kelulusan yang belum selesai dan meluluskannya, Pekerja berkenaan akan diberikan Kebenaran Admin Kelulusan secara automatik.

## 3. Langkah

### 1. Tetapkan ketua jabatan

Admin memasukkan URL [DingTalk Admin Console](https://oa.dingtalk.io) dalam pelayar untuk membuka Admin Console, kemudian klik "Pengurusan Kenalan" untuk membuka pengurusan Kenalan dalaman.

Selepas klik Tambah Jabatan, klik "..." di sebelah nama Jabatan, klik Tetapkan ketua jabatan, Pilih Pengguna yang dipaparkan daripada Kenalan, dan klik "Sahkan" untuk melengkapkan penetapan.

Nota: ketua jabatan mestilah tergolong dalam Jabatan semasa.

#### 2. Tetapkan ketua jabatan sebagai penyokong dalam Proses kelulusan

Pada Halaman **"Admin Console Kelulusan"** - **"Pengurusan Borang"**, klik [**Edit**] dalam Lajur Tindakan Borang.

Klik [**Reka bentuk proses**] untuk membuka antara muka reka bentuk proses utama.

Untuk penyokong nod, Pilih "ketua jabatan". Anda boleh memilih peringkat ketua jabatan di atas pemohon untuk dihalakan, sehingga peringkat ke-8.
