## 1. Gambaran keseluruhan

<Note>
Admin boleh mengkonfigurasikan tetapan wakil dalam Admin Console.

Ini termasuk penyokong yang diwakilkan, wakil, dan tempoh pewakilan.
</Note>

## 2. Prasyarat

*   Hanya Admin Kelulusan yang boleh melaksanakan reka bentuk proses, jadi anda perlu menjadi Admin Kelulusan terlebih dahulu.

Jika anda bukan Admin Kelulusan, buka Kelulusan OA DingTalk, ketik **Tetapan**, ketik **Cipta Borang kelulusan**, ketik **Mohon Kebenaran Admin**, kemudian ketik **Hantar**.

## 3. Langkah

### 1. Masuk ke tetapan wakil

Pergi ke **Approval Admin Console** > **System Management** > **Delegate Settings**.

<Frame>

![Entri Delegate Settings dalam Approval Admin Console](https://img.alicdn.com/imgextra/i1/O1CN01XzJSKu9nVvC4gn7Y_!!6000000002762-2-tps-2310-1634.png)
</Frame>

### 2. Tetapkan wakil

Pilih **penyokong yang diwakilkan** dan **wakil**, kemudian pilih **tempoh pewakilan**.

<Frame>

![Menetapkan wakil dan tempoh pewakilan](https://img.alicdn.com/imgextra/i2/O1CN01IHcerq6KcQL4gn7U_!!6000000000321-2-tps-2310-1630.png)
</Frame>

### 3. Semak rekod pewakilan

Klik **Delegation Records** untuk menyemak rekod mengikut **penyokong yang diwakilkan** atau **wakil**, atau untuk Batalkan Rekod pewakilan yang aktif.

<Frame>

![Senarai Delegation Records](https://img.alicdn.com/imgextra/i2/O1CN013qPjMQP5ZiD2LWMh_!!6000000000019-2-tps-1156-819.png)
</Frame>
