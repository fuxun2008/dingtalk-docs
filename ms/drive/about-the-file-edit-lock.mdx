# Apakah Kunci Edit Fail?

*   Apabila pengguna mula mengedit fail dalam folder segerak setempat DingTalk Drive, fail tersebut akan dikunci.
    
*   Fail yang dikunci tidak boleh diedit oleh orang lain pada peranti lain, ini mengelakkan konflik versi dan mengurangkan beban pengurusan versi.
    
*   Apabila pengguna menutup fail tersebut, kunci akan dibuka secara automatik, dan orang lain boleh membuka serta mengeditnya.
