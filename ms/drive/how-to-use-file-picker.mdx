---
title: "Cara Menggunakan File Picker DingTalk Drive untuk Menghantar Fail dengan Cekap"
description: "Gunakan File Picker DingTalk Drive dalam sembang — klik ikon hantar fail di bawah kotak input, pilih Send DingTalk Drive File, dan pilih fail sedia ada daripada Drive anda untuk hantar dengan cekap."
---

Dalam tetingkap mesej sembang, klik ikon **send file** di bawah kotak input, kemudian pilih **Send DingTalk Drive File** untuk memilih dan menghantar fail daripada DingTalk Drive.
