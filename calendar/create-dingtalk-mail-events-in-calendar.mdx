## Create DingTalk Enterprise Mail events

Organizations and individuals using DingTalk Enterprise Mail can send and receive mail calendar events directly in DingTalk Calendar. This helps them get the latest meeting arrangements and work tasks in real time, avoid missing important meetings or tasks, and manage organization and personal schedules more efficiently.

Supported on Mac, Windows, iOS, and web.

## Operation path

## Mobile

Tap **+** in the lower-right corner to create an event. Tap **+** to add participants, then select **Invite by email**.

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/ZWGl05m76X2YQn34/img/fe149f2b-475f-44a2-9eb9-778096005e11.png)

Select and add the enterprise mailbox to create a DingTalk Enterprise Mail event.

![33.jpeg](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/ZWGl05m76X2YQn34/img/35271e56-9828-49c1-a202-72fcc1d84f37.jpeg)

## Desktop

Create a new event, click **Add participants**, and select **Add in bulk**.

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/ZWGl05m76X2YQn34/img/f08f9113-96c7-4631-931e-0df1af3af793.png)

Select **Mail contacts**, then select the required mailbox.

When the sending prompt appears, click **Send** to create the DingTalk Enterprise Mail event.

In **DingTalk Calendar**, you can view the event and see the enterprise mailbox in the participant list.
