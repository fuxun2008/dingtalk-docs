title: "Set the Default Event Duration"
description: "Set a default duration for new events under Calendar Settings → View so common lengths apply automatically—useful for HR, recruiting, training, and recurring meeting workflows."
---

## Feature value

Calendar supports custom default event durations. You can set common event lengths based on your usual schedule types, making event creation more flexible and convenient.

## Use case

Ding Sanduo is an HR employee who often uses DingTalk Calendar to create interviews, meetings, trainings, and other work events. With this feature, Calendar can apply the default duration set by the user, so different types of events can be created more flexibly.

## How to use it

In Calendar Settings, open the **View** page and set the default event duration. When you create a new event, the default duration will follow your setting.
