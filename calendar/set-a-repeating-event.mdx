---
title: "Set a Repeating Event"
description: "Create one event that recurs over weeks—open the new-event form, tap Does not repeat, and pick daily, weekly, monthly, or a custom cycle so future schedules are filled in automatically."
---

Calendar supports setting a repeating event for multiple future weeks at once, saving you from repeated manual setup.

### How to set it

Go to **DingTalk Calendar**, click **+**, and create a new event.

![](https://img.alicdn.com/imgextra/i2/O1CN011qgfhimIwkJ5VtjE_!!6000000001117-2-tps-2716-1356.png)

On the new event page, click **Does not repeat**. You can set the repeat cycle to daily, weekly, monthly, and more. Custom repeat cycles are also supported.
