## Feature value

When you receive an event reminder, you can set a later reminder time. This makes reminders more timely, flexible, and considerate, helping you avoid missing important events.

## Use case

Ding Sanduo is an event planner at an internet company and often uses DingTalk Calendar to create work events. Sometimes an event reminder appears while she is in another meeting, and dismissing it may cause her to forget the event. With this feature, she can choose to be reminded later and postpone the reminder freely.

## How to use it

When you receive an event reminder, click **Later** in the pop-up to postpone the reminder.
