---
title: "Delete an Event"
description: "Cancel or remove events you no longer need—organizers can cancel future multi-participant events from desktop or mobile, while participants can delete events from their own calendar."
---

Created an unnecessary event by mistake? You can delete it easily and keep only the events you need.

Only future multi-participant events can be canceled.

The organizer can cancel an event.

![](https://img.alicdn.com/imgextra/i4/O1CN016i9525T52oC5VtjE_!!6000000001337-2-tps-2716-1356.png)

The organizer or participants can delete an event.

![](https://img.alicdn.com/imgextra/i4/O1CN01leSIoNghH0H5VtjE_!!6000000002000-2-tps-2716-1356.png)

## Operation path

### Desktop

Go to **DingTalk Calendar**, open the event you want to delete, click ... in the upper-right corner, and select **Cancel event**.

![](https://img.alicdn.com/imgextra/i4/O1CN01XhQuLPQ67jK5VtjE_!!6000000005955-2-tps-2716-1356.png)

### Mobile

Go to **DingTalk Calendar**, open the event you want to delete, tap ... in the upper-right corner, and select **Cancel event** or **Delete**.
