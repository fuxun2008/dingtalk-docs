## 1. Introduction

### 1.1 Feature overview

To visualize the data proportion of each department, use the Pie chart component.

Highlight: You can resize the component and move it freely (left-aligned, center-aligned, or right-aligned).

### 1.2 Use cases

For example, use angles to represent data proportions, as shown below.

### 1.3 Basic requirements

The basic requirements for a Pie chart are as follows:

| **Category field** | **Numerical field** | **Trend value field** | **Total value field** | **Total trend value field** | **Total value drill-down icon** |
|---|---|---|---|---|---|
| Up to 1 field | Up to 1 field | Multiselect supported, up to 30 fields | Up to 1 field | Multiselect supported, up to 30 fields | Up to 1 field |

### 2.3 Style settings

Five sub-categories are available: style configuration, labels, legend, tips, and percent decimal places, as shown below.

#### 2.3.1 Style configuration

- Adjust the color and size of the Pie chart
- Convert the basic Pie chart into a ring chart
- Adjust the inner radius of the ring chart

Note: When **Group color** is Not Configured, color adjustments under Style take effect.

Custom colors support English color names or hexadecimal values, such as #5894FF. Separate multiple values with commas.

**The inner metric refers to the area circled in red in the figure, as shown below.**

Effect after configuration

#### 2.3.2 Labels

Turn labels On or Close. When On, you can configure the connection line position and display, label size and content, and color (black by default).

**Note: When the position is set to Spider, no color settings are available. Font color can only be set when the position is Outside or Inside.**

Configure labels

#### 2.3.3 Legend

Turn the legend On or Close. When On, you can adjust its position and toggle pagination (On by default).

- Legend type: legend items and Metrics
- Metrics: When the Layout is vertical, you can adjust the ratio of the two columns.
