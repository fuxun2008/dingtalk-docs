## 1. Introduction

### 1.1 Feature overview

**Word Cloud** is a new chart component supported by Yida 3.0 reports, used for **data analysis** and **data visualization**.

- The Word Cloud component is configured through three main attributes: "Text", "Weight", and "Color".
- Supports customizable text size, shape, and color.
- Enables data drill-down through the "Drill-down" attribute, and parameter-based redirection through the "Link" attribute.

Word Cloud component entry and display effect

### 1.2 Use cases

During a Double 11 campaign at an electrical appliance company, the **Word Cloud component uses different colors and sizes to represent the relative significance of items**, showcasing the products with the highest sales revenue and volume. Similarly, in daily recruitment work, the Word Cloud component can display the positions with the highest business skill requirements.

### 2.2 Step 2: Configure the three attributes—Text, Weight, and Color

The data for these three attributes can be directly selected from columns in the dataset, or calculated and displayed using report formulas. For instructions on using formulas, [**view the tutorial**](/yida/form/yrofmw).

- Text: Required. The words to be displayed.
- Weight: Required. The weight data for each word, which supports aggregation.
- Color: Optional. The field that controls text color. For example, if your word is "Product Name" but you want cities within each province to share the same color, you can enter the "Product Name" field for Color. If left blank, the color will be set according to the "Weight" field by default.

### 3.1 FAQ

#### 3.1.1 When there is too much data, some Word Cloud entries are not fully displayed

Increase the chart's width and height. This happens because Yida sets the minimum font size of a word cloud unit to 12 pixels for better display quality, so excess data may be hidden.
