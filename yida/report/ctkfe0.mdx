## 1. Introduction

Aggregate scattered data under a field for statistical analysis. The available aggregation methods depend on the field type.

## 2. Steps

**Path**: Report page >> Spreadsheet column >> Edit button next to the field >> Data settings panel >> Aggregation

**String**: Count, Count (deduplicated)

**Date**: Count, Count (deduplicated), Maximum, Minimum

**Numerical**: Count, Count (deduplicated), Sum, Average, Maximum, Minimum
