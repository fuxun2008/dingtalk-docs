## 3. Other top-bar features

### 3.1 Export

Supports turning on and off. It is off by default. When the exported Data exceeds 10,000 records, at least one sort field must be set to improve the success rate of Data Export.

### 3.2 Refresh

Refresh the report Data.

### 3.4 Data cache

Enabled by default. Enabling it improves query performance.

Data cache

### 3.5 Enable component linkage

Click the designated area of a component to set up linkage between components. Currently, only the **Pie** chart supports initiating linkage, while all components can receive linkage.

**Tutorial**

(1) Configure the dataset and fields in the Pie chart component, and Enable component linkage.

(2) Add a new chart component and Configure it with the same dataset as the Pie chart.

(3) The result: when you Select a segment of the Pie chart with the mouse, the Column chart will only display the Data corresponding to what you clicked on the Pie chart.
