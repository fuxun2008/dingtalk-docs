## 1. Introduction

### 1.1 Feature overview

Used to display image information.

Highlight: You can adjust the size of the component, but cannot move its position (left, center, right).

### 1.2 Use cases

Displaying warehouse product data with the corresponding product images.

## 2. Operation steps

### 2.1 Select the Image component

Basic >> Image >> Once selected, it appears in the editor, as shown below:

Report page editing.

### 2.2 Attribute configuration

- Image link: Copy the image link and paste it in. The image is displayed on the page automatically.
- Direct upload: Drag and drop the image into the dashed frame. Supported formats include jpg, jpeg, png, gif, and mp. Image size must be less than 10 MB.

Upload image method.

Insert image link.

- Layout mode: Fill, Fit, Stretch.
- Corner type: The corner radius of the four corners of the image. Options include Large, Medium, Small, None, and Custom.

- Corner radius size: Works with the Custom corner type. When Custom is selected, you can set the corner radius size.

- title: A basic attribute of the image, not displayed.
- Alternative text: The fallback text shown when the image URL does not exist, as shown below:

Alternative text.

- Premium: Unique identifier.
