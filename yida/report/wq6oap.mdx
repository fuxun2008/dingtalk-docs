Reports provide a variety of chart styles. Use Details table and Pivot Table to view detailed and aggregated form or workflow form data. Use Column, Line, and other charts to process data and reveal trends, category comparisons, and more. Use Pie to show the proportion of each part in the data.

| **Component name** | **Purpose** |
|---|---|
| [**Column**](/yida/report/xybfun) | Uses vertical or horizontal bars to show **numerical comparisons between categories**. |
| [**Pie**](/yida/report/hb73mq) | Used to view the data proportion of each Department. |
| [**Line**](/yida/report/pnsoga) | Displays how data **changes over a continuous time interval or time span**. It reflects the trend of things changing over time or across ordered categories. |
| [**Column-Line combo chart**](/yida/report/wfno1e) | Column visualizes differences between groups of data and emphasizes comparisons between individuals.<br />Line analyzes how the sales of a product change over time, helping forecast future sales.<br />Column-Line combo chart displays both Column and Line at the same time. |
| [**Dashboard**](/yida/report/xgetgl) | Lets you control component size and freely move component positions (left-aligned, Center Align, right-aligned). |
| [**Funnel**](/yida/report/hd3q1n) | Provides an intuitive view of the conversion level of each business stage. In a sense, Funnel is a specialized application of path analysis, primarily focused on conversion analysis of critical paths. |
| [**Word cloud**](/yida/report/gtyrhp) | Generates a word cloud chart from form data. |
| [**Radar**](/yida/report/grr9lt) | A graphical method that displays multivariate data in the form of a two-dimensional chart, representing three or more quantitative variables on axes starting from the same point. |
| [**Calendar heatmap**](/yida/report/lyedo6) | Displays progress across different times on a Calendar and adjusts colors based on values. **Suitable for reviewing scenarios such as code volume or work activity over a time period.** |
| [**Map of China**](/yida/report/plcwtt) | An administrative map component that supports province, city, and county levels of the Map of China, along with drill-down and roll-up between these levels. |
| [**Basic table**](/yida/report/stqur9) | Displays submitted form data in an Excel-style Spreadsheet. |
| [**Cross pivot table**](/yida/report/osbbht) | One of the most commonly used visualizations in daily analysis, similar to Excel. YiDA provides multi-level pivoting, metric calculation, totals and subtotals, quick filtering, and other capabilities. Convenient actions such as clicking a metric to reveal detailed data are also available to explore. |
| [**Basic metrics card**](/yida/report/vn761o) | Configure Metrics and icons to display key metric values and icons, with drill-down supported via icon clicks. |
| [**Text**](/yida/report/hu9aqr) | Used to display basic Text information. |
| [**Image**](/yida/report/pyrhm5) | Used to display Image information. |
| [**Link**](/yida/report/tst3xa) | Used to Redirect To a URL and freely combine parameters. |
| [**Container**](/yida/report/qhbihp) | Primarily used for Layout, and can be combined with other components. |
| [**Column split**](/yida/report/xvx3lt) | Primarily used for Layout, and can be combined with other components. |
| [**Tabs**](/yida/report/pux8db) | Two common styles are standard and capsule. Primarily used for Layout, and can be combined with other components. |
| [**Time Filter**](/yida/report/hbqowi) | Supports both **single value** and **range** settings for filtering. |
| [**Dropdown filter**](/yida/report/is9r5k) | Supports **Select** and **Multiselect** settings, with fuzzy Search in the input box. You can configure the Show field to distinguish between the field displayed to the User and the field actually queried (for example, display the Department name while querying by the Department code).<br />Also supports **Tag** mode for Tag-based filtering. |
| [**iFrame**](/yida/report/cs2lgv) | Embeds content from other web pages into the current designer Page. |
