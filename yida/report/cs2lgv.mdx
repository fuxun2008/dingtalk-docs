## 1. Introduction

Embed content from other web pages into your current designer page. The following example embeds the URL of the DingTalk YiDA help document.

## 2. Steps

### 2.1 Select the Component

Open the report, then from the top menu select Others >> iFrame and drag it into the page.

<Frame>
  ![](https://gw.alicdn.com/imgextra/i1/O1CN01ZtgiAIIGmpD3gr3L_!!6000000000935-2-tps-1818-905.png)
</Frame>

Add the component.

### 2.2 Attribute Settings

#### 2.2.1 iFrame URL

Click the iFrame component. In the right-side attribute panel, locate iFrame URL and enter the YiDA official website URL.

  ![](https://gw.alicdn.com/imgextra/i2/O1CN01Ora02nIliOL3g6E3_!!6000000003500-2-tps-1812-907.png)
