## 1. Overview

### 1.1 Use cases

The column chart visually presents data volumes and enables comparison, clearly showing the proportional differences between data points.

### 1.2 Features

Use vertical or horizontal bars to display **numerical comparisons across categories**.

One axis represents the **category dimension to be compared**, and the other represents the corresponding **numerical value**.

Chart types include standard column, bar, and stacked (standard stacked and percent stacked).

Linkage effect for the same category. For usage, see [Linkage area](/yida/report/xybfun).

Highlight: control the component size and freely move the component position (left, center, or right).

### 1.3 Basic requirements

| **X-Axis** | **Y-Axis** | **Group** | **Reference line** |
|---|---|---|---|
| Up to 1 field | Multiple fields supported, up to 30 | Up to 1 field | Multiple fields supported, up to 30 |

## 2. Steps

### 2.1 Select the component and configure the dataset

Select a dataset.

### 2.2 Select the fields to display in the chart

Drag the fields on the right onto **X-Axis**, **Y-Axis**, **Group**, or **Reference line**.

- X-Axis: displays the X-axis of the column chart.
- Y-Axis: displays the Y-axis of the column chart.
- Series group: when the Y-axis contains a single value, series grouping is supported; when the Y-axis contains multiple values, grouping is not supported.
- Reference line: multiple lines are supported.
- Conditional filtering: supported.

Multiple values on the Y-axis.

**You can select fields directly from the dataset or generate them through a formula. For details, see** [**Report formulas**](/yida/form/yrofmw).

Select data.

### 2.3 Configure data

See the data configuration for the column-line combination chart.

This is a Yuque content card. Click the link to view: [Column-line combination chart](/yida/report/wfno1e).

### 2.4 Style settings

The settings are divided into seven categories: style, X-axis, Y-axis, legend, label, mini axis, and tooltip.

Style settings.

#### 2.4.1 Style settings

Adjust the color, thickness, and width of the columns, stacking and grouping, spacing, and bar chart layout.

Custom colors accept English color names or hexadecimal values, such as #5894FF. Separate multiple values with commas.

Note: color settings only take effect when the Y-axis contains multiple fields. See the image above for the display effect.
