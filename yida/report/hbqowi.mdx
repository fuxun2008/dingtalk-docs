### 2.4 Configure the Style

<Frame>
  ![](https://gw.alicdn.com/imgextra/i4/O1CN01UvNUAAT7SnK3tRYo_!!6000000000133-2-tps-1918-1076.png)
</Frame>

Style settings.

**Required**: When turned on, this Date filter becomes a required field.

**Range**: When turned on, users can select a start date and an end date.

**Title**

- [Show title]: A toggle switch. On by default. When turned off, all title-related settings below are also hidden.
- [Title name]: The title name of the filter.

- [Title tip]: When users hover over the title, an exclamation mark icon appears to display the tip.
- [Title location]: Top, Left, or Inside. Top by default.

<Frame>
  ![](https://gw.alicdn.com/imgextra/i1/O1CN01A6T0mEsrevH3gbRa_!!6000000000995-2-tps-1816-906.png)
</Frame>

Component title.

**Content:**

- Input placeholder: The placeholder text inside the input box.

**Overall style**:

- [Style]: Normal, Hidden, Disabled, or Read-only.
- [Maximum width]: 446 by default. The filter width adjusts automatically to the page size to improve user experience, but never exceeds the maximum width.

- [Overall size]: Medium by default. You can also select Small or Large.
- [Clear button]: Enable a one-click clear button (an X button) that appears next to the input box.
