## 1. Overview

### 1.1 Feature overview

A Funnel chart measures business performance across key stages by illustrating each stage of a business process. It offers an intuitive view of the conversion rate at each stage. In a sense, a Funnel chart is a specialized application of path analysis, focused on conversion analysis for critical paths.

Take a Taobao purchase as an example. Buying an item on Taobao involves the following stages:

Browse → Add to cart → Pay → Receive → Review

Highlights: You can freely adjust the component size and move the component position (left-aligned, center-aligned, or right-aligned).
