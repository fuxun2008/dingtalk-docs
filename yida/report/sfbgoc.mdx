## 1. Introduction

### 1.1 Feature overview

On a heatmap, set the **X-Axis**, **Y-Axis**, and **Numerical** value, then apply colors through conditional styles based on the X-axis, Y-axis, and numerical value.

Highlights: Freely control component size and move the component to any position (left-aligned, center-aligned, or right-aligned).

### 1.2 Basic requirements

The basic requirements for a heatmap are as follows:

| **X-Axis** | **Y-Axis** | **Numerical** |
|---|---|---|
| 1 field | 1 field | 1 field |

## 2. Procedure

### 2.1 Select a component and configure the dataset

Select a dataset.

#### 2.2 Select fields to display on the chart

Drag fields from the right panel onto **X-Axis**, **Y-Axis**, and **Numerical**.

**You can either select fields directly from the dataset or generate them with a formula. For details on using formulas, see** [Report formulas](/yida/form/yrofmw).

Select data.

### 2.2 Style settings

Style settings.

#### 2.2.1 X-Axis

- Axis display: Show or hide the axis.
- Title: Show or hide the axis title. Off by default. When turned on, enter a title to display. If no title is entered, the field name is used.

Configure the X-axis.

#### 2.2.2 Label

Configure axis label settings, including color, size, and rotation angle.

- Rotation angle (auto position): Set the rotation angle of axis labels. Enable auto position to rotate labels automatically based on the page layout (recommended).
- Auto sparse: Automatically adjust the spacing between axis labels. Recommended.

Label configuration.
