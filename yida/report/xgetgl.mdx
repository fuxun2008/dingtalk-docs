## 1. Introduction

### 1.1 Feature overview

Use the Dashboard to set a **Primary metric** and **Auxiliary metrics**, freely configure colors for different scale intervals, and add tips to both primary and auxiliary metrics.

Highlights: Freely control the component size and move it anywhere (left-aligned, center-aligned, or right-aligned).

### 1.2 Basic requirements

The basic requirements for the Dashboard are as follows:

| **Primary metric (Required)** | **Auxiliary metric (Optional)** |
|---|---|
| Up to 1 field | Multiselect fields, up to 30 fields |

### 2.4 Style settings

#### 2.4.1 Color interval

- Single color: Uses only one color.
- Color interval: The dashboard scale color is determined by the value on the dashboard, as shown below:

Color interval.

#### 2.4.2 Scale: Configure the dashboard scale

- Minimum: The minimum value of the scale interval.
- Maximum: The maximum value of the scale interval.
- Interval: The spacing between two scale marks.

Configure the scale.

#### 2.4.3 Auxiliary metric settings

- On: Whether to display the auxiliary metric.
- Show comparison: Compares the auxiliary metric with the primary metric. Red indicates an increase; green indicates a decrease.
- Display position: Shows the metric at the bottom or in the middle.

Configure the auxiliary metric.

#### 2.4.4 Style configuration: Configure the dashboard appearance

- Rounded shape: A rounded shape for the color area.

- Show pointer: Whether to display the pointer on the dashboard.
- Bar thickness: The thickness of the color bar.
- Relative radius: The size of the color area ring.
- Relative inner radius: The size of the scale ring.

Style configuration.
