## 1. Introduction

Spreadsheet sorting follows the order of fields, so you can select a reference field for each field.

## 2. Procedure

Path: Report page >> Select a field column >> Edit button next to the field >> Data settings panel >> Sort

## 3. Reference Field

Choose ascending or descending order to set the reference field.

As shown below, although the product name is the first field, you can sort by created time so that created time takes the highest sort priority.
