## Introduction

Time offset is a capability built on rollup field types that displays data from different points in time. Use it to compare data across different periods.

<Note>
A report with time offset enabled can query up to 10,000 records at a time.
</Note>

## Settings panel

The Time offset tab in the Data settings panel provides the following options:

Time offset: Turn time offset on or off.

Time dimension: The granularity of the time offset.

Offset value: The offset value varies by time dimension and can be customized.
