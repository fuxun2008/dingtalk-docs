## 1. Overview

### 1.1 Feature Overview

Use this component to redirect users to a URL and freely combine parameters.

Highlights: You can control the component size, but you cannot change the link alignment (left, center, or right).

  ![](https://gw.alicdn.com/imgextra/i3/O1CN01Wf9v7kb0ITF3gjFK_!!6000000000847-2-tps-1817-897.png)

### 1.2 Use Cases

On a product data display page, configure a link that redirects users to the product details page when they want to view more information.
