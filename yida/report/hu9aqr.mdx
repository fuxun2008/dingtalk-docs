## 1. Overview

### 1.1 Feature Overview

Use the Text component to display basic text information.

Highlights: You can control the size of the component, but you cannot adjust its alignment (left, center, or right).

### 1.2 Use Cases

For example, when ranking students by exam scores, use the Text component to analyze the reasons behind lower-performing students and outline follow-up improvement plans.
