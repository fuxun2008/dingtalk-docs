## 1. Introduction

### 1.1 Feature overview

Forms are the foundational tool in Yida. All data collection and reporting rely on forms, which serve as the primary source of data. **Regular form**: collects all data generated during business operations. You can also share the collected data through permission-based collaboration by [publishing](/yida/form/ulqab1) Data Permissions to users who need to manage the data, or to external users for external data collection.

## 2. Entry point

**Entry point: Edit App > Page Management > ➕ > Create regular form.**

You can create a form in five ways: from a template, as a smart form, from a blank page, by importing an Excel file, or by syncing from DingTalk Base.

## 3. Create a regular form

### 3.1 Create a smart form

Click **Create smart form**, then enter a prompt in AI Assistant, such as "Create a Feedback Form with fields for satisfaction, rating, and feedback comments." Once the prompt is submitted, AI automatically generates the corresponding form.

### 3.2 Create a blank page

- Click **Create blank page** to open the blank page form designer.

### 3.3 Import an Excel file to create a page

1. Click **Import Excel to create page**.
2. Select an Excel file from your local device, preview the data, configure the form (select the Data type), and then import the data.
3. After the import succeeds, you are redirected to the new form page.

### 3.4 Sync from DingTalk Base or DingTalk OA Approval form to a Yida regular form

The following example uses DingTalk Base:

1. Click **Sync from DingTalk Base to form** and configure the Sync settings.

2. A dialog box displays the sync steps. First, select a dataset, and then configure the target form and fields.
3. To create a new Yida dataset, configure the base and the specific Table within it.

<Note>
**Available bases:**

- 1. Bases in the Organization Knowledge Base for which the current user has management permissions.
- 2. Bases created by the current user in My Docs.
</Note>

4. To use an existing Yida dataset, see **Create a dataset from the DingTalk Data Asset Platform** for detailed steps.

<Warning>
**Note: A dataset that is already in use by another form cannot be selected here.**
</Warning>

[**View the detailed documentation.**](https://www.yuque.com/yida/updates/im5pr57rmgfn7a56#nAxlM)

### 3.5 Create from a template

- In the template List, select a template and click **Use**.
