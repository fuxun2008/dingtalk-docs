## 1. Introduction

### 1.1 Feature overview

Forms are the foundational tool in Yida, and all data entry and collection rely on them. As a result, forms also serve as the source of data. **Workflow form**: enables data to flow upward level by level for tiered approval. You can also assign permissions to further manage workflow data.

## 2. Entry point

**Entry point: Edit app > Page management > ➕ > Create workflow form.**

Five creation methods are available: create from template, create smart form, create blank page, create page by importing Excel, and sync from DingTalk Base to form.

## 3. Create a regular form

### 3.1 Create a smart form

Click **Create smart form**, then enter a prompt in the AI Assistant, such as "Build a 'Vehicle request' workflow form containing request ID, request date, requested vehicle type, requester, and request reason." Based on the prompt, the AI automatically creates the corresponding form.

### 3.2 Create a blank page

- Click **Create blank page** to open a blank page in the form designer.

### 3.3 Create a page by importing Excel

1. Click **Create page by importing Excel**.
2. Select the Excel file (local Excel) > Preview data > Form settings (select data type) > Import data.
3. Once the import succeeds, you are redirected to the new form page.

### 3.4 Sync from DingTalk Base to form

1. Click **Sync from DingTalk Base to form** and configure the sync settings.

2. The popup displays the sync steps: first select a dataset, then configure the sync form and fields.
3. To create a new Yida dataset, configure the base and the specific table within it.

<Note>
**Available bases:**

- 1. Bases within the Organization Knowledge Base for which the current user has management permissions.
- 2. Bases created by the current user in My Docs.
</Note>

4. To select an existing Yida dataset, see **Create a dataset from the DingTalk Data Asset Platform** for detailed steps.

<Warning>
**Note: A dataset already used by a form cannot be selected here.**
</Warning>

[**View the detailed documentation.**](https://www.yuque.com/yida/updates/im5pr57rmgfn7a56#nAxlM)

### 3.5 Create from a template

- In the template list, select a template and click **Use**.
