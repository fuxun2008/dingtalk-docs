- Before using this connector, create a custom DingTalk Bot. For instructions, see: Build a custom single-chat bot for your organization.
- To find the bot's App Key, go to DingTalk Open Platform > App Development > In-house Development > Bots > your bot > App Key.
</Warning>

## 1. Use Case

The YiDA Bot connector integrates data with a custom bot built by your organization. After a form is submitted, the bot sends a message to employees automatically, supporting the digital transformation of your organization.

## 2. Procedure

### 2.1 Step 1: Design the Form

Create a form and add the fields required for the message notification.

**Steps:**

1. Create a form and name it "Bot message notification entry".
2. Add a member component, name it "Recipient", enable Multiselect mode, and mark it as Required. (See Figure 2.1-1.)

Figure 2.1-1 Add and configure the member component

3. Add a Single-line text component, name it "Bot App Key", and mark it as Required. (See Figure 2.1-5.)

Figure 2.1-2 Add and configure the Single-line text component

4. Add a Multi-line text component, name it "Message content", and mark it as Required. (See Figure 2.1-6.)

Figure 2.1-3 Add and configure the Multi-line text component

5. Click Save in the upper-right corner of the page.

### 2.2 Step 2: Configure the Connector

<Note>
For a full introduction to YiDA connectors, see: [Integration & Automation - Connector](https://docs.aliwork.com/docs/yida_support/zevvr1).
</Note>

Add and configure a connector for the "Bot message notification entry" form to integrate the YiDA form with the DingTalk announcement app.

**Steps:**

1. Go to the admin console > "Bot message notification entry" form > Integration & Automation > Create Integration & Automation. (See Figure 2.2-1.)

Figure 2.2-1 Connector entry point

2. Name the connector "Bot notification", set the Trigger type to Form event trigger, and click Save. (See Figure 2.2-2.)

Figure 2.2-2 Create the connector

3. Configure the form event trigger: set the trigger event to Create succeeded and the data filter to All data, then click Save. (See Figure 2.2-3.)

Figure 2.2-3 Configure the form event trigger

4. Select the connector app: choose the "Bots" app and click Next. (See Figure 2.2-4.)

Figure 2.2-4 Select the connector app

5. Select the connector action: choose the "Bot notification" action and click Next. (See Figure 2.2-5.)

Figure 2.2-5 Select the connector action

6. Configure the connector action and click Save. (See Figure 2.2-6.)

Figure 2.2-6 Configure the connector action

7. Click Save in the upper-right corner of the page, then click Publish.

### 2.3 Step 3: Submit the Form

Submit data through the "Bot message notification entry" form to trigger the connector. (See Figure 2.3-1.)
