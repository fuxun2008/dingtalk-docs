Manual nodes in integration & automation differ from those in an approval process. In integration & automation, manual nodes are used primarily to start approvals—that is, to submit a workflow form on behalf of another user. As a result, the manual node in integration & automation contains only the Start approval node. This article describes how to configure it.

## Prerequisites

Before you start an approval through integration & automation, create a workflow form and complete the approval process configuration. For more information, see workflow design.

## Procedure

1. Sign in to the YiDA console and click **My apps**.
2. Select the target app to open the **App settings** page.
3. Click **Integration & Automation**, select the integration & automation flow you created, and click **Edit**.

4. Move the cursor to the connection line at the approval node. When the **+** button appears, click it and select the **Start approval** node.
5. Set the values of the Fields to be filled in the workflow form, and specify the **Process initiator**.

6. When the configuration is complete, click **Save**.
