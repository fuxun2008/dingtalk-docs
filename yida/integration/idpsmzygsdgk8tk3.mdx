Time-Based Triggers work with existing node types to handle scenarios such as scheduled message delivery, scheduled data updates, and scheduled approval submissions. This article describes the rules for time-based triggers and explains how to configure them.

## Steps

Follow these steps to create an integration & automation with a time-based trigger.

1. Sign in to the Yida workbench and click **My Apps**.
2. Select the app for which you want to create an integration & automation to open the **App settings** page.
3. Click **Integration & Automation**, then select **Create Integration & Automation** > **Create from blank**.

<Steps>
  <Step title="In the dialog box, enter a name for the integration & automation, select Time-Based Triggers as the trigger event, and click Confirm.">
  </Step>
  <Step title="On the integration & automation editor page, click Time-Based Triggers. In the dialog box, configure the Start time, Repeat rule, and End time.">
  </Step>
  <Step title="Click Save when configuration is complete.">
  </Step>
</Steps>

## Repeat rules

Integration & automation supports the following repeat rules:

- Trigger once only.
- Fixed repeat rule.
- Repeat rule based on the first trigger time of the automation.
- Custom repeat rule: when the repeat rule is set to **Custom**, use **Preview trigger time** to verify whether the custom rule is correct.

<Note>
Preview trigger time shows only the next 5 trigger times.
</Note>

## End time

The following two end rules are supported:

- **Trigger count**: the total number of times the integration & automation runs. This is unrelated to the number of nodes in the trigger flow or the recipients and groups being notified.
- **Specified time**: regardless of the repeat rule, the integration & automation stops triggering once the current time reaches the specified end time.
