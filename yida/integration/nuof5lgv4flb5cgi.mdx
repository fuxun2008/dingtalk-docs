The Create Data node is a core feature of Integration & Automation. It performs different execution actions on the data generated by an app. This article explains what a Create Data node is.

## Procedure

1. Sign in to the YiDA workbench and click **My Apps**.
2. Select the app you want and open the **App Settings** page.
3. Click **Integration & Automation**, select an existing integration & automation flow, and click **Edit**.

4. Move the cursor to the connector line of the Approval node. When the **+** button appears, click it and select the **Create Data** node.

When a form event or app event is triggered, you can create one or more records in the target table. Two creation methods are currently supported: **Create in form** and **Create in sub-table**.

<Frame>
  ![](https://gw.alicdn.com/imgextra/i1/O1CN014nsi3vAa2WD3LCbW_!!6000000003285-2-tps-1646-704.png)
</Frame>

5. Select a creation method.

<Frame>
  ![](https://gw.alicdn.com/imgextra/i4/O1CN0128VY7plILZD3Xuvm_!!6000000002766-2-tps-1747-931.png)

After you select a creation method and a target table, options for creating a single record or multiple records and field settings appear. **Create a single record** is selected by default. To create multiple records, switch the option manually.
