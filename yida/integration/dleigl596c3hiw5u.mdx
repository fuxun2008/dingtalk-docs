## 1. Use Case

As one of DingTalk's collaborative office products, DingTalk Drive is the foundation for organization file management and helps teams handle files more efficiently. Use this connector to **create an organization shared space** in DingTalk Drive.

## 2. Procedure

### 2.1 Step 1: Design the Form

Create a regular form to capture the data required by the DingTalk Drive connector.

**Procedure:**

1. Create a regular form and name it "Create space".
2. Add a Single-line text component, name it "Space name", and set it as Required.

<Frame>
  ![](https://gw.alicdn.com/imgextra/i4/O1CN01uBN10QmIkoF3th8a_!!6000000003790-2-tps-1920-952.png)
</Frame>

Figure 2.1-1 Adding and configuring the Single-line text component

3. Add a member component, name it "Space owner", and set it as Required.

<Frame>
  ![](https://gw.alicdn.com/imgextra/i2/O1CN0161OVZmFaGjJ3th8Z_!!6000000005482-2-tps-1920-951.png)
</Frame>

Figure 2.1-2 Adding and configuring the member component

4. Click Save in the top-right corner of the page.

### 2.2 Step 2: Configure the Connector

For a detailed introduction to YiDA connectors, see [Introduction to Integration & Automation](/yida/integration/gqmveiswrxkgxu9s).

Create and configure a connector to integrate data between the YiDA app and DingTalk Drive.

**Procedure:**

<Frame>
  ![](https://gw.alicdn.com/imgextra/i3/O1CN01pC8aLrBCv0E3th8Z_!!6000000002861-2-tps-1920-951.png)
</Frame>

1. On the admin page, go to the "Create space" form > Integration & Automation > Create Integration & Automation.

Figure 2.2-1 Connector entry point

<Frame>
  ![](https://gw.alicdn.com/imgextra/i1/O1CN01jYTWDXg9inG3th8Y_!!6000000004260-2-tps-1920-950.png)
</Frame>

2. Name the connector "Create space", set Trigger type to Form event trigger, and click Save.

Figure 2.2-2 Creating a connector

3. Configure the form event trigger: set the trigger event to Create success, set data filtering to All data, and click Save.

<Frame>
  ![](https://gw.alicdn.com/imgextra/i4/O1CN01abKrl94L8eE3th8a_!!6000000004757-2-tps-1920-952.png)
</Frame>

Figure 2.2-3 Configuring the form event trigger

4. Select the connector app: choose the DingTalk Drive app and click Next.

<Frame>
  ![](https://gw.alicdn.com/imgextra/i1/O1CN01w7IGucz0DoG3th8X_!!6000000005789-2-tps-1920-949.png)
</Frame>

Figure 2.2-4 Selecting the connector app

5. Select the connector action: choose the Create space action and click Next.

<Frame>
  ![](https://gw.alicdn.com/imgextra/i1/O1CN01hj7dHPlaHiL3th8Z_!!6000000005223-2-tps-1920-951.png)
</Frame>

Figure 2.2-5 Selecting the connector action

6. Configure the connector action and click Save.

<Frame>
  ![](https://gw.alicdn.com/imgextra/i2/O1CN01M73u4MwVMwK3th8Z_!!6000000002046-2-tps-1920-951.png)
</Frame>

Figure 2.2-6 Configuring the connector action

7. Click Save in the top-right corner of the page, then click Publish.

### 2.3 Step 3: Submit the Form

Fill in and submit the "Create space" form to trigger the connector and create the space in DingTalk Drive.
