This topic describes how to configure error message notification rules and where to view the resulting notifications for YiDA integration & automation flows.

<Warning>
**Supported scope:**

- Up to 720 error messages per day per organization.
- Up to 30 error messages per hour per organization.
- Basic edition (Standard edition) apps can enable monitoring for 10 integration & automation flows.
- Professional edition (Premium edition) apps can enable monitoring for 30 integration & automation flows.
- Dedicated edition apps can enable monitoring for 50 integration & automation flows.
- Not supported on the Free plan of YiDA.
</Warning>

| **Steps** | **Description** |
|---|---|
| **Configuration** | Configure error message notification rules for integration & automation:<br />• Notification recipients<br />• Do Not Disturb duration: within the set period, duplicate error messages are suppressed for the same error node in the same integration & automation flow<br />• Integration & automation flows with error notifications enabled |
| **Notification** | • When a flow with notifications enabled encounters an error, an error notification is sent to the configured recipients<br />• Click Details to go directly to the integration & automation operations log page in the admin console |
