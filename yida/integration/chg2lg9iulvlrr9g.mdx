An app event trigger uses official DingTalk events, DingTalk ecosystem events, or third-party app events to trigger Integration & Automation flows. For example, an Integration & Automation flow can be triggered when a new user joins your organization. This article explains how to configure an Integration & Automation flow triggered by an app event.

<Warning>
Note: Due to data security requirements, only DingTalk organization admins can configure app event triggers.
</Warning>

## Procedure

Follow the steps below to create an Integration & Automation flow with the trigger type set to app event trigger.

1. Sign in to the YiDA workbench and click My apps.
2. Select the app for which you want to create an Integration & Automation flow, and go to the App settings page.
3. Click Integration & Automation, then select Create Integration & Automation > Create from blank.

<Steps>
  <Step title="In the dialog box, enter a name for the Integration & Automation flow, select App event trigger as the trigger event, and click Confirm.">
  </Step>
  <Step title="On the Integration & Automation editor page, click App event trigger, and then select the target app in the pop-up window.">
  </Step>
  <Step title="After the configuration is complete, click Save.">
  </Step>
</Steps>

## Configure Steps

Once the trigger type is configured, add Steps to build the flow. For details, see [Step configuration](/yida/integration/nl4abrm791inlvm2).
