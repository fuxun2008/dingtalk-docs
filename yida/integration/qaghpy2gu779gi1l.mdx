## Steps

Follow the steps below to use an official connector in Integration & Automation or a workflow form.

1. Sign in to the YiDA workbench.
2. Select the target app and go to the **Integration & Automation** page.
3. Select an existing integration & automation flow and click **Edit**.

## Supported Official Connectors

DingTalk currently provides 24 official apps. Each app offers different execution actions to achieve different results.

| **App name** | **Function** |
|---|---|
| [**To-Do tasks**](/yida/integration/vs2cqwywsanvmg3o) | Automatically create DingTalk To-Do tasks. |
| **Event** | Create an event. |
| **Chats** | Send messages to an organization group. This node must be used together with the Scenario Group node. |
| [**Scenario Group**](/yida/integration/wh85s70zssv2gnck) | Create a new scenario group. |
| [**Video Meeting (schedule)**](/yida/integration/qwlh57zqlr4e7047)<br />[**Video Meeting (start)**](/yida/integration/zx7hyx0awsq2zfb9) | Start or schedule a Video Meeting. |
| [**Attendance**](/yida/integration/te5kym9fz7u9x8dq) | Create a new scenario group. |
| [**Contacts**](/yida/integration/ncdt7p3g2db6d11n) | Update, create, or delete user information in DingTalk Contacts. |
| [**Smart HR**](/yida/integration/imnxrgek49qmqfux) | Add pre-onboarding employee information after an event is triggered. |
| [**Chat Group**](/yida/integration/iqqlaphgykttuihb) | Add or remove group members and create group chats. Only organization groups can be created; standard groups are not supported. |
| **Check-in** | Retrieve employee check-in records. |
| [**Smart Form Filling**](/yida/integration/og32nngcyadrao3k) | Retrieve user form-filling templates. |
| **App Management** | Set the visibility of an app. |
| **Log** | Retrieve the unread log count. |
| **Associated organization** | Retrieve the branch or parent organization. |
| **Data Table of contents** | Retrieve organization group chat statistics. |
| **Drive** | Create a Space. |
| **To-Do 2.0** | Create To-Do tasks. |
| **Employee Service Desk** | Send personal messages through the service assistant. |
| **AI** | Translate content between languages, such as Chinese to English. |
| [**Announcement**](/yida/portal/ik3610wn0kc5twhv) | Publish announcements. |
| **Bots** | Send messages using a specified bot. |
