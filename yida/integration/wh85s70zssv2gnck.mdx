Scenario groups are a collaboration capability unique to DingTalk. Beyond standard group chat features, they offer business-specific capabilities such as Chat Quick actions, group assistants, and group message push. In a scenario group, you can **display notifications and announcements via pinned cards, send and receive approval forms or alerts through the group message assistant, interact via message cards, and quickly open frequently used apps through Chat Quick actions**. You can now create a scenario group by submitting a YiDA form.

![](https://gw.alicdn.com/imgextra/i1/O1CN01aVvGQhSKOQH3thAe_!!6000000004902-2-tps-1920-1080.png)



## Step 1: Create and Configure the Form

Create a form to capture the relevant information. This form serves as the data source that triggers the connector.

**Steps:**

1. Create a form and name it "Create Group Chat".
2. Add a member component to the form, mark it as required, and enable multi-select.

<Frame>
  ![](https://gw.alicdn.com/imgextra/i3/O1CN01hFG8RJSfPoK3thA2_!!6000000005412-2-tps-1920-1042.png)
</Frame>

3. Add another member component, name it "Select Group Owner", and mark it as required.

4. Add a Single-line text component, name it "Event Title", and mark it as required.

<Steps>
  <Step title="Step 1">
    Add a Select component and name it "Group Chat Management Permissions". Set the option value of "Everyone can manage" to "0" and enable it as the default selection. Set the option value of "Only group owner can manage" to "1" and enable required validation.
  </Step>
  <Step title="Click the Save button in the upper-right corner">
  </Step>
</Steps>

## Step 2: Create Integration & Automation

<Note>
**Further reading**: For a detailed introduction to connectors, see [Integration & Automation - Connectors](/yida/integration/gqmveiswrxkgxu9s).
</Note>

When the form is submitted, the system automatically performs the action for the specified users, so you need to configure a connector.

**Steps:**

1. Go to the admin console >> Integration & Automation >> "Create Integration & Automation".

2. In the "Create Integration & Automation" dialog >> name the connector "Create Scenario Group" >> select "Form event trigger" as the trigger type and specify the trigger form >> click Confirm.

#### Configure the Connector

**Steps:**

1. Configure the "Connector" node. Under Select app, select "Scenario Group", then click Next.

2. Under Select action, select the "Create Scenario Group" action, then click Next.

3. Under Configure action, complete each configuration item, then click Save.

4. Click the "Save" button in the upper-right corner of the page, then click the "Publish" button.
