## 1. Use Case

This example creates a "Check-in Query Form" and a "Query Result Record" form, then uses a form connector to pull each employee's check-in status, time, and location into the result form.

## 2. Steps

### 2.1 Step 1: Create the Forms

Create two regular forms. The "Check-in Query Form" triggers the connector to run the query, and the "Query Result Record" stores the results returned by the connector for easy review.

#### 2.1.1 Create the Query Form

**Steps:**

1. Create a regular form and name it "Check-in Query Form".
2. Add two Date components named "Query Start Date" and "Query End Date". Set the format to "YYYY-MM-DD HH:mm" and mark both as required. (See Figure 2.1-1.)

<Frame>
  ![](https://gw.alicdn.com/imgextra/i2/O1CN01s0P5kr2C4TH3th8d_!!6000000000862-2-tps-1920-955.png)
</Frame>

Figure 2.1-1 Add and configure the Date components

3. Add a member component and name it "Employee to Query". Mark it as required. (See Figure 2.1-2.)

<Frame>
  ![](https://gw.alicdn.com/imgextra/i1/O1CN01J5YNeLYihbG3th8d_!!6000000007129-2-tps-1920-955.png)
</Frame>

Figure 2.1-2 Add and configure the member component

4. Click **Save** in the upper-right corner of the page.

#### 2.1.2 Create the Result Record Form

**Steps:**

1. Create a regular form and name it "Query Result Record".
2. Add four Single-line text components named "Connector Execution Status", "Check-in Status", "Check-in Time", and "Check-in Location". (See Figure 2.1-3.)

<Frame>
  ![](https://gw.alicdn.com/imgextra/i1/O1CN01BDueaLEeB5E3th8d_!!6000000000287-2-tps-1920-955.png)
</Frame>

Figure 2.1-3 Add and configure the Single-line text components

3. Click **Save** in the upper-right corner.

### 2.2 Step 2: Configure the Form Connector for the "Check-In Query Form"

<Note>
For an introduction to connectors, see [Integration & Automation - Connector](/yida/integration/gqmveiswrxkgxu9s).
</Note>

Configure the form connector on the "Check-in Query Form" to enable the check-in query feature and automatically write the results to the "Query Result Record" form.

**Steps:**

<Frame>
  ![](https://gw.alicdn.com/imgextra/i4/O1CN01mctXY6H2ZVL3th8d_!!6000000002274-2-tps-1920-955.png)
</Frame>

1. On the admin page, select the "Check-in Query Form", switch to the **Integration & Automation** tab, and click **Create Integration & Automation**. (See Figure 2.2-1.)

Figure 2.2-1 Connector entry

2. Name the connector "Check-in Query", set the trigger type to "Form event trigger", and click **Confirm**. (See Figure 2.2-2.)

<Frame>
  ![](https://gw.alicdn.com/imgextra/i2/O1CN01TKbW3zVRZCC3th8d_!!6000000006369-2-tps-1920-955.png)
</Frame>

Figure 2.2-2 Create the connector

3. Click the **Form event trigger** node. Set the trigger event to "Create success" and the data filter to "All data". (See Figure 2.2-3.)

<Frame>
  ![](https://gw.alicdn.com/imgextra/i1/O1CN01j1Wg1uGzGTB3th8d_!!6000000004138-2-tps-1920-955.png)
</Frame>

Figure 2.2-3 Configure the form event trigger

4. Click the **Connector** node, select the "Check-in" app, and click **Next**. (See Figure 2.2-4.)

<Frame>
  ![](https://gw.alicdn.com/imgextra/i3/O1CN011qGTTE1enhL3th8d_!!6000000008111-2-tps-1920-955.png)
</Frame>

Figure 2.2-4 Select the connector app

5. Set the action to "Get personal check-in record" and click **Next**. (See Figure 2.2-5.)

<Frame>
  ![](https://gw.alicdn.com/imgextra/i2/O1CN01JlFvv0fF8CB3th8d_!!6000000003734-2-tps-1920-955.png)
</Frame>

Figure 2.2-5 Select the connector action

6. Configure the action and click **Save**. (See Figure 2.2-6.)

<Frame>
  ![](https://gw.alicdn.com/imgextra/i3/O1CN01FnA3nwRa6PL3th8d_!!6000000002813-2-tps-1920-955.png)
</Frame>

Figure 2.2-6 Configure the connector action

7. Hover over the area below the **Connector** node, click **+**, and select the **Create data** node. (See Figure 2.2-7.)

<Frame>
  ![](https://gw.alicdn.com/imgextra/i3/O1CN01puBzFgiBFnG3th8d_!!6000000002946-2-tps-1920-955.png)

Figure 2.2-7 Add the "Create data" node

8. Configure the **Create data** node. For Creation method, select "Create in form" and set the form to "Query Result Record". For Data to create, select "Create a single record". Configure the field mappings and click **Save**. (See Figure 2.2-8.)
