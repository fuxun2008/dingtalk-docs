The DingTalk Dedicated connector supports the following action: Send DING message.

<Warning>
This connector will be discontinued on July 31, 2024. After that date, the YiDA platform will no longer maintain it. Existing users are not affected. For more information, see the [DingTalk Dedicated documentation](https://oa.dingtalk.io/register_new.htm?spm=ding_open_doc.document.0.0.1d82d394uGH6HK&source=50061&useMt2=1#/).
</Warning>

## Introduction

Send in-app DING messages (available only to DingTalk Dedicated customers).

## Workflow

| **Step** | **Action** |
|---|---|
| Step 1 | Confirm the version: this connector is valid only for DingTalk Dedicated. |
| Step 2 | API authorization:<br />1. In App development on the Open Platform, select or create an Internal app.<br />2. Copy the app's **clientid (also known as appkey)**.<br />3. In the accesskey field of the DingTalk Dedicated connector, enter the clientid (appkey) obtained above.<br />4. Return to App development on the Open Platform and enable DingTalk Dedicated permissions for that app. |
| Step 3 | Fill in the fields:<br />1. accesskey: clientid (appkey)<br />2. Recipient object<br />3. App type: ORG<br />4. Message content |
