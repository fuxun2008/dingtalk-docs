## 1. Use Case

This connector automates announcement publishing so admins no longer need to manually create announcements in the DingTalk admin console each time.

## 2. Steps

### 2.1 Step 1: Design the Form

Create a form and fill in the announcement content and settings.

**Steps:**

<Frame>
  ![](https://gw.alicdn.com/imgextra/i3/O1CN01FtuTITFemRH3th8Y_!!6000000005312-2-tps-1920-950.png)
</Frame>

1. Create a form named "Create Announcement".
2. Add a member component, name it "Publisher", and set it as required. (See Figure 2.1-1.)

Figure 2.1-1 Add and configure the member component

3. Add a Select dropdown component named "Send DING Notification". Add two custom options: "Display value: Yes, Option value: true" and "Display value: No, Option value: false". Set it as required. (See Figure 2.1-2.)

<Frame>
  ![](https://gw.alicdn.com/imgextra/i4/O1CN01Pqdq7MD5G1J3sghu_!!6000000006332-2-tps-1912-978.png)
</Frame>

Figure 2.1-2 Add and configure the Select dropdown component

4. Add a department component, name it "Recipient Departments", enable Multiselect mode, and set it as required. (See Figure 2.1-3.)

<Frame>
  ![](https://gw.alicdn.com/imgextra/i2/O1CN01ZYN3BGY69JB3th8X_!!6000000001092-2-tps-1920-949.png)
</Frame>

Figure 2.1-3 Add and configure the department component

5. Add a member component, name it "Recipient Users", enable Multiselect mode, and set it as required. (See Figure 2.1-4.)

<Frame>
  ![](https://gw.alicdn.com/imgextra/i4/O1CN018nHEbumNs7K3th8Y_!!6000000006571-2-tps-1920-950.png)
</Frame>

Figure 2.1-4 Add and configure the member component

6. Add a Single-line text component, name it "Announcement Title", and set it as required. (See Figure 2.1-5.)

<Frame>
  ![](https://gw.alicdn.com/imgextra/i1/O1CN01tyynTkMWuYC3th8X_!!6000000004872-2-tps-1920-949.png)
</Frame>

Figure 2.1-5 Add and configure the Single-line text component

7. Add a Multi-line text component, name it "Announcement Content", and set it as required. (See Figure 2.1-6.)

<Frame>
  ![](https://gw.alicdn.com/imgextra/i2/O1CN01YjETs0j0eRB3th8X_!!6000000000638-2-tps-1920-949.png)
</Frame>

Figure 2.1-6 Add and configure the Multi-line text component

8. Click Save in the upper-right corner of the page.

### 2.2 Step 2: Configure the Connector

<Note>
For a detailed introduction to YiDA connectors, see [Integration & Automation - Connectors](/yida/integration/gqmveiswrxkgxu9s).
</Note>

Add and configure a connector for the "Create Announcement" form to integrate the YiDA form with the DingTalk Announcement app.

**Steps:**

<Frame>
  ![](https://gw.alicdn.com/imgextra/i1/O1CN018ThcyXiR89J3th8X_!!6000000000855-2-tps-1920-949.png)
</Frame>

1. Go to the admin console >> "Create Announcement" form >> Integration & Automation >> Create Integration & Automation. (See Figure 2.2-1.)

Figure 2.2-1 Connector entry point

<Frame>
  ![](https://gw.alicdn.com/imgextra/i1/O1CN01THmEeTIbmDG3th8X_!!6000000004523-2-tps-1920-949.png)
</Frame>

2. Name the connector "Create Announcement", set Trigger type to "Form event trigger", and click Save. (See Figure 2.2-2.)

Figure 2.2-2 Create the connector

3. Configure the form event trigger: set the trigger event to Create success, set the data filter to All data, and click Save. (See Figure 2.2-3.)

<Frame>
  ![](https://gw.alicdn.com/imgextra/i3/O1CN01O7mJAxrg6JF3th8X_!!6000000006353-2-tps-1920-949.png)
</Frame>

Figure 2.2-3 Configure the form event trigger

4. Select the connector app: choose the "Announcement" app and click Next. (See Figure 2.2-4.)

<Frame>
  ![](https://gw.alicdn.com/imgextra/i2/O1CN01pcFLnlwOQIF3th8X_!!6000000006727-2-tps-1920-949.png)
</Frame>

Figure 2.2-4 Select the connector app

5. Select the connector action: choose the "Publish announcement" action and click Next. (See Figure 2.2-5.)

<Frame>
  ![](https://gw.alicdn.com/imgextra/i2/O1CN0100MrQg7LmxJ3th8Y_!!6000000000020-2-tps-1920-950.png)
</Frame>

Figure 2.2-5 Select the connector action

6. Configure the connector action and click Save. (See Figure 2.2-6.)

<Frame>
  ![](https://gw.alicdn.com/imgextra/i2/O1CN01j4MHvgCi4vJ3th8Y_!!6000000005886-2-tps-1920-950.png)
</Frame>

Figure 2.2-6 Configure the connector action

7. Click Save in the upper-right corner of the page, and then click Publish.
