In YiDA, group users who share the same function by setting up a role. Roles apply to the following scenarios: workflow approver, workflow initiator, message recipient, template printing, custom page viewer, and report viewer.

For example, an expense reimbursement requires approval from finance. When multiple finance staff are involved, create a Finance role and add the corresponding users. When configuring the approver, select the Finance role directly. This avoids adding approvers one by one, simplifies workflow steps, and saves time.

<Warning>
**Additional notes:**

- Role creation permission: any user with app creation permission can create a new role.
- Role visibility: all users can see the roles created on the platform. Once a role is created, it is visible to everyone.
- Role deletion and modification permission: only the role maintainer can delete or modify the role. Other users are not authorized to perform these actions.
</Warning>

<Note>
- DingTalk roles can only be managed and viewed by YiDA platform admins and DingTalk primary or sub admins. They are not visible to other users.
- DingTalk roles are display-only within the YiDA platform. To modify them, sign in to the DingTalk admin console.
- On the role selection page in the App Management console, you can select both DingTalk roles and YiDA roles at the same time.
</Note>

## Set the Management Scope for Role Members

1. Go to the Role management page and select YiDA roles.
2. Select the target role, then click Set management scope next to the role member you want to edit.

  ![](https://gw.alicdn.com/imgextra/i2/O1CN019PGZk8vmAmB5Io2A_!!6000000006512-2-tps-2612-1306.png)
