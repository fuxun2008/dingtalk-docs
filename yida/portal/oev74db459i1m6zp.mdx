## 1. Introduction

YiDA officially provides 9 portal scenario templates. Even business beginners can build a new portal from scratch in **3 steps: drag and drop components, configure data, and configure the subject**.

### 1.1 Feature Overview

In YiDA, the portal displays the app home page or the organization workbench. A broadcastable portal design consists of three parts: "Add components", "Set component attributes", and "Set page style attributes". By default, it adapts to both desktop and mobile.

### 1.2 Use Cases

- Organization broadcastable portals: organization operation dashboards, government affairs, enterprise customer service, and more.
- App broadcastable portals: customer management, quality inspection management, procurement management, CRM, and more.

### 2.1 Select Components

From the component library on the left, select the components that fit the current portal to display the relevant information.

<Frame>
  ![](https://gw.alicdn.com/imgextra/i1/O1CN01lcGuOGgke4E5qI9U_!!6000000004327-2-tps-2878-1638.png)
</Frame>

### 2.2 Set Component Attributes

Select an added component to configure its attributes. For example, edit the component title, add help tips, configure the page Data Source, or set the component image source and link.

<Frame>
  ![](https://gw.alicdn.com/imgextra/i4/O1CN01B6DVXDvMguB5qI9a_!!6000000005093-2-tps-2878-1644.png)
</Frame>

### 2.3 Set Page Style Attributes

Click "Page style" to configure the style attributes of the current portal, including switching the portal subject and setting the page layout — for example, adjusting the page width, changing the background image, toggling user information display, and adjusting card styles.
