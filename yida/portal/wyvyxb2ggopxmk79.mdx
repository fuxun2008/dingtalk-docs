This article describes the basic settings, permission settings, and page publishing features of the broadcastable portal in detail.

## 1 Broadcastable Portal Page Settings

### 1.1 Basic Settings

Choose whether to enable "Hide the top navigation" on the broadcastable portal page.

### 1.2 Permission Settings

Set the visibility range of the broadcastable portal. Select All users or Custom to define which users can view the page.

<Note>
You can create up to 100 permission groups for a portal page.
</Note>

## 2 Publish the Broadcastable Portal Page

### 2.1 Publish Within the Organization

Users within the organization must sign in and grant authorization to access the link.
