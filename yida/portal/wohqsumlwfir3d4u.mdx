## 1. Overview

Reference the official DingTalk Calendar directly to quickly view meeting events. **By default, data is read from the DingTalk Calendar (meetings and events).**

## **2. Entry point**

Select any app → Edit portal → DingTalk Calendar component.

## **3. Configuration steps**

Configure the following attributes to adjust the final display and behavior of the component. After adding the DingTalk Calendar to the portal, you can:

### 3.1 Adjust the title bar

Control whether to "Show title", change the "Title name", set "Help tips", and toggle the "View more" option. Once enabled, set the redirect URL for "View more".

## **4. Notes**

**Note: Only one DingTalk Calendar component can be configured per page.**
