## 1. Feature overview

Associate in-app pages or reference external links to quickly open pages in different scenarios.

## **2. Feature entry**

Select any app > Edit portal > Quick Access component

## **3. Setup steps**

Configure the following component attributes to adjust how the component behaves. After you add the Quick Access component to a portal, you can:

### 3.1 Switch component styles

Click the **Switch appearance style** button to switch component styles as needed. Seven display styles are supported.

### 3.2 Adjust the title bar

Control whether to **Show title**, change the **Title name**, set the **Help tips**, and control whether to enable **View more**. Once enabled, set the redirect URL for **View more**.

### 3.3 Configure content

Quickly create a quick access entry, or batch edit quick access entry information, including the following:

### 3.4 Set groups

When there are multiple quick access entries and you have entered their **Group** names, control whether to enable **Group**. Once enabled, select a group display style.
