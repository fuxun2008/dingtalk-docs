Unlike reports, which offer a complete analysis workflow, Data Cards let you quickly combine fragmented, scenario-based charts for use in YiDA portals. Cards also include built-in broadcasting capabilities, letting you sync data as snapshots within groups.

For an overview of Data Cards, see [Data Card](/yida/app-admin/cpkmxvpgchx339qq).

For instructions on building Data Cards, see [Card setup](/yida/app-admin/nosysc2swtkkph3p).

For instructions on deploying Data Cards, see [Card deployment](/yida/app-admin/sv1c236glf4ok4nx).
