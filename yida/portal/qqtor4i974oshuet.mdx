YiDA broadcastable portals currently provide 8 components. Different components serve different functions. Select the appropriate component in the portal designer.

## Component List

> To ensure optimal data loading and performance, we recommend no more than 20 total components per portal, with no more than 5 data cards.

| **Component name** | **Use case** |
|---|---|
| [**Data card**](/yida/portal/tax9ktxaqxxbkcft) | Quickly quote report data card content for data display and analysis, and **enable data broadcasting** as needed. **Up to 5 data cards can be configured per portal page.** |
| [**Quick entry**](/yida/portal/kb5a0gh7oq93ffgl) | Associate in-app pages or quote external links to quickly access pages in different scenarios. |
| [**To-Do metric**](/yida/portal/cnl6wehhgf0iiz4e) | Quickly view to-do metrics across different workflow statuses. **Data is read from the YiDA Task Center by default. Only 1 component of this type can be configured per page.** |
| [**To-Do list**](/yida/portal/vntvxl7vsxwfgt09) | Quickly view to-do lists across different workflow statuses. **Data is read from the YiDA Task Center by default. Only 1 component of this type can be configured per page.** |
| [**Announcement board**](/yida/portal/ik3610wn0kc5twhv) | Quickly upload text-and-image summaries to display as announcements. |
| [**News list**](/yida/portal/bd77lg07oxxuuhcg) | Upload text-and-image materials to display as a news list. |
| [**Carousel**](/yida/portal/xbn4iv7pclumwhep) | Upload multiple images with embedded links, displayed in a looping carousel. |
| [**DingTalk Event**](/yida/portal/wohqsumlwfir3d4u) | Directly quote the official DingTalk Calendar to quickly view meeting events. **Data is read from the DingTalk Calendar by default. Only 1 component of this type can be configured per page.** |

## Special Notes

The portal component library currently provides out-of-the-box high-frequency standard components. In the future, portal components will support customization to enable scenario extension and enhancement. If you have additional suggestions or requirements for portal components, submit a personalized request form.
