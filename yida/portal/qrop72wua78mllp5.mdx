## Image Size Specifications

<Note>
Configure images separately for each platform. If you upload only a PC image, the mobile image is cropped automatically from it.
</Note>

PC size specifications:

- To prevent blurry images, export at 3x resolution (5760px\*720px) and keep the file smaller than 3 MB
- Center-align the "effective content" of the background image (for example, the copy) within the header image, and keep it consistent with the page width you set (standard, medium, or extra wide)
- Alias: page width, standard = 1180px; medium = 1440px; extra wide = 1920px
