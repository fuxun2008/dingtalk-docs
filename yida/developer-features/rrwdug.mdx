## 1. Introduction

Open APIs are mainly used in the following scenarios:

1. Periodically pull data back into in-house systems for refinement or archival.
2. Integrate form submission and workflow initiation entry points into existing platforms.

If your use case matches any of the above, consider using YiDA's Open API capabilities.

Currently, YiDA has published all Open APIs on the DingTalk Open Platform, while still retaining the YiDA Open API (legacy). Calling YiDA Open APIs through the DingTalk Open Platform is the recommended approach.
