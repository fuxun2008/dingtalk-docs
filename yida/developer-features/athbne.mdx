## 1. Background

This release upgrades YiDA's existing openAPI to give YiDA developers (such as ISV service providers or YiDA users who need to call APIs) more capabilities and a smoother development experience, unlocking their full development potential.

## 2. Iteration Content List

This release covers **14 API changes across 4 modules** and **removes 11 unavailable APIs**, as follows:
