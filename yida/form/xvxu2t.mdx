## 1. Overview of activity logs

You can query records for Import, Export, modification, File download, and Print actions.

**Note: A 7-day limit applies to repeated downloads**, covering Import records, Export records, modification records, File download records, and Print records.

### 1.1 Query Export records

**Path**: Click Form/workflow form >> Data management >> Export records

To quickly locate an Export record, Filter by File name, status, operator, or modified time, as shown below:

Export records

### 1.2 Query Import records

**Path**: Click Form/workflow form >> Data management >> Import records

Similarly, to quickly locate an Import record, Filter by File name, status, operator, or modified time, as shown below:

Import records

### 1.3 Query Print records

**Path**: Click Form/workflow form >> Data management >> Print records

**Note**: Print records cannot be Filtered.

### 1.4 Query modification records

**Path**: Click Form/workflow form >> Data management >> Modification records

**Path**: Click Form/workflow form >> Data management >> File download records
