## 1. Introduction

### 1.1 Feature overview

When using component data linkage, associating data from other forms, or the associated form component for data filtering/data population, you can query form data across apps. You must first create a cross-app dataset.

**Path**: App Settings > App Data Management > Datasets > Create Dataset > Create from Cross-App. For more details, see [Create a dataset from cross-app](/yida/app-admin/btrtnt).

### 1.2 Example scenario

Most companies group contract management, project management, financial management, and procurement management into separate apps. When finance staff need to procure items, they must link the purchase requisition with the contract approval form. Without the ability to query data across apps, the purchase requisition cannot be linked to the contract form. Yida now provides the ability to retrieve and query form data across apps, which resolves this issue.

## 2. Capability overview

This applies to querying data from other forms across apps. Only joined-table data queries are supported.

### 2.1 Supported components

Cross-app form data queries currently support the following components:

- Data linkage: Single-line text, Multi-line text, Numerical, Date, Image upload, Attachment, User & Department, Radio, Dropdown radio, Checkbox, Dropdown checkbox.
- Association with data from other forms: Radio, Dropdown radio, Checkbox, Dropdown checkbox.
- Display settings/data filtering/data population: Associated form.

### 2.2 Data linkage

When using the data linkage feature on a component, both the Default value and the option type support selecting forms across apps.

### 2.3 Associate data from other forms

When Radio, Dropdown radio, Checkbox, or Dropdown checkbox components are used to associate data from other forms, you can select forms across apps.

### 2.4 Associated form

The associated form component can select cross-app forms that you have permission to access, and can be used for data filtering and data population.

### 2.5 Maximum number of cross-app forms

| **Edition** | **Maximum number of cross-app forms per app** |
|---|---|
| Free plan | Not supported. Upgrade your edition to use this feature. |
| Paid editions<br />(paid editions other than the Professional edition, such as the Basic edition and Education edition) | 50 |
| Professional edition | 100 |

### 2.6 Notes

Cross-app form data reading involves entry points such as formulas and integration & automation. For details, see [Version update on April 27, 2022 – Cross-app read/write of form data](https://docs.aliwork.com/docs/yida_support/yida_updates/mw0bmqngpgz6sxba/hldb7o).

## 3. FAQ

### 3.1 Does the Free plan support querying form data across apps?

Creating a dataset from cross-app is a paid feature, so the Free plan of Yida does not support querying form data across apps.

For more FAQs, see [Create a dataset from cross-app](/yida/app-admin/btrtnt).
