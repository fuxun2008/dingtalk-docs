Use business association rules when data across two forms needs to be linked. For example, in inventory management, both inbound and outbound records must roll up to a final inventory table for viewing.

## Overview

Advanced formulas maintain the data relationship between two forms. They are mainly used on form and workflow pages to control how data is added to, deleted from, or updated in another form when the current form is submitted.

Four advanced formulas are currently available: `INSERT`, `UPDATE`, `UPSERT`, and `DELETE`.

- INSERT

Inserts a record into the target form ([INSERT](/yida/form/yhdw79)).

- UPDATE

Finds the specified instance data by condition. If a match is found, updates the values of the specified fields in that instance ([UPDATE](/yida/form/svrgxm)).

- UPSERT

Finds the specified instance data by condition. If a match is found, updates the values of the specified fields; otherwise, inserts a new instance. Equivalent to UPDATE + INSERT ([UPSERT](/yida/form/al3gkc)).

- DELETE

Deletes the matching data by condition ([DELETE](/yida/form/fqtnhh)).

Advanced formulas support the following components:

- Components that can serve as filter conditions: Single-line text, Multi-line text, Select, Dropdown select, Date, and User.
- Components that can be assigned values: Single-line text, Multi-line text, Numerical, Select, Dropdown select, Checkbox, Dropdown checkbox, Cascading select, Date, Date range, Image upload, Attachment, User, Address, Department, and Associated form.

**Note: Placing a Department component in a subform for value assignment is not supported.**
