## Component Overview

Common fields are the most basic and frequently used components for configuring forms. They include:

- Single-line text
- Multi-line text
- Select
- Checkbox
- Numerical
- Rating
- Dropdown Select
- Dropdown Checkbox
- Cascading Select
- Date
- Date range
- Image Upload
- Attachment
- User
- Subform
