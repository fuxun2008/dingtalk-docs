## 1. Use Cases

Image Upload lets you attach image-based supporting materials required by the current form submission, such as ID cards or reimbursement invoices.

### 2.5 Multiselect

When Multiselect is off, you can upload only one image at a time. When it is on, you can upload multiple images at once.

**Note**: When Multiselect is enabled, you also need to enable the maximum number of upload files setting below.

### 2.6 Upload Image Type

Customize the file types allowed for image upload. The system default is "image/\*", which allows all image formats.

**Note: When the upload type is set to Drag, the image format is not restricted.**

## 3. FAQ

- Q: How can I restrict image upload to real-time photo capture only?

A: Enable "Allow photo capture only" on the Image component.

<Frame>
  ![](https://gw.alicdn.com/imgextra/i1/O1CN01ODmsK0HuWpJ3hESX_!!6000000003195-2-tps-1821-876.png)
</Frame>

- Q: Why are thumbnails not shown for some images?

A: Thumbnails are not displayed for images larger than 20 MB.
