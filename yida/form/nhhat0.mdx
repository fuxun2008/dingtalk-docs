## 1. What Is a Data Management Page

A data management page aggregates and displays data from a form or workflow form.

## 2. How to Create a Data Management Page

**Path**: Open the target form or workflow form, then click **Generate data management page** in the upper-right corner. See the example below.

  ![](https://gw.alicdn.com/imgextra/i1/O1CN01fvo1Fc9FUpI3ro3J_!!6000000004457-2-tps-1905-892.png)

Create a data management page.

### 2.1 Data Display

The data list shows all fields by default. To customize the visible columns, click **Settings** in the upper-right corner of the list. Select the checkboxes for the columns you want to show, and **drag them up or down to reorder**.

<Frame>
  ![](https://gw.alicdn.com/imgextra/i4/O1CN01GwBVTGIa71I5p20W_!!6000000004917-2-tps-2868-1260.png)
</Frame>

Set the Show fields.

### 2.2 Data Actions

The data management page offers a rich set of features. Available actions may differ slightly between forms and workflow forms.

The example below shows the data management page of a form. It provides many practical features, such as Create, batch export, batch import, batch edit, batch print, and file download. For each submitted record, you can also perform individual actions: view details, delete, and view run logs.

## 3. Page Permissions Settings

### 3.1 How to Set Page Permissions

The Page permissions setting on the data management page controls who can view the page. As shown in the example, when the page is visible to all users, everyone can see it.

<Frame>
  ![](https://gw.alicdn.com/imgextra/i4/O1CN01u32GWvfz4LC5q2No_!!6000000000635-2-tps-2876-1024.png)
</Frame>

Set the page to be visible to all.

However, to display only the data submitted by the current user on this page, you must configure it in the source form, as shown below.

<Frame>
  ![](https://gw.alicdn.com/imgextra/i4/O1CN01bV72CuGDFoE5nWOU_!!6000000005220-2-tps-2856-1422.png)
</Frame>

Configure the form page data scope to Submitted by current user.

The final result:

<Frame>
  ![](https://gw.alicdn.com/imgextra/i3/O1CN01GqpaJDozQYH3GIH5_!!6000000005921-2-tps-1607-900.png)

### 3.2 What Page Permissions Mean

The Page permissions settings control access to the current page, that is, whether a user can open it.

**Note**: If no permissions are configured, any user with the Share link can access the page. To open the page only to specific users, configure the allowed viewers separately.
