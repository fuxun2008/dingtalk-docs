## 1. Use Cases

Use the Rating component to evaluate items such as task completion or personal performance. It is commonly used in surveys and similar scenarios.

<Note>
For component attributes, usage, and examples, see the [**Rating component reference**](/open/yida/components/form/rateField).
</Note>

## 2. Basic Features

### 2.1 Total Score

The total score defines the rating cap, with each point represented by a star. Set the upper limit to a value such as 5 or 10.

### 2.2 Half-Star Rating

Enable half-star ratings for more precise evaluations.

Note: Half-star ratings are currently supported only on desktop. **Mobile does not support half-star ratings.**
