The following sections describe how default View settings are configured in Admin mode and how temporary adjustments work in View mode.

### Admin Mode

In the app admin console, Admins Configure filters, column display and order, row sorting rules, row height, and other settings, then click **Save** to provide the default View configuration for View mode.

Grid Views support four row-height styles: Low, Medium, High, and Extra high. Configure the row height for each View.

### View Mode

Based on the Admin's default configuration, users in View mode can make temporary changes to filters, column display and order, row sorting rules, row height, and other settings. Temporary changes can be saved, and the latest View-mode configuration is displayed when the user returns.

<Warning>
After an **app visitor** refreshes the page, the current form order is preserved. To restore the default settings (that is, the order defined by the app editor), open the browser and clear the cache. The steps below use Chrome as an example.
