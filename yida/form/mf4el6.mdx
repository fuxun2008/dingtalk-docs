## 1. Use cases

The school selector component is designed for K12 scenarios that require school selection, and is most commonly used in applications for education bureaus.

## 2. Basic features

**Form edit mode:**

| **Form edit mode** | **Form runtime mode** |
|---|---|

- If an education Organization has linked its subordinate schools through Organization association, this component lets users Select from the associated schools. If the education bureau has categorized the associated subordinate schools through the bureau-school management app, the component displays the school list by category.
- If an education Organization has not linked any subordinate schools through Organization association, the component can only Select the current school.

## 3. Attributes

### 3.1 Clear button

### 3.2 Multiselect mode

- Select mode is enabled by default. To Select multiple schools, turn on Multiselect mode. When only one school needs to be selected, turn this button off.

## 4. Data source

If the current Organization has linked subordinate schools, all associated schools can be selected. If the Organization has categorized the associated schools, schools are displayed by category. If the current Organization has not linked any subordinate schools, only the current Organization can be selected.

## 5. Selection scope

| **Organization type** | **Selection scope** |
|---|---|
| Associated Organization | Multiple schools can be selected |
| Non-associated Organization | Cannot select other schools |
