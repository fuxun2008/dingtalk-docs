## 1. Use Cases

This section describes typical use cases where the Academic Year component simplifies school selection for education bureau administrators, such as selecting a student's enrollment academic year during enrollment registration or student profile creation.

## 2. Basic Features

### 2.1 Multiselect Mode

Users can select multiple academic years. To allow only a single academic year, turn off this button.

| **Form design view** | **Form runtime view** |
|---|---|

- If an education organization is linked to subordinate schools through Organization Association, this component allows you to select those associated schools. If the education bureau has categorized its associated subordinate schools through the bureau-school management app, this component displays the school list by category.
- If an education organization has no subordinate schools linked through Organization Association, this component only allows selection of the current school.

**Note: The Semester component does not support data auto-fill.**

## 3. Data Source

This component uses unified academic year master data from the education industry. The data source is preset by the system and does not support custom configuration.
