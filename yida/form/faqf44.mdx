## 1. What Is a Data Management Page

The data management page provides an aggregated overview that makes it easy to review form submission data.

## 2. Use Cases

To check how many entries have been submitted by all employees across your organization, go directly to the data management page.

## 3. Steps

**Path**: Form >> Generate data management page in the top-right corner >> Name the data management page >> Confirm

Create the data management page

Name the data management page

View the data management page

## 4. Hide the Form Page in the Navigation

When generating the data management page, you can select the option to hide the original form page in the navigation. Once selected, the original form is hidden on the PC side.
