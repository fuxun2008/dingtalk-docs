## 1. Introduction to the Group Component

### 1.1 What Is Group

Group is an officially recommended block manager that gathers modules with similar functions into a single group.

The effect is shown below:

  ![](https://gw.alicdn.com/imgextra/i1/O1CN01xop0RTxR7LJ3gr2j_!!6000000006064-2-tps-1818-867.png)

</Frame>

Add components inside a group

### 1.2 Use Cases

Use groups when a page contains multiple independent modules (for example, products, shelves, and prices in a store, where each product sits in its own module) and each module includes multiple form components. Place each module into its own group.

### 3.2 State

Configure the group using the traditional PC-side component states:

- Default: normal state
- hover: the mouse hovers over the component hotspot without clicking

- focus: the page element has cursor focus
- active: the page element is selected and activated

<Frame>
  ![](https://gw.alicdn.com/imgextra/i1/O1CN01SiI19V5sxUJ3hbrz_!!6000000002876-2-tps-1824-863.png)
</Frame>

**Notes:**

- Among the state settings, the default state overrides the other 3 states.
- The hover, focus, and active states are configured independently and do not affect each other.

- In CSS, they are defined as independent selectors.

<Frame>
  ![](https://gw.alicdn.com/imgextra/i2/O1CN012GmBaWi2OWB29R3c_!!6000000001366-2-tps-1060-576.png)

### 3.3 Display

Corresponds to the CSS display mode:

- block: box model
- inline-block: inline box model

- inline: inline model
- flex: flexible layout model

<Frame>
  ![](https://gw.alicdn.com/imgextra/i4/O1CN01P9NgK0ZJ6vH3iEta_!!6000000002599-2-tps-1829-873.png)
</Frame>

The 4 modes above are all standard front-end CSS layout models and are not covered in detail here. For more information, see the [**corresponding W3C documentation**](https://www.runoob.com/css/css-website-layout.html).

Common uses of flex include:

- Use flex layout to arrange items horizontally or vertically as needed.

### 3.8 Shadow

Set the component's shadow. Use x and y to set the direction, and use blur and spread to shape the shadow.

### 3.9 Opacity

Sets the overall transparency of the component module. The range is 0 to 100, with a default of 100. A value of 0 means fully transparent.

### 3.10 Cursor

- Select pointer: a hand icon appears when the mouse hovers over the block.
- Select default: an arrow icon appears when the mouse hovers over the block.
