## 1. Use Cases

The Grade component applies to K12 campus scenarios that require grade selection.

## 2. Basic Features

### 2.1 Multiselect Mode

Select multiple grades. To allow only one grade to be selected, turn off this button.

### 2.2 Data Population

Data population fills the basic attributes of a grade into components in a YiDA app to automatically generate form data. Grade attributes include:

- Campus
- Academic stage

- Enrollment year
