## 1. Use Cases

Use the Subject component in K-12 school scenarios that require subject selection, such as registration for subject-based interest classes.

## 2. Basic Features

### 2.1 Multiselect Mode

The component supports selecting multiple subjects. To allow only one subject, turn off this toggle.

## 3. Data Source

Each grade level is mapped to a standard subject list on the backend. This list cannot be modified yet.
