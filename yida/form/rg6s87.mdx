## 1. Use Cases

The user component retrieves users from DingTalk Contacts and is used whenever you need to select people, such as when setting business trip applicants, asset owners, or maintenance staff. It can also be combined with [**Formula**](/yida/form/vwncwe), and is used on workflow forms to designate approvers—for example, when the initiator selects approvers manually.

<Note>
For component attributes, usage, and examples, see [**Component interface**](/open/yida/components/interface).
</Note>

### 2.4 Advanced Search Mode (New User Component)

When you use the YiDA user component on the DingTalk desktop client or in a web browser, the new advanced search feature lets you select users based on the tree structure of Contacts and drill down through the organization.

The advanced user selection entry is enabled by default on the desktop client. Click it to open a dialog that provides a full user selection page.

## 4. Notes

1. The user component can select users from across the entire company, but only users from the current department are displayed by default. Use Search to select users from other departments.
2. Due to container limitations, when this component is used inside an iframe on the DingTalk mobile client, users cannot be selected because the container does not inject JSAPI into the iframe. Avoid using this component in such scenarios.

## 5. FAQ

<AccordionGroup>
<Accordion id="q1" title="5.1 Why does the User component show blank entries when I enter names during bulk import?">
  This is caused by an incorrect format. Follow the required format for bulk import. See [**Bulk import**](/yida/form/andrke) for details.
</Accordion>
<Accordion id="q2" title="5.2 I want to use a Department component to select a specific department, and then restrict the User component to only users from that department. How can I do this?">
  The user component does not currently offer a configuration option that directly limits the selection range. As a workaround, create an intermediate table containing departments and their users, then retrieve it through data linkage.
</Accordion>
