## 1. Use Cases

This component is typically added to forms that need to collect or display a school's campus information, such as student registration or class assignment forms.

## 2. Basic Features

### 2.1 Multiselect Mode

You can select multiple campuses. If only one campus needs to be selected, turn off this button.

| **Form design mode** | **Form runtime mode** |
|---|---|
|  |  |

**Note: The Campus component does not support data population.**

## 3. Data Source

If the current organization has created a school contacts, you can select any campus name from the school contacts.
