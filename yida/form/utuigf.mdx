## 1. Use Cases

The class picker component suits K-12 campus scenarios that require class selection, such as class moral education evaluations.

## 2. Basic Features

### 2.1 Multiselect Mode

Select multiple classes. To allow only a single class, turn off this toggle.

### 2.2 Data Population

Data population fills a class's basic attributes into components in the YiDA app to automatically generate form data. The class attributes include:

- Campus
- School stage

- Grade
- Homeroom teacher

- Number of students in the class
- Year of enrollment
