The Grid displays form data in a table format.

In addition to the default "All data" grid view, you can create multiple grids on a single data management page. Each grid supports filter conditions, field visibility, list actions, and other rules to present data in different ways.

### Use cases

The Grid can display multiple records at once. Use this view when you need to browse or manage large volumes of data.

### Steps

#### 1. Create a view

Path: Page management > Select a form from the page navigation menu > Generate the data management page > Create view > Create Grid

- The generated data management page includes a default "All data" grid. Delete it or add new views to fit your business needs.
- The List supports adding custom buttons in the action column. If a button is configured with availability conditions, it appears for all records, but users who click it on records that don't meet the conditions see a "No permission" message.

#### 2. Set data filter conditions

Path: Select the Grid > Grid settings > Data filter conditions

- Configure filter conditions for the view. Users only see records that match the filter conditions.
- Filter conditions support multiple tiers, AND/OR logic, and various operators. Click to view detailed operator descriptions.

#### 3. Configure the fields included in the view

Path: Select the Grid > Grid settings > Field visibility

Set the fields to hide from users in this view. Hidden fields are invisible to all users in the grid and cannot be sorted or filtered on the user side.

1) Field visibility settings apply only to the view list. The source records page and the form filling page for a single record are not affected.

2) Each user can only see the fields they have permission to view, and can further configure the Show field when viewing data, independent of the view settings.

#### 4. Configure custom buttons

Add custom buttons defined in the form to the action column of the Grid. You can either add existing buttons or create new ones. [Detailed introduction to custom buttons](/yida/form/ohyllrtgx9v5opox)
