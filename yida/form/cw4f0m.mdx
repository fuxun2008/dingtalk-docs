## 1. Use cases

The Student component is used in K12 campus scenarios where students need to be selected, such as student recognition awards or student score statistics.

## 2. Basic features

### 1.2.1 Multiselect mode

This mode supports selecting multiple students. If you only need to select one student, turn off this option.

### 1.2.2 Data auto-fill

Data auto-fill populates the basic student data maintained in the school's Student Profile app into the components of a YiDA app, automatically generating form data.

- This feature is only available when the Student component is in single-select mode. Data auto-fill is not supported in multiselect mode.
- Student attribute information can be filled into existing or new fields on the form.

- Currently, ID card information maintained in the Student Profile cannot be used for data auto-fill.

## 3. Data source

The component uses student ID and name master data from the School Contacts.

## 4. Selectable user scope

| **Role** | **Selectable scope** |
|---|---|
| Admin / Sub Admin | All student information |
| Homeroom teacher / Teacher | All student information |
| Parent | Associated student information in the School Contacts |
