## 1. Overview

### 1.1 Feature Overview

Forms are the foundational tool in YiDA. All data collection and entry rely on forms, which serve as the source of data.

YiDA offers two form types:

**Regular form**: Collects all data generated during business operations. Collected data can be shared with different collaborators. You can [publish](/yida/form/ulqab1) data permissions to internal members who need to manage the data, or to external members for external data collection.

**Workflow form**: Enables data to flow from the bottom up through multiple approval levels. Permissions can also be assigned to further manage workflow data.

The key difference between a regular form and a workflow form is that a workflow form requires step-by-step approval and workflow configuration.

### 1.2 Use Cases

- Regular form: surveys and statistics, online registration, sales reporting, meeting reservations, procurement receiving, order entry, QR code check-in, and more.
- Workflow form: expense approval, work reports, task dispatching, employee leave requests, item requisition, repair requests, feedback collection, and more.

### 1.3 Availability

Forms are a Free YiDA feature and are available to users on all plans.

Free plan users are limited to 20,000 data records and 20 GB of attachment storage. For details, see YiDA pricing policy.

## 2. Ways to Create a Form

After creating a YiDA app, you can create a regular form or a workflow form in the following ways:

Method 1: Open the newly created app, go to Page Management, and select Create form or Create workflow form.

## 3. Form Setup

After creating a form, you can begin configuring it. Setup for workflow forms and regular forms differs slightly — workflow forms require an additional workflow design step.

(1) Regular form

<Frame>
  ![](https://gw.alicdn.com/imgextra/i3/O1CN01aYBq466EJNK3icJK_!!6000000006124-2-tps-1832-878.png)
</Frame>

Setup steps: Open Form design >> Select the components you want to use >> Save.

(2) Workflow form

<Frame>
  ![](https://gw.alicdn.com/imgextra/i1/O1CN01lnG24HJLXuK3iMhV_!!6000000006715-2-tps-1830-875.png)
</Frame>

Setup steps: Open Form settings >> Select the components you want to use >> Save >> Workflow design >> Configure Steps such as approver, executor, and CC recipient >> Save >> Publish the workflow.

<Frame>
  ![](https://gw.alicdn.com/imgextra/i2/O1CN01TQBeHGDvkmH3iziy_!!6000000003489-2-tps-1835-877.png)
</Frame>

After completing the steps above, publish the app so that members can access the form and enter data. Admins can view submitted data in Data management.

### 3.1 Form Design

The form design page is divided into three sections, as shown below:

<Frame>
  ![](https://gw.alicdn.com/imgextra/i4/O1CN01x6FfjZ57VKE3ik7F_!!6000000004597-2-tps-1833-880.png)
</Frame>

Component selection: choose components. Different components store different types of data.

Canvas area: arrange the layout and order of components.

Component attributes: configure attributes for individual components and for the form as a whole.

### 3.2 Workflow Design

Workflow design applies only to workflow forms. Regular forms do not require this step.

<Frame>
  ![](https://gw.alicdn.com/imgextra/i4/O1CN010wuNcMrO8GJ3izj1_!!6000000003405-2-tps-1835-880.png)
</Frame>

Step type selection: choose an approver, executor, or CC recipient Step based on your scenario.

<Frame>
  ![](https://gw.alicdn.com/imgextra/i4/O1CN01jFGgrDKEHWJ3j7Wx_!!6000000002545-2-tps-1836-883.png)
</Frame>

Step user and permission configuration: configure user rules for approvers, executors, and CC recipients, as well as field permissions and approval permissions.

### 3.3 Save the Form

For both regular forms and workflow forms, after configuring components in form design, click Save in the upper-right corner to finish creating the form.

<Frame>
  ![](https://gw.alicdn.com/imgextra/i1/O1CN01YVZiebSiyOB3jFKj_!!6000000006964-2-tps-1837-876.png)
</Frame>

### 3.4 Publish the Workflow

Workflow forms include a default Step in which the initiator is set as the approver. This prevents workflows from stalling if the Admin forgets to configure Steps. You can customize Steps as needed. After customizing Steps, click Publish on the workflow page for the changes to take effect.

<Warning>
Note: Newly published workflow Steps apply only to data submitted after publication. Previously submitted data continues to follow the earlier workflow rules.
</Warning>

## 4. Data Management

After employees submit data through a form, Admins with app management permissions can import, export, edit, delete, view, and print the submitted data in Data management. There are currently two entry points to Data management:

Entry 1: Open the form or workflow form >> Edit form or workflow form >> Data management.

  ![](https://gw.alicdn.com/imgextra/i1/O1CN01JremgILUCwI3izit_!!6000000001964-2-tps-1835-872.png)
