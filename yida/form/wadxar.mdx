## 1. Introduction

### 1.1 Component overview

A premium text component that allows independent configuration of text styles.

### 1.2 Use cases

Use this component in scenarios such as product display, expense reimbursement, and corporate culture.

## 2. Basic features

### 2.1 Configure premium content

Click **Configure premium content** to open the Rich Text editor. The editor is identical to the [**Rich Text component**](/yida/form/hdi3ya) and consistent with the DingTalk Docs editor. Customize text and styles, upload images, and more.

#### 2.2.2 Page collapse settings

- Collapsible: Whether the page can be collapsed when a maximum height is set.
- Collapse height: When the content exceeds this height, the page can be collapsed.
- Initially collapsed: Whether the page is collapsed on initialization (when the page opens).

**Example**: With the settings shown above, the page is collapsed when opened on a mobile device. Tap the dropdown button to expand the full page.
