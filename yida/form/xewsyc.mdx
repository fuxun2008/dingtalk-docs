## 1. Overview

This topic explains how to download QR Code labels for a form, covering both admin and employee paths and the available label sizes.

For QR Code label configuration, see [QR Code labels](/yida/form/knk7hr).

## 2. User Guide

Both YiDA admins and employees can download QR Code labels, but the paths differ as follows.

### 2.1 Download as an Admin

**Edit mode**: Go to YiDA > My Apps > select the target app and form > Data Management > Download QR Code Labels.

<Frame>
  ![](https://gw.alicdn.com/imgextra/i3/O1CN01q9xmAekafvK5pHbW_!!6000000007101-2-tps-2870-1212.png)
</Frame>

<Frame>
  ![](https://gw.alicdn.com/imgextra/i3/O1CN01HKXCgimsgMB5p232_!!6000000007712-2-tps-2868-1416.png)
</Frame>

**View mode**: Go to YiDA > App Center > locate the data management page of the target app and form > Download QR Code Labels.

<Frame>
  ![](https://gw.alicdn.com/imgextra/i2/O1CN01ZRVbpUfXRuF5q2N2_!!6000000004335-2-tps-2876-976.png)
</Frame>

### 2.2 Download as an Employee

Employees can download QR Code labels in view mode only.

**Path**: YiDA > App Center > locate the data management page of the target app and form > Download QR Code Labels.

<Frame>
  ![](https://gw.alicdn.com/imgextra/i1/O1CN01QvzUKrVa6SK4Mtko_!!6000000005836-2-tps-2152-730.png)
</Frame>
