## 1. Batch Printing

### 1.1 Print Templates

Print settings are supported only in the Basic edition and Professional edition. The Free plan does not support configuring print templates.

Print settings

### 1.2 Batch Printing

Generate print files for the selected records based on a print template, and download them as a package.

**Path 1**: Data management >> Select the records to print >> More actions >> Print selected >> Select a print template >> Confirm.

Select a print template

A PDF file is generated after printing.

Review the selected print data in the print records. A Work Notification is also sent within the organization. See the example below:

Print records

Work Notifications

**Path 2**: Open the app page >> Data management page / Source records page >> More actions >> Batch print.

## 2. Two Ways to Download Batch Print Files

### 2.1 Work Notifications

**Path**: Work Notifications >> Click View details >> Redirect To the local download page >> Print the file.

Work Notifications

### 2.2 Print Records

**Path**: Form >> Data management >> Print records >> Download (saves directly to your local device).

Print records
