## 1. Use Cases

The Semester component is designed for K12 campus scenarios where users need to select a semester.

## 2. Basic Features

### 2.1 Multiselect Mode

Allows users to select multiple semesters. To restrict selection to a single semester, turn off this toggle.

## 3. Data Source

Uses the unified semester master data of the education industry. It is preset by the system and cannot be customized.
