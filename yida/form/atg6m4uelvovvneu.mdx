The Budget control component is a deep integration of YiDA and the budget control capability of DingTalk Smart Finance. Drag the Budget control component into a YiDA form to enable budget rule management for approval form amounts, flexibly configure expense tags, customize budget rules, and monitor budget information in real time.

The Budget control component boosts executive efficiency by 100% (real-time control over organization spending, with cost reduction and efficiency gains) and finance efficiency by 70% (no manual budget reconciliation required, with intelligent management of organization expenses).

## Prerequisites

Before using the Budget control component, enable the budget control capability and complete the configuration. For details, see [Budget control module](https://alidocs.dingtalk.com/i/p/vwY7kmb6aV4mLq2NN0G7ADJDVJDoaXWY?dontjump=true).

## Procedure

Follow these steps to use the Budget control component.

1. Sign in to the YiDA workbench and go to the app details page.

<Note>
If you do not have a YiDA app, create one first. See [Create an app](/yida/app-admin/oncnoy).
</Note>

2. Create a blank form (either a regular form or a workflow form).
3. In the left menu, select Component > Basic components > Premium > Budget control.

4. In the configuration dialog box, select the expense control type. Two types are supported: Reimbursement and Payment.

| Expense control type | Configuration items |
|---|---|
| Reimbursement | • Reimbursement amount (CNY)<br />• Expense date<br />• Expense category<br />• Expense category details<br />• Expense description<br />• Invoice<br />• Project<br />• Customer<br />• Supplier<br />• Product<br />• Owner<br />• Owning department<br />• Detail ID |
| Payment | • Payment amount (CNY)<br />• Expenditure category<br />• Payment description<br />• Invoice<br />• Owner<br />• Owning department<br />• Project<br />• Customer<br />• Supplier<br />• Product<br />• Detail ID |

5. After configuration, click Save.

## FAQ

**Q: When the form is opened in a browser, why can't I upload an invoice directly after clicking Add invoice?**

A: The Budget control component does not currently support adding invoices in browser-based forms. A prompt appears, allowing you to open the form in the DingTalk client to submit it. From the client, you can add invoices normally and use all subsequent features.

**Q: Is the billed user count based on actual component users or all users on the platform? If it is based on actual users, can I control which specific users are counted?**

A: The Budget control component is billed based on actual users. Once the free quota is used up, you can purchase additional entitlements. To manage component users, go to **Smart Finance** > **Budget control** > **Authorized users**.
