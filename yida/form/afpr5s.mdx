## 1. Applicable Scenarios

Use the school stage selection Component in K12 campus scenarios that require selecting a school stage.

## 2. Basic Features

### 2.1 Multiselect Mode

Supports selecting multiple school stages. To allow only a single selection, turn off this Button.

| **Form design mode** | **Form runtime mode** |
|---|---|
|  |  |

**Note: The school stage Component does not support data population.**

## 3. Data Source

Uses the school stage master data from the parent-school Contacts structure of Standard K12: Kindergarten, Primary school, Middle school, and High school.
