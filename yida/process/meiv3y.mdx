Node submission rules use formula validation to determine whether a user can perform an action when submitting a process or when an approver handles a process.

## Trigger Methods

<Note>
**Difference between task completion execution and node completion execution**:

If an approval node has multiple approvers, each approver counts as a separate task, while the node itself remains a single unit.
</Note>

### Task Completion Execution

As shown in the figure, this rule is triggered when the actual action on the manual node is "Accept".
