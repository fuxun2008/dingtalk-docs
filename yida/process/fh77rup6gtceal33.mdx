After you create a workspace, use the shortcut entry component on the space portal to configure an approval task center. This lets you pin frequently used approval processes to the space home for quick access.

## Steps

<Steps>
  <Step title="Step 1">
    Sign in to the [YiDA workbench](https://www.yidaapps.com/workPlatform) as an Admin, then click **Platform management** in the upper-right corner to open the platform management page.
  </Step>
  <Step title="Step 2">
    In the left-hand menu, select **Platform-specific customization** > **Space management**, choose the target space, and click **Edit**.
  </Step>
  <Step title="Step 3">
    Select **Space portal settings** and click **Edit portal**.
  </Step>
</Steps>

<Steps>
  <Step title="In the left component panel, select the Shortcut entry component and add it to the central canvas area">
  </Step>
  <Step title="In the right attribute panel, select Content > Batch edit">
  </Step>
  <Step title="Step 3">
    In the dialog box, set Entry type to Page, set App/Page/Link to a workflow form in the app, set Entry name to the process name, and set Auxiliary description to the process description. Then click Confirm.
  </Step>
  <Step title="After configuration is complete, click Save in the upper right corner">
  </Step>
</Steps>
