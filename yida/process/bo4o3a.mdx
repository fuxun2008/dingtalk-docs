Approval assignment methods fall into two types: simultaneous assignment and sequential assignment.

- Simultaneous assignment: If a node requires approval from multiple people, the task is assigned to all approvers at the same time.
- Sequential assignment: Tasks are assigned in order. The task is passed to the next approver only after the previous approver completes the Approval.

## Simultaneous Assignment

All three approvers receive the approval message at the same time.
