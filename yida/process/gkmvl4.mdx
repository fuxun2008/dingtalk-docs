The End node marks the endpoint of the entire workflow. A properly configured workflow should progress step by step and eventually reach this node to signal completion. You can configure associated actions on the End node to run when the workflow result is Accept, Decline, undone, or terminated.

## Configure the End node

1. Access the advanced workflow design page.
2. Click the End node, then click Premium in the Attribute panel on the right.
3. Click the Settings button next to Node submission rules.
