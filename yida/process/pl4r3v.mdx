To notify people other than the approver when a workflow reaches a node, add a message notification. You can include a link to the workflow in the notification. However, users who are not workflow admins and do not have View Permission for the instance cannot view the workflow.

## Prepare a Message Template

Before using a message node, create a message notification template. Both Plain messages and DingTalk To-Do are supported. For details, see [Message notification templates](/yida/platform-admin/fkfhud).

## Node Message Settings

**Path**: Approval node > Premium > Plain message

| **Message type** | **Function** |
|---|---|
| **Notification rule when a task is created** | Triggered when an approval task is created. A single approval node may have multiple approvers, with one approval task per approver, and the rule triggers once for each task. |
| **Notification rule when a node is entered** | Triggered when the approval node is entered. Triggers only once per node. |
| **Notification rule when a node is exited** | Triggered when the approval node is exited. Triggers only once per node. |
| **Notification rule when a task is closed** | Triggered when an approval task is completed or canceled. |
| **Notification rule based on a Date field in the workflow** | Triggered based on the date selected in the form Date component. |
