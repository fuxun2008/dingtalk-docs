App permissions settings define the administrators of an App. App administrators can edit, configure, and manage data within the App. This article explains how to configure App permissions.

<Note>
- The YiDA Free plan does not require enabling App administrators. By default, every User can create Apps.
- Paid YiDA plans require App administrators to be enabled separately. Only users designated as App administrators can create Apps.
</Note>

## Set App administrators

1. Sign in to the YiDA workbench and open the **My Apps** page.
2. Select the target App, then choose **···** > **App settings**.

3. In the left-hand menu of the App settings page, click **App permissions** > **App administrators**.
4. Click **Set users** under each Role, select the appropriate users, and click **Confirm**.

## Manage permissions

Manage permissions provides a centralized view for configuring permissions across all types of pages in an App.

1. Sign in to the YiDA workbench, locate the target App, and open the **App settings** page.
2. In the left-hand menu of the App settings page, click **App permissions** > **Manage permissions**.
3. Find the page whose permissions you want to manage, and edit them on the right.

## Permission details

The permissions available to each User within an App are described below:

| **User** | **Description** |
|---|---|
| **App Super Admin** | Has full permissions in the App admin console, including App building, editing, configuration, and data management. |
| **Data Admin** | Has **data-management permissions** only. Can manage App data, build reports, and manage datasets and data services. Cannot access Form design, workflow design, custom pages, page settings, or App administrator configuration. |
| **Developer** | Has **App development permissions, excluding data management**. Cannot access App data management, report building, dataset management, or App administrator configuration. |

<Note>
Platform administrators and App administrators must be configured on the **platform management** page. For details, see [Platform permission management](/yida/platform-admin/omvowq).
</Note>

## FAQ

**Q: I cannot select a dataset when editing a report on the App page settings. What should I do?**

A: Set the User who edits the report as an App administrator.

**Configuration path**: App settings > App permissions > App administrators > Add the User as App Super Admin or Data Admin.
