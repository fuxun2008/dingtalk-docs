**Data Preparation** is a core feature of the YiDA low-code platform. It helps enterprise users clean, merge, and transform raw data before analysis or app use. Data Preparation uses a zero-code ETL (Extract, Transform, Load) approach to process data from YiDA apps, external databases, file-based sources, and official DingTalk data sources (including Contacts, OA, Smart HR, and Attendance). By building data-processing pipelines, it consolidates scattered data into standardized datasets that support visual analysis and data-driven decisions.

## Data Preparation Entitlement Upgrade

**Purchase an add-on package**

1. Go to **Platform management** > **Basic information** > **Premium features** > **Data Preparation**.

<Frame>
  ![](https://gw.alicdn.com/imgextra/i3/O1CN01ctzeyYIbeyF3kNao_!!6000000001355-2-tps-1846-944.png)
</Frame>

2. Click **Purchase**. DingTalk opens and displays the purchase order.
3. Select the value-added service type, then click **Share with Admin**.

<Frame>
  ![](https://gw.alicdn.com/imgextra/i2/O1CN01gYVCkoFqP5D3vCwY_!!6000000000500-2-tps-1932-1530.png)
</Frame>

**Use Data Preparation entitlements**

1. Go to **App settings** > **Data Factory** > **Data Preparation** > **Run rules**.

<Frame>
  ![](https://gw.alicdn.com/imgextra/i4/O1CN01LjgLRiHVZAI5mlYO_!!6000000002051-2-tps-2850-1374.png)
</Frame>

- Automatic downgrade: The system detects auto-run tasks that have not been used for three days and cancels them automatically.

2. Click **Settings**. In the dialog, choose a run frequency: every 1 hour, every 4 hours, or every 24 hours.

<Frame>
  ![](https://gw.alicdn.com/imgextra/i2/O1CN0109CNdutZHxH1cCZg_!!6000000002758-2-tps-796-344.png)
</Frame>

## **Usage Limits and Management**

View Data Preparation usage details on the **Platform management** page in the [YiDA workbench](https://www.yidaapps.com/platformManage).

<Note>
Data Preparation tasks do not run automatically between 22:00 and 07:00 the next day. To run tasks during this window, trigger them manually.
</Note>
