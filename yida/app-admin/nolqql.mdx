An external link is a URL that you can access from a browser. Copy the URL directly from your browser and add it to a YiDA app to help users organize pages from other application systems. This article describes how to add an external link.

<Note>
An external link page cannot be set as the first visible page.
</Note>

## Steps

1. Sign in to the YiDA workbench and open the My apps page.
2. Select the app to which you want to add an external link, and open the app details page.
