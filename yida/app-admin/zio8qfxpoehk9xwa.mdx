After building your app, publish it to the Calendar Plugin Center in the DingTalk client with one click from the app publishing page. Once published, you can quickly enable the app from the Calendar sidebar in the DingTalk client.

## Use Cases

- Assistants managing executives' schedules: Executive assistants can subscribe to executives' calendars to arrange schedules efficiently.
- Approval before creating important meetings: For meetings that include executives as attendees, an assistant approval is triggered. The meeting or event is created only after the approval is passed.
- Custom meetings or events.

## Feature Overview

The [DingTalk Calendar Plugin](https://alidocs.dingtalk.com/i/p/BrO5pXBP3oG7ZvJKb9XJlbJAKwJ28GyA?dontjump=true) is a new DingTalk app format built on the principles of immersive experience, scenario orientation, collaboration, and data accessibility. It transforms the complex features and workflows of traditional enterprise apps into atomic, component-based interaction cards and quick entries. These are reorganized around time management scenarios, seamlessly integrating meeting management, task management, and other time-related workflows into the Calendar to deliver an immersive work experience.

Through the YiDA workbench, you can publish YiDA apps directly to the DingTalk Calendar Plugin Center, allowing employees in your organization to quickly enable plugins in event-related scenarios. Organization admins can also configure the usage scope in the [DingTalk admin console](https://oa.dingtalk.io/calendar_oa?openType=oa&lang=zh_CN&nation=CN&code=1f1ac81e66203e2f96df785666f12075#/plugin-management).

## Procedure

<Steps>
  <Step title="Create an app or open an existing app">
    <Note>
    If you do not have a YiDA app yet, create one first. For details, see [Create an app](/yida/app-admin/oncnoy).
    </Note>
  </Step>
  <Step title="Create a form page and configure the event fields on it">
    <Note>
    For the form fields required to create an event, see [Event Connector](https://docs.aliwork.com/docs/yida_support/yida_qalist/sk2s4ft0ic8tdqzn/tcgvmmgmhrsbf21k/lt4tqm/wnf6sv).
    </Note>
  </Step>
  <Step title="Go to the Integration & Automation page, click Create Integration & Automation, select Form event trigger, choose the form for creating events, and click Confirm">
  </Step>
  <Step title="Use the Event Connector to trigger event creation upon form submission">
    <Note>
    For details on how to use the Event Connector, see [Event Connector](https://docs.aliwork.com/docs/yida_support/yida_qalist/sk2s4ft0ic8tdqzn/tcgvmmgmhrsbf21k/lt4tqm/wnf6sv).
    </Note>
  </Step>
  <Step title="Go to the app Settings page, select Publish to Calendar Plugin Center, and click Publish">
  </Step>
  <Step title="Configure the plugin Icon, Name, Description, Usage scope, plugin pages, and page opening method, then click Publish to complete the release">
    <Note>
    The enablement scope must include yourself so that you can use the plugin normally.
    </Note>
  </Step>
</Steps>

## Use the Calendar Plugin

1. Open the DingTalk client and click Calendar on the left to enter the Calendar Center.
2. On the right side of the page, select the Calendar plugin you want to use, and click the app icon to start using it.
