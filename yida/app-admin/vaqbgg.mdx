## 1. Introduction

### 1.1 Feature Overview

Creating a form from Excel lets you design a form quickly and import Excel data directly into it for streamlined data management.

### 1.2 Use Cases

In inventory management scenarios that require entering product names, specifications, quantities, and unit prices, enter the component names and data in an Excel spreadsheet to quickly import product information into the base data table.

## 2. Steps

### 2.1 Select an Excel File

Path: Create form >> Import from Excel >> Select Excel file

## 3. Import Rules

Uploaded Excel files must meet the following requirements:

• Merged cells are not allowed.

• File size must not exceed 2 MB.

• Only *.xls and *.xlsx files are supported.

• Make sure the header row of the sheet contains no empty cells. Otherwise, the system will not import data from that sheet.
