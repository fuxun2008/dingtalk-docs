Manage all form data sources of the current app in one place. See the table below for details:

| **Name** | **Purpose** |
|---|---|
| [**Datasets**](/yida/app-admin/roe3o1) | Manage all single-table data sources, view tables (multi-table associations), data preparation (big-data offline solutions), and cross-app (form) data sources of the current app in one place. Datasets serve as Yida's standard data control unit for data interconnection scenarios. |
| [**View Tables**](/yida/app-admin/oim554) | View tables preprocess existing form data through single-table or multi-table associations, and also support intermediate table mode to strengthen data processing. Scenarios such as report visualization and form linkage can call data from view tables directly. |
| [**Cross-app**](/yida/app-admin/btrtnt) | Also known as cross-app data retrieval. Call form data from other Yida apps within the current app to enable data interconnection across Yida apps. |
| [**Data Source**](/yida/app-admin/duy0wi) | A Data Source describes where data comes from. Yida supports managing and maintaining data sources such as files and databases. |
| [**Data Cards**](/yida/app-admin/cpkmxvpgchx339qq) | A new data visualization carrier. Unlike reports with a complete analytical pipeline, data cards quickly combine fragmented, scenario-based charts for use in Yida portals. Cards also come with built-in broadcast capabilities that sync data to groups as snapshots. |
| [**Data Services**](/yida/app-admin/fw9qtv) | Data services process datasets by selecting specific fields and converting them into API services. They can currently only be consumed within Card nodes of the integration & automation / workflow designer. |
| [**Data Preparation**](/yida/app-admin/ykemo6) | Before analysis and use, clean, merge, and transform raw data to aggregate scattered data into standardized datasets, supporting visual analysis and data-driven decision-making. |
