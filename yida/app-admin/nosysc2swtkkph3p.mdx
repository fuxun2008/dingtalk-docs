Building a data card is similar to building a report and uses the same design panel, with a few limits on the building capabilities. For example, a single card supports up to five chart components. When building a card, decide which data to present through it.

## Steps

Follow these steps:

1. Sign in to the YiDA workbench and open the App settings page.
2. Click Data Factory > Data card.
3. Click Create data card to open the card design page.

In addition, the chart layout supports magnetic snapping just like reports, so you can drag and drop components to adjust their positions.

4. After building the card, click Publish data card at the top to complete the release.

## Card actions

A card supports three actions: preview, save, and publish data card.

- Save: saves only the card's configuration or changes, without affecting other scenarios where the card is used.
- Publish data card: once a data card is published, it takes effect immediately in all scenarios where the card is used.

## Editing tips for data cards

Because a data card in a portal is a single unit, read the following tips carefully to build attractive and practical cards:

| **Case** | **Illustration** | **Tip** |
|---|---|---|
| The card shows only half of its content in the portal | | When building a data card, make sure components are anchored to both sides. |
| The card has data in edit mode but shows none in preview | | If the card was created from a template, its data is demo data rather than real data. Preview and access require real data. |

**In addition, use full blocks for the layout of data cards. Data linkage between data cards (such as linked filters) is not yet supported.**

## Component selection

Data cards mainly support three categories of chart components and one category of filter components.

- Chart components include: Chart (Column, Line, Pie, Dashboard, Funnel, Heatmap, China Map, Column-Line Combo, Word Cloud, Radar, Calendar Heatmap), Metrics, and Table (Basic Table).
- Filter components include: Filter Dropdown, Filter Range, and Filter Time.

For details on how to use these components, see [Report components](/yida/report/wq6oap).

Select the components that fit each consumption scenario. For details, see [Card distribution](/yida/app-admin/sv1c236glf4ok4nx).

## Switch the display side

Because a data card is captured at mobile size when broadcast, review how it looks from different user perspectives so that you can adjust the styling accordingly.

## Turn on filters

The filter capability is off by default in data cards. To filter data within a card in the portal, turn on this capability and use it together with filter components. For more information, see [Filters](/yida/report/pf0tv9).

## Usage limits

- Each data card supports up to five chart components.
- After distribution, a data card has a lifecycle of seven days. Its data is automatically destroyed seven days after distribution.
