## Overview

This section explains the data sources available through official data integration, the entitlements required for each YiDA edition, and how to request the necessary permissions.

With this capability, enterprises can efficiently drive deep integration between low-code development and their full range of enterprise data resources on the YiDA platform, significantly improving the efficiency and effectiveness of data-driven decision-making.

## Request Permission

To use official data integration, the app's Super Admin must first obtain management permissions for the corresponding data.

For example, to use Employee Roster data, obtain Sub Admin permissions for Smart HR. Follow these steps:

<Steps>
  <Step title="Step 1">
    Sign in to the OA Admin Console as the DingTalk Super Admin.
  </Step>
  <Step title="Step 2">
    Click Security & Permissions > Manage permissions > Sub Admin > Add Sub Admin.
  </Step>
  <Step title="Step 3">
    Select the users to add, then Configure the required permissions.
  </Step>
  <Step title="Step 4">
    After configuration, click Save.
  </Step>
</Steps>

## Dataset Permissions

YiDA now supports independent permission control for all datasets. When a dataset with permissions configured is consumed, its data is filtered and controlled in real time by user (who can view), row permissions (rule configuration), and column permissions (field scope).

As YiDA is used in richer scenarios, Data permissions control becomes essential for consumption scenarios such as reports and dashboards.
