Aggregate tables cannot directly operate on form data. Once an aggregate table is created, you can use its calculation results in forms, reports, Integration & Automation, data linkage, associated forms, and other scenarios. You can also view data change logs on the aggregate table details page.

## Channels for Using Aggregate Tables

You can use aggregate tables in the following scenarios.

| **Channel** | **Description** | **Illustration** |
|---|---|---|
| **Data linkage** | Aggregate tables support data linkage in forms.<br />• In condition rules, select the title field of an aggregate table on the right.<br />• In linkage rules, select the calculation metric field of an aggregate table on the right. | ![](https://gw.alicdn.com/imgextra/i3/O1CN016Ten0ESt8kL3W9fc_!!6000000004162-2-tps-1733-947.png) |
| **Associated form** | Aggregate tables support data association in associated forms. | ![](https://gw.alicdn.com/imgextra/i2/O1CN01Qp2K9O6rmnF3W1ra_!!6000000005059-2-tps-1732-938.png) |
| **Report** | Select an aggregate table directly as the data source in a report. | ![](https://gw.alicdn.com/imgextra/i3/O1CN011TJ9WZaPStI3UGZA_!!6000000002377-2-tps-1718-814.png) |
| **Data card** | Select an aggregate table directly as the data source in a data card. | ![](https://gw.alicdn.com/imgextra/i2/O1CN01mTH9DOub6dB4v8nq_!!6000000006573-2-tps-2424-1458.png) |
| **Integration & Automation/Business rules** | Query data from aggregate tables in Integration & Automation and business rules.<br />Note: Directly modifying or deleting aggregate table data is not supported. | ![](https://gw.alicdn.com/imgextra/i1/O1CN01J5hcEEMhwoD2ynTg_!!6000000002981-2-tps-1468-1080.png) |
| **Open API** | Query the results of aggregate tables through Open API. | |

## View Data Operation Logs

To help Admins trace the calculation and change source of aggregate table result data, the platform provides a data change log feature. On the aggregate table details page, click the **View** button in the action column of a record to view its **change log**.
