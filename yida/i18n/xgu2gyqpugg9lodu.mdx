- Available in YiDA international edition when the plan includes "internationalization capabilities".
</Note>

YiDA's global file acceleration resolves slow attachment upload and download in overseas regions. It currently covers 14 countries and regions worldwide.

Two file acceleration modes are supported:

- Designated region storage: All files in the app are uploaded to the database in the specified region. Attachment preview and upload within the same region are accelerated. Use this mode when overseas employees are concentrated in one region.
- Automatic storage selection based on the uploader's region: Files are uploaded to the nearest database based on the uploader's region. Use this mode when the app is used by employees across multiple countries and regions.
