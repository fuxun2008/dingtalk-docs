## International Edition vs. China Edition for Overseas Use

- **International edition of YiDA**: Designed for overseas customers (overseas subsidiaries). The international edition of YiDA is deployed in Singapore and stores data there.
- **China edition of YiDA (overseas use edition)**: Designed for Chinese organizations expanding overseas. The China edition of YiDA is deployed in China and stores data there, adding internationalization capabilities on top of the Professional edition and Dedicated edition.

## Internationalized Time Zones

Internationalized time zones offer comprehensive support for users managing time zones and time.

- The Default time zone supports three configuration methods: Custom, data linkage, and quick configuration.
- Certain time formats are automatically converted based on the time zone, such as showing the difference between UTC+8 and UTC-8.
- Layout formats include horizontal (time zone on the left, date on the right) and vertical (time zone on top, date on the bottom).

<Note>
For details, see [Internationalized time zone capabilities](/yida/i18n/embkd0mxxyeow0at).
</Note>

## Global File Acceleration

The updated global file acceleration feature automatically selects the file storage region based on the user's location, improving file preview and upload speeds. File sharing and transfer settings have also been optimized for multi-language management and global requirements.

- Multi-region file acceleration has been enhanced to boost cross-region transfer speeds.
- The file storage database is automatically selected based on the user's region, optimizing preview and upload performance.
- Multi-language management is supported to meet the language needs of global users.

<Note>
For details, see [Global file acceleration](/yida/i18n/xgu2gyqpugg9lodu).
</Note>

## Internationalized Mail

The China edition of YiDA requires an internationalization capability extension module, while the international edition includes internationalization capabilities by default. Outlook and Gmail accounts are supported and can be used to send mail in Chats nodes.

- To create an Outlook Mail account, obtain an authorization code to complete authorization.
- To create a Gmail account, enter the Mail account and authorization code, then save.
- Mail content can dynamically receive form parameters or system Default data for greater flexibility.

<Note>
For details, see [Internationalized mail](/yida/i18n/hin4xmdnlruym0g3).
</Note>

## Internationalized Currency

Internationalized currency **supports multiple international currencies**. The system supports various currency types (such as USD, JPY, and EUR), and users can select the appropriate one as needed. A clear currency Dropdown List enables intuitive and quick selection.

<Note>
For details, see [Internationalized currency](/yida/i18n/la0zaple0giylcvx).
</Note>

## Viewing Internationalization Entitlements

- In the China edition of YiDA, go to **Platform management** > **Basic information** > **Internationalization entitlements** Card to view and purchase additional entitlements.
- After purchasing YiDA internationalization entitlements, platform administrators can go to **Platform management** > **Basic information** to view details such as the number of licensed users and the expiration date.
