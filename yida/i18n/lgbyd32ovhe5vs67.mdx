## 1. Overview of Basic Address Component Capabilities

Built on China's standard administrative regions, this component supports quick location and address entry, and lets you set a default address as needed. Key features include:

- Standardized selection of China's administrative regions with support for detailed address entry.
- Mobile location for quick address entry, with the option to re-edit.
- Built-in, up-to-date data for China's administrative regions, including provinces, cities, districts (counties), and streets.

<Note>
For details on the basic address component, see [Basic address component](/yida/form/bcxgpv).
</Note>

## 2. International Address Component Upgrade

The **international address component** is an upgrade of the basic address component. It **covers countries and regions worldwide** to meet international business needs, as shown below:

1. Set the country/region scope to Default, Custom, or All.
2. Choose whether to display the country/region scope.
