title: "Workflow Data Privatization Support"
description: "Organizations can run workflow governance and analysis on dedicated storage. Approval data is stored by default in the organization's custom dedicated storage, enabling workflow governance and analysis."
polished: true
---

Dedicated storage now supports moving workflow-related physical tables to the organization's custom database, so organizations can run workflow governance and analysis on dedicated storage.

Approval data is also stored by default in the organization's custom dedicated storage. Organizations can leverage the workflow data they continuously accumulate to conduct workflow governance and analysis.

Workflow instance approval record table (alibpms_app_cm_operator_record)
