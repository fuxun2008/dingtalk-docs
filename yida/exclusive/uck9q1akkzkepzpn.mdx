This topic describes how organization admins can configure global app settings, including how to enable dedicated storage, dedicated cluster environments, and other governance features for apps across the organization.

## Feature Overview

Global app settings let you control whether apps in the organization enable dedicated storage, a dedicated cluster environment, dedicated physical columns, app watermark, and app protection box. Of these, dedicated storage, dedicated cluster environment, and dedicated physical columns can be enforced. Once enforced, newly created YiDA apps automatically enable these features by default and cannot be turned off.

### Dedicated Storage

- Enforce: Once on, all newly created YiDA apps enable app-level dedicated storage by default. Business data is automatically stored in the organization's private storage. This default state cannot be turned off once on.

<Frame>
  ![](https://gw.alicdn.com/imgextra/i2/O1CN01M2Q5EPs48PC47Hz3_!!6000000004475-2-tps-2028-745.png)
</Frame>

- Default state: Once on, dedicated storage is selected by default when you create a new YiDA app.

### Dedicated Cluster Environment

- Enforce: Once on, all newly created YiDA apps enable app-level watermark effects by default. The app's build artifacts, runtime state, and business data are automatically stored in the organization's private environment. This default state cannot be turned off once on.
- Default state: Once on, the dedicated cluster environment is turned on by default when you create a new YiDA app.

### Physical Column Storage

- Enforce: Once on, form data storage for newly created YiDA apps switches from JSON to physical column mode (one field maps to one physical column field). This default state cannot be turned off once on.

- Default state: Once on, app-level physical column storage is selected by default when you create a new YiDA app.

### App Watermark

- Default state: Once on, app-level watermark effects are turned on by default when you create a new YiDA app.

### App Protection Box

- Default state: Once on, the app protection box is turned on by default when you create a new YiDA app.

## Dedicated Settings for Individual Apps

- Each app supports configuration by department, enabling refined ownership and app governance.
- Within each app, you can view and configure its dedicated features separately, enrich app master data, and manage the organization's low-code data assets.
