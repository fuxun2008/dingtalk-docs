- In a VPC cloud PostgreSQL environment, 50,000 rows with 100 basic fields import within 5-10 minutes.
- The Dedicated edition optimizes the underlying connection technology and delivers faster import speeds through Dedicated Storage database connection technology.

## Dedicated Edition Import

For large-volume data imports on regular forms, the single-import limit rises to 50,000 rows.

  ![](https://gw.alicdn.com/imgextra/i2/O1CN01bDY6BuemshC2QgMw_!!6000000000557-2-tps-1197-873.png)
</Frame>

For large-volume imports on workflow forms, the limit rises to 10,000 rows.

<Frame>
  ![](https://gw.alicdn.com/imgextra/i2/O1CN01R9bjCMcDK0J5qI8E_!!6000000001017-2-tps-2878-1560.png)
</Frame>

Integration & automation and business rules (for data retrieval, update, and deletion) support up to 2,000 records.

<Frame>
  ![](https://gw.alicdn.com/imgextra/i2/O1CN01QdPB2ZIaOgK4Neou_!!6000000000534-2-tps-2158-1646.png)
</Frame>

<Note>
- Within the Update node, the higher limit applies only to the "Update by node" method. The "Direct update" method remains capped at 100 records.

<Frame>
  ![](https://gw.alicdn.com/imgextra/i4/O1CN01P3weSewpzGG4yAAC_!!6000000005580-2-tps-2448-1648.png)
</Frame>

- If you use a Data Retrieval node to fetch 2,000 records and insert them into a subform through an Insert node, the subform's 500-record limit still applies, so only 500 records are written.
</Note>

## Non-Dedicated Edition Import (Comparison)

- For large-volume data imports on regular forms, the single-import limit is 5,000 rows, and import speed is relatively slow.

## **Notes**

If Dedicated Storage is enabled for the app, integration & automation can retrieve only 100 subform records at a time.
