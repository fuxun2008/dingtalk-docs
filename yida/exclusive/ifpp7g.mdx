YiDA Dedicated is a custom-built **low-code business development platform** for your organization. It addresses customization needs that the public cloud edition cannot meet, including custom data storage, business extension, security protection, and business analytics. It also delivers higher product performance, solutions for ultra-large data volumes, and additional Safety Policy options to further raise the security level of your business.

## Solution overview

YiDA Dedicated edition offers cloud-native upgrade capabilities. All business data from low-code apps is stored in the customer's designated private storage space, providing higher exclusive security for both data and runtime. It also includes multiple dedicated extension and customization capabilities, making it a strong fit for medium and large organizations with demanding platform requirements and customization needs.

## Three core capabilities

### 1. Reliable business data security

- Data privatization: business data is stored in dedicated storage for more reliable independent storage.
- Network security: a zero-trust gateway protects your organization's intranet services.
- Important files: supports network fence detection and control with differentiated policies.
- Behavior auditing: actions are logged with dedicated protection, and organization logs are traceable and searchable.

### 2. Rich dedicated customization capabilities

- Brand enhancement: build your organization's brand image with a custom domain, logo, and more.
- UI customization: reflect your corporate culture with a dedicated page style.
- Chats management: provide a Do Not Disturb mode for executives.
- Manage permissions: a multi-level permission system meets personalized management needs.

### 3. Cross-organization connectivity

- Organization interconnection: connect with upstream and downstream partners and customers.
- Single sign-on: DingTalk dedicated accounts support multiple IDaaS services.
- API + Connector: link business and data across systems.

## Higher product benefits and capabilities

YiDA Dedicated offers higher data volume limits, supporting more than one million records per Form, tens of millions of total records per Organization, and higher business concurrency QPS limits. ## Frequently asked questions

<AccordionGroup>
<Accordion title="Q: After purchasing YiDA Dedicated edition, do I have to configure dedicated storage?">
  A:

  No. Configure it based on your actual needs. You can skip configuration (data stays in the cloud) and still use other dedicated features. To store data for specific apps in a designated storage medium, enable dedicated storage at the app level in app settings.
</Accordion>
<Accordion title="Q: What data does data privatization cover? Forms? Files? Approval process records?">
  A:

  (1) App design and runtime remain in the cloud.

  (2) Business data submitted by users and uploaded attachments can be stored locally.

  (3) **Approval-related process record data is also stored locally. New YiDA Dedicated organizations created after July 2023 are privatized automatically; organizations created before July can contact their account manager to arrange migration.**
</Accordion>
</AccordionGroup>

### **Q: How is data privatized—direct write to private storage or transfer from the public cloud? Does it cover both structured and unstructured data?**

A:

(1) Direct write; no data is stored in the cloud.

(2) Direct write is also supported if you use public cloud OSS and databases.

(3) Structured data is stored as standard JSON strings.

### **Q: What does privatized data look like? Is it encrypted? Can we use the privatized data directly for local data analysis? Ideally, could we see a screenshot of a privatized data sample?**

A:

(1) Data storage is not encrypted.

(2) Yes, you can analyze it. Most BI tools can extract, deconstruct, and analyze the data.

(3) In specific scenarios, app Form Data can be stored directly in fully physical columns, which simplifies statistical analysis.

<AccordionGroup>
<Accordion title="Q: What are the requirements of data privatization for our cloud platform?">
  A:

  (1) For better query and architectural performance, the business database for dedicated storage currently requires PostgreSQL 14 or later.

  (2) Object storage currently supports OSS from several mainstream vendors, including Alibaba Cloud OSS, Huawei Cloud OBS, and Inspur Cloud OSS.
</Accordion>
<Accordion title="Q: With apps in the cloud and data on premises, what is the approximate latency for data storage and reads? Do you have similar deployment cases?">
  A:

  (1) For an on-premises data center, latency is 20–40 ms.

  (2) For the cloud, latency is 3–5 ms.

  (3) Dedicated edition customers include Sungrow and FAW-Volkswagen.
</Accordion>
<Accordion title="Q: Do file storage and data storage support heterogeneous clouds?">
  A:

  (1) File object storage only supports Alibaba Cloud OSS, Huawei Cloud OBS, Inspur Cloud OSS, and similar services.

  (2) Data storage supports multiple clouds—choose one—but a PostgreSQL database must be installed.
</Accordion>
<Accordion title="Q: Does the Dedicated edition support data preparation?">
  A:

  Yes, provided that user data is stored on Alibaba Cloud. If data is stored locally, customers must handle offline data processing themselves.
</Accordion>
</AccordionGroup>

### **Q: Is historical data migration supported?**

A: Yes. One-time batch migration of historical data is supported. You can also migrate manually in the YiDA app admin console under App settings > Basic information. You can also select the storage mode when creating a new app.

### **Q: Is database scaling and sharding supported?**

Yes. Once you provide the target database instance, YiDA's professional engineers can assist with elastic scaling.

### **Q: How is data transmission secured?**

Data is encrypted throughout transmission, and all Form business data lands in your organization's dedicated storage database.
