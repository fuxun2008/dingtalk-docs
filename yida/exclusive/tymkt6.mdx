## Enable on Demand (App Level)

### 1. Enable When Creating a New App

When creating a new app, select whether the app's business data is stored in the public cloud (default) or in a dedicated hybrid cloud database (recommended for core critical data).

### 2. Enable Manually for Existing Apps

- As the App Admin, go to App Settings > Basic Settings > Dedicated Configuration in the app backend, then select and enable dedicated storage for the app.
- After you enable it, both historical data and future data for that app are stored in the dedicated PostgreSQL database and dedicated attachment OSS configured in platform management.
- App functionality is suspended during the upgrade, so perform this action during off-peak hours. The process takes about 3–10 minutes and cannot be canceled after completion. You can manually stop the upgrade while it is in progress.
