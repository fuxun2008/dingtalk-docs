Exclusive to Dedicated edition.

YiDA Dedicated edition lets you view the organization's performance data details. This article describes each metric.

The data detail metrics are as follows:

## Average Daily Visits This Week

| **Metric** | **Description** |
|---|---|
| Average daily visits UV this week | Average number of visits to YiDA by all users within your organization this week. |
| Industry reference value | Average daily visits for the industry the organization belongs to. |
| Top 10 user visits in the last 7 days | Visits from the 10 users with the highest visit counts in the last 7 days. |
| Visit PV Line for the last 7 days | Line of total PV for the last 7 days. Use it to view visit trends. |
| App visits in the last 30 days | Details of YiDA app visits by employees within your organization in the last 30 days. |

## Authorization Usage Data

| **Metric** | **Description** |
|---|---|
| Number of authorized users | Total number of users within your organization who can use YiDA. |
| Industry reference value | Average number of people who can use YiDA in the industry the organization belongs to. |
| Department usage distribution | Proportion of people using YiDA in each department within your organization. |
| Active usage departments | Total number of people using YiDA in each department within your organization. |
| (Authorized users) Recent usage records | Details of YiDA visits by employees within your organization in the last 30 days.<br />**Note**: The data update rule for authorized users' recent usage records is `T + 1`. If the authorized user has no visit records after authorization, the authorization time is used as the last visit time. If the authorized user has visit records after authorization, the actual last visit time is used. If an authorized user's last visit time is earlier than the permissions grant time, they may have been previously authorized and later had access revoked. |

## Cumulative Instance Count

| **Metric** | **Description** |
|---|---|
| Cumulative instance count | Total number of apps created within your organization. |
| Industry reference value | Average total number of apps created in the industry the organization belongs to. |
| Cumulative new instance count in the last week | Number of new apps created in the organization in the last week. |
| Top 10 users by instance submissions in the last week | Top 10 users by instance submits within your organization in the last week. |
| Instance table submitted in the last week | Details of instances submitted within your organization in the last week. |

## Workbench App Count

| **Metric** | **Description** |

## Authorized Access Data

- Large enterprises often purchase many platform license authorization accounts. Whether authorized employees actively use them is an important reference for the organization's digitalization costs and business value.
- View the last visit time records of all authorized users in the organization. The details support Excel export (the day a user is authorized is used as the default first-time timestamp).
- The platform management admin of the organization can define an account management strategy based on activity (last visit time), and temporarily freeze inactive accounts on the authorization management page.
