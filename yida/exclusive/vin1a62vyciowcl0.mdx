## Feature overview

The dedicated cluster environment is a hybrid cloud architecture solution built on the Yida Dedicated product foundation that fully privatizes app build artifacts, app data, and app runtime services.

Development and design still run in the cloud. On each release, the app's build artifacts, carrying a specified Version number, are pushed by Version to the Organization's target cluster environment.

## FAQ

### 1. Which capabilities are not yet supported in the dedicated cluster?

The product capabilities in the cluster environment are based on a specific Version of the [Yida cloud Version dated September 7, 2022](https://docs.aliwork.com/docs/yida_updates/lxttkz7d83gs2hco). **For scenarios that involve on-premises deployment in the future, refer to and consult the** [**Yida Private Edition**](https://alidocs.dingtalk.com/i/nodes/ydxXB52LJqL79mQ4un1lnm1vVqjMp697?corpId=ding77a7af8924a84af0&utm_medium=im_card&iframeQuery=utm_medium%3Dim_card%26utm_source%3Dim&utm_scene=team_space&utm_source=im).
