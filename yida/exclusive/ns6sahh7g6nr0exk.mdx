<Note>
Both Quick BI and the YiDA Data Factory offer report building, data processing and modeling, and data preparation. So how should developers or enterprise buyers choose between them for a specific business scenario?
</Note>

## 1. Product overview

### 1.1. Quick BI

Quick BI is a next-generation intelligent BI service platform built for cloud users. It delivers real-time online analytics on massive datasets, supports drag-and-drop operations, and offers rich visualizations to help you handle data analysis, business data exploration, and report building with ease.

Quick BI supports fully private deployment and meets enterprise needs for data mid-platform analytics and integrated data analysis. It is the only domestic BI product in China named to the Gartner ABI Magic Quadrant for four consecutive years.

### 1.2. YiDA's cool data capabilities

**YiDA** is DingTalk's official low-code app development platform. It helps organizations build apps quickly, saving both money and time. YiDA fits a wide range of scenarios, including enterprise digital transformation, project management, marketing and customer management systems, and new retail supply chain management.

Quick BI and YiDA are both enterprise-grade digital productivity tools developed independently by Alibaba Group. Quick BI focuses more on data visualization, processing, and analysis, while YiDA focuses more on enterprise-grade low-code app development, covering forms, workflows, reports, work Automation, and collaborative office.

Combining YiDA Dedicated with Quick BI covers the vast majority of data analysis and visualization work. This combination enables agile business innovation while also aggregating process data for analysis and turning metrics into visualizations.

As a digital productivity platform for organizations of all sizes, YiDA ships with a substantial set of cool data capabilities out of the box. For visualization, it provides reports and data dashboards (with a built-in DataV engine). For data processing, it provides the Data Factory, which offers independent capabilities for datasets, Data Sources, data preparation, and data services. Quick BI, by contrast, is a more specialized BI product. YiDA Dedicated has already completed Data Source integration with Quick BI, and the latest version of Quick BI can directly sync YiDA app data, workflow data, and platform data for personalized analysis.

## 3. Which one to choose: Quick BI or YiDA?

**Choose YiDA for data visualization and analysis when:**

1) All your data resides in YiDA and you want to analyze, view, and manage it entirely within a single product. Pair YiDA's visualization capabilities with the YiDA Data Factory.

2) You need to connect to official DingTalk Data Sources. The YiDA Data Factory is recommended.

3) Your data volume is modest and your metric analysis is not complex. The YiDA Data Factory is a good fit.

**Choose Quick BI for data visualization and analysis when:**

1) You need private BI analysis. Combine private Quick BI with dedicated storage from YiDA Dedicated.

2) You have demanding requirements for data push and data alerts. Quick BI is recommended.

3) You need broad Data Source integration coverage. Quick BI supports virtually All Types available in the industry.

4) Your analysis involves large data volumes (millions of records or more). **Quick BI** is recommended.

5) You need to run complex analyses and expose the results for further Open use. Quick BI is recommended.
