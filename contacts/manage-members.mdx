#### Create, view, update, and delete employee information

Go to [Admin Console](https://oa.dingtalk.io) > Contacts > Member Management > Edit Employee.

You can set information such as name, department, direct supervisor, position, email, role, employee ID, office location, entry date, work information, and role attendance group.

You can enable Executive Mode. If enabled, the mobile number is hidden from all employees. You can also enable Number Hidden, which hides the mobile number on the profile page, and Dedicated External Position, which displays a dedicated external position.
