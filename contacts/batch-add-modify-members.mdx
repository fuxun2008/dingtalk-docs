## 1. Feature Overview

To improve HR management efficiency, DingTalk provides enterprise administrators with Batch Add Members and Batch Modify Member Information. By importing Excel files, you can quickly add or update large amounts of employee information and avoid repetitive manual work.

## 2. Use Cases

Use this feature when:

*   An enterprise creates a new DingTalk organization or establishes a new department.
    
*   An enterprise runs campus recruiting or another large-scale recruiting process.
    
*   An enterprise works on a project with external partners such as suppliers or customers.
    
*   You need to add members or modify member information in bulk.
    

## 3. Procedure

Administrators with permission can go to [Admin Console](https://oa.dingtalk.io) > Contacts > Members> Batch Edit > Bulk Import / Bulk Export.

![](https://img.alicdn.com/imgextra/i4/O1CN01jgZFXRjPS6C5m0ZW_!!6000000007676-2-tps-2844-782.png)

For batch member addition, download the standard template on the Batch Import Members page, fill in member information, and upload it back to DingTalk to quickly add new members to Enterprise Contacts.

For bulk export or modification, export the standard template from the Export/Modify Members page, modify member information in the file, and upload it back to DingTalk to quickly modify multiple members.

### Batch Add Members

#### Go to Batch Import

Go to [Admin Console](https://oa.dingtalk.io) > Contacts > Members > Batch Edit > Bulk Import > Download Template.

![](https://img.alicdn.com/imgextra/i4/O1CN01ptcKYP3BwdL5ch7A_!!6000000002919-2-tps-2770-1110.png)

#### Fill in Employee Information

After downloading the template, refer to the sample text in the first row and the filling instructions to enter the new employee information.

![](https://img.alicdn.com/imgextra/i2/O1CN01LMvGx3RHuBG5m0ZO_!!6000000004809-2-tps-2844-774.png)

#### Delete the Sample Row

After filling in the file, delete the first row of sample text and save the file.

#### Upload the File

On the Batch Import Members page, click Upload File, select the employee information file, and click Import. The new members will be added to Enterprise Contacts.

![](https://img.alicdn.com/imgextra/i4/O1CN01Fpn27VbaIXF4bV8U_!!6000000005097-2-tps-2268-902.png)

### Batch Modify Member Information

#### Export Member Information

Go to [Admin Console](https://oa.dingtalk.io) > Contacts > Members> Batch Edit > Bulk Export, then click Export/Modify Members > Export.

![](https://img.alicdn.com/imgextra/i2/O1CN014ARSAbqmrsG5P6C8_!!6000000006206-2-tps-2662-1034.png)

#### Select Departments

Select the departments whose information needs to be modified, then click Confirm.

![](https://img.alicdn.com/imgextra/i4/O1CN01gBkpbc7NahI4SBes_!!6000000005071-2-tps-2194-1152.png)

#### Download the Exported File

When the page shows that Contacts export succeeded, click Download.

![](https://img.alicdn.com/imgextra/i1/O1CN01gN53LonvcrG5WOkK_!!6000000000268-2-tps-2720-584.png)

#### Modify the File

Open the downloaded file and modify the existing information according to the filling instructions.

![](https://img.alicdn.com/imgextra/i3/O1CN01QCGBTUjuk3F5kUw8_!!6000000006082-2-tps-2832-860.png)

#### Upload the Modified File

Upload and import the saved file.

![](https://img.alicdn.com/imgextra/i4/O1CN01aanodNTqmrF5YA7O_!!6000000004202-2-tps-2734-996.png)

## 4. FAQs

### Q: Why Does Upload or Export Fail?

A: Try refreshing the page, or log in to the Admin Console again with another browser. Google Chrome is recommended for better compatibility.
