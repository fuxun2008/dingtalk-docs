#### 1. Configure the Contacts Organization Structure

The Contacts organization structure can be configured in the desktop Admin Console, on the mobile enterprise management page, or through API.

#### 2. Configure Employee Attribute Fields in Contacts

You can configure:

*   Contacts display style
    
*   Department path display style
    

Path: Go to [Admin Console](https://oa.dingtalk.io) > Contacts > Profile Management.
