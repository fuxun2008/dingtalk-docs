钉钉企业邮箱是基于钉钉打造的原生企业邮箱产品，与钉钉内许多应用组成协同办公套件，提升用户工作效率。钉钉企业邮箱具备海量吞吐、负载均衡、资源动态调度扩展、数据多副本冗余存储等技术特点，为用户提供高安全、高性能、高稳定的邮件基础服务。

---

钉钉企业邮箱功能列表：

| 功能点 | 说明 |
| --- | --- |
| 邮箱容量 | 不限容量 |
| 邮箱账号 | 5账号起售 |
| **管理侧功能** |  |
| 域名管理 | 支持添加子域名、域别名 |
| 邮箱搬家 | ✅ |
| 邮件组管理 | 支持多种邮件组管理 |
| 公共邮箱 | ✅ |
| 分级管理员 | ✅ |
| 账号回收站 | ✅ |
| 第三方安全客户端管理 | ✅ |
| 收信黑名单 | ✅ |
| 收信白名单 | ✅ |
| 邮件规则 | ✅ |
| 外部账号警示 | ✅ |
| 风险链接 | ✅ |
| 日志查询 | ✅ |
| 邮件撤回 | ✅ |
| **用户侧功能** |  |
| 智能助手 | 邀测中 |
| 一键迁移 dingtalk 邮箱数据 | 支持一键迁移 dingtalk 个人邮箱邮件历史数据，同时未来接受的邮件也会同步到钉钉企业邮箱中 |
| 钉钉邮箱助手 | 通过钉钉邮箱助手在钉钉消息中收取多个邮箱的新邮件提醒，在钉钉上不错过任何一封邮件，用户也可在设置中自定义接受邮件提醒的账号 |
| 免密登录邮箱 | 管理员分配账号后，员工只要登录钉钉即可使用，更加安全便捷 |
| 邮箱日历同步 | 支持通过钉钉日历发送邮件邀约，将日程与会议集于一处 |
| DING提醒未读收件人 | 支持查看收件人已读/未读，可DING提醒未读收件人去查邮件，重要信息不再错过 |
| 发送钉钉群邮件 | 可在组织内部群中创建群邮件组，一键发送群邮件 |
| 在IM中发邮件 | 可在钉钉联系人聊天窗口中直接给对方写邮件 |
| 转发到聊天 | 将邮件转发到钉钉聊天消息中 |
| 设为钉钉待办 | 支持将邮件设为代办，实时跟进重要事项 |
| 发起钉钉会议 | 在邮件中一键发起会议邀约 |
| 邮箱设置 | 登录日志、收发删除邮件操作查询、邮件到达提醒设置、签名设置、假期自动回复、收件规则、自助转发、黑白名单、反垃圾、邮件阅读等等 |
| 邮件代收代发 | 添加其他邮箱账号，在钉钉企业邮箱邮箱统一代收代发。 |
| 正文快捷键功能 | 钉钉企业邮箱天然具备了当今互联网产品的一些热门功能，如@，-p,-d，可以在邮件的正文直接@某人，@和-p,-d组合，可以快速地给自己部门的同事发邮件。 |
| 邮件机密模式 | 通过机密模式发送邮件和附件，从而保护敏感信息。功能包括：邮件水印、设置邮件有效期，超过有效期后电子邮件内容将不可见、禁止转发复制和下载等。 |
| 邮件撤回 | 让误发送的邮件便捷的收回。 |
| 群发单显 | 群发邮件时可让每个收件人一对一收到，体现关怀同时保护了收件人邮件地址信息。 |
| 会话模式 | 按主题将邮件分类的浏览模式，在同一个会话里展示相关邮件的来往情况。 |
| 疑似垃圾邮件提醒 | 对于被拦截的垃圾邮件，系统每天进行提醒，以免错过重要的邮件，可便捷地根据需要进行开启和关闭提醒功能。 |
| 邮件标签 | 为邮件添加多个分类标签，个性化对邮件进行分类和管理，可随时查看同一标签的所有邮件。 |
