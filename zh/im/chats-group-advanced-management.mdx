群主和群管理员可以进入群管理，查看和配置高级群控制项。

## 打开群管理

1.  打开群聊。
    
2.  点击右上角的齿轮图标。
    
3.  选择 **群管理**。

## 群管理中的设置

| 设置 | 用途 |
| --- | --- |
| **管理员** / **添加** | 添加群管理员。 |
| **禁言设置** | 打开群禁言相关设置。 |
| **群权限设置** | 管理指定群功能的使用权限。 |
| **群快捷栏** | 管理群快捷栏。 |
| **入群许可** | 管理新成员入群方式。 |
| **新成员可查看聊天记录** | 管理新成员可查看的历史消息范围。 |
| **群日历** | 打开群日历设置。 |
| **群可接收邮件** | 管理群是否可以接收邮件。 |
| **群文件同步钉盘** | 管理群文件自动同步至钉盘。 |
| **禁止群成员私聊** | 管理群内私聊入口。 |
| **转让群主** | 将群主身份转让给其他成员。 |

## 群权限设置

打开 **群权限设置**，可管理以下权限：

*   **谁可以@所有人**
    
*   **谁可以在群内发 DING**
    
*   **谁可以把群消息置顶**
    
*   **谁可以置顶群动态**
    
*   **谁可以上传文件、文件夹和钉盘文件？**
    
*   **谁可以在群里发起视频和语音会议**
