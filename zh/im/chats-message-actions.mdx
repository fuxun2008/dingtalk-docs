消息操作用于处理会话中的单条消息；会话操作用于管理会话列表中的显示和通知方式。可用操作可能因消息类型、发送者、会话类型和发送时间而异。

## 打开消息操作菜单

1.  打开 **消息**。
    
2.  打开一个会话。
    
3.  右键点击要处理的消息。
    
4.  在菜单中选择操作。
    

## 消息操作

| 操作 | 说明 |
| --- | --- |
| **复制** | 复制消息内容。 |
| **转发** | 打开消息转发流程。 |
| **回复** | 回复该消息。 |
| **撤回** | 在仍允许撤回时，撤回自己发送的消息。 |
| **重新编辑** | 将消息内容重新放入输入框，以便编辑后再次发送。 |
| **多选** | 选择多条消息并执行批量操作。 |
| **更多** | 显示可用的更多消息操作。 |

## 查看消息编辑记录

部分消息旁会显示消息操作按钮，可用于查看编辑记录。

1.  打开 **消息**，然后进入会话。
    
2.  将鼠标移到需要查看的消息附近。
    
3.  点击消息旁的操作按钮。
    
4.  选择 **消息编辑记录**。
    

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/r4mlQ5bJLwprBlxo/img/c1b5d965-2bca-455b-8672-6fb56da3c06a.png)

消息编辑记录会显示在会话右侧。

## 从会话列表管理会话

1.  打开 **消息**。
    
2.  在会话列表中找到目标会话。
    
3.  右键点击会话。
    
4.  选择操作。
    

| 操作 | 说明 |
| --- | --- |
| **置顶会话** | 将会话置顶。 |
| **标为未读** | 将会话标为未读。 |
| **消息免打扰** | 为会话开启消息免打扰。 |
| **移除** | 从会话列表中隐藏该会话。 |
| **个人信息** | 打开个人信息或会话信息。 |
| **清空聊天记录** | 清空该会话的本地聊天记录。 |
