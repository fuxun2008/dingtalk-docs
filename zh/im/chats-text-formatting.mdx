富文本格式可以让较长的消息更易阅读，适合用于发送工作进展、总结或待办事项。

## 打开格式工具栏

1.  打开会话。
    
2.  点击消息输入框中的 **Aa**。
    

![](https://img.alicdn.com/imgextra/i4/O1CN01fxhCxwcqG4K3xTM6_!!6000000005764-2-tps-1950-1256.png)

格式工具栏会显示在输入框上方。

## 可用格式

| 选项 | 用途 |
| --- | --- |
| **正文** | 选择文本样式。 |
| **加粗** | 加粗重要内容。 |
| **文字颜色** | 更改所选文本的颜色。 |
| **斜体** | 将所选文本设为斜体。 |
| **删除线** | 为不再有效的内容添加删除线。 |
| **无序列表** | 创建项目符号列表。 |
| **有序列表** | 创建编号列表。 |
| **链接** | 添加超链接。 |
| **清除格式** | 清除所选文本的格式。 |

![](https://img.alicdn.com/imgextra/i3/O1CN01A8pgc3PVu4B3xTM6_!!6000000002743-2-tps-1950-1256.png)

## 发送格式化消息

1.  点击 **Aa**。
    
2.  输入消息。
    
3.  选择需要设置格式的文本。
    
4.  在工具栏中选择格式。
    
5.  点击 **发送**。
