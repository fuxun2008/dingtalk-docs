你可以在群设置中管理群信息、个人偏好和群级别功能。

打开群聊，然后点击右上角的齿轮图标，即可进入群设置。

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/oJGq75kVPQdXylAK/img/0589272c-5df2-4335-9e9c-70ef2b0d1a3a.png)

## 群信息

| 设置 | 说明 |
| --- | --- |
| **群名称** | 查看或修改群名称。 |
| **群公告** | 打开群公告。 |
| **邀请加入群** | 打开群邀请选项。 |

## 个人群设置

以下设置仅影响你在当前群聊中的使用体验。

| 设置 | 说明 |
| --- | --- |
| **我在本群的昵称** | 设置你在当前群聊中的显示名称。 |
| **群别名** | 为当前群聊设置本地别名。 |
| **置顶会话** | 将群聊置顶。 |
| **消息免打扰** | 为群聊开启消息免打扰。 |

## 群管理

打开 **群管理**，可管理群管理员、群权限、入群规则和其他群级别功能。

| 设置 | 说明 |
| --- | --- |
| **管理员** / **添加** | 添加群管理员。 |
| **禁言设置** | 打开群禁言相关设置。 |
| **群权限设置** | 管理群功能的成员权限。 |
| **群快捷栏** | 打开群快捷栏设置。 |
| **入群许可** | 管理新成员的入群方式。 |
| **新成员可查看聊天记录** | 设置新成员可查看的历史消息范围。 |
| **群日历** | 打开群日历设置。 |
| **群可接收邮件** | 设置群是否可以接收邮件。 |
| **群文件同步钉盘** | 设置群文件自动同步至钉盘。 |
| **禁止群成员私聊** | 关闭群内私聊入口。 |
| **转让群主** | 将群主身份转让给其他成员。 |

## 清空消息或退出群聊

*   清空本地消息：打开群设置 > **清空聊天记录**。
    
*   退出群聊：打开群设置 > **退出群**。
