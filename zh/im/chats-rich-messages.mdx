消息输入框提供发送文件和启动关联工作的快捷入口。你可以直接在会话中共享材料、创建日程、发送代码片段或打开其他工具。

## 从会话中发送文件

1.  打开会话。
    
2.  点击消息输入框中的上传图标。
    
![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/Pd6l2Z7PyQG3yl7M/img/a141b9d0-38e1-4ff5-9f71-ada0b21fa2da.png)
    
3.  选择以下选项之一：
    
    *   **上传文件**
        
    *   **上传文件夹**
        
    *   **发送钉盘文件**
        
    *   **发送钉钉文档**
        
    
![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/meonarbj1VAM0qXx/img/8deccda1-c40c-4e42-a240-32e0e802f5e9.png)
    
4.  完成文件或文档选择。
    

使用 **上传文件** 发送电脑中的本地文件、图片或视频；使用 **上传文件夹** 发送整个文件夹；使用 **发送钉盘文件** 或 **发送钉钉文档** 发送已存储在钉钉中的内容。

## 打开输入框快捷功能

1.  打开会话。
    
2.  点击消息输入框中的 **+**。
    
3.  选择需要使用的快捷功能。
    

| 快捷功能 | 用途 |
| --- | --- |
| **通讯录** | 选择或分享联系人。 |
| **代码片段** | 以结构化格式发送代码。 |
| **钉钉文档** | 从聊天中使用钉钉文档。 |
| **新建日程** | 创建与当前讨论相关的日程。 |
| **视频会议** | 从聊天中发起视频会议。 |
| **邮箱** | 从聊天中进入邮件相关流程。 |

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/Pd6l2Z7PyQG3yl7M/img/95702f88-e367-4dc2-8841-0575c7a7bd35.png)

## 浏览会话文件

打开会话，然后点击右上角的文件或文件夹图标，即可查看会话中共享的文件。
