单聊适合一对一沟通，可用于快速提问、跟进事项，或讨论不需要群聊参与的话题。

## 发起单聊

1.  点击钉钉桌面端顶部的搜索框。
    
2.  输入联系人姓名。
    
3.  在搜索结果中选择联系人。
    
4.  在输入框中输入消息。
    
5.  按 `Enter`，或点击 **发送**。![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/3BMqYyb9mLdgvqwZ/img/c7e1f962-e939-4975-8065-d9f97ce21557.png)
    

## 搜索单聊记录

1.  打开单聊。
    
2.  点击右上角的搜索图标。
    
3.  保持选中 **聊天记录**。
    
4.  输入关键词。
    
5.  如有需要，使用 **筛选** 缩小搜索范围。
    

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/4EZlweZPLkW4zqxA/img/b19a4e0c-88e9-4e83-8d28-2382758d3422.png)

## 管理单聊

| 操作 | 路径 |
| --- | --- |
| 开启消息免打扰 | 打开会话 > 齿轮图标 > 开启 **消息免打扰** |
| 置顶会话 | 打开会话 > 齿轮图标 > 开启 **置顶会话** |
| 从会话列表开启消息免打扰 | 右键点击会话 > **消息免打扰** |
| 从会话列表置顶 | 右键点击会话 > **置顶会话** |
| 标为未读 | 右键点击会话 > **标为未读** |
| 隐藏会话 | 右键点击会话 > **移除** |
| 清空本地聊天记录 | 右键点击会话 > **清空聊天记录** |

## 从单聊中发起会议

打开单聊，然后点击会话右上角的视频会议图标。
