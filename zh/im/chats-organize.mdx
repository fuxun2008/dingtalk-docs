你可以通过会话列表菜单置顶重要会话、保留待处理提醒，并减少不必要的消息打扰。

## 置顶会话

右键点击会话，然后选择 **置顶会话**。该会话会显示在会话列表靠前的位置。

## 标为未读

右键点击会话，然后选择 **标为未读**。适合在已打开会话后，为自己保留稍后处理的提醒。

## 开启消息免打扰

右键点击会话，然后选择 **消息免打扰**。会话仍会保留在列表中，但不会发送常规通知提醒。

## 隐藏会话

右键点击会话，然后选择 **移除**。该操作会从会话列表中隐藏会话，但不会清空本地聊天记录。

## 清空本地聊天记录

右键点击会话，然后选择 **清空聊天记录**。

| 目标 | 使用的操作 |
| --- | --- |
| 让重要会话保持可见 | **置顶会话** |
| 稍后返回处理会话 | **标为未读** |
| 减少通知打扰 | **消息免打扰** |
| 从会话列表中隐藏会话 | **移除** |
| 清空本地消息记录 | **清空聊天记录** |
