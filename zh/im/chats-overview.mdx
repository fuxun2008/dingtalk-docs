即时通讯是钉钉中集中管理工作沟通的入口。在桌面端，你可以发起单聊、创建群聊、搜索历史消息，以及管理会话的显示方式和通知。

## 打开即时通讯

在钉钉桌面端左侧导航栏中，点击 **消息**。

会话列表会显示最近的单聊和群聊，包括未读标记和最新消息预览。如需查找联系人、群聊、聊天记录、文档、报告、标签、功能或部门，可使用窗口顶部的搜索框。

![](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/3BMqYyb9mLdgvqwZ/img/1ef50ba4-e0f0-4837-a0ef-05f62dc23297.png)

## 发起单聊

1.  点击钉钉桌面端顶部的搜索框。
    
2.  输入联系人姓名。
    
3.  在搜索结果中选择联系人。
    
4.  在输入框中输入消息。
    
5.  按 `Enter`，或点击 **发送**。
    

打开单聊后，该会话会显示在会话列表中，方便你之后继续沟通。

![](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/3BMqYyb9mLdgvqwZ/img/c7e1f962-e939-4975-8065-d9f97ce21557.png)

## 发起群聊

1.  点击钉钉桌面端右上角的 **+**。
    
2.  选择 **发起群聊**。
    
3.  在 **选择联系人** 页面搜索联系人，或从 **好友**、**组织架构**、**群聊** 或 **导入** 中选择。
    
4.  选择要加入群聊的联系人。
    
5.  点击 **确定**。
    

![](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/3BMqYyb9mLdgvqwZ/img/662477ba-1ea5-4c48-a682-c625b670e0ff.png)

## 发送消息

| 操作 | 方法 |
| --- | --- |
| 发送文本消息 | 输入消息后按 `Enter`，或点击 **发送**。 |
| 换行 | 按 `Shift + Enter`。 |
| 设置文本格式 | 点击 **Aa** 打开富文本工具栏。 |
| 静默发送或锁定发送 | 点击 **发送** 旁的下拉箭头，然后选择 **静默发送** 或 **锁定发送**。 |
| 打开快捷功能 | 点击输入框中的 **+**，可使用 **通讯录**、**代码片段**、**钉钉文档**、**新建日程**、**视频会议** 或 **邮箱**。 |

## 搜索消息和文件

打开会话后，点击右上角的搜索图标。系统默认打开 **聊天记录**，输入关键词后，可使用 **筛选** 缩小搜索范围。

![](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/4EZlweZPLkW4zqxA/img/b19a4e0c-88e9-4e83-8d28-2382758d3422.png)

如需浏览会话中共享的文件，点击会话右上角的文件或文件夹图标。

## 管理会话

在会话列表中右键点击会话，可使用置顶、标为未读、消息免打扰、隐藏会话和清空本地聊天记录等操作。

![](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/3BMqYyb9mLdgvqwZ/img/d89ec1ef-d20f-42c5-9005-f593bf9d5076.png)

## 打开群设置

打开群聊，点击右上角的齿轮图标。在群设置中，你可以查看群成员、打开群公告和群邀请、修改群内昵称、开启消息免打扰、进入群管理、清空消息或退出群聊。

![](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/3BMqYyb9mLdgvqwZ/img/1459cf8d-1e98-41b4-b770-c40bc08f4011.png)
