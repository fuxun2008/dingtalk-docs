## 一、功能简介

为了满足企业的不同考勤统计场景需求，钉钉不仅为广大用户提供了基础的考勤统计字段，便于日常考勤统计。也提供了更多可自定义考勤字段设置选项，方便企业更灵活的统计考勤数据。

## 二、适用场景

企业考勤统计报表有个性化需求场景。

## 三、操作流程

管理员打开 **电脑端钉钉 > 工作台 > 考勤打卡 > 考勤统计 > 报表设置 > 字段管理 >** 点击对应字段 **编辑**，字段的编辑有两种模式，分别是 **选项模式** 和 **专家模式**。

<Note>
**操作须知：**

1. **选项模式**：系统自带的字段中可以通过选项模式编辑规则，如应出勤天数、出勤天数、工作时长、出勤班次等；

2. **专家模式**：企业可以自定义函数满足个性化、定制化统计规则，系统提供了运算符，字段和函数可以编写出企业需要的计算逻辑和规则；

3. **专家模式** 需开通 **钉钉专业版**，支持创建年度报表，可跨多月或按年导出数据，满足个性化考勤述求；

4. 考勤 **专家模式** 介绍视频，您可以 **点此查看**。
</Note>

## 四、字段介绍

### 固定字段

*   **姓名、考勤组、部门、工号、职位** 为固定字段，在所有报表内均有展示，且 **不支持** 在报表内 **删除** 或 **编辑**。

### 基础字段

| **基础字段** | **说明** |
| --- | --- |
| 打卡时间 | 为员工在上下班有效打卡的时间。包括以下字段：上班1打卡时间、下班1打卡时间、上班2打卡时间、下班2打卡时间、上班3打卡时间、下班3打卡时间 |
| 打卡结果 | 为根据员工上下班打卡和考勤时间，生成的考勤结果。包括以下字段：上班1打卡结果、下班1打卡结果、上班2打卡结果、下班2打卡结果、上班3打卡结果、下班3打卡结果 |
| 关联的审批单 | 为请假、出差、补卡等关联到考勤的审批单 |

### 出勤统计字段

| **出勤统计字段** | **说明** |
| --- | --- |
| 应出勤天数 | 统计时间段内排班的天数。 但在统计时间段内法定节假日、休息日或未排班，则不会统计为应出勤天数 |
| 补卡次数 | 为员工在统计时段内所有已通过的补卡次数 |
| 出勤班次 | 为员工当天所上的班次 |
| 出勤天数 | 展示员工在统计时段内打卡的天数，支持自定义配置出勤天数规则 |
| 休息天数 | 展示员工在统计时段内打卡的天数，支持自定义配置出勤天数规则 |
| 工作时长 | 展示员工打卡总时长，支持自定义配置规则 |
| 出差时长 | 为员工在统计时段内所有审批通过的出差，在班次时间段内的出差总时长。(注：出差同行人的数据也会自动同步) |
| 外出时长 | 为员工在统计时段内所有审批通过的外出，在班次时间段内的外出总时长 |
| 考勤结果 | 为员工每天的打卡结果 |
| 班次 | 为员工当天所排的班次 |

### 异常统计字段

| **异常统计字段** | **说明** |
| --- | --- |
| 迟到次数 | 为员工在统计时段内，计为上班迟到的次数 |
| 迟到时长 | 为员工在统计时段内，计为上班迟到的总时长 |
| 严重迟到次数 | 为员工在统计时段内，计为严重迟到的次数 |
| 严重迟到时长 | 为员工在统计时段内，计为严重迟到的总时长 |
| 旷工迟到次数 | 为员工在统计时段内，计为旷工迟到的次数 |
| 早退次数 | 为员工在统计时段内下班早退的次数 |
| 早退时长 | 为员工在统计时段内下班早退的总时长 |
| 上班缺卡次数 | 为员工在统计时段内上班缺卡的次数 |
| 下班缺卡次数 | 为员工在统计时段内下班缺卡的次数 |
| 旷工迟到天数 | 为员工在统计时段内旷工迟到的次数 |

### 请假统计字段

| **请假统计字段** | **说明** |
| --- | --- |
| 请假 | 为员工在统计时段内，通过的请假审批单时长之和 |

### 加班统计字段

| **加班统计字段** | **说明** |
| --- | --- |
| 加班审批单统计 | 为员工在审批统计时段内工作日、休息日、节假日加班时长之和 |
| 工作日加班 | 为员工在统计时段内，通过的工作日加班时长之和 |
| 休息日加班 | 为员工在统计时段内，通过的休息日加班时长之和 |
| 节假日加班 | 为员工在统计时段内，通过的节假日加班时长之和 |

## 五、常见问题

<AccordionGroup>
  <Accordion id="q1" title="出勤天数如何计算？">

出勤天数的统计是按照管理员自行设置的出勤天数规则计算的，若未设置，则按照系统默认规则计算，即：按照打卡计算，无论是休息还是排班有打卡就会统计出勤。支持自定义配置出勤天数规则，管理员打开 **电脑端钉钉 > 工作台 > 考勤打卡 > 考勤统计 > 报表设置 > 字段管理 >** 点击 **出勤天数** 字段 **编辑**。

  </Accordion>
  <Accordion id="q2" title="应出勤天数计算错误？">

如果月度汇总报表中没有应出勤天数的字段，需要管理员先在报表中添加该字段，管理员操作路径： **电脑端钉钉 > 工作台 > 考勤打卡 > 考勤统计 > 报表设置 > 字段管理 > 应出勤天数 > 编辑**，保存即可。

<Note>
**操作须知：**

1. 自由工时不会统计应出勤天数；

2. 没有排班不会计入应出勤天数；

3. 旧版考勤报表不支持设置应出勤天数统计规则，需切换新版考勤报表设置。
</Note>

  </Accordion>
</AccordionGroup>
