DingTalk 国际版考勤为 **标准版**，面向简单上下班考勤场景，免费支持大多数企业的排班与工时计算，涵盖以下核心能力：

- 考勤规则设置
- 员工排班
- 员工手机打卡、考勤机打卡
- 假勤审批
- 考勤统计和报表
- 考勤确认

## 标准版功能清单

下表列出标准版支持的功能，部分能力在标准版下有使用限制（已在「说明」中标注）。

| 功能模块 | 功能 | 说明 |
| --- | --- | --- |
| 基础设置 | 工作日历 | 自动同步元旦/春节等国家法定假日（标准版不支持自定义节假日） |
| 基础设置 | 工时制度 | 支持标准工时制（标准版不支持综合工时制、不定时工时制） |
| 基础设置 | 假勤审批 | 支持通过请假、外出、出差、补卡等审批处理考勤异常 |
| 考勤组管理 | 考勤人员 | 支持按人、部门等快速选人创建考勤组，新员工加入部门自动同步 |
| 考勤组管理 | 考勤时间 | 支持固定班制、排班制，也支持自由工时（满足工作时长即可） |
| 考勤组管理 | 考勤方式 | 支持地点打卡、Wi-Fi 打卡、蓝牙打卡、考勤机打卡等多种方式 |
| 考勤组管理 | 关联规则 | 支持按考勤组设置加班规则、补卡规则、外勤打卡、外出出差规则等 |
| 班次管理 | 固定班次 | 支持固定班次，支持一天一次/多次上下班 |
| 班次管理 | 弹性班次 | 支持早到早走、晚到晚走、晚走第二天可晚到等 |
| 班次管理 | 异常规则 | 支持班次卡点考勤迟到、早退异常设置 |
| 排班管理 | 按人排班 | 支持按人排班 |
| 排班管理 | 按周期排班 | 支持设置 1 个或多个周期进行循环排班 |
| 员工打卡 | 考勤机打卡 | 钉钉考勤机、门禁支持指纹、人脸打卡 |
| 员工打卡 | 手机打卡 | 支持 GPS 精准定位打卡、公司 Wi-Fi 与考勤机蓝牙打卡 |
| 补卡管理 | 补卡次数 | 支持按月设置补卡次数 |
| 补卡管理 | 补卡类型 | 支持设置迟到/早退/缺卡等异常类型是否可补卡 |
| 补卡管理 | 补卡时限 | 支持设置补卡申请时间限制 |
| 加班管理 | 加班类型 | 支持独立设置工作日/休息日/节假日加班规则 |
| 加班管理 | 加班时段 | 支持设置班前、班后是否计算加班 |
| 加班管理 | 加班时长计算方式 | 支持按打卡时长/审批时长/在审批时段内按打卡时长计算 |
| 加班管理 | 加班时长取整 | 标准版仅支持向下取整 |
| 加班管理 | 扣除休息时间 | 支持按时段扣除、按加班时长扣除 |
| 加班管理 | 加班补偿 | 支持转加班费或调休，或由员工自主选择 |
| 加班管理 | 风险预警 | 支持按日/周/月设置加班预警额度 |
| 假期管理 | 手动发假 | 支持手动发放假期余额 |
| 假期管理 | 定期发假 | 支持每年/每月按规则发放假期余额 |
| 假期管理 | 加班转调休 | 支持根据加班时长自动转调休 |
| 考勤统计 | 按日/周/月查看团队统计 | 支持实时查看员工出勤记录与结果 |
| 考勤统计 | 按日/周/月查看员工统计 | 支持员工自助查看考勤记录与结果 |
| 考勤报表 | 打卡原始记录 | 支持打卡原始记录、打卡时间与疑似作弊行为记录 |
| 考勤报表 | 汇总统计报表 | 支持按天/月汇总导出报表 |
| 考勤报表 | 修改考勤结果 | 支持管理员逐个/批量修改考勤结果 |
| 考勤报表 | 考勤确认 | 支持发送考勤确认，让员工及时确认考勤数据 |
