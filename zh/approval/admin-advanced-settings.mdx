## 一、操作说明

<Note>
管理员可以操作高级设置；

高级设置作用于当前的 **单个表单**；

包括：发起人设置、审批人设置、数据标题/摘要设置、权限设置、填写提醒等；
</Note>

## 二、操作前提

*   仅审批管理员才能进行流程设计，因此需要先成为审批管理员

非审批管理员，进入钉钉OA审批，点击【设置】，点击【创建审批单】，点击【申请管理员权限】，点击“提交”。

### 2、发起人设置

<Note>
当前区块所有的设置项，仅对 **当前表单** 的 **发起人和评论人** 生效
</Note>

<Frame>

![截屏2025-06-24 20.35.42.png](https://img.alicdn.com/imgextra/i1/O1CN01LROkJusEQXL3GQ5K_!!6000000005136-2-tps-1608-922.png)
</Frame>

<AccordionGroup>
<Accordion id="q1" title="撤销设置">

允许发起人撤销，审批通过的审批单

默认设置：不允许撤销

区间范围：通过时间在1-180天

允许发起人撤销，审批中的审批单

默认设置：允许撤销

区间范围：不支持设置，最长180天

允许评论人撤销，表单上的评论

默认设置：允许撤销，不能更改

区间范围：评论后的1-30分钟内

</Accordion>
<Accordion id="q2" title="修改设置">

允许发起人修改，审批通过的审批单

默认设置：不允许修改

区间范围：通过时间在1-180天，修改次数1-3次

开启后：允许发起人修改审批单

</Accordion>
<Accordion id="q3" title="提交后选审批人">

允许发起人先提交审批单，再选择审批人

默认设置：允许

</Accordion>
<Accordion id="q4" title="发送到聊天">

允许发起人将审批单发送单群聊/单聊

默认设置：允许

</Accordion>
<Accordion id="q5" title="多部门选项">

当发起人在多个部门时，所在部门的默认值

默认设置：发起时手动选择

可设置按照【智能人事】应用中的主部门

</Accordion>
<Accordion id="q6" title="代他人提交">

当前流程允许由他人代为发起

默认设置：不允许

开启后：可以由他人代提交

</Accordion>
</AccordionGroup>

### 3、审批人设置

<Note>
当前区块所有的设置项，对审批人生效
</Note>

<Frame>

![高级设置-审批人设置.png](https://img.alicdn.com/imgextra/i2/O1CN01j1wJS2mxB6J2z349_!!6000000002090-2-tps-1470-999.png)
</Frame>

<AccordionGroup>
<Accordion id="q7" title="审批人去重">

同一个审批人多次出现时，去重

默认设置：不去重

设置选项：

*   中流程中出现多次时，仅保留第一个

*   仅在连续出现时，自动去重

审批人和发起人是同一个人，审批自动通过

默认设置：关闭

</Accordion>
<Accordion id="q8" title="审批意见">

审批人必须填写审批意见

默认设置：关闭

区间范围：支持设置审批意见填写提示

审批人评语仅管理员和审批人可见

默认设置：关闭

开启后：审批意见对发起人不可见

</Accordion>
<Accordion id="q9" title="允许加签">

审批人是否可以在审批过程中添加审批人

默认设置：允许

允许发起人加签

默认设置：不允许

</Accordion>
<Accordion id="q10" title="手写签名">

审批人是否必须填写手写签名，才能同意审批

默认设置：关闭

设置选项：

*   使用上次签名：第一次签名后，可以在后续审批中重复使用

*   每次重新签名：每次审批都需要重新手写签名

</Accordion>
<Accordion id="q11" title="审批相关消息通知">

审批拒绝时，通知之前审批通过的人

默认设置：开启

审批拒绝时，通知同个节点，其他或签的审批人

默认设置：开启

审批拒绝时，通知同个节点，其他会签的审批人

默认设置：开启

审批同意时，通知同个节点，其他或签的审批人

默认设置：开启

</Accordion>
<Accordion id="q12" title="退回审批">

退回后再次提交，是否需要重新审批

默认设置：需要重新开始审批

付费能力：设置跳过已审批的节点，回到退回的节点

</Accordion>
<Accordion id="q13" title="限时审批">

付费能力

默认设置：关闭

</Accordion>
<Accordion id="q14" title="显示用户通讯录职位信息">

付费开启

</Accordion>
</AccordionGroup>

### 5、权限管理

<Note>
权限设置仅对应用内的数据查看生效，对管理后台不生效

注意：在这里删除了管理员的数据查看和操作权限，但在基础设置的 **【表单管理员】** 中设置不可管理时，管理员仅仅是在应用内不能操作数据，在 **管理后台仍然可以查看和删除数据**。
</Note>

**管理范围说明**

| 管理范围 | 说明 |
| --- | --- |
| 自己负责的 | 权限组成员自己提交的表单 |
| 全公司 | 公司所有人提交的表单 |
| 同层级 | 权限组成员，同一个主管下所有人提交的表单 |
| 下属的 | 权限组成员自己及其下属提交的表单 |
| 自定义 | 权限组成员自己及指定部门或人员提交的表单 |

**操作权限说明**

| 操作权限 | 说明 |
| --- | --- |
| 查看 | 有该权限的组织成员，可以在OA审批应用内-【数据管理】和表单-【历史记录】中查看管理范围内的审批表单列表和详情 |
| 导出 | 有该权限的组织成员，可以在OA审批应用内-【数据管理】和表单-【历史记录】中导出管理范围内的审批表单明细列表 |
| 删除 | 有该权限的组织成员，可以在OA审批应用内-【数据管理】和表单-【历史记录】、以及表单上删除管理范围内的审批数据 |
