## 一、操作说明

<Note>
管理员可以操作高级设置；

高级设置作用于当前的 **单个表单**；

包括：发起人设置、审批人设置、数据标题/摘要设置、权限设置、填写提醒等；
</Note>

## 二、操作前提

*   仅审批管理员才能进行流程设计，因此需要先成为审批管理员

非审批管理员，进入钉钉OA审批，点击【设置】，点击【创建审批单】，点击【申请管理员权限】，点击”提交”。

### 2、发起人设置

<Note>
当前区块所有的设置项，仅对 **当前表单** 的 **发起人和评论人** 生效
</Note>

| 设置项 | 名称 | 说明 |
| --- | --- | --- |
| **撤销设置** | 允许发起人撤销，审批通过的审批单<br />默认设置：不允许撤销<br />区间范围：通过时间在1-180天 |
|  | 允许发起人撤销，审批中的审批单<br />默认设置：允许撤销<br />区间范围：不支持设置，最长180天 |
|  | 允许评论人撤销，表单上的评论<br />默认设置：允许撤销，不能更改<br />区间范围：评论后的1-30分钟内 |
| **修改设置** | 允许发起人修改，审批通过的审批单<br />默认设置：不允许修改<br />区间范围：通过时间在1-180天，修改次数1-3次<br />开启后：允许发起人修改审批单 |
| **提交后选审批人** | 允许发起人先提交审批单，再选择审批人<br />默认设置：允许 |
| **发送到聊天** | 允许发起人将审批单发送单群聊/单聊<br />默认设置：允许 |
| **多部门选项** | 当发起人在多个部门时，所在部门的默认值<br />默认设置：发起时手动选择<br />可设置按照【智能人事】应用中的主部门 |
| **代他人提交** | 当前流程允许由他人代为发起<br />默认设置：不允许<br />开启后：可以由他人代提交 |

### 3、审批人设置

<Note>
当前区块所有的设置项，对审批人生效
</Note>

| 设置项 | 名称 | 说明 |
| --- | --- | --- |
| **审批人去重** | 同一个审批人多次出现时，去重<br />默认设置：不去重<br />设置选项：<br />中流程中出现多次时，仅保留第一个<br />    <br />仅在连续出现时，自动去重 |
|  | 审批人和发起人是同一个人，审批自动通过<br />默认设置：关闭 |
| **审批意见** | 审批人必须填写审批意见<br />默认设置：关闭<br />区间范围：支持设置审批意见填写提示 |
|  | 审批人评语仅管理员和审批人可见<br />默认设置：关闭<br />开启后：审批意见对发起人不可见 |
| **允许加签** | 审批人是否可以在审批过程中添加审批人<br />默认设置：允许 |
|  | 允许发起人加签<br />默认设置：不允许 |
| **手写签名** | 审批人是否必须填写手写签名，才能同意审批<br />默认设置：关闭<br />设置选项：<br />使用上次签名：第一次签名后，可以在后续审批中重复使用<br />    <br />每次重新签名：每次审批都需要重新手写签名 |
| **审批相关消息通知** | 审批拒绝时，通知之前审批通过的人<br />默认设置：开启 |
|  | 审批拒绝时，通知同个节点，其他或签的审批人<br />默认设置：开启 |
|  | 审批拒绝时，通知同个节点，其他会签的审批人<br />默认设置：开启 |
|  | 审批同意时，通知同个节点，其他或签的审批人<br />默认设置：开启 |
| **退回审批** | 退回后再次提交，是否需要重新审批<br />默认设置：需要重新开始审批<br />付费能力：设置跳过已审批的节点，回到退回的节点 |
| **限时审批** | 付费能力<br />默认设置：关闭 |
| **显示用户通讯录职位信息** | 付费开启 |

### 5、权限管理

<Note>
权限设置仅对应用内的数据查看生效，对管理后台不生效

注意：在这里删除了管理员的数据查看和操作权限，但在基础设置的 **【表单管理员】** 中设置不可管理时，管理员仅仅是在应用内不能操作数据，在 **管理后台仍然可以查看和删除数据**。
</Note>

**操作入口**

OA审批应用内-【数据管理】

<Frame>

![截屏2025-06-25 14.17.42.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/2M9qP5jJXRgRYO01/img/656a00f9-0241-4d11-9000-14c0aad392e3.png)
</Frame>

表单-【历史记录】

<Frame>

![截屏2025-06-25 14.17.55.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/2M9qP5jJXRgRYO01/img/3084b536-f29b-4cf6-9a1d-2ed3a7b8aec2.png)
</Frame>

**默认权限组：所有【OA审批】管理员**

可以查看、导出、删除全公司的审批数据

<Frame>

![截屏2025-06-24 21.37.39.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/2M9qP5jJXRgRYO01/img/274762ad-1afd-4563-9989-edb1308313a7.png)
</Frame>

**管理范围说明**

| 管理范围 | 说明 |
| --- | --- |
| 自己负责的 | 权限组成员自己提交的表单 |
| 全公司 | 公司所有人提交的表单 |
| 同层级 | 权限组成员，同一个主管下所有人提交的表单 |
| 下属的 | 权限组成员自己及其下属提交的表单 |
| 自定义 | 权限组成员自己及指定部门或人员提交的表单 |

**操作权限说明**

| 操作权限 | 说明 |
| --- | --- |
| 查看 | 有该权限的组织成员，可以在OA审批应用内-【数据管理】和表单-【历史记录】中查看管理范围内的审批表单列表和详情 |
| 导出 | 有该权限的组织成员，可以在OA审批应用内-【数据管理】和表单-【历史记录】中导出管理范围内的审批表单明细列表 |
| 删除 | 有该权限的组织成员，可以在OA审批应用内-【数据管理】和表单-【历史记录】、以及表单上删除管理范围内的审批数据 |
