## 一、角色说明

<Note>
在钉钉OA审批中，非管理员，但是可以管理数据的主管、专员等操作人成为数据管理人；

数据管理人的操作权限：查看、导出、删除权限范围内的数据

数据管理人可以在【OA审批】-【数据中心】、【OA审批】-表单-【历史记录】中进行数据管理操作

**注**：数据管理人的操作管理范围、操作权限等由审批管理员在表单中设置
</Note>

## 二、操作前提

审批应用内的数据权限，默认只能“ **查看**”“ **本人发起、参与**”的审批单，如果想要获取更大的数据范围和更多的操作权限，需要由管理员在表单中【**新建权限组**】；

在表单-【编辑】-【高级设置】-【权限管理】中，【新增权限组】，并设置【管理范围】和【操作权限】

**管理范围说明**

| 管理范围 | 说明 |
| --- | --- |
| 自己负责的 | 权限组成员自己提交的表单 |
| 全公司 | 公司所有人提交的表单 |
| 同层级 | 权限组成员，同一个主管下所有人提交的表单 |
| 下属的 | 权限组成员自己及其下属提交的表单 |
| 自定义 | 权限组成员自己及指定部门或人员提交的表单 |

**操作权限说明**

| 操作权限 | 说明 |
| --- | --- |
| 查看 | 有该权限的组织成员，可以在OA审批应用内-【数据管理】和表单-【历史记录】中查看管理范围内的审批表单列表和详情 |
| 导出 | 有该权限的组织成员，可以在OA审批应用内-【数据管理】和表单-【历史记录】中导出管理范围内的审批表单明细列表 |
| 删除 | 有该权限的组织成员，可以在OA审批应用内-【数据管理】和表单-【历史记录】、以及表单上删除管理范围内的审批数据 |
