## 三、基本操作

流程设计包含以下四类基本操作：

| 基本操作 | 说明 |
| --- | --- |
| 添加节点 | 在流程中添加发起人、审批人、抄送人、办理人等节点 |
| 设置节点属性 | 选择节点操作人类型，并按照类型完成对应设置 |
| 设置节点权限 | 调整各节点对表单字段的操作权限 |
| 添加分支 | 设置分支条件、设置分级条件流程 |

### 一）添加节点

点击 **+** 可添加审批人、抄送人、办理人、条件分支等。

<Frame>

![在流程设计中点击加号添加节点](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/YdgOk2b0JJJNXq4B/img/1991fcb9-5976-4331-bc66-5332c816016e.png)
</Frame>

| 审批节点类型 | 解释 | 详细说明 |
| --- | --- | --- |
| 发起人 | 发起人节点是一个审批流程的起始点，在发起节点，可以配置谁能提交这个审批单，发起人在填写表单时可以填写哪些字段等等 | 默认节点<br />不可修改节点名称<br />发起后，在流程中心"我发起的"分类中查看<br />可设置表单中字段操作权限，支持可编辑、只读、隐藏 |
| 审批人 | 可以对审批单进行"同意"、"拒绝"、"转交"、"回退"、"加签"等操作 | 可选节点<br />可修改节点名称<br />审批前，在流程中心"待处理的"分类中查看；审批后，在流程中心"我处理的"分类中查看<br />可设置表单中字段操作权限，支持可编辑、只读、隐藏 |
| 抄送人 | 流转到该节点时，没有审核的功能，可以收到对应的审批单，可以进行查看、评论操作 | 可选节点<br />可修改节点名称<br />流转到该节点后，在流程中心"抄送我的"分类中查看<br />可设置表单中字段可见权限，支持只读、隐藏 |
| 办理人 | 可以对审批单进行"提交"、"转交"、"回退"、"加签"、"评论"等操作 | 可选节点<br />可修改节点名称<br />办理前，在流程中心"待处理的"分类中查看；办理后，在流程中心"我处理的"分类中查看<br />可设置表单中字段操作权限，支持可编辑、只读、隐藏 |
| 条件分支 | 通过这个节点可以实现不同情况走不同审批分支<br />详细操作可以查看>>>[如何设置分条件审批](/zh/approval/set-conditional-approval) | 可选节点<br />可修改分支名称<br />支持复制分支<br />支持添加条件：不同条件之间是"且"关系<br />支持添加条件组：不同条件组之间是"或"关系<br />执行时**按照优先级依次运行**<br />只要有一个分支规则执行通过，其他分支则不再继续尝试，**有且最多只执行一个条件分支** |
| 并行分支 | 付费开通，通过这个节点可以实现多个审批分支同时流转 | 可选节点<br />可修改分支名称<br />支持复制分支<br />支持添加条件：不同条件之间是"且"关系<br />支持添加条件组：不同条件组之间是"或"关系<br />多个分支可按照设定的规则**同时执行** |
| 连接器 | 付费开通，通过这个节点可以调用"我的集成"中配置的连接器 | 可选节点 |
| 自动化 | 付费开通，通过这个节点可以配置自动化任务 | 可选节点 |

### 二）设置节点属性

#### 1、发起人

发起人是业务事项的申请者，是审批流程的起始点，可以进行表单内容填写并提交。

| 属性 | 说明 |
| --- | --- |
| 发起人类型 | 默认为组织内成员 |
| 谁可以提交 | 与基础设置中的"谁可以发起"保持一致，这里调整后，基础设置也会联动调整 |

<Frame>

![发起人节点属性设置面板](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/WgZOZA8xwkvdrqLX/img/756fccfb-b266-4cc6-915e-17b381ff5936.png)
</Frame>

#### 2、审批人

审批人是业务事项的审核、批准人，可以对审批单进行"同意"、"拒绝"、"转交"、"回退"、"加签"等操作。

**1）审批人属性设置**

| 属性 | 说明 |
| --- | --- |
| 节点名称 | 展示在审批详情页上，对应审批节点的名称，默认是"审批人"<br />可以设置为节点对应的岗位，例如"财务总监"，或者具体审核内容，例如"合同合规性审核" |
| 审批类型 | 支持人工审批、自动通过、自动拒绝<br />默认是人工审批<br />自动通过和自动拒绝通常配合条件分支使用，实现自动审批 |
| 节点审批人 | 节点审批人支持多种类型，灵活满足不同的审批流转需要 |
| 多人审批时的审批方式 | 当多人参与同一个节点时支持依次审批、会签、或签、投票<br />依次审批：多人依次审批，且全部人都同意时，审批才能通过<br />会签：多人同时审批，且全部人都同意时，审批才能通过<br />或签：多人同时审批，且任意一人同意，审批通过；任意一人拒绝时，审批不通过<br />投票：付费开通，多人同时审批，且达到满足要求的同意人数时，审批通过 |
| 审批人为空时的处理方式 | 在设置了审批人为上级、部门负责人、角色等类型时，可能会遇到通讯录设置不完整，导致没有匹配人员等情况，需要设置此时审批人为空时的流转规则<br />自动通过：该节点找不到审批人时，审批单将自动通过<br />自动拒绝：该节点找不到审批人时，审批单将自动拒绝<br />自动转交给管理员：默认转交模板管理员，如果没有模板管理员转给审批管理员<br />指定人员审批：当角色或主管为空时，审批单会自动转交给指定成员，最多指定一人 |

#### 3、抄送人

| 节点抄送人 | 节点抄送人支持多种类型，灵活满足不同的抄送人通知需要 |

#### 4、办理人

办理人是业务事项的具体执行人，没有审核、批准权限，可以对审批单进行"提交"、"转交"、"回退"、"加签"、"评论"等操作。

| 属性 | 说明 |
| --- | --- |
| 节点名称 | 展示在审批详情页上，对应办理节点的名称，默认是"办理人"<br />可以设置为节点对应的岗位，例如"出纳"，或者具体办理事项，例如"合同用印" |
| 节点办理人 | 节点办理人支持多种类型，灵活满足不同的办理人流转需要 |
| 多人办理时的办理方式 | 当多人参与同一个节点时支持依次办理、所有人同时办理、一名办理人处理 |
| 办理人为空时的处理方式 | 在设置了办理人为角色、主管时，可能会遇到通讯录设置不完整，导致没有匹配人员等情况，需要设置此时办理人为空时的流转规则<br />自动通过：该节点找不到办理人时，自动跳过<br />自动转交给管理员：默认转交模板管理员，如果没有模板管理员转给审批管理员<br />指定人员办理：当角色或主管为空时，转交给指定人员办理 |

### 三）设置节点操作权限

在节点属性面板中，切换到「**表单操作权限**」页签，可以设置该节点对表单中各字段的操作权限。

<Frame>

![节点属性中的表单操作权限设置](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/jP2lRYjZmyDkLO8g/img/cb38d7f6-5d7d-460d-9800-94dca7333874.png)

### 四）添加分支

<Note>
条件分支不是传统意义的节点，它同样是流程配置必不可少的功能。

**执行时按照优先级依次运行，只要有一个分支规则执行通过，其他分支则不再继续尝试，有且最多有一个条件分支会被最终通过。**
</Note>
