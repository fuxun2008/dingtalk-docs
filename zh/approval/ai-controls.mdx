## 一、能力概述

<Note>
一句话价值：帮审批人快速掌握表单关键信息，提升决策效率

适用角色：审批人

支持字段：文本、数字、图片等大部分审批控件，暂不支持附件、业务控件组

核心能力：管理员选择控件技能 → 审批人打开表单时自动调用
</Note>

| 使用前 | 使用后 |
| --- | --- |
| 表单内容多，找不到重点 | 文字总结：像秘书一样，一句话总结申请核心内容 |
| 日期、金额、数量等关键信息分散，容易遗漏 | 信息提取：像秘书一样，帮你找出重点信息，结构化展示 |
| 跨国审批，审批单内容看不懂 | 文本翻译：像随行翻译一样，在需要处理审批时提供翻译支持 |
| 图片信息需要逐一查看，效率低 | 图片解读：像老师傅一样解读图片，给出专业判断 |

## 二、适用场景

<Note>
输入：表单内的控件（自定义选择，最多支持10个）

判断依据：默认的4个技能+自定义prompt

输出：面向审批人输出结论
</Note>

prompt 示例：

```text
你是一个有10年经验的项目负责人。
请总结变更内容，并给出变更是否合理的建议。
字数100字以内，总结和建议分行展示。
```

```text
帮我翻译成英语、日语、泰语。
```

### 4、图片解读

prompt 示例：

```text
请分析这家店铺的堆头摆放是否整齐，橱窗中的摆设是否美观，广告标识是否正常张贴。
基于图片给这家店铺打分，并且重点说明扣分原因。
堆头，满分40分，最多只能扣除40分。要求是最少4张图片，每张图最高得分10分，内容不相关的图片不得分。图片有异常的需要根据异常程度扣分，最低得0分，超过4张图片，取得分最高的4张图片。
橱窗，满分30分，要求最少3张图片，其他规则同上。
广告标识，满分30分，要求最少3张图片，其他规则同上。
```

## 五、常见问题

<AccordionGroup>

<Accordion id="q1" title="AI控件谁可以看到？">

AI控件跟其他控件一样，可以按照节点设置可见范围：

<Frame>

![流程节点的字段权限设置界面，AI控件可按节点配置可见范围](https://img.alicdn.com/imgextra/i4/O1CN01Lj1PSFNKeCD4q6fU_!!6000000002889-2-tps-2384-1652.png)
</Frame>

</Accordion>

<Accordion id="q2" title="支持哪些控件？">

文字总结、信息提取、文本翻译：不支持说明文字、图片、明细/表格、附件、手写签名、行业通讯录部门、关联审批单、工程项目、全部业务控件、身份证识别、全部业务控件组。

图片解读：仅支持图片控件。

</Accordion>

<Accordion id="q3" title="手机端能用吗？">

目前设置态仅支持电脑端和网页端，使用态支持手机和电脑。

</Accordion>

<Accordion id="q4" title="AI会读取我的审批内容吗？">

仅在使用AI能力时，临时发送当前内容用于生成，后续不存储、不记录，符合企业数据安全要求。

</Accordion>

</AccordionGroup>
