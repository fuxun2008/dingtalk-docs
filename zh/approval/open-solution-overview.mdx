## 方案概述

通过钉钉OA审批开放能力，提供 **四种** 企业业务系统接入钉钉OA审批的方案，实现业务系统发起审批，在钉钉端内处理审批，同时无缝连接钉钉沟通、待办、通知功能，实现企业各种业务流程集中审批、高效协同。

## 四种接入方式

钉钉OA审批提供四种企业流程接入方案，满足企业各类业务管理诉求。

<Frame>
![流程对接方案@2x.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/meonaAY0QjamnXxj/img/ed9de9d9-76ea-4172-97ce-1d4aa84bfd75.png)
</Frame>

|  |  |  |  |
| --- | --- | --- | --- |
| **接入方式** | **方案说明** | **方案特点&价值** | **接入方案** |
| 1、三方流程+页面<br />（钉钉端内打开） | 可在业务系统发起流程，调用钉钉接口创建钉钉OA审批流程，在钉钉端打开业务系统审批详情页处理流程 | **更轻量** <br />1、接入简单，直接在钉钉端内打开业务系统页面审批<br />2、只有同意拒绝等基础操作，无和钉钉连接操作，如拉群<br />3、延续用户原来使用的流程和页面习惯，低成本快速使用 | [使用三方流程和页面对接](/zh/approval/open-third-party-process) |
| 2、钉钉OA审批流程+页面 | 可在业务系统发起流程，调用钉钉接口创建钉钉OA审批流程，在钉钉端打开钉钉审批详情页处理流程 | **更标准** <br />1、标准化对接，使用钉钉OA流程和页面能力，无缝和钉钉聊天、待办、通知连接，高效审批 | [使用钉钉OA审批流程和页面对接](/zh/approval/open-dingtalk-process) |
| 3、三方流程+钉钉OA审批页面（钉钉智能OA专享） | 可在业务系统发起流程，调用钉钉接口用三方流程渲染钉钉OA审批页面，在钉钉端打开钉钉OA审批详情页处理流程 | **更灵活** <br />1、灵活对接，将不同业务系统的审批单结构、样式统一，为用户提供多端（移动端/PC/平板）一致体验<br />2、审批操作区按钮可自定义，同意、拒绝、转交、打印等等 | 敬请期待 |
| 4、企业自建应用，集成钉钉OA审批（钉钉智能OA专享） | 通过钉钉OA审批开放接口，支持企业自建应用，来实现业务应用的流程和钉钉侧流程在自建应用统一批量处理 | **更定制** <br />1、定制对接，企业可根据业务，实现页面和功能逻辑的定制 | 敬请期待 |
