## 一、产品简介

钉钉OA审批是钉钉官方应用，提供了开箱即用的OA审批产品，通过简单的设置，就能灵活满足组织日常审批需求，提升团队管理和业务效率，协助组织落地各项管理规范，降低企业运行风险。

##### 3.2 表单设置

设置审批的表单内容，即在发起审批时能看到和需要填写的内容。

1）可添加控件库

包含选项、数字、文本、日期等多个控件，单击或拖拽即可将左侧栏中的控件添加至表单中，长按并拖拽控件可自由调整顺序

<Frame>

![image.png](https://img.alicdn.com/imgextra/i1/O1CN013AS6p7GKdkK5bwRq_!!6000000007809-2-tps-2764-1730.png)
</Frame>

2）可添加控件组

钉钉审批还提供了 **请假、加班、录用、离职等假勤类、人事类控件组、报销、付款等财务类控件组、合同、用印等法务类控件组**。控件组和考勤打卡/智能人事/智能财务/智能合同等相关联，即在使用添加了控件组的审批时，员工的假勤、入离职、报销/付款、合同/用印等数据会自动同步至考勤打卡/智能人事/智能财务/智能合同系统。

你可以 **点击** 或 **拖拽** 所需控件组完成添加，并在右侧对控件组进行设置。 **一份表单最多只能添加一个控件组**。

3）基础设置

基础设置一般包括：控件标题、提示文字、控件规则（比如单选控件的选项设置、日期控件的类型设置等）、以及设置该控件是否打印及是否必填。

| 操作界面 | **公共设置项** | **详细说明** |
| --- | --- | --- |
| 标题 | 展示在表单上的标题，最多支持50字 |
| 提示文字 | 未填写时展示在表单输入框内的灰色提示文字，最多支持50字 |
| 默认值 | 未填写时展示在表单输入框内的默认内容，节点权限时“可编辑”时，支持修改该控件对应字段内容 |
| 必填设置 | 默认关闭；开启后，在发起表单时会校验该控件对应的字段是否填写，未填写时不允许发起 |
| 打印设置 | 默认开启；关闭后，该控件对应字段将不会出现在下载、打印的表单详情PDF上 |

2）审批节点类型

| **审批节点类型** | **解释** | **详细说明** |
| --- | --- | --- |
| 发起人 | 发起人节点是一个审批流程的起始点，在发起节点，可以配置谁能提交这个审批单，发起人在填写表单时可以填写哪些字段等等 |   默认节点<br />    <br />不可修改节点名称<br />    <br />发起后，在流程中心“我发起的”分类中查看<br />    <br />可设置表单中字段操作权限，支持可编辑、只读、隐藏 |
| 审批人 | 可以对审批单进行“同意”、“拒绝”、“转交”、“回退”、“加签”、“评论”等操作 |   可选节点<br />    <br />可修改节点名称<br />    <br />审批前，在流程中心“待处理的”分类中查看，审批后，在流程中心“待处理的”分类中查看<br />    <br />可设置表单中字段操作权限，支持可编辑、只读、隐藏 |
| 抄送人 | 流转到该节点时，没有审核的功能，可以收到对应的审批单，可以进行查看、评论操作 |   可选节点<br />    <br />可修改节点名称<br />    <br />流转到该节点后，在流程中心“抄送我的”分类中查看<br />    <br />可设置表单中字段可见权限，支持只读、隐藏 |
| 办理人 | 可以对审批单进行“提交”、“转交”、“回退”、“加签”、“评论”等操作 |   可选节点<br />    <br />可修改节点名称<br />    <br />办理前，在流程中心“待处理的”分类中查看，巴黎后，在流程中心“待处理的”分类中查看<br />    <br />可设置表单中字段操作权限，支持可编辑、只读、隐藏 |
| 条件分支 | 通过这个节点可以实现不同情况走不同审批分支<br />详情可查看>>>[如何设置分条件审批](/zh/approval/set-conditional-approval) |   可选节点<br />    <br />可修改分支名称<br />    <br />支持复制分支<br />    <br />支持添加条件：不同条件之间是“且”关系<br />    <br />支持添加条件组：不同条件组之间是“或”关系<br />    <br />执行时 **按照优先级依次运行** <br />    <br />只要有一个分支规则执行通过，其他分支则不再继续尝试， **有且最多只执行有一个条件分支** |
| 并行分支 | 通过这个节点可以实现多个审批分支同时流转； |   可选节点<br />    <br />可修改分支名称<br />    <br />支持复制分支<br />    <br />支持添加条件：不同条件之间是“且”关系<br />    <br />支持添加条件组：不同条件组之间是“或”关系<br />    <br />多个分支可按照设定的规则 **同时执行** |
| 连接器 | 通过这个节点可以调用“我的集成”中配置的连接器 |   可选节点 |
| 自动化 | 通过这个节点可以 |   可选节点 |

3）审批人、抄送人、办理人支持选择不同的类型，灵活满足不同的审批流转需要

| **审批人类型** | **解释** | **详细说明** |
| --- | --- | --- |
| 指定成员 | 由流程设计者指定的成员进行审批、抄送、办理 |   点击添加，可从通讯录选择组织内成员<br />    <br />标准版支持 50 人；高级版支持100人 |
| 发起人自己 | 发起人自己参与审批、抄送、办理 |  |
| 发起人自选 | 由发起人在发起申请时，自己选择由谁审批 |   选择方式：单选/多选，即发起人可以单选/多选审批人<br />    <br />选择范围：全公司/指定成员/角色，即发起人只能在此范围内进行选择 |
| 角色 | 由指定角色进行审批，如人事、行政、财务等<br />详情可查看>>>[如何设置角色人员审批](/zh/approval/set-role-approval) |   角色，即企业中配置的特定角色人员。这里与[钉钉管理后台](https://oa.dingtalk.io)  > 角色管理中设置相对应，可前往检查及修改。<br />    <br />用角色作为审批人，若有某位角色人员离职变动时，可通过变更角色人员快速完成流程参与人员的替换 |
| 直属主管 | 由发起人的直属主管审批<br />详情可查看>>>[如何设置直属主管审批](/zh/approval/set-direct-manager-approval) |   直属主管（汇报线）是以人维度的领导，在[钉钉管理后台](https://oa.dingtalk.io) >通讯录-个人档案页上进行设置<br />    <br />仅支持设置一个 |
| 部门主管 | 由发起人的部门主管进行审批，默认为直属部门负责人，可指定其他层级 |   企业中指定的部门主管，这里与[钉钉管理后台](https://oa.dingtalk.io)  > 通讯录中设置相对应，可前往检查及修改<br />    <br />一个部门可设置多个部门主管 |
| 连续多级主管 | 由发起人向上的各级主管依次审批 |   这里与 [钉钉管理后台](https://oa.dingtalk.io) > 通讯录中设置相对应，可前往检查及修改<br />    <br />最高审批层级支持发起人向上的第n级，最多支持20级；<br />    <br />也支持最高审批层级，审批到通讯录中的最高第几个层级<br />    <br />**需要注意：** 当发起人本人是通讯录对应的第n层级时，会再向上审批一个层级； |
| 部门控件对应主管 | 可根据员工在发起表单时所填的部门信息，流转给对应的部门负责人审批 | 表单中拖入“ **部门”** 控件，该流程的审批人就是发起人在表单中选择的部门对应的主管 |
| 部门控件对应角色 | 可根据员工在发起表单时所填的部门信息，流转给特定角色，且管理范围时对应部门 | 表单中拖入“ **部门”** 控件，该流程的审批人所设置的角色，且角色管理范围由发起人在表单中选择的部门决定 |
| 表单内联系人 | 可根据员工在发起表单时所填的联系人信息，流转给对应审批人 | 只有当表单设计中添加了  **联系人**  控件后，才可以设置此项 |

| **审批方式** | **解释** | **详细说明** |
| --- | --- | --- |
