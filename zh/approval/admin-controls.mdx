## 一、表单控件详情

审批表单由各类控件组成，控件分为三类：

| 控件分类 | 包含控件 |
| --- | --- |
| 布局控件 | 分栏 |
| 基础控件 | 单行输入框、多行输入框、数字输入框、单选框、多选框、日期、日期区间、说明文字、身份证、电话 |
| 增强控件 | 级联/分类、图片、明细/表格、金额、附件、手写签名、联系人、部门、当前地点、计算公式、关联审批单、省/市/区、评分 |

### 一）布局控件

分栏用于优化桌面端的信息展示效率，可将表单字段分成多栏并排展示。

<Note>
分栏效果仅在 **桌面端** 生效，手机端仍按单栏展示。该控件不涉及属性设置、数据约束和搜索。
</Note>

### 二）基础控件

基础控件共用以下公共设置项：

| 公共设置项 | 详细说明 |
| --- | --- |
| 标题 | 展示在表单上的标题，最多支持50字 |
| 提示文字 | 未填写时展示在表单输入框内的灰色提示文字，最多支持50字 |
| 默认值 | 未填写时展示在表单输入框内的默认内容，节点权限为"可编辑"时，支持修改该控件对应字段内容 |
| 必填设置 | 默认关闭；开启后，在发起表单时会校验该控件对应的字段是否填写，未填写时不允许发起 |
| 打印设置 | 默认开启；关闭后，该控件对应字段将不会出现在下载、打印的表单详情PDF上 |
