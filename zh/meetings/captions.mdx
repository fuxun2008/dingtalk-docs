## 💻 如何在电脑端使用字幕

### 打开字幕

会议进行中界面 >> 点击底部「更多」>> 点击「字幕」，即可打开字幕功能。

开启字幕后，可在界面看到如下的字幕效果，将会中说话人的语音实时转写成文字：

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/eYVOL5jMGP3jRlpz/img/8fe1692f-c207-421c-a77f-02acfb305b8d.png)

### 使用字幕翻译

在字幕块右上角 >> 点击翻译图标 >> 选择「你看的语言」，即可启用字幕翻译功能。当前支持中英日韩等 21 种小语种的双向实时互译能力。

![截屏2026-06-10 09.25.38.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/eYVOL5jMGP3jRlpz/img/14d2dbc7-91fd-4f40-b87e-eabed65c42ec.png)

还可以选择「同时显示双语」，效果如下：

![截屏2026-06-10 09.26.01.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/eYVOL5jMGP3jRlpz/img/9dd48504-80d5-4fb0-9ebc-df4c7d38d0c4.png)

更具体的语言设置，可以点击底部「更多」>> 点击「设置」 >> 点击左侧「字幕」，即可调整。

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/eYVOL5jMGP3jRlpz/img/bb1771c9-1cc7-4b46-9f2f-897ef4cef308.png)

### 调整字幕字号大小

**调节字号大小：**打开字幕后，鼠标悬浮到字幕块，并点击右上方的设置图标，即可快速调节字幕字号大小

也可以点击底部「更多」>> 点击「设置」 >> 点击左侧「字幕」，即可调整字幕大小

![截屏2026-06-10 09.28.21.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/eYVOL5jMGP3jRlpz/img/13a119da-b3d4-45ec-b409-f8cc8deff6b9.png)

### 配置个人热词

会议中会用到一些自己常用的特殊词汇，比如自己负责的业务、品牌等，在字幕中想要提高这些专业词汇的识别正确率的时候，就可以用到个人热词自定义。

可以点击底部「更多」>> 点击「设置」 >> 点击左侧「字幕」>> 在右侧输入「个人热词」并点击「添加」，即可配置个人热词。

注：个人热词最多支持 50 个，支持中/英文热词配置

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/eYVOL5jMGP3jRlpz/img/b259a78a-c280-4a0f-a964-31801154739d.png)

## 📱 如何在手机端使用字幕

### 打开字幕

会议进行中界面 >> 点击底部「更多」>> 点击「字幕」，即可打开字幕功能。

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/eYVOL5jMGP3jRlpz/img/120857d4-28c8-4181-b417-e76bce28bd61.png)

### 字幕设置（翻译、热词）

开启字幕后，点击界面底部的字幕块，即可打开字幕设置，以配置字幕翻译、字幕热词以及查看完整字幕

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/eYVOL5jMGP3jRlpz/img/30299065-97d6-40e8-a0b3-eec305c23c78.png?x-oss-process=image/crop,x_0,y_206,w_5012,h_5074/ignore-error,1)
