## 如何集成到网站

iframe 方式的嵌入十分简单，只需要在 HTML 页面中插入一个钉钉会议的 iframe 标签即可。

一个基础的嵌入示例如下：

```html
<iframe 
  src="https://meeting.dingtalk.com/app/room?linkId={:linkId}" 
  allow="camera; microphone; display-capture">
</iframe>
```

集成钉钉会议网页端的 iframe 之后，支持通过 URL 传参、消息传递的方式，实现自定义UI 、获取会中信息等功能。如需了解具体接口，请[立即咨询](https://alidocs.dingtalk.com/notable/share/form/v01oJGq76QW6oPBnAKe_dv19yqvsgs3oebp3pcjys_1qX0QQ0)以获取完整的开发文档。

## 自定义 UI 

此功能支持自定义配置界面上的 UI 组件是否隐藏或展示，例如会议页面中的共享按钮、邀请按钮。

自定义 UI 示例如下：

```html
<iframe 
  src="https://meeting.dingtalk.com/app/room?linkId={:linkId}&invite=0&screen_share=0" 
  allow="camera; microphone; display-capture">
</iframe>

<!-- 通过URL传参隐藏了共享和邀请按钮 -->
```
