## 重要会议

**定义：参与人数较多，比如超过100人以上，且会议场景比较复杂，或者高层管理人员参与的重要会议，对会议质量有较高要求**

**典型场景：董事会、高管战略会、企业年会**

|  | 项目 | 注意事项 | 备注 |
| --- | --- | --- | --- |
| 会前准备 | 日程 | *   提前预约会议日程，注意日程归属的组织一定要选择正确，以便可以按预期使用组织权益。<br />    <br />*   日程中添加视频会议，点击「会议设置」，可按需调整会议设置项。例如：入会权限设置、录制设置等、入会默认静音等。<br />    <br />    *   锁定会议：适用于安全性较高的会议，只有主持人主动呼叫特定成员时，该成员才能接听并加入会议<br />        <br />    *   等候室：适用于汇报会等，新成员加入时，默认进入等候室，主持人批准进入会议后，成员才能加入会议<br />        <br />    *   仅组织内成员可加入：适用于仅限公司公司成员参与的会议，勾选后，只有和主持人在同一个组织的成员才可加入会议 | [1.1 如何发起/预约视频会议？](/zh/meetings/start-or-schedule-meeting) |
|  | 议题 | *   重要会议可在日程底部点击添加议题，确保会议按照设定议题进行，且每个议题可设置讨论时长 |  |
| 设备 | 电脑 | *   检查电脑硬件配置，建议至少配置为：10代标压i5 CPU、16G内存、2G独立显卡。<br />    <br />*   卸载无关软件，Windows电脑暂停系统更新，避免会中弹窗干扰。<br />    <br />*   笔记本电脑需要连接外接电源，保持电量充足。<br />    <br />*   电脑尽量连接有线网络，有线网络相对无线网络更稳定。 |  |
|  | 手机 | *   检查手机硬件配置，建议选择各家厂商近年生产的中高端主流机型。<br />    <br />*   手机连接充电线或充电宝，保持电量充足。<br />    <br />*   如果使用运营商的流量，注意充值购买足够的流量包，因为会议消耗流量较高，避免欠费造成网络中断。 |  |
|  | 会议设备 | *   确保使用经过钉钉会议认证的会议设备，检查麦克风、摄像头的状态是否正常，扬声器音量是否正常。<br />    <br />*   建议使用会议控制屏来进行会议控制，避免使用手机控制器可能出现的误操作。<br />    <br />*   建议选择有线网络连接，避免无线环境干扰。 |  |
|  | 麦克风（外设） | *   尽量使用经过钉钉会议认证的麦克风。<br />    <br />*   检查外设能否正常开关，能否正常传入声音，音质是否清晰，音量是否适中。<br />    <br />*   检查路径：前往「会议中-更多-设置-音频」，点击「测试」，对着麦克风讲话看是否能清晰收听到刚讲过的内容。 | [4.4 如何处理视频会议中的声音异常问题？](/zh/meetings/audio-abnormal) |
|  | 摄像头（外设） | *   尽量使用经过钉钉会议认证的摄像头。<br />    <br />*   检查外设能否正常开关，能否正常传入画面，画质是否清晰。 | [4.9 如何处理摄像头画面异常的问题](/zh/meetings/camera-abnormal) |
| 网络 | 网络质量 | *   网络应稳定可靠，准备充足的带宽，满足低延迟、无丢包的要求。测试Ping公网域名，延迟应低于200ms，无丢包。<br />    <br />*   应按照每位与会者3Mbps的带宽评估整体带宽需求，尤其要结合公网出口带宽占用情况。<br />    <br />*   各类设备可连接有线网络时，优先连接有线。<br />    <br />*   使用WiFi时，因为无线信号容易相互干扰影响，要充分评估网络覆盖范围、信号强度、连接稳定性等综合性能指标。 | 网络检测小工具：[DingTalk Network Test Tool](https://n.dingtalk.io/dingding/network-test-tool/index.html) |
|  | 防火墙 | *   提前测试，验证防火墙是否允许会议正常连接，并且无中断，可以正常发送和接收声音、画面、屏幕共享。建议将钉钉相关IP地址加入白名单。 | 钉钉相关IP白名单：<br />[钉钉相关域名和IP列表](https://docs.dingtalk.io/i/p/Y7kmbokZp3pgGLq2/docs/lo1YvX0prG98kvEewqNyJPw7xzbmLdEZ?dontjump=true) |
| 高频场景 | 海外会议 | *   提前测试当地网络环境和设备接入会议的效果和体验。<br />    <br />*   测试体验字幕翻译功能，操作路径「会议中-更多-字幕」，可设置想看的语种，更建议前往「更多-设置-字幕」中设置自己的源语言，确保源语言和自己说的语种保持一致，可有效提升准确率 | [2.20 如何使用字幕？](/zh/meetings/captions) |
|  | 共享屏幕 | *   如果普通与会者不需要共享屏幕，请关闭「允许参会成员发起共享」，这样仅主持人和联席主持人可发起共享，避免普通成员误操作。<br />    <br />*   共享屏幕的设备不要用于会议控制，避免误操作。<br />    <br />*   共享屏幕的设备，检查关闭省电节能、自动息屏等设置，防止共享中断。<br />    <br />*   如果共享的画面包含视频，请开启：共享 - 视频流畅度优先。<br />    <br />*   如果需要同时共享设备的声音，请开启：共享 - 共享电脑音频。 | [2.4 如何开启共享屏幕？](/zh/meetings/share-screen) |
|  | 画面布局 | *   钉钉会议支持“标准”、“演讲者”、“宫格”三种常规布局<br />    <br />    *   标准布局下，正在讲话的人将显示在屏幕中央大画面，其他人显示在顶部小画面<br />        <br />    *   演讲者布局下，正在讲话的人将显示在屏幕中央大画面，其他人显示在右侧小画面<br />        <br />    *   宫格布局下，所有人以同等画面大小显示在宫格中，正在讲话的人将会有绿框提升，目前默认最多显示25宫格，也可进入「更多-设置-视频」 | [2.8 如何切换视图？](/zh/meetings/switch-views) |
|  |  | *   重要会议可通过「全员看TA功能来聚焦特定发言人，主持人点击「全员看TA」后，所有其他参会人大画面均会显示“TA”的大画面 |  |
|  | 会议秩序 | *   按照预定的流程，主持人可开启全员静音，与会人员依次发言时开启对应成员麦克风，并测试声音效果。<br />    <br />*   不发言或者尚未轮到发言时，主持人可关闭参会成员麦克风，避免干扰会议。<br />    <br />*   当会议中突然有陌生人加入或干扰会议时，可点击会议界面底部「安全」模块，点击「暂停参会成员活动」，会中所有成员会默认静音且暂停共享画面，待会议秩序恢复后，重新设置会议安全 | [2.12 如何保障会议安全？](https://docs.dingtalk.io/i/p/Y7kmbokZp3pgGLq2/docs/ROGpvEna5YQWmD1XQAon84ykmK3zoB27) |

**注意**：企业年会等复杂会议场景，建议联系我们，获取更专业的重保服务  **免费咨询**
