## 功能价值

日历支持自定义日程默认时长，个性化设置常用日程类型时长，让创建日程体验更灵活便利。

## 使用场景

钉三多是一名HR，日常会使用钉钉日历创建面试、会议、培训等工作日程，使用该功能之后，日历支持设置日程默认时长，可以根据不同的日程安排设置日程默认时长，并且默认的日程时长可跟随用户设置，让日程创建更灵活。

## 操作方法

在**日历设置**中点击【**视图】**界面设置日程默认时长，在创建日程时，默认的日程时长可跟随用户设置。
