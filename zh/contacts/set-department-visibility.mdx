## 一、功能简介

在企业组织架构中，有些部门由于涉及敏感信息或特殊职能（如法务、审计、高管团队等），可能不希望被其他成员随意查看。钉钉支持将部门设置为  **隐藏部门**，以保护部门成员隐私和信息安全。

## 二、操作流程


**隐藏本部门** 和 **限制本部门成员查看通讯录区别**

**隐藏本部门**：若开启，本部门将不会在个人资料页、会话中展示；

**限制本部门成员查看通讯录**：若开启，本部门成员在组织架构、搜索、个人资料页、会话中只能看到限定范围内的通讯录，同时将不能给其他人发送 DING、待办、日程等。

### 电脑端

进入 [**管理后台**](https://oa.dingtalk.io/) > 通讯录 > 部门管理 > 点击对应部门后方 ... > 编辑部门信息 > 开启 **隐藏本部门** / **限制本部门成员查看通讯录**。

### 隐藏范围区别

| **功能** | **范围名称** | **说明** |
| --- | --- | --- |
| 隐藏本部门 | 向所有人和部门隐藏 | 某个部门设置对所有人隐藏，隐藏的部门在浏览通讯录架构的时候不可见。 |
|  | 允许指定部门 / 人可见 | 可以设置人和部门的白名单，白名单内的人可以看到该隐藏部门。 |
| 限制本部门成员查看通讯录 | 不能看到所有通讯录，仅可见自己 | 某个部门设置只能看到自己，则该部门的人在浏览通讯录的时候只能看到自己。 |
|  | 只能看到所在部门及下级部门通讯录 | 该部门的人在浏览通讯录的时候，只能看到所在部门及下级部门。 |
|  | 只能看到指定部门 / 人 | 某个部门设置只能看指定的人和部门，则该部门的人在浏览通讯录的时候只能看到指定的人和部门。 |

## 三、常见问题

### 问：开启隐藏部门后，其他人员还能查看隐藏的部门吗？

    答：隐藏本部门开启后，本部门将不会显示在公司通讯录中，别人从通讯录中无法看到此部门，不影响此部门的人员查看其他部门。隐藏范围可以选择：a.向所有人和部门隐藏；b.允许指定部门/人可见。

### 问：隐藏部门能不能看到其他部门？

     答：隐藏部门可以看到未被隐藏的部门，其他部门看不到隐藏部门；未被隐藏部门人员无法搜索到隐藏部门人员。

### 问：主部门隐藏后，还能看到对应子部门吗？

     答：主部门开启部门隐藏，能否看到子部门，分以下两种情况：

     **情况一**：主部门设置向所有人和部门隐藏

      a：组织成员在主部门/子部门中，开启了主部门隐藏，该成员依然可见主/子部门；

      b：组织成员在其他部门内，不在主部门/子部门中，开启了主部门隐藏，则不可见主/子部门。

     **情况二**：主部门设置允许指定部门/人可见

       组织成员在主部门/子部门中，设置允许指定部门/人可见，该成员依然可见指定部门的主/子部门；因为允许指定部门/人可见是包含了所在部门和下级部门。

### 问：部门隐藏后还能参与考勤吗？

      答：部门被设置隐藏后，在考勤组添加参与考勤人员时，依旧可以选择被隐藏的部门。
