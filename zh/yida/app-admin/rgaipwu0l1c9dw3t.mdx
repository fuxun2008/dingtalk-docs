**数据准备**是宜搭低代码平台中的一项关键功能，旨在帮助企业用户在进行数据分析和应用前对原始数据进行清洗、融合和转换。本文介绍如何创建数据准备。

数据准备采用零代码ETL（Extraction Transformation Loading）方案处理来自宜搭内应用、企业外部数据库、文件型数据以及钉钉官方数据源（支持花名册、OA、智能人事、考勤等）的数据，通过构建数据加工流程，将零散数据整合为标准化数据集，以满足可视化分析和数据化决策的需求。

## 操作步骤

1. 登录 宜搭工作台 ，进入应用设置页。
2. 依次单击 数据工厂 > 数据准备 。
3. 单击 新建数据准备 ，进入数据准备设计器。
4. 在画布中拖入 输入 节点，并设置数据 输入源 。

支持输入数据设置**数据集**或**数据源**。

| **数据源** | **字段（非实时更新，实际请以数据准备展示为准）** |
|---|---|
| **通用指标** | 通讯录人数、日志提交人数、日志提交率、发DING总数、群聊总数、报销单数、近1天创建文档数等 |
| **花名册** | 员工姓名、职位、工号、部门名称、试用期类型、入职时间、转正时间等 |
| **OA审批** | 表单自定义业务字段、提交人、提交时间、审批人、审批状态、审批完成时间、审批记录等 |
| **智能人事** | 入职时间、岗位职级、转正时间、转正职级、离职时间、离职原因等 |
| **考勤（近半年内）** | 人员姓名、部门、打卡时间、是否加班、是否应到、考勤组名称、是否外勤、是否缺卡等 |
