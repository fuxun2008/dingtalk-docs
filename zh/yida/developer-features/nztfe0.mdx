**eagleeye-traceid** 是一次请求的唯一标识，开发同学使用其进行用户进行问题排查使用的。

**操作步骤**
**1. 打开开发者工具**
快捷键：f12，若无效，可按下图流程：
1点击右上角的三个点
2点击更多工具
3点击开发者工具
4点击network

**3. 获取 traceId**

请求->Headers -> Response Headers -> eagleeye-traceid 即为 traceId ，拷贝该值给开发同学即可
