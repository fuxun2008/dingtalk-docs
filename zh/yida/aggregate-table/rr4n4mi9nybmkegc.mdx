聚合校验是聚合表控制各关联表单的数据一致性的重要措施，只有满足校验规则的数据才可以提交，不满足校验规则的数据提交则会被阻断。本文介绍如何配置聚合校验。

## 配置提交校验规则

你可以参考以下步骤，配置聚合表校验规则。

1. 进入聚合表编辑页面，单击 提交校验 > 添加一项 。
2. 配置指标值的提交校验规则。
3. 单击 确定 完成配置。 提交校验通常与指标配合使用，用于阻断表单提交或逻辑验证。

<Note>
- 校验公式前仅支持 > 、 \< 、 == 、 != 、 >= 、 \<= 。
- 暂不支持指标间的运算。即，不支持类似 [指标1]>[指标2] 或 [指标1] + [指标2] > 0 的运算。
- 不满足的校验的提示文字，支持自定义，文字个数上限为 50。
- 可用变量为指标字段，也可以用数字。
</Note>
