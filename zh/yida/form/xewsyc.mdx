## 1. 功能简介

宜搭现如今提供二维码标签的自定义设计、二维码标签的批量下载、二维码标签预览等能力，在此处可以批量下载所需的表单二维码。

二维码标签配置请移步查看文档：[二维码标签](/zh/yida/form/knk7hr)

## 2. 操作指南

宜搭管理员和员工均可下载二维码标签，但操作路径有区别，如下：

### 2.1 管理员下载

**编辑态**：进入宜搭 >> 我的应用 >> 点击对应应用及表单  >> 数据管理 >> 下载二维码标签

<Frame>
  ![](https://img.alicdn.com/imgextra/i1/O1CN01WrdJohVHhnB5pHbW_!!6000000006372-2-tps-2870-1212.png)
</Frame>

<Frame>
  ![](https://img.alicdn.com/imgextra/i2/O1CN01ESm9aRhxwHC5p232_!!6000000007639-2-tps-2868-1416.png)
</Frame>

**访问态**：宜搭 >> 应用中心 >> 找到对应应用及表单数据管理页 >> 下载二维码标签

<Frame>
  ![](https://img.alicdn.com/imgextra/i4/O1CN01xSNm8W5cujI5q2N2_!!6000000006651-2-tps-2876-976.png)
</Frame>

### 2.2 员工下载

员工仅支持在访问态下载二维码标签。

**路径**：宜搭 >> 应用中心 >> 找到对应应用及表单数据管理页 >> 下载二维码标签

<Frame>
  ![](https://img.alicdn.com/imgextra/i2/O1CN01oABgAiaLAPD4Mtko_!!6000000005488-2-tps-2152-730.png)
</Frame>

### 2.3 可下载尺寸

选择不同的标签样式则下载的尺寸不同，在设置标签样式的时候可以查看到可下载尺寸。
