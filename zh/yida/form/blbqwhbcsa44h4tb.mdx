CASCADEDATEINTERVALV2函数用于计算日期区间选择框组件中的，开始和结束日期的差值。

## 支持产品场景

CASCADEDATEINTERVALV2函数支持在宜搭的以下场景中使用。

- 表单（主表字段）
- 表单（业务关联规则）
- 表单（校验）
- 流程设计（校验规则）
- 流程设计（关联操作）
- 集成自动化
- 流程-节点
- 连接器

## 格式

```text
CASCADEDATEINTERVALV2(日期组件,type,Offset)
```

## 属性说明

| **属性** | **是否必填** | **说明** |
|---|---|---|
| timestamp | 是 | 日期区间组件。 |
| type | 是 | 差值单位，取值：<br />• d：天<br />• **h**：小时<br />• **s**：秒 |
| Offset | 是 | 以单位长度作为偏移量，可以为正数或者负数。 |

## 返回值

| **返回值类型** | **说明** |
|---|---|
| 数字 | 得出日期区间的相隔天数。 |
