本文为你列举了宜搭所有人员相关的函数。

## 函数概览

| **函数名称** | **说明** |
|---|---|
| [USER](/zh/yida/form/vwncwe) | 无参数模式：User() 获取当前登录人； 有参数模式：User(level) 当前登录人的主管， level 是 获取当前登录人的主管。 |
| [USERFIELD](/zh/yida/form/oyuexdmpaxiys2tm) | 人员搜索框需要联动带出一些基本信息。 |
| [DIRECTOR](/zh/yida/form/pvw37ge84kxg9x28) | 获取当前登陆人的主管名称。 |
| [EMPLOYEE](/zh/yida/form/sxc8gv9dkhmt8zro) | 返回对应的人员信息对象数组（即人员组件底层的值）。 |
| [GETUSERNAME](/zh/yida/form/zl5s2mdi2ue214n4) | 获取当前登录人昵称。 |
| [LOGINUSER](/zh/yida/form/iak2o5xcbksb13wz) | 登录人。 |
| [LOGINUSERWORKNO](/zh/yida/form/sprth45e4nh19yhw) | 获取当前登录人员工唯一ID(员工UserID)。 |
| [DEPTNAME](/zh/yida/form/igrvxuztr0syw9sn) | 用于根据userId获取指定用户所在的部门信息。 |
