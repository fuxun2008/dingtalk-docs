## 1. 批量打印

### 1.1 打印模板

打印设置目前仅支持轻享版和专业版，免费版暂不支持设置打印模板设置

### 1.2 批量打印

对选择的数据按照打印模板生成打印文件并支持打包下载

**路径一**：数据管理 >> 勾选需要打印的数据 >> 更多操作>>打印选中>>选择打印模板 >> 确定即可

  ![](https://img.alicdn.com/imgextra/i2/O1CN01rYMClXqFI2E5qI1i_!!6000000004363-2-tps-2878-1156.png)

## 2. 下载批量打印文件的两种方式

### 2.1 工作通知

**路径**：工作通知 >> 点击查看详情 >> 跳转到下载到本地的页面 >> 然后再进行打印

<Frame>
  ![](https://img.alicdn.com/imgextra/i3/O1CN01Vowle2pjmcK37EMJ_!!6000000000121-2-tps-1535-968.png)
</Frame>

工作通知

### 2.2 打印记录

**路径**：表单 >> 数据管理 >> 打印记录 >> 下载（直接下载到本地）

<Frame>
  ![](https://img.alicdn.com/imgextra/i1/O1CN0124CZtd2eNFL4MtjX_!!6000000001775-2-tps-2152-651.png)
