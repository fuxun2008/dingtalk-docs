- 使用该连接器之前应先自建钉钉机器人，创建教程请移步： 企业自建单聊机器人
- 机器人AppKey查看路径： 钉钉开放平台 >> 应用开发 >> 企业内部开发 >> 机器人 >> 您创建的机器人 >> AppKey
</Warning>

## 1. 使用场景

通过宜搭机器人连接器，与企业自建机器人进行数据集成。提交表单数据，即可通过机器人发送消息给员工。为组织数字化转型业务服务。

## 2. 操作步骤

### 2.1 步骤一：表单设计

创建表单，进行消息通知的相关内容填充及配置。

**操作步骤：**

1. 创建表单，命名为「机器人消息通知录入」。
2. 添加成员组件，命名为「接收人」，开启多选模式，并设置为必填项。（操作如图2.1-1 所示）

<Frame>
  ![](https://img.alicdn.com/imgextra/i1/O1CN01U47BCSvU6nL3th8Y_!!6000000002018-2-tps-1920-950.png)
</Frame>

图2.1-1 添加并配置成员组件

3. 添加单行文本组件，命名为「机器人AppKey」，设置为必填项。（操作如图2.1-5 所示）

<Frame>
  ![](https://img.alicdn.com/imgextra/i4/O1CN01svHTNwJsYnJ3th8Y_!!6000000007262-2-tps-1920-950.png)
</Frame>

图2.1-2 添加并配置单行文本组件

4. 添加多行文本组件，命名为「消息内容」，设置为必填项。（操作如图2.1-6 所示）

<Frame>
  ![](https://img.alicdn.com/imgextra/i3/O1CN01AUt3G2DREUJ3th8Y_!!6000000004591-2-tps-1920-950.png)
</Frame>

图2.1-3 添加并配置多行文本组件

5. 点击页面右上角「保存」按钮，即可。

### 2.2 步骤二：配置连接器

<Note>
获取宜搭连接器详细介绍，请移步：[集成&自动化-连接器](https://docs.aliwork.com/docs/yida_support/zevvr1)
</Note>

给「机器人消息通知录入」添加并配置连接器，以实现宜搭表单与钉钉公告应用进行数据集成。

**操作步骤：**

1. 后台管理页 >>「机器人消息通知录入」表单 >> 集成&自动化 >> 新建集成&自动化。（操作如图2.2-1 所示）

<Frame>
  ![](https://img.alicdn.com/imgextra/i4/O1CN01Nxj9gieJAGK3th8Y_!!6000000001537-2-tps-1920-950.png)
</Frame>

图2.2-1 连接器入口

2. 将连接器命名为「机器人通知」，触发类型选择「表单事件触发」，点击「保存」。（操作如图2.2-2 所示）

<Frame>
  ![](https://img.alicdn.com/imgextra/i3/O1CN01B6Kx7ok2I4E3th8V_!!6000000001534-2-tps-1920-947.png)
</Frame>

图2.2-2 新建连接器

3. 配置表单事件触发：触发事件为创建成功，数据过滤为全部数据，点击「保存」。（操作如图2.2-3 所示）

<Frame>
  ![](https://img.alicdn.com/imgextra/i3/O1CN015jVA7HifyFL3th8X_!!6000000000412-2-tps-1920-949.png)
</Frame>

图2.2-3 配置连接器表单事件触发

4. 选择连接器应用：选择「机器人」应用，点击「下一步」。（操作如图2.2-4 所示）

<Frame>
  ![](https://img.alicdn.com/imgextra/i4/O1CN01c61dudVEwmD3th8X_!!6000000003571-2-tps-1920-949.png)
</Frame>

图2.2-4 选择连接器应用

5. 选择连接器执行动作：选择「机器人通知」执行动作，点击「下一步」。（操作如图 2.2-5 所示）

<Frame>
  ![](https://img.alicdn.com/imgextra/i3/O1CN01t2dFhDsgPJL3th8X_!!6000000006838-2-tps-1920-949.png)
</Frame>

图2.2-5 选择连接器执行动作

6. 配置连接器执行动作，点击「保存」按钮。（操作如图2.2-6 所示）

<Frame>
  ![](https://img.alicdn.com/imgextra/i3/O1CN01gm8Jbu8G12H3th8X_!!6000000006075-2-tps-1920-949.png)
</Frame>

图2.2-6 配置连接器执行动作

7. 点击页面右上角「保存」按钮后，点击「发布」按钮，即可。
