在平台的管理基本信息页面，你可以查看到属于组织架构内宜搭使用的相关数据，包括企业的基础信息与资源消耗情况等重要信息。

## 企业基本信息

你可以在此处查看以下内容：

- 版本信息 ：目前宜搭为你提供了免费版、轻享版、专业版和专属版四种版本。此处会显示你组织当前的宜搭版本。
- 组织名称 ：你当前登录的组织名称。
- Corp ID ：钉钉为每个注册企业赋予的唯一标识符，用于标识和区分不同的企业账号，以确保数据的独立性和安全性。
- Corp Token ：Corp Token是也可以称为企业凭证，是企业的安全令牌，用于验证和授权访问企业资源和服务。
- 企业域名 ：展示企业的在宜搭中所使用的域名。使用付费版宜搭可享有三次更换二级域名的权益，宜搭免费版暂不支持修改二级域名。

<Note>
仅可修改二级域名。例如：你可以对`***.aliwork.com`域名中的`***`进行自定义。
</Note>

## 资源容量

资源容量为你直观的展示了当前企业已使用的各项资源情况，以及版本资源上限。

<Frame>
  ![](https://yida-support.oss-cn-shanghai.aliyuncs.com/static/png/1700724707353-f79e4e7b-4b44-4477-8225-ebe9a8657214.png)
</Frame>

| **资源** | **说明** |
|---|---|
| **授权人数** | 企业内所有可以使用宜搭的总人数。如果需要增加使用人数，可以单击下方**增购**按钮。 |
| **组织数据量** | 企业内所有应用可用的表单数据总量。如果需要增加组织数据总量，可以单击下方**增购**按钮。 |
| **单表单数据量上限** | 单个表单的数据总量上限，如果提升数据量上限，可以单击下方**增购**按钮。 |
| **组织附件量** | 当前组织在宜搭全平台的历史上传附件总和，包括但不限于表单附件、应用图标、多媒体附件（自定义页面）以及表单中已上传单未提交的附件等。<br />**说明**：特定版本支持与钉钉企业存储做容量打通，详情请参考[宜搭打通钉钉企业存储](https://docs.aliwork.com/docs/yida_updates/yvhg4bx5wkiugnsv#zufFX)。 |
