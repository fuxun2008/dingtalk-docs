| 能力 | 免费版 | 轻享版 | 专业版 | 专属版 |
|---|---|---|---|---|
| 消息通知模板 | 不支持 | 支持 | 支持 | 支持 |

## 使用消息模板

你可以通过以下两种方式使用消息模板。

- 方式一：在流程表单流程设计的消息通知节点使用。详情请参考 消息通知节点 。
- 方式二：在表单页面设置中使用消息模板。详情请参考 表单消息通知 。

<Note>
普通表单暂不支持使用钉钉待办类型的消息模板。
</Note>

## 内置变量格式

消息模板中的消息内容支持配置变量，变量为表单组件的ID，变量格式为`$!{组件ID}`。在发送消息时，宜搭会自动将该变量替换为表单组件的值。

| 变量 | 字段 | 表单 | 流程 |
|---|---|---|---|
| $!\{formInstId} | 实例ID | ✓ | ✓ |
| $!\{formUuid} | 表单Code | ✓ | ✓ |
| $!\{formTitle} | 表单名称 | ✓ | ✓ |
| $!\{formTitleEn} | 表单英文名称 | ✓ | ✓ |
| $!\{title} | 表单实例标题 | ✓ | ✓ |
| $!\{titleEn} | 表单英文实例标题 | ✓ | ✓ |
| $!\{creator} | 创建人工号 | ✓ | ✓ |
| $!\{originator} | 发起人工号 | ✓ | ✓ |
| $!\{originatorName} | 发起人姓名 | ✓ | ✓ |
| $!\{originatorNameEn} | 发起人英文姓名 | ✓ | ✓ |
| $!\{serialNo} | 流水号 | ✓ | ✓ |
| $!\{createTime} | 创建时间 | ✓ | ✓ |
| $!\{modifiedTime} | 修改时间 | ✓ | ✓ |
| $!\{processInstStatus} | 流程实例状态 | ✗ | ✓ |
| $!\{approvedResult} | 审批结果 | ✗ | ✓ |
| $!\{approvedResultCode} | 审批结果Code | ✗ | ✓ |
