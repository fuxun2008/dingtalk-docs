# FCM是什么

FCM（Firebase Cloud Messaging）是一个跨平台的消息解决方案，支持Android/iOS/Web端，是GCM(Google Cloud Messaging) 的一种增强版本。

当专属APP期望能够在国外手机接收到离线推送消息时，请申请FCM并提供相关物料。

# 申请开通FCM

## （1）申请开通Google开发者账号

## （2）注册Firebase

在Firebase创建project 并注册应用，注册地址：[https://console.firebase.google.com/](https://console.firebase.google.com/)

创建好项目后，选择Android图标，配置Android应用：

![image](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/LAJdl6zMMMDQlke1/img/31d942c8-486b-4c24-a2fb-dc73e486d5fc.png)

请注意：

“Android package name”： 请填写正确的专属钉钉包名

“App nickname”（可选）：请填写专属钉钉名字

![4be90cef3bb0663de3a3cddab12a56ef.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/ZWGl05KJJPvmDn34/img/16b878cb-579b-4b6d-a91b-de54a1fdc40f.png)

## （3）下载配置文件并上传到钉钉OA打包平台

点击下载：google-services.json，请保存文件并发给钉钉技术配置。

![image](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/LAJdl6zMMMDQlke1/img/22c5b047-c9e5-446b-a305-a28d97a6b93f.png)

## （4）进入控制台配置其他参数

直接进入最后一步，前往控制台

![image](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/LAJdl6zMMMDQlke1/img/e525e9d1-eb2f-4d98-9a07-4d05788c384d.png)

## （5）创建服务账号密钥

选择项目设置 - 服务账号 - 生成密钥，如下图：

![image](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/LAJdl6zMMMDQlke1/img/3aa274ea-2364-4406-8508-97d4b564c1c3.png)

![image](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/LAJdl6zMMMDQlke1/img/3aa2ab85-2a68-4d39-88f3-a9786fd93d54.png)

![image](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/LAJdl6zMMMDQlke1/img/fccc3bd5-e635-43d9-9bcc-71b999c20c39.png)

点击生成密钥后会自动生成一个json文件，请将json文件保存并发送给钉钉技术：

![image](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/LAJdl6zMMMDQlke1/img/adb6ae9a-4fa7-4764-87af-5dd4afd82d38.png)

## （6）申请实时数据库（Realtime Database）

点击创建数据库：

![image](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/LAJdl6zMMMDQlke1/img/169b982d-35a9-457b-86b4-d122a41529d3.png)

![image](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/LAJdl6zMMMDQlke1/img/31428bb0-eedb-4560-bfc9-9dae66c668aa.png)

![image](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/LAJdl6zMMMDQlke1/img/1f9f3fbf-dc40-4c05-b55f-a5cedb3fad50.png)

点击启用，拷贝数据库地址作为打包物料。

![image](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/LAJdl6zMMMDQlke1/img/97870976-6475-4696-bf5e-7924bd147cd1.png)

## （7）请将以上物料提供给钉钉方配置

*   google-services.json
    
*   密钥json文件
    
*   实时数据库地址
    

## （8）打包完成后可到Firebase平台发起测试验证（可选）

**注意：该步骤可以不执行。**

为了验证FCM，我们必须提前准备一台具有Google推送服务的手机（建议国外版Pixel）。进入后台，选择 Cloud Messaging。

![image](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/LAJdl6zMMMDQlke1/img/1a6513d9-bd98-484c-9399-3b5edc9a2c18.jpg)

然后一步步按照提示发送测试通知（请注意，务必只能在上线前测试，避免消息被全员推送导致引起故障）。

![image](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/LAJdl6zMMMDQlke1/img/aaff376b-8259-411a-a17f-26051fe14304.jpg)

发送后手机将收到测试通知，代表申请成功：

![image](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/LAJdl6zMMMDQlke1/img/fb12f2da-5680-4df3-a285-e394f73f979a.png)
