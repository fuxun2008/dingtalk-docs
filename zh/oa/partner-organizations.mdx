协作组织是一项跨组织协作功能，帮助两个独立组织之间建立可信的协作关系。建立协作后，双方组织的成员可以像同事一样便捷地查找联系人、发起聊天、开会、协作编辑文档等，打破组织之间的沟通壁垒。

协作组织适用于以下场景：

- **集团内部协作**：如总部与海外分支机构之间的深度协作，双方成员互相可见，共享通讯录。
- **母子公司协作**：母公司与多个子公司之间建立协作关系，实现统一管理与信息共享。
- **跨企业合作**：与外部合作伙伴建立轻度协作，指定范围内的成员可相互查看与联系。

## 管理员指南

### 建立协作

<Info>
**前提条件**

使用协作组织功能前，请确认以下条件已满足：

1. **权益要求**：双方组织均需具有协作组织相关权益或席位。
2. **管理员权限**：操作者需为组织的主管理员，或拥有相关权限的子管理员。
</Info>

建立协作关系需要双方组织管理员共同完成，分为三个步骤：**发起邀请 → 接受邀请 → 最终确认**。

<Steps>
  <Step title="第一步：发起邀请（A 组织管理员）">
    1. 登录管理后台，在导航栏点击 **协作组织（跨境协作组织）**。
    2. 点击页面中的 **邀请协作**。
    3. 选择我方共享的协作成员（详见下方"协作设置说明"）。
    4. 阅读并勾选《风险须知》。
    5. 点击 **生成邀请链接**，系统将生成邀请链接。
    6. 复制该链接并发送给对方组织管理员。

    <Note>
    邀请链接自生成起 **24小时内有效**，过期后自动失效。
    </Note>

### 管理协作

#### 查看协作组织列表

路径：**管理后台 > 协作组织**

在协作组织列表页，你可以：

- 查看所有协作组织及其当前状态。
- 通过状态筛选框筛选组织，可选状态包括：**协作中**、**待确认**、**待对方确认**、**已拒绝**、**已解除**。
- 点击任意组织进入详情页。

#### 协作设置

在建立协作或后续编辑时，管理员需要配置以下设置项：

- 我方共享的协作成员

设置将哪些本组织成员共享给对方组织，对方可在通讯录中查看和搜索到这些成员。

| 选项 | 说明 |
| --- | --- |
| 共享全部成员 | 本组织所有成员对协作方可见 |
| 共享指定成员 | 仅指定成员对协作方可见 |

- 授予对方的权限

| 权限项 | 说明 |
| --- | --- |
| 默认权限（始终授予） | 对方可查看与搜索我方协作成员；<br />与我方协作成员发起聊天或会议；<br />与我方协作成员协作编辑文档；<br />查看我方协作成员的忙闲状态 |

- 编辑方法

1. 进入协作组织详情页。
2. 点击 **编辑** 按钮，我方设置区域进入可编辑状态。
3. 修改相应设置后，点击 **确认变更**。
4. 二次确认后完成保存。

- 仅可编辑我方设置，对方设置为只读。
- 设置变更后，系统将自动通知对方管理员。

### 解除协作

#### 解除方法

如需解除与某个组织的协作关系，请按以下步骤操作：

1. 进入协作组织详情页。
2. 点击右上角 **更多（三点）** 按钮，选择 **解除协作**。
3. 在弹出的窗口中阅读解除协作的风险说明。
4. 在输入框中输入"确认"以确认风险。
5. 点击 **确认解除**。

<Warning>
**解除协作为单方面操作，无需对方审批，立即生效。**
</Warning>

#### 解除后的影响

请在解除前仔细了解以下影响：

| 影响项 | 说明 |
| --- | --- |
| 找人限制 | 若解除前双方协作成员之间未产生过会话，解除后将完全不可见不可搜对方组织成员 |
| 私聊降级 | 若解除前双方产生过私聊，解除后双方成员必须相互添加为个人联系人，才能继续发送会话消息 |
| 退出群聊 | 双方成员都将退出由对方组织创建的所有内部群 |
| 数据权限回收 | 协作数据所有权归属于应用（如文档、音视频会议、AI 听记等）所有者所属组织。对方协作成员的访问权限将被回收 |

解除后，双方管理员都会收到系统通知。解除协作后如需重新建立协作，需重新走邀请协作流程。

### 协作能力一览

与协作组织成员之间，您可以进行以下协作操作：

- **搜索联系人**：通过首页搜索框搜索到对方成员。
- **发起聊天**：与对方成员进行单聊或群聊。
- **音视频会议**：邀请对方成员加入音视频会议。
- **协作文档**：在文档中@或分享给对方成员，共同编辑。
- **日历**：查看对方成员的忙闲状态，创建日程并添加对方成员。
- **邮件**：添加对方成员为收件人或抄送人。
- **AI 听记**：分享 AI 听记给对方成员。
- **钉盘**：分享钉盘文件给对方成员。

## 常见问题

<AccordionGroup>
  <Accordion id="q1" title="一个组织可以同时与多个组织建立协作吗？">
    可以。协作组织之间是网状结构，一个组织可以与 **至多20个组织** 分别建立协作关系，各组协作互不影响。
  </Accordion>
  <Accordion id="q2" title="邀请链接过期了怎么办？">
    邀请链接有效期为 24 小时。过期后，请发起方管理员重新生成新的邀请链接。
  </Accordion>
  <Accordion id="q3" title="对方拒绝了协作邀请，还能重新邀请吗？">
    可以。拒绝后，发起方可通过重新发送邀请链接再次建立协作。新的协作设置将覆盖之前的数据。
  </Accordion>
  <Accordion id="q4" title="解除协作后还能重新建立吗？">
    可以。解除后需重新走邀请协作流程。重新建立协作后，新的协作设置将覆盖之前的数据。
  </Accordion>
  <Accordion id="q5" title="协作期间产生的数据归属于谁？">
    协作期间产生的数据（如群聊数据、文档、音视频会议、AI 听记等）归属于发起该应用的成员所属组织。权益用量也由发起方组织承担。
  </Accordion>
</AccordionGroup>
