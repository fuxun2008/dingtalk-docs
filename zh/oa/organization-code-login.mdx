## 一、功能介绍

管理员可在OA管理后台查看与复制当前组织代码。成员可通过组织代码、登录名、密码登录企业账号。

**二、操作流程**

*   **查看当前组织代码**：【企业设置】-【组织代码登录】
    

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/QvjnA3jZ7erGaOXo/img/69ddb0fb-ba57-4b3c-829a-78d2e5275204.png)

*   **添加成员账号**
    

路径1：【首页】-【添加成员】-【添加成员】

路径2：【通讯录】-【成员管理】-【添加成员】

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/QvjnA3jZ7erGaOXo/img/616d12a5-cedb-4f85-958c-ea1ec70b2b78.png)![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/QvjnA3jZ7erGaOXo/img/ec730747-d7e6-409e-8b02-8e7484cbe582.png)

设置好成员信息后，管理员可复制信息并发送给成员。

成员凭借【组织代码】【登录名】【密码】即可登录企业账号。
