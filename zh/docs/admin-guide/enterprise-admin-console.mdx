企业的管理员可以进入企业设置后台，进行**权限与安全**、**容量使用说明**、**外部成员管理**、**企业知识数据大脑等**模块功能设置。

## 权限与安全

通过权限与安全设置，你可以配置**新建文档默认权限设置**、**对外分享**、**谁能将文档设置为企业内公开**、**创建知识库权限**、**将知识库设为企业内公开**、**文档水印**。

### 新建文档默认权限设置

通过设置，可以定义企业员工新建文档时，文档的默认权限规则；创建文档后，文档管理者也可自行调整。

### 对外分享

*   支持设置钉钉文档、钉闪会、AI听记是否允许将分享到企业外

*   支持设置钉钉文档是否允许公开发布到网页

### 谁能将文档/文件设置为企业内公开

当文档设置在企业内公开后，企业内任何获得文档/文件的用户都可以访问公开内容。你可以通过设置定义谁可以可将文档/文件设置/取消组织内公开。

## 容量使用说明

钉钉文档**容量计算访问包括：「我的文档」和「知识库」。可以查看到企业中**钉钉文档已占用的企业容量。

*   **我的文档：**企业分配你的用于个人知识管理，可用于个人工作知识沉淀与管理。每个员工「我的文档」容量上限为 2G。

*   **知识库：**以公司、部门、项目等为主体进行知识管理，共享与协作，用于企业的知识沉淀和管理。
