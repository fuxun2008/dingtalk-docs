通过对新建文档默认权限设置，可以定义企业员工新建文档时，文档的默认权限规则；创建文档后，文档管理者也可自行调整。

## 什么是「新文档的权限偏好」设置？

*   钉钉文档支持为单篇文档设置不同的权限规则（详见[分享、复制、下载、评论等权限配置](https://docs.dingtalk.io/i/p/gx9JOGOjR6Rm4QLAY7kmbAEMBp7ZKXLq?dontjump=true)），企业管理员可以设置这些规则的默认值，即「新文档的权限偏好」
    
    ![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/LvBPlN7a8NJPndG8/img/72e37a9e-6cf0-4b40-bb3d-bf624d164aa5.png)
    
*   企业内所有员工在知识库内新建文档时，权限规则将默认按「新文档的权限偏好」的配置生效，且后续可调整。同时，若父文档或知识库的权限规则更严格，则仍然继承更严格的权限规则
    
*   示例
    
    *   企业「新文档的权限偏好」设置了：
        
        *   允许文档被分享到企业外
            
        *   拥有「可编辑」及以上权限的人可以添加协作者
            
        *   拥有「可查看/下载」及以上权限的人可以复制内容、场景副本、打印、下载
            
        *   拥有「仅可查看」及以上权限的人可以评论
            
    *   知识库“AAA”设置了：
        
        *   不允许文档被分享到企业外（比企业「新文档的权限偏好」更严格）
            
        *   拥有「可编辑」及以上权限的人可以添加协作者
            
        *   拥有「可查看/下载」及以上权限的人可以复制内容、场景副本、打印、下载
            
        *   拥有「仅可查看」及以上权限的人可以评论
            
    *   则，在知识库“AAA”里新建一篇文档的时候，权限默认是：
        
        *   不允许文档被分享到企业外（按更严格的规则生效）
            
        *   拥有「可编辑」及以上权限的人可以添加协作者
            
        *   拥有「可查看/下载」及以上权限的人可以复制内容、场景副本、打印、下载
            
        *   拥有「仅可查看」及以上权限的人可以评论
            

## 如何设置「文档权限偏好」？

*   操作路径为「管理后台 - 钉钉文档 - 权限与安全」
