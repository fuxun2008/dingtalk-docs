## 一、钉钉文档容量计算规则

| 文件类型 | 使用行为 | 是否计入容量 |
| --- | --- | --- |
| 本地文件 | 在钉钉文档内上传文件，文件类型包括文档、图片、音视频、压缩包等。 | 计入 |
| 在线文档 | 在钉钉文档内新建或导入为在线文档（文档、表格、脑图、白板），在线文档内进行编辑++**插入的附件包括图片、音视频、压缩文件、本地文件**++等内容。 | **2023 年 7 月 30 日**<br />**正式计入** |
| 快捷方式 | 在钉钉文档内添加快捷方式。 | 不计入 |

## 二、钉钉文档容量计算范围

**容量计算访问包括：「我的文档」和「知识库」。**

*   **我的文档：**企业分配你的用于个人知识管理，可用于个人工作知识沉淀与管理。
    
*   **知识库：**以公司、部门、项目等为主体进行知识管理，共享与协作，用于企业的知识沉淀和管理。

## 三、什么是本地文件、什么是在线文档？

**本地文件：**本地文件上传至知识库后，不改变文件格式，可获得文件链接进行分享，部分格式支持预览；

**在线文档：**包含新建在线文档、导入在线文档两种

*   新建在线文档：目前支持新建钉钉文档、钉钉表格、钉钉脑图三种文档类型；
    
*   导入在线文档：部分类型本地文件导入至知识库，可转为在线文档，可获得文档链接进行分享，且转换为钉钉文档格式。导入转换格式说明：
    

| **本地文件类型** | **在线文件类型** |
| --- | --- |
| doc、docx、markdown、mark，md、txt | 钉钉文档 |
| xls、xlsx | 钉钉表格 |
| xmind | 钉钉脑图 |

## 四、目前支持上传与导入的文件类型有哪些？文件大小是否有限制？

上传文件可支持预览多种文件类型，且单个文件最大 8G；导入仅支持文档类型，单个文件最大 20M。具体差异如下：

| **传输方式** | **文件类型** | **支持预览格式** | **大小限制** |
| --- | --- | --- | --- |
| 上传 | 文档 | pdf, pptx, ppt, pot, potx,  pps, ppsx, dps, dpt, pptm, potm,  ppsm, xls, xlt, et, ett, xlsx, xltx, xlsb,  xlsm, xltm, csv, doc, dot, wps, wpt, docx, dotx, docm, dotm, txt，xmind | 单个文件最大 8G |
|  | 图片 | peg ，bmp，png，jpg ，ico ，webp |
|  | 音视频 | 3GP、AVI、FLV、MP4、M3U8、MPG、ASF、WMV、MKV、MOV、TS、WebM、MXF、AAC、AC-3、ADPCM、AMR、DSD、MP1、MP2、MP3、PCM、RealAudio、Windows Media Audio |
|  | 其他 | zip 压缩包 |
| 导入 | 文档 | docx, xlsx, doc, xls，txt，xmind，markdown，mark，md | 单个文件最大 20M |

关于「上传」与「导入」更多说明，可查看：

## 六、如何付费扩展容量？

在钉钉文档（我的文档、知识库）上传本地文件，占用企业钉盘容量；使用在线文档（文档、表格、脑图、白板）插入图片、音视频、压缩文件，占用企业钉盘容量，详细可见上文第一点「钉钉文档容量计算规则」。

钉钉为每个组织默认赠送了 100GB 永久免费的企业钉盘容量，若容量不足，组织可以自行购买，
