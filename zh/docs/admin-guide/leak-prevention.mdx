---
title: "什么是「防泄漏保护」？"
description: "DingTalk Docs 防泄漏保护功能可限制文档的下载、复制、创建副本和打印操作，支持在知识库、文件夹或单篇文档层级分别开启，保障敏感内容不外泄。"
---

当需要提升文档内容保密等级，不希望内容被下载、复制、创建副本或者打印，文档的管理员可开启「防泄漏保护」功能，防止文档内容外泄。

## 开启方式说明

*   文档开启「防泄漏保护」功能后，可禁止部分人或所有人复制、下载、创建副本和打印。

    # 开启生效范围说明

    知识库、文件夹、单篇文档/文件均可以开启「防泄漏保护」，启用后具体生效及影响如下（注：拷贝指的是复制、下载、创建副本和打印）：

*   若知识库开启了「防泄漏保护」，则知识库内的所有文档/文件均不能被拷贝；

*   若某个文件夹单独开启了「防泄漏保护」，则文件夹内的所有文档/文件均不能被拷贝；

*   若某一篇文档单独开启了「防泄露保护」，则该文档的所有子文档均不能被拷贝；


**特殊说明：**当“知识库”或者“文件夹”开启「防泄漏保护」后，若管理员勾选了“仅生效可预览的内容”，则只有可预览的文档/文件被限制（不可预览的内容如 zip、exe 等类型的文件，仍可以下载，方便协作）
