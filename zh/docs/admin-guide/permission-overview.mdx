## 一、新建的文档默认谁能查看/编辑？

*   在「我的文档」中新建一篇文档，默认只有自己能查看/编辑/删除。

*   在「知识库」中新建一篇文档，默认知识库的所有成员可以查看，成员的权限继承自知识库的「成员及权限」设置。

*   在已有文档下新建一篇子文档，默认父文档中的所有协作者可以查看。他们对这篇子文档的权限默认继承自父文档，可以被修改或移除。


## 二、新建的文档或文件夹，默认的权限配置是什么？

在钉钉文档的「我的文档」、「知识库」中新建的文档或文件夹，默认的权限配置如下：

| **权限规则** | **默认配置** |
| --- | --- |
| 是否允许将文档分享到企业外 | 是 |
| 是否允许企业外的人主动申请权限 | 是 |
| 是否限制：仅“可管理”权限可以将文档分享到企业外 | 是 |
| 谁可以添加协作者 | 拥有「可编辑」及以上权限的所有人 |
| 是否限制：仅企业内用户可以添加协作者 | 是 |
| 谁可以评论 | 可查看文档的所有人 |
| 是否开启“显示水印” | 否 |
| 谁可以复制内容、创建副本、打印、下载 | 拥有「可查看/下载」及以上权限的所有人 |

在钉盘的「我的文件」、「团队文件」中新建的文档或文件夹，默认的权限配置如下：

| **权限规则** | **默认配置** |
| --- | --- |
| 是否允许将文档分享到企业外 | 是 |
| 是否允许企业外的人主动申请权限 | 是 |
| 是否限制：仅“可管理”权限可以将文档分享到企业外 | 是 |
| 谁可以添加协作者 | 拥有「可管理」及以上权限的所有人 |
| 是否限制：仅企业内用户可以添加协作者 | 是 |
| 谁可以评论 | 可查看文档的所有人 |
| 是否开启“显示水印” | 否 |
| 是否开启“防泄漏保护” | 否 |

## 三、在哪里可以修改权限配置？

### 1）修改单篇文档、文件、文件夹的权限配置

*   拥有文档、文件、文件夹「可管理」权限的人，可以在「权限管理 - 权限配置」中调整权限规则配置

### 2）修改知识库的权限配置

*   拥有知识库「可管理」权限的人，可以在知识库的「更多设置 - 安全设置」中调整权限规则配置

## 四、如何为他人添加权限？

邀请他人共同查看、编辑、管理一篇文档时，需要为对方添加相应的权限

*   方式1：点击「分享」，在“邀请协作者”搜索框内，直接搜索<strong>用户、群、部门、角色</strong>，将他们添加为协作者并赋权

<img src="https://img.alicdn.com/imgextra/i2/O1CN01ku4tmAjwjgC1ldyU_!!6000000007301-2-tps-871-547.png" referrerPolicy="no-referrer" alt="image.png" />

*   方式2：从「更多」或「分享」进入「权限管理」，并点击「添加协作者」，添加他人为文档协作者并赋权


<img src="https://img.alicdn.com/imgextra/i1/O1CN01REYWXkEMaPC1QUr1_!!6000000003987-2-tps-703-768.png" referrerPolicy="no-referrer" alt="image.png" />

## 五、文档权限配置是怎么继承的？

### 1）单篇文档、文件、文件夹的「权限配置」默认继承给它们的子文档

以下情况例外：

*   若子文档自己的权限配置更收紧，则依然按子文档的配置生效

*   若子文档_“已设为私密，上级文档权限不再作用于本文档”_，则依然按子文档的配置生效

    ### 2）知识库的「安全设置」可以限制知识库内的所有内容

*   单篇文档、文件、文件夹的权限配置，可以在知识库的基础上更为收紧，但不能打破知识库的限制。

## 五、如何修改协作者权限？

*   从「更多」或「分享」进入「权限管理」，在“所有协作者”列表中，可以修改协作者的权限，或移除协作者

*   知识库管理员，默认有文档的可管理权限，不能被修改


<img src="https://img.alicdn.com/imgextra/i1/O1CN01W6i1U0QQClD2MHDt_!!6000000007103-2-tps-1162-935.png" referrerPolicy="no-referrer" alt="image.png" />

## 六、如何将文档公开给企业内所有人？

*   开启“企业内公开”，则企业内所有成员都可以查看此文档，无需添加为文档协作者

*   开启“企业内公开”后，可进一步设置企业内所有成员的权限

*   方式1：点击「分享」，开启企业内公开

*   方式2：进入「权限管理」，开启企业内公开
