## 一、为什么我不能查看权限、添加协作者？

*   知识库、文件夹、单篇文档文件的管理员，都可以设置「谁能添加协作者」（如下图），若你不满足该项设置，则无法查看权限、添加协作者，可联系管理员修改

*   单篇文档、文件、文件夹的管理员，可在「权限管理 - 权限配置」中修改，知识库的管理员可在「更多设置 - 安全设置」中修改。更多内容请参考：文档权限设置说明

    # 二、为什么我不能添加外部成员

    不能添加外部成员的情况，有可能是企业禁止、知识库禁止、文件夹禁止，或单篇文档文件禁止。具体原因请参考谁能将文档分享到企业外

    # 三、为什么我不能复制内容、创建副本、打印、下载等？

    #### 1）“权限配置”老版本：

*   知识库、文件夹、单篇文档文件的管理员，都可以设置「谁能复制、下载、创建副本、打印」（如下图），若你不满足该项设置，则无法进行复制、创建副本、添加副本到、打印、下载、保存为模版等和复制下载相关的操作，可联系管理员修改。

*   单篇文档、文件、文件夹的管理员，可在「权限管理 - 权限配置」中修改，知识库的管理员可在「更多设置 - 安全设置」中修改。更多内容请参考：文档权限设置说明

    #### 2）“权限配置”新版本：

*   在新版本中，「谁能复制、现在、创建副本、打印」功能将升级为「防泄漏保护」（如下图），若知识库、文件夹、单篇文档开启了防泄漏保护，将根据具体的防泄漏保护设置，禁止部分人进行复制、创建副本、添加副本到、打印、下载、保存为模版等和复制下载相关的操作，可联系管理员修改。

*   单篇文档、文件、文件夹的管理员，可在「权限管理 - 权限配置」中修改，知识库的管理员可在「更多设置 - 安全设置」中修改。更多内容请参考：什么是文档的「防泄漏保护」？

    # 三、为什么我不能评论文档

*   知识库、文件夹、单篇文档文件的管理员，都可以设置「谁能评论」（如下图），若你不满足该项设置，则无法评论文档，可联系管理员修改。

*   单篇文档、文件、文件夹的管理员，可在「权限管理 - 权限配置」中修改该配置，知识库的管理员可在「更多设置 - 安全设置」中修改该配置。更多内容请参考：：文档权限设置说明
