创建一个知识小组后，对小组成员进行管理。以一个空白小组为例，可以添加、删除成员。并支持设置成员类型，每种成员类型对应不同权限。

<img src="https://img.alicdn.com/imgextra/i2/O1CN01nhGv0kmz1cF2rcWP_!!6000000006260-2-tps-1411-726.png" referrerPolicy="no-referrer" alt="image.png" />

## 如何添加/删除成员

*   添加成员：进入小组成员管理列表，点击左上角「添加成员」，可以按照<strong>好友、群聊、架构、批量导入</strong>四种方式进行选择添加。但目前仅支持添加组织内成员，无法添加组织外成员。

<img src="https://img.alicdn.com/imgextra/i1/O1CN01YBvuwtnoC8D2pM2K_!!6000000004064-2-tps-1393-719.png" referrerPolicy="no-referrer" alt="image.png" />

*   删除成员：对已添加到小组内的成员，可以点击操作「移除」，将成员移除小组。


<img src="https://img.alicdn.com/imgextra/i2/O1CN01k5hMArlOf3K2oych_!!6000000002877-2-tps-1390-721.png" referrerPolicy="no-referrer" alt="image.png" />

## 小组成员角色权限说明

小组成员角色有：所有者、管理者、成员、只读成员（可下载）、只读成员，对应权限如下：

| 角色类型 | 小组权限 |
| --- | --- |
| 所有者 | 转交小组、可管理、编辑主页和知识库 |
| 管理者 | 可管理、编辑主页和知识库 |
| 成员 | 可编辑内容 |
| 只读成员（可下载） | 可查看/下载内容 |
| 只读成员 | 仅可查看，不可下载 |

## 知识库默认继承小组成员

小组内的知识库，默认继承小组成员权限，如需要对小组内的知识库单独进行权限设置，需要在知识库-「成员及权限」进行设置：
