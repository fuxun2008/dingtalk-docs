创建一个知识小组后，对小组成员进行管理。以一个空白小组为例，可以添加、删除成员。并支持设置成员类型，每种成员类型对应不同权限。

## 如何添加/删除成员

*   添加成员：进入小组成员管理列表，点击左上角「添加成员」，可以按照**好友、群聊、架构、批量导入**四种方式进行选择添加。但目前仅支持添加组织内成员，无法添加组织外成员。

    <img src="https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/J9LnWNyw2D28lvDe/img/c48d17d7-de65-4481-be64-0ffc8d3133ab.png" referrerPolicy="no-referrer" alt="image.png" />

*   删除成员：对已添加到小组内的成员，可以点击操作「移除」，将成员移除小组。


<img src="https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/J9LnWNyw2D28lvDe/img/c5e29ae0-ee62-4a99-a7c1-cb897da1f5cf.png" referrerPolicy="no-referrer" alt="image.png" />

## 小组成员角色权限说明

小组成员角色有：所有者、管理者、成员、只读成员（可下载）、只读成员，对应权限如下：

| 角色类型 | 小组权限 |
| --- | --- |
| 所有者 | 转交小组、可管理、编辑主页和知识库 |
| 管理者 | 可管理、编辑主页和知识库 |
| 成员 | 可编辑内容 |
| 只读成员（可下载） | 可查看/下载内容 |
| 只读成员 | 仅可查看，不可下载 |

## 知识库默认继承小组成员

小组内的知识库，默认继承小组成员权限，如需要对小组内的知识库单独进行权限设置，需要在知识库-「成员及权限」进行设置：
