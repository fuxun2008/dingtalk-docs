知识小组是钉钉文档推出的「团队知识协作与管理工具」，**帮助企业和组织****打造**部门、项目、兴趣小组知识空间**，可分主题归类知识库。**通过知识小组可以创建团队专属的「知识协作场」，用于企业内知识的生产沉淀、消费流转、应用创新，提升组织的知识生产力和协作效率。

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/r4mlQgNxGAGvqxow/img/6a03f377-4a07-4576-804f-74efa3a5d24a.png)

创建知识小组时，可以选择创建空白小组，也可以选择常见的团队类型如部门、项目、兴趣小组。创建后通过小组丰富的功能组件，高效搭建主页、整合知识库、管理成员，帮助团队实现知识高效流转，打造团队的 “文化窗口”。

## 为什么要使用知识小组？

企业和组织在日常协作中，通常以团队为维度进行知识管理。过程中产生的大量文档沉淀在知识库，但不同知识库之间以往缺乏联系，每个知识库犹如一个个信息孤岛，造成组织内的知识无法得到高效的流转，常见的问题有：

| 常见痛点 | 场景举例 |
| --- | --- |
| 容易出现信息孤岛 | *   团队的管理者，看不到团队成员相关的所有文档；<br />    <br />*   团队成员之间看不到彼此的文档；<br />    <br />*   产品、业务、项目负责人，看不到相关的所有文档； |
| 知识管理复杂无序 | *   团队内的知识库缺乏管理：同一件事情（产品、业务、团队、项目），会重复创建多个知识库，文档散落在不同知识库中；<br />    <br />*   团队内的文档缺乏传承：新的团队负责人创建新的知识库，旧的知识库不再使用，沉淀的知识无法复用。 |
| 缺乏团队文化展示 | *   需要有阵地展示团队目标、业务动态、文化建设、优秀员工，激励团队学习成长。 |

为解决以上痛点，通过「小组」的形式，把知识库与知识库、知识库与团队成员连接起来，打破信息孤岛、有序管理知识、搭建团队文化，让知识在企业和组织内高效流转。

## 知识小组能帮助我们做什么？

通过“小组-知识库-文档”三层信息架构，可以同时满足企业员工的内容创作、团队协作、组织知识和文化建设等核心场景的知识管理需求。

以知识“小组”为轴点，带动员工知识与经验的沉淀，从而提升组织的生产力，组织的进步反哺个人成长，帮助企业内形成 “学习型组织” 的文化。

## 支持创建多种类型小组

创建知识小组时，根据需要可选择创建空白、部门、项目组、兴趣小组四种类型，高效管理不同类型组织的知识：

*   空白小组：适合各类型团队，能快速完成创建，小组内无预设知识库；
    
*   部门：适用于部门，预置提供团队介绍、新人指南、部门会议、目标管理知识库，创建部门小组需绑定部门，且只能绑定一个部门；
    
*   项目组：适用于项目团队，预置提供项目方案、项目成员、项目验收、项目执行知识库；
    
*   兴趣小组：适用于有共同兴趣爱好的团队，如音乐、运动、旅行、摄影等，预置提供活动管理、小组介绍、兴趣分享、新人指南知识库。

## 自定义知识小组主页

在小组主页，可以自定义布局、展示模块、可见范围。直观展示小组的团队文化、知识库、成员风采，帮助小组成员快速了解团队动态、热门文档、更新动态、提升知识流转和团队协作效率。

## 成员权限控制

在成员管理中，可以根据角色设置不同知识库权限。成员角色有：所有者、管理者、成员、只读成员（可下载）、只读成员，对应权限如下：

| 角色类型 | 小组权限 |
| --- | --- |
| 所有者 | 转交小组、可管理、编辑主页和知识库 |
| 管理者 | 可管理、编辑主页和知识库 |
| 成员 | 可编辑内容 |
| 只读成员（可下载） | 可查看/下载内容 |
| 只读成员 | 仅可查看，不可下载 |

## 数据看板

通过知识库「数据统计」功能，知识库的管理员可以查看知识库文档的数据明细，包括文档和文件总数、各类型文档数量、文档使用数据，公开发布文档阅读数据等。帮助管理员分析知识库使用情况，提升知识管理效果。

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/r4mlQgNxGAGvqxow/img/acb7b543-7f6c-41b3-b2e0-d91063253400.png)

## 可管理多个知识库

知识小组可以包含多个知识库。「知识库」负责聚合知识，更好地对知识进行分类和整理；「小组」则聚合人与知识库，实现人和知识的连接，承担知识的流转与消费。
