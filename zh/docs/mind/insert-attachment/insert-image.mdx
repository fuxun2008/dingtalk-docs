钉钉脑图支持插入多种格式的图片，如 png/jpg/gif 等，是增强脑图表现能力的利器。

## 插入图片使用说明

*   电脑端插入图片：在「脑图视图模式下」，点击工具栏上的「插入图片」按钮，即可选择本地的图片文件进行上传。

    ![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/X8oLl9jEJwdgnapY/img/3aaae843-89bf-4639-9c7b-ce31da45ff5b.png)

*   也可以直接复制本地的图片文件，通过快捷键 Command + V 或 Ctrl + V 完成粘贴插入。


![/Users/wenshuang/Library/Application Support/DingTalkMac/ScreenCapture/钉钉录屏_2025-09-11 095932.gif](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/X8oLl9jEJwdgnapY/img/103838fe-f5f6-4a6a-83c3-0bb6bf49d66e.gif)

## 手机端插入图片

*   在「脑图视图」模式下，点击节点工具栏上的「插入图片」按钮，即可选择系统的相册图片，进行上传。


![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/X8oLl9jEJwdgnapY/img/c5b3de48-9486-46e3-8032-da52a47c521f.png)
