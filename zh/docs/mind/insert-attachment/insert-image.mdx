钉钉脑图支持插入多种格式的图片，如 png/jpg/gif 等，是增强脑图表现能力的利器。

## 插入图片使用说明

*   电脑端插入图片：在「脑图视图模式下」，点击工具栏上的「插入图片」按钮，即可选择本地的图片文件进行上传。

<img src="https://img.alicdn.com/imgextra/i2/O1CN01bjuI6ki5zhD2clb9_!!6000000004481-2-tps-1293-814.png" referrerPolicy="no-referrer" alt="image.png" />

*   也可以直接复制本地的图片文件，通过快捷键 Command + V 或 Ctrl + V 完成粘贴插入。


<img src="https://img.alicdn.com/imgextra/i2/O1CN014v3Fpono6bK2K0gS_!!6000000007281-1-tps-1144-720.gif" referrerPolicy="no-referrer" alt="/Users/wenshuang/Library/Application Support/DingTalkMac/ScreenCapture/钉钉录屏_2025-09-11 095932.gif" />

## 手机端插入图片

*   在「脑图视图」模式下，点击节点工具栏上的「插入图片」按钮，即可选择系统的相册图片，进行上传。
