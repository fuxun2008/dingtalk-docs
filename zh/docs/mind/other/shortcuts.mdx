绘制脑图时，使用快捷键能够帮助你更好的输入内容，减少鼠标和键盘的切换，提高输入效率。

## 使用说明

*   选中一个或多个节点，按下快捷键即可。和节点无关的快捷键无需选中内容即可使用。
    

## 脑图视图模式

*   Mac OS 系统：
    

| 快捷键分类 | 快捷键功能 | 快捷键 |
| --- | --- | --- |
| 常用 | 插入同级节点 | Enter |
|  | 插入子节点 | Tab |
|  | 插入父节点 | Shift + Tab |
|  | 删除节点 | Delete、Backspace |
|  | 节点导航 | ↑↓←→ |
|  | 撤销 | ⌘ + Z |
|  | 重做 | ⌘ + Y |
| 节点操作 | 复制节点 | ⌘ + C |
|  | 剪切节点 | ⌘ + X |
|  | 粘贴节点 | ⌘ + V |
|  | 创建节点副本 | ⌘ + D |
|  | 展开/折叠 | ⌘ + . |
| 导航 | 画布放大 | ⌘ + + |
|  | 画布缩小 | ⌘ + - |
|  | 进入演示模式 | ⌘ + Shift + P |
|  | 快捷键助手 | Control + H |

| --- | --- | --- |

|  | 插入子节点 | Tab |
|  | 插入父节点 | Shift + Tab |
|  | 删除节点 | Delete、Backspace |
|  | 节点导航 | ↑↓←→ |
|  | 撤销 | Ctrl + Z |
|  | 重做 | Ctrl + Y |
| 节点操作 | 复制节点 | Ctrl + C |
|  | 剪切节点 | Ctrl + X |
|  | 粘贴节点 | Ctrl + V |
|  | 创建节点副本 | Ctrl + D |
|  | 展开/折叠 | Alt + . |
| 导航 | 画布放大 | Ctrl + + |

|  | 进入演示模式 | Ctrl + Shift + P |
