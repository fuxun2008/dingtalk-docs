在「脑图视图」模式下，可以对整个画布进行缩放、滚动，可以更好地在细节和全貌中切换。

## 电脑端缩放画布

*   目前支持四种方式：
    

1.  Ctrl + 鼠标滚动控制；
    
2.  触摸板双指控制（目前在钉钉 Mac 客户端中还不支持，通过浏览器打开可获得更好体验）；
    
3.  Ctrl + +/- 控制；
    
4.  通过右下角的缩放工具控制画布的缩放。
    

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/oeLbnjp6bLmYOaNY/img/9112e6e1-c2aa-4324-ad22-b3ef30424599.png)

## 电脑端移动画布

*   目前支持五种方式：
    

1.  使用鼠标滚轮即可移动画布；
    
2.  触摸板双指控制；
    
3.  长按鼠标右键拖动画布；
    
4.  左侧【手掌图标】移动画布；
    
5.  内容较多时，也可以通过拖动滚动条来实现画布的移动。
    

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/oeLbnjp6bLmYOaNY/img/62e6de74-3f56-4313-b247-640f9e361578.png)

## 手机端缩放画布

*   在「脑图视图」模式下，在画布的空白区域中，可通过双指缩放画布。
    

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/e1X3lErXGE74nJbv/img/ffaaa545-76d3-495a-b137-7cc4c5d7657d.png)

*   双指缩放成功后，在屏幕中央会显示当前的缩放比例
    

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/oeLbnjp6bLmYOaNY/img/8dc5eef6-a29d-4124-a2e5-4398b8c26355.png)

## 手机端移动画布

*   在「脑图视图」模式下，单指滑动画布的空白区域，即可移动画布。
