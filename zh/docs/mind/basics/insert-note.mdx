备注功能是对主题的补充描述，想要对一个主题做简单注释或者详细阐述，但又不影响整张思维导图的整洁美观，就把文案写入备注。

**插入备注功能入口**

*   插入备注目前仅支持电脑端，手机端敬请期待。功能使用点击工具栏，编辑备注，如下图所示：


![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/P4maOgDgx3kmlWNX/img/1ed61710-5708-43da-9d05-406be60c2020.png)

## 如何使用插入备注

*   添加一条备注后点击备注内容或【编辑备注】icon唤起备注编辑面板直接编辑。


![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/P4maOgDgx3kmlWNX/img/7bce88bd-5472-43b9-a95e-f357ef0c87bf.png)
