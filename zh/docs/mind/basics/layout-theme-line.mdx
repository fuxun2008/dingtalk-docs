## 如何切换布局结构、主题、线型？

*   电脑端：在「脑图视图」模式下，点击屏幕左上方的按钮，即可弹出面板，切换到您喜爱的布局结构、线型和主题。
    

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/AmPdnp6jwPpwOw98/img/14c9e28e-21f1-4173-b4d0-27eeed6baa10.png)

*   手机端：在「脑图视图」模式下，点击屏幕右下方的按钮，即可弹出面板，切换到您喜爱的布局
    

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/AmPdnp6jwPpwOw98/img/4810de18-7a69-4bbe-add1-70a136bec4e0.png)
