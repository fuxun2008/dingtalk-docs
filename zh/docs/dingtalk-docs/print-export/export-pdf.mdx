在日常办公的过程中，难免会碰到将个人文档发送给他人查看的情况，为避免文档内容被随意篡改，保护信息安全，将文档导出为PDF就能很好的解决这些职场尴尬。

## 操作说明

## 导出PDF入口

点击文档右上角导航栏 ┇**\> 下载到本地 >** **PDF** 即可将文档下载为本地 PDF 文件，支持正文和评论同时导出。

## 导出 PDF的权限

拥有文档访问权限的人，都可将文档导出成 PDF。

## 补充说明

以下元素暂不支持 1:1 导出：

*   项目看板

*   在线音/视频

*   公式
