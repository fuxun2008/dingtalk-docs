很多时候编辑好的文档需要被打印出来给他人查看，如合作方案、用户使用手册等。

## 操作说明

## 打印入口

*   电脑端点击文档右上角导航栏 【┇】**—>打印** 或使用**快捷键 Ctrl+P（ MAC ：Cmd + P ）**即可进入打印设置页面；


![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/P4maOgxR14jKlWNX/img/c1816b3d-b301-4e6e-9e7d-c767db256548.png)

*   支持开启文档水印（在企业后台开启水印），[**管理后台**](https://oa.dingtalk.io/)**\> 文档与存储管理 > 权限及安全 > 企业安全管控 >** 开启/关闭 **文档水印**


![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/P4maOgxR14jKlWNX/img/e5cecfa6-508f-4ee4-87a3-3068a172917c.png)

*   手机端打开钉钉文档，点击右上角**「…」-打印。**


![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/P4maOgxR14jKlWNX/img/1e6ab5cd-3223-4347-84fd-0d6e89582170.png)

## 打印权限

拥有文档访问权限的人，都可在文档中使用打印功能。

## 补充说明

以下元素暂不支持 1:1 打印：

*   项目看板

*   在线音/视频

*   公式
