---

我们经常需要在线将文档通过其他平台发送给他人阅读，或者需要将文档内容打印张贴到其它地方，此时导出图片不失为一种简单直接的方式。

## 操作说明

## 导出长图入口

点击文档右上角导航栏 ┇**\> 下载到本地 > 高清长图** 即可进入长图导出界面。

<img src="https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/XJ9LnWmoVPyWOvDe/img/e87da601-f1f7-49d6-abc5-7dc46e05756d.png" referrerPolicy="no-referrer" alt="image.png" />

长图导出支持 <strong>电脑 和手机</strong>两种预览模式，还可以根据需要选择是否需要显示<strong>标题、作者、最后编辑时间、文档二维码</strong>，此外，还支持不同的风格设置。

<img src="https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/XJ9LnWmoVPyWOvDe/img/bdb9a1ce-3752-4bab-9235-47a485d35861.png" referrerPolicy="no-referrer" alt="image.png" />

## 导出长图权限

拥有文档访问权限的人，都可在文档中使用导出长图功能。

## 补充说明

以下元素暂不支持 1:1 导出长图：

*   项目看板

*   在线音/视频

*   公式
