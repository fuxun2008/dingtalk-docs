**「钉钉文档」**与钉钉深度结合, 让协同办公更高效。「钉钉文档」支持在文档中用 @ 提及他人，在正文或评论中**直接输入 @ + 用户名**，可向他人发送钉钉聊天通知，提醒其关注文档或评论内容，对方可通过聊天通知点击定位到文档目标区域。以前需要专门组织一个会议进行讨论的活动方案或重要文档，在钉钉文档中支持多人随时随地进行讨论与修改，大大提升了日常办公效率。

## 操作说明

1.  选择需要@他人的文档位置，直接在此处**输入「@ 」**，会自动弹出通讯录面板，然后在通讯录面板中选择需要@的用户，则可以选择需要通知人：

    <img src="https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/Kr4mlQxM6yBMOxow/img/8c7f3483-cba9-466f-839d-496c0ad46372.png" referrerPolicy="no-referrer" alt="image.png" />

2.  在弹窗中选择**发送**便可通过钉钉聊天通知提醒他人查看或评论。@接收者可直接点击钉钉聊天通知，定位到文档的指定位置。
