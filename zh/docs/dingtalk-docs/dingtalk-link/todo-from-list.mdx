撰写会议纪要、待办清单，或做团队工作计划的时候经常会产生大量的待跟进任务，如何做到「事事有回应，件件有着落」呢？可在钉钉文档中直接将任务列表生成钉钉待办，提及对应负责人提醒对方查看。

## 操作说明

选择需要添加任务列表的文档位置，点击工具栏中**待办列表** ![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/a/pWGGlPbw2ClgPWEl/b9cd48584ccd47e283a84998a334fff60579.png?x-oss-process=image/crop,x_3,y_3,w_49,h_49/ignore-error,1) 即可生成任务，再点击任务列表最右边的图标可**“转为钉钉待办"**，生成待办任务。

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/X8oLl9WDyRJzqapY/img/617f23cc-0fcb-4107-ada6-0efa7b0248db.png)

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/X8oLl9WDyRJzqapY/img/9a55520c-0c31-4f3f-8dc7-c1cd4ab637bc.png)

## 补充说明

待办任务可提及对应负责人、可设置截止时间、可转为钉钉待办，生成待办提醒。

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/X8oLl9WDyRJzqapY/img/b7f012a9-d3f4-4078-8605-b9710875d3df.png)
