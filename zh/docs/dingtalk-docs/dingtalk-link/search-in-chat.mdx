在群内搜索的聊天记录中，可在“文件”、“文档”Tab下直接搜出钉钉文档，查找更便捷。

## 操作说明

电脑端聊天群内，点击右上角**「聊天记录」**，搜索目标文档关键字，即可在**“文件”Tab** 直接搜索到目标文档。<img src="https://img.alicdn.com/imgextra/i1/O1CN01UbWfUXShb0I1sorK_!!6000000003360-2-tps-928-626.png" referrerPolicy="no-referrer" alt="image.png" />
