在群内搜索的聊天记录中，可在“文件”、“文档”Tab下直接搜出钉钉文档，查找更便捷。

## 操作说明

电脑端聊天群内，点击右上角**「聊天记录」**，搜索目标文档关键字，即可在**“文件”Tab** 直接搜索到目标文档。<img src="https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/P4maOgrkxe0mqWNX/img/3e64ecc4-5e0f-49d5-9bd7-5067e2faaa23.png" referrerPolicy="no-referrer" alt="image.png" />
