钉钉文档中将钉钉项目关联进来，以便进行项目复盘和追踪。

## 操作说明

在文档中选择添加项目看板的位置，点击顶部导航栏<strong>插入—>项目看板</strong>，在弹出的项目看板选择器上选择要插入的项目，即可在文档中直接查看该项目详情，如<strong>任务、状态、执行者</strong>等。还可以在项目看板上进行排序和筛选设置。
