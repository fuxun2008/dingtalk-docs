---
title: "添加或编辑列表"
description: "钉钉文档列表格式功能：支持为文档内容添加无序项目符号或有序编号列表，使同一主题下的多条内容排列有序、层次清晰，提升文档可读性。"
---

在日常的文档编辑中，若同一主题下对应多个内容，可对这些内容添加项目符号或编号列表，让文档内容排列有序，使内容层次更清晰。

## 操作说明

## 添加列表

在工具栏中点击对应图标<img src="https://img.alicdn.com/imgextra/i3/O1CN01jKYcRcAQsYI0TxWA_!!6000000006128-2-tps-238-64.png" referrerPolicy="no-referrer" alt="image.png" />即可依次添加符号列表（即无序列表）、编号列表（即有序列表）、任务列表。

<img src="https://img.alicdn.com/imgextra/i1/O1CN01igrKWc6iU7F2EirY_!!6000000004331-2-tps-1102-618.png" referrerPolicy="no-referrer" alt="image.png" />

## 编辑列表

钉钉文档支持更改符号类型、编号类型，点击工具栏对应操作的下拉菜单小箭头或对应操作的图标即可进行设置。
