设置文本格式可丰富文档的多样性，根据内容设置不同形式的文本格式，可使文本内容层次突出，帮助阅读者更好地抓住重点和更易理解文本内容。

## 操作说明

「钉钉文档」支持设置的文本格式如下：

文本格式主要包括字体、字体大小、粗体、斜体、下划线、删除线、上标、下标、字体颜色、文本突出显示颜色。

## 字体与字体大小的调整

*   选择目标文本，点击工具栏中的<strong>字体框</strong><img src="https://img.alicdn.com/imgextra/i4/O1CN01HuMhZQFqXYB0M1ot_!!6000000003248-2-tps-175-40.png" referrerPolicy="no-referrer" alt="字体.png" /> 自主选择字体形式。

*   选择目标文本，点击<strong>字体大小框</strong><img src="https://img.alicdn.com/imgextra/i1/O1CN01y94QSWKHGiL09gxs_!!6000000005127-2-tps-77-35.png" referrerPolicy="no-referrer" alt="字号.png" /> 选择即可调整字体大小。同时，你还可以通过**A**^**+**^**、A**^**\-**^进行快速调整，此功能一般是点击一次改变2个字体大小。

 ## 文本形式的调整

 字体的粗体、斜体、下划线、删除线、上标、下标等均可在菜单栏中选择，也可选中所需调整内容后，直接设置。

<img src="https://img.alicdn.com/imgextra/i3/O1CN01VP0LkjnHnGL2OI1A_!!6000000005284-2-tps-1178-630.png" referrerPolicy="no-referrer" alt="image.png" />

 ## 文本颜色的调整

*   点击<strong>字体颜色</strong><img src="https://img.alicdn.com/imgextra/i1/O1CN016dix3T4zbuB06IEq_!!6000000003622-2-tps-50-30.png" referrerPolicy="no-referrer" alt="字体颜色.png" /> ，在弹出的颜色面板中自主选择字体颜色。

<img src="https://img.alicdn.com/imgextra/i3/O1CN0197yhYOZtPkL3XA6N_!!6000000002596-2-tps-1741-926.png" referrerPolicy="no-referrer" alt="image.png" />

*   点击<strong>文本突出显示颜色</strong><img src="https://img.alicdn.com/imgextra/i2/O1CN01Dj4gI5auQ5K06feW_!!6000000001090-2-tps-53-31.png" referrerPolicy="no-referrer" alt="文本突出显示颜色.png" /> ，在弹出的颜色面板中自主选择文本突出显示色。
