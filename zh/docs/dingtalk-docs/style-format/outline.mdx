可以使用「文档大纲」功能构建文档的结构。钉钉文档会检测出文档中设置的标题，并自动添加到文档右侧的大纲面板。可让阅读者在阅读时迅速 get 文档的内容结构，也有助于编辑者在调整文档内容时快速检查是否有内容上的遗漏或重复。

# 操作说明

## 添加文本大纲

选择要作为文档大纲的文本，点击顶部工具栏的标题样式，系统会自动将标题设置为大纲。

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/AXNkOMavM8WEOY74/img/db9f6bd7-ca83-4863-9b8c-77dce7cbb2fe.png)

## 查看文档大纲 

#### 电脑端

鼠标放在文档右侧大纲悬浮图标，点击![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/LvBPlNoyebQPndG8/img/3c38c172-0189-4810-9587-2019fa2db191.png)即可固定大纲。如下图所示。

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/AXNkOMavM8WEOY74/img/fcde3e81-10e0-4d87-8adc-46616c7be0ef.png)

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/AXNkOMavM8WEOY74/img/27351a14-5db3-4164-a906-27d23bf16cf5.png)

#### 手机端

支持大纲显示，在手机端打开钉钉文档，点击右上角**··· -大纲**

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/AXNkOMavM8WEOY74/img/49b320ce-5f50-4cf9-9df1-3646d94f4212.png)
