可以使用「文档大纲」功能构建文档的结构。钉钉文档会检测出文档中设置的标题，并自动添加到文档右侧的大纲面板。可让阅读者在阅读时迅速 get 文档的内容结构，也有助于编辑者在调整文档内容时快速检查是否有内容上的遗漏或重复。

## 操作说明

## 添加文本大纲

选择要作为文档大纲的文本，点击顶部工具栏的标题样式，系统会自动将标题设置为大纲。
