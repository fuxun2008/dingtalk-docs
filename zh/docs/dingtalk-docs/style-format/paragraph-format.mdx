统一或有规律的段落格式往往能为文档的整洁性加分，视觉上更美观。

## 操作说明

## 更改段落对齐方式

选择想更改的段落，在顶部工具栏中选择一个对齐方式选项，或点击顶部导航栏**菜单-格式-水平对齐**，选择想要的对齐方式即可。

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/8ABmOojN7KpzqawZ/img/84feafd7-7c85-4f4a-914f-d145b64db51c.png)

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/8ABmOojN7KpzqawZ/img/ff98b8ec-438b-4941-ae6a-5fd4176b2621.png)

## 更改行间距

选择想要更改的行，在工具栏中点击**行高选项**![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/a/RNZo2LenKIGxqY2G/426a9b5e76884fab8e58f01ba31894b50579.png)，选择一个行间距值；或点击顶部导航栏**菜单-格式-行距**，选择想要的间距值即可。

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/8ABmOojN7KpzqawZ/img/fd3d7142-13c7-43d7-b450-3f61eca7daa1.png)

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/8ABmOojN7KpzqawZ/img/2f4691e4-5b74-45a9-b1f7-4716fc96bcab.png)

## 调整文本的缩进

选择要缩进的文本行，鼠标可放在该行的任意位置，点击工具栏的**缩进图标**![缩进.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/a/p24y90Aw2fex2DM1/bd00e9f231324a41a89a97103fe104970521.png) ，即可减少或增加缩进，或使用快捷键 **Ctrl+【 或** 快捷键 **Ctrl+】；**也可点击顶部导航栏**菜单-格式-缩进**，选择增加缩进或减少缩进。

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/8ABmOojN7KpzqawZ/img/4ea5c2dd-78d7-45b8-9ccd-ba0f29050119.png)

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/8ABmOojN7KpzqawZ/img/1cc697d6-02fc-4e59-a286-c1b0142ec211.png)
