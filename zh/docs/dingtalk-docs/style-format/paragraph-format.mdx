统一或有规律的段落格式往往能为文档的整洁性加分，视觉上更美观。

## 操作说明

## 更改段落对齐方式

选择想更改的段落，在顶部工具栏中选择一个对齐方式选项，或点击顶部导航栏<strong>菜单-格式-水平对齐</strong>，选择想要的对齐方式即可。

<img src="https://img.alicdn.com/imgextra/i3/O1CN01eIKBvWku74B2KtIV_!!6000000004817-2-tps-1151-648.png" referrerPolicy="no-referrer" alt="image.png" />

## 更改行间距

选择想要更改的行，在工具栏中点击<strong>行高选项</strong><img src="https://img.alicdn.com/imgextra/i3/O1CN01K6K3v77b0MH0BpeG_!!6000000007395-2-tps-94-54.png" referrerPolicy="no-referrer" alt="image.png" />，选择一个行间距值；或点击顶部导航栏<strong>菜单-格式-行距</strong>，选择想要的间距值即可。

<img src="https://img.alicdn.com/imgextra/i2/O1CN01kyeuBSX4AUL2JFpO_!!6000000001003-2-tps-1138-612.png" referrerPolicy="no-referrer" alt="image.png" />

<img src="https://img.alicdn.com/imgextra/i4/O1CN01MaBpSL2YnCK2Nmo5_!!6000000001155-2-tps-1174-659.png" referrerPolicy="no-referrer" alt="image.png" />

## 调整文本的缩进

选择要缩进的文本行，鼠标可放在该行的任意位置，点击工具栏的<strong>缩进图标</strong><img src="https://img.alicdn.com/imgextra/i3/O1CN01BNp77VqdQJK08Yil_!!6000000001448-2-tps-68-27.png" referrerPolicy="no-referrer" alt="缩进.png" /> ，即可减少或增加缩进，或使用快捷键 **Ctrl+【** 或快捷键 **Ctrl+】**； 也可点击顶部导航栏<strong>菜单-格式-缩进</strong>，选择增加缩进或减少缩进。
