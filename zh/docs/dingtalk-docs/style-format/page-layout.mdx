在日常的工作中，不同的文档对页面布局的要求也不同。页面布局是文档排版的重要选项之一。

## 操作说明

## 设置页边距

点击顶部导航栏，选择 **菜单-布局-页边距** ，可设置文档的页边距。

<img src="https://img.alicdn.com/imgextra/i2/O1CN01vkkTfSRwYTK2Gbw2_!!6000000001135-2-tps-1117-629.png" referrerPolicy="no-referrer" alt="image.png" />

## 设置纸张方向

点击顶部导航栏，选择 **菜单-布局-纸张方向** ，可将文档设置为纵向或横向。

<img src="https://img.alicdn.com/imgextra/i2/O1CN01xyBBVnuzcSG2JsrM_!!6000000005439-2-tps-1143-645.png" referrerPolicy="no-referrer" alt="image.png" />

## 设置页面大小

点击顶部导航栏，选择 **菜单-布局-页面大小** ，可将文档设置为 常规/超宽/全宽。

<img src="https://img.alicdn.com/imgextra/i1/O1CN01RVaJBqmRTsC2Nf0A_!!6000000002803-2-tps-1173-657.png" referrerPolicy="no-referrer" alt="image.png" />
