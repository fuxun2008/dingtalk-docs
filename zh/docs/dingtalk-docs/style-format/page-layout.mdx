在日常的工作中，不同的文档对页面布局的要求也不同。页面布局是文档排版的重要选项之一。

## 操作说明

## 设置页边距

点击顶部导航栏，选择 **菜单-布局-页边距**，可设置文档的页边距。

<img src="https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/P4maOgxRkMwmlWNX/img/1ff60659-3051-4122-81d1-f88653bfc55d.png" referrerPolicy="no-referrer" alt="image.png" />

## 设置纸张方向

点击顶部导航栏，选择 **菜单-布局-纸张方向**，可将文档设置为纵向或横向。

<img src="https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/P4maOgxRkMwmlWNX/img/ba4f085c-18c5-4e49-affe-6d5c7a638865.png" referrerPolicy="no-referrer" alt="image.png" />

## 设置页面大小

点击顶部导航栏，选择 **菜单-布局-页面大小**，可将文档设置为 常规/超宽/全宽。

<img src="https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/P4maOgxRkMwmlWNX/img/66be4b05-8786-4ca2-b7e8-89a1eb5d3b22.png" referrerPolicy="no-referrer" alt="image.png" />
