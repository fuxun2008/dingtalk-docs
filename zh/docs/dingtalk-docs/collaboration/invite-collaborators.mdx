# 一、新建的文档谁能查看/编辑？

*   在**「我的文档」**中新建一篇文档，默认**只有自己能查看/编辑**
    
*   在**「知识库」**中新建一篇文档，默认**知识库的所有成员可以查看**，他们对这篇文档的权限默认继承自知识库的「成员及权限」设置，可以被修改或移除
    
*   在**已有文档下**新建一篇子文档，默认**父文档中的所有协作者可以查看**（进入「更多 - 权限管理」可以查看文档的所有协作者），他们对这篇子文档的权限默认继承自父文档，可以被修改或移除
    

# 二、如何邀请协作者共同查看/编辑文档？

任何一篇文档，如果需要**分享给他人**共同查看或编辑，都可以将对方邀请为协作者，并添加对应的权限

*   点击「分享」，在“邀请协作者”搜索框内，可以直接搜索**用户、群、部门、角色**，将他们添加为协作者
    
    ![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/Kr4mlQAPBmYglxow/img/c98cf237-846f-4a4a-8a00-5cfe3eeb9a3b.png)
    
*   点击「权限管理」，可以查看当前文档的所有协作者，继续点击「添加协作者」，可以继续添加其他人为文档的协作者

# 三、如何修改协作者权限？

*   进入「更多 - 权限管理」或「分享 - 权限管理」，在“所有协作者”列表中，可以修改协作者的权限，或移除协作者
    
*   知识库管理员，默认有文档的可管理权限，不能被修改
    

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/Kr4mlQAPBmYglxow/img/de1f4898-08dc-4d28-bf87-e11b41c029ec.png)

# 四、如何将文档公开给组织内所有人？

*   开启“企业内公开”，则组织内所有成员都可以查看此文档，无需添加为文档协作者
    
*   开启“企业内公开”后，可进一步设置组织内所有成员的权限
