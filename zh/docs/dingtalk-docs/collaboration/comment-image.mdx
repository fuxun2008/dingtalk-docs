## 功能价值

在文档内划词评论支持上传图片，一图胜千言，清晰表达高效协作。

## 使用场景

钉三多是互联网公司的产品运营，在日常工作中会使用钉钉文档与同事进行互动协作，文档的划词评论支持上传图片后，一些用文字表达不清晰的内容，如：数据分析、项目进度等可以直接在评论中插入图片，提高了同事之间的协作效率。

## 使用说明

评论时点击图片图标——即可插入图片到评论中。
