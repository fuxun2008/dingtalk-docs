在直播、演讲时，如何才能与观众进行有效的互动呢？钉钉文档演示模式下，同一组织内用户<strong>支持通过扫码进行现场互动提问</strong>，演示最后一页可查看现场提问的问题，可以边看问题边看正文，轻松提高观众参与度。

## 操作说明

**方式一**：在开启演示模式后，在底部工具栏演示设置中，点击**「现场互动」**，即可弹出二维码，扫码即可参与互动；

<img src="https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/e1X3lEV6geBmnJbv/img/7193ea38-6a02-4452-a091-b4423f08dbbc.png" referrerPolicy="no-referrer" alt="image.png" />

**方式二**：在钉钉文档右上角演示旁的箭头<img src="https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/e1X3lEV6geBmnJbv/img/3304e5d2-bcd7-481d-8e9f-1e46a5997330.png" referrerPolicy="no-referrer" alt="image.png" />，点击编辑演示分页，点击上方「**演示设置**」，在演示设置中开启**「现场互动」**即可<img src="https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/e1X3lEV6geBmnJbv/img/28a417be-ff80-4e75-877f-e4028509a190.png" referrerPolicy="no-referrer" alt="image.png" />

扫码互动开启后，观看者可直接扫码进行提问和互动，演讲者可以边看问题边看正文，轻松提高观众参与度，此外演示最后一页可查看现场提问的问题。
