## 功能价值

IM 消息列表新增文档蓝条通知，及时查看协作消息，助力高效办公。

## 使用场景

手头工作多、来不及查看文档协作？当有人在文档中艾特你时，IM消息列表档蓝条通知，协作消息及时显示，方面快速知晓。

## 使用说明

收到文档消息提醒时，IM 消息列表内出现最新一条消息的蓝条通知。
