目前文档中支持的快捷键如下，此外，你还可以点击文档右下角键盘图标<img src="https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/a/RQ4k8QkeyuNgKnBQ/b6641db2191148258b1262baed3528220521.png" referrerPolicy="no-referrer" alt="键盘.png" /> 显示部分快捷键。

| 类别 | 功能 | Mac | Windows |
| --- | --- | --- | --- |
| 文本格式 | 粗体 | ⌘ + B | Ctrl + B |
|  | 斜体 | ⌘ + I | Ctrl + I |
|  | 删除线 | ⌘ + Shift + X | Ctrl + Shift + X |
|  | 下划线 | ⌘ + U | Ctrl + U |
|  | 上标 | ⌘ + . | Ctrl + . |
|  | 下标 | ⌘ + , | Ctrl + , |
|  | 增大字号 | `⌘ + Shift + >` | `Ctrl + Shift + >` |
|  | 减小字号 | `⌘ + Shift + <` | `Ctrl + Shift + <` |
|  | 复制文本格式 | ⌘ + Shift + C | Ctrl + Shift + C |
|  | 粘贴文本格式 | ⌘ + Shift + V | Ctrl + Shift + V |
|  | 清除格式 | ⌘ + \ | Ctrl + \ |
| 插入 | 提及某人 | @ | @ |
|  | 超链接 | ⌘ + K | Ctrl + K |
| 段落格式 | 标题 | ⌘ + Option + \[1-4\] | Ctrl + Alt + \[1-4\] |
|  | 正文 | ⌘ + Option + 0 | Ctrl + Alt + 0 |
|  | 有序列表 | ⌘ + Shift + 7 | Ctrl + Shift + 7 |
|  | 无序列表 | ⌘ + Shift + 8 | Ctrl + Shift + 8 |
|  | 任务列表 | ⌘ + Shift + Y | Ctrl + Shift + Y |
|  | 增加缩进 | Tab | Tab |
|  | 减少缩进 | Shift+tab | Shift+tab |
|  | 水平居左 | ⌘ + Shift + L | Ctrl + Shift + L |
|  | 水平居中 | ⌘ + Shift + E | Ctrl + Shift + E |
|  | 水平居右 | ⌘ + Shift + R | Ctrl + Shift + R |
|  | 两端对齐 | ⌘ + Shift + J | Ctrl + Shift + J |
| 编辑 | 撤销 | ⌘ + Z | Ctrl + Z |
|  | 重做 | ⌘ + Y | Ctrl + Y |
|  | 查找 | ⌘ + F | Ctrl + F |
|  | 查找与替换 | ⌘ + H | Ctrl + H |
| 其他 | 进入演示模式/全屏 | ⌘ + Shift + P | Ctrl + Shift + P |
|  | 演示模式放大 | ⌘ + + | Ctrl + + |
|  | 演示模式缩小 | ⌘ + - | Ctrl + - |
|  | 打印 | ⌘ + P | Ctrl + P |
