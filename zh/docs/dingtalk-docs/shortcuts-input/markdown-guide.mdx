# 什么是 Markdown？

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/LvBPlN2vg1QkldG8/img/5016a248-ed96-43e4-9cec-c45326f4ab11.png)

  Markdown 是由知名独立博主约翰·格鲁伯（John Gruber）发明的轻量级写作语言，通过一些简单的符号语法，就能够在写作的同时完成排版。帮助我们可以专注在文字的内容上，让我们更丝滑地写作，更沉浸式地输出，提升写作的效率。

# 为什么要使用 Markdown ？

使用 Markdown 写作内容时顺便去输入一些语法符号，让编辑器自动排版，这样的好处在于：当写完这篇文章的同时，也完成了排版，不需要在菜单栏里面去调整字符符号、文字加粗等等，提升写作的效率。

:::
## Markdown 的优点

**语法简单**

**兼容性强**

**专注内容**
:::

*   语法简单：Markdown 的语法是一些简单而且常用的标记符号。即使不是程序员，任何人只要花几分钟就能学会；
    
*   兼容性强：使用任何编辑器打开，格式都不会乱；
    
*   专注内容：使用 Markdown 写作再也不用纠结排版，其简洁优雅的格式会让你的双手无需离开键盘，沉浸到写作的乐趣之中。
    

# 钉钉文档 Markdown 升级亮点 

:::
#### 支持范围
:::

*   完整支持**粗体**/**斜体**/**删除线**/**下划线**/**上下标**/**高亮文本**等多种文本样式
    
*   新增支持输入 Katex **公式**，包括行内样式 **$a+b$**、块级样式 **$$a+b$$** 
    
*   新增支持**高亮块**语法
    
*   新增支持**图片**、**链接**语法
    
*   新增支持 **emoji** 语法
    
*   新增支持 **\`\`\`mermaid** + **回车** 插入**文本绘图**
    
*   新增支持**表格**语法
    
*   粘贴转富文本支持 Markdown 内嵌 HTML
    
    :::
    #### 细节优化
    :::
    
*   内置多种高亮块颜色，可以通过 ::: + &lt;type> 快速指定
    
*   新增辅助输入提示，无需记忆繁多的 **代码块语法**、**高亮块类型**、**emoji 编码**
    
*   友好的链接 Markdown 输入方式：
    
    *   支持 **\[\]()** 输入链接占位符并自动 focus 到链接标题输入框
        
    *   支持 **\[title\]()** 输入链接，并自动 focus 到链接地址输入框完成输入
        
*   表格 **| | |** + **回车** 后会插入一个两行两列的表格，并 focus 到首行首列，类似 **|x| |** + **回车** 这样就会 focus 到第二行首列
    
*   粘贴时会在尽可能需要的时候出现「转为富文本」选项，可以将 Markdown 文本转为钉钉文档支持的格式
    

# Markdown 使用宝典

钉钉文档支持绝大部分 Markdown 语法，你可以在「**导入**」、「**导出**」、「**粘贴**」、「**编辑**」时使用 Markdown 语法。

| 常用 Markdown 语法 | 高阶的 Markdown 语法 |
| --- | --- |
| *   **标题 1-6**<br />    <br />*   **引用**<br />    <br />*   **列表**：有序列表、无序列表、任务列表等<br />    <br />*   **代码块**<br />    <br />*   **行内代码**<br />    <br />*   **分割线**<br />    <br />*   **文本格式**：粗体、斜体、下划线、删除线、背景色、上下标等 | *   **链接**<br />    <br />*   **图片**<br />    <br />*   **公式**<br />    <br />*   **高亮块**<br />    <br />*   **表格**<br />    <br />*   **Emoji**<br />    <br />*   **文本绘图** |

### 导入

在创建文档时，选择「导入为在线文档」- 「本地文档」，选择本地的 .md 文件，即可导入为钉钉文档。

![Kapture 2022-10-31 at 18.53.23.gif](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/w5VLqX3yGx1VnX19/img/83c33423-075b-4a73-b683-acc1351ffb29.gif)

### 导出

编辑完成后，可以选择下载为 md 文件，完成导出。目前导出时支持的 Markdown 格式：《⏬ 导出为 Markdown 》

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/P4maOgQ6NaMVnWNX/img/2f731ec4-f6cd-4e27-bd56-acdc855af753.png)

### 粘贴

从纯文本编辑器或 Markdown 编辑器中复制一段 Markdown 文本，然后粘贴到钉钉文档中，在弹出的粘贴选项中点击「转为富文本」，从而转为钉钉文档支持的富文本格式粘贴时支持的 Markdown 格式：《🖨️ 粘贴 Markdown 文本》

![Kapture 2022-10-31 at 22.04.05.gif](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/P4maOgQ6NaMVnWNX/img/e58d20bf-5bf6-495b-bfb2-e552549476d3.gif)

### 编辑

输入特定的 Markdown 格式文本，并输入相应的触发键（空格或回车），将文本转换为对应格式。编辑时支持的 Markdown 格式可查阅：《⌨️ 编辑 Markdown》
