## 使用指引

新建文档时，可以选择「导入为在线文档」，然后选择本地的 .md 文件，即可导入到钉钉文档中。

<img src="https://img.alicdn.com/imgextra/i3/O1CN01CVvcHytn3lK3HIhW_!!6000000004465-2-tps-1615-859.png" referrerPolicy="no-referrer" alt="image.png" />

## 支持的格式

### 文件格式

支持如下三种文件

.markdown

.mark

.md

### 编码

目前仅支持utf-8字符集编码的文件
