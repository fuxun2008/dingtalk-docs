## 使用指引

新建文档时，可以选择「导入为在线文档」，然后选择本地的 .md 文件，即可导入到钉钉文档中。

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/e1X3lEV1yrPBnJbv/img/5244ba92-6dd0-4e9e-b6e9-e088cecd2731.png)

## 支持的格式

### 文件格式

支持如下三种文件

.markdown

.mark

.md

### 编码

目前仅支持utf-8字符集编码的文件
