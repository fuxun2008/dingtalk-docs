## 功能价值

双屏模式下，两份文档支持同时编辑，无需来回切换页面，轻松高效编辑文档、校对内容。

## 使用场景

钉三多是新媒体公司的文案编辑，日常会使用钉钉文档校对、审核各类文案稿件，撰写文章等。使用钉钉文档双屏模式后，校对、审核文案稿件时无需来回切换文档页面；撰写文章时，如需翻阅资料也可以在双屏模式中同步进行，让工作更轻松高效。

## 使用说明

打开A文档，再点击A文档中插入的B文档——进入双屏模式（双屏模式下两份文档支持同时编辑）
