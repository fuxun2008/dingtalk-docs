## Emoji 语法

钉钉文档支持使用 Markdown 语法输入 emoji 表情。

## 使用

输入 `:<编码>:` + `Space` 可以将文本转换为对应的 emoji 表情，具体支持的 emoji 可以查阅《Emoji 编码表》。

## 编码太多记不住？

钉钉文档可以在输入过程中提示你可能想输入的 emoji 编码，无需刻意记忆即可使用 emoji~

## 图片语法

## 规则

格式为：`![<ALT>](<URL> "TITLE")`  + `空格`

当输入 `![]()` + `空格`后，会生成一个占位符

ALT 允许为空

TITLE 必须和 URL 成对出现，不能单独出现

URL 必须为 http/http 协议

## 样例

下面这样是可以的：

```text/x-markdown
![]()
![foo](http://bar)
![<f o o>](http://bar)
![](http://bar)
![](https://www.example.com/foo-1?bar=x#search)
![](https://www.example.com/foo-1?bar=x&zoo#search "title 1")
![alt](https://www.example.com/foo-1?bar=x&zoo#search "title 1")
```

下面这些是不支持的：

```text/x-markdown
![abc]()
![ab]]()
![](())
![](/uri)
![](file:///uri)
![](http://uri"")
![](http://uri"t")
![]("abc")
![](http://uri " abc ")
![](</uri>)
```

## 文本绘图语法

## 格式

文字利用 [mermaid](https://mermaid-js.github.io/mermaid/#/) 实现的文本绘图，支持 mermaid 语法

```plaintext

  C -->|Two| E[iPhone]
  C -->|Three| F[fa:fa-car Car]
```
