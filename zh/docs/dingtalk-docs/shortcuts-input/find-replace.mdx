在文档编辑中或阅读中，查找替换不仅可以帮助我们快速的定位到想要的内容，还可以让我们批量修改文章中相应的内容。

## 操作说明

点击工具栏右侧 **查找替换**<img src="https://img.alicdn.com/imgextra/i2/O1CN01TGu3jLyDGuC08oLC_!!6000000006073-2-tps-70-68.png" referrerPolicy="no-referrer" alt="image.png" /> 或使用<strong>快捷键 Ctrl+F（ Mac ： Cmd + F ）</strong>，可在文档内查找特定字段并进行替换。查找结果会以黄色背景色高亮显示，通过最底部右下方的箭头可切换查看查找到的所有内容。
