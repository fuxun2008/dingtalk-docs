当需要将知识库内文档移动到另外一个知识库，文档的协作者和权限配置会发生相应的变化，具体说明如下：

## 一、协作者的变化

文档的协作者可以从上一级目录自动同步，也可以单独添加。

当移动一篇文档（或文件夹）时：

*   从原先位置上一级自动同步的协作者，会被移除；

*   移动后，会重新同步目标位置的上一级协作者；

*   由用户单独为文档添加的协作者，会保留。


:::
### 举个例子：

文档《功能更新说明》需要从知识库「销售知识库」移动到「客服知识库」，那么文档的协作者将会发生如下变化

### 移动前

位置：销售知识库 / 功能更新说明

该文档协作者列表：

销售主管小王（继承自知识库《销售知识库》）

技术负责人小张（由用户单独添加）

:::
### 移动后

位置：客服知识库 / 功能更新说明

该文档协作者列表：

~~销售主管小王~~~~（同步自知识库「销售知识库」）~~ _**从原先位置自动同步的协作者，会被移除**_

客服主管小李（同步自知识库「客服知识库」） _**移动后，会重新同步目标位置的上一级协作者**_

技术负责人小张（由用户单独添加） _**由用户单独为文档添加的协作者，会保留**_
:::
:::

## 二、权限配置的变化

文档的管理员可以设置文档自身的权限配置，同时文档的权限配置也受控于上一级目录的管控，具体配置可参考：权限设置｜文档权限设置说明

当移动一篇文档（或文件夹）时：

*   原先位置上一级的权限管控效果将会失效；

*   文档自身的权限配置仍然保留；

*   移动后，会受到目标位置上一级的权限配置管控。


:::
### 举个例子：

文档《功能更新说明》需要从知识库「销售知识库」移动到「客服知识库」，那么文档的权限配置将会发生如下变化

### 移动前

位置：销售知识库 / 功能更新说明

该文档的部分配置：

允许添加组织外的人为协作者：

++**关闭**++ （用户为该文档单独添加的配置）

显示水印：

++**开启**++ （受到知识库「销售知识库」的管控）

防泄漏保护：

关闭 （默认状态）

### 移动后

位置：客服知识库 / 功能更新说明

该文档的部分配置：

允许添加组织外的人为协作者：

++**关闭**++ （用户为该文档单独添加的配置） _**文档自身的权限配置仍然保留**_

显示水印：

关闭 （不再受原先位置管控，恢复默认状态） _**原先位置上一级的权限管控配置将会失效**_

防泄漏保护：

++**开启**++ （受到目标位置「客服知识库」的管控） _**移动后，会受到目标位置上一级的权限配置管控**_
:::
