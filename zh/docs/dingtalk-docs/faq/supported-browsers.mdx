钉钉文档网页版不支持 IE 内核的浏览器。为了更好地体验钉钉文档，可以按需选用钉钉文档支持的浏览器类型。在系统中将钉钉文档支持的浏览器设置为默认浏览器，可以体验到顺畅、完整的钉钉文档网页版体验

了解更多：[修改系统默认浏览器](/zh/docs/dingtalk-docs/settings/set-default-browser)

## 一、Windows 系统

| **系统版本** | **支持浏览器** |
| --- | --- |
| **Windows 7、8、8.1 和 10** | *   [Chrome浏览器](https://www.google.cn/chrome/)：63.0 及以上版本 <br />    <br />*   [Microsoft Edge](https://www.microsoft.com/zh-cn/edge)（新版） <br />    <br />*   [QQ 浏览器](https://browser.qq.com/)（极速模式）：10.0 及以上版本 <br />    <br />*   [360 极速浏览器](https://browser.360.cn/ee/)（极速模式） |
| **Windows XP** | *   [360 极速浏览器](https://browser.360.cn/ee/)（极速模式） |

## 二、MacOS 系统

| **支持浏览器** |
| --- |
| *   [Chrome浏览器](https://www.google.cn/chrome/)（63.0 及以上版本） <br />    <br />*   [Microsoft Edge](https://www.microsoft.com/zh-cn/edge)（新版） <br />    <br />*   [QQ 浏览器](https://browser.qq.com/)（极速模式）：10.0 及以上版本 <br />    <br />*   [360 极速浏览器](https://browser.360.cn/ee/)（极速模式）<br />    <br />*   Safari：12.0 及以上版本 |

## 三、Linux 系统

| **支持浏览器** |
| --- |
| *   [Chrome 浏览器](https://linuxconfig.org/how-to-install-google-chrome-browser-on-linux)（63.0 及以上版本） <br />    <br />*   [360 极速浏览器](https://browser.360.cn/se/linux/index.html)<br />    <br />*   [Microsoft Edge](https://www.microsoftedgeinsider.com/zh-cn/download/) |

## 四、如何修改默认浏览器

### Windows 系统

1.  选择「开始」 按钮，点击「设置」，然后键入「默认应用」。

<img src="https://img.alicdn.com/imgextra/i2/O1CN01syfKUu57m3G1vy3V_!!6000000004117-2-tps-953-936.png" referrerPolicy="no-referrer" alt="设置.png" />

2.  在搜索结果中，选择「默认应用」。

<img src="https://img.alicdn.com/imgextra/i1/O1CN01iANPLLxB8JD22deB_!!6000000004560-2-tps-1006-729.png" referrerPolicy="no-referrer" alt="应用.png" />

3.  应用 \> 默认应用 \> Web 浏览器，选择需要设置为默认程序的浏览器，点击 将此程序设置为默认值，遇到提示框选择 仍然切换，完成设置。


<img src="https://img.alicdn.com/imgextra/i2/O1CN01gxLHrr40xKF2BZlw_!!6000000004730-2-tps-1077-715.png" referrerPolicy="no-referrer" alt="浏览器.png" />
