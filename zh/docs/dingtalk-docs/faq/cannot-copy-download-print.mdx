## 问题原因

默认情况下，拥有「可查看/下载」及以上权限的文档协作者，可以复制文档正文内容、下载文档、打印文档、创建副本。当出现有权限，但无法复制、下载、打印文档，**主要是因为：**

文档或者知识库管理员在「权限配置」功能中，设置了**“仅拥有「可管理」权限的人可以下载、创建副本、打印/****所有人禁止下载、创建副本、打印****”**，上述规则便会失效，如下图所示：

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/MeYVOLkbYWaJqpz2/img/b8ca2274-1f95-4692-bc3c-bc40a79f5809.png)

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/MeYVOLkbYWaJqpz2/img/a4f28295-5083-4464-8867-ad91573f75e2.png)

此时，即使用户拥有文档的「可查看/下载」权限，也无法进行复制文档正文内容、下载文档、打印文档、创建副本等操作。该场景下，相关操作时会有提示。

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/MeYVOLkbYWaJqpz2/img/5d22b9c2-b8e1-4b19-8c1a-d0ca3a2027ce.png)

## 如何解决

可联系文档或者知识库管理员修改文档/知识库的权限设置。关于文档权限设置的更多信息，请参见 分享、复制、下载、评论等权限配置
