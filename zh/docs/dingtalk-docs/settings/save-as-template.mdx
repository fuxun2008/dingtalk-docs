在工作中，我们经常会碰到编辑同类型文档的情况，如每年或每月撰写工作计划、工作总结或工作周报等，此时，我们可根据自己的撰写习惯将文档保存为模板，免去重复编辑的繁琐，提高工作效率。除此之外，钉钉文档也精心准备了大量的通用模板方便大家日常工作。

## 操作说明

点击文档右上角导航栏 ┇**\> 保存为模板 > 保存为我的模板** 即可将目标文档保存为模板，可以在唤出的面板中修改文档标题，该标题不会在原文档中生效。

创建的模板可在新建时选择**我的模板**使用
