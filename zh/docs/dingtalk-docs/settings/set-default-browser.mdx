**简介**

为了更好地体验钉钉文档网页版，可以在系统中将钉钉文档支持的浏览器设置为默认浏览器。以下提供设置方法参考，请以实际操作页面为准。

## 一、Windows 系统

1.  选择「**开始**」 按钮，点击「**设置**」。
    
    ![设置.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/gMp7ld6X9wwAqBQN/img/2cf2aa40-9bd6-4086-80e1-d55bba88adfc.png)
    
2.  选择「**应用**」。
    
    ![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/wYdgOk9M5xPLn4BX/img/b2f9e6ed-06d1-4522-962e-06eb9447649b.png)
    
3.  ​**应用** **\>** **默认应用** **\>** **Web 浏览器**，选择需要设置为默认程序的浏览器，点击 将此程序设置为默认值，遇到提示框选择 仍然切换，完成设置。
    

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/wYdgOk9M5xPLn4BX/img/cf4bc3f6-8d61-4230-bc7a-f8a6f0195e70.png)

## 二、MacOS 系统

*   第一步：打开 **系统设置**，点击进入 **桌面与程序坞**
    
*   第二步：找到默认网页浏览器，选择想要默认使用的浏览器，如下图所示：
    

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/wYdgOk9M5xPLn4BX/img/ad975d18-94c0-4235-9eb3-22e8ed7c83d0.png)

## 三、如何设置默认使用浏览器打开钉钉文档

使用钉钉时，根据个人使用习惯，可设置使用Web浏览器打开、查看、编辑文档，

*   **Windows系统 ：**打开 **钉钉** **\>** 左上角 **头像 > 设置与隐私 > 通用 > 钉钉文档**，打开「始终在浏览器中打开文档」，即可完成设置。
    

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/wYdgOk9M5xPLn4BX/img/bd2bd869-ad6b-4c81-a22c-0d32154ce443.png) 

*   **Mac 系统：**打开**钉钉** **\>**左上角 **头像 > 设置与隐私 > 通用 > 钉钉文档**，点击勾选「始终在浏览器中打开文档」，即可完成设置。
    

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/wYdgOk9M5xPLn4BX/img/7ad75fbb-1dba-46ee-a5e5-2e50fa229259.png)
