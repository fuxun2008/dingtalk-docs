**简介**

为了更好地体验钉钉文档网页版，可以在系统中将钉钉文档支持的浏览器设置为默认浏览器。以下提供设置方法参考，请以实际操作页面为准。

## 一、Windows 系统

1.  选择「**开始**」 按钮，点击「**设置**」。

<img src="https://img.alicdn.com/imgextra/i2/O1CN01syfKUu57m3G1vy3V_!!6000000004117-2-tps-953-936.png" referrerPolicy="no-referrer" alt="设置.png" />

2.  选择「**应用**」。

<img src="https://img.alicdn.com/imgextra/i1/O1CN01VpPceOQTmtL2cleK_!!6000000007072-2-tps-1293-1011.png" referrerPolicy="no-referrer" alt="image.png" />

3.  **应用** **\>** **默认应用** **\>** **Web 浏览器**，选择需要设置为默认程序的浏览器，点击 将此程序设置为默认值，遇到提示框选择 仍然切换，完成设置。

<img src="https://img.alicdn.com/imgextra/i4/O1CN01CUoIdqMHuBJ2EivV_!!6000000003381-2-tps-1102-863.png" referrerPolicy="no-referrer" alt="image.png" />

## 二、MacOS 系统

*   第一步：打开 **系统设置**，点击进入 **桌面与程序坞**

*   第二步：找到默认网页浏览器，选择想要默认使用的浏览器，如下图所示：


<img src="https://img.alicdn.com/imgextra/i2/O1CN01LidNZzV3a2F1kVmt_!!6000000001788-2-tps-862-757.png" referrerPolicy="no-referrer" alt="image.png" />

## 三、如何设置默认使用浏览器打开钉钉文档

使用钉钉时，根据个人使用习惯，可设置使用Web浏览器打开、查看、编辑文档，

*   **Windows系统 ：**打开 **钉钉** **\>** 左上角 **头像 > 设置与隐私 > 通用 > 钉钉文档**，打开「始终在浏览器中打开文档」，即可完成设置。


<img src="https://img.alicdn.com/imgextra/i4/O1CN01as7w4ePCFnJ25PNc_!!6000000001763-2-tps-1028-848.png" referrerPolicy="no-referrer" alt="image.png" />

*   **Mac 系统：**打开<strong>钉钉</strong> **\>**左上角 **头像 > 设置与隐私 > 通用 > 钉钉文档**，点击勾选「始终在浏览器中打开文档」，即可完成设置。


<img src="https://img.alicdn.com/imgextra/i4/O1CN01lUvcbrnh8aG26Xck_!!6000000002104-2-tps-1037-857.png" referrerPolicy="no-referrer" alt="image.png" />
