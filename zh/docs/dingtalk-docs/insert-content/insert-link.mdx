在文档的编辑中，经常会使用插入链接，这样有助于阅读者<strong>快速跳转</strong>到指定的位置，节省阅读时间，此外，插入链接还有助于扩展文档知识承载的范围，一般用于对名人的介绍、专有名词的解释等。

## 操作说明

## 插入链接

选择要插入链接的位置或目标文字，点击文档工具栏上方选择<strong>链接</strong><img src="https://img.alicdn.com/imgextra/i3/O1CN01jf0C1htls0F0PAye_!!6000000003627-2-tps-200-200.png" referrerPolicy="no-referrer" alt="链接.png" />，若插入链接的位置或目标文字字体颜色显示为蓝色，则插入成功。

> 添加网页链接可点击左侧“添加网页链接”感受下插入链接的功能

## 链接相关设置

在插入链接的弹窗里，可对链接<strong>设置标题</strong>内容，且可以选择<strong>链接风格</strong>：**链接或卡片**。

<img src="https://img.alicdn.com/imgextra/i2/O1CN01lXMpFto218L2b86b_!!6000000001176-1-tps-1280-689.gif" referrerPolicy="no-referrer" alt="/Users/wenshuang/Library/Application Support/iDingTalk/ScreenCapture/阿里钉录屏_2025-09-09 110447.gif" />

## 取消插入链接

点击插入链接的位置或文字，在上方<strong>取消链接</strong>即可。
