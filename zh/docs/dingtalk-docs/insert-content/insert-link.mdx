在文档的编辑中，经常会使用插入链接，这样有助于阅读者**快速跳转**到指定的位置，节省阅读时间，此外，插入链接还有助于扩展文档知识承载的范围，一般用于对名人的介绍、专有名词的解释等。

## 操作说明

## 插入链接

选择要插入链接的位置或目标文字，点击文档工具栏上方选择**链接**<img src="https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/a/payv1LlXBSVj9e7v/34323cf6f4c448acb5888c49c612edb50521.png" referrerPolicy="no-referrer" alt="链接.png" />，若插入链接的位置或目标文字字体颜色显示为蓝色，则插入成功。

> 添加网页链接可点击左侧“添加网页链接”感受下插入链接的功能

## 链接相关设置

在插入链接的弹窗里，可对链接**设置标题**内容，且可以选择**链接风格**：**链接或卡片**。

<img src="https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/Kr4mlQx73MrgOxow/img/07b5b338-a827-478a-8afd-8c4e663e8335.gif" referrerPolicy="no-referrer" alt="/Users/wenshuang/Library/Application Support/iDingTalk/ScreenCapture/阿里钉录屏_2025-09-09 110447.gif" />

## 取消插入链接

点击插入链接的位置或文字，在上方**取消链接**即可。
