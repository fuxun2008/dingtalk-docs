「钉钉文档」可支持插入日期，省去了手动输入日期的繁琐，省去手动输入的麻烦，让日期格式规范化。且插入的日期可包含具体的时间点。

## 操作说明

选择添加日期的位置，点击顶部导航栏**插入—>日期**，在弹出的日历表上选择目标时间即可，添加的日期字体显示为**蓝色**，如需修改，可直接点击该日期进行重新选择。

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/jWgZOZyGj3BLqLX8/img/38c0f07d-1d9b-48fc-ac2f-d5550ee4e136.png)

## 补充说明

*   点击日历表上的**左右箭头** `<` `>` 可切换月份；

*   点击日历表左上角年份可切换年份；

*   勾选日历表下方的**时间**选项即可将具体的时间点显示在日期的后方，时间点可自行调整。


![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/jWgZOZyGj3BLqLX8/img/43dbeef8-29bf-4749-850b-a11cbc4f3081.png)
