## 使用说明

在钉钉文档中，可以插入<strong>宜搭链接</strong>，直接展示宜搭页面信息，并同步更新。可以直接使用文档「/」、「+」「插入」功能，便捷选中插入对应的宜搭页面。

目前仅支持<strong>宜搭公开访问页面</strong>、**DataV页面**，其他宜搭页面链接暂不支持。
</Note>
