有时候为了使文档内容的表格更直观，通常会使用插入图片的功能，且适当的插入图片可美化文档。

## 操作说明

## 添加图片

点击顶部导航栏 **插入—>图片** 或直接点击工具栏上传**图片**![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/a/pXbqkL21OcOxn9BO/0eeac74d704a4c0c82118f551cb618720579.png?x-oss-process=image/crop,x_8,y_9,w_55,h_47/ignore-error,1) ，即可将本地图片上传到文档中。

## 编辑图片

点击图片可调出图片工具栏，并进行相应的设置，目前支持的操作项如下：

*   提取图中文字

*   下载图片

*   设置图片样式

*   设置图片大小

*   裁剪图片

*   图片描述

*   添加链接

*   旋转图片

*   水平对齐

*   替换图片
