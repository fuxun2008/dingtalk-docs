有时候为了使文档内容的表格更直观，通常会使用插入图片的功能，且适当的插入图片可美化文档。

## 操作说明

## 添加图片

点击顶部导航栏 **插入—>图片** 或直接点击工具栏上传<strong>图片</strong><img src="https://img.alicdn.com/imgextra/i2/O1CN018OEt826XrvB06vGY_!!6000000003918-2-tps-55-47.png" referrerPolicy="no-referrer" alt="image.png" /> ，即可将本地图片上传到文档中。

## 编辑图片

点击图片可调出图片工具栏，并进行相应的设置，目前支持的操作项如下：

* 提取图中文字

* 下载图片

* 设置图片样式

* 设置图片大小

* 裁剪图片

* 图片描述

* 添加链接

* 旋转图片

* 水平对齐

* 替换图片
