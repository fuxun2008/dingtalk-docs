钉钉文档提供了丰富的第三方在线音视频嵌入能力，目前支持 **优酷**、**西瓜视频**、**腾讯视频**、**搜狐视频**、**哔哩哔哩**、和 **网易云音乐** 等平台，本文将逐一讲解如何从各个平台获取可嵌入链接。

> 请注意：嵌入内容由第三方提供，钉钉文档无法保证其长期可用，请遵守第三方使用规范和当地政策法规。

## 优酷

在播放页点击 **分享**，复制 **页面地址** 或 **通用代码**：

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/QoJGq7b2aDxBnAKe/img/686a4a38-0f40-49de-acee-5903901eee1a.png)

嵌入链接格式如下：

```application/xml
https://v.youku.com/v_show/id_xxx==.html?xxx
或
<iframe src='https://player.youku.com/embed/xxx'></iframe>
```

## 西瓜视频

在播放页点击 **分享**，复制 **视频地址** （您也可以直接复制浏览器地址栏链接）：

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/QoJGq7b2aDxBnAKe/img/2028fc88-eb56-48f8-bb6e-7a301034ba0f.png)

嵌入链接格式如下：

```application/xml
https://www.ixigua.com/xxx
```

## 腾讯视频

在播放页点击 **分享**，复制 **嵌入代码**（推荐） 或 **链接**：

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/QoJGq7b2aDxBnAKe/img/30de1095-eb89-4cd7-9b06-fa51204cbcca.png) 

嵌入链接格式如下：

```application/xml
https://v.qq.com/x/cover/xxx/xxx.html
或
<iframe src="https://v.qq.com/txp/iframe/player.html?vid=xxx"></iframe>
```

## 搜狐视频

在播放页点击 **分享**，复制 **通用代码**（不支持页面地址解析）：

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/QoJGq7b2aDxBnAKe/img/cb46fafb-9871-41fa-9142-e5ca26e0476d.png)

嵌入链接格式如下：

```application/xml
https://v.qq.com/x/cover/xxx/xxx.html
或
<iframe src="https://tv.sohu.com/s/sohuplayer/iplay.html?vid=xxx"></iframe>
```

## 哔哩哔哩

在播放页点击 **分享**，复制 **视频地址** 或 **嵌入代码**（您也可以直接复制浏览器地址栏链接）：

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/QoJGq7b2aDxBnAKe/img/1558438a-5d20-4478-8c9c-0676c187b98c.png)

嵌入链接格式如下：

```application/xml
https://www.bilibili.com/video/xxx
或
<iframe src="//player.bilibili.com/player.html?aid=xxx&bvid=xxx"> </iframe>
```

## 网易云音乐

复制 **单曲页地址**（推荐） 或点击 **生成外链播放器** 并 **复制代码**：

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/0QvjnAa932dBnXo5/img/f872ee7f-68ec-4621-9834-cec5a706770d.png)                     ![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/0QvjnAa932dBnXo5/img/0e319de6-6cfe-45d2-b7ee-dce7046b0b61.png)  

嵌入链接格式如下：

```application/xml
https://music.163.com/#/song?id=xxx
或
<iframe src="//music.163.com/outchain/player?type=2&id=xxx"></iframe>
```

## 粘贴链接转音视频卡片

在粘贴符合要求的 **西瓜**、**哔哩哔哩**、**YouTube** 和 **网易云音乐** 的链接时，您也可以通过粘贴菜单中的 “预览卡片” 直接将链接转为在线音视频卡片：

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/QoJGq7b2aDxBnAKe/img/c1f57745-529d-4cd0-817e-40010303ed40.png)

## 常见问题

1.  **是否支持短链？**
    
    钉钉文档不支持解析第三方平台短链，请尽量按照上述说明获取嵌入链接。
    
2.  **为什么嵌入的视频不能播放？**
    

部分平台可能对嵌入内容做了播放限制，这可能和资源类型有关（例如部分电影视频不允许嵌入方播放），也可能和您账号有关（例如您是否登录、是否会员等），您可以联系平台方客服咨询。另外，YouTube 视频需要确保您当前网络能连接该网站。
