钉钉文档提供了丰富的第三方在线音视频嵌入能力，目前支持 **优酷** 、 **西瓜视频** 、 **腾讯视频** 、 **搜狐视频** 、 **哔哩哔哩** 、和 **网易云音乐** 等平台，本文将逐一讲解如何从各个平台获取可嵌入链接。

> 请注意：嵌入内容由第三方提供，钉钉文档无法保证其长期可用，请遵守第三方使用规范和当地政策法规。

## 优酷

在播放页点击 **分享** ，复制 **页面地址** 或 **通用代码** ：

<img src="https://img.alicdn.com/imgextra/i3/O1CN018AhaxewzYdG19cwp_!!6000000006432-2-tps-569-438.png" referrerPolicy="no-referrer" alt="image.png" />

嵌入链接格式如下：

```application/xml
https://v.youku.com/v_show/id_xxx==.html?xxx
或
<iframe src='https://player.youku.com/embed/xxx'></iframe>
```

在播放页点击 **分享** ，复制 **视频地址** （您也可以直接复制浏览器地址栏链接）：

<img src="https://img.alicdn.com/imgextra/i1/O1CN01TlCzE72MWxK1UWbT_!!6000000003360-2-tps-735-772.png" referrerPolicy="no-referrer" alt="image.png" />

嵌入链接格式如下：

```application/xml

```

## 腾讯视频

在播放页点击 **分享** ，复制 **嵌入代码** （推荐） 或 **链接** ：

<img src="https://img.alicdn.com/imgextra/i3/O1CN01s0z7iAJ8mkD1W2Em_!!6000000004695-2-tps-747-689.png" referrerPolicy="no-referrer" alt="image.png" />

## 哔哩哔哩

在播放页点击 **分享** ，复制 **视频地址** 或 **嵌入代码** （您也可以直接复制浏览器地址栏链接）：

## 常见问题

1. **是否支持短链？**

 钉钉文档不支持解析第三方平台短链，请尽量按照上述说明获取嵌入链接。

2. **为什么嵌入的视频不能播放？**

部分平台可能对嵌入内容做了播放限制，这可能和资源类型有关（例如部分电影视频不允许嵌入方播放），也可能和您账号有关（例如您是否登录、是否会员等），您可以联系平台方客服咨询。另外，YouTube 视频需要确保您当前网络能连接该网站。
