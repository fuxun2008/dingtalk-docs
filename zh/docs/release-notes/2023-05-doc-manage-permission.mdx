## 安全管控权限升级，单篇文档支持添加「可管理」权限

单篇文档可以单独设置“可管理”权限，增加文档内容管理者，保障文档内容安全。

![image](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/93M0OzWEejZYlzeE/img/ef167284-9075-49dd-883a-ccbbed6f3226.png)

:::
[灯泡] 功能支持：Android/iOS/Mac/Windows/Web 用户使用

[本子] 使用说明：文档分享面板 > 权限管理
:::
