### 钉钉文档：双屏模式支持同时编辑两份文档

> 功能支持：桌面端

:::
    **功能价值**

双屏模式下，两份文档支持同时编辑，无需来回切换页面，轻松高效编辑文档、校对内容。

    **使用说明**

打开A文档，再点击A文档中插入的B文档——进入双屏模式（双屏模式下两份文档支持同时编辑）。

    **场景实践**

钉三多是新媒体公司的文案编辑，日常会使用钉钉文档校对、审核各类文案稿件，撰写文章等，常常会在文档里插入其他关联文档。当使用双屏模式时，两份文档可以同时编辑，校对、审核文案稿件时无需来回切换页面，让工作更轻松高效。
:::

![gaitubao_FhOUllORp_bClh9xpJk9elzdPJE7.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/YpLdn53D8oj5Oo83/img/f93c2250-b18b-4d4a-a285-eebcf9762b17.png)

### 钉钉文档：支持导入 confluence 空间文档

> 功能支持：桌面端

:::
    **功能价值**

支持批量导入 Confluence 空间文档，高效便捷完成文档迁移、备份与沉淀。

    **使用说明**

在「创建团队空间」的下拉菜单中——选择「导入 Confluence 空间」——根据指引上传 Confluence 空间 ZIP 包即可。

    **场景实践**

钉三多在广告公司负责活动策划，公司最近全员使用钉钉协作办公。团队之前的工作方案文档存储在  Confluence 空间，使用钉钉办公后，通过钉钉文档知识库里「导入 Confluence 空间」功能，将原 Confluence 空间里的文档批量导入知识库，一站式完成文档的迁移、备份与沉淀，同时也更方便团队成员学习。
:::

### 钉钉表格：筛选日期，年月自动分组

> 功能支持：桌面端支持全链路操作；移动端仅支持接收消息号通知

:::
    **功能价值**

在表格使用值筛选时，日期支持按年月分组，让信息筛选更高效便捷。

    **使用说明**

若选区内包含日期格式的数据——在筛选面板中年月日期会自动聚合。

    **场景实践**

钉三多是行政资产管理人员，日常会使用钉钉表格来登记公司资产出入库情况，有时候需要筛选时间较久的出入库记录，逐一查找非常浪费时间。现在使用钉钉表格值筛选时，列表中的日期会自动按年月分组，可以快速筛选出不同时间段信息筛选的资产入口数据，让使用表格更加便捷高效。
:::

### 钉钉日历：日程新增支持组织归属，管理更安全

> 功能支持：桌面端/移动端

:::
    **功能价值**

组织内部日程仅限组织内员工参与，员工离职后自动退出内部日程，一键创建内部会议群，让会议日程管理更高效、更安全。

    **使用说明**

1. 组织人选择同组织参与人预约日程时，支持将日历标记为该组织内部日程；

2. 内部日程不支持添加外部参与人；

3. 离职用户无法在钉钉日历中继续查看原组织日程，未发生的日程将已离职的组织人转移给下一位参与人；

4. 内部日程可发起同组织的内部会议群和对应组织的钉闪会；

5. 共享日程时仅支持共享同组织日程，管理更安全。

    **场景实践**

钉三多是一名房地产公司的销售经理，日常工作中，需要使用钉钉日历创建日程组织内部成员进行会议沟通、以及和客户沟通各种项目事宜，使用该功能后，组织内部的日程和会议尽显内部员工参与，还可以一键发起、创建内部会议群，避免因不慎邀请外部参与人导致的信息、数据等泄漏问题。
:::
