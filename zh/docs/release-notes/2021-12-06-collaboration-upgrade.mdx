# 钉钉文档

### 1.文字：分栏布局

功能价值：对文档内容进行分栏

核心操作：斜杠命令——插入分栏

![image](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/Q35O8Y27e5PLl9Vb/img/159d183c-8606-4edb-8111-f2775460ef28.png)

### 2.文字：模板按钮

功能价值：快速新建文档内容模板

核心操作：

在极简模式下，输入斜杠命令 —— 插入——模板按钮；

在专业模式下：点击顶部菜单 —— 插入 —— 模板按钮

![image](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/Q35O8Y27e5PLl9Vb/img/bdf3d365-ef98-4c42-a7b8-aada0064f737.png)

### 3.表格：插入附件

功能价值：支持上传多种类型文件，轻松搭建团队线上资料

核心操作：插入——附件。本地文件、图像、音视频等格式均支持。

![image](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/Q35O8Y27e5PLl9Vb/img/4ec70a51-0cfb-4bc1-87ef-ea03d9915f61.png)

[请至钉钉文档查看附件《钉钉表格支持插入附件-done.mp4》。](https://docs.dingtalk.io/i/nodes/Xzr6RBgD3LYJnak7roz1VZPnyElvd7e9?iframeQuery=anchorId%3DX02ky0xb55drrdmutn85m8)

### 4.表格：表单支持导出PDF、打印。（目前仅支持电脑端）

功能价值：支持实时预览，自定义布局样式，数据无损导出，表格轻松存档

核心操作：顶部栏——表格——导出PDF或打印

![image](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/Q35O8Y27e5PLl9Vb/img/973fa102-856c-45bf-b4b1-af910018a58f.png)

[请至钉钉文档查看附件《钉钉表格新增在线打印-done‘.mp4》。](https://docs.dingtalk.io/i/nodes/Xzr6RBgD3LYJnak7roz1VZPnyElvd7e9?iframeQuery=anchorId%3DX02ky0xb55dmuph4pmxfr)

### 5.表格：将某行置顶（目前仅支持电脑端）

功能价值：史上最强冻结，Pin 住你的所有表头

核心操作：选中某行，点击工具栏——冻结——选中行固定在顶部。

![image](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/Q35O8Y27e5PLl9Vb/img/bf4cfcdb-b7c8-4f22-a0be-267e659cb01c.gif)

[请至钉钉文档查看附件《钉钉表格新增选中行置顶-done.mp4》。](https://docs.dingtalk.io/i/nodes/Xzr6RBgD3LYJnak7roz1VZPnyElvd7e9?iframeQuery=anchorId%3DX02ky0xb55di4c6qxogrsk)

### 6.便签：内容生成图片分享

功能价值：一键将内容升级为精美“便笺”

核心操作：便签页面——右上角分享图标——生成

![image](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/Q35O8Y27e5PLl9Vb/img/a1906513-d7c7-45a1-b67a-bd4eee3698e5.png)

### 7.脑图：插入图片

功能价值：新增插入图片功能，丰富内容类型、提升表达效果

核心操作：选中——插入图片

![image](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/Q35O8Y27e5PLl9Vb/img/703282de-fadd-4264-8493-0fab422b1350.png)

# 日历

### 1.日程设置支持可选参会人

功能价值：同步日程，该参会人可自主选择是否参与

核心操作：在日程中添加参会人时，可支持将参会人添加为“可选参会人”

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/a4jKqme6kAVLqw19/img/8f191929-91ba-4d49-9822-ef1cb66cb7de.png)

### 2.日程响应支持“暂定”状态

功能价值：日程可标记为“暂定”，响应状态更精确

核心操作：收到日程卡片——选择暂定

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/a4jKqme6kAVLqw19/img/a1f061a4-b470-4050-9de2-5f63bc82031e.png)

# 钉盘

### 1.群文件支持置顶

功能价值：置顶关键的文件，更方便查找

核心操作：在群文件——更多，点击“设为我的置顶”

![image](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/Q35O8Y27e5PLl9Vb/img/8cf009ae-deda-4dfe-938f-1dd4725f3d2f.png)

### 2.群容量上限单独设置（支持网页端OA后台操作）

功能价值：方便进行群文件容量细粒度管控

核心操作：OA后台——钉盘——容量管理——群文件，可设置单个群的容量上限

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/a4jKqme6kAVLqw19/img/87aeac75-936c-496b-b571-33f7a3d1eb5b.png)

[请至钉钉文档查看附件《云盘灵活设置群容量上限-done.mp4》。](https://docs.dingtalk.io/i/nodes/Xzr6RBgD3LYJnak7roz1VZPnyElvd7e9?iframeQuery=anchorId%3DX02ky0xb55dgw9fyaonog)

### 3.快速找到聊天内的文件夹

功能价值：查找聊天文件支持按“文件夹类型优先”排序，提升查找效率

核心操作：聊天文件列表-排序-文件夹类型优先

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/a4jKqme6kAVLqw19/img/eadaf769-91d8-4e9e-ad24-7850db1ef472.png)
