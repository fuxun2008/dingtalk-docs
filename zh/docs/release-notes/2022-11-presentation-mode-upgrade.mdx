### 钉钉文档｜演示模式支持自定义分享者姓名，灵活设置汇报主讲人。

文档由多人编辑，汇报时却无法显示正确主讲人？++**新增「自定义分享者」**++，演示模式下支持自定义修改分享者名称，也可设置不显示分享者。即使多人编辑文档，也可以自由设置显示当前汇报主讲人。

### 钉钉表格｜兼容性更好了，本地文件在线编辑，支持撤销工作表保护。

以往在钉钉打开本地 Excel 文件，却发现工作表被锁定，无法在线编辑怎么办？别担心，本期钉钉表格兼容性能力升级，即使本地 Excel 文件有工作表保护，++**可直接鼠标右键设置「撤销工作表保护」**++，让在线编辑体验更顺畅。

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/av9kqDLL15XNqVxe/img/77e478b3-13bd-47c2-a85b-b5741b45acd2.png?x-oss-process=image/crop,x_30,y_0,w_1072,h_714/ignore-error,1)

:::
💡 功能支持｜桌面端

📖 使用说明：

选择本地表格，点击在线编辑

命中自研编辑时，若表格中有工作表保护，右键工作表，提示可以撤销工作表保护

当用户选择撤销时，提示用户，撤销后不可重新设置密码，但可以通过锁定功能代替

### 钉钉 Teambition｜工时应用优化

Teambition ++**提供更细致的「工时」字段**++填写约束能力，统筹管理更轻松。

:::
**场景1：**项目成员创建任务时，总是忘记填写工时？本次优化，支持将工时字段在任务创建时设置为必填。
:::

![image](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/Wmeona2AMRBaqXxj/img/249f6411-0140-48de-af59-b07dea37e327.jpeg)

:::
**场景2：**成员挪动任务进入下一个阶段时总是忘记填写工时？本次优化，支持填写「工时」字段才能实现任务流转。
:::

![image](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/Wmeona2AMRBaqXxj/img/66c50d4d-9ab7-43d0-9537-2deca78d2425.jpeg)

:::
**场景3：**项目成员在提交「实际工时」时往往忘记填写「工作进展」？本次优化，支持填报「实际工时」时，「工作进展」为必填项，便其他成员快速了解实际工时背后的工作进展细节。
:::

![image](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/Wmeona2AMRBaqXxj/img/928c3af7-447b-4b0b-95a3-766931fd167e.jpeg)

:::
💡 功能支持：桌面端

📖 使用说明：

场景1:开启「工时」应用-配置任务类型-找到「计划工时」和「实际工时」企业级字段，点击「…」勾选「设置为必填字段」进行配置

场景2:进入配置工作流规则-选择「执行条件」-「必填字段」-添加「计划工时」或者「实际工时」字段。

场景3:开启项目「工时」应用-「菜单」-「更多设置」-「工时设置」-开启「实际工时-工作进展必填」开关
:::
