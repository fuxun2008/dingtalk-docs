## 钉钉文档：自动调整中英文间距

> 功能支持：桌面端

:::
    **功能价值**

智能识别中英文，自动调整间距，免去手动操作步骤繁琐，让文档内容编辑更规范。

    **使用说明**

打开页面设置，在编辑行为中开启**中文/英文/数字间自动添加空格**选项，开启后在文档中混合输入中文/英文/数字，会自动填充空格。

    **场景实践**

钉三多是企划部的内容运营，日常会使用钉钉文档编辑公司各类型宣传稿件、公告通知、行政文档等。使用该功能后，写稿时中文前后的英文、数字就可以自动添加空格，不需要再逐个校对格式，让文章格式更规范标准，减轻了格式校对的工作量。
:::

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/EPd6l2oZ414gn7Ma/img/f7d12d73-1d67-460d-a885-c595d2fb23ae.png)

## 钉钉表格：关注选区更新

> 功能支持：桌面端支持全链路操作；移动端仅支持接收消息号通知

:::
    **功能价值**

新增关注选区功能，选取数据增删变化及时提醒，成员协作更及时顺畅。

    **使用说明**

顶部菜单新增的**协作**—选择**关注选区**—即可设置**希望关注的选区**和**需要通知的成员。**

    **场景实践**

钉三多是办公室行政文员，日常会使用钉钉表格来汇总不同部门的办公耗材需求。使用「关注选区」功能后，各部门负责人通过钉钉表格提交办公耗材需求信息，单元格有更新变动，钉三多就可以第一时间收到钉钉消息通知，不需要单独提醒，不仅降低沟通成本，同时也提高了协作效率。
:::

![lQLPDhtUgzd0Zu_NCILNDS-wpe83nXGY2tECWyN6RoDBAQ_3375_2178.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/EPd6l2oZ414gn7Ma/img/773d35e2-4217-407d-890a-94b91847b644.png)

_注：只有拥有表格__**仅可查看**__及__**以上权限**__的用户才能收到通知，离职成员不会再接收通知；通知方式由钉钉文档消息号通知。_

## 钉钉项目：「我的任务」快捷创建支持选择「所属项目」

> 功能支持：网页端/桌面端

:::
    **功能价值**

更便捷地分发任务至不同项目中，缩短创建任务路径。

    **使用说明**

进入「我的任务」页面，点击顶部创建框快捷创建任务，可直接选择「设置项目」。

    **场景实践**

钉三多是一名项目经理，参与了 N 个项目，平时会用「我的任务」汇总查看自己执行的所有工作。以前在「我的任务」首页创建任务不能直接选择任务归属的项目，得先创建好，再进入任务详情页修改。现在使用了该功能后，任务创建变得更加便捷，时间缩短了一半。
:::

## 钉钉项目：「我的任务」和「捷径」增加「显示子任务」开关

> 功能支持：网页端/桌面端

:::
    **功能价值**

可以根据需要灵活选择是否「显示子任务」，覆盖更多办公场景。

    **使用说明**

在「我的任务」和「捷径」中，点击「视图」，下拉菜单里选择开关。

    **场景实践**

钉三多是一名项目经理，平时喜欢在「我的任务」和「捷径」里平铺直叙地查看任务。因其中很多任务的颗粒度较大，它们被层层拆解为了子任务、子子任务，随着时间的推移，任务数量越来越多，导致钉三多经常无法关注到重点。有了「显示子任务」开关后，钉三多可以聚焦在父任务上，关注重点。
:::

![钉钉项目：「我的任务」和「捷径」增加「显示子任务」开关.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/Kr4mlQ9V0gddlxow/img/86664960-97a1-44c3-b504-7a867660f889.png)
