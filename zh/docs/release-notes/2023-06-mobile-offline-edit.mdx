## 钉钉支持离线打开使用，网络恢复自动更新，无需手动操作

新功能｜钉钉文档移动端支持离线编辑，不必受到地点和网络条件的限制

在出差路上坐飞机、搭高铁、乘车途中，遇到离线或者弱网的情况，在移动端仍可以正常浏览和编辑文字、表格，当网络恢复时，自动同步编辑内容。

![Billboard@1x.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/yBRq1bbED84mOdv1/img/64204d34-ca4c-4838-8801-323562b415ed.png)

:::
[灯泡] 功能支持：支持：Android/iOS/Pad 用户使用

[本子] 使用说明：使用手机切换成飞行模式，进入钉钉文档即可体验
:::
---

## 钉钉文档「分栏」再次升级，布局排版更方便 

体验优化｜分栏手柄快速地新增、删除和移动分栏，让内容创作与排版更流畅

钉钉文档分栏新增分栏手柄 ，更方便地新增左右侧分栏 ，还支持拖拽调整位置及删除当前分栏，布局排版更方便​。

![分栏手柄.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/yBRq1bbED84mOdv1/img/c12b1815-ca22-4550-86cd-411403eec98a.png)

:::
[灯泡] 功能支持：Mac/Windows 用户使用

[本子] 使用说明：

1、 点击文档内的分栏即可查看到分栏手柄

2、点击分栏手柄即可在工作栏中向左或向右新增分栏以及删除多余分栏

3、鼠标选中分栏手柄，即可移动分栏位置
:::
---

## 优化体验升级：表格行列拖拽优化，表格行列调整更轻松

体验优化｜摆脱行列拖拽难操作痛点，让表格行列调整更便捷

文档内插入的表格行列优化，帮你清晰区别行列，便捷地选中目标行/列并轻松快速将行/列拖动到目标位置。

![拖拽优化.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/yBRq1bbED84mOdv1/img/3f0f506c-d9a7-4965-b817-0eb86cc9d33f.png)

:::
[灯泡] 功能支持：Mac/Windows 用户使用

[本子] 使用说明：在钉钉文档内插入表格，选中某一行或某一列，按住拖拽移动行列的位置
:::
---

## 公开发布支持「内容大纲」，快速定位内容位置

新功能｜公开发布文档内容大纲、清晰了解内容框架

想要快速了解公开发布文档内容框架、获取关键信息？钉钉文档对外发布新增内容大纲，文章内容一目了然，快速定位目标位置。

![内容大纲.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/yBRq1bbED84mOdv1/img/77fc8b78-a0e9-432e-a38c-9ffe7e3a958a.png)

:::
[灯泡] 功能支持：Mac/Windows 用户使用

[本子] 使用说明：文档设置对应的标题层级，将文档公开发布，自动带大纲
:::

**文档卡片透出与你亲密的协作者，清晰查看文档更新动态**

**新功能｜聊天文档卡片清晰展示阅读者，不用打开文档即可查看文档协作信息**

聊天卡片上支持千人千面地展示此文档阅读者，透出与你近期最关注或协作最紧密2位用户信息，第一时间了解谁已经看过或更新过文档。

![亲密的协作者.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/yBRq1bbED84mOdv1/img/37503427-5274-4555-86c5-5afb597f378e.png)

:::
[灯泡] 功能支持：Android/iOS/Mac/Windows  用户使用

[本子] 在以下场景会展示亲密人相关信息：

1. 有亲密人阅读、有点赞（移动端不展示点赞）

2. 上次打开后有亲密人更新

3. 多于10人看过，但无亲密人

## 表格视图粘贴支持直接转换对应的字段，让表格内容转化多维表字段更便捷

新功能｜通过复制粘贴快速将表格内容转换多维表字段，减少重复操作，让字段编辑更高效

表格视图支持从 Excel、文本、多维表、电子表格粘贴并转换对应的字段，并且支持首行转为表头，让编辑字段更便捷、更高效。

![表格粘贴.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/yBRq1bbED84mOdv1/img/6f423c79-2cd2-47b1-bba8-2f127d5e66d9.png)

:::
[灯泡] 功能支持：Android/iOS 用户使用（钉钉专业版、专属版权益）

[本子] 使用说明：在 excel 上复制，选中多维表单元格 - 粘贴
