## 文档协作更清晰，新增「我的知识数据」

新增「我的知识数据」，可查看个人使用文档的情况，支持按时间周期统计分析个人文档的创建、查看、协作情况，还有文档推荐功能，帮助发现优秀文档和团队知识。

:::
[▶️ 看视频了解更多](https://cloud.video.taobao.com/play/u/null/p/1/e/6/t/1/429312045036.mp4)
:::

![钉钉文档新增我的知识数据.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/8K4nyaJJE6MVnLbj/img/f9a8de4d-eee8-4804-995d-114e8b564e98.png)

:::
[灯泡] 功能支持：Android/iOS/Mac/Windows 用户使用

[本子] 使用说明：

钉钉文档首页，点击个人头像，点击我的知识数据；

钉钉文档功能号 ，点击数据周报卡片
:::
