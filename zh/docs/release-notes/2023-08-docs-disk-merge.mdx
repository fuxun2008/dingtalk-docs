## 新功能｜保障日程安全不泄露，让日程安全管理更加得心应手

创建日程时，默认创建于当前组织，当添加组织外参与人会进行安全提醒；日程组织人离职时，日程将自动移交给下一位参与人；如组织内成员全部离职，日程将被自动取消，保证企业数据不泄露。

![image](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/QoJGq77KNdJ6qAKe/img/d30c0fd8-2556-400e-b6e4-7c8de733e20e.jpg)

</Note>
[灯泡] 功能支持：Android/iOS/Mac/Windows 用户使用

[本子] 使用说明：

创建日程时，默认缺省组织为框架组织；

归属于组织的日程，支持添加外部参与人，日程中标记为外部参与人，并做相应的安全提醒；

组织内成员离职，日程组织人将转让给同组织内下一位参与人，当组织内成员全部离职，则日程会被自动取消
<Note>
