## 🆕【钉钉文档：支持插入更多元素】

支持插入语雀文档、西瓜视频、搜狐视频、Bilibili、网易云音乐，让文档展现形式更丰富，内容更全面。

## 🆕【钉钉文档：插入面板快捷键优化】

在原来的「+」号触发基础上，新增斜杠「/」 触发，同时支持插入搜索，输入元素类型名称实现快捷插入。
![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/NybEnBYWazV3lP13/img/fabe17e5-cb5b-4b06-8029-3d0e255b2c3d.png)
