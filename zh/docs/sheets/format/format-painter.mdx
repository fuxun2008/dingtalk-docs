在表格处理与美化的过程中，经常会碰到表格颜色、字体、格式等需要大面积修改，但是逐个修改太过麻烦和浪费时间，那么格式刷就可以快速简单完成这些操作。省去了逐个处理的多个步骤。

## 操作说明

## 格式刷

*   首先选择好需要复制格式的目标单元格

*   然后点击工具栏左侧<strong>格式刷</strong><img src="https://img.alicdn.com/imgextra/i3/O1CN01NZEfnFG3WlD0PAye_!!6000000003497-2-tps-200-200.png" referrerPolicy="no-referrer" alt="格式刷.png" /> ，即可快速将目标单元格的格式复制下来，此时，鼠标箭头变成刷子形状，就代表格式复制成功

*   最后再选中待处理格式的单元格，点击一次，即可将复制的格式应用于待处理的单元格，待处理的单元格会立马变成与目标单元格一样的格式，就代表格式刷应用成功

## 清除格式

*   首先选中待清理的目标单元格

*   然后点击工具栏左侧的<strong>清除格式</strong><img src="https://img.alicdn.com/imgextra/i3/O1CN01ekipD4fcYbI0PAye_!!6000000000806-2-tps-200-200.png" referrerPolicy="no-referrer" alt="清除、擦除.png" />**，或使用快捷键 Ctrl + / ( Mac：Cmd + / )** 即可高效完成操作。或<strong>右键菜单—>清除—>清除格式。</strong>
