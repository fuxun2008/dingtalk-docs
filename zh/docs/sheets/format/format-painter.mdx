在表格处理与美化的过程中，经常会碰到表格颜色、字体、格式等需要大面积修改，但是逐个修改太过麻烦和浪费时间，那么格式刷就可以快速简单完成这些操作。省去了逐个处理的多个步骤。

## 操作说明

## 格式刷

*   首先选择好需要复制格式的目标单元格

*   然后点击工具栏左侧**格式刷**![格式刷.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/a/RbEPGwrl2TAX5jq1/bf63f9f161e8433499ed1b6c884c38460521.png) ，即可快速将目标单元格的格式复制下来，此时，鼠标箭头变成刷子形状，就代表格式复制成功

*   最后再选中待处理格式的单元格，点击一次，即可将复制的格式应用于待处理的单元格，待处理的单元格会立马变成与目标单元格一样的格式，就代表格式刷应用成功


## 清除格式

*   首先选中待清理的目标单元格

*   然后点击工具栏左侧的**清除格式**![清除、擦除.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/a/RbEPGwrl2TAX5jq1/39f2f17e82cc4c79bd0e8e9bed01a70a0521.png)**，或使用快捷键 Ctrl + / ( Mac：Cmd + / )** 即可高效完成操作。或**右键菜单—>清除—>清除格式。**


![44d868d6115c89beafea82af6f9a5009.gif](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/ya2QnVLkrV4bO4XB/img/59d5161a-87fa-4479-a383-8d89bcf6c56b.gif)
