文本样式的调整往往能让表格内容重点突出、主题鲜明，增加表格文本显示的多样性，使表格阅读者更易捕捉表格中的重点，更好的理解表格内容。且合理的调整文本样式，可提升表格的美感。

# 操作说明

## 文本样式一：加粗![加粗.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/a/dzZLzNEPPTzQwM1O/46e165f92aef4590852b275ca6446c030521.png) 

加粗使得文本被扩大，体积变大，且字体颜色会被加重，使文本表现效果更明显。一般用于表格中的行首或列首或表格名称，好比文档中的“标题”加粗就属于常规的处理方式。

选中目标单元格，点击顶部**菜单—>格式—>文本样式—>加粗**，或选中目标文本，点击工具栏中的**加粗**更快捷

## 文本样式二：斜体![斜体.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/a/dzZLzNEPPTzQwM1O/7a423d56603e4323ad0710b9170311140521.png) 

选中目标单元格，点击顶部**菜单—>格式—>文本样式—>加粗**，或选中目标文本，点击工具栏中的**斜体**更快捷

## 文本样式三：下划线![下划线.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/a/dzZLzNEPPTzQwM1O/403489b8c34a4785856f6e8d5ebd4d780521.png) 

下划线一般用于用于强调文本中的重点，即所谓的“划重点”。

选中目标单元格，点击顶部**菜单—>格式—>文本样式—>下划线**，或选中目标文本，点击工具栏中的**下划线**更快捷

## 文本样式四：删除线![删除线.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/a/dzZLzNEPPTzQwM1O/ea7f5362d09d4cd48bcf1c3fd094c5290521.png) 

**（快捷键 Ctrl + Shift + X ）（ Mac：Cmd + Shift + X ）**

删除线一般用户原来内容的修改和审批。

选中目标单元格，点击顶部**菜单—>格式—>文本样式—>删除线**，或选中目标文本，点击工具栏中的**删除线**更快捷，或使用快捷键 Ctrl+Shift+X
