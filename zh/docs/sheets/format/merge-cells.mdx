在日常的表格制作中，经常需要对表格主题与分类进行处理，一个标题下往往包含多个内容，则需要将标题所在位置的多个单元格进行合并。合并单元格的一般在处理首行/列的时候用的比较多。

![2f443ed6dc99033e38d9187d7ce3c81c.gif](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/Wmeona0Wma1jlXxj/img/7d5dbe0b-e8a4-4bc4-8767-912273d53a64.gif)

# 合并单元格

选择需要合并的目标单元格，点击工具栏**合并单元格**![合并单元格.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/a/dY0EVbm5ei32JXE1/df87b3fd3ca14bd4bcf9a8612c39fee90521.png) 即可快速将单元格合并。

# 补充说明

*   两个或两个以上已被合并过的单元格之间无法进行合并，若想继续合并，则需要先取消合并，才能合并生效。
    
*   若需要对文本内容不一样的两个或多个单元格进行合并，系统会默认只保留左/上的文本内容，其余文本内容将被清除。
    

# 取消合并

选择已被合并的单元格，就会发现工具栏中合并单元格会变成**拆分单元格**![取消合并单元格.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/a/dY0EVbm5ei32JXE1/f78ffddafb72450d907db6ad3cc06c2a0521.png) ，点击即可取消合并。

# 补充说明

*   取消合并支持批量操作，即一次选择多个已合并的单元格可同时取消合并。
    
*   取消合并后的单元格文本默认保留在上行，对齐方式保持不变。
