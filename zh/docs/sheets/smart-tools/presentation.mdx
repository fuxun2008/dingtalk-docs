在做数据汇报时，钉钉表格支持演示模式，一键可让表格秒变PPT模式，使数据汇报更顺畅，省去做 PPT 的繁琐。

## 操作说明

## 如何进入演示模式

点击右上角**演示模式**![演示播放.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/a/pAxq25KZOS4DEPj3/624612468f0c4226bec4c1114bac537e0521.png) ，即可让工作表秒变 PPT

## 演示模式调整

在演示模式界面，可作以下调整：

1.  **字体大小**：点击右上角缩放A，可对字体进行调整

2.  **界面比例**：右下角比例框，可对显示界面进行大小调整

3.  **新建临时筛选视图****：**选中目标区域，再点击左上角（图标）筛选，可新建临时筛选视图，可对数据进行横向、纵向的比对，增加观众对数据的理解。

4.  **排序**：选中目标区域，点击左上角排序，可对选区进行升序或降序排列，或不选择目标区域，点击左上角排序，可对整个表格进行升序或降序排列处理。


    （注意：不能对包含纵向合并单元格的范围进行排序）

![ba7af2e45390a3ac2315ddb1b6f9d758.gif](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/av9kqDwVjyEanVxe/img/ff89fe25-2490-40fb-b1fb-5fefeee1fafb.gif)

## 退出演示模式

*   点击左上角**“退出演示模式”**的 button 可立即退出

*   按 F11 可退出演示模式的全屏模式
