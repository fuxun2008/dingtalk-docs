在钉钉表格中，若你需要将表格通过其他平台发送给客户或他人查看，可以使用表格打印和导出功能

## 操作说明

打印：点击顶部导航栏**菜单—>表格—>打印**即可打印

<img src="https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/7mxPOGwra6rQOKa9/img/4e079c04-bae1-44fa-928c-3a25a56484a2.gif" referrerPolicy="no-referrer" alt="screenshot_2025-09-11_10-17-05.gif" />

导出：点击顶部导航栏**菜单—>表格—>下载为**即可快速保存至本地，导出面板中可以重新设置目标表格的标题，但原始表格不受影响。（目前钉钉表格支持导出为 XLSX. CSV. TSV. PDF形式的本地表格）
