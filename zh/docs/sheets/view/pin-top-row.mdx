钉钉表格电脑端支持指定行在滚动过程中始终固定在表格顶部，轻松Pin 住你的所有表头

# 操作说明

*   固定行置顶：电脑端选中某一行>>点击工具栏>>冻结>>选中行固定在顶部
    
    ![63e628ae39f0ca5787716f215173f18f.gif](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/a4jKqmBvWEdLOw19/img/9b0b2609-4a2a-4947-8b8b-209a90947b2b.gif)
    
*   取消固定行置顶：电脑端选中已置顶的行>>点击工具栏>>冻结>>取消固定
    

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/a4jKqmBvWEdLOw19/img/7c6b20c1-d1ff-4876-8527-254ef997c342.png)
