钉钉表格的单元格支持插入评论，通过「单元格评论」，可直接对内容进行备注，还可以@成员实时协同，提升了内容创作生产、编辑的效率

# 操作说明

*   单元格评论：选中某个单元格 - 右键【添加评论】即可
    

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/Kr4mlQPr67PvOxow/img/a5546428-7883-4211-af8c-069f023df489.png)

*   在评论中 @人，可以在消息窗口通知对方，点击消息即可进入表格查看评论内容。
    

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/Kr4mlQPr67PvOxow/img/f6ac51cf-83a5-4a72-a81e-721bc3f3d446.png)

注：

1.  当您@ 其他成员时，对方将通过「钉钉单聊」收到评论发起人@ 他的消息提醒
    
2.  单元格评论支持插入表情
    
3.  可以针对同一个单元格内容做出追加评论或者回复
    
4.  可以点击「工具栏-评论-查看所有评论」，活通过右侧面板，查看当前工作表内的全部评论
    
5.  仅可以删除自己发出的评论，评论删除后无法找回
    
6.  通过右侧的评论列表，可以查看已解决的评论，并恢复它，即可重新展开讨论
