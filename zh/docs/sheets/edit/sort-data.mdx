在钉钉表格中，你可以使用「 排序 」按照指定的顺序将数据重新排列组织，这是数据整理的一种重要手段。

## 操作说明

选择目标区域，点击工具栏中的<strong>排序</strong><img src="https://img.alicdn.com/imgextra/i1/O1CN01hYrJthbCrjJ0PAye_!!6000000001341-2-tps-200-200.png" referrerPolicy="no-referrer" alt="排序.png" /> 即可，在下拉菜单中还可对排序方式进行选择，并支持「自定义排序」，根据个人需求，调整表格排序。

*   数字类型的数据，一般按数值的整体大小进行排序；

*   文本类型的数据，一般按照英文字母、中文拼音字母的前后顺序进行排序；

*   温馨提示：为了得到正确的排序结果，排序前一定要对数据的格式进行规范化处理。
