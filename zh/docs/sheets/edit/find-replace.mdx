在钉钉表格中，你可以通过「查找替换」功能快速查找和替换数据，或使用键盘<strong>快捷键 Ctrl + F（ Mac ： Cmd + F ）</strong>来查找数据。

## 操作说明

1.  在工具栏最右侧点击<strong>更多->「查找替换」</strong><img src="https://img.alicdn.com/imgextra/i2/O1CN01H4AL2PbASJK04WyT_!!6000000003520-2-tps-36-33.png" referrerPolicy="no-referrer" alt="image.png" /> ，展开面板，在**「查找」**选项中输入希望查找的数据，数据形式支持文本、数值、符号；

2.  包含查找数据的单元格会被实时搜索出来，通过黄色高亮呈现，匹配英文文本时不区分大小写；

3.  若想替换查找到的数据，可在 **「替换为」** 输入框中输入希望替换的数据，点击 **「替换」** ，支持替换选中的单元格数据，或点击 **「替换所有」** 对全部查找出来的数据进行替换。
