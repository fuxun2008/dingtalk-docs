你可以在钉钉表格中使用「自动填充」，基于已有数据的输入规则，进行快捷复制和填充，以便于完成单元格数据的规律性填充，适用于内容复制、序列编号等数据输入场景。

# 操作方法

1.  选中一片已经填写部分数据的单元格区域，作为自动填充的数据基础；
    
2.  鼠标悬停放置在选区右下角的单元格右下角，会发现光标变成**「 + 」**样式，即为**填充柄**；
    
3.  按住填充柄，向垂直或水平方向拖动，即可在对应方向的空白单元格中填充数据；
    
4.  释放填充柄后，填充区域的右下角出现填充选项 ![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/a/pP4YNXW52caMgJma/83023d3eb4c044459fb6a68e077e27780579.png) ，点击可选择：**复制单元格、序列填充、仅填充格式、不带格式填充。**
