可以在钉钉表格中使用快捷键「复制」（或「剪切」）和「粘贴」，对表格内容进行高效编辑。

## 操作说明

## 复制（或剪切）内容

*   **复制**：选中目标区域，使用<strong>快捷键「 Ctrl + C 」（ Mac ：「 Cmd + C 」）</strong>完成内容复制。

*   **剪切**：选中目标区域，使用<strong>快捷键「 Ctrl + X 」（ Mac ：「 Cmd + X 」）</strong>完成内容剪切。

此时选区边缘线会变成 **「虚线」** 样式，代表内容已完成复制或剪切<img src="https://img.alicdn.com/imgextra/i1/O1CN01AiJe9ClOb2C0Ba2A_!!6000000001473-2-tps-92-34.png" referrerPolicy="no-referrer" alt="image.png" />

## 粘贴内容

选中单元格区域，使用<strong>快捷键「 Ctrl + V 」（ Mac ：「 Cmd + V 」）</strong>完成内容粘贴。

*   **默认粘贴** ：粘贴内容时，会带上复制（或剪切）内容的原始格式、样式；

*   **选择性粘贴** ：也可以选择只粘贴值、样式和公式。

    *   具体方式为：完成粘贴后，可以看到选区右下角出现 <img src="https://img.alicdn.com/imgextra/i1/O1CN017CFdPWhCQhE03WXE_!!6000000007556-2-tps-28-24.png" referrerPolicy="no-referrer" alt="image.png" />  （选择性粘贴图标），点击即可选择自己希望粘贴的方式，或完成粘贴后，选区点击右键菜单中的「选择性粘贴」进行选择。

<img src="https://img.alicdn.com/imgextra/i4/O1CN013zooWqEsWYI2b862_!!6000000000792-1-tps-1280-654.gif" referrerPolicy="no-referrer" alt="screenshot_2025-09-04_15-44-15.gif" />

*   **复制为图片** ：复制内容时，会在选择框右下角出现「复制为图片」选项，点击后复制内容可以粘贴为图片进行保存。
