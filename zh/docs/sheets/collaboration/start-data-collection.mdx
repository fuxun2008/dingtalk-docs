## 功能价值

联动智能填表，**填表内容互不可见，收集结果自动汇总回表格**，管理统计更高效。

## 使用场景

日常办公，收集数据必不可少，但当遇到要汇总敏感、隐私性较强的数据时，填表人不愿自己的信息被他人看见，如果逐一设置权限，那么统计人的工作量就会陡增。通过钉钉表格「收集数据」功能，填表时内容互不可见，自动汇总表格，结果只有创建人可以查看，收集处理效率大大提高。

## 操作方法

*   新建钉钉表格，在左上方【菜单】-【协作】-【收集数据】-【新建收集表】。


![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/P4maOgNgLzQXqWNX/img/e785e2ff-ba1c-4c51-ba73-f399e38d3a04.png)

*   在编辑表单页面，根据需求从左侧问题栏拖拽相应的模块进行创建即可，编辑好点击【完成】进入发布设置。


![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/P4maOgNgLzQXqWNX/img/90a6b950-26ef-49a4-ac5d-d97cc595dc9f.png)

*   在设置页面，可以根据需求进行表单设置，完成后，点击右上角【发布】，可以通过聊天、链接、二维码三种方式，将收集表单分享给多人进行填写。


![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/P4maOgNgLzQXqWNX/img/a40646c5-7814-432a-a327-087b4c9df447.png)

*   当填写人完成填写提交后，信息会自动汇总至表格中，统计人可直接用钉钉表格的能力对数据进行分析和统计。**「注意：此时所有收集的数据，只有创建人才能看到，轻松保护填表人隐私」**


![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/P4maOgNgLzQXqWNX/img/cc4879e2-36a6-4a0b-a0cf-303c89a47b05.png)

*   此外，若创建人要对表单做编辑和调整，可以点击表单卡片右上方箭头【打开收集表】，在表单填写页面右上角，可以进行**分享、统计查看、更多编辑**等设置。


![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/P4maOgNgLzQXqWNX/img/9307a07f-3307-47c2-8ddd-5f1083d8fb13.png)
