# INDIRECT 函数

INDIRECT 间接引用函数，是将文本解析为范围引用。相对来说，在大多公式中常常是直接填写引用的，如 SUM(A1:A5)，其中的“A1:A5”前后无引号包裹，即直接表示引用范围 A1:A5。

通常来说，INDIRECT 函数是与拼接符号"&"或文本函数搭配使用的，例如：
