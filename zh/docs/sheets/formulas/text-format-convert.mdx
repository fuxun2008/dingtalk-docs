## 数值、日期 => 文本：TEXT 函数，或拼接符号“&”

TEXT 函数的作用是对各类数据（第 1 个参数）应用指定的格式（第 2 个参数），返回文本结果。当指定格式为“0”时，即转换为最基本的文本。例如：

## 转换到日期时间

首先，在钉钉表格中，日期是以数值形式存储的，数值配合“格式”得到日期时间。因此，如果您要将其它类型数据转换为日期，需要先将数据转换为数值。

得到数值结果后，**工具栏菜单 —>格式—> 数据格式—> 日期时间**，即可使单元格显示为日期时间。例如：
