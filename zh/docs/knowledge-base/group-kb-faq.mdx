<Accordion title="如何进入知识库？">

  知识库已经全面开放，无需申请。您可以通过以下路径进入：

  【手机端钉钉】-底部【更多】-【文档】-【知识库】即可进入；

  【电脑端钉钉】- 【文档】-【知识库】即可进入。

</Accordion>
<Accordion title="知识库的文档可以分享吗?">

  知识库内的文档可以分享给组织内/外人员，分享方法如下：

  1、【手机端钉钉】-底部【更多】-【文档】-【知识库】-点击【对应知识库】- 进入对应文档页中 - 右上角【...】-【分享】；可通过生成长图、二维码、链接、分享到聊天等形式分享出去。

  2、【电脑端钉钉】- 【文档】-【知识库】- 进入对应文档页中 - 右上角【分享】；可通过链接、分享到聊天等形式分享出去。

</Accordion>
<Accordion title="知识库是什么？">

  知识库是由阿里巴巴自主研发的专业高效的企业知识管理平台，可用于搭建企业知识管理库和企业内部的文档协同。操作简单便捷，管理员在其中创建一个知识库后，添加成员即可多人共享，实时同步，团队成员可以在其中记录内部协作产出的所有内容。

  【温馨提示】：

  1、个人用户：无法使用知识库，页面会提示加入企业或者创建企业。

  2、企业用户：创建一个知识库，并添加团队成员，即可一群人一起创作知识库，沉淀企业知识。

</Accordion>
<Accordion title="知识库可以导入什么格式的文档为在线文档？">

  知识库支持以下格式文件（单个文件 20MB 以内）：.docx， .xlsx，.doc， .xls， .txt， .xmind， .markdown， .mark， .md。导入文件路径：【电脑端钉钉】-【文档】-【知识库】-【进入对应知识库】-点击【+】-【导入为在线文档】，选择文件并导入。

</Accordion>
<Accordion title="如何给知识库成员设置权限？">

  知识库管理员可以为成员分配权限。支持分配的权限有：可管理、可编辑、可查看/下载、仅可查看、设为所有者。权限明细：

  1.  **可管理：**可编辑/上传/下载/删除；

  2.  **可编辑：**可编辑/上传/下载；

  3.  **可查看/下载：**可下载/复制/打印；

  4.  **仅可查看：**仅可在线预览、不能复制/下载；

  5.  **设为所有者（仅支持电脑端）**：可将所有者身份转让。

</Accordion>
<Accordion title="知识库中被删除的文档可以恢复吗？">

  可以，被删除的文档将会转移至【回收站】，打开对应知识库左下角【回收站图标】，打开回收站，即可看到相关文件。温馨提示：可以对回收站的文件进行【还原】或【彻底删除】。

</Accordion>
<Accordion title="知识库占用钉盘空间吗？">

  目前知识库内的在线文档不占用钉盘空间。

</Accordion>
<Accordion title="知识库可以移动吗？">

  目前拥有该知识库可编辑权限的成员支持将知识库内的文档迁移到企业内其他的知识库中。同个企业内，不支持一个知识库整迁移到另一个知识库中；不支持知识库跨组织/企业移动。

  温馨提示：目前仅支持电脑端操作，手机端暂不支持。具体方法为：在左侧目录树内，选择某个文档右侧的【...】-【移动到】-【选择目标位置】-【移动】。

</Accordion>
<Accordion title="知识库收费吗?">

  知识库目前是免费使用。

</Accordion>
<Accordion title="如何查看知识库的编辑者">

  目前在知识库文档的顶部会显示：编辑者（包含所有编辑过的人员）、最近更新时间、阅读人数（可以显示具体的阅读人员信息）。
