## 什么是上传与导入？

### 上传：

支持所有类型本地文件上传至知识库，部分格式支持预览；上传后可获得文件链接进行分享，**且不改变文件格式**。

上传方式：在<strong>知识库主页</strong>\>>在左侧目录栏“”>>选择上传本地文件/文件夹至该知识库。

<img src="https://img.alicdn.com/imgextra/i1/O1CN019xeu8ly6jcF3QzfW_!!6000000000044-2-tps-1692-902.png" referrerPolicy="no-referrer" alt="image.png" />

### 导入：

支持部分类型本地文件导入至知识库，**转为在线文件**，可获得文档链接进行分享，**且转换为钉钉文档格式**。

导入方式：在<strong>知识库主页</strong>\>>在左侧目录栏“”>>选择【导入为在线文档】。

<img src="https://img.alicdn.com/imgextra/i2/O1CN01u7DXtnfLnEE3MaV8_!!6000000004587-2-tps-1657-881.png" referrerPolicy="no-referrer" alt="image.png" />

以下为不同文件类型导入之后转换格式说明：

| **本地文件类型** | **在线文件类型** |
| --- | --- |
| doc、docx、markdown、mark，md、txt | 钉钉文档 |
| xls、xlsx | 钉钉表格 |
| xmind | 钉钉脑图 |

## 上传与导入支持文件类型有哪些？文件大小有限制么？

「上传」文件<strong>可支持预览多种文件类型</strong>，且单个文件最大 8G；「导入」**仅支持文档类型**，单个文件最大 20M。

具体差异如下：

| **传输方式** | **文件类型** | **支持预览格式** | **大小限制** |
| --- | --- | --- | --- |
| 上传 | 文档 | pdf, pptx, ppt, pot, potx,  pps, ppsx, dps, dpt, pptm, potm,  ppsm, xls, xlt, et, ett, xlsx, xltx, xlsb,  xlsm, xltm, csv, doc, dot, wps, wpt, docx, dotx, docm, dotm, txt，xmind | 单个文件最大 8G |
|  | 图片 | peg ，bmp，png，jpg ，ico ，webp |
|  | 音视频 | 3GP、AVI、FLV、MP4、M3U8、MPG、ASF、WMV、MKV、MOV、TS、WebM、MXF、AAC、AC-3、ADPCM、AMR、DSD、MP1、MP2、MP3、PCM、RealAudio、Windows Media Audio |
|  | 其他 | zip 压缩包 |
| 导入 | 文档 | docx, xlsx, doc, xls，txt，xmind，markdown，mark，md | 单个文件最大 20M |

## 什么场景适合使用上传，什么场景适合使用导入？

| **传输方式** | **适用场景** |
| --- | --- |
| 上传 | *   已有的团队 PPT、文档资料，想传到部门知识库统一管理<br />    <br />*   本地的图片和视频，想共享给多个团队一起看 |
| 导入 | *   本地文件转为在线文件 |

## 上传与导入是否占用企业存储空间？

「上传文件」**占用企业存储空间**，「导入为在线文档」**不占用企业存储空间**。具体说明如下：

| **传输方式** | **计费对象** | **计入存储空间的文件** | **备注** |
| --- | --- | --- | --- |
| **上传**<br />本地文件（夹）上传至「我的文档」、「知识库」 | 所上传位置的空间 | 所有上传的文件 | *   若直接上传文件夹，只有文件夹中的文件计入云存储空间，文件夹本身不计入 ;<br />    <br />*   浏览他人所有的图片、视频、文件等，不占用己方的空间； |
| **导入**<br />在「我的文档」、「知识库」内新建或导入为在线文档 | 【限免】暂不计入 | 【限免】暂不计入 | 【限免】暂不计入 |

关于钉钉文档容量计算规则说明，可查看：钉钉文档容量如何计算？
