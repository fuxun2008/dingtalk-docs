📲  如何使用钉钉表格？1

钉钉表格，是由阿里巴巴钉钉自主研发多人在线编辑电子表格，通过使用钉钉表格，可以在钉钉或者浏览器上与他人协作处理电子表格。可以满足日常的信息统计，可以与组织内他人完成在线编辑整理数据，高效完成工作，同时支持自定义设置权限，保证数据安全。

*   例如，产品运营经常需要策划运营活动顺利落地，活动中囊括的事情很多很细碎，这时候可以**利用「项目管理表格」对活动规划管理，**协调程序员哥哥，测试姐姐，产品汪汪和各位运营喵喵的共同配合，让活动方案完美的落地执行。

*   例如，作为门店店长，需要对门店销售的商品销量和销售金额进行统计，建立了一张《商品销售清单》，邀请门店伙伴一起填写，但是针对「销量」、「单价」和「金额」这些重要的销售数据，希望只有「店长和副店长」可以编辑修改，其他伙伴禁止查看，**避免核心数据泄露，保障数据安全。**


使用「钉钉表格」，3大硬核功能可以同时兼顾「高效协同」与「数据安全」，帮助你解决使用文档时效率与安全的问题。

## 01 ｜数据权限安全

## 对重要、敏感数据轻松设置锁定

多名员工在线编辑同一份表格文件，可以利用**「锁定权限」**对不同角色员工设置不同的权限，高效填写数据同时保证数据安全

*   锁定编辑权限：重要数据设置锁定，指定人才能编辑；

*   锁定查看权限：敏感数据设置锁定，其他人禁止查看；


**店长视角：可以设置不同员工数据查看权限**

## 03 ｜多人协作在线编辑

## 支持插入多种组件，帮你实现不同的协作场景需求

项目管理在产品经理的日常工作中是非常必要的一项技能。面对手上的项目，需要协调各业务对各自负责的全部工作进行有效地汇总、协同编辑、管理，借助钉钉表格规范项目管理流程，确保流程有序地进行并如期完成。

*   推荐功能： **@ 人 + 复选框 + 插入链接 + 插入日期 +条件格式数据条**

*   价值：项目经理可搭建「项目管理表」，团队成员指派任务、核对进度、计划时间、更新状态，沉淀项目资料，跟进项目毫不费力；

对于 HR 来说，招聘是一个复杂繁琐的过程。从招聘规划、招聘实施、招聘效果一系列流程，都需要系统地进行管理，利用钉钉表格搭建一个简易的招聘进度管理，记录招聘流程数据，让招聘进展清晰可见。

*   推荐功能组： **@人 + 下拉列表+高亮重复项**

*   价值：HR可搭建「人才库」，人才资料避免重复录入，高效管理用人部门、实时分配跟进人，轻松更新招聘进度；

## 📲  如何使用钉钉表格？

*   PC端：钉钉左侧工具栏点击「文档」——「+新建」——「表格」
