# 了解｜什么是钉钉文档

钉钉文档是**阿里巴巴**集团钉钉出品、自主研发的企业协同办公套件，包含**文档、表格、脑图、AI表格、白板、幻灯片、知识库**等在线创作和文档管理工具。无需下载文档，在电脑、手机、平板都可以直接编辑查看，内容实时保存。同时，钉钉文档**与钉钉深度整合**，可基于组织关系，与同事高效协作。**信息收集、项目管理、会议、业务汇报、新人入职**等日常工作场景，都可以通过钉钉文档高效完成。

## 📝 文档

文档支持多人在线实时协同编辑，让你快速完成内容创作、方案讨论输出工作。同时文档支持插入图片、表格、视频、地理位置等内容，与钉钉深度整合，在文档中可以插入名片、项目、待办、群聊。**智联万物，让你的文档活起来。**

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/G1wvqr2m6Xe2qako/img/3598524f-0e3c-47ff-aa3f-926ca1f81f63.png)

*   支持在文档内插入 图片、视频、文件、名片、高德地图、优酷视频 等丰富的内容，将所有信息汇集一处，智能动态更新，让你的文档活起来
    
*   在文档内@同事，提醒同事快速查看
    
*   会议中产生的行动项，还可以在文档中插入「待办」，提醒同事完成
    
*   在文档中插入项目看板，直观展示项目进展
    
*   针对文档全文或者指定段落内容可以直接评论沟通，开会前完成大部分细节的沟通
    
*   一键开启演示模式，文档秒变 PPT
    
*   支持生成长图分享，创作的文档分分钟即可将文档变成长图海报，内容分享更高效
    
*   语音速记，将会议中讨论全过程实时转为文字方便后续整理纪要
    

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/93M0Ozkmr57NlzeE/img/1929141b-f1a9-4ca6-96c2-38f47ebc52c4.png)

## 📊 表格

表格同样支持多人在线实时协同编辑，强大的公式编辑、图表绘制功能，让团队在钉钉内即可协同完成数据收集、分析、展示全过程。

![钉钉文档使用手册-4-表格.gif](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/a/6n51x53xLUGn05JD/b6f44d7f1e2f46989976fd05ca1285c10521.gif)

*   具备完整的公式函数能力，更好地支持业务数据分析
    
*   支持常用的柱状、折线、饼图展示，简单的配置就可以让数据呈现更直观
    
*   支持互相独立的筛选视图，保障多人筛选数据，结果互不干扰，数据也能私人定制
    
*   支持锁定单元格，只有指定成员可查看 / 可编辑，其他成员禁止查看，保证数据私密性和安全性
    
*   链接地址 / 单元格 / 工作表，打开你的表格任意门，一键直达目标数据
    
*   美颜利器斑马色，一键套用表格样式，让你的数据秀色可餐
    
*   高亮重复项，录入信息时快速发现重复项，减少重复录入
    
*   一键插入复选框、下拉列表、日期时间，配合条件格式，轻松搭建任务清单，跟进任务状态

脑图是钉钉自主研发的表达发散性思维的有效图形思维工具，是可作为学习、生活、工作的实用与效率兼具的工具，又名心智导图、思维导图。

*   支持多人协同编辑

## 👨‍💻知识库

知识库是一个专业高效的企业知识管理平台，可用于搭建企业知识管理库和企业内部的文档协同。操作简单便捷，管理员添加成员后即可多人共享，实时同步，团队成员可以在其中记录内部协作产出的所有内容。

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/93M0Ozkmr57NlzeE/img/26be2d8c-a7cb-4661-b156-386f123c5560.png)

无论是中小团队、还是大型企业组织，创建一个知识库，并添加团队成员，即可一群人一起创作知识库，沉淀企业知识：

*   项目文档编写、产品需求文档
    
*   团队事务管理、知识沉淀
    
*   企业规章制度、流程
    
*   制作帮助手册、产品说明、API 手册
    
*   团队内异步交流

👍 **独立安全审计：**国内首家通过SOC2隐私性原则审计，安全性，保密性和隐私性三项原则审计

👍 **安全体系认证：**通过ISO27001:2013，27018:2014，安全认证体系的企业级应用产品

企业数据使用加解密技术方案，对敏感数据的保护贯穿整个数据安全生命周期，达到银行级数据加密存储级别；基于SSL/TLS协议以加密形式传输数据，以确保端到端的网络传输安全。

**安全防御体系，基于大数据实时入侵检测能力保障**

钉钉依托阿里巴巴集团安全部十多年攻防安全技术沉淀，自主研发的动态防入侵系统，实时监测平台的安全状况，对于主动入侵事件具备分钟级快速发现能力及进行事件的快速响应、止血与溯源能力。通过组建的虚拟组织蓝军、红军攻防对抗，不断提升入侵检测及安全应急响应能力。
