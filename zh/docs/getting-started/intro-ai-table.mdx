## 什么是AI表格？

AI表格是一款基于表格的新一代数据协作管理工具，是一款在线的可视化数据库的应用。AI表格可以建立表与表之间的关联关系，并且支持多种视图：表格视图、甘特视图、日历视图、看板视图、画册视图、表单视图；每一种视图都有对应的场景和功能，能够高效地解决企业中信息展现、多人协作。

与传统表格不同，AI表格的每一列是统一的字段类型，每一行是一条数据记录。可以通过排序、筛选、分组、等对数据视图进行操作，以数据驱动的方式，可以很好地实现数据聚合、看板分析、任务管理与汇报汇总等场景应用。

## AI表格能够解决哪些业务痛点

<CardGroup cols={2}>
  <Card title="数据管理和可视化">
    AI表格提供丰富的视图切换和仪表盘功能，轻松创建直观的图表和动态的仪表盘，无须进行复杂的设置，全面分析数据趋势。
  </Card>
  <Card title="数据安全难把控">

  </Card>
  <Card title="协作沟通不畅效率低">

  </Card>
  <Card title="更新数据难保一致">
    在数据分析时，当需要分析的数据存储在不同的表，可以通过数据关联，把多个表连接起来，实现一处更新，处处同步，无需手动频繁更改，保障数据一致性。

## AI表格的功能亮点

### 多种字段支持分组与排序

AI表格的每一列被称为「字段」。字段就是AI表格中的表头，它规定了每一列信息的类型和填写格式，让输入的数据更加规范有序。

<img src="https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/ya2QnVkyQr4oq4XB/img/9e09e499-c293-4ea9-a766-02b3992890e5.gif" referrerPolicy="no-referrer" alt="1755570140740_screen_recording_2025-08-19_10-21-58.gif" />

### 一份数据多种视角

多视图呈现数据是AI表格的灵魂。在AI表格中，根据数据的不同类型和使用场景，可以用<strong>表格、看板、甘特、画册等</strong>不同视图形态来呈现数据。

以简历收集场景为例，收集完简历后，通过多维度数据筛选候选人，关联指定人跟进面试进度，预定面试时间，直观展示不同候选人的面试耗时
