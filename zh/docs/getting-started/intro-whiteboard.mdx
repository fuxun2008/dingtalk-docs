## 一、钉钉白板快速入门

钉钉白板是一款支持多人实时编辑的在线协作白板，基于无边、可任意缩放的画布之上，每一个协作者都可以借助<strong>画笔、文本、图形、图片等</strong>多种元素共同创作，<strong>打破时间和空间壁垒，让想法发生碰撞</strong>，同时轻松完成思考、内容管理全流程，打造团队的<strong>「灵感空间」</strong>。

<img src="https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/32M9qPPBEzNZq015/img/9e7a1c31-0ee9-4f18-aef5-d58bd3170f74.png" referrerPolicy="no-referrer" alt="image.png" />

### 元素丰富，创作无限

钉钉白板的内置「模板」，提供了丰富模板，可以一键复用行业最佳实践，提升团队创作和协作效率。此外，通过画笔、文本、图形、图片、便签、音视频等丰富元素，让所有创意想法具象呈现于白板。

### 碰撞灵感，协作无界

在钉钉白板中，支持50人以上在线实时协作，每一位协作者都可以在这里思考创作，或者评论提出建议，高效提升团队成员的协作效率和表达意愿。

### 适配 iPad，无纸化办公

灵感涌现的一瞬，拿起身边的 iPad 记录，配合手写笔，图文并茂，轻松表达创意思路。同时，多端数据同步，让灵感碰撞不受限制，随时随地记下所思所想。

### 与「旧白板」有何区别？

|  | **Before 旧白板** | **After 新白板** |
| --- | --- | --- |
| 1. **无边画布** | 画布背景接近于黑板，页数仅支持3页，绘制和表现能力有限，局限性较强。 | 打破传统“黑板”画布，<strong>无限画布</strong>，支持<strong>多主题</strong>配色，视觉效果更清新。 |
| 2. **编辑灵活** | 仅支持画笔、形状、文本3种基础编辑功能，创作能力单一。 | 新白板新增更多编辑能力，支持<strong>画笔、文本、图形、图片、便签</strong>等多种工具，创作更灵活。 |
| 3. **元素丰富** | 图形及线条素材有限，色彩选择不多，所想表达不生动。 | 线条、图形、颜色<strong>素材种类更加丰富</strong>，还有<strong>精美模板</strong>可以一键复用，让你的想法表达得更充分、更生动。 |
| 4. **多人协作** | 仅支持在同一块画布上进行创作，无法互动交流。 | 新白板可支持<strong>50人以上</strong>在线同步协作，即时<strong>评论互动</strong>，交流观点更便捷。 |

### 如何开启灵感创作？

**桌面端入口**：打开钉钉，点击左侧导航进入「文档」，点击「新建」选择「白板」即可完成创建。

<img src="https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/32M9qPPBEzNZq015/img/28fec106-8195-4529-b1ff-d6fdffa82656.png" referrerPolicy="no-referrer" alt="image.png" />

**iPad端：**打开钉钉**，**点击「更多」-「文档」，点击下方蓝色「+」选择「白板」。

<img src="https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/32M9qPPBEzNZq015/img/19cab050-d5ca-4f31-a358-f1e6fb65533d.png" referrerPolicy="no-referrer" alt="image.png" />

## 三、使用场景

### 1. 企业培训

通过钉钉白板，可以随时随地开启一场企业培训或是线上团建，支持无边界、不限页数的画布，内置有趣的内容元素和互动功能，即便隔着电脑屏幕，也能激发成员们的参与热情与活跃度，实时协作互动，增加培训趣味性。

### 2. 头脑风暴

在线白板轻轻松松就可以组织富有成效的头脑风暴，激发团队成员发散地创造更多想法，支持多人实时协作，灵感碰撞，还能互动评论，即时发表建议，让脑暴过程井井有条。

<img src="https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/32M9qPPBEzNZq015/img/729cc652-87c7-4aaf-95b8-87fc55f1ee6e.png" referrerPolicy="no-referrer" alt="image.png" />

全新白板让线上会议不再枯燥，实时发布评论对方案细节发表看法，支持添加表情符合，让白板内容有态度、有温度。讲述方案时支持一键演示，白板秒变PPT，白板内容生动展示，聚焦参会者注意力，更加高效完成方案落地。
