**钉钉项目经理智冀：**终于找到了一个项目文档管理好工具，信息实时同步，格式整齐划一，在项目进行中直接完成了项目文档的沉淀。

## 背景

钉钉每次发版迭代都是一次横跨多个业务线的项目，在这个过程中，项目经理需要与多个团队的各种角色进行沟通，获取最新进展。同时又要第一时间将最新进展与所有项目成员同步。项目完成后还需要将项目过程中所有相关的进程文档进行统一归档。

## 痛点

1.  各团队因要插入多种内容，往往格式不统一，提交工具不统一，信息汇总费时费力。

2.  尝试过各种笔记工具做分析整理，有的不能同时支持手机电脑，有的不支持多人分享权限设置。

3.  项目完成后需要把成员提交的内容和笔记中的内容统一归档保存，既耗时又容易发生遗漏。

## 使用钉钉知识库以后

*   项目启动时，项目经理通过模板提前创建项目知识本，一键分享链接到群聊，快速开启合作。


<img src="https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/av9kqDv6bGBZlVxe/img/1977423c-867a-4795-a858-aa49694bc7c4.png" referrerPolicy="no-referrer" alt="image.png" />

*   项目进行中，项目成员按权限各司其职同时更新，格式整齐划一，项目经理无需专门整理汇总，实时反馈任务进度。


<img src="https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/av9kqDv6bGBZlVxe/img/2a8746e0-7b85-45d8-9851-309ab926e5cc.png" referrerPolicy="no-referrer" alt="image.png" />

*   项目完成后，文档已按结构完成规范存档，无需额外存档整理。
