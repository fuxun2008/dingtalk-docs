**资深开发新鹏：**知识库是一个非常敏捷的文档管理工具，大大提高了与研发、产品之间的协作效率，还能把开发中的心得原汁原味的保留下来。

## 背景

在开发过程中，研发团队每天都有大量的待办任务需要跟踪完成进度，开发进程中与和产品不断对焦的执行细节也需要与团队公示。如果解决了一些典型的技术问题，也需要保留开发的心得体会，分享给其他的团队成员。这一切都需要有一个支持多样格式，能便捷使用的文档管理工具。

## 痛点

1.  开发小组每天有很多需要公示进度的待办任务，尝试过群公告，不能支持表格、视频等内容的插入，体验不好。

2.  开发进程中与产品设计大量的沟通消息需要转成待执行的任务，群聊记录很容易就被新的聊天记录埋藏，翻查不容易，跨群转发更麻烦。

3.  开发过程里的技术心得，需要有专门的地方来积累，原来保存的地方不统一，每次新人加入都要申请各种权限，很不方便，团队人员调整时，访问权限更新也不够及时。

## 使用钉钉知识库以后

1.  使用知识库每天发布任务列表，支持多种格式内容插入，任务完成度一目了然。

2.  讨论对焦细节用知识库记录，@相关的人员自动发送查看提醒，无需翻查聊天记录。

3.  开发心得集中记录，日积月累，打造团队知识聚宝盆。新人入群自动授权，一步开启自学模式。
