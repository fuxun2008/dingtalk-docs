<Note>
## 把「工作汇报」这件事做好

我是管理者：通过日志了解下属的工作进展以及思考。并将自己的思考同步给下属。

我是员工：通过日志记录工作，沉淀思考。在年度总结和季度总结是可以清晰看到自己的工作路径，让优秀被看见。
</Note>

钉钉日志涵盖了职场中常见的汇报场景：日报、周报、月报、季度报、年报等。企业管理者可以灵活设置报告方式、自定义各种工作汇报模板。员工随时随地可以做工作汇报，帮助员工把工作梳理得更有条理、目标性。领导在外也能实时查看了解员工的工作状态和成效，还能通过点赞和评论对员工的工作给予鼓励和指导。

<Note>
### 以前：我是公司管理层，因为工作的关系需要经常出差，不能经常和员工能够面对面沟通，如何在有限的时间了解员工工作情况？
</Note>
<Note>
### 现在：使用钉钉日志，助力管理层透明便捷了解员工工作情况。
</Note>

管理层即使经常外出不在公司或不直接与下属沟通交流，通过钉钉日志，可以将员工提交的日报、计划报告的情况便捷透明的了解到每个员工的工作状态情况，合理的把控员工工作推进进度。钉钉日志支持电脑端+手机端，写日志时支持自动实时保存，员工随时随地可完成日报内容的填写。

**—不同部门不同模板，汇报更规范—**

<Note>
### 以前：作为公司的管理者，分管了好几个部门：销售、财务、行政、人事等，工作业务和重点都不一样，怎么让不同岗位的员工做好工作汇报？
</Note>
<Note>
### 现在：使用钉钉日志，不同岗位员工可以自定义专属模板，让汇报更规范高效。
</Note>

针对不同岗位的员工，企业管理者可灵活自定义不同的汇报模板，方便规范员工填写内容，避免员工乱填写上报的情况，也能帮助管理层更好了解员工每日、每月等的核心工作产出，无需重复沟通询问了解，更透明化的进行管理。员工也可以快速按照模板汇报工作内容，提升工作效率。

**—帮助员工自我管理，提升工作计划性—**

<Note>
### 以前：员工日常工作繁杂，工作缺乏计划，没有重点，苦恼如何帮助员工做好工作规划？
</Note>
<Note>
### 现在：使用钉钉日志，养成良好的工作总结与计划，定期回顾工作重点。
</Note>

使用日志进行工作汇报，可以帮助员工养成良好的工作总结与计划的习惯，定期将工作进行总结与规划，工作推进有始有终。接下来的工作提前规划提前安排，提升工作计划性，加强工作的效率与实施节奏。**「工作回顾」功能，**使用日志整理工作汇报就可以查找最近使用的文档，帮助员工更好梳理工作，回顾重点。
