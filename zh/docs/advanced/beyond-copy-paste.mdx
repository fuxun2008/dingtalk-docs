**手把手教学如下：**

:::
**模板按钮：**

如果排版和格式固定，且需要在一篇文档里**多次操作“复制粘贴”该排版、格式和框架，**也可以使用**模板按钮**进行一键快速操作！

:::
[旗子] **什么是模板按钮？**     

有任何需要多次操作“复制粘贴”的排版、格式和框架，都可以用它！
:::

下面以小组协同编辑周报文档为例，示意使用方法：

[优先级: 1]点击文档上方导航栏**插入**，找到**模板按钮**并点击

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/Wmeona1PEB6QnXxj/img/4c59a3b2-78cc-4674-9cba-4c6051af93b5.png)

[优先级: 2] 将团队统一的周报框架输入进模板内容，然后保存：

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/Wmeona1PEB6QnXxj/img/1d5044b4-ae20-48d0-b985-2aad33472cc9.png)

[优先级: 3]点击已经保存的模板按钮，就能一键复制之前输入好的周报框架和格式啦，小组成员只需要调整名称，即可开始编写自己部分的周报内容！

**花最少的时间在排版和格式，更多的时间聚焦在内容本身的创作！**

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/Wmeona1PEB6QnXxj/img/17831bb7-aeca-49cf-8a42-f560f6a3c3ad.png)

**内容拖拽：**

遇到需要移动位置或者需要剪切的文字，可以将鼠标放在该段文字的头部，出现下方图标后，直接拖拽到你需要移动的位置就好啦~

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/Wmeona1PEB6QnXxj/img/74ed38c2-27d5-4a5b-83a6-6debcaece4e1.png)

**文档生成模板：**

[优先级: 1]打开需要生成模板的文档，点击右上角**...**，**保存为模板**，**保存为我的模板**，自定义更改模板标题即可

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/Wmeona1PEB6QnXxj/img/4d0047ca-3c86-4024-9bcb-4f14b776de28.png)

[优先级: 2]保存成功后，在新建文档界面可以选择**“我的模板”**使用

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/Wmeona1PEB6QnXxj/img/8b3b38e7-bdc7-4c3c-ade4-be42a5ca3127.png)
