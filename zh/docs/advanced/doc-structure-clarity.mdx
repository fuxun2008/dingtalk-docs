![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/LAJdl6vMZ5jalke1/img/b40486cc-e1a4-452a-ba45-f1349137d7e8.png)  

**可以用到的关键功能：****设置标题、标题折叠、大纲视图**

**手把手教学如下：**

:::
[优先级: 1]找出一篇有文字内容的钉钉文档

[优先级: 2]根据你的文档内容，将文章标题部分设置成导航栏里的**标题字体**（字号大小可自定义）

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/jWgZOZPyYB3XnLX8/img/e36ca839-0283-49b5-834b-4179033b51ee.png)

[优先级: 3]所有标题设置完成之后，点击左上角**菜单**，选择**视图**，开启**大纲，**右侧就会出现整篇文章的大纲标题，如需快速查看，点击大纲内的标题即可自动跳转至指定章节

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/jWgZOZPyYB3XnLX8/img/4b771bf2-fe97-492f-99c8-3cdc506a635e.png)

[优先级: 4]同时，文档内的标题也支持将其内容折叠，以方便查阅和修改；将鼠标放至该行标题最前面，会出现三角形符号，点击即可将该标题下的内容折叠起来，文章结构一目了然

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/jWgZOZPyYB3XnLX8/img/ce70f01c-6179-4c35-9e71-ca2df18f02b1.png)

这样一顿操作下来，你的文档界面是不是干净整洁又有逻辑？简直是老板最爱的亚子有木有！

你学废了嘛？！快快用起来吧！
:::
