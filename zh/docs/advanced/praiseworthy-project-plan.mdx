俗话说一个好的项目方案就是成功的开始

对于职场人来说

每次写方案都要回顾、总结、规划再来份报告

工序多且过程复杂，到最后总是焦头烂额

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/P4maOg0D2QzVlWNX/img/f322652e-3186-4863-ab7b-837812d22f66.png)

虽然但是，写方案这件事依然避免不了

咱可以换个思路去！比如说：用钉钉表格来写项目方案也不是不可以

甚至比普通的方案更加条理清晰、言简意赅

**先来康康我是怎么用钉钉表格做项目方案吧！**

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/G1wvqrRyVMeoqako/img/4bac3aa9-4ca1-48a5-bb65-697cc00b556b.png)

**需要用到的关键功能：****合并单元格、 填充颜色、固定行高、加日程**

**手把手教学如下：**

:::
[优先级: 1]新建一个钉钉表格，可以参考下图的结构给你的项目方案定好大纲

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/G1wvqrRyVMeoqako/img/43e90402-6c0b-4c31-99d4-82916dde512f.png)

[优先级: 2]在需要合并单元格的区域，选中该部分表格单击右键/或点击上方导航栏**合并单元格**即可

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/G1wvqrRyVMeoqako/img/652982e5-2971-4365-a8df-9cc89ee69292.png)

[优先级: 3]如某些区域需要用不同颜色区分，可在上方导航栏选择**背景填充**为单元格添加底色

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/G1wvqrRyVMeoqako/img/222e9302-5094-4861-9ee8-0975f50836c8.png)

[优先级: 4]中间每个模块可用单独行隔开，设置表格行高，可在选中表格后单击右键，在**设置行高**一栏自定义设置行高

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/G1wvqrRyVMeoqako/img/505683fa-a77d-4b9a-848e-ab1d9e62dd99.png)

[优先级: 5]如需在表格中添加日程提醒，可以左上角【菜单】导航栏点击插入并选择**日程提醒，**设置完成后，该日程联动钉钉日程，打开钉钉日历即可看到该日程

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/G1wvqrRyVMeoqako/img/8880b741-1c8e-42c4-94b6-8bdea27a8759.png)

最后，只要根据你的方案大纲，在表格中填充项目方案的具体内容就好啦~

你学废了嘛？！快快用起来吧！
:::
