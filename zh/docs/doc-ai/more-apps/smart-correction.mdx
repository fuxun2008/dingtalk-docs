# 什么是智能纠错？

开启智能检查常见错别字、拼写错误，并给出修改建议，为写作保驾护航。

# 使用场景

钉三多是企划部的内容运营，日常会使用钉钉文档撰写宣传稿件、工作文章等。开启智能纠错功能后，写稿时不小心出现的错别字或拼写错误，系统会智能检查并给出修改建议，写作完成后也不需要再逐个检查，节省了更多的工作时间。

# 使用说明

点击导航栏左上角菜单——选择工具——智能纠错——打开智能纠错开关即可。
