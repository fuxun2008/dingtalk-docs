# 一、什么是 Prompt

Prompt 词译为提示词，在使用智能助手时可以理解为给 AI 模型的指令。Prompt 可以是一个问题、一段文字描述，甚至可以是带有一堆参数的文字描述。当提供一个具体的提示或问题时，可以让AI模型更准确地生成相关的文本、图片或表格等内容。

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/3M0OzeZGL9gWLqze/img/2079bdc2-ce4e-4788-ae7e-aa89db84f91d.png)

例如，如果我们要让 AI 模型生成一篇关于健康饮食的文章，我们可以提供一些问题或关键词，如：什么是健康饮食？哪些食物是健康的？如何保持健康的饮食习惯？然后，AI 模型可以通过对这些问题的分析和理解，生成一篇详细的文章，介绍健康饮食的重要性、健康饮食的组成和建议等内容。此外，我们还可以通过提供具体的图片或表格等内容，让 AI 模型生成相关的内容，以更加生动形象地展现我们想要表达的信息。

# 二、什么是 Prompt Engineering？

Prompt Engineering 中文意思为提示工程，后缩写为 PE 则是：

> Prompt Engineering 是一种人工智能（AI）技术，它通过设计和改进 AI 的 prompt 来提高 AI 的表现。Prompt Engineering 的目标是创建高度有效和可控的 AI 系统，使其能够准确、可靠地执行特定任务。

# 三、为什么要学习掌握 Prompt ？

如果你只是想要简单的答案，那么你只需要在智能助手中输入文字即可，但如果你想要获得满意且精确的答案，就需要用到 PE 技术。

*   作为 AI 产品的用户，当你学会掌握 Prompt 使用技巧，你可以通过智能助手，获得更优质的答案，提高工作效率。
    
*   作为 AI 产品设计师或研发人员，可以设计和改进 AI 系统的 Prompt 提示，以提高其性能和准确性，从而为用户提供更出色的 AI 体验。
    

#  四、 Prompt 的基础用法

在使用钉钉文档中，启用智能助手后，在输入框内输入问题或者指令即可。智能助手会根据你的指令，返回相应的内容。在使用智能助手对话时，以下几个原则与建议，能帮助你写出更好的 prompt。

### Prompt 包含完整、详细的信息

这是对智能助手生成结果影响最大的因素。比如如果你想让智能助手写一首关于 杭州 的诗。如：

prompt：写一篇诗歌：关于杭州

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/4j6OJ5jN1E0yJq3p/img/8aaafd64-173b-4f05-9406-99507481c6af.png)

prompt：写一篇诗歌：关于杭州秋天的诗，包含西湖、莫干山等景点

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/4j6OJ5jN1E0yJq3p/img/e6ad2f0a-c0c4-4083-a514-510b7f27c2b1.png)

### Prompt 最好简洁易懂，并减少歧义

说一些简单的短句，智能助手更容易理解你的要求。另外，在 prompt 里也需要减少一些歧义，少用模棱两可的词语。

想几个关于柠檬茶饮品的标题，几个就可以，不要太多。

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/4j6OJ5jN1E0yJq3p/img/63d67182-05d5-4159-a613-d0fb54bf92b0.png)

你现在是一个产品推广员，现在要推广柠檬茶饮品，帮我想8个标题，每个标题字数控制在15个字以内。

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/4j6OJ5jN1E0yJq3p/img/fcf0307f-1194-4dcf-8b23-234130371764.png)

需要注意的是，简单不等同于简短。同样长度的 prompt 提示，描述得越充分，智能助手给你生成的内容和答案就越接近你想要的效果。
