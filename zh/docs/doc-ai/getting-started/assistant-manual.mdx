## 一、钉钉文档 AI 是什么？

钉钉文档 AI（简称文档 AI ）是**钉钉文档**与**阿里巴巴通义大模型**共同合作研发推出的基于大模型的文档辅助创作工具，可以辅助用户**生成文字、表格、图片**等各类文档内容，使用文档 AI，**玩转创意，轻松创作**。

## 二、主要功能

文档 AI 除了**任意写**之外，还提供**辅助创作、生成图片、生成表格、快速生成和改写内容、基于文档生成内容****共六****类功能**，可以满足不同场景下的内容创作需求，提高写作效率和写作质量，具体描述如下：

| **功能分类** | **功能描述** | **输入示例** |
| --- | --- | --- |
| **任意写** | ##### 快问快答，为你高效提供创意与灵感<br />> 输入你想操作的任意指令，向文档 AI 提问 | 地球是怎么形成的？<br />黑洞会不会消失？... |
| **辅助创作** | ##### 场景丰富，智能生成多种类型文档内容<br />> 头脑风暴、营销策划、创意故事、推广文案、职位描述、总结报告、竞品分析、利弊分析、产品说明、新闻稿、合同、大纲、待办清单、电子邮件、文章、诗歌 | 选择特定的创作类型，再输入主题<br />头脑风暴：北京春日游、亚运会环保活动主题<br />竞品分析：新能源汽车和燃油车<br />推广文案：写一篇关于春日奇异果饮品的推文<br />新闻稿：AIGC技术的应用... |
| **快速生成和改写内容** | ##### 风格多样，为你将内容转换多种表达方式<br />> 生成摘要、识别待办、继续写、帮我润色、<br />> 丰富内容、精简内容、改写语气... | — |
| **生成图片** | ##### 省时省力，为你生成生动有趣图片素材<br />> 根据关键词或特定场景的描述生成图片 | 酣睡的小猫、奔跑的汽车、<br />阳光下的沙滩、火星漫步... |
| **生成表格** | ##### 清晰直观，为你制作可视化数据表格<br />> 让文档 AI 用表格列出你想要对比的信息 | 新能源汽车的优缺点、<br />中国各个城市之间的差异... |
| **基于文档生成内容** | **言之有据，基于实际工作文档生成内容**<br />> 基于已有工作文档，智能化生成更准确的内容 | 工作周报/日报/工作报告汇总分析<br />会议纪要重点 |

## 三、适用场景

文档 AI 支持**知识问答、创意想法、思路梳理、运营策划、市场分析、人事招聘、新闻撰写、工作汇报、文案优化、文档配图、信息比对**等多种使用场景，你可以在任何时候使用文档 AI，帮你解决各类问题。

| **适用场景** | **对应功能** | **输入示例** |
| --- | --- | --- |
| **知识问答** | 任意写 | 如：在线文档与本地文档相比有什么优势？ |
| **创意想法** | 头脑风暴 | 如：脑暴5个公益活动的名称和主题 |
| **思路梳理** | 大纲、待办清单 | 如：团队计划组织一场户外烧烤，需要准备哪些事情？ |
| **运营策划** | 营销策划、推广文案、创意故事 | 如：为运动饮料写一篇创意故事 |
| **市场分析** | 竞品分析、利弊分析 | 如：分析macbook pro 和macbook air的优缺点 |
| **人事招聘** | 职位描述 | 如：为移动互联网产品经理写一篇职位描述 |
| **新闻撰写** | 新闻稿 | 如：围绕熊猫丫丫回国写一篇正能量的新闻稿 |
| **工作汇报** | 总结报告 | 如：结合校园跑公益活动策划写一篇工作总结 |
| **文案优化** | 帮我润色、丰富内容、精简内容、改写语气 | 如：「选中文案」- 改写为更有吸引力的 |
| **文档配图** | 生成图片 | 如：生成一张流浪地球的图片 |
| **信息对比** | 生成表格 | 如：用表格列举主流电动汽车品牌及配置 |
| ... | ... | ... |

## 五、快速上手

在使用文档 AI 时，你可以参考以下步骤，帮助你提升创作效率，以下是详细的操作步骤：

1.  **唤起文档 AI：**打开钉钉文档，通过输入斜杠“/”，或在工具栏唤起；

2.  **输入写作指令：**在文档 AI 输入框输入信息，选择所需的功能类型，让 AI 帮你完成内容创作；

3.  **调整写作效果：**AI 创作后，你可以选择“换一换”或者“继续写”，调整内容；

4.  **确认写作结果：**当创作效果满意后，确认结果并应用到文档。

## 七、常见 Q&A

## 1. 如何体验文档 AI

收到钉钉文档 AI 定向邀约的客户，可凭借钉钉发放的邀请码，在邀请页面申领体验资格。

## 2. 文档 AI 是否有端/版本/组织的要求？

支持的客户端：目前文档**仅支持PC端**（**包含钉钉端内和浏览器**）、移动端部能力体验；

支持的钉钉版本：为保证更好的使用的体验，建议升级到钉钉的最新版本：

## 3. 文档 AI 是否有次数限制

目前**参加**钉钉文档智能助手**定向邀约的客户，邀测期间不限制使用时间，如有调整，以官方通知为准**。

## 4. 文档 AI 发布时间和计费方式？

钉钉文档 AI 火热内测中，现仅对部分钉钉专业版和专属版客户的定向邀约，具体发布时间和计费方式请持续关注。
