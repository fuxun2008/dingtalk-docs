## 一、了解钉钉文档 AI · 脑图

++**钉钉文档**++与++**阿里巴巴通义大模型**++共同合作研发，在脑图上推出的基于大模型的文档辅助创作工具——文档智能工具，可以为用户提供创作灵感和想法，使用脑图中可以根据节点内容自动生成完整思维导图，拓展无限思维能力，还能一键生成文章，高效完成内容创作。

![未命名的设计 (1).png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/4EZlweZbNe2kGqxA/img/1a954451-f027-416a-b320-2cc33037233f.png?x-oss-process=image/crop,x_0,y_0,w_1587,h_969/ignore-error,1)

## 二、主要功能

目前有++**智能创作、给我灵感、生成文章**++ 3 个核心功能点；

*   **智能创作：**输入一个主题向 AI 提问，将自动新建一个主题和大纲，展现关键节点和重要信息，++**帮助你快速创建出思考框架**++。

*   **给我灵感：**基于原有的主题或者节点，继续进行创作，列出下一级节点内容，++**帮助你智能完善脑图的节点**++。

*   **生成文章：**基于脑图节点，生成完整文档。可以按照段落或全文一键进行内容创作，++**生成完整的一篇文章，并支持保存为在线文档**++。

## 三、适用场景

目前支持多种使用场景，如++**活动大纲、旅游攻略、思路梳理、文章撰写、物品清单、学习地图、工作计划、学习笔记**++等，你可以在任何时候使用 AI ，帮你提升工作与学习效率。

| **适用场景** | **对应功能** | **输入示例** |
| --- | --- | --- |
| 活动大纲 | 智能创作、给我灵感 | 如：钉钉产品发布会内容大纲 |
| 旅游攻略 | 智能创作、给我灵感 | 如：杭州旅游攻略 |
| 思路梳理 | 智能创作、给我灵感、生成文章 | 如：如何快速学习一个新的领域 |
| 文章撰写 | 智能创作、生成文章 | 如：为什么年轻人开始“摆烂” |
| 物品清单 | 智能创作、给我灵感 | 如：爬山必备物品 |
| 学习地图 | 智能创作 | 如：新媒体运营知识体系 |
| 工作计划 | 智能创作 | 如：产品运营第二季度工作计划 |
| 学习笔记 | 智能创作、给我灵感 | 如：什么是产品驱动增长 |
| ... | ... | ... |

收到钉钉脑图 AI 定向邀约的客户，可凭借钉钉发放的邀请码，在邀请页面申领体验资格。

## 3. 脑图 AI 是否有次数限制

目前**参加**钉钉文档智能助手**定向邀约的客户，邀测期间不限制使用时间，如有调整，以官方通知为准**。
