## 一、了解钉钉文档 AI · 知识库问答

钉钉文档知识库通过接入大模型能力，可基于权限管控范围内，生成当前知识库的专属模型，让企业和组织都可以拥有专属的智能文档助理。可以帮助每个员工更高效获取知识库内容，提高知识生产、知识消费效率，成为学习型组织。

## 二、主要功能

开启知识库智能助手后，可自动学习当前知识库**钉钉文档、PDF** 文件内容，进行增、删、改等操作后，也可实现自动学习同步。可以直接在钉钉聊天窗查看 PDF 文件，并打开智能助手向 TA 提出问题，TA 将会帮你从 PDF 中快速提取有效信息，智能整理归纳进行回答，让阅读论文、书籍和合同变得更轻松。

*   **目前支持学习文档格式如下：**

| 文档格式 | 支持状态 | 备注 |
| --- | --- | --- |
| 钉钉文档 | [进度: 已完成] 支持 | 支持文档里面“表格”内容的学习 |
| 钉钉表格 | [禁行] 暂未支持 |  |
| 钉钉脑图 | [禁行] 暂未支持 |  |
| PDF | [进度: 已完成] 支持 |  |
| WORD | [禁行] 暂未支持 |  |
| EXCEL | [禁行] 暂未支持 |  |

\*更新至 2023-07-05，“[禁行] 暂未支持” 将陆续开发支持上线。

## 三、适用场景

知识库智能助手可以让你快速获取团队知识，适用于工作总结、知识问答、新人帮助、企业百科、产品手册等各类工作场景，智能阅读、分析、归纳团队知识，成为每个企业专属的知识助理！

## 四、如何启用和关闭？

*   **首次启用：**进入有管理权限的知识库首页，在右下角选中「AI助理」，点击立即开启，即可启用。

*   **机器学习：**在首次开启时，智能助手将会自动学习知识库内有权限文档内容，请耐心等待，学习完成后，即可使用智能助手进行提问，如下图所示：

## 五、常见 Q&A

## 知识库文档是有权限的，问答会不会跨越权限？

不会。提问者对文档有权限时才会回答相关内容。

## 平均学习一个知识库需要多久？

一般1-5分钟内可以学习完。最长不会超过40分钟。若有学习时间过长的的情况烦请反馈。

## 支持哪些类型文件，什么时候支持doc、xls？

目前支持钉钉文档和PDF，其他格式会尽快支持。

##  是否支持基于上下文的问答，什么时候会支持？

暂不支持，能力规划中。

## 5. 文档智能助手是否有次数限制？

目前**参加**钉钉文档智能助手**定向邀约的客户，邀测期间不限制使用时间，如有调整，以官方通知为准**。

## 6. 文档智能助手发布时间和计费方式？

钉钉文档智能助手火热内测中，现仅对部分钉钉专业版和专属版客户的定向邀约，具体发布时间和计费方式请持续关注。
