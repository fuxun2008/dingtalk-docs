## 各版本高级权限使用说明

AI表格的高级权限能力在不同版本中均可使用，但**可创建的自定义角色数量有所区别**

| **功能权益**​   | **免费版**​ | **企业版**​ | **旗舰版**​ |
| ----------- | -------- | -------- | -------- |
| 高级权限自定义角色个数 | 3 个      | 50 个     | 100 个    |

## 功能概述

AI表格的**所有者**和**管理者**可以开启或关闭**高级权限**，并对**角色**及其**成员** 进行配置与管理。

通过创建并设置不同角色，管理者可以为**数据表、仪表盘、视图、字段和记录**分别配置对应的**访问权限**和**操作权限**，实现更加精细的权限管理，从而为数据安全提供更可靠的保障。

**常见使用场景**：

- 销售人员只能查看和维护自己的客户信息，无法查看其他销售的客户数据
- 公司管理层可查看整体经营数据和汇总报表，但不参与具体数据的编辑或维护
- 统计类字段（如金额、评分、汇总结果）仅允许管理员查看或修改，普通成员无法访问
- 不同项目成员只能访问自己参与的项目数据，无法查看其他项目的信息
- 部门负责人仅可查看和管理本部门相关的数据表及仪表盘内容
- 普通协作者只能新增或更新记录，无法更改表

## 名词解释

- **所有者**（默认角色）：指 AI表格的**最高权限持有者**。创建者默认即为所有者；当所有权被转让后，新的接收成员将成为所有者
- **管理者**（默认角色）：高级权限中的**默认管理角色**。拥有文档权限中的**可管理 权限**的协作者将自动成为管理者。管理者可**编辑 AI表格的全部内容**，并可配置**高级权限、自动化及仪表盘** 等设置
- **编辑者**（默认角色）：编辑者默认可以**查看和修改数据内容**，包括新增、编辑和删除记录，但**无法更改表结构**，也无法配置**高级权限、自动化或仪表盘设置**。编辑者的具体权限可由管理者进行调整，实际可执行的操作以**角色权限配置** 为准
- **查看者**（默认角色）：查看者默认仅可**查看数据内容**，无法新增、编辑或删除记录，也无法修改**表结构、权限设置、自动化或仪表盘配置**。查看者的具体可见范围可由管理者进行调整，实际可查看的数据以**角色权限配置** 为准。
- **自定义角色**：指由管理者自行创建的角色。每个角色即一个**权限组**，为角色配置的权限将对该角色下的**所有成员** 统一生效
- **成员**：指被添加到角色中的权限主体，**不一定是单个人**，可以是**具体人员、群组或部门** 等
- **数据表权限**：指对 AI表格中**数据表** 的访问与操作权限。
- **仪表盘权限**：指对 AI表格中**仪表盘** 的访问与操作权限。
- **记录权限**：指对数据表中**每一行记录** 的查看与编辑权限。
- **字段权限**：指对数据表中**每一列字段** 的查看与编辑权限。
- **视图权限**：指对数据表中**视图** 的访问与操作权限。

## 文档权限和高级权限

### 文档权限

在AI表格的顶部右上角，点击 **分享** 按钮，可以对当前AI表格进行分享和协作设置

![](/zh/aitable/permissions/advanced-permissions-overview/images/image_IfoiiQb0X0.png)

多种分享范围和协作权限可以结合业务场景自由配置，还有更多管理员精细化配置项

三种分享范围：仅协作者、企业内公开、互联网公开。

![](/zh/aitable/permissions/advanced-permissions-overview/images/image_eG1ZMTUumL.png)

四种协作权限：支持配置个人、群、部门可管理、可编辑、可查看/下载、仅查看权限

可管理不支持给组织外人员配置。

![](/zh/aitable/permissions/advanced-permissions-overview/images/image_jQJeavO9g9.png)

### 高级权限

AI表格的**所有者**或拥有**可管理 权限**的协作者可以开启**高级权限**。

**高级权限是在文档权限基础上的补充能力**，用于对协作者的访问范围和操作权限进行更精细的控制。

通过创建不同角色，可以精确设定谁可以**查看或编辑各个数据表**，并可进一步控制成员可访问的**记录范围、字段内容（及对应单元格）**，以及**视图、仪表盘、自动化和应用** 的访问权限。

### 文档权限和高级权限的比较

开启**高级权限**后，协作者的实际权限将由**高级权限**与**文档权限** 共同决定。

在高级权限中，若成员同时属于多个角色，其**记录权限**和**字段权限**会先按角色进行**并集计算**；随后再与该成员的**文档权限**进行**交集计算**，最终结果即为该成员实际生效的权限范围

举例：

| AI表格 **高级权限**                | **文档权限**​  | **实际权限**​              |
| -------------------------------- | ---------- | ---------------------- |
| 小李在角色1可编辑全部记录                    | 小李可编辑      | 可编辑全部记录                |
|                                  | 小李可查看      | 仅可查看全部记录               |
| 小李在角色1可编辑自己负责的客户记录；在角色2可查看全部客户数据 | 小李可编辑      | 可查看全部客户数据，可编辑自己负责的客户记录 |
|                                  | 小李可查看      | 仅可查看全部客户数据             |
| 小李在角色1可编辑全部项目记录；在角色2可查看统计字段      | 小李可编辑      | 可编辑全部项目记录，并可查看统计字段     |
|                                  | 小李可查看      | 仅可查看全部项目记录和统计字段        |
| 小李在角色1可查看金额字段；在角色2可查看客户联系方式字段    | 小李可编辑      | 可查看金额字段和客户联系方式字段       |
|                                  | 小李可查看      | 可查看金额字段和客户联系方式字段       |
| 小李在角色1可编辑全部记录                    | 小李未被授予文档权限 | 小李无法访问AI表格             |

## 高级权限类型

| 权限    | 权限说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| ----- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 数据表权限 | 用于定义角色对数据表的整体访问与操作范围。  **完全权限**：可修改表结构、配置字段，并可编辑所有记录内容  **可编辑**：可新增、修改和删除记录，可查看数据，但不能修改表结构或字段配置  **可查看**：仅可查看记录内容，不能新增、修改或删除记录  **无权限**：无任何访问权限，且不会在 AI表格中看到该数据表  注意：数据表权限作用于整个数据表，不会随视图变化而改变。同时支持对视图的新增、编辑和删除进行整体控制                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| 记录权限  | 用于设置协作者能否新增、编辑、查看或删除记录，并可对可操作或可查看的记录范围进行精细化控制。需先为该角色设置**数据表权限** 后，才可配置记录权限  当数据表权限为**完全权限** 时，协作者默认拥有全部记录的查看与操作能力，无需额外设置记录权限    **当数据表权限为 可编辑 时**  **新增与删除记录权限**  可新增：允许新增记录    可删除：允许删除记录  **可编辑和删除的记录范围**  所有记录：可对数据表中的全部记录进行编辑和删除  与成员自己相关的记录：仅可编辑和删除与成员相关的记录，包括    成员本人创建的记录    字段包含成员本人的记录（需数据表中存在人员类型字段）  **指定记录**  可通过筛选条件限定可编辑或删除的记录范围    支持按字段设置筛选条件，例如按 创建人、状态等字段进行过滤    可添加多个筛选条件进行组合筛选  **其他记录权限**  可查看：对未被允许编辑或删除的记录，仅可查看内容 无权限：未包含在范围内的记录不会展示给协作者    **当数据表权限为 可查看 时**  仅可配置记录的可见范围，用于控制协作者可以看到哪些记录  **可查看的记录范围**  所有记录：可查看数据表中的全部记录  与成员自己相关的记录：仅可查看与成员相关的记录，包括    成员本人创建的记录    字段包含成员本人的记录（需数据表中存在人员类型字段）  指定记录：可通过筛选条件限定可查看的记录范围    支持按字段设置筛选条件，并可添加多个筛选条件进行组合筛选    仅当记录满足筛选条件时才会显示给协作者，不满足条件的记录不会展示  **其他记录权限**  可查看：对未包含在可查看范围内的记录，仅允许查看    无权限：未包含在范围内的记录不会展示给协作者 |
| 视图权限  | 用于定义角色对数据表中视图的访问与操作范围。需先为该角色设置**数据表权限** 后，才可配置视图权限。  **完全权限**：可查看全部视图，并可新增、修改和删除视图。  **可查看**：仅可查看视图内容，不可新增、修改或删除视图。  **视图可见范围**： 可选择**所有视图**或**指定视图** 进行访问控制。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| 字段权限  | 用于设置协作者能否新增、编辑、查看字段对应单元格的内容。需先为该角色设置**数据表权限** 后，才可配置字段权限  **所有字段内容可编辑**：该角色可对数据表中的所有字段进行查看、编辑及新增记录操作  **指定字段内容权限**：可针对不同字段分别设置权限范围  在指定字段模式下，可对每个字段分别配置以下权限  可查看：仅可查看该字段对应的单元格内容    可新增：仅可在新增记录时填写该字段内容，不可修改已有数据    可编辑：可查看、新增并编辑该字段对应的单元格内容  注意：仅当数据表权限为**完全权限**或**可编辑** 时，才可以配置字段权限                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| 仪表盘权限 | **仪表盘整体权限**  **完全权限**：可修改仪表盘结构、配置组件，并可编辑内容  **可查看**：仅可查看仪表盘内容  **无权限**：无法查看该仪表盘    **仪表盘数据权限**  用于设置仪表盘中图表的数据统计与展示方式  **当存在无权限查看的数据时，图表不可见**：若协作者对图表所依赖的全部或部分数据无查看权限，则对应图表内容不会显示  **基于访问者权限统计**：即“千人千面“，图表仅统计不同协作者有权限查看的数据内容  **基于全部数据统计**：即“千人一面“，图表按数据表中的全部数据进行统计                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| 自动化权限 | 用于设置角色对自动化流程的管理、编辑、发布和启用  角色需同时拥有 **全部数据表的可管理** 权限，且仅组织内成员可配置自动化                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |

## 开启高级权限

点击AI表格右上角 **高级权限** 按钮开启高级权限。

> ⚠️开启高级权限后，原有的编辑者和查看者默认权限将不再生效，协作者会暂时失去对 AI表格的访问权限，需要重新为其配置相应的角色权限后方可继续访问

![](/zh/aitable/permissions/advanced-permissions-overview/images/image_5aziJdWkxg.png)

## 关闭高级权限

在高级权限设置弹窗内点击滑块可以关闭已开启的高级权限。

> ⚠️注意：关闭高级权限后，已配置的自定义角色权限将不再生效，但自定义角色及其成员和配置会保留。你可以随时重新开启高级权限并继续使用原有配置

![](/zh/aitable/permissions/advanced-permissions-overview/images/image_psjQUbhDuN.png)

## 添加自定义角色

在高级权限设置中，点击左侧 + **添加角色**。

![](/zh/aitable/permissions/advanced-permissions-overview/images/image_K5XCvzDWAM.png)

添加角色后，可以为每一个数据表、仪表盘配置角色的权限。比如为 **销售人员** 角色配置 **每月销售额** 数据表的访问与操作权限

![](/zh/aitable/permissions/advanced-permissions-overview/images/image_uuOGgzPB75.png)

可以对自定义角色进行重命名、复制、删除的操作。

![](/zh/aitable/permissions/advanced-permissions-overview/images/image_WdKdq3fErN.png)

## 为自定义角色添加成员

在自定义角色右上方，点击 **+ 添加成员**，即可为该角色添加相应的成员。你可以按需选择具体人员、群组或部门，添加后的成员将拥有该角色已配置的全部权限

![](/zh/aitable/permissions/advanced-permissions-overview/images/image_meLTmoIvml.png)

## 修改角色整体权限配置

开启高级权限后，默认仅**管理员**和**自定义角色成员** 可以访问 AI表格。此时，原有的编辑者和查看者将暂时无法访问，需要为其配置相应的自定义角色后才能继续使用。

![](/zh/aitable/permissions/advanced-permissions-overview/images/image_-6YzkTpyMw.png)

你也可以切换为**所有角色成员可访问**。在该模式下，可为未被分配到任何自定义角色的成员设置**默认生效角色**。默认情况下，该角色为遵循文档权限的编辑者或查看者，也可根据需要指定为某个自定义角色。

设置完成后，所有拥有文档权限但未被分配到任何自定义角色的成员，将按该默认角色的权限，并结合其文档权限共同生效。

![](/zh/aitable/permissions/advanced-permissions-overview/images/image_LlfrJo2J7C.png)

## 预览（查看成员实际生效权限）

用于快速确认指定成员在当前权限配置下的最终可访问范围与操作能力。系统会综合该成员的角色权限与文档权限，实时展示其可以查看的数据、可执行的操作以及受限内容，方便在配置完成后进行校验与调整

![](/zh/aitable/permissions/advanced-permissions-overview/images/image_fT-GV-4AZh.png)
