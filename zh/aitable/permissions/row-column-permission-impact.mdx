## 高级权限中可以设置的行列权限

| **权限**​             | **可设置的权限**​                                                                                                                                                                                                             |
| ------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **可编辑：与成员自己相关的记录**​ | - 可对记录进行的操作：是否可以**新增**、**删除记录** - 可记录和删除的记录范围：成员是否可以编辑**自己创建**的，或者**人员字段中包含自己**的记录 - 其他记录权限：是否可以查看和自己不相关的记录 - 字段内容权限：是否可以**查看**、**编辑**、**新增**指定的**字段内容** - 视图操作权限：是否可**新增、修改、删除**视图 |
| **可编辑：指定字段内容**​     | - 可对记录进行的操作：是否可以**新增**、**删除记录** - 字段内容权限：是否可以**查看**、**编辑**、**新增**指定的**字段内容** - 视图操作权限：是否可**新增、修改、删除**视图                                                                                     |
| **可编辑：自定义范围**​      | - 可对记录进行的操作：是否可以**新增**、**删除记录** - 可记录和删除的记录范围： 是否可以编辑或删除**符合筛选条件**的记录内容 - 其他记录权限：是否可以查看和自己不相关的记录 - 字段内容权限：是否可以**查看**、**编辑**、**新增**指定的**字段内容** - 视图操作权限：是否可**新增、修改、删除**视图                |
| **可查看**​            | - 可阅读的记录范围： 是否可以阅读**符合筛选条件**的记录内容 - 字段内容权限：是否可以阅读指定的**字段内容**                                                                                                                                                    |

## 高级权限对表单的影响

| **表单中的字段**​              | **填写效果**​                                                | **适用场景**​                                                |
| ------------------------ | -------------------------------------------------------- | -------------------------------------------------------- |
| **单向/双向关联字段**​           | **表单视图**：用户在AI表格表单内填写时，自动过滤显示权限内的关联数据          | 销售录入订单时需要关联客户，仅能看到和关联自己负责的客户                             |
|                          | **通过链接分享的表单**：隐藏权限外的关联数据，仅显示索引列（如物品名称，不显示库存量）        | 员工办公物品领用，办公物品的库存等基本信息不对外部开放开放，仅能看到物品名称                   |
| **公式字段**​                | **表单视图**：用户在AI表格的表单视图内填写时，仅能查看自己权限范围内数据的计算结果   | 员工报销时，仅能看到自己填写的费用明细总和                                    |
|                          | **通过链接分享的表单**：完全显示公式结果，无需源数据权限                       | 填写订单信息时，即使对商品表无权限，也能通过公式字段看到需要下单商品的总报价                   |
| **单选/多选字段引用了其他数据表的选项时**​ | **表单视图：** 用户在AI表格的表单视图内填写时，只能查看和选择自己有权限的选项               | 内部调研时，仅显示本区域的选项    员工入职表单中，部门下拉选项仅显示有权限的部门   |
|                          | **通过链接分享的表单**：用户通过表单分享链接填写表单时，可以查看和选择全部选项            | 客户提交需求时，可自由选择所有产品类别                                      |
