通过为表单设置**预填默认值**，我们可以实现：

**预填默认值**：当门店提交一个表单任务后,希望自动带入门店信息,避免误填

**获取信息提交渠道**：用户提交报名后,在一列来源中自动填充**来源渠道**

## 基础操作

格式：
**单题预设**：表单分享链接`?prefill_问题名称=预填值`**多题预设**：表单分享链接`?prefill_问题名称=预填值&prefill_问题名称=预填值`

示例：
[https://alidocs.dingtalk.com/notable/share/form/v011GXn4BrXGJobODQ4_hERWDMS_7LisUkm?prefill_标题=预设标题&prefill_单选=选项二](https://alidocs.dingtalk.com/notable/share/form/v011GXn4BrXGJobODQ4_hERWDMS_7LisUkm?prefill_标题=预设标题&prefill_单选=选项二 "https://alidocs.dingtalk.com/notable/share/form/v011GXn4BrXGJobODQ4_hERWDMS_7LisUkm?prefill_标题=预设标题&prefill_单选=选项二")

当前支持设置默认值的问题类型：文本、数字、单选、多选

| 问题类型  | 设置规则                     |
| ----- | ------------------------ |
| 文本    | 表单链接`?prefill_渠道=微信`  |
| 数字    | 表单链接`?prefill_得分=1`   |
| 单选/多选 | 表单链接`?prefill_单选=运动鞋` |

默认值中包含特殊符号，需参照下表进行转化。

| 特殊符号 | 转换为以下内容添加至链接 |

| 空格   | %20 或 +      |
| ;    | %3B          |
| :    | %3A          |
| \\[ | %5B          |

| &    | %26          |

如果不希望表单中展示设置了默认值的问题，可在表单链接后添加参数`&hide_问题名称=1`来隐藏该问题。例如，若要隐藏内容提交表中的“审核人”信息，可将表单链接设置为：

[表单链接?prefill_审核人=Kato](https://alidocs.dingtalk.com/notable/share/form/v011GXn4BrXGJobODQ4_hERWDMS_7LisUkm?prefill_标题=预设标题&prefill_单选=选项二 "表单链接?prefill_审核人=Kato")[&hide_项目负责人=1](https://alidocs.dingtalk.com/notable/share/form/v011GXn4BrXGJobODQ4_hERWDMS_7LisUkm?prefill_标题=预设标题&prefill_单选=选项二 "&hide_项目负责人=1")

通过这种方式，还可以实现对表单提交渠道的追溯。比如，在收集用户对活动的反馈时，希望分析哪个渠道提交的表单最多。具体操作如下：

1. 在表单中新增一个问题，命名为“提交平台”。
2. 打开表单分享功能，设置填写范围，并复制表单分享链接。
3. 为表单链接添加来源参数。例如，若来源为DingTalk，则链接为：  

   表单链接`?prefill_提交平台=DingTalk&hide_提交平台=1`
4. 将不同的链接分别分享到各个平台上。

设置完成后，即可通过默认值来追溯表单提交的具体来源。

## 常见问题

#### **问：修改了表单中的题目名称后，预填的默认值会失效么？**

答：会导致预填默认值失效，此时请重新设置更新的题目名称。

#### **问：为什么我在AI表格表单中预填的人员姓名未生效？**

答：有以下几种可能

- 该姓名在组织内存在重复情况。
- 该人员为组织外部成员且未被列入你的DingTalk联系人。
- 姓名填写有误，请检查并修正。

#### **问：在AI表格表单中设置默认值后，所有填写者都能看到默认值吗？**

答：是的。若不希望填写者看到，默认值问题可通过添加参数`&hide_问题名称=1`隐藏。详见上文。

#### **问：为何链接中设置了隐藏问题，但表单中仍显示该问题？**

答：可能是字段为必填且默认值无效。因默认值无效，必填字段内容为空，可重新设置默认值解决。
