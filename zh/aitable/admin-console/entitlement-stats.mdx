**权益数据**页面用于帮助企业管理员统一查看和管理当前组织在**AI表格**中的版本权益使用情况，包括容量上限、功能开通状态及实时使用进度。

通过本页面，管理员可以清晰了解：

- 当前所使用的 AI 表格版本与有效期。
- 各项核心权益的可用上限 / 已使用情况。
- 需要扩容或升级的权益项。

从而辅助企业进行**容量规划、权限配置和版本升级决策**。

![](/zh/aitable/admin-console/entitlement-stats/images/image_4zIMUodv2N.png)

## 访问地址

打开DingTalk客户端>更多>管理后台，或直接访问[https://oa.dingtalk.io/#/welcome](https://oa.dingtalk.io/#/welcome "https://oa.dingtalk.io/#/welcome")进入DingTalk管理后台。在左侧菜单中打开AI表格>权益数据 进入权益数据页面。

![](/zh/aitable/admin-console/entitlement-stats/images/image_KCZ2NJLjuh.png)

## 信息说明

### 当前版本与有效期

页面顶部展示当前组织所使用的 AI 表格版本（企业版 / 旗舰版），以及已使用天数和到期时间。管理员可快速确认当前订购状态，并在到期前选择「预约咨询」或「立即升级」。

### 权益提醒

当某些关键权益（如行数、角色数量等）接近或达到上限时，系统将进行提示，管理员可点击「预约咨询」

![](/zh/aitable/admin-console/entitlement-stats/images/image_0ymaP1WbWj.png)

## 权益数据模块说明

| **权益类型**​  | **权益名称**​      | **详细说明**​                                                       |
| ---------- | -------------- | --------------------------------------------------------------- |
| **用量型权益**​ | 自动化流程运行次数      | 每月自动化工作流程节点运行次数可执行的最大上限，于次月 1 日起重计。                             |
|            | 单表最大行数         | 一个数据表内可容纳的数据记录数量，单表容量最大可扩容至 1000 万行。                            |
|            | 高级权限自定义角色数量    | 每个 AI 表格中可设置的高级权限自定义角色的个数                                       |
| **功能型权益**​ | 仪表盘支持按用户权限统计   | 仪表盘数据图表展示可设置跟随访问者数据权限进行统计，1 个仪表盘实现多人不同数据展示效果。                   |
|            | 自动化循环节点最大可循环次数 | AI 表格自动化工作流支持节点循环的逻辑。通过设定规则，它可以重复执行相同的操作，直到任务完成。每个循环节点可执行的最大次数。 |
|            | 仪表盘联表分析        | 在同一 个AI 表格中，可将不同数据表中数据组合在一张图表中显示，实现更全面、更有深度的数据分析。               |
|            | AI字段高速通道       | AI 字段快速生成，减少等待时间。让业务运转更高效                                       |
|            | AI字段定时更新       | 部分高级AI字段支持每24小时定时更新（包含快递物流查询、整行内容总结等）                           |

### 权益扩容

#### **单表最大行数扩容**

1. 点击单表最大行数卡片上的「去扩容」；

   ![](/zh/aitable/admin-console/entitlement-stats/images/image_rLGU1dqw7d.png)
2. 跳转到扩容表单，在此页面提交扩容申请。

   ![](/zh/aitable/admin-console/entitlement-stats/images/image_-kbL5qqMif.png)

#### **高级权限自定义角色数量扩容**

1. 点击高级权限自定义角色数量卡片上的「去扩容」；

   ![](/zh/aitable/admin-console/entitlement-stats/images/image_GBK3XK7LbQ.png)
2. 跳转到订单页，直接提交升级订单或预约咨询。

   ![](/zh/aitable/admin-console/entitlement-stats/images/image_EA0WAn6Iqz.png)

### 用量明细

#### **单表最大行数用量明细**

1. 点击单表最大行数卡片上的「用量明细」；

   ![](/zh/aitable/admin-console/entitlement-stats/images/image_TsTduB0C3P.png)
2. 跳转到数据表行数用量界面，在此页面可以查询企业内数据表的行数用量。

   ![](/zh/aitable/admin-console/entitlement-stats/images/image_XJ97g0KWRv.png)

#### **自定义角色用量明细**

1. 点击高级权限自定义角色数量卡片上的「用量明细」；

   ![](/zh/aitable/admin-console/entitlement-stats/images/image_IfV40nihny.png)
2. 跳转到高级权限自定义角色用量界面，在此页面可以查询企业内数据表的自定义角色用量。

   ![](/zh/aitable/admin-console/entitlement-stats/images/image_nw-n1fIFOH.png)

## 使用建议

1. 建议管理员定期查看权益数据页面，关注核心容量的使用趋势。
2. 当出现红色进度条或权益告警时，及时进行资源调整。
3. 结合企业实际规模与业务复杂度，合理选择或升级 AI 表格版本。
