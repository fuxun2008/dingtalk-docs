#### 问：一个AI表格中的数据表最多支持多少行？

答：最高单表支持1000万行。免费版本20,000行，企业版本30,000行，旗舰版本50,000行。

注：1000万行可申请付费使用。[扩容申请](https://alidocs.dingtalk.com/notable/share/form/v01eLbnj1bgP0ARrlaN_hERWDMS_BbIMDo9?dontjump=true "扩容申请")

---
#### 问：AI字段免费使用次数是多少？

答：AI表格免费版，每人每天最多可使用 AI 字段 10,000 次；AI表格企业版/旗舰版，每人每天最多可使用 AI 字段 50,000 次。

请注意，免费使用额度可能根据实际用量、成本及政策等因素进行动态调整。

#### 问：AI表格的不同字段在单个单元格内的上限是？

答：详情见下表。

| 字段类型          | 单个单元格内的上限      |
| ------------- | -------------- |
| 文本            | 字数不超过 10,000 字 |
| 人员（在允许多选的情况下） | 总个数不超过 1000 个  |
| 附件            | 总个数不超过 100 个   |
| 单向/双向关联       | 总个数不超过 500 个   |
| 群组            | 总个数不超过 10 个    |
