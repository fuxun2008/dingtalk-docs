在AI表格中，可以使用键盘快捷键进行一系列快捷操作：

| 操作            | Windows                            | Mac OS                          |
| ------------- | ---------------------------------- | ------------------------------- |
| 打开AI表格助理      | `Ctrl` + `/`                   | `⌘` + `/`                   |
| 撤销            | `Ctrl` + `Z`                   | `⌘` + `Z`                   |
| 重做            | `Ctrl` + `Shift` + `Z`       | `⌘` + `Shift` + `Z`       |
| 剪切            | `Ctrl` + `X`                   | `⌘` + `X`                   |
| 删除单元格内容       | `Del`                            | `Del`                         |
| 向上/下/左/右多选单元格 | `Shift` + `↑/↓/←/→`            | `Shift` + `↑/↓/←/→`         |
| 滚动到表格边缘并选中单元格 | `Ctrl` + `Shift` + `↑/↓/←/→` | `⌘` + `Shift` + `↑/↓/←/→` |
| 向下添加记录        | `Shift` + `Enter`              | `Shift` + `Enter`           |
| 全选            | `Ctrl` + `A`                   | `⌘` + `A`                   |
| 评论            | `Ctrl` + `Shift` + `M`       | `⌘` + `Shift` + `M`       |
| 保存视图配置        | `Ctrl` + `S`                   | `⌘` + `S`                   |
| 查找            | `Ctrl` + `F`                   | `⌘` + `F`                   |
| 展开文本单元格       | `Shift` + `Space`              | `Shift` + `Space`           |
| 展开侧边栏记录详情     | `Space`                          | `Space`                       |
| 关闭侧边栏记录详情     | `Esc`                            | `Esc`                         |
| 滚到视图最底部       | `Ctrl` + `↓`                   | `⌘` + `↓`                   |
| 滚到视图最顶部       | `Ctrl` + `↑`                   | `⌘` + `↑`                   |
| 记录详情切换上一条记录   | `Ctrl` + `Shift` + `↑`       | `⌘` + `Shift` + `↑`       |
| 记录详情切换下一条记录   | `Ctrl` + `Shift` + `↓`       | `⌘` + `Shift` + `↓`       |
| 隐藏/展开左侧边栏     | `Ctrl` + `\\`                  | `⌘` + `\\`                  |
| 竖向滚动          | `鼠标滚轮`                           | `鼠标滚轮`                        |
| 横向滚动          | `Shift` + `鼠标滚轮`               | `Shift` + `鼠标滚轮`            |
