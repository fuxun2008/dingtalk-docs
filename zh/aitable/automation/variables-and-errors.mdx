## 1 术语解释

在AI表格自动化流程中点击“+”按钮引用内容时，您可能会遇到一些特定的概念或名词。以下将对这些可引用的变量或字段进行解释说明。

### 1.1 AI表格变量

通过点击自动化面板右侧的+号，可添加AI表格内的字段变量，常用与发送AI表格内的字段内容列表给他人，创建群后回填群ID等操作

![](/zh/aitable/automation/variables-and-errors/images/image_8Js_35peXg.png)

#### 1.1.1 视图链接

某一个AI表格视图的链接，打开链接可以直接到达该视图。

![](/zh/aitable/automation/variables-and-errors/images/image_fVtn7vUAZj.png)

### 1.2 记录变量

通常在前置步骤中包含具体记录，在被后续引用时出现。

#### 1.2.1 记录ID

行记录的唯一标识符，在一个数据表内是唯一的，但在整个数据库中可能不唯一。换句话说，不同数据表中的记录ID有可能相同。

![](/zh/aitable/automation/variables-and-errors/images/image_st7rq8RnmT.png)

#### 1.2.2 流程配置者

配置此自动化流程的人员。

![](/zh/aitable/automation/variables-and-errors/images/image_ozVKWgcvwF.png)

#### 1.2.3 流程触发时间

包含今天（流程触发时间）、明天（流程触发时间+1天）、后天（流程触发时间+2天）。

![](/zh/aitable/automation/variables-and-errors/images/image_fdRm0KZO46.png)

### 1.3 附件字段

包含附件大小、附件名、附件类型、附件临时链接（此处为临时地址，将在生成链接2小时后失效）。

![](/zh/aitable/automation/variables-and-errors/images/image_OOixJ1Gf0H.png)

### 1.4 群组字段

通过群组ID可发送消息给群，也可将群组ID更新到「群组字段」中即可识别为「群卡片链接」

![](/zh/aitable/automation/variables-and-errors/images/image_gJGzk90v8c.png)

## 2 常见报错

### 2.1 数据表已被删除，请重新配置流程

原因：数据表被删除

解决办法：再次配置自动化，选择其他数据表。

### 2.2 指定的记录不存在

原因：出现在“更新记录”时，要修改的记录不存在。

解决办法：重新配置自动化流程。

### 2.3 字段已被删除

原因：字段被删掉

解决办法：重新配置自动化，选择其他字段。

### 2.4 数据表已达记录上限，无法新增记录

原因：数据表记录达到了行数上限

解决办法：重新配置自动化，选其他数据表

### 2.5 当前流程触发过程中被关闭，运行终止

原因：流程配置者关闭了流程，导致运行终止。

解决办法：按需重新启动自动化流程。

### 2.6 HTTP 请求超时

原因：HTTP 请求的响应上限为20秒，超时后将不再等待请求结果返回。

解决办法：如需AI表格获取请求结果，需要被调用方调整执行逻辑，在超时前返回执行结果。

### 2.7 HTTP 请求出参返回格式不正确，请检查是否符合请求响应格式。

原因：可能是因为“发送 HTTP 请求”返回的内容自动带上了 content-type 等请求头（Header）的默认值，导致无法识别。

解决办法：检查并删除请求头默认值后重试。

### 2.8 HTTP 请求 URL 被封禁，请检查公网是否可访问。

原因：HTTP 请求不支持调用内网的 URL。

解决办法：更换请求 URL。

### 2.9 该附件字段仅支持移动端实时填写，请重新配置

原因：自动化流程中选择的附件字段设置了“仅可通过移动端拍摄上传”，无法通过自动化流程更改。

解决办法：重新配置，检查附件字段的设置（取消勾选“仅可通过移动端拍摄上传”），或选取其他字段。

### 2.10 自动化流程报错「接口业务错误：description:机器人模版已经停用或者未启用;solution:请联系管理员，上线机器人模版」

原因：应用被组织管理员禁用。

解决办法：组织管理员登录OA后台（[https://oa.dingtalk.io/index.htm#/microApp/microAppListNew](https://oa.dingtalk.io/index.htm#/microApp/microAppListNew "https://oa.dingtalk.io/index.htm#/microApp/microAppListNew")）启用「文档自动化助手」应用。

![](/zh/aitable/automation/variables-and-errors/images/局部截图@1x-3_LFNxUq5goi.png)

### 2.11 发送消息时报错 check group admin failed

原因：群配置为需要管理员才可以添加酷应用，但当前用户不是群管理员。

解决办法：请群管理员将你设为群管理员，或者请群管理员配置一个流程，将酷应用加进群里。

### 2.12 流程中包含发送消息执行动作，保存时报错 installCoolApp for xxx, service result...

![](/zh/aitable/automation/variables-and-errors/images/局部截图@1x-2_ijha5WxElS.png)

解决办法：

1. 组织管理员登录OA后台（[https://oa.dingtalk.io/index.htm#/microApp/microAppListNew](https://oa.dingtalk.io/index.htm#/microApp/microAppListNew "https://oa.dingtalk.io/index.htm#/microApp/microAppListNew")）启用「文档自动化助手」应用。

   ![](/zh/aitable/automation/variables-and-errors/images/局部截图@1x-3_tmUcDRTsal.png)
2. 请群管理员将你设为群管理员，或者请群管理员配置一个流程，将酷应用加进群里。

### 2.13 创建待办失败，报错「ISV suiteKey check privilege error」

原因：组织限制了「文档自动化助手」的可见范围，但报错流程的最后保存者不在可见范围内。

1. 组织管理员登录OA后台（[https://oa.dingtalk.io/index.htm#/microApp/microAppListNew](https://oa.dingtalk.io/index.htm#/microApp/microAppListNew "https://oa.dingtalk.io/index.htm#/microApp/microAppListNew")）配置「文档自动化助手」应用。

   ![](/zh/aitable/automation/variables-and-errors/images/局部截图@1x_QOIHkyW9hc.png)
2. 将「应用可见范围」调整为「全部员工」，或者将流程的最后保存者加入到「部分员工」列表中

   ![](/zh/aitable/automation/variables-and-errors/images/局部截图@1x-4_jKYJBKmZ9Q.png)

### 2.14 错误描述: robot 不存在；解决方案:请确认 robotCode 是否正确；

解决办法：

1. 组织管理员登录OA后台（[https://oa.dingtalk.io/index.htm#/microApp/microAppListNew](https://oa.dingtalk.io/index.htm#/microApp/microAppListNew "https://oa.dingtalk.io/index.htm#/microApp/microAppListNew")）启用「文档自动化助手」应用。

   ![](/zh/aitable/automation/variables-and-errors/images/局部截图@1x-3_p1wymwaEC0.png)
2. 请群管理员将你设为群管理员，或者请群管理员配置一个流程，将酷应用加进群里。
