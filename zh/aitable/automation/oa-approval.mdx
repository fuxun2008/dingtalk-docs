## 自动化发起OA审批的场景有哪些？

- 工厂制造：部件招投标项目管理，每个节点需要内部会签后才可进入下一步
- 行政流程：通过AI表格表单提交设备租借申请后，进入OA审批流程，审批通过后自动出库并减库存
- 餐饮连锁：开店流程中的每个环节需要发起审批，审批通过后才可进入下一个环节

## 如何设置自动化流程？

首先设置一个触发条件后，选择发起OA审批（新）节点（新节点支持回填状态）；

![](/zh/aitable/automation/oa-approval/images/image_7J-PklmVID.png)

然后选择一个你要关联的OA审批单（你需要先具备OA审批管理员权限才可发起 如何申请管理员权限）

- 设置为系统自动发起
- 设置按钮点击者身份发起
- 设置表单对应的AI表格字段变量，目前支持附件、部门等高级字段的输出

![](/zh/aitable/automation/oa-approval/images/image_tYqsCgC9fl.png)

如果你希望审批状态回写到AI表格中，你需要开启「审批发起后，将状态同步回AI表格」开关

- 选择回写的数据表，一般设置为第一步触发的记录所在表
- 选择状态回填的字段名称

![](/zh/aitable/automation/oa-approval/images/image_jTjYXXHNKq.png)

## 字段如何与OA审批匹配？

目前通过AI表格发起OA审批因为是2个应用系统，所以字段类型需要完全一一对应，否则会出现审批发起失败，或审批内容为空的问题。以下是目前支持的字段类型：

| OA审批字段 | 对应AI表格字段     | 说明                               |
| ------ | ------------ | -------------------------------- |
| 单行输入框  | ✅文本          |                                  |
| 多行输入框  | ✅富文本         | 但富文本中的格式/图片等信息会丢失                |
| 数字输入框  | ✅数字          |                                  |
| 单选框    | ✅单选          | 请确保选项完成一致                        |
| 多选框    | ✅多选          | 请确保选项完成一致                        |
| 身份证    | ✅身份证         |                                  |
| 日期     | ✅日期          |                                  |
| 时间区间   | ✅日期          |                                  |
| 电话     | ✅电话          |                                  |
| 附件     | ✅附件与图片       | 支持多选，最多支持10个附件，超过的数量附件将无法同步到OA审批 |
| 联系人    | ⚠️仅支持选择内部联系人 | 仅可选择内部联系人，如用户选择外部联系人则字段为空        |
| 图片     | ⚠️不支持        | 请在OA审批中使用附件字段                    |
| 外部联系人  | ⚠️不支持        |                                  |
| 手写签名   | ❌不支持         |                                  |
| AI控件   | ❌不支持         |                                  |
| 级联/分类  | ❌不支持         |                                  |
| 明细/表格  | ❌不支持         |                                  |
| 金额     | ❌不支持         |                                  |

- **如何创建OA审批？**
  - 请查阅以下链接操作创建

    [ OA审批 来自「DingTalk使用手册」 https://alidocs.dingtalk.com/i/p/Y7kmbokZp3pgGLq2/docs/lo1YvX0prG98keM3X7aqVPw7xzbmLdEZ](https://alidocs.dingtalk.com/i/p/Y7kmbokZp3pgGLq2/docs/lo1YvX0prG98keM3X7aqVPw7xzbmLdEZ " OA审批 来自「DingTalk使用手册」 https://alidocs.dingtalk.com/i/p/Y7kmbokZp3pgGLq2/docs/lo1YvX0prG98keM3X7aqVPw7xzbmLdEZ")
- **如何申请OA审批的管理员权限**？
  1. 找到企业管理员：前往通讯录，在人员名录中找到管理员，说明使用原因并联系他开通子管理员：OA审批权限

![](/zh/aitable/automation/oa-approval/images/image_1_5IQsb04E.png)

  2. DingTalk后台设置：管理员可以通过以下路径为你添加管理员权限：
     - 管理员点击进入[DingTalk管理后台](https://login.dingtalk.io/oauth2/challenge.htm?redirect_uri=https%3A%2F%2Foa.dingtalk.com%2Fomp%2Flogin%2Fdingtalk_sso_call_back%3Fcontinue%3Dhttps%253A%252F%252Foa.dingtalk.com%252Findex.htm&response_type=code&client_id=dingoaltcsv4vlgoefhpec&scope=openid+corpid&org_type=management#/welcome "DingTalk管理后台")
     - 点击安全与权限，进入权限管理页面

![](/zh/aitable/automation/oa-approval/images/image_ALt_VuRgkg.png)

     - 添加你为子管理员，并设置权限范围为 OA审批权限

![](/zh/aitable/automation/oa-approval/images/image_nQys5MDqu8.png)

- **发起审批字段报错怎么办？**
  1. 检查是否有必填字段为空，导致失败
  2. 查看上方OA审批字段对照表，是否有不支持的字段被引用
- **我发起的时候有15个附件，为什么在OA审批里只有10个？**

  OA审批附件最大支持10个，在AI表格内超过的附件数量将无法同步
