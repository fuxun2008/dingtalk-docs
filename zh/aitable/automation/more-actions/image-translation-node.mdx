## 使用效果

当用户上传一张商品图片后，可自动触发自动化工作流中的图片翻译节点，并自动生成排版一致的目标语言图片，目前已支持：中文、中文（繁体）、英语、日语、韩语、马来西亚、阿拉伯语。

## 如何使用该节点搭建自动化工作流

1. **进入自动化工作流搭建流程**

   选择当表中图片添加后立即执行「图片翻译」由三方Aidge提供，当前可免费试用1000次）动作，并更新记录到第一步触发的流程

   ![](/zh/aitable/automation/more-actions/image-translation-node/images/image_sHWgiwhzM-.png)
2. **添加图像翻译节点后，按以下方式获取凭证**
   - **Aidge 登录入口**
     - Web 端地址：[https://www.aidc-ai.com/](https://www.aidc-ai.com/ "https://www.aidc-ai.com/")
   - **Web 端注册/登录流程：**
     - 进入上述 Web 端地址，点击“登录”。
       ![](/zh/aitable/automation/more-actions/image-translation-node/images/image_xP1YPVNE8h.png)
   - **凭证的获取与使用**
     - 登录 Aidge 平台账户后，点击首页的立即试用，或点击右上角的用户logo，点击进入控制台
       ![](/zh/aitable/automation/more-actions/image-translation-node/images/image (86)_cWnE5NfDxN.png)
     ![](/zh/aitable/automation/more-actions/image-translation-node/images/image (87)_G9AuI5diq-.png)
     - 点击左侧资产，点击API Key，可获取该账户的名称与密钥。API Key 为该账户的授权永久凭证，可用于调用接口。
       ![](/zh/aitable/automation/more-actions/image-translation-node/images/image (88)_Sqxxa2JuKI.png)

- **回到自动化流程配置页面，在配置凭证时输入可调用产品**
  - 凭证名称：用户自定义
  - 名称：Aidge官网中API key名称
  - 密钥：Aidge官网中API key密钥
    ![](/zh/aitable/automation/more-actions/image-translation-node/images/image (89)_DNDaa-X_qL.png)
