## 使用前准备：**获取飞书App ID与App Secret**

![](/zh/aitable/automation/more-actions/feishu-node/images/image_nY1PwQWXVm.png)

1. **前往**[**飞书创建自建应用**](https://open.feishu.cn/app "飞书创建自建应用")**并获取App ID与App Secret**；

   ![](/zh/aitable/automation/more-actions/feishu-node/images/f25e9a4d-f7b3-4797-81e2-46a90b0da11f_yO9TQqAyxR.png)
2. **确保自建应用拥有对应字段权限**；

   如[获取子部门列表](https://open.feishu.cn/document/server-docs/contact-v3/department/children "获取子部门列表")接口，需要活动对应通讯录相关接口权限

   ![](/zh/aitable/automation/more-actions/feishu-node/images/a11a22fb-ceea-4f2b-9a13-d59bfce7c37b_lDtz7z3uRE.png)
3.  **申请自建应用API权限（**[**企业自建应用申请 API 权限**](https://open.feishu.cn/document/server-docs/application-scope/introduction?lang=zh-CN "企业自建应用申请 API 权限")**）**
   1. 登录[开发者后台](https://open.feishu.cn/app "开发者后台")，进入指定自建应用。
   2. 在左侧导航栏进入 开发配置 > 权限管理 页，点击 开通权限 按钮。
   3. 在弹出页面中选择所需权限，点击 确认开通权限，系统自动跳转到已申请的权限列表页面。
      ![](/zh/aitable/automation/more-actions/feishu-node/images/75aef05e-aca4-4708-82ba-c115ef00a4a2_ZxKAxw9tgH.png)
