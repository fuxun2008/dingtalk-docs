# 天气查询

根据用户输入的 **城市编码**（adcode），查询目标区域当前/未来的天气情况。如需更高精度，或者更多深度内容（如积水、积雪）等高级天气能力，请通过 [工单](https://console.amap.com/dev/ticket/create/66 "工单") 进行商务咨询。

parameters 代表的参数包括必填参数和可选参数。所有参数均使用和号字符(&)进行分隔。下面的列表枚举了这些参数及其使用规则。

1. **前置条件：你需要获取 城市编码**

   请前往[ 城市编码表 ](https://lbs.amap.com/api/webservice/download " 城市编码表 ")
2. **工作流配置说明**

   输入城市编码和气象类型

   参数选择说明可前往：
