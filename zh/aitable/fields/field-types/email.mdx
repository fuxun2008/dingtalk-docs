# 功能概述

使用AI表格邮箱字段，通过格式校验来保证输入的邮箱地址规范有效。

# 基础操作

点击新建字段：点击AI表格标题栏右侧的+，在字段类型中选择邮箱

![](/zh/aitable/fields/field-types/email/images/全屏截图@1x-6_PxFkAtxh7H.png)

输入邮箱时会自动校验邮箱地址

![](/zh/aitable/fields/field-types/email/images/全屏截图@1x-7_sN2jTeHqvx.png)

# 常见问题

- **问：同一个单元格可以导入多个邮箱地址吗？**

  答：不可以，输入新的邮箱地址会覆盖以前的邮箱地址。
