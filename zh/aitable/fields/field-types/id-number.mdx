# 1 功能概述

用于**信息收集**中统计身份证号，并对于身份证号的真实性进行**校验**，当身份证号格式不对时会进行提示并无法保存

# 2 基础操作

## 2.1 在表格视图新建字段

点击AI表格顶端标题栏右侧的➕，在字段类型中选择**身份证**

![](https://img.alicdn.com/imgextra/i4/O1CN01Yzog048qwlD5XPUW_!!6000000001677-2-tps-2728-1768.png)

## 2.2 在表单视图新建字段

在表单左侧的题目中选择身份证，即可作为表单问题进行信息收集

![](https://img.alicdn.com/imgextra/i1/O1CN01InmhJl7mcsK7a2zP_!!6000000000642-2-tps-3734-1921.png)

## 2.3 管理编辑字段

双击字段标题或点击下拉按钮，在弹窗中可选择复制/删除/冻结等

![](https://img.alicdn.com/imgextra/i1/O1CN01Y5WDvuh279G5XPW8_!!6000000007035-2-tps-2728-1868.png)

# 3 场景实践

身份证字段主要应用于信息收集的场景，建议使用表单视图进行收集确保填写人隐私。如果希望使用表格视图进行收集可以开启**高级权限**，将角色**可编辑权限**设置为：与成员自己相关的记录，将其他记录权限设置为**不可查看**

![](https://img.alicdn.com/imgextra/i4/O1CN01DOsSlqQeiGB5XPQU_!!6000000000310-2-tps-2728-1518.png)
