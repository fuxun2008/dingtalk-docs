# 1 功能概述

在AI表格中，按钮字段可作为**自动化的触发条件**。用户进入数据表后，只需点击按钮即可启动预设操作。

**常见场景**：

- **消息通知**：在维修场景中，点击按钮提交维修需要，会通知对应的维修人员
- **群组创建**：在门店运营时，点击按钮一键创建群聊，并将群组的群号更新到表格中
- **信息流转**：在需求转化场景中，点击按钮确认立项，更新需求数据表中的状态为“已立项”并在需求管理表格中新建一条记录

# 2 基础操作

点击标题栏右侧的加号**创建新字段**，在字段类型中选择**按钮**，在配置面板中设置按钮字段的名称、按钮显示的文字、按钮的颜色、执行成功的提醒。

![](https://img.alicdn.com/imgextra/i1/O1CN01VGCoiC1chVebyxJgh_!!6000000003632-1-tps-1280-648.gif)

点击按钮后执行的操作通过**自动化**进行配置，点击按钮后可以配置的自动化包括常用动作（基础操作、执行逻辑、HTTP请求）、AI能力和业务应用。具体可参照自动化执行动作。

![](/zh/aitable/fields/field-types/button/images/image_lwgu4NezFH.png)

配置结束后点击右上角的**保存并启用**，也可以点击**执行记录**查看执行的记录

![](/zh/aitable/fields/field-types/button/images/image_dUeK1hcfwa.png)

# 4 按钮自动化和条件自动化

## 4.1 核心功能区分点

| 维度   | 按钮自动化        | 条件自动化            |
| ---- | ------------ | ---------------- |
| 触发方式 | 人工主动触发（点击按钮） | 系统被动触发（满足预设条件）   |
| 控制权  | 用户明确授权       | 完全依赖规则           |
| 执行时机 | 即时响应（需人工决策）  | 实时/周期性监测（无需人工干预） |
| 灵活性  | 单次/批量触发      | 自动触发             |

## 4.2 什么场景选择按钮自动化而非条件自动化

| 场景         | 案例                   | 价值                         |
| ---------- | -------------------- | -------------------------- |
| 需人工确认的敏感操作 | 财务付款审批确认             | 避免系统误判导致的资产损失              |
| 动态业务场景     | 客服工单的"紧急升级"、库存异常人工复检 | 人工介入复杂判断，弥补规则覆盖不足          |
| 合规性要求高的领域  | 医疗系统处方执行、法律文件电子签章    | 满足"操作留痕+人工确认"的审计要求，按钮记录触发人 |
| 资源敏感型任务    | 批量建群、批量邮件推送          | 避免高频自动化消耗服务器资源             |

## 4.3 什么场景选择条件自动化而非按钮自动化

| 场景           | 案例               | 价值          |
| ------------ | ---------------- | ----------- |
| 实时性要求高       | 股价、汇率等高频数据变动提醒   | 反应及时        |
| 规范化重复操作      | 订单状态同步           | 节省审核成本      |
| 无需人工介入的标准化流程 | 考勤打卡数据同步、发送入群欢迎语 | 反应及时、节省审核成本 |

# 5 常见问题

- 问：按钮字段支持哪些操作？

  答：支持自动化中的**所有操作**。
- 问：按钮字段可以**复制**吗？

  答：可以复制，但仅复制字段的标题、文本和颜色，不包括自动化。
- 问：谁可以配置或点击按钮字段？

  答：**配置权限**：未开启高级权限时，多维表所有者、可管理及可编辑权限的用户可配置按钮字段。开启高级权限后，仅多维表所有者和可管理权限的用户可配置；有数据表可编辑权限的用户可查看配置页面，但无法编辑或修改。

  **点击权限**：按钮为可点击状态时，所有能看到按钮字段的用户均可点击。
- 问：如何记录点击按钮的用户？

  答：可通过设置自动化流程实现，将触发条件设为“**点击按钮时**”，执行操作设为“**更新记录**”，将点击按钮的“按钮点击者”记录到一个单独的人员字段中。

  **注**：此方法仅展示最近一次点击按钮的用户，若想查看所有点击过按钮的用户，需查询该记录的历史记录。
