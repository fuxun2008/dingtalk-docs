**查找引用** 功能类似于Excel的`FILTER`函数。它无需手动输入复杂公式或建立表间关联，只需设定筛选条件，即可快速查找并引用目标数据，实现数据筛选与统计。

## 创建字段

点击最右侧的+，选择字段类型为**查找引用**

![](https://img.alicdn.com/imgextra/i2/O1CN01ZjYq0ENB6KI2b85w_!!6000000001644-1-tps-1280-648.gif)

## 字段配置

### 要引用的字段

选择**要引用的字段**，支持跨数据表进行引用，需要选择字段所处的**数据表**和**字段名称**

![](https://img.alicdn.com/imgextra/i3/O1CN01HtTNLPg4pcH3LCjw_!!6000000002969-2-tps-1646-1226.png)

### 查找条件（筛选所需记录）

可以添加多个**查找条件**条件进行筛选，逻辑判断词（等于、不等于、包含、不包含、为空、不为空）的前面需要选择**被引用数据表**的字段，后面选择**当前数据表**的字段或者**输入字符串/选择选项**（前面的字段为单选）。

可以设置满足所有条件/满足任一条件。

![](https://img.alicdn.com/imgextra/i2/O1CN01BcrJ1Xp94kJ36Lq8_!!6000000001825-2-tps-1528-1404.png)

### 计算方式（实现统计效果）

选择合适的计算方式对符合筛选条件的记录进行**统计**处理，并选择展示的**数字格式**

![](https://img.alicdn.com/imgextra/i4/O1CN01vmIRlrFjM7H36Lq8_!!6000000003796-2-tps-1528-1404.png)

| **计算方式名称**​ | **解释**​                | **使用场景示例**​           |
| ----------- | ---------------------- | --------------------- |
| 原值          | 从数据表里面直接引用列数据          | 配合筛选，为符合某一条件的记录添加原值   |
| 去重          | 将原值的数据去重复              | 删除重复的记录               |
| 总和          | 将原值的数据累加               | 配合筛选，查看符合某一条件的总和      |
| 平均数         | 计算原值的数据的平均数            | 配合筛选，查看符合某一条件的平均值     |
| 最大值         | 返回原值的数据的最大值            | 配合筛选，查看符合某一条件的最大值     |
| 最小值         | 返回原值的数据的最小值            | 配合筛选，查看符合某一条件的最小值     |
| 非空数值计数      | 计算原值的数据中非空【数字】类型的数量    | 查看非空的数字记录数量           |
| 非空值计数       | 计算原值的数据中非空的数量，包含数值和文本值 | 查看非空的记录数量             |
| 去重计数        | 计算原值数据去重后的数量           | 配合筛选，查看符合条件的记录种类      |
| 行数          | 计算原值的记录数量              | 配合筛选，查看符合条件的记录数量      |
| 连接成文本       | 将显示值合并成一个文本，以逗号为分隔符    | 引用多选字段，将多选选项连接为文本进行展示 |

可以展示的数字格式包括：小数位数、百分位、千分位、货币、日期等

**为什么强调配合筛选？**

如果不存在筛选条件，仅仅需要找出最大值/最小值/求和/计数等，可以直接通过数字字段上方的统计功能实现。

# 常用场景

## 为货品名称找到对应的编号

将库存台账作为引用数据源，引用货品编号这个字段，通过货品名称作为匹配项去，从而找到对应的编号。

![](https://img.alicdn.com/imgextra/i2/O1CN01IluMUaWpTTK4DpxA_!!6000000001995-2-tps-2080-1240.png)

## 计算门店的销售额

选择商品明细作为数据源，引用预售交易额数据，以类目作为筛选条件，对类目的业绩进行求和处理。

## 常见问题

- **问：一个查找引用字段可以同时引用多个字段吗？**

  答：不可以。每个查找引用字段只能引用一个字段。可以通过创建多个查找引用字段来引用不同数据表中的不同字段
- **问：我能设置哪些查找条件？**

  答：当前在查找条件中支持设置等于和不等于、包含、为空和不为空、早于和晚于（仅日期字段）。
- **问：我最多能添加多少个查找条件？**

  答：当前最多支持添加 5 个查找条件。
- **问：可以在文档和表格的AI表格使用查找引用字段吗？**

  答：可以。你可以在文档或表格中添加多个数据表，并在多个数据表之间查找引用数据。
- **问：哪些字段可以被引用和查找？**

  答：AI表格的所有字段类型都可被查找引用字段所引用，引用字段保留源字段的格式。如果被引用字段为单向或双向关联字段，将默认对关联的记录进行去重。AI表格的所有字段类型都能被用来作为查找条件。
- **问：可以查找被隐藏的字段吗？**

  答：可以，被隐藏的字段也将出现在查找引用字段面板的下拉列表中，点选即可将该字段设为源数据或查找条件。
- **问：查找结果会实时更新吗？**

  答：查找结果会实时更新。若源数据被修改，查找结果也将显示为更新后的数据，无需多次更新。
- **问：可以跨AI表格文件查找数据吗？**

  答：暂时不能。当前仅支持在同一AI表格、文档或表格文件中使用查找引用字段。
- **问：为什么我不能修改查找引用字段的内容？**

  答：查找引用字段的内容是通过引用自动生成的，需要在被引用的数据表中才能修改该字段的内容。
