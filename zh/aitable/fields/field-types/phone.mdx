# 功能概述

通过AI表格的「**电话**」字段，您可以录入电话信息，并支持**移动端**一键拨打电话或发送消息，让沟通更加便捷。

# 基础操作

## 新建电话字段

**表格视图-新建电话字段：**

1. 点击标题栏右侧+
2. 点击选择「字段类型」
3. 选择字段类型为「**电话**」

![](/zh/aitable/fields/field-types/phone/images/image_pb6Y3cPjPi.png)

利用表单收集**电话**，进入表单视图「**编辑模式**」，在题目中选择电话即可创建题目

![](/zh/aitable/fields/field-types/phone/images/image_oaHCu8jI4x.png)

## 添加电话

点击单元格即可输入电话，自动校验**电话格式**

## 移动端拨打电话

在移动端打开AI表格，进入「**记录详细**」，点击电话号码字段右侧的图标，即可拨打电话或发送消息。

![](/zh/aitable/fields/field-types/phone/images/image_8Qv-dHNYnx.png)

# 常见问题

- **问：如何直接拨打字段中的电话号码？**

  答：在移动端打开AI表格，点击电话号码字段右侧的图标，即可拨打电话或发送短信。
