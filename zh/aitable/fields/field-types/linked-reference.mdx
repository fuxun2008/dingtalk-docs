# 功能概述

**同步功能**：利用单向关联[单向关联](/zh/aitable/fields/field-types/one-way-link)或者[双向关联](/zh/aitable/fields/field-types/two-way-link)将A表和B表进行联动，单向（双向）关联字段显示为主字段，如果希望将A表的**其他字段**显示在B表，可以利用**关联引用**字段。

**统计功能**：在将A表的其他字段显示在B表的同时，可以对于该字段进行简单的统计处理，包括原值、去重、总和等

# 基础操作

## 新建字段

点击AI表格顶端标题栏右侧的➕新建字段，在字段类型中选择**关联引用**。

![](https://img.alicdn.com/imgextra/i2/O1CN018ejD97pBkcH5XPUW_!!6000000005049-2-tps-2728-1768.png)

## 关联引用配置

**选择要引用的数据**：仅可以选择所在数据表中的**单向/双向关联字段**，即要使用关联引用的基础是有单向/双向关联字段。

**选择要引用的字段**：仅可以在单向/双向引用的**数据源表**中进行选择。例如：在选择要引用的数据中选择了a字段，a字段是对于A表的引用，那么选择要引用的字段只能在A表进行选择。

**计算方式**包括以下几种：原值、去重、总和、平均数、最大值、最小值、非空数值计数、非空值计数、去重计数、行数、连接成文本，具体的解释如下：

| 计算方式名称 | 解释                     |
| ------ | ---------------------- |
| 原值     | 从数据表里面直接引用列数据          |
| 去重     | 将原值的数据去重复              |
| 总和     | 将原值的数据累加               |
| 平均数    | 计算原值的数据的平均数            |
| 最大值    | 返回原值的数据的最大值            |
| 最小值    | 返回原值的数据的最小值            |
| 非空数值计数 | 计算原值的数据中非空【数字】类型的数量    |
| 非空值计数  | 计算原值的数据中非空的数量，包含数值和文本值 |
| 去重计数   | 计算原值数据去重后的数量           |
| 行数     | 计算原值的记录数量              |
| 连接成文本  | 将显示值合并成一个文本，以逗号为分隔符    |
