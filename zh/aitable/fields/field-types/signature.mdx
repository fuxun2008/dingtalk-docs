# 1 功能概述

签名仅为方便用户绘制签名图片的辅助功能，并非《中华人民共和国电子签名法》所述的电子签名或者电子签名行为，**不具有法律效力**，仅供用户记录使用

# 2 基础操作

点击顶部标题栏右侧的➕新建字段，在字段类型中选择**手写签名**

![](/zh/aitable/fields/field-types/signature/images/全屏截图@1x-8_M0w8LOuqre.png)

**双击单元格**可以在弹出的白板进行签名，对签名不满意可以点击右上角**清空**，对签名满意可以点击右下角的**确认**

![](/zh/aitable/fields/field-types/signature/images/DingTalk录屏_2025-03-21 150120_IBMVj5dId8.gif)
