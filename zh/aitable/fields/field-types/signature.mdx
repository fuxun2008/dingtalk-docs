# 1 功能概述

签名仅为方便用户绘制签名图片的辅助功能，并非《中华人民共和国电子签名法》所述的电子签名或者电子签名行为，**不具有法律效力**，仅供用户记录使用

# 2 基础操作

点击顶部标题栏右侧的➕新建字段，在字段类型中选择**手写签名**

![](https://img.alicdn.com/imgextra/i1/O1CN018U6iHYDutIF5XPUW_!!6000000001026-2-tps-2728-1768.png)

**双击单元格**可以在弹出的白板进行签名，对签名不满意可以点击右上角**清空**，对签名满意可以点击右下角的**确认**

![](https://img.alicdn.com/imgextra/i2/O1CN01zV4d9dIulrB2b85v_!!6000000005747-1-tps-1280-647.gif)
