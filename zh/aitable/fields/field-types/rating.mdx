# 1 功能概述

使用评分字段，可将分值以星星、爱心或点赞等图标展示，让打分效果更直观。

# 2 基础操作

## 2.1 新建字段

表格视图新建字段，点击AI表格顶端标题栏右侧的加号，在字段类型中选择评分

![](/zh/aitable/fields/field-types/rating/images/cobalt-plum.png)

**表单视图**新建字段，点击表单视图左侧添加问题，在编辑表单界面设置图形、分值、两级文案

![](/zh/aitable/fields/field-types/rating/images/flint-juniper.png)

## 2.2 配置字段

**图形**：选择星星、爱心、数字等图形

**分值**：自定义分值范围

**两级文案**：包括满意度、可能性、认同度等等

![](/zh/aitable/fields/field-types/rating/images/yarrow-thistle.png)
