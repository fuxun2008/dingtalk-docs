# 功能概述

使用单向关联字段，可快速在当前数据表中关联其他数据表中的记录，点击即可查看该记录的整行信息，无需进行切换操作。

**注**：在单向关联或双向关联字段里关联一条记录时，只能显示对应记录的第一个字段的值（即主字段的内容），不支持显示其他字段的内容。需要显示其他字段的内内容可以参考[关联引用](/zh/aitable/fields/field-types/linked-reference)

# 基础操作

## 新建单向关联

在标题栏最右侧点击➕，在字段类型中选择**单向关联**字段

![](/zh/aitable/fields/field-types/one-way-link/images/DingTalk录屏_2025-03-18 153558_EmMbPr0K0R.gif)

## 配置单向关联

### 选择要关联的表

下拉选择要关联的数据表，目前不支持跨AI表格进行关联

![](/zh/aitable/fields/field-types/one-way-link/images/全屏截图@1x-6_u-fcBPznjf.png)

### 勾选配置

勾选**允许多选记录**，可以在一个单元格内单线关联多条记录。

勾选**从视图筛选记录**，记录保留的字段和视图显示的字段一致，调整视图中显示的字段，单向关联的列表同步调整。

![](/zh/aitable/fields/field-types/one-way-link/images/全屏截图@1x-7_aA-pfwKv5a.png)

## 添加和查看关联记录

点击单元格勾选单向关联的记录，点击确认后所选记录的**主字段**将会列示在单元格中，**点击单个主字段**可以查看当条记录的详细信息，点击下拉按钮，可以查看**全部记录**或通过右上角滑块，**仅查看已选记录**。

![](/zh/aitable/fields/field-types/one-way-link/images/DingTalk录屏_2025-03-18 154930__whp8O9M4y.gif)

## 快速创建并关联新记录

如果你对被关联的数据表有**新增记录的权限**，你可以在建立单向关联时，直接在被关联数据表内新增一条记录并实现关联。

点击单元格下拉按钮查看单向关联的记录，选择**左下角➕**可以直接增添一条被关联的新纪录

在打开的空白记录卡片中填写信息，填写完成后，点击卡片右上角的**关闭卡片**按钮，新记录就会同步出现在被关联数据表和当前列表中。

勾选新创建的记录，点击右下角**确认**按钮即可。

![](/zh/aitable/fields/field-types/one-way-link/images/DingTalk录屏_2025-03-18 160000_wDXCyi_ShK.gif)

## 移除已经关联的记录

方式 1：单击单元格，点击需删除的条目右侧的**×**即可移除。

![](/zh/aitable/fields/field-types/one-way-link/images/全屏截图@1x (2)_ySvDvYqVIb.png)

方式 2：双击单元格，在弹窗中取消勾选记录，并点击右下角**确认**来移除关联。

**注**：删除单元格内的关联项不会影响源数据。

![](/zh/aitable/fields/field-types/one-way-link/images/全屏截图@1x-9_r8Nh_QcAIh.png)

## 跳到关联的数据表

添加关联记录时，搜索框上方会显示被关联数据表的名称。点击即可跳转，跳转到的具体页面是**从视图筛选记录**所选的视图。

![](/zh/aitable/fields/field-types/one-way-link/images/DingTalk录屏_2025-03-18 160942_3KqmYuWPnp.gif)

# 常见问题

- **问：我可以在一个单元格里添加多个关联记录吗？**

  答：可以，在字段配置的面板中勾选**允许添加多个记录**即可。
