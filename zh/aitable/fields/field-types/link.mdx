# 1 功能概述

使用「链接」字段，快速输入链接及展示文本，点击跳转相应网页。

# 2 基础操作

## 2.1 新建链接字段

1. 点击标题右侧+
2. 点击「字段类型」进行选择
3. 选择字段类型为「链接」

![](https://img.alicdn.com/imgextra/i1/O1CN01mrz5uRshBYC36bMk_!!6000000000932-2-tps-1530-1084.png)

## 2.2 编辑链接

1. 双击单元格
2. 上方文本框中输入展示的**文本**
3. 下方链接框中输入跳转到的网页**链接**
4. 输入完成后点击保存

![](https://img.alicdn.com/imgextra/i2/O1CN01WoDNnQBcTSI1JJwi_!!6000000003031-2-tps-646-598.png)

# 3 常见问题

- **问：可以在一个单元格内添加多个链接吗？**

  答：不能，在每个单元格内只能添加一个链接。
