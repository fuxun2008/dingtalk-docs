# 1 功能概述

使用条码字段，可通过DingTalk**移动端**扫描并识别**条形码**或**二维码**中的信息（如数字、文本、链接等），快速批量录入AI表格，便于后续处理。

# 2 基础操作

## 2.1 添加条码字段

在**表格视图**中，点击顶端功能栏右侧的+，在字段类型中选择条码在**表单视图**中，在左侧的题目中选择条码，即可实现利用表单收集条码

![](https://img.alicdn.com/imgextra/i4/O1CN01kPR6zSgBlUC5XPUW_!!6000000006259-2-tps-2728-1768.png)

**表单视图**中，在左侧的题目中选择**条码**进行添加，开启或关闭**仅允许手机端扫码录入**，从而实现利用表单收集条码

![](https://img.alicdn.com/imgextra/i1/O1CN017pMguTKFUmF6Z6cd_!!6000000000244-2-tps-3234-1721.png)

## 2.2 条码录入

关闭**仅允许手机端扫码上传**，可以通过**手动输入**或者**手机端扫码**实现条码录入。

开启**仅允许手机端扫码上传**，仅仅可以通过**手机端扫码**实现录入，具体的操作方式：点击进入手机端详细记录/点击表单链接，点击扫码，二维码、条形码中的信息将会填充在单元格中。

![](https://img.alicdn.com/imgextra/i3/O1CN010hGt9gURk1E1B8p1_!!6000000003726-2-tps-581-1278.png)

## 2.3 编辑管理条码字段

双击标题栏或者点击标题栏右侧的下拉按钮，可选择复制、粘贴、冻结该字段

![](https://img.alicdn.com/imgextra/i2/O1CN01xdyUV9QDygE5XPUW_!!6000000007135-2-tps-2728-1768.png)

# 3 常见问题

- **问：一个单元格能输入多个条码信息吗？**

  答：手动输入时可以，但通过移动端扫码仅支持录入一个条码信息。
- **问：能根据表格中的编码生成条形码或二维码吗？**

  答：目前不支持，建议使用第三方工具生成。
- **问：有哪些方法可以录入条码信息？**

  答：支持两种方式：手动输入和移动端扫码录入。
- **问：条码字段支持哪些类型的信息？**

  答：支持文本、链接和数字类型，暂不支持@人员。
