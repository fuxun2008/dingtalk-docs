# 1 功能简介

使用AI表格「**地理位置**」，你按照**省市区（-街道）** 的格式手动选择一个地理位置

# 2 基础操作

**表格视图-添加地址**

1. 点击标题栏最右侧的+
2. 点击「字段类型」进行选择
3. 选择字段类型为「**地址**」。

![](/zh/aitable/fields/field-types/administrative-region/images/image_eA7LaA8vDQ.png)

**设置地址格式**

格式的下拉框中选择「**省市区**」或者「**省市区-街道**」

选择「**省市区**」，只能在内置的省市区中进行选择

选择「**省市区-街道**」则在选择后还需要填写详细地址

![](/zh/aitable/fields/field-types/administrative-region/images/image_Jh5nmJZWa7.png)

**表单视图-添加地址**

1. 在左侧新增题目中选择「**地址**」
2. 在题目下方下拉栏选择「格式」

![](/zh/aitable/fields/field-types/administrative-region/images/image_cBtUr16sg3.png)

选择「**省市区**」，填表时所见问题如下图所示

![](/zh/aitable/fields/field-types/administrative-region/images/DingTalk录屏_2025-03-19%20150101_mmdc1SdZZu.gif)

选择「**省市区-街道**」，填表时所见问题如下图所示：

# 3 常见问题

- **问：同一个单元格可以导入多个地理位置吗？**

  答：不能。
- **问：切换地理位置的输入方式后，是否会影响我已经输入的信息？**

  答：不会。
