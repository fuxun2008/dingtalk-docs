# 1 功能简介

使用AI表格「**地理位置**」，你按照**省市区（-街道）** 的格式手动选择一个地理位置

# 2 基础操作

**表格视图-添加地址**

1. 点击标题栏最右侧的+
2. 点击「字段类型」进行选择
3. 选择字段类型为「**地址**」。

![](https://img.alicdn.com/imgextra/i3/O1CN01AE1Cav3iwzG34Ktw_!!6000000003955-2-tps-1512-1156.png)

**设置地址格式**

格式的下拉框中选择「**省市区**」或者「**省市区-街道**」

选择「**省市区**」，只能在内置的省市区中进行选择

选择「**省市区-街道**」则在选择后还需要填写详细地址

![](https://img.alicdn.com/imgextra/i3/O1CN01cufLGItZ2FE1pIM6_!!6000000005959-2-tps-900-726.png)

**表单视图-添加地址**

1. 在左侧新增题目中选择「**地址**」
2. 在题目下方下拉栏选择「格式」

![](https://img.alicdn.com/imgextra/i2/O1CN01PXRi3NCK5wB4joBc_!!6000000000322-2-tps-2334-690.png)

选择「**省市区**」，填表时所见问题如下图所示

![](https://img.alicdn.com/imgextra/i3/O1CN01hhC1axWRQ3B2b85w_!!6000000000910-1-tps-1280-648.gif)

选择「**省市区-街道**」，填表时所见问题如下图所示：

![](https://img.alicdn.com/imgextra/i3/O1CN01TyKr9OXgheF2b85w_!!6000000005354-1-tps-1280-648.gif)

# 3 常见问题

- **问：同一个单元格可以导入多个地理位置吗？**

  答：不能。
- **问：切换地理位置的输入方式后，是否会影响我已经输入的信息？**

  答：不会。
