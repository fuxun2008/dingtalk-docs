# 1 功能概述

使用AI表格的**地理位置**字段，你可以快速记录位置信息。支持手动输入、搜索任意地理位置，或通过移动端获取实时位置。

**常见场景：** 利用移动端获取实时位置保证巡查、打卡等位置的真实性

# 2 基础操作

表格视图点击顶部功能栏右侧的➕**新建字段**，在字段类型中选择**地理位置**，输入方式包括**可输入任何地理位置**和**仅允许移动端实时定位**

![](/zh/aitable/fields/field-types/geo-location/images/全屏截图@1x_-B4UZfRePJ.png)

**表单视图**中，在左侧的题目中选择**地理位置**进行添加，开启或关闭仅**允许移动端实时定位**，从而实现利用表单收集地理位置

![](/zh/aitable/fields/field-types/geo-location/images/全屏截图@1x-2_-pIAJKiIMf.png)

输入方式选择**可输入任何地理位置**，双击单元格，在搜索栏中输入地址，在搜索结果中选择地址，点击右下角的确认进行保存。

![](/zh/aitable/fields/field-types/geo-location/images/DingTalk录屏_2025-03-21%20153104_fspfI2RQ_1.gif)

输入方式选择**仅允许移动端实时定位**，在移动端进入记录详细/点击表单链接，**点击定位**

![](/zh/aitable/fields/field-types/geo-location/images/image_3DburAzLdb.png)

![](/zh/aitable/fields/field-types/geo-location/images/image_Ipnyjx0yoN.png)

# 3 常见问题

- **问：同一个单元格可以导入多个地理位置吗？**

  答：不可以。
- **问：切换地理位置的输入方式后，会影响已输入的信息吗？**

  答：不会影响。
