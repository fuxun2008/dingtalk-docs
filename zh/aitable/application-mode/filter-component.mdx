## 功能简介

过滤器组件是数据可视化分析的核心交互工具，用于**动态筛选和过滤仪表盘应用中的数据内容**。通过添加一个或多个过滤器，用户能够快速聚焦于特定数据子集，实现交互式数据分析与探索。

**典型的适用场景包括**：

- **全局数据筛选**：在仪表盘设置关键维度（如时间、地区、产品线）的过滤器，控制页面中所有关联组件的数据范围。
- **多组件联动筛选**：为仪表盘中不同组件设置专属的过滤器，实现分层筛选逻辑（例如：先用"时间"过滤器全局筛选，再用"产品线"过滤器仅作用于销售明细表）。

## 操作流程

### **添加过滤器组件**

1. 进入AI表格应用模块。
2. 在左侧导航栏选择需要添加组件的目标页面。
3. 点击页面左下角的  **+ 添加组件** ，然后选择** 过滤器** 。

![](/zh/aitable/application-mode/filter-component/images/image__s0YDcetXe.png)

![](/zh/aitable/application-mode/filter-component/images/image_GfF5oNSfKg.png.mark.png)

### **基础配置**

在添加组件后，通过右侧面板的 **基础配置** 进行以下设置：

![](/zh/aitable/application-mode/filter-component/images/image_huSXhDwo9v.png.mark.png)

- **标题名称**
  - 默认名称为“过滤器”，支持用户自定义修改。
- **数据选择**
  - **数据表与范围**：支持选择具体数据表及数据范围。
    - 选择 **全部数据** 时，可进一步设置筛选条件。
  - **展示字段**：支持从下拉列表中选择一个字段作为过滤器的显示内容。
    - 提供模糊搜索功能，便于快速定位字段。
- **过滤器样式**
  - **样式类型**：支持根据字段类型选择不同展示样式。

    ![](/zh/aitable/application-mode/filter-component/images/image_Wi7IsYc784.png.mark.png)
    - 日期型字段：支持下拉、平铺、日期三种样式。
    - 数值型字段：支持下拉、平铺、数字三种样式。
    - 枚举型字段：支持下拉、平铺两种样式。
  - **内容排序**：支持正序或倒序排列选项。

    ![](/zh/aitable/application-mode/filter-component/images/image_ysDi0ymXqM.png.mark.png)
  - **选择模式**：可设置支持单选或多选。

    ![](/zh/aitable/application-mode/filter-component/images/image_FBCN1yEwNs.png.mark.png)
- **生效范围**
  - **生效图表**
    - **自动模式**：默认控制当前页面中所有同数据源的图表。
    - **自定义范围**：手动选择需要关联的图表范围。

      ![](/zh/aitable/application-mode/filter-component/images/image_DMeLs4q8T3.png.mark.png)

      ![](/zh/aitable/application-mode/filter-component/images/image_yLx-R56Lp6.png.mark.png)
  - **关联过滤器**
    - **自动模式**：默认关联页面中所有同数据源的过滤器。
    - **自定义范围**：手动选择要关联的同数据源过滤器。

      ![](/zh/aitable/application-mode/filter-component/images/image_shQbYkNcyj.png.mark.png)**关联说明**：多个过滤器同时作用于图表时，各条件之间为“且”关系，即同时满足所有过滤条件。

### **自定义配置**

在右侧面板 **自定义配置** 中，进一步调整组件的视觉与交互效果：

![](/zh/aitable/application-mode/filter-component/images/image_fT7mnasLGy.png.mark.png)

- **背景颜色**  

  自定义设置组件的整体背景颜色。
- **边框样式**
  - **边框颜色：** 通过下拉配色板选择边框颜色。
  - **边框粗细：** 下拉选择设置边框粗细。
- **选中颜色**  

  在平铺样式下，可通过色板设置过滤器选项被选中时的突出显示颜色。
- **垂直对齐**  

  提供两种对齐方式选项，用于设置内容项在组件内的垂直位置（上部对齐或居中对齐）。

### **组件管理**

- **操作菜单**  

  选中组件后，点击其右上角的  图标，将展开操作菜单，您可以在此进行以下操作：

  ![](/zh/aitable/application-mode/filter-component/images/image_fzc_EW9KoE.png.mark.png)
  - **配置**：快速打开该组件的属性配置面板。
  - **复制**：在当前页面内复制一个相同的组件。
  - **复制到**：将组件复制到本应用内的其他指定页面。
  - **删除**：将组件从当前页面中移除。
- **调整大小与位置**

  ![](https://img.alicdn.com/imgextra/i3/O1CN01kr8YBj1VdCcRzEuyM_!!6000000002675-1-tps-2938-1494.gif)
  - **调整大小**：将鼠标悬停在组件右下边角通，并拖动拖拽手柄，即可自由调整组件的宽度和高度。
  - **移动位置**：将鼠标移至组件上方，浮现  图标，按住鼠标左键并拖动，可在页面内拖拽组件调整位置。

## 常见问题

#### 问：单个页面最多可以添加多少个过滤器？

答：20个。
