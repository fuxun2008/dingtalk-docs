## 使用前准备

在使用本连接器前，需要在合思费控后台开通开放接口，并获取一组 **App Key** 与 **App Security**，用于授权 AI 表格读取合思费控数据。

1. 登录合思费控（原易快报）后台，进入 **【应用中心】 → 【应用商店】 → 搜索“开放接口(新)”** → 选择对应商品

![](/zh/aitable/data-connectors/data-connectors-overview/hexin-expense/images/截屏2026-05-09%2009.47.28_WJrUCVCNmo.png)

1. 唤起开放接口(新)详情后，点击**【商品配置】**，可获取企业的 **App Key**（接入账号） 与 **App Security**（接入密码）。

![](/zh/aitable/data-connectors/data-connectors-overview/hexin-expense/images/截屏2026-05-09%2009.52.49_fIGLX2MRPL.png)

![](/zh/aitable/data-connectors/data-connectors-overview/hexin-expense/images/截屏2026-05-09%2009.54.30_ReaEKgU9a8.png)

> 📌 **请注意**：App Key 和 App Security 具备访问对应企业全部数据的能力，请妥善保管，避免外泄。如需作废可在【开放接口（新）】中**停用**，停用后原 App Key 和 App Security 将立即失效。

1. 凭证作废与重置

   因人员离职或其他原因需要作废原有的 App Key 和 App Security 时，管理员可在 **【应用中心】 → 【应用商店】 → 【开放接口（新）】 → 【商品配置】** 中点击 **【停用】**，原  App Key 和 App Security 将立即失效。停用后可创建新密钥，请同步在 AI 表格中编辑账号信息并填入新的 App Key 和 App Security。

> 📌 关于开放接口的详细说明，请参考[合思开放平台官方文档](https://docs.ekuaibao.com/docs/open-api/getting-started/question-answer "合思开放平台官方文档")。

## 选择数据源

进入 AI 表格 **数据连接中心**，搜索 **合思费控** 连接器，点击 **【使用】** 按钮，进入连接器配置界面。

![](/zh/aitable/data-connectors/data-connectors-overview/hexin-expense/images/截屏2026-05-09%2009.18.02_UGnqzrhyHA.png)

## 数据源设置

1. **关联合思费控账号**，首次使用时，点击 **【关联账号】** 按钮，在弹窗中填写 App Key 和 App Security：

![](/zh/aitable/data-connectors/data-connectors-overview/hexin-expense/images/截屏2026-05-09%2009.19.45_JR7q1X34uO.png)

填写完成后点击 **【确定】**，账号信息会保存在当前数据源中，后续可在数据源页面的账号卡片中**切换账号**或**编辑账号信息**。

1. **选择要同步的数据表**，每次数据源配置仅支持选择一个数据表。如需同步多个数据表，请重复创建数据源。本连接器目前支持同步以下数据表：

| 数据表         | 说明          |
| ----------- | ----------- |
| 合思费控 预算包列表  | 同步预算包信息     |
| 合思费控 报销单据列表 | 同步报销单据及金额信息 |
| 合思费控 借款单列表  | 同步借款单据信息    |
| 合思费控 申请单列表  | 同步申请单据信息    |

选择数据表后，连接器将自动加载对应的数据表配置。按需选择数据源获取的数据内容。

1. **字段设置**，选择数据表后将自动加载该数据表的字段列表。您可按需勾选要同步的字段，主键字段默认勾选且不可取消。

## 点击创建，开始同步数据

完成上述配置后，点击 **【保存并同步】** 按钮，连接器将进行数据同步。

![](/zh/aitable/data-connectors/data-connectors-overview/hexin-expense/images/截屏2026-05-09%2010.06.36_DAdtQBBnGX.png)

## 完成创建并查看数据

同步完成后，可在 AI 表格左侧的数据表列表中看到新创建的数据表。该表会以「同步表」形式存在，后续可以进行以下操作：

- **修改数据同步设置**

  在数据表右侧 更多操作 菜单中选择 【数据同步设置】，可调整勾选的字段以及同步参数。
- **手动同步更新**

  在数据表右侧 更多操作 菜单中点击 【更新数据】，连接器将立即重新调用合思费控接口并刷新当前表数据。
- **解除同步关系**

  在数据表右侧 更多操作 菜单中点击 【解除同步关系】，同步表将转换为普通可编辑表格，与合思费控数据源不再保持同步。
- **新增自定义字段**

  在不影响同步字段的前提下，可以在 AI 表格中新增自定义字段（如备注、标签、AI 字段等），自定义字段不会被同步操作覆盖。
