## 使用前准备：获取Access Token设置账号

获取Access Token指引示例：

1. 点击访问轻流-轻商城-拓展插件：[https://qingflow.com/center/plugin#3](https://qingflow.com/center/plugin#3 "https://qingflow.com/center/plugin#3")，点击** 第三方连接** 选择OPEN API ，点击配置

   ![](/zh/aitable/data-connectors/data-connectors-overview/qingflow/images/image_RIrpz5o4cS.png)

   ![](/zh/aitable/data-connectors/data-connectors-overview/qingflow/images/image_zNtONDjpm9.png)
2. 获取Access Token：超级管理员 Access Token拥有工作区创建者权限，可以调用除「code登评论」外所有openAPI接口。若是子管理员权限及获取操作，点击 **了解更多**，查看轻流的具体配置[https://exiao.yuque.com/ixwxsb/bgzs0e/onnrnp9i7nihz5l8](https://exiao.yuque.com/ixwxsb/bgzs0e/onnrnp9i7nihz5l8 "https://exiao.yuque.com/ixwxsb/bgzs0e/onnrnp9i7nihz5l8")。

   ![](/zh/aitable/data-connectors/data-connectors-overview/qingflow/images/image_AQ8Ly769Z7.png)

## 进入数据连接中心

点击AI表格左下角 **添加/导入** 按钮，选择 **数据连接中心** 。

![](/zh/aitable/data-connectors/data-connectors-overview/qingflow/images/image_7GDJX22gfM.png)

进入数据连接中心

![](/zh/aitable/data-connectors/data-connectors-overview/qingflow/images/image_nC7xX4HUsy.png)

## 选择数据源

支持选择或直接搜索 **轻流** 连接器，点击 **使用** 按钮，进入连接器设置界面。

![](/zh/aitable/data-connectors/data-connectors-overview/qingflow/images/image_0G--q2S3EO.png)

## 数据源设置

1. **选择数据源**，进行数据源的勾选，目前仅有1个数据源，默认勾选。
2. **账号设置**，账号名称自定义，输入在第一步准备好的关联账号Access Token。

   ![](/zh/aitable/data-connectors/data-connectors-overview/qingflow/images/image_1NxLUIlKTr.png)
3. **字段设置**，全选/勾选部分字段，灵活设置表格字段范围，其中主键不支持取消勾选。
4. **同步设置**，可以开启或关闭数据表同步设置。开启时，支持选择按小时同步模式或定时同步模式。
   - 按小时同步：支持选择每隔1小时、12小时或24小时进行同步。
   - 定时同步：支持选择按每天、每周或每月的某个固定时间点进行同步，可以配置是否跳过节假日。

     提示：如果在连接器设置过程中出现问题，可以通过 **数据源设置页 - 提交反馈** 进行反馈。

![](/zh/aitable/data-connectors/data-connectors-overview/qingflow/images/image_3ITBBayEJu.png)

## 点击创建，开始同步数据

连接器配置完成后，点击 **创建** 进行数据同步，成功创建后会自动新增一张数据同步表。

## 同步后相关操作

1. **修改数据同步设置**

   已设置同步的数据表，想要修改数据同步设置，点击数据同步表右侧  图标，选择 **数据同步设置** ，支持修改同步的字段项及同步机制，开启/关闭自动同步。
2. **手动同步更新**

   点击同步来的数据表，点击数据表名称右侧的 ⋮ 更多操作 图标。点击** 更新数据 **即可发起手动同步，点击后将重新拉取数据源数据并更新当前表。
3. **解除同步关系**

   点击 **解除同步关系** 即可将同步表变为可编辑的表格，与原始数据源不再具有同步关系。
