## 使用前准备

在使用本连接器前，需要在 Tapd 【公司管理】后台开通 API 账号，并获取一组 **API 账号** 与 **API 密钥**，以及需要同步数据的**项目 ID**，用于授权 AI 表格读取您的 Tapd 数据。

> 📌Tapd API 是 Tapd 的商业化模块，仅 **Tapd 企业版**支持。**公司管理员**可在【**公司管理**】 → 【**开放集成**】 → 【**API 账号管理**】中申请试用 90 天。

1. 申请并查看 API 账号和 API 密钥。使用公司管理员账号登录 Tapd，依次进入：**【公司管理】 → 【开放集成】 → 【API 账号管理】**，完成 API 账号的申请与开通。开通成功后，可查看企业的 **API 账号** 与 **API 密钥**。

![](/zh/aitable/data-connectors/data-connectors-overview/tapd/images/截屏2026-05-08 21.20.51_hop2TiZm8h.png)

![](/zh/aitable/data-connectors/data-connectors-overview/tapd/images/截屏2026-05-08 21.24.10_kI1xgTe6g2.png)

> 📌 **请注意**：API 账号和 API 密钥具备访问对应企业项目数据的能力，请妥善保管，避免外泄。如需作废可在【API 账号管理】中重置对应的 API 密钥，重置后原密钥将立即失效。

1. 获取项目 ID。每个数据源同步任务都需指定**项目 ID**，用于告知连接器同步哪个项目空间下的数据。登录 Tapd 后，进入对应的项目空间，点击页面右上角 **【设置】 → 【基本信息】 → 【项目信息】**，即可查看项目 ID。

> 📌 一个数据源仅支持配置一个项目 ID，如需同步多个项目的数据，请重复创建数据源。

## 选择数据源

进入 AI 表格 **数据连接中心**，搜索 **Tapd** 连接器，点击 **【使用】** 按钮，进入连接器配置界面。

![](/zh/aitable/data-connectors/data-connectors-overview/tapd/images/截屏2026-05-09 10.42.01_JBHpZsE2mr.png)

## 数据源设置

1. **关联 Tapd 账号**，首次使用时，点击 **【关联账号】** 按钮，在弹窗中填写 API 账号和 API 密钥。

![](/zh/aitable/data-connectors/data-connectors-overview/tapd/images/截屏2026-05-08 21.45.47_qRTdh2bslW.png)

填写完成后点击 **【确定】**，账号信息会保存在当前数据源中，后续可在数据源页面的账号卡片中**切换账号**或**编辑账号信息**。

1. **选择要同步的数据表**，每次数据源配置仅支持选择一个数据表。如需同步多个数据表，请重复创建数据源。本连接器目前支持同步以下数据表：

| 数据表       | 说明                 |
| --------- | ------------------ |
| Tapd 迭代列表 | 同步指定项目中符合查询条件的所有迭代 |
| Tapd 缺陷列表 | 同步指定项目中符合查询条件的所有缺陷 |
| Tapd 需求列表 | 同步指定项目中符合查询条件的所有需求 |
| Tapd 任务列表 | 同步指定项目中符合查询条件的所有任务 |

选择数据表后，连接器将自动加载对应的数据表配置。按需选择数据源获取的数据内容。

1. **字段设置**，您可按需勾选要同步的字段，主键字段默认勾选且不可取消。

## 点击创建，开始同步数据

完成上述配置后，点击 **【保存并同步】** 按钮，连接器将进行数据同步。

![](/zh/aitable/data-connectors/data-connectors-overview/tapd/images/截屏2026-05-08 21.50.22_3N1KyHauux.png)

## 完成创建并查看数据

同步完成后，可在 AI 表格左侧的数据表列表中看到新创建的数据表。该表会以「同步表」形式存在，后续可以进行以下操作：

- **修改数据同步设置**

  在数据表右侧 更多操作 菜单中选择 【数据同步设置】，可调整勾选的字段以及同步参数。
- **手动同步更新**

  在数据表右侧 更多操作 菜单中点击 【更新数据】，连接器将立即重新调用 Tapd 接口并刷新当前表数据。
- **解除同步关系**

  在数据表右侧 更多操作 菜单中点击 【解除同步关系】，同步表将转换为普通可编辑表格，与 Tapd 数据源不再保持同步。
- **新增自定义字段**

  在不影响同步字段的前提下，可以在 AI 表格中新增自定义字段（如备注、标签、AI 字段等），自定义字段不会被同步操作覆盖。
