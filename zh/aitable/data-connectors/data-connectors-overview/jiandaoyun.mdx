## 使用前准备：简道云关联账号

账号申请指引：[https://hc.jiandaoyun.com/open/10992](https://hc.jiandaoyun.com/open/10992 "https://hc.jiandaoyun.com/open/10992")

请**先登录** 简道云，新手进入到管理后台可以先领取试用版

![](/zh/aitable/data-connectors/data-connectors-overview/jiandaoyun/images/image_98uLlc9NeR.png)

获取 API Key，点击[https://www.jiandaoyun.com/open#/key/api_key](https://www.jiandaoyun.com/open#/key/api_key "https://www.jiandaoyun.com/open#/key/api_key")，创建 API Key 复制即可。

![](/zh/aitable/data-connectors/data-connectors-overview/jiandaoyun/images/image_UiVgSMrb5Z.png)

## 进入数据连接中心

点击AI表格左下角 **添加/导入** 按钮，选择 **数据连接中心** 。

![](/zh/aitable/data-connectors/data-connectors-overview/jiandaoyun/images/image_gJNkUq9c5u.png)

进入数据连接中心

![](/zh/aitable/data-connectors/data-connectors-overview/jiandaoyun/images/image_Dw_LPLZj2q.png)

## 选择数据源

支持选择或直接搜索 **简道云** 连接器，点击**使用** 按钮，进入数据源设置界面。

![](/zh/aitable/data-connectors/data-connectors-overview/jiandaoyun/images/image_Qpw4GAqpY5.png)

## 数据源设置

### **选择数据源**

进行数据源的勾选，目前仅有1个数据源，默认勾选。

![](/zh/aitable/data-connectors/data-connectors-overview/jiandaoyun/images/image_zXFYt_m1N-.png)

### **账号设置**

自定义账号名称，添加已准备好的API Key。见上面使用前准备。

![](/zh/aitable/data-connectors/data-connectors-overview/jiandaoyun/images/image_haP2o_nmHp.png)

### **字段设置**

全选/勾选部分字段，灵活设置表格字段范围，其中主键不支持取消勾选。

### **同步设置**

![  ](/zh/aitable/data-connectors/data-connectors-overview/jiandaoyun/images/20250823142129_ZKB82IJEn5.jpg)

可以开启或关闭数据表同步设置。开启时，支持选择按小时同步模式或定时同步模式：

- 按小时同步：支持选择每隔1小时、12小时或24小时进行同步。
- 定时同步：支持选择按每天、每周或每月的某个固定时间点进行同步，可以配置是否跳过节假日。

  提示：如果在连接器设置过程中出现问题，可以通过**连接器设置页-提交反馈**进行反馈。

## 点击创建，开始同步数据

连接器配置完成后，点击 **创建** 进行数据同步，成功创建后会自动新增一张数据同步表。

![](/zh/aitable/data-connectors/data-connectors-overview/jiandaoyun/images/image_XDybbmjY5R.png)

## 同步后相关操作

- **修改数据同步设置**

  已设置同步的数据表，想要修改数据同步设置，点击数据同步表右侧  图标，选择 **数据同步设置** ，支持修改同步的字段项及同步机制，开启/关闭自动同步。
- **手动同步更新**

  点击同步来的数据表，点击数据表名称右侧的 ⋮ 更多操作 图标。点击**更新数据**即可发起手动同步，点击后将重新拉取数据源数据并更新当前表。
- **解除同步关系**

  点击 **解除同步关系** 即可将同步表变为可编辑的表格，与原始数据源不再具有同步关系。

![](/zh/aitable/data-connectors/data-connectors-overview/jiandaoyun/images/image_NRnOfkXqMV.png)
