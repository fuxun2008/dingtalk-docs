AI 表格支持通过「阿里云资源管理」数据源连接器，同步阿里云账号下的 **资源标签数据**，帮助你在 AI 表格中统一管理云资源、标签体系与资源归属信息。

本文将指导你完成从阿里云到 AI 表格的完整数据同步流程，包括账号准备、密钥获取、参数配置和字段说明。

---
## 一、使用前准备

在开始前，请确认你已具备以下条件：

- 已注册并可正常登录阿里云账号  
- 账号已开通 **资源管理（Resource Management）** 服务  
- 当前账号或 RAM 子账号拥有资源管理相关的只读权限  
- 拥有 AI 表格的使用权限  

为保障账号安全，**建议使用 RAM 子账号 + AccessKey 的方式**进行数据连接，避免直接使用主账号密钥。

---
## 二、获取 AccessKey ID 和 AccessKey Secret

AI 表格通过 AccessKey 调用阿里云资源管理 API 获取数据，需要你先在阿里云控制台中创建密钥。

### 操作步骤

1. 打开阿里云官网（[https://www.aliyun.com](https://www.aliyun.com "https://www.aliyun.com")），并登录你的阿里云账号  
2. 进入「访问控制（RAM）」控制台  
3. 在左侧菜单中点击「用户」，新建或选择一个已有 RAM 用户  
4. 为该用户授予资源管理相关权限（只读即可）  
5. 进入该 RAM 用户的「认证管理」页面，创建 AccessKey  
6. 复制并妥善保存以下信息：  
   - **AccessKey ID**  
   - **AccessKey Secret**

> 说明：AccessKey Secret 仅在创建时展示一次，请及时保存。

---
## 三、在 AI 表格中创建阿里云资源管理数据源

1. 打开 AI 表格  
2. 点击顶部「数据连接中心」  
3. 在搜索框中输入「阿里云」  
4. 选择「阿里云资源管理」数据源  

---
## 四、数据源设置

在「数据源选择」步骤中，当前支持的数据源类型为：

- **资源标签列表**  

  同步当前账号下所有云资源及其对应的标签信息。

确认选择后，进入下一步。

---
## 五、账号设置

在账号设置步骤中，需要填写阿里云账号的认证信息：

- **账号名称**：自定义名称，用于在 AI 表格中区分不同阿里云账号  
- **AccessKey ID**：在阿里云控制台获取的 AccessKey ID  
- **AccessKey Secret**：在阿里云控制台获取的 AccessKey Secret  

填写完成后点击「确定」。

> AI 表格会对 AccessKey 信息进行加密存储，仅用于当前数据源的数据同步。

---
## 六、参数设置说明

### 访问域名 / 地域

用于指定需要同步资源数据的地域范围。

- 示例：华北 1（青岛）
- 不同地域下的资源需分别同步
- 如账号下资源分布在多个地域，可分别创建多个数据源

---
## 七、字段设置说明

你可以根据业务需要，选择同步到 AI 表格中的字段。

### 当前支持字段

| 字段名称   | 说明                    |
| ------ | --------------------- |
| 资源 ARN | 云资源的全局唯一标识            |
| 标签键    | 资源标签的 Key             |
| 标签值    | 资源标签的 Value           |
| 标签类型   | 标签来源类型（系统标签 / 自定义标签等） |

你可以：

- 勾选「全选」同步全部字段  
- 或仅选择业务所需字段，用于资源分类、归属或成本分析  

---
## 八、同步设置

- **同步关闭（默认）**  

  数据仅在创建或手动触发同步时更新  
- **开启同步**  

  系统将按照设定频率自动同步最新资源标签数据  

建议在资源频繁变更或标签治理场景中开启自动同步。

---
## 九、完成创建并查看数据

1. 点击右下角「创建」  
2. AI 表格开始拉取阿里云资源管理数据  
3. 同步完成后，可在 AI 表格中查看资源标签列表  
4. 数据可用于以下场景：  
   - 云资源盘点  
   - 标签规范治理  
   - 资源归属与成本分析  

---
## 十、常见问题

### 同步失败或提示无权限怎么办？

请确认 RAM 用户已授予资源管理相关权限，并检查 AccessKey 是否填写正确。

### 为什么没有同步到某些资源？

请确认所选地域是否正确，不同地域的资源需要分别同步。

### AccessKey 是否安全？

AI 表格会对 AccessKey 信息进行加密存储，仅用于当前数据源调用，不会对外暴露。
