AI 表格支持通过**阿里云对象存储（OSS）数据源连接器**，将阿里云账号下的 OSS 存储空间信息同步至 AI 表格，实现统一管理与分析。

本文将指导你完成以下操作：

- 登录阿里云控制台
- 获取 AccessKey ID 和 AccessKey Secret
- 在 AI 表格中创建阿里云对象存储数据源
- 配置参数与字段，完成数据同步

## 一、使用前准备

在开始前，请确保你已具备以下条件：

- 已开通**阿里云账号**
- 账号下已开通**对象存储 OSS 服务**
- 当前账号拥有 OSS 资源的**只读或以上权限**
- 拥有 AI 表格的使用权限

> ⚠️ 建议使用**RAM 子账号** + AccessKey 的方式进行数据连接，避免使用主账号密钥。

## 二、获取阿里云 AccessKey

AI 表格通过 AccessKey 调用阿里云 OSS API，需要你在阿里云控制台中创建并获取密钥信息。

### 1. 登录阿里云控制台

1. 打开阿里云官网：[https://www.aliyun.com](https://www.aliyun.com "https://www.aliyun.com")
2. 点击右上角**登录**
3. 使用你的阿里云账号完成登录

### 2. 创建 / 获取 AccessKey

#### 方式一：使用 RAM 用户（推荐）

1. 登录阿里云控制台后，进入**访问控制（RAM）**
2. 在左侧菜单选择**用户**
3. 新建或选择一个已有 RAM 用户
4. 为该用户授权（至少包含 OSS 只读权限，例如`AliyunOSSReadOnlyAccess`）
5. 进入**认证管理**
6. 创建 AccessKey
7. 复制并保存以下信息：
   - **AccessKey ID**
   - **AccessKey Secret**

> ⚠️ AccessKey Secret 仅在创建时可见，请妥善保存。

#### 方式二：使用账号已有 AccessKey

如你已创建过 AccessKey，可直接在**RAM → 用户 → AccessKey 管理** 中查看 AccessKey ID，并重新创建 Secret。

## 三、在 AI 表格中创建阿里云对象存储数据源

### 1. 进入数据连接中心

1. 打开 AI 表格
2. 点击左下角**数据连接中心**
3. 在搜索框中输入「阿里云」
4. 选择**阿里云对象存储**

![](/zh/aitable/data-connectors/data-connectors-overview/alibaba-cloud/aliyun-oss/images/image_1dbdOiHyK_.png)

### 2. 数据源选择

当前支持的数据源类型为：

- **阿里云对象存储空间列表**  

  同步当前账号下所有 OSS Bucket（存储空间）的基础信息。

确认选择后，进入下一步。

## 四、账号设置

在「账号设置」步骤中，关联阿里云账号信息。

![](/zh/aitable/data-connectors/data-connectors-overview/alibaba-cloud/aliyun-oss/images/image_uZd7WvRBz1.png)

### 填写说明

| 字段               | 说明                          |
| ---------------- | --------------------------- |
| 账号名称             | 自定义名称，用于在 AI 表格中区分不同阿里云账号   |
| AccessKey ID     | 从阿里云控制台获取的 AccessKey ID     |
| AccessKey Secret | 从阿里云控制台获取的 AccessKey Secret |

填写完成后，点击 确认。

🔒 AI 表格会对密钥信息进行加密存储，仅用于数据同步调用。

## 五、参数设置说明

### 1. 地域（必填）

用于指定 OSS 服务的地域范围。

- 示例：`cn-hangzhou`、`cn-shanghai`
- 该地域决定了 OSS API 的访问节点

> 如果你的 OSS Bucket 分布在多个地域，可分别创建多个数据源。

### 2. 前缀（可选）

用于过滤指定命名规则的 Bucket。

- 留空：同步账号下所有 Bucket
- 填写前缀：仅同步名称以该前缀开头的 Bucket

示例：

- `prod-`：只同步`prod-xxx` 的 Bucket
- `test/`：同步指定路径下的资源（如支持）

## 六、字段设置说明

你可以选择需要同步到 AI 表格中的字段信息。

| 字段名称             | 说明             |
| ---------------- | -------------- |
| 名称               | OSS Bucket 名称  |
| OSS 专用 Region ID | Bucket 实际所在地域  |
| 阿里云通用 Region ID  | 阿里云统一地域标识      |
| 外网访问域名           | Bucket 的公网访问地址 |
| 内网访问域名           | Bucket 的内网访问地址 |
| Bucket 存储类型      | 标准存储 / 低频访问等   |
| Bucket 创建时间      | Bucket 的创建时间   |
| 备注               | 预留扩展字段         |

你可以：

- 勾选**全选** 同步所有字段
- 或仅选择业务所需字段

## 七、同步设置

### 同步方式说明

- **关闭同步**（默认）：  

  数据仅在创建或手动刷新时更新
- **开启同步**：  

  系统将按照设定的频率自动同步 OSS 数据

> 可根据数据变更频率与使用场景选择是否开启。

## 八、完成创建并查看数据

1. 点击右下角**创建**
2. 系统开始拉取 OSS 数据
3. 同步完成后，可在 AI 表格中查看 OSS 存储空间列表
4. 数据可用于筛选、分析或与其他表格进行关联

## 九、常见问题

#### Q1：AccessKey 填写后提示无权限？

- 请确认 RAM 用户已授权 OSS 相关权限
- 建议至少包含 OSS 读取权限

#### Q2：为什么没有同步到部分 Bucket？

- 请检查「地域」是否匹配
- 是否设置了前缀过滤条件

#### Q3：AccessKey 会不会泄露？

- AI 表格对密钥进行加密存储
- 仅用于当前数据源调用，不会对外暴露
