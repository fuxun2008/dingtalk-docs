AI 表格支持通过「阿里云安全中心」数据源连接器，同步阿里云账号下的 **安全告警数据**，帮助你在表格中统一管理云上安全风险、告警事件与处置状态。

本文将指导你完成以下操作：

- 登录阿里云控制台
- 获取 AccessKey ID 和 AccessKey Secret
- 在 AI 表格中创建阿里云安全中心数据源
- 配置参数与字段，完成数据同步

## 一、使用前准备

在开始前，请确认你已具备以下条件：

- 已注册并登录阿里云账号
- 账号已开通 **阿里云安全中心**
- 账号拥有安全中心相关的只读或以上权限
- 拥有 AI 表格的使用权限

> ⚠️ 建议使用 **RAM 子账号 + AccessKey** 的方式进行数据连接，避免使用主账号密钥。

## 二、获取阿里云 AccessKey

AI 表格通过 AccessKey 调用阿里云安全中心 API，需要你先在阿里云控制台中创建密钥。

### 1. 登录阿里云控制台

1. 打开阿里云官网：[https://www.aliyun.com](https://www.aliyun.com "https://www.aliyun.com")
2. 点击右上角【登录】
3. 使用你的阿里云账号完成登录

### 2. 创建或获取 AccessKey（推荐使用 RAM 用户）

1. 登录后进入【访问控制 RAM】
2. 在左侧菜单中点击【用户】
3. 新建或选择一个已有 RAM 用户
4. 为该用户授权安全中心相关权限（至少只读）
   - 示例：安全中心只读权限
5. 进入【认证管理】
6. 创建 AccessKey
7. 复制并保存以下信息：
   - **AccessKey ID**
   - **AccessKey Secret**

> ⚠️ AccessKey Secret 仅在创建时显示一次，请妥善保存。

## 三、在 AI 表格中创建阿里云安全中心数据源

### 1. 进入数据连接中心

1. 打开 AI 表格
2. 点击顶部【数据连接中心】
3. 在搜索框中输入「阿里云」
4. 选择【阿里云安全中心】

## 四、数据源设置

在「数据源选择」中，当前支持的数据源类型为：

- **告警列表**  

  同步当前阿里云账号下的安全中心告警记录。

选择后进入下一步。

## 五、账号设置

在「账号设置」中关联你的阿里云账号。

### 填写说明

| 字段               | 说明                          |
| ---------------- | --------------------------- |
| 账号名称             | 自定义名称，用于在 AI 表格中区分不同阿里云账号   |
| AccessKey ID     | 在阿里云控制台获取的 AccessKey ID     |
| AccessKey Secret | 在阿里云控制台获取的 AccessKey Secret |

填写完成后点击【确定】。

> 🔒 AI 表格会对密钥进行加密存储，仅用于本数据源调用。

## 六、参数设置说明

### 1. 地域（必填）

用于指定安全中心数据所属地域范围。

- 示例：`国内地域`
- 不同地域对应不同的安全中心数据范围

### 2. 开始时间（必填）

用于指定同步告警数据的时间范围起点。

可选方式：

- 最近时间
- 指定时间点

### 3. 时间范围（必填）

指定同步的告警时间跨度。

- 示例：近 7 天 / 近 30 天
- 时间范围越大，同步数据量越多

## 八、同步设置

### 同步方式说明

- **同步关闭（默认）**  

  数据仅在创建或手动触发同步时更新
- **开启同步**  

  系统将按照设定频率自动同步最新告警数据

> 建议在安全监控、运营值班等场景中开启自动同步。

## 九、完成创建并查看数据

1. 点击右下角【创建】
2. AI 表格开始拉取阿里云安全中心告警数据
3. 同步完成后，可在表格中查看告警列表
4. 数据可用于：
   - 安全风险统计
   - 告警跟踪与处置
   - 多账号安全分析

## 十、常见问题

### Q1：提示无权限或同步失败？

- 请确认 RAM 用户已授权安全中心相关权限
- 检查 AccessKey 是否填写正确

### Q2：为什么告警数量与控制台不一致？

- 请确认时间范围设置
- 不同地域告警数据可能不同

### Q3：AccessKey 是否安全？

- AI 表格会对 AccessKey 信息加密存储
- 仅用于当前数据源调用，不会对外暴露
