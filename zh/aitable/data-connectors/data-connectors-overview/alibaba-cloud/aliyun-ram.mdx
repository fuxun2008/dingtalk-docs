AI 表格支持通过「阿里云访问控制（RAM）」数据源连接器，同步阿里云账号下的 **RAM 角色信息** 与 **RAM 用户信息**，帮助你在表格中统一管理云账号权限、成员与角色配置。

本文将指导你完成以下操作：

- 登录阿里云控制台
- 获取 AccessKey ID 与 AccessKey Secret
- 在 AI 表格中创建阿里云访问控制数据源
- 配置参数与字段，完成数据同步

## 一、使用前准备

在开始前，请确认你已具备以下条件：

- 已注册并登录阿里云账号
- 账号已开通「访问控制 RAM」服务
- 拥有 RAM 相关的只读或以上权限
- 拥有 AI 表格的使用权限

> ⚠️ 建议使用 **RAM 子账号 + AccessKey** 的方式进行数据连接，避免直接使用主账号密钥。

## 二、获取阿里云 AccessKey

AI 表格通过 AccessKey 调用阿里云 RAM API，需要你先在阿里云控制台中创建密钥。

### 1. 登录阿里云控制台

1. 打开阿里云官网：[https://www.aliyun.com](https://www.aliyun.com "https://www.aliyun.com")
2. 点击右上角【登录】
3. 使用你的阿里云账号完成登录

### 2. 创建或获取 AccessKey（推荐使用 RAM 用户）

1. 登录后进入【访问控制 RAM】
2. 在左侧菜单中点击【用户】
3. 新建或选择一个已有 RAM 用户
4. 为该用户授权（至少包含 RAM 只读权限）
   - 示例权限：`AliyunRAMReadOnlyAccess`
5. 进入【认证管理】
6. 创建 AccessKey
7. 复制并保存以下信息：
   - **AccessKey ID**
   - **AccessKey Secret**

> ⚠️ AccessKey Secret 仅在创建时展示一次，请妥善保存。

## 三、在 AI 表格中创建阿里云访问控制数据源

### 1. 进入数据连接中心

1. 打开 AI 表格
2. 点击顶部【数据连接中心】
3. 搜索「阿里云」
4. 选择【阿里云访问控制】

![](/zh/aitable/data-connectors/data-connectors-overview/alibaba-cloud/aliyun-ram/images/image_gLmi2rWeG2.png)

## 四、数据源设置

在「数据源选择」步骤中，可选择需要同步的数据类型：

### 支持的数据源类型

- **阿里云访问控制角色列表**  

  同步当前账号下的所有 RAM 角色
- **阿里云访问控制用户列表**  

  同步当前账号下的所有 RAM 用户

请选择其中一种（或分别创建多个数据源）。

## 五、账号设置

在「账号设置」中关联你的阿里云账号。

### 填写说明

| 字段               | 说明                           |
| ---------------- | ---------------------------- |
| 账号名称             | 自定义名称，用于在 AI 表格中区分不同阿里云账号    |
| AccessKey ID     | 在阿里云控制台中获取的 AccessKey ID     |
| AccessKey Secret | 在阿里云控制台中获取的 AccessKey Secret |

填写完成后，点击【确认】。

> 🔒 AI 表格会对 AccessKey 信息进行加密存储，仅用于数据同步调用。

## 六、参数设置说明

### 访问域名（必填）

用于指定阿里云 RAM 服务的 API 访问地址。

- 默认值：`ram.aliyuncs.com`
- 一般情况下无需修改

## 七、字段设置说明

你可以根据需要选择同步到 AI 表格中的字段。

### 1. RAM 角色字段说明

| 字段名称   | 说明          |
| ------ | ----------- |
| 角色 ID  | RAM 角色的唯一标识 |
| 角色名称   | RAM 角色名称    |
| 角色描述   | 角色的描述信息     |
| 创建时间   | 角色创建时间      |
| 更新时间   | 角色最近更新时间    |
| 最大会话时间 | 角色最大会话时长    |
| 资源描述符  | 角色的资源标识信息   |
| 标签     | 角色绑定的标签     |

### 2. RAM 用户字段说明

| 字段名称      | 说明      |
| --------- | ------- |
| RAM 用户 ID | 用户的唯一标识 |
| RAM 用户名称  | 用户名称    |
| 登录名称      | 用户登录名   |
| 用户邮箱      | 绑定的邮箱   |
| 手机号码      | 绑定的手机号  |
| 创建时间      | 用户创建时间  |
| 用户更新时间    | 最近更新时间  |
| 备注        | 用户备注信息  |

你可以：

- 勾选【全选】同步所有字段
- 或仅选择业务所需字段

## 八、同步设置

### 同步方式说明

- **同步关闭（默认）**  

  数据仅在创建或手动触发时更新
- **开启同步**  

  系统将按照设定的频率自动同步 RAM 数据

> 建议在权限频繁变更的场景中开启自动同步。

## 九、完成创建并查看数据

1. 点击右下角【创建】
2. AI 表格开始拉取阿里云 RAM 数据
3. 同步完成后，可在表格中查看角色或用户列表
4. 数据可用于筛选、权限盘点、人员管理或审计分析

## 十、常见问题

#### Q1：提示无权限或拉取失败？

- 请确认 RAM 用户已授权 RAM 相关权限
- AccessKey 是否填写正确

#### Q2：为什么没有同步到部分用户或角色？

-
- 请确认账号下是否存在对应资源
- 检查是否使用了正确的 AccessKey

#### Q3：AccessKey 是否安全？

- AI 表格会对密钥进行加密存储
- 密钥仅用于当前数据源调用，不会对外暴露
