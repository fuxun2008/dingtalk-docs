## 使用前准备

在使用本连接器前，需要在领星 ERP 后台开通开放接口，并获取一组 **App ID** 与 **App Secret**，用于授权 AI 表格读取您的领星数据。

1. 使用超级管理员账号登录领星 ERP，依次进入：**【设置】 → 【业务配置】 → 【基础】 → 【开放接口】**

> 若【业务配置】下未显示「开放接口」入口，请联系领星客服为账号开通开放平台权限。

> 📌首次使用开放接口，需使用超级管理员账号登录领星 ERP进入【**开放接口】**，需要预留邮箱用于接收领星发布的开放接口相关通知。

![](/zh/aitable/data-connectors/data-connectors-overview/lingxing-erp/images/截屏2026-05-09 10.24.58_qUHpeXwdI6.png)

1. 查看企业的 AppID 和 AppSecret。在 **【API账号管理】** 中可添加企业的 AppID 和 AppSecret。

![](/zh/aitable/data-connectors/data-connectors-overview/lingxing-erp/images/image_P-8sZG62sm.png)

> 📌**请注意**：获取该 App ID 和 AppSecret 将有权限访问企业全部数据，请妥善处理，避免外泄。如需作废可点击 **【重置】** 按钮作废并生成新的授权码，或者限制授权码有效期。

1. 凭证作废与重置

因人员离职或其他原因需要作废原有的 AppSecret 时，可使用超级管理员账号登录领星 ERP，在 **【设置】 → 【业务配置】 → 【基础】 → 【开放接口】** **→ ** 【**API账号管理**】 中点击 **【重置】** AppSecret，生成新的 AppSecret 后，原 AppSecret 将立即失效；或者点击禁用，禁止当前App ID和AppSecret访问数据。重置后请同步在 AI 表格中编辑账号信息并填入新的 App IDAppSecret。

![](/zh/aitable/data-connectors/data-connectors-overview/lingxing-erp/images/截屏2026-05-08 20.16.56_KozpZ8nB57__c4qotx82C.png)

## 选择数据源

进入 AI 表格 **数据连接中心**，搜索 **领星 ERP** 连接器，点击 **【使用】** 按钮，进入连接器配置界面。

![](/zh/aitable/data-connectors/data-connectors-overview/lingxing-erp/images/截屏2026-05-09 10.29.28_fK10y52oae.png)

## 数据源设置

1. **关联领星账号**，首次使用时，点击 **【关联账号】** 按钮，在弹窗中填写App ID和App Secret：

![](/zh/aitable/data-connectors/data-connectors-overview/lingxing-erp/images/截屏2026-05-08 20.35.14_J3pDA2bj5D.png)

填写完成后点击 **【确定】**，账号信息会保存在当前数据源中，后续可在数据源页面的账号卡片中**切换账号**或**编辑账号信息**。

1. **选择要同步的数据表**，每次数据源配置仅支持选择一个数据表。如需同步多个数据表，请重复创建数据源。本连接器目前支持同步以下数据表：

| 数据表           | 说明                               | 领星ERP数据来源               |
| ------------- | -------------------------------- | ----------------------- |
| 多平台销量统计       | 同步销量/订单量/销售额，支持按日、周、月、年维度汇总      | 【统计】→ 【销售分析】 → 【销量统计】   |
| MSKU 维度产品表现统计 | 同步 MSKU 维度的销量、销售额、毛利润等表现数据       | 【统计】→ 【销售分析】 → 【产品表现】   |
| ASIN 维度产品表现统计 | 同步 ASIN 维度的销量、销售额、毛利润等表现数据       | 【统计】→ 【销售分析】 → 【产品表现】   |
| MSKU 维度订单利润   | 同步 MSKU 维度的订单利润，含销售额、毛利润、广告花费等   | 【统计】→ 【利润统计】 → 【订单利润】   |
| 结算中心-结算汇总     | 同步亚马逊结算中心的结算汇总数据，含销售、退款、支出、转账等   | 【财务】 → 【财务结算】 → 【结算中心】  |
| 结算中心-交易明细     | 同步亚马逊结算中心的交易明细数据，支持按来源筛选         | 【财务】 → 【财务结算】 → 【结算中心】  |
| MSKU维度利润报表    | 同步MSKU维度利润报表，含销售额、广告费、仓储费、毛利润等   | 【财务】 → 【财务报告】 → 【利润报表】  |
| 仓库库存明细        | 同步本地仓/海外仓库存明细，含库存量、成本、库龄等        | 【仓库】 → 【库存】 → 【库存明细】    |
| FBA库存列表       | 同步 FBA 库存数据，含可售、在途、库龄、成本等        | 【仓库】 → 【库存】 → 【FBA库存明细】 |
| FBA货件列表       | 同步 FBA 货件数据，含货件状态、子项明细、地址信息等     | 【FBA】 → 【货件】 → 【FBA货件】  |
| 采购单列表         | 同步采购单数据，含子项明细、供应商、金额、状态等         | 【采购】 → 【采购单据】 → 【采购单】   |
| 亚马逊店铺列表       | 同步企业已授权的全部亚马逊SC店铺信息，含站点、状态、广告授权等 | 【设置】 → 【平台授权】 → 【店铺授权】  |
| 亚马逊概念店铺列表     | 同步亚马逊概念店铺信息，含站点、状态等              | 【设置】 → 【平台授权】 → 【店铺授权】  |
| 仓库列表          | 同步仓库数据，支持按仓库类型、海外仓类型、删除状态筛选      | 【设置】 → 【仓库设置】           |
| 本地产品列表        | 同步本地产品数据，含SKU、品名、采购信息、状态、标签等     | 【产品】 → 【产品管理】           |
| 亚马逊订单列表       | 同步亚马逊订单数据，支持按店铺、日期、状态、配送方式筛选     | 【销售】 → 【平台订单】 → 【订单列表】  |
| 亚马逊多渠道订单列表    | 同步亚马逊多渠道订单数据，含订单状态、商品信息、配送信息等    | 【销售】 → 【平台订单】 → 【订单列表】  |

选择数据表后，连接器将自动加载对应的数据表配置。按需选择数据源获取的数据内容。

1. **业务参数设置**，不同数据表所需的业务参数有所不同，常见参数如下：
   - **统计日期范围**：用于销量、利润、订单等具有时间维度的数据表。支持「自然日范围」与「最近 N 天动态范围」两种模式，后者会在每次同步时根据当日自动截取时间范围。
   - **店铺筛选**：可选择一个或多个领星已授权店铺，仅同步指定店铺的数据；不勾选则同步该账号下全部已授权店铺的数据。
2. **字段设置**，点击【下一步】将自动加载该数据表的字段列表。您可按需要同步的字段，主键字段默认勾选且不可取消。

![](/zh/aitable/data-connectors/data-connectors-overview/lingxing-erp/images/截屏2026-05-08 21.00.22_6nIgYgUgIf.png)

## 点击创建，开始同步数据

完成上述配置后，点击 **【保存并同步】** 按钮，连接器将进行数据同步。

![](/zh/aitable/data-connectors/data-connectors-overview/lingxing-erp/images/截屏2026-05-08 21.05.18_zTsJl9ROYX.png)

## 完成创建并查看数据

同步完成后，可在 AI 表格左侧的数据表列表中看到新创建的数据表。该表会以「同步表」形式存在，后续可以进行以下操作：

- **修改数据同步设置**

  在数据表右侧 更多操作 菜单中选择 【数据同步设置】，可调整勾选的字段以及同步参数。
- **手动同步更新**

  在数据表右侧 更多操作 菜单中点击 【更新数据】，连接器将立即重新调用领星接口并刷新当前表数据。
- **解除同步关系**

  在数据表右侧 更多操作 菜单中点击 【解除同步关系】，同步表将转换为普通可编辑表格，与领星数据源不再保持同步。
- **新增自定义字段**

  在不影响同步字段的前提下，可以在 AI 表格中新增自定义字段（如备注、标签、AI 字段等），自定义字段不会被同步操作覆盖。

## 常见问题

### Q1. 在领星 ERP 后台找不到「开放接口」入口

「开放接口」属于领星开放平台能力，需使用**超级管理员账号**登录后，在 **【设置】 → 【业务配置】 → 【基础】** 下查看。如仍未显示，请联系领星侧确认企业是否已开通开放平台权限。

### Q2. 提示「AppID 或 AppSecret 无效」

请按以下顺序排查：

1. 确认 AppID 与 AppSecret 来自**同一企业**的开放接口后台 **【API 信息】**，且未被重置；
2. 确认凭证未在复制过程中混入空格、换行等不可见字符；
3. 确认连接器服务的**出口 IP** 已加入领星侧的 IP 白名单（联系AI 表格官方进行解决）。
