#### 第二步：安装到浏览器扩展程序

安装到Chrome浏览器：

| 安装步骤                                                                                             | Chrome浏览器                                                              |
| ------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------- |
| 1. 打开Chrome浏览器，复制`chrome://extensions/` 链接到地址栏，并按回车确认打开扩展程序管理页，**或者**点击“扩展程序”按钮，打开扩展程序管理页； | ![](/zh/aitable/plugins/plugins-overview/web-scraper/install-guide/images/image_D6wd-vw3G7.png)  ![](/zh/aitable/plugins/plugins-overview/web-scraper/install-guide/images/image_HM7QdxfzED.png) |
| 1. 打开页面右上角的“开发者模式”；                                                                              | ![](/zh/aitable/plugins/plugins-overview/web-scraper/install-guide/images/image_PFBTQS5VuR.png)                                     |
| 1. 把Fusion**已解压的文件夹**拖入Chrome扩展程序界面；                                                         | ![](/zh/aitable/plugins/plugins-overview/web-scraper/install-guide/images/image_tImcl3ffLp.png)                                     |
| 1. 找到刚添加的Fusion插件，**确认启用**；                                                                  | ![](/zh/aitable/plugins/plugins-overview/web-scraper/install-guide/images/image_hYt8VkvZM1.png)                                     |
| 1. 安装成功后，**刷新**AI表格 > 打开插件边栏 > 搜索或进入插件中心打开“网页采集助手”插件，开始一次采集指令时，登录DingTalk账号，即可使用。              | ![](/zh/aitable/plugins/plugins-overview/web-scraper/install-guide/images/image_aFJgMIMhpo.png)  ![](/zh/aitable/plugins/plugins-overview/web-scraper/install-guide/images/image_z2vZ0D-f2f.png) |

安装到Edge浏览器：

| 安装步骤                                        | Edge浏览器                                                                |
| ------------------------------------------- | ---------------------------------------------------------------------- |
| 1. 打开Edge浏览器，点击右上角  ，选择“扩展”；               | ![](/zh/aitable/plugins/plugins-overview/web-scraper/install-guide/images/image_eyOw1ML8OX.png)                                     |
| 1. 点击进入“管理扩展”；                              | ![](/zh/aitable/plugins/plugins-overview/web-scraper/install-guide/images/image_9r-72RzILW.png)                                    |
| 1. 进入扩展管理页面，开启“开发人员模式”；                     | ![](/zh/aitable/plugins/plugins-overview/web-scraper/install-guide/images/image_0mB0NeNL1q.png)                                     |
| 1. 把解压过的Fusion**文件夹**拖入浏览器窗口；           | ![](/zh/aitable/plugins/plugins-overview/web-scraper/install-guide/images/image_hfIflMZD-4.png)                                     |
| 1. 在浏览器扩展按钮弹窗中点击“Fusion”，唤起浏览器插件Fusion边栏界面； | ![](/zh/aitable/plugins/plugins-overview/web-scraper/install-guide/images/image_C9ELxygGJA.png)                                     |
| 1. 使用DingTalk登录，登录后可以回到 AI 表格中启用“网页采集助手”；         | ![](/zh/aitable/plugins/plugins-overview/web-scraper/install-guide/images/image_4EaoyzmAmD.png)  ![](/zh/aitable/plugins/plugins-overview/web-scraper/install-guide/images/image_z2vZ0D-f2f.png) |
