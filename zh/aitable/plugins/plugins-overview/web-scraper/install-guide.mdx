#### 第二步：安装到浏览器扩展程序

安装到Chrome浏览器：

| 安装步骤                                                                                             | Chrome浏览器                                                              |
| ------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------- |
| 1. 打开Chrome浏览器，复制`chrome://extensions/` 链接到地址栏，并按回车确认打开扩展程序管理页，**或者**点击“扩展程序”按钮，打开扩展程序管理页； | ![](https://img.alicdn.com/imgextra/i4/O1CN01Q8zGMgRIMKD39N3z_!!6000000002014-2-tps-1552-1067.png)  ![](https://img.alicdn.com/imgextra/i2/O1CN01P44IUoSKL2L0k4bN_!!6000000000919-2-tps-366-415.png) |
| 1. 打开页面右上角的“开发者模式”；                                                                              | ![](https://img.alicdn.com/imgextra/i2/O1CN01YRwXmyF4FwB39N3z_!!6000000005942-2-tps-1552-1067.png)                                     |
| 1. 把Fusion**已解压的文件夹**拖入Chrome扩展程序界面；                                                         | ![](https://img.alicdn.com/imgextra/i4/O1CN01TFNPJHN55RG2u8fi_!!6000000007383-2-tps-1431-947.png)                                     |
| 1. 找到刚添加的Fusion插件，**确认启用**；                                                                  | ![](https://img.alicdn.com/imgextra/i1/O1CN01opRfWHcMt8F0pzMw_!!6000000003121-2-tps-413-221.png)                                     |
| 1. 安装成功后，**刷新**AI表格 > 打开插件边栏 > 搜索或进入插件中心打开“网页采集助手”插件，开始一次采集指令时，登录DingTalk账号，即可使用。              | ![](https://img.alicdn.com/imgextra/i1/O1CN01jSiERBtaGLC2PAgq_!!6000000001007-2-tps-1185-783.png)  ![](https://img.alicdn.com/imgextra/i3/O1CN01qLbW7OFy9VJ1F2e0_!!6000000006449-2-tps-612-812.png) |
