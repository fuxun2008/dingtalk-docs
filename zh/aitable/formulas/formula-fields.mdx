公式字段是AI表格中的一种字段类型，可以使用丰富的函数表达式来实现数据的灵活计算。

## 新建公式字段

点击AI表格字段标题栏右侧的 + 图标，在字段类型中选择 **公式**。

![](/zh/aitable/formulas/formula-fields/images/image_nXFdaulyVx.png)

## 编辑公式

点击 **编辑公式**，将会弹出公式编辑的窗口。

![](/zh/aitable/formulas/formula-fields/images/image_tQUgvXaMKY.png)

在上方编辑框内可以直接进行 **公式编辑**。

点击 **公式编辑**tab，可以引用字段或选择各个类型的函数方法。

点击**AI生成公式**tab，可以通过自然语言描述来生成公式，详细参考[使用AI生成公式](/zh/aitable/formulas/ai-generate-formula)。

![](/zh/aitable/formulas/formula-fields/images/image_kpXM33gLKW.png)

## 公式概念

| **名词**​ | **说明**​                    |
| ------- | -------------------------- |
| 字段      | 数据表中，目标列所对应的每一行的值，用于参与公式运算 |
| 整列字段    | 数据表中，目标列每一行的值的集合，用于参与公式运算  |
| 中括号     | 在公式中用来引用AI表格的数据表或字段        |
| 运算符     | 公式中使用的的逻辑或运算符号             |
| 函数      | 通过特定的运算规则得到期望的输出值          |
| 参数      | 在公式中参与计算的数字或文本             |
| 字符串     | 参与公式计算的一系列文本               |
| 数组      | 数值的集合                      |

## 常用运算符号

| **符号类型**​ | **运算符**​ | **说明**​                       |
| --------- | -------- | ----------------------------- |
| 数值运算符     | `+`    | 两个数值相加                        |
|           | `-`    | 两个数值相减                        |
|           | ` *`     | 两个数值相乘                        |
|           | `/`    | 两个数值相除                        |
| 文本拼接符     | `&`    | 将两个文本进行拼接；在数值与文本之间使用时，拼接数值与文本 |
| 逻辑运算符     | `>`    | 大于                            |
|           | `>=`   | 大于等于                          |
|           | `<`    | 小于                            |
|           | `<=`   | 小于等于                          |
|           | `=`    | 等于                            |
|           | `!=`   | 不等于                           |
|           | `&&`   | 与运算（AND）                      |
|           | `|`   | 或运算（OR）                       |
