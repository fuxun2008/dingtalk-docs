#### 1 功能

在表格里标记每个人的最新日报记录：

![](https://img.alicdn.com/imgextra/i1/O1CN013ipFHafrM9H3KRiM_!!6000000008004-2-tps-1640-466.png)

#### 2 如何配置

新建一个最后“更新时间字段”，系统自动标记每个记录的最后一次更新时间

![](https://img.alicdn.com/imgextra/i2/O1CN01xShyNzuv5DC1qYQ8_!!6000000002015-2-tps-910-798.png)

新建一个查找引用字段，根据人员信息找到出最新一条纪录录入的时间

![](https://img.alicdn.com/imgextra/i3/O1CN01SV1Z4NNeF0F2AC34_!!6000000005448-2-tps-1066-1204.png)

新建一个公式函数，可视化标记哪一条是最新的纪录

```javascript 
IF([最后更新时间]=[最后一次填写的时间],"✅是最新的填写结果","")
```
