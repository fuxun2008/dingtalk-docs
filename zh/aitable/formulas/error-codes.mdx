如果公式错误或者根据当前行无法计算出结果时，会在单元格中展示错误代码。

以下为AI表格的常见错误代码：

| 错误代码                 | 含义                                                             | 示例                          |
| -------------------- | -------------------------------------------------------------- | --------------------------- |
| \#NULL!             | **空值错误**  公式中包含错误的区域运算符或指定两个并不相交的区域的焦点。                    |                             |
| \#DIV/0!            | **被零除错误**  公式做除法运算时，除数是零或引用了空白单元格就会出现。                     | `2/0`                     |
| \#REF!              | **无效引用错误**  引用无效或删除了公式引用的列，一般出现在引用了某一列，但当某一列被更改或删除后。       |                             |
| \#N/A               | **值不可用错误**  某个值对函数或公式不可用，导致找不到引用值。                         | `REGEXEXTRACT("def","a")` |
| \#VALUE!            | **值错误**  公式或函数中使用的参数或操作数类型错误，例如文本参与数值运算。                   | `SQRT("test")`            |
| \#ERROR!            | **公式解析错误**  错误的公式会显示此代码。                                   | `test formula`            |
| \#NUM!              | **数字错误**  数字或函数使用了无效的数值，或者公式生成的数字太大或太小以致无法显示，如负数开平方根。      | `SQRT(-1)`                |
| \#NAME?             | **无效名称错误**  无法识别公式中的文本，如函数名或名称拼写错误。                        | `SUMMM()`                 |
| \#TOO\\_LARGE!     | **计算结果过大错误**  当计算结果超过 200 个就会出现。例如查找引用结果选择原值，但结果超过 200 个时。 |                             |
| \#MISMATCH\\_TYPE! | **类型不匹配错误**  当前实际结果与当前列结果类型不匹配，经常出现在原值被更改后。                |                             |
| \#CIRCULAR!         | **循环引用错误**  公式直接或间接地引用了自身所在的单元格形成了循环引用。                    |                             |
| \#UNSUPPORT!        | **未支持的特性错误**  公式使用到的部分函数或特性，将在未来支持使用（暂不支持），例如用到跨表的特性。      | \-                         |
