# **逻辑函数**

| 函数名称        | 函数功能                                                          | 函数示例                                                 | 说明                                                                                                                                                         |
| ----------- | ------------------------------------------------------------- | ---------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `AND`     | 当提供的所有参数均为逻辑 true 时返回 true；如果提供的参数中任何一个为逻辑 false，则返回 false。   | AND(\\[逻辑表达式1], \\[逻辑表达式2])                        | 逻辑表达式1：一个表达式或对包含表达式的单元格的引用，该表达式代表某种逻辑值（即 TRUE 或 FALSE）或者可以强制转换为逻辑值。  逻辑表达式2：更多表示逻辑值的表达式。                                                                   |
| `FALSE`   | 返回逻辑值 FALSE。                                                  | FALSE()                                              |                                                                                                                                                            |
| `IF`      | 当逻辑表达式的值为 TRUE 时返回一个值，而当其为 FALSE 时返回另一个值。                     | IF(\\[逻辑表达式], \\[返回值1], \\[返回值2])                 | 逻辑表达式：一个表达式或对包含表达式的单元格的引用，该表达式代表某种逻辑值，即 TRUE 或 FALSE。  返回值1:为 TRUE 时的返回值当“逻辑表达式”为 TRUE 时的返回值。  返回值2:为FALSE 时的返回值当“逻辑表达式”为 FALSE 时的返回值。                     |
| `IFERROR` | 如果第一个参数不是错误值，就返回第一个参数；否则，当第二个参数存在时返回第二个参数，不存在则返回空白值。          | IFERROR(\\[值], \\[错误情况的返回值])                       | 值：在“值”本身不为错误值的情况下要返回的值。  错误情况的返回值：在“值”为错误值情况下的函数返回值。                                                                                                       |
| `IFS`     | 评估多个条件，并返回与第一个值为 true 的条件所对应的值。                               | IFS(\\[条件1], \\[值1], \\[条件2], \\[值2])            | 条件1：要评估的第一个条件，可以是布尔值、数值、数组或指向这些值的引用。  值1：“条件1”为“TRUE”的情况下返回的值。  条件2：之前的条件为“FALSE”的情况下，要评估的其他条件。  值2：相应条件为“TRUE”的情况下返回的其他值。                                 |
| `NOT`     | 返回某个逻辑值的相反值 - “NOT(TRUE)”将返回 FALSE；“NOT(FALSE)”将返回 TRUE。      | NOT(\\[逻辑表达式])                                      | 逻辑表达式：一个表达式或对含有表达式的单元格的引用，该表达式表示某个逻辑值。                                                                                                                     |
| `OR`      | 只要提供的参数中任何一个为逻辑真就返回 true，如果提供的所有参数均为逻辑假则返回 false。             | OR(\\[逻辑表达式1], \\[逻辑表达式2])                         | 逻辑表达式1：一个表达式或对包含表达式的单元格的引用，该表达式代表某种逻辑值（即 TRUE 或 FALSE）或者可以强制转换为逻辑值。  逻辑表达式2：更多计算结果为逻辑值的表达式。                                                                |
| `SWITCH`  | 根据案例列表测试表达式，并返回第一个匹配案例的对应值；没有相符结果时，返回默认值（可选）。                 | SWITCH([表达式], [案例1], [值1], [案例2_或_ 默认], [值2]) | 表达式：要检查的值。  案例1：检查是否与“表达式”匹配的第一种情况。  值1：“案例1”与“表达式”匹配后返回的对应值。  案例2_或_ 默认：之前情况未与“表达式”匹配后要尝试的其他情况，或者在没有与“表达式”匹配的情况后返回的默认值（可选）。  值2：相应情况与“表达式”匹配的情况下返回的其他值。 |
| `TRUE`    | 返回逻辑值 TRUE。                                                   | TRUE()                                               |                                                                                                                                                            |
| `XOR`     | 当提供的参数个数为奇数在逻辑上为 true 时返回 true；如果参数个数为偶数在逻辑上为 true，则返回 false。 | XOR(\\[逻辑表达式1], \\[逻辑表达式2])                        | 逻辑表达式1：一个表达式或对包含表达式的单元格的引用，该表达式代表某种逻辑值（即 TRUE 或 FALSE）或者可以强制转换为逻辑值。  逻辑表达式2：更多表示逻辑值的表达式。                                                                   |
