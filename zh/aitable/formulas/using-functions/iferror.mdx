# 1 函数基础介绍

**IFERROR**是AI表格中常用的函数，用于检查某个公式或表达式是否返回错误。如果表达式的结果是错误（如#DIV/0!**,**#VALUE!**,**#REF!**,**#NAME?**,**#NULL!等），则返回用户指定的值；如果表达式的结果不是错误，则返回表达式本身的值。

**常见错误类型**

| **错误类型**​ | **错误说明**​                  |
| --------- | -------------------------- |
| \#N/A    | 数据缺失                       |
| \#VALUE! | 输入公式的方式错误或参与计算的数值错误        |
| \#REF!   | 引用的数值错误，如复制了被删除的字段内容或内容不存在 |
| \#DIV/0! | 除数为 0 而导致的错误（除数不能为 0）      |
| \#NUM!   | 当公式或函数中某个数字有问题时产生错误值       |
| \#NAME？  | 出现了不能识别的内容                 |
| \#NULL!  | 使用了不正确的区域运算符或不正确的数值引用      |

### **基本语法**

```text 
IFERROR(值, [如果出错])
```


- **值**：需要检查的单元格、公式或表达式。
- **如果出错**：当**值**返回错误时要显示的内容或返回的值。

### **示例**

#### **示例 1：处理除以零的错误**

假设[字段1]中第一行记录的内容为**0**。

```text 
=IFERROR(5/[字段1], "错误")
```


结果为：**"错误"**（因为 5/0 会产生 **#DIV/0!** 错误）

#### **示例 2：正常计算**

假设[字段1]中第一行记录的内容为**2**。

```text 
=IFERROR(5/A2, "错误")
```


结果为：**2.5**（因为 5/2 不会产生错误）通过**IFERROR**函数，您可以优雅地处理公式中的错误，从而避免错误信息干扰数据展示和分析过程。这使得电子表格更加整洁，并且可以提高用户体验和数据分析的准确性。

# 2 常见场景案例

### 2.1 找不到指定内容显示

按照要求，产品简介中需要详细注明过敏原，利用find函数可以判断每一个简介是否有标注过敏源

```text 
IFERROR（FIND("过敏原",[产品简介],1),"缺少过敏原提示❌"）

```
