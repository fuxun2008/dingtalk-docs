# 1 函数基础介绍

**IF**和**IFS**是AI表格中常用的逻辑函数，用于根据特定条件执行不同的操作或返回不同的值。

### **IF 函数**

**IF**函数允许用户指定一个条件，并根据该条件的真假返回不同的结果。它是电子表格中最基本的逻辑判断工具之一。

#### **基本语法**

```text 
IF(条件, [如果为真], [如果为假])
```


- **条件**：需要测试的逻辑表达式。
- **如果为真**：当条件为真时要返回的值。
- **如果为假**：当条件为假时要返回的值。

#### **示例**

假设[字段1]第一行记录的内容为**50**。

##### **示例 1：判断 A1 是否大于 30**

```text 
=IF([字段1] > 30, "合格", "不合格")
```


结果为：**"合格"**（因为 50 大于 30）

### **IFS 函数**

**IFS**函数是**IF**函数的扩展版，它允许用户同时测试多个条件，并返回第一个满足条件的结果。与嵌套多个**IF**函数相比，**IFS**更加简洁和直观。

#### **基本语法**

```text 
IFS(条件1, 返回值1, 条件2, 返回值2, ..., [默认值])
```


- **条件1, 条件2,...**：一系列需要测试的逻辑表达式。
- **返回值1, 返回值2,...**：当对应条件为真时要返回的值。
- **默认值**（可选）：如果没有条件为真时返回的值。

#### **示例**

假设[字段1]第一行记录的内容为**75**。

##### **示例 1：根据分数范围返回等级**

```text 
=IFS([字段1] >= 90, "优秀", [字段1] >= 70, "良好", [字段1] >= 60, "及格", TRUE, "不及格")
```


结果为：**"良好"**（因为 75 满足第二个条件）通过**IF**和**IFS**函数，您可以轻松地在电子表格中实现复杂的逻辑判断和数据处理，从而更好地满足各种业务需求。

# 2 常见问题

- 问：为什么使用 IFS() 函数时，公式没有语法错误，结果却显示为 #N/A？

  答：当输入数据不满足 IFS() 函数中的任何条件时，函数会返回 #N/A。为了避免这种情况，可以在公式最后添加一个通用条件。例如：**IFS([成绩]=100,"满分", [成绩] >=85,"优秀", [成绩] >=75,"良好", [成绩] >=60,"及格", TRUE,"不及格")** 在上述公式中，**TRUE,"不及格"** 就是一个通用条件，所有不满足前面条件的数据都将被归类为“不及格”。
