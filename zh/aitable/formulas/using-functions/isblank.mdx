# 1 函数基础介绍

**ISBLANK**是一种在电子表格软件（如 Microsoft Excel 或 Google Sheets）中常用的函数，用于检查某个单元格是否为空。如果指定的单元格为空，则返回**TRUE**；如果单元格包含任何内容（包括空字符串、公式结果等），则返回**FALSE**。

### **基本语法**

```excel formula 
ISBLANK(值)
```


- **值**：需要检查的单元格或表达式。

### **示例**

#### **示例 1：检查是否为空**

假设[字段1]第一行记录没有任何内容。

```excel formula 
=ISBLANK([字段1])
```


结果为：**TRUE**

#### **示例 2：检查包含文本的单元格**

假设[字段1]第一行记录包含文本 **"Hello"**。

```excel formula 
=ISBLANK([字段1])
```


结果为：**FALSE**
