# 1 函数基础介绍

**TEXTJOIN**是AI表格中常用的函数，用于将多个文本字符串合并为一个单一的字符串。与简单的文本连接不同，**TEXTJOIN**函数允许用户指定分隔符，并可以选择是否忽略空单元格。以下是**TEXTJOIN**函数的基本介绍：

### **基本语法**

```纯文本 
TEXTJOIN([分隔符], [忽略_空白], [文本1], [文本2])
```


**分隔符**：可能为空的字符串或指向有效字符串的引用。如果为空，文本将被简单地连接在一起。

**忽略_空白**：一个布尔值；如果为“TRUE”，则文本参数中选中的空白单元格将不会包含在结果中。

**文本1**：任何文本内容。可能是一个字符串，或是某个范围内的字符串数组。

**文本2**：其他文本内容。

### **示例**

假设 一条记录（一行）中，字段1内容为 "苹果"，字段2内容为 "香蕉"，字段3为空，字段4内容为 "葡萄"。

#### **示例 1：忽略空值**

```text 
TEXTJOIN(", ", TRUE(), [字段1], [字段2], [字段3], [字段4])
```


结果为：**苹果, 香蕉, 葡萄**

#### **示例 2：不忽略空值**

```text 
TEXTJOIN(", ", FALSE(), [字段1], [字段2], [字段3], [字段4])
```


结果为：**苹果, 香蕉, , 葡萄**

通过**TEXTJOIN**函数，您可以轻松地将多个数据源中的信息组合成一个易于阅读和处理的格式，同时控制分隔符和空值的处理方式。

# 2 常见场景案例

### 2.1 合并不同字段的内容

将门店的[名称]和[营业状态]进行合并，连接符号为"-"

```纯文本 
TEXTJOIN("-",TRUE(),[名称],[营业状态])
```
