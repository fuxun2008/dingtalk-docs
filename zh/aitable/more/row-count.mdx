## 版本说明

AI表格针对不同场景需求，为各版本用户提供差异化行数支持，所有版本均支持热行数据秒级响应，无需担心海量数据卡顿问题。

| 版本类型 | 单表默认最大行数 | 扩展行数支持    | 适用场景                               |
| ---- | -------- | --------- | ---------------------------------- |
| 免费版  | 20,000行  | 不支持扩容     | 小团队协作、个人项目管理、基础数据记录                |
| 企业版  | 30,000行  | 可申请扩容至千万行 | 中大型企业日常运营、多门店数据汇总、中等规模业务分析         |
| 旗舰版  | 50,000行  | 可申请扩容至千万行 | 集团化管理、高频数据迭代、超大规模数据分析（如电商大促、全渠道运营） |

注：行数统计包含表格内所有有效数据行，空行不计入额度；1000万行可按表申请付费使用。

## 特殊场景行数限制说明

### 数据同步与导入限制

| 复制粘贴限制                                | 单次复制AI表格内数据，或从外部数据复制粘贴至AI表格的行数上限为20,000行。      |
| ------------------------------------- | ---------------------------------------------- |
| 本地文件导入         （支持.xlsx/.csv格式） | 单个文件大小不超过20MB，导入行数无额外限制（需在当前版本单表行数额度内）。        |
| 数据源同步限制                               | 通过数据链接中心同步的AI表格，单表页同步上限为20,000行，每次同步将全量覆盖原有数据。 |

### 超行数限制处理规则

- 免费版用户超限后，需升级至企业版/旗舰版，或清理历史数据，直至行数低于20,000行方可继续新增。
- 当通过表单提交、自动化运行、接口调用等方式导致行数超出当前版本上限时，系统将自动暂停数据新增操作，并向表格所有者发送超限通知；
- 超限后，用户可选择升级版本或申请扩容，完成后即可恢复数据新增功能；已存储的数据可正常查看、编辑、导出，不受影响；

## 常见问题

**Q1：单表行数达到上限后，是否影响已有的数据计算和视图展示？**

A：不影响。已存储的数据可正常进行筛选、排序、分组、公式计算等操作，视图展示、仪表盘关联功能均保持正常，仅限制新增数据行。

**Q2：不同版本之间升级，行数额度如何衔接？**

A：版本升级后，单表行数额度即时提升至对应版本默认值；若原表格已达到原版本行数上限，升级后可直接新增数据至新版本额度，无需手动调整。

**Q3：单表行数最多支持可扩容到多少万行？**

A：企业版和付费版的企业组织可按单表进行付费扩容，一张表可按100万行、200万行、300万行（以此类推）阶梯扩容，最高可支持扩容到1000万行。

**Q4：进行单表行数扩容后，可支持多少张数据表享受权益？**

A：一张表里支持5个数据表享受额外扩容行数权益，超出5张数据表外其他数据表的行数上限回归版本对应的最大行数。如：在旗舰版上对一张表扩容到了1000万行，则这张表里有5张数据表可分别达到1000万行，其他数据表的行数上限为旗舰版的行数权益5万行。

**Q5：千万行扩容后，数据存储安全是否有保障？**

A：AI表格采用阿里云ADB-PG存算一体架构，具备银行级数据加密、多副本备份、异地容灾等安全能力，扩容后数据安全性与基础版保持一致，符合国家信息安全等级保护三级标准。
