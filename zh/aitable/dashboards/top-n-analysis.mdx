## 功能简介

仪表盘图表提供 **Top N 分析功能**，通过仅展示排名“前 N”或“后 N”的数据，聚焦关键信息，简化复杂数据视图，助力快速决策。

### 使用场景示例

- **销售分析**：查看销售额 Top 10 的产品，快速定位核心商品。
- **成本管控**：筛选利润最低的 5 个地区，及时发现问题区域。

## 操作流程

### 前提条件

使用 Top N 功能前，请确认您拥有对应权限：

- **高级权限开启** → 只有管理员/所有者可用。
- **高级权限关闭** → 所有有编辑/管理权限的人（包括管理员/所有者）都可用。

### 开启 Top N 功能

1. 在仪表盘中，选中需要配置的图表，打开配置面板。

![](https://img.alicdn.com/imgextra/i1/O1CN01BL3WxD5lN5K5y60C_!!6000000003441-2-tps-2940-1496.png)

1. 在右侧图表配置面板中，点击 **分析** 选项卡。

![](https://img.alicdn.com/imgextra/i2/O1CN01AMONxiuOUWH5y60C_!!6000000001400-2-tps-2940-1496.png)

1. 找到 **Top N** 设置项，点击开关即可开启。

![](https://img.alicdn.com/imgextra/i1/O1CN017KBIAlIBvKG5y60C_!!6000000007501-2-tps-2940-1496.png)

### 配置排名规则

#### 1. 选择排名方式

根据图表类型，系统提供不同的排名逻辑：

- **XY轴图（柱状图 / 折线图 / 条形图 / 面积图 / 组合图 / 雷达图 / 散点图）**

![](https://img.alicdn.com/imgextra/i4/O1CN01E4z6NUSPr1B2BS0q_!!6000000003466-2-tps-1076-888.png)

  - **按类别求和排名**：按分类维度（如“产品类别”）的总值排名。
  - **按系列值排名**：按选定的具体数据系列（如“利润”）排名。
  - **按类别组内排名**：在每个分类内部对系列进行独立排名。
  - **按系列求和排名**：按数据系列在所有分类下的总值排名。
- **饼图 / 环形图**

![](https://img.alicdn.com/imgextra/i2/O1CN016lcZkv9iu8J5xamY_!!6000000001442-2-tps-2936-1490.png)

  - 固定为 **按扇区值排名**，即直接比较每个数据块的大小。

#### 2. 设置保留数量

- **方向选择**：
  - **前 N 个**：展示数值最大的 N 条数据。
  - **后 N 个**：展示数值最小的 N 条数据。
- **数量输入**：在输入框中填写正整数，如 `10`、`5`。

### 关闭 Top N 功能

如需关闭筛选，再次点击 **Top N** 开关即可，图表将恢复显示全部数据。

## 常见问题

#### 问：为什么我无法使用 Top N 功能？

答：请确认您是否拥有对应表格的**管理员**或**所有者**权限。如果高级权限未开启，则需要具备图表的**可编辑**或**可管理**权限。

#### 问：设置 Top N 后，图表数据变少了，是丢失了吗？

答：数据没有丢失，只是被暂时筛选隐藏了。关闭 Top N 开关后，所有数据会重新显示。
