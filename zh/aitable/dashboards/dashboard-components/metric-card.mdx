指标卡组件能够直观地展示关键业务指标的数据，例如总收入、剩余库存等核心信息。同时，通过配置**同环比数据**，你可以清晰地对比数据的发展趋势；添加**趋势图功能**，还能深入洞察关键指标的变化动态。

新增的指标卡组件不仅继承了以往**统计数字组件**的功能，还进一步强化了**数据分析能力**。其内置的同比、环比功能以及趋势图功能，能帮助你从海量数据中挖掘更多有价值的变化信息，从而为决策提供更有力的支持。

## 添加指标卡

在仪表盘左上角点击  **添加图表** ，在弹窗菜单的图表类型中选择 **指标卡** 。

![](/zh/aitable/dashboards/dashboard-components/metric-card/images/image_JhFeoDTuT3.png)

## 配置指标卡

进入指标卡配置框，可以对于指标卡的数据来源、指标卡设置、自定义样式进行配置，并支持进行**同比／环比**的比较、绘制**趋势图**。

**数据：** 支持选择数据来源，包括数据表、数据范围，当数据范围选择**全部数据** 时，支持设置筛选条件。

![](/zh/aitable/dashboards/dashboard-components/metric-card/images/image_IAuZjRST2g.png)

**指标卡设置**：主要包括指标卡标题的设置和统计方式的设置，统计方式包括统计记录总数和统计字段数值。仅在数据源表内有数字字段，计算结果为数字的公式字段，或被引用字段为数字的查找引用字段时，才可以统计字段数值。若选择**统计字段数值**，可在**选择字段**中选择要统计数值的字段和计算方式。计算方式支持选择求和、最大值、最小值或平均值。

![](/zh/aitable/dashboards/dashboard-components/metric-card/images/image_YV8sfwXaGQ.png)

**自定义样式：** 在自定义样式的页面可以调整背景颜色、标题颜色、指标颜色、数字格式和同环比样式。数字格式包括数字、百分比、人民币和美元，支持配置小数位数和大数缩写。

![](/zh/aitable/dashboards/dashboard-components/metric-card/images/image_TTggvJrn-v.png)

## 指标卡的同环比＆趋势图功能

**同环比配置** 

**同／环比**：默认关闭，勾选开启后，即可配置对应的时间依据、时间范围、计算维度、同期/累积和计算类型（差异率／差值／原始值）。

**时间依据**：可选字段为数据表里格式为日期的公式字段。

**时间范围**：可选今天、昨天、本周、上周、本月、上月、本季度、今年、去年、最近 7 天、最近 14 天、最近 30 天、最近 3 个月、最近半年、最近 365 天。

**计算维度**：可选择同比、环比。

**同期/累计**：同期是指所选周期目前的单位时间和对比周期的相同单位时间的比较；累计是指所选周期目前的单位时间和对比周期整个周期的比较。例如：本月和上月比较，同期就是本月（3.1-3.19）和上月（2.1-2.19对比，累计是本月（3.1-3.19）和上月（2.1-2.28）对比。适用场景：同期用于比较截止到目前当前周期和上一个周期的比较；累积用于监控以上一个周期为基准，目前实现的进度。

**计算类型：** 可选差值、差异率和原始值。

**差值**： 当前数据-同期（累积）数据

**差异率**：（当前数据-同期（累积）数据）/ 同期（累积）数据 * 100%

**原始值**： 同期（累积）数据

![](/zh/aitable/dashboards/dashboard-components/metric-card/images/image_U6z6_mcVFf.png)

**趋势图配置**

**趋势图**：默认关闭，勾选开启后，即可选择趋势图的时间依据和时间范围。时间依据为数据表中的一个日期字段；时间范围为趋势图统计的时间范围。完成配置后，趋势图会以折线图的样式展示在指标卡内。

**时间依据**：可选字段为数据表里的日期格式的字段。

**时间范围**：可选今天、昨天、本周、上周、本月、上月、本季度、今年、去年、最近 7 天、最近 14 天、最近 30 天、最近 3 个月、最近半年、最近 365 天

**注**：所选的时间范围内，至少需要有 2 个数据点才能使用趋势图。

![](/zh/aitable/dashboards/dashboard-components/metric-card/images/image_lswtCcIbon.png)

> 📌**同比和环比的区别**

**同比（Year-over-Year, YoY）**

同比变化率是指与**相同统计周期的历史数据**相比较的变化，可用于观察**长期趋势**和发展情况。这里默认是年同比。

计算公式：

•  **同比差异率** = (当期数据 - 同期数据) ÷ 同期数据 × 100%

•  **同比差值** = 当期数据 - 同期数据

•  **原始值** = 同期数据

**环比（Month-over-Month, MoM 或 Period-over-Period, PoP）**

环比变化率是指与**上一个相邻统计周期**的数据相比较，用于观察**逐期的发展变化**。例如，202５年３月与202５年２月的数据对比称为环比。

计算公式：

•**环比差异率** = (当期数据 - 上一期数据) ÷ 上一期数据 × 100%

•  **环比差值**= 当期数据 - 上一期数据

•  **原始值**= 上一期数据

通过同比和环比的对比分析，可以更全面地了解数据的变化趋势和背后的业务逻辑。同比数据有助于评估长期发展，而环比数据则能捕捉短期波动，两者结合使用可以为决策提供更有力的支持。

## 管理指标卡

鼠标浮动至已添加的指标卡上，在右上方找到    图标，点击后可以选择执行以下操作：配置、重命名、复制、添加到仪表盘中心、复制为图片、导出为图片和删除。

![](/zh/aitable/dashboards/dashboard-components/metric-card/images/image_Nv-_dCbIrh.png)

此外，可以拖拽图表右下角来调整组件大小，或者拖拽组件上方区域来调整其位置。

## 常见问题

#### **问：移动端可以使用仪表盘指标卡组件吗？**

答：移动端支持查看指标卡组件，不支持新增和编辑指标卡组件。

#### **问：在配置指标卡组件时，选择的时间范围具体指的是哪段时间？**

答：时间范围具体如下：​​

| 时间范围           | 描述                      |
| -------------- | ----------------------- |
| 本周             | 指当前所在的完整的一周             |
| 上周             | 指当前所在周的上一周              |
| 本月             | 指当前所在的完整的一个月            |
| 上月             | 指当前所在月的上个月              |
| 本季度            | 指当前所在的完整的一个季度           |
| 今年             | 指当前所在的完整的一年             |
| 去年             | 指当前所在年的上一年              |
| 最近7/14/30/365天 | 指过去 7/14/30/365 天（包含今天） |
| 最近3个月          | 指当前所在月份的前 2 个月的 1 日至今天  |
| 最近半年           | 指当前所在月份的前 5 个月的 1 日至今天  |
