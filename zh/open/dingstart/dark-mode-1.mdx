组件必须要支持深色模式，否则在钉钉深色模式下页面不可用。

## **场景描述**

|  |  |
| --- | --- |
| 深色模式 | 浅色模式 |
| IMG_4153.PNG | IMG_4154.PNG |

## **实现方案**

组件被工作台页面集成后，会被自动注入 **this.props.mode** 属性。

|  |  |
| --- | --- |
| mode值 | 说明 |
| dark | 深色模式 |
| light | 浅色模式 |

## **示例代码**

### **axml 示例代码**

给组件的 className 设置“&#123;&#123;mode&#125;&#125;”变量，当此时为深色模式时，该组件的 className为'dark'。

| --- | --- |
| 代码 | image.png |

### **acss 示例代码**

```
// 浅色模式时，字体颜色为黑色
.title-area {
  color: #000000;
}

// 深色模式时，字体颜色为白色
.dark .title-area {
  color: #FFFFFF;
}
```
