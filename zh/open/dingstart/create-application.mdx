本文档包含钉钉应用的创建、添加应用能力、添加开发人员等操作步骤。

## **创建应用**

1. 登录[钉钉开发者后台](https://open-dev.dingtalk.io/)。
2. 单击**应用开发** > **企业内部应用** > **钉钉应用** > **创建应用**。
3. 填写应用信息。

   |  |  |  |
   | --- | --- | --- |
   | **配置项** | **是否必选** | **配置说明** |
   | **应用名称** | 是 | 输入应用名称，应用名称最小长度为 2 个字符。 |
   | **应用描述** | 是 | 简要描述应用提供的产品或服务，应用描述最小长度为 4 个字符。 |
   | **应用图标** | 否 | 上传应用图标，图标要求 JPG/PNG 格式、240 px \* 240 px 以上、1:1 、2 MB 以内的无圆角图标。 |
4. 单击**保存**，进入应用详情页。

创建完成后，即可单击**基础信息** > **凭证与基础信息**，查看应用凭证与基础信息。

如果你之前已经完成创建应用操作，需要查找之前创建应用，可以根据应用名称、创建人等信息进行查询。

**说明** 

如果其他开发人员，也需要查看该应用，需要在**基础信息** > **成员管理**中添加协同开发成员，详情参考[添加开发人员](/document/dingstart/optional-add-developers#)。

## **添加应用能力**

在钉钉开放平台，您可以通过添加应用能力来扩展应用的功能范围。支持的能力类型包括小程序、网页应用、酷应用和机器人等。不同能力对应不同的业务场景，例如 小程序和网页应用适用于完整功能模块的嵌入，酷应用可实现消息内交互，机器人则用于自动消息推送与交互。

**说明** 

**酷应用/机器人**：只开发酷应用或机器人应用不能上架，如果需要上架酷应用或机器人应用你需要联合小程序应用或网页应用。

1. 登录[开发者后台](https://open-dev.dingtalk.io/#/)，单击目标应用，进入应用详情页。
2. 单击**应用能力** > **添加应用能力**，选择你需要的应用能力进行添加，应用能力详情参考[应用类型介绍](/zh/open/dingstart/application-type-introduction)。
3. 在列表中，选择所需的应用能力（如小程序、网页应用、酷应用、机器人等）。

   ![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/0923809671/p1047305.png)
4. 根据引导完成能力配置，具体能力的配置项请参考对应的能力文档。

## **添加开发人员**

协同开发功能支持多名企业内部成员共同参与同一应用的开发与维护，适用于团队协作场景。通过该功能，团队成员可根据其角色权限查看代码、配置信息、发布记录，并执行相应操作。

协同开发的优势包括：

- **分工明确**：不同角色拥有不同的操作权限，便于职责划分。
- **安全可控**：非协同成员默认不可见该应用，保障应用安全性。
- **高效协作**：支持多人同时配置与调试，避免单点依赖。

**说明** 

当前登录账号具有企业管理员或应用管理权限。

1. 登录[开发者后台](https://open-dev.dingtalk.io/#/)，单击目标应用，进入应用详情页。

   ![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/2325836671/p1036902.png)
2. 单击**成员管理** > **添加人员**。完成协同开发成员的添加。

   ![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/2325836671/p1036909.png)
3. 在添加角色成员模态窗中，选择需要添加的人员和该人员角色最后，单击**确定**即可，如下图所示：

   ![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/2325836671/p1036914.png)
