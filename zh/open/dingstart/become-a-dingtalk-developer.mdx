在正式开发前，组织管理员需要给开发者添加开发者权限。不同身份的钉钉开发者可开发不同类型的应用。

|  |  |  |
| --- | --- | --- |
| **开发者** | **开发的应用类型** | **关联的组织** |
| 企业内部开发者 | 企业自建内部应用 | 作为企业内部员工开发企业自建应用。 |
| 产品方案商的开发者 | 第三方企业应用  以委托身份开发企业内部应用 | 作为产品方案商的开发者开发第三方企业应用或为企业定制开发应用，你的企业组织必须完成产品方案商认证。详情请参考[合作全流程指引](/zh/open/development/isv-cooperation-guide)。 |

## 操作步骤

组织管理员根据以下步骤为开发者添加开发者权限：

**说明** 

申请开发者权限后，开发者登录可对应用进行开发、上传和发布。

1. 组织管理员登录[OA管理后台](https://oa.dingtalk.com/index.htm#/safety/subAccount)。

2. 在管理后台，依次选择**安全与权限** > **权限管理**，然后单击**管理组**，进入权限**管理组**页面。

3. 单击**添加管理组**。![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/5340927661/p507251.png)

4. 在**编辑管理组**页面，依照下列要求填写后，单击**保存**。

- **管理组名称：**输入管理组名称。
- **成员：**分配管理组成员。
- **管理范围：**选择管理范围。
- **分配权限：**勾选对应的权限。

![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/5340927661/p507256.png)

5. 开发者登录[开发者后台](https://open-dev.dingtalk.com/#/index)，进行应用开发。
