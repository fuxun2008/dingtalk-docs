本文介绍组件支持的其他参考自JSAPI的SDK。

## 查看地图位置

**openLocation**

更多参数内容。请参考[使用内置地图查看位置](/document/development/jsapi-open-location#)。

```
getSdk().openLocation({
    longitude: '120.126293',
    latitude: '30.274653',
    name: '黄龙万科中心',
    address: '学院路77号',
});
```

## 扫码

**scan**

更多参数内容。请参考[扫码](/document/development/jsapi-scan#)。

```
getSdk().scan({
    type: 'qr',
    success: (res) => {
       dd.alert({ title: res.code });
    },
});
```
