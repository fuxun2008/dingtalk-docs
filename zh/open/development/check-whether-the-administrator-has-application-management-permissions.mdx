---
title: "查询管理员是否有应用管理权限"
---

调用本接口，用于查询企业管理员是否有应用的管理权限。

## 请求

### 基本信息

| 字段 | 值 |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/v1.0/microApp/apps/&#123;agentId&#125;/users/&#123;userId&#125;/adminAccess |
| HTTP Method | GET |
| 支持的应用类型 | appType-第三方企业应用 |
| 权限要求 | permission-qyapi\_get\_member-成员信息读权限 |

### 请求头

| 名称 | 类型 | 是否必填 | 描述 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | 是 | 调用该接口的访问凭证，通过调用[获取第三方应用授权企业的accessToken](https://open.dingtalk.io/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#)接口获取。 |

### 路径参数

| 名称 | 类型 | 是否必填 | 描述 |
| --- | --- | --- | --- |
| agentId | Long | 是 | 授权企业安装三方应用时的agentId，可调用[获取企业开通应用后的授权信息](https://open.dingtalk.io/document/development/obtains-the-authorization-information-after-the-enterprise-activates-the-application-1#)接口获取agentId参数值。 |
| userId | String | 是 | 授权企业管理员userId，可调用[获取管理员列表](https://open.dingtalk.io/document/development/query-the-administrator-list#)接口获取userid参数值。 |

GET /v1.0/microApp/apps/111/users/manager1123/adminAccess HTTP/1.1

x-acs-dingtalk-access-token:xxx
