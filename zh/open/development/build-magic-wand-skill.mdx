AI 能力是指通过使用一系列 AI 和工程技术，实现一项完整任务的特定功能或服务。一个完整的魔法棒应用通常由一个或多个技能组成，它们可以协同工作，实现复杂和多样化的 AI 功能和任务。

一个 AI 能力通常由执行链、模型、提示工程、插件、AI卡片等元件组成。关于 AI 能力元件的详细介绍，参考[元件介绍](https://open.dingtalk.com/document/ai-dev/large-model-execution-chain#)。

## **前提条件**

1. 完成[创建应用](https://open.dingtalk.com/document/ai-dev/create-an-application#)流程。
2. 已添加魔法棒应用能力，详情参考[添加 AI 应用能力](https://open.dingtalk.com/document/ai-dev/add-ai-application-capabilities#)。

## **操作步骤**

1. 在左侧导航栏中找到 **AI 应用，**单击 AI 能力打开 AI 能力页面。
2. 创建 AI 能力。

   - 方式一：从模板创建。平台提供了多个 AI 能力模板，覆盖岗位招聘、行政咨询、语言翻译、智能问答等多种场景，帮助你快速上手 AI 应用开发。
   - 方式二：直接创建。如果模板满足不了你的业务需求，可以直接创建一个空白的 AI 能力，并从零开始搭建。

   技能创建后，系统自动进入技能搭建页面。

3. 搭建 AI 能力。

   1. 选择适用于业务场景的执行链。有关通用执行链介绍和典型业务场景。
   2. 根据选定的执行链，选择所需的其他技能元件。比如，大模型执行链需要用到通用模型和提示词模板元件。因此，需要在技能搭建页面的左侧元件栏中选择一个模型和一个提示词模板。
   3. 填写元件的参数值。元件中的属性，若标注"**\***"，则为必填参数，否则为可选。关于各元件及其参数详细介绍，参考[元件介绍](https://open.dingtalk.com/document/ai-dev/large-model-execution-chain#)。
   4. 根据元件之间的依赖关系，将所有元件通过拖拽的方式连接起来，组合成为完整的执行链路，然后点击**保存**。
4. 配置触发方式。

   |  |  |  |
   | --- | --- | --- |
   | **配置项** | | **说明** |
   | 基础信息 | AI 能力名称 | 技能名称，最大长度为6个字符。 |
   | AI 能力说明 | 对技能的进一步说明，展示给使用用户，最大长度为15个字符。 |
   | 常用提示词 | 提示词标题 | 用户常用的提问词标题示例，用于引导用户触发技能。 |
   | 提示词描述 | 用户常用的提问词描述示例，用于引导用户触发技能。 |
   | 关联提示词，更多范例 | | 输入和常用提示词相似的更多问法。  说明：提示词不会向用户透出，仅提供给模型提高技能识别度。 |
5. 配置完成后，点击**保存**。

## **后续步骤**

搭建 AI 能力完成后，你需要[配置魔法棒应用](https://open.dingtalk.com/document/ai-dev/configure-the-magic-wand-application#)。
