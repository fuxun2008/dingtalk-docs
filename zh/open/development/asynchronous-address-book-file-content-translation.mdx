# 异步转译通讯录ID

## 接口调用说明

1. 构造需要转译的文档，示例如下图所示。

### 说明

   只支持xlsx，xls，csv，txt格式文件。

![接口调用说明](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/8903630871/p1075878.png)

2. 调用[单步文件上传](https://open.dingtalk.com/document/isvapp/single-step-file-upload)接口，获取media_id。
3. 调用本接口，获取转译任务ID。

### 说明

   调用本接口后，如果文件转译成功，会触发异步任务回调通知。
4. 调用[获取异步转译任务结果](/zh/open/development/obtains-the-results-of-an-asynchronous-translation-task)接口，获取转译后的文件下载链接。

### 说明

   返回的文件下载链接建议使用`<a>标签`引用，`download`属性不可指定（浏览器兼容性问题）。
5. 用户下载得到的文件内容，如下图所示。

![接口调用说明](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/8903630871/p1075879.png)

在调用本接口的过程中，你可能会遇到以下问题：

- **问题**：使用`NodeJs`第三方库`exceljs`生成的`excel`文件，文件内容看上去正常，但是转译不成功。
- **问题原因**：`exceljs`在不开启`sharedString`的情况下，会默认使用`formula string`进行文件内容写入，这种行为不合规范，导致转译失败。
- **解决方法**：查看`exceljs`文档，强制开启`useSharedStrings`选项。

## 请求

### 基本信息

| 字段 | 值 |
| --- | --- |
| HTTP URL | https://api.dingtalk.io/v1.0/contact/files/translate |
| HTTP Method | POST |
| 支持的应用类型 | appType-第三方企业应用 |
| 权限要求 | permission-qyapi_get_member-成员信息读权限 |

### 请求头

| 名称 | 类型 | 是否必填 | 描述 |
| --- | --- | --- | --- |
| x-acs-dingtalk-access-token | String | 是 | 调用该接口的访问凭证，通过调用[获取第三方应用授权企业的accessToken](https://open.dingtalk.com/document/development/obtain-the-access-token-of-the-authorized-enterprise-1#)接口获取。 |

### 请求体

| 名称 | 类型 | 是否必填 | 描述 |
| --- | --- | --- | --- |
| medias | `Map<String, String>` | 是 | 需要转译的文件信息。   - Map类型，key为钉盘文件media_id，调用[获取文件上传信息](/zh/open/development/obtain-file-upload-informations#)接口获取。 - value为文件名，需要包含文件扩展名，与调用[获取文件上传信息](/zh/open/development/obtain-file-upload-informations#)接口时传入的文件名称保持一致。        - 只支持xlsx，xls，csv，txt类型文件。 - 最大数量20个文件。 |
| outputFileName | String | 否 | 转译完打包的文件名，不需带后缀。      若medias中文件个数大于1，则该参数必填。 |
| unionId | String | 是 | 当前操作导出文档的用户的unionId，可以调用[通过免登码获取用户信息](/zh/open/development/obtain-the-userid-of-a-user-by-using-the-log-free#)接口获取。 |
