## 接入流程简介

本文档展示了创建一个企业内部应用，再使用日程提供的API，实现创建日程、修改日程、查询单个日程详情、删除日程流程。

前提条件：完成[应用创建与配置](/zh/open/dingstart/create-and-configure-an-application)的流程。

步骤一：获取应用凭证信息，获取应用 Client ID 和 Client Secret。

步骤二：申请接口权限，申请日程相关接口的权限。

步骤三：获取应用访问凭证[获取企业内部应用的accessToken](/zh/open/development/obtain-the-access-token-of-an-internal-app)，调用接口时，通过accessToken鉴权调用者身份。

步骤四：调用服务端日程相关API：

1. 调用服务端API-[创建日程](/zh/open/development/create-schedule)接口，进行创建日程。获取日程`id`。
2. 根据日程`id`，调用服务端API-[修改日程](/zh/open/development/modify-event)接口，进行日程信息修改。
3. 根据日程`id`，调用服务端API-[查询单个日程详情](/zh/open/development/query-details-about-an-event)接口，获取日程详情信息。
4. 根据日程`id`，调用服务端API-[删除日程](/zh/open/development/delete-event)接口，删除创建的日程。

## 前提条件

完成[应用创建与配置](/zh/open/dingstart/create-and-configure-an-application)的流程。

## 步骤一：获取应用凭证

1. 选择目标应用，进入应用详情页，单击**基础信息** > **凭证与基础信息**。
2. 获取应用 Client ID 和 Client Secret。

## 步骤二：添加接口权限

单击**开发配置** > **权限管理**，在权限搜索框中分别输入`Calendar.Event.Write`和`Calendar.Event.Read`，并申请权限。

## 步骤三：获取应用访问凭证accessToken

<Warning>
服务端API差异详情参见旧版API VS 新版API。以下接口均使用服务端API接口，SDK下载详情参见服务端SDK下载。
</Warning>

根据步骤一中 的 Client ID 和 Client Secret，获取应用访问凭证获取企业内部应用的access_token。

```java lines
 public void getAccessToken() throws Exception {

                .setAppKey("ding*********hgn")
                .setAppSecret("9G_O**********xamBkhgGIO");
        GetAccessTokenResponse accessToken = client.getAccessToken(accessTokenRequest);
        System.out.println(JSON.toJSONString(accessToken.getBody()));
    }
```

<Note>
支持以下2种删除场景：
</Note>

- 当组织者删除日程时（Path参数中的userId参数使用组织者uninoId），所有参与者会收到日程取消通知，同时日程将从所有参与者的日历中删除。
- 当参与者删除日程时（Path参数中的userId参数使用参与者uninoId），仅将日程从自己的日历中删除，其他日程参与者不受影响。
