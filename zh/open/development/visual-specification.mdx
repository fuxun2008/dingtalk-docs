应用Logo在钉钉工作台、广场、应用详情页以圆角方形外观展现。

## 设计规范

### 1.设计原则

| 设计原则 | 说明 |
| --- | --- |
| 简洁明了 | 应用Logo通常情况下在移动端会被不同程度的缩小，所以在设计的时候就要非常注重图形的简洁，避免在小尺寸展示的时候清晰度不足不能被识别的情况，并且简洁的图形设计方式也会提升Logo的设计品质。 |
| 表达准确 | 优秀的Logo设计首要前提是表意准确，能让用户一眼就识别出它所代表的含义。所以我们应当高度提炼产品特色找到最能代表产品属性的图形元素，并对这个元素进行突出设计。 |
| 具有差异性 | 同类型的产品很多，应用Logo都大同小异，要想让你的应用从众多的同类产品中脱颖而出，必须在突出产品核心功能的同时表现出差异性来，避免视觉同质化。 |
| 品牌延续 | 具有品牌效应的产品，应充分利用其品牌Logo，它们已经建立起非常强大品牌印象和品牌影响力，并具有超强的品牌识别度。所以在设计应用图标的时候应当充分的利用已有的品牌形象加以运用。让品牌深厚积淀继续发挥作用并且让品牌形象延续从而赋予品牌更强的生命力。 |
| 避免使用文字 | 使用文字作为应用Logo时，这种设计手法简单粗暴，由于文字太多所以只能在有限的空间内将文字缩小展示，导致应用Logo看起来拥挤很难看清楚。大量使用文字的另一个致命的后果是会大大降低应用图标的设计美感，不仅不能使用户产生好的印象反而会招致用户的反感。 |
| 不要使用照片 | 在应用Logo设计中不要直接使用照片作为Logo使用，照片是位图，位图缩放容易损失质量，用来设计Logo会造成一系列潜在的问题，照片的作用在于为Logo设计提供创意、灵感，而不是直接用于Logo的设计创作，使用矢量图则可以无损地缩放，所以对于Logo设计来说，矢量图是最适合的。 |

### 2、容器栅格

应用Logo输出需保证主体元素的完整性，不能被前端圆形容器裁切。

#### 2.1、切图要求

应用Logo输出实际尺寸为：240\*240px，直角PNG/JPG，纯色不透明背景。

![](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/a/deE5mJWxzH8Y3OnB/7b26fbbed0d7497a819f081b3bf4f1b60521.png)

#### 2.2、栅格系统

- 为统一应用Logo视觉体量，请确保背景容器内图形尺寸处于圆形、方形、矩形的栅格区域内；
- 单位栅格尺寸为8\*8px。

![](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/a/deE5mJWxzH8Y3OnB/2b90729969b345418c30a6e1e745c4cc0521.png)

#### 2.3、示例

![](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/a/deE5mJWxzH8Y3OnB/a09e9399af884fd8afc740137f5223d40521.png)

### 3、背景颜色

- 二方、三方应用可使用自己的品牌色；
- 一方应用与功能入口图标背景色，从以下色板选取；
- 不可使用渐变、纯白、纯黑色，应当为单一的纯色背景。

![市场应用LOGO规范](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/4273502461/p384339.png)

### 4、图形要求

- 主体使用“面性”图形设计手法，便于应用Logo在各种场景下保证清晰、抢眼；
- 建议使用纯白颜色填充，以保证在彩色背景下足够突出；
- 如二方、三方有自己的品牌图形，应当使用扁平化或剪影的方式呈现，以便在应用Logo缩小后易于识别；
- 正确案例请参考“2.3、示例”内容。

![](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/a/deE5mJWxzH8Y3OnB/96cff6ab07144d06a802c7024c6989790521.png)

文字Logo、主体元素面积太小，在实际展示时难以识别。

![](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/a/deE5mJWxzH8Y3OnB/4082b2147ad7446e96e5dc9a3790da400521.png)

浅色背景上使用太细的线性图形，在实际展示时清晰度不够。

## 安全风险

1. 应用Logo需原创，无法律风险；
2. 应用Logo不允许出现禁限售、低俗等非法字符和图案，如“黄赌毒、枪支、烟草等”；不能涉及政治倾向、政治色彩；
3. 应用Logo不允许出现红点、NEW、HOT等标签；
4. 不要使用二维码作为小程序Logo。
