本文档将帮助你了解钉钉应用的丰富能力，包括小程序、网页应用、酷应用和机器人。

## **小程序**

小程序应用是在钉钉内部使用的轻量级应用程序，可用于协同办公、人力资源管理、企业服务、业务流程等各种场景。

相比于网页应用，钉钉小程序开发模式采用了类似于React Native、Weex等开发框架，让你通过简洁的前端语法写出Native级别的性能体验，并且支持iOS、安卓等多端部署。

## **网页应用**

网页应用是指用通过 网页方式开发的轻量级应用，可以调用丰富的原生控件能力，帮助你高效使用获取手机基础信息、定位等手机系统的能力，同时可以直接使用扫一扫、分享、钉盘等钉钉特有的能力，带给微应用接近原生代码的体验。

## **酷应用**

将复杂的应用逻辑，通过卡片式交互，在群、文档、音视频等场景中浅透出给成员快速使用。

## **机器人**

机器人是独立存在的一个应用能力，可以开箱即用，也可以进行二次开发，无需和其他应用或者群等场景进行强制绑定，通过简单配置，用机器人将业务信息和任务在钉钉聊天场景中实现敏捷协作。

## **小程序&网页应用区别**

小程序应用和网页应用区别如下：

|  |  |  |
| --- | --- | --- |
| **对比项** | **小程序** | **H5微应用** |
| **支持的端** | 支持移动端和PC端   - Android - iOS - Windows - Mac | 支持移动端和PC端   - Android - iOS - Windows - Mac |
| **加载性能** | 首次使用略慢，后续加载快 | 受很多因素影响，优化不够好，容易慢 |
| **使用性能** | 顺滑，接近Native | 容易卡顿 |
| **页面跳转/切换** | 和Native的效果一样 | 无法达到Native的效果 |
| **开发环境搭建** | 提供钉钉开发者工具，快速创建项目 | 提供钉钉开发者工具，快速创建项目 |
| **调试** | 提供钉钉开发者工具，可以在电脑上调试大部分功能 | 在电脑上只能调试 UI，涉及到钉钉的JSAPI，必须真机调试 |
| **使用开源 UI 组件** | 目前不支持 | 支持 |
| **使用NPM包** | 支持 | 支持 |
| **模块化组织代码** | 支持小程序特有的模块化 | 使用Vue、React等框架可以获得模块化支持 |
| **灰度发布** | 钉钉提供 | 需要开发者实现 |
| **CDN** | 小程序包默认在CDN | 需要开发者自己购买相关服务 |
| **开发个人应用** | 支持 | 不支持 |
| **应用离线化** | 支持 | 支持 |
