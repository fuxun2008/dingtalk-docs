为了保障产品质量，应用提交上架或对外推广前请完成自检流程。

## 应用自检介绍

第三方企业应用开发完成后，需要进行应用自检：

- 功能自检，用于基础设置检查，例如应用服务器出口IP、推送设置等。
- 安全审核，用于安全方面检查。
- 稳定性监控，用于应用的稳定性检查，例如应用的白屏率、API平均耗时等。

## 操作步骤

1. 登录[开发者后台](https://open-dev.dingtalk.com/)。
2. 选择已创建的第三方企业应用。
3. 单击目标应用，进入详情页，选择 **应用自检**，然后单击 **开始检查**。

   ![Image 10](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/2160334161/p243890.png)
   - **功能自检**

     用于检查应用的基础设置，例如应用服务器出口IP、推送设置、API 接入等情况，检测详情如下：

     |  |  |  |
     | --- | --- | --- |
     | 检查项 | 说明 | 参考文档 |
     | 是否设置服务器出口ip | 需要在应用的开发信息中完成服务器出口IP设置。 | 开发概述 |
     | 是否设置有效推送类型 | 需要在应用的开发信息中完成推送设置。 | 概述 |
     | 官方验收组织是否成功安装当前应用 | 需要把当前应用安装到钉钉官方验收组织里用于后续产品验收。点击该第三方应用的应用自检页面中的开始监测按钮，官方验收组织（CorpId为ding0ed2f6a472ab48fef5bf40eda33b7ba0 开放平台应用审核组）会自动安装该应用。iShot2022-06-01 14  **说明**  点击开始监测按钮时，请确保该应用推送服务正常。 | — |
     | 是否完成监控中心接入 | 需要在监控中心中完成接入，并且产生监控数据。 | 监控中心 |
     | 服务端是否部署在阿里云或者聚石塔 | 应用云部署方式需选择阿里云或者聚石塔，详情参考应用部署文档。 | 部署概述 |
     | 是否完成小程序版本发布 | 需要在应用的版本管理中完成一个小程序版本发布。 | 版本管理与发布 |
     | 是否完成安全网关域名申请并在应用中使用 | 上广场的应用也就是部署到聚石塔的应用要求使用安全域名。 | [钉钉安全域名](/zh/open/development/config-domain-name) |
4. 单击 **下一步**，进入 **安全审核** 界面。
5. 参考安全准入评估指南，完成应用上架安全审核评估项的材料填写并提交。
6. 提交完成后，进入 **稳定性监控** 界面。

   **说明** 

   应用上架钉钉市场前需要完成稳定性审核。接入稳定性监控系统后，钉钉将统计以下应用数据并展示，当数据低于标准时会进行通知，详情可参考稳定性认证标准。
7. 选择 **接入稳定性监控系统**。

   ![46AAC590-2AD0-42E7-91FA-5AFA721E7370](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/0626473661/p493584.png)

   |  |  |  |
   | --- | --- | --- |
   | 数据指标 | 说明 | 指标要求 |
   | 监控中心的API成功率 | 可以在监控中心的**监控指标**->**API请求**->**成功率**处查看。 | ≥98.99% |
   | 监控中心的API平均耗时 | 可以在监控中心的**监控指标**->**API请求**->**请求耗时**处查看。 | &lt;300 |
   | 监控中心的js报错率 | 可以在监控中心的**监控指标**->**JS异常**->**异常次数PV比**处查看。 | &lt;1.99% |
   | 监控中心的白屏率 | 可以在监控中心的**监控指标**->**白屏异常**->**白屏率**处查看。 | &lt;1.99% |
   | dd.config成功率 | 调用d**d.config**JSAPI的日平均成功率。 | ≥98.99% |
   | Http推送成功率 | 如果推送类型是HTTP或SyncHttp时，成功率是统计日期内钉钉给回调地址推送的成功率（**耗时超过1500ms的推送算超时失败**）。 | ≥98.99% |
8. 单击 **自检完成**，完成自检。完成应用自检流程后，如下图所示：

   ![Image 12 ](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/2160334161/p243915.png)

   当应用完成自检后，可以在钉钉市场中进行上架或进行线下推广活动。
