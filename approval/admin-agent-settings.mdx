## 1. Overview

<Note>
The Admin can configure delegate settings in the Admin Console.

This includes the delegated approver, the delegate, and the delegation period.
</Note>

## 2. Prerequisites

*   Only an Approval Admin can perform process design, so you must first become an Approval Admin.

If you are not an Approval Admin, open DingTalk OA Approval, tap **Settings**, tap **Create Approval form**, tap **Request Admin Permissions**, then tap **Submit**.

## 3. Steps

### 1. Enter delegate settings

Go to **Approval Admin Console** > **System Management** > **Delegate Settings**.

<Frame>

![Delegate Settings entry in the Approval Admin Console](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/3BMqYyb3d9XA6qwZ/img/f566f0c2-36a4-4357-98b3-6b44fe9c8c20.png)
</Frame>

### 2. Assign a delegate

Select the **delegated approver** and the **delegate**, then choose the **delegation period**.

<Frame>

![Assigning a delegate and setting the delegation period](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/3BMqYyb3d9XA6qwZ/img/9f36e909-5474-46ed-bf5b-cfda2bf64acb.png)
</Frame>

### 3. View delegation records

Click **Delegation Records** to query records by **delegated approver** or **delegate**, or to Undo an active delegation Record.

<Frame>

![Delegation Records list](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/3BMqYyb3d9XA6qwZ/img/7046dd1d-8b67-4219-bc1e-8af64f7822c7.png)
</Frame>
