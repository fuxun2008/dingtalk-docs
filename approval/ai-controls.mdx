## 1. Capability overview

<Note>
Value in one sentence: helps approvers quickly grasp key form information and improve decision efficiency.

Applicable role: approver.

Supported fields: Text, Number, Image, and most other approval form controls. Attachments and business control groups are not supported yet.

Core capability: the admin selects a skill for the control → the AI runs automatically when the approver opens the form.
</Note>

| Before | After |
| --- | --- |
| The form has too much content, making key points hard to find | Text summarization: like a secretary, summarizes the core content of the application in one sentence |
| Key information such as dates, amounts, and quantities is scattered and easy to miss | Information extraction: like a secretary, surfaces the key information and presents it in a structured way |
| Cross-border approvals where you cannot read the form content | Text translation: like an on-site translator, provides translation support when you need to process the approval |
| Images have to be reviewed one by one, which is inefficient | Image interpretation: like a seasoned expert, interprets images and delivers professional judgments |

## 2. Applicable scenarios

<Note>
Input: fields on the form (custom selection, up to 10).

Judgment basis: the 4 default skills plus a custom prompt.

Output: conclusions delivered to the approver.
</Note>

Prompt example:

```text

Deduct points based on the severity of any errors, with a minimum of 0. If there are more than 4 images, take the 4 highest-scoring ones.
Window display: max 30 points, requires at least 3 images; other rules are the same as above.
Advertising signage: max 30 points, requires at least 3 images; other rules are the same as above.

## 5. FAQs

<AccordionGroup>

<Accordion id="q1" title="Who can see the AI control?">

Like other controls, the AI control's visibility can be set per step:

<Frame>

![Field permissions settings on a step, where the AI control's visibility can be configured per step](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/yBRq1ZPyX12BWOdv/img/16d3ffdb-98d8-4162-8f56-78e4ccfc3ddd.png)
</Frame>

</Accordion>

<Accordion id="q2" title="Which controls are supported?">

Text summarization, information extraction, and text translation: do not support description text, Image, detail/Spreadsheet, Attachment, Signature, industry contacts department, associated approval form, engineering project, all business controls, ID card recognition, or all business control groups.

Image interpretation: only supports the Image control.

</Accordion>

<Accordion id="q3" title="Can it be used on mobile?">

The configuration side currently supports only desktop and web, while the usage side supports both mobile and desktop.

</Accordion>

<Accordion id="q4" title="Will the AI read my approval content?">

Only while the AI capability is running, the current content is sent temporarily for generation; it is not stored or logged afterward, meeting organization data security requirements.

</Accordion>

</AccordionGroup>
