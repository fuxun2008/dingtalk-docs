## 1. Overview

<Note>
Admins can set a direct manager as an approver.

A direct manager refers to a manager on a business-related reporting line other than the Contacts manager:

For example, in project management, project team Users on a specific project must report to the project manager and project director when handling project-related Approvals.

For example, in product R&D, procurement, design, and production teams must report to the product development lead when handling Approvals related to that product's R&D.

When you set a direct manager as an approver and the direct manager later changes, you only need to adjust the direct manager to keep the process running normally.

Direct manager updates take effect simultaneously on Approvals that have already been initiated but have not yet reached the current Step, as well as on process settings in approval templates.
</Note>

## 3. Steps

### 1. Set the direct manager

In the browser, the Admin opens the [DingTalk Admin Console](https://oa.dingtalk.io), then clicks [Contacts] - [User Management] to open the User List:

<Frame>

![Open the User Management page under Contacts in the Admin Console](https://img.alicdn.com/imgextra/i1/O1CN01I1SGJMj9HbG5qIC2_!!6000000005577-2-tps-2878-1796.png)
</Frame>

Locate the target User, click [More] on the right, and select [Edit User Info]:

<Frame>

![Click More on the right of the User and select Edit User Info](https://img.alicdn.com/imgextra/i4/O1CN01pbOhWV4iUxD5qIC2_!!6000000005155-2-tps-2878-1796.png)
</Frame>

In the "Direct Manager" field of the Edit User Info panel, add the corresponding User, then click [Confirm] to Save:

<Frame>

![Set the direct manager in the Edit User Info panel](https://img.alicdn.com/imgextra/i4/O1CN01nCPxkLx4kTC5qIC2_!!6000000007832-2-tps-2878-1796.png)
</Frame>

### 2. Set the direct manager as approver in the Approval process

On the "**Approval Admin Console**" - "**Form Management**" page, click [**Edit**] in the Form Action column.

<Frame>

![Click Edit in the Form Action column on the Form Management page](https://img.alicdn.com/imgextra/i1/O1CN01XbUIqd5PJ7H5bBcU_!!6000000005183-2-tps-2758-1728.png)
</Frame>

Click [**Process Design**] to open the main process design interface.

<Frame>

![Click Process Design to open the main interface](https://img.alicdn.com/imgextra/i1/O1CN01rzDmSqUAZpF5bBcY_!!6000000001097-2-tps-2758-1732.png)
</Frame>

Click the "**Approver Card**" to open approver Settings. Under "Select the approver for this node", select direct manager approval. You can then Configure which level of the initiator's direct manager acts as the approver.

<Frame>

![Select direct manager approval in the approver Settings](https://img.alicdn.com/imgextra/i2/O1CN016okjsklzrxD5bgqA_!!6000000005317-2-tps-2762-1736.png)
</Frame>
