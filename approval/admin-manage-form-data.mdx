## 1. Overview

<Note>
Admins can configure premium settings.

Premium settings apply to the **current form only**.

They include initiator settings, approver settings, data title and summary settings, permission settings, submission reminders, and more.
</Note>

## 3. Steps

### 1. Access form data management

Click **Manage Approval Forms** in the top-right corner, and then click **Form Data Management** to manage your data.

<Frame>

![Entry to Form Data Management](https://img.alicdn.com/imgextra/i2/O1CN01MjDM9iE0UfB5bREK_!!6000000005692-2-tps-2760-1732.png)
</Frame>

### 2. Query and export data

Query data by form name, approval status, initiator, approval number, submission time, or completion time. The time range cannot exceed six months.

<Frame>

![Query filters for form data](https://img.alicdn.com/imgextra/i4/O1CN01STqUqqdkq7I5bBcW_!!6000000001341-2-tps-2758-1730.png)
</Frame>

*   Select the query results. You can select multiple records or Select all, and then click **Export All**.

<Frame>

![Export selected records](https://img.alicdn.com/imgextra/i1/O1CN01thnEYfJLPFC5cRfU_!!6000000000907-2-tps-2768-1736.png)
</Frame>

### 3. Delete data

After filtering or querying, Select all to delete records in bulk, or select specific records and click **Delete Selected**.

<Frame>

![Delete selected records](https://img.alicdn.com/imgextra/i4/O1CN01KMuRSTL3tPB5bREI_!!6000000003013-2-tps-2760-1730.png)
</Frame>

After you click Delete, a confirmation dialog appears with two options: **Delete approval form only** and **Delete and clear associated data**.

*   Delete approval form only: Deletes only the Approval form without removing data in associated systems. For example, when deleting a leave request approval, this option does not affect the leave that has already been applied for. **Dates that have already been requested for leave cannot be requested again.**

*   Delete and clear associated data: Deletes the Approval form and also removes data in associated systems. For example, when deleting a leave request approval, this option restores the previously requested leave dates so they can be requested again. **Once associated system data is deleted, it cannot be recovered.**

<Frame>

![Deletion confirmation dialog with two options](https://img.alicdn.com/imgextra/i2/O1CN01LxzIZrwWy1J5bREK_!!6000000006571-2-tps-2760-1732.png)
</Frame>

Because deletion has a significant impact, a personal Signature is required for confirmation.

<Frame>

![Personal signature required to confirm deletion](https://img.alicdn.com/imgextra/i4/O1CN013agKF9uixOH5bREK_!!6000000005602-2-tps-2760-1732.png)
</Frame>

After deletion succeeds, review it under **Activity log** > **Deletion records**.

<Frame>

![Review deletion records in the activity log](https://img.alicdn.com/imgextra/i1/O1CN01oSEhNDywuXF5bBcW_!!6000000002212-2-tps-2758-1730.png)
</Frame>

### 4. Transfer data

When an error occurs with an individual Approval form—for example, when an approver did not set up an approval delegate before taking leave—the Admin can transfer the in-progress Approval form to another approver by clicking **More** under **Data Management**.

<Frame>

![Transfer an in-progress approval form via More](https://img.alicdn.com/imgextra/i1/O1CN01Rg1PMtEYkNF5bgq2_!!6000000005701-2-tps-2762-1728.png)
</Frame>

### 5. Download approval form details

Click **View** to open the form details, then click **Download** in the top-right corner to save the current form as a PDF for archiving.

<Frame>

![Download the approval form as a PDF](https://img.alicdn.com/imgextra/i1/O1CN01qTjRzbO9wRH5bBcQ_!!6000000001762-2-tps-2758-1724.png)
</Frame>

### 6. Activity log

In the Admin Console, go to **Data Management** > **Activity log** to view records for actions such as Export, Print, Delete, attachment cache cleanup, and template sync.

<Frame>

![Activity log in the Admin Console](https://img.alicdn.com/imgextra/i4/O1CN01ifJsld8pERD5bwRw_!!6000000000024-2-tps-2764-1736.png)

### 7. Process handover

1) **Approval process handover**

When a User's position changes or a User leaves the company, go to **Process Handover** in the Admin Console to bulk replace the "designated approver" set in the approval process with another "designated approver," so approver changes can be completed quickly.

If you select another type—such as manager or role—the approvers configured in the approval process are automatically replaced when the corresponding manager or role settings are updated.

2) **Pending approval form handover**

Use **Pending Approval Form Handover** to bulk transfer approval forms that have been submitted and are still in progress.

Note the following:

*   You can hand over a pending Approval form only after the process reaches the Step that needs to be handed over. Forms that have not yet reached that Step do not appear in the pending List.

*   For forms whose approver is set as a role or manager, if the form has been submitted and is in progress, you must also use **Pending Approval Form Handover**. Approvers are not automatically replaced when roles or department managers are updated.
