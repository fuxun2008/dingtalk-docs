## 1. Detailed instructions

For example, in a reimbursement approval, when a different reimbursement type is selected, the reimbursement amount field should display tip text indicating the amount limit for that type. Transportation has a maximum reimbursement of 200 CNY, meals 400 CNY, and office supplies 100 CNY.

### 1) How to set it up

First, configure the reimbursement type Select field with three options: Transportation, Meals, and Office Supplies.

<Frame>

![Configure the reimbursement type Select field with three options](https://img.alicdn.com/imgextra/i2/O1CN011zVflhAPNRH3hMFt_!!6000000004810-2-tps-1822-843.png)
</Frame>

Next, set up the fields to be linked—that is, the amount fields shown for each reimbursement type—and configure the tip text. Edit the Title, tip text, and other properties in the panel on the right.

<Frame>

![Set up the linked amount fields and configure the tip text](https://img.alicdn.com/imgextra/i2/O1CN01IVvJUyWAiTI3th9g_!!6000000002342-2-tps-1920-1020.png)
</Frame>

Then click the reimbursement type Select field, and click "Option linkage".

<Frame>

![Click the Select field and choose Option linkage](https://img.alicdn.com/imgextra/i1/O1CN01Y4g6qFLgZVD3th9g_!!6000000001009-2-tps-1920-1020.png)
</Frame>

Select the amount fields you configured earlier, then click "Confirm".

<div style={{display: 'flex', flexDirection: 'column', gap: '16px', margin: '16px 0'}}>
<Frame>

![Select the previously configured amount fields](https://img.alicdn.com/imgextra/i2/O1CN01HhU4ZcQrw3D3hMFt_!!6000000003561-2-tps-1822-843.png)
</Frame>

<Frame>

![Click Confirm to save the option linkage settings](https://img.alicdn.com/imgextra/i2/O1CN01Dtcv1BqCJBB3hMFt_!!6000000001152-2-tps-1822-843.png)
</Frame>
</div>

Finally, click "Publish" to complete the setup.

<Frame>

![Click Publish to finish the configuration](https://img.alicdn.com/imgextra/i4/O1CN01ietO1XpEUYL3hMFt_!!6000000001048-2-tps-1822-843.png)
</Frame>
