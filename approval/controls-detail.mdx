## 1. Detailed instructions

The [Detail/Spreadsheet] control works like a List or Spreadsheet. Use it when multiple records with the same fields need to be filled in. You can combine it with controls such as single-line input, amount, number, and select. For example, in an item request application where an Employee needs to request several different items at once, the Admin can add the [Detail/Spreadsheet] control in [Form design].

### 1) How to set up

Drag the [Detail/Spreadsheet] control from the control library on the left and drop it into the desired position on the Form.

<Frame>

![Dragging the Detail/Spreadsheet control onto the Form](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/AmPdnpmdDExgqw98/img/5847dc3c-4b41-4530-9016-a5ea132aed68.gif)
</Frame>

Drag other controls into the [Detail/Spreadsheet] control as needed, such as [Single-line input] and [Number input], to record the item name and quantity.

<Frame>

![Adding sub-controls to the Detail/Spreadsheet control](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/AmPdnpmdDExgqw98/img/3fc6cc4c-2221-4626-8419-76d941537f58.gif)
</Frame>

Click the [Detail/Spreadsheet] control to set the Title and action name.

<Frame>

![Setting the Title and action name](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/AmPdnpmdDExgqw98/img/9b7a1af1-16ce-4854-b63e-83985ef4e9aa.gif)
</Frame>

Set the **input method** to List or Spreadsheet.

<Frame>

![Input method options: List or Spreadsheet](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/AmPdnpmdDExgqw98/img/e67a21b0-4314-400e-b99a-cf5481883ac5.png)
</Frame>

Set the print layout to horizontal or vertical.

<Frame>

![Setting the print layout](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/AmPdnpmdDExgqw98/img/bda9b7de-1610-4b80-a282-a0c38c86d799.gif)
</Frame>

Once configured, click "Publish" in the upper-right corner.
