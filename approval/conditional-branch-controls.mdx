The fields that can be used as approval conditions are **Number input, Select, Multiselect, Amount, Formula, Department, and Date range**, along with Number, Amount, and other fields placed inside a Details table / Spreadsheet.

<Note>
Drag the field to a suitable position on the form. Every field must be **set to Required** before it can be used as a condition.
</Note>

The setup for each field type as an approval condition is described below.

### 1. Select

When a Select field is used as a condition, matching is based on the chosen option — when the initiator selects a given option on the form, the Approval form enters that branch.

In form design, add a Select field, edit its options, and turn on Required:

<Frame>

![Add a Select field in form design and edit its options](https://img.alicdn.com/imgextra/i3/O1CN01OfqRENoNi9F5bBcY_!!6000000002404-2-tps-2758-1732.png)
</Frame>

In the condition Settings panel of process design, check the options that should trigger this branch:

<Frame>

![Check Select options as conditions in the condition Settings panel](https://img.alicdn.com/imgextra/i2/O1CN01GV2HglQpEHJ5bBcY_!!6000000000556-2-tps-2758-1732.png)
</Frame>

### 2. Multiselect

When a Multiselect field is used as a condition, two matching modes are supported: **Full match** and **Contains any**. Full match requires the initiator's selected options to be exactly the same as the condition; Contains any is triggered as long as any one of the condition's options is selected.

In form design, add a Multiselect field, edit its options, and turn on Required:

<Frame>

![Add a Multiselect field in form design and edit its options](https://img.alicdn.com/imgextra/i1/O1CN01nbzEu4k1yhH5aw0o_!!6000000002418-2-tps-2756-1734.png)
</Frame>

In the condition Settings panel, select **Full match** or **Contains any** as the matching mode and check the corresponding options:

<Frame>

![Select the matching mode for Multiselect in the condition Settings panel](https://img.alicdn.com/imgextra/i3/O1CN017tA9uHJdgsB5aw0o_!!6000000002092-2-tps-2756-1734.png)
</Frame>

### 3. Date range

When a Date range field is used as a condition, the check runs against the **duration** automatically calculated between the start and end time, and supports less than, less than or equal to, equal to, greater than or equal to, greater than, and between (two numbers). Typical scenario: a leave request under 12 hours goes to the manager for Approval; if it is longer, an additional Approval from the department head is required.

In form design, add a Date range field and turn on Required:

<Frame>

![Add a Date range field in form design](https://img.alicdn.com/imgextra/i4/O1CN018sDNyftX38E5bBca_!!6000000001861-2-tps-2758-1734.png)
</Frame>

In the condition Settings panel, select the comparison mode for **Duration (hours)** and enter a numeric value:

<Frame>

![Select the comparison mode for duration in the condition Settings panel](https://img.alicdn.com/imgextra/i4/O1CN01TGRDCbhqx8G5bwRo_!!6000000002412-2-tps-2764-1728.png)
</Frame>

### 4. Number input

When a Number input field is used as a condition, the check runs against the entered number and supports less than, less than or equal to, equal to, greater than or equal to, greater than, and between (two numbers).

In form design, add a Number input field and turn on Required:

<Frame>

![Add a Number input field in form design](https://img.alicdn.com/imgextra/i3/O1CN01D0vw6SbdEhG5bREE_!!6000000004500-2-tps-2760-1726.png)
</Frame>

In the condition Settings panel, select the comparison mode for the Number input and enter a numeric value:

<Frame>

![Select the comparison mode for the Number input in the condition Settings panel](https://img.alicdn.com/imgextra/i2/O1CN01JYA3KFLmqhL5bREM_!!6000000000895-2-tps-2760-1734.png)
</Frame>

### 5. Amount

When an Amount field is used as a condition, the check runs against the entered amount and supports less than, less than or equal to, equal to, greater than or equal to, greater than, and between (two numbers). Typical scenario: reimbursements within 1,000 CNY go to the manager for Approval; anything above adds a finance Approval.

In form design, add an Amount field and turn on Required:

<Frame>

![Add an Amount field in form design](https://img.alicdn.com/imgextra/i2/O1CN011k5J8TkTVHD5bgq8_!!6000000008042-2-tps-2762-1734.png)
</Frame>

In the condition Settings panel, select the comparison mode for **Amount (CNY)** and enter a numeric value:

<Frame>

![Select the comparison mode for Amount in the condition Settings panel](https://img.alicdn.com/imgextra/i2/O1CN01zwumWv83PeB5bgq2_!!6000000001493-2-tps-2762-1728.png)
</Frame>

### 6. Formula

When a Formula field is used as a condition, the check runs against the Formula's calculated result and supports less than, less than or equal to, equal to, greater than or equal to, greater than, and between (two numbers). For example, calculate the total price as unit price × quantity, then route the Approval by that total.

In form design, add a Formula field and configure the Formula:

<Frame>

![Add a Formula field in form design](https://img.alicdn.com/imgextra/i1/O1CN01dik5MDXqNGD5ZAkG_!!6000000005299-2-tps-2742-1726.png)
</Frame>

In the condition Settings panel, select the comparison mode for the Formula's result and enter a numeric value:

<Frame>

![Select the comparison mode for the Formula's result in the condition Settings panel](https://img.alicdn.com/imgextra/i3/O1CN01nJMVHNNIjiD5bgpy_!!6000000005432-2-tps-2762-1724.png)
</Frame>

### 7. Fields inside a Details table / Spreadsheet

Amount, Number, and other fields placed inside a Details table / Spreadsheet can also be used as conditions, with two aggregation modes supported: check by the **sum** across all Records, or check by **any single value** (matched as soon as any one Record satisfies it).

In form design, add a Details table / Spreadsheet, and place an Amount or similar field inside it:

<Frame>

![Place an Amount field inside a Details table / Spreadsheet](https://img.alicdn.com/imgextra/i2/O1CN011k5J8TkTVHD5bgq8_!!6000000008042-2-tps-2762-1734.png)
</Frame>

In the condition Settings panel, select the comparison mode for **Spreadsheet.Amount (CNY).Sum** or any single value of **Spreadsheet.Amount**, and enter a numeric value:

<Frame>

![Check the Amount inside Details by sum or by any single value in the condition Settings panel](https://img.alicdn.com/imgextra/i1/O1CN01rh6xhW8JWQC5bwRg_!!6000000004904-2-tps-2764-1720.png)
</Frame>
