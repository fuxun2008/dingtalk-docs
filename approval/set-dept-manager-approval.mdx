## 1. Overview

<Note>
An Admin can set a department manager as an approver.

A department manager refers to the manager assigned in Contacts.

When a department manager is set as an approver, if the department manager changes, the Approval process continues to run normally—simply update the department manager.

Changes to a department manager take effect on both Approvals that have already been initiated but have not yet reached the current node, and on the process Settings in approval templates.
</Note>

## 2. Prerequisites

*   Only an Approval Admin can perform process design, so you must first become an Approval Admin.

If you are not an Approval Admin, open DingTalk OA Approval, click [Settings], click [Create Approval form], click [Apply for Admin Permissions], and click "Submit".

Once the Admin receives the pending approval reminder and approves it, the corresponding Employee is automatically granted Approval Admin Permissions.

## 3. Steps

### 1. Set the department manager

The Admin enters the [DingTalk Admin Console](https://oa.dingtalk.io) URL in the browser to open the Admin Console, then clicks "Contacts Management" to open internal Contacts management.

After clicking Add Department, click the "..." next to the Department name, click Set department manager, Select the User that appears from the Contacts, and click "Confirm" to complete the setup.

Note: the department manager must belong to the current Department.

#### 2. Set a department manager as an approver in the Approval process

On the **"Approval Admin Console"** - **"Form Management"** Page, click [**Edit**] in the Form Action column.

Click [**Process design**] to open the main process design interface.

For the node approver, Select "department manager". You can choose which level of department manager above the initiator to route to, up to the 8th level.
